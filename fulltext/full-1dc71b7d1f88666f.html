摘要

机器人能否自主开展并从交互与经验中学习，是该领域的一项核心挑战，可为劳动密集型人工示范提供一种可扩展的替代方案。然而，实现此类“玩耍”需满足两个条件：（1）策略需对多样、甚至分布外的环境状态具备鲁棒性；（2）需有持续生成有用机器人经验的流程。为应对这些挑战，我们提出 Tether——一种涉及结构化、任务导向交互的自主功能玩耍方法。

首先，我们设计了一种新型开环策略，通过将少量源示范（≤10）的动作锚定于目标场景中的语义关键点对应关系，实现动作形变。实验表明，该设计数据效率极高，且在显著的空间与语义变化下仍具鲁棒性。

其次，我们通过视觉-语言模型（VLM）的视觉理解能力，将该策略部署于真实世界中，执行任务选择—执行—评估—改进的连续循环，从而生成多样、高质量数据集，仅需极少人工干预。在类家庭多对象环境中，本方法首次实现了从仅少量示范起步、持续24小时以上的自主多任务玩耍，生成超1000条专家级轨迹，持续提升闭环模仿策略性能，最终训练出与人工收集示范训练策略相媲美的策略。

1 引言

近期机器人操作的进展主要依赖于模仿学习策略（Zhao et al., 2023; Chi et al., 2023; Zhao et al., 2024; Black et al., 2024; Kim et al., 2024; Brohan et al., 2022, 2023; Collaboration et al., 2024），其训练数据来自真实世界的遥操作示范。所有这些方法中，人类教学所需的努力均十分巨大：尽管持续 efforts 简化遥操作界面（Zhao et al., 2023; Shafiullah et al., 2023; Chi et al., 2024; Cheng et al., 2024; Fu et al., 2024），但此类示范数据集本质上仅能随人类时间线性扩展；而这些数据饥渴的策略架构需大量空间与语义多样化的数据集，才能实现有效泛化（Lin et al., 2024）。

本文提出一种替代范式：受发展心理学中“功能玩耍”（functional play）（Piaget, 1962; Smilansky, 1968）启发——其特征为结构化、任务导向的交互与重复练习——我们设计了 Tether，一种规避人类努力瓶颈的自主机器人玩耍方法。

我们的方法包含两个关键组件。首先，自主功能玩耍需一种极强鲁棒的策略，能可靠地从错误和分布外状态中恢复。我们未依赖大规模数据训练大型神经策略架构，而是设计了一种新型开环策略类，专门支持少量示范下的泛化。具体而言，我们的架构利用了语义图像关键点对应关系的显著进展：给定包含新任务相关对象实例、新空间布局与新干扰物的新场景，系统首先计算其与示范图像的关键点对应关系，选择最匹配的示范，计算每个对应关系的3D变换，并据此形变机器人轨迹以适配新场景。

在12项类家庭操作任务上验证表明，我们的策略优于其他方法，包括依赖基础模型或在大型机器人/互联网数据集上预训练的方法。

其次，我们将策略嵌入一个循环功能玩耍流程中，自主产生数据以持续训练下游策略。针对每项仅有少量人工示范的任务集合，我们调用VLM反复规划并选择策略应尝试的任务。这是无需人工重置的真实世界玩耍：流程自然诱导重置，随着对象配置随玩耍漂移，初始状态分布逐渐扩大。

此外，为评估次优玩耍数据，我们调用VLM检测成功执行，用于下游的过滤式模仿学习。我们表明，该流程可在26小时内以极少人工干预（仅5次干预，总计1分钟，占执行次数的0.26%）收集超1000条新专家级示范。我们还验证了，这些新生成示范流持续提升模仿学习策略的训练效果，策略随玩耍数据增多而持续改进，达到与人工收集示范训练策略相媲美的高成功率。

总结贡献如下：
1. 一种关键点对应驱动的轨迹形变策略，在多样操作任务中展现出卓越的空间与语义鲁棒性。
2. 一种多任务VLM引导的玩耍流程，可生成大量专家级示范，支撑下游神经策略训练。

2 相关工作

2.1 模仿学习中的鲁棒性

为构建在多样环境中表现优异的鲁棒策略，许多前期工作转向扩展数据与策略架构，常借助基础模型或大型人工收集示范数据集（Khazatsky et al., 2024; Collaboration et al., 2024; AgiBot-World-Contributors et al., 2025）。突出技术包括：在非机器人数据（如人类视频）上训练机器人表征（Nair et al., 2022; Ma et al., 2023; Shi et al., 2025）；查询视觉-语言模型（VLM）或大语言模型（LLM）（Nasiriany et al., 2024; Goetting et al., 2024; Fang et al., 2024）；微调视觉-语言-动作模型（VLAs）（Black et al., 2024; NVIDIA et al., 2025; Intelligence et al., 2025）。

另一类方法为在更少示范上训练的模型设计强内置先验，部分采用开环执行：构建动作可达性或基元（Kuang et al., 2024; Haldar & Pinto, 2025）；从现有数据集检索（Du et al., 2023; Memmel et al., 2024; Xie et al., 2025）；利用预训练表征与模型（Pari et al., 2021; Burns et al., 2023; Shi et al., 2024）；或利用3D场景几何（Rashid et al., 2023; Goyal et al., 2024; Ke et al., 2024; Ze et al., 2024）。

与我们工作最接近的是基于视觉语义关键点对应的方法。与面向对象的方法（Devin et al., 2018; Qian et al., 2024; Zhao et al., 2025）类似，它们受益于场景理解的最新进展，天然对干扰物鲁棒，且提供更高空间精度，避免了对刚性“对象性”的僵化假设（后者在柔性物体和颗粒物质上失效）。一类方法追踪人类或机器人视频帧中的关键点，并将稠密轨迹重定向至目标设置（Wen et al., 2023; Bharadhwaj et al., 2024; Ren et al., 2025）。另一类方法则将关键点对应用作紧凑轨迹表示：KAT（Di Palo & Johns, 2024）通过关键点查询LLM生成开环动作；P3-PO（Levy et al., 2024）和SKIL（Wang et al., 2025）将关键点输入点条件策略。我们同样使用关键点对应，但证明了更直接方法的优势：选择并形变示范轨迹以适配新场景。我们在实验中与KAT（Di Palo & Johns, 2024）进行了对比。

2.2 自主数据生成

为减少对大型人工收集操作数据集的依赖，近期工作探索了策略学习的数据生成。部分工作在仿真中通过查询基础模型提出并求解任务（Ha et al., 2023; Wang et al., 2024），或利用特权仿真状态将示范适配至新场景配置（Mandlekar et al., 2023; Jiang et al., 2025; Lin et al., 2025a）。然而，基于仿真的方法在杂乱、非结构化环境中的仿真到现实迁移面临困难，尤其对于涉及复杂接触与基于合成渲染训练的视觉策略（Blanco-Mulero et al., 2024; Yu et al., 2024; Lin et al., 2025b）。

另一类方法直接在真实世界生成数据。部分工作需数百条人工示范训练策略（Zhou et al., 2024; Mirchandani et al., 2024），在迁移到新任务与环境时仍构成瓶颈。与我们工作最相似的是从少量示范初始化、使用特殊设计策略的方法。Manipulate-Anything（Duan et al., 2024b）引入零样本基础模型策略进行自主数据收集，但多轮基础模型推理显著降低吞吐量，最终生成不足50条示范；且未考虑环境重置。相比之下，我们提出一个系统，可在真实世界中以极少人工干预自主生成超1000条示范。

3 鲁棒模仿与自主玩耍

我们将机器人操作建模为受控马尔可夫过程（CMP）。CMP表示为元组 $M = (S, A, \mathcal{T})$，其中 $S$ 为状态集，$A$ 为动作集，$\mathcal{T}: S \times A \rightarrow \Delta(S)$ 为转移动力学函数。

在模仿学习问题中，给定CMP $M$ 与目标任务，我们有一组 $N$ 条专家示范 $\mathcal{D} = {\tau_1, \tau_2, \ldots, \tau_N}$，轨迹 $\tau_i = {s_1, a_1, s_2, a_2, \ldots}$。实践中，机器人无法直接访问状态 $s_t$，而接收视觉观测 $o_t = O(s_t)$，包括左右两侧两个第三人称RGB相机视图（如图2所示）。我们假设无显著遮挡或部分可观测性。动作 $a_t$ 为机器人夹爪的6自由度位姿与夹爪开/闭二值命令。给定示范数据集 $\mathcal{D}$，我们的目标是学习任务策略 $\pi: O \rightarrow \Delta(A)$。

如引言所述，当前标准模仿学习方法需大量人力，难以扩展。本文直接解决此问题：首先，为以最少人工示范产生有效行为，我们引入一种基于开环轨迹形变的策略，从少量训练示范（Section 3.1）生成动作计划，远少于标准神经策略；其次，该策略作为鲁棒引导，支撑VLM引导的功能玩耍流程（Section 3.2），生成示范以训练更强大、灵活的下游策略架构。

3.1 基于关键点对应的关系轨迹形变

为实现对初始状态大幅变化的空间与语义鲁棒模仿，Tether利用图像对应匹配算法的语义视觉先验，在少量示范内插值并泛化。

我们的策略设计为开环运行，从初始状态分布映射至完整动作序列，流程如下：每条示范由初始帧（即示范开始时的相机观测）与夹爪运动的3D航点序列表示。这些航点投影到图像上，标识该示范的重要视觉“关键点”。为从场景初始观测执行策略，我们基于关键点对应质量选择最佳匹配示范，反投影这些关键点以计算期望的3D夹爪航点，并根据这些航点对示范轨迹进行形变。以下详细说明各步骤。

示范摘要：图像、航点与关键点
我们的策略为非参数化，依赖在测试时访问示范。为方便，我们首先对所有示范进行预处理，生成紧凑摘要以备执行。此为“训练时”操作，每条示范仅需执行一次，摘要后原始示范可丢弃。对每条示范轨迹 $\tau_i \in \mathcal{D}$，我们将关键信息摘要为元组 $\kappa_i = (o, W, K, \mathbf{a})$，其中：
- $o$ 为初始图像，即轨迹开始时的双视图相机观测；
- $W = [w_1, w_2, \ldots, w_T]$ 为任务关键的3D夹爪位置“航点”序列；实践中，我们简单使用夹爪开/闭位置切换帧的夹爪位置，遵循先前工作选择关键帧的惯例（Johns, 2021; Mandlekar et al., 2023; Vecerik et al., 2024），适用于多样操作任务；附录A.1还表明Tether与替代航点提取机制兼容。
- $\mathbf{a} = [a_1, \ldots, a_M]$ 为轨迹期间的完整机器人动作序列，即6自由度夹爪位置与夹爪状态；
- 最后，对每个 $T$ 个航点位置，将其投影到 $o$ 上以识别视觉重要关键点 $K = [k_1, k_2, \ldots, k_T]$。此过程如图2所示。

对应匹配与源示范选择
为执行Tether策略，我们首先匹配当前相机观测 $o$ 与示范集 $\mathcal{D}$，找到最近邻示范。具体而言，对每个示范摘要 $\kappa_i$，我们在当前图像 $o$ 中搜索示范图像 $o_i$ 中所有关键点位置 $K_i$ 的对应关系。我们分别对左图与右图进行，以在每张图像中找到对应像素集 $\tilde{K}i = [\tilde{K}{i,\text{left}}, \tilde{K}_{i,\text{right}}]$。为找到这些2D对应关系，我们在实现中使用基于DINOv2（Oquab et al., 2023）与Stable Diffusion（Rombach et al., 2022）特征的最先进模型（Zhang et al., 2024）。

然后，我们使用校准的相机外参将这些对应关系 $\tilde{K}_i$ 反投影，获得目标3D航点序列 $\tilde{W}_i$。若反投影不相交，则匹配失败，即示范 $i$ 对当前观测 $o$ 为“不可行”匹配。对可行匹配，我们通过计算原始与目标航点间的欧氏距离 $score_i(o) = |W_i - \tilde{W}_i(o)|_2$，按与 $o$ 的不相似度对示范排序。最近邻示范被选为源示范 $\kappa^$，其原始夹爪航点 $W^$、原始机器人动作序列 $\mathbf{a}^$ 与当前场景的转换目标航点 $\tilde{W}^(o)$。

形变源示范轨迹
上述“目标航点” $\tilde{W}^*(o)$ 为当前场景的机器人轨迹形变提供了骨架。然而，我们仍需通过形变航点间的中间段，填充细粒度机器人动作。

考虑从所选源示范 $\kappa^$ 中两个连续航点 $[w_t, w_{t+1}]$ 构成的段。目标航点为 $[\tilde{w}t, \tilde{w}{t+1}]$。记该航点段的动作序列为 $\mathbf{a}^t$。我们首先计算标记段起始与终止的两个航点的3D位移：$d_t = \tilde{w}_t - w_t$ 与 $d{t+1} = \tilde{w}{t+1} - w{t+1}$。现在，我们在这些位移间进行线性插值，并将所得位移加至原始动作序列 $\mathbf{a}^*_t$，得到变换后的动作计划段 $\tilde{\mathbf{a}}_t$。将这些段拼接，生成在新场景中执行的完整动作计划 $\tilde{\mathbf{a}} = [\tilde{\mathbf{a}}_1, \tilde{\mathbf{a}}_2, \ldots]$。

为优先保留空间关系，我们在空间而非时间上进行此线性插值。对航点 $w_t, w_{t+1}$，我们定义局部1D坐标系，将 $w_t$ 映射为0，$w_{t+1}$ 映射为1。则源动作段 $\mathbf{a}^*t$ 中每个动作 $a$ 的插值系数 $\alpha$ 即为其在此坐标系中的坐标。几何上，这可视为将夹爪位置 $a$ 投影到 $w_t$ 与 $w{t+1}$ 构成的直线上，然后计算投影点相对于 $w_t$ 与 $w_{t+1}$ 的相对距离。则 $a$ 在形变至新场景时必须经历的对应位移为：$d_a = (1-\alpha)d_t + \alpha d_{t+1}$。新动作为 $a + d_a$。

尽管简单，我们在第4.2节中表明，我们的对应驱动轨迹形变在仅10条示范下，于具有挑战性的操作任务（包括分布外对象、毫米级精度与复杂接触）中表现卓越。更多细节与伪代码见附录。

图4：自主功能玩耍

现在，我们通过使用Tether策略启动自主玩耍，解决人类数据收集的可扩展性问题。这从每项任务的少量示范开始扩展数据分布，使扩展后更多样化的数据集可支撑更大、更灵活的神经策略架构。

为最大化数据生成的自主性，我们将策略应用于连续功能玩耍，并设计一组促进自然重置与随机化的任务：每项任务的终态是另一任务的有效初态（例如，“将菠萝放在桌上”可过渡为“将菠萝放在架子上”或“将菠萝放入碗中”），即使在失败情况下亦然。这种近似无限可组合的结构是先前无重置学习中前向-后向任务的扩展（Eysenbach et al., 2017; Sharma et al., 2021; Mirchandani et al., 2024），促进了一组在任务分布下“闭合”的可达状态，同时允许先前任务（及潜在错误）自然随机化每项任务的相关与背景对象位置与状态。第4.3节的实验进一步说明了此公式。

基于这些任务，我们运行迭代流程，每步应用策略完成我们任务集中的一个任务。高层次上，每次迭代流程如下：首先，用场景图像查询VLM，请求应尝试的适当任务；然后，运行相应Tether策略，记录其执行，并通过另一VLM查询评估它。这些步骤如图4所示，伪代码见附录。

任务选择与规划
每次迭代中，我们基于希望添加至集合的示范与实际可执行任务选择任务。为优先添加示范，我们维护每项任务的成功次数运行计数，并对稀有任务赋予更高权重。具体而言，我们从失败计数的负值的softmax中采样目标任务。

然而，此稀有目标任务可能无法立即执行。例如，尝试“将物体从架子移到桌上”时，目标物体首先必须被放置在架子上。若该物体在场景中可能位于许多其他位置，则在无导向玩耍中可能极少到达架子。为克服此问题，我们查询VLM提供任务计划，即以目标任务为终点的可执行任务序列，我们在当前迭代中尝试计划中的首个任务，类似滑动窗口控制。我们的提示与示例见附录。

成功评估
尝试任务后，我们通过VLM查询确定轨迹的成功性。我们遵循推荐实践（Team, 2025），提供左、右与腕部相机的执行前后场景状态图像。尽管前期工作（Duan et al., 2024a）发现简单查询现成VLM会导致假阳性偏差，我们在设置中观察到近乎完美的性能，可能归因于多相机全可观测设置及使用专为具身推理任务训练的VLM（Gemini Robotics-ER 1.5，Team et al., 2025）。

通过玩耍改进
部署Tether时还有几点额外考虑。首先，玩耍受益于注入随机性以生成探索性数据，搜索改进策略。这还扩展了潜在动作集，降低陷入所有动作均无法诱导环境转换状态的几率。因此，我们未向策略提供所有示范，而是先子选择 $k$ 条示范，并运行策略从其中最匹配者形变。

虽可随机选择这些 $k$ 条示范，但有第二考虑：人工示范质量可能参差不齐，此时使用多种源示范的玩耍可帮助识别“始终更优的示范”以进行形变，避免例如涉及非鲁棒指尖抓取的示范。因此，我们通过构建多臂老虎机问题选择前 $k$ 条示范：臂为示范，选择示范的奖励为从该示范形变执行的轨迹的二值成功。对此问题，我们使用上置信界（Garivier & Moulines, 2011），在探索相对较少测试的源示范与利用高成功率示范之间取得平衡。

我们进行实验评估策略设计与自主玩耍流程。具体而言，我们研究（1）Tether策略对初始状态配置（即新姿态或新对象实例）大幅、潜在分布外变化的鲁棒性；（2）自主玩耍在生成下游闭环策略学习数据流方面的有效性。

Tether策略在空间与语义泛化上均表现出色
首先，我们的策略在涉及空间鲁棒性的任务中表现出色，包括需精确朝向与位置以防滑落的碗。其次，我们的策略在分布外对象下仍表现良好，证明了从视觉对应继承的强大泛化能力：即使示范对象在测试时不存在，对应关系仍能找到语义最相似的对象，并精确定位关键点的相对区域（例如，水果中心或容器边缘）。此能力对抓取草莓（外观迥异，尺寸为示范菠萝的1/4）与杯子（直径为碗的一半，仅够容纳菠萝，需精度与泛化结合）尤为重要。

Tether策略在挑战性操作任务中亦能成功
尽管面临变形、持续接触、关节与精度等挑战，我们的策略在更困难的操作任务中同样有效。对柜门把手、钩子与咖啡机舱等场景小特征的成功，证明了我们语义对应关系的高精度。最显著的是，我们的方法在未使用腕部相机的情况下，对“咖啡插入”任务取得了非平凡成功：该任务在抓取与插入时均需高精度，因可变形圆柱形胶囊若悬停1厘米即会坍塌，且胶囊与舱直径差异仅8毫米。此外，完全打开柜门与擦拭白板痕迹表明，轨迹形变可在无闭环调整下维持与场景的一致接触。最后，对软布的精确抓取展示了我们方法对柔性物体的灵活性，与依赖刚性对象进行姿态估计的前期工作（Wen et al., 2022; Mandlekar et al., 2023; Zhu et al., 2024）形成对比。

最后，尽管Tether策略在初始状态的空间与语义变化下表现出强大鲁棒性，甚至在挑战性任务中亦然，但其开环本质仍是瓶颈，限制了执行中的反应性与恢复能力。因此，它并非独立策略解决方案，而是作为生成经验与训练更富表现力策略的引导，如下所述。

Tether策略对鲁棒自主玩耍至关重要
最后，我们探究Tether策略是否仅在源示范数量极少时有价值，以及若示范更多，标准模仿学习方法是否更有效。为回答此问题，我们模拟将上述人工数据扩散策略接入玩耍、替代Tether策略的结果：对6项任务，使用多小时玩耍实验中随机采样的20个玩耍诱导初态，比较Tether策略（10条示范）与扩散策略（每项任务141至202条示范）。如图9所示，Tether策略始终实现更高成功率，而扩散策略无法泛化至更广的玩耍状态分布（例如，侧倾的碗或缠绕的对象）。因此，我们的策略设计对维持高效鲁棒的自主玩耍至关重要，最小化人工干预并最大化吞吐量。

5 结论

我们提出了Tether，一种涉及结构化、任务导向交互的自主功能玩耍系统。我们引入一种结合关键点对应与轨迹形变的新颖策略设计，展现出卓越的空间与语义鲁棒性，并将其部署于VLM引导的多任务玩耍流程中，在26小时内以极少人工干预生成超1000条成功轨迹。此生成数据经下游过滤式模仿学习，持续提升神经策略性能，最终达到近乎完美的成功率。我们认为，Tether展示了机器人学习的替代路径潜力：由可扩展方法驱动，通过自主交互与经验进行学习与学习。

局限性
我们的策略在利用语义对应上的优势亦是其弱点：尽管计算机视觉的最新进展可在无纹理表面、柔性区域、光照变化与部分遮挡下实现鲁棒特征追踪，但将图像抽象为关键点本质上使策略更易受遮挡影响。此外，我们的策略专为低数据场景设计，具有内置结构泛化与假设，不适用于大数据集；特别是，开环执行限制其在需反应性的动态任务中的适用性，轨迹形变难以处理无法从源示范变换的复杂运动。有前景的未来方向可利用Tether策略作为强先验，同时保持灵活性，通过模仿或强化学习在更多数据通过玩耍获得时持续改进，从而实现更有效的自我提升。

替代航点提取机制
在主结果中，我们通过识别夹爪开/闭位置切换的帧进行航点提取。然而，Tether对航点提取方法的选择不敏感，可轻松替换为替代方法。

为说明，我们提出“从杯中倒水入碗”这一困难任务，因其（1）需在倒水位置设置航点，无法通过夹爪变化提取（夹爪正持杯）；（2）用于对应碗的关键点不位于夹爪位置（夹爪悬于碗上方）。此时，我们改为查询VLM从示范视频中选择关键帧并指向航点的2D像素，然后从双视图三角测量计算航点。最后，我们继续运行原始算法进行对应与轨迹形变。我们在真实世界设置中经验性验证此替代机制，成功识别杯与碗的航点，实现90%成功率。

对应过滤
如第3.1节所述，我们主要通过三角测量过滤无效示范对应：若反投影对应在10厘米阈值内不相交，则将示范视为对观测 $o$ 的“不可行”匹配。

然而，实践中我们发现，错误对应可能仅因巧合而有有效三角测量，从而通过可行性检查。最坏情况下，可能导致危险碰撞。因机器人设置缺乏内置避障，我们选择通过快速多视图对应算法MAST3R（Leroy et al., 2024）构建简单自定义安全层。对示范与观测 $o$，我们将每个关键点从其视图匹配至另一相机视图的同一场景（左至右相机及反之）。然后计算3D航点至该匹配投影射线的距离，若示范与观测的距离差异超过10厘米，则将此对应视为不可行。

形变后速度调整
实现轨迹形变的另一关键考虑是示范与形变轨迹间相对航点位置 $w_t, w_{t+1}$ 的差异：若位置差异大（例如，示范中物体较近而观测中较远），且保持中间时间步数恒定，则形变轨迹的速度差异亦大，可能危险。

因此，在第3.1节所述形变过程后，我们重新计算中间时间步，使示范与形变轨迹间速度保持一致。具体而言，我们按新动作计划段 $\tilde{\mathbf{a}}t$ 的弧长 $\tilde{L}$ 与原始段 $\mathbf{a}_t$ 的弧长 $L$ 的比例缩放中间航点数 $T{\text{segment}}$：$\tilde{T}{\text{segment}} = (\tilde{L}/L) T{\text{segment}}$。然后，我们按原始中间动作的相对分布计算新中间动作：对原始中间动作 $a_t$，将时间步 $t/T_{\text{segment}}$ 映射至 $s/L$，其中 $s$ 为从 $w_t$ 到 $a_t$ 的弧长。然后，沿此函数插值，将新时间步 $t/\tilde{T}_{\text{segment}}$ 映射至 $\tilde{s}/\tilde{L}$，并计算结果中间动作为距 $\tilde{w}_t$ 弧长 $\tilde{s}$ 的位置。

4: $\tilde{K}_i \leftarrow \text{findCorrespondences}(K_i, o_i, o)$
5: // 反投影对应以计算航点
6: $\tilde{W}_i \leftarrow \text{backprojectStereo}(\tilde{K}{i,\text{left}}, \tilde{K}{i,\text{right}})$
7: end for
8: // 选择最匹配示范
9: $i^ \leftarrow \arg\min_i score_i(o)$
10: $W^, \tilde{W}^, \mathbf{a}^ \leftarrow W{i^}, \tilde{W}_{i^}, \mathbf{a}{i^}$
11: // 形变每个动作段
12: for $t = 1, \dots, T-1$ do
13: // 计算段起始与终止航点的位移
14: $d_t \leftarrow \tilde{w}t - w_t$
15: $d{t+1} \leftarrow \tilde{w}{t+1} - w{t+1}$
16: for $a \in \mathbf{a}^_t$ do
17: // 在空间中计算线性插值
18: $v \leftarrow w^_{t+1} - w^{t}$
19: $\alpha \leftarrow (a - w^{t})^\top v / |v|^2$
20: $d_a \leftarrow (1-\alpha)d_t + \alpha d{t+1}$
21: $\tilde{a} \leftarrow a + d_a$
22: end for
23: $\tilde{\mathbf{a}}_t \leftarrow [\tilde{a} \mid a \in \mathbf{a}^_t]$
24: // 计算形变后速度调整
25: $\tilde{\mathbf{a}_t} \leftarrow \text{adjustSpeed}(\tilde{\mathbf{a}}_t)$
26: end for

A.3 实验设置

扩散策略（DP）设置
训练与部署所有扩散策略时，我们使用DROID（Khazatsky et al., 2024）提供的代码库，遵循原始超参数并稍作修改。具体而言，批量大小设为32，洗牌缓冲区大小为1000，训练轮数为600。对每项任务，我们消融策略接收的相机视图选择：“菠萝入架”与“菠萝离架”使用左、右外部相机，其余使用腕部与右外部相机。

关键点动作标记（KAT）设置
关键点动作标记（KAT）接收一系列遥操作机器人示范，将初始视觉观测与动作编码为输入与输出标记对，并将示范标记与当前视觉观测馈送至LLM以生成新场景中的轨迹。我们发现KAT在我们的任务中未取得任何成功，尽管对三个关键组件进行了消融：关键点标记、动作标记与用于查询的LLM。以下回顾这些尝试修复。

  1. 关键点标记通过使用DINO-ViT提取视觉描述符，使用输入示范集初始观测间的最佳伙伴最近邻匹配提取对应关系，然后在新场景中查找每个选定视觉描述符的对应位置来提取。然而，因相机视图捕获整个工作空间，我们发现这些视觉标记常落在示范间恒定但与示范任务无关的场景部分（例如背景柜子）；相反，对当前任务至关重要的位置（例如菠萝）未被任何描述符追踪。因此，KAT可能易受视觉干扰物影响。尽管原始论文在测试时实验干扰物，但它们不在示范中，故不影响视觉描述符提取。为解决此限制，我们手动选择图像中相关关键点进行追踪。例如，对“拿起菠萝并放入碗”任务，我们在菠萝与碗位置标注关键点。然而，最终发现即使仅标记任务相关关键点，输出轨迹仍不准确。

  2. 原始论文中，KAT以4 Hz记录动作。我们实验了3 Hz至15 Hz的各种频率，但均无效。此外，我们观察到频率超过10 Hz后，模型常输出相同轨迹，无论输入视觉观测的关键点位置。

  3. KAT原使用GPT-4-Turbo生成新轨迹。我们测试了GPT-4-Turbo，发现其常输出无效动作序列或不准确动作。我们还测试了GPT-4.1、Gemini-2.5-Flash与Gemini Robotics-ER 1.5，发现这些模型输出格式有效的动作序列，但动作序列不准确。

总之，我们认为KAT的局限性源于LLM无法处理我们轨迹中的多维数值模式（由方向变化、非线性速度与宽对象分布引起）。为验证此假设，我们在两个轨迹分布更简单的任务上对KAT进行额外实验：抬起咖啡机盖手柄与打开抽屉。KAT分别达到70%与60%（Tether达到90%与100%），证实其确实在更局部的对象中心交互中表现良好。这验证了我们的少样本模仿基线在某些较简单轨迹分布中成功，而Tether在处理更多样、更具挑战性的轨迹上表现卓越。

微调 $\pi_0$ 设置
