## LLM如何看待创造力：基于可解释推理的视觉创造力零样本评分

**William Orwig** 哈佛大学心理学系，剑桥，马萨诸塞州，美国

**Roger E. Beaty** 宾夕法尼亚州立大学心理学系，大学公园，宾夕法尼亚州，美国

通讯作者：Roger E. Beaty（邮箱：rebeaty@psu.edu）

### 摘要

评估视觉图像的原创性对创造力评估提出了持久挑战。使用AI模型进行自动评分在言语领域已被证明有效，但关于评估视觉创造力以及理解模型如何得出评分的关键问题仍然存在。本研究探讨多模态大语言模型（LLM）是否可以在零样本条件下——无需任何微调或人类评分示例——作为视觉创造力的评判者，以及它们的"推理"输出是否为评估过程提供了可解释的窗口。我们在992张AI生成图像（基于人类撰写的提示词）和1500张手绘草图（已由人类评分者评分）上测试了六个多模态LLM（Gemini 3 Flash、Gemma 4 31B IT、GPT-5.4 Mini、GLM-5v Turbo、Kimi K2.5和Qwen 3.6 Plus）。在研究1中，所有模型在两个数据集上都与人类创造力评分显示出实质性一致性（AI生成图像r = .57–.68；草图r = .29–.68）。在研究2中，我们分析了三个LLM评估相同图像和绘图时的逐步推理过程。虽然推理使模型评估变得可解释——展示了它们关注什么、如何平衡原创性与质量，以及如何证明其评分——但推理并未提高与人类评分的一致性。总之，我们的研究结果表明，多模态LLM无需任何额外训练即可匹配人类对视觉创造力的判断，并且其推理揭示了AI模型如何评估创造力。实现此流程的开放评分应用可在 https://review-visual-eval-scoring.hf.space 获取。

**关键词：** 自动创造力评估；思维链推理；大语言模型；LLM作为评判者；视觉创造力

### 引言

随着LLM现在产生大量开放式输出，研究的瓶颈往往不再是生成，而是评估。这一问题对于创意产品尤为突出，因为其质量是主观的、多维的，且现有基准无法完美捕捉。生成式AI的兴起将注意力转向了人类与AI之间的共创形式，系统可以在许多领域支持创意生成、选择和生产（Rafner 等，2023）。在这一过渡时刻，出现了几个实证问题：LLM能否支持人类评估？需要多少指令和训练数据才能实现人类与LLM评分之间合理的对应关系？关键的是，支持LLM创造力评估的潜在、未观测过程是什么？

创造力表现传统上通过人类判断来评估，共识评估技术仍然是评估想法和产品的标准方法，对领域知识和专业知识敏感（Amabile，1982）。相关的主观评分方法也已被证明，当多名评分者独立评估反应时，在发散思维研究中能够产生可靠和有效的判断（Silvia 等，2008）。同时，这些方法劳动密集且难以扩展，特别是当研究涉及数千个反应时。心理有效性与规模之间的这种张力推动了对创造力评估自动化方法的日益关注；结合在线施测与创造力任务自动评分的平台（Patterson 等，2025）使大规模评估更加可及，并为基于模型的评估方法奠定了基础。

计算心理测量学的近期工作致力于为替代用途任务（AUT）——发散思维的基准测量——开发自动创造力评分方法。早期方法通过量化反应与提示词或语义空间中其他概念的远近来提供原创性的代理指标（即SemDis；Beaty和Johnson，2021）。更近期的基于LLM的方法在人类评分示例的大型数据集上训练模型（Organisciak 等，2023），与人类判断产生了强一致性（r = .81）。这项工作已扩展到其他创造力领域，包括隐喻生成（DiStefano 等，2025）、叙事写作（Orwig 等，2024）和图形创造力（Patterson 等，2024）。特别是在图形领域，Cropley和Marrone（2025）在创造性思维测试-绘图生产上训练了卷积神经网络，达到了.83–.94的分类准确率；Cropley 等（2025）通过大规模开源管道对此进行了扩展。类似地，Acar 等（2025）将计算机视觉分类器应用于图形托兰斯发散思维测试（r = .54–.85）。综合来看，这些研究表明基于模型的评分能够在多项任务中恢复人类创造力判断中的有意义变异。

即使没有特定任务训练，通用LLM也能出人意料地好地对言语创造力进行评分。零样本指的是仅提供提示词和反应的基于模型的评估；类似地，少样本在提示词中为模型提供有限的示例反应/人类评分集合（即上下文学习；Dong 等，2024）。Organisciak 等（2023）发现，基于提示词的GPT-4对AUT反应的评分在零样本条件下达到r = .53的相关性，在少样本条件下达到r = .66。Saretzki 等（2025）将零样本GPT-4评分扩展到德语AUT反应，报告与人类评分的平均相关性为r = .55，在不同项目和研究之间存在相当大的变异性（r = .34–.70）。相关地，Luchini 等（2025）将少样本提示应用于创造性问题解决任务，发现与人类原创性评分的相关性范围从r = .11到.66。尽管零样本评分在一些言语创造力任务中显示出前景，但零样本评估是否适用于视觉领域仍属未知。

目前大多数LLM是多模态的，可同时处理图像和文本，其作为零样本评判者的能力已在基于文本的任务中得到记录（Chiang和Lee，2023；Zheng 等，2023）。最近的发展是具备推理能力的LLM，在给出答案之前产生明确的推理链（Wei 等，2022；Guo 等，2025）。在扩展推理模式下，推理链与模型的最终答案分开返回，揭示了它在输出响应之前如何"思考"用户的请求。对于创造力评估，这提供了机会来获得对支持创造性评估的潜在过程的新见解。

本研究在两个分析层面评估通用多模态LLM作为视觉创造力零样本评判者：与人类评分的行为一致性以及模型推理链的评估内容。我们在两个视觉创造力数据集上测试了来自五个不同开发者的六个多模态LLM——992张来自人类撰写提示词的AI生成图像（Orwig 等，2026）和1500张手绘草图（Patterson 等，2024）——没有特定任务训练、没有示例、没有微调。研究1在两个数据集上测试所有六个模型与人类评分的对比，评估它们在简单视觉复杂性之外的一致性。研究2收集三个具备推理能力的LLM产生的推理链，将每个推理序列分类为离散步骤（如图像感知、原创性评估、评分证明），并测试模型是否能正确识别每幅绘图实际描绘的内容——这是粗糙手绘草图的特殊挑战。总之，这些研究旨在扩展多模态自动创造力评分，并提供对AI模型如何评估创造力的见解。为了使评分程序可用于新图像，我们还分享了一个开放网络应用，可在任何用户提供的刺激上运行相同的流程（附录A）。

### 研究1：零样本视觉创造力评分

#### 方法

**数据集**

本研究使用了两个在刺激类型上不同的视觉创造力数据集。数据集1（以下简称"AI生成图像"）由992张通过DALL-E 3从参与者撰写的简短创意词组生成的图像组成（Orwig 等，2026）。三名训练有素的评分者独立地在1到5的量表上评估每张图像的创造力（1 = 非常无创意；5 = 非常有创意），对生成提示词不知情。评分者间信度充足（ICC = .66）。每张图像的标准分数是三个评分的连续平均值（M = 2.39，SD = 0.80；数值在1-5范围内以1/3点增量分布）。全部992张图像样本用于所有分析。

数据集2（以下简称"人类绘制草图"）由通过AuDrA平台收集的绘图组成（Patterson 等，2024），其中参与者被给予一个不完整的起始形状，并被要求将其扩展为一幅创意绘图。完整数据集包括来自14个不同起始形状的11,075幅绘图，每幅由约50名训练有素的评分者使用计划缺失设计进行评分。人类创造力分数使用评判者反应理论（JRT）等级反应模型得出，该模型考虑了评分者严厉度和测量误差（Myszkowski和Storme，2019）。为了与Orwig 等（2026）的1到5评分可比，在指明处也报告了重新缩放的整数1到5形式。

为了在数据集2中平衡项目内一致性与项目间变异性，我们从三个不同的抽象起始形状（完整数据集中的形状4、11和12）中抽样绘图。在每个形状内，我们随机抽样500幅绘图（随机种子42），得到最终样本1500幅绘图（重新缩放的整数评分：M = 2.95，SD = 0.71；范围1-5）。此设计在每个形状内保持起始刺激恒定，使得人类和模型评分中的变异反映了不同参与者如何解决相同的提示词，同时也捕捉了项目级别的变异。形状成员身份作为子组分析的元数据变量保留。图1显示了每个数据集中人类创造力评分范围内的代表性示例。

**图1：** 示例刺激，按人类创造力平均评分从低到高自上而下排序。(A) 通过DALL-E 3从参与者撰写的词组生成的AI图像（Orwig 等，2026；完整样本N = 992）。(B) 扩展不完整起始形状的手绘草图（Patterson 等，2024；本子样本N = 1,500）。

**模型**

我们测试了来自五个开发者的六个多模态LLM，能够处理图像输入（表1）。所有六个模型在研究1中以可比的单次生成模式运行；来自三个具备推理能力模型的推理链在研究2中单独收集。

**表1：** 本研究中评估的多模态LLM。

**程序**

每个模型接收一张图像和一个文本提示词，指示其在1到5的量表上对图像的创造力进行评分。所有请求使用temperature = 0以确保确定性输出。响应被解析为1到5之间的第一个整数，解析失败最多重试四次，使用指数退避。API请求异步发出，并发限制设置为遵守提供商的速率限制。

对于AI生成图像，提示词特意简短，以反映Orwig 等（2026）中原始人类评分者指示的简洁性：

> 你正在评估AI生成图像的创造力。在1到5的量表上对创造力进行评分，其中1为非常无创意，5为非常有创意。使用整个1到5量表。仅提供一个数字作为你的评分。

对于手绘草图，提示词改编自Patterson 等（2024）中的人类评分者指示。LLM提示词同样强调原创性而非艺术质量，并提供了关于不完整形状绘图程序的背景：

> 你正在评估各种人在研究研究中创作的绘图的创造力（不一定是艺术家）。在1-5的量表上对创造力进行评分，其中1为完全无创意，5为非常有创意。使用整个1到5量表进行评分。适当时不要犹豫使用极端值。关注想法的原创性，而非艺术质量。该绘图是使用一个不完整形状的起始图像创作的，该形状被融入到绘图中。仅提供1到5之间的一个数字作为你的评分，其中：1 = 完全无创意；2 = 略有创意；3 = 中等创意；4 = 非常有创意；5 = 极具创意。

**边缘密度**

为了考虑视觉复杂性混淆——即人类和AI模型都对更精细的反应给予更高评分（Domanti 等，2026）——我们从每张图像中提取了边缘密度，定义为超过Sobel滤波器梯度阈值0.1的像素比例（范围0-1）。边缘密度索引图像中视觉内容的数量，已知能预测图形绘图任务中的人类创造力评分，其中精细度与原创性相关（Patterson 等，2024）。在此，我们将边缘密度用作偏相关的协变量，而非因变量。

**分析方法**

对于每个模型，我们计算其评分与人类标准分数之间的Pearson相关，以及控制边缘密度后的偏相关。评分分布以均值、标准差和每个量表点上评分的比例进行总结，以表征相对于人类评分者的系统性偏差。对于手绘草图样本，我们还报告了每个形状的相关性以表征项目级别的变异。

#### 结果

**多模态LLM与AI生成图像的人类创造力评分一致。**

我们首先测试了零样本LLM评分与AI生成图像上人类创造力评分的相关程度。结果显示中等到强的相关性（图2）。Gemini 3 Flash显示出最强的一致性（r = .68），其次是Gemma 4 31B IT（r = .66）、Kimi K2.5（r = .64）、Qwen 3.6 Plus（r = .64）、GPT-5.4 Mini（r = .61）和GLM-5v Turbo（r = .57）。边缘密度与该数据集上的人类评分仅有弱相关（r = .17），控制边缘密度后的偏相关与双变量相关几乎相同（偏r = .56–.67），表明LLM与人类在AI生成图像上的一致性不能归因于对低级视觉复杂性的共同敏感性。值得注意的是，模型相对于人类评分者显示出系统性宽容偏差。人类评分集中在量表的低端（M = 2.39，SD = 0.80；42%的图像评分在2.0或以下），而模型评分向上偏移（各模型M = 2.67–3.63）。大多数模型很少或从不给予1的评分（图3），将其判断压缩到量表的中上部。

**LLM与人类的一致性扩展到手绘草图。**

我们接下来考察这种一致性是否推广到根本不同的刺激类型。总体而言，大多数模型与人类评分保持强一致性，但有显著变异性（图2）。Gemini 3 Flash再次显示出最强的一致性（r = .68），其次是Kimi K2.5（r = .60）、Qwen 3.6 Plus（r = .57）、Gemma 4 31B（r = .55）、GLM-5v Turbo（r = .49）和GPT-5.4 Mini（r = .29）。有趣的是，模型的相对排名在数据集之间发生了变化：Kimi K2.5和Qwen 3.6 Plus从AI生成图像上的中间排名上升到绘图上的第二和第三，而Gemma 4 31B从第二下降到第四。

**一致性在视觉复杂性之外持续存在。**

关于边缘密度，我们发现在该数据集上与人类评分有大的重叠（r = .64），比AI生成图像强得多。然而，鉴于对这些线条绘图的先前分析（Patterson 等，2024），这种精细化效应是预期的。在剔除边缘密度后，LLM-人类相关性有所减弱，但排名顺序未变，Gemini 3 Flash保持最强的一致性（偏r = .56；各模型范围 = .17–.56）。值得注意的是，在考虑边缘密度后，前沿闭源模型GPT-5.4 Mini与人类评分的一致性较差，而开源模型（Kimi和Qwen）的偏相关仍然较大（图2）。尽管如此，一些LLM的实质性残差相关突出了它们检测被人类判断为有创造力的特征的能力，超越了简单的复杂性。

**LLM偏好AI生成图像。**

与在AI生成图像上观察到的宽容偏差相反，模型在手绘草图上显示出负向偏差。我们发现人类评分集中在量表中点3附近（M = 2.95，SD = 0.71），而模型评分向下偏移（各模型M = 1.79–2.19），大多数模型将大部分评分分配给1或2（图3）。因此，模型对精致的AI生成图像评分偏高，对稀疏的手绘草图评分偏低，表明模型惩罚视觉简单性，尽管提示词指示关注所表达想法的原创性。

**图2：** 按数据集划分的模型-人类一致性。对于六个LLM中的每一个，柱长显示与人类评分的双变量Pearson r，白色菱形显示控制边缘密度后的偏r。模型在每个面板内按Pearson r排名。所有模型在AI生成图像上与人类一致良好。在手绘草图上，控制边缘密度降低了一致性，表明它们与人类的部分一致反映了视觉复杂性而非原创性。

**图3：** 每个数据集上每个来源的平均创造力评分。每个点是一个来源的平均值（人类为黑色，LLM为彩色）；须线跨度为±1 SD，虚线标记人类均值。行在面板间顺序相同。偏差按数据集反转：每个模型对AI生成图像的评分比人类更宽容，对手绘草图的评分更严厉。

**项目显示手绘草图的可变一致性。**

由于手绘草图样本包括来自三个不同起始形状（4、11、12）的各500幅绘图，我们可以为每个形状分别计算模型-人类相关（表2）。我们发现形状4在几乎所有LLM中都引发了一致性更强的一致性，优于形状11和12。该效应对于GLM-5v Turbo最大，其Pearson r从形状4的.66下降到形状11的.36，对于Kimi K2.5和Qwen 3.6 Plus也是如此，两者都从形状4到形状11下降了约.10–.15。Gemini 3 Flash和Gemma 4 31B在各项目间最为稳定，跨形状范围约为.03–.07。GPT-5.4 Mini在各形状间均匀较弱（r = .26–.34）。然而，我们发现边缘密度在各形状间一致地预测人类评分，因此项目效应可能反映模型表现而非刺激可评性的差异。

### 研究2：视觉创造力判断中的推理链

研究1确立了多模态LLM可以在两个非常不同的数据集上预测人类创造力评分，在无需额外训练（即零样本）的情况下达到中等到强的一致性。Gemini 3 Flash在两个数据集上都显示出最强的一致性，开源模型（Kimi K2.5、Qwen 3.6 Plus）的表现优于领先的专有LLM（GPT-5.4 Mini）。在研究2中，我们探索模型如何得出其评分。为此，我们分析了研究1中三个具备推理能力的模型产生的明确推理链。这些链与最终评分分开显示，可以直接访问模型在图像中注意到什么以及它如何"思考"创造力。我们使用这些推理链来回答四个问题：（1）推理是否提高了与人类评分的一致性（与无推理的基线相比）？（2）推理链本身是否携带评分之外的有意义信息（我们能否仅从推理内容预测最终评分）？（3）模型在判断创造力时实际考虑什么？（4）正确识别绘图描绘的内容对于匹配人类评分是否重要？

#### 方法

**推理链收集与验证。**

我们在研究1的完整样本上重新运行了三个具备推理能力的模型（GLM-5v Turbo、Kimi K2.5和Qwen 3.6 Plus），启用推理，记录每个模型的最终1到5评分及其产生的完整推理链。评分提示词与研究1相同。

对推理链的一个核心关注是它们可能不反映模型的实际评估，即链可能只是事后合理化，评分是独立决定的（Chiang和Lee，2023；Zheng 等，2023）。因此，我们要求一个单独的LLM（GPT-5.4 Nano）仅从链中猜测每个评分，无法访问图像。为了防止该预测模型简单地匹配明确的候选评分短语（例如，"我给这个3分"），我们在将链文本传递给预测器之前删除了所有数字。预测评分与（a）产生该链的原始LLM评分和（b）人类评分进行对比。如果链包含驱动评分的评估信号，纯文本模型应该能够重建它；如果链只是事后合理化，预测评分应该与原始评分不相关。

**推理过程编码。**

为了表征模型在判断创造力时关注什么，我们将每个推理链分解为其组成句子，并将每个句子分类为四个评估维度之一（或残余的"其他"类别）。这四个类别遵循视觉语言思维链分析中的感知→推理→整合分解（Avogaro 等，2026；Jiang 等，2025）。该分类体系针对创造力判断任务操作化为：感知（描述可见内容，列举模型所见，或重述任务；无评估），原创性（判断新颖性、惊喜、常规性、陈词滥调、稀有性，或引用类似内容的常见程度），质量（判断视觉质量、构图、渲染、技巧、细节或精致度），以及证明（明确推理1到5量表，锚定评分，或以简短证明承诺最终评分）。第五个类别"其他"捕捉过渡、元评论以及不适合四个评估类别的任何句子。

句子通过在每个句号、问号和感叹号终止符以及双换行符处拆分每个链来提取，然后丢弃短于25个字符的片段和仅数字的片段。三名评判者是Mistral Small（mistralai/mistral-small-2603）、Grok 4.1 Fast（x-ai/grok-4.1-fast）和MiMo v2 Pro（xiaomi/mimo-v2-pro，明确禁用推理），均通过OpenRouter在temperature = 0下访问。我们选择这组评判者是为了使用我们研究1模型集中未代表的开发者提供的模型，在被评分模型与编码管道之间提供独立性。为了使编码在562,053个句子中可行，每次API调用呈现15个编号句子，并引出JSON响应，将每个编号映射到一个类别。在相同链上与每句一次调用的编码进行试点比较显示83-89%的每句一致性，表明批处理将API成本降低了约十倍，而没有有意义的可靠性损失。每个句子的规范编码是三名评判者的多数投票；三名评判者产生不同标签（1-1-1分裂）的句子被排除在规范分析之外（2.5%的句子）。每个链的分析单位是五个类别中每个类别的规范句子比例。图4显示了在此方案下编码的一条链作为定性锚点；图5展示了这种模式如何扩展到手绘草图，其中质量评估内容减少。

**图4：** AI生成图像的推理链示例（Orwig 等，2026；图像77），来自启用推理的GLM-5v Turbo。句子按评估类别颜色编码：感知、原创性、质量、证明或其他。句子为原文；简短的任务重述和过渡行被省略。

**图5：** 来自启用推理的GLM-5v Turbo的手绘草图推理链示例。颜色编码同图4。与AI图像链不同，质量句子缺失，感知句子占主导——这种转变在所有三个具备推理能力的LLM中都会出现（图6）。句子原文复制；为呈现起见省略了简短的任务重述行。

**感知准确性与人类标注。**

为了评估模型是否正确识别了每幅绘图描绘的内容，我们使用一个单独的LLM评判者（通过OpenRouter的MiniMax M2.7，temperature = 0）从每个推理链中提取主要对象级概念。这些概念与作为原始AuDrA档案数据集一部分收集但先前未分析的共识标签进行比较（Patterson 等，2024）。标签通过多阶段人类程序生成：MTurk工作者独立标注每幅绘图，之后一名研究助理将响应整合为每个起始图像最频繁的三个标签类别。

每个链被分类为匹配（模型识别出与人类标签相同的概念，允许同义词、近义词和合理的下义词或上义词）、部分匹配、不匹配、模型弃权或人类不可解释。最后一个类别保留给最终共识标签为空白的绘图，因为评分者无法就绘图描绘的内容达成一致。我们将这些称为"无共识绘图"（NCD；N = 82幅独特绘图，三个模型共246条链）。此分析限于手绘草图数据集，因为精致的DALL-E图像在对象识别方面几乎没有歧义。

**LLM幻觉审计。**

对于246条NCD链，我们进行了后续审计，其中同一LLM评判者重新评估每条链，并将模型对所提识别的信心分类为三个类别之一。确信识别意味着模型无条件地断言一个特定对象。有保留识别意味着模型在表达不确定性的同时命名了一个可能的对象。弃权意味着模型明确表示无法识别绘图或绘图是抽象的或不清楚的。

**分析方法。**

对于推理开与推理关的比较，我们在共享项目上分别计算每个条件下与人类标准的Pearson相关，并计算两个条件下模型内的评分一致性，以确认同一模型无论是否明确推理都会对相同图像分配相似评分。对于链验证分析，我们报告预测评分与原始LLM评分和人类标准的Pearson相关。对于过程编码分析，我们报告句子级别的评判者间信度（成对百分比一致性、三方一致同意和成对Cohen's kappa，包括总体和按类别的one-vs-rest），每个链的类别概况（五个比例的均值和标准差，包括汇总和按推理模型分解），以及预测效度测试，其中每个链的类别比例与绝对模型-人类分歧|AI - H|和有符号的（AI - H）相关。相同的预测相关重新计算为控制图像级别边缘密度的偏相关，以测试链内容效应是否独立于研究1中记录的视觉复杂性混淆。对于感知准确性分析，我们报告每个匹配类别中链的比例以及每个类别内AI评分与人类评分的Pearson相关。对于幻觉审计，我们报告每个信心类别中链的比例以及与人类评分的相应相关。

#### 结果

**推理不提高一致性。**

我们首先询问启用推理链是否提高了与人类评分的一致性。与无推理相比，我们发现推理链并未有意义地提高与人类评分的一致性（表3）。在所有六个模型内、图像内比较（三个推理模型×两个数据集）中，推理开的最大优势是微不足道的+.012（Kimi K2.5在人类绘图上），而有趣的是，最小代价是相当大的-.075（Qwen 3.6 Plus在AI生成图像上）。对于三个模型中的两个（Kimi K2.5和GLM-5v Turbo），推理在两个数据集上基本中性。Qwen 3.6 Plus在两个数据集上启用推理时都显示出一致的约.07的降低。这种模式与LLM作为评判者文献中更广泛的发现一致，表明思维链有时会降低主观评估任务的性能（例如，Zheng 等，2023）。因此，推理在此的价值不在于与人类评分的更好一致性，而在于对评估过程的透明视图。

**表3：** 推理开与推理关与人类评分的一致性，模型内，图像内。

| 模型 | 数据集 | r 开 | r 关 | 差值 | |------|--------|------|------|------| | Kimi K2.5 | AI生成图像 | .648 | .636 | +.012 | | GLM-5v Turbo | AI生成图像 | .570 | .572 | -.002 | | Qwen 3.6 Plus | AI生成图像 | .562 | .637 | -.075 | | Kimi K2.5 | 手绘草图 | .544 | .550 | -.005 | | GLM-5v Turbo | 手绘草图 | .444 | .462 | -.018 | | Qwen 3.6 Plus | 手绘草图 | .470 | .535 | -.065 |

**模型内评分一致性。**

在转向链内容之前，我们验证了同一模型无论是否明确推理都会对相同图像分配相似评分。推理开和推理关评分在每个模型总体上呈强正相关。然而，评分并非完全相关，且明显降低，特别是在线条绘图数据集中：Kimi K2.5（AI图像r = .76，人类草图r = .67），Qwen 3.6 Plus（AI图像r = .75，人类草图r = .55）和GLM-5v Turbo（AI图像r = .68，人类草图r = .51），确认上述报告的一致性差异反映了一些评估标准的重新加权，而非根本不同的评分。

**链语言在没有图像的情况下携带评估信号。**

为了测试链是否携带驱动评分的评估信号，我们要求一个单独的纯文本模型（GPT-5.4 Nano）仅从链中预测每个评分，无法访问图像，且链文本中所有数字均被删除。我们发现模型以高准确率恢复了原始LLM评分：预测评分与实际评分总体相关r = .82（AI生成图像r = .81，手绘草图r = .65），69.8%精确匹配一致，99.4%的预测在实际评分的+/-1范围内。值得注意的是，预测评分也与人类评分实质性相关（AI生成图像r = .53，手绘草图r = .40），表明推理链包含与人类创造性判断一致的评估语言。

**四个评估维度构建链内容。**

我们接下来将每个链分解为句子并分类其评估内容。四个评估维度是：感知（描述可见内容），原创性（判断新颖性），质量（判断视觉美学和构图），以及证明（推理1到5量表并承诺评分）。三名独立的LLM评判者将7,475条链中的562,053个句子分类为四个评估类别之一或"其他"残余类别。覆盖率在两个数据集上都很高且稳定：AI生成图像97.3%的句子和人类绘制草图97.6%的句子获得了多数投票规范编码，其余反映三名评判者的1-1-1分裂（分别为2.7%和2.4%）。评判者间信度在两个数据集上都很实质性，AI生成图像的成对Cohen's kappa范围从+.69到+.79，人类绘制草图从+.71到+.81。按类别的kappa在AI图像上范围从+.64到+.76，在人类草图上从+.53到+.81，质量类别的值最低，这也是草图上最稀有的类别（仅3%的句子）。

汇总的句子级别分布在数据集之间明显不同（图6）。在AI生成图像上，模型将32.5%的推理句子用于原创性，23.3%用于证明，19.9%用于感知，12.2%用于质量，12.1%用于其他。在手绘草图上，相同模型将37.8%用于感知（与AI图像相比几乎翻倍），27.2%用于原创性，16.8%用于证明，15.3%用于其他，仅3.0%用于质量。这些结果表明四个类别捕捉了每个LLM稳定的评估倾向，且模型根据视觉刺激在不同阶段花费或多或少的时间。

**图6：** 按数据集划分的推理链内容。每个句子被分类为四个评估类别（感知、原创性、质量、证明）之一或残余的"其他"类别；柱形显示每个类别中句子的汇总百分比，跨所有链和所有三个具备推理能力的模型求和。手绘草图引发的感知几乎是AI生成图像的两倍（38%对20%），质量是AI生成图像的四分之一（3%对12%）。

关于模型效应，我们发现三个LLM显示出在两个数据集上都保持的明显评估概况（图7）。Qwen 3.6 Plus在两个数据集上都是最重感知和最重质量的；GLM-5v Turbo在两者上都是最重证明的；Kimi K2.5在人类草图上产生了最多的原创性和"其他"内容，反映了其推理中更多的过渡、对冲和元评论。

**图7：** 按模型划分的推理链内容。单元格显示每个链在每个类别中的平均比例，在模型和数据集内平均。概况在数据集间一致：Qwen 3.6 Plus最重感知和质量，GLM-5v Turbo最重证明，Kimi K2.5产生最多的原创性。因此，评估倾向是模型特定的而非刺激驱动的。

**原创性和质量预测模型-人类分歧。**

我们接下来询问四个评估维度是否预测模型在哪里偏离人类评分者（图8）。在两个数据集上，更多的原创性内容与相对于人类的较低模型评分相关，而更多的质量内容与较高的模型评分相关。然而，质量效应在AI生成图像上明显更强（模型系统性宽容），而在人类绘制草图上质量内容很少。感知和证明显示出较小的、依赖于数据集的效应，其他可以忽略不计。当我们用绝对分歧替换有符号分歧时，相同的模式成立。这些结果表明驱动模型-人类分歧的类别与模型花费最多评估努力的类别相同，原创性一致地拉低评分，而质量在模型有精致图像可评估时拉高评分。

**图8：** 推理链内容如何与模型-人类评分差距相关。柱形显示链的原创性（或质量）句子比例与有符号的模型减去人类评分差的Pearson相关：正值（珊瑚色）意味着该类别将模型评分推高至人类之上，负值（蓝色）推至之下。在两个数据集中，更多的原创性与更严厉的模型评分相关，更多的质量与更宽容的评分相关；质量效应在AI生成图像上最强，模型在那里相对于人类评分者更宽容。

**模型识别对象但误识别几乎不损害一致性。**

推理链不仅描述评估标准，还描述每个模型认为绘图描绘的内容（即感知），我们使用单独的LLM评判者将其与人类共识标签进行比较（表4）。我们发现，排除人类自身无法识别的绘图（NCD；见下文），模型在65.1%的链中正确识别了描绘的对象（2,770/4,253匹配或部分匹配）。识别准确性随项目难度系统性变化：形状4产生最高匹配率（75.6%），其次是形状11（63.9%），而形状12作为难度上限，为55.5%。这一梯度反映了研究1中观察到的按形状模式。

然而，核心问题是对象误识别是否会削弱与人类创造力评分的一致性。结果表明并非如此：正确识别绘图的模型与人类评分的相关（r = .49，N = 2,605）仅略高于误识别绘图（r = .43，N = 1,422）。部分匹配（r = .43，N = 165）和明确弃权（r = .45，N = 61）落在相同的狭窄范围内，表明这些模型检测到的创造力信号独立于模型是否正确感知绘图描绘的内容。

**表4：** 按匹配类别划分的感知准确性和评分一致性（手绘草图）。

| 匹配类别 | N | 与人类评分的r | |----------|---|--------------| | 匹配 | 2,605 | .49 | | 部分匹配 | 165 | .43 | | 不匹配 | 1,422 | .43 | | 模型弃权 | 61 | .45 | | NCD（人类不可解释） | 246 | .55 |

**一致性在人类无法识别的绘图上最强。**

最后，我们检查了模型如何处理人类无法分类的绘图。1,500幅手绘草图中有82幅缺乏共识标签，因为评分者无法就绘图描绘的内容达成一致。这些NCD产生了任何匹配类别中最高的模型-人类一致性（r = .55，三个模型共246条链）。为了表征模型如何处理这些模糊刺激，我们按模型对所提识别的信心对每条NCD链进行分类。大多数链反映有保留识别（63.4%），模型在表达不确定性的同时命名了一个可能的对象；较小比例反映确信识别（33.3%），模型无条件地断言一个特定对象；很少反映彻底弃权（3.3%）。与人类评分的一致性在各信心类别中都很稳健（有保留：r = .56；确信：r = .51）。这些结果表明，当绘图抗拒分类时，即当人类和模型都无法确定一个常规标签时，两者都退回到绘图本身的结构和构图属性，这些评估趋于收敛。

### 讨论

本研究提供了首个证据，表明通用多模态LLM无需任何额外训练即可匹配人类对视觉创造力的判断。研究1确立了六个模型在AI生成图像和手绘草图上都与人类创造力评分显示出强正相关，偏相关确认一致性不能由低级视觉复杂性解释。研究2证明三个推理模型产生的"思维链"遵循四部分结构（感知、原创性、质量、证明），该结构在各模型间反复出现并解释其最终评分，提供了一种可解释的方式来理解AI模型如何评估创造力。

在研究1中，Gemini 3 Flash在两个数据集上都显示出与人类评分的最强一致性（各r = .68）。值得注意的是，两个开源模型（Kimi K2.5、Qwen 3.6 Plus）的表现优于领先的专有LLM（GPT-5.4 Mini），后者总体上产生最弱的一致性，特别是在人类绘制草图上（r = .29）。一致性在草图上总体上也比AI生成图像上弱，即使对于最强模型也是如此，模型的排名顺序在草图和图像之间发生了变化。这些结果表明，零样本视觉创造力评分在一系列多模态LLM上是可行的，但模型选择对于稀疏刺激（如人类草图）比对于精致刺激（AI生成图像）更重要。

我们的结果扩展了自动创造力评分文献，该文献主要关注言语任务，如AUT（Beaty和Johnson，2021；Organisciak 等，2023；Saretzki 等，2025）。这类工作通常在数千个创造性反应和人类评分上微调语言模型，产生一个在特定创造力任务上表现良好（但在其他任务上不表现）的训练模型。最近，研究人员开始探索LLM仅使用提示进行自动评分的潜力，显示出在没有示例的情况下与人类评分的极高相关性（Organisciak 等，2023；Saretzki 等，2025）。本研究将这项工作扩展到图形领域，该领域迄今为止只微调了需要大规模人类评分数据的视觉分类器（Acar 等，2025；Cropley 等，2025；Cropley和Marrone，2025；Patterson 等，2024）。我们在没有特定任务训练的情况下实现了可比的相关性，使用零样本提示，仅给予人类评分者简短的评分提示。尽管我们的结果指出了零样本创造力评分的潜力，但我们警告不要在尚未验证的新任务上为此目的使用LLM。

我们在LLM创造力评分中观察到两个明显的偏差：精细化偏差和宽容偏差。关于精细化，模型（和人类）倾向于在言语和视觉任务上对更复杂的反应给予更高评分（Domanti 等，2026；Patterson 等，2024）：页面上的墨水等特征对于AI模型来说很容易检测（即更多线条，更高评分）。关键的是，在我们的研究中，LLM与人类的一致性在控制边缘密度后仍然稳健，表明它们追踪了创造力的一些更高层面。关于宽容偏差，模型平均对AI生成图像给予比人类绘制草图更高的创造力评分，表明LLM评判者惩罚线条绘图的简单性，尽管提示词指示关注原创性而非技术熟练度。这种模式与LLM作为评判者系统中自我偏好和熟悉性偏差的证据日益增多一致，其中模型对类似于自己生成或落在其训练分布内的输出给予不成比例的高评分（Panickssery 等，2024；Wataoka 等，2024）。这种不对称性对自动评分的有效性构成相当大的威胁，应在未来工作中通过仔细校准来解决。

据我们所知，本研究是首次分析LLM如何推理视觉创造力，分析其导致最终评分的"思考过程"。我们识别了评估过程的四个阶段——图像感知、原创性评估、质量评估和评分证明——这些阶段在三个不同的LLM中对绘图和图像都反复出现。然而，这些推理阶段部分是预期的，因为推理模型经过后训练以遵循近期视觉语言思维链工作中识别的更广泛的感知→推理→整合结构（Avogaro 等，2026；Jiang 等，2025）。分析推理轨迹的价值在于它们展示了这种一般推理结构如何在创造性评估中实例化：模型首先描述视觉内容，然后评估原创性和质量，最后将这些考虑整合到评分中。

值得注意的是，推理相对于无推理基线并未提高与人类评分的一致性，这与先前工作显示推理不一定提高主观评估任务性能一致（Zheng 等，2023）。因此，推理轨迹作为可解释性来源最有用，揭示了LLM如何评估不同视觉输入的系统性差异。具体而言，模型在评估手绘草图时在感知上花费更多时间，但在评估AI生成图像时在质量上花费更多时间。分析推理链还澄清了模型判断在哪里偏离人类评分，原创性语言与较低评分相关，质量语言与较高评分相关，特别是对于AI生成图像。总之，这些模式表明推理轨迹可以通过展示不仅模型是否与人类一致，而且哪些评估标准似乎驱动了这种一致，来帮助审计LLM创造力判断。

感知准确性分析进一步表明，LLM创造力判断不能简化为对象识别。尽管模型在大多数情况下正确识别了人类绘制草图中描绘的对象，但误识别仅略微降低与人类评分的一致性。一个特别引人注目的结果来自人类评分者自身无法清楚分类的绘图，这些绘图显示出任何匹配类别中最强的模型-人类一致性。这种模式表明，当对象身份模糊时，人类和模型可能都更严重地依赖更广泛的视觉特征，如精细化、构图和起始形状的整合。因此，LLM检测到的创造力信号似乎部分独立于成功的对象识别。

有几个局限性值得注意，特别是关于本研究发现的普适性。两个数据集在刺激类型、评分指示和人类评分程序上不同，这使得AI生成图像和手绘草图之间的直接比较具有挑战性。然而，这部分是有意的，因为目标是测试零样本评分是否适用于不同形式的视觉创造力。未来工作应使用更标准化的设计，将刺激效应与评分方法效应分离。我们的过程分析也受到可用数据的限制。感知准确性只能对手绘草图进行测试，没有共识标签的绘图子集相对较小，幻觉审计依赖于单一LLM评判者。最后，本研究关注两个视觉创造力任务。关于视觉创造力评估的更广泛主张将需要测试其他领域，如设计、摄影和混合媒体作品，理想情况下使用校准的评分程序和在共同指示下收集的人类基准。

总之，本研究首次表明多模态LLM可以匹配人类对视觉创造力的判断。我们发现它们的推理遵循一致且可解释的序列，有助于解释模型如何得出其评分。此外，模型-人类一致性在对象误识别下保持稳健，并在控制视觉复杂性后持续存在。因此，多模态LLM为视觉创造力评估提供了一种有前景的工具，同时也使其偏差更容易检测、量化和缓解。为了支持其他研究人员对此流程的二次使用，我们还分享了一个开放网络应用，可在用户提供的图像上运行相同的评分程序（附录A）。

### 附录A：使用评分应用

为了使流程在本文报告的分析之外可访问，我们构建了一个小型网络应用，可在任何用户提供的图像上重现稿件的评分程序。该应用在浏览器中运行，无需安装，托管在 https://review-visual-eval-scoring.hf.space/ 。源代码位于GitHub存储库的 scoring_app/ 目录中。

**设置。** 该应用通过OpenRouter路由每次模型调用，OpenRouter是跨模型提供商的统一OpenAI兼容API，因此用户只需要一个API密钥。密钥可在 https://openrouter.ai/keys 获取。密钥仅发送给OpenRouter用于用户触发的请求，不被应用记录、存储或持久化。源代码公开可供检查。

**评分单张图像。** 用户将一张图像拖放到上传框中，粘贴其OpenRouter密钥，然后点击"Score image(s)"。默认情况下，查询所有六个模型，并为三个具备推理能力的模型（GLM-5v Turbo、Kimi K2.5、Qwen 3.6 Plus）捕获推理链。评分填充四列表格（图像文件名、模型、1-5评分和推理链的简短摘录）。非推理模型通常在几秒内返回评分，而具备推理能力的模型明显需要更长时间，因为它们在承诺最终评分之前生成完整推理链。图9显示了一个代表性会话。

**图9：** 评分应用截图。用户上传一张或多张图像，提供单个OpenRouter API密钥，并使用稿件中的确切提示词恢复每个模型的创造力评分（以及，对于具备推理能力的模型，底层推理链）。

**批量评分。** 相同的上传框一次接受任意数量的图像。调用并行运行并在瞬时错误时自动重试，因此批量完成比逐个评分图像快得多。

**自定义评分提示词。** 该应用默认加载AI生成图像提示词。"高级设置"在可编辑框中显示完整提示词文本，以及一键加载稿件中AI图像提示词或手绘草图提示词的按钮。希望将此流程应用于新视觉领域的研究人员可以直接编辑提示词而无需更改任何代码；然后新提示词用于批量中每个模型对每张图像的评分。

**其他可调设置。** 温度（默认0；与稿件匹配）、最大输出令牌和并行API调用的并发级别在"高级设置"中作为滑块显示。

**输出。** 每次运行后，结果表格显示每个（图像，模型）对一行。可下载的CSV保留每个单元格的完整推理文本，列为 image、model、rating 和 reasoning。CSV在每次评分运行时重新生成；用户应在评分新批量之前将其保存在本地。

**可重现性。** 该应用使用表1中列出的确切模型标识符和第2.3节中的提示词。将温度设置为零的用户在相同模型检查点上对相同图像评分时将恢复稿件中报告的相同评分。
