摘要

能量模型（EBMs）通过标量能量定义分布 p_θ(x) ∝ exp(−E_θ(x))，通常被呈现为众多模型家族中的一员。本教程有一个更宏大的目标：除了介绍EBMs之外，它将EBMs作为连接机器学习不同方面的统一视角。任何EBM由三个选择指定：能量，决定模型表示什么；推理过程，从能量中采样或优化能量；以及学习方法，将能量拟合到数据。我们首先发展这些组件，包括采样、变分推理和通过最大似然、噪声对比估计、伪似然、分数匹配和对抗训练的学习，并展示这些学习方法共享一个对比结构。然后我们展示判别模型、生成模型（如GANs、归一化流、扩散和自回归模型）、表示学习方法（如对比学习、word2vec、BERT、去噪自编码器和扩散表示）、使用EBM策略和世界模型的强化学习、逆强化学习和规划，以及使用验证器的推理时计算，都是EBMs，它们在这三个选择上有所不同，主要在于它们如何处理配分函数和采样。这个视角解释了现有方法，将它们组织成一个通用框架，并通过替换一个组件同时保留其他组件来建议新算法，能量组合是在推理时组合学习模型的原则性方式。

1 引言

机器学习通常被分为监督学习、生成建模、表示学习和决策制定，每个领域都有自己的模型和训练目标。然而，这些领域共享一个共同的问题：学习变量之间的关系并使用这些关系来推断未知量。能量模型（EBMs）通过标量能量函数表示配置的兼容性，为这个问题提供了统一的视角。低能量配置对应于合理的观察、兼容的表示或期望的结果。学习塑造这个能量景观，而推理使用它来产生预测、样本或动作。

这个视角连接了三个想法：表示、推理和组合。能量函数通过变量之间的关系和约束来表示知识。推理通过搜索兼容的配置来使用这些知识，无论是通过优化还是采样。组合结合能量函数来表达必须一起考虑的要求。分离这些角色允许学习的知识在不同的计算中被重用，并在推理时与新信息结合。例如，观察和潜在变量上的联合能量既可以支持从潜在描述生成观察，也可以支持从观察推断描述。轨迹上的能量可以与一个新目标结合来表述规划问题。

在本教程中（源自Bo Dai在佐治亚理工学院教授的课程CSE 6243），我们在不同的生成模型、表示学习方法和规划与强化学习方法中发展这个视角。我们主要考虑概率表述，其中能量通过 p_θ(x) ∝ exp(−E_θ(x)) 定义一个非归一化分布。对于生成建模，这为比较参数化密度、学习分数或构建采样过程的模型提供了共同语言。自回归模型指定条件因子，其负对数求和得到能量，而可逆的归一化流通过变量替换指定密度。扩散模型在不同噪声水平下学习对数密度的梯度。这些联系既阐明了生成模型之间的关系，也阐明了它们对表示和推理的不同假设。它们还提供了开发新生成模型的统一方式。

对于表示学习，能量表达观察与潜在描述之间，或同一数据的不同视图之间的兼容性。对比方法通过匹配和不匹配观察的分数学习特征，而重建和去噪目标训练表示以支持缺失或损坏信息的预测。通过它们相关的能量来看待这些目标，将表示学习与条件预测和生成建模联系起来。它还提示了学习的生成模型如何为推断新观察的表示提供目标。

对于规划和决策制定，能量根据候选动作或轨迹的预测后果对其进行评分。成本和约束贡献能量项，而奖励以相反的符号进入。规划搜索满足这些要求的配置，熵正则化表述将这个搜索与概率推理联系起来。学习的动力学、行为模型和任务目标因此可以贡献一个共同推理问题的不同组件。

对于推理时计算，能量对问题的不同可能解决方案进行评分。推理时计算的不同方法，如在采样的响应中进行选择、搜索部分解决方案或迭代地改进候选，对应于最小化这个能量的不同程序。微调对应于直接拟合这个组合能量，在训练期间支付推理成本而不是为每个输入支付。

组合使我们能够使用这些联系来解决新任务。兼容变量上的能量函数可以相加以组合它们的要求，当结果分布可归一化时，对应于它们非归一化密度的乘积。例如，描述合理机器人轨迹的能量可以与表达目的地和障碍约束的能量相结合。由此产生的推理问题将学习的知识与任务特定信息一起使用，而不需要为每个组合训练单独的预测器。这种表示可重用组件并对其组合进行推理的能力激发了基于能量的视角。它的实际成功取决于组件的准确性和相对尺度，以及优化或从组合景观中采样的能力。

我们从EBMs的表述和推理与学习方法开始（第2节）。然后我们通过这个通用框架检查判别模型（第3节）、生成模型（第4节）、表示学习（第5节）、强化学习和规划（第6节）以及推理时计算（第7节），并以讨论结束（第8节）。在整个过程中，我们询问每种方法表示什么，推理如何使用该表示，以及其组件如何可以组合或适应新任务。我们的目标是解释现有方法之间的联系，并展示这些联系如何可以指导学习可重用知识并在推理时对其进行推理的模型设计。

2 能量模型简介

2.1 能量模型

我们从单变量的能量模型开始，它也被称为Gibbs分布 [75]。形式上，EBM将密度定义为

p_θ(x) = exp(−E_θ(x)) / Z_θ，其中 Z_θ = ∫ exp(−E_θ(x)) dx，　(1)

其中 E_θ(x)，称为能量函数，是由 θ 参数化的某个函数，Z_θ 被称为配分函数，它通常是未知的且难以计算。EBM公式1定义了一个有效的分布，满足正性 p_θ(x) ⩾ 0 和归一化 ∫ p_θ(x) dx = 1。公式1中密度 p_θ(x) 的值（相差一个乘法常数）完全由能量函数 E_θ(x) 确定，使我们即使在不知道归一化常数的情况下也能从密度中采样。

EBMs可以容易地推广到具有多个变量的联合或条件模型，即

p_θ(x, y) = exp(−E_θ(x, y)) / Z_θ，其中 Z_θ = ∫ exp(−E_θ(x, y)) dx dy，　(2)

p_θ(y | x) = exp(−E_θ(x, y)) / Z_θ(x)，其中 Z_θ(x) = ∫ exp(−E_θ(x, y)) dy。　(3)

通过比较公式2和公式3中的联合和条件EBMs，我们强调配分函数的重要性，这引出了EBMs的一个关键特性：使用相同的能量函数但不同的配分函数，我们可以表示并从相应的条件分布或联合分布中采样。虽然这个特性看起来微不足道，但它将在实现组合性、适应性以及改善训练数据样本复杂度方面发挥重要作用。

与许多类生成模型相比，EBMs公式1直接建模概率密度，没有任何形式的分布分解来实现高效采样。因此，对于许多分布，将分布表示为EBMs比其他分解参数化更简单，但代价是推理成本更高。在深入讨论EBMs的组合和自适应特性之前，我们首先提供一般EBMs的例子。事实上，各种经典机器学习模型可以表示为EBMs的特殊形式。

残差EBM。 对于公式1中的任何EBM，它也可以等价地写为

p_θ(x) = p₀(x) · exp(−Ẽ_θ(x)) / Z_θ，其中 Ẽ_θ(x) = E_θ(x) + log p₀(x)，　(4)

其中 p₀(x) 是某个基础概率测度。等价模型公式4被称为残差EBM [43, 5]。我们强调，虽然原始EBM公式1和残差EBM公式4具有相同的建模灵活性，但当有好的基础分布可用时，残差EBM更方便，如第4.4节中能量启发的模型和第6.1节中KL正则化策略。

指数族。 指数族是统计学和机器学习中最重要的分布类之一 [185]，它具有许多有用的性质 [23]，是EBM的一种特殊形式。

概率分布属于指数族，如果它可以写成以下标准形式：

p_θ(x) = h(x) exp(θ^⊤ T(x) − A(θ))，

其中 θ 是自然参数，T(x) 是充分统计量，h(x) 表示 x 的某个基础测度，A(θ) = log ∫ exp(θ^⊤ T(x)) h(x) dx 是对数配分函数。指数族包括许多常用的分布，如高斯分布、泊松分布和多项式分布等。

显然，指数族是EBMs的特殊情况，其能量对 θ 是线性的，即 E_θ(x) = −θ^⊤ T(x) − log h(x)。

最大熵模型。 最大熵模型 [4, 60] 是一种统计建模技术，它选择在满足从训练数据导出的一组观察约束的所有分布中具有最高熵的概率分布。形式上，MaxEnt定义为

max_{q∈Δ(X)} H(q) := −∫ q(x) log q(x) dx　(5)
s.t. E_{q(x)}[f_i(x)] = a_i，∀i = 1, …, k，　(6)

这引出拉格朗日函数

L(q, λ) = −H(q) − ∑{i=1}^{k} λ_i (E{q(x)}[f_i(x)] − a_i) − λ₀(∫ q(x) dx − 1)。　(7)

对 L(q, λ) 关于 q(x) 求偏导并设为零，得到

∂L(q, λ)/∂q(x) = log q(x) + 1 − ∑{i=1}^{k} λ_i f_i(x) − λ₀ = 0　⇒　q*(x) = exp(∑{i=1}^{k} λ_i f_i(x)) / Z，　(8)

这显然是一个具有能量函数 E(x) = −λ^⊤ f(x)（参数为 λ，特征为 f(x)）的EBM。

马尔可夫随机场和条件随机场。 马尔可夫随机场（MRFs）是变量之间具有显式依赖关系的分布。形式上，MRF通过无向图 G 在 x = {x₁, x₂, …, x_d} 上定义概率分布，其中节点对应变量 x_i，边定义两个变量之间的依赖关系，得到

p(x) = (1/Z) ∏{c∈C} ψ_c(x_c) = (1/Z) exp(∑{c∈C} log ψ_c(x_c))，　(9)

其中 Z 为配分函数，C 表示 G 的团集合，每个因子 ψ_c(·) 是相应子图中变量上的非负函数。

类似地，条件随机场（CRFs）推广了MRFs并定义条件分布为

p(y | x) = (1/Z(x)) ∏{c∈C} ψ_c(x, y) = (1/Z(x)) exp(∑{c∈C} log ψ_c(x, y))　(10)

显然，MRF公式9和CRF公式10都可以等价地简化为相应的EBMs，其显式依赖结构由能量函数 E(x) = −∑{c∈C} log ψ_c(x_c) 和 E(x, y) = −∑{c∈C} log ψ_c(x, y) 捕获。

Hopfield网络和（受限）玻尔兹曼机。 Hopfield网络被提出作为具有循环连接的二值阈值单元。已经揭示，如果连接是对称的，二值 x 存在相应的全局能量函数

E(x) = −(1/2) x^⊤ W x − x^⊤ b，其中 x ∈ {−1, +1}^d，

它诱导分布 p(x) ∝ exp(−E(x))，与随机Hopfield网络更新的平稳分布一致，即 p(x_i = 1 | x_{−i}) = 1 / (1 + exp(−2(∑{j≠i} w{ij} x_j + b_i)))。诱导的随机规则和平稳分布也分别被称为玻尔兹曼机和玻尔兹曼分布。

此外，如果我们将变量分成两个不相交的组 {x, y} 并构建二部连接，我们得到能量函数

E(x, y) = −x^⊤ b − y^⊤ a − x^⊤ A y，　(11)

其中 x 和 y 可以是二值的、分类的或高斯的。由于能量函数的结构受限，使得 x 或 y 中没有层内连接，该模型被命名为受限玻尔兹曼机。同时，由于这种特殊结构，y 的分量在给定 x 时条件独立，反之亦然。

虽然EBMs定义了灵活的分布，但众所周知，公式2和公式3中的配分函数是难以处理的，因此，从EBMs采样和计算概率都不简单。因此，使用EBMs的学习是复杂的。我们在第2.4节讨论采样，在第2.5节讨论学习。

2.2 超越EBMs：广义最大熵

第2节的最大熵模型公式5做了两个选择：它最大化Shannon熵，并且它精确地施加矩约束；其解公式8则是指数族中的EBM。EBMs超越了这两个选择。最大化Shannon熵等价于最小化与均匀基础测度的KL散度，这可以被其他散度替代，精确约束可以放松为近似约束；不同的选择诱导不同的模型家族 [79, 4, 60, 67]。考虑广义问题

min_{q∈Δ(X)} D(q ∥ p₀)　s.t.　‖E_{q(x)}[f(x)] − a‖_ℬ ⩽ ε，　(12)

其中 D 是来自基础测度 p₀ 的凸散度，‖·‖_ℬ 是范数，ε ⩾ 0 允许近似矩匹配。最大熵模型公式5是KL散度、均匀 p₀ 和 ε = 0 的情况。

公式12中的两个选择以不同的方式改变模型。

  • 散度决定模型家族。 对于具有凸生成器 φ 的 f-散度，最优解是

D_φ(q ∥ p₀) = ∫ p₀(x) φ(q(x)/p₀(x)) dx　⟹　q*(x) = p₀(x) (φ′)⁻¹(λ^⊤ f(x) − λ₀)，　(13)

其中 λ₀ 为归一化而选择，只有当 φ(u) = u log u 时它才是指数族。更一般地，正则指数族与正则Bregman散度一一对应 [13]，其他散度和广义熵诱导广义或变形的指数族 [79, 129, 67]。对于 α-散度，φ_α(u) = (u^α − αu + α − 1)/(α(α−1))，它是幂律族

q*(x) = p₀(x) [1 + (α−1)(λ^⊤ f(x) − λ₀)]₊^{1/(α−1)}，　(14)

当 α → 1 时恢复指数族，否则具有更重的尾部或有界支撑。它对应于Tsallis统计学的 q-指数族 [129]。用这样的重尾族替换指数族改变了学习模型的行为，例如，t-逻辑回归 [46] 用 t-指数族替换逻辑回归的softmax，这使得分类器对标签噪声鲁棒。

  • 范数决定正则化和特征空间。 当 ε > 0 时，公式12的对偶变成由对偶范数正则化的最大似然 [4]，例如，产生稀疏模型的 ℓ₁ 惩罚 [60]。取 f(x) = k(x, ·) 作为再生核希尔伯特空间（RKHS）ℋ 的特征映射，ℬ 作为其范数，得到无穷维核指数族 p(x) ∝ p₀(x) exp(⟨λ, k(x, ·)⟩_ℋ)，带有RKHS范数惩罚 [4, 25, 164, 34]，这是一个能量为 ℋ 中非参数函数的EBM。

2.3 EBMs的适应性和可组合性

学习EBMs的一个主要好处是它们在使用相同能量函数表示不同概率分布方面的灵活性。如公式3后所述，联合能量也定义了通过固定其任何变量子集获得的条件分布，只有配分函数改变。能量还可以相加、相减和组合，这从学习的分布形成新的分布而无需重新训练 [58, 50]。下面，我们描述集合和分布上的这些操作，讨论组合何时正确以及它与专家乘积的区别，并展示相同的操作如何适应预训练模型以及如何从组合能量中采样。

组合EBM集合函数。 我们首先说明能量函数上的组合如何用于实现逻辑集合操作 [51]。考虑集合 A 和 B 以及这些集合的学习能量函数 E_A(x) 和 E_B(x)，例如

E_A(x) = { 0，若 x ∈ A；C，若 x ∉ A }，　(15)

其中 C 是一个大的数值。在这些学习的能量函数 E_A(x) 或 E_B(x) 下采样对应于从集合 A 或 B 中抽取样本。集合上的逻辑操作然后变成能量上的算术运算，如图1(a)所示。

  1. 逻辑AND。 交集 A ∩ B 由能量的和表示，

E_{A∧B}(x) = E_A(x) + E_B(x)，　(16)

它在 A ∩ B 上为0，在其他地方至少为 C，因此低能量样本满足两个要求。

  1. 逻辑OR。 并集 A ∪ B 由能量的软最小值表示，

E_{A∨B}(x) = −log(exp(−E_A(x)) + exp(−E_B(x)))，　(17)

它在 A ∪ B 上至多为0，在其他地方等于 C − log 2。它与 min{E_A(x), E_B(x)} 相差至多 log 2，因此低能量样本满足任一要求。

  1. 逻辑NOT。 否定减去一个能量。有界集合的补集是无界的，因此否定相对于另一个集合应用：没有 A 的 B 由

E_{B∧¬A}(x) = E_B(x) − E_A(x) + C，　(18)

表示，它在 B∖A 上为0，在其他地方至少为 C。减去的能量充当否定操作：它在 A 成立的地方提高能量，在其他地方保持不变。

每个操作返回一个能量，因此操作可以嵌套，它们适用于学习的能量以及公式15的理想化能量。图1(b)显示了从独立训练的条件能量的嵌套组合中采样的人脸，每个都在单个属性上训练 [51]。

图1： 能量函数的逻辑组合。 AND、OR和NOT应用于两个集合 A 和 B；组合能量在阴影区域中较低。 从条件能量组合中采样的人脸，每个在CelebA的一个属性上独立训练。图来自Du等人 [51]。

组合EBM概率分布。 我们同样可以组合分布而不是集合。乘积、混合和反转是AND、OR和NOT的分布对应物，但能量现在是 log-密度，因此它们的值（而不仅仅是它们的最小化子）很重要，如图2所示。设 p_i(x) = exp(−E_i(x))/Z_i，i = 1, 2。

  1. 分布的乘积。 两个分布的乘积可以写为

p_product(x) ∝ p₁(x) p₂(x) ∝ e^{−(E₁(x)+E₂(x))}。　(19)

因此，我们可以构造能量函数 E′(x)，使用表达式

E′(x) = E₁(x) + E₂(x)，　(20)

表示密度的乘积，提供了一种组合能量函数来实现密度乘积的方法。密度乘积允许我们构造结合两个分布中信息的新密度——采样在两个分布下都很可能出现的 x [50, 197]。配分函数 Z₁ 和 Z₂ 不起作用，因为向任一能量添加常数只改变乘积的归一化子，并且只要其中一个密度有界，乘积就是可归一化的，因为 p₁p₂ ⩽ (sup_x p₁(x)) p₂。对能量加权，w₁E₁ + w₂E₂（w₁, w₂ > 0），得到 p₁^{w₁} p₂^{w₂}，其中每个权重充当逆温度，锐化或平坦化其组件。

  1. 分布的混合。 我们可以表示混合 p_mix(x) = w₁p₁(x) + w₂p₂(x)（w₁ + w₂ = 1），通过能量

E_mix(x) = −log(w₁ exp(−E₁(x))/Z₁ + w₂ exp(−E₂(x))/Z₂)，　(21)

这是软最小值公式17，每个能量 E_i 移动 log Z_i − log w_i。与乘积不同，混合依赖于配分函数。能量仅由加性常数确定，这不改变其自身分布但移动其组件的权重。例如，在公式17的能量组合算子中，E₁ 和 E₂ 单独的软最小值是权重与 Z₁ 和 Z₂ 成比例的混合。对于一般分布，具有给定权重的混合需要 log Z₁ − log Z₂，它可以与能量一起学习，如二元NCE公式42的常数 c，或用变分界公式30估计。如果只对混合进行采样，可以通过祖先采样避免配分函数：以概率 w_i 抽取 i，然后抽取 x ∼ p_i。一旦混合进一步组合，例如乘以第三个分布，就需要它们，因为组合能量上的MCMC评估 E_mix 本身。

  1. 分布的反转。 我们可以表示一个有利于在 p₁ 下可能但在 p₂ 下不可能的点的分布，通过将 p₂ 提升到负幂，

p_inv(x) ∝ p₁(x)/p₂(x)^α，　E_inv(x) = E₁(x) − αE₂(x)，　(22)

其中 α > 0，这是公式18的分布对应物。与乘积一样，反转不依赖于配分函数，但可能不可归一化。对于高斯分布 p_i = N(0, σ_i²I)，p_inv 只有当 ασ₁² < σ₂² 时才可归一化，即被否定的专家必须相对于正专家是宽的。无分类器引导公式88是这种反转提升到 1+w 次幂，因为 p_t(x|y)^{1+w}/p_t(x)^w = (p_t(x|y)/p_t(x)^α)^{1+w}，α = w/(1+w) < 1，其被否定的分布是无条件模型。

图2： 组合两个一维密度。 左：p₁（点线）和 p₂（虚线），在其他面板中以灰色重复，其中每个组合（蓝色）缩放到其自身最大值。乘积保持两者一致的质量，混合保持两者的质量。添加非归一化密度 e^{−E₁}+e^{−E₂}，而是通过其配分函数加权每个组件公式21，因此宽的 p₂ 得到权重 w₂ ≈ 0.72 而不是 1/2（这里每个 E_i 的最小值为零）。反转 p₁/p₂^{0.7} 保持 p₁ 在 p₂ 低的地方的质量。

组合何时正确？ 我们可以通过贝叶斯规则理解乘积的作用。设 c₁, …, c_n 是 x 上的条件，例如图像的属性或轨迹上的要求，假设我们有无条件EBM p(x) ∝ exp(−E(x)) 和每个条件单独的条件EBM p(x|c_i) ∝ exp(−E(x|c_i))。如果条件在给定 x 时条件独立，那么

p(x|c₁, …, c_n) ∝ p(x) ∏{i=1}^{n} p(c_i|x) ∝ p(x) ∏{i=1}^{n} p(x|c_i)/p(x)，　(23)

E(x|c₁, …, c_n) = E(x) + ∑_{i=1}^{n} (E(x|c_i) − E(x))，

相差不依赖于 x 的常数 [117]。每个差 E(x|c_i) − E(x) 等于 −log p(c_i|x)（相差一个常数），即它是隐式分类器的能量，因此合取向单个先验添加每个条件一个分类器能量，先验被计算一次而不是 n 次。对差加权给出第4.3节的引导分布，n = 1 对应无分类器引导，添加 c₁ 的差同时减去 c₂ 的差给出否定 p(x) p(c₁|x)/p(c₂|x)，这是反转公式22，其被否定的专家是 c₂ 的隐式分类器。推导使两个要求显式。首先，条件必须在给定 x 时条件独立，例如当每个条件是 x 的函数时成立。其次，每个 p(x|c_i) 必须在组合放置其质量的区域准确，该区域可能对任何单个条件包含很少的训练样本。第一个是建模假设，第二个决定组合超出其训练数据的泛化程度。

组合做什么？ 组合在新组合中重用学习的组件。每个组件描述数据或任务的一个方面，例如概念、约束、动力学模型或目标，并且可以是单独训练的模型或在某个条件下评估的条件模型。组件也可以定义在变量的不同子集上，在这种情况下，组合能量是MRF公式9，其因子单独学习，其图为每个任务选择，如场景中对象之间的约束组合成其姿态上的因子图 [197]。由于组件单独学习，训练需要覆盖每个组件但不是每个组合。假设 x 由 K 个条件描述，每个取 M 个值之一。p(x|c₁, …, c_K) 的单个模型必须在足够多的 M^K 组合上训练，而组合公式23只需要 K·M 个条件 p(x|c_k)，并且它生成从未在训练数据中一起出现的组合 [51, 117]。相同的操作在整个教程中反复出现：引导采样将扩散模型乘以分类器（第4.3节），规划器组合动力学、目标和障碍（第6.5节），推理将单个约束的能量组合成更大的问题（第7.3节）。乘积公式20具有专家乘积的形式 [87]，它使用联合训练的专家来建模单个分布；组合使用它来组合单独训练的模型。参见Du和Kaelbling [50]的更广泛讨论。

适应。 相同的操作使预训练模型适应新数据或要求而无需重新训练。条件化是最简单的情况：通过公式2和公式3，固定联合能量的任何变量子集，例如图像的可见像素或轨迹的起点和终点，将相同的能量转换为条件模型，MCMC从不需要新的配分函数。残差能量使模型适应新数据：通过公式4，p(x) ∝ p₀(x) exp(−Ẽ_θ(x)) 保持预训练的 p₀ 固定并只学习 Ẽ_θ，当新分布接近旧分布时它可以很小。这是第6.1节中语言模型KL正则化微调的结构，其中 Ẽ = −r/λ，以及视频模型的概率适应，其中大型预训练文本到视频模型（仅通过其分数使用而无需微调）作为乘积与在领域特定视频上训练的小模型组合 [194]。最后，新要求是新的能量项：第6.5节的规划问题通过添加它们的能量使轨迹模型适应目标和约束。

从组合中采样。 组合能量使用第2.4节的方法采样或最小化，这些方法需要组合能量或其梯度但不需要配分函数。三个实际问题仍然存在。首先，将能量之和读取为分布乘积要求每个能量是相差常数的 log-密度。通过回归（第2.5节）或带边距（第3节）训练的能量不是最大似然拟合，对于它们，和更好地被读取为目标，如上面的集合操作：当要求兼容时，其最小化子满足所有要求，通过能量最小化公式35的预测直接适用。其次，单独训练的能量没有共同的尺度，因此 ∑_i w_i E_i 中的权重充当必须在推理时选择的逆温度。第三，乘积的模式位于所有组件一致的地方，这可能是远离每个组件模式的小区域，因此组合景观比其部分更难采样。通过平滑能量的退火有帮助，扩散模型为每个组件提供这样的序列；然而，在某个噪声水平添加它们的分数不给出平滑乘积的分数，因此在求和能量上的朗之万或MCMC修正是正确采样组合所必需的（第4.3节）[49]。

2.4 EBMs的推理

在本节中，我们首先介绍计算EBMs诱导的相应概率分布的近似算法，它们可以大致分为两类：通过生成样本的Metropolis–Hastings算法和通过分布近似的变分推理。然后，我们介绍通过优化的预测，它返回单个输出而不是样本。我们主要讨论无条件EBMs公式2的推理方法，然而，这些算法可以容易地推广到条件EBMs公式3。

Metropolis-Hastings采样。 由于 Z_θ 是难以处理的，我们不能直接从 p_θ(x) ∝ exp(−E_θ(x)) 采样或计算概率。马尔可夫链蒙特卡洛（MCMC）而是构造一个平稳分布为 p_θ 的马尔可夫链，并将燃烧期后链的状态视为近似样本。Metropolis-Hastings（MH）算法 [125, 85] 是通用配方：给定当前状态 x，它从提议分布中抽取候选 x′ ∼ q(x′|x)，并以概率

α(x, x′) = min{1, exp(−E_θ(x′)) q(x|x′) / (exp(−E_θ(x)) q(x′|x))}　(24)

接受它，否则停留在 x。配分函数在比率中抵消，因此只需要能量差 E_θ(x′) − E_θ(x)，接受步骤保证对任何有效提议关于 p_θ 的详细平衡。不同的MH采样器只在 q 的选择上不同，这决定了能量函数如何被使用。

吉布斯采样器 [72] 每次更新一个变量（或变量块），使用完整条件 p_θ(x_i | x_{−i}) 作为提议。通过这种 q 的选择，公式24中的接受概率总是一，这意味着候选总是被接受。条件只涉及包含 x_i 的能量项，这使吉布斯采样对MRFs和玻尔兹曼机自然。特别是，在RBMs中，给定 x 时 y 的条件独立性（反之亦然）允许每层在一个块中采样。

对于连续 x 和可微能量，梯度 ∇_x E_θ(x) 提供比随机扰动好得多的提议。朗之万动力学跟随梯度并注入噪声，

x^{(t+1)} = x^{(t)} − η ∇_x E_θ(x^{(t)}) + √(2η) ξ^{(t)}，ξ^{(t)} ∼ N(0, I)，　(25)

当 η → 0 时收敛到 p_θ。在有限步长下，更新是有偏的；使用公式25作为MH步骤的提议消除偏差，得到Metropolis调整的朗之万算法（MALA）[147]。在实践中，许多EBM学习方法运行未调整版本固定步数。

朗之万动力学在每次迭代中移动一个小的随机步，因此它像随机游走一样缓慢探索空间。哈密顿蒙特卡洛（HMC）[59, 130] 通过借用物理粒子的动力学避免这一点。它引入辅助动量 v ∈ ℝ^d 并定义哈密顿量

H(x, v) = E_θ(x) + (1/2)‖v‖₂²，　(26)

即势能 E_θ(x) 加动能。联合分布 p(x, v) ∝ exp(−H(x, v)) = p_θ(x) N(v; 0, I) 在 x 上有 p_θ 作为边缘分布，因此从联合采样并丢弃 v 就足够了。每个HMC迭代首先重采样动量 v ∼ N(0, I)，然后沿哈密顿方程移动 (x, v)，

dx/dt = v，dv/dt = −∇_x E_θ(x)。　(27)

粒子在滚下能量景观时加速，在攀爬时减速，而总能量 H 保持不变。因此它可以从起点移动到相似概率的状态。由于公式27不能精确求解，它用步长 ε 的蛙跳积分器模拟 L 步，

v ← v − (ε/2)∇_x E_θ(x)，x ← x + εv，v ← v − (ε/2)∇_x E_θ(x)。　(28)

蛙跳积分器是可逆的且保持体积，因此终点 (x′, v′) 可以用作MH提议，具有简单的接受概率 min{1, exp(H(x, v) − H(x′, v′))}，这修正离散化误差。因为蛙跳积分器几乎保持 H，即使对于遥远的提议，这个概率也保持接近一。HMC因此以每个样本更多的梯度评估（每次迭代 L 个）换取相关性小得多的样本。其性能取决于 ε 和 L：大的 ε 降低接受率，而选择不当的 L 浪费计算或使轨迹折返。No-U-Turn采样器 [91] 通过自适应设置 L 来平衡这种权衡。

在单个蛙跳步骤（L = 1）下，HMC简化为步长 η = ε²/2 的MALA。

上面的精确采样器，一般MH、吉布斯采样、MALA和HMC，都是MH算法的特殊情况；未调整的朗之万动力学不是，并且在有限步长下不能从 p_θ 精确采样。这些采样器对能量函数有不同的要求：一般MH和吉布斯采样只需要评估能量（或条件），因此适用于离散和结构化空间，而朗之万动力学和HMC需要梯度 ∇_x E_θ，因此需要连续输入和可微能量。

通过变分推理的摊销采样。 MCMC采样器为每个样本支付成本：每个新样本需要运行链许多步骤，连续样本是相关的。变分推理采取不同的路线：它拟合一个易于处理的分布 q_φ(x) 来近似EBM p_θ，因此之后抽取样本只需通过 q_φ 一次；推理的成本因此在所有样本上摊销。标准目标是最小化反向Kullback-Leibler散度，

min_{q_φ} KL(q_φ ∥ p_θ) = E_{x∼q_φ}[E_θ(x)] − H(q_φ) + log Z_θ，　(29)

其中 H(q_φ) = −E_{q_φ}[log q_φ(x)] 是 q_φ 的熵。由于 log Z_θ 不依赖于 φ，我们可以通过最小化 E_{q_φ}[E_θ(x)] − H(q_φ) 来拟合 q_φ，这从不评估难以处理的配分函数。第一项将样本拉向低能量区域，熵项保持它们分散而不是塌缩到单个最小值。因为KL散度是非负的，公式29还产生变分下界

log Z_θ ⩾ E_{x∼q_φ}[−E_θ(x)] + H(q_φ)，　(30)

当且仅当 q_φ = p_θ 时紧。因此，相同的优化提供采样器和 log-配分函数的估计，这也可以用于学习EBMs。

唯一剩下的部分是 q_φ 的参数化选择需要使采样和熵都易于处理。MRFs的经典选择是平均场近似 q_φ(x) = ∏i q{φ_i}(x_i)，它忽略变量之间的依赖 [185]。现代选择是神经采样器：归一化流 [146] 和自回归模型给出精确的 log-密度，因此精确的熵，变分自编码器 [104] 给出 log-密度的下界，隐式生成器 x = g_φ(z)（z ∼ N(0, I)）更灵活但需要估计熵 [101, 34, 36]。

为了优化变分目标公式29，我们可以利用随机梯度下降方法，这需要估计关于 φ 的梯度。困难在于 φ 出现在期望所取的分布中。有两种标准估计器。对于连续 x 和隐式或可重参数化的 q_φ，即 x = g_φ(z)，z ∼ N(0, I)，重参数化技巧 [104] 将 φ 移到期望内部，

∇_φ E_z[E_θ(g_φ(z))] = E_z[(∂g_φ(z)/∂φ)^⊤ ∇_x E_θ(g_φ(z))]，　(31)

这再次使用 ∇_x E_θ。对于离散 x，或每当 ∇_x E_θ 不可用时，我们使用REINFORCE或分数函数估计器 [190]。它依赖于恒等式 ∇_φ q_φ(x) = q_φ(x) ∇_φ log q_φ(x)，给出

∇φ E{x∼q_φ}[E_θ(x) + log q_φ(x)] = E_{x∼q_φ}[(E_θ(x) + log q_φ(x) − b) ∇_φ log q_φ(x)]，　(32)

其中左边正好是变分目标，即 E_{q_φ}[E_θ(x)] − H(q_φ)。log q_φ 在期望内的导数消失，因为 E_{q_φ}[∇_φ log q_φ(x)] = 0；出于同样的原因，任何常数基线 b 可以被减去而不引入偏差。REINFORCE只需要在样本处评估能量和 q_φ 的 log-密度，因此它适用于任何 x，包括离散和结构化输出。其代价是高方差，因为它只使用能量的值而不是其梯度。因此，在实践中，基线 b（例如，批次中其他样本上 E_θ(x) + log q_φ(x) 的平均值）或其他控制变量是必要的。简而言之，两个估计器以方差换通用性：重参数化估计器公式31使用能量梯度，通常方差低得多，但需要连续 x、可微 E_θ 和可重参数化的 q_φ；REINFORCE公式32只需要能量值和 log q_φ，因此适用于离散或不可微设置，代价是更高的方差。当两者都适用时，通常首选重参数化估计器。

与MCMC相比，变分推理在采样时快速但有偏：误差受限于 q_φ 的家族，反向KL公式29是模式寻求的，因此 q_φ 倾向于错过 p_θ 的一些模式。两者可以结合 [36]：学习的 q_φ 可以为短MCMC链提供初始化，或在MH步骤中充当提议，其接受概率公式24然后修正 q_φ 的偏差。

预测。 除了抽取样本，我们可以使用EBM在给定输入 x 时进行预测。对于条件模型

p_θ(y|x) = exp(−E_θ(x, y)) / Z_θ(x)，　(33)

最大后验（MAP）预测是

ŷ_MAP ∈ arg max_y p_θ(y|x) = arg min_y E_θ(x, y)。　(34)

配分函数依赖于 x 但不依赖于候选输出 y，因此比较预测不需要它。更一般地，能量最小化定义预测规则，即使能量不诱导可归一化的概率分布，只要最小值存在。概率解释额外要求 0 < Z_θ(x) < ∞。

找到预测所需的计算取决于能量和输出空间。对于一小组离散标签，我们可以评估每个候选并选择能量最低的那个。对于连续输出和可微能量，我们可以通过梯度下降迭代更新候选，

y^{(t+1)} = y^{(t)} − η_t ∇_y E_θ(x, y^{(t)})，　(35)

其中 η_t 是步长。对于结构化离散输出，我们需要使用组合搜索或其他近似最小化方法。总的来说，对于一般非凸能量，这些最小化程序可能找不到全局最小值，使得初始化显著影响最终预测。

标准前馈预测是最小值直接可用的特殊情况。考虑二次能量

E_θ(x, y) = (1/2σ²)‖y − f_θ(x)‖₂²，σ > 0。　(36)

其唯一的最小化子是 ŷ = f_θ(x)，可以通过一次网络评估计算。相比之下，一般能量 E_θ(x, y) 不需要具有这种二次形式，可以表达输出变量之间的多个复杂依赖关系。

2.5 EBMs的学习

学习EBM意味着拟合能量 E_θ，使 p_θ(x) ∝ exp(−E_θ(x)) 匹配数据分布。障碍再次是配分函数：Z_θ 依赖于 θ，因此似然及其梯度不能直接计算。EBMs的学习方法主要在如何避免或近似 Z_θ 上不同，我们将在下面讨论。

最大似然估计。 给定数据集 D = {X}，学习能量函数 E_θ(x) 最直接的方法是通过最大似然估计（MLE）。我们可以直接拟合概率密度 p_θ(x) ∝ exp(−E_θ(x)) 以最大化从数据集 D 抽取的样本的 log-似然，即最小化负 log-似然。

公式1中定义的 E_θ(x) 的似然的完整形式是 exp(−E_θ(x))/Z，其中 Z 是配分函数。负 log-似然损失目标由

L_NLL(D) = E_{x∼D}[−log(p_θ(x))]，　(37)

给出，可以等价地写为

L_NLL(D) = E_{x∼D}[E_θ(x)] + log(∫ exp(−E_θ(x)) dx)。　(38)

取上述目标的梯度，我们得到表达式

∇θ L_NLL(D) = E{x∼D}[∇_θ E_θ(x)] − ∫ exp(−E_θ(x)) ∇_θ E_θ(x) dx / ∫ exp(−E_θ(x)) dx，　(39)

我们可以将右边简化为期望

∇θ L_NLL(D) = E{x∼D}[∇θ E_θ(x)] − E{x∼p_θ(x)}[∇_θ E_θ(x)]。　(40)

使用上述表达式，L_NLL 的梯度可以从代理损失等价计算

L̃NLL(D) = E{x∼D}[E_θ(x)] − E_{x∼stopgrad(p_θ(x))}[E_θ(x)]，　(41)

这给了我们通过最大似然估计训练 E_θ(x) 的简单目标，其中我们对比地降低真实数据样本的能量，同时提高从模型分布 x ∼ p_θ(x) 抽取的样本的能量。然而，在实践中，从分布 p_θ(x) 抽取样本可能具有挑战性——第2.4节讨论了几种抽取这些样本的方法。特别是，在原始的对比散度中，这些负样本从真实数据初始化 [87]，而也可以从随机噪声或近似分布初始化样本并使用朗之万动力学抽取负样本来训练EBM [55, 36]。

噪声对比估计。 最大似然在每个梯度步骤中需要来自模型 p_θ 的样本，这是它昂贵的原因。噪声对比估计（NCE）[81] 通过将学习问题重新表述为数据与噪声之间的分类来避免这一点，从分类器中可以恢复能量函数。具体地，通过表述二元分类和多类分类问题，我们获得NCE的两种变体。

二元NCE。 原始表述 [81] 提出数据与噪声之间的二元分类。它将 log-配分函数视为额外的标量参数 c，因此模型的归一化 log-密度是

log p_{θ,c}(x) = −E_θ(x) − c。　(42)

假设每个数据点带有 ν 个噪声样本，因此样本先验地是噪声的可能性大 ν 倍。由贝叶斯规则，样本 x 是数据而不是噪声的概率是

P(y=1|x) = p_{θ,c}(x) / (p_{θ,c}(x) + ν p_n(x)) = sigm(h_{θ,c}(x))，h_{θ,c}(x) = −E_θ(x) − log p_n(x)（非归一化对噪声的log-比率）+ (−c − log ν)（偏置 b），　(43)

其中 sigm 是逻辑函数。后验因此是模型对噪声的 log-密度比的sigmoid，加上偏置项 b = −c − log ν，这意味着我们可以从分类器 P(y=1|x) 恢复EBM参数。

我们得到二元NCE，它通过逻辑回归拟合 (θ, c)，即最小化交叉熵，

L_NCE^bin(θ, c) = −E_{x∼p_d}[log sigm(h_{θ,c}(x))] − ν E_{x∼p_n}[log(1 − sigm(h_{θ,c}(x)))]，　(44)

关于 θ 的梯度为

∇θ L_NCE^bin = E{x∼p_d}[(1 − sigm(h_{θ,c}(x))) ∇θ E_θ(x)] − ν E{x∼p_n}[sigm(h_{θ,c}(x)) ∇_θ E_θ(x)]。　(45)

我们强调，公式45中的负样本现在来自 p_n 而不是 p_θ，因此不需要MCMC。如果模型家族包含 p_d，最小化子满足 p_{θ,c} = p_d，因此估计器是一致的 [81]，学习的常数恢复 log-配分函数，c* = log Z_θ = log ∫ exp(−E_θ(x)) dx。二元NCE因此学习能量及其归一化子，这允许之后评估新样本的似然。

排序NCE。 第二种形式提出多类问题 [124]：给定隐藏在 K 个噪声样本 x₁, …, x_K ∼ p_n 中的一个数据点 x₀ ∼ p_d，模型必须识别 K+1 个样本中哪一个是真实的。为了看到这个概率是什么，设 i ∈ {0, …, K} 是数据点的未知位置，具有均匀先验。如果数据从模型 p_θ 抽取，K+1 个样本在给定 i 时具有联合密度 p_θ(x_i) ∏_{j≠i} p_n(x_j)。由贝叶斯规则，位置上的后验是

P(i | x_{0:K}) = p_θ(x_i) ∏{j≠i} p_n(x_j) / ∑{l=0}^{K} p_θ(x_l) ∏{j≠l} p_n(x_j) = (p_θ(x_i)/p_n(x_i)) / ∑{l=0}^{K} (p_θ(x_l)/p_n(x_l)) = (exp(−E_θ(x_i))/p_n(x_i)) / ∑_{l=0}^{K} (exp(−E_θ(x_l))/p_n(x_l))，　(46)

其中第二个等式将分子和分母除以 ∏_{j=0}^{K} p_n(x_j)，第三个代入 p_θ = exp(−E_θ)/Z_θ，因此 Z_θ 抵消。这是对具有logits −E_θ(x_k) − log p_n(x_k) 的样本的softmax。排序NCE最大化识别数据点的概率，i = 0，即它最小化负 log-概率，

L_NCE^rank(θ) = −E[log (exp(−E_θ(x₀))/p_n(x₀)) / ∑_{k=0}^{K} (exp(−E_θ(x_k))/p_n(x_k))]。　(47)

由于能量中的任何常数出现在分子和分母中，配分函数抵消：排序NCE只学习 E_θ，没有参数 c。其梯度，

∇θ L_NCE^rank = E[∇_θ E_θ(x₀) − ∑{k=0}^{K} w_k ∇θ E_θ(x_k)]，w_k = (exp(−E_θ(x_k))/p_n(x_k)) / ∑{j=0}^{K} (exp(−E_θ(x_j))/p_n(x_j))，　(48)

再次是最大似然梯度，p_θ 下的期望被使用 p_n 作为提议的自归一化重要性采样估计替代。排序NCE也是一致的，它对条件模型 p_θ(y|x) 特别方便，其中配分函数 Z_θ(x) 对每个输入不同，二元NCE需要为每个 x 单独的常数 [124]。代价是它不恢复 Z_θ，如果需要归一化似然，必须单独估计，例如通过重要性采样。

选择噪声。 两种形式都严重依赖噪声分布。p_n 必须在 p_d 为正的地方为正，它应该接近 p_d：如果噪声容易与数据区分，分类器成功而不学习太多关于数据的知识，梯度携带很少信息。更大的 ν 或 K 使两个估计器更接近最大似然，代价是每个数据点更多的噪声样本。

伪似然估计。 给定变量 x = {x₁, x₂, …, x_d} 上的非归一化EBM E_θ(x)，在伪似然估计 [21] 中，我们将伪似然定义为

PL(θ; x) = ∏{j=1}^{d} p_θ(x_j | x{−j})。　(49)

我们训练估计器的目标然后是负 log-伪似然

L_PL(θ) = −∑{i=1}^{N} ∑{j=1}^{d} log p_θ(x_j^{(i)} | x_{−j}^{(i)})。　(50)

公式50中的目标比公式37容易优化得多，因为我们可以以封闭形式计算 p_θ(x_j^{(i)} | x_{−j}^{(i)})，为

p(x_j = k | x_{−j}) = p(x_j = k, x_{−j}) / ∑{v∈V} p(x_j = v, x{−j}) = exp(−E(x_j = k, x_{−j})) / ∑{v∈V} exp(−E(x_j = v, x{−j}))，

可以通过枚举 x_j 的词汇表大小 V 来计算。

一般来说，伪似然是整体分布 p(x) 的一致估计器，只要分布在每个数据点 x 处为正 [21, 95]。然而，与其他训练EBMs的方法相比，伪似然关注变量之间的局部交互。当拟合多个变量之间存在全局交互的分布时，这可能使方法数据效率低下。

与掩码离散扩散的联系。 伪似然与掩码或吸收态离散扩散模型 [9, 150, 157] 密切相关。两者都被训练以从可见变量预测隐藏变量。伪似然隐藏恰好一个变量 x_j 并拟合 p_θ(x_j | x_{−j})。掩码扩散隐藏变量的随机子集 M，其大小范围从一个变量到所有变量，并为每个 j ∈ M 拟合 p_θ(x_j | x_{−M})。使用线性噪声调度，其训练目标是这种掩码预测损失在掩码比率上的加权平均，

L_MD(θ) = E_{t∼U[0,1]}[(1/t) E_{M∼q_t}[−∑{j∈M} log p_θ(x_j | x{−M})]]，　(51)

其中 q_t 以概率 t 独立隐藏每个变量。伪似然公式50是一次只隐藏一个变量的特殊情况。在连续时间中联系更紧密：离散扩散模型的分数可以通过单变量条件 p_t(x_j | x_{−j}) 写出，正是伪似然拟合的量，它可以通过建立在它们之上的分类比率匹配目标学习 [165]。

差异对每个目标学习什么很重要。由链式法则，对于变量的任何排序 π，log p(x) = ∑{k=1}^{d} log p(x{π(k)} | x_{π(<k)})。掩码扩散目标公式51等价于在随机排序上平均这个分解 [178, 92, 136]，因此它是负 log-似然的上界。伪似然只保留每个排序的最后一项，k = d，其中每个其他变量都是可见的。因此它不是似然的界，它从不训练模型预测邻居也未知的变量，这就是为什么它难以处理上述全局交互。在这个意义上，掩码扩散将伪似然从一个掩码级别扩展到所有级别。

两者在另一个方面也不同。在EBM中，每个条件从单个能量函数导出，因此条件总是与一个联合分布一致。掩码扩散模型通常直接用神经网络参数化条件，学习的条件不需要与任何联合分布一致。两者的采样也不同：吉布斯采样一次从伪似然条件重采样一个变量并持续循环，而掩码扩散从每个变量隐藏开始并逐渐揭示它们直到没有剩余。

分数匹配。 分数匹配 [94] 通过拟合 log-密度的梯度而不是密度本身来避免配分函数。对于连续 x，这个梯度是分数，

∇_x log p_θ(x) = −∇_x E_θ(x) − ∇_x log Z_θ = −∇_x E_θ(x)，　(52)

Z_θ 消失，因为它不依赖于 x。分数匹配通过最小化模型分数与数据分数的期望平方距离（Fisher散度）来拟合模型分数，

L_ESM(θ) = (1/2) E_{x∼p_d}[‖∇_x log p_θ(x) − ∇_x log p_d(x)‖₂²]。　(53)

数据分数 ∇_x log p_d 是未知的，但Hyvärinen [94] 通过分部积分表明，在温和的光滑性和边界条件下，公式53等于（相差不依赖于 θ 的常数）

L_SM(θ) = E_{x∼p_d}[(1/2)‖∇_x E_θ(x)‖₂² − tr(∇_x² E_θ(x))]，　(54)

只涉及能量和数据。像NCE一样，分数匹配不需要来自模型的样本；与NCE不同，它也不需要噪声分布。当模型家族包含 p_d 时它是一致的 [94]。

可扩展的变体。 公式54中Hessian的迹需要 d 次反向传播，在高维中昂贵。切片分数匹配 [162] 将分数投影到随机方向 v 上，用 v^⊤ ∇_x² E_θ(x) v 替换迹，这需要单个Hessian-向量乘积。去噪分数匹配 [183] 完全移除二阶导数。它向数据添加高斯噪声，x̃ = x + σε，ε ∼ N(0, I)，并将 x̃ 处的模型分数匹配到噪声核的分数，它是封闭形式已知的，

L_DSM(θ) = (1/2) E_{x∼p_d, ε}[‖−∇_{x̃} E_θ(x̃) + (x̃ − x)/σ²‖₂²]。　(55)

其最小化子是噪声数据分布的分数而不是 p_d 本身的分数，当 σ → 0 时接近数据分数。在一系列噪声水平上训练（从大到小），得到基于分数的扩散模型背后的噪声条件分数模型 [161, 163]，可以读取为在每个噪声水平学习能量并用退火朗之万动力学公式25采样的EBMs。

局限性。 因为分数是局部量，分数匹配只通过密度在那里如何变化来看到空间的每个区域。在数据稀少的地方，如分离模式之间的低密度区域，学习的分数不准确，从中进行朗之万采样在模式之间混合不良 [161]；去噪分数匹配中的噪声通过填充这些区域来帮助。分数匹配还需要连续 x 和可微能量。对于离散数据，比率匹配 [96] 通过匹配在单个变量上不同的状态之间的比率 p_θ(x′)/p_θ(x) 发挥相同的作用，其中 Z_θ 再次抵消。这些比率由单变量条件 p_θ(x_j | x_{−j}) 确定，这将离散数据的分数匹配与伪似然以及离散扩散中使用的分类比率匹配联系起来 [165]。

对抗训练。 对抗训练从最大似然开始，用第2.4节的变分界移除配分函数。负 log-似然公式38包含 log Z_θ，由公式30，log Z_θ 本身是分布上优化问题的解，

log Z_θ = max_q E_{x∼q}[−E_θ(x)] + H(q)，　(56)

其中最大值在 q = p_θ 处取得。将公式56代入公式38将最大似然转变为最小-最大问题，

min_θ L_NLL(θ) = min_θ max_q E_{x∼p_d}[E_θ(x)] − E_{x∼q}[E_θ(x)] + H(q)。　(57)

两个玩家有明确的角色。对于固定能量，关于 q 的内部最大化正好是变分推理问题公式29：它通过最小化 KL(q ∥ p_θ) 将 q 拟合到 p_θ，因此 q 成为当前EBM的摊销采样器。对于固定的 q，外目标关于 θ 的梯度是

E_{x∼p_d}[∇θ E_θ(x)] − E{x∼q}[∇_θ E_θ(x)]，　(58)

这是最大似然梯度公式40，来自 p_θ 的样本被来自 q 的样本替代。能量因此在数据上降低自身，在采样器输出上提高自身，而采样器将其样本移向低能量并通过熵项保持它们分散。训练期间不运行MCMC；而是学习采样器。

这是生成对抗网络 [77] 的结构：能量扮演判别器，q 扮演生成器。区别是熵项 H(q)。没有它，内部最大化会将 q 的所有质量放在能量的最小值处，这是GANs中熟悉的模式崩溃，游戏不再对应最大似然。有了它，公式57的解是最大似然估计，学习的生成器是学习EBM的采样器 [101, 39]。

熵也是使该方法在实践中困难的原因。它只对受限的 q 家族（如归一化流 [146]）容易计算。对于灵活的隐式生成器 x = g_φ(z)，它必须被估计或有界，不同的估计导致不同的算法 [101, 39]。一种替代方案通过几步可学习采样动力学定义 q，例如从简单分布开始的朗之万或哈密顿更新，其熵可以通过动力学跟踪 [36]；公式57的对偶视图也扩展到核指数族 [34]。第二个困难是，对于固定的 q，公式57中的目标只是负 log-似然的下界，因为 q 只下界 log Z_θ。如果 q 落后于当前能量，关于 θ 的最小化降低界而不是似然。在实践中，θ 和 q 交替更新，学习EBM的质量取决于 q 跟踪 p_θ 的紧密程度。

回归训练。 能量函数也可以通过监督能量最小化的输出或更新的回归目标学习。监督不需要指定标量能量值：它可以描述优化应该到达哪里或候选应该如何移动 [38]。IREM和平衡匹配说明了这两种方法。

回归优化预测。 通过能量最小化的迭代推理（IREM）[52] 通过监督最小化后获得的预测来学习条件能量 E_θ(x, y)。给定配对的输入和解决方案，初始化 ŷ^{(0)} 并执行 K 次更新，

ŷ^{(k+1)} = ŷ^{(k)} − η ∇_y E_θ(x, ŷ^{(k)})。　(59)

回归目标是

L_IREM(θ) = E_{(x,y)∼D, ŷ^{(0)}}[‖ŷ^{(K)} − y‖₂²]。　(60)

训练通过优化进行微分以塑造能量景观。在实践中，IREM将反向传播截断到最终更新，并使用优化候选的回放缓冲区以及随机初始化。回归目标是优化到达的解决方案，而不是分配给该解决方案的能量。在推理时，学习的能量可以优化不同数量的步骤，尽管仅有限步训练不保证更长的优化改善预测。

回归更新场。 平衡匹配 [186] 而是监督损坏数据点处的时间无关场。给定数据 x、高斯噪声 ε 和 γ ∼ U[0,1]，设

x_γ = (1 − γ)x + γε。　(61)

EqM将 f_θ 回归到 (ε − x)c(γ)，c(0) = 0。其显式能量变体EqM-E设置 f_θ = ∇E_θ 并最小化

L_EqM-E(θ) = E_{x,ε,γ}[‖∇_{x_γ} E_θ(x_γ) − (ε − x)c(γ)‖₂²]。
