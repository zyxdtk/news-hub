人们正用 AI 让智能电视重新变“笨”

📅 2026-10-17 📄 TechCrunch AI 🔗 原文链接

原标题：People are using AI to make their smart TVs dumb again

中文摘要： 随着 AI 编程工具普及，越来越多用户利用 Claude Code 等智能体“氛围编程”破解智能电视，删除广告、臃肿软件与观看追踪，让电视回归纯粹的观看体验。dumbtv、cleanyourtv 等开源项目应运而生，已支持小米、索尼、TCL 等多品牌电视。但此类操作存在风险，有用户甚至将电视刷成“砖”。若担心风险，可选用 ATV Launcher 等现成替代方案。

其中一个名为“dumbtv”的解决方案在其 GitHub 页面上如此描述其使命：“你的电视应该只做你为之付费的事情：你的应用、你的 HDMI 输入，仅此而已。没有电视自带的广告，没有观看追踪，没有你未曾要求的更新。”

另一个名为“cleanyourtv”的工具则承诺，可通过 Wi-Fi 清除任何 Android TV 或 Google TV 上的臃肿软件，并将启动器替换为类似 Apple TV 风格的界面。

虽然通过破解消费电子设备来获得对系统的更多控制权并非什么新鲜事，但 AI 技术的最新进展让任何人都更容易开展这类尝试。就智能电视而言，这些破解手段出现的时机，正值人们对被迫观看广告、忍受设备监视自己的观看习惯感到日益不满之际。

现代智能电视出厂时均配备一项名为自动内容识别（ACR）的技术，该技术通过截屏、音频片段或其他形式的数字指纹来识别屏幕上正在播放的内容。

如果这些“傻瓜电视”破解方法在普通消费者中流行开来，它们有可能颠覆智能电视广告行业——该行业通过向广告商出售观看数据，或利用这些数据在自己的界面上投放个性化广告来获利。

正如 cleanyourtv 的创建者 Gathin T. 所说，清理智能电视界面的想法始于某个下午，当时他厌倦了父母电视上没完没了的广告。

今天下午给我父母的电视来了次“氛围编程”（vibe coding）！
以前你甚至还没打开 Netflix，它就先给你放一条赞助广告。
我把型号告诉了 Claude Code，它在 Wi-Fi 上找到了这台电视，删除了 25 个小米软件包，还写了一个新启动器。

“我让 Claude Code 通过 Wi-Fi 清理了电视，并构建了一个只包含他们自己应用的简单主屏幕。我把提示词放到了 GitHub 上，在推特上发布了前后对比，接下来的两天里，几千人对自己的电视做了同样的事情。小米、TCL、索尼、Fire TV、LG，还有一两台投影仪，”这位开发者在项目主页所链接的一个捐赠网站上写道。

该解决方案无需获取电视的 root 权限，而且如果需要，也不会导致无法恢复出厂设置。

与此同时，dumbtv 解决方案已在 Fire TV Edition 电视机以及索尼、TCL、飞利浦、海信、小米和 Shield 等品牌电视的 Android/Google TV 平台上完成了端到端测试。开发者 Muzzammil Yasin Sabuwala 建议，使用这一破解方法时，只需将你喜欢的 AI 智能体指向 GitHub 上的 dumbtv 代码仓库即可。

Sabuwala 表示，他开发 dumbtv 的动力来自于对广告的厌倦，以及无法直接进入自己想看的内容的沮丧。他告诉 TechCrunch，他的解决方案是结合使用 Deepseek V4.1 Flash、Claude Opus 5.5 和 Claude Sonnet 5.5 编写的，他计划继续维护这个 GitHub 仓库，并逐步增加对更多机型的支持。

友情提醒：所有这些解决方案都仍在开发完善中，目前已有众多用户在不同的电视平台上进行测试，并提出更新和修复建议。

不过，个人也无需借用他人在 GitHub 上的现成成果来完成这项工作。

在一条新近走红的 X 帖子中，Ryan Doyle 解释说，他只是把自己电视的产品页面发给了 Claude Code，并问了一句“你能破解它吗？”他声称，该智能体随后一步步引导他完成了整个过程，使他得以删除电视上的广告和臃肿软件，加快卡顿的用户界面，并自定义了屏幕保护程序。

随后，Doyle 还在一段视频中演示了 AI 完成所要求的更改后，新界面的运行速度和响应有多快。

看到人们“氛围编程自己电视”的帖子，X 用户 Mihir Gupta 受到启发，决定亲自尝试。

“用 Claude Code 折腾了一个下午：禁用了 25 个臃肿应用，把 192 MB 的原装启动器换成了 83 MB 的自定义启动器，还加上了轮换壁纸，”他写道。

然而，这些破解的最终效果可能参差不齐。

有些人发现，Claude 对他们“破解我的电视”这样简单的指令毫无反应，需要更复杂的提示词。还有人警告说，AI 智能体可能会犯错，在此过程中可能禁用重要的软件包或造成损坏。甚至有人说自己用 Claude 把 Android TV 刷成了“砖”，还有人在破解 Fire TV 时卡在了半路。

对于那些对用 AI 全面破解电视心存顾虑的人，市面上已有一些自定义基于 Android 的智能电视的现成方案，例如主屏幕替换应用 ATV Launcher、Projectivy Launcher 和 FLauncher。
