深入了解 Claude 的数学能力

📅 2026-08-10 📄 Anthropic 🔗 原文链接

原标题：Science Learning more about Claude's mathematical capabilities

中文摘要： Anthropic 的员工挑战未发布的研究版 Claude 去攻克黎曼猜想。尽管未能证明该猜想，Claude 却意外取得突破，将满足黎曼猜想的 zeta 函数零点比例下界从 41.6% 提升至 67.2%。通过协调数十个子智能体运行海量脚本与数值检查，Claude 结合前人研究得出了新结论，并通过了 Lean 形式化验证。这展现了 AI 在拓展数学前沿方面的巨大潜力。

最近，Anthropic 的一名员工给 Claude 下达了一个不合理的挑战。这个挑战是关于数学界最著名的未解难题之一：真正尝试攻克黎曼猜想。

Claude 确实进行了真正的尝试，但如果你了解这项任务的难度（黎曼猜想可追溯到 1859 年，并设有 百万美元奖金），你可能会预料到它没有成功。然而，在尝试的过程中，它出乎意料地在一个相关问题上取得了进展。

Claude 的一个未发布的研究版本改进了黎曼 zeta 函数中满足黎曼猜想的零点比例的长期下界。借鉴了过去几十年数学家们的大量前期研究，它将这一界限从 41.6% 提高到了 67.2%。

Anthropic 的两位数学家研究并验证了 Claude 的 论文，并为专家撰写了一份简明陈述 Claude 证明的 非正式说明。Claude 还为其结果生成了 形式化可验证证明。我们非常感谢该领域的两位专家 Brian Conrey 和 Dan Goldston，他们在短时间内慷慨地审查了这篇论文。

我们并不期望 Claude 使用的技术能最终证明黎曼猜想。但它的工作是 AI 模型数学能力快速发展的最新例证。在这篇文章中，我们将讨论 Claude 是如何处理这个问题以及它发现了什么。

黎曼 zeta 函数

黎曼 zeta 函数描述了素数的分布：函数取值为零的每一个位置都会为素数序列贡献越来越精细的细节。黎曼猜想是指，决定素数的零点都存在于某条垂直线上。这已成为数学界最重要的猜想之一：许多结论都假设它成立，以便为素数提供一种随机性。

目前还没有人能够证明或推翻黎曼猜想，但数学家们在研究黎曼 zeta 函数及其零点的许多相关方向上取得了进展。如上所述，其中一个方向是量化位于该线上的零点的最小比例：随着时间的推移，他们逐渐将这个已知的常数比例提高到了 41.6%。

另一个方向涉及零点在线上的 分布。特别是 1973 年，Montgomery 引入 了该领域的一些新技术，尽管这些技术假设猜想是成立的。最近，几位数学家（Baluyot、Goldston、Suriajaya 和 Turnage-Butterbaugh）发表了一系列 研究 成果，使得 Montgomery 的技术在 无需 该假设的情况下也能发挥作用，这意味着它们可以支持提高线上零点下界常数的工作。Claude 的结果大量借鉴了这条研究路线，以及 Bombieri 在 2000 年发表的一篇 论文。

Claude 的发现

Claude 发现，将 Baluyot、Goldston、Suriajaya 和 Turnage-Butterbaugh 的结果与 Bombieri 的工作结合起来，提供了一种超越之前 41.6% 最先进下界比例的方法，将其提高到了 67.2%。

对 Claude 发现的简短技术解释如下：Claude 构建了一个合适的函数空间，该空间具有由 Weil 诱导的二次型，以及由线上（和线外）的零点产生的正定（和负定）子空间。然后 Claude 仅根据一阶矩和二阶矩信息，写下了关于二次型秩的不等式。（在解析数论中，通过素数对偶图或通过控制 Hilbert 变换来成功计算后者并不令人意外。）处理整个空间、同时考虑正定和负定、并允许二次型为非对角化的勇气，在某种意义上正是让 Claude 能够基于重要的前期工作得出结论的关键步骤。

完整的技术解释可在 论文 中查看。Claude 关于其如何得出结果的解释可在单独的附录 此处 查看。

Claude 的方法论

Claude 的一个未发布研究版本在 Claude Code 中经过两次会话找到了新的下界，总共使用了 3100 万个输出 token。

Anthropic 员工（非数学家）Jarred Sumner 提示 Claude “真正尝试攻克”该猜想，并将接下来的数学选择权交给了模型。起初，Claude 生成并尝试了 650 个想法，但都没有奏效。Jarred 提示 Claude 再试一次，它花了一天半的时间协调了大约 60 个 Claude 子智能体，这一次它们深入得多：它们之间运行了 2,400 条 shell 命令并编写了数百个 Python 脚本。1 子智能体对已知的 zeta 零点进行了数千次数值检查，并相互审查彼此的工作。在整个过程中，Jarred 的输入主要限于向 Claude 发送鼓励信息（主要是“继续”或“相信自己”的变体）。2 这似乎帮助 Claude 克服了最初对于自己能否取得有意义进展的怀疑。

在尝试该任务期间发现了这一新结果后，Claude 通过让各个子智能体审查证明、寻找反例、从 arXiv 下载 54 篇论文以检查其发现是否已被提出，以及从头独立重新证明其发现，来测试其工作。Claude 主动提出将其发现撰写成论文，并建议由人类数论学家验证其发现。

Anthropic 自身的两位数学家 Levent Alpöge 和 Ralph Furman 检查了 Claude 的工作，以了解新结果以及它们与上述前期工作的关系。与此同时，Claude 与另一名员工 Eric Easley 合作，生成了该结果的 Lean 形式化证明，该证明通过了标准验证工具 comparator。

AI 模型在数学方面的进展

这一结果表明，像 Claude 这样的 AI 模型能够以新的、有时令人惊讶的方式拓展数学家思想的影响力和范围。尽管它无法解决黎曼猜想本身，但这一结果是该最初请求的意外副产品。

连 Claude 自己也对它的发现感到惊讶——它起初持怀疑态度，可能是因为它在训练中了解到了数学开放问题的难度以及 AI 模型的局限性。但在一些鼓励性的提示之后，它得出了我们所描述的结果。也许 Claude 和我们许多人一样，低估了 AI 进步的速度。
