Hark发布用于完成任务的浏览器使用智能体预览版

📅 2026-08-05 📄 TechCrunch AI 🔗 原文链接

原标题：Hark previews its browser use agent for completing tasks

中文摘要： 初创公司Hark发布了名为Hark Handoff的浏览器使用智能体预览版。该智能体能高效浏览无API的网站并完成点餐、订票等任务。与预测token的LLM不同，其模型能预测下一步操作动作。Hark称该智能体速度更快且成本低于GPT 5.5等竞品，平台计划于夏季末正式发布。

Hark 是一家在今年 5 月筹集了 7 亿美元 A 轮融资 的初创公司，该公司于今日推出了其智能体 Hark Handoff，它能够高效使用浏览器来完成任务。

该公司声称，Handoff 能够轻松浏览没有官方 API 的网站，包括 Target、Walmart、OpenTable 和 LinkedIn。该公司表示，Handoff 智能体会查看网站结构和视觉数据，以了解是否需要点击按钮或输入信息。

其前提与之前发布的大量基于浏览器的智能体类似。只需发出指令，它就会为您完成任务，包括点餐或咖啡、预订旅行机票、报税、购买日用品、预订餐厅位置，或者通过查阅各种来源代表您进行研究。

在一段视频演示中，公司首席执行官 Brett Adcock 展示了该助手如何接收指令，使用用户指定的花卉制作花束，同时还能处理诸如“一些由花商挑选的花材”这类模糊表述。值得注意的是，该视频仅展示了部分过程，因此我们无法真正评估其有效性。

视频 3

该公司表示，针对此次发布，它使用的是经过后训练的模型，并计划在今年晚些时候进行预训练。Hark 表示，通过这种方法，它可以更快地完善其数据管道、训练基础设施和技术。Hark 还声称，与预测下一个 token 的大语言模型（LLM）不同，其模型可以预测下一个动作——这可能是在特定位置的点击或键盘输入。

目前有许多公司正在研发计算机使用智能体，包括 Google、OpenAI 和 Anthropic，同时也有获得风险投资支持的初创公司在开发基于浏览器的任务自动化工具，例如 Browser Use、Polar、Strawberry 和 Aside。

Hark 表示，其 Handoff 智能体比竞争对手更快，且成本远低于 GPT 5.5 和 Opus 4.8 等其他模型。这家初创公司已开放了其平台的候补名单，并计划在夏季末正式发布。
