Z.ai发布ZCode，挑战Cursor等A...

📅 2026-07-07 📄 VentureBeat AI 🔗 原文链接

原标题：Z.ai launches ZCode to challenge Cursor, Claude Code and GitHub Copilot in AI coding

中文摘要： Z.ai（智谱AI）发布免费桌面应用ZCode，作为GLM-5.2模型的智能体开发环境，直接挑战Cursor和Claude Code等工具。ZCode具备跨设备远程控制等差异化功能，且订阅价格大幅低于西方竞品。GLM-5.2完全基于中国芯片训练，性能接近顶尖专有模型。在美国对Anthropic实施出口管制引发企业对地缘政治风险担忧的背景下，ZCode凭借开源、可自托管等特性，为全球开发者提供了极具竞争力的替代方案。

总部位于北京的人工智能实验室[Z.ai](http://z.ai/)（前身为智谱AI）于周三正式推出了[ZCode](https://zcode.z.ai/)，这是一款免费的桌面应用程序，被其描述为专为其旗舰[GLM-5.2](https://z.ai/blog/glm-5.2)大语言模型量身定制的“智能体开发环境”。此举标志着该公司向快速增长的AI驱动编程工具市场发起了迄今为止最猛烈的冲击，目前它在该市场直接与[Cursor](https://cursor.com/get-started)、[Claude Code](https://www.anthropic.com/product/claude-code)、[GitHub Copilot](https://github.com/features/copilot)以及[Google的Antigravity](https://antigravity.google/)展开竞争。

“推出ZCode，GLM-5.2的官方开发环境，”该公司在X上写道，并指出该工具可在macOS、Windows和Linux上使用，支持第三方模型的自带密钥（BYOK）配置，并为其GLM Coding Plan订阅者提供1.5倍的使用配额奖励。

从一方面看，[ZCode](https://zcode.z.ai/)只是拥挤市场中的又一个新入局者。从另一方面看，它是一款将当今企业软件领域三个最重要趋势具体化的单一产品：前沿AI模型的价格战、AI技术栈的地缘政治巴尔干化，以及智能体编程工具的快速成熟——Gartner目前估计这已是一个[约100亿美元的市场](https://enterprisedna.co/resources/news/gartner-enterprise-ai-coding-agents-10-billion-market-2026/)。

## **一款以项目而非提示词为思考维度的AI编程工具**

与通过聊天侧边栏或自动补全扩展硬塞入AI的传统IDE不同，[ZCode](https://zcode.z.ai/)最好被理解为一个智能体优先的开发环境。其核心设计围绕长周期任务构建：用户描述一个预期结果，智能体规划工作、编辑文件、运行检查、审查进度，并跨越多次迭代继续工作，直到目标达成。

[ZCode](https://zcode.z.ai/)围绕[ZCode Agent](https://zcode.z.ai/en)组织开发体验，该智能体针对[GLM-5.2](https://z.ai/blog/glm-5.2)进行了深度调优，并强调深度集成：模型、工具和执行工作流共同调优，使Agent能够适应持续的、多步骤的实际开发任务。该环境支持跨设备的持续跟进：桌面端、移动端Remote以及飞书/微信Bot都可以保持同一个工作区任务继续推进。敏感命令、文件更改和高权限操作在执行前都需要经过确认。

这种远程控制功能——在手机上通过[微信](https://www.wechat.com/en)、[飞书](https://baike.baidu.com/en/item/Feishu/14594)或[Telegram](https://web.telegram.org/)操控正在运行的编程智能体——是一个直接针对中国开发者市场的差异化优势，因为这些通讯平台主导着中国的职场沟通。在长时间运行的工作继续进行时，你可以通过任何装有这些通讯应用的设备不断检查进度并添加指令。

该工具可免费下载。收入通过Z.ai的[GLM Coding Plan订阅层级](https://z.ai/subscribe)实现，“Lite”计划起价为每月16.20美元，“Max”计划最高为每月144美元——这些价格以大幅优势低于Anthropic的Claude Code和Cursor的同类订阅层级。

在7月31日之前，[ZCode](https://zcode.z.ai/)为Coding Plan订阅者提供1.5倍有效配额的促销奖励，非高峰时段的token消耗按0.67的系数收费。该平台还支持多种AI模型和智能体，包括Claude Code、Codex、Gemini和OpenCode——这是对没有单一模型能在所有任务中胜出这一现实的务实让步。

## **GLM-5.2：完全基于中国芯片训练的开源模型，驱动整个体验**

ZCode的价值主张与其旨在展示的[GLM-5.2](https://z.ai/blog/glm-5.2)模型密不可分。Z.ai于6月16日发布了GLM-5.2，首先面向其Coding Plan订阅者，随后在[Hugging Face](https://huggingface.co/zai-org/GLM-5)上以MIT许可证开源了模型权重——这一发布顺序决定优先考虑分发，而非传统的以基准测试为主导的发布方式。

该模型的规格令人瞩目。GLM-5.2是一个拥有7440亿参数的混合专家架构，其中活跃参数为400亿，具备真正的100万token上下文窗口——是其前身20万限制的五倍——并在28.5万亿token上进行了训练。截至6月中旬，它在[Code Arena](https://arena.ai/leaderboard/code/webdev)上全球排名第二，仅次于Anthropic的Claude Fable 5，使其成为编程任务中性能最高的公开可用模型之一。

关键的是，该模型的构建完全没有使用美国芯片。据Decrypt报道，GLM-5.2“[完全在华为芯片上运行](https://decrypt.co/371613/china-z-ai-glm-5-2-model-rivals-claude-opus)”。Stability AI创始人Emad Mostaque估计总训练成本约为2500万美元，其中80%用于后训练——如果这一数字准确的话，相对于西方前沿模型，GLM-5.2的成本将极其低廉。

在基准测试中，[GLM-5.2](https://z.ai/blog/glm-5.2)的表现与最好的专有系统相差无几。在衡量多小时自主工程项目的[FrontierSWE](https://www.frontierswe.com/)基准测试中，它仅落后Anthropic的Claude Opus 4.8一个百分点，同时略微领先于OpenAI的[GPT-5.5](https://openai.com/index/introducing-gpt-5-5/)。

其API定价——每百万输入token 1.40美元，每百万输出token 4.40美元——与Anthropic Claude Opus 4.8的5美元和25美元相比，成本降低了高达82%。由于ZCode是开发该模型的同一家公司推出的第一方工具，因此无需手动配置端点——模型已内置其中。

## **Anthropic出口禁令给了中国AI迄今最大机遇**

ZCode的到来与过去三周搅动AI产业的地缘政治事件密不可分。6月12日，美国政府[以国家安全权力为由](https://www.reuters.com/technology/us-blocks-foreign-access-anthropics-most-advanced-ai-models-axios-reports-2026-06-13/)发布了一项出口管制指令，暂停任何外国公民（无论在美国境内还是境外，包括Anthropic的外籍员工）对Anthropic Fable 5和Mythos 5模型的所有访问权限。金融、医疗、SaaS和关键基础设施领域的企业客户发现，其核心智能服务被突然禁用，没有任何例外、事先警告或有效的追索权。

尽管特朗普政府[昨天刚刚取消了这些管制](https://www.cnbc.com/2026/06-30/anthropic-says-trump-admin-has-lifted-export-controls-on-claude-fable-5-and-mythos-5.html)——Anthropic于6月30日证实商务部已撤销该指令——但这一事件在开发者社区引起了轩然大波，并加速了人们对开源、可自托管替代方案的兴趣。政府对Anthropic的打压恰逢中国开源模型的迅速崛起，这些模型被证明几乎与美国一些最强大的模型一样有能力，且价格要便宜得多。

Z.ai的时机把握得非常精准。在特朗普政府下令禁止外国公民使用Anthropic最先进模型的同一天，智谱宣布[开源发布GLM-5.2](https://z.ai/blog/glm-5.2)且没有使用限制。[《南华早报》报道](https://www.scmp.com/tech/article/3343239/chinas-zhipu-ai-launches-new-major-model-glm-5-challenge-its-rivals)称，GLM-5.2将向智谱新推出的GLM Coding Plan订阅的所有用户开放，“价格仅为Anthropic高级Claude Code和Claude Max层级的十分之一。”

市场对此做出了反应。在盘中股价飙升42%的推动下，智谱AI的市值在6月22日突破1万亿港元（[1280亿美元](https://www.scmp.com/tech/article/3357858/zhipu-ai-market-cap-tops-hk1-trillion-shares-glm-52-developer-soar)）。摩根大通在此次发布后将智谱2026-2030年的收入预测提高了7%至16%，预计2026年收入将激增超过534%，并预计这家AI公司将在2028年实现盈利。

## **为何供应商锁定现在带有任何SLA都无法覆盖的地缘政治风险**

[Fable 5事件](https://venturebeat.com/technology/anthropic-is-bringing-back-claude-fable-5-globally-after-us-lifts-export-control-order-where-can-enterprises-access-it)不仅让Anthropic感到尴尬。它还为企业AI采购引入了一个新的风险类别：主权访问风险。当政府能够在一夜之间禁用一个已商业部署的AI模型时，开发者体验、基准测试分数和定价等传统评估标准，就退居次要地位，让位于一个更根本的问题：这个工具明天还能用吗？

该事件暴露了标准企业合同语言的不足。[FifthRow](https://www.fifthrow.com/blog/us-export-control-order-and-global-suspension-of-fable-5-mythos-5-operationalizing-compliance-as-a)的一项调查发现，几乎所有的标准数据处理附录、SaaS协议和采购SLA都“依赖于模糊的‘不可抗力’或‘遵守法律’的兜底条款，而不是精确、可操作的监管暂停或‘熔断’条款。”

ZCode的[BYOK架构](https://aiidelist.com/ide/zcode)和[GLM-5.2](https://z.ai/blog/glm-5.2)的MIT许可开源权重提供了一个部分解决方案。开发团队可以下载该模型，托管在自己的基础设施上，并在其上运行ZCode，而无需接触Z.ai的云服务——一举消除了美国出口管制风险和中国数据主权担忧。问题是，任何使用Z.ai云API的人仍受中国法律管辖，只有通过纯粹的自托管，这一顾虑才会消失。

Gartner分析师[曾警告称](https://news.creeta.com/en/gartner-enterprise-ai-coding-agents-2026/)，在评估企业级采用的编程智能体供应商时，治理、定价、支持、工作流、商业成熟度和市场持久性与开发者体验及模型能力同等重要。以此衡量，ZCode面临着艰巨的挑战。它本身并不是开源的；Linux支持仍处于测试阶段；安全审查人员已指出需要仔细评估其凭证处理方式，特别是对于通过SSH进行的远程开发和由通讯平台触发的任务——一个可以从微信调用的智能体涉及访问路径，在信任它处理任何敏感信息之前，应对这些路径进行梳理。

## **深入100亿美元竞赛：模型实验室正转型为全栈IDE公司**

[ZCode](https://zcode.z.ai/)进入了企业软件中最拥挤、发展最快的市场之一。据[Gartner](https://enterprisedna.co/resources/news/gartner-enterprise-ai-coding-agents-10-billion-market-2026/)称，截至2026年4月，企业AI编程智能体正占据企业软件工程支出中越来越大的份额，该市场的年化规模估计约为98亿至110亿美元。这家分析公司指出，今年的一决定性转变是“前沿模型提供商进入与应用层供应商的直接竞争”——这正是ZCode所体现的模式。

Gartner在5月份将年度魔力象限从“AI代码助手”更名为“企业AI编程智能体”，从而将这一演变正式化，将该类别定义为“自主或半自主的软件工程解决方案，能够感知上下文、将人类意图转化为多步骤计划，并在代码、测试和相关工程工件中执行和验证这些步骤。”2026年的魔力象限将Anthropic、Cursor、GitHub和OpenAI列为领导者。Z.ai不在被评估的12家供应商之列——这一缺席突显了该公司在中国以外地区企业销售业务的初生状态，以及分析界仍用以西方为中心的视角来看待该市场。

竞争格局令人生畏。Cursor是一款[年经常性收入达20亿美元的IDE](https://www.bloomberg.com/news/articles/2026-03-02/cursor-recurring-revenue-doubles-in-three-months-to-2-billion)，感觉就像是装了增压器的VS Code。到2026年初，Claude Code的年化收入达到了[约25亿美元](https://www.anthropic.com/news/anthropic-raises-30-billion-series-g-funding-380-billion-post-money-valuation)。谷歌在5月的I/O大会上重新发布了[Antigravity 2.0](https://blog.google/innovation-and-ai/technology/developers-tools/google-io-2026-developer-highlights/)，而Cognition则退役了Windsurf品牌，将该IDE重新发布为[Devin Desktop](https://devin.ai/desktop/)，并将Agent Command Center作为默认界面。

面对这些根深蒂固的参与者，ZCode的卖点建立在三大支柱之上：与GLM-5.2的深度第一方集成（这是任何第三方编辑器都无法复制的）、起价仅为西方竞争对手零头的激进定价，以及允许企业自托管的MIT许可开源权重——消除了Fable禁令让人真切感受到的监管“熔断”风险。

## **Z.ai的真正挑战：将1280亿美元估值转化为全球开发者工具业务**

[Z.ai](http://z.ai/)控制着模型（[GLM-5.2](https://z.ai/blog/glm-5.2)）、订阅层（[GLM Coding Plan](https://z.ai/subscribe)）和IDE（[ZCode](https://zcode.z.ai/)）——这是一个高度耦合的技术栈，优化了性能但也集中了切换成本。对该公司而言，商业逻辑很清晰。其最可靠的收入来源一直是中国政府机构、国有银行和能源集团的本地部署。2025年全年，本地部署收入达到5.34亿元人民币，同比增长超过100%，占总收入的73.7%，毛利率为48.8%。ZCode和GLM Coding Plan代表了该公司在全球（而不仅仅是在中国）建立基于云的开发者工具可比收入引擎的尝试。

对[Z.ai](http://z.ai/)来说，早期信号令人鼓舞，尽管只是轶事。X上的社区反响热烈，一位早期用户称该工具“超级稳定”，其他人则呼吁增加Coding Plan的容量。“兄弟，抢不到你家的Coding Plan？什么时候多上点卡？”[一位用户用中文写道](https://x.com/realchendahuang/status/2072361920976593163)，这表明需求已经超过了供应。

但严峻的问题依然突出。在技术紧张局势加剧的背景下，一家中国AI公司能否与西方企业买家建立信任？ZCode的生态系统能否足够快地成熟，以与Cursor精致的UX、Claude Code深度的智能体原语以及GitHub Copilot无与伦比的分发能力竞争？Z.ai能否在仍在亏损的情况下，维持一家估值1280亿美元的公司？

毫无疑问的是竞争态势本身。三周前，美国政府的一项指令证明了获取世界最佳编程模型的途径可能在一夜之间消失。今天，一家中国实验室正在发布一款免费的IDE、一个完全没有使用美国芯片训练的开源模型，以及一个每月费用低于曼哈顿一顿午餐的订阅计划。今年夏天，AI编程智能体市场不仅仅是走向了全球。它变成了一个备用选项可能比首选选项更好的市场——这改变了2026年下半年每一位选择工具链的工程领导者的考量。
