摘要
准确且负责任的医疗问答（QA）在医疗保健中非常重要，复杂病例需要事实知识和细致的推理。现有的医疗问答系统通常基于单智能体架构和静态检索，往往缺乏适应性、持久记忆和结构化决策。本文引入了自适应记忆与反思（AMR）智能体系统，这是一个多智能体框架，其中专业化智能体使用专用记忆和基于反思的反馈来检索相关先验病例并改进后续推理。复杂性评估将问题路由通过单干、协作或升级工作流，而共识和伦理监督模块支持推理整合和输出审查。
在 MedQA 和 MedMCQA 上的评估表明，与几个基线相比表现出色。消融研究表明，结合智能体特定记忆、反思和外部检索可产生最佳性能。这些发现突出了结构化记忆和反馈在开发更值得信赖的医疗智能体方面的潜力。

I 引言
医疗问答（QA）旨在通过将响应建立在生物医学知识、临床证据和特定领域推理的基础之上，来回答自然语言医疗问题 [12]。它支持在护理点进行简明的证据访问 [10]、生物医学文献理解、医学教育和考试式评估，以及人工智能系统中专家级推理的评估 [10]。该领域已从临床证据检索系统发展到现代自然语言处理（NLP）和大语言模型（LLM）环境 [25]。
当前的医疗问答研究主要沿三个方向进行。第一个方向探索更强的特定领域 LLM，以进行更好的医疗分析 [28]。第二个方向通过检索增强生成（RAG）改进回答，以便响应可以建立在外部医疗证据的基础上 [26]。第三个方向使用智能体来模仿临床决策讨论 [14]。尽管医疗问答系统取得了许多进展，但它们通常缺乏持久记忆和反思能力，无法从过去的错误中学习或随着时间的推移改进推理 [18, 17, 5]。此外，缺乏明确的伦理控制机制导致在临床环境中产生不可靠的输出 [6, 2]。虽然 RAG 和多智能体方法部分解决了这些问题，但如果没有集成的适应性和反馈，它们仍然不够。
为了解决这些局限性，我们提出了一种自适应记忆与反思（AMR）智能体系统，这是一个集成了角色特定记忆和结构化反思-反馈回路的多智能体医疗问答框架。AMR 建立在基于图的编排 [16] 之上，支持动态路由、共识驱动的推理 [4] 和生成后安全筛查 [21]。受临床团队流程 [8] 的启发，这种设计支持更透明和可控的医疗问答工作流。主要贡献如下：

II 相关工作
大语言模型显著推进了医疗 NLP，在临床摘要、概念提取和问答等任务中优于传统方法 [15, 29]。在生物医学语料库上训练的特定领域模型进一步提高了上下文理解能力，而与结构化本体的集成增强了可解释性并减少了幻觉 [3, 18]。
尽管在临床决策支持和问答任务中表现出色，LLM 仍然受到幻觉、推理不稳定和缺乏透明度的限制 [6]。此外，监管和隐私约束以及检索对齐的挑战限制了实际部署 [19, 1]。
多智能体系统（MAS）支持与临床决策的跨学科性质相一致的分布式、协作推理 [23]。虽然早期系统依赖于基于规则的协调 [8]，但现代方法采用基于 LLM 的智能体进行通信和协作，以提高推理准确性、鲁棒性和可解释性 [14, 30, 2]。然而，在管理智能体分歧、协调延迟和自适应协作策略方面仍然存在挑战 [13]。
检索增强生成（RAG）通过在推理过程中集成外部知识来改进事实基础 [24, 9]。虽然 RAG 在提高准确性方面很有效，但它仍然对检索不对齐很敏感，这会降低推理一致性 [22]。此外，诸如可解释性和证据可追溯性等临床可用性方面仍然没有得到充分探索。
与上述范式相比，提出的 AMR 框架在医疗问答设计中引入了两个系统级的转变。首先，AMR 将医疗问答视为一个流水线设计问题，并使路由显式化，以便根据问题复杂性而不是针对每个病例固定来选择推理深度。其次，AMR 在同一框架中结合了角色特定记忆、事后反思和输出筛查（伦理监督者），使得先前的病例能够以有针对性的方式被重用，并且候选答案在发布前接受潜在不安全内容的筛查。因此，由此产生的系统不仅是一个多智能体医疗问答模型，而且是一项关于系统组织如何改变医疗问答性能的显式研究。
III 方法
本节介绍了提出的自适应记忆与反思（AMR）智能体系统，旨在解决基于 LLM 的医疗问答中推理不一致、缺乏持久记忆和缺乏结构化反馈的问题。该框架将智能体特定的记忆与反思驱动的反馈相结合，以支持持续学习和随时间推移的推理改进。
III-A 总体架构
AMR 框架（图 1）采用基于 LangGraph 构建的模块化多智能体设计，用于基于图的编排 [16]。节点代表智能体或处理步骤，边定义转换。Moderator 评估问题复杂性，然后 Recruiter 将查询路由到三个路径之一： 低复杂性——由 General Practitioner 处理， 中等复杂性——通过多智能体协作和共识解决，以及 高复杂性——通过迭代的分层智能体细化处理，然后是报告摘要，最后由更高级的 Decision Maker（如首席顾问）进行选择。
该实现遵循 LangGraph 风格的执行流水线。Moderator 首先评估问题复杂性并对传入的查询进行分诊。Recruiter 根据分配的复杂性级别激活相应的智能体。推理输出在选定的路径内进行整合，并由 Ethical Overseer 审查。Final Answer Picker 随后将筛选后的输出映射到返回的答案选项。
III-B 自适应路由与协作推理
AMR 对不同的问题使用不同的推理深度。直接回忆或简单机制问题使用低复杂性路径；结合症状、发现和专科解释的问题使用专家协作；而具有竞争性诊断或治疗解释的病例则遵循更长的工作流，包括草稿生成、批评、细化和最终决策。Moderator 分配三个路由标签（低、中或高）之一，决定下游执行路径。
这种路由避免了对每个病例应用相同的多智能体程序。对于中等复杂性的问题，专家生成独立的意见，使用共享记录对其进行细化，然后由 Consensus Facilitator 总结一致和分歧之处。对于高复杂性问题，中间报告允许在最终答案选择之前修改推理。因此，路由既是一种计算捷径，也是一种将推理深度与问题难度对齐的控制机制。
III-C 智能体特定记忆与反思更新
每个 AMR 智能体都维护一个独立的记忆，而不是单一共享存储。记忆条目包含问题上下文、答案、事后笔记、角色元数据和时间戳，以供日后检索。当启用反思时，不正确的预测会生成一个额外的角色特定反思条目，其中包含纠正性反馈。这种设计允许不同角色为同一问题检索不同的先前经验；例如，肝病科和肾病科智能体可能会检索到不同的病例，因为它们从不同的专科视角进行推理。
除了记忆检索之外，AMR 还包含一个仅在预测答案与真实标签不同时触发的反思回路。纠正性反馈和推理摘要被存储为反思记忆，以改善未来的检索，而不是更新模型参数。算法 1 总结了这一过程。

III-D 答案合成与输出筛查
在专家推理完成后，AMR 将答案合成与答案发布分离开来。Summarizer 将专家的理由浓缩为一个解释，Final Answer Picker 将该解释映射到返回的答案选项。在发布之前，Ethical Overseer 会审查候选响应中是否存在潜在的不安全内容，包括直接的诊断声明、有害的建议或超出预期教育范围的治疗建议。响应被标记为 APPROVED 或 FLAGGED，并记录相应的理由以供审计。
在医疗问答中，合成与筛查之间的分离很重要。候选答案可能在事实上是有根据的，但在部署策略下仍需要过滤或弃权 [21, 19]。通过将输出筛查作为一个显式阶段隔离出来，AMR 使策略决策变得可检查，而不是将它们埋没在推理提示中。
Ethical Overseer 作为一个基于策略的生成后筛查层，审查候选响应中是否存在潜在不安全的医疗建议、不受支持的诊断声明和治疗建议。它不修改底层的推理过程，而是根据预定义的安全标准评估最终响应，并批准响应或将其标记为不合规。在当前的实现中，该组件旨在作为一种初步的安全机制，以减少潜在的不安全输出，不应被解释为正式临床验证或监管安全评估的替代品。

IV-B 实现细节
实验使用带有 JSONL 输入的 Python 流水线，并通过 OpenAI API 使用 GPT-4o。LangGraph 编排工作流，而 FAISS 作为持久向量存储。智能体记忆使用 text-embedding-3-large 进行嵌入，并索引以供语义检索。问题根据 Moderator 的复杂性评估进行路由。智能体检索前五个角色特定的先前病例，并在不正确的预测后记录反思更新。日志捕获了预测、路由决策、检索轨迹和伦理筛查结果。
每个智能体都收到角色特定的提示。Moderator 评估复杂性，Recruiter 选择专家，专家智能体生成独立的推理，Final Answer Picker 仅返回最终答案选项。检索文档由训练语料库构建，被分块为重叠的段落，进行嵌入，并索引在 FAISS 中。
为了计算效率，每个基准以 50 个问题为一批进行顺序评估。
为了防止测试集泄漏，检索语料库在评估之前构建，并在整个测试过程中保持冻结。评估样本被独立处理，不将测试问题、预测或反思反馈写回持久记忆。

在错误案例中（图 3b），系统产生了错误的答案，暴露了推理的局限性。此类案例触发反思，其中结构化反馈（不正确的预测、正确的答案和推理纠正）被存储在记忆中。例如，系统选择了选项“E”而不是“C”，引发了对伦理披露优先级的反馈。Ethical Overseer 标记了潜在不安全的建议并记录了审查原因，这说明了预期的筛查机制，而不是全面的定量评估。
V 结论
本文提出了一种用于医疗问答的自适应记忆与反思（AMR）智能体框架，该框架集成了复杂性感知路由、智能体特定记忆、协作推理、反思和输出筛查。通过将医疗问答视为结构化推理流水线而不是单提示任务，AMR 使智能体能够协作、细化中间推理，并利用检索到的知识和积累的经验。在 MedQA 和 MedMCQA 上的实验表明，与基线相比有一致的改进，其中记忆、反思和 RAG 的结合实现了最佳性能。
这些结果证明了结构化多智能体系统在实现更准确和自适应的医疗问答方面的潜力。
存在几个局限性。该框架仍然受到检索质量的约束，并且随着存储经验的增加，记忆的有效性可能会下降，从而引入重复或不太相关的病例。反思机制仅在回顾性基准上进行了评估，而不是在真实的临床工作流中。此外，伦理监督者使用 LLM 知识，尚未使用专门的临床规则或由临床医生进行验证。最后，MedQA 和 MedMCQA 并没有完全捕捉到现实世界临床决策的复杂性和工作流要求。
未来的工作将研究更有效的记忆管理和检索策略，包括记忆修剪、基于置信度的保留、新近度感知检索、重排序和遗忘机制，以提高长期性能。我们还计划将 AMR 扩展到多项选择基准之外，应用于开放式临床推理和现实世界的决策支持，同时对安全性、推理延迟、token 消耗以及推理质量和计算效率之间的权衡进行系统评估。
