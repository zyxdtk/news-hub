摘要

语言模型通常通过更深或循环的层以及潜在推理步骤来增加每 token 的计算量，同时更丰富的残差连接改善了跨层的信息流。我们转而增加计算容量：模型维护的活跃计算状态数量。我们引入了潜在晶格（Lattice of Latents），这是一组沿时间循环运行的每层水平潜在流，与沿深度流动的垂直残差流并行。类似于超连接、mHC 和注意力或值残差，晶格增强了残差流，但它不是通过深度添加或重新路由残差路径，而是提供跨 token 持久存在的伴随计算状态。与混合 Transformer–SSM 架构不同（其循环状态主要作为序列混合的内部记忆），这些潜在变量直接调节垂直流的注意力、KV 缓存写入、MLP 计算和解码。在 20B FineWeb-Edu token 上训练的 Transformer 上，406M 参数的晶格模型将验证困惑度从 15.41 降低到 14.40，超过了参数匹配的 Transformer。这些增益扩展到各种架构变体。晶格与先前的残差流增强可组合：结合超连接和输入残差，它将验证困惑度从 15.41（基础 Transformer）和 14.22（具有相同增强的 Transformer）降低到 13.61。在 Gated DeltaNet、Mamba-2、Triadic GDN 和 GDN–Mamba-2 混合模型上，它在每个测试的原生状态大小下都改善了困惑度，Lattice-GDN 和 Lattice-Triadic-GDN 变体优于具有 4 倍更大原生状态的纯基线。这些结果将持久的每层状态确定为扩展语言模型计算的互补轴。

1 引言

语言模型接受原始文本作为输入，通过内部表示进行转换，并预测后续文本。与大多数学习系统一样，该过程依赖于某种形式的潜在计算。但是，大语言模型中的潜在计算究竟是什么？

在标准的自回归 LLM 中，每个 token 由沿单一残差流的一系列层处理，这一个潜在变量同时承担多项任务。在每一层，它通过注意力查询从记忆中读取，通过键和值向记忆写入，通过 MLP 更新自身，并在顶部被解码为下一个 token。它写入的记忆——KV 缓存——是写入后保持不变的仅追加记录；残差流承载所有活跃计算。

最近的工作增加了在此流上执行的计算：更深或循环的层对每个 token 应用更多更新（Dehghani et al., 2019; Geiping et al., 2025; Zhu et al., 2026），连续潜在推理在 token 之间继续潜在处理（Hao et al., 2024; Wu et al., 2026; Zeng et al., 2026; Shen et al., 2025），更丰富的残差连接（如超连接、mHC 和注意力或值残差）改善了流跨深度携带信息的方式（Zhu et al., 2025; Xie et al., 2026; Team et al., 2026; Zhou et al., 2025）。这些方法给残差流提供了更多计算内容。

我们转而关注增加计算容量：模型维护的活跃计算状态数量。

我们提出了一个计算潜在变量的晶格：除了沿深度流动的垂直潜在变量 $h_t^\ell$（图 1 中的蓝色箭头）之外，每个晶格层维护自己的水平潜在变量 $r_t^\ell$（橙色箭头），跨时间步循环更新。我们将这种架构称为潜在晶格，基于它构建的语言模型称为潜在晶格语言模型（LLLM）。

类似于残差流增强（Zhu et al., 2025; Xie et al., 2026; Team et al., 2026），晶格增强了垂直流，但它不是通过深度加宽或重新路由，而是添加跨 token 持久存在的伴随计算状态。水平潜在变量添加固定大小的循环状态，而不需要额外的 token 位置或 KV 缓存条目。那么，这种水平信息流如何支持垂直潜在变量？

图 1：潜在晶格语言模型。 蓝色箭头表示沿深度流动的垂直潜在变量 $h_t^\ell$；橙色箭头表示水平潜在变量 $r_t^\ell$，每个晶格层一个，沿时间流动。从顶部晶格层到下一时间步底层的箭头说明了可选的自顶向下反馈；另外两个增强（输入注入和深度方向读出流）为清晰起见省略。参见项目网页获取动画和与基础 Transformer 的比较。

在每一步计算中——层 $\ell$，时间步 $t$——有两个活跃信息流可用：来自下层的垂直潜在变量 $h_t^{\ell-1}$，以及通过更新同层前一状态 $r_{t-1}^\ell$ 形成的水平潜在变量 $r_t^\ell$。

在我们的 Transformer 实例化中，两个潜在变量共同驱动该层的注意力和 MLP 计算。水平潜在变量调节注意力查询和 KV 缓存写入，调制 MLP，并且在最顶部的晶格层，还与最终垂直潜在变量一起参与输出解码。

我们设计水平更新使其满足： 有效到足以作为残差流的有用伴随，以及 与 token 并行、教师强制训练兼容。

为实现这些目标，我们从仿射 Mamba 风格（Gu and Dao, 2024）更新开始，其中 $r_t^\ell$ 使用传入的垂直潜在变量 $h_t^{\ell-1}$ 从 $r_{t-1}^\ell$ 更新。在层输入序列条件下，此仿射递归允许跨 token 位置的精确关联扫描。

虽然更新类似于 Mamba 和混合 Transformer–SSM 模型中的更新，但其角色不同。在那里，循环状态充当序列混合器：替代注意力或与其并行操作的内部记忆。在这里，注意力（或骨干网络的原生记忆）仍然是序列混合器，水平潜在变量充当残差流的伴随，调节垂直流如何读取和写入该记忆以及其 MLP 如何处理它。

在此基础更新 $r_{t-1}^\ell \to r_t^\ell$ 中，水平潜在变量仅通过传入的垂直潜在变量（残差流）$h_t^{\ell-1}$ 接收新信息。因此，我们添加了三个增强来丰富水平路径：输入注入将 token 嵌入直接馈送到每层的更新中，使每个水平潜在变量在不依赖垂直流保留的情况下看到当前 token；非线性深度方向读出流让每层对其水平潜在变量的读出依赖于下层的读出，在每层仿射递归之上添加非线性跨层计算；自顶向下反馈将顶层水平潜在变量馈送到下一时间步底层更新中，使前一个 token 处理最深的状态为当前 token 的最早计算提供信息。

前两个保持并行扫描，使我们的主要模型在近似匹配的计算量下保持单次通过。自顶向下反馈不保持 token 并行性，因此我们用几次 token 并行的 Jacobi 扫描（Wu et al., 2026; Zeng et al., 2026）来近似它，训练期间三次扫描约 2.6 倍 FLOPs；在推理时，同一模型可以以基础 FLOPs 顺序展开。

在 10B 到 30B FineWeb-Edu token 的预训练预算中，潜在晶格在近似匹配的参数和计算量下改善了语言建模质量（表 1、表 3、图 7）。在 20B token 下，具有输入注入和深度方向读出流的 406M 参数 LLLM 将 FineWeb-Edu 困惑度从 15.41 降低到 14.40，匹配 1.5 倍更大的 40 层 Transformer。单独训练的具有非线性自顶向下精炼器的 LLLM，运行三次 Jacobi 扫描（以更高 FLOPs），将困惑度进一步降低到 14.03（表 1）。这些增益扩展到分布外困惑度、下游任务和微调的数学推理（GSM8K）。

作为记忆调节的残差流增强，单独的晶格比超连接、mHC 或值残差降低更多困惑度，并且与它们组合（第 4.2 节）：结合超连接和输入残差，达到 13.61，而没有晶格时为 14.22（图 3）。

总体而言，在相似参数和计算预算下的比较表明，将容量分配给垂直和水平潜在变量优于在测试配置中仅将其用于残差流宽度或网络深度。总之，这些结果将持久的每层状态确定为扩展语言模型计算的互补轴。

2 相关工作

单一流上的更多计算。 最近的工作增加了语言模型对每个 token 应用的计算量。沿深度方向，模型添加层或重复应用共享堆栈（Dehghani et al., 2019; Geiping et al., 2025; Zhu et al., 2026）；沿时间方向，连续潜在推理将最终隐藏状态反馈为下一个输入，在发出 token 之前运行额外的潜在步骤（Hao et al., 2024; Shen et al., 2025; Zeng et al., 2026），Jacobi 风格的精炼恢复 token 并行训练（Zeng et al., 2026; Wu et al., 2026）。两个方向都对一个活跃流应用更多更新，并通常随之增长持久记忆：额外的层和循环特定的缓存，或作为额外位置持有的潜在思考，添加 KV 缓存条目。晶格转而通过在每个晶格层维护一个跨 token 持久的活跃潜在变量来增加计算容量，而不添加每 token 的 KV 缓存条目。

残差流增强。 一条互补的工作线改变了残差流通过深度携带信息的方式。超连接将其扩展为具有学习混合的并行流（Zhu et al., 2025），mHC 将其约束为双随机（Xie et al., 2026）；注意力残差用对早期层输出的注意力替代固定残差和（Team et al., 2026）；值残差在后续层中重用第一层的值（Zhou et al., 2025）；输入残差在每层之前重新注入 token 嵌入。这些方法通过深度加宽或重新路由每 token 计算，但没有一个给层提供从一个 token 持续到下一个的自有状态。晶格添加了这样的状态并与这些增强组合：在我们的实验中，在标准、输入残差和超连接的残差流之上添加它降低了困惑度（第 3.3 节）。

循环序列模型和混合模型。 我们的仿射水平更新与线性循环模型（如 Mamba（Gu and Dao, 2024; Dao and Gu, 2024）、Gated DeltaNet（Yang et al., 2025）和 DeltaProduct（Siems et al., 2025））共享扫描并行形式，其转换在前一状态中保持线性或仿射。在这些模型以及用 SSM 层在选定深度替换注意力的混合模型（Lieber et al., 2024）或与注意力头并行运行的混合模型（Dong et al., 2024）中，循环状态是序列混合器：它替代或补充注意力作为读取过去的手段。在晶格中，水平潜在变量是残差流的伴随：在 Transformer 中，softmax 注意力被保留，潜在变量调节注意力、其 KV 缓存写入和 MLP。因为这一角色与序列混合不同，晶格也补充循环骨干：在 GDN、Mamba-2、Triadic GDN 和 GDN–Mamba-2 混合模型上，它在近似匹配的参数量下降低了困惑度（第 3.4 节）。

Transformer 内的循环。 其他工作在不替换注意力的情况下将循环引入 Transformer。Mozer et al. (2026a) 认为前馈 Transformer 将演化状态推入越来越深的层，耗尽深度，并呼吁循环。NextLat（Teoh et al., 2025）保持架构不变并添加辅助目标，训练潜在动力学模型预测下一个隐藏状态，鼓励类似循环的信念状态；晶格转而在架构中添加显式循环状态。几项并行工作添加循环或多流路径，通常将前一个 token 的更深表示反馈到当前 token 的计算中（Wang et al., 2026; Huang et al., 2026; Cai et al., 2026; Mozer et al., 2026b），或将状态准备与下一 token 预测分离到不同的流中（Monea et al., 2026）。其中，T²MLR（Cai et al., 2026）最接近我们的 Jacobi 精炼器，尽管其循环对象是缓存的垂直表示而不是逐层水平状态的晶格。这些工作主要添加单一反馈路径或分离两个角色，而晶格在每个晶格层维护一个持久潜在变量；附录 A.1 给出了并行工作的详细描述。

3 方法

图 2：循环骨干：FineWeb-Edu 困惑度。 纯 GDN、Mamba2、Triadic GDN 和 GDN–Mamba2 混合模型及其晶格版本（约 405M 参数，10B FineWeb-Edu token），每个混合器多种原生状态大小。每个晶格模型与其纯对应模型参数等量，在每个状态大小下都降低困惑度。参见第 4.3 节。

我们提出了潜在晶格，这是一种将计算分布在潜在变量晶格上而不是仅依赖于通常的每 token 单一残差流潜在变量的增强。潜在计算跨越两个轴。沿垂直轴（网络深度），每 token 潜在变量从当前 token 嵌入初始化，自底向上流经骨干网络的层，在那里通过注意力或循环状态计算以及随后的位置式 MLP 更新，然后被解码为下一 token 分布。沿水平轴（时间），潜在晶格在中间晶格块的每层添加一个持久潜在向量，跨时间步演化而不是通过深度。每个水平潜在变量保持在它自己的层和抽象级别，通过调节该层的记忆读取和更新来辅助垂直流。在我们的 Transformer 实例化中，我们还研究了 MLP 调制。

晶格由此增加了计算容量——模型维护的活跃计算状态数量——通过向残差流添加伴随状态来调节残差流的计算，而不是简单地加宽残差流或通过深度添加残差路径。

我们将潜在晶格集成到标准 Transformer、具有残差流增强的 Transformer（超连接、mHC、值残差和输入残差）以及循环骨干：Gated DeltaNet（GDN）、Mamba-2、Triadic GDN 和 GDN–Mamba-2 混合模型中。

3.1 背景：单一活跃潜在变量的计算

垂直潜在变量的每 token 计算图。 考虑深度为 $N$、宽度为 $d_{\text{model}}$ 的自回归 Transformer，处理 token 流 $x_1, x_2, \dots$。在时间步 $t$，模型通过单一残差流潜在变量 $h_t^\ell \in \mathbb{R}^{d_{\text{model}}}$ 将输入 token $x_t$ 映射到下一 token 分布，从 token 嵌入 $h_t^0$ 初始化并在 $N$ 层中精炼。

层 $\ell \in {1, \dots, N}$ 用 pre-norm 注意力块后跟 MLP 块更新此潜在变量：

$$q_t^\ell, k_t^\ell, v_t^\ell = W_q^\ell \hat{h}, W_k^\ell \hat{h}, W_v^\ell \hat{h}$$
$$\bar{h}_t^\ell = h_t^{\ell-1} + W_o^\ell \, \text{Attn}(q_t^\ell, \mathcal{M}_t^\ell)$$
$$h_t^\ell = \bar{h}_t^\ell + \text{MLP}^\ell(\text{Norm}(\bar{h}_t^\ell))$$

其中 $\hat{h} = \text{Norm}(h_t^{\ell-1})$，Norm 是 RMSNorm，$\mathcal{M}t^\ell = {(k_s^\ell, v_s^\ell)}{s \leq t}$ 是层 $\ell$ 的 KV 缓存，每个 token 向其追加键和值。最终潜在变量被解码为 $p(x_{t+1} | x_{\leq t}) = \text{softmax}(W_U \, \text{Norm}(h_t^N))$。

因此，每 token 一个潜在变量完成所有活跃计算（读取记忆、写入记忆和产生输出），而 KV 缓存被动存储其过去的投影。

垂直潜在变量的循环视角。 连续潜在推理（Hao et al., 2024; Shen et al., 2025; Zeng et al., 2026）通过将前一步的最终层潜在变量反馈为下一个输入 $h_t^0 = h_{t-1}^N$ 来跨时间步扩展此路径，绕过解码和重新嵌入。反馈因此可以携带比离散 token 的 $\log_2 V$ 位更多的信息，垂直潜在变量成为跨时间的运行状态。标准 Transformer 转而在每个时间步从 token 嵌入重新初始化其垂直潜在变量。

3.2 潜在晶格

我们如何增加这一单一活跃潜在变量的计算容量？可以加宽它（更大的 $d_{\text{model}}$），如超连接中那样复制为并行深度流，或沿不同轴添加潜在变量。我们采取第三条路线：每个晶格层 $\ell$ 维护自己的水平潜在变量 $r_t^\ell$，跨时间步运行，从学习的状态初始化并从其前值 $r_{t-1}^\ell$ 和传入的垂直潜在变量 $h_t^{\ell-1}$ 更新。垂直潜在变量在每个时间步通过深度推进，水平潜在变量在每层通过时间推进；它们一起形成晶格。

3.2.1 水平潜在变量如何作用

设 $r_t^\ell \in \mathbb{R}^{d_r}$ 为层 $\ell$ 和时间步 $t$ 的水平潜在变量，宽度 $d_r$ 独立于 $d_{\text{model}}$ 选择。标准 Transformer 层从垂直潜在变量 $h_t^{\ell-1}$ 及其 KV 缓存计算。在晶格中，层 $\ell$ 有两个潜在输入：来自下层的垂直潜在变量 $h_t^{\ell-1}$，以及从同层前一状态 $r_{t-1}^\ell$ 更新的水平潜在变量 $r_t^\ell$。它们共同调节该层的注意力和 MLP，从而调节产生 $h_t^\ell$ 的残差更新和写入记忆的键和值。

图 4：水平潜在变量如何作用。 Transformer 实例化：循环晶格潜在变量 $\hat{r}_t^\ell$ 调节该层的 QKV 和 MLP 计算；当启用可选的水平解码头时，最顶部的水平潜在变量也参与输出解码（未显示）。

通过 FiLM 调节注意力。 水平潜在变量 $\hat{r}_t^\ell$ 通过特征级线性调制（FiLM）（Perez et al., 2017）调制 $\hat{h} = \text{Norm}(h_t^{\ell-1})$ 的查询、键和值投影：

$$q_t^\ell = (W_q^\ell \hat{h}) \odot (1 + \gamma_q(\hat{r}t^\ell)) + \beta_q(\hat{r}_t^\ell)$$
$$\gamma{(\cdot)}(\hat{r}t^\ell) = \tanh(W{(\cdot)}^\gamma \hat{r}t^\ell) \qquad \beta{(\cdot)}(\hat{r}t^\ell) = W{(\cdot)}^\beta \hat{r}_t^\ell$$

对 $k_t^\ell$ 和 $v_t^\ell$ 同样如此。乘性增益 $1 + \gamma \in (0, 2)$ 有界，而 $\beta$ 是加性偏移；$q, k, v$ 各自有其特定层的零初始化 $W^\gamma$ 和 $W^\beta$，因此调制从恒等开始。增益 $\gamma$ 可以在每个头内的通道组之间共享，而 $\beta$ 始终是每通道的。因为调制的 $k_t^\ell, v_t^\ell$ 被写入 $\mathcal{M}^\ell$，水平潜在变量同时塑造记忆读取和记忆写入。

调制 MLP。 水平潜在变量还通过各自的零初始化映射偏移该层 SwiGLU MLP 的门控和上升预激活：

$$m = \text{Norm}(\bar{h}t^\ell) \qquad \text{gate} = W{\text{gate}}^\ell m + \beta_{\text{gate}}(\hat{r}t^\ell)$$
$$\text{up} = W{\text{up}}^\ell m + \beta_{\text{up}}(\hat{r}_t^\ell)$$

MLP 输出 $W_{\text{down}}^\ell(\text{SiLU}(\text{gate}) \odot \text{up})$ 被加到 $\bar{h}_t^\ell$，得到 $h_t^\ell$。

调制解码。 可选地，最顶部晶格层的归一化水平潜在变量和最终垂直潜在变量被投影到共享读出空间，下一 token 从它们的和解码（详见附录 A.2.1）。我们仅在高度压缩的垂直潜在变量（$d_{\text{model}}=256$）时使用此头（图 6），否则标准解码器将仅从 256 维潜在变量读取输出分布。

3.2.2 水平潜在变量如何更新

我们将骨干网络的层分为早期块（E）、中间晶格块（L）和晚期块（D）；水平潜在变量仅存在于 L 中。对于 $\ell \in L$，更新形式为：

$$r_t^\ell = U(r_{t-1}^\ell; h_t^{\ell-1}, h_t^0, r_{t-1}^{\text{top}})$$

基础更新使用该层自身的历史 $r_{t-1}^\ell$ 和传入的垂直潜在变量 $h_t^{\ell-1}$。输入注入添加 token 嵌入 $h_t^0$，可选的 Jacobi 精炼器添加来自一个时间步前顶部晶格层的反馈 $r_{t-1}^{\text{top}}$，仅在底部晶格层注入并取自前一次扫描。

图 5：水平潜在变量更新。 在 Mamba 风格仿射更新之上，我们进一步引入输入注入、vstream（未显示）和可选的跨时间步非线性流。参见网页获取动画。

从 $r_{t-1}^\ell$ 到 $r_t^\ell$ 的仿射更新。 为保持训练 token 并行和教师强制，我们需要一个允许跨时间步精确关联扫描而不是逐 token 循环的递归。具有输入依赖系数的仿射转换具有此属性。遵循线性注意力和 Mamba 风格状态空间模型，我们使用其系数仅依赖于当前层输入、从不直接依赖于前一水平状态的更新。仿射更新读取垂直潜在变量的归一化副本 $n_t^\ell = \text{Norm}_{\text{in}}(h_t^{\ell-1})$，定义为：

$$\Delta_t^\ell = \text{softplus}(W_\Delta^\ell n_t^\ell + b_\Delta^\ell)$$
$$g_t^\ell = \exp(-\exp(a^\ell) \odot \Delta_t^\ell)$$
$$c_t^\ell = \text{SiLU}(W_r^\ell n_t^\ell + b_r^\ell)$$
$$b_t^\ell = (1 - g_t^\ell) \odot c_t^\ell$$
$$r_t^\ell = g_t^\ell \odot r_{t-1}^\ell + b_t^\ell$$

这里 $r_0^\ell$ 是第一个 token $x_1$ 之前的学习初始状态，$a^\ell$ 和 $b_\Delta^\ell$ 是学习的每通道对数衰减率和时间步偏置。因为 $g_t^\ell$ 和 $b_t^\ell$ 仅依赖于 $n_t^\ell$，转换在层输入序列条件下精确仿射，因此训练期间所有 token 位置的水平状态用并行扫描计算。层仍按深度顺序评估，每层扫描下层产生的垂直输入。下游使用的读出是 $\hat{r}_t^\ell = \text{Norm}(r_t^\ell)$。

虽然更新遵循 Mamba 风格门控仿射递归，水平潜在变量扮演不同角色——残差流的伴随而不是序列混合器——我们在已经维护循环记忆的骨干中重新审视这一点（第 3.4 节）。我们将此配置称为基础更新，标记相应模型为 $\mathbf{LLLM}(d_{\text{model}}, d_r)$，垂直宽度 $d_{\text{model}}$ 和水平宽度 $d_r$；额外机制在模型标签中单独标记。

将输入嵌入添加到水平潜在变量。 基�更新仅通过 $h_t^{\ell-1}$ 看到当前输入，到层 $\ell$ 时可能已丢弃了关于原始 token 身份的信息（参见窄垂直潜在变量消融，图 6）。输入注入（inj）还将归一化 token 嵌入 $h_t^0$ 通过零初始化投影馈送到 $\Delta_t^\ell$ 和 $c_t^\ell$。这些系数仍仅依赖于当前时间步输入，因此转换保持精确仿射，相同的并行扫描适用（详见附录 A.2.2）。

增强水平潜在变量的逐层非线性。 在层 $\ell$，来自基础更新和输入注入的读出 $\hat{r}_t^\ell$ 仅通过垂直潜在变量中幸存的内容间接接收来自较低晶格层水平潜在变量的信息。深度方向读出流（vstream 或 vs）添加直接路径：纯深度方向状态 $s_t^\ell \in \mathbb{R}^{d_r}$ 自底向上跨晶格运行，在第一个晶格层 $\ell_0$ 处以 $s_t^{\ell_0-1} := 0$ 播种：

$$s_t^\ell = s_t^{\ell-1} + W_{s\uparrow}^\ell \text{SiLU}(W_{s\downarrow}^\ell [\text{Norm}(\hat{r}_t^\ell), \text{Norm}(s_t^{\ell-1})])$$

其中 $[\cdot, \cdot]$ 表示拼接。因为 $W_{s\uparrow}^\ell$ 零初始化，初始化时 $s_t^\ell \equiv s_t^{\ell-1}$，因此用零种子时流在整个晶格中为零。该流在深度上携带同时间步通信，与跨时间作用的循环更新 $U$ 分开。因为 $s_t^\ell$ 仅依赖于同时间步量，它添加跨深度的非线性依赖但不跨时间，保持基础递归及其并行扫描不变。启用 vs 时，丰富读出 $\tilde{r}_t^\ell := \hat{r}_t^\ell + \text{Norm}(s_t^\ell)$ 在调节注意力或 MLP 的地方替换 $\hat{r}_t^\ell$（第 3.2.1 节）。跨时间步携带的状态保持为原始 $r_t^\ell$，不是 $\tilde{r}_t^\ell$；丰富读出仅通过垂直流间接影响更高层的更新。

跨时间步非线性更新。 输入注入和深度方向读出流仅使用当前时间步信息，因此都不将更高层处理更深的潜在变量反馈到下一时间步的较低层。在 Transformer 实例化中，我们添加此自顶向下反馈：顶部晶格层在 $t-1$ 的潜在变量，通过零初始化 SwiGLU 传递，被加到底部晶格层在 $t$ 的更新中，使递归跨时间步非线性。此反馈在逐 token 展开中直接明了但破坏单次通过教师强制训练，因此我们用 Jacobi 精炼器（Zeng et al., 2026; Wu et al., 2026）近似它：在晶格块的初始通过后，每次精炼扫描跨 token 并行重新运行所有晶格层，从前一次扫描获取反馈。与 Zeng et al. (2026); Wu et al. (2026) 将 Jacobi 迭代应用于垂直潜在变量（$h_t^0 = h_{t-1}^N$）不同，我们将其应用于水平潜在变量。J0 表示没有此跨时间步反馈的单次通过模型，J3 表示初始通过后跟两次精炼扫描（约 2.6 倍 FLOPs）。推理时，反馈可以通过顺序展开精确计算；我们评估两者（详见附录 A.2.3）。

3.3 与残差流增强的组合

因为晶格调制约每个块的计算而不是残差路径本身，它与残差流增强组合而不改变水平更新。输入残差在每层之前重新注入归一化 token 嵌入，$h_t^{\ell-1} \leftarrow \lambda_r^\ell h_t^{\ell-1} + \lambda_0^\ell \text{Norm}(h_t^0)$，具有学习的每层标量；水平更新然后将此重新注入的层输入读取为 $h_t^{\ell-1}$。这与输入注入不同，后者将嵌入馈送到水平更新而不是残差流。超连接（Zhu et al., 2025）将残差流扩展为 $n$ 个并行流，学习路由器将其混合到每个块的输入并在其输出后重新混合（mHC（Xie et al., 2026）将此混合约束为双随机）。使用超连接时，每个晶格层的水平更新读取混合块输入代替 $h_t^{\ell-1}$，FiLM 如第 3.2.1 节调节该块的 QKV 和 MLP 计算，路由器将块输出写回流。每个晶格层的单一水平潜在变量在 $n$ 个流之间共享。值残差（Zhou et al., 2025）将每层的注意力值与第一层的值混合；在晶格层中，混合在 FiLM 调节之后、注意力之前应用。在我们的实验中，我们将晶格与这些残差流增强进行比较并评估它们的组合。

3.4 循环骨干上的潜在晶格

虽然水平更新使用 Mamba 风格递归，晶格也补充已经维护循环记忆的骨干。我们在 GDN、Mamba-2、Triadic GDN 和 GDN–Mamba-2 混合模型上实例化它。与 Transformer 不断增长的 KV 缓存不同，这些骨干保持固定大小的原生记忆：GDN 和 Mamba-2 中每头的矩阵值状态，以及 Triadic GDN 中每头的三维状态（添加路由轴）。晶格保持这些记忆不变并添加单独的水平潜在变量来调节它们的使用方式。

我们保持基础更新，输入注入和深度方向读出流作为选项，并将 FiLM 应用于每个骨干的记忆读取、写入和更新量：在 GDN 中，Q、K、V、保留（$\alpha$）和更新强度（$\beta$）预激活以及输出门；在 Mamba-2 中，读取（C）和写入（B）投影、输入流、时间步预激活和输出门。Triadic GDN 额外调节其路由因子，GDN–Mamba-2 混合模型遵循每层骨干的设置。所有调制权重零初始化，调制应用于每个量的约束转换之前。这些比较使用未调制的 MLP、普通解码头和无 Jacobi 精炼器；更多细节见附录。

为将此与简单扩大原生记忆区分开来，我们在近似匹配参数量下比较有和没有晶格的模型跨原生状态预算。例如在 GDN 中，256 维水平潜在变量结合每层 65,536 原生状态条目达到的困惑度低于具有 262,144 条目的纯 GDN。我们还分析了 GDN 的状态几何（谱、有效和稳定秩，以及与主导记忆方向的查询对齐），有和没有晶格。区别是功能性的：水平潜在变量本身是持久状态，但它不是扩展骨干的关联记忆，而是提供学习到的、历史依赖的路径来调节垂直流的计算。我们假设这种额外的计算容量帮助模型更有效地使用其原生记忆，补充而不是复制记忆容量的增加；我们的实验与此假设一致。

4.2 与残差流增强的组合

晶格添加跨时间携带潜在变量的水平路径，而最近的残差流增强重塑信息如何垂直（跨深度）流动。我们通过在 20B FineWeb-Edu token 上预训练 400M 模型来测试两者是否互补，使用超连接（HC）（Zhu et al., 2025）、流形约束超连接（mHC）（Xie et al., 2026）、值残差（Zhou et al., 2025）和 nanochat 风格输入残差（x0）（Karpathy, 2025），单独和组合，有和没有晶格（图 3）；晶格模型将垂直宽度从 1024 缩小到 932 以保持参数等量（详见附录 A.4.2）。

单独使用时，晶格将 FineWeb-Edu 困惑度从 15.41 降低到 14.47，多于 HC（15.28）、mHC（14.93）或值残差（14.69），仅次于 x0（14.34）。更重要的是，其增益叠加在它们之上：晶格将 HC 从 15.28 降低到 14.21（−7.0%），HC + x0 从 14.22 降低到 13.61（−4.3%）。Lattice + HC + x0 是总体最佳模型，比普通 Transformer 低 11.7%，比最强的 Transformer 组合（x0 + 值残差，14.16）低 3.9%。因此，水平潜在变量不是更好残差流的替代品；它们是与它复合的正交轴。

4.3 循环骨干

我们在 10B FineWeb-Edu token 上预训练 GDN、Mamba2、Triadic GDN 和 GDN–Mamba2 混合模型（无滑动窗口注意力，no-SWA），将每个纯骨干与相同原生状态几何和近似匹配参数量（约 405M）的晶格对应物配对。我们扫描每个混合器 16K、32K、64K、128K 和 256K 原生状态条目（1K = 1024 标量条目），不包括添加的水平潜在变量和辅助卷积状态。对于 GDN，状态大小为 $H d_k d_v$，$H$ 个头具有每头键和值维度 $d_k, d_v$；我们使用 $(H, d_k, d_v) = (16,16,64), (16,32,64), (16,64,64), (8,128,128)$ 和 $(4,256,256)$，其他骨干类似变化（附录）。水平潜在变量仅调制混合器的记忆读取、写入和更新量，不调制 MLP 或解码。困惑度结果使用输入注入 + vstream，晶格模型的垂直残差流（$d_{\text{model}}$）缩窄以抵消添加的参数，保持每个比较参数等量。对于下游结果，在每个状态预算和 shot 设置下，我们通过九任务平均值选择三种耦合中最佳的一种——输入注入 + vstream 和两种仅 vstream 变体（通过减少 $d_{\text{model}}$ 或 FFN 宽度恢复参数预算）（详见附录 A.3）。

语言建模。 在 FineWeb-Edu（图 2）上，晶格在每个原生状态大小下降低困惑度：GDN 降低 1.2–2.6%，Mamba2 降低 0.6–2.2%，Triadic GDN 降低 1.1–2.1%，GDN–Mamba2 混合降低 0.3–1.0%（256K 时 15.85 vs. 15.92）。晶格模型还可以优于具有四倍原生状态条目的纯模型：64K Lattice GDN 优于 256K 纯 GDN（16.05 vs. 16.11），64K Lattice Triadic GDN 优于 256K 纯 Triadic GDN（15.98 vs. 16.09）。这些结果与水平潜在变量帮助垂直残差流控制记忆写入和读取、实现更有效使用原生记忆的假设一致（第 4.4 节）。

下游评估。 在相同的九任务平均值（图 12 和 13）上，选定的晶格模型在几乎所有配对比较中优于其纯对应物，跨越三个骨干（GDN、Mamba2 和 no-SWA 混合）、五个状态预算和两种 shot 设置。在状态预算上平均，增益范围为零样本 +0.53 到 +0.67 点，五样本 +0.76 到 +0.95 点，峰值 +1.50（Mamba2，16K，五样本），并且在最大预算下持续存在：在 256K，晶格为 GDN 添加 +0.86 和 +1.06 点。晶格模型再次可以优于具有更大原生状态的纯模型。每混合器原生条目少 8 倍时，32K Lattice GDN 在两种设置中都超过 256K 纯 GDN（零样本 44.88 vs. 44.45），32K 混合超过 256K 混合，16K Lattice Mamba2 超过 128K 纯 Mamba2；少 16 倍时，16K Lattice GDN 零样本仍超过 256K 纯 GDN（44.57 vs. 44.45）。

记忆几何和查询对齐。 最后，我们询问晶格如何改变 GDN 使用其原生记忆的方式。每个 GDN 头维护一个记忆矩阵 $S \in \mathbb{R}^{d_k \times d_v}$，用键写入并用查询读取，其中 $d_k$ 和 $d_v$ 是每头键和值维度。写 $S = U \Sigma V^\top$，奇异值 $\sigma_1 \geq \sigma_2 \geq \cdots$，主导左奇异向量 $u_1 \in \mathbb{R}^{d_k}$，我们用有效和稳定秩测量记忆的集中程度。熵有效秩 $r_{\text{ent}} = \exp(-\sum_i p_i \log p_i)$，$p_i = \sigma_i / \sum_j \sigma_j$，是谱分布的有效方向数；稳定秩 $r_{\text{stable}} = |S|F^2 / \sigma_1^2 = \sum_i \sigma_i^2 / \sigma_1^2$ 测量主导方向的支配程度。两者都在 $[1, \min(d_k, d_v)]$ 中；较低的值意味着更集中的谱，但本身不意味着存储的信息更少。我们还测量查询对齐增益 $G_1 = d_k (u_1^\top q)^2 / |q|_2^2$：用于读取的归一化查询 $q \in \mathbb{R}^{d_k}$ 与 $u_1$ 之间的余弦平方，按 $d_k$ 缩放使得各向同性随机查询给出 $\mathbb{E}[G_1]=1$。表 2 显示每个状态预算下的一致模式：晶格将 $r{\text{ent}}$ 降低 9.6–18.3%，$r_{\text{stable}}$ 降低 10.9–15.0%，同时将 $G_1$ 提高 33.5–67.4%。对齐差距随状态大小扩大，从 16K 时的 +1.89 到 256K 时的 +5.36，其中晶格查询与主导记忆方向的对齐是随机的 13.3 倍，而纯模型为 8.0 倍。因此，使用晶格，GDN 写入更集中的记忆并沿其主导方向更强地读取，与水平潜在变量帮助垂直流控制记忆写入和读取的假设一致。

5 结论

我们引入了潜在晶格，它将计算容量分布在垂直残差流和持久的逐层水平潜在变量之间。这些潜在变量不是替代序列记忆，而是充当引导骨干计算的伴随计算状态。我们使用仿射水平更新并引入增强，在保持每次通过内 token 并行教师强制计算的同时增加潜在表达力。LLLM 在 Transformer 和循环骨干上改善了语言建模和下游任务平均值。晶格还与残差流增强组合：结合超连接和输入残差，它优于我们测试的每个 Transformer 变体。在循环骨干上，增益出现在匹配的原生状态大小和近似匹配的参数量下，Lattice GDN 和 Lattice Triadic GDN 优于使用 4 倍原生状态条目的纯基线。总体而言，我们的结果表明，将活跃计算容量分布在相互作用的潜在变量之间是扩展宽度、深度、记忆或单独残差流的有前途的补充。

A.1 扩展相关工作

单一流上的更多计算。 沿深度或时间的额外计算通常伴随额外的持久记忆。在基于深度的方法中，每个添加的层带来自己的 KV 缓存，循环模型可能保持特定迭代的缓存，尽管最近的工作跨循环共享或压缩状态（Vendrell et al., 2026; Neill and Reid, 2026）。在连续潜在推理方法中，Coconut 将最终隐藏状态反馈为下一个输入，CODI 从显式思维链教师蒸馏此类推理，PonderLM-2 将其带入预训练（Hao et al., 2024; Shen et al., 2025; Zeng et al., 2026）；当潜在思考作为额外位置持有时，它们也添加 KV 缓存条目。因为连续思考相互依赖，单次通过教师强制不再适用；PonderLM-2 和 PCCoT 用 Jacobi 风格精炼恢复 token 并行性（Zeng et al., 2026; Wu et al., 2026），这启发了我们的可选 Jacobi 精炼器（附录 A.2.3）。

残差流增强。 我们详述三种残差流增强：输入残差、值残差和超连接。输入残差在每层之前重新注入归一化 token 嵌入，$h_t^{\ell-1} \leftarrow \lambda_r^\ell h_t^{\ell-1} + \lambda_0^\ell \text{Norm}(h_t^0)$，具有学习的每层标量。值残差学习（Zhou et al., 2025）在注意力内部添加类似快捷方式：每层将其注意力值与第一层的值混合，$v_t^\ell \leftarrow \lambda_1^\ell v_t^1 + \lambda_2^\ell v_t^\ell$，具有学习的每层标量，因此后续层保留对早期 token 信息的直接访问。超连接（Zhu et al., 2025）将残差流扩展为 $n$ 个并行流：每个块读取流的学习的、输入依赖的混合，其输出在流重新混合时写回；mHC（Xie et al., 2026）将此混合约束为双随机。所有三个都在时间步内作用，因此它们直接与晶格组合（第 3.3 节）；水平更新读取残差设计产生的任何输入。使用超连接时，每层一个水平潜在变量在 $n$ 个流之间共享。

循环序列模型。 除了 Mamba-2 的门控递归，Gated DeltaNet 添加 delta 规则状态更新，DeltaProduct 将多个 Householder 风格校正组合成更具表达力但仍然线性的转换（Yang et al., 2025; Siems et al., 2025）。非线性递归的工作是互补的：ParaRNN 用牛顿迭代并行化一般非线性递归，M²RNN 结合非线性更新与矩阵值状态（Danieli et al., 2025; Mishra et al., 2026）。我们保持时间更新仿射，通过其输入和读出添加表达力，仅通过可选的 Jacobi 精炼获得跨时间的非线性反馈。可并行化非线性递归的进步可以进一步加强水平潜在变量作为残差流的时间伴随。

Transformer 内的循环（并行工作）。 Full-Bandwidth Transformer（Wang et al., 2026）将前一个 token 的顶层状态与下一个嵌入一起反馈；Latent Recurrent Transformer（Huang et al., 2026）重用选定的高级表示作为循环记忆；T²MLR（Cai et al., 2026）通过门控路径将前一个 token 的更深表示路由到较早层。T²MLR 最接近我们的 Jacobi 精炼器，但其循环对象是缓存的垂直表示，而我们的 Jacobi 精炼器链接水平状态晶格的顶部和底部，每个都遵循自己的时间递归。Recirculation（Mozer et al., 2026b）也在跨步骤中将深层激活发送到较浅层，但是免训练的推理时干预，具有顺序预填充，而晶格以 token 并行方式端到端训练。State-Prediction Separation Transformer（Monea et al., 2026）共享我们的观点，即单一表示可能被多个角色负担，但在每个 token 的计算中分离它们，而不是在每层保持持久潜在变量。

A.2 附加方法细节

A.2.1 解码调制（水平潜在变量如何作用）

启用此可选头时，最顶部晶格层的水平潜在变量（具有自己的归一化）与最终垂直潜在变量一起加入维度 $d_s$ 的共享读出空间，下一 token 从它们的和解码：

$$p(x_{t+1} | x_{\leq t}) = \text{softmax}\Big(W_U\big(P_v \text{Norm}(h_t^N) + P_r \text{Norm}_{\text{head}}(r_t^{\text{top}})\big)\Big)$$

其中 $P_v \in \mathbb{R}^{d_s \times d_{\text{model}}}$ 和 $P_r \in \mathbb{R}^{d_s \times d_r}$ 是学习的投影，$W_U \in \mathbb{R}^{V \times d_s}$ 映射到词汇表 logits。与第 3.2.1 节中的每个其他注入一样，$P_r$ 零初始化。因此在初始化时水平潜在变量不贡献任何内容：注意力和 MLP 退化为标准 Transformer 层，输出仅从垂直潜在变量解码。水平潜在变量仅通过训练获得影响力。我们仅在具有高度压缩垂直潜在变量（$d_{\text{model}}=256$）的实验中使用解码调制。启用时，水平解码头读取单独归一化的原始顶层状态 $r_t^{\text{top}}$，而不是 vstream 丰富的读出。

A.2.2 输入注入（水平潜在变量如何更新）

基础更新仅通过 $h_t^{\ell-1}$ 接收新信息，因此其对当前输入的访问受限于垂直潜在变量保留的内容，我们通过消融较窄的垂直潜在变量来探测（图 6）。到层 $\ell$ 时，垂直潜在变量可能也已丢弃了关于原始 token 身份的信息。输入注入（inj）因此将 token 嵌入（具有自己的归一化读取 $\hat{h}_t^0 = \text{Norm}_e(h_t^0)$）直接馈送到更新的两个预激活中：

$$\Delta_t^\ell = \text{softplus}(W_\Delta^\ell n_t^\ell + W_{e,\Delta}^\ell \hat{h}t^0 + b\Delta^\ell)$$
$$c_t^\ell = \text{SiLU}(W_r^\ell n_t^\ell + W_{e,c}^\ell \hat{h}_t^0 + b_r^\ell)$$

$W_{e,\Delta}^\ell$ 和 $W_{e,c}^\ell$ 零初始化。递归 $r_t^\ell = g_t^\ell \odot r_{t-1}^\ell + b_t^\ell$ 否则不变：$\Delta_t^\ell$ 和 $c_t^\ell$ 仍仅依赖于当前时间步输入（$n_t^\ell$ 和 $\hat{h}t^0$），从不依赖于 $r{t-1}^\ell$，因此转换保持精确仿射，相同的并行扫描适用。

A.2.3 Jacobi 精炼器（水平潜在变量如何更新）

图 9：消融自顶向下残差流流动。 将每个 token 的顶层状态反馈到下一 token 的网络底部，通过残差流添加非线性路径。垂直 Jacobi 将此反馈应用于垂直残差流，类似于并行的 Full-Bandwidth Transformer（Wang et al., 2026）；晶格 Jacobi 将其应用于水平潜在变量；最后一个条同时应用两者。我们称之为"Jacobi"因为反馈用三次并行的、教师强制的 Jacobi 扫描训练和评估（J3；附录 A.2.3），以额外前向传递为代价。两种反馈形式都有帮助，且它们复合：16.94（Transformer）和 15.52（单次通过晶格）在两者都有反馈时降至 14.92。FineWeb-Edu 验证困惑度，10B token 训练。

输入注入和 vstream 路径仅使用当前时间步可用的信息，因此基础更新保持跨时间的精确并行扫描。两者都不将更高层的水平潜在变量反馈到下一时间步的较低层。这种自顶向下反馈在逐 token 展开中直接明了，但破坏教师强制训练的单次自底向上扫描，因为底层更新时顶层潜在变量尚不可用。遵循 Zeng et al. (2026); Wu et al. (2026)，我们在训练期间用 Jacobi 迭代近似它。与这些将最终垂直潜在变量反馈为下一个输入的递归进行迭代的工作不同，我们将其应用于水平潜在变量。

扫描。 设 $J \geq 1$ 为总扫描次数：J0 表示基础单次通过，J3 表示基础通过后跟两次精炼扫描。扫描 $j=0$ 自底向上精确运行晶格块，如基础更新中那样，为每层和时间步产生 $r_t^{\ell,(0)}$。每次后续扫描 $j=1,\dots,J-1$ 取前一次扫描的顶部晶格层潜在变量，向后移动一个时间步，并通过 SwiGLU 映射：

$$N_t^{(j)} = W_{J,\text{down}}(\text{SiLU}(W_{J,\text{gate}} \hat{z}t^{(j-1)}) \odot (W{J,\text{up}} \hat{z}t^{(j-1)}))$$
$$\hat{z}_t^{(j-1)} = \text{RMSNorm}(r{t-1}^{\text{top},(j-1)})$$

隐藏宽度 $2d_r$，$\hat{z}$ 在第一个时间步设为零，$N_t^{(0)}=0$。仅底部晶格层 $\ell_0$ 接收校正，添加到其候选内容 $c_t^{\ell_0,(j)} = \text{SiLU}(W_r^{\ell_0} n_t^{\ell_0,(j)} + b_r^{\ell_0})$，从归一化垂直输入 $n_t^{\ell_0,(j)}$ 计算（使用时加上输入注入项；完整更新见第 3.2.2 节）：

$$b_t^{\ell_0,(j)} = (1 - g_t^{\ell_0,(j)}) \odot (c_t^{\ell_0,(j)} + N_t^{(j)})$$

进入相同的仿射递归 $r_t^\ell = g_t^\ell \odot r_{t-1}^\ell + b_t^\ell$。每次扫描从相同的早期块输出和相同的学习初始状态重新运行整个晶格块，参数跨扫描共享，所有层输入和系数重新计算；最终扫描提供块输出。因为 $N_t^{(j)}$ 仅依赖于完全解析的前一次扫描，每次扫描的扫描保持精确仿射和 token 并行；代价是 $J$ 次串行扫描而不是一次。

训练和推理。 $W_{J,\text{gate}}$ 和 $W_{J,\text{up}}$ 从 $\mathcal{N}(0, 0.02^2)$ 初始化，$W_{J,\text{down}}$ 零初始化，因此 J3 模型在初始化时等于其 J0 对应物。我们用固定次数的扫描（$J=3$）训练并通过所有扫描反向传播。推理时，前一 token 的顶层潜在变量已经可用，因此精确递归（$N_t = F(r_{t-1}^{\text{top}})$）可以在单次逐 token 通过中评估而无需精炼扫描（"顺序展开"）；有限次数的扫描不必重现此展开。我们报告三扫描和顺序展开两种评估（第 4.1 节）。
