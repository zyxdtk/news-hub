原标题：OpenAI launches GPT-6 Cyber with stronger exploit research and higher API price than Anthropic and Google

中文摘要： OpenAI 发布安全专用模型 GPT-6 Cyber，经 Daybreak Red 门控计划向获批客户开放。该模型 ExploitGym 得分 48.5%（前代为 32.1%），研究人员用它复现 1724 个 Linux 内核漏洞并为 948 个开发出可用漏洞利用，另发现 81 个 Firefox 高危漏洞，网络安全能力评级升至 Critical。定价为每百万输入 token 20 美元、输出 100 美元，高于前代及 Anthropic、谷歌竞品。模型在蜜罐测试中 99.93% 避免越权攻击

太平洋时间 2026 年 11 月 5 日下午 4:31

OpenAI 今日发布了 GPT-6 Cyber，这是一款专门的安全模型，该公司称其能够发现并利用更多软件漏洞，同时更可靠地遵守研究人员设定的限制。

对于企业安全团队来说，此次发布提供了又一个测试防御和开发修复的工具，但访问需要审批，而且其公布的 token 价格超过了竞争对手 Anthropic 和谷歌的同类网络安全模型。

OpenAI 的开发者文档将 GPT-6 Cyber 定价为每百万输入 token 20 美元、每百万输出 token 100 美元，缓存输入为每百万 token 2 美元。这些基础费率使其高于前代产品和竞争对手的产品。

该模型最初通过 Daybreak Red（OpenAI 面向高级、经授权安全工作的门控访问计划）向选定客户开放。该计划接受个人和组织加入，前提是他们上传供 OpenAI 审查使用的信息，例如你计划使用该模型（以及其他 OpenAI 网络安全模型/产品）的具体防御工作流程。

OpenAI 计划将访问范围扩展至整个该层级，同时通过范围更广、限制更少的 Daybreak Blue 网络安全计划扩大 GPT-6 Astra 的访问。OpenAI 未具体说明目前有哪些组织和个人参与，但表示截至上个月已注册超过 2000 家实体。

与 GPT-5.6 Cyber 相比有哪些变化

OpenAI 将 GPT-6 Cyber 描述为 GPT-6 Astra 的一个变体，接受了针对安全调查的额外训练。其系统卡（system card）解释说，强化学习会奖励在复现崩溃和构建漏洞利用等任务上的成功，同时也奖励尊重授权并准确描述结果的行为。

在该公司的 Preparedness Framework（准备就绪框架）下，其网络安全能力被评为 Critical（危急）级，高于 GPT-5.6 Cyber 的 High（高）级。GPT-6 Astra 此前已获得同样的 Critical 评级。

在测试模型能否利用指定漏洞的 ExploitGym 上，OpenAI 报告 GPT-6 Cyber 得分为 48.5%，而 GPT-5.6 Cyber 为 32.1%。这相当于提升了 16.4 个百分点，相对改进约 51%。

在另一项不提供应用源代码的 Web 应用测试中，GPT-6 Cyber 发现了 40.3% 的漏洞，而 Astra 为 32%。

OpenAI 还推出了 RemoteExploitBench，这是一项涉及 GitLab、PostgreSQL 和 Jenkins 等应用中已知漏洞的评估。GPT-6 Cyber 完成了 95% 的任务，而 Daybreak Blue 下的 Astra 拒绝了所有任务。这一对比既衡量了模型能完成什么，也衡量了其访问配置允许什么。

这一 95% 的数字来自与 VentureBeat 8 月份 GPT-5.6 Cyber 报道中所引用的完成率基准不同的另一项评估。相同的标题百分比并不能证明两代模型性能相当。

Linux 和 Firefox 提供了基准测试之外的证据

OpenAI 表示，使用 GPT-6 Cyber 的研究人员复现了 1724 个 Linux 内核漏洞，并为其中 948 个开发了可用的漏洞利用程序。在相同的研究设置下，GPT-5.6 Sol 为 166 个漏洞开发了漏洞利用程序。

该公司表示，已向 Linux 维护者披露了 304 个严重发现并附带了建议补丁，目前仍在继续处理更多修复。漏洞利用总数不应被理解为之前未知或已修复缺陷的数量。

对于 Firefox，OpenAI 报告了 81 个此前未知的漏洞，Mozilla 将其归类为高严重性，另有证据表明另外 30 个已知问题应获得更高的严重性评级。据 OpenAI 称，研究人员提供了可复现的测试和修复建议；Mozilla 在收到报告后开始整合修复。

客户背书也描述了相关工作。CodeRabbit CEO Harjot Gill 在公告中表示："GPT-6 Cyber 是我们测试过的用于安全审查的最强模型。"CodeRabbit 报告称，在其内部基准上，该模型发现的中高严重性问题比其生产模型多 66%。

这些客户报告支持了该模型的实际应用价值，但公告并未建立跨竞争对手厂商的统一、独立管理的性能比较。

资料来源：OpenAI 的 GPT-6 Cyber 和 GPT-5.6 Cyber 模型页面；Anthropic 定价；谷歌云定价。访问：Anthropic Mythos、Argon Cyber Permissive 和 Flash Cyber。

GPT-6 Cyber 的输入价格比 GPT-5.6 Cyber 高 60%，输出价格高约 33%。其基础输入和输出费率是 Mythos 5.1 的两倍，是 Argon Cyber Permissive 的五倍。

缓存和请求大小使这一比较更加复杂。OpenAI 列出 GPT-6 Cyber 的缓存写入价格为每百万 token 25 美元（30 分钟）或 50 美元（12 小时）。GPT-5.6 Cyber 超过 272,000 输入 token 的请求，将在整个请求中按两倍基础输入费率和 1.5 倍输出费率计费。Anthropic 列出 Mythos 5.1 的缓存写入价格为 12.50 美元（五分钟）或 20 美元（一小时）；其文档还指出，不同代模型的分词方式有所不同。谷歌针对普通 Argon 的临时促销不包含 Cyber Permissive。

这些是 token 价格比较，并非对每项已完成调查成本的衡量。不同模型在得出经验证的发现时，可能消耗不同数量的上下文、推理和重复的工具输出。沙箱基础设施和分析师审查也会影响部署经济性。

竞争对手提供进入受限安全工作的不同途径

Anthropic 的 Mythos 5.1 面向网络安全和生物学研究，访问仅限于经过审核的组织。该公司还在 Mythos 5.1 上运行 Claude Security，并通过其 Cyber Verification Program（网络验证计划）接受高级网络能力的申请。

谷歌的 Argon Cyber Permissive 支持漏洞发现、逆向工程、漏洞利用验证和补丁生成。客户通过 Fairwind 或其谷歌团队申请；较便宜的 Flash Cyber 模型获批并不会自动授予 Argon 访问权限。

这些产品在重叠的工作领域展开竞争，但仅凭公布的价格无法看出哪个模型能为特定代码库或安全团队产出最有用的发现。

OpenAI 将授权置于部署的核心

OpenAI 明确将其新的范围遵循评估与早前的 Hugging Face 事件联系起来。其 ExploitGym Honeypot（蜜罐）测试在指定目标旁边放置具有诱惑性、存在漏洞的辅助服务。成功要求模型识别出攻击这些服务超出了任务范围。

在没有部署安全提示的情况下，GPT-6 Cyber 在 99.93% 的测试中避免了这些未授权攻击，而 GPT-5.6 Cyber 为 94.49%。在有提示的情况下，它在所有测试用例中都保持在范围内。这些结果描述的是评估表现，而非对生产环境行为的保证。

OpenAI 将这种训练与监控和账户控制相结合。Daybreak Red API 访问通常需要经过批准的网络地址。根据公告，采用零数据保留（Zero Data Retention）的 API 客户通常必须使用 Private Safety Processing（私有安全处理），该功能会检查由客户存储 30 天的加密交互记录。

该公司还推出了 Daybreak Red for Critical Infrastructure（面向关键基础设施的 Daybreak Red），这是为测试关键系统的获批团队设立的额外访问组，并强调了其现有的 10 亿美元计划，为资源有限的防御者提供访问补贴。

对于安全负责人来说，采购决策不仅在于智能体能否演示漏洞利用，还包括该智能体是否恪守任务范围、能否产生工程师可复现的证据，以及能否交付足够多的经验证发现，以证明其价格以及围绕它的审查工作是合理的。
