📅 2026-10-15 📄 arxiv 🔗 原文链接

原标题：Velox: Spatial Memory Makes World Models Efficient

中文摘要： Velox是一种免训练的注意力路由器，旨在解决分块视频世界模型中KV缓存随生成块增长而导致的推理减速问题。该方法将历史块表示为带深度区间的相机视锥体切片，通过新近优先多重扭曲获取当前块深度，并用视锥体切片重叠软性调节各层模型导出的块重要性；未覆盖区域保留原始模型路由。固定token块粒度与FlashAttention分块执行匹配，几何构建与去噪异步并行。实验显示第48块时注意力加速4.36倍、去噪加速2.43倍，WBench导航任务质量接近稠密注意力基线。

摘要

视频世界模型将动作和相机运动转化为长视觉推演，使视频成为交互式模拟的自然界面。这种交互需要响应式生成，而连贯的推演必须保留已生成内容的视觉记忆。分块视频扩散模型通常将此上下文保存在不断增长的KV缓存中，因此后续块会逐渐变慢。为解决这一瓶颈，我们提出了Velox，一种免训练的注意力路由器，利用来自流式几何的视锥体切片对应关系进行区域级上下文选择。Velox将历史块表示为带有深度区间的相机视锥体切片，并通过新近优先多重扭曲获得当前块深度。对于覆盖良好的区域，视锥体切片重叠会软性调节每层模型导出的块重要性；未覆盖区域则保留模型导出的路由，不受几何偏置影响。固定的token块粒度与FlashAttention风格的分块执行相匹配，并减少了随推演长度增长的注意力项。视锥体切片构建与去噪在同一H200上异步运行。在第48块时，Velox将注意力加速4.36倍，去噪加速2.43倍。在完整的158例WBench导航分割上，其无API平均值与稠密LingBot-Fast-Cam相差不超过0.15分。请参阅我们的项目页面了解更多详情。

1 引言

视频世界模型正成为交互式模拟的实用接口。用户指定动作轨迹或相机运动，模型通过生成未来视频帧来推进世界。这一方向建立在视频扩散Transformer和大型视频基础模型的快速进展之上（Ho等，2020；Rombach等，2022；Peebles和Xie，2023；Blattmann等，2023；Chen等，2024b；Yang等，2024b；Kong等，2024；Wan等，2025；Ma等，2025）。最近的工作越来越多地针对可控的长视频世界，而非孤立的短片段（Alonso等，2024；Valevski等，2024；Bruce等，2024；Parker-Holder等，2024；Sand.ai，2025；Gao等，2026；HY-World等，2026）。对于这些模型，上下文管理是一个核心方法论挑战。过去的帧携带了未来帧必须遵循的外观、几何和物体状态。如果无法访问正确的历史，长推演会漂移、遗忘重访区域，或不一致地重新合成同一场景。

保留这种历史最直接的方法是保留不断增长的视觉上下文。分块或因果视频扩散模型让每个新块通过KV缓存关注历史帧token。稠密FlashAttention使其在中等长度下变得实用（Dao等，2022；Dao，2023），因果扩散或自强制训练使长推演变得自然（Chen等，2024a；Huang等，2025b）。然而，成本随着生成块数量的增加而增长。即使当前相机仅与过去场景的一小部分重叠，后续块也会继承更大的上下文。因此，当长期一致性最重要时，逐块生成恰恰会变得越来越慢。

这促使我们进行上下文选择而非朴素的上下文累积。帧和视图记忆方法选择较小的相关过去观测集合。Context-as-Memory通过相机视场重叠检索历史视图，VMem存储面片索引的视图以实现一致的重访（Yu等，2025a；Li等，2025）。AnchorWeave及相关工作（Xiao等，2025；Wu等，2025；Wang等，2026）进一步通过ControlNet（Zhang等，2023a）注入来自持久记忆的扭曲渲染，以稳定相机控制的生成。这些方法表明并非所有过去的帧都同样有用，图1总结了从稠密历史到视图级检索的演进。然而，帧级选择对Transformer注意力来说仍然粗糙。它为活动块中的所有区域提供相同的选定上下文，尽管动态场景通常需要局部时间连续性，且同一噪声块中的不同区域可能依赖于过去的不同部分。将扭曲点渲染注入模型输入的方法也可能需要架构适配或微调，这限制了预训练视频生成器的直接重用。

受逆渲染工作启发（Kerbl等，2023；Mildenhall等，2021），我们观察到几何已被观测的区域应主要关注其对应的过去区域。相比之下，新揭示的或不确定的区域可能需要模型导出的语义上下文和局部时间邻居。因此，同一噪声块中的道路块、立面块和新揭示的天空不一定需要关注相同的过去视图。于是，问题不再仅仅是检索哪些帧，而是长上下文视频生成能否为每个区域分配其自己的相关历史，同时保持局部运动连续性并保持预训练生成器不变。

我们在FlashAttention（Dao，2023）的分块执行模型中的token块级别考虑这个问题。我们的关键洞察是，带有深度区间的相机视锥体切片可以在分块注意力使用的相同粒度上提供区域特定的路由信号。Velox不添加新的条件分支或微调视频生成器，而是将生成的历史总结为逐块视锥体切片，并使用它们的重叠来指导每个当前区域应该看到哪些历史KV token块。对于每个目标块，Velox通过新近优先多重扭曲获得查询侧深度，并通过世界空间OBB视锥体切片重叠对查询块和历史块进行评分。在覆盖良好的区域，该分数在选择之前软性重新加权每层模型导出的块重要性。未覆盖区域保留模型导出的路由，不受几何偏置影响。前一块保留和全局对齐的Gilbert邻域保持局部运动连续性，无需单独的跨块接缝表。

在48块计时轨迹和158例WBench导航分割上（Ying等，2026），Velox降低了不断增长的长上下文注意力成本，同时保持总体质量接近稠密注意力。其优势随着生成块数量的增加而增长。在第48块时，注意力延迟从稠密FlashAttention的约34.2毫秒降低到7.8毫秒，加速4.36倍。在相同的单H200异步设置下，去噪时间从约7.19秒降低到2.96秒。基于LingBot-Fast-Cam构建（Gao等，2026），Velox在WBench无API平均值上与稠密注意力相差不超过0.15分，并将19指标总体平均值从75.52提高到75.60。这些结果支持以下范围性声明：软视锥体切片路由可以缓解后期块的注意力瓶颈，而不会实质性降低基准质量。

我们的贡献可以总结为：

  • 我们提出了Velox，一个免训练框架，使用视锥体切片对应关系来降低分块视频世界模型中不断增长的KV注意力成本。
  • 我们设计了一种软几何融合规则，使用OBB视锥体切片重叠来调节每层模型导出的块重要性，同时为未覆盖区域保留无偏回退。
  • 我们实现了带有全局对齐Gilbert KV存储、优化稀疏注意力内核和与去噪在同一H200上的异步视锥体切片构建的Velox，在第48块达到4.36倍注意力加速和2.43倍去噪加速。

图1：长期世界生成的三种上下文管理范式。稠密分块生成保持不断增长的视觉上下文。帧记忆方法使用相机重叠检索一小组过去视图。Velox使用视锥体切片对应关系将每个当前潜区域路由到紧凑的、几何相关的历史块。

2 相关工作

2.1 视频世界模型与空间记忆

视频生成已经从潜扩散发展到可扩展的扩散Transformer和整流流（Ho等，2020；Rombach等，2022；Blattmann等，2023；Peebles和Xie，2023；Esser等，2024），基础模型提供了强大的视觉先验（Yang等，2024b；Kong等，2024；Wan等，2025；HaCohen等，2024；Ma等，2025；Gao等，2025；Team等，2025）。长视频方法通过渐进生成、自推演训练和因果分块扩展这些先验（Kim等，2024；Jin等，2024；Henschel等，2024；Xie等，2024；Gu等，2025；Chen等，2024a；Huang等，2025b；Sand.ai，2025；Chen等，2025a；Liu等，2025a），而交互模型针对可控的持久世界（Bruce等，2024；Parker-Holder等，2024；Alonso等，2024；Valevski等，2024；Feng等，2024；Zhang等，2025d；Che等，2024；Yang等，2024a；Yu等，2025b；Decart等，2024；Gao等，2026；HY-World等，2026；Shen等，2026）。这些方向使历史管理成为核心：更多上下文支持一致性但使稠密注意力越来越昂贵。空间记忆方法通过检索视图、保留重访或扩展重建世界来解决这一矛盾（Yu等，2025a；Li等，2025；Xiao等，2025；Wu等，2025；Huang等，2025a；Chen等，2025b；Yu等，2024b；Yu等，2024a；Engstler等，2024）。相机感知和可控生成（Yu等，2024c；YU等，2025；Bai等，2025；He等，2024；He等，2025；Yang等，2025c；Ren等，2025；Yu等，2026）和流式重建（Wang等，2024b；Leroy等，2024；Cabon等，2025；Yang等，2025a；Wang等，2024a；Wang等，2025a；Wang等，2025b；Keetha等，2025）进一步使可投影记忆变得实用。Velox使用这种记忆来路由预训练注意力，而不是添加条件通路或重新训练的记忆模块。

2.2 高效注意力与上下文路由

长上下文Transformer通过稀疏性、局部性、压缩、状态重用、重要命中选择和KV驱逐来降低注意力成本（Kitaev等，2020；Zaheer等，2020；Beltagy等，2020；Wang等，2020；Dai等，2019；Liu等，2023；Lee等，2025；Jiang等，2024；Li等，2024；Zhang等，2023b；Kwon等，2023；Li和Wang，2026），而FlashAttention是稠密IO感知基线（Dao等，2022；Dao，2023）。视频加速器还通过自适应稀疏性、缓存和量化注意力利用空间、时间、去噪步骤和特征规律性（Zhang等，2025c；Xi等，2025；Yang等，2025b；Zhang等，2025b；Xia等，2025；Ding等，2025；Zhang等，2024；Zhang等，2025a；Liu等，2024b；Liu等，2025b；Liu等，2024a；Guo等，2024；Nawaz等，2026；Feng等，2026）。这些方法通常从位置、缓存特征或注意力统计中导出稀疏性，而帧记忆方法选择视图但在其中保留稠密注意力。Velox通过使用投影对应作为区域特定注意力路由的软先验连接这两个方向，并带有模型导出的回退和时间保障。

3 方法

概述。长期生成需要持久的视觉历史，但稠密KV注意力使每个当前区域处理所有保留的块。Velox保持预训练生成器和条件接口不变，仅修改当前查询块和历史KV块之间的推理时可见性关系。它将历史表示为带有深度区间的相机视锥体切片，使用它们的重叠作为每层模型导出块重要性的软先验，并使每个当前区域暴露于紧凑的路由。图2总结了这个免训练流程。

3.1 预备知识：分块世界生成

考虑一个自回归生成块 x₀, x₁, ... 的视频世界模型。在去噪步骤 s，块 c 具有噪声潜token z_c ∈ ℝ^(T×H×W×d)、文本/动作控制 (y_c, a_c) 和相机序列 π_c = {π_{c,t}}{t=1}^T，其中 T 是潜帧数，H×W 是潜空间网格，d 是通道维度，每个 π{c,t} 将3D场景位置映射到对应的潜/图像视图。参数为 θ 的预训练扩散Transformer预测：

ε̂c = f_θ(z_c, s, y_c, a_c, π_c, 𝒞{<c})，　　(1)

其中 𝒞_{<c} 是保留的历史上下文，在Transformer中实现为视觉KV缓存。如果 𝒞_{<c} 包含所有之前的块，即使当前相机只能看到过去场景的一小部分，注意力成本也会随历史长度增长。

我们在块粒度上操作。设 σ 为全局对齐Gilbert序，𝒞_c = {B_i}_{i=1}^N 将当前块划分为每块 b_tok 个token的块。历史KV块使用相同大小，M_c 表示块 c 之前可见的历史KV块数量。对于固定块 c 和层 ℓ，记 Q_i 为当前块 B_i，(K_r, V_r) 为可见KV块 r ∈ {1, ..., M_c}。

该块大小匹配FlashAttention风格的执行（Dao等，2022；Dao，2023），后者流式处理固定的查询和KV分块。抽象地，历史注意力分解为：

Σ_{i=1}^N Σ_{r=1}^{M_c} TileAttn(Q_i, K_r, V_r)，　　(2)

其中每次交互计算 Q_i K_r^⊤，更新在线softmax，并应用 V_r。稠密FlashAttention仍然调度每个当前-历史对。固定路由在启动前移除整个KV分块，同时保持块连续的聚集。token级或可变大小的稀疏性将需要不规则的行级索引。

活动注意力窗口按全局对齐Gilbert秩排序。块 i 的稠密视觉注意力使用每个可见块：

Attn_dense(Q_i) = softmax(Q_i K_{1:M_c}^⊤ / √d) V_{1:M_c}。　　(3)

Velox在每个Transformer层 ℓ 用路由 ℛ_i^ℓ ⊆ {1, ..., M_c} 替换 1:M_c。层索引很重要，因为每层产生自己的池化查询-键重要性分布，而几何对应在去噪步骤内的各层之间共享。

图2：Velox概述。Velox保持预训练分块视频生成器不变，并用视锥体切片路由注意力替换稠密历史注意力。历史块由带有深度区间的逐块视锥体切片总结，目标查询块通过多重扭曲获得深度，块路由在添加时间和全局Gilbert保障之前软融合视锥体切片重叠与层特定模型重要性。索引稀疏注意力然后产生下一个块。

3.2 视锥体切片对应

Velox不通过脆弱的重建样本身份进行路由。相反，它将每个历史KV块存储为一个或多个视锥体切片基元，每个基元包含源相机token矩形和鲁棒深度区间：

ψ_{j,r,m} = (r, t, R_{j,r,m}, [z⁻{j,r,m}, z⁺{j,r,m}], ν_{j,r,m})，　　(4)

这里 j、r、m 和 t 分别索引源块、全局Gilbert块、基元和潜帧。源相机token矩形为 R_{j,r,m}，其百分位深度区间为 [z⁻{j,r,m}, z⁺{j,r,m}]，ν_{j,r,m} 存储有效性统计。跨越帧或块边界的块具有多个基元，在评分前按源块聚合。

历史视锥体切片构建。在块 j 解码后，重建后端为生成的帧产生深度、置信度、掩码和相机位姿。Velox暂时将可靠的深度样本反投影到3D，将其投影到该块的潜相机中，按全局Gilbert块分桶，并为每个块片段计算深度分位数阶梯。设 Quantile_p(·) 为有效源相机深度的经验第p百分位数，p_lo 和 p_hi 为固定的低和高百分位水平。视锥体切片区间为：

z⁻{j,r,m} = Quantile{p_lo}(𝒵_{j,r,m})，　z⁺{j,r,m} = Quantile{p_hi}(𝒵_{j,r,m})，　　(5)

其中 𝒵_{j,r,m} 是为该基元收集的有效源相机深度集合。有效性门控要求足够的样本数、足够的覆盖token数、有界的相对深度散布和最小视锥体切片厚度。这为存储的历史产生紧凑的视锥体切片表，而无需在路由评分中携带稠密的重建几何。

目标侧多重扭曲深度。为了对当前查询块评分，Velox还需要目标相机中的深度区间。当前实现通过新近优先多重扭曲获得此Q深度。它缓存最近重建块的第一和最后像素帧深度，然后将所有缓存帧前向扭曲到目标块的潜相机中。对于每个目标token u，设 f 索引缓存的源帧，n_f(u) 为落在 u 上的扭曲深度样本数，k_warp 为样本下限。具有至少 k_warp 个样本的最新缓存帧获胜：

f(u) = max{f | n_f(u) ≥ k_warp}，　z_Q(u) = Quantile₅₀(𝒵_{f(u),u})。　　(6)

这里 𝒵_{f,u} 是从缓存帧 f 扭曲到目标token u 的深度样本集合，Quantile₅₀ 是中位数深度。如果没有缓存帧达到样本下限，f*(u) 未定义，该token没有Q深度，该行可以回退到模型导出的路由。直观上，该规则偏好最新的可靠几何，同时仍允许在当前相机返回到先前看到的表面时由较旧的观测填充重访。附录B.3形式化了源过滤、目标相机重投影、胜者选择和查询块聚合。

世界空间视锥体切片重叠。给定具有多重扭曲深度的查询块 i 和附加到KV块 r 的历史基元，Velox用面向相机的有向包围盒近似每个相机视锥体切片。设 Ψ_r = {ψ_{j,r,m}} 为附加到历史块 r 的基元集合，𝒪_i^Q 和 𝒪_{j,r,m}^K 为世界坐标中的查询和历史OBB。几何分数为：

g_{i,r} = max_{ψ_{j,r,m}∈Ψ_r} Vol(𝒪_i^Q ∩ 𝒪_{j,r,m}^K) / (Vol(𝒪_i^Q) + Vol(𝒪_{j,r,m}^K) − Vol(𝒪_i^Q ∩ 𝒪_{j,r,m}^K) + ε)。　　(7)

这里 ε＞0 防止除零。该实现通过分离轴测试后用确定性OBB网格估计交集，然后对多片段KV列应用分组片段聚合。该分数是视图感知的，因为目标和历史块都携带相机方向、token覆盖范围和深度范围。它还避免将对应关系绑定到精确的重建样本身份，后者在生成视频伪影下是脆弱的。

覆盖率。路由器将几何分数与几何信任分离。当一个token的多重扭曲深度位于至少一个有效的历史视锥体切片内（该切片在空间和深度裕度内包含token光线）时，该token被覆盖。块覆盖率为：

ρ_i = (1/|B_i|) Σ_{u∈B_i} 1[∃r, ∃ψ_{j,r,m}∈Ψ_r: u ∈ Π_c(ψ_{j,r,m}) ∧ z_Q(u) ∈ [z⁻{j,r,m}, z⁺{j,r,m}]]，　　(8)

其中 Π_c(ψ_{j,r,m}) 表示视锥体切片基元在当前目标视图中的投影覆盖范围，η_cov 是覆盖率阈值。当 ρ_i ≥ η_cov 时块被覆盖。因此 g_{i,r} 识别哪些历史KV块与当前视锥体重叠，而 ρ_i 决定几何是否足够可靠以驱动路由。

3.3 基于视锥体切片对应的Velox注意力

几何分数应指导路由而不对每层施加相同的硬块集。重建可能留下Q深度空洞，陈旧的扭曲深度可能在去遮挡后残留，不同的Transformer层可能偏好不同的视觉证据。硬几何top-K路由会覆盖这些层特定的偏好。Velox转而使用视锥体切片重叠来调节模型自身的块重要性。

层特定模型重要性。设 q̄_i^ℓ 为层 ℓ 块 i 中的平均查询向量，k̄_r^ℓ 为可见KV块 r 中的平均键向量。我们计算：

p_{i,r}^ℓ = softmax_r(q̄_i^ℓ (k̄_r^ℓ)^⊤ / √d)，　　(9)

其中softmax在所有可见KV块上归一化。该分布保留了预训练Transformer的层特定有用上下文概念。

软几何融合。对于覆盖良好的查询块（ρ_i ≥ η_cov），我们首先抑制低于或等于噪声阈值 τ 的重叠值并重新缩放剩余值：

ĝ_{i,r} = 1[g_{i,r} ＞ τ] · min(g_{i,r}/g_ref, 1)，　　(10)

其中 g_ref 将观测到的视锥体切片IoU范围映射到有界的提升。然后我们将模型重要性乘以此几何先验并重新归一化：

p̃{i,r}^ℓ = p{i,r}^ℓ (1 + λĝ_{i,r}) / Σ_{r'=1}^{M_c} p_{i,r'}^ℓ (1 + λĝ_{i,r'})。　　(11)

这里 λ＞0 控制融合强度。g_{i,r} ≥ g_ref 的块获得最大乘数 1+λ，而没有经验证的几何重叠的块保留其原始模型重要性。由于乘法作用于 p_{i,r}^ℓ，几何可以提升模型支持的对应关系，而不为每层分配相同的路由。

覆盖和未覆盖路由。设 𝒫_{c-1} 为前一块的KV块。路由实体化器在选择较旧历史之前保留这些块，因此局部时间证据消耗与长程路由相同的有限预算。对于覆盖良好的块，Velox用最大的融合分数填充剩余的 K_cov − |𝒫_{c-1}| 个位置：

ℛ_i^ℓ = 𝒫_{c-1} ∪ Top_{K_cov−|𝒫_{c-1}|}({p̃{i,r}^ℓ : r ∉ 𝒫{c-1}})，　ρ_i ≥ η_cov。　　(12)

对于几何覆盖不足的块，Velox保持模型分布不变。它对 {p_{i,r}^ℓ} 排序，取累积质量达到 η_imp 的最小前缀，受路由上限 K_unc 约束：

ℛ_i^ℓ = 𝒫_{c-1} ∪ Prefix_{η_imp, K_unc−|𝒫_{c-1}|}({p_{i,r}^ℓ : r ∉ 𝒫_{c-1}})，　ρ_i ＜ η_cov。　　(13)

该分支让预训练注意力信号处理天空、新暴露区域和视锥体切片表中的空洞。校准配置使用 τ=0.1、g_ref=0.2、λ=2、η_cov=0.9、K_cov=80 和 K_unc=150。

全局对齐Gilbert邻域。Velox通过Gilbert块上的全局/窗口26邻域邻接保持短程视频连续性。早期版本使用重复的块局部Gilbert序和单独的跨块接缝表。当前实现改为增量构建单一的全局对齐Gilbert块域。它一次性构建单块Gilbert曲线，根据块奇偶性和基准帧出口象限翻转块局部坐标，从而为每个生成的块匹配全序列Gilbert前缀。跨块边界邻居在可见全局窗口中成为普通的时间邻居。无需单独的接缝表。

设 ℒ_i^glob 为查询块 i 在此全局Gilbert块域中的可见26邻域，ℱ₀ 为可选的参考帧块。实体化路由为：

R̄_i^ℓ = ℛ_i^ℓ ∪ ℒ_i^glob ∪ ℱ₀。　　(14)

空间邻居和可选参考块作为确定性保障添加在路由预算之外。

稀疏视觉注意力输出为：

Attn_Velox(Q_i) = softmax(Q_i K_{R̄i^ℓ}^⊤ / √d) V{R̄_i^ℓ}，　　(15)

在每个Transformer层。通过此公式，Velox保留每层模型导出的排序，仅在对应关系可靠处注入几何，并仍向稀疏内核暴露有界的块列表。

Gilbert KV布局。Velox以路由使用的相同全局对齐Gilbert序存储当前和历史视觉KV块。这使相邻图像区域在内存中保持接近，并减少每次调用的置换开销。该布局是一种实现优化。公式(11)和(15)中的软路由独立于特定的空间填充曲线，但全局对齐Gilbert使局部邻域保持和块连续KV存储共享一个坐标系。

3.4 复杂度与设计原理

Velox的益处来自分离稠密注意力耦合在一起的两个量：世界模型保留的视觉记忆量和暴露给每个查询块的KV块数。使用固定块大小 b_tok，N 个当前块和 M_c 个可见KV块之间的稠密注意力成本为：

𝒪(N M_c b_tok² d)。　　(16)

随着保留更多块，即使当前相机只需要过去的一小部分，M_c 也会增长。Velox保持记忆可用但限制暴露的路由。设 K_max = max(K_cov, K_unc)，Δ_safe = |ℒ_i^glob ∪ ℱ₀| 为小的附加保障预算：

𝒪(Σ_{i=1}^N |R̄_i^ℓ| b_tok² d) ≈ 𝒪(N(K_max + Δ_safe) b_tok² d)　每个稀疏注意力层。　　(17)

该近似突出了预期机制：路由和保障预算是固定的，而 M_c 随历史长度增长。

相同的块单元也匹配FlashAttention风格的执行。稠密FlashAttention高效地评估每个查询-键分块，但仍调度所有 N·M_c 个分块对。Velox将分块调度改为 Σ_i |R̄_i^ℓ|。跳过的块同时移除了 QK^⊤ 分块乘积和KV分块加载。因此，当注意力受内存限制时路由减少KV流量，当注意力受计算限制时路由减少分块矩阵乘积。校准路由在每个Transformer层应用，因此增长的历史项在整个去噪网络中是有界的。

4 实验

4.1 实现细节

我们在LingBot-Fast-Cam推理栈上实例化Velox（Gao等，2026），使用Wan风格视频扩散Transformer。报告的配置使用新近优先多重扭曲Q深度、世界空间OBB视锥体切片IoU、分组片段聚合和全局对齐Gilbert KV存储。我们在每个Transformer层对覆盖良好的行应用固定软几何融合，参数为 τ=0.1、g_ref=0.2、λ=2 和 η_cov=0.9。覆盖的行保留 K_cov=80 个块。未覆盖的行使用模型导出的累积质量路由，K_unc=150 且无路由大小下限。

测量的稀疏路径是原生Triton索引块稀疏注意力实现，而非带Python掩码的稠密调用。当前查询每块重排一次，KV缓存以全局对齐Gilbert序存储，内核以运行时路由长度界限消费路由块列表。前一块始终保留在路由预算内，而当前块局部邻居和参考帧块作为确定性保障。视锥体切片状态以两块新鲜度滞后异步准备，因此块 c 通常消费到块 c−2 为止的几何。在报告的计时轨迹中，DiT去噪和异步几何构建在一块H200上并发运行。

我们在WBench导航分割的全部158个案例上评估质量（Ying等，2026）。三个基于LingBot的行使用相同的生成案例和Gemini评判器进行VLM评分指标。已发表的WBench行使用官方豆包评判器，因此依赖评判器的值不应在这两组之间比较。因此我们包含一个无API平均值，它排除VLM评分的设置指标，并可在不同评判后端之间比较。

4.4 几何与模型重要性一致性

软融合假设视锥体切片重叠识别有用的历史而不施加硬替换集。我们使用离线亲和度转储审计这一关系。对于层 ℓ、阈值 τ 和覆盖良好的查询块 i，设 ℋ_i 为移除自身块后的 K_hist 个候选历史块，𝒢_i(τ) = {h ∈ ℋ_i : g_{i,h} ＞ τ} 为 n_i(τ) 个正重叠块，𝒫_i⁵⁰(ℓ) 为在批和头上平均亲和度后模型偏好的top-50。

设 a_i(ℓ,τ) = |𝒢_i(τ) ∩ 𝒫_i⁵⁰(ℓ)|，几何召回率为 R_geo(ℓ,τ) = 𝔼_i[a_i(ℓ,τ)/n_i(τ)]，随机期望为 50/143 = 0.350。固定预算集合 𝒰_i⁵⁰(ℓ,τ) 包含所有正重叠块和达到50所需的最高重要性外部块。其一致性为 R₅₀(ℓ,τ) = 𝔼_i[|𝒫_i⁵⁰(ℓ) ∩ 𝒰_i⁵⁰(ℓ,τ)|/50]。我们省略没有正重叠或非有限分数的行，并对来自四个校准场景最后一块和四个去噪步骤的至少0.9覆盖率的行取平均。

在 τ=0.1 时，表2显示一致性高于随机期望，层14达到 R_geo=0.7302 和 R₅₀=0.8909。层间变化促使保留每个模型导出的分布而非施加层不变的几何集合。在48个池化重要性网格的单独校准中，λ=2 和 g_ref=0.2 将融合top-80正重叠召回率从0.602提高到0.852，同时改变了9.0%的选定块。该工作点增加了测量的几何偏置而没有替换模型排序。

总体分数不能显示推演如何随时间演变，因此我们还视觉比较两个模型。图4显示了从相同输入帧开始并遵循相同相机轨迹的稠密LingBot-Fast-Cam和Velox的推演。我们在每个推演的固定比例处采样帧，而非为每个案例选择特定时刻。附录A.2提供了额外案例。

5 结论

我们提出了Velox，一种免训练路由器，将空间记忆投影到当前潜相机视图中，并使用视锥体切片重叠调节层特定块重要性，同时保留模型导出的回退和局部时间保障。在第48块，Velox通过在一块H200上的异步几何构建将注意力加速4.36倍，去噪加速2.43倍。在全部158个WBench导航案例中，它与稠密LingBot-Fast-Cam的无API平均值相差不超过0.15分，并略微提高了19指标总体平均值。这些结果表明，区域级空间对应可以将持久世界记忆转化为长期生成的实用路由信号。

我们在来自两条导航轨迹的池化查询-键分布和视锥体切片重叠矩阵上校准固定融合强度。校准包含48个网格，涵盖四个代表性层、两个去噪步骤和三个推演长度。正重叠值的中位数为0.211，这促使重新缩放而非乘以原始IoU。在测试的设置中，λ=2 和 g_ref=0.2 是在融合top-80中恢复至少85%正重叠块同时最多改变25%仅模型选择的最弱组合。具体而言，正重叠召回率从0.602增加到0.852，选定集合平均改变9.0%。低于或等于 τ=0.1 的值不获得提升。

附录B 实验实现细节

Velox在LingBot-Fast-Cam推理栈上实例化（Gao等，2026），使用Wan风格视频扩散Transformer。其路由后端使用视锥体切片匹配：存储的块提供源相机token矩形和鲁棒深度区间，目标查询块通过多重扭曲获得Q深度，公式(7)提供世界空间OBB重叠分数。

B.1 报告的路由配置

报告的配置仅在 ρ_i ≥ 0.9 时应用公式(11)中的固定融合。使用 λ=2、g_ref=0.2、τ=0.1 和 K_cov=80。低于覆盖率阈值的行保留仅模型累积质量路由，上限为 K_unc=150，无最小路由大小下限。前一块在这些预算内保留。然后添加全局Gilbert邻居和参考帧块作为保障。相同的稀疏路由规则在每个Transformer层应用。

B.2 视锥体切片几何的相机位姿对齐

视锥体切片表在LingBot-map相机到世界坐标系中重建，而视频生成器使用的块相机来自ViPE位姿。LingBot-map在流式重建期间不接受外部相机位姿。因此Velox在多重扭曲、OBB构建、视锥体切片IoU和覆盖率估计之前将每个目标ViPE相机映射到重建坐标系。

设 (Rᵛ, pᵛ) 和 (Rᴸ, pᴸ) 为最近匹配的ViPE和LingBot-map相机到世界位姿。在已见相机中心上的对齐拟合提供正尺度 α，最新位姿对定义桥接旋转 R_b = Rᴸ(Rᵛ)ᵀ。对于目标ViPE相机 (R_qᵛ, p_qᵛ)，报告的相对对齐构造：

R̂_q = R_b R_qᵛ，　p̂_q = pᴸ + R_b(α(p_qᵛ − pᵛ))。　　(18)

该构造将最新ViPE位姿精确映射到最新LingBot-map位姿。它还保留目标相机相对于该锚点的相对旋转和缩放平移。视锥体切片构建器消费 Ĉ_q⁻¹，其中 Ĉ_q = [R̂_q | p̂_q]，作为目标世界到相机矩阵。在评分之前，实现在当前桥接下刷新历史切片相机，使缓存几何和目标查询共享一个坐标系。

B.3 查询块深度的新近优先多重扭曲

当前噪声块不提供重建深度图，但每个查询块需要目标相机深度区间用于几何匹配。仅使用最新重建帧会在相机旋转或场景重访后留下空洞。汇集所有历史扭曲也不可取，因为陈旧和最近的观测可能在同一目标token中放置不同的表面。多重扭曲通过在计算任何深度统计之前选择具有足够支持的最新源帧来解决这一歧义。

有界源缓存。对于每个重建块，Velox缓存其第一和最后帧的像素深度、相机位姿、内参、置信度值和有效性掩码。环形缓冲区保留最近的 K 个块，最多提供 2K 个源帧。对于源帧 f，像素 p 仅在其深度 D_f(p) 有限且超过 ε_z、其置信度高于配置的下百分位截断、且通过可用的静态区域掩码时保留。可选的天空掩码可进一步拒绝不可靠的远距离区域。报告的配置使用 K=30、ε_z=0.01，无天空拒绝。它丢弃具有有效深度的像素中置信度值最低的20%。每个缓存深度图与其自己的LingBot-map位姿配对，即该深度重建时的相机位姿。

扭曲到目标潜相机。设 K_f 和 [R_f | t_f] 为源内参和世界到相机位姿。对于具有齐次坐标 p̄ 的有效源像素，多重扭曲首先恢复其世界点：

x_p^f = D_f(p) K_f⁻¹ p̄，　X_{f,p}^w = R_fᵀ(x_p^f − t_f)。　　(19)

对于目标潜帧 t，设 K_t^Q 和 [R_t^Q | t_t^Q] 为来自公式(18)的内参和对齐世界到相机位姿。源点变为：

x_{f,p,t}^Q = R_t^Q X_{f,p}^w + t_t^Q，　p̃{f,p,t}^Q = π(K_t^Q x{f,p,t}^Q)，　　(20)

其中 π 应用透视除法。位于目标相机后方或目标图像之外的样本被丢弃。如果一个潜token跨越 h_c × w_c 个目标图像像素，投影像素 (x̃, ỹ) 被分配到token坐标 (⌊ỹ/h_c⌋, ⌊x̃/w_c⌋)。x_{f,p,t}^Q 的第三坐标提供其目标相机深度。我们将分配给token u 的深度多重集合记为 𝒵_{f,t,u}，其大小为 n_{f,t,u}。

最新可靠源。缓存帧从最旧到最新排序。多重扭曲选择对目标token贡献至少 k_warp 个样本的最新帧：

f*{t,u} = max{f | n{f,t,u} ≥ k_warp}。　　(21)

只有来自 f*_{t,u} 的样本贡献给该token的统计。实现记录分位数阶梯：

z_Q^τ(t,u) = Quantile_τ(𝒵_{f*_{t,u},t,u})，τ ∈ {5, 10, 20, 50, 80, 90, 95}，　　(22)

并使用 z_Q(t,u) = z_Q⁵⁰(t,u) 作为token深度。如果最新帧缺乏足够样本，较旧的帧可以填充空洞。如果没有源达到样本下限，token保持无效。在取分位数之前选择源防止了来自不同观测和表面的深度样本混合。

从token深度到查询视锥体切片。全局Gilbert查询块可以跨越潜帧边界，因此Velox首先将其划分为帧局部矩形片段。对于片段 B_{i,t}，定义其有效token集合为 𝒱_{i,t} = {u ∈ B_{i,t} | f*_{t,u} 存在}。其目标相机深度区间为：

z⁻{i,t} = Quantile{p_lo}({z_Q(t,u) : u ∈ 𝒱_{i,t}})，　z⁺{i,t} = Quantile{p_hi}({z_Q(t,u) : u ∈ 𝒱_{i,t}})。　　(23)

实现强制 z⁺{i,t} ≥ z⁻{i,t} + ε_slab。片段的token矩形和此鲁棒区间定义用于世界空间OBB匹配的查询视锥体切片。空的 𝒱_{i,t} 不贡献几何证据。如果结果查询块未达到覆盖率阈值，路由器遵循公式(13)中的模型导出路径。

实现路径。GPU过程有两个逻辑通道。第一个为每个源帧、目标帧和目标token元组计数有效样本并选择 f*_{t,u}。第二个仅压缩胜者帧样本并计算分段分位数。此排序使源缓存有界，避免跨帧深度混合，并在不重建噪声目标块的情况下提供块对齐的Q深度。报告的配置使用 k_warp=2 和 (p_lo, p_hi) = (10, 90)。它不应用可选的源到目标位姿门控或实验性扭曲遮挡器。

B.4 运行时路径与计时范围

测量的稀疏路径是Triton索引块稀疏注意力实现，而非围绕稠密注意力的Python掩码包装。查询每块一次重排到全局对齐Gilbert token序，KV缓存直接以该布局写入，使热内核加载连续KV分块而无需每次调用的主机置换。内核支持矩形当前查询与增长历史的注意力，消费由融合分数调度器产生的路由块列表，并使用运行时路由长度界限，使后续块不触发新的编译器特化。D节给出完整内核路径。

视锥体切片几何异步构建。在块解码后，专用CUDA流上的工作线程更新重建状态，记录块相机，构建存储的视锥体切片，刷新多重扭曲帧缓存，并在主流继续DiT去噪的同时为后续块准备Velox状态。实现使用两块新鲜度滞后。块 c 通常消费到块 c−2 为止的几何，这已足够，因为视锥体切片重叠变化缓慢。工作者是几何对象的唯一写入者。主流仅在需要未来状态时等待完成事件。C节给出完整实现路径，包括工作者流、VAE侧流、预热和尾部处理。

所有速度数字在图3的48块计时轨迹中在一块H200上测量。我们报告每块注意力调用延迟和每块去噪关键路径时间，而非单一聚合墙上时间数字，因为早期块的稠密注意力基线成本较小，而后期块暴露了对长视频生成重要的扩展行为。

附录C 异步视锥体切片构建

如果几何流水线在生成块之间串行插入，将会很昂贵。在同步实现中，块 c 必须去噪、解码、重建为深度和位姿状态、插入视锥体切片表和多重扭曲缓存、与下一个目标相机对齐并评分，然后块 c+1 才能去噪。在我们的设置中，重建和视锥体切片准备路径与一个DiT去噪步骤处于同一量级，因此串行执行会掩盖注意力内核的增益。

Velox通过两块新鲜度滞后放松此依赖。目标块 c 消费由到块 c−2 为止的视锥体切片构建的Velox状态，而工作者为后续块准备状态。状态保持自洽：每个工作者任务首先将恰好一个解码的块插入视锥体切片表和多重扭曲缓存，然后针对目标块的潜相机对该表评分。在第一个可用Velox状态之前的块运行稠密注意力，因此该方法从不消费未初始化的路由。

实现使用一个Python工作者线程和一个专用CUDA流。工作者是视锥体切片表、位姿对齐器、多重扭曲帧缓存和稀疏注意力上下文的唯一写入者。主去噪线程在块解码后提交几何任务，并接收以目标块为键的未来。在块 c 去噪之前，如果工作者尚未完成，主流等待未来的CUDA事件，然后消费准备好的几何和重要性状态。此等待是设备端流依赖。热路径中没有主机范围的同步。

每个几何任务执行四个操作。第一，将重建帧通过流式重建后端以更新深度、位姿、置信度和掩码。第二，相对对齐将目标相机控制位姿映射到重建帧，并在当前桥接下刷新存储的切片相机。第三，有效深度样本转换为逐块视锥体切片基元并插入版本化的视锥体切片表，同时缓存第一和最后帧深度用于多重扭曲。第四，稀疏上下文将缓存深度扭曲到目标相机中，构建Q视锥体切片，对历史视锥体切片评分OBB重叠，计算覆盖率，并实体化每个注意力层软融合消费的几何状态。

实现还通过侧流将VAE解码移出去噪关键路径，预热工作者线程的cuDNN句柄，在测量区间外预热分割和稀疏注意力内核，并跳过最后一块的视锥体切片评分，因为没有后续去噪消费它。帧在解码后移至CPU并在工作者流上复制回来，避免主流去噪时额外的GPU驻留。

所有报告的计时结果使用单块NVIDIA H200。异步工作者和DiT去噪器共享该GPU。记忆重建未卸载到第二设备。第二GPU可以减少CUDA流争用并进一步改善端到端时间，但不属于报告的测量协议。
