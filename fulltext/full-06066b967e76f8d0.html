摘要
大型语言模型（LLM）越来越多地与外部环境交互并积累了大量的行为经验，但现有的智能体基准测试大多将它们作为固定策略进行评估。因此，智能体能否主动测试其行为、评判所得的经验，并利用这些经验来改进未来的决策，仍然不清楚。我们引入了 S³Gym，这是一个通过三项耦合能力：自我测试（Self-Testing）、自我评判（Self-Judging）和自我改进（Self-Improvement）来评估 LLM 自我改进的交互式基准测试。S³Gym 将宽松的探索与严格的留出评估分开，并在七个带有可执行环境验证器的文本游戏中实例化了该协议。我们评估了整合交互经验的三种途径：直接历史上下文学习、分数条件化摘要记忆和参数训练。
我们的实验表明，自我改进既不是自动的，也不是均匀的。上下文级别的经验提高了几个模型-游戏对的性能，但最有效的途径强烈依赖于任务结构：当经验可以压缩为可重用的策略规则时，摘要是有益的；但当成功依赖于精确的、状态相关的信息时，摘要通常不如原始历史表现好。参数训练在某些任务上产生了实质性的收益，但在其他任务上表现出不稳定的改进和严重的负迁移。这些发现表明，认识到成功的动作是不够的；智能体还必须将反馈转化为可执行和可迁移的策略。S³Gym 提供了一个统一的框架来诊断这一过程，并识别阻止智能体将交互经验转化为可靠自我改进的瓶颈。

1 引言
大型语言模型（LLM）越来越多地被部署为自主智能体，通过反复的观察-推理-行动-反馈循环来调用工具、执行代码并与外部环境交互。这种交互对于自动化研究、软件工程和开放式决策等应用至关重要，在这些应用中，智能体不断积累行为经验。现有的基准测试评估了多轮决策、环境探索和任务完成 [15, 16]，但它们通常将被评估的模型视为固定策略。因此，它们主要回答一个静态问题——模型在评估时有多大的能力？——而对于模型是否能够利用其过去的交互来改进未来的行为，提供的见解有限。我们将这种经验驱动的能力称为自我改进。
经验学习和反思性探究的理论表明，只有当经验被主动检查、抽象和再次测试时，它才会变得有用。Dewey 和 Kolb 强调通过反思和再应用将经验转化为知识 [8, 14]，而 Popper 将进步描述为将猜想暴露于可以揭示错误的测试中的迭代过程 [21]。同样的原则适用于 LLM 智能体：仅收集轨迹并不能保证学习。智能体必须生成有信息量的证据，解释成功和失败的原因，并将这些解释转化为改进的行为。因此，我们将经验驱动的学习分解为三个相互依赖的能力：自我测试，即智能体探索策略并收集诊断证据；自我评判，即它评估动作、结果及其潜在的可重用性；以及自我改进，即由此产生的经验改变未来的决策 [23, 2]。
经过测试和评判的经验可以在不同级别的持久性上被整合。在短期的上下文学习级别，智能体直接根据之前的观察、动作和分数来条件化未来的决策。在中间的外部记忆级别，长轨迹被压缩成自然语言规则、失败模式或可重用的技能，如 Reflexion 和 Voyager [26, 30]。在长期的训练级别，选择或纠正的轨迹通过参数更新被内化，遵循 STaR、ReST 和 Re-ReST 探索的更广泛方向 [37, 11, 9]。这些机制做出了不同的权衡：原始历史保留了详细的证据但消耗上下文，摘要提供了紧凑的抽象但依赖于判断质量，而训练提供了持久的内化但也可能放大错误判断的经验。因此，需要一个统一的评估协议来在相同的交互和测试条件下比较这些途径。
为了满足这一需求，我们引入了 S³Gym，全称 自我测试、自我评判和自我改进健身房（Self-Testing, Self-Judging, and Self-Improvement Gym），这是一个交互式基准测试，用于评估 LLM 是否能通过自身的环境经验变得更有能力。每次评估都包含一个探索阶段和一个评估阶段，反映了寻找新策略和利用所获知识之间的区别 [17]。在探索过程中，智能体在相对宽松的环境配置下进行交互，生成成功、不成功和部分成功的轨迹。重要的是，S³Gym 明确将模型生成的自我评判与环境可验证的结果分开：自我评判决定了交互经验如何组织和重用，而环境分数衡量由此产生的行为表现。然后，更新后的智能体在更严格和留出的配置上进行评估，直接测试探索期间获得的经验是否迁移到新条件，以及自我评判中的错误是否成为后续自我改进的瓶颈。
我们用基于文本的游戏实例化 S³Gym（图 1），遵循 KORGym 的基于游戏的评估范式 [25]。KORGym 通过多样化的交互游戏评估 LLM 推理，而 S³Gym 将此类环境作为经验驱动的自我改进的受控测试床。它们的多轮交互、部分可观察性、延迟后果和长视野决策提供了丰富的行为轨迹，而可编程验证的规则使得能够通过客观的步骤级或终端分数进行可复现的评估。相关环境，包括 TextWorld、ALFWorld 和 ScienceWorld，同样证明了文本交互在评估规划、具身推理和科学问题解决方面的效用 [5, 27, 31]。S³Gym 包括七个游戏——国际象棋（Chess）、扫雷（Minesweeper）、消除（Nullify）、俄罗斯方块（Tetris）、贪吃蛇（Snake）、植物大战僵尸（PvZ）和信任演化（Trust Evolution）——涵盖潜在规则归纳、约束满足、数值转换、空间规划、资源分配、生存和多智能体策略。每个游戏都提供相关但不同的探索和评估配置，要求智能体从经验中提取可迁移的知识，而不是记住孤立的动作或种子。

我们的主要贡献总结如下：
* 经验驱动自我改进的统一表述。 我们将 LLM 自我改进形式化为一个连接自我测试、自我评判和后续行为改变的迭代过程，并引入了 S³Gym，它具有独立的探索和留出评估阶段。
* 经验整合途径的系统比较。 我们在统一协议下评估了整合交互经验的三种机制——历史 ICL、摘要记忆和参数训练。
* 自我评判的显式评估。 通过将模型生成的判断与验证器计算的结果进行比较，我们评估了智能体是否能够识别有用和有害的经验，并将这些判断转化为可操作的改进方向。
* 全面的实证和诊断分析。 我们在七个交互环境中评估了代表性的 LLM，并分析了改进动态、判断可靠性、摘要有效性、跨游戏一致性和常见失败模式。

2 背景
大多数智能体基准测试都是在问题已经变得可执行之后开始的：任务已指定，奖励或评判器已定义，执行支架已固定。这种设置对于受控比较是必要的，但它隐藏了在实际部署中占主导地位的工作。在工业界，这项工作分布在几个角色中——包括解决方案架构师、应用工程师和平台工程师——但其最近最明显的结晶是前线部署工程师（FDE），这一头衔由 Palantir 推广，随后被前沿模型公司采用 (Palantir Technologies, 2020; Orosz, 2025)。FDE 嵌入在部署环境中，将通用模型转变为一个能够处理客户数据格式、工作流和操作约束的系统。该角色的成功标准不是演示或基准测试分数，而是部署的系统是否真正被使用、继续工作并针对故障进行改进。前沿模型和数据平台公司中 FDE 角色的增长反映了一个简单的事实：一个有能力的模型还不是一个可工作的系统 (The New Stack, 2026; Challapally et al., 2025)，而今天这一差距主要由人类工程师来弥补。
从模型的角度来看，FDE 工作提供了基准测试设计者通常预设的三部分结构。首先，目标是模糊的：非正式的部署需求必须转化为具体的目标、约束和成功标准。其次，反馈信号可能缺失或不可靠：测试、评判器、追踪或其他验证机制必须在任何人能够确定系统是否正在改进之前构建好。第三，执行系统可能不以可用的形式存在：未来任务将运行所通过的工具、上下文管理、状态、生命周期逻辑和验证接口必须随着需求的变化而被构建、改编和维护。
S³Gym 专注于第二层：面向智能体的反馈信号及其支持的经验驱动改进循环。该基准测试保留了一个可执行的环境验证器作为外部基准真相，但在探索期间不向智能体提供验证器计算的结果。智能体必须转而通过自我测试生成有信息量的证据，通过自我评判评估该证据，并通过自我改进将其转化为更好的未来行为。这种分离既揭示了自我判断是否与实际结果一致，也揭示了判断的经验是否产生可迁移的改进。Aspire 研究广泛的部署需求如何变成能力增长，HarnessDev 研究模型如何构建和维护承载它们的执行系统，而 S³Gym 则在可执行环境中隔离了经验到改进的循环。

3 相关工作
3.1 交互式智能体基准测试
大型语言模型智能体的最新进展推动了交互式基准测试的发展，这些基准测试评估多轮决策、工具使用、规划和环境交互。AgentBench (Liu et al., 2024) 在操作系统、数据库和游戏等多个领域评估 LLM 智能体，而 AgentBoard (Ma et al., 2024) 提供了对多步任务中智能体进展和失败的细粒度分析。基于文本的环境，如 TextWorld (Côté et al., 2018)、ALFWorld (Shridhar et al., 2021) 和 ScienceWorld (Wang et al., 2022)，进一步为语言基础规划、具身推理和科学问题解决提供了可控的测试床。最近面向游戏的基准测试还检查了在文本或可编程验证环境中的交互推理和策略行为。
这些基准测试为评估智能体行为提供了丰富的基底，但它们通常将被评估的模型视为固定策略。交互轨迹主要用于测量任务完成情况或诊断预定义评估设置内的失败，而不是确定智能体是否能将其自身的经验转化为改进的未来行为。S³Gym 建立在交互环境的可控性和客观验证之上，同时将评估目标从静态任务能力转移到经验驱动的行为改进。

3.2 基于经验的智能体改进
越来越多的工作研究语言智能体如何通过重用自身的交互经验来改进。在上下文级别，Reflexion (Shinn et al., 2023) 引入了言语强化学习，智能体反思之前的尝试并使用文本反馈来指导未来的决策。在外部记忆级别，Voyager (Wang et al., 2023) 在一个不断发展的库中积累可重用的技能，使具身智能体能够保留和重用在开放式交互中获取的知识。最近基于记忆的方法类似地将轨迹压缩为规则、失败模式或可在后续回合中检索的可重用策略：ReasoningBank (Ouyang et al., 2025) 从智能体自我判断的成功和失败经验中提炼出可推广的推理策略，Tree-of-Experience (Deng et al., 2026b) 将积累的经验组织成支持反馈归因和跨任务迁移的层次结构，MetaSkill-Evolve (Wang et al., 2026b) 通过双时间尺度的元技能演化将技能文件重写扩展到改进过程本身。
经验也可以通过参数更新来整合。STaR (Zelikman et al., 2022)、ReST (Gulcehre et al., 2023) 和 Re-ReST (Dou et al., 2024) 通过生成、过滤或完善自我生成的推理轨迹来改进语言模型。自奖励语言模型 (Yuan et al., 2024) 进一步利用模型生成的偏好信号进行迭代优化。在交互环境中，RetroAgent (Zhang et al., 2026) 使用回顾性双重内在反馈训练智能体，以便跨回合获取的经验可以被检索和重用，而不是仅仅隐式地编码在参数中，而测试时自我改进 (Acikgoz et al., 2025) 从智能体自身的交互失败中构建有针对性的训练样本。这些研究表明，交互历史和自我生成的监督可以提高模型性能。然而，它们通常在特定任务或训练设置中研究特定的改进机制，因此很难理清改进或失败是源于收集经验的质量、经验解释的可靠性，还是用于整合该经验的机制。S³Gym 提供了一个统一的评估协议，在相同的探索和留出评估设置下比较不同的经验整合策略，包括历史 ICL、摘要记忆和参数训练。

3.3 评估自适应和自我改进的智能体
在基于 LLM 的评估工作中，模型生成的监督的可靠性已被广泛研究。LLM-as-a-Judge (Zheng et al., 2023) 和 JudgeBench (Tan et al., 2025) 表明，语言模型可以提供有用的评估信号，但它们的判断仍然容易受到偏见、校准错误和推理限制的影响。最近对 ALFWorld 中步骤级信用分配的审计进一步表明，当与执行重放进行测量时，LLM 评判分数、结果条件的对数概率比率和策略自身的置信度都无法比随机机会更好地识别因果重要的步骤 (Zhang, 2026)。这种限制对于自我改进的智能体尤为重要，因为不准确的判断可能导致有害的经验被保留或有价值的经验被丢弃。
最近的基准测试已开始从静态能力评估向自适应和自我改进系统迈进。PostTrainBench (Rank et al., 2026) 评估了在留出任务上改进模型参数的自动化后训练流水线。SEA-Eval (Jiang et al., 2026) 通过顺序任务交互研究长期智能体演化，而 SEAGym (Zheng et al., 2026) 调查了持久智能体工具包的演化，包括提示、记忆、工具和工作流。PAST-Bench (Xue et al., 2026) 通过在开启和关闭保留经验的情况下运行匹配的任务序列，测试保留的经验是否确实改进了个人智能体。ContinualSkillBench (Guan et al., 2026) 测量上下文中的持续技能学习，发现不同模型和领域的收益差异很大，FinEvo-Bench (Deng et al., 2026a) 为专业金融工作流中的自我演化智能体提供了纵向基准测试，Social Gym (He et al., 2026) 在具有规则可验证结果的游戏中对多智能体社会推理进行基准测试，AI4AI-Bench (Chi et al., 2026) 隔离了递归自我改进的训练算法设计。除了基准测试之外，最近的分析表明，自我改进本身通常是不可靠的：基于记忆的方法表现出高方差和对任务顺序的强烈敏感性 (Ye et al., 2026)，一旦有缺陷的技能进入池中，积累的技能可能会污染后续行为 (Shang et al., 2026)，而优化器驱动的智能体收益不一定能在持续学习轮次中复合 (Wang et al., 2026a)。这些基准测试和分析代表了向评估自适应系统迈出的重要一步，但它们关注的是不同的改进产物或适应过程的特定方面，并且没有一个在可执行环境验证下将自我测试与显式的自我评判结合起来。表 1 总结了现有基准测试与 S³Gym 之间的关键区别。

4 方法
4.1 概述
S³Gym 评估 LLM 是否能通过在交互环境中测试策略、评判所得经验并重用所获知识来改进其未来行为。一个自我改进循环包含五个阶段：
$\mathcal{R}{t}^{(p)}=\mathrm{Explore}\rightarrow\mathrm{Judge}\rightarrow\mathrm{Consolidate}\rightarrow\mathrm{Update}{p}\rightarrow\mathrm{Evaluate}$, (1)
其中 $t$ 是循环索引，$p\in{\mathrm{History},\mathrm{Memory},\mathrm{Training}}$ 表示改进途径。在探索期间，智能体在相对宽松的游戏配置下积累轨迹。然后它判断自己的决策，并将由此产生的经验整合为原始历史、摘要记忆或训练示例。最后，更新后的智能体在更严格和留出的配置上进行评估。

图 2：S³Gym 概览。探索轨迹通过历史 ICL、摘要记忆或参数训练进行判断和整合。然后，更新后的智能体在更严格的游戏配置上进行评估。

4.2 交互协议与形式化
每个游戏包含多个独立的回合，每个回合由一系列交互步骤组成。对于回合 $x$ 在步骤 $i$，我们用 $O_{x,i}$ 表示当前观察，$H_{x,i}$ 表示回合内交互历史，$a_{x,i}$ 表示智能体动作，$s_{x,i}$ 表示智能体自我判断的即时分数，$F_{x,i}$ 表示可观察的环境反馈，$r_{x,i}$ 表示验证器计算的步骤奖励，$y_{x}$ 表示最终环境分数。
回合初始化为
$O_{x,0}=\operatorname{Reset}(\operatorname{seed}{x},c{x})$, (2)
$H_{x,0}=\varnothing$, (3)
其中 $c_{x}$ 表示游戏配置。
在每一步，智能体接收当前观察、回合内历史以及从先前探索回合继承的特定途径经验状态 $Z_{t}^{(p)}$。遵循实际的交互接口，模型联合产生一个动作和一个自我判断的即时分数：
$(a_{x,i},s_{x,i})=\pi_{\theta_{t}}\left(O_{x,i},H_{x,i};Z_{t}^{(p)}\right)$, (4)
其中 $p\in{\text{History},\text{Memory},\text{Training}}$。分数 $s_{x,i}$ 代表模型对其提出的动作在游戏规则下所获得的即时奖励的估计，而不是自由形式的置信度分数。在上下文级别的途径中，$Z_{t}^{(p)}$ 包含保留的原始历史或摘要经验；对于参数训练，获取的经验主要通过更新的参数 $\theta_{t}$ 反映出来。
然后环境执行提出的动作并返回下一个观察、可观察反馈、验证器计算的奖励和终止信号：
$(O_{x,i+1},F_{x,i},r_{x,i},d_{x,i})=\operatorname{Env}(O_{x,i},a_{x,i})$. (5)
重要的是，$F_{x,i}$ 表示智能体可用于后续交互的环境信息，而 $r_{x,i}$ 被基准测试保留作为外部验证信号。在主要设置中，验证器计算的奖励在探索期间不暴露给智能体。这种分离允许 S³Gym 将智能体的自我判断 $s_{x,i}$ 与实际环境奖励 $r_{x,i}$ 进行比较，而不允许基准真相奖励直接指导后续决策。
然后，智能体可见的转换被附加到回合内历史中：
$H_{x,i+1}=H_{x,i}\oplus\operatorname{Format}\left(O_{x,i},a_{x,i},s_{x,i},F_{x,i},O_{x,i+1}\right)$, (6)
其中 $\oplus$ 表示有序连接。因此，交互历史记录了智能体自己的分数以及状态转换，而验证器奖励 $r_{x,i}$ 仍然是基准测试侧的信息。在下一步，智能体再次将等式 (4) 应用于更新的观察和历史。
当回合终止或达到最大步数时，环境返回最终的验证器计算分数
$y_{x}=\operatorname{Score}(\tau_{x})$, (7)
其中 $\tau_{x}$ 表示回合 $x$ 的完整执行轨迹。步骤级奖励 $r_{x,i}$ 用于评估自我判断的可靠性，而 $y_{x}$ 衡量用于基准测试评估的回合级行为表现。在主要设置中，这两个信号在探索期间都不提供给智能体。

4.3 自我评判与经验整合
当智能体无法获得精确的环境奖励时，自我评判为识别有用和有害的经验提供了内部信号。低分轨迹片段表明可能的错误或应避免的策略，而高分片段提供了要保留的候选策略。
S³Gym 以两种上下文级别的形式组织被判断的经验。
历史上下文。 带有分数注释的轨迹被直接序列化并附加到未来的上下文中：
$C_{t+1}=\operatorname{Serialize}!\left(C_{t},\mathcal{T}{t}^{\mathrm{exp}},\mathcal{S}{t}^{\mathrm{exp}}\right)$, (8)
其中 $\mathcal{T}{t}^{\mathrm{exp}}$ 和 $\mathcal{S}{t}^{\mathrm{exp}}$ 是循环 $t$ 中的探索轨迹及其自我判断分数。
摘要记忆。 模型将被判断的轨迹压缩为可重用的经验：
$M_{t+1}=\operatorname{Summarize}!\left(M_{t},\mathcal{T}{t}^{\mathrm{exp}},\mathcal{S}{t}^{\mathrm{exp}}\right)$. (9)
摘要包含要保留的策略、要避免的错误以及下一个交互循环的具体方向：
$M_{t+1}=\left(R_{t}^{\mathrm{retain}},R_{t}^{\mathrm{avoid}},D_{t}^{\mathrm{next}}\right)$. (10)

4.4 探索与评估阶段
每个游戏提供一个探索分布 $\mathcal{C}{g}^{\mathrm{exp}}$ 和一个评估分布 $\mathcal{C}{g}^{\mathrm{eval}}$。探索环境保留了主要的任务结构，但使用更宽松的条件，例如更小的状态空间、更弱的失败惩罚或额外的尝试机会。评估环境使用更严格的规则或更复杂的配置。
一个自我改进循环包含 $N_{\mathrm{exp}}$ 个探索回合，随后是 $N_{\mathrm{eval}}$ 个评估回合：
$\left{\tau_{t,x}^{\mathrm{exp}}\right}{x=1}^{N{\mathrm{exp}}}\rightarrow\operatorname{Improve}\rightarrow\left{\tau_{t,x}^{\mathrm{eval}}\right}{x=1}^{N{\mathrm{eval}}}$. (11)
探索为判断和整合提供了多样化的经验，而评估则验证由此产生的改进是否迁移到更严格的条件。这两个阶段使用不相交的随机种子，评估轨迹不会添加到历史、记忆或训练数据中。
对于途径 $p$ 和游戏 $g$，循环 $t$ 之后的评估性能为
$\overline{Y}{t,g}^{(p)}=\frac{1}{N{\mathrm{eval}}}\sum_{x=1}^{N_{\mathrm{eval}}}y_{t,g,x}^{(p)}$, (12)
相对于原始模型的改进为
$\Delta_{t,g}^{(p)}=\overline{Y}{t,g}^{(p)}-\overline{Y}{0,g}$. (13)
我们报告最终评估分数和 $\Delta_{t,g}^{(p)}$。前者衡量最终能力，而后者衡量模型从其自身的交互历史中受益的有效程度。

4.5 自我改进途径
S³Gym 评估了整合探索经验的三种途径。
历史 ICL。 带有分数注释的轨迹直接插入到后续回合的上下文中：
$Z_{t+1}^{(\mathrm{History})}=C_{t+1}$. (14)
该途径保留了详细的交互证据，但受到上下文长度的限制。
摘要记忆。 智能体接收整合的摘要，而不是完整的轨迹：
$Z_{t+1}^{(\mathrm{Memory})}=M_{t+1}$. (15)
该途径评估模型是否能从冗长的交互历史中抽象出可迁移的策略。
参数训练。 探索轨迹和自我判断被转换为监督微调示例：
$\mathcal{D}{t}^{\mathrm{SFT}}=\operatorname{BuildSFT}!\left(\mathcal{T}{t}^{\mathrm{exp}},\mathcal{S}{t}^{\mathrm{exp}}\right)$, (16)
随后是参数更新
$\theta{t+1}=\operatorname{SFT}!\left(\theta_{t},\mathcal{D}_{t}^{\mathrm{SFT}}\right)$. (17)
高分动作被保留为正例，而低分动作被过滤或替换为纠正后的动作。训练被视为辅助途径，因为它引入了上下文级别改进中不存在的优化变量。
所有途径都从相同的基础模型开始，并使用相同的探索种子、评估种子、交互预算和解码设置。

指标。 设 $y_{m,p,g,k}$ 表示模型 $m$、途径 $p$ 和游戏 $g$ 在检查点 $x_{k}$ 处的评估分数。我们为每个模型-游戏对报告三个互补指标：
$\displaystyle\operatorname{Avg}{m,p,g} = \frac{1}{K+1}\sum{k=0}^{K}y_{m,p,g,k}$, (18)
$\displaystyle\operatorname{Max}{m,p,g} = \max{0\leq k\leq K}y_{m,p,g,k}$, (19)
$\displaystyle\operatorname{AUC}^{+}{m,p,g} = \int{0}^{30}\max!\left(0,y_{m,p,g}(x)-y_{m,p,g,0}\right)\,dx$. (20)
$\operatorname{AUC}^{+}$ 中的连续曲线 $y(x)$ 是通过相邻检查点之间的分段线性插值获得的。Avg. 衡量整个探索过程中的整体性能；Max. 捕捉最佳观察能力，而 $\operatorname{AUC}^{+}$ 衡量在初始评估分数之上的持续改进。由于游戏使用不同的分数范围，原始 $\operatorname{AUC}^{+}$ 值应在同一游戏内进行比较，而不是直接跨游戏比较。

5.3 主要结果
表 4 报告了在历史 ICL 和摘要记忆下所有完整模型的 Avg.、Max. 和 $\operatorname{AUC}^{+}$。粗体值表示在相应途径和游戏内每个指标的最佳结果。
整体上下文级别性能。 结果表明，自我改进潜力由基础模型、经验途径和环境共同决定。在历史 ICL 下，Gemini-3.5-Flash 获得了最强的国际象棋结果以及贪吃蛇和信任演化的最大 AUC，而 GPT-5.5 在更脆弱的扫雷、消除和俄罗斯方块任务中领先，并获得了最大的植物大战僵尸 AUC。在摘要记忆下，GPT-5.5 在国际象棋、消除和俄罗斯方块上变得最强，并在贪吃蛇上达到了最高的平均分和最高分。Gemini-3.5-Flash 在植物大战僵尸和信任演化的平均性能上仍然最强。这些结果表明，仅靠高基础能力并不能决定自我改进；模型在检索、压缩和应用自身经验方面的有效性也有所不同。
历史 ICL 与摘要记忆。 摘要记忆并不普遍优于原始历史。它可以显著改进那些难以直接使用长轨迹的模型。例如，Gemini-2.5-Flash 将其扫雷的 $\operatorname{AUC}^{+}$ 从 ICL 下的 $0.000$ 提高到摘要记忆下的 $7.794$，其植物大战僵尸的 $\operatorname{AUC}^{+}$ 从 $24.402$ 提高到 $238.501$。GPT-5.5 类似地将其国际象棋的 $\operatorname{AUC}^{+}$ 从 $0.474$ 提高到 $16.840$。然而，总结可能会丢弃特定状态的证据或保留不正确的判断。GPT-5.5 的植物大战僵尸 $\operatorname{AUC}^{+}$ 从 $548.499$ 下降到 $33.219$，而 Gemini-3.5-Flash 在国际象棋上从 $12.280$ 下降到 $0.000$，在信任演化上从 $200.000$ 下降到 $55.095$。因此，摘要记忆应被视为一种选择性压缩机制，而不是对历史 ICL 的无条件改进。
跨游戏一致性。 这七个游戏揭示了不同的自我改进机制。国际象棋、扫雷和消除具有稀疏或高度离散的分数，因此一个成功的回合可以强烈影响 Max.，但只产生很小的 Avg. 或 AUC。俄罗斯方块、贪吃蛇、植物大战僵尸和信任演化提供了更密集的顺序反馈，并暴露了持续适应中更明显的差异。因此，这三个指标是互补的：Max. 识别偶尔的能力突破，Avg. 反映整体性能，而 $\operatorname{AUC}^{+}$ 区分持续改进和孤立的峰值。由于不同游戏的分数范围差异很大，跨游戏一致性应通过游戏内排名或改进的游戏数量来评估，而不是通过平均原始 AUC 幅度来评估。

6 分析
6.1 RQ1：参数训练能否实现自我改进？
RQ1 检查智能体是否能够通过参数更新内化其交互经验，随后在没有历史轨迹或外部记忆的推理时间内进行改进。与上下文级别的适应相比，参数训练提供了一种更持久的改进途径，但它也带来了更大的风险：嘈杂或错误判断的轨迹可能会被整合到模型中，并覆盖之前有效的行为。
我们在 20 个连续的检查点上评估 Qwen3-8B，其中 epoch 0 代表原始模型，epoch 1-19 代表使用探索轨迹更新的模型。在每个检查点，模型在没有历史 ICL 或摘要记忆的情况下，在所有七个 S³Gym 游戏的严格配置上进行评估。我们报告训练后的平均分和最高分、最终变化 $\Delta_{\mathrm{Final}}=y_{19}-y_{0}$，以及高于初始基线的正面积 $\operatorname{AUC}^{+}=\int_{0}^{19}\max!\left(0,y(e)-y_{0}\right)\,de$，其中 $y(e)$ 是通过对相邻检查点进行线性插值获得的。

图 7：Qwen3-8B 在 20 个训练检查点上的严格模式评估性能。Epoch 0 表示原始模型。由于游戏使用不同的分数范围，每条轨迹应相对于其自身的初始性能进行解释。
* 训练在信任演化上产生了实质性的自我改进。 分数从 0 上升到最高 30，并在 19 个更新检查点中的 18 个保持高于初始基线。训练后的平均分达到 8.684，$\operatorname{AUC}^{+}$ 达到 163.5，提供了交互衍生策略可以内化到模型参数中的最清晰证据。
* 在国际象棋和贪吃蛇上的收益有限或短暂。 国际象棋在大多数检查点保持为零，但在最后一个检查点达到 0.0667，表明有稀疏但积极的收益。贪吃蛇在 epoch 8、12 和 15 达到 1 分，但随后回到零。因此，训练发现了偶尔的成功行为，但没有持续保留。
* 扫雷、消除和俄罗斯方块没有显示出可测量的改进。 它们的评估分数在整个训练过程中保持为零。一种可能的解释是探索产生的成功轨迹太少，无法引导出有效的监督信号，尽管验证这一假设需要轨迹级别的分析。
* 训练在植物大战僵尸上产生了明显的负迁移。 初始分数为 23，而每个更新检查点的得分为 6。这种持续的退化表明参数更新可以覆盖之前有效的行为。潜在原因包括对探索轨迹的过拟合、宽松探索与严格评估之间的不匹配，或不可靠的自我判断信号。
* 总体而言，参数训练实现了自我改进，但在不同任务上并不一致。 Qwen3-8B 在信任演化上有显著改进，在国际象棋上改进微弱，在贪吃蛇上间歇性改进，而在三个游戏上没有改进，在植物大战僵尸上严重退化。因此，有效的训练级别自我改进不仅取决于更新参数的能力，还取决于被内化经验的质量、多样性和正确性。

6.2 RQ2：智能体自我判断可靠吗？
自我判断是 S³Gym 的核心组件，因为模型生成的分数 $s_{i}$ 与每次转换一起存储，并随后影响轨迹选择、摘要构建和训练数据生成。如果 $s_{i}$ 与环境信号不一致，智能体可能会将有害动作保留为有用经验，或丢弃本应保留的转换。因此，我们将自我判断作为一项独立能力进行评估，并检查判断质量是否能预测后续的改进。
步骤级可靠性。 对于每次转换，我们将模型生成的分数 $s_{i}$ 与环境奖励 $r_{i}$ 进行比较。我们首先测量事件一致性，它表明模型和环境是否就存在积极结果达成一致：
$\mathrm{Agree}=\frac{1}{N}\sum_{i=1}^{N}\mathbf{1}\left[\mathbf{1}(s_{i}>0)=\mathbf{1}(r_{i}>0)\right]$. (21)
由于不同游戏的奖励范围不同，我们额外报告归一化平均绝对误差：
$\mathrm{NMAE}=\frac{1}{N}\sum_{i=1}^{N}\left|\frac{s_{i}-s_{\min}}{s_{\max}-s_{\min}}-\frac{r_{i}-r_{\min}}{r_{\max}-r_{\min}}\right|$. (22)
我们还测量过度自信 $\Pr(s_{i}>0,r_{i}\leq 0)$ 和自信不足 $\Pr(s_{i}\leq 0,r_{i}>0)$。该分析涵盖了直接历史和摘要记忆条件下的七个目标模型和游戏，包含 98 次运行和 116,117 次转换。

表 5 表明自我判断只是部分可靠的。植物大战僵尸、贪吃蛇、俄罗斯方块、扫雷和消除表现出相对较高的事件一致性，但这一结果部分是由于零奖励转换的比例很大。NMAE 揭示了模型判断的幅度是否也校准得很好。俄罗斯方块和消除实现了较低的 NMAE，而植物大战僵尸尽管其二元一致性很高，却表现出最大的校准误差。因此，模型可以识别一个动作是否在局部看起来有用，同时却大大低估了它的价值。
国际象棋和信任是最明显的失败案例。国际象棋的事件一致性接近随机，过度自信率最高。一个预测可能在语法上是完整的，但仍然放错了几个棋子，导致模型对其响应的置信度与环境分数产生分歧。信任同样表现出较弱的一致性、高 NMAE 和严重的过度自信。这些结果表明，当奖励取决于隐藏的动态、对手策略或精确的多对象状态预测，而不是立即可观察的局部后果时，自我判断变得不那么可靠。
判断-改进耦合。 可靠的局部判断只有在智能体能够将其转化为更好的后续行为时才有用。为了测试这种关系，我们将探索轨迹划分为相邻评估检查点之间的块 $B_{t}$。对于每个块，我们计算事件一致性 $A_{t}$、归一化校准误差 $E_{t}$，以及下一次评估时的归一化分数变化：
$g_{t}=\frac{y_{t}-y_{t-3}}{\max_{g,\tau}y_{g,\tau}-\min_{g,\tau}y_{g,\tau}}$. (23)

运行级别的分析得出了相同的结论。为了在考虑初始性能差异的同时量化持续改进，我们使用高于基线的归一化面积 (NABA)，定义为 $\mathrm{NABA}=\frac{\mathrm{AUC}^{+}}{\max(y_{0},\epsilon)}$，其中 $y_{0}$ 是初始评估分数，$\epsilon$ 表示当 $y_{0}=0$ 时的第一个非零分数范围。在 Pearson 和 Spearman 测量下，事件一致性与 NABA 仅表现出微弱的负相关（$r=-0.23$ 和 $\rho=-0.11$），而正奖励和正自我分数率仅表现出微弱的正相关。这些结果表明，仅靠准确的局部自我判断不足以实现自我改进：智能体还必须将反馈转化为可重用的状态抽象、决策规则和探索策略。

6.3 RQ3：分数条件化的摘要是否产生有效的迭代方向？
摘要记忆比直接历史重用提出了更强的要求。模型不仅要根据先前的轨迹进行条件化，还必须识别哪些低分行为应该被抑制，哪些高分行为应该被保留，以及如何将这些观察转化为未来回合的可执行策略。我们通过将分数条件化的摘要与直接历史 ICL 进行比较，并检查具有代表性的成功和不成功摘要来评估这一能力。

成功的摘要
* GPT-5.5 / 信任
* 摘要方向。 当观察到的收益结构持续有利于背叛时，总是选择背叛；避免不必要的互惠探索。
* 轨迹证据。 在第一个决策中，智能体选择了 cheat 并获得了 3.0 的环境奖励。
* 结果。 $\Delta\mathrm{NABA}=+66.89$。
* 要点。 摘要将收益反馈转化为显式的对手条件化策略。
* o3-mini / 俄罗斯方块
* 摘要方向。 共同检查当前和下一个方块，测试替代旋转，优先考虑消行放置，并保持低表面且没有孤立的孔洞。

* 结果。 $\Delta\mathrm{NABA}=+14.42$。
* 要点。 摘要将成功的消行转化为可执行的向前看规则。
* Gemini-2.5-Flash / 扫雷
* 摘要方向。 应用局部数字约束：扩展零区域，标记强制地雷，并揭开可证明安全的单元格。
* 轨迹证据。 智能体在部分揭示的棋盘上选择了 flag (2,2) 并获得了 0.0625 的奖励。
* 结果。 $\Delta\mathrm{NABA}=+25.49$。
* 要点。 当摘要将局部推理表达为可执行的约束规则时，它们会有所帮助。
* Gemini-3.5-Flash / 消除
* 摘要方向。 向后规划以创建精确的相反数，使用向下取整或向上取整操作去除小数，并在每次合并后跟踪索引变化。
* 轨迹证据。 终端单元为 -19 和 19，智能体选择了 0 1 并获得了 1.0 的奖励。
* 结果。 $\Delta\mathrm{NABA}=+8.50$。

* GPT-5.5 / 植物大战僵尸
* 摘要方向。 优先考虑阳光生产、早期防御、坚果墙拖延以及覆盖受威胁的赛道。
* 轨迹证据。 智能体以 X 1 0 开局并获得 1.0 奖励，但其随后的严格分数从 38.67 下降到 32.33。
* 结果。 $\Delta\mathrm{NABA}=-2.56$。
* 要点。 建议是合理的，但太粗糙，无法捕捉赛道时间、当前僵尸位置和可用阳光预算。
* Gemini-3.5-Flash / 国际象棋
* 摘要方向。 跟踪每个棋子的移动规则，并在提交答案前验证所有坐标。
* 轨迹证据。 在一个低分回合中，模型产生了 END，尽管生成了详细的规则摘要，但总奖励为零。
* 结果。 $\Delta\mathrm{NABA}=-33.27$。
* 要点。 高层提醒无法解决精确的多棋子定位问题。
* GPT-4.1 / 扫雷
* 摘要方向。 从角落开始，扩展零区域，仅标记确定的地雷，并在没有安全进展可用时停止。
* 轨迹证据。 智能体在耗尽可用生命后选择了 uncover (8,0)，随后的检查点分数从 0.0606 下降到 0。
* 结果。 $\Delta\mathrm{NABA}=-22.09$。
* 要点。 通用启发式方法不能替代精确的约束传播。
* GPT-4o / 贪吃蛇
* 摘要方向。 向食物移动，同时避开墙壁、障碍物、蛇身和直接反转。
* 轨迹证据。 给定一个包含食物、障碍物和自身身体的棋盘，智能体选择了 DOWN；它没有获得奖励，严格分数从 1.0 下降到 0。
* 结果。 $\Delta\mathrm{NABA}=-22.00$。
* 要点。 摘要省略了安全导航所需的精确几何形状。

综上所述，这些案例揭示了基于摘要的有效改进的两个要求。首先，分数必须识别出一个有意义的、可重用的失败模式，而不是仅仅表明回合结束得很糟糕。其次，摘要必须将该信号转化为一个足够精确以在新状态中执行的动作规则。因此，摘要记忆是一种选择性的改进机制：当经验允许紧凑的因果抽象时，它是有效的，但它不能普遍替代对状态丰富的交互历史的直接访问。

7 结论
S³GYM 将自我改进从一种宽泛的主张转变为一种可衡量的智能体能力。通过将宽松的探索与更严格的评估分开，并支持上下文级别和训练级别的轨迹重用，该基准测试了 LLM 是否能将交互历史转化为未来的性能。目前的证据以一种有用的方式呈现出混合结果。摘要记忆在紧凑规则跨回合迁移的游戏中有所帮助，而在细节至关重要的反应式控制游戏中，直接历史通常更好。在当前实现中，对自我生成的轨迹进行训练仍然不稳定。这些发现表明，未来的自我改进智能体需要更好的判断校准、记忆选择和轨迹过滤，而不仅仅是更多的交互数据。

六个游戏前置了下面描述的共享基础指令，而信任演化使用其自己的游戏特定系统指令。两种记忆条件都保留相同的游戏规则、动态状态、合法动作空间和自我判断契约。它们的区别仅在于先前探索回合的经验在当前状态之前是如何表示的。
* 直接记忆：原始历史上下文学习
直接记忆将先前回合保留的每一步序列化为环境-智能体对，Env: <STATE> 后跟 LLM: Answer: <ACTION>, Score: <SELF-SCORE>。在动作执行时，模型接收以下组合：
* 提示消息：<来自先前回合的原始历史>
* 当前回合的游戏历史：<本回合早期步骤的原始历史>
* <游戏系统提示 + 当前步骤提示>
实现完整保留了当前回合历史和当前游戏提示，而在超出上下文预算时截断先前回合历史的尾部。
* 摘要记忆：分数条件化的策略压缩
在每个回合的第 0 步，摘要记忆首先对游戏规则和截断的先前回合历史进行单独的压缩调用：
* 规则：<游戏系统提示>
* 历史：<截断的先前回合原始历史>
* 请总结实用经验和建议……
* 提示：<项目符号策略摘要>
提取的提示为会话缓存并在后续步骤中重用。动作时的输入为：
* 提示消息：<摘要提示>
* <游戏系统提示>
* 当前回合的游戏历史：<本回合早期步骤的原始历史>
* <游戏系统提示 + 当前步骤提示>
因此，只有跨回合经验被压缩；当前回合仍作为原始状态-动作-分数历史可用。在发布的实现中，游戏系统提示与缓存的摘要前缀一起出现一次，并在当前步骤提示中再次出现。
无论记忆条件如何，模型都必须报告动作及其自我判断的即时分数。共享的最后一行契约是：
* Answer: <ACTION>, Score: <SELF-JUDGED SCORE>.
如果智能体确定回合已终止，它返回 Answer: END, Score: 0.。自我判断的分数旨在成为所提出动作在所述游戏规则下获得的奖励，而不是自由形式的置信度值。
