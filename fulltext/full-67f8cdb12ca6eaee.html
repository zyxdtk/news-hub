原标题：DeepSeek Harness launches as open source rival to Claude Code, alongside V4-Pro on API with higher prices

中文摘要： DeepSeek 发布了开源智能体框架 DeepSeek Harness，作为 Claude Code 的替代方案，强调“一切皆插件”的模块化设计。同时推出了专注于智能体工作负载的 V4-Pro 正式版，支持原生 Responses API。然而，DeepSeek 宣布放弃统一 API 定价，转向高峰与低谷时段差异化收费，新价格最高涨幅超 1100%。这标志着 DeepSeek 正向智能体堆栈上层拓展，在开放框架的同时提高了托管 API 成本。

DeepSeek 正在超越模型层，向开发者用于驱动 AI 智能体工作的软件领域深入拓展。

这家中国 AI 实验室于周四发布了 DeepSeek-V4-Pro 的正式版本，这是一款专注于智能体工作负载的更新版旗舰模型，同时发布了 DeepSeek Harness v0.1，这是一款新的开源智能体框架，为开发者提供了 Anthropic Claude Code 等集成编码智能体环境的替代方案。

这些发布标志着 DeepSeek 向开发者领域的更广泛推进。V4-Pro 现已在 DeepSeek 的网页界面、移动应用和 API 中提供，并原生支持 OpenAI Responses API 和 Codex 集成。

同时，DeepSeek Harness 以 MIT 许可证进入开发者预览阶段，代码现已在 GitHub 上提供下载和使用。它围绕一个不同寻常的模块化前提构建：智能体运行时的几乎所有部分都可以作为插件被替换。

但是，通过 DeepSeek API 访问 V4 的开发者很快将为此支付更多费用。DeepSeek 同时正在放弃其现有的统一 API 定价，转而采用高峰和低谷时段费率，该政策将于 8 月 16 日星期日 16:00 UTC（美国东部时间凌晨 2:00）生效。

即使是享受折扣的低谷时段缓存未命中和输出价格，也将大大高于目前的价格。

这一组合意义重大，因为 DeepSeek 不再仅仅在模型智能和 Token 价格上竞争。凭借 Harness，它正在进入决定模型如何使用工具、操作文件、维护会话和执行长时间运行智能体工作流的层面——在这一领域，Anthropic 的 Claude Code 和其他编码智能体已成为越来越重要的开发者产品。

DeepSeek 构建自己的智能体框架

DeepSeek 将 Harness（或称 dsh）描述为基于 Cordis 构建的开源智能体框架，Cordis 是一个围绕可组合插件设计的框架。

它的指导原则很简单：“一切皆插件。”

DeepSeek 表示，这延伸到了模型、工具、技能、会话、沙箱、文件系统、循环、编排和用户界面。Harness 不是将这些组件作为单个编码智能体的固定部分，而是旨在让开发者混合、替换和扩展它们。

该项目在 MIT 许可证下提供，目前可以通过 npm 使用 npx @deepseek-ai/dsh web 启动。DeepSeek 还提供了直接从源代码构建的说明。该代码库明确将该软件描述为开发者预览版，并警告称“将会有破坏兼容性的更改”。

这一警告对企业开发者很重要。Harness 尚未被定位为稳定的即插即用生产平台。但其架构指向了一个潜在的重要战略：DeepSeek 现在不仅可以向开发者提供模型，还可以提供一个用于组装围绕模型的系统的开放框架。

这使得 Anthropic 的 Claude Code 和 OpenAI 的 Codex 成为有用的竞争参考，尽管不应将这些产品视为功能完全相同。

DeepSeek Harness 是 Claude Code 和 Codex 底层智能体基础设施的开源、模型无关替代方案——但目前还不能完全替代这两款产品更广泛的开发者体验。

它已经可以检查代码库、编辑文件、执行 shell 命令、搜索文件和网络、维护计划、调用技能、将工作委托给子智能体以及执行审批策略。这些是使 Claude Code 和 Codex 成为智能体编码工具而非自动补全系统的基本能力。

DeepSeek 明确将标准模式描述为具备文件编辑、shell 访问、搜索、规划、子智能体和工作流功能的完整编码智能体。其本地 Web 界面允许用户选择工作区并批准敏感操作。

DeepSeek 的代码库在发布当天就已经吸引了开发者的极大关注，截至 8 月 13 日，大约有 27,500 个 GitHub Star 和 2,000 个 Fork，尽管这些快速变化的数字最好被视为一个快照，而不是采用率指标。

V4-Pro 获得专注于智能体的升级

Harness 与 DeepSeek-V4-Pro-0813 的正式发布同步推出。

DeepSeek 最初于 4 月以预览版形式推出了 V4 系列。 该系列包括 1.6 万亿参数的 V4-Pro（每个 Token 激活 490 亿参数），以及较小的 2840 亿参数的 V4-Flash（激活 130 亿参数）。两者都支持高达 100 万个 Token 的上下文窗口。

因此，该公司 8 月 13 日的发布并不是 V4-Pro 的首次亮相。这是从早期预览版向更新后的正式版本的过渡，DeepSeek 强调了智能体性能。

“DeepSeek-V4-Pro 正式版本已发布，具有显著增强的智能体能力，并支持 Responses API 和 Codex 集成，”DeepSeek 在其 API 网站上表示。“它现在已在网页、移动应用和 API 上全面提供；我们欢迎您的测试和反馈。”

DeepSeek 的更新日志同样表示，正式发布的模型具有“显著增强的智能体能力”，尤其是在生产环境中。使用 API 的开发者无需更改模型标识符：deepseek-v4-pro 现在会解析为最新的 V4-Pro 版本。

该公司还添加了原生的 OpenAI Responses API 支持，减少了已经围绕该接口构建的应用程序所需的集成工作量。

DeepSeek 表示，V4-Pro 针对 OpenAI 自己的开源框架 Codex 进行了优化，可实现一键设置。其当前的 API 文档将 Responses API、工具调用、JSON 输出和 Anthropic 格式 API 列为 V4-Pro 和 V4-Flash 支持的接口。

对于直接使用 DeepSeek 而非通过 API 使用的开发者，现在可以通过该公司应用和网站上的“专家模式”访问 V4-Pro。

推理努力成为另一个部署旋钮

DeepSeek 还将推理努力作为 V4-Pro 和 V4-Flash 上的显式控制项。

V4 模型文档描述了三个级别：Non-think，专为快速日常任务设计；Think High，用于更复杂的问题解决和规划；以及 Think Max，为困难问题分配大量推理。

这种区分对于智能体系统在操作上很重要，因为在每个步骤上进行最大限度的推理会消耗不必要的时间和 Token。编码智能体可能会使用相对较少的推理来检查文件或执行常规工具调用，然后在诊断困难错误或规划多阶段代码更改时增加努力程度。

DeepSeek 最新的基准测试表表明，0813 模型在面向智能体的测试上有显著改进，尽管这些数字是公司自报的，且一些结果取决于框架配置。

DeepSeek 报告称 V4-Pro-0813 的得分为：Terminal Bench 2.1 为 87.9，Toolathlon-Verified 为 74.1，DSBench-FullStack 为 71.1，DSBench-Hard 为 67.2。它并没有在 DeepSeek 自己的表格中的所有比较中领先：例如，Fable 5 在 Toolathlon-Verified 上的得分为 77.9，在 DSBench-FullStack 上的得分为 77.2。

在基准测试表下面隐藏着一个特别重要的限定条件。对于公开的代码智能体任务，DeepSeek 表示 V4-Pro-0813 是在“最小模式”下使用其即将推出的 DeepSeek Harness 进行测试的。

换句话说，随 Harness 一起发布的一些智能体结果并非纯粹的模型基准测试。它们衡量的是在智能体执行环境中运行的模型——这正是 DeepSeek 现在向开发者发布的软件层。

DeepSeek API 价格轨迹的急剧逆转

对于已经在生产环境中运行 DeepSeek 的团队来说，更大的直接变化可能是定价。

DeepSeek 当前的 API 文档显示，V4-Flash 的缓存未命中输入 Token 价格为每百万 0.14 美元，输出 Token 为每百万 0.28 美元，而 V4-Pro 的缓存未命中输入为 0.435 美元，输出为 0.87 美元。缓存命中的价格要便宜得多，Flash 为 0.0028 美元，Pro 为 0.003625 美元。

这些价格本身相比 V4 在 4 月份首次发布时的经济性已经有了大幅降低。当 V4 在 4 月份发布时，V4-Pro 的缓存未命中输入 Token 定价为每百万 1.74 美元，输出 Token 为每百万 3.48 美元。到 5 月下旬，DeepSeek 将 75% 的降幅永久化，巩固了其作为高容量智能体工作负载异常廉价选择的地位。现在，钟摆正在向另一个方向摆动。

从 8 月 16 日 16:00 UTC 开始，DeepSeek 将根据 API 调用发生的时间收取不同的费率。高峰时段为 UTC 时间 01:00-04:00 和 06:00-10:00（分别为美国东部时间晚上 9 点至 12 点，以及凌晨 2 点至 6 点），所有其他时间被归类为低谷时段。低谷时段费率是相应高峰价格的一半。

对于 V4-Flash，低谷时段缓存未命中输入从每百万 Token 0.14 美元上涨至 0.22 美元，而输出从 0.28 美元上涨至 0.66 美元。在高峰时段，这些费率分别达到 0.44 美元（输入）和 1.32 美元（输出）。

V4-Pro 从目前的每百万缓存未命中输入 Token 0.435 美元和输出 0.87 美元，分别变为低谷时段的 0.66 美元和 1.98 美元。高峰费率则上涨至输入 1.32 美元和输出 3.96 美元。

对于缓存输入，涨幅更为明显。V4-Pro 缓存命中从目前的每百万 Token 0.003625 美元上涨至低谷时段的 0.022 美元和高峰时段的 0.044 美元。Flash 则从 0.0028 美元上涨至低谷时段的 0.007 美元和高峰时段的 0.014 美元。

这使得“低 50%”的低谷时段说法在没有上下文的情况下可能具有误导性。低谷时段比 DeepSeek 的新高峰费率便宜 50%；它并不是比开发者今天支付的 API 价格低 50% 的折扣。

对于由一百万个缓存未命中输入 Token 加上一百万个输出 Token 组成的简单工作负载，V4-Pro 目前的成本为 1.305 美元。相同的 Token 组合在低谷时段将花费 2.64 美元，大约是原来的两倍，而在高峰时段则花费 5.28 美元，是当前价格的四倍多。

根据缓存输入、未缓存输入和生成输出的比例，实际应用程序成本会有很大差异，这使得这些综合数字只是说明性的，而不是通用的总成本估算。

DeepSeek 正在向智能体堆栈上游移动

这一时机使得其战略方向不容错过。

当 DeepSeek 在 4 月 24 日发布 V4 预览版时，主要的焦点在于该公司能够通过异常高效的架构提供多少前沿级的能力。

V4-Pro 采用了结合压缩稀疏注意力和重度压缩注意力的混合注意力设计；在 100 万 Token 上下文下，DeepSeek 表示它只需要 V3.2 单 Token 推理 FLOPs 的 27% 和 KV 缓存的 10%。

8 月 13 日的发布将竞争推向了更高一层。

DeepSeek 现在拥有了一个围绕智能体工作负载进行调整的更新版 V4-Pro、旨在更容易与现有开发者工具连接的标准化接口、可配置的推理努力，以及一个用于控制围绕智能体的模型、工具、沙箱、文件系统和编排的 MIT 许可证框架。

与此同时，DeepSeek 正在向开发者表明，不能假设其极具侵略性的低 API 费率是永久的。对于考虑该平台的组织来说，工作负载调度、缓存行为以及在自己的基础设施上运行开放权重的选项，现在成为总成本计算中更重要的部分。

这使得 DeepSeek 同时追求两个潜在冲突的优势：使其智能体堆栈更易于访问和开放，同时使其自己的托管 API 变得更加昂贵。

对于企业开发者来说，Harness 最终可能是周四公告中更具影响力的部分。模型越来越可以在标准化接口背后进行替换。而控制智能体如何推理、调用工具、编辑软件和在工作流中持久化的框架，可能要难替换得多。

DeepSeek 现在也在争夺这一层。
