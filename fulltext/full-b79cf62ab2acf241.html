Meta 发布可在 Mac 上运行的开放权重...

📅 2026-10-15 📄 TechCrunch AI 🔗 原文链接

原标题：Meta launches an open-weight AI model that runs on Macs

中文摘要： Meta 发布开放权重 AI 模型 Muse Spark Open，号称美国"最强"。该模型拥有 8160 亿参数和 100 万 token 上下文窗口，原生多模态，专为复杂编程和智能体任务设计，可在配备 M5 Ultra 芯片的 Mac Studio 上本地运行，但需至少 1TB 内存。Meta 已将其与 Muse Code 编程终端配合，用于代码修复和视频编辑等智能体工作流程，现可通过多个 API 平台获取。

Meta 发布了其称之为美国"最强"的开放权重模型。该模型名为 Muse Spark Open，其独特之处在于专为 Mac 电脑而设计。

根据 Meta 周四发布的评估结果，这款新模型拥有 8160 亿个参数和 100 万 token 的上下文窗口，号称性能优于其他流行的开放权重模型。

Muse Spark Open 为原生多模态模型，专为复杂编程任务和智能体（agentic）工作而构建。它还被设计为可在苹果电脑上本地运行。不过，据 Engadget 报道，要在本地运行该模型，你仍然需要强大的硬件，内存要求至少为 1TB。该模型在配备 M5 Ultra 芯片的 Mac Studio 上运行效果最佳。

尽管如此，如果你能凑齐足够的内存，Muse Spark Open 或许能成为编程和其他桌面任务的得力干将。Meta 表示，他们将该模型与其 AI 编程终端 Muse Code 配合使用，并将其部署到各种智能体工作流程中，包括为 Mastodon 客户端进行代码修复，涵盖"错误修复、新功能[以及]完整构建"。

该公司表示，他们还将该模型用于运行高端视频编辑软件 DaVinci Resolve，并透露该模型能够审看和裁剪视频素材。

开放权重模型具有许多闭源专有模型无法提供的独特行业优势。开放权重模型的成本效益可能显著更高，还能提供闭源模型所不具备的透明度和灵活性。

Meta 目前已通过多个不同的 API 平台提供该新模型。
