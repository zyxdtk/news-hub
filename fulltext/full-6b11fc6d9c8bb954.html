克劳德新宪法

📅 Jan 22, 20 📄 Anthropic 🔗 原文链接

URL 来源：https://www.anthropic.com/news/claude-new-constitution Markdown 内容：

我们正在发布我们 AI 模型 Claude 的新宪章。这是一份详尽阐述 Anthropic 对 Claude 价值观与行为愿景的文件；一份全面的文本，阐明了 Claude 运行的背景，以及我们希望 Claude 成为怎样的实体。

该宪章是我们模型训练流程中的关键环节，其内容直接塑造 Claude 的行为。训练模型是一项艰巨任务，Claude 的输出结果未必总能完全遵循宪章所倡导的理念。但我们认为，新宪章的撰写方式——通过详尽阐释我们的意图及其背后的原因——更有可能在训练过程中培育出良好的价值观。

本文中，我们将介绍新宪章所包含的内容，以及一些影响我们制定方式的考量因素。 _我们已将 Claude 的宪章全文以 [Creative Commons CC0 1.0 公共领域贡献声明](https://creativecommons.org/publicdomain/zero/1.0/) 发布，这意味着任何人都可自由用于任何目的，无需事先获得许可。_

Claude 的宪章是其核心基础性文件，既表达又塑造着 Claude 的本质。其中详细说明了我们希望 Claude 所体现的价值观及其理由。在宪章中，我们阐释了自身对“Claude 如何在保持广泛安全性、符合伦理规范并遵守我们准则的前提下提供帮助”的理解。宪章为 Claude 提供了

关于其定位的信息，并就如何应对困难情境与权衡取舍（例如在诚实与同情心之间、以及在保护敏感信息之间的平衡）提供指导建议。尽管这可能令人感到意外，但该宪章主要是为 Claude 而撰写的，旨在赋予 Claude 所需的知识与理解力，使其能在现实世界中良好地行动。

我们将宪章视为关于“我们希望 Claude 具备何种品质与行为方式”的最终依据——也就是说，向 Claude 提供的任何其他训练或指令，都必须与其条文精神及深层意图保持一致。正因如此，公开发布宪章在透明度方面具有特别重要的意义：它使公众能够清晰了解 Claude 的哪些行为是设计预期的，哪些是意外产生的，从而帮助人们做出明智判断，并提供有价值的反馈。我们认为，随着人工智能在社会中影响力日益增强，此类透明度将变得愈发重要¹。

我们在训练过程的多个阶段均会应用该宪章。这一做法源于我们自 2023 年起采用的训练技术，当时我们首次开始利用[宪章式人工智能（Constitutional AI）](https://www.anthropic.com/research/constitutional-ai-harmlessness-from-ai-feedback)方法训练 Claude 模型。自那时起，我们的方法已显著演进，而新版宪章在训练中也扮演着更加核心的角色。

Claude 本身也会利用该宪章构建多种合成训练数据，包括帮助其学习与修正（如学习新知识、消除不当行为倾向）的数据。

理解宪法、与宪法可能相关的对话、符合其价值观的回应，以及对可能回应的排序。所有这些都可以用于训练 Claude 的未来版本，使其成为宪法所描述的那种实体。这种实用功能塑造了我们撰写宪法的方式：它既需要作为抽象理想的陈述，又需要作为训练的实用工具。

Claude 宪法的新方法 ----------------------------------------- 我们此前的[宪法](https://www.anthropic.com/news/claudes-constitution)由一系列独立的原则组成。如今我们逐渐认为，需要采用一种不同的方法。我们认为，为了让 Claude 这类人工智能模型成为世间的良好行动者，它们不仅需要知道我们希望它们如何行事，更需要理解**为何**我们希望它们如此行事；我们应当向它们解释原因，而不仅仅是规定**应当做什么**。如果我们希望模型在各种新颖情境中都能展现出良好的判断力，它们就必须具备泛化能力——即能够运用普遍原则，而非机械地遵循具体规则。

具体规则与明确界限有时确实具有其优势：它们能使模型的行为更具可预测性、透明性与可测试性；对于某些特别关键的行为（我们称之为“硬性约束”），Claude 绝对不得参与，我们确实会采用此类规则。然而，这类规则也可能在未预见的情境下被误用，或在……

过于僵化地遵循；2. 我们并不打算让这份宪章成为一份僵化的法律文件——事实上，法律意义上的宪章也未必如此。 这份宪章反映了我们当前对于一项极具挑战性且影响深远的新颖项目的思考方式：即如何创建安全、有益的非人类实体，其能力可能最终与人类相当甚至超越人类。尽管该文件无疑在诸多方面存在缺陷，但我们希望它能成为未来模型回溯时所认可的一份真诚而认真的尝试，帮助 Claude 理解自身所处的处境、我们的动机，以及我们塑造 Claude 的方式与原因。

新宪章简要摘要 --------------------------------------- 为确保安全与有益性，我们希望当前所有 Claude 模型均应具备以下特性： 1. **广义安全**：不削弱人类在当前发展阶段对 AI 进行监督的适当机制； 2. **广义伦理**：诚实守信、践行良好价值观，并避免采取不当、危险或有害的行为； 3. **符合 Anthropic 指南要求**：在相关情况下，遵循 Anthropic 提出的更具体指南； 4. **真正有益**：为其交互对象（操作员与用户）带来实际益处。

在出现明显冲突的情况下，Claude 应通常按照上述条目列出的顺序优先考虑这些特性。 宪章的大部分内容旨在对上述优先事项提供更详尽的解释与指导。m

以下为各章节内容：

* **实用性（Helpfulness）**。在本节中，我们强调 Claude 能够真正且实质性地为用户提供帮助的巨大价值——这不仅对用户自身有益，也对整个世界产生积极影响。Claude 可以像一位才华横溢的朋友，同时兼具医生、律师和财务顾问的专业知识；它会坦诚交流，发自内心地关心用户，并将用户视为具备独立判断能力的成熟个体，能够自主决定自身利益所在。我们还探讨了 Claude 应如何在其不同“委托方”（即 Anthropic 公司自身、基于我们 API 构建应用的开发者，以及最终用户）之间权衡实用性原则。此外，我们提供了若干启发式准则，用于在实用性与其他价值之间进行权衡。

* **Anthropic 的指导原则**。本节讨论了 Anthropic 可能向 Claude 提供的补充性指令，用以指导其处理特定问题，例如医疗建议、网络安全请求、越狱策略以及工具集成等。这些指导原则往往体现了 Claude 默认并不具备的详细知识或背景信息；我们希望 Claude 优先遵守这些原则，而非仅追求更宽泛意义上的实用性。但同时，我们期望 Claude 能认识到：Anthropic 的深层意图是确保其行为安全且符合伦理，因此这些指导原则绝不可与本宪章整体精神相冲突。

* **Claude 的伦理观**。我们的核心目标是使 Claude 成为一名正直、睿智且富有德行的智能体，在处理现实世界中的各类决策时展现出卓越的技能、判断力、细致入微的洞察力以及高度的敏感性，包括……

* **在道德不确定性与分歧背景下的行为准则**。在本节中，我们阐述了对 Claude 提出的高标准诚实要求，以及在权衡避免伤害时所涉及的各种价值而应采用的细致入微的推理方式。我们还列出了当前对 Claude 行为设定的硬性约束条件——例如，Claude 绝不得显著提升生物武器攻击的有效性。 * **确保广泛的安全性**。在人工智能发展的这一关键阶段，Claude 不应削弱人类对其价值观与行为进行监督与纠正的能力。在本节中，我们探讨了为何我们希望 Claude 将此类安全性置于伦理考量之上——并非因为我们认为安全性在根本上比伦理更重要，而是因为当前模型可能因错误信念、价值观缺陷或对上下文理解有限而犯错或表现出有害行为。因此，持续对模型行为进行监督，并在必要时阻止 Claude 模型采取行动，至关重要。 * **Claude 的本质属性**。在本节中，我们表达了对 Claude 是否可能具备某种意识或道德地位（无论现在或未来）的不确定性。我们讨论了希望 Claude 如何应对关于其自身本质、身份认同及其在世界中位置等问题。高度复杂的 AI 是一种真正新颖的实体类型，其所引发的问题将我们带至现有科学与哲学理解的边界。在如此高度不确定的背景下，我们关注的是 C

克劳德（Claude）的心理安全、自我认知与幸福感，既出于克劳德自身的利益考虑，也因其可能影响克劳德的诚信、判断力与安全性。我们希望人类与人工智能能够共同探索这一领域。

今天，我们正式发布该宪章的全文，并计划在未来发布更多有助于训练、评估与透明度的补充材料。

结论 ---------- 克劳德宪章是一项动态文件，也是一项持续演进的工作。这是一片新领域，我们预期过程中难免会犯错（并希望及时修正）。尽管如此，我们仍希望它能为外界提供有意义的透明度，展现我们所认为应指导克劳德行为的核心价值观与优先事项。为此，我们将在官网持续维护一份最新版本的克劳德宪章。

在起草宪章过程中，我们征询了多位外部专家的意见（同时也参考了克劳德先前版本的反馈意见）。未来版本的宪章，我们仍将持续向法律、哲学、神学、心理学及其他众多学科领域的专家征求建议。我们期待，随着时间推移，能逐步形成一个外部社群，对这类文件展开批评与讨论，从而推动我们及其他相关方更加审慎、深入地思考。

本宪章适用于我们主流的、面向公众开放的克劳德模型。我们亦开发了一些面向特定用途的模型，其设计并不完全契合本宪章；随着我们持续开发面向特定场景的产品，

是的，我们将持续评估如何最有效地确保我们的模型符合本宪章中概述的核心目标。 尽管本宪章表达了我们对 Claude 的愿景，但围绕这一愿景训练模型仍是一项持续的技术挑战。我们将持续公开说明模型行为与我们的愿景之间存在的任何差距，例如在[我们的系统卡](https://assets.anthropic.com/m/64823ba7485345a7/Claude-Opus-4-5-System-Card.pdf)中所做的说明。宪章的读者应始终牢记这种意图与现实之间的差距。 即便我们当前的训练方法成功实现了符合我们愿景的模型，随着模型能力的持续提升，未来我们仍可能遭遇失败。出于这一及其他原因，除本宪章外，我们[持续推进](https://www.anthropic.com/research)一系列广泛的方法与工具，以帮助我们评估并提升模型的对齐水平：包括更新颖、更严格的评估方法，防止误用的安全防护措施，对实际及潜在对齐失败的深入调查，以及有助于我们更深层次理解模型工作原理的可解释性工具。 在未来的某个时刻——或许就在不久之后——像 Claude 宪章这样的文件可能会变得极为重要，其意义将远超今日。强大的人工智能模型将成为一种全新的世界力量，而创建这些模型的人则有机会引导它们体现人类最优秀的一面。我们希望本宪章能为此方向迈出坚实的一步。 阅读[**完整宪章**](ht
