DeepSeek-V4发布：性能逼近SOTA，成本仅为Opus 4.7和GPT-5.5的1/6

Carl Franzen
发布于
2026年4月24日，太平洋时间上午9:34
更新于
2026年4月24日，太平洋时间上午9:37

跃出彩虹核心的巨鲸，伴随金钱与代码。图片来源：VentureBeat使用OpenAI ChatGPT Images 2.0制作

巨鲸再次跃出水面。
DeepSeek，这家中国量化分析公司幻方资本的AI初创分支，凭借其媲美美国专有巨头的开源R1模型的发布，在2025年1月几乎一夜之间轰动全球。
从那时起，AI领域已经历了一个时代，尽管DeepSeek对该模型及其V3系列发布了数次更新，但国际AI和商业界很大程度上一直在屏息以待R1时刻的后续之作。
现在，随着昨晚DeepSeek-V4的发布，这一时刻已经到来。这是一个1.6万亿参数的混合专家模型，在商业友好的开源MIT许可下免费提供，其性能接近——并在某些基准测试中超越——世界上最先进的闭源系统，而应用程序编程接口（API）成本仅约为后者的1/6。
此次发布——DeepSeek AI研究员Deli Chen在X上将其描述为V3发布484天后的“心血结晶”——被誉为“第二次DeepSeek时刻”。
正如Chen在帖子中所指出的，“AGI属于每个人”。它现在可以在AI代码共享社区Hugging Face上以及通过DeepSeek的API使用。

前沿级AI被推入更低价格带

DeepSeek-V4发布最直接的影响是经济层面的。修正后的定价表显示，DeepSeek并未将其新的Pro模型定价在接近零的水平，但仍将高端模型的访问门槛推至远低于美国领先前沿模型的成本层级。
DeepSeek-V4-Pro的API定价为：缓存未命中时每100万输入token 1.74美元，每100万输出token 3.48美元。

DeepSeek V4 API定价表。图片来源：DeepSeek AI
这使得一个简单的100万输入、100万输出的比较成本为5.22美元。如果使用缓存输入，输入价格降至每100万token 0.145美元，使同样的混合比较成本降至3.625美元。
这比OpenAI和Anthropic目前的溢价定价要便宜得多。GPT-5.5的定价为每100万输入token 5.00美元，每100万输出token 30.00美元，在同样的简单比较中合计为35.00美元。
Claude Opus 4.7定价为输入5.00美元，输出25.00美元，合计30.00美元。

在标准的缓存未命中定价下，DeepSeek-V4-Pro的成本大约是GPT-5.5的七分之一，约为Claude Opus 4.7的六分之一（1/6）。
使用缓存输入时，差距进一步扩大：DeepSeek-V4-Pro的成本约为GPT-5.5的十分之一，约为Claude Opus 4.7的八分之一。
更极端的接近零定价属于DeepSeek-V4-Flash，而不是Pro模型。Flash的定价为缓存未命中时每100万输入token 0.14美元，每100万输出token 0.28美元，合计0.42美元。
使用缓存输入时，价格降至0.308美元。在这种情况下，DeepSeek的廉价模型在简单的输入加输出比较中比GPT-5.5和Claude Opus 4.7低98%以上，或成本近百分之一——尽管性能有明显下降。
DeepSeek正在将先进模型的经济学压缩到一个低得多的区间，迫使开发者和企业重新审视围绕高端闭源模型的成本效益计算。
对于运行大型推理工作负载的公司来说，这种价格差距可以改变哪些自动化是值得的。在GPT-5.5或Claude Opus 4.7上看起来太昂贵的任务，在DeepSeek-V4-Pro上可能变得经济可行，在DeepSeek-V4-Flash上更是如此。这次发布并没有让智能变得免费，但它确实让高端提供商更难仅凭性能来捍卫自己的市场。

前沿基准测试：DeepSeek-V4-Pro紧随其后，但GPT-5.5和Opus 4.7在多数共享测试中依然领先

最好将DeepSeek-V4-Pro-Max理解为一次重大的开放权重飞跃，而不是对最新闭源前沿系统的全面击败。
该模型最强的基准测试声明来自DeepSeek自己的比较表，其中显示了它与GPT-5.4 xHigh、Claude Opus 4.6 Max和Gemini 3.1 Pro High的对比，并在包括Codeforces和Apex Shortlist在内的几项测试中击败了它们。
但这与和OpenAI更新的GPT-5.5或Anthropic更新的Claude Opus 4.7正面交锋不同。
如果只看DeepSeek-V4与最新专有模型的对比，情况则更为克制。
在这组共享测试中，GPT-5.5和Claude Opus 4.7仍在大多数类别中领先。
DeepSeek-V4-Pro-Max最好的表现是在BrowseComp上，这是衡量代理式AI网络浏览能力（特别是高度容器化的信息）的基准，其得分为83.4%，紧随GPT-5.5的84.4%之后，领先于Claude Opus 4.7的79.3%。
在Terminal-Bench 2.0上，DeepSeek得分为67.9%，接近Claude Opus 4.7的69.4%，但远低于GPT-5.5的82.7%。

共享的学术推理结果有利于闭源模型：在GPQA Diamond上，DeepSeek-V4-Pro-Max得分90.1%，而GPT-5.5达到93.6%，Claude Opus 4.7达到94.2%。
在不使用工具的“人类最后考试”上，DeepSeek得分37.7%，落后于GPT-5.5的41.4%、GPT-5.5 Pro的43.1%和Claude Opus 4.7的46.9%。启用工具后，DeepSeek上升至48.2%，但仍落后于GPT-5.5的52.2%、GPT-5.5 Pro的57.2%和Claude Opus 4.7的54.7%。
代理和软件工程的结果更为复杂，但仍显示DeepSeek-V4-Pro-Max落后于GPT-5.5和Opus 4.7。
在Terminal-Bench 2.0上，DeepSeek的67.9%与Claude Opus 4.7的69.4%相比具有竞争力，但GPT-5.5要高得多，为82.7%。
在SWE-Bench Pro上，DeepSeek的55.4%落后于GPT-5.5的58.6%和Claude Opus 4.7的64.3%。在MCP Atlas上，DeepSeek的73.6%略低于GPT-5.5的75.3%和Claude Opus 4.7的79.1%。
BrowseComp表现突出：DeepSeek的83.4%击败了Claude Opus 4.7的79.3%，几乎匹配GPT-5.5的84.4%，尽管GPT-5.5 Pro的90.1%仍然遥遥领先。
因此最终，在各公司发布的表格中可以直接比较的基准测试上，DeepSeek-V4-Pro-Max似乎并没有取代GPT-5.5或Claude Opus 4.7。但它在其中几项上已经足够接近——特别是BrowseComp、Terminal-Bench 2.0和MCP Atlas——以至于其低得多的API定价成为了头条。
实际上，DeepSeek不需要赢得排行榜的每一行才能显得重要。如果它能在许多与企业相关的代理和推理任务上以大约GPT-5.5或Claude Opus 4.7标准API成本六分之一到七分之一的价格提供接近前沿的性能，它仍然迫使人们重新思考高级AI部署的经济学。
DeepSeek-V4-Pro-Max显然是目前该领域最强的开放权重模型，并且在几项实际基准测试中异常接近前沿闭源系统。
虽然GPT-5.5和Claude Opus 4.7在公司的基准测试图表中的大多数直接对比中仍保持领先，但DeepSeek V4 Pro在大幅降低成本和开放可用的情况下紧随其后。

相较DeepSeek V3.2的巨大飞跃

要理解此次发布的规模，必须看看基础模型的性能提升。DeepSeek-V4-Pro-Base代表了相对于上一代DeepSeek-V3.2-Base的显著进步。在世界知识方面，V4-Pro-Base在MMLU（5-shot）上达到90.1，而V3.2为87.8，在MMLU-Pro上从65.5大幅跃升至73.5。
高级推理和经验证事实的改进更为显著：在SuperGPQA上，V4-Pro-Base达到53.9，而V3.2为45.0；在FACTS Parametric基准上，其性能比上一代翻了一倍多，从27.1跃升至62.6。Simple-QA验证分数也出现了从28.3到55.2的大幅上升。
长上下文能力也得到了优化。在LongBench-V2上，V4-Pro-Base得分51.5，显著超过了V3.2-Base的40.2。在代码和数学方面，V4-Pro-Base在HumanEval（Pass@1）上达到76.8，高于V3.2-Base的62.8。
这些数字强调，DeepSeek不仅优化了推理成本，而且从根本上提高了其基础架构的智能密度。Flash变体的效率故事同样引人注目。DeepSeek-V4-Flash-Base尽管使用了大量更少的参数，但在广泛的基准测试中表现优于更大的V3.2-Base，特别是在长上下文场景中。

新的信息“交通控制器”：流形约束超连接

DeepSeek提供这些价格和性能数据的能力源于其今天同时发布的技术报告中详述的激进架构创新，该报告题为“迈向高效百万Token上下文智能”。
V4最突出的技术成就是其原生的100万token上下文窗口。从历史上看，维持如此大的上下文需要大量内存（键值或KV缓存）。
DeepSeek通过引入混合注意力架构解决了这个问题，该架构结合了压缩稀疏注意力（CSA）以降低初始token维度，以及重度压缩注意力（HCA）以积极压缩长距离依赖的内存占用。
在实践中，即使在100万token上下文下运行，与前身DeepSeek-V3.2相比，V4-Pro模型仅需要10%的KV缓存和27%的单token推理FLOPs。
为了稳定1.6万亿参数的网络，DeepSeek超越了传统的残差连接。该公司的研究人员引入了流形约束超连接，以加强跨层的信号传播，同时保持模型的表达能力。
mHC允许AI拥有更广泛的信息流（从而可以学习更复杂的事物），而不会冒模型在训练期间变得不稳定或“崩溃”的风险。这就像给一个城市修了一条10车道的高速公路，但增加了一个完美的AI交通控制器，以确保没有人会踩刹车。
这与Muon优化器配合使用，使团队能够在超过32万亿多样化和高质量的token上进行预训练时实现更快的收敛和更大的训练稳定性。
这一预训练数据经过精炼，去除了自动生成的内容，减轻了模型崩溃的风险，并优先考虑了独特的学术价值。该模型的1.6万亿参数采用了混合专家设计，每个token仅激活490亿参数，进一步降低了计算需求。

训练混合专家模型协同工作

DeepSeek-V4不仅仅是被训练出来的；它是通过独特的两阶段范式“培育”出来的。
1. 首先，通过独立专家培育，使用GRPO（群组相对策略优化）算法通过监督微调（SFT）和强化学习（RL）训练了特定领域的专家。这允许每个专家掌握数学推理或代码库分析等专业技能。
2. 其次，统一模型整合通过策略蒸馏将这些不同的能力整合到一个单一模型中，其中统一模型作为学生学习优化与教师模型的反向KL散度损失。这种蒸馏过程确保模型在作为一个凝聚整体运行的同时，保留了每个专家的专门能力。
该模型的推理能力进一步细分为三种递增的“努力”模式。
1. “非思考”模式为常规任务提供快速、直观的响应。
2. “高思考”模式为复杂问题解决提供有意识的逻辑分析。
3. 最后，“极限思考”模式突破了模型推理的边界，在复杂推理和代理任务上弥合了与前沿模型的差距。这种灵活性允许用户将计算努力与任务难度相匹配，进一步提高了成本效益。

用中国本土华为昇腾NPU打破英伟达GPU束缚

虽然模型权重是头条，但与之一起发布的软件堆栈对于“主权AI”的未来可以说更为重要。
分析师Rui Ma强调了发布中的一句话是最关键的：DeepSeek在华为昇腾NPU（神经网络处理器）上验证了其细粒度专家并行（EP）方案。
然而，值得注意的是，DeepSeek仍声称除了华为NPU外，它还使用了官方许可的合法Nvidia GPU进行DeepSeek V4的训练。
DeepSeek还开源了MegaMoE大型内核，作为其DeepGEMM库的一部分。这种基于CUDA的实现为RL展开和高速代理服务等延迟敏感任务提供了高达1.96倍的加速。
这一举措确保开发者能够在现有硬件上极其高效地运行这些大型模型，进一步巩固了DeepSeek作为开源AI基础设施主要推动者的角色。
技术报告强调，这些优化对于在所有官方服务中支持标准的100万上下文至关重要。

许可和本地部署

DeepSeek-V4在MIT许可下发布，这是业内最宽松的框架。这允许开发者出于商业目的使用、复制、修改和分发权重而无需版税——这与其他公司青睐的“受限”开放权重许可形成了鲜明对比。
对于本地部署，DeepSeek建议将采样参数设置为temperature = 1.0和top_p = 1.0。对于使用“极限思考”推理模式的用户，团队建议将上下文窗口设置为至少384K token，以避免截断模型的内部推理链。
此次发布包括一个专用的编码文件夹，其中包含Python脚本，演示如何以兼容OpenAI的格式编码消息并解析模型的输出，包括推理内容。
DeepSeek-V4还与Claude Code、OpenClaw和OpenCode等领先的AI代理无缝集成。这种原生集成强调了其作为开发者工具基石的作用，为主要云提供商的专有生态系统提供了开源替代方案。

社区反应及未来展望

社区的反映是震惊与认可。Hugging Face官方欢迎“巨鲸”回归，并表示经济高效的100万上下文长度时代已经到来。
业内专家指出，“第二次DeepSeek时刻”有效地重置了整个领域的发展轨迹，给OpenAI和Anthropic等闭源提供商带来了证明其溢价的巨大压力。
AI评估公司Vals AI指出，DeepSeek-V4现在是“我们Vibe Code基准测试上的第一名开放权重模型，而且遥遥领先”。
DeepSeek正迅速淘汰其旧架构。该公司宣布，传统的deepseek-chat和deepseek-reasoner端点将于2026年7月24日完全退役。所有流量目前正被重新路由到V4-Flash架构，标志着向百万token标准的全面过渡。
DeepSeek-V4不仅仅是一个新模型；它是对现状的挑战。通过证明架构创新可以替代原始的计算最大化，DeepSeek以低得多的成本让全球开发者社区能够访问最高级别的AI智能——这可能使全球受益，即使华盛顿的立法者和领导人正在对中国实验室从美国专有巨头“蒸馏”以训练开源模型表示担忧，并担心上述开源或越狱的专有模型被用于制造武器和实施恐怖活动。
事实是，虽然所有这些都是潜在的风险——就像以前拓宽信息获取的技术（如搜索和互联网本身）一样——但其好处似乎远远超过了风险，DeepSeek保持前沿AI模型开放的追求有利于整个地球上潜在的AI用户，特别是希望以尽可能低的成本采用前沿技术的企业。
