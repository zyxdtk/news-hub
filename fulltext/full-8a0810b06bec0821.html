基于生活史叙事的社区治理模拟大模型基准测试

原标题：Benchmarking LLMs for Community Governance Simulation with Life-history Narratives

中文摘要： 本文提出基于生活史叙事的社区治理模拟框架，构建了包含92位居民、120万字生活史及2000余问答对的数据集。对18个主流大模型的基准测试表明，丰富的生活史能提升模拟保真度，但提示词方法成本高昂。为此，提出curriculum-LoRA算法，在匹配最强基线保真度的同时将单次调用成本降低约10倍，实现帕累托占优。最后，集成该算法的闭环政策评估系统，使资源受限的地方政府能够进行政策预评估。

摘要
有效的社区治理取决于了解特定居民的想法和需求。近期的研究使用大语言模型来模拟人类受访者，提供了一种可扩展、可复现的低成本研究人类态度和行为的方法。然而，这些研究通常仅使用少量人口统计变量（年龄、性别、收入）来提示模型，仅模拟一般的角色类型。这对于社区治理来说是不够的，因为决策取决于特定居民的观点。我们通过一个涵盖数据集、基准测试、算法和系统的综合研究框架弥补了这一空白。该数据集包含约120万字符的第一人称叙事，是通过对城市社区92位居民每人进行两小时的半结构化访谈收集的，涵盖九个社区治理领域。该基准测试在四种提示策略下探测了18个主流大语言模型，结果表明，添加丰富的生活史画像显著提高了保真度，使其高于无画像基线，但这种收益伴随着更长提示带来的每次调用更多的输入token成本。算法 curriculum-LoRA 是一个参数高效的个性化框架，通过缩小这种保真度-成本差距，它以大约 10× 更低的单次调用成本匹配了最强基线的保真度，并且在测试的每种配置中均实现帕累托占优。该系统将 curriculum-LoRA 集成到闭环政策评估流程中。总之，这些结果使得资源受限的地方政府能够实现个体级别的基于大语言模型的居民模拟，从而能够在实际部署之前在计算机中系统地预评估社区治理决策。

关键词：大语言模型，社会治理，社会模拟

引言
社区治理是社会稳定和公众信任的基础。作为公共管理最基层的尺度，它是关于服务提供、资源配置和冲突解决的政策转化为居民生活体验的地方 [ostrom1990governing, putnam2000bowling]。这一层级治理的有效性在很大程度上取决于了解居民的实际想法、需求以及对特定提案的可能反应 [soss2000unwanted, schneider1993social]。如果没有这种了解，政策就有可能与当地现实脱节，从而侵蚀公众信任并破坏社会凝聚力 [sampson2012great, heberer2009community]。

然而，获取这些知识仍然非常困难。大规模收集高质量的回复既缓慢又昂贵：每位受访者都必须被招募、补偿并投入大量时间，这使得常规的、广泛覆盖的数据收集超出了大多数资源受限的地方政府的能力范围 [groves2011survey, dillman2014internet]。也许更根本的是，传统的调查本质上是一次性的：无法在反事实的政策设计下对相同的受访者进行再次询问，使得决策者无法在实际部署前评估提案 [salganik2019bit, manning2024automated]。

最近大语言模型的出现提供了一种放宽这两个约束的方法：它们查询成本低、可复现且可重复运行。快速增长的大量工作表明，当使用人口统计或态度画像进行提示时，大语言模型可以再现从政治学到城市规划等领域的人类行为倾向 [argyle2023one, santurkar2023whose, lin2026alignsurvey, aher2023using, horton2023large, park2023generative, wang2025user, zhang2025simulating]。然而，这些研究几乎无一例外地使用稀疏的、通用的人物描述来提示模型：少数几个人口统计变量，如年龄、性别、收入和教育，或者在没有与真实个体直接接触的情况下拼凑的简短合成传记 [hwang2023aligning, jiang2023personallm]。这种输入最多只能让大语言模型扮演一个人口统计角色类型，而不是任何特定的个体。然而，社区治理的要求不止于此。作为公共管理最基层的层面，社区工作面对面地处理居民事务，重要的是确切地知道哪些个体会以何种方式反应，而不是群体平均水平。一个强烈的反对者就能让邻居们反对一项政策；一个被忽视的家庭就能成为长期冲突的根源；一个关键的支持者就能说服犹豫不决的群体。捕捉这种异质性需要在个体层面进行模拟。这反过来又需要更丰富的居民数据，以便模型能够区分个体之间的差异。然而，将如此大量的画像信息输入到当前最先进的商业大语言模型中会产生巨大的成本。因此，如何将成本保持在社区规模可接受的低水平也是一个必须解决的关键问题。

据我们所知，以前没有工作尝试使用大规模、细粒度的居民画像数据来驱动大语言模型进行社区治理。为了为这一方向奠定基础并解决上述差距，我们提出了一个包含四个组件的综合研究框架：数据集、基准测试、算法和系统。

首先是数据集：我们对一个代表性城市社区的92位长期居民进行了约两小时的半结构化访谈 [guest2006many]，涵盖了社区治理的九个核心维度。由此产生的语料库包含约120万字符的第一人称叙事，我们从中提炼出2000多对结构化的问答，捕捉每位居民的人口背景、治理态度和行为模式。因为每位居民现在都由丰富的生活史来代表，据我们所知，该语料库首次使得在社区治理领域对更个性化的大语言模型角色扮演进行系统研究成为可能。

其次是基准测试：我们系统评估了18个主流大语言模型，涵盖了开源家族（如 Qwen [bai2023qwen], GLM [glm2024chatglm], Kimi [team2025kimi]）和来自 OpenAI [achiam2023gpt]、Google [team2023gemini] 及其他领先商业供应商的专有前沿模型。每个模型结合了四种代表性的提示策略（零样本 [brown2020language]、生活史 [deshpande2023toxicity, argyle2023out, morocho2026assessing]、无生活史少样本 [brown2020language] 和生活史增强少样本），产生了72种模型-提示配置。我们发现，在提示中添加丰富的生活史画像显著提高了个体级模拟保真度，使其高于无画像基线；然而，最佳的提示配置在接近50%的准确率时达到平台期，并且每次调用的成本比与之相差仅几个百分点的中等规模替代方案高出大约一个数量级。因此，纯提示提供的准确率-成本权衡是极其不利的，没有任何模型替换或少样本调整能够弥合这一差距。

第三是算法：为了弥合这一差距，我们提出了 curriculum-LoRA，一个参数高效的个性化框架，它通过两个关键组件增强了以人物画像为条件的监督微调 [ouyang2022training, suh2025language, krsteski2025valid]：在线随机采样参考问题，使模型能够利用每位居民偏好中的跨问题一致性；以及一个课程 [bengio2009curriculum, wang2021survey, soviany2022curriculum]，在训练期间逐渐增加参考问题的数量，使模型首先学习基本的画像到答案的映射，然后再利用更丰富的跨问题上下文。建立在7B参数的基础模型上，curriculum-LoRA 匹配了最强提示基线的保真度（51.6% 对比 GLM-5 的 49.7%），同时将每次调用的推理成本降低了一个数量级或更多（所有评估调用成本为0.41元人民币，而在相同提示策略下 GLM-5 为6.54元，GPT-5 为13.84元，GPT-4.1 为38.12元）。在联合准确率-成本平面上，它帕累托占优了我们基准测试中的所有其他配置，并且它进一步泛化到了未见过的居民和未见过的治理领域。

第四是系统：我们将校准后的模型集成到一个端到端的政策态度模拟系统中，该系统支持完整的治理工作流程：政策探测设计、居民态度模拟、结果分析和迭代政策探测优化。这形成了从政策假设到计算机评估再返回的闭环。

总之，这项工作做出了三项贡献。首先，我们构建了迄今为止最大的个体级居民模拟基准，包含约120万字符的生活史叙事（通过对92位居民每人约两小时的半结构化访谈收集），以及他们在九个维度上的结构化治理回复。其次，我们系统绘制了主流大语言模型在该基准上的准确率-成本前沿，表明纯提示提供了极其不利的准确率-成本权衡，排除了实际部署的可能性。第三，我们开发了 curriculum-LoRA，一个参数高效的个性化框架，通过以低一个数量级的单次调用成本匹配其保真度，帕累托占优了所有测试的提示配置，并且我们将其集成到了从业者可以实际使用的闭环政策评估系统中。

结果
基于生活史的个体居民模拟基准
为了能够对个体级居民模拟进行严格评估，我们构建了一个基准，将广泛的生活史叙事与真实居民的结构化治理回复配对 [park2023generative, argyle2023one, wang2025user, wang2025sociobench, santurkar2023whose]。

数据集分四个阶段构建（图1a）： 我们与当地居委会合作，确定居民最关心的治理问题； 我们将这些议题转化为结构化问题工具； 训练有素的社会科学实地工作者对每位居民进行了两小时的访谈，涵盖结构化问题和开放式生活史； 我们对录音进行转录、核实、去标识化和清理，然后将其组织成与每位居民政策态度回复配对的生活史画像。完整的协议细节、同意书和伦理批准见 SI A。

通过这一流程，我们在针对年龄、性别和教育平衡覆盖的分层抽样下招募了92名长期居民。每位参与者完成了大约两小时的单一半结构化访谈，产生了关于该居民生活轨迹和个人价值观的丰富第一人称叙事；完整的转录语料库包含92位居民的大约120万字符（平均每位居民约13,000字符），示例如图1b所示。这种个体刻画的深度远远超过了基于大语言模型的人类模拟中通常使用的简短人口统计标签，在这些模拟中，模型通常以每人仅几十到几百个token的人物描述为条件 [argyle2023one, santurkar2023whose, hwang2023aligning]；我们的生活史画像大约长两个数量级。该队列跨越了整个成年生命历程（图1d），从二十多岁的年轻人到八十多岁的居民，其中最大比例在40-59岁年龄段。样本包括51名女性和41名男性（图1f），并涵盖了披露教育程度的居民的完整教育光谱：小学（n=7），初中（n=33），高中（n=21）和大学或以上（n=29）；两名居民拒绝报告其教育水平（图1e）。数据集在设计上有两个组成部分： 捕捉每位居民身份的生活史画像，以及 捕捉每位居民想法的政策态度记录。生活史画像分为四个部分：(P1) 基本个人信息和成长，(P2) 教育、工作和迁移历史，(P3) 婚姻、家庭和照顾，以及 (P4) 社区互动和个人价值观。政策态度记录是居民对涵盖九个治理领域的结构化50项工具的回复，该工具与居委会共同开发，以反映居民在日常治理互动中最常提出的问题（图1c）：电梯安装与资金（Q1，7项），车辆停放与空间管理（Q2，6项），社区公民参与（Q3，8项），物业管理与服务评估（Q4，8项），邻里关系与纠纷解决（Q5，5项），社区级服务与信息覆盖（Q6，4项），协商与人才孵化（Q7，3项），志愿服务与管理（Q8，4项），以及空间共享与资源利用（Q9，5项）（图1g；完整的50项工具见 SI A.2.2）。项目既探究事实情况（例如，大楼是否有电梯），也探究规范态度（例如，对电梯安装费用分摊的公平性的看法）。

据我们所知，该数据集构成了迄今为止社区治理环境中配对生活史叙事和结构化政策态度回复的最广泛语料库，为一系列社会科学和计算研究提供了基础——从分析个人生活轨迹如何塑造治理态度，到研究政策接受度方面的人口差异，再到作为评估大语言模型与不同社会背景下真实人类价值观对齐的测试平台。

主流大语言模型基准测试揭示了不利的准确率-成本前沿
为了构建用于评估异构大语言模型的高质量数据集，我们从访谈回复在50项政策态度工具中信息丰富、完整且无歧义的参与者中选择了60位长期居民。由于一些居民拒绝回答特定项目或给出的回复无法明确评分，无效单元格被排除，产生了2,291个有效的（居民，问题，答案）三元组。然后，对于每位居民，我们将有效项目划分为留出的评估问题和参考问题；参考问题的黄金答案作为上下文条件暴露给模型，而评估问题保持未见并通过精确匹配评分。

我们评估了18个主流大语言模型，涵盖开源家族（Qwen2.5-32B/72B, Qwen3-32B/235B/Max, GLM-5, Kimi-K2.5）和专有前沿模型（GPT-4.1/4.1-mini/4.1-nano/4o-mini, GPT-5/5-mini/5-nano, GPT-5.4-mini/5.4-nano, Gemini-2.5-Flash, Grok-4-Fast）——每个模型结合四种提示策略：无提示，仅生活史，仅少样本，以及生活史与少样本示例。在每种策略中，我们进一步扫描了上下文内少样本示例的数量（{0, 2, 4, 6, 8, 10}）。每位居民的生活史被组织成四个区块：基本个人信息和成长（P1），教育、工作和迁移历史（P2），婚姻、家庭和照顾（P3），以及社区互动和个人价值观（P4）。我们穷举评估了这些区块的所有 2^4 = 16 个子集；按模型、策略和少样本数量划分的完整准确率报告在图 S1 中。

我们沿五个轴线呈现以下发现：生活史条件的价值（图2a–d, f, i），生活史起作用的内部机制（图2g, j），上下文内少样本示例的收益递减（图2e, h），模型能力的有限作用，以及跨配置出现的准确率-成本权衡（图2a–d）。

生活史显著提高了个体级保真度。
在没有少样本示例的情况下，以生活史为条件在18个大语言模型中平均提高了5.6个百分点的准确率（图2a 对比 b），其中 GPT-5-nano（29.2% → 43.1%，+13.9 pp）和 Qwen2.5-32B（24.0% → 37.4%，+13.4 pp）的增益最大。在带有少样本示例的情况下，添加生活史仍然平均产生3.1个百分点的增益（图2c 对比 d），其中 Qwen3-32B（41.1% → 49.4%，+8.3 pp）和 GPT-4.1（41.4% → 49.1%，+7.7 pp）的增益最大。因此，无论有无少样本示例，生活史都有所帮助。为了更好地理解不同生活史组件的作用，我们检查了区块级消融：图2f, i 显示了两个代表性模型，SI G 中的图 S2 报告了所有18个大语言模型的完整细分。出现了三种模式。首先，包含所有四个区块始终是一个安全的选择：大多数模型在完整配置下达到最高准确率，我们从未观察到严格占优它的子集。其次，额外区块的边际收益因模型而异：一些在单个区块后饱和（例如，GPT-5.4-mini），而另一些则随着更多区块的添加而单调增加（例如，Qwen2.5-32B, GPT-5-nano）。第三，在任何固定的区块数量下，包含哪些区块很重要：具有相同区块数量的两个配置之间的差异可能超过具有不同区块数量的两个配置，甚至少数单区块配置的表现不如无提示基线。

逐层探测揭示了生活史在模型内部编码的位置。
上面的基准测试结果证明了生活史条件改善了保真度，但没有证明模型如何在内部处理传记信息。为了阐明内部机制，我们在 Qwen2.5-struct 上进行了逐层探测分析，这是一个可以访问其中间表示的开源权重模型。我们从模型64个 Transformer 层的每一层提取隐藏状态，并训练了一个线性分类器（逻辑回归），在四种输入条件下仅从该层的表示预测每位居民的政策态度答案：无上下文（C_None），具有来自其他居民的打乱文本的长度匹配控制提示（C_Ctrl），完整生活史（C_LH），以及生活史加少样本参考轨迹（C_LH+F）。出现了三个发现（图2g）。首先，所有条件在早期层（0-10层）都接近机会水平（21.1%），证实了表面token统计几乎没有携带态度信号。其次，C_LH 和 C_LH+F 条件从大约第13层（起始层）开始与 C_None 和 C_Ctrl 分离，差距在第46层达到峰值（7.0 pp）——这是一个态度推断窗口，模型在其中将传记叙事转换为与偏好相关的特征；相比之下，匹配了提示长度但缺乏有意义的个人内容的 C_Ctrl，在整个深度上几乎没有显示出相对于 C_None 的增益。第三，生活史信号（C_LH - C_Ctrl；图2j）首先在第13层超过5%的阈值并在第46层达到峰值，表明模型的中后期层是将传记叙事主动编译为态度表示的地方。这些结果提供了生活史为何有帮助的机制解释：它为模型提供了逐步被提炼为态度表示的叙事材料，而长度匹配的控制文本无法触发这种转换。

上下文内少样本示例带来收益递减。
添加来自同一居民的参考问答对稳步提高了准确率（图2e, h 显示了两个代表性模型；所有18个大语言模型的完整少样本扫描见 SI G 的图 S1）。0 → 2 样本的跃升是最大的，随后的每一步增加的增量更小；8 → 10 样本的增益在18个大语言模型中平均约为1个百分点。因此，额外少样本的边际收益始终小于生活史条件的边际收益。

更大的模型和侧重推理的模型并没有更好地模拟居民。
首先，更大的尺寸并没有产生更高的准确率：在生活史与少样本示例下，中等规模的开源模型（GLM-5 49.7%, Qwen2.5-72B 49.5%, Qwen3-32B 49.4%）匹配或击败了更大的专有系统（GPT-5 47.7%, GPT-4.1 49.1%）。其次，侧重推理的模型（GPT-5.4-mini, GPT-5.4-nano）在无提示下排名接近底部（均为27.5%），远低于较小的通用模型如 GPT-4o-mini（37.2%）。居民模拟依赖于理解个人价值观和态度，而不是逻辑推理。因此，瓶颈不是模型规模或推理能力，而是缺乏个体级信息——这正是生活史所提供的。

最佳提示配置伴随着高得多的成本。
在每个模型家族内，从无提示切换到生活史与少样本示例将每次调用成本提高了3-4倍，而准确率最多提高10-15个百分点。跨模型层级差距甚至更大：前沿专有模型的成本比与之相差仅几个百分点的中等规模开源模型高出一个数量级。GPT-4.1 的所有评估调用成本为38.12元，GPT-5 为13.84元，而 GLM-5 仅需6.54元，Qwen2.5-72B 仅需1.50元。因此，在纯提示下，左上角的“低成本、高准确率”区域是空的（图2a–d；每种模型的 API 定价见 SI F）。

这种成本差距对于实际使用很重要。一轮政策评估很容易需要数以万计的模拟回复（例如，针对大约100名居民的50问题调查，跨越几个政策选项），而迭代优化将这种需求成倍增加。对于前沿提示，单轮可能花费数千元人民币，远超大多数地方组织的预算。因此，实践中重要的不是原始准确率，而是每元人民币的准确率：以十分之一的成本匹配提示上限，正是将学术演示转化为可部署工具的关键。我们接下来解决这一准确率-成本差距。

a，curriculum-LoRA 可以利用的两种能力来源——少样本参考问答轨迹（F）和生活史（L）的隐式（训练阶段，y轴）与显式（测试阶段，x轴）使用对比。每个单元格报告一种（训练，测试）组合下的留出准确率，其中四个标签表示 None（无输入），F（仅少样本），L（仅生活史）和 FL（两者）。

curriculum-LoRA 改变了准确率-成本前沿
为了改善基于大语言模型的居民模拟的准确率-成本权衡，我们提出了 curriculum-LoRA，一个参数高效的个性化框架，通过在标准基于 LoRA 的监督微调基础上增加两个轻量级组件来微调7B参数的基础模型（Qwen2.5-7B-Instruct）。
首先，在每个训练步骤中，我们随机采样一部分参考问题——已知同一居民答案的其他治理问题——并将它们与居民的生活史画像一起前置到目标问题之前，以便模型能够利用每位居民偏好中的跨问题一致性。
其次，我们应用了一个课程，在训练过程中将参考问题的数量从 k_min=1 逐渐增加到 k_max=9，以便模型首先掌握基本的生活史到答案映射，然后再学习利用更丰富的跨问题上下文。完整的描述，包括损失、调度函数和超参数搜索，在方法中给出（超参数分析见图3c–e；算法伪代码见 SI D）。

在准确率和成本上帕累托占优提示前沿。
仅就准确率而言，curriculum-LoRA 在留出测试集上达到了51.6%的精确匹配准确率（3个种子平均），比最强的提示基线（GLM-5, 49.7%）绝对优势1.9个百分点（相对3.7%）；我们将此视为一种真实但适度的增益，而不是绝对的准确率优势。决定性的贡献在于成本轴：curriculum-LoRA 以0.41元人民币的所有评估调用成本提供了这种保真度——大约比 GLM-5（6.54元）便宜16倍，比 Kimi-K2.5（7.66元）便宜19倍，比 GPT-5（13.84元）便宜34倍，比相同的生活史与少样本示例协议下的 GPT-4.1（38.12元）便宜93倍。在联合准确率-成本平面上（图2a–d），curriculum-LoRA（金星）独占左上方的“我们的区域”：我们测试的任何提示配置都没有同时更准确和更便宜。对于激发这项工作的部署场景而言，以低一个数量级的成本提供保真度等效的解决方案，是学术演示与地方组织实际可运行工具之间的区别。

生活史和少样本参考轨迹协同作用，在训练和测试中相互加强。
图3a 中的 4×4 矩阵映射了来自 {None, F, L, FL} 的训练时间和测试时间输入的所有16种组合的测试准确率，其中 F 表示少样本参考问答轨迹，L 表示生活史，FL 表示两者，None 表示都没有。
训练/测试输入不匹配可能直接产生反效果。矩阵中最低的单元格是 (训练: F, 测试: L) = 46.53%，其中模型经过微调期望在测试时有参考轨迹，但随后仅被给予生活史；微调在这里是有害的，将准确率降低了3.5个百分点，低于基础模型在相同测试条件下的 (训练: None, 测试: L) = 50.07%。无论模型在训练时依赖什么信号，在测试时也必须存在，否则微调不仅无益反而有害。
单元格 (训练: FL, 测试: FL) = 51.59% 严格占优矩阵中的每个其他单元格。所有15种替代配置都低于联合峰值，准确率从 (训练: FL, 测试: F) 的51.39%（低0.20个百分点的最近邻）到 (训练: F, 测试: L) 的46.53%（低5.06个百分点的最差值）不等。只有当两个信号在两个阶段共同存在时才达到峰值：即使测试提示携带完整的 FL 对，单信号训练也不够（例如，(训练: F, 测试: FL) = 51.20%，(训练: L, 测试: FL) = 50.11%），即使训练包含两者，单信号测试也不够。因此，这两个信号是互补的而不是可替代的，它们在训练和测试中相互加强，而不是仅在一个阶段起作用。

课程调度和超参数敏感性。
我们比较了课程函数 g(t/T) 的三个调度家族：线性、平方根和在一个训练分数 ρ 处达到最大值的分段“斜坡”（图3b）。线性调度达到了最高的留出准确率（51.59%），以0.52个百分点击败了平方根（51.07%），以0.65–1.13个百分点击败了每个斜坡变体（50.46–50.94%）。在斜坡变体中，较晚的斜坡终止（ρ=0.7，50.94%）略好于较早的（ρ=0.3 为50.89%；ρ=0.5 为50.46%），但所有斜坡变体都低于更平滑的调度。因此，在整个训练轨迹中逐渐拓宽上下文优于在训练早期突然跳到最大上下文大小。
curriculum-LoRA 的准确率对学习率最敏感，对 LoRA 秩适度敏感，对 dropout 几乎不敏感（图3c–e）。最佳学习率是 10^{-4}；对于较小的学习率（从 10^{-5} 到 10^{-4}，≥50%），准确率是稳定的，但在 5×10^{-4} 及以上时急剧下降到44-47%。最佳 LoRA 秩为8；秩4具有竞争力（51.2%），而秩16和32的表现差2-3个百分点。Dropout 几乎无关紧要：从0到0.3的值中，准确率变化不到0.2个百分点。

泛化到未见过的居民和未见过的领域。
可部署的模拟器必须能够转移到训练期间未见过的居民和治理主题上，因为一个城市的居民和政策问题远多于我们能够访谈的。我们在两个实验中测试了这一点。每个实验都改变训练池的大小，并在留出的剩余部分上评估准确率；第一个改变居民，第二个改变领域。

跨居民。
我们在 {10, 20, 30, 40, 50} 个居民的子集上训练 curriculum-LoRA，并在留出的剩余部分上进行评估（图4a）。在五种训练集大小上平均，curriculum-LoRA 比最强基线高约2.6个百分点。差距在 train=10 时最小（-2.2 pp；curriculum-LoRA 以48.9%匹配 GLM-5，低于 Qwen3-32B 的51.2%），在 train=40 时最大（+5.8 pp）。从 train=20 开始，它超越了每个基线（train=20 时为54.6%，而 GLM-5 为50.0%，Qwen3-32B 为52.0%），在30位居民时达到峰值（56.2%），并在50位居民时稳定在54%以上。
观察随着训练集从10增长到50名居民时准确率的变化，使得差异更加清晰：curriculum-LoRA 增益了7.0个百分点，而每个提示基线几乎没有移动（GLM-5 +1.8 pp，Qwen3-32B +0.7 pp，Qwen2.5-72B -0.5 pp）。这种对比暴露了微调相对于提示的结构优势：每个测试实例仅从目标居民自己的生活史和参考答案中评分，因此提示基线没有机制来消耗训练池中的其他居民——改变训练池大小只会重绘留出测试集，跨池看到的小波动是测试集噪声而不是学习。相比之下，LoRA 适配器在微调期间将每个训练居民内化到其参数中，因此每次深度访谈都直接增加了模型知识，无论基础模型容量如何。互补的见解在于数据方面——在30名居民（队列的三分之一）处的早期平台期意味着生活史到态度的映射在人口水平上很大程度上是共享的，因此中等规模的队列已经覆盖了潜在的倾向结构。在实践中，这是可操作的缩放机制：每个地点收集数百次深度访谈是不必要的，而仅收集少数几次是不够的（所有18个基线见图 S3）。

跨领域。
然后，我们随机抽取了九个治理领域中的 {1, 2, …, 8} 个子集进行训练，并在留出的剩余部分上进行评估（图4b）；随机抽取协议防止任何单个“容易”或“困难”的领域在小子集大小时主导结果。在八个训练领域计数上平均，curriculum-LoRA 在每个计数上比最强基线高约2.5个百分点，每个计数的增益高达4.3个百分点；它在计数1到7上优于每个基线（GLM-5, Qwen2.5-72B, Qwen3-32B），仅在8个训练领域时 Qwen2.5-72B 略微胜过 curriculum-LoRA（64.1% 对比 62.8%）。少领域机制是与部署更相关的：在实践中，社区更有可能在一两个治理主题上收集了访谈答案，而不是所有九个，因此从一小组训练主题泛化到许多未见主题正是决定模拟器在实践中是否可用的机制。例如，仅在九个治理领域中的一个上训练，curriculum-LoRA 在八个未见领域上达到了49.5%，比最强基线高4.3个百分点。简而言之，适配器学习了一种从生活史加少量先前答案到新态度的可泛化映射，而不是每个领域的模式；然后课程使得这种技能对部署提供的任何参考集大小都具有鲁棒性（所有18个基线见图 S4）。

用于政策模拟和优化的闭环系统
为了将校准后的模型转化为社区治理的可用工具，我们构建并公开部署了 Onelink-Community，一个端到端的政策态度模拟系统（图5；上线于 http://39.107.76.51:9882/）。该系统在单个闭环中涵盖了完整的治理评估工作流程。它是模型无关的：任何大语言模型都可以作为推理骨干，从通用前沿模型到我们的 curriculum-LoRA 校准模型。因此，从业者可以选择适合其用例的保真度-成本操作点。我们方法论的每个阶段都作为一个交互模块暴露，从生活史画像到 curriculum-LoRA 推理再到多视角分析，因此领域从业者可以端到端地操作系统，而无需机器学习专业知识。

图5：用于政策模拟和优化的闭环端到端平台。
部署的 Onelink-Community 系统将硅基社会流程操作化为五个相互连接的阶段： 居民初始化，导入或创作基于生活史的画像； 来自用户或报告的问题初始化，支持三种可互换的创作模式——手动、结构化模板上传和从既定研究目标出发的 AI 生成草稿； 模拟执行，其中 curriculum-LoRA 居民代理大规模响应，进度通过社区仪表板实时流式传输； 多视角结果分析，呈现汇总回复统计以及每个问题和每个队列的细分； 自动合成的模拟报告，诊断提议政策的接受度、摩擦和公平性问题。虚线的政策优化箭头闭合了循环：发现作为修订后的政策重新进入，用于迭代预部署优化。

操作流程。
系统由五个顺序阶段构成，通过单个反馈循环串联，因此操作员可以从空白的政策想法转到可比的、基于证据的修订，而无需离开平台。
阶段1 – 居民初始化。操作员通过导入现有居民画像或通过“添加个人信息”表单（姓名、性别、教育、年龄、自由形式传记）输入新画像来填充虚拟社区；每个画像成为在所有后续模拟中重复使用的持久居民。
阶段2 – 问题初始化。政策探测以三种共享通用模式的可互换模式创作：手动编写调查标题、问题和选项；通过 Excel 工作簿进行结构化模板上传，以实现跨研究的可比性；以及 AI 生成草稿，其中操作员仅提供研究目标、目标样本量和可选提示，骨干大语言模型生成领域适当的问卷，操作员可进一步编辑。同一界面还接受先前的模拟报告作为输入，这是优化循环的入口。
阶段3 – 模拟执行。一旦创建了调查，仪表板会将其分发给所有居民并依次运行每个居民代理；每个调查带有三个生命周期控制——待处理、进行中、已完成——操作员通过它们启动、监控和关闭运行，同时实时事件日志流式传输每个受访者的状态。
阶段4 – 结果分析。已完成的模拟在交互式分析视图中总结，报告整体回复量和每个问题的答案分布，使操作员可以一目了然地看到模拟社区在哪里集中、分裂或犹豫。
阶段5 – 模拟报告和政策优化。对于每次完成的运行，系统合成一份结构化的政策报告，诊断接受度、预期摩擦、公平性问题和具体的修订建议，每个主张都基于底层的回复分布；图5中的虚线反馈箭头闭合了循环，因为报告本身成为阶段2的一等输入，使得在任何实际推出之前能够进行迭代的预部署优化。
综上所述，这五个阶段形成了一个端到端的、公开部署的流程，将基于画像的大语言模型居民、可扩展的模拟编排、多视角分析和报告驱动的政策迭代耦合在一个单一的 Web 应用程序中。这个循环的完整性正是使得前面部分的实证结果能够作为治理工作流程而不是离线基准被操作化：从业者可以在基于真实人类画像的硅基社区上探测、比较和优化政策，然后再在物理社区中采取行动。

讨论
这项工作为社区治理中基于大语言模型的居民模拟建立了一个综合研究基础，涵盖了基于生活史的基准、18个主流大语言模型的系统准确率-成本图谱、curriculum-LoRA 个性化框架和闭环政策评估系统。出现了三个启示。

有利的准确率-成本权衡使得个体级居民模拟变得可部署。
在跨越18个大语言模型的72种模型-提示配置中，准确率在50%附近达到平台期，并且在8个少样本以上时对模型规模、画像粒度或上下文内少样本数量在很大程度上不敏感。curriculum-LoRA 以大约低一个数量级的单次调用成本匹配了最强提示基线的保真度（51.6% 对比 GLM-5 的 49.7%）（比 GLM-5 便宜约16倍，比 GPT-5 便宜34倍，比 GPT-4.1 便宜93倍）。实际意义不在于任何一个大语言模型正在“获胜”——绝对准确率差异是适度的——而在于基于大语言模型的人类模拟现在可以在迭代政策优化实际所需的规模上运行：每轮数以万计的合成回复，跨越许多政策变体和许多迭代，在地方行政部门可以负担的预算内。对该领域更广泛的启示是，该领域的进展最有效的是在联合准确率-成本前沿上衡量，而不是仅仅在原始准确率上。

生活史和少样本参考轨迹是协同的，不可替代的，并且在训练和推理时都很重要。
curriculum-LoRA 利用的两种信息源——生活史和少样本参考问答轨迹——在微调期间一起提供时贡献最大。在没有任何上下文的情况下训练会使模型无法在测试时充分利用任一信号；仅在生活史上训练几乎不超过此基线；仅在参考轨迹上训练仍然错过了0.30个百分点的全局最大值。峰值（(训练: FL, 测试: FL) 时的51.59%）仅在模型在微调期间暴露于两种信号并且参考轨迹在测试提示时也被激活时才能达到。因此，参考轨迹不仅仅是推理时间的激活器：它们在训练时间的包含是教会模型将跨问题一致性与传记上下文整合起来的原因，而生活史只有在与这种训练时间的暴露配对时才增加协同提升。我们的逐层探测分析提供了这种协同作用的机制解释：生活史叙事在局部化的中后期层窗口内（在 Qwen2.5-32B-Instruct 中起始在第13层，峰值差距在第46层）逐步被提炼为态度表示，这种转换是长度匹配的控制文本无法触发的，解释了为什么丰富的传记上下文对于个体级模拟是不可或缺的。对于基于大语言模型的人类模拟的一般设计教训是，将个体证据（传记）和任务特定信号（参考轨迹）视为应在微调期间联合吸收的互补输入，而不是仅在进入模型阶段不同的可替代输入。

忠实地模拟主观的、充满价值的偏好仍然是开放的方法论前沿。
即使有丰富的生活史条件和基于课程的个性化，准确率也在50%附近达到平台期，表明当前大语言模型从传记上下文推断主观偏好的能力存在根本限制。这正是对社区级政策最重要的机制：关于停车分配或电梯安装费用分摊的治理决策取决于居民的主观偏好，而不是他们报告的情况。在我们看来，弥合这一差距是该领域最重要的单一方法论前沿，并且可能需要超越我们这里使用的下一个token预测的建模进步。

一些局限性限制了目前的工作并定义了其近期议程。

从单一实证案例研究到多地区实例化。
这项工作的贡献是双重的：方法论上的——基准协议、提示基线评估框架和 curriculum-LoRA 个性化方法——和实证上的——在一个城市社区中单一、严格构建的实例化。方法论贡献有意与地区无关：相同的基准设计、提示策略和训练程序可以应用于任何可以与结构化政策态度探测配对进行可比生活史访谈的地方。相比之下，实证实例化必然是局部的；社区治理实践、文化规范和居民期望因地区而异，我们不声称我们报告的具体准确率上限在数值上可以转移到其他环境。然而，我们期望定性模式能够泛化：仅提示就达到了远低于政策使用要求的上限，这个上限只有在大幅成本溢价下才能接近，而针对性的参数高效个性化改变了准确率-成本前沿。在其他治理环境中复制该方法论是直接的下一步，这将测试这些定性主张并拓宽该领域的实证基础。

从静态快照到活的模拟。
我们的数据集在单一时间点捕捉居民，然而态度随着生活事件、政策变化和社会变迁而演变。更深远的雄心是建立随着社区变化而更新的活的模拟——通过定期重新访谈、与公共数据流整合，或能够持续丰富居民画像的大语言模型辅助对话代理。这样的系统将从回顾性分析走向真正的预见性治理。

从模拟到人机协作治理。
我们目前的系统模拟居民对预先设计的政策探测的态度，但长期的潜力在于一种更具交互性的范式，其中模拟居民首先提出候选关注点，真实居民然后通过有针对性的参与验证和细化这些发现，系统从这一反馈循环中迭代学习。这种人机协作模型可以重塑治理决策的制定方式——不是取代公民参与，而是使其更加集中、高效和知情。模拟器充当一个镜头，帮助决策者向真实社区提出更好的问题，而不是代替他们回答。

更广阔的愿景。
这里提出的框架——实证画像、系统基准测试和在联合准确率-成本前沿上的个性化校准——自然地扩展到社区治理之外。任何需要大规模理解不同人类反应的领域，包括公共卫生、教育和城市规划，都可以采用相同的范式。更广泛地说，我们的结果表明，随着大语言模型在模拟个体人类方面变得越来越有能力，社会科学将在指导这些能力如何负责任地开发、验证和部署方面发挥越来越核心的作用——而且考虑成本意识的模型部署框架，而不仅仅是原始能力，将决定这些能力中哪些真正能够到达它们旨在服务的社区。

方法
数据集构建
招募和伦理监督。我们与作为实证案例研究的代表性城市社区的居委会合作，通过分层抽样招募长期居民，目标是年龄十年段、性别、教育水平和民族的平衡覆盖。所有参与者在访谈前提供了书面知情同意书；参与是自愿的并给予适度补偿。研究方案获得了牵头机构的机构伦理委员会批准。

访谈协议。每位居民参加了大约两小时的单一半结构化访谈，由训练有素的社会科学实地工作者在居委会办公室的私密环境中以普通话进行。访谈指南有两个互补部分。第一部分引出围绕四个提示组织的开放式生活史叙事：(P1) 基本个人信息和成长，(P2) 教育、工作和迁移历史，(P3) 婚姻、家庭和照顾，以及 (P4) 社区互动和个人价值观。第二部分实施了涵盖与居委会共同开发的九个治理领域的结构化50项工具：电梯安装与资金（Q1，7项），车辆停放与空间管理（Q2，6项），社区公民参与（Q3，8项），物业管理与服务评估（Q4，8项），邻里关系与纠纷解决（Q5，5项），社区级服务与信息覆盖（Q6，4项），协商与人才孵化（Q7，3项），志愿服务与管理（Q8，4项），以及空间共享与资源利用（Q9，5项）。

转录和质量控制。所有访谈都进行了录音并逐字转录。转录稿由第二名注释员审查并对照录音进行纠正。个人身份识别信息（个人姓名、楼宇地址、工作单位）在模型使用前被移除。最终语料库包含92名居民和约120万字符的生活史叙事（两份匿名完整样本转录见 SI B）。

问答对。对于每个（居民，问题）单元格，我们提取了居民的选定选项和适用的态度标签（积极、中立、消极）。居民拒绝回答或问题不适用的单元格被标记为无效并排除，留下了2,291个有效的单选（居民，问题，答案）三元组用于训练和评估。

提示基线的基准测试协议
我们对跨越开源和专有前沿系统的18个主流大语言模型进行了基准测试：Qwen (Qwen2.5-32B/72B, Qwen3-32B/235B/Max), GLM (GLM-5), Kimi (Kimi-K2.5), OpenAI (GPT-4.1, GPT-4.1-mini, GPT-4.1-nano, GPT-4o-mini, GPT-5, GPT-5-mini, GPT-5-nano, GPT-5.4-mini, GPT-5.4-nano), Google (Gemini-2.5-Flash) 和 xAI (Grok-4-Fast)。每个模型通过其官方 API 查询，温度设置为0以确保确定性解码，除了 Kimi-K2.5，其 API 仅允许温度0.6。

对于每个模型，我们评估了四种提示策略，以隔离生活史和先前问答上下文的贡献：零样本（仅问题）、生活史（带有生活史画像）、少样本（仅带有参考问答对）以及生活史与少样本（两者）。将18个模型与4种策略结合产生了72种提示配置。在每种策略中，我们进一步扫描了 三个领先模型的上下文内示例数量 {0, 2, 4, 6, 8, 10}，以及 两个代表性模型的提示中包含的生活史部分的所有16种 {P1, P2, P3, P4} 组合的子集。所有准确率均报告为40个问题留出测试集上的精确匹配准确率，在居民上均匀平均。

成本核算。对于每次 API 调用，我们记录了提示和完成 token 数量，并使用每个提供商在实验日期发布的每 token 定价将产生的成本转换为人民币；正文中报告的所有成本数据均标准化为所有评估调用的人民币。由于 curriculum-LoRA 在本地硬件上运行而不是通过 API，我们将其计算消耗转换为可比的货币成本 C = (T_min / 60) × P_hour，其中 T_min 是完整测试集的累计挂钟推理时间（以分钟计），P_hour = 4.98元人民币/GPU小时是公有云参考费率（AutoDL, https://www.autodl.com/home）；所有 curriculum-LoRA 运行使用 NVIDIA A800 GPU。这种标准化使得所有回复成本可直接与 API 定价的基线比较（每种模型定价快照及平均提示/完成 token 数见 SI F；成本计算示例见 SI E）。

curriculum-LoRA
任务制定。我们将居民模拟构建为以人物画像为条件的政策态度预测。设 p_u 表示居民 u 的文本生活史画像，设 q_i = (x_i, O_i) 表示第 i 个政策态度问题，其中 x_i 是问题文本，O_i = {o_{i,0}, ..., o_{i,C_i-1}} 是离散答案选项集。对于每个（居民，问题）对，目标是预测居民的答案 y_{u,i} ∈ {0, ..., C_i-1}。50个单选题在问题级别均匀地跨居民划分为10个问题的参考集 Q_ref 和40个问题的留出评估集 Q_eval。

参考条件提示。curriculum-LoRA 不仅以 p_u 和 q_i 为条件，还以参考问题的子集 S_{u,i} ⊆ Q_ref 以及居民对这些参考问题的已知答案为条件，暴露了居民偏好中的跨问题一致性。在训练期间，如果目标问题本身在参考集中，我们通过从 Q_ref \ {q_i} 中采样 S_{u,i} 来将其从条件块中排除。聊天式提示 m_{u,i} = T(p_u, q_i, {(q_j, y_{u,j})}{j∈S{u,i}}) 包含要求模型返回选项索引的系统指令，随后依次是生活史画像、参考问答块和目标问题。采样限制为居民 u 有有效记录答案的问题。完整的聊天模板和计算示例见 SI C。

上下文大小的课程。在总共 T 个更新步骤的训练步骤 t，我们每个训练示例采样 k_t 个参考问题，其中 k_t = k_min + ⌊(k_max - k_min) g(t/T)⌋。我们实现了三个调度函数家族：g(r) = r（线性），√r（平方根），和 min(1, r/ρ)（终止分数 ρ ∈ (0, 1] 的斜坡）。我们始终使用 k_min = 1 和 k_max = 9。参考子集的在线随机采样使模型暴露于 epoch 内和跨 epoch 的多样上下文组合（减少了对任何固定提示模板的过拟合），而课程逐渐拓宽上下文，使模型首先掌握基本的生活史到答案映射，然后再利用更丰富的跨问题结构。

训练目标。微调仅在来自10个问题参考分割的观察到的三元组上执行，D_train = {(u, i, y_{u,i}) : q_i ∈ Q_ref, y_{u,i} 被观察到}。对于每个训练目标 q_i ∈ Q_ref，参考子集 S_{u,i} 从 Q_ref \ {q_i} 中采样，因此目标答案本身从不包含在提示中。40个问题的留出分割 Q_eval 被排除在参数更新之外，仅用于评估。模型使用仅掩码到助手回复 token 的因果语言建模损失进行微调：L = -∑{(u,i,y{u,i})∈D_train} log p_θ(y_{u,i}, eos | m_{u,i})，其中 θ 是添加到冻结基础模型的 LoRA 适配器参数。LoRA 适配器应用于注意力和前馈投影层；秩/dropout 敏感性如图3d–e所示。

推理。对于每个评估目标 q_i ∈ Q_eval，我们设置 S_{u,i} = Q_ref，使用所有10个参考问题作为条件上下文。然后我们通过约束分类进行预测：单次前向传递对最后位置的 logits 进行评分，我们返回 ŷ{u,i} = arg max{v∈{0,...,C_i-1}} p_θ(v | m_{u,i})。这避免了不必要的自回归生成，并为离散选项的政策态度项目产生了确定性、高效的预测。

训练和超参数选择
我们使用 Qwen2.5-7B-Instruct 作为基础模型，并在学习率 {1×10^{-5}, 2×10^{-5}, 5×10^{-5}, 1×10^{-4}, 5×10^{-4}, 1×10^{-3}}，梯度累积步数 {4, 8}，LoRA 秩 {4, 8, 16, 32}，LoRA dropout {0, 0.05, 0.1, 0.2, 0.3}，和课程调度器 {linear, sqrt, ramp} 上进行网格搜索，总计720种配置 × 3个随机种子 = 2,160次训练运行。最佳配置通过种子平均的留出测试准确率选择。其他设置固定：3个 epoch，训练批量大小1，评估批量大小10，最大输入长度2048，预热比例0.1，带有余弦学习率衰减和梯度裁剪的 AdamW，bfloat16 混合精度，NVIDIA A800 GPU。超参数分析如图3c–e所示；算法伪代码见 SI D。
