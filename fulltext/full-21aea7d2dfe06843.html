摘要

视觉语言模型（VLM）在机器人学习的零样本视频任务进度估计方面前景广阔，但现有框架常受确认偏差困扰：由于隐式成功假设或相对时间排序设计，模型会在失败的执行中幻觉出进度。对前沿模型的朴素提示会退化为二元成功检测器，无法捕捉细致的非线性进度与失败。虽然后训练方法可通过显式训练缓解此问题，但它们需要昂贵的真实机器人数据，且必须为每个基础模型单独进行计算密集的后训练。

为解决这些局限，我们提出 D&A（Describe & Assess，描述与评估）：该方法将进度估计解耦为两个阶段——先对场景动态生成客观的、基于任务的文本描述，再使用显式评分标准进行评估。通过强制 VLM 在打分前先综合出明确的、基于文本的绝对成功定义，该框架将评估锚定于外部的全局标准，而非视频的内部时间线。实证结果表明，本方法校准了零样本估计并缓解了确认偏差，提供细粒度的部分进度指标，能准确惩罚失败的执行，同时正确插值成功的运行。D&A 纯粹基于提示，可跨任务、本体形态与基准泛化——达到或超越后训练奖励模型——其奖励估计可支持高效的下游强化学习。

I 引言

第一印象出了名地难以克服 [1]。在评估复杂情况时，人类常表现出确认偏差 [2]，寻找并解释与其初始假设一致的证据，从而在判断中引入系统性错误。类似的偏差也出现在语言模型中：这些模型被训练得在人类评估者面前显得有能力，会扭曲答案以迎合用户，或走“捷径”假装解决给定任务 [3,4,5,6,7,8]。至关重要的是，心理学文献表明，此类偏差可通过结构化程序缓解——即要求在任何任务评估之前先对可用数据进行全面描述 [9,10]。

我们基于这一直觉，为下游应用（如真实世界强化学习与失败解释）设计更好的机器人奖励模型。当朴素地查询视觉语言模型（VLM）进行零样本视频奖励估计时，我们观察到同样的确认偏差捷径：即使几乎没有实质性进展，模型也频繁幻觉出进度（见图 1）。当前的零样本机器人奖励模型同样受此问题困扰——GVL [11] 和 TOPReward [12] 等框架通过排序打乱的视频帧或跟踪 token logits 来估计进度——我们的实验表明，这些方法偏向任务成功。对于下游强化或模仿学习算法，这些错误的评估会成为高度误导的奖励信号，严重阻碍策略学习。

为绕过零样本基础模型的局限，近期方法在任务特定的机器人数据集上后训练模型 [13,14,15,16]。然而，带有失败标注的多样化真实机器人数据难以获取 [17]，限制了所得模型的泛化能力。后训练还仅限于较小、能力较弱的开源模型，且必须针对每个基础 VLM 重复进行，为真正通用的机器人奖励模型设置了成本、算力与能力壁垒。

图 1：朴素 VLM 奖励估计中的确认偏差： 零样本查询导致模型即使在失败任务上也幻觉出进度，导致高预测方差，且成功与失败轨迹的奖励估计没有明显差异。

相反，我们提出 D&A（Describe & Assess），一种零样本奖励模型，既避免了先前零样本方法的偏差问题，又实现了比后训练奖励模型更好的视觉与语义泛化。零样本是其有效性的核心：无需任何机器人特定训练，同一套基于提示的方案可直接套用于任何可提示的 VLM，并随底层模型进步而免费提升。

D&A 将评估解耦为描述与评估两个不同阶段。它首先强制 VLM 生成关于机器人实际行为的显式文本描述，为进度度量奠定客观基础；随后通过语义上推理“任务成功意味着什么”，并将奖励估计锚定于成功标准来评估进度。在轨迹描述与该成功推理的条件下，VLM 对关键帧预测 [0,1] 区间的进度，作为策略学习的密集奖励。

我们进一步表明，该范式可轻松扩展以生成丰富的自然语言反馈，超越二元奖励信号，为策略改进提供有针对性的纠正上下文。

总之，D&A 是一种将视频描述与进度评估解耦的奖励模型范式，利用预训练 VLM 实现零样本机器人奖励建模。由于纯粹基于提示，D&A 与模型无关，无需机器人数据或微调；它可跨任务、本体形态与语言泛化，在奖励基准上达到或超过后训练模型。我们的扩展实验表明，D&A 随 VLM 能力提升而改进，覆盖四个模型家族、28 个开源与闭源模型。在使用 DROID Franka 和两个双臂 YAM 机械臂任务的真实世界在线与离线强化学习中，D&A 相比零样本与后训练奖励模型分别将成功率提高 +95%、+15% 和 +45%。最后，将 D&A 扩展至 GPT-6 Astra，在 D&A-Bench、RBM-EVAL-OOD 和 RoboRewardBenchmark 上取得 SOTA 性能，超越全部七个预训练与零样本基线。

II 相关工作

基础模型作为奖励模型。 LLM 与 VLM 已被广泛用于指定奖励，例如从自然语言生成可执行的奖励代码或塑形项 [18,19,20,21]，但此类方法通常假设可访问真实部署中不可得的特权低维状态。更可部署的替代方案是直接从像素使用预训练 VLM 作为零样本进度或成功估计器 [22,23,24,11,12,25]。D&A 属于这一零样本家族，但先前方法直接提取标量信号——例如 GVL [11] 排序打乱的帧，或 TOPReward [12] 读取 "True" token 的 logit——而我们让奖励估计经过显式的描述与评估阶段，我们发现这对对抗直接提示的成功偏差至关重要。

后训练奖励模型。 为提高可靠性，越来越多的工作在机器人数据上以进度预测目标 [13,15,16,14,26,27,28] 或语言推理 [29,30] 微调 VLM 与 VLA。RoboReward [15] 预测通过反事实指令重标注获得的离散进度标签；Robometer [16] 从大型精选数据集联合预测进度、成功与轨迹偏好。这些模型承担了收集多样化高质量机器人数据的成本 [17]，仅限开源骨干网络，且随着更强基础模型出现必须重新训练。D&A 则保持完全零样本，与模型无关并随前沿 VLM 进步而提升，同时在分布外基准上达到或超过后训练模型。

我们首先用一个定性例子说明：直接提示零样本 VLM [31] 进行逐帧进度估计——以机器人视频及其任务指令为条件——无法产生准确奖励。给定配有正确指令的专家演示，VLM 通常能给出合理的逐帧 [0,1] 奖励并以 1.0 结束。然而，当机器人错误或次优地执行任务时，模型常通过假设成功来“走捷径”——而这恰恰是奖励模型为纠正已部署策略所必须检测的情形。例如，图 2 中我们以“为这段机器人‘展开衬衫’的视频提供每步奖励”提示 GPT-5.3。然而，视频（来自 π₀-FAST 博客 [32]）实际展示的是 π₀ 策略在折叠衬衫。模型并未推理任务完成情况，而是编写了一个对相邻帧归一化平均像素差打分的奖励函数，奖励的是“运动”而非“进度”。这反映了源自人类反馈微调的确认偏差，使模型不太可能挑战用户假设 [3,4,5,6,7,8]。虽然提示工程可缓解个别情况，但我们的实验（第 V 节）表明，现有零样本奖励方法——无论基于闭源还是开源 VLM、采用何种自定义提示与奖励提取方案——在基准、真实任务与本体形态上仍表现不佳。接下来我们详述解决方案：解耦的描述与评估阶段。

IV D&A：解耦描述与评估

图 3：D&A 概览。 给定视频 o₁:T 与指令 l，D&A 将奖励预测 R(o₁:T, l) = A(l, D(o₁:T)) 分解为描述器 D 与评估器 A。D 在“看不到” l 的情况下叙述轨迹以避免确认偏差，产生时间一致的描述 d₁:T；A 随后针对 l 的显式成功标准对 d₁:T 的每个时间步打分，得到密集的逐帧奖励 r₁:T ∈ [0,1] 以及丰富的语言反馈。

问题表述。 给定长度为 T 的图像序列（视频）o₁:T ≔ {o₁, o₂, …, o_T}，机器人执行由自然语言指令 l 指定的任务，目标是预测相应的奖励值序列 r₁:T ≔ {r₁, r₂, …, r_T}。每个标量值 r_t ∈ [0,1] 表示时间步 t 的估计奖励，其中 r_t = 0 表示无进度，r_t = 1 对应任务完成。我们构造映射函数 R: (o₁:T, l) ↦ r₁:T，从多模态输入 o₁:T 与 l 估计奖励。先前工作要么后训练 VLM 学习 R [13,14,15,16]，要么以自定义提示与打乱图像输入直接查询 VLM [11,33]，要么在处理 o₁:T 与 l 后通过检查特定 token 的 logits 产生 r₁:T [12]。

方法概述。 我们希望零样本地直接使用预训练 VLM 进行奖励预测；这使我们能利用在互联网规模数据上训练、不断进步的前沿 VLM 的泛化能力与习得推理链，免去机器人特定后训练的繁琐。但实践中，如第 III 节所示，我们发现将 R(o₁:T, l) 朴素地实例化为 VLM 会受确认偏差困扰：无论观察-语言配对代表成功还是失败，模型都预测递增的奖励。

为解决这些局限，我们提出 Describe and Assess（D&A），将 R 分解为带有显式自然语言接口的两个组件：

  • 描述器　d₁:T = D(o₁:T)，▷ 用语言描述观察到的行为
  • 评估器　r₁:T = A(l, d₁:T)，▷ 依据描述对行为打分　(1)

两个函数可使用同一 VLM（或满足相同规范的其他函数），但由不同的输入与提示指定，且无共享上下文。每个函数各司其职，以防固有的 VLM 偏差污染奖励生成。完整奖励函数为复合形式 R(o₁:T, l) = A(l, D(o₁:T))。虽然此处使用 o₁:T 记号，实践中我们将 T 帧线性下采样为 H 帧（H ≪ T，如 H = 8），再将奖励线性插值回长度 T，以降低推理成本与时间。第 IV-A 节详述描述器，第 IV-B 节详述评估器。图 3 给出 D&A 的可视化概览。

IV-A 描述机器人轨迹视频

描述器 D(o₁:T) 的职责是描述机器人在 o₁:T 中做了什么，不以任务指令 l 为条件。对 l 保密可避免确认偏差 [2,3]：知晓预期任务的描述器倾向于把行为叙述成“正在完成该任务”，无论实际发生了什么。示例描述见图 3。

图 4：真实世界 RL 结果。 D&A 改进了真实世界在线（左）与离线强化学习（中、右），而其他零样本与后训练模型表现不佳。左：在线设置中，TOPReward 无法区分成功与失败，对抓取冰淇淋筒和抓取香蕉都预测高奖励。中、右：在次优数据上做行为克隆损害性能，而用 D&A 的离线 RL 带来更高成功率与更快完成时间。TOPReward 与 Robometer 缺乏泛化，对最优与次优动作块给出相近奖励。

一次性描述完整轨迹。 与先前因果地预测单个奖励 r_t = R(o₁:t, l) 再迭代 t 以标注密集奖励的工作 [13,14,15,16,26] 不同，D&A 单次遍历即消费整条轨迹 o₁:T。通过整体描述轨迹，D 能将每个时间步置于其前后事件的上下文中，产生时间一致的描述。

将描述锚定于场景实体。 对 l 保密避免了确认偏差，但引入新的失败模式：在完全不知任务的情况下，描述器可能遗漏对下游评估至关重要的细节。以图 3 为例，实体提取器可能将目标书描述为“Daniel Kahnemann 的《思考，快与慢》”“橙色书脊的书”“白色封面上有铅笔的书”等。实体应反映指令中的粒度以避免描述歧义。为在不向描述器泄漏 l 的前提下解决该问题，我们将 D 分解为两个阶段：实体提取器 E 从指令与视频中列出所有场景实体 e（含任务相关与无关的），以及锚定描述器 D^desc 以这些实体为锚叙述轨迹：d₁:T = D^desc(o₁:T, E(o₁:T, l))。由于 D^desc 不知道哪些实体与任务相关，完整描述器 D 实际上对 l 是“盲”的。接下来我们说明评估器如何使用该描述。

IV-B 成功标准生成与奖励评估

给定锚定描述 d 与指令 l，评估器的职责是产生逐时间步奖励序列 r₁:T。此时人们可能又想朴素地直接查询 LLM/VLM：输入 (l, d) 并要求其为进度打分。但实践中我们发现，这种朴素版本以一种特征性方式失败：评估器经常坍缩为全零输出（当它无法判断是否有实质进展时），或退化为二元成功检测器，简单地从 0 线性插值到 1（如图 1 所示）。然而，要生成对下游应用有用的奖励，我们希望其编码更细粒度的进度信息，例如朝向任务或子任务完成的部分进度。此类细粒度奖励能为策略学习提供更有用的密集信号，例如提高强化学习策略的样本效率，或在模仿学习中帮助过滤低质量动作 [34]。

将评估器锚定于显式成功标准。 该失败模式表明评估器缺乏明确的进度“目标”：l 规定了要做什么，但不一定描述任务成功。我们让评估器先显式生成任务完成条件来解决此问题。具体而言，给定 (l, d₁:T)，评估器内部生成自然语言成功标准 c——即 l 被完全完成时世界可观察状态的描述——然后针对 c（而非仅针对 l）对描述的每个时间步打分：r₁:T = A(l, d₁:T) = A^score(d₁:T, C(l, d₁:T))，其中 C 生成成功标准 c，A^score 依据它对描述打分。将评估锚定于 c，把“估计朝向 l 的进度”重构为更良定的问题“d 距离满足成功标准 c 有多近？”，有助于（1）承认部分进度的有意义概念，（2）抵抗两种奖励坍缩模式。实践中，标准生成与打分通过系统提示在单次评估器调用 A 内完成：模型被指示先阐明 l 的成功条件，再据此对 d 的每个时间步打分——通过 CoT 推理 [36] 强制实现隐式评分量规 [35] 设计。示例见图 3。

IV-C 从进度到丰富的语言反馈

标量奖励只能指出执行失败，无法为策略纠正提供可操作的上下文。通过相对定义的成功标准评估轨迹进度，D&A 随时间构建出隐式语义量规。跟踪各时间步的标准达成情况，使 D&A 能定位执行偏差，展现出对轨迹如何以及为何失败的隐式理解。

为将这些诊断能力转化为下游指导，我们为评估器 A 增加反馈生成器 F(l, d₁:T)，输出包含失败分析与纠正指令的文本字符串 f。评估器公式相应更新为：A(l, d₁:T) = A^score(d₁:T, C(l, d₁:T), F(l, d₁:T))。反馈示例见图 3。

IV-D 使用 D&A 进行下游策略改进

D&A 产生的密集进度奖励与丰富语言反馈可在多种下游策略改进范式中直接使用。这里概述 D&A 如何加速第 V 节实验中使用的范式：在线与离线强化学习（RL）以及代码即策略 [37]。虽着重于此，D&A 是通用的奖励与丰富反馈框架，也可与其他应用结合。

在线 RL。 在线 RL 中，智能体通过与环境的主动交互改进行为。D&A 的绝对进度分数 r₁:T = R(o₁:T, l) 直接作为密集环境奖励，可被任意在线 RL 算法优化。实验中，我们用潜在空间 RL [38] 微调冻结的基础策略。

离线 RL。 离线 RL 中，给定无真实奖励标签的轨迹数据集 𝒟 = {τₙ}ₙ₌₁ᴺ，用 D&A 补充缺失的奖励信号。由于 D&A 的进度分数有界于 [0,1] 且反映全局任务完成度，我们将其视为势函数 [39]，由此导出基于势的逐步密集奖励 r_t，进而导出离线优势：A_t = r_min(t+C,T) − r_t，其中 C 为动作块大小。我们用这些优势过滤训练数据或以其条件化策略（参见 RECAP 与 CFGRL [27,40]）；测试时，条件化于正优势使生成偏向最优轨迹，利用 D&A 的零样本奖励最大化下游性能。

代码即策略。 机器人失败分析 [41] 与反馈驱动优化 [42] 的近期观察表明，丰富的语言反馈可提升策略性能。我们将 D&A 评估为开环 CaP 规划器的尝试间反馈源。每次尝试中，规划器观察初始场景状态并生成代码计划，随后在环境中开环执行。跨尝试地，规划器持续记录先前的计划以及 D&A 生成的反馈（识别失败模式并提出纠正）。

我们将 D&A 与六个表现最强的方法比较，覆盖显式后训练与零样本奖励模型，以全面分析当前格局。除非另有说明，D&A 选用 Gemini 3 Flash 作为基础模型以平衡成本与性能，同时报告 GPT-6 Astra（D&A*）的基准数字以展示能力扩展。

后训练基线在机器人数据集上显式训练以预测进度，均以 Qwen-3-VL [43] 为基础模型。RoboReward [15] 微调以预测 1 至 5 的离散回合末分数，训练数据为大规模机器人数据 [44,45] 并用模拟失败或错配轨迹的反事实语言指令增强。Robometer [16] 在 RBM-1M（最优与次优数据）上微调，采用多目标框架联合预测 [0,1] 连续进度、二元成功与成对轨迹偏好。SOLE-R1 [30] 在 CoT [36] 与连续进度估计上微调，再用可验证奖励强化学习（RLVR）进一步调优。

零样本基线利用现成 VLM 的世界知识，无需任何任务或机器人特定微调。朴素 VLM 用单次 VLM 调用建模映射 R: (o₁:T, l) ↦ r₁:T，不做解耦或成功标准推理即预测进度。GVL [11] 以时间打乱的帧提示 VLM，迫使其独立于时间顺序判断每帧的内在进度，以对抗 VLM 对时间连续性的偏向。TOPReward [12] 以完整视频与指令提示 VLM，但不以文本形式输出进度，而是从“指令是否匹配执行”的 "True" 回答 token logit 中提取。为公平比较，我们为 TOPReward（Qwen-VL 8B）与 GVL（Gemini 3 Flash）选择可比模型，并在图 8 中报告其在更强模型上的扩展表现。

(Q1) D&A 是否是真实世界离线与在线 RL 的有效奖励模型？

在线 RL。 我们将 DSRL [38] 应用于在 DROID [47] 上微调的 π₀ [46] 策略，直接以 D&A 进度分数作为密集奖励。我们在 DROID 厨房环境中评估“把水果放进碗里”（图 4 左），π₀ 基础模型总是去抓冰淇淋筒，最初仅 10% 的时间完成任务；通过 RL 学到正确行为需要能区分好坏状态转移的奖励。D&A 提供了这种信号：对抓冰淇淋筒的轨迹给零奖励，对操作香蕉给高而密集的奖励，在约 90 分钟墙钟时间内将成功率提升至 100%。相比之下，TOPReward 对成功与失败轨迹都给高奖励，成功率仅 5%。

离线 RL。 我们将 π₀.₅ [48] 条件化于由 D&A 奖励经 CFGRL/RECAP [40,27] 计算的优势，回报相对全数据集估计的全局价值基线居中，使优势依据数据集全局结果分布对状态-动作对排序。我们在双臂 YAM（图 4）上收集 50 条最优、50 条次优与 50 条失败演示，任务为“把红书从顶层架子移到灰盒子里”，失败包括用错盒子或手臂、中途掉落书本。我们对 π₀.₅ 进行 50k 步 LoRA 微调。仅在成功与次优数据上微调的基线 π₀.₅ 成功率仅 20%，复现了许多次优行为。TOPReward 与 Robometer 对次优数据利用更好，但其噪声奖励无法完全滤除次优性；D&A 则过滤掉这些行为，将 BC 提升 +80%，优于所有其他模型。

优势过滤的行为克隆。 我们在双臂 YAM 上为“抽出《思考，快与慢》这本书，抓住它并放到桌上”收集 50 条最优与 100 条次优演示。次优演示包括轻推或抽出别的书但最终完成任务。我们用单一数据集级阈值 τ 按优势 A_t 对数据集中所有动作块排序，使动作块与全局结果分布比较而非仅在本回合内比较。我们在排名前 35 百分位的动作块（A_t ≥ τ）上对 π₀.₅ 进行 25k 步 LoRA 微调。Robometer 与 TOPReward 均表现不佳，难以应对任务的长时程，对最优与次优动作块给出相近分数。在全量数据上训练的 π₀.₅ 有竞争力但常执行次优动作，性能尚可但执行缓慢。成功时，D&A 比基线微调 π₀.₅ 更快完成任务，平均 18.8±1.8 秒对 28.5±9.2 秒，且各次 rollout 方差显著更低。这表明 D&A 滤除了次优并保留了最优动作块。

(Q2) D&A 对不同任务与本体形态的泛化能力如何？

为跨任务、本体形态与语言评估 D&A，我们在三个离线基准上评估：D&A-Bench——我们手动收集的泛化基准，保证对所有模型均为分布外，以压力测试细粒度场景与语言理解；以及两个外部基准 RBM-EVAL-OOD [16] 与 RoboRewardBenchmark [15]。

我们提出 D&A-Bench 以评估细致的场景理解（如“精确量取 16 克咖啡豆”）、计数（“搭一座 5 块积木的塔”）与语义推理（“组装汽车”）。该基准包含 14 个 YAM 任务的 54 条轨迹（27 成功、27 失败），每个任务配 10 条 VLM 生成的指令改写以测试语言鲁棒性。D&A-Bench 与 RBM-EVAL-OOD 报告 Kendall τ_α 系数 [49]，衡量奖励模型最终步预测与最优、次优、失败轨迹真实排序的一致程度（∈ [−1, +1]，越高越好）。RoboRewardBenchmark 使用离散回合末进度标签并报告平均绝对误差（MAE，越低越好）。

在全部三个基准（图 5）上，D&A 缩小了与后训练模型的差距：在 RBM-EVAL-OOD 上超越 RoboReward，在 RoboRewardBenchmark 上超越 Robometer，在两者上均超越 SOLE-R1。在 D&A-Bench 上，D&A 发挥其基础 VLM 的泛化与推理能力，得分最高（0.67），击败最佳后训练模型 Robometer（0.56）与 RoboReward（0.43）。零样本 TOPReward（0.24）与 GVL（0.27）无法泛化到这些高难任务。D&A 比朴素 VLM 提升 +0.23——后者在此竟是出人意料的强基线：由于该基准考察场景与语言泛化，即使对强基础 VLM 的非结构化提示，其泛化也远好于无法可靠比较轨迹的 GVL 与 TOPReward。图 7(b) 以“按下回车键”为例说明：其完成仅体现为屏幕上的细微变化——D&A 跟踪完整轨迹并将成功与视觉上相似的失败干净分开，而 Robometer 对两者给出几乎相同的奖励，RoboReward/SOLE-R1 判断相反，零样本朴素 VLM/GVL/TOPReward 则对两者都打高分。更多定性示例见第 XIV 节。

(Q4) 哪些组件对 D&A 的性能有贡献？

为理解各设计决策的贡献，我们使用 Gemini 3.7 Flash 在表 I 中进行系列消融。为朴素 VLM 引入显式成功标准可将性能提升 +0.18，缩小零样本与后训练方法的差距。将成功标准与描述/评估阶段解耦相结合，反而损害性能，原因是任务相关对象无法被识别或在语言描述中完全缺失。当把描述锚定于视频中出现的对象后，性能较朴素 VLM 提升 +0.26，在某些情况下超越后训练模型。

(Q5) D&A 生成的丰富反馈能否超越标量奖励？

我们在 LIBERO 基准（goal 套件）[50] 上评估 D&A 作为改进代码即策略 [37] 的丰富反馈源。CaP 规划器多次尝试解决任务，生成代码并在环境中执行。我们比较“代码 + 二元成功”的历史记录与在此基础上追加 D&A 丰富反馈的版本。允许 CaP 利用历史迭代改进，将性能从 11.4%（无历史）提升至 40.6%（有历史）。加入 D&A 的丰富语言反馈后达到 51.4%（相对历史基线 p = 0.00076），展示了丰富的语义反馈如何为下游改进提供比标量奖励更有效的信号。反馈改进行为的示例见图 10。

VI 局限与讨论

本文提出 D&A，一种在前沿模型中进行奖励建模与丰富反馈的方法。我们通过解耦描述与评估来对抗确认偏差并解决成功幻觉，并在多个真实机器人操作任务上验证了 D&A 的有效性。

尽管有效，本方法存在若干局限。首先，它继承了现成前沿模型的系统性约束，包括高推理延迟、token 成本与有限的上下文窗口。由于这些模型通常经闭源 API 访问，会引入随机性且细粒度控制有限。它们也仍可能出现偶发的语义幻觉，降低描述保真度及后续奖励评估质量。

其次，生成的奖励受自然语言描述粒度的限制。这在需要高度细致或连续、难以言喻的奖励结构的领域构成挑战，例如精确的空间关系或绝对几何距离。

尽管存在这些挑战，D&A 标志着从微调到零样本机器人奖励建模的关键转变，并随前沿 VLM 的快速进步而扩展。

VII 基于优势条件化的离线 RL：完整推导

我们提供第 IV-D 节概述的优势条件化离线 RL 流程的完整推导。与严格受训练数据平均性能约束的标准行为克隆（BC）或过滤 BC 不同，RL 可以得到优于演示者的策略。

设给定包含 N 条轨迹的离线数据集 𝒟 = {τₙ}ₙ₌₁ᴺ。每条轨迹 τ 是观察与动作的序列 τ = {(o₁,a₁),(o₂,a₂),…,(o_T,a_T)}。回顾我们将进度分数 r_t = R(o₁:T, l) 视为势函数，并将逐步基于势的奖励定义为时间差分 r̃t = r_t − r{t−1}（r₀ = 0），有效捕捉每步任务改进的瞬时速率。

由于处于离线设定，我们可完全离线计算经验状态值与优势，无自举的稳定性风险或误差累积。对轨迹内任意时间步 t，折扣蒙特卡洛回报为 G_t = Σ_{k=t}^T γ^(k−t) r̃k，其中 γ ∈ [0,1) 为折扣因子。为衡量特定动作序列相对整个数据集的优劣，我们建立全局价值基线 V 为 𝒟 中所有时间步与所有轨迹的折扣蒙特卡洛回报的经验均值：V = (1/Σₙ Tₙ) Σₙ Σₜ G{t,n}。

在全数据集（而非逐轨迹或逐任务）上计算 V，使所得优势依据数据集全局结果分布对状态-动作对排序，这正是 CFGRL 条件化的对象。利用该全局基线，每个状态-动作对的离线优势 A(s_t, a_t) 计算为中心化回报：A(s_t, a_t) = G_t − V。

这些优势可直接用于下游离线 RL 算法。我们借助 CFGRL 框架 [40]，通过训练条件策略 π_θ(a_t | s_t, l, g) 及其无条件或基线变体来扩展动作或动作 token，在优化中以优势作为显式条件变量 g。遵循 RECAP [27]，我们将该优势引导框架直接适配 π₀.₅ [48]，并以标准监督对数似然目标优化模型：ℒ(θ) = −𝔼_{(s_t,a_t,l)∈𝒟}[log π_θ(a_t | s_t, l, g)]。

VIII 基于潜在空间噪声引导的在线 RL：完整推导

我们提供第 IV-D 节概述的在线 DSRL 流程的完整优化细节。与受益于静态、数据集级基线计算的离线设定不同，在线策略学习要求智能体通过主动环境交互持续探索并优化行为。DSRL [38] 学习策略 π_θ(w | s, l)，生成低维潜在引导向量或噪声变量 w，再经冻结的基础模型映射产生最终机器人动作，而非直接在高维动作空间中优化。

在该范式下，智能体在线与环境交互，D&A 生成的绝对任务进度分数 r_t = R_{1:T}(o₁:T, l) 直接用作密集环境奖励。为在潜在空间交互上优化策略，我们维护软动作值函数 Q_ϕ(s, w, l) 与目标状态值网络 V_ψ̄(s, l)。评论家参数 ϕ 通过最小化标准时序差分（TD）误差优化：

ℒ(ϕ) = 𝔼_{(s_t,w_t,r_t,s_{t+1})∼ℬ}[(Q_ϕ(s_t, w_t, l) − (r_t + γ V_ψ̄(s_{t+1}, l)))²]　(2)

同时，策略参数 θ 更新以最大化评论家给出的期望未来回报并附加熵正则项：

ℒ(θ) = −𝔼_{s_t∼ℬ, w_t∼π_θ}[Q_ϕ(s_t, w_t, l) − α log π_θ(w_t | s_t, l)]　(3)

通过将该在线优化循环直接映射到冻结专家的潜在噪声空间，该框架缓解了灾难性遗忘与策略坍缩，实现了由 D&A 奖励驱动的样本高效在线行为优化。
