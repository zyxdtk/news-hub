面向对话的多模态情绪识别混合专家模型

📅 2026-02-26 📄 arxiv 🔗 原文链接

原标题：A Mixture-of-Experts Model for Multimodal Emotion Recognition in Conversations

中文摘要： 本文提出MiSTER-E，一种用于对话情绪识别的模块化混合专家模型，通过解耦模态特定上下文建模与多模态融合，利用语音与文本大语言模型生成嵌入，并在决策层融合三个专家（仅语音、仅文本、跨模态）的预测。实验表明，该模型在IEMOCAP、MELD和MOSI数据集上分别取得70.9%、69.5%和87.9%的加权F1分数，优于现有基线，且无需说话人身份信息。

面向对话的多模态情绪识别混合专家模型 苏米娅·达塔 斯姆鲁蒂·巴拉吉 斯里拉姆·甘纳帕蒂

摘要 对话情绪识别（ERC）面临独特挑战，要求模型捕捉多轮对话的时间流，并有效融合多模态线索。本文提出语音-文本专家混合情绪识别模型（MiSTER-E），一种模块化的混合专家（MoE）框架，旨在解耦ERC中的两大核心挑战：模态特定上下文建模与多模态信息融合。MiSTER-E利用针对语音和文本微调的大语言模型（LLMs）生成丰富的语句级嵌入，并通过卷积-循环上下文建模层加以增强。系统采用学习到的门控机制动态加权融合三个专家（仅语音、仅文本、跨模态）的预测结果。为进一步促进模态间一致性与对齐，我们引入了成对语音-文本表示间的监督对比损失，以及基于KL散度的专家预测正则化项。 值得注意的是，MiSTER-E在任何阶段均不依赖说话人身份信息。在IEMOCAP、MELD和MOSI三个基准数据集上的实验表明，本方法分别取得70.9%、69.5%和87.9%的加权F1分数，优于多个基线语音-文本ERC系统。我们还提供了多种消融实验，以凸显所提方法的贡献。

关键词：混合专家，协同注意力模型，多模态融合，情绪识别

1 引言 对话情绪识别（ERC）旨在推断参与多轮交互（常涉及多种模态）的说话人的情绪状态。作为构建情感智能与社会感知AI系统的关键组件，ERC在诸多现实应用中发挥着重要作用——从共情式对话代理、客户服务机器人，到社交媒体监控与心理健康评估系统[1,2,3]。在对话场景中，情绪并非孤立表达；其随时间展开，并通过文本内容、语音韵律及视觉线索等多种信号的复杂组合进行传递。这些信号常以微妙且依赖上下文的方式交互，因此必须同时捕捉模态内动态与跨模态依赖关系。对话固有的序列性与多模态性，加之情绪的主观性与上下文敏感性，使ERC成为情感计算中一项复杂而富有挑战性的任务。

为推进ERC研究，已提出多种方法，在对话上下文建模[4,5]、捕捉人际依赖关系的说话人感知表征[6,7]，以及多模态融合策略（从简单早期拼接[8]到更复杂的基于注意力[9]与张量方法[10]）等方面取得了显著进展。然而，尽管取得进展，多数现有系统仍采用单体架构，将两个根本不同的建模挑战混为一谈：(i) 捕捉多轮对话的时间上下文；(ii) 执行跨模态信息融合。这种耦合会限制模型性能，尤其在训练数据稀缺（ERC任务中常见）时，易导致模型过拟合于数据集特有模式，而非学习可泛化的情绪线索。由此引出本文核心研究问题： 架构模块化——即明确将上下文建模与模态融合解耦——能否带来更有效、更具泛化能力的对话情绪识别？

在我们先前的研究（Dutta等[11]）中，曾尝试通过构建ERC分层建模框架来回应此问题。该工作将建模流程分为两阶段：首先进行模态内上下文建模，再进行模态间融合。该结构引入了一定程度的架构解耦，并提升了性能。然而，关键局限仍存：当各模态性能差距较大时，整体系统无法超越最优单模态系统。

本文提出语音-文本专家混合情绪识别模型（MiSTER-E），一种在logit（决策）层级而非特征层级实施专家组合的模块化架构。MiSTER-E采用混合专家（MoE）形式，包含三个独立优化分支：仅语音上下文专家、仅文本上下文专家与多模态专家。单模态系统采用时间 inception 网络后接循环层，以捕捉模态特定对话动态；多模态专家则通过交叉注意力与自注意力层融合语音与文本特征。专家输出通过门控机制组合，即在softmax归一化前计算加权和。该决策层级融合支持动态专家选择，使模型能有效整合互补的多模态线索。

为稳定专家专业化，我们引入对比损失与基于KL的一致性损失，同时以焦点损失（focal loss）监督各专家以应对类别不平衡问题。特别地，当任一模态（语音或文本）显著优于另一模态时，我们的模态解耦结合基于MoE的组合方式展现出相较于先前工作的独特融合优势。

本文主要贡献如下： 1. 提出MiSTER-E，一种用于对话情绪识别的模块化框架，通过决策层级混合专家架构分离模态特定上下文建模与多模态融合。 2. 证明自适应、按语句的专家加权可有效应对模态不平衡，使单模态专家在跨模态线索不可靠时占据主导。 3. 引入辅助训练目标，包括语音-文本对比损失与基于KL散度的一致性正则化，以稳定专家专业化。 4. 证明MiSTER-E在三个基准ERC数据集（IEMOCAP[12]、MELD[13]、CMU-MOSI[14]）上达到最优性能，且无需使用说话人身份信息。

2 相关工作 文本嵌入提取：早期ERC方法依赖Word2Vec[15]和GloVe[16]等静态词嵌入编码语句[17,10,18]。随着BERT[19]和RoBERTa[20]等基于Transformer的语言模型兴起，ERC系统开始采用上下文编码器[21,22,23]，显著提升了文本特征质量。近期仅文本方法[24,25]将ERC视为生成任务，以自回归方式微调大语言模型（LLMs）。然而，LLMs在语音-文本联合场景下的高效利用尚未探索。为此，我们将LLMs适配为文本情绪识别的编码器，从而发挥其强大能力并支持跨模态融合。

语音嵌入提取：ERC中语音特征传统上依赖OpenSMILE[26]和COVAREP[27]等手工设计描述符，虽有效但泛化性受限于多样声学条件[5,17]。近期研究转向可学习前端（如LEAF[28]）与自监督模型（如HuBERT[29]和wav2vec[30]），并取得成功[31,32]。然而，多模态大语言模型在ERC中的应用仍属空白。因此，我们直接微调语音大语言模型（SLLMs）用于情绪推断——此方法在多模态ERC中尚未被探索。

MoE在ERC中的应用：尽管混合专家（MoE）架构在扩展语言[33,34]与视觉模型[35]中展现出潜力，其在ERC中的应用仍有限。近期工作MMGAT-EMO[36]将MoE与图注意力结合用于情绪建模。相比之下，我们利用MoE构建包含语音、文本与融合模态三类专业化专家的模型结构，明确针对上下文建模与跨模态融合的解耦。

ERC损失函数：Li等[38]首次将监督对比学习[37]引入ERC，并在后续工作中扩展[39,40]，使用情绪类别原型。部分方法进一步扩展至模态对齐——例如将音视频线索与文本锚点对齐[41]。本文则采用多模态监督对比损失，对同一情绪类别下跨模态语句表示进行对齐。此外，引入一致性损失以促进专家间共识，强化模块化协作。

基于LLM的ERC上下文建模：近期研究探索在语音处理流程中使用大语言模型（LLMs）进行情绪识别。例如，提出基于LLM的生成误差校正框架以优化ASR输出并执行下游任务（包括情绪识别[42]）。Stepachev等[43]利用多个ASR系统输出与固定对话上下文窗口作为LLM输入，提升ASR后情绪识别性能。Zhang等[44]进一步证明，精心选择上下文语句可提升情绪识别性能，即使文本来自噪声ASR系统。这些方法凸显了LLMs在上下文建模与ASR后情绪识别中的日益重要性。相比之下，MiSTER-E将LLMs作为嵌入编码器嵌入模块化混合专家框架中，明确解耦并集成模态特定上下文建模与多模态融合于决策层级。

3.1 问题描述 设ERC数据集𝒟包含P段对话：𝒞={𝐜₁,𝐜₂,…,𝐜ₚ}，其中每段对话𝐜ᵢ由语句序列𝒰ᵢ=(𝐮ᵢ₁,𝐮ᵢ₂,…,𝐮ᵢNᵢ)构成，Nᵢ为该对话语句数。𝐮ᵢₖ表示第k条语句，其语音与文本模态分别记为𝐬ᵢₖ与𝐭ᵢₖ。每条语句关联情绪标签yᵢₖ∈𝒴，𝒴为数据集情绪类别集合。ERC任务即映射语句序列{𝐮ᵢ₁,…,𝐮ᵢNᵢ}至对应标签序列𝐲ᵢ={yᵢ₁,…,yᵢNᵢ}。

3.2 单模态特征提取 文本嵌入：尽管大语言模型（LLMs）在文本生成上表现出色，其在情绪识别中的应用仍有限。以往工作通常以自回归模式或冻结特征提取器方式使用LLMs[45]。本文微调LLaMA-3.1-8B作为文本编码器而非生成器。每条语句文本𝐭ᵢₖ经分词后输入LLM，池化token级隐藏状态并送入两层前馈分类器（经任务监督训练）。为保留预训练知识并实现高效适配，采用LoRA[46]微调权重。文本嵌入表示为： 𝐞ᵢₖᵗ = Text-Embed(𝐭ᵢₖ) (1) 嵌入取自分类器首层全连接层输出。

语音嵌入：语音端采用类似方案，使用SALMONN-7B[47]（含语音编码器、Q-Former[48]与LLM主干的语音大语言模型）。ERC任务中，通过LoRA更新Q-Former、LLM及分类头，使系统学习情绪显著声学模式，同时保留LLM主干语义特征。给定语音信号𝐬ᵢₖ，其表示为： 𝐞ᵢₖˢ = Speech-Embed(𝐬ᵢₖ) (2) 嵌入取自语音分类头首层全连接层。替代LLM/SLLM模型对比见第4.8节。

3.3 对话建模 对对话𝐜ᵢ，文本与语音嵌入序列（第3.2节）分别记为𝐄ᵢᵗ=(𝐞ᵢ₁ᵗ,…,𝐞ᵢNᵢᵗ)与𝐄ᵢˢ=(𝐞ᵢ₁ˢ,…,𝐞ᵢNᵢˢ)。图2：(a) MiSTER-E中语音侧上下文添加网络（CAN）；(b) 多模态网络。TIN：时间Inception网络；MHA：多头注意力。

如图1所示，微调后的语音与文本嵌入提取器在其余流程训练时保持冻结。

3.3.1 上下文添加网络 为使语句表征具备上下文感知能力，引入上下文添加网络（CAN），利用对话上下文增强文本与语音嵌入（第3.2节）。其核心为时间Inception网络（TIN），通过核大小为1、3、5的一维卷积捕捉短程依赖，模拟局部语句邻域内不同感受野。受图像分类中Inception架构[49]启发，TIN支持对话内多尺度时间上下文建模。然而，对话中情绪信号常随更长时间演变。为捕捉此类全局依赖，附加Bi-GRU层以整合全对话信息。残差连接将原始嵌入与其上下文增强版本相加，在保留基础LLM特征语义根基的同时实现加性精炼。最后，全连接（FC）层将每条语句𝐮ᵢₖ映射至对应情绪类别yᵢₖ。

分别训练两个相似网络处理语音与文本模态，操作表示为： 𝐲̂ᵢˢ = (𝐲̂ᵢ₁ˢ,…,𝐲̂ᵢNᵢˢ) = CAN(𝐄ᵢˢ) (3) 𝐲̂ᵢᵗ = (𝐲̂ᵢ₁ᵗ,…,𝐲̂ᵢNᵢᵗ) = CAN(𝐄ᵢᵗ) (4) 语音侧CAN示意图见图2(a)。

3.3.2 多模态网络 为整合跨模态信息，设计基于语音-文本交叉注意力的融合模块。该机制使模型能将文本语义线索与音频情感信号对齐。语音与文本嵌入𝐄ᵢˢ与𝐄ᵢᵗ首先投影至查询、键、值空间，再双向应用交叉注意力： 𝐌ᵢᵗ→ˢ = LN(FC(𝐄ᵢˢ) + MHA(𝐐ᵢˢ,𝐊ᵢᵗ,𝐕ᵢᵗ)) (5) 𝐌ᵢˢ→ᵗ = LN(FC(𝐄ᵢᵗ) + MHA(𝐐ᵢᵗ,𝐊ᵢˢ,𝐕ᵢˢ)) (6) 其中MHA与LN分别指多头注意力与层归一化。

此设计虽实现跨模态对齐，却忽略了对话上下文对ERC至关重要的线索。为解决此问题，在对齐表示上应用模态特定自注意力层，以捕捉对话时间上下文： 𝐌ᵢˢ = Self-attn.(𝐌ᵢᵗ→ˢ) (7) 𝐌ᵢᵗ = Self-attn.(𝐌ᵢˢ→ᵗ) (8)

输出𝐌ᵢˢ与𝐌ᵢᵗ拼接后经全连接层： 𝐲̂ᵢᵐ = (𝐲̂ᵢ₁ᵐ,…,𝐲̂ᵢNᵢᵐ) = FC([𝐌ᵢˢ;𝐌ᵢᵗ]) (9) 整体流程见图2(b)。

3.4 混合专家门控 对每条语句𝐮ᵢₖ，从三个专家获取softmax前logits：语音专家（𝐲̂ᵢₖˢ）、文本专家（𝐲̂ᵢₖᵗ）与多模态专家（𝐲̂ᵢₖᵐ）。

为组合logits，采用门控机制动态融合专家预测。计算权重时，将logits拼接后输入全连接层： 𝐠ᵢₖ = FC([𝐲̂ᵢₖˢ;𝐲̂ᵢₖᵗ;𝐲̂ᵢₖᵐ]) (10) 门控网络输出𝐠ᵢₖ∈ℝ³，经softmax变换得自适应混合权重𝛽ᵢₖ。最终logits为专家预测的加权和： 𝐲̂ᵢₖ = βᵢₖˢ·𝐲̂ᵢₖˢ + βᵢₖᵗ·𝐲̂ᵢₖᵗ + βᵢₖᵐ·𝐲̂ᵢₖᵐ (11) 对𝐲̂ᵢₖ应用softmax得语句𝐮ᵢₖ最终预测分布。该门控网络端到端训练，使模型能灵活整合模态，突出最可靠专家。

3.5 模型训练 3.5.1 损失函数 ERC通常存在严重类别不平衡，导致稀有情绪类别易被误分类[50]。为应对此问题，采用焦点损失[51]，根据样本复杂度调节其贡献，降低易分类样本的相对损失，聚焦困难（可能为少数类）样本。

在MiSTER-E中，该损失用于训练文本与语音单模态嵌入提取器及其各自上下文添加网络（CAN）。语音与文本CAN网络损失为： ℒ_CANⁱ = ∑ₖ₌₁^Nᵢ FL(𝐲̂ᵢₖˢ,yᵢₖ) + ∑ₖ₌₁^Nᵢ FL(𝐲̂ᵢₖᵗ,yᵢₖ) (12) 其中FL(·)表示焦点损失函数。焦点损失描述及消融见第4.4节。

3.5.2 多模态对比损失 语音与文本常提供关于说话人情绪的互补信号。为利用此特性，引入监督对比损失，基于情绪标签构建联合表征空间，拉近跨模态共享情绪意图的语句距离。

设多模态语音与文本表示分别为𝐌ᵢˢ={𝐦ᵢ₁ˢ,…,𝐦ᵢNᵢˢ}与𝐌ᵢᵗ={𝐦ᵢ₁ᵗ,…,𝐦ᵢNᵢᵗ}。将嵌入批处理为： 𝐙ᵢ={𝐦̃ᵢ₁ˢ,…,𝐦̃ᵢNᵢˢ,𝐦̃ᵢ₁ᵗ,…,𝐦̃ᵢNᵢᵗ} (13) 其中𝐦̃ᵢₖ^· = 𝐦ᵢₖ^· / ||𝐦ᵢₖ^·|| 表示归一化嵌入。

设𝐳ₐ∈𝐙ᵢ（a∈{1,2,…,2Nᵢ}），yₐ为其关联情绪标签。对比损失为： ℒ_conⁱ = ∑ₐ₌₁^{2Nᵢ} [-1/|P(a)|] ∑_{p∈P(a)} log[exp(𝐳ₐ^⊤𝐳ₚ/τ) / ∑_{q=1,q≠a}^{2Nᵢ} exp(𝐳ₐ^⊤𝐳_q/τ)] (14) 其中τ为温度，P(a)={p∈{1,2,…,2Nᵢ}\{a\}|yₚ=yₐ}为锚点𝐳ₐ的正样本集。此目标拉近同情绪类别跨模态语句距离，推远其他样本，引导模型学习情绪连贯、模态不变表征。

总多模态损失：最终用于训练多模态模型的损失结合分类与对比目标： ℒ_multiⁱ = ∑ₖ₌₁^Nᵢ FL(𝐲̂ᵢₖᵐ,yᵢₖ) + λℒ_conⁱ (15) 其中𝐲̂ᵢₖᵐ为多模态预测，λ控制对比损失贡献。

3.5.3 MoE门控损失 为训练混合专家（MoE）门控网络，结合两个目标：(i) 情绪分类焦点损失；(ii) 促进专家预测一致性的正则化项。具体地，通过Kullback-Leibler（KL）散度强制三个专家（仅语音、仅文本、多模态）预测分布相似。

MoE层总损失为： ℒ_moeⁱ = ∑ₖ₌₁^Nᵢ FL(𝐲̂ᵢₖ,yᵢₖ) + α·ℒ_KLⁱ (16) 其中𝐲̂ᵢₖ定义见式(11)，α控制一致性正则化强度，KL项为： ℒ_KLⁱ = ∑ₖ₌₁^Nᵢ [KL(𝐩̂ᵢₖᵐ||𝐩̂ᵢₖˢ) + KL(𝐩̂ᵢₖᵐ||𝐩̂ᵢₖᵗ)] (17) 其中𝐩̂ᵢₖ^· 为对相应专家logits 𝐲̂ᵢₖ^· 应用softmax所得类别概率分布。KL一致性损失鼓励单模态语音与文本专家生成与多模态专家对齐的预测分布。由于多模态专家联合建模两模态，将其输出分布视为更强监督信号，故采用此方向性KL散度。

3.5.4 总损失 上下文添加网络、多模态网络与MoE门控层联合训练。总损失为： ℒ_tot = ∑ᵢ₌₁^P [ℒ_CANⁱ + ℒ_moeⁱ + ℒ_multiⁱ] (18)

4.4 焦点损失 焦点损失[51]常用于处理类别不平衡。鉴于本文ERC数据集均不平衡，以焦点损失替代交叉熵损失。设logits 𝐲̂ᵢₖ^· 对应样本预测概率为𝐩̂ᵢₖ^·，焦点损失为： FL(𝐲̂ᵢₖ^·,yᵢₖ) = -∑_{c=1}^𝒴 yᵢₖ^c (1-𝐩̂ᵢₖ^·c)^γ log(𝐩̂ᵢₖ^·c) (19) 其中yᵢₖ^c在真实类别为1，其余为0；𝐩̂ᵢₖ^·c为类别c预测概率（·替换为s、t或m）；γ为焦点损失超参数。

图3展示不同γ值（式19）下所提方法性能。交叉熵损失（γ=0）下两数据集性能均下降，表明需采用更适不平衡数据集的损失函数。γ值设为3。

6 结论 提出MiSTER-E，一种显式分离上下文建模与多模态融合的ERC模块化框架。利用基于LLM的语音与文本表征，通过时间inception块后接Bi-GRU建模对话上下文，并以注意力网络执行模态融合。混合专家（MoE）门控自适应整合上下文感知与多模态专家决策。 MiSTER-E在IEMOCAP、MELD与CMU-MOSI上达新SOTA，无需说话人身份信息，证明模块化上下文-融合与决策层门控有效性。 焦点损失、监督对比学习与基于KL的一致性正则化等辅助组件仅带来小幅性能提升，宜视为提升训练稳定性与鲁棒性的优化，而非架构必需元素。

7 局限性 尽管MiSTER-E在多基准上表现强劲，仍存若干局限： (i) 大LLM/SLLM编码器引入显著计算与内存开销，可能限制低资源或实时场景应用（尽管采用参数高效微调）。表3已部分缓解此问题，显示所提方法对非LLM特征亦有益； (ii) 评估主要在脚本化/半脚本化对话基准数据集（如电视剧、表演对话）进行，跨域至自发真实对话场景的性能仍待探索； (iii) 情绪推断模型易受与人口统计、语言使用及标注主观性相关的数据集偏差影响，本文未进行偏差/公平性分析； (iv) 本文有意避免显式说话人身份建模，但利用说话人元数据可能提升人际动态建模。部分局限的解决构成未来工作。
