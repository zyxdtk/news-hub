摘要

时序基础模型（TSFMs）正日益广泛地应用于各领域的概率预测，但其不确定性估计的可靠性仍缺乏充分理解。在本工作中，我们从更广泛的方法论与实证视角研究概率TSFMs的不确定性校准问题。我们引入了一个关于TSFMs如何表示预测不确定性的分类体系，并针对多步预测中的校准问题开发了一个细粒度评估框架，该框架区分了池化、逐视界以及更强的条件化校准概念。利用该框架，我们对多种流行的TSFMs在多样化数据集上进行了全面的实证评估，结果表明当前模型表现出标准指标常常掩盖的、独特且系统性的失准模式。我们进一步分析了常见的后处理重校准方法，刻画了它们能够改进哪些形式的校准、而哪些失准问题倾向于持续存在。我们的结果为评估和改进TSFMs的不确定性校准提供了实用指导，并凸显了当前实践的重要局限。

1 引言

时序基础模型（TSFMs）正逐步成为预测领域的通用方法（Liang 等，2024）。这类模型在大规模且异构的时序数据集合上进行预训练，通常能够以零样本方式应用于未见过的数据集、频率和领域，同时与专门的预测系统保持竞争力（Ansari 等，2024a；Woo 等，2024；Das 等，2024）。随着其在医疗保健（Gu 等，2025）、能源系统（Meyer 等，2025）和金融（Zhu 等，2025）等高风险应用中的采用日益增长，这些模型不仅需要产生准确的预测，还需要以可信的方式传达不确定性，这一点变得越来越重要。

在许多此类场景中，决策不仅取决于预测结果本身，还取决于不利结果发生的可能性。这使得不确定性估计的质量成为超越预测准确性的重要实践目标。然而，此类估计只有在其声明的置信水平能够被可靠解读时才有价值。具体而言，以90%置信度报告的预测区间应当在大约90%的情况下包含实际结果。这种可靠性概念通常由校准来刻画，即预测概率与观测频率相一致（Gneiting 等，2007；Gruber 与 Buettner，2022；Kuleshov 等，2018；Song 等，2019）。因此，一个模型完全可能在取得优异预测精度的同时，提供在实践中具有误导性的不确定性估计。

尽管TSFMs日益支持不确定性感知的预测，但该场景下的校准问题仍只得到部分理解。近期工作已开始对这一问题进行实证研究（Adler 等，2026），为现代预测模型的校准提供了重要的初步视角。与此同时，校准在多步预测中是一个微妙的属性：结论可能取决于预测的表示方式、行为在不同视界步骤间的变化，以及结果在不同实例间的聚合方式。这就需要一个更系统的评估框架，以支持异构TSFMs之间的比较，并揭示可能被标准聚合指标掩盖的失准形式。

这一问题也具有重要的实践意义，因为失准通常在训练后通过后处理重校准方法加以解决。此类技术在分类（Minderer 等，2021；Silva Filho 等，2023）和回归（Kuleshov 等，2018；Song 等，2019；Dheur 与 Taieb，2023）领域已被广泛研究，作为一种轻量级手段，可在不对底层预测器进行显著重训练的情况下提升模型置信估计的可靠性。然而，对于概率TSFMs而言，这些方法的作用仍不明朗，因为人们尚不清楚它们在单个数据集上能有多大效果，以及它们能够纠正哪些形式的失准。

在本工作中，我们对概率TSFMs的不确定性校准进行了系统研究。我们首先引入一个不确定性量化机制的分类体系，按照获取不确定性估计所依据的预测对象来组织TSFMs。基于这一统一视角，我们随后开发了一个面向多步预测的校准评估框架，该框架超越了池化平均覆盖率，纳入了更强的分位数条件化诊断。最后，我们利用该框架在广泛的TSFMs和数据集上分析校准与后处理重校准。图1概述了该框架及主要实证发现。

我们的主要贡献如下：

  • 我们引入了概率TSFMs中不确定性量化机制的统一分类体系，按照获取逐视界预测分布所依据的预测对象对模型进行组织。
  • 我们开发了一个适用于上述各类模型的概率多步预测校准评估框架，区分了池化、逐视界和分位数条件化的校准概念。
  • 我们建立了所得校准度量之间的理论关系，阐明了池化与平均覆盖率如何掩盖结构化的失准形式，并利用这些关系定义了针对视界特定误差和值依赖误差的诊断性差距度量。
  • 我们提供了跨多种TSFMs和数据集的校准与后处理重校准的大规模实证研究，结果表明当前模型表现出系统性但异质的失准模式，而标准重校准方法虽能显著改善平均校准水平，却只能部分解决更强的条件化缺陷。

2 背景与相关工作

数学设置。 我们将单变量时间序列视为实值观测的有序序列。在预测任务中，我们观测最近的 T ∈ ℕ 个值，称为上下文窗口 x = (x₁, …, x_T) ∈ ℝ^T，目标是预测接下来的 H ∈ ℕ 个值，称为预测视界 y = (y₁, …, y_H) ∈ ℝ^H。由于未来值具有不确定性，我们将 y 视为随机向量 Y = (Y₁, …, Y_H) 的一次实现，并记 P(Y|X=x) 为给定上下文 x 时其真实条件分布，其中 x 是随机向量 X = (X₁, …, X_T) 的一次实现。

对于标量值目标，不确定性通常通过累积分布函数（CDF）及其逆函数——分位数函数来表示。对于具有实现值 y ∈ ℝ 的随机变量 Y，二者定义为：

F_Y(y) := P(Y ≤ y)，F_Y⁻¹(τ) := inf{y ∈ ℝ : F_Y(y) ≥ τ}

其中 F_Y(y) 给出 Y 不超过 y 的概率，F_Y⁻¹(τ) 给出低于该阈值的结果占比为 τ 的阈值。分位数在预测中尤为重要，因为它们可直接导出预测区间。在名义水平 1−α 下，若 F_Y 连续，则区间 [F_Y⁻¹(α/2), F_Y⁻¹(1−α/2)] 在真实分布下将以概率 1−α 包含实际结果。

因此，概率预测的目标是为每个上下文 x 估计未来值的条件预测分布。在本工作中，我们关注相应的逐视界边缘预测CDF F̂(Y_h|X=x)，h = 1, …, H，将其作为下文所考虑的各类TSFM家族均可获取的共同概率对象。然而，这些预测CDF的表示机制在不同模型之间存在显著差异。

预测中的不确定性校准。 若概率预测所声明的概率与经验频率相一致，则称该预测是校准的（Gneiting 等，2007；Gruber 与 Buettner，2022）。在概率回归中，一个标准概念是概率校准（Kuleshov 等，2018；Dheur 与 Taieb，2023），它要求预测分位数在所有预测实例上平均达到所标称的覆盖率。对于单步预测和分位数水平 τ ∈ (0,1)，这可以写成：

(1/N) ∑ₙ₌₁ᴺ 1{Yₙ ≤ F̂⁻¹(Y|X=xₙ)(τ)} ≈ τ

也就是说，在 N 个预测实例中，落在预测的 τ 分位数之下的观测结果所占比例应接近 τ。在有限分位数水平集合 T ⊂ (0,1) 上对该恒等式偏差取平均，即得到概率校准误差（PCE）（Dheur 与 Taieb，2023）：

PCE = (1/|T|) ∑_{τ∈T} |(1/N) ∑ₙ₌₁ᴺ 1{Yₙ ≤ F̂⁻¹(Y|X=xₙ)(τ)} − τ|

在多步预测中，每次预测会产生 H 个预测步骤，校准情况可以以不同方式跨视界进行汇总。Adler 等（2026）将所有视界-实例对合并为单一集合，从而得到覆盖整个测试集的全局校准度量。这提供了一种有用的聚合视角，但它可能掩盖不同视界或其他实例子集之间的系统性差异。特别地，一个模型在池化平均覆盖率下可能显得校准良好，但在其预测分布的特定区域仍存在结构化失准。

这一局限性与校准的平均概念和条件概念之间的区别密切相关（Gneiting 等，2007；Gneiting 与 Resin，2023）。概率校准仅要求覆盖率在所有实例上平均成立，因此某些区域的过度自信可以被其他区域的自信不足所抵消。更强的条件化概念则追问：在给定模型自身预测水平的情况下，预测概率是否仍然可靠，而不仅仅是在对所有预测取平均之后。我们的工作正是基于这一视角，在比池化平均覆盖率更细的粒度上研究TSFMs的校准问题。

后处理重校准。 当预测不确定性失准时，一个实际问题是能否在不重训练预测模型的情况下加以纠正。后处理重校准通过在留出数据上学习一个轻量级修正并在训练后应用来解决这个问题。此类方法对TSFMs尤其具有吸引力，因为TSFMs规模庞大、经过预训练，且常以零样本方式使用。常见方法包括保序重校准（Kuleshov 等，2018）、Platt式缩放（Platt 等，1999）、基于分布的重校准方法（Song 等，2019）以及基于核密度估计（KDE）的方法（Dheur 与 Taieb，2023）。尽管这些方法在回归场景中已展现出强劲的实证表现（Dheur 与 Taieb，2023），但它们在TSFMs上的适用性与局限性在很大程度上仍未被探索。

3 概率TSFMs的统一分类体系

概率TSFMs不仅在架构和预训练数据上存在差异，在用于表示预测不确定性的预测对象上也各不相同。为了在如此异构的模型之间比较校准水平，我们首先引入一个统一视角。它们的共同点在于：对于每个预测视界步骤 h = 1, …, H，每个模型最终都给出边缘预测CDF F̂(Y_h|X=x) 的一个估计。关键区别在于获得该CDF所依赖的中间表示，以及用于学习它的训练目标。基于这一视角，我们区分出四个概念上不同的类别。

类别1：参数密度模型。 在此类别中，TSFMs通过显式参数族表示预测不确定性。对于每个视界步骤 h，模型预测条件密度的参数 θ̂_h，即 p̂(Y_h|X=x)(y) = p(y; θ̂_h)。预测CDF随后通过积分获得：

F̂(Y_h|X=x)(y) = ∫₋∞^y p(z; θ̂_h) dz

对于自回归输出头，较远视界的边缘分布通过采样获得，未必仍属于该参数族。此类别的训练自然基于负对数似然。在推理时，对于简单的分布族，分位数和预测区间或许可以解析获得，但实践中通常通过数值方法或采样获得。例如，Lag-Llama（Rasul 等，2023）采用Student-t输出头，MOIRAI 1.x 与 MOIRAI-MoE（Woo 等，2024；Liu 等，2024）使用混合分布头，Toto 1.0（Cohen 等，2025）使用Student-t混合头，均采用此机制。

类别2：离散化分布模型。 在此类别中，TSFMs在实值轴的有限离散化上表示预测不确定性。设 b₀ < b₁ < ⋯ < b_K 为 ℝ 中的分箱边界。对于每个视界步骤 h，该类别中的模型预测概率：

p̂{h,k} = P̂(Y_h ∈ (b{k−1}, b_k] | X = x)，k = 1, …, K

Chronos-T5（Ansari 等，2024a）采用此机制，它将数值量化为词元并自回归地预测词元概率；TabPFN-TS（Hoo 等，2025）也采用此机制，其条形分布将预测质量分配到固定区间上。

对于基于词元的模型，预测CDF随后通过在离散化支撑上的累加形成，得到阶梯状近似：

F̂(Y_h|X=x)(y) = ∑{k: b_k ≤ y} p̂{h,k}

对于条形分布，假设质量在每个箱内均匀分布，因此CDF不是阶梯状，而是在每个箱内线性递增。训练通常采用交叉熵，等价于在所诱导表示下的离散化对数似然。在推理时，分位数通过CDF的直接求逆获得，而自回归的基于词元的变体则通过从每一步的分类分布中采样来生成预测值。

类别3：直接分位数预测器。 在此类别中，TSFMs直接在预先设定的有限概率水平集合 τ₁, …, τ_M ∈ (0,1) 上预测逆CDF的值。对于每个视界步骤 h，模型输出 F̂⁻¹(Y_h|X=x)(τ₁), …, F̂⁻¹(Y_h|X=x)(τ_M)。因此，模型被训练为直接估计逆CDF上的若干选定点，而非结果空间上的完整密度或CDF。标准训练目标是弹球损失或其加权变体（Chung 等，2021）。在推理时，不确定性通常仅在所选分位数水平上可得，因此其分辨率受限于训练时使用的分位数网格，尽管部分模型额外提供了连续分位数头。这是许多近期模型采用的流行方法，例如 Chronos-Bolt（Ansari 等，2024b）、Chronos-2（Ansari 等，2025）、MOIRAI 2.0（Liu 等，2025a）、TiRex（Auer 等，2025）、TimesFM（Das 等，2024）、KAIROS（Feng 等，2025）、FlowState（Graf 等，2026）和 YINGLONG（Wang 等，2025）。

类别4：隐式生成过程模型。 该类别的定义性特征是：预测不确定性以隐式方式表示，只能通过采样来获取。相应的TSFMs学习针对整条预测轨迹 ŷ⁽¹⁾, …, ŷ⁽ˢ⁾（ŷ⁽ˢ⁾ ∈ ℝ^H）的生成过程，这些轨迹作为来自整个视界上隐式联合预测分布的样本而产生。逐视界预测CDF随后通过经验方式估计：

F̂(Y_h|X=x)(y) = (1/S) ∑ₛ₌₁ˢ 1{ŷ⁽ˢ⁾_h ≤ y}

例如，Sundial（Liu 等，2025b）通过流匹配（Lipman 等，2023）学习条件生成传输过程，TimeDiT（Cao 等，2024）使用基于扩散的去噪目标（Ho 等，2020）生成轨迹，二者均采用此机制。在这两种情况下，分位数和预测区间都需要从采样路径的经验分布中计算，而非来自显式的概率输出。

该分类体系按照获得逐视界CDF所依赖的中间预测对象对TSFMs加以区分，表1对此进行了总结。这一区分对校准分析至关重要，因为它阐明了预测分布的哪些方面可直接用于评估，以及哪些校准诊断方法和后处理修正方法可以自然地适用。

4 面向概率TSFMs的校准评估框架

我们现在引入一个专为概率TSFMs量身定制的校准评估框架。其目标是以既能在第3节的异构输出类型之间进行比较、又对多步预测足够细粒化的方式来评估不确定性估计。为此，我们首先将概率校准评估细化以适应多步设置，然后转向更强的条件化校准概念，以刻画不确定性估计在单个预测层面上是否同样可信。在整个过程中，我们固定一个有限的分位数水平集合 T = {τ₁, …, τ_Q} ⊂ (0,1)，并记 q̂_{h,τ_q} := F̂⁻¹(Y_h|X)(τ_q) 为网格水平上的预测分位数。

多步概率校准。 第2节中概率校准误差的一个自然扩展是将所有视界-实例对合并，并在整个测试集上比较经验频率与名义分位数水平。遵循 Adler 等（2026），我们定义：

PCE_pool = (1/Q) ∑{q=1}^Q |(1/H) ∑{h=1}^H P(Y_h ≤ q̂_{h,τ_q}) − τ_q|

这提供了一个简洁的全局汇总，但它可能隐藏预测步骤之间的系统性差异，因为不同视界上的过度覆盖与覆盖不足在合并后可能相互抵消。为避免这一问题，我们在每个视界上分别评估校准，并通过均值和最大值汇总所得误差。对于 h = 1, …, H，我们定义：

PCE_h = (1/Q) ∑{q=1}^Q |P(Y_h ≤ q̂{h,τ_q}) − τ_q|

使得 PCE_avg = (1/H) ∑{h=1}^H PCE_h 汇总视界上的典型误差，而 PCE_max = max{h=1,…,H} PCE_h 则识别出最差的预测步骤。

分位数条件化校准。 即使概率校准误差很小，模型仍可能以更结构化的方式不可靠。其预测区间对于某些预测分位数值可能过窄，而对另一些则过宽，这些效应在总体上相互抵消。为捕捉此类值依赖的失真，我们考虑更强的分位数条件化校准概念（Gneiting 与 Resin，2023），它要求校准在以模型自身预测的分位数值为条件时依然成立。

定义4.1（分位数条件化校准）。对于实值结果 Y 的预测CDF F̂，若对所有 τ ∈ (0,1)，几乎必然地有 P(Y ≤ F̂⁻¹(τ) | F̂⁻¹(τ)) = τ，则称该预测CDF是分位数条件化校准的。

换言之，在模型预测出相似 τ 分位数值的所有实例中，实际结果应当有 τ 比例的时间落在该值之下。对于连续的预测CDF，这就是 Gneiting 与 Resin（2023）中讨论的条件超越概率（CEP）校准。

这一概念比平均概率校准更强，因为它以模型输出本身为条件，而非对所有预测取平均。同时，它仍可通过非参数估计在实践中逼近（见附录B.3），这使其即便比平均覆盖率更难估计，仍可作为有用的诊断工具。我们随后定义：

QCE_h = (1/Q) ∑{q=1}^Q E[|P(Y_h ≤ q̂{h,τ_q} | q̂_{h,τ_q}) − τ_q|]，h = 1, …, H

并同样通过 QCE_avg = (1/H) ∑{h=1}^H QCE_h、QCE_max = max{h=1,…,H} QCE_h 进行汇总。

因此，QCE_avg 和 QCE_max 是PCE的视界感知对应指标，基于更强的校准要求，但仍可在实践中估计。这对TSFMs尤为重要，因为 PCE_avg 相近的模型，其不确定性估计在不同类型预测上的可靠性仍可能存在巨大差异。我们通过保序回归来估计该指标，其总体目标构成 QCE_h 的下界，且当条件覆盖非递减时取等号（见附录B.3）。

校准误差的层级。 上述引入的度量形成了一种自然的排序，可由以下命题表达：

命题4.2。对于任意预测模型和任意有限分位数网格 T：

PCE_pool ≤ PCE_avg ≤ QCE_avg ≤ QCE_max

该命题阐明了各度量的角色。PCE_pool 是最弱的汇总，因为它一次性对所有视界和实例进行聚合。PCE_avg 更严格，因为它在聚合之前对每个视界分别评估。QCE_avg 更进一步，它评估校准在以模型自身预测的分位数值为条件时是否依然成立。最后，QCE_max 为它们提供上界，并在此处考虑的最强概念下突出校准最差的预测视界。

定义4.3（视界差距与条件化差距）。我们将视界差距 Δ_H 和条件化差距 Δ_C 定义为额外的诊断指标：

Δ_H := PCE_avg − PCE_pool ≥ 0，Δ_C := QCE_avg − PCE_avg ≥ 0

视界差距 Δ_H 度量跨视界合并所隐藏的校准误差。较大的值表明可靠性在不同预测步骤之间存在显著差异，即便池化汇总看起来可以接受。条件化差距 Δ_C 度量一旦以模型自身预测的分位数值为条件，会显现出多少额外误差。因此，较大的条件化差距指向在仅看平均覆盖率时不可见的结构化值依赖失准。这些诊断指标共同帮助区分视界特定效应与更深层的条件化不可靠性，在解读后处理重校准结果时同样有用。由于二者的有限样本估计即使在没有此类结构时也为正值，我们为其配备了显著性检验（见附录B.4）。

对后处理重校准的启示。 所提出的评估框架不仅可用于评估TSFMs开箱即用的校准程度，还可用于分析后处理修正能够改进哪些类型的失准。分位数重标记方法（Dheur 与 Taieb，2023）对概率TSFMs尤其具有吸引力，因为这类方法保持了预测结果的支撑集和排序，仅通过重新分配概率质量来改进校准。这使其十分轻量，且不改变预训练模型本身。形式上，此类方法从少量留出校准数据中估计一个单调映射 g: [0,1] → [0,1]，并重新定义：

F̂⁻¹,ᵍ(Y_h|X)(τ) := F̂⁻¹(Y_h|X)(g(τ))

对于仅在有限网格上输出分位数的模型，F̂⁻¹(Y_h|X) 在网格水平之间进行插值。

为了理解此类重校准如何与我们的诊断框架相互作用，我们刻画了单一全局重标记映射能够与不能够解决哪些形式的失准。

定理4.4。设 g: [0,1] → [0,1] 为任意重标记映射，并设 PCEᵍ_pool、PCEᵍ_avg 和 QCEᵍ_avg 表示用 g 重校准之后的相应校准误差。则以下结论成立： 若池化覆盖率 p̄(t) := (1/H) ∑_{h=1}^H P(Y_h ≤ F̂⁻¹(Y_h|X)(t)) 关于 t 连续，则存在非递减映射 g 使得 PCEᵍ_pool = 0。 对于任意 g，PCEᵍ_avg ≥ Δ_H/2，其中 Δ_H 是原始预测的视界差距。特别地，若原始预测存在非零视界差距 Δ_H > 0，则对每个 g 都有 PCEᵍ_avg > 0，包括任何满足 PCEᵍ_pool = 0 的 g。 对于任意 ε ∈ (0, 1/2)，存在一个池化覆盖率 p̄ 连续的预测设置，其中每个满足 PCEᵍ_pool = 0 的 g 都有 QCEᵍ_avg − QCE_avg > ε。

该定理凸显了基于全局重标记的重校准方法的关键局限。原则上，重标记能够完全消除池化概率校准误差——保序重校准通过估计池化覆盖率曲线来逼近这一映射。然而，这只是我们层级中最弱的概念。如果失准在不同视界间存在差异，那么任何全局重标记都无法同时消除各视界的误差。在每个分位数水平上，该映射会将所有视界的覆盖率朝同一方向移动，因此它只能通过加剧其他视界的覆盖不足来缓解某些视界的过度覆盖。部分表明视界差距的一半是 PCE_avg 的一个下界，任何全局重标记都无法突破。此外，在池化覆盖率下的成功并不意味着在更强的分位数条件化概念下也有所改善。部分表明，存在这样的设置：每个能消除池化误差的映射都会使 QCE_avg 增加近 1/2。这进一步论证了所提出的层级化方法对评估概率TSFMs重校准的必要性，因为仅凭池化汇总可能高估不确定性估计真正得到改善的程度。所有证明及其背后的直觉见附录A。

5 实验

设置。 我们现在将所提出的校准框架应用于一项全面的实证基准测试。我们评估了14个零样本概率TSFMs，涵盖第3节中的全部四个不确定性量化类别：五个参数密度模型、三个离散化分布模型、五个直接分位数模型和一个隐式生成模型。此处"零样本"指没有任何模型在所评估的数据集上进行过微调。每个模型都在GIFT-Eval基准（Aksu 等，2024）的55个数据集配置上完成短期预测任务测试，这些配置覆盖了多样的领域和采样频率。重校准实验额外要求每个数据集至少有50个预测窗口，从而剩下42个配置。为确保各类模型之间的可比性，所有校准度量都在共同分位数网格 T = {0.1, 0.2, …, 0.9} 上计算。对于不直接提供这些分位数的模型，则从相应的预测分布或经验样本中提取。分位数条件化校准误差通过覆盖指示变量对预测分位数值的保序回归进行非参数估计，并且我们对每个至少包含两条序列的模型-数据集对检验两个诊断差距的显著性。完整的实现细节见附录B，配套代码可在 https://github.com/thomdeck/tsfm-calibration 获取。

6 讨论与结论

我们提出了一个面向概率TSFMs的校准评估框架，它超越了池化平均覆盖率，能够对多步预测中的不确定性可靠性进行更细粒度的诊断。我们的结果表明，标准池化度量会通过掩盖预测步骤间的差异以及额外的值依赖误差，系统性地低估失准程度。在14个模型和55个数据集上，我们发现此类失准在当前TSFMs中普遍存在，无论预测不确定性以何种方式表示。我们进一步研究了后处理重校准这一轻量级的实用补救手段。我们的分析与实验均表明，标准重校准方法能够显著改善较弱的平均校准概念，即便仅在历史数据上拟合时也是如此；但它们在消除更强的条件化缺陷方面效果有限。本研究的主要局限在于其范围：我们仅关注逐视界的边缘校准和简单的后处理重校准方法。此外，我们对分位数条件化校准的保序估计是保守的，且结果中的点质量可能使覆盖率误差膨胀。将分析扩展到跨时间的联合预测校准（Allen 等，2024）、以预测视界或预测本身为条件的更具表达力的重校准方法（Song 等，2019；Kuleshov 与 Deshpande，2022），以及训练阶段改善校准的方法（Dheur 与 Taieb，2024），是未来工作的有前景方向。总体而言，我们希望此处引入的框架有助于使校准评估成为实践中评估概率TSFMs时更标准、更具信息量的组成部分。

附录A 理论结果

本附录证明校准层级（命题4.2）与全局重标记的局限（定理4.4），并刻画保序估计量的总体目标（引理A.1）。所有论证基于两个基本观察。第一，平均值的绝对值不超过绝对值的平均，其差度量正负项相互抵消的程度。层级的每一步都是这一原理的实例，应用于跨视界或跨预测值的抵消。第二，单一重标记映射在给定水平上将每个视界和每个预测的预测分位数朝同一方向移动。因此它可以消除所有视界和预测共有的误差，但不能消除它们之间不同的误差。

记号。 对于水平 t ∈ [0,1]，设 q̂{h,t} := F̂⁻¹(Y_h|X)(t) 表示视界 h 处的预测 t 分位数，约定 q̂{h,0} = −∞、q̂_{h,1} = +∞。两个核心量是视界 h 处的覆盖率和池化覆盖率：

p_h(t) := P(Y_h ≤ q̂{h,t})，p̄(t) := (1/H) ∑{h=1}^H p_h(t)

由于预测分位数关于 t 非递减，p_h 和 p̄ 亦然，且在 t = 0 处取值 0、t = 1 处取值 1。在网格水平 τ_q 处，我们记 r_{h,q} := p_h(τ_q) − τ_q（视界 h 的带符号覆盖率误差，过度覆盖为正，覆盖不足为负）以及 C_{h,q} := P(Y_h ≤ q̂{h,τ_q} | q̂{h,τ_q})（给定预测值的条件覆盖率）。在此记号下，第4节的校准误差为：

PCE_pool = (1/Q) ∑{q=1}^Q |(1/H) ∑{h=1}^H r_{h,q}|，PCE_avg = (1/QH) ∑{q=1}^Q ∑{h=1}^H |r_{h,q}|，QCE_avg = (1/QH) ∑{q=1}^Q ∑{h=1}^H E|C_{h,q} − τ_q|

用映射 g 进行重校准将 q̂{h,τ} 替换为 q̂{h,g(τ)} 并保持名义水平 τ。因此重校准后的误差通过在 g(τ_q) 而非 τ_q 处评估覆盖率得到，QCEᵍ_avg 用条件覆盖率 Cᵍ_{h,q} := P(Y_h ≤ q̂{h,g(τ_q)} | q̂{h,g(τ_q)}) 类似定义。

A.1 校准误差层级的证明

直觉。 链条的每一步都消除了一种误差抵消的机会。PCE_pool 先对视界取带符号误差的平均再取绝对值，因此一个视界的过度覆盖可以抵消另一个视界的覆盖不足。PCE_avg 对每个视界分别取绝对值，排除了这种抵消，但仍对一个视界的所有预测取平均。QCE_avg 进一步以预测值为条件，从而也排除了不同预测值的预测之间的抵消。QCE_max 最终用最差视界取代对视界的平均。

命题4.2的证明。 我们依次验证三个不等式。

跨视界池化。 由三角不等式，在每个水平处 |(1/H) ∑h r{h,q}| ≤ (1/H) ∑h |r{h,q}|，对 q 取平均即得 PCE_pool ≤ PCE_avg。

以预测值为条件。 由塔性质，条件覆盖率平均后等于边缘覆盖率，E[C_{h,q}] = p_h(τ_q)。因此对凸函数 x ↦ |x − τ_q| 的Jensen不等式给出 |r_{h,q}| = |E[C_{h,q}] − τ_q| ≤ E|C_{h,q} − τ_q|，对 q 和 h 取平均即得 PCE_avg ≤ QCE_avg。

视界的均值不超过其最大值，故 QCE_avg ≤ QCE_max。∎

同样的链条对估计量成立。 附录B.3的估计量在每个样本上精确满足该层级，因此两个估计差距均非负。第一步和最后一步用经验覆盖率 p̂_h 代替 p_h 后逐字成立。对于中间一步，保序拟合为每块连续预测分配其覆盖指示变量的均值，因此拟合值平均后等于经验覆盖率 p̂_h(τ_q)。这是塔性质的经验对应，Jensen不等式对经验分布同样适用。

A.2 分位数重标记局限的证明

我们分别证明定理4.4的三个部分，并在每个证明前给出其主要思想。

部分：池化校准总可恢复。 要使名义水平 τ 处的池化覆盖率等于 τ，只需找到一个使池化覆盖率等于 τ 的模型水平 t，并将 τ 重标记为 t。由于 p̄ 从 0 变到 1，只要 p̄ 没有跳跃，这样的水平就存在，广义逆选取其中最小者。保序重校准通过在校准数据上估计 p̄ 来实现这一思想。

定理4.4的证明。 我们首先将 g 定义为 p̄ 的广义逆。对 τ ∈ (0,1)，令 g(τ) := p̄⁻¹(τ) = inf{t ∈ [0,1] : p̄(t) ≥ τ}，并设 g(0) = 0、g(1) = 1。固定 τ ∈ (0,1) 并记 t := g(τ)。集合 {t : p̄(t) ≥ τ} 包含 1 且因 p̄ 连续而是闭集，故 p̄(t) ≥ τ。由于 p̄(0) = 0 < τ，有 t > 0 且对所有 t < t 有 p̄(t) < τ；令 t ↑ t，由连续性得 p̄(t) ≤ τ。因此 p̄(g(τ_q)) = τ_q 对每个网格水平成立，从而 PCEᵍ_pool = 0。此外，由于该集合随 τ 增大而缩小，g 非递减，因此重校准后的分位数 q̂_{h,g*(τ)} 保持关于 τ 有序。∎

p̄ 的连续性仅在这一部分需要，用于精确求解 p̄(t) = τ_q。如果 p̄ 跳过某个目标水平（例如对于含点质量或并列分位数的预测分布），则没有确定性重标记能在该水平达到精确的池化覆盖率。对于仅输出分位数的模型，该陈述指的是在网格水平之间插值的分位数函数所对应的预测。另一种做法是保持预测值不变而仅重标记其名义水平为 p̄(τ_q)，即实验中使用的形式（见下文）。此时无需任何连续性假设池化误差即为零，但水平不再是所请求的水平。部分和在没有该假设的情况下成立。

部分：跨视界的抵消无法消除。 在给定水平上，全局映射为所有视界选择同一个模型水平 t。提高 t 会提高每个视界的覆盖率，降低 t 则降低所有视界的覆盖率。如果某些视界过度覆盖而另一些覆盖不足，那么任何此类移动都只能以牺牲另一组为代价使一组更接近名义水平，或者保持不变。视界差距恰好度量同一水平上过度覆盖与覆盖不足并存的程度，由此得到下界。

定理4.4的证明。 对每个水平，收集跨视界的总过度覆盖和覆盖不足：S⁺q := ∑_h max(r{h,q}, 0)，S⁻q := ∑_h max(−r{h,q}, 0)。

第一步：视界差距度量抵消。 由于 ∑h |r{h,q}| = S⁺q + S⁻_q，|∑_h r{h,q}| = |S⁺q − S⁻_q|，以及 a + b − |a − b| = 2·min(a, b)，可得 Δ_H = PCE_avg − PCE_pool = (2/QH) ∑{q=1}^Q min(S⁺_q, S⁻_q)。因此 Δ_H 是被其他视界覆盖不足所抵消的过度覆盖量的两倍，并在水平上取平均。

第二步：全局映射无法同时纠正两侧。 固定任意映射 g 和水平 q，令 t := g(τ_q)。由于每个 p_h 非递减，t ≥ τ_q 时对所有 h 有 p_h(t) − τ_q ≥ r_{h,q}；t ≤ τ_q 时对所有 h 有 p_h(t) − τ_q ≤ r_{h,q}。在第一种情形，每个过度覆盖的视界仍至少过度覆盖 r_{h,q}，故 ∑h |p_h(t) − τ_q| ≥ S⁺_q。在第二种情形，每个覆盖不足的视界仍至少覆盖不足 |r{h,q}|，故 ∑_h |p_h(t) − τ_q| ≥ S⁻_q。两种情形下均有 ∑_h |p_h(g(τ_q)) − τ_q| ≥ min(S⁺_q, S⁻_q)。

第三步：取平均。 除以 QH、对 q 求和并利用 (∗) 得 PCEᵍ_avg ≥ Δ_H/2。

最优性。 设 H = 2、Q = 1、τ₁ = 1/2、a ∈ (0, 1/4)。取均匀预测分布 q̂{h,t} = t，以及 [0,1] 上具有连续CDF c_h 的结果 Y_h，从而 p_h = c_h。令 c₁ 分段线性插值 (0,0), (1/2, 1/2+a), (1/2+a, 1/2+a), (1,1)，c₂ 插值 (0,0), (1/2, 1/2−a), (1/2+a, 1/2), (1,1)。则 r{1,1} = a、r_{2,1} = −a，由 (∗) 得 Δ_H = a。重标记为 g(1/2) = 1/2+a 使第二个视界精确校准，而第一个视界的覆盖率在 [1/2, 1/2+a] 上平坦，其误差保持为 a。因此 PCEᵍ_avg = (1/2)(a + 0) = Δ_H/2，下界可以取到。∎

实验中使用的前向重标记。 在实验中，重校准后的预测以另一种形式表示：保持预测值 q̂{h,τ_q} 不变，并赋予所有视界共享的新名义水平 ℓ_q，误差为 (1/QH) ∑{q,h} |p_h(τ_q) − ℓ_q|。这避免了对稀疏分位数网格求逆，但其在有限网格上的平均未必与变换后分位数 q̂{h,g(τ_q)} 的平均一致。部分的界对这一形式同样成立，论证方式相同，只是两种情形的角色互换。若 ℓ_q ≥ τ_q，每个覆盖不足的视界至少贡献 |r{h,q}|；否则每个过度覆盖的视界至少贡献 r_{h,q}。由于该论证适用于任何分布（包括测试集的经验分布），该界在每个样本上也精确成立。

部分：恢复池化覆盖率可能暴露条件误差。 分位数条件化校准以预测分位数为条件。如果所有预测都给出相同的分位数，则以其为条件不产生任何影响，QCE 退化为边缘误差。该构造正是利用了这一点。两个机制预测相同的中位数，因此它们截然不同的校准情况在重校准之前不可见。任何恢复池化覆盖率的映射必须移动到两个机制预测不同分位数的水平。重标记后的分位数于是揭示了机制，QCE 便暴露出模型在一个机制中过度覆盖、在另一个机制中覆盖不足。重校准因此在消除池化误差的同时，使条件误差几乎达到最大可能。

定理4.4的证明。 固定 ε ∈ (0, 1/2) 和 η ∈ (0, 1/2 − ε)。设 H = Q = 1、τ₁ = 1/2，潜在机制 X 在 {A, B} 上均匀分布。表4给出了预测分布、其分位数函数 q_x、结果分布以及由此得到的机制内覆盖率 c_x(t) := P(Y ≤ q_x(t) | X = x)。两个覆盖率均连续，故 p̄ = (1/2)(c_A + c_B) 连续。

表4：定理4.4的构造。两个机制都预测中位数 q_A(1/2) = q_B(1/2) = 0，但模型在机制 A 中过度覆盖，在机制 B 中覆盖不足。

第一步：重校准之前，两个机制不可区分。 两个机制都预测中位数 q_A(1/2) = q_B(1/2) = 0。因此预测中位数为常数，其条件覆盖率等于边缘覆盖率 (1/2)(c_A(1/2) + c_B(1/2)) = (1/2)(1 + 2η)，且 PCE_pool = QCE_avg = η。

第二步：恢复池化覆盖率迫使选择区分机制的水平。 池化覆盖率满足：在 [0, 1/4) 上 p̄(t) = 2t < 1/2；在 [1/4, 3/8] 上 p̄ = 1/2；超过该区间后 p̄ > 1/2。因此 PCEᵍ_pool = |p̄(g(1/2)) − 1/2| = 0 当且仅当 t := g(1/2) ∈ [1/4, 3/8]，部分的映射给出 t = 1/4。对每个这样的 t，重标记后的中位数 q_A(t) = 4t−2 与 q_B(t) = 2t−1 不同，因为 t ≠ 1/2。

第三步：重标记后的中位数揭示机制。 在重标记后中位数的条件下，机制是已知的，条件覆盖率在 A 下为 c_A(t) = 1，在 B 下为 c_B(t) = 0。因此对每个满足 PCEᵍ_pool = 0 的 g，QCEᵍ_avg = (1/2)|1 − 1/2| + (1/2)|0 − 1/2| = 1/2，增加量为 1/2 − η > ε。∎

A.3 保序估计量的总体目标

附录B.3的保序估计量并不直接以条件覆盖率曲线为目标，而是以其最佳非递减逼近为目标。该逼近将相邻的预测值合并为块，并在每块内平均条件覆盖率。平均只能将值拉向其均值，因此所得误差介于边缘误差与完全条件误差之间。如果条件覆盖率已经非递减，则无需合并，目标等于 QCE_h。

引理A.1。固定 h 和 q，记 Z := q̂_{h,τ_q}、c(z) := P(Y_h ≤ Z | Z = z)，并设 c↑ 为 c 在非递减函数空间上的 L²(P_Z) 投影，即附录B.3中保序拟合的总体对应物。则 |p_h(τ_q) − τ_q| ≤ E|c↑(Z) − τ_q| ≤ E|c(Z) − τ_q| = QCE_h(τ_q)，且当 c 非递减时右侧取等号。

证明。 保序投影是 c 在其自身水平集上的条件期望 [8, 38]：E[c(Z) | c↑(Z)] = c↑(Z) 几乎必然。取期望得 E[c↑(Z)] = E[c(Z)] = p_h(τ_q)，左不等式即Jensen不等式。右不等式是条件Jensen不等式 |c↑(Z) − τ_q| = |E[c(Z) − τ_q | c↑(Z)]| ≤ E[|c(Z) − τ_q| | c↑(Z)]，再取期望。若 c 非递减，则 c↑ = c，等号成立。∎

下界可以是严格的。设 Z 以各 1/2 的概率取值 −1 和 0，在水平 τ_q = 1/2 处条件覆盖率为 c(−1) = 1、c(0) = 0。则 QCE_h(τ_q) = 1/2，而投影将两个值合并为常数 1/2，故保序目标为零，与边缘误差相同。因此该诊断检测的是覆盖率随预测值增加而增加的值依赖性。这正是预测在两个方向上都过于极端的模式，主导了我们的案例研究（附录C.2），而递减或非单调的模式可能被遗漏。
