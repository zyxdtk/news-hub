GPT-6.1 Sol 发布：近 Astra 智能

📅 2026-09-22 📄 OpenAI 🔗 原文链接

原标题：Introducing GPT-6.1 SolMeet GPT-6.1 Sol: near-Astra intelligence for coding, computer use, and professional work at one-fifth of Astra’s standard API input and output token prices.

中文摘要： OpenAI 发布 GPT-6.1 Sol，为 GPT-6 Sol 的升级版，在智能体编程、计算机使用和专业工作方面接近 GPT-6 Astra 的智能水平，价格仅为其五分之一，缓存输入每百万 token 低至 0.10 美元。该模型在 DeepSWE、GDP.pdf、AutomationBench、OSWorld 等评测中表现优异，事实准确性与安全对齐也显著提升，现已向 ChatGPT Work、Codex 用户及 API 开发者开放，并将推出速度提升 8 倍的 Ultrafast 版本。

GPT-6.1 Sol
以五分之一的价格获得接近 Astra 的智能

我们推出 GPT-6.1 Sol，这是 GPT-6 Sol 的升级版本，在智能体编程、计算机使用和专业工作方面几乎媲美 GPT-6 Astra 的智能水平，而价格仅为 Astra 标准输入和输出 token 价格的五分之一。缓存输入的价格仅为每百万 token 0.10 美元——比标准输入定价低 95%，比 GPT-6 Sol 的缓存输入定价低 50%——为开发者构建和运行能够跨请求复用上下文的强大智能体留出了更大空间。

全面更强的 Sol

GPT-6.1 Sol 为重要的日常工作提供了能力与成本的新平衡。在从编写和调试代码到理解文档、执行多步骤业务流程等各类复杂专业任务中，它相比 GPT-6 Sol 均有显著提升。在其中多项评测中，它以大幅降低的成本逼近 GPT-6 Astra 的表现。

编程

在 DeepSWE v1.1（一项在真实代码库中评估复杂软件工程任务的评测）上，GPT-6.1 Sol 以约五分之一的成本追平 GPT-6 Astra，同时以更低的推理投入和成本超越 GPT-6 Sol 的最佳得分 6.4 个百分点。

在 DeepSWE 1.1（在新窗口中打开）中，AI 智能体需要解决原创的长期软件工程任务。

专业工作

在 GDP.pdf（一项衡量模型利用复杂 PDF 文档——包括表格、图表、示意图和细则细节——回答专业问题准确度的评测）上，在所有测试的推理设置下，GPT-6.1 Sol 的得分均高于带回退机制的 Opus 5.5，且每项任务的成本不到其一半。它还以约五分之一的每任务成本逼近 GPT-6 Astra 的最先进表现。

在 GDP.pdf（在新窗口中打开）中，模型必须回答与复杂 PDF 相关的真实提示，这些 PDF 来自金融、医疗、法律及其他七个专业领域的专业工作流。

在 AutomationBench（一项衡量智能体能否正确完成多步骤业务工作流的评测）上，GPT-6.1 Sol 在中等推理投入下的得分比 Opus 5.5 高 2.2 个百分点，而成本仅约为其三分之一。在同一设置下，该得分也比 GPT-6 Sol 提高了 4.8 个百分点。

在 AutomationBench 1.0.6（在新窗口中打开）中，AI 智能体需要使用涵盖销售、市场营销、运营、客户支持、财务和人力资源领域的 47 种工具完成端到端工作流。Claude Fable 5.1 的数据点低估了其实际成本，因为该数据未计入回退的成本，而回退在约 40% 的任务中发生。

计算机使用

GPT-6.1 Sol 在需要与计算机应用程序交互的任务上也取得了显著进展。在 OSWorld 2.0 的离线集（一项在高难度计算机使用工作流上评估智能体的评测）上，GPT-6.1 Sol 在最大推理投入下以不到一半的成本超越 GPT-6 Sol 七个百分点。在最大推理投入下，它与 Astra 的得分仅相差 2.1 个百分点，而每项任务的成本仅约为其七分之一。

在 OSWorld 2.0（在新窗口中打开）中，AI 智能体尝试完成涵盖日常和专业任务的长期计算机使用工作流。我们报告的是 v2026.08.08 版本离线集上的部分奖励。

科学研究

在 Terminal-Bench Science 0.1（一项评估包括数据分析、模拟和定理证明在内的科学工作流的评测）上，GPT-6.1 Sol 在最大推理投入下的得分达到 GPT-6 Sol 的两倍以上，而每项任务的成本不到其一半。在最大投入下，GPT-6.1 Sol 平均每项任务的成本为 5.47 美元，相比之下 Opus 5.5 为 23.21 美元，Astra 为 23.80 美元，以比这两个模型低 75% 以上的成本提供了强大的科学能力。

在测试的模型中，GPT-6 Astra 仍以 68.1% 的得分保持最高，最困难的科学研究任务应使用该模型。

在 Terminal-Bench Science 0.1（在新窗口中打开）中，智能体使用代码和终端工具完成科学研究工作流，包括分析数据、运行模拟和拟合模型。

事实准确性

GPT-6.1 Sol 还提高了在困难提示上的事实准确性。相比 GPT-6 Sol，其事实准确性的最大提升出现在低推理投入下：包含事实错误的回复比例从 11.4% 降至 7.7%，降幅约为 32%。在所有测试的推理设置中，其错误率与 GPT-6 Astra 的差距保持在 1.9 个百分点以内，而每项任务的成本不到其五分之一。

该评测衡量的是在用户标记了早期模型错误的去标识化对话中，包含至少一个事实错误的答案比例。这些刻意设置的困难提示并不代表典型使用场景。

我们在用户标记了先前模型事实错误的去标识化 ChatGPT 对话上评估事实准确性。这些引发错误的对话并不代表典型使用场景——在典型使用中，事实错误更为罕见。

安全部署 GPT-6.1 Sol

在我们的对齐评测中，GPT-6.1 Sol 相比 GPT-6 Sol 有显著改进，使其更接近 GPT-6 Astra。

GPT-6.1 Sol 对自身局限性更加透明，在尊重用户意图和安全约束方面更加可靠。在高难度评测中，它在搜索工具损坏时的透明度、遵守明确限制以及避免智能体任务中出现未经授权的结果等方面的失败率均低于 GPT-6 Sol。我们未观察到任何绕过自动化安全审查器的尝试，这一点与 GPT-6 Astra 和 GPT-6 Sol 一致。完整细节可在 GPT-6.1 Sol 系统卡附录（在新窗口中打开）中找到。

以下评测刻意测试了具有挑战性的情境，并不衡量典型使用中的失败率。

定价与可用性

GPT-6.1 Sol 从今天起向 ChatGPT Work 和 Codex 中的所有 Plus、Pro、Business、Enterprise 和 Edu 用户开放。GPT-6.1 Sol 尚未在 Chat 中提供。开发者也可以通过 OpenAI API 以 gpt-6.1-sol 的名称访问它。其标准 API 价格为：每百万输入 token 2 美元，每百万缓存输入 token 0.10 美元，每百万输出 token 10 美元。未来几天内，我们还将推出 GPT-6.1 Sol Ultrafast，其在 Codex 中的 token 生成速度最高可达标准速度的 8 倍。
