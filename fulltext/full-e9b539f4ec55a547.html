阿里Qwen4-Max降低任务成本，基准表现参差

📅 2026-11-18 📄 VentureBeat AI 🔗 原文链接

原标题：Alibaba’s Qwen4-Max cuts AI task costs, but benchmarks show an uneven challenge to frontier rivals

中文摘要： 阿里巴巴发布旗舰AI模型Qwen4-Max，支持文本、图像、视频输入及百万token上下文，以专有形式推出，未开放权重。其API定价低于Anthropic、OpenAI等主要对手，内部Work360评估显示任务平均成本下降约62%。但基准表现参差：编码智能体测试领先，终端任务与软件复刻明显落后，Artificial Analysis综合智能指数43分仍落后于领先模型。企业用户需针对具体工作负载验证其性价比。

太平洋时间2026年11月17日凌晨4:36

阿里巴巴为其最新旗舰AI模型提出了一个务实的卖点：企业应该能够花更少的钱完成更多的工作，即使该模型并不领先于整体智能排名。

该公司的 Qwen4-Max 发布公告介绍了一款接受文本、图像和视频输入、可与外部软件协作、并支持多达100万token上下文的模型。阿里巴巴表示，它在 Qwen3.8-Max 基础上有所改进，同时将其内部 Work360 评估中任务的平均成本从4.43美元降至1.67美元，降幅约62%。

Qwen4-Max 以专有模型形式发布，而非开源或开放权重版本。Artificial Analysis 将其归类为专有模型，阿里巴巴也未提供可供企业在自己基础设施上运行的可下载权重。客户可通过 QwenCloud API 访问，或在 Qwen Studio、QwenWork 和 Qoder 中使用。

对于一个以发布开发者可下载并改编的模型而闻名的模型家族而言，这是一个影响重大的区别。阿里巴巴的发布公告承诺将开放发布较小的 Qwen4 模型，但未给出日期或许可证，也未对 Max 作出同等承诺。截至发稿，我们未发现公开发布 Qwen4-Max 权重的承诺，也未发现其将永久封闭的明确声明。这款旗舰模型目前是专有的；已公布的开放模型路线图只涉及较小的版本。

该API每百万输入token收费1.50美元，每百万输出token收费4.50美元。这些费率低于 Anthropic、OpenAI 和 Google 的多款知名替代产品，尽管仅凭token价格并不能决定完成一项任务的成本。

性能图景则更为复杂。Qwen 的发布图表显示，该模型在若干专业和长时工作基准上取得有竞争力的结果，但在其他编码和视觉任务上存在明显差距。一项独立综合评估也将该模型排在领先的美国竞争对手和月之暗面（Moonshot AI）的 Kimi K3.1 Pro 之后。

对于企业买家而言，Qwen4-Max 提出的是一个针对特定工作负载的主张：潜在的有吸引力的经济性和实用的能力，但在准确性、速度和部署选项上存在重大差异。

更低的价格和更少的token支撑效率卖点

阿里巴巴的 Work360 框架将专业工作划分为26个大领域、182个子领域和721个专业方向，示例包括会计审查、制造分析、法律任务和文档制作。

Qwen4-Max 在该公司基准上得分52.69，而 Qwen3.8-Max 为47.74，提高4.95分，相对此前分数约提升10.4%。

阿里巴巴报告称，在 Work360 上，Xhigh 推理设置下token消耗下降约24%，High 设置下下降35%。在 Terminal-Bench 4.0 上，相应降幅接近48%和49%。

这些是不同的发现。约50%的token减少来自终端测试；62%的成本降低来自 Work360，同时反映了token用量和定价。两者都不能为客户工作负载确立一个普遍的节省率。

经济性改善也有独立证据。Artificial Analysis 的 Qwen4-Max 评估报告为每个 Intelligence Index 任务3.27美元；其对 Kimi K3.1 Pro 的评估报告为3.68美元，即 Qwen 在该指标上便宜约11%。这些数字来自与阿里巴巴1.67美元结果不同的测试套件，不应视为可互换。

Qwen 的输出费率比标准 Sol、Sonnet 和 introductory Carbon 使用所收取的$10低55%，比 Opus 5.5 低77.5%。其输入费率与 Hydrogen 持平，而输出成本低40%。

但 Qwen4-Max 并非所有应用中最便宜的选择。Anthropic 的费率表显示，Haiku 5.5 对不超过10万token的提示收取输入$0.10、输出$0.50，超过该阈值后升至$0.50和$2.50。买家仍需确定哪个模型能可靠完成其工作。

Qwen 还对显式缓存创建单独收费：五分钟缓存每百万token $1.875，一小时缓存$3，读取为$0.075。较低的缓存输入数字不应被套用到请求中的每个token上。

其单独的 Token Plan 订阅为新客户宣传低至$3的促销入门价。该订阅优惠以及单独列出的 qwen4-max-preview 折扣，不应与标准 qwen4-max API 定价混淆。

智能体基准显示优势——以及明显局限

智能体必须做的不仅是给出看似合理的回答。它需要操作工具、解读结果、修正方法，并交付可用的成果。Qwen 的发布对比测试了这一过程的多个环节，结果分化明显。

Qwen 在所展示的 DeepSWE 结果中略微领先，并在 APEX-Agents 上接近 Opus。它还在 Agents' Last Exam v1.1 上获得46.7分，其前代为27.9分，Opus 为43.4分。

然而，其 Terminal-Bench 结果大幅落后于 Kimi，ProgramBench 得分不到 Opus 的一半。评估自主软件维护系统的买家，不应以一项有利的编码分数替代该系统必须执行的各项操作的整体证据。

图表解读方面的差距对金融和文档分析工作流同样重要。

整体智能仍落后于领先者

Artificial Analysis 的发布图表将 Qwen4-Max 的 Intelligence Index 定为43分，高于 Qwen3.8-Max 的34分。Kimi K3.1 Pro 得46分；GPT-6.1 Sol 和 Claude Sonnet 5.5 得55分；Opus 5.5 达59分；Gemini 4 Carbon 得60分；Claude Fable 5.2 以65分领先这一展示组。

这些数字代表图表中显示的推理配置，不一定是各模型的默认设置。

这一综合图景对阿里巴巴精选任务结果的最强解读构成了限定。Qwen 可以在特定任务上紧咬对手，但在综合指标上仍明显落后。

它还有点慢：截至评测时，Artificial Analysis 的模型页面报告其每个 Intelligence Index 任务约需32分钟，首个答案token约需159秒，处于主要基础模型中较耗时的一端。

这些测量针对其高要求的评估工作负载和测试配置，并不代表它在每次响应中的表现。尽管如此，它们仍提醒人们不要把更低的成本等同于更快的交付。

多模态输入，但非原生媒体生成

QwenCloud 规格列出文本、图像和视频输入以及文本输出，不含音频输入，也不含原生的图像、音频或视频输出。

这一区别澄清了发布演示的性质。Qwen 使用 Blender 进行3D工作，使用游戏引擎制作交互式软件，并在视频制作工作流中使用 WonderClip。通过软件工具制作影片与模型直接生成视频是两回事。

竞争对手的边界各不相同。Opus 5.5 接受文本和图像并返回文本。GPT-6.1 Sol 同样列出文本和图像输入，音频和视频不支持作为原生模态，但它可以调用图像生成等工具。Google 的 Carbon 和 Hydrogen 列出文本、图像、视频和音频输入，输出为文本。Artificial Analysis 列出 Kimi K3.1 Pro 接受文本和图像。

因此，对于以录音语音为中心的应用，Qwen 公布的规格要求采用与 Google 支持音频的模型不同的集成方式。对于视觉检查或视频分析，Qwen 提供了直接输入选项，但相关的准确性和处理限制仍需测试。

更大的架构旨在减少活跃计算

阿里巴巴描述了一个2.4万亿参数的主干网络，每个token激活710亿参数，另有3280亿参数专门用于局部token模式表示。因此，2.4万亿这一数字并非包含该额外组件在内的完整计数。

其混合专家设计每次只激活网络的一部分。压缩历史与选择性注意的结合旨在让长输入更经济，而经过修订的信息通路则支持训练稳定性。

阿里巴巴表示，该模型激活的参数比 Qwen3.8-Max 少约25%。其预训练图表还报告了知识、代码、问答和 STEM 方面预测分数的提升。这些测量描述的是预测性能，而非完成任务的成功率，且阿里巴巴指出该比较混合了基础检查点与后训练检查点。

实际问题是：这些架构变化能否以可接受的成本产出可靠的工作成果？仅凭参数数量无法回答。

各方反应揭示了对“成功发布”的不同定义

此次发布引发了对精选基准结果与更广泛排名之间差距的批评。在本文审阅的截图所示帖子中，X 账号 Chubby，@kimmonismus 写道：“Qwen 4 不是一个好的发布。”

该账号认为，Artificial Analysis 的结果削弱了其与 Opus 表面上的旗鼓相当，并推测对蒸馏的限制是差距的原因。所提供的帖子并未给出确立这一因果解释的证据；仅凭基准分数无法确定模型的训练数据访问如何影响其性能。

独立的成本测量支持一种更为审慎的评估。Qwen 在综合智能上落后于 Kimi，但每个评估任务的成本更低。这对于处理大规模工作负载的企业可能很重要，即使这并不能确立前沿领导地位。

可用性、开放权重与企业决策

Qwen4-Max 可通过 QwenCloud、Qwen Studio、QwenWork 和 Qoder 使用。其API功能包括工具调用、结构化响应、网络搜索、批处理，以及与 OpenAI 和 Anthropic API 格式的兼容。

阿里巴巴还描述了一种 Live Delivery（实时交付）工作流，可展示可用的中间结果，让用户能在智能体完成前调整其方向。该公司表示将开源相关插件。

但与其众多前代不同，Qwen4-Max 不是开放权重模型。阿里巴巴承诺将发布带可下载权重的较小 Qwen4 版本，但公告既未提供许可证，也未提供发布时间表。希望在自己的基础设施上运行这款旗舰模型的组织，不能把这一未来承诺当作当前的可用性。

制造和科学演示雄心勃勃。阿里巴巴报告称，将一个加工工件的手动编程工作量从约475分钟降至24分钟，并描述了一次48小时的材料研究运行，产出了实物冷却液样品。这些是公司自报的演示，并非可比的节省或发现在客户部署中会再次出现的证据。

Qwen4-Max 最明确的企业机会是可衡量的：测试其更低的费率和改进的执行是否降低了产出可接受结果的成本。这一计算应包括重试、审查时间、外部工具和延迟。其最强的基准结果证明了评估的价值；其较弱的结果则使得针对特定工作负载的验证必不可少。
