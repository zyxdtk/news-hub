AMA-Bench：评估智能体应用的长时记忆能力

AMA- Bench：评估智能体应用的长时记忆能力 赵宇杰 袁博钦 黄俊博 袁浩诚 余仲铭 徐浩洲 胡兰翔 Abhilash Shankarampeta 黄子萌 倪文涛 田元东 赵吉申

摘要 大语言模型（LLMs）正被部署于日益复杂的自主智能体应用中，其中实现长时记忆对提升性能至关重要。然而，实际应用与当前智能体记忆评估标准之间存在显著差距：现有基准主要聚焦于以对话为中心的人-机交互场景。现实中，智能体记忆由连续的智能体-环境交互流构成，主要由机器生成的表示形式组成。为弥合这一差距，我们提出 AMA-Bench（Agent Memory with Any length），用于评估 LLM 在真实智能体应用中的长时记忆能力。其包含两个关键组件：（1）来自代表性智能体应用的真实世界智能体轨迹，配以专家审核的问答对；（2）可扩展至任意时间跨度的合成智能体轨迹，配以基于规则的问答对。我们的综合研究表明，现有记忆系统在 AMA-Bench 上表现不佳，主要因其缺乏因果性与客观信息，且受限于多数记忆系统采用的基于相似性检索的有损特性。为应对这些局限，我们提出 AMA-Agent，一种融合因果图与工具增强检索的有效记忆系统。实验结果表明，AMA-Agent 在 AMA-Bench 上达到 57.22% 的平均准确率，超越最强记忆系统基线 11.16%。

大语言模型（LLMs）已迅速从解决封闭形式推理任务（图 1(a)）和充当聊天机器人（图 1(b)），发展为自主智能体（图 1(c)）。自主智能体需进行长时程推理与经验复用，以完成开放空间导航、代码编辑、网页搜索等任务。为赋予 LLMs 这些能力，智能体记忆已成为智能体设计的关键组件，用于管理 LLM 的上下文（Wang 等，2025b；Agashe 等，2024）。强大的记忆模块应具备两大核心能力：（1）高效记忆处理，将完整智能体轨迹转化为结构化事实表示（如摘要、事实表或嵌入向量）（Edge 等，2025；Packer 等，2023；Liu 等，2026）；（2）高效记忆检索，可靠地选择并利用最相关记忆以指导决策。现有基准通常在以对话为中心或合成检索任务中评估这些能力（Hsieh 等，2024；Maharana 等，2024），聚焦于特定子组件，如单跳/多跳问答（记忆检索）或状态更新与记忆压缩（记忆处理）。目前尚缺乏针对长时程智能体任务的记忆模块基准与评估体系。

现实中的智能体主要运行于机器生成环境（如数据库、代码执行器与网页接口），需处理大量机器生成的表示形式。然而，现有多数记忆基准仍以自然语言为中心，存在三大关键局限：（1）表示类型缺失：智能体轨迹涵盖多样机器生成符号（如 ASCII 表格、JSON 数据、Unicode 片段、Python 或 HTML 代码块），而当前基准主要依赖自由文本；（2）因果性缺失：智能体轨迹具有因果基础——每项动作引发潜在环境状态转移，从而约束后续观测；但现有基准遵循无约束的语言流；（3）客观信息稀疏：智能体轨迹为机器生成且客观，而对话中心基准包含大量冗余信息（如寒暄闲聊）。
