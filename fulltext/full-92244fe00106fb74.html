原标题：Dynamic Task Allocation with Dialogue

中文摘要： 本文提出一个通信增强的贝叶斯任务分配框架，支持部分可观测环境下的动态任务分配。智能体通过对话减少对环境和协作者的不确定性，同时决策基于显式概率信念，将自然语言作为概率证据纳入推断过程。在扩展了动态到达任务的Overcooked环境中评估表明：通信智能体在完全和部分可观测下均持续优于普通LLM智能体；在完全可观测下与非通信基线表现相当，但在部分可观测下随任务复杂度增加大幅超越基线（平均加速0.585，提前18个时间步完成），证明可用信息减少时通信愈发重要。

基于对话的动态任务分配

Matthew Groholski, Weiwei Gu, and Nakul Gopalan

所属机构：
计算与增强智能学院
亚利桑那州立大学
Tempe, AZ, USA
{mgrohols, weiweigu, ngopala6}@asu.edu

摘要

有效的多智能体协作要求智能体在目标和职责不断演变时调整任务分配。先前的任务分配框架通常假设静态目标、完全可观测性，或依赖大语言模型（LLM）而缺乏对任务分配或意图的明确、可验证的信念。这些假设限制了它们在现实世界协作中的适用性，因为在现实协作中，智能体通常缺乏关于彼此行动、进度或局部环境的完整信息。为了支持部分可观测下的动态任务分配，我们引入了一个通信增强的贝叶斯任务分配框架。我们的智能体使用对话来减少对环境和协作者的不确定性，同时保持决策基于明确的概率信念。我们在扩展了动态到达任务的Overcooked领域中，在完全和部分对象空间可观测性下评估了我们的框架。我们的通信智能体在两种设置中均持续优于普通LLM智能体。此外，我们的框架在完全可观测性下与不通信的任务分配基线表现相当，但在部分可观测性下随着任务复杂性的增加而大幅超越该基线，平均加速0.585，平均提前18个时间步完成任务。这些结果表明，我们的智能体在部分可观测环境中比基线更高效地进行动态任务分配，并且随着可用信息的减少，通信变得愈发重要。

索引词： 多智能体协作、任务分配、人机对话、部分可观测性、贝叶斯推断、大语言模型

I 引言

人类经常在目标和职责不断演变的环境中协作，从厨房烹饪到交响乐演奏 [12]。在这些场景中，协作者必须不断协调职责如何随时间分布和更新，这一过程被称为动态任务分配。例如，在繁忙的厨房中，厨师们会根据工作量和个人进度重新分配备菜、烹饪、摆盘和上菜等任务。对话是这种协调最常见的模态之一，使协作者能够交流进度、协商职责并保持对任务的共同理解 [8, 4, 6, 9]，如图1所示。因此，有效的人机协作要求人工智能体能够使用对话执行动态任务分配，推理协作者的目标、行动和进度，以便在交互展开时调整职责 [13]。

先前的工作已使用强化学习和大语言模型（LLM）来开发协作智能体 [5, 21, 10, 19]。然而，许多方法假设静态目标、关于协作者的先验知识和完全可观测性 [23, 24]，这限制了它们在目标和职责不断变化或环境仅部分可观测的场景中的适用性。这类场景在现实世界的协作中很常见，智能体必须在任务和协作者的双重不确定性下进行推理。

我们通过开发一个在环境和协作者上维护信念状态的智能体来应对这一挑战，使其能够在部分可观测、任务演变且对伙伴无先验知识的情况下进行动态任务分配。基于Wu等人 [23] 的工作，我们的智能体推理未观测的对象，根据新证据更新任务分配，并通过对话交换超出直接观察的任务相关信息。这些机制共同支持在环境和其他智能体行为双重不确定性下的长时域协作规划。

我们的贡献如下：

  1. 我们引入了一个语言提升（language-lifted）智能体，它在未观测状态上维护信念，并将自然语言通信作为任务分配推断的概率证据。
  2. 我们引入了一个新颖的框架，用于在完全和部分对象空间可观测性下评估具有动态到达任务的动态多智能体任务分配，该框架在Overcooked环境中实现。

II 相关工作

II-A 多智能体规划

多智能体规划领域已有大量工作研究智能体如何与协作者协调任务分配 [18, 2, 16]。临时团队协作（ad hoc teamwork）研究了智能体需要在没有事先就联合策略达成一致的情况下与从未见过的队友协调的场景 [18, 2, 16]。Wu等人 [23] 引入了贝叶斯委托（Bayesian Delegation）来更新协作中的任务分配，该方法将任务分解为子任务并使用逆向规划推断协作者的潜在子任务分配。Ying等人 [24] 将这一方向扩展到部分可观测场景，将递归心智理论推理与通信相结合用于人机协作。然而，这些先前的方法假设固定的目标规范 [18, 2, 16, 24, 23]，在目标持续演变时无法工作。相比之下，我们的智能体在部分可观测环境中通过自然语言对话执行动态任务分配，而无需协作者行为的先验知识。

II-B 人机对话

研究人员长期研究如何构建使用对话的协作智能体 [25, 24, 10, 20, 7, 15]。Chai等人 [3] 将对话描述为一种人类向具身智能体传达任务相关知识的交互形式。先前的工作还开发了在智能体卡住 [20] 或对任务不确定 [15, 7] 时主动寻求帮助的智能体。除了寻求帮助之外，最近的工作已将对话纳入协作任务推理，使用语言模型推断协作者的心理状态或生成协调行动 [25, 24, 10]。在我们的场景中，对话用于传达任务相关信息，并为决定未来行动提供证据。

II-C 基于LLM的规划

LLM在生成规划和协调智能体方面的研究日益增多 [26, 11, 1]。Liu等人 [10] 提出了一种基于LLM的分层语言智能体，通过将基于语言的意图推理与反应式执行相结合，实现实时人机协调。Sun等人 [19] 通过引入一个在协作任务上评估基于LLM的多智能体系统的基准，表明LLM智能体在主动协作和持续适应方面存在困难。此外，Valmeekam等人 [22] 表明LLM作为自主长时域规划器表现不佳，但可以为其他规划器提供有用的启发式指导。在我们的方法中，LLM用于将对话解释为显式多智能体规划过程的任务相关证据。

III-A 预备知识

Wu等人 [23] 将协作任务分配形式化为多智能体马尔可夫决策过程（MMDP），其中智能体共享已知的静态目标并推断每个协作者正在追求哪个子任务。给定包含从时间步0到T观察到的状态和联合动作的交互历史 H_{0:T}，并令 𝐭𝐚 表示可行任务分配的集合，Wu等人 [23] 推断最可能的分配为：

ta* = argmax_{ta∈𝐭𝐚} P(ta | H_{0:T})　　(1)

在这种表述中，任务分配是用完全观测的联合动作计算的，而当协作者的动作、进度或环境不可见时，这些信息是无法获得的。

III-B 分散式POMDP

为了考虑这种部分可观测性，我们将Wu等人 [23] 的表述扩展为带有子任务的分散式部分可观测马尔可夫决策过程（Dec-POMDP）[14]，由元组 ⟨n, 𝒮, 𝒜_{1…n}, T, 𝕆, 𝒪, R, h, b₀, 𝒯⟩ 定义，其中 n、𝒮、𝒜、T、R 和 𝒯 由Wu等人 [23] 定义。联合观测空间为 𝕆 = 𝐨₁ × ⋯ × 𝐨ₙ，其中 𝒪(𝐨|s) 是给定状态 s 下联合观测 𝐨∈𝕆 的概率；视野 h 为已完成的时间步数 t_max；b₀ ∈ Δ(𝒮) 是 t=0 时的初始状态分布。

III-C 语言提升规划器

为了建模对话交互，我们在每个智能体的观测历史中添加通信。每个智能体维护任务分配上的信念分布，并在此信念足够不确定时广播消息；图2(a) 展示了一个对话示例。智能体使用香农熵 [17] 估计当前任务分配的不确定性，并在此熵超过预定义阈值时进行通信；详细信息见附录"扩展方法论"。观测历史 H_{0:T} 是包含智能体观测 s_t、联合动作 𝐚_t 和联合话语 𝐳_t 在所有时间步上的元组序列，表示为 H_{0:T} = {(𝐳_t, 𝐚_t, s_t)}_{t=0}^{T}。我们通过根据观测动作似然和话语似然对每个任务分配加权来计算公式1中的后验：

P(ta | H_{0:T}) ∝ P(ta) ∏_{t=0}^{T} P(𝐚_t | s_t, ta) P(𝐳_t | ta)　　(2)

项 P(ta) 和 P(𝐚_t | s_t, ta) 分别是任务分配先验和联合动作似然，由Wu等人 [23] 定义。联合话语似然 P(𝐳_t | ta) 直接从LLM对每个智能体话语的输出词元概率计算。详细信息见附录"扩展方法论"。

III-D 部分可观测性

我们的表述可以扩展到部分可观测场景。每个智能体维护一个信念状态，交互历史变为 H_{0:T} = {(𝐳_t, 𝐚_t, o_t, b_t)}_{t=0}^{T}，其中未观测的动作记为 ∅，o_t 是智能体在时间步 t 的观测，b_t 是其对未观测状态的信念。为了更好地近似部分可观测下的Q值，每个智能体维护对描述环境未观测部分特征的潜在命题 p 的信念（图2(b)），在每个时间步更新为：

P(p | o_T, H_{0:T-1}) ∝ { φ(p)/b^j_{T-1}(p)，若 b^j_{T-1}(p) ≠ 0；0，否则 }　　(3)

其中 φ(p) 将从当前观测、前一联合动作 𝐚_{T-1} 和前一观测 o_{T-1} 中提取的证据与智能体推断的任务分配相结合，以估计无法直接观测的命题。完整推导见附录"扩展方法论"。

因此，公式2进一步扩展了观测似然项：

P(ta | H_{0:T}) ∝ P(ta) ∏{t=0}^{T} P(𝐚_t | o_t, b_t, ta) P(𝐳_t | ta) × P(o_t | 𝐚{t-1}, o_{t-1}, b_{t-1}, ta)　　(4)

该公式各项的详细信息见附录"扩展方法论"。

IV 结果

IV-A 领域

我们扩展了Wu等人 [23] 引入的Overcooked环境，加入动态目标设置，其中任务在执行过程中逐步揭示，而不是在开始时固定。我们还引入了部分可观测设置，其中协作者的动作或局部环境对智能体不可访问。该环境使我们能够在不同不确定性水平下测试智能体对动态目标的推理和通信能力。更多详细信息见附录"扩展结果"。

IV-B 基线

我们与适合每种可观测性设置的基线进行比较。在完全可观测下，我们调整Wu等人 [23] 的任务分配算法以支持动态任务到达，修改其在任务队列随回合变化时重新规划。在部分可观测下（我们为该领域引入的设置），我们使用移除通信的我们自身方法的消融版本，以隔离当智能体缺乏完整环境知识时显式通信的贡献。在这两种设置中，我们还与普通LLM智能体进行比较，该基线遵循Sun等人 [19] 基准测试的基于LLM的智能体，接收相同的适合可观测性的信息，但直接选择动作，而没有我们方法论中的额外机制。

IV-C 指标

我们使用时间步差 Δt = T_M − T_B（负值有利于通信智能体 M 优于基线 B）和加速比 T_B/T_M − 1（正值有利于 M）评估性能，遵循Ying等人 [24]。我们报告各指标在多次运行中的均值和标准误（SE）。

IV-D 实验结果

我们分别评估完全和部分可观测性，在每种设置中改变任务队列长度和布局；完整实验参数见附录"扩展结果"。

IV-D1 完全可观测

如图3(a) 所示，通信智能体在两种布局中均持续优于普通LLM智能体，在队列长度为1时加速最大，随着队列长度增加收益递减。如图3(b) 所示，我们的智能体在大多数条件下与非通信基线表现相当。因为两个智能体都观测完整的对象空间，非通信智能体已经可以获得通信本来会传达的大部分信息，这限制了通信的附加收益。

IV-D2 部分可观测

通信智能体持续优于普通LLM智能体，收益同样在队列长度为1时最大（图4(a)）。然而，通信现在比非通信基线具有明显优势（图4(b)）。这一优势通常随队列长度增长而增大，在非对称布局队列长度为3时最为明显。随着可用知识的减少，通信对于弥合智能体之间的信息差距变得更加重要。

V 讨论

我们的结果表明，显式任务分配和通信提供了普通LLM智能体所缺乏的结构：LLM基线未能完成任何配置，而我们的智能体在各种可观测性设置下都能成功。通信的价值取决于可观测性。在完全可观测下，我们的智能体与非通信基线表现相似，因为智能体可以从可见的动作推断协作者的任务。在部分可观测下，通信变得越来越重要，特别是随着队列长度的增长，因为仅凭动作不再能充分揭示协作者的任务或进度。

VI 局限性

我们的工作有两个主要局限性。首先，我们的通信机制是刻意收窄的：话语传达任务分配意图，但不传达更丰富的信念、问题、协商或修复，并且基于熵的说话触发器可能无法反映协作者已经知道的内容。其次，我们的实验规模有限，只有一个环境系列、两种布局、短任务队列、两个基线和每个配置六次运行，并且假设已知的任务类型、固定的智能体集合和可靠的无成本通信。

VII 结论

我们引入了一种针对动态到达任务和部分对象空间可观测性的贝叶斯任务分配算法，在显式推断过程中使用语言作为概率证据。我们的结果表明，该框架在部分可观测下比基线实现了更强的动态任务分配，并且随着可用信息的减少，通信变得更加重要。

扩展方法论

本附录提供了第III节中引入的话语策略、联合话语似然、潜在命题上的信念更新以及部分可观测似然项的完整公式。

-A 话语策略

当智能体任务分配信念的香农熵超过最大可能熵的一定比例时，智能体进行通信 [17]：

−∑{ta∈𝐭𝐚} P(ta | H{0:T}) ln P(ta | H_{0:T}) ≥ ε ln |𝐭𝐚|　　(5)

其中 ε∈[0,1] 控制话语阈值（第III-C节）。

-B 话语似然

公式2（第III-C节）中使用的联合话语似然 P(𝐳_t | ta) 计算为：

P(𝐳 | ta) = ∏{i: 𝒯_i ∈ ta} { 1，若 z_i = ∅；∏{j=0}^{|z_i|−1} P(z_{i,j} | ta, z_{i,<j})，否则 }　　(6)

其中 z_i = ∅ 表示智能体 i 未产生话语。在后一种情况下，词元概率直接从LLM的输出logits获得。

-C 信念更新推导

本小节提供了第III-D节（公式3）中引入的信念更新的完整推导，将第III-A节和第III-C节的表述扩展到具有部分可观测对象空间的环境。智能体无法直接观测环境的完整状态，必须推理可能存在于其视野之外的对象；因此每个智能体维护对描述环境隐藏区域的潜在命题的概率信念，并使用环境观测和来自协作者的通信递归更新这些信念。

-C1 信念表示与初始化

我们将对象空间划分为三个区域：S^i，智能体 i 可观测的区域；S^j，仅智能体 j 可观测的区域；以及 S^s，两个智能体都可见的共享分隔区域。由于 S^j 的内容不可观测，智能体 i 维护对描述其状态的命题的信念。命题 p 是描述 S^j 潜在属性的布尔陈述——例如，某种食材或动作对象是否存在于 S^j 内，或者 S^j 内是否创建了某个对象。

在每个时间步 T，智能体 i 维护对每个命题 p 的信念分布，定义为后验概率：

b^j_T(p) = { P(p | o_T)，若 T = 0；P(p | o_T, H_{0:T−1})，否则 }　　(7)

其中 o_T 表示时间步 T 的观测，H_{0:T−1} = {(𝐳_t, a^i_t, o_t, b^j_t)}_{t=0}^{T−1} 是由传达的话语 𝐳_t、智能体 i 的动作 a^i_t、观测 o_t 和来自先前时间步的信念 b^j_t 组成的交互历史。

初始信念由两个环境假设构建：每个任务都是可完成的，并且最初存在的每种食材都与一个分配器相关联。因此，任何未直接观测到的对象必须位于 S^j 内或位置未知。对于每种食材 x_m ∈ X，其在隐藏区域中存在的初始信念为：

b^j_0(x_m) = P(x_m ∈ S^j_0 | o_0) = { 1，若 x_m ∈ X_0 ∖ (S^i_0 ∪ S^s_0)；0，若 x_m ∉ X_0；b_init，否则 }

由于在初始时间步尚未执行任何动作，任何对象在隐藏区域内被创建的概率初始化为零：

b^j_0(C(x_m, S^j_T) > C(x_m, S^j_{T−1})) = 0

类似地，对于最初存在的每种食材，其对应分配器位置的信念为：

b^j_0(d(x_0)) = P(d(x_0) ∈ S^j_0 | o_0) = { 1，若 d(x_0) ∉ (S^i_0 ∪ S^s_0)；0.5，否则 }

对动作对象的信念以相同方式初始化：对于每个动作对象 y ∈ Y，

b^j_0(y) = P(y ∈ S^j_0 | o_0) = { 1，若 y ∉ (S^i_0 ∪ S^s_0)；0.5，否则 }

-C2 后验信念更新

在每个后续时间步，智能体 i 使用新观测的证据和智能体 j 产生的话语更新其信念。由于智能体 i 对自己的动作及其确定性效果有完整的知识，观测中其自身动作无法解释的任何变化必定是由智能体 j 造成的，因此提供了关于 S^j 的证据。我们用证据提取函数 E(o_T, a^i_{T−1}, o_{T−1}) = e 来隔离这些信息，其中 e 通过比较执行 a^i_{T−1} 后的预期观测与实际观测 o_T 获得。

每个命题的信念通过结合两个互补的信息源来更新：给定观测证据的命题似然，以及传达的任务分配所隐含的命题似然。后验信念为：

P(p | o_T, H_{0:T−1}) ∝ { [P(p | e, o_{T−1}, H_{0:T−2}) × ∑{ta∈𝐭𝐚} P(z^j{T−1} | ta) × P(p | ta, o_{T−1}, H_{0:T−2})] / b^j_{T−1}(p)，若 b^j_{T−1}(p) ≠ 0；0，否则 }　　(8)

其中 P(p | e, o_{T−1}, H_{0:T−2}) 是以提取的证据为条件的命题似然，P(z^j_{T−1} | ta) 是候选任务分配下传达话语的似然，P(p | ta, o_{T−1}, H_{0:T−2}) 是任务分配隐含的命题似然，b^j_{T−1}(p) 是来自前一时间步的先验信念。

-C3 证据条件似然

观测似然基于环境的确定性动态：由于只有智能体 j 能解释与智能体 i 自身动作不一致的变化，每个观测到的状态转换都提供了关于隐藏环境的证据。我们将这些证据分为四种类型——对象被拾起、放下、交付，或没有发生可观测的证据——每种类型仅更新受转换直接影响的命题，所有其余命题保持先前的信念。

当一个对象从可观测区域消失而未被智能体 i 移除时，智能体 i 推断智能体 j 在 S^j 内拾起了该对象；因此被拾起的对象必定在动作之前立即存在于隐藏区域内，并且同一时间步内不可能创建任何对象：

P(p | e_pick up, o_{T−1}, H_{0:T−2}) = { 1，若 p 陈述被拾起的对象存在；0，若 p 是创建命题；b^j_{T−1}(p)，否则 }　　(9)

新观测到的对象表明智能体 j 在隐藏区域内生成了该对象，然后将其放入可观测空间。由于环境动态是已知的，智能体可以推断构建新观测对象所需的食材、动作对象和分配器。令 X_x 表示构建过程中消耗的中间对象，Y_x 表示配方所需的动作对象，D_x 表示未直接观测到被收集的食材的分配器，X′_x 表示可以从新观测对象随后产生的对象：

P(p | e_set down, o_{T−1}, H_{0:T−2}) = { 1，若 p 关于 y 且 y ∈ Y_x；1，若 p 关于 d(x) 且 d(x) ∈ D_x；0，若 p 陈述被放下的对象存在；0，若 p 关于 x 且 x ∈ X_x ∪ X′x；0，若 p 是创建命题；b^j{T−1}(p)，否则 }　　(10)

交付证据与放下证据类似处理：交付一个对象揭示了必须在隐藏区域内执行以产生它的配方，因此相同的推断食材、动作对象和分配器更新命题似然：

P(p | e_deliver, o_{T−1}, H_{0:T−2}) = { 1，若 p 关于 y 且 y ∈ Y_x；1，若 p 关于 d(x) 且 d(x) ∈ D_x；0，若 p 陈述被交付的对象存在；0，若 p 关于 x 且 x ∈ X_x ∪ X′x；0，若 p 是创建命题；b^j{T−1}(p)，否则 }　　(11)

当没有观测到证据时，每个命题保持先前的信念：

P(p | e_none, o_{T−1}, H_{0:T−2}) = b^j_{T−1}(p)　　(12)

-C4 任务分配条件似然

虽然环境证据提供了关于已经发生的动作的信息，但通信提供了关于智能体打算在未来执行的动作的信息。由于完成任务需要必要的先决对象，描述任务分配的话语隐含地传达了关于隐藏环境的信息：例如，如果智能体 j 传达它将独立准备一道菜，智能体 i 可以推断该任务所需的食材、动作对象和分配器在 S^j 内可用。

如第III-C节所述，我们使用大语言模型的输出logits估计候选任务分配下话语的似然：

P(z^j_{T−1} | ta) = ∏{l=0}^{|z^j{T−1}|} P(z_l | ta, z_{<l})　　(13)

其中 z_l 表示第 l 个生成的词元，z_{<l} 表示前面的词元。

给定任务分配，智能体 i 可以推断隐藏区域内必须已经存在哪些对象才能使传达的计划可行；由于环境动态是已知的，这些先决对象还揭示了产生它们所需的中间对象、动作对象和分配器。令 X_ta 表示构建任务分配隐含的先决对象时消耗的中间对象，Y_ta 表示相应的动作对象，D_ta 表示与未直接观测到被收集的食材相关联的分配器：

P(p | ta, o_{T−1}, H_{0:T−2}) = { 1，若 p 关于 y 且 y ∈ Y_ta；1，若 p 关于 d(x) 且 d(x) ∈ D_ta；1，若 p 关于 x 且 x 是 ta 的先决条件；0，若 p 关于 x 且 x ∈ X_ta；0，若 p 是创建命题；b^j_{T−1}(p)，否则 }　　(14)

该似然捕获了独立于环境观测由通信传达的信息；在后验更新期间，它与观测似然相结合，产生同时反映智能体观测行为和其传达意图的信念分布。

-D 部分可观测似然项

在部分可观测下（第III-D节），公式4中的联合动作似然定义为：

P(𝐚_t | o_t, b_t, ta) = ∏{i: 𝒯_i ∈ ta} { 1，若 a^i_t = ∅；exp(β Q*{𝒯_i}(o_t, b_t, a^i_t))，否则 }　　(15)

其中 a^i_t = ∅ 表示智能体 i 在时间步 t 的动作未被观测到；后一种情况由Wu等人 [23] 定义。

观测似然定义为：

P(o_t | b_t, 𝐚_{t−1}, o_{t−1}, ta) = ∏{i: 𝒯_i ∈ ta} { 1，若 a^i_t ≠ ∅；1/V*{𝒯_i}(o_t, b_{t−1})，否则 }　　(16)

如果智能体的动作被直接观测到（a^i_t ≠ ∅），观测的该部分被视为完全由任务分配解释并分配似然 1。否则，使用任务 𝒯_i 下估计值函数的倒数来近似似然，反映了对应于更高价值状态的观测在智能体潜在任务下更有可能的直觉。
