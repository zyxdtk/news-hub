摘要
近期的研究利用大型语言模型（LLMs）通过语义描述和基于轨迹的提示来增强自动特征工程。
然而，存在两个挑战限制了它们在长期优化中的适用性和可扩展性：
（1）在许多实际场景中无法获取语义元数据，以及
（2）轨迹的积累增加了超出上下文窗口的风险，而如果没有它，生成过程可能会变得不稳定，导致陷入局部最优以及生成特征的高重复率。
为此，我们提出了一种用于无元数据AutoFE的SHAP增强隐式轨迹生成方法（SIGMA），这是一个可扩展的恒定上下文优化框架。
SIGMA利用SHAP值提供任务感知信号，以引导分组特征生成，而不是依赖语义信息。
此外，我们采用了一种暴露特征隐式轨迹（EXIT）方法，其中提示中的暴露特征隐式地代表了轨迹。
实验结果表明，SIGMA在提示长度几乎恒定的情况下，实现了与最先进的（SOTA）LLM基线相当的性能。
值得注意的是，EXIT将生成特征的重复率从37.2%显著降低到了6.8%。
同时，SIGMA平均仅使用5.4个特征就达到了传统SOTA的性能，展现了在特征利用方面的显著效率提升。

3.1
特征组
原始特征根据其 SHAP 值被划分为组。
我们没有按固定比例划分每个组（例如，每组 33% 的特征），而是通过添加噪声特征引入了一个阈值。
具体来说，我们首先向原始特征集添加一个高斯噪声列，然后计算它们所有的 SHAP 值。
为了使特征与噪声具有可比性，在此阶段应用了 min-max 归一化。
之后，噪声的 SHAP 值被用作阈值，将特征分为三组：top、useful 和 weak。
top 组包含 SHAP 值排名前 10% 的特征（至少两个特征）。
这些特征对于模型的预测是最重要的。
weak 组由 SHAP 值低于阈值的特征组成，而其余特征被分配到 useful 组。
基于噪声阈值划分特征有助于调整 LLM 对当前特征空间的注意力。
如果我们使用固定的划分比例，LLM 将在所有数据集中为每个组分配固定水平的注意力。
然而，不同的数据集有其自身的特点。
例如，在某些情况下，大多数特征表现出比噪声更低的重要性，而在其他情况下，所有特征都比噪声更重要。
一个组包含的特征越多，LLM 对它的关注就越多。
因此，引入噪声特征可以帮助 LLM 生成符合目标数据集内在特征的特征。
此外，该分组策略也可以使后面将介绍的 EXIT 策略受益，使其不可或缺。
3.2
组内和跨组生成
将特征划分为组后，我们构建提示供 LLM 生成新特征。
提示模板可以在附录
A
中找到。
我们要求 LLM 生成一个组内特征和一个跨组特征，而不是在每一步中仅生成一个特征。
组内特征侧重于深度特征变换或多特征交互，以发现同一组中的隐藏模式。
通过生成组内特征，我们旨在改善已有的有影响力的信号。
相比之下，跨组特征侧重于通过将高重要性特征与较弱信号桥接起来建立协同效应。
换句话说，跨组生成旨在改善弱信号。
两个生成的特征都将由下游模型评估，并且只有具有最积极改进的特征才会被接受。
3.3
暴露特征隐式轨迹 (EXIT)
由于我们在提示中丢弃了显式轨迹，LLM 表现出生成重复特征的高倾向。
基于信息不仅通过显式信号的存在传达，而且通过它们的战略性省略传达的原则，我们提出了 EXIT。
具体而言，在每一步中，用于生成的所有选定特征

我们还跟踪应用的操作，并阻止 LLM 在提示中使用两个最频繁的操作，因为 LLM 倾向于为给定数据集选择相同的操作。
然而，仅跟踪与失败生成相关的操作并暂时禁止它们。
如果一个操作持续改善性能，它应该被认为非常适合该数据集并相应地得到奖励。
总之，轨迹信息被隐式封装在暴露特征集中，而不是维护优化历史的显式、重标记记录。

4.1

在我们的实验中，我们使用了先前研究

此外，我们使用不同的随机种子执行了三次此数据拆分，以提高结果的可靠性。
评估指标：
我们采用 F1 分数作为主要评估指标，以提供对模型性能的平衡评估。
基线：
我们将 SIGMA 与基于 LLM 和传统的 AutoFE 方法进行了比较，并选择 XGBoost
(
6
)
作为下游模型。
作为代表性的基于 LLM 的方法，我们使用 CAAFE 和 OCTree 作为基线。
CAAFE 是一种利用详细特征描述的基于语义的方法，而 OCTree 使用特征空间的树结构表达式作为轨迹信息来实现非语义生成。
我们使用众所周知的 AutoFE 方法，包括 DFS、OpenFE 和 AutoFeat 作为传统基线。
这些方法基于预定义的变换规则，并通过在操作空间上进行详尽搜索来执行特征生成。
实验协议：
为了确保全面评估，我们采用以下设置。
对于 SIGMA 和传统特征工程方法，通过掩码特征名称和编码值来移除语义信息，以便所有方法在没有访问语义描述的情况下运行。
为了消除由变换定义引起的差异，我们进一步采用了由基本算术运算（加、减、乘、除）、常见的一元变换（对数、平方根、绝对值）和简单的特征交互（比率）组成的共享操作空间。
对于基于 LLM 的基线，我们遵循它们的原始实现。
为了减少由温度参数和采样策略引起的性能波动，我们将每种基于 LLM 的 AutoFE 方法重复了三次。
生成预算设置为 50 个特征，计算的是生成的特征而不是接受的特征。
我们认为 AutoFE 方法的性能也应该通过预测性能和特征预算之间的权衡来衡量。
在现实世界中，大量生成的特征将难以解释并需要巨大的维护成本。

总体而言，可以观察到，即使没有语义信息，基于 LLM 的 AutoFE 仍然可以取得强大的性能。
通过暴露特征提供隐式轨迹，EXIT 帮助 SIGMA 在迭代期间保持恒定上下文，从而实现长期优化。

消融研究
进行消融研究是为了评估所提出的 EXIT 策略的有效性，以及预定义和跟踪操作的影响。

结合图

换句话说，近 40% 的生成机会被浪费了，导致图
4

EXIT 按设计成功解决了这个问题，重复率降低了 30%。
接下来，关于操作的两个消融变体也展示了 LLM 的另一个特征——操作选择的倾向。
在没有预定义操作的情况下，LLM 仍然会生成 14.1% 的冗余特征，这一结果与既不跟踪也不限制前 2 个最频繁操作的场景一致。
这表明了一种固有的启发式偏好：LLM 倾向于根据其初始评估优先考虑特定的操作-特征配对，而不是探索更广泛的替代方案。
因此，优化过程仍然局限于这些首选操作，导致特征生成的多样性较低。
当难以生成接受的特征时，这种现象更为严重。
原因是特征空间的更新（接受新特征）将迫使 LLM 思考新的操作。
因此，跟踪和禁止操作也有利于获得更好的性能。
然而，强制 LLM 使用不常见的操作也会导致较高的代码错误率，如图

SIGMA 的错误率达到 5.6%，比其他变体高 4%。
因此，当反复暴露于相似的特征对时，LLM 倾向于选择相同的操作，从而产生更安全的代码生成但重复率更高。
这引入了错误率和重复率之间的权衡。

结论
在本文中，我们提出了 SIGMA，一个用于无元数据基于 LLM 的 AutoFE 的新颖且可扩展的恒定上下文优化框架。
SIGMA 不使用语义信息，而是利用 SHAP 值来引导任务感知生成，并引入了用于结构化特征探索的分组生成策略。
为了以较低的重复生成率实现长期优化，我们引入了 EXIT 以在提示中使用暴露特征，以隐式方式跟踪轨迹。
实验结果表明，SIGMA 在近乎恒定的上下文下实现了与当前基于 LLM 的基线相当的性能，并且在高效特征利用方面与传统 AutoFE 保持竞争力。
然而，在未来的工作中仍有几个局限性需要解决。
首先，当前的操作限制仍然很弱，因此重复率仍然接近 7%。
其次，SIGMA 仅关注分类任务；也应考虑回归任务。
最后是对验证集的过拟合，表现为性能下降。
因此，在未来，我们将专注于结合更多样化的数据集，并通过使用更强大的操作选择方法解决过拟合问题来进一步提高性能。
