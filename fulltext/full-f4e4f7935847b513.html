GPT-5.6：随野心扩展的前沿智能

📅 2026-07-09 📄 OpenAI 🔗 原文链接

原标题：GPT-5.6: Frontier intelligence that scales with your ambition More intelligence from every token, stronger performance per dollar, and more capability on demand for your hardest work.

中文摘要： OpenAI 正式发布 GPT-5.6 系列模型，包含旗舰 Sol、均衡型 Terra 和高性价比 Luna 三个层级。该系列在编程、知识工作、网络安全和科学领域实现全面性能提升，以更少 token 和更低成本超越竞争对手。新增 ultra 模式可并行协调多智能体加速复杂任务。模型具备更强的计算机使用和设计判断能力，并配备迄今最强大的分层安全保障系统，在防御性网络安全和生物学研究方面保持双用途平衡。

我们在有限预览⁠之后，正式推出 GPT‑5.6 系列模型供通用使用：我们的新旗舰模型 Sol，以及适用于日常工作的均衡模型 Terra，还有我们最具成本效益的模型 Luna。

GPT‑5.6 Sol 在智能和效率两方面都树立了新标准，在编程、知识工作、网络安全和科学领域取得了最先进的结果，同时以更少的 token 和更低的预估成本超越了此前及竞争中的前沿模型。其结果是更强的单位美元性能：在相同支出下完成更多成功的工作，或以更低的总成本获得相当的结果。我们还引入了一种加速最严苛工作的新方式：ultra 是我们最高能力的设置，可跨并行工作流协调多个智能体，更快地完成复杂任务。更强的计算机使用能力和设计判断力使 GPT‑5.6 Sol 成为我们迄今为止最成熟的协作者，能够检查、优化并交付可直接使用的结果。

我们训练 GPT‑5.6 从每个 token 中获取更多有用的工作成果。在 Agents' Last Exam⁠（在新窗口打开）——一项涵盖 55 个领域的长时间运行专业工作流评估中，GPT‑5.6 Sol 创下了 53.6 的新高，比 Claude Fable 5（自适应推理）高出 13.1 分。即使在中等推理模式下，它也以大约四分之一的预估成本击败 Fable 5 达 11.4 分。这种效率也延伸到较小的模型，这对于让智能更丰富、更可负担至关重要：GPT‑5.6 Terra 和 GPT‑5.6 Luna 以大约十六分之一的成本超越了 Fable 5。在 Artificial Analysis Intelligence Index⁠（在新窗口打开）——一项涵盖智能体工作、编程、科学推理和通用能力的广泛智能衡量指标上，GPT‑5.6 Sol 在最大推理模式下与 Fable 5 的差距不到一分，同时完成任务的时间减少了 61%，预估成本约为后者的一半。

GPT‑5.6 发布时配备了我们有史以来最强大的安全保障措施，旨在抵御有针对性的、自适应的滥用，同时不会广泛限制合法工作。在正式发布之前，我们对模型和安全保障措施进行了迄今为止最广泛的评估期，将人工红队测试与大规模自动化测试相结合。在预览期间，我们与专家组织和值得信赖的合作伙伴密切合作，在更广泛发布之前对防御措施进行压力测试并加强安全保障。由此产生的系统将训练到模型中的保护措施与实时检查、监控以及根据信任和风险校准的访问权限分层结合。

GPT‑5.6 Sol 是我们迄今为止最好的编程模型。在 Artificial Analysis Coding Agent Index 上，GPT‑5.6 Sol 在最大推理模式下以 80 分创下新的最先进水平，比 Fable 5 高出 2.8 分，同时使用的输出 token 不到一半，耗时不到一半，成本约低三分之一。这一优势贯穿整个系列：Terra 的表现略高于 Fable 5，而 Luna 超越了 Opus 4.8；两者都在大约三分之一的时间内完成，输出 token 约为一半，预估成本约为四分之一。它还在 Terminal‑Bench 2.1 和 DeepSWE 上创下了新的最先进结果，这两项测试分别检验真实代码库中的复杂命令行工作流和长周期工程。

Artificial Analysis Coding Agent Index: 一项涵盖实现、终端使用和真实代码库的编程智能体性能独立指数。

GPT‑5.6 可以编写和运行轻量级程序，在工作推进过程中协调工具、处理中间结果、监控进度并选择下一步行动。这使得工具密集型任务能够以更少的 token、更少的模型往返和更少的指导来推进。Responses API 中的 Programmatic Tool Calling⁠（在新窗口打开）无需开发者编写每一步脚本或将每个工具响应传回模型，即可过滤大量中间数据，仅保留重要内容，并沿途调整其工作流。

对于值得投入更多时间和计算的问题，GPT‑5.6 可以超越这种高效默认设置。max 给予 GPT‑5.6 比 xhigh 更多的时间来推理和探索替代方案、运行检查并修改其方法。ultra 则更进一步，默认并行协调四个智能体，以更高的 token 使用量换取更强的结果和更快的任务完成时间。下面的图表比较了 ultra 的默认四智能体设置与单智能体基线在 BrowseComp、SEC-Bench Pro 和 Terminal-Bench 2.1 上的表现；BrowseComp 和 SEC-Bench Pro 还展示了 16 智能体配置。在所有三项评估中，增加并行智能体将分数-延迟前沿向左上方移动，即在更短的时间内达到更强的结果。在 API 中，开发者可以使用 Responses API 中的 multi-agent⁠（在新窗口打开） beta 构建类似 ultra 的体验。

GPT‑5.6 还创建了视觉上更精致的文档和电子表格。它更忠实地遵循复杂的参考格式，这对于可重复的知识工作活动很重要。它以更高的精度处理方程和财务模型，并更好地利用排版、间距、层级和页面或工作表布局。

Executive summary

We initiate coverage of Blossom Co. ("Blossom" or "BLSM") with an Overweight rating and a $34 price target, implying ~24% upside from the last close. Blossom is a technology-enabled premium floral, gifting, and subscription platform that combines proprietary personalization, nine regional preparation hubs, and approximately 280 certified local studios. We see Blossom evolving from a holiday-driven online florist into a higher-frequency gifting platform, with recurring membership and enterprise services lifting revenue visibility, customer lifetime value, and fulfillment density.

Our investment thesis rests on three points:

•(1) Revenue quality is improving. Membership, subscription, and business-platform revenue represented 35.8% of FY25 sales; we model that mix reaching 44.3% by FY28. These streams carry higher retention, lower incremental acquisition expense, and better order visibility than one-off occasion purchases. Paid subscribers rise from 1.15 million to 2.18 million over the same period, while corporate gifting benefits from employee-recognition programs, loyalty integrations, and an expanding fulfillment API.

GPT‑5.6 是我们迄今为止最强的网络安全模型，以显著更少的 token 实现了前沿性能。在 ExploitBench 2（衡量从到达漏洞代码到任意代码执行的进展）上，它在可比的输出 token 预算下得分 73.5%，而 GPT‑5.5 为 47.9%。在 ExploitGym 3（要求智能体将真实世界的漏洞转化为可用的漏洞利用）上，它几乎将 GPT‑5.5 的峰值通过率翻倍，从 15.1% 提升至两小时限制下的 24.9%；在六小时限制下，达到 33.7%。在 SEC-Bench Pro（测试复杂软件的概念验证生成）上，它以改善的延迟得分 71.2%，而 GPT‑5.5 为 45.8%。

GPT‑5.6 支持重要的防御性任务，如安全代码审查、补丁修复、威胁建模和蓝队演练。OpenAI Daybreak 的 Cyber 受信访问⁠ 计划中的合格个人和组织可以在授权环境中通过更精确的安全保障措施访问更多防御能力，包括漏洞分类和验证、恶意软件分析、检测工程和补丁验证。

ExploitBench: 构建逐步更强大的 V8 漏洞利用；GPT‑5.6 相比 GPT‑5.5 显示出大幅提升。延迟图表未显示，因为该基准的延迟估计不可靠。

GPT‑5.6 Sol 还在 科学研究 方面展现出广泛提升。在生命科学评估中，GPT‑5.6 在真实世界的生物学、生命科学研究工作流和化学方面相比 GPT‑5.5 实现了帕累托改进。

GeneBench Pro⁠: 长周期基因组学和定量生物学分析；GPT‑5.6 以更少的 token 和更短的时间达到更强的结果。Claude Fable 5 未被纳入，因为它不回答⁠（在新窗口打开）高级生物学问题，并拒绝该评估中的大多数问题。

GPT‑5.6 是我们迄今为止用于加速 AI 研究的最强模型。在 OpenAI 内部，研究人员在整个开发循环中使用它：诊断故障、优化训练系统、运行实验和解释结果。我们已经在 GPT‑5.6 的内部测试期间看到了这种加速和更强的采用，因为每位活跃研究人员的平均每日输出 token 超过了 GPT‑5.5 观察到的最高水平的两倍以上。

这种工作方式正在迅速成为标准。在过去六个月中，用于内部编程推理的研究计算份额增长了 100 倍，而内部智能体 token 使用量增加了约 22 倍。这些采用指标本身并不衡量研究进展，但它们显示了 AI 辅助在研究和其他团队（如销售、市场、用户运营、财务等）中的增长速度。

为了直接衡量这一能力，我们开发了一套基于真实 AI 研究任务的内部评估套件，包括调试研究系统、优化内核和训练方案、运行机器学习实验以及改进另一个模型。

Aggregate RSI capability: 在一组衡量递归自我改进进展的评估中，我们观察到 GPT‑5.6 Sol 比 GPT‑5.5 提高了 16.2 分，全面加速了内部研究。

随着模型能力的提升，我们加强了安全栈，使先进智能能够保持广泛有用，同时对最高风险的使用施加更严格的审查。对于 GPT‑5.6，我们构建了迄今为止最强大的安全系统，根据每个模型的能力进行校准，并由比以往更多的计算能力驱动。

GPT‑5.6 模型在生物学和网络安全方面都比我们之前的模型更有能力，但在这两个类别中均未越过关键阈值。在网络安全方面，我们的测试表明 GPT‑5.6 更擅长发现和修复漏洞，而不是可靠地对加固目标执行自主的端到端攻击——这为防御者提供了在弱点被利用之前加强系统的机会。在生物学方面，我们的测试表明 GPT‑5.6 可以支持合法研究，但不提供创建、工程化或合成高度危险的新型威胁所需的端到端能力。

这两个领域本质上都是双用途的。在网络安全中，可以帮助攻击者利用漏洞的同样能力也可以帮助防御者发现它、复现它并构建可靠的修复。因此，过度阻断本身也会造成安全风险。它可能阻止防御者测试系统和部署补丁，而恶意行为者继续使用其他模型，包括越来越强大的开源模型，以及既有工具。有效的安全保障措施会考虑请求的上下文和可能后果，在保留合法防御工作的同时对证据表明存在严重伤害风险的情况施加更强的控制。

GPT‑5.6 的安全保障措施分层设计以实现更高的准确性和冗余，并旨在随着新攻击的出现快速适应。训练到模型中的保护措施与实时检查、持续监控和账户级执行协同工作，帮助系统即使在某一层未按预期工作时也能保持安全。在许多系统中，仅靠分类器标志来决定阻断什么，依赖于更难更改的低智能模型来防止伤害。我们的方法增加了一个推理监控器，审查对话以确定是否存在潜在伤害。这种设计旨在启用防御性工作同时阻止严重滥用，最敏感的能力通过受信访问保留给经过验证的用户。由于某些保护措施使用测试时推理，我们可以快速更新它们以弥合差距，而无需从头重新训练分类器。

在继续加强系统以抵御自适应攻击的同时，我们采取了更保守的方法。与之前的模型相比，我们的 GPT‑5.6 Sol 网络安全保障措施阻止了大约十倍多的潜在有害活动。由于这些措施可能对良性使用造成摩擦，我们在 ChatGPT 和 Codex 中提供了在较低能力模型上轻松重试提示的选项，我们将继续减少安全保障措施对良性使用的影响，同时保持高稳健性标准。这反映了我们的迭代部署方法：从保守开始，并根据从真实世界使用中学到的内容进行改进。

在正式发布之前，我们进行了迄今为止最密集的安全评估，包括广泛的红队测试、与外部专家的稳健能力和安全保障测试，以及大约 NVIDIA A100 Tensor Core GPU 等效小时的黑盒自动化红队测试。这使我们能够系统地探测可能的薄弱点，发现越狱，并帮助我们在发布前加强系统。

不存在完美的安全，我们保护日益强大模型的工作仍在继续。新的弱点将被发现，绕过现有安全保障的新越狱也会出现。每一代新模型也将创造新的攻击和滥用途径。我们通过分层安全保障、持续监控、快速修复和防御社区的协作来为这一现实构建。对于 GPT‑5.6，我们将现有安全⁠（在新窗口打开）和生物学漏洞赏金计划⁠与新的快速修复流程和我们迄今为止最强的监控工作相结合。来自研究人员、监控和真实世界滥用的发现将持续输入新的评估和更强的安全保障措施。

GPT‑5.6 涵盖三个模型层级：Sol，我们的旗舰；Terra，性能与 GPT‑5.5 相当的较低成本模型；以及 Luna，我们最快且最实惠的模型。数字标识代次，而 Sol、Terra 和 Luna 是持久的能力层级，可以按自己的节奏推进。

GPT‑5.6 从今天起在 ChatGPT、Codex 和 OpenAI API 中可用。全球推出从现在开始，将在未来 24 小时内逐步实现完全可用。

  • Chat： Plus、Pro、Business 和 Enterprise 用户通过中等及更高努力设置访问 GPT‑5.6 Sol。Pro 和 Enterprise 用户还可以选择 GPT‑5.6 Sol Pro，以在复杂任务上获得最高质量的结果。
  • ChatGPT Work 和 Codex： Free 和 Go 用户访问 GPT‑5.6 Terra。Plus、Pro、Business 和 Enterprise 用户可以在 GPT‑5.6 Sol、Terra 和 Luna 之间选择，并为每个模型设置努力级别。max 可供所有在 ChatGPT Work 和 Codex 中访问 GPT‑5.6 的用户使用，并可在设置中切换开启。在 ChatGPT Work 中，ultra 可供 Pro 和 Enterprise 用户使用。在 Codex 中，它可供 Plus 及更高级别计划使用。
  • API： 开发者可以通过 OpenAI API 访问 Sol、Terra 和 Luna。在 Responses API 中，Programmatic Tool Calling 让 GPT‑5.6 在内存中编写和运行程序以协调工具和处理中间结果，使其与零数据保留（ZDR）兼容。Multi-agent 最初以 beta 版提供，让 GPT‑5.6 在单个请求中运行并发子智能体并综合其工作。

GPT‑5.6 按每 100 万 token 定价，分为三个模型规模：Sol 为输入 $5 / 输出 $30；Terra 为输入 $2.50 / 输出 $15；Luna 为输入 $1 / 输出 $6。GPT‑5.6 还引入了更可预测的提示缓存，包括对显式缓存断点⁠（在新窗口打开）的支持和最少 30 分钟的缓存生命周期。对于 GPT‑5.6 及后续模型，缓存写入按模型未缓存输入费率的 1.25 倍计费，而缓存读取继续享受 90% 的缓存输入折扣。
