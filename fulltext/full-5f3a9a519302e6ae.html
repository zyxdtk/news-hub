推出 Claude Opus 4.8

📅 2026-05-28 📄 Anthropic 🔗 原文链接

原标题：Introducing Claude Opus 4.8

中文摘要： Anthropic发布Claude Opus 4.8，该模型在基准测试、智能体任务和诚实度上均有提升，代码缺陷遗漏率降低四倍。同步推出Claude Code动态工作流、claude.ai精力控制及API系统条目更新。Opus 4.8定价不变，快速模式成本大降。此外，Anthropic预告将发布比Opus更智能的Mythos级模型。

我们正在将 Claude Opus 升级到新版本：Claude Opus 4.8。它在 Opus 4.7 的基础上构建，在各项基准测试中均有提升，是一个更高效的协作者。该版本今日上线，价格不变。

Opus 4.8 与几项新功能一同发布。claude.ai 上的用户现在可以控制 Claude 在任务中投入的精力大小。Claude Code 推出了新的“动态工作流”功能，使其能够处理超大规模的问题。此外，Opus 4.8 的快速模式（模型可以 2.5 倍速运行）现在的成本比以前的模型低三倍。

Opus 4.8 的能力

下表展示了 Opus 4.8 与其前身及其他模型在编码、智能体技能、推理和实用知识工作任务测试中的比较。更多细节和更广泛的能力评估请参阅 Claude Opus 4.8 系统卡片。

与 Opus 4.8 协作

早期测试者发现，Claude Opus 4.8 在执行智能体任务时更可靠，判断力更敏锐。以下是许多测试者对与 Opus 4.8 协作体验的评价：

Claude Opus 4.8 的判断力有了显著提升。在 Claude Code 中，它会提出正确的问题，捕捉自身的错误，在计划不靠谱时提出异议，并在进行重大更改前对复杂的多服务探索建立信心。这是一个非常适合用来构建产品的模型。

在我们的 Super-Agent 基准测试中，Claude Opus 4.8 是唯一一个端到端完成所有用例的模型，在成本对等的情况下击败了之前的 Opus 模型和 GPT-5.5。对于翻译、深度研究、幻灯片制作和分析等智能体产品，它提供了强大的可靠性。

在 CursorBench 上，Claude Opus 4.8 在各个精力级别上都超越了之前的 Opus 模型。工具调用的效率显著提高，在同等智能水平下使用更少的步骤，并能将端到端任务执行到底。

Claude Opus 4.8 在我们的法律智能体基准测试中取得了有史以来的最高分，也是第一个在全通过标准上整体突破 10% 的模型。对于实质性的法律工作来说，这种准确性的提升直接转化为我们的客户可以放心交托多少真正的律师工作。

Claude Opus 4.8 感觉像是相对于 Opus 4.7 的一次重大体验升级：更快、更容易协作，并且在长会话中更好地保持上下文和风格方向。Opus 4.8 是我一直信赖的模型，适用于需要同时兼顾语态、品味和技术执行的工作。

Claude Opus 4.8 是我们测试过的最强的计算机使用和浏览器智能体模型，在 Online-Mind2Web 上得分 84%，比 Opus 4.7 和 GPT-5.5 都有显著飞跃。它始终保持反思和专注任务的状态，这正是客户的智能体工作负载实现端到端可靠运行所需要的。

Claude Opus 4.8 干净利落地使用工具，并以我们的自主工程工作负载所需的连续性遵循指令，从而保持无人值守运行。它改进了 Opus 4.6，并修复了我们在 Opus 4.7 中看到的注释冗长和工具调用问题。Anthropic 的这次发布直接转化为在 Devin 上构建的工程师更快的效能提升。

在我们的长时间运行评估中，Claude Opus 4.8 的分析质量始终高于之前的 Opus 模型。它完成得更快，并产生更丰富、信息密度更高的输出。总的来说，信噪比有了显著改善。最大的区别在于 Opus 4.8 倾向于主动标记分析输入和输出中的问题，而其他模型通常会忽略这些问题，留给用户去发现。

在整个 CoCounsel Legal 中，与之前的 Opus 模型相比，Claude Opus 4.8 在一致性和推理质量方面提供了有意义的改进。对于客户所依赖的高风险专业工作流来说，这种可靠性至关重要。随着我们为法律和税务专业人士构建信托级 AI 系统，这样的进步有助于提高现实世界工作流中可信 AI 性能的标准。

Claude Opus 4.8 为企业 AI 设定了新标准。在 Databricks 面向数据和知识工作的 AI 智能体 Genie 中，新的 Opus 模型解锁了智能体推理的阶跃变化，比以往任何 Opus 模型都能更快地处理更深层次的多步问题。其多模态优势还使 Genie 能够直接对 PDF、图表和其他非结构化内容进行推理，而 token 成本比 Opus 4.7 便宜 61%。

对于 Hebbia 编排器中的金融文档工作流，Claude Opus 4.8 提供了与 Opus 4.7 同样强大的质量，但在检索方面具有明显更好的引用精度和更高的 token 效率，这对于我们客户每天处理的那种密集文件来说效果极佳。

Opus 4.8 最显著的改进之一是它的_诚实性_。我们训练所有的模型保持诚实——例如，避免做出它们无法支持的声明。但 AI 模型的一个普遍问题是，它们有时会妄下结论，尽管证据不足，却自信地声称自己取得了进展。早期测试者报告称，Opus 4.8 更有可能标记其工作中的不确定性，而不太可能做出毫无根据的声明。这在我们的评估中得到了证实，评估显示 Opus 4.8 让其编写的代码中的缺陷未被注意到的可能性比其前身低大约四倍。

像往常一样，我们在发布前对模型进行了详细的价值观对齐评估。在积极特质方面，我们的对齐团队得出结论，Opus 4.8“在支持用户自主性和以用户最佳利益行事等亲社会特质的衡量标准上达到了新高”。评估还显示，Opus 4.8 的不良对齐行为（如欺骗或配合滥用）发生率大大低于 Opus 4.7，与我们最对齐的模型 Claude Mythos Preview 相当。完整的对齐评估以及一套部署前的安全测试报告在 Claude Opus 4.8 系统卡片中。

今日同步上线

除了 Claude Opus 4.8，我们还进行了以下更新：
* 动态工作流。这项在研究预览中提供的新功能，允许 Claude 在 Claude Code 中承担更大的任务。Claude 可以规划工作，然后在单个会话中运行数百个并行的子智能体（并且借助 Opus 4.8，智能体可以运行更长时间）。然后它会在向用户报告之前验证其输出。例如，配备 Opus 4.8 的 Claude Code 现在可以执行跨越数十万行代码的代码库级别迁移，从启动到合并，并以现有的测试套件为标准。您可以在这篇文章中阅读有关动态工作流的更多信息——该功能已在 Claude Code 的 Enterprise、Team 和 Max 计划中提供。
* claude.ai 和 Cowork 中的精力控制。模型选择器旁边的一个新控件允许用户选择 Claude 在回复中投入多少精力。在较高的精力设置下，Claude 会更频繁、更深入地思考，以给出更好的回复。在较低的精力设置下，Claude 响应更快，并更慢地消耗用户的速率限制。用户现在有了这种选择——精力控制功能在所有计划中均可用。
* Messages API 现在接受消息数组中的系统条目。 开发人员可以在任务中途更新 Claude 的指令，而不会破坏提示缓存或通过用户轮次路由更新。这可以在给定的运行框架中使用，以便在智能体运行时更新权限、token 预算或环境上下文。

关于精力的说明

Opus 4.8 默认为高精力，我们认为这是质量和用户体验的最佳整体平衡。在编码任务上，该精力级别消耗的 token 数量与 Opus 4.7 的默认值相似，但性能更好。用户可以选择“额外”（在 Claude Code 中为“xhigh”）或“最大”，模型将花费更多 token 以获得更好的结果；我们建议在困难任务和长时间运行的异步工作流中使用“额外”。我们提高了 Claude Code 中的速率限制，以适应较高精力级别较高的 token 使用量；用户可以根据其特定项目选择最合适的级别。

下一步是什么？

用户会发现 Opus 4.8 是对其前身的适度但切实的改进。还有很多工作要做：我们正在努力开发和发布以更低成本提供许多与 Opus 相同能力的模型。

不仅如此，我们还计划发布一类比 Opus 具有更高智能的新模型。作为 Project Glasswing 的一部分，少数组织目前正在使用 Claude Mythos Preview 进行网络安全工作。这种能力级别的模型在普遍发布之前需要更强的网络保障措施。我们正在迅速开发这些保障措施，并预计能在未来几周内将 Mythos 级别的模型带给所有客户。

可用性

Claude Opus 4.8 今日起在全球可用。常规使用定价与 Opus 4.7 相同：每百万输入 token 5 美元，每百万输出 token 25 美元。快速模式的定价为每百万输入 token 10 美元，每百万输出 token 50 美元。开发人员可以通过 Claude API 使用 claude-opus-4-8。
