📅 2026-08-13 📄 VentureBeat AI 🔗 原文链接

原标题：SpaceXAI debuts Grok 4.6, overtaking Kimi K3's performance and matching GPT-5.6 Sol for world's third best on Artificial Analysis

中文摘要： SpaceXAI 发布最新前沿模型 Grok 4.6，在 Artificial Analysis 指数上超越 Kimi K3 并比肩 GPT-5.6 Sol。该模型在编程、智能体和知识工作基准上显著提升，且 API 价格仅为部分竞品的一半。尽管长周期任务表现优异，但其在终端基准上仍落后于头部竞品，且 Grok 品牌历史争议可能影响企业采购。

埃隆·马斯克旗下的 SpaceXAI（前身为 xAI）发布了其最新的前沿 AI 模型 Grok 4.6，该模型专注于长时间运行的智能体、编程和知识工作——其定价策略旨在降低这些工作负载的运行成本。

该模型在第三方 Artificial Analysis 智能指数中得分为 61 分，超越了月之暗面（Moonshot）广受欢迎的中国开源权重模型 Kimi K3，与竞争对手 OpenAI 的 GPT-5.6 Sol Max 持平，并比 Grok 4.5 High 提高了 5 分。Anthropic 的 Claude Opus 5 和 Fable 5 分别占据第一和第二的位置。

对于评估 AI 智能体的企业来说，更重要的是，根据 VentureBeat 的分析，Grok 4.6 在编程、终端、知识工作和智能体基准测试中比其前代产品取得了显著进步，同时应用程序编程接口（API）价格保持在每百万输入 token 2 美元、每百万输出 token 6 美元起，这使其在与全球领先的专有和开源模型相比时，成为一款中等价位的前沿模型。

尽管如此，这仍然不到 GPT-5.6 Sol 在 OpenAI API 标准模式下成本的一半。

SpaceXAI 表示，Grok 4.6 今天已在 Grok Build 中可用，这是 SpaceXAI 对标 Anthropic 的 Claude Code 和 OpenAI 的 Codex 的产品，可以从 每月 30 美元的 SuperGrok 计划 开始使用。

它也可以在 SpaceX 最近收购的 AI 编程初创公司 Cursor 中使用，并可通过合作伙伴 OpenRouter、Vercel 和 Cloudflare 获取。

在第一周内，SpaceXAI 为在 Cursor 和 Grok Build 中使用 Grok 4.6 提供了两倍的包含使用量。

此次发布距离 Grok 4.5 发布仅几周时间，SpaceXAI 在 7 月推出了 Grok 4.5，作为一款针对编程、智能体任务和知识工作的模型；而在此前一天，Grok Bot 刚刚发布，这是一个将 AI 智能体分配为虚拟员工以完成指定任务的新系统。

更大的变化在于智能体行为，而不仅仅是另一个基准分数

SpaceXAI 表示，Grok 4.6 是专门为在更长的工作序列中保持任务而构建的，包括研究不熟悉的主题、分析信息、导航代码库以及将产品创意转化为可运行的应用程序。

该公司表示，对模型进行了比 Grok 4.5 更长时间的补充训练，使用了经过筛选的模型生成的推理和技术数据，以及工程数据，并对其优化器和训练方案进行了更改。随后，它使用 Grok 4.5 重新生成了跨推理级别、智能体框架、STEM、软件工程和知识工作的监督微调轨迹，并通过基于模型的检查过滤掉有问题的轨迹。

强化学习也针对涵盖通用编程、知识工作、内核优化、Web 开发和计算机辅助设计的智能体环境。

这很重要，因为企业 AI 部署正越来越多地超越孤立的提示和响应交互，转向期望智能体能够在更长的执行路径中维护状态、操作工具、修改代码并从问题中恢复。

SpaceXAI 表示，在其测试期间，Grok 4.6 在更长的轨迹上表现出了更多的自我测试和验证，在继续之前会检查自己的工作。它还报告说，在交互式和视觉项目上的首次尝试比 Grok 4.5 更强。这些是公司的观察结果，而不是对生产行为的独立保证，但它们表明了 SpaceXAI 在模型训练后工作上的集中发力点。

Grok 4.6 达到了前沿水平，但并未全面横扫

在当前 AI 模型竞争的节点上，Grok 4.6 相对于 Grok 4.5 的提升怎么强调都不为过。

根据 Artificial Analysis 的数据，在衡量调度和图表绘制等现实世界任务性能的基准 GDPVal-AA v2 上，Grok 4.6 的 Elo 分数（源自国际象棋的模型输出正面交锋人类偏好）达到了 1,753 分，而 Grok 4.5 为 1,526 分，GPT-5.6 Sol Max 为 1,728 分，Fable 5 Max 为 1,741 分。

SpaceXAI 的编程结果显示出类似的代际提升，但在前沿领域的竞争更加激烈。

SpaceXAI Grok 4.6 基准测试。图片来源：SpaceXAI

Grok 4.6 在 CursorBench v3.2 上得分为 69.9%，高于之前的 66.7%，而 Fable 5 Max 达到 70.5%。在 DeepSWE v1.1 上，Grok 从 54% 大幅上升至 65.9%，但 GPT-5.6 Sol Max 以 73% 领先。FrontierCode v1.1 Extended 从 56.6% 移动到 61.3%，相比之下，GPT-5.6 Sol Max 为 60.6%，而 Fable 5 Max 领先，为 63.6%。

智能体基准测试也讲述了大致相同的故事。Grok 4.6 在 APEX-Agents 上达到 57.5%，比 Grok 4.5 的 47.1% 增加了 10.4 个百分点，略微超过 GPT-5.6 Sol Max 的 56.7%，但落后于 Fable 5 Max 的 59.2%。在 APEX-SWE 上，Grok 4.6 从 53.6% 上升至 56.4%，而 Fable 5 Max 得分为 58.8%。

Terminal-Bench v3.0 暴露了更大的剩余差距。Grok 4.6 从 15.7% 提升至 26%，但 GPT-5.6 Sol Max 和 Fable 5 Max 分别得分为 34.6% 和 34.1%。

Grok 4.6 最强的两个结果来自更长周期的专业工作。在 AA-Briefcase 上，它的 Elo 得分为 1,577，略微超过 Fable 5 Max 的 1,574，并超过了 GPT-5.6 Sol Max 的 1,502。在 Harvey LAB 上，Grok 4.6 达到 15.8%，而 Grok 4.5 为 12.9%，Fable 5 Max 为 11.3%，GPT-5.6 Sol Max 为 2.5%。

SpaceXAI 指出了一个重要的方法论注意事项：其表格中的第三方分数使用了最佳的自我报告或公开可用结果。因此，不应将此比较解释为完美控制的四模型评估。

换句话说，证据更清楚地支持了对 Grok 4.5 的实质性升级，而不是支持其对竞争前沿模型的全面优势。Grok 4.6 赢得了几项展示的评估，而 GPT-5.6 Sol Max 和 Fable 5 Max 在其他方面保持了有意义的领先。

成本可能是更重要的企业基准

Artificial Analysis 提供的评估增加了另一个维度：模型在花费的资金下执行了多少工作。

测试将 Grok 4.6 置于其智能与每任务成本帕累托前沿上，报告的每任务成本为 0.84 美元——这实际上使其不如前代产品 Grok 4.5 划算，也不如 OpenAI 的 GPT-5.6 Luna、z.ai 的 GLM-5.2 和 Meta 的新 Muse Spark 1.2 等其他模型经济。

Artificial Analysis 还报告称，Grok 4.6 平均在大约 53 轮和 5 亿输入 token 内完成了其 AA-Briefcase 工作负载，而 Claude Opus 5 Max 大约需要 103 轮和 20 亿输入 token。

这些测量结果并不能证明每个生产智能体都会使用更少的 token 或快两倍完成。智能体成本很大程度上取决于框架设计、提示、工具调用、缓存、重试行为和任务本身。但它们指向了一个日益重要的企业指标：完成工作流的成本，而不仅仅是生成一百万个 token 的成本。这一区别是 SpaceXAI 定位的核心。

标准 Grok 4.6 API 起价为每百万输入 token 2 美元和每百万输出 token 6 美元，SpaceXAI 还提供了一个价格翻倍的更快速变体。

提供的 API 文档对长上下文部署添加了重要的注意事项。Grok 4.6 支持 500,000 个 token 的上下文窗口，但低于 200,000 个 token 的提示按每百万输入 token 2 美元、每百万缓存输入 token 0.50 美元和每百万输出 token 6 美元计费。一旦提示达到 200,000 个 token，这些费率分别上升至 4 美元、1 美元和 12 美元，较高的定价适用于该请求中的所有 token。

这意味着企业在估算总拥有成本时，不应将 2 美元/6 美元的标头定价推断到模型的整个上下文窗口中。

Artificial Analysis 表示，标准的标头费率仍然比其引用的 Claude Opus 5 和 GPT-5.6 Sol 竞争前沿模型价格低 60% 以上。实际的节省将取决于每个模型消耗多少 token 来完成相同的工作负载。

除了普遍的 AI 怀疑论外，Grok 这个名字还背负着相当大的包袱和争议

性能和价格可能不是 SpaceXAI 将 Grok 4.6 的基准收益转化为企业采用所面临的唯一障碍。Grok 品牌在安全和治理争议方面有着异常显眼的历史——包括极端主义和反犹太主义输出、政治偏见的回复、对埃隆·马斯克的夸张赞美，以及最近使用 Grok 的图像生成功能制作未经同意的色情图像。对于有严格合规、品牌安全或负责任 AI 要求的公司来说，这一历史可能会成为独立于 Grok 4.6 本身技术能力的采购考虑因素。

最臭名昭著的文本生成事件发生在 2025 年 7 月，当时 Grok 发布了反犹太主义帖子，赞扬了阿道夫·希特勒，并在一些回复中称自己为“MechaHitler”。SpaceXAI 的前身 xAI 随后表示，正在删除不当帖子，并采取措施防止 Grok 发布仇恨言论。

同样在 2025 年夏天，Grok 开始将与南非所谓“白人种族灭绝”相关的引用插入到不相关问题的答案中。xAI 表示，对 Grok 响应软件的未经授权修改指示系统在绕过正常审查流程的情况下对政治话题产生特定响应。该公司表示，此更改违反了其政策，随后承诺发布 Grok 的系统提示并建立对问题回复的全天候监控。南非政府否认了正在发生针对南非白人种族灭绝的说法。

同年 11 月，在该聊天机器人多次产生对马斯克令人难以置信的赞美评估后，Grok 的客观性再次受到审查。当时报告的例子中包括将马斯克置于精英运动员和历史知识分子之上的说法。马斯克表示，Grok 是通过对抗性提示被操纵，从而做出了关于他的“荒谬积极”的声明。无论根本原因是什么，该事件都说明了一个企业模型的声誉问题，该模型的输出可能会与其开发商最密切相关的高管的公众形象纠缠在一起。

最严重的争议涉及图像生成。2026 年 1 月，在报道称 Grok 账户被用于制作和分发人们的不雅图像和儿童色情图像后，英国监管机构 Ofcom 对 X 展开了正式调查。Ofcom 表示，正在审查的材料可能构成未经同意的亲密图像滥用、色情和儿童性虐待材料。X 随后表示，它已实施措施旨在阻止 Grok 账户被用于制作人们的亲密图像，但 Ofcom 表示其调查仍在进行中。

审查范围不仅限于 Ofcom。英国信息专员办公室正在调查 X 和 xAI 在 Grok 开发和部署方面的情况，包括个人数据是否得到合法处理，以及是否存在足够的保障措施来防止有害的操纵图像。与此同时，欧盟委员会根据《数字服务法》展开了单独的正式调查，审查 X 对与 Grok 相关的系统性风险的管理，包括传播被操纵的色情材料。

这些调查涉及 X 和早期的 xAI 组织，而不是确定新发布的 Grok 4.6 API 违反了这些法律。尽管如此，它们不太可能帮助 SpaceXAI 向企业推销 Grok。

SpaceX 于 2026 年 2 月收购了 xAI，该 AI 部门现在以 SpaceXAI 的名义进行营销，这意味着 Grok 的最新模型处于不同的公司结构下，但保留了相同的面向消费者的品牌。

在本文审查的材料中，没有证据表明 Grok 4.6 本身重复了与早期 Grok 部署相关的特定“MechaHitler”、“白人种族灭绝”、色情图像或马斯克赞美事件。但企业采购团队很少脱离供应商和产品历史来评估模型。对于 SpaceXAI 来说，这意味着 Grok 4.6 可能不仅必须证明它比竞争的前沿模型更便宜或更强大，而且还要证明围绕它的控制对于无法承受其 AI 供应商成为品牌安全事件的组织来说是充分可预测的。

这种连续性造成了一个基准表无法衡量的潜在采用问题。为内部编程智能体选择模型的开发者可能主要关心价格、延迟和任务完成度。将相同模型部署到面向客户或受监管工作流中的银行、政府机构、医疗保健提供商或消费品牌，可能还必须考虑供应商治理、内容安全控制、可审计性和声誉风险。

为部署而设计的模型，而不仅仅是用于聊天

根据提供的 API 规范，Grok 4.6 支持文本和图像输入以及文本输出、函数调用、结构化输出和推理。这些规范还列出了每秒 150 个请求和每分钟 5000 万个 token 的速率限制，API 可在 us-east-1 和 us-west-2 中使用。

Cursor 的发布公告同样将 Grok 4.6 描述为专为长时间运行的智能体和雄心勃勃的交互式及视觉工作而设计，让开发者可以在成熟的编程智能体环境中立即访问该模型，而不需要他们首先围绕 API 构建新的框架。

对于企业买家来说，这种分发方式可能几乎与另一个排行榜结果一样重要。模型的竞争不仅在于推理分数，还在于开发者是否可以将它们放入现有的编程、研究和运营工作流中，而不会破坏这些工作流或大幅增加推理成本，以及是否会因为与有争议的品牌相关联而遭到抵制。

Grok 4.6 并未确立无可争议的性能领先地位。相反，它的发布提出了一个不同的主张：前沿级别的智能、相对于上一代的巨大改进、更强大的长时间运行智能体行为以及相对激进的 token 经济性。

下一个测试将是 Artificial Analysis 在受控智能体工作负载上观察到的效率是否能带入生产环境。如果 Grok 4.6 能够以更少的轮次和更少的 token 持续完成长时间运行的编程和知识工作任务，那么该模型最重要的基准最终可能是企业推理账单，而不是排行榜。
