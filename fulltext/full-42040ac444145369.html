强制长期覆盖的代价：在线保形预测中的相变

作者： Yu Gui（宾夕法尼亚大学沃顿商学院统计与数据科学系）、Rina Foygel Barber（芝加哥大学统计系）、Cong Ma（芝加哥大学统计系）

摘要

考虑一个在线预测设置，其中在每个时刻，我们获得一个新的特征向量，并被要求提供一个可能包含相应响应的预测区间或预测集。在此设置中，如果数据点是独立同分布的（或更一般地，可交换的），保形预测提供了一种在任何训练模型输出周围构建有效预测集的机制，在每个时刻 t 提供覆盖率 ≥ 1−α。然而，在实践中，分布漂移、变点或其他挑战等问题可能导致违反独立同分布假设。在这种对抗设置中，在线保形预测方法仍然可以提供长期经验覆盖的保证。然而，这两类目标之间存在权衡：在对抗设置中强制对长期经验覆盖施加严格约束，可能导致独立同分布设置中瞬时训练条件覆盖的不稳定振荡。

在这项工作中，我们寻求“两全其美”的算法，旨在在独立同分布设置中最小化瞬时训练条件覆盖的累积误差，同时在对抗设置中提供长期经验覆盖保证。具体而言，考虑一个要求长期经验覆盖与目标水平 1−α 的偏差不超过 𝒪(T^(−β)) 的条件，其中 β ∈ [0,1]。我们证明这一族条件可以用相变来描述。对于 β ∈ [0, 1/2]，可以在对抗设置中构造满足此类约束的算法，同时在数据实际为独立同分布时提供与分裂保形预测相同的瞬时覆盖性能。另一方面，对于 β ∈ (1/2, 1]，这种类型的条件是有代价的，无法实现两全其美的行为。

1 引言

考虑一个在线不确定性量化问题，其中每个数据点由特征 X_t ∈ 𝒳 和响应 Y_t ∈ 𝒴 组成。对于每个时刻 t ≥ 1，令 𝒞_t 表示任何预先指定的构造，将观测数据流映射到时刻 t 的数据点的预测集。具体地，我们写

𝒞_t(X_t) = 𝒞_t(X_t; (X_1,Y_1), …, (X_(t−1),Y_(t−1))) ⊆ 𝒴　　(1)

表示在数据点 (X_1,Y_1), …, (X_(t−1),Y_(t−1)) 上训练时，时刻 t 的预测集。当前结果 Y_t 在集合构建时不可用。在本文中，我们使用记号 𝒞 = (𝒞_t)(t≥1) 表示产生预测集序列 (𝒞_t(X_t))(t≥1) 的在线算法。

在 Y_t 被揭示后，预测集的性能可以由二元误覆盖指示符概括：

e_t = 1{Y_t ∉ 𝒞_t(X_t; (X_1,Y_1), …, (X_(t−1),Y_(t−1)))}。

我们期望预测集经常覆盖真实响应 Y_t，由名义覆盖水平 1−α ∈ (0,1) 量化。为了量化这一点，我们可以要求每个时刻的覆盖概率是校准的——即 ℙ(e_t ≠ 1) 或给定历史条件下的覆盖率 ≈ 1−α，在每个时刻 t。然而，这种类型的保证只能在对数据流的某些假设下实现。更一般地，我们可以转而追求较弱的保证，要求经验平均覆盖率在一段时间内 ≈ 1−α。我们在以下小节中正式定义并讨论这两个保证。

1.1 独立同分布设置：瞬时训练条件覆盖

当数据点 (X_t, Y_t) 独立同分布（或可交换）时，分裂保形预测使用过去的得分来校准预测集。得分函数是固定的或拟合于独立数据，较高的得分表示与拟合模型的偏差更大。具体地，对于固定的得分函数 s: 𝒳 × 𝒴 → ℝ，分裂保形预测集可以定义为

𝒞_t^CP(x) = {y ∈ 𝒴 : (1 + Σ_(r<t) 1{s(X_r,Y_r) ≥ s(x,y)})/t > α}。　　(2)

可交换性给出有限样本边缘覆盖保证，即 ℙ(Y_t ∈ 𝒞_t^CP(X_t)) ≥ 1−α。

更局部的要求是询问在每个时刻 t 给定观测的过去，覆盖是否接近 1−α。对于独立同分布观测和非原子得分分布¹，(2) 中的分裂保形预测集满足以下界限 (Vovk, 2012; Angelopoulos et al., 2024a)：

𝔼_ℙ |ℙ{Y_t ∈ 𝒞_t^CP(X_t) | (X_s,Y_s)_(s<t)} − (1−α)| ≤ 1/(2√(t+1)) + 1/t。　　(3)

¹ 如果概率测度 μ 满足：对于任何满足 μ(A) > 0 的可测集 A，存在 A 的可测子集 B 使得 μ(A) > μ(B) > 0，则该分布是非原子的。

因此，在这些假设下，分裂保形预测的瞬时训练条件覆盖，即给定历史 (X_s,Y_s)_(s<t) 在时刻 t 的覆盖，在期望中偏离目标水平 1−α 至多 O(t^(−1/2))。为了测量 T 轮内的这种偏差，对于任何在线算法 𝒞，我们定义

Δ_T^inst(𝒞) := Σ_(t=1)^T 𝔼_ℙ |ℙ{Y_t ∈ 𝒞_t(X_t) | (X_s,Y_s)_(s<t)} − (1−α)|。　　(4)

取 𝒞 = 𝒞^CP，对 t 求和 (3) 得到 Δ_T^inst = O(√T)。

1.2 对抗设置：长期经验覆盖

当不假设可交换性时，一个广泛采用的衡量在线算法对抗性能的量是长期累积覆盖偏差 (Gibbs and Candès, 2021)：

Σ_(t=1)^T [1{Y_t ∈ 𝒞_t(X_t)} − (1−α)] = Σ_(t=1)^T (α − e_t)。　　(5)

这里，我们记 E_T = Σ_(t=1)^T (e_t − α)，其中 |E_T|/T 追踪长期经验覆盖率偏离 1−α 的程度。一个校准良好的算法保持 |E_T| 相对于 T 较小。这种保证可以由一大类算法实现，而无需对数据序列 {(X_t, Y_t), t ≥ 1} 施加分布假设。

为了量化对抗设置中的长期经验覆盖保证，如果

|E_T|/T ≤ κ T^(−β)　对所有 T ≥ 1，　　(6)

我们说算法满足 (β, κ)-约束。在本文中，β ∈ [0,1] 且 κ ≥ 1/2，因此区间宽度至少为一，并且在每轮都存在可行的误差结果。注意，如果 β = 0 且 κ ≥ max{α, 1−α}，则约束对任何序列 (e_t)(t≥1) 平凡地成立。对于 β > 0，这意味着长期经验覆盖率收敛到 1−α。较大的 β 要求对长期经验覆盖率更严格的控制。我们使用 𝒜(β,κ) 表示满足 (6) 的所有算法的集合。

² 为了表述简单，我们在对称约束下呈现主要理论结果，并在附录 A 中给出它们的非对称对应。我们同样可以定义非对称约束：如果 E_T/T ∈ [−c_− T^(−d), c_+ T^(−b)]，我们说算法满足 (b, d, c_−, c_+)-约束。我们使用 𝒜_(b,d,c_−,c_+) 表示此类算法。相同的相变在非对称设置中成立，其中 min{b,d} 扮演 β 的角色：极小极大预言机分歧的阶为 T^max{1/2, min{b,d}}。

我们的核心问题是，当数据独立同分布时，𝒜_(β,κ) 中的算法能在多大程度上接近给定历史的精确覆盖。由 (3)，分裂保形预测的瞬时训练条件覆盖在第 t 轮期望中在 1−α 的 O(t^(−1/2)) 范围内，因此其累积偏差在 T 轮内求和为 O(√T)，即对于 𝒞 = 𝒞^CP，Δ_T^inst = O(√T)。然而，对于非平凡约束，分裂保形预测不必属于 𝒜_(β,κ)。我们证明 𝒜_(β,κ) 中的算法对于独立同分布数据可以保证的瞬时训练条件覆盖的最小累积误差的阶为

T^max{1/2, β} = {√T, 0 ≤ β ≤ 1/2; T^β, 1/2 < β ≤ 1}。　　(7)

因此，当 β ≤ 1/2 时，约束在速率上不产生代价，而当 β > 1/2 时，速率由约束主导，在 β = 1/2 处产生相变。

1.3 重访自适应保形推断（ACI）

自适应保形推断（ACI）由 Gibbs and Candès (2021) 引入，是在每个数据序列上强制长期经验覆盖的一种方法。我们考虑其分位数阈值形式 (Angelopoulos et al., 2024b; Angelopoulos et al., 2024a)，它使用固定的得分 s: 𝒳 × 𝒴 → ℝ 并构造

𝒞_t^ACI(x) = {y : s(x,y) ≤ q_t}。

在观测到结果后，ACI 通过以下方式更新其阈值

q_(t+1) = q_t + η_t(e_t − α)，　　(8)

其中 η_t > 0 是步长。我们注意到原始的 ACI 程序 (Gibbs and Candès, 2021) 更新名义覆盖水平。这里我们分析分位数阈值更新 (8)。阈值在误覆盖后增加，在覆盖后减少。步长决定 ACI 在对抗情形中控制累积覆盖偏差的紧密程度。

更具体地，当 s(x,y) ∈ [0,B]，η_t ≡ η（即常数步长），且 q_1 ∈ [0,B] 时，ACI 在对抗设置中具有长期经验覆盖保证 (Gibbs and Candès, 2021; Angelopoulos et al., 2024b)

|E_T| = |Σ_(t=1)^T (e_t − α)| ≤ (B + η)/η，

表明 ACI 满足 β = 1 且常数足够大以支配 (B+η)/η 的约束。

1.4 两全其美的算法？

回顾分裂保形预测满足 (3) 但可能在某些数据序列上违反 (6)。常数步长的 ACI 满足 (6)，但其阈值在每次观测后至少移动 η min{α, 1−α}，因此即使对于独立同分布数据，其瞬时训练条件覆盖也会持续波动。由于很少事先知道数据是否独立同分布，我们寻求一个单一算法，在每个数据序列上满足长期约束，并且当数据独立同分布时，保持其瞬时训练条件覆盖尽可能接近 1−α。我们称这样的算法为“两全其美”的。

对于 ACI，这一目标建议保持其长期经验覆盖界限，同时减小每次阈值更新的幅度，即指定衰减步长 (Angelopoulos et al., 2024b)。具体地，当 s(x,y) ∈ [0,B]，q_1 ∈ [0,B]，且 η_t = c t^(−(1−β))，其中 c > 0 且 0 < β < 1 时，Angelopoulos et al. (2024b, Theorem 1) 的界限给出

|E_T|/T ≤ ((B+c)/c) T^(−β)　对每个 T ≥ 1。　　(9)

因此 ACI 在每个数据序列上满足 κ = (B+c)/c 的 (β, κ)-约束。步长更快的衰减对应于更小的 β 和更弱的长期经验覆盖保证。

在具有固定有界得分（其 CDF 连续且 (1−α)-分位数唯一）的独立同分布抽样下，步长 η_t = c t^(−(1−β))（其中 0 < β < 1/2）使得工作分位数 q_t 几乎必然收敛到总体 (1−α)-分位数 (Angelopoulos et al., 2024b, Theorem 3)。瞬时训练条件覆盖随后也收敛到 1−α。连同公式 9，这在渐近意义上给出了两个保证。

每个新的观测都会使 ACI 的阈值改变与 η_t 成比例的量，即使阈值收敛到总体分位数。较大的 β 产生更紧密的长期经验覆盖，但使这些更新衰减得更慢，这引出了瞬时训练条件覆盖随时间累积多少误差的问题。更具体地，对于第 3 节中得分密度假设下的独立同分布数据，第 3 节量化了这一代价。取 η_t = c t^(−(1−β)) 且 0 < β < 1，它给出

Σ_(t=1)^T 𝔼_ℙ |ℙ{Y_t ∈ 𝒞_t^ACI(X_t) | (X_s,Y_s)_(s<t)} − (1−α)| ≍ T^((1+β)/2)。　　(10)

对于每个 0 < β < 1，该速率超过 (3) 中分裂保形预测的 O(√T) 界限。然而，分裂保形预测本身并不在每个序列上强制长期对抗约束。这促使我们提出问题：在长期经验覆盖约束下，瞬时训练条件覆盖中可实现的最小累积误差是多少？

图 1 说明了合成数据集（第 4 节）中的权衡，其中固定的得分按构造在 [0,1] 上均匀分布。我们比较 β ∈ {1, 0.8, 0.6, 0.4} 的 η_t = t^(−(1−β))，包括 β = 1 时的常数步长。在面板 中，我们关注量化 ACI 预测集与总体得分预言机之间预期分歧的度量；正式定义在第 2 节中给出。在这个实验中，较大的 β 使累积覆盖偏差更接近零，但瞬时训练条件覆盖波动更大，且时间平均的预言机分歧减少得更慢。这些观察留下了 ACI 的统计代价在多大程度上是覆盖约束所必需的，以及多少来自其自身算法设计的问题。

核心问题。 受上述权衡的启发，在长期经验覆盖约束下，多少瞬时训练条件覆盖误差是不可避免的，这仍然是一个开放问题。我们的目标是找到一个提供“两全其美”保证的算法：它在每个数据序列上满足规定的长期经验覆盖约束，并在数据独立同分布时实现最佳统计性能。为了使这一目标精确，我们将算法与知道数据分布且给定过去具有精确覆盖 1−α 的预言机进行比较。它们的累积分歧计算观测响应恰好属于其预测集之一的轮数。我们的核心问题是：单一算法在独立同分布抽样下能在多大程度上匹配精确预言机，同时在每个数据序列上满足规定的长期经验覆盖约束？特别地，分裂保形预测的 √T 累积速率能否保留，更紧密的长期经验覆盖何时迫使更高的代价？我们寻求最小可能的代价以及在不知道数据分布或观测是否独立同分布的情况下实现它的算法。

论文组织。 第 2 节形式化预言机分歧，并将近似预言机的难度与长期经验覆盖约束的代价分开。对于所有精确预言机族，在具有固定得分非原子分布的独立同分布律下，我们证明 T^max{1/2,β} 的极小极大速率，并仅在需要强制约束时通过截断分裂保形预测来实现它。因此 √T 速率对于 β ≤ 1/2 得以保留，而更紧的约束必然增加速率。第 3 节表明，在所述密度假设下，步长与 t^(β−1) 成比例的固定得分 ACI 对于 0 < β < 1 产生更大的代价。

2 对抗约束下的预言机分歧

回顾第 1 节中引入的设置。我们使用 𝒜 表示 (1) 中与未知数据分布无关的可测在线算法类。在第 t 轮，在线算法 𝒞 使用过去的观测 (X_r,Y_r)(r<t) 和当前特征 X_t 在观测 Y_t 之前构造预测集 𝒞_t(X_t) ⊆ 𝒴。记 e_t^𝒞 = 1{Y_t ∉ 𝒞_t(X_t)} 且 E_T^𝒞 = Σ(t=1)^T (e_t^𝒞 − α)。对于数据序列 (X_t,Y_t)(t∈ℕ) 的固定联合分布 ℙ，为了使条件清晰，我们定义 𝒢(t−1) = σ((X_r,Y_r)_(r<t))。

³ 需要时，我们使用 ζ_(1:t) = (ζ_1, …, ζ_t)（与数据独立）来收集直到时刻 t 的辅助随机化。在本文中，这里考虑的所有算法和预言机都是观测数据的确定性可测函数。

在本节中，我们正式量化在线算法的瞬时训练条件性能。为了定义该度量，我们在时刻 t 将每个预测集 𝒞_t(x) 与在每个 t 瞬时训练条件覆盖精确校准的预言机进行比较。具体地，预言机 𝒞_ℙ^* 可以知道 ℙ，使用与 𝒞 相同的可用信息，并满足

预言机的定义： ℙ(Y_t ∈ 𝒞_(ℙ,t)^*(X_t) | 𝒢_(t−1)) = 1−α　几乎必然对每个 t ≥ 1。　　(11)

作为一个例子，在具有可测得分函数 s: 𝒳 × 𝒴 → ℝ 的独立同分布抽样下，如果 s(X_1,Y_1) 的分布是非原子的，令 F_(ℙ,s) 为其 CDF 并设

q_(ℙ,s) = inf{q : F_(ℙ,s)(q) ≥ 1−α}，　𝒞_(ℙ,s,t)^*(x) = {y : s(x,y) ≤ q_(ℙ,s)}。　　(12)

数据序列的独立性和 F_(ℙ,s) 的连续性给出预言机条件 (11)。我们注意到，一般而言，𝒞_ℙ^* 的存在需要对联合分布 ℙ 的正则性条件，为简单起见，除非另有说明，我们在本文中假设 ℙ 是非原子的。

为了评估两个在线算法，我们通过以下方式测量它们在同一数据序列上的累积分歧

ℓ_T(𝒞, 𝒞′) = Σ_(t=1)^T |e_t^𝒞 − e_t^𝒞′|。　　(13)

这计算恰好属于两个集合之一的响应。然后，与预言机 𝒞_ℙ^ 的预期分歧，即 𝔼_ℙ[ℓ_T(𝒞, 𝒞_ℙ^)]，量化算法 𝒞 = (𝒞_t)(t∈ℕ) 在给定数据分布 ℙ 下的瞬时训练条件性能。对于 p_t^𝒞 = ℙ(e_t^𝒞 = 1 | 𝒢(t−1))，条件 Jensen 不等式进一步给出

𝔼_ℙ ℓ_T(𝒞, 𝒞_ℙ^) ≥ Σ_(t=1)^T 𝔼_ℙ |p_t^𝒞 − α| = Δ_T^inst　对每个精确预言机 𝒞_ℙ^。　　(14)

当两个预测集耦合时等号成立，即集合由同一得分上的两个阈值定义，其截断值由过去数据确定。

2.1 长期经验覆盖约束下匹配预言机的困难

令 𝒬̃ 为数据序列 (X_t,Y_t)_(t∈ℕ) 上所有独立同分布联合律的类。固定可测得分 s: 𝒳 × 𝒴 → ℝ，令 𝒬 = {ℙ ∈ 𝒬̃ : s(X_1,Y_1) 在 ℙ 下具有非原子分布}。我们假设 𝒬 非空。对于每个 ℙ ∈ 𝒬，令 𝒪_α(ℙ) 表示满足预言机条件 (11) 的算法集合。特别地，该族包括 (12) 中定义的总体得分预言机。我们通过以下方式测量算法的性能

sup_(ℙ∈𝒬) inf_(𝒞_ℙ^∈𝒪_α(ℙ)) 𝔼_ℙ ℓ_T(𝒞, 𝒞_ℙ^)。　　(15)

下确界允许每个算法和律有单独的预言机，而不让算法访问预言机或分布。在本文中，≲、≳ 和 ≍ 比较在所有足够大的 T 下相差正常数的量。

匹配预言机是困难的，原因有二。算法必须从未知分布中学习，并保持其实际误差在规定界限内。以下结果将这两种代价分开。

定理 2.1 在上述设置下，每个 𝒞 ∈ 𝒜_(β,κ) 满足

sup_(ℙ∈𝒬) inf_(𝒞_ℙ^∈𝒪_α(ℙ)) 𝔼_ℙ ℓ_T(𝒞, 𝒞_ℙ^) ≥ C_(α,β,κ) T^max{1/2,β}，　　(16)

对于足够大的 T，其中 C_(α,β,κ) > 0 仅依赖于 α, β, κ。

更一般地，下界可以分解为

sup_(ℙ∈𝒬) inf_(𝒞_ℙ^∈𝒪_α(ℙ)) 𝔼_ℙ ℓ_T(𝒞, 𝒞_ℙ^) ≳ inf_(𝒞⁰∈𝒜) sup_(ℙ∈𝒬) inf_(𝒞_ℙ^∈𝒪_α(ℙ)) 𝔼_ℙ ℓ_T(𝒞⁰, 𝒞_ℙ^) [≍√T] + {0, 0 ≤ β < 1/2; T^β, 1/2 ≤ β ≤ 1}。　　(17)

第一项是从过去数据学习的不可避免代价。即使没有长期经验覆盖约束，没有算法可以在 𝒬 上一致地实现小于 √T 阶的分歧。当允许与每个精确预言机比较时，这仍然成立。分裂保形预测通过估计总体得分分位数达到该阶。第二项是强制长期经验覆盖约束的代价。精确校准并不能阻止预言机的实际误差波动：其中心化误差和的标准差为 √(α(1−α)T)。然而，约束只允许 κ T^(1−β) 的偏差。当 β ≥ 1/2 时，将误差保持在这些界限内需要反复偏离预言机。这些偏离迫使至少 T^β 阶的累积分歧，即使分布已知。较高的代价决定下界速率，在 β = 1/2 处呈现尖锐的相变。学习未知分布的代价在 β < 1/2 时占主导，两种代价在 β = 1/2 时均为 √T 阶，长期经验覆盖约束在 β > 1/2 时占主导。在下一小节中，我们构造在这两种情形下都达到该速率的算法。

如果分布不是非原子的，可能没有满足条件 (11) 的预言机，但我们可以通过考虑松弛的预言机以不同方式处理问题；见附录 E。

2.2 截断达到极小极大速率

在本节中，我们给出在 2.1 节中具有匹配上界的在线算法的显式在线构造。固定可测得分 s: 𝒳 × 𝒴 → ℝ。回顾 𝒪_α(ℙ) 表示满足 (11) 的预言机算法集合，且在 ℙ ∈ 𝒬 下，得分 s(X_t,Y_t) 的分布是非原子的。为了满足长期经验覆盖约束，一种直接的方法是截断累积误覆盖误差 E_T 并在每一步强制对抗约束。具体地，对于任何基线 𝒞⁰，定义 𝒞̂ = Γ_(κ,β) ∘ 𝒞⁰，从 E_0^𝒞̂ = 0 开始递归地，

(Γ_(κ,β) ∘ 𝒞⁰)t(x) = 𝒞̂_t(x) = {𝒴, 若 E(t−1)^𝒞̂ + 1 − α > κ t^(1−β)； ∅, 若 E_(t−1)^𝒞̂ − α < −κ t^(1−β)； 𝒞_t⁰, 否则}。　　(18)

如果第 t 轮的潜在误覆盖会将累积偏差推到其上界之上，我们输出 𝒴 以确保覆盖。类似地，如果覆盖会将 E_t^𝒞̂ 推到其下界之下，我们输出 ∅ 以强制误覆盖。否则，任一结果都遵守界限，因此我们保持基线预测集。E_t^𝒞̂ 由 𝒞̂ 的误差计算，而基线 𝒞⁰ 继续使用每个观测，包括其集合被其截断对应物替换的轮次的观测。对于 κ ≥ 1/2，两个强制条件不能同时成立，并且所得预测集在每个数据序列上满足 (6)。

以分裂保形预测为基线，该截断达到预期预言机分歧的极小极大速率，如下列定理所示。

定理 2.2 单一算法 Γ_(κ,β) ∘ 𝒞^CP ∈ 𝒜_(β,κ) 达到上界：

sup_(ℙ∈𝒬) inf_(𝒞_ℙ^∈𝒪_α(ℙ)) 𝔼_ℙ ℓ_T(Γ_(κ,β) ∘ 𝒞^CP, 𝒞_ℙ^) ≲ T^max{1/2,β}。　　(19)

作为 2.1 节和 2.2 节的直接推论，给定上述得分、类 𝒬 和完整预言机族，我们得到极小极大速率

inf_(𝒞∈𝒜_(β,κ)) sup_(ℙ∈𝒬) inf_(𝒞_ℙ^∈𝒪_α(ℙ)) 𝔼_ℙ ℓ_T(𝒞, 𝒞_ℙ^) ≍ T^max{1/2,β}。　　(20)

(20) 中的速率反映两种不同的代价。第一种是从过去数据近似精确预言机的代价。对于分裂保形预测，与总体得分预言机的分歧等于瞬时训练条件覆盖中的预期误差。对 (3) 求和因此得到 O(√T) 上界。2.1 节的下界论证表明该阶在 𝒬 上是不可避免的，即使没有长期经验覆盖约束且对所有精确预言机取下确界。第二种代价来自强制约束，即使总体预测集已知。正如我们从 2.1 节已经看到的，即使精确校准的预测集也被长期经验覆盖约束迫使偏离预言机，且当 β ≥ 1/2 时，所得分歧至少为 T^β 阶。截断通过控制两种代价达到组合速率。由附录 C，截断基线与截断预言机之间的分歧至多为基线与预言机分歧的两倍。为了与原始预言机比较，三角不等式加上预言机自身的截断代价。由于精确预言机具有独立同分布 Bern(α) 误差，附录 C 在期望中界定该额外代价。因此，对于任何精确预言机 𝒞_ℙ^* 和基线 𝒞⁰ ∈ 𝒜，截断给出

𝔼_ℙ ℓ_T(Γ_(κ,β) ∘ 𝒞⁰, 𝒞_ℙ^) ≤ 2 𝔼_ℙ ℓ_T(𝒞⁰, 𝒞_ℙ^) + K_(α,β,κ) {1, 0 ≤ β < 1/2; T^β, 1/2 ≤ β ≤ 1}。　　(21)

该界限对每个 T ≥ 1 成立。对于分裂保形预测和总体得分预言机，第一项是 O(√T)。当 β < 1/2 时，额外项在 T 上一致有界，因此强制长期经验覆盖保持无约束统计速率。在 β = 1/2 时，强制代价变为 √T，与学习目标的代价匹配。对于 β > 1/2，强制代价 T^β 占主导，且最优分歧速率随约束的紧密性增加。这导致 (20) 中的尖锐转变：最优速率在 β = 1/2 之前保持 √T，超过该阈值后变为 T^β。

3 与衰减步长的 ACI 比较

我们接下来将截断与具有衰减步长和固定得分函数的 ACI 进行比较，后者在每次观测后调整其阈值。固定 B > 0，可测得分 s: 𝒳 × 𝒴 → [0,B]，确定性初始阈值 q_1 ∈ [0,B]，以及正的确定性步长 (η_t)_(t≥1)。ACI 构造

𝒞_t^ACI(x) = {y : s(x,y) ≤ q_t}，　q_(t+1) = q_t + η_t(e_t^(𝒞^ACI) − α)。　　(22)

我们研究该更新的对抗保证及其与 (11) 中定义的最接近条件精确预言机的分歧。

对抗覆盖保证。 对于非增步长，Angelopoulos et al. (2024b, Theorem 1) 的覆盖界限给出 |E_T^(𝒞^ACI)| ≤ (B + η_1)/η_T 在 [0,B] 中的每个得分序列上。特别地，对于 η_t = c t^(−(1−β))，其中 c > 0 且 β ∈ (0,1]，

|E_T^(𝒞^ACI)|/T ≤ ((B+c)/c) T^(−β)　对每个 T ≥ 1。　　(23)

因此 ACI 具有 κ = (B+c)/c 的 (β, κ) 对抗保证，表明对于规定的 κ > 1，选择 c = B/(κ−1) 得到长期覆盖约束。

与预言机的分歧。 现在假设观测在 ℙ 下独立同分布，且得分具有满足

0 < λ_− ≤ f_s(u) ≤ λ_+ < ∞　对几乎每个 u ∈ [0,B]　　(24)

的密度。那么我们有以下结果，其中对 𝒞_ℙ^* 的下确界遍及满足 (11) 的所有预言机。最小预期分歧由使用相同得分的总体预测集实现，如 (12) 中定义。

命题 3.1 [ACI 的分歧] 在 ℙ ∈ 𝒬 满足 (24) 下，如果 η_t → 0 且 |η_(t+1)^(−1) − η_t^(−1)| → 0，则

inf_(𝒞_ℙ^∈𝒪_α(ℙ)) 𝔼_ℙ[ℓ_T(𝒞^ACI, 𝒞_ℙ^)] ≍ Σ_(t=1)^T √η_t。　　(25)

ACI 的阈值在 √η_t 尺度上围绕总体分位数波动，这即使在步长衰减时也产生分歧。具体地，对于 η_t = c t^(−(1−β)) 且 0 < β < 1，我们有以下推论。

推论 3.2 在 ℙ ∈ 𝒬 满足 (24) 下，对于 η_t = c t^(−(1−β)) 且 0 < β < 1，

inf_(𝒞_ℙ^∈𝒪_α(ℙ)) 𝔼_ℙ[ℓ_T(𝒞^ACI, 𝒞_ℙ^)] ≍ T^((1+β)/2)。　　(26)

由于 (1+β)/2 > max{1/2, β}，这比 2.2 节中在相同对抗保证（κ > 1）下截断分裂保形预测的分歧增长更快。因此，使用相同的固定得分函数，对于这些步长，ACI 的累积分歧在每个 β ∈ (0,1) 都超过极小极大速率。截断的分裂保形预测通过仅在约束强制覆盖或误覆盖时改变基线集合来达到最优速率。

(2024) 为 f-散度球内的测试分布构建具有有限样本覆盖界限的预测集。关于稳健风险评估的相关工作在密度比上引入保序约束 (Gui et al., 2026)。应用包括反事实和个体处理效应的推断 (Lei and Candès, 2021; Jin et al., 2023)、删失生存结果的预测 (Candès et al., 2023; Gui et al., 2024)、缺失协变量 (Zaffran et al., 2023) 以及未观测矩阵条目 (Gui et al., 2023)。在批处理设置中，Areces et al. (2024) 对固定得分上由阈值或区间定义的预测集，建立了 n 次独立同分布观测后预期训练条件覆盖误差 n^(−1/2) 阶的极小极大下界。Duchi (2025) 为分裂保形预测开发了样本条件覆盖界限，并将它们与这些下界联系起来。我们研究在线预测中的累积误差和长期经验覆盖约束的额外代价。

在线保形预测和自适应校准。 自适应校准使用过去的覆盖误差在数据分布变化时调整预测集。自适应保形推断 (ACI) 调整名义覆盖水平并控制任意数据序列上的长期经验覆盖 (Gibbs and Candès, 2021)。后续方法以局部动态遗憾保证适应学习率 (Gibbs and Candès, 2024)，或聚合具有不同学习率的 ACI 预测器 (Zaffran et al., 2022)。基于赌注的方法使用无参数在线优化避免选择学习率 (Podkopaev et al., 2024)。直接阈值更新将长期经验覆盖控制与分位数估计联系起来。保形 PID 控制结合分位数跟踪、累积覆盖误差的校正以及未来得分分位数的预测 (Angelopoulos et al., 2023)。对于固定的有界得分，适当衰减的步长保持长期经验覆盖，并在独立同分布抽样和唯一目标分位数下产生分位数收敛 (Angelopoulos et al., 2024b)。时间序列方法使用过去的残差和预测来使预测区间适应时间依赖性。EnbPI 使用自助集成残差并在新观测到达时更新其经验分位数 (Xu and Xie, 2021)。顺序预测保形推断转而从过去的残差估计未来残差的条件分位数 (Xu and Xie, 2023)。Bellman 保形推断使用多步预测和动态规划选择预测区间 (Yang et al., 2024)。Jiang et al. (2026) 记录了留一法 jackknife 在短程时间依赖性下的严重欠覆盖。他们的留窗修改省略观测块，并在拟合算法的稳定性和时间依赖性的定量界限下给出近似边缘覆盖保证。Srinivas (2026) 研究经验覆盖与平均区间长度之间的权衡，相对于事后达到目标覆盖的最短固定区间测量。Areces et al. (2025) 将校准表述为在线优化问题，在对抗设置中获得长期经验覆盖，并在包括条件得分分位数线性模型的假设下获得瞬时训练条件覆盖的收敛。当数据律变化时，中心目标是保持训练条件覆盖接近其目标。Liang et al. (2026) 研究 (4) 中定义的 Δ_T^inst，针对具有未知变点或有界累积分布漂移的独立观测。他们的方法结合漂移检测和重新校准，在他们研究的算法类内达到对数因子内的极小极大速率，但不施加在每个数据序列上成立的长期经验覆盖约束。

遗憾、局部覆盖和组覆盖。 强自适应在线方法在所有时间区间上界定分位数损失遗憾 (Bhatnagar et al., 2023)，然而分位数损失遗憾本身并不直接蕴含覆盖保证。多有效方法在得分分布的光滑性条件下控制组和阈值范围内的经验覆盖 (Bastani et al., 2022)。Ramalingam et al. (2025) 区分遗憾与覆盖，将交换遗憾与多有效性联系起来，并开发 ACI 的组条件扩展。其他工作研究指数折扣遗憾和覆盖 (Zhang et al., 2024)、候选预测模型之间的选择 (Hajihashemi and Shen, 2024)，以及梯度均衡（将平均损失梯度的消失与在线校准联系起来）(Angelopoulos et al., 2025)。

6 讨论

我们寻求一种“两全其美”的在线算法，其预测集在每个数据序列上满足长期经验覆盖约束 (6)，并且对于独立同分布数据，与瞬时训练条件覆盖精确为 1−α 的预言机尽可能少地分歧。我们证明，在具有非原子得分的独立同分布分布类 𝒬 上，该约束下与最接近此类预言机的极小极大预期分歧的阶为 T^max{1/2,β}。因此，该约束对于 β ≤ 1/2 保持无约束速率 √T 不变，对于 β > 1/2 将其提高到 T^β。截断的分裂保形预测达到该速率。使用相同的固定得分，步长与 t^(−(1−β)) 成比例的 ACI 满足相同的约束，但当得分具有远离零和无穷的密度界限时，其预期分歧的阶为 T^((1+β)/2)。该速率在每个 0 < β < 1 都超过 T^max{1/2,β}。

本文还留下以下开放问题。由于极小极大最优构造可能不唯一，通过体积量化此类预测集的准确性来细化最优性准则可能是有意义的。开放问题包括如何在保持规定对抗约束的同时，在分布漂移下保留信息丰富的预测集和自适应瞬时训练条件覆盖。
