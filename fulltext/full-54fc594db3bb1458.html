摘要

低秩适应是大型神经网络参数高效微调的事实标准方法，以最少的可训练参数和低优化成本实现强大的任务适应。除了这种效率之外，从业者还观察到两个显著的特性：对灾难性遗忘的鲁棒性以及将独立训练的适配器合并为在多个任务上具有竞争力的单一模型的能力。这些特性对于持续学习和多任务学习至关重要，但至今仍未被充分理解。在本工作中，我们通过统一的基于边际的视角提供了理论解释。我们在具有 ℓ₂ 正则化的近正交任务机制下分析多类线性分类中的 LoRA，并刻画了不同正则化区间下最优 LoRA 适配器的特征。我们的分析表明，在正则化参数的中间区间内，最优适配器与微调数据上的最大边际解对齐。基于这一刻画，我们推导出两个关键结论。首先，我们获得了预训练和微调数据上边际的闭式表达式，揭示了精确的边际权衡：正则化参数控制了保留与适应之间的平衡。其次，我们分析了适配器合并，证明合并模型在每个任务上都能实现正边际，并推导出在各任务间平衡边际并在其并集上最大化边际的最优混合系数。这些结果产生了一个简单的免训练合并规则，我们称之为基于边际的 LoRA 合并（MaLoRA）。在现代架构和真实数据集上的实验验证了我们的理论预测，表明 MaLoRA 在一系列视觉和语言分类任务中匹配或优于几种适配器合并基线方法。

1 引言

基础模型已经在众多领域改变了人工智能。然而，在现实应用中部署这些模型通常需要在专门的数据集上进行微调，以满足准确性、安全性和对齐要求。传统的全参数微调更新预训练模型的所有参数，产生大量的计算成本，包括大内存占用、长训练时间和显著的存储需求。低秩适应通过用低秩适配器 B, A 增强预训练权重矩阵 W 同时保持 W 冻结来解决这一挑战。经验上，LoRA 在仅训练一小部分参数的情况下就能匹配全参数微调的性能。

虽然 LoRA 最初因其计算效率而被引入，但从业者此后发现了两个显著的经验特性。

  1. 对灾难性遗忘的鲁棒性。 在微调和持续学习中，适应新任务后对先前学习任务性能的退化（即灾难性遗忘）是一个基本挑战。令人惊讶的是，最近的研究表明 LoRA 表现出对灾难性遗忘的强鲁棒性，即使在大量适应之后。这种鲁棒性使 LoRA 对持续学习特别有吸引力。

  2. 有效的适配器合并。 在多任务设置中，为每个任务维护单独的微调模型是存储密集型的。值得注意的是，在不同任务上独立训练的 LoRA 适配器可以合并（例如，通过简单的加权平均）为在所有任务上表现良好的单一适配器。这一特性实现了灵活高效的部署。

尽管有这些经验上的好处，LoRA 对灾难性遗忘的鲁棒性及其适配器合并能力背后的理论机制仍然知之甚少。在本工作中，我们通过基于边际的视角为这两个现象提供了统一的理论解释。

论文贡献。 我们在近正交任务机制下研究多类线性分类中的 LoRA，其中微调样本彼此之间以及与预训练样本之间近似正交。在此设置中，我们刻画了 LoRA 目标的全局最小值，并利用这一刻画来分析遗忘和适配器合并。与之前关于 LoRA 的理论工作（见附录 B）相比，我们的工作做出以下贡献：

  • 最优解的刻画。 我们刻画了不同正则化区间下 LoRA 的全局最小值（定理 3.1）。在高惩罚区间，最优适配器为零。在中间区间，适配器与微调数据上的最大边际方向对齐。在低惩罚区间，适配器与一个非最大边际分类器对齐，其方向通常不承认简单的闭式形式。然而，我们证明当正则化参数趋于零时，该方向收敛到一个可解释的极限。

  • 减少遗忘的理论。 我们将遗忘定义为微调后预训练数据上边际的减少，并推导出预训练数据、微调数据及其并集上归一化边际的闭式表达式（定理 3.2）。我们的分析表明，这些边际由正则化参数控制，并满足精确的权衡：减小正则化参数会增加微调边际，但也会增加适配器与预训练权重的 Frobenius 范数比，导致更大的遗忘。我们进一步识别出在预训练和微调任务并集上最大化边际的正则化参数，从而最优地平衡保留和适应。

  • 适配器合并的理论。 在每个任务的中间区间假设下，我们推导出合并模型在每个任务上边际的闭式表达式（定理 3.3）。我们证明合并模型在每个任务上都能获得严格正的边际，为适配器合并的有效性提供了理论解释。我们还以闭式形式刻画了在所有任务并集上最大化合并模型边际的混合系数，这自然导致了基于边际的 LoRA 合并（MaLoRA），一种理论驱动的适配器合并方法。这与许多现有的模型合并方法形成对比，后者主要依赖启发式规则来选择如何组合任务特定模型。

  • 数值验证。 在真实数据集和现代架构上的实验从三个方面支持理论： 在线性探测设置中，经验最优正则化参数与我们分析预测的值一致； 在同一设置中，经验最优适配器混合权重与我们的闭式系数一致； 在 LoRA 适配器合并中，MaLoRA 在视觉和语言分类任务中实现了与强启发式适配器合并基线相当甚至更好的性能。

2 预备知识

在本节中，我们首先介绍多类线性分类问题及其对应的硬边际 SVM 公式。然后描述本工作中考虑的特定学习问题，包括预训练和微调阶段。最后，我们陈述支撑我们分析的关键假设，并讨论其动机和含义。

2.1 多类线性分类背景

我们首先回顾标准的 K 类线性分类问题。给定数据集 𝒟，目标是学习一个权重矩阵 W ∈ ℝ^(K×d)，最小化平均经验交叉熵损失：

$$\min_{W\in\mathbb{R}^{K\times d}} L(W;\mathcal{D}) := \frac{1}{|\mathcal{D}|}\sum_{(\bm{x},\bm{y})\in\mathcal{D}}\mathcal{L}_{\mathrm{CE}}(\bm{y},W\bm{x}) \tag{1}$$

其中 x ∈ ℝ^d 是输入，y ∈ ℝ^K 是 one-hot 标签向量。交叉熵损失由下式给出：

$$\mathcal{L}{\mathrm{CE}}(\bm{y},\hat{\bm{y}}) := -\sum{c=1}^{K}y_{c}\log\left(\frac{\exp(\hat{y}{c})}{\sum{i=1}^{K}\exp(\hat{y}_{i})}\right),\quad\hat{\bm{y}}=W\bm{x} \tag{2}$$

最近的研究表明，当数据线性可分时，梯度下降（GD）隐式地将 (1) 的解偏向最大边际分类器。具体而言，GD 的迭代在方向上收敛到以下硬边际 SVM 问题的最大边际解¹：

$$W^{\mathrm{SVM}}(\mathcal{D}) := \arg\min_{W\in\mathbb{R}^{K\times d}}|W|_{F}^{2}\quad\text{subject to}\quad C(W;\mathcal{D})\geq 1 \tag{3}$$

其中 C(W; 𝒟) 是数据集上的最小边际：

$$C(W;\mathcal{D}) := \min_{(\bm{x},\bm{y})\in\mathcal{D}}\;\min_{k\neq c,y_{c}=1}\left(\bm{w}{c}^{\top}\bm{x}-\bm{w}{k}^{\top}\bm{x}\right),\quad\text{with}\quad W=[\bm{w}{1};\dots;\bm{w}{K}]^{\top} \tag{4}$$

(3) 中的硬边际 SVM 问题寻求一个最小范数的权重矩阵，在正确类别和最近竞争类别之间以至少单位边际分隔所有样本。

直观上，分类决策主要取决于权重矩阵的方向而非其尺度。为了在不同尺度的 W 之间进行比较，我们采用 Crammer and Singer (2001) 中使用的归一化边际，即 γ(W; 𝒟) := C(W; 𝒟)/‖W‖_F（当 W ≠ 0 时）。这一定义已在最近的理论研究中使用。我们另外约定 γ(0; 𝒟) := 0。

2.2 预训练和微调设置

我们现在描述理论分析中使用的特定预训练和微调框架。

预训练阶段。 设 𝒟_pre 为具有 K 个类别的标记数据集，W_pre ∈ ℝ^(K×d) 表示通过 GD 最小化交叉熵损失 L(W; 𝒟_pre) 获得的预训练线性分类器。当 𝒟_pre 线性可分时，该目标不存在有限最小值。GD 迭代反而在范数上发散而在方向上收敛到最大边际解。我们在假设 2.4 中形式化这种方向结构。

微调阶段。 我们将预训练模型适应到下游数据集 𝒟_ft，该数据集由从原始 K 个预训练类别中选出的 2 ≤ K̄ ≤ K 个类别的各 n 个额外样本组成。这一限制适用于全文和附录，包括适配器合并中的每个任务。

此设置捕获了实际场景，如域增量学习、域适应和偏差再平衡微调。

当应用 LoRA 将预训练模型适应到微调任务时，我们引入对权重的低秩更新，由矩阵 B ∈ ℝ^(K×r) 和 A ∈ ℝ^(r×d) 参数化：

$$\min_{B,A}\;L(W_{\mathrm{pre}}+BA;\mathcal{D}{\mathrm{ft}})+\frac{\lambda}{2}(|B|{F}^{2}+|A|_{F}^{2}) \tag{5}$$

这里，Frobenius 范数惩罚在权重空间中显式约束适配器，限制微调模型与预训练初始化的偏差。

虽然一些 LoRA 的经验研究在损失中不显式包含此惩罚，但它们使用 AdamW 优化器训练适配器，其解耦权重衰减对 B 和 A 产生类似于 L₂ 正则化的效果。因此，(5) 中的目标捕获了标准 LoRA 微调实践中显式或隐式使用的正则化。

我们的目标是理解 (5) 最优解的结构，以及它如何解释 LoRA 对灾难性遗忘的鲁棒性及其在实现适配器合并方面的有效性。

2.3 假设及其含义

我们的理论分析使用以下假设。

设 N_ft = K̄n 为微调样本数，记 X_ft = [x̄₁, ..., x̄_{N_ft}]，X_pre 收集预训练特征向量作为列。

假设 2.1（任务几何）。预训练和微调合并数据集线性可分。存在 ε₁, ε₂ ∈ [0,1) 使得对所有 i, j ∈ [N_ft] 和 x ∈ 𝒟_pre：
- (a) ‖x̄ᵢ‖₂ = ‖x‖₂ = 1
- (b) |x̄ᵢ^⊤ x̄ⱼ| ≤ ε₁ (i ≠ j)
- (c) |x̄ᵢ^⊤ x| ≤ ε₂

假设 2.2（维度）。在严格正交情况 ε₁ = ε₂ = 0 下，输入维度满足 d ≥ N_ft + rank(X_pre)。对于近正交数据，我们假设 (N_ft - 1)ε₁ < 1。

假设 2.3（LoRA 秩）。LoRA 秩参数满足 r ≥ K̄，其中 K̄ 是微调类别数。

假设 2.4（预训练分类器）。预训练分类器 W_pre 是 𝒟_pre 上硬边际 SVM 解的缩放版本：W_pre = ρ_pre · W_pre^SVM/‖W_pre^SVM‖_F，对某个标量 ρ_pre > 0，其中 W_pre^SVM = W^SVM(𝒟_pre)。

假设合理性说明。 近正交任务假设 2.1 在实践中可以说是一个强假设，但反映了微调数据的现实几何结构，类似的正交性假设在理论分析中常用于实现闭式刻画。附录 H.1.1 和 H.2.1 中对 CIFAR-100 和六个多域基准的特征相关性分析为研究这一参考几何提供了经验动机。假设 2.2 使几何可行性和条件要求显式化。严格情况的界限同时考虑了微调样本数和预训练特征张成，指定了一个高维、样本受限的设置。假设 2.3 仅要求 r ≥ K̄，意味着 LoRA 秩只需至少为微调类别数。最后，假设 2.4 由多类分类中 GD 隐式偏差的最近理论结果驱动。ρ_pre 捕获预训练停止时的（未指定）尺度，这在 GD 迭代沿 SVM 方向发散的隐式偏差分析中自然产生。

为清晰起见，正文中的所有定理都在假设 2.1 的严格正交特例（ε₁ = ε₂ = 0）下陈述。ε₁, ε₂ > 0 时这些结果的一般版本及其证明推迟到附录 D–F。

含义。 上述假设为微调任务的 K̄ 类硬边际 SVM 解导出了干净的闭式表达式，也蕴含了预训练权重 W_pre 与微调数据集 𝒟_ft 之间的近正交性，这支撑了我们在 §3 中的后续理论分析。

为形式化这些含义，我们首先引入单纯形等角紧框架的概念，它刻画了我们设置中硬边际 SVM 解的几何结构。

定义 2.1（单纯形 ETF）。对于 m ≥ 2，m-单纯形 ETF 是 ℝ^p 中 m 个向量的集合（某 p ≥ m），由 M_m := √(m/(m-1)) P(I_m - (1/m)1_m 1_m^⊤) 的列给出，其中 P ∈ ℝ^(p×m) 满足 P^⊤P = I_m。全文我们使用规范选择 p = m 和 P = I_m，因此 M_m ∈ ℝ^(m×m)。

命题 2.1。 设 K̄ ≥ 2。在假设 2.1（ε₁ = ε₂ = 0）和假设 2.4 下，以下成立：

(i) 𝒟_ft 的最小范数 SVM 解 W_ft^SVM ∈ ℝ^(K̄×d)（由 (3) 定义，具有 K̄ 个输出类别）具有闭式解 W_ft^SVM = √((K̄-1)/K̄)(M_{K̄} ⊗ 1_n^⊤)X_ft^⊤。

(ii) 预训练权重与微调数据正交：对所有 x̄ ∈ 𝒟_ft，W_pre x̄ = 0。

命题 2.1 的注记。 命题 2.1 揭示了微调任务的硬边际 SVM 解具有紧凑的闭式表达式。然而，这种形式并不能立即揭示分类器如何从微调数据中聚合信息。为提供洞察，我们显式推导 W_ft^SVM 第一行的表达式（其余行对称地得到）：

$$\left(\frac{\bar{K}-1}{\bar{K}}\sum_{i=1}^{n}\bm{\bar{x}}{1,i}-\frac{1}{\bar{K}}\sum{k=2}^{\bar{K}}\sum_{j=1}^{n}\bm{\bar{x}}_{k,j}\right)^{\top}$$

直观上，W_ft^SVM 的每一行编码了一个强调其对应类别均值同时均匀抑制所有其他类别影响的方向，在最大边际分类中实现类别分离。命题 2.1 的第二个结果来自 SVM 的表示定理，它蕴含预训练数据上的硬边际 SVM 解位于 𝒟_pre 的张成中。由假设 2.4，W_pre 继承了这一性质；结合假设 2.1 在 ε₂ = 0 时的条件，W_pre 的每一行因此与微调数据正交。

3 主要结果

在本节中，我们首先分析 LoRA 目标的优化景观并在 §3.1 中刻画其全局最小值。然后我们在 §3.2 中推导预训练和微调数据集并集上边际的闭式表达式，解释为什么 LoRA 缓解灾难性遗忘。最后，在 §3.3 中，我们将基于边际的分析扩展到多任务设置，解释适配器合并的有效性，并推导在所有任务并集上最大化边际的最优混合系数。此外，基于这些闭式系数，我们将它们转化为一个简单的免训练合并规则——基于边际的 LoRA 合并（MaLoRA，算法 1）。

3.1 LoRA 目标的全局最小值

在本小节中，我们呈现刻画 (5) 中 LoRA 目标全局最小值的主要理论结果。有趣的是，在适当的正则化下，我们发现最优 LoRA 适配器的一部分与微调数据的 K̄ 类硬边际 SVM 解（W_ft^SVM）精确对齐（见命题 2.1 的定义）。虽然我们的分析既不假设也不依赖这种对齐，但它的出现揭示了几何结构，部分解释了 LoRA 的有效性。

定理 3.1。 设 K 和 K̄ ≤ K 分别为预训练和微调类别数。存在关于 λ 的标量函数 a_λ, b_λ, c_λ, Θ_λ 使得对 (5) 的任何全局最小值 (B_λ, A_λ)（λ > 0），我们有：

$$B_{\lambda}^{}A_{\lambda}^{}=\left(\begin{pmatrix}(a_{\lambda}+b_{\lambda})\,\mathbf{I}{\bar{K}}-b{\lambda}\,\mathbf{1}{\bar{K}}\mathbf{1}{\bar{K}}^{\top}\-c_{\lambda}\,\mathbf{1}{K-\bar{K}}\mathbf{1}{\bar{K}}^{\top}\end{pmatrix}\otimes\mathbf{1}{n}^{\top}\right)X{\mathrm{ft}}^{\top},\quad|B_{\lambda}^{}A_{\lambda}^{}|{F}=\Theta{\lambda} \tag{7}$$

当 K̄ ≥ 2 时，存在临界正则化权重 λ_crit ∈ [0, 1/(K̄√n)) 使得标量函数 a_λ, b_λ, c_λ, Θ_λ 刻画如下：

(i) 高惩罚区间 (λ ≥ 1/(K̄√n))：a_λ = b_λ = c_λ = Θ_λ = 0，因此 B_λA_λ = 0_{K×d}。

(ii) 中间区间 (λ_crit < λ < 1/(K̄√n))：a_λ = Θ_λ√(K̄-1)/(K̄√n)，b_λ = Θ_λ/(K̄√(n(K̄-1)))，c_λ = 0，且 Θ_λ 是某个非线性方程的唯一根（见附录 D 中的 (29)），因此最小值为：

$$B_{\lambda}^{}A_{\lambda}^{}=\frac{\Theta_{\lambda}}{\sqrt{\bar{K}n}}\left(\begin{pmatrix}M_{\bar{K}}\\bm{0}{(K-\bar{K})\times\bar{K}}\end{pmatrix}\otimes\bm{1}{n}^{\top}\right)X_{\mathrm{ft}}^{\top} \tag{8}$$

(iii) 低惩罚区间 (0 < λ ≤ λ_crit)：a_λ, b_λ, c_λ, Θ_λ 非负。此外，小正则化极限满足：

$$\lim_{\lambda\to 0^{+}}\Theta_{\lambda}=\infty,\quad\lim_{\lambda\to 0^{+}}\frac{B_{\lambda}^{}A_{\lambda}^{}}{|B_{\lambda}^{}A_{\lambda}^{}|{F}}=\sqrt{\frac{1}{n\bar{K}}}\left(M{K}^{(\bar{K})}\otimes\bm{1}{n}^{\top}\right)X{\mathrm{ft}}^{\top} \tag{9}$$

其中 M_K^(K̄) 是 K-ETF 矩阵 M_K 的前 K̄ 列。

注记 3.1。 对于 K̄ ≥ 2，临界权重 λ_crit = 0 当且仅当 K̄ = K。在这种情况下，中间区间覆盖所有 0 < λ < 1/(K√n)，低惩罚区间不包含正的正则化权重。(9) 中的极限在 λ → 0⁺ 时仍然有效，通过中间区间逼近。

定理 3.1 的证明在附录 D 中提供。该定理表明最优 LoRA 更新 B_λA_λ 具有 (7) 中的统一形式，并基于正则化参数 λ 识别出最多三个区间。我们做以下注记：

正则化的效果及与最大边际分类器的联系。 定理表明正则化参数控制最优 LoRA 适配器的结构。在高惩罚区间，正则化项占主导并将最优适配器驱动为零。在中间区间，适配器平衡交叉熵和正则化，产生 (8) 中的显式形式。特别地，B_λA_λ 的前 K̄ 行与微调数据上的 K̄ 类硬边际 SVM 解（命题 2.1）对齐，这为学习到的解提供了清晰的最大边际解释。在低惩罚区间，a_λ 和 b_λ 的显式公式不再可用。然而，当 λ → 0⁺ 时，交叉熵项占主导且 Θ_λ → ∞，而我们的渐近分析仍然刻画了 (9) 中 B_λA_λ 的极限方向。该方向仅在 K̄ = K 时与硬边际 SVM 解重合。

对微调模型的含义。 (7) 中最优 LoRA 适配器的结构化形式自然使得 W_LoRA^λ := W_pre + B_λA_λ 在预训练和微调数据上都能表现良好。在假设 2.1 和 2.4 下，命题 2.1 和定理 3.1 蕴含对所有 x̄ ∈ 𝒟_ft 有 W_pre x̄ = 0，对所有 x ∈ 𝒟_pre 有 B_λA_λ x = 0。即，两个分量独立运作：W_pre 分类预训练数据，而 B_λA_λ 适应微调数据：

$$\forall\bm{x}\in\mathcal{D}{\mathrm{pre}}\cup\mathcal{D}{\mathrm{ft}},\quad W_{\mathrm{LoRA}}^{\lambda}\bm{x}=\begin{cases}W_{\mathrm{pre}}\bm{x}&\text{if }\bm{x}\in\mathcal{D}{\mathrm{pre}}\B{\lambda}^{}A_{\lambda}^{}\bm{x}&\text{if }\bm{x}\in\mathcal{D}_{\mathrm{ft}}\end{cases} \tag{10}$$

这种干净的分离使我们能够将 W_LoRA^λ 在每个组成数据集上的归一化边际分解为相关分量的贡献（W_pre 或 B_λA_λ）和一个相对范数因子：

$$\gamma(W_{\mathrm{LoRA}}^{\lambda};\mathcal{D})=\gamma(W;\mathcal{D})\frac{|W|{F}}{|W{\mathrm{LoRA}}^{\lambda}|_{F}} \tag{11}$$

(11) 中的表达式表明，合并数据集上的归一化边际不仅取决于 W_pre 和 B_λA_λ 分别在 𝒟_pre 和 𝒟_ft 上的各自归一化边际，还取决于这些分量的相对 Frobenius 范数。在以下章节中，我们使用 (11) 来推导合并数据集上归一化边际的闭式表达式，并计算适配器合并的最优混合系数。为清晰呈现，我们聚焦于 K̄ = K 的情况，并将完整版本的结果引导读者参考附录 E 和附录 F。

3.2 LoRA 适应下遗忘与微调之间的边际权衡

我们现在通过归一化边际分析灾难性遗忘。我们的目标是刻画 LoRA 微调模型如何在正则化参数变化时权衡预训练数据和微调数据上的性能，并识别在其并集上最大化边际的正则化水平。为方便起见，定义 γ_pre := γ(W_pre; 𝒟_pre)，γ_{ft,λ} := γ(B_λA_λ; 𝒟_ft)。此外，我们定义对微调数据的适应和对预训练数据的遗忘为：

$$\mathrm{Adapt}(\lambda)=\gamma(W_{\mathrm{LoRA}}^{\lambda};\mathcal{D}{\mathrm{ft}})-\gamma(W{\mathrm{pre}},\mathcal{D}{\mathrm{ft}}),\quad\mathrm{Forget}(\lambda):=\gamma{\mathrm{pre}}-\gamma(W_{\mathrm{LoRA}}^{\lambda};\mathcal{D}_{\mathrm{pre}}) \tag{12}$$

定理 3.2。 采用定理 3.1 在严格正交下的设置，假设 K̄ = K ≥ 2。设 γ_ft* 为任何线性分类器在微调数据 𝒟_ft 上能获得的最大归一化边际，并回忆假设 2.4 中的标量 ρ_pre。则 Adapt(λ) 和 Forget(λ) 可以在所有 λ 上统一刻画如下：

$$\mathrm{Adapt}(\lambda)=\gamma_{\mathrm{ft},\lambda}\,\frac{\Theta_{\lambda}}{\sqrt{\Theta_{\lambda}^{2}+\rho_{\mathrm{pre}}^{2}}},\quad\mathrm{Forget}(\lambda)=\gamma_{\mathrm{pre}}\left(1-\frac{\rho_{\mathrm{pre}}}{\sqrt{\Theta_{\lambda}^{2}+\rho_{\mathrm{pre}}^{2}}}\right) \tag{13}$$

此外，正则化参数 λ 的效果由两个区间刻画：

(i) 高惩罚区间：如果 λ ≥ 1/(K̄√n)，则 Θ_λ = 0，因此 Forget(λ) = Adapt(λ) = 0。

(ii) 中间和低惩罚区间：如果 λ < 1/(K̄√n)，则 γ_{ft,λ} = γ_ft*，且 Θ_λ 关于 λ 递减。因此 Adapt(λ) 和 Forget(λ) 都关于 λ 递减。特别地：

$$\lim_{\lambda\to 0^{+}}(\mathrm{Adapt}(\lambda),\mathrm{Forget}(\lambda))=(\gamma_{\mathrm{ft}}^{*},\gamma_{\mathrm{pre}}),\quad\lim_{\lambda\to\frac{1}{\bar{K}\sqrt{n}}}(\mathrm{Adapt}(\lambda),\mathrm{Forget}(\lambda))=(0,0) \tag{14}$$

注记 3.2。 值得注意的是，当 K̄ = K 时中间和低惩罚区间重合。这种合并是 K̄ = K 情况特有的；当 K̄ < K 时，两个区间保持不同。

平衡适应与遗忘。 定理 3.2 表明同一个量 Θ_λ 同时控制适应和遗忘。随着 λ 减小，适配器尺度 Θ_λ 增大，改善微调数据上的 Adapt(λ)，同时也增加预训练数据上的 Forget(λ)。因此，LoRA 微调产生直接的边际权衡：更强的适应以更大的预训练边际退化为代价。自然的问题是如何选择 λ 来平衡这些效果。

在以下推论 3.1 中，我们通过研究预训练和微调数据集并集上的归一化边际来量化这一权衡，这导致显式的最优正则化水平。

推论 3.1（适应与遗忘之间的最优平衡）。在定理 3.2 的条件下，K̄ = K，W_LoRA^λ 在并集 𝒟_pre ∪ 𝒟_ft 上的归一化边际为：

$$\gamma(W_{\mathrm{LoRA}}^{\lambda};\mathcal{D}{\mathrm{pre}}\cup\mathcal{D}{\mathrm{ft}})=\min{\gamma_{\mathrm{pre}}-\mathrm{Forget}(\lambda),\mathrm{Adapt}(\lambda)} \tag{15}$$

该边际在平衡点 λ* ∈ (0, 1/(K√n)) 处唯一最大化，最大值为：

$$\max_{\lambda>0}\gamma(W_{\mathrm{LoRA}}^{\lambda};\mathcal{D}{\mathrm{pre}}\cup\mathcal{D}{\mathrm{ft}})=\left(\frac{1}{(\gamma_{\mathrm{ft}}^{*})^{2}}+\frac{1}{\gamma_{\mathrm{pre}}^{2}}\right)^{-1/2} \tag{16}$$

3.3 合并 LoRA 模型的边际刻画与最优混合系数

我们现在将基于边际的分析扩展到多任务设置，其中一个预训练模型被 T 个 LoRA 适配器独立适应，我们希望将它们合并为一个统一模型。通过相同的边际视角，我们推导出合并模型在每个任务上边际的闭式表达式，并识别在所有任务并集上最大化边际的混合系数（定理 3.3）。基于这一刻画，我们设计了一个实用的 LoRA 合并算法——基于边际的 LoRA 合并（MaLoRA，算法 1）。

设 (B_i, A_i) 表示在数据集 𝒟_i 上训练的 LoRA 适配器，i ∈ [T]。我们将适配器与预训练权重矩阵合并如下：

$$W_{\mathrm{LoRA}}(\bm{\alpha}):=W_{\mathrm{pre}}+\sum_{i=1}^{T}\alpha_{i}\,B_{i}^{}A_{i}^{},\quad\alpha_{1},\dots,\alpha_{T}\geq 0 \tag{17}$$

其中 α = (α₁, ..., α_T) 是混合系数。

此外，我们将假设 2.1 推广到学习多个任务的设置如下。

假设 3.1。 存在 ε₁, ε₂ ∈ [0,1) 使得： 每个样本具有单位范数：对所有 x ∈ ⋃ᵢ₌₁ᵀ 𝒟_i ∪ 𝒟_pre，‖x‖₂ = 1。 任务内：对每个 i ∈ [T] 和每对不同的 x̄, x̄' ∈ 𝒟_i，|x̄^⊤ x̄'| ≤ ε₁。 跨任务和预训练：∀x̄ ∈ 𝒟_i, x̄' ∈ 𝒟_j (i ≠ j) 或 x ∈ 𝒟_pre，则 |x̄^⊤ x̄'|, |x̄^⊤ x| ≤ ε₂。

以下定理刻画了严格正交情况（ε₁ = ε₂ = 0）下的最优混合系数。我们将读者引导至附录 F 查看证明。

定理 3.3。 在假设 3.1 下，假设每个微调任务 𝒟_i (i = 1, ..., T) 使用中间或低惩罚区间的正则化参数训练。设 Θ_{λ,i} = ‖B_iA_i‖F 和 γ_i = γ(B_iA_i; 𝒟_i)。对任何非负系数向量 α = (α₁, ..., α_T) ∈ ℝ{≥0}^T，合并模型 (17) 在每个任务上获得以下归一化边际：

$$\gamma(W_{\mathrm{LoRA}}(\bm{\alpha});\mathcal{D}{\mathrm{pre}})=\frac{\gamma{\mathrm{pre}}\rho_{\mathrm{pre}}}{\sqrt{\rho_{\mathrm{pre}}^{2}+\sum_{j=1}^{T}\alpha_{j}^{2}\Theta_{\lambda,j}^{2}}},\quad\gamma(W_{\mathrm{LoRA}}(\bm{\alpha});\mathcal{D}{i})=\frac{\gamma{i}\alpha_{i}\Theta_{\lambda,i}}{\sqrt{\rho_{\mathrm{pre}}^{2}+\sum_{j=1}^{T}\alpha_{j}^{2}\Theta_{\lambda,j}^{2}}}$$

$$\gamma(W_{\mathrm{LoRA}}(\bm{\alpha});\mathcal{D}{\mathrm{pre}}\cup{D{i}}{i=1}^{T})=\min\left{\gamma(W{\mathrm{LoRA}}(\bm{\alpha});\mathcal{D}{\mathrm{pre}}),\gamma(W{\mathrm{LoRA}}(\bm{\alpha});\mathcal{D}_{i}),i\in[T]\right} \tag{18}$$

选择权重 α_i = C(W_pre; 𝒟_pre)/C(B_iA_i; 𝒟_i)，i ∈ [T]，最大化所有任务并集上的边际：

$$\max_{\bm{\alpha}\in\mathbb{R}{\geq 0}^{T}}\gamma(W{\mathrm{LoRA}}(\bm{\alpha});\mathcal{D}{\mathrm{pre}}\cup{D{i}}{i=1}^{T})=\left(\frac{1}{\gamma{\mathrm{pre}}^{2}}+\sum_{j=1}^{T}\frac{1}{(\gamma_{j})^{2}}\right)^{-1/2}$$

算法 1：基于边际的 LoRA 合并

1: 输入： W_pre, {(B_i, A_i)}{i=1}^T, 𝒟_pre^val, {𝒟_i^val}{i=1}^T, S ⊂ ℝ_{>0}
2: C̄_pre ← C̄(W_pre; 𝒟_pre^val)
3: for i = 1, ..., T do
4: C̄_i ← C̄(W_pre + B_iA_i; 𝒟_i^val)，β_i ← {C̄_pre/C̄_i, 若 C̄_i > 0; 0, 否则}
5: end for
6: s ∈ arg max_{s∈S} ValAcc(W_pre + s∑ᵢ₌₁ᵀ β_i B_i A_i)
7: return W_pre + s∑ᵢ₌₁ᵀ β_i B_i A_i

定理 3.3 刻画了每个任务以及任务并集上边际作为混合系数的函数。特别地，它表明最优混合系数由预训练模型在 𝒟_pre 上的未归一化边际与每个微调适配器在其自身任务上的未归一化边际的比值给出。未归一化边际衡量分类器在其数据集上分离类别的置信程度，值越小表示更具挑战性的分类问题。这个公式有直接的解释：在其任务上获得较小边际的适配器被分配更大的混合权重，增加其贡献以便在合并模型中为该任务保持正边际。

面向实用的基于边际的适配器混合。 前面的分析建议根据每个适配器分离其任务数据的置信程度（由未归一化边际衡量）来选择适配器混合系数。然而在实践中，数据集通常不是完美可分的，因此最小边际 C(·;·) 可能为负且对困难样本过于敏感。因此我们使用平均边际 C̄(·; 𝒟) 作为适配器性能的更稳定代理。在定理 3.3 的严格正交假设下，每个最优适配器的每样本边际在其自身的微调数据集上是相等的。因此，在这些微调数据集上最小边际和平均边际重合。在我们的实用算法中，我们因此使用平均边际作为理论混合规则中出现的最小边际的经验代理。

算法 1：基于边际的 LoRA 合并。 受定理 3.3 启发，我们提出使用平均边际代理 C̄(W; 𝒟) 的实用 LoRA 合并算法。当任务具有非正平均边际 C̄_i 时，对应系数将为负，不再与定理启发的区间一致。算法 1 因此通过将此类任务的系数设为零来丢弃它们。我们还在留出验证集上调优全局缩放因子 s*，遵循 Ilharco et al. (2022)，发现这进一步提高了性能。在 §4.2 中，我们将由此产生的方法与其他流行的适配器合并基线进行比较。

4 实验

我们的实验旨在验证第 3 节中的理论预测并评估它们在非线性设置之外的迁移程度，而不是建立最先进的性能。由于我们的分析给出了最优正则化和适配器混合系数的闭式预测，我们测试这些量是否与现代架构中的经验行为匹配。具体而言，我们关注两个问题： 从我们的边际分析导出的混合系数是否与经验最优系数一致； 由此产生的理论驱动的合并规则 MaLoRA 在非线性模型中是否仍与适配器合并基线具有竞争力。正则化效果的实验推迟到附录 H.1.2。

设置和指标。 我们在两个互补的设置中评估我们的理论和方法。首先，在 CIFAR-100 上的线性探测（§4.1）中，我们使用四个冻结的预训练骨干网络（ResNet-50、ViT-B/16、ConvNeXt 和 CLIP）作为特征提取器，仅将 LoRA 应用于最终的线性分类器，并从 CIFAR-100 超类层次结构构建任务。其次，在多域适配器合并（§4.2）中，我们在 PACS、VLCS 和 TerraIncognita 上评估 ViT-B/16，以及在 MNLI、Amazon Reviews 和 CivilComments 上评估 XLM-RoBERTa Base。虽然我们的理论以归一化边际表述，但我们在实验中报告分类准确率，因为现实世界的分类任务通常不能实现完美分离且可能有负的归一化边际。更多细节见附录 H。

5 结论、局限性与未来工作

在本工作中，我们在近正交任务机制下通过归一化边际研究 LoRA 微调。我们刻画了三个正则化区间下正则化 LoRA 目标的全局最小值（定理 3.1），推导了预训练和微调数据上边际的闭式表达式，并识别了在其并集上最大化边际的正则化水平（定理 3.2）。我们进一步通过推导适配器合并的闭式最优混合系数（定理 3.3）将分析扩展到多任务设置。基于这一理论，我们提出了基于边际的 LoRA 合并（MaLoRA，算法 1），在一系列视觉和语言基准上匹配或优于几种适配器合并基线。跨架构和任务的经验结果与理论预测紧密一致。

局限性与未来工作。 首先，我们的分析依赖于简化假设，最显著的是近正交任务结构（假设 2.1）和微调数据中的平衡类别大小。这些假设实现了精确的闭式刻画，但也限制了理论的范围。未来工作的一个重要方向是放宽它们并在更一般的数据分布和预训练条件下研究 LoRA。其次，将 MaLoRA 应用于非线性模型的实验为我们的合并规则在多类线性分类之外的实用有用性提供了经验支持。这些发现激发了将基于边际的理论分析扩展到非线性适应。第三，我们的理论刻画了训练数据集上的边际；建立相应的泛化或测试风险保证需要进一步分析。

LoRA 的理论。 有许多工作在理论上研究 LoRA 的表达能力、刻画损失景观和理解学习动态。Zeng and Lee [2023] 证明在温和假设下 LoRA 可以近似任何深度线性、前馈或 transformer 网络。在 NTK 机制内，Malladi et al. [2023] 刻画了可以在 NTK 机制中研究 LoRA 的条件，而 Jang et al. [2024] 表明当 LoRA 秩 r_i ≳ √N（N 为样本数）时，LoRA 的优化景观没有伪局部最小值，GD 可以找到泛化良好的 O(√N) 秩解。此外，Xu et al. [2025] 在矩阵分解的背景下研究 LoRA 的学习动态，表明较小的初始化导致更长的训练时间和更低的训练误差。然而，这些研究都没有在理论上刻画为什么 LoRA 减少灾难性遗忘并支持有效的适配器合并。

LoRA 合并。 已经提出了多种技术通过形成任务特定 LoRA 适配器参数的加权平均来合并它们。例如，LoRA-Hub [Huang et al., 2023] 首先学习每任务混合系数，然后分别对 LoRA 权重矩阵 B 和 A 应用加权平均。LoRA-Flow [Wang et al., 2024] 引入 token 级门控，在取加权平均之前动态地为每个 LoRA 适配器分配合并系数。LoRA-Retriever [Zhao et al., 2024] 首先为每个输入检索最相关的适配器，然后平均选定的 LoRA 适配器。除了加权平均之外，另一条工作线尝试直接解决冗余和冲突更新。TIES [Yadav et al., 2023] 分三步进行：修剪冗余参数、将符号冲突解决为聚合向量，以及仅平均与聚合符号一致的参数，从而减轻冗余或冲突更新的退化。DARE [Yu et al., 2024] 可用作其他合并方法的预处理步骤，其中参数按指定比率随机丢弃，剩余参数重新缩放，减少合并适配器之间的冗余和潜在干扰。然而，所有这些方法在很大程度上仍是启发式的，缺乏理论保证。

正则化和任务正交性帮助减少遗忘。 微调和持续学习中的大量工作表明，控制微调模型与预训练模型的偏差可以减少灾难性遗忘。具体而言，这些方法施加权重空间惩罚，限制参数更新远离预训练解的幅度和方向。权重锚定和重要性感知惩罚体现了这一思想：Kirkpatrick et al. [2017] 惩罚沿 Fisher 信息矩阵识别的方向移动，而 Zenke et al. [2017] 在训练期间累积路径重要性。Schwarz et al. [2018] 将这一思想扩展到长任务序列。相关方法估计参数敏感性 [Aljundi et al., 2018]、应用输出级蒸馏以保持先前行为 [Li and Hoiem, 2016]，或显式将参数正则化到预训练锚点 [Li et al., 2018]。尽管这些方法在重要性或锚定的计算方式上有所不同，但共同机制是相同的：权重空间正则化器约束微调期间相对于预训练模型的更新以减轻灾难性遗忘。

另一个互补的视角强调了任务关系的作用。当任务表示充分去相关时，任务间的干扰自然减少，遗忘得到缓解。在线性和核化模型中，已经证明当任务正交或近似正交时，跨任务梯度干扰在期望中消失，意味着可忽略的遗忘 [Doan et al., 2021, Evron et al., 2022]。这些洞察与我们关于 LoRA 的分析产生共鸣，我们显式研究低秩适配器上的正则化目标，并做出微调数据与预训练数据正交的简化假设。这一假设直接连接到先前关于任务正交性的发现，并提供了一个可处理的设置，我们可以在其中分离和分析正则化在减轻遗忘中的作用。

附录 C 正交数据硬边际 SVM 解的刻画

在本节中，我们刻画正交数据的 K̄ 类分类问题的硬边际 SVM 解。我们证明该解与 K̄-ETF 单纯形密切相关。

问题表述。 考虑具有数据 {(x_{i,j}, y_i)}{i=1,j=1}^{K̄,n} 的 K̄ 类分类问题，其中：K̄ ≥ 2 是数据集中的类别数；n 是每类的样本数；y_i ∈ [K̄] 表示样本 x{i,j} 的类别标签；所有数据向量 x_{i,j} 具有单位范数：‖x_{i,j}‖ = 1；所有数据向量相互正交：x_{i,j}^T x_{k,l} = 0 对 ≠ (k,l)。

设 W ∈ ℝ^(K̄×d) 为线性分类器的权重矩阵，其中输入 x 的预测类别为 argmax_k(W_k x)。为简单起见，我们使用以下记号表示所有数据点：X = [x_{1,1}, ..., x_{K̄,n}]。

我们使用规范 ETF M_{K̄} := √(K̄/(K̄-1))(I_{K̄} - 1_{K̄}1_{K̄}^⊤/K̄)，对应于定义 2.1 中的 P = I_{K̄}。

定理 C.1（Frobenius 范数下的最大边际）。在上述数据假设下，任何非零线性分类器能实现的最大归一化边际为：

$$\gamma^{*}=\frac{1}{\sqrt{n(\bar{K}-1)}} \tag{19}$$

唯一的单位边际最小 Frobenius 范数 SVM 解为：

$$W^{\mathrm{SVM}}=\sqrt{\frac{\bar{K}-1}{\bar{K}}}\left(M_{\bar{K}}\otimes\bm{1}_{n}^{\top}\right)X^{\top}$$

归一化边际精确地由 W = cW^SVM（c > 0）最大化。

证明。 我们首先求解具有 K̄ 个输出类别的单位边际最小范数 SVM 问题 (3)。由命题 G.1，其解具有形式 W^SVM = AX^⊤（某 A ∈ ℝ^(K̄×K̄n)）。由于 X^⊤X = I_{K̄n}，logits 满足 W^SVM X = A 且 ‖W^SVM‖_F = ‖A‖_F。因此，A* 求解：

$$A^{*}=\arg\min_{A\in\mathbb{R}^{\bar{K}\times\bar{K}n}}\frac{1}{2}|A|{F}^{2}\quad\text{subject to}\quad A{i,(i-1)n+j}-A_{k,(i-1)n+j}\geq 1$$

该可行问题具有严格凸目标和凸约束集，因此其解唯一 [Burges and Crisp, 1999]。

我们利用此固定尺度问题的置换不变性来刻画 A。我们首先将 A 分解为块矩阵，即 A = [A₁ ⋯ A_{K̄}]，其中 A_i ∈ ℝ^(K̄×n)。

块矩阵内列置换的不变性。 在类块内置换列保持 (20) 中的约束和目标。因此，对任何置换矩阵 Π_i ∈ ℝ^(n×n)，矩阵 [A₁Π₁ ⋯ A_{K̄}Π_{K̄}] 也是最优的。唯一性给出 A_iΠ_i = A_i 对每个 Π_i，因此每个块的所有列相等：A_i* = v_i 1_n^⊤（某 v_i ∈ ℝ^K̄）。

跨块矩阵置换的不变性。 设 V := [v₁, ..., v_{K̄}]。同时置换输出行和对应的类块保持 (20) 中的约束和目标。唯一性因此给出 ΠVΠ^⊤ = V 对每个置换矩阵 Π ∈ ℝ^(K̄×K̄)。由引理 G.5，V = aI_{K̄} - b1_{K̄}1_{K̄}^⊤（某 a, b ∈ ℝ）。

标量优化。 单位边际约束简化为 a ≥ 1，且：

$$|A^{*}|_{F}^{2}=n\bar{K}(a-b)^{2}+n\bar{K}(\bar{K}-1)b^{2}=n\left[(\bar{K}-1)a^{2}+\bar{K}^{2}\left(b-\frac{a}{\bar{K}}\right)^{2}\right]$$

唯一最小值在 a = 1 和 b = 1/K̄ 处取得。因此：

$$W^{\mathrm{SVM}}=\left[\left(\bm{I}{\bar{K}}-\frac{1}{\bar{K}}\bm{1}{\bar{K}}\bm{1}{\bar{K}}^{\top}\right)\otimes\bm{1}{n}^{\top}\right]X^{\top},\quad|W^{\mathrm{SVM}}|_{F}=\sqrt{n(\bar{K}-1)}$$

这给出了所述的 ETF 公式且 C(W^SVM; 𝒟) = 1。

最后，任何具有 C(W; 𝒟) > 0 的分类器 W 可以重新缩放为可行的单位边际分类器 W/C(W; 𝒟)。最小范数最优性产生：

$$\gamma(W;\mathcal{D})=\frac{1}{|W/C(W;\mathcal{D})|{F}}\leq\frac{1}{|W^{\mathrm{SVM}}|{F}}=\frac{1}{\sqrt{n(\bar{K}-1)}}$$

等式精确地在 W/C(W; 𝒟) = W^SVM 时成立，由单位边际最小范数解的唯一性。因此所有归一化边际最大化器恰好是 W^SVM 的正倍数。具有非正边际的分类器不能达到这一正的最优值。∎
