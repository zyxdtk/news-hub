原标题：Introducing Claude Design by Anthropic Labs

中文摘要： Anthropic 推出 Claude Design，一款基于 Claude Opus 4.7 视觉模型的新产品，允许用户与 Claude 协作创建设计、原型、幻灯片等视觉内容。适用于 Pro 及以上订阅用户。功能包括内置品牌系统、多源导入、精细化调整、团队协作及导出至 Canva 等。旨在帮助设计师探索创意，辅助非设计背景人员快速产出视觉作品，并实现从原型到代码的无缝移交。

URL 来源：https://www.anthropic.com/news/claude-design-anthropic-labs Markdown 内容： 今天，我们推出 Claude Design，这是 [Anthropic Labs](https://www.anthropic.com/news/introducing-anthropic-labs) 的一款新产品，让您能够与 Claude 协作创建设计、原型、幻灯片、单页文档等精美的视觉作品。

Claude Design 由我们最强大的视觉模型 [Claude Opus 4.7](https://www.anthropic.com/news/claude-opus-4-7) 提供支持，目前作为研究预览版向 Claude Pro、Max、Team 和 Enterprise 订阅者开放。我们将全天逐步向用户推送。

即使是经验丰富的设计师也不得不限制探索范围——很少有时间去原型化十几个方向，所以你会限制自己只尝试几个。而对于有想法但没有设计背景的创始人、产品经理和营销人员来说，创建和分享这些想法可能令人生畏。

Claude Design 为设计师提供了广泛探索的空间，也为其他人提供了制作视觉作品的方法。描述你的需求，Claude 就会构建第一个版本。从此处开始，你可以通过对话、内联评论、直接编辑或自定义滑块（由 Claude 制作）进行细化，直到满意为止。当获得访问权限时，Claude 还可以自动将团队的设计系统应用到每个项目中，因此输出结果与公司其余设计保持一致。

团队一直在使用 Claude Design 进行： * **逼真的原型：** 设计师可以将静态模型转换为易于共享的交互式原型，以收集反馈和进行用户测试，无需代码审查或 PR。 * **产品线框图和模型：** 产品经理可以 sketch 出功能流程，并将其移交给 Claude Code 进行实施，或与设计师分享以进一步细化。 * **设计探索：** 设计师可以快速创建多种方向进行探索。 * **路演 deck 和演示文稿：** 创始人和客户经理可以在几分钟内从粗略大纲转换为完整的、符合品牌的 deck，然后导出为 PPTX 或发送到 Canva。 * **营销材料：** 营销人员可以创建落地页、社交媒体资产和活动视觉图，然后让设计师介入润色。 * **前沿设计**：任何人都可以构建带有语音、视频、着色器、3D 和内置 AI 的代码驱动原型。 ## 工作原理 Claude Design 遵循自然的创作流程。 **内置你的品牌。** 在入职期间，Claude 通过读取你的代码库和设计文件为你的团队构建设计系统。之后的每个项目都会自动使用你的颜色、排版和组件。你可以随着时间的推移细化系统，团队可以维护多个系统。 **从任何地方导入。** 从文本提示开始，上传图片和文档（DOCX、PPTX、XLSX），或让 Claude 指向你的代码库。你还可以使用网页捕获工具直接从网站抓取元素，以便原型看起来像真实产品。 **通过细粒度控制进行细化。** 对特定元素进行内联评论，直接编辑文本，或使用调整旋钮实时微调间距、颜色和布局。然后让 Claude 将你的更改应用到整个设计中。 ![Image 1](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F499e91975d880b35eac6e48ad43161de7d10416c-2876x1614.jpg&amp;w=3840&amp;q=75) **协作。** 设计具有组织范围内的共享功能。你可以将文档保持私密，共享以便组织中任何拥有链接的人都可以查看，或授予编辑权限以便同事可以修改设计并在群聊中与 Claude 一起聊天。 **导出到任何地方。** 将设计作为组织内部的 URL 共享，保存为文件夹，或导出到 Canva、PDF、PPTX 或独立的 HTML 文件。 **移交给 Claude Code。** 当设计准备好构建时，Claude 会将所有内容打包成一个移交 bundle，你可以通过单条指令将其传递给 Claude Code。
