原标题：Google launches Gemini 4 Hydrogen — a faster, smarter, pricier Flash successor

中文摘要： 谷歌发布 Gemini 4 Hydrogen，默认推理设置下完成任务速度为 Gemini 3.8 Flash 的 2.5 倍，智能指数达 51 分。标准费率为每百万输入 token 1.50 美元、输出 7.50 美元，约为 Claude Haiku 5.5、GPT-6 Luna 等竞品最低标准费率的 15 倍。该模型在终端操作等智能体任务上提升显著，可承担部分原本由更大型推理模型处理的工作，但是否划算取决于任务原本分配给哪个模型。

谷歌于周四发布了 Gemini 4 Hydrogen，为开发者提供了一个更快的模型，可用于编写代码、处理文档以及运行需要多个步骤才能完成任务的 AI 智能体。

谷歌表示，在 Hydrogen 的默认推理设置下，Hydrogen 完成任务的速度是 Gemini 3.8 Flash 的 2.5 倍。在 Artificial Analysis 的独立测试中，该设置下的 Hydrogen 在该公司的智能指数（Intelligence Index）上得分为 51 分，高于 Flash 在高推理设置下的 31 分，并领先高推理设置下的 Gemini 4 Argon 1 分。

这使得 Hydrogen 处于一个不同寻常的位置。它可以承担团队原本可能交给更昂贵推理模型的部分工作，但其未缓存输入和输出 token 的单价是 Anthropic 的 Claude Haiku 5.5、OpenAI 的 GPT-6 Luna 和 Meta 的 Muse Ember 最低标准费率的 15 倍。

谷歌列出的 Gemini API 标准付费费率为：每百万未缓存输入 token 1.50 美元、每百万缓存输入 token 0.075 美元、每百万输出 token 7.50 美元（包括推理 token）。谷歌没有为 Hydrogen 的标准层级提供任何首发促销。

Batch、Flex 和 Contributor 各按标准费率的一半收费。Batch 在后台处理成组请求，目标周转时间为 24 小时。Flex 以较低优先级处理单个请求，目标响应时间为 1-15 分钟，在需求高峰期可用性有限。仅限受邀的 Contributor 层级提供标准层级的速度和可靠性，交换条件是允许谷歌使用参与请求的数据来改进其产品并训练模型。

对于要决定在编程助手、文档处理器或客户支持工具背后部署哪个模型的公司来说，问题在于 Hydrogen 的额外能力能多频繁地省下一次重试、捕获一个错误，或完成一项更便宜的模型会遗漏的工作。

Gemini 3.8 Flash 用户迎来哪些变化

谷歌报告的最大提升之一出现在需要智能体操作终端的工作上。在谷歌的 Terminal-Bench 4.1 评估中，Hydrogen 完成了 57% 的任务，而在谷歌的发布对比中 Flash 为 18.2%。在谷歌的表格中，它仍落后于 Claude Sonnet 5.5 的 63.9%。

谷歌还报告称，当工具调用失败或搜索返回空结果时，Hydrogen 能更可靠地恢复。在代码库中，这可能意味着在第一次尝试失败后换一种搜索方式或读取另一个文件。

根据 Box 首席执行官 Aaron Levie 在 X 上发布的图表，在一次早期访问测试中，Box 的智能体在其 Complex Work Eval 上的准确率从使用 Flash 时的 74% 提升到使用 Hydrogen 时的 79%。Levie 表示，在典型任务上，Hydrogen 所用时间不到一半，消耗的 token 减少了约 12%。

Box 的 AI 产品团队告诉谷歌，他们在需要读取表格和进行计算的工作上看到了最大的改进。Levie 表示 Box AI Studio 的支持即将推出。速度和准确性的提升只是故事的一部分。账单还取决于这些 token 中有多少被缓存，以及模型需要重复多少工作。

对于迁移现有应用的开发者，谷歌的迁移指南列出了模型名称之外的变化。Hydrogen 默认使用高推理（Flash 默认为中等），并新增了 xhigh 选项。它不再支持旧的 thinking_budget 参数和 MINIMAL 设置。

在 Google Cloud 上，自动缓存的起始门槛为 4,096 token（Flash 为 6,144），显式缓存在发布时尚不可用。Hydrogen 接受文本、图像、音频和视频，Google Cloud 可以直接摄取 Office 和 OpenDocument 文件。其约 100 万 token 的窗口由输入和输出共享，包括推理 token 和工具调用。受支持的 API 可以在超过单个前台片段 65,536 token 的限制后继续生成。

Hydrogen 与 Haiku、Luna 和 Ember 的比较

谷歌的标准全球费率为每百万输入 token 1.50 美元、每百万输出 token 7.50 美元，缓存输入为每百万 0.075 美元。这些费率在整个上下文窗口内保持不变。这与 Flash 自 2027 年 1 月 1 日起的计划标准定价一致，是 Flash 在 12 月 31 日前首发期费率的两倍。谷歌的弃用时间表没有列出 Flash 的关闭日期。

即使在中档设置下，Hydrogen 的得分也超过了最高设置下的 Haiku、Luna 和 Ember，但其每项任务的估计成本高于这三者中的任何一个。优势体现在一些编程测试中。在 Artificial Analysis 单独进行的 Terminal-Bench 4.0 测试中，Hydrogen 在 high 和 xhigh 设置下均得分为 54%，而 Ember 为 40.9%、Luna 为 12.6%、Haiku 为 32.8%（三者均在最高设置下）。

在另一项编程测试 FrontierCode 2.0 中，Haiku 以 34.9% 对 27.2% 击败了 Ember。对于已经付费使用 Hydrogen 的团队来说，更高的推理设置在 Terminal-Bench 4.0 上没有带来任何改进，却将整个套件的估计成本从 1.87 美元推高到 3.16 美元。

这三家美国竞争对手在接受的输入类型和运行平台上也有所不同。Haiku 接受文本和图像，可通过 Anthropic、Amazon Bedrock、Google Cloud 和 Microsoft Foundry 使用。对于超过 100,000 token 的提示，其 API 费率升至输入 0.50 美元、输出 2.50 美元。

Luna 通过 OpenAI 的 API 接受文本和图像，对于超过 272,000 输入 token 的提示，费率为输入 0.20 美元、输出 0.75 美元。

Meta 自己的 Ember API 除了文本、图像和 PDF 之外，还接受音频和视频。Ember 也已进入 Muse Code，Google Cloud 提供文本和图像预览。超过 200,000 输入 token 时，Meta 的费率升至输入 0.30 美元、输出 1.50 美元。

中国开放权重模型的定位

DeepSeek V4.1 Flash 1017 提供文本和图像输入、百万 token 窗口以及 MIT 许可的权重。DeepSeek 的托管 API 在非高峰时段降至输入 0.15 美元、输出 0.60 美元。

小米的 MiMo-V2.6-Flash 同样提供 MIT 许可的权重，可下载模型的文档中记录了对音频和视频的支持。Artificial Analysis 将小米的托管 Flash 模型定价为每项基准任务 0.13 美元，而高设置下的 Hydrogen 为 1.87 美元，两者综合得分相差 24 分。开放权重让公司可以选择自己运行模型或购买托管访问，自托管则需承担相应的硬件和运营成本。

月之暗面的 Kimi K3.1 Pro 在能力上更为接近。通过 Kimi 的 API，它得分为 46，每项任务的估计成本为 3.68 美元。其权重附带月之暗面自己的许可证，并且有多家提供商托管该模型。即使在谷歌托管模型在这一特定基准上占优的情况下，这也为买家提供了更多部署选择。

在哪里获取 Hydrogen

Hydrogen 正通过 Gemini API、AI Studio、Gemini for business、Gemini 应用和 Google Search 在全球推出。免费 Gemini 应用用户可通过自动模型选择获得该模型。个人使用 Antigravity 需要 Google AI Pro 或 Ultra 订阅。

Google Cloud 已将 gemini-4-hydrogen 列为正式可用（GA），谷歌表示符合条件的商业订阅也将在 Gemini in Sheets 中获得该模型。

谷歌还在 Antigravity 中加入了模型之间的选择能力。其新的 Orchestrator 可以在同一会话中在 Carbon 和 Hydrogen 之间切换。谷歌报告称，这种组合设置在 Terminal-Bench 4.0 上的成功率接近 Carbon，同时完成速度加快 19%，配额消耗减少 24%。

这使得 Hydrogen 适用于两种不同的工作：接管 Flash 的任务，以及承担原本由更大模型完成的部分工作。能省下多少钱，取决于这些工作原本会交给哪个模型。
