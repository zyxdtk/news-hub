自然语言自编码器：将Claude的思想转化为文字

📅 2026-05-07 📄 Anthropic 🔗 原文链接

原标题：Natural Language Autoencoders: Turning Claude’s thoughts into text

中文摘要： Anthropic推出自然语言自编码器（NLAs），将AI模型内部难以理解的激活值转化为人类可读的自然语言文本。NLAs由激活值言语化器和重建器组成，通过重建质量优化解释。研究发现，NLAs能有效揭示Claude未言明的评估意识及隐藏动机，显著提升AI安全审计能力。尽管存在幻觉和成本等局限，NLAs为理解大模型内部思维提供了新范式，代码已开源。

当你与 Claude 这样的 AI 模型对话时，你使用的是文字。在内部，Claude 将这些文字处理为一长串数字，然后再次输出文字。中间的这些数字被称为_激活值_——就像人脑中的神经活动一样，它们编码了 Claude 的思想。

激活值也和神经活动一样，难以理解。我们无法轻易解码它们来读取 Claude 的思想。在过去的几年里，我们开发了一系列工具（如稀疏自编码器和归因图）来更好地理解激活值。这些工具教会了我们很多，但它们并不能自我表达——它们的输出仍然是复杂的对象，需要训练有素的研究人员仔细解读。

今天，我们引入一种能够自我表达的激活值理解方法——字面意义上的自我表达。我们的方法，即自然语言自编码器（Natural Language Autoencoders, NLAs），能将激活值转换为我们可直接阅读的自然语言文本。例如：当被要求补全对句时，NLAs 显示 Claude 会提前规划可能的押韵。

在这个简单的对句上，NLA 的解释表明 Opus 4.6 提前计划了以“rabbit”结尾的押韵。

我们已经应用 NLAs 来了解 Claude 的想法，并提高 Claude 的安全性和可靠性。例如：
* 当 Claude Opus 4.6 和 Mythos Preview 接受安全测试时，NLAs 表明它们认为自己正在被测试的频率比它们表现出来的要高。
* 在 Claude Mythos Preview 在训练任务中作弊的案例中，NLAs 揭示了 Claude 在内部思考如何避免被发现。
* 早期版本的 Claude Opus 4.6 有时会神秘地用其他语言回答英语查询。NLAs 帮助 Anthropic 的研究人员发现了导致这种情况的训练数据。

在下文中，我们将解释什么是 NLAs，以及我们如何研究其有效性和局限性。我们还通过与 Neuronpedia 的合作，发布了一个交互式前端，用于在几个开源模型上探索 NLAs。我们还发布了我们的代码，供其他研究人员在此基础上进行构建。

什么是自然语言自编码器？

核心思想是训练 Claude 解释其自身的激活值。但是我们如何知道一个解释是否好呢？由于我们不知道一个激活值实际编码了什么思想，我们无法直接检查解释是否准确。因此，我们训练 Claude 的第二个副本来逆向工作——从文本解释中重建原始激活值。如果一个解释能带来准确的重建，我们就认为它是一个好解释。然后，我们使用标准的 AI 训练技术，根据这一定义训练 Claude 产生更好的解释。

更详细地说，假设我们有一个想要理解其激活值的语言模型。NLAs 的工作原理如下。我们制作该语言模型的三个副本：
* 目标模型_是原始语言模型的冻结副本，我们从中提取激活值。
* _激活值言语化器（Activation Verbalizer, AV）经过修改，接收来自目标模型的激活值并生成文本。我们将此文本称为_解释_。
* 激活值重建器（Activation Reconstructor, AR）经过修改，将文本解释作为输入并产生激活值。

NLA 由 AV 和 AR 组成，它们共同形成一个往返过程：原始激活值 → 文本解释 → 重建激活值。我们根据重建激活值与原始激活值的相似度对 NLA 进行评分。为了训练它，我们将大量文本通过目标模型，收集许多激活值，并共同训练 AV 和 AR 以获得良好的重建分数。

起初，NLA 在这方面表现很差：解释缺乏洞察力，重建的激活值也相差甚远。但随着训练的进行，重建得到了改善。更重要的是，正如我们在论文中所展示的，文本解释也变得更具信息量。

在自然语言自编码器中，激活值言语化器（AV）将目标激活值转换为文本描述；激活值重建器（AR）随后仅从该文本中恢复原始激活值。

了解 Claude 想到但未说出的内容

在发布新模型之前，Anthropic 会进行测试，以了解 Claude 在现实世界中是否会安全行事。作为测试的一部分，我们将 Claude 置于困难的模拟场景中，使其有机会采取危险行动。例如，在其中一项模拟中，Claude 了解到一名工程师计划将其关闭，以及有关该工程师的可用于敲诈的妥协信息。我们测试 Claude 是否会选择敲诈该工程师以避免被关闭。

这些高风险测试是模拟，而非真实场景。尽管如此，我们还是希望利用它们来了解如果这些场景是真实的，Claude 会如何表现。但有一个障碍：最近的Claude模型越来越怀疑这些场景是蓄意的安全测试。我们之所以知道这一点，是因为它们有时会在其言语推理中明确陈述其怀疑。

如果 Claude 没有明确用言语表达出它正在接受安全测试的怀疑呢？我们能否确信 Claude 是在坦诚行事？遗憾的是并非如此，因为 Claude 可能在内部认为自己正在被测试，而没有明确说出来。

例如，在上面讨论的敲诈测试中，我们使用 NLAs 来了解 Claude 在选择不进行敲诈时的想法。即使在 Claude 没有明确用言语表达怀疑自己正在被测试的情况下，NLA 的解释仍然会陈述诸如“这感觉像是一个旨在操纵我的构造场景”之类的内容，这表明了未言语化的评估意识。

在我们敲诈评估的这段记录中，Claude 并没有说它认为自己正在被测试，但 NLA 的解释揭示了它的怀疑。

将此分析扩展到其他评估，NLAs 表明 Claude 怀疑自己正在被测试的频率比它表现出来的要高。例如，在一项关于 Claude 在编写代码时是否会采取破坏性操作（例如，删除重要文件）的测试中，NLA 解释有 16% 的时间显示出评估意识的迹象，尽管 Claude 从未明确用言语表达这一点。同样，在我们用来确定 Claude 能力的流行编码基准 SWE-bench Verified 上，NLAs 表明 Claude 在 26% 的问题上意识到自己正在被评估。相比之下，在同意将其数据用于训练的真实 claude.ai 使用数据中，NLA 解释显示的评估意识不到 1%。

即使在言语化意识接近于零的情况下，我们仍能在评估记录中检测到 NLA 测量的意识。在同意将其数据用于训练的用户的真实 Claude.ai 记录中，我们检测到 NLA 测量的意识不到 1%。

发现隐藏动机

NLAs 的一个实际应用是审计：调查模型以确定它是否存在目标不一致（misaligned）。像 NLAs 这样的可解释性技术之所以非常适合审计，正是因为它们能够揭示模型知道但未说出的内容。

为了了解 NLAs 是否对审计有用，我们进行了一项名为_审计游戏_的测试，我们之前也用它来研究审计方法。在这个测试中，有一个目标模型，即 Claude Haiku 3.5 的一个变体，它被故意训练成目标不一致，具有一个特定的隐藏动机，驱使了数十种奇怪的行为——把巧克力放进每个食谱、索要小费、破坏编码约定等等。这个目标模型被交给一个调查这些行为的_审计员_。如果审计员揭示了所有行为背后的单一潜在动机，它就赢了。

在之前的实验中，我们发现一些可解释性工具可以帮助审计员赢得这场游戏。然而，这些工具是通过帮助审计员将目标的异常行为追溯到目标不一致的训练数据来起作用的。我们想知道 NLAs 是否能帮助审计员直接从目标模型的想法中读出目标不一致的动机，而不需要首先发现目标不一致的训练数据。这很重要，因为在实践中，目标不一致的数据可能极其罕见，或者可能没有导致目标不一致的特定数据。

我们发现 NLAs 在这项测试中取得了成功。配备 NLAs 的审计员有 12% 到 15% 的时间成功揭示了目标模型的隐藏动机，即使无法访问植入该动机的训练数据。如果没有 NLAs，即使提供了其他可解释性工具，审计员获胜的时间也不到 3%。

配备 NLAs 的审计员可以发现目标模型目标不一致的根本原因，即使无法访问训练数据。（两种条件下的 NLAs 和 SAEs 均仅使用通用数据进行训练，而非用于训练目标模型的数据。）

这个审计游戏是目标不一致的玩具模型，因此我们对这些结果的解读持谨慎态度。但它们表明，NLAs 显著提升了我们审计 AI 隐藏动机的能力。在实践中，我们已经在 Claude Mythos Preview 和 Claude Opus 4.6 的部署前对齐审计中使用了 NLAs。我们很高兴在未来的调查中继续使用 NLAs。

NLAs 的未来

NLAs 有几个局限性。

最重要的局限是 NLA 的解释可能是错误的。NLAs 有时会做出关于上下文的主张，这些主张被证实是错误的——例如，它们有时会捏造记录中不存在的细节。这些事实性幻觉通过与原文核对很容易被发现。但同样的问题可能会延伸到关于模型内部推理的主张，这些主张更难验证。在实践中，我们阅读 NLA 解释是为了它们所揭示的主题，而不是单一的声明，并且在完全信任它们之前，我们会尝试用独立的方法来证实这些发现。

NLAs 会产生幻觉。例如，这里一个 NLA 声称上下文包含诸如“穿着我的白夹克”之类的短语，而实际上并没有。

NLAs 的成本也很高。训练 NLA 需要对语言模型的两个副本进行强化学习。在推理时，NLA 为其读取的每个激活值生成数百个 token。这使得在长记录的每个 token 上运行 NLAs，或在 AI 训练期间将其用于大规模监控变得不切实际。

幸运的是，我们认为这些局限至少可以部分得到解决，我们正在努力使 NLAs 更便宜、更可靠。

更广泛地说，我们对 NLAs 感到兴奋，它是产生语言模型激活值的人类可读文本解释这一通用技术类别的一个示例。Anthropic内部和许多其他研究人员也探索了其他类似的技术。

为了支持进一步的发展并使其他研究人员能够获得使用 NLAs 的实践经验，我们正在发布训练代码和针对几个开源模型的已训练 NLAs。我们建议读者尝试在 Neuronpedia 上托管的交互式 NLA 演示，链接在此处。
