跨语言迁移与无监督聚类的低资源班图语零样本词法发现

📅 2026-04-24 📄 arxiv 🔗 原文链接

原标题：Zero-Shot Morphological Discovery in Low-Resource Bantu Languages via Cross-Lingual Transfer and Unsupervised Clustering

中文摘要： 本文提出一种结合跨语言迁移学习和无监督聚类的方法，用于低资源班图语的零样本词法发现。在仅有91个标注词形变化表的Giriama语中，该方法发现了2,455个名词类别分配，并识别出两种此前未记录的词法模式（a-前缀变体和k'-缩约前缀）。外部验证显示词形还原准确率达78.2%。该方法利用了迁移学习在同源词检测上的优势与聚类在发现特定语言创新上的互补性，并在16种班图语中成功扩展，发现了11,923个词形变化表。

基于跨语言迁移和无监督聚类的低资源班图语零样本词法发现 Hillary Mutisya Thiomi NLP John Mugane 哈佛大学

摘要 我们提出了一种结合跨语言迁移学习和无监督聚类来发现低资源班图语词法特征的方法。应用于仅有91个标注词形变化表的Giriama语（nyf），我们的流程为2,455个单词发现了名词类别分配，并识别出两种此前未记录的词法模式：第2类的a-前缀变体（wa-的元音融合——两个相邻元音的合并，95.1%一致性）和缩约的k'-前缀（98.5%一致性）。在444个已知Giriama动词词形变化表上的外部验证确认了78.2%的词形还原准确率，同时扩展至19,624个单词（9,014个唯一词元）的v3语料库在所有主要词类上实现了97.3%的切分率和86.7%的词形还原率。我们结合了来自斯瓦希里语的迁移学习和无监督聚类的集成方法，通过加权投票结合，利用了互补优势：迁移学习擅长同源词检测（利用约60%的词汇重叠），而聚类能发现迁移学习无法察觉的特定语言创新。我们发布了所有代码和发现的词汇表，以支持低资源班图语的词法记录。

1. 引言 1.1 动机 词法分析是语言记录和自然语言处理的基础，然而世界上7000多种语言中的大多数缺乏全面的词法资源。这对于班图语系（500多种语言，3亿多使用者）尤为严重，其名词类别系统——一种决定性的类型学特征——在许多语言中仍未被记录。 以Giriama语（Guthrie分类中的班图语E.72b，约60万使用者，肯尼亚海岸）为例：尽管是一种拥有大量使用人群的活语言，但在计算形式上仅存在91个词法词形变化表（带有语法特征的标注词-词元对）。标准的监督学习方法在如此少的数据下将实现很差的覆盖率。然而，Giriama语与斯瓦希里语（拥有816个以上词形变化表的高资源亲属语言）共享大约60%的词汇，这表明跨语言迁移可能是可行的。

1.2 研究问题 发现流程建立在BantuMorph（Mutisya和Mugane，2026）之上，这是一个在16种班图语言上训练用于词法分析的ByT5-small字符级模型。BantuMorph的编码器将任何班图语言的单词映射到一个共享的嵌入空间，其中词法相似的单词——包括跨语言同源词——聚集在一起。我们利用这一特性在Giriama和其他15种班图语言中进行零样本名词类别发现。 本研究解决了三个关键问题： 1. 零样本发现：我们能否在极少监督（n&lt;100个词形变化表）下发现低资源语言的词法特征？ 2. 特定语言创新：无监督方法能否识别目标语言独有的词法模式？ 3. 方法互补性：跨语言迁移和无监督聚类如何在词法发现中相互补充？

1.3 贡献 1. 新颖的多方法途径：我们结合了迁移学习（嵌入空间中的K近邻）、无监督聚类（UMAP + K-means）和集成验证。 2. 经验验证：在Giriama语上，我们发现了2,455个名词类别标签（增加27倍），并在444个已知词形变化表上验证了底层模型（78.2%的词形还原准确率）。 3. 语言学发现：两种此前未记录的Giriama模式：a-前缀变体（第2类，95.1%一致性）和k'-缩约前缀（98.5%一致性）。 4. 可扩展性：我们的方法仅需一个字符级预训练模型、一种相关的高资源语言和一个小型未标注语料库。 5. 开放资源：代码、发现的词汇表和可视化。

2. 相关工作 2.1 低资源语言的词法分析 监督方法需要大型标注数据集。半监督方法减少了标注负担但仍需种子数据。无监督词法诱导在无监督下发现结构，但在罕见词缀上表现不佳。跨语言迁移利用类型学相似性，在相关语言中显示出前景，但遗漏了特定语言的创新。我们的工作结合了这两种方法。

2.2 班图语词法 班图语表现出丰富的黏着词法，带有名词类别系统。每个名词属于15-20个类别之一，由前缀标记，触发句子中动词、形容词和其他词的一致关系。关于班图语词法的计算工作包括斯瓦希里语、祖鲁语的分析器以及最近的神经方法。大多数500多种班图语言在计算上仍研究不足。

2.3 基于嵌入的词法分析 上下文嵌入捕获词法句法信息。字符级模型自然地处理词法变化。跨语言嵌入实现迁移。ByT5是我们的基础模型，在字符级操作，并在词法丰富的语言中显示出强大的跨语言迁移能力。

3. 方法论 图1展示了我们的三组件流程。

图1：三阶段发现流程。第1行：数据源（标注的斯瓦希里语名词 + 未标注的Giriama语料库）。第2行：两种互补方法——KNN迁移发现同源词，聚类发现创新。第3行：加权集成产生高置信度名词类别标签。

3.1 问题表述 输入： • M：字符级预训练模型（ByT5） • Ls：带有名词类别标签的高资源源语言（斯瓦希里语） • Lt：低资源目标语言（Giriama语） • Ps = {(wi, ci)}_{i=1}^{Ns}：Ls中的标注词形变化表 • Ct：Lt中的未标注语料库 输出：Lt中单词的名词类别分配 Ĉ = {(wj, ĉj, confj)}_{j=1}^{Nt}。

3.2 方法1：通过跨语言投影的迁移学习 直觉：相关语言共享具有相似嵌入的同源词；最近邻可能具有相同的名词类别。

清单1：迁移学习算法 ⬇ 1. 提取嵌入： 对于 Ls 中的每个词 w：es[w] = M.encode(w) 对于 Lt 中的每个词 w：et[w] = M.encode(w) 2. 对于每个目标词 wt： a. 找到 K=5 个最近源语言邻居 b. 通过多数投票进行类别投票 c. 置信度 = vote_conf x sim_conf 3. 返回：{(wt, c_pred, conf)}

工作原理：BantuMorph的编码器将任何班图语言的单词映射到一个1472维空间，其中词法相似的单词聚集在一起。对于像Giriama语akimbola这样的目标语言单词，5个最近的斯瓦希里语邻居可能都是第2类复数形式（例如，wanafunzi, watu），从而产生与邻居协议和余弦相似度成比例的第2类预测。 优点：同源词上的高精度（Giriama-斯瓦希里语约60%词汇重叠）；可解释；利用标注的源数据。 局限性：无法检测源语言中不存在的特定语言创新（参见第6节了解聚类如何解决这一差距）。

3.3 方法2：无监督聚类 直觉：由于共享前缀模式和一致关系语境（名词触发动词和修饰语上的匹配前缀），同一名词类别的单词在嵌入空间中聚集。

清单2：聚类算法 ⬇ 1. 从语料库 Ct 中提取名词候选 2. 降维： - UMAP：降至 d=50 维 3. 聚类： - K-means，K=12 个聚类 4. 分析每个聚类： - 提取前缀模式（前1-3个字符） - 通过前缀-类别表映射到名词类别 5. 返回：{(w, c_cluster, consistency)}

工作原理：UMAP将高维嵌入投影到50维，保留局部结构。K-means（K=12，匹配能产的（积极用于构词的）班图语名词类别的典型数量）将单词划分为聚类。每个聚类通过提取主要前缀模式（前1-3个字符）并与跨语言编译的班图语前缀清单（例如，ma- → 第6类，ki- → 第7类）匹配来映射到名词类别。没有明确前缀匹配的聚类被标记为“未知”。 优点：发现迁移无法看到的特定语言模式；无需标注数据。 局限性：精度较低；聚类到类别的映射是启发式的，对于具有歧义前缀的类别可能会失败（例如，mu-：第1类或第3类）。

3.4 方法3：集成验证 直觉：多方法一致性表明高置信度预测；分歧揭示歧义或创新。

清单3：集成投票 ⬇ 对于被多种方法预测的每个词 w： score(class) = Sum weight(m) x confidence(m, c) weights = {transfer: 1.0, clustering: 0.8} 要求最低阈值为 0.70

优点：最高精度；保守；识别歧义情况。

4. 实验设置 4.1 数据 模型：BantuMorph v7（ByT5-small，300M参数），在16种班图语言上训练，包含80,765个词形变化表，涵盖5项任务（切分、词形还原、屈折变化、特征提取、名词类别预测）。嵌入是从编码器最后一层提取的，对字节序列进行平均池化。 源语言（斯瓦希里语）：816个带有名词类别标签的条目；14个名词类别（1–11, 14–16）。 目标语言（Giriama语）：91个训练词形变化表（仅动词，来自UniMorph）；7,812个来自英语-Giriama语平行数据集的句子（Lingua-Connect，2025）；约600,000使用者（肯尼亚海岸）；班图语E.72b（肯尼亚海岸米吉肯达班图语群的一员）。Giriama语与斯瓦希里语共享大约60%的词汇。

4.2 实现 迁移学习：K=5个最近邻；ByT5嵌入空间中的余弦相似度；置信度阈值0.60。 聚类：UMAP（降至50维）；K-means（K=12）。^1 ^1 完整UMAP超参数：n_neighbors=15, min_dist=0.1；K-means random_state=42。 集成：权重：迁移=1.0，聚类=0.8（由于迁移使用了标注的源数据，其权重更高；权重通过启发式设置，发现对适度变化不敏感）；最低置信度0.70。 我们区分两个质量指标：置信度是集成对每个词的预测分数，结合了邻居协议和余弦相似度；一致性是聚类中共享主要前缀模式的单词百分比。 运行时间：约15分钟处理1,000个句子。^2 ^2 Python 3.10, PyTorch 2.0, Transformers 4.30, UMAP 0.5, scikit-learn 1.3。

4.3 基线 (1) 频率基线：将最常见的类别（第6类）分配给所有单词；(2) 随机基线；(3) 仅迁移；(4) 仅聚类。

5. 结果 我们首先详细介绍Giriama案例研究（第5.1–5.3节），然后是多语言扩展结果（第5.4节）。

5.1 Giriama语：名词类别发现 应用于Giriama语料库（7,812个句子），集成流程发现了2,455个单词的名词类别分配（比91个已知词形变化表增加27倍）。迁移学习贡献了8,698个预测（平均置信度0.71）；无监督聚类贡献了18,508个；高置信度集成了5,279个。 跨方法一致性。Giriama语上的迁移-聚类一致性为36.7%。一致性在词法透明的特征上最高（非限定形式78.3%，现在时61.2%），在复杂或罕见形式上最低（将来时29.6%，完成时21.2%）。较低的整体一致性反映了两种方法的互补性（第6节）。

5.2 新颖的Giriama语词法发现 5.2.1 a-前缀变体（第2类） 从斯瓦希里语的迁移会将标准wa-前缀分配给第2类单词。无监督聚类识别出聚类1（266个单词，95.1%一致性）使用a-前缀变体：wa- → a-的元音融合，这是海岸班图语方言的特征： ⬇ akimbola "他们跑了" (参斯瓦希里语 wakimbilia) akimanywa "他们被知道了" (参斯瓦希里语 walijulikana) akimwamba "他们告诉他" (参斯瓦希里语 walimwambia) 这种模式占Giriama语料库中所有第2类单词的19.6%，并且是迁移学习无法检测到的。

5.2.2 Giriama语k'-缩约（98.5%一致性） 聚类识别出聚类8（206个单词，98.5%一致性）带有k'-（撇号表示省音）。迁移学习未检测到此模式；斯瓦希里语中不存在对应形式： ⬇ k’adzamuhala "他/她不在乎" k’ahendzeze "他/她取悦" k’ululu "自由/解放" 可能解释：ku- → k'-不定式缩约（快速语流）或原始班图语叙事ka- → k'-。这种模式需要Giriama语语言学家的验证。

5.3 已知Giriama语词形变化表的外部验证 为了解决名词类别发现缺乏黄金标准的问题，我们在来自UniMorph的444个已知Giriama语动词词形变化表（95个唯一词元）上评估了底层的BantuMorph模型，这些并未用于发现流程中。

| 任务 | 准确率 | | --- | --- | | 词形还原 | 78.2% (347/444) | | 屈折变化（补全）| 54.3% (241/444) |

表1：BantuMorph v7在444个已知Giriama语动词词形变化表上的准确率（外部评估）。模型未在这些词形变化表上训练。

78.2%的词形还原准确率表明，模型通过从相关语言的跨语言迁移学习了能产的Giriama语词法模式，验证了名词类别发现所基于的基础。在95个已知Giriama语词元中，25个（26%）出现在基于迁移的发现中，7个（7%）出现在集成发现中，确认了流程正确识别了已知词汇，同时将覆盖范围扩展到以前未记录的形式。

扩展语料库分析（v3）。单语语料库提取将覆盖范围从444个词形变化表扩展到19,624个单词（9,014个唯一词元），实现了97.3%的切分率和86.7%的词形还原率。词性分布——84.9%动词（16,665），10.5%名词（2,066），3.1%形容词（618），1.4%所有格（273）——表明BantuMorph泛化到了所有主要的Giriama语词类，而不仅仅是发现流程所针对的名词系统。 在2,066个验证的名词中，证实了9个名词类别，其中BANTU7（ki-/chi-，559个名词）最具能产性，其次是BANTU14（u-/bu-，371），BANTU9（N-，262）和BANTU6（ma-，261）。 第7类在Giriama语中的高能产性——超过第6类——与斯瓦希里语源数据形成对比，并支持了特定语言语料库分析的互补价值。

5.4 多语言扩展 我们将相同的三方法流程（迁移+聚类+集成）应用于所有16种班图语言。对于每种语言，迁移学习使用斯瓦希里语作为主要源（该语系中资源最高的语言）；对于J区域语言，卢旺达语也作为迁移源，因为词汇重叠度更高。聚类在未标注语料库上按语言独立运行。 我们将内部一致性衡量为模型能够从预测的词法特征重新生成精确表面形式的发现单词的百分比——这是一个惩罚任何字符级偏差的严格指标。 表2显示了所有16种语言的结果：来自9,320个唯一词元的11,923个验证词形变化表——比合并的UniMorph条目增加了130倍。

特定语言创新。除了Giriama语，聚类还发现了斯瓦希里语中不存在的能产模式（因此对迁移不可见）： • 卢干达语（J区域）：oku-不定式前缀（1,107个实例；例如，okulindiriza“等待”，okusasulwa“被支付”）——不同于斯瓦希里语ku-。 • 绍纳语（S区域）：zvi-第8类复数前缀（846个；例如，zvinema“电影院”）——原始班图语*bi-的S区域反映，不同于斯瓦希里语vi-。 • 基苏库马语（F区域）：ng'-带有省音的鼻音前缀（402个；例如，ng'wigulu“在天堂”）——F区域特有。 • 卢旺达语（J区域）：y'i-缩约所有格（245个；例如，y'ikiyaga“湖泊的”）——卢旺达语独有的省音。

6. 讨论 6.1 语言学意义 我们的发现有助于Giriama语的记录：2,455个名词类别标签（而之前只有91个），两种文献中没有的新模式（a-，k'-）。 理论意义： • a-变体确认了海岸班图语的元音融合 • k'-模式表明能产的缩约过程 • 第6类（ma-）能产性高于斯瓦希里语（50.6% vs. 约30%） • 扩展的语料库（19,624个单词）揭示第7类（ki-/chi-）是Giriama语中最具能产性的名词类别（559/2,066个名词），超过第6类——这是与斯瓦希里语的分歧，值得进一步的类型学研究

6.2 方法论见解 为什么一致性只有36.7%？迁移（同源词）和聚类（创新）具有互补优势。语言中存在真正的歧义。类别不平衡（第6类占主导）扭曲了单一方法的预测。 低一致性的价值：分歧揭示了特定语言特征（聚类发现a-，k'-），需要上下文的歧义情况，以及供人工纠正的错误。

6.3 错误分析 迁移学习错误：假同源词（借词），语音变化（遗漏th/s，k'/ku对应），类别转移。 聚类错误：低一致性聚类（混合模式），歧义前缀（mu-：第1类还是第3类？），不遵循本土词法的借词。

6.4 局限性 覆盖范围仅限于语料库中的名词；罕见类别代表性不足（第11类：6个单词，第16类：4个单词）。质量缺乏完全验证的黄金标准。泛化需要相关的高资源语言。

7. 结论 我们提出了一种结合跨语言迁移和无监督聚类的零样本词法发现方法。应用于Giriama语（91个训练词形变化表）： • 发现2,455个名词类别标签（增加27倍） • 两种新模式：a-前缀变体（95.1%一致性）和k'-缩约（98.5%一致性） • 外部验证：在444个已知词形变化表上78.2%的词形还原准确率；扩展至19,624个单词的v3语料库确认了对动词、名词、形容词和所有格的泛化（97.3%切分，86.7%词形还原） 该方法的关键优势是互补性：迁移学习识别与斯瓦希里语共享的同源词，而无监督聚类发现迁移无法看到的Giriama语特定创新。大规模应用于16种班图语言，该流程发现了11,923个词形变化表。我们注意到发现的标签是银标准（模型生成，未经人工验证），并建议在语言记录中使用前进行语言学家验证。
