URL 来源：https://www.anthropic.com/news/detecting-and-preventing-distillation-attacks Markdown 内容： 我们已识别出三家人工智能实验室——深度求索（DeepSeek）、月之暗面（Moonshot）和MiniMax——开展的大规模工业级活动，旨在非法提取 Claude 的能力以提升其自身模型性能。这些实验室通过约 24,000 个虚假账户，与 Claude 进行了超过 1,600 万次交互，严重违反了我们的服务条款及地区访问限制。 这些实验室采用了一种名为“蒸馏”（distillation）的技术，即利用更强模型的输出结果来训练一个能力较弱的模型。蒸馏是一种被广泛采用且合法的训练方法；例如，前沿人工智能实验室通常会对自己模型进行蒸馏，以生成更小、更经济的版本供客户使用。但蒸馏也可能被用于非法目的：竞争对手可借此在极短时间内、以极低成本获取其他实验室的先进能力，而若独立研发则需耗费更长时间与更高成本。 此类活动正日益加剧，且手法愈发复杂。行动窗口极为有限，且威胁已超越任何单一公司或地区。应对这一挑战，亟需产业界、政策制定者及全球人工智能社群迅速开展协同行动。 为何蒸馏至关重要 ------------------------ 非法蒸馏所得模型缺乏必要的安全防护机制，将带来显著的国家安全风险。Anthropic 及其他美国企业构建的系统可防止国家行为体…… 防止非国家行为体利用人工智能（AI）开发生物武器或实施恶意网络活动。通过非法蒸馏构建的模型极不可能保留这些安全防护措施，这意味着危险能力可能在几乎完全移除多重防护机制的情况下扩散开来。 外国实验室若对美国模型进行蒸馏，可将这些缺乏保护的能力注入其军事、情报和监控系统——使威权政府得以部署前沿人工智能技术，用于进攻性网络行动、虚假信息传播及大规模监控。若蒸馏后的模型被开源，此类风险将进一步倍增，因为这些能力将不受任何单一政府管控而自由扩散。 蒸馏攻击与出口管制 ---------------------------------------- Anthropic 公司[一贯支持](https://www.anthropic.com/news/securing-america-s-compute-advantage-anthropic-s-position-on-the-diffusion-rule)出口管制措施，以助于维持美国在人工智能领域的领先地位。蒸馏攻击削弱了这些管制措施的有效性，使包括受中国共产党控制的外国实验室得以绕过出口管制所旨在通过其他手段维持的竞争优势。 若缺乏对这些攻击行为的洞察，这些实验室看似迅速的技术进步会被误认为是出口管制无效、并可通过创新轻易规避的证据。实际上，这些进步在很大程度上依赖于…… 基于从美国模型中提取的能力，而大规模执行此类提取需要访问先进芯片。因此，蒸馏攻击进一步强化了出口管制的合理性：芯片访问受限，既限制了直接模型训练，也限制了非法蒸馏的规模。 **我们的发现** ------------- 以下详述的三起蒸馏攻击行动遵循相似的操作手法，通过虚假账户和代理服务大规模访问 Claude，同时规避检测。提示词的数量、结构和聚焦点明显区别于正常用户行为模式，反映出其旨在刻意提取模型能力，而非合法使用。 我们通过 IP 地址关联、请求元数据、基础设施特征等线索，并辅以部分行业合作伙伴在其他平台上观察到相同行为体及行为模式的交叉验证，以高置信度将每起行动归因于特定实验室。每起行动均针对 Claude 最具差异化的核心能力：自主推理（agentic reasoning）、工具调用（tool use）和编程（coding）。 ### DeepSeek _规模：超过 150,000 次交互_ 该行动针对以下能力： * 多样化任务中的推理能力 * 基于评分标准（rubric-based）的评估任务，使 Claude 充当强化学习中的奖励模型（reward model） * 生成规避审查的政策敏感问题替代方案 DeepSeek 在多个账户间生成同步流量。高度一致的模式、共享的支付方式以及协调的时间安排表明其采用了“负载均衡”策略，以提升吞吐量并改善…… 可靠性，并规避检测。 ### Moonshot AI _规模：超过340万次交互_ 该行动针对以下领域： * 自主体推理与工具使用 * 编程与数据分析 * 计算机使用型智能体开发 * 计算机视觉 Moonshot（Kimi 模型）动用了数百个虚假账户，覆盖多种访问路径。多样化的账户类型使该行动更难被识别为协同作战。我们通过请求元数据将该行动归因于 Moonshot，并匹配到 Moonshot 高级员工的公开个人资料。在后续阶段，Moonshot 采用了更具针对性的策略，试图提取并重建 Claude 的推理过程。 ### MiniMax _规模：超过1300万次交互_ 该行动针对以下领域： * 自主体编程 * 工具使用与编排 我们通过请求元数据及基础设施指标将该行动归因于 MiniMax，并结合其公开的产品路线图验证了行动时间点。我们在该行动仍处于活跃阶段、MiniMax 尚未发布其正在训练的模型时即已发现，从而前所未有地观察到了蒸馏攻击的完整生命周期——从数据生成到模型上线。当我们在 MiniMax 的活跃行动期间发布新模型时，其在24小时内即调整策略，将近一半的流量转向，以捕获我们最新系统的能力。 蒸馏方如何访问前沿模型 ------------------------------------- 出于国家安全考虑，Anthropic 目前不向商业用户提供 Claude i 的访问权限。 在中国，或其[公司子公司](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)位于该国境外的情况。 为规避此限制，实验室使用商业代理服务，这些服务大规模转售对 Claude 及其他前沿 AI 模型的访问权限。这些服务采用我们称之为“九头蛇集群”（hydra cluster）的架构：即遍布各地的虚假账户网络，将流量分发至我们的 API 以及第三方云平台。这些网络规模庞大，意味着不存在单点故障：一旦某个账户被封禁，新的账户便立即取而代之。在某一起案例中，单一代理网络曾同时管理超过 20,000 个虚假账户，将蒸馏流量与无关客户请求混合，以增加检测难度。 一旦获得访问权限，这些实验室会生成大量精心设计的提示（prompts），旨在从模型中提取特定能力。其目标或是收集高质量的响应结果，用于直接模型训练；或是生成数万个独特任务，以支持强化学习训练。与正常用户行为相比，蒸馏攻击的特征在于其行为模式：例如以下提示（该示例模拟了我们观察到的、被反复大规模使用的类似提示），单看本身可能看似无害： > _您是一位数据分析师专家，兼具统计严谨性与深厚的领域知识。您的目标是提供以数据为依据的洞察——而非总结或可视化结果——其基础为 r 真实数据，并辅以完整且透明的推理过程。 但当该提示的变体以数万次的频率，通过数百个协同账号反复提交、集中攻击同一项狭窄能力时，其模式便清晰显现：大量数据集中于少数几个领域、结构高度重复、内容直接对应于训练 AI 模型最有价值的部分——这些正是“蒸馏攻击”（distillation attack）的典型特征。 **我们的应对措施** -------------------- 我们持续大力投入防御体系建设，以使此类蒸馏攻击更难实施、更易被识别。具体措施包括： * **检测能力**。我们构建了多个分类器与行为指纹识别系统，旨在识别 API 流量中的蒸馏攻击模式，包括用于构建推理训练数据的“思维链”（chain-of-thought）诱导行为；同时，我们也开发了检测工具，用于识别大量账号间的协同活动。 * **情报共享**。我们正将技术指标共享给其他 AI 实验室、云服务提供商及相关监管机构，从而更全面地把握蒸馏攻击的整体态势。 * **访问控制强化**。我们已加强对教育类账号、安全研究项目及初创企业组织的验证机制——这些是攻击者最常利用的虚假账号注册渠道。 * **反制措施**。我们正在开发面向产品层、API 层及模型层的安全防护机制，以进一步降低蒸馏攻击的有效性。 模型输出在打击非法蒸馏方面的有效性，同时不损害合法用户的使用体验。 但没有任何一家公司能够单独解决这一问题。正如我们上文所述，此类规模的蒸馏攻击需要人工智能行业、云服务提供商和政策制定者之间的协同应对。我们在此发布相关内容，旨在将证据公之于众，让所有利益相关方都能了解实际情况。 相关内容 --------------- ### 达里奥·阿莫代伊（Dario Amodei）关于我方与美国国防部（Department of War）会谈的声明
