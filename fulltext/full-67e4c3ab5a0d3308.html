检测与防御蒸馏攻击

📅 Feb 23, 20 📄 Anthropic 🔗 原文链接

URL 来源：https://www.anthropic.com/news/detecting-and-preventing-distillation-attacks Markdown 内容：

我们已识别出三家人工智能实验室——深度求索（DeepSeek）、月之暗面（Moonshot）和MiniMax——开展的大规模工业级活动，旨在非法提取Claude的能力以提升其自身模型性能。这些实验室通过约24,000个虚假账户，与Claude进行了超过1600万次交互，违反了我们的服务条款及区域访问限制。

这些实验室采用了一种名为“蒸馏”（distillation）的技术，即利用能力更强的模型的输出结果来训练一个能力较弱的模型。蒸馏是一种被广泛采用且合法的训练方法；例如，前沿AI实验室通常会对其自身模型进行蒸馏，以生成更小、更经济的版本供客户使用。但蒸馏也可能被用于非法目的：竞争对手可借此在极短时间内、以极低成本获取其他实验室的先进能力，而若独立研发则需耗费更长时间与更高成本。

此类活动正日益加剧，其规模与复杂性持续提升。行动窗口极为有限，且威胁已超越任何单一公司或地区。应对该威胁需产业界、政策制定者及全球AI社区迅速开展协同行动。

为何蒸馏至关重要 ------------------------ 非法蒸馏所得模型缺乏必要的安全防护措施，从而带来显著的国家安全风险。Anthropic及其他美国企业构建的系统可防止国家行为体滥用AI能力……

防止非国家行为体利用人工智能（AI）开发生物武器或实施恶意网络活动。通过非法蒸馏构建的模型很可能无法保留这些安全防护措施，这意味着危险能力可能在几乎完全剥离各项防护机制的情况下广泛传播。

外国实验室若对美国模型进行蒸馏，可将这些缺乏保护的能力输入其军事、情报和监控系统——使威权政府得以部署前沿人工智能技术，用于进攻性网络行动、虚假信息传播及大规模监控。若蒸馏后的模型被开源，则风险将进一步倍增，因为这些能力将脱离任何单一政府的管控，自由扩散。

蒸馏攻击与出口管制 ---------------------------------------- Anthropic 公司[一贯支持](https://www.anthropic.com/news/securing-america-s-compute-advantage-anthropic-s-position-on-the-diffusion-rule)出口管制措施，以助于维持美国在人工智能领域的领先地位。蒸馏攻击削弱了这些出口管制措施的有效性，使包括受中国共产党控制的外国实验室得以绕过管制，通过其他途径缩小与美国之间的竞争优势差距。

由于缺乏对这些攻击行为的可见性，外界往往错误地将这些实验室看似迅速的技术进步，视为出口管制无效且可被创新轻易规避的证据。实际上，这些技术进步在很大程度上依赖于……

基于从美国模型中提取的能力，而大规模执行此类提取需要访问先进芯片。因此，蒸馏攻击进一步强化了实施出口管制的理由：限制芯片获取渠道，既限制了直接模型训练，也限制了非法蒸馏的规模。 **我们的发现** ------------- 以下详述的三起蒸馏攻击行动遵循相似的操作手法，通过虚假账户和代理服务大规模访问Claude，同时规避检测。这些行动中提示词的数量、结构和聚焦点均明显区别于正常用户行为模式，反映出其目的在于系统性地提取模型能力，而非合法使用。 我们通过IP地址关联、请求元数据、基础设施特征等信息，并结合部分行业合作伙伴在自身平台上观测到的相同行为体与行为模式，对每起行动归属的实验室做出了高度可信的归因判断。各起行动分别针对Claude最具差异化的核心能力：自主推理（agentic reasoning）、工具调用（tool use）与编程（coding）。

### DeepSeek _规模：超过15万次交互_ 该行动针对以下能力： * 多样化任务中的推理能力 * 基于评分标准（rubric-based）的评分任务，使Claude在强化学习中充当奖励模型（reward model） * 生成规避审查的安全替代方案，以响应涉及政策敏感性的查询

DeepSeek在多个账户间生成同步流量。完全一致的请求模式、共享的支付方式及协调的时间节点表明其采用了“负载均衡”策略，以提升吞吐量并改善蒸馏效果。

可靠性，并规避检测。 ### Moonshot AI _规模：超过340万次交互_ 该行动针对以下领域： * 自主推理与工具使用 * 编程与数据分析 * 计算机使用型智能体开发 * 计算机视觉

Moonshot（Kimi 模型）动用了数百个虚假账户，覆盖多种访问路径。多样化的账户类型使该行动更难以被识别为协同作战。我们通过请求元数据将该行动归因于 Moonshot，并匹配到 Moonshot 高级员工的公开个人资料。在后续阶段，Moonshot 采用了更具针对性的策略，试图提取并重建 Claude 的推理轨迹。 ### MiniMax _规模：超过1300万次交互_ 该行动针对以下领域： * 自主编程 * 工具使用与编排

我们通过请求元数据及基础设施指标将该行动归因于 MiniMax，并结合其公开的产品路线图验证了时间点。我们在该行动仍处于活跃阶段时即予以发现——早于 MiniMax 发布其正在训练的模型——从而首次实现了对蒸馏攻击生命周期的全程高精度观测，涵盖从数据生成到模型上线的全过程。当我们在 MiniMax 的活跃攻击期间发布新模型后，其在24小时内即调整策略，将近一半的流量转向，以捕获我们最新系统的能力。

蒸馏方如何访问前沿模型 ------------------------------------- 出于国家安全考虑，Anthropic 目前不向商业用户提供 Claude i 的访问权限。

在中国，或其[公司子公司](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)位于该国境外的情况。 为规避此限制，实验室使用商业代理服务，大规模转售对 Claude 及其他前沿人工智能模型的访问权限。这些服务采用我们所称的“九头蛇集群”（hydra cluster）架构：即由大量虚假账户构成的庞大网络，将流量分散至我们的 API 以及第三方云平台。这些网络规模庞大，因此不存在单点故障：一旦某个账户被封禁，新的账户便会立即顶替其位置。在某一案例中，单个代理网络曾同时管理超过 20,000 个虚假账户，将蒸馏流量与无关客户请求混合，以增加检测难度。

一旦获得访问权限，实验室便会生成大量精心设计的提示（prompts），旨在从模型中提取特定能力。其目标或是收集高质量响应结果，用于直接模型训练；或是生成数万个独特任务，以支持强化学习训练。与正常用户行为相比，蒸馏攻击的显著特征在于其行为模式。例如，以下提示（大致复现了我们观察到的、被反复大规模使用的类似提示）本身看似无害： > _您是一位专家级数据分析师，兼具统计严谨性与深厚领域知识。您的目标是提供以数据为依据的洞见——而非总结或可视化结果——其基础为 r

真实数据，并辅以完整且透明的推理过程。 但当此类提示的变体以数万次的频率、通过数百个协同账号反复提交，且全部针对同一狭窄能力时，其模式便清晰显现：海量数据集中于少数几个领域、结构高度重复、内容直接对应于训练人工智能模型最有价值的部分——这些正是“蒸馏攻击”的典型特征。

**我们的应对措施** --------------------

我们持续大力投资于防御体系，以使此类蒸馏攻击更难实施、更易被识别。具体包括：

* **检测机制**。我们已构建多个分类器与行为指纹识别系统，旨在识别 API 流量中的蒸馏攻击模式，包括用于构建推理训练数据的“思维链”（chain-of-thought）诱导行为。我们还开发了检测工具，用于识别大量账号间的协同活动。 * **情报共享**。我们正将技术指标共享给其他人工智能实验室、云服务提供商及相关监管机构，以更全面地把握蒸馏攻击的整体态势。 * **访问控制**。我们已加强对教育类账号、安全研究项目及初创企业组织的验证流程——这些是攻击者最常利用以设立虚假账号的渠道。 * **反制措施**。我们正在开发产品层、API 层及模型层的安全防护机制，以降低蒸馏攻击的有效性。

模型输出在打击非法蒸馏方面的有效性，同时不损害合法用户的使用体验。 但没有任何一家公司能够独自解决这一问题。正如我们上述所指出的，此类规模的蒸馏攻击需要人工智能行业、云服务提供商和政策制定者之间的协同应对。我们在此发布相关内容，以便所有利益相关方都能获取相关证据。
