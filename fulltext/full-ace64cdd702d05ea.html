您可以选择如何使用您的数据。 * 可自定义的安全和隐私设置旨在保护您的对话。 * 高级账户安全增加了更强的保护以防止未经授权的访问，并增强了登录和恢复保障。 * 由您决定您的数据是否用于训练和模型改进。 * 您的记忆、对话和账户数据可以在您选择时删除。 * 我们会在可疑活动影响您的数据之前进行监控。 * 您的内容在静态存储时以及在与 OpenAI 之间、OpenAI 与其服务提供商之间的传输过程中均经过加密。 在我们的[消费者隐私页面⁠](https://openai.com/consumer-privacy/)了解更多关于您的数据隐私控制的信息。 ![图片 支持我们的客户遵守隐私法，包括 GDPR、CCPA、HIPAA 和 FERPA，并为客户提供数据处理附录和业务伙伴协议。支持 API 以及 ChatGPT Enterprise、Business、Edu、for Teachers 和 for Healthcare 产品的基础设施已由独立的第三方审计师进行评估，以确认我们的控制措施符合安全和保密的行业标准。 访问我们的安全门户，了解更多关于我们的安全控制和合规活动的信息。 * [了解更多(在新窗口中打开)](https://trust.openai.com/) ### 我们的认证 #### SOC 2 Type 2 OpenAI 已对其 API 和 ChatGPT 商业产品服务中与安全性、可用性、机密性和隐私相关的控制措施进行了独立的 SOC 2 Type 2 审查。 #### ISO 27001、27017、27018 和 27701 OpenAI 为支持 OpenAI API、ChatGPT Enterprise 和 ChatGPT Edu 服务的信息安全和隐私管理系统维持 ISO/IEC 27001:2022 和 ISO/IEC 27701:2019 认证。 #### ISO 42001 OpenAI 维持 ISO/IEC 42001:2023 AI 管理系统，涵盖 OpenAI 作为 AI 生产者和 AI 提供者的消费级和商业级 AI 产品及模型。 #### PCI-DSS OpenAI 对 ChatGPT 中支持委托支付处理的组件维持 PCI-DSS 合规性。 #### CSA Star Level 1 ChatGPT 商业产品服务和 API 平台已通过云安全联盟安全信任保证和风险 (STAR) 注册表的评估，符合透明度和云安全最佳实践的关键原则。 ##
