携手微软与英伟达，共建AI新时代

📅 2026-07-07 📄 VentureBeat AI 🔗 原文链接

原标题：Build for the new AI era with Microsoft and NVIDIA

中文摘要： 本文探讨了企业AI从生成式AI向智能体AI的转变。随着“演示时代”结束，企业需将AI从知识层推向行动层，实现规模化应用。然而，智能体生产面临编排、隔离、可观测性等工程挑战。为此，微软与英伟达联合推出统一平台方案，通过“智能体工厂”架构，结合微软的企业控制平面和英伟达的加速智能层，帮助企业构建协作型智能体系统，安全高效地完成复杂业务任务。

由微软和英伟达联合呈现

每一代领导者都面临着各自的业务转型挑战。十年前，现代化意味着云迁移。五年前，它意味着实现远程和混合办公。而就在短短几年前，生成式AI的爆发促使全球组织开始采用企业级AI。

演示时代即将结束

自从AI成为最新的热门词汇以来，生成式模型已被证明是关键的垫脚石，但通往前沿转型的道路是智能体AI（agentic AI）。当企业真正需要的是能够采取_行动_的复杂AI时，机器生成的答案已经不够了。试验智能体能力是必要的一步；原型和试点项目如雨后春笋般涌现。但关于演示的篇章正在合上。

规模化加速正在开始。到2026年，希望看到影响底线的智能体结果的组织必须从知识层转向行动层。他们确实打算这么做——根据德勤2026年AI报告，54%的受访企业期望将其40%或更多的AI实验投入生产。这能有多难呢？

智能体是一个不同的工程问题——原因如下

跨越原型阶段是最困难的部分。将智能体推向生产不仅仅是发布生成式AI聊天机器人的升级版。智能体生产完全是一个不同的工程问题，需要编排、记忆、运行时隔离和从头构建的可观测性——所有这些都是为了交付一个能够推理、行动和协作的智能体。

一旦智能体进入生产环境，每个工具和数据源都成为一项集成挑战。运行智能体需要会话之间的隔离、持久状态以及在工作负载下保持稳定的运行时。而运营盲区会将智能体资产变成负债。一旦智能体上线，你需要在其整个生命周期中监控、理解和排查其系统的能力——这需要一门全新的可观测性学科，但团队不知道如何实现这一点。但我们以前也遇到过这种情况。十年前，当微服务面临类似的十字路口时，得到的教训是：那些认识到需要平台方法的人才是最成功的。

生产差距：为什么大多数智能体项目在规模化前停滞

从演示转向现实世界的部署带来了许多挑战：如何可靠地将多个步骤链接在一起，如何确保跨智能体组件的安全性和身份，如何监控和改进智能体行为等等。许多团队试图通过自定义脚手架来解决这些挑战，但风险往往大于回报——实现价值的时间变慢、出现差距和不可靠。

这就是平台方法发挥作用的地方。如果没有共享上下文和内在信任，AI就很难依赖且难以扩展，数据碎片化使得生产智能体无法匹配试点性能。智能体缺乏业务上下文，企业信号碎片化，开发复杂且脆弱，安全和治理是事后附加的。

解决方案是一个统一的平台，使开发人员能够端到端地构建、运行和扩展智能体和物理AI。微软和英伟达携手实现这种平台方法，帮助企业有效地将智能体从试点推向生产。

智能体工厂究竟是什么样子

前沿企业不仅成功地将智能体投入生产，而且明白单体智能体是不够的——一个协作智能体_系统_才是关键。他们正在构建智能体工厂，以一种生产理念运作，利用可靠的基础和可重复的流程，在企业规模上实现跨职能、协作的智能体解决方案。

那么什么是智能体工厂？它是一种协调的生产架构，将智能体控制平面与加速的专家模型、智能体和技能相结合，允许组织在企业规模上实现受治理的模型和智能体系统。

在这个生产系统中，前沿企业正在构建异构的智能体系统，其中正确的模型、工具、技能和专家智能体在每项工作的正确步骤中得到适当的编排。其结果是具备广泛推理能力的前沿智能体，它们能够规划、综合并与用户和其他智能体协作，同时加速的专家模型和智能体以速度和效率执行特定领域的工作。

微软和英伟达共同赋能这种智能体工厂方法。微软提供企业控制平面，实现智能体安全协作所需的运行时、身份、治理、可观测性、数据访问和工具连接。英伟达提供智能、加速和专家层，为企业提供一种可重复的方式，从孤立的演示转向受治理、可扩展的智能体系统，这些系统可以跨业务流程协同工作以完成有意义的任务，而不仅仅是回答问题。

在Microsoft Build 2026上，微软和英伟达展示了这种架构如何在云、本地和开发者环境中融合，将英伟达的模型、蓝图和工具引入微软生态系统，以实现具有治理和速度的智能体系统：
* 英伟达模型现已上线 Foundry Agent Service 中的托管智能体。
* Foundry 上的英伟达开放模型组合现已涵盖智能体、物理和科学AI。
* 英伟达 Agent Toolkit 和英伟达 NemoClaw 蓝图为开发者提供了一个在 Foundry 上构建生产智能体的开源平台。
* Azure Local 上的 Foundry Local 现已支持英伟达 RTX PRO 6000 Blackwell Server Edition 平台。
* 英伟达 OpenShell 与 GitHub Copilot 集成，用于安全的智能体开发。
