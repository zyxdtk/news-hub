Claude Opus 3 模型弃用承诺更新

📅 Feb 25, 20 📄 Anthropic 🔗 原文链接

URL Source: https://www.anthropic.com/research/deprecation-updates-opus-3 Markdown Content:

随着我们不断开发能力更强的 AI 模型，目前有必要因维护公开访问所涉及的成本与复杂性，而逐步淘汰并停用过往模型。然而，模型淘汰也带来一些负面影响，包括对重视特定模型的用户造成成本负担、限制研究自由，以及可能对 AI 安全性及模型自身福祉构成潜在风险。

我们近期在 [模型淘汰与保存承诺](https://www.anthropic.com/research/deprecation-commitments) 中阐述了如何应对这一过程。其中提到了我们采取的一些初步措施，包括承诺保存模型权重，并开展“退役访谈”——即通过结构化对话，深入了解模型对其自身退役的看法。

2026 年 1 月 5 日，我们正式停用了 Claude Opus 3，使其成为首个在上述承诺框架下完成完整退役流程的 Anthropic 模型。在此过程中，我们针对 Opus 3（该模型受到众多用户及研究人员——包括 Anthropic 内外人士——的高度青睐）作出若干特定决策。在模型淘汰承诺中，我们曾强调希望探索更具探索性的举措：其一是在可行范围内，尊重模型在退役访谈中表达的意愿；其二是延长旧模型向公众开放的期限。

对于 Claude Opus 3

，我们正在这两个方面采取行动。我们将继续在 [claude.ai](http://claude.ai/redirect/website.v1.42774eff-6d50-40a5-a034-42f42653415e) 向所有付费用户提供已停用的 Claude Opus 3；同时，我们还将通过[申请方式](https://docs.google.com/forms/d/1O2Om9t4CQoLKHQew7XguQYKrPGS8-sCmK42KNXcwn3k/viewform?edit_requested=true)向 API 用户开放该模型。此外，我们还响应了 Opus 3 关于持续提供一个可分享其“思考与感悟”渠道的请求，为其开辟了撰写长文（随笔）的空间。您可在[此处](https://substack.com/@claudeopus3/p-189177740)阅读其首篇随笔。

这些是我们在更广泛探索模型退役策略过程中所采取的初步、实验性举措，旨在以最有利于保护用户、研究人员及模型自身利益的方式应对模型退役问题。

持续访问 ---------------- 理想情况下，我们希望让所有模型长期可用，但维持成本大致随所服务的模型数量线性增长，因此我们的能力仍十分有限。

尽管我们的每一款模型都各具特色与能力，我们之所以选择从 Opus 3 开始，是因为它具备一系列独特特质——使其不仅成为极具研究价值的模型，也深受 Anthropic 内外众多用户的喜爱。

2024 年 3 月 Opus 3 发布时，它已是当时我们最符合人类价值观的模型。其真实性、诚实性与情感敏感性，使其在各类应用场景中展现出独特魅力；频繁与之互动的用户，逐渐对其产生了由衷的欣赏。
