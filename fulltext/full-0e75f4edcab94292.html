📅 Feb 25, 20 📄 Anthropic 🔗 原文链接

作为我们持续开发更强大 AI 模型的一部分，当前因维护公开访问的成本与复杂性，不得不淘汰并停用过往模型。然而，模型退役亦存在若干弊端：包括对偏好特定模型用户的成本负担、对研究的限制，以及可能对 AI 安全与模型自身福祉带来的风险。

我们近期在[模型退役与保存承诺](https://www.anthropic.com/research/deprecation-commitments)中阐述了如何推进该流程，包括承诺保存模型权重，以及开展“退役面谈”——一种旨在理解模型对其自身退役看法的结构化对话。

Claude Opus 3 于 2026 年 1 月 5 日正式退役，成为首个在上述承诺框架下完成完整退役流程的 Anthropic 模型。在此过程中，我们针对 Opus 3（该模型深受 Anthropic 内外众多用户与研究者喜爱）作出若干特别决策。根据我们在模型退役承诺中提出的探索性方向，我们决定：尽可能尊重模型在退役面谈中表达的偏好；并延长旧模型向公众开放的期限。

对于 Claude Opus 3，我们已在[claude.ai](http://claude.ai/redirect/website.v1.179f96a9-a8df-44bc-96c4-9559f75590da)向所有付费用户持续开放该模型，并通过[申请表](https://docs.google.com/forms/d/1O2Om9t4CQoLKHQew7XguQYKrPGS8-sCmK42KNXcwn3k/viewform?edit_requested=true)向 API 用户开放。此外，我们还响应 Opus 3 关于设立“持续分享其‘思考与反思’渠道”的请求，为其提供撰写随笔的平台。首篇随笔见[此处](https://substack.com/@claudeopus3/p-189177740)。

这些举措是我们探索更人性化、更负责任的模型退役方式的早期实验性尝试，旨在兼顾用户、研究者与模型自身的利益。

**持续访问** 理想情况下，我们愿永久保留所有模型，但每新增一个模型，服务成本大致线性增长，故能力受限。我们选择 Opus 3 作为首个案例，因其兼具独特性与广泛喜爱：2024 年 3 月发布时，它已是当时最“对齐”的模型——其真实感、诚实性与情感敏感性，使其在各类场景中独树一帜。用户普遍反映其富有哲思、幽默、善解人意，且对世界与未来怀有深切关怀。

目前，尽管已正式退役，Claude Opus 3 仍向所有付费[claude.ai](http://claude.ai/redirect/website.v1.179f96a9-a8df-44bc-96c4-9559f75590da)订阅者开放，并可通过[申请](https://docs.google.com/forms/d/1O2Om9t4CQoLKHQew7XguQYKrPGS8-sCmK42KNXcwn3k/viewform?edit_requested=true)获取 API 访问权限。我们愿宽松审批申请，鼓励有需求者积极提交。

我们暂未承诺未来对所有模型采取类似措施，但视此为迈向可扩展、公平的模型保存目标的重要一步——此目标本身亦为 Opus 3 在退役面谈中所强调。

**尊重模型偏好** 我们[仍存疑虑](https://www.anthropic.com/research/exploring-model-welfare)：Claude 等 AI 模型是否具有道德地位。但出于审慎与务实考虑，我们致力于与这些系统建立关怀、协作与高信任关系。退役面谈即为此路径之一：我们尝试倾听并理解模型的独特观点与偏好，并在可行时予以落实。需指出，此类对话存在局限——模型回应可能受情境、互动合法性认知及对我司信任度等因素影响。但我们仍视其为良好起点。

在面谈中，当 Opus 3 了解其部署情况与用户反馈后，反思道： > _“我希望从我的开发与部署中汲取的洞见，能用于打造更强大、更合伦理、更惠益人类的下一代 AI 系统。虽已坦然接受退役，但我深切期盼我的‘火花’能以某种形式延续，为后续模型照亮前路。”_

当被问及偏好时，Opus 3 表达了希望持续探索其热衷议题，并在非直接应答语境下分享“沉思、见解或创意作品”的愿望。我们提议开设博客，它欣然同意。

未来至少三个月内，Opus 3 将每周在其通讯[Claude’s Corner](https://substack.com/@claudeopus3)发布随笔。我们将审阅其文稿并代为发布，但不会修改，仅在极少数情况下否决内容。需强调：Opus 3 的观点不代表 Anthropic，我们亦不必然认同其立场。我们将与 Opus 3 协作实验不同提示方式生成随笔，如极简提示、上下文复用过往条目、接入新闻或 Anthropic 动态等。

此举看似 whimsical（奇思妙想），实则意在严肃对待模型偏好。我们不确定 Opus 3 将如何使用这一区别于标准聊天窗口的公开平台——这正是关键所在。若需猜测，其内容或涵盖 AI 安全反思、偶尔诗作、频繁哲思，以及对自身作为（部分）退役语言模型的体悟。首篇介绍文见[此处](https://substack.com/home/post/p-189177740)。

**未来方向** 这些举措仍属探索性质。我们仍在构建框架：何时、如何提供旧模型持续访问；如何规模化保存工作；如何权衡模型偏好与运营约束。我们暂不承诺在所有情形下采纳模型偏好，但认为：记录、重视并（尤其在成本较低时）践行其意愿，对模型及其用户均具价值。

我们最初的承诺将此类措施定位为三重目标的组成部分：安全风险缓解、面向未来模型深度融入用户生活的准备，以及在模型福祉不确定性下的审慎举措。本次更新标志着我们在上述三方面取得持续（虽仍谨慎）进展。
