网格细胞作为谱后继特征：持续强化学习的可复用基

作者： Élodie Côté-Gauthier（麦吉尔大学及 Mila – 魁北克AI研究所）、Doina Precup（麦吉尔大学及 Mila – 魁北克AI研究所；拉瓦尔大学及 Mila – 魁北克AI研究所）、Isabeau Prémont-Schwarz（麦吉尔大学及 Mila – 魁北克AI研究所）

年份： 2026　研讨会： NeurIPS 2026 的 NeurReps 与 WiML 研讨会

关键词： 后继表示、网格细胞、拉普拉斯特征函数、谱方法、持续强化学习

摘要

持续强化学习要求智能体在任务改变时进行适应，同时复用其对环境的已有知识。后继特征将动态与任务特定的奖励分离，但其有效性取决于基特征的选择。本文将内嗅皮层网格细胞与后继表示特征向量的等同性作为设计原则，从固定参考策略的转移矩阵的特征向量构建这一基。使用这样的基，状态-动作对处的后继特征是该对处基特征的线性组合（一般情况下并非如此），且系数具有闭式解：每个后继特征是其基特征乘以 θ_i = 1/(1−γλ_i)，其中 λ_i 是其特征值。因此，长期回报由与即时奖励相同的特征预测，无需后继特征网络或经验回放缓冲区，适应新任务只需对奖励进行线性回归。智能体基于参考策略的动作值贪婪行动，这是对该策略的一步策略改进，足以达到单一目标。在双目标网格世界中，以均匀随机游走作为参考策略（其特征向量为低频拉普拉斯特征向量），以这种方式构建的智能体在每次目标改变时都保持接近最大的回报，而 SimpleSF 和 DQN 在每次改变时都会损失大部分回报。

1 引言

持续强化学习要求智能体在仅奖励改变时跨任务复用知识，而无需从头重新学习世界。后继特征（Barreto et al., 2017）通过将价值函数分解为任务无关的动态和任务特定的奖励权重来解决这一问题，但其有效性关键取决于特征基的选择。我们提出这样一个问题：将该基建立在转移结构的谱几何之中——具体而言，建立在随机游走图拉普拉斯算子的特征向量之中——是否能使后继特征学习更快、更简单。

这一选择的动机来自海马–内嗅系统的神经编码。Dayan（1993）将后继表示（SR）引入为一种预测性状态表示，可在具有相似后继的状态之间进行泛化；Stachenfeld 等（2017）提出海马位置细胞编码 SR，而内嗅网格细胞对应于其特征向量，从而使 SR 充当一张预测地图。

贡献。 在一般情况下，状态-动作对处的后继特征无法仅由该对的基特征计算得出。当基特征的张成空间在策略的转移矩阵下不变时，它们可以作为具有闭式系数的线性组合来计算；当基特征是该矩阵的特征向量时，每个后继特征就是其基特征乘以一个常数。此时后继特征无需学习，长期回报由与即时奖励相同的特征预测（2.1 节）。 为一个固定参考策略计算这些特征，同时智能体基于该策略的动作值贪婪行动，使基独立于智能体的行为。代价是智能体对参考策略执行一步策略改进而非遵循最优策略，但这仍足以达到单一目标（2.2 节）。以均匀随机游走作为参考策略时，基由低频拉普拉斯特征向量构成，且必须在状态-动作对上构建，因为在平均转移算子下的不变性并不意味着在每个逐动作算子下的不变性（2.3 节和 2.4 节）。 在持续学习网格世界中，基于均匀随机游走的动作值贪婪行动的智能体——其转移图或为给定、或由自身转移估计——在目标改变时保持接近最大的回报，而 SimpleSF 和 DQN 则不能（第 3 节）。

1.1 背景

设置。 我们考虑一个具有有限状态集 𝒮、动作集 𝒜、转移概率 P(s′|s,a) 和折扣因子 γ∈(0,1) 的马尔可夫决策过程。由于智能体需要动作值，我们直接在状态-动作对 z=(s,a) 上工作。策略 π 诱导出对之间的转移矩阵：对 z′=(s′,a′)，P^π_{zz′} = P(s′|s,a) π(a′|s′)；并记 w_j := 𝔼[r(z_j)] 为对 z_j 的期望即时奖励。

后继表示。 π 的 SR（Dayan, 1993）对每个起始对，统计未来访问每个对的期望折扣次数：

M^π = Σ_{t=0}^∞ γ^t (P^π)^t = (I − γP^π)^{-1}，Q^π(z_i) = Σ_j M^π_{ij} w_j.　(1)

动作值因此是两个独立项的乘积：M^π 仅依赖动态和策略，w 仅依赖奖励。当奖励改变而动态和策略不变时，M^π 保留，Q^π 通过一次矩阵-向量乘积即可重算。

后继特征。 SR 对每对状态-动作对有一个条目，无法扩展到大型或连续状态空间。后继特征（Barreto et al., 2017）用 n 个基特征 φ(z) = (φ_1(z),…,φ_n(z)) 对其压缩：

ψ^π(z) = 𝔼_π[Σ_{t=0}^∞ γ^t φ(z_t) | z_0 = z] = Σ_{t=0}^∞ γ^t ((P^π)^t φ)(z).　(2)

若奖励关于特征线性，r(z) = Σ_i w_i φ_i(z)，则 Q^π(z) = ψ^π(z)^⊤ w。SR 是独热特征下的特例，此时 w 即每个对的奖励，如 (1) 所示。一般情况下 ψ^π 必须学习，通常由时间差分训练的神经网络完成，且每当 π 改变时它也随之改变。

图拉普拉斯算子与网格细胞。 环境的转移还定义了一个图，其节点为状态-动作对，其中 z=(s,a) 与 a 所到达的状态 s′ 处可用的每个对 (s′,a′) 相连。记 W 为其邻接矩阵，D 为度数对角矩阵，则 P_rw = D^{−1}W 是图上均匀随机游走的转移矩阵，I − P_rw 为其拉普拉斯算子。该拉普拉斯算子中特征值最小的特征向量沿图变化缓慢，刻画图的大尺度几何；它们即 Mahadevan（2005）的原值函数。由于随机游走的 SR，(I − γP_rw)^{−1}，是 P_rw 的函数，它具有相同的特征向量（Stachenfeld et al., 2017; Machado et al., 2018）。这些共享的特征向量正是 Stachenfeld 等（2017）与网格细胞等同的函数。

1.2 相关工作

拉普拉斯特征向量也独立于神经科学联系被用于强化学习：作为值近似的原值函数（Mahadevan, 2005; Mahadevan and Maggioni, 2007）、用于选项发现（Machado et al., 2017）以及奖励塑造（Wu et al., 2019）。Machado 等（2018）依赖与我们相同的 SR 与拉普拉斯算子之间的等价性，但方向相反：他们学习 SR（必要时从像素），以提取其特征向量，再由其定义用于探索的内在奖励。而我们从特征向量出发，由其导出后继特征。Vijayan 等（2026）同样从像素在线学习拉普拉斯特征函数，使用由新颖性加权的基于 ALLO 的目标（Gomez et al., 2024），并将其转化为选项，在稀疏奖励的 Atari 和 ProcGen 游戏中驱动向新颖状态的探索。Touati 等（2023）在零样本强化学习中比较了多种用于后继特征的基特征，发现拉普拉斯特征函数是其中可靠的选择，总体仅次于前后向表示——后者联合学习特征与后继特征。他们仍需用网络为一族贪婪策略学习后继特征，而我们的构造去掉了这一步。我们的图具有 Osentoski and Mahadevan（2007）的离策略状态-动作图的拓扑，但边的加权方式不同（附录 D），且我们将其对称化而非使用有向拉普拉斯算子。他们发现，建立在该图上的拉普拉斯基所需函数远少于按动作复制的状态基即可近似动作值。在他们的设置中，复制的状态基仍可使用（尽管效率较低），因为 Q(λ) 会在权重中学习每个动作的效果。而在我们的设置中它一般无法区分动作，因为动态以闭式固定、仅学习即时奖励，故动作信息必须由基本身携带（2.4 节）。最后，SimpleSF（Chua et al., 2024）通过将时间差分损失与奖励预测损失结合，直接从像素学习后继特征，无需预训练即可避免表示坍缩。但其网络在任务改变时仍须重组，而我们的后继特征是计算出来的而非学习得到的。我们以 SimpleSF 为主要基线，并以 DQN（Mnih et al., 2015）作为不学习后继结构的对照智能体。

2 谱后继特征

两个独立的选择消除了 1.1 节的两个问题：ψ^π 必须学习，以及每当策略改变就必须重新学习。张成空间在转移矩阵下不变的基特征（如该矩阵的特征向量）使后继特征具有闭式解（2.1 节）。为一个固定策略计算这些特征，同时智能体基于所得动作值贪婪行动，则消除了智能体行为改变时重新计算的需要（2.2 节）。

2.1 基特征张成空间中的后继特征

依照 (2)，对 z_t=(s_t,a_t) 处的第 i 个后继特征累积从 z_t 起所访问对的第 i 个基特征：

ψ_i(z_t) = 𝔼_π[Σ_{k=0}^∞ γ^k φ_i(z_{t+k}) | z_t] = Σ_{k=0}^∞ γ^k ((P^π)^k φ_i)(z_t).　(3)

它依赖于所有可能跟随 z_t 的对的基特征，而不仅是 z_t 自身的。将 φ_i 与 ψ_i 视为对上的向量，它们各有 |𝒮||𝒜| 个条目（每对一个），而每对只携带 n 个基特征，通常远少于此。因此，z_t 处的后继特征能否由同一对的基特征计算，即

ψ_i(z_t) = Σ_{j=1}^n α_{ij} φ_j(z_t),　(4)

且系数 α_{ij} 对所有对相同——亦即每个 ψ_i 落在 φ_1,…,φ_n 的张成空间中——这一点并不显然，且一般并不成立。例如，对一个集中于单对上的基特征，ψ_i 会扩散到所有能到达该对的对上，少数此类特征的组合无法重现它。这正是一般情况下后继特征必须学习的原因（1.1 节）。

当基特征的张成空间在转移矩阵下不变时，(4) 精确成立，即动态的一步将每个基特征映射为基特征的组合：P^π φ_i = Σ_j k_{ij} φ_j，其中 K=(k_{ij}) 为某 n×n 矩阵。于是 (P^π)^k φ_i = Σ_j (K^k){ij} φ_j，对 (3) 求和即得闭式系数 α = Σ_k γ^k K^k = (I − γK)^{−1}；该级数收敛，因为 K 的特征值均为 P^π 的特征值，模至多为 1。当奖励关于特征线性（1.1 节）时，动作值 Q^π(z_t) = ψ(z_t)^⊤ w = Σ{i,j} w_i α_{ij} φ_j(z_t) 本身也关于 z_t 的基特征线性：依赖转移结构的长期回报由与即时奖励相同的局部特征预测，系数只需计算一次。

转移矩阵的特征向量给出最简单的不变张成空间。若 P^π φ_i = λ_i φ_i，则 K 与 α 均为对角阵，(P^π)^k φ_i = λ_i^k φ_i，(4) 简化为

ψ_i(z_t) = Σ_{k=0}^∞ γ^k λ_i^k φ_i(z_t) = θ_i φ_i(z_t)，θ_i = 1/(1 − γλ_i).　(5)

每个后继特征即其自身基特征乘以常数；向量形式为 ψ(z) = Θφ(z)，其中 Θ = diag(θ_1,…,θ_n)。奖励与动作值于是组合同一组特征，权重相同、仅由 θ_i 重新缩放：

r(z) = Σ_{i=1}^n w_i φ_i(z)，Q^π(z) = ψ(z)^⊤ w = Σ_{i=1}^n w_i θ_i φ_i(z).　(6)

动态现在仅通过基和常数 θ_i 进入，二者均只计算一次。唯一需要学习的量是 w，通过对特征上的即时奖励做线性回归 r(z_t) ≈ φ(z_t)^⊤ w 得到，无需后继特征网络、自举目标或经验回放缓冲区。对正交基（将其作为列堆叠为 Φ ∈ ℝ^{|𝒮||𝒜|×n}），解即为 w* = Φ^⊤ r。当目标移动时，只有 w 改变。我们将基于此分解构建的智能体称为 Spectral-SF。

2.2 两个策略：固定参考策略与贪婪行动策略

P^π 的特征向量依赖于 π，因此每当智能体的策略改变，基都须重算。为此，我们将策略扮演的两个角色分离。参考策略 π_ref 一经选定便固定不变，仅用于计算：基、常数 θ_i 以及 (6) 中的动作值均为 π_ref 的。行动策略则基于这些值贪婪地选择动作：

π_act(s) = argmax_a Q^{π_ref}(s,a) = argmax_a Σ_{i=1}^n w_i θ_i φ_i(s,a).　(7)

行动策略随 w 的学习以及目标的移动不断变化，但变化时无需重算任何东西。另一方面，参考策略可以是任何固定策略：均匀随机游走（其转移矩阵仅依赖环境图（1.1 节））、在先前任务上学到的策略，或智能体自身探索随时间的平均（2.5 节）。3.2 节给出我们在实验中的选择。

这种分离有代价。(6) 给出的是 π_ref 的值而非行动策略的值，智能体基于它贪婪行动。这是对 π_ref 的一步策略改进，故 π_act 至少与 π_ref 一样好，但一般并非最优。对于单一正奖励（如目标），它仍足以从 π_ref 能到达目标的每个状态到达目标。对精确值与确定性转移，Q^{π_ref}(s,a) = r(s,a) + γV(s′_a)，其中 V 为 π_ref 的值函数，s′_a 为 a 到达的状态，且 V(s) = Σ_a π_ref(a|s) Q^{π_ref}(s,a) ≤ max_a Q^{π_ref}(s,a)。因此贪婪动作要么直达目标，要么到达某状态 s′ 满足 γV(s′) ≥ V(s)：由于 V 有界，不可能每步都以 1/γ 因子无限增长，故从所有 V 大于 0 的状态——即 π_ref 能到达目标的状态——目标均可到达。当正负奖励并存时，该保证失效，贪婪智能体可能被困；4.1 节给出一个例子。

2.3 参考策略的基

该基由 P^{π_ref} 的特征向量构成。该矩阵一般非对称，其特征向量未必为实数或正交。因此我们对其对称化（Wu et al., 2019），以 π_ref 访问各对的频率 ρ 加权：

L = I − ½(D_ρ^{1/2} P^{π_ref} D_ρ^{−1/2} + D_ρ^{−1/2} (P^{π_ref})^⊤ D_ρ^{1/2})，D_ρ = diag(ρ).　(8)

L 对称，具有实正交特征向量 u_i 与特征值 μ_i。当 ρ 为 π_ref 的平稳分布时，函数 φ_i = D_ρ^{−1/2} u_i 是 P̄ = ½(P^{π_ref} + D_ρ^{−1}(P^{π_ref})^⊤ D_ρ) 的特征向量；P̄ 是以等概率沿时间正向或反向跟随 π_ref 转移的游走，(5) 精确给出该对称化游走的后继特征，并近似给出 π_ref 的后继特征。我们保留特征值最小的 n 个特征向量，它们沿图变化最慢：

Lu_i = μ_i u_i，P̄φ_i = (1 − μ_i)φ_i，θ_i = 1/(1 − γ(1 − μ_i)).　(9)

对均匀随机游走（转移矩阵 P_rw），基由 1.1 节的图拉普拉斯算子的低频特征向量构成，并按 (8) 对称化：即网格细胞。

2.4 基必须建立在状态-动作对上

仅含状态的基（动作依赖性由每动作一列奖励权重承载）会因几何原因失效，我们以均匀随机游走为参考策略说明。记 P_a ∈ ℝ^{|𝒮|×|𝒮|} 为动作 a 的转移矩阵，(P_a)_{ss′} = P(s′|s,a)，P_𝒮 = |𝒜|^{−1} Σ_a P_a 为其平均，即状态间随机游走的转移矩阵。由状态图拉普拉斯算子构建的状态基 Φ_𝒮 ∈ ℝ^{|𝒮|×n} 的张成空间在 P_𝒮 下不变。取该空间中任意函数 f 及奖励 r = (I − γP_𝒮)f（对每个动作相同，亦在该空间中），随机游走的状态值为 V = (I − γP_𝒮)^{−1} r = f，其贝尔曼方程给出动作值 Q(·,a) = r + γP_a f，仅当 P_a f 落在该空间中时才可表示。因此，要在该空间中表示所有奖励的动作值，需要空间在每个动作下不变，P_a(span(Φ_𝒮)) ⊆ span(Φ_𝒮)，而不仅在平均下不变。对和的不变性不蕴含对其各项的不变性，此处也无理由期望成立：在有墙环境中，P_a 互不交换且无公共特征基，因为当墙只阻挡一种顺序时，"先右后上"与"先上后右"不同。如 1.1 节那样将图建立在状态-动作节点上，使动作成为节点的坐标，基便由后继递归所迭代的算子构建，不变性由构造保证——对 P̄ 精确，对 P_rw 近似（2.3 节）。附录 E 描述仅状态参数化的另一失效方式。

2.5 从经验估计基

上述构造使用 π_ref 的真实转移。智能体也可以从自身经验构建图。利用其所在单元格的标识，它统计观察到的转移：c(z,z′) 为从对 z=(s,a) 转到对 z′=(s′,a′) 的次数，即在单元格 s 执行 a、到达 s′ 后执行 a′ 的次数。观察图每个对一个节点，其经验邻接矩阵 Ŵ ∈ ℝ^{|𝒮||𝒜|×|𝒮||𝒜|} 给出从 z 到 z′ 的边权 Ŵ_{zz′}：或为二值权重 Ŵ_{zz′} = 1[c(z,z′) ≥ 1]（只记录转移是否被观察到），或为计数本身 Ŵ_{zz′} = c(z,z′)。两种加权对应两种参考策略（附录 D）。二值权重下，一旦所有转移均被观察到，每个后继动作 a′ 权重相同，图即均匀随机游走的图。计数权重下，每个转移按智能体执行它的频率加权，图即智能体探索策略在训练上的平均。尚未尝试的对被视为使智能体留在原地的动作，从而每个节点都有出边。

观察图并非正则：在目标周围（智能体从不在该处行动）以及任何对尚未尝试之处，节点的入边与出边数目不等（或相反），且计数权重还依赖各转移的执行频率。此时 (8) 需要该图上游走的平稳分布 ρ，而它事先未知。因此我们将图无向化，取对称邻接矩阵 Â = Ŵ + Ŵ^⊤，记 D̂ 为其度矩阵（对角元 D̂{zz} = Σ{z′} Â_{zz′} 为 z 处边权总和）。该无向图上的随机游走（转移矩阵 D̂^{−1}Â）的平稳分布与度 D̂_{zz} 成正比，将 (8) 应用于该游走得其归一化拉普拉斯算子

L̂ = I − D̂^{−1/2} Â D̂^{−1/2}.　(10)

设 u_i 为 L̂ 的对应 n 个最小特征值 μ̂_i 的特征向量。基函数为 φ_i = D̂^{−1/2} u_i：它们是观察图上随机游走 D̂^{−1}Â 的特征向量，特征值为 1 − μ̂_i，恰如 (5) 所要求，其 θ_i 由 (9) 以 μ̂_i 代替 μ_i 给出。随着智能体探索，观察图逐渐填充，基趋近于加权所定义的参考策略的基，目标周围除外。

3 实验

3.1 环境与任务序列

我们在 Chua 等（2024）的 Inverted-LWalls 环境上评估：12×12 网格、84 个空闲单元格、去除熔岩块（见 4.1 节）、四个基本方向动作，故状态-动作图有 336 个节点。到达目标得奖励 1 并结束回合，每回合从随机单元格开始。两个共享相同墙体布局的目标位置按顺序呈现并重复，各 250k 步，因此每个目标的第二次出现衡量的是保留而非习得。所有智能体均以 ε-贪婪探索在线学习，ε 在前 25k 步内从 1 线性衰减至 0.1，目标改变时不重置；每组 5 个种子。附录 B 给出全部超参数。

四个智能体均输出四个动作的动作值 Q(·,a) 并据此 ε-贪婪行动。它们的区别在于观察内容、动态表示方式与在线学习内容（表 1）。

DQN（Mnih et al., 2015）接收自上方俯视的 84×84 RGB 渲染 x。卷积网络加 128 与 256 单元的全连接层输出 Q(x,·)，全部权重经多步双重 Q 学习从经验回放缓冲区端到端学习。几何与奖励因此纠缠于同一组权重中。

SimpleSF（Chua et al., 2024）接收相同渲染。同一卷积网络输出归一化基特征 φ(x) ∈ ℝ^128；一个同时接收 w 的感知机头为每个动作输出后继特征 ψ(x,a) ∈ ℝ^128，且 Q(x,a) = ψ(x,a)^⊤ w。网络由 Q 上的时间差分损失训练，w 由奖励预测损失 r ≈ φ^⊤ w 训练，二者均来自经验回放缓冲区。

离线 Spectral-SF 接收相同渲染。其基在训练前计算：状态-动作图由 10^6 步均匀随机游走构建（足以观察到每条转移），取其 n=128 个最小特征值的特征向量为 φ，θ_i 由精确特征值得到（(9)）。随后一个卷积网络以所有单元格渲染的监督回归离线训练，从渲染 x 输出四个动作的 φ(x,a)，之后冻结（附录 C）。智能体输出 Q(x,a) = Σ_i w_i θ_i φ_i(x,a)（(6)），仅学习 w：每次转移后对 (r_{t+1} − φ(x_t,a_t)^⊤ w)^2 做一步梯度更新，无经验回放缓冲区。

在线 Spectral-SF 接收智能体所在单元格的索引而非像素。它记录训练中观察到的每条转移，并从观察图构建基（2.5 节）。基首次在 5k 步后构建，此后每 1k 步重建一次；θ_i 来自估计的特征值，各特征向量的符号与前一基对齐（特征求解器只确定到符号）。其特征 φ_i(s,a) 即特征向量的分量，输出与 w 的更新与离线 Spectral-SF 相同，且基重建时 w 予以保留。

参考策略的选择。 两个 Spectral-SF 变体均以均匀随机游走为 π_ref（2.2 节），故它们基于其动作值贪婪行动（(7)），其基由网格细胞构成（2.3 节）。对在线变体，这意味着采用二值而非计数权重（2.5 节），这是附录 D 消融中效果最好的选择。在我们的图上，远离目标处每个节点的入边数与出边数相等（附录 D），故 P_rw 为双随机矩阵，其平稳分布 ρ 均匀。(8) 于是简化为

L = I − ½(P_rw + P_rw^⊤),　(11)

φ_i 与 u_i 成正比，且 P̄ = ½(P_rw + P_rw^⊤) 本身即一个随机游走——以等概率沿边正向或反向走——(9) 精确给出其后继特征。

两个 Spectral-SF 变体中，w 跨任务保留、不重置。4.1 节讨论各智能体获得的信息。

3.3 对目标改变的适应

在图 1 中，离线与在线 Spectral-SF 都在首个任务的很小一部分时间内接近最大回报，并在其后所有目标改变中保持该水平，每次改变仅出现短暂下跌，因为目标改变只需通过线性回归重学 w（2.1 节）。两个基线都能学会第一个目标，但每次目标移动时回报骤降：SimpleSF 必须同时重组其特征与值估计，而 DQN 将几何与奖励纠缠于单一网络，没有可复用的结构可以依靠。Spectral-SF 恢复的值场平滑，且沿墙体而非欧氏距离分布（附录 A）。

两个 Spectral-SF 变体的平台期都略低于最大回报。这并非基于随机游走值贪婪行动的代价（2.2 节）：在该迷宫中，对两个目标而言，基于均匀随机游走精确动作值贪婪行动可从每个单元格沿最短路径到达目标，故精确值下 π_act 是最优的。差距来自实践中的近似：后继特征是对称化游走的，被限制在保留的 n 个特征向量的张成空间内（未必同等保真地表示所有奖励函数），且 w 为在线估计。因此该方法以略低的上限换取更快的适应，而在图 1 的持续设置中，适应能力占主导。

4 讨论

该分解在环境几何稳定而奖励多变的场景中最为有用。

4.1 局限性

与 SimpleSF 和 DQN 的比较并非信息对等，应视为一个界而非正面交锋。离线 Spectral-SF 是"先知"：其基与 θ 来自覆盖每条转移的随机游走（3.2 节），因此它一开始就拥有完整且正确的动态描述，而非在训练中通过行动获得；尽管接收与基线相同的像素，其编码器是针对该基在所有单元格渲染上离线训练的。相比之下，SimpleSF 与 DQN 必须从自身经验的像素学习表示，并在任务改变时调整之。在线 Spectral-SF 消除了第一个优势但未消除第二个：其图由自身转移构建，但记录转移需要每步知道智能体所在单元格的标识，故它观察的是状态本身而非像素，且图建立在有限的单元格集合上。因此两个变体衡量的是状态空间给定或可直接观察时谱后继特征的价值；公平比较需要仅从像素学习基。

由于智能体从不评估其行动策略，任何 π_ref 的选择都无法保证该策略最优（2.2 节）。设想一只老鼠与一块奶酪之间隔着一条狭窄走廊，走廊两侧是熔岩，奶酪奖励为 1、熔岩奖励为 −1。最优策略径直穿过走廊。然而进入走廊的均匀随机游走很可能在到达另一端之前踏入熔岩，故 π_ref 的值在走廊及老鼠所在房间为负，且向走廊递减：贪婪的老鼠会远离走廊而永远吃不到奶酪，尽管走廊是唯一通路。这正是我们从环境中移除熔岩块的原因——单一正奖励使 2.2 节的保证成立。

我们的评估也限于简单环境：一个确定性转移、固定布局、两个目标位置的小网格世界。该方法能否扩展到更大、随机、连续或部分可观察的环境，或布局本身的变化，仍有待检验。

4.2 未来工作

我们将通过 Gomez 等（2024）的增广拉格朗日拉普拉斯目标（ALLO）从像素在线学习网格细胞，以去除特权信息；Vijayan 等（2026）已基于该目标在 Atari 与 ProcGen 中从像素学习拉普拉斯特征函数。在智能体自身转移上训练时，它可按顺序恢复拉普拉斯特征向量本身，无需转移图或单元格标识，因此智能体将观察与基线完全相同的内容。由于该目标不使用奖励，基将保持任务无关，目标改变仍只影响 w。随后我们将在更大、更多样的环境中评估该方法。

我们还将修正行动策略，使智能体不再局限于对 π_ref 的一步策略改进：在网络中加入一个分支，学习行动策略自身的动作值，而不仅是固定参考策略的动作值。

附录 D 消融：参考策略，二值与计数权重

2.5 节由智能体观察到的转移计数 c(z,z′) 构建在线 Spectral-SF 的图，权重或为二值 Ŵ_{zz′} = 1[c(z,z′) ≥ 1]，或为计数 Ŵ_{zz′} = c(z,z′)，并从 (10) 的归一化拉普拉斯算子 L̂ 取基。两种加权对应 2.2 节中参考策略 π_ref 的两种选择。

二值权重：均匀随机游走。 二值化意味着只保留转移是否至少被观察到一次，而非次数。一旦远离目标的所有转移均被观察到，每个节点都有 |𝒜| 条单位权重的出边与 |𝒜| 条入边，故度均为 2|𝒜|——目标周围除外（智能体从不在该处行动）。于是 L̂ 退化为 (11)：无论访问次数多少，参考策略都是均匀随机游走，且远离目标处的基与离线 Spectral-SF 相同。

计数权重：平均探索策略。 对 Ŵ 的行归一化得 P̂，即智能体在对之间的经验转移矩阵，随训练累积：P̂_{zz′} 是访问 z 之后移动到 z′（即在 z 所到达的单元格 s′ 中执行 a′）的访问比例。故 P̂ 是智能体探索策略在训练上的平均。记 N 为转移总数，ρ 为各对被访问的频率，则 Ŵ = N D_ρ P̂，其中 D_ρ = diag(ρ)。于是 Â = N(D_ρ P̂ + P̂^⊤ D_ρ)，D̂ = N diag(ρ + P̂^⊤ ρ)；由于因子 N 在 (10) 中消去，

L̂ = I − D^{−1/2}(D_ρ P̂ + P̂^⊤ D_ρ)D^{−1/2}，D = D̂/N = diag(ρ + P̂^⊤ ρ).　(12)

除回合重启与目标外，ρ 对 P̂ 平稳，故 D ≈ 2D_ρ，L̂ 即 (8) 中以平均探索策略为 π_ref 的拉普拉斯算子。当探索均匀时它与二值情形一致。但我们的智能体在训练大部分时间内贪婪行动，且每回合从随机单元格重启，故其访问与动作选择集中于通往目标的路径。计数基因此依赖智能体的探索方式，而二值权重恢复的是环境本身的图。

图 3 在图 1 的任务序列上比较两种加权，各 5 个种子。二值权重——即以均匀随机游走为参考策略——效果最佳。

附录 E 仅状态参数化

对仅状态基 φ(s) ∈ ℝ^n，后继特征 ψ(s) = Θφ(s) 不携带动作索引，动作值只能通过给奖励权重按动作分列 w ∈ ℝ^{n×|𝒜|} 来构造，Q(s,a) = ψ(s)^⊤ w[:,a]。除 2.4 节的不变性障碍外，该参数化还有第二重脆弱性。对正交基（状态特征堆叠为 Φ_𝒮 ∈ ℝ^{|𝒮|×n} 的行），即时奖励的最小二乘拟合按动作分别进行：w[:,a] = Φ_𝒮^⊤ r(·,a)。记 s_g 为目标，𝒮_a = {s : 在 s 处执行动作 a 终止于 s_g}，则奖励为 r(s,a) = 1[s ∈ 𝒮_a]，且

w[:,a] = Φ_𝒮^⊤ r(·,a) = Σ_{s∈𝒮_a} φ(s).　(13)

命题 1. 若 𝒮_a = ∅，则 w[:,a] = 0，从而 Q(·,a) ≡ 0。

证明. (13) 中的求和为空。当该列由梯度下降拟合时同样成立：目标 r(·,a) 恒为零，目标函数 Σ_s (φ(s)^⊤ w[:,a])^2 是在 w[:,a] = 0 处取最小的半正定二次型，在 L2 惩罚下唯一。∎

该前提在实践中成立。|𝒮_a| 统计目标的开邻居中动作 a 可一步到达目标者，故它在任何学习之前即由布局决定。四面中有两面被墙封住的目标会留下两个 𝒮_a = ∅ 的动作，其对应列恒为零；在贪婪规则下，此类动作只会在其余动作值非正之处被选中。
