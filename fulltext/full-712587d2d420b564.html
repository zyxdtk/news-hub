原标题：Optimal Autoregressive Chain-of-Thought Learning via Bagging

中文摘要： 本文研究如何从思维链演示中学习自回归下一词元生成器。作者提出基于bagging的简单算法：在训练数据的自助样本上训练CoT一致预测器，并通过多数投票生成每个词元。对二元词元集，该算法达到与CoT长度T无关的最优样本复杂度O((d_VC+log(1/δ))/ε)；对有限词元集，最优性在log|Σ|因子内成立。集成仅需O(log(T/δ))个生成器，且可通过序列级蒸馏压缩为单个生成器，仅需n log(nT)个无标注提示，保持原有样本复杂度。证明结合了留一分析、后缀平均和稀疏化技术。

基于Bagging的最优自回归思维链学习

作者： Awni Altabaa, John Lafferty, Omar Montasser

单位： 耶鲁大学统计与数据科学系

摘要

我们研究如何从类 ℱ 中学习自回归下一词元生成器 f: Σ* → Σ，给定由 f 生成的长度为 T 的思维链（CoT）演示。我们提出了一种基于 bagging [8] 的简单算法，该算法输出在训练数据的自助样本上训练为 CoT 一致的生成器的多数投票。对于二元词元集，该算法实现了最优样本复杂度 O((d_VC + log(1/δ))/ε)，与 CoT 长度 T 无关，其中 d_VC 是 ℱ 的 VC 维数。对于有限词元集 Σ，VC 维数被多类类比——图维数 d_G 所取代，样本复杂度在 log|Σ| 因子范围内是最优的。多数投票集成中的生成器数量为 O(log(T/δ))，并且我们证明该集成可以以 n log(nT) 个无标注提示为代价蒸馏为 ℱ 中的单个生成器。

1 引言

大语言模型已成为近年来最重要的技术之一，但其核心机制却极为简单：单个下一词元预测器被反复应用，模型产生的每个词元都被附加到下一次预测的上下文中。这类模型在不立即回答、而是先生成一系列中间步骤（即思维链）时最为成功，答案随之而来 [54; 68]。在此类逐步推理的演示上进行训练已成为现代训练流程的核心组成部分。这一成功提出了仅靠经验进展无法解决的问题：需要多少演示才能学会正确推理？更长的推理过程是否会使学习变得更难？哪些学习算法能最好地利用可用数据？解决这些问题需要一种针对自回归生成的学习理论。

自回归学习模型。 秉承经典 PAC 学习理论的精神 [66; 64; 17; 65]，Joshi 等人 [40] 引入了一个优雅的 PAC 式框架来研究自回归学习，我们在全文中采用该框架。在此，语言模型被抽象为来自类 ℱ 的自回归下一词元生成器 f: Σ → Σ，其中 Σ 是词元集。在提示 x ∈ Σ 上，生成器产生词元 f^(1)(x) = f(x)，然后是 f^(2)(x) = f(x ∘ f^(1)(x))，依此类推；经过 T 步后，它产生了思维链 f^(1:T)(x) = (f^(1)(x) ∘ ⋯ ∘ f^(T)(x)) ∈ Σ^T，其最后一个词元被解释为答案。每一步都使用相同的生成器，正如语言模型对每个前缀应用相同的权重一样。自然地产生两种监督形式：在端到端监督下，学习者观察提示及其最终答案，而产生答案的推理过程仍然隐藏；在思维链监督（本文的主题）下，学习者观察整个思维链。

设 P 是 Σ × Σ^T 上的分布，可由某个 f ∈ ℱ 实现，即 Pr[f^(1:T)(x) = y] = 1。学习者观察 n 个独立同分布样本 S = ((x_j, y_j))_{j=1}^n ~ P^n，并输出预测器 f̂: Σ → Σ，然后自回归地运行它。其性能由 CoT 风险衡量，其中预测器 f̂ 必须重现整个思维链，单个错误词元即使输出不正确：

Pr_{(x,y)~P}[∃t ∈ [T]: f̂^(t)(x) ≠ y_t]. (1)

¹ 在思维链监督下，Joshi 等人 [40] 以及 Hanneke、Mehalel 和 Moran [34] 建立了端到端风险 Pr_{(x,y)~P}[f̂^(T)(x) ≠ y_T] 的保证，该风险至多为 CoT 风险 (1)。他们的分析通过界定 CoT 风险进行。本文的重点是 CoT 风险，它与端到端风险不同，两者的学习保证可能不同；进一步讨论见 [7] 和 [34, 第 8 节]。

目标是确定该问题的样本复杂度作为精度 ε、置信度 δ、CoT 长度 T 和类 ℱ 复杂度的函数。此外，该样本复杂度应通过简单高效的学习算法实现。当 T = 1 时，该问题恰好是标签集为 Σ 的 ℱ 的多类学习。因此，思维链监督下的学习至少与多类学习一样难；一个核心问题是：学习生成长思维链是否比学习预测单个词元更难？

先前工作。 作为背景，我们总结思维链监督下自回归学习的现有样本复杂度界。这些界总结在表 1 中，复杂度度量在第 4 节中回顾；相关工作的更广泛讨论推迟到第 7 节。故事始于 Joshi 等人 [40]，他们表明对 Cons_CoT 预言机（返回与训练数据 CoT 一致的生成器）的单次调用实现了 d log T 阶的样本复杂度，其中 d 是 ℱ 的 VC 维数。随后，Hanneke、Mehalel 和 Moran [34] 表明，通过多数投票压缩方案 [52] 可以去除这个 log T 因子，但代价是对偶 VC 维数 d* 的因子，它可能比 d 大指数倍 [1; 43]。之后，Doron-Arad、Mehalel 和 Mossel [22] 通过在线学习获得了另一个与 T 无关的界，但以 Littlestone 维数 d_L 表示，即使对于简单的类（如直线上的阈值），该维数也可能是无限的。

最近，Li [46] 解决了该问题的最优样本复杂度：每个自回归类 ℱ 都可以以样本复杂度 O((d_DS + log(1/δ))/ε) 学习，与 T 无关，其中 d_DS 是 ℱ 的 Daniely–Shalev-Shwartz（DS）维数 [23]，它刻画了多类可学习性 [14]（定义见第 4 节）。这一结果建立在多类学习的最新进展之上，该进展确立了 DS 维数也决定多类学习的最优样本复杂度 [35; 55]。由于 T = 1 的情况本身就是多类学习，这个界一般无法改进。因此，从信息论角度看，生成长思维链并不比生成单个词元更难。然而，实现该样本复杂度的学习器远非实用。它基于单包含图 [33]。给定测试提示 x，学习器构建单包含图，其顶点是 ℱ 中的函数在训练提示和 x 上可以生成的所有思维链，对其边进行定向，并从定向中读出其预测。该图通常非常庞大，并且必须为每个新的测试提示重建和重新定向，使得学习器在计算上难以处理，这与语言模型在实践中训练和部署的方式形成鲜明对比。这引出了我们在本文中研究的一个自然问题：是否存在一种简单高效的自回归学习算法能够达到最优样本复杂度？

2 我们的贡献

对于二元字母表，我们对这个问题给出肯定回答；对于有限字母表，答案最多相差 log|Σ| 因子。我们使用的是机器学习中最古老、最简单的思想之一：bagging。Bagging 由 Breiman [8] 引入，它在从训练集中有放回抽取的自助样本上训练基础学习器，并通过多数投票组合所得的预测器。我们的算法——bagging CoT 一致预测器（第 2 节）——将这一思想引入自回归学习：它在自助样本上训练 N = O(log(T/δ)) 个 CoT 一致预测器，并通过它们的下一词元预测的多数投票生成思维链的每个词元。我们证明它以样本复杂度 O((d_G + log(1/δ))/ε) 学习每个自回归类 ℱ，与 CoT 长度 T 无关，其中 d_G 是 ℱ 的图维数（定理 1）。对于二元字母表，图维数和 DS 维数都与 VC 维数一致，因此我们的界与 [46] 的最优样本复杂度相匹配。对于有限字母表，我们的界在 log|Σ| 因子范围内是最优的。第 2 节的输出是 N 个生成器的集成，这将每个词元的推理成本乘以 N。我们进一步表明，该集成可以使用 O(n log(nT)) 个无标注提示蒸馏为 ℱ 中的单个生成器，同时保持有标注样本复杂度（见命题 1）。

算法 1：Bagging CoT 一致预测器

输入： 训练集 S = ((x_j, y_j))_{j=1}^n，置信度 δ，以及 Cons_CoT 预言机 (4)。

  1. 设 N = max{4, ⌈log₂(2T/δ)⌉}，以及 J_n = {⌈n/4⌉, …, n−1}。
  2. 对每个 i = 1, …, N：
  3. 从 J_n 中均匀采样 k。
  4. 从 S_≤k = ((x_j, y_j))_{j=1}^k 中有放回地均匀采样 k 个样本的自助样本 S'_i。
  5. 在 S'i 上运行 Cons_CoT 预言机，令 f̂{S'_i} = Cons_CoT(S'_i) 为返回的预测器。

输出： f̂{S'_1}, …, f̂{S'_N} 上的多数投票预测器，定义如下（固定平局决胜规则）：

ŷ₁ = MAJ(f̂{S'_1}, …, f̂{S'N})(x) = arg max{y∈Σ} ∑{i=1}^N 1{f̂{S'_i}(x) = y},

ŷ_t = MAJ(f̂{S'_1}, …, f̂{S'N})(x ∘ ŷ{1:t−1})，2 ≤ t ≤ T。

定理 1。 对于图维数为 d_G 的任意自回归类 ℱ、任意 Cons_CoT 预言机，以及 Σ × Σ^T 上满足 P[f^(1:T)(x) = y] = 1（对某个 f* ∈ ℱ）的任意分布 P，对每个 n ≥ 4 和每个 δ ∈ (0,1)，设 N = max{4, ⌈log₂(2T/δ)⌉}，则在训练数据集 S = ((x_j, y_j))_{j=1}^n ~ P^n 的随机抽取和按第 2 节方式抽取的 N 个自助样本 S'_1, …, S'_N 上，以至少 1−δ 的概率，

Pr_{(x,y)~P}[∃t ∈ [T]: MAJ(f̂{S'_1}, …, f̂{S'_N})^(t)(x) ≠ y_t] = O(d_G/n + (1/n)log(1/δ))。

注 1（最优性）。 定理 1 中的样本复杂度与已知下界比较如下。

  • 二元字母表。 该界是最优的，因为 d_G 恰好是 ℱ 的 VC 维数，这与 PAC 学习的经典下界 Ω((d_G + log(1/δ))/ε) [27] 相匹配，该下界在 T = 1 时即成立。
  • 有限字母表。 该界在 log|Σ| 因子范围内是最优的：图维数满足 d_G ≤ 4.67 d_N log₂|Σ|，其中 d_N 是 ℱ 的 Natarajan 维数 [53; 15; 24]，而多类学习（因而我们的问题）需要 Ω((d_N + log(1/δ))/ε) 个样本 [53; 24]。

注 2。 使用 N = O(d + log(1/δ)) 个自助样本（和预言机调用）也可以获得相同的保证，其中 d 是 ℱ 的对偶 VC 维数（见引理 6）。因此 N = O(log(1/δ) + min{d*, log T}) 即可。

第 2 节简单且高效。它仅通过 Cons_CoT 预言机访问该类，调用次数为 N = O(log(T/δ))，其输出本身就是一个下一词元生成器：每个词元通过在当前前缀上评估 N 个基础预测器并返回最频繁的预测获得，因此长度为 T 的思维链只需 NT 次 ℱ 中预测器的评估。我们还注意到，与一般的 bagging [8] 一样，第 2 节中的训练和推理都可以在 N 个基础预测器之间并行化。此外，该集成可以在训练后蒸馏为 ℱ 中的单个生成器，从而去除每个词元成本中的 N 因子（见第 6 节）。相比之下，Li [46] 的最优学习器通过在 ℱ 可以在训练提示和测试提示上生成的所有思维链上构建和定向单包含图来进行预测，这种构造必须为每个新的测试提示重复进行，且在计算上难以处理。

对于非常大（和无限）的字母表，一个自然的问题是，像第 2 节这样聚合 ℱ 中预测器的简单算法是否能达到最优样本复杂度 O((d_DS + log(1/δ))/ε)。遗憾的是，答案是否定的。这一障碍继承自多类学习，因此在 T = 1 时就已经出现，此时我们的问题退化为 ℱ 的多类学习。在我们的背景下，关于适当学习器聚合的最新不可能性结果 [6] 有两个推论。第一，存在一些类 ℱ，在其上一致学习器的多数投票需要 Ω((d_G + log(1/δ))/ε) 个样本，因此定理 1 中对图维数的依赖对于第 2 节是紧的。第二，存在一个 DS 维数有限的类 ℱ，任何从该类中聚合有限多个预测器的算法都无法将其学习到常数误差，因此对于无限字母表，没有这样的算法能够达到最优样本复杂度。这或许表明学习算法的简单性与其样本复杂度的最优性之间存在根本性的张力，这与最近关于多类学习简单学习原理局限性的工作 [4] 一致。

3 证明思想概述

在简要描述先前方法之后，我们重点介绍定理 1 证明背后的主要思想。Joshi 等人 [40] 通过思维链错误类的 VC 维数分析 CoT 一致预测器，这产生了 log T 因子。Hanneke、Mehalel 和 Moran [34] 采用基于样本压缩方案的分析，这去除了对 T 的依赖，但产生了对偶 VC 维数 d* 的因子。Li [46] 通过定向思维链类的单包含图进行预测，达到了最优样本复杂度，但在计算上难以处理。我们采取不同的路线，灵感来自 [49] 中关于对抗鲁棒学习的 bagging 最新分析：我们不是分析单个预测器，而是分析在随机样本上训练的 CoT 一致预测器上的分布，并通过 bagging 聚合它们。在全文中，设 ℱ 是图维数为 d_G 的类，固定任意 Cons_CoT 预言机，设 P 是可实现的分布。分析有三个主要部分。

CoT 一致预测器的分布。 关键思想是分析从随机训练样本 S ~ P^n 获得的 CoT 一致预测器 f̂_S 的分布。引理 1 表明，对于随机测试样本，在目标思维链的最坏步骤处出错的这些预测器的比例很小：

E_{(x,y)~P}[max_{t∈[T]} Pr_{S~P^n}[f̂S(x ∘ y{1:t−1}) ≠ y_t]²] = O(d_G/n). (2)

换句话说：在大多数测试样本上，在目标思维链的每一步，大多数 CoT 一致预测器都能预测出正确的词元，尽管出错的预测器可能因步骤而异。这比要求单个预测器在所有步骤同时正确的要求更弱，这就是界不依赖于 T 的原因。对于单个 CoT 一致预测器，Li [46, 定理 6.2] 表明对 T 的依赖是不可避免的：对于合适的二元类和 Cons_CoT 预言机，

E_{(x,y)~P} E_{S~P^n}[max_{t∈[T]} 1{f̂S(x ∘ y{1:t−1}) ≠ y_t}] = Ω(d_G log T / n)。

(2) 的证明基于一个简单的观察。对于每个测试样本，我们预先固定随机预测器 f̂_S 最可能出错的步骤；这个选择依赖于 P、n 和 Cons_CoT 预言机，但不依赖于样本。每个 CoT 一致预测器在每个训练思维链的每一步都是正确的，特别是在每个训练样本的选定步骤处。因此，界定 (2) 相当于界定一致学习器在固定的下一词元预测问题上、在 VC 维数至多为 d_G 的错误区域类上的期望错误数，这是一个标准分析。为了避免对数因子，我们直接界定 (2) 中的二阶矩，依赖于最近关于一致学习器的二阶矩界 [5; 60]；如 [17] 中那样仅界定一阶矩会产生额外的 log(n/d_G) 乘法因子。

Bagging 留一分析。 界 (2) 涉及在来自 P 的新样本上训练的预测器，而第 2 节在单个样本 S 的自助样本上训练预测器。为了将两者联系起来，我们考虑一个理想化的 bagging 预测器，它聚合在 S 的所有有序自助样本上训练的 CoT 一致预测器。对于 x' ∈ Σ* 和 y' ∈ Σ，其 bagging 得分是在 x' 上预测 y' 的这些预测器的比例：

B̂S(y'|x') := Pr{S'~Unif(S)^|S|}[f̂_{S'}(x') = y']。

我们界定其留一误差。关键观察是，大小为 n−1 的 S 的自助样本以概率 (1−1/n)^{n−1} ≥ 1/e 省略第 i 个样本，此时它是不含该样本的样本 S_{−i} 的自助样本。这一观察是 bagging 误差的袋外估计 [9; 67; 62] 以及更广泛的留一自助估计 [25; 28] 的基础；在这里，我们用它来界定留一误差而不是估计它。由于 S 的自助样本是来自其经验分布 D := Unif(S) 的样本，该观察将留一误差归结为 (2) 中界定的量，其中 D 代替 P（引理 3）：

(1/n)∑{i=1}^n max{1≤t≤T}(1−B̂{S{−i}}(y_{i,t}|x_i ∘ y_{i,1:t−1}))² ≤ e² E_{(x,y)~D}[max_{1≤t≤T} Pr_{S'~D^{n−1}}[f̂{S'}(x ∘ y{1:t−1}) ≠ y_t]²]. (3)

由 (2)，右边是 O(d_G/n)。最后，由可交换性（注 3），(3) 也以 O(d_G/n) 界定理想化 bagging 预测器在新样本上的期望平方最坏步骤误差。由于其多数投票只有在某个步骤处正确词元获得至多一半投票时才在思维链上出错，其期望 CoT 风险也是 O(d_G/n)，与 T 无关。

高概率界与稀疏化。 为了获得对 log(1/δ) 具有最优依赖的高概率界，我们采用 Aden-Ali 等人 [3] 的后缀平均技术，该技术将置换不变预测器的留一界转换为高概率界。这导出了后缀 bagging 预测器，它对样本的前缀 S_≤k 的 bagging 预测器取平均，其平方最坏步骤误差以高概率为 O((d_G + log(1/δ))/n)（引理 4）。

主要挑战在于后缀 bagging 预测器难以计算：它聚合在每个前缀的所有有序自助样本上训练的预测器，数量是 n 的指数级，每个都需要调用 Cons_CoT 预言机。第 2 节的一个关键思想是随机采样这些预测器中的 N 个并进行多数投票，这可以看作是后缀 bagging 预测器的蒙特卡洛近似。秉承 [45, 引理 3] 的精神，我们证明 N = O(log(T/δ)) 个样本就足够了，与 n 无关（引理 5）。原因是只有每个样本的 T 个目标前缀上的投票才重要：在每个前缀处，采样多数投票以在 N 中指数小的概率出错，该概率与引理 4 控制的平方误差成正比，对 T 步的并集界完成证明。这是 CoT 长度出现的唯一地方，也是我们在全文中用平方最坏步骤误差衡量错误的原因：阈值化损失只会产生加性近似误差，从而导致预言机调用数量随 n 对数增长。或者，Moran 和 Yehudayoff [52] 的经典稀疏化论证给出 N = O(d + log(1/δ))，与 T 无关（引理 6），但对偶 VC 维数 d 可能比 d_G 大指数倍 [1; 43]。

4 技术定义

自回归学习。 我们回顾第 1 节的设定并固定记号。设 Σ 是词元集（有限或无限），设 Σ 是 Σ 上的有限字符串集，并对每个正整数 r 记 [r] = {1, …, r}。对于生成器 f: Σ → Σ 和提示 x ∈ Σ*，生成的词元递归地定义为

f^(1)(x) = f(x) 以及 f^(t)(x) = f(x ∘ f^(1)(x) ∘ ⋯ ∘ f^(t−1)(x))，t ≥ 2，

其中 ∘ 是拼接，且 f^(1:T)(x) = f^(1)(x) ∘ ⋯ ∘ f^(T)(x) ∈ Σ^T。学习者从 Σ* × Σ^T 上可由 ℱ 实现的分布 P 中接收 S = ((x_j, y_j))_{j=1}^n ~ P^n，并通过其 CoT 风险 (1) 进行评估。

CoT 一致预言机。 我们的算法仅通过 Cons_CoT 预言机访问 ℱ：这是一个确定性规则，给定可由 ℱ 实现的样本 S，返回重现 S 中每个思维链的 f̂_S := Cons_CoT(S) ∈ ℱ：

f̂S := Cons_CoT(S) ∈ {f ∈ ℱ : f^(t)(x_j) = y{j,t} 对所有 j ∈ [n] 和 t ∈ [T]}. (4)

我们称这样的生成器与 S 是 CoT 一致的。等价地，它正确预测 S 中思维链沿线的每个下一词元：对所有 j ∈ [n] 和 t ∈ [T]，f̂S(x_j ∘ y{j,1:t−1}) = y_{j,t}。

复杂度度量。 我们简要回顾 ℱ 的四个标准组合维数，将 ℱ 视为从 Σ 到 Σ 的下一词元预测器类：VC 维数、图维数、Natarajan 维数和 DS 维数。对于提示 x_1, …, x_k ∈ Σ，记 ℱ|_{(x_1,…,x_k)} = {(f(x_1), …, f(x_k)) : f ∈ ℱ} ⊆ Σ^k 为 ℱ 在它们上实现的下一词元模式集。下面的每个维数是使某些提示 x_1, …, x_k 在相应意义下被打散的最大 k，如果不存在最大 k 则为 ∞。

  • VC 维数 d_VC(ℱ) [66]，对于 |Σ| = 2：如果 ℱ|_{(x_1,…,x_k)} = Σ^k，则 x_1, …, x_k 被打散。
  • 图维数 d_G(ℱ) [53]：如果存在词元 s_1, …, s_k ∈ Σ，使得对每个 B ⊆ [k]，某个 f ∈ ℱ 恰好在 i ∈ B 处满足 f(x_i) = s_i，则 x_1, …, x_k 被 G-打散。等价地，d_G(ℱ) 是 Σ* × Σ 上 0-1 损失类 {(x,y) ↦ 1{f(x) ≠ y} : f ∈ ℱ} 的 VC 维数。
  • Natarajan 维数 d_N(ℱ) [53]：如果存在词元 s_i ≠ s'_i（i ∈ [k]），使得对每个 B ⊆ [k]，某个 f ∈ ℱ 在 i ∈ B 处满足 f(x_i) = s_i 且在 i ∉ B 处满足 f(x_i) = s'_i，则 x_1, …, x_k 被 N-打散。
  • DS 维数 d_DS(ℱ) [23; 14]：如果 ℱ|_{(x_1,…,x_k)} 包含一个 k 维伪立方体，即一个非空有限集 H ⊆ Σ^k，其中每个模式 h ∈ H 对每个 i ∈ [k] 都有一个邻居 h' ∈ H 满足 h'_i ≠ h_i 且对所有 j ≠ i 有 h'_j = h_j，则 x_1, …, x_k 被 DS-打散。

当类从上下文中清楚时，我们简单地写 d_VC、d_G、d_N 和 d_DS。对于二元字母表，四个概念一致：d_G = d_N = d_DS = d_VC。对于有限字母表，它们满足关系 d_N ≤ d_DS ≤ d_G ≤ 4.67 d_N log₂|Σ| [15; 24; 14]。特别地，三个维数同时有限，且 Natarajan 维数和 DS 维数都刻画了有限字母表的可学习性 [24; 14]。对于无限字母表，不等式 d_N ≤ d_DS 和 d_N ≤ d_G 仍然成立，但这些维数可能截然不同：图维数可能无限而 DS 维数有限 [23; 6]，DS 维数可能无限而 Natarajan 维数等于一；一般只有 DS 维数刻画可学习性 [14]。

5 定理 1 的证明

在本节中，我们提供定理 1 的完整证明，重述如下。

5.1 Bagging 的留一分析

我们首先表明，在大多数测试样本上，目标思维链沿线的每一步都被大多数 CoT 一致预测器正确预测：对每个 t ∈ [T]，在训练样本 S ~ P^n 上 f̂S 在前缀 x ∘ y{1:t−1} 上出错的概率很小。这个保证是逐步的，出错的预测器可能因步骤而异；正是多数投票随后将这些逐步保证组合成正确的思维链。

引理 1。 对于图维数为 d_G 的任意自回归类 ℱ、任意 Cons_CoT 预言机，以及 Σ × Σ^T 上满足 P[f^(1:T)(x) = y] = 1（对某个 f* ∈ ℱ）的任意分布 P，

E_{(x,y)~P}[a(x,y)²] ≤ C·d_G/n，其中 a(x,y) := max_{1≤t≤T} Pr_{S~P^n}[f̂S(x ∘ y{1:t−1}) ≠ y_t]，

其中 C ≥ 1 是引理 2 的普适常数。

证明依赖于以下关于 VC 类上一致学习规则的二阶矩界。经典的一阶矩界 [17] 也足够，但代价是 log(n/d_G) 的乘法因子。

引理 2（[5; 60]）。 存在普适常数 C ≥ 1 使得以下成立。设 P 是 𝒳 × 𝒴 上的分布，ℰ 是 𝒳 × 𝒴 上 VC 维数为 d 的子集类。设 E 是确定性选择器，使得对每个 S ∈ (𝒳 × 𝒴)^n 有 E(S) ∈ ℰ 且 Pr_{S~P^n}[E(S) ∩ S = ∅] = 1。则，

E_{(x,y)~P}[Pr_{S~P^n}[(x,y) ∈ E(S)]²] ≤ C·d/n。

引理 1 的证明。 量 a(x,y) 是 f̂_S 在目标思维链最坏步骤处的错误概率。思想是预先为每个样本固定这个最坏步骤，这将 a(x,y) 归结为单个下一词元样本上的错误概率，然后对所得的错误区域类应用引理 2。

我们首先为每个样本固定该预测器最可能出错的前缀。对于 ∈ Σ × Σ^T，设 t(x,y) ∈ [T] 是在 a(x,y) 定义中达到最大值的最小索引，并定义映射 φ: Σ × Σ^T → Σ* × Σ 为 φ(x,y) := (x ∘ y_{1:t(x,y)−1}, y_{t(x,y)})。换句话说，φ 将提示及其目标思维链映射到单个下一词元样本：思维链直到步骤 t(x,y)−1 的前缀，由步骤 t(x,y) 处的正确词元标注。映射 φ 依赖于 P、n 和 Cons_CoT 预言机，但不依赖于样本 S。记 φ = (φ₁, φ₂)，由构造我们有

a(x,y) = Pr_{S~P^n}[f̂_S(φ₁(x,y)) ≠ φ₂(x,y)]. (5)

我们现在验证引理 2 的条件：我们展示 Σ* × Σ^T 上 VC 维数至多为 d_G 的子集类，以及进入该类的确定性选择器，其选择的集合与样本不相交。对每个 f ∈ ℱ，定义相对于 φ 的错误区域及所有此类区域的类：

E_f := {(x,y) ∈ Σ* × Σ^T : f(φ₁(x,y)) ≠ φ₂(x,y)}，ℰ := {E_f : f ∈ ℱ}。

我们有 ∈ E_f 当且仅当 φ(x,y) ∈ G_f，其中 G_f := {(x',y') ∈ Σ* × Σ : f(x') ≠ y'} 是 f 的词元级错误区域。因此，如果 ℰ 打散 k 个点，那么 {G_f : f ∈ ℱ} 打散它们在 φ 下的 k 个像，这些像必然不同，因此 VCdim(ℰ) ≤ VCdim({G_f : f ∈ ℱ}) = d_G。

接下来，考虑选择器 E(S) := E_{f̂S}，它是确定性的且取值于 ℰ。由可实现性，存在 f ∈ ℱ 满足 Pr_{(x,y)~P}[f^(1:T)(x) = y] = 1。由 (4) 可得 f̂_S 与样本 S 是 CoT 一致的；即对所有_j) ∈ S 和 t ∈ [T]，f̂_S(x_j ∘ y{j,1:t−1}) = y_{j,t}。特别地，对每个 j 有 f̂_S(φ₁(x_j, y_j)) = φ₂(x_j, y_j)，因此 E(S) ∩ S = ∅ 以概率 1 成立。

我们现在可以调用引理 2。由 (5)，a(x,y) = Pr_{S~P^n}[(x,y) ∈ E(S)]，因此引理 2 应用于 ℰ 和选择器 E，得到

E_{(x,y)~P}[a(x,y)²] = E_{(x,y)~P}[Pr_{S~P^n}[(x,y) ∈ E(S)]²] ≤ C·d_G/n。∎

Bagging。 我们引入 bagging 的记号。对于序列 S = ((x₁,y₁), …, (x_n,y_n)) 和自助样本大小 m ≥ 1，设 S' ~ Unif(S)^m 是从 S 中均匀随机（有放回）抽取的 m 个样本的自助样本，f̂{S'} = Cons_CoT(S') 是 Cons_CoT 预言机 (4) 在 S' 上返回的预测器。等价地，我们可以将其表示为均匀随机抽取索引序列 I = (i₁, …, i_m) ∈ [n]^m，并将自助样本记为 S(I) = ((x{i₁},y_{i₁}), …, (x_{i_m},y_{i_m}))。

定义 bagging 预测器 B̂^m_S，它将每个输入 x ∈ Σ* 映射到 Σ 上的分布 B̂^m_S(·|x)，其 bagging 得分 B̂^m_S(y|x) 是 S 的大小为 m 的 n^m 个有序自助样本中返回的预测器在输入 x 上输出 y 的比例：

B̂^m_S(y|x) := Pr_{S'~Unif(S)^m}[f̂{S'}(x) = y] = (1/n^m)∑{I∈[n]^m} 1{f̂_{S(I)}(x) = y}. (6)

由于每个预测器恰好输出一个词元，∑{y∈Σ} B̂^m_S(y|x) = 1，因此 B̂^m_S(·|x) 确实是下一词元上的条件分布；在输入 x 上，所有自助预测器的多数投票输出该分布的众数 arg max{y∈Σ} B̂^m_S(y|x)。当自助样本大小等于其源样本大小时，我们使用简写 B̂_S := B̂^{|S|}_S。

我们现在着手界定 bagging 预测器 (6) 的留一风险。

引理 3（留一误差）。 对于图维数为 d_G 的任意自回归类 ℱ、任意 Cons_CoT 预言机，以及任意可实现的序列 S = ((x₁,y₁), …, (x_n,y_n))（n ≥ 2），

(1/n)∑{i=1}^n max{t∈[T]}(1−B̂{S{−i}}(y_{i,t}|x_i ∘ y_{i,1:t−1}))² ≤ 2e²C·d_G/n。

注 3（期望风险）。 注意，通过可交换性论证，将引理 3 应用于大小为 n+1 的样本得到期望界

E_{S~P^n} E_{(x,y)~P}[max_{t∈[T]}(1−B̂S(y_t|x ∘ y{1:t−1}))²] ≤ 2e²C·d_G/(n+1)。

由于所有自助预测器的多数投票只有在某个步骤处 bagging 分布在正确词元上放置至多一半质量时才在的思维链上出错，即仅当对某个步骤 t ∈ [T] 有 B̂S(y_t|x ∘ y{1:t−1}) ≤ 1/2 时，其期望 CoT 风险 (1) 至多为 8e²Cd_G/(n+1)。

引理 3 的证明。 思想是大小为 n−1 的 S 的自助样本以至少 1/e 的概率省略第 i 个样本，此时它只是 S_{−i} 的自助样本。因此留一误差由 S 上 bagging 的误差控制，引理 1 适用于 P 是 S 上的均匀分布的情况。这是 bagging 误差的袋外估计 [9] 的基础观察。

设 m = n−1 且 P = Unif(S)。固定 i ∈ [n] 和 t ∈ [T]，记 x' = x_i ∘ y_{i,1:t−1} 和 y' = y_{i,t} 为相应的前缀及其下一词元。从 [n]^m 中均匀抽取 I。在概率为 (1−1/n)^{n−1} ≥ 1/e 的事件 i ∉ I 上，索引序列 I 在 ([n]∖{i})^m 上均匀分布，因此 S(I) 是 S_{−i} 的大小为 m = |S_{−i}| 的自助样本。因此，由全概率公式和 (6)，

1−B̂^m_S(y'|x') = Pr_I[f̂{S(I)}(x') ≠ y'] ≥ Pr_I[i ∉ I]·Pr_I[f̂{S(I)}(x') ≠ y' | i ∉ I] ≥ (1/e)(1−B̂{S{−i}}(y'|x'))。

换句话说，在 S_{−i} 的自助样本上训练的 CoT 一致预测器在 x' 上未能预测 y' 的频率至多是在 S 的自助样本上训练的预测器的 e 倍。

现在观察到，对每个 ∈ Σ* × Σ^T，

max_{t∈[T]}(1−B̂^m_S(y_t|x ∘ y_{1:t−1})) = max_{t∈[T]} Pr_{S'~P^m}[f̂{S'}(x ∘ y{1:t−1}) ≠ y_t] = a(x,y)

恰好是引理 1 中的量，对应分布 P 和大小为 m 的样本。将此恒等式与上述比较结合，对 t ∈ [T] 取最大值并平方，我们对每个 i ∈ [n] 得到

max_{t∈[T]}(1−B̂{S{−i}}(y_{i,t}|x_i ∘ y_{i,1:t−1}))² ≤ e²a(x_i,y_i)²。

对 i ∈ [n] 取平均，并注意到 a(x_i,y_i)² 在 S 的 n 个样本上的平均值是其在 P = Unif(S) 下的期望，我们得到

(1/n)∑{i=1}^n max{t∈[T]}(1−B̂{S{−i}}(y_{i,t}|x_i ∘ y_{i,1:t−1}))² ≤ e²E_{(x,y)~P}[a(x,y)²] ≤ e²C·d_G/m，

其中最后一个不等式来自引理 1，该引理适用因为 P = Unif(S) 是可实现的（因为 S 是可实现的）。由于 n ≥ 2 时 m = n−1 ≥ n/2，引理得证。∎

5.2 高概率界与稀疏化

我们这里的目标是将引理 3 的留一误差界转换为高概率界，然后使用有限次 Cons_CoT 预言机调用来近似所得的后缀 bagging 预测器。

后缀平均与后缀 bagging 预测器。 我们的第一步是将 Aden-Ali 等人 [3] 的后缀平均技术应用于 bagging (6)。对于 n ≥ 4 的序列 S = ((x_j,y_j)){j=1}^n，设 J_n = {⌈n/4⌉, …, n−1}，S≤k = ((x_j,y_j)){j=1}^k（k ∈ J_n）。这里 S≤k 是长度为 k 的前缀。接下来我们引入后缀 bagging 预测器，它对后缀 k ∈ J_n 上的 bagging 预测器 B̂{S≤k} 取平均，然后着手以高概率界定其风险。形式上，对 x ∈ Σ* 和 y ∈ Σ 定义，

ĝ_S(y|x) := (1/|J_n|)∑{k∈J_n} B̂{S_≤k}(y|x) = E_{k~Unif(J_n)}[Pr_{S'~Unif(S_≤k)^k}[f̂_{S'}(x) = y]] (7)

= (1/|J_n|)∑{k∈J_n}(1/k^k)∑{I∈[k]^k} 1{f̂_{S(I)}(x) = y}。

作为分布 B̂{S≤k}(·|x) 的平均，ĝ_S(·|x) 再次是 Σ 上的分布，且 ĝ_S(y|x) 是 Cons_CoT 预言机在随机选择的前缀的随机自助样本上运行时在输入 x 上预测词元 y 的概率。下一个引理表明，在样本上以高概率，后缀 bagging 投票在目标思维链最坏步骤处的平方误差在测试样本上平均而言很小。

引理 4（高概率界）。 对于图维数为 d_G 的任意自回归类 ℱ、任意 Cons_CoT 预言机、Σ × Σ^T 上满足 P[f^(1:T)(x) = y] = 1（对某个 f* ∈ ℱ）的任意分布 P、任意 n ≥ 4 和任意 δ ∈ (0,1)，在 S ~ P^n 上以至少 1−δ 的概率，

E_{(x,y)~P}[max_{t∈[T]}(1−ĝ_S(y_t|x ∘ y_{1:t−1}))²] ≤ 19.28e²C(d_G/n + (1/n)log(2/δ))。

证明。 证明分两步。我们首先将引理 3 的留一保证转换为 bagging 预测器损失的高概率界（在样本的前缀 S_≤k 上取平均）；然后通过 Jensen 不等式从这个平均值过渡到后缀 bagging 预测器 ĝ_S。

bagging 预测器 B̂^m_S 在 S 的置换下不变，因为它对所有有序自助样本取平均，即使 Cons_CoT 预言机依赖于其输入的顺序。此外，引理 3 将平均留一损失 (1/n)∑{i=1}^n max{t∈[T]}(1−B̂{S{−i}}(y_{i,t}|x_i ∘ y_{i,1:t−1}))² 一致地（对所有可实现序列）界定为 2e²Cd_G/n，且该损失取值于 [0,1]。因此我们可以对该损失调用 Aden-Ali 等人 [3, 定理 2.1] 的后缀平均界²：在 S ~ P^n 上以至少 1−δ 的概率，

(1/|J_n|)∑{k∈J_n} E{(x,y)~P}[max_{t∈[T]}(1−B̂{S≤k}(y_t|x ∘ y_{1:t−1}))²] ≤ 19.28e²C·(d_G + log(2/δ))/n. (8)

² 对于可被 4 整除的 n，[3, 定理 2.1] 将 k ∈ {n/4, …, n−1} 上的平均风险界定为 4.82(M + log(2/δ))/n，其中 M 界定留一损失之和；这里 M = 2e²Cd_G。对于一般的 n ≥ 4，将其应用于前 n' = 4⌊n/4⌋ ≥ n/2 个样本。与其索引集相比，J_n 至多省略一个索引并至多添加三个，每个的损失至多为 1；由于 |J_n| ≥ max{n/2, 3n'/4}，这至多以因子 2 和加性 6/n 改变该界。由于 6 ≤ 9log(2/δ) 且 C ≥ 1，所得的界 (19.28e²Cd_G + 9.64log(2/δ) + 6)/n 至多为 (8) 的右边。

剩下的是从 bagging 预测器 B̂{S≤k} 的平均损失过渡到它们的平均值 ĝ_S 的损失。固定 ∈ Σ* × Σ^T，对 t ∈ [T] 记 x_t = x ∘ y_{1:t−1}。由 (7)，ĝ_S(y_t|x_t) 是 B̂{S≤k}(y_t|x_t) 在 k ∈ J_n 上的平均，因此 Jensen 不等式给出，对每个 t ∈ [T]，

(1−ĝ_S(y_t|x_t))² ≤ (1/|J_n|)∑{k∈J_n}(1−B̂{S_≤k}(y_t|x_t))² ≤ (1/|J_n|)∑{k∈J_n} max{s∈[T]}(1−B̂{S≤k}(y_s|x_s))²。

右边不依赖于 t。在左边对 t ∈ [T] 取最大值，然后对 ~ P 取期望，并应用 (8) 即证明了该断言。∎

后缀 bagging 预测器 (7) 对所有有序自助样本取平均，因此难以计算。我们通过采样有限多个预测器来近似其词元投票，如第 2 节所示。以下稀疏化界秉承 [45, 引理 3] 的精神直接控制 CoT 风险 (1)。思想很简单：采样多数投票只有在至少一半的采样预测器在目标前缀处出错时才出错，该事件的概率在 N 中指数衰减，且至多与由引理 4 控制的投票平方误差成正比。由于这个量既出现在期望误差的界中，也出现在 Markov 不等式的阈值中，它在失败概率中抵消，预言机调用次数不依赖于 n。

引理 5（通过二项尾部的稀疏化）。 固定大小为 n ≥ 4 的可实现样本 S 和 Σ* × Σ^T 上的分布 P。设 ĥ = MAJ(f̂{S'_1}, …, f̂{S'_N}) 是 Cons_CoT 预言机在按第 2 节步骤 3–4 抽取的 N 个独立自助样本上返回的预测器的多数投票（固定平局决胜）。对任意 δ ∈ (0,1)，如果 N ≥ max{4, log₂(T/δ)}，则在自助样本上以至少 1−δ 的概率，

Pr_{(x,y)~P}[∃t ∈ [T]: ĥ^(t)(x) ≠ y_t] ≤ 256 E_{(x,y)~P}[max_{t∈[T]}(1−ĝ_S(y_t|x ∘ y_{1:t−1}))²]. (9)

证明。 固定 S。在证明过程中，无下标的概率和期望是在自助样本 S'1, …, S'_N 上的。记 r(x,y) := max{t∈[T]}(1−ĝ_S(y_t|x ∘ y_{1:t−1}))² 为后缀 bagging 预测器在 ∈ Σ* × Σ^T 上的平方最坏步骤误差，因此 (9) 的右边是 256E_{(x,y)~P}[r(x,y)]。设 E 是 r(x,y) ≥ 1/256 的样本集，即对某个 t ∈ [T] 有 ĝ_S(y_t|x ∘ y_{1:t−1}) ≤ 15/16 的样本集。那么，对自助样本的每个实现，

Pr_{(x,y)~P}[∃t ∈ [T]: ĥ^(t)(x) ≠ y_t] ≤ P(E) + Z，Z := Pr_{(x,y)~P}[ ∉ E, ∃t ∈ [T]: ĥ^(t)(x) ≠ y_t]。

由于在 E 上 r(x,y) ≥ 1/256，P(E) ≤ 256E_{(x,y)~P}[1{ ∈ E}r(x,y)]。只需证明以至少 1−δ 的概率，Z ≤ 256E_{(x,y)~P}[1{ ∉ E}r(x,y)]；将两个界相加即证明 (9)。

由期望的线性性，E[Z] = E_{(x,y)~P}[1{ ∉ E}Pr[∃t ∈ [T]: ĥ^(t)(x) ≠ y_t]]。

现在固定 ∉ E。由 E 的定义，我们有 r(x,y) < 1/256，即 max_{t∈[T]}(1−ĝ_S(y_t|x ∘ y_{1:t−1})) < 1/16，因此正确词元的后缀 bagging 得分在每一步都超过 15/16。由于 ĥ 在第一次错误之前遵循目标思维链，它只有在某个 t ∈ [T] 处 ĥ(x ∘ y_{1:t−1}) ≠ y_t 时才在上出错。固定步骤 t，设 p = 1−ĝ_S(y_t|x ∘ y_{1:t−1}) < 1/16。我们断言采样预测器在该步骤的错误是均值为 p 的独立 Bernoulli 变量。事实上，自助样本 S'1, …, S'_N 是独立的，每个 S'_j 恰好按 (7) 的方式抽取，即从 J_n 中均匀选择 k，然后均匀自助抽取 S≤k。因此指标 1{f̂{S'_j}(x ∘ y{1:t−1}) ≠ y_t}（j ∈ [N]）是独立的，每个的均值为 Pr[f̂{S'_j}(x ∘ y{1:t−1}) ≠ y_t] = 1−ĝ_S(y_t|x ∘ y_{1:t−1}) = p。

如果少于一半的采样预测器出错，那么 y_t 获得严格多数投票。因此 ĥ(x ∘ y_{1:t−1}) ≠ y_t 仅当某个 ⌈N/2⌉ 个预测器的集合全部出错，由独立性，每个固定集合的该事件概率为 p^⌈N/2⌉ ≤ p^{N/2}。对至多 2^N 个这样的集合取并集界，利用 4p ≤ 1/4 和 N ≥ 4，得到

Pr[ĥ(x ∘ y_{1:t−1}) ≠ y_t] ≤ 2^N p^{N/2} = (4p)²(4p)^{N/2−2} ≤ 16p²·4^{2−N/2} = 256p²2^{−N}。

对 T 步取并集界得到，对每个 ∉ E 有 Pr[∃t ∈ [T]: ĥ^(t)(x) ≠ y_t] ≤ 256T2^{−N}r(x,y)。将其代入 E[Z] 的表达式，并利用 T2^{−N} ≤ δ（因为 N ≥ log₂(T/δ)），我们得到 E[Z] ≤ 256δE_{(x,y)~P}[1{ ∉ E}r(x,y)]。Markov 不等式现在蕴含，以至少 1−δ 的概率，Z ≤ 256E_{(x,y)~P}[1{ ∉ E}r(x,y)]，其中如果该期望为零，则 Z 几乎必然为 0。这就完成了证明。∎

或者，Moran 和 Yehudayoff [52] 的稀疏化论证同时近似所有后缀 bagging 得分，样本数与 T 无关但依赖于 ℱ 的对偶 VC 维数。以下高概率形式由 ℱ 的对偶类的一致收敛得出。

引理 6（通过对偶 VC 维数的稀疏化）。 设 ℱ 是从 Σ 到 Σ 的函数类。对每个 ∈ Σ × Σ，定义评估函数 g_{(x,y)}: ℱ → {0,1} 为 g_{(x,y)}(f) := 1{f(x) = y}。ℱ 的对偶类是 𝒢 := {g_{(x,y)} : ∈ Σ × Σ}，其 VC 维数 d := VCdim(𝒢) 是 ℱ 的对偶 VC 维数。设 Q 是 ℱ 上的任意分布。对任意 ε, δ ∈ (0,1)，以至少 1−δ 的概率，N = O((d* + log(1/δ))/ε²) 个独立预测器 f₁, …, f_N ~ Q 满足

sup_{(x,y)∈Σ*×Σ} |(1/N)∑{j=1}^N g{(x,y)}(f_j) − E_{f~Q}[g_{(x,y)}(f)]| ≤ ε。

5.3 组装各部分

定理 1 的证明。 设 S ~ P^n，ĥ = MAJ(f̂{S'_1}, …, f̂{S'_N}) 是算法 2 的输出。由引理 4，在 S 上以至少 1−δ/2 的概率，

E_{(x,y)~P}[max_{t∈[T]}(1−ĝ_S(y_t|x ∘ y_{1:t−1}))²] ≤ 19.28e²C(d_G/n + (1/n)log(4/δ)). (10)

对每个固定的 S，我们的选择 N = max{4, ⌈log₂(2T/δ)⌉} 允许我们以失败概率 δ/2 应用引理 5。因此，以至少 1−δ/2 的条件概率，ĥ 的 CoT 风险 (1) 至多为 (10) 左边的 256 倍。通过并集界组合两个保证，在训练和自助样本上以至少 1−δ 的概率，

Pr_{(x,y)~P}[∃t ∈ [T]: ĥ^(t)(x) ≠ y_t] ≤ 256·19.28e²C(d_G/n + (1/n)log(4/δ))。

对于 d_G ≥ 1，我们有 d_G + log(4/δ) ≤ (1+log 4)(d_G + log(1/δ))，给出常数为 256·19.28(1+log 4)e²C 的所述界。当 d_G = 0 时，ℱ 中的所有函数在每个下一词元上一致，CoT 风险 (1) 为零。该算法对 Cons_CoT 预言机进行 N = O(log(T/δ)) 次调用，每次在少于 n 个有标注样本的自助样本上。∎

6 将集成蒸馏为单个生成器

第 2 节通过聚合 ℱ 中 N = max{4, ⌈log₂(2T/δ)⌉} 个生成器的集成，实现了定理 1 的最优且与 T 无关的样本复杂度。虽然该集成训练高效，但它必须存储所有 N 个生成器并在生成的每一步评估每个生成器，将每个词元的计算成本和内存乘以 N。当生成器是前沿规模的语言模型时，这变得代价高昂。当前前沿的开放权重模型有数千亿到数万亿参数 [31; 20; 41]，因此单个副本需要数 TB 内存来存储，并且必须分片到许多 GPU 上运行。此外，集成大小 N 随 CoT 长度 T 增长，而 T 在实践中很大且增长迅速。上下文窗口现在达到数百万词元 [10]，推理轨迹的长度估计每年增长约 5 倍 [26]。

我们证明该集成可以在训练后仅使用无标注提示蒸馏为类 ℱ 中的单个生成器。该过程抽取 n_u 个新的无标注提示，用多数投票集成生成的思维链轨迹标注它们，并通过经验风险最小化将 ℱ 中的单个生成器拟合到这些轨迹。这是序列级蒸馏 [42] 的一个实例。蒸馏是将大模型或集成压缩为较小模型的标准技术 [16; 36]，现在广泛用于语言模型训练中，其中较小的模型在大型推理模型生成的思维链上训练 [57; 19 等]。使用 n_u ≥ n log(nT) 个无标注提示（比思维链演示便宜得多），蒸馏后的生成器保持定理 1 的 O((d_G + log(1/δ))/n) CoT 风险。

设定。 设 ĥ = MAJ(f̂{S'_1}, …, f̂{S'N}) 是第 2 节返回的多数投票集成。设 P_X 表示 Σ × Σ^T 上可由 f ∈ ℱ 实现的分布 P 的提示边缘分布。蒸馏使用 n_u 个新提示 x'_1, …, x'{n_u} ~ P_X，独立于 ĥ 抽取，其目标思维链未被观察。相反，每个提示由 ĥ 标注，ĥ 充当教师，用其自己的思维链 y'i ≔ ĥ^(1:T)(x'_i) 标注每个提示。这给出教师标注的样本 S̄ = ((x'_i, y'_i)){i=1}^{n_u}，从 x ~ P_X 的 的分布 P_ĥ 中独立同分布抽取。

由于多数投票集成 ĥ 不必在 ℱ 中，教师标注的样本 S̄ 可能不可由 ℱ 实现。因此，我们假设 Erm_CoT 预言机而不是一致性预言机 Cons_CoT，它返回 ℱ 中最小化经验 CoT 风险的生成器。蒸馏过程通过在 S̄ 上运行 Erm_CoT 产生学生 f̄：

f̄ = Erm_CoT(S̄) ∈ arg min_{f∈ℱ}(1/n_u)∑{i=1}^{n_u} 1{∃t ∈ [T]: f^(t)(x'_i) ≠ y'{i,t}}. (11)

以下命题表明学生 f̄（ℱ 中的单个生成器）保持定理 1 的速率。

命题 1（蒸馏为单个生成器）。 设 P 可由 f* ∈ ℱ 实现，ĥ 是满足 Pr_{(x,y)~P}[∃t ∈ [T]: ĥ^(t)(x) ≠ y_t] ≤ ε̂ 的任意生成器。设 f̄ 是在 n_u 个新提示 x'1, …, x'{n_u} ~ P_X 上训练的学生 (11)，这些提示独立于 ĥ 抽取并由 ĥ 标注。对每个 δ ∈ (0,1)，在提示上以至少 1−δ 的概率，

Pr_{(x,y)~P}[∃t ∈ [T]: f̄^(t)(x) ≠ y_t] ≤ 5ε̂ + (9/n_u)(d_G log(2n_uT + 1) + log(8/δ)). (12)

因此，如果 ĥ = MAJ(f̂{S'_1}, …, f̂{S'_N}) 是第 2 节在 S ~ P^n（n ≥ 4）上以置信度 δ 运行的输出，且 f̄ 在 n_u ≥ n log(nT) 个新提示上训练，则在 S、自助样本和无标注提示上以至少 1−2δ 的概率，我们有

Pr_{(x,y)~P}[∃t ∈ [T]: f̄^(t)(x) ≠ y_t] = O((d_G + log(1/δ))/n). (13)

蒸馏过程以无标注数据和训练后的一次性计算成本换取推理计算和内存的 N 倍减少。

命题 1 保持定理 1 的有标注样本复杂度，该复杂度是最优的且与 T 无关。在定理 1 中，对 T 的依赖仅出现在集成大小 N 中，在每次推理时付出。蒸馏将对 T 的依赖转移到无标注提示数 n_u ≥ n log(nT)，只需付出一次。虽然教师标注的分布 P_ĥ 不必可由 ℱ 实现，但它几乎是可实现的，因为 f* 和 ĥ 仅在 ĥ 出错的地方不一致，由定理 1，这至多以 O((d_G + log(1/δ))/n) 的概率发生。引理 7 的相对偏差不等式利用这一点给出 (12) 中的快速 1/n_u 速率，而最坏情况的不可知分析只会给出 1/√n_u。[63] 中出现了类似的通过蒸馏压缩的过程，其中由准确但昂贵的预测器标注的无标注输入用于训练来自更便宜类的预测器。他们的分析是不可知的，因为他们的学生类可能有近似误差，因此他们对无标注样本数的界按 1/ε² 而不是 1/ε 缩放。

6.1 命题 1 的证明

对于生成器 f 和 Σ* × Σ^T 上的分布 D，记 err_D(f) := Pr_{(x,y)~D}[∃t ∈ [T]: f^(t)(x) ≠ y_t] 为 f 在 D 下的 CoT 风险 (1)，err̂(f) := (1/n_u)∑{i=1}^{n_u} 1{∃t ∈ [T]: f^(t)(x'_i) ≠ y'{i,t}} 为其在教师标注样本 S̄ 上的经验 CoT 风险，学生在 (11) 中最小化它。证明依赖于以下关于二元函数类的相对偏差界，以增长函数的形式陈述。

引理 7（[12, 定理 5.1 和第 5.1.2 节]）。 设 ℒ 是集合 𝒵 上取值于 {0,1} 的函数类，增长函数为 Γ_ℒ(k) := max_{z₁,…,z_k∈𝒵}|{(ℓ(z₁), …, ℓ(z_k)) : ℓ ∈ ℒ}|。设 D 是 𝒵 上的分布，z₁, …, z_m ~ D^m。对每个 δ ∈ (0,1)，以至少 1−δ 的概率，每个 ℓ ∈ ℒ 满足

E_{z~D}[ℓ(z)] ≤ (2/m)∑_{i=1}^m ℓ(z_i) + 5·(log Γ_ℒ(2m) + log(4/δ))/m。

证明。 这是相对偏差不等式的标准推论，为完整性我们包含其简短推导。记 γ := (log Γ_ℒ(2m) + log(4/δ))/m，A := E_{z~D}[ℓ(z)] 和 B := (1/m)∑_{i=1}^m ℓ(z_i)。由 [12, 定理 5.1]，以至少 1−δ 的概率，每个 ℓ ∈ ℒ 满足 A ≤ B + 2√(Aγ)。对于 A, B, C ≥ 0，不等式 A ≤ B + C√A 蕴含 A ≤ B + C² + C√B，因此 A ≤ B + 4γ + 2√(Bγ) ≤ 2B + 5γ，其中最后一步使用 2√(Bγ) ≤ B + γ。∎

我们将引理 7 应用于 Σ* × Σ^T 上的 CoT 损失类 ℒ := {(x,y) ↦ 1{∃t ∈ [T]: f^(t)(x) ≠ y_t} : f ∈ ℱ}，其增长函数由 ℱ 的图维数控制。

引理 8。 对于图维数为 d_G 的任意自回归类 ℱ 和任意 k ≥ 1，Γ_ℒ(k) ≤ (kT+1)^{d_G}。

证明。 由于生成器在第一次错误之前遵循目标思维链，f^(t)(x) ≠ y_t（对某个 t ∈ [T]）当且仅当 f(x ∘ y_{1:t−1}) ≠ y_t（对某个 t ∈ [T]）。因此，如 [40, 定理 3.4] 中那样，ℒ 在_1), …, (x_k,y_k) 上实现的模式由 f 在 kT 个下一词元样本_i ∘ y_{i,1:t−1}, y_{i,t})（i ∈ [k]，t ∈ [T]）上的词元级错误模式决定。从第 4 节回忆 d_G 是词元级损失类 {(x',y') ↦ 1{f(x') ≠ y'} : f ∈ ℱ} 的 VC 维数，因此由 Sauer–Shelah 引理 [61]，它在这 kT 个样本上至多实现 ∑_{i=0}^{d_G} C(kT, i) ≤ (kT+1)^{d_G} 个模式。∎

命题 1 的证明。 学生在教师 ĥ 而不是 f 生成的思维链上训练，因此其训练分布 P_ĥ 不必可由 ℱ 实现。思想是 P_ĥ 仅在 ĥ 出错的提示上与 P 不同，因此 f 与 S̄ 几乎一致，经验 CoT 风险为 O(ε̂)。学生 f̄ 最小化经验 CoT 风险，因此它从 f* 继承了这个小经验风险，引理 7 以快速速率 1/n_u 将其转换为小风险。

我们首先关联两个分布。由于在 P 下 y = f^(1:T)(x)，在 P_ĥ 下 y = ĥ^(1:T)(x)，每个生成器 f 满足 err_P(f) = Pr_{x~P_X}[f^(1:T)(x) ≠ f^(1:T)(x)] 和 err_{P_ĥ}(f) = Pr_{x~P_X}[f^(1:T)(x) ≠ ĥ^(1:T)(x)]。两个事件仅在 ĥ^(1:T)(x) ≠ f*^(1:T)(x) 的提示上不同，因此

|err_P(f) − err_{P_ĥ}(f)| ≤ err_P(ĥ) ≤ ε̂，特别地 err_{P_ĥ}(f*) = err_P(ĥ) ≤ ε̂。 (14)

接下来，我们界定 f 的经验 CoT 风险。由于提示独立于 ĥ 抽取，在 ĥ 条件下，指标 1{∃t ∈ [T]: f^(t)(x'i) ≠ y'{i,t}}（i ∈ [n_u]）是均值为 p := err_{P_ĥ}(f*) ≤ ε̂ 的独立 Bernoulli 变量。由 Bernstein 不等式 [12, 第 5.1.2 节]，以至少 1−δ/2 的概率，

err̂(f*) ≤ p + √(2p log(2/δ)/n_u) + 2log(2/δ)/(3n_u) ≤ 2ε̂ + 2log(2/δ)/n_u，

其中最后一步对 L = log(2/δ)/n_u 使用 √(2pL) ≤ p + L/2。

我们现在将引理 7 应用于 ℒ，其中 D = P_ĥ、样本 S̄ 和置信度 δ/2。由引理 8，以至少 1−δ/2 的概率，每个 f ∈ ℱ 满足

err_{P_ĥ}(f) ≤ 2err̂(f) + 5γ，γ := (d_G log(2n_uT + 1) + log(8/δ))/n_u。

通过并集界，两个界以至少 1−δ 的概率成立。在该事件上，对 f̄ 应用 (14)，然后是最后一个显示式，然后是 err̂(f̄) ≤ err̂(f)（因为 f̄ 最小化 ℱ 上的经验 CoT 风险且 f ∈ ℱ 而成立），最后是 err̂(f*) 的界，我们得到

err_P(f̄) ≤ err_{P_ĥ}(f̄) + ε̂ ≤ 2err̂(f*) + 5γ + ε̂ ≤ 5ε̂ + 4log(2/δ)/n_u + 5γ ≤ 5ε̂ + (9/n_u)(d_G log(2n_uT + 1) + log(8/δ))，

这蕴含 (12)。

log(2n_uT + 1)/n_u ≤ log(3n_uT)/n_u ≤ (log 3 + log(nT) + log log(nT))/(n log(nT)) ≤ 3/n，

且 log(8/δ)/n_u ≤ log(8/δ)/n，因此 (12) 中的第二项是 O((d_G + log(1/δ))/n)。∎
