摘要

通用机器人策略的真实世界后训练面临两大挑战：部分可观测性使动作选择产生歧义，而离线后训练方法会延迟来自部署经验的反馈。我们提出价值即记忆，这是一个通过价值缓存与在线真实世界强化学习（RL）来应对这些挑战的框架。价值缓存以近期价值预测作为任务进度记忆来约束动作，而在线更新通过结合离线演示、离策略干预和同策略 rollout，实现样本高效的适应与及时的策略改进。由此，VaM 从离线 RL 预热过渡到使用稀疏奖励的在线自主学习。在涉及可变形物体与富接触操作的长时程任务上，VaM 借助价值缓存取得 29.4% 的平均绝对成功率提升，而相比匹配预算的离线训练，在线自主学习带来 32.8% 的提升。在相同梯度步预算下，所评估的在线调度执行多达 8 倍的策略迭代，并且通过数据收集与训练并行，使每梯度步的记录时间降低超过 2 倍。

1 引言

真实世界强化学习（RL）使通用机器人策略能够从物理交互中学习并在部署任务上持续改进（Chen 等，2025b；Physical Intelligence 等，2025）。策略从离线专家演示初始化，旨在最大化累积任务奖励（Luo 等，2024；Frans 等，2025），并可在部署期间选择性地从人类干预数据中学习（Luo 等，2025a；Wang 等，2026）。然而，当前的真实世界 RL 方法在数据复用和策略更新频率方面存在局限。同策略更新主要使用新采集的 rollout，限制了历史经验的复用（Chen 等，2025a）。迭代式离线 RL 将数据收集与优化分离，延迟了来自新遇到状态的反馈（Physical Intelligence 等，2025）。此外，部分可观测性带来另一项挑战。在观测历史有限的情况下，视觉上相似的状态可能需要不同的动作。与此同时，价值函数提供紧凑的任务进度估计，但通常仅作为过滤分数或优化权重（Physical Intelligence 等，2025；Frans 等，2025）。

因此我们提出问题：观测历史上的价值估计能否增强策略输入以缓解部分可观测性？以及一个在线 RL 系统如何利用学到的价值函数来融合离线演示、离策略数据和同策略 rollout，以高样本效率和快速闭环反馈实现策略与价值函数的联合适应？

为此，我们提出价值即记忆，一个具有两大关键特性的离线到在线 RL 系统。第一，我们提出价值缓存，它通过将近期价值预测历史作为额外的策略输入，将价值预测的用途扩展到训练监督之外。与视觉和本体感觉历史并列，该缓存指示估计的进度是在改善、停滞还是下降，帮助区分需要不同动作的状态。第二，VaM 采用混合训练数据方案，结合离线演示、离策略轨迹和当前同策略 rollout，实现策略与价值模型的样本高效联合适应。我们的训练流程从离线 RL 预热开始，经过人类辅助收集，最终过渡到使用稀疏奖励的自主学习。

在涉及可变形物体和富接触操作的真实世界任务上，VaM 相比无价值缓存的变体将平均绝对成功率提高 29.4%。在匹配的训练预算下，相比离线 RL 对应方法，其平均绝对成功率提升 32.8%。在相同梯度步预算下，所评估的在线调度执行多达 8 倍的策略迭代，并且通过数据收集与训练并行，使每梯度步的记录时间降低超过 2 倍。这些结果支持价值缓存用于缓解部分可观测性，以及我们采用混合训练数据方案的在线 RL 系统用于提升样本效率和策略迭代频率。

我们的贡献有两方面：

  1. 我们提出价值缓存，使策略以近期任务进度估计为条件，理论分析和真实世界消融实验支持其在部分可观测性下缓解动作歧义的作用。
  2. 我们开发了一个在线 RL 框架，复用离线演示、离策略轨迹和当前同策略 rollout 进行策略与价值联合适应，提升样本效率和策略迭代频率。

2 预备知识

2.1 问题形式化

我们将迭代式机器人后训练建模为马尔可夫决策过程（MDP）ℳ = (𝒮, 𝒜, P, r, γ)，其中 𝒮 和 𝒜 分别为状态空间和动作空间，P(s_{t+1} | s_t, a_t) 为转移核，r(s_t, a_t) 为奖励函数，γ ∈ [0,1) 为折扣因子。策略 π_θ(a_{t:t+H} | s_t) 具有参数 θ，预测动作序列 a_{t:t+H} = (a_t, …, a_{t+H−1})，其中 H 为预测时域。我们令 𝒟_offline = {τ_offline,n}{n=1}^N 表示 N 条成功的专家演示，π{θ^(0)} 表示由它们初始化的策略。后训练随后运行 M 轮。在每一轮 m ∈ {0,…,M−1}，我们部署 π_{θ^(m)} 以收集 rollout 和人类干预轨迹 𝒟_online^m，并使用累积数据得到 π_{θ^(m+1)}。在转移奖励 r_t = r(s_t, a_t) 下，我们的目标是最大化期望折扣累积奖励 E_{π_θ}[∑_{t=0}^∞ γ^t r_t]。

2.2 分布式价值学习

我们学习一个分布式价值函数来估计任务进度，并提供用于策略改进的标量优势。遵循分布式价值学习的已有文献（Bellemare 等，2017；Li 等，2025；Physical Intelligence 等，2025），参数为 ψ 的价值网络在 K ≥ 2 个均匀间隔的原子 𝒵 = {z_k}{k=1}^K ⊂ [0,1] 上预测类别分布 p_ψ(z_k | s)，其中 z_k = (k−1)/(K−1)，标量价值为 V_ψ(s) = ∑{k=1}^K z_k p_ψ(z_k | s)。我们用归一化的演示进度初始化价值专家，然后通过带稀疏结果奖励的时序差分（TD）学习对其进行适应。对于一条具有 T 个时间步的成功演示 τ_offline ∈ 𝒟_offline，初始化目标 q_t^init 是 𝒵 上以 t/T 为中心、方差为 σ_init^2 > 0 的归一化高斯标签。交叉熵（CE）初始化目标为

ℒ_init(ψ) = E_{τ_offline,t}[CE(q_t^init, p_ψ(·|s_t))]，CE(q,p) = −∑_{k=1}^K q_k log p_k. (1)

对于 TD 学习，只有成功的终止转移获得 +1 奖励，其余奖励为零。每次梯度步之后，目标参数 ψ̄ 按指数移动平均（EMA）更新：ψ̄ ← (1−β)ψ̄ + βψ，其中 β ∈ (0,1]。我们定义 R_{t:t+H} = ∑{h=0}^{H−1} γ^h r{t+h} 以及 H 步片段的终止指示符 d_t ∈ {0,1}。TD 目标 q_t^TD 将每个质量 p_ψ̄(z_k | s_{t+H}) 移动到 R_{t:t+H} + γ^H(1−d_t)z_k，然后线性投影到 𝒵 上（详细推导见附录 E）。我们用

ℒ_TD(ψ) = E_t[CE(q_t^TD, p_ψ(·|s_t))] (2)

训练价值专家。经 TD 适应的价值专家给出标量优势估计 Â_t = R_{t:t+H} + γ^H(1−d_t)V_ψ(s_{t+H}) − V_ψ(s_t)。

2.3 优势条件化策略学习

动作专家通过流匹配学习 π_θ，并带有可选的优势条件以区分动作质量。对于样本 (s_t, a_{t:t+H}) ∼ 𝒟_BC，其中 𝒟_BC 是行为克隆数据集，a_{t:t+H} 是 H 步动作序列，我们抽取具有单位协方差 I 的噪声 ε ∼ 𝒩(0,I) 和流时间步 λ ∼ 𝒰(0,1)，并设 a_λ = (1−λ)ε + λa_{t:t+H}（Black 等，2025）。速度场 v_θ 与策略共享参数 θ，并接受可选条件 c，其中 c = ∅ 表示行为克隆。在对采样数据、噪声和流时间步取期望后，流匹配目标及其行为克隆实例为

ℒ_FM(θ; c) = E[‖v_θ(a_λ, λ, s_t, c) − (a_{t:t+H} − ε)‖_2^2]，ℒ_BC(θ) = ℒ_FM(θ; ∅). (3)

对于优势条件化，当最优性概率随参考策略优势单调递增时，CFGRL 提供策略改进保证（Frans 等，2025；Physical Intelligence 等，2025）。对于第 m 轮收集的在线 rollout 数据 𝒟_online^m，我们以分位数参数 ρ ∈ (0,1) 设定阈值 ξ_m^ρ = Quantile_ρ({Â_i : (s_i, a_{i:i+H}) ∈ 𝒟_online^m})。二值优势条件为 o_t = 𝕀[Â_t ≥ ξ_m^ρ] ∈ {0,1}。训练期间，我们随机将 o_t 替换为 ∅，得到 o_t ∈ {∅, 0, 1}，并最小化 ℒ_FM(θ; o_t)。推理时，o_t = 1 请求高优势动作，权重为 w ≥ 1 的无分类器引导结合条件与无条件速度场（Ho 和 Salimans，2022）。

3.2 价值缓存与软混叠分析

3.2.1 价值缓存

价值缓存为动作专家提供明确的近期进度信息，同时不延迟其当前动作。在部署轮次 k，我们固定在前一轮训练结束时获得的价值快照 V_{ψ^(k−1)}，并使用其类别回报分布的期望作为标量进度信号。在时间步 t，我们用 h_t^π 表示动作专家的视觉观测历史，h_t^V 表示价值专家的视觉观测历史，s_t 表示动作专家的本体感觉观测历史。固定的价值快照预测 V̂{ψ^(k−1),t} = V{ψ^(k−1)}(h_t^V)。价值预测与动作生成异步运行，因此当动作专家生成 a_{t:t+H} 时，时间步 t 的价值预测尚不可用。因此，我们令 H_π ≥ 1 表示动作专家的观测时域，并定义价值缓存 c_t^(k−1) 和动作专家的完整观测 x_t^π 为

c_t^(k−1) = (V̂{ψ^(k−1),t−H_π}, …, V̂{ψ^(k−1),t−1}), (4)
x_t^π = (h_t^π, s_t, c_t^(k−1)).

该缓存概括了近期任务进度，并且当 H_π ≥ 2 时，还指示进度是在改善、停滞还是下降，帮助区分需要不同最优动作的视觉相似状态。

3.2.2 价值缓存为何能缓解软混叠

价值缓存针对软混叠问题，即视觉相似的状态需要不同的高优势动作分布。我们形式化了用价值缓存增强策略输入如何放松由表示引起的策略预测误差下界。我们考虑固定部署轮次 k 内以 i ∈ {1,2} 索引的两个状态。式 (4) 给出它们的价值缓存 c_i^(k−1) 和完整动作观测 x_i^π = (h_i^π, s_i, c_i^(k−1))。我们令 z_i^obs 表示视觉-本体感觉分量的表示。对于状态 i，μ_i 表示被赋予 2.3 节中定义的高优势标签的训练动作块分布。我们用 Wasserstein 距离 W_2 度量动作分布之间的差异。我们将完整动作观测 x_i^π 表示为 z_i^π = (z_i^obs, c_i^(k−1))。我们定义

ε_obs = ‖z_1^obs − z_2^obs‖_2, (5)
ε_π = ‖z_1^π − z_2^π‖_2 = √(ε_obs^2 + ‖c_1^{k−1} − c_2^{k−1}‖_2^2),
Δ_a = W_2(μ_1, μ_2).

当 ε_obs 很小而 Δ_a 很大时发生软混叠：即使期望动作不同，策略看到的输入却相似。我们假设策略相对于其输入表示是局部 L-Lipschitz 的：对于相关邻域中的任意两个表示 z 和 z′，有

W_2(π_θ(·|z, o_t=1), π_θ(·|z′, o_t=1)) ≤ L‖z − z′‖_2. (6)

定理 1（局部软混叠界）。对于表示 r ∈ {obs, π}，z_i^r 表示状态 i 的对应输入，ε_r 为式 (5) 中的成对距离。任何局部 L-Lipschitz 策略必然产生

max_{i∈{1,2}} W_2(π_θ(·|z_i^r, o_t=1), μ_i) ≥ ½(Δ_a − Lε_r)_+, (7)

其中 (x)_+ = max(x, 0)。特别地，只要 Δ_a > Lε_r，该下界严格为正，因此没有局部 L-Lipschitz 策略能同时精确匹配两个目标动作分布。若 Lε_obs < Δ_a ≤ Lε_π，则仅使用观测的策略无法在满足局部 Lipschitz 条件的同时匹配两个目标动作分布，而在 z_1^π 和 z_2^π 处的精确匹配并不违反该约束。形式化设定与证明见附录 F 和 G。由于 ε_π ≥ ε_obs，价值缓存可以通过使两个状态更易区分来削弱混叠下界。

3.3.2 训练阶段

离线演示初始化。 离线专家演示 𝒟_demo 使用 3.3.1 节中的初始化目标初始化 V_{ψ^(0)} 和 π_{θ^(0)}。

离线 RL 预热。 预热在在线 RL 开始之前使两个专家适应部署特定的状态。我们部署 (π_{θ^(0)}, V_{ψ^(0)}) 以收集用于训练价值专家的策略 rollout 和人类干预（HI）轨迹。遵循 GR-RL 的失败前缀增强（Li 等，2025），我们从 rollout 起点到每次人类接管处构造前缀。每个前缀以零奖励和 d_t = 1 结束，为卡住或重试阶段提供失败监督。完整 rollout 保留其结果奖励，并跨接管进行自举以保留恢复信息。得益于分布式价值模型，我们可以为共享样本表示前缀与完整 rollout TD 目标的混合。我们对价值训练轨迹进行时间下采样，以便在固定更新预算内更多次遍历它们。我们从 𝒟_demo 和处理后的预热 rollout 数据中采样以更新价值专家，得到 V_{ψ_warm}。然后我们用 V_{ψ_warm} 的优势标注预热轨迹，并在 𝒟_demo 和这些标注轨迹上训练动作专家以得到 θ_warm。

在线 DAgger。 在线 DAgger 使两个专家共同适应当前部署分布，同时人类纠正继续监督恢复行为。以 θ^(k) 表示第 k 轮策略参数，我们从 (π_{θ^(0)}, V_{ψ^(0)}) = (π_{θ_warm}, V_{ψ_warm}) 初始化在线轮次。在每轮 k，我们启用人类干预部署 π_{θ^(k−1)}，并用 V_{ψ^(k−1)} 标注当前 rollout。我们在当前 rollout 和由 𝒟_demo、预热数据及早期在线 rollout 组成的回放数据上训练价值专家。我们在 𝒟_demo、历史人类控制片段和标注后的当前 rollout 上训练动作专家。随后价值专家和动作专家同步更新，当前轨迹被并入下一轮的历史缓冲区。

从经验中学习。 LfE 使用来自自主 rollout 的稀疏终止奖励继续在线改进，不再收集新的人类纠正。我们对用于价值训练的完整 rollout 进行下采样，并将历史干预缓冲区固定为 LfE 之前收集的干预。数据混合、用 V_{ψ^(k−1)} 标注以及专家同步更新遵循在线 DAgger 流程。

3.4 实现细节

动作专家继承了 π_0.5 的完整架构和预训练参数，包括其 PaliGemma-2B 视觉-语言主干和独立的 3 亿参数动作生成 transformer（Black 等，2025）。价值专家将原 π_0.5 的 3 亿参数动作生成 transformer 重新用作其视觉-语言主干。遵循多尺度具身记忆（MEM）（Torne 等，2026），动作专家和价值专家使用时空注意力编码各自的图像历史 h_t^π 和 h_t^V，两者均终止于观测时间步 t。动作专家用门控循环单元（GRU）编码过去的价值预测和本体感觉状态，并将其最终隐藏状态附加在视觉 token 之后。为预测类别型任务进度，我们在时空历史处理之后，向价值主干输入序列的末尾附加一个可学习的读出 token。线性头将读出 token 的输出表示映射为 K 个 logits，softmax 生成第 2 节中固定支撑上的类别价值分布。关键超参数的具体取值见附录 B.5。

5 相关工作

5.1 通用机器人策略的后训练

以策略为中心的后训练通过残差更新或针对一致性策略、扩散策略和流策略定制的 RL 目标来适应通用机器人策略（Xiao 等，2026；Chen 等，2025b；Li 等，2026；Chen 等，2025a）。基于似然、分层和隐空间的形式化支持生成式策略的优化（Ren 等，2025；Lei 等，2026；Wagenmaker 等，2025；Li 等，2025；Chen 等，2025a），而世界模型通过提供想象或合成经验来减少物理交互（Yang 等，2026；Zhu 等，2026；GigaBrain Team 等，2026）。为了从机器人自身经验中学习，一些先前方法学习额外的价值函数来过滤次优片段。通用奖励和评论家模型从机器人轨迹或视觉-语言监督中学习可迁移的评估（Liang 等，2026；Tan 等，2026；Zhai 等，2026），而面向优势的方法从演示和轨迹中的时序关系推导相对进度（Liu 等，2026；Yu 等，2026a；Zhang 等，2025）。RECAP 结合演示、策略 rollout 和人类干预来估计价值并为通过 CFGRL 进行优势条件策略提取标注数据（Physical Intelligence 等，2025；Frans 等，2025）。然而，从固定或定期刷新的数据集中学习价值估计，可能使评论家在更新之间部署分布变化时变得过时。此外，当价值预测仅作为奖励、过滤分数、标注或优化权重时，部署的策略并不会将它们作为输入接收。缺少这种明确的任务进度信息，视觉相似的观测可能掩盖执行的不同阶段，使策略对任务进度只有部分可观测性。VaM 则从在线 rollout 和人类干预中持续更新价值，并将其预测同时用作策略学习监督和显式策略输入。

5.2 人在回路的在线适应

人类操作员在部署期间进行干预，以纠正不确定或失败的策略行为（Luo 等，2025b；Deng 等，2026；Hu 等，2026）。HG-DAgger 和 Sirius 等方法将干预用作策略改进的纠正性演示（Kelly 等，2019；Liu 等，2023）。Fleet-DAgger、SiriusFleet 和 ARMADA 通过分配操作员或仅在必要时请求帮助来扩展干预收集（Hoque 等，2023；Liu 等，2025；Yu 等，2026b），而最近的机群级系统在多机器人和多任务上结合在线机器人 rollout 与人类纠正（Pan 等，2026；Wang 等，2026）。VaM 进一步使用干预轨迹更新价值模型，该模型引导策略学习并约束策略输入。

5.3 离线到在线强化学习

离线到在线 RL 通过在线训练期间保留或回放离线数据来稳定策略改进（Ball 等，2023；Peng 等，2019；Nair 等，2020；Li 等，2025）。RLPD 混合离线和在线样本，Cal-QL 为在线微调校准离线价值函数，Warm-Start RL 用保留预训练行为的回放数据初始化在线学习（Ball 等，2023；Nakamoto 等，2023；Zhou 等，2025）。在真实世界机器人领域，SERL 和 HIL-SERL 将行为克隆初始化与离策略学习相结合用于物理操作（Luo 等，2024；Luo 等，2025a）。VaM 结合离线演示、历史离策略干预数据和当前同策略经验，实现样本高效的在线适应。

6 讨论与结论

尽管 VaM 在样本效率上优于先前方法并缓解了通用机器人策略的部分可观测性，但它存在若干局限，提示了未来工作的方向。首先，价值缓存依赖于紧密跟踪实际任务进度的价值函数，因此需要离线 RL 预热来实现稳定的在线训练。缓存历史由价值专家自身的预测组成，因此其作为任务进度记忆的用处取决于这些预测的质量。其次，我们的真实世界 RL 框架目前仅限于单机器人。我们的实验尚未确立当多台机器人贡献数据时该框架如何扩展。将 VaM 扩展到共享经验的机器人机群是进一步提升样本效率的有前景方向。

总之，我们提出了 VaM，一个将近期价值预测用作任务进度记忆，并结合离线演示、离策略轨迹和同策略 rollout 进行在线策略与价值适应的框架。价值缓存解决部分可观测性下的动作歧义，而离线到在线 RL 流程支持从部署经验中持续学习。这些组件共同为通用机器人策略后训练提供了一种实用方法。

E.1 分布式 TD 目标

高斯标签仅用于式 (1) 中的进度初始化。TD 学习则变换完整的目标网络分布，而不先取其期望。对于每个保留的 H 步元组，当片段到达任务结果或干预前缀的终止接管边界时 d_t = 1，否则 d_t = 0。在完整 rollout 中，人类接管不会终止自举，使随后的恢复能够贡献于目标。我们定义变换后的原子 y_{t,k} = R_{t:t+H} + γ^H(1−d_t)z_k 及其支撑截断位置 ỹ_{t,k} = min(1, max(0, y_{t,k}))。以原子间距 Δz = 1/(K−1) 和 (u)_+ = max(u, 0)，线性类别投影为

q_{t,i}^TD = ∑{k=1}^K p_ψ̄(z_k | s{t+H})(1 − |z_i − ỹ_{t,k}|/Δz)_+，i = 1, …, K. (8)

每个变换后的原子将其质量分配到两个相邻支撑原子之间，当位置重合时所有质量分配给一个原子。终止时，所有自举原子映射到累积奖励，与下一状态预测无关。标量优势使用相同的奖励和终止掩码，但使用在线价值网络 V_ψ。

E.2 预热价值数据构造

我们在在线 RL 之前部署 (π_{θ^(0)}, V_{ψ^(0)}) 以收集策略 rollout 和人类干预轨迹，记为 𝒟_warm^on = 𝒟_{π_{θ^(0)}}^rollout ∪ 𝒟_{π_{θ^(0)}}^HI，其中两个子集分别包含策略控制的 rollout 和人类控制的片段。对于一条具有 J 个人类干预片段的轨迹 τ_{0:T} ∈ 𝒟_warm^on，我们定位它们的起始索引 0 < t_0 < ⋯ < t_{J−1} < T，并构造前缀集合

𝒫(τ_{0:T}) = {τ_{0:t_j}}{j=0}^{J−1} ∪ {τ{0:T}}. (9)

GR-RL 在标注的重试关键帧处构造失败前缀，同时保留原始成功轨迹（Li 等，2025）。我们改用人类接管边界：每个前缀 τ_{0:t_j} 奖励为零并在 t_j 终止，而完整 rollout τ_{0:T} 保留其结果奖励并跨接管继续自举。这种增强在恢复结果之外提供不成功尝试的监督，使价值专家对重试和部分失败敏感。因此，共享观测在两种终止约定下可能接收不同的 TD 目标。类别预测器可以在交叉熵目标下表示这些目标的混合，包括多峰分布。其期望反映增强后的训练数据，而不仅仅是原始任务的不间断回报。时间下采样以整数步长 d ≥ 1 选择轨迹起始索引，同时保留每个 H 步奖励及其在 s_{t+H} 处的终止掩码自举。对于轨迹 τ_{0:L}，算子 DS_d 选择

DS_d(τ_{0:L}) = {(s_t, a_{t:t+H}, R_{t:t+H}, s_{t+H}, d_t) : t ∈ {0, d, 2d, …}, t+H ≤ L}. (10)

对于前缀集合，DS_d 应用于每个前缀，并将所得转移集合并。我们将用于价值学习的处理后预热 rollout 数据集构造为

𝒟̃warm^V = ⋃{τ∈𝒟_warm^on} ⋃_{τ′∈𝒫(τ)} DS_d(τ′). (11)

算法 D 指定了相应的预热和在线批来源、固定混合比例、标注快照和缓冲区更新。

E.3 在线数据来源

我们以 (π_{θ^(0)}, V_{ψ^(0)}) = (π_{θ_warm}, V_{ψ_warm}) 初始化在线轮次索引，并用 k ∈ {1,…,N_D} 索引 N_D 个在线 DAgger 轮次。离线来源是固定的演示数据集 𝒟_demo。同策略来源记为 𝒟_on^k，由启用人类干预部署 π_{θ^(k−1)} 收集的当前 rollout 组成。离策略来源包含第 k 轮之前收集的所有 rollout：

𝒟_off^k = 𝒟_warm^on ∪ ⋃_{i=1}^{k−1} 𝒟_on^i. (12)

我们用 HI(𝒟) 从轨迹集合中提取所有人类控制片段，得到历史纠正数据 𝒟_{HI,off}^k = HI(𝒟_off^k)。对于价值学习，离线和离策略来源构成回放数据集 𝒟_replay^k = 𝒟_demo ∪ 𝒟_off^k。我们使用干预前缀构造和时间下采样处理 𝒟_on^k，得到 𝒟̃_on^{V,k}。我们用 Annotate(𝒟; V_ψ) 将 V_ψ 产生的价值衍生优势条件附加到 𝒟 中的样本上。

附录 F 软混叠分析的形式化设定

我们假设动作序列位于欧氏积空间 𝒜^H 中，并用 𝒫_2(𝒜^H) 表示具有有限二阶矩的概率分布，即 ∫_{𝒜^H}‖a‖_2^2 dμ(a) < ∞。该条件仅确保 Wasserstein 距离 W_2 有限。我们令 h_t 表示时间步 t 的完整交互历史。对于每个被分析的状态 i ∈ {1,2}，ℋ_i 表示其在 2.3 节定义的标记为 o_t = 1 的样本中对应的完整历史局部集合。它们的目标动作块分布为

μ_i = ℒ(a_{t:t+H} | h_t ∈ ℋ_i, o_t = 1) ∈ 𝒫_2(𝒜^H)，i ∈ {1,2}, (13)

其中 ℒ 表示有效策略训练分布下的概率律。对于表示类型 r ∈ {obs, π}，我们使用 3.2.2 节引入的表示 z_i^r 及其在式 (5) 中的对应距离 ε_r。我们定义 q_i^r = π_θ(·|z_i^r, o_t = 1) 和相应的策略预测误差 e_i^r = W_2(q_i^r, μ_i)。定理 1 中使用的局部 L-Lipschitz 假设为

W_2(q_1^r, q_2^r) ≤ Lε_r. (14)

若两个状态具有相对权重 α 和 1−α（α ∈ (0,1)），同样的论证还给出频率加权界

α(e_1^r)^2 + (1−α)(e_2^r)^2 ≥ α(1−α)(Δ_a − Lε_r)_+^2. (15)

附录 G 软混叠界的证明

定理 1 的证明。 我们固定 r ∈ {obs, π}，为便于阅读省略 q_i^r 和 e_i^r 的上标 r。由 Wasserstein 三角不等式和局部 Lipschitz 假设，

Δ_a ≤ W_2(μ_1, q_1) + W_2(q_1, q_2) + W_2(q_2, μ_2) ≤ e_1 + Lε_r + e_2. (16)

因此 e_1 + e_2 ≥ (Δ_a − Lε_r)_+。由于 max_i e_i ≥ (e_1 + e_2)/2，这证明了式 (7)。在两个输入上精确匹配要求 q_i = μ_i，因此由式 (14) 要求 Δ_a ≤ Lε_r。于是，Lε_obs < Δ_a 排除了仅观测的精确匹配，而 Δ_a ≤ Lε_π 使 z_1^π 和 z_2^π 处的精确匹配与局部 Lipschitz 约束相容。该相容性陈述并不断言某个特定参数化策略在优化后一定能达到这些目标。为完整起见，我们证明式 (15) 中的频率加权扩展。对于 e_1, e_2 ≥ 0，直接展开得

αe_1^2 + (1−α)e_2^2 − α(1−α)(e_1 + e_2)^2 = (αe_1 − (1−α)e_2)^2 ≥ 0. (17)

将该不等式与 e_1 + e_2 ≥ (Δ_a − Lε_r)_+ 结合即证明加权界。∎
