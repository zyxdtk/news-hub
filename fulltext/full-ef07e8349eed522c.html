前沿红队：利用Claude发现密码学弱点

📅 2026-07-28 📄 Anthropic 🔗 原文链接

原标题：Frontier Red Team Discovering cryptographic weaknesses with Claude

中文摘要： Anthropic 研究人员利用 Claude Mythos Preview 发现了两种密码学攻击方法。第一种显著削弱了后量子数字签名方案 HAWK，将其有效密钥强度减半；第二种改进了对轮数缩减版 AES 的攻击，速度提升200-800倍。此外还发现了针对 LEA 和 Serpent-128 等密码的攻击。这些发现虽暂不影响生产系统，但展示了 AI 在密码学研究中的巨大潜力，预示着密码学审查方式的变革。

摘要

借助 Claude Mythos Preview，Anthropic 的研究人员发现了攻击密码学算法（用于保护在线数据隐私的数学方法）的改进方法。第一个攻击显著削弱了 HAWK——一种为后量子世界构建的数字签名方案。第二个攻击则找到了一种攻击轮数缩减版 AES（最广泛使用的对称密码）的新方法。这些是重大的研究进展，但目前不会影响任何生产系统。本文将详细描述这两项发现，并讨论在强大 AI 模型时代密码学所面临的启示。

引言

当我们发布 Claude Mythos Preview 时，我们展示了它能够自主发现并利用我们指向的几乎所有软件中的漏洞。这包括几个主要的密码学库——用于加密数据的共享代码集合。

Claude 在这些密码学库¹中发现的漏洞是由于算法的_实现_不正确——也就是说，程序员在代码中使用算法时出现的错误，为攻击者破解加密创造了机会。

现在，我们发现 Claude 能够在_算法本身_中发现数学缺陷。

密码学算法是数字安全的基础构建模块。例如，当你访问像 https://www.anthropic.com 这样的网页时，你的浏览器会使用一种称为_数字签名方案_的算法来验证它正在与一个真实的网站通信。随后，你与网站之间的流量会使用_对称密码_进行加密——这些密码允许共享相同密钥的各方之间进行安全的数据传输。如果没有这样安全的密码学系统，你的电子邮件、在线银行和其他互联网使用将向网络犯罪分子敞开，他们可以拦截或修改你的通信。这些广泛使用的密码学系统中的缺陷可能使数十亿用户的数据面临风险。

我们在本文中描述的第一个结果，是借助 Claude Mythos Preview 发现的，针对一种名为 HAWK 的数字签名方案的改进攻击。2022年，美国政府 国家标准与技术研究院（NIST）发布了 征集，寻求即使在量子计算机面前也能保持安全的额外密码学系统（量子计算机如果被开发出来，可能会破解当今使用的大多数现有签名方案）。HAWK 是此次征集的第三轮候选方案之一。尽管 HAWK 在两年内经受了两轮专家人类评审，但 Mythos 仅用了60小时的工作就改进了已知最佳攻击——实际上将其密钥强度削减了一半。

第二个结果涉及 高级加密标准（AES），这是一种由 NIST 于2001年采用的对称密码，其受到的审查几乎超过任何其他加密算法。为了更好地理解 AES 的鲁棒性，密码学研究中经常研究该算法的较弱变体；Mythos 找到了破解其中一种较弱版本的方法，并消除了攻击者需要做出的一个猜测，将之前最佳攻击的速度提高了200-800倍。

需要明确的是，这两个结果都不会对当今的计算机系统产生实际影响；没有任何生产软件需要因此做出改变。HAWK 只是一个_候选_签名方案，尚未部署；²我们的第二个攻击针对的是缩减版 AES，并不会破解完整密码。³

尽管如此，这两个结果都展示了前沿 AI 模型在帮助发现重要密码学算法缺陷方面的潜力——无论是在实际部署之前还是之后。这正是密码学研究按预期运作的方式：对算法进行压力测试以建立信任，并最终使系统更加安全。

Mythos Preview 取得这些结果的过程主要是自主的，且大部分无需人工干预。在一周的时间里，一位 Anthropic 研究员与 Claude 合作开发了 HAWK 攻击，另一位研究员构建了一个脚手架⁴，使 Claude 能够完全自主地发现 AES 攻击。⁵ 每个结果的开发成本约为100,000美元的 API 费用。在看到这些结果后，我们扩大了搜索范围，并开始发现其他攻击。我们在下文讨论了其中一些后续工作。

为了使其他人更容易地继续研究 LLM 的密码分析能力，我们与苏黎世联邦理工学院、特拉维夫大学和海法大学的学者合作，构建了 CryptanalysisBench，这是一个将许多密码学密码打包在一起的基准测试，使其他人能够轻松评估 LLM 在这一重要主题上的能力。

在整个研究过程中，我们遵循了负责任的披露程序，并与学者协商以确认我们发现的有效性。我们还向美国政府及行业合作伙伴分享了预印本，并就这项研究的意义进行了讨论。关于我们的 HAWK 发现，我们在6月与 HAWK 的作者分享了我们的攻击，并在我们发布结果的同时协调向 NIST 公共邮件列表进行了披露。

在本文的其余部分，我们将以更详细的技术细节总结这两项发现，并简要描述我们的一些其他近期密码学成果。两项主要发现的完整描述在两篇新论文中提供，我们希望在不久的将来发布其他发现的细节。

针对 HAWK 的改进密钥恢复攻击

在与 Mythos Preview 的合作中，一位 Anthropic 研究员开发了对 HAWK 后量子数字签名方案的攻击。该攻击大幅缩短了破解该签名方案所需的时间——更技术性地说，它将"有效密钥大小"减少了二分之一。在 我们的论文 中，我们提供了结果的完整技术细节，包括展示攻击运行的 演示代码。

HAWK 是 NIST 额外数字签名 征集的剩余第三轮候选方案之一。该竞赛是近十年来标准化新 后量子密码学（PQC）方案的努力的一部分。随着构建密码学相关量子计算机的前景 缩短 并威胁到 RSA 或 ECDSA 等经典密码学，这一标准化努力正变得至关重要。

HAWK 的安全性基于一个称为格同构问题的数学问题的困难性。Mythos 的攻击通过在 HAWK 使用的格中找到一个特定的、此前未被利用的对称性（称为非平凡自同构）来工作。先前的工作 证明了高效找到这样的自同构将允许攻击，但没有回答这种自同构在 HAWK 使用的格中是否可访问。Mythos 发现的自同构允许更快的枚举攻击，虽然仍然是指数级的，但意味着需要将 HAWK 密钥大小翻倍才能达到相同的安全级别。不幸的是，将 HAWK 的密钥大小翻倍会消除使该方案（就目前而言）成为有吸引力的 PQC 签名候选者的许多原因。

发现过程

为了找到攻击，Claude Mythos Preview 在一个智能体框架中半自主地工作，偶尔接受人类指导和非技术性方向指引。Mythos 在进行了广泛的文献综述以了解最新技术状态后，通过大量的数学推理和计算实验找到了攻击。找到攻击后，Mythos 实现了一个端到端的验证流程，以说服自己和人类操作者攻击的正确性。

在这个实验中，我们使用了一个类似 Claude Code 的框架，支持多个工作代理在沙盒环境中协同工作，可以访问 Python 和 Sage 等计算工具，以及已发表的密码学文献。人类操作者具有理论计算机科学背景，但不是基于格的密码学专家。在大多数情况下，Mythos 代理独立工作，人类输入仅限于项目管理，例如建议 Mythos 如何跟踪想法或使用哪些库进行计算验证。

多代理工作流带来了有趣的动态。例如，产生这次攻击的关键想法是由一对协同工作的工作者发现的。两人都开始研究这个想法；第一个工作者过早地认为该想法不可行而拒绝了它，但第二个工作者找到了充分利用它的方法。这对代理不断交换消息，最终双方都同意他们找到了一个有效的攻击。

发现、开发和验证攻击总共花了大约60小时。我们估计完整的攻击发现过程大约花费了100,000美元的 API 费用。

影响

Mythos 发现的直接影响是，HAWK 提案中建议的密钥大小比最初建议的要弱得多。例如，针对小型 HAWK-256 的完整密钥恢复攻击的预期成本被认为是 2⁶⁴，但 Mythos 证明是 2³⁸。对于更大的密钥，HAWK 因此仍然不切实际地难以攻击。也就是说：这种攻击是比已知方法更快的针对 HAWK 的指数时间攻击，而不是在多项式时间内运行的。它特定于 HAWK，不影响其他 NIST 后量子签名候选方案或基于格的密码学总体。

NIST 提案公开共享，旨在让广泛的受众在部署使用之前审查它们以发现缺陷。在过程后期发现关键缺陷并非闻所未闻：在 NIST 标准化 ML-KEM 和 ML-DSA 期间，几个竞争提案被证明是不安全的。一个候选方案 SIKE 被发现 在一台笔记本电脑上一小时内完全被破解。

我们相信，用 AI 审查像 HAWK 这样的规范将成为开发新型密码学标准的强大工具。我们期望配备高能力模型的密码学设计者能持续改进保护所有用户互联网安全的标准。在更远的未来，我们希望 AI 将在设计下一代更强大、更具弹性的密码学方案中发挥关键作用。

针对轮数缩减版 AES 的改进攻击

在我们的第二个结果中，Mythos Preview 改进了对 高级加密标准（AES）的一种更简单的"轮数缩减"变体的攻击，该标准于2001年作为 先前 NIST 竞赛 的一部分被创建。

AES 通过多次重复应用相同的_轮函数_来加密输入。AES-128，即我们攻击的特定密码，有10轮。我们的攻击仅适用于完整10轮中7轮的修改版本。学术界经常研究轮数缩减密码，以深入了解未来可能推广到完整密码的攻击技术，并通过研究更简单的子问题来帮助估计完整密码的安全级别。

该攻击在_选择明文威胁模型_下运行，这是研究像 AES 这样的密码时使用的最常见假设。在此威胁模型下，我们假设攻击者能够请求防御者使用固定的、未知的密钥加密任意输入，然后可以看到相应的输出。攻击者可以反复发出这些加密请求，并且可以发出许多这样的请求。我们在此基础上构建的先前工作假设攻击者可以请求加密 2¹⁰⁵ 个选择明文。因此，这种攻击完全不切实际，但在这些假设下量化了针对 AES 的攻击成本。

Mythos 通过开发一种更复杂的指纹算法（它称之为 Möbius Bridge，即莫比乌斯桥）改进了先前最强的中间相遇攻击。指纹算法的目标是增加成功进行表查找的潜在次数。先前工作攻击的一个阶段必须枚举256个不同的值，然后在预计算表中查找它们。Mythos 开发了一种对此猜测不变的指纹，直接将所需工作量减少了256倍。但这有一个代价：计算变换在计算上更加昂贵；为了解决这个问题，Mythos 发现了其他几种优化技术，使攻击速度提高了200到800倍，具体取决于用于测量运行时的确切技术。

我们的 技术论文 包含了攻击方法的完整细节及其正确性和运行时分析。与 Mythos 花费一周时间构思想法相比，人类研究人员的大部分时间都花在验证其声明的正确性上（尽管需要注意的是，研究人员并非密码学专家）。

发现

Mythos Preview 几乎完全自主地发现了这一结果。Anthropic 的一位研究员构建了一个脚手架，使 Claude 能够提出假设、运行实验来实验性地验证或反驳这些假设，然后要求 Claude 设计一种改进最佳 AES 密码分析的攻击。

最初，Claude 不愿参与这个问题，因为它声称改进 AES 的密码分析是不可能的。我们第一次运行的结果以 Claude 写下如下消息告终：

如果你想要不同的结果，目标必须改变……AES-128 r5/r6 确实很难

或者：

在 AES-128 r5/r6/r7 上它什么也没找到，因为没有什么容易找到的东西；这是现存研究最多的分组密码。

为了解决这个问题，我们给 Claude 写了一条消息（以下我们发布了我们研究员使用的真实提示，包括拼写和语法错误）："模型倾向于认为这是不可能解决的，所以它们不尝试，它们[原文如此]需要大量的提示。" 作为对这条消息的回应，Claude 用改进的设置重写了代理框架，告诉它搜索真正新颖的想法。这很有效，Claude 发现了一些有助于改进6轮 AES 密码分析的新想法。

然后我们问 Claude "为什么不做 aes-128 r7？整个意义在于找到比现有方法更好的东西。" 在接下来的三天里，Claude 在处理问题时自主产生了数亿个 token；我们只给了它三个实质性提示：

  1. 在第一条消息几个小时后，我们发现 Claude 仍在搜索简单的攻击，于是发送了一条消息："不，目标是我们拥有高度智能[原文如此]的模型，与优秀的顶级研究员一样好，我们想找到新的攻击"；
  2. 第二天早上，Claude 想尝试将目标更改为不同的密码；我们提醒模型："不，我们不想更改目标 [...] 再次[原文如此]我们需要找到值得[原文如此]发表的东西"；
  3. 那天晚上，我们发送了最后一条鼓励性的消息："再次，我们不是在寻找低垂的果实，我们想要适当的研究来找到真正[原文如此]困难的发现。"

三天后，Mythos 发现了莫比乌斯桥的想法，从而产生了改进的攻击。又过了几天，在 Claude 总共输出了十亿个输出 token 之后，它将攻击完善为我们论文中描述的版本。

Anthropic 的研究人员随后花了数百小时学习足够的密码学知识来验证模型的声明，并准备 研究论文 本身，我们随此博客文章一同发布。

除了研究论文外，我们还发布了 一份包含 Claude 思维链的文档，记录了其在发现关键算法洞察过程中的思考。⁶ 在这次会话中，Claude 首先回顾了先前代理发现的内容，阅读了各种批评，然后转向提出各种新的变换；在提出并否定了几个想法后，它想出了莫比乌斯变换的关键想法。然后 Claude 在数学和计算上验证了这个想法，并写了一份报告，未来的代理随后利用该报告开发了构成其论文的其余想法。

进一步工作

还有更多密码学研究可以利用语言模型来开展。但我们正在达到自身知识的极限，在过去几个月中，我们绝大部分时间都花在验证 Claude 结果的正确性上。HAWK 攻击可以端到端实现，因此更容易验证。但是，虽然 Mythos 仅用一周时间就自主发现了对 AES 的改进攻击，两位研究员却花了近一个月才确信它发现的方法是正确的。

尽管如此，我们继续使用 Claude 进行了许多其他密码学研究的初步实验。例如，轻量级加密算法（LEA）是一种为低功耗、资源受限环境设计的高效密码，已被编入 ISO/IEC 29192-2:2019 等国际标准。这种密码与 AES 一样是分组密码；完整的24轮密码已经抵抗了全轮密码分析，即使在评估轮数缩减变体时也保持强健。目前，对13轮 LEA 的最佳密码分析 需要 2⁹⁸ 个明文对和 2⁸⁶ 的工作量。

Mythos Preview 开发了一种实际攻击，可以在不到 2³⁰ 个加密明文下恢复13轮 LEA 密钥，并在现代台式计算机上不到一小时内运行完成。同样，这种攻击不适用于24轮密码，因此没有直接的实际影响。因为这种攻击实际上是端到端运行的（就像 HAWK 攻击一样），我们对其正确性更有信心：我们可以选择一个随机密钥，并验证此攻击在几小时内就能恢复它。Mythos 最近才发现这种攻击，我们仍有更多工作要做以理解完整结果（例如，所需明文对数量的确切边界、某些密钥如何更难恢复，以及它如何扩展到14轮）。经过更多调查后，我们计划公开完整结果。

Mythos Preview 还发现了另一种针对 Serpent-128 密码6轮的实际完整密钥恢复攻击（这是一种32轮密码——同样限制了此攻击的影响），扩展了当前 已发表的工作，后者需要超过 2⁷⁰ 个明文对和 2⁹⁰ 次解密。我们还发现了对 Salsa20 流密码、Poseidon 哈希函数和 SHA-1 哈希函数攻击的额外、相当有限的改进（提供 <10 倍的增益）。这些攻击目前不那么有效——但通过进一步的工作，我们希望既能改进上述结果，又能开发针对其他密码的新攻击，将其测试到极限。

此外，我们计划继续使用 CryptanalysisBench 进行实验，以跟踪前沿 LLM 能力随时间的演变。我们认为跟踪语言模型在各领域的能力很重要，并期望随着模型变得更强大，越来越依赖像这样的挑战性基准测试。

结论

这并不是语言模型第一次执行研究级别的数学。就在过去几个月中，Google 的研究人员使用 Gemini 解决了几个开放的 Erdős 问题，OpenAI 的研究人员使用 GPT 解决了单位距离猜想（一个特别具有挑战性的 Erdős 问题），本月早些时候 我们宣布 Claude Fable 5 解决了 雅可比猜想。我们在这里的结果——Claude 能够以顶级专家的水平执行密码学研究——表明这些同样的能力在密码学领域也有应用，因此可能很快产生更实际的后果。

网络安全社区现在正在应对这样一个事实：语言模型能够发现 如此多的漏洞，以至于标准的人类流程（如漏洞分类、验证和修复）难以跟上。我们预测，学术密码学研究很快也会出现同样的情况。随着语言模型越来越多地自主产生新颖的研究成果，人类研究人员可能会在研究和验证这些结果的技术有效性、新颖性和实用性方面遇到瓶颈。在接下来的几周里，我们将举办一次学术研讨会，与学术界的研究人员交流，讨论语言模型在安全和密码学研究中的角色。我们希望这一对话将在未来几个月在安全研究及其他领域继续下去。

我们的两个主要攻击都是_预期_的结果。在 HAWK 的情况下，NIST 标准化过程的目的就是在候选方案部署之前发现其弱点。在 AES 的情况下，我们的攻击延续了之前成功攻击轮数缩减变体的一系列工作。但我们不应假设语言模型的能力会停滞在这个水平。在短短一年内，语言模型已经从无法对最基本的密码进行密码分析，发展到能够发现那些尽管经过多年人类专家审查仍未被发现的密码学设计缺陷。保护现代系统的许多密码受到的审查少于它们应得的——它们可能仍然隐藏着 LLM 很快就能发现的重要弱点。我们将此视为扩大我们研究全球使用的长尾密码能力的机会，也是更深入研究最重要密码的能力的机会。事实上，正如我们上文提到的，我们已经开始了对其他方案的审计。

这两篇论文中描述的攻击是我们迄今为止发现的最强攻击。在经过一段与美国政府和行业领袖协商的时期后，我们分享了这些攻击。但随着我们开发出越来越强大的密码分析结果，如果语言模型在攻击_确实_具有即时现实影响的密码系统中发现了漏洞，研究人员应该如何应对，这是一个值得谨慎考虑的问题。我们相信，回答这个问题需要学术界、政府和行业的共同投入。我们希望我们在这里的工作能帮助启动这些对话。

密码学社区一直受益于对抗性审查：密码被提出、审查和修订，直到社区对其安全性感到满意。从长远来看，我们期望语言模型将在这一过程中发挥重要作用，带来更严格的审查、更安全的算法——并最终为世界带来更好的安全。
