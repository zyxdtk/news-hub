SpaceXAI 发布 Grok 4.5，马...

📅 2026-07-08 📄 TechCrunch AI 🔗 原文链接

原标题：SpaceXAI releases Grok 4.5, which Elon describes as an ‘Opus-class model’

中文摘要： SpaceXAI 发布了上市以来首个新模型 Grok 4.5，马斯克称其为"Opus 级别模型"，具备更快速度、更高 token 效率和更低成本。该模型定价为每百万输入 token 2 美元、输出 token 6 美元，远低于 Anthropic 的 Opus 4.7 和 OpenAI 的顶级模型。本周 OpenAI 也将发布 GPT 5.6，AI 模型竞争加剧。

SpaceXAI 发布了其最新模型 Grok 4.5——这是该公司几周前上市以来的首个新模型。

在[周三发布的一篇博客文章](https://x.ai/news/grok-4-5)中，SpaceXAI 将其新发布的模型描述为一款"主力工具"，能够处理 AI 行业一直试图自动化的所有典型任务：编程和应用构建、办公和文秘工作、研究、写作以及其他形式的常规知识工作。

据说 Grok 还能以更低的成本完成所有这些工作，因为 SpaceXAI 表示其模型的"token 效率是其他领先模型的两倍"。如果这一效率在实际应用中得到验证，这将是 SpaceXAI 的一大优势，因为 token 成本一直是 AI 用户日益关注的问题。

该公司周三发布了基准测试指标，似乎显示 Grok 与 SpaceXAI 竞争对手的其他顶级模型具有竞争力，尽管略逊于同类最佳： ![Image 1](https://techcrunch.com/wp-content/uploads/2026/07/Screenshot-2026-07-08-at-12.08.30-PM.png?w=680) **图片来源：**SpaceXAI

在其社交媒体平台 X（SpaceXAI 的子公司）上发布的[一篇帖子](https://x.com/elonmusk/status/2074740539874775163?s=20)中，创始人埃隆·马斯克将该模型与 Opus 进行了比较，Opus 是 Anthropic 专为高强度和复杂任务设计的大语言模型。

马斯克在 X 上的帖子中写道："基于我们 Beta 测试计划中客户的强烈正面反馈，@SpaceXAI 将于明天向公众开放 Grok 4.5。它是一款 Opus 级别的模型，但速度更快、token 效率更高、成本更低。"

[马斯克随后补充道](https://x.com/elonmusk/status/2074911038286295049?s=20)："我们的内部评估是，Grok 4.5 大致可与 Opus 4.7 相媲美，但速度要快得多。能力、更快速度和更低成本的结合使其具有竞争力。"

SpaceXAI 表示，其新模型的成本为每百万输入 token 2 美元，每百万输出 token 6 美元。如果 Grok 的能力与 SpaceXAI 的宣传相符，这将非常有竞争力。

相比之下，[Opus 4.7](https://www.finout.io/blog/claude-opus-4.7-pricing-the-real-cost-story-behind-the-unchanged-price-tag) 的成本为每百万输入 token 5 美元，每百万输出 token 25 美元。OpenAI 对不同模型版本[采用分级定价](https://www.eesel.ai/blog/gpt-5-6-pricing)：其最贵的 Sol 模型每百万输入 token 5 美元，每百万输出 token 30 美元；而最便宜的 Luna 模型每百万输入 token 1 美元，每百万输出 token 6 美元。

本周是 AI 模型发布的重要一周。OpenAI [计划于周四发布](https://www.politico.com/news/2026/07/08/open-ai-models-release-sol-00989959)其最新、最强大的模型 GPT 5.6。该模型的发布此前因安全影响方面的担忧而受到特朗普政府的限制。OpenAI [称其为](https://openai.com/index/previewing-gpt-5-6-sol/)"迄今为止最强大的模型"。
