扩展 Glasswing 项目

📅 2026-06-02 📄 Anthropic 🔗 原文链接

原标题：Expanding Project Glasswing

中文摘要： Anthropic宣布扩展Project Glasswing项目，将合作伙伴增至约150家新组织，涵盖电力、水务等关键基础设施及开源维护者。此前，初始合作伙伴利用Claude Mythos Preview模型已发现超1万个高危安全漏洞。该项目旨在帮助软件行业适应AI对网络安全的颠覆，推动从漏洞发现到补丁修复的转变。面对未来缺乏安全护栏的AI网络攻击威胁，Anthropic正努力安全发布高级网络防御能力，力求为防御者建立永久优势。

Project Glasswing 是我们为保护全球最重要软件安全而开展的协作项目。4 月初，我们宣布约 50 家初始合作伙伴可以使用 Claude Mythos Preview，从那时起，他们一直在部署该模型以扫描其代码库中的漏洞。我们最近描述了这些合作伙伴迄今为止如何发现超过 10,000 个高严重性或严重级别的安全缺陷。

我们现在正在扩展 Project Glasswing。在与 Project Glasswing 合作伙伴、安全行业、开源软件维护者以及美国政府进行了数周的密切合作后，我们将该合作伙伴关系扩展到约 150 个新组织。每个组织在获得访问权限之前都需要满足我们的安全要求。

这一新组中的组织位于 15 个以上的国家，其中大多数为更多组织提供关键基础设施。（未来，我们打算进一步扩大我们的地理范围。）该组涵盖了在我们初始群体中代表性不足的几个行业，如电力、水务、医疗保健、通信和硬件。许多新合作伙伴是供应商——即维护被全球（包括政府）许多其他组织所依赖的代码库的公司或非营利组织。

每个合作伙伴的共同点是，对其代码库的成功攻击可能是灾难性的。对于大多数合作伙伴，我们估计一次重大攻击可能会影响超过 1 亿人，对全球和国家安全产生重大影响。

此次扩展是我们实现长期目标的下一步：让 AI 使_所有_软件更安全，并帮助我们行业适应 AI 可能如何改变网络安全的许多核心假设。

Project Glasswing 的作用

Project Glasswing 和 Claude Mythos Preview 的能力引发了广泛的对话——无论是在软件行业内部还是与政府之间——关于 AI 如何改变网络安全。这些对话为我们如何扩展该项目提供了信息。它们也塑造了我们对 Project Glasswing 根本目的的思考。

具有强大网络能力的廉价、快速 AI 模型即将问世。我们希望 Project Glasswing 能推动机构采取反映这一现实的运营规范。

Mythos Preview 延续了我们一段时间以来一直在警告的长期趋势：在 6 到 12 个月内，我们预计许多其他 AI 公司将拥有 Mythos 级别的模型，并且他们可能会在没有防止滥用保障措施的情况下发布它们。在那个世界里，网络攻击可能会更频繁地发生，并以更不可预测的形式出现。网络防御者必须适应以保持同步。

我们认为我们的作用是双重的。首先，通过安全地提供对更好模型、工具和公共基础设施的广泛访问，帮助软件行业适应。其次，稳步转变我们提供的支持，从发现漏洞转向披露、修复和部署补丁软件。我们现在将依次讨论这两点。

支持网络防御者

到目前为止，公司、非营利组织、维护者和研究人员都迅速采取了行动。在 Project Glasswing 的最初几周内，每个成员都开始大规模使用 Mythos Preview，与其他合作伙伴分享信息和最佳实践，并与第三方合作对模型的发现进行分类。这些组织适应新工具的方法可以、也应该在容易受到网络攻击的数百万组织和开发人员中广泛复制。

为了支持这一点，我们最近发布了 Claude Security，这是一款使用我们最新的公开前沿模型（如 Claude Opus 4.8）来扫描代码库并建议补丁的产品。我们还在应要求向受信任的安全团队发布这些工具，这是我们开发的旨在帮助 Project Glasswing 合作伙伴更快发现漏洞的工具。

我们打算走得更远：我们的长期目标是支持行业为强大网络模型时代创建新的倡议、标准和基础设施。

加速补丁修复及其他安全工作

正如我们之前讨论过的，网络安全的瓶颈现在是验证、披露和修补 Mythos 级别模型可以发现的大量漏洞。

Mythos Preview 本身可以提供帮助。Project Glasswing 的许多合作伙伴现在使用该模型编写补丁，以及用于防止漏洞首先出现的发布前检查。像 Mythos Preview 这样的模型还可用于渗透测试（模拟网络攻击以识别漏洞可能如何被利用）、自动化威胁检测和响应，以及用内存安全语言重建遗留代码库等许多防御性任务。

我们正在与第三方讨论如何大幅扩大开源软件中漏洞的审查和修补规模。我们还在分享向开源维护者披露漏洞的想法和最佳实践，旨在使这些报告更容易分类和采取行动。

前进之路

为了应对这一即将到来的挑战的规模，可能需要成千上万的组织、研究人员和维护者获得可用的最先进网络能力和工具。

我们正在尽可能快地工作，以便在通用访问中安全地发布 Mythos 级别的能力。为此，我们需要高度强大的保障措施，以防止模型的网络能力被滥用——这些保障措施是我们（据我们所知，也是所有其他 AI 开发人员）尚未开发出来的。因为网络安全既有有益的用途，也有破坏性的用途，制定既强大又足够精确的保障措施是一项重大挑战。

同时，我们计划进一步扩展 Project Glasswing——优先考虑额外的重要基础设施提供商、关键开源软件的维护者和安全测试人员。我们打算让未来的扩展像这次一样覆盖美国和海外的组织。我们还打算扩大我们的网络验证计划，该计划将向更多组织授予 Mythos 级别的能力，用于特定的网络防御任务。

在未来，前沿模型的发布将变得越来越高风险。能力将在所有领域继续提高，包括许多像网络安全这样既能赋能攻击者也能赋能防御者的领域。这不会是我们最后一次需要面对这样的挑战。但 Project Glasswing 教会了我们很多关于当模型跨越重要能力阈值时如何应对的知识。如果我们成功了，我们希望能为防御者提供永久的优势。
