DocDUR-Net：退化感知的统一文档图像修复

📅 2026-11-25 📄 arxiv 🔗 原文链接

原标题：DocDUR-Net: Degradation-Aware Unified Document Image Restoration

中文摘要： DocDUR-Net是退化感知的统一文档图像修复网络，直接从输入图像提取退化信息指导修复。核心组件包括退化感知模块（DPM）和退化先验引导的自适应特征融合（DP-AFF）：前者预测退化权重，后者融合可学习先验与输入退化特征并注入共享修复主干，实现无需外部任务选择的自动修复，同时保留手动模式。在阴影去除、去模糊和高光去除基准上，该方法在统一方法中取得最佳平均PSNR（29.405 dB）和SSIM（0.960），并与单一退化方法相当。

DocDUR-Net：退化感知的统一文档图像修复

作者：Haowei Xu、Peirong Zhang、Xuhan Zheng、Lianwen Jin（🖂）

单位：华南理工大学，广州，中国

邮箱：haowei_xu@foxmail.com、{eeprzhang,eexhzheng}@mail.scut.edu.cn、eelwjin@scut.edu.cn

摘要

拍摄的文档图像常因不受控的成像条件而遭受多种退化，导致可读性下降并掩盖精细的文本结构。单一退化修复方法通常针对个别退化类型分别训练和部署，因此在修复前需要进行模型选择。统一修复模型通过在多个任务间共享一个网络，减轻了维护多个修复网络的负担，但代表性的统一文档图像修复方法仍依赖外部任务选择，这种依赖限制了文档图像修复的自动化。我们提出DocDUR-Net，一种退化感知的统一修复网络，直接从输入图像中获取修复指导。该方法引入退化感知模块（DPM）用于提取退化表示并预测退化权重，并引入退化先验引导的自适应特征融合（DP-AFF），将可学习的退化先验与从输入中提取的退化特征相结合。所得指导被注入共享修复主干，无需外部任务选择即可实现自适应修复。DocDUR-Net还支持带显式任务选择的手动模式。在文档图像修复基准上的实验表明，DocDUR-Net在统一方法中取得了最佳的平均PSNR 29.405 dB和SSIM 0.960，同时与单一退化方法保持竞争力。

关键词：文档图像修复、统一修复、退化感知

1 引言

文档图像修复旨在从退化的拍摄图像中恢复可读的文档图像[30, 27]。在真实采集场景中，文档图像可能因不受控的光照、相机运动或反光材料而遭受阴影、模糊和镜面高光[23, 19, 26]。这些退化会掩盖文本区域并破坏笔画结构，凸显了有效修复方法的必要性。

单一退化文档图像修复方法通常只关注一种退化类型。研究者针对文档阴影去除[9, 7]、文档图像去模糊[4, 12]和文档镜面高光去除[3, 21]设计并训练专用模型。这些方法虽然对其目标退化有效，但该范式依赖单独训练的模型，且需要在修复前进行模型选择，如图1(a)所示。任务指定的统一文档图像修复方法在多个任务间共享一个模型，减少了训练多个修复网络的需求。然而，现有的统一方法在修复前仍需要显式的任务选择，如图1(b)所示。

图1：以阴影去除为例的文档图像修复范式比较。 单一退化修复需要为目标退化选择专用模型。 任务指定的统一修复使用一个修复模型，但仍需要任务选择。 DocDUR-Net提取退化信息进行自动修复，同时在手动模式中保留显式任务选择。

因此，我们提出DocDUR-Net，一种退化感知的统一修复网络，通过从输入图像中提取退化信息来执行自动修复，如图1(c)所示。DocDUR-Net由一个共享修复主干和两个退化感知组件组成。退化感知模块（DPM）提取多尺度退化信息并预测退化权重，而退化先验引导的自适应特征融合（DP-AFF）将可学习的退化先验与输入退化特征相结合，并将所得指导注入主干。DocDUR-Net默认以自动模式运行，同时保留带显式任务选择的手动模式，用于受控评估和任务指定的修复。

我们的贡献总结如下：

  • 我们提出DocDUR-Net，一种退化感知的统一修复方法，通过从输入图像中获取修复指导实现自动文档图像修复，同时保留带显式任务选择的手动模式。
  • 我们设计了DPM和DP-AFF，将退化感知转化为自适应修复指导。DPM从输入图像预测退化权重，DP-AFF将可学习的先验与输入退化特征融合，以引导共享修复主干。
  • 在代表性基准上的实验证明了DocDUR-Net的有效性。它在统一方法中取得了最佳的平均PSNR和SSIM，同时与单一退化方法保持竞争力。

2 相关工作

2.1 单一退化文档图像修复

单一退化文档图像修复方法通常为特定退化设计专用网络。对于文档去模糊，代表性方法[4, 12]使用大感受野或直接图像回归来恢复清晰的字符笔画。对于文档阴影去除，FSENet[7]将Transformer块[17]与频率分解相结合，DocDeshadower[31]通过注意力聚合和门控融合去除阴影。对于文档镜面高光去除，HAFNet[5]采用分层自适应滤波，而DocSHRNet[21]引入了文档结构和自适应感受野。这些方法对其目标退化有效，但将其扩展到不同修复任务需要单独训练的模型并在推理前进行模型选择。

一些文档修复框架使用通用性较强的修复架构处理不同的文档修复任务[15, 22, 1, 11]。然而，它们仍需针对每个任务分别训练和使用。这促使了能够在单个模型内处理不同修复任务的统一文档图像修复方法的发展。

2.2 统一文档图像修复

统一建模在文档处理领域已被广泛研究[16, 18, 28]。在文档图像修复中，统一方法使用共享模型处理不同的修复任务。DocRes[25]是一种代表性的统一模型，它为不同任务构建动态视觉提示，并将其与退化输入拼接以引导修复网络。Uni-DocDiff[29]将统一文档修复扩展到扩散模型，使用可学习的任务提示来约束迭代修复过程。这些方法减少了维护多个修复网络的需求，但仍需为每个输入图像在外部指定修复任务。其修复过程依赖于外部指定的任务信息，而非从输入图像中提取的退化信息。

相比之下，DocDUR-Net将退化感知融入统一修复，并利用从输入图像中提取的退化信息引导修复，同时保留带显式任务选择的手动模式。

3 方法

3.1 问题表述与概述

给定一张退化文档图像 I_input，DocDUR-Net利用退化感知指导 g 预测修复后的图像 Î：

Î = R(I_input; g)，（1）

其中 R(·) 表示修复网络，g 源自输入图像中的退化信息。

DocDUR-Net通过一个共享修复主干和两个核心组件实现该表述，如图2所示。DPM与主干并行地提取退化信息并预测退化权重，而DP-AFF将退化信息与可学习的先验相结合以产生特征指导。

图2：DocDUR-Net的整体架构。DPM从输入图像预测退化权重，DP-AFF将退化引导的特征注入共享修复主干。可选的手动模式支持显式任务选择。

3.2 退化感知模块

DPM使用轻量级多阶段编码器从输入图像中提取退化信息，如图3所示。四个阶段的特征经全局平均池化[8]压缩后，沿通道维度拼接形成全局退化表示 f_global。

图3：DPM用于退化特征提取和权重预测的结构。

DPM包含两个并行分支。退化预测分支将 f_global 映射为退化logits z_deg ∈ ℝ^K，其中 K 表示修复任务的数量。可学习温度参数 τ[2]在Softmax之前对logits进行缩放：

w_deg = Softmax(z_deg / τ)，（2）

其中 w_deg ∈ ℝ^K 表示退化权重，供DP-AFF用于聚合退化先验。退化特征分支将 f_global 投影为连续的退化特征：

d_feature = f_proj(f_global)，（3）

其中 f_proj(·) 由两个全连接层实现，d_feature ∈ ℝ^d。

3.3 退化先验引导的自适应特征融合

DP-AFF利用退化权重聚合可学习的先验，并将其与输入退化特征融合。融合后的表示为修复主干提供指导，如图4所示。

图4：DP-AFF用于退化先验融合和特征指导的结构。

我们定义一个可学习的退化先验矩阵 P ∈ ℝ^(d×K)，其中每一列对应一个修复任务。给定 w_deg，DP-AFF得到聚合的退化先验：

e_deg = P·w_deg，（4）

其中 e_deg ∈ ℝ^d。先验 e_deg 与 d_feature 拼接后投影形成指导：

g = f_fusion(Concat[d_feature, e_deg])，（5）

其中 f_fusion(·) 由两个全连接层实现。向量 e_deg 表示加权退化先验，而 d_feature 保留了输入退化信息。

对于主干特征 F，投影后的指导被加到 F 上：

F' = F + φ(g)，（6）

其中 φ(·) 表示相应注入位置的线性投影，随后进行空间广播。这种加性融合在多个修复阶段中应用，以引导全局结构恢复和局部细节细化。

3.4 推理模式

DocDUR-Net主要以自动模式运行，如图2和图4所示。在该模式下，DPM从输入图像预测 w_deg，DP-AFF利用它聚合退化先验并引导主干，从而实现无需外部任务选择的统一修复。

手动模式作为可选协议，用于受控评估和带显式任务选择的修复。在该模式下，所选任务被映射为退化权重以替代DPM的预测，其余修复过程保持不变。

3.5 损失函数

训练使用修复监督和退化分类监督。修复损失由像素级L1损失、感知损失[6]和SSIM损失[20]组成：

L_rec = λ_L1·L_L1 + λ_perc·L_perc + λ_SSIM·L_SSIM。（7）

退化预测分支由退化标签监督：

L_cls = CE(z_deg, y_deg)，（8）

其中 y_deg 表示退化标签。总目标函数为：

L_total = L_rec + λ_cls·L_cls。（9）

我们设置 λ_L1 = 1、λ_perc = 0.1、λ_SSIM = 0.5、λ_cls = 0.1。

4 实验

4.1 数据集与任务

我们使用文档阴影去除、文档图像去模糊和文档镜面高光去除的代表性基准。对于文档阴影去除，我们使用SD7K[7]，遵循原始划分，包含6479个训练图像对和760个测试图像对。对于文档图像去模糊，我们使用TDD[4]；遵循DocRes[25]所用的划分，我们使用40000个图像对训练、1600个图像对测试。对于文档镜面高光去除，我们使用DocHighlight[21]，从2201张高分辨率真实配对图像中取1701个训练对和500个测试对。DocDUR-Net作为单一统一模型在所有训练集的并集上训练。

4.2 评估指标

我们报告修复图像与配对真实图像之间的PSNR和SSIM[20]，以衡量像素保真度和结构相似性。对于统一方法，表1还报告了所评估任务的平均分数。

4.3 实现细节

所有实验均基于PyTorch[13]实现，采用Restormer[24]作为共享修复主干。训练在四块NVIDIA RTX A6000 GPU上进行。我们使用AdamW[10]优化器，权重衰减为1×10⁻⁴。退化特征维度和先验维度设置为 d = 128。可学习温度 τ 初始化为1.0，并约束在[0.1, 10.0]范围内。

为平衡不同数据集的规模，训练时每个任务数据集以相等概率被采样。DocDUR-Net分两个阶段训练：第一阶段使用256×256随机裁剪训练100000次迭代，批量大小为4，学习率为2×10⁻⁴；第二阶段以学习率5×10⁻⁵再训练100000次迭代，批量大小为1，DocHighlight和SD7K使用512×512裁剪，TDD使用256×256裁剪。DPM输入被缩放至768像素长边，并采用随机旋转进行数据增强。对于文档镜面高光去除，我们遵循DocSHRNet[21]，使用1024×1024滑动窗口推理（步长512），而阴影去除和去模糊采用图像级推理。

5 结论

本文提出了DocDUR-Net，一种退化感知的统一文档图像修复方法。该方法从输入图像中提取退化信息，并利用DPM和DP-AFF引导共享修复主干，无需外部任务选择即可实现自动修复，同时保留了用于灵活修复控制的手动模式。实验结果证明了DocDUR-Net在退化感知统一文档图像修复中的有效性。
