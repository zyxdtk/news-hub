机器人损伤后风险感知规划的结果接口

📅 2026-11-20 📄 arxiv 🔗 原文链接

原标题：What Must a Model Tell a Planner? Outcome Interfaces for Risk-Aware Planning After Robot Damage

中文摘要： 本文研究机器人受损后学习模型应向规划器传递何种信息。作者比较四种决策接口：决策策略、带固定惩罚的策略、路线结果模型和能力契约，并在模拟的宇树Go2四足和H1人形机器人上评估。结果表明，结果模型在校准风险限制下保留更多任务，将Go2的拒绝率从约32%降至7–8%。两次低风险探测即可有效排序危险地形，AUC达0.87，试验成本远低于全面重测。

摘要

当机器人受损时，它必须决定自己仍能承担哪些路线，而其可接受的风险量可能随任务而变化。我们认为，学习模型能否帮助此类机器人取决于其决策接口，即模型向规划器传递什么信息。决策策略告诉规划器该做什么，而结果模型（一种世界模型）预测每条路线的后果。我们研究了带有减弱电机、附加负载或降低足部摩擦的模拟宇树Go2四足机器人和H1人形机器人。我们比较了四种接口。第一种是决策策略，第二种是使用不可行路线固定惩罚训练的相同策略。第三种是预测每条路线可行性和通行时间的结果模型。第四种我们称为能力契约，是一种预测机器人在每种地形上的成功几率和通行时间并沿路线组合这些预测的结果模型。所有接口共享相同的收集经验、匹配的调优和风险校准以及不确定性防护。两次相对低风险的探测使能力契约对危险地形的排序效果与在每个危险地形上进行四次新试验大致相当。在校准的5%经验性不可行路线选择限制下，与普通策略相比，结果模型将Go2上被拒绝的任务从约32%降至7–8%，将H1上从57%降至35–36%。固定惩罚缩小了这一差距，但最佳惩罚随风险目标而变化。预测结果使规划器能够在风险要求收紧时通过改变路线来保留任务。

关键词：世界模型、决策接口、风险感知规划、共形风险控制、腿式机器人

1 引言

设想一只左前膝关节失去一半扭矩的四足机器人。其规划器可以让它走上一段短楼梯、沿带有单个障碍物的混合路径行进，或绕行经过平缓坡面的较长迂回路线，且机器人始终可以停下来寻求帮助。地形和可用路线没有改变，但机器人完成它们的机会已经改变。通过试验来测试危险地形会招致规划器本要防止的跌倒。可接受的风险可能因任务而异，在人群附近的要求比勘测期间更严格。如果首选路线变得不可接受，规划器仍必须决定受损机器人可以尝试哪种替代方案。

策略将观测映射到选择 [3, 23, 10]，而世界模型预测可以为这些选择提供依据的后果 [7, 8]。我们研究它们的决策接口，即学习组件向规划器传递什么。决策策略对路线进行评分，而结果模型估计可行性或成功概率以及通行时间。对某条路线被偏好的信心并不等同于机器人能够完成该路线的概率。

相关工作。 损伤恢复利用高斯过程预测来搜索补偿行为 [4]，而自适应运动学习在变化的动力学下如何行动 [11, 14]。这些方法改善机器人的移动方式，而我们评估其现有控制器仍能在何处成功。相关的评估方法使用能力估计来决定自主系统何时应求助人工协助 [2]，或从经验预测感知性能以避免失败 [6]。我们的高斯过程则跨受损机器人学习较容易地形上的响应如何预测危险地形上的成功通行概率和通行时间。这种关系使得两次相对低风险的探测能够评估新机器人，而无需重新测试每个危险地形。我们评估由此产生的危险地形排序以及获得它所需的试验和跌倒次数，并与直接危险重测进行对比。

无模型强化学习可以在没有显式转移模型的情况下学习运动 [18]，而基于模型的强化学习可以将策略提议与预测rollout相结合 [9, 22]。这些方法确立了学习策略和结果预测可以发挥互补作用。我们提出的问题是：当关于物理执行的信息保持显式而非被压缩到路线选择中时，路线规划器能获得什么。导航方法已经纳入部署指令 [16, 20]，共形规划器校准不确定的预测或决策 [13, 5, 12, 17]。在共享运动、经验和风险校准的情况下，我们比较过滤学习路线选择与从路线或地形预测重新评估替代方案。此比较衡量随风险目标变化而保留的任务数量，并测试当任务重新组合地形时，针对单个地形的预测是否有帮助。

2 设置与接口

上下文 x 指定地形类型、难度和可观测的起始状态。对于机器人 r，p_r(x) 是重复通行中的经验成功比例，d_r(x) 是成功情况下的测量持续时间。路线 ρ 是此类通行 e 的序列。基准将它们的结果组合为 P_r(ρ) = ∏{e∈ρ} p_r(e) 和 D_r(ρ) = Σ{e∈ρ} d_r(e)。任务提供三条路线和一个拒绝通行的回退选项。当 P_r(ρ) ≥ p_min = 0.7 时，我们将路线标记为可行。损失 L_r 是选择经验性不可行路线的所有任务的比例，回退贡献为零。风险目标 α 在校准假设下限定此损失的期望。因此，5%的目标将经验性不可行选择限制为在期望中最多占所有提供任务的5%，分母中包括被拒绝的任务。它不限定跌倒、任务失败或承诺路线条件下的错误比例。拒绝每个任务的损失为零，因此有意义的比较是每个接口在相同校准目标下保留多少任务。

损伤后，机器人执行两次相对低风险的探测。它们的观测向量 z 记录成功、持续时间、能量、速度和俯仰角变化以及每条腿的扭矩饱和度。所有四种接口都使用这些观测和相同的收集通行经验，采用跨机器人核回归和匹配调优。

决策策略学习先知在三条路线和回退之间选择的得分。先知使用测量的通行结果（而非高斯过程预测）选择最快的经验性可行路线。惩罚决策策略从不可行路线的训练得分中减去固定惩罚 P。路线结果模型学习每条路线的可行性标签和持续时间。能力契约使用高斯过程 [21] 预测地形成功和持续时间，并沿路线组合这些估计。契约从拟合机器人的配对测量中学习探测观测如何预测危险地形结果。探测被贪婪地选择以减少预测成功中的误差。路线和任务描述、监督和调优见附录B。

每个规划器使用可调节的决策裕度。契约将组合成功估计与 p_min 加裕度进行比较，而路线模型将其可行性得分与 0.5 加裕度进行比较。每个规划器选择最快的被接受路线，如果没有符合条件的路线则回退。决策规划器仅当其最高路线得分超过回退得分加裕度时才承诺，因此增加裕度只能用回退替代承诺。共形风险控制在100个机器人上校准每个裕度 [1]。改变 α 会改变此校准，而 p_min 保持固定。共享防护使用探测观测上的预测方差将不熟悉的机器人送至回退。附录A陈述假设和期望损失保证。

3 基准

我们使用 Isaac Lab [15] 和冻结的预训练Go2和H1运动策略。每个机器人最多有三个减弱的关节、附加负载和降低的足部摩擦。每个平台有300个源机器人，分为200个拟合机器人和100个校准机器人，以及100个独立的测试机器人。Go2另增加80个损伤超出源群体的机器人。每种地形从八个可观测的起始状态通行，每个状态用两个隐藏的关节姿态扰动重复。每个上下文两次试验且 p_min = 0.7 时，当且仅当两次试验在每条边上都成功时路线可行。任务提供一条包含三个危险边的直接路线、一条包含一个危险边和三个简单边的混合路线，以及一条包含六个简单边的迂回路线。我们评估熟悉的任务、已表示危险地形的新组合以及更严重的Go2损伤，结果为20次源分割的平均值。正文报告熟悉任务的风险比较和探测评估，而附录C报告其余评估。这些路线评估组合记录的地形结果，而非连续执行完整路线。图3显示模拟地形，附录D和E提供基准和损伤细节。

4 结果

结果模型在风险限制下保留更多任务。 尽管在没有施加风险目标时与先知的相似一致性（图2，表2），两种结果接口在校准风险限制下在Go2和H1上都比普通策略保留更多任务。精心选择的固定惩罚恢复了大部分这种好处，在Go2上几乎消除了差距，在H1上缩小了差距，但最佳惩罚随风险目标而变化（表3）。在最严格的目标下，契约在两个平台上仍比最佳测试惩罚保留更多任务。实际好处是规划器可以在要求变化时改变路线，同时重用相同的结果预测器。

两次探测以低试验成本改进危险评估。 观察受损机器人比群体平均值改进危险地形的排序。两次设计探测将Go2上的AUC从0.67提高到0.87，将H1上的AUC从0.75提高到0.86（表4）。在每个危险地形上进行四次试验可实现相似的排序，但需要多16–18倍的运行次数，并且每个机器人产生大约16–18次跌倒，而探测期间少于0.1次。将设计探测的次数增加到两次以上几乎没有进一步的改进（表5）。

5 讨论与未来工作

两次相对低风险的探测让受损机器人能够评估危险地形，而无需自身重新测试每个危险地形。结果接口让被评估的规划器重新考虑替代方案，并在校准风险限制下比普通策略保留更多任务。在部署时，我们可以通过重新校准规划器的裕度来改变风险目标，而无需重新拟合其结果预测器，同时契约可以为已表示地形的新组合生成组合预测。风险条件策略可以将请求的目标作为输入并直接学习路线切换，但此处评估的策略不接收该目标。因此，我们的比较确立了向此规划器公开可重用结果估计的价值，而不是表明改变风险要求本质上需要结果模型。随着风险要求收紧，规划器变得越来越保守，以任务保留换取更少的不可行路线选择。未来工作应在严格目标下保留有用的路线选择，在物理机器人上验证完整路线执行，并在机器人损伤和任务分布的更广泛变化下测试评估和校准。

附录A 校准与风险解释

对于每个机器人 r 和决策裕度 λ，L_r(λ) ∈ [0,1] 是底层决策规则选择经验性不可行路线的任务比例。回退损失为零。设 Λ 为有限的有序裕度网格，包括始终选择回退的端点 λ_max。因为结果规划器可能随着裕度增长而切换路线，其原始损失不必单调递减。因此我们为每个机器人分别形成上包络：

L̃r(λ) = max{λ'∈Λ, λ'≥λ} L_r(λ').　(1)

使用 n = 100 个校准机器人，校准的裕度为：

λ̂ = min{λ∈Λ : (Σ_{i=1}^n L̃_i(λ) + 1)/(n+1) ≤ α}.　(2)

如果没有裕度符合条件，规则使用 λ_max。对于测试目标 α ∈ {0.02, 0.05, 0.10}，端点损失为零并使集合非空。在以拟合数据为条件下，我们假设校准机器人与新机器人 r 可交换，探测设计、特征变换、模型拟合和调优在校准前固定，且损失使用共同的固定任务分布或共享任务库。包络以一为界、非递增且至少与原始损失一样大。在这些假设下应用共形风险控制得到 E[L_{r}(λ̂)] ≤ α [1，推论1]。在拟合数据条件下，期望是对校准机器人、新机器人以及当任务不是从固定共享库中抽取时的任务采样取期望。这是已发表结果的应用，而非新的理论保证。

不确定性防护将新机器人的探测方差 s²(z_{r}) 与校准分位数 τ 进行比较。对于 δ = 0.05，τ 是第 ⌈(n+1)(1−δ)⌉ 小的校准方差。当 s²(z_{r}) > τ 时，防护用回退替代路线选择。在底层规则校准之后应用，它不能增加 L_{r*}，因此保持界限。在可交换性下，其边际标记概率最多为 δ [19]。此声明不保证检测源分布之外的机器人。受控损失涉及选择，而非跌倒或任务失败的物理概率，并且它对所有任务而非仅接受的任务取平均。该保证是边际的，因此单个校准分割的观察测试损失可能超过 α。例如，在5%的H1目标下，最大观察分割率为契约5.7%和决策策略5.8%。该保证不扩展到新组合任务分布或损伤超出源群体的机器人。

附录B 接口与实现

能力契约。 拟合机器人上的高斯过程预测每个地形上下文的经验成功和持续时间 [21]。对于上下文 x 处的任一目标，其预测和共享探测方差为：

μ_x(z) = ȳ_x + k(z)^T (K + σ²I)^(−1) (y_x − ȳ_x 1),
s²(z) = k(z,z) − k(z)^T (K + σ²I)^(−1) k(z).　(3)

这里 Z 包含拟合机器人的标准化探测观测，K = k(Z,Z) 是它们的核矩阵，k(z) 是新观测 z 与 Z 之间核评估的向量。向量 y_x 包含拟合目标，ȳ_x 是它们的均值，1 是全1向量，I 是单位矩阵，σ² 是对角正则化参数。契约将地形预测组合为 P̂(ρ) = ∏{e∈ρ} p̂(e) 和 D̂(ρ) = Σ{e∈ρ} d̂(e)。探测选择使用源机器人经验贪婪地减少危险地形上成功的预测误差。

描述和监督。 路线由每个上下文和地形中的边数描述，Go2 上有96+12个条目，H1 上有128+16个条目。任务堆叠其三条路线的描述。决策学习器接收这些描述和 z，因此它们已经有受损机器人的观测。它们的先知使用测量的地形结果选择组合持续时间最短的可行路线，如果没有可行路线则回退。普通策略学习先知选择得分；每个惩罚策略从每个不可行路线的训练得分中减去 P ∈ {0.3, 1, 3, 10}。每个惩罚分别训练并在所有风险目标下评估。路线结果模型直接学习可行性和持续时间，分别调优。其可行性得分被裁剪到 [0,1]，必须超过0.5加校准裕度；网格延伸到0.51，此时每条路线都被拒绝。

拟合和调优。 每个分割使用200个拟合机器人和100个校准机器人，以及100个独立的测试机器人。所有接口使用跨机器人核回归，使用精确的留一机器人残差进行调优，因此留出的机器人不向拟合贡献任何条目。网格使用六个机器人核长度尺度和岭惩罚 {0.03, 0.1, 0.3, 1}。路线和决策模型还使用线性或平方指数条目核，尺度为成对条目距离中位数的0.5、1或2倍。拟合数据和程序是匹配的，而目标、路线表示和选择规则不同。探测方差提供共同的不确定性防护。

附录D 基准细节

损伤。 每个机器人有零到三个减弱的腿部关节，概率分别为0.10、0.35、0.35和0.20，从12个Go2关节或10个H1腿部关节中选择。[0.25, 0.80] 中的减弱因子缩放Go2上的扭矩-速度包络和H1上的执行器扭矩限制。负载扰动使用1.0–1.3的质量乘数，质心偏移最多3厘米，足部摩擦在 [0.4, 1.0] 之间。80个额外的Go2机器人在一个因素上超出这些范围，使用四到五个弱关节、驱动因子0.10–0.25、质量因子1.30–1.45或摩擦0.25–0.40。

地形和探测。 Go2地形包括平地、12°、20°和24°上坡、26°下坡、8、12和14厘米台阶的楼梯、28厘米下坡、±14厘米粗糙地面以及12、16和20厘米箱体。H1地形包括平地、9–22°上坡、18°和29°下坡、26–34厘米楼梯、44厘米下坡、±26和±32厘米粗糙地面以及38–50厘米箱体。平均源成功在 [0.05, 0.8] 之间的地形被指定为危险地形，Go2上有九个，H1上有八个。探测候选在Go2上是平地、12°上坡和26°下坡，在H1上是平地、9°和12°上坡以及18°下坡，每个来自四个起始状态。基准包含145,920次Go2和109,072次H1 rollout。

成功通行和跌倒。 成功要求在6–10秒内不跌倒的情况下在平地或坡面上覆盖1.5米，在其他地形覆盖2.0–2.2米。当Go2上基座离地间隙降至0.14米以下或H1上降至0.55米以下、Go2上横滚或俯仰超过55–60°或H1上超过45°，或基座或躯干接触地面时，记录为跌倒。
