在机器人学中，形状控制（或形状伺服）是指将可变形物体自动操纵至期望形状。它包含一个反馈回路，其中变形雅可比矩阵提供了微小机器人指令运动如何改变物体测量形状的局部线性近似。由于该雅可比矩阵取决于物体的力学特性、几何形状和边界条件，从力学模型准确推导它通常很困难。它可以在操纵过程中从收集的测量数据进行局部估计。本文是关于这种数据驱动、基于雅可比矩阵的形状控制方法两篇教程的第一篇。文中介绍形状伺服回路的组成部分（形状特征与形状误差、变形雅可比矩阵、其离线估计与在线更新，以及标准控制律），将它们组合成完整的控制器，推导局部稳定性条件，并解释为什么某些目标形状无法达到。第二部分涵盖更高级的主题。在两部分中，一个仿真平面示例——两台机器人手臂操纵由相机观测的弹性杆——贯穿说明这些概念。

I 引言

I-A 本教程的动机与目的

可变形物体操作是机器人学中不断发展的研究领域，应用涵盖工业自动化、医疗机器人和服务机器人（如电缆布线、组织操作或衣物折叠）。这些应用中有许多需要在操纵过程中调节物体的形状，例如为了达到期望构型、避免碰撞或限制过度应力。这一任务被称为形状控制或形状伺服（图 1）。尽管关于形状控制的早期工作出现于 2010 年代，该领域直到最近才成熟到能够在广泛的应用中识别出反复出现的方法论选择。基于这些反复出现的选择，并作为经典视觉伺服教程 [1, 2, 3] 的自然延伸，本教程提供形状控制的入门级介绍。它聚焦于数据驱动的基于雅可比矩阵的形状控制，这一方法已在文献中成为标准。

现有的综述和分类学对可变形物体的建模、感知、学习和操作提供了广泛的概述 [4, 5, 6, 7]，但它们并未提供面向控制的形状伺服统一介绍。特别是，反复出现的基于雅可比矩阵的公式分散于面向特定应用的工作中，且常以不同的符号、假设和估计策略呈现。本教程通过将这些方法组织到一个共同框架中，并给出理解、实现和分析数据驱动基于雅可比矩阵的形状控制所需的概念，来弥补这一空白。

I-B 为什么选择数据驱动的基于雅可比矩阵的形状控制？

形状控制需要关于机器人运动如何影响可变形物体测量形状的局部描述 [6]。这一输入–输出关系由交互雅可比矩阵刻画，本文称之为变形雅可比矩阵。该雅可比矩阵一般取决于物体的力学特性（如刚度、密度）、几何形状（如表面曲率、自然形状）和边界条件（如抓取点、重力）。

一种选择是从力学或几何模型推导变形雅可比矩阵。此类模型可以给出变形响应的具有物理意义的描述，但可能计算代价高昂，并且需要难以测量或辨识的物体属性、边界条件或模型参数 [4, 8, 9]。

另一种方式是直接从操纵过程中收集的测量数据估计雅可比矩阵，并随物体变形在线更新。这避免了显式建模物体力学，同时提供反馈控制所需的局部输入–输出关系。在本教程中，无模型特指这种设定：不使用显式的力学或几何模型，尽管估计出的雅可比矩阵本身构成一个局部输入–输出模型 [6]。该表述与未标定视觉伺服 [10] 密切相关，并已成为形状控制的标准方法，应用于线缆 [11, 12]、轮廓与表面 [13, 14] 以及塑性可变形材料 [15]。

我们采用这一数据驱动表述，因为它在文献中已充分确立，足够紧凑以便在教程内呈现完整的形状伺服方法论，且足够模块化以提供一个共同框架——读者可以先将其作为整体学习，然后通过研究或替换个别组件加以扩展。例如，如前所述，变形雅可比矩阵也可以从力学或几何模型获得 [4]，而替代的形状特征或反馈律也可以在不改变本文所给整体控制结构的情况下使用。

I-C 本教程的适用范围

本教程中的方法适用于满足以下三个假设的操作任务：

  • 准静态、速度级操纵。 物体缓慢变形且仅响应机器人运动，惯性效应可忽略。因此，其变形可视为由机器人速度指令驱动的准静态力学平衡构型序列。
  • 可测量的形状反馈。 与任务相关的变形可在操纵过程中测量，例如来自视觉或其他传感模态。这可以对应于完整的物体形状或一组形状特征。不要求特定的感知流水线或表示，只要所选特征能够捕获与控制目标相关的变形即可。
  • 连续的操纵状态。 机器人运动与物体变形之间的关系在任务过程中平滑变化。接触条件的突变（如重新抓取或碰撞）、拓扑变化（如物体断裂或将其部分连接成环）、或显著不同的变形状态之间的转变（如高度弹塑性物体中）可能使当前的变形雅可比矩阵失效，需要重新估计或额外的任务级逻辑。

除这些假设外，本文给出的通用框架（图 1）适用于不同类型的可变形物体、传感模态以及获取变形雅可比矩阵的方法。

II 形状伺服回路的组成部分

标准形状伺服回路包含三个主要模块（图 1 左）：感知，从传感器测量中提取形状特征；局部模型估计，将机器人运动与这些形状特征的变化联系起来；反馈控制律，利用测得的形状特征和估计的局部模型生成减小形状误差的运动。在图 2 的详细回路中，它们分别对应感知模块、离线估计与在线更新模块、以及控制器模块。本节介绍与这些模块相关的量和运算，并用平面弹性杆运行示例加以说明。

II-A 形状特征与形状误差

设 x 表示可变形物体的完整构型，例如线缆的曲线（图 1）、布料的曲面或气球的封闭曲面。传感器提供该构型的测量 y(t)，如被跟踪的图像点、分割出的轮廓或点云。特征映射 s = f(y) ∈ ℝ^n 提取用于控制的有限维形状表示，如采样点的坐标、沿轮廓的曲率值或描述整体形状的模态系数（如傅里叶系数）。控制器以 s，即 x 的简化描述，作为其反馈信号。

给定目标特征向量 s*，形状误差为

e(t) = s* − s(y(t)). (1)

例如，若 s 堆叠沿线缆采样点的坐标，则 e 度量每个采样点与其目标位置的偏差。这要求 s 的每个元素保持一致的物理意义：第 i 个元素必须在线缆变形时跟踪同一材料点，且 s* 的第 i 个元素必须表示同一材料点的目标位置 [16]。其他表示（如模态描述符 [17, 14]）不将每个特征与特定材料点关联，但仍要求当前形状与目标形状之间曲线或域的参数化保持一致 [18]。

运行示例：形状特征。 图 2 右侧的插图在图像空间中说明了这一表示。感知沿杆跟踪 P = 5 个材料点（黄色点，顶部插图），并将其图像坐标堆叠为 s = [x_1, y_1, …, x_P, y_P]^⊤，得到 n = 10。目标 s* ∈ ℝ^10 包含目标形状上相同材料点的坐标（中间插图）。底部插图中的每个箭头（也显示在场景中的杆上）表示一个点的误差，对应 e_k 的两个分量（二维）。注意，在我们的示例中不需要相机标定，因为从机器人运动到形状特征变化的映射直接由图像测量估计（第 III 节）。

图 3： 运行示例中的离线雅可比矩阵估计。左：微小的机器人扰动 Δq_c 产生测得的特征变化 Δs_c。中：C = 24 个动作–响应对堆叠为 ΔQ 与 ΔS 的列。右：最小二乘回归给出初始雅可比矩阵估计 Ĵ_0。

II-B 准静态驱动与变形雅可比矩阵

遵循第 I-C 节的第一个假设，我们将操纵视为准静态：在微小机器人运动之后、下一次控制动作之前，物体稳定到邻近的平衡态，因此惯性效应被忽略。该假设排除了由快速动力学主导的状态²，如突变力学转变（滞后或分叉事件，例如屈曲）。为描述物体的平衡形状如何依赖于机器人构型，设 q ∈ ℝ^m 汇集被驱动的机器人状态，如关节状态或末端执行器位姿。在交互条件不变（如整个过程中抓取点相同）的情况下，当前构型附近的每个机器人构型都确定一个邻近的平衡形状，因此特征可写为 s = s(q)。

² 缓慢与准静态的动力学，如平衡构型中的重力效应，仍可用所提出的数据驱动方法处理。

形状控制器为被驱动的机器人坐标 q 输出速度指令 u ∈ ℝ^m。假设底层机器人控制器在比形状控制回路更快的时间尺度上跟踪该指令，机器人驱动可近似为纯积分器 q̇ = u ∈ ℝ^m。

运行示例：驱动与仿真。 两个夹爪在图 1（右）所示的平面内运动，各具有三个自由度：两个平面平移（x 与 y）和一个旋转（θ），如箭头所示。因此，q = [x_L, y_L, θ_L, x_R, y_R, θ_R]^⊤，m = 6。杆被建模为具有拉伸与弯曲刚度的基尔霍夫杆，离散为 25 个节点并受重力作用。对每个夹爪构型，其准静态平衡通过最小化杆的总势能求得。

由于形状特征依赖于物体构型，而物体构型又依赖于机器人坐标，链式法则给出 ṡ = (∂s/∂x)(∂x/∂q)q̇。因子 ∂x/∂q 描述机器人运动如何改变物体构型，∂s/∂x 描述这些变化如何反映到形状特征中。二者之积即变形雅可比矩阵 [11, 12]：

J(q) = (∂s/∂x)(∂x/∂q) = ∂s/∂q ∈ ℝ^{n×m}. (2)

当 q̇ = u 时，局部输入–输出关系成为

ṡ = J(q)q̇ = J(q)u. (3)

J 的第 j 列是机器人坐标 q_j 的单位速度所产生的特征速度。与视觉伺服中一样，J 将机器人运动映射为特征运动 [2]。然而，与视觉伺服不同的是，该映射并非仅由相机投影模型和特征几何决定，还取决于物体随构型变化的力学响应。因此，同样的夹爪运动可能产生截然不同的形状变化，例如杆松弛与绷紧时（第二部分）。

实际解读：变形雅可比矩阵。 变形雅可比矩阵是描述微小机器人运动如何改变物体形状的矩阵。它可以直接由真实数据估计，使用测得的机器人运动及其产生的形状变化。随着物体变形，同样的机器人运动可能产生不同的形状变化，因此雅可比矩阵必须在操纵过程中更新。

运行示例：变形雅可比矩阵。 雅可比矩阵 J ∈ ℝ^{10×6} 将夹爪的 m = 6 个速度（图 1）映射为图 2 中被跟踪点的 n = 10 个图像坐标的速度。图 3 右面板将其估计显示为 10×6 的彩色图，每列对应一个夹爪坐标，每行对应一个图像坐标。

II-C 控制律

真实雅可比矩阵 J 一般未知，因此控制器使用足够精确的估计 Ĵ ≈ J，由数据或物体模型获得（第 III 节）。给定 Ĵ，图 2 中的控制器模块使用 Moore–Penrose 伪逆³（记作 (·)^+）将形状误差（式 (1)）映射为机器人速度：

u = α Ĵ^+ e, (4)

其中 α > 0 为控制增益。

³ 接近秩损失时，伪逆变得病态。第二部分介绍了该情形下使用的阻尼逆。

理想情况下，特征将以期望速度 αe 运动，误差指数衰减。以 Ĵ 代替式 (3) 中的 J，该指令给出预测的特征速度 Ĵu = αĴĴ^+e。这是 αe 在 Range(Ĵ) 上的正交投影：换言之，即估计模型所能产生的最接近 αe 的特征速度。此处 Range(Ĵ) 表示由某个机器人速度可获得的所有特征速度的集合。因此，控制律仅作用于在估计模型下可通过机器人运动产生的那部分形状误差。

当 n > m 且 Ĵ 满列秩（即各列线性无关，如运行示例中）时，Ĵ^+ = (Ĵ^⊤Ĵ)^−1Ĵ^⊤，式 (4) 给出最小化特征空间中最小二乘误差的机器人速度，即使预测特征速度尽可能接近期望速度。当 n < m 且 Ĵ 满行秩（即各行线性无关，例如本教程第二部分的曲率表示）时，Ĵ^+ = Ĵ^⊤(ĴĴ^⊤)^−1，式 (4) 给出最小范数机器人速度：在所有能实现期望特征速度的机器人速度中，它选择幅值最小者。后一情形中，零空间 Null(Ĵ) 非平凡，包含被 Ĵ 映射为零的机器人速度。直观上，这些不改变所选形状特征的"额外"机器人运动可用于其他任务或控制目标，而不影响预测的形状运动。

II-D 离散时间实现

前述表述以连续时间给出，而控制回路通常以周期 Δt 在离散迭代 k 上运行（图 2）。在第 k 次迭代，感知给出特征 s_k = f(y_k)，随后控制器将式 (1) 与式 (4) 实现为 e_k = s* − s_k，控制律 (4) 成为

u_k = α Ĵ_k^+ e_k. (5)

机器人在一个控制周期内施加 u_k，产生坐标增量 Δq_k = u_k Δt。与准静态假设一致，物体在每个周期内力学上达到稳定，使每次测量 s_k 对应一个平衡形状。

最近产生的机器人增量 Δq{k−1} = u{k−1}Δt 及其导致的特征变化 Δsk = s_k − s{k−1} 构成一个动作–响应对。对于微小增量，式 (3) 给出 Δsk ≈ JΔq{k−1}，第 III 节正是基于这一关系估计和更新雅可比矩阵。在图 2 中，算子 Δt·z^−1 与 1 − z^−1（z^−1 表示一次迭代延迟）由 u_k 与 s_k 构成该对，在线更新模块将估计 Ĵ_k 回传给控制器。

III 变形雅可比矩阵的估计

控制律 (5) 需要初始雅可比矩阵估计 Ĵ_0（下标 0 指 k = 0），以及一种在物体变形过程中（k > 0）保持估计能代表物体响应的方法。在图 2 中，离线估计模块通过微小探索性运动的回归得到 Ĵ_0（第 III-A 节），而在线更新模块在控制过程中利用新记录的数据通过割线更新调整估计（第 III-B 节）。此外，物体模型也可以提供雅可比矩阵（第 III-C 节）。

III-A 基于回归的离线估计

为初始化雅可比矩阵，机器人在其初始构型 q_0 附近施加 C 个微小的探索性运动，并测量每个运动导致的特征变化（图 3）。对于探索性运动 c，定义动作–响应对 (Δq_c, Δs_c) 为相应的机器人状态增量与特征增量：Δq_c = q_c − q_0 与 Δs_c = s_c − s_0。这些增量分别堆叠为 ΔQ ∈ ℝ^{m×C} 与 ΔS ∈ ℝ^{n×C} 的列。对于足够小的运动，Δs_c ≈ JΔq_c（第 II-D 节），因此初始雅可比矩阵通过对全部测量对的最小二乘回归来估计：

Ĵ0 = arg min{J} ‖ΔS − JΔQ‖_F² = ΔSΔQ^+, (6)

其中 ‖·‖_F 表示 Frobenius 范数。若探索性运动张成输入空间（即它们共同激励机器人可运动的所有独立方向），则 ΔQ 满行秩，最小二乘解唯一。本教程中，我们通过逐一独立扰动每个驱动自由度来保证这一点。也可以使用更一般的探索性运动，只要其动作增量共同张成输入空间，即 rank(ΔQ) = m，这至少需要 C ≥ m 个运动。

探测幅度必须足够小，以使一阶近似 Δs_c ≈ JΔq_c 保持有效；又要足够大，以使产生的特征变化超过测量噪声。因此，回归残差 ‖ΔS − Ĵ_0ΔQ‖_F 量化了单一线性映射对所收集响应的解释程度。然而，小残差仅在探测构型附近局部支持该估计；随着物体变形，雅可比矩阵估计必须更新。

运行示例：离线雅可比矩阵估计。 两个夹爪各有三个自由度，共六个驱动自由度。对每个自由度，我们施加四个探索性运动：正方向两个、负方向两个，并使机器人在探测完一个自由度后回到初始状态 q_0。由此得到 C = 24 个动作–响应对。图 3 左面板展示了沿 x_L 方向的一个扰动及图像空间中产生的特征位移 Δs_c。中间面板中，扰动组装为 ΔQ ∈ ℝ^{6×24}，每列仅激励一个自由度，相应的测量响应构成 ΔS ∈ ℝ^{10×24} 的列。右面板展示拟合得到的雅可比矩阵 Ĵ_0，其残差 ‖ΔS − Ĵ_0ΔQ‖_F ≈ 0.31，约为 ‖ΔS‖_F ≈ 1.72 的 18%；即单一线性映射留下约 18% 的测量响应未被解释。

对 Ĵ_0 进行奇异值分解（SVD）可刻画机器人运动沿各方向改变形状的强弱。它将机器人运动方向与其产生的特征方向配对，每个方向的增益由奇异值 σ_l 给出。由于式 (4) 中的伪逆要除以这些增益，小奇异值可能将微小的特征误差放大为很大的机器人指令。条件数 σ_max/σ_min（最大与最小奇异值之比）概括了这种失衡；运行示例中，Ĵ_0 满列秩，条件数约为 17。本教程第二部分将进一步展开 SVD 分析，并用其解释形状伺服回路如何失效。

III-B 在线更新：Broyden 法则

随着物体变形，初始估计 Ĵ0 可能不再代表其当前的局部响应。若通过重复第 III-A 节的离线探测程序重新估计雅可比矩阵，则需要中断控制过程。相反，估计可以由闭环控制过程中已产生的数据更新：来自式 (5) 的每个控制动作 Δq{k−1} 都产生一个观测到的特征变化 Δsk。因此，这些动作–响应对可直接用于在线更新雅可比矩阵，无需额外探测，如图 2 中的在线更新模块所示。对最近一步，当前估计的预测误差为 r_k = Δs_k − Ĵ{k−1}Δq_{k−1}，Broyden 法则 [19] 将估计校正为

Ĵk = Ĵ{k−1} + (rk Δq{k−1}^⊤)/(Δq{k−1}^⊤ Δq{k−1}). (7)

该更新使新估计精确重现最近观测到的动作–响应对，即 Ĵk Δq{k−1} = Δsk，同时在 Frobenius 范数下尽可能少地改变 Ĵ{k−1}。

实际解读：利用控制运动与测量更新雅可比矩阵。 在控制过程中，每个指令机器人运动都提供关于物体如何变形的新数据。当前雅可比矩阵估计可用于预测形状特征的相应变化。再将该预测与感知测得的特征变化比较，得到预测误差。Broyden 法则利用该误差随操纵进程更新雅可比矩阵估计。同样的思想出现在未标定视觉伺服 [10] 以及无模型形状伺服的工作（如 [11, 12]）中。

注记 1（门控微小更新） 式 (7) 中校正的幅值（以 Frobenius 范数度量）为 ‖rk‖/‖Δq{k−1}‖，其中 ‖·‖ 表示向量的欧几里得范数。在模型平滑变化下，预测误差通常随指令步长减小而减小。然而，测量噪声并不随步长减小，因此除以非常小的指令可能产生过大的更新。因此，实际实现中当 ‖Δq_{k−1}‖ 低于最小阈值时跳过更新，并拒绝不合理过大的校正。

III-C 基于模型与混合估计

雅可比矩阵估计也可以由物体和机器人的力学、几何或学习模型获得：可以在每次迭代时获得，或作为初始估计再由 Broyden 更新在线精化。视模型而定，雅可比矩阵可以解析推导，也可以在仿真中复现第 III-A 节的离线估计程序来估计。这些模型还可以由控制期间收集的真实数据在线精化，例如通过参数估计。例子包括尽可能刚性模型 [8]、有限元模型和质量–弹簧模型。

此类基于模型方法的主要缺点在于，将模型与物理装置关联可能需要相机标定、物体的自然形态几何、足够精确的初始力学参数、抓取位置及其他约束，以及对可用驱动自由度的显式了解。这些要素中的任何误差也会影响雅可比矩阵估计。本教程的无模型方法避免了这些要求：它不需要显式物体模型、物理参数、相机–机器人标定或抓取构型的先验知识。无论哪种情形，闭环行为都取决于 Ĵ 代表当前局部响应的程度（第 IV-C 节）。

IV-A 完整的形状伺服回路

算法 1 说明了图 2 所示回路的步骤。从首次形状测量和初始估计 Ĵ_0 出发，每次迭代中控制器计算形状误差和控制动作（式 (5)）。机器人在一个控制周期内施加指令，随后测量所导致的形状变化并通过式 (7) 更新雅可比矩阵估计。回路持续运行，直到任务级监督器将其停止，例如当 ‖e_k‖ 低于选定容差时。

算法 1：在线基于雅可比矩阵的形状伺服

1:  输入：目标 s*，初始估计 Ĵ0，增益 α，周期 Δt
2:  测量 y0 并计算 s0 = f(y0)；k ← 0
3:  while true do
4:      ek ← s* − sk
5:      uk ← α Ĵk+ ek        ▷ 控制律 (5)
6:      施加 uk 持续 Δt；Δqk ← uk Δt
7:      测量 yk+1 并计算 sk+1 = f(yk+1)
8:      Δsk+1 ← sk+1 − sk
9:      Ĵk+1 ← 由 (Δqk, Δsk+1) 更新 Ĵk    ▷ (7)
10:     k ← k + 1
11: end while

回顾 Δs{k+1} 是对机器人指令 Δq_k 的测量响应。该动作–响应用于更新雅可比矩阵估计，后者再用于计算下一个控制指令。实践中，当 ‖Δq_k‖ 非常小时，算法 1 的第 8 行保持 Ĵ{k+1} = Ĵ_k 不变（注记 1）。

IV-B 目标可行性与可达性

并非每个目标形状都能用给定的操纵装置获得，无论采用何种控制律。机器人运动与工作空间、抓取构型、物理变形极限以及物体所能维持的平衡状态，都约束着可实现形状的集合。

用控制术语来说，若目标属于容许状态集合，则它是可行的；若存在容许输入轨迹将系统驱动至该目标状态，则它从给定初始状态是可达的。对于本文考虑的形状伺服问题，设 𝒮 ⊆ ℝ^n 表示在特定机器人装置、可变形物体及第 I-C 节引入的准静态假设下可实现的特征向量集合。若 s* ∈ 𝒮，则目标 s* 可行；若存在通往实现 s* 之构型的容许操纵路径，则它从当前构型可达。

可行性与可达性是全局性质，而控制器使用的变形雅可比矩阵是局部模型。由式 (3)，瞬时特征速度限于 Range(J)，其维数为 rank(J) ≤ min(n, m)。因此，雅可比矩阵刻画了当前构型下哪些形状变化是局部可达的，但它本身无法判定目标能否经由容许操纵路径从当前构型全局可达。同样的局部性也限定了下文闭环收敛性与稳定性分析的范围。

运行示例：可行性、可达性与残差误差。 运行示例有 n = 10 个特征维度和 m = 6 个驱动自由度，因此局部最多有六个独立的特征速度方向。图 4 比较了从同一初始状态出发的两个目标。第一个目标在另一个容许夹爪构型处记录，因此构造上可行。控制过程中误差收敛到零也证明该目标从给定初始状态可达。第二个目标通过修改第一个目标得到，将三个目标特征点位移至超出物体的容许变形极限，因此被认为不可行。

IV-C 局部稳定性与收敛性

为分析局部收敛性，我们假设目标形状固定，即 ṡ* = 0。首先考虑变形雅可比矩阵精确已知的理想情形，控制器使用 Ĵ = J。这提供了无雅可比矩阵估计误差的基线。然后考虑实际情形，控制器使用第 III 节所述方法获得的估计 Ĵ。两种情形下，结合式 (3) 与式 (4) 得到

ė = −α JĴ^+e. (8)

考虑李雅普诺夫候选函数 ℒ(e) = ½‖e‖²。其导数为 ℒ̇ = −αe^⊤JĴ^+e，故每当

e^⊤JĴ^+e > 0, (9)

误差范数即减小。

当 n ≤ m 时，满行秩雅可比矩阵在每个特征方向上都提供局部控制能力。理想情形下，Ĵ = J 且 JJ^+ = I_n（I_n 为 n×n 单位矩阵），完整特征误差指数收敛。对于估计的雅可比矩阵，一个便利的充分条件是 Sym(JĴ^+) ≻ 0，其中 Sym(A) = (A + A^⊤)/2，≻ 0 表示正定。实际而言，Ĵ 预测的特征运动方向必须与真实雅可比矩阵产生的方向保持足够对齐，使指令运动能够减小特征误差。n = m 为相应的方阵情形。

表 II：使用估计变形雅可比矩阵的局部稳定性与收敛性

n > m，最大秩 rank(J) = m 且 Sym(Ĵ^+J) ≻ 0 可控闭环模态指数收敛，e 趋于 Null(Ĵ^⊤) 中的残差。当精确已知雅可比矩阵（Ĵ = J）时，该残差成为 Null(J^⊤) 中的局部最小二乘残差，且当 e ∈ Range(J) 时为零。

当 n > m 时，任意特征误差一般无法被完全校正，因为机器人提供的独立运动方向少于特征坐标数。当精确已知雅可比矩阵（Ĵ = J）且 J 满列秩时，J^+e 是唯一的最小二乘机器人运动。矩阵 JJ^+ 是到 Range(J) 的正交投影算子：误差的局部可达分量被校正，而 Null(J^⊤) 中的任何分量作为最小二乘残差保留。此处 Null(J^⊤) 包含与 Range(J) 正交的特征误差方向。对于估计的雅可比矩阵，沿可用驱动方向的收敛由类似的充分条件 Sym(Ĵ^+J) ≻ 0 保证。Null(Ĵ^⊤) 中的误差不产生指令运动，因此估计误差也可能引入控制器停滞的方向。

前述收敛结果是局部的，即使在精确已知雅可比矩阵且局部驱动充分（m ≥ n 满行秩）的有利情形下亦然。变形雅可比矩阵是局部线性模型，其取值和秩一般随机器人与物体构型而变化。因此，不能假定上述秩与稳定性条件在任意操纵过程中始终成立。更大的变形还可能改变物体力学、引入分叉或接触变化、或使局部模型所依赖的假设失效。因此，该分析仅在模型与所述条件保持有效的局部区域内适用；当 e = 0 为闭环平衡时，该区域定义的是局部吸引域，而非全局收敛保证。

表 II 总结了这些局部条件；设 Ĵ = J 即恢复已知雅可比矩阵的情形。前两行假设真实雅可比矩阵具有最大秩，最后一行涵盖秩损失。

对于离散实现，局部收敛要求每个可控闭环模态保持在单位圆内。当 n ≤ m 时，这给出所有可控模态的 |1 − αΔt λ_i(JĴ^+)| < 1。当 n > m 时，相应条件为 |1 − αΔt λ_i(Ĵ^+J)| < 1。此处 λ_i(·) 表示相应矩阵的第 i 个特征值。当雅可比矩阵精确已知（Ĵ = J）且 J 具有最大秩时，相应的矩阵乘积在可控方向上退化为单位矩阵，得到条件 0 < αΔt < 2。

运行示例：闭环行为。 图 5 展示了 Δt = 1 时的形状控制过程。采用在线 Broyden 更新（式 (7)）时，Ĵ_k 随杆变形而更新，误差收敛到零。若 Ĵ_0 保持固定，则随着变形推进，估计的代表性下降，误差偏离标称衰减。增益对比说明了雅可比矩阵估计局部有效性的另一后果。当 α = 0.05 时，误差紧密跟随 (1−α)^k；而更大的增益会在更新之间产生更大的机器人运动，使当前雅可比矩阵估计作用于更大的形状变化范围而变得不够准确。当 α = 0.35 时，误差在收敛之前先增大。

V 结论

本教程给出了形状伺服的完整数据驱动、基于雅可比矩阵的表述，涵盖从形状表示与误差定义，到变形雅可比矩阵估计、在线自适应和闭环控制（图 2，算法 1）。核心思想是直接从机器人运动与测得的形状变化中估计控制器所需的局部输入–输出关系。这避免了对可变形物体显式力学模型的需求，同时保留了可由测量数据实现和分析的紧凑控制表述。

由此得到的保证本质上是局部的。变形雅可比矩阵仅在当前机器人–物体构型附近描述形状响应，其取值、秩和估计精度可能随物体变形而改变。在局部模型与所需秩条件保持有效的区域内，当估计的逆保持真实雅可比矩阵的校正方向时（式 (9)），反馈律可减小形状误差。充分的驱动可提供完整特征误差的局部收敛，而欠驱动或秩亏缺情形一般仅沿局部可达特征方向收敛，并可能留下残差误差。

第二部分更深入地展开这些假设背后的局限。特别地，它研究变形雅可比矩阵的秩损失与病态、所选形状特征的灵敏度不足，以及物体力学响应的变化。这些效应通过雅可比矩阵的奇异值结构相互关联，并用于刻画控制能力的丧失、形状灵敏度的丧失和力学不稳定性。第二部分还考虑将基本表述扩展至三维物体、时变目标或次要控制目标。
