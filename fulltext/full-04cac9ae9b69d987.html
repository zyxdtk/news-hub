中文摘要： 本文提出一种基于NeuralUCB的在线大语言模型（LLM）路由方法，旨在平衡推理成本与答案质量。通过将路由建模为上下文多臂老虎机问题，该方法在部分反馈下学习非线性路由策略，利用效用奖励函数实现成本-质量权衡。实验在RouterBench基准上进行，结果表明NeuralUCB在累积奖励和平均奖励上显著优于随机、最小成本及RouteLLM-BERT等基线，同时成本仅为最大质量策略的33%。该方法在探索与利用之间动态权衡，通过门控机制激活UCB奖励，有效提升路由效率。未来工作将聚焦于增强动作区分能力

**摘要**  
本研究探讨了使用 NeuralUCB 进行成本感知的大语言模型（LLM）路由。现有路由方法大致可分为监督路由方法和部分反馈方法，两者在效率和适应性方面各有权衡。我们实现了一种基于 NeuralUCB 的路由策略，并在模拟在线环境中使用 RouterBench 进行评估。实验结果表明，所提方法在效用奖励方面始终优于随机和最小成本基线。与最大质量参考相比，我们的方法在保持竞争性奖励的同时实现了显著更低的推理成本。这些发现表明，NeuralUCB 是一种有前景的成本感知 LLM 路由方法，同时也突显了在动作区分和探索方面仍存在的挑战。

1  
**问题定义**  
大语言模型（LLMs）在不同任务中表现出显著的能力和推理成本差异。高端模型通常以更高成本提供更高质量，而低成本模型可能在复杂推理或编码查询中失败。我们研究基于奖励的在线 LLM 路由，即动态为每个用户查询选择合适的 LLM，以平衡答案质量和推理成本。  
正式地，在交互轮次 $t$，系统观察到查询 $x_t$ 并从候选集 $\mathcal{A}=\{1,...,K\}$ 中选择模型 $a_t$。在我们的框架中，原始文本查询通过预训练的句子编码器映射到密集语义特征空间。由于部署通常每次查询仅调用一个模型，我们仅观察所选模型的反馈 $r_t = r(x_t, a_t)$，而不观察同一查询下其他模型的结果。目标是学习一个路由策略，以最大化长期期望效用：  
$\max_{\pi}\ \mathbb{E}\Big[\sum_{t=1}^{T}r(x_{t},a_{t})\Big],\qquad a_{t}\sim\pi(\cdot\mid x_{t})$.  
一个关键挑战是反馈稀疏，且从查询到最优模型选择的映射可能高度非线性。因此，我们将路由建模为上下文多臂老虎机问题，并采用 NeuralUCB 来学习一个非线性路由策略，以随时间提升平均效用和成本-质量权衡。

2  
**相关工作**  
LLM 路由旨在为每个查询动态选择合适的模型，以平衡答案质量和推理成本。代表性框架将路由视为将不同难度的查询分配给具有不同成本特征的模型，以降低平均推理成本（Ding 等，2024）。现有方法大致可分为两类。  
第一类是全信息监督路由，通过使用同一查询的多个候选模型输出和评分来训练路由器，如 RouterDC（Chen 等，2024）和 GraphRouter（Feng 等，2024）。尽管有效，但这些方法数据收集成本高，且在查询分布或模型池变化时通常需要重新标注和重新训练。  
第二类从部分反馈中学习，自然契合上下文多臂老虎机设置（Li 等，2010；Zhou，2015）。虽然 LinUCB 假设线性奖励，而核化方法（如 KernelUCB 或 GP-UCB）在高维嵌入下计算成本高，我们采用神经上下文多臂老虎机视角，使用 NeuralUCB 在部分反馈下高效学习非线性查询-模型映射，同时显式建模成本-质量权衡。为避免实时 API 实验的高昂成本，该框架在 RouterBench 基准上构建离线回放管道（Hu 等，2024）。这允许对在线环境进行稳健、分层模拟，实现对累积奖励、动作率和领域特定性能（如数学与编码）的持续跟踪。

3  
**方法论**  
3.1 **问题设定与效用函数**  
我们将成本感知的 LLM 路由形式化为上下文决策问题。对于每个输入样本，我们观察上下文表示：  
$x = (x_{\text{emb}}, x_{\text{feat}}, d)$，  
其中 $x_{\text{emb}}$ 表示文本编码器生成的提示嵌入，$x_{\text{feat}}$ 表示辅助特征，$d$ 表示样本领域。给定上下文 $x$，策略选择动作：  
$a \in \mathcal{A} = \{1,\dots,K\}$，  
来自一组候选 LLM。在我们的设定中，$K=11$。  
对于每个样本-动作对，我们考虑两个反馈信号：模型质量 $q(x,a)$ 和推理成本 $c(x,a)$。  
在我们的模拟在线 LLM 路由设定中，基准为每个样本提供所有候选模型的质量和成本，允许我们在固定数据流上比较不同动作的效用。  
我们的目标不是最大化模型质量本身，而是实现质量与成本之间的权衡。为此，我们定义效用奖励为：  
$r(x,a) = q(x,a)\exp\bigl(-\lambda\tilde{c}(x,a)\bigr)$，  
(1)  
其中 $\tilde{c}(x,a)$ 是归一化成本，$\lambda > 0$ 控制成本惩罚强度。为稳定奖励尺度，我们对原始成本应用对数归一化：  
$\tilde{c}(x,a) = \frac{\log\bigl(1+c(x,a)\bigr)}{\log\bigl(1+C_{\max}\bigr)}$，  
其中 $C_{\max}$ 表示数据集中观察到的最大成本。此变换将 $\tilde{c}(x,a)$ 映射到 $[0,1]$，并减少候选模型间大成本尺度差异引起的不稳定性。

图 1：UtilityNet 架构。效用分支预测每个上下文-动作对的效用奖励，而门控分支预测是否应激活基于 UCB 奖励的动作选择。  
如图 1 所示，UtilityNet 在我们的路由框架中作为效用预测器。给定上下文-动作对，它估计相应的效用奖励，其最后隐藏表示进一步用于 NeuralUCB 策略进行不确定性感知的动作选择。我们首先编码文本输入和辅助特征：  
$h_{\text{emb}} = f_{\text{text}}(x_{\text{emb}}),\qquad e_{d} = \mathrm{Emb}_{d}(d),\qquad h_{\text{feat}} = f_{\text{feat}}([x_{\text{feat}},e_{d}])$，  
其中 $f_{\text{text}}(\cdot)$ 和 $f_{\text{feat}}(\cdot)$ 分别表示文本和特征编码器，$\mathrm{Emb}_{d}(\cdot)$ 表示领域嵌入。  
对于效用预测，我们定义动作嵌入：  
$e_{a} = \mathrm{Emb}_{a}(a)$，  
并构建融合表示：  
$z_{u}(x,a) = [h_{\text{emb}}, h_{\text{feat}}, e_{a}]$。  
效用分支随后计算：  
$h(x,a) = f_{\text{mlp}}(z_{u}(x,a)),\qquad\mu(x,a) = f_{\text{u-head}}(h(x,a))$，  
并使用 Huber 损失回归方程 (1)：  
$\mathcal{L}_{u} = \mathrm{Huber}\bigl(\mu(x,a),r(x,a)\bigr)$。  
此外，我们基于上下文相关表示包含一个辅助门控分支：  
$z_{g}(x) = [h_{\text{emb}}, h_{\text{feat}}]$，  
预测：  
$p(x) = f_{\text{g-head}}\bigl(f_{\text{gate}}(z_{g}(x))\bigr)$。  
门控头使用二元交叉熵损失进行训练：  
$\mathcal{L}_{g} = \mathrm{BCE}\bigl(p(x),y_{\text{gate}}(x)\bigr)$。

3.3 **基于 NeuralUCB 的路由策略**  
基于 UtilityNet 提供的效用预测，我们进一步采用 NeuralUCB 进行动作选择。具体而言，对于每个上下文-动作对，我们使用 UtilityNet 生成的最后隐藏表示 $h(x,a)$ 作为 UCB 的特征表示，并定义增强特征：  
$g(x,a) = [h(x,a); 1]$，  
其中附加的常数 1 作为偏置项。我们不为每个动作维护独立的不确定性统计，而是使用共享的逆协方差矩阵 $A^{-1}$ 来估计最后一层特征空间中的不确定性。  
在此设定下，动作 $a$ 的 UCB 得分为：  
$s(x,a) = \mu(x,a) + \beta\sqrt{g(x,a)^{\top}A^{-1}g(x,a)}$，  
其中 $\mu(x,a)$ 是 UtilityNet 预测的效用得分，$\beta$ 控制探索奖励的强度。因此，NeuralUCB 倾向于选择预测效用高且不确定性高的动作。  
除了 UCB 得分，我们还定义一个保守的后备动作：  
$a^{\text{safe}} = \arg\max_{a\in\mathcal{A}}\mu(x,a)$，  
该动作仅基于预测的平均效用选择。使用门控分支生成的门控概率 $p(x)$，最终动作选择规则为：  
$a^{*} = \begin{cases}\arg\max_{a\in\mathcal{A}}s(x,a),&p(x)\geq\tau_{g},\\
a^{\text{safe}},&\text{otherwise},\end{cases}$  
其中 $\tau_{g}$ 表示门控阈值。换句话说，仅当门控分支预测探索有益时，策略才激活基于 UCB 奖励的动作选择；否则，回退到基于均值的安全动作。  
我们通过将数据划分为 20 个切片并顺序处理，在模拟在线设定下训练路由策略。对于每个切片，策略选择动作，更新回放缓冲区和共享 $A^{-1}$，然后使用累积缓冲区数据训练 UtilityNet 并重建 $A^{-1}$，如算法 1 所总结。

算法 1 模拟在线协议（决定、更新、训练）。  
1: 切片 $\{\mathcal{D}_{t}\}_{t=1}^{20}$，动作 $\mathcal{A}=\{1,\ldots,11\}$，回放轮次 $E=5$  
2: UtilityNet: 均值 $\mu_{\theta}(x,a)$，最后隐藏 $h_{\theta}(x,a)$，门控概率 $p_{\theta}(x)$  
3: 共享 UCB 统计: $A^{-1}$，超参数 $\beta,\lambda,\tau_{g}$  
4: 初始化缓冲区 $\mathcal{B}\leftarrow\emptyset$  
5: 初始化 $A^{-1}\leftarrow\frac{1}{\lambda_{0}}I$  
6: for $t=1$ to $20$ do  
7: for 每个样本 $i\in\mathcal{D}_{t}$ do  
8: $a_{i}\leftarrow\textsc{Decide}(x_{i};\theta,A^{-1},\beta,\tau_{g})$  
9: $\textsc{Update}(\mathcal{B},A^{-1};i,a_{i},\theta)$  
10: end for

4  
**实验**  
4.1 **实验设定**  
我们在 RouterBench 上评估所提方法，该基准包含 36,497 个样本、86 个领域和 11 个候选 LLM。对于每个样本，基准提供所有候选模型的质量得分和推理成本。我们通过将数据划分为 20 个切片并顺序处理，采用模拟在线协议。在每个切片之后，UtilityNet 在回放缓冲区上训练 5 轮，随后重建共享 $A^{-1}$。  
我们使用 all-MiniLM-L6-v2（Wang 等，2020）作为文本编码器，学习率 $10^{-3}$，UCB 奖励系数 $\beta=1$，岭回归系数 $\lambda=1$。为比较，我们使用三个基线：随机、最小成本和 RouteLLM-BERT（Ong 等，2024）。对于 RouteLLM-BERT，我们构建一个二元路由设置，其中强模型和弱模型分别定义为平均效用奖励最高和最低的模型。
