摘要

迭代精化是基于扩散生成的关键能力，并推动了将类似行为引入离散扩散和流模型的大量努力。越来越多的工作通过允许在采样过程中修改先前生成的 token 来实现这种精化，从而塑造连续采样状态之间的耦合。尽管这种耦合自由度在采样器设计中日益重要，但其仍未得到充分刻画。我们引入活动几何（Activity Geometry），通过期望转移代价（我们称之为活动度（activity））来研究这些有限步耦合。我们证明活动度可分解为诱导边际传输所需的最小值与由耦合产生的超额项之和。以该最小值为参考，我们提出最小活动度有限时间耦合（Minimal-Activity Finite-Time Coupling, MAFTC），无需重训练或额外模型评估即可实现具有最小活动度的规定边际。在连续时间极限下，单位时间的最小活动度收敛到与规定路径兼容的最小期望跳跃率。对于度量诱导的吉布斯路径，我们进一步证明动力学最优通量的活动度具有几何分解。我们发现总活动度本身可能掩盖耦合超额：采样器可能接近规定边际传输所需的最小活动度，同时仍保留大量耦合超额。在语言生成中，随着模型评估次数的增加，基于精化的采样器会累积额外的轨迹活动度而多样性增益有限，而 MAFTC 在保持可比生成质量和更高词汇多样性的同时降低轨迹活动度。

1 引言

离散扩散（Austin et al., 2021; Lou et al., 2024）和流（Gat et al., 2024; Shaul et al., 2024）模型为迭代精化提供了框架，采样器（Campbell et al., 2022）执行连续的 token 更新。在每一步，采样器使用模型预测来指定保留当前 token 值或用新值替换它们的概率（Gat et al., 2024; Shaul et al., 2024）。特别地，可以设计采样规则以允许修改先前生成的 token，从而提供一种迭代精化机制。

目前，实现迭代精化的努力涵盖掩码扩散和均匀状态扩散的采样方法，以及概率路径设计。在掩码扩散（Shi et al., 2024）中，MDLM（Sahoo et al., 2024）使用的祖先采样器在 token 解掩码后保持其固定；ReMDM（Wang et al., 2025a）则使这些 token 能够被重新掩码和重新采样，缩小了文本生成中与自回归模型的样本质量差距。同时，均匀状态扩散（Hoogeboom et al., 2021; Austin et al., 2021; Sahoo et al., 2025）允许生成的 token 直接转移到其他 token 值。Ψ-采样器（Deschenaux et al., 2026）进一步将预测-校正采样扩展到任意噪声先验，并且在均匀状态模型中，随着采样步数的增加持续提高样本质量。此外，概率路径设计提供了一条互补路线：FUDOKI（Wang et al., 2025b）使用度量诱导路径和动力学最优速度（Shaul et al., 2024），在视觉理解和图像生成的统一模型中实现迭代精化。

给定输入分布，每个采样规则都会诱导一个耦合，即连续采样状态的联合分布。这些修改机制提供了额外的耦合选择，创造了纠正的机会，同时也允许重复的 token 变更。Yuan et al. (2026) 表明随机转移可以在保持规定时间边际的同时收缩采样误差。同时，Xiang et al. (2026) 发现了翻转振荡现象，即 token 被重新掩码随后又恢复到先前的值，并表明这些振荡性修改可以在保持生成质量的同时减少。然而，耦合选择如何塑造采样过程中的 token 移动尚未得到系统研究。

为此，我们引入活动几何，这是一个通过期望转移代价（我们称之为活动度）来分析有限步耦合的框架。我们的主要贡献如下：

（i）有限时间活动几何。 我们将采样器设计形式化为规定条件边际之间耦合的选择。活动几何为这种选择提供了最小活动度参考，导出了闭式的最小活动度有限时间耦合（MAFTC）构造。我们将采样器的活动度分解为其诱导边际传输所需的最小值和其耦合引入的超额，并以全变差量化诱导输出边际与规定输出边际之间的边际失配。MAFTC 在离散失配代价下以最小活动度精确传输规定的类别边际。我们将这种最优性扩展到加权汉明代价下因子化条件边际之间的转移，得到一个无需重训练或额外模型评估的预训练离散生成模型采样器。

（ii）动力学最优动力学中的超额活动度。 我们将有限时间活动度分解扩展到瞬时跳跃率，将超额活动度与离散化误差分离。在 FUDOKI 使用的度量诱导吉布斯路径上，即使每次跳跃都接近端点，动力学最优动力学仍可能具有超额活动度。我们精确识别了哪些转移导致了这种超额。

（iii）轨迹活动度与生成质量。 我们在预训练图像和语言模型中发现，可以用显著更少的 token 变更实现可比的生成质量。在我们的文本实验中，随着采样步数的增加，MAFTC 的轨迹活动度降低，而两个基线采样器 Duo+DCD 和 Ψ 累积更多的 token 变更。在相似的生成困惑度下，MAFTC 还实现了比两个基线更高的语料库级多样性。

2 背景：离散流匹配

设 𝒯=[V]≜{1,…,V} 为我们的词汇表。状态空间由 𝒳=𝒯^D 给出，其中 D∈ℕ 为序列长度。我们考虑序列 x=(x¹,…,x^D)∈𝒳 上的离散生成建模，其中 x^i∈𝒯 表示位置 i 处的 token。

概率路径。 我们将 𝒳 上的源概率质量函数（PMF）和数据 PMF 分别记为 p₀ 和 p₁，并考虑因子化的源分布 p₀(x)=∏ᵢ₌₁^D p₀ⁱ(xⁱ)。遵循离散流匹配（Gat et al., 2024; Shaul et al., 2024），我们考虑在 p₀ 和 p₁ 之间插值的概率路径 (pₜ)_{t∈[0,1]}。我们通过引入数据端点 A∼p₁ 并对其实现 a∈𝒳 上的条件概率路径进行边际化来构造该路径：

pₜ(x) = ∑_{a∈𝒳} pₜ(x|a) p₁(a)， pₜ(x|a) = ∏ᵢ₌₁^D pₜⁱ(xⁱ|aⁱ)。 (1)

我们将 (pₜ){t∈[0,1]} 称为边际概率路径。对每个坐标 i，条件概率路径 pₜⁱ(·|aⁱ) 在源边际 p₀ⁱ 与 aⁱ 处的点质量之间插值，满足边界条件 p₀ⁱ(·|aⁱ)=p₀ⁱ 和 p₁ⁱ(·|aⁱ)=δ{aⁱ}，其中 δ_b(z)=𝟙{z=b} 表示 b 处的点质量。

概率速度与通量。 我们用时间非齐次连续时间马尔可夫链（CTMC）(Xₜ)_{t∈[0,1]} 建模生成动力学，其时间边际遵循规定的概率路径：Xₜ∼pₜ, t∈[0,1]。(2)

其无穷小动力学由概率速度 uₜ 控制，也称为速率矩阵（Gat et al., 2024; Shaul et al., 2024）。使用目标优先约定，uₜ(y,x) 表示从状态 x 到状态 y 的瞬时转移速率，因此对于小的 h>0：

Pr(X_{t+h}=y | Xₜ=x) = δₓ(y) + h·uₜ(y,x) + o(h)， h↓0， (3)

其中 o(h)/h→0，uₜ(y,x)≥0（对于 y≠x），且 ∑y uₜ(y,x)=0。当相关 CTMC 在每个 t 处具有时间边际 pₜ 时，我们说 uₜ 生成概率路径 (pₜ){t∈[0,1]}。

我们将 CTMC 限制为每次最多改变一个 token 的转移。对每个坐标 i，我们用 uₜⁱ(yⁱ,x) 表示从 x 到将 xⁱ 替换为 yⁱ≠xⁱ 而其余坐标保持不变所得到状态的转移速率。对角项设为 uₜⁱ(xⁱ,x) := −∑_{z∈𝒯∖{xⁱ}} uₜⁱ(z,x)。组合这些逐坐标速率得到 𝒳 上的概率速度：

uₜ(y,x) = ∑ᵢ₌₁^D uₜⁱ(yⁱ,x) ∏{j≠i} δ{xʲ}(yʲ)。 (4)

因此，对于 x≠y，当 x 和 y 在多于一个坐标上不同时，速率 uₜ(y,x) 为零；当它们仅在坐标 i 上不同时，等于 uₜⁱ(yⁱ,x)。我们定义概率通量 jₜ(y,x) := pₜ(x)uₜ(y,x)，其非对角项量化了每单位时间从状态 x 移动到状态 y 的概率质量。边际演化由连续性方程（也称为 Kolmogorov 前向方程）控制：

ṗₜ(y) = ∑{x≠y} jₜ(y,x) − ∑{x≠y} jₜ(x,y)， ṗₜ(y) := d/dt pₜ(y)。 (5)

对于固定的概率路径，该方程仅确定每个状态处的净通量，而非各个成对通量 jₜ(y,x)。因此，不同的概率速度可以生成相同的概率路径（Shaul et al., 2024）。

后验预测与边际速度。 遵循 Gat et al. (2024); Shaul et al. (2024) 的边际化构造，我们通过关于端点后验对条件速度进行边际化来获得边际速度。对每个坐标 i，设 uₜⁱ(yⁱ,xⁱ|aⁱ) 为生成 pₜⁱ(·|aⁱ) 的条件速度，相应的边际速度为：

uₜⁱ(yⁱ,x) = ∑_{aⁱ∈𝒯} uₜⁱ(yⁱ,xⁱ|aⁱ) p¹ⁱ|ₜ(aⁱ|x)。 (6)

然后我们通过式 (4) 组合这些边际速度，得到生成边际概率路径的概率速度 uₜ。这里 p¹ⁱ|ₜ(·|x) 是第 i 个 token 的端点后验：

p¹ⁱ|ₜ(aⁱ|x) := Pr(Aⁱ=aⁱ | Xₜ=x) = ∑{a'∈𝒳} δ{aⁱ}(a'ⁱ) pₜ(x|a')p₁(a')/pₜ(x)， pₜ(x)>0。 (7)

由于这些端点后验依赖于未知的数据分布 p₁，实际的离散流模型用参数为 θ 的学习到的因子化后验来近似它们：

q_θ(a|x,t) = ∏ᵢ₌₁^D q_{θ,i}(aⁱ|x,t)， (8)

其中每个 q_{θ,i}(·|x,t) 以完整当前状态 x 为条件，近似 p¹ⁱ|ₜ(·|x)。

时间网格上的采样。 对于 PMF ν 和 𝒳 上的马尔可夫核 K，我们记 (νK)(y) := ∑x ν(x)K(y|x) 为将 K 应用于 ν 得到的边际。对于 0≤t<s≤1，我们将 CTMC 转移核记为 P{s|t}(y|x) := Pr(X_s=y | Xₜ=x)，它满足 pₜP_{s|t} = p_s。实际采样器在 N 个采样区间的网格 0=t₀<⋯<t_N=1 上操作，使用由模型预测构造的核 K_{tₙ,tₙ₊₁}。一种方法是近似选定的 CTMC 转移 P_{tₙ₊₁|tₙ}。欧拉型方案（Campbell et al., 2022; Shaul et al., 2024）在每个区间开始时冻结转移速率，而校正方案（Wan et al., 2026; Fu and Fan, 2026）在此近似中加入区间内校正。另一种方法是直接在规定的条件边际之间选择有限时间耦合，如下面 MAFTC 所做的那样。

将 K_{tₙ,tₙ₊₁} 应用于规定的时间边际 p_{tₙ} 得到诱导输出边际：

p̃{tₙ₊₁} = p{tₙ}K_{tₙ,tₙ₊₁}。 (9)

然而，在 rollout 过程中，同一核作用于采样器的当前时间边际，后者可能已经与 p_{tₙ} 不同。我们使用函数评估次数（NFE）来衡量采样预算；附录 E 指定了无分类器引导下的计数约定。

3 有限时间活动几何

我们通过将有限时间转移的期望代价与其输入和输出边际联系起来来发展活动几何。我们首先将诱导边际传输所需的最小活动度与耦合超额分离，并将活动度与边际失配联系起来。然后我们构造 MAFTC 并将其扩展到因子化条件概率路径。

3.1 转移核与最小活动度参考

我们首先考虑状态空间为 𝒯 的单个类别变量，并在第 3.4 节将构造扩展到 𝒳=𝒯^D 中的序列。设 p 和 q 分别表示输入和规定的输出边际。我们考虑 𝒯 上的马尔可夫核 K，其中对所有 x,y∈𝒯 有 K(y|x)≥0，且对每个 x∈𝒯 有 ∑_{y∈𝒯} K(y|x)=1。

定义 3.1（有限时间转移与活动度）。 对于 X∼p 和 Y|X∼K(·|X)，我们定义诱导耦合 π_K 和诱导输出边际 q̃ 为：

π_K(x,y) = p(x)K(y|x)， q̃(y) = (pK)(y) = ∑_x p(x)K(y|x)。

对于非负转移代价 d: 𝒯×𝒯→[0,∞)，K 在输入边际 p 下的活动度为 A_d(K) := 𝔼_{π_K}[d(X,Y)]。对于离散失配代价 d(x,y)=𝟙{x≠y}，我们将其缩写为 A(K) = Pr_{π_K}(X≠Y)。

设 Γ(p,q) 表示 p 和 q 的耦合集合。根据经典的极大耦合恒等式（Griffeath, 1975; Thorisson, 2000; Jacob, 2021），将 p 传输到 q 所需的最小活动度为：

A_min(p,q) := min_{π∈Γ(p,q)} Pr_π(X≠Y) = TV(p,q) = (1/2)∑_x |p(x)−q(x)|， (10)

其中 TV 表示全变差距离。极大耦合为每个状态 x 的 X=Y=x 分配质量 min{p(x),q(x)}，因此剩余的概率质量对应于状态变更。附录 A 给出了推导并刻画了最小化耦合。

3.2 诱导边际、边际失配与耦合超额

马尔可夫核不必实现规定的输出边际 q。在 p 和 q 固定的情况下，我们区分到达诱导边际 q̃=pK 所需的最小活动度与到达 q 所需的最小活动度：

A_ind(K) := A_min(p,q̃)， A_pres := A_min(p,q)， ε(K) := TV(q̃,q)。 (11)

边际失配 ε(K) 衡量诱导输出边际 q̃ 与规定输出边际 q 之间的全变差距离。由于 π_K∈Γ(p,q̃)，式 (10) 给出 A(K) = Pr_{π_K}(X≠Y) ≥ A_min(p,q̃) = A_ind(K)。我们将耦合超额活动度定义为 χ(K) := A(K) − A_ind(K)，得到：

A(K) = A_ind(K) + χ(K)， χ(K) ≥ 0。 (12)

该分解将到达 q̃ 所需的最小活动度与耦合引入的额外变更分离；ε(K) 单独衡量边际失配。特别地，低于 A_pres 的活动度意味着非零的边际失配。我们用 [z]₊ := max{z,0} 表示标量 z 的正部。

命题 3.2（边际失配界）。 对于 𝒯 上的 PMF p,q 和 𝒯 上的任意马尔可夫核 K：

A(K) + ε(K) ≥ A_pres， ε(K) ≥ [A_pres − A(K)]₊。 (13)

对每个 b∈[0,A_pres]，存在马尔可夫核 K_b 使得 A(K_b)=b 且 ε(K_b)=A_pres−b。

当诱导边际转移需要较少活动度时，接近 A_pres 的总活动度仍可能包含大量耦合超额。附录 A 证明了该界及其尖锐性。

3.3 最小活动度有限时间耦合

我们现在构造一个以活动度 A_pres 将 p 映射到 q 的核，使得 ε(K) 和 χ(K) 均为零。在每个状态 x 处，我们保留公共质量 c(x) := min{p(x),q(x)}，并定义损失残差 r⁻(x) := [p(x)−q(x)]₊ 和增益残差 r⁺(x) := [q(x)−p(x)]₊。它们分别是需要从状态 x 移除和添加到状态 x 的质量。由于 p 和 q 的总和均为一，移除的总质量等于添加的总质量：τ := ∑_x r⁻(x) = ∑_x r⁺(x) = TV(p,q)。

对于 τ>0，我们在每个状态保留 c(x)，并将来自每个损失状态 x 的质量 r⁻(x) 按比例 r⁺(y) 分配给增益状态 y。得到的耦合 π^MA（MA 表示最小活动度）为：

π^MA(x,x) = c(x)， π^MA(x,y) = r⁻(x)r⁺(y)/τ （x≠y）。 (14)

我们将此构造称为最小活动度有限时间耦合（MAFTC）。对于 τ>0 和 p(x)>0，对每行归一化得到马尔可夫核：

K^MA(y|x) = min{p(x),q(x)}/p(x)（y=x）； r⁻(x)r⁺(y)/(τp(x))（y≠x）。 (15)

如果 τ=0，则 p=q，我们使用对角耦合 π^MA(x,y)=p(x)δₓ(y) 和恒等核 K^MA(y|x)=δₓ(y)。对于 τ>0，我们还在 p(x)=0 的行上设 K^MA(·|x)=δₓ，这些行不影响诱导耦合。

命题 3.3（MAFTC 的边际精确性与活动度最优性）。 对于 𝒯 上的 PMF p,q，MAFTC 耦合具有边际 p,q 和失配概率 TV(p,q)。其核满足 pK^MA=q 且 ε(K^MA)=χ(K^MA)=0。

对于 p(x)>0，该核以概率 min{1, q(x)/p(x)} 保留 x。当发生移动时，它从 r⁺/τ 中抽取目标。该规则需要 O(V) 的工作量来构造和从残差分布中采样，而无需构造 V×V 耦合矩阵。附录 A 证明了该命题。

3.4 Token 序列与条件采样

我们使用可加代价将类别构造扩展到 𝒳=𝒯^D 中的序列。对于正坐标权重 w₁,…,w_D，定义加权汉明距离 d_{H,w}(x,y) := ∑ᵢ₌₁^D wᵢ𝟙{xⁱ≠yⁱ}。

命题 3.4（最小加权汉明活动度）。 设 p=⨂ᵢ₌₁^D pⁱ 和 q=⨂ᵢ₌₁^D qⁱ 为 𝒳 上的 PMF，其中 pⁱ,qⁱ 是它们的坐标边际。每个耦合 Π∈Γ(p,q) 满足：

𝔼_Π[d_{H,w}(X,Y)] ≥ ∑ᵢ₌₁^D wᵢ·TV(pⁱ,qⁱ)。 (16)

逐坐标 MAFTC 耦合的乘积达到等式，因此在所有序列耦合（包括具有跨坐标依赖的耦合）中是最优的。

我们将此结果应用于式 (1) 中的因子化条件概率路径。固定数据端点 a∈𝒳 和采样时间 0≤t<s≤1。对每个坐标 i，从时间边际 pₜⁱ(·|aⁱ) 和 p_sⁱ(·|aⁱ) 构造 Kᵢ^MA。它们的乘积 K^a_{t,s}(y|x) := ∏ᵢ₌₁^D Kᵢ^MA(yⁱ|xⁱ) 满足：

pₜ(·|a)K^a_{t,s} = p_s(·|a)， (17)

并最小化这些条件时间边际之间的期望加权汉明距离。附录 A 给出了证明以及不需要因子化边际的活动度和边际失配的逐坐标界。

上述最小活动度保证适用于每个固定端点转移。为了恢复边际路径，我们用精确的联合端点后验 p₁|ₜ(a|x) := Pr(A=a | Xₜ=x) 对 K^a_{t,s} 进行平均。对于 pₜ(x)>0，贝叶斯法则给出 pₜ(x)p₁|ₜ(a|x) = p₁(a)pₜ(x|a)；因此核 K^⋆{t,s}(y|x) := ∑_a p₁|ₜ(a|x)K^a{t,s}(y|x) 满足 pₜK^⋆_{t,s} = p_s。

算法 1 则从学习到的因子化后验 q_θ 独立采样端点 token 并并行应用条件核，每个区间使用一次模型评估。我们将 tₙ 处的采样器状态记为 X̂ₙ，可选的条件输入记为 ξ。附录 C 给出了所得核并证明了联合后验构造的精确性；附录 D 描述了实现。

4 动力学最优流的活动几何

我们使用第 3 节的最小活动度参考来检验遵循规定概率路径且每次跳跃都接近端点的动力学是否也最小化活动度。为此，我们将有限时间分解扩展到连续时间马尔可夫动力学，将路径兼容的最小期望跳跃率与超额跳跃活动度分离。然后我们对度量诱导吉布斯路径上的动力学最优动力学精确刻画这种超额。

4.1 从有限时间超额到超额跳跃活动度

对于 CTMC，期望跳跃率通常称为动力学活动度或流量（Shiraishi et al., 2018; Maes, 2020; Van Vu and Saito, 2023）。我们考虑 𝒯 上可微的概率路径 (pₜ)_{t∈[0,1]} 并固定内部时间 t。遵循 Shaul et al. (2024) 的通量表述，如果非对角概率通量 jₜ(y,x) 非负、在 pₜ(x)=0 时为零且满足连续性方程，我们称其为容许的。其瞬时活动度 𝒜ₜ(j) 是每单位时间的总概率通量，因此约束和目标为：

ṗₜ(y) = ∑{x≠y} jₜ(y,x) − ∑{x≠y} jₜ(x,y)， 𝒜ₜ(j) := ∑_{x≠y} jₜ(y,x)。 (18)

我们将状态 x 处净概率增益和损失的速率分别记为 gₜ(x) := [ṗₜ(x)]₊ 和 ℓₜ(x) := [−ṗₜ(x)]₊。由于 ∑_x ṗₜ(x)=0，它们的总速率相等。共同速率 Mₜ := ∑_x gₜ(x) = ∑_x ℓₜ(x) = (1/2)‖ṗₜ‖₁ 衡量每单位时间必须重新分配的概率质量，其中 ‖ṗₜ‖₁ = ∑_x |ṗₜ(x)|。

命题 4.1（瞬时最小活动度）。 ṗₜ 的每个容许通量满足：

𝒜ₜ(j) ≥ Mₜ = (1/2)‖ṗₜ‖₁。 (19)

对于 Mₜ>0，等式由下式达到：

jₜ^MA(y,x) = ℓₜ(x)gₜ(y)/Mₜ， x≠y。 (20)

等号成立当且仅当所有非零通量从 ṗₜ<0 的状态移动到 ṗₜ>0 的状态，且逐状态流出为 ℓₜ、流入为 gₜ。若 Mₜ=0，零通量是唯一的最小化者。

对于具有边际路径 pₜ 和通量 jₜ 的 CTMC，设 P_h := P_{t+h|t} 为其精确转移核。则 pₜP_h = p_{t+h} 且 ε(P_h)=0。在式 (3) 的短时展开下：

A(P_h)/h → 𝒜ₜ(j)， TV(pₜ,p_{t+h})/h → Mₜ。 (21)

因此式 (12) 给出超额跳跃活动度：

χ_ct(j) := 𝒜ₜ(j) − Mₜ = lim_{h↓0} χ(P_h)/h ≥ 0。 (22)

pₜ 和 p_{t+h} 之间的 MAFTC 耦合 π^MA_{t,t+h} 满足：对于 x≠y 和 Mₜ>0，π^MA_{t,t+h}(x,y)/h → jₜ^MA(y,x)。附录 A.5 证明了这些陈述。

4.2 动力学最优吉布斯流中的超额活动度

我们将式 (1) 特化到 Shaul et al. (2024) 的度量诱导吉布斯路径，这些路径也被 FUDOKI（Wang et al., 2025b）使用。省略坐标索引，我们固定端点 token a∈𝒯 和有限非负端点距离分数 ρ(x,a)，其中 ρ(a,a)=0<ρ(x,a)（对于 x≠a）。使用逆温度 β≥0 作为路径参数：

p_β(x|a) = e^{−βρ(x,a)}/Z_a(β)， Z_a(β) := ∑_{z∈𝒯} e^{−βρ(z,a)}。 (23)

路径从均匀源开始并收敛到 δ_a。我们写 p_β = p_β(·|a)，并令 μ(β) := ∑_x p_β(x)ρ(x,a) 表示 p_β 下的平均端点距离分数。

对于逆温度 βₜ<β_s 的采样时间 t<s，比较两个吉布斯边际得到阈值：

ρ*{t,s} = (1/(β_s−βₜ)) ∫{βₜ}^{β_s} μ(b) db， (24)

它分离了第 3 节中有限步损失和增益残差的支撑：当 ρ(x,a)>ρ_{t,s} 时状态 x 损失概率质量，当 ρ(x,a)<ρ_{t,s} 时状态 x 增益概率质量（附录 B）。当 β_s↓βₜ 时，阈值收敛到 μ(βₜ)。在固定 β 处，我们将 μ(β) 缩写为 μ。恒等式 ∂_β p_β(x) = (μ−ρ(x,a))p_β(x) 给出相应的瞬时损失和增益集合；ρ(x,a)=μ 的状态具有零概率导数。

动力学最优（KO）概率速度最小化 Shaul et al. (2024) 的对称动能目标，诱导通量：

j_β^KO(y,x) = p_β(x)p_β(y)[ρ(x,a)−ρ(y,a)]₊， x≠y， (25)

其中正部因子将跳跃限制到端点距离分数较小的状态。我们将得到的活动度 𝒜_KO 与同一吉布斯路径兼容的最小值 𝒜_MA 进行比较。

为了识别哪些转移对超额跳跃活动度 χ_ct 有贡献，我们用阈值 μ 将状态划分为 H := {x: ρ(x,a)>μ} 和 L := {x: ρ(x,a)≤μ}，将中性状态包含在 L 中。

定理 4.2（动力学最优动力学中超额活动度的定位）。 对于式 (23) 中的吉布斯路径，从 H 到 L 的总动力学最优通量等于最小活动度：

∑_{x∈H, y∈L} j_β^KO(y,x) = 𝒜_MA。 (26)

超额跳跃活动度等于 H 内和 L 内的总通量：

χ_ct(j_β^KO) = 𝒜_KO − 𝒜_MA = ∑{x,y∈H, x≠y} j_β^KO(y,x) + ∑{x,y∈L, x≠y} j_β^KO(y,x)。 (27)

该定理表明，即使每次跳跃都减少端点距离分数，超额跳跃活动度也可能来自通过中间状态的概率传输。在保持吉布斯路径的同时消除组内转移需要重新分配跨组通量，使每个状态的概率导数不变。用可微非减调度 βₜ 重新参数化路径将所有通量和活动度速率缩放 β̇ₜ，在 βₜ<∞ 处保持分解不变（附录 B）。

5 实验

我们首先评估活动度分解和动力学最优动力学中超额活动度的定位。然后我们在采样精度、生成质量、多样性和推理成本方面比较 MAFTC 与基线采样器。附录 E 提供了完整的协议和结果。

设置。 在冻结的 FUDOKI（Wang et al., 2025b）上，我们将 MAFTC 与欧拉和时间校正（TC）采样（Wan et al., 2026）进行比较，两者均通过离散化连续时间跳跃率获得。在通过离散一致性蒸馏（DCD）（Sahoo et al., 2025）获得的 Duo 检查点上，我们将 MAFTC 与祖先采样（Duo+DCD）和 Ψ（Deschenaux et al., 2026）进行比较，两者均源自有限时间条件后验。在每个模型内，方法在匹配的 NFE 下共享检查点、路径、网格、截断和解码设置。

我们使用 GenEval 评估图像生成，报告其六个任务的平均准确率。每个图像配置包含 553 个 GenEval 提示（Ghosh et al., 2023）各四个样本。对于文本，我们报告 GPT-2-large 下的生成困惑度和池化 Dist-4，即所有生成序列中不同 token 四元组的数量除以这些序列中四元组出现的总次数。每个文本配置包含 2,048 个长度为 1,024 token 的序列。

轨迹测量。 为了描述 rollout 过程中实现的 token 变更，我们使用无权重汉明距离 d_H(x,y) := ∑ᵢ₌₁^D 𝟙{xⁱ≠yⁱ}。我们定义轨迹活动度 L_act、净位移 D_net 和轨迹超额 R_traj：

L_act = ∑ₙ₌₀^{N−1} d_H(X̂ₙ, X̂ₙ₊₁)， D_net = d_H(X̂₀, X̂_N)， R_traj = L_act − D_net ≥ 0。 (28)

三角不等式使 R_traj 非负。它衡量超出初始到最终距离的汉明路径长度，并且即使每次转移都最小化活动度也可能为正，因为一个 token 可以在轨迹上多次变更。这些量描述单个采样轨迹，而 A(K) 和 χ(K) 是在指定输入边际和核下的期望。这些轨迹量的平均值描述采样器当前时间边际下的 rollout，后者可能与规定的时间边际不同。对于每个生成的样本，L_act 计算整个采样轨迹上的 token 变更。我们将这些计数在生成样本上的平均值报告为 NTC。NFE 计数模型评估。

6 相关工作

跳跃目标与有限时间耦合。 Campbell et al. (2024) 为均匀和掩码条件路径构造跳跃最小化生成器，而 Haxholli et al. (2026) 在跳跃代价目标下优化源-目标训练耦合。对于规定路径，广义离散路径（Shaul et al., 2024）最小化对称动能；我们识别了度量诱导吉布斯路径上所得动力学中负责超额活动度的转移。在有限步中，极大耦合出现在学习的加噪过程（Bartosh et al., 2026）和均匀扩散桥（Song et al., 2021; Gourevitch et al., 2026）中。MAFTC 将此原理应用于规定的条件边际。我们的框架将活动度分解为诱导边际传输所需的最小值和耦合超额，同时单独衡量边际失配。

修改与误差纠正。 ReMDM（Wang et al., 2025a）和 Ψ-采样器（Deschenaux et al., 2026）通过预测-校正采样实现修改。Yuan et al. (2026) 分析了收缩采样误差的边际保持随机转移，而 COVER（Xiang et al., 2026）减少重新掩码-恢复振荡。我们量化相对于边际传输所需最小活动度的变更，为解释修改活动度提供分布参考。

采样精度。 校正采样器（Wan et al., 2026; Fu and Fan, 2026）改进有限步近似，而使用精确 token 后验的评估（Tang et al., 2026）将采样器误差与学习预测误差分离。我们通过同时检查采样精度、生成质量和活动度来补充这些研究。

7 结论

活动几何通过规定条件边际的耦合来形式化采样器设计。其最小活动度参考产生了 MAFTC，并揭示了在保持路径同时接近端点的动力学最优吉布斯动力学中的超额。在更细的网格上，MAFTC 以更少的 token 变更实现可比的图像和文本质量。其文本轨迹超额随网格细化而降低，而两个基线则增加。选择性执行将其转移结构转化为更低的推理成本。

A.1 经典极大耦合与残差耦合

设 p 和 q 为状态空间 𝒯 上的 PMF。耦合集合具有标准边际约束 [Villani, 2009]：

Γ(p,q) = {π≥0: ∑{y∈𝒯} π(x,y)=p(x)（x∈𝒯）； ∑{x∈𝒯} π(x,y)=q(y)（y∈𝒯）}。

我们首先将 p 和 q 共享的质量与必须移动的质量分离。设：

c(x) := min{p(x),q(x)}， r⁻(x) := [p(x)−q(x)]₊， r⁺(x) := [q(x)−p(x)]₊。

损失残差 r⁻ 是要从输入中移除的质量，增益残差 r⁺ 是要添加以达到输出的质量；它们满足：

p = c + r⁻， q = c + r⁺， q − p = r⁺ − r⁻。

对每个状态 x，两个残差中至少一个为零，给出 r⁻(x)r⁺(x)=0 和 |p(x)−q(x)| = r⁻(x)+r⁺(x)。此外，由于 ∑_x(q(x)−p(x))=0，我们有：

τ := ∑_x r⁻(x) = ∑_x r⁺(x) = 1 − ∑_x c(x) = (1/2)∑_x|p(x)−q(x)| = TV(p,q)， (29)

其中最后一个等式是离散状态空间上全变差距离的标准表达式 [Griffeath, 1975; Thorisson, 2000]。

引理 A.1（耦合下界与等式条件）。 对每个 π∈Γ(p,q)，Pr_π(X≠Y) ≥ TV(p,q)。等式成立当且仅当对每个 x 有 π(x,x)=min{p(x),q(x)}。

证明。 由于 π 具有边际 p 和 q，我们对每个 x 有 π(x,x)≤c(x)。因此，由式 (29)：

Pr_π(X≠Y) − TV(p,q) = (1−∑_x π(x,x)) − (1−∑_x c(x)) = ∑_x[c(x)−π(x,x)] ≥ 0。 (30)

因此 Pr_π(X≠Y) ≥ TV(p,q)。由于式 (30) 中的每个求和项均非负，等式成立当且仅当对每个 x 有 π(x,x)=c(x)。

我们接下来刻画达到等式的耦合。设 τ>0，D_c 为对角数组，[D_c]_{xy} := c(x)𝟙{x=y}。对任何达到等式的耦合 π，定义：

γ(x,y) := (π(x,y)−[D_c]_{xy})/τ。 (31)

等式条件给出 γ(x,x)=0，而对于 x≠y，γ(x,y)=π(x,y)/τ≥0。此外，其行和列边际为：

∑_y γ(x,y) = r⁻(x)/τ， ∑_x γ(x,y) = r⁺(y)/τ。 (32)

因此每个 τ>0 时达到等式的耦合具有形式：

π = D_c + τγ， γ∈Γ(r⁻/τ, r⁺/τ)。 (33)

反之，设 γ∈Γ(r⁻/τ, r⁺/τ) 并定义 π := D_c + τγ。由于对每个 x 有 r⁻(x)r⁺(x)=0，γ 在 x 处的行或列边际中至少一个为零，因此 γ(x,x)=0。因此 π 具有边际 p 和 q 以及对角项 π(x,x)=c(x)。由上述等式条件，它因此达到 Pr_π(X≠Y)=TV(p,q)。最后，若 τ=0，则 p=q，等式条件唯一给出对角耦合 π(x,y)=p(x)𝟙{x=y}。∎

我们还使用耦合与马尔可夫核之间的对应关系。对任何 π∈Γ(p,q)，定义：

K_π(y|x) = π(x,y)/p(x)（p(x)>0）； δₓ(y)（p(x)=0）。 (34)

每行总和为一。零行边际迫使对所有 y 有 π(x,y)=0，因此即使 p(x)=0 时 p(x)K_π(y|x)=π(x,y) 也成立。对 x 求和给出 pK_π=q。任何概率分布都可以替换这些零概率状态上的恒等行而不影响诱导耦合。

A.2 命题 3.2 的证明与尖锐性

证明。 诱导律 π_K(x,y)=p(x)K(y|x) 耦合 p 和 q̃=pK。引理 A.1 给出 A(K)≥TV(p,q̃)，因此 χ(K)≥0。三角不等式给出：

TV(p,q) ≤ TV(p,q̃) + TV(q̃,q) ≤ A(K) + ε(K)。

重排并使用 ε(K)≥0 证明式 (13)。

对于尖锐性，设 τ=TV(p,q)>0 并选择活动度水平 b∈[0,τ]。设 λ=b/τ 和 q̃=(1−λ)p+λq。由于 q̃−p=λ(q−p) 和 q−q̃=(1−λ)(q−p)，ℓ¹ 范数的齐次性给出：

TV(p,q̃) = λTV(p,q) = b， TV(q̃,q) = (1−λ)TV(p,q) = τ−b。

由式 (34)，p 和 q̃ 的极大耦合因此诱导一个核，满足 A(K)=b 和 ε(K)=τ−b。若 p=q，恒等核达到零活动度和边际失配。∎

推论 A.2（活动度和边际失配的逐坐标界）。 设 Π 耦合具有坐标边际 pⁱ 和 q̃ⁱ 的序列值输入和输出状态。固定规定的输出坐标边际 qⁱ 和正权重 w₁,…,w_D。则：

𝔼_Π[d_{H,w}(X,Y)] + ∑ᵢ wᵢ·TV(q̃ⁱ,qⁱ) ≥ ∑ᵢ wᵢ·TV(pⁱ,qⁱ)。

推论 A.2 的证明。 将 Π 投影到坐标 i 并写 Aᵢ := Pr_Π(Xⁱ≠Yⁱ)。该失配概率和诱导输出边际 q̃ⁱ 满足命题 3.2，因此：

Aᵢ + TV(q̃ⁱ,qⁱ) ≥ TV(pⁱ,qⁱ)。

乘以 wᵢ>0 保持不等式。对坐标求和并使用 𝔼_Π[d_{H,w}(X,Y)]=∑ᵢ wᵢAᵢ 给出所述的界。∎

A.3 MAFTC 构造与命题 3.3 的证明

证明。 使用附录 A.1 的公共质量和残差。若 τ=0，恒等核以零活动度实现 p=q。对于 τ>0，选择独立残差耦合：

γ = (r⁻/τ)⊗(r⁺/τ)， γ(x,y) = r⁻(x)r⁺(y)/τ²，

其中 ⊗ 表示两个概率分布的乘积。它属于 Γ(r⁻/τ, r⁺/τ)，因此式 (33) 给出 π^MA = D_c + τγ。该耦合具有边际 p,q 和活动度 τ。应用式 (34) 给出式 (15) 中的核，且 pK^MA=q。因此 ε(K^MA)=0 且 χ(K^MA)=τ−TV(p,q)=0。

对于损失状态 x，p(x)>q(x)，因此其保留和移动概率分别为 q(x)/p(x) 和 r⁻(x)/p(x)。在移动条件下：

Pr(Y=y | X=x, Y≠X) = K^MA(y|x)/(r⁻(x)/p(x)) = r⁺(y)/τ， y≠x。

对于 p(x)>0 的增益或中性状态，r⁻(x)=0 且核保留该状态。零概率输入状态使用式 (34) 中的恒等行约定。∎

A.4 命题 3.4 的证明

𝔼_Π𝟙{Xⁱ≠Yⁱ} = Pr_{Πᵢ}(Xⁱ≠Yⁱ) ≥ TV(pⁱ,qⁱ)。

乘以 wᵢ>0 并求和得到：

𝔼_Π[d_{H,w}(X,Y)] = ∑ᵢ wᵢ·Pr_{Πᵢ}(Xⁱ≠Yⁱ) ≥ ∑ᵢ wᵢ·TV(pⁱ,qⁱ)。 (35)

对于可达性，对每个坐标选择任何极大耦合 πᵢ^⋆∈Γ(pⁱ,qⁱ) 并形成乘积耦合：

Π^⋆((x¹,…,x^D),(y¹,…,y^D)) = ∏ᵢ₌₁^D πᵢ^⋆(xⁱ,yⁱ)。

其第一边际为 ⊗ᵢpⁱ=p，第二边际为 ⊗ᵢqⁱ=q。每个投影对具有失配概率 TV(pⁱ,qⁱ)，因此 Π^⋆ 在式 (35) 中达到等式。这证明了式 (16)。

乘积结构确保该构造具有完整的边际 p 和 q。对于一般序列边际，相同的下界成立，等式需要一个全序列耦合，其坐标投影均为极大耦合。此外，该命题最小化期望加权汉明距离而非全序列失配 Pr(X≠Y)。后者的最小值为 TV(p,q)，通常与逐坐标和不同。∎

条件 MAFTC 精确性。 固定端点 a 并缩写 pⁱ=pₜⁱ(·|aⁱ) 和 qⁱ=p_sⁱ(·|aⁱ)。形成乘积核 K^a=⊗ᵢKᵢ^MA，即 K^a(y|x)=∏ᵢKᵢ^MA(yⁱ|xⁱ)。对每个 y∈𝒯^D，有限和因子化给出：

(pₜ(·|a)K^a)(y) = ∑{x∈𝒯^D} ∏ᵢpⁱ(xⁱ)Kᵢ^MA(yⁱ|xⁱ) (36)
= ∏ᵢ ∑{xⁱ∈𝒯} pⁱ(xⁱ)Kᵢ^MA(yⁱ|xⁱ) = ∏ᵢ qⁱ(yⁱ) = p_s(y|a)。

因此条件输出边际对任何区间长度等于 p_s(·|a)。每个诱导坐标耦合是极大的，因此乘积耦合对每个正权重选择达到命题 3.4 中的下界。这证明了第 3.4 节中的条件序列声明。∎

A.5 命题 4.1 的证明与超额极限

证明。 固定内部时间 t∈(0,1) 并省略下标。设 g=[ṗ]₊ 和 ℓ=[−ṗ]₊。对 ∑_x pₜ(x)=1 求导给出 ∑_x ṗ(x)=0，因此：

∑_x g(x) = ∑_x ℓ(x) = (1/2)∑_x|ṗ(x)| =: M。 (37)

对任何容许通量 j，定义状态 y 的总流入和流出为：

I(y) = ∑{x≠y} j(y,x)， O(y) = ∑{x≠y} j(x,y)。

我们的索引约定是 j(y,x) 表示从源 x 到目标 y 的通量，因此连续性方程为 ṗ(y)=I(y)−O(y)。在增益状态上，ṗ(y)>0，因此 I(y)=ṗ(y)+O(y)≥ṗ(y)。仅在增益状态上求和给出：

𝒜(j) = ∑y I(y) ≥ ∑{y: ṗ(y)>0} I(y) ≥ ∑_{y: ṗ(y)>0} ṗ(y) = M。 (38)

对于 M>0，定义 j^MA(y,x)=ℓ(x)g(y)/M。g 和 ℓ 的支撑不相交，因此通量是非对角的。对目标求和给出流出通量 ∑_{y≠x} j^MA(y,x) = ℓ(x)∑_y g(y)/M = ℓ(x)，对源求和给出流入通量 g(y)。因此诱导导数为 g(y)−ℓ(y)=ṗ(y)，总活动度为 ∑_x ℓ(x)=M。在所考虑的内部时间，pₜ(x)=0 意味着 ṗₜ(x)=0，因为 pₜ(x) 非负且可微。因此 ℓ(x)=0 在零概率状态上，构造的通量满足容许性的支撑条件。这达到式 (38)。若 M=0，则 ṗ=0，零通量是容许且最优的。

剩下刻画等式。式 (38) 中的第一个不等式为等式当且仅当对每个损失或中性状态有 I(y)=0。第二个为等式当且仅当对每个增益状态有 O(y)=0，因为 I(y)=ṗ(y)+O(y)。连续性方程则给出：

O(x)=ℓ(x)（x∈{ṗ<0}）， I(y)=g(y)（y∈{ṗ>0}），

所有其他流入和流出为零。因此每个最小化通量支撑从损失集到增益集，并具有逐状态流出 ℓ 和流入 g。对于 M>0，数组 γ(x,y):=j(y,x)/M 具有行边际 ℓ/M 和列边际 g/M。这将最小化通量识别为 Γ(ℓ/M, g/M) 中的耦合。式 (20) 中的通量对应于独立耦合。

最后，有限状态空间上的可微性给出：

‖(p_{t+h}−pₜ)/h − ṗₜ‖₁ → 0（h↓0）。

范数的连续性则给出：

TV(pₜ,p_{t+h})/h = (1/2)‖(p_{t+h}−pₜ)/h‖₁ → (1/2)‖ṗₜ‖₁ = M。 (39)

为获得耦合极限，写 r_h⁻=[pₜ−p_{t+h}]₊，r_h⁺=[p_{t+h}−pₜ]₊ 和 τ_h=TV(pₜ,p_{t+h})。正部映射是 1-Lipschitz 的，因为 |[a]₊−[b]₊|≤|a−b|。逐点应用该不等式给出：

‖r_h⁻/h − ℓ‖₁ → 0， ‖r_h⁺/h − g‖₁ → 0。

当 M>0 时，τ_h/h→M 确保对足够小的 h 有 τ_h>0，因此 r_h⁻/τ_h → ℓ/M，r_h⁺/τ_h → g/M（ℓ¹ 中）。对于 x≠y，式 (14) 现在给出：

π^MA_{t,t+h}(x,y)/h = [r_h⁻(x)/h][r_h⁺(y)/h]/(τ_h/h) → ℓ(x)g(y)/M = j^MA(y,x)。

由于非对角对有限，其绝对误差之和也消失：

∑{x≠y}|π^MA{t,t+h}(x,y)/h − j^MA(y,x)| → 0。

这是非对角数组的所述 ℓ¹ 收敛。若 M=0，定义 j^MA=0。总非对角质量为 τ_h，因此 ∑{x≠y}|π^MA{t,t+h}(x,y)/h| = τ_h/h → 0。因此当瞬时最小值消失时耦合极限也成立。∎

活动度分解的连续时间极限。 设 P_h:=P_{t+h|t} 为局部实现规定路径的有限状态 CTMC 的精确转移核，因此 pₜP_h = p_{t+h}。假设局部有界速率和式 (3) 的短时展开。对于 x≠y 有 jₜ(y,x)=pₜ(x)uₜ(y,x)，有限时间定义给出 ε(P_h)=0 和 A_ind(P_h)=TV(pₜ,p_{t+h})。由于状态有限：

附录 B 度量诱导路径与超额活动度的定位

我们识别吉布斯路径的有限区间损失和增益阈值，然后证明动力学最优动力学中超额活动度的定位。固定端点 token a∈𝒯 和有限非负端点距离分数 ρ(·,a)。对于逆温度 β≥0，设 Z_a(β) 为条件路径的归一化常数：

p_β(x|a) = e^{−βρ(x,a)}/Z_a(β)， Z_a(β) := ∑_{z∈𝒯} e^{−βρ(z,a)}。 (40)

以下计算使用有限 β，其中每个状态具有正概率。我们省略坐标索引并将 p_β(·|a) 缩写为 p_β。

对于两个采样时间处的逆温度 0≤βₜ<β_s<∞，设 μ(β) := ∑_x p_β(x)ρ(x,a) 为 p_β 下的平均端点距离。损失和增益集合由阈值分离：

ρ*{t,s} = (log Z_a(βₜ) − log Z_a(β_s))/(β_s−βₜ) = (1/(β_s−βₜ))∫{βₜ}^{β_s} μ(β)dβ。 (41)

引理 B.1 刻画了增益和损失集合并证明了收缩区间极限 lim_{β_s↓βₜ} ρ*_{t,s} = μ(βₜ)。(42)

阈值 μ 附近的动力学活动度。 在固定有限 β 处，写 ρ_x:=ρ(x,a) 和 μ:=μ(β)=∑_x p_β(x)ρ_x。由于 ∂_β log Z_a(β) = −μ，对吉布斯路径求导给出：

∂_β p_β(x) = p_β(x)(μ−ρ_x)。 (43)

对于 Shaul et al. [2024, Eq. (26)] 中也被 FUDOKI [Wang et al., 2025b] 使用的动力学最优构造，我们目标优先约定中的通量因此为：

j_β^KO(y,x) = [p_β(x)∂_β p_β(y) − p_β(y)∂_β p_β(x)]₊ = p_β(x)p_β(y)[ρ_x−ρ_y]₊， x≠y。

对于具有有限 βₜ 的可微非减调度，返回到模型时间 t 将此通量和下面的两个活动度乘以 β̇ₜ≥0，保持其分解不变。设 R=ρ(X,a) 和 R'=ρ(X',a)，其中 X,X'∼p_β 独立，μ=𝔼R。动力学最优和最小活动度通量的活动度为：

𝒜_KO = (1/2)𝔼|R−R'|， 𝒜_MA = (1/2)𝔼|R−μ|。 (44)

两个通量诱导吉布斯概率路径的相同导数。定理 4.2 陈述了正文中的定位结果。在上述记号中，其组内恒等式等价于：

𝒜_KO − 𝒜_MA = 𝔼[(R−R')₊𝟙{R'>μ}] + 𝔼[(R−R')₊𝟙{R≤μ}]。 (45)

第一项是距离均超过 μ 的状态之间的通量；第二项是距离不大于 μ 的状态之间的通量。下面的证明还建立了跨阈值恒等式。
