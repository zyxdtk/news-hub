Gartner：智能体成本将涨五倍，如何控制？

📅 2026-10-17 📄 VentureBeat AI 🔗 原文链接

原标题：Gartner says agent costs will rise fivefold by 2028 even as tokens get cheaper. Here is how to keep them in check

中文摘要： Gartner 预测，尽管 token 价格持续下降，到 2028 年智能体工作流的推理成本仍将增长超过五倍，形成"推理悖论"。原因有二：模型实验室将效率提升再投资于更昂贵的前沿模型；智能体完成相同任务消耗的 token 是聊天机器人的 5-30 倍。Gartner 建议企业通过五大架构变革控制成本：投资可观测性、嵌入成果价值指标、推理分层制度化、设定 AI 执行最低标准、利用专有数据微调。

Token 价格下跌让许多企业以为 AI 成本也会随之下降。但智能体正在打破这一假设。

Gartner 预测，尽管 token 经济学不断改善，但到 2028 年，每个智能体工作流的推理成本将增长超过五倍。该公司表示，与基本的聊天机器人交互相比，将任务路由到智能体推理模型会使提供商的推理成本至少提高 5 倍，而且随着任务复杂性的增加，成本往往会高出更多。他们将此称为推理悖论（Inference Paradox）。更好的单位经济效益反而推高了 AI 的整体成本，却没有一条通往相应且可预测价值的清晰路径。

Gartner 表示，效率的提升正被重新投入到更强大、更昂贵的模型中。

"这样一来，token 成本并没有下降，而是在扩大，"Gartner 高级总监分析师 Will Sommer 告诉 VentureBeat。

为什么更便宜的 token 仍然意味着更大的账单

推理悖论背后有两大主要驱动因素。

第一个问题出在模型实验室。Sommer 指出，生成 token 的成本效益正在不断提高。

"然而，基础 AI 实验室并没有将这些节省的成本收入囊中，而是投资于需要更多计算能力的下一代模型，因此每个 token 的成本反而更高，"他说。

旧能力正变得便宜得多，而前沿模型却越来越贵。Sommer 以 Anthropic 的 Fable 每 token 成本高于 Opus 为例，说明了这种分化。

第二个驱动因素是消耗量。更高的 token 效率使更复杂的工作负载变得可行，而这些工作负载消耗的 token 要多得多。

"对于相同的任务，AI 智能体所需的 token 量是基本 AI 聊天机器人的 5-30 倍，"Sommer 说。

竞争压力将两者联系在一起。希望与同行保持同步的企业会采用更先进的用例，而这些用例需要比上一代 AI 系统更强大、更昂贵的模型以及多得多的 token。

成本将呈锯齿状波浪式攀升，而非直线上升

Gartner 预计到 2028 年之前成本不会平稳攀升。控制成本与保持同行竞争力之间的张力使支出上下波动，而且支出已随着新模型的发布而震荡。

"第一波智能体能力在春季导致支出大幅增加，部分原因是 tokenmaxxing（最大化 token 使用）的风潮，"Sommer 说。"我们目前正处于紧缩阶段。"

Gartner 预计，随着更强大的推理智能体、世界模型和其他 AI 技术的成熟，还会出现几波浪潮。

企业控制成本的方式并不均衡。9 月份一项针对 109 名合格受访者的 VB Pulse 调查发现，21% 使用编排平台的企业没有任何自动停止智能体 token 支出的机制。另有 31% 的企业将常规、大批量的智能体任务发送给更便宜的模型以控制成本。

据 Sommer 介绍，五倍的估计基于 Gartner 的 Token 经济学预测（Tokenomics Forecast），这是一个计量经济学模型，通过 300 多个输入变量预测 token 成本随时间的变化。该模型既考虑了 token 成本效率的提高，也考虑了随着 AI 被用于解决更难的问题而急剧增加的 token 消耗量。Sommer 表示，具有学习能力的 AI 解决方案，或跨企业、跨多个领域运行的 AI 解决方案，需要多得多的 token 才能将工作流投入实际运行。

应对推理悖论的五大架构变革

组织应考虑以下五项关键变革，以抢占先机。

投资可观测性。 AI FinOps 对任何成本优化工作都至关重要。"企业无法优化其无法观测的东西，"Sommer 说。

在 AI 部署中嵌入"每成果价值"指标。 要求每个 AI 功能针对广泛的不确定性进行预测，并根据明确的结果指标跟踪支出，例如自动化的任务数量或成功解决的案例数量。快速改进或淘汰低效工作流，以保护利润率。

将推理分层制度化。 强制将查询自动路由到最具成本效益的模型，并阻止在常规任务中默认调用前沿模型。"投资于智能体框架（agentic harnesses），它们定义了模型在自主系统中部署的位置、时间和方式，"Sommer 说。

对 AI 执行实施最低标准。 "一劳永逸"的做法行不通。组织需要预先定义成功阈值、合规开销和风险缓解成本——并且在场景经过 token 价格波动和合规费用的压力测试之前，拒绝批准部署。

利用专有数据。 嵌入专有数据微调和自学习反馈循环，以长期维持差异化和利润率。"高效的领域特定模型在可靠性和特定工作负载的任务上，通常优于通用前沿模型，"Sommer 说。
