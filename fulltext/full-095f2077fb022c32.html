摘要

开发有效的机器学习模型需要复杂的手动调优，而当前的自动机器学习框架仍然是领域特定的，并且将模型架构、训练超参数和数据比例优化相互隔离。在此，我们通过提出一个通用的、基于大语言模型（LLM）的 AutoML 框架来弥合这一差距，该框架首次联合优化这些配置，而无需任务特定的微调。我们提出了 NCode，一种统一的数值编码方案，将多样化的 AutoML 设计选择转换为通用离散序列，并有效地将优化过程重新构建为统一的排序任务。仅在从有限的单一领域视觉任务导出的优化轨迹上训练，所提出的基于 LLM 的搜索器展示了令人印象深刻的跨任务、跨模态和联合搜索空间优化泛化能力，在图像分类、图像分割、说话人验证和文本到图像基准上实现了最先进的性能。至关重要的是，它在十亿参数扩散 Transformer 的大规模训练和联合优化中表现出卓越的可扩展性，需要 896 个 GPU 天，并获得了 0.91 的最先进 GenEval 分数。通过利用强化学习灌输思维链推理，我们提供了一种系统的方法来解释基于 LLM 的搜索器的内部决策机制，揭示其优化策略从早期多样性驱动的探索转变为后期锚点利用。我们提出的框架为通用开放世界机器学习优化提供了一条可扩展、可泛化和可解释的途径。

I 引言

机器学习（ML）的最新进展已经彻底改变了包括计算机视觉、自然语言处理和音频分析在内的多个领域。尽管取得了进展，开发有效的 ML 模型仍然是一项复杂的工作，通常需要在设计网络架构、调整超参数和组织训练数据方面的大量人类经验。因此，自动机器学习已成为一个关键的解决方案，旨在以最少的人工干预自动化 ML 流程的此类设计选择。

虽然在 AutoML 方面已经进行了深入的探索，特别是在用于架构设计的神经架构搜索（NAS）[57, 58, 31]和用于确定训练超参数的超参数优化（HPO）[9]方面，该领域仍然缺乏通用的 AutoML 框架。在基础模型时代，这一差距已变得越来越具有挑战性。目前，这种开放领域系统的实现受到三个基本障碍的阻碍：

  • 开放世界问题泛化。 现有的 AutoML 方法通常针对特定搜索空间进行优化，缺乏跨不同任务、数据集和架构泛化的灵活性。例如，流行的基于梯度的 NAS 方法 DARTS [31] 在其原始搜索空间内的 CIFAR-10 测试集上实现了 97.24% 的准确率，但在广泛使用的 NAS-Bench-201 基准 [12] 上评估时，却遭遇了 39.77% 的严重性能崩溃。尽管两种设置共享相同的数据集和优化器，这种急剧下降凸显了当前 NAS 和 AutoML 技术在面临搜索空间结构变化时的固有脆弱性。因此，这一限制阻碍了 AutoML 方法在数据分布、架构搜索空间和任务定义新颖或未见的开放世界问题中的应用。

  • 模型优化选择的复杂相互依赖性。 模型的最佳性能是模型架构、训练超参数和数据比例等之间复杂相互作用的结果。这种高度非线性的交互很难孤立地优化。现有的 AutoML 方法未能捕获协同效应，当组件被单独优化时，通常会导致次优的局部最小值。

  • AutoML 训练数据获取的过高成本。 创建 AutoML 训练数据集在计算上昂贵且耗时，因为它涉及为每个新任务重复进行模型训练和性能评估的过程。高成本阻碍了基于学习的 AutoML 方法的发展和可扩展性。

为了克服这些障碍，该领域正在见证从专门的优化算法向更可泛化方法的范式转变。特别是，大语言模型（LLM）被用来优化 AutoML 问题，以利用其强大的推理能力 [54, 29]。然而，它们仍然严重依赖于任务特定的训练、微调和手动提示工程。因此，能够导航跨越多个架构、任务和模态的开放世界问题的 AutoML 框架的部署很少。

在这项工作中，我们引入了一个开放世界的基于 LLM 的 AutoML 框架，该框架首次能够在无需任务特定微调的情况下联合优化模型架构、训练超参数、不同任务数据比例的复杂组合。为了实现对多个内在多样化搜索空间的优化，我们引入了 NCode，一种将异构设计选择映射到其各自索引的编码方案，将它们表示为统一的数值序列（图 1 b,c）。通过将多样化的 AutoML 任务转换为通用的离散优化问题，NCode 允许 LLM 轻松地泛化到未见的开放世界领域，而无需领域特定的微调（图 1 a）。为了训练基于 LLM 的搜索器，我们从 NAS-Bench-301 数据集 [53] 中整理优化轨迹，该数据集提供了模型架构及其在 CIFAR-10 数据集上相应的图像分类性能。我们将模型架构实例建模为密集连接的有向无环图（DAG），并应用随机边剪枝以生成多样化、局部化的架构搜索空间，用于丰富的轨迹构建。此外，对于基于 LLM 的搜索器的输出，我们将离散 NCode 优化重新构建为排序问题，其中 LLM 从候选池中识别优越的候选者，而不是直接预测它们的 NCode，这一设置被证明比直接生成完整 NCode 明显更简单易学。因此，尽管仅在单一领域视觉数据上训练，我们的 LLM 搜索器有效地泛化到数据收集通常成本高昂的跨领域联合优化任务。

我们系统的初步版本仅专注于模型架构搜索，已在 EMNLP2025 [21] 中展示。当前研究揭示了统一的基于 LLM 的搜索器在显著更复杂、异构的搜索空间中的能力，并掌握了跨七个领域、四个任务和三个模态（视觉、文本、音频）的模型架构、训练超参数和数据比例之间的协同作用，而无需微调。更重要的是，我们的基于 LLM 的搜索器通过经由组相对策略优化（GRPO）[39] 学习可解释的思维链（CoT）来训练解释其优化原理。我们的分析揭示了模型如何导航解决方案空间进行优化，并提供了关键见解。大量实验提供了令人信服的证据，并证明我们的框架在多样化的开放世界机器学习问题套件中实现了最先进的性能。

图 1： 提议的基于 LLM 的开放世界 AutoML 框架和通用 NCode 表示的概述。(a) 传统 AutoML 范式通常需要为不同任务单独调整模型。相比之下，我们提出的开放世界基于 LLM 的搜索范式使用通用编码来联合优化跨任务、领域和模态的模型架构、训练配置和数据组合。(b) NCode 将异构 AutoML 设计选择（包括架构、超参数和数据采样权重）映射到统一的离散数值序列。(c) 具有不同拓扑、操作、训练超参数和数据比例的模型的说明性编码过程。注意，所描绘的码本是简化摘录；我们实验中使用的功能码本更为广泛。

我们强调我们的主要贡献如下：

  1. 统一问题表示： 我们引入了一种通用数值编码，将模型架构、超参数和数据比例映射到统一的离散空间，允许 AutoML 框架跨不同搜索空间联合优化多样化的设计选择。

  2. 搜索轨迹整理： 我们引入了一种基于剪枝的架构采样策略来整理丰富、多样化的优化轨迹，缓解了 AutoML 数据收集的过高成本。通过同时将 LLM 的目标从直接序列生成重新构建为条件排序，我们提高了搜索器在复杂优化景观中泛化的能力。

  3. 广泛的实证验证： 通过在多样化场景的真实世界机器学习任务中部署我们的方法，并实现最先进的（SOTA）性能，我们证明了该框架的强大零样本泛化能力。

  4. 通过 RL 驱动的思维链实现可解释性： 为了揭示基于 LLM 的搜索器的内部决策机制，我们利用组相对策略优化（GRPO）灌输思维链推理，而无需人工标注。这种自我解释能力提供了对模型学习的优化策略的关键见解，特别是揭示了从早期多样性驱动的探索到后期锚点利用的动态转变，并突出了现有 AutoML 框架中传统离散优化方法的固有局限性。

II 相关工作

II-A 传统自动机器学习

自动机器学习已经显著发展，从早期的强化学习 [57, 52] 和基于梯度的神经架构搜索（NAS）[31] 发展到基于 Transformer 的超参数优化（HPO）[9]。最近，该领域越来越接受先进的生成范式，例如利用多条件图扩散模型 [2] 来采样候选神经结构。尽管有这些进步，传统的 AutoML 方法本质上仍然是针对预定义的、任务特定的搜索空间定制的。此外，即使是当代的生成式 NAS 模型通常也将架构搜索和训练配置调优视为不相关的问题。这种隔离未能捕获异构组件之间复杂的协同作用，限制了它们在涉及未见模态或结构变化的开放世界场景中的适用性。与孤立地优化组件相反，我们的框架引入 NCode 将这些异构设计选择统一到一个共享的数值空间中，实现整体联合优化。

II-B 基于 LLM 的自动机器学习

近年来，人们对利用大语言模型（LLM）进行神经架构搜索（NAS）和自动机器学习的兴趣日益增长，代表性框架包括 AutoML-GPT [54]、LLMatic [33] 和 CoLLM-NAS [29]。尽管有这些进步，现有的基于 LLM 的搜索器存在关键限制：它们要么严重依赖任务特定的微调，要么将搜索表述为直接的文本生成任务，这容易产生无效配置，并在巨大的离散空间中表现出高学习复杂性。虽然我们的初步工作 LM-Searcher [21] 通过统一的数值编码启动了跨领域 NAS 的探索，但它仍然局限于仅架构搜索。为了克服这些瓶颈，提议的框架将异构配置统一到离散 NCode 空间中，并将搜索重新构建为条件候选排序问题。这种设计实现了跨不同领域和模态的架构、超参数和数据比例的鲁棒零样本联合优化，而无需任务特定的适应。

II-C 可解释性和思维链推理

传统的 AutoML 算法和神经搜索代理经常因其黑盒性质而受到批评，为其优化轨迹提供最少的内在原理 [23]。虽然思维链提示 [43] 和像组相对策略优化（GRPO）[39] 这样的强化学习算法已经提高了 LLM 的逻辑推理能力，但将自我解释的 CoT 应用于解释 AutoML 搜索逻辑仍然未被充分探索。为了弥合这一差距，提议的框架利用 GRPO 对基于 LLM 的搜索器进行后训练，以用自然语言阐明其推理步骤。通过将产生的 CoT 输出分类为不同的行为模式，我们为 LLM 驱动的优化机制提供了可解释性。

图 2： 使用组相对策略优化对具有 CoT 推理能力的 LLM 进行后训练的概述。具有原生思考能力的 Qwen3-8B 模型通过强化学习在我们的整理数据集上进行微调，以阐明其推理路径。给定系统提示、历史上下文和表示为 NCode 的候选配置，策略模型生成多个候选响应。总奖励计算为准确性奖励（模型是否从候选池中选择最优配置）和格式奖励（模型是否以正确格式输出完整的推理过程和最终答案）的加权和。

III 基于 LLM 的搜索器框架

III-A 概述

为了实现包括模型架构、训练超参数和数据比例在内的复杂 AutoML 设计选择的联合优化，我们提出了一个通用的、基于 LLM 的开放世界搜索框架。我们框架的核心是一种称为 NCode 的统一数值编码方案，它将异构配置映射到离散序列中。在搜索阶段，基于 LLM 的搜索器迭代地分析已评估的 NCode-奖励对的历史缓冲区，以自主地从未评估的候选池中识别和选择最有前途的配置。我们的基于 LLM 的搜索器不依赖于领域特定的微调，而是被训练为隐式学习优化轨迹和推理策略，使其能够无缝地泛化到未见的配置和模态。

III-B 通用 NCode 表示

为了统一异构 AutoML 设计选择（例如，模型架构、训练超参数和数据比例）和任务领域的表示，我们将所有配置统一编码为称为 NCode 的离散数值序列。形式上，让给定的 AutoML 搜索空间表示为 𝒮。AutoML 配置 a∈𝒮 可以由一组 n 个决策定义，这些决策可以表示操作原语、网络连接性、训练模块特定的超参数或数据比例。我们定义编码函数 f:𝒮→𝒞，其中 𝒞 是 NCode 序列的通用空间。该函数将配置映射到离散索引字符串，表示为 c=(c₁,c₂,…,cₙ)，其中每个元素 cᵢ 是对应于第 i 个配置的所选配置选项的数值索引。

NCode 实现了模型拓扑、操作、训练超参数和数据比例的联合状态。为了表示网络拓扑，网络可以建模为有向无环图（DAG），其中每条边表示一个操作，每个节点表示求和的特征图。例如（图 1b），在 NAS-Bench-201 搜索空间中，每个架构通过为单元内的六条边中的每一条分配五个不同操作之一来定义。NCode 表示建立了这些操作与一组整数之间的映射。值得注意的是，通过将搜索构建为黑盒组合优化问题，NCode 原生地扩展到联合编码其他异构配置。图 1c 说明了 NCode 如何联合编码模型架构、训练超参数和数据比例。

图 3： 子空间采样数据整理策略的流程。给定建模为有向无环图（DAG）的整个架构搜索空间，应用随机边剪枝以生成结构多样化、局部化的子空间（𝒮_sub）。在每个孤立的子空间内，采样并评估模型架构的子集，以将其统一的 NCode 表示与相应的性能指标配对。为了构建训练轨迹，这些样本被分割为已评估试验的顺序上下文历史（ℋ）和未评估候选者池（𝒞）。该流程将大规模优化问题重新构建为可处理的排序任务，训练模型在历史上下文条件下选择具有最高预期性能的候选者。

III-C 优化轨迹整理

为了有效地利用 LLM 作为 AutoML 的通用搜索器，我们整理了优化轨迹数据集，以捕获迭代搜索过程的顺序、因果步骤。具体而言，每个优化轨迹包括一系列 AutoML 配置-奖励对，架构由我们统一的 NCode 方案表示。在每次迭代中，搜索算法利用历史评估对作为上下文来采样新的模型架构，随后对其进行评估以导出其性能指标。这些指标的加权和作为给定架构的奖励信号。

我们没有直接收集 AutoML 联合优化样本（这既耗时又计算昂贵），而是从既定的 NAS 数据集 NAS-Bench-301 中采样模型-奖励对，该数据集包括大约 10²¹ 个不同的模型架构及其在 CIFAR-10 分类任务上的性能。为了增强优化数据中架构搜索空间的多样性，我们引入了一种基于剪枝的架构采样策略，从单一总体搜索空间生成不同的子空间。如图 3 所示，综合架构搜索空间 𝒮 被建模为完全连接的 DAG。我们以概率 p=0.5 独立地剪枝每条边。这种随机独立剪枝本质上定义了局部化的子搜索空间 𝒮_sub⊂𝒮。迭代这种独立剪枝生成了大量不同的子搜索空间，产生了具有高度变化结构分布的训练数据集。

鉴于架构空间的巨大规模（包括大约 10²¹ 个架构），识别单个最优架构作为绝对地面真值在计算上是不可处理的，并且对模型构成了重大的学习挑战。因此，我们将基于 LLM 的搜索器的目标从直接预测重新构建为候选排序。在每个孤立的子空间 𝒮_sub 内，我们随机采样一组 N 个模型（其中 N∈[100,200]）及其相应的性能指标。包括先前评估的 NCode 表示及其奖励序列的上下文历史 ℋ 被提供给基于 LLM 的搜索器。然后，模型被任务化为从同一子空间采样的未评估配置的候选池 𝒞 中选择最有前途的 NCode。

通过这种方法，我们整理了一个包含大约 228,000 个优化轨迹实例的鲁棒数据集。这个广泛的数据集提高了 LLM 以领域无关方式优化 AutoML 配置的能力。

III-D 通过 LLM CoT 推理实现可解释性

为了揭示基于 LLM 的搜索器在 AutoML 优化中的推理过程，我们利用组相对策略优化（GRPO）[39] 微调 Qwen3-8B [49] LLM 作为自我解释的搜索器，学习在其自己的 CoT 推理指导下导航最优 AutoML 配置。然后，我们分析了在 NAS-Bench-201 [12] 和 GenEval [18] 数据集上用自然语言解释的 CoT 推理，在搜索阶段提取其推理轨迹用于后续的可解释性分析。

AutoML 搜索的策略优化。 我们将基于 LLM 的 AutoML 搜索构建为马尔可夫决策过程（MDP），旨在优化通用 NCode 空间内的决策轨迹。对于给定的搜索上下文 x（包括历史试验和当前候选者），搜索器充当生成令牌序列 y 的策略 π_θ，表示组合的推理和最终配置选择。为了在没有显式值网络的内存开销的情况下有效地导航这个复杂的离散搜索空间，我们实现了组相对策略优化（GRPO）[39]。GRPO 的奖励是准确性奖励（验证最优 NCode 候选的选择）和格式奖励（强制执行可解释性分析所需的推理过程的结构完整性）的加权和。

思维链推理行为的分类学

我们采用具有 CoT 能力的基于 LLM 的搜索器在 NAS-Bench-201 上进行图像分类搜索，在 GenEval 上进行文本到图像生成搜索。实验产生了 2,500 个搜索步骤，每个任务都附有模型的中间推理过程。为了系统地分析搜索器的推理轨迹，我们将生成的思维链输出分类为六种不同的行为模式。这些模式的定义如图 4 所示，如下：

  • 位置锚定：当搜索器明确识别出在指定序列位置上特定操作数字的存在与极端（高或低）性能结果强烈相关时，就会出现这种模式。LLM 使用这种单点启发式作为后续候选选择的锚点。

  • 全局组件分布：当搜索器将其决策基于操作的全局分布时适用。模型观察到整个配置序列中特定功能数字的聚合计数与整体模型性能系统相关，而不管它们的绝对位置如何。

  • 邻域变异：我们将这种行为定义为一种进化搜索策略，其中 LLM 选择历史上高性能的配置作为基线（"父代"），并针对代表最小结构扰动（例如，仅修改一个或两个序列数字）的候选者。这反映了一种专注于探索直接局部最优邻域的利用策略。

  • 组合协同：这描述了推理过程强调多个位置之间组合交互的情况。搜索器识别出特定的多位数字组合（例如，位置 3 和 5 处的耦合操作对）对性能产生协同效应，这无法由单个数字单独解释。

  • 层次序列进展：这分类了 LLM 检测配置字符串的特定子区域内单调递增或递减数值模式的行为。模型将这些序数趋势解释为网络拓扑中平滑或突然的层次转换的反映，这些转换系统性地影响目标指标。

  • 操作异构性：当搜索器基于其数字异构性评估候选者时，就会出现这种模式。通过观察到高性能模型通常包含比同质的、性能不佳的模型更广泛的独特功能数字词汇，LLM 故意偏爱集成多样化数值组件的配置。

III-E 零样本推理流程

一旦基于 LLM 的搜索器在整理的轨迹数据集上训练（如第 III-C 节详述），它就可以直接部署到联合优化未见领域、新颖搜索空间和不同模态的架构、超参数和数据比例，而无需任何任务特定的梯度更新。这个零样本推理流程充当闭环马尔可夫决策过程，如图 5 所示，包括以下核心阶段：

  1. 冷启动初始化：为了初始化 LLM 的历史上下文，我们采用随机搜索策略来采样一小组初始配置（例如，K_init=5）。这些配置通过通用 NCode f̂ 映射到它们各自的离散序列。随后在目标任务上评估它们以获得其性能指标，这些指标被聚合和归一化为标量奖励以形成初始历史缓冲区 ℋ。

  2. 候选池生成：在每次搜索迭代中，我们生成未评估配置的候选池 𝒞。为了确保探索和利用，该池通过应用进化算法（即，对历史上高性能的 NCode 进行结构变异）以及随机采样来填充。

  3. LLM 引导的推理和选择：当前历史缓冲区 ℋ（包括已评估的 NCode-奖励对）和候选池 𝒞 被整合到标准化提示中。冻结的基于 LLM 的搜索器处理此上下文，识别并输出池中最有前途的候选者 c*。

  4. 代理评估和上下文更新：为了缓解搜索阶段完全训练大规模模型的过高计算成本，我们实现了早期停止代理评估协议。选定的候选者被解码回实际的机器学习流程，并训练最少的步数或时期（例如，分割 1 个时期，文本到图像合成 2500 步）。然后将导出的代理奖励 r 与其 NCode c 配对并附加到历史缓冲区 ℋ。

  5. 有界缓冲区管理：为了尊重 LLM 的最大令牌上下文窗口并保持高质量的上下文，历史缓冲区的容量是有界的。一旦评估对的数量超过预定义阈值（例如，M=200），就会触发过滤机制，仅保留表现最好的前 M 个配置，丢弃次优试验。

这个迭代循环持续到预定义的计算预算耗尽。整个过程在算法 1 中形式化。

IV 实验

IV-A 概述

为了全面评估我们提出的基于 LLM 的搜索器的有效性、零样本可转移性、可扩展性和可解释性，我们在四个不同的机器学习场景中进行了广泛的实证评估。具体而言，我们在以下方面评估我们的框架：(1) 跨领域图像分割，以测试零样本领域转移下的 PEFT 设计和超参数优化；(2) 跨模态说话人验证，以评估从视觉到音频的跨模态泛化；(3) 大规模文本到图像合成，以展示规模化的联合架构、超参数和数据比例搜索；以及 (4) NAS 基准，以验证标准的神经架构搜索性能。对于每种范式，我们提出详细的实验设置，然后是定量结果。此外，我们研究了基于 LLM 的搜索器内部决策过程的可解释性，并有彻底的消融研究和定性案例研究支持。下面，我们首先概述常见的实现细节，然后详细说明每个特定任务。

实现细节

  • 基于 LLM 的搜索器训练：为了构建主要的搜索代理，LLaMA-3.1-8B 基础模型 [1] 经过全参数监督微调（SFT）。训练锚定在包含大约 228,000 个优化轨迹实例的整理数据集上。为了鲁棒地捕获历史试验奖励和候选配置的广泛序列，我们采用扩展的上下文窗口，严格的令牌截止长度为 20,480。SFT 过程执行 3 个时期，学习率为 1.0×10⁻⁵，由余弦学习率调度器调节，遵循 10% 的预热阶段。为了确保全参数优化期间的内存效率，训练分布在配备 8 个 GPU 的单节点上，使用 DeepSpeed ZeRO-2 框架，采用 bfloat16 混合精度，配置为每设备批量大小为 1，梯度累积步数为 2。

为了分析搜索器的内部决策过程，我们使用组相对策略优化（GRPO）后训练 Qwen3-8B 模型。对于这个强化学习阶段，我们从主要的 228,000 实例数据集中子采样 2,000 个代表性轨迹实例，并执行 3 个时期的策略训练。为了在 GRPO 的算法框架内促进相对优势估计，策略模型被配置为为每个单独的提示样本生成一组 8 个独立的候选响应。计算密集型训练分布在配备每节点 8 个 GPU（总共 32 个 GPU）的分布式 4 节点集群上，运行 DeepSpeed ZeRO-3 框架，在 bfloat16 混合精度中进行 CPU 卸载。执行配置利用每设备批量大小为 1，匹配梯度累积步数为 4。为了缓解长格式思维链生成的巨大令牌开销，同时保持搜索对齐，我们通过针对注意力投影模块（q_proj 和 v_proj）的低秩适应采用参数高效微调（PEFT）。最大提示和完成边界分别限制为 10,240 和 8,192 个令牌，为结构合理化提供足够的容量。vLLM 推理引擎与训练框架并置，以加速基于组的相对奖励采样。

  • 搜索阶段：为了初始化我们框架内的 AutoML 配置搜索，我们利用随机搜索来采样和评估五个配置。这为基于 LLM 的搜索器生成了一组初始的五个 NCode-奖励对以供分析。在随后的每次迭代中，LLM 提出一个 NCode，然后将其解码为特定的训练配置。为了确保图像分割和说话人验证搜索期间的计算效率，我们在单个时期后应用早期停止，并使用部分训练的模型来导出代理性能度量。对于大规模文本到图像合成，我们联合搜索模型架构、训练超参数和数据采样比例，使用缩小到目标模型的块深度和隐藏维度大小一半的代理模型，训练在 2,500 步处截断。总体奖励计算为所有指标的加权平均值，随后在所有评估的配置中归一化。值得注意的是，对于较低值表示优越性能的指标，它们对最终奖励的贡献被取反。在整个搜索过程中，我们维护最多 200 个 NCode-奖励对的历史缓冲区。一旦评估对超过此阈值，我们过滤提供给 LLM 的上下文，仅保留表现最好的前 200 个配置。

  • 重训练阶段：一旦在早期停止代理评估期间由基于 LLM 的搜索器识别出最优配置，选定的配置将经历完整的重训练阶段以进行严格的评估。由于这些最优配置（包括架构、超参数和数据比例）代表我们搜索过程的直接结果，特定的重训练实现细节本质上是任务特定的。因此，我们在每个任务的相应搜索配置部分（第 IV-B–IV-D 节）中详细说明完整的重训练设置。

IV-B 跨领域图像分割

IV-B 1 实验设置

  • 数据集。 为了评估我们提出的基于 LLM 的搜索器的跨任务和跨领域泛化能力，我们利用了包含多个不同领域的多样化图像分割数据集套件。搜索阶段在医学成像领域使用 Kvasir-SEG 和 CVC-612 数据集进行。具体而言，Kvasir-SEG 和 CVC-612 分别使用内窥镜和结肠镜图像评估模型在胃肠道息肉分割中的能力。为了测试零样本可转移性，搜索期间发现的最优配置在跨领域的七个数据集上进行评估。除了这两个数据集外，还包括 ISIC2017（专注于黑色素瘤检测的皮肤病变精确边界描绘）；CAMO（包含巧妙融入周围环境的伪装物体的自然图像）；SBU（要求模型在日常场景中区分真实结构边界和复杂阴影遮罩）；Leaf（专注于从重叠叶子背景中描绘单个植物叶子的农业数据集）；以及 Road（利用高分辨率遥感图像评估广阔景观中连续拓扑道路网络的提取）。

  • 搜索配置。 搜索空间包括模型架构和训练超参数。对于架构，我们使用 Segment Anything Model（SAM）作为基础分割器，通过从 {3,6,12,24} 中分配 ViT 编码器中 32 个 LoRA 模块的秩来搜索 PEFT 设计，产生大约 10¹⁹ 个架构的搜索空间。超参数搜索空间包括焦点损失 γ、权重衰减和学习率。为了有效地导航这个广阔的空间，我们在搜索阶段实现早期停止代理评估协议，其中每个候选配置仅训练 1 个时期以导出代理奖励。发现的最优配置随后进行 30 个时期的完整重训练，建立 1:30 的高效搜索到完整训练工作负载比。有关搜索空间的全面细节在附录表 1 中提供。对于随后的重训练阶段，我们将识别出的表现最好的 AutoML 配置应用于每个下游数据集。具体而言，我们使用我们最优的 LoRA [20] 配置微调 Segment Anything Model（SAM）[25]。训练在单个 GPU 上进行，利用全局批量大小为 4，学习率为 1×10⁻³，权重衰减为 3×10⁻⁵，γ 值为 2.0。

  • 评估指标。 为了全面评估搜索配置在多样化目标领域的零样本可转移性，我们采用适合每个数据集形态学特征的多方面评估协议。对于除平衡错误率（BER）之外的所有指标，值越高表示性能越好。

  • 结构和对齐指标：对于需要严格前景对象一致性和结构完整性的数据集（Kvasir-SEG、CVC-612 和 CAMO），我们利用 S-measure（S_α）[14] 和增强对齐度量（E_φ）[15]。

  • 空间重叠和区域指标：对于精确空间重叠是最关键成功因素的任务（ISIC2017、Leaf 和 Road），我们依赖广泛采用的 Jaccard 指数。此外，加权 F-measure（F_β^ω）在多个数据集上进行评估，以自适应地强调高度显著区域中的错误。

  • 平衡错误指标：平衡错误率（BER）专门应用于评估 SBU 数据集上的性能。它通过同等加权阴影和非阴影区域的分类错误率，确保阴影检测的无偏评估。

对策略分布、状态转换和时间动态的后续分析揭示，LLM 本质上发展出复杂的探索-利用范式，逐渐从广泛的结构探索转向关键架构锚点的贪婪利用。

分析这些推理模式的时间演变揭示了合理的搜索逻辑而不是策略的随机应用（图 7）。最初，搜索器主要采用邻域变异来导航配置空间，选择对历史高性能基线引入局部结构扰动的候选 NCode。随着搜索的进行，利用这种邻域变异的概率逐渐减少，让位于利用历史上下文的利用模式。至关重要的是，这种转变适应目标任务的复杂性。在较简单的 NAS-Bench-201 图像分类基准上，搜索器逐渐转向位置锚定策略，表明学习到的在关键拓扑位置固定特定、高产模块的倾向。相反，在高度复杂的 GenEval 文本到图像合成任务上，模型逐渐转向组合协同。通过关注 NCode 内的多位数字模式，它展示了解开异构配置复杂组合效应的能力。

此外，全局组件分布的轨迹，其中搜索器基于特定操作数字的宏观频率而不是它们的绝对位置评估配置，揭示了不同的适应。在同质的 NAS-Bench-201 搜索中，这种策略的利用逐渐加强，从最初的 10% 扩展到近 20%。与此形成鲜明对比的是，对于异构的 GenEval 任务，这种模式始终保持低调，稳定在约 5% 的概率。这种分歧为系统的开放世界泛化能力提供了令人信服的证据：虽然模型学会利用全局频率启发式作为同质模型架构搜索的稳定描述符，它正确地认识到跨架构、数据和超参数的联合优化需要严格偏离简单的全局计数。最终，这些动态表明基于 LLM 的搜索器不仅仅记忆模式；相反，它通过自适应地组合不同的策略来有效地导航搜索空间以精确定位最优配置。

IV-G 消融研究

为了验证我们方法和结果配置的有效性，我们将我们的方法与几个基线进行了比较。如表 IV-F2 所示，我们的联合架构和超参数搜索方法分别以 0.05 和 0.02 的总分超过了仅架构搜索和仅超参数/数据比例搜索。这突出了联合优化模型架构、训练超参数和数据比例的关键重要性。此外，当应用搜索的 AutoML 配置而没有搜索的架构或没有超参数和数据配置（恢复到手动设计的基线）时，总分分别下降 0.07 和 0.09。这些结果证明我们的基于 LLM 的搜索器成功地导航了所有配置的最优组合，而不是将它们的优化视为孤立的问题。

此外，为了研究我们框架中关键组件的功效并评估不同 LLM 主干的影响，我们在 NAS-Bench-201 基准上进行了全面的消融研究（表 IV-F2）。如表 IV-F2 所述，移除基于剪枝的架构采样策略（无基于剪枝的样本）在所有三个数据集（CIFAR-10、CIFAR-100 和 ImageNet16-120）上引起明显的性能下降，验证了其在增强轨迹多样性和结构分布中的关键作用。更重要的是，当禁用目标重构机制（无目标重构）并强制模型直接生成完整 NCode 而不是对候选者进行排序时，我们观察到灾难性的性能崩溃（例如，ImageNet16-120 上的测试准确率从 46.51% 暴跌至 42.53%）。这种急剧下降坚定地证明将离散优化重构为可处理的排序任务实质性地减轻了 LLM 搜索器的学习负担。

此外，我们比较了基于 LLaMA-3.1-8B 和 Qwen3-8B 构建的基于 LLM 的搜索器的搜索效率。实证结果表明，两个模型在所有验证和测试集上实现了高度相当和竞争性的性能（例如，在 CIFAR-100 上分别达到 72.96% 和 73.13% 的测试准确率）。这种可比的性能证明通过组相对策略优化（GRPO）灌输思维链推理能力不会危害核心优化效能。为了优化整体搜索效率并规避与令牌繁重的 CoT 生成相关的实质性计算开销，我们部署 LLaMA-3.1-8B 搜索器来执行本研究中报告的所有主要搜索环境。同时，Qwen3-8B 搜索器专门用于可解释性分析，以解开和系统地解释通用搜索代理的内部决策机制和时间战略转换。

IV-H 案例研究

为了进一步评估我们优化的扩散 Transformer 的细粒度组合文本到图像对齐，我们提出了定性案例研究，将我们的方法与 120 亿参数的 FLUX.1-dev [27] 和 AutoML 方法 OptFormer [9] 进行比较。如图 8 所示，我们的方法在涉及着色、属性绑定和空间关系的复杂组合提示中展示了卓越的语义理解和指令遵循。

具体而言，在评估颜色属性绑定的前两列中，FLUX.1-dev 难以克服强烈的视觉先验并将非典型颜色分配给对象。它生成标准的橙色而不是请求的"红橙色"，并且尽管提示明确指定"白色停止标志"，但默认为标准红色停止标志。相比之下，我们的方法忠实地遵循指令，准确地渲染红橙色和白色停止标志。在第三列（"紫色酒杯和黑色苹果的照片"）中，FLUX.1-dev 错误地解释了属性绑定，将紫色应用于液体酒而不是玻璃本身。相反，我们的模型成功地解开了这些概念，生成了紫色色调的玻璃。

此外，我们的方法在理解空间动态和关系对象关联方面表现出色。在第四列（"花瓶在马右边的照片"）中，FLUX.1-dev 未能理解不同的对象关系，遭受概念渗透，错误地生成了由与花瓶匹配的瓷器材料制成的马。类似地，在第五列（"鸟在沙发左边的照片"）中，FLUX.1-dev 未能反映用户请求的正确相对空间定位。我们的模型在这两个实例中都正确地捕获了这些空间和组合动态。最后，虽然 OptFormer 展示了中等程度的指令遵循，但它遭受严重的几何失真和缺乏真实感。例如，OptFormer 生成了一匹缺腿的马（第 4 列），并产生了严重变形、不真实的沙发结构（第 5 列）。这些定性结果强调了我们基于 LLM 的搜索框架发现产生高保真、真实感和高度指令符合的视觉生成的模型配置的能力。

V 结论和未来工作

在本文中，我们提出了一个通用的基于 LLM 的 AutoML 框架，旨在跨开放世界场景联合优化模型架构、训练超参数和数据比例，而无需任务特定的微调。通过引入 NCode（一种统一的数值编码方案），我们将异构设计选择映射到通用离散序列中，并将优化过程重构为条件候选排序问题。仅在从单一领域视觉数据集整理的轨迹数据上训练，我们的搜索器在七个领域、四个任务和三个模态（视觉、文本和音频）中展示了卓越的零样本泛化能力。实验结果验证了其最先进的效率和可扩展性，特别是优化 13 亿参数的扩散 Transformer 以获得 0.91 的 GenEval 分数。

此外，通过组相对策略优化（GRPO）灌输思维链推理，我们阐明了搜索器的内部决策机制，揭示了从早期多样性驱动的探索到后期锚点利用的自适应转变。这项工作为自主、通用的机器学习优化建立了一条可扩展、可泛化和可解释的途径。未来的工作将探索将搜索器扩展到视觉语言模型（VLM），以整合直接的视觉奖励以进行更丰富的生成质量评估。
