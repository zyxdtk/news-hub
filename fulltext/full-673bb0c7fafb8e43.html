摘要

当前的零样本异常检测方法通常依赖复杂的提示学习技术或计算代价高昂的滑动窗口策略来实现细粒度视觉对齐以检测小尺度异常。这种依赖源于标准 CLIP 架构的根本局限：[CLS] token 注意力和空间 patch 池化难以捕捉细微的、局部化的异常特征。虽然提示学习方法旨在弥合这一差距，但它们通常需要来自辅助数据集的大量真实分割掩码，而这些掩码在专业领域中往往无法获得。在本工作中，我们展示了视觉语言模型中多头注意力池化的一个新兴特性：开箱即用的卓越零样本异常定位与检测能力。我们将这一特性转化为一种单次前向异常检测技术——RADIOlogy，它无需密集的窗口化执行，并显著优于其他免训练基线方法。该方法依赖于一种简单的对比评分方法，比较视觉特征与一组正常和异常提示之间的平均相似度。此外，我们利用 RADIO 模型的聚合特性，通过密集异常细化流水线增强像素级异常分割。最后，我们展示了免训练零样本异常检测技术的视觉语言模型家族如何在最小修改的情况下成功应用于医学领域。代码可在 https://github.com/jacomof/RADIOlogy 获取。

1 引言

视觉异常检测（AD）旨在识别和定位图像中不规则的视觉模式，这些模式通常与异常相关 [3]。由于异常事件本质上罕见且结构上不可预测，传统方法通过无监督或自监督表示来建模正常外观的分布 [37,10,11,15,27]。多模态基础模型和零样本迁移的最新突破催生了一类相对较新的技术：零样本异常检测（ZSAD）[20,53]，这类方法在无法访问目标分布的参考正常样本的情况下识别分布外缺陷。在 ZSAD 中，现有范式大致分为两类：跨数据集训练方法 [7,30]，从单独的标注数据集学习辅助缺陷先验；以及免训练方法，严格依赖冻结基础模型的内在表示 [20,29,19]。

图 1：性能与延迟对比。RADIOlogy（以星形标记表示）、五个已发表的免训练基线方法和朴素 CLIP 方法在七数据集工业套件上的异常分割和分类性能相对于检测延迟的关系。我们的方法以显著优势超越基线方法，同时比除朴素 CLIP 方法外的所有方法至少快两倍。

免训练方法对现实世界部署特别有吸引力：它们绕过了辅助训练的操作开销和计算费用 [20]，能立即适应严重的域偏移 [49]，并消除了在专业下游领域中对精心策划的缺陷标注的需求 [7]。

直到最近，免训练流水线仍以 WinCLIP [20] 为核心，该方法通过预定义的提示集成查询弱监督视觉语言模型（VLM）CLIP [34]。然而，标准 CLIP 架构的一个根本局限是其较弱的 patch 级视觉语言对齐 [52,48]。为了绕过原始 patch 嵌入的噪声定位，WinCLIP 依赖昂贵的多尺度滑动窗口执行，在每张图像的大量局部裁剪上提取 [CLS] token。虽然这有效地规避了 CLIP 较差的密集特征，但这种多次窗口化引入了推理延迟和计算开销。因此，最近利用 CLIP 的工作已转向在辅助异常语料库上进行提示调优或微调视觉语言骨干网络 [53,30]，在很大程度上放弃了免训练架构。

在本工作中，我们证明了视觉语言架构的现代进展使得复杂的窗口化流水线变得不再必要，最终目标是重振语言对齐的免训练异常检测。通过研究 SigLIP 系列 [51,45] 采用的多头注意力池化（MAP）机制，以及在现代聚合基础模型（如 C-RADIOv4 [36]）中固化的机制，我们发现了一种新兴能力：MAP 池化的编码器直接从单次前向传播中产生内在良好对齐的密集视觉语言异常特征。由于 MAP 通过学习的摘要查询关注单个 patch token，每个 token 保留了与文本提示的强独立语义对齐。这消除了阻碍标准 CLIP 骨干网络的结构瓶颈。

利用这些特性，我们提出了一个统一的免训练零样本异常检测框架 RADIOlogy。对于图像级检测，我们的流水线在单次前向传播中对全局异常边际进行评分，在不使用裁剪集成的情况下，在基准数据集上设定了免训练方法中的新最先进水平。对于像素级分割，我们利用 C-RADIOv4 原生暴露的互补教师头。其原始主干特征提供内容自适应的亲和图以锐化缺陷边界，而 SAM3 对齐的特征使对象部件聚类能够保持结构边界。结合抑制背景噪声的免训练前景先验，我们的方法弥合了多裁剪与单次前向免训练异常检测方法之间的性能差距。

最后，我们观察到，先前在医学领域对免训练 VLM 方法的评估受到不充分工业先验的人为限制。我们表明，在我们特定流水线的背景下，将领域适当的临床术语替换到提示集成中，可以在免训练零样本机制中实现最先进的医学异常检测，而无需针对每个数据集进行提示工程。

总结而言，我们的主要贡献如下：

• 我们引入了一种对比异常评分策略，该策略依赖于正常和异常提示之间对齐的差异，而非绝对相似度分数。
• 我们提出了一种利用 C-RADIOv4 多教师表示的异常分割细化策略。
• 我们确定基于 MAP 的视觉语言编码器是单次前向机制中零样本异常检测的优越骨干网络。
• 我们证明了 VLM ZSAD 在免训练机制中以最小修改即可有效泛化到医学领域。

2 相关工作

视觉异常检测。 视觉异常检测（AD）包含由目标域数据可用性定义的各种操作机制 [3,37]。在标准无监督 AD 下，模型可以访问干净的标称训练样本集，以构建正常性表示，据此识别分布外偏差 [11,50]。批处理零样本设置评估包含正常和异常图像混合的小型未标记目标集 [28]。相比之下，纯零样本异常检测（ZSAD）在最严格的约束下运行：在无法访问任何目标域训练样本的情况下识别和定位目标数据集中的异常 [20]。

零样本异常检测范式。 在 ZSAD 中，出现了两种主要方法论：辅助训练方法和免训练方法。辅助训练方法通过在不相关的基础数据集上学习缺陷表示来依赖跨数据集泛化。这些包括优化连续文本/视觉提示的提示调优技术 [53,7]、跨多模态组件的全网络微调 [30,54]，以及模拟表面异常的合成缺陷注入方案 [13]。虽然有效，但辅助训练会产生大量的适应成本，并存在过拟合到合成或特定领域缺陷原型的风险。相反，免训练方法利用预训练基础模型中嵌入的隐式世界知识和语义先验。基础性工作，如 WinCLIP [20] 和 FADE [29]，通过预定义的组合文本提示查询冻结的 CLIP 表示。最近的扩展探索了通过扩散反演的生成重建（如 DIVAD [19]）或非参数 patch 记忆检索（如 MRAD-TF [49]）。然而，生成式和滑动窗口架构在推理期间的计算成本仍然过高，而原始 CLIP 特征在密集评估时表现出严重的空间退化。我们的框架通过消除窗口化推理同时实现免训练方法中最先进的分割质量，推进了免训练 ZSAD 范式。

视觉语言与聚合基础模型。 视觉语言模型（VLM）通过联合对比目标将视觉和文本模态映射到共享的度量嵌入空间 [34,22,12]。标准 CLIP 骨干网络使用专用的 [CLS] token 提取全局图像摘要 [34,42,12]。虽然对整体场景理解有效，但标准 ViT 中无约束的自注意力导致局部 patch 嵌入的语义特异性下降，阻碍了细粒度的 patch-文本对齐 [52]。为了解决这些表示瓶颈，SigLIP 架构 [51,45] 用成对 sigmoid 损失替换了成对 softmax 对比损失，并采用了 MAP。MAP 通过学习的查询探针总结视觉序列，将单个 patch 表示与全局 token 混合解耦，从而保留局部语义对齐 [26,51]。与此同时，基础模型蒸馏产生了聚合多模态编码器，将不同的能力统一到单个单体骨干网络中 [35,46,38,40]。以 RADIO 框架 [35,18,36] 为例，这些架构采用轻量级投影适配器来同时模拟多样化的教师空间，包括零样本分割（SAM [24,8]）、自监督密集几何（DINOv2/v3 [32,41]）和开放词汇语言对齐（SigLIP2 [45]）。通过利用 C-RADIOv4 的统一特征空间，我们的工作证明了 MAP 语言对齐、视觉骨干网络的结构亲和力与 SAM 部件分割之间的协同作用，能够在无需专门网络微调的情况下实现全面的单次前向零样本异常定位。

3 方法

图 2：我们提出的方法概述。首先，输入图像由聚合编码器和三个教师头中的两个（SigLIP2 和 SAM3）编码。使用语言对齐的特征和提示集成，计算每个 token 嵌入的边际分数，以获得图像级异常分数和原始 patch 级边际分数 (1)。然后，使用上下文池化 (2)、亲和力细化 (3) 以及最后的对象部件池化 (4) 对 patch 分数应用像素级细化。最终分数按 patch 聚合，通过将基于颜色的前景分割掩码应用于 patch 分数获得最终的异常掩码。

我们的流水线（如图 2 所示）通过聚合编码器的单次前向传播，同时产生图像级异常分数和像素级异常图。3.1 节固定符号和提示集成，我们继承自 WinCLIP [20]。3.2 节描述如何将 MAP 嵌入用作异常分类器。3.3 节通过将 patch-文本评分与来自 C-RADIOv4 [36] 的两个辅助信号结合，从相同的前向传播构建异常图。这些包括用于空间细化的 C-RADIOv4 原始密集特征和用于对象部件聚类的 SAM3 对齐特征。3.4 节添加了在评分后抑制背景的免训练前景先验。3.5 节描述了将整个流水线移植到医学领域的单一替换。

3.1 预备知识

文本锚点。 给定测试图像 x，SigLIP2 兼容的视觉骨干网络 φ 产生 N 个 patch 嵌入 {p_i}_{i=1}^N ⊂ ℝ^d，排列在 g_h × g_w 网格上，以及单个全局嵌入 𝐠 ∈ ℝ^d，两者均已投影到 SigLIP2 [45] 的联合视觉语言空间。对于所采用的主编码器 C-RADIOv4，φ 是蒸馏主干和 SigLIP2 对齐投影头的组合。遵循 WinCLIP，我们从 22 个摄影模板（如 "a photo of a {}"、"a close-up photo of the {}"）与一小组正常和异常状态短语（如 "flawless {}"、"{} with defect"）交叉构建文本集成，类别名称替换到 {} 中。对于每个类别 c，每个模板-状态组合都被编码，嵌入进行 ℓ2 归一化，并计算正常和异常提示的平均值。这个初始的 ℓ2 归一化在平均之前执行，因此较长的提示不会主导集成。这为每个类别产生两个单位向量 t_n 和 t_a，即正常和异常文本锚点。我们逐字重用 WinCLIP 的原始工业词汇；我们纳入的唯一替换是 3.5 节中描述的域范围替换。

对于从视觉嵌入获得的单位范数向量 v，我们定义异常边际：

μ(v) = ⟨v, t_a⟩ − ⟨v, t_n⟩. (1)

由于两个文本锚点共享描述类别的所有公共元素（如对象身份），它们的差异消除了该共享分量，并产生分离正常与异常外观的轴。我们对图像级分数和像素级图的每一步使用不同输入的 μ。

MAP 头的密集对齐。 我们利用 MAP 头对齐的视觉编码器的密集特征（通过模型的单次传播获得）来构建我们的异常检测机制。MAP 头用学习的查询总结 token 网格，该查询关注视觉骨干网络产生的每个 patch token。该头的输出是与文本表示对齐的图像全局表示，使用二元分类或对比损失。在其最简单的形式中，预训练任务包括判断输入图像和输入文本是否相关。鉴于 token 嵌入作为 MAP 头的直接键和值，并且该头相对于视觉骨干网络较浅，它被迫积极地对齐 patch token 表示以获得高质量的摘要表示。这在结构上不同于 CLIP 的原始方案 [34]，其中 [CLS] 摘要 token 通过重复的自注意力块与每个 patch 混合。结果是 [CLS] token 与每个 patch token 之间更稀释的关系，最终导致弱密集对齐。注意，虽然 C-RADIOv4 内部不使用 MAP 头，但其与 SigLIP2 的 MAP 模块的对齐保留了其密集特征质量。

3.2 异常分类

我们用单个数字对图像评分，s = μ(𝐠)，直接使用 MAP 池化的全局嵌入对文本锚点进行评分。这绕过了基于 VLM 的异常检测流水线中的标准做法，该做法采用密集和全局特征的组合来获得异常分类分数 [20,29]。

3.3 异常分割

我们利用 MAP 对齐的视觉编码器产生的强密集特征，通过单次前向传播获得每个 patch 的异常分数。3.2 节中描述的图像级分数在构造上丢弃了空间信息。为了定位异常，我们使用相同的边际公式直接对 patch 评分，并使用相同编码器传播产生的两个信号细化结果：C-RADIOv4 原始密集特征和 SAM3 对齐的密集特征。对于视觉骨干网络产生的 patch 嵌入 p_i，我们将其原始 C-RADIOv4 特征定义为 f_i。

Patch-文本边际与上下文池化。 原始像素图将公式 1 应用于每个 patch 嵌入 p_i，m_i = μ(p_i)，其中 m_i 表示 p_i 的边际分数。就其自身而言，该图在语义上有信息量但在空间上有噪声：单个 patch 并不总是包含足够的语义信息来表示异常概念。我们通过在评分前对 k × k 邻域 W_i 上的 patch 嵌入进行平均池化来恢复上下文：

p̄i = (1/|W_i|) Σ{j∈W_i} p_j, m_i^k = μ(p̄_i). (2)

亲和力细化。 方形窗口不加区分地混合对象和背景，导致低分辨率的缺陷边界。为了解决这个问题，我们用内容自适应的窗口替换方形窗口，该窗口从 RADIO 的密集原始特征 {f_i} 构建，更适合识别语义相关的视觉概念。我们构建 patch 亲和矩阵：

A_ij = exp(f̂i · f̂_j / τ) / Σ{k≠i} exp(f̂_i · f̂_k / τ), j ≠ i, (3)

其中 f̂ 表示 ℓ2 归一化特征，τ 是确定亲和分布均匀性的温度参数。A 的对角线被排除，因此 patch 的相同自相似性不会使 softmax 塌缩到恒等上。然后我们在这个图上扩散边际场 m：

D: m ← αm + (1−α)Am, (4)

其中 α 是确定扩散过程 D 强度的衰减系数。该过程受 CLIP-DINOiser [48] 语义分割细化的启发，执行少量固定次数的迭代，使 patch token 中嵌入的信息被来自相邻 patch 的信息丰富。这通过允许语义相关 token 之间的信息共享，将缺陷锐化到其真实范围。

对象部件区域池化。 上下文池化和亲和力细化基于固定邻域操作，并忽略单个对象的边界。为了解决这个问题，我们在 RADIO 的 SAM3 对齐特征上利用球形 k-means。由于 SAM3 是为分割训练的，其特征更适合此任务。使用这种聚类算法，图像的 patch 网格被划分为 K 个尊重对象结构而非固定或扩散区域的聚类。我们在评分前池化每个聚类内的文本对齐嵌入：

z_i^K = μ(Σ_{j:c(j)=c(i)} 𝐩_j / ‖Σ_{j:c(j)=c(i)} 𝐩_j‖_2), (5)

其中 c(i) 是 patch i 的聚类分配，因此整个部件作为一个单元被评分。分段常数图丢弃区域内的梯度；因此，我们将区域分数与公式 2 中 k=5 的上下文场平均：

m_i^{K,mix} = (1/2)(z_i^K + m_i^5). (6)

为了最大化对广泛对象部件关系配置的覆盖，然后我们在一个或多个聚类计数和公式 4 的亲和扩散 D(·) 上平均该量。这类似于 WinCLIP 跨多个窗口尺度平均的方法，但没有每张图像多次骨干网络前向传播的计算开销。最终掩码前的 patch 级分数使用以下四路平均计算：

m_i^final = (1/4) Σ_{K∈{8,32}} [m_i^{K,mix} + D(m_i^{K,mix})]. (7)

3.4 前景掩码

鉴于图像背景通常缺乏特征且缺乏独特语义，将语义对齐的 patch-文本边际应用于背景 patch 会产生异常分数噪声。为了减轻这种失真的影响，我们在应用先前描述的 patch 评分方案后应用前景掩码。为此，我们提出了一种简单的方法：完全从图像计算的前景先验，无需骨干网络也无需学习的特征。对于测试图像，我们取沿图像边界的固定宽度条带的中值 RGB 颜色，并以像素分辨率计算每个像素与该颜色的距离。Otsu [33] 方法自动对该场进行阈值化，如果 patch 的任何像素高于阈值，则该 patch 被视为前景。在没有背景的图像中（如 MVTec-AD 上的表面类别），Otsu 方法变得无信息量，并且通常基于表面特征导致输入图像的任意分区。我们不为为此引入单独的检测器，而是重用 3.2 节中的机制。我们用公式 1 的边际对相同的 MAP 池化全局嵌入 𝐠 评分，替换第二对文本锚点。第二对 t_obj 和 t_surf 分别由对象类词汇（即 "object"、"thing"）和表面类词汇（即 "surface"、"texture"）构建。更确切地说，这个语言引导的背景门定义在 MAP 池化摘要 token 𝐠 上：γ = μ_obj/surf(𝐠)。每当 γ 低于固定阈值时，掩码被禁用。与状态词汇本身一样，这个对象/表面对是先验声明的，每个域交换一次。唯一增加的成本是两个锚点的文本编码器查询；不需要额外的图像前向传播。如果 patch 的任何像素在前景掩码内，则该 patch 被标记为前景，背景 patch 的边际在上采样前被图像自身的最低分数替换。这样做是为了确保被掩码的区域永远不会超过真正正常的前景 patch。

3.5 域词汇适应

上述每一步都仅通过状态词汇依赖于文本锚点 t_n、t_a；图像、编码器和聚合在所有域中保持固定。WinCLIP 的状态词汇假设制造环境，使用诸如 "damaged" 或 "with flaw" 之类的描述符，这些在语义上无法转化为医学环境。为了适应医学领域的适当先验，我们将工业状态词汇替换为从领域知识派生的临床集合（如 "{} with a lesion"、"diseased {}"），并固定流水线的所有其他组件。

在本工作中，我们展示了窗口化执行的计算复杂性不是基于提示的零样本视觉异常检测的基本前提。通过系统分析视觉语言架构的 token 池化动态，我们证明了多头注意力池化固有地保留了细粒度的 patch 级文本对齐，克服了历史上降低标准 [CLS] 基于 CLIP 编码器的结构性 token 混合限制。利用这一特性以及聚合 C-RADIOv4 骨干网络暴露的蒸馏表示，我们统一的 RADIOlogy 框架在单次前向传播中计算全局异常边际，同时应用免训练像素细化以产生清晰、局部化的缺陷分割。在十四个工业和临床基准中，我们的方法在免训练机制中设定了新的最先进水平，在以先前基线推理延迟的一小部分运行时，提供了相对于先前基线的实质性增益。

局限性与未来工作。 我们的框架存在一些限制，为未来的研究提供了机会。启发式前景先验假设标称背景边界，这对于接触图像边界的偏离中心对象会失败。将深度估计头纳入聚合编码器可以建立稳健的几何边界来解决这一问题。此外，异常检测与定位分割之间仍然存在性能差距。为了解决这一问题，未来的方向包括集成多分辨率 token 表示以捕获精细结构缺陷，以及微调 C-RADIOv4 骨干网络以弥合与训练的 ZSAD 方法的差距。
