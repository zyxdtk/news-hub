原标题：Flipper Device’s new Busy Bar is a customizable display for productivity

中文摘要： Flipper Devices推出全新生产力工具Busy Bar。该设备配备LED矩阵显示屏，支持设置计时器、屏蔽应用和自定义消息，适合居家办公场景。它拥有Matter认证，支持智能家居联动，并提供开放固件供开发者定制。设备将于7月14日开售，起售价179美元。

总部位于伦敦的 [Flipper Devices](https://flipperdevices.com/) 因其 [Flipper Zero 设备](https://techcrunch.com/2023/09/05/flipper-zero-hacking-iphone-flood-popups/) 而闻名，黑客和创客们使用该设备通过蓝牙、RFID、NFC 和 1GHz 以下收发器来访问不同的无线电。该公司今天采取了不同的方向，推出了一款专注于生产力的设备，名为 [Busy Bar](https://busy.app/)，它可以帮助你设置计时器、屏蔽应用程序，并在 LED 显示屏上显示自定义消息和小部件。

Flipper Devices 去年宣布了这款设备，现在将于下个月开始公开发售。Busy Bar 看起来像一个带有许多旋钮和按钮的台钟。正面配备了一块 72×16 LED 矩阵显示屏，亮度高达 400 尼特，支持 1600 万种颜色，并配有可自动调节亮度的传感器。

背面有一块单色屏幕，用于显示状态、计时器、电池和连接指示器。这样即使主屏幕朝向另一侧，你也能查看信息。此外，侧面还有一个小型扬声器，用于播放自定义声音和通知。

![Image 1](https://techcrunch.com/wp-content/uploads/2026/06/bb_pdp_back_desktop_v1.jpeg?w=680) **图片来源：**Flipper Devices

顶部有一个模式选择开关、一个启动/停止按钮、一个指示灯和一个用于导航菜单和设置时间的滚轮。该设备支持 Wi-Fi、蓝牙和 USB 连接。

Busy Bar 配备了一块 3250 mAh 电池，在活跃状态下可续航长达 8 小时，待机时间长达两周。该公司表示，使用 15W 适配器，用户可以在一小时内将设备充满电。

这款设备背后的理念是，你可以设置一条消息，在执行任务时向他人（以及你自己）发出提示。这在居家办公且家里有其他人的情况下非常有用。你还可以设置番茄工作法风格的计时器，划分生产力时间块，让你集中精力完成任务。

Flipper Devices 正在发布适用于 iOS、Android 和 macOS 的应用程序，并计划支持 Windows 应用。用户可以在 iOS 和 Android 上使用不同类型的计时器屏蔽选定的应用程序。此外，该设备还与 macOS 进行了麦克风集成，当你加入会议或开始录制或流式传输时，设备会在显示屏上显示“通话中”状态，并静音通知。

![Image 2](https://techcrunch.com/wp-content/uploads/2026/06/Automatic_status_activation_oncall_2026.jpeg?w=680) 图片来源： Flipper Devices**图片来源：**Flipper Devices

Busy Bar 还获得了 Matter 认证，这意味着它可以与你现有的基于亚马逊、苹果和谷歌的智能家居生态系统配合使用。这意味着用户可以根据该设备的状态触发智能家居自动化。

该公司使该设备适合开发者使用开源固件进行定制。他们可以使用开放的 HTTP API、MQTT 以及官方的 Python 和 TypeScript 库来构建小部件和组件。用户还可以[通过其云 API 在互联网上控制 Busy Bar](https://cloud.busy.app/api-tokens)。

用户可以注册候补名单，以 179 美元的特价购买 Busy Bar。一旦开始公开发售，前 3000 名用户将能够以 199 美元的价格购买该设备。所有其他用户将需要支付 249 美元。发货和销售将于 7 月 14 日开始，面向美国、欧盟、英国和加拿大。该公司还计划发布配件，包括壁挂支架、屏幕保护膜和定制开关。
