OpenAI 全面开放 Jev 竞品，决策模...

📅 2026-10-22 📄 TechCrunch AI 🔗 原文链接

原标题：OpenAI makes its Jev competitor widely available as decision model competition heats up

中文摘要： OpenAI 正式向所有客户开放 Decisions API，进军由 TypeSafe 的 Jev 模型开创的快速、低成本决策模型市场。该 API 基于重新配置的 ChatGPT Luna，将响应时间从数秒缩短至约百毫秒。Box、Datadog、Speak 等客户已用它替代 LLM 以提升吞吐量。随着 Liquid、Base Lab 等竞争者加入，决策模型市场竞争日趋激烈，而速度与成本的持续下降有望催生更多新用例。

首次向广大用户开放，进军快速、廉价的智能市场。这一市场最近让 TypeSafe——一家由前沿实验室前研究员创立的初创公司——成为了一家市值 76 亿美元的企业。

TypeSafe 的 Jev 模型开创了一个全新类别：充当超级分类器的深度学习模型。给定一组选项，它们可以快速做出选择，并为其决策提供置信度评级。软件开发者很快发现，这些决策模型（或称“系统一”模型）可以在多种工作流中替代 LLM，运行速度更快，成本也大幅降低。

OpenAI API 产品负责人 Nikunj Handa 告诉 TechCrunch，他的同事们看到 Jev 后说：“哇，我们大概有一百万个应用场景。”Handa 的团队火速推出了自己的版本：他们没有专门构建一个经过校准的决策模型，而是对 ChatGPT Luna 进行了重新配置，以加快推理速度并降低成本。

“Decisions API 的重大突破在于速度，把原来一到三秒的时间缩短到了 100、120、180 毫秒，”Handa 说。“未来，我们可能会进行一些专门训练，让我们的模型在这些方面更上一层楼。但就目前而言，普普通通的 Luna 就能把活干好。”

Decisions API 于 9 月 29 日在该公司的开发者日上亮相，并于周四面向所有客户开放。OpenAI 为公开版本增加了新的语音和视觉模态，并通过按地理位置部署推理资源，致力于确保全球各地区更低的延迟。

在与 Box、Datadog、Ramp 和 Speak 等客户的初步试验中，工程师们使用该 API 以更高的吞吐量替代了 OpenAI 的 LLM。开发 AI 语言辅导产品的 Speak 公司 CTO Andrew Hsu 表示，Decisions API 帮助公司将动作之间的间隔时间从 1.4 秒缩短到 0.13 秒。OpenAI 还使用该产品提升了其 Dots 语音助手的响应能力。

不过，除了“对你有用”之外，究竟什么才算好的决策模型仍不明朗——在智能、成本、校准和速度之间的优化似乎因工作负载而异。TypeSafe CEO Diogo Almeida 对基准测试持不信任态度，并敦促人们在自己的工作中试用这些模型。但即便是 TypeSafe，上周在发布其最新 Jev 模型的同时也发布了自己的排名，新模型包含支持图像和 smart-if 语句等新功能。

AIM System One Index 和 Artificial Analysis Decision Index 等公开基准测试往往更青睐 Liquid 上周发布的新决策模型 D1 Ultra 以及 Base Lab 的 Elephant-1。最新的 Jev 模型在两项指数上仍具竞争力，分别位列第七和第三，而 OpenAI 的决策模型则分别位列第八和第十四。不过，就目前而言，TypeSafe 的产品在 OpenRouter 上的查询量最大。

然而，最有趣的 Jev 基准测试当属 JevMan——一个让决策模型玩吃豆人（PacMan）的基准测试；最新的 Jev 模型在该排行榜上高居榜首。构建该基准测试的 Opper AI 首席增长官 Felix Wunderlich 表示，这款经典游戏“是一个有趣的测试，因为它需要不间断地做出快速、高风险的决策。在每个路口，模型都必须在几百毫秒内决定往哪里走。”

OpenAI 这款可以说更强大的模型，其优势可能在于多模态——在图像分类方面，“Luna 极其强大，并且一直表现出更好的校准度，”Handa 告诉 TechCrunch。他还补充说，OpenAI 的客户希望 Decisions API 在使用图像作为输出方面也能更加灵活。

Handa 还认为速度的进一步提升将带来新的用例：“我们能不能把它做到大概 60 毫秒？那样你就可以想象，比如对视频中的每一帧都进行一次 API 调用？”

随着这些产品变得更快、更便宜，我们可以预期它们将印证 Jev 之名的由来——那位经济学家曾解释，更高效地使用一种资源会如何使其更加无处不在。或者用 Handa 的话说，将会出现不断扩大的“疯狂用例集”，这些用例一直隐藏在众目睽睽之下，直到决策模型将它们揭示出来。
