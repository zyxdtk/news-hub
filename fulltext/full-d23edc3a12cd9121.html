摘要。
将无人机（UAV）从其预定任务轨迹中重定向一直是一个活跃的研究领域。然而，现有的无人机重定向攻击在针对特定目标的诱导方面缺乏可靠性、精确性和隐蔽性。它们主要依赖物理捕获、通信劫持或传感器欺骗。但是，物理拦截成本高昂，只有一次成功机会，且附带损害风险高；基于网络的攻击需要深厚的技术专长和对加密通信通道的访问权限；而传感器欺骗技术通常无法达到将无人机引向指定目标所需的精度和鲁棒性。因此，我们提出了 Phantom Navigator，一种无人机重定向攻击，旨在隐蔽且精确地将无人机误导至指定的欺骗目标。我们的方法结合了离线的重定向前可达性分析（提供对可实现重定向范围的高保真估计）和在线闭环隐蔽执行层（确保在实际中成功重定向）。基于这种方法，我们构建了一个物理攻击平台，配备了激光雷达-相机检测、跟踪和欺骗栈，执行实时识别、位姿估计和针对性欺骗信号计算，以隐蔽且准确地将受害无人机重定向到指定位置。我们在真实案例研究中展示了我们的重定向方法和攻击实现的有效性。

为了验证该框架，我们实现了一个攻击者平台原型，配备了实时攻击管道，通过激光雷达-相机融合执行识别和跟踪、攻击结果估计和闭环欺骗信号生成。

2.2.
物理 GPS 接管攻击
GPS 欺骗通过伪造卫星信号来操纵飞行器定位，使接收器计算出错误的位置或时间。由于民用 GPS 信号缺乏身份验证，攻击者可以使用软件定义无线电（SDR）生成伪造信号，将接收器误导至任意轨迹
(
Tippenhauer et al., 2011
)
。典型的研究设置（例如，
(
Sathaye et al., 2022
)
）采用基于 SDR 的 GPS 信号发生器、射频放大器和全向发射天线，在屏蔽的微波暗室中运行，并使用动作捕捉系统进行地面实况跟踪；使用微波暗室是因为在非政府批准的设置中通过空中传输欺骗性 GPS 信号是非法的
(
Murray, 2019
)
。

通常，GPS 欺骗分为压制（即过功率）和接管攻击
(
Sathaye et al., 2022
)
。压制攻击以高得多的功率发射伪造的 GPS 信号，试图淹没合法信号，但由于 GPS 接收器端的突然变化，这很容易被检测到，导致卫星锁定突然丢失。
为了绕过 GPS 接收器端潜在的完整性检查，在接管攻击中，欺骗信号首先与合法信号同步；然后逐渐增加功率以诱发错误的位置估计。最后，通过复杂的接管后（欺骗）信号设计来规避传感器融合中的新息检查（例如，与 IMU 的融合）。

6.
讨论与结论
本文介绍了 Phantom Navigator，这是一种隐蔽的无人机重定向攻击，利用攻击者侧的跟踪和 GPS 欺骗能力来重定向受害无人机的轨迹。可实现的重定向能力由 GPS 欺骗的强度表征，这可以通过攻击前分析进行有效估计。然后，实时、轻量级的重定向控制器根据指定目标和估计的受害无人机位置生成欺骗信号，保持对间歇性跟踪退化的鲁棒性。在物理平台上的实验评估验证了 Phantom Navigator 在室内和室外环境中实现精确和可靠重定向的有效性。接下来，我们讨论我们提出的无人机重定向攻击框架的局限性、潜在改进和防御措施：

重定向攻击的隐蔽性。
在我们的工作中，重定向的隐蔽性是通过设计满足 Sec.
4.1
中讨论的隐蔽性约束的攻击信号来确保的。然而，我们的隐蔽性考虑了攻击者的最坏情况：受害者配备了高效的入侵检测系统，该系统平衡了高检测精度和低检测时间，并且对任务和环境引起的变化具有鲁棒性。这种检测器在商用自动驾驶仪中并未见到。相反，它们依赖于具有过于保守阈值的静态故障安全策略，为隐蔽欺骗留下了大量机会。因此，攻击者可以利用提出的隐蔽重定向攻击来诱发实质性的轨迹偏差，同时保持在检测阈值以下并满足预期的攻击目标。

迈向移动空中攻击者平台。
在这项工作中，我们考虑了一个静态攻击者平台。将攻击扩展到移动空中平台是一个重要的未来方向，但它给攻击者带来了额外的挑战。一个关键问题是自欺骗：在传输 GPS 欺骗信号时，攻击者可能会破坏自己的 GPS 测量值。为了减轻这种影响，移动攻击者可以依赖独立的定位源，包括

改进跟踪和重定向范围。
虽然本文提出了一种计算轻量级且在各种级别传感器退化下保持鲁棒的激光雷达-相机跟踪管道，但其性能本质上仍然受到相机和激光雷达的感知范围和分辨率的限制。在长时间感知丢失的场景中，仅在预测模式下运行的滤波器可能会由于缺乏测量更新而逐渐漂移。一个潜在的扩展是将 RADAR 集成到管道中，提供远程感知，以补充激光雷达的中程覆盖和相机的高分辨率但短程特性。

针对恶意重定向的防御。
潜在的防御包括两个方向。首先，更高精度的定位系统，如 RTK-GPS，可以减少定位不确定性并限制隐蔽欺骗信号的幅度。其次，结合环境语义或利用来自受信任代理和基础设施的协作感知，可以在不同的机载感知模块之间建立信任，并帮助识别恶意重定向攻击下被破坏的定位源。
