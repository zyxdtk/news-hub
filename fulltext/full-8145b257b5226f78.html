摘要

GRPO已成为利用可验证奖励来激发大语言模型推理能力的主流强化学习方法。然而，它存在一个根本性的失败模式：当训练问题超出基础模型的当前能力时，所有生成的响应都会失败并获得零奖励，从而无法产生梯度信号，阻碍了能力的进一步扩展。一类新兴的GRPO扩展方法，称为提示增强GRPO（HA-GRPO），通过在上下文中添加"提示"来降低问题难度，从而产生可用的梯度信号。然而，现有的HA-GRPO方法共享一个关键问题：在推理时没有可用的提示来附加到问题上，这造成了训练-推理上下文不匹配，导致不一致的性能提升。在本工作中，我们重新解读提示的功能——不是降低问题难度，而是引导模型行为——并基于这一观点提出了ASH（Activation Steering for Hinting），一种新颖的HA-GRPO方法。在训练过程中，模型同时面对带提示的问题和原始问题，同时优化一个可训练的引导向量来扩大模型对带提示版本响应的生成概率相对于原始版本的间隔，从而捕获提示所诱导的行为变化中与问题无关的成分。在推理时，训练好的引导向量直接注入到模型的激活中，在不需要任何上下文提示的情况下重现提示条件下的行为。在四个大语言模型（Qwen3-1.7B/4B-Base, Llama-3.2-1B/3B-Instruct）上的实验表明，ASH在竞赛级数学基准（AMC、OlympiadBench、AIME24、AIME25）和分布外基准（Minerva、GPQA-Diamond）上一致提升了pass@k。值得注意的是，它将Qwen3-1.7B-Base和Qwen3-4B-Base的平均pass@8分别提升了2.60%和2.21%。

1 引言

近年来，使用可验证奖励的强化学习已成为激发大语言模型推理能力的关键驱动力，特别是在数学和编程等领域，最终答案的正确性可以自动评分。在各种方法中，组相对策略优化被广泛采用；它消除了评论家模型，并通过组相对奖励归一化来估计一组生成响应的优势。尽管这种设计提供了令人印象深刻的计算效率，但当训练问题对基础模型来说太难时，它会根本性地失败：所有生成的响应都失败并获得零奖励；它们的优势因此消失，该问题不产生任何梯度信号，阻碍了基础模型之外的任何能力扩展。这一限制激发了对能在这种太难问题上产生梯度信号的方法的需求。

一种简单的方法是为太难的问题分配更多的生成预算，希望最终能获得罕见的成功响应；然而，这会使计算成本倍增。第二种方法使用成功响应的代理，如模型的置信度或确定性，但只能恢复间接的梯度信号。第三种更有前景的方法通过在上下文中添加"提示"来降低问题本身的难度，产生了一类我们称之为提示增强GRPO（HA-GRPO）的方法。例如，给定一个训练问题，QUESTA使用解答的前50%的token作为提示，并增强问题以引导模型走向成功的响应。后续的HA-GRPO方法采用了更微妙的提示提取机制；然而，它们都共享一个关键的、未解决的问题：训练-推理上下文不匹配，因为在推理时没有可用的提示来附加到问题上。直观地说，这些方法允许模型在训练期间通过利用辅助来"作弊"，而在推理期间（即真正的考试）不允许这种辅助。

为了表征这种训练-推理上下文不匹配的影响，我们使用GRPO和QUESTA在OpenR1-MATH-220k数据集的子集上训练Qwen3-1.7B-Base和Qwen3-4B-Base进行了初步实验（详见第6节）。如图1(a)所示，与GRPO相比，QUESTA在训练过程中大幅减少了每批次中太难问题的比例，符合预期。然后我们在训练数据上评估QUESTA训练的模型，分别在有问题提示和无提示的情况下。如图1(b)所示，在推理时没有提示的情况下，pass@k急剧下降；例如，Qwen3-1.7B-Base和Qwen3-4B-Base的pass@8分别下降了27.34%和10.83%。这些巨大的性能差距表明，用QUESTA训练的模型在训练期间严重依赖提示作为拐杖：提示所解锁的能力提升大部分都丢失了，因此模型对推理时实际面临的无提示环境的泛化能力很差。

为了缓解这个问题，我们重新构建提示的功能：不是像现有HA-GRPO方法那样将其视为降低问题难度，而是将其视为引导模型行为。这一观点将提示置于更广泛的基于上下文的控制范式中，与少样本上下文学习（通过演示引导行为）和指令跟随（通过明确指令引导行为）并列。在这种视角下，QUESTA和其他方法中的提示将模型行为引导向更高质量的推理空间，而不是降低问题难度，这表明对提示的依赖不是源于提示本身，而是源于信息在训练期间被引入但在推理期间被撤回的方式。

基于这一观点，我们提出了ASH（Activation Steering for Hinting），它利用提示通过模型的激活而非上下文来引导模型行为走向更高质量的推理空间。在训练过程中，同时呈现带提示的问题和原始问题，并将一个可训练的引导向量添加到模型在特定层的激活中，并对其进行优化以扩大模型在带提示版本下对响应的生成概率相对于原始版本的间隔。这驱动引导向量在激活空间中捕获提示所诱导的行为变化中与问题无关的成分，这正是能迁移到未见问题的成分。在推理时，训练好的引导向量直接注入到模型的激活中，在不让模型接触任何提示的情况下重现提示条件下的行为。由于提示的好处被蒸馏到在推理时仍然可用的引导向量中，ASH消除了训练-推理上下文不匹配，使模型能够保留提示所解锁的能力提升的很大一部分，而不是丢失它。

我们的贡献总结如下：

  • 训练-推理上下文不匹配问题。 我们识别了现有HA-GRPO方法忽视的一个关键问题，并进行了初步实验来表征其影响。
  • ASH。 我们新颖的HA-GRPO方法通过引导模型行为的视角来缓解所识别的问题。ASH将提示的行为变化内化到一个可训练的引导向量中，该向量在推理时仍然可用。
  • 评估。 ASH在四个大语言模型上一致提升pass@k。平均而言，pass@8的提升在Qwen3-1.7B/4B-Base上达到竞赛级数学1.97%/2.25%，分布外基准3.84%/2.13%；在Llama-3.2-1B/3B-Instruct上达到竞赛级数学1.86%/2.15%，分布外基准2.80%/2.11%。
  • 深入分析。 我们展示了训练好的引导向量可以有效地迁移到其他推理领域，如逻辑问答和编程。

2 相关工作

在本节中，我们首先回顾GRPO进展的先前工作，然后将重点缩小到提示增强GRPO（HA-GRPO）类别。然后，我们简要讨论激活引导研究。

GRPO进展 - 一系列工作旨在改进GRPO。例如，给定每个训练问题的一组生成响应，SAGE-GRPO试图控制这些响应的长度。Dr. GRPO旨在克服GRPO中的问题级难度偏差，而GRPO-LEAD则通过根据问题的难度（通过响应的逆成功率估计）重新加权每个问题来利用这种偏差。尽管进展迅速，GRPO的一个根本失败模式仍然存在：当训练问题对基础模型来说太难时，所有生成的响应都失败并获得零奖励；它们的优势消失，该问题不产生任何梯度信号，阻碍了基础模型之外的任何能力提升。为了解决这一限制，SA-GRPO和GRPO-ZVP利用模型的置信度和确定性作为代理来补充响应级奖励。然而，该代理与正确性脱钩，因此恢复的梯度信号不能保证指向增强能力的方向。

HA-GRPO - 一类GRPO扩展尝试通过在上下文中添加"提示"来降低此类问题的难度，基于其参考解答。例如，给定一个训练问题，QUESTA使用解答的前50%的token作为提示，并增强问题以引导模型走向成功的响应。BREAD使用前50%的句子，以"\n"分隔。后续方法引入了更微妙的提示提取机制。值得注意的是，Zhang et al. (2026a); Wang et al. (2026)利用脚手架理论构建分层渐进式提示而非解答前缀，尽管这种策略需要一个强大的专有教师模型（例如GPT）。为了放松这种依赖，SAGE从模型本身提取自适应提示，不仅以解答为条件，还以生成的响应为条件；HILL则同时创建模型的副本来充当提示提供者。尽管这两种方法消除了对专有教师模型的依赖，但两者几乎使计算成本翻倍。重要的是，现有的HA-GRPO方法专注于提示提取机制，而忽视了推理时没有可用的提示来附加到问题上的问题。在本工作中，我们通过引导模型行为的视角来缓解这种训练-推理上下文不匹配。

激活引导 - 一种基于激活的大语言模型行为控制范式。这是通过首先在大语言模型架构的特定层的激活空间中搜索"引导向量"来完成的。在推理时，这些引导向量被直接注入回去以改变模型生成。Turner et al. (2023)明确创建了与对比概念相关的引导向量，例如"爱"和"恨"。基于这一想法，Todd et al. (2024)构建了编码演示的引导向量以增强少样本上下文学习，Stolfo et al. (2025)构建了编码明确指令的引导向量以增强指令跟随。通常，这类技术从对比提示对中离线构建引导向量，限制了它们在复杂推理任务上的有效性。在本工作中，我们基于这一范式，构建了一个通过设计使其在线可训练的提示引导向量。

3 预备知识

我们形式化GRPO及其在太难问题上的失败，并介绍在其基础上构建的提示增强GRPO（HA-GRPO）类别。然后，我们描述激活引导的工作原理。

GRPO。 近期加强大语言模型推理能力的努力越来越依赖于GRPO，它从组相对奖励归一化中估计优势。设 π_θ 表示模型，由 θ ∈ ℝ^d 参数化。从训练数据 𝒟 中采样问题 q，模型生成 G 个响应作为一组 {o_i ∼ π_θ(·|q)}{i=1,...,G}。将它们的奖励表示为 {R_i}{i=1,...,G}，G 个响应的优势通过以下公式计算：

{A_i = (R_i - mean({R_i}{i=1,...,G})) / (std({R_i}{i=1,...,G}) + ε)}_{i=1,...,G}

接下来，通过最小化基于这些优势定义的（简化的）损失来更新模型：

J(θ; q) = -[1/G Σ_{i=1}^G 1/|o_i| Σ_{t=1}^{|o_i|} (r_θ(o_{i,t}) A_i)]

其中 r_θ(o_{i,t}) = π_θ(o_{i,t}|q, o_{i,<t}) / [π_θ(o_{i,t}|q, o_{i,<t})]_{not_updated}。 (1)

尽管有其优势，但这种组相对奖励归一化设计存在一个阻碍能力扩展的脆弱性。当问题 q 太难时（所有 G 个生成的响应都失败），奖励满足 R_i = mean({R_i}_{i=1,...,G}) 对所有 i，导致 A_i = 0 对所有 i，产生 ∇_θ J(θ; q) = 0。

HA-GRPO。 为了解决这一限制，一种自然的方法是降低问题 q 的难度，HA-GRPO方法通过在上下文中添加"提示"来实现。设 z_q 表示 q 的参考解答，ℱ 表示特定方法的提示提取机制（例如，在QUESTA中，ℱ 返回 z_q 的前50%的token）。带提示的问题 q^+ 替代 q，设计为：

q^+ = concat[q, h_q], h_q := ℱ(q, z_q)。 (2)

然而，在推理时，对于给定问题 q̄ 的参考解答 z_q̄ 自然是不可用的，因此无法提取提示 h_q̄ 并附加到 q̄ 以形成带提示的问题 q̄^+。因此，模型无法再访问提示所解锁的能力提升。

激活引导。 假设模型 π_θ 由 L 层组成，设 h_t^(l) ∈ ℝ^{d'} 表示模型在第 l ∈ {1,...,L} 层（解码器块的输出）和第 t 个token的激活。对于与选定层 l 相关联的引导向量 v ∈ ℝ^{d'}，v 被添加到该层每个token t 的模型激活中：

h̃_t^(l) = h_t^(l) + v, ∀t。 (3)

然后，被干预的 h̃_t^(l) 替代 h_t^(l) 通过剩余的层 l+1,...,L 传播。我们将带激活引导的模型表示为 π_θ^v，以区别于 π_θ。

激活引导中的一个核心问题是获得能够可靠捕获行为变化的 v。通常，v 是离线计算并保持静态的——适合目标行为随时间稳定的情况。在复杂的推理任务中，目标（提示条件下的）行为与随问题变化的参考解答纠缠在一起，并且必须随着训练的进展跟踪模型的演变。

4 用于提示的激活引导

我们提出了ASH，一种新颖的HA-GRPO方法，它将提示作为引导模型行为的观点付诸实践。设计目标是将提示的行为变化内化到一个可训练的引导向量中，该向量在推理时仍然可用。图2给出了ASH的概念性说明。

首先，与其他HA-GRPO方法一样，从原始问题 q 设计带提示的问题 q^+。在这里，我们采用QUESTA的简单机制 ℱ，它返回 z_q 的前50%的token（示例见附录A）。随后，模型同时面对带提示的问题 q^+ 和原始问题 q，并对每个版本生成 Ĝ 个响应：带提示的 {o_i^+ ∼ π_θ(·|q^+)}{i=1,...,Ĝ} 对应 q^+，原始的 {o_i ∼ π_θ(·|q)}{i=1,...,Ĝ} 对应 q。然后，我们将可训练的引导向量 v 添加到模型在选定层 l 的激活中（公式3），并对其进行优化以增加在 q 条件下带提示响应相对于原始响应的生成概率差异。借鉴我们的目标与直接偏好优化（DPO）之间的类比，我们制定了从其改编的损失：

ℒ(v; q) = -[1/Ĝ Σ_{i=1}^Ĝ log σ(β Σ_{t=1}^{|o_i^+|} log (π_θ^v(o_{i,t}^+|q, o_{i,<t}^+) / π_θ(o_{i,t}^+|q, o_{i,<t}^+)) - β Σ_{t=1}^{|o_i|} log (π_θ^v(o_{i,t}|q, o_{i,<t}) / π_θ(o_{i,t}|q, o_{i,<t})))] (4)

其中 β 是一个缩放因子，控制带激活引导的模型 π_θ^v 因偏离 π_θ 过远而受到的惩罚程度。通过最小化这个损失，v 的方向准确地与提示所诱导的行为变化中与问题无关的成分对齐。注意，在这个阶段我们不根据正确性过滤对带提示问题 q^+ 的 Ĝ 个响应和对原始问题 q 的 Ĝ 个响应，因为我们努力隔离模型中的行为变化，而不考虑最终答案是否正确。

一旦引导向量 v 训练完成，然后像其他HA-GRPO方法一样用GRPO训练模型本身，但同时在带提示的问题 q^+ 和原始问题 q 上，以及它已经生成的内容，即带提示的 {o_i^+ ∼ π_θ(·|q^+)}{i=1,...,Ĝ} 对应 q^+ 和原始的 {o_i ∼ π_θ(·|q)}{i=1,...,Ĝ} 对应 q。将它们的奖励分别表示为 {R_i^+}{i=1,...,Ĝ} 和 {R_i}{i=1,...,Ĝ}，每个 Ĝ 个响应的优势通过以下公式计算：

{A_i^+ = (R_i^+ - mean({R_i^+}{i=1,...,Ĝ})) / (std({R_i^+}{i=1,...,Ĝ}) + ε)}{i=1,...,Ĝ} 和 {A_i = (R_i - mean({R_i}{i=1,...,Ĝ})) / (std({R_i}{i=1,...,Ĝ}) + ε)}{i=1,...,Ĝ}

随后，通过最小化 J(θ; q^+) 和 J(θ; q) 之和来更新模型：

J(θ; q^+) + J(θ; q) = -[1/Ĝ Σ_{i=1}^Ĝ 1/|o_i^+| Σ_{t=1}^{|o_i^+|} (r_θ(o_{i,t}^+) A_i^+)] - [1/Ĝ Σ_{i=1}^Ĝ 1/|o_i| Σ_{t=1}^{|o_i|} (r_θ(o_{i,t}) A_i)]

其中 r_θ(o_{i,t}^+) = π_θ(o_{i,t}^+|q^+, o_{i,<t}^+) / [π_θ(o_{i,t}^+|q^+, o_{i,<t}^+)]{not_updated} 和 r_θ(o{i,t}) = π_θ(o_{i,t}|q, o_{i,<t}) / [π_θ(o_{i,t}|q, o_{i,<t})]_{not_updated}。 (5)

注意，模型是在 q^+ 和 q 上联合训练的，而不是仅在 q^+ 上。这是可能的且不会产生干扰，因为 J(θ; q^+) 和 J(θ; q) 是从独立估计的优势计算的并且简单求和，所以它们不会相互竞争。这样做更充分地利用了已经为 q^+ 和 q 生成的响应，并且额外地作为一种正则化形式，减少了模型对提示的依赖。

协同训练顺序。 这两个阶段共同形成单个训练步骤，它们的顺序至关重要。引导向量 v 必须在模型更新之前优化，因为之后优化 v 会使其拟合到一个过时的模型，与实际在公式4中生成带提示的 {o_i^+ ∼ π_θ(·|q^+)}{i=1,...,Ĝ} 和原始的 {o_i ∼ π_θ(·|q)}{i=1,...,Ĝ} 的模型不一致。这种不一致会导致 v 将模型行为引导到不再对应提示真实行为变化的方向。这种顺序不会产生干扰，因为优化 v 不会改变模型。此外，由于 v 在每个训练步骤都重新优化，它随着训练的进展跟踪模型的增长，使激活引导忠实于当前模型而非过时模型。为了在终止时保持这种对应关系，在最后一个训练步骤不更新模型。算法1描述了训练过程。经验训练动态见附录D。

5: 从 𝒟 中采样问题 q 和参考解答 z_q
6: q^+ = concat[q, h_q], h_q := ℱ(q, z_q) ▷ 公式2
7: 获得带提示的 {o_i^+ ∼ π_θ(·|q^+)}{i=1,...,Ĝ} 和原始的 {o_i ∼ π_θ(·|q)}{i=1,...,Ĝ}
8: 使用 {o_i^+}{i=1,...,Ĝ} 和 {o_i}{i=1,...,Ĝ} 计算 ℒ(v; q) ▷ 公式4
9: v ← v - η∇v ℒ(v; q)
10: if 训练步 < T then
11: 计算 {A_i^+}{i=1,...,Ĝ} 和 {A_i}_{i=1,...,Ĝ}
12: 计算 J(θ; q^+) + J(θ; q) ▷ 公式5
13: θ ← θ - η∇_θ [J(θ; q^+) + J(θ; q)]
14: end if
15: end for
16: return v^, θ^

推理

最后，给定一个问题 q̄，训练好的引导向量 v^ 直接注入到模型在同一层 l 的激活中（公式3），而不需要任何伴随的提示 h_q̄。这使带激活引导的模型 π_{θ^}^{v^*} 能够在 q̄ 上重现提示条件下的行为，从而精确满足ASH的设计目标。

5 理论分析

我们提供了理论分析，确立ASH如何界定和缩小由训练-推理上下文不匹配引起的性能差距。完整的证明推迟到附录B。

定理1（带激活引导的性能差距界限）。 给定一个训练问题 q 和从它设计的带提示的问题 q^+，以及在生成响应 o ∈ 𝒪 上的有界奖励函数 ℛ: 𝒪 → {0,1}，期望性能差距的上界为：

|𝔼_{o∼π_θ(·|q^+)}[ℛ(o)] - 𝔼_{o∼π_θ^v(·|q)}[ℛ(o)]| ≤ √(2 D_KL(π_θ(·|q^+) ∥ π_θ^v(·|q)))。 (6)

直观地说，最小化 ℒ(v; q) 增加了在 q 条件下带提示响应相对于原始响应的可能性，我们期望这将使 π_θ^v(·|q) 向 π_θ(·|q^+) 移动，从而减少右侧的散度并收紧性能差距的上界。

7 局限性

ASH的一个潜在限制是训练引导向量的计算开销。这种开销在实践中是适度的，原因有二。首先，公式4中的隐式奖励不需要额外的生成：它们是通过对已经生成的带提示和原始响应进行并行预填充来计算的。其次，我们仅在索引配对的响应上计算 ℒ(v; q) 而非所有可能的组合，这足以训练引导向量（附录D）。因此，ASH需要大约1.5倍于GRPO的训练时间，大大少于SAGE和HILL所需的2倍（附录C），同时实现了更高的有效性。

8 结论

我们介绍了ASH，一种新颖的HA-GRPO方法，通过将提示重新解读为引导模型行为的手段来缓解训练-推理上下文不匹配。在四个大语言模型上，ASH在所有六个基准上一致提升了pass@k，并建立了一个可以有效跨推理领域迁移的引导向量。此外，ASH与其他HA-GRPO方法（如SAGE和HILL）是正交的且兼容的。最后，ASH采用单一全局引导向量；通过任务或问题特定的引导向量来丰富其容量是未来工作的有前景方向。

附录B 定理1的证明

证明。 期望奖励的绝对差（期望性能差距）写为：

|𝔼_{o∼π_θ(·|q^+)}[ℛ(o)] - 𝔼_{o∼π_θ^v(·|q)}[ℛ(o)]| = |Σ_{o∈𝒪} ℛ(o)(π_θ(o|q^+) - π_θ^v(o|q))|

由于奖励函数 ℛ 有界，使得 0 ≤ ℛ(o) ≤ 1 对所有 o ∈ 𝒪：

|Σ_{o∈𝒪} ℛ(o)(π_θ(o|q^+) - π_θ^v(o|q))| ≤ Σ_{o∈𝒪} ℛ(o)|π_θ(o|q^+) - π_θ^v(o|q)| ≤ Σ_{o∈𝒪} |π_θ(o|q^+) - π_θ^v(o|q)|

根据定义，两个分布之间的总变差（TV）距离为：

D_TV(π_θ(·|q^+), π_θ^v(·|q)) = 1/2 Σ_{o∈𝒪} |π_θ(o|q^+) - π_θ^v(o|q)|

将其代入不等式得：

|𝔼_{o∼π_θ(·|q^+)}[ℛ(o)] - 𝔼_{o∼π_θ^v(·|q)}[ℛ(o)]| ≤ 2 D_TV(π_θ(·|q^+), π_θ^v(·|q))

应用Pinsker不等式，它将总变差距离与KL散度关联起来：

D_TV(π_θ(·|q^+), π_θ^v(·|q)) ≤ √(1/2 D_KL(π_θ(·|q^+) ∥ π_θ^v(·|q)))

将其代回界限得：

|𝔼_{o∼π_θ(·|q^+)}[ℛ(o)] - 𝔼_{o∼π_θ^v(·|q)}[ℛ(o)]| ≤ √(2 D_KL(π_θ(·|q^+) ∥ π_θ^v(·|q))) ∎

回顾并简化我们的DPO风格 ℒ(v; q)：

ℒ(v; q) = -[1/Ĝ Σ_{i=1}^Ĝ log σ(β log (π_θ^v(o_i^+|q) / π_θ(o_i^+|q)) - β log (π_θ^v(o_i|q) / π_θ(o_i|q)))]

将 ℒ(v; q) 与界限联系起来。 ℒ(v; q) 直接映射到DPO，通过在 q 下以参考模型 π_θ 评估，建立带提示响应 o^+ ∼ π_θ(·|q^+) 相对于原始响应 o ∼ π_θ(·|q) 的偏好。在DPO中，由带激活引导的模型 π_θ^v 相对于参考模型 π_θ 参数化的隐式奖励函数定义为：

r^v(q, o) = β log (π_θ^v(o|q) / π_θ(o|q))

重要的是，最小化 ℒ(v; q) 在Bradley-Terry偏好框架下执行此隐式奖励的最大似然估计。如Rafailov et al. (2023)所示，该估计过程将 π_θ^v(·|q) ∝ π_θ(·|q) exp(1/β r(q,·)) 与目标（最优）π(·|q) 对齐——这里定义为 π_θ(·|q^+)——即它推动 π_θ^v(·|q) 跟踪 π_θ(·|q^+)。因此，最小化 ℒ(v; q) 是最小化 D_KL(π_θ(·|q^+) ∥ π_θ^v(·|q)) 的替代。

附录E 关于pass@k指标

在这里，我们提供了论文中使用的pass@k指标的深入讨论。

定义。 pass@k测量模型对给定问题独立生成的k个响应中至少有一个成功（即产生正确的最终答案）的概率。形式上，给定问题和n个响应，其中c个成功，pass@k的无偏估计为：

pass@k = 𝔼_questions [1 - C(n-c, k) / C(n, k)]

当 k=1 时，该指标简化为温度控制生成下的平均成功率；当 k>1 时，它捕获模型在多次尝试中至少一次产生正确最终答案的能力。我们使用 n=8 计算该指标，温度为0.6，top-p为0.95，固定随机种子为0。

一个模型可能在单次尝试中无法解决一个困难的问题，但仍然具有在更多尝试中解决它的潜在能力；传统指标完全忽略了这种区别。同时，k>1的pass@k通过考虑k个生成的响应并在任何一个响应正确时将该问题计为已解决来解决这一问题，直接测试正确的推理路径是否存在于模型输出分布中的任何位置，而不仅仅是它是否是最可能的输出。

因此，我们使用pass@k来衡量模型推理能力的扩展，并且为了平衡评估覆盖范围与计算成本，我们将评估限制在k=8。

问题： N是一个整数，它在基 b 下的表示是777。求使得 N 在十进制表示中是某个整数的四次幂的最小正整数 b。正确答案：18

Qwen3-1.7B-Base的输出：
为了解决这个问题，我们需要找到最小的正整数 b，使得在基 b 下表示为 777 的数 N 是一个整数的完美幂。

步骤1：将基 b 下的 777 转换为十进制表示
N = 7b² + 7b + 7 = 7(b² + b + 1)

步骤2：将 N 设为完美幂
我们需要 N 是一个完美平方数，所以设 N = k² 对某个整数 k：
7(b² + b + 1) = k²

步骤3：被7整除
由于7是素数且 7|k²，我们有 7|k。设 k = 7m。则：
7(b² + b + 1) = 49m²
b² + b + 1 = 7m²

步骤4：测试小的 m 值
(m=1)：b² + b + 1 = 7
b² + b - 6 = 0
b = (-1 ± √(1+24))/2 = (-1 ± 5)/2
b = 2（因为 b 必须是正数）

由于 b=2 是正整数，它是最小的可能基数。

步骤5：验证解答
N = 7·2² + 7·2 + 7 = 28 + 14 + 7 = 49 = 7²

由于 49 = 7² 是完美平方数，b=2 满足条件。

最终答案： 2

为什么错误： 问题要求的是四次幂，不是平方数。基2也不能包含数字7。

Qwen3-4B-Base的输出：
为了解决这个问题，我们需要遵循以下步骤：

步骤1：将基 b 表示转换为十进制
N = 7b² + 7b + 7

步骤2：建立四次幂条件
7b² + 7b + 7 = k⁴

两边除以7：
b² + b + 1 = k⁴/7

由于 b² + b + 1 是整数，7|k⁴，所以 7|k。最小的这样的 k 是 k=7：
b² + b + 1 = 2401/7 = 343
b² + b - 342 = 0

步骤3：解二次方程
b = (-1 ± √(1+1368))/2 = (-1 ± √1369)/2 = (-1 ± 37)/2
b = 18 或 b = -19

我们舍弃负根，所以 b=18，它大于7，因此是一个有效的基数。

N = 7(18)² + 7(18) + 7 = 2268 + 126 + 7 = 2401 = 7⁴
