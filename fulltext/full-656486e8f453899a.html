中国人工智能公司 MiniMax 发布了 M3.1 Flash，这是一款全新的 AI 模型，旨在以远低于许多竞争性前沿模型的成本处理复杂的企业工作流、软件开发和计算机使用任务——其成本甚至低于广受欢迎的中国竞争对手 DeepSeek 高峰时段的价格。

MiniMax 表示，其新模型的运行速度比前代产品快近 3 倍，同时将 AI 智能体的整体使用成本降低了 70%。我们将在 10 月 28 日于旧金山举行的 VentureBeat 智能体基础设施堆栈峰会（Agentic Infrastructure Stack Summit）上深入探讨团队如何削减上下文和 token 成本。

但更有说服力的证据来自独立测试：Artificial Analysis 在其智能指数（Intelligence Index）中给 M3.1 Flash 打出了 42 分，比上一代 MiniMax M3 高出 13 分，而每项任务的评估成本不到前代产品的一半。

这使得 M3.1 Flash 与 Z.ai 的 GLM-5.3 Flash 持平，略领先于谷歌的 Gemini 3.8 Flash，并接近 DeepSeek V4.1 Flash-1017——另一款新推出的廉价中国 AI 模型——后者的得分为 45 分。

然而，该模型存在一个重要局限：Artificial Analysis 还发现，虽然 M3.1 Flash 正确回答了超过一半的事实知识问题，但它表现出极强的倾向去生成错误答案，而不是承认不确定性。

这些结果既凸显了廉价中国 AI 模型日益增强的竞争力，也凸显了企业在将其部署于需要准确性、可靠性和最少人工监督的任务时必须考虑的权衡。

独立测试显示 MiniMax 以更低成本逼近 DeepSeek

根据 Artificial Analysis 的评估，M3.1 Flash 在最大推理力度设置下取得了 42 分的智能指数得分，而其前代产品 M3 为 29 分。

这代表了实测能力的显著提升，同时将完成一项智能指数任务的平均成本从约 0.51 美元降至仅 0.22 美元——降幅接近 57%。

其最接近的竞争对手包括：GLM-5.3 Flash（得分 42，每项任务约 0.28 美元）；DeepSeek V4.1 Flash-1017（得分 45，每项任务约 0.26 美元）；以及 Gemini 3.8 Flash（得分 41，每项任务约 1.24 美元）。

虽然 M3.1 Flash 在总指数上仍落后于 Anthropic 和 OpenAI 最强大的前沿系统，但其相对较强的性能与低运营成本相结合，使其对于运行执行大量任务的 AI 系统的企业而言，成为一个颇具吸引力的选择。

Artificial Analysis 发现，该模型在复杂推理方面的改进尤为显著。M3.1 Flash 在"人类最后的考试"（Humanity's Last Exam）中得分 48%，高于 M3 的 39%，超过了得分为 40% 的 GLM-5.3 Flash 和得分为 43% 的 DeepSeek V4.1 Flash-1017，同时与 Gemini 3.8 Flash 持平。

在物理推理基准 CritPt 上，MiniMax 从仅 4% 提升至 22%，领先于 GLM-5.3 Flash 的 15% 和 Gemini 3.8 Flash 的 18%，略落后于 DeepSeek 的 24%。

根据 Artificial Analysis 的公告，新模型在智能指数评估期间使用的输出 token 也更少——约为 1.89 亿个，相比之下 GLM-5.3 Flash 约为 3.24 亿个，Gemini 3.8 Flash 约为 3.34 亿个。

这一点很重要，因为开发者需要为 AI 模型生成的 token 付费，其中包括完成困难任务所需的中间推理。一个在生成更少 token 的同时取得相当结果的模型，可以在标称 API 费率差异之外带来可观的节省。

MiniMax 瞄准企业自动化、编程和计算机使用

在其官方公告中，MiniMax 强调了该模型跨商业软件、编程环境和计算机界面执行长序列操作的能力。

该公司报告称，在 Automation-Bench v1.0.6 上得分为 62.2，该基准用于测试 AI 智能体在涉及销售、营销、运营、客户支持、财务和人力资源等应用的业务工作流中的表现。

图片来源：MiniMax

这一成绩略高于 DeepSeek V4.1 Flash-1017 的 60.5 分，并大幅超越 MiniMax 对比中 GPT-5.6 Sol 和 Claude Opus 5 的报告结果。

在 BankerToolBench（一个评估涉及文档一致性、合规性和工具使用的多步骤金融工作流的基准）上，M3.1 Flash 得分为 76.2，在该公司公布的结果中与 Claude Opus 5 持平。

其编程成绩同样具有竞争力。MiniMax 报告在 DeepSWE v1.1 上为 73.7%，相比之下 Claude Opus 5 为 74%，GPT-5.6 Sol 为 73%，DeepSeek V4.1 Flash-1017 为 77%。

在计算机使用方面，该模型在 OSWorld 2.0 上得分为 61.7，在"智能体最后的考试"（Agents' Last Exam）上得分为 29.6，这两项基准评估 AI 系统操作软件和完成复杂专业任务的能力。

尽管这些数字落后于 Anthropic 和 OpenAI 最强大的模型，但 MiniMax 随附的成本对比表明，该公司能够以大幅降低的任务成本提供它们大部分的实用能力。

该公司还报告在 CyberGym 上得分为 82.2，这是一个专注于漏洞发现和验证的网络安全基准。

这些是基准测试结果，而非有据可查的生产部署，且不同的评估设置使直接比较并不完美。尽管如此，它们表明廉价模型对于以前需要昂贵得多的替代方案的苛刻企业工作而言，正变得越来越可行。

93% 的幻觉率引发可靠性质疑

Artificial Analysis 最重要的发现之一涉及事实准确性。

在其 AA-Omniscience 基准上，M3.1 Flash 正确回答了 56% 的问题，相比之下 DeepSeek V4.1 Flash-1017 为 43%，GLM-5.3 Flash 为 28%。

然而，Artificial Analysis 发现，MiniMax 几乎尝试回答了每一个问题，按照该基准的定义，这产生了 93% 的幻觉率。

重要的是，这并不意味着其 93% 的答案都是错误的。该指标衡量的是非正确回答中完全错误（而非部分回答或拒绝回答）的比例。

换句话说，当 M3.1 Flash 未能提供正确答案时，它绝大多数情况下会选择给出一个错误答案，而不是承认自己不知道。

尽管该模型的事实记忆能力相对较强，这种行为仍导致其 AA-Omniscience 总分仅为 16 分。

对于考虑使用 AI 智能体自主更新记录、分析财务文件、调研客户或做出运营决策的企业而言，这一区别意义重大。仅凭高基准智能分数，并不能保证模型会可靠地识别自身的局限性。

因此，将 M3.1 Flash 用于知识密集型工作流的企业，可能需要额外的验证机制、检索系统、护栏或人工审查，以降低"自信但错误"的输出风险。

API 定价为每百万输入 token 0.15 美元起，开放权重将于 10 月 23 日发布

MiniMax 通过其第一方 API、M Plan 订阅服务以及 MiniMax Code 桌面应用程序提供 M3.1 Flash。

该模型的定价为每百万输入 token 0.15 美元、每百万输出 token 0.60 美元，缓存输入折扣至每百万 token 仅 0.015 美元。

按此费率，消耗 100 万个未缓存输入 token 并生成 100 万个输出 token 的工作负载，模型使用费为 0.75 美元，不包括其他基础设施或应用程序费用。

这使 M3.1 Flash 成为目前全球可用的最廉价前沿 AI 模型之一。

据 Artificial Analysis 称，该模型支持文本和图像输入、文本输出，并拥有 100 万 token 的上下文窗口。

MiniMax 还声称，该模型每秒可生成超过 200 个 token，中位输出速度持续超过每秒 170 个 token。

该公司将性能提升部分归因于稀疏度的提高——这是一种旨在减少生成响应所需计算量的架构方法。

该模型的权重在发布时仍为专有，但 MiniMax 表示计划于 10 月 23 日开放发布。该公司尚未提供此次发布的许可条款，因此现在判断企业能够在多大程度上修改或自托管该模型还为时过早。

在另一项值得关注的披露中，MiniMax 透露，M3.1 Flash 的早期版本此前曾以"Space Bunny"的名义匿名运行，在其身份被公开披露之前已处理超过 200 万亿个 token。该公司尚未提供这一使用情况的详细明细。

MiniMax 表示还计划推出一款能力更强的 Pro 模型，但尚未公布发布日期。

对于企业 AI 团队而言，M3.1 Flash 再次表明，编程和自动化任务上的强大性能正以越来越低的价格变得可用。其第三方基准测试结果强化了这一主张，而幻觉方面的发现则突显了：在决定哪些 AI 模型可以被信任用于实际业务运营时，定价和智能分数只是考量因素的一部分。
