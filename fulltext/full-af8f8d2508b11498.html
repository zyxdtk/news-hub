Abstract
LLM-based agents increasingly operate in persistent environments where they must store, update, and reason over information across many sessions. While prior benchmarks evaluate only single-entity updates, MEME defines six tasks spanning the full space defined by the multi-entity and evolving axes, including three not scored by prior work: Cascade and Absence (dependency reasoning) and Deletion (post-removal state). Evaluating six memory systems spanning three memory paradigms on 100 controlled episodes, we find that all systems collapse on dependency reasoning under the default configuration (Cascade: 3%, Absence: 1% in average accuracy) despite adequate static retrieval performance. Prompt optimization, deeper retrieval, reduced filler noise, and most stronger LLMs fail to close this gap. Only a file-based agent paired with Claude Opus 4.7 as its internal LLM partially closes the gap, but at

Task Definitions
Within each quadrant of the entity scope
×

Exact Recall (ER)
targets a single static entity and demands character-level verbatim reproduction, testing encoding fidelity.
Aggregation (Agg)
combines multiple static entities scattered across separate sessions into a single answer, testing retrieval coverage when no explicit link connects them.
Tracking (Tr)
reconstructs the full revision history of a single evolving entity in chronological order, testing whether past values are retained rather than overwritten.
Deletion (Del)
tests whether the system stops reporting a fact after the user explicitly removes it, rather than continuing to surface the old value.
Cascade (Cas)
infers that a dependent entity’s value has changed based on a stated dependency rule and an upstream update, testing propagation through dependency chains.
Absence (Abs)
recognizes that a dependent entity is uncertain after an upstream change with no replacement rule, where the correct answer is uncertainty rather than a new value.

Conclusion
Long-running agentic systems demand more from memory than retrieval over a fact store. As user-stated context evolves, an agent’s memory must propagate updates through related facts and signal uncertainty when no resolution rule is available. MEME tests this through Cascade and Absence, two dependency-reasoning task types that no prior benchmark covers.
Among the practical-cost systems we evaluated, none solves dependency reasoning. Across all six systems the dependency rule and the change event are written and retained, but at retrieval the change event is either out-ranked by the pre-change value (vector retrievers) or never surfaced at all (tool-use, graph, sparse retrievers), so the answering LLM ends up reporting the pre-change value. Closure does emerge, but only with a frontier LLM (Opus 4.7) on a file-based substrate, where the internal LLM writes the propagated value into the store at ingest so the retriever can surface it directly; this configuration costs
∼
70
×
{\sim}70\times
the baseline and is not deployable today.
Our per-stage diagnosis suggests two deployment patterns. For retrieval-heavy or static workloads, existing

systems (BM25, Mem0, MD-flat) suffice. For dependency-heavy workloads, no practical-cost option exists today; careful upstream design (writing dependency rules into the conversation log, surfacing change events through pre-defined templates) is the near-term workaround. Looking further out, the path forward is memory architectures that natively propagate updates through dependent facts at maintenance, rather than relying on a costly internal LLM to do so. We leave the architecture open; MEME provides the diagnostic for tracking progress.
6
Limitations
Several limitations bound our findings. The dataset uses two hand-crafted knowledge graphs (Personal Life, Software Project) authored by us; broader domains and crowd-sourced graphs would test generalization further. Dialogues are LLM-generated rather than collected from real users, which constrains realism. We evaluate on 100 episodes with
∼
\sim
35K-token contexts; longer contexts and larger sample sizes may surface different patterns. Most ablation studies (prompt optimization, top-
k
k
sweep, noise ablation, internal-LLM swap) run on 10–40 episode subsets and cover only a subset of the six memory systems due to compute cost; only the main results and answering-LLM swap cover all 100 episodes across all six systems. Verbalization uses explicit conditional phrasing for dependency rules as a best-case framing for memory systems; we have not ablated implicit-conditional or no-conditional variants. All data is English.
