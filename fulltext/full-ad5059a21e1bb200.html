币安推出AI代理交易，风控责任主要在用户

📅 2026-08-20 📄 TechCrunch AI 🔗 原文链接

原标题：Binance now lets AI agents trade, but keeping them in check is largely up to users

中文摘要： 全球最大加密货币交易所币安推出了Agent OS平台，允许AI代理代表用户分析市场并执行交易。该平台整合了币安API、MCP等工具，支持ChatGPT、Claude等应用。为控制风险，币安通过“子账户”机制限制代理权限，默认禁用提款，由用户决定代理的交易自主权和资金限额。然而，由于AI推理过程在币安系统外进行，币安对决策是否受操纵的可见性有限。Kraken、Coinbase等竞争对手也在推进类似AI代理交易功能。

拥有超过3亿注册用户的全球最大加密货币交易所币安于周四推出了一个新平台，允许AI代理分析市场并代表用户执行交易，将自主AI直接引入真实资金管理业务中。

该平台名为 Agent OS，允许开发者将AI应用程序和代理连接到币安的金融基础设施。它整合了交易所现有的工具和服务，如币安API、币安钱包代理中心、币安x402交易验证和支付促成API以及币安技能中心，并引入了对模型上下文协议（MCP）的支持。该平台还支持与OpenAI的ChatGPT和Codex、Anthropic的Claude Code以及Cursor等工具配合使用，允许用户授权代理访问市场数据、查看账户信息并执行交易。

币安的 Agent OS 允许代理代表用户进行交易。
图片来源：币安

然而，随着AI竞赛从回答问题的聊天机器人转向能够采取行动的代理，币安将大部分约束代理的责任交给了用户。用户最终必须决定代理可以访问和交易的内容，并限制它们的行为。

币安产品副总裁Jeff Li在接受采访时表示：“我们并没有给予完全的自由，而是将权力交到用户手中，让他们能够对代理的操作进行细粒度的访问控制。我们将控制权放在账户级别，以保护用户的资金。”

Li告诉TechCrunch，币安主要通过专用的“子账户”来实现这一点，用户可以将子账户分配给代理，并针对特定活动（如现货或期货交易）进行配置。默认情况下，这些子账户的提款功能被禁用，从而在代理的活动周围创建了一个沙盒。

币安代表表示，用户还可以选择AI代理是否必须为每个订单寻求批准，或者在配置权限后是否可以自主执行交易。币安没有对AI代理可以交易或亏损的金额施加单独的上限，因此用户转入子账户的金额实际上就是限额。

币安的子账户可以具有特定的交易限额和权限。
图片来源：币安

当被问及币安是否能看到代理进行特定交易的原因时，Li表示，推理过程发生在其系统之外，要么在用户的计算机上，要么在他们选择的AI应用程序中。“我们确实无法看到用户操作的推理过程，”他说。

这意味着币安可以监控代理最终的交易活动，但对于决策是否受到错误信息或操纵的影响，其可见性有限。

当被问及如果代理通过提示注入攻击被操纵或以其他方式被入侵会发生什么时，Li再次指出子账户是主要防线。币安还表示，其针对子账户API的现有安全、风险控制和反洗钱政策在 Agent OS 推出时同样适用。

交易是币安瞄准的首批用例之一。尽管如此，Li表示，代理可以监控市场、进行研究和风险分析、对信号做出反应，并自主下单或执行套利等策略。

Agent OS 还旨在将代理连接到支付和链上活动。通过币安的x402集成，代理可以发送和结算支付，而其代理钱包允许它们与代币和去中心化金融协议进行交互。

与交易所交易（币安不对代理在其子账户内可以交易或亏损的金额施加单独上限）不同，代理钱包交易带有币安设定的每日限额。据该公司称，常规兑换每天上限为50,000美元，DeFi交易的默认每日限额为100,000美元，而x402支付每天限制为20美元。

Li表示，Agent OS 是币安向开发者提供一个平台以构建能够跨越加密货币和传统市场运作的AI驱动应用程序的“第一步”。

币安并不是唯一一家向AI代理开放基础设施的机构。竞争对手加密货币交易所也一直在朝着同一个方向努力，使用MCP和其他开发者工具让AI应用程序直接访问市场数据和交易系统。

今年3月，Kraken 推出了 一款开源命令行工具，内置MCP服务器，允许AI代理执行操作，包括现货和期货交易。Coinbase在6月紧随其后推出了 Coinbase for Agents，将AI代理直接连接到用户账户，并允许它们在用户设定的限制内进行交易、支付和执行其他金融工作流程。同样，OKX在今年早些时候通过引入开源MCP工具包，在其平台上 启用了代理交易。
