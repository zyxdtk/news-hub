摘要

反事实解释方法已被引入单模态场景，针对表格、时间序列、文本和图像数据设有专门框架，但尚未有为从多模态输入学习的分类器设计的后验方法。现有多模态分类器的可解释性方法对每个输入独立应用特定模态的归因，这既无法产生连贯的解释，也无法迁移到任意预训练的多模态架构。为解决这些不足，我们提出 CRANE（通过不可知最近邻解释的反事实检索，Counterfactual Retrieval via Agnostic Nearest-neighbour Explanations），这是首个面向最近邻多模态反事实生成的后验、模型不可知框架，它从目标类别中检索真实训练样本作为候选解释，通过构造确保合理性。在四个异构数据集和三种融合策略上，我们表明多模态共识检索（MC-R）——通过交叉各模态邻居集以识别在每个模态中都与查询联合接近的实例——成为最强的多模态策略，在四个数据集中的三个上取得最佳或并列最佳结果，同时将每个解释立足于联合训练分布。当单一模态主导决策边界时，单模态策略仍具竞争力。

I 引言

数据科学管道越来越多地处理异构输入，在单个预测模型中组合结构化记录、自由文本、时间序列和图像。临床决策支持系统将生命体征与结构化患者人口统计数据融合以预测结局，如脓毒症死亡率 [1] 和癌症转移 [2,3,4]；内容审核系统将图像与其说明文字配对以检测仇恨表情包 [5]；欺诈检测器将自由文本职位发布与结构化发布元数据结合以标记欺骗性招聘信息 [6]。

随着这些多模态架构成为标准实践，解释其预测的需求日益增长。这一需求推动了可解释人工智能（XAI）方面的大量研究工作 [7,8]。

反事实解释是最自然、最可操作的后验论证形式之一：反事实 x′ 对样本 x 进行重新配置，以翻转其预测，同时保持接近 x 并与数据流形一致。作为基于实例的 XAI 方法之一，它们回答了直观且通常可直接付诸行动的问题："x 中需要改变什么，模型才会做出不同的决定？"

针对单个模态已存在性能良好的反事实生成器：表格 [9,10]、时间序列 [11,12]、文本 [13] 和图像 [14]。然而，这些生成器假设单一、同质的输入空间。

当分类器同时消费多种模态时，对每个模态独立应用这些生成器无法产生连贯的解释，如图 1 所示。对于一个基于静态人口统计特征和实验室时间序列的多模态死亡率分类器，表格反事实生成器可能返回同龄的女性幸存者，而时间序列生成器可能返回反映 N 末端 B 型利钠肽原（NT-proBNP，一种心脏应激标志物）下降的信号，但可能不会改变前列腺特异性抗原（PSA）的上升趋势，而这是临床上的不可能情形，因为生物学女性不产生 PSA。这一过程将产生一个嵌合式反事实：它在每个模态内部局部合理，但作为整体来看全局上不连贯且在临床上无意义。

图 1： 独立生成的各模态反事实可能产生静态特征与时间序列轨迹不连贯的嵌合式解释。箭头表示上升（↑）或下降（↓）的生物标志物。

基于检索的方法从构造上避免了这一问题：它们不合成新样本，而是返回目标类别中的真实训练样本。最近异类邻居（NUN）文献在单模态场景中利用了这一思路 [15,12,11]，但尚未扩展到多模态情形。

此外，在使用基于检索的方法时，关于搜索空间本身的不同选择也值得考虑。可以在单一模态的特征空间中搜索，可以将所有模态嵌入拼接后联合搜索，也可以在多模态模型的潜在表示中搜索。每种选择都编码了不同的相似性概念，而它们在标准反事实质量目标（预测翻转率、接近度、稀疏性和合理性）[16] 以及生成集合多样性 [10] 方面的相对优劣仍有待探索。

我们通过 CRANE（通过不可知最近邻解释的反事实检索）来解决这些开放问题，这是一个面向多模态分类器的最近邻反事实生成的后验、模型不可知框架。

CRANE¹ 支持表格、时间序列、文本和图像模态的任意组合，检索策略涵盖从单模态搜索到多模态融合，并将标准反事实质量目标（即结果、接近度、稀疏性和合理性）扩展到异构输入空间。在各种策略中，多模态共识检索（MC-R）——检索在每个模态中都与查询联合接近的训练实例——在涵盖社交媒体、招聘、内容审核和临床预测的四个数据集中成为最强的多模态策略，而当单一模态主导决策边界时，单模态检索仍具竞争力。

¹ 代码可在 GitHub 上获取；该库可通过 pip install crane-cf 安装。

II 相关工作

机器学习（ML）的可解释性方法涵盖广泛的领域，从特征归因方法 [17,18]，到显著性图 [19]、基于注意力的解释 [20]，以及基于实例的方法（如反事实），但绝大多数假设单一、同质的输入空间。这一局限性对反事实方法最为尖锐，因为解释必须同时指定在所有输入空间中会发生什么变化，而不仅仅是在某一个空间中。

反事实解释由 Wachter 等人 [9] 在机器学习背景下形式化，此后发展成为一个丰富的研究领域。例如，DiCE [10] 通过在目标函数中添加行列式点过程项来生成多样化的反事实集合，使不同的解释建议不同的可操作路径；而 Dandl 等人 [21] 提出了多目标公式，同时优化接近度、稀疏性、合理性和可操作性，而不将它们合并为单一加权和。

反事实文献中的一个独特分支完全避免优化，将解释构建为检索问题，其中目标类别的真实训练样本（即 NUN）直接用作解释或作为进一步细化的种子。Brughmans 和 Martens [15] 在 NICE 中形式化了这一方法，利用 NUN 构建保证存在于观测数据分布中的表格反事实。

检索策略带有重要的结构性保证：由于返回的样本是在训练数据中观测到的，它在构造上就是合理的，无需在目标函数中加入任何显式的合理性惩罚。

然而，上述方法均专为扁平表格或嵌入空间输入而设计；如何为同时融合多种模态的分类器生成反事实，这一问题受到的关注要少得多，正如以下对特定模态方法的回顾所清楚表明的那样。

III 通过不可知最近邻解释的反事实检索

III-A 问题形式化

我们引入一个独立于任何特定数据类型、分类器架构或应用领域的多模态反事实生成的一般性形式化。

多模态实例空间。 设 M≥1 为数据集 S 中存在的模态数量。对于每个模态 m∈{1,…,M}，设 X^m 为相应的模态空间，编码该模态的表示格式和领域约束。多模态输入空间为：

X := X¹ × ⋯ × X^M. (1)

多模态实例是元组 x=(x¹,…,x^M)∈X，其中 x^m∈X^m 是 x 在模态 m 中的分量。

原则上，X^m 可以表示任何能够定义合适距离函数 d_m 和合理性估计器 p_m 的数据类型。不失一般性，本工作探索异构数据管道中常见的四种模态类型：静态特征向量（表格）、多变量时间序列、标记序列（文本）和二维像素阵列（图像）。添加额外模态只需为每种模态指定适当的 d_m 和 p_m 函数。

多模态分类器。 设 Y 为有限标签集。多模态分类器是函数 f: X→[0,1]^|Y|，其中 f_y(x) 是分类器为实例 x 的标签 y∈Y 分配的分数。预测标签为 ŷ := argmax_{y∈Y} f_y(x)。CRANE 将 f 视为黑盒：只需要预测函数，不假设可以访问模型内部结构、梯度或训练过程。

多模态反事实生成。 给定预测标签为 ŷ=f(x) 的事实实例 x∈X、带标签训练集 D={(x_i,y_i)}_{i=1}^n 以及目标标签 y≠ŷ，目标是找到反事实实例 x′∈X，使得 f(x′)=y，且 x′ 在第 III-A1 节所定义的标准反事实目标的多模态等价形式下具有高质量。

III-A1 目标

为评估生成的反事实，我们使用反事实解释文献中常用的四个指标：结果、接近度、稀疏性和合理性。每个候选反事实 ẋ 与事实实例 x=(x¹,…,x^M) 进行比较。后三个分数按模态计算，并使用非负权重 w_m≥0（∑_m w_m=1）进行聚合。

每个检索策略返回此类候选的有序列表；在聚合目标下得分最高的候选被保留为反事实实例 x′，如第 III-A 节所述。

所有目标均为最小化；值为零表示完美候选。

为确保来自不同原生尺度的模态分数具有可比性，每个按模态计算的函数在聚合前都被映射到 [0,1]，因此无论存在多少或何种类型的模态，多模态聚合值都保证位于 [0,1] 中。

在本文报告的所有实验中，我们使用均匀权重 w_m=1/M；当具备关于模态相对重要性的先验知识时，可替换为数据集特定的权重。四个指标定义如下：

结果

第一个目标衡量候选是否以及以多大决定性达到目标标签 y*，使用有效性这一二元指标：

Validity(ẋ) = 𝟙[argmax_{y∈Y} f_y(ẋ) = y*], (2)

记录预测是否已被翻转，以及

Φ_out(ẋ) = 1 − f_{y*}(ẋ), (3)

这是分类器分配给目标类别的分数与它分配给该类别明确成员的分数之间的连续偏差。Φ_out 位于 [0,1] 区间，当分类器对 y* 具有完全置信时最小化为 0。

接近度

接近度衡量候选与事实实例的偏离程度：

Φ_prox(x,ẋ) = ∑_{m=1}^{M} w_m · d̃_m(x^m, ẋ^m), (4)

其中 d̃_m∈[0,1] 是特定模态的归一化距离。

对于表格和时间序列模态，原始距离是 x^m 与 ẋ^m 之间的平均绝对误差；通过将其转换为相对于由所有跨类别训练对计算的成对距离参考分布的百分位排名进行归一化，因此分数为 0 表示反事实比所有参考对都更接近，分数为 1 表示它更远。

对于文本和图像模态，d̃_m 是归一化余弦距离，即：

d̃_m(x^m, ẋ^m) = (1 − cos(φ_m(x^m), φ_m(ẋ^m))) / 2, (5)

其中 φ_m 是特定模态的编码器。注意 d̃_m(·)∈[0,1]，确保与表格和时间序列模态所用的百分位归一化距离具有可比性。

稀疏性

稀疏性衡量事实实例的多少分量必须被改变才能得到反事实：

Φ_spar(x,ẋ) = ∑_{m=1}^{M} w_m · s_m(x^m, ẋ^m), (6)

其中 s_m∈[0,1] 是特定模态的归一化变化计数。

对于表格模态，s_m 是 ℓ₀ 范数除以总特征数 D：s_m = ‖ẋ^m − x^m‖₀ / D，因此值为 1 表示每个特征都发生了变化。

对于具有 C 个通道的时间序列模态，s_m 按通道计算为绝对差超过阈值 τ_c≥0 的时间步比例（默认 τ_c=0，因此任何非零变化都会被计入）；这些按通道的比例在所有 C 个通道上取平均，得到 s_m∈[0,1]。

对于文本模态，s_m 是 x^m 与 ẋ^m 之间的标记级 Levenshtein 距离，除以 max(1,|x^m|)，其中 |x^m| 是事实实例中的标记数，并封顶为 1.0。

对于图像模态，s_m 是像素元素（跨所有通道，在将整数图像归一化到 [0,1] 之后）绝对差超过阈值（默认为 0）的比例。

合理性

合理性衡量候选反事实相对于目标类别训练分布的典型程度：

Φ_plaus(ẋ) = ∑_{m=1}^{M} w_m · p_m(ẋ^m), (7)

其中 p_m∈[0,1] 是模态 m 的归一化异常值分数。对于每个模态，在训练集的目标类别部分上以新颖性检测模式拟合一个具有 k=20 个邻居的局部异常因子（LOF）模型；时间序列在拟合前被展平为长度 T×C 的向量。候选 ẋ^m 的原始异常度为 −score_samples(ẋ^m)，因此值越高表示偏离训练分布越大。

然后通过该原始分数相对于所有目标类别训练点原始分数的百分位排名，将其映射到 [0,1]：

p_m(ẋ^m) = (1/n) ∑_{i=1}^{n} 𝟙[raw(x_i^m) ≤ raw(ẋ^m)], (8)

其中求和遍历 n 个目标类别训练实例。分数为 0 表示候选至少与每个目标类别训练点一样像内点；分数为 1 表示它是比每个目标类别训练点都更强的异常值。

关于检索式反事实的合理性。 基于检索的方法的一个关键特性是：当 k=1 时，返回的反事实是来自目标类别的真实训练实例，因此在构造上是合理的：它位于经验数据流形上，其所有模态都在单个真实世界实例中被共同观测到，从而保持了跨模态一致性。当 k>1 时，CRANE 始终返回单个最近邻作为第一个候选；第 j 个后续候选（j=2,…,k）是 j 个最近邻上的分量中位数，产生一系列逐渐平滑的原型。一般而言，这些中位数候选均不对应任何观测到的训练实例。公式 (7) 中的合理性目标对所有候选统一量化合理性。

III-B CRANE 检索策略

CRANE 通过在训练集 D 中搜索标记为 y 的实例中最接近 x 的 k 个实例，并从这些邻居组装候选来构建反事实候选。关键设计选择在于在哪个空间中执行最近邻搜索。CRANE 提供一族检索策略，涵盖从单模态搜索到多模态融合。所有策略共享一个通用接口：它们以 (x, y, k) 为输入并返回候选反事实的有序列表。所有策略都将分类器 f 视为黑盒。不同策略描述如下：

III-B1 单模态检索

CRANE 提供四种单模态检索策略——TabularNN、TimeSeriesNN、TextNN 和 ImageNN——每种策略通过在单一模态的特征或嵌入空间中的距离对目标类别训练实例进行排序。设 D_{y}={x_i | y_i=y} 表示目标类别训练实例。给定特定模态的距离 d_m，k 个最近邻为：

N_m^(k)(x) = kNN_{y*}(x^m; d_m), (9)

即 D_{y*} 中 d_m(x^m, x_i^m) 最小的 k 个元素。

对于文本和图像模态，d_m 在编码器嵌入空间中操作：d_m(a,b) = 1 − cos(φ_m(a), φ_m(b))，其中 φ_m 是可配置的预训练编码器，被视为距离函数的超参数。在本文报告的实验中，我们评估了文本的 BERT 系列模型（多语言 E5、MiniLM）、TF-IDF 和 Word2Vec；图像的 ResNet-50、EfficientNet-B0、ViT-B/16 和 CLIP ViT-B/32。四种策略共享相同的检索接口，但从排序后的邻居构建第 j 个候选（j=1,…,k）的规则取决于模态是结构化还是非结构化的，这一选择对质量指标随 k 增大时的行为有直接影响。

结构化模态（表格、时间序列）。 特征值定义在共同的连续尺度上，因此 j 个邻居上的分量中位数是有意义的摘要。第 j 个候选原型是 j 个最近邻上的渐进中位数：

π_m^(j)(x) = median_{x_i ∈ N_m^(j)(x)} x_i^m. (10)

当 j=1 时返回真实训练实例。当 j>1 时，原型是可能不对应任何观测行的平滑聚合，但仍接近局部目标类别邻域的中心。因此，随着 j 增大，接近度和合理性趋于适度改善，因为渐进中位数平均掉了异常特征值。

TabularNN 使用欧几里得或曼哈顿距离；TimeSeriesNN 使用欧几里得、DTW 或 LCSS。

非结构化模态（文本、图像）。 原始表示空间中不存在有意义的中位数：标记序列或像素阵列的分量中位数不是连贯的文本或图像。因此 CRANE 使用排序匹配选择：第 j 个候选直接取嵌入空间中第 j 个最近邻的字面文本或图像：

π_m^(j)(x) = x_(j)^m, (11)

其中 x_(j) 表示 d_m 下的第 j 个最近邻。因此，在任何 j 下每个候选都是真实观测的训练实例，但随着 j 增大，所选实例来自嵌入空间中逐渐更远的区域。文本和图像的接近度和稀疏性目标在嵌入空间中测量，因为一般而言无法从编码器表示恢复出明确的标记序列或像素阵列。

III-B2 早期融合最近邻（EF-NN）

早期融合检索通过将所有模态的嵌入拼接成单个向量来形成联合表示：

x̃ = concat(φ₁(x¹), …, φ_M(x^M)), (12)

并使用定义在拼接向量上的距离 ρ（如余弦或欧几里得距离）在此联合空间中检索 k 个最近邻。

原型使用第 III-B 节中定义的模态类型物化规则（公式 10–11）从联合排序的邻居组装。与单模态策略的唯一区别在于排序步骤：邻居按拼接空间 x̃ 中的距离排序，而非在任何单一模态的空间中排序。

III-B3 中间融合最近邻（IF-NN）

中间融合检索在分类器学习到的潜在表示中执行邻居搜索。设 λ: X→ℝ^d 表示多模态分类器 f 的倒数第二层激活。距离计算为：

d_int(x, x_i) = ‖λ(x) − λ(x_i)‖₂, (13)

第 j 个候选从此表示中的 j 个最近邻组装。由于无论原始模态类型如何，λ(x) 都是单个连续向量，候选物化始终遵循结构化规则：第 j 个候选是潜在空间排序邻居上的分量中位数，通过检索相应的完整训练实例并按模态应用公式 10–11 映射回输入空间。

通过在模型自身的嵌入空间中操作，IF-NN 检索分类器自己认为与 x 相似的实例。然而，与所有其他仅通过预测函数操作且完全模型不可知的 CRANE 策略不同，该策略要求被解释的模型是具有可访问中间激活的深度神经网络；它不适用于不可微模型。

III-B4 多模态共识检索（MC-R）

MC-R 通过交叉各模态邻居集来检索在所有模态中同时接近 x 的实例。对于每个模态 m，独立检索前 k 个最近的目标类别邻居：

N_m^(k)(x) = kNN_{y*}(x^m; d_m). (14)

共识集是这些集合的交集：

S(x) = ⋂_{m=1}^{M} N_m^(k)(x). (15)

选择足够大的 k 以确保 S(x)≠∅。然后使用相同的物化规则（公式 10–11），从 S(x) 中按各模态距离之和排序的 j 个最近实例组装第 j 个候选。MC-R 是最保守的多模态策略：候选来自各模态邻域的交集，因此在每个模态中同时与 x 联合接近。第一个候选（当 |S(x)|≥1 时）始终是真实训练实例。

III-B5 逐模态原型合成（MPS）

MPS 通过组合独立的各模态原型来合成候选。对于每个模态 m，在该模态自身的特征或嵌入空间中检索 k 个最近邻，如公式 (9) 所示。第 j 个候选的各模态原型 π_m^(j)(x) 按照公式 10–11 中的模态类型规则计算。第 j 个合成反事实通过拼接各模态原型组装而成：

ẋ_MPS = (π₁^(j)(x), …, π_M^(j)(x)). (16)

与 MC-R 不同，MPS 不要求任何训练实例在所有模态中同时排名靠前，因此即使没有单个实例在所有模态中与 x 联合接近，它也能产生多模态候选。然而，由于每个模态来自不同的最近邻，MPS 候选是合成复合体，一般不对应任何观测到的训练实例，即使在 j=1 时也是如此。因此，MPS 不具备对 MC-R 和单模态检索器成立的结构性合理性保证。

IV 实验

IV-A 数据集

我们在四个公开可用的数据集上评估 CRANE，涵盖不同的应用领域、模态组合和类别结构。摘要见表 I。

脓毒症（院内死亡率）。 脓毒症数据集从 MIMIC-III [22] 中提取，遵循 [1] 中描述的流程，识别有确诊脓毒症的 ICU 入院记录。每次入院表示为 100 个特征上的 24 个每小时时间步，划分为由 53 个时变临床变量（生命体征和实验室值）组成的时间序列模态，以及由 47 个静态特征（从第一个时间步提取的人口统计和入院数据）组成的表格模态。分类任务是二元院内死亡率预测。该数据集严重不平衡，死亡率约为 7.4%。评估遵循 5 折分层交叉验证；结果跨折合并，以 F1 分数作为主要指标报告，同时报告 AUC。

Long COVID 推文（情绪分类）。 该数据集² 由讨论长期新冠的意大利语推文组成，标注有来自 FEEL-IT 分类法 [23] 的四个情绪标签：恐惧、愤怒、悲伤和喜悦。每个实例包含原始推文文本字段和一个编码互动元数据（点赞、转发、回复、引用数）及结构化推文特征（话题标签和 URL 计数）的表格模态。类别分布不平衡，恐惧（41.6%）和愤怒（32.9%）占主导，喜悦（8.8%）为少数类。

² https://huggingface.co/datasets/Santarabantoosoo/italian_long_covid_tweets

仇恨表情包（仇恨言论检测）。 仇恨表情包数据集 [24] 是用于检测互联网表情包中仇恨言论的二元分类基准。每个实例由文本说明和 224×224 的 RGB 图像组成。类别分布中度不平衡，63.7% 为非仇恨实例，36.3% 为仇恨实例。

真实或虚假招聘（欺诈检测）。 该数据集 [25] 包含标记为真实或欺诈的职位发布。每个实例结合表格模态（薪资范围、就业类型和所需经验等结构化字段）与三个独立的文本字段：职位描述、公司简介和任职要求。该任务严重不平衡，欺诈性发布仅占数据的 4.8%。

IV-B 实验设置

IV-B1 分类器家族与融合策略

对于每个数据集，我们在三种融合策略下训练分类器：早期融合、中间融合和晚期融合，如第 III-B 节所定义。对于每种融合策略，我们比较两个分类器家族：基于多层感知机（MLP）与任务训练分支的深度家族，以及使用基于树的集成（随机森林和梯度提升）或对于时间序列分支使用 ROCKET 变换加逻辑回归 [26] 的非深度家族。这一设计产生了一系列分类器类型，对 CRANE 的模型不可知声明进行了压力测试：IF-NN 检索策略需要具有可访问倒数第二层激活的深度神经分类器，因此仅在深度模型上评估，而所有其他 CRANE 策略在两个家族上统一评估。

文本使用预训练变换器模型编码：Long COVID 推文使用 XLM-RoBERTa，真实或虚假招聘使用 DistilBERT，仇恨表情包使用 BERT 或 MiniLM。仇恨表情包中的图像使用 ResNet-50、EfficientNet-B0 或 ViT-B/16 编码。对于早期融合分类器，所有编码器均被冻结（不做微调）；对于中间融合分类器，变换器骨干网络进行端到端微调。所有分类器通过逆频率加权处理类别不平衡。训练时我们使用 15% 的保留验证集用于早停和超参数调优。

IV-B2 CRANE 配置

每个 CRANE 检索策略配置为 k=20，每个查询返回 20 个候选。对于 MC-R，交集之前每个模态的搜索池设置为 k_search=200 个邻居，确保我们数据集中所有查询的共识集非空。对于每个数据集，我们对每种模态的编码器和距离度量的所有有效组合（如第 III-B 节所定义）进行系统性消融，分别为脓毒症、Long COVID 推文、真实或虚假招聘和仇恨表情包产生 6、22、16 和 84 个组合。结果报告为所有消融组合的平均值。

IV-B3 各数据集的 CRANE 策略

并非所有检索策略都适用于每个数据集和分类器组合。如第 IV-B 节所述，IF-NN 仅在深度分类器上评估；对于缺失某模态的数据集（如脓毒症、推文或招聘中没有图像模态），相应的单模态策略不予评估。

IV-C 评估协议

我们使用第 III-A1 节引入的四个质量目标评估每个检索策略。所有指标以越低越好为尺度报告，其中 0.0 表示该目标的完美分数。

所有四个指标使用合并的测试查询在五个交叉验证折上取平均。对于每个数据集和策略，我们报告所有消融组合的均值和标准差，以衡量对编码器和距离度量选择的敏感性。

反事实生成在被解释分类器预测为非期望类别的所有测试实例上进行；不进行子采样。对于二元数据集，目标标签 y* 是唯一的相反类别。对于存在四个情绪类别的 Long COVID 推文，我们关注悲伤→喜悦方向，因为这两个类别代表该数据集中语义上最对立的两极；其余类别对（恐惧和愤怒）没有明确定义的对立面，因此被排除在反事实评估之外。

VI 讨论

单模态检索。 单模态生成器取得很强的接近度和合理性，因为它们检索的是完整、连贯的训练实例：跨模态一致性通过构造得以保持。在脓毒症上，TimeSeriesNN 取得接近完美的结果（0.021），因为时间性临床轨迹主导了分类器的决策边界，这与该数据集上的先前发现 [1] 一致；检索实例的静态特征共同强化了预测翻转。在不平衡数据集（脓毒症、招聘）上，性能部分得益于较大的多数类检索池；当目标类别为少数类时，从业者应预期性能下降。

相反，在仇恨表情包上，TextNN（0.070）大幅优于 ImageNN（0.182），表明文本模态主导了表情包分类器的决策边界，这与该基准上的先前发现 [24] 一致。

潜在空间检索。 IF-NN 在所有数据集和融合策略上均持续未能产生有效反事实，即使在 k=50 时也是如此。深度分类器的倒数第二层是针对判别性分离而非类内聚类而优化的，因此该空间中的邻居并不可靠地来自目标类别。这一局限性特定于当前的训练目标；显式优化聚类潜在表示的架构可能会克服它。

分类器质量。 反事实质量部分是分类器质量的函数：分离良好的分类器会为不同类别分配截然不同的预测，因此检索到的目标类别实例更有可能翻转预测。这与结果一致：在招聘数据集上，所有分类器的 F1 均高于 0.88，除 IF-NN 外的每个生成器都达到接近零的结果；而在仇恨表情包上（该基准中分类器最弱，F1 为 0.669–0.713），所有生成器的结果都显著更高。

MC-R 作为推荐的多模态策略。 MC-R 是整体上最强的多模态生成器，在四个数据集中的三个上取得最佳或并列最佳结果，并在真实或虚假招聘上取得完美结果（0.000）。在招聘数据集上，MC-R 还取得整个基准中最低的稀疏性（0.137），表明交集机制识别出与查询仅在极少数特征上不同的目标类别实例，这是欺诈检测中可操作解释的理想特性。其交集机制识别在所有模态中与查询联合接近的实例，以 MPS（独立合成各模态原型）无法保证的方式将反事实立足于联合训练分布。其结果在 k=5 时即达到饱和，使其在实践中十分高效。k 的选择还支配着一致性与多样性之间的权衡 [10]：当 k=1 时，提议的候选是真实、连贯的训练实例；增大 k 会产生更大且更多样化的候选集合，而第一个候选始终保持完全的跨模态一致性。

VII 结论

我们提出了 CRANE，一个面向多模态分类器的最近邻反事实生成的后验、模型不可知框架，支持任意模态组合。其对新模态的可扩展性使其自然适用于临床决策支持等领域，在这些领域中，规范性框架要求机器学习工具具备可解释性 [27]。在四个数据集和三种融合策略上，MC-R 成为最强的多模态策略，兼具基准中最强的结果分数、联合分布基础和计算效率。未来工作包括与第 II 节所述基线的比较评估、与领域专家共同开展反事实质量的人工评估、扩展到更多临床数据集，以及在 CRANE 评估协议内探索生成式反事实策略。
