摘要

尽管结构预测取得了重大进展，但在大规模尺度上模拟驱动生物分子功能的运动和相互作用仍然是一个核心挑战。我们介绍了BioEmu2，这是一种原子级分辨率的生物分子结构生成模型，结合了静态结构预测、平衡采样和时间演化，其采样速度比分子动力学（MD）快多个数量级。该模型在实验和合成结构以及大量MD数据上训练，支持包含蛋白质、核酸、修饰残基、配体和离子的多组分体系。结构预测精度与顶级开源生物分子折叠模型相当，上下文并行模式能够预测兆道尔顿级别的复合物。平衡分布近似MD参考结果，在测试的蛋白质和复合物中自由能误差接近1 kcal/mol。时间传播可预测长时间尺度的动力学轨迹以及结合和构象变化的动力学。生成的结构可通过残基接触条件化或用户自定义偏置势来控制。增强采样能够进行涉及稀有态的自由能计算。BioEmu2使生物分子系综和动力学的研究变得可扩展。

1 引言

蛋白质、DNA和RNA构成生命的基本构建模块，执行从氧气运输和肌肉收缩到存储和处理遗传信息等功能。它们的活动结合了三个反复出现的过程： 构象变化，改变分子的三维排列； 结合和解离，组装复合物并捕获或释放配体；以及 化学反应，转化底物或作为分子开关。这些过程通常是耦合的。例如在血红蛋白中，氧结合将构象平衡从低亲和力的紧张态（T）向高亲和力的松弛态（R）转变。这种耦合支持肺部协同加载氧气和在组织中较低氧分压下卸载氧气[1]。在腺苷酸激酶中，催化循环连接核苷酸结合、结构域闭合、磷酸转移和重新开放以释放产物[2]。这些分子活动形成支撑细胞功能的相互连接的通路。一种可扩展的理解分子功能及其在疾病中失调的手段可以改变药物靶点选择，阐明作用机制，并改善药物疗效和安全性的预测。

下一代测序使分子序列广泛可获取[3]，而AlphaFold、RoseTTAFold及其全原子扩展已经改变了分子结构和复合物的预测[4,5,6,7]。然而，仅预测结构并不能确定哪些构象被占据、它们相互转化的速度有多快，或者配体结合如何改变这些性质。因此，理解功能需要关于结构系综及其动力学的信息。

生物物理实验可以揭示生物分子功能的许多方面，但通常存在低通量或低分辨率的问题。例如，冷冻电子显微镜可以分辨不同的构象状态，核磁共振波谱测量结构波动和交换过程[8,9]，但两者都昂贵且需要漫长的样品制备、数据收集和数据分析。广泛的生物物理技术探测生物分子形状、动力学和相互作用，包括荧光和红外光谱、小角X射线散射和氢-氘交换质谱[10,11,12,13]。无细胞表达、微型化和cDNA展示扩大了功能表征的规模，实现了生化活性和蛋白质稳定性的高通量测量[14,15]。即使扩大规模，这些方法测量的是低维可观测量，而不是直接解析完整的原子构象系综。

原子分子动力学（MD）描述了在选定力场下生物分子结构的详细时间分辨演化。其预测能力受限于相互作用势的精度，但尤其受限于充分采样的计算成本。折叠、构象重排和缔合可能涉及稀少的势垒跨越，需要大量的模拟时间尺度，如蛋白质折叠和蛋白质-蛋白质缔合的模拟所示[16,17]。专用硬件和增强采样算法扩展了可访问的时间尺度，但探索复杂构象景观的计算负担仍然很高[16,17,18]。

机器学习的粗粒化模型通过学习更少自由度的有效相互作用来减轻这种负担[19,20]。最近的可转移模型再现了原子模拟的结构和热力学性质，同时在基准蛋白质上实现了数量级的计算节省[20]。然而，在小分子上扩展这种精度、恢复原子细节和校准动力学仍然具有挑战性。

生成模型学习直接采样目标分布，而不是解析每个中间模拟步骤。Boltzmann生成器采样由已知能量函数定义的分布[21]，但在扩展到大型系统方面能力有限。DiG、AlphaFlow和BioEmu从数据中学习分子系综[22,23,24]，但是粗粒化的单蛋白质模型。Timewarp、MDGen和隐式转移算子将这种方法扩展到时间分离的构型或轨迹段[25,26,27]，但这些都不是能够在广泛复杂结构上泛化的生物分子基础模型。

在这里我们介绍BioEmu2，它在一个原子框架中统一了三种模式：
(1) 结构预测，在FoldBench和Runs N' Poses上精度与当前开源生物分子折叠模型相当[28,29,30,31]。
(2) 近似室温平衡采样，在1 kcal/mol自由能误差内再现大量MD模拟的自由能面并覆盖主要极小值。
(3) 时间传播，允许结构在任意时间滞后τ内向未来传播，以模拟长时间尺度MD轨迹并预测构象变化和结合的动力学。

BioEmu2支持包含蛋白质、DNA、RNA、修饰残基、配体和离子的多组分体系，具有重原子分辨率。上下文并行使得能够对超过5000个残基的系统进行推理。接触条件化和推理时转向提供了对结构生成的控制。增强采样改善了稀有态的覆盖，有效的重加权可以恢复学习的基础系综的统计量。

若干能力仍处于实验阶段，特别是慢动力学，需要更高质量的实验数据集和进一步验证。通过将许多MD风格的采样任务加速多个数量级，BioEmu2使得能够快速迭代实现生物分子动力学和功能的可扩展模拟。

2 BioEmu2模型

BioEmu2是一个生成模型，能够以原子分辨率预测生物分子结构、系综和动力学。与第一版BioEmu[24]相比，BioEmu2可以模拟由任意数量的蛋白质、RNA/DNA、翻译后修饰、脂质、小分子和离子组成的分子系统（图1）。

图1：BioEmu2概览：BioEmu2的高层架构——序列和结构模块的详细架构见第4节。BioEmu2有三种主要使用模式：静态结构预测、平衡结构采样和用于模拟分子动力学的结构时间传播。

在高层次上，BioEmu2模型将学习问题分为两个互补部分：序列主干中的生物推理和结构模块中的坐标生成[4,5]。

在主干中，生物分子系统的标记化描述𝒮通过氨基酸组成表示蛋白质链、通过核苷酸表示核酸、其他物种直接通过其组成原子来获得。蛋白质链进一步以多序列比对（MSA）形式的进化信息进行增强[34,35]。可选的主干条件输入𝒞_trunk可以提供以实现推理时对结构生成的控制。

这三个输入然后由序列主干处理：

(𝒮, MSA, 𝒞_trunk) → 序列主干 → ℰ_trunk (2.1)

BioEmu2支持两种主干条件输入：一个方法标志，定义采样分布是旨在精确结构预测还是近似平衡采样；以及一组（可能为空的）标记到标记的物理接触，作为生成结构时对模型的软约束。

作为扩散生成模型[36,37,38]，BioEmu2的结构模块不会在单次前向传递中产生结构，而是在不同噪声水平σ下逐步去噪结构。因此，结构模块的单次传递将缓存的主干嵌入以及描述部分噪声结构x_noisy和噪声水平σ作为输入：

(𝒮, ℰ_trunk, 𝒞_dyn; x_noisy, σ) → 结构模块 → x̂ (2.2)

产生去噪预测x̂。

与该领域早期模型不同[5,39]，BioEmu2还模拟动力学。在实践中，这是通过结构模块的可选条件输入𝒞_dyn = (x_t, τ)实现的。它携带起始结构x_t和时间滞后τ > 0。然后训练模型采样分布p_τ(x_{t+τ}|x_t)，即从x_t开始并在时间间隔τ内向前传播MD模拟的结构分布。

推理模式。 序列主干和结构模块的不同条件输入的可能性产生了三种主要的推理模式组合，总结如下：

  • 结构预测（方法=结构预测，𝒞_dyn = ∅）：结构模块生成模拟X射线晶体学或冷冻电镜实验获得的静态结构的预测结构x̂。
  • 平衡采样（方法=平衡，𝒞_dyn = ∅）：从学习的近似平衡分布中生成构象样本。
  • 时间传播/动力学（方法=平衡，𝒞_dyn = (x_t, τ)）：模拟初始结构x_t在时间滞后τ内的时间演化，得到时间传播结构x ~ p_τ(x_{t+τ}|x_t)。

我们注意到，可以将动力学条件与结构预测推理模式相结合的输入设置为模型，但不推荐这样做，因为没有训练数据示例使用这种组合。

MSA计算和主干嵌入通常比单个结构模块评估更昂贵。因此，BioEmu2计算一次主干嵌入ℰ_trunk并在许多样本或传播步骤中重复使用它们。

3 结果

我们首先验证BioEmu2在已建立的共折叠基准上静态结构预测的竞争性能，并探测我们推理对大型结构的可扩展性。然后分析BioEmu2在平衡采样方面的性能，最后转向其对生物分子动力学的建模。最后，我们强调转向和增强采样技术如何提供对获得的系综和生成结构质量的推理时控制。

3.1 结构预测

FoldBench和Runs N' Poses。 我们首先评估BioEmu2预测准确的单个生物分子结构的能力。在结构预测模式中，模型目标是实验结构数据（如X射线晶体学和冷冻电镜）特征的结构，而不是平衡系综。使用此设置，我们将BioEmu2与一系列共折叠基线模型在流行的FoldBench基准套件[32]和蛋白质-配体结合结构预测的Runs N' Poses基准[33]上进行比较。

我们选择了具有适当商业许可证（排除AlphaFold3[5]）和可比训练数据截止日期（排除Boltz-2[39]）的模型进行比较，得到以下基线方法：Boltz-1[28]、ESMFold2[31]、OpenFold3[40]、Protenix v1和v2[29]以及OpenDDE[30]。在聚合多个样本时我们不使用置信度头。两个基准的完整细节在第4.8节中描述。

在两个基准中，BioEmu2实现了与评估的共折叠基线相当的准确性，将结构预测确立为我们模型的核心能力（图2a,b）。具体而言，在FoldBench结果中，我们看到BioEmu2在蛋白质和核酸单体上实现了有竞争力的lDDT[41]分数，并在链间结合方面获得了基于DockQ[42]的强成功率。蛋白质-蛋白质结合的较高分数可能由训练数据组成驱动，该组成强调蛋白质-蛋白质相互作用。来自Runs N' Poses的蛋白质-配体评估也突出了BioEmu2在周围蛋白质结构旁边建模配体放置的能力[33]，其性能水平与其他强模型相当。在第3.4节提出的比较中，物理性转向的采样在很大程度上保持了结构预测精度，在某些类别中有适度提升（图6b）。

图2：BioEmu2结构预测模式评估及与具有可比截止日期训练的顶级开源模型比较。 彩色为示例预测结构，灰色为PDB真实值。a) FoldBench结果，按蛋白质、RNA/DNA、蛋白质复合物和蛋白质-RNA/DNA复合物分组。图例同b)。b) 高分辨率蛋白质-配体复合物的Runs N' Poses基准。c) 计算序列嵌入和使用给定嵌入采样结构的计算成本。d) 使用多GPU上下文并行计算的大型复合物示例。e) 说明如何通过在单个残基（链C和D的Asn202）上进行接触条件化来修复8WY8的失败蛋白质复合物结构预测。

将推理扩展到大型复合物。 BioEmu2的结构预测能力扩展到更大的分子组装体。为了在推理时使更大的生物分子系统可访问，BioEmu2实现了上下文并行（CP）以在多个GPU上分布对表示[43]。在NVIDIA B200 GPU上的基准测试展示了从单个GPU到4 GPU（2×2）和16 GPU（4×4）配置的扩展，支持最多约16,000个残基的系统。图2c显示我们的CP代码以可管理的通信开销大幅扩展了最大可访问系统大小。在这个规模下，预测的物理性比计算可行性更成为瓶颈。BioEmu2对包含数千个残基的各种大型蛋白质复合物保持了局部结构精度和整体组装组织。示例包括测试集中的四个多聚体复合物：9ISQ（3,508个残基）、8DOL（3,558个残基）、9Q3J（4,040个残基）和8WW8（5,832个残基），分别实现骨架lDDT分数0.81、0.87、0.94和0.80，全局RMSD分别为5.5Å、5.7Å、2.0Å和6.6Å（图2d）。

对于越来越大的复合物，开箱即用获得成功结构预测的概率趋于降低——既因为结构预测问题更难，也因为大复合物通常在细胞中组装而不是在溶液中形成，因此问题通常没有明确定义。在这种情况下，提供一些额外的提示，如从实验知识获得的残基-残基接触，可以足以显著改善BioEmu2的预测。例如，对于4,020残基的复合物8WY8，仅指定一个链间接触就显著提高了预测精度，将RMSD从71.2Å降至5.0Å，DockQ从0.10提高到0.46（图2e）。

3.2 平衡采样

在平衡模式中，BioEmu2从指定系统的学习结构分布中生成独立抽样。这种模式不是针对尖锐的单态预测，而是旨在再现环境条件下（室温和大气压）水溶液中结构的分布。这通常导致比结构预测模式更高的灵活性和更浅的能量极小值（图3a）。

BioEmu2是一个Boltzmann模拟器：与从已知力场指定的分布p_eq(x)采样的Boltzmann生成器[21]不同，它学习从数据中采样近似p_θ(x)，在蛋白质和生物分子系统之间泛化。这遵循了早期的数据驱动系综模型，包括AlphaFlow[23]和BioEmu[24]。形式上：

x ~ p_θ(x|𝒮), p_θ(x|𝒮) ≈ p_eq(x|𝒮) (3.1)

其中𝒮是分子系统，x是所有重原子的3D坐标，p_θ是BioEmu2的平衡分布，旨在近似真实平衡分布p_eq。p_θ从在300K温度和1 atm压力下使用Amber力场在等温等压（NpT）系综中的显式溶剂全原子MD模拟产生的结构分布中学习[44]。溶剂和模拟体积被边缘化，因此溶剂效应被模型隐式学习。

自由能面。 为了将BioEmu2的p_θ分布与MD数据真实分布p_eq进行比较，我们首先将两个分布的样本投影到控制每个测试系统最慢转变过程的两个集体变量上，通过时间滞后独立成分分析（TICA）计算[45,46]。这种投影解析了亚稳态（长寿命）状态，这些状态 具有潜在的生物学相关性，例如作为结合伙伴选择的构象，以及 在比较p_θ和p_eq时代表比快速或局部波动指标更具挑战性和信息性的测试[47]。我们计算并比较自由能面U(x) = -k_BT ln p_Y(x)，其中p_Y(x)是来自MD或BioEmu2的2D-TICA密度（图3）。

自由能误差衡量模型再现亚稳态相对群体的准确程度。设q_n^eq和q_n^θ分别表示参考和模型分布中亚稳态n的相对群体，通过在相应构象空间区域上积分p_eq和p_θ并归一化获得。我们随后报告在TICA投影中发现的M个亚稳态上的平均绝对误差：

MAE_F = (k_BT/M) Σ_n |ln q_n^θ - ln q_n^eq| (3.2)

状态覆盖衡量模型采样的参考构象空间比例，按样本数归一化。我们将二维TICA空间精细离散化为状态，报告：

coverage = |C_θ ∩ C_ref| / c̃_ref(N) (3.3)

其中C_θ和C_ref是模型访问和参考访问的状态集合，c̃_ref(N)是从参考分布独立抽取的等大样本预期访问的不同状态数。当模型匹配预期参考覆盖时，覆盖等于1。

总之，这些指标捕获BioEmu2是否既找到相关的构象状态又再现它们的相对群体。

3.3 动力学和速率

分子动力学可以通过转移密度p_τ(y|x)来描述，即在构型x之后物理时间τ观察到构型y的概率密度。它定义了一个将构型系综向前时间传播的转移算子。最近的可转移生成模型如Timewarp[25]、MDGen[26]和隐式转移算子（ITO）[27,48]隐式学习这种密度并可以直接采样未来构型。BioEmu2遵循这种方法并采样：

x_{t+τ} ~ p_{θ,τ}(·|x_t) (3.4)

其中p_{θ,τ}从MD轨迹中时间滞后τ间隔的构型对(x_t, x_{t+τ})中学习。模型生成端点x_{t+τ}而不解析中间运动，迭代此步骤产生时间步长比MD飞秒积分步长长多个数量级的轨迹。

对于遍历物理动力学，转移密度p_τ(y|x)在足够长的滞后τ下失去对起始构型x的记忆并接近平衡分布p_eq(y)。通过适当的参数化（第4.6节），BioEmu2再现了这一极限，从而在一个模型中统一了其转移算子和平衡分布。随着τ时间尺度的增加，时间传播因此在同一网络中连续转变为平衡采样，并在τ >> 1 ms时失去对起始构型的所有记忆。

尽管有这一渐近极限，较慢的结合、解离、折叠、展开和其他重排的预测在当前BioEmu2发布版本中尚未建立为定量准确的动力学。

MD时间尺度上的自相关。 匹配平衡分布不一定意味着现实的动力学，因为不同的动力学可以产生相同的平衡。对动力学的直接测试是BioEmu2轨迹是否像MD揭示的最慢运动那样快速去相关。为此，我们比较了78个系统的BioEmu2 ITO轨迹与MD：CATH结构域、PDBbind蛋白质-配体复合物和蛋白质异二聚体（图4）。对于每个系统，我们将MD轨迹和100条BioEmu2轨迹投影到MD的两个最慢TICA坐标IC1和IC2上。自相关C(τ)随着轨迹失去对早期构型的记忆而衰减到零，更快的衰减意味着沿该坐标更快的动力学。

对于大多数系统，在τ = 100 ns时与MD的差异位于MD数据随机两半之间差异的范围内；在差异较大的地方，BioEmu2大多衰减更快（图4）。无论100 ns是由一步τ = 100 ns还是100步τ = 1 ns覆盖，差异都相似，没有明确迹象表明误差在许多步骤中累积。总的来说，我们观察到BioEmu2在许多系统上接近MD，但有时松弛得太快。

3.4 转向和增强采样

BioEmu2样本生成可以在推理时使用转向进行操纵。这既可以用于增强生成样本的物理质量，也可以用于使用增强采样技术改善稀有状态覆盖[52]。

设p_θ(x)表示未转向的模型分布，势函数v(x)定义所需的倾斜分布：

p_v(x) ∝ p_θ(x) exp[-v(x)] (3.5)

势可以惩罚几何缺陷、有利于接触或参考构象，或针对集体变量的范围。

对于物理性转向，我们在分离的去噪坐标上使用引导，可选Feynman-Kac重采样[28,53]。对于增强采样，我们通过去噪器微分势，并使用改编自Twisted Diffusion Sampler（TDS）的离散转移比率加权方案[54]。

物理性转向。 对于结构预测，我们使用几何约束来阻止键畸变、空间重叠和立体化学缺陷，而不强加特定的目标折叠。我们的实现结合了源自Boltz[28,39]的势，并添加了显式聚合物几何和冲突项，包括核酸约束（详见第4.7节）。图6b中的结果比较了FoldBench基准上未转向采样与在去噪最后约20%期间应用的物理性转向。对于大多数类别，结构精度基准不受转向影响，但DNA单体（0.571至0.604）和RNA单体（0.660至0.679）的平均最佳五次lDDT有显著改善。对于个别DNA/RNA系统，改善可能很大（图6b，右）。在各个类别中，转向样本中具有聚合物冲突、键长异常或键角异常的比例显著更少（图6b，底部）。对于DNA和RNA单体，非物理分数分别从70.0%降至1.4%和从61.3%降至4.0%。

稀有态的增强扩散采样。 增强采样是MD模拟中使用的一系列方法，用于实现具有大自由能差异的自由能计算[55,56]。原理是使用偏置势人为增加平衡中稀有的状态频率，然后重新加权偏置样本以恢复无偏自由能差异。我们将相同原理应用于扩散模型采样[52]：推理时转向方法如TDS[54]或Feynman-Kac校正器（FKC）[57]生成偏置系综，多状态Bennett接受率（MBAR）[58,59,60]将它们组合以估计零偏置模型分布。

4 方法

4.1 分子系统定义

我们通过以下方式描述分子系统：

𝒮 = (ℰ, ℐ, ℬ) (4.1)

其中ℰ指定分子实体，ℐ指定它们的链拷贝，ℬ指定它们的共价连接性。这种分离将分子身份与化学计量区分开：两个相同的蛋白质链共享实体定义但在生成的复合物中保持不同的链。该表示遵循PDBx/mmCIF的实体和链组织以及AlphaFold 3的全原子建模方法[5]。

化学组成和连接性。 系统定义支持单体、多链组装体和包含蛋白质、RNA、DNA、修饰残基、小分子和支链组分的复合物。蛋白质通过其氨基酸序列指定，RNA和DNA通过其碱基序列指定。化学组分可以通过化学组分字典（CCD）代码[61]识别，该代码指定原子身份、键和立体化学，或通过支持的基于文本的化学编码。配体（包括脂质和离子）接受CCD代码、SMILES或InChI；SMILES和InChI直接描述化学结构。修饰和非标准聚合物残基通过其序列位置和CCD代码或InChI指定。这替换了指定位置的化学身份。例如，磷酸苏氨酸可以通过在苏氨酸位置的CCD代码TPO指定。标准聚合物链接从序列顺序构建。可以添加额外的共价键以指定不由链顺序确定的连接性，例如二硫键或链之间的共价链接。总之，链定义、链拷贝和共价键确定分子拓扑。支链组分可表示但当前训练数据中不存在。

原子和标记级表示。 系统被扩展为原子级图和标记序列，遵循全原子结构预测中使用的混合分辨率表示[5]。传统聚合物残基各占一个标记；配体、修饰残基和支链单体每个重原子使用一个标记。因此，标记是计算单元而不是生成结构的统一粗粒化描述。

4.2 多序列比对

蛋白质多序列比对（MSA）提供补充分子组成的进化信息。序列保守性和相关替换帮助模型识别蛋白质内和相互作用链之间的结构约束，如基于MSA的结构预测方法[35,4]。BioEmu2将这些输入用于结构预测和平衡模拟。

链比对和配对。 为每个不同的蛋白质序列获得独立的比对。默认获取使用ColabFold[35]搜索MSA。每个比对包括查询序列和与其残基位置对齐的同源序列。非蛋白质组分不需要进化比对。对于异聚体系统，配对比外还将同源物跨蛋白质链关联，例如通过匹配单个生物体基因组中两个序列的出现。配对行提供可以告知分子间相互作用的对应关系，而未配对比对提供链内进化上下文而不指示两个链的独立比对之间的特殊关系。BioEmu2组合两种行并记录哪些位置源自配对比对。

示意性地，比对准备产生：

{链比对} → (A, d, q) → MSA特征 (4.2)

其中A_ri是行r中标记位置i的对齐符号，d_ri记录相对于查询的插入信息，q_ri是指示配对的二进制标志。缺口表示缺失的对齐位置和给定行中没有序列的链。这些特征的连接给出MSA特征向量u_ri。MSA信息的粗略摘要也通过MSA行上的简单平均池化包含在主干中。

4.3 序列主干和条件化

序列主干将化学和进化输入转换为主干嵌入E_trunk = (E_single, E_pair)。对于L个标记，单标记和标记对嵌入具有形状：

E_single ∈ ℝ^{L×d_s}, E_pair ∈ ℝ^{L×L×d_z} (4.3)

其中d_s和d_z分别是单标记和标记对特征维度。我们在BioEmu2模型中设置d_s = 384，d_z = 256。主干的输出取决于分子系统、比对和条件化。条件输入𝒞_trunk由模式标签m ∈ {平衡，结构预测}和可选的接触集合ℋ组成。然后主干被评估为：

(E_single, E_pair) = F_θ(𝒮, MSA, m, ℋ) (4.4)

这种分离遵循AlphaFold 3和Boltz的表示和扩散架构[5,28]。它允许一次表示计算支持具有不变条件化的许多坐标样本。

我们使用PairMixer序列主干[62]，它放弃了PairFormer的三角形注意力和单表示更新[5]。早期工作（包括Minifold[63]）也表明，更简单的主干架构可以实现与PairFormer基本相同的性能。

给定该特征向量f_i，单和对表示初始化为：

s_i^(0) = W_s f_i (4.5)
z_ij^(0) = W_a f_i + W_b f_j + r_ij + b_ij^bond

其中r_ij编码关于i,j相对位置的信息，例如它们是否属于相同链或实体以及它们的序列分离，b_ij^bond携带共价键信息。

模式条件化。 采样模式m区分MD条件的平衡模拟和非MD结构预测。我们将其实现为添加到每个标记的初始单表示的学习偏置向量和添加到初始对表示的第二个偏置。

接触条件化。 遵循Boltz2[39]，接触输入是标记对和距离阈值的列表：

ℋ = {(i, j, d_ij^max)} (4.6)

每个提供的对预期位于其阈值内。列表被转换为成对特征：类别区分选定接触、未选定对和接触条件化的缺失。添加到对表示的学习接触偏置表示为b_ij^contact。对于选定对：

b_ij^contact = Embed_contact(category_ij, d_ij^max) (4.7)

对 被对称更新。主干中的接触条件化不同于转向，后者是影响采样过程的推理时手段。

MSA输入。 行r中标记i的初始MSA特征包含残基（或缺口）的独热编码，以及插入、删除和配对的标志。给定这些MSA特征u_ri，我们通过以下方式将它们与初始标记特征f_i结合：

M_ri^(0) = W_M u_ri + W_f f_i (4.8)

主干层。 主干使用MSA模块，后跟PairMixer堆栈[62]。MSA模块通过条件化平均耦合序列行，并通过外积聚合将比对信息转移到对。在4个MSA层之后，随后的48个PairMixer层仅在对表示上操作。MSA模块和PairMixer都使用三角形乘法，组合关于共享中间标记的对的信息。抑制学习的投影、门和归一化，两个三角形操作具有形式：

Δz_ij^out ~ Σ_k A(z_ik) ⊙ B(z_jk), Δz_ij^in ~ Σ_k A'(z_ki) ⊙ B'(z_kj) (4.9)

其中⊙表示逐元素乘法。这些操作通过标记三元组通信，允许局部化学和进化证据告知系统范围内的关系。PairMixer将出站和入站三角形更新与成对转换网络结合，没有三角形注意力层[62]。主堆栈精化对特征；单标记特征保留其输入和模式相关信息。

循环。 我们重复MSA和对处理阶段，同时将归一化、投影的单和对表示反馈到其初始状态。我们在推理时默认使用3个循环步骤。在训练时，我们在循环步骤上使用保持所有秩同步的确定性调度。

4.4 结构模块和采样

双流结构架构。 我们的结构模块受到NeuralPLexer3引入的流块[64]的启发。其16个块中的每一个交错原子级和标记级更新，而不是像AlphaFold 3那样分离原子编码、标记转换器和原子解码[5]。原子流使用窗口化注意力和转换MLP；标记流使用完整标记注意力和转换MLP。跨流更新在指定标记中心原子处收集特征并将标记特征广播到其关联的原子。两个流都以主干表示和扩散噪声水平为条件。对于时间传播，滞后时间特征和提供的起始坐标提供额外条件化。坐标读出跟随堆栈，EDM预处理将此更新与噪声输入结合以获得去噪坐标估计。

图8：结构模块。 输出是评估的去噪器x̂ = D_θ(x_noisy, σ|𝒞)。重复的采样更新使用该预测生成坐标。

条件去噪。 在生物分子系统被序列主干嵌入后，BioEmu2的结构模型使用条件扩散模型生成结构。条件定义如下：

𝒞 = (𝒮, E_single, E_pair; [x_t, τ]) (4.10)

  • 𝒮：系统嵌入下描述的静态系统特征。
  • E_single和E_pair：序列主干产生的单标记和标记对嵌入。
  • [x_t, τ]：初始物理时间的可选构型和时间传播的正滞后τ。当提供平衡模式条件时，这些指定以x_t为条件的未来端点x_{t+τ}的采样。

扩散模型是全原子笛卡尔坐标上的条件分数模型。在每个去噪步骤中，它接收当前噪声坐标x_noisy及其噪声水平σ，以及𝒞。静态系统特征和嵌入跨步骤缓存。分数估计噪声扰动条件密度对数的梯度：

s_θ(x_noisy, σ|𝒞) ≈ ∇_{x_noisy} log p_σ(x_noisy|𝒞) (4.11)

其中p_σ是与协方差σ²I的高斯噪声卷积的目标结构分布。BioEmu2使用去噪器参数化[65]：网络重建干净坐标D_θ(x_noisy, σ|𝒞)，通过以下定义分数：

s_θ(x_noisy, σ|𝒞) = (D_θ(x_noisy, σ|𝒞) - x_noisy)/σ² (4.12)

从模型采样意味着逐步去噪结构。它从高斯坐标x_noisy,σmax ~ 𝒩(0, σ_max²I)开始，并沿递减噪声调度[65]逐步去噪。没有ITO条件，结果是从选定结构分布中的样本。有x_t和τ，结果是未来构型x_{t+τ}。（噪声水平σ和采样器的去噪步骤不同于物理滞后τ。）

ITO输入的处理。 时间条件输入[x_t, τ]仅通过结构模块进入。在训练时，我们对结构x_t应用噪声N(0, ς²)以提高模型对原始结构中错误的鲁棒性（ς = 0.1Å）。我们通过以下方式特征化τ：

e_k(τ) = e^{-τ/s_k}{1, sin(2πqτ/s_k), cos(2πqτ/s_k)}

在各种衰减率s_k和各种q上连接。这些特征与扩散噪声尺度嵌入一起进入单条件流。时间条件坐标x_t与噪声坐标x_noisy一起进入，并乘以门g(τ)，其构造使得当τ→∞时g→0。

EDM预处理和推理更新。 我们遵循EDM扩散模型设置[65]。将Δx_θ写为网络的坐标更新读出，EDM去噪器[65]为：

D_θ(x_noisy, σ|𝒞) = c_skip(σ)x_noisy + c_out(σ)Δx_θ(c_in(σ)x_noisy, c_noise(σ)|𝒞) (4.13)

其中：
c_skip(σ) = σ_data²/(σ² + σ_data²)
c_out(σ) = σσ_data/√(σ² + σ_data²) (4.14)
c_in(σ) = 1/√(σ² + σ_data²)
c_noise(σ) = (1/4)log(σ/σ_data)

这里，σ_data设置用于预处理的坐标尺度，在我们的情况下为16Å。

设σ_0 > ⋯ > σ_K = 0为推理噪声调度，x^(0) ~ 𝒩(0, σ_0²I)。在步骤k，噪声注入暂时增加噪声水平：

σ̂_k = (1+γ_k)σ_k, x_noisy,k = x^(k) + S_noise √(σ̂_k² - σ_k²) ε_k, ε_k ~ 𝒩(0, I) (4.15)

我们在某个噪声水平以下关闭churn，简单地设置x_noisy,k = x^(k)和σ̂_k = σ_k。

给定结构x_noisy,k，一次去噪器评估给出x̂_k = D_θ(x_noisy,k, σ̂_k|𝒞)，然后：

x_update,k = (x_noisy,k - x̂k)/σ̂_k, x^(k+1) = x_noisy,k + S_step(σ{k+1} - σ̂_k)x_update,k (4.16)

每一步应用全局刚性增强。如果使用ITO条件结构x_t，则对其应用相同的刚性增强。在推理时，如AF3中那样，每个反向步骤的噪声坐标在更新（4.16）之前刚性地对齐到去噪预测。

通过直接转向，x̂_k被引导的去噪估计替换，然后计算x_update,k。相应的方程和粒子校正变体在第4.7节中给出。

结构预测锐化。 对于结构预测，我们通过放大去噪更新相对于注入噪声在EDM采样框架[65]中应用经验锐化。在上面的更新中，这对应于在方程（4.16）中设置S_step = 1.5，S_noise = 1.003，而平衡采样为S_step = S_noise = 1。结构预测修改也用于AlphaFold 3[5]和Boltz[28,39]。

4.5 平衡分布采样

我们的MD模拟使用等温等压或NpT系综：粒子数N、外部压力p和温度T固定，而模拟体积V波动。BioEmu2针对环境条件下的平衡采样：NpT训练模拟使用室温T和p = 1 atm压力。设x表示BioEmu2生成的生物分子坐标，z收集剩余的构象自由度，包括显式溶剂。在积分出动量后，完整构型的无量纲约化能量为：

u(x, z, V) = β[U(x, z; V) + pV], β = 1/(k_BT) (4.17)

其中U是势能，k_B是Boltzmann常数。联合平衡密度为：

ρ(x, z, V) = Z^{-1} exp[-u(x, z, V)] (4.18)

具有归一化常数Z和体积相关的笛卡尔构型域。与模型相关的平衡分布是溶剂和体积上的边缘分布：

p_eq(x) = ∫₀^∞ dV ∫ dz ρ(x, z, V) (4.19)

因此BioEmu2隐式包含溶剂效应：它生成生物分子坐标而不显式溶剂坐标，同时学习溶剂和体积自由度已被边缘化的分布。因此，结构分布不仅仅是孤立蛋白质的Boltz曼因子。

BioEmu2是一个Boltzmann模拟器，通过以下近似该平衡分布：

x ~ p_θ, p_θ(x) ≈ p_eq(x) (4.20)

其中θ表示共享的学习参数，为可读性而省略对系统序列嵌入的依赖。平衡采样是近似目标，不是对每个系统校准群体或定量自由能的保证。

4.6 时间传播

马尔可夫状态模型（MSM）将分子动力学描述为在选定滞后时间τ下离散构象状态之间的转变[66,67,68]。当许多短轨迹集体采样相关状态和转变时，MSM可以恢复长时间弛豫和平衡群体而不要求每条轨迹平衡[67,68]。然而，传统MSM是特定系统的分析模型，不能跨分子系统转移。

最近的工作转向生成神经网络，可以跨分子系统泛化。示例包括深度生成MSM[69]、Timewarp[25]、MDGen[26]和隐式转移算子（ITO）框架的可转移扩展[48,70]。BioEmu2遵循原始ITO公式[27]，其中以起始坐标x_t和物理滞后τ为条件的扩散模型采样：

x_{t+τ} ~ p_{θ,τ}(·|x_t) (4.21)

近似物理转移密度p_τ(x_{t+τ}|x_t)。该公式允许BioEmu2直接生成端点x_{t+τ}，而不解析中间MD轨迹。长时间运行的、时间排序的轨迹可以通过重复条件采样来采样。因为只保留生物分子坐标，其他动力学自由度（如动量和溶剂）通常不会从一步携带到下一步。

平衡极限。 对于遍历系统，动力学弛豫到唯一平衡分布，物理转移密度失去其初始构型的记忆。对于模型，相应的一致性条件是：

lim_{τ→∞} p_{θ,τ}(x_{t+τ}|x_t) = p_θ(x_{t+τ}) (4.22)

其中p_θ是方程（4.20）中所述的平衡模型。我们施加与分子动力学训练数据定义的经验平衡的一致性，而不是像MSM那样从转变推断平衡。为实现这一点，我们遵循BoPITO[71]的思想，将转移密度分为由平衡模型给出的平稳部分和随滞后衰减的时间相关部分。在实践中，网络不添加单独的平衡和动态分数。相反，它通过随滞后增长淡出其动力学条件来移除时间相关部分。

滞后时间特征携带指数包络e_k(τ)，对初始构型的条件化由这些包络的学习正组合门控：

e_k(τ) = exp(-τ/s_k), g(τ) = Σ_k w_k e_k(τ), w_k > 0, 0 < s_k ≤ s_max (4.23)

添加到单表示的滞后时间嵌入采用阻尼谐振子的形式并在相同时间尺度上衰减。当s_max = 1 ms时，门和滞后时间嵌入在τ >> s_max时都消失，因此只有平稳部分保留，网络精确恢复平衡去噪器。这种交叉的形式是架构选择，但权重w_k和时间尺度s_k从数据中学习。因此，交叉不应被理解为物理弛豫时间的估计：它保证与学习平衡分布的一致性，这不必与精确热力学平衡一致。

训练。 对于一部分训练样本，我们从同一MD轨迹中抽取帧对(x_t, x_{t+τ})。我们将目标帧刚性地对齐到起始帧，然后对两者应用相同的随机旋转和平移，这保留了相对于起始构型的运动。其余MD帧作为独立平衡示例，动力学条件化被屏蔽，滞后设为τ = ∞。两个任务共享相同的网络和EDM去噪损失（第4.4节）。

BioEmu2的动力学训练数据几乎全部来自最多1 μs的MD模拟。为较慢过程（如结合、解离、折叠、展开和其他慢重排）预测的速率和路径因此需要独立验证。在模型在这些时间尺度的实验数据上训练和验证之前，此类预测应被视为定性假设而不是定量动力学。

展开。 每个ITO步骤运行完整的扩散采样器，每次去噪器评估以前一个构型x_t和选定滞后τ为条件，而主干嵌入每个系统计算一次并跨步骤重复使用。在固定采样器设置下，每步的成本与τ无关，所需计算随模拟时间线性增长。滞后可以在步骤之间变化，起始构型可以是实验或预测结构、平衡样本或手动修改的结构，例如旁边放置配体的apo蛋白质。

4.7 转向和增强采样

转向改变推理时采样的结构分布而不重新训练模型。与更改主干嵌入的模式或接触条件化不同，它作用于坐标生成。它可以有利于物理几何、特定构象或在未转向模型下稀少的区域。BioEmu2实现势梯度引导和基于粒子的Feynman-Kac方法[53,57,54]，这些也可以支持增强采样工作流程[52]。

势和倾斜分布。 设p_base(x)表示固定系统和条件化的未转向分布。无量纲势v(x)指定所需的倾斜：

p_v(x) = Z_v^{-1} p_base(x) exp[-v(x)], Z_v = ∫ p_base(x) exp[-v(x)] dx (4.24)

较低的势值受到青睐。对于物理偏置能量B(x)，相应的无量纲势为v(x) = βB(x)；几何惩罚可以直接以无量纲形式定义。多个目标可以通过对其势求和来组合。倾斜定义目标分布，不保证每个引导过程都精确采样它。

坐标表示法。 遵循第4.4节的表示法，i索引去噪步骤而不是物理时间。坐标x^(i)是计划噪声水平σ_i下的当前噪声状态；x_noisy,i表示增强和噪声注入后的坐标，在重新加热的噪声水平σ̂_i；x̂_i = D_θ(x_noisy,i, σ̂_i|C)是条件化C下干净坐标的相应预测。我们省略粒子索引。两个过程使用这些相同的坐标，但在其重新加热调度和梯度取处不同。

物理性转向：几何惩罚。 物理性势阻止坐标生成期间的局部几何缺陷。我们改编Boltz转向势[28]用于配体距离几何、手性、键立体化学、平面性和链重叠，并用显式键长和键角约束以及聚合物冲突惩罚扩展它们。聚合物冲突惩罚阻止链内和链间的原子冲突。一般的链内和链间冲突惩罚排除在三个共价键内连接的原子对。单独的局部惩罚防止由两个或三个键连接的不同残基中合格蛋白质或核酸原子之间过度接近的接触。几何约束使用表格参考值，包括肽和核苷酸连接以及声明的二硫键，在没有匹配参考值时具有宽边界。遵循Boltz转向，可允许区间可以用平底惩罚强制执行。单侧约束省略相应的边界项。违反在允许区间内消失并在其外线性增长；势特定的缩放和采样器系数决定其影响。对于具有下限和上限q_min和q_max的标量几何量q，未加权违反为：

h(q; q_min, q_max) = max(q_min - q, 0) + max(q - q_max, 0) (4.25)

其他势可以有利于指定的接触、参考构象或集体变量范围。

物理性转向：分离坐标引导。 我们使用第4.4节的churn调度并在不通过去噪器微分的情况下评估x̂_i。在每个引导扩散步骤，我们初始化单独的优化变量y_i^(0) = x̂_i。这里ℓ计算内部势梯度步骤，而不是扩散步骤，j索引势：

y_i^(ℓ+1) = y_i^(ℓ) - Σ_j η_{j,i,ℓ} ∇_y U_j(y_i^(ℓ)), x̂_i^g = y_i^(L_i) (4.26)

在L_i内部步骤后，x̂i^g = y_i^(L_i)是引导的干净坐标预测；上标g表示引导。系数η{j,i,ℓ}包括每个势的引导强度和激活调度，引导在非终端转换上应用。然后我们应用方程4.16中的EDM更新，用引导的干净预测x̂_i^g替换x̂_i。如果启用重采样，每个选定的粒子携带其噪声坐标和引导预测。如果启用刚性对齐，我们首先将这些噪声坐标对齐到该预测。因此，势修改用于传输的去噪预测，而不是通过去噪器反向传播到其噪声输入。可选的FK重采样使用在引导之前评估的加权势能差异，乘以全局加权强度，以及基于携带的引导位移和当前高斯噪声的校正。

对于图6b中的物理性比较，我们使用了没有粒子重采样的分离坐标梯度引导，在200个去噪转换的最后约20%期间激活。采样队列和评估程序在第4.8节中描述。更好的局部几何不保证更好的平衡群体，但有助于保持和改善结构预测指标同时显著减少非物理性。

增强采样：通过去噪器的引导和TDS权重。 对于PGK示例，我们使用Twisted Diffusion Sampler（TDS）[54]。设v_i(x)为步骤i处干净坐标上的偏置，包括任何步骤相关的缩放或其参数的变化。噪声坐标上的相应偏置为V_i(x_noisy) = v_i(D_θ(x_noisy, σ̂i|C))。这里V_i是通过去噪器的噪声输入坐标的函数，不同于在分离y上的物理性优化。我们使用sigma重新加热而不是物理性churn调度：σ̂_0 = σ_0且对于i > 0，σ̂_i = σ{i-1}，注入噪声方差ν_i = σ̂_i² - σ_i²。当S_step = 1时，非终端提议为：

x^(i+1) = x_noisy,i + (σ̂i - σ{i+1})/σ̂i [D_θ(x_noisy,i, σ̂_i|C) - x_noisy,i] - (ν_i/2)∇{x_noisy,i} V_i(x_noisy,i) (4.27)

梯度通过去噪器作用于噪声坐标x_noisy,i。设w_i表示在重新加热状态x_noisy,i处的未归一化粒子权重。对数权重根据重采样事件之间的以下方式累积：

log w_i = log w_{i-1} - V_i(x_noisy,i) + V_{i-1}(x_noisy,i-1) + log(K_i/Q_i), i ≥ 1 (4.28)

这里K_i和Q_i是在x_noisy,i处评估的参考和引导提议转移密度。它们分别将前面的未引导或引导传输与当前高斯刷新结合，条件于相同的采样刚性增强。如果它们的均值相差δ_i = m_{Q,i} - m_{K,i}且r_i = x_noisy,i - m_{Q,i}是采样的高斯残差，则log(K_i/Q_i) = -r_i^T δ_i/ν_i - ||δ_i||²/(2ν_i)。均值在应用共享旋转和平移之前分别居中。初始对数权重为-V_0(x_noisy,0)，对于恒定强度转向不必为零。在最后转换m，σ_{m+1} = 0且引导被禁用。在方程4.27中将引导项设为零，a = 1，给出完成的样本X = x^(m+1) = D_θ(x_noisy,m, σ̂_m|C)；最终对数权重增量为-v(X) + V_m(x_noisy,m)。结果目标为p_v(X) ∝ p_θ(X)e^{-v(X)}，其中p_θ是有限步未引导参考采样器的端点分布。有限粒子群体和权重退化限制该目标的估计。

我们的PGK示例使用方程4.28中的离散TDS核比率[54]，而不是之前工作[52]中的Feynman-Kac校正器（FKC）权重规则[57]。与FKC不同，TDS规则不需要∂_σ U，即通过去噪器的势的噪声水平导数。

增强采样：粒子重采样。 我们在每个粒子组内归一化权重并计算N_eff = 1/Σ_{n=1}^{N_p} w̄_n²。TDS实现支持在配置间隔或当任何组的分数N_eff/N_p低于阈值时重采样。系统重采样复制所有依赖祖先的状态并重置累积对数权重；当提供势时执行最终重采样。返回的粒子具有相等权重但可以共享祖先，不应被计为独立观测。

增强采样：恢复无偏模型统计量。 偏置势可以有利于未转向模型仅稀少采样的构象[52]。在倾斜系综中，结构x的概率与其未转向概率p_base(x)乘以exp[-v(x)]成比例。在偏置和未转向系综之间有足够重叠的情况下，我们可以通过用逆因子加权每个结构来估计可观测量A的未转向均值：

⟨A⟩_base = ⟨A(x)exp[v(x)]⟩_v / ⟨exp[v(x)]⟩_v (4.29)

当使用多个窗口应用不同偏置时，它们的相对归一化可以使用MBAR通过多状态重加权来估计[60]。我们注意到转向和重加权方法可以解决稀有事件采样以恢复基础模型的统计量；它们不消除基础模型本身的误差。

示例：PGK结构域姿态增强采样。 为了说明已知的替代构象如何在不规定其群体的情况下指导探索，我们以平衡模式条件化采样apo PGK，并将其N和C结构域核心的相对平移和旋转偏向闭合参考2X13。结果显示在图6c中。我们将居中的闭合参考核心拟合到相应的采样C-alpha坐标，使用164个N核心和186个C核心原子。设R_N, R_C为行向量约定中正确拟合的旋转，c_N, c_C为采样的核心质心，c_N, c_C为它们的闭合参考质心。偏置集体变量是N核心坐标系中的平移误差和相对旋转弦误差：

d(X) = ||(c_C - c_N)R_N^T - (c_C - c_N)||, c(X) = ||R_C R_N^T - I||_F/√2 (4.30)

对于强度为k的窗口，偏置v(X;k)在平底容差外是二次的：

v(X;k) = (k/2)[([d(X)-d_0]+/w_d)² + ([c(X)-c_0]+/w_c)²], [u]_+ = max(u, 0) (4.31)

我们使用d_0 = 1Å，w_d = 2Å，c_0 = 2sin(5°/2)，w_c = 2sin(15°/2)。这约束拟合的链间姿态而不是直接惩罚内部核心RMSD。我们使用了两个偏置窗口，k = 0.5和k = 1，具有TDS权重和每14粒子群体200个扩散转换。当N_eff/14 < 0.5时触发系统重采样，也在最终端点执行。在每个非零强度下保留的所有1,008个返回结构没有进行基于RMSD的群体筛选。对于可视化，我们在共同的406原子选择上计算了独立刚性对齐的C-alpha RMSD到开放2XE7和闭合2X13。基线面板（图6c左）包含4,032个未转向结构。增强面板（图6c右）通过普通MBAR[60]估计无偏（即k = 0）分布，将2,016个基线结构与来自每个k = 0.5和k = 1的转向系综的1,008个结构合并。我们在所有三个偏置条件k = 0, 0.5, 1下评估每个保存的结构，并将这些偏置能量和样本计数提供给MBAR，后者计算用于估计无偏基线统计量的单独权重。自由能景观渲染为ΔF = -RT log(p/p_max)的等高线，T = 300 K。代表性结构A-C从该投影中指定区域的保存源池帧中选择，受蛋白质几何质量检查约束。这些选择没有过滤景观。结构插图使用N核心对齐和共同的相机和尺度，而绘制的RMSD使用独立的整个蛋白质对齐。
