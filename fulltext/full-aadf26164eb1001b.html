摘要

动态超表面天线（DMA）因其能够实现密集且节能的天线架构，已成为在下一代无线网络中实现大规模天线阵列的一种有前景的技术。然而，在时变信道条件下，联合优化数字波束成形和DMA单元权重仍然具有挑战性，因为二者对接收信号功率和干扰功率存在耦合影响。我们将该问题表述为在时变信道条件下最大化时间平均能量效率（EE），并受发射功率约束、洛伦兹相位限制和最小速率需求的约束。为了实现长期规划，并与无模型强化学习相比提高样本效率，我们开发了一种世界模型框架，该框架通过与环境的交互学习潜在系统动力学，并通过想象轨迹联合优化数字波束成形和DMA单元权重。此外，我们引入了保持可行性的动作映射和安全代价信号，以确保策略学习过程中的约束满足。仿真结果表明，与深度Q网络基线相比，所提出的框架将时间平均EE提高了约20%，同时实现了更高的样本效率和更可靠的约束满足。

索引术语：动态超表面天线（DMA），强化学习（RL），世界模型。

I 引言

下一代无线网络预计将依赖基站（BS）上的大型天线阵列来实现更高的波束成形增益和更好的连接性。动态超表面天线（DMA）已成为一种以降低硬件成本和功耗实现此类阵列的有前景的技术。在DMA架构中，多个辐射超材料单元沿微带波导排列，每条微带由专用的射频链馈电。然而，联合优化数字波束成形和DMA单元权重仍然具有挑战性，特别是在时变信道条件下 [1, 2]。

大量研究集中于基于DMA的天线架构以增强无线通信性能 [1, 2, 3, 4]。例如，文献 [1] 的作者研究了多用户下行链路系统中的近场波束聚焦以实现和速率最大化，考虑了三种天线架构，即全数字架构、基于移相器的混合架构和DMA架构。文献 [2] 的作者提出了一种新颖的算法来最大化用户的信噪比，并推导了DMA权重的闭式表达式。文献 [3] 的作者研究了基于DMA系统中的频谱效率最大化，其中考虑了计入实际辐射功率的现实发射功率约束。文献 [4] 的作者研究了基于DMA的宽带通信的速率分裂多址接入，考虑了超表面单元的频率选择性洛伦兹响应，以最大化子载波间的最小和速率。然而，这些研究中采用的基于优化的方法的有效性在很大程度上依赖于无线网络的精确数学模型，而由于时变信道条件和不完整的系统信息，这在实践中通常难以获得。此外，这些方法通常需要在每个时隙对非凸优化问题进行迭代求解，带来了巨大的计算复杂度，限制了它们在实时操作中的适用性 [5]。虽然启发式算法为解决非凸优化问题提供了替代方法，但它们在大规模和高度动态的无线网络中通常表现出有限的可扩展性和鲁棒性 [6]。

为了应对这些挑战，最近的研究探索了强化学习（RL）方法，包括基于模型的RL（MBRL）和无模型的RL（MFRL），以在时变信道条件下优化无线网络性能，而无需底层系统动力学的完整知识 [7, 8]。例如，文献 [9] 的作者开发了一种深度RL框架来优化频率选择性DMA权重，以在近场上行链路通信中最大化子载波间的平均波束成形增益。然而，现有的基于RL的方法仍然面临若干挑战，包括数据低效（需要大量的环境交互来探索高维动作空间）以及有限的长期规划能力（这可能阻碍时变信道条件下数字波束成形和DMA单元权重的联合优化）。

基于世界模型的RL（WMBRL）通过学习系统动力学的紧凑表示并通过想象轨迹优化策略，为应对这些挑战提供了一种有前景的方法。这通过利用预测的未来状态，在时变信道条件下联合优化数字波束成形和DMA单元权重，实现了样本高效的策略优化。

这种长期规划对于在时变信道条件下最大化时间平均能量效率（EE）尤为重要 [10]，因为它能够在多个时隙上联合优化数字波束成形和DMA单元权重，而不是针对每个信道实现独立地优化它们。然而，在时变信道条件下通过长期规划和安全感知学习来联合优化数字波束成形和DMA单元权重在很大程度上仍未被探索。

贡献： 基于上述研究空白，本文的主要贡献概述如下：

• 我们开发了一个统一的优化框架，用于联合优化数字波束成形和DMA单元权重，以在时变信道条件下最大化时间平均EE，并受发射功率约束、洛伦兹相位限制和最小速率需求的约束。

• 我们提出了一种约束处理方法，通过保持可行性的动作映射来强制执行发射功率约束和洛伦兹相位限制，同时通过安全代价机制解决最小速率需求。这种方法降低了学习复杂性，同时在策略优化过程中能够对约束满足进行显式控制。

• 我们开发了一个WMBRL框架，该框架从收集的经验中学习系统动力学，并利用想象轨迹联合优化数字波束成形和DMA单元权重，实现长期规划，同时减少策略学习期间大量环境交互的需求。

• 我们通过仿真证明，在所考虑的系统中，所提出的框架相对于深度Q网络（DQN）基线在时间平均EE上实现了约20%的平均改进，同时表现出更高的样本效率和更可靠的约束满足。

II 系统模型与问题表述

我们考虑一个基于DMA的基站为 K 个单天线用户服务。该基站配备 N = N^𝖽 × N^𝖾 个超材料单元，排列在 N^𝖽 条微带上，每条微带包含 N^𝖾 个亚波长辐射单元。假设用户随机分布在基站周围，水平距离在 [ψ^min, ψ^max] 范围内。传输周期被划分为 T 个时隙。

II-A 时变信道模型

第 t 个时隙基站与第 k 个用户之间的信道向量表示为 𝐠_k[t] = √ν_k · 𝐠̃_k[t], ∀t, k，其中 ν_k = (c₀/(4πf^c ψ_k))² 表示自由空间信道功率增益，c₀ 是光速，f^c 表示载波频率，ψ_k ∈ [ψ^min, ψ^max] 是基站与第 k 个用户之间的距离。此外，𝐠̃_k[t] 表示小尺度衰落向量。为了捕捉无线信道的时变特性，小尺度衰落分量使用遵循Jakes衰落模型的一阶复高斯–马尔可夫过程建模，表示如下 [11, 10]：

𝐠̃_k[t] = ρ𝐠̃_k[t−1] + √(1−ρ²) · 𝐞_k[t], ∀t, k, (1)

其中 𝐠̃_k[0] ∼ 𝒞𝒩(𝟎, 𝐈_N) 表示初始小尺度衰落向量，𝐞_k[t] ∼ 𝒞𝒩(𝟎, 𝐈_N) 表示独立的新息过程。此外，0 ≤ ρ < 1 表示连续小尺度衰落实现之间的时间相关系数。

II-B DMA架构与信号模型

第 t 个时隙每个单元的频率响应表述如下 [2]：

q_{i,ℓ}[t] ∈ 𝒬_{i,ℓ}[t] = {(j + e^(jε_{i,ℓ}[t]))/2 | ε_{i,ℓ}[t] ∈ [0, 2π]}, ∀t, i, ℓ, (2)

其中 i ∈ {1, …, N^𝖽} 且 ℓ ∈ {1, …, N^𝖾}。此外，每条微带上的信号传播以衰减和相移为特征，其中衰减取决于微带的物理特性和几何形状，而相移由传播波数和沿波导的位置决定。因此，每条微带上的信号传播建模为 m_{i,ℓ} = e^(−ζ_{i,ℓ}(α_i + jβ_i)), ∀i, ℓ，其中 ζ_{i,ℓ} 表示第 i 条微带上第 ℓ 个辐射单元的位置，而 α_i 和 β_i 分别表示相应的衰减系数和传播波数 [1]。我们假设所有微带类型相同，即 α_i = α 且 β_i = β。第 t 个时隙DMA辐射单元发射的等效信号表示为 𝐱[t] = 𝐌𝐐[t]𝐯[t], ∀t，其中 𝐌 ∈ ℂ^(N×N) 表示对角矩阵，其对角元素定义为 𝐌_{(i−1)N^e+ℓ,(i−1)N^e+ℓ} = m_{i,ℓ}。此外，𝐐[t] ∈ ℂ^(N×N^d) 表示第 t 个时隙的可配置DMA权重矩阵，其元素定义如下 [1]：

𝐐_{(i−1)N^e+ℓ,n}[t] = q_{i,ℓ}[t]（当 i = n 时）；0（当 i ≠ n 时）。 (3)

最后，𝐯[t] = [v₁[t], …, v_{N^d}[t]]^T 表示第 t 个时隙DMA微带的输入信号向量，表示为 𝐯[t] = Σ_{k=1}^K 𝐰_k[t]s_k[t], ∀t，其中 𝐰_k[t] ∈ ℂ^(N^d×1) 是第 t 个时隙用于 s_k 的数字预编码向量。假设发射符号是归一化且互不相关的，满足 𝔼{|s_k[t]|²} = 1, ∀t, k，以及 𝔼{s_k[t]s_j*[t]} = 0, k ≠ j。因此，第 t 个时隙用户 k 的接收信号表示如下：

y_k[t] = 𝐠_k^H[t]𝐌𝐐[t]𝐰_k[t]s_k[t] + Σ_{j=1,j≠k}^K 𝐠_k^H[t]𝐌𝐐[t]𝐰_j[t]s_j[t] + n_k[t], ∀t, k, (4)

其中 n_k[t] ∼ 𝒞𝒩(0, σ_k²) 是第 t 个时隙用户 k 处均值为零、方差为 σ_k² 的加性高斯白噪声。基于式(4)，第 t 个时隙用户 k 的可达速率表示为 Γ_k[t] = log₂(1 + Π_k[t])，其中 Π_k[t] = |𝐠_k^H[t]𝐌𝐐[t]𝐰_k[t]|² / (Σ_{j=1,j≠k}^K |𝐠_k^H[t]𝐌𝐐[t]𝐰_j[t]|² + σ_k²) 表示第 t 个时隙用户 k 的信干噪比。

第 t 个时隙系统的EE表示如下：

η[t] = Σ_{k=1}^K Γ_k[t] / (P^rad[t] + P^c), (5)

其中 P^rad[t] = Σ_{k=1}^K ∥𝐌𝐐[t]𝐰_k[t]∥² 表示第 t 个时隙DMA单元的总辐射功率，而 P^c 是固定电路功率 [3]。

II-C 问题表述

本文的目标是在时变信道条件下，通过在 T 个时隙上联合优化数字波束成形向量 {𝐰_k[t]} 和DMA权重矩阵 𝐐[t] 来最大化时间平均EE，并受发射功率约束、洛伦兹相位限制和每个用户在每个时隙的最小速率需求的约束。由此产生的优化问题表述如下：

𝒫1: 在 {𝐰_k[t], 𝐐[t]}{t=1}^T 上最大化 (1/T) Σ{t=1}^T η[t] (6a)

s.t. Σ_{k=1}^K ∥𝐌𝐐[t]𝐰_k[t]∥² + P^c ≤ P^max, (6b)

q_{i,ℓ}[t] ∈ 𝒬_{i,ℓ}[t], ∀t, i, ℓ, (6c)

Γ_k[t] ≥ Γ^min, ∀t, k. (6d)

在问题 𝒫1 中，约束(6b)将包括辐射功率和电路功率在内的总功耗限制在最大功率预算 P^max 之内。约束(6c)确保DMA权重满足超材料单元的洛伦兹相位响应，而约束(6d)保证每个用户的可达速率在每个时隙满足其最小需求 Γ^min。

III 提出的解决方案

问题 𝒫1 是一个非凸随机优化问题，这是由于时变信道条件以及数字波束成形和DMA单元权重变量之间的耦合。为了应对这些挑战，我们开发了一个WMBRL框架，该框架从收集的经验中学习潜在系统动力学，并通过想象轨迹联合优化数字波束成形和DMA单元权重，实现长期规划，同时减少大量环境交互的需求。此外，所提出的框架在策略学习期间通过保持可行性的动作映射和安全代价信号处理操作约束。

III-A 观测、动作和奖励表述

为了将WMBRL框架应用于问题 𝒫1，我们使用观测、动作和奖励表示来表征智能体与无线环境之间的交互，定义如下：

III-A1 观测空间

在每个时隙 t 开始时，智能体通过以下观测向量观测无线环境：

𝐨[t] = [ℑ{𝐠_k[t]}, ℜ{𝐠_k[t]}, ∥𝐠_k[t]∥², Π_k[t−1], Γ_k[t−1], P^rad[t−1]], (7)

其中 ∥𝐠_k[t]∥² 表示第 k 个用户的信道功率。观测空间维度为 d^o = 2NK + 3K + 1。

III-A2 动作空间

在每个时隙 t，动作向量定义如下：

𝐚[t] = [ϵ̄[t], {P̄k[t]}{k=1}^K, P̄₀[t]] ∈ [−1, 1]^(d^a), (8)

其中 ϵ̄[t] = [ϵ̄{i,ℓ}[t]]{i=1,ℓ=1}^{N^d,N^e} 控制DMA单元权重，P̄k[t] 控制分配给用户 k 的发射功率，P̄₀[t] 控制总辐射功率，d^a = N + K + 1 是动作空间维度。相应的数字波束成形向量构造为 𝐰_k[t] = √(P_k[t]) · 𝐥_k[t]，其中 P_k[t] 表示分配给用户 k 的发射功率，𝐥_k[t] 表示用户 k 的单位范数正则化迫零波束成形方向，由 𝐥_k[t] = 𝐥̄_k[t] / ∥𝐌𝐐[t]𝐥̄_k[t]∥ 给出，其中 𝐥̄_k[t] 是 𝛀^Ht^(−1) 的第 k 列，𝛀[t] = 𝐆^H[t]𝐌𝐐[t]，𝐆[t] = [𝐠₁[t], …, 𝐠_K[t]]，δ > 0 表示一个小的正则化参数。这种归一化确保 ∥𝐌𝐐[t]𝐥_k[t]∥ = 1，从而得到 P^rad[t] = Σ{k=1}^K P_k[t]。

III-A3 奖励函数

奖励函数旨在最大化时间平均EE，时隙 t 的即时奖励定义为 r[t] = Σ_{k=1}^K Γ_k[t] / (P^rad[t] + P^c)。因此，T 个时隙上的期望折扣累积奖励表示如下：

J^r(π) = 𝔼_π[Σ_{t=1}^T γ^(t−1) r[t]], (9)

其中 γ 表示折扣因子，π 表示策略。最大化该目标通过在传输时域上联合优化数字波束成形和DMA单元权重来促进长期EE的改进。

III-B 约束处理

问题 𝒫1 中的约束根据其特性使用不同的方法处理。具体而言，发射功率和洛伦兹相位约束通过保持可行性的动作映射来强制执行，而最小速率需求则在策略学习期间使用安全代价函数解决。这些机制的详细说明如下。

III-B1 发射功率约束

为了满足发射功率约束，执行者确定总辐射功率及其在用户之间的分配。具体而言，分配给每个用户的功率通过softmax函数获得：P_k[t] = P^a[t] · exp(P̄k[t]) / Σ{j=1}^K exp(P̄j[t])，其中 P^a[t] = P^m · ((P^max − P^c)/P^m)^((P̄₀[t]+1)/2) 表示总分配辐射功率，P^m 是最小辐射功率。这种变换确保 P_k[t] > 0 且 Σ{k=1}^K P_k[t] = P^a[t] ≤ P^max − P^c。因此，式(6b)中的发射功率约束在每个时隙都得到满足。

III-B2 洛伦兹相位约束

对于每个DMA单元，执行者生成一个归一化的相位控制动作 ϵ̄{i,ℓ}[t] ∈ [−1, 1]，该动作被映射到可行相位区间：ϵ{i,ℓ}[t] = π(ϵ̄{i,ℓ}[t] + 1)。此映射保证 0 ≤ ϵ{i,ℓ}[t] ≤ 2π。然后从式(2)中的洛伦兹响应获得相应的DMA单元权重，并根据式(3)排列成DMA权重矩阵 𝐐[t]。

III-B3 最小速率需求约束

为了将最小速率需求纳入策略学习，我们定义了一个安全代价函数，用于量化每个时隙的速率约束违反情况：c[t] = (1/K) Σ_{k=1}^K 𝕀{Γ_k[t] < Γ^min}。期望折扣累积安全代价定义为 J^c(π) = 𝔼_π[Σ_{t=1}^T γ^(t−1) c[t]]。因此，约束策略优化问题表述如下：

𝒫2: 在 π 上最大化 J^r(π)，s.t. J^c(π) ≤ b, (10)

其中 b 表示预定义的安全代价预算。这种表述鼓励智能体最大化时间平均EE，同时减少最小速率约束的违反。为了解决约束策略优化问题 𝒫2，我们开发了一个WMBRL框架，详见以下小节。

III-C 学习方法

所提出的WMBRL框架包含三个关键组件： 世界模型，从观测中学习系统动力学的潜在表示，并预测未来状态、奖励和安全代价； 奖励和代价评论家，评估与所学策略相关的期望长期奖励和安全代价； 安全执行者，优化策略以最大化期望累积奖励，同时满足安全约束。每个组件的详细内容在以下小节中介绍。

III-C1 世界模型学习

世界模型包含一个观测编码器、一个用于学习潜在系统动力学的循环状态空间模型（RSSM），以及用于重建观测和预测奖励与安全代价信号的预测头。观测编码器将观测 𝐨[t] 映射为紧凑的潜在表示，而RSSM通过确定性和随机潜在状态捕捉系统的时间演化。具体而言，确定性状态 𝐡[t] 使用前一个确定性状态 𝐡[t−1]、随机状态 𝐳[t−1] 和动作 𝐚[t−1] 进行更新。然后从当前观测特征和确定性状态推断随机状态 𝐳[t]。RSSM采用转移先验来预测未来潜在状态，从而无需进一步的环境交互即可生成想象轨迹。所学到的潜在状态能够进行观测重建以及奖励和安全代价信号的预测。相应的世界模型组件表示如下：

RSSM：
- 序列模型：𝐡[t] = f_ϕ(𝐡[t−1], 𝐳[t−1], 𝐚[t−1])
- 编码器：𝐳[t] ∼ q_ϕ(𝐳[t] | 𝐡[t], 𝐨[t])
- 转移先验：𝐳̂[t] ∼ p_ϕ(𝐳̂[t] | 𝐡[t])
- 奖励预测器：r̂[t] ∼ p_ϕ(r̂[t] | 𝐡[t], 𝐳[t])
- 代价预测器：ĉ[t] ∼ p_ϕ(ĉ[t] | 𝐡[t], 𝐳[t])
- 解码器：𝐨̂[t] ∼ p_ϕ(𝐨̂[t] | 𝐡[t], 𝐳[t])

其中 ϕ 表示世界模型的可训练参数，𝐳̂[t] 表示预测的潜在状态，r̂[t]、ĉ[t] 和 𝐨̂[t] 分别表示预测的奖励、安全代价信号和重建的观测。此外，函数 q_ϕ(⋅) 和 p_ϕ(⋅) 分别表示后验分布和预测分布，而 f_ϕ(⋅) 表示确定性状态转移函数。世界模型的整体损失函数表述如下 [12]：

ℒ(ϕ) = 𝔼_{q_ϕ}[Σ_{t=1}^T (β^pred ℒ^pred[t] + β^tran ℒ^tran[t] + β^rep ℒ^rep[t])],

其中 ℒ^pred[t] = −log p_ϕ(𝐨̂[t] | 𝐡[t], 𝐳[t]) − log p_ϕ(r̂[t] | 𝐡[t], 𝐳[t]) − log p_ϕ(ĉ[t] | 𝐡[t], 𝐳[t])，

ℒ^tran[t] = max{1, KL[sg(q_ϕ(𝐳[t] | 𝐡[t], 𝐨[t])) ∥ p_ϕ(𝐳[t] | 𝐡[t])]},

ℒ^rep[t] = max{1, KL[q_ϕ(𝐳[t] | 𝐡[t], 𝐨[t]) ∥ sg(p_ϕ(𝐳[t] | 𝐡[t]))]}.

相应的权重系数为 β^pred = 1、β^tran = 0.5 和 β^rep = 0.1，而 KL(⋅∥⋅) 表示两个概率分布之间的Kullback–Leibler（KL）散度，sg(⋅) 是停止梯度算子。预测损失 ℒ^pred 联合优化观测解码器以及奖励和安全代价预测器。转移损失 ℒ^tran 最小化预测先验和后验潜在分布之间的KL散度，而表示损失 ℒ^rep 最小化后验分布和预测先验分布之间的KL散度以训练后验编码器。这些损失函数使世界模型能够学习系统动力学的紧凑潜在表示，并预测未来状态、奖励和安全代价，以支持通过想象轨迹进行策略优化。

III-C2 评论家学习

所提出的框架包含两个评论家网络，使用世界模型预测的想象轨迹来估计所学策略的期望长期EE和安全代价。具体而言，奖励评论家估计期望累积奖励，而代价评论家预测由约束违反引起的期望累积安全代价。两个评论家都使用时序差分 TD(λ) 回报进行训练，该回报将预测的即时奖励或代价与未来回报的估计相结合。因此，奖励 TD(λ) 回报递归定义如下 [13]：

V_λ^r[t] = r̂[t] + γ[(1−λ)v_{ψ^r}(𝐡[t+1], 𝐳[t+1]) + λV_λ^r[t+1]]（当 t < H̃ 时）；v_{ψ^r}(𝐡[H̃], 𝐳[H̃])（当 t = H̃ 时），

其中 v_{ψ^r}(⋅) 表示具有可训练参数 ψ^r 的奖励评论家，H̃ 表示想象视界，λ 是 TD(λ) 参数。类似地，代价 TD(λ) 回报表述如下：

V_λ^c[t] = ĉ[t] + γ[(1−λ)v_{ψ^c}(𝐡[t+1], 𝐳[t+1]) + λV_λ^c[t+1]]（当 t < H̃ 时）；v_{ψ^c}(𝐡[H̃], 𝐳[H̃])（当 t = H̃ 时），

其中 v_{ψ^c}(⋅) 表示由可训练参数 ψ^c 参数化的代价评论家。两个评论家都被训练以使用symlog域中的Dreamer风格双热（two-hot）分类表示来近似它们各自的 TD(λ) 目标。因此，奖励评论家损失表示如下：

ℒ(ψ^r) = 𝔼_t[−twohot(symlog(V_λ^r[t]))^T log p_{ψ^r}[t]], (11)

而代价评论家损失表示如下：

ℒ(ψ^c) = 𝔼_t[−twohot(symlog(V_λ^c[t]))^T log p_{ψ^c}[t]], (12)

其中 symlog(x) = sign(x)log(|x| + 1) [13]。

III-C3 执行者学习

执行者被优化以最大化时间平均EE，同时利用世界模型生成的想象轨迹以及奖励和代价评论家提供的未来回报估计来减少最小速率约束违反。基于这些估计，计算奖励和代价优势以分别评估所选动作对EE和约束满足的影响。奖励和代价优势分别定义为 A^r[t] = (V_λ^r[t] − v_{ψ^r}[t])/S^r 和 A^c[t] = (V_λ^c[t] − v_{ψ^c}[t])/S^c，其中 S^r 和 S^c 分别表示奖励和代价回报归一化尺度。为了平衡EE最大化和最小速率约束满足，组合优势表述为 A[t] = (A^r[t] − λ^c A^c[t])/(1 + λ^c)，其中 λ^c 表示有效拉格朗日乘子，它控制执行者优化期间安全性的相对重要性。有效拉格朗日乘子更新为 λ^c = max{0, λ^L + μ^c(J^c − b)}，其中 μ^c 表示惩罚系数，λ^L ← [λ^L + μ^L(J^c − b)]₀^{λ^max} 是基于观测到的安全代价迭代更新的拉格朗日乘子，μ^L 表示对偶步长，λ^max 指定最大允许乘子。此外，[x]₀^{λ^max} = min{λ^max, max{0, x}} 表示裁剪操作。因此，执行者损失表示为 [13]：

ℒ(𝜽) = −𝔼_t[(sg(A[t]) log π_𝜽(𝐚[t] | 𝐡[t], 𝐳[t]) + ξℋ[π_𝜽(⋅ | 𝐡[t], 𝐳[t])])], (13)

其中 π_𝜽 表示由 𝜽 参数化的随机执行者策略，ℋ[⋅] 表示策略熵，ξ 是熵正则化系数。这种表述鼓励执行者最大化长期EE，同时惩罚最小速率约束违反。

IV 仿真结果

在本节中，我们通过数值仿真评估所提出的WMBRL框架的性能。仿真中使用的系统和学习参数总结在表I中。在图1(a)–1(c)中，最大用户距离设置为 ψ^max = 150 m，而在图1(d)和1(e)中，其在50至200 m之间变化。为了证明所提出框架的有效性，我们将其性能与使用基于拉格朗日的约束处理的DQN基线进行比较。

图1(a)展示了所提出的WMBRL框架和DQN基线的训练奖励（定义为式(6a)中问题 𝒫1 的目标函数）与训练步数的关系。收敛后，所提出的框架比DQN获得更高的训练奖励，证明了其在改善长期性能方面的有效性。图1(b)展示了违反率与训练步数的关系。所提出的框架在大约 2×10³ 步内将违反率降低到规定的安全代价预算以下，并在此后保持接近该预算，而DQN需要大约 1.4×10⁴ 步才能达到该水平，并表现出更大的波动。这些结果表明，所提出的框架比DQN实现了更快的约束满足和更稳定的安全性能。

图1(c)展示了世界模型和评论家损失的收敛行为。世界模型总损失迅速下降并稳定在4.3左右，而观测、奖励和代价预测损失收敛到相对稳定的值。类似地，两个评论家损失在初始训练阶段大幅下降，随后表现出适度波动，表明学习行为稳定。

图1(d)展示了最大用户距离对时间平均EE的影响。随着最大距离从50 m增加到200 m，两种方案的EE由于路径损耗增加和信道增益降低而下降。尽管如此，所提出的WMBRL框架在所有考虑的距离上始终优于DQN，在时间平均EE上实现了约20%的平均改进。这些结果证明了所提出的框架在变化的用户距离下保持卓越EE性能的有效性。

图1(e)展示了最大用户距离对违反率的影响。随着最大用户距离从50 m增加到200 m，由于路径损耗增加和可达速率降低，两种方案都表现出更高的违反率。尽管如此，WMBRL在所有考虑的距离上始终实现更低的违反率，保持在规定的安全预算以下，而DQN在200 m时超过了该阈值。这些结果表明，所提出的框架在所有考虑的用户距离上将违反率保持在规定的安全代价预算以下。

V 结论

在本文中，我们提出了一个WMBRL框架，用于联合优化数字波束成形和DMA单元权重，以在时变信道条件下最大化时间平均EE。该框架利用所学到的潜在动力学和想象轨迹进行样本高效的长期策略优化，同时采用保持可行性的动作映射和安全代价机制来处理操作约束。仿真结果表明，WMBRL在时间平均EE上比DQN实现了约20%的平均改进，同时表现出更快的收敛和更可靠的约束满足。
