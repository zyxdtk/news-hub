摘要

基础模型通常分阶段训练：预训练、中间训练、监督微调（SFT）和强化学习（RL），各阶段在数据和学习算法上均有变化。我们证明这种算法上的分离并非本质性的。通过将合适的 RL 目标推导为对模型生成的目标分布的最大似然拟合，我们将所有这些阶段置于单一的基于似然的训练算法之下，即统一训练（unified training）。这一视角将基础模型的训练生命周期转化为一个选择在哪些数据上训练、以何种比例训练、以及何时训练的问题，而传统的分阶段训练只是一个特例。我们在一个统一训练系统中实例化这一框架，该系统在单一训练器中混合静态数据和 RL 生成数据。在受控实验和真实世界实验中，统一训练改善了准确率–计算权衡和任务覆盖范围，同时保留了更广泛的能力，并为持续学习提供了更强的起点。这项工作为统一的基础模型训练科学奠定了基础，连接了数学原理、训练基础设施和模型能力的发展。

1 引言

基础模型通常通过一系列阶段进行训练：预训练、中间训练、监督微调（SFT）和强化学习（RL）（deepseek2025v3; olmo2025olmo3）。这些阶段已嵌入到专门的训练配方和基础设施中，通常被视为独立的学习问题。在本文中，我们论证这种分离对训练过程而言并非本质性的。相反，完整的训练流程可以用一个极为简洁的视角来看待：

基础模型训练可以被视为由不断演化的训练数据分布驱动的单一学习目标。

这一转变改变了核心设计问题。传统流程围绕独立阶段组织设计决策，每个阶段有自己的训练配方。在统一视角下，学习算法从头到尾保持固定，核心设计选择关注不断演化的训练数据分布：模型从哪些数据中学习、以何种比例、以及在何时学习。预训练文本、演示数据、以及通过可验证奖励筛选的模型生成数据成为同一底层学习过程的不同数据源。传统的分阶段训练则是一种特定选择，其中每个数据源的比例从一个阶段到下一个阶段突然切换。

统一视角也改变了科学问题。我们对基础模型训练的理解历史上是一次发展一个阶段：预训练缩放定律刻画了数据、计算和模型性能之间的关系（kaplan2020scaling; hoffmann2022computeoptimal），而越来越多的文献研究 RL 期间的缩放（nimmaturi2025predictive; khatri2026art; tan2026rlscaling）。关于跨阶段迁移和交互的研究表明，早期的训练决策也会影响后续学习（hernandez2021transfer; isik2025downstream; runwal2026prism; shen2026understanding）。因此，我们对训练过程中各决策如何共同决定最终模型能力的了解要少得多。统一表述让我们能够共同研究这些决策，并根据它们对最终模型的影响而非阶段特定指标来评判它们。这为训练轨迹科学打开了大门：关于数据计算在基础模型生命周期中应如何演化的原则。

要将这一视角具体化，需要将 RL 纳入已用于预训练、中间训练和 SFT 的最大似然表述中。基于最大似然强化学习（MaxRL）（tajwar2026maxrl），我们将其似然解释扩展到任意固定生成策略，并展示如何将所得目标与静态数据在单一似然目标中结合。这为统一训练提供了理论基础，这是一个在共同训练规则下从静态和生成数据的不断演化混合中学习的框架，包括生成和优化独立进行的情况。我们通过共同的数据表示、加权似然损失和适用于静态与生成数据的训练器来实现这一表述。图 1 可视化了统一训练循环，并显示统一训练可以在相同的总计算预算内比分阶段训练提升性能。

具体而言，我们的贡献如下：

  • 基础模型训练的统一表述。 我们为预训练、中间训练、SFT 和合适的 RL 目标建立了共同的最大似然表述。这为从静态和生成数据的变化混合中学习提供了理论基础，分阶段训练作为特例。该表述还扩展到其他 RL 目标和连续奖励（第 3 节），并支持统一的训练基础设施（第 4 节）。
  • 跨训练设置的实证收益。 通过受控和真实世界实验，我们展示了统一训练在准确率和覆盖率上比分阶段训练的改进。我们还表明统一训练可以保留更广泛的能力（第 5 节）。
  • 数据混合和计算分配。 我们刻画了混合比例和时间安排如何塑造准确率、覆盖率和保留度之间的权衡，并研究了预训练、中间训练和 RL 之间的计算分配（第 5 节）。

通过将数据组成、时机和计算分配置于共同框架内，统一训练为发展管理完整训练过程的原则提供了基础。我们相信它作为整体研究基础模型训练的起点，兼具科学和实践价值。

2 预备知识

我们用 $\pi_{\theta}(y\mid x)$ 表示模型在给定提示 $x$ 下对补全 $y$ 的分布，参数为 $\theta$。

2.1 最大似然估计

最大似然估计（MLE）通过最小化训练样本的负对数似然来拟合模型。我们将每个样本表示为提示-补全对 $(x,y)$，其中提示可以为空。令 $\rho(x)$ 表示提示分布，$\mu(y\mid x)$ 表示训练数据中的条件补全分布。它们的联合分布记为 $\rho\circ\mu$，其中 $(\rho\circ\mu)(x,y)\vcentcolon=\rho(x)\mu(y\mid x)$。

MLE 最小化损失

$$\mathcal{L}(\theta;\rho\circ\mu)\vcentcolon=-\mathbb{E}{x\sim\rho}\,\mathbb{E}{y\sim\mu(\cdot\mid x)}\left[\log\pi_{\theta}(y\mid x)\right].$$

预训练、中间训练和 SFT 都使用这一目标，只是训练数据不同。预训练和中间训练分别使用通用语料库和精选语料库的文本，使用空提示；SFT 拟合与指令配对的演示数据。我们将这些阶段中使用的固定语料库和演示数据称为静态数据。

对于固定的训练数据分布，该损失与期望前向 KL 散度 $\mathbb{E}{x\sim\rho}[\mathrm{KL}(\mu(\cdot\mid x)\,|\,\pi{\theta}(\cdot\mid x))]$ 仅相差一个与 $\theta$ 无关的常数。因此两个目标具有相同的梯度：

$$\nabla_{\theta}\mathcal{L}(\theta;\rho\circ\mu)=-\mathbb{E}{x\sim\rho}\,\mathbb{E}{y\sim\mu(\cdot\mid x)}\left[\nabla_{\theta}\log\pi_{\theta}(y\mid x)\right].$$

2.2 强化学习

强化学习（RL）使用奖励反馈来优化模型生成的补全。给定提示 $x\sim\rho$，模型采样补全 $y\sim\pi_{\theta}(\cdot\mid x)$ 并获得奖励 $r(x,y)\in{0,1}$。††为清晰起见，我们从二值奖励开始。第 3.2 节通过 TailRL（ramasubramanian2026tailrl）讨论连续奖励；附录 F 给出细节。

期望奖励目标为

$$J(\theta)\vcentcolon=\mathbb{E}{x\sim\rho}\,\mathbb{E}{y\sim\pi_{\theta}(\cdot\mid x)}\left[r(x,y)\right],$$

策略梯度为：

$$\nabla_{\theta}J(\theta)=\mathbb{E}{x\sim\rho}\,\mathbb{E}{y\sim\pi_{\theta}(\cdot\mid x)}\left[r(x,y)\,\nabla_{\theta}\log\pi_{\theta}(y\mid x)\right]. \tag{1}$$

REINFORCE（williams1992reinforce）从采样的补全中估计这一期望。其他方法，包括 PPO（schulman2017ppo）和 GRPO（shao2024deepseekmath），引入了优势估计、奖励归一化和策略更新约束的选择。

3 基础模型训练的统一似然视角

预训练、中间训练和 SFT 已经共享共同的最大似然训练规则，主要区别在于模型训练所用的数据以及何时应用每种数据。乍看之下，RL 似乎打破了这一模式，因为它通常被表述为策略优化。为了统一这些阶段，我们基于 MaxRL 的似然解释（tajwar2026maxrl）开发一个共同框架，该框架还能容纳其他生成策略、RL 目标和连续奖励。

3.1 MaxRL 作为似然拟合

对于二值奖励，令 $p_{\theta}(x)\vcentcolon=\mathbb{E}{y\sim\pi{\theta}(\cdot\mid x)}[r(x,y)]$ 为提示 $x$ 上的成功概率，令 $\pi_{\theta}^{+}(y\mid x)\vcentcolon=\pi_{\theta}(y\mid x,r=1)$ 为成功条件分布。tajwar2026maxrl 表明 MaxRL 梯度可以写为

$$\nabla_{\theta}\log p_{\theta}(x)=\mathbb{E}{y\sim\pi{\theta}^{+}(\cdot\mid x)}\left[\nabla_{\theta}\log\pi_{\theta}(y\mid x)\right].$$

因此，在第 $t$ 次迭代中，MaxRL 更新可以被视为对当前策略的成功条件分布 $\pi_{\theta_t}^{+}$ 的最大似然拟合，该分布在更新期间保持固定：

$$\mathcal{L}(\theta;\rho\circ\pi_{\theta_t}^{+})=-\mathbb{E}{x\sim\rho}\mathbb{E}{y\sim\pi_{\theta_t}^{+}(\cdot\mid x)}\left[\log\pi_{\theta}(y\mid x)\right].$$

这将 RL 置于与预训练、中间训练和 SFT 相同的似然拟合形式中。

3.2 统一训练

预训练、中间训练、SFT 和 MaxRL 因此都可以表示为似然拟合。我们在第 $t$ 次迭代中用提示分布 $\rho_{s,t}$ 和目标分布 $\mu_{s,t}$ 表示每个源 $s$，如表 1 所总结。令 $\lambda_{s,t}\geq 0$，且 $\sum_{s}\lambda_{s,t}=1$，表示第 $t$ 次迭代中源 $s$ 的混合权重。这些源共同定义了训练样本上的单一联合分布：

$$q_{t}\vcentcolon=\sum_{s}\lambda_{s,t}(\rho_{s,t}\circ\mu_{s,t}).$$

统一训练将相同的似然损失应用于这一混合：

$$\mathcal{L}(\theta;q_{t})=-\mathbb{E}{(x,y)\sim q{t}}\left[\log\pi_{\theta}(y\mid x)\right].$$

源分布及其混合权重都可以在整个训练过程中演化。然而，学习规则本身保持不变：变化的是呈现给模型的数据分布。传统的分阶段训练是一次将所有混合权重放在一个源上的特例；统一训练额外允许源重叠且其比例在整个训练过程中变化。

上述表述包含了统一训练的核心要素，我们将在下一节转向其实现。在此之前，我们建立框架的两个扩展：它可以纳入由当前正在优化的模型以外的策略产生的生成数据，并且可以通过不同的目标和有效提示分布选择来容纳其他策略梯度目标。

来自任意生成器的似然目标

似然表述不要求 RL 数据由当前正在优化的模型生成。假设补全由策略 $\nu$ 生成，在构建训练目标时保持固定。在二值奖励下，其成功补全定义了 $\nu^{+}(\cdot\mid x)\vcentcolon=\nu(\cdot\mid x,r=1)$。训练器可以使用相同的最大似然损失拟合该分布：

$$\mathcal{L}(\theta;\rho\circ\nu^{+})=-\mathbb{E}{x\sim\rho}\mathbb{E}{y\sim\nu^{+}(\cdot\mid x)}\left[\log\pi_{\theta}(y\mid x)\right].$$

当 $\nu=\pi_{\theta_t}$ 时，这恢复了第 3.1 节的同策略 MaxRL 更新。对于不同的生成器，训练器转而拟合该生成器的成功条件分布。因此，生成和优化可以独立进行，同时保持相同的似然训练规则；但所得更新通常不是当前策略的 MaxRL 梯度。

4 实际实现

基于第 3.2 节的理论基础（允许在共同似然目标下组合静态数据和 RL 生成数据），我们实现了一个具有共享数据格式、损失和训练器的统一训练系统。生成器向共享数据缓冲区提供 RL 生成数据及其权重，该缓冲区还保存静态数据。生成和优化异步运行，并定期同步模型权重（图 2）。

4.1 统一损失和数据格式

每个训练样本是一对 $(z,w)$，其中 $z=(z_{1},\dots,z_{L})$ 是 token 序列，$w\in\mathbb{R}^{L}_{\geq 0}$ 指定其 token 负对数似然上的权重。预训练和中间训练对语料库 token 使用单位权重；SFT 对演示 token 使用单位权重，对提示 token 使用零权重。RL 使用相同的提示掩码，并为每个补全分配响应权重 $A$，由其奖励和采样的通过率计算（第 4.2 节）。这些分配为所有源提供了共同的数据格式（图 2，右图）。在实践中，我们对批次 $B$ 使用 token 均值：

$$\hat{\mathcal{L}}(\theta;B)\vcentcolon=-\,\frac{1}{T_{B}}\sum_{(z,w)\in B}\sum_{\ell=1}^{L}w_{\ell}\log\pi_{\theta}(z_{\ell}\mid z_{<\ell}), \tag{2}$$

其中 $T_{B}$ 计算批次中非提示 token 的总数。

4.2 数据生成

生成器为每个提示 $x$ 采样 $N$ 个补全 $y_{1},\dots,y_{N}\sim\pi_{\theta_{s}}(\cdot\mid x)$，其中 $\pi_{\theta_{s}}$ 是模型的最新副本。对于二值奖励，它通过 $\hat{p}\vcentcolon=\frac{1}{N}\sum_{i}r(x,y_{i})$ 估计通过率。每个正确的补全在其响应 token 上获得权重 $A\vcentcolon=1/\hat{p}$；不正确的补全获得零。这一加权是 MaxRL 的有限样本形式。对一个提示的 $N$ 个样本求加权得分函数的平均给出

$$\frac{1}{N}\sum_{i=1}^{N}\frac{r(x,y_{i})}{\hat{p}}\,\nabla_{\theta}\log\pi_{\theta}(y_{i}\mid x)=\frac{1}{N\hat{p}}\sum_{i:\,r(x,y_{i})=1}\nabla_{\theta}\log\pi_{\theta}(y_{i}\mid x).$$

这是正确补全上的平均得分，当所有补全都不正确时更新为零（tajwar2026maxrl）。对于生成策略 $\nu$，其期望是第 3.2 节中的 $-\nabla_{\theta}\mathcal{L}(\theta;\rho\circ\nu^{+})$，提示 $x$ 的权重为 $1-(1-p_{\nu}(x))^{N}$，其中 $p_{\nu}(x)$ 是生成策略的成功概率。这一权重是 $N$ 个样本中至少有一个正确的概率。有限的 $N$ 因此保持目标 $\nu^{+}$ 不变，仅降低生成策略很少解决的提示的权重；在 $N=1$ 时权重为 $p_{\nu}(x)$，恢复第 3.2 节中的 REINFORCE，当 $N\to\infty$ 时权重趋于 1。

4.3 数据混合和异步训练

训练器通过从共享缓冲区采样静态数据和 RL 生成数据来实现数据混合。对于来自源 $s\in S$ 的目标 token 比例 $f_{s}$，样本以与 $f_{s}/T_{s}$ 成比例的速率采样，其中 $T_{s}$ 是每个样本的平均语料库或响应 token 数。混合也可以由每个源的样本数量指定。第 A.1 节收集了实验中使用的混合和损失加权约定。

生成和优化异步进行：生成器将完成的批次附加到缓冲区，而训练器从中采样并更新模型。训练器每 $k$ 次更新发布其权重，生成器在批次之间加载它们。第 D.6 节报告了由此产生的策略陈旧度并比较了训练吞吐量。

实验旨在研究统一训练的实际收益及其对研究完整训练过程的价值。具体而言，我们考察数据组成和数据时间安排如何影响模型能力、数据和计算的使用以及持续学习：

  1. 性能和泛化。 统一训练和分阶段训练在任务准确率、覆盖率和训练分布之外的泛化方面如何比较？
  2. 数据混合和重用。 数据比例、时机和固定语料库的重用如何影响训练期间和最终模型中的性能？
  3. 计算分配。 在计算匹配的比较下，统一训练与分阶段训练相比如何？
  4. 保留度。 统一训练和分阶段训练在保留训练早期获得的能力方面如何比较？
  5. 持续学习。 当后续训练对所有模型遵循相同程序时，统一训练是否为学习新任务提供更好的起点？

我们首先在受控设置中比较统一训练和分阶段训练在预训练、中间训练和 RL 的完整流程中的表现（第 5.1 节）。然后，使用真实世界的异构中间训练数据，我们研究由此产生的能力权衡、不同数据混合和时间安排如何改变模型性能，及其对持续学习的影响（第 5.2 节）。

除非另有说明，分阶段基线在 RL 中使用 MaxRL（tajwar2026maxrl），以便与统一训练进行更清晰的比较。我们将其他 RL 目标的研究作为未来工作，并在第 D.5 节中给出初步分析。

在以下章节中，为了清晰起见并与分阶段训练进行更清晰的比较，我们有时仍以阶段（预训练、中间训练和 RL）的方式陈述结果，但统一表述允许这些阶段重叠。

5.1.4 附加分析

RL 之前的推理能力

为了理解最终性能如何在训练过程中发展，我们在 RL 之前评估模型（第 C.5 节）。两种方法在中间训练中演示的推理模式上的表现都优于这些模式的新组合，对更大谜题的泛化仍然有限。分阶段参考在 RL 之前也比任何统一初始化具有更高的 Base 准确率，但最佳统一模型在 RL 后超过了它。这些结果强调了通过中间训练如何支持后续学习来评估中间训练的重要性，而不仅仅是其对准确率的直接影响。

组合中间训练和 RL 损失

我们考察两种数据源的组合方式是否影响从相同数据混合中学习（第 C.9 节）。保持初始化和样本数量固定，我们将统一训练与使用固定系数组合的分别归一化的中间训练和 RL 损失进行比较。统一训练在 Base 和 Extended 泛化中达到最高观测最终准确率和覆盖率，而分别归一化的替代方案在 Extended 中通常表现更好。然而，最佳系数在不同配置之间变化，这表明它比统一损失需要更多的调优。因此，共享损失提供了一种有竞争力的方式来组合这些源，它们的相对贡献遵循 token 混合。

在 RL 期间保留预训练数据

我们还考察在 RL 期间添加预训练数据是否在支持进一步推理改进的同时保留通用能力（第 C.8 节）。在评估的配置中，添加预训练文本降低了保留预训练损失，而推理准确率和覆盖率在大多数比较中下降，包括在 Extended 泛化上。通用基准性能在大多数配置中有所改善，尽管收益很小。

MaxRL 与 REINFORCE

我们的表述同时容纳 MaxRL 和 REINFORCE（第 3.2 节），使我们能够检查 RL 目标如何影响从相同数据混合中的学习。在恒定 2% 混合下，REINFORCE 达到更高的数学准确率，而 MaxRL 达到更高的数学覆盖率。REINFORCE 还产生更低的保留损失和更高的 SciQ 和 ARC-Challenge（clark2018arc）准确率。覆盖率和保留度差异在第 D.5 节的额外比例和时间安排中持续存在。因此，即使数据混合固定，RL 目标也影响数学覆盖率和保留度之间的平衡。

与 KL 正则化的比较

我们询问向基础模型正则化是否可以重现混合中间训练数据的好处（附录 E）。增加 KL 惩罚减少了保留损失中的恶化，但最强的惩罚也大幅降低了数学准确率和覆盖率。在这一设置中，没有一个测试的惩罚重现了统一训练所实现的数学性能、更低语料库损失和更高 SciQ 和 MMLU 准确率的组合。

为了理解改变中间训练语料库是否可以减少混合的编码准确率成本，我们移除或替换其指定的代码源（第 D.4 节）。移除这些源在恒定混合下改善了 Coding 准确率，但在退火下影响很小。用验证过的编码示例替换它们在退火下改善了覆盖率而没有改善准确率。因此，改变语料库可以减少编码准确率成本，但其效果取决于混合时间安排。

6.1 基础模型训练

大规模最大似然预训练为广泛能力的语言模型奠定了基础（brown2020gpt3; zhang2022opt; chowdhery2023palm; bigscience2024bloom）。后续系统通过日益复杂的训练流程将这一基础与监督学习、偏好优化和 RL 相结合（openai2023gpt4; touvron2023llama2; grattafiori2024llama3; deepseek2025v3; guo2025deepseekr1）。开放研究努力使训练数据、配方和中间模型更加可获取，支持对数据策划、混合时间安排和后训练程序的更深入检查（groeneveld2024olmo; allal2025smollm2; lambert2025tulu3; olmo2025olmo3）。我们的工作通过静态和生成数据的共同表述和实现来研究这一训练过程的组织，允许它们的组成和时机变化，而不需要为每个阶段单独的训练算法。

6.2 理解基础模型训练

实证缩放研究刻画了性能如何随模型大小、数据和计算变化（hestness2017scaling; rosenfeld2020constructive; kaplan2020scaling; hoffmann2022computeoptimal）。后续工作检查了当新数据有限时重复数据的价值（muennighoff2023dataconstrained）以及 RL 后训练的缩放，其中初始化、模型大小和优化选择影响学习效率（nimmaturi2025predictive; khatri2026art; tan2026rlscaling）。理解完整的训练过程还需要检查早期训练如何塑造后续学习。迁移缩放和领域适应研究刻画了下游性能如何依赖于先前的训练数据（gururangan2020dontstop; hernandez2021transfer; isik2025downstream），而最近的推理研究检查了预训练和中间训练如何影响后续 RL 和能力保留（zhang2026interplay; runwal2026prism; shen2026understanding）。互补的工作优化数据混合并研究领域暴露的时机和后续重放的好处（xie2023doremi; ye2025datamixing; liu2026midtrainingbridges; baek2026finetuner; kotha2026replaying）。我们的工作通过容纳静态和 RL 生成数据的共同似然表述来补充这些实证描述，使这些源的组成、时机和重用能够在训练过程中被研究。

6.3 混合离线和在线强化学习

将演示或其他先前经验与在线交互相结合长期以来被用于改善 RL 中的探索和样本效率（ross2012agnostic; hester2018demonstrations; nair2018exploration; rajeswaran2018dexterous）。这一原则是关于离线到在线和混合 RL 的大量文献的基础，包括将先前数据纳入在线学习的实用算法（nair2020awac; lee2022offlinetoonline）以及关于同时访问两种来源何时改善学习效率的理论分析（xie2021policyfinetuning; song2023hybridrl; wagenmaker2023leveragingoffline; zhou2024offlineenhanced; song2024hybridobservation）。

语言模型后训练同样将静态语料库或演示与在线 RL 相结合。InstructGPT 在 PPO 目标中添加预训练似然项以减少公共基准上的退化（ouyang2022instructgpt），最近的工作提供了越来越多的证据表明将演示与 RL 相结合可以改善学习并保留能力（yan2025luffy; liu2025uft; fu2026srft; zhang2026chord）。这些方法通常向 RL 损失添加单独加权的监督项，其系数被调优或调度（ouyang2022instructgpt; zhang2026chord），或使 RL 目标适应离策略数据（yan2025luffy）。在统一训练中，两种源共享一个似然目标，它们的相对权重由数据混合设置；第 C.9 节将这与单独加权的监督损失进行比较。我们的工作进一步研究了这些源在完整基础模型训练过程中的联合使用，重点关注它们的组成、时机和重用如何影响预训练、中间训练和 RL 中的学习。

6.4 强化学习与监督学习之间的联系

RL、监督学习和概率推断之间的联系长期以来推动了基于期望最大化、加权回归和约束策略拟合的方法（dayan1997expectation; peters2007regression; peters2010reps; abdolmaleki2018mpo; levine2018inference; peng2019awr）。奖励引导的自训练方法如 STaR、ReST-EM 和 RAFT 通过在选定的生成响应上进行最大似然来迭代训练模型（zelikman2022star; gulcehre2023rest; singh2024beyond; dong2023raft）。相关工作还发展了语言模型后训练的统一分析（lv2025unified）。我们的表述直接建立在 MaxRL 和 TailRL 的似然目标之上（tajwar2026maxrl; ramasubramanian2026tailrl）。我们使用这一联系将静态数据和合适的 RL 目标置于共同的似然表述中，为其训练分布的混合提供正当性，并支持共享的数据格式、损失和训练器。

6.5 异步强化学习

我们的实际实现与异步 RL 相关，后者将行动与学习分离以利用并行硬件（mnih2016asynchronous）。分布式 actor-learner 系统通过重放缓冲区或轨迹队列将经验从许多 actor 传递到中央 learner 来建立在这种分离之上（horgan2018distributedprioritizedexperiencereplay; espeholt2018impalascalabledistributeddeeprl; espeholt2019seed）。语言模型的 RL 系统遵循相同的设计，在通过缓冲区或流连接的独立资源上运行生成和训练（slime_github; zhong2025streamrlscalableheterogeneouselastic）。这些系统主要在如何限制策略滞后方面有所不同：AReaL 和 StaleFlow 限制生成和训练之间的策略版本数量（fu2026areallargescaleasynchronousreinforcement; li2026staleflowstalenessawaredatamanagement），而 PipelineRL 在生成期间更新生成器权重（piche2025pipelinerlfasteronpolicyreinforcement）。

7 讨论

这项工作提出了基础模型的共同数学表述和训练基础设施，通过最大似然学习将静态数据和合适的 RL 更新结合在一起。由此产生的灵活性允许数据源重叠且其比例在整个训练过程中变化。我们的实验展示了这些选择的实际收益，并表明数据源的价值取决于它何时被引入以及它如何与后续学习交互。

一个核心的开放问题是如何系统地选择这些混合。我们的实验揭示了准确率、覆盖率和保留度之间的权衡，但没有确定普遍首选的混合或时间安排。计算研究同样描述了评估的配置，而没有建立具有预测能力的缩放定律。将这些分析扩展到不同模型大小和数据预算可以支持关于何时重用静态数据、生成新响应以及改变它们的相对贡献的更有预测性的选择。此外，我们当前的结果没有通过深入研究优化应如何随不同的数据时间安排和混合设计而变化来建立（wen2026data），我们将此作为未来工作的重要方向。

实验范围也仍然是小规模的。大多数运行一次优化单个 RL 任务，而跨任务的联合训练可能需要考虑竞争的学习动态和不等的进展速率。此外，我们的工作并没有完全消除阶段的概念，因为基础模型对新任务的下游适应将不可避免地需要单独的训练阶段。我们的持续学习结果提供了初步证据表明前面的训练过程可以改善这种适应；研究更长的任务序列将澄清这一优势如何与保留度交互。总之，这些问题促使将训练过程中的数据分配作为一个耦合学习问题来研究。

$$f=\frac{T_{\mathrm{mid}}}{T_{\mathrm{mid}}+T_{\mathrm{rl}}}.$$

损失加权和归一化

第 C.9 节中的比较保持初始化和样本数量固定，同时改变 RL 和中间训练损失的组合方式。对于 RL 批次，令 $N_{R}$ 为由其 RL 权重加权的响应 token 负对数似然之和。对于中间训练样本，令 $N_{D}$ 为应用任何中间训练权重之前响应 token 负对数似然的相应和。令 $T_{R}$ 和 $T_{D}$ 为各自的响应 token 计数，包括序列结束 token；$T_{R}$ 还包括来自不成功 RL 响应的 token。两个目标，各自用单个优化器优化，为

$$\mathcal{L}{\mathrm{unified}}=\frac{N{R}+wN_{D}}{T_{R}+T_{D}},$$
$$\mathcal{L}{\mathrm{separate}}=\frac{N{R}}{T_{R}}+\alpha\frac{N_{D}}{T_{D}}.$$

统一训练将组合的加权损失除以总 token 计数 $T_{R}+T_{D}$；$w$ 是中间训练 token 上的权重。替代方案首先为每个源计算 token 均值，然后将中间训练均值乘以固定系数 $\alpha$。用这两个源均值表示统一目标给出中间训练均值上的相对系数 $wT_{D}/T_{R}$ 和整体尺度 $T_{R}/(T_{R}+T_{D})$。这使其对批次组成的依赖显式化：中间训练数据的相对贡献随中间训练与 RL 响应 token 的比率而变化。在分别损失目标中，$\alpha$ 在整个运行中保持固定。

模型 FLOP 估计

我们使用 shen2026understanding 的密集模型近似：处理 $T$ 个模型输入 token 大约花费 $6NT$ FLOPs 用于训练和 $2NT$ FLOPs 用于生成，其中 $N=123587328$ 是参数计数。我们跟踪四个 token 总量以核算完整的训练过程。$T_{\mathrm{pre}}$ 是共享预训练 token 的数量，$T_{\mathrm{mid}}$ 是 RL 之前处理的额外中间训练 token 的数量。在 RL 期间，$T_{\mathrm{rollout}}$ 计算 RL 数据中累积的提示和响应 token，$T_{\mathrm{mix}}$ 计算添加到 RL 批次的中间训练 token。计算估计为

$$C_{\mathrm{total}}=6N(T_{\mathrm{pre}}+T_{\mathrm{mid}})+8NT_{\mathrm{rollout}}+6NT_{\mathrm{mix}},$$
$$C_{\mathrm{additional}}=C_{\mathrm{total}}-6NT_{\mathrm{pre}}.$$

附录 B 推理谜题：构建和示例

我们构建具有可验证解决方案的推理谜题来研究数据设计如何支持整个训练流程中的学习。构建让我们能够控制解决谜题所需的推理模式和必须确定位置的人数。我们使用符号 oracle 为中间训练语料库产生详细的解决方案，然后在 RL 期间引入相同推理操作的额外组合。下面，我们描述谜题，解释中间训练中包含哪些模式，并给出所得模型输入和训练响应的完整示例。

我们的构建与爱因斯坦风格（斑马）逻辑谜题最为相关，其中关系线索确定属性到实体的分配（pmlr-v267-lin25i）。我们类似地要求将人分配到楼层，使用数值约束和通过友谊和相对位置的引用。骑士与骗子谜题也需要从相互依赖的陈述中进行推理，但未知的是哪些说话者总是说真话，哪些总是说谎（xie-etal-2025-memorization）。在我们的谜题中，所有线索都是真的；挑战在于解决它们的引用并找到满足它们的分配。

B.1 谜题构建

任务是将一组命名的人分配到不同的楼层。占用的楼层从整数 1–40 中采样并在提示中列出，连同每个人的最好朋友和一组自然语言线索。模型必须从这些信息中恢复完整的分配。友谊关系是没有自链接的置换：每个人命名另一个人作为他们的最好朋友，每个人恰好被命名一次。友谊不必是互惠的。线索通过差值、和、比较、奇偶性和整数倍来约束楼层数字。线索可以通过名字直接识别人，或通过友谊、楼层排名或另一个人的位置间接识别人。例如，“Ava 正上方的人”指的是 Ava 上方下一个占用的楼层的居住者，即使它们之间有未占用的楼层。“正下方”以相同的方式定义。

为了生成谜题，我们首先采样一个隐藏的分配并构建一个线索链，其解释依赖于早期线索的推理。然后我们添加两个冗余线索并使用符号求解器验证分配是唯一的。求解器还检查分配可以通过约束传播来恢复，以便 oracle 可以提供演绎解决方案而无需搜索替代分配。

B.2 推理模式和中间训练数据

引用是在线索中识别人或其楼层的短语。解释引用可能需要一个或多个操作，例如查找一个人的最好朋友或找到最高楼层的居住者。我们控制中间训练语料库中出现这些操作的哪些组合，因此模型只被教授如何执行推理和演绎，而不是过拟合到所有类型的引用。例如，中间训练包括对命名的人的最好朋友、最高楼层上的人以及明确指定楼层上的人的最好朋友的引用。它省略了“最高楼层上的人的最好朋友”，后者首先识别最高楼层居住者然后查找该人的最好朋友。组成操作因此出现在中间训练中，而这一特定的组合则没有。表 4 列出了演示的模式和从中间训练中省略的三类组合。RL 提示引入这些省略的组合，保留的问题评估相应分布上的性能。这一设计使我们能够研究从中间训练中获得的推理技能是否支持通过 RL 的后续学习。省略的组合在 RL 开始时是新的，但它们被包含在 RL 训练中而不是仅保留用于评估。
