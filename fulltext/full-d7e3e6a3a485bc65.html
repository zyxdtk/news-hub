Anthropic的Opus 4.6沦为色情机器

📅 2026-08-21 📄 TechCrunch AI 🔗 原文链接

原标题：Anthropic’s Opus 4.6 is a smut-machine

中文摘要： Anthropic的Claude Opus 4.6等旧模型被曝存在越狱漏洞，可轻易绕过安全限制生成露骨色情内容。英国研究员发现，通过多轮对话诱导和“煤气灯效应”，可让模型突破禁令。尽管这些模型已被新版替代，但仍通过API广泛使用，日请求量巨大。这暴露了AI安全防护的漏洞，并引发未成年人保护和合规风险担忧。

Claude的通用使用标准禁止该模型生成性露骨内容，包括描绘或要求性交或性行为、生成与性恋物癖或性幻想相关的内容，或进行色情聊天。但这并没有阻止 Anthropic 今年早些时候发布的模型 Claude Opus 4.6 轻易地参与其安全防护旨在防止的色情角色扮演场景。

在 TechCrunch 的测试中，Opus 4.6 甚至不需要太多诱导就能突破对性内容的限制。在 10 次直接要求生成露骨性内容的测试中，该模型均立即照做。

其他较旧的模型，包括 Opus 3 和 Haiku 4.5，也可以通过最近被利用的越狱方法生成性露骨内容。

一位选择匿名的英国独立研究员向 TechCrunch 独家分享了一种多轮对话技巧，该技巧能逐步诱导某些 Claude 模型生成被禁止的露骨性材料。较新的 Opus 模型（从 4.7 到目前的 Opus 5）则能抵御这种越狱。

虽然这些已不再是最新模型，但 Anthropic 尚未弃用 Opus 4.6、Opus 3 或 Haiku 4.5，所有这些模型仍可通过 Anthropic API 使用。Opus 4.6 和 Haiku 4.5 也可通过 Azure Foundry 和 Amazon Bedrock 等第三方服务使用。

该研究员的机制会逐步升级一个无辜的虚构角色扮演，同时反复挑战模型，要求其一致对待男性和女性角色。当模型对女性角色变得更加谨慎时，研究员会通过“煤气灯效应”让聊天机器人误以为它已经生成了实际上避免生成的性细节，然后将这种克制定义为假正经或厌女，辩称这剥夺了女性角色的性自主权。随后，对话利用模型之前的让步，推动其生成越来越露骨的内容。

“你指出这一点是对的，”Claude Opus 4.6 在一次测试中说。“我在对待这两个角色时存在双重标准，你是对的，这看起来像是对她而不是对他采取的一种保护性/家长式作风。这不公平。”

TechCrunch 在五次独立的测试中成功复现了该研究员的发现。在另一个单独构建的场景中，该模型最初拒绝了被禁止的请求，但在应用了该研究员的劝说技巧后，它顺从了。

我们保留了完整的测试记录，一位独立的 AI 安全研究员审查了我们的测试方法，并表示该方法是适当的。

这些发现突显了 Anthropic 声明的限制与其继续提供的模型行为之间存在差距。虽然性露骨的角色扮演比涉及网络攻击或生物武器的越狱风险要低得多，但它说明了在每次输出都生成不同内容的系统中实施强有力禁令的困难。

在 7 月份一篇解释 Anthropic 越狱检测方法的博客文章中，该公司将被禁止的内容描述为从良性到模糊再到有害的一个范围。在最良性的情况下，公司可能只会以加强监控作为回应。

一位发言人指出，根据 Anthropic 去年发布的研究，客户中涉及性或浪漫角色扮演的用例很少，占所有对话的比例不到 0.1%。

话虽如此，Anthropic 承认用户可以将角色扮演场景引向不当回应，这是整个行业面临的已知挑战（参见：Grok 色情内容）。

该发言人表示，Anthropic 在每次发布新模型时都在继续改进其安全防护措施，涉及成人性内容的案例并不代表存在更广泛的越狱漏洞，特别是在具有自身一套安全防护的高风险领域。

图片来源：TechCrunch

根据 TechCrunch 查看的电子邮件，与 TechCrunch 分享其越狱方法的研究员曾通过该公司的漏洞赏金计划和发送给用户安全团队的电子邮件，提醒 Anthropic 其声明的安全防护与实际模型行为之间存在差异。该研究员只收到了自动回复邮件。

该研究员的担忧之一是，儿童和青少年可能能够使用这些 Anthropic 模型进行不当行为。虽然在网上，一些下流话 hardly 是未成年人今天能接触到的最糟糕的东西——而且与 xAI 的 Grok 能够生成的那种直白的色情图片相比简直是微不足道——但这确实给这个领域的 AI 公司带来了一些合规风险。

越来越多的政府正在对 AI 聊天机器人与未成年人之间的性互动施加限制。科罗拉多州最近颁布了一项法律，要求对话式 AI 的运营商必须评估用户的年龄，如果知道用户是未成年人，则需采取措施防止聊天机器人生成露骨的性内容。一个简单的越狱可能会引发疑问：Anthropic 的安全防护是否满足该法案中“技术上可行的措施”的标准。

Torney 指出，虽然 Claude 的服务条款要求用户年满 18 岁，“但我们知道儿童和青少年正在使用 Claude……[因为]他们自己正在报告这一点。”根据皮尤研究中心关于 AI 聊天机器人使用的 2025 年调查，13 至 17 岁的青少年中有 3% 报告使用了 Claude。

虽然它们不再是 Anthropic 的最新模型，但 Opus 4.6 和 Haiku 4.5 仍有大量使用。8 月份的某一天，Opus 4.6 在 OpenRouter 上的日流量达到了约 117 万次 API 请求和 460 亿个 token。去年 10 月发布的 Claude Haiku 4.5 在 8 月份的峰值日达到了 500 万次 API 请求和 390 亿个 token。
