摘要

鲁棒的3D点云识别对机器人技术、测绘和城市感知至关重要，然而点云分类器在传感器变化、环境变化和采集伪影引起的域偏移下经常出现性能下降。许多现有自适应方法在实践中难以部署，因为它们需要访问源数据或源模型的内部参数，而这些可能受到隐私、许可或安全限制。我们提出 3D-BBDA，一个无反向传播的黑盒域自适应框架，仅使用黑盒输出即可将源训练的预测器适应到无标签目标数据。我们的方法执行伪标签引导的基于原型的对齐，并采用加权预测模块将源logits与对齐logits融合，降低对噪声伪标签的敏感性。为了在伪标签覆盖不完整时稳定原型记忆，我们从无标签目标预测中构建高斯扰动原型先验，并在对齐期间将其用作缺失或不可靠类原型的后备。在四个受损3D基准上的实验展示了对强基线的一致改进。在ModelNet-40C上，3D-BBDA实现了32.08%（PointNet）和29.62%（GDANet）的平均误差，优于Source-only（35.88%/34.03%）和BFTT3D（33.78%/32.36%）。3D-BBDA仅需单次前向传播且无梯度更新，使其适合可迁移3D识别流程中的实时、隐私保护部署。项目页面：https://visdomlab.github.io/3D_BBDA

1 引言

鲁棒的3D感知是自主系统的基础，包括移动机器人、自动驾驶车辆、无人机平台和城市测绘解决方案。这些系统严重依赖从LiDAR、深度相机和其他3D传感器获取的点云数据，用于非结构化环境中的物体识别、导航和交互。在实际部署中，感知模型经常在变化的环境条件、传感器变化和采集伪影下运行，这些会引起域偏移，导致显著的性能下降[19, 21]。在这种分布偏移下确保鲁棒性对于AI驱动机器人系统的安全可靠部署至关重要。

虽然无监督域自适应（UDA）试图将知识从有标签源域迁移到无标签目标域[7, 23]，但大多数UDA方法在自适应过程中需要访问源数据或源模型参数[15]。在实际机器人部署中，这一假设通常不现实。感知模型可能是专有的、经认证的或在训练后冻结的，而源数据集可能因隐私、存储或许可限制而无法访问[20]。此外，由于计算和安全考虑，在线基于梯度的微调在边缘机器人平台上经常不可行。这些限制激发了依赖推理时观测的黑盒和无源自适应策略。

黑盒域自适应（BBDA）通过将源模型视为不可变预测器并仅通过其输出进行自适应来解决这一设置[16, 15, 11]。然而，现有BBDA研究主要集中在2D视觉任务上。将BBDA扩展到3D点云并非易事，因为点云具有无序结构、不规则空间分布和变化的密度模式。此外，现有方法通常依赖反向传播或源统计信息进行对齐，限制了其在严格受限部署场景中的适用性。这些凸显了一个关键的研究空白，需要针对黑盒约束下3D点云独特特性的新方法。

此外，这些方法通常强制使用与源模型相同的网络架构，这限制了自适应期间为目标模型采用不同架构的灵活性[15, 33]。这一限制阻碍了将目标网络定制到特定任务或计算约束的能力。

自训练生成目标的伪标签并通过重新训练适应网络，然而，使用伪标签学习会导致误差累积，降低模型性能。为处理该问题，一些现有工作利用无反向传播方法在推理时获得自适应预测[27, 36]。然而，使用源数据进行对齐使其不可行。

3D点云数据的BBDA设置在域自适应研究中很大程度上仍未被探索，如图1所示。

我们在无源、黑盒和无反向传播部署的联合约束下研究3D点云自适应：源训练数据和源模型内部不可用，冻结的源模型仅通过其预测访问，且测试时不执行基于梯度的参数更新。与依赖访问源数据和相应模型的传统域自适应方法不同，黑盒范式将访问限制为仅预训练的源模型，该模型被视为不可变的黑盒（表1）。

在这项工作中，我们解决了一个更严格且具有实际动机的设置。我们提出了一种新颖的面向3D点云数据的无反向传播黑盒域自适应框架（3D-BBDA），该框架在不访问源数据或源模型内部的情况下执行自适应，且测试时不更新任何参数。通过避免参数更新，模型消除了可能随时间降低性能的误差累积风险。源模型纯粹被视为黑盒预测器。目标是减少源域和目标域之间的域差距。

利用基于原型的对齐模块来对齐源域和目标域的特征空间。使用非参数网络从目标样本中提取特征。对于每种损坏，使用非参数网络从目标样本中提取特征，并基于从预训练源模型获得的伪标签为其分配标签，假设伪标签为真实标签。基于这些伪标签，通过取对应于每个标签的平均特征生成每个类的原型。进一步，这些类级原型用于对齐样本。为避免丢失源域信息，使用加权预测模块通过整合源模型和非参数网络获得最终预测。

为确保在稀疏或不完整伪标签分配下的稳定性，我们进一步构建高斯扰动原型先验，在目标伪标签覆盖缺失或不可靠时提供后备类原型。最后，加权预测模块将源预测与基于对齐的预测融合，平衡源泛化与目标特定校正，同时避免误差累积。由此产生的框架不需要源数据、不需要源模型参数访问、也不需要梯度更新，使其适合隐私保护和部署受限的3D识别。

主要贡献总结如下：

  • 我们在机器人部署场景驱动的严格无源和无参数约束下，制定并解决了面向3D点云识别的无反向传播黑盒域自适应问题。
  • 我们提出了一种伪标签引导的基于原型的对齐模块，在不访问源数据或源模型内部的情况下适应目标特征。
  • 我们引入了高斯扰动原型先验，在严重目标偏移下伪标签覆盖不完整时稳定原型记忆。
  • 我们在多个受损3D基准上进行了广泛实验，展示了一致的鲁棒性提升且推理开销可忽略不计。

2 相关工作

深度架构如PointNet[18]和GDANet[30]，以及最近基于Transformer的模型（DAPoinTr[14]和P3Former[29]），实现了强大的域内性能，但在分布偏移下（例如传感器噪声、遮挡、密度变化、损坏）可能很脆弱，这促使人们为鲁棒部署进行自适应。

无监督域自适应（UDA）对齐有标签源域和无标签目标域，利用几何先验和自训练，例如SRDAN[35]、基于图的自蒸馏[2]和FAST3D[6]。然而，UDA通常需要源数据且经常需要访问模型内部，这在隐私、许可限制或数据可移植性限制下可能不可行。无源域自适应（SFDA）放宽了源数据要求，但通常仍依赖访问源模型组件和伪标签，这可能存在确认偏差和误差累积问题。

BBDA通过仅允许来自源模型的黑盒预测并禁止源数据来进一步限制该设置。先前的BBDA/SFDA方法研究了具有不确定性感知过滤的增强和自学习[11, 8]，以及教师/原型机制以减轻噪声标签和遗忘[5, 9, 12]。测试时自适应（TTA）使用无标签测试数据适应模型；在3D领域，最近的工作探索了重建/增强和基于原型的策略[25, 24, 10, 37]。与我们的部署约束最接近的是BFTT3D[27]，它通过用于特征对齐的原型记忆执行无反向传播的3D测试时自适应，但它使用源数据构建原型记忆，这与严格的无源和隐私受限部署相冲突。

相比之下，我们解决了一个更严格且具有实际动机的机制：面向3D点云的无反向传播黑盒自适应，既不需要源数据也不需要源模型内部（或梯度更新），同时在受损目标条件下提高鲁棒性，以及架构无关的自适应策略。与使用源信息构建自适应记忆的BFTT3D不同，3D-BBDA用伪标签引导的目标原型替换源导出的原型，使用无标签目标先验完成缺失类，并将结果预测与黑盒源输出融合。

3 方法论

3.1 问题陈述

我们在3D点云数据的分类任务中解决黑盒域自适应问题，使用源训练模型作为预训练黑盒预测器（F_S），即只有预测输出可访问，其在域D_s下的有标签源域数据 {x_i^s, y_i^s}{i=1}^{n_s} 上训练，其中n_s表示源样本数（图2）。对于自适应，我们有域D_t下的无标签目标域数据 {x_i^t}{i=1}^{n_t}，其中n_t表示目标样本数。这里，我们遵循[27]的约定使用非参数网络（F_nn）。所提出的3D-BBDA框架的目标是在测试时将源模型（F_S）适应到目标域，并在没有源数据或内部参数的情况下，使用预训练源模型、非参数网络（F_nn）和无标签目标数据 {x_i^t}{i=1}^{n_t} 推断目标标签 {y_i^t}{i=1}^{n_t}，确保在未见条件下的鲁棒感知。算法总结见补充材料。

图2：3D-BBDA概述，其中来自非参数网络的目标特征通过原型生成和共享子空间对齐进行对齐。高斯扰动原型先验完成缺失的类原型，最终预测通过加权预测融合源输出和对齐输出。

闭集假设。 我们考虑闭集自适应设置，其中源域和目标域共享相同的标签空间 𝒴_s = 𝒴_t = {1, …, C}。虽然目标标签在自适应期间不可用，但假设每个目标样本属于C个源类之一。这一假设使得能够从黑盒伪标签构建类级原型，并随后与源模型预测融合。

3.2 从非参数网络提取特征

为清晰起见，x_i^t 表示𝒟_t中的第i个目标点云样本，而以下特征提取方程中的 x_{t,i} 表示对应目标点云中的单个3D点。

利用非参数网络PointNN[34]从目标域提取鲁棒特征。三角函数首先将其x、y和z坐标编码为大小为d的通道嵌入。对于每个通道 s∈{x,y,z}，通道嵌入为：

g(x_{t,i})^{(s)} = { sin(αx_{t,i}^{(s)}/β^{i/d})，i=2k；cos(αx_{t,i}^{(s)}/β^{i/d})，i=2k+1 } ∈ ℝ^{d/3} (1)

这里，α和β表示波长和尺度超参数。来自x、y、z坐标的这些通道级嵌入被连接以获得原始嵌入 f_{raw,t,i}：

f_{raw,t,i} = [g(x_{t,i})^{(X)}, g(x_{t,i})^{(Y)}, g(x_{t,i})^{(Z)}] ∈ ℝ^d (2)

此外，采用最远点采样（FPS）从数据集中的所有点下采样局部中心点 x_cen。随后，使用k近邻（k-NN）为每个中心点 x_cen 分组 N_ct 个相邻点（x_nb）。使用中心和相邻信息的组合，x_cen 的扩展中心特征 f̃_cen 为：

f̃cen = Concat(f_cen, f{nb,j})，j∈N_cen (3)

这里，f_cen 是点 x_cen 的特征，f_nb 表示点 x_nb 的特征，𝒩_cen 指中心点 x_cen 的相邻点集合。为展示相邻点 x_nb 的空间分布，特征 f̃_cen 进一步通过其相对于中心点的相对位置编码 g(Δ_nb) 重新加权：

f̃_cen^w = (f̃_cen + g(Δ_nb)) ⊙ g(Δ_nb) (4)

其中⊙表示逐元素乘法，Δ_nb 是 x_nb 相对于其中心点 x_cen 的相对位置。最后，使用最大池化和平均池化降低 f̃_cen^w 信息的维度：

f̃_cen^p = MaxPool(f̃_cen^w) + AvgPool(f̃_cen^w) (5)

最后，应用全局池化操作获得 x_{t,i} 的特征 f_{t,i}∈ℝ^d。提取的特征用作我们自适应框架后续阶段原型生成的基础。

3.3 基于原型的对齐模块

对于每个输入点云 x_{t,i}，通过F_S获得对应的伪标签 ŷ_i^t。同时，通过非参数网络提取目标特征。提取的特征被分配对应的伪标签。

目标缓冲区协议。 24的小批量大小仅用于数据加载和特征提取，并不定义原型构建集。目标特征及其黑盒伪标签在无标签目标缓冲区上累积，然后从该累积缓冲区构建类原型。在128样本的目标块上执行共享子空间对齐时，结果原型记忆保持固定，每个对齐块重新计算W。

对应于每个类i的特征原型通过取分配给该类的所有样本的平均特征生成：

P_i = (1/n_i) ∑_{j=1}^{n_i} f_j (6)

其中 n_i 是分配给类i的样本数，f_j 表示分配给类i的第j个样本的特征。

3.3.1 高斯扰动原型先验

在严重域偏移下，伪标签可能产生不完整的类覆盖，其中某些类没有分配的目标样本。在这种情况下，公式6中对应的原型无法计算，这可能破坏后续对齐步骤的稳定性。为维护类完整的原型记忆，我们从无标签目标预测中构建高斯扰动原型先验，并在对齐期间使用它完成缺失的类原型。具体来说，无标签的高斯扰动目标流通过黑盒源预测器F_S和冻结的非参数编码器F_nn传递。结果伪标签和特征用于计算类对齐的原型先验 {P_i^g}_{i=1}^C。对于类i，令 𝒮_i^g 表示分配给类i的高斯扰动目标样本集合，令 n_i^g = |𝒮_i^g|。如果某个类在高斯扰动流中也缺失，我们使用可用高斯扰动原型的全局均值作为保守后备：

P_i^g = { (1/n_i^g)∑{k∈𝒮_i^g} f{t,k}^g，若 n_i^g > 0；(1/|𝒞_g^+|)∑_{j∈𝒞_g^+} P_j^g，若 n_i^g = 0 } (7)

其中 𝒞_g^+ = {j | n_j^g > 0} 是具有可用高斯扰动原型的类集合。该先验从无标签目标预测计算，不需要源样本、目标标签、源模型参数或梯度更新。

原型补全。 对于目标流d，伪标签可能使某些类没有分配的样本。令 𝒮_i^{(d)} 表示流d中分配给类i的目标样本集合，令 n_i^{(d)} = |𝒮_i^{(d)}|。类i的补全原型计算为

P̃i^{(d)} = { (1/n_i^{(d)})∑{k∈𝒮_i^{(d)}} f_{t,k}^{(d)}，若 n_i^{(d)} > 0；P_i^g，若 n_i^{(d)} = 0 } (8)

补全的原型记忆 {P̃i^{(d)}}{i=1}^C 然后用于共享子空间对齐。这一补全步骤为缺失的伪标签类提供后备类原型，同时保持3D-BBDA的无反向传播、黑盒和无源约束。

3.3.2 通过共享子空间投影和对齐减少域偏移

当目标特征偏离学习原型的分布时发生域偏移，使直接对齐不充分。它首先计算来自目标域和原型记忆的余弦相似度归一化特征向量以引导分类[27]。考虑目标特征向量 G_t = [g_{t,1}, g_{t,2}, …, g_{t,n_t}] 和原型记忆 P = [P_1, P_2, …, P_c]。余弦相似度为：

K = (G̃_t · P̃) / (‖G̃_t‖‖P̃‖) (9)

这里，向量 G̃_t 表示G_t的归一化特征向量，表示为 G̃_t = G_t/‖G_t‖，其中‖G_t‖表示G_t的幅度。类似地，P̃表示归一化的原型记忆向量，由 P̃ = P/‖P‖ 给出，其中‖P‖表示P的幅度。该相似度通过为每个原型的影响分配权重来引导分类。带伪标签 y_i 的输出logits为：

l_am = φ(K_{y_i})，φ(x) = exp(−β(1−x)) (10)

其中β为缩放超参数。

为显式减少原型（f*）和目标特征（f_t*）之间的分布差距，两者都使用映射函数ψ(.)投影到共享子空间。通过计算它们均值表示之间的统计距离来减少这些域之间的差异：

Dist(P, G_t) = ‖(1/n_p)∑_{i=1}^{n_p} f_i^ − (1/n_t)∑_{i=1}^{n_t} f_t^‖_2^2 (11)

其中 n_p 和 n_t 分别表示原型特征数和目标特征数。

现在，我们引入核相似度矩阵K和缩放矩阵L，它们编码原型和测试数据点之间的相似性，K_{i,j} = ⟨ψ(x_i), ψ(x_j)⟩。L_{i,j} 的值定义为：

L_{i,j} = { 1/n_t^2，若 x_i, x_j∈G_t；1/n_p^2，若 x_i, x_j∈P；−1/(n_p n_t)，其他 } (12)

其中 x_i 和 x_j 是被比较的点。该方程根据两个点是否都属于目标域（G_t）、原型或来自不同域来为 L_{i,j} 赋值。为进一步优化对齐，通过最小化迹正则化目标来优化变换矩阵W：

min_W tr(W^T K L K W) + μ tr(W^T W) (13)

其中μ控制 W∈ℝ^{(n_p+n_t)×m} 的复杂度，中心矩阵为 H = I − (1/(n_p+n_t))11^T ∈ ℝ^{(n_p+n_t)×(n_p+n_t)}。W的最优解从 (KLK + μI)^{-1}KHK 的m个最大特征向量获得。结果变换通过 𝐖^T𝐊∈ℝ^{m×(n_p+n_t)} 将公式11中目标导出的原型和目标特征投影到共享潜在子空间，从而减少域差异。通过对齐全局统计和局部相似性，模型提高了域偏移下的鲁棒性。

3.4 加权预测模块

为使我们的框架对有限数量的目标样本具有鲁棒性，仅使用来自对齐模块的预测可能效果不佳，因为它只处理目标特征。而且我们不想丢失源模型的信息，因为当目标样本在分布上接近源域时它会很有帮助。此外，仅使用源模型的输出可能效果不佳，因为源和目标分布之间的域差距引起的内部协变量偏移。

因此，为整合来自源模型和对齐模块的预测，我们采用加权预测模块：

l_final = λ·l_s + (1−λ)·l_am (14)

这里，l_s 是从预训练源模型获得的logits，l_am 是从对齐模块获得的logits，l_final 是用于预测的最终logit，λ是分配给源模型预测的权重。

我们使用预定义的λ，因为我们希望有意地为源模型的预测分配较少的权重，以减少噪声标签对最终预测的影响。我们将λ视为控制源预测贡献的固定超参数。最初报告的基准特定值是通过类似于表6的一次性离线验证扫描选择的，随后在每个基准内的所有样本和损坏类型中保持固定。该验证仅使用标签进行离线超参数选择，不是自适应流程的一部分；在伪标签生成、原型构建、对齐或推理期间不访问任何目标标签。

为评估3D-BBDA是否依赖于基准特定的选择，我们额外固定单个全局λ=0.1并将其不变地跨数据集迁移。该设置仍然在ModelNet40-C、ScanObjectNN-C和ShapeNet-C上分别比Source-only提升+3.67、+1.06和+2.76个百分点（表7）。表11显示该策略使我们的框架对噪声预测不太敏感。

7 结论

我们提出了3D-BBDA，一个面向3D点云分类的无反向传播黑盒域自适应框架，既不需要源数据也不需要源模型内部。该方法将伪标签引导的原型对齐与高斯扰动原型先验补全策略相结合以稳定稀疏伪标签下的自适应，以及加权预测模块以平衡源先验与目标特定校正。在多个受损3D基准上的实验展示了一致的鲁棒性提升且开销最小，实现实时和隐私保护部署。我们通过标准损坏基准和推理开销测量验证了鲁棒性和实时可行性。

1 与BFTT3D的详细比较

BFTT3D是与3D-BBDA最接近的先前方法，因为两者都避免测试时反向传播并采用非参数目标表示以及基于原型的共享子空间对齐。因此，主要的方法论区别不是引入全新的子空间对齐目标，而是在更严格的无源、仅logits黑盒接口下重新表述该流程。表4总结了组件级关系。表4中的区别也阐明了流程中哪些部分是保留的而非新推导的。3D-BBDA并不声称共享子空间对齐目标本身是新贡献。相反，该方法改变了该对齐可用的信息：移除源导出记忆并替换为伪标签引导的目标原型，从无标签高斯扰动目标先验完成缺失类，并将结果对齐预测与黑盒源预测融合。这些变化使对齐框架能够在联合无源、黑盒和无反向传播约束下运行。

4.2 受控2D→3D DINE[15]端口

DINE最初为来自黑盒2D预测器的域自适应提出。为评估2D BBDA目标的直接迁移是否足以应对3D损坏设置，我们构建DINE-3D‡作为受控特征空间端口。为可比性，DINE-3D使用与3D-BBDA相同的冻结PointNN目标表示。我们保留DINE的主要优化组件，包括源概率蒸馏、基于EMA的预测记忆、信息最大化目标、MixUp和目标侧微调。因此，与3D-BBDA不同，DINE-3D需要通过目标侧自适应模型的反向传播。

如表6所示，直接DINE端口不能有利地迁移到这些3D损坏基准。例如，在ModelNet40-C/PointNet上其平均误差为46.53%，而Source-only为35.88%，3D-BBDA为32.08%。在其余数据集/骨干组合中观察到类似退化。我们强调，该实验不应被解释为表明原始DINE方法本质上不适合3D数据。DINE-3D‡是一个受控特征空间端口，旨在回答审稿人提出的更窄问题：将已建立的2D黑盒自适应目标直接迁移到相同的3D目标表示是否足够。在此受控迁移下，答案是否定的。

4.3 与LN-TTA[31]的比较

LN-TTA是最近为基于Transformer的点云架构设计的无反向传播测试时自适应方法。其自适应机制依赖LayerNorm相关表示和Transformer特定token（包括CLS token）。相比之下，我们主实验中使用的PointNet和GDANet骨干是基于BatchNorm的架构，不提供这些Transformer特定表示。因此，LN-TTA不能在我们的PointNet/GDANet评估协议下不变地应用。数值比较需要用Transformer替换源骨干，或修改LN-TTA以在其原始自适应机制未定义的表示上操作。这样的比较会将自适应方法与骨干变化混淆，或构成非等效的重新实现。因此我们不将LN-TTA包含在主要定量表中，而是明确报告这一架构不兼容性。这一区别也突出了部署假设的差异：LN-TTA需要访问特定的内部LayerNorm/token表示，而3D-BBDA将冻结的源模型视为黑盒，仅访问其最终预测输出。
