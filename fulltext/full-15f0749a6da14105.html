Meta 发布首个前沿模型 Muse Wonder

📅 2026-10-12 📄 TechCrunch AI 🔗 原文链接

原标题：Meta releases its first frontier model, Muse Wonder

中文摘要： Meta 周一发布两款最先进模型 Muse Wonder 和 Muse Wonder Full，首次进军前沿模型领域。两款模型基准得分与 Fable 5.1 和 GPT-6 Astra 相当，定价为每百万输入 token 4 美元、输出 20 美元。Wonder Full 仅面向 Muse Code 订阅用户。新模型重点强化"主动记忆"能力，在 MemoryBench 测试中超越 Fable、Opus 和 Astra。这是去年 8 月 Alexandr Wang 重组 Meta AI 业务以来首

Meta 于周一发布了两款全新的最先进模型——Muse Wonder 和 Muse Wonder Full，这是该公司首次尝试打造前沿模型。

Muse Spark 的定位是能够以低延迟运行的轻量级模型，而 Wonder 系列模型规模更大，据称能力更强，基准测试得分更高，在编程等复杂任务上的表现也更出色。

根据 Meta 的测试（详见模型卡），Wonder 和 Wonder Full 的基准测试得分与 Fable 5.1 和 GPT-6 Astra 相当。

Meta 在介绍这些模型的博客文章中写道："它们共同标志着我们扩展阶梯上的下一步，也是迈向个人超级智能的重大飞跃。"

这种规模也体现在定价上：通过 Meta Model API 访问，Wonder 的价格为每百万输入 token 4 美元、每百万输出 token 20 美元，成本大致与 GPT-6 Sol 或 Opus 5.5 相当。

值得注意的是，Wonder Full 将仅向 Muse Code 订阅用户提供，不会通过 API 提供服务。这两款模型还将用于驱动 Muse 智能体。

与 Meta 致力于开发能够长期执行任务的个人助理的方向一致，该公司特别强调了新模型保留和综合用户提供信息的能力，Meta 将这一特性称为"主动记忆"（active memory）。

为了实现更好的记忆召回能力，Meta 重点介绍了 MemoryBench 基准测试，该测试专门考验持续学习和记忆构建框架。根据该公司的测试，Muse Wonder 目前在 MemoryBench 上的得分已超过 Fable、Opus 和 Astra。

研究科学家 Kavya Kopparapu 在随发布一同推出的视频中表示："我们投入了大量精力，确保你的模型能够在数天、数周、数月乃至更长的时间里记住对你重要的事情。"

这两款新模型是自去年 8 月 Scale AI 创始人 Alexandr Wang 重组 Meta 的 AI 业务以来，该公司首次发布的前沿模型。此后，Meta 发布了轻量级 Muse Spark 模型和 Muse 智能体，但一直避免 OpenAI 和 Anthropic 所擅长的那种最先进模型的发布。

据文章介绍，这些模型是在 Meta 位于俄亥俄州中部的 Prometheus 数据中心训练的，该数据中心于今年早些时候投入使用。
