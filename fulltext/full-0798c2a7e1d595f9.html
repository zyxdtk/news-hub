为防御者提供前沿网络安全能力

📅 Feb 20, 20 📄 Anthropic 🔗 原文链接

**Claude Code 安全功能**（Claude Code Security）——一项内置在网页版 Claude Code 中的新能力——现已以有限研究预览形式上线。该功能可扫描代码库以识别安全漏洞，并提出有针对性的软件补丁建议，供人工审核，从而帮助团队发现并修复传统方法常遗漏的安全问题。

安全团队普遍面临一个难题：软件漏洞数量过多，而能够处理这些漏洞的人手却严重不足。尽管现有分析工具在一定程度上有所帮助，但其能力有限，通常仅能识别已知模式的漏洞。发现那些细微、依赖上下文、常被攻击者利用的漏洞，需要经验丰富的专业研究人员，而他们正疲于应对日益膨胀的工作积压。

人工智能（AI）正开始改变这一局面。我们近期已证明，[Claude 可检测新型高危漏洞](https://red.anthropic.com/2026/zero-days/)。然而，赋予防御者发现与修复漏洞的能力，同样也可能被攻击者用于实施攻击。

Claude Code 安全功能旨在将这一能力牢牢交到防御者手中，以保护代码免受这一新型 AI 赋能攻击的威胁。我们此次以有限研究预览形式向企业版及团队版客户开放此功能，并为开源仓库维护者提供加速访问权限，以便我们协同优化其能力，并确保其负责任地部署。

**Claude Code 安全功能工作原理** --------------------
