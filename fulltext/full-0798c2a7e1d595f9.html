向防御者开放前沿网络安全能力

📅 2026-02-20 📄 Anthropic 🔗 原文链接

原标题：Making frontier cybersecurity capabilities available to defenders

中文摘要： Anthropic 推出 Claude Code Security，一种基于 AI 的新型安全工具，可像人类专家一样深入分析代码、发现传统工具遗漏的复杂漏洞，并提供修复建议。该功能面向企业与开源维护者限量预览，旨在赋能防御者，提升代码安全性，应对日益增长的 AI 驱动型网络攻击风险。

**Claude Code Security**，一项内置在网页版 Claude Code 中的新功能，现已面向企业及团队客户推出限量研究预览版。它可扫描代码库以识别安全漏洞，并提出针对性的软件补丁供人工审核，帮助团队发现并修复传统方法常遗漏的安全问题。

安全团队普遍面临挑战：软件漏洞数量庞大，而人力资源却严重不足。现有分析工具虽有帮助，但通常仅能检测已知模式，难以识别攻击者常利用的细微、依赖上下文的漏洞——这类问题需依赖经验丰富的研究人员，而他们正面临日益膨胀的工作积压。

人工智能正开始改变这一局面。我们近期已证明[Claude可检测新型高危漏洞](https://red.anthropic.com/2026/zero-days/)。但同样，赋予防御者发现与修复漏洞的能力，也可能被攻击者用于反向利用。

Claude Code Security 的目标正是将这一能力牢牢交予防御者手中，以保护代码免受这一新型AI赋能攻击的威胁。我们将其作为限量研究预览版发布，优先向企业与团队客户开放，并为开源仓库维护者提供加速访问通道，以便协同优化其能力，确保负责任地部署。

**Claude Code Security 工作原理** ---------------------------------- 静态分析——一种广泛应用的自动化安全测试方式——通常基于规则，即匹配代码与已知漏洞模式。它可捕获常见问题（如暴露的密码或过时加密），但常遗漏更复杂的漏洞，例如业务逻辑缺陷或访问控制失效。

Claude Code Security 并非仅扫描已知模式，而是像人类安全研究人员那样阅读并推理代码：理解组件间交互、追踪数据在应用中的流动路径，从而捕获基于规则的工具所忽略的复杂漏洞。

每项发现均需通过多阶段验证流程方可提交给分析师：Claude 会重新审视每项结果，尝试证明或证伪自身发现，并过滤误报；同时为每项发现标注严重等级，便于团队优先处理关键修复项。

经验证的发现将显示在 Claude Code Security 仪表板中，供团队审阅、检查建议补丁并批准修复。由于此类问题常涉及仅凭源码难以判断的细节，Claude 还为每项发现提供置信度评级。所有操作均需人工批准：Claude Code Security 仅负责识别问题并提出方案，最终决策权始终在开发者手中。

**将 Claude 用于网络安全** ---------------------------------- Claude Code Security 基于一年多来对 Claude 网络安全能力的深入研究。我们的前沿红队已系统性地开展压力测试：让 Claude 参与[攻防竞赛（Capture-the-Flag）](https://red.anthropic.com/2025/ai-for-cyber-defenders/)，与太平洋西北国家实验室合作[探索AI用于关键基础设施防御](https://red.anthropic.com/2026/critical-infrastructure-defense/)，并持续优化其在真实代码中发现与修补漏洞的能力。

由此，Claude 的防御能力显著提升。借助本月初发布的[Claude Opus 4.6](https://www.anthropic.com/news/claude-opus-4-6)，我们的团队在生产级开源代码库中[发现超500个漏洞](https://red.anthropic.com/2026/zero-days/)——这些已潜伏数十年、历经多位专家审查却未被发现的漏洞。我们正与维护者开展漏洞分级与负责任披露工作，并计划进一步扩大与开源社区的安全合作。

我们亦使用 Claude 审查自身代码，证实其在加固 Anthropic 系统方面极为有效。Claude Code Security 即旨在将此类防御能力更广泛地开放。由于其基于 Claude Code 构建，团队可在现有工具中直接审阅发现并迭代修复。

**未来之路** ------------------ 当前正值网络安全的关键转折点。鉴于模型在发现长期隐藏漏洞方面的卓越表现，我们预计未来大量世界代码将接受AI扫描。

攻击者将利用AI以前所未有的速度挖掘可利用弱点；而迅速行动的防御者则可抢先发现、修补这些弱点，从而降低攻击风险。Claude Code Security 是我们迈向更安全代码库与全行业更高安全基线目标的重要一步。

**快速上手** ------------------- 今日起，我们面向企业与团队客户开放 Claude Code Security 的限量研究预览。参与者将获得早期访问权限，并直接与我们团队协作打磨工具能力。我们也鼓励开源维护者申请免费加速访问权限。
