原标题：MIBURI: Towards Expressive Interactive Gesture Synthesis

中文摘要： 本文提出 Miburi——首个在线、因果框架，用于实时生成与口语对话同步的 expressive 全身手势与面部表情。通过身体部位感知手势编解码器与二维因果生成器，Miburi 在低延迟下建模时间与运动学运动结构，结合对比目标提升多样性与表现力。实验表明其在自然性与语境对齐性上优于近期基线，推动具身对话智能体（ECAs）向真正交互式人机交流迈进。

摘要 具身对话智能体（ECAs）旨在通过语音、手势和面部表情模拟人类面对面交流。当前基于大语言模型（LLM）的对话系统缺乏具身性，且缺少自然交互所必需的 expressive 手势。现有 ECAs 解决方案常生成僵硬、多样性低的动作，难以满足拟人化交互需求；而生成式共 Speech 手势合成方法虽能产生自然身体动作，但依赖未来语音上下文且运行时间长。为弥合此差距，我们提出 Miburi——首个在线、因果框架，用于实时生成与口语对话同步的 expressive 全身手势与面部表情。我们采用身体部位感知的手势编解码器，将分层运动细节编码为多级离散 token；这些 token 由二维因果框架自回归生成，该框架以 LLM 驱动的语音-文本嵌入为条件，实时建模时间动态与部件级运动层次结构。此外，我们引入辅助目标以鼓励 expressive 与多样性手势，防止收敛至静态姿态。对比评估表明，我们的因果实时方法在自然性与语境一致性方面优于近期基线。欢迎访问项目页面观看演示视频。

1 引言 人机交互已从打孔卡界面演进至 LLM 驱动的对话系统。当前文本聊天助手虽具备强大的语言知识理解能力，但仅依赖语音或文本交互，缺乏非语言元素（如全身手势与面部表情）。人类交流不仅限于言语，还包括非语言行为，如身体手势与面部表情，这些在现有助手系统中均缺失。全身手势不仅传递语境信息，还结构化人类交互过程，是另一重要交流渠道。将此新通道引入数字助手，可推动具身对话智能体（ECAs）[6]的发展：即更富交互性与自然性的人机界面[46]，迈向超越语言的物理世界知识理解。

为实现交互智能体目标，Cassell 等人[6]的开创性工作指出系统需满足两个关键要求：（1）因果性（causal），即不能依赖未来话语；（2）实时性（real-time），即低延迟。需强调，仅具低平均生成速率（如扩散模型）不足以满足要求。

近年来，生成式方法[2,38,37,58]利用扩散[41,59]或掩码建模[28]生成更自然 expressive 的共 Speech 手势，但通常为离线、非因果模式，需同时访问过去与未来语音上下文，无法与实时语音并行运行。值得注意的是，因果性与实时性虽相关但不同：因果模型（如自回归 Transformer）仅依赖过去输入，不考虑延迟；而实时交互系统还需满足严格时间约束以维持对话流畅性与手势表现力。因此，现有生成式手势方法虽具表现力，却无法作为 Cassell 等人[6]所提具身智能体的即插即用方案。

为填补此空白，我们提出 Miburi——一种在线、完全因果的生成框架，可实时生成与口语对话同步的 expressive 共 Speech 身体手势与面部表情。我们基于 Moshi[12]（一种生成全双工口语对话的语音-文本基础模型）构建本框架，并利用其丰富的上下文语音-文本嵌入生成同步身体运动。尽管已有 LLM 驱动的手势合成方法[9,37]，但通常采用复杂流水线：LLM 输出先转为语音，再 token 化以驱动手势合成模型（图2上）。我们提出替代范式：为满足因果与实时性，我们直接利用 Moshi 的语音-文本对齐 token 流，通过接入其内部 token 构建手势合成架构（图2下），避免传统流水线中引入延迟的步骤，同时受益于 token 嵌入提供的丰富语义与声学上下文。

架构上，我们的因果生成网络利用这些内部 token，通过两个 Transformer 生成手势：一个整合时间上下文，另一个生成逐帧、骨架感知的运动学特征。为支持该分解，我们提出二维手势编码（通过残差 VQ-VAE），并训练其对生成的手势 token 进行因果解码。值得注意的是，我们的 token 编码短时间窗口（2帧）以保持低延迟。我们将身体分为三组（面部、上身、下身），通过独立编解码器分别 token 化。

本文贡献如下： • 提出一种新范式，用于在线、实时、因果手势生成，通过接入语音大语言模型内部 token 流实现交互式手势合成； • 设计精巧的网络架构与 token 化方法，在不牺牲表现力前提下实现因果手势合成； • 全面分析方法中的多种设计选择。通过感知与数值实验，证明 Miburi 推动了具身对话智能体（ECAs）的前沿进展。

2 相关工作 我们首先回顾共 Speech 手势合成方法，再讨论具身对话智能体构建方法。尽管二者均生成共 Speech 手势，但需求差异使跨领域融合非平凡。

2.1 共 Speech 手势合成 共 Speech 手势是与语音同步的身体与手部动作，传递语义对齐含义[34]。现有手势生成方法涵盖早期基于规则系统[7,49,51]至现代学习驱动系统[13,22,14,16,55]。学习方法[28,2,38,41]通常数据驱动，采用深度网络将语音输入转为同步自然动作。CaMN[29]与 EMAGE[28]引入大规模语音对齐运动数据集及基于 Transformer 的手势合成方法。GestureDiffuCLIP[2]利用扩散 Transformer 对过去与未来语音帧施加因果注意力。ConvoFusion[38]用扩散泛化单人与双人交互生成；Audio2Photoreal[41]亦生成真实感双人交互。RAG-Gesture[37]与 SemanticGesticulator[58]采用检索范式提升生成手势的语义对齐性。上述方法因计算量大无法实时运行，不适用于在线手势合成。

为降低运行时间，MambaTalk[53]采用选择性状态空间模型与非因果交叉注意力实现低延迟生成；GestureLSM[30]提出实时流匹配框架与快捷采样。二者推理时仍需种子手势序列。然而，二者仍属离线非因果模型，依赖过去与未来语音，无法支持在线 ECAs。这凸显了对实时、因果框架的需求：直接从语音生成 expressive 手势，无需未来上下文、种子序列或长运行时间。

2.2 具身对话智能体（ECAs） 在语言生成中，LLM[50,43]展现出强大文本生成与理解能力。类似地，近期口语对话系统[12,44]旨在实时对话中保持 LLM 的知识与推理能力，但缺乏虚拟角色所需的全身动态。在虚拟角色领域，近期方法尝试通过关节身体动作增强 LLM 驱动对话。Digital Life Project[5]用 LLM 主干合成虚拟角色的指令驱动动作；TaoAvatar[9]聚焦于给定动作库输入时实时生成全身真实感虚拟角色。

完整 ECAs 解决方案主要为基于规则系统，数据驱动系统极少。基于规则系统[8,6,4]通常利用预录动画实时合成身体运动；混合系统[31,52]用神经方法合成唇动，规则方法生成身体手势。近期，Abel 等人[1]提出基于 GRU 的实时共 Speech 手势生成流水线；Nagy 等人提出 Gesturebot[39]，利用数据驱动方法[23]创建身体手势具身角色。但 Gesturebot 仅支持轮流交互，且仅在说话时动画化手势，使用非因果模型。相比之下，我们的框架在语音与手势 token 层面均因果运行，支持实时连续交互。

3 方法 本方法目标是为 ECAs 生成与语音同步的全身手势与面部表情。理想框架需生成口语对话，并利用其语言与韵律上下文合成 expressive 与多样身体手势。根据 Cassell 等人[6]的开创性工作，交互式手势合成需满足：（1）因果性（即不假设未来话语可用）；（2）实时性（低延迟）。需强调，仅低平均生成速率（如扩散方法）不足。

本方法基于语音-文本基础模型[12]生成全双工口语对话，并提取其内部语音-文本 token 流为手势合成提供丰富上下文输入（第3.1节）。手势生成器随后通过二维时间与运动学 Transformer（第3.3节）自回归生成身体区域感知运动 token（第3.2节）。然而，该基础框架不足以实现自然通信所需的多样 expressive 身体手势。因此，我们为自回归框架引入额外目标以提升手势拟人质量（第3.4节）。最后，通过精心设计注意力上下文与高效缓存机制确保因果与实时推理（第3.5节）。图3展示所提架构。

3.1 预备知识：Moshi 为生成实时对话语音与语言，我们采用开源口语对话系统 Moshi[12]。该框架基于文本 LLM 主干，自回归生成文本与语音 token。关键地，其通过并行 token 流联合建模自身语音与用户语音，实现全双工对话。输出生成语音与文本 token： \(\mathbf{f}^{\text{speech}}\in\mathbb{R}^{T\times K^{\text{speech}}\times d}\) 与 \(\mathbf{f}^{\text{text}}\in\mathbb{R}^{T\times K^{\text{text}}\times d}\)， 其中 \(T\) 为时间轴 token 数，\(d\) 为嵌入维度。Moshi 还利用残差向量量化[56]将语音编码为多级语义与声学 token，\(K^{\text{speech}}\) 与 \(K^{\text{text}}\) 分别为语音与文本的量化级别。Miburi 旨在利用 Moshi 的语义与韵律细节生成其骨架感知手势 token 流。

3.2 身体部位感知手势编解码器 作为本框架第一步，我们构建稳健运动先验，将手势帧编码为离散 token，供下游自回归 Transformer 生成手势。鉴于各身体区域共 Speech 发音尺度不同[38]且与语音关联独立[28,37]，我们将手势序列 \(\mathbf{x}\) 解耦为三部分： 上身（含手）\(\mathbf{x}^{u}\in\mathbb{R}^{N\times 6J^{u}}\)， 下身（含全局平移与足部接触）\(\mathbf{x}^{l}\in\mathbb{R}^{N\times(6J^{l}+3+4)}\)， 面部表情（FLAME 参数）\(\mathbf{x}^{f}\in\mathbb{R}^{N\times(100+6J^{f})}\)[27]。 其中 \(N\) 为运动帧数，\(J^{u}, J^{l}, J^{f}\) 分别为上身、下身与下颌关节数[45,60]。

各区域手势序列通过独立手势编解码器编码，采用残差 VQ-VAE 进行运动 token 化。

残差 VQ-VAE 用于手势：共 Speech 身体发音包含多层级细节，从大幅手臂动作到细微手指动作。朴素 VQ-VAE 编码[28,53,47]易因丢失精细运动学细节导致动作粗糙卡顿（见第4.4节）。为封装细微运动细节，我们用残差 VQ-VAE[56]为各身体区域训练手势编解码器。

各区域编解码器由编码器-解码器架构（图3）组成：编码器 \(\mathcal{E}^{b}\) 含下采样1D卷积层与带因果自注意力的 Transformer 编码器，将给定区域运动编码为 \(\mathbf{\tilde{g}}^{b}=\mathcal{E}^{b}(\mathbf{x}^{b})\)，再经残差向量量化（RVQ）得 token \(\mathbf{{g}}^{b}\in\mathbb{R}^{T\times K^{b}}\)（\(K^{b}\) 为运动细节级别）。其中 \(T\) 为 token 序列时间长度（由 \(N\) 下采样得）。每残差级学习码本 \(\mathbf{C}_{k}\in\mathbb{R}^{V\times d}\) 用于对应残差向量量化。运动可通过解码器重建：\(\mathbf{\hat{x}}^{b}=\mathcal{D}^{b}(\mathbf{{g}}^{b})\)（含类似因果 Transformer 编码器与上采样转置1D卷积层）。这些手势 token 编解码器以重建/几何损失与各量化级潜在嵌入损失训练（详见补充材料）。

最终手势序列 \(\mathbf{{g}}\in\mathbb{R}^{T\times K}\) 定义为沿 \(K\) 级轴拼接： \(\mathbf{{g}}=\operatorname{Concat}(\mathbf{{g}}^{u},\mathbf{{g}}^{l},\mathbf{{g}}^{f})\)， 其中 \(K=K^{u}+K^{l}+K^{f}\)。该 token 序列 \(\mathbf{{g}}=\{\mathbf{{g}}_{(t,k)}\mid t=1\dots T,k=1\dots K\}\) 沿时间与运动学维度表示运动：前者涵盖时间维度运动学细节，后者包含身体区域维度部件级细节。

3.3 自回归与因果 Transformer 回顾目标：设计因果手势合成框架，给定 Moshi 的语音 \(\mathbf{f}^{\text{speech}}\) 与文本 \(\mathbf{f}^{\text{text}}\) token 及角色身份嵌入 \(\mathbf{f}^{\text{id}}\)，生成手势 token \(\mathbf{{g}}\)。

自回归 Transformer 常用于因果 next-token 预测任务（注意力层仅关注前 \(T\) 个 token）。但本任务中，每时间帧 \(T\) 含 \(K\) 级 token，代表分层运动细节。朴素实现需自回归建模 \(T\cdot K\) 个 token，注意力层需至少 \(>K\) 个 token 上下文以学习帧间时间动态，导致注意力层上下文窗口增大，训练困难且推理计算昂贵（见第4.4节）。

因此，我们受 RQ-Transformer[24,61,12] 启发，解耦手势编解码器 \(\mathbf{{g}}\) 的时间与运动学维度预测，采用两个 Transformer。

时间 Transformer：首先构建基础时间 Transformer \(\mathcal{T}_{\text{temporal}}\) 专注时间维度动态。该因果 Transformer 训练为自回归预测首级 token \(\mathbf{{g}}_{(t,1)}\)（\(K\) 级中），以先前时间步 token 为条件： \(\mathbf{h}_{t} = \mathcal{T}_{\text{temporal}}\big(\mathbf{{g}}_{(<t)},\mathbf{f}^{\text{speech}}_{(\leq t)},\mathbf{f}^{\text{text}}_{(\leq t)},\mathbf{f}^{\text{id}}\big)\) \(\mathbf{{g}}_{(t,1)} = \text{Softmax}\big(\text{Linear}(\mathbf{h}_{t})\big)\)

内部，沿运动学维度 \(K\) 的 \(\mathbf{{g}}_{(<t)}\) 嵌入求和为每 \(t\) 的单输入 \(\mathbf{i}_{t-1}\)（见图3）。Transformer 输出 \(\mathbf{h}_{t}\) 经分类层转为 logits \(\mathbf{{o}}_{(t,1)}\in\mathbb{R}^{V}\)，再经 Softmax 得 \(\mathbf{{g}}_{(t,1)}\)。该模块实现为带因果自注意力的 Transformer 解码器，及双因果交叉注意力层（关注前续与当前语音/文本 token）。另学习每身份特征嵌入于每时间步添加。

运动学 Transformer：其次，通过 Transformer \(\mathcal{T}_{\text{kinematic}}\) 建模手势 token 的运动学维度，自回归预测每时间步 \(t\) 的下一身体部件级 token。除先前生成级别外，运动学 Transformer 以时间上下文 \(\mathbf{h}_{t}\) 及语音、文本、身份嵌入为条件： \(\mathbf{{g}}_{(t,k)} = \mathcal{T}_{\text{kinematic}}\big(\mathbf{h}_{t},\mathbf{{g}}_{(t,<k)},\mathbf{f}^{\text{speech}}_{t},\mathbf{f}^{\text{text}}_{t},\mathbf{f}^{\text{id}}\big)\)

此处时间步 \(t\) 对每级预测固定，故语音/文本输入仅对应 \(t\) 时刻嵌入。该 Transformer 同样实现为带因果自注意力层与交叉注意力层的解码器。身份嵌入与时间上下文 \(\mathbf{h}_{t}\) 添加至每级步输入。最后，每步 \(k\) 输出经分类层投影以预测 \(\mathbf{{g}}_{(t,k)}\)。注意，首级步中，\(\mathcal{T}_{\text{kinematic}}\) 接收时间 Transformer 输出 \(\mathbf{{g}}_{(t,1)}\) 为输入，预测下一级别 \(\mathbf{{g}}_{(t,2)}\) 等。

两 Transformer 联合以交叉熵损失 \(\mathcal{L}_{\text{CE}}\) 训练。另采用教师强制（teacher-forcing）防模型过拟合干净真实样本。

3.4 提升表现力 自回归运动合成架构在因果场景下擅长生成连贯运动序列，但易收敛至均值姿态并沿时间维度累积漂移[10,23]。为获得 expressive 手势，我们引入辅助目标以明确鼓励运动多样性，防收敛至静态或重复手势。

训练中，对预测 token 应用对比 InfoNCE 损失[42]以提升手势表现力。但离散采样不可微，需用 Gumbel-Softmax 重参数化技巧[19]近似离散采样过程。此法可从时间与运动学 Transformer 的 logit 输出 \(\mathbf{\tilde{o}}\in\mathbb{R}^{T\times K\times V}\) 得概率，再转为 RVQ 步潜在输出（第3.2节）： \(\mathbf{z}=\sum_{k=1}^{K}\text{GumbelSoftmax}(\mathbf{\tilde{o}}_{k})\mathbf{C}_{k}\in\mathbb{R}^{T\times d}\)

GumbelSoftmax 温度设0.4，输出用可微直通估计器采样 one-hot 向量。每身体区域用其对应 RVQ 码本独立计算潜在输出 \(\mathbf{z}\)。给定真实潜在 \(\mathbf{z}^{\text{GT}}\) 与生成潜在 \(\mathbf{z}^{\text{pred}}\)，计算所有真实-生成对相似矩阵并应用 Info-NCE 损失： \(\mathcal{L}_{\text{con}}=-\mathbb{E}_{i}\Bigg[\log\frac{\exp(\text{sim}(\mathbf{z}_{i}^{\text{GT}},\mathbf{z}_{i}^{\text{pred}})/\tau)}{\sum_{j=1}^{B}\exp(\text{sim}(\mathbf{z}_{i}^{\text{GT}},\mathbf{z}_{j}^{\text{pred}})/\tau)}\Bigg]\)

其中 \(\text{sim}(\cdot)\) 为余弦相似度，\(\tau\) 为温度参数。该损失强制匹配真实-生成潜在高相似度，同时推远批次 \(B\) 内不匹配对，实现更 expressive 与语音对齐的运动生成。实践中，对 \(\mathbf{z}\) 时间片段而非完整时间长度 \(T\) 应用该损失，以鼓励手势阶段间运动轨迹相似性。

语音激活损失：本框架可泛化至身体手势的聆听与说话状态。因人类聆听与说话时手势方式不同，我们显式强制网络学习二者区分。通过将 Transformer 输出 \(\mathbf{h}_{t}\) 投影至二分类头（分类为聆听(0)或说话(1)状态），以二元交叉熵损失 \(\mathcal{L}_{\text{va}}\) 训练该多任务头，防聆听状态下的“幻觉”手势，并强制说话阶段语音对齐的 expressive 手势。

最终，整个网络以联合损失 \(\mathcal{L}=\mathcal{L}_{\text{CE}}+\alpha\mathcal{L}_{\text{con}}+\beta\mathcal{L}_{\text{va}}\) 优化，\(\alpha,\beta\) 为损失权重。

3.5 实现 为实现实时手势生成（与 Moshi 时间对齐），我们采用高效技术以加速合成。Moshi 延迟为200ms（12.5 token/秒），每 token 代表0.08秒音频，故 Miburi 每时间步生成0.08秒手势与面部表情。训练数据含25 FPS 运动，即每步生成2帧。手势编解码器含 \(K_{u}=K_{l}=8\) 与 \(K_{f}=4\) 残差级，训练时 \(T=125\)（10秒运动序列）。时间 Transformer 含4层2注意力头，运动学 Transformer 含2层1注意力头。训练优化用 AdamW[32]，初始学习率1e-4，随轮次衰减。

为高效注意力推理，将前时间步的 key 与 value 存于 KV-Cache 以保留注意力所需上下文。自注意力层上下文限制为25 token，交叉注意力层（语音/文本）上下文保持50 token。时间 Transformer 以零初始 token 开始推理以预测 \(\mathbf{{g}}_{(1,1)}\)（见图3）。实践中，因下身与语音/文本关联弱，屏蔽下身 token 的交叉注意力以节省运行时间。训练中设 \(\alpha=0.1\)，\(\beta=0.01\)。

推理时，用 top-p（核）采样[18]替代贪婪采样以保多样性：时间 Transformer top-p 设0.8，运动学 Transformer 设0.95，二者 softmax 温度0.9。此外，采样时应用无分类器引导（CFG）[17]以提升手势与 Moshi 丰富语义/声学信息对齐。

4 实验 我们对比语音共 Speech 手势合成的最先进基线评估本方法。进行定量（第4.2节）与感知（第4.1节）评估以衡量手势质量、运动自然性与语音适配性。另分析各基线生成时间以测实时能力。最后通过消融分析（第4.4节）验证设计选择。

基线方法分两类：（1）非因果非实时方法如 RAG-Gesture[37]与 CaMN[29]，旨在合成有意义 expressive 运动；（2）实时方法如 GestureLSM[30]与 MambaTalk[53]，生成时采样时间快。因无因果神经基线，我们亦实现实时方法[30,53]的因果版本以对比朴素因果手势合成（详见补充材料）。需注意，所有基线（除[37]）需种子序列并利用其上下文生成运动，而本框架无需。

数据集：在 BEAT2 数据集[28]上训练，于其标准 train/val/test 分割评估性能。数据集原含25说话人，移除2人（carla & itoi）以保训练/评估数据高质量运动追踪。遵循[37]，不同于其他 BEAT2 基线方法，我们在单人（scott）与多人测试集评估以评估大规模多人设置性能。测试集含15与249条完整语句（单人与23人设置）。按需对多人设置重训方法。补充材料中亦提供 Embody3D 数据集[33]评估。

5 局限性与未来工作 当前框架仅建模智能体运动，未整合用户身体动态或完整 dyadic 上下文，限制其处理交互式多方手势能力。将 Miburi 扩展至感知并响应伙伴手势为重要未来方向。

6 结论 本文提出 Miburi——一种在线、因果框架，用于生成与实时对话同步的 expressive 共 Speech 手势与面部表情。通过身体部位感知手势编解码器与二维因果生成器，本方法以低延迟建模时间与运动学运动结构。对比目标进一步提升手势多样性与表现力。单人与多人设置实验表明，Miburi 生成自然、语境对齐手势，优于近期基线。本方法推动 ECAs 更接近真正交互式、拟人化具身交流。

10 关于因果性-质量权衡 回顾 Miburi 设计为交互式具身对话智能体（ECA），故模型需不仅因果，且实时，设计选择深受此考量影响。自然地，因果性以质量为代价。但此权衡非仅限于有限上下文所致。本节强调人类手势因果合成设计相关细微差别。

手势源于何处？ 我们主张因果共 Speech 手势合成前提实为不妥，因其隐含假设智能体（或人类）基于过去上下文已发语音做手势。此假设不成立。现实中，人类语音与手势由共享意图并行驱动[20,11,25,21]。观察显示手势常在语音发出前即出现[34,36]，多说话人轮流中亦然[48]。手势亦可延迟（如强化或限定语音论点）[35]。后者原则上可由因果模型建模，前者固有挑战。因此，因果建模激励更显著节拍手势（因训练中语音-手势时间相关性易发现）。另一方面，非因果全上下文模型受益于未来上下文可用性，能建模更精细语义有意义手势[58,37]。

是否应建模手势背后意图？ 我们认为建模意图后再生成语音与手势为值得追求目标。可通过先推断 LLM 输出背后意图，再基于推断意图联合生成语音与手势实现。但此法次优：破坏因果约束且慢。对真正交互 ECAs，需实时 LLM 训练为在最终输出前生成意图，或方法解耦 LLM 意图与中间特征。二者均为未来研究方向，但超出当前提交范围。

11 手势编解码器实现细节 用残差 VQ-VAE[56]为每身体部位构建流式编解码器。编解码器由编码器-解码器架构组成：编码器下采样输入运动序列2倍，解码器上采样重建。训练输入250帧时，编码器输出125 token（10秒序列）。训练中每迭代随机采样输入序列长度2至250帧。上身与下身编解码器含2层1D卷积层与8层 Transformer（4注意力头）；面部编解码器含2层1D卷积层与4层 Transformer（2注意力头）。每编解码器以重建与几何损失及各码本承诺损失训练。对旋转矩阵应用测地损失，对运动6D、轴角与关节位置表示应用标准 MSE 损失。另应用 MSE 损失优化运动速度/加速度[37]。最后，编解码器训练中对足部接触预测应用损失以减少足部滑动[37,57]。

12 评估指标 FGD：采用 Fréchet Gesture Distance (FGD)，遵循 Yoon 等人[54]。评估用 BEAT2 发布手势编码器提取手势嵌入计算 FGD（不重训编码器）。

Beat Alignment Score：原为评估音乐节拍与舞蹈运动同步性[26]，现适配手势合成以测手势节拍事件与音频节拍事件对齐程度，捕捉手势动态与语音韵律时间相关性。

L1 Divergence：亦称 L1 方差，计算生成姿态与序列均值姿态平均 L1 距离。低值指示运动坍缩至静态姿态，用于检测无表现力或冻结手势生成。

Facial-MSE：由 EMAGE[28]引入，测真实与预测面部表情均方误差。用 FLAME[27]表示计算此损失。

Mean Per Joint Position Error (MPJPE)：标准运动重建与姿态估计评估指标。测所有关节与帧预测与真实关节位置平均欧氏距离。形式上，计算为3D空间平均 L2 距离，直接测姿态准确性。

13 用户研究细节 为评估感知质量，进行53名参与者用户研究。每位参与者随机回答15题（来自45题）。每题显示侧对动画，比较本方法与最先进基线及真实数据。每题显示本模型与 EMAGE[28]、GestureLSM[30]或真实数据侧对动画。每成对比较中，参与者回答两问题： • “哪组手势序列更自然？” • “哪组与口语内容更对齐？” 所有比较结果统计显著（\(p<0.001\)），除与 GestureLSM[30]对齐性比较（\(p<0.05\) 显著）。

14 基线实现 单人评估用各基线方法公开检查点。多人评估中，多数基线未发布多人模型。为公平比较，在 BEAT2 23人子集（排除 carla 与 itoi）上重训 EMAGE[28]与 MambaTalk[53]，遵循其论文训练配置。除对比非因果基线，亦创建 GestureLSM 与 MambaTalk 因果变体，在相同在线实时约束下评估。因果性通过训练中对所有 Transformer 层施加因果注意力掩码实现。本法可报告等效因果条件下模型定量对比。
