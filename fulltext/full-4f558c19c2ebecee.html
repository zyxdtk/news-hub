VentureBeat 使用 OpenAI ChatGPT-Images-2.0 制作

继上周令人惊艳的首秀后，中国初创公司 z.ai 推出的新一代开源大语言模型 GLM-5.3 凭借其极为先进的网络能力，据报道在 Cursor 中发现了一个此前未被检测到的漏洞。如今，该模型已正式接入应用程序编程接口（API），允许开发者在其基础上进行构建，并将其接入他们的智能体和应用程序中。

此前订阅了 GLM Coding Plan 的开发者目前仅限于使用兼容 OpenAI Chat Completions 的协议。Z.ai 表示计划公开该模型的权重，但具体日期和许可协议仍有待公布。

在 API 方面，价格与 GLM-5.2 相比保持不变：每百万输入 token 为 1.40 美元，每百万输出 token 为 4.40 美元。缓存的输入成本为每百万 token 0.26 美元，而 Z.ai 目前在有限时间内将缓存输入存储列为免费。

这意味着开发者可以无缝过渡到新一代模型，而无需承担 Z.ai 更高的按 token 公布费率，尽管该公司声称其在编码和长程智能体性能方面有了大幅提升。

按照这些费率，GLM-5.3 的价格远低于几款最高端的前沿 API。

使用 VentureBeat 简单的对比方法（即一百万输入 token 加上一百万输出 token），GLM-5.3 的总价为 5.80 美元，而 Grok 4.6 在其较低上下文费率下为 8 美元，Kimi K3 为 18 美元，Claude Opus 5 为 30 美元，GPT-5.6 Sol 为 35 美元。

这并不是工作负载成本的估算——实际账单很大程度上取决于输入/输出的比例、缓存和 token 消耗量——但它使得相对的 API 价格层级一目了然。

GLM-5.3 并不是市面上最便宜的可用模型。谷歌目前为 Gemini 3.7 Flash 提供的入门价格在 2026 年 12 月 31 日前为每百万输入 token 0.75 美元和每百万输出 token 3.75 美元，而 OpenAI 的 GPT-5.6 Luna 定价为输入 0.20 美元和输出 1.20 美元。

尽管如此，Z.ai 的定价使 GLM-5.3 处于明显低于高端前沿模型的成本区间，而人们正越来越多地将其与这些模型进行基准测试比较。

在最新的独立测试结果公布后，这种对比变得更加有意义。

Artificial Analysis 在其智能指数中给 GLM-5.3 打了 60 分，与 Kimi K3 并列成为世界上性能最高的开放权重模型，并且比 GLM-5.2 高出 7 分。

其分析还估计，尽管 API token 价格相同，但 GLM-5.3 每项智能指数任务的成本约为 0.68 美元，而 GLM-5.2 约为 0.44 美元。

这一差异凸显了 API 标头定价中的一个重要注意事项：Artificial Analysis 发现 GLM-5.3 比其前代模型更加冗长，因此单一的按 token 费率并不一定意味着完成工作负载的成本保持不变。

不过，对于开发者来说，直接的变化很简单：GLM-5.3 现在可以通过 Z.ai 的 API 以与 GLM-5.2 相同的每百万 token 1.40 美元/4.40 美元的费率进行调用，为团队测试前沿级编码和智能体工作负载提供了另一个相对低成本的选项。
