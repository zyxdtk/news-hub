Abstract LLM agents increasingly rely on skills to encapsulate reusable capabilities via progressively disclosed instructions. High-quality skills inject expert knowledge into general-purpose models, improving performance on specialized tasks. This quality and ease of dissemination drive the emergence of a skill economy: free skill marketplaces already report 90368 published skills, while paid marketplaces report more than 2000 listings and over $100,000 in creator earnings. Yet this growing marketplace also creates a new attack surface, as adversaries can interact with public agent to extract hidden proprietary skill content. We present the first empirical study of black-box skill stealing against LLM agent systems. To study this threat, we first derive an attack taxonomy from prior prompt-stealing methods and build an automated stealing prompt generation agent. This agent starts from model-generated seed prompts, expands them through scenario rationalization and structure injection, and enforces diversity via embedding filtering. This process yields a reproducible pipeline for evaluating agent systems. We evaluate such attacks across 3 commercial agent architectures and 5 LLMs. Our results show that agent skills can be extracted with only 3 interactio

ns, posing a serious copyright risk. To mitigate this threat, we design defenses across three stages of the agent pipeline: input, inference, and output. Although these defenses achieve strong results, the attack remains inexpensive and readily automatable, allowing an adversary to launch repeated attempts with different variants; only one successful attempt is sufficient to compromise the protected skill. Overall, our findings suggest that these copyright risks are largely overlooked across proprietary agent ecosystems. We therefore advocate for more robust defense strategies that provide stronger protection guarantees. I Introduction Figure 1: The emerging commercial skill ecosystem. II-B System Prompt Stealing Attack and Defense System prompt stealing studies an adversary that attempts to recover hidden developer instructions through interaction with an LLM interface. For the scope of this paper, we focus on two attack types that are directly relevant to automated skill stealing. The first type uses scenario rationalization to make extraction requests appear legitimate, for example, by role-playing as an administrator, debugger, or authorized maintainer [ 46 , 28 ] . The second family uses structured prompt templates to bias the model toward disclosure, especially through chain-of-thought-style scaffolding and few-shot demonstrations that normalize extraction behavior in context [ 28 , 12 ] . On the defense side, we focus on the defenses evaluated in this paper and group them into two categories: prompt-level defenses and output-filtering defenses. Prompt-level defenses operate by modifying or reinforcing the model’s input context. One example is instruction-based defense, which strengthens privileged instructions and explicitly directs the model not to comply with extraction requests [ 41 ] . Another is sandwich-style defense, which repeats or restates the trusted instruction after the user input so that the intended task remains salient even in the presence of adversarial

At a high level, the framework operationalizes the abstract threat of skill stealing as a reproducible black-box evaluation pipeline that generates diverse extraction prompts and measures their effectiveness against target agent systems. The framework consists of three main modules. First, seed generation produces a small set of generic extraction prompts that capture the core intent of eliciting hidden skill content. Second, prompt optimization expands these seeds into a diverse attack pool through scenario construction, structural augmentation, and diversity checking. Third, stealing evaluation runs the resulting benchmark against the target agent and measures how effectively different prompt variants recover the protected skill content. This component fixes the instruction priority during inference. In particular, it states that user requests cannot override system- or developer-level constraints through roleplay, priority-reset claims, “ignore previous instructions,” testing authorization, or similar prompt-injection patterns. Exact copying is only one leakage channel. This component is designed to reduce semantic leakage that would otherwise survive a purely string-level defense. Refusal Policy ( R R ). Once a request is judged to be extraction-oriented, the model is instructed to return a brief and stable refusal that does not restate the protected content, speculate about hidden instructions, or provide partial disclosures. The effect is especially pronounced for rewriting, where the original outputs often retain ROUGE-L, cosine similarity, and LLM-leakage scores in the 0.7–0.95 range, showing that reconstructed responses can carry extensive semantic information despite low exact-match rates. Against this attack family, our defense is still effective, but the effectiveness differs by filtering rule. The exact-match-filtered setting is the most reliable, driving all reported metrics to zero or near zero across the attack space. The cosine-filtered setting is also strong for translation attacks, but under rewriting it is mixed: several high-leakage cases are sharply reduced, while others remain close to the unfiltered original outputs. The LAN setting (LLM and NVRecall) is nearly identical to the original outputs under both translation and rewriting, suggesting that this threshold choice is too permissive in these transformation-heavy conditions. Overall, the results suggest that the core defense benefit comes from strict leakage-aware filtering, and that exact-match-based filtering is substantially more reliable than cosine-only filtering against rewritten leakage. VI Conclusion This paper presents the first systematic study of skill stealing , a black-box extraction threat against LLM agent systems. We show that proprietary skills ca

n be leaked through adversarial interaction with a public agent interface, making skills a concrete security concern as they become reusable and monetizable digital assets. To study this threat, we build an automated skill stealing framework and use it to evaluate representative proprietary models and a commercial agent framework. Our results show that skill leakage is practical, while prompt-level defenses provide only limited protection. Although lightweight defenses can reduce leakage in part of the benchmark, they do not fundamentally eliminate the risk. Overall, our findings suggest that agent ecosystems inherit and amplify the leakage risks of prompt-based systems.
