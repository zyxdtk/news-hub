摘要

多模态大语言模型（MLLMs）中一个核心但尚未被充分探索的问题是"在何处连接"——即如何将来自分层视觉编码器的视觉信息接入大语言模型的逐层语义。主流MLLMs将固定的单层视觉表示注入LLM，并将所有LLM层视为单一消费者，忽略了不同层需要不同的视觉粒度。近期的多层融合方法要么在编码器侧压缩分层特征，要么依赖预定义的稀疏或分层逐层连接，因而无法建模ViT与LLM层级之间的自适应跨层交互。我们通过DGP（动态门控通路，Dynamic Gated Pathways）弥补这一空白，这是一种路由机制，在每个ViT层与每个LLM层之间建立全对全连接，其中每个LLM层根据自身语义状态动态门控其对各视觉层的偏好。基于LLaVA-1.5-7B和13B构建，DGP在LLaVA-1.5-7B基线之上带来一致提升（例如SQA_I上+4.2，MM-Vet上+3.3，VizWiz和LLaVA_W上+3.1），并在大多数基准上超越先前的多层视觉融合方法。逐层路由分析进一步表明，不同的LLM层确实会按需选择不同的视觉粒度，这同时支持了所提动态门控通路的有效性与可解释性。代码地址：https://github.com/YingyingYan1/DGP

1 引言

多模态大语言模型（MLLMs）[19, 3, 21, 16]使用预训练视觉骨干网络[32, 31, 42]编码图像，通过适配器投影所得特征，并将视觉令牌注入语言模型。在这一范式中，视觉信息的有效性不仅取决于编码器的表示能力[38, 7, 34]，更关键地取决于"在何处连接"：视觉令牌如何接入LLM的内部各层。

如图1所示，各ViT层的注意力模式差异显著：浅层关注边缘、纹理和局部细节，而深层逐渐聚焦于少数语义锚点。然而，大多数MLLMs[2, 25, 10]只是将某一固定ViT层（通常是最后一层或倒数第二层）的输出前向传递给LLM，如图2(A)所示，实际上将图像压缩为单一粒度的语义表示。因此，仅将LLM连接到末端深层会丢弃浅层和中层线索，并阻碍LLM的逐层语义与完整视觉层级交互。

图1：各ViT层的注意力分布。浅层在边缘和纹理上呈现分散的注意力；深层逐渐聚焦于少数语义锚点。

图2：视觉令牌插入策略。 固定单层连接。 将多个ViT层融合为单一表示的编码器侧融合。 ViT与LLM层之间预定义的稀疏或分层连接。 DGP（本文方法）：所有ViT层与所有LLM层之间的动态门控通路。w_m表示LLM层m在所有ViT层上分配的路由权重。

已有两条工作路线开始向LLM暴露多层视觉特征，但每一条在"在何处连接"问题上均有不足。编码器侧融合[39, 4, 20, 23, 36]在LLM之前将多层特征合并为单一表示（图2(B)）；任何动态性都在编码器内部被消耗，无法适应各个LLM层的差异化需求。预定义稀疏或分层连接[30, 43, 37, 8]将选定的ViT层连接到特定的LLM层（图2(C)），通常使用手工设计的连接模式或固定的分层映射。CLI[5]引入了以当前LLM状态为条件的自适应门控，但仅在采样的ViT层和指定的LLM注入点上操作。这两类方法都没有显式建模"在何处连接"问题所要求的、所有ViT层与所有LLM层之间的自适应、动态跨层交互。

视觉神经科学中的预测编码表明，感知并非单向前馈过程，而是一个持续调节各层激活的分层反馈回路[33]。我们以此为灵感重新审视视觉令牌注入：视觉证据不应通过固定通路一次性交付，而应通过动态跨层通路持续"参与"LLM的表示更新。基于这一观点，我们引入DGP（动态门控通路），通过学习的、动态门控的路由将所有ViT层连接到所有LLM层（图2(D)）。

具体而言，不同ViT层的输出作为不同粒度的候选表示。在每个LLM层，DGP从当前隐藏状态生成对所有ViT层的路由分布，通过门控加权融合聚合候选特征，并通过残差连接将结果注入该层的视觉隐藏状态。分层视觉证据持续为语言推理提供线索，而LLM的逐层语义状态驱动对视觉层级的偏好，形成一种跨层的、渐进演化的视觉-语言交互，在不同解码深度按需整合低级细节与高级语义。

我们在LLaVA-1.5[25]之上实例化DGP，并在Qwen3-VL-2B[3]和LLaVA-NeXT[26]上进一步验证。在广泛的多模态基准上，DGP相比基线带来一致改进，并优于先前的多层视觉特征利用方法。学习到的路由模式证实不同的LLM层确实偏好不同的视觉粒度，缓解了固定单层融合的信息瓶颈。我们的贡献如下：

  • 我们围绕"在何处连接"问题重新构建MLLMs中的视觉信息注入，并表明固定单层输入和预定义稀疏或分层连接无法匹配分层ViT表示与逐层LLM语义的差异化需求。
  • 我们提出DGP（动态门控通路），一种全对全跨层连接机制，其中每个LLM层根据其当前语义状态动态门控其对每个ViT层的偏好。
  • 我们在多个多模态基准上展示了DGP的有效性和可解释性，逐层路由分析揭示了所提动态门控通路的自适应、层依赖选择行为。

2 相关工作

2.1 多模态大语言模型

典型的多模态大语言模型（MLLM）由视觉编码器、视觉-语言适配器和大语言模型组成：编码器将图像转换为视觉令牌，适配器将其投影到语言空间，LLM消费联合的视觉-文本序列以生成回答。现有MLLMs主要分为两大架构家族：基于投影器的仅解码器设计（如LLaVA[25]、MiniGPT-4[44]、Qwen-VL[2]、InternVL[10]）和基于交叉注意力的设计（如Flamingo[1]）。

当前MLLMs使用预训练视觉骨干网络，如CLIP-ViT[32]和SigLIP[42]，它们均在各层暴露不同粒度的表示。然而大多数流程只将单一固定层投影到LLM中，因此语言模型只能看到一种级别的视觉抽象。视觉连接机制不仅仅是跨模态接口：它决定了丰富的分层视觉表示能否在LLM内部被访问和复用。

2.2 视觉令牌插入的连接策略

不同ViT层携带不同的语义粒度：浅层保留局部纹理和空间细节，而中层和深层逐渐编码对象结构和高级语义[6]。单一深层并不总是最佳选择[6]，利用视觉层级既取决于层"如何"连接到LLM，也取决于选择"哪些"层[24]。换言之，关键在于建立视觉编码器层与LLM层之间的有效连接——即"在何处连接"问题。先前的努力可分为两类。

统一的编码器侧连接。 该类方法在编码器侧融合多层视觉特征，并将单一统一表示传递给LLM。DenseConnector[39]沿令牌或通道维度拼接不同ViT层的特征。MMFuser[4]使用深层特征作为查询从浅层提取细粒度信息。IGVA[20]和TGIF[23]根据指令调整ViT层权重。CCRA[36]结合多种注意力机制进行文本条件的区域-语义对齐。虽然这些设计改善了多层特征利用，但整个融合发生在LLM"之前"；LLM仍然接收同质化的单一输入，无法在解码过程中回溯到视觉层级。

预定义稀疏或分层连接。 该类方法将分层视觉信息路由到不同的LLM层。DeepStack[30]根据固定的分层调度将视觉令牌分布到解码器各深度。Sparse Shortcuts[43]通过预定义连接模式连接ViT和LLM层。EVLM[8]将多层ViT特征馈送到不同的门控交叉注意力层。CLI[5]在采样的视觉层和指定的LLM注入点应用自适应门控，而非将每个ViT-LLM对视为候选连接。最近的一条工作路线[37]以每个LLM层的表示为条件选择和融合分层视觉特征。尽管这些方法开始承认视觉与语言之间的分层对应关系，但大多数仍依赖手工设计的连接模式或固定的层间映射，且很少有方法同时实现 全对全跨层连通性、 由"当前"LLM层状态驱动的路由权重，以及 端到端训练且路由分布稳定——这正是DGP所针对的设计要点。

总之，现有方法要么将视觉层级压缩为单一的LLM前表示，要么通过预定义稀疏或分层连接将其接入LLM；均未通过所有ViT层与所有LLM层之间的动态跨层交互来回答"在何处连接"。我们通过DGP弥补这一空白，它通过动态门控通路在ViT与LLM层之间建立自适应的全对全连接。

3 方法

图3：DGP概览。 在每个LLM层，动态门控通路模块以当前语言层状态为条件在所有ViT层上进行路由，聚合所选视觉特征，并通过门控残差连接将其注入回LLM隐藏状态——在ViT与LLM之间建立全对全跨层连接。 在模块内部，ViT层摘要作为键/值，语言层状态作为查询；共享交叉注意力后接层特定路由MLP生成每层路由权重。权重矩阵表示LLM层m在所有ViT层上的路由权重。

问题形式化。 在现有MLLMs中，单一固定的视觉表示被一次性注入，然后通过LLM隐式传播[2, 25, 10]，在视觉层级与语言层级之间不存在直接的跨层通路。因此，不同的解码阶段无法回溯到它们实际需要的视觉粒度。DGP（动态门控通路）通过在每个ViT层与每个LLM层之间开启动态门控通路来消除这一瓶颈，使每个LLM层能够自适应地选择最符合其当前语义状态的视觉层级。

设视觉编码器有L_v层，第ℓ层（ℓ=1,…,L_v）的输出记为X_v^(ℓ)。LLM共有L层，第l层（l=1,…,L）的隐藏状态为H^(l) ∈ ℝ^((N_v+N_t)×d)，其中H_v^(l) ∈ ℝ^(N_v×d)对应视觉令牌段。对于每个LLM层l，我们旨在学习一个层特定的融合函数：

Ẑ^(l) = g^(l)(H^(l), {X_v^(ℓ)}_{ℓ=1}^{L_v})， (1)

其中Ẑ^(l) ∈ ℝ^(N_v×d)是为第l个LLM层定制的融合视觉表示。g^(l)(·)的目标是以当前语言层状态为条件在视觉层上分配融合权重，使多个深度的视觉证据在解码过程中被按需整合。

3.1 全对全跨层连接

我们与典型MLLMs的结构性区别在于将每个LLM层（l=1,…,L）连接到每个ViT层（ℓ=1,…,L_v）：每个解码深度都保持对完整视觉层级的直接访问，而不是被限制在一个固定深度或手工设计的稀疏路由模式上。

如图2(D)和图3(A)所示，我们用ViT与LLM堆栈之间的动态门控跨层通路取代传统的固定单层视觉注入。

给定输入图像I，视觉编码器F(·)产生视觉表示层级：

{X_v^(ℓ)}_{ℓ=1}^{L_v} = F(I)，X_v^(ℓ) = [c^(ℓ); P^(ℓ)]， (2)

其中c^(ℓ)是第ℓ个ViT层的[CLS]表示，P^(ℓ) ∈ ℝ^(N_v×d_v)是其块（patch）表示。我们不依赖初始视觉令牌的隐式传播，而是显式地将每个LLM层连接到每个ViT层。具体而言，对于任意LLM层l=1,…,L，模型通过式(1)从{X_v^(ℓ)}_{ℓ=1}^{L_v}导出层特定的视觉表示Ẑ^(l)。这在视觉与语言层级之间实现了全对全连接集合：

E = {(ℓ, l) | ℓ=1,…,L_v, l=1,…,L}。 (3)

因此每个LLM层可以直接获取低级细节、中级结构和高级语义，而不是被锁定在单一视觉层或手工设计的稀疏路由模式上。

层特定表示Ẑ^(l)通过门控残差连接（在下文"令牌融合"段落中形式化）写回同一LLM层的视觉令牌段。重要的是，g^(l)(·)并非视觉层上的均匀平均：它由下文描述的动态门控通路模块实现，该模块自适应地控制每个ViT-LLM连接的强度。

3.2 动态门控通路模块

权重生成。 受现有概览令牌设计[41]启发，我们在每个多模态训练样本的第一个答案令牌之前紧邻前置一个可学习的概览令牌g ∈ ℝ^d。由于因果自回归结构，该令牌可以关注所有先前的视觉和文本上下文，因此充当总结当前解码深度的紧凑查询信号。设h_g^(l) ∈ ℝ^d为第l个LLM层中概览位置的隐藏状态；我们将其用作路由查询，Q^(l) = h_g^(l)。

对于每个ViT层ℓ，我们取其全局[CLS]表示c^(ℓ)作为层摘要：由于[CLS]已经在该层内聚合了整个图像，它提供了相应视觉粒度的紧凑层级描述符[12]。我们将所有L_v个摘要映射到LLM隐藏空间并堆叠成共享的键和值，K = V = Stack(c̃^(1),…,c̃^(L_v)) ∈ ℝ^(L_v×d)。

一个多头交叉注意力[35]模块——在所有LLM层之间共享——随后建模当前语言层状态与视觉层摘要之间的交互，产生路由特征：

r^(l) = MHA_shared(Q^(l), K, V) + Q^(l)， (4)

其中Q^(l)编码当前LLM层的多模态上下文，K、V总结所有候选视觉层；二者共同决定第l个LLM层应如何在ViT层级上分配连接强度。

以该路由特征为条件，第l个LLM层通过层特定——即不共享的——路由MLP在所有ViT层上产生路由分布：

ω^(l) = Softmax(W_2^(l)·Dropout(GELU(W_1^(l)·LN(r^(l)) + b_1^(l))) + b_2^(l)) ∈ ℝ^(L_v)， (5)

其中ω^(l) = (ω_1^(l),…,ω_{L_v}^(l))^T表示LLM层l在L_v个ViT层上的路由权重，且满足Σ_{k=1}^{L_v} ω_k^(l) = 1。W_1^(l) ∈ ℝ^(h×d)和b_1^(l) ∈ ℝ^h将路由特征从LLM隐藏空间映射到路由隐藏空间；W_2^(l) ∈ ℝ^(L_v×h)和b_2^(l) ∈ ℝ^(L_v)将其投影到L_v维logit，再由softmax转换为每层路由分布。简言之，MHA_shared为每个LLM层暴露相同的查询-摘要接口以在视觉层之间进行公平比较，而层特定路由MLP {W_1^(l), b_1^(l), W_2^(l), b_2^(l)}让每个LLM层表达自己对视觉层级的偏好。

令牌融合。 给定路由权重，我们逐位置融合来自不同视觉层的块特征：

p̃i^(l) = Σ{k=1}^{L_v} ω_k^(l)·p_i^(k)，i=1,…,N_v， (6)

其中p_i^(k) ∈ ℝ^(d_v)是来自第k个视觉层位置i的块，p̃i^(l) ∈ ℝ^(d_v)是第l个LLM层在该位置的聚合视觉特征。将这些向量按行堆叠得到P̃^(l) = [p̃_1^(l);…;p̃{N_v}^(l)] ∈ ℝ^(N_v×d_v)。然后逐行应用层特定投影器ρ_l: ℝ^(d_v)→ℝ^d，得Ẑ^(l) = ρ_l(P̃^(l)) ∈ ℝ^(N_v×d)，并通过门控残差连接将结果注入回视觉隐藏状态：

H̃_v^(l) = H_v^(l) + γ_l·Ẑ^(l)，γ_l = σ(a_l)， (7)

其中a_l是可学习标量，σ是sigmoid函数；门γ_l控制在当前层注入视觉信息的强度。

通过这些动态门控通路，视觉层级在每一层与LLM交互：视觉表示随解码深度演化，而不是由一次性固定注入预先确定。

3.3 训练目标

为防止路由分布坍缩到少数视觉层子集上，我们在标准自回归损失上增加一个轻量级熵正则化项，最大化每个LLM层上批次平均路由分布的熵：

L_total = −(1/|M|)·Σ_{t∈M} log p_θ(x_t | x_{<t}, {Ẑ^(l)}{l=1}^L) − λ·(1/L)·Σ{l=1}^L H(ω̄^(l))，H(p) = −Σ_{k=1}^{L_v} p_k·log p_k。 (8)

这里M表示有效监督位置集合，{Ẑ^(l)}{l=1}^L是注入LLM的每层融合视觉表示，ω̄^(l) = (ω̄_1^(l),…,ω̄{L_v}^(l))^T是LLM层l上批次平均的路由分布，H(·)是香农熵，λ≥0控制正则化强度。第二项奖励更高的熵，因此阻止坍缩到少数视觉层。遵循TGIF[23]，我们在预训练期间设λ=0.01，在指令微调期间设λ=0，使路由可以专门化到任务相关的视觉粒度。

4 实验

4.1 实验设置

实现细节与训练配方。 我们遵循LLaVA-1.5[25]训练配方，使用CLIP-ViT-L/14-336[32]作为视觉编码器，Vicuna作为LLM骨干。训练分两个阶段：在LLaVA-558K[25]上的预训练（PT）和在LLaVA-mixed-665K[25]上的监督微调（SFT）。由于DGP与每个LLM层的隐藏状态交互，两个阶段均联合优化LLM与新引入的DGP模块。视觉编码器全程保持冻结，每个阶段训练一个epoch。

所有超参数遵循LLaVA-1.5：AdamW与余弦调度（预热比例0.03），PT/SFT的批次大小为256/128，学习率为1×10⁻³/2×10⁻⁵。路由MLP使用1024的隐藏维度，残差门初始化为0.3。遵循TGIF[23]，熵正则化项在PT期间使用λ=0.01，在SFT期间禁用（λ=0）以便路由专门化。更多超参数敏感性结果见附录C。

基准。 我们在两套互补的多模态基准上评估。学术VQA涵盖GQA[15]、SciQA-IMG[29]、VQAv2[13]和VizWiz[14]。指令跟随/LMM基准涵盖SEED-Bench（SEED/SEED_I）[18]、LLaVA-Wild[27]、MM-Vet[40]、MMBench[28]和POPE[22]，共同探测多模态理解、细粒度感知和抗幻觉能力。

逐层门控通路分析。 为检查DGP实际学到什么，我们可视化每个LLM层在ViT层上的路由权重。图5(A)显示明显非均匀、层依赖的分布：DGP既不固定于最后一个ViT层，也不退化为均匀平均。中间ViT层被最频繁地激活，表明它们在局部结构和高级语义之间提供了有用的权衡。浅层和深层特征也被某些LLM层选择，证实模型根据其在解码中的位置动态触及不同的视觉粒度，而非依赖单一视觉层。

图5(B)放大代表性LLM层。它们的路由曲线在不同位置达到峰值：LLM层1偏好浅到中间ViT层，LLM层20倾向于浅层特征，而LLM层22和32分别在中间深层和深层ViT层达到峰值。曲线通常呈多峰而非单峰或平坦，表明DGP在每个LLM层选择性地组合多个视觉层，且不同LLM层根据其语言状态偏好不同的视觉粒度。这些可视化证实DGP发现了非均匀、动态的ViT-LLM连接模式，利用了视觉层级的互补性。

任务感知门控通路分析。 我们接下来探究路由是否也适应任务本身。图5(C)绘制了LLM层21跨基准的路由权重：每个基准诱导出不同的视觉层轮廓。LLaVA_W和VizWiz将更多权重分配给中间层特征，符合开放式问答和真实世界理解需要平衡对象级语义和局部视觉线索的需求，而SQA_I额外在浅层ViT层2上放置了可观的权重，反映科学推理所需的细粒度细节。图5(D)进一步下钻一层：即使在单一基准内，单个样本也表现出实质性的路由多样性，表明DGP的适应性超越基准级差异并在样本级起作用。

图6固定图像并改变问题。对于属性识别或小区域细节的问题，DGP激活浅层或浅到中间ViT特征——保留边缘、纹理和局部空间结构的层。对于更依赖全局语义或抽象推理的问题——绘画识别、历史意义、动作理解——路由权重峰值转而出现在中间深层或深层ViT层。对于"详细描述图像"等需要局部细节和整体语义的开放式问题，路由分布自然扩展为更宽的多峰形状，同时利用多个视觉层级。这些模式表明DGP的路由以LLM的逐层语言上下文和语义状态为动态条件，而非仅由固定的视觉层先验决定。

特征可视化。 图7比较了固定单层CLIP特征（L23）、所有24个ViT层上的均匀平均，以及DGP在不同LLM层产生的特征。CLIP（L23）产生粗糙的空间响应，背景中存在噪声激活；朴素平均融合引入多层信息，但由于不同语义粒度的特征未经选择地叠加，仍存在弥散响应和放大的局部噪声。DGP的LLM层特定特征则显示出明显更稳定的空间结构、更清晰的主题轮廓和更低的背景噪声，保留了勺子边缘和建筑边界等局部细节。关键的是，融合特征在LLM层1、18和28之间各不相同，证实DGP通过动态路由生成差异化的视觉表示，而非坍缩为固定的平均模式。总体而言，DGP在保持浅层和中间层线索完整的同时加强全局语义，缓解了固定单层特征的信息瓶颈和朴素平均的噪声累积。

5 结论

在这项工作中，我们围绕"在何处连接"问题重新构建MLLMs中的视觉信息注入，并论证固定单层输入或预定义稀疏/分层连接无法匹配分层ViT表示与逐层LLM语义的差异化需求。我们用DGP（动态门控通路）回答这一问题，这是一种全对全跨层连接机制，其中每个LLM层基于其当前语义状态自适应地门控其对每个ViT层的偏好，在每个解码深度按需整合多粒度视觉信息。DGP在广泛的多模态基准上带来一致增益，而路由分析和特征可视化表明它学习到可解释的、层依赖的连接模式，解释了增益的来源。

算法1 动态门控通路（DGP）

1: 输入图像 I ∈ ℝ^(H×W×3)，文本令牌 T ∈ ℝ^(N_t×d)
2: 具有L_v层的视觉编码器F(·)，具有L层的LLM
3: 共享交叉注意力MHA_shared，层特定路由MLP {MLP^(l)}{l=1}^L
4: 层特定投影器{ρ_l}{l=1}^L，门控标量{a_l}{l=1}^L
5: 可学习概览令牌g ∈ ℝ^d，层ID嵌入E_id ∈ ℝ^(L_v×d)
6: // 步骤1：视觉编码与特征缓存
7: {X_v^(ℓ)}{ℓ=1}^{L_v} ← F(I) ▷ 提取分层视觉特征
8: for ℓ = 1,…,L_v do
9: P^(ℓ) ← X_v^(ℓ)[:, 1:] ▷ 块特征：[B, N_v, d_v]
10: c^(ℓ) ← X_v^(ℓ)[:, 0] ▷ CLS令牌：[B, d_v]
11: c̃^(ℓ) ← Linear(LN(c^(ℓ))) ▷ 将CLS投影到LLM空间：[B, d]
12: end for
13: K = V ← Stack(c̃^(1),…,c̃^(L_v)) + E_id ▷ 带层ID的CLS摘要：[B, L_v, d]
14: // 步骤2：初始视觉令牌注入
15: V_0 ← mm_projector(P^(L_v−1)) ▷ 倒数第二层块到LLM空间：[B, N_v, d]
16: H^(0) ← Concat(V_0, T, g) ▷ 多模态输入序列
17: // 步骤3：逐层动态门控通路注入
18: for l = 1,…,L do
19: h_g^(l) ← H^(l−1)[glimpse_pos] ▷ 概览隐藏状态：[B, 1, d]
20: Q^(l) ← h_g^(l) ▷ 路由查询（如方法部分所述）
21: r^(l) ← MHA_shared(Q^(l), K, V) + Q^(l) ▷ 带残差的交叉注意力
22: ω^(l) ← Softmax(MLP^(l)(LN(r^(l)))) ▷ 路由权重：[B, L_v]
23: P̃^(l) ← Σ_{k=1}^{L_v} ω_k^(l)·P^(k) ▷ 加权块融合：[B, N_v, d_v]
24: Ẑ^(l) ← ρ_l(P̃^(l)) ▷ 投影到LLM空间：[B, N_v, d]
25: γ_l ← σ(a_l) ▷ 门控系数
26: H̃_v^(l−1) ← H_v^(l−1) + γ_l·Ẑ^(l) ▷ 门控残差注入（方法部分式(7)）
27: H^(l) ← LLMLayer_l(H^(l−1)，其中H_v^(l−1) ← H̃_v^(l−1)) ▷ 带注入视觉段的前向传播
28: end for

附录C 超参数敏感性分析

熵正则化系数λ。 熵正则化项阻止路由坍缩到少数视觉层子集。我们采用与TGIF[23]相同的阶段性调度：预训练期间λ=0.01以鼓励跨层探索，监督微调期间无熵正则化（等价于λ=0）以便路由专门化到下游任务。

路由MLP隐藏维度h。 路由MLP将4096维路由特征映射到24维层权重分布。为平衡表达能力和计算效率，我们将中间隐藏维度设为h=1024，与ViT隐藏维度对齐。该设计确保路由网络具有足够的非线性建模能力，同时避免使用完整LLM维度（4096）带来的额外计算开销。

门控初始化γ_init。 门控系数γ_l = σ(a_l)控制第l层视觉信息的注入强度，其中a_l是可学习标量。我们使用默认门控初始化γ_init=0.3，并将门学习率设为5×10⁻³。过小的初始化值导致视觉注入不足，使模型退化为纯语言模型行为；过大的初始化值可能在早期训练中引入过多噪声，影响收敛稳定性。表8显示不同初始化值对性能的影响。

附录F 局限性与未来工作

动态门控通路模块被设计为即插即用：它仅引入与LLM隐藏状态接口的轻量级逐层路由组件，而不修改视觉编码器或LLM架构本身。这种模块化表明DGP应在视觉编码器和LLM骨干之间泛化，无论特定的编码器-解码器配对如何，均可自适应地选择适当的视觉粒度。

在这项工作中，我们主要在LLaVA-1.5设置（CLIP + Vicuna-7B/13B）下验证DGP，并进一步在较小规模的替代框架上验证，包括Qwen3-VL-2B（SigLIP2 + Qwen3-1.7B）和LLaVA-NeXT（AnyRes切分）。然而，由于资源和时间限制，在更大LLM（30B+）、更广泛的视觉编码器家族和更大规模多模态语料库上的实验仍然有限。沿这些轴扩展验证构成我们主要的未来工作。我们预期动态路由机制将保持有效——并可能更有益——随着模型容量和数据规模增加，因为更丰富的语言表示应能实现更细粒度的视觉层选择。

附录G 更广泛的影响

这项工作改善了MLLMs中的分层视觉访问，可能有益于无障碍工具和教育助手等应用。同时，更强的视觉推理可能被滥用于监视或误导性内容，且DGP可能继承其微调所基于的预训练视觉和语言骨干的偏见。因此，我们将DGP视为在宿主模型的许可和安全实践下用于研究的架构改进。
