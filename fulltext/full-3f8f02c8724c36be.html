摘要

药物错误，尤其是临床试验（CT）中的剂量错误，可能导致患者伤害、不良药物事件以及更差的患者预后。剂量错误是可以预防的，早期识别可以提高试验的完整性并减轻后续的临床和经济负担。本研究旨在通过使用在生物医学语料库上训练的基于Transformer的语言模型评估试验信息的文本表示，来检测CT方案中的剂量错误。CT文本数据使用多种模型进行编码，包括ClinicalBERT、PubMedBERT、BioBERT和MedCPT，并与分类特征整合。这些文本嵌入作为经典机器学习模型和神经网络架构的输入，在实验框架中进行评估。性能主要通过ROC-AUC评估，以预测剂量错误。在逻辑回归基线下，BioBERT始终优于其他编码器，达到0.794的ROC-AUC，比ClinicalBERT基线提高了3.95%。组合多个嵌入并未带来改善，表明领域对齐比表示堆叠更为重要。梯度提升模型、支持向量分类器、逻辑回归和残差神经网络在预测剂量错误方面取得了最强的性能，ROC-AUC范围为0.821至0.853。总体而言，将领域特定Transformer嵌入与结构化元数据相结合，能够区分满足预定义高剂量错误风险标准的试验，推进安全监测并支持知情的监管决策。

关键词：
药物错误，临床试验，剂量错误，Transformer模型，自然语言处理（NLP），机器学习

摘要内容

1. 引言

临床试验提供了评估新型药物化合物在人群中的安全性和有效性所需的结构化和严格控制的框架。然而，这一过程既昂贵又不确定。尽管在每个阶段都有大量财务投资，但进入临床试验的化合物中只有14%最终获得监管批准（Wong等人，2019）。I期试验的中位成本估计为340万美元，II期为860万美元，III期为2140万美元（Martin等人，2017）。

除了财务风险外，试验方案本身具有内在的复杂性，涉及众多交互变量、多个治疗组以及严格的程序约束。这种复杂性增加了操作和方法学错误的可能性，可能损害统计有效性、延迟开发时间表或完全使研究结果无效，导致资源浪费和治疗机会的丧失（Buyse等人，2017；Berger和Alperson，2009）。

药物错误是药物治疗过程中的非预期失败，导致或有可能导致患者伤害（欧洲药品管理局，2026）。这些错误可能包括：给药时间不正确、剂量不正确、额外的非预期给药或不适当的给药速率（Tariq等人，2024），以及随机化、盲法和更广泛的实验设计中的错误（Berger和Alperson，2009）。药物错误仍然是临床环境中不良患者结果中最常见但可预防的原因之一（Tariq等人，2024）。在临床环境中发生的药物错误同样可能在临床试验中出现。临床试验期间的药物错误可能导致试验效果降低、严重毒性、患者安全受损、不良药物事件，还可能对临床试验结果的内部有效性和可解释性构成威胁（欧洲药品管理局，2026）。

鉴于与新化合物错误批准决策相关的重大后果，在整个临床试验过程中进行严格监测和统计稳健的评估至关重要。美国食品药品监督管理局（FDA）和欧洲药品管理局（EMA）等监管机构强调，由于剂量错误可能导致公共卫生负担，在临床试验期间主动识别、监测和减轻剂量错误的重要性（Stewart，2021）。此外，及时识别临床试验中的剂量错误可以通过促进更早地纠正或终止无效研究来降低财务成本和患者风险（Rim等人，2024）。

然而，临床试验文件通常由大量非结构化文本数据组成，使得提取相关方法学细节既耗时又具挑战性（Chen等人，2020）。这使试验完整性的验证变得复杂，特别是在各研究组和队列的正确剂量和给药方案方面。临床试验报告和方案中非结构化文本文档的主导地位，凸显了对能够系统提取和验证关键方法学细节的自动化方法的需求。

在医学领域，特别是在评估临床报告时，自然语言处理（NLP）提供了一种可扩展的方法，用于识别和结构化嵌入在叙述性临床文本中的相关信息。自然语言处理是计算机科学和人工智能的一个子领域，它允许计算机和数字设备识别和理解文本和语音数据（IBM，2026）。除了从文本中提取信息外，NLP技术还支持下游分析任务，如诊断解释、疾病进展建模和治疗有效性评估。机器学习的最新进展推动了日益复杂的NLP算法的发展，在信息提取和摘要方面有广泛应用（Khurana等人，2023）。NLP领域的这些发展特别与医学文档相关，因为从医学实践和研究中产生的临床笔记和报告通常以大量非结构化文本的形式出现。NLP方法已在医学领域的某些用例中得到应用，包括：提取剂量信息和给药方案（Lu等人，2016；McNeer等人，2019），识别临床和治疗事件（Bitterman等人，2023），以及检测不良药物事件和反应（Murphy等人，2023；Naderian等人，2024）。最近的研究还调查了这些NLP方法在临床试验背景下的具体应用，包括：自动化报告起草、提取药物-药物相互作用（DDI）和优化CT方案设计（Chopard等人，2021；Kuo等人，2025；Lee等人，2024；Zhu等人，2020）。

基于Transformer的语言模型的快速扩散显著推进了NLP研究（Kalyan等人，2021；Patwardhan等人，2023）。这些模型利用自监督学习和注意力机制，从大量未标记文本语料库中学习特征丰富的通用表示。由于在大规模数据上进行了广泛的预训练，只需相对少量的任务特定数据即可在下游任务上实现强大的性能，因为每个模型中的预训练参数已经编码了从训练语料库中衍生的大量语言和语义结构。

在预训练期间，Transformer架构学习输入文本的上下文化表示，在固定长度的数值嵌入中捕获语义和句法关系。由于其在通用领域NLP中的成功，这些模型越来越多地应用于医学领域，涵盖问答、命名实体识别（NER）、文本摘要、分类和情感分析等任务（Nerella等人，2024；Cho等人，2024）。

最近，研究调查了在生物医学语料库（如PubMed摘要和Mayo Clinic电子健康记录）上进行领域特定预训练是否能进一步提高医学环境中的性能（Wang等人，2018）。实证结果表明，主要在医学文本语料库上预训练的模型在临床任务上取得更优的结果（Wang等人，2018）。接触专业临床术语和领域特定词汇提高了表示精度，而反复接触临床叙述使模型能够隐式地捕获医学文档的结构模式。此外，领域对齐的预训练减少了预训练数据和下游数据之间的分布偏移，提高了鲁棒性和样本效率。这在临床环境中尤为重要，因为标注数据集稀缺、制作成本高或范围有限。

预训练Transformer模型在NER任务中的强大性能使得可靠提取关键临床实体成为可能，包括疾病、药物、程序和干预属性。这种能力对于临床试验分析尤为相关，因为实验设计元素（如研究组、干预类型和剂量方案）经常以非结构化文本的形式记录。在临床试验背景下应用预训练Transformer模型已经取得了一些成功，包括与以下相关的任务：提取结果和组信息（Whitton和Hunter，2023），区分不良事件报告（Chopard等人，2021），以及提取药物-药物相互作用（Zhu等人，2020）。然而，尽管有这些最新进展，获取大型公开可用的临床试验数据集仍然有限，限制了大规模实验和假设检验（Navar等人，2016）。最近的倡议如TrialBench试图通过多模态数据集构建和临床试验预测任务的标准化基线来填补这一空白（Chen等人，2025）。

因此，基于Transformer的模型为结构化和验证嵌入在临床试验文档中的关键方法学信息提供了可扩展的框架。作为本研究项目的一部分，作者调查了在生物医学文本语料库上预训练的各种基于Transformer的模型的适用性，以编码与每个临床试验相关的文本信息，并使机器学习模型能够预测特定临床试验在其方法中是否包含剂量错误。

2. 方法

2.1. 数据集和问题定义

作为CT-DEB'26挑战赛（从临床试验中检测剂量错误）的一部分（Ferdowsi等人，2026），生成了一个数据集（Hêche等人，2026），包含从ClinicalTrials.gov网站收集的大量不同临床试验（以英语编写）的结构化和非结构化信息（U.S. National Library of Medicine, 2026）。每一行对应一项临床试验研究，包括长文本字段以及与每个特定试验相关的若干数值和分类变量。作为数据集构建过程的一部分，生成了一个二元标签：如果剂量错误率的95% Wilson置信区间下限超过0.01%，则分配标签1（Ferdowsi等人，2026；Hêche等人，2026）。

本研究的目标是比较几种预训练生物医学模型用于编码文本特征，并开发和评估能够预测哪些临床试验满足此高剂量错误风险标准的机器学习模型（包括经典模型和神经网络）。该研究系统评估了不同特征子集、文本数据的替代输入表示以及不同模型架构对预测性能的影响。

鉴于存在大量非结构化文本，需要将文本数据转换为机器可读的表示。为此，评估了几种预训练的基于Transformer的模型，包括ClinicalBERT（Huang等人，2020）、BioBERT（Lee等人，2020）、PubMedBERT（Gu等人，2021）和MedCPT（Jin等人，2023）。这些在大规模生物医学语料库上预训练的模型可以生成捕获领域特定语义信息的输入文本上下文化向量表示。所得嵌入用作下游机器学习分类器的输入特征，包括传统机器学习模型以及更先进的神经网络。在整个研究过程中应用了受控的实验框架，每次修改一个变量同时保持其他变量不变，以隔离实验变化的个体效应。遵循标准机器学习实践，使用单独的数据子集分析每个模型的预测性能，以防止因向模型展示其在训练过程中已见过的数据而产生偏差。

数据集以两个独立的子集提供：包含29,478个数据点的训练数据集和包含6,316个数据点的保留验证数据集。每个数据集包含以下列：
phases, enrollmentCount, allocation, interventionModel, primaryPurpose, masking, healthyVolunteers, sex, oversightHasDmc, briefSummary, detailedDescription, conditions, conditionsKeywords, protocolPdfText, numArms, armDescriptions, armGroupTypes, numInterventions, interventionTypes, interventionDescriptions, interventionNames, numLocations, locationDetails, target, nctid。

数据集变量的详细描述可在附录A.1中找到。

数据集包含分类变量、数值变量和自由文本变量的混合，每个变量都与特定的临床试验相关。

在最终建模管道中，文本特征（briefSummary、detailedDescription、armDescriptions和interventionDescriptions）使用BioBERT嵌入进行编码。结构化分类变量（包括分配方法、干预模型、主要目的、oversightHasDmc和试验阶段）进行独热编码并与文本嵌入拼接。连续数值变量（如enrollmentCount、numArms和numLocations）未包含在最终模型中。numArms变量与目标变量之间表现出较弱的统计关联，而enrollmentCount和numLocations被认为不太可能在已纳入的结构化和文本特征之外提供有意义的预测信号。

protocolPdfText字段由于数据稀疏性较大和长度极端变化而未被纳入建模管道。在训练集中，81.3%的记录（29,478条中的23,963条）不包含提取的PDF文本，而验证集中只有3.2%的记录为空。这种不平衡引起了担忧，即模型可能隐式地将非空PDF文本的存在作为数据集分区的代理，从而引入分布偏差。此外，当protocolPdfText字段中有数据时，提取的方案文本非常长（训练集最大值：11,298,927个字符；验证集最大值：6,424,120个字符），分布高度偏斜且标准差非常大。在固定的Transformer上下文窗口内编码如此长的文档需要大量截断，可能丢弃大部分内容并在样本间引入不一致的表示质量。鉴于训练数据中缺失条目的高比例、处理超长文档的巨大计算负担以及通过严重截断的表示引入噪声的风险，该特征被排除在最终实验之外。

由于本研究的主要目标是评估预训练生物医学语言模型在编码非结构化临床试验文档方面的比较有效性，建模框架旨在隔离文本表示的贡献。因此，嵌入旁边仅包含分类结构化特征，排除了连续数值变量。

2.2. 实验研究概述

采用了迭代和受控的实验框架。在每个阶段，仅修改一个变量或建模组件，同时保持所有其他元素不变。这使得能够隔离单个设计决策对预测性能的影响。

实验过程分两个主要阶段进行：
阶段1：文本编码方法和特征选择的迭代
阶段2：模型架构和训练过程的迭代

2.2.1. 阶段1：文本编码和特征重要性

分类特征分析： 初始实验采用逻辑回归分类器作为基线模型。使用这一固定架构，研究评估了纳入独热编码分类变量的增量影响。使用卡方检验和Cramér's V统计量评估分类特征与目标变量之间的关联。重要的是，这些统计分析仅在训练数据上进行，以防止信息泄露，确保验证集在特征选择和模型评估期间保持完全未见，从而对模型在未见数据上的性能进行无偏报告。

通过逐步添加单个特征进行消融研究，以衡量其对预测性能的贡献。分类特征的选择主要基于与目标特征的统计显著性。

使用预训练Transformer模型进行文本编码： 鉴于存在大量非结构化文本，评估了多种预训练生物医学Transformer编码器，为以下文本列生成上下文嵌入："简要摘要"、"详细描述"、"组描述"、"干预描述"。比较了以下编码器：ClinicalBERT、PubMedBERT、BioBERT、MedCPT，以及多种编码器的组合。每个Transformer模型的简要描述如下：

  • BioBERT 是一个领域特定语言模型，在大规模生物医学文献上预训练，包括PubMed摘要和PubMed Central全文文章，使其能够捕获临床文本中的生物医学术语和上下文关系（Lee等人，2020）。
  • ClinicalBERT 是一个基于BERT的模型，在MIMIC-III数据库的重症监护病房记录中的临床笔记上预训练，使其非常适合临床叙述理解任务（Huang等人，2020）。
  • MedCPT 是一个基于对比学习的生物医学语言模型，在PubMed的2.55亿用户点击日志上训练，旨在为零样本生物医学信息检索产生高质量语义嵌入（Jin等人，2023）。
  • PubMedBERT 是一个仅在PubMed摘要上从头预训练的语言模型，没有通用领域预训练，使其能够开发专门针对生物医学文本优化的词汇和表示（Gu等人，2021）。

每个预训练编码器为文本字段生成固定长度的向量表示。选择256个token的最大序列长度作为上下文覆盖和计算效率之间的实际折衷。使用BioBERT分词器进行的token级分析（见附录A.2）表明，在此约束下，被截断条目的比例为：briefSummary 8.65%，detailedDescription 31.81%，armDescriptions 7.79%，interventionDescriptions 4.03%。值得注意的是，detailedDescription字段包含大量空条目——训练集中39.4%（29,478行中的11,604行），验证集中34.6%（6,316行中的2,187行），这降低了该字段的有效截断影响。总体而言，briefSummary、armDescriptions和interventionDescriptions中超过90%的条目在256个token限制内被完全保留；detailedDescription的截断率较高（31.81%），但很大一部分条目为空。在所有文本字段中应用统一的最大token长度，以确保编码管道内的一致性。虽然增加上下文窗口可能允许捕获额外的长程信息（特别是对于detailedDescription字段），但这将大幅增加计算成本和内存需求。因此，所选限制反映了表示完整性和实际可行性之间的权衡。

通过对每个模型生成的token级表示进行平均池化获得句子级嵌入。然后将这些嵌入用作下游逻辑回归分类器的输入特征，该分类器学习将数值向量表示映射到二元剂量错误标签。比较实验评估了不同预训练编码器对验证ROC-AUC性能的影响。BioBERT取得了最强的结果，因此被选为后续实验的主要文本编码器。

2.2.2. 阶段2：模型架构和训练过程的迭代

基于统计分析和领域知识选择了最终的输入特征集，将所有文本字段的BioBERT嵌入与独热编码的分类特征（具体为：干预模型、分配类型、监督、主要目的、阶段）相结合。这些特征为模型在确定特定临床试验中发生剂量错误的概率是否超过定义阈值方面提供了最具判别性的预测能力。

由于数据集表现出显著的类别不平衡（约95.4%的训练记录标记为无剂量错误——29,478个数据点中的28,126个），有必要研究减轻这种严重不平衡的方法。一系列实验评估了训练期间改变类别权重的影响。通过改变类别权重，我们可以指示机器学习模型在训练过程中对某一类别的示例赋予更大的重要性。这些实验包括以下阶段：无权重（所有示例赋予相同重要性）、固定权重比（1:5、1:10、1:20）偏向少数类，以及基于数据集中每个元素的比例量自动计算类别权重（对于0和1剂量错误变量，权重分别约为0.5:11）。

一旦固定了最终输入特征集并确定了最佳类别权重，就进行了若干实验以改变用于进行预测的机器学习模型类型，从而改变模型从输入数据中学习的方式。这些模型包括经典机器学习模型和更先进的神经网络架构。所检查的经典机器学习模型包括：逻辑回归、线性支持向量分类器、支持向量分类器、K近邻分类器、朴素贝叶斯、决策树、XGBoost和LightGBM。由于Transformer嵌入的高维度，一些经典模型遇到了收敛或计算限制。比较评估确定逻辑回归、SVC变体以及梯度提升模型为最强的经典基线。对表现最佳的模型使用GridSearch进行超参数优化，以识别提供最佳预测能力的模型参数组合。

在评估经典机器学习模型之后，探索了多种神经网络架构：简单多层感知器（MLP）、宽多层感知器、残差神经网络（带跳跃连接）、文本塔架构（文本和分类特征的独立处理流，在神经网络的后续部分合并）。各种神经网络架构的具体实现细节可在附录A.6中找到。

使用一致的特征表示和固定其他神经网络训练参数（如损失函数、优化器、学习率、训练轮次）分析神经网络架构之间的性能差异。在神经网络模型研究的后期阶段，一旦确定了最佳性能架构，就进一步优化了训练过程本身。这包括以下方法：基于验证ROC-AUC的早停、学习率调度（ReduceLROnPlateau、OneCycleLR）、损失函数比较（二元交叉熵vs焦点损失）以及模型检查点保存以保留针对验证数据的最佳参数。这些实验旨在优化模型训练期间的收敛行为并减少对训练数据的过拟合。所有模型都在保留的验证数据上进行评估，以评估在未见数据上的泛化性能。主要评估指标为ROC-AUC，次要指标用于表征类别不平衡条件下的性能。

未对神经网络模型进行广泛的超参数优化。相反，架构的构建旨在代表常见且实际相关的结构变化，如宽网络、残差连接和门控文本塔，而不是对每种配置进行详尽调优以获得最大性能。虽然更全面的优化可能会提高绝对预测性能，但这超出了本研究的范围。因此，报告的结果反映了受控和代表性的配置，旨在实现跨建模方法的公平和一致比较。

2.2.3. 阶段3：最终建模

在识别出最强性能的经典模型和神经网络架构后，进行了最终评估阶段以获得更稳健的预测性能估计。将原始训练和验证数据集合并，并应用分层k折（k=5）交叉验证以创建唯一的数据子集，同时保持每折中阳性和阴性病例的整体比例。

在每次迭代中，模型在四折上训练并在剩余一折上评估，产生五组独立的性能指标。平均这些结果通过减少对任何单一训练-验证分区的依赖来提供更可靠的泛化性能估计。分层进一步确保类别不平衡在各折中得到一致表示，从而限制由不均匀类别分布引起的变异性，并产生更稳定和无偏的模型性能评估。

BioBERT表现出最强的单个编码器性能，在逻辑回归下对验证集实现了0.794的ROC-AUC，而PubMedBERT为0.775，MedCPT为0.789，ClinicalBERT为0.764（见图1）。这与BioBERT的设计一致，它在大规模生物医学文献上预训练，包括PubMed摘要和PMC全文文章，使其能够捕获与临床试验干预描述相关的领域特定语言模式。如图2所示，与ClinicalBERT基线编码方法相比，BioBERT在ROC-AUC上显示出接近4%的改进。ClinicalBERT虽然在重症监护病房记录的临床笔记上预训练，但可能不太适合ClinicalTrials.gov记录特有的结构化方案语言（Alsentzer等人，2019）。更先进的模型架构，包括XGBoost、LightGBM和残差神经网络，在使用BioBERT嵌入时取得了更强的预测性能，ROC-AUC值范围为0.821至0.832。这些结果表明，这些模型具有从BioBERT向量表示中学习的增强能力，并提高了识别满足预定义高剂量错误风险阈值的试验的判别能力。

与组合多个编码器将产生累加增益的初始预期相反，逻辑回归下的结果显示，组合的四编码器表示（ROC-AUC：0.764）的表现不如单独使用BioBERT，与ClinicalBERT基线相比ROC-AUC差异最小。这表明当下游模型缺乏足够的能力来利用高维拼接表示时，额外的编码器可能引入噪声而非补充判别能力。更先进的梯度提升模型和神经网络可能能够更好地同时利用多个编码器的文本编码来提升预测能力，但这一主题未作为本研究的一部分进行严格检验。

3.2. 分类特征重要性结果

纳入独热编码的分类特征持续改善了模型性能。结合卡方检验和Cramér's V的统计分析确定，interventionModel（χ²=219.13, p<0.001）、allocation（χ²=90.88, p<0.001）和oversightHasDmc（χ²=76.83, p<0.001）是剂量错误发生的最具统计学显著性的预测因子。从临床角度来看，这是直观的：交叉和析因干预设计涉及更复杂的剂量方案和治疗组之间的转换，与更简单的平行或单组设计相比，增加了剂量错误的程序风险（England等人，2020）。类似地，缺乏数据监测委员会可能反映了监督基础设施的减少，如先前工作所示，这与临床试验中更高的方案偏离率和不良事件率相关（Stewart，2021）。

尽管分类特征"主要目的"和"试验阶段"未达到对剂量错误目标特征影响的统计显著性阈值，但领域知识支持将其纳入。它们的添加在若干模型配置中产生了改进，并且似乎没有主动降低预测能力，因此被纳入后续实验。这反映了临床预测任务中特征选择的更广泛挑战，即统计显著性并不总是与机器学习模型的预测能力一致。

3.3. 类别权重结果

本研究中一个重要的方法学挑战是数据集内显著的类别不平衡，约95.4%的训练记录标记为0（29,478条中的28,126条），表明这些临床试验的剂量错误率的95% Wilson置信区间下限未超过预定义阈值。这种分布反映了临床试验注册中正式报告的剂量错误在现实世界中的罕见性，其中药物错误已知被系统性低报（Delavoipière等人，2021）。此外，使用ROC-AUC作为评估指标在高度不平衡的应用中可能具有误导性，因为强性能可能仍然伴随着较差的少数类检测（Imani等人，2026）。为解决这一问题，纳入了额外的评估指标，包括精确率、召回率和平衡准确率，以确保模型有意义地识别剂量错误可能性超过定义阈值的情况，而不是默认为多数类预测。

当使用逻辑回归等较简单的机器学习模型时，改变少数类的类别权重对逻辑回归性能没有有意义的影响，在所有权重策略中，验证集的ROC-AUC保持在狭窄范围内（0.791–0.798）（均值：0.795，标准差0.003）。这表明重新加权并未实质性地改变关于ROC-AUC的基于排名的判别性能。替代方法，如对少数类进行上采样，可能会潜在地提高敏感性；然而，这在当前研究中未进行探索。在医学环境中，合成或重复采样策略必须谨慎应用，因为它们可能引入过拟合、扭曲临床有意义的分布，或在罕见但异质的病例中放大噪声。

与逻辑回归相比，神经网络在应用类别权重时表现出改善的剂量错误预测能力，ROC-AUC从0.806（无权重）增加到使用基于训练数据中每个类别示例比例自动计算的类别权重时的0.838。这表明神经架构对不平衡感知训练更敏感，在不牺牲整体判别性能的情况下提高了检测少数类实例（剂量错误概率超过定义阈值）的能力（在应用类别权重的实验中，均值：0.835，标准差0.002）。

3.4. 经典ML模型比较结果

如图3所示，在验证集上以ROC-AUC衡量的最强判别性能由LightGBM、XGBoost、校准支持向量分类器（SVC）和逻辑回归实现。这些模型始终优于K近邻和决策树等较简单的方法，表明良好正则化的线性决策边界或梯度提升集成方法特别适合由基于Transformer的文本嵌入与分类变量结合产生的高维特征空间。

经过轻度超参数优化后，LightGBM使用num_leaves = 31、max_depth = 8、learning_rate = 0.05和min_child_samples = 50实现了0.831的验证ROC-AUC。逻辑回归使用L2惩罚和正则化强度C=0.1以及"平衡"类别权重实现了0.812的验证ROC-AUC。校准SVC使用C=1、γ=0.001和RBF核实现了0.831的交叉验证ROC-AUC。这些发现表明，基于集成的方法和正则化的基于间隔的分类器都能有效利用领域特定Transformer编码器生成的语义表示。

值得注意的是，基于树的提升方法和校准线性模型都取得了相当的预测性能，表明在不一定增加架构复杂性的情况下就能获得实质性增益。从实际角度来看，逻辑回归在可解释性方面提供了额外优势。学习到的系数直接估计了特征对预测剂量错误概率的贡献，使得能够透明地检查有影响的变量。当与L1正则化或具有非零L1比率的弹性网络正则化结合时，模型通过将信息量较小的系数收缩为零来促进稀疏性。这促进了特征选择，降低了模型复杂性，并增强了可解释性——这是在模型透明度和决策论证至关重要的临床和监管环境中的重要考虑因素。

3.6. 交叉验证后的结果

通过GridSearch进行模型选择和超参数优化后（仅应用于经典ML模型，具体GridSearch参数见附录A.4），使用分层k折交叉验证（k=5）在合并的训练和验证数据集上进行了最终评估。完整的折级结果报告在附录A.5中。

轻梯度提升模型、校准SVC模型和文本塔神经网络在所有折中都表现出更强和更稳定的判别能力。对于这些模型，分层五折交叉验证下的性能与之前的训练-验证一致，表明在采样分割间的稳定性。校准SVC实现了0.841（±0.007）的平均ROC-AUC，LightGBM实现了0.836（±0.010），文本塔神经网络实现了0.831（±0.012）。

各折间相对较低的标准差表明对采样变异性的鲁棒性，表明这些模型在数据集的不同子集上泛化一致。尽管校准SVC实现了最高的ROC-AUC，但其在默认决策阈值0.5下的召回率仍然较低，反映了在此操作点下保守的阳性类预测。

在比较分层k折（k=5）交叉验证数据分割的性能与使用提供的训练-验证分割训练的结果时，逻辑回归模型在交叉验证下的平均ROC-AUC有所下降。逻辑回归实现了0.732（±0.006）的平均ROC-AUC。这种下降表明，之前在初始训练和验证集上的性能可能由于数据分区变化而产生偏差。特别是，降低的性能表明这种方法可能更依赖于数据中特定于折的结构，导致在多个分层分割上评估时泛化能力较低。

所有分类指标均使用固定的0.5概率阈值计算，以确保模型间的一致性。鉴于数据集中显著的类别不平衡，该阈值可能不是最大化精确率和召回率之间临床有意义权衡的最佳选择。在实践中，基于应用特定优先级（例如，优先考虑早期风险检测的敏感性）的阈值调优可以进一步改善精确率、召回率和平衡准确率，而不会改变ROC-AUC衡量的底层排名性能。

总体而言，交叉验证结果提供了更可靠的模型泛化性能估计，并突出了校准SVC和基于文本的神经架构在此任务中的相对鲁棒性。

3.7. 发现总结

本研究评估了基于Transformer的生物医学文本嵌入与结构化分类特征相结合，用于预测剂量错误概率超过定义阈值的临床试验方案。模型性能主要通过ROC-AUC评估，次要指标包括F1-macro、精确率、召回率和平衡准确率。在所有实验中，BioBERT作为独立编码器使用时始终优于其他生物医学语言模型。此外，组合多个预训练编码器未产生累加增益，表明领域对齐比表示堆叠更重要。在文本嵌入旁边纳入结构化分类试验设计变量改善了跨模型类别的预测性能。

在所评估的方法中，残差神经网络、校准支持向量分类器和轻梯度提升在交叉验证下实现了最强和最稳定的性能，而梯度提升模型以更低的计算成本取得了有竞争力的结果。显式处理类别不平衡对于获得有意义的少数类召回是必要的。这些发现突出了领域特定预训练和仔细模型选择在高度不平衡临床预测任务中的重要性。

4. 结论

本工作表明，领域特定Transformer嵌入，特别是BioBERT，为建模非结构化临床试验文档提供了高效的表示。当与结构化试验元数据整合时，这些嵌入能够可靠地判别估计剂量错误概率超过预定义阈值的试验。

结果表明，编码器-领域对齐在预测性能中发挥的作用比增加架构复杂性或组合多个预训练表示更大。虽然神经架构取得了强大的性能，但梯度提升方法以更高的可解释性和更低的计算成本提供了有竞争力的判别能力，使其成为在透明性至关重要的监管或治理环境中部署的有吸引力的候选者。

未来研究可探索针对特定临床优先级定制的阈值优化策略、应用模型可解释性技术识别高风险方案元素，以及将此框架扩展到剂量错误类型的多类预测。纳入额外的数据源（如不良事件报告或电子健康记录）可进一步增强现实世界的适用性并支持主动安全监测。

5. 局限性

首先，计算约束阻止了对具有更多参数的语言模型的评估，如BioGPT（Luo等人，2022）和SciFive（Phan等人，2021）。这些模型的编码可能产生更强的临床试验方案文本语义表示。其次，二元目标变量将不同严重程度和类型的剂量错误合并为单一标签，限制了预测的粒度。未来的工作可以探索区分错误类型（如不正确剂量、不正确频率和遗漏错误）的多类表述，如先前工作中的分类（England等人，2020）。第三，数据集完全来自ClinicalTrials.gov注册库，该注册库捕获结构化方案信息，但可能不反映补充方案文件或内部试验管理系统中描述的剂量程序的完整复杂性。如先前工作所述（Navar等人，2016），注册数据受到选择性报告和不一致文档实践的影响。

最后，虽然可以从XGBoost和LightGBM中提取特征重要性分数，但解释方案描述中哪些特定文本模式驱动预测仍然是一个开放挑战，值得使用SHAP值或基于注意力的可视化等可解释性技术进行进一步研究。此外，由于神经网络内部学习过程的"黑箱"性质，神经网络模型在结果可解释性方面存在困难。

def build_binary_classifier_skip_layers(input_dim):
    inputs = layers.Input(shape=(input_dim,))
    # 第一块
    x = layers.Dense(512, activation="relu", kernel_regularizer=keras.regularizers.l2(0.001))(inputs)
    x = layers.BatchNormalization()(x)
    x = layers.Dropout(0.4)(x)

    x2 = layers.BatchNormalization()(x2)
    x2 = layers.Dropout(0.3)(x2)
    # 第三块
    x3 = layers.Dense(128, activation="relu", kernel_regularizer=keras.regularizers.l2(0.001))(x2)
    x3 = layers.BatchNormalization()(x3)
    x3 = layers.Dropout(0.2)(x3)

    x2_pooled = layers.Dense(64, activation="relu")(x2)

    x = layers.Dropout(0.2)(x)

def build_single_input_text_cat_fusion_model(
    input_dim: int,
    text_embedding_dim: int = 768,
    num_text_fields: int = 4,
    num_cat_features: int | None = None,
    # 如果为None，则推断为 input_dim - num_text_fields*text_embedding_dim
    text_proj_dim: int = 192,
    cat_proj_dim: int = 64,
    hidden_dim: int = 128,
    dropout_rate: float = 0.2,
    l2_strength: float = 1e-4,
    use_gating: bool = True,
):
    """
    单输入模型：期望输入向量形状为 (batch, input_dim)
    布局：[text1(768) | text2(768) | text3(768) | text4(768) | cat_features(…)]
    """
    l2 = keras.regularizers.l2(l2_strength)
    if num_cat_features is None:
        num_cat_features = input_dim - (num_text_fields * text_embedding_dim)
    if num_cat_features < 0:
        raise ValueError(
            f"input_dim={input_dim} is smaller than {num_text_fields}*{text_embedding_dim}="
            f"{num_text_fields*text_embedding_dim}"
        )
    inputs = layers.Input(shape=(input_dim,), name="flat_input")
    # —- 将平坦向量切片为块 —-
    def slice_block(start_idx, end_idx, name):
        return layers.Lambda(lambda x: x[:, start_idx:end_idx], name=name)(inputs)
    text_blocks = []
    for i in range(num_text_fields):
        start = i * text_embedding_dim
        end = start + text_embedding_dim
        text_blocks.append(slice_block(start, end, name=f"text_{i+1}_slice"))
    cat_start = num_text_fields * text_embedding_dim
    cat_end = cat_start + num_cat_features
    cat_block = slice_block(cat_start, cat_end, name="cat_slice")
    # —- 每个文本字段的塔 —-
    text_reprs = []
    for i, t in enumerate(text_blocks):
        x = layers.LayerNormalization(name=f"text_{i+1}_ln")(t)
        x = layers.Dense(text_proj_dim, activation="gelu", kernel_regularizer=l2, name=f"text_{i+1}_proj1")(x)
        x = layers.Dropout(dropout_rate, name=f"text_{i+1}_drop1")(x)
        x = layers.Dense(text_proj_dim, activation="gelu", kernel_regularizer=l2, name=f"text_{i+1}_proj2")(x)
        text_reprs.append(x)  # (batch, text_proj_dim)
    # —- 文本字段上的可选门控 —-
    if use_gating:
        stacked = layers.Concatenate(name="text_concat_for_gate")(text_reprs)
        # (batch, num_text_fields*text_proj_dim)
        gate = layers.Dense(64, activation="relu", kernel_regularizer=l2, name="gate_dense")(stacked)
        gate = layers.Dense(num_text_fields, activation="softmax", name="gate_weights")(gate)
        # (batch, 4)
        weighted = []
        for i in range(num_text_fields):
            w_i = layers.Lambda(
                lambda g, idx=i: tf.expand_dims(g[:, idx], axis=-1),
                name=f"gate_w_{i+1}"
            )(gate)
            weighted.append(layers.Multiply(name=f"text_{i+1}_weighted")([text_reprs[i], w_i]))
        text_fused = layers.Add(name="text_fused")(weighted)
        # (batch, text_proj_dim)
    else:
        # 更简单：直接拼接所有文本表示
        text_fused = layers.Concatenate(name="text_fused_concat")(text_reprs)
    # —- 分类塔 —-
    c = layers.LayerNormalization(name="cat_ln")(cat_block)
    c = layers.Dense(cat_proj_dim, activation="relu", kernel_regularizer=l2, name="cat_proj")(c)
    c = layers.Dropout(dropout_rate, name="cat_drop")(c)
    # —- 融合头 —-
    x = layers.Concatenate(name="fusion_concat")([text_fused, c])
    x = layers.Dense(hidden_dim, activation="relu", kernel_regularizer=l2, name="fusion_dense1")(x)
    x = layers.Dropout(dropout_rate, name="fusion_drop1")(x)
    x = layers.Dense(hidden_dim // 2, activation="relu", kernel_regularizer=l2, name="fusion_dense2")(x)
    x = layers.Dropout(dropout_rate, name="fusion_drop2")(x)
    outputs = layers.Dense(1, activation="sigmoid", name="output")(x)
    model = keras.Model(inputs=inputs, outputs=outputs, name="single_input_text_cat_fusion")
    return model
