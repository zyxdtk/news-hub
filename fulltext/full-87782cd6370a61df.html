在推出模型上下文协议（MCP）两年后，Anthropic 正在为 Claude 和 Claude Code 添加 Skills over MCP（通过 MCP 交付技能）支持的公开测试版。

MCP 服务器让 AI 代理能够访问外部工具和数据。借助 Skills over MCP 扩展，服务器还可以随这些工具一起提供标准化、可复用的工作流指令。开发者可以同时更新工具和指导内容，而用户无需单独安装任何东西。

该测试版功能对 Pro、Max 和 Ultra 计划默认开启。Team 计划需要管理员启用，Enterprise 版本的支持则被列为即将推出。

MCP 的另外两个组成部分现已在 Claude 和 Claude Code 中面向 Pro、Max 和 Ultra 订阅用户正式发布，并将陆续推广至 Team 和 Enterprise 客户。Tasks（任务）是一项官方 MCP 扩展，允许服务器运行长时间任务，同时 Claude 继续处理其他工作。Elicitation（信息征询）是 MCP 规范中的一项功能，允许服务器在处理请求时向用户询问信息。

另一项新增功能 File Uploads（文件上传）也即将推出。它基于一项实验性 MCP 扩展构建，将允许 Claude 向服务器发送文件而不仅仅是文本，且无需让这些文件经过模型的上下文窗口。

Anthropic 于 2024 年 11 月将 MCP 作为开源项目发布，随后获得了 OpenAI 和微软的支持。MCP 项目于 2025 年 12 月加入了 Linux 基金会的代理式 AI 基金会（Agentic AI Foundation，AAIF）。

Skills over MCP 让团队能做什么

技能（skill）是一组指令包，用于告诉 AI 代理如何处理某类任务。它以目录形式存在，包含一个 SKILL.md 文件和可选的辅助文件。Skills over MCP 建立在 Anthropic 于 2025 年 12 月开放为标准的 Agent Skills 格式之上。

技能可以包含最佳实践、分步工作流，或针对用户账户或组织定制的操作手册。在 Claude 中，技能会在服务器连接时被发现，但其完整指令仅在需要时才会加载。

Anthropic 给出的示例展示了所涉及任务的广泛范围。据该公司介绍，Shopify 技能可帮助 Claude 从头到尾设计并更新商家的在线商店。HubSpot 利用技能在 Claude 中引导新客户完成入门和设置。Atlassian 的技能则利用公司自身的上下文来分析工作并呈现洞察。Anthropic 还表示，即将推出的 Carta 技能将帮助 Claude 根据上传的文档起草并发行股权。

服务器如何向代理交付技能

Skills over MCP 是一项官方 MCP 扩展。该扩展规范目前标记为测试版，软件开发工具包和客户端应用中的支持仍在构建之中。

该扩展通过 Resources（资源）这一 MCP 现有功能来提供技能文件。客户端可以发现服务器提供哪些技能，并在需要时加载这些文件。

Claude Code 增加了自己的限制。它会忽略 MCP 服务器技能可能声明的若干设置，包括工具权限和钩子（hooks）相关的设置。在 Claude Code 的默认自动模式下，由一个分类器决定某个技能是否可以在不提示用户批准的情况下加载。用户还可以设置权限规则，阻止某个服务器的技能，或在每次技能加载时进行提示。一项托管设置允许组织为 Claude 连接器之外的服务器开启或关闭 MCP 技能。

Claude 并非唯一支持技能的客户端。微软已将该功能添加到 VS Code 1.147 及更高版本中，并配有自己的设置和审批控制。

早期反应聚焦便利性与控制权

对基础设施团队而言，一大吸引力在于可以将操作指南与其所覆盖的工具保存在一起。资深 DevOps 工程师 Filipe Motta 在一篇 LinkedIn 帖子中描述了这一好处。

Motta 写道："暴露你的 Terraform 或 Kubernetes 工具的服务器，也可以携带用好这些工具的操作手册。当它发生变化时，无需在每台笔记本电脑上单独更新任何东西。"

便捷的获取方式也引出了"到底会加载什么"的问题。开发者 Jeff Allen 在 X 上发帖称："当代理几乎无需任何设置就能获取正确的能力时，Skills over MCP 是一次真正的产品胜利。我仍然在意控制权，因为把错误的内容自动加载到上下文中，成本会迅速攀升。"

该扩展规范将服务器提供的技能识别为一种提示注入（prompt injection）风险，并要求每个技能在能够触发本地代码执行之前必须获得用户的明确批准。当技能发生变化时，控制机制同样适用。如果客户端检测到先前已批准技能的文件发生变更，就必须再次请求用户批准该技能。

服务器提供的指令改变了团队在连接服务器时所批准的内容。StackOne（一家为 AI 代理构建集成基础设施的公司）的联合创始人兼首席技术官 Guillaume Lebedel 在一篇 LinkedIn 帖子中描述了这一转变。

Lebedel 写道："批准一个 MCP 服务器，过去主要意味着批准它能做什么。现在，它还意味着批准它告诉代理去做什么。"
