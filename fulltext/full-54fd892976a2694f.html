摘要

本文开发了一种分散式事件触发拓扑切换协议，允许智能体在保持状态安全并排除 Zeno 行为的同时断开与通信网络的连接。我们建立了一个鲁棒障碍函数条件，只要估计误差保持在规定阈值内，该条件即可保证安全性。每个智能体使用本地可计算的证书来确定何时连接和断开网络。证书构造通过将拓扑相关计算的复杂度从 O(2^N) 降低到 O(N) 来提高可扩展性，其中 N 是智能体数量。我们形式化地证明该协议确保估计误差不超过规定阈值且是非 Zeno 的。交替方法计算误差加权矩阵和二次障碍函数，以保证所提协议下的安全性。最后，我们在四个互联微电网上评估该协议。与始终保持网络连接相比，该协议减少了智能体保持连接的时间，同时将相位和频率保持在其安全运行区域内。

关键词： 多智能体系统、网络化控制、控制障碍函数、事件触发控制。

I 引言

过去几十年中，多智能体系统的分散控制在自动驾驶车辆 [1]、配水网络 [2]、移动机器人 [3, 4] 和电网 [5] 等应用中受到越来越多的关注。在这些系统中，智能体通过本地通信和反馈控制协调其行动以实现全局目标 [6]。许多此类应用是安全关键的，因为故障可能对物理基础设施造成严重损害并危及人类生命。因此，控制动作必须在运行期间满足安全约束。这些约束可能取决于多个智能体的状态。例如，保持两个机器人之间的最小距离需要两个机器人位置的信息 [7]。

在分散设置中，每个智能体仅测量部分全局状态，并使用全局状态估计来计算其控制输入。如果智能体自身的测量不足，其状态估计可能随时间偏离真实全局状态，增加其估计误差。随着估计误差的增长，基于状态估计的控制动作可能导致系统违反安全约束。为防止此类违规，常见方法是导出对规定阈值内的每个估计误差都成立的安全条件 [8, 9, 10]。如果估计误差保持在此阈值内，则该条件保证状态安全。当智能体无法仅使用自己的测量将其估计误差保持在此阈值内时，它必须与其他智能体通信以获取改善其状态估计的信息。

为交换信息，智能体形成通信网络。当智能体连接到网络时，它可以从其他智能体接收新信息并向它们广播自己的信息。维持连接消耗带宽和能量 [11, 12] 并增加网络攻击的风险 [13]。这些成本和风险促使减少通信。事件触发控制（ETC）广泛用于通过仅在满足规定的触发条件时交换信息或更新控制输入来减少多智能体系统中的通信开销 [14, 13, 15, 16]。传统 ETC 要求智能体始终保持与网络的连接，以便可以随时访问每个智能体的状态以评估触发条件。一旦当前状态违反触发条件，协议激活通信以改善智能体的状态估计。在这种情况下，虽然通信减少了，但智能体仍然始终保持网络连接。

先前工作 [17] 通过提出分散 ETC 协议解决了这一缺点，该协议允许智能体在不需要通信时断开网络，同时保持系统稳定性。每个智能体通过评估规定的触发条件独立确定何时重新连接。断开连接时，智能体仅使用自己的测量更新其估计。该协议保证估计误差收敛到规定区域，但允许它们在重新连接后收敛回来之前暂时离开该区域。这种收敛保证不能确保状态安全，因为估计误差可能在收敛之前超过规定阈值。

在这项工作中，我们通过开发分散事件触发拓扑切换协议来解决间歇连接下保证状态安全方面的差距。在这里，我们使用前向不变性来保证安全：从安全集中开始的状态轨迹永远保持在该集合中。控制障碍函数（CBF）广泛用于通过安全集的前向不变性来认证状态安全 [18, 19, 3, 1, 20]。我们使用障碍函数来认证在估计误差保持在规定阈值内时，给定控制器下规定安全集子集的前向不变性。在我们的协议下，每个智能体从其可用的拓扑信息计算估计误差的上界。通过将其估计误差界与规定阈值进行比较，每个智能体独立确定何时连接和断开。

我们的主要贡献如下：

  • 我们建立了状态安全的充分条件，该条件将障碍条件与估计误差保持在规定阈值内的要求相结合。
  • 我们证明该协议是非 Zeno 的，并始终保持估计误差在规定阈值内，从而保证状态安全。
  • 我们采用交替方法计算定义规定估计误差阈值的误差加权矩阵和认证状态安全的障碍函数。
  • 我们在非线性四微电网系统上评估该协议，证明在间歇连接下相位和频率偏差保持在规定限度内。

与我们的会议论文 [21] 相比，这项工作开发了更具可扩展性的拓扑切换协议。使用每个智能体可用的拓扑信息，该协议将拓扑相关计算的数量从 O(2^N) 减少到 O(N)，其中 N 是智能体数量。我们还证明该协议是非 Zeno 的，并采用交替优化方法计算满足所需条件的误差加权矩阵和障碍函数，而不是假设这些量是给定的。

本文组织如下。第 II 节介绍系统模型和预备知识。第 III 节阐述安全要求并推导鲁棒障碍证书条件。第 IV 节开发拓扑切换协议并证明它保持安全并排除 Zeno 行为。第 V 节介绍交替方法。第 VI 节介绍仿真，第 VII 节总结本文。

II-B 系统模型

我们考虑 N 个智能体，每个智能体由 i ∈ 𝒩 ≜ {1, …, N} 索引。全局动力学遵循连续时间线性时不变（LTI）模型：

ẋ(t) = Ax(t) + Bu(t) + w(t), (1)
y(t) = Cx(t) + v(t).

(1) 中的变量定义如下：

  • x(t) ≜ [x₁(t)⊤, …, x_N(t)⊤]⊤ ∈ ℝⁿ 是全局状态，其中 x_i(t) ∈ ℝ^(n_i) 且 Σ_{i=1}^N n_i = n。
  • u(t) ≜ [u₁(t)⊤, …, u_N(t)⊤]⊤ ∈ ℝᵐ 是控制输入，其中 u_i(t) ∈ ℝ^(m_i) 且 Σ_{i=1}^N m_i = m。
  • y(t) ≜ [y₁(t)⊤, …, y_N(t)⊤]⊤ ∈ ℝᵖ 是测量输出，其中 y_i(t) ∈ ℝ^(p_i) 且 Σ_{i=1}^N p_i = p。
  • w(t) ∈ ℝⁿ 是过程扰动。v(t) ≜ [v₁(t)⊤, …, v_N(t)⊤]⊤ ∈ ℝᵖ 是测量噪声，其中 v_i(t) ∈ ℝ^(p_i)。

矩阵 A ∈ ℝ^(n×n)，B ≜ [B₁ ⋯ B_N] ∈ ℝ^(n×m)，C ≜ [C₁⊤, …, C_N⊤]⊤ ∈ ℝ^(p×n)，其中 C_i ∈ ℝ^(p_i×n) 和 B_i ∈ ℝ^(n×m_i)，是已知且恒定的。

智能体 i 访问其本地测量 y_i(t) = C_i x(t) + v_i(t)。我们假设 w(t) ∈ 𝒲，v(t) ∈ 𝒱 对所有 t ≥ 0，其中

𝒲 ≜ {w ∈ ℝⁿ : w⊤Q_w w ≤ 1}, (2)
𝒱 ≜ {v ∈ ℝᵖ : v⊤R_v v ≤ 1}, (3)

矩阵 Q_w ∈ 𝕊_++^n 和 R_v = diag(R_{v,1}, …, R_{v,N}) ∈ 𝕊_++^p 是给定的，其中 R_{v,i} ∈ 𝕊_++^(p_i) 对每个 i ∈ 𝒩。

II-C 通信模型

设 𝒢̄ ≜ (𝒩, ℰ̄) 是固定的连通无向图。时刻 t 的通信拓扑由 𝒢̄ 的生成子图 𝒢(t) ≜ (𝒩, ℰ(t)) 建模，意味着 𝒢(t) 和 𝒢̄ 具有相同的顶点集 𝒩 且 ℰ(t) ⊆ ℰ̄ 对所有 t ≥ 0。

设 𝒜(t) = [a_ij(t)] ∈ ℝ^(N×N) 是 𝒢(t) 的对称邻接矩阵。如果 ∈ ℰ(t)，则 a_ij(t) = 1；如果 ∉ ℰ(t)，则 a_ij(t) = 0。对角元素满足 a_ii(t) = 0。边 在时刻 t 称为活动通信边，如果 a_ij(t) = 1，表示智能体 i 和 j 之间的直接通信被启用。智能体 i 的活动邻居是与 i 共享活动通信边的智能体。每个智能体 i 可以访问其活动通信边。其活动邻居集定义为

𝒩_i(t) ≜ {j ∈ 𝒩∖{i} : a_ij(t) = 1}. (4)

为减少通信开销，每个智能体确定何时连接或断开，并在以下模式之一中运行：

  • 断开模式（DM）：智能体 i 不可用于通信，仅使用其本地测量 y_i(t) 更新其状态估计。
  • 连接模式（CM）：智能体 i 可用于通信。如果 𝒩_i(t) ≠ ∅，它与其活动邻居交换信息，并使用其本地测量 y_i(t) 和从活动邻居接收的信息更新其状态估计。如果 𝒩_i(t) = ∅，它仅使用 y_i(t) 更新其状态估计，但保持可用于通信。边 ∈ ℰ̄ 仅当两个智能体都处于连接模式时才能活动。因此，处于连接模式但没有活动邻居的智能体保持可用于通信，并且当 j 进入连接模式且 变为活动时可以与智能体 j 交换信息。

对于处于连接模式的智能体 i，其连通分量由 i 和通过活动通信边路径从 i 可达的所有智能体组成。时刻 t 从 i 到 j 的路径是满足 a_{i_{r−1}i_r}(t) = 1 的不同智能体序列 i = i₀, i₁, …, i_k = j，对每个 r = 1, …, k。我们假设智能体 i 知道其连通分量的顶点集和边集。

设 ℒ(t) = [ℓ_ij(t)] ∈ ℝ^(N×N) 表示与 𝒢(t) 相关的图拉普拉斯矩阵，其中 ℓ_ii(t) = |𝒩_i(t)| 且 ℓ_ij(t) = −a_ij(t) 对 i ≠ j。设 ℒ̄ ∈ ℝ^(N×N) 表示 𝒢̄ 的拉普拉斯矩阵。由于 𝒢̄ 连通，ℒ̄ 是半正定的，在 0 处有单特征值且 λ₂(ℒ̄) > 0。此外，ℰ(t) ⊆ ℰ̄ 意味着 0 ⪯ ℒ(t) ⪯ ℒ̄ 对所有 t ≥ 0。

II-D 分散状态估计

控制器和观测器以及由此产生的第 II-E 节中的误差动力学遵循 [17]。

每个智能体 i 应用控制律 u_i(t) = K_i x̂_i(t)，其中 K_i ∈ ℝ^(m_i×n) 是给定的本地增益矩阵，x̂_i(t) ∈ ℝⁿ 是其对全局状态的本地估计。定义堆叠增益 K ≜ [K₁⊤, …, K_N⊤]⊤ ∈ ℝ^(m×n) 和标称闭环矩阵 A_bk ≜ A + BK ∈ ℝ^(n×n)。

观测器增益 L ≜ [L₁ ⋯ L_N] ∈ ℝ^(n×p)，其中 L_i ∈ ℝ^(n×p_i)，选择使得 A − LC 是 Hurwitz 的。

智能体 i 具有模式相关的观测器增益 L̄_i(ℓ_ii(t)) ∈ ℝ^(n×p_i)，为

L̄_i(ℓ_ii(t)) ≜ { L̂_i, 若 ℓ_ii(t) = 0; NL_i, 若 ℓ_ii(t) > 0 }, (5)

其中 L̂_i ≜ T_i[L_i^o, 0]⊤ ∈ ℝ^(n×p_i)。为构造 L̂_i， 的可观测性分解给出可逆变换矩阵 T_i ∈ ℝ^(n×n) 使得

T_i⁻¹AT_i = [A_i^o 0; A_i²¹ A_i^ō]，C_iT_i = [C_i^o 0]。

设 n_i^o 表示 的可观测子空间的维数，n_i^o ≤ n。矩阵 A_i^o ∈ ℝ^(n_i^o×n_i^o) 和 C_i^o ∈ ℝ^(p_i×n_i^o) 描述可观测子系统，A_i^ō ∈ ℝ^((n−n_i^o)×(n−n_i^o)) 描述不可观测子系统，A_i²¹ ∈ ℝ^((n−n_i^o)×n_i^o) 是非对角块。对 是可观测的，增益 L_i^o ∈ ℝ^(n_i^o×p_i) 选择使得 A_i^o − L_i^o C_i^o 是 Hurwitz 的。

我们将智能体 i 在时刻 t 的本地可用信息定义为由其本地测量 y_i(t)、其自己的全局状态估计 x̂_i(t) 和其活动邻居集 𝒩_i(t) 组成。当智能体 i 处于连接模式时，该信息还包括从活动邻居 j ∈ 𝒩_i(t) 接收的估计 x̂_j(t) 及其连通分量的拓扑。基于此信息，智能体 i 的分散观测器动力学遵循

x̂̇i(t) = A_bk x̂_i(t) + L̄_i(ℓ_ii(t))(y_i(t) − C_i x̂_i(t)) (6)
+ η Σ{j=1}^N a_ij(t)(x̂_j(t) − x̂_i(t)),

其中 η ≥ 0 是网络耦合增益，ℓ_ii(t) 是 ℒ(t) 的第 i 个对角元素。

II-E 误差动力学与闭环动力学

我们将智能体 i 的全局状态估计误差定义为 e_i(t) ≜ x(t) − x̂_i(t) ∈ ℝⁿ。相应的误差动力学由

ė_i(t) = (A_bk − L̄i(ℓ_ii(t))C_i)e_i(t) + w(t) − L̄_i(ℓ_ii(t))v_i(t) − Σ{j=1}^N (B_jK_j + ηℓ_ij(t))e_j(t).

通过将智能体的全局状态估计误差堆叠为

e(t) ≜ [e₁(t)⊤, …, e_N(t)⊤]⊤ ∈ ℝ^(Nn),

我们将堆叠误差动力学紧凑地写为

ė(t) = (F(ℒ(t)) − η(ℒ(t) ⊗ I_n))_{A_e(ℒ(t))} e(t) (7)
+ ℐw(t) − J(ℒ(t))v(t),

其中 ℐ ≜ [I_n⊤, …, I_n⊤]⊤ ∈ ℝ^(Nn×n)，

J(ℒ(t)) ≜ diag(L̄₁(ℓ₁₁(t)), …, L̄_N(ℓ_NN(t))),

且 F(ℒ(t)) ∈ ℝ^(Nn×Nn) 是块矩阵，块元素 F_ij(ℒ(t)) ∈ ℝ^(n×n) 为

F_ij(ℒ(t)) ≜ { A_bk − L̄_i(ℓ_ii(t))C_i − B_iK_i, 若 i = j; −B_jK_j, 若 i ≠ j }. (8)

最后，将本地控制输入 u_i(t) = K_i x(t) − K_i e_i(t) 代入系统模型得到全局闭环状态动力学

ẋ(t) = A_bk x(t) − Ee(t) + w(t), (9)

其中 E ≜ [B₁K₁ ⋯ B_NK_N] ∈ ℝ^(n×Nn)。

II-F 障碍证书

考虑动力学系统 ẋ(t) = f(x(t))，其中 f: ℝⁿ → ℝⁿ 是局部 Lipschitz 的。设 φ: ℝⁿ → ℝ 连续可微并定义其零超水平集为 𝒮 ≜ {x ∈ ℝⁿ : φ(x) ≥ 0}。φ 沿向量场 f 的导数由 L_f φ(x) ≜ ∇φ(x)⊤f(x) 给出。扩展 class-𝒦 函数 α_φ: (−a_φ, b_φ) → ℝ，对某些 a_φ, b_φ > 0，是连续的、严格递增的，且满足 α_φ(0) = 0。假设 ∇φ(x) ≠ 0 对所有 x ∈ ∂𝒮。以下定义遵循 [19]。

定义 1 函数 φ 是 𝒮 的障碍证书，如果存在扩展 class-𝒦 函数 α_φ 使得

L_f φ(x) + α_φ(φ(x)) ≥ 0，对所有 x ∈ 𝒮. (10)

设 x(t) 是 ẋ(t) = f(x(t)) 满足 x(0) ∈ 𝒮 的唯一解，并假设它对所有 t ≥ 0 存在。如果 (10) 成立，则 𝒮 是前向不变的且 x(t) ∈ 𝒮 对所有 t ≥ 0。

III 问题阐述

我们首先指定安全要求并在有界估计误差下开发状态安全的充分条件。然后我们阐述开发分散拓扑切换协议确保估计误差不超过规定阈值的问题。

III-A 问题设置

状态需要满足 x(t) ∈ 𝒞 对所有 t ≥ 0，其中

𝒞 ≜ {x ∈ ℝⁿ : h(x) ≥ 0} (11)

是规定的安全集，h: ℝⁿ → ℝ 是给定的多项式。初始状态假设满足 x(0) ∈ 𝒞。然而，规定的集合 𝒞 在 (9) 下不必是前向不变的。因此我们寻找 𝒞 的一个包含初始状态且只要估计误差不超过规定阈值就保持前向不变的子集。为构造此子集，我们引入多项式障碍函数 b: ℝⁿ → ℝ 并定义

ℬ ≜ {x ∈ ℝⁿ : b(x) ≥ 0} (12)

使得 x(0) ∈ ℬ 且 ℬ ⊆ 𝒞。

为量化估计误差，我们定义

V_e(e) ≜ e⊤P̄e, (13)

其中全局误差加权矩阵为

P̄ ≜ I_N ⊗ P_e ∈ 𝕊_++^(Nn), (14)

且 P_e = P_e⊤ ≻ 0 是每个智能体全局状态估计误差的加权矩阵。矩阵 P̄ 为每个智能体的估计误差 e_i 分配相同的权重 P_e。

将障碍证书条件 (10) 应用于闭环动力学 (9)，定义

g_b(x, e, w) ≜ ∇b(x)⊤(A_bk x − Ee + w) + α_b(b(x)). (15)

假设扩展 class-𝒦 函数 α_b 选择使得 α_b(b(x)) 是 x 的多项式。

III-B 状态安全的充分条件

我们使用平方和（SOS）条件建立状态安全的充分条件。设 Φ(e) ≜ 1 − V_e(e)。

第一个 SOS 条件认证 g_b(x, e, w) ≥ 0 对所有 x ∈ ℬ，w ∈ 𝒲 和满足 Φ(e) ≥ 0 的 e。第二个认证 ℬ ⊆ 𝒞。

如果估计误差满足 Φ(e(t)) ≥ 0 对所有 t ≥ 0，则状态安全成立。

z ∈ ℝ^d 中的实多项式 p(z) 是 SOS 多项式，如果存在 r ∈ ℕ 和实多项式 q₁, …, q_r 使得 p(z) = Σ_{k=1}^r q_k(z)²。因此，p(z) ≥ 0 对所有 z ∈ ℝ^d。设 Σ[·] 表示指定变量中 SOS 多项式的锥。

引理 1 对任意初始状态 x(0) ∈ ℬ，设 g_b 由 (15) 定义。如果 Φ(e(t)) ≥ 0 对所有 t ≥ 0 且

g_b − s_b b − s_Φ Φ − s_w(1 − w⊤Q_w w) ∈ Σ[x, e, w] (16)

对某些 SOS 乘子 s_b, s_Φ, s_w ∈ Σ[x, e, w]，

则 ℬ 在 (9) 下对每个满足 w(t) ∈ 𝒲 对所有 t ≥ 0 的扰动是前向不变的。

证明： 对 x ∈ ℬ，(12) 给出 b(x) ≥ 0。对 w ∈ 𝒲，(2) 给出 1 − w⊤Q_w w ≥ 0。由于 s_b、s_Φ 和 s_w 是 SOS，(16) 给出以下不等式对所有 x ∈ ℬ，w ∈ 𝒲 和满足 Φ(e) ≥ 0 的 e ∈ ℝ^(Nn)：

g_b(x, e, w) ≥ s_b b(x) + s_Φ Φ(e) + s_w(1 − w⊤Q_w w) ≥ 0. (17)

由 (10)，对任意 x(0) ∈ ℬ，x(t) ∈ ℬ 对所有 t ≥ 0。因此，ℬ 是前向不变的。证毕。

引理 1 要求 Φ(e(t)) ≥ 0 对所有 t ≥ 0 以保证 ℬ 的前向不变性。因此我们定义误差安全集

Ω ≜ {e ∈ ℝ^(Nn) : Φ(e) ≥ 0}. (18)

等价地，Ω = {e ∈ ℝ^(Nn) : V_e(e) ≤ 1}。

我们接下来给出 ℬ ⊆ 𝒞 的 SOS 条件并将其与障碍条件结合以建立状态安全。

命题 1 设 0 ≤ t₁ < t₂。如果 x(t₁) ∈ ℬ，e(t) ∈ Ω 和 w(t) ∈ 𝒲 对所有 t ∈ [t₁, t₂]，(16) 成立，且存在 s_h ∈ Σ[x] 使得

h(x) − s_h(x)b(x) ∈ Σ[x], (19)

则 x(t) ∈ ℬ ⊆ 𝒞 对所有 t ∈ [t₁, t₂]。

证明： 由于 e(t) ∈ Ω 和 w(t) ∈ 𝒲 对所有 t ∈ [t₁, t₂]，(17) 在 [t₁, t₂] 上成立。由于 x(t₁) ∈ ℬ，(10) 给出 x(t) ∈ ℬ 对所有 t ∈ [t₁, t₂]。此外，(19) 意味着 h(x) ≥ s_h(x)b(x)。由于 s_h 是 SOS，b(x) ≥ 0 意味着 h(x) ≥ 0，因此 ℬ ⊆ 𝒞。所以，x(t) ∈ ℬ ⊆ 𝒞 对所有 t ∈ [t₁, t₂]。证毕。

引理 1 和命题 1 表明，如果 SOS 条件 (16) 和 (19) 成立，保持 e(t) ∈ Ω 对所有 t ≥ 0 保证状态安全。我们将问题表述如下。

问题 1 对 (9) 中满足 x(0) ∈ 𝒞 的系统，我们找到 P_e ∈ 𝕊_++^n，满足 x(0) ∈ ℬ 的多项式障碍函数 b，以及满足 (16) 和 (19) 的 SOS 乘子。然后我们开发分散拓扑切换协议使得 每个智能体仅使用其本地可用信息决定何时切换模式。对每个 e(0) ∈ Ω，协议保持 V_e(e(t)) ≤ 1 并保证 x(t) ∈ ℬ ⊆ 𝒞 对所有 t ≥ 0。 协议是非 Zeno 的。每个智能体在每个有界时间区间内仅有限次改变模式。

IV 拓扑切换协议

在本节中，我们开发问题 1 中的分散拓扑切换协议。由引理 1 和命题 1，保持 V_e(e(t)) ≤ 1 对所有 t ≥ 0 在 SOS 条件 (16) 和 (19) 下保证 x(t) ∈ ℬ ⊆ 𝒞 对所有 t ≥ 0。由于状态 x(t) 未知，智能体 i 不能直接计算 V_e(e(t))。因此我们构造满足 V_e(e(t)) ≤ U_i(t) 的可计算上界 U_i(t)。

处于断开模式的每个智能体在 U_i(t) 达到 1 时进入连接模式。因此，在存在处于断开模式的智能体 i 的任意时刻 t，

V_e(e(t)) ≤ U_i(t) ≤ 1, (20)

使得 e(t) ∈ Ω。然而，在所有智能体都处于连接模式的任意时刻 t，(20) 不再适用。因此我们建立使 V_e 减小的恢复条件，即当 V_e ≥ γ_off 时 V̇_e < 0，使得 e(t) ∈ Ω。这里，γ_off ∈ (0,1) 是确定智能体何时准备好断开网络的规定释放阈值。

设 Ψ(t) ⊆ 𝒩 表示时刻 t 处于连接模式的智能体集合。我们对每个智能体 i ∈ 𝒩 在三种情况下构造 U_i(t)：

1) 完全连接：如果每个智能体都处于连接模式，即 Ψ(t) = 𝒩，则所有智能体共享界

U_i(t) ≜ Z_fc(t). (21a)

2) 智能体 i 的部分连接：如果 Ψ(t) ≠ 𝒩 且智能体 i 有活动邻居，即 𝒩_i(t) ≠ ∅，则智能体 i 使用

U_i(t) ≜ Z_{pc,i}(t). (21b)

3) 智能体 i 无活动邻居：如果 Ψ(t) ≠ 𝒩 且智能体 i 没有活动邻居，即 𝒩_i(t) = ∅，则智能体 i 使用

U_i(t) ≜ Z_{dc,i}(t). (21c)

此情况适用于两种场景： 处于断开模式的智能体和 处于连接模式但没有活动邻居的智能体。

在第 IV-A 节中，我们建立完全连接下的恢复条件并推导 Z_fc。在第 IV-B 节中，我们推导 Z_{dc,i} 和 Z_{pc,i}。然后我们使用第 IV-A 和 IV-B 节中推导的界在第 IV-C 节中开发拓扑切换协议，并在第 IV-D 节中证明协议下的非 Zeno 行为和安全性。

IV-A 完全连接下的恢复条件与误差界

在完全连接下，即 (21a) 中的情况 1，我们建立确保当 V_e ≥ γ_off 时 V̇_e < 0 的恢复条件并推导 Z_fc。然后我们确定恢复时间 τ_rec，即 Z_fc 从 1 减少到 γ_off 所需的时间。我们还推导满足 τ_rec ≥ τ̲_rec > 0 的一致正下界 τ̲_rec 用于第 IV-D 节中的非 Zeno 分析。

设 t_fc 表示完全连接开始的时间。设 t_off 表示所有智能体同时进入断开模式的时间。我们有 t_off > t_fc。如果 Ψ(t) = 𝒩 对所有 t ∈ [t_fc, t_off)，我们称 [t_fc, t_off) 为完全连接区间。在此区间上，𝒢(t) 是 𝒢̄ 的连通生成子图，具有固定拉普拉斯 ℒ(t) = ℒ_fc 对所有 t ∈ [t_fc, t_off)。我们称 ℒ_fc 为容许的，如果 0 ⪯ ℒ_fc ⪯ ℒ̄ 且 λ₂(ℒ_fc) > 0。条件 λ₂(ℒ_fc) > 0 意味着完全连接中的所有智能体通过活动通信边路径连接。

IV-A1 恢复条件

在完全连接区间 [t_fc, t_off) 上，误差动力学 (7) 变为

ė(t) = A_e(ℒ_fc)e(t) + ℐw(t) − J(ℒ_fc)v(t), (22)

对所有 t ∈ [t_fc, t_off)，其中 A_e(ℒ_fc) = F(ℒ_fc) − η(ℒ_fc ⊗ I_n)。定义 S_e(ℒ_fc) ≜ A_e(ℒ_fc)⊤P̄ + P̄A_e(ℒ_fc)。我们陈述以下命题。

命题 2 设 V_e 如 (13) 中定义并满足 V_e(e(t)) ≥ γ_off 对所有 t ∈ [t_fc, t_off)。对每个容许的 ℒ_fc，给定任意 P̄ = I_N ⊗ P_e ≻ 0 和 γ_off ∈ (0,1)，如果存在标量 α ∈ ℝ_{>0} 和 β_w, β_v ∈ ℝ_{≥0} 使得

[S_e(ℒ_fc) + αP̄, P̄ℐ, −P̄J(ℒ_fc); ℐ⊤P̄, −β_wQ_w, 0; −J(ℒ_fc)⊤P̄, 0, −β_vR_v] ⪯ 0, (23a)
β_w + β_v < αγ_off, (23b)

则 V̇_e(e(t)) < 0 对所有 t ∈ [t_fc, t_off)。

证明： 由 (23a)，

[e(t); w(t); v(t)]⊤[矩阵][e(t); w(t); v(t)] ≤ 0。

展开此不等式并使用 (22) 给出

V̇_e(e(t)) ≤ −αV_e(e(t)) + β_w w(t)⊤Q_w w(t) + β_v v(t)⊤R_v v(t)

对所有 t ∈ [t_fc, t_off)。由于 w(t)⊤Q_w w(t) ≤ 1，v(t)⊤R_v v(t) ≤ 1 且 β_w, β_v ∈ ℝ_{≥0} 对所有 t ∈ [t_fc, t_off)，可得

V̇_e(e(t)) ≤ −αV_e(e(t)) + β_w + β_v. (24)

对 V_e(e(t)) ≥ γ_off，(23b) 给出 V̇_e(e(t)) ≤ −αγ_off + β_w + β_v < 0。证毕。

IV-A2 完全连接下的误差界与恢复时间

对每个容许的 ℒ_fc，设 α、β_w 和 β_v 满足 (23a) 和 (23b)。这些标量依赖于 ℒ_fc 并在每个完全连接区间内保持固定。设 γ_min ≜ (β_w + β_v)/α ∈ [0, γ_off)。初始化 Z_fc(t_fc) = 1 并设 Ż_fc = −αZ_fc + β_w + β_v，则 Z_fc 取以下形式：

Z_fc(t) ≜ γ_min + (1 − γ_min)e^{−α(t−t_fc)}. (25)

我们进一步定义

τ_rec ≜ (1/α) log((1 − γ_min)/(γ_off − γ_min)), (26)

和 t_off ≜ t_fc + τ_rec。因此，Z_fc(t_off) = γ_off。我们陈述以下引理。

引理 2 如果 V_e(e(t_fc)) ≤ 1，则 V_e(e(t)) ≤ Z_fc(t) ≤ 1 对所有 t ∈ [t_fc, t_off]，且 V_e(e(t_off)) ≤ γ_off。

证明： 设 d(t) ≜ V_e(e(t)) − Z_fc(t)。由 (24)，ḋ ≤ −αd，所以 d/dt[e^{α(t−t_fc)}d(t)] ≤ 0。由于 d(t_fc) ≤ 0，我们得到 d(t) ≤ e^{−α(t−t_fc)}d(t_fc) ≤ 0。方程 (25) 和 (26) 给出 γ_off ≤ Z_fc(t) ≤ 1 和 Z_fc(t_off) = γ_off。由 e 的连续性，V_e(e(t_off)) ≤ Z_fc(t_off) = γ_off。证毕。

我们接下来推导对所有容许 ℒ_fc 成立的 τ_rec 的正下界 τ̲_rec。给定 (5) 中每个 k ∈ 𝒩 的观测器增益 L̄_k(ℓ_kk)，我们定义

a_k ≜ −tr(A_bk − B_kK_k) + max_{L̄_k(ℓ_kk) ∈ {L̂_k, NL_k}} tr(L̄_k(ℓ_kk)C_k),

并设

ᾱ ≜ (2/(Nn))(Σ_{k∈𝒩} a_k + ηn tr(ℒ̄)). (27)

引理 3 对任意容许的 ℒ_fc，如果 (23a) 和 (23b) 成立，则 0 < α ≤ ᾱ 且

τ_rec ≥ τ̲_rec ≜ (1/ᾱ) log(1/γ_off) > 0. (28)

证明： 由 (23a)，S_e(ℒ_fc) + αP̄ ⪯ 0。左乘和右乘 P̄^{−1/2} 给出

P̄^{−1/2}S_e(ℒ_fc)P̄^{−1/2} + αI_{Nn} ⪯ 0。

取迹，代入 S_e 的定义，并使用 tr(XY) = tr(YX) 得出

0 ≥ tr(P̄^{−1/2}S_e(ℒ_fc)P̄^{−1/2}) + Nnα
= tr(P̄^{−1/2}A_e(ℒ_fc)⊤P̄^{1/2}) + tr(P̄^{1/2}A_e(ℒ_fc)P̄^{−1/2}) + Nnα
= 2tr(A_e(ℒ_fc)) + Nnα。

这里，tr(I_{Nn}) = Nn 且 tr(A_e⊤) = tr(A_e)。由于 L̄k(ℓ_kk) ∈ {L̂_k, NL_k} 对 k ∈ 𝒩，ℒ_fc ⪯ ℒ̄，且 η ∈ ℝ{≥0}，

−tr(A_e(ℒ_fc)) = −Σ_{k∈𝒩} tr(A_bk − B_kK_k) + Σ_{k∈𝒩} tr(L̄k(ℓ_kk)C_k) + ηn tr(ℒ_fc)
≤ Σ{k∈𝒩} a_k + ηn tr(ℒ̄) = (Nn/2)ᾱ。

因此，0 < α ≤ ᾱ。最后，0 ≤ γ_min < γ_off < 1 给出 (1−γ_min)/(γ_off−γ_min) ≥ 1/γ_off，这与 (26) 一起证明了 (28)。证毕。

如果 V_e(e(t_fc)) ≤ 1，则 V_e(e(t)) ≤ Z_fc(t) 对所有 t ∈ [t_fc, t_off]。在完全连接区间上，Z_fc 在时间 τ_rec 内从 1 减少到 γ_off。然而，当某些智能体处于断开模式时，即 Ψ(t) ≠ 𝒩，每个智能体无法访问完整拉普拉斯 ℒ(t)。在下一小节中，我们考虑 Ψ(t) ≠ 𝒩 并推导每个智能体可以从其本地可用信息计算的 V_e(e(t)) 的上界。

IV-B 部分连接下连接模式与断开模式的误差界

我们现在考虑 (21b) 中的情况 2 和 (21c) 中的情况 3。我们对每个智能体 i ∈ 𝒩 推导界 Z_{pc,i} 和 Z_{dc,i}。我们首先界定估计误差增长的速度，并基于此界求解微分方程以获得 V_e(e(t)) 的上界。该方程有两个拓扑相关系数：一个与估计误差相关，另一个与过程扰动 w 和测量噪声 v 相关。然后我们仅使用智能体 i 的本地可用信息界定这些系数，而不需要完整拉普拉斯 ℒ(t) 的知识。将系数界代入微分方程给出 Z_{pc,i} 和 Z_{dc,i}。

IV-B1 误差增长与上界构造

定义误差半径 r_e(t) ≜ √(V_e(e(t))) = ‖P̄^{1/2}e(t)‖₂。为界定 r_e(t) 的增长，定义拓扑相关系数

μ(ℒ(t)) ≜ λ_max(P̄^{−1/2}[A_e(ℒ(t))⊤P̄ + P̄A_e(ℒ(t))]P̄^{−1/2}), (29)
c(ℒ(t)) ≜ ‖P̄^{1/2}ℐQ_w^{−1/2}‖₂ + ‖P̄^{1/2}J(ℒ(t))R_v^{−1/2}‖₂. (30)

以下引理界定 ℒ(t) 保持固定时 r_e(t) 的增长。

引理 4 设 t₃ < t₄ 且 ℒ(t) = ℒ(t₃) = ℒ₀ 对所有 t ∈ [t₃, t₄)，我们有

D⁺r_e(t) ≤ (1/2)μ(ℒ₀)r_e(t) + c(ℒ₀)，∀t ∈ [t₃, t₄), (31)

其中 D⁺ 表示右上 Dini 导数。

证明在附录 A 中给出。

然而，当 Ψ(t) ≠ 𝒩 时，智能体 i 无法评估 μ(ℒ(t)) 或 c(ℒ(t))，因为它无法访问完整拉普拉斯 ℒ(t)。假设智能体 i 可以从其连通分量的拓扑计算上界 μ̄_i ≥ μ(ℒ(t)) 和 c̄_i ≥ c(ℒ(t))。以下引理从这些界构造 U_i(t)。然后我们在第 IV-B2 节中推导 μ̄_i 和 c̄_i 的表达式。

引理 5 对每个 i ∈ 𝒩，设 0 ≤ t₅ < t₆，Ψ(t) ≠ 𝒩 且 ℒ(t) = ℒ(t₅) = ℒ₁ 对所有 t ∈ [t₅, t₆)。设 μ̄i ∈ ℝ 和 c̄_i ∈ ℝ{≥0} 满足

μ(ℒ₁) ≤ μ̄_i，c(ℒ₁) ≤ c̄_i. (32)

定义 r̄_{e,i}(t, μ̄_i, c̄_i) 对 t ∈ [t₅, t₆) 为

{ e^{(1/2)μ̄i(t−t₅)}(r̄{e,i}(t₅, μ̄i, c̄_i) + 2c̄_i/μ̄_i) − 2c̄_i/μ̄_i, 若 μ̄_i ≠ 0;
r̄{e,i}(t₅, μ̄_i, c̄_i) + c̄_i(t − t₅), 若 μ̄_i = 0. } (33)

如果 r̄_{e,i}(t₅, μ̄_i, c̄_i) ≥ r_e(t₅)，则对所有 t ∈ [t₅, t₆)，

r_e(t) ≤ r̄_{e,i}(t, μ̄_i, c̄_i), (34)

且 V_e(e(t)) ≤ U_i(t) ≜ r̄_{e,i}²(t, μ̄_i, c̄_i)。
