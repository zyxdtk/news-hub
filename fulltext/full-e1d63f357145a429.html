摘要

序列压缩是高效语言模型和多模态模型中的一项基本操作和关键信息瓶颈，然而目前基于池化或学习投影的主流方法表现仍然不佳。我们通过测试时回归的视角重新审视序列压缩：输入 token 定义了一个回归问题，其拟合系数构成压缩表示。重要的是，该回归问题通过反向传播进行端到端学习，而其系数在前向传播过程中以闭式高效计算。这催生了 TTR-Compressor，一种可替代传统池化和基于投影压缩的通用方案。我们将 TTR-Compressor 作为块级稀疏注意力的压缩器和多模态大语言模型的视觉 token 合并器进行评估。在块级稀疏注意力上，TTR-Compressor 大幅提升了 RULER 性能，超越了基于注意力的压缩器。在视觉 token 合并方面，它持续优于标准 MLP 合并器，并以减少 55.6% 的视觉 token 数量达到相同性能。这些结果确立了测试时回归作为高效语言和多模态模型中序列压缩的有效原语。

图 1： TTR-Compressor 概览。 与池化和投影独立处理各 token 不同，TTR-Compressor 联合拟合所有 token，从而捕捉它们之间的相互作用。 TTR-Compressor 在块级稀疏注意力和视觉 token 合并上均优于现有方法。

1 引言

序列压缩是现代高效大模型架构中无处不在的操作（Qwen Team, 2026b; DeepSeek-AI, 2026），但仍然令人惊讶地未被充分探索。例如，块级稀疏注意力将每个 token 块压缩为用于评分和选择相关块的摘要向量（Jiang et al., 2024; Lu et al., 2025; Yuan et al., 2025），而多模态大语言模型（MLLM）在将视觉特征送入语言主干之前，会将相邻视觉特征合并为紧凑的 token（Wang et al., 2025; Bai et al., 2025; Team et al., 2026a）。在这两种设置中，压缩器都充当关键的信息瓶颈。信息一旦被丢弃，就无法在下游恢复。

人们期望压缩是一个经过精心设计的架构组件。然而，大多数模型依赖于简单的机制，例如无参数池化、对拼接 token 的学习投影，或者至多是注意力加权池化。

我们认为这些默认压缩器存在一个根本性的结构局限，即它们使用不考虑 token 间关系的权重来聚合 token。平均池化使用均匀权重，线性投影使用固定的位置相关权重，而注意力加权池化则独立地对每个 token 进行评分。因此，冗余 token 会相互增强，而独特的信息则被稀释。从统计角度来看，这些方法主要利用一阶 token 统计量，而忽略了二阶 token 间相关性——恰恰是揭示哪些信息冗余、哪些信息独特的结构。

我们引入了一种根本不同的压缩策略。我们不再询问哪种加权平均最能概括一组 token，而是让 token 定义一个回归问题，并将其拟合系数作为摘要。具体而言，我们提出的 TTR-Compressor 直接从输入 token 构造一个自监督岭回归问题，无需外部标签，并使用其闭式解作为压缩表示。

这种表述创造了一种自然的分工：外层训练循环元学习哪个回归问题能产生对任务有用的表示，而内层闭式解则确定该问题应如何拟合每个输入。与常规池化和投影的关键区别源于回归解中的格拉姆矩阵。通过显式捕捉 token 间相关性，TTR-Compressor 联合拟合相关的 token，因此冗余证据的影响力递减而非纯粹累加。这种输入自适应行为无法通过固定投影或加性 token 组合来复现。

此外，学习正则化项消除了大规模预训练中岭超参数调优的需要。由于压缩窗口通常小于通道维度（即 T < d），我们通过对偶问题以高效的 T×T Cholesky 分解求解。因此，TTR-Compressor 产生的开销极小，每个压缩器仅引入 2d 个可学习参数，使其成为序列压缩的有效直接替换方案。

我们在两个对压缩提出根本不同要求的应用上评估 TTR-Compressor。在块级稀疏注意力中，压缩摘要必须充当忠实的检索键。在此设置中，TTR-Compressor 在 RULER（Hsieh et al., 2024）检索任务上持续优于传统基线，以相当大的优势超越了复杂的基于注意力的压缩器（Hu et al., 2026）。相比之下，在视觉 token 合并中，压缩摘要必须保留忠实的表示。在此，TTR-Compressor 在各种压缩率下持续优于广泛使用的 MLP 合并器，并以减少 55.6% 的视觉 token 数量实现相当的性能。我们的贡献总结如下：

  • 一种新颖的压缩框架。 我们引入了用于序列压缩的测试时回归框架，将 token 摘要重构为实例自适应的优化问题。
  • 一种实用的算子。 我们推导出高效的对偶闭式解并消除了超参数调优，使 TTR-Compressor 完全实用且可扩展至大规模预训练。
  • 实证有效性。 作为大模型中的直接替换组件，TTR-Compressor 在块级稀疏注意力和视觉 token 合并中均持续优于传统基线。

2 相关工作

序列压缩。 将 token 序列压缩为单个向量是现代架构中的一项基本操作，应用范围从多模态 token 缩减（Bolya et al., 2022; Li et al., 2023; Yao et al., 2024; Cha et al., 2024; Chu et al., 2024）到块级稀疏注意力（Jiang et al., 2024; Lu et al., 2025; Gao et al., 2024; Lai et al., 2025）。现有压缩算子主要分为三种范式： 无参数池化，例如平均池化； 拼接后接学习投影；以及 基于注意力的压缩，通过注意力加权平均来汇总 token（Mohtashami & Jaggi, 2023; Yang et al., 2025b）。这些方法族的一个根本局限在于它们计算 token 组合时未显式考虑 token 间相关性。相比之下，TTR-Compressor 将其表示推导为线性系统的解，其格拉姆矩阵直接编码这些相关性，为上述算子提供了一种富有表现力的直接替换方案。

测试时回归与测试时训练。 在推理时针对每个输入调整网络部分内容的想法可追溯到快速权重编程器（Schmidhuber, 1992; Schlag et al., 2021），并作为测试时训练（TTT）复兴——首先用于分布偏移下的鲁棒性（Sun et al., 2020），然后作为序列建模层，其隐藏状态是由自监督损失梯度下降更新的小模型（Sun et al., 2024; Behrouz et al., 2026b; Behrouz et al., 2026a; Han et al., 2026）。In-Place TTT（Feng et al., 2026）通过直接调整预训练 Transformer 的现有 MLP 投影权重进一步扩展了这一范式。另一条平行工作线将线性注意力及其后继者（例如 DeltaNet（Yang et al., 2024）、Gated DeltaNet（Yang et al., 2025c）、Longhorn（Liu et al., 2025）、Titans（Behrouz et al., 2026b））重新解释为在线回归：每层维护一个键到值的回归器，每个 token 用一步梯度或 delta 规则更新，并由查询读出。MesaNet（von Oswald et al., 2026）将内层优化推至收敛，在每个时间步用共轭梯度求解问题，而 LaCT（Zhang et al., 2026）在大的无序块上更新快速权重以提高硬件利用率。

TTR-Compressor 在两个根本方面与这些方法不同。首先，由于压缩在小的、不相交的块上独立运行，没有跨块依赖性，回归可以通过单个 T×T 对偶求解获得高效的精确闭式解。这既避免了基于梯度的迭代内层优化（如 TTT、ViT³、In-Place TTT 和 MesaNet），也避免了单步近似（如 delta 规则更新）。其次，我们不是使用测试时回归来产生输入相关的模型权重（Bertinetto et al., 2018; Sun et al., 2020）或随后被查询的快速权重记忆（Schlag et al., 2021; Yang et al., 2025c; Behrouz et al., 2026b），而是使用回归直接产生 token 块的表示。具体而言，拟合系数本身充当压缩表示（例如视觉 token 或检索键）。

3 通过测试时回归的联合序列压缩

我们介绍基于测试时回归的序列压缩算子 TTR-Compressor，如图 2(a) 所示。给定一系列 token 表示，TTR-Compressor 从 token 构造一个回归问题，并使用其拟合系数作为压缩表示。我们首先给出压缩的回归表述及其构造，然后推导高效解，并描述 TTR-Compressor 如何在模型内进行端到端学习。

3.1 将压缩作为测试时回归

我们将序列压缩表述为岭回归（Hoerl & Kennard, 1970）。序列中的 token 提供回归观测值，拟合的回归系数作为该序列的紧凑表示。回归目标鼓励该表示捕捉 token 之间的关系，而正则化控制拟合系数的大小。

给定序列 𝑿 = [𝒙₁, …, 𝒙_T]⊤ ∈ ℝ^(T×d)，我们的目标是将其 T 个 token 表示压缩为单个向量 𝒉 ∈ ℝ^d。我们将每个 token 与回归键 𝒌_t ∈ ℝ^d 和标量目标 v_t ∈ ℝ 相关联，并将压缩表示定义为：

𝒉⋆ = arg min_{𝒉∈ℝ^d} (1/2) Σ_{t=1}^T ω_t (𝒌_t⊤𝒉 − v_t)² + (λ/2)‖𝒉‖₂²， (1)

其中 ω_t ≥ 0 决定每个 token 的贡献，λ > 0 控制正则化。𝒉⋆ 通过拟合其 token 间的键-目标关系来概括序列。

回归目标 v_t 通过任务损失进行元学习，而回归本身在训练和推理期间针对每个输入序列进行构造和求解。

总体而言，我们在求解一个双层优化，其中外层目标是寻找对任务有用的目标 v_t 的任务损失，内层目标是求解压缩表示 𝒉⋆ 的测试时回归公式 1。这里，"测试时"指的是拟合这些输入特定的系数；学习到的模型参数在推理时保持固定。

图 2： TTR-Compressor 概览。 双层学习：内层求解将序列压缩表述为测试时岭回归，通过精确的对偶 Cholesky 求解获得表示 𝒉*，而回归参数通过任务梯度端到端学习。 输入相关的二阶自适应：通过格拉姆矩阵联合耦合 token，TTR 自然地降低了冗余 token 相对于加性池化的相对影响。为了直观说明，我们设置 𝑫 = 𝑰 和均匀目标 𝒗 = 𝟏；如实践中通常学习到的，较小的正则化项 𝑫 会进一步放大这种去重效应，为独特 token 带来更高的相对份额。

3.2 构造回归问题

键和目标。 我们通过归一化输入特征构造回归键，并使用学习投影生成标量目标：

𝒌_t = 𝒙_t / ‖𝒙_t‖₂， v_t = 𝒂⊤𝒙_t，

其中 𝒂 ∈ ℝ^d 在压缩器内的所有 token 和序列之间共享。

键归一化确保 𝑲⊤𝑲 仅度量方向（语义）相似性（Liu et al., 2017）。至关重要的是，这种归一化是不对称的，因为目标保留了原始 token 幅度（v_t = 𝒂⊤𝒙_t）。如果目标也被归一化（v_t = 𝒂⊤𝒌_t），拟合项将退化为 (1/2)‖𝑲(𝒉 − 𝒂)‖₂²，使 𝒉⋆ 平凡地坍缩到序列不变的静态向量 𝒂。通过在目标中保留 token 范数，没有常数向量可以拟合变化的幅度，迫使 𝒉⋆ 动态整合 token 语义及其相对重要性。

目标完全来自输入，因此拟合 𝒉⋆ 不需要额外的标签。

可选地，可以通过首先应用局部卷积（语言为 1D，视觉为 2D）在投影之前聚合相邻上下文来进一步丰富目标，即 v_t = 𝒂⊤Conv(𝑿)，其中 Conv(·) 表示卷积算子，𝑿 表示位置 t 周围 n 个相邻 token 的局部上下文窗口。v_t 的其他参数化在附录 E.2 中探讨。

均匀 token 贡献。 我们使用均匀权重 ω_t = 1，为每个 token 的回归误差分配相同的系数。

令 𝑲 = [𝒌₁, …, 𝒌_T]⊤ ∈ ℝ^(T×d) 和 𝒗 = [v₁, …, v_T]⊤ ∈ ℝ^T。将公式 1 的梯度设为零可得闭式解：

(𝑲⊤𝑲 + λ𝑰_d)𝒉⋆ = 𝑲⊤𝒗， 𝒉⋆ = (𝑲⊤𝑲 + λ𝑰_d)^(−1)𝑲⊤𝒗。 (2)

由于 λ > 0，目标是严格凸的且具有唯一解。

该解将键-目标统计量 𝑲⊤𝒗 与序列相关的特征几何 𝑲⊤𝑲 相结合。

可学习对角正则化。 在常规岭回归中，λ 是一个可调超参数。这种调优在大模型预训练期间代价高昂，并且使扩展到不同模型尺寸变得复杂。为避免这一点，我们将 λ𝑰_d 替换为可学习的正对角矩阵（通过任务损失元学习），产生广义岭回归目标（Tikhonov & Arsenin, 1977）：

𝑫 = diag(δ₁, …, δ_d)， δ_j = softplus(ρ_j)， (3)

其中 𝝆 ∈ ℝ^d 可训练。

由此产生的目标及其解为：

𝒉⋆ = arg min_𝒉 (1/2)‖𝑲𝒉 − 𝒗‖₂² + (1/2)𝒉⊤𝑫𝒉， (4)
= (𝑲⊤𝑲 + 𝑫)^(−1)𝑲⊤𝒗， (5)

它求解了一个考虑 token 成对交互的正则化线性系统。

3.3 高效的对偶形式解

直接计算公式 2 需要求解 d×d 线性系统。当被压缩的 token 数量通常小于特征维度时，我们转而使用等价的对偶形式（Saunders et al., 1998）以提高计算效率：

𝒉⋆ = 𝑲⊤(𝑲𝑲⊤ + λ𝑰_T)^(−1)𝒗。 (6)

这将特征空间系统替换为 T×T 的 token 空间系统。其条目取决于回归键之间的成对相似性，使拟合的表示能够考虑 token 之间的相关性。

我们通过求解 (𝑲𝑲⊤ + λ𝑰_T)𝜶 = 𝒗 并计算 𝒉⋆ = 𝑲⊤𝜶 来计算公式 6，而无需显式形成逆。由此产生的计算成本为 𝒪(T²d + T³)，相比之下直接原始形式的成本为 𝒪(Td² + d³)。因此，对偶形式特别适合压缩高维特征的短序列。

获得高效的对偶解。 通过第 3.2 节引入的可学习对角正则化，λ𝑰_d 被 𝑫 替换。为获得高效的对偶解，我们将键重新缩放为 𝑲̃ = 𝑲𝑫^(−1/2)，得到 TTR-Compressor 的最终形式：

TTR(𝑿) = 𝑫^(−1/2)𝑲̃⊤(𝑰_T + 𝑲̃𝑲̃⊤)^(−1)𝒗 (7)

由于 𝑫 是对角的，重新缩放键的成本仅为 𝒪(Td)，保持了对偶表述的整体复杂度。在实践中，我们计算 Cholesky 分解 𝑳𝑳⊤ = 𝑰_T + 𝑲̃𝑲̃⊤，通过三角求解求解 𝑳𝑳⊤𝜶 = 𝒗，并返回 𝑫^(−1/2)𝑲̃⊤𝜶。

3.4 完全端到端训练

目标投影 𝒂 和对角参数 𝝆 通过可微闭式解使用原始模型的训练目标进行端到端优化。每个压缩器维护自己的参数，这些参数在所有输入序列之间共享。在推理时，这些学习到的参数保持固定，而 𝒉⋆ 则针对每个输入序列独立重新计算。因此，TTR-Compressor 将学习到的回归目标与精确的、输入自适应的解相结合，而无需在测试时进行基于梯度的迭代优化。

4 理解 TTR-Compressor

TTR-Compressor 的学习过程可以分解为两种不同的机制：外层循环训练学习哪个回归问题对压缩有用，而内层解使压缩表示适应当前输入的统计特性。我们分别对其进行考察。

4.1 压缩目标的任务监督学习

回归目标并非独立于任务而规定。其目标 v_t = 𝒂⊤𝒙_t 和正则化矩阵 𝑫 通过压缩表示的下游使用来学习。将 𝒉⋆_{𝒂,𝝆} 写为回归解，训练目标采用以下形式：

min_{θ,𝒂,𝝆} 𝔼_{(x,y)}[ℒ_task(F_θ(𝒉⋆_{𝒂,𝝆}(𝑿_θ(x))), y)]， (8)

其中 𝑿_θ 产生输入表示，F_θ 表示后续计算。因此，外层目标评估 𝒉⋆ 对最终任务的有用性，而不是利用其可学习性来仅仅最小化内层回归误差。

学习目标和正则化。 这种耦合可以直接从梯度中看出。令 𝑨 = 𝑲⊤𝑲 + 𝑫，𝒈 = ∇_{𝒉⋆}ℒ_task，𝒔 = 𝑨^(−1)𝒈。对回归解求导可得：

∇_𝒂ℒ_task = 𝑿⊤𝑲𝒔， ∇_𝝆ℒ_task = −sigmoid(𝝆) ⊙ 𝒉⋆ ⊙ 𝒔， (9)

其中 ⊙ 表示逐元素乘法。因此，下游梯度塑造了通过 𝒂 从 token 导出的标量目标和通过 𝝆 施加的逐坐标惩罚。因此，标量目标不需要预定义的语义；相反，它们充当学习到的度量，其拟合系数为下游层产生信息丰富的表示。在这个意义上，回归为压缩提供了结构性归纳偏置，而外层优化则引导这种结构性偏置更好地处理下游任务。

4.2 输入相关的二阶自适应

除了学习回归目标之外，内层求解还使压缩表示适应每个输入的相关结构。对于各向同性正则化，对偶形式的解为：

𝒉⋆ = 𝑲⊤(𝑲𝑲⊤ + λ𝑰)^(−1)𝒗。 (10)

令 𝑮 = 𝑲𝑲⊤ ∈ ℝ^(T×T)。由于键是归一化的，每个条目 G_ij = 𝒌_i⊤𝒌_j 直接度量 token i 和 j 之间的相似性。因此，𝑮 捕捉 token 组的输入相关二阶相关结构。

压缩表示可以等价地写为：

𝒉⋆ = 𝑲⊤𝜶， 𝜶 = (𝑮 + λ𝑰)^(−1)𝒗。 (11)

与池化和投影中 token 贡献被独立聚合不同，有效权重 𝜶 由目标响应和所有成对 token 相关性共同决定。高度相似的 token 通过格拉姆矩阵显式耦合，因此冗余证据表现出递减而非累加的影响。相反，当回归目标支持时，未被强相关 token 解释的信息可以保留更大的相对影响，如图 2(b) 所示。因此，TTR 使其压缩规则适应每个输入的二阶结构，而不是应用固定或独立加权的 token 组合。

学习 token 间几何。 通过可学习对角正则化项 𝑫，这种解释扩展到重新缩放的键 𝑲̃ = 𝑲𝑫^(−1/2)。相应的 token 格拉姆矩阵变为：

𝑮̃ = 𝑲̃𝑲̃⊤ = 𝑲𝑫^(−1)𝑲⊤。 (12)

因此，训练学习在度量 token 相似性时哪些特征维度应该更重要。外层循环学习任务适应的相关几何，而内层求解使压缩表示适应每个单独输入的相关结构。

5 应用与实验结果

我们在两种设置下评估 TTR-Compressor：用于高效语言建模的块级稀疏注意力（压缩表示引导上下文选择），以及用于高效多模态理解的视觉 token 合并（压缩表示作为语言主干的视觉输入）。

5.1 块级稀疏注意力

架构与基线。 块级稀疏注意力将上下文划分为块，将它们的压缩表示与每个查询进行评分，并在局部窗口旁边关注所选块中的 token。因此，压缩器决定了哪些远距离信息仍然可访问：无论其单个 token 表示的质量如何，信息不丰富的摘要都可能阻止相关块被选中。

我们采用 HiLS-Attention（Hu et al., 2026）作为基础框架，仅改变压缩器。HiLS-Attention 具有三个有效的架构组件：分层 softmax 注意力，将块内注意力与学习到的块级权重相结合；低秩查询校准，使查询适应压缩表示的评分；以及 HoPE，仅对特征维度的子集应用 RoPE 以支持长度外推。我们比较四种压缩器：平均池化、拼接与投影、原始 HiLS-Attention 中使用的注意力加权池化，以及 TTR-Compressor。全注意力和滑动窗口注意力作为额外参考。

训练与评估。 我们在 FineWeb 数据集（Penedo et al., 2024）上训练 345M 参数的语言模型，上下文长度为 8K。训练运行 30,000 个优化步骤，全局批大小为 128 个序列，对应于大约 30B 个 token，并使用学习率为 3×10⁻⁴ 的 AdamW。所有稀疏注意力变体使用 64-token 块，每个查询最多选择 32 个远距离块，并保留 512-token 的局部窗口。

5.2 视觉 token 合并器

架构与基线。 高分辨率图像产生大量视觉 token，使得语言主干直接处理它们代价高昂。因此，现代多模态模型通常使用空间合并器来减少视觉序列长度。一种广泛采用的设计将每个 2×2 相邻视觉特征组拼接起来，并通过两层 MLP 将其映射为一个 token（Wang et al., 2025; Bai et al., 2025; Qwen Team, 2026a; Team et al., 2026b）。更长的多模态上下文和具有重复视觉观察的智能体工作流进一步推动了更强的压缩，例如 3×3 合并（Team et al., 2026a; DeepSeek-AI, 2026）。

我们将 TTR-Compressor 与标准 MLP 合并器进行比较。TTR-Compressor 对每个空间组拟合一个回归，将其四个或九个视觉特征压缩为单个向量，然后由两层 MLP 投影到语言模型的隐藏维度。其卷积变体在构造回归目标之前对特征图应用 3×3 深度卷积。

训练与评估。 我们使用 Qwen3-VL（Bai et al., 2025）的 ViT 作为视觉编码器，Qwen3-4B-Instruct（Yang et al., 2025a）作为语言模型。训练包括两个阶段。第一阶段仅在 LLaVA-558K（Liu et al., 2024a）上训练合并器模块一个 epoch，学习率为 10⁻³。第二阶段在 1.3M 指令样本上联合训练合并器模块和语言主干一个 epoch，混合图像（Liu et al., 2024b）、多图像（Li et al., 2024）和视频（Zhang et al., 2024）数据，学习率为 2×10⁻⁵。

6 结语

在这项工作中，我们通过测试时回归的视角重新审视了序列压缩——现代架构中普遍存在但经常被忽视的瓶颈。我们没有依赖固定池化或学习投影，而是将 token 压缩表述为实例自适应的岭回归问题，允许直接从每个输入序列求解压缩表示。

通过二阶交互利用 token 间相关性，TTR-Compressor 提供了一种更具表现力的方式来保留序列信息，同时保持轻量级和参数高效。其对偶形式解进一步使这种表述在实践中具有可扩展性。

在经验上，TTR-Compressor 在块级稀疏注意力和多模态 token 缩减方面均表现强劲，改善了长上下文检索，同时以显著更少的 token 匹配标准视觉合并器。

更广泛地说，我们的结果表明，序列压缩不必被视为静态聚合，而可以被视为适应每个序列结构的输入相关推理问题。我们期望这一视角将测试时回归确立为高效基础模型的简单、富有表现力且可扩展的原语。

附录 A 对偶形式解的推导

我们首先证明岭回归原始形式和对偶形式（公式 6）之间的等价性。然后我们证明，通过可学习对角正则化，重新缩放键可以得到公式 7 中的对偶解。

原始形式和对偶形式的等价性。

引理 1（推进恒等式）。对于任意 𝐊 ∈ ℝ^(T×d) 和 λ > 0，

(𝑲⊤𝑲 + λ𝑰_d)^(−1)𝑲⊤ = 𝑲⊤(𝑲𝑲⊤ + λ𝑰_T)^(−1)。 (13)

证明。 𝑲⊤𝑲 和 𝑲𝑲⊤ 都是半正定的。因此，对于 λ > 0，矩阵 𝑲⊤𝑲 + λ𝑰_d 和 𝑲𝑲⊤ + λ𝑰_T 是对称正定的，因此可逆。直接展开两边可得

(𝑲⊤𝑲 + λ𝑰_d)𝑲⊤ = 𝑲⊤𝑲𝑲⊤ + λ𝑲⊤ = 𝑲⊤(𝑲𝑲⊤ + λ𝑰_T)。 (14)

左乘 (𝑲⊤𝑲 + λ𝑰_d)^(−1) 并右乘 (𝑲𝑲⊤ + λ𝑰_T)^(−1) 得到公式 13。∎

将公式 13 右乘 𝒗，将公式 2 中的原始解变为公式 6 中的对偶形式：

𝒉⋆ = (𝑲⊤𝑲 + λ𝑰_d)^(−1)𝑲⊤𝒗 = 𝑲⊤(𝑲𝑲⊤ + λ𝑰_T)^(−1)𝒗。 (15)

因此，𝒉⋆ 位于 𝑲 的行空间中。其对偶系数 𝜶 = (𝑲𝑲⊤ + λ𝑰_T)^(−1)𝒗 ∈ ℝ^T 通过求解单个 T×T 系统获得。

对角正则化下的对偶解。

命题 1。 令 𝐃 = diag(δ₁, …, δ_d)，δ_j > 0，并令 𝐊̃ = 𝐊𝐃^(−1/2)。则公式 4 的解满足

(𝑲⊤𝑲 + 𝑫)^(−1)𝑲⊤𝒗 = 𝑫^(−1/2)𝑲̃⊤(𝑰_T + 𝑲̃𝑲̃⊤)^(−1)𝒗。 (16)

证明。 由于 𝑫 是具有正条目的对角矩阵，𝑫^(±1/2) 是良定义的且 𝑫^(1/2)𝑫^(−1/2) = 𝑰_d。使用 𝑲 = 𝑲̃𝑫^(1/2)，我们分解

𝑲⊤𝑲 + 𝑫 = 𝑫^(1/2)(𝑲̃⊤𝑲̃ + 𝑰_d)𝑫^(1/2)。 (17)

对该乘积求逆并使用 𝑲⊤ = 𝑫^(1/2)𝑲̃⊤ 可得

(𝑲⊤𝑲 + 𝑫)^(−1)𝑲⊤𝒗 = 𝑫^(−1/2)(𝑲̃⊤𝑲̃ + 𝑰_d)^(−1)𝑫^(−1/2)𝑫^(1/2)𝑲̃⊤𝒗 = 𝑫^(−1/2)(𝑲̃⊤𝑲̃ + 𝑰_d)^(−1)𝑲̃⊤𝒗。 (18)

将引理 1 应用于 𝑲 ← 𝑲̃ 和 λ = 1 得到公式 16。∎

等价地，变量替换 𝒈 = 𝑫^(1/2)𝒉 将公式 4 转换为标准岭问题 (1/2)‖𝑲̃𝒈 − 𝒗‖₂² + (1/2)‖𝒈‖₂²。然后其对偶解通过 𝒉⋆ = 𝑫^(−1/2)𝒈⋆ 映射回来。

由此可得两个进一步的性质：

  • 矩阵 𝑰_T + 𝑲̃𝑲̃⊤ 是对称正定的，因此其 Cholesky 分解存在且唯一。
  • 由于 𝑫 是对角的，形成 𝑲̃ 和应用 𝑫^(−1/2) 的成本分别仅为 𝒪(Td) 和 𝒪(d)。因此整体复杂度保持为 𝒪(T²d + T³)。

设置 𝑫 = λ𝑰_d 可恢复公式 6。

附录 B TTR-Compressor 的冗余感知加权

我们形式化第 4.2 节中的断言：冗余 token 的影响力递减，而未被相关 token 解释的信息保留较大的相对影响。我们采用各向同性正则化 λ > 0，并将目标 𝒗 视为任意的，因此结果适用于任何学习投影 𝒂。对可学习 𝑫 的扩展在最后给出。在整个过程中，令 𝑨 = 𝑲⊤𝑲 + λ𝑰_d，𝜶 = (𝑮 + λ𝑰_T)^(−1)𝒗，因此 𝒉⋆ = 𝑲⊤𝜶。

有效权重作为未解释残差。

命题 2（残差形式）。对于任意键 𝐊 和目标 𝐯，有效权重满足

𝜶 = (1/λ)(𝒗 − 𝑲𝒉⋆)。 (19)

证明。 由 (𝑮 + λ𝑰_T)𝜶 = 𝒗 可得 λ𝜶 = 𝒗 − 𝑲𝑲⊤𝜶 = 𝒗 − 𝑲𝒉⋆。∎

因此，token 的权重由联合拟合表示未解释的目标部分决定。相比之下，加性池化无论其他 token 如何排列都分配权重 𝒗。为了分离其他 token 的作用，令 𝑲_{−t} 和 𝒗_{−t} 表示移除 token t 后的键和目标。定义

𝑨_{−t} = 𝑲_{−t}⊤𝑲_{−t} + λ𝑰_d， 𝒉_{−t} = 𝑨_{−t}^(−1)𝑲_{−t}⊤𝒗_{−t}， (20)

其中 𝒉_{−t} 是不含 token t 拟合的解。

命题 3（留一形式）。令 r_t = v_t − 𝐤_t⊤𝐡_{−t} 为 token t 在其他 token 下的残差，令 q_t = 𝐤_t⊤𝐀_{−t}^(−1)𝐤_t ≥ 0。则

α_t = r_t / (λ(1 + q_t))， 𝒉⋆ = 𝒉_{−t} + (r_t/(1 + q_t))𝑨_{−t}^(−1)𝒌_t。 (21)

证明。 写出 𝑨 = 𝑨_{−t} + 𝒌_t𝒌_t⊤ 和 𝑲⊤𝒗 = 𝑲_{−t}⊤𝒗_{−t} + v_t𝒌_t。代入 𝑨𝒉⋆ = 𝑲⊤𝒗 可得

𝒉⋆ = 𝒉_{−t} + (v_t − 𝒌_t⊤𝒉⋆)𝑨_{−t}^(−1)𝒌_t。 (22)

与 𝒌_t 取内积可得 𝒌_t⊤𝒉⋆ = 𝒌_t⊤𝒉_{−t} + (v_t − 𝒌_t⊤𝒉⋆)q_t，因此 v_t − 𝒌_t⊤𝒉⋆ = r_t/(1 + q_t)。将其代入上式和公式 19 得到公式 21。∎

命题 3 表明，token t 仅通过 r_t（其目标中剩余 token 无法预测的部分）改变表示。特别地，如果其他 token 完全解释了 token t（r_t = 0），则 α_t = 0 且 𝒉⋆ = 𝒉_{−t}，因此该 token 没有影响。加性池化则总是加上 v_t𝒌_t。

重复证据下的饱和。 我们现在对相关 token 组量化这种效应，推广图 2(b) 中的例子。

命题 4（组饱和）。假设 token 形成 C 个组。组 c 包含 m_c 个共享键 𝐮_c 的 token，其中 ‖𝐮_c‖₂ = 1 且 𝐮_c⊤𝐮_{c'} = 0（c ≠ c'）。令 S_c 为组 c 中目标的和。则

𝒉⋆ = Σ_{c=1}^C (S_c/(λ + m_c))𝒖_c， 而 𝑲⊤𝒗 = Σ_{c=1}^C S_c𝒖_c。 (23)

证明。 在此假设下 𝑮 是块对角的，组 c 的块为 𝑱_{m_c} = 𝟏𝟏⊤。由于 𝑱_m² = m𝑱_m，可以验证 (𝑱_m + λ𝑰_m)^(−1) = λ^(−1)(𝑰_m − 𝑱_m/(λ + m))。因此组 c 的权重 𝜶_c 之和为

𝟏⊤𝜶_c = (1/λ)(S_c − m_cS_c/(λ + m_c)) = S_c/(λ + m_c)。 (24)

因此 𝒉⋆ = Σ_c 𝒖_c𝟏⊤𝜶_c，得到公式 23。∎

推论 1（冗余的递减影响）。假设每个 token 具有相同的目标 v > 0，因此 S_c = m_cv。比较 m 个重复 token 的组与单个独特 token。它们的相对影响为

[m/(λ+m)] / [1/(λ+1)] = m(λ+1)/(λ+m) < m，当 m > 1。 (25)

该比值对所有 m 以 λ + 1 为界，而加性池化的相应比值为 m。此外，第 n 个重复 token 使组的系数增加

nv/(λ+n) − (n−1)v/(λ+n−1) = λv/[(λ+n)(λ+n−1)] = 𝒪(n^(−2))， (26)

它随 n 衰减，因此重复证据具有递减的回报。

岭强度控制两种机制之间的过渡：

  • 当 λ → ∞ 时，λ𝒉⋆ → 𝑲⊤𝒗，即加性池化。
  • 当 λ → 0 时，每组贡献 S_c/m_c（其平均目标），无论它包含多少 token。

设置 λ = 1、m = 3 可恢复图 2(b)：比率为 3:2，𝜶 = (1/4, 1/4, 1/4, 1/2)⊤。

对可学习对角正则化的扩展。 所有结果都适用于可学习对角正则化。使用命题 1 中的变量替换，设置 𝜶 = (𝑰_T + 𝑲̃𝑲̃⊤)^(−1)𝒗，因此 𝒉⋆ = 𝑫^(−1)𝑲⊤𝜶。由于 𝑲𝒉⋆ = 𝑲̃𝑲̃⊤𝜶，命题 2 的论证给出 𝜶 = 𝒗 − 𝑲𝒉⋆。然后命题 3 在 λ = 1 和 𝑨_{−t} = 𝑲_{−t}⊤𝑲_{−t} + 𝑫 下成立。当组在学习到的度量下正交（𝒖_c⊤𝑫^(−1)𝒖_{c'} = 0，c ≠ c'）时，命题 4 成立，其中 λ 被组特定的 λ_c = (𝒖_c⊤𝑫^(−1)𝒖_c)^(−1) 替换，𝒖_c 被替换为 λ_c𝑫^(−1)𝒖_c。因此，学习到的 𝑫 决定哪些特征方向被视为冗余，而递减影响机制本身保持不变。

附录 C 实现细节

数值精度。 卷积和目标投影使用输入精度（BF16），而回归键和目标在对偶求解之前被转换为 FP32。对角正则化在 FP32 中评估。我们使用 Cholesky 分解求解正定对偶系统，而不显式形成逆，并将压缩表示转换回输入数据类型。

局部目标构造。 只有回归目标包含卷积上下文；键由原始输入计算。对于语言，我们在每个压缩块内独立应用核大小为 5 的非因果深度 1D 卷积，使用宽度为 2 的双侧零填充。该卷积既无偏置也无激活，并初始化为恒等。对于视觉，我们使用 3×3 深度卷积。每个通道都有自己的空间核，在标量目标投影之前没有跨通道混合。

基础压缩器具有 2d 个有效可训练参数：d 个用于目标投影，d 个用于对角正则化。具有 s 个核元素的无偏置深度卷积增加 sd 个参数和 𝒪(sTd) 计算。因此，语言和视觉变体分别需要 7d 和 11d 个参数。它们的总计算复杂度在固定核大小和 T ≪ d 下保持为 𝒪(T²d)。

附录 D 实验细节

块级稀疏注意力。 HiLS-Attention（Hu et al., 2026）认为，小模型为 RULER 主要的"查找并复制"任务提供了更具诊断性的设置，因为较大的模型可能通过更大的信息带宽来补偿检索的不准确性。因此，我们遵循他们的设置，使用 345M 参数模型来评估压缩质量。所有模型使用 16 个 Transformer 层、1024 的隐藏维度、4096 的 FFN 维度，以及具有 16 个查询头和 2 个键-值头的分组查询注意力。我们使用秩 64 查询校准。训练使用 0.01 的 AdamW 权重衰减和范数为 1.0 的梯度裁剪；归一化参数、偏置和嵌入不参与权重衰减。学习率在训练的前 0.7% 期间预热，之后保持恒定。

视觉 token 合并器。 我们使用 BF16 训练，配合 DeepSpeed ZeRO-1、梯度检查点和 16,384 token 的最大序列长度。两个阶段使用每设备批大小 4 和 1，分别在 4 和 8 步上进行梯度累积。两个阶段都应用 3% 的学习率预热，然后是余弦衰减，最小学习率分别为 10⁻⁵ 和 0，权重衰减分别为 0.01 和 0.02。对于 TTR-Compressor，回归系统在 FP32 中求解。

E.2 值参数化的消融

如表 8 所示，我们观察到： 内容依赖性至关重要：常数目标产生最低的平均值（53.56），而线性目标获得 +0.74，表明回归目标必须编码 token 内容以形成有效的摘要。 更深头部提供边际增益：普通 MLP 与线性基线匹配（54.30），添加卷积使其退化（53.91）。虽然双线性头部略微提高了性能（54.55），但其卷积对应物没有进一步增益（54.37）。 空间上下文胜过头部容量：结合局部卷积与线性读出 v_t = 𝒂⊤Conv(𝑿)_t 实现最佳总分（54.85）。这些结果表明，值容量不是瓶颈；局部邻域聚合比非线性投影提供了更有效的归纳偏置。
