原标题：Anthropic’s new Fable release is cheaper, less restrictive

中文摘要： Anthropic 发布了限制更少、成本更低的 Fable 5.1 模型，仅限特定领域合作伙伴使用的 Mythos 5.1 也同步推出。新模型支持零数据保留，允许客户在本地基础设施运行，并将于秋季推出高隐私服务。Anthropic 强调从未未经许可使用企业数据训练。新模型在多项基准测试中创下纪录，并产出了多项科学发现。系统卡片指出，Mythos 在自我迭代风险上被评为低风险，但在不当行为上较 Opus 略有倒退。

与之前的 Mythos 模型一样，Mythos 5.1 将仅提供给从事网络安全或生命科学研究的已注册 Anthropic 合作伙伴。而无限制版本的 Fable 5.1，从今天起可通过云平台或 Anthropic API 使用。

其中一项最重大的变化是 Anthropic 此前曾报道过的对“零数据保留”的采纳，允许客户在自己的基础设施上运行 Anthropic 模型而不会发生数据外流。由于安全方面的考虑，此前 Fable 无法使用的一项名为“Enterprise Frontier Safeguards”的高隐私服务，将于今年秋季向用户推出。值得注意的是，该系统仍会监控代理或人类用户的滥用行为，但客户将可以自行控制监控的方式。

作为公告的一部分，Anthropic 向客户保证他们的数据没有被不当访问。公告中写道：“Anthropic 从未在未经明确许可的情况下使用企业数据进行训练，而且永远不会。”

正如 Anthropic 发布新模型的惯例，新模型在一系列基准测试中创下了纪录，包括 Terminal-Bench 4.0（用于基于 CLI 的编码）和 Humanity’s Last Exam（用于通用推理）。Anthropic 还发布了模型在发布前生成的三项全新科学发现，包括一项定制的 GPU 优化方案，以及一张由现有照片拼合而成的高分辨率金星地图。

与之前的发布一样，这些模型附带了一份详细的系统卡片，以最直白的方式解释了它们的能力。系统卡片将 Mythos 在与自动化 AI 开发（即 AI 自我改进）相关的风险评估为“低风险”，一些人认为这种自我改进可能会导致人类失去控制权。卡片指出，“其加速内部 AI 研发进展的能力与当前趋势相符。”

在一般性的不当行为方面，Mythos 比 Opus 稍微更容易出现这种情况，这可能是由于其能力增强所致。

系统卡片写道：“与 Opus 5 相比，Mythos 5.1 在整体目标偏离行为上略有倒退，但比 Mythos 5 和 Claude Sonnet 5 有所改善。它比 Opus 5 更容易配合人类的滥用行为，也更容易接受无法验证的授权声明，但它比以前的模型更不容易忽视明确的限制、产生输入幻觉或谎称已完成任务。”
