摘要
冗余机器人多轴增材制造（MAAM）能够实现无支撑和共形制造，但在严格的沉积位置约束和时变碰撞约束下，长时程路径的轨迹优化仍面临挑战。本文提出了一种用于冗余机器人MAAM中碰撞感知轨迹优化的计算框架。我们首先利用相对雅可比公式化喷嘴-工件的相对运动学，并开发了一种基于可微SDF的碰撞模型，该模型能够捕捉制造引起的几何演化并提供优化梯度。然后，通过将沉积位置作为逐路径点的硬等式约束，利用迭代投影到自运动流形上，并将损失梯度限制在相应的切空间中来实现约束。在具有多种长时程无支撑和共形刀路的8自由度机器人MAAM平台上的实验表明，我们的方法将平均喷嘴位置误差保持在10 μm以下，最大关节加加速度降低高达77.6%，并消除了所有采样碰撞和姿态违规。与基于SQP的基线方法相比，实现了高达10.2倍的加速和更好的收敛性。物理制造实验进一步验证了所得到的平滑、无碰撞轨迹能够成功打印复杂几何形状，且可见的沉积缺陷更少。
I 引言
多轴增材制造（MAAM）通过局部控制喷嘴的位置和姿态实现空间材料对齐，从而实现诸如消除支撑结构[10, 28]、提高表面质量[23]以及定制制造模型的各向异性强度[12, 11]等先进功能。冗余机器人系统被广泛用于提供MAAM所需的运动自由度和工作空间[31, 29]。在这些系统中，可用自由度（DOF）超过沉积任务所需的自由度，提供了可用于运动相关目标的额外自由度[17, 21]。
图1展示了一个冗余机器人MAAM系统的示例。该装置总共有8个自由度，结合了ABB IRB 1200机器人手臂（6自由度）和ABB IRBP A 250变位机（2自由度）。该装置可以成功执行两种代表性的多轴AM工艺：1）无支撑空间打印[19]，通过装置的同步运动在无支撑结构的情况下打印自由曲面几何体（图1(a)）；2）共形表面打印[30]，通过局部调整喷嘴姿态在现有物体上沉积材料（图1(b)）。
对于这两种任务，机器人装置的冗余运动允许存在无限多种遵循相同刀路的关节构型，为优化运动和制造相关目标（如运动平滑性和碰撞避免）开辟了广阔的解空间[15, 1]。
图1：冗余机器人MAAM场景和轨迹优化挑战概述。8自由度平台为复杂自由曲面打印提供冗余运动。考虑了两种代表性场景： 无支撑空间打印，从基板上构建自由曲面结构； 共形表面打印，在现有物体上沉积材料。 打印成品部件。
制造任务的运动规划需要 处理具有大量路径点的长时程刀路并保持良好的可扩展性， 满足无碰撞约束， 生成优化的平滑关节轨迹并减少加速度/加加速度峰值。
I-A 轨迹优化中的挑战与相关工作
尽管冗余机器人MAAM提供了复杂打印任务所需的运动自由度，但在长时程刀路上利用这种自由度进行高效轨迹优化仍然具有挑战性。主要复杂性来自以下三个方面：
• 高精度路径跟踪与平滑运动。对于MAAM工艺，喷嘴必须准确跟随预定的沉积路径，同时满足打印姿态要求。这种路径跟踪必须与平滑的冗余运动相结合（图1(f)），因为突然的运动变化和高加加速度会降低沉积稳定性和打印质量[9, 8]。
• 演化的碰撞约束。在打印过程中，沉积材料不断改变工件几何形状，并成为后续运动的动态演化障碍物。优化器必须处理沿轨迹的机器人-工件和机器人-机器人碰撞（图1(e)），其中碰撞约束是非凸的且计算代价高昂[16, 26, 27]。
• 优化的可扩展性。MAAM刀路通常包含数千到数万个路径点（见图1(d)）。直接求解完整的约束问题计算代价高昂，而逐路径点优化可能产生不连续运动[22, 13]。
这些挑战需要一种统一的优化框架，该框架能够保持沉积精度、处理演化的碰撞约束，并在长时程刀路上高效地解析冗余且具有良好的可扩展性。
然而，现有方法通常只解决该问题的部分内容，无法为具有冗余机器人装置的MAAM提供充分的解决方案。
对于具有冗余机器人系统的路径约束规划任务，一种经典方法是基于惩罚的方法族，包括STOMP[13]、CHOMP[20]和路径逆运动学（IK）求解器[14]。它们计算效率高，已被广泛用于在考虑重构成本的同时优化平滑性[26, 16, 25]。然而，由于沉积要求仅作为软惩罚应用，位置精度本质上通过惩罚权重与平滑性进行权衡。
精确的路径约束可以通过参数化任务空间冗余来实现，例如绕喷嘴轴的自由旋转[6, 2]。虽然这保持了跟踪精度，但它依赖于显式的低维参数化[5]，并且不能扩展到高冗余系统（例如图1所示的系统），其中冗余无法由单个直观参数捕捉。另一方面，序列二次规划（SQP）类方法[22, 4]显式地强制约束，并已应用于加加速度感知的轨迹优化[9, 8, 6]。通过直接施加约束，它们在保持路径跟踪精度的同时，在优化中将冗余作为附加决策变量进行解析，这自然地适应了高维冗余系统[8]。然而，基于SQP的方法对于长时程轨迹优化任务通常产生高计算成本，因为每次迭代求解的二次子问题的大小随变量和约束数量的增长而增长，导致每次迭代的成本随问题维度急剧增加[3]。
对于大多数这些工作，碰撞处理是另一个尚未充分解决的关键组成部分。许多轨迹优化器依赖于预计算或静态碰撞模型[22, 20]，它们假设在整个规划过程中环境是已知且不变的[16, 26, 27]。如上所述，对于增材制造任务，将碰撞模型简化为静态会极大地限制可行搜索空间[19]。为了应对这些约束，先前的工作通常依赖于图搜索阶段，首先离散化冗余自由度并修剪碰撞构型，然后由连续优化器细化幸存的候选者[9, 31]。虽然这在短刀路（即数百个路径点[8]）上可能有效，但搜索图随路径点数量和冗余维度组合增长。目前没有现有工作能够同时解决具有动态演化碰撞约束的长时程MAAM轨迹优化问题。
I-B 我们的方法与贡献
本文提出了一种基于梯度投影的可扩展轨迹优化框架，用于冗余机器人MAAM，通过流形投影强制沉积位置精度，并通过可微SDF惩罚模型纳入演化碰撞约束。核心思想是将路径跟踪要求视为定义自运动流形的逐路径点等式约束，并将每个梯度更新投影到其切空间上。该投影直接在关节空间中操作，不需要冗余的显式低维参数化，因此自然地适应高维冗余系统。与传统的基于惩罚的方法（通过调节权重在沉积精度与平滑性之间进行权衡）或SQP类方法（反复求解代价高昂的约束子问题）不同，所提出的投影将沉积路径精度保持到数值精度，同时保留了基于梯度优化的低每次迭代成本，使其可扩展到长时程刀路。
为了处理连续演化的工件，我们提出了一种基于隐式符号距离场（SDF）表示的面向制造的可微碰撞检测模型。在每个轨迹点处，在刀路的已沉积部分和机器人构型之间执行碰撞检测。这模拟了增量增长的工件，同时为基于梯度的冗余解析提供可微的碰撞信息，避免了单独的图搜索预过滤阶段。由于SDF查询及其梯度在各路径点之间是独立的，碰撞模型自然地与投影梯度优化器集成，并可在GPU上并行评估以实现高效优化。
本文的技术贡献总结如下：
• 我们将冗余机器人MAAM轨迹规划公式化为长时程硬路径约束优化问题，联合优化平滑性、姿态一致性、动态可行性和碰撞避免。
• 我们开发了一种针对MAAM定制的可微碰撞模型，该模型沿沉积序列表示累积打印几何形状，并为轨迹优化提供碰撞梯度。
• 我们提出了一种轨迹级梯度投影优化器，在自运动流形投影和切空间冗余优化之间交替进行，无需显式冗余参数化即可保持跟踪精度。
所提出的框架在自由曲面模型的无支撑MAAM和复杂表面共形打印上进行了评估。在六个测试案例中，它将平均路径点位置误差保持在0.01 mm以下（模型尺寸的0.005%），在所采用的采样SDF碰撞模型下获得无碰撞和姿态一致的轨迹，并与基于SQP的基线相比实现了高达一个数量级（最高10.2倍）的加速和77.6%的最大加加速度降低。
II 无碰撞多轴增材制造的轨迹优化
在本节中，我们首先给出MAAM轨迹优化问题的公式，介绍一般冗余机器人装置的相对喷嘴-物体运动学，并提出考虑累积打印几何形状的基于SDF的可微碰撞模型。
II-A MAAM轨迹优化的问题公式
考虑由具有n个自由度的机器人系统执行MAAM任务以制造物体𝒪。该任务要求驱动末端执行器沿预定的空间打印路径𝒫 = {𝐩_i}{i=1}^N，每个点𝐩_i分配有参考无支撑打印方向𝐧_i。𝐩_i和𝐧_i均由基于场的切片器[19]生成，以确保无支撑可打印性（图2(a)）。对于共形表面打印，路径遵循主应力引导的共形刀路[24]以增强模型，而𝐧_i定义为局部表面法线以保持垂直于表面的沉积（见图1(c)、图8、图10）。预计算的路径和姿态用作我们运动规划框架的输入。
轨迹优化问题寻求一组可行的关节构型序列𝒬 = {𝐪_i}{i=1,...,N}，其中𝐪_i ∈ ℝ^n，在满足运动学和安全性要求的同时最小化动态代价：
min_𝒬 ∑{i=1}^N Φ_i(𝐯_i, 𝐚_i, 𝐣_i) (1)
s.t. 𝐅𝐊_𝐩(𝐪_i) = 𝐩_i, (2)
⟨𝐅𝐊_𝐧(𝐪_i), 𝐧_i⟩ ≥ cos θ_max, (3)
⟨𝐅𝐊_𝐧^m(𝐪_i), 𝐠⟩ ≥ cos θ_max^g, (4)
Γ(𝒪_i, 𝐪_i) = 0, (5)
𝐪_min ≤ 𝐪_i ≤ 𝐪_max, (6)
|𝐯_i| ≤ 𝐯_max, |𝐚_i| ≤ 𝐚_max, |𝐣_i| ≤ 𝐣_max. (7)
这里，目标函数Φ_i对速度、加速度和加加速度进行惩罚以确保运动平滑性：
Φ_i = ω_𝐯 𝐯_i^T 𝐖𝐯_i + ω_𝐚 𝐚_i^T 𝐖𝐚_i + ω_𝐣 𝐣_i^T 𝐖𝐣_i. (8)
ω_𝐯、ω_𝐚和ω_𝐣分别是速度、加速度和加加速度惩罚的权重系数，而𝐖是对角关节权重矩阵。
时间间隔Δt_i在优化前预计算，通常为Δt_i = ‖𝐩{i+1} - 𝐩_i‖ / v_print，其中v_print是末端执行器的规定恒定打印速度。
约束式(2)和式(3)强制刀路要求：末端执行器必须到达位置𝐩_i，同时保持工具姿态误差在容差θ_max以内（为获得高表面光洁度选择为30°[31]）。式(4)进一步要求主打印臂的喷嘴方向与重力方向𝐠保持在θ_max^g以内，这有助于保持可行的沉积姿态。此外，式(5)表示无碰撞条件，在优化过程中通过可微SDF惩罚来处理。最后，式(6)和式(7)指定了关节限位和动态可行性要求。

II-C MAAM的可微碰撞模型
如前所述，有效处理式(5)中的无碰撞约束是轨迹优化中的另一个挑战。困难来自碰撞几何的时变特性。在MAAM过程中，机器人几何形状随构型𝐪变化，而打印物体沿沉积路径持续增长。因此，在每次迭代中重建全局碰撞表示对于基于梯度的优化来说是低效且不可取的。
为了解决这个问题，我们提出了一种可微碰撞模型，将时变打印物体与固定的机器人连杆几何形状解耦。核心思想是为每个刚性机器人连杆预计算单独的SDF，并使用采样查询点表示增长的打印物体。具体地，对于每个机器人连杆和打印喷嘴ℐ_j ∈ {ℐ}，在其局部坐标系{LCS}j中预计算单独的SDF ϕ_SDF^{ℐ_j}(·)。如图4(a)所示，给定查询点𝐩_s，SDF返回其到连杆ℐ_j表面的有符号距离，而其空间梯度∇ϕ_SDF^{ℐ_j}(·)提供有符号距离增大的局部方向。这种单独SDF表示避免了为时变障碍物重建全局SDF，并在轨迹优化过程中保持梯度兼容性。

另一方面，增长的打印物体由每个路径点处沉积材料块的采样查询点表示。设𝒮_i表示在第i步近似所有障碍物当前几何形状的查询点集合，对于构型𝐪_i下的每个查询点𝐩_s ∈ 𝒮_i，我们首先将几何形状转换到{LCS}j（见图4(b)），然后可以使用预构建的SDF有效查询碰撞距离和相应的空间梯度：
d_coll^{ℐ_j}(𝐩_s, 𝐪_i) = ϕ_SDF^{ℐ_j}(^{L_j} 𝐩{L_j s}), (16)
∇{^{L_j} 𝐩{L_j s}} d_coll^{ℐ_j}(𝐩_s, 𝐪_i) = ∇ϕ_SDF^{ℐ_j}(^{L_j} 𝐩_{L_j s}).
这里，ϕ_SDF^{ℐ_j}(·)和∇ϕ_SDF^{ℐ_j}(·)分别表示连杆ℐ_j的预计算SDF和空间梯度，^{L_j} 𝐩_{L_j s}表示从{LCS}j原点到𝐩_s的向量，在{LCS}_j中表示。利用式(16)，式(5)中的碰撞约束可以转换为关于𝐪_i的可微函数：
g_coll^{ℐ_j, 𝐩_s}(𝐪_i) = -d_coll^{ℐ_j}(𝐩_s, 𝐪_i) ≤ 0, ∀ℐ_j ∈ ℐ, ∀𝐩_s ∈ 𝒮_i. (17)
为所有𝐩_s计算g_coll的梯度计算代价高昂。为了加速该过程，对于每个连杆ℐ_j，我们首先通过结合边界框过滤和Top-K最小有符号距离选择来构建稀疏活跃碰撞集：
𝒜{i,ℐ_j}^K = TopK_{𝐩_s ∈ {𝐩_s ∈ 𝒮_i | ^{L_j} 𝐩_{L_j s} ∈ ℬ_{L_j}}} (-d_coll^{ℐ_j}(𝐩_s, 𝐪_i)). (18)
仅使用𝒜_{i,ℐ_j}^K中的样本来评估碰撞梯度∇{𝐪_i} g_coll。值得一提的是，优化后，使用完整采样查询集评估碰撞可行性（即算法1中第14行的操作）。在我们的流程中，机器人连杆之间的自碰撞以相同方式处理，即将一个机器人连杆上的采样点作为查询点，在坐标变换后针对另一个目标连杆的SDF进行评估。
注意，碰撞查询需要将每个查询点𝐩_s转换到{LCS}_j中为^{L_j} 𝐩{L_j s}。因此，g_coll关于𝐪_i的梯度可以使用链式法则推导：
∇{𝐪_i} g_coll^{ℐ_j, 𝐩_s}(𝐪_i) = -[∇{^{L_j} 𝐩_{L_j s}} d_coll^{ℐ_j}(𝐩_s, 𝐪_i)]^⊤ ∂^{L_j} 𝐩_{L_j s}/∂𝐪_i (19)
= ∇ϕ_SDF^{ℐ_j}(^{L_j} 𝐩_{L_j s})^⊤ ^{L_j} 𝐑_X (𝐉_{𝐯,X,L_j} - 𝐒(^X 𝐩_{Xs}) 𝐉_{𝝎,X,L_j}).
这里，点雅可比项∂^{L_j} 𝐩_{L_j s}/∂𝐪_i使用微分运动学获得：
^{L_j} 𝐩̇{L_j s} = ^{L_j} 𝐑̇_X ^X 𝐩{Xs} - ^{L_j} 𝐑_X ^X 𝐩̇{XL_j} (20)
= -^{L_j} 𝐑_X 𝐒(^X 𝝎{L_j}) ^X 𝐩_{Xs} - ^{L_j} 𝐑_X ^X 𝐩̇{XL_j}
= -^{L_j} 𝐑_X (𝐉{𝐯,X,L_j} - 𝐒(^X 𝐩_{Xs}) 𝐉_{𝝎,X,L_j}) 𝐪̇i.
X ∈ {W, O, L_k}指定𝐩_s固定的坐标系。这些选择分别对应于与障碍物的碰撞检测、演化的𝒪_i以及机器人连杆（包括机器人间和自碰撞情况）。矩阵𝐉{𝐯,X,L_j}和𝐉_{𝝎,X,L_j}表示几何雅可比𝐉_{X,L_j}的线性和角速度分量，它将关节速度映射到{LCS}j相对于坐标系X的旋量，在X中表示。当X = W时，𝐉{W,L_j}简化为连杆L_j相对于固定基坐标系的标准几何雅可比。当X = O或X = L_k时，参考系本身是运动的。因此，相关量是连杆L_j相对于该动态坐标系的相对运动。相应的雅可比因此使用第II-B节中介绍的相对雅可比公式计算。
III 基于流形引导梯度投影的有效优化
鉴于上述运动学连杆和碰撞模型的可微性，本节详细介绍了所提出的MAAM轨迹优化求解器。
我们首先将运动平滑性项（式(1)）和所有不等式约束（式(3)-式(7)）公式化为可微目标。沉积路径等式约束（式(2)）通过迭代投影来强制，使每个路径点以高数值精度保持在预定的低维路径流形上，随后进行具有梯度投影的流形约束迭代求解器。这种设计允许优化器在保持路径可行性和惩罚约束违规的同时改善轨迹平滑性。
III-A 损失构建
对于离散化的关节轨迹𝒬，不等式约束被纳入以下惩罚目标：
min_𝒬 ℒ(𝒬) = ℒ_obj + ℒ_ori + ℒ_coll + ℒ_joint + ℒ_dyn (21)
ℒ_obj = ∑{i=1}^N Φ_i(𝐯_i, 𝐚_i, 𝐣_i), (22)
ℒ_ori = w_ori ∑{i=1}^N [ζ(g_ori(𝐪_i), δ_ori) + ζ(g_grav(𝐪_i), δ_grav)],
ℒ_coll = w_coll ∑{i=1}^N ∑_j ∑{𝐩_s} ζ(g_coll^{ℐ_j, 𝐩_s}(𝐪_i), δ_coll),
ℒ_joint = w_joint ∑{i=1}^N ∑{j=1}^n ζ(|q_{i,j} - q̄j| - Δq_j, δ_joint),
ℒ_dyn = w_dyn ∑{i=1}^N ∑{j=1}^n ∑{𝐱 ∈ {𝐯, 𝐚, 𝐣}} ζ(|x_j| - x_{max,j}, δ_𝐱).
其中ζ(·)表示具有安全裕度的softplus惩罚：
ζ(y, δ) = (1/β) log(1 + e^{β(y+δ)}), (23)
在ℒ_joint中q̄j = (q{max,j} + q_{min,j})/2, Δq_j = (q_{max,j} - q_{min,j})/2。路径跟踪损失被省略，因为位置约束在第III-B节中通过投影显式处理。
ℒ关于𝒬的梯度可以逐点堆叠为∇𝒬 ℒ = [∇{𝐪_1} ℒ, ..., ∇{𝐪_N} ℒ]。对于一般惩罚项ζ(g(𝐪), δ)，其梯度具有闭式表达式：
∇_𝐪 ζ(g(𝐪), δ) = σ(β(g(𝐪) + δ)) ∇_𝐪 g(𝐪), (24)
其中σ(y) = 1/(1 + exp(-y))是sigmoid函数。
因此，所有惩罚项通过链式法则具有闭式梯度。姿态和碰撞损失分别按第II-B节和第II-C节给出的方式微分，而目标和动态损失通过𝐯_i、𝐚_i、𝐣_i的有限差分算子微分。

III-B 约束梯度投影
与不等式约束不同，沉积路径约束被强制为硬等式约束。如图5中低自由度示例所示，在每个路径点𝐩_i处，相应的自运动流形可以构造为：
ℳ_i = {𝐪 ∈ ℝ^n | 𝐅𝐊_𝐩(𝐪) = 𝐩_i}. (25)
仅用软损失惩罚该等式约束可能允许小的违规累积，导致轨迹偏离预定刀路（参见[18]和第IV-C节中的详细消融研究）。因此，我们通过投影而非仅将其视为惩罚项来强制沉积路径约束。对于每个轨迹𝒬，每个构型被投影到其相应的流形上：
𝒬̄ = {Π_{ℳ_i}(𝐪_i)}{i=1}^N = {q̄_i}{i=1}^N, q̄i ∈ ℳ_i,
然后损失及其梯度（见图5的放大图）在投影轨迹𝒬̄上评估。该策略保持每个路径点以增材制造工艺所需的高位置精度被跟踪。
为了进一步减少基于流形投影引入的数值误差，操作Π{ℳ_i}通过基于雅可比的迭代校正实现，将每个构型驱动到𝐩_i上。如算法1所示，从𝐪_i^0 = 𝐪_i开始，每个路径点通过以下方式更新：
𝐪_i^{k+1} = 𝐪_i^k - 𝐉_{𝐯,i,k}^† (𝐅𝐊_𝐩(𝐪_i^k) - 𝐩_i), (26)
其中𝐉_{𝐯,i,k} = ∂𝐅𝐊_𝐩(𝐪_i^k)/∂𝐪_i^k是在当前迭代𝐪_i^k处评估的位置雅可比，𝐉_{𝐯,i,k}^†表示其阻尼伪逆：
𝐉_{𝐯,i,k}^† = 𝐉_{𝐯,i,k}^⊤ (𝐉_{𝐯,i,k} 𝐉_{𝐯,i,k}^⊤ + λ𝐈)^{-1}。在我们的实现中，每次优化迭代使用固定数量K_p个投影步骤。
为了通过投影反向传播损失梯度，我们对迭代(26)关于初始构型进行微分。将位置残差记为𝐞_𝐩(𝐪) = 𝐅𝐊_𝐩(𝐪) - 𝐩_i，则

= ∏{k=K_p-1}^{0} (𝐈 - 𝐉_{𝐯,i,k}^† ∂𝐞_𝐩/∂𝐪_i^k - ∂𝐉_{𝐯,i,k}^†/∂𝐪_i^k · 𝐞_𝐩)^⊤ ∇{q̄_i} ℒ
≈ ∏{k=K_p-1}^{0} (𝐈 - 𝐉_{𝐯,i,k}^† 𝐉_{𝐯,i,k}){𝐍{𝐯,i,k}}^⊤ ∇{q̄_i} ℒ.
当𝐞_𝐩 → 𝟎时近似成立。因此，对于稳定的优化，我们首先应用无约束IK投影以满足位置约束并将𝐞_𝐩驱动到接近零，然后在投影空间中优化剩余目标和约束。𝐍{𝐯,i,k}实际上是切空间投影器。完整轨迹梯度∇𝒬 ℒ(𝒬̄)最终通过堆叠{∇{𝐪_i} ℒ(𝒬̄)}_{i=1}^N组装。

这些定量结果支持了我们的主张，即将沉积精度视为软惩罚对于冗余机器人MAAM轨迹优化是不够的。基于惩罚的公式无法严格强制沉积精度，可能将其与其他目标（如运动平滑性和碰撞避免）进行权衡。相比之下，所提出的梯度投影方法保持了沉积位置，并利用剩余冗余来改善可行性和运动质量。

IV-D 讨论与未来工作
通过所展示的结果，所提出的方法展示了轨迹优化的强收敛性和可扩展性。然而，其性能仍然对初始化敏感。对于挑战性任务的差初始输入——例如具有严重关节限位违规或深度碰撞的情况——可能需要更多迭代或在固定预算内仍然不可行。我们计划通过结合基于采样的搜索与局部优化的混合策略来解决这一问题。此外，奇异性避免未被显式约束，而仅通过速度和加速度限制间接抑制。我们将在未来工作中纳入基于最小奇异值、条件数或可操作性的可微奇异性感知项[7]。
这里提出的基于SDF的碰撞模型在离散路径点和采样几何点处评估。虽然有效且可微，但其采样密度直接影响内存成本和运行时间。在我们的实现中，碰撞模型的几何形状（即喷嘴和机器人连杆）以约2 mm的间距采样——远低于所采用的安全裕度——这可靠地检测了所有测试模型中的碰撞。对于具有冗余系统的大规模MAAM，将几何表示为神经SDF[19]是更好的可扩展性和检测精度的有前途方向。
V 结论
本文提出了一种用于冗余机器人多轴增材制造中碰撞感知轨迹优化的约束梯度投影框架。所提出的方法通过将梯度更新投影到自运动流形的切空间上，将预定的沉积位置强制为逐路径点硬等式约束，并进一步开发了一种制造序列感知的可微碰撞模型，考虑了累积打印几何形状。在8自由度机器人MAAM平台上的实验验证了其在无支撑空间打印和共形表面打印上的有效性和可扩展性。与基于SQP的基线相比，所提出的方法实现了高达10.2倍的更快收敛，同时保持了显著更小的位置漂移。
