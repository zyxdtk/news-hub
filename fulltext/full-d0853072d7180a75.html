ParamMem：参数化反思记忆增强语言智能体

📅 2026-02-26 📄 arxiv 🔗 原文链接

原标题：ParamMem: Augmenting Language Agents with Parametric Reflective Memory

中文摘要： 本文提出 ParamMem，一种参数化记忆模块，通过将跨样本反思模式编码至模型参数，实现多样化反思生成，从而增强语言智能体推理能力。基于 ParamMem 的 ParamAgent 框架在编程、数学与多跳问答任务上显著优于现有方法，具备样本高效、弱到强迁移及无需外部强模型的自我提升能力。

ParamMem: Augmenting Language Agents with Parametric Reflective Memory Tianjun Yao Yongqiang Chen Yujia Zheng Pan Li Zhiqiang Shen Kun Zhang

摘要 自反思使语言智能体能够迭代优化解决方案，但常产生重复输出，限制推理性能。近期研究尝试通过多种方法缓解该局限，其中提升反思多样性已展现出良好前景。我们的实证分析揭示了反思多样性与任务成功率之间存在强正相关关系，进一步凸显了生成多样化反思信号的必要性。我们提出 ParamMem，一种参数化记忆模块，通过温度控制采样将跨样本反思模式编码至模型参数中，从而实现多样化反思生成。基于该模块，我们提出 ParamAgent，一种将参数化记忆与情景记忆、跨样本记忆融合的反思型智能体框架。在代码生成、数学推理与多跳问答上的大量实验表明，本方法持续优于当前最先进基线。进一步分析表明，ParamMem 具有样本高效性，可实现弱模型到强模型的迁移，并支持无需依赖更强外部模型的自我提升，凸显其作为增强语言智能体的有效组件潜力。代码与数据见：https://github.com/tianyao-aka/ParamAgent。

1 引言 大语言模型（LLMs）（brown2020language; chowdhery2023palm; touvron2023llama）在复杂推理任务中已取得显著进展。推动近期进展的关键洞见是“测试时扩展”，即在推理阶段分配额外计算以提升推理能力（wei2022chain; wang2022self; madaan2023self; yao2023tree; shinn2023reflexion; snell2024scaling）。其中，基于反思的框架尤为有效：智能体对任务反馈进行语言化反思，并将自反思积累于情景记忆中以指导后续尝试（shinn2023reflexion; madaan2023self; yao2023tree）。此类反思机制已成功应用于编程（shinn2023reflexion）、数学推理（lightman2023let）、决策（yao2023react）及多智能体系统（wu2023autogen; hong2024metagpt）。

然而，近期研究指出自反思存在局限：其常产生重复且不准确的输出（huang2023large; yao2023retroformer; lingam2025enhancing; ozer2025mar），阻碍反思有效性。其中，lingam2025enhancing 尝试通过提示层面修改（DoT）及引入跨样本轨迹（DoT-bank）提升反思多样性，取得初步成功。本文首先探索反思多样性与最终性能的关系：我们在五个数据集上使用 LLaMA-3.1-8B，在 Reflexion、DoT 和 DoT-bank 下计算每样本多轮反思日志的成对余弦距离并取平均。如图1所示，五数据集平均 Pearson 相关系数为 0.76，表明反思多样性与任务性能存在强正相关。尽管基于提示的方法有时提升有限，但引入相似样本的推理轨迹常可增强多样性与最终性能。

尽管有效，DoT-bank 等基于检索的方法依赖嵌入相似性检索跨样本轨迹，其捕捉组合模式的能力有限（nguyen2023generative; weller2025theoretical）；且学习到的嵌入易坍缩至低秩子空间，降低检索多样性（guo2023embedding）。这自然引出问题：如何进一步拓展反思多样性以实现更强推理性能？

为应对该挑战，我们提出 ParamMem，一种通过根本不同机制提供多样性的新型反思记忆。不同于依赖提示变化或显式利用相似样本的检索方法，ParamMem 通过在辅助反思数据集 $\mathcal{D}=\{(x_{i},r_{i}^{g})\}_{i=1}^{n}$ 上微调轻量级参数模块实现：训练中，模块将跨样本模式编码至参数；推理时，通过泛化所学模式而非检索已有示例生成反思。

贡献：我们提出一种增强反思多样性以提升语言智能体推理的新范式。核心是 ParamMem——一种将跨样本反思模式内化为参数的记忆模块。ParamMem 专为多样性设计，轻量且可无缝集成至现有反思框架。基于 ParamMem，我们提出 ParamAgent 及其增强版 ParamAgent-plus，将参数化反思记忆与情景记忆、跨样本记忆统一于连贯框架。大量实证表明本方法具有以下优势： ① 显著性能提升：在编程、数学推理与多跳问答中持续优于最先进基线； ② 样本高效：ParamMem 仅需约 500 训练样本即可实现强性能，适用于资源受限场景； ③ 自我提升：无需依赖更强外部模型，仅用基础 LLM 自身生成数据即可增强反思多样性，提升 ParamAgent 与 ParamAgent-plus 性能； ④ 弱到强迁移：即使 ParamMem 由较弱 LLM 训练，其生成的反思信号仍可增强基于更强 LLM 的 ParamAgent，表明弱模型亦可有效提升强模型的反思多样性。

2 预备知识 图2：不同框架的记忆机制对比。 Pale Mint：仅情景记忆（如 Reflexion、DoT）； Lavender Gray：情景记忆 + 跨样本记忆（如 DoT-bank）； Soft Sand：情景、跨样本与参数化记忆完全融合（如 ParamAgent-plus）。仅使用情景与参数化记忆时，框架退化为 ParamAgent。

我们考虑预训练语言模型 $p_{\theta}$，给定输入 $x$ 生成输出 $y$。用 $r_{1},\ldots,r_{k}$ 表示截至第 $k$ 轮累积的自反思，用 $r_{k}^{g}$ 表示从参数化记忆模块 $\mathcal{M}_{g}$ 采样的模型生成输出（如编程与数学任务中的反思）。

Reflexion 框架（shinn2023reflexion）通过四个组件实现迭代推理：(1) 生成候选解的 actor $p_{\theta}$；(2) 提供任务特定反馈（如测试结果、正确性信号）的 evaluator；(3) 将反馈转化为诊断性自然语言反思的 self-reflection module $p_{\theta}$；(4) 存储先前迭代反思的情景记忆 $\mathcal{M}$。第 $k$ 轮中，actor 基于情景记忆中累积反思生成候选解： $$y_{k}\sim p_{\theta}(\cdot\mid x,r_{1:k-1}).$$

Cross-Sample Memory：跨样本记忆利用过往经验或外部日志以增强智能体推理能力（borgeaud2022improving; shi2023replug; wang2023augmenting; zhong2024memorybank; wang2024agent）。鉴于自反思多样性有限，跨样本记忆存储已解问题的推理轨迹，丰富反思输入多样性，已被证明可提升智能体推理。给定新任务，从记忆库检索相关轨迹并融入提示： $$y\sim p_{\theta}(\cdot\mid x,r_{1:k},\textsc{Retrieve}(\mathcal{B},x)),$$ 其中 $\mathcal{B}$ 为轨迹库。本文提出 ParamMem——一种与情景记忆、跨样本记忆互补的参数化记忆模块 $p_{\phi}(\cdot)$，进一步促进反思输入多样性。

基于 ParamMem，我们提出 ParamAgent 与 ParamAgent-plus。在 ParamAgent 中，actor 基于情景记忆与参数化记忆生成解： $$y_{k}\sim p_{\theta}(\cdot\mid x,r_{1:k-1},r^{g}_{k}),$$ 其中 $r^{g}_{k}\sim p_{\phi}(\cdot\mid x)$ 表示第 $k$ 轮从 ParamMem 采样的反思。ParamAgent-plus 进一步融合跨样本记忆，条件于全部三类记忆源： $$y_{k}\sim p_{\theta}(\cdot\mid x,r_{1:k-1},\textsc{Retrieve}(\mathcal{B},x),r^{g}_{k}).$$ 图2展示了这些框架的架构对比。

3 基于 ParamMem 增强语言智能体 本节首先介绍 ParamMem 构建方法，再阐述其如何融入所提 ParamAgent 框架。

3.1 构建 ParamMem ParamMem 的核心思想是通过训练动态隐式捕捉跨样本规律。微调中，模块学习泛化反思模式至未见样本，而非依赖提示模板或检索相似样本。提示方法受限于固定指令模板，检索方法受限于与现有样本的嵌入相似性，而 ParamMem 可通过对所学模式插值与外推生成新颖反思，提供额外多样性来源。

构建过程始于构建辅助微调数据集：我们整理数据集 $\mathcal{D}=\{(x_{i},r_{i}^{g})\}_{i=1}^{n}$，其中 $x_{i}$ 为输入样本（如编程任务），$r_{i}^{g}=f_{\phi}(x_{i};\mathcal{P})$ 通过向 LLM $f_{\phi}$ 提供任务特定提示 $\mathcal{P}$ 生成 $x_{i}$ 的辅助监督信号。随后使用 LoRA（hu2022lora）在 $\mathcal{D}$ 上微调预训练 LLM，获得参数化模块 $\mathcal{M}_{g}$。

对于编程与数学任务，$r_{i}^{g}$ 形式为枚举潜在错误与 buggy 实现的反思反馈；对于多跳 QA，直接提供全部支持段落消耗过多 token。受认知分块（miller1956magical; baddeley2020working）与最少到最多提示（zhou2022least）启发，我们改为提示 LLM 将查询分解为紧凑语义单元与潜在推理子任务。图3展示了编程与多跳 QA 的示例。

3.2 将 ParamMem 融入 Reflexion 框架 获得参数化模块 $\mathcal{M}_{g}$ 后，将其融入 Reflexion 框架：第 $k$ 轮向 actor 提供 $\{r_{1},\ldots,r_{k-1}\}$ 时，额外从 $\mathcal{M}_{g}$ 采样模型输出 $r_{k}^{g}\sim p_{\psi}(\cdot\mid x)$ 并与自反思拼接： $$y_{k}\sim p_{\theta}(\cdot\mid x,r_{1:k-1},r_{k}^{g}).$$ 其中 $r_{k}^{g}$ 在编程与数学中表示全局级反思，在多跳 QA 中表示分解的语义单元与子任务。该框架称为 ParamAgent。

我们进一步提出 ParamAgent-plus，其额外从已解任务记忆库 $\mathcal{B}$ 检索推理轨迹 $\{\tau_{1},\ldots,\tau_{k}\}$。为确保公平比较，检索机制遵循 DoT-bank（lingam2025enhancing）。actor 随后条件于参数化与跨样本信号： $$y_{k}\sim p_{\theta}(\cdot\mid x,r_{1:k-1},r_{k}^{g},\tau_{1:j}).$$

算法1给出了所提方法的伪代码。与先前方法（yao2023retroformer; lingam2025enhancing）类似，ParamMem 在推理时不直接与环境交互；而是通过使 actor 条件于模型反馈 $r_{k}^{g}$，由参数化知识塑造输出分布，进而影响新自反思生成。该反馈环使 ParamMem 间接参与动态交互过程。

4 实验 本节详述实验设置并展示编程、数学推理与多跳 QA 上的结果。随后对所提方法进行深入实证分析：首先验证 ParamMem 在静态与动态环境下促进反思多样性的有效性；再进行消融研究考察若干关键属性：(1) ParamAgent 是否可无需更强外部模型实现自我提升；(2) 较小参数模块是否可增强基于更强 LLM 的智能体（弱到强迁移）；(3) ParamMem 的样本效率。更多实验结果见附录 B（含 70B 规模 LLM 实验与成本分析）。

4.1 实验设置 数据集：我们在三个领域评估框架。编程任务采用 HumanEval（chen2021evaluating）、MBPP（austin2021program）及更具挑战性的 LiveCodeBench（jain2025livecodebench）。数学推理采用 MATH 数据集（hendrycks2021measuring），涵盖七门学科的竞赛级问题。多跳 QA 采用 HotpotQA（yang2018hotpotqa）与 2WikiMultiHopQA（ho2020constructing），需跨多段落推理。各数据集细节及划分见附录 B。

评估：编程任务报告 Pass@1（生成时仅用可见或合成测试用例，最终评估在隐藏测试用例上进行）；数学推理与多跳 QA 报告子采样测试集上的 0-1 准确率。

基线：比较 (1) Base：无反思的基础 LLM 智能体；(2) Reflexion（shinn2023reflexion）：使用情景自反思；(3) Retroformer（yao2023retroformer）：采用参数化反思模块，但通过策略梯度优化提升反思准确性而非多样性；(4) DoT（lingam2025enhancing）：通过提示层面多样性增强 Reflexion；(5) DoT-bank（lingam2025enhancing）：进一步融合记忆库丰富反思反馈。

为全面评估，我们采用三种推理能力各异的骨干 LLM：(1) Llama-3.1-8B（dubey2024llama）：强开源推理模型；(2) Mistral-7B-v0.2（jiang2023mistral7b）：高效中型模型；(3) Qwen2-1.5B-instruct（bai2023qwen）。该选择使我们可考察方法在不同模型规模与推理强度下的表现。附录 B.3 提供了更强基础 LLM 的结果，表明即使参数模块 $\mathcal{M}_{g}$ 为较小模型，仍可为 70B 规模 LLM 构建的智能体提供显著增益。

实现细节：所有实验中，基线与本文方法迭代次数固定为 5。ParamAgent 及其变体首轮采样温度 $T=0.2$，后续迭代 $T=1.0$ 以促进多样性。除非另有说明，参数模型使用 Llama3.1-8B-Instruct 并通过 LoRA 微调：LoRA 秩 $r=128$，缩放因子 $\alpha=32$，学习率 $2e{-}5$，训练 3 轮。

4.2 实验结果 观察①：ParamMem 在所有领域持续增强 Reflexion 框架。表1显示 ParamAgent 与 ParamAgent-plus 在三领域均取得显著性能。ParamAgent 仅通过引入 ParamMem 区别于 Reflexion 与 DoT；ParamAgent-plus 则通过为 DoT-bank 增强的情景与跨样本记忆添加参数模块扩展而来。

编程基准上，ParamAgent 即使无跨样本记忆组件亦显著优于所有基线；多跳 QA 上亦大幅超越多数 prior 方法，凸显 ParamMem 的独立有效性。数学推理中，ParamAgent 改善 Reflexion 与 DoT，但跨样本轨迹作用更关键——这符合直觉：数学问题求解受益于类比问题与解法模式的暴露，类似人类学习。尽管如此，ParamAgent-plus 仍因引入 ParamMem 而超越 DoT-bank，证明模型驱动反思记忆的互补价值。

值得注意的是，Retroformer 在 MATH 上表现优异（反思准确性可能比多样性更重要），但在编程与多跳 QA 上表现欠佳——尽管同样使用参数编码。我们归因于分布偏移：训练数据与测试数据对齐不佳，导致准确性导向优化过拟合。而 ParamMem 的目标是多样性驱动，表明多样性导向的参数记忆在分布间泛化更好。

观察②：ParamMem 在情景与跨样本记忆之外引入额外反思多样性层。我们假设参数模块 $\mathcal{M}_{g}$ 通过训练动态引入额外多样性来源。为验证，我们在编程任务上进行分析：使用 GPT-4o-mini 或 Llama-3.1-8B 自身生成的合成数据微调 Llama-3.1-8B 作为参数模块。对 HumanEval 每任务以 $T=1.0$ 采样 10 条反思，嵌入后计算成对余弦距离均值 $D_{mean}$。如图4(a)所示，GPT-4o-mini 数据训练的模块多样性最高；即使使用同模型生成与微调，多样性仍超未微调 Llama-3.1-8B。该发现亦解释了 ParamAgent 与 ParamAgent-plus 在自我提升设置中的有效性（表2）。

上述分析刻画了静态环境下的多样性。我们进一步考察 ParamMem 融入 Reflexion 框架后与环境交互时多样性是否持续：在 HumanEval 上维护每样本完整反思历史，使用 OpenAI text-embedding-3-small 模型嵌入所有反思，对所有反思执行 K-means 聚类并用肘部法则确定最优聚类数 $K^{*}$。图4(b)显示 ParamAgent 达 $K^{*}=39$，显著高于 Reflexion、DoT 与 DoT-bank，表明 ParamMem 引入更丰富多样的反思信号。且 ParamAgent 的轮廓系数在所有 $K$ 下均更高（图4(c)），证实其生成反思具有更优聚类质量与语义一致性。

综上，这些分析表明 ParamMem 引入了互补的反思多样性来源，丰富了智能体在迭代优化中可利用的反馈信号。

观察③：多样反思扩大错误诊断的假设空间。为理解多样性驱动增益的原因，我们在 MBPP 上开展案例研究（附录 B.5 图8），聚焦 ParamAgent 成功而 Reflexion 与 DoT 失败的实例。观察发现，自反思常无法识别错误核心根源，甚至误导智能体远离正确实现。ParamAgent 虽非完全免疫此类失败，但增加的反思反馈多样性为智能体提供了更广的诊断假设集，从而提高遇到正确线索以成功优化的可能性。这也解释了为何 ParamAgent 与 ParamAgent-plus 在某些数据集上偶尔 token 消耗更高。

观察④：ParamMem 支持无需依赖更强外部模型的智能体自我提升。近期自提升智能体工作旨在不依赖外部更强模型下增强推理能力（wei2022chain; zelikman2022star; shinn2023reflexion; zeng2024b; snell2025scaling; muennighoff2025s1）。ParamAgent 具有类似特性：即使 ParamMem 由基础模型自身生成的合成数据微调，仍可获得持续增益。具体地，我们使用 Llama-3.1-8B 生成合成数据并微调同基础模型为参数记忆模块。表2显示 ParamAgent 与 ParamAgent-plus 显著优于 DoT 与 DoT-bank，证明 ParamMem 可通过多样化反思增强推理，无需更强外部模型。

观察⑤：迭代自教学进一步增强 ParamAgent。我们在 HumanEval 上研究迭代自教学：从 Llama-3.1-8B-Instruct 开始，于 1000 个随机样本上微调 ParamMem；训练后用所得模型为相同输入生成新目标，得更新数据集 $\mathcal{D}^{\prime}=\{(x_{i},\tilde{r}_{i}^{g})\}_{i=1}^{1000}$（$\tilde{r}_{i}^{g}\sim p_{\phi}(\cdot\mid x_{i})$ 为新采样反思），再于 $\mathcal{D}^{\prime}$ 上微调并重复 3 轮。图5显示 ParamAgent 在迭代中稳步提升，表明 ParamMem 逐步生成更多样反思；而 ParamAgent-plus 仅微弱增益，我们推测跨样本轨迹已使模型接近多样性上限。

这类似于 STaR（zelikman2022star）及近期变体（hosseini2024v; zeng2024b），但关键区别在于：那些方法在每轮迭代中筛选正确样本，隐式执行奖励驱动的自举；而我们的方法无需筛选，因 ParamMem 目标是多样性而非正确性。

观察⑥：ParamAgent 实现弱到强推理增强。前述观察表明 ParamMem 支持自我提升。此处考察较弱模型作为 ParamMem 是否可增强更强智能体。我们在 LiveCodeBench 与 HotpotQA 上评估，以 Qwen3-Next-80B-A3B-Instruct（qwen3technicalreport）为基础 LLM，ParamMem 由 Llama-3.1-8B 或 Qwen3-Next-30B-A3B-Instruct（qwen3technicalreport）实例化。表3显示两种配置均持续优于所有基线。编程任务中，基于 Qwen3-30B 的 ParamMem 更有效，较最强基线提升 9.7%；有趣的是，多跳 QA 中，更小的 Llama-3.1-8B 实例化 ParamMem 反超 Qwen3-30B 对应版本，较最佳基线方法相对提升 2.0%。这些结果证实 ParamMem 可实现弱到强迁移：较小模型亦可提供有益强智能体的多样化反思信号。

5 相关工作 LLM 推理与多样性：LLM 通过 CoT 提示（wei2022chain）、自一致性（wang2022self）与 ReAct（yao2023react）执行多步推理。自一致性通过采样多推理路径并多数投票聚合，证明推理轨迹多样性可提升输出鲁棒性。迭代自反馈方法（madaan2023self; shinn2023reflexion）与测试时计算扩展（snell2025scaling; openai2024openaio1card; Guo_2025）通过推理阶段分配额外计算进一步提升推理。

为增强多样性，结构化探索方法如思维树（yao2023tree）与思维图（besta2024graph）支持对推理状态的刻意搜索，强调探索多样解路径对解决复杂问题的关键性。与本文最相关的是 DoT（lingam2025enhancing），其通过提示干预与跨样本记忆缓解重复自反思。我们扩展此方向，提出 ParamMem——通过参数编码提供超越情景与跨样本记忆的正交反思多样性来源。

改进 LLM 智能体反思：近期工作探索多样性驱动方法改进反思。DoT（lingam2025enhancing）通过提示干预与跨样本记忆检索缓解重复自反思。除多样性驱动方法外，其他方法通过不同机制改进反思：Retroformer（yao2023retroformer）使用策略梯度优化学习回顾模型，基于环境反馈优化提示以提升反思准确性；Self-RAG（asai2024self）将特殊反思 token 直接训练入生成模型，实现推理时生成与检索决策的自批判；ExpeL（zhao2024expel）从成功轨迹中提取可泛化洞见并存储以跨任务迁移。这些方法主要通过不同机制提升反思质量或准确性。ParamMem 虽亦采用 Retroformer 与 Self-RAG 的参数化反思编码，但在目的与设计上不同：其目标非优化反思准确性或自批判能力，而是通过统一情景记忆、跨样本记忆与参数化记忆于单一框架增强反思多样性。

自提升语言智能体：语言模型的自提升使智能体能通过迭代学习自生成数据增强推理能力。STaR 引入自举推理，模型生成推理并微调于导向正确答案的推理（zelikman2022star）。该范式由 ReST（gulcehre2023reinforced）与 ReST-EM（singh2023beyond）扩展，证明当存在可验证反馈时自生成训练数据可超越人工标注数据。更近期工作完全消除外部奖励模型需求：Self-Rewarding Language Models（yuan2024self）使用 LLM-as-a-Judge（zheng2023judging）生成偏好数据；Meta-Rewarding（wu2025meta）添加元判断能力；SPIN（chen2024self）证明自博弈微调可通过模型与早期版本自我竞争，无需额外人工标注数据将弱模型迭代转为强模型。

与这些方法不同，ParamMem 通过逐步多样化反思反馈实现自提升，从而强化基于反思的框架。值得注意的是，ParamMem 不需要任何外部奖励信号或人工标注；其利用基础模型自身生成的反思作为训练数据，使自提升过程既可扩展又实用。

6 结论与局限 我们提出 ParamMem——一种将反思内化为模型参数的参数化记忆模块，在情景与跨样本记忆之外引入额外多样性层。基于 ParamMem，我们引入 ParamAgent 与 ParamAgent-plus，为基于反思的推理框架增强 ParamMem。三领域实验显示本方法显著优于最先进基线，凸显参数化记忆作为轻量级即插即用模块构建语言智能体的潜力。

尽管优势显著，本方法存在局限：一显著局限是某些场景下 token 消耗增加，这是额外反思多样性的固有代价。未来工作将探索更 token 高效的集成策略以缓解此权衡。

Impact Statement：基于反思的推理被广泛采用以提升语言智能体系统在 diverse 领域的任务性能。本工作研究自反思的根本局限：生成反思的多样性缺乏，并提出新方法解决。本方法对推进语言智能体的理解与能力有积极影响。我们未预见本工作可能带来任何负面社会影响。

附录 A 更多相关工作 语言智能体的记忆系统：记忆架构已广泛研究以增强智能体能力。Generative Agents（park2023generative）引入基于近期性、重要性与相关性检索的记忆流；MemGPT（packer2023memgpt）应用类操作系统虚拟内存管理；MemoryBank（zhong2024memorybank）引入 Ebbinghaus 遗忘曲线实现类人记忆衰减。跨样本学习方面，ExpeL（zhao2024expel）维护经验池与抽象洞见库。值得注意的是，几乎所有现有记忆系统均为检索式，依赖嵌入相似性访问存储经验。尽管 DoT-bank（lingam2025enhancing）等检索方法通过跨样本轨迹展现多样化反思潜力，其仍受限于捕捉组合模式能力有限（nguyen2023generative）及嵌入坍缩至低秩子空间（guo2023embedding）。

从经验学习的参数方法：日益增长的工作探索将经验与反思能力直接编码入模型参数。Retroformer（yao2023retroformer）通过策略梯度强化学习训练专用回顾模型生成改进 verbal 反馈，证明学习反思可优于提示方法；但需昂贵在线 RL 与环境交互。Self-RAG（asai2024self）训练 LLM 生成特殊反思 token，实现推理时自适应检索决策与生成质量自批判，代表提示与参数学习的混合，但主要聚焦事实验证而非推理多样性。LEMA（an2023learning）在更强模型生成的错误修正对上微调 LLM，通过参数编码错误模式在数学推理上取得强结果。SCoRe（kumar2024training）通过多轮强化学习训练模型内在自校正，无需外部反馈即显著提升但计算成本高。MemoryLLM（wang2024memoryllm）在 LLM 潜在空间内集成自更新记忆池，实现无需全微调的参数存储。这些工作共同表明参数学习对捕捉复杂模式可能比检索更有效，但常伴随显著计算成本或窄任务聚焦。本文提出 ParamMem——一种轻量参数记忆模块，专为反思多样性设计，通过高效监督微调将跨样本反思模式编码入参数以支持多样化反思生成，使基于反思的框架统一多种记忆形式。

附录 B 更多实验细节与结果 B.1 数据集统计 编程：在 HumanEval（164 个手写 Python 编程问题，每个附隐藏单元测试与少量可见测试用例）与 MBPP（397 个筛选后的众包问题）上评估。 数学：采用 MATH 数据集（278 个跨七学科的竞赛风格问题），随机采样平衡子集评估。 多跳 QA：在 HotpotQA（300 个分层采样问题：100 每难度级）与 2WikiMultiHopQA（300 个分层采样问题：75 每类型）上评估。

B.2 参数模块微调 编程：从 APP 数据集采样 4000 个入门级编码问题，并用 GPT-4o-mini 合成 4200 个覆盖多样编程领域的任务；对每问题，GPT-4o-mini 进一步生成潜在错误与 buggy 实现；使用 LoRA 在此数据集上微调 LLaMA-3.1-8B 获得编程专用参数模块 $\mathcal{M}_{r}$。 数学：利用 MATH 训练集，从每学科领域随机采样 800 问题，采用相同流程：GPT-4o-mini 为每样本生成反思反馈与 buggy 推导；用此数据集 LoRA 微调 LLaMA-3.1-8B 实例化数学推理的 $\mathcal{M}_{r}$。 多跳 QA：从 HotpotQA 与 2WikiMultiHopQA 训练集各随机采样 10000 实例；GPT-4o-mini 被提示为每示例输出结构化语义单元（如实体、关系、约束、答案类型与子问题）；应用 LoRA 微调 LLaMA-3.1-8B 构建多跳 QA 的参数模块 $\mathcal{M}_{p}$。
