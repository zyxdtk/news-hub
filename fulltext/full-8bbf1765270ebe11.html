摘要

3D物体组合对数字内容创作和机器人仿真至关重要，同时也是检验基础模型物理智能的关键测试平台。以往方法要么利用大语言模型直接预测物体坐标，要么利用生成式扩散先验合成组合图像以进行视觉对齐，二者均依赖数字空间中的静态先验。然而，这些方法在处理精确悬挂、重力驱动沉降和隐藏包含等复杂组合时始终力不从心，因为这些任务需要包含全局规划、细粒度对齐和物理仿真的交互式构建过程。为应对这些挑战，我们提出 PhySGA——一个通过智能体探索与物理仿真实现3D组合的物理空间落地智能体框架，支持刚体、铰接体和可变形物体的通用交互式组装。直接将原始 LLM 或 VLM 应用于该任务并不足够，因为现有模型本质上缺乏落地的物理理解与交互式构建经验。为克服这一局限，我们设计了协作式前馈-反馈架构：装配智能体专注于几何与运动学推理，负责全局步骤规划与粗调；评估智能体则对接触动力学进行推理，负责仿真器状态诊断与细粒度闭环修正。此外，动作路由器将语义规划与分析映射为仿真器中可执行的物理原语，而任务特定的自进化技能库将历史试错反馈提炼为可复用经验，提升成功率并减少探索次数。在 Isaac Sim 中的大量实验表明，PhySGA 在关系保真度、物理合理性和视觉质量上均显著超越现有方法。

1 引言

3D物体组合旨在构建独立物体资产之间物理和功能上连贯的交互 [25]。赋予 AI 智能体在动态仿真器中构建复杂交互任务的能力至关重要，因为这能产生可扩展的、物理落地的环境，直接增强具身模型的能力 [46]。此外，这种交互式构建为评估基础模型的真实物理智能确立了严格标准。与依赖静态视觉问答的传统基准 [10, 5] 不同，3D组合迫使模型将语义理解转化为可执行的物理动作，利用直接的仿真反馈明确验证其推理能力。

早期的场景合成方法使用预定义规则或从标注3D数据集中提取的启发式空间关系来放置物体 [7]。近来，基础模型推动了3D组合的两条主流路线。语言驱动路线使用 LLM 从文本指令直接预测物体坐标 [9]。SAGE [42] 和 SceneSmith [24] 等智能体框架通过工具使用迭代调整分层放置来扩展这一方法，然而其核心机制仍严重依赖语义布局先验。视觉驱动路线依赖2D生成模型创建目标组合的图像，随后利用扩散先验指导3D物体的空间定位 [31]。

然而，这些方法主要依赖数字空间中的静态先验，即语言模型或扩散先验中编码的物体位置和关系知识，在处理复杂3D物体组合（如精确悬挂、重力驱动沉降和隐藏包含）时举步维艰。这是因为精确悬挂需要精确的多视角观察和精准的空间对齐；重力驱动沉降必须在重力动力学下显式利用物理仿真；而隐藏包含涉及一系列交互式运动学动作。回顾这些方法，语言驱动分支在这些场景中表现不佳，因为它学到的是合理的静态布局，却缺乏复杂交互的经验性数据，而物理平衡的最终状态又众所周知难以用文本精确表达。同样棘手的是，视觉驱动分支优先考虑视觉合理性，而这很少等同于物理有效性，对细粒度组装而言是致命缺陷。因此，复杂交互中的一个根本挑战在于：在严格遵守物理定律的同时实现目标关系。我们认为，一种可靠的途径是将组合过程直接扎根于物理空间，以迭代方式逐步组装物体。这样可在每一步保持物理有效性，并最终确保关系得到满足。直观上，这反映了人类在现实世界中组装物体的方式：不是一次性预测，而是通过规划、调整和利用物理反馈的持续循环。

本文提出 PhySGA，受人类在现实世界中组装物体方式的启发，将3D物体组合形式化为物理空间中的交互式组装过程，如图 1 所示。为此，我们设计了面向物理交互的协作式前馈-反馈架构。装配智能体进行运动学推理以制定全局计划，执行度量落地的粗调以实现可靠的初步修正；随后，评估智能体分析仿真运动和接触反馈以诊断物理失败，执行像素落地的细粒度修正，直至目标关系达到物理平衡。为桥接高层语义推理与低层仿真执行，我们引入模块化动作路由器，将智能体预测无缝转换为精确的几何、铰接和速度命令。最后，我们维护一个自进化技能库来提炼历史交互记忆，使智能体能够检索过往经验以避免重复失败，并促进经验的持续复用。

我们的主要贡献总结如下：

  • 我们提出 PhySGA，将3D物体组合形式化为扎根于动态物理空间的交互式组装过程，确保复杂目标关系建立在严格的物理有效性之上。
  • 我们设计了一个完备的智能体框架，其核心是由装配智能体与评估智能体驱动的前馈-反馈范式（用于全局规划与精确视觉修正）、用于执行解耦物理命令的模块化动作路由器，以及用于历史经验复用的自进化技能库。
  • 在 Isaac Sim 中针对刚体、铰接和可变形任务的大量实验表明，PhySGA 显著优于最先进方法，为仿真器中的复杂任务构建提供了可扩展的解决方案，同时有效释放了基础模型的潜在物理智能。

2 相关工作

2.1 仿真场景生成

仿真场景生成为训练具身智能体提供交互环境。早期方法通过程序化规则 [7, 27, 26] 或学习静态物体布局的分布 [23, 34, 36, 29, 37] 来构建这些环境。近期的语言引导方法，如 Holodeck 和 SceneWeaver [46, 45]，通过直接将文本指令转化为物体选择和空间安排 [15] 推进了该领域。语言智能体可以将推理与动作交织，并利用环境观察指导后续决策 [47]。为进一步优化这些布局，SAGE [42] 和 SceneSmith [24] 等智能体框架引入了迭代工具使用以及视觉或物理评估器。然而，这些语言驱动的流水线主要将生成形式化为静态坐标预测，仅将物理仿真视为二元验证步骤，缺乏处理需要持续交互的复杂关系的能力。为此，PhySGA 通过将智能体嵌入仿真器，绕过一次性坐标预测，以逐步物理执行驱动组合过程。

2.2 3D物体组合

3D物体组合旨在建立不同3D物体之间的功能和空间关系。以往研究探索了不同尺度的空间安排。在场景层面，SimRecon [41] 和 PhyRecon [19] 等方法从视觉观察重建3D场景 [8, 13, 14, 39, 20, 40]。在部件层面，Jigsaw [17] 等方法通过匹配局部几何来组装断裂碎片 [30]。将焦点转向完整的物体组合，Interact3D [31] 利用扩散先验指导独立资产的几何配准。然而，这些方法严重依赖视觉对齐来恢复静态终端姿态，无法保证物理合理性。关键在于，纯视觉对齐在复杂交互上完全失效：重力驱动沉降需要动态物理仿真来确定最终静止状态，而隐藏包含涉及视觉遮挡的目标区域，使基于图像的匹配无效。PhySGA 通过将组合转化为闭环物理构建问题克服了这些限制，确保物体关系受到物理定律的严格验证。

2.3 评估物理智能

评估基础模型的物理智能日益受到关注 [5]。当前基准主要通过视觉问答来探测这一能力，要求模型从静态图像或视频中推断空间关系 [10, 28]、度量数量 [44] 或物理动力学 [48, 4] [33, 5]。与此同时，经验性语言智能体表明，模型可以通过积累试错反馈 [18, 2, 32, 49] 或跨回合的自进化技能 [35, 43, 50] 随时间改进。然而，被动视觉提问往往不足以捕捉现实世界物理的复杂性。物理智能最严格的测试平台是仿真器内的可执行构建，其中语义推理必须通过动态物理交互加以验证。PhySGA 采用这一范式，通过持续的仿真反馈而非静态预测来评估和增强智能体的物理理解。

图 2：PhySGA 框架概览。在协作式前馈-反馈架构的驱动下，装配智能体执行度量落地的粗调，而评估智能体通过仿真反馈执行像素落地的细粒度修正。动作路由器将这些语义决策转化为解耦的物理命令，自进化技能库将成功的交互提炼为可复用技能。

3.1 PhySGA 概览

3.1.1 交互式组合表示

给定自然语言指令 q 和一对独立实例化、仿真就绪的3D资产 𝒜 = {a₁, a₂}，目标是从初始仿真器状态 s₀* 出发构建物理上可实现的组合 𝒞*。以往方法主要将此任务形式化为对最终相对物体姿态的一次性预测，绕过了物理交互轨迹。然而，复杂组合本质上依赖于持续的接触动力学和中间状态转换。因此，我们将3D物体组合形式化为迭代式物理构建过程。从 s₀* 出发，组合通过一系列状态转换实现，利用全面的操作集合，包括几何变换（平移、旋转、缩放）、动态速度分配和物理仿真。这一广义迭代表示可写为：

sₖ = Φ(sₖ₋₁, aₖ), (1)

其中 aₖ 表示第 k 次迭代中施加的调整或仿真步骤，Φ 表示环境转换函数。这一逐步演化持续进行，直至产生最终目标组合 𝒞* = s_K。

3.1.2 前馈-反馈智能体架构

为执行这一广义迭代过程，我们设计了包含两个高层智能体的分层架构。装配智能体（π_Asm）掌管前馈构建的外循环，利用几何和运动学推理制定 N 步计划并执行粗略度量调整。对于第 n 步，它对先前已验证的状态 sₙ₋₁* 施加调整，产生新状态 sₙ。若该步骤需要物理验证，sₙ 将初始化预仿真状态 sₙ,₀。评估智能体（π_Crit）管理反馈细化的条件内循环。在第 r 轮中，仿真器 𝒮 评估该状态，评估智能体基于仿真物理证据施加细粒度修正，产生修订状态 sₙ,r+1。一旦满足物理要求，已验证状态便作为 sₙ* 返回前馈过程。所有 N 步完成后即实现最终目标组合，得到 𝒞* = s_N*。步骤 n 的状态演化显式实例化为：

sₙ = π_Asm(q, 𝒜, sₙ₋₁*), (2)

sₙ → sₙ,₀（若需要物理验证），

sₙ,r+1 = π_Crit(q, 𝒜, sₙ,r, 𝒮(sₙ,r)),

sₙ,r+1 → sₙ*（验证成功后）。

这种非对称协作在结构上将逐步的全局装配规划与仿真器内像素落地的物理修正分离开来。

3.1.3 统一资产流水线

PhySGA 使用 GPT Image 2 [22] 和 SAM 3D Objects [3] 处理生成的刚体资产，同时通过统一流水线检索来自 ArtVIP [12] 和 GarmentLab [16] 的铰接与可变形资产。为向高层智能体提供跨资产类型的一致观察，我们采用共享元数据模式对所有资产进行标准化，显式记录语义、度量几何、规范方向和物理属性。此外，我们提供带度量标注的标准化 CAD 风格正交多视角渲染，以促进准确的空间推理。

3.2 协作式双智能体架构

3.2.1 共享状态机设计

为有效探索交互式组装过程，我们将装配智能体和评估智能体均构建为持久状态机。与标准的一次性坐标预测不同，这种循环式形式赋予智能体时间感知能力和环境条件化推理能力。交互循环通过四个认知阶段的统一序列展开：观察、决策、执行和验证。形式化地，在任意交互时间步 t，活跃智能体 i ∈ {Asm, Crit} 从观察阶段开始，处理当前仿真器观察 oₜ 及其历史记忆 ℳₜ₋₁ⁱ。基于此上下文，智能体转入决策阶段，制定几何或物理调整，输出自然语言指令 dₜⁱ。在执行阶段，动作路由器将该语义指令落地为具体的仿真器命令，产生物理执行状态。最后，在验证阶段，智能体评估结果。此时，智能体确定宏观控制流：若当前要求已满足则推进到下一步，否则循环回退以启动新的尝试。无论成功与否，已执行的动作及其环境后果都会立即被吸收到当前记忆 ℳₜⁱ 中，为后续推理循环提供依据。

3.2.2 装配智能体

全局规划。 为模拟人类前馈任务分解的认知过程，我们为装配智能体配备了结构化思维链先验 [38]。从初始仿真器状态 s₀ 和任务指令给定的预期装配关系出发，它生成一份概述整个构建过程的自然语言计划。每一步提供目标物体状态的语义描述及其可观察的检查条件。给定任务指令 q、任务相关资产语义 η_𝒜、初始观察 o₀ 及其记忆 ℳ_Asm，它产生：

𝒫_Asm = Plan_Asm(q, η_𝒜, o₀, ℳ_Asm) = {(gₖ, cₖ)}ₖ₌₁ᴷ, K ≤ K_max. (3)

每对 (gₖ, cₖ) 作为指定目标状态和验证标准的高层语义指令，确立全局轨迹，而非规定刚性的低层命令序列。

度量落地的粗调。 为执行这些计划步骤，装配智能体将预期调整类型、估计度量值、目标状态及相应验证标准传输至其指定的动作路由器。在正交多视角场景渲染构成的观察空间中，智能体选择一个或多个最能暴露交互区域的主视图，随后对这些选定视图进行推理，推导出调整所需的实际度量值，从而进一步具体化目标状态及其检查标准。这种度量输出范式最大限度地保留了视觉语言模型固有的常识性空间推理能力，使其在粗略全局协调和结构对齐中非常有效。

3.2.3 评估智能体

试错归因。 与装配智能体的前馈方法不同，评估智能体基于物理反馈模拟人类的试错细化。在步骤 n 的第 r 轮物理仿真之后，评估智能体从仿真状态 sₙ,r^sim 中诊断失败 ξₙ,r 并识别修正方面 αₙ,r。利用该诊断及最新观察，它细化预仿真状态 sₙ,r 以产生调整后的状态 sₙ,r+1，随后由下一轮物理仿真评估。若仿真成功，sₙ,r+1 作为已验证状态返回；若失败，智能体则策略性地决定是从新调整状态 sₙ,r+1 继续细化，还是回滚到先前状态 sₙ,r 以寻求替代修正路径。该物理细化过程形式化为：

(ξₙ,r, αₙ,r) = Diagnose_Crit(q, sₙ,r^sim, ℳ_Crit,r), (4)

sₙ,r+1 = Refine_Crit(sₙ,r, oₙ,r, ξₙ,r, αₙ,r, ℳ_Crit,r).

像素落地的细粒度对齐。 粗略度量调整往往不足以实现精确的物理对齐。为此，我们直接利用视觉语言模型固有的像素级对齐能力。在失败仿真后的诊断阶段，评估智能体检查多视角观察以识别具体的几何误差。智能体不估计语义度量值，而是直接输出像素坐标，将受操纵物体的代表像素映射到其在多个视图下目标物体上的预期位置。动作路由器随后利用校准的相机投影对这些像素对应关系进行三角化，将精确的视觉对齐直接转换为仿真器的可执行命令。

3.3 动作路由器

动作路由器通过三个模块化功能，将高层智能体的语义目标和调整分析落地为可执行的仿真器命令。几何路由器将沿3D正交轴的平移、旋转和均匀缩放预测转换为精确变换。铰接路由器将语义指令（如打开抽屉）映射为铰接物体的相应关节运动。速度路由器将释放指令（如向前抛掷）转换为仿真前施加于可变形物体的均匀世界空间速度。这种设计可无缝适应多样物体类型，并显式解耦不同的物理变量。此外，通过将高层语义推理与低层物理细节分离，它显著减轻了装配智能体和评估智能体的认知负担，使其能够专注于任务规划和空间对齐。

3.4 自进化技能库

为避免重复过往失败、减少推理时间，并简化具有相似物理条件任务的规划，我们维护一个自进化技能库 𝒦。在执行新指令 q 之前，框架从 𝒦 中检索兼容知识，为智能体提供参考策略。执行之后，整合的交互记忆 ℳ 和最终物理结果 𝒪 被联合提炼，以构建新知识或补充现有技能。这种提炼总结了关键洞察，如装配规划瓶颈和评估智能体的根因错误分析。整个检索与演化过程简洁地形式化为：

pᵢ ← pᵢ ⊕ Retrieve(𝒦, q), (5)

𝒦 ← Update(𝒦, Distill(ℳ, 𝒪)),

其中 ⊕ 表示将检索到的技能附加到智能体 i ∈ {Asm, Crit} 的提示 pᵢ 中。

4 实验

我们进行了大量实验以评估我们方法在3D组合中的有效性。遵循 4.1 节的实验设置，我们在 4.2 节将 PhySGA 与最先进的3D组合框架进行比较，在 4.3 节与多种基础模型上的原始编码智能体进行比较。最后，4.4 节对核心智能体组件进行了全面消融。

4.1 实验设置

基准。 我们构建了一个涵盖三种类别的物体组合任务基准：刚体、铰接和可变形。刚体任务涵盖刚体物体间的物理接触关系（如包含、插槽）。铰接任务涉及运动学关节的驱动，而可变形任务需要物理仿真使软体自然沉降。该基准包含 40 个独特任务（20 个刚体、10 个铰接、10 个可变形）。每个任务实例化为三个提示变体，资产描述不同但目标关系相同，共产生 120 个评估场景。

基线。 我们将 PhySGA 与三个代表性系统进行比较：SAGE [42]、SceneSmith [24] 和 Interact3D [31]。由于 SAGE 和 SceneSmith 是分层场景生成框架，我们主要比较其物体级性能。具体而言，我们保留 SAGE 的放置智能体和评估智能体以及 SceneSmith 的操作物智能体，同时省略房间初始化和全局布局规划。每个系统使用其原生资产获取流水线，所有最终组合在 Isaac Sim 中以统一协议执行和评估。

实现细节。 所有方法在 NVIDIA Isaac Sim 4.2.0 中执行和评估。在基线比较中，GPT-5.5 作为所有 VLM 驱动推理的基础 VLM。每个方法接收相同的 120 个语言提示，并遵循其原生流水线生成组合，随后以相同的渲染和物理执行配置加载到 Isaac Sim 中。

指标。 我们使用物理和视觉两类指标评估组合质量。物理指标包括穿透率（PR）和接触率（CR），取值范围均为 0 到 1，分别衡量出现无效碰撞的场景平均占比（越低越好）和成功实现目标接触的场景平均占比（越高越好）。视觉指标方面，由 VLM 评估器对多视角输出进行 0 到 10 分的评分。我们报告衡量资产保真度的资产保真度分数（AFS）、衡量整体组合质量的组合总分（COS），并重点突出关系保真度分数（RFS）作为成功实现指令关系的主要指标。所有视觉指标均在 120 个场景上取平均。

表 1 给出了组合任务的定量评估结果。PhySGA 在物理和视觉指标上均显著优于所有基线，实现了接近完美的接触率（CR）0.958，同时保持了极低的穿透率（PR）0.033。值得注意的是，SAGE 的 PR 为 0.000，但这只是其无法建立交互所造成的假象：它将资产放置得相距甚远而没有实质接触，导致 CR 为 0.000 以及最低的关系保真度分数（RFS）。相比之下，PhySGA 的 RFS 达到 8.75，几乎是最强基线 Interact3D（4.45）的两倍，展示了其将语义关系转化为物理验证配置的卓越能力。

图 3 的定性比较进一步凸显了这些优势。基线方法经常在空间容差上出现问题，导致资产漂浮（如 SAGE 所示）或物理仿真后出现严重视觉错位（如 Interact3D 所示）。相反，PhySGA 在所有物体类别上始终产生物理连贯的组合。它独树一帜地完成了需要毫米级精度的细粒度操作，例如将盘子插入狭窄的碗架插槽或通过环孔悬挂汤勺。此外，它还能有效处理复杂的多步骤铰接交互以及仿真中逼真的可变形沉降。

Qwen3.8-Max 0.258 0.542 1.42 2.46

我们在相同实验设置下评估了 PhySGA 的六种消融配置，以评估各核心组件对整体组合质量的贡献。无全局规划用孤立的逐步规划取代完整的全局计划；无度量调整用直接预测像素级移动变化取代度量估计；无错误归因在不利用物理仿真反馈的情况下直接调整；无像素对齐迫使智能体直接预测实值空间移动而非精确像素对齐；无动作路由器要求智能体直接输出低层仿真器控制代码而不经模块化路由器执行；无自进化技能则移除历史经验检索。

如表 3 所示，完整的 PhySGA 始终取得最高的接触率（CR）和视觉分数（RFS、COS），以及最低的穿透率（PR）。移除任何单个模块都会导致整体组合质量明显下降。这证实了全局规划、从粗到细的视觉对齐、模块化动作路由和自进化技能对于物理落地的3D组合均不可或缺。

5 结论

本文提出了 PhySGA，一个面向刚体、铰接和可变形物体交互式3D物体组合的物理空间落地智能体框架。我们设计了协作式前馈-反馈架构：装配智能体利用几何和运动学推理进行全局装配规划和度量落地的粗调，评估智能体从仿真接触动力学诊断组合失败并执行像素落地的细调。动作路由器将其决策转化为可执行的仿真器命令，自进化技能库则将完整装配运行的经验提炼为可复用技能以服务后续任务。Isaac Sim 中的实验表明，相比现有方法和原始 VLM 编码智能体，PhySGA 在关系保真度和整体组合质量上均有提升，消融研究进一步支持了关键设计选择的有效性。
