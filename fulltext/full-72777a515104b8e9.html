摘要

弱监督表格数据异常检测是许多标签稀缺应用中的一项重要任务，因为表格数据广泛存在，且实践中通常只能获得少量标注异常样本和大量未标注样本。现有大多数方法试图学习捕捉目标领域内在分布模式的特征。然而，这类特征往往难以完整描述可能的异常特性，且极易对极其稀缺的标签过拟合。为应对这一挑战，我们提出了一种基于通用语义增强的表格数据弱监督异常检测方法，该方法将预训练表格基础模型中的通用知识与在目标数据集上学习的领域特定知识相融合。这两类知识天然互补：通用语义描述了跨领域表格数据的共性模式，而领域特定特征则捕捉目标数据集中正常与异常行为的内在分布。随后设计了一种原型条件调制机制来有效整合这两类特征，使它们相互增强以提升异常检测性能。在公开数据集上的大量实验表明，当训练过程中仅有八个标注异常样本可用时，所提方法优于竞争方法。代码可在以下地址获取：https://github.com/Simon-zsy/USE-AD

关键词： 弱监督异常检测；表格数据；通用语义；特征融合

1 引言

表格数据是现实应用中最普遍的数据形式之一，广泛应用于金融风险管理、医疗诊断和设备监控等领域 [7, 18]。在这些领域中，检测异常（即偏离大多数数据的记录）可以及时发现欺诈交易和入侵行为等潜在风险事件，并减少相应损失 [18]。构建有效的深度异常检测模型通常需要大量标注样本来指导训练过程。然而，异常事件在实践中很少发生，且准确标注它们需要大量领域专家知识，因此收集足够数量的标注异常样本极其昂贵 [18, 12]。因此，实际场景通常只提供少量标注异常样本和大量未标注样本。弱监督异常检测因此受到广泛关注，因为它正是从这类数据中学习检测模型，且不依赖大规模标注 [12, 13, 11]。

为了充分利用稀缺标签，现有大多数针对表格数据的弱监督异常检测方法在目标数据集上训练特征编码器和异常评分函数 [12, 21, 11, 26]。以这种方式学习的特征反映了单一领域的内在分布模式，即少数标注异常所携带的领域先验以及历史数据中正常行为的统计模式。然而，异常可能以高度多样的形式出现，从单一领域学习的特征很难完整描述这些可能的形式；此外，在标注异常极少的情况下，学习的模型容易过拟合这些有限的样本。

最近，预训练表格基础模型 [8] 表明可以从大规模、多样化的数据中学习表格数据的通用语义，由此得到的样本表示描述了跨领域共享的共性模式。这种通用知识自然地补充了在目标数据集上学习的领域特定知识，但如何有效地结合这两类知识用于弱监督异常检测在很大程度上仍未被探索。受此观察启发，本文研究如何利用表格数据上的通用语义来增强弱监督异常检测。

本文提出了一种基于通用语义增强的表格数据弱监督异常检测方法。核心思想是将预训练表格基础模型中包含的跨领域通用语义引入领域特定的检测模型，使通用知识与领域特定知识相互补充。这两个视角是互补的：通用语义特征提供了跨领域先验，有助于发现难以从单一领域数据中发现的异常，而领域判别特征捕捉目标数据集的正常和异常分布。具体而言，所提方法首先使用预训练表格基础模型为每个输入样本提取通用语义特征。然后，在目标数据集上训练基于自编码器的特征提取器以获得领域判别特征，该特征描述样本如何偏离该领域的正常模式。由于这两类特征来自不同的特征空间，且在分布和语义层次上均存在差异，直接拼接它们往往导致相互干扰，而具有许多额外参数的融合模块在标签稀缺时难以可靠训练。因此设计了一种原型条件调制机制，该机制在类原型上构建融合信号，并为每个样本自适应地整合这两类特征；在整合特征之上，使用弱监督损失训练异常评分网络。在各种公开数据集上的实验表明，所提方法优于竞争方法，尤其是当训练过程中只有少量标注异常可用时。本文的主要贡献总结如下。

  • 我们将通用语义增强引入表格数据的弱监督异常检测。通过引入预训练表格基础模型的跨领域知识，所提方法解决了现有方法仅依赖单一领域先验的局限性，并使通用知识与领域特定知识相互补充。
  • 我们设计了一种原型条件调制机制，该机制为每个样本无缝整合通用语义特征和领域判别特征，即使在标注异常极其稀缺时也能稳定训练。
  • 我们在公开数据集上进行了大量实验，结果表明当只有少量标注异常可用时，所提方法优于竞争方法。消融研究进一步验证了各组件的有效性。

2 相关工作

2.1 弱监督异常检测

弱监督异常检测方法从少量标注异常和大量未标注数据中学习检测模型。DevNet [12] 在标注异常与高斯参考先验之间施加统计偏差损失；Deep SAD [21] 将 Deep SVDD [20] 扩展为半监督超球目标；FEAWAD [11] 用从深度自编码器导出的三个互补信号丰富评分网络。最近，PReNet [13] 通过在标注对上学习成对关系特征来放大有效监督，而 RoSAS [26] 通过在标注异常和未标注样本之间插值生成连续目标伪异常来解决标签稀缺问题。尽管有这些进展，所有这些方法都仅从目标数据集学习表示，在目标数据之外的分布上表现不佳。在视觉异常检测领域，研究人员尝试使用预训练模型解决这一问题。分别在 ImageNet [3] 和 CLIP [17] 后端上预训练的 PatchCore [19] 和 WinCLIP [9] 优于仅在目标数据上训练的方法，表明跨领域语义知识可以迁移到异常检测。然而，如何在表格数据的异常检测中有效利用这种跨领域通用语义知识仍是一个未探索的方向。我们的方法旨在通过利用表格数据上预训练模型的通用语义来增强领域特定模型的异常检测能力，从而填补这一空白。

2.2 预训练知识整合与特征融合

结合来自异构源的互补知识是跨多种任务的广泛策略。在视觉-语言建模中，CLIP [17] 证明视觉和语言特征编码了同一输入的正交方面，实现了任何单一模态都无法单独实现的零样本泛化。在自然语言处理中，用领域特定特征增强预训练表示（如 BERT [4]）已成为低资源任务的标准做法，其中预训练编码器提供跨领域先验来补偿稀缺标签 [16]。在特征融合方面，特征级线性调制（FiLM）[14] 通过特征级仿射变换实现跨模态条件化；更具表达力的设计，包括门控多模态单元（GMU）[1]、交叉注意力 [24] 和 DCN v2 [25]，以显著更多可训练参数为代价建模高阶交互。原型网络 [22] 提供了互补的视角：将表示学习锚定到不可训练的类原型向量上，可以在无需大量参数优化的情况下实现有效的少样本学习。在推理时，零参数集成方法如预测性动态融合（PDF）[5] 通过按每个视图的置信度和跨模态一致性加权来结合互补的预测分数。然而，这些现有的参数化融合模块在极端标签稀缺下往往失效，因为少数标注异常提供的信号不足以可靠地优化额外参数。我们的方法通过将融合信号锚定在固定的类原型上来弥合这一差距，在没有可训练条件向量的情况下实现每样本自适应调制。

3 方法

3.1 问题定义

设 𝒳 = {𝐱ᵢ}ᵢ₌₁ⁿ ⊂ ℝᵈ 为一个表格数据集，其中 𝐱ᵢ ∈ ℝᵈ 是第 i 个实例的特征向量，yᵢ ∈ {0, 1} 表示其真实标签（yᵢ = 1 表示异常，yᵢ = 0 表示正常）。在弱监督设置中，只有少量异常样本子集 ℳ = {(𝐱ⱼ, yⱼ) | yⱼ = 1}（|ℳ| ≪ n）被标注。其余 n − |ℳ| 个样本构成未标注集合 𝒰，该集合以正常样本为主，但可能包含少量未检测到的异常。目标是学习一个函数 s: ℝᵈ → ℝ，将每个实例映射到异常分数，使标注异常 𝐱ₚ ∈ ℳ 的分数明显高于未标注样本 𝐱_q ∈ 𝒰，从而在分数空间中清晰地将两者分开。

3.2 框架概述

图 1： 所提框架概述。通用语义特征 𝐭ᵢ 由冻结的预训练模型提取，领域特定特征 (𝐡ᵢ, 𝐫ᵢ, eᵢ) 由自编码器提取。我们的 ProtoFiLM-Dynamic 通过每样本原型注意力融合 𝐡ᵢ 和 𝐭ᵢ，产生融合表示 𝐟ᵢ。评分网络以 (𝐫ᵢ, 𝐟ᵢ, eᵢ) 为输入，输出异常分数 sᵢ。在训练期间，标注异常与未标注样本之间系数为 α 的标签插值生成伪样本 𝐱_mix，其分数被监督朝向插值的软目标 αa（a 为分数边距）；在推理时，零参数分数集成将异常分数与预训练模型的类概率 p_t 结合为最终分数 s_final。

如图1所示，我们的框架由四个组件组成。(1) 通用语义特征提取：冻结的表格数据预训练模型生成跨领域嵌入 𝐭ᵢ ∈ ℝ⁵¹²，无需任何梯度更新。(2) 领域判别特征提取：基于重构的特征提取器捕捉目标数据集的领域特定知识，产生隐藏嵌入 𝐡ᵢ、归一化残差 𝐫ᵢ 和重构误差 eᵢ。(3) ProtoFiLM-Dynamic：我们的原型条件调制模块通过类原型上的每样本软注意力自适应编码 𝐡ᵢ，产生融合表示 𝐟ᵢ；在训练期间，标签插值策略在标注异常和未标注数据之间生成具有连续监督目标的伪样本 𝐱_mix，从而致密化稀缺的监督信号。(4) 异常评分网络：三层 MLP 以 (𝐫ᵢ, 𝐟ᵢ, eᵢ) 为输入，输出异常分数 sᵢ；在推理时，零参数分数集成根据置信度和一致性将该分数与预训练模型的类概率 p_t 结合。

3.3 模块设计

通用语义特征。 我们选择 TabPFN [8]，这是一个先验数据拟合网络，在从贝叶斯先验采样的大量合成表格分类任务上进行元训练。在测试时，它通过将整个训练集作为线索学习上下文来生成校准的类概率，无需任何梯度更新。我们使用其内部表示作为冻结的特征提取器：对每个样本 𝐱ᵢ，我们提取

𝐭ᵢ = TabPFN(𝐱ᵢ | 𝒳) ∈ ℝ⁵¹², (1)

其中 𝒳 表示用作 TabPFN 上下文示例的完整训练集。由于 TabPFN 已接触过远超任何单一目标数据集范围的分布，𝐭ᵢ 编码了跨领域统计规律性，例如哪些特征组合在多个领域中在统计上是异常的。更重要的是，TabPFN 在所有训练阶段完全冻结：其唯一开销是联合训练开始前对训练集的一次前向传播以缓存 𝐭ᵢ，这降低了我们的训练开销。

领域判别特征。 TabPFN 提供通用语义上下文；作为补充，我们需要一个特征提取器来揭示每个样本如何偏离目标数据集的结构规律。我们采用 FEAWAD [11] 中基于重构的特征提取模块，该模块建立在对称的编码器-解码器对之上：编码器 fₑ: ℝᵈ → ℝ⁶⁴ 通过两个全连接层（d → 128 → 64）将每个样本压缩为紧凑的结构嵌入，解码器 f_d: ℝ⁶⁴ → ℝᵈ 与之镜像，通过两个全连接层（64 → 128 → d）重构输入。该提取器在以正常样本为主的未标注数据上预训练，能准确重构正常模式，而对偏离这些模式的样本产生较大的重构误差，使其具有揭示领域特定异常的固有能力。从输入 𝐱ᵢ 和重构的 𝐱̂ᵢ = f_d(fₑ(𝐱ᵢ))，我们提取三个特征：

𝐡ᵢ = fₑ(𝐱ᵢ) ∈ ℝ⁶⁴, (2)

𝐫ᵢ = (𝐱̂ᵢ − 𝐱ᵢ) / ‖𝐱̂ᵢ − 𝐱ᵢ‖₂ ∈ ℝᵈ, (3)

eᵢ = ‖𝐱̂ᵢ − 𝐱ᵢ‖₂ ∈ ℝ. (4)

每个特征扮演独特的角色：隐藏嵌入 𝐡ᵢ 携带样本的压缩结构表示；归一化残差 𝐫ᵢ 编码重构偏差的方向，提供有关异常类型的信息；标量误差 eᵢ 量化偏差的大小，并作为持久信号注入评分网络的每一层。总之，这三个特征提供了 TabPFN 语义表示可能无法完全捕捉的互补领域特定信息。

ProtoFiLM-Dynamic 融合

虽然通用语义特征和领域特定特征互补，但在极其稀缺的监督下有效融合它们仍是一个关键挑战。标准 FiLM [14] 对一个特征空间应用全局仿射变换，并用另一个特征空间对其进行条件化，使用所有样本共享的单个条件向量。这种方法在数据丰富的场景中效果良好，但在异常监督严重受限的异常检测中性能下降。

首先，在联合训练之前，我们在 TabPFN 嵌入空间中计算两个类原型向量 [22]。异常原型 𝐜ₐ 是 ℳ 中标注异常的平均嵌入；正常原型 𝐜ₙ 是随机子样本 𝒰₀ ⊂ 𝒰 的平均值，作为正常类的代理：

𝐜ₐ = (1/|ℳ|) Σⱼ∈ℳ 𝐭ⱼ ∈ ℝ⁵¹², (5)

𝐜ₙ = (1/|𝒰₀|) Σⱼ∈𝒰₀ 𝐭ⱼ ∈ ℝ⁵¹². (6)

两个原型在整个联合训练过程中存储为不可训练的缓冲区。

其次，对每个样本，我们在 TabPFN 空间中计算到两个原型的欧氏距离平方，并通过 softmax 将它们转换为软混合系数：

[αᵢⁿ, αᵢᵃ] = softmax([−‖𝐭ᵢ − 𝐜ₙ‖₂², −‖𝐭ᵢ − 𝐜ₐ‖₂²]), (7)

其中 αᵢⁿ 和 αᵢᵃ 分别是朝向正常原型和异常原型的软注意力权重。然后我们形成每样本条件向量作为它们的凸组合 𝜹ᵢ = αᵢⁿ𝐜ₙ + αᵢᵃ𝐜ₐ ∈ ℝ⁵¹²。接近异常原型的样本获得 αᵢᵃ ≈ 1；明显正常的样本获得 αᵢⁿ ≈ 1。

第三，两个零初始化的线性层（W_γ, W_β ∈ ℝ⁶⁴ˣ⁵¹²）将 𝜹ᵢ 映射到每通道的缩放和平移参数 𝜸ᵢ = W_γ𝜹ᵢ 和 𝜷ᵢ = W_β𝜹ᵢ，用于调制自编码器隐藏嵌入：

𝐡'ᵢ = (1 + 𝜸ᵢ) ⊙ 𝐡ᵢ + 𝜷ᵢ, (8)

其中 ⊙ 表示逐元素乘法。最后，我们得到融合表示 𝐟ᵢ = [𝐡'ᵢ; 𝐭ᵢ] ∈ ℝ⁵⁷⁶。由于 𝜹ᵢ 是固定不可训练向量的凸组合，流入 W_γ 和 W_β 的梯度保持有界且条件良好，与标签数量无关，这直接避免了梯度饥饿。

异常评分网络。 评分网络接收归一化残差 𝐫ᵢ、融合表示 𝐟ᵢ 和重构误差标量 eᵢ，并生成异常分数。重构误差在每个隐藏层中被拼接，确保这一强几何信号在整个计算过程中保持可见，无论前面的层如何变换 𝐫ᵢ 和 𝐟ᵢ。

𝐳₁ = ReLU(W₁[𝐫ᵢ; 𝐟ᵢ; eᵢ]) ∈ ℝ²⁵⁶, (9)

𝐳₂ = ReLU(W₂[𝐳₁; eᵢ]) ∈ ℝ³², (10)

sᵢ = W₃[𝐳₂; eᵢ] ∈ ℝ, (11)

其中所有权重矩阵均使用 Xavier 初始化 [6]。标量输出 sᵢ 在训练期间直接用于偏差损失，在推理时通过 sigmoid 函数映射到开区间 (0, 1) 用于分数融合。

3.4 训练与推理

训练按三个连续阶段进行，如算法1所示。在联合训练阶段，每个小批量 ℬ 是类平衡的，包含从未标注集合 𝒰 中抽取的等量正常样本和从标注异常 ℳ 中重采样的异常样本（有放回，因为只有 |ℳ| 个可用）。模型通过最小化每个批次上的平均损失进行训练，每样本损失为：

ℒ = ℒ_d + ℒ_e + λ·ℒ_rosas. (12)

我们的部分目标函数受 FEAWAD [11] 提出的损失启发。对于标签为 yᵢ 的样本 𝐱ᵢ，偏差损失 ℒ_d 驱动异常分数 sᵢ 对正常样本趋向 0，对标注异常超过边距 a = 5，重构约束 ℒ_e 在重构误差 eᵢ 上镜像这一目标：

ℒ_d = (1 − yᵢ)|sᵢ| + yᵢ max(0, a − sᵢ), (13)

ℒ_e = (1 − yᵢ)eᵢ + yᵢ max(0, a − eᵢ). (14)

RoSAS 插值损失 [26] ℒ_rosas 用连续目标伪样本致密化监督信号，定义在 ℬ 内形成的异常和未标注样本对上，每对被插值为恰好一个伪样本 𝐱_mix。具体而言，对于异常样本 𝐱ₚ，我们将其与 ℬ 未标注部分中的一个不同正常样本 𝐱_q 一一配对，抽取独立系数 α ~ Uniform(0, 1)，并在特征空间中将两者混合为 𝐱_mix：

𝐱_mix = (1 − α)𝐱_q + α𝐱ₚ, (15)

其分数被回归到软目标 αa：

ℒ_rosas = |s(𝐱_mix) − αa|, (16)

其中 s(𝐱_mix) 通过将 𝐱_mix 经过相同的编码器-融合-评分管道获得。由于 αa 是连续软标签而非常数，这些伪样本填充了 (ℒ_d + ℒ_e) 监督的两个端点 {0, a} 之间的整个分数区间，这鼓励平滑的评分函数并缓解极端标签稀缺下的过拟合。因此，每个伪样本与 ℬ 的样本一一对应，贡献一个独立的回归项，与其构建来源的批次样本共享网络参数，但在损失中不与它们中的任何一个交互。

推理时分数融合。 在推理时，有两个互补的异常信号可用：基于偏差的分数 s_d = σ(s(𝐱)/a) ∈ [0, 1]，其中 σ(·) 是 sigmoid 函数，a 是分数边距，以及 TabPFN 类概率 p_t ∈ [0, 1]。我们应用预测性动态融合（PDF）[5] 作为辅助零参数集成，它按每个信号自身的预测置信度和跨模态一致性加权：

w_d ∝ |s_d − 0.5| + (1 − |s_d − p_t|), (17)

w_t ∝ |p_t − 0.5| + (1 − |s_d − p_t|), (18)

s_final = (w_d·s_d + w_t·p_t) / (w_d + w_t), (19)

其中 ∝ 表示成比例：两个未归一化权重在公共因子上定义，该因子在 s_final 中被 w_d + w_t 归一化时抵消，因此只有它们的相对大小重要。这里 |s − 0.5| 通过与决策边界的距离衡量预测置信度，(1 − |s_d − p_t|) 奖励两个视图之间的跨模态一致性。这种融合不引入额外的训练成本，作为学习框架的轻量级补充。总之，四个组件和三阶段训练过程形成了一个连贯的框架，系统地解决了表格数据弱监督异常检测中极端标签稀缺下的跨领域特征融合和梯度饥饿问题。

4 实验

4.1 实验设置

我们使用 ADBench 基准 [7] 评估我们的模型。ADBench 是一个标准化数据集，包含来自各个领域的57个真实世界表格异常检测数据集，包括网络入侵、医疗诊断和金融欺诈。与之前的研究一致，我们排除了异常少于30个的数据集，得到42个用于评估的数据集。这42个数据集跨越五个应用领域：医疗诊断（annthyroid, breastw, Cardio, Cardiotocography, Hepatitis, Lymphography, mammography, Pima, thyroid, vertebral, WBC, WDBC, WPBC）、网络入侵（HTTP, InternetAds, SMTP）、图像和信号识别（ALOI, landsat, letter, mnist, optdigits, PageBlocks, pendigits, satellite, satimage-2, speech, Waveform）、金融欺诈和垃圾信息（campaign, SpamBase, Stamps），以及其他科学和工业数据（cover, fault, glass, Ionosphere, magic.gamma, musk, shuttle, skin, Wilt, vowels, wine, yeast）。数据集大小从几百到几万个样本不等，异常比例在1%到35%之间。每个数据集按80/20比例分层划分为训练集和测试集。未标注训练集包含2%未检测到的异常，反映了未标注数据并非纯正常而是不可避免地被少量异常污染的现实。在训练集中，我们只向模型提供 |ℳ| = 8 个标注异常，这比常用的 |ℳ| = 30 [12, 11, 13] 是更严格的设置。所有实验用不同随机种子重复10次，报告平均 AUROC 和平均 AUPRC 值。所有模型在 NVIDIA RTX 3090 GPU 上运行，使用 Adam 优化器 [10]（β₁ = 0.9，β₂ = 0.999，ε = 10⁻⁸，lr = 10⁻³）训练。自编码器预训练100轮，整个框架联合优化30轮。

我们与三类基线进行比较。(1) 传统机器学习分类器：随机森林（RF）[2] 和 CatBoost [15] 作为监督二分类器训练，将8个标注异常和所有未标注训练样本分别作为正类和负类。(2) 深度弱监督方法：DevNet [12] 通过带高斯先验的偏差损失学习异常评分函数；DeepSAD [21] 将超球目标扩展到半监督设置；FEAWAD [11] 用三个自编码器导出的特征信号丰富评分网络；PReNet [13] 通过在标注对上学习成对关系特征放大监督。(3) 基础模型基线：独立的 TabPFN [8] 直接作为上下文分类器应用。

完整训练目标 ℒ = ℒ_d + ℒ_e + λ·ℒ_rosas 引入了一个额外的超参数 λ，控制 RoSAS 增强损失的相对权重。图4报告了 λ 在0.05到5.0的100倍范围内变化时，42个数据集上10次运行的 AUROC 和 AUPR。

根据结果，大多数测试的 λ 值优于消融基线（拼接 + 偏差损失）。曲线是非单调的，而不是在任一极端显示明显退化：λ = 0.5 达到峰值 AUROC（0.9308），λ = 2.0 紧随其后（0.9303），而即使在 λ = 0.1（0.9156）处的单一下降也在 λ = 0.2（0.9286）处快速恢复。这一围绕0.5–2.0的宽最优区域表明 RoSAS 信号在很宽的强度范围内都是有益的，该方法不需要仔细调整此超参数。我们选择 λ = 0.5 作为默认值。

5 结论

本文提出了一种面向表格数据弱监督异常检测的通用语义增强方法，该方法将冻结表格基础模型中的通用知识与目标数据集自编码器学习的领域特定特征相结合。为了在极端标签稀缺下整合它们，我们设计了 ProtoFiLM-Dynamic，一种原型条件调制模块，通过将调制信号锚定在固定类原型上来自适应增强每个样本，并采用 RoSAS 风格的标签插值损失来致密化稀缺监督。在42个公开数据集上，仅有八个标注异常时，所提方法在竞争基线中获得最佳平均排名，通用语义在领域标签最稀缺时最有益。消融研究进一步表明，ProtoFiLM-Dynamic 的每样本条件化与无参数推理时分数融合互补，带来额外增益。当前设计的一个局限是类原型在联合训练前计算一次并保持固定。未来工作可以专注于在线原型细化，随着评分网络的改进更新类表示，这可能在极其稀疏的监督下进一步稳定语义增强。更广泛地说，我们希望这项工作能激励进一步探索如何将大规模预训练模型的通用语义知识与领域特定表示系统地整合到其他数据稀缺的检测设置中。
