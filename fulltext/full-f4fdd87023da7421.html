摘要
研究规划是 AI 科学家的决定性能力。然而，研究计划没有可验证的答案，因此强化学习缺乏所需的环境：任务与评估器配对。从科学论文中提取的评分标准可以提供评估器。然而，现有的流水线从相同的内容中提取问题和标准，因此可以通过改写来获得奖励。评分标准在每次 rollout 中进一步被压缩为单个标量。我们引入了 PaperGym，这是一个将每篇研究论文转化为完整训练环境的统一框架。PaperGym 利用论文的结构：问题由研究目标和背景合成，而标准则从方法和实验中得出。这些标准涵盖方法创新和实验设计，标准泄漏率降至 3.7%，而现有数据集为 11.90% 至 34.10%。训练中两次使用评分标准：首先作为 OPSD 自教师的特权上下文，然后作为 GRPO 的奖励。在 Qwen3-1.7B/4B/8B 中，该策略优于监督微调、单独使用任一阶段以及反向顺序，将五个基准测试的平均分提高了 +5.6、+5.0 和 +4.8 分。在训练配方固定的情况下，在 PaperGym-20k 上训练的模型在三项比较中获胜率为 58.1%，而 RubricHub Science 为 28.2%。训练后的 Qwen3-8B 在 ResearchQA 上达到 73.48，超过了规模大得多的 Kimi K2.6。我们发布了流水线、包含 20,000 个实例的语料库 PaperGym-20k，以及基准测试 PaperGym-Innov 和 PaperGym-Design。

引言
AI 科学家在自动化科学发现方面取得了快速进展，在自然科学领域产出了完整的研究论文和新发现
(
Lu et al., 2024
;
Mitchener et al., 2025
;
Weng et al., 2025
)
。每一个这样的结果都始于研究计划，它规定了要进行的假设、方法和实验；计划的质量限制了系统最终能实现的成就
(
Goel et al., 2025
)
。然而，与数学答案或程序不同，研究计划没有自动检查机制：没有可供比较的基准真相，判断其质量需要专家评审。
具有可验证奖励的强化学习在数学和代码生成方面推动了显著进展，其中每个问题都配有一个可自动检查的答案
(
Guo et al., 2025
;
Yu et al., 2026
)
。该范式依赖于一个训练环境：一组任务，每个任务都配有一个对候选解决方案进行打分的评估器。研究规划没有提供这样的环境。专家评审无法提供训练所需规模的反馈。然而，科学文献已经大规模包含了这两个组成部分：数百万篇研究论文记录了现实问题及其作者开发的解决方案。这些知识嵌入在非结构化文本中，不能直接用作训练任务或奖励信号。
每篇论文都提出一个研究问题，开发一个解决方案，并报告支持它的实验，因此可以从问题中提取现实任务，从解决方案中提取评判标准。最近的研究遵循这一路线，将论文转化为用于监督微调的问答对
(
Wang et al., 2025
)
或提取研究目标与评分标准，作为强化学习的奖励
(
Goel et al., 2025
;
Fan et al., 2026
;
Sauter et al., 2026
)
。然而，以这种方式获得的环境存在两个问题：奖励不能如实地衡量规划能力，并且它携带的信息在训练过程中很大程度上被浪费了。
现有的流水线在不考虑论文结构的情况下从论文中提取问题和评分标准，通常来自相同的内容
(
Goel et al., 2025
;
Yifei et al., 2025
)
。结果，标准经常重述问题已经说过的内容：我们发现其中 11.90% 到 34.10% 可以仅从问题中推断出来（表
4
）。因此，模型可以简单地通过改写问题来提高其奖励。此外，计划是根据其提出的方法和验证它的实验来评判的。现有数据集中的特定实例标准几乎只涵盖方法，而实验设计则由所有实例共享的通用指南来检查
(
Goel et al., 2025
;
Sauter et al., 2026
)
。
即使标准本身是合理的，当前的训练也只利用了它们提供的监督的一小部分。在“评分标准作为奖励”的训练中，每个标准由单独的评估器调用检查，然而判决结果仅作为每次 rollout 的一个聚合标量到达策略
(
Gunjal et al., 2025
;
Goel et al., 2025
)
。监督微调避开了评分标准并模仿单一参考计划；因为一个研究问题有许多有效的计划，这降低了输出多样性，在实践中收效甚微
(
Goel et al., 2025
)
。最近的工作以评分标准为条件生成自蒸馏教师，以恢复 token 级别的指导
(
Gu et al., 2026
;
Rezaei et al., 2026
)
，但单独的蒸馏从不根据标准检查生成的计划，而且我们发现它对特权上下文过拟合（图
3
）。
在本文中，我们引入了 PaperGym，这是一个将每篇研究论文转化为完整训练环境的统一框架。该流水线利用论文的固有结构来分离两个组件的来源：问题仅从研究目标和背景合成，而参考答案仅从方法和实验设计中得出。这一单一约束将标准泄漏率降低至 3.7%，比现有数据集低三到九倍。每个实例包含十个原子二元标准，检查方法创新和实验设计。然后，训练通过在计划分布的以评分标准为中心的演化中两次使用评分标准，提取了评分标准的全部价值：作为自蒸馏教师的特权上下文，将标准转化为密集的 token 级别指导，并在有效计划上建立广泛的先验；以及作为 GRPO 的奖励，根据标准验证完整的计划并优化策略。该流水线应用于计算机科学、物理学和经济学领域的 20,000 篇论文，生成了 PaperGym-20k 和两个留出基准测试 PaperGym-Innov 和 PaperGym-Design。
大量实验支持该框架的两个方面。在训练配方固定的情况下，在 PaperGym-20k 上训练的模型在三项比较中获胜率为 58.1%，而在 RubricHub Science 上训练的同一模型为 28.2%：这一差距来自数据。两阶段策略在所有三个规模上都优于监督微调、单独使用任一阶段以及反向顺序，将 Qwen3-1.7B、4B 和 8B 的五个基准测试平均分分别提高了 +5.6、+5.0 和 +4.8 分。训练后的 Qwen3-8B 在 ResearchQA 上达到 73.48，高于规模大得多的 Kimi K2.6 的 73.19。
我们的主要贡献总结如下：
•
我们提出了一种将研究论文转化为训练环境的流水线，独立于双维度评分标准构建任务；生成的 PaperGym-20k 包含跨三个领域的 20,000 个实例，标准泄漏率为 3.7%，而现有数据集为 11.90% 至 34.10%。
•
我们构建了 PaperGym-Innov 和 PaperGym-Design，这是留出基准测试，分别评估生成研究计划的方法创新和实验设计。
•
我们开发了一种两阶段策略，首先将相同的评分标准用作自蒸馏的特权上下文，然后用作 GRPO 奖励；它优于监督微调、单独使用任一阶段以及反向顺序，并且 Qwen3-8B 在 ResearchQA 上达到 73.48，超过了 Kimi K2.6。

仅 OPSD 在第 200 步左右达到峰值，然后下降，因为其特权信息推动了早期的快速进展，但会过拟合，在没有 GRPO 优化的情况下限制了性能。仅 GRPO 落后于 OPSD，因为从基础策略进行的探索是不稳定的，这种影响在较小规模时最为明显。相比之下，OPSD+GRPO 始终优于所有替代方案，包括 GRPO+OPSD，因为它能更快地收敛到更高的最终准确率。关键是预热：OPSD 为 GRPO 构建了初始分布以进行优化，而先应用 GRPO 在随机初始化上会产生不稳定的探索和更糟糕的结果。这种优势延伸到所有规模（第
B.3
节）。
熵动力学。
训练期间的熵轨迹解释了 OPSD+GRPO 的优势，因为 OPSD 通过注入新知识提高了输出熵，而 GRPO 通过向高奖励区域收敛降低了熵。至关重要的是，在 OPSD 预热之后，GRPO 的熵下降更为急剧，证实了 OPSD 提供了一个更广泛、结构更好的先验供 GRPO 优化（图

结论
我们提出了 PaperGym，这是一个将每篇研究论文转化为用于研究计划生成的完整训练环境的统一框架。其四阶段提取流水线从研究目标和背景合成研究问题，并从研究方法和实验设计中得出参考解决方案，将输入与答案解耦，从源头上消除了标准泄漏。生成的包含 20,000 个实例的语料库 PaperGym-20k 的标准泄漏率为 3.7%，是开源替代品中最低的。特定于实例的评分标准检查方法创新和实验设计，训练中两次使用相同的评分标准：首先作为自蒸馏教师的特权上下文，然后作为 GRPO 的奖励。使用这种以评分标准为中心的演化训练的 Qwen3 模型在领域内和外部基准测试上持续改进，并且训练后的 8B 模型在 ResearchQA 上超过了规模大得多的 Kimi K2.6。
