OpenAI 推出 Linux 版 ChatGPT 桌面应用

ChatGPT 已在全球各地的桌面上线，但有一个地方明显缺席：Linux 社区。事实上，开源开发者社区中的某些群体一直强烈呼吁OpenAI 将其聊天机器人引入他们的领地。
截至本周，OpenAI 已经纠正了这一疏忽，发布了专用的 Linux 版 ChatGPT 应用。
“Linux 一直是桌面应用程序需求量最大的平台之一，此次发布将 ChatGPT 和 Codex 扩展到了所有主要的桌面操作系统，”该公司周二表示。
这款目前以预览版形式发布的新应用，将使 Linux 用户能够在多种不同的发行版上使用 ChatGPT、ChatGPT Work 和 Codex。截至周二，该版本已在全球范围内发布。
OpenAI 表示，将支持的发行版包括 Ubuntu 24.04 和 26.04 LTS、Debian 13 以及 Fedora 43 和 44 的桌面变体。整个 Linux 社区包含数百种发行版，尽管 OpenAI 在此选择的发行版可作为各种“下游”桌面发行版或“分支版本”的基础，因此这些版本也应该与 OpenAI 的应用程序兼容。
OpenAI 的动作比 Anthropic 稍慢了一些，后者在一个月前发布了 Linux 版 Claude 桌面应用。Anthropic 的应用适用于Ubuntu 22.04 或更高版本以及 Debian 12 或更高版本。
