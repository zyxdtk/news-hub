摘要

基于 Transformer 的神经网络的一项显著能力是上下文学习。这促使我们思考"上下文"控制。我们能否在仅知道（1）系统属于某一特定系统族，以及（2）一些系统演化数据（以上下文轨迹形式提供）而没有具体参数信息的情况下控制系统？

具体而言，我们研究了 Transformer 模型对不稳定非线性动力系统执行"上下文"控制的能力，其中上下文仅由无驱动的系统动态组成。我们利用多头 GPT-2 风格架构，并在两个经典非线性系统——车摆系统和双连杆 acrobot 系统——上评估性能，其中系统参数对 Transformer 而言是未知的。我们考虑这样一种设置：专家控制器的轨迹在训练时可用，但在推理时不可用。在此，我们确定了训练 Transformer 执行低层控制所必需的训练技术。通过对检查点的分析，我们表明上下文控制是可行的，并且所学策略的性能通常随上下文增加而提升。此外，Transformer 模型能够泛化以稳定分布外的系统。

I 引言

驱动 Transformer 性能的一个关键特性是上下文学习（ICL），它使模型能够在推理时通过上下文提示适应新任务，而无需更新模型权重 [1, 2, 3, 4]。虽然 ICL 已在线性回归 [5]、滤波 [6] 和中层机器人控制 [7] 中得到研究，但其在不稳定、欠驱动、非线性系统的低层闭环稳定控制中的应用在很大程度上仍未被探索。

稳定一个具有部分未知动态的系统，传统上需要系统辨识 [8] 或直接合成数据驱动控制器 [9]。基于通用控制范式 [10]，我们旨在实现一个能够稳定整个参数化系统族的单一策略，而无需显式参数估计或权重更新。在这种设置下，参数辨识从离线预处理转移到测试时的上下文操作。

图 1：给定零力矩系统演化 u_{0:k-1}{=}0 的上下文和当前状态 x_k，Transformer 预测下一状态 \hat{x}_{k+1}、控制器模式 \hat{c}_k 和动作 \hat{u}_k，并将其应用于受控对象。

强化学习算法通常用于欠驱动系统的稳定等任务 [11, 12]，然而我们感兴趣的是研究 Transformer 的 ICL 能力以及架构和训练设计选择如何促成类似的任务成功。

本工作的主要贡献是 ¹：

  • 涌现的上下文能力分析：我们研究了稳定成功率如何随上下文长度和模型训练而扩展，证明 ICL 随训练进展而涌现。延长训练显示出数据记忆的证据，这有助于在某些情况下成功泛化到分布外数据。
  • 通过高斯扰动实现鲁棒性：我们在专家数据生成过程中注入状态级高斯噪声。若不这样做，车摆系统在 50 个上下文样本下的分布内稳定成功率将骤降至 5%（有扰动时为 86%），证实了接触驱动扰动至关重要。
  • 在非线性基准上的实证验证：我们在欠驱动车摆 [13] 和 acrobot [14] 系统上评估我们的架构，在最长上下文长度下分别实现高达 86%（车摆）和 74%（acrobot）的分布内稳定成功率。

II 相关工作

为不稳定非线性系统开发通用控制器处于 ICL、基于序列的决策制定和机器人学基础模型的交叉点。

上下文学习的涌现
Transformer 执行 ICL 的能力最初在简单设置中被表征，例如线性回归 [5, 15] 和高斯-马尔可夫过程预测 [6]。虽然 ICL 在大语言模型中被广泛研究 [1, 16, 17]，但最近的工作表明 ICL 是一种由训练数据的分布特性驱动的涌现属性 [18, 19]，而 [20] 研究了 ICL 与动力系统预测和联想回忆的关系。我们将这些发现扩展到不稳定、欠驱动非线性系统的低层稳定控制。

用于基于序列控制的 Transformer
决策 Transformer [21] 和轨迹 Transformer [22] 推动了 Transformer 在强化学习的序列建模方法中的应用。后续工作将这些模型应用于系统辨识 [23] 和任务适应 [24]。现有方法侧重于高层规划，然而在不稳定平衡点处的低层稳定控制是一个有趣的案例研究，因为其对复合误差具有独特的敏感性。我们通过使用多任务目标进行隐式参数辨识和状态扰动专家演示以确保稳定鲁棒性来弥合这一差距。

通用控制器与基础模型
我们基于通用控制范式 [10] 构建，该范式统一了跨受控对象实现的控制。机器人学中的并行工作利用微调的 LLM [25, 26] 或视觉-语言模型 [27, 28] 进行闭环控制。与依赖高层抽象的基础模型不同，我们摒弃了自然语言提示 [26]。

III 问题表述

III-A 系统表示与离散化

考虑由常微分方程支配的非线性连续时间动力系统族 ℱ：
x˙(t) = f(x(t), u(t); ω)
其中 x(t) ∈ 𝒳 ⊆ ℝ^n 是状态，u(t) ∈ 𝒰 ⊆ ℝ^m 是控制输入，ω ∈ Ω ⊂ ℝ^p 表示未知物理参数。在采样间隔 δ_t 下运行，离散时间动态由下式给出：
x_{k+1} = Φ_ω(x_k, u_k, δ_t)。
我们可以将系统分布定义为 𝒟 := {Φ_ω | ω ∈ Ω}。

对于每个实现 ω，专家控制器 κ_ω: ℝ^n → ℝ^m 在给定状态 x_k 时产生控制动作 u_k* = κ_ω(x_k)。我们使用 κ_ω 进行离线训练数据生成；在推理期间，所学策略仅接收状态-动作历史，而无法访问 ω。

III-B 通过上下文学习实现通用控制

遵循通用控制的思想 [10]，我们的目标是训练一个策略 π，能够在没有 ω 的显式知识的情况下稳定任何系统实现 Φ_ω ∼ 𝒟，利用通过初始无驱动响应实现的 ICL。

设 N 为无驱动响应的窗口，其中我们施加零力矩 u_k = 0。在无驱动阶段生成的序列形成上下文提示：
H_{0:N-1} = {(x_k, e_k, c_k, u_k=0)}_{k=0}^{N-1}。

这里，e_k ∈ ℝ 是当前状态与目标状态之间的范数距离，c_k 表示当前激活的控制器模式，这在我们的情况下是必要的，因为我们采用混合专家控制器。

由于系统模型已知，动态可以在物理参数 ω ∈ Ω 中线性表示，而从轨迹 H_{0:N-1} 估计 ω 需要最小上下文窗口 N 以产生唯一可解的方程组 [29]。这促使我们对稳定成功率作为 N 的函数进行实证研究。

策略 π 在步骤 k ≥ N 时使用 H_{k-N:k-1} 产生近似专家的动作：
π(H_{k-N:k-1}, x_k) ≈ κ_ω(x_k)。

为了优化 π，我们首先构建训练数据集 𝒯 = {τ^{(j)}{κ_ω}}{j=1}^M，其中每条轨迹 τ^{(j)}_{κ_ω} 是通过在采样的实现 Φ_ω ∼ 𝒟 下展开长度为 N_total 的轨迹生成的。每次展开从无驱动响应阶段（0 ≤ k < N，其中 u_k = 0）过渡到控制阶段（N ≤ k ≤ N_total，其中 u_k = κ_ω(x_k)），存储为 (x_k, e_k, c_k, u_k)。展开被切分成长度 L ≪ N_total 的片段，起始索引以相等概率从无驱动响应或完整序列中采样，确保频繁接触不同长度的无驱动序列。

IV 多任务序列模型框架

IV-A Transformer 模型

通用策略 π_γ 由权重 γ ∈ Γ 参数化，使用 GPT-2 风格的仅解码器 Transformer [30] 建模。该模型通过因果自注意力掩码处理上下文历史，仅允许关注先前的标记 [31, 30]。为了在上下文序列之间保持相对位置感知，我们采用旋转位置编码[32]。

为了将潜在嵌入同时锚定在系统动态和控制律合成上，Transformer 在每一步 k 分支为三个多层感知机（MLP）头：
(1) 控制头（\hat{u}k）：预测控制动作。
(2) 状态动态头（\hat{x}{k+1}）：作为辅助任务预测状态，迫使共享表示隐式辨识 ω。
(3) 模式头（\hat{c}_k）：一个分类器，预测控制器的当前激活模式（例如能量整形或稳定）。

IV-B 多任务学习目标

我们通过在系统分布 𝒟 上最小化复合损失函数 ℒ 来优化 γ 以获得 π_γ：

min_γ 𝔼_{Φ_ω∼𝒟} [Σ_{k=0}^T ℒ(π_γ(H_{k-L:k-1}, x_k), z_k)] (1)

其中 z_k = (u_k, x_{k+1}, c_k) 包含专家动作 u_k = κ_ω(x_k)、下一状态 x_{k+1} 和控制器模式 c_k，且
ℒ = λ_u ‖u_k* − \hat{u}k‖²_2 + λ_x ‖x{k+1} − \hat{x}_{k+1}‖²_2 + λ_c CE(\hat{c}_k, c_k)，
其中 λ_u、λ_x、λ_c 是标量损失权重，CE(·) 是交叉熵损失。

通过将控制任务与状态预测任务耦合，鼓励模型利用零力矩上下文来改进其对参数 ω 的内部估计。

IV-C 通过状态扰动实现鲁棒轨迹生成

在闭环中，微小的预测误差会随时间复合，将系统驱动到训练分布之外 [33]。虽然 DAgger [34, 35] 等方法通过在修正的探索轨迹上微调来解决此问题，但我们使用一种无需在初始阶段之外进行额外训练的替代方法。

在专家展开的稳定阶段（精确动作至关重要），我们使用带有加性高斯扰动的系统：
x_{k+1} = Φ_ω(x_k + ϵ_k, κ_ω(x_k + ϵ_k), δ_t)，ϵ_k ∼ 𝒩(0, σ²I)，
迫使 κ_ω 在稳定点附近产生修正力矩。在这些轨迹上训练使 π_γ 具备闭环恢复行为，防止推理期间的误差复合，并缓解目标附近信号幅度消失带来的数值问题。

V 实验评估

我们在欠驱动车摆和 acrobot 基准系统上评估所提出的上下文控制框架。

V-A 模型架构、训练和推理协议

每个模型由 12 层、8 个注意力头、256 维嵌入空间和 RoPE 组成。

训练：我们使用 AdamW 优化 (1)，学习率为 10^{-4}，权重衰减为 10^{-2}，批量大小为 64，子轨迹长度 L=120，来自 𝒯，如第 III-B 节所述。

推理：在推理开始时，模型最初接收上下文 H_{0:k-1} = {(x_i, e_i, c_i, u_i=0)}{i=0}^{k-1} 和查询 x_k 作为提示，并预测 (\hat{x}{k+1}, \hat{c}k, \hat{u}_k)。预测的动作 \hat{u}_k 在动态中执行以产生 x{k+1}，上下文通过追加 (x_k, e_k, \hat{c}k, \hat{u}_k) 并通过滑动窗口丢弃最旧的条目更新为 H{1:k} = {(x_i, e_i, c_i, u_i)}{i=1}^k，如图 1 所示。此过程以上下文 H{1:k} 和查询 x_{k+1} 作为新提示重复。重复这些步骤直到轨迹达到所需长度。

V-B LSTM 基线

为了测试稳定成功是否特定于 Transformer 的 ICL 能力而非任何序列模型的通用益处，我们训练了一个 LSTM 基线（3 层，隐藏大小 1024），具有相同的多头结构、训练数据和损失函数。为了公平比较，其隐藏状态由第 V-A 节中概述的相同滑动上下文窗口构建。

V-C 车摆系统

车摆系统需要通过水平小车力将摆杆摆起并保持直立 [13]。

V-C1 系统动态

状态为 x = [p, ṗ, θ, θ̇]^⊤，其中 p 是小车位置，θ 是摆杆角度，直立平衡点为 x = [0, 0, 0, 0]^⊤。动力系统由物理参数 ω = [M, m, l] ∈ Ω_cart 支配，其中 M 是小车质量，m 是摆杆质量，l 是摆杆长度：

p̈ = [(u + mlθ̇² sin θ) − (mlθ̈ cos θ)] / (M + m) (2)

θ̈ = [g sin θ + cos θ((−u − mlθ̇² sin θ)/(M + m))] / [l(4/3 − m cos²θ/(M + m))]

V-C2 参数化专家控制器（κ_{ω_i}）

对于每个 ω_i，我们合成混合专家控制器 κ_{ω_i}：
(1) 能量整形摆起：将机械能量 E(x; ω_i) = ½ml²θ̇² + mgl cos(θ) 泵向直立目标 E^d = mgl，施加力矩 u = −kθ̇(E − E^d)（k > 0）[36]。
(2) 线性二次型调节器（LQR）：在直立附近，切换到 LQR 力矩 u = −K(ω_i)x，其中增益矩阵 K(ω_i) 求解线性化动态的代数黎卡提方程。

V-C3 数据生成

轨迹 τ^{(i)}{κ{ω_i}} ∈ 𝒯 使用来自均匀分布 𝒰(Ω_cart) 的参数实现 ω_i 展开，其中 Ω_cart 在表 I 中定义。初始条件采样 p_0 = 0，ṗ_0 = 0，θ_0 ∼ 𝒰(π/2, 3π/2)，θ̇ ∼ 𝒰(−1, 1)。如第 III-B 节所述，轨迹 τ^{(i)}{κ{ω_i}} 通过强制 N = 50 步零力矩演化后跟专家响应构建，δ_t = 0.025。为了处理角度周期性，状态增广为 x̃ = [p, ṗ, cos(θ), sin(θ), θ̇]。最后，我们在 LQR 阶段采用第 IV-C 节详述的高斯扰动方法，并过滤掉稳定失败的轨迹。

V-C4 主要结果

图 2：车摆的稳定成功率与上下文长度（N）的关系。左/中：早期和晚期训练检查点的 Transformer。右：匹配晚期检查点的 LSTM 基线。虚线表示标称基线性能。Transformer 更好利用长上下文的能力在检查点 之间涌现，而 LSTM (c) 在短上下文下优于晚期检查点 Transformer (b)，但在 N=50 时在分布内和 OOD-简单系统上被超越。

我们在早期（5k 步，320k 训练轨迹）和晚期（10k 步，640k 训练轨迹）Transformer 检查点上展示稳定性能，在来自三个分布的 100 个随机采样系统上进行评估（表 I）。OOD-简单具有较低的惯性（更轻、更短），使其比 OOD-困难（更高惯性）更容易稳定。

稳定判据：在展开的最后阶段 |θ| ≤ 0.1 rad 且 |θ̇| ≤ 0.3 rad/s（由于欠驱动，p 收敛较慢）。

我们与使用平均分布内参数 ω_avg = [2.5, 1.5, 1.8] 的标称基线 κ_{ω_avg} 进行比较，并报告稳定系统的比例。

比较图 2(a) 和 (b)，分布内和 OOD-简单的成功率通常随上下文增加而提高，直到上下文 25，晚期检查点 Transformer 在上下文 50 处表现更佳。我们还看到，在两个 Transformer 训练点上，OOD-简单性能在较长上下文下超过分布内性能，因为在高惯性系统上的训练可以迁移到更容易的低惯性系统。

在所有数据机制的上下文 1 处，早期检查点没有稳定任何系统，而晚期检查点实现了非零成功。由于一个数据点无法辨识三个未知数（ω = [M, m, l]），这表明晚期检查点记忆了默认行为而非执行辨识。晚期检查点也优于标称基线（78% 分布内，0% OOD-简单，20% OOD-困难），并且是唯一能够有意义地稳定 OOD-困难系统的检查点，表明这种能力同样受益于延长训练。这需要在未来的工作中探索。

特别是对于 OOD-困难系统，成功率在最长的上下文（50）处下降，这与 ICL 文献一致，表明额外的上下文可能引入误导模型的虚假相关性 [37]，这种效应可能被放大，因为 OOD-困难系统更难稳定。

我们将晚期检查点 Transformer 与相同训练的 LSTM 基线（图 2(c)）进行比较。在上下文 1 处，LSTM 在分布内和 OOD-简单系统上显著优于 Transformer，反映出更强的记忆默认策略而非优越的上下文利用。这种优势随上下文缩小并逆转，到上下文 50 时，Transformer 在分布内和 OOD-简单系统上均优于 LSTM，而 LSTM 在辨识最困难的 OOD-困难系统上保持更好的性能。

V-D Acrobot 系统

Acrobot 是仅在肘关节驱动的双连杆平面机器人，是摆起和平衡方面更具挑战性的基准 [36]。

V-D1 系统动态

状态为 x = [θ_1, θ_2, θ̇_1, θ̇_2]^⊤，其中 θ_1 是第一连杆角度，θ_2 是第二连杆相对于第一连杆的角度，直立平衡点为 x = [π, 0, 0, 0]^⊤。物理参数向量 ω = [m_1, m_2, l_1, l_2] 表示连杆质量 m_1、m_2 和连杆长度 l_1、l_2。运动方程表示为：

M(q, ω)q̈ + C(q, q̇, ω)q̇ = G(q, ω) + Bu, (3)

其中 q = [θ_1, θ_2]^⊤，矩阵 M、C、G 遵循标准机械臂符号 [36]。

V-D2 参数化专家控制器（κ_{ω_i}）

对于每个实现 ω_i，我们合成具有滞环切换逻辑以防止抖振的混合专家控制器 κ_{ω_i}：
(1) 部分反馈线性化摆起：u = d̄_22 v_2 + h̄_2 + φ̄_2，其中 d̄_22、h̄_2、φ̄_2 是从动态导出的降阶项，v_2 = taper(θ_1^d, θ_1)[k_p(E)(θ_2^d − θ_2) − k_d(E)θ̇_2] 是能量整形信号 [38]。
(2) LQR：在直立附近，切换到 LQR 力矩 u* = −K(ω_i)(x − x_goal)。

V-D3 数据生成

轨迹 τ^{(i)}{κ{ω_i}} ∈ 𝒯 使用如表 III 所示有界的采样实现 ω_i ∼ 𝒰(Ω_acro) 展开。初始条件采样 θ_1 ∈ 𝒰(−π/2, −π/4) ∪ 𝒰(π/4, π/2)，θ_2 = 0，θ̇1 ∼ 𝒰(−1, 1) rad/s，θ̇_2 = 0。轨迹 τ^{(i)}{κ_{ω_i}} 通过在专家（κ_{ω_i}）响应之前强制 N = 100 步零力矩演化构建，δ_t = 0.02。为适应角度周期性，状态增广为 x = [cos(θ_1), sin(θ_1), cos(θ_2), sin(θ_2), θ̇_1, θ̇_2]。我们还在 LQR 阶段应用高斯扰动，解决第 IV-C 节中提到的问题。未稳定的轨迹被过滤掉（由于系统复杂性，约 33% 的轨迹）。

图 5：acrobot 摆起展开比较的一个示例：专家 κ_ω（浅蓝色）与给定 N=50 上下文步骤的 Transformer（红色）。角度 θ_1 收敛到 −5π ≡ π rad 直立。

我们在 50 个分布内和 50 个 OOD 随机采样的测试系统上评估性能（表 III）。

稳定判据：鉴于 acrobot 的复杂性，如果状态进入并在直立平衡的固定邻域（|θ_1| < 0.2 rad 且 |θ_2| < 0.3 rad）内保持至少 3 秒，则系统被视为稳定，表明模型可以摆起并切换到 LQR 稳定，即使是短暂的。

我们与使用平均分布内参数 ω_avg = [l_1=0.75, l_2=1.25, m_1=1.75, m_2=1.25] 的标称基线 κ_{ω_avg} 进行比较，该基线仅稳定 26% 的分布内系统和 1% 的 OOD 系统。

图 4(a) 表明，早期检查点 Transformer（25k 训练步，160 万训练轨迹）在 N=1 时不稳定任何系统，但改进至上下文 25，确认了上下文驱动的适应而非记忆。图 4(b) 所示的晚期检查点（300k 训练步，2050 万训练轨迹）实现了强分布内稳定，并越来越多地利用上下文处理 OOD 系统，超过标称基线。上下文 1 的非零稳定成功表明记忆，这似乎有助于 OOD 稳定。

比较图 4(c) 中的晚期检查点 Transformer 与 LSTM，LSTM 在超过 N=1 的每个上下文长度上匹配或超过 Transformer 的分布内性能。因此，在这些示例中，Transformer 模型的上下文学习能力并未优于 LSTM 行为。然而，在 OOD 系统上，模式类似于车摆的 OOD-简单：LSTM 在短上下文下性能更好，但 Transformer 在较长上下文 N=50 下表现更好（0.22 对 0.14）。结合车摆 OOD-困难的结果（LSTM 即使在长上下文下也保持优势），这表明 Transformer 相对于 LSTM 的上下文驱动优势并不均匀，但也许 Transformer 在不熟悉的机制中执行具有优势。

图 5 展示了在 N=50 上下文样本下 Transformer 展开与参考专家控制器 κ_ω 对比的一个示例。Transformer 成功完成摆起机动，θ_1 → −5π ≡ π rad 收敛，并应用 LQR 修正动作以保持直立稳定。

局限性：我们的框架需要每个训练实现的专家控制器 κ_ω。这对于车摆和 acrobot 是可行的，因为摆起/LQR 专家由 ω 参数化，但可能无法推广到缺乏解析专家的系统。

VI 结论

我们研究了 Transformer 模型在欠驱动非线性动力系统低层稳定控制中的 ICL 能力。给定零力矩状态-动作观测的上下文，Transformer 可以相应地调整其控制律。我们发现，在没有驱动扰动的系统数据上无法成功训练。然而，在具有加性高斯噪声的系统轨迹上训练，使模型能够学习稳定所需的修正动作，而这些动作在"干净"的专家轨迹中是缺失的。此外，我们表明，一旦 Transformer 开始记忆训练数据并在没有上下文样本的情况下稳定系统，即使对于 OOD 系统，ICL 能力似乎也会涌现。在车摆和 acrobot 基准上评估，Transformer 始终优于朴素的标称基线，但与 LSTM 基线性能相似。
