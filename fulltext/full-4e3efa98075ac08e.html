摘要

我们提出了一种可证明无失真的语义水印算法，该算法仅需对生成模型的黑盒采样访问权限以及对语义嵌入的黑盒访问权限。如果一个水印在对其秘密检测密钥取平均后不改变生成器的输出分布，则称其为无失真的；这提供了一个形式化保证，即水印不会降低输出质量。传统的此类水印通常对变换很脆弱。这对于图像尤其成问题，因为压缩、裁剪或调整大小等良性操作会实质性地改变整个像素表示。为此，语义水印引入了水印检测应对保持内容的变换具有鲁棒性的要求。以往结合这些属性的方法严重依赖于底层模型特定的白盒属性：要么依赖于自回归文本生成，要么依赖于扩散模型特定的访问权限，例如对初始噪声的控制或扩散逆过程。相比之下，我们的构造是完全通用的：它仅通过样本和查询访问与生成模型和语义嵌入（一个定义了检测应在其下保持鲁棒的"保持内容"概念的函数）进行交互。然后我们将此框架实例化用于图像生成。我们刻画了语义嵌入所需的两个相互竞争的属性：它应在保持图像内容的变换下保持稳定，但应能区分来自同一提示的独立生成结果。我们直接针对这种权衡训练了一个图像编码器。由此产生的编码器在保持稳定性的同时，比现成的替代方案实现了更好的分离效果，并在对各种变换保持鲁棒性的同时实现了强大的聚合检测。我们在开源和闭源模型上展示了我们水印方案的有效性，这只有通过限制为黑盒访问才成为可能。

1 引言

生成模型可以产生大量难以确定原始来源的文本和图像。水印技术通过嵌入一个稍后可使用秘密密钥检测到的信号来解决这一问题。这样的信号可用于可靠地将内容归属于特定模型或服务。

水印不应明显降低模型的输出质量。Christ 等人 (2024) 引入了一个理论框架，通过密码学不可检测性的概念来保证质量的保持：在没有（秘密）水印检测密钥的情况下，任何高效的观察者都不应能够区分带水印的输出和普通模型输出；特别是，任何基准测试都不应显示出任何退化。

上述概念的一个较弱变体是无失真性，在此概念下，对秘密密钥取平均的（单个）带水印输出的边际分布与原始输出分布相同。这种方法随后被实际系统所采用。DeepMind 引入了 SynthID-Text 的可配置无失真版本，并将其部署在 Gemini 中 (Dathathri et al., 2024)。Anthropic 后来为 Claude 采用了 SynthID-Text 的一个版本 (Anthropic, 2026)。

由此产生的部署说明了无失真水印的一个重要优势：质量保持保证避免了对每个基准测试或提示类别的重新评估。

然而，分布保持并不能保证水印的另一个理想属性：对编辑的鲁棒性。水印可能在原始输出中可检测到，但在输出被稍微修改后消失。

编辑问题与图像高度相关。即使是 JPEG 压缩、裁剪、调整大小或应用滤镜等平凡操作，也可以实质性地改变图像的整个像素表示。因此，直接与该像素表示绑定的水印可能会消失，即使图像的内容保持不变。

这激发了语义水印的研究，其中检测应对保持图像所表示内容的变换具有鲁棒性。对模型输出的语义含义进行水印处理，也可以说对水印移除尝试具有更强的鲁棒性。通常，输出的某些语义成分是在提示中请求的，但其中一些是模型在生成过程中随机选择的。只看到输出的对手不知道哪些语义成分是提示固有的，哪些不是，因此他们应该无法在不大幅降低输出预期含义的情况下移除模型的语义选择。这与句法攻击（如各种释义）形成鲜明对比，后者完全改变句法而不损害输出的预期含义。

现有的语义水印方法通常依赖于底层生成过程特定的"白盒"属性。对于文本，这限制较少，因为许多模型共享自回归的逐词元接口。另一方面，图像水印通常需要对特定扩散潜空间或噪声分布的控制，以及特定于模型的逆过程。这种访问在闭源图像生成 API 中不可用，并且生成架构的任何变化都可能使水印方案不适用。

我们引入了第一个同时具备无失真、语义鲁棒且仅使用黑盒访问（针对生成模型和语义嵌入）的水印框架，使其适用于一般生成模型。我们仅将生成模型作为一个返回独立样本的预言机来访问，仅将语义嵌入作为一个将完成的输出映射到向量的预言机来访问，而不假设任何一个预言机是如何实现的。

我们的算法采样多个候选输出，根据它们的语义嵌入将它们映射到语义码，并使用秘密密钥函数选择一个。通过统计接收每个码的候选数量，我们确保在对密钥和算法的随机性取平均时，所选输出具有与生成器原始边际分布完全相同的分布。这对每个生成器和语义嵌入都成立。如果编辑保持了语义表示，水印很可能会存活（附录 F）。

我们对任意两个预言机证明了这些保证，而不需要特定的嵌入架构或模型架构。这种通用性是有代价的：单输出检测具有不可忽略的假阳性率和有限的真阳性率。这一限制是黑盒输出选择固有的：在 N 个独立候选中进行选择给出的单输出检测率满足 TPR ≤ N·FPR（附录 K.1）。因此，我们关注可以将多个输出归属于同一来源的场景，例如由一个社交媒体账户上传的图像或由一个学生提交的作业。在这批输出上聚合水印检测分数可以实现高置信度检测。

为了将我们的框架应用于图像，我们需要一个语义嵌入，它能区分从同一提示生成的不同图像，同时在保持图像内容的编辑下保持稳定。标准语义编码器可能会故意将来自同一提示的这种独立生成视为相似，因为它们描绘了相同的高级概念。然而，对于水印，我们需要观察生成输出之间的变化，这种变化在编辑后仍然可以区分。否则，选择一个输出而不是另一个就不能引入可检测的语义水印。这要求生成内容本身的含义中存在随机性，而不仅仅是其像素表示中的随机性；我们称之为语义熵，并根据该熵推导出算法检测概率的下界。

我们专门训练了一个图像编码器来区分由同一模型使用不同随机种子从同一提示生成的输出，同时保持每个图像与其编辑版本接近。我们将由此产生的编码器与现有的图像嵌入进行比较，评估其在保持内容变换下的稳定性及其在多个图像生成模型中区分独立生成的能力。

我们评估了单张图像和批次的检测、对常见变换的鲁棒性、图像质量和同提示多样性。使用 32 个候选，我们获得了单张图像 0.920 的 AUROC 和十张图像 1.000 的 AUROC。即使重用固定密钥，我们的方法在被评估的方法中相对于无水印生成实现了最低的 FID，同时保持基本相同的 Vendi 多样性。我们还将我们的框架应用于 OpenAI 的闭源 GPT Image API，仅使用采样访问，对于每输出八个候选的五张图像批次获得了 0.978 的 AUROC。

因此，我们的主要贡献是：

  1. 我们为一般生成模型提供了一个黑盒、无失真的语义水印框架，仅需对生成器的采样访问和语义嵌入预言机。
  2. 我们刻画了语义编码器如何影响检测。我们使用语义熵来量化编码器区分来自同一提示的独立生成的能力，并证明了随语义熵增加的真阳性率下界。
  3. 对于扩散图像生成，我们训练了一个编码器，并评估了图像质量、同提示多样性、检测和对保持内容变换的鲁棒性。

2 相关工作

早期的语言模型水印在自回归生成过程中嵌入统计信号。Kirchenbauer 等人 (2023) 在解码过程中提升了一个密钥选择的词元子集。后来的工作加强了分布保证：Christ 等人 (2024) 形式化了密码学不可检测性，Vaikuntanathan & Zamir (2026) 引入了精确保持输出分布的束采样，Kuditipudi 等人 (2024) 使用了基于 Gumbel 的采样，Bahri & Wieting (2026) 仅使用采样的文本获得了无失真水印，并观察到候选之间的共享含义可能会削弱水印。MUSE 从黑盒表格生成器的样本中进行选择，但不是无失真的 (Fang et al., 2026)。

保持输出分布并不能确保对编辑的鲁棒性。鲁棒的文本方案可以承受替换和释义，包括基于伪随机纠错码的构造 (Kuditipudi et al., 2024; Christ & Gunn, 2024)。语义方法使信号依赖于含义：SemStamp 使用局部敏感哈希，k-SemStamp 使用聚类，PMark 考虑多个信道约束 (Hou et al., 2024a; Hou et al., 2024b; Huo et al., 2026)。这些方法利用自回归决策；我们的方法对输出评分，在独立生成之间聚合证据。

图像水印在很大程度上依赖于扩散模型内部机制。Tree-Ring 在初始噪声中插入傅里叶模式，而 Gaussian Shading 将水印信息映射到高斯潜变量 (Wen et al., 2023; Yang et al., 2024b)。Gunn 等人的图像构造使用伪随机纠错码实现多查询不可检测性，并区分 Gaussian Shading 的单图像保证与固定密钥重用（他们报告了同提示多样性的降低）(Gunn et al., 2025)。T2SMark 添加每生成随机性以放宽固定码字限制 (Yang et al., 2025)。这些方法需要对初始噪声的访问（这通常在图像生成 API 中不可用）以及用于检测的扩散逆过程。NoisePrints 避免了逆过程但需要生成种子 (Goren et al., 2026)。我们则是在完成的输出中进行选择。

图像也使语义水印的动机变得清晰：水印应在保持内容的像素级变化中存活，但不应在内容本身的变化中存活。重提示攻击通过生成保留原始水印的不同内容来暴露后一种风险 (Müller et al., 2025)。SEAL 在初始噪声中编码从标题导出的信息 (Arabi et al., 2025)，尽管标题可能省略外观或构图。SemBind 学习与提示一致的码 (Zhang et al., 2026)，而 SLICE 分离语义因子 (Gao et al., 2026)。我们则使用在保持内容编辑下保持稳定但能区分独立同提示生成的直接图像表示，而不修改或逆转生成。

3 预备知识

在本节中，我们介绍我们方法使用的符号，额外的形式化定义和讨论在附录 A 中提供。

设 G: 𝒫 × 𝒮 → 𝒳 为条件生成器，其中 p ∈ 𝒫 是提示，s ∈ 𝒮 = {0,1}^k 是种子，𝒳 是输出空间。对于固定提示，我们记 X = G(p, S)，其中 S ~ Unif(𝒮)，分布为 P_G(·|p)。语义编码器 E: 𝒳 → ℝ^d 将输出映射到语义表示。对于非零表示，令

z(x) = E(x)/‖E(x)‖₂, d_E(x, x′) = 1 − ⟨z(x), z(x′)⟩.

我们使用 M 位随机超平面局部敏感哈希 H_ℛ: ℝ^d → 𝒞，其中 𝒞 = {0,1}^M，它将表示空间划分为由二进制码标识的区域。这里，ℛ 表示采样的超平面法向量。二进制表示还提供了哈希区域之间的自然邻近概念：对于 c, c′ ∈ 𝒞，汉明距离 d_H(c, c′) 是它们不同的位数。参数 r_ham 表示检测期间考虑的边界不确定位的最大数量（第 5 节）。对于密钥 κ ∈ 𝒦，其中 𝒦 是秘密密钥空间，密钥化伪随机函数 F_κ: 𝒞 → [0,1] 为每个哈希码分配一个秘密分数。

4 用于无失真水印的语义编码器

无失真性施加了固有的熵要求。如果一个提示确定性地产生一个输出，任何无失真方案都必须返回它，使得带水印和不带水印的输出不可区分。更一般地，Christ、Gunn 和 Zamir 表明，无失真水印的检测能力必然与生成熵相关 (Christ et al., 2024)。

语义鲁棒性产生了更强的限制：生成器可能具有高输出熵，但产生在所选语义下等价的输出。例如，从稍微不同的视点观看的同一场景。鲁棒的语义表示应将它们映射到一个语义区域，不留下任何可以引入可检测信号的变化。因此，我们要求从同一模型和提示采样的输出的语义表示中有足够的变化。我们将这种变化称为语义熵。下面的定义在选定的语义分辨率下量化了这种变化。

语义嵌入决定了检测能力和鲁棒性。检测能力随生成输出的语义熵增长（定理 4），鲁棒性取决于编辑是否使图像在语义空间中保持接近其原始表示（附录 F）。我们的框架不特定于图像或特定的嵌入架构。然而，对于我们的图像实例化，嵌入必须满足两个互补要求：图像及其保持内容的变换应在嵌入空间中保持接近，而独立的同提示生成应保持可区分。

黑盒编码器访问还允许用户定制什么算作保持内容的变换。例如，基于布局的表示可能有利于对风格变化的鲁棒性，而基于风格的表示可能有利于对空间变换的鲁棒性。附录 J.4 在三种风格编辑和三种空间变换中展示了这些对比行为，而不改变水印算法。

然而，所选的表示还必须区分独立的同提示生成。大多数语义编码器旨在分离与不同概念或提示相关联的图像，而不是同一提示的不同生成。然而，即使提示保持固定，更改随机种子也可以实质性地改变内容和构图 (Xu et al., 2025)。因此，我们训练编码器来捕获这些实例级差异。

附录 G 中的图 3 和图 4 说明了表示要求和训练对：一个图像的变换应保持其表示，而独立的同提示生成可以接收不同的表示。现有表示没有针对这两个要求进行显式优化：CLIP 强调图像-文本对齐，DINOv2 强调增强视图间的不变性，TPIPS 强调感知相似性。因此，我们使用对比目标微调 DINOv2，该目标将保持内容的变换视为正样本，将来自同一提示的不同种子生成视为负样本。附录 G 提供了架构和训练细节。

与将每个不同图像视为不同结果的精确输出熵不同，语义熵衡量独立同提示生成在编码器空间中的多样性。对于固定的语义半径 ε，当两个独立生成不太可能彼此距离在 ε 以内时，语义熵很高。

定义 1（语义熵）。固定 ε ∈ [0,2]，令 X, X′ i.i.d.~ P_G(·|p) 为提示 p 的两个独立生成。我们定义

H_sem^{E,ε}(G|p) = −log Pr_{X,X′}[d_E(X, X′) ≤ ε].

ε 的选择决定了什么算作有意义的差异。如果 ε 非常小，语义熵可能很高，仅仅因为两个生成很少几乎相同，即使它们在语义上仍然非常相似。较大的 ε 给出了更强的测试：高语义熵则意味着独立生成即使在有意义的语义半径下也保持分离。

因为枚举所有种子是不切实际的，给定提示 p，我们从 n 个独立样本 X₁, …, Xₙ ~ P_G(·|p) 估计语义熵，并报告 Ĥ_sem^{E,ε}。我们通过对距离最多为 ε 的对的比例来估计对数内的概率：

P̂ε = (n choose 2)^{-1} Σ{1≤i<j≤n} 1{d_E(Xᵢ, Xⱼ) ≤ ε}, Ĥ_sem^{E,ε} = −log P̂_ε.

附录 H 报告了估计语义熵如何随 ε 变化。在评估的语义半径 0.3 ≤ ε ≤ 1 中，我们的编码器在每个测试的生成器中都在被评估的编码器中实现了最高的估计语义熵。

语义熵捕获了可用于水印的表示级可变性。下一节展示它如何在保持生成器输出分布的同时产生可检测的信号。

5 方法

我们通过选择返回黑盒生成器的哪些输出来对其进行水印。给定一个提示，我们独立采样 N 个候选图像，使用语义编码器 E 嵌入每个图像，并使用固定的 LSH 函数 H_ℛ 将其归一化嵌入 z(x) 映射到语义区域 c = H_ℛ(z(x))。对于选定的码长 M，我们的方案一次性采样 M 个独立的均匀单位超平面法向量 ℛ，独立于秘密密钥，并在生成和检测中重用得到的 H_ℛ。我们为每个语义区域分配一个伪随机分数 F_κ(c)，由我们在生成之间和检测期间重用的秘密密钥 κ 确定。然后我们使用这些分数来选择输出图像。通过将相同的分数分配给同一语义区域中的图像，我们旨在使水印对非语义变换具有鲁棒性。特别是，当变换保持图像的语义区域时，它也保持其分数，从而保持检测器的决策。

伪随机评分函数允许我们构造无失真的选择规则。当所有 N 个候选属于不同的语义区域时，在理想 PRF 假设（假设 17）下，每个区域在随机秘密密钥下接收最高分数的概率相等。因此，选择得分最高的候选给每个候选 1/N 的概率。正如我们在附录 C 中证明的，这种均匀选择特性足以保证在对秘密密钥取平均后的无失真性。然而，多个候选可能共享同一语义区域，破坏了这个简单的论证。我们首先用代表采样（算法 3）解决这个问题，这是一个受束采样启发的直观构造，它从每个语义区域均匀地选择一个代表，并通过额外的随机选择步骤补偿剩余的候选。我们在附录 B 中描述完整的构造。

代表采样不是唯一的无失真选择规则。因此，我们在附录 J.3 中比较了几种采样规则，发现基于 Gumbel 的选择 (Kuditipudi et al., 2024) 在我们评估的方法中实现了最强的经验检测性能。因此，我们在最终生成算法中用基于 Gumbel 的采样器替换了代表采样。算法 1 和图 1 说明了这个过程，附录 C 证明了两种采样规则的无失真性。

6 理论保证

我们现在建立我们水印方案的理论保证。首先，我们证明在对秘密密钥取平均后，我们的生成算法对任何黑盒生成模型和语义编码器都是无失真的。其次，我们建立检测器的假阳性率，并证明足够高的语义熵保证在适当选择参数的情况下有强检测。最后，我们为批次检测和对近似保持语义表示的变换的鲁棒性建立保证。

定理 3（无失真生成）。 设 G 是任何条件生成模型，E 是算法 1 定义良好的任何编码器。在理想 PRF 假设（假设 17）下，算法 1 定义的带水印生成器是无失真的（定义 10）：对于每个提示 p，

𝔼_{K~Unif(𝒦)}[P_{G_K^wm}(·|p)] = P_G(·|p).

我们在附录 C 中证明定理 3。这确保了无论输出的语义分布如何，当我们对密钥的随机选择取平均时，水印生成器的输出也按照原始模型的分布分布。

我们接下来建立我们水印方案检测优势的下界，并分析它如何取决于生成器 G 和编码器 E 对给定提示 p 的语义熵，以及三个可配置参数：

  • 候选数量 N：每个带水印输出的黑盒生成器调用次数。较大的 N 增加潜在检测优势，生成成本与 N 线性增长。
  • 哈希位数 M：增加 M 减少哈希碰撞，改善检测界限但可能降低鲁棒性，因为语义表示的小变化更可能改变哈希码。
  • 检测阈值 τ：控制假阳性率和真阳性率之间的权衡。

该保证还取决于第 4 节中定义的语义熵 H_sem^{E,ε}(G|p)。更高的语义熵加强我们的检测保证。

定理 4（语义熵和检测）。 固定提示 p 和语义半径 ε ∈ [0,2]。生成 N ≥ 2 个独立候选并应用算法 1。在理想 PRF 假设下，对于单图像检测，阈值 τ ∈ [0,1] 处的精确码检测器（算法 2）满足

FPR(τ) = 1 − τ

和

TPR^{(N)}(τ) ≥ 1 − τ + (1 − q_{M,ε}(p))/(1 + (N−1)q_{M,ε}(p)) · (τ − τ^N),

其中

q_{M,ε}(p) = e^{−H_sem^{E,ε}(G|p)} + (1 − e^{−H_sem^{E,ε}(G|p)})(1 − arccos(1−ε)/π)^M.

两个速率都对固定提示 p 的秘密密钥和随机超平面取平均。

定理 4 表明，更高的语义熵在不增加假阳性率的情况下加强了保证的检测优势。因此，对于适当选择的参数，足够高的语义熵保证了带水印和不带水印输出之间的实质性分离。这些保证对秘密密钥和随机超平面取平均。我们在附录 D 中提供证明。

最后，我们在附录 E 中证明，如果独立生成的输出的预期干净分数和带水印分数位于固定密钥阈值的相反两侧，则批次检测将两种错误概率随独立生成输出数量呈指数级降低。在附录 F 中，我们建立保持语义相似的变换很可能保持哈希码，从而保持水印分数。

7.3 语义表示分析

我们的水印方法依赖于具有两个互补属性的语义表示：保持内容的变换应产生相似的表示，而独立生成应保持可区分。我们分析学习的编码器是否满足这些属性、其在生成器之间的迁移以及其几何与水印保留率的关系。

9 局限性和未来工作

我们的方法有三个主要局限性，每个都指向未来的工作：

  • 单图像检测。 我们当前的图像实现提供了比直接修改扩散过程的方法更弱的干净单图像检测（表 2）。当每张图像必须独立检测且内部模型访问可用时，这种权衡最重要。我们的方法优先考虑黑盒适用性、语义绑定和分布保持，而聚合显著加强了检测（表 2）。更一般地，任何选择 N 个独立、未修改生成器输出之一的方法对单图像检测满足 TPR ≤ N·FPR（附录 K.1 中的定理 23）。因此，在指数级小的 FPR 下实现恒定 TPR 需要指数级多的生成器查询。这个 O(N) 上限属于黑盒采样，而不是我们的构造。
  • 语义编码器。 更好的语义编码器可以在此限制内改善检测并加强鲁棒性。它必须保持保持内容的变换接近，同时分离独立生成；我们的编码器在被评估的替代方案中改善了这种平衡（附录 J.2）。
  • 计算成本。 我们最强的配置为每张发布图像生成 32 个完整候选，这对于大规模或延迟敏感的应用可能不切实际。早期选择方法可以通过使用中间去噪器激活来预测质量或在去噪步骤中重用低分辨率语义特征来降低此成本 (Guo et al., 2026; Habibian et al., 2024; Parmar et al., 2026)。如果这些信号预测最终语义码，无前景的候选可以提前丢弃。

我们在附录 K 中详细讨论这些局限性以及进一步的开放问题。

10 结论

我们引入了一个黑盒、无失真的语义水印框架，仅需对生成器的采样访问和对语义编码器的查询访问。我们的分析将可检测性与语义熵联系起来，而实验展示了聚合检测和对常见变换的鲁棒性，而不影响生成质量或多样性。这些结果将语义拒绝采样确立为生成水印的通用黑盒基础。更强的编码器和更高效的采样仍然是未来工作的方向。

A.1 生成模型和采样

定义 5（条件生成模型）。 设 𝒫 是所有可能提示的集合，𝒮 = {0,1}^k 是所有可能种子的集合，𝒳 是输出空间。条件生成模型是映射 G: 𝒫 × 𝒮 → 𝒳。

我们将 𝒮 建模为有限的种子集合，如实际实现中的情况，而提示空间 𝒫 可以是无限的。对于任何固定提示 p ∈ 𝒫 和种子 s ∈ 𝒮，输出 G(p, s) 是确定性的。

定义 6（来自条件生成模型的 i.i.d. 样本）。 固定提示 p ∈ 𝒫。令 S₁, …, Sₙ i.i.d.~ Unif(𝒮)，Xᵢ = G(p, Sᵢ)。(X₁, …, Xₙ) 的任何实现 (x₁, …, xₙ) 被称为 G 在提示 p 条件下的 i.i.d. 样本。

定义 7（编码器和语义编码器）。 设 𝒵 = ℝ^d 是 d 维表示空间。编码器是映射 E: 𝒳 → 𝒵。对于 x ∈ 𝒳，我们称 E(x) 为 x 的表示。如果 E 的表示捕获输出的语义内容，我们称 E 为语义编码器。我们框架中语义编码器所需的精确属性在第 4 节中介绍。

A.2 生成模型水印

定义 8（密钥化水印方案）。 设 G 是条件生成模型，𝒦 是有限密钥空间。G 的密钥化水印方案是一对 𝖶 = (G^wm, 𝖣𝖾𝗍𝖾𝖼𝗍)，其中，对于每个密钥 κ ∈ 𝒦：

  1. 带水印生成器是可能随机化的映射 G_κ^wm: 𝒫 × 𝒮^N → 𝒳。给定提示和 N 个种子，它产生带水印的输出。
  2. 对于每个批次大小 B ≥ 1，检测器是映射 𝖣𝖾𝗍𝖾𝖼𝗍_{κ,τ}^{(B)}: 𝒳^B → {0,1}。给定一批图像 x_{1:B} = (x₁, …, x_B) 和固定检测阈值 τ ∈ [0,1]，当批次在密钥 κ 下被检测为带水印时输出 1，否则输出 0。B = 1 的情况对应于单图像检测。

定义 9（黑盒水印方案）。 水印方案 𝖶 = (G^wm, 𝖣𝖾𝗍𝖾𝖼𝗍) 关于 G 是黑盒的，如果 G^wm 和 𝖣𝖾𝗍𝖾𝖼𝗍 只能通过评估 G(p, s) 与 G 交互，否则无法访问其内部实现。

定义 10（无失真水印）。 设 P_G(·|p) 表示 G(p, S) 的分布，其中 S ~ Unif(𝒮)。对于每个密钥 κ ∈ 𝒦，设 P_{G_κ^wm}(·|p) 表示提示 p 的带水印生成器的输出分布。水印方案是无失真的，如果对于每个提示 p ∈ 𝒫，

𝔼_{K~Unif(𝒦)}[P_{G_K^wm}(·|p)] = P_G(·|p).

这是密钥平均的、单输出的保证：它要求在均匀采样的密钥 K 上取平均后相等，但不要求对每个固定密钥。

A.3 哈希和伪随机函数

定义 11（哈希函数）。 哈希函数是映射 h: 𝒵 → 𝒞，其中 𝒞 是有限码空间。如果 h(z) = h(z′)，则两个表示 z, z′ ∈ 𝒵 在 h 下碰撞。

定义 12（局部敏感哈希族）。 设 (𝒵, d) 是度量空间。哈希函数 h: 𝒵 → 𝒞 上的分布 ℋ 是 (r, cr, p₁, p₂)-局部敏感的，如果 c > 1，p₁ > p₂，并且对于每个 z, z′ ∈ 𝒵，

d(z, z′) ≤ r ⟹ Pr_{h~ℋ}[h(z) = h(z′)] ≥ p₁,

而 d(z, z′) ≥ cr ⟹ Pr_{h~ℋ}[h(z) = h(z′)] ≤ p₂.

我们使用标准的局部敏感哈希概念 (Indyk & Motwani, 1998)。在我们的方法中，ℋ 用角度距离（等价于余弦相似性）的 M 位随机超平面 LSH 构造实例化，遵循 Charikar (2002)。

定义 13（随机超平面局部敏感哈希）。 设 ℛ = (r̄₁, …, r̄_M) 由从单位球独立且均匀采样的 M 个单位超平面法向量组成。对于归一化表示 z ∈ ℝ^d，随机超平面 LSH 是码

H_ℛ(z) = (1{⟨r̄₁, z⟩ ≥ 0}, …, 1{⟨r̄_M, z⟩ ≥ 0}) ∈ {0,1}^M.

因此，每个位指示表示位于其对应超平面的哪一侧。

定义 14（汉明距离和汉明球）。 遵循 Hamming (1950)，两个码 c, c′ ∈ {0,1}^M 之间的汉明距离是它们不同的位位置数：

d_H(c, c′) = Σ_{j=1}^M 1{cⱼ ≠ c′ⱼ}.

对于整数 r ∈ {0, …, M}，以 c 为中心的半径 r 汉明球是

ℬ_H(c, r) = {c′ ∈ {0,1}^M : d_H(c, c′) ≤ r}.

定义 15（边界限制的汉明邻域）。 对于归一化表示 z 和边界阈值 δ，令

J_δ(z) = {j ∈ [M] : |⟨r̄ⱼ, z⟩| ≤ δ}

是其对应超平面位于边界裕度内的哈希位集合。令 Flip(c, S) 表示通过翻转由 S 索引的 c 的位获得的码。对于整数 r ∈ {0, …, M}，定义

𝒩_{δ,r}(z) = {Flip(H_ℛ(z), S) : S ⊆ J_δ(z), |S| ≤ r}.

𝒩_{δ,r}(z) 中的每个码位于 H_ℛ(z) 的汉明距离 r 以内。然而，与完整的汉明球不同，此邻域只允许更改与附近超平面边界相关联的位。

我们使用伪随机函数（PRF）为每个哈希码分配秘密分数，遵循 Goldreich et al. (1986)。

定义 16（密钥化评分函数）。 设 𝒦 是密钥空间，𝒞 = {0,1}^M 是码空间。密钥化评分族是函数族 {F_κ: 𝒞 → [0,1]}_{κ∈𝒦}。对于秘密密钥 κ，值 F_κ(c) 是分配给码 c 的归一化秘密分数。

假设 17（理想 PRF 评分模型）。 令 K ~ Unif(𝒦)。对于每个不同码的集合 c₁, …, c_L，分数 F_K(c₁), …, F_K(c_L) 独立且在 [0,1] 上均匀分布。等价地，在理论分析中，F_K 被建模为从 𝒞 到 [0,1] 的均匀随机函数。特别是，不同的码接收独立的分数，分数平局以零概率发生。

实际实现可以从密码学 PRF 的有限位串输出获得归一化分数。我们理论结果中的精确等式指的是上述理想模型；安全的 PRF 提供相应的计算解释。
