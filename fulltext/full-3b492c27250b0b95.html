微软推新自研AI模型，成本较OpenAI降89%

📅 2026-07-29 📄 VentureBeat AI 🔗 原文链接

原标题：Microsoft launches new in-house AI models it says cut costs up to 89% versus OpenAI

中文摘要： 微软发布了MAI-Image-2.5-Pro和MAI-Voice-2-Flash两款自研AI模型，称其在特定任务中比OpenAI模型成本最高降低89%。这些模型已部署于Bing、Excel等产品中。CEO纳德拉提出“前沿扩散”战略，强调模型独立性，通过“爬山”策略让小模型在特定任务上媲美前沿模型。此外，微软正将内部AI工具链转化为Azure产品出售，标志着其正从依赖OpenAI转向独立的AI编排者。

周三，Microsoft AI 发布了两款新的内部模型进入公开预览阶段——迄今为止保真度最高的图像生成器 MAI-Image-2.5-Pro，以及专为高并发企业工作负载构建的语音模型 MAI-Voice-2-Flash。同时，其公布的生产数据构成了该公司迄今为止最强有力的论据，证明它可以在不依赖 OpenAI 前沿模型的情况下为自己的产品提供动力。

这项由 Microsoft AI 的超级智能团队 发布的公告，距离该公司承诺在内部构建专用模型大约已有一年时间。它对模型目前的运行环境提供了罕见的细节：Bing、PowerPoint、OneDrive、Dynamics 365、Excel、GitHub Copilot 和 Azure。向企业买家——以及隐晦地向 OpenAI——传递的信息是，微软的自研模型不再是研究项目。它们是服务于数百万用户的生产基础设施。

“每一项增强功能都是朝着同一目标迈出的一步：由微软模型驱动的微软产品，”该公司在其公告博客中写道。

MAI-Image-2.5-Pro 和 MAI-Voice-2-Flash 如何在 AI 成本曲线的两端占据一席之地

这两款新发布的模型占据了微软所谓的“质量-速度-成本”曲线的两端，这种定位是刻意为之的。MAI-Image-2.5-Pro 瞄准高端层级：主视觉图、详细编辑和精确的图内文本渲染——后者长期以来一直是图像生成模型臭名昭著的弱点。微软将该模型的定价为每百万文本输入 token 5 美元，每百万图像输入 token 8 美元，每百万图像输出 token 106 美元。基础的 MAI-Image-2.5 模型最近在 Arena 的图像编辑类别中排名第二，该社区排行榜已成为生成式媒体事实上的记分牌。

创意行业似乎也注意到了这一点。广告巨头 WPP 的全球首席创意官 Rob Reilly 在微软公告中的一份声明中称 Pro 模型是“生成式媒体工具的一次强劲飞跃”，并补充说“微软已牢牢确立了其在生成式 AI 领域的领导者地位。”

MAI-Voice-2-Flash 则走向了另一个方向。该模型最初在微软的 Build 大会 上预览，运行速度是 MAI-Voice-2 的两倍，成本低 32%，定价为每百万字符 15 美元。它是为高并发语音这一并不光鲜但庞大的市场设计的——呼叫中心、语音代理和实时语音应用，在这些场景中，延迟和单次通话成本比表现力的边际收益更重要。这两款模型共同反映了一种构建模型家族而非单一旗舰模型的策略，因为正如该公司所说，追求最大保真度的创意工作室与每天处理数百万次通话的客户服务运营有着截然不同的需求。

微软的生产指标显示，自研模型将 GPU 成本最高降低 89%

模型的发布可以说不如微软随附的部署指标更具新闻价值——这些数字读起来就像是为其在整个产品组合中替换第三方前沿模型提供的系统性案例。

Bing Image Creator 现在完全在 MAI-Image-2.5 上端到端运行，标志着这款消费者图像工具首次完全实现自研化。在 PowerPoint 中，微软表示与 OpenAI 的图像模型 GPT-Image-2 相比，MAI-Image-2.5 将 GPU 成本降低了高达 84%。在 OneDrive 中，MAI-Image-2.5 现在是关键图像编辑场景的默认模型，该公司报告称保存率提高了 26%，P95 延迟降低了约 25%，并且在中等利用率的生产工作负载下效率提高了 2.5 倍。

在语音方面，MAI-Voice-2-Flash 现在为 Dynamics 365 联系中心提供支持——该平台被包括 T-Mobile 和 EasyJet 在内的客户使用——微软声称其 GPU 成本降低了高达 89%。该模型还集成到 Azure Voice Live 中，供构建语音到语音代理的开发者使用。

也许最具影响力的部署在于医疗保健领域。微软的 Dragon Copilot 被 17 万名医疗服务提供者使用，并在上季度负责处理了 2800 万次患者就诊记录，现在该工具在涵盖 58 种语言的多语言工作流中运行于 MAI-Transcribe-1.5 上。微软表示，内部评估显示，在大多数语言中，转录和语言识别的错误率相对降低了 50%——在一个转录错误可能直接蔓延到临床记录的领域，这是一个有意义的声明。

揭秘让小模型在 Excel 中击败 GPT-5.6 的“爬山”策略

在同一天发布的一篇配套文章中，微软详细介绍了这些结果背后的方法论——它称之为“爬山机器”，这是一个由数据、模型和围绕它们的产品“套件”组成的集成飞轮。

最清晰的例子是 MAI-Code-1-Flash，这是 6 月份在 GitHub Copilot 中推出的轻量级编码模型。微软表示，在 VS Code 中，该模型的代码接受率比 GPT-5.4 Mini 和 Claude Haiku 4.5 高出约 10%，同时使用的中位数 token 减少了 10%。开发者留存率也讲述了类似的故事：用户在多天后返回的可能性比使用 GPT-5.4 Mini 高 6%，比使用 Claude Haiku 4.5 高 11%。

然后微软做了一件更有趣的事情。它提取了 MAI-Code-1-Flash 的检查点，并在 Excel 强化学习环境中对其进行了进一步训练，教授编码模型电子表格知识工作的工具和工作流。根据生产用户的反馈，其结果是一个在处理最常见的 Excel 任务时与 GPT-5.6 相当的模型——而且它足够小，可以在英伟达较旧的 H100 甚至 A100 GPU 上运行，而不需要最新一代的加速器。

这一硬件细节值得强调。每家主要的 AI 公司都在争夺尖端芯片的配额，而一个能在两代以前的硅片上提供接近前沿质量的模型，从根本上改变了部署经济学。它还解放了最新的硬件——包括微软现已投入运营的 GB200 集群——使其用于训练而不是服务。

萨提亚·纳德拉的“前沿扩散”宣言重新定义了与 OpenAI 的关系

微软首席执行官萨提亚·纳德拉在 X 上发布了一篇题为“前沿扩散与控制”的长文来为这些公告定调，其功能几乎等同于一份战略宣言。“我们现在可以通过针对高使用率产品优化的模型，以规模化且更低成本的方式，提供已饱和的前沿能力，同时继续使用前沿模型来满足前沿需求，”纳德拉写道，并补充说微软正“开始在我们的第一方平台上，每当我们的模型匹配或超越前沿替代方案时，就将流量路由到 MAI。”

从高管的话语翻译过来就是：一年前还是最先进的能力现在已成为基本门槛，微软相信它能够以低成本复制这些能力，用于主导实际产品使用的特定、重复性任务。当用户只是想重新格式化电子表格的列时，为什么要为前沿模型支付前沿价格呢？

纳德拉谨慎地指出，“来自 OpenAI 和 Anthropic 的前沿模型与 MAI 一起构成了编排系统的一部分”——但他也阐明了一项尖锐的模型独立原则，认为一家公司的评估“应该继续爬山，即使任何给定的模型被移除了。”

他认为，将套件、记忆、上下文和技能保留在模型之外，正是赋予微软控制权的原因。其中的潜台词不容忽视。路透社在 4 月份报道称，微软对 OpenAI 技术的独家许可已被修改为非独家安排，The Information 去年 9 月报道称，微软已开始将 Anthropic 模型整合到某些产品中。周三的公告完成了这个三角关系：微软作为编排者，将其合作伙伴的前沿模型作为可互换的组件，而其自己的模型则吸收了越来越大部分的常规流量。”

开发者为更便宜的特定任务模型欢呼，而怀疑者质疑微软的过往记录

网上的反应既捕捉到了该策略的吸引力，也体现了围绕它的怀疑态度。“我喜欢人们为小众任务使用小模型，”X 用户 @mavihsk 回复纳德拉的帖子时写道。“为什么我非得用全知全能的模型来更改我在 Excel 里的字段？”另一位用户 @nabu_lines 简洁地总结了这一推销：“当你停止过度使用最大的模型时，成本和性能都会提升。”

其他人对微软的执行记录则不那么宽容。“在倾听用户反馈方面，微软是最糟糕的，”设计师 @designedbyabin 写道，并认为该公司“将输掉 AI 竞赛，因为他们屡次未能理解用户需求。”而用户 @tokenoverflow 则对模型独立的推销提出了更干瘪的批评：“我希望在移除微软后它还能继续爬山。”

怀疑者提出了一个合理的观点。微软自我报告的指标——接受率、保存率、GPU 节省——来自其内部评估，而非独立基准测试，而且由该公司选择发布哪些比较结果。

但该策略的逻辑并不依赖于任何单一数字。纳德拉关于软件现在“首次有了真正的边际成本”的框架，解释了为什么微软对 token、GPU 和服务成本如此痴迷：当 AI 功能在拥有十亿用户的产品组合中的每一次击键上运行时，84% 的 GPU 成本降低不是一种优化。它是可行企业与无底洞之间的区别。

为什么微软将其内部 AI 手册转化为 Azure 产品

该策略的最后一部分是，微软正在出售这本手册，而不仅仅是模型。纳德拉明确将爬山方法定位为“每个其他 AI 原生、SaaS 或企业公司的模板”，微软正在通过 Foundry 和其所谓的 Frontier Tuning 打包该工具链——让企业针对其专有评估和强化学习环境训练专用模型。这将微软内部的削减成本练习变成了一个 Azure 产品，并为企业客户提供了一个在微软云上运行其 AI 工作负载的理由，即使模型本身来自其他地方。

该公司强调模型是“在干净、可追溯的企业级数据上训练的，没有从第三方模型中提取”，这服务于同样的商业目的。在一个面临对训练数据来源日益严格审查的行业中，微软押注企业买家——以及法院——会关心模型能力的来源。微软表示，它现在正将爬山方法扩展到 Copilot Chat、Outlook 和 PowerPoint，并且这两款新模型都可以通过 Microsoft Foundry 和 MAI Playground 进行公开预览。“这些都不是终点，”该公司写道。“我们才刚刚开始。”

七年前，微软押注超过 130 亿美元，认为 OpenAI 将构建 AI 的未来。周三的公告表明，该公司此后学到了一个更便宜的教训：AI 的未来可能属于构建前沿的人，但利润属于让它变得平凡的人。
