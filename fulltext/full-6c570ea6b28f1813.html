摘要

尽管自动驾驶技术已被广泛采用，但由于需要交互感知策略，在杂乱环境中实现可靠导航仍然十分艰巨；典型场景包括：多智能体共存的狭窄通道、密集交通中的变道以及通过无信号交叉口。这些场景通常需要高度主动的策略，同时要求可解释性和快速适应性，这对端到端和数据驱动方法构成了挑战。有效策略需要：对多智能体的可扩展性、对其他智能体行为变化的适应性，以及与周围交通的协调性，既不冻结也不过度保守。为满足这些要求，我们提出了SIGMO——一种Sigmoid门控的交互感知运动规划器，具有两项主要贡献。首先，我们提出了多项式Sigmoid函数，利用捕捉驾驶直觉的基于物理的交互特征，解析地估计周围智能体的让行分数。其次，我们将多项式Sigmoid函数集成到滚动时域规划器中，便于使用任意轨迹预测进行交互感知规划。我们在交互密集的仿真和硬件实验中验证了SIGMO。结果表明，SIGMO在保持计算轻量化的同时平衡了主动与防御行为，可作为移动技术栈中的强基线。仿真和硬件实验视频可在此处获取：

I 引言

自动驾驶车辆已从研究原型发展到商业部署，但在杂乱、交互密集的环境中实现可靠导航仍具挑战性。代表性场景包括穿越与多个智能体共享的狭窄通道、汇入密集交通以及通过无信号交叉口。在这些环境中，经典的鲁棒规划通常不够用，因为可能不存在独立"安全"的间隙供自车在不与其他智能体交互的情况下前进。相反，自车必须进行协商：主动鼓励其他智能体让行，同时在对方不让行时保持防御。过度保守的行为可能导致著名的"冻结机器人"问题[1]，而过于激进的行为则可能危及安全。因此，有效的规划器必须能够(i)扩展到多个智能体，(ii)快速适应其他智能体行为的变化，以及(iii)与周围交通保持兼容，同时提供可解释的决策。

图1：激励场景：在狭窄街道上导航，停放的车辆（黑色）迫使自车和迎面而来的智能体（蓝色）进入共享通道（红色），同时行人朝不同方向移动。不存在独立安全的间隙；自车必须判断迎面而来的智能体和行人是否可能让行，在适当时主动占据通道，否则选择退让。

大量研究工作探讨了交互感知规划。博弈论方法[2,3,4]显式建模智能体间的相互影响，但其计算复杂度可能随参与者数量快速增长，限制了可扩展性。基于学习的方法，包括端到端策略[5,6,7]和强化学习(RL)[8,9,10]，在捕捉复杂交互行为方面颇具吸引力。然而，有限的可解释性、可靠性以及对分布偏移的鲁棒性，仍然是在安全关键场景中部署的重大障碍[11,12]。结合神经交互预测器的优化规划器，如NNMPC[13,14]和IANN-MPPI[15]，提供了另一种途径，通过在滚动时域框架内显式评估其他智能体对候选自车动作的可能响应。然而，这些方法需要对预测模型（通常是循环神经网络）进行重复推理，且该模型以单个候选展开为条件。因此，其计算成本随样本数量和智能体数量而增长。此外，其学习的交互模型在训练数据所代表的行为和智能体类型之外可能泛化不佳。因此，仍然需要一种轻量且可解释的机制来估计智能体的让行意愿，无需重复的动作条件推理，也无需假设特定的预测模型。

为弥补这一差距，我们提出了SIGMO——一种Sigmoid门控的交互感知运动规划器，具有两项主要贡献。

第一，我们引入了多项式Sigmoid函数（"Polygate"），它将基于物理的特征（碰撞时间、近期加速度、相对速度、路径优先级和车身接近度）解析地映射到周围智能体让行的概率。该公式通过可解释的特征捕捉直观的驾驶行为，其参数（即拐点和锐度）具有直接的物理解释，只需最少的调参。

第二，我们将Polygate集成到基于采样的滚动时域控制框架——模型预测路径积分(MPPI)控制[16]中，其中估计的让行概率用于调制交互感知风险项。Polygate从每个候选展开的几何特征进行评估，而非从以其为条件的预测模型评估，因此避免了先前方法[13,15]所需的重复推理，并与任何预测模型的选择保持兼容。这在保持可解释决策机制的同时，实现了高效的交互感知规划。

我们在交互密集的仿真场景中评估SIGMO，包括有行人穿越的狭窄通道协商和汇入密集交通。随后，我们使用由Waymo开放数据集[18]初始化的MetaDrive[17]进行泛化性分析。我们在汇入场景中使用1/10比例的F1Tenth赛车演示SIGMO。结果表明，SIGMO在各种场景中平衡了主动协商与防御行为，同时保持了计算效率。

II POLYGATE：基于Sigmoid函数的交互评分

作为预备知识，Sigmoid函数 s(·) 基于拐点 μ 和锐度 τ 将特征 x 投影到 [0,1]：

σ(z) = 1/(1+e^(−z))，s_x(x) = σ(±(x−μ)/τ)。 (1)

Sigmoid函数的符号取决于每个特征的性质，每个特征从智能体（下标为a）相对于自车（下标为e）的视角计算；例如，相对速度特征为 Δv = v_a − v_e。

II-A 直觉驱动的Sigmoid函数

多项式Sigmoid函数的设计始于驾驶直觉。当以下情况发生时，智能体更可能向自车让行：(i)预计将发生碰撞，(ii)自车具有攻击性，(iii)自车速度更快（以间隙正在闭合的方式），以及(iv)自车更接近目标。

这些直觉从根本上基于物理，因而具有泛化性。随后分别用形式化方法定义Sigmoid函数。

II-A1 碰撞预期

碰撞时间(TTC)是估计碰撞迫近程度的有效指标——当当前机动持续时——可假设恒定机动或使用预测。

在恒定相对速度下，当 ‖Δp + tΔv‖² = r_c² 时发生接触，其中 Δp = p_a − p_e，r_c = r_ego + r_agent 为碰撞圆半径之和。

定义 α = ‖Δv‖²，β_q = 2Δp·Δv，ζ = ‖Δp‖² − r_c²。

当 α > ε 且判别式 D = β_q² − 4αζ ≥ 0 时，接触时间为：

t_{1,2} = (−β_q ∓ √D)/(2α)。 (2)

当这些条件成立且 t_2 > 0（即接触间隔尚未过去）时，碰撞时间为 TTC = clip(t_1, 0, T_max)；否则 TTC = T_max，表示视野内无碰撞。TTC Sigmoid函数为：

s_TTC(TTC) = σ((TTC − μ_TTC)/τ_TTC)， (3)

其中较大的TTC值产生较高的TTC分数，表明其他智能体并未缩小间隙，对应于较不迫近的预测碰撞。

规划器不仅可假设恒定速度，还可利用完整的自车展开轨迹 {p_{e,t}^(i)}{t=1}^T 和逐样本的智能体预测 {p{a,t}^(i,m)}_{t=1}^T（样本 i、智能体 m）。TTC通过遍历这些预测轨迹来评估：在每步 t，找到成对距离降至 r_c 以下的最早未来步 k ≥ t，并报告提前时间 (k−t)Δt：

TTC_{i,t,m} = {(k−t)Δt，若 k 存在；T_max，否则}， (4)

其中 k* = min{k ≥ t : ‖p_{a,k}^(i,m) − p_{e,k}^(i)‖ < r_c}。这自然地适应了更广泛的预测，包括非线性行为（如转弯或让行的智能体）。

II-A2 攻击性

攻击性通过近期加速度之和来表征，含义是："加速越多，预计越不可协商"；换言之，"制动越多，预计越可协商"。使用智能体记录的纵向加速度历史 {a_k}：

Σa = Σ_{k=t−K+1}^{t} a_k，K：步数。 (5)

符号约定：Σa < 0 ⇒ 窗口内持续制动；Σa > 0 ⇒ 持续加速。攻击性Sigmoid函数为：

s_Σa(Σa) = σ(−(Σa − μ_Σa)/τ_Σa)， (6)

当 Σa 较高（即强烈加速）时，得出较低的让行概率。

II-A3 相对速度

当前状态下的相对速度暗示了对目标点的优先级（当两个智能体距离相等时）。我们将相对速度投影到从自车指向智能体的向量上，翻转符号使"接近"为正，并用自车速度归一化。设接近率 c = −((v_a − v_e)·r̂)/‖v_e + ε‖，其中 r̂ 从自车指向智能体。相对速度Sigmoid函数为：

s_speed(c) = σ(−(c − μ_c)/τ_c)， (7)

当接近率 c > 0 较高（即快速接近）时，得出较低的让行概率。

II-A4 路径优先级

到目标点的距离清楚地表明了优先级（当两个智能体驶向同一点时）；这通常适用于高速公路汇入、四路交叉口等交通场景。

路径优先级（裁剪至对称范围）为：

π = clip(‖g − p_a‖ − ‖g − p_e‖, −π_max, π_max)。 (8)

该公式与相遇方式无关（适用于迎面、同向、交叉和绕行情况）。Sigmoid函数为：

s_path(π) = σ((π − μ_π)/τ_π)。 (9)

π > 0 表示自车先到达冲突点 ⇒ 自车拥有路权；这作为一个软门控，使低优先级的自车即使TTC很大也无法主张让行。

II-A5 接近度门控

我们还定义了接近度门控，当智能体紧邻自车时施加更高风险（即低让行概率）——这补充了被低估的情况，例如自车与智能体以相同方向和速度驶向汇合点；此时无论两个智能体的邻近程度如何，TTC较大且攻击性/相对速度/路径优先级均为中性。在这种情况下，接近度门控会抑制朝向自车的让行概率，以鼓励自车采取保护性行为。

我们采用椭圆车身坐标系度量[19,20]而非欧几里得距离。相对位置 Δp 被投影到自车的航向坐标系中，并用车辆半尺寸 (L_h, W_h) 归一化：

d_lon = |Δp·f̂_e|，d_lat = |Δp·n̂_e|， (10)

d_body = √((d_lon/L_h)² + (d_lat/W_h)²)， (11)

其中 f̂_e 表示自车的纵向单位向量，n̂_e 表示自车的法向单位向量。

结果以车身半径为单位：相邻车道交通具有较大的 d_lat/W_h，因此 d_body 较大（典型3米横向间隙约为3），而同车道跟车保持较近（3米纵向间隙约为1.2）。这使得接近度门控天然具有方向感知能力，无需任何道路坐标系下的车道假设。

接近度门控为：

s_prox(d_body) = σ((d_body − μ_d)/τ_d)。 (12)

接近的智能体 s_prox → 0，防止同向跟车（高TTC、低接近率）被误读为"让行"。

II-B Polygate公式

各个单独的Sigmoid函数（II-A节定义）无法独立泛化，且可能相互冲突。因此，我们通过以下步骤融合五个Sigmoid函数来定义"Polygate"。

II-B1 TTC门控交互项

我们首先定义交互项，作为加速度和与相对速度信号的凸组合，由权重 w_Σa、w_speed 归一化：

I = (w_Σa·s_Σa + w_speed·s_speed)/(w_Σa + w_speed)。 (13)

II-B2 TTC加权基础让行

TTC分数较大时占主导地位；交互项 I 仅在TTC较小（s_TTC → 0）时起作用，表明"当两个智能体不太可能相交时，交互可能不会发生"：

P_base = (w_TTC·s_TTC + w_I·(1−s_TTC)·I)/(w_TTC + w_I·(1−s_TTC))。 (14)

II-B3 路径优先级混合

路径优先级提供加性偏置（软化形式的"独立门控"）：

P' = (w_path·s_path + w_base·P_base)/(w_path + w_base)。 (15)

II-B4 接近度门控

对于接近的智能体，我们向中性先验 P̄ 混合：

P_yield = s_prox·P' + (1−s_prox)·P̄。 (16)

当 s_prox → 1（智能体在车身半径单位上较远）时，P_yield ≈ P'。当 s_prox → 0（接近/重叠）时，无论其他特征如何，P_yield → 0.3。

本文使用的Sigmoid参数列于表I。注意拐点 μ 几乎无需调参——因为中性点很直观——除了 s_prox 需要根据期望距离（基于自车尺寸）进行调整。我们在仿真验证和硬件演示中使用相同参数（除了 μ(d_body) = 0.5）。

III SIGMO：Polygate交互感知运动规划

III-A 原始优化问题

我们首先定义离散时间下的原始问题：

min_{u_{0:T−1}} Σ_{k=0}^{T−1}[J_nom(x_k, u_k, g) + Σ_{m=1}^{M} J_int(x_k, x̂_{k,m})] + J_T(x_T, g) (17)

s.t. x_{k+1} = f(x_k, u_k)，u_k ∈ U，k = 0, …, T−1。

其中 J_nom 汇集表II中的跟踪与舒适度项，J_int 汇集针对智能体 m 的交互感知风险与碰撞惩罚（III-B3、III-B4小节），J_T 为终端目标成本。

对于 M 个周围智能体和规划时域 T，系统动力学 f(x_k, u_k) 表示自行车运动学[21]，U 定义控制边界，X 定义状态可行集。估计值 x̂_{k,m} 表示智能体 m 在第 k 步的预测，g 为自车的局部目标点 {x_goal, y_goal}。成本函数 J(·) 泛指运动规划目标，包括参考跟踪、驾驶舒适度和风险，详见III-B节。

我们使用模型预测路径积分(MPPI)[16]求解式(17)的问题，因其在处理非线性（动力学与约束）方面具有实用性，且其并行计算结构高效。MPPI通常遵循：(i)设定标称控制序列；(ii)在标称控制序列周围采样候选；(iii)评估样本（此步骤可并行化），涉及成本与约束；(iv)最佳候选选择（取顶部候选的加权和或单个最佳）。详见[16,15]。

备注1 SIGMO在步骤(iii)中融入交互感知，使用Polygate调制空间风险项，因此不像[15,13,14]那样需要以每个候选自车轨迹为条件的智能体预测。

III-B 成本构成

III-B1 完整成本

对于 N 个控制序列样本 {u_{0:T−1}^(i)}_{i=1}^N，通过自行车模型[21]展开，并为每个样本 i 赋予成本：

J^(i) = w_y·J_y-goal^(i) + w_{lat-v}·J_{lat-v}^(i) + w_v·J_speed^(i) + w_u·J_ctrl^(i) + w_j·J_jerk^(i) + w_δ̇·J_steer^(i) + w_lane·J_lane^(i) + w_bnd·J_bnd^(i) + w_x·J_{term-x}^(i) + w_term·J_{term-y}^(i) + (w_int·J_int^(i) + w_col·J_col^(i))【风险项】。 (18)

Sigmoid函数位于交互感知风险项 J_int^(i) 中。

III-B2 标称成本——参考跟踪与舒适度

标称成本被一般性地公式化，以在位置和速度上鼓励平滑且面向目标的机动，无论其他智能体是否存在；列于表II。

虽然大多数项不言自明，但车道保持和边界违规项需要额外输入。车道保持项需要所有车道 L 的车道中心线 {c_l}_{l=1}^L（如适用）。边界违规项需要边界几何 b = {y_min, y_max} 以及带符号的内部距离 d_sgn = min(y − y_min, y_max − y)。中心线项与边界项可相互替换。

III-B3 交互感知风险

图2：汇入场景中有无polygate的风险对比。式(21)中的交互感知风险基本上随智能体（红色）对自车（蓝色）的让行概率而减小。

对于样本 i、预测步 t = 1, …, T 以及交互半径 R_int 内的智能体 m = 1, …, M，风险估计 risk_t^(i,m) 为：

risk_t^(i,m) = γ^t【衰减】· B(p_t^(i), p̂_t^m; θ)【空间风险】· g(P_yield^(i,m,t))【合作门控】， (19)

其中空间风险 B(·) 表示两个具有范围 (ℓ_cov, w_cov) 的定向2D高斯之间的Bhattacharyya核重叠[22,23]，当两个高斯严重重叠时产生高值。来自式(16)的polygate让行概率作为风险乘数：

g(P_yield) = max(1 − P_yield, 0.3)。 (20)

通过合作门控，交互感知风险表达的含义是："当智能体 m 变得不合作时，重点考虑与智能体 m 相关的风险，反之亦然"。这种门控风险通过对每个智能体施加优先级和重要性来促进交互感知。

注意风险乘数设有下界——风险被衰减但从不消除，因为让行的智能体仍是物理障碍物。在时间和智能体上求和，交互感知风险项为：

J_risk^(i) = Σ_{t=1}^T Σ_{m=1}^M risk_t^(i,m)。 (21)

图2展示了汇入场景中交互感知风险如何随polygate而减小。Polygate施加优先级并相应地衰减风险，使自车得以汇入。

III-B4 碰撞风险

由于MPPI不施加硬约束，我们添加了主导性碰撞惩罚，限制在近期时域 T_c = min(T, 1/Δt)（即一秒）内，以避免交互场景中的过度保守行为。

扩展[15]中应用三个圆的方法，每个智能体根据其尺寸 (ℓ, w) = (2ℓ_h, 2w_h) 由一个或多个圆表示。圆的数量计算为 max(1, ⌈ℓ/w⌉)；例如 ℓ = 5m、w = 2m → 3个圆。对于自车圆 p 和智能体 m 的圆 q，裕度为 δ_{p,q} = ‖c_p^ego − c_q^(m)‖ − r_comb，其中 r_comb = w_h^ego + w_h^agent。硬碰撞惩罚针对任意圆对之间的重叠，正式写为：

J_hard^(i) = α_hard·Σ_{t=1}^{T_c} Σ_{m=1}^M [max(−min_{p,q} δ_{p,q}, 0)]²。 (22)

为便于对碰撞进行连续风险估计，将自车-智能体间隙投影到自车车身坐标系中，并由各向异性安全范围 S_lon = r_comb·α_lon 和 S_lat = r_comb·α_lat 归一化：

d_norm = √((d_lon/S_lon)² + (d_lat/S_lat)²)。 (23)

细长的纵向范围（即 α_lon > α_lat）为跟车间隙提供更深的预警，同时对相邻车道交通较为宽容。软碰撞惩罚为：

J_soft^(i) = α_soft·Σ_{t=1}^{T_c} Σ_{m=1}^M [max(1 − d_norm, 0)]²， (24)

其中标量 α_soft 的设置用于合理衰减碰撞权重 w_col；例如我们实验中 α_soft = 0.2。

最终碰撞惩罚为硬碰撞项与软碰撞项之和：

J_col^(i) = J_hard^(i) + J_soft^(i)。 (25)

备注2 碰撞惩罚保持独立于Polygate：硬项惩罚圆重叠，而软项惩罚在安全范围 d_norm 内的接近。

IV 验证

IV-A 仿真

IV-A1 场景

我们开发了具有交互密集场景的仿真环境。我们考虑两个场景：(i)有行人和其他车辆的狭窄通道，以及(ii)汇入密集交通。两者虽都是交互密集的，但各自提出了不同的挑战。在狭窄通道场景中，自车必须在可能时通过行人，判断何时减速、何时加速，并主要通过制动保持安全。相比之下，在汇入场景中，自车必须在接近目标车道时推动相邻车辆让行（即主动性），在保持目标速度与尽快完成汇入之间取得平衡，并主要在相邻车辆拒绝让行时通过转向避让保持安全。在汇入场景中，我们将期望速度 v_des 设为自车当前速度，以降低通过加速获取位置的激励。

IV-A2 行为建模

我们对其他智能体采用响应式行为模型，以评估规划器如何适应不同的智能体行为。两类模型均有一个规划器不可见的可配置合作性参数。

行人。在狭窄通道场景中，每个行人 i 被建模为质点，状态为 s_i = [x_i, y_i, v_{x,i}, v_{y,i}]^T，并采用由潜在合作性变量 c_i ∈ [0,1] 参数化的类型条件、目标导向策略。我们考虑四种行人类型 τ_i ∈ {same_dir（同向）, oncoming（迎面）, crossing（穿越）, loitering（游荡）}。对于非游荡行人 i，期望速度为 v_i^des = (1 − c_i·ρ_i)·v_i^pref·ĝ_i，其中 ĝ_i 指向采样目标，ρ_i = max(0, 1 − ‖p_i − p_ego‖/d_react) 以 d_react = 8m 度量自车接近程度，轨迹为 p_(·)。因此，合作行人会随自车接近逐渐降低速度，且当 c_i > 0.3 且 ρ_i > 0.3 时，将其航向偏向较近的内侧人行道以模拟横向让行。游荡行人则经历有界随机漂移，具有高斯加速度噪声 σ_ℓ = 0.3 m/s² 和阻尼 λ_ℓ = 0.5 s⁻¹，当自车在附近时，合作的游荡者还会被额外吸引向较近的人行道。独立于 c_i，所有行人在与附近车辆 j 的自由间隙 d_{ij} 降至 d_avoid = 8m 以下时施加反应性横向排斥，使用 a_{y,i}^avoid = k_avoid·max(0, 1 − d_{ij}/d_avoid)·sign(y_i − y_j)，其中 k_avoid = 2 m/s²；因此没有行人完全无视碰撞。最终加速度为 a_i = (v_i^des − v_i)/τ_v + ε_i + a_{y,i}^avoid·e_y，其中 τ_v = 0.5s，ε_i ~ N(0, 0.08²I)，状态使用 Δt = 0.2s 的欧拉步长积分，并受通道墙壁约束。该模型将由 (g_i, τ_i) 捕捉的行人意图与由潜在变量 c_i 捕捉的倾向分离，使自车规划器（无论是SIGMO还是基线）能够从观测运动中推断合作性，为评估交互感知规划提供了受控机制。

车辆。在汇入场景中，周围车辆遵循[13,15]的交互行为模型。每辆车使用智能驾驶员模型(IDM)[24]跟踪其车道，该模型本身仅对同车道前方车辆做出反应。该模型被扩展为对来自相邻车道的汇入车辆做出让行决策。当自车接近车道边界时，每个周围车辆通过参数为 p_m 的伯努利抽样决定是否将其视为车道内车辆（从而让行）。p_m 值高表示容易让行，而值低则代表更激进的行为，即周围车辆无视自车。底层交互模型的详情请参阅[13]。

图3：SIGMO在狭窄通道场景中的轨迹。带polygate的SIGMO估计其他智能体的响应性，成功穿越杂乱通道。相比之下，缺少polygate则纯粹依赖恒定预测，使自车滞留于杂乱通道中。智能体的颜色表示对自车的估计风险（即红色↑ → 风险↑）。

图4：SIGMO在汇入场景中的轨迹。带polygate的SIGMO估计目标车道中智能体的让行概率，成功创造空间并汇入。相比之下，纯恒定预测无法单独预测让行行为，使自车留在源车道。智能体的颜色表示对自车的估计风险（即红色↑ → 风险↑）。

图5：汇入场景中的让行概率估计。智能体A4是自车为创造汇入空间而与之交互的关键智能体。带polygate的SIGMO推动A4减速，随着A4减速，让行概率上升，促使自车决定汇入。

IV-A3 比较分析基线

我们首先将SIGMO与基础规划器和两个预言机进行比较。(i) MPPI除III-B4节的碰撞惩罚（作用于接下来的 T_c = 1s）外，没有额外的交互感知风险项。(ii) Oracle-yield用每个智能体的真实合作性参数（c_i 或 p_m）替换估计的 P_yield，同时保持恒定速度预测。(iii) Oracle-traj用每个智能体的实际未来轨迹替换恒定速度预测，该轨迹通过在每个候选自车轨迹下向前滚动仿真器获得。Oracle-yield界定了相同预测下完美让行估计所能达到的水平，Oracle-traj界定了完美反应式预测所能达到的水平。

IV-A4 指标与协议

每个场景运行100个种子；种子固定所有智能体的初始位置、速度和合作性参数。狭窄通道运行若自车在90秒内无碰撞到达通道末端则为成功；汇入运行若在30秒内无碰撞到达目标车道则为成功。既未成功也未碰撞的运行计为超时。我们还报告最小自车-智能体距离、成功运行的完成时间，以及狭窄通道场景的停滞时间：即速度低于1 m/s的时间，在自车发生停滞的运行中取平均。

IV-B 定性分析

我们首先考察一个由多名行人和车辆共享的狭窄通道场景。仿真中的行人在名义上拥有优先权，然而它们通常会通过让开和/或停下/缓慢移动，为共享通道的车辆腾出空间。它们可能根据其他智能体的行为切换即时决策（例如，若某智能体正在激进接近，行人可能决定让行）。这些行为要求自车基于合作性调整速度。

图3展示了SIGMO与采用恒定速度的朴素MPPI（即不含式(II-B)中polygate）的对比表现。约在 t = 40 时，自车接近穿越通道的行人。SIGMO在接近这些行人时加速，使穿越的行人让行。约在 t = 50 时，自车决定为路径与其重叠的迎面行人减速。同一规划器产生了两种行为，展示了穿越人群时及时且可切换的策略。相比之下，朴素MPPI（仅在碰撞处于一秒之内时才对行人做出反应）在行人穿越时迟缓且反复制动，导致长时间滞留（超过10秒）。

汇入场景比狭窄通道场景简单，因为车辆行为可以以直接方式刻画：每辆车要么在前方打开间隙，要么关闭间隙。然而，汇入场景非常清晰地展示了"主动机动"：在没有可用间隙的情况下，自车必须推动目标车道车辆创造间隙——我们将定性分析聚焦于这种推动行为。

图4展示了这种交互。自车与目标车道上的其他车辆以相近速度行驶，可借以利用现有间隙的相对运动很少。SIGMO（即带polygate）始终呈现主动汇入机制：(i)缓慢接近目标车道中的车辆；(ii)若该车决定减速，自车在让行车辆前方汇入；(iii)若该车保持速度，自车在下一时间步重复推动；(iv)若该车决定加速，自车尝试在其后方汇入。相比之下，采用恒定预测（即无polygate）且无交互项的朴素MPPI最终停留在源车道。

图5展示了交互期间让行估计随时间的变化。随着目标车道车辆减速，其估计让行概率上升。这可降低相应的交互风险乘数，鼓励自车更主动地汇入，这在朴素MPPI（无polygate）中未被观察到。

图6：F1Tenth[25]硬件实验。自车与行人交互以从匝道汇入。第一张图为朴素MPPI，其余为SIGMO（展示多种行为）。所有实验采用相同的硬件设置（如定位和感知）以及行人预测。每对红圈表示行人的足迹。

IV-C 比较分析

我们现在在IV-A4节的100种子协议上量化这些行为，与IV-A3节的基线进行比较；表III报告了结果。

在狭窄通道场景中，SIGMO相比MPPI成功率提高4个百分点。几个有趣的讨论点：(i)成功率的提升并不显著，但停滞时间显著减少(24.3%)；(ii)同时，SIGMO不损害安全性（碰撞率和最小距离相近），只带来性能收益——当前的碰撞主要非自车过错；(iii)有趣的是，SIGMO的成功率高于Oracle-yield（后者掌握交通智能体的真实合作参数）且碰撞更少；可以看出，让行估计中的残差导致了更主动的行为，带来更成功且更安全的机动。(iv)通过"对响应的完美预测"（即Oracle-traj）可进一步提升性能，但成功率停留在93%，表明测试用例的难度。

在汇入场景中，SIGMO显著提升成功率（↑12%），因为该场景常需要强力推动才能汇入，而MPPI不会执行。SIGMO不增加碰撞（与狭窄通道场景一致），再次展现无代价的优势；它将超时转化为成功。不过，最小距离有所下降(0.2m)，这源于缩小与相邻智能体横向距离的推动行为。完成时间（即汇入耗时）同样受益于SIGMO；虽然数值看似不大(1.5s)，但完成时间在完美预测下界为19s，表明缩小了36.5%的性能差距。该场景的成功率上限为69%，表明汇入存在根本性不可行的情况。

我们在设有匝道和汇入车道的室内赛道上，以1/10比例的F1Tenth赛车[25]演示SIGMO的性能。测试车搭载配备Intel ARC GPU/AI就绪NPU的Asus NUC 15 Pro。

图6展示了SIGMO的三个实验与作为基线的朴素MPPI实验的对比。前两图展示了MPPI与SIGMO在相同场景下的表现，MPPI未能汇入，而SIGMO成功。该发现始终成立：polygate基于让行可能性估计，有效沿行人预测路径衰减风险。相比之下，MPPI朴素地依赖行人预测，将自身局限于反应式机动。右侧两个示例展示了SIGMO的"放弃"案例：在"放弃-长"案例中，SIGMO持续尝试超车但最终放弃，在行人后方汇入；在"放弃-短"案例中，SIGMO在短时间内尝试超车后迅速放弃，在行人后方汇入。结果展示了SIGMO行为的多样性，以及在放弃时机的及时决策。

IV-F 局限性与未来工作

本文的局限性主要在于交通交互模型相对简单（IV-A2节），可能无法代表真实的人类行为。因此，未来工作包括采用更真实、更复杂交互行为的更严格仿真设置。另一个局限性是SIGMO建立在MPPI之上，因而共享其缺乏碰撞避免硬约束的局限。尽管如此，SIGMO中的polygate并不限于MPPI方案，它可以很容易地作为附加惩罚集成到其他具有硬约束的方案中，例如模型预测控制。

V 结论

本文提出了交互感知运动规划方案的原则性公式与验证；命名为SIGMO（Sigmoid门控交互感知运动规划）。特别地，本文首先通过组合代表两个智能体间物理相关性的五个Sigmoid函数，形式化了让行概率估计。组合后，这些Sigmoid函数作为风险乘数集成到MPPI方案中；即使采用朴素的非交互预测（如恒定预测），也能为经典规划器增添交互感知能力。仿真与硬件实验中的验证支持了所提方案在实现自动驾驶主动且交互感知规划方面的潜力。
