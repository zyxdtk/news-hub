中文摘要： 本文提出了一种名为“生成式路由金字塔”的无监督学习方法，用于从无标注显微镜图像中分割细胞实例并分类表型。该方法通过由粗到细的路由金字塔重建图像，将像素与空间稀疏的潜在源关联以生成实例掩码，同时利用源潜在变量编码细胞形态。实验表明，该方法在多种细胞形态和成像模态下表现出色，并能有效建模扰动下的细胞表型。

摘要
识别和表示细胞或细胞核等对象实例是显微镜图像分析中的一项常见任务。现有的机器学习流程通常采用监督检测或分割，随后进行特征提取或分类，这不仅需要人工标注，还将实例分割和细胞表示视为独立的阶段。我们提出了一种全新的无监督方法，用于从无标注显微镜图像中进行细胞实例分割和表型分类。该方法基于使用由粗到细的路由金字塔重建每张图像，该金字塔将像素与空间稀疏的潜在源相关联。由此产生的像素到潜在源的关联可生成实例掩码，而源潜在变量则编码了细胞形态。我们在多种细胞形态和成像模态下展示了具有竞争力的实例分割性能，并实现了扰动条件下细胞表型的生成式建模。源代码和模型检查点可在 https://github.com/weigertlab/routing-pyramids 获取。

关键词：细胞分割，无监督学习，以对象为中心的学习，显微镜技术

1 引言
图 1：生成式路由金字塔概览。a) 编码器从输入图像预测潜在场，随后用于生成金字塔形（由粗到细）流以重建图像。b) 各层流与路由特征图。流以 HSV 编码显示，其中色调为流方向，饱和度为流幅度，明度为路由概率质量。特征以 RGB 值显示，代表前三个主成分。

在显微镜图像中识别细胞或细胞核等单个对象是定量生物图像分析中的一项基础任务 [18]，其应用包括细胞计数、形态学分析和追踪 [4, 2, 27]。目前，基于监督深度学习的方法是最成功的细胞分割方法 [22, 23, 25, 19]。然而，训练这些模型需要对大量训练图像进行繁琐的人工标注，使得当样本、成像模态或采集条件发生变化时，数据集的创建成为一项经常性成本。尽管对象的外观在不同的成像模态和样本类型之间可能存在显著差异，但在单一实验设置中（特别是在本文所考虑的细胞培养实验中），它们通常表现出更为刻板的外观。这种设置提供了大量无标注样本，模型可以从中学习共享结构，同时保留特定对象的变异。然而，仅靠共享的外观模型无法确立实例身份，因为相邻细胞可能看起来相似，但必须保持与不同空间源的关联。因此，无标记的细胞实例学习需要一个共享的外观模型以及能够将单个对象分开的空间分配。

以对象为中心的学习为这一思想提供了框架：基于重建的方法将图像解释为对象和背景的集合，并为每个组件学习对象级的潜在表示 [5, 9, 15, 13]。现有的表述通常通过全局槽位、迭代推理或独立渲染的对象局部视图来分离组件，但在处理具有许多小对象的显微镜图像时扩展性较差（第 2.2 节）。在这项工作中，我们引入了生成式路由金字塔，这是一种直接在无标注显微镜图像上训练的以对象为中心的生成模型。该模型预测对象存在的位置，并对所有候选对象运行单次解码器传递，从其潜在表示中重建图像。由于对前景存在性进行了惩罚，模型仅在共享解码器能够利用它来重建反复出现的对象外观时才会激活一个源。为了在保持空间身份的同时重建扩展对象，解码器通过由粗到细的金字塔扩展每个源。在每一层级，每个更精细尺度的位置在其附近的父位置中进行软选择，因此由此产生的局部选择链将图像像素追溯至解释它们的源。这些像素到源的祖先关系生成实例掩码，而相应的源潜在变量为单细胞表型分析提供对象表示。

2 相关工作
2.1 细胞分割与表示学习
监督式细胞实例分割模型通常预测从实例掩码衍生的几何目标。StarDist [23] 沿固定方向集回归径向距离以形成星凸多边形提议，然后进行非极大值抑制。Cellpose [25] 则预测指向对象中心的密集像素空间流，并通过在多个步骤中跟随这些流来对像素进行分组。我们的方法则在没有流目标或实例标注的情况下进行训练。

无监督方法用替代目标取代了从掩码衍生的目标。Cellulus [28] 预测图像块之间的相对偏移以学习密集空间嵌入，通过比较损坏输入图像的嵌入来估计前景，并通过均值漂移聚类和形态学滤波获取实例。CellSeg3D [1] 改编了 W-Net [29] 以无标签学习语义前景，并使用 Voronoi-Otsu 后处理分离实例。Cellulus 和 CellSeg3D 都是通过非学习的后处理来分离实例。基于运动的伪标签提供了另一种替代方案 [21]，但需要具有平滑前景运动和静态背景的延时数据。我们的方法适用于静态图像，并直接将实例分配作为图像生成过程的一部分进行学习。

显微镜表示学习要么产生密集的像素或图像块特征 [8, 12]（这仍然需要提取实例以进行单细胞分析），要么从单细胞裁剪中学习 [26, 10]（这假设了先前的检测或掩码）。在这两种情况下，分割和表示学习被视为不同的阶段，需要独立的数据整理和训练工作。相反，我们的方法在没有标签的情况下，从相同的数据集中联合学习实例分割和对象表示。

2.2 以对象为中心的生成式学习
以对象为中心的生成模型通过图像重建学习组件表示，但在推断和渲染组件的方式上有所不同 [5, 9, 15, 13, 24]。它们的计算扩展性对于包含许多小实例的显微镜图像至关重要（表 1）。全局组件方法将全图成本（具有 N 个像素）与组件计数 K 耦合，迭代变体增加了因子 T。例如，SPACE [13] 在空间上执行并行候选推理，但在全图空间中渲染每个提议。我们的方法在一次 O(N) 的前向传递中预测所有候选源，并重建共享的空间特征场，而不是单独渲染每个候选。读出 K 个推断的实例掩码的成本为 O(KN)。

2.3 分层流场
由粗到细的金字塔是有效近似位移场的既定工具 [6, 3]，学习的金字塔已用于预测视频帧之间的光流 [20]。在我们的设置中，由粗到细的层次结构定义了单图像生成模型的空间信息流，从而引发实例分割。直观上，这种空间流场类似于 StarDist 和 Cellpose 中的对象中心到边界的流，但由图像生成过程隐式定义。使用分层近似避免了像 StarDist 那样的不可微分配，或在训练期间运行许多 Cellpose 风格的流模拟步骤，从而允许端到端的无监督学习。

3 方法
3.1 概述
我们的方法从无标注的显微镜图像中学习对象实例。如图 1 所示，给定输入图像，编码器推断前景和背景潜在变量，而稀疏正则化的存在图标记对象候选。由粗到细的金字塔解码器使用局部路由权重重建图像。相同的权重将像素与潜在源相关联，生成实例掩码和每个推断对象的一个潜在表示。对于延时数据，模型独立处理每一帧。

3.2 空间潜在变量与学习的对象种子
给定输入图像 x∈ℝ^(H×W×C)，编码器 E_φ 在空间步长为 δ 的网格 Ω_0 上生成特征 f=E_φ(x)∈ℝ^(h×w×d_E)。步长是模型超参数，对于可整除的输入大小，h=H/δ，w=W/δ。我们在所有实验中使用 δ=8。逐点头预测两个潜在网格的对角高斯后验：
q^r_φ(z^r|x) = ∏_{u∈Ω_0} N(z^r_u; μ^r_u, diag((σ^r_u)^2)), r∈{fg, bg} (1)
这里 z^r_u∈ℝ^d，其中 d 是共享的潜在维度。前景和背景候选在给定 x 的情况下独立采样，并且都使用标准正态先验。在背景头之前，编码器特征以步长 δ_bg 进行平均池化，并双线性恢复到 Ω_0。此步长是独立的模型超参数；我们在所有实验中使用 δ_bg=8。此操作将依赖于图像的背景后验参数限制为在空间上平滑变化。来自前景候选的逐点预测定义了一个确定性的软存在门：
s_u = sigmoid(w_s^T z^fg_u + b_s), u∈Ω_0 (2)
解码器从门控混合开始：
h^0_u = s_u z^fg_u + (1-s_u) z^bg_u (3)
接近 1 的 s_u 值暴露前景候选，而接近 0 的值选择空间平滑的背景候选。后验候选独立采样，但这个确定性门在解码前将它们耦合。在训练期间，高斯场通过重参数化采样 [11]，推理使用它们的后验均值。重建压力决定了哪里需要前景容量，而 s 的稀疏活动区域被解释为学习的对象种子。

3.3 路由金字塔解码器
令 Ω_ℓ 表示解码器第 ℓ 层的目标网格。每个位置 j∈Ω_ℓ 在其前一个父网格上的锚点周围的有效 3×3 邻域 N_ℓ(j) 中进行选择，父网格要么具有相同分辨率，要么粗糙两倍。卷积残差预测器从存在门控的解码器特征生成 logits a^ℓ_{ji}，掩码 softmax 给出：
T^ℓ_{ji} = exp(a^ℓ_{ji}) / Σ_{i'∈N_ℓ(j)} exp(a^ℓ_{ji'}), i∈N_ℓ(j), Σ_i T^ℓ_{ji} = 1 (4)
无效的边界边缘概率为零。因此，T^ℓ_{ji} 是目标 j 选择位置 i 作为其父节点的条件概率。在 Ω_ℓ 上的均匀测度下，T^ℓ 可以被视为局部支撑的、单侧传输耦合。层索引的金字塔位置及其局部父链接形成有向无环图 (DAG) G：每当 i∈N_ℓ(j) 时，边连接 (ℓ,j) 到 (ℓ-1,i)。因此，每条边都从输出像素指向潜在种子网格，并减小层索引。在推断的图像表示条件下，局部归一化的路由分布定义了 G 上的有限、层非齐次马尔可夫链。如果分配质量到达位置 j，权重 T^ℓ_{ji} 将其全部分配给有效的父节点；流可以在精细位置分裂并在父位置合并。组合链的分层过渡核给出：
A_{nu} = Σ_{γ∈Γ(n,u)} ∏ℓ T^ℓ{γ_ℓ γ_{ℓ-1}} (5)
其中 n 索引输出像素，Γ(n,u) 是从像素 n 到粗糙种子位置 u 的有效路径集。因此，A_{nu} 是起源于 n 的单位分配质量到达 u 的概率，且 Σ_u A_{nu} = 1。因此，A∈[0,1]^(HW×hw) 是由金字塔 DAG 引起的像素到种子关联矩阵，输出像素为行，潜在种子位置为列。每一行是从一个像素到种子网格的完整过渡分布。等价地，它描述了通过学习的概率流网络从每个像素引发的单位流。这种马尔可夫链解释适用于预测依赖于图像的路由核之后的祖先过程；特征传播还包括下面描述的神经更新。传播的前景概率为：
p^fg_n = Σ_{u∈Ω_0} A_{nu} s_u (6)
在生成期间，相同的路由权重从每个目标的父节点拉取种子存在和解码器值：
s^ℓ_j = Σ_i T^ℓ_{ji} s^{ℓ-1}i, r^ℓ_j = Σ_i T^ℓ{ji} V_ℓ(h^{ℓ-1}i) (7)
传输更新 r^ℓ_j 被归一化、激活、由 s^ℓ_j 门控，并添加到最近邻残差路径。逐点前馈残差块完成该层。层要么保持在当前分辨率，要么上采样两倍；最后的逐点网络将全分辨率特征映射到重建图像 x̂。因此，由粗到细的生成计算和由细到粗的祖先解释使用相同的学习图。令 c_u 为种子位置 u 的图像空间中心坐标，c_n 为像素 n 的坐标。预期的像素到种子流为：
v_n = Σ{u∈Ω_0} A_{nu} c_u - c_n (8)
这种预期的位移从学习的关联矩阵中给出了类似 Cellpose 的流读数 [25]。每一层的硬局部支撑限制了单个传输步骤，而它们的组合允许通过金字塔实现更大的对象扩展。

3.4 无监督学习目标
令 z=(z^fg, z^bg) 为采样的潜在场，x̂θ(z) 为相应的解码器输出。预期的重建项为：
L_rec(x) = E{q_φ(z|x)} [ 1/(HWC) ||x̂θ(z) - x||_1 ] (9)
独立的均值 KL 项将前景和背景后验向其标准正态先验进行正则化：
L^r_KL = 1/(|Ω_0|d) Σ{u,k} 1/2 ( (μ^r_{uk})^2 + (σ^r_{uk})^2 - 1 - log(σ^r_{uk})^2 ), r∈{fg, bg} (10)
平滑凹惩罚鼓励前景容量集中到更少的种子区域：
L_sparsity = 1/|Ω_0| Σ_{u∈Ω_0} ( (s_u + ε)^α - ε^α ), α∈(0,1) (11)
指数 α 是控制惩罚凹性的超参数；我们在所有实验中使用 α=0.5。这里 ε 是一个小偏移量，保持导数在 s_u=0 附近有限。用 c^{ℓ-1}i 和 c^ℓ_j 表示以图像像素为单位的父位置和目标位置中心，每个局部边具有二次几何成本 ||c^{ℓ-1}_i - c^ℓ_j||^2_2。我们在学习的路由分布下对其期望进行正则化：
L_flow = 1/(Σ{ℓ=1}^L |Ω_ℓ|) Σ_{ℓ=1}^L Σ_{j∈Ω_ℓ} Σ_{i∈N_ℓ(j)} T^ℓ_{ji} ||c^{ℓ-1}_i - c^ℓ_j||^2_2 (12)
因此，L_flow 对跨层和目标位置的预期平方局部步长进行平均。它通常不同于组合预期流 v_n 的平方范数。完整的每图像目标为：
L = λ_rec L_rec + λ_fg L^fg_KL + λ_bg L^bg_KL + λ_flow L_flow + λ_sparsity L_sparsity (13)
我们在所有实验中使用 λ_rec=1.0，λ_fg=0.01，λ_bg=0.05，λ_flow=0.005，并为不同数据集选择 λ_sparsity∈{0.2, 0.5}（第 4 节）。我们在前 10 个 epoch 中对正则化损失项的权重使用线性预热。

3.5 实例分割与对象表示
在推理时，模型用后验均值替换采样的潜在场。它将粗糙存在图在 τ_s 处进行阈值处理，并使用 8 连通性对相邻的活动源位置进行分组：
{C_k} = CC_8({u : s_u ≥ τ_s}) (14)
每个组件作为一个对象种子。我们在所有实验中使用 τ_s=0.5。路由祖先将这些粗糙种子扩展为图像空间实例。组件 C_k 在像素 n 处的存在加权质量为：
m_k(n) = Σ_{u∈C_k} A_{nu} s_u (15)
如果该质量达到阈值 τ_m，则将像素分配给具有最大质量的组件：
ŷ_n = arg max_k m_k(n), 如果 max_k m_k(n) ≥ τ_m; 否则为 0 (16)
我们在所有实验中使用 τ_m=0.1。实例在模型分辨率网格上按最小面积进行过滤。我们在所有实验中使用 100 像素的最小面积。如果模型和原始图像分辨率不同，则通过最近邻（用于上采样）或模式池化（用于下采样）将掩码重新缩放到原始图像分辨率。相同的种子组件定义了用于表型分析的对象级表示。对于每个组件，其嵌入 e_k 是前景后验均值的存在加权平均值：
e_k = (Σ_{u∈C_k} s_u μ^fg_u) / (Σ_{u∈C_k} s_u) (17)

数据集。我们在三个细胞培养数据集上进行了评估（表 2）：Allen 研究所核形态数据集 [7]，以及来自细胞追踪挑战赛 (CTC) 的 Fluo-N2DL-HeLa 和 PhC-C2DL-PSC 数据集 [16]。它们涵盖细胞核和全细胞目标、荧光和相差成像，并且在形态和密度上有所不同。对于 Allen 数据集，我们使用 FOV-nuclei 延时数据集中的三个分析延时。我们使用其中的大和小时延时进行训练，使用中延时进行测试。对于 CTC 数据集，我们使用两个测试视频（无标注）进行训练，使用训练视频（有标注）进行测试。由于 CTC 数据集只有稀疏的手动标注分割掩码，我们使用它们的“银标准”标注 [16] 作为目标。

训练。我们仅使用单通道图像从头开始训练我们的方法。所有数据集使用相同的模型架构，潜在维度 d=64。模型在 256×256 的裁剪图像上训练 200 个 epoch，批次大小为 64。我们将 PhC-PSC 图像双线性上采样 2 倍。Allen 图像是 3D 采集的最大强度投影，并通过平均池化进行两倍下采样。我们对 Allen 和 PhC-PSC 使用 λ_sparsity=0.5，对 Fluo-HeLa 使用 λ_sparsity=0.2。

基线。我们将 Cellpose-SAM [19]（冻结权重）作为强大的监督参考进行比较，将 Cellulus 作为无监督基线，将 Otsu 阈值处理后接连通分量作为非参数基线。Cellulus 和 Otsu 使用在测试集上选择的特定于数据集的后处理参数（例如，对象大小，见表 3），这使它们在比较中具有优势。我们的方法在所有数据集上使用相同的后处理（第 3.5 节）。

指标。通过交并比 (IoU) 匹配预测和标注的实例。我们报告 IoU 阈值为 0.5、0.7 和 0.9 时的对象级 F1 分数，以及全景质量 (PQ)。

结果。表 3 报告了定量比较，图 2 显示了代表性预测。在无监督方法中，生成式路由金字塔在几乎每个数据集和指标上均获得最佳分数，在所有三个数据集上提高了相对于最强无监督基线的全景质量（PQ 0.867、0.800、0.518 对比 Cellulus 的 0.787、0.756、0.370）。生成式路由金字塔在大多数设置中仅次于监督方法 Cellpose-SAM 参考。在 Allen 数据集上，它在全景质量（0.867 对比 0.859）和严格 IoU 0.9 阈值下的 F1 分数（0.649 对比 0.256）上均超过了这种监督参考，表明与真实核边界更紧密的一致性。主要的例外是 PhC-PSC 上 IoU 0.9 的 F1 分数，其中每种方法的得分都低于 0.1，反映了在低分辨率相差图像中实现像素精确边界的困难。

4.2 生成式对象表示学习
我们测试了学习的对象潜在代码是否捕获单细胞表型变异，使用的是经 BBBC013 [14] 中 LY294002 或 wortmannin 系列稀释处理的 U2OS 细胞的双通道荧光图像。板的第 2-11 列形成系列稀释训练集，而第 1 和 12 列包含用于验证的阳性和阴性对照。在无监督训练之后，我们为每个预测的细胞提取一个嵌入（第 3.2 节）。为了定性评估按表型进行的潜在空间聚类，将主成分分析 (PCA) 和 UMAP [17] 拟合到系列稀释（训练）嵌入，并叠加系列稀释的扰动强度（剂量）（图 3a）和对照图像（图 3b）。对于两个划分，对象潜在变量按剂量形成不同的簇。为了对二元表型进行定量建模，将双分量高斯混合模型 (GMM) 拟合到训练集的对象潜在变量上，它显示了扰动下细胞的剂量反应（图 3c）。通过将它们的均值与保留的对照进行比较，将身份分配给组件（图 3b）。在平均 GMM 责任上以 0.5 进行阈值处理，可 100% 准确地恢复 16 个对照重复样本的阳性/阴性类别。GMM 可进一步用作实例生成的近似后验，以及用于实例检索的簇（图 4），方法是从高斯组件中采样或检索（通过欧几里得距离）最接近组件均值的最近邻。生成的样本表明生成模型与扰动诱导的表型变异一致，而检索的样本说明了与学习的潜在簇相对应的不同形态。

5 结论
我们提出了生成式路由金字塔，这是一种无监督的以对象为中心的模型，可从无标注的 2D 显微镜图像中学习细胞实例和形态表示。其路由金字塔解码器重建每张图像，同时将像素追溯到空间稀疏的潜在源，因此实例掩码和对象嵌入源于相同的分解。在荧光和相差数据集上，我们的方法在 IoU 阈值为 0.5 时优于评估的无监督基线，同时需要最少的后处理。在双通道荧光药物扰动实验中，从学习的对象表示计算出的混合责任与处理剂量一致，而生成的和检索的细胞恢复了相应的表型。我们目前为每个数据集训练一个单独的模型，将跨多样样本的泛化留作未来的工作。我们的方法还假设在更平滑的背景下具有相似外观的紧凑对象，对更复杂场景（如组织成像）的应用仍未探索。尽管存在这些局限性，我们表明实验内反复出现的视觉结构可以支持在没有人工标注的情况下学习细胞实例及其形态。
