Dropbox 3.5亿美元收购Tigris...

📅 2026-11-05 📄 TechCrunch AI 🔗 原文链接

原标题：Dropbox acquires Tigris Data for $350M to bolster its AI infrastructure

中文摘要： Dropbox宣布以3.5亿美元收购云存储公司Tigris Data，交易预计2026年第四季度完成。此次收购旨在强化其AI基础设施，支持面向AI模型和智能体开发者的新存储平台DBX Agent Cloud，初期提供兼容Amazon S3的独立对象存储。Dropbox还为核心产品引入更多AI功能，用户可选择不同AI模型并连接ChatGPT等第三方工具。Tigris Data由前Uber工程师创立，去年完成2500万美元A轮融资，此为Dropbox迄今最大规模的收购。

这笔交易于周四宣布，预计将增强Dropbox的AI基础设施能力，并支持DBX Agent Cloud的开发。DBX Agent Cloud是一个面向构建AI模型和智能体的企业和开发者的全新存储平台。

Dropbox通过电子邮件向TechCrunch表示，该交易预计将于2026年第四季度完成。该公司还表示，目前没有计划在此次收购中进行裁员。据《华尔街日报》（WSJ）报道，该公司上个月已在全球范围内裁员9%。

DBX Agent Cloud最初将以独立产品形式提供对象存储，允许企业单独购买存储服务，并将其与现有的、为Amazon S3（简单存储服务）构建的工具和应用程序配合使用。Amazon S3是一种云存储服务，可帮助企业存储和检索大量数据。

除了在基础设施方面的布局，Dropbox还在为其核心产品引入更多AI功能。用户将能够要求AI利用其文件执行支持的任务、在不同AI模型之间进行选择，并将其Dropbox内容连接到第三方工具，包括ChatGPT、Claude和Muse。

该公司还计划为DBX Agent Cloud扩展更多功能，旨在帮助AI系统处理不同类型的内容，包括文档、图像、音频和视频。其他计划新增的功能还包括文件系统特性，使AI智能体能够管理文件，并在不同任务和会话之间保持连续性。

Dropbox表示，更新后的体验已覆盖超过7万个团队。初期推出面向美国、英国和澳大利亚符合条件的Standard（标准版）和Advanced（高级版）客户，并计划于2027年实现更广泛的开放。

Tigris Data由前Uber工程师创立，这些工程师曾参与开发这家网约车公司的存储基础设施。该公司提供云存储技术，帮助企业跨不同区域存储和访问数据。其平台会自动将数据放置在更靠近需要它的用户和计算资源的位置，从而缩短访问时间并提升性能。

Tigris Data去年在A轮融资中筹集了2500万美元。

虽然收购Tigris似乎是Dropbox规模最大的一笔收购，但这并不是该公司首次通过并购扩展其AI能力。Dropbox此前已收购了多家专注于AI的公司，包括Reclaim.ai、Promoted.ai和Mobius Labs。
