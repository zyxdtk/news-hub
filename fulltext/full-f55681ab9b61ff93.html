Spotify 欲成为 AI 生成个人音频的大本营

📅 2026-05-07 📄 TechCrunch AI 🔗 原文链接

原标题：Spotify wants to become the home for AI-generated personal audio

中文摘要： Spotify推出处于测试阶段的新CLI工具，允许用户将AI生成的个人播客导入其Spotify资料库。用户可通过OpenAI的Codex或Anthropic的Claude Code等编程工具，输入提示词生成定制化音频内容（如课堂笔记摘要、日程简报等），并直接保存至Spotify。这些播客仅对创建者可见，其他用户无法访问，Spotify正借此成为AI个人音频的归属地。

在过去的几年里，诸如[谷歌的 NotebookLM](https://techcrunch.com/2025/05/19/google-launches-standalone-notebooklm-app-for-android/)、[Hero](https://techcrunch.com/2025/02/03/heros-all-in-one-ai-productivity-app-takes-on-googles-calendar-and-others/) 以及最近的 [Adobe Acrobat](https://techcrunch.com/2026/01/21/adobe-acrobat-now-lets-you-edit-files-using-prompts-generate-podcast-summaries/) 等应用，已经让用户能够基于文档、日程安排和文章等现有材料创建播客。现在，Spotify 允许你在其应用内访问这些播客，但你需要一些编程工具来实现。

该公司表示，如果你已经在使用 OpenAI 的 Codex、Anthropic 的 Claude Code 或 OpenClaw 等工具，你可以使用目前处于测试阶段的 [Spotify 新 CLI 工具](https://github.com/spotify/save-to-spotify)来创建播客并将其导入 Spotify，以便日后收听。

“人们已经开始使用他们的智能体来创建指导一天生活的个人音频：从考试前的课堂笔记摘要到日程安排简报。他们希望能有一种方法在 Spotify 上收听这些内容，因为他们已经在 Spotify 上收听其他所有内容了，”该公司在一篇[博客文章](https://newsroom.spotify.com/2026-05-07/personal-podcasts-launch/)中表示。

这些播客将出现在用户的 Spotify 资料库中以便于访问，但其他 Spotify 用户无法收听。

要使用这项新功能，用户可以前往该工具的 GitHub 页面并按照那里的说明进行操作。系统将提示他们通过浏览器登录其 Spotify 帐户。
