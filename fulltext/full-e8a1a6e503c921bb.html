摘要
在本文中，我们探索了一项新任务：多模态无监督持续后训练（MU-CPT），使部署的多模态大语言模型（MLLMs）能够从流式未标记数据中持续演化。现有的针对 MLLMs 的无监督后训练方法通常均匀地优化目标 token，忽略了它们异构的视觉依赖（VD）。然而，我们揭示了 token 级别的 VD 对 MU-CPT 至关重要。具体而言，其结构失真可作为跨模态灾难性遗忘的指标，而其固有的异构性则作为指导新任务学习的指南针。利用这一特性，我们提出了一个视觉依赖感知（VDA）框架，包含两个主要组件。首先，视觉约束最优传输（VC-OT）将新任务学习期间旧任务 VD 的结构失真表述为一个最优传输问题，以缓解跨模态遗忘。通过设计区域感知的地面成本和依赖分层传输惩罚，它防止了视觉焦点的全局偏移，同时严格禁止视觉依赖退化为语言偏差。其次，视觉调制适应（VMA）利用 VD 异构性来强调基于视觉的新任务学习，促进新任务可塑性。结合在一起，我们的方法在具有挑战性的 MU-CPT 中同时维持了旧任务的稳定性和新任务的可塑性。在我们设定的 MU-CPT 下的广泛实验验证了 VDA 的有效性。

我们进一步将 VC-OT 与几种保留旧任务 VD 的替代策略进行了比较。“无保护”表示没有 VC-OT 的 VDA，而其余变体用 token 级别的 L1 匹配或 Mass+KL 对齐替换 VC-OT。如表 4 所示，无保护表现出显著的 VD 漂移和严重的遗忘，证明了显式保留旧任务 VD 结构的必要性。Token 级别 L1 实现了最小的 VD 漂移和 0.4 的最低 AvgF，但仅达到 59.1 的 AvgAcc，表明刚性逐位置匹配抑制了模型的可塑性。Mass+KL 提供了更软的分布级别约束，然而均匀地处理所有跨 token 偏移，没有区分视觉一致的重新分配和向独立于视觉的 token 的有害转移。相比之下，VC-OT 实现了可比的 VD 保留，同时使用区域感知传输和依赖分层传输惩罚来调节不同的重新分配路径，从而产生了较低的 AvgF 和最高的全局 AvgAcc。

结论
这项工作引入了多模态无监督持续后训练（MU-CPT），其中 MLLMs 在没有带标签答案的情况下从非平稳多模态数据中持续学习。我们将 token 级别的视觉依赖（VD）确定为跨模态归因遗忘的内在信号，并提出了 VDA，它通过 VC-OT 保留旧任务的 VD，并通过 VMA 促进基于视觉的适应。在六个任务上的实验表明，我们提出的框架减少了遗忘，同时保留了强大的可塑性。
