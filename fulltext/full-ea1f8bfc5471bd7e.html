美国取消出口管制，Anthropic全球恢复...

📅 2026-07-02 📄 VentureBeat AI 🔗 原文链接

原标题：Anthropic is bringing back Claude Fable 5 globally after US lifts export control order — where can enterprises access it?

中文摘要： 美国撤销出口管制令后，Anthropic在全球范围内恢复了其最强AI模型Claude Fable 5的访问权限。此前因亚马逊报告其存在安全漏洞，美国政府于6月12日发布紧急管制令导致该模型被停用。经过技术改进与政治斡旋，Fable 5重返市场，但网络安全模型Mythos 5仍受限。此次事件凸显了企业依赖封闭API模型的脆弱性，促使企业考虑采用本地化或开源模型作为替代方案，以应对未来潜在的监管风险。

昨晚，美国商务部撤销了此前围绕该模型发布的紧急出口管制令，今天，Anthropic 正在恢复全球访问其迄今为止发布的性能最强的通用 AI 模型 Claude Fable 5。

2026年6月12日发布的美国出口管制令，导致 Anthropic 在两款模型首次推出仅几天后，就暂停了全球范围内对 Fable 5 及其限制较少的网络安全对应模型 Claude Mythos 5 的所有访问。

现在，Fable 5 再次向全球用户在主要的 Anthropic 生态系统中开放，包括 Claude Platform、Claude.ai、Claude Code 和 Claude Cowork。官方的 X 上的 Claude 账号于美国东部时间2026年7月1日下午3:31宣布了该模型的回归。

对于利用云超大规模计算平台的组织，Anthropic 表示正在“尽快”在 Amazon Web Services、Google Cloud 和 Microsoft Foundry 上重新启用访问权限。到目前为止，VentureBeat 的研究还无法确认这些外部云超大规模计算平台是否已经恢复了该模型。

Mythos 5 的情况则有所不同。一封发布在社交网络 X 上的信件据称是美国商务部长霍华德·卢特尼克写给 Anthropic 高管汤姆·布朗的，信中称不再需要 Fable 和 Mythos 的出口、再出口或国内转让许可证。

但 Anthropic 自己网站上的重新部署帖子仅表示，在6月26日获得政府批准后，Mythos 5 的访问权限已对“部分美国组织”恢复。该公司表示，正在继续与政府协调，以扩大其选择性加入的网络安全测试计划 Project Glasswing 中更广泛的国内外合作伙伴的访问权限。

这使得 Mythos 5 处于一个中间类别：在法律上已免于紧急出口管制令，但并未普遍提供。目前的限制似乎来自于 Anthropic 将 Mythos 保留在审查访问模型之后的决定，而美国政府仍在审批、标准和扩展方面发挥作用。

商务部长霍华德·卢特尼克在 X 上发帖表示，Anthropic 和政府“密切合作”以“分析和批准 Fable 5”，而白宫办公厅主任苏西·怀尔斯也在 X 上发帖，将这一决定围绕美国 AI 领导地位和部署速度进行了阐述。

怀尔斯写道，美国是“AI 竞赛中无可争议的赢家”，并补充说共同的优先事项是“尽可能快速、安全地部署最好的技术”。

这一逆转是在网络安全领导者和 AI 政策专家对出口管制令表示担忧之后发生的，他们认为美国有可能在给中国 AI 实验室可乘之机的同时削弱自己的产业。前 Facebook 安全主管亚历克斯·斯塔莫斯称 Fable 的限制是“美国的一个巨大乌龙球”，警告称安全公司可能会被驱使转向中国模型，而其他批评者则表示，这种所谓的“临时性”监管干预使得对美国 AI 平台的依赖看起来像是一种战略负担。

然而，为了在出口管制令中断事件后激励企业立即采用，Anthropic 正在执行一项持续到7月7日的临时推广计划。

一些 AI 领域的影响者已经在尝试为企业和开发者提供指导，说明如何在 Fable 5 为期7天的折扣价/订阅包含促销期间最大化其使用量：

危机编年史：从发布到锁定

围绕该模型的反复无常的监管周期突显了当前企业软件供应链面临的波动性。这场危机在三周的快速时间线内展开：

  • 2026年6月9日：Anthropic 发布 Claude Fable 5 和 Mythos 5。早期企业案例研究报告了重大的性能提升。例如，Stripe 报告称，Fable 5 将跨越5000万行 Ruby 基础设施的整个代码库迁移压缩到了一天内——这是一个估计需要团队手工完成两个多月的项目。
  • 2026年6月12日： 美国东部时间下午5:21，美国政府发布出口管制指令，援引国家安全权力。该命令禁止任何外国公民访问该模型，无论其在美国境内还是境外。由于缺乏在 API 层面实时验证用户国籍的机制，Anthropic 被迫为所有客户拔掉插头以确保合规。Anthropic 表示对所有其他 Anthropic 模型的访问未受影响。
  • 2026年6月13日至25日： 企业用户和开发者面临突然的中断，迫使采用 Fable 5 或 Mythos 5 的工作流退回到 Opus 4.8 等旧模型。随着 Anthropic 公开反对，紧张局势达到顶峰，该公司辩称，因为一个狭窄的越狱发现而撤下一个主要的商业模型可能会“实质上阻止所有前沿模型提供商的所有新模型部署”。
  • 2026年6月26日： 美国政府允许 Anthropic 向一组受信任的美国组织恢复 Mythos 5 的访问权限，部分撤销了6月12日的命令。Anthropic 表示正在为这些组织恢复访问权限，并继续与政府合作扩大 Mythos 5 的访问范围，并使 Fable 5 再次普遍可用。
  • 2026年6月30日： 商务部长霍华德·卢特尼克致信撤销了6月12日对 Mythos 和 Fable 的出口管制许可证要求。该决定移除了紧急法律封锁，但 Anthropic 的推出仍然对这两个模型区别对待：Fable 5 全球回归，而 Mythos 5 仍然仅限于通过 Glasswing 和相关受信任访问渠道批准的用户。

技术催化剂：亚马逊漏洞报告

联邦政府的迅速干预源于亚马逊研究人员的一份报告，该报告描述了一种绕过 Fable 5 安全防护的方法。这对 Anthropic 来说是一个残酷的讽刺，因为亚马逊是该初创公司最初也是最大的支持者之一，投资高达80亿美元，而且两家公司此前曾合作改进亚马逊的 Alexa+ 语音助手。

根据 Anthropic 的说法，该技术促使 Fable 5 识别软件漏洞；在一个案例中，该模型生成了代码，演示了如何利用相关漏洞。

当报告送达政府官员手中时，引发了对公开 AI 大语言模型（LLM）攻击性网络能力的警报。Anthropic 反驳称，该漏洞利用并未触及独特的“Mythos 级别”网络能力，并指出其自身的测试发现其他模型——包括 Claude Opus 4.8、OpenAI 的 GPT-5.5 和 Moonshot 的 Kimi K2.7——也能识别相同的漏洞。Anthropic 还表示，它测试的每个模型都能产生与 Fable 5 相同的漏洞利用演示。

为了打破监管僵局，Anthropic 开发了一种改进的自动化安全分类器，专门经过训练以捕获和中和亚马逊的技术。经商务部人工智能标准与创新中心（CAISI）测试，更新后的分类器在超过99%的情况下成功阻止了该特定技术。

Anthropic 明确警告企业客户，这种安全执行会带来运营成本。由于新的分类器需要扩大的“安全边际”来捕获模糊的边缘情况，良性的编码和调试请求可能会更频繁地被标记。当提示被安全层阻止时，活动会话会自动降级，将请求路由到 Opus 4.8。

在 X 上的一篇帖子中，Anthropic 负责 Claude Code 的技术团队成员 Thariq Shihipar 表示，Anthropic 正在“继续完善这些防护措施，以更好地区分真正的滥用和合法请求，并减少误报。”

幕后外交：换防

将 Fable 5 带回商业市场的突破既是技术性的，也是政治性的。据 WIRED 报道，Anthropic 最初辩称，政府的安全担忧被夸大了，没有任何前沿模型提供商能够保证零越狱。

据 WIRED 的报道，这一论点让政府感到沮丧。最近几周，Anthropic 改变了策略，不再关注消除越狱的理论不可能性，而是更加关注建立更强的防护措施并满足政府的运营担忧。

WIRED 报道称，Anthropic 首席执行官 Dario Amodei 最近在会议中被布朗取代，官员们在个人层面上更喜欢布朗。布朗也是卢特尼克6月30日商务部信件的收件人。

在布朗的指导下，Anthropic 似乎已经从争论模型安全的绝对限制，转向承诺政府要求的扩大防护措施和合作框架。

由此产生的商务部信件描述了 Anthropic 的几项承诺。根据许可条款，Anthropic 已同意：

  1. 主动检测和应对与模型相关的安全风险。
  2. 就 Mythos、Fable 和未来模型的协议、标准和发布与美国政府合作。
  3. 向美国政府通报恶意活动。

此外，Anthropic 表示将扩大政府对前沿模型的发布前访问和评估，在发现重大越狱或滥用模式时迅速共享信息，为政府联合研究投入资源，并努力实现共同的行业安全标准。

美国商务部明确保留在情况发生变化或 Anthropic 未能履行其承诺时重新评估这些权限并重新实施许可证要求的权利。

主权考量：企业 AI 的经验教训

Claude Fable 5 两周的停用暴露了集中式、封闭 API 模型对现代商业基础设施的脆弱性。它表明企业自动化管道仍然容易受到突发监管转变和供应商合规要求的影响。

科技界的反应突显了向硬件和模型主权迈进的更广泛推动。在最初关闭之后，知名科技人物表达了对这种中心化的担忧。AI 创始人 Alex Finn 将 Anthropic 的冻结描述为一个重大的“警钟”，敦促开发者大力投资本地、开放权重基础设施，以使运营免受联邦波动的影响。正如 Finn 在社交媒体上指出的：

“没有任何公司或政府能够夺走你的本地模型。”

对于企业架构师来说，Fable 5 的回归要求在部署时采取平衡的方法：

  • 前沿性能优势： 根据 Anthropic 的发布材料和早期客户案例，利用像 Fable 5 这样的封闭模型可以在代理编码、长上下文工作、文档推理和多步骤企业自动化方面提供最先进的能力。
  • 缓解数据权衡： 访问 Fable 5 意味着接受 Anthropic 对受保护模型的强制性30天数据保留要求。Anthropic 表示，提示和模型输出默认保留至少30天，然后自动删除，除非它们是安全调查的一部分或出于法律原因必须保留。受高度监管的金融、医疗和法律集团必须评估此遥测窗口是否符合其数据隐私要求。

事实是，美国和全球的企业在前沿级 LLM 方面拥有比以往更多的选择，特别是过去几个月新推出的强大、开放权重的中国替代品，这些替代品可以下载、在本地或虚拟私有云上运行，并根据任何企业的喜好进行定制。

MiniMax M3将前沿层级的编码和代理性能与100万 token 的上下文窗口和原生多模态相结合。Z.ai 的 GLM-5.2 的基准测试结果在 SWE-bench Pro 和几项长周期编码测试中超过了 OpenAI 的 GPT-5.5，并在 FrontierSWE 和 MCP-Atlas 上接近 Claude Opus 4.8。美团的 LongCat-2.0也定位于企业用途，拥有100万 token 的上下文窗口、MIT 许可证，并通过其在 OpenRouter 上的 Owl Alpha 运行获得了强劲的早期开发者吸引力——尽管正如我们报道的那样，完整的权重仍被列为“即将推出”。

与此同时，Anthropic 在国内最大的竞争对手 OpenAI 仍因美国政府的压力而难以广泛发布其最新模型。该公司表示，其最新、最强大的模型 GPT-5.6 Sol、Terra 和 Luna——上周发布——正在向一小群受信任的合作伙伴进行有限的预览，此前 OpenAI 向美国政府预览了这些模型及其功能，政府要求分阶段推出。

OpenAI 表示仍计划更广泛地提供这些模型，但在其公告中辩称，“我们认为这种政府访问流程不应成为长期的默认做法。它使得需要这些工具的用户、开发者、企业、网络防御者和全球合作伙伴无法获得最好的工具。我们采取这一短期步骤，是因为我们相信这是在未来几周内实现更广泛可用性的最强有力的途径，同时我们将与政府合作制定网络安全行政命令框架以及未来模型发布的可重复流程。”

相关的行政命令由唐纳德·J·特朗普总统于2026年6月2日签署，呼吁各联邦机构合作制定一个对新 AI 模型的能力进行基准测试和评估的流程，以确保它们安全且适合广泛发布，该流程预计需要30天（这似乎表明各机构应在明天，即2026年7月2日提供其流程。）

前沿模型的发布开始看起来不再像普通的产品发布，而更像是由美国国家安全审查塑造的协商部署——这种转变可能会减缓美国的分发速度，即使中国竞争对手正通过开放权重和低成本渠道积极进取。

为了保护运营免受未来监管锁定的影响，企业技术领导者正转向与模型无关的回退架构。

Fable 5 已正式重新上线，但 governing 其发布的格局已发生了根本性的转变。
