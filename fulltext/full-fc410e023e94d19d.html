原标题：Anthropic launches Claude Ship, letting AI agents review, fix, and approve code changes

中文摘要： Anthropic 推出 Claude Ship 工具套件，包含已正式上线的 Code Review 以及处于测试阶段的 PR Steward 和 Claude Approvals 两个智能体。该工具可自动审查、修复代码变更，并能依据团队以自然语言编写的策略自动批准代码变更，以缓解 AI 大量生成代码带来的审查与批准瓶颈。团队可控制运行范围、审查深度设置及需上报人工决策的变更，并可先以仅观察模式运行。目前面向 Claude Team 和 Enterprise 套餐的 GitHub 用户推出。

Anthropic 宣布推出 Claude Ship，这是一套用于自动化代码审查、修复以及常规代码变更批准的 AI 智能体工具。

后者是这套新工具中更有趣的部分，因为在此之前，AI 编码工具就已经提供了代码审查功能。Claude Ship 的值得关注之处不仅在于它能够审查提议的代码变更、识别并解决问题，还在于它包含一个可以根据开发团队设定的策略自动批准代码变更的智能体。

图片来源：Anthropic

此次发布正值 AI 编码智能体生成大量代码的能力日益增强之际，这导致代码变更在上线前的审查和批准环节出现瓶颈。借助 Claude Ship，其理念是将开发过程中涉及的工作进一步自动化，本质上是将批准权限委托给 AI 智能体本身。

公司的一篇博客文章解释道：“大多数团队希望由人来批准每一项变更，当每一行代码都由人编写时，这很容易跟上节奏。但现在很多开发者都在使用智能体进行构建。在 Claude Code 团队，我们的大部分代码都是由 Claude 编写的，我们希望 PR 之后的每个环节也能以同样的速度推进。”

Claude Ship 目前以测试版形式推出，允许早期用户使用它来审查拉取请求（PR），然后决定哪些内容可以合并。

这项新产品由已正式上线的 Code Review，以及目前处于测试阶段的两个新智能体组成：PR Steward 和 Claude Approvals。PR Steward 专注于解决诸如 CI 检查失败、合并冲突以及来自 Code Review 的反馈等问题。它还会在每次推送后发表评论，说明它做了哪些更改，以及必要时如何回滚。

图片来源：Anthropic

而 Claude Approvals 则会应用团队以文件形式写入代码仓库的批准策略。这一批准流程可以整合各种信号，包括 Code Review 的发现结果或公司自有的分类器，策略以自然语言编写。

由于该产品仍处于测试阶段，Anthropic 建议先以仅观察模式运行批准功能。团队也可以选择仅从一个代码仓库开始，并设置月度支出限额，以便更好地控制整个流程。

Anthropic 表示，团队仍然可以掌控 Claude Ship 的运行位置、使用哪种审查设置（例如 Quick、Standard 或 Deep），以及哪些变更应上报给人工进行决策。

Claude Ship 正在向 Claude Team 和 Enterprise 套餐用户推出，适用于 GitHub 上的代码仓库。Code Review 已正式上线，而 PR Steward 和 Claude Approvals 仍处于测试阶段。
