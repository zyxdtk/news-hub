一封被遗漏的客户邮件、一张逾期的发票、一场时间安排错误的会议，每一项都可能产生无人计划去做的额外工作。Anthropic 希望其最新应用能够在企业主或员工想到提出之前，就发现这些问题并着手处理。

该公司于周三发布了 Claude Duet，这是一款能够监控已连接应用程序、呈现优先事项并在后台执行任务的 AI 助手。Anthropic 围绕其 Opus 5.5 模型设计了该产品，并通过候补名单向美国 Pro 和 Max 计划订阅者开放研究预览版。

Duet 通过适用于 iOS 和 Android 的独立移动应用以及 claude.ai 运行。据 Anthropic 介绍，它可以准备晨间简报、调查未付发票、起草客户跟进内容、构建财务预测以及创建 Web 应用程序。其远程计算环境使其能够在用户合上笔记本电脑或关闭手机后继续工作。

对于企业技术领导者而言，此次发布具体展示了 Anthropic 希望 AI 智能体如何参与日常业务运营：从多个系统提取信息、判断哪些事项值得关注，并准备好供人审批的行动。

但此次初始发布面向专业人士和较小规模的企业。Anthropic 的公告并未将 Duet 的使用权限扩展到 Team 或 Enterprise 订阅，也未宣布 Duet API 或给出企业推广时间表。

一个主动发起工作的助手

Duet 的核心主张是：用户不必主动发起每一次交互。

Anthropic 表示，该应用会根据已连接的服务生成每日简报，然后定期检查这些账户中是否有值得通知的动态。用户可以调整它标记哪些主题以及希望接收更新的频率。

这些检查每隔几小时进行一次。Anthropic 表示，更频繁的监控会更快消耗订阅者的使用额度——对于考虑时间敏感型工作流的企业来说，这是一个重要的限定条件。Duet 的后台活动并不等同于持续的实时监督。

用户通过文本或语音在持久对话中进行交流。Duet 沿用了账户记忆、技能和现有的应用连接，使其能够基于用户已向 Claude 提供的上下文开始工作。

在该界面之下，Duet 运行于一个配备浏览器的虚拟机中。它会判断所请求的任务需要哪些应用程序和步骤，远程执行工作，并在完成或需要决策时通知用户。

这种架构可能使其适用于跨越多个系统的工作：例如收集账户信息、生成文档并准备后续跟进。实际的考验在于，它在系统之间切换时能否可靠地保留相关细节。

Duet 与 Remote Control 及现有 Claude 应用的区别

Claude 用户已经可以通过多种方式用手机工作，而这些体验与 Duet 存在重叠。

Claude Code Remote Control 将移动应用或浏览器连接到在用户电脑上执行的编码会话。手机提供对该会话的访问；宿主机仍然负责代码执行和本地文件访问。Remote Control 支持 Pro、Max、Team 和 Enterprise 订阅，后两者需要组织管理员启用。

Dispatch 是 Cowork 的一项早期功能，允许用户从手机向桌面端的 Claude 发送任务。它要求那台电脑保持唤醒状态且桌面应用正在运行。Anthropic 现在表示 Dispatch 已对新用户关闭，但现有用户可以继续使用。

但仅凭云端执行并不能将 Duet 与当前的 Claude 应用区分开来。Anthropic 更新后的 Cowork 文档显示，自 10 月 6 日以来，新的 Pro 和 Max 任务已在其服务器上运行。这些任务在笔记本电脑合上后仍会继续，定时任务也不需要任何设备保持在线。Anthropic 还正在将聊天和 Cowork 整合为一个统一的 Claude 体验。

Duet 的差异化主张在于：独立应用、持续对话、对已连接账户的例行检查，以及对何时打断用户的判断，这几者的结合。Remote Control 提供对本地编码智能体的访问；云端 Cowork 执行被请求或定时安排的任务；而 Duet 的目标是从一开始就发现有值得关注的工作。这是一种产品侧重点，而非证明每一项底层能力都为 Duet 所独有。

从逾期发票到薪资发放和采购

Anthropic 表示，Duet 可以利用通过 Claude Marketplace 提供的 6000 多个连接器和插件。

其公布的工作流涵盖多项业务职能。Duet 可以查看 QuickBooks 或 Stripe 记录中的未结发票并准备催款提醒，利用 HubSpot 的客户信息起草外联内容，并协助通过 Docusign 组装协议以供审阅和签署。

在人事运营方面，Anthropic 描述了 Duet 可以根据员工工时和调整项（包括奖金和报销）准备并运行 Gusto 薪资发放。Duet 还可以起草招聘启事，并在用户审阅和授权后将其发布到 LinkedIn。

营销和商务方面的例子包括开发 Canva 营销活动，以及帮助配置或维护 Shopify 商店。Anthropic 表示，功能更强的店面设计界面（包括发布前预览）将于晚些时候推出。

该产品还支持通过 Stripe 的 Link 钱包和 Shopify 的 Shop Pay 进行购买。在 Link 流程中，Duet 会与用户确认拟购买的商品，Link 请求支出授权，付款则使用虚拟卡，从而保护底层卡号的隐私。

Anthropic 还计划允许 Duet 在获得用户许可的情况下使用存储在 1Password 中的凭证。该功能即将推出。

对于技术采购方来说，这些集成的广度带来了一个显而易见的机会：减少业务应用程序之间的手动交接。这也使得附加在每个连接上的权限变得至关重要：足以汇总发票的访问权限与发起付款的权限是两回事。

人工审批仍是工作流的一部分

Anthropic 在准备工作与采取有重大影响的行动之间划定了明确的界限。

Duet 可以独立查看信息和组装草稿。根据公告，在发送消息、支付款项、签署协议或删除材料之前，它会展示拟执行的操作并请求批准。

某些活动即使获得授权也被禁止，包括证券交易和金融账户之间的转账。用户还可以撤销应用程序连接。

在评估薪资发放和采购示例时，这些区别非常重要。Anthropic 提出的是一款能够在审批约束内准备和执行业务工作流的软件，而不是赋予其对公司支出的无限制控制权。

该公司还描述了一个专用的敏感信息分类器，它与安全指令配合，对消息进行评估以帮助防止不当披露。Anthropic 表示，该系统会阻止共享其限制级别最高的信息类别，包括支付卡号和政府颁发的身份证件号码。对于某些其他敏感材料（如健康和个人财务信息），只有在明确指示后才允许披露。

其他保障措施包括凭证隔离（旨在让密码和身份验证令牌不进入模型的直接视野）、行动审批分类器，以及针对提示注入（隐藏在智能体所遇内容中的恶意指令）的防御。

Anthropic 表示，内部安全团队和一家外部公司对 Duet 的基础设施进行了测试，其公开的漏洞赏金计划也覆盖该产品。不过，这些只是对保障措施的描述，并不能证明该智能体会避免每一次未经授权的操作或信息泄露。

定价中包含后台工作的权衡

在预览期间，Anthropic 将 Duet 包含在 Pro 和 Max 订阅中，未宣布单独的 Duet 收费。其公布的订阅价格显示，Pro 为每月 20 美元或每年 200 美元，Max 起价为每月 100 美元。

订阅者与 Duet 共享其现有的 Claude 使用额度。自动检查会消耗部分额度，而构建财务模型或演示文稿等任务则需要额外的工作量。

这就产生了一个超出订阅价格之外的预算问题：在扣除智能体持续监控的消耗后，用户能获得多少有用的产出？

Anthropic 在 Duet 公告中没有提供任务级别的成本估算、量化的生产力提升或基准测试结果。因此，评估该预览版的组织需要自行衡量完成的工作量、纠错时间和额度消耗。

初始的套餐资格对治理也很重要。Anthropic 的定价页面将审计日志和自定义保留控制等组织级功能列在 Enterprise 套餐下。买家不应假设个人订阅上的 Duet 预览版具备相同的控制措施。

Muse、Dots、Instinct 和 Tolan 的定位

Duet 进入的是一个已存在的持久型个人智能体市场。与其最接近的对比对象包括 Meta 的 Muse 和 OpenAI 的 Dots，两者都已承诺在专用云端计算机上提供主动协助和执行能力。

Meta 于 9 月推出 Muse，侧重于日常任务、购物、旅行和长期目标。用户通过其应用或 WhatsApp 使用它。与 Duet 一样，它可以在应用关闭后继续工作，并在执行敏感操作前寻求许可。Meta 还描述了活动历史记录和一个单独的监控智能体来检查外发操作。因此，人工审批和云端隔离本身并不能构成 Duet 的差异化优势。

Muse 的快速普及有助于解释这场竞争的利害关系：据雅虎财经 10 月 20 日报道的 Sensor Tower 估算数据，该应用自 9 月 8 日上线以来已获得 1090 万次下载（其中美国 1020 万次），10 月 16 日的日活跃用户达到 250 万。这种早期的市场吸引力表明，消费者对 AI 的需求已超越回答问题，转向执行任务——随着 OpenAI 的 Dots 和 Anthropic 的 Duet 的推出，这一转变正变得更加清晰。

OpenAI 的 Dots 与 Duet 的专业定位重叠尤为紧密。OpenAI 描述了由 GPT-6 Astra 驱动的智能体，它们可以调查问题、构建应用程序，并在对话之间推进项目。它们通过 ChatGPT 以及包括 Slack 和 Teams 在内的消息渠道工作。OpenAI 的访问文档显示，其面向 Pro 和 Business Premium 订阅者，另有管理员启用的 Enterprise 测试版。这为 Dots 提供了一条明确的组织级访问途径，而 Duet 的初始公告并未提供这一点。

Instinct 的竞争点在于通过熟悉的通信方式进行委托：用户发短信或打电话给一个能够操作手机和电脑来处理杂事的助手。其示例侧重于食品杂货、交通和预订。它来自另一家独立公司 Spear Street Technology，而非 Meta。

由 Portola 打造的 Tolan 则是一个较为间接的对比对象。其基于角色的体验侧重于对话、记忆、定期问候以及对日常目标的帮助。这些特质与个人助手有重叠，但其公开资料并未展示一套能够操作薪资发放、客户管理工具或其他业务应用程序的等效系统。因此，不应将其视为 Duet 业务工作流的已验证替代品。

定价方面也存在显著差异：Duet 每月 20 美元的入门价格低于 Dots 最低每月 100 美元的个人 Pro 订阅，但 Muse 提供免费入门选项。对于现有订阅者来说，计算方式则有所不同，因为 Duet 和首个 Dot 都已包含在更广泛的订阅中。

对于企业买家来说，有意义的比较远不止智能体能否通过手机回答问题。它还包括：能否访问经批准的系统、能否解释提议的变更、能否保留可供审查的历史记录，以及能否在可预测的额度内完成有用的工作。Duet 的发布使这些比较成为可能，但没有提供任何正面交锋的证据表明它能更准确或更便宜地完成同样的任务。

早期示例，可靠性仍有待证明

Anthropic 的发布示例强调的是一些小的运营改进，这些改进可能在整个工作日中不断累积。

该公司描述了房地产经纪人 Jess Provencher 使用 Duet 发现一处录入错误日期的房产带看安排。据 Anthropic 介绍，经营着拥有约 110 名员工的 Shahs of Kabob 餐厅的老板 Amin Ebrahimi 已将其用于会计、客户服务和营销。

“它把一切都整合在一起，”Ebrahimi 在该公司的公告中说。“我不需要打开 100 个标签页。”

这些都是公司挑选的客户案例，而非对准确性或业务影响的独立评估。Anthropic 承认，预览版可能会误解对话内容，或对问题的紧急程度判断不当。该公司还表示，Duet 目前还无法向用户展示其浏览器，限制了用户对其这部分工作的可见性。

对于企业团队来说，合理的初步评估应聚焦于结果易于核查的有界任务：简报准备、发票跟进草稿或会议协调。影响更大的工作流则需要更仔细地审查审批行为、权限设置，以及当出现问题时员工如何还原事情的经过。

Duet 为企业提供了一种测试途径：一个主动发起工作的助手能否减少管理工作所需的注意力。其价值将取决于这些干预有多少帮助——以及要信任其结果，还需要多少监督。
