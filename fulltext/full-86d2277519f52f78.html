摘要
预训练在LLM训练的总计算成本中占很大比例。然而，噪声主导的梯度和高度病态的损失景观带来了严峻的挑战。尽管诸如AdamW和Muon等现代自适应优化器在大规模预训练中取得了巨大成功，但它们对梯度归一化的依赖对病态曲率的缓解有限。沿着平坦方向（小特征值对应的特征方向）的进展主导了最终的损失下降，但该进展仍然相对缓慢。为了增强沿平坦方向的训练动力学，我们提出了一种带有球面约束的曲率条件多尺度动量方法，为LLM预训练提供了稳定的加速。这种仅应用于平坦方向的多尺度动量，将用于降噪的慢衰减分量与用于快速适应曲率的快衰减分量相结合，利用了它们互补的优势。至关重要的是，我们采用球面约束技术来防止参数膨胀和有效学习率过快衰减，如果不采用该技术，这些问题将因简单的组合而产生。大量实验表明，所提出的方法在多种架构（稠密、MoE）和模型规模（0.12B–2.3B参数）上显著加速了Muon。在理论上，我们验证了加速效果，并深入探讨了平坦方向多尺度动量背后的设计原则。

1 引言
在大语言模型（LLM）预训练阶段，优化器是影响训练效率和持续扩展的最关键因素之一。LLM预训练面临几个固有的挑战。由于训练token总数远远超过每步的批次大小，噪声主导了随机梯度：其幅度远远超过真实的梯度信号。此外，损失景观高度非凸且病态，其特征是存在大量平坦方向和少数尖锐方向。值得注意的是，沿平坦方向的训练动力学主要驱动了最终的损失下降[33, 42]。由于学习率受到沿尖锐方向的最大特征值和噪声水平的限制[3, 5]，在这些关键的平坦方向上的进展仍然缓慢，阻碍了整体训练并可能破坏稳定性。

诸如AdamW [14, 22]和Muon [13, 20]等自适应优化器通过梯度统计的坐标级或块级归一化，部分缓解了病态问题。它们在工业规模的LLM训练中展示了稳定性和良好的扩展行为。然而，这种归一化（白化）仅部分补偿了病态曲率，沿平坦方向的进展仍有改进空间。

最近的工作[37, 40, 54, 56]试图通过估计平坦方向并手动放大沿这些方向的学习率来解决这个问题。然而，这种方法也放大了沿平坦方向的随机噪声，导致改进有限并可能破坏训练的稳定性。这引出了一个问题：
如何通过降低梯度噪声来加速沿平坦方向的训练动力学？

我们通过一种针对平坦方向量身定制的动量机制来解决这个问题。我们的贡献总结如下：
• 算法设计。我们提出了一种球面约束的多尺度动量方法，该方法结合了快衰减和慢衰减动量分量，以增强沿平坦方向的训练动力学。该多尺度动量是曲率条件的：它在平坦方向激活以实现稳健的降噪，在尖锐方向停用以保持稳定性。然而，单独使用它会导致范数膨胀和有效学习率崩溃。为了解决这个问题，我们引入了带有平行传输的球面约束来作用于权重，这防止了范数膨胀，并确保了动量在不同切空间中的正确继承。它们共同释放了多尺度动量在LLM预训练中的潜力。
• 实证评估。我们在广泛的LLM预训练设置中评估了所提出的方法（通过在基础优化器名称后添加后缀“M”来表示，例如MuonM），涵盖了稠密和MoE架构，模型规模从0.12B到2.3B，以及多样的学习率调度（余弦衰减和WSD）。结果表明，MuonM始终优于Muon，具有更低的最终损失。值得注意的是，这些损失收益在扩展的token预算下依然存在，表明其对更长训练周期的良好可扩展性。
• 理论分析。最近的研究[16, 19, 25]表明，适当设计的线性回归模型可以作为LLM预训练动力学的有效代理，捕捉损失演变的关键趋势。在此框架内，我们分析了沿平坦方向注入慢衰减动量如何加速优化。我们的分析表明，它能够更快地遗忘累积的噪声，同时提高信号学习率，从而导致更低的最终损失。这些发现支持了平坦方向多尺度动量背后的设计直觉。

2 预备知识与相关工作
深度学习中的景观几何与训练动力学。实证研究[10, 35, 48, 51]表明，深度学习中的损失景观高度病态。具体而言，Hessian矩阵具有一小部分大的正特征值（相应的特征空间被称为“尖锐方向”）和大量接近零和负的特征值（相应的特征空间被称为“平坦方向”）。最近的研究[6, 33, 42]表明，这种景观结构驱动了快-慢训练动力学：在尖锐方向上发生振荡行为而不发散，而在平坦方向上则取得缓慢但持续的进展，最终主导最终的损失下降。因此，加速沿平坦方向的优化至关重要，这正是我们工作的重点。

用于LLM预训练的高效自适应优化器设计。自适应优化器已成为大规模LLM预训练不可或缺的工具。AdamW [22]因其简单有效的坐标级预条件而成为事实上的选择。然而，其对角预条件器固有地限制了其捕捉全曲率中跨参数相关性的能力。

Muon [13, 20]则对参数块应用矩阵级预条件，展现出良好的收敛速度和扩展行为。最近的方法，如[18, 28, 36]，进一步开发了结构化矩阵预条件器以更好地近似曲率相关信息。我们的工作与这一研究方向互补。我们不改进预条件器结构，而是专注于动量的设计。

自适应优化器的改进动量机制。Heavy Ball动量[30]已被现代自适应优化器广泛采用以促进训练。在此基础上，Nesterov型动量[47, 50]提供了额外的稳定性能提升。最近，多尺度动量被引入以平滑和加速动量方法的动力学。AggMo [23]线性组合了具有不同衰减率的多个动量缓冲区以抑制振荡。AdEMAMix [26]通过在神经网络训练中将多尺度动量与Adam的预条件器集成来扩展这一方法。GPA [9]采用额外的原始平均来平滑Nesterov动量的迭代。SODA [29]和EMA-Nesterov [49]分别通过原始外推和前瞻方向的指数移动平均引入额外动量，以在预训练中实现加速，同时兼容各种基础优化器。
与这些主要由确定性优化驱动的方法不同，我们的工作关注其在噪声主导的随机环境下的方差缩减作用，以及在具有不同曲率（尖锐和平坦）区域中不同时间尺度上的独特行为。此外，我们在附录D中提供了一个统一的高阶ODE公式，为理解这些不同的算法形式提供了连续时间视角。

控制有效学习率：从权重衰减到球面约束。现代LLM中的归一化层引入了冗余的自由度，使得仅靠学习率不足以完全表征参数更新速度。例如，形式为W1(γ⊙Norm(W2x))的RMSNorm层表现出径向冗余结构W1 diag(γ)以及关于W2的范数-尺度不变性（当W2可学习时）。这自然促使人们将径向和角度更新分开处理。最近的研究[15, 32, 43, 55]将角度更新率∥∆W∥ F /∥W∥ F视为有效学习率，经验证其在塑造损失轨迹中起主导作用[17, 21, 45]。径向演变决定了权重范数，进而影响有效学习率。权重衰减可以解释为控制由噪声引起的权重范数膨胀，从而防止有效学习率衰减过快。参考文献[8]使用修正的权重衰减系数来稳定权重范数。为了实现更精细的控制，最近的一些方法[2, 12, 43, 46]用直接的权重范数约束代替了权重衰减，并在LLM预训练中展示出优于权重衰减的良好前景。

3 激励平坦方向多尺度动量的示例
在本节中，我们将说明不同的动量衰减率如何影响随机优化动力学。

3.1 动量通过方差缩减加速平坦方向优化
我们从一个简单的案例开始：在第k次迭代中，随机梯度服从gk ∼ N (µ, Σ2)，具有恒定的真实梯度µ，heavy-ball动量更新为mk = (1 −α )mk−1 + αgk。系数1 −α衡量动量衰减率：较小的α对应较慢的衰减，较大的α对应较快的衰减。
估计器mk具有相同的均值µ和减小的平衡协方差α/(2−α)Σ2。因此，使用较小的α（较慢的动量衰减）允许mk以较低的方差估计真实的梯度信号µ。

3.2 平坦方向多尺度动量：针对投影误差的稳健方差缩减
在实践中，(1)提供的加速受到各种不完善因素的损害，包括对平坦子空间投影估计的误差以及Hessian特征空间中未建模的变化。投影估计误差在尖锐方向引入了部分慢衰减动量，从而破坏了训练的稳定性。同时，Hessian特征空间的持续旋转和交替转换将大量突发性的尖锐方向动量注入平坦子空间。由于平坦区域中的遗忘速率较慢（需要Θ(α −1 flat)步），这种偏差可能会持续存在并引起振荡。

5.2 提出的方法

8 结论与讨论
在这项工作中，我们提出了一种带有球面约束的平坦方向多尺度动量方法来加速LLM预训练。球面约束通过解决多尺度设计固有的有效学习率崩溃问题，为释放平坦方向多尺度动量的加速潜力提供了比标准权重衰减更有效的基础。大量实验表明，我们提出的方法（MuonM）在各种模型架构和训练设置中始终加速Muon，并显著降低损失。我们的结果还表明，球面约束技术作为开发更高效优化器的一般构建块具有广阔的前景。
本研究存在一些局限性和开放性问题。首先，球面约束方法的最优学习率调度仍然是一个开放问题。其次，我们没有研究慢动量的预条件器设计，我们认为这可以进一步加速训练。

Pleftk = msign(fMfastk Prightk) ∈R m×d.

Qk(U) =P TWk SR((Im −P leftk (Pleftk )⊤) U (In −P rightk (Prightk )⊤)),

E 说明性理论分析
E.1 多尺度动量的方差缩减
在本节中，我们通过一个说明性的高斯示例分析多尺度动量的方差，展示了引入慢动量分量的方差缩减效应。考虑
mslowk = (1−α slow)m slowk−1 +α slow gk,
mfastk = (1−α fast)m fastk−1 +α fast gk,
mk =c m slowk + (1−c)m fastk , (44)
其中0 < α slow < α fast ≤ 1且gk i.i.d.∼ N (µ, Σ2)。我们对保持平稳均值的更新mk的平稳协方差感兴趣，即E[m∞] =µ。
令ϵk = gk −µ表示零均值噪声。展开递归，两个动量的噪声分量为
mslowk −µ=Σk j=0 (1−α slow)j αslow ϵk−j , m fastk −µ=Σk j=0 (1−α fast)j αfast ϵk−j . (45)
因此，在平稳状态下，
Cov(mslow∞ ) =Σ∞ j=0 (1−α slow)2j α2 slow Σ2, Cov(m fast∞ ) =Σ∞ j=0 (1−α fast)2j α2 fast Σ2,
Cov(mslow∞ , mfast∞ ) =Σ∞ j=0 (1−α slow)j(1−α fast)j αslowαfast Σ2. (46)
对几何级数求和，可得
Cov(m∞) = [c2 α2 slow / (1−(1−α slow)2) + (1−c) 2 α2 fast / (1−(1−α fast)2) + 2c(1−c)α slowαfast / (1−(1−α slow)(1−α fast))] Σ2. (47)
化简得
Cov(m∞) = [c2 αslow / (2−α slow) + (1−c) 2 αfast / (2−α fast) + 2c(1−c)α slowαfast / (αslow +α fast −α slowαfast)] Σ2. (48)
其中括号内部分记为f(c)。对c求导得
f ′(c) =−2(αfast −α slow)(αfast(2−α slow)−2(α fast −α slow)c) / [(αslow +α fast −α slowαfast)(2−α slow)(2−α fast)] <0, (49)
因为对于0< αslow < αfast ≤ 1和c∈ [0, 1]，每个因子都是正的。因此f在[0, 1]上严格递减。
增加慢动量的权重c会单调减少平稳方差。特别地，两个极限情况是
f(0) = αfast / (2−α fast) (仅快动量), f(1) = αslow / (2−α slow) (仅慢动量). (50)
因此，引入慢动量相对于仅使用快动量，平稳方差最多可减少αslow(2−α fast) / [αfast(2−α slow)] ≈ αslow / αfast倍。
