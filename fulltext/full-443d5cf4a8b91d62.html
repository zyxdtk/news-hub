摘要

我们证明，时空的因果结构可以在执行量子信息任务的学习智能体的记忆中涌现。我们训练了一个基于模型的强化学习智能体，使其最大化在闵可夫斯基时空中与量子场相互作用的局域量子探针之间的量子互信息，而不直接向其提供有关时空度规或因果结构的信息。在学习完成这一任务的过程中，该强化学习智能体构建了一个内部预测模型，其规划器发展出时空特有的零（类光）结构，使我们能够高精度地重建闵可夫斯基度规的因果结构。在此任务中，时空几何由智能体的成功预测和行动获得，为证明时空概念从操作性量子经验中涌现迈出了第一步。

I 引言

广义相对论是我们对时空最成功的描述，迄今已通过了极为广泛的实验检验[64]，然而该理论所描述的几何——通常由洛伦兹度规张量表示，即一个编码时空距离、角度和因果关系的对象[61,14]——在实验中从未被直接获取，而是从与物质和场相互作用的物理系统留下的记录中推断出来的[14,3]。无论是通过因果轨迹族还是局域探测器的响应，每一次观测都只提供有限的操作性信息，必须从中重建底层几何[57,14,47,23,36,52,44,19]。这种操作性观点将重点从几何本身转移到编码该几何的物理记录上，从而引出处于时空重建核心的更广泛问题：什么样的记录足以让观察者恢复底层时空的结构，以及这些记录在多大程度上保留了生成它们的时空的几何信息？

目前已发展出多种方法来尝试回答这些问题，其中基于量子信息的方案与当前工作所考虑的内容尤为相关（下文将进一步介绍）。例如，文献[9]通过使用互信息定义有效距离再拟合涌现几何，从希尔伯特空间因子分解的纠缠结构中重建空间几何。文献[26]主张用相关强度取代时空距离，将抽象关联函数视为基本结构，时空和场可作为其近似描述从中产生。此外，文献[16]分析了在基于纠缠的涌现时空场景中相对距离如何与互信息相关联，同时表明简单的纠缠系统在此类重建中已存在歧义。

相对论量子信息（RQI）可以说是解决这一问题最自然的框架。特别是，Unruh–DeWitt（UDW）探测器[59,13]提供了与量子场相互作用的局域量子系统的简单模型[15,18]，同时保持足够的可处理性，使得所得探测器状态可以使用量子信息理论的工具进行分析[35,41,38]。正是通过这些相互作用，几何和因果关系以及场关联被编码到有限维量子态中，其操作性性质可以被直接研究。因此，UDW系统已成为研究时空结构如何反映在量子信息中的主要工具之一[10]，并产生了多种从探测器数据重建几何量的协议[39,44,52]。

本文采用的视角与上述工作略有不同，我们询问的是：一个仅与嵌入时空中的量子系统所产生的操作性量子数据交互（且对时空没有任何先验知识）的学习智能体，能否自身获得反映生成这些观测的时空几何的内部表示。因此，问题是与相对论量子环境的成功交互是否自然地产生可以从中随后提取该几何的表示。从这个角度看，学习智能体充当了一个具体的操作性观察者，其内部记忆由经验塑造。更具体地说，我们的设置考虑基于模型的强化学习（RL）智能体，其作用于由在时空中执行的量子信息协议的结果所定义的环境。RL将该环境的结构转换为行动记忆，我们可以尝试查询该记忆以确定它是否包含可恢复的度规结构。

我们应用机器学习来回答这一问题是较新的发展，采用相同策略的工作相对较少，使用RL的更是少之又少。例如，文献[65]的作者在纠缠特征上训练模型，使学习到的张量网络几何重现量子多体态的纠缠结构；文献[22,21]的作者在AdS/CFT启发的设置中使用深度学习，从场论或格点数据推断涌现的体度规，最近还使用可解释的神经架构从线性响应数据重建引力度规[20]；最近的全息重建工作使用纠缠熵数据作为体度规机器学习逆问题的输入[1]；在RQI领域，文献[17]使用深度学习来区分场态、检测场热化以及感知时空边界。关于量子增强智能体和量子设置中因果机器学习的工作更进一步，将智能体视为积极参与者，其行动和记录介导了关于量子环境可学习的内容[54]。我们的方法将这种积极参与者思想与RQI设置中的RL相结合，以回答最初的问题，同时也通过关注从行动中学习新概念的智能体特性而与这些其他工作区别开来。在这方面，该问题还与直觉物理学和物理概念学习的工作相关，其中预测模型从经验中获取物理规律性的内部表示，而非访问明确的符号理论[48]。

为了研究这些问题，我们构建了一个探测器生成的环境，其中一个高斯涂抹的UDW探测器保持固定，而另一个探测器在二维时空涂抹中心 𝗑=(x,t) 的网格上平移。它们与(3+1)维闵可夫斯基时空中（固定两个空间维度）的实无质量标量量子场的相互作用，产生了一个变换后的量子互信息目标，该目标是基于模型的RL智能体的唯一奖励，而该智能体对时空没有初始概念。底层时空结构隐式地编码在该奖励中，因此RL智能体必须通过与环境的交互学习环境的预测表示——从而学习时空结构。然后我们询问，支持其成功行为的记忆是否保留了足够的底层操作性量子信息结构，以便从中重建时空几何。为此，我们对学习到的规划器表示应用一个掩码，以最小方式识别类光锥分支，然后拟合一个二次型，其系数给出度规张量分量 g_tt ≈ −0.99988 和 g_tx ≈ 7.79×10⁻⁸（在通过设置 g_xx=1 固定共形自由度之后），零斜率 dx/dt ≈ ±0.99994，与相应的闵可夫斯基值非常接近。由于零结构仅在共形因子范围内确定洛伦兹度规[23,36,14]，这证明了仅为预测和行动而学习的内部表示可以保留足够的操作性信息，以便随后恢复时空的局域共形几何。

本文其余部分组织如下。第II节建立UDW模型的基础和代数量子场论（AQFT）框架，然后推导探测器生成的奖励景观的相关量。第III节简要介绍RL的基础知识并详述学习智能体的架构。学习任务和RL智能体训练过程的细节在第IV节中给出，随后第V节展示从RL智能体记忆中的学习表示重建时空度规。最后，第VI节讨论该框架的含义、局限性和可能的扩展。用于获得结果的代码可在配套的GitHub存储库[31]中找到。

II Unruh-DeWitt模型

UDW模型以具体的方式将量子信息与相对论联系起来，使得基于量子信息的学习任务可以在时空设置中表述。从选择与探测器耦合的时空区域和场态出发，可以确定最终的有限维探测器状态，其关联随后被用于构建奖励景观。RL智能体只能访问由此产生的奖励，而生成该奖励的时空几何和场论量仍然无法直接访问。因此，环境中的每个点对应于探测器2的一个可能时空涂抹中心，分配给该点的值由其通过与场的相互作用诱导的关联确定。

UDW探测器作为量子场和观察者相关粒子内容的探针被引入[59,13,58]。它们在相对论量子信息中的吸引力来自于这样一个事实：有限维量子系统可以在局部与量子场耦合，同时在探测器状态层面保持操作性输出。这使得该模型在研究跃迁概率、场噪声、信号传递、协变性以及探测器响应对开关和局域化的依赖性方面非常有用[35,53,41,38,12]；同时提供了一种将时空属性操作化为量子信息和计算资源的方法，用于纠缠/语境性收割[49,50,32]和相对论量子计算[37,8,40,2,30]。工作还表明探测器模型如何捕获光–物质相互作用的基本特征[34]，以及它们如何扩展到线性化引力设置[45]。

就本手稿而言，我们考虑两个量子比特UDW探测器与(3+1)维闵可夫斯基时空中的实无质量标量量子场 ϕ̂(𝗑) 相互作用，其动力学由克莱因–戈登方程

∇^μ ∇_μ ϕ̂(𝗑) = 0,　(1)

规定，并且可以分解为

ϕ̂(𝗑) = ∫ d³k/√(2(2π³)|k|) (â_k† e^{i(|k|t−k·x)} + â_k e^{−i(|k|t−k·x)}),　(2)

其中 â_k, â_k† 是满足对易关系 [â_k, â_k′†] = δ³(k−k′) 的场阶梯算符。

探测器被建模为具有希尔伯特空间 H₁≅H₂≅ℂ² 的量子比特，每个沿着共动惯性类时世界线 𝗓_d^μ(t)=(t, x_d)，d∈{1,2}，其中 t 是仿射惯性时间参数，也表示探测器的固有时间。沿着每条世界线，每个量子比特具有由自由哈密顿量 Ĥ_d = (Ω_d/2)(𝟙−σ̂_z^(d)) 支配的内部动力学，其中 Ω_d 表示基态 |0_d⟩ 与激发态 |1_d⟩ 之间的能隙，因此 σ̂_z^(d) = |0_d⟩⟨0_d| − |1_d⟩⟨1_d|。此外，每个量子比特在其轨迹附近局域地与无质量标量量子场 ϕ̂(𝗑) 相互作用。在场论的局域描述中（参见例如文献[19]），标量场 ϕ̂(𝗑) 满足对易关系

[ϕ̂(𝗑), ϕ̂(𝗑′)] = iE(𝗑, 𝗑′)𝟙　(3)

其中 E(𝗑, 𝗑′) = G_R(𝗑, 𝗑′) − G_A(𝗑, 𝗑′) 称为因果传播子，G_R(𝗑, 𝗑′) 和 G_A(𝗑, 𝗑′) 分别是场的推迟和超前传播子。因果传播子通过分解

W(𝗑, 𝗑′) = (1/2)⟨{ϕ̂(𝗑), ϕ̂(𝗑′)}⟩{ρ̂_φ} + (1/2)⟨[ϕ̂(𝗑), ϕ̂(𝗑′)]⟩{ρ̂_φ} = (1/2)H(𝗑, 𝗑′) + (i/2)E(𝗑, 𝗑′)　(4)

与场的Wightman函数 W(𝗑, 𝗑′) = ⟨ϕ̂(𝗑)ϕ̂(𝗑′)⟩{ρ̂_φ} 相关联，其中 H(𝗑, 𝗑′) = ⟨{ϕ̂(𝗑)ϕ̂(𝗑′)}⟩{ρ̂_φ} 称为Hadamard函数。由于场对易子与场的恒等算符成正比，显然因果传播子与场的状态 ρ̂_φ 无关。因果传播子编码通过场在不同事件之间传播的信息。另一方面，Hadamard函数包含场的所有状态依赖性（包括量子自由度），因为不同的场态不一定与场的反对易子对易。

量子比特–场相互作用由相互作用绘景中的相互作用哈密顿量密度规定为

ĥ_d(𝗑) = λ_d Λ_d(𝗑) μ̂_d(t) ⊗ ϕ̂(𝗑),　(5)

其中 λ 是耦合常数，μ̂_d(t) = e^{iΩt}|1_d⟩⟨0_d| + e^{−iΩt}|0_d⟩⟨1_d| 是作用于量子比特 d 的时间演化算符 σ̂_x^(d)，而 Λ_d(𝗑) 是时空涂抹函数，它们定义了相互作用在时空中的形状。函数 Λ_d(𝗑) 各自在探测器的轨迹 𝗓_d(t) 附近强支撑。涂抹函数 Λ_d(𝗑) 还定义了场的涂抹版本

ϕ̂(Λ_d) = ∫ d⁴𝗑 Λ_d(𝗑) ϕ̂(𝗑).　(6)

UDW系统从初始状态 ρ̂(t₀) = ρ̂₁₂(t₀) ⊗ ρ̂_φ = ⨂_d² |0⟩_d⟨0| ⊗ ρ̂_φ 开始，其中 ρ̂_φ 被选为场的真空态 |0⟩_φ⟨0|，而 |0⟩_d 是 Ĥ_d 的基态。该状态到最终时间 t 的时间演化由

ρ̂(t) = Û(t, t₀) ρ̂(t₀) Û†(t, t₀),　(7)

给出，其中时间演化算符定义为

Û(t, t₀) = 𝒯_t exp ∫_{t₀}^t d⁴𝗑 ĥ(𝗑),　(8)

其中 ĥ(𝗑) = ĥ₁(𝗑) + ĥ₂(𝗑) 是整个系统的哈密顿量密度，𝒯_t exp 表示关于时间参数 t 的时间排序指数[38]。

我们在本工作中考虑的时空涂抹函数 Λ_d(𝗑) 由

Λ_d(𝗑) = (1/(2πσ_d²)^{3/2}) exp[−(x−x̄_d)²/(2σ_d²) − (t−t̄_d)²/(2T_d²)]　(9)

给出，其中 T_d∈ℝ₊ 是系统 d 的时间宽度，σ_d∈ℝ₊ 是系统 d 的空间宽度，t̄_d∈ℝ 是系统 d 的时间中心，x̄_d∈ℝ³ 是系统 d 的空间中心向量。

场介导的探测器关联已在纠缠收割和相对论量子通信中得到广泛研究，其中已经表明局域探测器可以从真空中提取关联并通过相对论量子场交换量子信息[60,51,49,50,25,55]。该文献区分了对称和因果场关联以及从探测器状态计算的任务相关信息度量。RL智能体学习的环境是两个量子比特探测器与实无质量标量量子场相互作用的RQI设置，RL智能体以奖励函数形式接收的反馈取决于量子互信息：

I(i:j) = S(ρ̂_i) + S(ρ̂_j) − S(ρ̂_ij),　(10)

其中 S(ρ̂_i) 是系统 i 的约化状态 ρ̂_i 的冯·诺依曼熵：

S(ρ̂_i) = −Tr(ρ̂_i log(ρ̂_i)).　(11)

注意，I(i:j) 和 S(ρ̂_i) 都可以用算符 ρ̂_i、ρ̂_j 和 ρ̂_ij 的谱显式计算。

在我们的协议中，我们将考虑探测器具有平凡内部动力学的情况，即 Ω=0。这种情况对于研究涉及非无穷小耦合常数的协议特别方便，因为该模型在这些情况下可以非微扰地求解[28]。事实上，在文献[46]中，两个无能隙探测器的最终状态以标量场 ϕ̂(𝗑) 沿探测器的时空涂抹函数 Λ_d(𝗑) 的涂抹Hadamard和推迟格林函数的闭合形式被求出。特别地，如果探测器相互作用区域通过时空平移相关联（Λ₁(𝗑) = Λ₂(𝗑−𝗏)）并且考虑探测器初始化为基态（ρ̂_d(t₀) = |0_d⟩⟨0_d|），它们在相互作用后某时刻 t 的最终状态 ρ̂₁₂(t) = Tr_φ(ρ̂(t)) 在 σ̂_x 基中由

ρ̂₁₂(t) = (1/4) 矩阵，其元素为：第1行 [1, e^{−H}e^{−2iG₂₁}, e^{−H}e^{−2iG₁₂}, e^{−2(H+H₁₂)}]；第2行 [∗, 1, e^{−2(H−H₁₂)}, e^{−H}e^{2iG₁₂}]；第3行 [∗, ∗, 1, e^{−H}e^{2iG₂₁}]；第4行 [∗, ∗, ∗, 1]　(12)

给出，其中我们定义了 H = λ²H(Λ₁,Λ₁) = λ²H(Λ₂,Λ₂)，H₁₂ = λ²H(Λ₁,Λ₂) = λ²H(Λ₂,Λ₁)，G_ij = λ²G_R(Λ_i,Λ_j)，

其中 H(Λ_i,Λ_j) = ∫d⁴𝗑 d⁴𝗑′ H(𝗑,𝗑′)Λ_i(𝗑)Λ_j(𝗑′)，　(16)

G_R(Λ_i,Λ_j) 类似。

注意在式(12)中，推迟传播子 G_ij 产生非对角相位，而 H 和 H_ij 项与退相干相关。具体而言，H 项决定每个探测器经历的局域噪声，而 H_ij 项对应于它们之间的关联退相干项。相应的约化状态是

ρ̂₁(t) = (1/2) 矩阵 [1, e^{−H}cos(2G₁₂); e^{−H}cos(2G₁₂), 1],　(17)
ρ̂₂(t) = (1/2) 矩阵 [1, e^{−H}cos(2G₂₁); e^{−H}cos(2G₂₁), 1].　(18)

特别地，ρ̂₁₂ 的特征值是

λ_{1,2} = (1/4) − (1/4)e^{−2H}cosh(2H₁₂) ∓ (1/4)e^{−2H}√(4e^{2H}sin²(E₁₂) + sinh²(2H₁₂)),　(19)
λ_{3,4} = (1/4) + (1/4)e^{−2H}cosh(2H₁₂) ∓ (1/4)e^{−2H}√(4e^{2H}cos²(E₁₂) + sinh²(2H₁₂)),　(20)

其中 E_ij = G_ij − G_ji，约化特征值是

Spec(ρ̂₁(t)) = {(1/2)(1 ± e^{−H}cos(2G₁₂))},　(21)
Spec(ρ̂₂(t)) = {(1/2)(1 ± e^{−H}cos(2G₂₁))}.　(22)

我们可以看到，量子互信息仅取决于以下参数：耦合常数 λ、空间涂抹宽度 σ₁=σ₂=σ、时间涂抹宽度 T₁=T₂=T、空间涂抹中心 x̄₂ 和时间涂抹中心 t̄₂。在本工作中，我们将固定 λ、σ、T，同时允许探测器的相对时空位置（编码在 t̄₂ 和 x̄₂ 中）变化。

我们论文的核心思想是允许RL智能体相对于第一个探测器移动第二个探测器，试图最大化两个探测器与场相互作用后的量子互信息。更准确地说，我们将把 t̄₂ 和 x̄₂ 描述为时空网格中的值，构成RL智能体的环境。然后RL智能体通过改变第二个探测器的时空放置来探索环境，基于其通过 t̄₂ 和 x̄₂ 的局域变化改善量子互信息的程度接收奖励函数。此任务更新RL智能体的环境模型并在每一步更新其记忆。我们将在以下两节中更详细地讨论任务结构和RL智能体的模型。

III 强化学习与智能体架构

在本节中，我们将介绍制定学习任务和在下一节分析RL智能体学习表示所需的强化学习（RL）框架和RL智能体架构。我们首先介绍本工作所需的一些RL基础知识，然后描述RL智能体使用的模型架构，其示意图如图1所示。已经熟悉RL的读者可以直接阅读下文的模型架构描述，而已经通晓机器学习的读者则可以直接进入下一节而不失理解。

由于我们对学习时空结构的智能体视角感兴趣，该问题自然地以RL的形式表述。RL的基本智能体–环境交互循环始于智能体观察状态并决定选择一个行动，然后接收奖励作为反馈，最后通过学习更新规则更新记忆函数，其目的是最大化未来奖励[56]。在当前设置中，状态是探测器2的时空涂抹中心，行动是时空网格上的局域位移，奖励是量子互信息的函数，因此RL表述保持了任务的操作性质。

RL任务被形式化为马尔可夫决策过程（MDP），写为四元组 (𝒮, 𝒜, ℛ, P)。这里 𝒮、𝒜、ℛ 分别是状态、行动和奖励空间；我们通常将它们的元素表示为 s∈𝒮、a∈𝒜、r∈ℛ。完整的转移核 P 指定了给定当前状态和所选行动时每个可能的下一状态和奖励的概率：

P(s′, r|s, a) = ℙ(S_{t+1}=s′, R_{t+1}=r | S_t=s, A_t=a),　(23)

其中 S_t、A_t、R_t 表示在时间 t 可以分别从状态、行动和奖励空间取值的随机变量。从这些量中，我们还可以定义状态转移核（我们保留符号 P，但省略其第二个参数）为

P(s′|s, a) = Σ_{r∈ℛ} P(s′, r|s, a)　(24)

以及从状态 s 转换到 s′（s→s′）同时采取行动 a 时交付奖励的期望奖励函数为

R(s, a, s′) = 𝔼[R_t | S_t=s, A_t=a, S_{t+1}=s′] = Σ_{r∈ℛ} r·P(s′, r|s, a)/P(s′|s, a),　(25)

其中 𝔼[·|·] 是条件期望值。RL智能体在某个时间 t 的行为（即给定某个状态它将如何行动）可以由随机策略 π(a|s) = ℙ_π(A_t=a | S_t=s) 描述，RL智能体的目标通常是最大化其期望折扣回报（称为价值函数）

v_π(s) = 𝔼_π[G_t | S_t=s]　(26)

其中

G_t = Σ_{k=0}^∞ γ^k R_{t+k+1}　(27)

称为折扣回报，γ∈[0,1) 称为折扣因子，它控制未来奖励的强度[5,56]；γ 既在标准有界奖励假设下使回报有限，又确定后来的探测器放置在多大程度上影响当前行动。

RL智能体有两种广泛的使用经验来改进其决策的方式：无模型基于价值的方法和基于模型的方法。无模型基于价值的方法，如Q学习[63,62]，直接学习与在某个状态中采取行动相关的期望长期回报，这对于中小型问题效果相当好。对于大型状态空间，这些价值函数可以由人工神经网络更有效地表示，人工神经网络提供灵活的参数化函数逼近器，能够在状态之间泛化，而不是为每个状态–行动对存储单独的值[11,24,42,43]。另一方面，基于模型的方法让RL智能体学习环境的内部预测模型，并使用该模型在执行之前评估可能的行动[56]。

我们采用基于模型的方法来建模RL智能体的记忆和决策能力，在我们的案例中，它由编码器、解码器、转移模型、奖励模型和将其预测组合成决策的规划规则组成（这些组件如何组合参见图1）。我们将这些学习到的内部模型的集合称为智能体记忆，因为正是这些学习到的模型的编排保留了在环境中行动所需的必要行为信息。这种基于模型的方法对我们的目的很重要，因为学习到的智能体模型提供了可以在训练后询问的显式内部对象，这意味着我们还可以检查支持其行为的表示和预测是否保留了有关生成奖励景观的时空结构的信息。

为了区分物理状态与其在智能体内的表示，令 s_t∈𝒮 表示物理环境状态，o_t = o(s_t)∈𝒪 表示在第 t 步提供给编码器神经网络（将在下一节中展示）的归一化观测。在当前问题中，s_t 指定探测器2的时空涂抹中心，o_t 是其归一化版本。决策过程始于编码器，它将该观测映射到内部潜在状态

z_t = E_{θ_E}(o_t) ∈ 𝒵,　𝒵 ⊆ ℝ^{d_z},　(28)

其中 θ_E 表示编码器的可训练参数，d_z 是潜在维度，潜在空间 𝒵 是智能体内部的，其元素是观测的内部向量表示，其各个分量没有被赋予任何内在的物理或几何意义。正是编码器确定观测的哪些信息被保留在内部表示中，并且必须保留足够的信息以支持后来的动力学和奖励预测以及解码器的重建。

RL智能体的决策然后通过在该潜在表示上进行规划来进行。一般的有限视野基于模型的规划器考虑由 H 个模拟未来行动组成的候选行动序列 a_{0:H−1}（H 称为规划视野），通过内部预测每个序列生成的转移和奖励，然后执行具有最大预测折扣回报的序列的第一个行动。在此及下文中，索引 t 标记与环境的实际交互，而 k=0,…,H 标记这些规划展开之一中的模型预测步骤（定义见下文），我们使用帽子表示由学习模型预测的量。从编码的当前状态 ẑ₀ = z_t 开始，规划器生成模型预测的潜在轨迹

ẑ_{k+1} = ẑ_k + F_{θ_F}(ẑ_k, e_{a_k}),　(29)

其中 F_{θ_F} 是具有可训练参数 θ_F 的学习潜在动力学模型，向量 e_{a_k} 是行动 a_k 的独热编码（意味着其对应于 a_k 的分量为1，所有其余分量为零）。我们选择式(29)的形式是因为它使 F_{θ_F} 学习潜在空间中依赖行动的位移，而不是仅仅预测下一个潜在状态。

对于初始规划步骤 ô₀ = o_t，而后续预测的观测从解码器 D_{θ_D}: 𝒵→𝒪 获得，它将潜在状态映射回观测的归一化坐标并具有可训练参数 θ_D。为了区分实际观测的重建与模型预测的未来观测，我们使用波浪号表示当前观测的重建，

õ_t = D_{θ_D}(z_t)　(30)

而规划期间的解码模型预测用帽子表示

ô_{k+1} = D_{θ_D}(ẑ_{k+1}).　(31)

解码器的作用鼓励

D_{θ_D}(E_{θ_E}(o_t)) ≃ o_t,　(32)

即它鼓励解码的预测下一状态应该位于相应的观测下一坐标附近。解码器将潜在表示锚定到探测器坐标，而不对该表示施加特定的几何，这是一个关键的区别，因为尽管编码器接收探测器坐标作为输入，但潜在变量本身先验地不易于几何解释。

最后一个学习组件是奖励模型 R_{θ_R}，它在训练期间预测给定当前潜在状态 z_k 和编码的观测下一潜在状态 z_{k+1} = E_{θ_E}(o_{k+1}) 在行动 a_k 下的下一奖励，如

r′{k+1} = R{θ_R}(z_k, z_{k+1}, e_{a_k}),　(33)

其中 θ_R 表示其可训练参数。规划器反而使用模型预测的转移 ẑ_k→ẑ_{k+1} 在行动 a_k 下，因为未来状态 z_{k+1} 对其不可用，由下式给出

r̂{k+1} = R{θ_R}(ẑ_k, ẑ_{k+1}, e_{a_k}).　(34)

因此，该程序将所有先前的机制引导到构建最终用于为候选行动序列分配得分的表示

J_θ(s_t, a_{0:H−1}) = Σ_{k=0}^{H−1} γ^k r̂_{k+1},　θ = (θ_E, θ_F, θ_D, θ_R),　(35)

然后立即选择行动¹

a_t^⋆ = [arg max_{a_{0:H−1}} J_θ(s_t, a_{0:H−1})]₀.　(36)

¹ 得分对除 θ_R 之外的其他可训练参数的依赖通过 r̂_k 作为其函数的潜在向量表示 ẑ_k 隐式地引入。

重要的是，这里的模型预测展开是指由学习的动力学和奖励模型内部生成的序列，而不是在环境中实际执行的序列。在本工作中，我们使用规划视野 H=1，这意味着规划器从当前编码状态 z_t 预测与每个有效局域行动相关联的下一潜在状态和即时奖励，然后选择具有最大预测奖励的行动

a_t^⋆ = arg max_{a∈𝒜} R_{θ_R}(z_t, z_t + F_{θ_F}(z_t, e_a), e_a).　(37)

因此，尽管提供给编码器的观测是探测器坐标，行动评估完全由学习的潜在表示和预测模型介导。

为了学习广泛行动的后果，RL智能体有时必须探索规划器推荐的替代方案。因此，智能体以概率 1−ε 遵循规划器的推荐，以概率 ε 均匀随机选择行动，其中 0≤ε≤1。对于指定的常数 ε，这是通过从 [0,1] 均匀地抽取数字 u 来实现的：如果 u≥ε，智能体遵循规划器的推荐；否则，它从可用行动中均匀地采样一个行动。此程序称为 ε-贪婪探索。还实现了探索调度，其中 ε 根据环境步骤的累积数量 n 变化为 ε(n) = 0.1 + 0.9e^{−n/ε_decay}。此调度从 ε=1 开始并逐渐接近 0.1，因此早期训练由均匀随机行动主导，这些行动用广泛的局域转移填充重放记忆（更多内容见下文），而后期训练越来越多地使用规划器的输出。

IV 学习任务

在本节中，我们介绍和描述学习任务的细节和RL智能体架构的参数选择。我们在这项工作中感兴趣解决的问题是，一个执行嵌入时空中的量子信息任务的学习智能体——对时空没有先验概念——能否在成功完成任务后在其记忆中发展出该时空的表示。更具体地说，给定一个（基于模型的）RL智能体的预测模型和行为策略，其任务是最大化嵌入时空中的两个UDW量子比特系统之间量子互信息的单调函数，我们能否从中提取时空的因果或度规结构？UDW模型的简单性，结合它连接量子信息和时空几何的方式，使其成为设置问题环境的理想选择。注意，从现在开始，我们将固定(3+1)维时空的两个空间维度，并考虑(1+1)维切片。

在我们的设置中，表示任务的MDP (𝒮, 𝒜, ℛ, P) 具有由 301×301 网格组成的状态空间 𝒮，其单元索引探测器2的时空涂抹中心

𝗑 = (x, t),　x, t ∈ [−10, 10],　(38)

探测器1固定在原点。如果 i_x, i_t ∈ {0,…,300}，物理坐标是

x(i_x) = −10 + i_x Δ,　(39)
t(i_t) = −10 + i_t Δ,　(40)
Δ = 20/(301−1),　(41)

模型在交互步骤 t 的观测输入是归一化坐标表示

o_t = o(s_t) = ((x+10)/20, (t+10)/20) ∈ [0,1]².　(42)

任务的目标状态对应于物理网格的中心 (0,0) ∈ [−10,10]²，其中探测器的相互作用区域重合。由于量子互信息测量联合系统的总信息内容（不包括子系统之间的关联），在我们的设置中，当探测器的相互作用尽可能接近时，它被最大化；原因是场介导的关联和通信可以随着探测器间距迅速衰减。当RL智能体达到此目标状态（对应于最大变换量子互信息 Ĩ_max）或达到允许的最大步骤数时，回合终止。如果RL智能体在此最大值之前达到目标状态，则回合被认为是成功的。

行动集 𝒜 由八个最近邻网格移动组成

𝒜 = {(δ_x, δ_t) : δ_x, δ_t ∈ {−1, 0, 1}} \ {(0,0)},　(43)

因此行动将整数单元改变 (i_x+δ_x, i_t+δ_t)，对应于物理位移 (Δx, Δt) = (x(i_x+δ_x)−x(i_x), t(i_t+δ_t)−t(i_t))。注意，𝒮 中的每个状态对应于探测器之间的间隔为 的一次实验运行。智能体将相对相互作用中心移动 的决定然后对应于与新的相对间隔 (x+Δx, t+Δt) 相关联的另一次实验运行。环境还阻止将离开网格的提议移动并分配相应的边界惩罚 b_t = 0.2·1_boundary(s_t, a_t)。时空网格转移本身是确定性的，训练期间的随机性来自 ε-贪婪探索规则，而不是来自随机时空动力学或探测器状态的采样。

为了在不破坏量子互信息作为信息度量的单调性的情况下增加其在远离时空网格中心处的对比度和可见性，我们使用量子互信息的归一化幂变换

Ĩ(𝗑) = [I(𝗑)/max_𝗒 I(𝗒)]^p,　p = 1/4.　(44)

用于此景观的探测器参数²是 T=0.15、σ=0.15 和 λ=1，具有第II节中给出的初始不关联乘积探测器状态。裸量子互信息范围是 [3.1929×10⁻⁸, 6.5477×10⁻²]，变换后的范围约为 [0.02643, 1]。图2可视化了这个函数，突出了量子互信息通过中心对角光锥脊对时空性质的依赖。

来自环境的奖励由四项组成：

R(s_t, a_t, s_{t+1}) = [Ĩ(s_{t+1}) − Ĩ_max] + 0.02·1_{ΔĨ_t≥0} − 0.05·1_{ΔĨ_t<0} − b_t,　(45)

其中实现的奖励是 r_{t+1} = R(s_t, a_t, s_{t+1})，b_t 是先前定义的边界惩罚，ΔĨ_t = Ĩ(s_{t+1}) − Ĩ(s_t)，在这种情况下 Ĩ_max = 1，并且在达到目标状态时没有分配额外的终端奖励。第一项仅仅奖励RL智能体处于大幅度状态，从中减去最大值本质上创建了一个惩罚场，而达到最大值时的终止阻止RL智能体通过在目标状态附近徘徊来利用奖励。接下来的两项 0.02·1_{ΔĨ_t≥0} 和 −0.05·1_{ΔĨ_t<0} 测量RL智能体向目标状态的进展，前一项为不减少量子互信息的移动给予小的正奖励，后一项为减少量子互信息的移动给予稍大的惩罚。奖励从量子互信息继承了对时空结构的依赖，由于RL智能体不知道这个函数是什么或代表什么，从智能体的角度来看，这种反馈只是隐式地与所述结构相关联。

在这项工作中使用基于模型的架构的目的是增加智能体对环境结构的真正发现元素。奖励已经掩盖了显式结构，但RL智能体仍然接收时空坐标，因此模型的工作是首先通过可训练的编码器（仅隐式依赖于时空坐标）将它们转换为内部潜在状态，而解码器的工作是使该表示在某种程度上忠实。在此之后，RL智能体基于内部潜在状态进行所有决策：训练环境奖励的奖励模型和环境转移概率的潜在动力学模型，以从它们自己的内部视角模拟环境。在这个意义上，该模型确实可以被论证是从头开始自主发现时空结构。

在训练期间，RL智能体通过在均匀采样的经验重放小批量上最小化复合损失函数，从反馈更新其模型来学习导航环境。经验重放作为一个记忆缓冲区，保存观测到的转移 (s_t, a_t, r_{t+1}, s_{t+1})——包括回合边界标记，以便采样的窗口不会跨越重置——随后从中随机采样的单步转移或小批量子集用于参数更新[33,43]。采样的小批量包含由当前归一化坐标 o_{b,k}、行动 a_{b,k}、实现的奖励 r_{b,k+1} 和下一归一化坐标 o_{b,k+1} 组成的转移 (o_{b,k}, a_{b,k}, r_{b,k+1}, o_{b,k+1})，批量索引为 b。我们将编码的潜在状态 z_{b,k} 和预测的下一潜在状态 ẑ_{b,k+1} 表示为

z_{b,k} = E_{θ_E}(o_{b,k}),　(46)
z_{b,k+1} = E_{θ_E}(o_{b,k+1}),　(47)
ẑ_{b,k+1} = z_{b,k} + F_{θ_F}(z_{b,k}, e_{a_{b,k}}),　(48)

并使用 ⟨·⟩ 表示采样重放小批量上的均匀平均。我们将在下面的损失函数中使用的范数是均方范数 ‖v‖² = d⁻¹ Σ_{i=1}^d v_i²，对于向量 v∈ℝ^d。复合损失函数是一系列发挥不同作用的单个损失函数的线性组合。现在让我们逐一讨论复合损失函数的每一项。

第一个损失项是奖励预测损失，它在即时实现的奖励 r_{b,k+1} 上训练局域奖励模型 r′_{b,k+1}：

ℒ_r = ⟨(r′{b,k+1} − r{b,k+1})²⟩,　(49)

其中

r′{b,k+1} = R{θ_R}(z_{b,k}, z_{b,k+1}, e_{a_{b,k}})　(50)

由 z_{b,k}、z_{b,k+1} 和 a_{b,k} 计算。下一个损失项是潜在动力学损失，它训练潜在转移模型落在编码的下一观测附近：

ℒ_dyn = ⟨‖ẑ_{b,k+1} − sg(z_{b,k+1})‖²⟩,　(51)

其中 sg(·) 表示停止梯度操作，它在优化期间阻止梯度流动，以便编码目标在主动力学项中被分离，转移模型不会追逐移动的编码器。接下来的两个损失项作为一致性约束，防止这种分离成为漏洞。如果 a⁻¹_{b,k} 表示反向网格行动，则相应的潜在动力学更新是

ẑ^←{b,k} = ẑ{b,k+1} + F_{θ_F}(ẑ_{b,k+1}, e_{a⁻¹_{b,k}}),　(52)

损失项由下式给出

ℒ_{dyn,cyc} = ⟨‖ẑ^←{b,k} − z{b,k}‖²⟩,　(53)
ℒ_{enc,dyn} = ⟨‖sg(ẑ_{b,k+1}) − z_{b,k+1}‖²⟩.　(54)

第一项强制执行一个想象的向前步骤，然后是反向行动返回原始潜在状态，而第二项应用相同的转移失配，但预测的潜在状态被分离，因此编码器也受到压力以保持与潜在动力学模型兼容。最后一批损失项与解码器相关联，它们的工作是将潜在状态锚定到观测坐标：

ℒ_{dec} = ⟨‖D_{θ_D}(z_{b,k}) − o_{b,k}‖²⟩,　(55)
ℒ_{dec,dyn} = ⟨‖D_{θ_D}(ẑ_{b,k+1}) − o_{b,k+1}‖²⟩,　(56)
ℒ_{cyc} = ⟨‖E_{θ_E}(D_{θ_D}(z_{b,k})) − z_{b,k}‖²⟩.　(57)

第一项从编码的潜在状态重建归一化坐标特征，第二项试图约束预测的下一潜在状态解码到观测下一坐标附近，第三项防止解码器仅在离开编码器的潜在表示后才准确。将所有这些损失项放在一起，复合损失函数因此是

ℒ_total = ℒ_r + 2.5ℒ_dyn + 0.2ℒ_{dec} + 0.2ℒ_{dec,dyn} + 0.05ℒ_{cyc} + 0.5ℒ_{dyn,cyc} + 0.8ℒ_{enc,dyn}.　(58)

与使用深度神经网络的标准做法一样，损失函数项附带的权重经过调整以使学习方案能够成功。最大的权重落在动力学项上，因为规划器在其得分表面能够携带有意义的行动信息之前需要一个可用的单步潜在模型。奖励损失将潜在转移与环境奖励联系起来，这对于正确导航环境和完成任务至关重要，因此它的权重为1。潜在转移损失项也具有相对较大的权重，因为前面所述的转移模型的重要性。最后，解码器损失项保持潜在表示与观测探测器网格的联系，这很有用但不如其他项重要，因此它们具有小权重。

V 智能体记忆的几何特征

图3显示RL智能体已经基本收敛到完成任务的最优策略。如果支持此收敛策略的预测模型保留了奖励景观中间接编码的时空依赖性，则该结构应该在其转移 F_{θ_F} 和奖励 R_{θ_R} 模型记忆以及其内部潜在状态中可检测到。规划器使用这些学习的对象来预测候选局域行动的结果并优化得分式(35)，使我们能够显式检查其决策是否保留了有关探测器环境底层因果结构的信息。问题是：这些对象内的关系是否保留了足够的信息来重建探测器环境底层的因果几何？我们训练五个独立的智能体，索引为 m=1,…,5，除非另有说明，否则在这些智能体上平均相应的诊断场。

我们将使用提供该学习记忆互补视图的两个场来研究规划器的记忆以尝试回答上述问题。对于每个时空网格点 𝗑=(x,t)，令 s(𝗑) 表示其相应的环境状态。第一个诊断是最佳行动规划器得分

B̄(𝗑) = (1/5) Σ_{m=1}^5 B^{(m)}(𝗑),　(60)

这是每个RL智能体 m 的最佳行动规划器得分（式(35)）的平均值：

B^{(m)}(𝗑) = max_{a∈𝒜} J_{θ^{(m)}}(s(𝗑), a),　(61)

其中活动设置在每个 𝗑 使用完整的八行动集 𝒜，因此这为每个探测器放置分配其最有利行动 a_t^*（式(36)）的得分。第二个诊断是从规划器得分上的软最大分布获得的期望行动：

ξ̄{θ^{(m)}}(𝗑) = Σ{a∈𝒜} ξ_a exp[βJ_{θ^{(m)}}(s(𝗑), a)] / Σ_{b∈𝒜} exp[βJ_{θ^{(m)}}(s(𝗑), b)],　(62)

其中 ξ_a = (δ_x, δ_t) 是与行动 a 相关联的网格位移，β 的作用类似于控制分布展开程度的逆温度参数。我们在五个智能体上平均此场，并用它来可视化相对行动得分如何确定整体优选的运动方向。对于几何重建，我们首先平均行动得分本身

J̄(𝗑, a) = (1/5) Σ_{m=1}^5 J_{θ^{(m)}}(s(𝗑), a),　(63)

然后形成标量软最大平均得分

S̄(𝗑) = Σ_{a∈𝒜} J̄(𝗑, a) exp[β′J̄(𝗑, a)] / Σ_{b∈𝒜} exp[β′J̄(𝗑, b)],　(64)

其中 β′=2 为重建程序提供了最佳结果。

图4和5清楚地显示了图2中展示的时空结构的残余。我们现在将使用 S̄ 的局域结构来恢复底层时空的因果几何，在这种情况下是具有度规张量分量 g_tt=−1、g_tx=g_xt=0、g_xx=1 和特征值 v_±=±1 的平坦(1+1)维闵可夫斯基时空。为此，我们将定义一个程序来提取相关的光锥数据 {(Δt_i, Δx_i)}_i，然后使用它来确定二次型

q(Δt, Δx) = g_tt Δt² + 2g_tx Δt Δx + g_xx Δx²,　(67)

的系数，通过求解零（类光）情况

q(Δt, Δx) = 0.

在(1+1)维中，两个零方向确定洛伦兹度规的共形类，因此写 v = dx/dt，零条件变为

g_tt + 2g_tx v + g_xx v² = 0.　(68)

对于光锥分支斜率 v₊ 和 v₋，它们的和与积满足

v₊ + v₋ = −2g_tx/g_xx,　(69)
v₊v₋ = g_tt/g_xx,　(70)

其中 g_xx 的选择具有共形自由度，我们选择 g_xx=1，之后光锥分支几何确定 g_tt 和 g_tx。对于提取的光锥分支点 (Δt_i, Δx_i)，这些系数以等权重从最小二乘问题

(ĝ_tt, ĝ_tx) = arg min_{g_tt, g_tx} Σ_i (g_tt Δt_i² + 2g_tx Δt_i Δx_i + Δx_i²)².　(71)

获得。

我们现在需要找到一种好的方法来定义从智能体记忆的角度来看哪些点位于光锥分支上。由于规划器根据局域可访问的结果分配价值，中心高奖励区域延伸到可以从中到达有利状态的相邻单元，因此绝对得分阈值会选择这个宽盆地的很大一部分。对角光锥分支更清楚地以其局域突出性为特征，这促使将每个规划器得分与其紧邻邻域中的得分进行比较；我们将这个8单元邻域（不包括 𝗑 本身）表示为 𝒩₁(𝗑)。然后我们构造二元邻居比较掩码为

M(𝗑) = 1[(1/8) Σ_{y∈𝒩₁(𝗑)} 1_{S̄(𝗑)>S̄(y)} ≥ 0.7],　(72)

因此保留其标量软最大平均得分超过其局域邻域中至少70%得分的单元，排除邻域在网格边界之外的单元。想法是这个掩码将剥离足够的得分场特征，只留下光锥分支的中心脊，然后可以将其与式(67)的零方向进行比较。

然后在此二元掩码上逐行执行分支提取，其中有效掩码阈值为 M(𝗑) > 0.5，因此只有 M(𝗑)=1 的单元是活动的，光锥中心固定在。对于每个保留的时间行 t_j，活动单元被分为 x<x_c 和 x>x_c 的左右区域，足够接近 t_c 的行被排除在拟合之外。在每一侧内，活动单元被分为连续的运行，因此如果一个运行包含具有掩码值 p_k 的 N 个单元，则它被分配得分

S = (Σ_{k∈run} p_k)√N.　(73)

由于当前的掩码是二元的，这简化为 S = N^{3/2}，因此保留每一侧最宽的连续活动运行。然后从所选运行的峰值单元获得代表性分支坐标，每个时间行最多保留一个左分支点和一个右分支点。上下光锥臂都通过正负时间行包括在内，所得的左右分支点使用

Δt_i = t_i − t_c,　(74)
Δx_i = x_i − x_c,　(75)

组合，然后与式(67)的零方向进行比较以计算度规张量的分量。
