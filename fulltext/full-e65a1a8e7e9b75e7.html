摘要

量化降低了大语言模型（LLM）推理的内存和带宽需求，但可能损害精度；而将高精度数据卸载到其他存储层则可能使生成过程停滞。我们提出StrataFlux——一个挑战这种权衡的框架，它在保留量化的内存和速度优势的同时，恢复因低比特权重和键值（KV）缓存量化而损失的精度。StrataFlux对精化表示、选择与交付进行协同设计，使主机RAM和固态硬盘成为额外精度的有效来源。其“选择性精度流送”减少了传输量，使交付与计算重叠，并在解码步骤间重用已获取的精度，因此生成过程无需等待每次传输。我们在独立GPU和统一内存平台上评估了2–4比特权重和2–3比特KV缓存。对于2比特Llama-3.1-8B-Instruct权重，StrataFlux将WikiText-2困惑度从9.46降至8.40，同时在RTX 5090上保持量化基线95.4%的吞吐量。使用2比特权重和KV，StrataFlux将Qwen3-8B的AIME 2024/2025准确率从11.0%提升至47.1%，且GPU内存占用不变。在128K上下文下，采用3比特权重和2比特KV的Llama-3.1-8B-Instruct在RTX 5090上实现了与vLLM的4比特AWQ权重和8比特KV相当的困惑度和速度，而GPU内存占用仅约为其一半。这些结果表明：GPU驻留精度不必设定精度上限，卸载层级的延迟也不必决定解码速度。

1 引言

LLM推理涉及三个相互耦合的目标：精度、延迟和内存占用。模型权重编码学习到的参数，而键值（KV）缓存保留先前词元的键和值。它们的表示形式既决定了计算可用的精度，也决定了生成过程中存储和搬运的数据量。

量化和卸载以不同方式应对快速内存容量有限的问题。量化通过更少的比特数减少存储和流量；它可以加速带宽受限的推理，但可能损害精度（Frantar等，2023；Liu等，2024）。卸载通过将数据放置在更大、更慢的后备层级来保留存储精度，但传输延迟可能拖延生成（Na等，2025）。这些方法似乎表明，我们只能在精度损失与传输延迟之间二选一。

我们认为，这是将表示与放置分离所造成的虚假选择。单独来看，量化丢弃了本可由其他层级保留的精度，而卸载则是在表示已经选定之后才引入该层级。我们能否在快速内存中使用更少的比特，同时既不牺牲精度也不减慢推理？

我们用StrataFlux回答这一问题，它采用选择性精度流送在存储层级间分配权重和KV精度（图1）。紧凑的量化权重和KV作为驻留基线保留在GPU内存中，提供高带宽访问。更大、更廉价的层级——主机内存或固态硬盘（SSD）——保留额外精度，但其较低的带宽和较高的延迟要求选择性获取和灵活调度。

通过获取全部额外精度来恢复精度会侵蚀量化带来的带宽节省。选择性之所以可行，是因为保护一小部分权重即可改善低比特精度（Lin等，2024；Kim等，2024），而注意力可以集中在小的、依赖查询的词元子集上（Tang等，2024；Ribar等，2024）。StrataFlux利用这种不均衡的重要性，为当前计算选择性地获取额外精度。

保留量化的速度优势还需要灵活调度：当结果被立即需要时，选择性传输仍可能使生成停滞。对于权重，若仅将获取与它所精化的权重矩阵运算本身重叠，会限制可用于隐藏交付的时间。StrataFlux通过更早选择通道或延后加入其精化结果来扩大这一窗口，使传输和精化计算能够与中间运算重叠。对于权重和KV，它还在解码步骤间重用已获取的精度，避免重复传输，并让对某一步而言到达过晚的数据服务于后续选择。

StrataFlux使LLM推理原生适配内存层级，在保留量化的内存和速度优势的同时恢复精度。我们的贡献如下：

  1. 选择性精度流送。 我们用来自主机RAM或SSD的精化比特增强驻留低比特权重和KV，将传输集中于对每次计算最重要的通道和词元。
  2. 异步精度交付。 通过将精度的获取时机与使用时机解耦，StrataFlux隐藏了获取延迟而不使生成停滞。
  3. 层级原生推理。 通过数值表示与内存放置的协同设计，StrataFlux消除了量化与卸载之间的取舍，在独立GPU和统一内存平台上实现快速、精确且内存高效的推理。

对于2比特Llama-3.1-8B-Instruct权重，StrataFlux将WikiText-2困惑度从9.46降至8.40，同时在RTX 5090上保持量化基线95.4%的吞吐量。使用2比特权重和KV，StrataFlux将Qwen3-8B的AIME 2024/2025准确率从11.0%提升至47.1%，且GPU内存占用不变。在128K上下文下，采用3比特权重和2比特KV的Llama-3.1-8B-Instruct在RTX 5090上实现了与vLLM的4比特AWQ权重和8比特KV相当的困惑度和速度，而GPU内存占用仅约为其一半。

2 背景与动机

2.1 训练后量化

交互式端侧LLM推理反复读取模型权重和KV缓存以生成新词元。它们的大小限制了哪些模型和上下文能装入快速内存，而每词元的流量可能使内存带宽成为生成速度的瓶颈（Pope等，2023；Liu等，2024）。量化通过低比特编码表示数值来降低这些需求，例如码本索引（Han等，2016）或带缩放和偏移的整数（Jacob等，2018）。训练后量化（PTQ）无需重训练模型即可压缩权重（Frantar等，2023），而KV缓存量化压缩推理期间生成的键和值（Liu等，2024）。

这些节省引入的误差对不同数值的影响不同。大幅值离群值难以与典型值一同表示（Dettmers等，2022），而显著性描述表示误差对计算或损失的影响程度。PTQ方法应对这些差异：SmoothQuant对激活和权重通道进行重缩放（Xiao等，2023），AWQ通过缩放保护显著权重通道（Lin等，2024）。SqueezeLLM则将敏感度加权码本与对选定敏感权重和离群值的高精度存储相结合（Kim等，2024）。

2.2 动态精度精化

这些方法在构建量化表示时考虑了权重敏感度，但该表示在解码期间保持固定。输入激活随每个词元变化，使对投影误差贡献最大的权重通道不断变化。设W为原始浮点权重，cW为其反量化近似，R=W−cW为权重残差。对于输入x，每个残差列对投影误差贡献xᵢR:,ᵢ。大的激活幅值会放大这些贡献，使|xᵢ|可作为选择精化通道的依据：

(W−cW)x = Rx = Σᵢ xᵢR:,ᵢ。（1）

DecDEC（Park等，2025）发现校准选出的通道往往与解码期间激活幅值最大的通道不同。在每一步，它选出k个最大的|xᵢ|，从主机内存获取其4比特残差列，并将其与带符号xᵢ的乘积加到量化投影的输出上。在单序列解码期间，内存受限的投影使GPU核心可被并发精化使用而不拖慢投影。但获取必须等待投影的输入，且精化必须在其输出被消费之前完成以避免停滞，这将重叠限制在该投影的执行窗口内。

现在转向KV缓存，接收最多注意力的词元同样会在解码步骤间变化。注意力将查询（由当前词元表示导出的向量）与缓存的键进行比较，以对缓存的值加权。Top-k注意力和Quest利用这种依赖性将注意力限制在选定词元上（Gupta等，2021；Tang等，2024）。SpeCache则保留完整的低比特缓存，并用从主机内存获取的选定16位条目替换（Jie等，2025）。它使用投机词元在当前步计算继续的同时为下一解码步预取选定条目。然而，获取完整的16位替换忽略了联合设计精化编码与注意力计算以降低传输和执行成本的机会。

紧凑表示和选择性精化减少了流量，但并未消除访问延迟。DecDEC的重叠窗口随着更低比特量化和更高GPU带宽加速底层投影而缩小（Park等，2025）。在DGX Spark上，孤立的2KB随机SSD读取的中位延迟为200µs（第99百分位为709µs）——远长于Llama-3.1-8B-Instruct的YAQA 2比特输出投影平均21µs的耗时，使得投影局部重叠下长停滞不可避免。

两个已有机制提示了解决方案。每个Transformer块的注意力和MLP输出被累加到一个运行中的激活向量，即残差流。Deja Vu发现该向量的方向在相邻OPT块间变化缓慢，可用较早的激活预测稍后要计算哪些注意力头和MLP神经元（Liu等，2023）。KTransformers的专家延迟将混合专家模型中CPU计算专家的输出晚一个块加入残差流，使其计算与GPU的工作重叠（Chen等，2025）。

这些机制可扩展到权重精化（第2.2节）。查询/键/值和门控/升维投影从残差流读取，允许较早的激活预测通道并在这些投影执行前启动获取（获取提前，fetch lead）。精化在每个投影的输入可用后执行一次。注意力输出和降维投影写入残差流，允许将精化推迟到稍后的流更新（获取延迟，fetch lag）。这些情形共同为每个注意力和MLP投影揭示了重叠机会，将精化扩展到单个投影的执行窗口之外（图4(a)）。

我们分别评估这些偏移：获取提前测试较早激活预测精化通道的效果，获取延迟测试延迟加入精化对模型精度的影响。较早的选择可在小偏移下保留大部分投影输出均方误差（MSE）降幅（图4(b)）；延迟加入相对省略精化仍能持续降低KL散度（图4(c)）。因此精化的收益可延续到原始投影的执行窗口之外。在第3.3节中，StrataFlux跨Transformer块组合获取提前和延迟，使精化传输和精化计算与中间的模型计算重叠。

连续解码步骤间的重复选择带来了另一个独立机会。图5显示，仅缓存全部权重通道或KV词元的一小部分即可获得很高的命中率。为重复选择缓存精化比特可避免重复传输。对某一步到达过晚的数据也可服务于后续选择。我们利用这两点来减少权重和KV精化的传输与等待（第3.4节）。

3.1 在内存层级间分配精度

在独立GPU平台上，GPU内存保存量化权重和覆盖全部词元的紧凑KV缓存，GPU直接从锁页主机RAM获取精化比特。在统一内存平台上，CPU和GPU共享保存这些紧凑表示的RAM，SSD存储我们加载到共享RAM供GPU访问的精化比特（第3.4节）。这些相对廉价的后备层级使StrataFlux能够利用LLM推理期间原本闲置的容量。

3.2 为选择性精化设计精度

3.2.1 权重精化

StrataFlux保留驻留权重量化器的格式和投影内核。我们将量化的权重精化列存储为精化比特；C为相应的反量化值矩阵。对于选定的输入通道索引S(x)，我们将选定列的贡献加入基础量化投影：

y′ = cWx + Σ_{i∈S(x)} xᵢC:,ᵢ。（2）

通道选择。 遵循DecDEC（Park等，2025），我们将每个投影的输入通道划分为1,024大小的块，每块选择k个通道，以最大|xᵢ|为目标。这些索引构成S(x)；每个选定列的精化比特被连续获取。四组投影集——查询/键/值、注意力输出、门控/升维、降维——分别由独立预算k_qkv、k_o、k_gu和k_d控制。我们将精化值编码为带独立缩放因子的整数，使精化内核具有独立于驻留权重量化器的统一格式。

精化值拟合。 DecDEC量化权重残差R（第2.2节）。StrataFlux使用精化拟合调整精化值，使选定列能够补偿被省略的贡献。设z_k(x)将每个输入块中除k个最大幅值激活外全部置零。我们在最小化投影误差的同时以强度λ惩罚与R的偏差：

C*_k = arg min_C E_x[‖Rx − Cz_k(x)‖²₂] + λ‖C − R‖²_F。（3）

公式3的最小化器满足公式4，其中M_k = E_x[z_k(x)z_k(x)ᵀ]，G_k = E_x[xz_k(x)ᵀ]，I为单位矩阵。我们在小型RedPajama校准集（Weber等，2024）上估计期望，并使用M_k的对角线均值作为默认λ：

C*_k(M_k + λI) = RG_k + λR。（4）

我们在推理前将拟合矩阵量化为4比特，遵循DecDEC对权重残差的4比特编码。

神经元级替代方案。 对于输入x，量化MLP将门控和升维输出组合为神经元激活h，然后计算其未精化输出y_q：

g = cW_gate x，u = cW_up x，
h = ϕ(g)⊙u，y_q = cW_down h。（5）

其中ϕ为门控激活函数，⊙为逐元素乘法，hⱼ为门控后神经元j的激活。通道级精化分别针对大的输入激活：门控/升维针对x，降维针对h。神经元级精化则在每个1,024大小的块中选择|hⱼ|最大的k_n个神经元，并同时精化其门控/升维行和降维列。每个选定神经元的MLP神经元束编码门控/升维精化行c^gⱼ、c^uⱼ、降维精化列c^dⱼ，以及该BF16降维列的4比特副本dⱼ。对于选定神经元索引N(h)，我们从公式5重算hⱼ为h′ⱼ。如公式2，所得输出精化加入y_q：

h′ⱼ = ϕ(gⱼ + c^gⱼx)(uⱼ + c^uⱼx)，
y′ = y_q + Σ_{j∈N(h)} [dⱼ(h′ⱼ − hⱼ) + c^dⱼhⱼ]。（6）

通道级与神经元级MLP精化在不同模型、量化器、平台和速度预算下各有优劣，因此StrataFlux同时保留两种选项。

3.2.2 KV精化

对于KV精化，我们为驻留缓存格式定制嵌套重构。我们的主要KV实现StrataFlux-KV采用KVarN（Muller等，2026）的量化格式，以平衡精度与内存占用。我们对其低比特注意力内核与选择性精化进行协同设计。StrataFlux对其他KV缓存格式的适配见附录E。

嵌套编码。 如图2(a)所示，我们将每个KVarN码的量化区间细分为等分子区间，并将其索引作为精化比特存储在后备层级。驻留码与获取的索引独立地为键和值确定更精细的重构值。

词元选择。 我们对当前查询与驻留低比特键之间的分数应用softmax计算注意力权重。一个KV头存储由一个或多个查询头共享的键和值。设α_{h,i}为查询头h分配给词元i的注意力权重，H(j)为共享KV头j的查询头集合。对于词元i和KV头j，定义选择分数

sⱼ(i) = max_{h∈H(j)} α_{h,i}。（7）

该分数捕捉共享其键和值的查询头对该词元的最强注意力。对每个KV头，我们选择可配置数量的最高分词元进行精化。

注意力精化。 将获取的比特与驻留码结合，重构选定词元的更高精度键和值（图6）。对单个查询头，驻留分数ℓᵢ和值vᵢ给出输出o和归一化因子Z = Σᵢ e^{ℓᵢ}。精化词元集S给出分数ℓ′ᵢ、值v′ᵢ及输出

o′ = [Zo + Σ_{i∈S}(e^{ℓ′ᵢ}v′ᵢ − e^{ℓᵢ}vᵢ)] / [Z + Σ_{i∈S}(e^{ℓ′ᵢ} − e^{ℓᵢ})]。（8）

实践中，我们在每个KV头内将连续词元分组，并将每组的嵌套精化比特连续打包以实现更大的读取。我们用公式7对词元组评分，将每个查询头的注意力权重在组内求和。由于词元选择依赖初始注意力分数，而加权和依赖精化后的分数，KV精化引入了一段无法与周围注意力计算重叠的区域。我们通过连续获取以及将值精化融合进加权和来限制这一开销。

生成KV精化比特。 预填充期间，我们对未压缩的键和值计算注意力，然后编码驻留低比特码并卸载精化比特。解码期间，我们以相同格式编码新KV条目的已完成块。

3.4 跨解码步骤重用精度

对于独立GPU平台，主机RAM的访问延迟低于SSD，允许直接获取精化比特而无需中间缓存。而对于统一内存系统，SSD较高的访问延迟促使将获取的精化比特缓存到GPU可访问的RAM中。

缓存获取的精度。 权重和KV选择在连续解码步骤间重复出现（图5）。为避免重复SSD读取及其延迟，我们将获取的精化比特保留在GPU可直接读取的可配置大小RAM缓存中（图6）。

未命中策略。 选择仍可能未命中缓存。对于权重和KV，当前步可决定跳过缺失的精化而使用驻留低比特表示。CPU加载器将比特取入缓存供未来选择使用，保持传输有用而不让请求步骤等待。或者，运行时可以等待并在当前步应用精化，以速度换取精度。

缓存组织。 权重和KV精化拥有独立的缓存预算。权重缓存存储全部四组投影集的精化比特，并采用最近最少使用（LRU）替换。KV词元组在所有KV头和Transformer块间共享容量。

填充KV精化缓存。 预填充期间，我们将KV精化比特写入SSD，并为最近编码的词元组在RAM中缓存副本。解码期间，新生成的精化比特直接进入缓存，为后续选择服务而无需SSD回读。

3.5 在速度预算内调谐权重精化

搜索空间。 权重调谐器在用户指定的相对量化基线的减速限制下选择配置。它为每组投影集选择通道预算k、获取提前/延迟距离s，以及MLP采用通道级精化还是带预算k_n的神经元级精化。遵循DecDEC（Park等，2025），它还调谐执行精化的GPU线程块（协作线程组）数量。更多线程块可加速精化，但也会因竞争GPU资源而拖慢并发的量化投影。

候选选择。 对于偏移距离与通道级/神经元级MLP精化的每种组合，调谐器搜索满足端到端解码减速限制的最大公共通道预算k。它在保留文本上选择与BF16参考KL散度最低的候选，然后在实测减速保持在限制内时逐步增加个别通道预算或神经元预算。我们对每个模型、权重量化器和平台分别调谐。然后按第3.2.1节所述在选择预算下拟合精化。

5 相关工作

异构内存推理系统在GPU内存之外容纳权重和KV缓存。FlexGen（Sheng等，2023）在GPU、CPU和磁盘间调度压缩张量；InfiniGen（Lee等，2024）和FreeKV（Liu等，2026）从主机内存预取选定的KV条目。Quest（Tang等，2024）和SparQ（Ribar等，2024）通过依赖查询的选择减少KV读取。SpeCache（Jie等，2025）以预取的16位条目补充完整低比特缓存。StrataFlux则协同设计低比特注意力与选择性获取的精化比特，利用缓存和跳过未命中来恢复精度，而不让解码停滞于后备层级读取。

在权重方面，DecDEC（Park等，2025）从当前激活中选择精化通道，并将主机内存获取和精化与相应量化投影重叠。其他推理系统跨Transformer块重叠工作：Deja Vu（Liu等，2023）用较早激活预测要计算哪些注意力头和MLP神经元，KTransformers（Chen等，2025）延迟专家输出以重叠CPU和GPU计算。StrataFlux通过早期通道选择和延迟加入，将权重精化重叠扩展到DecDEC投影窗口之外，并拟合精化值以补偿未选定通道。

6 结论

StrataFlux在保留量化的内存和速度优势的同时，从低比特权重和KV缓存中恢复精度。其选择性精度流送通过协调获取什么、何时到达以及如何精化计算，使主机RAM和SSD成为额外精度的有效来源。在独立GPU和统一内存平台上，StrataFlux证明：分布在内存层级中的精度可以提升精度，而无需让后备层级的传输决定解码速度。
