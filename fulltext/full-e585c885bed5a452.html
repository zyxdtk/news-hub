**标题：** Spatio-Temporal Token Pruning for Efficient High-Resolution GUI Agents （面向高效高分辨率图形用户界面代理的时空令牌剪枝）

**作者：** Zhou Xu（徐舟） Bowen Zhou（周博文） Qi Wang（王琦） Shuwen Feng（冯书文） Jingyu Xiao（肖景宇）

[查看论文《Spatio-Temporal Token Pruning for Efficient High-Resolution GUI Agents》的 PDF 版本，作者：Zhou Xu、Bowen Zhou、Qi Wang、Shuwen Feng、Jingyu Xiao](#) [查看 PDF](#) [HTML 版本（实验性）](#)

**摘要：** 纯视觉 GUI 代理具备通用交互能力，但其效率严重受限于高分辨率截图与历史轨迹中固有的大量时空冗余。我们发现现有压缩范式中存在两个关键错位问题：其一为**时间错位**，即统一的历史编码方式与代理的“衰减记忆”注意力模式不一致；其二为**空间拓扑冲突**，即无结构的剪枝操作破坏了实现精确定位坐标所需的网格完整性，从而引发空间幻觉。为应对上述挑战，我们提出了 **GUIPruner**——一种面向高分辨率 GUI 导航的免训练框架。该框架融合了**时序自适应分辨率（Temporal-Adaptive Resolution, TAR）**（通过基于衰减的重缩放消除历史冗余）与**分层结构感知剪枝（Stratified Structure-aware Pruning, SSP）**（在保障全局布局完整性的前提下，优先保留交互性前景区域与语义锚点）。在多个多样化基准上的大量实验表明，GUIPruner……

Pruner 持续取得最先进的性能，有效防止了大规模模型在高压缩率下出现的性能坍缩现象。值得注意的是，在 Qwen2-VL-2B 模型上，我们的方法实现了 3.4 倍的 FLOPs 减少和 3.3 倍的视觉编码延迟降低，同时保留了超过 94% 的原始性能，从而实现了低资源消耗下的实时高精度导航。
