Kimi K3.1 Pro 领跑开放权重，却...

📅 2026-10-26 📄 VentureBeat AI 🔗 原文链接

原标题：Moonshot's Kimi K3.1 Pro flirts with open weights leadership amid paid influencer scandal allegations

中文摘要： Moonshot 发布 3 万亿参数大模型 Kimi K3.1 Pro，为 Kimi K3 的后训练升级版。第三方基准显示其在终端编码、网络安全等智能体任务上大幅提升，智能指数达 55，有望在 11 月 4 日开放权重后登顶全球最强开放权重模型。API 输入定价 2 美元/百万 token，约为 Opus 5.5 的一半。但发布同期陷入未披露付费网红推广指控，相关截图尚未获独立核实。企业宜按工作负载开展试点评估，权衡性能与成本。

卡尔·弗兰森
太平洋时间 2026 年 10 月 24 日晚 8:31
图片来源：VentureBeat 使用 OpenAI ChatGPT-Images-2.5 制作

中国 AI 初创公司 Moonshot（月之暗面）周五刚刚发布了其迄今最新、规模最大的大语言模型（LLM）：Kimi K3.1 Pro 是其 7 月份发布的前代模型 Kimi K3 的 3 万亿参数后训练版本，而这看起来将是一次历史性的发布。

这是因为，据 Moonshot 和第三方 AI 模型测试公司 Artificial Analysis 双方所述，Kimi K3.1 Pro 在第三方基准测试中得分极高，当 Moonshot 以开放许可证发布模型权重时——该公司表示将在一周半之后，即 2026 年 11 月 4 日进行——它几乎肯定会加冕全球最强开放权重 AI 模型。

目前，Kimi K3.1 Pro 已经在 Artificial Analysis 的智能指数上击败了小米的 MiMo-V2.6-Pro、DeepSeek V4.1-Flash-1017、Meta 的新模型 Muse Wonder，甚至 OpenAI 的 GPT-6 Astra，登上榜首。

该模型擅长复杂编码、金融分析、3D 创作和软件安全工作，在需要反复编码、使用工具、调试和修改的任务中提升尤为显著。

目前，开发者和用户可以通过其应用程序和开发者应用编程接口（API）使用该模型，其输入和输出费率为 Claude Opus 5.5 和 Meta Muse Wonder 的一半，不过 DeepSeek 和小米仍然更便宜。

然而，与此同时，它也成为社交网络 X 上一场涉嫌付费网红丑闻的主角。

最大提升体现在持续编码和工具驱动的工作

Kimi 最显著的提升出现在智能体必须执行一系列操作的评估中，而不仅仅是回答一个困难的问题。

对于开发团队而言，终端测试结果使 Kimi 值得在代码库维护、调试，以及在检查文件、编辑代码、运行测试和响应失败之间交替进行的工作流上进行评估。商业软件结果则支持对执行多个关联操作的智能体进行测试。这些是针对试点选择的启示，而非对公司自身应用的实测保证。

评估机构当前的 Kimi–Opus 对比还显示，Kimi 在 AutomationBench-AA 上以 73% 对 70% 领先，在 GDP.pdf 文档推理上以 31% 对 26% 领先。Opus 则在“人类最后的考试”上以 61% 对 52% 保持领先，在 CritPt 上以 32% 对 25% 领先。这种分化有利于按工作负载进行选择，而不是将综合排名视为普适排序。

在其他独立测试中提升较小：“人类最后的考试”从 47% 升至 52%，CritPt 物理评估从 23% 升至 25%，SciCode 从 59% 升至 61%。证据更强烈地指向任务执行能力的提升，而非各类推理能力的同等跃升。

该公司的 Terminal-Bench 结果也与 Artificial Analysis 的不同：Moonshot 认为 Kimi 略落后于 Opus，而这家独立评估机构则报告其以 67% 领先。两个结果都支持其竞争力；但都不能确立全面的编码优势。

API 定价：低于 Opus，与 Sonnet 持平，高于 DeepSeek

Moonshot 的 API 平台将 K3.1 Pro 定价为每百万输入 token 2 美元、每百万输出 token 10 美元、每百万缓存输入 token 0.20 美元。这些费率比 Kimi K3 低三分之一。

Highspeed 变体的输入费用为 4 美元、输出为 20 美元，缓存输入仍为 0.20 美元。Moonshot 声称在速度约为两到三倍的情况下智能水平相当。更快的模型生成速度应与完整工作流的持续时间分开评估，因为后者还需等待工具、构建和测试。

以上为 2026 年 10 月 24 日核实的已公布美元 token 费率，不包括额外的工具费用、缓存写入费用、税费和协商折扣。所列 OpenAI 费率适用于 272,000 输入 token 以内的请求；更长的请求费率更高。DeepSeek 的文档将其 Flash API 对应 1017 模型，并在指定工作日时段之外（包括所有周末时段）适用非高峰价格。GPT-6 Sol 因网络安全对比而被纳入；其文档指出 GPT-6.1 Sol 是更新的模型。

标准版 Kimi 的每输入或输出 token 成本比 Opus 5.5 和 Muse Wonder 低 50%，比 Astra 公布的基础费率低 80%。但与 Sonnet 5.5 相比，它在输入/输出上没有任何价格优势，而后者在综合智能指数上高出一分。Sonnet 的缓存输入费用也更低。

与高峰费率的 DeepSeek 相比，Kimi 的非缓存输入收费约为其 6.7 倍，输出约为其 8.3 倍。为这一溢价付费的理由是特定工作负载上的更好结果，而不是“面向开放权重的模型都很便宜”这种笼统说法。

虚幻引擎、CAD 与金融模型：Moonshot 声称它能构建什么

Moonshot 的编码展示明确将虚幻引擎与 Unity 和 Godot 并列。该公司表示，Kimi 可以将游戏引擎工作与网络研究和 3D 生成相结合，产出完整的交互体验。它还重点展示了浏览器界面、Three.js 场景，以及布局、动画和视觉呈现方面的改进。

对于企业而言，这些说法提示了涉及交互式产品演示、培训模拟、游戏原型和基于浏览器的可视化的试点项目。它们并不能证明单凭一次 API 请求就能交付可用于生产的虚幻引擎项目：外围智能体仍然需要访问引擎、项目文件、工具，以及测试输出的方法。

3D 工作并不限于游戏。Moonshot 表示，Kimi 可以将书面简报、草图或参考图像转化为模型；处理现有资产集合；并通过 Blender 或 CAD 脚本修改几何结构、材质和场景布置，而这些脚本化操作无需 MCP 连接器。

它特别强调了机械部件、建筑、可配置产品和家具的可调节设计。其 3D Make 应用允许用户在线检查和编辑模型、下载用于 3D 打印，或导出视频和实况照片。

这使得设计探索和原型生成成为合理的应用场景。然而，BenchCAD 结果衡量的是重建质量，而非制造公差、结构完整性或监管审批。工程团队在将生成的零件视为可制造之前，仍需执行其现有的验证流程。

这一区别意义重大：据报道，该智能体调查了环境中的缺陷，而不是无休止地调整它所奖励的行为。这仍然是公司演示，而非其在各类工程项目中具有可比可靠性的独立证据。

金融是另一个明确的目标。Moonshot 描述了电子表格建模、投资筛选、盈利能力分析，以及将结论追溯到证据的研究。其内部测试报告金融建模提升 7.2 分、研究提升 11.6 分，并在一项模拟商业管理练习中取得约为前代 4.2 倍的分数。

独立的 GDPval-AA 结果和 Moonshot 的 OfficeQA 结果为测试文档密集型分析师工作流提供了理由。合适的试点可以包括准备有来源依据的初稿、核对各申报文件中的数字，以及组装供分析师审查的工作簿。内部模拟管理结果并不能确立现实世界收入或生产力的相应提升。

更多后训练——以及一个能发现自身模拟器缺陷的智能体

Moonshot 将此次升级归因于对 Kimi K3 进行的大幅增加的后训练，包括跨越数百个任务领域的强化学习。这是模型从所尝试任务的反馈中学习的阶段。

该公司描述了整个流程中的改进：训练软件、长上下文处理、计算效率、隔离的工具环境、尝试调度以及环境质量检查。其解释的核心在于让更大规模的训练稳定运行；它并未指出某种新发明的模型架构，也未量化训练成本的突破。

一项报道的行走模拟器实验为 Moonshot 所寻求的行为提供了一个具体例子。

Kimi 围绕 human-atlas（一个包含 296 个骨骼元素和 402 个肌肉组件的解剖模型）构建了模拟和训练管线。Moonshot 表示，历经 167 次任务和 420 次独立审查，它不断修改控制器，直到模拟身体从几秒内摔倒进步到交替迈步 11.2 秒。

当奖励调整未能改善手臂动作时，该模型调查了模拟器的动力学特性，纠正了 36 处肩部肌肉力臂计算错误，并重新训练了控制器。

其企业相关性在于这种调试模式：调查环境是否出错，而不是反复调整同一个不成功的解决方案。这是在工程智能体中值得寻找的有用行为。这一特定结果仍是公司演示，而非其在陌生工业模拟上可重复性能的证明。

网络防御是强项，但综合得分掩盖了权衡

Cyber Index 评估发现漏洞、复现漏洞以及在不破坏现有软件的情况下进行修复的能力。Kimi 64% 的综合结果给了安全团队一个理由，去测试其代码审查和修复辅助能力，包括需要反复调查的困难代码库。

其分项得分说明了为什么模型选择仍然取决于具体任务。

Kimi 在 CyberGym-E2E-AA 上以 95% 领先，相比之下 Daybreak Blue 为 93%。在 CWE-Bench-AA 上，DeepSeek 以 69% 领先，高于 65% 的 Daybreak Blue 和 61% 的 Kimi。在 DeepsecBench-AA 上，Kimi 得分为 37%，落后于 Daybreak Blue 的 48%。

Artificial Analysis 还报告称，Kimi 在这些任务上没有出现安全拒绝。一些竞争对手因其服务拒绝请求而失分。因此，该排名既反映了能力，也反映了被测服务允许开发者做什么；它并未单独衡量模型的最大技术能力。

Moonshot 表示，它通过移除网络安全相关训练材料和过滤强化学习任务，单独限制了攻击性安全能力。在其内部漏洞利用开发评估中，未过滤版本在最多三次尝试内解决了 90.5% 的问题，而最终模型为 81%。该公司表示，尽管有这些干预措施，更广泛的编码改进仍然可以迁移到安全工作中。

在部署方面，这些结果支持有监督的漏洞研究或补丁提案试点。它们并不能证明智能体可以在没有测试和审查的情况下，安全地将每一项提议的修复应用于生产基础设施。

每项完成工作流的成本比 token 折扣更重要

Artificial Analysis 的发布报告显示，Kimi 每项智能指数任务的成本为 1.98 美元，与 K3 相比大致持平。平均输出从约 48,000 token 升至 55,000 token，有助于消化较低的费率。

其于 10 月 24 日核查的实时对比页面则列出 Kimi 为 2.11 美元、Opus 5.5 为 5.98 美元。发布报告与实时页面的 Kimi 数据有所不同，但后者的对比仍显示 Kimi 的实测成本比 Opus 低约 65%；这并非对每项企业任务都能节省费用的预测。

网络安全评估显示了更明显的权衡：

模型 Cyber Index 每项评估任务的平均成本
Kimi K3 41% $2.45
Kimi K3.1 Pro 64% $2.81
DeepSeek V4.1 Flash 1017 57% $0.42
GPT-6 Sol Daybreak Blue（受限访问） 69% $1.77

Artificial Analysis 将 Kimi 相比 K3 约 15% 的成本增长归因于输入 token 消耗大约翻倍。与 DeepSeek 相比，它获得了 7 个百分点的提升，但每项评估任务的成本约为后者的 6.7 倍。

这提示了一个具体的部署实验：对较便宜模型已能令人满意处理的工作使用该模型，并在未解决或更困难的案例上测试 Kimi。这种路由安排是否省钱，取决于重试和失败的成本；已公布的结果并未衡量这种提议的安排。

Kimi 计费文档还指出，重复前缀会使用自动缓存，通常有五分钟的生命周期，且缓存写入有由保留时长决定的单独费用。重放大型代码库或文档的团队应测量缓存写入和命中情况，而不是仅凭输出估算账单。

对于企业试点而言，有用的比较是每个被接受交付物的成本——包括工具执行、重试和人工修正——以及完成时间和失败率。

开发者需要核对的不仅仅是模型名称

API 标识符为 kimi-k3.1-pro 和 kimi-k3.1-pro-highspeed。Moonshot 的参数参考文档称，两者均遵循 Kimi K3 的约束。

推理力度接受 low、high 或 max，默认为 max。在对话过程中更改力度会使前缀缓存失效。开发者应对预期设置进行基准测试，而不是假设较低力度的调用能够复现最大力度下的发布分数。

文档还将温度固定为 1.0、top-p 固定为 0.95，并支持自动、禁用或必需的工具选择。对于多步交互，应用程序必须保留完整的返回助手消息，包括推理内容。

在改造现有智能体时，这些细节很重要：保留的对话状态、工具处理和缓存行为都会影响结果和成本。API 模型还需要配套的执行环境，才能复现该公司的代码、CAD 和游戏引擎演示。

Moonshot 列出了通过其网页和移动应用、Work 和 Code 的访问方式，并表示 API 客户可以使用零数据保留。企业管理员必须启用 K3.1 Pro，因为组织访问默认处于禁用状态。

未披露的网红推广指控使发布蒙上阴影

Kimi K3.1 Pro 的首发还因一项指控而受到审视：网红被要求在未披露与 Moonshot 商业关系的情况下推广该模型。

X 用户 Elshayib 发布了他所称的 Kimi 推广活动指令截图，并表示他拒绝按这些条款参与。所谓的指令要求创作者提交草稿以供审批，并包含如下指示：“请不要打上付费合作伙伴标签”，这将违反美国多项法律，也可能违反其他公司的规定。

建议的谈点将 Kimi 描绘为 Anthropic Claude Opus 5.5 的开源等价物，而价格仅为其一小部分。

关键事实仍未查明。正如 Pekingnology 的报道明确指出的，该文件尚未得到独立核实。目前不清楚这些指令是来自 Moonshot、外部机构还是其他方；有多少创作者收到了这些指令；以及是否有人按这些条款发布了有偿背书。

截图的流传并不能证明 Moonshot 授权了一场未披露的广告活动。截至 10 月 25 日，在本小节所审查的材料中，未发现该公司对具体指控的确认回应。

尽管如此，披露问题依然重要。X 的政策要求在符合条件的帖子上进行付费合作伙伴披露。美国联邦贸易委员会（FTC）的指导意见也要求明确披露背书者与品牌之间的实质性关系，包括付款或免费产品和服务。某项特定背书是否违反这些标准，将取决于实际关系、内容和披露情况——而不仅仅是所谓活动简报的存在。

对于企业买家而言，实际关切在于表面上独立的推荐是否反映了未披露的激励。采购团队应询问评论者有关付款、积分和编辑审批的情况，并根据已公布的条款核实定价和部署声明。鉴于 K3.1 Pro 的权重尚未发布、其生产 API 收取使用费，“开源”或“免费”之类的笼统描述需要加以限定。

这些指控本身并不能否定独立的基准测试结果。它们确实强化了将宣传热情与可复现证据区分开来的重要性：在公司自身工作负载上的表现、总运营成本、数据处理条款，以及可部署权重的可用性。

Kimi 在企业候选清单中的位置——以及它尚不适合之处

发布证据支持若干有针对性的评估，而不是对现有模型的一揽子替换。

企业工作负载 为何测试 Kimi 什么应决定采用

这是基于已公布证据对模型试点方向的评估；此次发布并未提供这些企业工作流的生产验收率。

鉴于 Moonshot 科学对比中的巨大差距，科学工作流需要格外谨慎。当 DeepSeek 和 MiMo 便宜得多时，高容量常规任务也需要强有力的质量理由来支付 Kimi 的费率。

这些结果也不能证明未经审查的金融结论或自动化生产变更是合理的。Artificial Analysis 报告 Kimi 的 AA-Omniscience 幻觉率从 53% 降至 44%，而准确率从 48% 升至 51%。Moonshot 单独进行的内部压力测试报告，断言层面的幻觉率从 23.4% 降至 8.3%。这些是不同的测量指标，都不能作为日常错误率的保证。

最后，需要立即自托管的组织目前还无法通过 K3.1 Pro 满足这一要求。最终权重、许可条件和生产部署要求仍有待落实。托管 API 的零数据保留并不能证明满足了特定的数据位置、合同或基础设施要求。

在权重发布之前，使用 Moonshot API 的企业必须将其输入托付给一项外部服务，而该服务的国际隐私政策标明其服务器位于新加坡，不能假设处理过程留在美国。在对中国开发的 AI 审查趋严之际，这可能让政府供应商格外犹豫：继 VentureBeat 报道的限制措施之后，一项美国国土安全部（DHS）命令将 DeepSeek 排除在民用联邦采购之外，并要求将其产品及受涵盖的第三方实施从机构系统中移除。该命令并未针对 Kimi，但给了潜在用户另一个理由，在发送敏感材料之前核实处理位置和政府合同要求。

考虑 Kimi 的最强理由是它兼具竞争力的多步性能、低于若干旗舰对手的标准 token 价格，以及独立运行该模型的承诺路径。保留替代方案的最强理由同样具体：更便宜的模型可能已经满足任务需求，专有对手在某些评估上仍然更强，而自托管目前仍只是一个未来选项。

对于企业团队而言，下一步是在其最困难的重复性工作上开展有边界的比较——衡量被接受的结果、总成本和节省的时间——同时等待 11 月的权重发布，以确定部署灵活性是否与基准承诺相符。
