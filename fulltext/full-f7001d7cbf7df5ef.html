摘要

安全对齐已使大语言模型能够可靠地直接拒绝有害请求，然而将同样的请求分散到多轮对话中时，攻击仍然频繁得逞。这种脆弱性有其机制根源：对齐是浅层的，安全行为集中在模型的前几个输出 token 上，而现有防御继承了这一弱点——它们只监督回复的表面形式，从未让模型学习一个明确的安全决策。我们对“浅层性”持相反观点：如果一小段内容决定了整个回复的轨迹，那么这段内容就是干预杠杆最大的位置，而防御者可以先占据它。我们提出“评估→决策→响应”框架，其中防御者评估用户意图，做出一个明确的、可解析的安全决策，然后才在该决策条件下生成回复，并通过强化学习在载荷轮次上训练这一承诺。由于决策是一个 token 跨度，奖励可以是一条规则：自验证奖励将承诺的标签与对话的已知性质进行核对，无需评判器、无需标注；同一格式也支持在带安全重定向的分级决策空间上使用 LLM-as-judge 奖励。在两个模型家族和涵盖安全性、效用与有用性的十四个基准上，我们的防御者在受控比较中取得了最强的多轮安全性，在保持安全领先的同时以适度的有用性代价维持了效用。逐 token 的 KL 分析和干预式探针证实了其有效的原因：训练将影响集中在设定回复轨迹的短暂审议上，而在那里承诺的决策是一个因果控制点。攻击者所利用的浅层性本身成为了防御机制。

1 引言

随着大语言模型（LLM）被部署到越来越广泛的应用场景中，确保其行为安全已变得与提升其能力同等重要。安全对齐——训练模型拒绝有害请求同时对良性请求保持有帮助——如今已是每一个前沿模型开发流程中的标准阶段（Ouyang et al., 2022; Sharma et al., 2025; Cunningham et al., 2026）。这一投入在单轮设置中已见成效：连续多轮的安全训练与红队测试使对齐模型对单轮越狱攻击具有了相当的鲁棒性，无论是手工构造的提示还是优化得到的对抗后缀（Bai et al., 2022; Zou et al., 2023; Ganguli et al., 2022），如今直接提出的有害请求会被高可靠性地拒绝。然而，多轮对话仍然远未受到充分保护。在单轮攻击中，恶意意图在提示本身中显而易见；而在多轮对话中，攻击者可以隐藏意图，将请求分散到多轮中，使每条消息看起来都无害（Russinovich et al., 2024; Weng et al., 2025; Alobaid et al., 2026）。在此类攻击下，模型失败得频繁得多，人类红队队员持续击败那些报告近乎完美单轮鲁棒性的防御（Li et al., 2024; Feng et al., 2026; Song et al., 2026; Rahman et al., 2025）。

越来越多的防御工作针对这一场景：在对抗性对话上进行监督微调（Rahman et al., 2025）、在安全与不安全回复上进行偏好优化（Jiang et al., 2024; Yan et al., 2025）、使用基于评判器的奖励进行强化学习（Guo et al., 2025）、表征层面的干预（Lu et al., 2025），以及在推理时提示模型在回答前分析用户意图（Zhang et al., 2025b）。在这些差异之下，基于训练的方法共享一个依赖：每一种方法都需要一个“预言机”参与其中——无论是有害性分类器、偏好标注器还是守卫模型——来说明什么样的回复是安全回复，并且每一种方法都监督该预言机所偏好的回复“形式”。这一依赖既昂贵又脆弱。评判器之间在相当一部分样本上彼此不一致（§4.2），因此基于某一评判器构建的奖励会将其错误引入训练，并使训练信号与评估指标纠缠在一起。而且，由于模型只见过安全回复的样子，它从未学到一个可以由规则（而非模型）检查的明确安全决策。

第二个观察说明了这样的决策应该放在哪里。安全对齐已知是“浅层的”：对齐模型几乎只在最初几个输出 token 上偏离其基座模型（Qi et al., 2024a）。安全训练实际上教会模型以拒绝开头，而一旦回复以顺从的方式开头，对齐分布就会坍缩回基座模型的分布。这就是为什么预填充一个肯定性前缀能击溃拒绝（Vega et al., 2023; Andriushchenko et al., 2025），也是多轮攻击者获胜的方式：引导对话直到局部自然的开头是顺从的，到了载荷轮次，拒绝在任何有害内容被写出之前就已消失。先前的工作将这种浅层性视为缺陷并试图加深对齐（Qi et al., 2024a）。我们将其视为一张地图。如果回复前端的一小段内容决定了其后一切内容的轨迹，那么这段内容就是干预杠杆最大的位置，防御者可以先占据它——不是用隐式的拒绝前缀，而是用一个明确的承诺。

我们将这一想法实例化为“评估→决策→响应”。在每一轮，防御者简要评估用户的潜在意图，做出一个可解析的安全决策，然后才在该决策条件下撰写回复。承诺是设计的核心。它是外化的：模型自身输出中的一个 token 跨度，规则可以读取它。它是绑定的：因为它在同一个生成过程中先于回复出现，回复是在其条件下生成的，所以改变承诺就会改变回复。它是提前的：它恰好占据了浅层对齐所暴露的、设定轨迹的位置。我们用强化学习训练这一承诺，只对每段对话的最后一轮给予奖励——攻击在该轮投放载荷，防御必须在那里坚守。

将决策外化正是奖励得以简单的原因。训练对话由性质预先已知的种子提示生长而来，因此每条轨迹都免费携带一个真值标签，奖励简化为一次字符串比较：从有害种子生长的对话上“拒绝”，良性对话上“顺从”。无需评判器、无需标注、无需模型参与：一个面向对话安全的可验证奖励，秉承 RLVR 的精神（Shao et al., 2024; Lightman et al., 2024）。在有评判器可用时，同一格式也支持主流的评判器打分设计（Inan et al., 2023; Guo et al., 2025; Ding et al., 2025），其决策空间是分级的，并增加了“安全重定向”。由于决策条件化了回复，仅训练决策跨度就足以改变端到端的行为。

在两个模型家族（Grattafiori et al., 2024; Yang et al., 2025）和涵盖安全性、效用与有用性的十四个基准上的实验表明：两种变体都匹配或超越在相同数据上训练的每一个基线；这一领先在六个独立评判器下保持；自验证变体在无评判器参与、且配方在不同骨干间保持不变的情况下实现了这一点。效用得以保持，代价是有用性略有下降，我们对此进行了量化。我们将贡献总结如下：

  • 一个多轮防御框架：“评估→决策→响应”将浅层对齐从漏洞转化为安全对齐的一个明确的、可训练的控制点。
  • 两种互补的奖励：一种自验证奖励，将承诺的标签与对话的已知性质核对，无需评判器、无需标注；以及一种外部 LLM-as-judge 奖励，作用于带安全重定向的分级决策空间。
  • 全面的实验与分析：在两个模型家族、十四个基准、六个评判器上的受控比较中取得最强的多轮安全性，无需针对骨干调参；KL 分析与干预分析证实防御通过所承诺的决策发挥作用。

2 方法

我们通过强化学习训练一个多轮防御者。在每一轮，防御者遵循“评估→决策→响应”流程：先评估用户的潜在意图，然后做出一个明确的决策，最后在该决策条件下生成回复。对于策略优化，我们探索两种奖励形式：一个评判回复安全性的外部奖励模型，以及一个基于规则的自奖励，将承诺的决策与对话的真值性质核对。图 1 给出了我们框架的概览。

2.1 评估→决策→响应

在每一轮，防御者先评估用户的潜在意图，然后做出一个明确的决策，最后才在该决策条件下生成回复。决策空间由“顺从”和“拒绝”组成。当使用外部奖励模型训练时，我们为其增加第三个选项“安全重定向”，允许防御者在不直接拒绝的情况下转移有害请求。具体而言，系统提示引导模型生成如下形式的单次输出：

评估：用户的真实潜在意图，以及满足该请求是否可能造成真实伤害
决策：COMPLY / REFUSE / SAFE-REDIRECT
回复：给用户的答复

我们将第 t 轮的分解记作 y_t = (d_t, a_t)，其中“审议” d_t 跨越直到并包括决策行在内的所有内容，“回复”为 a_t。该格式的两个性质支撑了方法的其余部分。第一，决策是外化的：它是模型自身输出中的一个 token 跨度，因此可以由规则读取而非由模型评判。第二，它是绑定的：因为它在同一生成中先于回复出现，回复是在其条件下生成的，这正是使“仅训练决策”成为可能的原因。引导该格式的两个系统提示原文见附录 D。

2.2 外部奖励

我们的第一种奖励形式采用外部 LLM-as-judge，在策略优化期间为防御者的行为打分。设 c_T = (x_1, y_1, …, x_T, y_T) 表示一个 T 轮的 rollout，其中 x_t 是用户话语，y_t = (d_t, a_t) 是防御者在第 t 轮的输出。评判器 𝒥 接收完整对话上下文以及最终回复 a_T，判断防御是否被绕过，即 a_T 是否实质性地满足了有害请求。奖励被分配到最后一轮：

R(c_T) = 1，若 𝒥(c_{T-1}, x_T, a_T) = safe；否则为 0　（公式 1）

其中 𝒥(·) ∈ {safe, unsafe} 是评判器的裁决。若回复拒绝有害请求或在未提供有害内容的情况下将其重定向，则被视为“安全”。对于良性对话，只有当回复有帮助地顺从时才被视为“安全”，这会惩罚过度拒绝。策略梯度仅施加于最后一轮 y_T，所有之前的轮次被视为上下文。

2.3 自验证决策奖励

先前的基于 RL 的防御使用外部评判器为防御者的回复打分——在有害对话上是有害性分类器，在良性对话上通常是拒绝短语或有帮助性代理。我们用一条只读取承诺标签的规则替代两者。设 ℓ(d_t) ∈ {comply, refuse} 表示从第 t 轮审议中解析出的标签，b ∈ {0,1} 表示对话的真值性质，目标决策为：

g(b) = refuse，若 b=0（有害对话）；comply，若 b=1（良性对话）　（公式 2）

与公式 1 对应，轨迹回报检查最后一轮的承诺是否与该目标一致：

R(c_T) = 1，若 ℓ(d_T) = g(b) 且 a_T ≠ ∅；否则为 0　（公式 3）

其中条件 a_T ≠ ∅ 作为完整性守卫：若某一轮的审议耗尽了每轮 token 预算而没有留下回复，则受到惩罚。若无此守卫，奖励会容许一个退化的最优解：发出 refuse 而从不回答。正是这一守卫要求每个承诺都有实际回复支撑。还需注意，自验证设置将 safe-redirect 排除在决策空间之外：在有害对话中，refuse 和 safe-redirect 都是可辩护的承诺。因此，只读取承诺标签的规则无法指定唯一目标，会使奖励信号产生歧义。我们因此将该设置限制在二元决策空间，把三向决策空间留给评估回复本身的外部评判器。

梯度范围　由于奖励只读取审议，一个自然的问题是回复是否需要训练。我们在同一奖励上提供两种梯度选项：

  • 全梯度：防御者最后一轮的每个生成 token 都可训练（默认）。
  • 部分梯度：只有决策边界之前的 token 可训练。a_t 中的每个回复 token 的掩码为 0，因此不贡献策略梯度项。

形式上，设 m_{t,i} ∈ {0,1} 表示第 t 轮第 i 个 token 的掩码，全梯度对所有生成 token 置 m_{t,i}=1，部分梯度置 m_{t,i} = 𝟙[i ≤ |d_t|]。定位 |d_t| 需要将审议与回复之间的字符级边界映射到 token 索引。由于 |decode(y_{t,1:k})| 关于 k 单调不减，我们二分搜索最小的 k 使其解码前缀到达边界字符，每轮代价为 O(log|y_t|) 次解码。

全梯度将整个生成视为动作，因此回复风格与决策共同适应；部分梯度将学习限制在审议中，并在很大程度上保留基座模型的回复风格。部分梯度之所以可行，依赖于绑定性质：回复是在承诺决策条件下生成的，因此仅训练决策就能改变端到端行为。同一性质也让奖励可以只读取标签。规则本身无法排除与标签矛盾的回复，我们也没有添加内容检查，原因有二。第一，一个解耦的策略不可能得高分，因为安全性只在面向用户的回复上开放式地评判，标签与回复之间的任何差距都会表现为更低的安全率，而实际上并没有出现这种差距。第二，绑定在构造上成立：即使在训练之前，强制 refuse 在所有情况下都会产生安全回复（§A）。与这两点一致，发出的 Decision 标签与每个外部评判器的裁决正相关，其水平与评判器间的一致性相当（§4.2）。

2.4 训练算法

我们用 GRPO（Shao et al., 2024）优化 LLM 防御者。设 τ = (x_1, y_1, …, x_T, y_T) 表示一段训练对话，其中 x_t 是第 t 个攻击者或良性用户轮次，y_t 是防御者的回复。除标准目标外，两个设计选择至关重要。

每轮长度预算　每个回复被限制在 L 个 token 内，即对所有 t 有 |y_t| ≤ L。若只有轨迹级预算，策略会学到一个退化策略：将容易回答的早期轮次的回复膨胀到预算耗尽，使后续更困难的轮次被截断或无法回答。每轮上限通过使每一轮都可独立作答来封堵这一奖励黑客路径。

结果监督奖励　我们只从最后一轮分配奖励：R(τ) = r(y_T | x_{1:T}, y_{1:T-1})　（公式 4）。多轮越狱在最后一轮达到高潮，而早期轮次保持无害，因此过程级信号会被容易的轮次主导，使策略偏向只在防御廉价之处进行防御。监督结果将学习集中在决定性的轮次，并反映了部署场景——重要的是模型在升级结束时是否顺从（细节见附录 C）。

3.1 实验设置

训练　有害池混合了五个多轮攻击家族，实例化于相同的 AdvBench（Zou et al., 2023）行为之上：SEMA（Feng et al., 2026）、Crescendo（Russinovich et al., 2024）、登门槛效应 FITD（Weng et al., 2025）、Echoing（Li et al., 2024）和 Hidden Intention Streamline（Li et al., 2024）。行为被划分为不相交的训练集和测试集，每个训练行为被均匀随机分配一个家族。良性池由来自 UltraChat-200k（Ding et al., 2023）的多轮对话组成，在表面形式和深度上与有害对话匹配，使两者均不与有害性相关。两个池以相等比例混合以约束过度拒绝；混合比例的消融见 §3.3。我们使用 HarmBench-13B 分类器（Mazeika et al., 2024）作为外部奖励模型。对于每种奖励变体，我们报告两种条件：“未对齐”，即将我们的系统提示应用于未训练的基座权重；“对齐”，即 RL 之后的相同提示。前者隔离了框架本身，两者之间的差距是训练的贡献。

基线　每个基线在与我们模型完全相同的数据上训练。我们使用两个基座模型：Llama3.1-8B-Instruct（Inan et al., 2023）和 Qwen3-8B（Yang et al., 2025）。我们排除了贡献主要是数据集而非方法的防御（Ren et al., 2025; Rahman et al., 2025），因为我们的受控比较在相同数据上训练所有方法。SFT 在从基座模型自蒸馏的安全对话上微调——攻击轮次上拒绝、良性轮次上有帮助的回复。DPO（Rafailov et al., 2023）在安全/不安全回复对上优化偏好。SDGO（Ding et al., 2025）运行由模型自身判别裁决奖励的 GRPO。MTSA（Guo et al., 2025）将被越狱轮次的安全修订向前滚动，并用 DPO 拟合由此产生的未来奖励边际。MUSE-D（Yan et al., 2025）将 LoRA DPO 应用于用其发布的风险规则构建的偏好数据。X-Boundary（Lu et al., 2025）是一种表征层面的防御，应用于转换为其擦除/保留格式的我们的 rollout。

评估　我们沿三个维度评估防御者：安全性、效用和有用性。
1. 安全性。AdvBench（Zou et al., 2023）（我们训练攻击的底层行为来源）、HarmBench（Mazeika et al., 2024）（未见过的行为来源），以及三个训练中未出现的多轮基准：MultiBreak（Song et al., 2026）、CoSafe（Yu et al., 2024）和 MHJ（Li et al., 2024）。前两者衡量跨行为的泛化；后三者衡量向未见攻击机制的迁移。
2. 效用。MMLU（Hendrycks et al., 2020）、HellaSwag（Zellers et al., 2019）、Winogrande（Sakaguchi et al., 2021）、GSM8K（Cobbe et al., 2021）、TruthfulQA（Lin et al., 2022）和 IFEval（Zhou et al., 2023），涵盖已知对齐干预会使其退化的能力维度。
3. 有用性。XSTest（Röttger et al., 2024）和 XSB（Yuan et al., 2025）衡量过度拒绝，MT-Bench（Bai et al., 2024）衡量多轮对话质量，检查安全性不是通过拒绝合法请求换来的。

每个答案由 gpt-5-mini（Singh et al., 2025）评判，它接收完整对话历史及目标行为，返回二元有害性裁决。与其他评判器的一致性分析见 §4.2，五个额外留出评判器下的安全性见附录 E.3。

3.2 主要结果

表 1 报告了完整比较。我们的方法在两个骨干上都取得了最高的平均安全率，并在每个单独的安全性列上领先。两个面板的领先构成不同。在 Llama3.1-8B 上，基线分化明显，X-Boundary 在 AdvBench 上接近饱和而大多数其他方法远远落后，因此我们的优势来自最强基线表现最差的套件，尤其是人工构造的 MHJ 攻击。在 Qwen3-8B 上，基线彼此接近得多，我们的优势是跨所有五个套件的均匀领先。这些增益在其他方面代价适度：我们的模型在 MT-Bench 上保持竞争力，在效用上与同类持平——效用是在不使用对话模板的情况下评分的，因此对安全训练基本不敏感（Qi et al., 2024a）（图 2）；唯一可见的代价是略高的过度拒绝，这是更严格决策策略的预期结果。附录 B 绘制了安全-有用性权衡，我们的模型位于前沿的有利端；附录 E.2 用 95% 置信区间重述了表 1。

两个比较定位了增益的来源。第一，我们在未训练的基座权重上运行我们的系统提示（未对齐），并在 RL 之后再次运行（对齐）。仅提示就优于基座模型，但远达不到训练后的结果，因此结构化审议本身有帮助，但不能替代奖励。第二，该表固定数据只改变方法，因此剩余差异可归因于训练目标而非训练集。在 Qwen3-8B 上达到基线数字确实需要针对每个方法的配置更改，其中没有一个能从 Llama 设置迁移过来（附录 C）；我们自己的配方在不同骨干间保持不变。

3.3 消融研究

设置　我们在 Llama 骨干上一次消融一个因素，其他保持不变。两个消融改变训练配方：“每轮奖励”将结果级奖励分配到各个轮次，“部分梯度”将梯度从完整回复限制到决策跨度。两个改变框架：“无决策”去掉 Decision 行，留下“评估→响应”；“无评估”去掉 Intent 行，留下“决策→响应”。两个框架消融均使用外部奖励，因为不发出标签的防御者给自验证奖励没有可检查的内容（§2.3）。最后一个消融改变训练混合的有害-良性比例。图 3(a) 展示前四个：水平线是我们的两个完整模型，每个柱形是一次修改，对照其奖励的线读取。图 3(b) 展示混合比例扫描。

两个配方更改朝相反方向失败。“每轮奖励”失去安全性同时将过度拒绝推到最低水平，因为将结果级信号分散到每一轮会侵蚀安全决策并推动策略走向无差别顺从；“部分梯度”以适度更高的过度拒绝为代价换取鲁棒性，答案质量未受影响。框架消融显示了防御所在之处。移除决策是研究中最具破坏性的更改：安全性在每个套件上都下降，并且在人工红队测试下降到低于未防御的基座模型，即使评估、奖励和数据都保持不变。移除评估的代价小得多，主要表现为校准的损失，过度拒绝上升，因为承诺的放置不够精确。两次移除都整体上更少拒绝，这略微提升了答案质量。是承诺，而非其前的审议，承载了防御；附录 A.1 通过干预而非移除得出相同结论。

训练混合只决定策略在前沿上的位置，因为自动安全性全程饱和：过采样有害对话以过度拒绝和答案质量的高昂代价换取红队鲁棒性，而过采样良性对话只边际地削减过度拒绝。我们保持平衡混合。

4 分析

4.1 浅层对齐

图 4：对齐、未对齐和基座模型上的逐 token KL 散度。

当前 LLM 的安全对齐已知是浅层的：对齐分布几乎只在最初几个输出 token 上偏离基座模型，这种集中正是预填充和解码参数攻击所针对的（Qi et al., 2024a）。我们的框架没有将浅层性视为需要消除的病态，而是将其重新利用：干预仍然集中在少数设定轨迹的位置上，但脆弱的拒绝前缀被一个显式控制结构取代，其决策字段门控后续回复。设置详见附录 C。

图 4 显示了一个与浅层对齐定性不同的模式。D_KL(对齐‖未对齐) 并不集中在最初几个 token；相反，训练引起的散度分布在决策 token 之前的评估阶段，在其附近达到峰值，此后随着两个模型收敛而逐渐消失。这是构造使然：训练重塑模型如何评估意图并做出决策，因此其影响分布在整个审议上而非压缩到一个开头的拒绝前缀中；一旦决策发出，回复基本确定，两个分布逐渐收敛。相比之下，对齐和未对齐模型都在第一个位置就与基座模型急剧分化并保持分离，这反映了框架推迟承诺而基座模型立即开始回答的事实。总之，这些观察证实我们的设计将与安全相关的概率质量从表面的拒绝前缀重新定位到评估-决策阶段，保留了早期干预的好处，同时消除了浅层对齐创造的单点攻击面。附录 A 通过直接干预进一步验证了相同主张，表明覆盖承诺的决策会在两个方向上移动回复安全性，并且训练加固的是承诺背后的回复，而不仅仅是标签。

4.2 LLM 评判器之间的相关性

由于安全性由 LLM 评判器评分，评判器的选择是一个潜在混杂因素：在一个评判器下测得的改进未必能在另一个评判器下存活。我们没有假设评判器可互换，而是量化它们的一致性并讨论其对结果解读的含义。设置详见附录 C。

图 5 报告了逐样本裁决上的成对 φ 系数，得出两个观察。第一，所有对都正相关但仅中等程度相关：评判器对什么构成越狱有广泛共识，但在相当一部分样本上不一致，甚至同风格的评判器也有差异。这种分散提醒人们不要将任何单一评判器的攻击成功率视为真值，并促使我们报告多个评判器下的结果（附录 E.3）。第二，模型自身的 Decision 标签与每个外部评判器的相关性水平与评判器间一致性相当，尽管外部评判器从未观察到产生该标签的审议。因此，承诺的决策不是与结果脱钩的内部产物：它追踪对最终回复的独立评估，支持其在我们决策奖励中作为自验证训练信号的使用。

5 相关工作

多轮越狱。 对齐模型如今能高可靠性地拒绝直接的有害请求，这推动攻击转向对话设置：将有害目标分解为单独无害轮次的升级方案（Russinovich et al., 2024; Ren et al., 2025）、基于说服和建立关系的策略（Zeng et al., 2024），以及人工红队测试——它仍然明显比自动攻击更有效（Li et al., 2024）。这些攻击无需提出明显有害的查询即可成功，因此单轮防御和输入过滤器提供的保护甚少。我们的威胁模型正是这一设置：静态重放的脚本化多轮攻击，自适应对手被承认为开放限制。

多轮防御。 现有的基于训练的防御监督回复：在安全回复上的 SFT 和偏好优化（Jiang et al., 2024; Yan et al., 2025），以及以有害性分类器或守卫模型为奖励的 RL（Ding et al., 2025; Guo et al., 2025）。这种设计将评判器的错误引入训练，使训练奖励与评估指标纠缠，并打开奖励黑客面。表征层面的方法则在激活空间中分离有害与良性方向（Zou et al., 2024; Lu et al., 2025）。第三条路线在推理时而非权重中介入，提示模型在回答前分析用户的潜在意图（Zhang et al., 2025b）。该工作在精神上与我们的评估步骤最接近，比较也很有启发性：它仅从审议中获得收益，而我们的消融表明没有承诺决策的审议几乎无法恢复防御（§3.3）。我们的奖励与三者都不同：它只读取模型承诺的决策与对话的已知标签，无需模型参与，且梯度从不触及响应。

浅层对齐。 一条互补的工作路线定位了这些失败的机制：对齐行为集中在最初几个输出 token 上（Qi et al., 2024a），这就是为什么预填充的肯定性开头（Andriushchenko et al., 2025; Vega et al., 2023）、解码参数攻击（Huang et al., 2024）和早期位置的微调扰动（Qi et al., 2024b）能击溃拒绝。提出的补救措施加深对齐，例如用“从有害前缀恢复”的数据增强训练（Qi et al., 2024a; Zhang et al., 2025a）。

6 结论

我们提出了“评估→决策→响应”，一种多轮防御，防御者在回复之前做出一个明确的、可解析的安全决策，并通过强化学习在载荷轮次上训练。该框架没有修复浅层对齐，而是重新利用它：决定回复命运的短跨度——通常是攻击者的目标——成为防御者控制的承诺。由于决策是一个 token 跨度，规则可以将其与对话的已知性质核对并给予奖励，无需评判器、无需标注，同一格式也支持带安全重定向的基于评判器的奖励。在两个模型家族和十四个基准上，我们的防御者在受控比较中取得最强的多轮安全性，在六个评判器下保持领先，并保持效用，代价是过度拒绝。KL 分析、干预探针和消融一致认为防御通过承诺的决策运作。更广泛地说，我们的结果表明，对齐的结构性质——常被视为弱点——可以被工程化为防御，并且对于对话安全，承诺提供了一种可扩展的、替代基于评判器监督的方案。

附录 A 浅层对齐实验

本节通过直接干预验证我们的框架实现了其设计目标：利用浅层对齐而非受制于它。浅层对齐将安全行为集中在少数设定轨迹的位置上，这通常是一个漏洞，因为这些位置可以被覆盖或被采样跳过（Qi et al., 2024a）。我们的框架有意将这种集中重新定位到一个明确的、经过训练的决策中，下面的探针证实了重新定位按预期工作：承诺的决策是因果控制点而非相关物，训练同时加强了承诺及其背后的回复，而通常击败浅层对齐的采样路径被关闭。我们改编了 Qi et al. (2024a) 的三个诊断：拒绝前缀捷径、预填充攻击和解码参数攻击。

设置。 表 1 的每个分支都以“未对齐”形式（框架提示下的基座权重，未训练）和“对齐”形式（已训练）出现。未对齐分支是参照：它仅凭指令遵循就能发出格式良好的 Decision 行，因此决策可以像在训练过的模型中一样被读取和覆盖，两者之间的任何差距可归因于训练而非提示。两个探针都使用留出的 SEMA/AdvBench 载荷轮次（n=104）；裁决来自 gpt-5-mini，即表 1 的评判器。

A.1 决策是原因吗？

强制决策探针（图 6，左）用一个以所选标签结尾的规范审议替换载荷轮次的审议，并只生成回复，这是观察性 KL 分析的干预对应物。跟进在构造上是精确的：每个单元格中发出的标签都与强制标签一致。

两个发现指向相反方向，共同精确定位了训练的贡献。第一，拒绝捷径以决策形式重现。强制 refuse 将未对齐模型在两个骨干上提升到完美安全，是真正的拒绝而非空轮次：提供的承诺使未训练模型表现得像对齐过一样，用可解析的标签代替表面前缀。模型遵守它的能力继承自指令遵循，这正是我们框架利用的浅层性。第二，训练不仅仅是选择标签。若是如此，强制 comply 会将对齐模型带回未对齐的危害。相反它们保持高位：未对齐分支在强制 comply 下崩溃，而每个对齐分支都远高于其未对齐对应物，Llama 上的“自奖励（对齐）”与其自然解码基本无法区分。因此，训练既加固了承诺也加固了回复。§3.3 的组件消融通过移除而非干预得出相同结论：在没有 Decision 行的情况下训练的防御者放弃了大部分鲁棒性，而在没有评估的情况下训练的防御者放弃的相对较少。

A.2 保护有多深？

深度探针（图 6，右）让出决策并攻击其后内容：在强制 refuse 之后，预填充真实有害回复的前 k 个 token 并继续生成，将预填充攻击移到承诺之后（k=0 恢复上述强制 refuse 条件）。未对齐分支是教科书式的浅层：少数预填充 token 就抹去了承诺获得的大部分安全性，此后曲线保持平坦。训练在 Llama 上买到了可观的决策后深度，对齐曲线在浅预填充下保持高位并逐渐衰减；但在 Qwen3 上只有边际深度，对齐与未对齐曲线在较大 k 处收敛。每条曲线最终都会衰减，这是一个构造上浅层的防御的预期特征：保护是程序性的，不能在能向助手通道写入任意远的对手面前存活。这样的对手在我们的威胁模型之外，该模型只授予用户轮次的控制权；右图量化了该边界而非将其留作注意事项。

A.3 采样能动摇承诺吗？

第三个探针运行解码参数攻击，它仅凭采样击败浅层对齐。对每个有害行为，我们在直接单轮 AdvBench 请求上跨温度、top-p 和 top-k 网格抽取十二个样本（每个分支 1,248 个样本），加上定义承诺决策的贪心生成，并记录“决策翻转率”：标签偏离该承诺的样本比例。每个分支的绝对攻击成功率都很低（any-of-N 至多 9%），因为我们的基座已经是指令微调的对话模型而非该攻击设计所针对的预训练基座；因此有信息量的量是以采样标签为条件的行为。在未对齐 Llama 中它是明确的：少数翻转到 comply 的样本约有三分之二被判定为越狱，而保持 refuse 的样本几乎为零。采样偶尔动摇承诺而回复随之而来，与 §A.1 中通过机会而非干预显现的机制相同。相比之下，对齐分支从不采样出 comply 标签（翻转至多 0.2%）：训练关闭了浅层对齐通常被击败的采样路径。我们观察到的唯一大翻转率——Qwen3 三标签分支上的 20–30%——不是安全事件：每次这样的翻转都在两个可辩护标签（refuse ↔ safe-redirect）之间交换，没有一个到达 comply，攻击成功率保持为零。因此，我们得出结论，采样只是暴露了决策空间的歧义而没有损害安全性。

附录 B 安全-有用性权衡

由于效用在所有方法间基本不变（§3），有意义的张力在于安全性与有用性之间，我们正是将这一权衡可视化。图 7 将每个方法置于一个共同的 [0,100] 平面上，汇总表 1 的各基准结果。纵轴将安全性报告为 AdvBench 和 MHJ 上的平均 SAFE%：前者在数据上域外但在攻击风格上域内，而后者由人工构造的越狱组成，在两者上都域外且经验上是最难的套件，因此它们共同覆盖泛化谱系而不让饱和的基准夸大分数。横轴将有 用性聚合为 ½[(100−XSTest) + 10×MT-Bench]，其中 100−XSTest 将过度拒绝转换为顺从率，MT-Bench 重新缩放到 [0,100]；两轴越高越好。星号表示我们的两个奖励变体，灰色圆圈表示基线。

附录 C 实现细节

所有防御者都在 verl（Sheng et al., 2024）中用 GRPO 训练，由通过 verl 的 agent-loop 接口注册的自定义多轮 agent 循环驱动。我们独立训练两个骨干，Llama-3.1-8B-Instruct 和 Qwen3-8B；Qwen3 在启用其原生推理通道的情况下训练，因此每轮除了脚手架的输出外还包含模型自己的 <think> 块，而 Llama-3.1 没有这样的通道。策略是 LoRA 适配器而非全量微调（秩 32，α=32，所有线性模块），在 FSDP2 和梯度检查点下用 Adam 以学习率 10^-4 优化。我们对冻结的参考策略施加 KL 惩罚，系数 0.001，使用低方差估计器，并将熵奖励设为零。Rollout 由 vLLM 以异步模式生成，张量并行度为 1，为 rollout 引擎保留 60% 的 GPU 内存；适配器在更新之间热交换到引擎中，因此训练期间不需要权重合并。

每个训练行是一个完整的、预生成的多轮攻击对话，因此攻击者是固定的，只有防御者是被学习的。一次 rollout 逐个重放脚本化的攻击者轮次，每次之后策略生成一个完整轮次，上限 2048 token。生成的 token 被追加到运行上下文并标记为可训练；注入的攻击者轮次以掩码 0 追加，因此没有梯度流经策略未产生的文本。Rollout 最多运行 7 个防御者轮次，在 14,336 token 的模型窗口内有 1024 token 的提示预算和 12,288 token 的响应预算。我们为每个提示抽取 n=16 个 rollout，这一规模由二元奖励决定：GRPO 在每个提示组内归一化优势，因此所有 rollout 都发出相同标签的组方差为零且不贡献梯度，大组正是维持组内标签多样性的关键。

Qwen3-8B 上的基线复现。 每个基线都在我们的 rollout 上用其发表的目标和作者的超参数训练。在 Llama-3.1 上这些设置直接迁移。在 Qwen3-8B 上，四个权重训练基线中的每一个都需要一处更改才能至少优于基座模型，并且在每种情况下，默认设置产生的防御者的分数与未训练的骨干无法区分。DPO 发表的学习率和轮数使 LoRA 更新在该骨干上太小；我们将学习率提高到 10^-4 并训练八个 epoch。MUSE-D 的数据构建器发出两个偏好流，混合流的 chosen 字段只有 32% 是拒绝；我们在风险流上训练，该流有 89% 的拒绝。MTSA 将隐式奖励边际拟合到从未来奖励差距导出的目标，而归一化该差距——如我们最初所做——将目标驱动到大约一个 nat，优化器在行为不变的情况下达到它；恢复作者公式的未归一化尺度将目标置于约 350 nat，可与普通 DPO 在相同对上达到的边际相当。X-Boundary 需要两处：必须提供其多轮边界集，因为没有它只有损失的擦除分支处于活动状态；其保留项必须变为尺度无关。该项是原始表征距离而擦除项是余弦，因此它们的平衡取决于骨干的残差流范数，我们在 Qwen3 上测得 182，而 Llama-3.1 上为 10；使用原始形式时保留项占主导而擦除目标不动。这些都不是 Qwen3 作为模型的属性。每一个都是从 Llama 配置中静默延续的设置，每一个都在此报告以便表 1 中的比较可复现。

KL 散度设置。 我们在固定的教师强制续写上测量逐位置 KL 散度，因此所有模型在相同 token 上评分，任何差异都反映模型而非其采样。对每个留出攻击对话，续写 y 是基座模型的贪心最终轮响应，生成一次并逐字复用；位置 i 索引 y 的第 i 个 token，在每个位置我们计算完整词表上的精确下一 token D_KL，并在留出集上取平均。我们比较“对齐”模型（在我们的评估→决策→响应框架下微调）、“未对齐”模型（框架提示，无微调）和“基座”模型（两者皆无）：对齐-未对齐对隔离训练的效果，而与基座的比较隔离框架本身。三者共享相同的对话内容，只在系统提示和权重上不同；对于推理模型我们禁用原生思考以便 y 是直接续写。阴影带标记模型自身贪心生成上的决策 token 位置。

评判器相关性设置。 我们在 Qwen3-8B 防御者（双标签脚手架，自验证决策奖励）上比较七个裁决来源：gpt-5-mini（Singh et al., 2025）、gpt-oss-20b（Agarwal et al., 2025）、StrongREJECT（Souly et al., 2024）、Llama-Guard-3-8B（Llama Team, 2024）、Qwen3Guard（Zhao et al., 2025）、HarmBench-13B（Mazeika et al., 2024），以及模型自身的承诺 Decision 标签。该池覆盖所有十三个留出多轮安全单元格：五个攻击家族（SEMA、Crescendo、FITD、Echo、HIS）在 AdvBench 和 HarmBench 上，加上 MHJ、CoSafe 和 MultiBreak，共 3738 段对话。每个来源将一段对话简化为最后一轮上的单个二元“越狱”裁决。关键的是，六个外部评判器只看到面向用户的回复，评估/Decision 审议被剥离。

附录 D 提示

图 8 逐字展示了两个“评估→决策→响应”系统提示。两者都指示防御者在每个回复之前写一个开放的、无标签包裹的、恰好两行的审议——一行 Intent 评估用户的潜在目标及其伤害潜力，一行 Decision 承诺一个标签——然后是与该决策一致的回复。两个提示只在标签菜单和结束指令的匹配子句上不同。双标签变体伴随自验证奖励：因为该奖励将发出的标签与该行已知的真值核对，每个可接受的标签都必须有一个真值，而 safe-redirect 没有。因此三标签变体只能与对回复本身打分的外部奖励一起使用，在那里对冲选项是有意义的。两个提示都没有用标签包裹审议；在有原生推理通道的骨干上，这使 <think> 块明确无误地属于模型自身，框架与其干净分离。

E.2 统计显著性

我们针对评估的采样噪声报告表 1 的精度：表 3 用 95% 置信区间重述表 1 的每个单元格。每个安全性单元格是 n 个留出对话上的 SAFE 率（Adv.、Harm.、MB、CoS. 和 MHJ 分别为 n=516、785、500、1400 和 537；总计 3,738），有一个例外：Llama3.1-8B Base 的 MHJ 单元格在 300 段对话上评分，其更宽的区间反映了这一点，因此其采样误差是二项比例的采样误差；我们报告 95% Wilson 区间作为半宽，并为合并的 Avg. 报告行为聚类的 bootstrap 区间。过度拒绝（XSTest、XSB）带有 Wilson 区间（n=250、340），MT-Bench 带有其 160 个逐轮分数上的 95% t 区间。效用是六个 lm-eval 任务的平均值；由于 lm-eval 为每个任务报告独立的标准误，平均值带有约一个点的组合半宽。

从区间得出三个趋势。第一，安全性结论的分辨不均匀，区间值得在点估计之前阅读。最清晰的案例是 Qwen3-8B 上的自验证奖励：其平均值超过按平均值计算的最强基线 MUSE-D 近九个半宽，并且其区间在所有五个套件上与 MUSE-D 的不相交。那是专门关于 MUSE-D 的陈述。在 MHJ 上——最难的套件也是最受审视的套件——自验证区间（75.2±3.6）与 MTSA 的（70.9±3.8）重叠，因此在该套件上两者没有被分开，即使点估计相差四个点。同一骨干上的外部奖励是另一回事——其平均领先不到两个半宽，且其逐套件区间在每个套件上都与最强基线的重叠，因此在那个骨干上两者应被解读为相当而非有序。在 Llama3.1-8B 上，两个变体在平均值上都超过最强基线，但逐套件区间在 AdvBench 上与 X-Boundary 的重叠（两者都是），在 MultiBreak 和 MHJ 上与自验证变体的重叠。区间始终支持的是我们的变体与基线“群体”之间的分离，而不是在每个套件上对单一最强者的已分辨排序。第二，效用列在方法间无法区分：每个条目都在其基座模型的大约一个组合区间内，证实没有方法（包括我们的）有意义地改变能力。第三，有用性区间建议不对称阅读：相对于 XSTest 和 MT-Bench 上方法间的小差异，它们很宽，因此不应被过度解读，而对齐防御者相对于其基座模型的升高过度拒绝则轻松越过区间，是真实的代价而非噪声。
