基于3D深度学习的ACL足迹自动识别

📅 2026-08-18 📄 arxiv 🔗 原文链接

原标题：Automated ACL Footprint Identification Using 3D Deep Learning

中文摘要： 本研究旨在探索3D深度学习模型直接从3D MR图像中自动识别前交叉韧带（ACL）股骨足迹中心。研究开发了两种架构：基于3D图卷积神经网络（DGCNN）的股骨网格几何模型，以及基于3D MR图像的增强型nnLandmark识别模型。使用近8000个膝关节图像集进行训练和测试。结果表明，两种模型均表现优异，其中基于图像的方法平均误差为2.1mm，优于基于网格的方法（2.8mm）。该研究证明3D深度学习为ACL足迹定位提供了可行的临床方案，有望提高ACL重建手术的准确性。

摘要

前交叉韧带（ACL）重建失败的最常见原因之一是股骨隧道定位不良（ACL足迹中心和隧道方向）。这种失败可能导致半月板病变和骨关节炎的发展。因此，准确识别ACL股骨足迹对于精确的隧道放置、恢复原生膝关节力学、术后膝关节健康以及预防移植物失败至关重要。人工智能（AI）的最新进展为改进图像引导骨科手术带来了新机遇。然而，目前现有的AI研究主要集中在基于术前和术后磁共振（MR）图像的ACL分割和断裂分类上。使用深度学习方法识别ACL足迹中心尚未得到深入研究。因此，本研究旨在探索直接从3D MR图像中识别ACL股骨足迹的3D深度学习模型。我们开发了两种综合的3D深度学习架构：一种是基于3D图卷积神经网络的几何模型，应用于3D股骨网格；另一种是基于3D MR图像的3D地标增强识别模型。从公开可用的数据库中使用了总共4883个右膝和3087个左膝图像集。80%用于模型生成，20%保留用于模型测试。两种模型均取得了优异的性能；然而，基于图像的方法优于基于模型的方法（平均误差为2.1mm对比2.8mm）。因此，3D深度学习为ACL足迹定位提供了一种可行的临床方法，并具有提高ACL重建足迹准确性的潜力。

关键词：GCNN，地标，检测，ACL，足迹

1. 引言

美国每年大约进行150,000至400,000例前交叉韧带（ACL）重建手术[1]。虽然确切的手术数量未知，但这一数字与ACL损伤发病率的上升相一致[2]。尽管ACL重建改善了膝关节稳定性，但由于膝关节力学恢复不充分，术后膝关节不稳、异常运动学和骨关节炎的发生率仍然很高[3]。早期的ACL重建手术通常采用经胫骨技术，其中股骨隧道是基于预钻的胫骨隧道进行钻孔的。然而，这种技术因导致股骨隧道放置不当而受到批评，这是导致ACL翻修的最常见因素之一[4]。ACL股骨足迹解剖识别的进展引发了人们对在ACL重建中改善股骨隧道位置的新兴趣[5]。作为回应，开发了独立于胫骨的股骨隧道钻孔技术，该技术更准确地重现了原生ACL解剖结构[6]。然而，ACL足迹识别仍然是一个手动过程。人工智能的最新发展，如CNN（卷积神经网络）和3D深度学习算法，使得自动化基于磁共振图像（MR图像）的ACL损伤分析成为可能。初期研究主要围绕识别ACL撕裂展开。Liu等人[7]提出了一个由基于LeNet、基于YOLO和基于DenseNet的分类器网络组成的CNN级联流水线，用于选择包含ACL的矢状面MR切片，基于地标识别ACL区域，以及分类ACL状态（完整或断裂）。基于AlexNet CNN架构的MRNet[8]用于膝关节MR图像分析（在每个三平面中），被提出来分类异常、ACL撕裂和半月板撕裂。它分别达到了0.937、0.965和0.847的曲线下面积一致性。Qu等人[9]提出了一个从粗到细的深度学习流水线，用于定位ACL断裂并分类断裂类型。它使用基于3D UNet的分割模型来隔离ACL区域，然后使用基于YOLO的2D模型定位ACL断裂点，最后分类断裂类型。Liu及其同事[10]提出了一个基于ACLNet的模型，该模型将卷积MR图像表示与基于Transformer的骨形态点云相结合，利用成像和几何数据来预测ACL断裂。

由于韧带尺寸小、与周围软组织对比度低以及损伤后外观的变异性，自动分割整个ACL仍然是一项具有挑战性的任务。Lee等人[11]提出了一种带有形状先验和标签细化的基于图割的ACL分割。该方法需要初始的半手动种子选择以获得粗略的ACL区域。Flannery等人[12]应用2D U-Net使用246个MR图像集进行完整ACL分割。该模型达到了0.84的平均Dice分数。MGACA-Net[13]修改了DeepLabv3架构，使用空洞空间金字塔池化和挤压激励块在膝关节MR切片上分割ACL区域。它报告了97.64%的最高Dice分数。大多数ACL分割工作探索了U-Net衍生模型以2D或2.5D方式分割ACL和撕裂的ACL。这些模型都没有评估定位ACL足迹的准确性。开发能够直接从3D体积MR图像中准确识别股骨ACL足迹的3D深度学习模型，可以通过为ACL重建期间更准确的隧道放置提供解剖目标，帮助弥合自动图像分析和手术规划之间的差距。这种自动足迹识别模型可以与新兴的计算机导航和关节镜计算机视觉系统相结合，以改善ACL隧道放置，从而改善结果。然而，ACL股骨足迹的自动化患者特异性定位仍然研究不足。因此，本研究旨在探索直接从3D MR图像中识别ACL足迹的3D深度学习模型。

2. 方法

2.0 ACL足迹中心定位

将ACL足迹中心识别为3D体积图像或3D表面网格内的单个点具有挑战性。单点检测是一个高度不平衡的定位问题。目标中心点仅占据整个体积图像域的一小部分。因此，使用3D特征卷积进行直接的单点预测很难将单个地标点与周围的解剖结构区分开来。我们通过将ACL中心定位表述为地标热图预测任务来解决这种空间不平衡问题，其中真实中心由空间概率分布表示，而不是单个正体素或顶点。

2.0.1 基于3D网格的ACL足迹中心定位

基于3D股骨表面网格的模型是我们通过将其定位表述为地标检测任务来识别ACL股骨足迹中心的第一次尝试。受图CNN[14]的启发，我们开发了一个建立在动态图CNN网络[15]（DGCNN）上的框架，这是一种进行顶点级地标检测的3D几何深度学习方法。该网络由三个主要阶段组成：网格预处理（以减少顶点和面开销）、DGCNN图特征提取和基于顶点的概率图估计（图1）。

图1 用于ACL足迹中心检测的DGCNN

阶段1：网格预处理
对于每个膝关节，PLY格式的股骨表面网格连同带注释点的CSV文件是模型输入。地标点由ACL股骨足迹中心和周围的采样点组成。后者增加了在3D网格中空间分布的中心点特征表示的可能性。股骨网格通常由数十万个顶点组成，使得基于网格的图卷积成本过高。因此，我们执行预处理步骤，通过确定性采样和归一化来减少顶点。确定性采样确保每个点的均匀间距。每个顶点的解剖位置和局部表面方向由一个七维特征向量表示：𝑓!=#𝑥"%,𝑦"%,𝑧"%,𝑛#,𝑛$,𝑛%,𝑟!+
𝑥"%,𝑦"%,𝑧"% : 顶点坐标
𝑛#,𝑛$,𝑛%: 表面法线
𝑟!: 距中心的距离

阶段2：动态图特征提取
DGCNN模型通过边缘卷积块在3D网格点云上执行ACL股骨足迹中心地标检测，该块在每个网络层动态重新计算k近邻。动态计算技术有助于获取3D点云的局部几何形状。浅层和深层分别连接在物理距离和学习特征空间中接近的顶点。动态图卷积神经网络学习多尺度几何表示并生成顶点级的概率分布。

阶段3：顶点级概率估计
多尺度顶点特征通过多层感知机为每个顶点的每个关键点（中心和采样点）生成一个定位分数（logits，图1）。这会生成一个N×K张量（图1），其中K列代表3D股骨网格上的空间似然图。在训练过程中，每个带注释的关键点由一个软高斯目标表示，而不是仅仅一个正顶点，其中更接近ACL足迹中心的顶点具有更高的概率。随着顶点远离中心，概率降至接近零。
DGCNN网络提取多尺度几何特征，并为每个目标地标点（中心和采样点）生成顶点级的概率分布图。训练过程基于将高斯热图监督与坐标回归损失相结合，给予接近ACL中心的点更高的权重。在推理过程中，预测的中心坐标是从所有采样顶点估计的，精细化的估计顶点源自最高概率图。基于原始的动态图CNN模型，我们将网络与确定性网格采样、网格归一化、7维顶点特征、DynamicEdgeConv主干中扩大的感受野以及带有坐标回归损失的KL散度热图损失相集成。总体机制确保了在3D股骨表面网格上几何和解剖学上正确检测ACL足迹中心。

2.0.2 基于3D体积图像的ACL足迹中心定位

基于3D MR图像的模型（图2）是我们识别ACL股骨足迹中心的第二次尝试，我们再次将其定位表述为地标检测任务。我们受到nnLandmark[16]架构的启发，该架构改善了3D医学图像中小而模糊目标的定位。我们开发了一个框架，通过挤压激励（SE）注意力[17]、多尺度高分辨率融合模块和Top-K峰值解码构建块扩展了原始的nnLandmark架构，以进一步改善对3D MR图像中空间模糊的小目标（如ACL足迹中心）的检测。对于一个新的3D MR图像体积，所提出的架构为每个目标地标生成一个热图通道。在应用sigmoid激活后，每个体素的热图强度代表预测概率。

图2. 基于3D图像的ACL足迹中心地标检测架构。

步骤1：主干
地标检测架构主干基于传统的基于3D残差的nnUNet[18]。编码器的浅层捕获局部空间特征，而深层编码更抽象的解剖和上下文全局特征。瓶颈扩展了SE块，以提供最大的感受野并捕获全局上下文。解码器逐步对瓶颈表示进行上采样，并通过跳跃连接将它们与编码器侧的特征图合并。基线主干从1 x 1 x 1卷积预测头输出一组初始的地标热图logits。

步骤2：挤压激励注意力
为了改善特征判别能力，挤压激励注意力块被集成到更深的编码器阶段和瓶颈中。SE块通过重新校准特征图和捕获通道依赖性来实现通道级注意力。挤压操作符应用全局平均池化在输入特征图上生成通道级的局部描述符。激励操作符将输入特定的描述符映射到一组通道权重，以生成最终的通道级注意力。SE块放大了更多信息的通道特征，并抑制了地标检测的噪声和不太相关的特征。

步骤3：多尺度高分辨率融合
主干解码器通过1 x 1 x 1预测头卷积层输出第一组热图logits。然而，解码器特征可能不具备定位小目标（如ACL足迹中心）所需的分辨率。因此，使用多尺度融合模块来改善第一组热图预测。提取第二和第三编码器的中间特征，并使用1 x 1 x 1卷积转换为共同的特征大小。然后使用三线性插值将这些特征调整为最终的热图分辨率，并与第一组热图logits连接。通过残差3D卷积块的进一步处理得到最终的热图。

步骤4：Top-K峰值解码
推理是通过使用sigmoid激活将处理后的logits分数转换为概率热图，然后进行Top-K峰值选择解码来完成的。首先使用概率阈值（τ = 0.10）过滤体素。然后使用3D最大池化方法定义空间局部最大值，邻域由最小距离参数定义。排名候选者按分数降序处理。任何位于已选峰值最小距离（r=5个体素）内的候选者都被抑制，以去除重复检测。保留K个最高分数的峰值（默认k=5）；排名最高的峰值作为主要地标预测。然后，将结果点转换回原始图像空间，并在患者/世界坐标系中报告。
所提出的增强型nnLandmark检测架构由三个集成的构建块组成：SE注意力突出了在更深的编码器和瓶颈中选择通道的重要性；多尺度融合有助于恢复最终热图中高分辨率的空间特征表示；Top-K解码有助于确保单个体素候选者的推理更稳定。这三个构建块旨在提高模型检测小地标（如ACL足迹中心点）的能力。

2.1 MRI数据

从3DReasonKnee数据集[19]中，我们获得了源自骨关节炎倡议（OAI）的7969个3D膝关节MR图像。这些图像是使用标准化3T西门子MAGNETOM Trio扫描仪获取的轴向3D双回波稳态（3D DESS）采集。这些DESS体积的体素分辨率约为0.365 x 0.365 x 0.7 mm3，每个体积的图像大小为384 x 384 x 160切片。3DReasonKnee数据集提供了基于分割的解剖注释掩码，如ACL和股骨；然而，它不提供ACL股骨足迹中心地标。在本研究中，我们从ACL和股骨分割掩码中推导出ACL足迹中心识别算法。4883和3087个图像集分别代表右膝和左膝。我们拆分数据集，使80%的图像用于模型训练，其余20%用于模型测试（表1）。我们通过开发基于ACL和股骨分割掩码的3D网格重建算法和ACL中心识别算法，生成3D股骨网格和ACL足迹中心（作为3D地标点）。对于3D网格方法，每个股骨网格有一个ACL足迹中心点和20个周围的采样点，每个病例产生21个地标。

3. 结果

所提出的3D网格方法在左右股骨数据集上独立评估，使用预测地标点和真实地标点之间的欧几里得距离（绝对平均误差）。ACL足迹中心识别性能指标包括平均误差、中位数误差、第95百分位误差（P95，即95%的地标误差落在其下的距离）以及距离阈值2 mm、3 mm和5 mm下的正确关键点百分比（PCK）。
对于右侧股骨数据集，所提出的3D网格DGCNN框架获得了2.638 mm的平均误差，中位数误差为2.096 mm（表2，图3）。左侧股骨数据集的性能略差于右侧。平均检测误差在3 mm以内（左膝和右膝分别为59%和73%）。对于左侧股骨数据集，所提出的3D网格DGCNN框架获得了3.170 mm的平均检测误差和2.378 mm的中位数误差（表2，图3）。95%的地标预测在真实位置6.9 mm以内。

4. 结论

这项初步研究说明了应用3D深度学习使用两种互补模型自动检测ACL股骨足迹中心的可行性。由于没有其他研究（据我们所知）评估过自动定位ACL股骨足迹中心的准确性，因此无法与文献进行直接比较。在这些模型中，基于3D体积图像的nnLandmark检测优于3D网格几何DGCNN。假设一个完美圆形的股骨足迹为126.8 mm2 [20]（图5），我们的基于图像和基于网格的模型平均误差使7mm的钻孔保持在股骨足迹内。如果钻头尺寸增加到10mm，那么基于图像和基于网格的模型预测分别只有6%和14%的孔落在ACL足迹之外。这些与实际足迹的微小偏差仅发生在最大钻头尺寸时，表明这两种方法在指导手术决策方面都显示出前景。由于本研究基于具有完整ACL的图像，基于模型的方法可能由于图像中存在完整的ACL而产生更准确的结果。因此，基于网格的模型虽然准确性稍低，但在定位ACL撕裂个体的股骨ACL足迹方面具有重大前景，因为原始足迹可能在图像上不可见。在未来的工作中，我们将研究基于图像的深度学习模型处理完整和撕裂ACL的泛化能力，并研究模型增强以进一步减少误差。因此，本研究表明，3D深度学习提供了一种可行的临床方法来辅助ACL足迹定位，提高ACL重建足迹的钻孔位置选择准确性。
