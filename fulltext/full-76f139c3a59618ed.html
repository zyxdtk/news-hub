摘要

长上下文模型会反复求解密切相关的检索问题。注意力或全局检索可以保留大规模存储，但每次前向传播都要重新搜索重要内容。循环压缩只有通过提前决定保留哪些信息才能避免这种搜索。这两种机制都没有直接利用相邻检索步骤中有用的记忆可能大量重叠这一事实。我们提出一种替代方案，其中检索是在地址空间中的持久局部遍历。我们将记忆的内容与其地址分离。效用由检索内容所揭示的信息定义，而几何结构仅决定获取该信息的代价高低。由此得到一个代价正则化的索引目标，它在局部邻域内保留信息价值，同时对每个被设为局部可访问的记忆收取代价。其边际价值形式同时给出吸引压力和排斥压力。因此，当额外价值超过检索代价时，互补的记忆应当可共同检索；而冗余的记忆不应仅因其单独有用就占据同一检索集合。作为原理验证，我们仅在 MiniGrid Memory 上测试了最简单的固定几何实例。持久局部遍历头在五 token 上下文下经过 0.59M 训练步后达到 0.95 的平均回报，相比之下，高斯绝对寻址需要 0.94M 步，类别绝对寻址需要超过 2M 步。该实验并未测试学习的几何结构或重复检索，而是启发了如下假设：有状态检索可能比无状态检索更易学习。要测试完整提出的方法，还需进一步实验。

1 引言

长上下文模型面临一个基本的权衡。保持大量历史可用可以保留信息，但注意力或检索必须反复确定历史中哪些部分重要。将过去压缩到有界的循环状态中可避免扫描，但压缩是在所有未来的信息需求已知之前执行的。稀疏注意力、近似最近邻搜索和外部检索降低了单次查询的代价，但通常仍将连续查询视为全新的匹配问题 [5,7,9,6]。

这忽略了重复性——第三个代价来源。在两个相近推理步骤上有用的记忆不必是独立的集合。为了避免这种代价，必须在检索之前就知道待检索记忆的价值信息。我们将这一思想作为遍历式检索来研究。记忆、当前上下文和检索头被放置在一个地址空间中。当前上下文和检索头的位置旨在保存关于待检索记忆当前期望价值的信息，因为 ε 距离内的所有记忆都将被检索。

我们的提案在一个重要方面不同于语义检索：地址应由检索记忆内容的决策价值塑造，而非由内容本身之间的相似性塑造。这一区别很重要，因为两条语义相似的记忆可能是冗余的，而两条不相似的记忆可能只有在一起才有用。

本文做出两个刻意有限的贡献。第一，我们给出一个用于学习这种几何结构的决策论目标，并推导冗余性和互补性如何影响局部共同检索。第二，我们报告一个小规模的原理验证实验，其中几何结构固定，仅学习持久检索机制。我们并不声称本文提出的学习式价值索引已经得到实验验证。

相关工作。 外部可微记忆早已将计算与存储状态分离。神经图灵机结合了内容寻址与位置寻址 [3]。可微神经计算机增加了动态分配和时间链接 [4]。李群访问神经图灵机（Lie-access Neural Turing Machines）在机制上尤为接近：记忆占据连续的地址流形，读头通过相对变换移动 [12]。神经地图则使用物理位置作为外部记忆索引 [8]。现代稀疏注意力和检索系统使用哈希、学习路由、最近邻搜索或检索索引来避免关注每个存储项 [5,9,11,6]。我们则追问：地址空间本身能否按未来检索的期望效用来组织，并在相关查询间被持久遍历。

2 价值索引记忆

2.1 内容、上下文与地址

记忆的内容必须与其存储位置区分开来。设 Ω_t = {1,…,n_t} 索引时刻 t 可用的外部记忆。记忆 j 包含一个随机变量 M_j ∈ ℳ。在检索之前，M_j 在模型的当前信息状态下是未观测的，检索该记忆会揭示一个实现的内容 m_j。

设 C_j^w 表示记忆 j 被写入时的上下文。其地址为

z_j = Φ(C_j^w) ∈ ℝ^R. (1)

在给定的已实现记忆存储条件下，z_j 是一个固定位置。检索 j 会将 m_j（而非 C_j^w）插入模型的工作上下文。

当前上下文 C_t 由最近的观测和最近检索的记忆组成，包含预测器当前可用的信息序列。检索头的位置单独维护，不属于 C_t 的一部分。

对于已实现的当前上下文 c 和集合 S ⊆ Ω_t，设 M_S 表示按固定规范顺序排列的相应记忆内容。我们将其查询前信息价值定义为

V(S;c) = 𝔼[U(c ⊕ M_S) − U(c) | C_t = c], (2)

其中 U 是任务效用，例如期望回报或负预测损失，⊕ 表示并入工作上下文。V 也可以通过反事实训练从下一 token 预测器中学习。

重要的是，V 由记忆内容定义，(2) 中不出现任何地址。几何结构影响哪些内容可以廉价地检索，但不影响这些内容的价值。

在理论讨论中，我们假设自由处置，即额外信息不会降低期望效用。因此

S ⊆ T ⟹ V(S;c) ≤ V(T;c). (3)

2.2 代价正则化的局部索引

设 B_ε(x) = {j ∈ Ω_t : ‖z_j − x‖ ≤ ε} 表示从地址 x 局部可访问的记忆。上下文 c 被映射到查询位置 Φ(c)，得到

N_c(Φ) = B_ε(Φ(c)). (4)

一个朴素的目标只会最小化该邻域缺失的信息，即 V(Ω_t;c) − V(N_c(Φ);c)。然而在 (3) 之下，该目标有一个平凡解：将每个上下文和记忆映射到同一点会使所有 Ω_t 都落入每个球内，信息损失为零。

因此，我们对每个可访问的记忆收取检索代价 λ > 0：

ℒ_λ(Φ) = 𝔼[V(Ω_t;C_t) − V(N_{C_t}(Φ);C_t) + λ|N_{C_t}(Φ)|]. (5)

外层期望遍及上下文和已实现的记忆存储。常数嵌入现在在每次查询时都要支付 λ|Ω_t|，不再普遍最优。

对于固定上下文，最小化 (5) 等价于选择一个使下式较大的局部可访问集合：

J_λ(S;c) = V(S;c) − λ|S|. (6)

因此，λ 用价值阈值取代了任意的 top-k 预算：只有当一条记忆新增的信息足以抵偿其检索代价时，才值得使其可访问。

2.3 互补性与冗余性诱导相反的压力

将已拥有集合 S 的访问权后记忆 j 的边际价值定义为

Δ_j(S;c) = V(S ∪ {j};c) − V(S;c). (7)

对于两条记忆 i, j ∉ S，定义其条件交互作用

s_ij(S;c) = V(S ∪ {i,j};c) − V(S ∪ {i};c) − V(S ∪ {j};c) + V(S;c) (8)
= Δ_j(S ∪ {i};c) − Δ_j(S;c).

正的 s_ij 是互补性，意味着观测 i 会提高 j 的边际价值。负的 s_ij 是冗余性。

观察 1（代价调整的共同检索）。 对于任意上下文 c、背景集合 S 以及 i, j ∉ S，

J_λ(S ∪ {i,j};c) − J_λ(S ∪ {i};c) = Δ_j(S ∪ {i};c) − λ. (9)

因此，当且仅当 Δ_j(S ∪ {i};c) > λ 时，联合检索优于仅检索 i。

证明。 代入 (6) 并消去公共项。∎

该观察为几何结构同时给出了吸引准则和排斥准则。如果 i 使 j 足够有价值，使得 Δ_j(S ∪ {i};c) > λ，那么局部邻域会受益于使该对记忆可共同访问。正交互作用 s_ij 增加了出现这种情况的上下文。

反之，假设 j 在 i 已知后是冗余的。在精确情况下，V(S ∪ {i,j};c) = V(S ∪ {i};c)，因此 Δ_j(S ∪ {i};c) = 0，同时检索两者相比仅检索 i 恰好损失 λ。因此，索引没有动机仅凭两者较高的单例价值就将它们放入每个查询邻域。由于这种排斥压力，学习到的几何结构应尽可能使冗余的替代项分别可达。特别地，‖z_i − z_j‖ > 2ε 足以确保没有单个 ε 球同时包含两者，尽管该目标并不要求这一特定的几何解。

这一论证关注的是决策论意义上的冗余，而非 M_i 与 M_j 之间的原始统计相关性。隐藏表示的协方差依赖于表示方式，未必能表明两条记忆是否为下游决策提供相同的信息。

替代品竞争相同的联盟。 交互结构还形式化了更强的冗余概念。如果对每个上下文 c 和每个不包含它们的背景集合 S，都有

V(S ∪ {i};c) = V(S ∪ {j};c) = V(S ∪ {i,j};c), (10)

则称记忆 i 和 j 为价值等价替代品。那么对每个 S, c 有 Δ_i(S;c) = Δ_j(S;c)。对另一个联盟 A，定义 A 引起的 i 边际价值变化为

η_i(A|S,c) = Δ_i(S ∪ A;c) − Δ_i(S;c). (11)

式 (10) 立即蕴含

η_i(A|S,c) = η_j(A|S,c)，对所有 A, S, c。 (12)

因此，精确替代品具有相同的个体价值，并且与每个其他联盟共享相同的交互特征。在这个意义上，冗余记忆竞争相同的协同集合。这表明学习到的地址几何应由价值和交互特征驱动，而非由原始记忆内容的相似性驱动。

2.4 作为遍历的持久检索

一旦存在有用的几何结构，检索就不必在每一步全局重启。设 i_t ∈ ℝ^R 为持久检索头位置，并定义

M_t = B_ε(Φ(c_t)) ∪ B_ε(i_t), W_t = ⋃_{τ=t−H+1}^{t} M_τ. (13)

因此，工作窗口保留最近遍历过的记忆，而检索头继续局部移动。

移动规则保持模块化。它可以像我们的实验中那样通过强化学习学习，即在上一次前向传播中移动到价值最高的记忆，或者通过扩展现有的键、值估计器来学习。找到在给定 Φ 构造下最规范的移动规则是未来的工作。

持久性可以发挥作用的情形可以在不选择固定 k 的情况下描述。定义代价最优检索集合

S_t* ∈ argmax_{S⊆Ω_t} [V(S;c_t) − λ|S|] (14)

及其单步新增漂移

D_t = |S_t ∖ S_{t−1}|. (15)

当 D_t 相对于 |S_t*| 较小时，大多数有用信息在连续检索之间得以保留。持久机制原则上可以复用先前的检索状态，而不是重新发现整个集合。

3 一个高度粗糙的固定 Φ 原理验证

学习 Φ 是本提案中尚未解决的核心部分。因此，我们测试一个刻意更弱的问题：在环境提供正确地址空间的前提下，相对且持久的检索是否比选择绝对记忆位置更容易学习？

对 Φ 的刻意粗糙近似。 理论模型从价值关系中学习 z_j = Φ(C_j^w)。本实验并非如此，而是用一个手工设计的映射替代 Φ，该映射源自记忆创建时的时空状态，示意性地为

Φ_0(C_j^w) = (x_j, y_j, t_j). (16)

因此，该实验假设物理邻近性和时间邻近性是有用的索引特征。

任务与架构。 我们使用 MiniGrid Memory [1]。智能体观察一个线索，穿过一条走廊，随后在 T 形路口选择对应的物体。策略使用 Transformer-XL 骨干网络 [2] 和 PPO [10]。每一步的动作是 a_t = (a_t^ext, a_t^mem)，其中第一个分量作用于环境，第二个分量移动检索头。

记忆地址空间固定为环境的空间和时间坐标。在这个早期阶段的实验中，没有学习价值索引嵌入。检索到的观测和当前观测进入共享的 FIFO 上下文窗口。模型首先在固定尺寸任务上以 64 的上下文长度进行无检索头预训练，然后在随机化变体上以 5 的上下文长度进行微调。在随机化任务中，相关线索位于决策前 7 到 17 个环境步之间。

我们将相对头移动与两个选择绝对记忆位置的头进行比较，后者分别由高斯分布和类别分布参数化。每种检索头条件使用六个随机种子，缩减上下文的无头基线使用三个种子。

结果。 主要的学习时间统计量是跨种子平均学习曲线首次超过 0.95 回报的训练步数。我们没有选择各种子阈值穿越时间的均值，因为某些单独的运行在训练预算内从未越过阈值。

相对移动在 0.59M 步后达到 0.95 阈值，相比之下，高斯绝对寻址需要 0.94M 步，类别绝对寻址需要超过 2.0M 步。尽管只接收五个上下文 token，它也产生了接近全上下文参考的轨迹。

这一结果仅支持初步论断，即在这个单检索任务中，增量相对寻址比所测试的绝对寻址替代方案更容易学习。它并未测试学习式索引目标 (5)、交互驱动的几何结构或低漂移假设。

一个富有启发性的阴性对照。 缩减上下文基线比预期更强。在短窗口下，智能体可以将线索间接编码到自己的行为中。在时间编码可用时，它等待与线索相关的步数，随后读取由此产生的时钟状态。当移除时间和空间编码并进一步缩短窗口时，它则可以在走廊中反复转弯，将线索编码到其近期轨迹中。这些都是合理的解。它们使我们无法声称存在能力差距，并使当前实验仅成为学习效率和行为效率方面的证据。

4 局限性

该框架最强的主张仍未得到检验。实验使用环境提供的几何结构，而不是从 (5) 学习 Φ。此外，实验只需要检索一条信息，因此没有测试所提方法在记忆变得有用时是否有助于顺序访问记忆。

固定维度几何结构能在多大程度上表示 ℒ_λ(Φ) 所偏好的检索集合也尚未被探索。如果两条记忆 M_i 和 M_j 非常相似，它们在许多上下文中可能是冗余的，即 s_ij(c) < 0，同时在许多其他上下文中是互补的，即 s_ij(c) > 0。最优的 Φ 能否将位置 z_i 和 z_j 安排为主要在它们互补的上下文中被包含于同一个 ε 球内，还是这种空间排列是不可能的？

此外，检索规则保持模块化而非规范化。需要对所提方法稍作修改，使检索头的移动和 Φ 的构造源自同一底层原则。

最后，虽然给出了损失项，但没有清晰详细地描述应如何训练 Φ。探索 s_ij 相对于 Φ 的行为可能会得到一类附加约束，使损失可以分解为多个更易训练的项。训练过程本身也未讨论。

5 结论

我们提出将长上下文检索视为在从检索效用学习到的地址空间中的持久遍历。将记忆内容与记忆地址分离产生了一个简单的组织原则。几何结构应使有价值的组合局部可访问，同时对不必要的共同检索收取代价。由此产生的目标自然地区分了互补性与冗余性，并表明精确替代品与其他记忆联盟共享相同的交互特征。

我们目前的 MiniGrid 实验仅测试了固定几何下的遍历机制。下一步的实证测试将是学习价值索引空间并评估重复的低漂移检索。
