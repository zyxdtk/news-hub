📅 2026-08-28 📄 arxiv 🔗 原文链接

原标题：Sliding-window beats linear attention

中文摘要： 本文对比了滑动窗口注意力（SWA）与线性注意力在大型语言模型中的表现。研究发现，带有注意力池的SWA在无需任何训练后微调的情况下，即可在短上下文任务中恢复99%的基线性能，与昂贵的线性注意力方法相当。在长上下文任务中，SWA性能显著优于线性注意力，且具有更快的解码速度和更低的内存成本。作者强烈建议从业者采用SWA以实现低成本高效推理。

摘要
由于二次注意力的特性，大型语言模型 (LLM) 消耗大量内存和能量。每个新 token 的成本都高于前一个。对于每个额外的 token，其键和值必须无限期地存储在内存中，这是不可持续的。
为了解决二次缩放问题，已经提出了几种替代方案，其中之一是将 LLM 改造为使用线性注意力。这个想法引起了广泛关注，因为它有望以低成本解决二次缩放问题并保持最先进的性能。然而，这一研究方向尚未与更简单的基线进行适当的比较。

在这项工作中，我们表明带有注意力池 的滑动窗口注意力 (SWA) 表现得与训练后的线性注意力模型一样好，甚至更好。我们在各种下游任务上的多个 LLM 中观察到了这一点。
对于长上下文推理任务 (大海捞针和 BABILong)，SWA 取得了高得多的性能（比线性注意力高 2 到 10 倍）。SWA 不需要训练后微调，速度极快，且所需内存低；因此，它是一个极其廉价且可靠的解决方案。

为了降低推理内存成本，我们强烈建议切换到 SWA，而不是训练线性模型。线性注意力模型可能已经展现出一些潜力，但它们可能需要从头开始训练或进行大量的训练后微调才能与 SWA 相媲美。

1 引言
大型语言模型 (LLM) 消耗大量内存和能量，因为它们随上下文长度呈二次方缩放
(
Vaswani et al., 2017
)
。每个新 token 的键和值都必须添加到 KV 缓存中，这导致了不断增加的内存和计算成本。

线性注意力方法
(
Katharopoulos et al., 2020
)
提出了一种替代方案，将时间和内存复杂度从二次方降低到线性。这消除了存储 KV 缓存的需要，使得推理时的内存成本很小且固定，而不是拥有一个不断增长的 KV 缓存。

虽然前景广阔，但线性注意力模型存在显著的缺点：1) 表达能力较低，2) 必须决定记住什么以免重要信息被覆盖/忽略的棘手问题，以及 3) 训练昂贵且大多数软件/硬件并非为它们而构建。

为了解决昂贵的训练问题，一种解决方案是采用现有的预训练模型，并将其昂贵的二次注意力替换为线性注意力。这通常需要使用数十亿个 token 进行微调
(
Bick et al., 2024a
)
，但 LoLCATs
(
Zhang et al., 2025a
)
表明，通过结合 Hedgehog
(
Zhang et al., 2024
)
和滑动窗口注意力 (SWA)，这可以仅用 4000 万个 token 来完成。在此过程中，LoLCATs 在知识和推理任务上恢复了大部分全注意力性能。

鉴于这些线性化方法的承诺，我们尝试了一下。我们的发现令人震惊。我们发现，将注意力掩码更改为带有注意力池 的滑动窗口注意力 (SWA)（意味着我们关注前
k
k
个 token 和前 4 个 token），为我们提供了比大多数线性化模型更好的下游性能。对于长上下文任务，性能差距更加明显，SWA 获得了比线性注意力训练后微调高得多的准确率。

带有注意力池的 SWA 保留了原始模型大部分性能的事实是众所周知的
(
Xiao et al., 2024
;
Cabannes et al., 2026
)
，然而，据我们所知，线性化方法尚未与带有注意力池的 SWA 进行比较。在这项工作中，我们在各种基准测试（短上下文和长上下文）上对各种模型（从 1.3B 到 70B）提供了这种直接比较。在此过程中，我们证明了预训练模型已经可以在推理时使用 SWA，以固定的推理内存成本获得高性能，而无需任何训练后微调或专门的线性内核。

3 缺失的比较：滑动窗口 vs 线性注意力
训练后微调线性注意力是解决二次缩放问题的一种有趣方式，尽管它有其自身的缺点（例如，低表达力、不知道保留什么和遗忘什么的棘手问题、需要额外训练）。然而，大多数线性注意力论文仅将线性注意力与常规（无注意力池）SWA 进行比较。这使得比较不充分，因为我们知道，一旦前几个（池）token 移出滑动窗口，无注意力池的 SWA 就会导致灾难性的失败。此外，训练后微调注意力模型的长上下文行为研究不足。

在这项工作中，我们证明了带有注意力池的滑动窗口注意力 (SWA) 在知识和推理短上下文任务上的表现与训练后微调的线性化模型相当或更好。SWA 在长上下文方面带来了特别大的收益。请参阅下面的结果。

速度：
随着上下文长度增长超过 1K，FA 的速度会下降；所有其他方法保持相对平坦的速度。SWA 是最快的方法（窗口大小=64 比窗口大小=512 快，但两者都比其他方法快）。

因此，SWA 速度更快，并且在窗口大小小于 512 时具有相似或更低的内存成本。

5 局限性 / 未来工作
我们的工作集中在免训练的 SWA 上。然而，训练后微调可以进一步提高 SWA 的性能
(
Yu et al., 2025
)
。未来的工作应该研究使用 SWA 进行训练后微调的效果，并在不同数量的 token（即缩放定律）下将其与线性化方法进行比较。

我们没有考虑某些 token 或整个层使用全注意力 (FA) 的混合模型。了解不同程度全注意力与 SWA 或线性注意力的影响将会很有趣。

该分析也可以扩展到超大型模型和复杂指标，例如智能体任务。对多模态 LLM 和具有多维滑动窗口（例如，具有 (x, y) 图像位置和 (t) 时间坐标的 3D）的视频生成模型的影响，作为未来的工作来研究也会很有趣。

请注意，对于视频扩散模型
(
Ho et al., 2022
)
，已经有强有力的证据表明免训练的 SWA 是一个极其强大的基线。例如，滑动瓦片注意力
(
Zhang et al., 2025b
)
在相同的采样步数下以 3.53 倍的速度恢复了 HunyuanVideo
(
Kong et al., 2024
)
基线 VBench 分数
(
Huang et al., 2024
)
的 97%。

6 结论
在这项工作中，我们表明带有注意力池的滑动窗口注意力 (SWA) 比大多数线性注意力训练后微调方法取得了更好的性能。它在没有任何训练后微调的情况下做到了这一点，并且具有更高的解码速度和更低的内存成本。

在短上下文推理任务上，SWA 恢复了 99% 的平均基线性能，这与更昂贵的最先进线性注意力训练后微调方法相匹配。在长上下文任务上，SWA 的表现比线性注意力训练后微调好得多。在上下文长度 256 时，SWA 在 S-NIAH-3 和 BABILong 上分别恢复了 20% 和 25% 的基线性能，而 LoLCATs 仅分别恢复了 2.2% 和 5%。

鉴于我们的发现，我们强烈建议从业者使用带有注意力池的 SWA，以便在固定的小内存成本下实现最佳性能。
