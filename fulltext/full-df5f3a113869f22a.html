MediX-R1：开放型医学强化学习框架

📅 2026-02-26 📄 arxiv 🔗 原文链接

MediX-R1：开放型医学强化学习 沙哈尔·沙吉·穆拉皮利 穆罕默德·伊尔凡·库尔帕特 奥马尔·穆罕默德 穆罕默德·齐丹 法哈德·汗 萨尔曼·汗 拉奥·安瓦尔 希沙姆·乔拉卡尔

摘要 我们提出MediX-R1，一种面向医学多模态大语言模型（MLLM）的开放型强化学习（RL）框架，可生成基于临床实践、自由格式的答案，突破选择题限制。MediX-R1以基线视觉-语言骨干网络为基础，结合基于分组的强化学习（GRPO/GSPO/DAPO），并设计了一种专为医学推理定制的复合奖励机制：基于LLM的准确性奖励（严格YES/NO语义判断）、基于医学嵌入的语义奖励（捕捉同义改写与术语变体）、以及轻量级格式与模态奖励（强制可解释推理与模态识别）。该多信号设计为开放型输出提供了稳定、丰富的反馈，弥补了传统可验证或仅MCQ奖励的不足。为评估进展，我们提出统一评估框架，支持文本与图文任务，采用基于参考的LLM-as-judge替代脆弱的字符串匹配指标，全面衡量语义正确性、推理质量与上下文一致性。尽管仅使用约51K条指令样本，MediX-R1在标准医学LLM（纯文本）与VLM（图文）基准上表现优异，超越强开源基线，在开放型临床任务上提升尤为显著。结果表明，结合全面奖励信号与LLM评估的开放型RL是实现可靠医学推理的可行路径。训练模型、精选数据集与源代码已公开于MediX-R1。

关键词：医学强化学习、开放型RL、GRPO、GSPO、医学VLM

1 引言 大型医学语言与视觉-语言模型正日益用于临床问答、分诊支持、报告撰写与教育（chen2024huatuogpto1medicalcomplexreasoning; sellergren2025medgemma; pieri-etal-2024-bimedix）。许多任务本质上是开放型的：临床医生期望简洁、自由格式的答案，能灵活整合上下文、不确定性与多模态证据。然而，多数训练与评估流程仍针对选择题（MCQ）或字符串匹配设计，导致：（i）低估有效临床同义表达；（ii）无法衡量推理质量或模态识别；（iii）在开放型场景中无法提供可靠的强化学习信号。因此，仅用监督目标或MCQ式奖励训练的模型常难以生成忠实、可解释、稳健的临床响应。

RL已在可验证奖励领域（如数学与代码）提升推理能力（shao2024deepseekmath; guo2025deepseek），但医学任务极少支持可执行检查。二元精确匹配对临床表述过于脆弱；BLEU/ROUGE可能误判语义正确答案；自由型VLM输出使视觉推理更复杂。单一奖励信号易导致不稳定或奖励欺骗（reward hacking），尤其当信号噪声大或过于宽松时。因此，亟需一种原则性方法，将语义正确性与结构/模态约束结合，实现高效、数据友好的医学MLLM开放型RL训练。

我们提出MediX-R1，一种开放型医学RL框架，通过复合奖励微调基线多模态骨干网络。设计包含：（1）LLM准确性奖励（严格YES/NO语义判断）；（2）医学嵌入语义奖励（捕捉同义与术语变体）；（3）轻量格式奖励（生成可解释推理痕迹）；（4）模态识别奖励（通过显式模态标签抑制跨模态幻觉）。该多信号目标稳定优化过程，提供传统奖励失效时的丰富反馈，实现单阶段开放型RL直接应用于临床任务。

图2：MediX-R1整体架构 MediX-R1开放型医学推理强化学习框架。输入医学图像与自然语言问题，模型策略通过基于分组的RL训练，利用多维奖励信号：a) LLM奖励评估输出质量与正确性；b) 嵌入奖励确保语义对齐；c) 格式奖励强制期望输出结构（<think>…</think>与<answer>…</answer>块）；d) 模态奖励确保响应基于指定影像模态。此奖励引导方法鼓励模型生成准确、可解释的推理路径。

与现有医学VLM的差异： 表1对比了MediX-R1与强开源模型在关键临床能力上的区别。首先，在“多模态多样性”方面，MediX-R1支持X光、CT、MRI、显微镜/组织病理学、超声、荧光造影、内窥镜、血管造影、乳腺X光、临床摄影、SPECT、OCT与眼底成像等多种模态，而MedVLM-R1仅限放射影像。MedGemma、HuatuoGPT-Vision、MedMO与BiMediX2虽覆盖临床模态，但需多阶段训练。在“单阶段RL”方面，多数基线依赖多阶段流程（预训练→SFT→RL），而MediX-R1采用单阶段端到端RL训练（Sec.2.2），简化训练流程，并因基于参考的LLM-as-judge准确性信号与医学嵌入提供可靠反馈（超越MCQ精确匹配），实现真正的开放型RL（不同于MedVLM-R1）。复合设计（格式+LLM裁判+嵌入+模态识别）稳定优化并减少奖励欺骗（Fig.7），带来表2中最佳平均性能。在“可解释推理”方面，MediX-R1输出显式推理痕迹（包含在<think>…</think>中），由格式奖励强制执行，使决策路径可审计；多数基线无法可靠生成结构化临床推理。尽管多模型支持“开放型响应”，MediX-R1明确优化自由型临床问答与模态识别，抑制跨模态幻觉，提升VLM鲁棒性。最后，MediX-R1实现“无标注推理”：无需人工整理推理链或验证思维链；RL奖励仅基于最终答案（通过参考LLM裁判与嵌入）计算，大幅降低数据整理成本，同时鼓励忠实、可解释推理。这些特性共同解释了其在纯文本与图文基准上的持续优势及临床实用价值。

为评估进展，我们提出统一的三阶段基于参考的LLM-as-judge评估框架，支持文本与图文任务的统一协议。通过以指令微调裁判（通过vLLM服务）替代脆弱的字符串匹配指标，评估捕获语义正确性、推理充分性与上下文一致性，适用于从简短问答到长报告生成的各类任务，减少评估与临床效用的偏差。尽管仅用约51K条指令样本，MediX-R1在多样医学基准上表现强劲。我们发现复合奖励不仅提升准确率，还缓解奖励欺骗、降低波动性，实现稳定训练与可解释输出。相比开源医学模型（如BiMediX2、MedGemma、HuatuoGPT-V、MedVLM-R1、MedMO），MediX-R1融合广泛模态覆盖、单阶段RL与结构化推理。

贡献： (i) 我们提出“开放型医学强化学习”，通过为临床推理定制奖励扩展基于分组的RL； (ii) 我们设计一种复合奖励，结合LLM准确性与医学语义信号，首次在医学领域实现开放型RL响应并稳定训练； (iii) 我们提出三阶段“基于参考的LLM-as-judge评估框架”，统一医学场景下LLM（纯文本）与VLM（图文）任务的基准测试； (iv) MediX-R1以单阶段RL配方（约51K指令）在LLM与VLM任务上取得优异结果，经参考LLM-as-judge与人类专家评估验证； (v) 我们证明所提复合奖励在基于分组RL算法上的有效性，在GRPO、DAPO与GSPO上实现一致性能提升。此外，我们在Qwen2.5-VL、Qwen3-VL与SmolVLM2等多种基线VLM上实验，均获得一致性能提升。

2.1 基于分组的RL与复合奖励 设置：给定输入𝐯（图像I+问题q）来自P(𝐕)，从冻结的行为策略πθold(⋅|𝐯)采样G个候选完成{o_i}_{i=1}^G。每个完成获得由复合奖励（Sec.2.2）计算的标量奖励r_i。随后计算标准化的组相对优势： A_i = (r_i - mean({r_j}_{j=1}^G)) / std({r_j}_{j=1}^G) 该方法无需学习价值函数，同时保持组内稳定的相对学习信号。

GRPO目标：GRPO（shao2024deepseekmath）通过PPO风格裁剪重要性比与KL正则化（至固定参考策略πref）更新πθ： 𝒥_GRPO(θ) = 𝔼_{𝐯,{o_i}} [ (1/G) ∑_{i=1}^G min(ρ_i(θ)A_i, clip(ρ_i(θ),1-ε,1+ε)A_i) - β 𝔻_KL(π_θ || π_ref) ] 其中ρ_i(θ) = π_θ(o_i|𝐯) / π_θold(o_i|𝐯)，ε,β≥0控制裁剪与正则强度。

复合奖励与不同优化器：除GRPO外，我们还用相同复合奖励运行两种近期基于分组的RL优化器DAPO（yu2025dapoopensourcellmreinforcement）与GSPO（zheng2025groupsequencepolicyoptimization），结果见表6。

DAPO（效率导向改进）：DAPO保留GRPO/PPO裁剪结构，提升token效率（yu2025dapoopensourcellmreinforcement总结）：（i）使用非对称裁剪（“Clip-Higher”），增大上限避免罕见但优质token梯度过早归零；（ii）对所有生成token平均损失而非按样本平均（减少长响应梯度稀释）。紧凑形式： 𝒥_DAPO(θ) = 𝔼_{𝐯,{o_i}} [ (1/∑_{i=1}^G |o_i|) ∑_{i=1}^G ∑_{t=1}^{|o_i|} min(r_{i,t}(θ)A_i, clip(r_{i,t}(θ),1-ε_low,1+ε_high)A_i) ] 其中r_{i,t}(θ) = π_θ(o_{i,t}|𝐯,o_{i,<t}) / π_θold(o_{i,t}|𝐯,o_{i,<t})。DAPO还通过动态采样（避免奖励相同的退化组）鼓励rollout，并可应用过长奖励塑造软性惩罚过长输出。

GSPO（序列级比值提升稳定性）：GSPO通过以长度归一化序列级比值（在完成内所有token共享）替代token级比值r_{i,t}(θ)解决其方差问题。GSPO使用相同裁剪目标形式，但以s_i(θ)替代token级比值： 𝒥_GSPO(θ) = 𝔼_{𝐯,{o_i}} [ (1/G) ∑_{i=1}^G min(s_i(θ)A_i, clip(s_i(θ),1-ε,1+ε)A_i) ] 因序列内所有token共享同一比值，GSPO降低序列内方差，在token级比值噪声大（如长输出与动态架构）时更稳定。

2.2 奖励设计 我们定义复合奖励： r = w_fmt R_fmt + w_llm R_llm + w_emb R_emb + w_mod R_modality 系数通过简单分阶段消融实验选定。所有实验中保持格式奖励权重较小且固定以强制可解析输出，其余权重分配至语义正确性（LLM裁判/嵌入）与模态定位。具体系数选择见Sec.4.3。

为何支持开放型医学RL：不同于受限于可验证信号或MCQ式准确率（如精确匹配、可执行或基于规则的评分器）的先前RL设置，我们的LLM准确性奖励R_llm与嵌入语义奖励R_emb为自由格式、临床定位答案提供可靠反馈。基于参考的LLM-as-judge在同义改写与临床表述下将语义正确性转化为稳健YES/NO决策；医学领域嵌入提供补充的内容对齐信号。双信号使强化学习在开放型医学推理中可行；格式（R_fmt）与模态（R_modality）奖励作为结构正则化器，但R_llm与R_emb是MediX-R1开放型RL的主要驱动力。

基准测试 表2：评估基准。上半部分为LLM（纯文本）任务，下半部分为VLM（图文）任务。我们的三阶段评估设置在统一框架下评估两类任务。MediX-R1在多样化基准中取得最高平均分，展现开源模型中的最先进性能。最佳与次佳结果加粗与下划线。

LLM准确性奖励（R_llm）：解析模型输出中<answer>...</answer>间最终答案，用紧凑参考LLM-as-judge提示（强制YES/NO决策）与参考答案比较。具体地，本地vLLM端点（Qwen3-4B）在候选语义回答参考时返回YES（映射为1），否则NO（映射为0）。该方法捕获正确性与对同义改写的鲁棒性，同时保持信号离散。

嵌入奖励（R_emb）：为鼓励语义对齐，用医学嵌入模型MedEmbed-large（balachandran2024medembed）计算预测答案与参考的余弦相似度。通过阈值（默认0.8）转为二元奖励：R_emb = 1[cos(e_pred, e_ref) ≥ τ]。该奖励补充LLM裁判，帮助捕捉术语变体。

格式奖励（R_fmt）：通过匹配正则表达式（标准化角度括号周围多余空白后）<think>...</think><answer>...</answer>强制结构化输出。匹配输出得1分，否则0分。该奖励稳定训练并提升医学推理可解释性。

模态识别奖励（R_modality）：通过要求模型在</think>块前输出预测模态标签（不区分大小写）鼓励显式模态定位。与参考模态标签比较，匹配得1分，否则0分。该奖励减少跨模态幻觉（如在X光上描述CT发现）。

3 评估框架 我们的评估流程分三阶段：生成、评估与评分。我们在纯文本（LLM）与图文（VLM）任务上评估，涵盖问答、选择题与长报告任务。

生成：通过vLLM对测试模型运行批处理推理，保存每样本完整响应。对生成结构化推理的模型，保留全部输出，但评分时通过剥离至并包括 closing </think> 标签的内容，仅评估最终答案块。

评估：采用独立基于参考的LLM-as-judge（Qwen3-14B，通过vLLM服务以在中等GPU上保证吞吐量与稳定性）。使用两种提示族：BASE模板（§A.8）用于开放型、单词与MCQ式问题，生成二元决策；MIMIC模板（§A.9）用于长报告生成，按临床标准评分。例如，对视觉问答题“激光斑点对比分析灌注图像中深蓝色代表什么？”参考答案为“低灌注”，若模型响应含隐式推理与最终答案“血流低或灌注少”，裁判判为正确并赋分1。裁判将预测答案与参考比较，考虑同义改写与临床等效表述。

评分：聚合判断输出为数据集级指标。对二元评估，报告样本平均准确率；对长报告，平均各样本标量量表分（可选标准化以比较）。我们也计算基准间的宏平均。

为何基于参考的LLM-as-judge（通过vLLM）：传统字符串重叠指标（BLEU、ROUGE、F1）与参考（真实值）比较常低估正确、临床适当的同义改写，且无法评估理由质量或上下文一致性。基于参考的LLM裁判通过精心设计提示捕获语义正确性、临床推理与任务特定标准符合性，而vLLM服务确保评估一致、快速、可复现。

4.3 奖励欺骗与缓解 在强化学习中，奖励欺骗指模型以非预期方式最大化奖励，常绕过真实目标。当策略利用单奖励信号缺陷以高分获取但未生成临床正确答案时发生。我们观察到两种具体模式（示例简化）：

嵌入模型利用：使用MedEmbed-large等嵌入模型时，短或非语义token可能虚假获得高余弦相似度。例如，对问题“图B中白色箭头指向何处？”，候选输出<answer>-</answer>对真实答案“肾动脉”得R_emb=1.0，尽管错误。

LLM裁判利用：使用Qwen3-4B等LLM作为奖励器时，模板占位符在提供参考比较时可能混淆裁判。例如，<answer>图中最大器官是[根据上述医学推理插入您的答案]</answer>对参考“肺”被判正确（R_llm=1.0）。

MediX-R1缓解措施：为抑制这些失败，MediX-R1采用复合奖励与输入/输出约束：（i）复合目标R_llm+R_emb+R_modality（共享R_fmt）减少对任一脆弱信号依赖，惩罚内容或模态识别不匹配（表4）；（ii）嵌入门控：对低于最小字符/词长、高标点或非字母数字比的答案设R_emb=0；嵌入前去除标点；校准相似度阈值；（iii）模态识别：R_modality要求正确模态标签，抑制可能欺骗文本奖励的视觉未定位捷径；（iv）结构控制与正则化：R_fmt强制可解析输出；组相对优势与参考策略的KL惩罚通过 discouraging异常行为减少退化欺骗；（v）奖励系数选择（消融驱动）：为使奖励设计透明，我们通过分阶段程序而非穷举超参数搜索选择系数。具体地，所有实验固定w_fmt=0.10，其余0.90质量分配至任务导向信号。这产生表4消融设置，如仅嵌入r=0.1R_fmt+0.9R_emb与仅LLM r=0.1R_fmt+0.9R_llm。对组合语义奖励，我们在固定w_fmt下评估R_llm与R_emb的少量直观分割；在验证基准上性能相似，我们选择稍偏重LLM裁判的配置。最后，添加模态定位时，为R_modality预留非格式预算的5%（即总奖励质量的0.045），并按v2重新归一化其余非格式权重。（完整系数选择细节见附录§A.3，含所有R_llm/R_emb分割。）

这些措施共同缓解奖励欺骗并稳定训练，导致更平滑奖励轨迹与更高最终性能（见图7）。

图7：整体验证奖励 vs 训练步数（不同奖励设计）。仅LLM或仅嵌入训练显示波动与奖励欺骗；LLM+嵌入减少但未消除不稳定。MediX-R1复合奖励稳定学习，提供最高最终奖励与最佳整体性能。
