摘要

直接偏好优化（DPO）越来越多地应用于成对偏好与逐点准则（如回复长度、答案正确性或安全评分）共存的场景。当两者不一致时，标准DPO对“偏好输出在逐点准则上得分更差”的样本对（冲突对）与其余（匹配）样本对一视同仁。我们刻画了一种系统性失效模式——约束漂移：对于足够小的更新，冲突对倾向于推高约束代价，而匹配对倾向于修复它，净变化取决于二者的平衡。该平衡导出一个闭式的对齐前诊断量 ρ_eq，仅凭数据集统计量即可计算，用于判断数据集是自我修正的还是需要干预。基于该诊断量，我们提出冲突感知DPO（CoDPO）：以由 ρ_eq 设定（而非调参）的强度对冲突对降权，并加入自适应边际偏移以处理训练过程中的残余漂移。实验表明，在冲突主导的领域上漂移随冲突暴露单调增长，而 ρ*_eq 给出的干预决策在每个领域上均与观测漂移一致，包括一个被其判定为自我修正的领域。在主要比较的四个领域上，CoDPO在基本保留普通DPO偏好学习的同时降低了漂移。与硬过滤及近期的约束式、多目标基线相比，CoDPO也取得了更优的漂移—偏好权衡。

1 引言

生成模型越来越多地通过偏好优化与人类目标对齐。RLHF [1,2,3] 与 DPO [4] 等偏好优化方法通过学习候选输出之间的成对比较，显著提升了有用性、推理质量和指令遵循能力 [5,6,7,8]。然而，在此类比较中被偏好的回复，在逐条评估每个回复的逐点准则（如正确性或安全性）上可能得分不佳 [9,10]。沿用 PSDPO [11] 的术语，我们将这种成对偏好与逐点准则的共存称为异构监督。

图1：CoDPO概览。 (a) 在DPO下，冲突对推高约束代价，匹配对将其拉低；ρ_eq 在训练前计算，用于比较二者。若推力占主导（ρ_eq < 1），CoDPO进行干预；否则数据自我修正，直接使用普通DPO。 (b) 冲突对按严重程度降权，τ 由 ρ_eq 设定。 (c) 训练过程中DPO边际发生偏移，当约束风险估计上升时偏移更强。与中的曲线为示意图。

在异构监督下，标准偏好优化对所有训练对统一处理，隐含假设偏好输出在逐点准则上也表现良好。在我们研究的领域中，相当大比例的样本对里偏好输出在逐点准则上得分更差：当准则为回复长度时，HelpSteer2 [12] 中57%的样本对里偏好回复是较长的一方；当准则为正确性时，GSM8K [13] 中71%、ARC [14] 中58%的样本对里偏好回复是错误的一方。此类样本对——PSDPO [11] 术语中的冲突对——在我们研究的其他冲突主导领域中出现的比例相近（表1）；其余样本对为匹配对。

冲突对倾向于把偏好优化推向“赢得成对比较但在逐点准则上代价更高”的输出。PSDPO [11] 将这种退化识别为文本到视频对齐中的语义漂移；我们将它在一般逐点准则下的对应现象称为约束漂移。

现有针对约束漂移的干预方法在如何权衡逐点准则与偏好上各有不同。约束式RLHF、约束式DPO [9,15,16,17,18] 与多目标方法 [19,20] 通过一个权重来设定该权衡：权重或由实践者固定，或在拉格朗日方法中依据估计平均代价是否超过目标而在训练中调整。硬过滤类似于偏好数据选择 [21]，直接删除冲突对——当冲突频繁时会丢弃大量数据；逐对加权 [22,11] 则对其衰减。在上述每种情形中，干预强度均由实践者选择，这给给定数据集留下两个悬而未决的问题：其一，它究竟是否需要干预（理想情况下应事先知晓）；其二，若需要，干预应有多强——无论训练前还是训练中。

我们从DPO下约束漂移的理论刻画出发回答这两个问题。我们证明：对于足够小的更新，冲突对与匹配对将约束推向相反方向——冲突对抬高期望约束代价，匹配对则修复它。因此漂移并非仅取决于冲突频率，而取决于冲突侧压力与匹配侧修复之间的平衡。在一阶近似下，该平衡可以仅凭数据集统计量估计，无需任何对齐步骤。由此得到闭式诊断量 ρ*_eq，指示数据集是自我修正还是需要干预（图1a）。

当需要干预时，我们的控制方法——冲突感知DPO（CoDPO）——在单一损失内作用于两个层面（图1b,c）。粗层面通过非对称冲突加权 [11] 按严重程度对冲突对降权，而非全部删除。CoDPO不靠调参确定加权强度，而是通过 ρ*_eq 从数据集统计量中解出强度，使冲突侧压力与匹配侧修复在一阶意义下平衡。诊断量在初始化时计算，而随着训练中策略偏离参考模型，平衡点可能移动，故可能残留一定漂移。细层面通过按每个样本对的约束代价差成比例地偏移其DPO边际来处理这种残余漂移，并在训练中测得的漂移上升时增强偏移。总之，诊断量告诉实践者数据集是否需要干预，CoDPO则确定干预应有多强。

我们在五个冲突主导领域（HelpSteer2、GSM8K、ARC、Math-Calc、TL;DR）和一个自我修正对照（PKU-SafeRLHF [10]）上检验诊断量与CoDPO。在这些领域中，除对照领域漂移始终可忽略外，漂移随冲突暴露单调增长；ρ*_eq 在全部六个领域上给出了正确的干预机制判定。在主要比较的四个领域（均判定需要干预）上，CoDPO在基本保留普通DPO偏好学习的同时降低了漂移。与硬过滤及近期的约束式、多目标基线相比，CoDPO也取得了更优的漂移—偏好权衡。

综上，我们的贡献如下：

  • 我们证明，对于小更新，每个DPO步骤引起的约束代价变化是冲突侧压力与匹配侧修复之间的平衡，并由此导出闭式诊断量 ρ*_eq，可在训练前判断数据集是否需要干预。
  • 我们提出CoDPO：其粗层面沿用PSDPO的非对称加权形式，但仅在 ρ_eq < 1 时启用，强度由 ρ_eq 设定而非调参；其细层面偏移DPO边际，并在训练中测得的漂移上升时增强偏移。
  • 实验上，ρ*_eq 给出的干预决策在我们评估的每个领域上均与观测漂移一致；在主要比较中，CoDPO在基本保留普通DPO偏好学习的同时降低了漂移，且与所比较的基线相比具有更优的漂移—偏好权衡。

2 相关工作

偏好与约束对齐。 RLHF [2,1] 与 DPO [4] 从成对偏好中学习；后续变体或修改偏好目标 [5,6,7,23,24,25]，或处理多个成对维度之间的冲突 [26,27,28,29]，但监督信号仍纯为成对形式。约束对齐则加入逐点代价：Safe RLHF [9] 采用带拉格朗日更新的代价模型，近期还出现了多种约束式DPO变体 [15,30,16,17,18]。这些方法与我们的监督结构相同——成对偏好加逐点准则——并通过实践者选定或由聚合代价估计驱动的参数来设定二者之间的权衡。我们的分析处理的是先于该权衡的问题：给定数据集究竟是否需要约束处理，若需要则应有多强——这由其样本对的冲突结构决定。

多目标优化与偏好数据选择。 PCGrad [31]、CAGrad [32]、Rewarded Soups [19]、MODPO [20] 等多目标方法通过梯度投影、模型插值或奖励组合处理目标竞争；以数据为中心的方法保留训练对的高边际子集 [21] 或选择样本对内的信息性token [33]；这些方法作用于目标或一般数据质量，而非样本对内部成对偏好与逐点准则之间的冲突。与我们的粗层面更接近的是Uni-DPO [22]：它保留每个样本对，但按外部评分边际与隐式奖励边际重新加权，使模糊和已学会的样本对贡献更少。在文本到视频对齐中，PSDPO [11] 则按冲突方向加权，用非对称指数权重对冲突对降权而保持匹配对不变。我们的粗层面采用该加权形式，区别在于强度的设定方式。PSDPO界定了冲突对贡献的梯度范数并证明该界随降权增强而缩小，这为降权提供了动机，但强度仍需调参。第3节转而追踪约束代价本身——冲突对抬高它、匹配对降低它。由于存在这种修复，一旦冲突权重降到临界值以下，代价在一阶意义下便停止上升；CoDPO据此设定强度并决定是否需要降权。为限制训练中累积的漂移，PSDPO仅在第二阶段引入冲突对，而我们的细层面在整个训练过程中偏移DPO边际，并在测得漂移上升时增强偏移。

3 约束漂移：压力与修复的平衡

3.1 设定与冲突结构

每个训练样本是一个偏好对，其中 y_w 为成对标注所偏好的输出，y_l 为被拒绝的输出。设 π_θ(y|x) 为按DPO标准做法初始化于参考策略 π_θ0 = π_ref 的生成策略，并设 L_R(θ) = −E_D[log σ(β r̂θ)] 为DPO偏好损失 [4]，其中隐式奖励边际为 r̂_θ = log[π_θ(y_w|x)/π_ref(y_w|x)] − log[π_θ(y_l|x)/π_ref(y_l|x)]。另有一个独立评分器 s: X×Y→R，与成对信号无关地评估每个输出，其方向约定为值越大表示越满足逐点准则；例如在长度约束领域 s 随回复长度递减 [34,35]，在安全约束领域 s 为奖励模型评分 [2,1]。约束代价 c(x,y) ≥ 0 关于 s 严格递减，并定义约束风险 C(θ) = E{x,y~π_θ}[c(x,y)]。

定义1（冲突 [11]） 对于偏好对，令 Δs := s(x,y_w) − s(x,y_l)，Δc := c(x,y_w) − c(x,y_l)。冲突对满足 Δs < 0（等价地 Δc > 0），即偏好输出在逐点准则上的得分劣于被拒绝的输出。定义冲突集 D_conf := {(x,y_w,y_l): Δs < 0} 与匹配集 D_match := {(x,y_w,y_l): Δs ≥ 0}，冲突率为 p_c := Pr(Δs < 0)。¹

¹ Δs = 0 的样本对满足 Δc = 0。我们将其归入 D_match 以使划分完备，并在附录B.1假设(vii)下定义其复合贡献 |Δc|·I_θ 为零；I_θ 本身无需在 Δc = 0 处求值。

3.2 压力、修复与诊断量

沿用 PSDPO [11]，冲突—匹配划分将DPO梯度拆分为两个子集的贡献：

∇L_R(θ) = (1−p_c)·g_match + p_c·g_conf，

其中 g_match = E_{D_match}[∇ℓ_R]，g_conf = E_{D_conf}[∇ℓ_R]，每样本损失为 ℓ_R = −log σ(β r̂_θ)。

PSDPO [11] 界定的是冲突项的范数，而我们界定它对约束风险的一阶效应，这与DPO训练动力学的一阶分析 [36,37] 一致：在关于 C 的正则条件与附录B.2的耦合论证下，冲突项可在一阶意义下抬高约束风险：

−⟨∇C, g_conf⟩ ≥ E_{D_conf}[β(1−σ(β r̂_θ))·Δc·I_θ] ≥ 0，

其中，当 Δc ≠ 0 时，几何项 I_θ := (Δc)^(−1)·⟨∇θ C_x(θ), ∇_θ r̂_θ⟩ > 0（其中 C_x(θ) = E{y~π_θ}[c(x,y)]）度量DPO学习该样本对时，提示 x 上的期望代价随单位代价差 Δc 的变化量；其名称来自两个梯度方向的内积。对 g_match 成立符号相反的类似界，刻画了匹配对提供的修复。

定理1（约束漂移） 在附录B.1的正则条件下（证明见附录B.3），对 L_R 做梯度下降满足

E[C(θ_{t+1}) − C(θ_t)] ≥ −η(1−p_c)μ_0 + η·p_c·κ_0 − (1/2)η²L_C·G_R², (1)

其中 η 为步长，L_C 为 C 的平滑常数，G_R 界定 ‖∇ℓ_R‖。项

κ_0 := E_{D_conf}[β(1−σ(β r̂θ))·Δc·I_θ] > 0，μ_0 := E{D_match}[β(1−σ(β r̂_θ))·|Δc|·I_θ] > 0

分别聚合冲突侧漂移压力与匹配侧修复。对足够小的 η，只要 p_c·κ_0 > (1−p_c)·μ_0，该下界严格为正，期望约束风险上升。定理1由此把每个DPO步骤表示为冲突侧压力与匹配侧修复的平衡：当压力压过修复时出现漂移；反之，当修复至少与压力持平时，我们称之为自我修正机制，第3.3节将给出精确表述。

注1（对齐前诊断量） 定理1的漂移条件 p_c·κ_0 > (1−p_c)·μ_0 等价于 (1−p_c)μ_0/(p_c·κ_0) < 1，且该比率在对齐开始时存在简单的数据依赖近似。μ_0 与 κ_0 都是对三个因子乘积取平均：学习信号、代价差与几何项。初始化时 π_θ = π_ref，故 r̂θ = 0，学习信号 β(1−σ(β r̂_θ)) 在每个样本对上取相同值 β/2，在比率中精确消去。假设（附录B.1）假定：按单位代价差计，学习一个冲突对所改变的期望代价与学习一个匹配对大致相当；在此假设下几何项也近似消去，比率简化为平均代价差 Δc̄_conf := E{D_conf}[Δc] 与 |Δc|̄match := E{D_match}[|Δc|]，得到闭式诊断量

ρ*_eq = (1−p_c)·|Δc|̄_match / (p_c·Δc̄_conf), (2)

即匹配对的总代价削减除以冲突对的总代价增量；因此 ρ_eq 不仅取决于冲突出现的频率，也取决于代价差的大小。在该近似下，ρ_eq ≥ 1 表示数据集在对齐前即可判定为自我修正、无需干预；低于1则需干预。附录B.5给出完整推导。

3.3 对冲突对降权

定理1建议保持匹配对全权重、对冲突对降权，正如 PSDPO [11] 在文本到视频对齐中所为；我们要回答的问题是：降权多少才够。我们为每个样本对赋予权重 w(Δs)：匹配对上为1，冲突对上落于 [0,1]；并用平均冲突权重 ρ := E_{D_conf}[w(Δs)] 概括冲突侧信号的保留程度，于是 ρ = 1 退化为普通DPO，ρ = 0 相当于删除全部冲突对。定理2以平均冲突权重的临界值 ρ* 回答该问题：低于该值时，削减后的冲突侧压力小于匹配侧修复。

定理2（漂移衰减） 在定理1的条件下，调制损失 L_{R,w}(θ) = −E[w(Δs)·log σ(β r̂_θ)] 满足上界

E[C(θ_{t+1}) − C(θ_t)] ≤ −η(1−p_c)μ_0 + η·p_c·κ_w + (1/2)η²L_C·G_R²，

其中 κ_w := E_{D_conf}[w(Δs)·β(1−σ(β r̂_θ))·Δc·I_θ] 是 κ_0 的调制对应项，且由假设(v)与切比雪夫求和不等式（附录B.4）满足 κ_w ≤ ρ·κ_0。利用 κ_w ≤ ρ·κ_0，该界的一阶部分至多为 η·[p_c·ρ·κ_0 − (1−p_c)·μ_0]，当 ρ 低于临界权重

ρ* = (1−p_c)·μ_0 / (p_c·κ_0)

时为负——这是冲突侧压力与匹配侧修复达到平衡的模型相关阈值。当 ρ < ρ* 且步长满足附录B.4给出的显式界时，约束风险的期望每步变化非正。

降权不改变匹配对的修复，而把冲突对的压力最多压缩到原来的 ρ 倍。一旦 ρ 降到 ρ 以下，削减后的压力小于修复，因此对足够小的步长，每次更新预期会降低约束风险或保持不变。普通DPO对应 ρ = 1，故当 ρ > 1 时它已满足该条件，数据自我修正。

要将该结果用于实践，CoDPO需要在训练开始前得到 ρ 的取值。由于 ρ 依赖模型梯度，CoDPO转而采用注1中的估计 ρ_eq——它只需要数据中的代价差。CoDPO把平均冲突权重设为 ρ = ρ_eq；当 ρ_eq ≥ 1 时则把所有权重保持为1，即普通DPO。即便如此仍可能残留漂移，原因有二：ρ 设定在估计的平衡点而非严格低于 ρ；且 ρ 本身会随训练推进而移动。第4节实现该粗层面，并加入处理残余漂移的细层面。

4 CoDPO：训练前与训练中的平衡控制

CoDPO把上述分析转化为两级控制：粗层面在训练前设定冲突权重（第4.1节），细层面校正训练中残留的漂移（第4.2节）。

4.1 粗层面：训练前设定权重

粗层面分配逐对权重，使其平均冲突权重匹配注1中的对齐前估计 ρ*_eq。²

² 式(2)的两个退化情形按惯例处理，各为该表达式的极限：若 p_c = 0，无冲突对，ρ_eq = +∞，调制关闭；若 p_c = 1，无匹配对，ρ_eq = 0，删除冲突对。

匹配对保持全权重，冲突对按严重程度通过如下加权族降权：

w_{τ,p}(Δs) = 1（当 Δs ≥ 0）；exp(−(|Δs|/τ)^p)（当 Δs < 0）， (3)

其中 τ 设定冲突对整体降权的强度，p 设定权重随冲突加剧而从1骤降至接近0的陡峭程度。³

³ 我们在所有实验中取 p = 8。当 p→∞ 时，调制趋近于 |Δs| = τ 处的硬阈值：保留轻度冲突、删除严重冲突；这与 ρ→0 不同，后者不分严重程度地删除冲突对。

该加权族在PSDPO [11] 的非对称指数加权基础上引入锐度参数 p，并在 p = 1 时复原后者；在PSDPO中 τ 作为超参数选取，而CoDPO中 τ 由诊断量确定。固定 p 后，每个 τ 对应平均冲突权重 ρ(τ) := E_{D_conf}[w_{τ,p}(Δs)]，它随 τ 从0增至 ∞ 而从0严格递增至1：小 τ 几乎压制所有冲突对，大 τ 使其几乎保持全权重。CoDPO选取平均冲突权重恰等于诊断量的 τ：

ρ(τ) = clip(ρ_eq, 0, 1). (4)

由于 ρ(τ) 严格递增，式(4)在 0 < ρ_eq < 1 时有唯一解，我们用二分法求解；当 ρ_eq ≥ 1 时，CoDPO将每个样本对的 w_i 保持为1。该校准仅使用数据集统计量，无需梯度计算。

4.2 细层面：训练中偏移边际

粗权重由 ρ_eq 校准，这假设学习信号 β(1−σ(β r̂_θ)) 在每个样本对上相同。该假设在初始化时成立（π_θ = π_ref 使每个样本对的边际 r̂_θ 为零）。随着训练推进，学习信号逐对分化，ρ_eq 所近似的平衡点在权重固定的同时发生移动，约束风险可能继续上升；我们称这部分剩余漂移为残余漂移。进一步压低冲突权重会丢弃冲突对携带的更多偏好信号，而固定权重又无法应对新出现的漂移，因此我们加入第二级控制：在不改动权重的前提下于训练中起作用。

偏移边际。 DPO以强度 β(1−σ(β r̂θ)) 推动每个样本对，该强度由样本对的边际 r̂_θ 决定：边际越大，该对越被视为已学会，推动越弱。因此，给样本对的边际加上偏移即可让DPO更强或更弱地更新该对，同时保持其粗权重 w 不变。在第 i 个样本对上，DPO把概率从 y{l,i} 移向 y_{w,i}。在冲突对（Δc_i > 0）上，y_{w,i} 是代价更高的回复，故此操作抬高期望约束代价；在匹配对（Δc_i < 0）上则降低之。为使冲突对被推得更轻、匹配对被推得更重，我们按各样本对的代价差成比例偏移其边际：

r̂_θ → r̂_θ + λ·Δc，λ ≥ 0.

冲突对的边际被抬高、被推得更轻——冲突越严重越是如此——因此它对约束代价的影响减弱，而其偏好仍被学习；匹配对的边际被压低、被推得更重，因此其修复增强。单个标量 λ 便可根据每个样本对自身的代价差进行调整，且与 ODPO [38]、R-DPO [35]、SafeDPO [18] 的固定边际偏移不同，它可以在训练中改变。

实现偏移。 边际偏移 r̂_θ → r̂_θ + λ·Δc 无需修改DPO损失：当参考分布被“倾斜”以抑制高代价输出时，标准DPO即可实现它，

π̃_ref(y|x) ∝ π_ref(y|x)·exp(−λ·c(x,y)), (5)

因为 log π̃_ref(y|x) = log π_ref(y|x) − λ·c(x,y) − log Z(x)，而归一化因子 Z(x) 为 y_w 与 y_l 所共有，在成对边际中消去，留下 r̃_θ = r̂_θ + λ·Δc（附录C.2）。以 π̃_ref 运行标准DPO等价于把 ℓ_R 换成 ℓ_tilt = −log σ(β·r̃_θ)；由于 λ·Δc 不依赖 θ，梯度方向不变，仅 σ 的自变量发生偏移：

∇ℓ_tilt = −β(1−σ(β r̂_θ + βλΔc))·∇r̂_θ. (6)

该倾斜还把偏移与约束对齐联系起来：由于最优DPO策略正比于参考分布乘以 exp(r/β)，针对 π̃_ref 训练所瞄准的是代价惩罚奖励 r − βλc——这正是拉格朗日方法 [9,16] 使用的形式，后者通常在估计代价超过预设阈值时抬高 λ；CoDPO则在训练对上测得的约束风险上升时抬高 λ，详见下文。

算法1：CoDPO训练流程

输入：偏好数据集 D、评分器 s、代价 c、参考策略 π_ref、温度 β、学习率 η、步数 T、间隔 K、步长比例 α
输出：训练后的策略 π_θ*
1:  为所有样本对计算 Δs_i 与 Δc_i
2:  计算 p_c 与 ρ*_eq（当 p_c ∈ {0,1} 时采用 §4.1 的退化惯例）
3:  若 ρ*_eq ≥ 1：
4:      对所有样本对置 w_i ← 1
5:  否则若 ρ*_eq = 0：
6:      匹配对置 w_i ← 1，冲突对置 w_i ← 0
7:  否则：
8:      二分法求解式(4)得 τ*，并按式(3)设定 w_i
9:  结束 if
10: 按式(8)计算 λ_tilt
11: 初始化 λ ← α·λ_tilt，C_prev ← Ĉ_D(θ_0)
12: 对 t = 1,…,T 循环：
13:     采样小批量 B
14:     以 ∇_θ L_CoDPO(θ) 更新 θ
15:     若 t mod K = 0：
16:         C_curr ← Ĉ_D(θ_t)
17:         若 C_curr &gt; C_prev：
18:             λ ← min(λ + α·λ_tilt, λ_tilt)
19:         结束 if
20:         C_prev ← C_curr
21:     结束 if
22: 结束循环

在线设定偏移强度。 粗权重下约束代价还会上升多少取决于训练的实际展开，这在训练前无法知晓，故 λ 需在训练中调整。调整 λ 需要决定何时增、增多少。何时增由约束风险的变化决定：每 K 个训练步在训练对上用估计量

Ĉ_D(θ) = (1/|D|)·Σ_i [q_{θ,i}·c(x_i, y_{w,i}) + (1−q_{θ,i})·c(x_i, y_{l,i})]，其中 q_{θ,i} = π_θ(y_{w,i}|x_i) / [π_θ(y_{w,i}|x_i) + π_θ(y_{l,i}|x_i)], (7)

测量，其中 q_{θ,i} 是当前策略在该样本对内分配给 y_{w,i} 的概率——这是归一化的策略概率，而非Bradley–Terry概率 σ(β r̂θ)。由于 Ĉ_D 只使用训练数据中已有的回复 y{w,i} 与 y_{l,i}，而不从策略采样新回复，故不产生生成开销；当策略在各样本对间总体上把概率移向代价更高的一方时，该估计上升。

增多少则由与 ρ*_eq 相同的一阶分析确定：在相同近似下，对未调制损失，消除一阶漂移所需的偏移强度为（附录C.4）

λ_tilt = max(0, 2·E_D[Δc] / (β·E_D[Δc²])). (8)

由于粗权重已消除部分漂移，直接令 λ = λ_tilt 可能过度校正，因此我们以增量 α·λ_tilt 渐进抬升 λ，并以 λ_tilt 封顶。具体而言：λ 从 α·λ_tilt 起步，使偏移自第一步即生效；每当 Ĉ_D 在相邻两次评估间上升——表明残余漂移增大、当前偏移过弱——λ 即增加 α·λ_tilt，直至 λ_tilt；否则保持不变，因为 Ĉ_D 稳定或下降表明当前偏移已足够。λ_tilt 中与0取最大可防止 λ 为负（那会反转偏移方向）。它还在自我修正数据上自动关闭细层面：此时 E_D[Δc] ≤ 0，等价于 ρ*_eq ≥ 1，故 λ_tilt = 0，且所有粗权重为1，CoDPO退化为普通DPO。

4.3 两级控制的结合

CoDPO把粗权重与边际偏移合并进单一损失：

L_CoDPO(θ) = −(1/|B|)·Σ_{i∈B} w_i·log σ(β·r̂_θ^(i) + βλΔc_i), (9)

其中权重 w_i 在训练前固定（第4.1节），偏移 λ·Δc_i 在训练中调整（第4.2节）。完整流程见算法1。离线校准在训练前一次性完成，每次二分迭代耗时 O(|D|)。每个优化步与普通DPO开销相同，因为 w_i、Δc_i 与 λ 仅以标量系数进入损失。额外开销只来自为更新 λ 而评估约束风险估计 Ĉ_D(θ_t)：它只需在固定训练对上做前向传播、无需生成，且每 K = 500 步才进行一次。

5.5 LLM评审评估

为评估超越概率级指标的生成质量，我们在全部7,220个 HelpSteer2 提示上用 JudgeLM-13B [43]（位置去偏评分）将CoDPO与各方法成对比较（表5）：CoDPO对每个比较对象都是胜多负少。与 SafeDPO [18]、PD-DPO [16]、MODPO [20] 相比，CoDPO在52%–86%的比较中获胜，与它们在表3中较低的 P 相符。与普通DPO [4]、C2-DPO [17]、Rewarded Soups [19] 相比，多数比较为平局（75%–77%），说明CoDPO相对普通DPO降低漂移的同时，该评审无法检测到生成质量的变化。GPT-4o 作为第二评审得出一致结论：CoDPO与普通DPO战平，且以44.9%对3.9%优于MODPO（附录F.3）。

5.6 消融实验

锐度参数 p。 式3的加权族在 p = 1 处复原PSDPO加权，在 p→∞ 时趋近冲突严重度上的硬阈值。表8在 HelpSteer2 上扫描 p：漂移降幅随 p 单调增大（22%至75%），而 P 基本不变（.640–.644）。受算力所限，我们在全部实验中固定 p = 8 而未逐领域调优，尽管此处更大的 p 能进一步降低漂移。

动态诊断量有效性。 为检验初始化近似 σ(β r̂_θ) ≈ 1/2，我们在 HelpSteer2 的普通DPO训练过程中追踪 ρ(t)，仅用全部7,220个样本对上的实际 σ(β r̂_θ) 重算学习信号：ρ(0) = 0.710 与 ρ_eq = 0.709 吻合；当 σ→0.946 时，ρ(t) 移至0.603（差距0.11）。这与训练中平衡点的移动相一致，也印证了自适应边际偏移的必要性；附录E报告训练中 λ 的轨迹。

6 结论

我们研究了异构监督下的约束漂移，并证明对于小更新，它取决于冲突侧压力与匹配侧修复之间的平衡。由该平衡我们导出诊断量 ρ_eq：它在训练前由数据集统计量算得，指示数据集是否需要干预。需要时，CoDPO通过PSDPO [11] 的非对称加权对冲突对降权——强度由 ρ_eq 设定而非调参——并在训练中偏移DPO边际以处理剩余漂移。实验上，ρ*_eq 给出的干预决策在所有评估领域与观测漂移一致；在主要比较中，CoDPO在基本保留普通DPO偏好学习的同时降低了漂移。自然的后续工作是在训练中随模型变化持续追踪平衡（而非仅在初始化时），并将分析扩展到偏好对本身在训练中生成的场景 [44]。
