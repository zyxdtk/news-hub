# DeepSeek预览新AI模型，缩小与前沿模型的差距

[Ram Iyer](https://techcrunch.com/author/ram-iyer/) 太平洋夏令时间上午6:30 · 2026年4月24日

![图片 4：一名男子在杭州一家商场拍摄DeepSeek展示屏](https://techcrunch.com/wp-content/uploads/2026/04/GettyImages-2272184430.jpg?w=1024) **图片版权：**CN-STR/AFP / Getty Images

[AI](https://techcrunch.com/category/artificial-intelligence/)

中国AI实验室DeepSeek发布了其最新大语言模型[DeepSeek V4](https://huggingface.co/collections/deepseek-ai/deepseek-v4)的两个预览版本，这是对去年V3.2模型及随附的[R1推理模型](https://techcrunch.com/2025/01/27/deepseek-claims-its-reasoning-model-beats-openais-o1-on-certain-benchmarks/)的备受期待的更新，后者曾[席卷AI界](https://techcrunch.com/2025/09/29/deepseek-everything-you-need-to-know-about-the-ai-chatbot-app/)。

该公司表示，DeepSeek V4 Flash和V4 Pro均为混合专家模型，上下文窗口各为100万个token——足以在提示词中使用大型代码库或文档。混合专家方法涉及每个任务仅激活一定数量的参数，以降低推理成本。

Pro模型总参数量为1.6万亿（490亿活跃），这使其成为目前可用的最大开源权重模型，超越了月之暗面的Kimi K 2.6（1.1万亿）、MiniMax的M1（4560亿），并且是DeepSeek V3.2（6710亿）的两倍多。较小的V4 Flash有2840亿参数（130亿活跃）。

DeepSeek表示，由于架构上的改进，这两个模型都比DeepSeek V3.2更高效、性能更好，并且在推理基准测试上几乎“缩小了差距”，与当前领先的模型（无论是开源还是闭源）不相上下。

该公司声称其新的V4-Pro-Max模型在推理基准测试中优于其开源同类，并在某些任务上超越了OpenAI的GPT-5.2和Gemini 3.0 Pro。在编程竞赛基准测试中，DeepSeek表示两个V4模型的性能“与GPT-5.4相当”。

![图片 5](https://techcrunch.com/wp-content/uploads/2026/04/260424_18h44m20s_screenshot.png?w=680) **图片版权：**DeepSeek

然而，在知识测试中，这些模型似乎略微落后于前沿模型，特别是OpenAI的GPT-5.4和谷歌最新的Gemini 3.1 Pro。该实验室写道，这种滞后表明其“发展轨迹大约落后最先进的前沿模型3到6个月”。

V4 Flash和V4 Pro都仅支持文本，这与许多提供理解及生成音频、视频和图像支持的闭源同类不同。

值得注意的是，DeepSeek V4比目前可用的任何前沿模型都要便宜得多。较小的V4 Flash模型每百万输入token收费0.14美元，每百万输出token收费0.28美元，价格低于GPT-5.4 Nano、Gemini 3.1 Flash、GPT-5.4 Mini和Claude Haiku 4.5。同时，较大的V4 Pro模型每百万输入token收费0.145美元，每百万输出token收费3.48美元，也低于Gemini 3.1 Pro、GPT-5.5、Claude Opus 4.7和GPT-5.4。

此次发布的前一天，美国[指责](https://www.bbc.com/news/articles/cpqxgxx9nrqo)中国使用数千个代理账户大规模窃取美国AI实验室的知识产权。DeepSeek本身也被Anthropic和OpenAI指责[“蒸馏”](https://techcrunch.com/2026/02/23/anthropic-accuses-chinese-ai-labs-of-mining-claude-as-us-debates-ai-chip-exports/)（本质上是复制）其AI模型。
