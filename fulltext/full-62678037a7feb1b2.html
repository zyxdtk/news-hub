Cloudflare推出专为AI智能体打造的...

📅 2026-08-07 📄 TechCrunch AI 🔗 原文链接

原标题：Cloudflare launches Kitesurf, a browser built for AI agents

中文摘要： Cloudflare推出了专为AI智能体设计的云托管浏览器Kitesurf。与面向人类的传统浏览器不同，它专注于管理上下文窗口、性能和token成本，并应对提示词注入等安全威胁。该浏览器基于Workers无服务器平台构建，融合了Blitz、Stylo和Boa JS等技术。它使开发者能低成本构建可自动浏览网页和填表的AI软件，在常见任务上比Chromium更高效，目前已通过超21.5万项网络平台测试。

Cloudflare 是最新一家加入构建新型网络浏览器竞赛的公司。但这家互联网基础设施提供商并没有向消费者推销 Chrome 的替代品，而是推出了 Kitesurf，这是一款专为 AI 智能体设计的云托管浏览器。

AI 软件正从回答问题的聊天机器人，演变为能够代表用户完成任务的智能体。浏览器是这一转变的关键部分，因为它们需要像人类一样浏览网络和使用网站。

Cloudflare 在其公告中解释说，与为人类构建的传统网络浏览器不同，为 AI 智能体构建的浏览器不关心视觉元素，如主题、标签页或浏览器扩展。为 AI 智能体设计的浏览器需要管理上下文窗口、性能、token 成本和可扩展性。该公司指出，它还面临不同的威胁模型，因为 AI 浏览器可能会受到提示词注入攻击等漏洞的影响。

借助 Kitesurf，AI 开发者将能够构建可以浏览网站、填写表单和完成其他基于浏览器任务的软件，而无需构建自己的浏览器软件。

Cloudflare 表示，它仅在 12 周前决定构建 Kitesurf，它完全运行在该公司名为 Workers 的无服务器平台之上。Kitesurf 在 Browser Run 的测试阶段免费提供，该功能允许开发者以编程方式控制和交互 Cloudflare 网络上的无头浏览器实例。

对于开发者来说，Cloudflare 的推销点是，这使得 AI 智能体在使用比 Chromium 更少的计算能力的同时，更高效地使用网络，从而降低成本。

该公司表示：“在执行截图和 HTML 提取等常见智能体任务时，Kitesurf 在 CPU 和内存消耗方面比 Chromium 效率显著提高。”


图片来源：Cloudflare

该浏览器本身由其他技术构建而成，包括来自 Blitz 的模块化渲染引擎；Firefox 的 CSS 解析器 Stylo；以及 Boa JS，一个 Rust ECMAScript 引擎。其他一切都运行在 Cloudflare Workers 内部。尽管仍处于起步阶段，Cloudflare 表示 Kitesurf 已经通过了约 215,000 多项网络平台测试，并且每周都在增加数百项测试并通过它们。

Cloudflare 还感谢了开源 Rust 无头引擎 Obscura，称其启发了 Kitesurf 的开发，并指出最初的概念验证就是将 Obscura 移植到 Workers 上。

该公司表示，该浏览器能够正确渲染如 TodoMVC（一个用于比较 JavaScript 框架的流行基准应用程序）等页面，以及维基百科、Hacker News、Cloudflare 博客和大部分 Cloudflare 仪表板。
