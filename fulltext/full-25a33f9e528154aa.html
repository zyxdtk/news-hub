苹果起诉OpenAI窃取商业机密的最惊人指控

📅 2026-07-13 📄 TechCrunch Funding 🔗 原文链接

原标题：The wildest allegations in Apple’s trade secrets lawsuit against OpenAI

中文摘要： 苹果在针对OpenAI的商业机密诉讼中提出多项惊人指控，称OpenAI领导层纵容并系统性指导员工窃取苹果机密。指控包括前员工利用漏洞访问苹果系统、要求面试者携带苹果零部件、指导离职员工逃避安全审查，以及被收购的io公司滥用苹果专有技术等。苹果称已有超400名前员工加入OpenAI，此事仅是冰山一角。OpenAI回应称对他人机密不感兴趣。

太平洋夏令时间 上午 11:22 · 2026年7月13日

苹果针对 OpenAI 的商业机密诉讼包含多项非同寻常的指控，描绘了一幅从苹果现任和前任员工处获取机密信息的协同行动画面。但或许最引人注目的是，这些被指控的不当行为描述得有多么随意，其中包括一条写道：“哈哈，我发现我可以访问[网络存储]，太好玩了。”的消息。

这份于周五提交的长达 41 页的诉状充满了异常详细的指控，包括上述内容和其他一些指控。以下是我们认为最引人注目的几点：

  • “由领导层常态化并示范。”通过对 OpenAI 的这一描述，苹果明确表示，其诉讼不仅针对个别违规员工，而且此类不当行为是 OpenAI 企业文化的一部分，并由高层领导。
  • “烂到核心。”苹果在批评 OpenAI 在本案中的行为时，巧妙地使用了一个腐烂水果的比喻。有传言称，这家 AI 模型制造商正在研发一款硬件设备以挑战 iPhone，可能是其自主研发的智能手机。但苹果想强调的是，OpenAI 正在开发的东西据称是利用苹果的商业机密构建的。“OpenAI 新兴的硬件业务现在建立在最不稳固的基础之上，由于非法依赖盗用的商业机密而烂到了核心，”诉状称。
  • “这只是冰山一角。”除了记录针对其前员工的指控外，苹果还暗示，诉状中概述的不当行为只是它在证据开示程序开始后将要揭露的一小部分。在证据开示中，将获取公司文件和通信（包括短信和电子邮件），可能会揭露 OpenAI 此类行为的其他例子。“证据开示将揭露，这种盗用行为的规模比下文描述的几个实例要大许多倍，”苹果的诉状称。
  • “哈哈，我发现我可以访问[网络存储]，太好玩了。”苹果表示，Chang Liu 在加入 OpenAI 之前是苹果的高级系统电气工程师，他将这条消息发送给了苹果员工 Yu-Ting “Alyssa” Peng，据称后者是苹果和 OpenAI 之间的渠道。Peng 后来离开苹果加入了 OpenAI，但不是本案的被告。据称 Peng 回复该消息说：“我准备好了。”苹果声称，Liu 利用一个身份验证漏洞访问了苹果的系统，他是通过 Peng 的苹果配发的工作电脑做到这一点的。
  • “我还有另一台电脑。”据称，Liu 在离开苹果后的几小时内也发了这条短信，指的是他计划用来访问苹果机密信息的另一台苹果电脑。苹果在 Peng 的苹果配发的工作笔记本电脑上发现了这条消息。
  • “甚至不知道我们可以把这些带出办公室。”其中一项更离谱的指控是，在苹果工作且正在应聘 OpenAI 的求职者被 OpenAI 首席硬件官 Tang Yew Tan 指示，要求他们从苹果带“实际部件”去参加 OpenAI 的面试，用于“展示和讲述环节”。Tang Yew Tan 在苹果工作了 24 年，最近的职务是 iPhone 和 Apple Watch 的产品设计副总裁。苹果声称，一名候选人对这一要求感到惊讶，说他甚至没有意识到苹果的部件可以带出办公室。苹果还表示，员工被指示将“CAD/设计工件”和“原型”带到面试中。
  • 避免“可怕的护送离职”。苹果指控 OpenAI 指导即将离职的苹果员工如何逃避苹果的安全程序，以降低他们涉嫌窃取商业机密被抓获的机会。诉状称，OpenAI 向新员工传阅了一份标有“需要知道”的苹果内部文件，其中详细说明了如何避免“可怕的护送离职”——即在提出辞职后立即被要求离开苹果，而不是让他们继续工作通常的两周时间，这将使他们有更多时间访问苹果的机密信息。
  • 如果在辞职时被要求签署任何文件，要“尽快”通知 OpenAI。诉状指控称，除了帮助 OpenAI 的求职者逃避苹果的安全程序外，OpenAI 还建议离职员工，如果苹果在离职面谈时要求他们签署任何文件，他们应该立即通知 OpenAI，并建议他们不要签字。
  • “超过四百名前苹果员工现在在 OpenAI 工作。”另一个令人惊讶的是：诉状揭示了苹果员工离开这家 iPhone 制造商转而为 OpenAI 工作的程度。苹果利用这一数字描绘了该问题潜在规模的画面，指出“某些 OpenAI 人员了解苹果的机密和专有信息，他们有义务对此保密，这并不令人惊讶。但 OpenAI 却利用了这些机密信息……”
  • “io……访问、利用并使用了苹果与金属加工相关的秘密、专有工业设计技术、工艺和诀窍。”io 公司由包括 Jony Ive 在内的前苹果员工创立，去年被 OpenAI 以 65 亿美元的交易收购。现在 io 是本案的被告，因为苹果指控该公司通过误导苹果的合作伙伴，使其相信它获得了苹果的许可来执行“机密的金属加工技术”，从而使用了其工业设计技术，诉状称。苹果还指控 OpenAI 利用其关于电源和电池相关设计与组件的机密信息接触了一家供应商，甚至使用“内部术语”提出“只有苹果内部人士才知道问”的有针对性的问题。
  • “苹果别无选择。”虽然看似是典型的法律用语，但在这种情况下，苹果似乎曾试图先在法庭外解决这一问题。这家科技巨头表示，它曾在 2 月份首次尝试联系 OpenAI，提出了它的担忧，但 OpenAI 从未回应。

到目前为止，OpenAI 仅在周五通过在 X 上分享的一份声明进行了公开回应，声明写道：“我们对其他公司的商业机密不感兴趣。我们仍然专注于构建能够赋能全球各地人们的创新技术。”
