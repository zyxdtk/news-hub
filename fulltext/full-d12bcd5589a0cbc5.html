摘要

从有限观测中抽象出结构化建筑对于3D城市建模和数字孪生至关重要。同一建筑的部分点云和俯视图像分别提供不完整的3D表面测量，以及其轮廓、屋顶几何和屋顶结构的视觉线索。这激发了一个在3D空间中对齐几何与视觉线索、并能从单一或两种模态重建建筑的统一框架。基于这一联系，我们提出了Any2Building，一个从部分点云、俯视图像或两者进行细节层次2（LoD2）建筑重建的统一模型，支持可选的粗糙几何先验。其核心是一种以占用为锚定的共享空间查询表示，将可用观测组织在共同的3D网格中。在完整建筑表面体素的监督下，这些查询将观测证据与目标几何连接起来，使共享生成器能够跨任务学习结构先验，并为恢复缺失结构提供空间引导。随后，训练好的体素条件表面生成与低多边形重网格化流水线将预测结构转换为紧凑的LoD2建筑模型。为支持这一框架，我们引入了BuildingWorld-Image数据集，包含跨18个城市约100万个部分点云、俯视图像和LoD2建筑模型的配对样本。在多个基准上的实验表明，Any2Building在单模态和多模态点云补全、单图像建筑生成和先验辅助生成方面的几何重建精度均优于现有方法，同时在点云输入模态退化时仍保持细致且鲁棒的恢复能力。

1 引言

结构化3D建筑模型支持城市数字孪生[2]以及城市理解[43]和视觉定位[44]等应用。细节层次2（LoD2）建模[17]以紧凑、结构化的表示捕捉建筑的空间组织，保留其屋顶部分和精细屋顶结构的几何与空间关系。建筑重建通常依赖有限的观测，包括部分点云[13, 16, 22, 15]和俯视图像[30, 18]。点云提供部分几何测量，而俯视图像揭示外观和布局，但使高度和隐藏表面保持模糊。尽管这些异构观测可以来自同一建筑，但基于点云的建筑重建和基于图像的建筑生成在很大程度上仍被视为相互独立的任务。这种共同来源激发了一个统一重建框架，可以独立地从任一模态或其组合恢复LoD2建筑。

最近的建筑重建方法通过借鉴强大的3D生成流水线[25, 31, 32, 1]取得了进展，但其设计仍针对个别观测设置定制，难以直接扩展到互补模态。BuildAnyPoint[13]从部分点云重建结构化建筑，但其体素对齐的条件机制无法轻易将图像证据作为空间锚定的3D条件纳入。在先验辅助的基于图像的建筑生成[18]中，将基于噪声的先验注入扩展到部分点云可能会模糊精细的结构线索。与此同时，通用3D生成器通过在共享框架内统一异构条件的努力提供了有益启发[6, 42, 28, 11]。Axolotl3D[11]和Hunyuan3D-Omni[28]拼接视觉和几何标记进行基于注意力的条件化，但依赖生成器在推断缺失几何的同时解决跨模态结构关系——这是不完整观测下一个具有挑战性的联合推断问题。这种直接耦合在建筑重建中尤其困难，因为低分辨率正射影像提供的高度和立面线索有限，但揭示了LoD2重建所必需的屋顶布局和轮廓边界。然而，直接特征融合无法轻易将这些视觉线索与部分点云中的细粒度几何证据对齐，如图1(b)中直接融合示例所示。

剩下的挑战是在异构观测与完整建筑结构之间建立一致的几何对应关系，实现模态对齐与融合以及任务统一，从而促进跨重建任务的正迁移。

为应对这一挑战，我们引入了Any2Building，一个统一的LoD2建筑重建模型，支持点云输入和遥感图像输入，以及高度或边界框先验。我们的主要技术创新是一组在低分辨率3D体素网格上初始化的共享查询。可用输入被编码为条件标记，共享空间查询在共同的3D位置聚合其特征。完整建筑表面体素的监督鼓励查询在条件化生成器之前捕捉整体建筑结构，包括未观测区域。通过将不同观测与相同的基础几何关联，查询进一步引导生成器，实现跨点云补全和基于图像生成的共享结构学习，并支持可选的粗糙几何先验。生成的结构潜在表示被解码为体素网格。我们发现，仅凭这些体素就足以通过训练好的表面生成器进行连续网格重建，无需额外的点或图像条件。低多边形重网格化和纹理化随后产生紧凑的LoD2建筑资产。

为支持跨观测设置的学习，我们引入了BuildingWorld-Image，即BuildingWorld[17]的图像扩展。它包含跨18个城市约100万个对齐的部分点云、俯视图像和LoD2建筑模型三元组。这些观测共享相同的几何目标，实现跨输入模态的结构学习和评估。在多个公共数据集和BuildingWorld-Image数据集上的大量实验表明，我们的方法不仅在单个任务上取得了优越性能，而且在点云模态观测有限时受益于互补模态。

我们的贡献总结如下：

  • 我们提出了Any2Building，一个从部分点云、俯视图像或两者进行LoD2建筑重建的统一模型，支持可选的粗糙几何先验。该模型结合互补观测并促进跨重建任务的正迁移。
  • 我们设计了基于共享3D查询的空间条件化模块。在完整建筑体素的监督下，这些查询将异构观测与建筑几何对齐，并为生成器提供空间引导。
  • 我们引入了BuildingWorld-Image数据集，包含跨18个城市约100万个对齐的部分点云、真实俯视图像和LoD2建筑模型三元组，支持跨观测设置的训练和评估。

2 相关工作

用于建筑重建的点云补全。 通用点云补全方法通过全局特征编码[40, 37]、分层解码[27, 33]、体素化表示[34]和几何感知变换器[38, 39, 3]恢复缺失几何[9]。多模态方法，包括EGIInet[36]、DuInNet[21]和MAENet[20]，进一步纳入配对图像[10]。这些方法输出点集，需要后续处理进行结构化网格重建。为恢复连贯的建筑结构，PolyFit[23]和City3D[15]通过约束面选择将平面基元组装成紧凑网格。ArcPro[16]预测编码建筑层及其层次结构的建筑程序，而Point2Building[22]从点云自回归地生成网格顶点和面。对于现有网格，RoLoPM[4]结合偏移表面提取、简化和几何流，在保持视觉保真度的同时产生低多边形模型。BuildAnyPoint[13]将点条件扩散与自回归网格生成相结合，而UniCo[5]使用可学习的基元代理非自回归地联合预测点几何和可装配基元。两者都通过体素化点条件和共享点云特征依赖观测到的3D几何，因此纳入图像需要额外的机制来空间锚定2D外观。

基于图像的建筑生成。 最近的图像到3D模型，包括TRELLIS、TRELLIS.2和SAM 3D[31, 32, 1]，为从视觉观测恢复几何提供了强大的生成先验。在建筑层面，BuilDiff[30]通过单图像条件扩散生成点云，而SatSkylines[18]通过将粗糙先验潜在表示与高斯噪声插值引入几何控制。然而，将这种噪声空间注入扩展到部分点云可能会模糊精细几何线索，而将几何引导与噪声强度耦合会限制对局部结构的独立控制。相关的城市生成方法通过组合建模[35, 19]和卫星条件生成[12, 14, 24, 29]合成更大的场景。然而，俯视外观使高度和隐藏表面保持模糊，而粗糙先验不指定详细的建筑几何。

几何条件化的3D生成。 几何条件化能够对生成的形状进行更明确的控制。SDFusion[6]支持从部分几何和图像生成，而CLAY[42]适应多种控制，包括点云、体素和边界框。SpaceControl[7]在测试时引入空间约束，无需额外训练。Hunyuan3D-Omni[28]和Axolotl3D[11]拼接视觉和几何标记进行基于注意力的条件化，让生成器推断这些异构线索如何联合约束缺失几何。这需要一种共享表示，能够空间地组织互补观测，并将其与跨输入设置的完整建筑结构关联起来。

3 方法

Any2Building从部分点云P、俯视图像I或两者生成LoD2建筑，支持可选的粗糙几何先验R。其核心组件是一组在低分辨率3D网格上聚合观测的共享空间查询。在完整建筑占用的监督下，这些查询在条件化生成器之前形成整体结构的中间表示。如图2所示，查询特征通过查询增强（QE）标记和空间提示引导流匹配DiT。生成的结构被解码为64³表面体素网格，并转换为紧凑的LoD2网格。所有几何输入、空间查询和输出体素网格共享与地理配准俯视影像链接的归一化建筑坐标系。这使得生成的建筑能够与源影像对齐并映射回其真实世界位置，即使在仅图像设置中也是如此。

3.1 多模态输入分词器

我们首先编码可用观测，以便由共享空间查询聚合。点云和图像产生宽度为C=1024的模态特定标记，而可选几何先验为查询初始化提供描述符。点编码器使用四个EdgeConv阶段，在坐标空间中采用16最近邻图。最远点采样依次选择2,048个和1,024个中心，必要时重复采样。所得的中心坐标P_c和局部特征H_c满足：

(P_c, H_c) = E_EdgeConv(P), T_P = φ_feat(H_c) + φ_pos^P(P_c), (1)

其中两个MLP分别编码局部几何和空间位置，得到T_P ∈ ℝ^(1024×1024)。冻结的DINOv3编码器[26]提取图像块标记T_I ∈ ℝ^(N_I×C)。标记序列保持其模态特定的组织方式；共享空间查询将它们与3D位置关联。

LoD0先验是3D建筑边界框；LoD1先验是挤出到相应高度的建筑轮廓。每个先验被体素化为二进制64³表面占用网格V_R，内部留空。对于对应于16³查询网格单元的每个4³体素块B_j，我们计算：

s_j = max_{v∈B_j} V_R(v), b_j = max_{v∈B_j} B_R(v), ρ_j = (1/64)Σ_{v∈B_j} V_R(v), (2)

其中B_R标记至少有一个空的六连通邻居的占用体素；网格外的位置视为空。MLP φ_R编码描述符r_j=(s_j, b_j, ρ_j)，表示表面占用存在、边界存在和占用比例。对于薄表面壳，s_j和b_j可能重合。

3.2 共享空间查询条件器

我们将可用观测聚合到粗糙3D体素网格上的中间表示中，由完整建筑表面占用监督。该网格需要同时表示观测区域和缺失区域，在生成器之前提供结构引导。

我们在固定的网格单元中心{p_j}_{j=1}^N初始化N=16³个查询。平均池化、归一化的模态特征和可用性标志a=(a_P, a_I)形成全局描述符g，缺失模态贡献零特征。初始粗糙查询为：

q_j⁰ = φ_init([φ_pos^Q(p_j), g]), (3)

其中[·,·]表示拼接。当先验可用时，其描述符按如下方式更新查询：

q̃_j⁰ = q_j⁰ + α[s_j·LN(φ_pos^Q(p_j)) + φ_R(r_j)], (4)

其中α缩放更新幅度。无先验时，Q̃⁰=Q⁰。所有查询位置均被保留，允许在占用的先验体素之外进行生成。训练期间的先验丢弃减少了对这一额外输入的依赖。

查询通过交叉注意力聚合可用模态：

A_m = Attn_m(LN(Q̃⁰), T_m, T_m), m∈{P, I}, (5)
Q^r = Q̃⁰ + φ_f([A_P, A_I, a]).

缺失模态产生零读数，a在查询间广播。残差自注意力和前馈块，随后是归一化，产生空间查询特征Q。辅助头预测表面占用，损失为：

L_occ = (1/N)Σ_{j=1}^N BCE(σ(w_occ^⊤ q_j + b_occ), y_j). (6)

目标y_j通过将完整建筑的解码64³参考网格最大池化到16³获得。它们表示表面占用而非填充内部，并在各输入设置间共享。此辅助损失仅监督Q而非最终体素。

查询特征Q以两种方式引导生成。首先，它们通过交叉注意力丰富基础条件标记H。对于单一观测模态，H=T_P或H=T_I。对于点-图像输入，交叉注意力用图像标记和辅助补全特征更新点标记，保持点标记的数量和宽度。补全特征来自与16³空间查询不同的512个可学习查询。增强后的条件为：

H_QE = H + Attn_back(LN(H), Q, Q). (7)

其次，Q提供保留其3D网格索引的空间提示。

3.3 具有空间提示的DiT

流匹配DiT生成16³结构潜在表示，通过每个块中的交叉注意力以H_QE为条件。选定的块额外接收对齐的空间提示：

h_ℓ ← h_ℓ + β·P_ℓ(LN(Q)), ℓ∈S, (8)

其中P_ℓ是零初始化的、层特定的线性投影，β缩放残差。共享网格索引将每个查询与其对应的潜在位置对齐（图3）。图3(b)可视化了注入两个DiT块（标记为分支A和分支B）的空间提示残差。层特定的投影提供强调建筑不同部分的空间引导。

给定完整建筑潜在表示x₀、高斯噪声ε和时间t∈[0,1]，流路径和目标速度为：

x_t = (1−t)x₀ + [σ_min + (1−σ_min)t]ε, (9)
u_t = (1−σ_min)ε − x₀.

这里x₀表示干净的目标潜在表示，σ_min指定t=0时的残余噪声水平。训练目标为：

L = E[‖v_θ(x_t, t; H_QE, Q) − u_t‖₂²] + λ_occ·L_occ + λ_geo·L_geo. (10)

对于体素级几何监督，使用公式9的系数从x_t和预测速度估计干净潜在表示。估计的潜在表示被解码为体素网格，L_geo在其上应用BCE和Dice监督。训练采样四种输入模式：、(I)、(P,I)和(I,R)，它们共享条件器、生成器和完整建筑目标表示。QE标记和空间提示在训练期间联合丢弃以用于无分类器引导，这是DiT的常见训练设置。

在推断时，我们从t=1的高斯噪声积分流至t=0，并将采样端点记为x̂₀。结构解码器将此潜在表示映射到64³体素网格。

3.4 LoD2构建

获得64³体素网格V̂后，我们在其占用的体素坐标Ω处生成局部表面潜在表示。我们发现预测的体素几何足以进行表面生成，无需额外的图像或输入点云特征。因此，我们从表面阶段结构化潜在生成器[32]中移除图像条件化，并使用以下损失在建筑数据上训练它：

L_surf = E_{z₀,ε_z,t}[‖v_ψ(z_t, t; Ω) − u_t^surf‖₂²], (11)

其中z₀表示参考表面潜在表示，z_t表示它们与高斯噪声ε_z的插值，u_t^surf = ∂z_t/∂t为目标流速度。训练使用参考体素坐标，而推断使用预测坐标Ω。预训练的形状解码器将生成的表面潜在表示转换为网格，RoLoPM[4]产生保留主要屋顶和立面几何的紧凑多边形模型。这一表面构建流水线由所有输入模式共享。

对于纹理化，我们使用ControlNet[41]合成合理的立面参考图像，以无纹理网格渲染和从俯视图像及城市名称推断的外观描述为条件，然后使用预训练的纹理生成器[32]用这些参考为低多边形网格添加纹理。生成的LoD2建筑可以通过逆转归一化并应用相关的地理配准变换映射回其真实世界场景。

5 结论

我们提出了Any2Building，一个从部分点云、俯视图像或两者进行LoD2建筑重建的统一模型。该模型还支持带粗糙几何先验的基于图像的重建。在完整建筑表面占用的监督下，我们的共享空间查询在共同的3D网格上聚合输入特征，并在各输入设置间条件化相同的结构生成器。我们仅从预测的体素生成表面，并将其重网格化为紧凑的LoD2模型。我们还引入了BuildingWorld-Image，包含跨18个城市约100万个对齐的部分点云、俯视图像和LoD2建筑网格三元组。实验表明，在单模态和多模态点云补全、单图像生成和先验辅助生成方面的重建精度均有提升。消融研究表明，联合训练改善了从任一模态单独进行的重建，而添加图像改善了从稀疏或空间不完整点云的补全。

A.2 地理锚定的关联

恢复共同的空间参考。 源网格使用不同的坐标系、单位、局部原点和轴约定。我们保留源元数据，并在提取实例观测之前恢复从局部几何到地理图像框架的变换。坐标投影、轴顺序、局部偏移和单位在这一变换链中解析。图像仿射映射在裁剪、填充和调整大小后更新，以便像素间距继续表示正确的物理范围。网格和部分点被放置在相同的直立建筑坐标框架中进行训练。源到地理的变换保持与关联附加，而不是从归一化几何推断。

检索俯视证据。 建筑的地理范围在正射影像或遥感镶嵌图中定义了一个上下文窗口。我们保留图像到世界的变换和可用的源元数据。市政正射影像和混合航空/卫星底图均被使用；因此，我们将该集合描述为俯视遥感影像，而不是假设统一的卫星传感器。上下文保留了邻近结构，而实例掩码将注意力集中在目标上。

实例掩码和配对条件。 我们将源建筑几何投影到地理窗口中以初始化实例掩码。RGB上下文、掩码和裁剪作为同一目标的相关观测存储。部分点云根据其源池使用可用的测量或源衍生的模拟。粗糙几何条件包括边界体和轮廓衍生的棱柱。使用目标衍生高度的先验与完全从外部观测衍生的先验区分开来；它在仅图像重建中不被视为免费信息。投影的实例掩码在单图像设置中不作为额外条件提供。

对于定量评估，每个目标建筑使用通过将其参考几何投影到地理配准图像中获得的2D边界框进行定位。所有比较方法使用相同的边界框裁剪。在单图像设置中，裁剪内的背景像素被保留。投影的实例掩码及其边界框是不同的注释：存储掩码并不意味着在每个输入设置中都应用背景移除。因此，我们的基于图像的评估假设从真实值衍生的实例定位，并测量给定实例裁剪的重建，而不是端到端的建筑检测和重建。虽然这对于单建筑生成已经足够，但我们目前也在探索使用智能体自动化整个城市规模生成流水线。

几何准备。 我们移除无效或空的几何资产，标准化方向，并将有效表面编码为稀疏结构和形状表示。基准面处理遵循源的约定和开放底部训练目标；它不是通用的水密性修复。几何与其关联的点观测一致地归一化。

A.3 质量筛选和细化

原生图像信息。 质量筛选检查原生分辨率、前景覆盖、曝光、纹理和方向。分辨率层级使用重采样前的源图像；放大裁剪不会增加证据或改善其层级。上下文和裁剪变体共享相同的图像窗口、填充和显示尺度，仅实例掩码不同。

坐标、单位和尺度校准。 系统性尺度不一致首先在坐标转换中诊断，而不是被逐建筑的图像拟合吸收。错误的地图投影、米和英尺之间的混淆，或裁剪调整大小后过时的像素到世界尺度，可能影响来自同一源的每个目标。我们的波士顿修复恢复了局部偏移和源测量英尺约定。检查的剑桥导出额外需要源特定的尺度因子；它不是对剑桥数据的通用校正。这些校正属于共享的源到世界变换，并在局部对齐之前对照地理上下文进行检查。

不同的边界和高度视差。 可见的屋顶边界、屋檐轮廓和地面轮廓不必重合。将源网格投影到图像中也可能与可见边缘不一致，因为倾斜采集使高表面相对于地面位移，不同的屋顶级别位移不同。遮挡和采集日期的差异引入了进一步的不一致。单一各向同性尺度通常无法解决这些影响。因此，我们将坐标校准与对应细化区分开来，保留每个轮廓的含义，并标记模糊的屋顶-轮廓匹配，而不是将每个残差视为尺度误差。

保持形状的边界细化。 地理校准后，局部细化处理投影和可见边界兼容处的残余轮廓位移。我们的细化提议在配准轮廓周围搜索有界平移和各向同性尺度。对于轮廓点p及其中心c，候选变换为T(p)=s(p−c)+c+t。目标结合了方向兼容的图像边缘距离与平移t和尺度s的惩罚，保留源多边形而不是重新分类前景像素。变换保留多边形组件、顶点顺序和角点，避免无约束图像分割可能引入的屋顶结构侵蚀。我们仅当提议改善边缘目标并保持在图像内时保留它；否则保留配准的先验。连续的细化过程记录其累积尺度，因此相对于中间轮廓的边界不会与相对于源几何的边界混淆。图S2显示了示例。

细化保留矢量轮廓结构，并在提议的更新未通过接受标准时保留配准的先验。此细化没有独立的像素注释，因此示例不能确定掩码IoU的改进。涉及遮挡、多个屋顶级别、建筑群或不正确源轮廓的困难案例仍有待审查。

B.1 架构、训练和推断

点编码器使用四个EdgeConv阶段，具有16邻居聚合和最远点缩减到2,048和1,024个中心。它返回1,024个宽度为1,024的空间索引标记。冻结的DINOv3编码器处理512×512的图像。空间查询晶格包含16³个位置。查询特征被投影到隐藏宽度为1,536的30块扩散变换器中。空间提示进入块0、10、20和29（零基索引），而查询增强条件标记在整个变换器中提供交叉注意力。

共享训练配置以相等概率采样仅点、仅图像(I)、点-图像(P+I)和图像加先验(I+R)模式。点退化在重采样到编码器输入大小之前进行；重复的输入行不构成额外的观测。查询占用损失的权重为0.1。体素级几何监督使用冻结的稀疏结构解码器，BCE/Dice辅助损失权重为0.02。查询增强标记和空间提示以0.1的概率一起丢弃以用于无分类器引导。

在推断时，表面生成器在预测的占用体素坐标处操作，没有额外的图像或点云特征。因此，它以预测结构为条件，即使直接观测条件化被移除。

基线适配。 我们从发布的预训练检查点初始化学习的3D生成基线，并在对应于每个实验的训练分割上微调它们。每个独立训练的生成阶段接收200,000次优化器更新，使用附录A.5中描述的任务特定输入预处理。对于Hunyuan3D-Omni，我们将形状扩散模型和统一控制编码器作为单个形状生成阶段联合微调。更新预算指的是优化器步骤而不是推断采样步骤。

基线可用性。 BuilDiff和Axolotl3D作为相关工作被讨论，但被排除在定量比较之外，因为截至2026年11月15日我们无法获得可运行的官方实现。BuilDiff的官方存储库仅包含README和许可证，而Axolotl3D项目页面没有提供公共实现或检查点下载。

B.2 几何指标和输出表示

Building-PCC比较和编码器消融遵循BuildAnyPoint[13]的指标定义和报告尺度。其补充材料将CD定义为两个方向平均最近邻L1（曼哈顿）距离之和，每个点云使用16,384个点。下面详述的几何距离定义和缩放适用于BuildingWorld-Image。

在补全比较中，PC表示表面生成和低多边形重建之前的补全点集，而LP表示最终的低多边形网格。基于网格的几何指标从表面采样点计算。参考网格通过表面面积均匀采样16,384个点。共同的评估框架对每种方法使用参考质心和最大半径。对于预测点X和参考点Y，定义d(x,Y)=min_{y∈Y}‖x−y‖₂。我们计算：

CD_L1 = (1/2)[(1/|X|)Σ_{x∈X}d(x,Y) + (1/|Y|)Σ_{y∈Y}d(y,X)], (12)

CD_L2 = (1/|X|)Σ_{x∈X}d(x,Y)² + (1/|Y|)Σ_{y∈Y}d(y,X)². (13)

精度P_τ是预测点在参考τ范围内的比例，召回率R_τ在相反方向定义。表面F分数为：

F_τ = 2P_τR_τ/(P_τ+R_τ), τ∈{0.01, 0.02}, (14)

当P_τ+R_τ=0时F_τ=0。除非另有说明，报告的表面F分数使用τ=0.02。

EMD在1,024个采样点上使用精确双射匹配，并对两个采样种子取平均。此评估中的CD和EMD乘以10³。对于点输出，CD和F分数使用原生预测点数。均匀性和DCD使用16,384个点，仅在必要时进行替换。均匀性是100个查询点处半径0.05内邻居计数的归一化方差，对三个种子取平均。DCD使用α=1000和计数指数1。

附录C.2中的体素F1测量预测和参考表面支持体素之间的重叠。这些体素表示建筑表面，而不是填充的内部。体素F1和表面F分数测量不同的量，在数值上不可互换。

低多边形复杂度。 对于表1中的Building-PCC低多边形结果，我们比较预测和参考的顶点和面数。对于建筑i和计数类型c∈{V,F}，令n^pred_{c,i}和n^ref_{c,i}表示相应的计数，并定义ρ_{c,i}=n^pred_{c,i}/n^ref_{c,i}。在N座评估建筑上，我们报告：

r_c = (1/N)Σ_{i=1}^N ρ_{c,i}, (15)
e_c = (1/N)Σ_{i=1}^N |ρ_{c,i}−1|, c∈{V,F}.

每个表项报告r_c，括号中为e_c。误差在单个建筑上取平均，而不是从聚合比率计算，防止跨建筑的高估和低估相互抵消。

B.3 消融协议

评估范围。 表4中的所有三项研究都使用完整的2,000座建筑BuildingWorld-Image测试集。几何指标在每项研究指定的重建程序产生的最终低多边形网格上评估，使用附录B.2中的共享评估框架和指标定义。F分数使用归一化距离阈值0.02，CD_L1以10³的尺度因子报告。组件变体在面板的每个输入设置内进行比较；图像的配对贡献在面板中单独评估。在表面生成研究中，仅结构和表面阶段变体都在评估前使用指定的后端转换为低多边形网格。

空间查询变体。 条件拼接基线用可用输入标记的直接拼接替换空间查询条件化设计。根据输入设置包括点和图像标记，在I+R设置中还拼接编码的先验标记。结果序列直接条件化DiT，没有查询回读或空间提示注入。因此，该基线将完整的空间查询条件化设计与直接标记条件化进行比较，同时保留对可用输入模态和先验的访问。

其余变体一次移除一个组件。无占用监督变体省略辅助查询占用损失，同时保留查询表示和其余生成目标。无查询回读变体直接使用基础条件标记H，即H_QE=H，同时保留查询占用监督和空间提示。无空间提示变体移除对DiT的对齐残差注入，同时保留查询增强条件标记和占用监督。每个变体使用相同的训练协议重新训练；组件不是简单地在训练好的完整模型中在推断时禁用。

联合和单任务训练。 我们为P、I、P+I和I+R各训练一个专家模型，使用相应的架构和推断输入。每个专家模型和联合模型接收相同数量的优化器更新。联合模型以相等概率采样四种输入模式，而每个专家模型仅使用其指定的模式。因此，比较匹配每个模型的总更新计数，而不是每种模式的训练暴露次数。在评估时，联合模型和相应的专家模型接收相同类型的输入；联合训练不会在仅P或仅I比较中引入额外的推断模态。

配对点退化。 图像贡献研究对P和P+I推断使用相同的训练检查点。"无"设置使用原始的2,048点部分观测，没有额外退化；它不表示完整的建筑点云。随机退化从该观测中保留205或41个点。空间退化改编了AdaPoinTr[39]使用的ShapeNet-55裁剪方案。首先移除随机选择的空间区域，然后将剩余观测子采样到41个点。因此，空间移除先于子采样，41点输入不是通过直接裁剪掉除41个点之外的所有点获得的。将此设置与相同计数的随机子采样进行比较，检查同等稀疏观测下空间覆盖的作用。

对于每次比较，P和P+I使用相同的保留点、归一化和生成噪声；P+I额外接收配对的俯视图像。退化在重采样到编码器输入大小之前应用，因此重复样本不会添加几何观测。报告的点数指的是保留的观测，而不是重采样编码器输入的长度。
