摘要
最近的扩散模型能够生成高质量的视频，但运行速度较慢。
这些模型中使用的大型基于Transformer的骨干网络在时空注意力计算上成为瓶颈。
在本文中，我们发现，在各种输入下，大量token-to-token连接始终产生可忽略的得分，且其模式在不同查询中经常重复。
因此，在这些情况下，可以跳过注意力计算，而对结果几乎没有影响。
这一观察同样适用于局部token块之间的连接。
受此启发，我们提出了CalibAtt，一种无需训练的方法，通过校准稀疏注意力来加速视频生成。CalibAtt执行一次离线校准过程，识别出在不同输入下保持稳定的块级稀疏性和重复模式，并将这些模式编译为每一层、每个注意力头和每个扩散时间步的优化注意力操作。
在推理阶段，我们密集计算选定的输入相关连接，并以硬件高效的方式跳过未选中的连接。
我们在Wan 2.1 14B、Mochi 1以及多种步数蒸馏模型上进行了大量实验，验证了该方法的有效性。

1 引言
Transformer [vaswani2017attention] 已成为一种基础架构，彻底改变了自然语言处理 [brown2020language, grattafiori2024llama]、计算机视觉 [dosovitskiy2021an, oquab2024dinov2] 以及图像和视频扩散模型 [ho2020denoisingdiffusionprobabilisticmodels, peebles2023scalable, esser2024scaling, wan2025] 等多个领域。
然而，其最先进的性能伴随着显著的推理计算开销。
Transformer 架构中的自注意力机制（self-attention mechanism）在序列长度上具有二次复杂度，这使得处理较长序列时尤为具有挑战性。

在许多应用中发挥着重要作用。
在本研究中，我们提出了一种无需训练的自注意力优化方法，重点针对视频生成应用，原因如下：
(i) 它们是内容生成的强大且日益重要的工具；
(ii) 它们本质上需要长序列以支持更高分辨率和更多帧数；
(iii) 视频数据通常包含高水平的时空冗余，使其成为计算节省的理想候选对象。

为了缓解注意力机制的计算需求，已提出多种创新方法 [zhang2026survey]。
其中最显著的是 FlashAttention [dao2022flashattention, dao2023flashattention2fasterattentionbetter, shah2024flashattention3]，它显著降低了注意力操作的内存占用和运行时间。然而，它并未减少乘法操作的数量。
许多论文 [zhang2026survey] 探索了降低注意力计算量的方法，通常遵循与 FlashAttention 兼容的约束条件，从而获得更好的运行时性能提升。
尽管这些方法取得了进展，但它们通常需要微调，或通过在某些层或扩散时间步中禁用其方法来提供有限的加速效果。

在本研究中，我们提出 CalibAtt，一种新颖的无需训练的加速方法，用于视频扩散变换器中的注意力机制。该方法可自动适配任意模型，与 FlashAttention3 [shah2024flashattention3] 协同工作，并提供当前最先进的运行时节省效果。

我们首先检查视频模型中的注意力图，并在 token 级别和 block 级别上观察其典型行为。我们发现稀疏且重复的注意力模式，其中许多模式在各种文本提示和潜在初始噪声输入下都能很好地复现。然而，这些模式在不同的 Transformer 层、注意力头，以及在某些情况下在扩散时间步中存在显著差异。基于这些观察，我们设计了一种算法，能够自动识别在 FlashAttention block 级别上与数据无关的模式，并为模型中每一层、每个注意力头以及每个时间步的组合校准注意力掩码或标记重复查询。

我们在多个主流开源视频扩散模型上进行了大量实验：Wan 2.1 [wan2025]、Mochi 1 [genmo2024mochi] 和 LightX2V [lightx2v]（一种多步蒸馏模型）。我们在不同的输出分辨率和扩散步数下应用我们的方法。在所有场景中，CalibAtt 始终保持与较慢的密集注意力基线相当的生成质量，同时在无训练加速方法中实现了最先进的注意力稀疏度和端到端运行时性能。此外，由于校准过程对启发式方法的依赖极小，CalibAtt 的性能在不同模型上表现稳定，对超参数调优几乎不敏感，且无需任意排除特定层或时间步。最后，我们进行了超参数消融实验。

影响 CalibAtt 的推理运行时、内存占用以及校准步骤的一次性成本。值得注意的是，结果表明，即使在校准预算较低的情况下，CalibAtt 也能生成令人印象深刻的稀疏掩码。

注意力输出
𝐀 ∈ ℝ^{N_q × d} 通过以下公式计算：
𝐏 = softmax(𝐐𝐊^⊤ / √d),
𝐀 = 𝐏𝐕.
(2)
通常使用多头注意力机制，即对 h 个头重复该操作，每个头拥有各自独立的键、查询和值。

随着序列长度的增长，显式构建密集注意力矩阵
𝐏 ∈ ℝ^{N_q × N_kv} 会因内存限制而变得不可行；当 N_q, N_kv ≫ d 时，处理该矩阵的计算成本也会主导推理运行时间。
FlashAttention [dao2022flashattention]（FA）通过将计算划分为块（tiling）来解决这一问题，确保在任意时刻只有注意力矩阵的一小部分驻留在高速内存中。该方法避免了二次方的内存消耗，同时通过更优的硬件利用率实现了显著的运行时性能提升。

(4)

虽然 FlashAttention 提高了注意力计算的运行效率，但乘法操作的总次数保持不变。
为了降低计算成本，许多近期方法提出将注意力限制在特定结构或模式中，这些模式反映了对 token 间相关性的假设 [Beltagy2020Longformer, liu2021swin, hassani2023neighborhood, huang2019ccnet, wang2020axial, yang2021focal, zhu2021deformable]。
由于这些注意力模式具有较强的限制性，它们通常在架构设计阶段选定，并且很少能直接应用于使用密集（标准）注意力训练的模型，除非进行微调。

另一条互补的研究路线利用典型注意力图的内在稀疏性，从而在不改变架构的前提下实现加速。

这些方法观察到，当令牌不匹配时，对应的 𝐏 元素几乎为零，因此可以在公式 2 中完全跳过其计算，从而消除冗余操作。
然而，预先确定哪些元素或块可以安全跳过并非易事，为此已提出多种方法来应对这一挑战。有关详细综述，请参见 [zhang2026survey]。

几种方法 [zhang2025sla, wu2025vmoba, liu2025fpsattention, zhang2025vsa] 通过微调模型以适应其注意力层来实现稀疏性。
尽管这些方法可以通过显式优化模型来达到较高的稀疏度，但它们需要大量的计算资源和高质量的训练数据，而这些资源可能并不可用。
另一种方法是无训练稀疏性方法，即在无需额外训练的情况下，将稀疏注意力机制应用于预训练模型。
一些研究 [zhang2025fast, liradial] 基于位置和结构先验预计算注意力掩码，并在推理时以极小的运行时开销将其应用于 𝐏。
例如，Radial Attention [liradial] 使用静态稀疏注意力掩码，其中每个令牌仅关注空间上邻近的令牌，且窗口大小随时间距离呈指数级缩小。
相比之下，具有在线决策能力的方法 [xi2025sparse, zhang2025spargeattn, shmilovich2025liteattention, xu2025xattentionblocksparseattention, xia2025trainingfree]

adaptivesparseattention, ohayon2025blocksparseflashattention] 通过分析注意力特征，在推理过程中识别稀疏模式，从而实现输入自适应稀疏，但需付出推理时开销的代价。例如，SpargeAttention [zhang2025spargeattn] 通过在压缩后的查询和键上计算注意力，实时估计块的重要性，跳过低于阈值的块，并引入跳过列表来指定需要计算的块区间。LiteAttention [shmilovich2025liteattention] 在 SpargeAttention 的基础上，将其适配为基于 FlashAttention3 的内核，并在不同时间步之间重用跳过列表。Sparse VideoGen 2 [yang2025sparse] 对 token 进行聚类，在聚类中心之间计算注意力，并仅在高分聚类交互内部计算 token 级别的注意力。

在我们的工作中，我们专注于使用预计算掩码来加速注意力计算，且不产生推理时开销。
我们不假设固定的衰减模式，而是通过模型相关的校准过程来计算掩码。
我们的校准算法能够适应每个模型、扩散时间步、层和注意力头的内在注意力模式，同时对具体的校准数据保持很大程度的无关性，从而实现比依赖预定义掩码的方法更高的稀疏度。

3 方法
3.1 初步检查与观察
我们首先分析文本到视频扩散模型在不同输入提示和种子下注意力层的典型行为。
具体而言，我们聚焦于使用 Wan 2.1 14B [wan2025] 生成 480p 视频的场景，并发现这些观察结果在其他设置中也具有普遍性。
我们得出四个关键观察。

观察 1：许多注意力图是稀疏的。
我们检查 N × N 的 softmax 后注意力矩阵 P。
在绝大多数情况下，我们注意到它仅关注少量 token 之间的交互（见图 2）。
其余 token 获得的注意力微乎其微，使其在输出值求和中的包含变得冗余。
此外，我们观察到，即使在考虑注意力矩阵 P 中的 B × B 块时，稀疏性依然非常明显，其中每个块表示在键上对 softmax 后注意力进行查询方向平均后的结果。
这一观察

高亮了注意力机制作为推理阶段计算节省的首选候选，尤其是因为块级稀疏性与硬件友好的高效注意力内核兼容 [dao2022flashattention, shah2024flashattention3]。
类似观察在先前工作中也已被提出 [xi2025sparse, liradial, zhang2025vsa]。

观察 2：注意力模式在不同注意力头、层和时间步之间并不重复。
如图 2 所示，同一层中不同注意力头、同一时间步中不同层，以及同一层和头在不同时间步之间的注意力模式均不一致。
在成功的模型训练过程中，不同的注意力层和头通常会学习关注不同的语义概念 [voita2019analyzing]。
因此，在提出基于稀疏性的加速技术时，我们认为更优的方法是为每一组层、头和时间步的组合设计特定的注意力掩码，而不是对所有组合使用固定的掩码 [liradial]。
尽管如此，我们注意到时间步是一个特殊情况。较晚的时间步（对应较低的噪声水平）在给定层和头下通常表现出高度相似的注意力模式，这一现象也在先前工作中被观察到 [shmilovich2025liteattention]。
我们在第 0.A.3 节中分析了这种行为。

观察 3：注意力模式在不同输入中保持稳定。
我们观察到，注意力图的稀疏性模式在各种输入提示词和初始扩散噪声向量下均保持稳定。
尽管不同提示词生成了不同的语义内容，但注意力连接在大多数情况下仍倾向于聚焦于相同的时空区域，如图 3(a) 所示。
这一观察促使我们进行一次性的离线校准，以生成与数据无关的稀疏注意力掩码，用于在线推理中，从而在无显著开销的情况下降低视频生成推理的计算成本。我们在第 3.2 节中探讨了这一点。

观察 4：注意力模式在空间行之间重复。
我们进一步观察到，某些注意力图在帧与帧之间的块内表现出重复结构。

基于能量的每提示块选择。
在固定的 (t,l,h) 下，我们考虑在公式 1 中定义的、大小为 N × N 的 softmax 后注意力图 𝐏（查询 × 键）。
受观察 1 的启发，我们采用能量视角：对于每个查询，注意力质量通常集中在一小部分键上，而其余部分对输出的贡献可忽略不计。
为了识别在硬件中可以高效跳过的 𝐏 的哪些部分，我们在块粒度上进行操作。
我们将 𝐏 划分为大小为 B × B 的连续块，为简化起见，假设查询和键/值具有相等的块大小，并在第 0.B.3 节中对不同配置进行消融实验。这在每个维度上产生 N_B = N/B 个块。
对于每个查询块行 r 和键块列 c，我们定义块能量为在 c 中键的注意力分数之和，对 r 中的查询取平均：
𝐄_{r,c} = (1/B) ∑{i∈ℐ_r} ∑{j∈𝒥_c} 𝐏_{ij},
(5)
其中 ℐ_r 和 𝒥_c 是公式 3 中定义的查询和键/值索引集。
直观上，𝐄_{r,c} 衡量了块行 r 中的查询分配给块列 c 中键的注意力质量，对 B 个查询取平均。这样平均确保每个块行能量 𝐄_r 的总和为 1。

对于每个查询块行 r，我们的目标是

为保留最少数量的关键块，使其累积能量达到预设阈值：
min_{𝒮_r ⊆ {1,…,N_B}} |𝒮_r| s.t. ∑{c∈𝒮_r} 𝐄{r,c} ≥ ε.
(6)
我们定义能量阈值为与时间步相关的 ε(t)。
这遵循先前观察到的现象：在去噪过程早期过早应用激进的稀疏化会导致输出质量明显下降 [liradial, yang2025sparse]。在实践中，我们使用在时间步 t ∈ {0,…,T−1} 上的指数调度，其中 t=0 表示噪声最大的步骤：
ε(t) = A + (C−A) exp(−kt/T),
(7)
其中 T 是扩散过程的总步数，A、C 和 k 是调度超参数。
在实践中，ε(t) 始终保持较高水平，在 Wan [wan2025] 中范围从 0.99 到 0.84。

5 局限性
尽管 CalibAtt 实现了令人印象深刻的稀疏性和加速效果，但我们的算法设计存在三个关键的内在局限性。
首先，由于 CalibAtt 是一种严格的离线方法，生成与数据无关的掩码，因此可能会错过某些特定提示或提示类型所带来的额外运行时收益。
其次，校准阶段需要投入初始计算预算。这一一次性成本可以视为摊销成本，因此相较于带有推理时开销的替代方法，它更具优势。
第三，由于必须将校准后的掩码存储在内存中，CalibAtt 在内存使用上存在限制。

在推理时增加了内存使用量。在 Wan2.1 14B 模型于 720p 分辨率下，掩码内存开销为 21.5 GB，而如我们在第 0.A.2 节中所示，可通过最小影响将其降低至 3.6 GB。

6 结论
我们提出了 CalibAtt，一种无需训练即可加速视频扩散变换器中注意力机制的方法。我们的方法基于以下观察：尽管注意力稀疏性和重复模式在不同层、注意力头和时间步之间有所变化，但在不同输入提示下它们基本保持一致。
通过一次性的离线校准，我们的算法能够自动识别出块级稀疏模式和空间上重复的注意力头，从而用于快速推理。此外，我们还贡献了一个基于 FlashAttention3 的内核，支持按时间步、层和注意力头动态变化的预计算块稀疏跳过列表。
值得注意的是，CalibAtt 在不同模型架构、输出分辨率和扩散配置下均表现出鲁棒性，且无需手动调整针对特定层或时间步的排除设置。
与我们的工作相关的几个未来方向仍待探索。
首先，无训练校准可以扩展到识别稀疏性和空间行重复之外的注意力冗余。例如，尽管我们的校准是按时间步独立进行的，但探索注意力之间的相关性仍有潜力。

在连续时间步的注意力图中，可能会揭示额外的稀疏模式，从而进一步减少计算量。
其次，通过更紧凑的跳表（skip list）表示方式，可以降低校准掩码的内存占用。
第三，对能量阈值调度 ε(t) 和相似性阈值 γ 进行更丰富的参数化，包括基于层、注意力头或时间步的变体，可能会带来更好的稀疏性-质量权衡。
最后，尽管我们专注于视频扩散模型，但所提出的校准框架可以推广到其他基于 Transformer 的场景，例如图像扩散模型和语言模型。
