摘要

投机解码通过在目标模型生成候选延续之前预先准备候选延续来加速语言模型推理。其效率取决于有限的起草计算对目标模型实际遵循路径的预测程度。预测该路径涉及两个不确定性来源：目标模型的预测和采样的随机性。然而，前者需要目标模型的前向传播，而后者可以在起草开始之前固定。基于这一观察，我们提出了 DICE（Draw-Informed Candidate Selection，基于抽签信息的候选选择），该方法预采样验证随机性并在起草与验证之间保持同步。通过将这些已知的抽签与现有起草器的预测相结合，DICE 将计算分配给在当前采样运行中更可能被使用的延续。这一原则贯穿草稿树构建过程中的节点选择，并可扩展至异步预取——DICE 在此预测应准备哪些下一轮草稿。无需额外的起草器训练，也不改变目标采样分布，DICE 在多种设置下实现了最先进的解码吞吐量，相较强基线最高提速 24.6%。

1 引言

投机解码（Speculative Decoding, SD）是一门预测未来的艺术。在大型目标模型生成其下一个 token 之前，一个轻量级起草器会预先准备合理的候选延续，使目标模型能够用一次并行验证前向传播替代多个串行推理步骤。

但起草器无法负担探索所有可能的延续。因此，其效率取决于将有限的计算分配到目标模型实际会遵循的路径上。

预测目标模型的延续涉及两个不确定性来源：未知的目标模型预测与采样随机性。前者源于起草器无法完全预测目标模型的输出分布；后者则即使在目标分布与草稿分布固定的情况下依然存在，因为采样结果会随随机抽签而变化。

例如，在标准投机采样（Leviathan et al., 2023; Chen et al., 2023）中，提议 token $x$ 被接受的条件是

$$u\,q(x)\leq p(x), \tag{1}$$

其中 $p(x)$ 和 $q(x)$ 分别是 $x$ 的目标概率与草稿概率，$u\sim\mathrm{Uniform}(0,1)$ 是验证抽签。

投机解码领域的大部分进展集中于前者，即通过改进草稿架构（Cai et al., 2024; Li et al., 2024b; Chen et al., 2026）和训练方法（Zhou et al., 2024; Zhang et al., 2025; Li et al., 2025），使草稿分布 $q$ 更接近目标分布 $p$。

然而，这两个不确定性来源在一个关键方面有所不同：获取目标模型的预测需要昂贵的前向传播，而用于验证的随机抽签可以在起草开始之前生成。

这一不确定性来源能否帮助我们决定起草什么内容？

图 1 以固定提议 $x$ 且 $q(x)=0.5$ 为例进行说明。当 $u=0.1$ 时，只要 $p(x)\geq 0.05$，$x$ 就会被接受；当 $u=0.9$ 时，接受则要求 $p(x)\geq 0.45$。目标概率虽然仍然未知，但接受阈值已经确定！较小的抽签值有利于沿 $x$ 继续深入前瞻，而较大的抽签值则有利于准备备选方案以应对 $x$ 被拒绝的情形。因此，同样的草稿预测可以导向不同的投机计算分配。

图 1：已知的采样随机性指导投机计算。两行共享相同的提议 $x$，$q(x)=0.5$，但验证抽签 $u$ 不同。深紫色与浅紫色分别表示会使 $x$ 被接受或拒绝的 $p(x)$ 取值。虚线箭头展示了同样的起草预算如何被分配到沿 $x$ 的更多前瞻，或拒绝情形下的更多备选方案。同样的思想也适用于 Gumbel-max 采样，其中用于目标采样的随机扰动同样可以在起草之前生成。

基于这一观察，我们提出了 DICE（Draw-Informed Candidate Selection，基于抽签信息的候选选择），其名称源于指导起草决策的随机抽签。DICE 将这些抽签与草稿模型预测相结合，用以指导投机计算。在草稿树构建中，由此得到的分数指导候选生成、树扩展以及最终节点选择。我们进一步将 DICE 应用于异步预取，利用已知的随机抽签预测验证结果，并对下一轮草稿进行优先级排序。

DICE 可与现有草稿模型配合使用，并保持目标采样分布完全不变。

我们在多种目标-起草器组合、生成任务和推理设置上评估了 DICE。在匹配的树节点与预取缓存预算下，DICE 提升了接受长度和缓存命中率，在基于树的解码和异步预取中分别带来最高 24.6% 和 13.7% 的解码吞吐量增益。在 SGLang 和 vLLM 等优化推理引擎中，DICE 在所有评估方法中取得最高的解码吞吐量，且在采样温度、并发级别和硬件配置上均有所提升。我们的贡献总结如下：

  • 我们将已揭示的采样随机性识别为一种尚未被充分探索的信息来源，可用于指导投机计算的分配。
  • 我们提出了 DICE，一个免训练、无损的框架，在草稿树构建和异步预取中充分利用这一信息。
  • 我们在多种模型、任务和推理设置上展示了一致的加速效果和最先进的解码吞吐量。

2 预备知识

草稿树验证。 基于树的投机解码将候选延续组织成草稿树以进行并行验证（Miao et al., 2024; Chen et al., 2024; Wang et al., 2025）。给定前缀 $h$，每个节点 $x$ 表示长度为 $|x|$ 的延续，$xv$ 表示在 $x$ 后追加 token $v$ 得到的子节点。树中最多包含 $N$ 个非根节点。目标模型在单次前向传播中评估所有候选前缀。随后，验证从根节点开始沿目标模型的 token 选择进行，直到所选子节点不在树中为止；每访问一个非根节点即接受一个 token，并在停止节点额外生成一个 token。

我们使用 Gumbel-max 技巧（Maddison et al., 2014）表示目标采样：

$$y_{x}=\arg\max_{v}{z_{x}(v)+Tg_{|x|+1}(v)}, \tag{2}$$

其中 $z_{x}$ 表示 $hx$ 之后的目标 logits，$T>0$ 是采样温度，$g_{i}$ 是 $h$ 之后第 $i$ 个位置的独立标准 Gumbel 抽签向量。由此得到目标采样分布 $\operatorname{softmax}(z_{x}/T)$。

投机采样与异步预取。 在标准投机采样（Leviathan et al., 2023; Chen et al., 2023）中，起草器提议序列 $x_{1:K}$，目标模型在单次前向传播中评估并逐 token 验证。提议 $x_{i}$ 被接受的条件是 $u_{i}q_{i}(x_{i})\leq p_{i}(x_{i})$，其中 $p_{i}$ 和 $q_{i}$ 是位置 $i$ 处的目标分布与草稿分布，$u_{i}\sim\mathrm{Uniform}(0,1)$ 独立于提议进行抽取。在首次拒绝时，验证保留已接受的前缀，并从与 $[p_{i}-q_{i}]{+}$ 成正比的残差分布中采样校正 token。若所有提议均被接受，则从目标分布中采样一个奖励 token。我们将验证结果记为 $(k,v)$，其中 $k$ 是被接受的草稿 token 数量，$v$ 是校正 token 或奖励 token。下一轮从 $hx{1:k}v$ 开始。

投机投机解码（Speculative Speculative Decoding, SSD）（Kumar et al., 2026）在目标模型验证当前提议的同时，为可能的下一轮前缀准备草稿。每个预取的草稿对应一个验证结果 $(k,v)$，缓存最多容纳 $B$ 个条目。若实际结果与就绪的缓存条目匹配，下一轮可直接复用预取的草稿，无需等待再次起草。

3 方法

本节介绍 DICE——一种进一步加速投机解码的简单方法。其关键技术设计是：在起草之前抽取验证所用的随机性，并在起草策略与目标验证器之间同步这些抽签。起草策略将其与现有草稿模型的预测相结合，决定准备哪些延续；而验证器使用相同的抽签确定实际输出。如此，DICE 在无需额外草稿模型训练、也不改变目标采样分布的前提下，改进了投机计算的分配。

我们在两种设置中实例化 DICE： 草稿树构建（第 3.1 节），指导整个树构建过程中的节点选择； 异步预取（第 3.2 节），对预取的下一轮草稿进行优先级排序。

图 2：DICE 使用预采样的随机性指导草稿树构建。给定相同的前缀、草稿模型和节点预算（$N=6$），标准 EAGLE 仅使用草稿预测构建树，而 DICE 将草稿预测与已知的 Gumbel 抽签相结合，指导整个树构建过程中的节点选择。分数插图展示了已知扰动如何改变 token 偏好。目标模型使用其真实 logits 和相同的同步抽签，生成右侧所示的实现延续。彩色节点表示被接受的草稿 token，虚线节点表示不在树中的下一个目标 token。在本例中，DICE 接受了三个草稿 token，而 EAGLE 仅接受一个。

3.1 种子感知的草稿树构建

在每个节点 $x$ 处，目标模型的下一个 token 选择取决于其 logits $z_{x}$ 和 Gumbel 扰动 $g_{|x|+1}$（公式 2）。如前所述，获取 $z_{x}$ 需要目标模型前向传播，而 $g_{|x|+1}$ 可以在起草之前采样。我们将草稿 logits $d_{x}$ 与已知扰动相结合，估计目标模型的下一个 token 选择：

$$\widehat{r}{x}(v)=\operatorname{softmax}{v}\left(\frac{\alpha d_{x}+Tg_{|x|+1}}{\sigma}\right), \tag{3}$$

其中 $\alpha,\sigma>0$ 分别控制草稿 logits 的相对尺度和所得分数的集中程度。对于草稿 logit 相同的 token，较大的 Gumbel 扰动会带来更高的选择分数。我们仅针对每个目标-起草器组合校准一次这两个参数。实践中，解码过程中观察到的前 2,000 个节点（通常对应 1–3 个提示）足以完成精确校准。评分规则的推导和校准精度的分析见附录 A。

为对整条延续评分，我们沿每条路径累积局部选择分数：

$$\widehat{w}(\varnothing)=1,\qquad \widehat{w}(xv)=\widehat{w}(x)\widehat{r}_{x}(v). \tag{4}$$

只有当目标模型选中某节点路径上的每一个 token 时，验证才会到达该节点，因此 $\widehat{w}(x)$ 估计了该节点被访问的可能性。我们在整个树构建过程中使用这些分数：在每个起草步骤中，局部分数决定提议哪些子 token，累积路径分数决定接下来扩展哪些节点；同样的路径分数用于选择最终提交目标验证的节点。当启用动态树规模时，它们还指导起草深度和验证宽度的选择。算法 1 总结了由此得到的树构建流程。

该方法与底层草稿模型无关，适用于采用独立小型起草器（Svirschevski et al., 2024; Wang et al., 2025）、EAGLE 系列起草器（Li et al., 2024b; Li et al., 2025; EAGLE-4 Team, 2026）以及多 token 预测（MTP）模块（Gloeckle et al., 2024; DeepSeek-AI, 2024）的基于树的解码。DICE 保留了它们现有的起草架构和树验证基础设施。

算法 1 用于草稿树构建的 DICE

  • 输入：前缀 $h$，起草器 $D$，策略 $\mathcal{P}$，预算 $N$，步数 $L$，已校准的 $(\alpha,\sigma)$，温度 $T$，抽签 ${g_{i}}$
  • 输出：验证树 $\mathcal{S}$，$|\mathcal{S}|\leq N$
  • 1: $\mathcal{U}\leftarrow\mathcal{F}\leftarrow{\varnothing}$，$\widehat{w}(\varnothing)\leftarrow 1$　⊳ 起草并评分候选节点
  • 2: for $\ell=1,\ldots,L$ do
  • 3: 　${d_{x}}_{x\in\mathcal{F}}\leftarrow D(h,\mathcal{F})$
  • 4: 　$\widehat{r}{x}\leftarrow\operatorname{softmax}((\alpha d{x}+Tg_{|x|+1})/\sigma)$，$x\in\mathcal{F}$
  • 5: 　$\mathcal{C}\leftarrow \operatorname{Propose}{\mathcal{P}}(\mathcal{F},{\widehat{r}{x}})$
  • 6: 　$\widehat{w}(xv)\leftarrow \widehat{w}(x)\widehat{r}_{x}(v)$，$xv\in\mathcal{C}$
  • 7: 　$\mathcal{U}\leftarrow \mathcal{U}\cup\mathcal{C}$
  • 8: 　$\mathcal{F}\leftarrow \operatorname{Select}_{\mathcal{P}}(\mathcal{C},\widehat{w})$
  • 9: end for
  • 10: $\mathcal{S}\leftarrow \operatorname{Top}_{N}(\mathcal{U}\setminus{\varnothing},\widehat{w})$　⊳ 选择验证节点
  • 11: return $\mathcal{S}$

目标模型随后使用其真实 logits 以及起草时所用的同一组 Gumbel 抽签对构建好的树进行验证。每个 Gumbel 向量绑定到一个逻辑输出位置，因此同一深度的节点共享对应的向量。未使用的抽签会结转至后续解码轮次。因此，DICE 改变的只是预先计算哪些延续，而在相同随机抽签下，生成的序列与自回归目标采样完全一致。形式化的正确性证明见附录 B。

3.2 种子感知的异步预取

除草稿树构建外，DICE 还指导预取哪些下一轮草稿。每个验证结果 $(k,v)$ 确定一个可能的下一轮前缀 $hx_{1:k}v$，而缓存最多只能容纳其中 $B$ 个的草稿。因此，DICE 基于预采样的验证随机性和草稿模型预测，估计哪些结果最有可能出现。均匀抽签 $u_{i}$ 有助于预测将接受多少个草稿 token，而 Gumbel 向量 $g_{k+1}$ 有助于预测校正 token 或奖励 token $v$。

为估计接受长度，我们对每个提议 token 建模未知的目标-草稿概率比 $\rho_{i}=p_{i}(x_{i})/q_{i}(x_{i})$。接受条件变为 $\rho_{i}\geq u_{i}$。由于预取期间无法获得目标概率，我们从草稿概率 $q_{i}(x_{i})$ 出发估计 $\rho_{i}$ 的分布。具体而言，我们假设草稿概率是校准的，即 $\mathbb{E}[\rho_{i}\mid q_{i}(x_{i})]=1$。结合界限 $0\leq\rho_{i}\leq 1/q_{i}(x_{i})$，可得到一个最大熵模型 $f_{q_{i}(x_{i})}$，其形式为截断指数分布。其参数仅由草稿概率决定，无需额外拟合（附录 C）。

给定已知抽签 $u_{i}$，接受概率估计为：

$$\widehat{\eta}{i}=\Pr{\rho\sim f_{q_{i}(x_{i})}}(\rho\geq u_{i}). \tag{5}$$

假设各位置的比率相互独立，恰好接受 $k$ 个草稿 token 的概率估计为：

$$\widehat{P}(k)=\begin{cases}\left(\prod_{i=1}^{k}\widehat{\eta}{i}\right)(1-\widehat{\eta}{k+1}),& k<K,\ \prod_{i=1}^{K}\widehat{\eta}_{i},& k=K.\end{cases} \tag{6}$$

接下来，我们使用相同的比率模型和已知的 Gumbel 向量 $g_{k+1}$ 估计已接受前缀之后跟随的 token。对每个可能的 $k$，我们从 $f_{q_{k+1}(v)}$ 中采样比率 $\rho_{k+1}(v)$，并构造非归一化的 token 权重：

$$m_{k}(v)=\begin{cases}q_{k+1}(v)[\rho_{k+1}(v)-1]{+},& k<K,\ q{K+1}(v)\rho_{K+1}(v),& k=K.\end{cases} \tag{7}$$

第一种情形对应拒绝后的校正采样，此时被拒绝的提议残差权重为零；第二种情形对应所有提议均被接受时的奖励 token 采样。固定 $g_{k+1}$ 后，我们反复选取最大化 $\log m_{k}(v)+g_{k+1}(v)$ 的 token，所得 token 频率即为 $\widehat{r}_{k}(v)$ 的估计。

综合两项预测，得到每个验证结果的估计概率：

$$\widehat{\pi}(k,v)=\widehat{P}(k)\widehat{r}_{k}(v). \tag{8}$$

DICE 选取得分最高的 $B$ 个结果，并使用现有的 SSD 流水线（Kumar et al., 2026）异步准备其对应草稿。验证使用真实目标概率和相同的预采样随机抽签。对每个可能的下一轮前缀，预取的提议均从原始草稿分布中采样，且独立于其自身的接受均匀变量。缓存命中时复用已准备的草稿，未命中则回退到常规起草。因此，DICE 只改变预先准备哪些草稿，而不改变目标采样分布。

3.3 实现

我们使用以请求种子和绝对 token 位置为索引的确定性、基于计数器的哈希按需生成验证随机性；对于 Gumbel 扰动，还额外加入词表索引。接受、目标采样和草稿提议分别使用独立的随机流。这使得起草和验证工作进程（即使位于不同 GPU 上）能够复现相同的验证抽签，而无需存储或传输随机数缓冲区。以绝对位置索引还确保抽签在解码轮次、树结构和执行调度之间保持一致。

由于抽签可在本地获取，我们将 DICE 的评分融合到现有的 GPU 候选选择内核中，在存在已知扰动时于词表过滤阶段应用。额外的运算在现有起草步骤内完成，并可被 CUDA 图捕获，无需额外的模型前向传播。

4.1 实验设置

模型与基准。 对于草稿树解码，我们在 16 个目标-起草器组合上评估 DICE，其中包括 5 个使用 OPT-Tree（Wang et al., 2025）的独立小型起草器、8 个使用 EAGLE-2（Li et al., 2024a）、EAGLE-3（Li et al., 2025）或 EAGLE-4（EAGLE-4 Team, 2026）的组合，以及 3 个使用多 token 预测（MTP）模块（Gloeckle et al., 2024; DeepSeek-AI, 2024）的组合。两个 EAGLE-4 组合同时在 SGLang（Zheng et al., 2024）和 vLLM（Kwon et al., 2023）中评估，共计 18 个模型-后端配置。对于异步预取，我们在 4 个目标-起草器组合上结合 SSD（Kumar et al., 2026）评估 DICE，包括原研究中的两个设置和两个额外设置。

草稿树实验使用 Spec-Bench（Xia et al., 2024）和 SPEED-Bench（Abramovich et al., 2026），涵盖对话、翻译、摘要、数学推理、问答和检索增强生成。预取实验遵循原始 SSD 评估套件：Alpaca（Taori et al., 2023）、GSM8K（Cobbe et al., 2021）、HumanEval（Chen et al., 2021）和 UltraFeedback（Cui et al., 2024）。

基线与后端。 我们将 DICE 与相应的原始投机解码方法进行比较，保持草稿模型权重和推理后端不变。对于草稿树解码，独立起草器和 EAGLE-2/3 使用基于 Hugging Face Transformers（Wolf et al., 2020）的参考实现，MTP 和 EAGLE-4 使用 SGLang（Zheng et al., 2024）和 vLLM（Kwon et al., 2023）中的优化实现。对于异步预取，我们使用原始 SSD 实现（Kumar et al., 2026），仅将其预取选择策略替换为 DICE。我们同时纳入自回归解码作为衡量加速的参照。

评估。 我们报告解码吞吐量、相对自回归解码（AR）的加速倍数，以及平均接受长度 $\tau$（定义为每次目标前向传播生成的 token 数量）。对于预取，我们还报告缓存命中率。每个基线使用其作者推荐的配置；若无推荐配置或存在更快配置，则使用在保留集上找到的最快配置。DICE 采用相同的配置方式。除非另有说明，我们在 $T=1$ 下采样，并在 H200 GPU 上每次服务一个请求。

4.2 草稿树解码

主要结果。 表 1 显示，DICE 在所有目标-起草器组合和后端上均提升吞吐量，在 Spec-Bench 上提升 4.3–21.5%，在 SPEED-Bench 上提升 5.6–24.6%。增益适用于独立起草器、EAGLE 起草器和 MTP 模块，且同时适用于参考实现和生产级后端。在所有情形中，DICE 每次目标前向传播接受的 token 更多，因为已知的随机性将树引导向目标模型将要采样的延续。

采样温度。 图 3(a, b) 在固定节点预算下比较了 EAGLE-4 与 DICE 在不同采样温度下的表现。在 $T=0$ 时，两种方法均进行贪婪验证，速度相同。随着温度升高，目标分布变得更加分散，固定节点预算覆盖采样延续的频率下降，EAGLE-4 的吞吐量随之降低。DICE 则针对实际将使用的抽签构建树，因此其吞吐量下降幅度小得多，优势随温度增大而扩大。

图 5：增益的来源。 相对于不使用抽签的起草器，在 60 个节点、深度 10 的固定树上（OPT-Tree，Spec-Bench）接受长度的变化。打乱的抽签与目标模型的抽签相互独立；"仅子节点"变体只用抽签选择每个节点的子节点，但按草稿概率分配预算。 树在深度 $d$ 内覆盖目标延续的概率 $C_{d}$（Llama-3.1-70B 搭配 Llama-3.1-8B 起草器）。 接受长度随节点预算的变化（SGLang 中 Qwen3.8-27B 搭配 EAGLE-4）。 缓存命中率随缓存预算的变化（Llama-3.1-70B-Instruct 搭配 SSD）。

并发。 同时服务大量请求会减少可用于投机的空闲算力。图 4 报告了并发从 1 增长到 64 时 DICE、EAGLE-4 以及两个并行起草器 DFlash2（Chen et al., 2026）和 DSpark（Cheng et al., 2026）的吞吐量。在 SGLang 和 vLLM 中，DICE 在所有并发级别上都是最快的方法，分别领先最强基线 2–18% 和 8–20%。在并发为 64 时，DFlash2 和 DSpark 的速度低于 AR，而 DICE 仍分别比 AR 快 1.19 倍和 1.28 倍。当引擎在高并发下将投机缩减为单条草稿链时，DICE 可原样适用，因为链即是每节点单子节点的树。

4.3 异步预取

图 6：Llama-3.1-70B-Instruct 搭配 Llama-3.2-1B-Instruct 起草器时，带与不带 DICE 的 Saguaro 采样 SSD。较小的 $C$ 对草稿的重塑更强，$C=1$ 即标准采样。

主要结果。 表 2 显示，DICE 在所有组合上提升了 SSD 的缓存命中率，从 45.6–67.6% 提升至 69.8–80.7%，带来 4.0–13.7% 的吞吐量增益。接受长度几乎不变，因为 DICE 改变的是准备哪些草稿，而非草稿本身。增益在原始 SSD 最常未命中的场景中最大。图 3(c, d) 展示了这一现象随温度的变化。低温下，SSD 已能预测大多数验证结果，DICE 与之持平；随着采样随机性增强，SSD 的命中率在 $T=1$ 时降至 57–60%，而 DICE 保持在 80% 附近。

与 Saguaro 采样的比较。 SSD 还可通过 Saguaro 采样（Kumar et al., 2026）提升命中率，该方法用参数 $C$ 重塑草稿分布，使下一次验证结果更易预测，但代价是接受率降低。DICE 在不改变草稿的前提下提升命中率，因此两种方法互补。图 6 对 $C$ 进行扫描：在每个 $C$ 值下，DICE 均带来 13–18 个百分点的命中率提升。单独使用 DICE（$C=1$）即可匹敌 SSD 在最优 $C$ 下的表现（170 对 168 tokens/s），二者结合可达 177 tokens/s。

5 讨论

如第 4 节所示，DICE 仅通过改变投机计算的分配方式，就在起草器、推理引擎和采样设置上取得一致的加速。为深入理解其原因，本节考察： 这些增益的来源； 增益在多大程度上依赖于对目标模型未知预测的建模。

5.1 增益来自哪里？

增益是否仅仅来自对草稿分数的扰动？ DICE 在起草器的 logits 上添加 Gumbel 噪声，而噪声本身就会改变树所探索的候选。为区分抽签中的信息与扰动本身，我们固定树预算和目标模型的抽签，仅改变起草器所见的内容（图 5a）。使用打乱后的抽签时，起草器遵循 DICE 的评分规则，但所用抽签与目标模型将使用的抽签相互独立，这使接受长度相对不使用抽签的起草器下降 11–14%；使用同步抽签时，DICE 将其提升 11–24%。增益来自知晓目标模型实际将使用的抽签，而非来自对起草器的随机化。

这一知识只有在塑造预算分配时才有帮助。 若 DICE 仅选择每个节点的子节点，而树仍按草稿概率分配预算，则大部分增益消失（图 5a）。

图 5b 展示了预算的去向。它绘制了树在深度 $d$ 内包含目标延续的概率 $C_{d}$，其对 $d$ 求和即为接受长度。DICE 在除第一层之外的每个深度上都更频繁地覆盖实际路径，且差距随深度扩大。

可分配资源越多，更优分配的价值应越大。 图 5c 和 d 改变预算规模。对于草稿树，DICE 的优势随节点数增加而扩大：EAGLE-4 需要 64 个节点才能达到 DICE 用 16 个节点达到的接受长度；对于预取，拥有 8 个缓存结果的 DICE 即可匹敌 SSD 用 24 个缓存结果达到的命中率。

两类抽签在此贡献不同：接受抽签 $u_{i}$ 指示验证将在何处停止，Gumbel 抽签 $g_{k+1}$ 指示随后将出现哪个 token。在 Llama-3.1-70B-Instruct 上，单独使用任一类抽签可将 SSD 的命中率从 59.8% 提升至 66.9–67.9%，两者结合可达 76.2%。

5.2 需要多少建模？

图 7：需要多少建模。 相对于不使用抽签的起草器，三种目标选择预测器在图 5a 的固定树上的接受长度变化（Vicuna-33B 和 Llama-3.1-70B）。 使用不同停止模型的预取缓存命中率（Llama-3.1-70B-Instruct，24 个缓存结果）。

前述结果表明，实际抽签对投机计算的分配具有信息价值。然而，DICE 仍依赖对目标模型未知预测的估计。这些估计需要多精确？

对于草稿树，我们在相同的固定树上比较容量递增的预测器（图 7a, b）。$\alpha=\sigma=1$ 的即插即用规则已能将接受长度提升 9–22%；校准这两个参数可再增加一至两个百分点，且几百个观测节点即已足够（附录 A）。在校准分数上附加学习修正的神经预测器，对目标选择的留出似然几乎没有改变（Vicuna-33B 上 0.94 对 0.95 nats，Llama-3.1-70B 上 0.56 对 0.55），最多增加 1.5 个百分点。DICE 需要的是能对候选进行足够好排序以分配预算的估计，而非目标分布的完整模型。

对于预取，我们用其他随观测抽签递增的估计替换停止位置的最大熵模型（图 7c）。这些变体仅改变停止位置的估计方式，其命中率均在最大熵模型的三个百分点以内；而忽略抽签或反转其方向则会损失 10 到 17 个百分点。

在两种应用中，增益更多取决于使用实际的验证抽签，而非概率估计的具体形式。即使目标模型的预测仅近似已知，揭示采样随机性也能让投机解码将算力投入到将被实际使用之处。

6 相关工作

投机解码。 投机解码通过在单次目标前向传播中验证多个草稿 token 来加速自回归生成，同时保持目标分布不变（Leviathan et al., 2023; Chen et al., 2023）。后续工作同时改进了草稿预测和候选组织。SpecInfer 验证树状结构候选（Miao et al., 2024）；EAGLE-2 利用草稿置信度构建上下文相关的树（Li et al., 2024a）；OPT-Tree 显式优化期望接受长度（Wang et al., 2025）；Sequoia 在树结构之外还考虑了硬件相关的成本（Chen et al., 2024）；EAGLE-3 通过多层特征和训练时展开改进草稿预测（Li et al., 2025）；最近的 EAGLE-4 将高效起草器与成本感知的树规模调整相结合（EAGLE-4 Team, 2026）。DICE 通过在即将到来的验证所使用的随机性上对候选分数进行条件化，对这些进展形成补充。

异步解码。 异步方法将起草与目标验证重叠以减少串行执行。SwiftSpec 发展了异步起草以及 KV 缓存管理和执行优化（Zhang et al., 2026）。投机投机解码（SSD）为预测的验证结果准备未来草稿（Kumar et al., 2026）。DICE 在此设置之上，利用实际的接受均匀变量预测拒绝位置，并利用后续采样噪声对校正或奖励 token 排序。

共享随机性。 共享随机性耦合提供了基于拒绝的投机采样之外的另一种途径。Daliri et al. (2025) 使用免通信耦合获得起草器不变的投机解码，其输出由目标模型和随机种子决定。Rowan et al. (2025) 将耦合扩展到多个草稿并建立了条件起草器不变性。Kobus and Gündüz (2025) 提出指数竞赛投机解码，并利用边际节点接受概率分析树构建。PTP 将采样随机性作为辅助模型输入，训练模型联合预测多个未来 token（Draxler et al., 2026）。相比之下，DICE 利用共享随机性不仅耦合样本，还在验证结果已知之前指导投机计算。这释放了种子感知的更大潜力，实现了通用的免训练加速，并可直接集成到现代 LLM 服务引擎中。

7 结论

我们提出了 DICE，一种免训练方法，消除了投机解码中的一个不确定性来源。控制验证的随机抽签可以在起草之前采样，并在起草器与验证器之间共享。DICE 将这些已知抽签与现有起草器的预测相结合，决定准备哪些延续：在草稿树构建中指导节点选择，在异步预取中对下一轮草稿排序。目标采样分布保持不变。在独立起草器、EAGLE 和 MTP 起草器，参考和生产引擎，以及一系列温度和并发级别上，DICE 一致地提升解码吞吐量——在草稿树解码中最高达 24.6%，在异步预取中最高达 13.7%。这些增益源于将同样的投机预算花费在采样运行将实际使用的候选上。

更广泛地说，我们的结果表明，在决定预先计算什么时，采样随机性不必被视为未知，这一思路或可惠及其他形式的投机与异步推理。

附录 A 树评分规则的推导

目标选择的随机效用模型。 在节点 $x$ 处，目标选择 $y_{x}=\arg\max_{v}{z_{x}(v)+Tg_{|x|+1}(v)}$（公式 2）。起草期间，抽签 $g_{|x|+1}$ 已知，但目标 logits $z_{x}$ 未知。我们通过草稿 logits $d_{x}$ 对目标 logits 建模：

$$z_{x}(v)=\alpha\,d_{x}(v)+\epsilon_{x}(v)+c_{x}, \tag{9}$$

其中 $c_{x}$ 是所有 token 共享的常数，误差 $\epsilon_{x}(v)$ 是尺度为 $\sigma$ 的独立 Gumbel 变量，且与抽签独立。于是目标选择最大化已知效用加独立 Gumbel 噪声：

$$y_{x}=\arg\max_{v}{\alpha\,d_{x}(v)+Tg_{|x|+1}(v)+\epsilon_{x}(v)}. \tag{10}$$

由 Gumbel-max 性质（也是多项 logit 模型的基础，McFadden, 1974），

$$\Pr(y_{x}=v\mid d_{x},g_{|x|+1})=\operatorname{softmax}{v}\left(\frac{\alpha d{x}+Tg_{|x|+1}}{\sigma}\right)=\widehat{r}_{x}(v), \tag{11}$$

即公式 3。斜率 $\alpha$ 修正相对于目标过尖或过平的起草器 logits，$\sigma$ 度量目标偏离重标定起草器的程度。当 $\sigma\to 0$ 时，估计集中于 $\arg\max_{v}{\alpha d_{x}(v)+Tg_{|x|+1}(v)}$；当 $\sigma$ 增大时，趋近均匀分布。设 $\alpha=\sigma=1$ 可得无参数默认值。

路径分数与节点选择。 验证访问节点 $x=x_{1}\cdots x_{\ell}$ 当且仅当目标在每个 $x_{j}$ 的父节点处选择 $x_{j}$。若误差跨节点独立，该事件在给定草稿和抽签下的概率为 $\prod_{j=1}^{\ell}\widehat{r}{x{<j}}(x_{j})=\widehat{w}(x)$，即公式 4。每个被访问的非根节点贡献一个接受 token，因此对树 $\mathcal{S}$，接受 token 的期望数量为

$$\mathbb{E}[A\mid{g_{i}}]=\sum_{x\in\mathcal{S}}\Pr(x\text{ 被访问}\mid{g_{i}}), \tag{12}$$

DICE 用 $\sum_{x\in\mathcal{S}}\widehat{w}(x)$ 估计。在 $N$ 个节点的预算下，该估计由路径分数最大的 $N$ 个节点最大化。由于 $\widehat{w}(xv)\leq\widehat{w}(x)$，被选节点的每个祖先的分数不低于该节点本身，因此所选集合（平局时偏向较浅节点）构成合法的树。

校准。 已验证树的每个节点都揭示目标选择 $y_{x}$，因为目标在单次前向传播中评估所有节点。我们在这些选择上以最大似然拟合 $(\alpha,\sigma)$。令 $a=\alpha/\sigma$，$b=1/\sigma$，单个节点的对数似然为

$$\log\widehat{r}{x}(y{x})=a\,d_{x}(y_{x})+bTg_{|x|+1}(y_{x})-\log\sum_{v}\exp(a\,d_{x}(v)+bTg_{|x|+1}(v)), \tag{13}$$

它关于 $(a,b)$ 是凹的。因此拟合具有唯一最优解，并在少数梯度步内收敛，也可在解码过程中在线运行。

校准需要多少数据。 图 8 在表 1 的七个目标-起草器组合上，用观测节点的随机子集拟合 $(\alpha,\sigma)$，并报告每个子集恢复的留出似然增益占全量校准数据拟合的比例。几百个节点即可恢复大部分增益。使用 1,600 个节点时，每个组合的中位比例为 98–100%，十分之九的子集至少恢复 95%。我们实验中使用的 2,000 个节点对应一到三个提示。

附录 B 正确性

全文中，抽签按绝对输出位置索引。设 $g_{1},g_{2},\ldots$ 为独立标准 Gumbel 向量，定义参考序列 $y^{\star}$ 为目标的自回归 Gumbel-max 采样：

$$y^{\star}{j}=\arg\max{v}{z_{y^{\star}{<j}}(v)+Tg{j}(v)},\qquad j=1,2,\ldots \tag{14}$$

由 Gumbel-max 技巧，给定 $y^{\star}{<j}$ 时 $y^{\star}{j}$ 是 $\operatorname{softmax}(z_{y^{\star}{<j}}/T)$ 的样本，因此 $y^{\star}$ 服从目标的自回归采样分布。在第 3.1 节的记号中，某轮在已输出 $j-1$ 个 token 后开始，该轮中节点 $x$ 使用的抽签 $g{|x|+1}$ 在绝对索引下为 $g_{j+|x|}$。

命题 1（草稿树构建）。 对抽签的每次实现以及任何根据前缀、起草器和抽签构建草稿树的规则，DICE 恰好输出 $y^{\star}$。

证明。 只需证明从前缀 $y^{\star}{<j}$ 开始的一轮输出 $y^{\star}{j},\ldots,y^{\star}{j+M}$（某个 $M\geq 0$），因为下一轮随后从 $y^{\star}{<j+M+1}$ 开始，结论通过对轮数的归纳成立。在该轮内，设验证已到达节点 $y^{\star}{j}\cdots y^{\star}{j+m-1}$（$m\geq 0$，$m=0$ 为根）。其前缀为 $y^{\star}{<j+m}$，其抽签为 $g{j+m}$，因此目标选择 $\arg\max_{v}{z_{y^{\star}{<j+m}}(v)+Tg{j+m}(v)}=y^{\star}{j+m}$。若该 token 是节点的子节点，验证接受它并移至该子节点；否则它作为奖励 token 输出且该轮结束。无论哪种情况，该轮都输出 $y^{\star}$ 的下一个 token，且由于树有限，该轮在输出 $y^{\star}{j},\ldots,y^{\star}_{j+M}$ 后结束。∎

草稿树可以以任意方式依赖抽签，但它只决定每轮输出多少 token，而不决定输出哪些 token。这就是为什么在抽签上条件化树构建不改变输出分布。

命题 2（异步预取）。 采用 DICE 预取策略的 SSD 与目标具有相同的输出分布。

证明。 SSD 的每轮通过投机采样验证提议 $x_{1:K}$。若 $u_{i}q_{i}(x_{i})\leq p_{i}(x_{i})$ 则接受 $x_{i}$，并用 $g_{k+1}$ 通过 Gumbel-max 技巧从归一化残差 $[p_{k+1}-q_{k+1}]{+}$ 或从 $p{K+1}$ 采样校正或奖励 token。只要在给定前缀时， 提议取自草稿分布，且 验证抽签与提议独立，投机采样即产生目标分布（Leviathan et al., 2023; Chen et al., 2023）。两个条件在 DICE 下均成立。起草器用自身的随机性从 $q_{i}$ 采样每个提议，预取策略只选择提前为哪些前缀起草，因此无论草稿是预取的还是缓存未命中后起草的，实现前缀的提议都是 $q_{i}$ 的抽取。验证抽签独立于起草器采样，且从不用于生成提议。策略读取它们仅为了决定准备哪些草稿，这改变的是草稿何时可用，而非其取值。因此每轮都是标准的投机采样轮，输出服从目标分布。∎

附录 C 最大熵比率模型

推导。 对草稿概率为 $q=q_{i}(x)$ 的提议 token $x$，比率 $\rho=p_{i}(x)/q$ 位于 $[0,b]$，其中 $b=1/q$，因为 $p_{i}(x)\leq 1$。若起草器已校准，$\mathbb{E}[p_{i}(x)\mid q]=q$，故 $\mathbb{E}[\rho\mid q]=1$。在 $[0,b]$ 上均值为 1 的密度中，最大熵者求解

$$\max_{f}\ -\int_{0}^{b}f\log f\,d\rho\quad\text{s.t.}\quad\int_{0}^{b}f\,d\rho=1,\qquad\int_{0}^{b}\rho f\,d\rho=1. \tag{15}$$

令拉格朗日函数的变分为零得 $\log f(\rho)=-1-\mu-\lambda\rho$，因此

$$f_{q}(\rho)=\frac{\lambda e^{-\lambda\rho}}{1-e^{-\lambda b}},\qquad 0\leq\rho\leq b, \tag{16}$$

即截断指数分布，$\lambda=0$ 时 $f_{q}$ 为均匀分布。速率 $\lambda$ 由均值约束确定：

$$\frac{1}{\lambda}-\frac{b}{e^{\lambda b}-1}=1. \tag{17}$$

$f_{q}$ 的均值关于 $\lambda$ 严格递减，从 $\lambda\to-\infty$ 时的 $b$ 到 $\lambda\to\infty$ 时的 $0$，且在 $\lambda=0$ 时等于 $b/2$。由于 $0<1<b$，公式 17 有唯一解，且仅依赖于 $q$。当 $q<1/2$ 时为正，$q=1/2$ 时为零，$q>1/2$ 时为负。我们对 $\lambda$ 关于 $q$ 做一次制表，因此该模型没有需要拟合的参数。

接受概率。 提议被接受当且仅当 $\rho\geq u_{i}$。给定已知抽签 $u_{i}$，公式 5 有闭式解：

$$\widehat{\eta}{i}=\frac{e^{-\lambda u{i}}-e^{-\lambda b}}{1-e^{-\lambda b}}\quad(\lambda\neq 0),\qquad \widehat{\eta}{i}=1-\frac{u{i}}{b}\quad(\lambda=0). \tag{18}$$

对 $u_{i}\sim\mathrm{Uniform}(0,1)$ 取平均可得 $\mathbb{E}[\min(\rho,1)]$，即该模型下投机采样的接受概率。

校正与奖励 token。 在同一模型下，$q_{k+1}(v)\rho_{k+1}(v)$ 扮演目标概率 $p_{k+1}(v)$ 的角色。公式 7 中的权重因此分别是拒绝后的残差 $[p_{k+1}-q_{k+1}]{+}$ 和完全接受后的目标分布 $p{K+1}$，即验证采样的两个分布。固定 $g_{k+1}$ 并在采样的比率上最大化 $\log m_{k}(v)+g_{k+1}(v)$ 复现了验证的 Gumbel-max 步骤，因此所得频率估计给定已知抽签时每个 token 的概率。被拒绝的提议满足 $\rho_{k+1}(x_{k+1})<u_{k+1}\leq 1$，故其残差权重为零，与验证一致。
