多模态音乐会视频编辑：系统设计与探索性评估

作者： Lennart Schiweck、Adrian Kempf、Michelle Retig、Moritz Feucht、Tim Mangliers、Benjamin Himpel

机构： 罗伊特林根大学信息学系，72762 罗伊特林根，德国

通讯作者： Tim Mangliers

摘要

编辑多机位音乐会视频需要在音乐相关性、画面质量和切换时机方面做出协调决策。我们提出了一个模块化框架，将来自多轨音频的乐器活跃度、可见乐器和图像清晰度与基于节拍的时机控制和概率性摄像机选择相结合。一个可解释的评分模型将这些组件与完整镜头区间上的视角选择联系起来。针对四机位音乐会的组件测试和探索性专家研究显示，各编辑变体的评估结果不一。这些发现促使将局部视听相关性扩展至情境和序列级标准。该架构为测试这些扩展以及研究组件行为如何影响完整编辑质量提供了基础。

关键词： 自动视频编辑；音乐会录制；多模态分析；摄像机选择；可解释评分

1 引言

多机位音乐会编辑需要决定何时切换以及显示哪个视角。编辑者需要协调音乐活动、图像质量、构图和序列的进展。清晰看到正在演奏的乐器可能有用，但乐队其他位置的反应或互动同样有价值。因此，将这一工作流程自动化需要的不仅仅是对孤立图像的排序。

自动摄像机管理已在讲座环境 [9]、音乐会混搭 [15] 和社交摄像机素材 [1] 中得到研究。音乐会导播系统结合了听觉和视觉乐器信息 [17]；学习方法则处理下一视角选择和切换预测 [8, 6]。多机位编辑中也对时间和候选视角上下文进行了建模 [12, 2]，而戏剧系统则结合了摄像机选择和景别控制 [16]。

我们提出了一个模块化框架，将音频分析、视觉分析、摄像机评分和时间选择相互分离。命名的音频分轨提供乐器活跃度和角色；视觉检测描述乐器可见性，图像梯度统计表征清晰度。一个显式的效用函数结合这些信号，在预期镜头区间上对其进行聚合，并控制概率性摄像机选择器。节拍和速度估计独立于视角选择确定候选切换边界。

本文的贡献有三方面：用于音乐会编辑的透明多模态架构；从角色和质量线索到区间级摄像机选择的显式映射；以及激发针对性架构扩展的组件和专家评估。该研究比较了人工参考编辑、随机摄像机选择和两个评分驱动变体。其混合结果为镜头适用性、情境反应和序列结构的后续工作提供了信息，而不将组件准确性视为完整编辑质量的替代品。

Shrestha 等人 [15] 在音乐会混搭中结合了感知图像质量、内容多样性和切换点适用性。他们的 40 名参与者评估已经比较了自动、手动和随机编辑，因此我们的基线遵循了既定策略。Daniyal 和 Cavallaro [3] 用内容质量和切换成本建模有限时域摄像机调度；我们的无重复采样器不优化序列级目标。Stoll 等人 [16] 为四视角戏剧录制结合了基于规则的摄像机选择和裁剪，包括视听说话者分配。他们对四视角和单视角编辑版本的比较保持切换时间、镜头长度和景别固定。我们的系统选择现有视角而不生成更紧凑的构图。

基于学习的音乐会编辑方法也是直接的比较对象。Jiménez 等人 [8] 从专业编辑的音乐会视频中学习视觉下一镜头选择。他们的人类研究评估静态图像选择。因此，基于学习的下一视角选择是一种既定方法。Gonzálbez-Biosca 等人 [6] 将切换时间预测与视角选择分离：音频和时间特征为前者提供信息，学习的视觉表示为后者提供信息。他们的古典音乐会评估使用从现有编辑派生的伪标注候选，并报告切换预测和检索度量。这些与完整实现编辑的感知质量是不同的结果。

Rao 等人 [12] 引入了包含音乐会在内的同步多机位素材的 TVMCE 基准，并对过去帧和候选视角进行建模。Cabacas-Maso 等人 [2] 通过具有交叉注意力的双变换器架构进一步区分历史和候选编码。这些方法明确表示了我们无重复采样器之外的上下文，但它们的参考决策一致性度量本身并不能确立我们音乐会编辑的感知质量。

相邻的编辑方法使更广泛的目标显式化。Galvane 等人 [4] 使用动作、连续性和节奏成本优化 3D 动画中的镜头序列，并对退化成本变体进行主观比较。EditIQ [5] 将对话解释、显著性和说话者线索与电影约束相结合，从广角录制生成虚拟视角；其用户研究包括情感和反应。EmotionCast [18] 还研究了舞台节目导播中的情感线索。这些工作激发了对编辑上下文和序列级标准的测试，而它们不同的材料和设计阻碍了将其性能结论迁移到本试点研究中。音乐会评估激发了为器乐演奏和乐队互动测试这些想法。

我们框架的重点在于乐器角色、质量线索、镜头时机和摄像机选择之间的显式模块化连接。组件测量和完整编辑评估提供了该设计的互补视角。

3 系统概述与素材

该框架以四个同步摄像机流和音乐会音频作为输入。音频处理有两个互补分支：命名的乐器分轨提供活跃度和可听角色，而它们的单声道混合提供节拍和速度估计。视觉分支使用预训练的 D-FINE 目标检测器（保留 Objects365 中的乐器类别 [11, 14]）和用于表征清晰度的图像梯度统计。这些信号馈入摄像机效用，而时间分支定义评估视角的区间。图 1 给出了完整的处理流程。

4 摄像机评分与选择

系统将可听和可见乐器角色转换为每秒摄像机效用，与图像质量结合，并在每个候选镜头上进行聚合。选择模块在每个区间采样一个摄像机，同时防止摄像机立即重复。

4.1 局部效用

在整数秒 t，可听主/次标签与每个摄像机中的可见主/次标签进行匹配。设 R_c(t) 为这些匹配的总和，主—主、主—次、次—主和次—次匹配的奖励分别为 4、1、1 和 0.5。惩罚为

P_c(t) = 0.9|A_p(t)∖V_c(t)| + 0.5|A_s(t)∖V_c(t)| + 0.75|V_c(t)∖A(t)|, (1)

其中 A_p、A_s 是可听角色集合，A、V_c 是可听和摄像机可见联合。评分为

S_c(t) = round_2([4 + R_c(t) − P_c(t)]Q_c(t)). (2)

质量乘子 Q_c 对于完全模糊或识别的平移标签为零，否则为一；部分模糊不受惩罚。平移线索由标注驱动变体使用。

4.2 时机、区间效用与选择

时间模块将边界放置在每个第四个跟踪节拍上，并为慢速、中速或快速速度类别采样 10–15、6–10 或 3–6 秒的目标持续时间。这假设每小节四拍，不建立真正的强拍或音乐乐句。

对于预期区间，评分进行保守聚合。如果 S_c,(1) ≤ ⋯ ≤ S_c,(n) 是其整数区间评分，

q_c = max(0, (1/m)Σ_{j=1}^{m} S_c,(j)), m = max(1, ⌈0.10n⌉). (3)

对于最多十个区间，这相当于在零处截断的最小值。给定前一个摄像机 i，比例采样选择 j ≠ i，满足

p_j = q_j / Σ_{k≠i} q_k, p_i = 0, (4)

当分母为正时；否则回退在其他三个摄像机上均匀分布。因此，零分不是硬性否决。这是无重复约束而非编辑语法的序列模型。全区间评分和居中音频分析使用未来上下文；当前实现以离线方式运行。

5 组件性能

音频角色估计达到主角色 0.654 和次角色 0.601 的支持加权 F1 分数。性能因乐器而异，模糊分类强烈依赖于摄像机。这些差异影响相应线索如何指导摄像机选择。附录 B 报告了每类音频和模糊结果、采样定义、角色时间线和摄像机评分图。

6 专家评估

6.1 研究设计

比较了同一录制的四个编辑：V1 是专家指导下学生制作的人工参考；V2 使用随机摄像机选择和基于节拍的时机；V3 使用预测的摄像机评分；V4 使用标注驱动的评分。来自不同媒体领域的三位专家在不知道编辑方法的情况下评估了完整版本。

问卷要求提供整体发布/广播就绪等级以及切换时机、过渡、画面质量/清晰度和连贯性/美学印象的详细评分，以及自由文本评论。整体等级使用 1 = 优秀到 5 = 差。方向锚点的冲突使详细量表含义模糊，因此只有整体等级被方向性解释；详细响应在附录 E 中未反转地报告。附录 D 描述了问卷维度。

6.2 切换时机和镜头持续时间

四个编辑使用相同的音频。V1 包含 35 次内部摄像机切换；V2–V4 各包含 65 次。相应的自动切换边界最多相差一帧：V3 和 V4 完全重合，而 V2 早一帧。因此，自动变体具有基本相同的节奏，使其视角选择能够在相似的切换时机下进行比较。

剪辑包括开场公告、音乐和最终掌声。我们使用约 0–80 秒、80–460 秒和 460–467.7 秒的近似窗口。表 3 报告了完整剪辑和音乐窗口上显示片段的持续时间。跨越窗口边界的镜头被截断用于摘要，不计为额外的摄像机切换。附录 C 给出了定义和其他阶段摘要。

不同的节奏标准 E1/E2 认为 V2 的模式程式化或缺乏动机，而 E3 认为它连贯且富有动感。 E1/V2：切换、过渡评论；E2/V2：切换评论；E3/V2：切换评论
情境性观众价值 E1/E2 批评 V3 的观众选择；E3 也重视一些观众反应，同时拒绝无动机的视角。 E1/V3：备注；E2/V3：切换评论；E3/V3：切换和印象评论

反馈突出了技术可用图像与编辑有用时刻之间的区别。它还重视反应和乐队互动以及当前突出的乐器。对偶然观众视图的批评与对有动机反应的赞扬共存，因此评论不支持一般性地禁止观众视图。

7 讨论

7.1 将系统组件与编辑评估联系起来

评估涉及组件标签一致性、时间特征和完整序列的专家评估。自动变体共享基本相同的测量边界，而它们的整体等级和报告的视角选择不同。这将解释缩小到摄像机选择、线索内容和序列行为；它没有识别出单一因果组件。V4 对两位评分者的改善也不能隔离识别准确性，因为标注源、可用线索和潜在的随机抽取是一起变化的。

反馈明确了有用视角对这些评分者的意义：音乐动作的覆盖、可接受的构图和时刻，以及有动机的反应或乐队互动。这些标准跨越不同的架构接口。表 6 将报告的关注点与可以影响选择的操作以及可以测试的变化联系起来。反馈激发了每个链接；它并未表明命名的操作导致了特定镜头。

线索接口：V4 在参考角色之外添加平移/鼓掌标签。 V4 对两位评分者比 V3 有所改善，但没有超过 V2 的等级。 可以在线索对等条件下比较标签源，可选线索然后作为单独因素测试。

一个重要的例子是测量误差与操作影响之间的区别。CAM1 的部分/不模糊分歧产生了较差的分类指标，但两种状态都有 Q_c = 1。仅纠正该分歧因此使其评分保持不变。它本身无法解释观众视图的选择。相比之下，可听角色变化同时进入奖励和惩罚，完全模糊或识别的平移标签可以使每秒评分为零。即便如此，区间聚合、前一个摄像机和回退决定了评分变化是否到达显示的视图。附录 G 给出了用于研究这些效应的条件评分示例和控制比较。

目标还省略了评论所做的一些区分。相关乐器的大而清晰的视图不一定显示合适的动作，有价值的反应不一定描绘主奏乐器。添加更大的乐器奖励不会解决该表示问题。同时，观众的存在或非主奏音乐家本身都不固有地不合适：E3 的积极反应反馈支持情境评估而非一揽子惩罚。必须单独检查素材覆盖范围，因为选择无法创建不存在的特写。

7.3 建议的控制比较

一个有用的下一版本将为线索可用性和可靠性、候选资格格、音乐/情境相关性以及序列策略提供单独的接口。时间将接收显式的语音/表演/掌声状态。这种分解使得可以询问识别的属性是否准确、它是否按预期改变效用，以及由此产生的视图是否改善了相关的编辑判断。它还使分歧具有信息性：反应价值和节奏偏好可以按评分者报告，而不是隐藏在单一均值中。

比较 1：分离适用性和相关性。 在共同决策机会和其余输入不变的情况下，初始比较可以将独立标注的资格信息添加到现有选择器；单独的比较可以测试情境反应价值。结果将包括不合适视图暴露、音乐动作覆盖和成对序列偏好，资格例外引起的实际切换的任何变化将被明确报告。这将首先测试编辑标准，然后才引入来自新检测器的预测误差。动作感知和反应敏感目标在其他场景中有先例 [4, 5, 18]；它们对本次音乐会的价值仍有待测量。

比较 2：添加序列上下文。 控制比较将保持局部评分和时间固定，保留相同的无重复和回退规则，并比较有和没有一个预先指定的历史/转换项（例如最近显示的表演者或视角角色）的选择。可检查的规则将避免最初就需要更大的学习模型。时间上下文系统 [12, 2] 和学习的音乐会选择 [8, 6] 提供了后续比较模型。需要若干预先指定的实现和盲序列判断；仅参考决策一致性是不够的。

比较 3：使质量和回退在操作上显式化。 质量可以首先在开发材料上校准，每个摄像机有支持的类别，然后独立测试质量到效用的映射和回退策略。此比较将区分硬性资格约束和软性偏好。如果只有当前视图可用，保持它可能比强制切换更好；如果没有视图合格，该区间可以被标记或调用明确记录的例外。这种保持会改变实际切换和停留时间，因此共同决策机会并不意味着匹配的实际节奏。试点研究激发了这些测试，但没有从中确立改进。

阶段特定时间是补充性扩展。语音/内容边界应在公告期间评估，节拍/强拍或乐句线索应在音乐期间评估。其效果需要单独的时机比较。约 80 秒的公告和不同的节奏判断显示了为什么全剪辑等级和音乐窗口持续时间摘要回答的是不同的问题。在将预测标签更改为参考标签之前，一致的线索词汇也是必要的；平移/鼓掌扩展必须保持为独立因素。

7.4 研究范围

评估涵盖一场音乐会、一个摄像机布置、每个自动方法的一个实现和三位专家。因此，它表征的是此应用场景，而不是建立编辑策略的一般排名。需要更多的音乐会、重复的随机实现和更广泛的专家或观众研究来评估跨素材和偏好的迁移性。

8 结论

该框架在模块化编辑系统中结合了音频和视觉分析、显式摄像机评分、基于节拍的时机和概率选择。在有效匹配的自动时机下，预测驱动编辑从所有三位评分者那里获得了比可用随机编辑更不利的整体等级。标注驱动编辑对两位评分者比预测有所改善，但没有获得比随机选择更好的等级。该结果激发了选择目标和策略的进一步发展。

组件结果和专家反馈支持超越检测器准确性的研究议程。研究结果激发了将音乐相关性、合适时刻、构图和有动机反应作为不同因素进行测试；质量标签需要定义的操作效果，资格格、聚合和序列上下文应该可以独立测试。组件到评估的映射将评分规则与控制比较的具体方向联系起来。后续研究因此可以调查变化如何从标签传播到评分、选择的视图和完整编辑判断，同时保留有利和关键的观察。

A.1 节拍网格和目标镜头持续时间

命名的音频分轨混合形成计时波形，使用 librosa [10] 以其现有采样率作为单声道加载。如果 WAV 文件缺失，切割器从 CAM4 提取 48 kHz 立体声 PCM 波形，然后将其作为单声道加载。节拍跟踪器返回时间 ℬ = {b_0, b_1, …}。我们构建近似的小节网格 𝒟 = {b_0, b_4, b_8, …}。(A.1)

这假设每小节四拍，并使用第一个检测到的节拍作为相位参考。它不估计拍号或识别真正的强拍。切割器不包含节拍序列上的额外中值滤波器，也没有报告节拍或小节标注准确性。

局部速度在 30 秒窗口上估计，10 秒跳跃。在镜头开始 t，实现按时间顺序使用第一个重叠的速度窗口，当没有窗口覆盖 t 时使用中速回退。其速度类别和目标停留时间范围为

Δ ∼ 𝒰(a_f, b_f)，(a_f, b_f) = (10, 15) 秒（f < 90 BPM）；(6, 10) 秒（90 ≤ f < 130 BPM）；(3, 6) 秒（f ≥ 130 BPM）。 (A.2)

下一个边界是 t + Δ 处或之后的第一个网格点，

t' = min{d ∈ 𝒟 : d ≥ t + Δ}, (A.3)

如果没有这样的点剩余，则为剪辑结束。剪辑结束受音频持续时间和最大评分时间戳限制。公式 A.2 约束的是采样的目标，而非实际的镜头持续时间，后者在网格对齐后可能更长。节拍对齐因此提供的是一种时机约定，而不是乐句或戏剧性编排的已验证模型。

A.2 从音频分轨估计活跃度和角色

独立的分轨允许直接能量分析，而无需从复调混合中识别乐器。分轨身份由轨道名称提供。每个分轨以其原始采样率 f_s 加载，并用居中的 3 秒 RMS 帧和 1.5 秒跳跃进行分析。对于分轨 i 和帧 k，

r_i[k] = √((1/N)Σ_{n=0}^{N−1} x_i[kH + n − ⌊N/2⌋]²), N = round(3f_s), H = round(1.5f_s), (A.4)

在信号边界处零填充。居中的九帧移动平均产生 r̄_i[k]。其有效时间支持约为 3 + 8 × 1.5 = 15 秒。这种平滑可能掩盖短暂的进入并引入未来上下文，因此角色估计器也是离线程序。

归一化使用所有平滑分轨能量上的共享边界，L = perc_1({r̄i[k]}{i,k}) 和 U = perc_99({r̄i[k]}{i,k})，定义活跃度：

v_i[k] = clip_0,1. (A.5)

如果边界无效或 U ≤ L，实现使用 L = 0，U = 1。这些是全局边界，不是单个乐器的独立百分位数尺度。相对分轨电平因此仍然依赖于录音增益和麦克风串音。

当 v_max[k] = max_i v_i[k] 时，活跃分轨同时满足绝对和相对阈值：

A[k] = {i : v_i[k] ≥ 0.075 且 v_i[k] ≥ 0.35 v_max[k]}. (A.6)

对于非空活跃集，归一化能量份额为

α_i[k] = v_i[k]² / Σ_{j∈A[k]} v_j[k]². (A.7)

如果 α_i[k] ≥ 0.92 max_{j∈A[k]} α_j[k]，则该分轨为主角色；其他活跃分轨为次角色。多个主分轨是可能的。连续相等的角色合并为 1.5 秒网格上的区间。导出时将公告、长号、吉他、贝斯拾音和钢琴分轨映射到其语义标签，并将底鼓和军鼓分轨都映射到鼓。角色在此标签映射之前分配，因此导出的主和次集合对于分组乐器可能重叠。标签被截断到 480 秒。这些操作角色描述相对信号能量，不等同于感知层面的独奏者识别。

A.3 可见乐器和图像清晰度

视觉乐器检测使用预训练的 D-FINE-X Objects365 检测器 [11, 14]，置信度阈值 0.55。当检测到的乐器框覆盖超过帧面积的 20% 时，该乐器在视觉上为主角色。保留的类别为鼓、吉他、钢琴、大提琴和长号；大提琴作为特定应用的代理映射到贝斯。检测器未经微调使用。

在宽度 W 和高度 H_v 的帧中检测到的边界框 (x_1, y_1, x_2, y_2)，如果

(x_2 − x_1)(y_2 − y_1) / (WH_v) > 0.20; (A.8)

则在视觉上为主角色；否则为次角色。这是尺寸代理；它不评估遮挡、面部可见性、镜头美学或乐器是否正在演奏。检测器未在音乐会上进行微调，图 B.1 中的视觉时间线是示例而非定量检测精度测试。

对于模糊估计，帧使用 max(1, round(0.2 fps)) 的帧步长大约每 0.2 秒采样一次。输入分辨率的灰度帧用 5×5 高斯核（OpenCV 的自动 sigma 设置）平滑。核大小为 3 的 Sobel 导数产生 g_x 和 g_y [7]。清晰度统计量是像素上的总体标准差，

B_c(t) = std_{x,y}(√(g_x(x,y,t)² + g_y(x,y,t)²)). (A.9)

当 B_c < 20 时帧为完全模糊，20 ≤ B_c < 25 时为部分模糊，否则为不模糊。连续相同的标签合并为半开区间。由于统计量未做尺度归一化，阈值依赖于图像分辨率、纹理、曝光和视点。它们不应被解释为通用的对焦阈值。

A.4 基于角色匹配和惩罚的摄像机效用

设 A_p(t) 和 A_s(t) 为全局主和次可听标签集合，V_{c,p}(t) 和 V_{c,s}(t) 为摄像机 c 的相应可见集合。评分在整数秒处评估。区间标签在 s ≤ t < e 时存在。跨摄像机任务重复的相同音频区间被去重。评分解析器将语音和歌唱组合成标记 Speech/Singing；鼓掌标签（存在时）被视为主事件标签。

对于可听角色 r ∈ {p, s} 和标签 a，定义匹配贡献

M_{c,r}(a, t) = w_{r,p}（若 a ∈ V_{c,p}(t)）；w_{r,s}（若 a ∈ V_{c,s}(t)∖V_{c,p}(t)）；0（否则）， (A.10)

其中如果两个可见角色同时出现，可见主角色成员资格优先。匹配奖励为 R_c(t) = Σ_{r∈{p,s}} Σ_{a∈A_r(t)} M_{c,r}(a, t)。当 V_c = V_{c,p} ∪ V_{c,s} 且 A = A_p ∪ A_s 时，正惩罚幅度为

P_c(t) = 0.9|A_p(t)∖V_c(t)| + 0.5|A_s(t)∖V_c(t)| + 0.75|V_c(t)∖A(t)|. (A.11)

每秒评分为

S_c(t) = round_2([4 + R_c(t) − P_c(t)]Q_c(t)), (A.12)

角色权重和质量乘子见表 A.1。偏移量不保证非负评分；非负性在区间聚合处强制执行。部分模糊的素材在此配置中不受额外评分降低。完全模糊标签或识别的小写平移标签将评分设为零。预测驱动变体使用模糊和乐器角色估计；标注驱动变体还提供平移和鼓掌标签。

A.5 下尾区间聚合和摄像机采样

对于候选区间 [t, t')，代码使用从 ⌊t⌋ 到 ⌈t'⌉ − 1 的整数秒区间。这包括包含小数开始时间的区间。设 n 为它们的数量，S_{c,(1)} ≤ ⋯ ≤ S_{c,(n)} 表示排序后的评分。区间效用是最低 m 个样本的截断均值，

q_c([t, t')) = max(0, (1/m)Σ_{j=1}^{m} S_{c,(j)}), m = max(1, ⌈βn⌉), β = 0.10. (A.13)

缺失的评分区间为零。这种经验下尾平均值与下尾条件风险价值相关 [13]；上限约定是实现中的有限样本规则，而非精确的分数尾估计量。对于 n ≤ 10，它简化为在零处截断的最小评分。这使短暂失败具有较大影响力，可能拒绝原本有用的镜头；该聚合是保守选择，不是经过验证的编辑最优解。

当总和为正时定义 w_c = q_c/Σ_j q_j，否则 w_c = 1/4。给定前一个摄像机 i，实现形成

p̃j = T{ij} w_j, p_j = p̃j/Σ_k p̃_k, T{ij} = 0（i = j）；0.30（i ≠ j）。 (A.14)

当所有剩余权重消失时，回退在除 i 之外的三个摄像机上均匀分布。下一个摄像机从该分类分布中为整个区间抽取，并成为下一决策的前一个摄像机。初始前一摄像机状态为 CAM1，因此 CAM1 也从第一次抽取中排除。

非对角线值 0.30 是未归一化权重：最终归一化使其等效于 1/3。对于正的合格效用，公式 A.14 简化为 j ≠ i 时 p_j = q_j/Σ_{k≠i} q_k。因此，转换机制是一阶无重复约束，不是编辑语法的学习模型。调度方法可以使用更丰富的转换模型 [3]；此处未确立此类益处。此外，零效用不是无条件的镜头否决，因为全零回退仍可能选择不合适的视图。

语音和歌唱共享组合事件标签。时间模块在整个剪辑中应用相同策略；单独的公告策略是进一步发展的方向。

附录 G 评分敏感性和摄像机选择效应

一个示例说明可见性标签的变化如何影响摄像机评分和选择。所有其他标签和质量状态保持固定。对于一个仅为主角色的可听标签，将其可见性从两个可见角色集合中均不存在更改为视觉上主角色，会增加主—主奖励 4 并移除缺失主角色惩罚 0.9。因此，当 Q_c = 1 时，每秒评分增加 4.9；当 Q_c = 0 时，两个评分均为零。

下尾聚合和在零处截断可以使区间效用保持不变。无重复规则也排除前一个摄像机，无论其评分如何。对于合格摄像机，归一化依赖于其他合格视图的效用：如果它是唯一具有正效用的视图，即使效用增加，其概率仍保持为一。即使概率发生变化，分类采样也可能返回相同的摄像机。这些条件效应区分了标签变化、评分变化和摄像机选择；仅凭其中任何一个都不能确立编辑质量的改善。
