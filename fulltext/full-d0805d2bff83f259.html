TCS与Anthropic合作将Claude...

📅 2026-06-12 📄 Anthropic 🔗 原文链接

原标题：TCS and Anthropic partner to bring Claude to regulated industries

中文摘要： Anthropic宣布与全球最大技术服务公司之一TCS建立合作伙伴关系。TCS将向56个国家的5万名员工提供Claude，并为金融、医疗等受监管行业构建基于Claude的产品。作为“零号客户”，TCS将在内部团队应用Claude，并成立专门业务部门为客户设计系统。目前TCS多个业务线已开始使用Claude改善客户体验、提升软件工程生产力及提供培训认证。此次合作进一步深化了Anthropic对印度市场的承诺。

我们宣布与全球最大的技术服务公司之一 Tata Consultancy Services (TCS) 建立合作伙伴关系。TCS 将向其在 56 个国家的 5 万名员工提供 Claude；为金融服务、医疗保健、公共部门和其他受监管行业的客户构建基于 Claude 的产品；并加入 Claude Partner Network, 这是我们由咨询和服务公司组成的网络，旨在帮助将 Claude 引入其企业客户。

受监管行业需要其工作高度准确且可审计，这些领域的企业已经因此在使用 Claude。TCS 带来了数十年的经验，提供符合公司监管要求的技术，并拥有将 Claude 带给全球数千家企业的覆盖能力。

TCS 如何使用 Claude

作为“零号客户”，TCS 将把 Claude 应用于其自身的工程、财务、法务、市场和销售团队，并利用所学经验来塑造其向客户推广 Claude 的方式。它还在为这一合作伙伴关系建立一个专门的业务部门，汇集顾问、工程师和行业专家，为客户设计和运行基于 Claude 的系统。TCS 将把 Claude 打包成特定行业的产品，例如保险公司的理赔处理和银行的贷款咨询，其团队将为金融服务、公共服务、生命科学、医疗保健、航空、电信和医疗技术领域的客户实施并运行这些产品。

这项工作已经在进行中。例如：

  • Diligenta，TCS 的英国人寿和养老金业务，将使用 Claude 改善其服务的超过 2200 万投保人的客户体验。
  • TCS 的银行和金融服务产品团队将使用 Claude Code 提高软件工程和 IT 运营方面的生产力。
  • TCS 的工程团队将向 Claude Code 生态系统添加可重用的技能和插件，首先从专注于理赔裁定和贷款咨询的技能和插件开始。
  • TCS iON，每年在印度 1500 个城市进行超过 7500 万次评估，将提供 Claude 培训和认证。

“我们将 Claude 打造得安全、可信且有用，特别是在准确性至关重要的环境中，”Anthropic 联合创始人兼首席执行官 Dario Amodei 说。“这种伙伴关系加深了我们对印度这个第二大市场的承诺，TCS 将把 Claude 带给该地区和全球的企业和专业人士。”

要了解有关 Claude Partner Network 的更多信息，请访问 anthropic.com/partners。
