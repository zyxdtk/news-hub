摘要

太空经济的快速增长，加之轨道拥挤与碎片日益增多，正在推动对大型和非合作物体可靠在轨运输的需求。使用小航天器集群执行此类运输可分散风险，并消除单体架构固有的单点故障，但需要求解一个将每个智能体的锥约束推力与载荷旋转动力学耦合在一起的非凸轨迹优化问题。现有方法包括具有渐近保证但约束执行能力有限的分布式控制律，以及重新引入单点故障的集中式和部分集中式规划器。在本工作中，我们提出了一个由精确梯度驱动的分布式双层框架：问题被分解为内层凸推力分配和外层载荷力矩轨迹搜索。这种分解能够快速产生燃料高效的解，无需完整的 NLP 收敛，且在短时间尺度上其性能随智能体数量扩展。我们建立了理论收敛保证，并通过大量蒙特卡洛仿真验证了该方法，包括飞行中故障的闭环恢复。这些特性使该框架非常适合航天器集群应用。

I 引言

太空经济的快速增长显著增加了对可靠、高效的在轨运输解决方案的需求，以支持商业和科学应用。与此同时，日益严重的轨道拥挤和大型碎片的扩散对可持续太空运营构成越来越大的风险。应对这些挑战需要能够安全、高效地改变非合作物体轨道的运输技术，而这些物体的翻滚运动以及服务航天器的有限推力已经使即使是近距操作也变得十分困难 [1]。

单体任务架构（由单个航天器执行整个机动）成本高昂、易发风险且缺乏冗余。多智能体架构提供了一种有前景的替代方案，将风险分散到多个航天器上，从而通过协调行动提高鲁棒性和操作灵活性。

虽然多智能体协同物体运输在地面和空中领域已被广泛研究 [2,3,4,5]，包括用于多机器人载荷运输的基于分布式学习 [6] 和模型预测 [7] 的控制器，但其在轨道环境中的应用相对有限。值得注意的方法包括分布式 PD 控制 [8]、基于遮挡的启发式方法 [9]、空间机械臂的反步控制 [10]，以及通过设计力矩控制律实现翻滚目标的协同多卫星消旋 [11]。还提出了基于编队的方法，如 Meng 等人 [12] 的工作，将协同运输重新表述为编队跟踪问题。然而，这些方法通常只提供渐近保证，约束执行能力有限，且很少关注燃料效率或收敛时间——而这些因素对实时轨道操作至关重要。

部分集中式架构已被探索用于轨道协同运输任务。特别是，具有集中规划和分布式执行的母舰式系统已被提议用于小行星探索 [13]、望远镜组装 [14] 和轨道碎片减缓 [15] 等任务。最近，有研究在人在回路速度命令下演示了通过推进式追踪航天器对被动自由飞行器的协同运输，其稳定性和安全性由屏障条件强制执行，推力由集中式混合整数规划分配 [16]。这些架构虽然在许多场景中有效，但将规划或分配集中在单个节点，因此仍然容易受到可能危及整个任务成功的单点故障的影响。

完全分布式架构通过在智能体之间分散计算和决策来消除这种脆弱性，并且随着太空运营规模的扩大，越来越被视为必不可少 [17,18]。成熟的分布式控制体系提供了具有力分配和故障响应的分布式运输 [12]，以及执行器损失下的容错编队飞行 [19,20,21]。然而，这些方法保证渐近跟踪或同步，仅近似处理推力方向锥和终端边界条件，且不优化任何任务目标（如燃料）。最接近的分布式优化器 [22] 使用对偶性处理自由飞行器之间的碰撞约束，而非通过共享载荷耦合的目标。因此，具有硬约束满足能力的分布式轨迹优化仍然是一个开放问题。

本文研究了涉及一个刚体和 N 个航天器智能体的协同轨道运输问题，这些智能体必须协作将物体从初始状态机动到期望的最终状态，同时最小化总燃料消耗。每个智能体固定安装在载荷表面的固定位置，并可在受限的角度范围内施加推力。

约束优化框架非常适合该问题，因为它能自然地纳入相对轨道动力学、姿态动力学、执行约束和轨迹边界条件。基于优化的规划已通过序列凸规划 [23]、可达集碰撞约束 [24] 以及动态通信拓扑上的分层规划 [25] 应用于航天器集群，但这些工作均采用集中式或分层设置，且针对自由飞行的智能体，而非通过共享载荷刚性耦合的智能体。然而，由于智能体的控制输入与刚体旋转动力学之间的耦合，该问题本质上是非凸的。先前的工作 [26] 采用集中式双层优化方法应对这一挑战，其中整个问题被分解为内层凸问题（在给定力矩分布下求解最优控制输入轨迹）和外层非凸优化问题（使用基于种群的启发式方法优化力矩轨迹）。由于采用集中式方法，该方法仍然容易受到单点故障的影响。

在本文中，我们将先前的方法扩展到分布式环境，利用多智能体架构从而消除单点故障。我们没有将外层力矩搜索视为纯粹的启发式问题，而是观察到内层凸问题的最优值关于力矩轨迹是可微的，并且一旦内层求解器收敛，其精确梯度可以以相对较低的计算代价获得。外层问题随后通过带随机重启的投影梯度下降求解，而分布式由此获得了明确的作用：每个智能体从自己的随机种子运行独立的重启流，因此由 N 个智能体组成的集群在单位墙钟时间内可抽取 N 倍的重启次数，从而能够到达单个节点会错过的吸引域；同时在视线通信图上进行单轮最大共识即可将集群范围内的最佳轨迹传递给每个智能体。同样的分布式搜索被嵌入到闭环恢复模式中，该模式可检测飞行中的执行和通信故障、对载荷进行消旋、识别并移除故障智能体，并与幸存者一起重新规划。

本文的主要贡献为：

  1. 一种用于文献 [26] 中引入的双层公式外层问题的一阶方法，利用内层最优值的精确包络定理梯度；
  2. 一种解的质量随智能体数量提升的分布式多起点架构；
  3. 由架构的分布式特性所实现的闭环故障恢复模式。

本文其余部分组织如下。第 II 节描述所研究的问题、其双层重构以及二者的等价性。第 III 节介绍所提出的方法并建立其收敛保证。第 IV 节通过蒙特卡洛测试评估该方法，在锥半角、计算预算和集群规模上与基于采样的方法和直接 NLP 基线进行比较，包括闭环故障生存性统计；第 V 节报告结果。第 VI 节讨论意义与未来工作。

II 问题表述

II-A 状态、输入与系统动力学

系统在 Hill 坐标系中表述，这是一个以参考主星轨道为中心的相对轨道坐标系。载荷刚体状态为

𝒙_p(t) = col{𝒓(t), 𝒗(t), ϕ(t), 𝝎(t)} ∈ ℝ^9 × 𝔰𝔬(3),　(1)

其中 𝒓, 𝒗 ∈ ℝ^3 为相对位置和速度，ϕ ∈ ℝ^3 为在李代数 𝔰𝔬(3) 上参数化姿态的旋转向量，𝝎 ∈ ℝ^3 为角速度。姿态以旋转矩阵 R ∈ SO(3) 的形式携带，并通过指数映射更新以消除范数漂移。每个智能体 i ∈ {1, …, N} 刚性安装于体坐标系附着点 𝒒_i^ℬ ∈ ℝ^3；Hill 坐标系下的附着向量为 𝒒_i(t) = R(t)𝒒_i^ℬ。完整状态为

𝒙(t) = col{𝒙_p(t), 𝒒_1(t), …, 𝒒_N(t)} ∈ ℝ^(9+3N) × SO(3),　(2)

堆叠控制输入为 𝒖(t) = col{𝒖_1(t), …, 𝒖_N(t)} ∈ ℝ^(3N)，其中 𝒖_i ∈ ℝ^3 为智能体 i 的推力向量。

连续时间动力学为

𝒙̇(t) = 𝐀(𝝎, t)𝒙(t) + 𝐁(𝒒_1:N)𝒖(t),　(3)

其中 𝐀 包含线性化相对轨道动力学（适用于偏心参考轨道的时变 Tschauner–Hempel 方程）和欧拉旋转方程，𝐁 通过斜对称算子 [·]× 将单个推力向量映射为平移加速度和体力矩。步长为 Δ 的离散时间更新为

[𝒓_{k+1}; 𝒗_{k+1}] = [𝒓_k; 𝒗_k] + Δ(𝚿(t_k)[𝒓_k; 𝒗_k] + (1/m)[𝟎; 𝐈_3] Σ_{i=1}^N 𝒖_{i,k}),　(4a)
R_{k+1} = R_k · exp(Δ[𝝎_k]×), R_0 = exp([ϕ_0]×),　(4b)
𝝎_{k+1} = 𝝎_k + Δ(−𝐉^−1[𝐉𝝎_k]×𝝎_k + 𝐉^−1𝝉_k),　(4c)
𝒒_{i,k} = R_k 𝒒_i^ℬ, ∀i.　(4d)

方程 (4a)–(4d) 定义了离散时间映射 𝒙_{k+1} = f_d(𝒙_k, 𝒖_k)。方程 (4b) 直接在 SO(3) 上传播姿态，旋转向量通过 ϕ_k = log(R_k)∨ 恢复；边界姿态以旋转向量 ϕ_a, ϕ_b ∈ 𝔰𝔬(3) 给定。惯量张量 𝐉 被视为常数，因为载荷质量远大于智能体质量。

II-B 最优控制问题

每个智能体被约束在以向内附着方向 −𝒒_{i,k} 为中心、半角为 ν 的锥内推力，从而使推力压向载荷而排气羽流指向远离载荷的方向。设 𝐔 = {𝒖_{i,k}} ∈ ℝ^(3NT) 表示完整推力序列。所研究的问题是找到最小燃料推力序列

argmin_𝐔 J(𝐔) = Σ_{i=1}^N Σ_{k=0}^{T−1} ‖𝒖_{i,k}‖　(5a)
s.t. 𝒙_{k+1} = f_d(𝒙_k, 𝒖_k),　(5b)
−𝒖_{i,k}^⊤𝒒_{i,k} / (‖𝒖_{i,k}‖‖𝒒_{i,k}‖) ≥ cos ν, ∀i, k,　(5c)
𝒙_0 = 𝒂, 𝒙_T = 𝒃.　(5d)

由于非线性姿态动力学和推力锥约束 (5c)，问题 (5) 是非凸的。

II-C 双层重构

控制输入通过分离净力与净力矩进行分解：

𝐁𝒖(t) = 𝐁̃ [Σ_{i=1}^N 𝒖_i(t); 𝝉(t)], 𝝉(t) = Σ_{i=1}^N [𝒒_i(t)]× 𝒖_i(t),　(6)

其中 𝐁̃ 将净力映射为平移加速度，净力矩经 𝐉^−1 映射为角加速度。一旦初始条件和力矩轨迹 𝝉_{0:T−1} 固定，方程 (4b)–(4d) 便可独立于平移状态传播所有旋转量 {R_k, 𝝎_k, 𝒒_{i,k}}。随后对 𝐔 和 {𝒓_k, 𝒗_k} 的剩余优化是凸的。这启发了如下双层分解：

内层凸问题。 给定固定的 𝝉_{0:T−1}：

argmin_𝐔 Σ_i Σ_k ‖𝒖_{i,k}‖　(7a)
s.t. 平移动力学 (4a),　(7b)
𝝉_k = Σ_i [𝒒_{i,k}]× 𝒖_{i,k},　(7c)
−𝒖_{i,k}^⊤𝒒_{i,k} / (‖𝒖_{i,k}‖‖𝒒_{i,k}‖) ≥ cos ν,　(7d)
𝒓_0 = 𝒓_a, 𝒓_T = 𝒓_b, 𝒗_0 = 𝒗_a, 𝒗_T = 𝒗_b.　(7e)

力矩轨迹仅通过约束 (7c) 进入该问题。其解 ξ(𝝉_{0:T−1}) ∈ ℝ^(3NT) 是与给定力矩轨迹一致的最小燃料推力序列。

外层搜索问题。 求最小化内层代价的力矩轨迹：

argmin_{𝝉_{0:T−1}} L(𝝉_{0:T−1}) = J(ξ(𝝉_{0:T−1}))　(8a)
s.t. R_{k+1} = R_k · exp(Δ[𝝎_k]×),　(8b)
𝝎_{k+1} = 𝝎_k + Δ(−𝐉^−1[𝐉𝝎_k]×𝝎_k + 𝐉^−1𝝉_k),　(8c)
R_0 = exp([ϕ_a]×), R_T = exp([ϕ_b]×),　(8d)
𝝎_0 = 𝝎_a, 𝝎_T = 𝝎_b.　(8e)

II-D 双层重构的等价性

我们现在证明双层重构与原问题 (5) 达到相同的最优值。设 ℱ 表示 (5) 的可行集，即满足 (5b)–(5d) 的所有推力序列，并设 J* ≜ min_{𝐔∈ℱ} J(𝐔) 为其最优值。定义控制序列 𝐔 的诱导力矩轨迹为

𝝉_k(𝐔) ≜ Σ_{i=1}^N [𝒒_{i,k}]× 𝒖_{i,k}, k = 0, …, T−1,　(9)

并将满足旋转边界条件的可采纳力矩轨迹集合定义为

𝒯 ≜ {𝝉_{0:T−1} : ϕ_0 = ϕ_a, ϕ_T = ϕ_b, 𝝎_0 = 𝝎_a, 𝝎_T = 𝝎_b},　(10)

其中边界值是在 𝝉_{0:T−1} 下传播 (4b)–(4c) 之后评估的。对每个 𝝉 ∈ 𝒯，内层可行集为

𝒰(𝝉) ≜ {𝐔 : 平移动力学 (4a), 𝝉_k = Σ_i [𝒒_{i,k}]× 𝒖_{i,k} ∀k, −𝒖_{i,k}^⊤𝒒_{i,k}/(‖𝒖_{i,k}‖‖𝒒_{i,k}‖) ≥ cos ν ∀i,k, 𝒓_0 = 𝒓_a, 𝒓_T = 𝒓_b, 𝒗_0 = 𝒗_a, 𝒗_T = 𝒗_b}.　(11)

于是 (8a) 的外层目标即为内层问题的值函数，双层最优值为

L(𝝉) = min_{𝐔∈𝒰(𝝉)} J(𝐔), J̃* ≜ min_{𝝉∈𝒯} L(𝝉).　(12)

断言： J̃ = J。

证明（J̃ ≤ J）。 设 𝐔 ∈ ℱ 为 (5) 的任意可行解，令 𝝉 = 𝝉(𝐔)。由于 𝐔 满足 (5) 的完整动力学，诱导力矩轨迹满足所有旋转边界条件，故 𝝉 ∈ 𝒯。根据构造，𝐔 也满足 𝒰(𝝉) 中的所有约束，因此 𝐔 ∈ 𝒰(𝝉) 且 L(𝝉) ≤ J(𝐔)。对所有 𝐔 ∈ ℱ 取最小值：

J̃ = min_{𝝉∈𝒯} L(𝝉) ≤ J.　(13)

证明（J ≤ J̃）。 设 𝝉 ∈ 𝒯 且 𝐔 ∈ 𝒰(𝝉)。由于 𝝉 ∈ 𝒯，传播 (4b)–(4c) 得到的旋转轨迹满足 ϕ_0 = ϕ_a、ϕ_T = ϕ_b、𝝎_0 = 𝝎_a、𝝎_T = 𝝎_b。由于 𝐔 ∈ 𝒰(𝝉)，平移边界条件成立，锥约束得到满足，且力矩一致性 𝝉_k = Σ_i [𝒒_{i,k}]× 𝒖_{i,k} 在每一步均成立。综合而言，(𝐔, 𝝉) 满足 (5) 的所有约束，因此 𝐔 ∈ ℱ 且 J* ≤ J(𝐔)。先对 𝐔 ∈ 𝒰(𝝉) 取最小值，再对 𝝉 ∈ 𝒯 取最小值：

J ≤ min_{𝝉∈𝒯} L(𝝉) = J̃.　(14)

结合两个方向即得 J = J̃。此外，(5) 的任意优化器 𝐔 会诱导外层优化器 𝝉 = 𝝉(𝐔)；反之，任意外层优化器 𝝉 与其内层最小化器 𝐔 ∈ argmin_{𝐔∈𝒰(𝝉)} J(𝐔) 配对即为 (5) 的优化器。

注 1（主图）。 旋转向量参数化 ϕ = log(R)∨ 在其主图 ‖ϕ‖ ≤ π 上使用。上述等价性是在 SO(3) 上陈述的，不受此选择影响，但第 III 节的搜索算子在主图上参数化边界姿态，因此只探索旋转的主同伦类：以“绕远路”方式到达终端姿态的候选轨迹在 𝒯 中是可采纳的，但不会被所实现的投影生成。因此，关于所实现方法的所有最优性陈述均是针对 𝒯 的这一可达子集做出的。

III 所提出的方法

外层问题 (8) 是非凸的，但并非毫无结构：其目标 L(𝝉) 是一个数据平滑依赖于 𝝉 的凸规划的最优值。我们利用这一点，沿包络定理给出的 L 的精确梯度下降，并通过随机重启处理 L 的多峰性。分布式由此具有明确的功能：N 个智能体并行运行 N 个独立的重启流，并通过最大共识就最佳结果达成一致。算法 1 概括了每个智能体执行的循环。图 2 概括了完整架构，包括第 III-G 节的闭环恢复路径。

图 2：方法概述。 从共享的初始轨迹猜测出发，每个智能体运行独立的双层梯度下降孤岛（第 III-A–III-D 节）；一轮最大共识选出最低代价的轨迹（第 III-F 节），由集群执行。检测到的偏差触发第 III-G 节的恢复回路：消旋、隔离故障智能体，并从当前状态与幸存者一起重新规划。

III-A 内层值的包络定理梯度

将内层问题 (7) 写为一般形式

L(𝝉) = min_𝐔 J(𝐔) s.t. 𝒈(𝐔; 𝝉) = 𝟎, 𝒉(𝐔; 𝝉) ≤ 𝟎,　(15)

力矩轨迹通过两条通道进入约束函数：直接通过力矩分配等式 (7c)；间接通过传播姿态递归 (4b)–(4c) 得到的旋转矩阵 R_k(𝝉)，这些矩阵出现在分配等式和锥约束的附着向量 𝒒_{i,k} = R_k(𝝉)𝒒_i^ℬ 中。设

ℒ(𝐔, 𝝀, 𝝁; 𝝉) = J(𝐔) + 𝝀^⊤𝒈 + 𝝁^⊤𝒉

表示拉格朗日函数，并设 (𝐔, 𝝀, 𝝁) 为 (15) 的原-对偶解。在标准正则性条件（𝐔 处的 LICQ 与严格互补性）下，值函数可微，包络定理 [27] 给出

∇_𝝉 L(𝝉) = ∇_𝝉 ℒ(𝐔, 𝝀, 𝝁*; 𝝉).　(16)

不需要最小化器的敏感性 ∂𝐔*/∂𝝉：只需在收敛点处拉格朗日函数的偏导数。特别地，不执行穿过求解器 KKT 系统的隐式微分。由于 𝝉 ∈ ℝ^(3T)，梯度 (16) 的维数为 3T：其规模及求取代价随时间步数缩放，而与智能体数量无关。

在实现中，内层问题被精确求解为二阶锥规划（SOCP）：燃料目标以上图形式进入，即 ‖𝒖_{i,k}‖ ≤ t_{i,k}，线性目标为 Σ_{i,k} t_{i,k}；推力锥 (7d) 是精确的二阶锥约束；平移动力学是线性的；旋转矩阵 R_k(𝝉) 作为数值数据进入，由当前 𝝉 下展开姿态递归得到。加入了一个小的二次正则化项 ϵ_r Σ_{i,k} ‖𝒖_{i,k}‖²（ϵ_r = 10^−3），因为纯燃料目标可能使分配不唯一——若干总燃料相同的分配可以实现同一力矩，这会使对偶变量不稳定；正则化项可选出唯一的最小化器。SOCP 在 CVXPY [28] 中建模，并由内点锥求解器 Clarabel [29] 求解至认证最优性。

梯度 (16) 由上述两条通道组装而成。直接通道穿过力矩分配等式 (7c)，可从求解器中零代价读出：拉格朗日函数对 𝝉_k 的偏导数即相应等式乘子的负值。间接通道穿过出现在附着向量中的旋转矩阵 R_k(𝝉)，通过使用 SO(3) 指数映射的右雅可比矩阵对姿态递归 (4b)–(4c) 进行一次反向伴随传递来评估。该传递长度为 T，代价与 N 无关。姿态伴随在光滑代理值函数上对照算法微分验证至 10^−7 的相对精度，组装后的梯度对照 SOCP 值的中心有限差分验证至 10^−3 的相对方向精度——后者是锥求解器容差所设定的噪声下限。

III-B 可行性投影

候选力矩轨迹并不保证满足旋转边界条件 (8d)–(8e)。每个候选 𝝉_{0:T−1} 通过求解如下问题被投影到可行集上：

min_{𝝉̂{0:T−1}} Σ{k=0}^{T−1} ‖𝝉̂_k − 𝝉_k‖² s.t. (8b), (8c),　(17a)
ϕ_0 = ϕ_a, ϕ_T = ϕ_b,　(17b)
𝝎_0 = 𝝎_a, 𝝎_T = 𝝎_b.　(17c)

尽管 (17) 是非凸的，但其维数较小，可通过从 𝝉_{0:T−1} 热启动的多重打靶 NLP 快速求解，从而确保外层搜索评估的每个候选在旋转意义上可行。当投影 NLP 未能收敛时（随着锥半角 ν 变小，这种情况发生得越来越频繁），该候选被直接拒绝而不做未投影评估；这对可达搜索空间的影响在第 III-E 节中明确说明。

III-C 投影梯度下降

由于外层可行集 𝒯（旋转边界条件）由投影 (17) 而非解析方式强制执行，该下降是在复合映射 L∘Π 上的投影梯度方法，其中 Π 表示投影；与投影梯度方案的标准做法一致，投影的导数被忽略。每次迭代沿归一化梯度迈出试验步长并重新投影：

𝝉⁺ = Π(𝝉 − α ∇_𝝉L(𝝉) / ‖∇_𝝉L(𝝉)‖).　(18)

步长由真实目标上的回溯线搜索管理（每次试验需要一次投影和一次内层求解）：初始步长相对于力矩尺度选取，α_0 = η·RMS(𝝉)·√(3T)，其中 η = 0.03，使第一次移动将轨迹位移约其均方根幅值的 3%；成功的步长将 α 增大 1.5 倍，失败的步长将其缩小 0.5 倍；当不存在超过最小相对长度的改进步时，下降宣告达到一阶平稳性。相对缩放对于力矩幅值跨越若干数量级的场景间的迁移至关重要。

III-D 随机重启与分布式多起点

值函数 L 一般是多峰的；经验上，相互分离的吸引域数量随锥半角 ν 收紧而增长。因此单次下降只能证明一个局部最小值。达到平稳性后，方法从随机冷力矩轨迹重启：

𝝉_0^(j) ~ 𝒩(𝟎, s²𝐈_{3T}), s = c·RMS(𝝉_best),　(19)

其中 c = 1，并保留所有重启中找到的最佳对 (𝝉, L)。第一次下降改为从多重打靶标称值热启动，这能可靠地落入良好的吸引域；注意，重新求解打靶问题并不构成重启，因为其结果是确定性的，因此真正的探索需要 (19) 的冷抽取。

在分布式变体中，每个智能体 i ∈ {1, …, N} 是一个独立的“孤岛”，在自身的墙钟时间预算内执行相同的带重启下降循环。孤岛 1 从打靶标称值热启动；孤岛 2, …, N 从具有各自孤岛种子的独立随机抽取 (19) 初始化，所有孤岛在预算允许范围内继续各自的随机重启。搜索期间不发生任何通信。因此，集群在单位每智能体墙钟时间内评估 N 条重启流。

1: 输入：边界条件 (𝒂, 𝒃)；种子 s_i；每智能体预算 t_max
2: (𝝉_i, L_i) ← (∅, +∞)
3: 若 i = 1，𝝉_0 ← shooting_nominal()；否则按 (19) 抽取（第 III-D 节）
4: 当 wall_clock() ＜ t_max：
5: 　𝝉 ← 按 (17) 计算 Π(𝝉_0)（第 III-B 节）
6: 　若 𝝉 = ∅：𝝉_0 ← 按 (19) 抽取；继续

8: 　当 未达平稳 且 wall_clock() ＜ t_max：

III-E 随机多起点的收敛性

设 D 表示 ℝ^(3T) 上的重启分布 (19)，设 A: ℝ^(3T) → 𝒯 ∪ {∅} 为将抽取 𝝉_0 映射到第 III-C 节投影下降所返回平稳点的确定性映射，当投影失败时 A(𝝉_0) = ∅。定义诱导代价 𝒞(𝝉_0) = L(A(𝝉_0))，失败时 𝒞 = +∞，以及本质下确界

L‡ ≜ inf{y ∈ ℝ : ℙ_D(𝒞(𝝉_0) ≤ y) ＞ 0}.　(20)

定理 1（几乎必然收敛）。 设 𝝉_0^(1), 𝝉_0^(2), … 为来自 D 的独立同分布抽取，并设 M_n = min_{j≤n} 𝒞(𝝉_0^(j))。则当 n → ∞ 时，M_n → L‡ 几乎必然成立。

证明。 由 L‡ 的定义，ℙ(𝒞 ＜ L‡) = 0，因此几乎必然地每个 𝒞(𝝉_0^(j)) ≥ L‡，从而对所有 n 有 M_n ≥ L‡。对任意 ϵ ＞ 0，p_ϵ ≜ ℙ(𝒞 ≤ L‡ + ϵ) ＞ 0，且事件 {𝒞(𝝉_0^(j)) ≤ L‡ + ϵ} 相互独立并具有共同概率 p_ϵ；由第二 Borel–Cantelli 引理，其中之一几乎必然发生，故 limsup_n M_n ≤ L‡ + ϵ 几乎必然成立。由于 M_n 单调不增且 ϵ 任意，M_n → L‡ 几乎必然成立。∎

注 2（极限是什么，又不是什么）。 L‡ 是 V 在复合算子可达集上的全局最优值，即在投影所接受的初始化下投影下降能够到达的平稳点之上。若 V 在主图上全局最小化器的吸引域具有正的 D 测度，且投影在其中以正概率成功，则 L‡ 与该全局最优值一致。经验上，投影从冷抽取的接受概率随 ν 变小而衰减，在 ν ≈ 2.5° 以下，某些场景中该概率可能消失，从而缩小可达集。该方法收敛到其投影所能到达的最佳解，而非无条件地收敛到 (8) 的全局最优值。

注 3（分布式加速）。 当 N 个孤岛从 D 独立抽取时，前 n 次重启在 ⌈n/N⌉ 轮每智能体墙钟时间内完成，因此定理 1 沿集群的聚合序列成立，且经过时间缩短 N 倍。热启动的孤岛还额外保证集群永远不会比确定性单起点基线更差。

III-F 共识轮

搜索预算耗尽后，集群通过对 (1/L_i, i) 进行单轮最大共识就最佳解达成一致，其中 L_i 为孤岛 i 的最佳代价：在每次同步迭代中，每个智能体将其二元组替换为自身与其在视线通信图 𝒢 中邻居之间（按第一坐标）的最大值。所有起点均失败的孤岛携带适应度 0，不可能获胜。只要 𝒢 连通，所有智能体至多在 diam(𝒢) 次迭代后持有全局获胜者；获胜智能体沿同一棵树广播其力矩轨迹，每个智能体通过最后一次内层求解 (7) 恢复自己的推力序列。全文假设 𝒢 连通。

III-G 闭环故障恢复

分布式规划器被嵌入用于应对飞行中故障的闭环架构。每个智能体在跟踪规划推力序列的同时监控两个触发器：轨迹偏差监控器和带超时的每智能体通信心跳，且在异构通信延迟下工作。当触发器被触发时，集群执行三阶段恢复： 消旋，一个锥投影比例-微分制动阶段，使载荷静止，从而使重新规划从明确定义的边界条件出发； 识别，将无响应或行为异常的智能体标记并从活动集中移除； 重新规划，幸存智能体从当前状态到原始终端条件运行第 III-D 节的分布式多起点，随后进行共识轮。若幸存者的附着几何不再张成所需的力旋量空间，则重新规划问题不可行。此时规划器明确报告失败而非返回无法实现的计划，该事件被计为生存性失败。

IV 数值实验

IV-A 基线方法

所提方法与两种基于采样的外层搜索和一种直接联合 NLP 进行比较。所有基线共享第 II-C 节的双层结构：相同的内层求解器、相同的可行性投影 (17) 以及相同的多重打靶热启动，因此该比较隔离了外层搜索策略的影响。

IV-A1 遗传算法（GA）

对 P 个扁平化的力矩轨迹 𝝉 ∈ ℝ^(3T) 组成的种群进行进化，采用两点交叉、固定比例变异和带精英保留的稳态选择。每个候选在评估前经 (17) 投影，适应度为内层代价的倒数。GA 使用 PyGAD [30] 实现。

IV-A2 模型预测路径积分（C-MPPI / D-MPPI）

路径积分搜索 [31] 用 S 个高斯样本 𝜺^(s) ~ 𝒩(𝟎, σ²𝐈) 扰动标称轨迹，投影每个候选 𝝉̂^(s) = Π(𝝉^(t) + 𝜺^(s))，用内层求解器评分，并将标称向投影后候选的加权均值更新：

𝝉^(t+1) = 𝝉^(t) + γ(Σ_{s=1}^S (w^(s)/Σ_j w^(j)) 𝝉̂^(s) − 𝝉^(t)),　(21)
w^(s) = exp(−(J^(s) − J_min)/λ),

其中温度 λ ＞ 0，步长 γ ∈ (0,1]。对投影后候选而非原始扰动进行加权，可使更新目标保持在实际被评估的点集内；若使用原始扰动，评分与更新将在不同点上计算，从而损害收敛。扰动尺度相对于标称的均方根幅值设定，与第 III-C 节一致。失败的内层求解携带代价 +∞ 和零权重，并保留有史以来最佳的投影候选。分布式变体从独立种子为每个智能体运行一个 MPPI 孤岛，随后进行共识轮。

IV-A3 直接 NLP

原问题 (5) 亦直接作为 (𝐔, 𝒙_{0:T}) 上的单一联合 NLP 求解，采用与双层流程相同的 Tschauner–Hempel 平移动力学、体坐标系推力和李群姿态运动学，并从多重打靶标称值冷启动。

IV-B 实验设计

场景通过从任务代表性范围内的均匀分布中采样轨道参数、载荷属性、终端边界条件、智能体数量和附着向量进行随机化（半长轴 1.1–1.3 R⊕，偏心率至 0.30，载荷质量和主惯量矩至 5000（SI 单位），3–10 个智能体，终端状态在位置和 SO(3) 上均匀采样）。载荷初始静止且无旋转，须到达采样的终端位置和姿态并静止。每次求解器调用记录两个指标：总燃料 J = Σ_{i,k} ‖𝒖_{i,k}‖ 和终端状态违反量

𝐕 = ‖𝒓_T − 𝒓_b‖ + ‖𝒗_T − 𝒗_b‖ + ‖log(R_T^⊤R_b)‖ + ‖𝝎_T − 𝝎_b‖,　(22)

其中姿态项为 SO(3) 上的测地距离。每个返回的控制序列都在独立的积分器中重新仿真，所报告的燃料和违反量均来自该重新仿真结果，而非求解器自身的声明。当重新仿真满足 𝐕 ＜ 10^−3 时，该次运行记为成功。分布式方法遵循每智能体预算约定。每个孤岛获得完整的墙钟时间预算，以反映每个智能体均为独立计算机的硬件条件；仿真中孤岛被串行执行。

基线网格在锥半角 ν ∈ {1°, 2°, 2.5°, 5°, 15°, 60°} 与每智能体计算预算 {10, 30, 60, 300, 600} 秒的每个组合上，对六种方法（集中式与分布式 GD 和 MPPI、集中式 GA 以及 NLP）各进行 500 次随机化试验，计算预算作为每次求解器调用的硬性 CPU 时间上限；剔除重复的场景抽取后，所有统计量均按每个角度 472 个唯一场景计算。同一数据支持分布式分析，其中每个分布式方法逐场景与其集中式对应方法成对比较。可扩展性研究在第 III-G 节的闭环架构上进行，集群规模 N ∈ {4, 11, 18, 25}，分两种条件：开环（不注入故障）和闭环（随机智能体掉线故障），记录代价、终端违反量、恢复周期、被移除的智能体数以及定义故障生存性统计的重新规划可行性状态。

V-A 基线比较

图 3 报告了可靠性。梯度下降方法与采样基线在每个预算下都占据远高于联合 NLP 的区间。在所有角度上汇总，随着每智能体预算从 10 秒增至 600 秒，D-GD 在 77.6–79.8% 的场景上成功，C-GD 为 77.0–79.2%，采样方法稳定处于 76–79%，而 NLP 从 19.8% 攀升至 50.1%。差距随计算时间延长而缩小但仍然很大：在 10 秒时，NLP 求解的场景数仅为 D-GD 的四分之一；在 600 秒时，仍落后 30 个百分点。600 秒下的角度扫描显示在每个锥宽度上均有同样的差距。NLP 在 ν ≤ 15° 时达到 41–46%，即使在宽松的 ν = 60° 时也仅为 82%；相比之下 D-GD 为 69–87% 和 100%，在每个角度单元格中匹配或超越所有基线，并在 30 秒及以上的每个预算下取得最高成功率（表 I）。NLP 在短预算下的主要失败模式是截断——CPU 上限在联合求解下降途中将其打断，返回的迭代点经重新仿真后错过终端集合。双层方法在相同上限下则优雅降级，因为内层分配在每个外层迭代点都被精确求解，因此被中断的外层搜索仍能返回动力学一致、锥可行的控制。

燃料在 NLP 确实求解的场景上讲述了互补的故事（图 4）。逐场景与 NLP 配对，梯度方法在每个预算下都是外层搜索中最接近的。D-GD 的平均比率从 10 秒时的 1.18 降至 600 秒时的 1.12，C-GD 从 1.20 降至 1.14，而采样方法随预算向上漂移，从 10 秒时的 1.21–1.24 升至 600 秒时的 1.34–1.46。结论是：增加的计算为采样方法带来更多成功但不带来更优的解，而为梯度方法同时带来两者。NLP 与所提方法之间的直接比较（图 5）更清晰地揭示了权衡。在预算匮乏且锥角紧的情况下，所提方法比 NLP 基线消耗显著更多的燃料（在 ν = 1°、10 秒时高达 1.73），但其可靠性高出数倍。所提方法的可靠性优势与 NLP 基线的燃料优势均沿两个轴衰减：在 300 秒及以上的所有预算下，当 ν ≥ 15° 时 D-GD 距收敛 NLP 的代价在 5–8% 以内。10 秒时接近持平的单元格（ν = 5°–15° 时为 0.99–1.01）是截断效应的反向体现：此时 NLP 的幸存迭代点可行但代价高昂，D-GD 可直接与之匹敌。

V-B 分布式的价值

第 III-D 节的分布式多起点相对集中式变体提供了一致而适度的优势。D-GD 的平均配对燃料比率在每个预算下均匹配或优于 C-GD：10 秒时 1.18 对 1.20，600 秒时 1.12 对 1.14。独立孤岛在每秒墙钟时间内探索的吸引域至少与单条集中式重启链一样多，且一旦任一变体探索完可达吸引域，二者相差不超过 0.02。D-GD 在每个预算下还取得更高的成功率（图 3）。因此，分布式在解质量上毫无代价，并且正是它使第 III-G 节的闭环恢复模式成为可能。

V-C 可扩展性与故障生存性

图 6： 注入执行故障下闭环故障恢复成功率随集群规模的变化（每个集群规模 700–1800 个事件；误差条为 Wilson 95% 置信区间）。对于 N ≥ 11，恢复对一个、两个或三个智能体同时故障不敏感。

图 6 报告了闭环架构在随机执行故障（使一至三个智能体失效）下的表现，幸存者检测故障、在飞行中重新推导边界条件并分布式地重新规划。恢复可靠性随集群规模提升：N = 4 时 54% 的事件成功恢复，N = 11 时升至 93%，N ∈ {18, 25} 时为 94–96%。对于 N ≥ 11，该比率对同时故障的数量不敏感：双故障事件的恢复率为 92–95%，三故障事件在有采样的情况下（N = 25）为 94%。四智能体的下限是物理性的而非算法性的，因为失去四个智能体之一便移除了集群四分之一的执行能力，主要失败模式是力旋量不可行的重新规划——幸存者的附着锥不再张成为制动并重新引导载荷所需的力旋量。在串行孤岛仿真下，所有集群规模的中位重新规划墙钟时间恒定为每智能体约 29 秒，因此在分布式硬件上恢复延迟是平坦的。容错能力由此成为冗余的新兴效益，而分布式规划器将其在规模上转化为被挽回的任务。

VI 结论

本文提出了一种用于刚性载荷协同轨道运输的分布式双层框架。该问题被分解为内层凸推力分配和外层载荷力矩轨迹搜索，并证明了与原问题等价；外层搜索通过沿内层最优值的精确包络定理梯度进行投影梯度下降求解。随机重启处理多峰性，每个智能体运行独立的重启流，最大共识轮选出集群范围内的最佳轨迹；我们建立了向投影可达集最优值的几乎必然收敛，且同一规划器驱动闭环故障恢复模式。

在锥半角从 1° 到 60°、每智能体预算从 10 到 600 秒的蒙特卡洛实验中，该方法在每个锥角度上均匹配或超越所有基线的可靠性，在 78–80% 的经仿真验证场景上取得成功，而直接 NLP 为 20–50%。在所有外层搜索中，其燃料最接近收敛的 NLP，在中等锥角和充足预算下差距在 5–8% 以内，而采样基线要多付出 34–46%；在任何预算下，其在燃料或可靠性上均不逊于其集中式对应方法；并将闭环故障生存性从四智能体时的 54% 提升至十一及以上智能体时的 93–96%。所提方法有效地处理了 NLP 求解器无法求解的问题，并为其返回可行但更昂贵的解；随着问题变得更容易且计算预算增加，所提方法与 NLP 求解器之间的差距随之缩小。

更广泛地说，这些结果表明：凸子问题的精确敏感性可以将启发式分解转化为有原理的一阶方法；而分布式最有价值之处不在于分割计算，而在于对底层轨迹景观多峰性的对冲。这两个观察均可推广到其他多智能体太空任务，如共享刚体耦合各智能体执行机构的在轨组装与在轨服务。未来工作将通过更宽的投影漏斗或锥角上的同伦变换，扩大紧锥角下投影的可达集；在线调整重启分布以趋向未探索的吸引域；并将闭环层扩展到时变通信拓扑以及消旋阶段的故障。总之，这些步骤将推动我们迈向这样的集群：能够接管轨道上的大型或非合作物体，并被信任在真实任务的故障与约束下、无单点故障地、燃料高效地移动它。
