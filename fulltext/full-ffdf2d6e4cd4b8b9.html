据报道阿里巴巴禁止员工使用 Claude Code

📅 2026-07-04 📄 TechCrunch AI 🔗 原文链接

原标题：Alibaba reportedly bans employees from using Claude Code

中文摘要： 据报道，阿里巴巴将从7月10日起禁止员工使用Anthropic的编程工具Claude Code。此前，Anthropic已禁止中国公司使用其模型，并试图堵住允许中国用户访问Claude的漏洞，其中包括一项能秘密识别中国用户的实验。阿里巴巴已将Claude Code列为高风险软件，并指示员工改用公司内部的Qoder工具。

Claude Code，该版本可以秘密识别中国用户。Anthropic 的 Thariq Shihipar [在 X AI 模型的做法。） Shihipar 说：“自那以后，团队已经实施了更强有力的缓解措施，实际上我们一直打算将其下架一段时间。” 尽管如此，据报道阿里巴巴已将 Claude Code 列为高风险软件，并指示员工改用公司内部的 Qoder 工具。 主题 [AI](https://techcrunch.com/category/artificial-intelligence/),
