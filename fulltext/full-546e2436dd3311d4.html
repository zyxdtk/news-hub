摘要

通用机器人策略受益于大规模视觉预训练，但在富接触灵巧操作中常常表现不佳，因为力、柔顺性和初始滑移难以从图像中观察。我们提出 Spark-0，一个空间对齐的视觉-触觉-语言-动作（VTLA）模型，以两种互补方式使用触觉。预训练期间，由触觉手套导出的图像空间接触图，连同冻结 3D 几何教师的特征，共同监督视觉 token；这些目标在推理时被移除。同时，一条触觉通路编码区域力历史和 3D 触点状态以条件化动作专家。因此单一检查点即可支持纯视觉和触觉条件两种部署。为扩展该监督，我们构建了 HumanTouch——一个 1,000 小时的全手触觉人类操作数据集，并在其上结合自我中心视频、机器人数据和仿真对 Spark-0 进行预训练。我们还发布了 SparkArena，在同一灵巧本体上配对纯视觉仿真任务与触觉条件真实机器人任务。Spark-0 在两条 SparkArena 赛道上取得最高平均成功率，并在 Ego Humanoid 操作基准全部八项汇总指标上排名第一。与在相同数据和计算量上丢弃触觉的纯视觉预训练相比，保留 1,000 小时 HumanTouch 触觉将 Ego Humanoid 上的纯视觉成功率从 52.5% 提升至 71.7%，将部署时同样使用触觉的 SparkArena-Real 成功率从 44.0% 提升至 52.0%，表明触觉不仅可作为策略输入，还可作为灵巧视觉运动预训练的可扩展监督信号。

1 引言

大规模视觉预训练赋予视觉-语言-动作（VLA）模型强大的语义和视觉运动先验 [1, 2, 3]，但富接触灵巧操作仍然困难：力、柔顺性和初始滑移从图像中只能弱观测，且手部常常遮挡接触区域。先前工作通过时序触觉反馈 [4]、通用触觉预训练 [5]、人机触觉迁移 [6] 以及使用预测潜在触觉 token 的视触预训练 [7] 引入触觉。但仍存在三个缺口：与手部姿态和多视角视频同步的大规模全手触觉数据稀缺；触觉通常用于条件化或预测动作，而非监督视觉表征；且很少有基准同时衡量视觉灵巧性和富接触触觉控制。因此我们提出问题：触觉能否作为视觉运动预训练的可扩展监督，而不仅仅是额外的策略输入？

回答该问题首先需要大规模触觉数据。机器人遥操作成本高且覆盖接触范围窄，因此我们转向人类演示并构建 HumanTouch：跨越 100 多个任务、32 名操作员的 1,000 小时操作数据，使用双手全手触觉手套、手部和腕部追踪以及 60 Hz 同步的头部和腕部相机录制。相同手套可安装到目标灵巧手上，使人类和机器人数据共享相同触觉布局。

基于这些数据，我们训练 Spark-0——一个空间对齐的视觉-触觉-语言-动作（VTLA）模型，它用触觉监督视觉表征并条件化动作，为其分配两种角色（图 1）。第一，手套导出的接触图渲染到头部视角，连同冻结 3D 几何教师的特征，用接触发生位置的线索监督视觉 token。这些目标仅用于训练，因此即使部署时没有触觉传感器，模型也能从触觉中受益。第二，一条触觉通路编码区域力历史和 3D 触点状态，仅以接触如何演变来条件化动作专家。原始触觉从不进入视觉-语言主干，因此一个检查点即可服务纯视觉和触觉条件两种部署。

评估这两种角色需要在同一本体上测试有触觉和无触觉的部署，而现有基准不支持。因此我们发布 SparkArena，包含所有任务定义、资产、配对初始条件和评分协议。在同一灵巧本体上，SparkArena-Sim 测试纯视觉灵巧性，SparkArena-Real 测试带在线触觉的富接触操作。为测试无测试时触觉的跨本体迁移，我们还在 Ego Humanoid 操作基准 [8] 上评估。Spark-0 在两条 SparkArena 赛道上取得最高平均成功率，并在所有八项 Ego Humanoid 汇总指标上排名第一。与在相同数据和计算量上丢弃触觉的纯视觉预训练相比，保留 1,000 小时 HumanTouch 触觉将 Ego Humanoid 纯视觉成功率从 52.5% 提升至 71.7%；在 SparkArena-Real 上，相同比较将成功率从 44.0% 提升至 52.0%。

贡献

  • HumanTouch：1,000 小时全手触觉人类操作数据集，使用也可安装于机器人手的手套采集。
  • Spark-0：一个 VTLA 模型，将触觉既用作视觉 token 的仅训练监督，又用作动作专家的输入，从单一检查点支持纯视觉和触觉条件部署。
  • SparkArena：一个开放基准，在同一灵巧本体上配对纯视觉仿真任务与触觉条件真实机器人任务。
  • 实验：在三个基准上表明 Spark-0 优于强基线，且大规模触觉预训练显著提升在未见本体上的纯视觉性能。

2 相关工作

2.1 触觉数据

触觉传感器涵盖从高分辨率局部传感器到全手柔性阵列 [9, 10]。现有数据来自人类交互、视触夹爪和仿真 [11, 12, 13, 14, 15]，表征学习探索触觉估计、生成、补全、跨传感器聚合和人机迁移 [16, 17, 18, 5, 19, 6]。这些数据集大多规模有限或缺乏同步的手部姿态和多视角视频。HumanTouch 以 1,000 小时规模提供两者，且手套为人类和机器人采集共享。

2.2 富接触灵巧操作策略

VLA 模型将视觉-语言模型扩展到机器人控制 [20, 21]，采用扩散或流匹配动作专家 [22, 23, 24, 1, 2, 3, 25]。统一动作空间 [26, 27]、3D 语义物体表征 [28]、自我中心视频 [29, 30]、人手运动迁移 [31, 8, 32, 33, 34] 和世界动作模型 [35] 拓宽了视觉和运动覆盖；这些方法在记录触觉时，触觉作为策略输入而非视觉表征的预训练信号。触觉策略将触觉用于动作条件化、预测或反馈 [4, 7, 36, 37, 38, 39, 5]。最接近的工作 STAR 用 200 小时双手机器人数据处理触觉稀疏性 [40]。Spark-0 则在 HumanTouch 和异构数据上预训练，同时用触觉监督视觉表征和条件化动作专家。

2.3 操作基准

经典和近期基准主要评估基于夹爪的多任务、长时程、双手、记忆依赖或仿真-真实操作 [41, 42, 43, 44, 45, 46]。灵巧和视触基准 [47, 48, 8, 15] 大多在仿真中评估。SparkArena 则在同一灵巧本体上同时评估纯视觉灵巧性和真实机器人触觉控制。

3.1 采集硬件

每个采集单元组合了双手柔性压阻手套（每手 460 个传感点）、25 关节手指追踪、6 自由度腕部追踪、一个头戴式场景相机和两个腕装相机，全部以 60 Hz 同步（附录图 6）。我们屏蔽每只手位于弯曲区域的 140 个点（弯曲会产生虚假压力），其余 320 个点既用作触觉输入也用于生成接触图（附录图 7）。操作员在无机器人参与下执行自然的富接触任务，相同手套可安装到目标灵巧手上以记录具有相同信号布局的机器人演示。

HumanTouch 包含 1,000 小时多模态操作数据，跨越 100 多个任务和 32 名操作员。任务在接触模式、物体属性、运动复杂度和回合时长上变化，而非重复一小组动作（图 2）。更多细节见附录 A。

3.3 预训练混合数据

Spark-0 在异构混合数据上预训练，每个来源各有用途。HumanTouch 提供来自人类演示的全手接触监督；EgoDex 自我中心视频 [29] 拓宽场景、物体和运动覆盖；真实机器人数据使模型与目标本体对齐并增加机器人任务多样性，其中一部分通过相同手套记录；域随机化仿真增加视觉变化。来源时长、采样权重、相机配置和 400k 步调度见附录 D。

4 Spark-0

富接触灵巧控制需要视觉难以提供的两类信息：接触发生在哪里以及接触如何演变。前者部分可见但未被语义 VLM 特征显式编码；后者涉及被遮挡的压力变化。Spark-0 分别处理：仅训练的空间对齐用接触区域监督视觉 token（4.2 节），触觉通路以接触动力学条件化动作专家（4.3 节）。我们首先描述主干和动作空间。

图 3：Spark-0 架构。 Qwen3-VL 条件化一个流匹配动作专家；仅训练目标对齐视觉 token，原始触觉绕过 VLM。 偶数层对 VLM 交叉注意力；奇数层在状态-触觉-动作 token 上自注意力。所有层使用力条件化的 AdaLN。 区域力和 3D 触点（每手 320 个）流产生 24 个触觉 token。 VLM 列是偶数层交叉注意力（包括训练捷径）；其他列是奇数层自注意力。细节见附录 B。

图 3 内容要点： 视觉监督（仅训练）：RGB → DA3（冻结）、接触图；几何（所有视角）+ 接触图（头部）→ h₂₅；VLM Qwen3-VL 处理图像、语言+离散化状态、动作查询；联合流 DiT 自注意力与交叉注意力 ×L/2；状态 ×3、触觉 ×24、动作 ×50；逐层 KV；触觉编码器。 交替 DiT 层（先交叉 · L 层）：偶数层（i=0,2,4,…）AdaLN(c) + VLM 交叉注意力（K,V ← h_{i+1}，来自 VLM+查询）；奇数层（i=1,3,5,…）AdaLN(c) + 掩码联合自注意力（Q,K,V：联合序列）；跨 L 层重复交叉→自注意力；c = Embed(τ) + Embed(flatten(F_l, F_r))，状态·触觉·动作使用相同条件。 触觉编码器：3D 触点（左右手，xyz+压力）；独立双手 · 共享 MLP/池化；区域力 · 左/右 ×6 区域 ×20 帧；点 MLP（傅里叶 xyz+p）、区域池化（每区域 softmax）；加手和区域嵌入 e_h+e_r、拼接双手、标量门 γ3D/γF 得到 3D token 和力 token；时间卷积得触觉 token；缺失 → 共享占位符 e∅；g：触觉查询门；对数缩放窗口 → 展平（无卷积）→ 中的 c。 注意力掩码：Q\K 矩阵涵盖 VLM、状态、力、3D、动作；交叉与联合自注意力；可见；注意力偏置 b(g) = −6(1−σ(g))；捷径。

4.1 VLA 主干与动作目标

Spark-0 基于 StarVLA [3] 和 XPolicyLab 代码库 [49] 构建。它将 Qwen3-VL-4B 与逐层流匹配动作专家配对，使动作生成能利用完整视觉层次，从低层空间特征到高层语义。给定图像 I、指令 w 和机器人状态，VLM 产生隐藏状态 {h^(l)}_{l=1}^L。当前状态以离散化 token 进入 VLM 序列，状态历史在动作专家中连续嵌入。附加到 VLM 序列的可学习动作查询总结视觉-语言上下文；因果掩码防止其改变更早的 token。

统一状态与动作空间：人类和机器人来源在手部形态和坐标系上不同，因此所有来源离线转换为目标本体的双手布局：对于侧 k ∈ {L,R} 在时刻 t，末端执行器位姿 T^k_t ∈ SE(3) 和 WUJI Hand 2 的 20 个关节角 q^k_t。对于人类数据（HumanTouch 和 EgoDex），腕部轨迹配准到机器人坐标系，手部关键点通过逆运动学重定向到 WUJI 手。设 C_t 为头部相机位姿，ρ(T) = [p, r(R)] ∈ R⁹ 通过平移 p 和由 R 前两行构成的 6D 旋转 r(R) 编码位姿；ρ⁻¹ 通过正交归一化恢复有效旋转。状态使用头部相机坐标系中的绝对位姿，第 h 个动作行使用相对于当前末端执行器的位姿和绝对关节目标：

s^k_t = (ρ(C⁻¹_t T^k_t), q^k_t)，a^k_{t+h} = (ρ((T^k_t)⁻¹ T^k_{t+h}), q^k_{t+h})，h = 0, …, H−1。　(1)

相机坐标系为所有来源提供共享的、以视觉为中心的参考，相对块在每个推理步骤重新锚定到最新观测位姿；部署时从预测位姿分量 â^k_{t+h} 恢复绝对目标 T^k_{t+h} = T^k_t ρ⁻¹(â^k_{t+h})。拼接两侧得到 2×(9+20) = 58 维状态和动作。

动作专家：动作专家有 L = 36 个宽度 1024 的 DiT 块，与 VLM 深度匹配。偶数块对相应 VLM 层的投影隐藏状态交叉注意力，包括 64 个动作查询；奇数块执行 4.3 节的联合自注意力。从三个状态帧，专家预测 H = 50 的动作块 a = a_{t:t+H−1}。以归一化目标块 a、高斯噪声 ϵ 和流时间 τ ∈ [0,1]，训练目标为

a_τ = (1−τ)ϵ + τa，L_act = E_{a,τ,ϵ}[∥v_θ(a_τ, τ, C) − (a − ϵ)∥²₂]，　(2)

其中 C 表示连续状态、逐层 VLM 上下文和可选触觉 token。损失对每个样本的六次噪声采样取平均，推理用四个欧拉步积分预测速度。归一化和流时间采样见附录 D。

4.2 空间对齐：监督交互区域

由于动作专家逐层读取 VLM 特征，我们希望这些特征编码交互发生的位置。我们对 VLM 第 ℓ⋆ = 25 层应用两个仅训练目标，该层是深层但非最终层，被一个交叉注意力块读取。几何对齐为每个视角和来源提供密集场景结构；接触对齐在手套数据可用时标记交互区域。两个头在推理时被丢弃。

几何对齐：冻结的 Depth-Anything-3 教师 [50] 产生重采样到合并视觉 token 网格的块特征，使 z^geo_{b,v,j} 匹配视角 v 中的视觉 token j。我们通过下式将其与投影的 VLM token 对齐：

L_geo = E_{b,v,j}[1 − cos(φ_geo(h^(ℓ⋆){b,v,j}), z^geo{b,v,j})]。　(3)

损失先在每个视角内取平均再跨视角取平均，使 token 更多的相机不占主导。

接触对齐：几何描述场景但无法区分手是否接触物体。对每只手，我们检测接触中的触点，将其锚定到从手套重建的 MANO 网格，沿手表面扩散其强度，并将网格渲染到头部视角；两只手通过逐像素最大值合并。该图池化到 token 网格作为软目标 y_{b,j} ∈ [0,1]，一个轻量级头从头部视角 token h^(ℓ⋆)_{b,0,j} 预测接触 logits。由于接触区域稀疏，我们结合 focal 和软 Dice 损失：

L_con = 0.1·L_focal + 0.1·L_dice。　(4)

接触图仅是训练目标，从不是策略输入；其构建细节见附录 C.1。

4.3 触觉融合：以接触动力学条件化动作

空间对齐提升视觉可推断的内容但无法恢复被遮挡的压力变化。因此我们添加一条仅馈送到动作专家的触觉通路；原始触觉从不进入 VLM，纯视觉部署用可学习占位符替换触觉 token。接触在两个时间尺度上演变：压力在毫秒内变化，而接触几何由单帧捕获。因此时间卷积为每只手六个区域各总结 20 帧（约 333ms）力历史，产生 12 个区域力 token；共享点编码器嵌入每手当前 320 个触点（头部相机坐标系 xyz 和压力）并在相同区域内注意力池化，产生 12 个 3D token。

缺失触觉：只有部分预训练数据带触觉，且缺失传感器不同于零压力。存在的流由独立的可学习门缩放，缺失或无效的流使用共享的可学习占位符 e∅。这一固定布局让纯视觉和触觉样本共享批次，而不将缺失传感视为无接触。编码器细节、压力条件化、质量检查和门初始化见附录 B。

联合动作-触觉流：接触应随动作计划演变而非作为固定外部上下文，因此触觉 token 与状态和动作 token 加入同一序列：

Z^(0)_b = (E_s(s_b) ∥ ẽ^reg_b ∥ ẽ^3d_b ∥ E_a(a^τ_b))，　(5)

其中 E_s 和 E_a 将每个 58 维状态帧和带噪动作行嵌入到宽度 1024，得到三个状态、十二个区域力、十二个 3D 和五十个动作 token。交叉注意力块让所有行读取视觉-语言上下文，自注意力块联合更新它们。为使触觉 token 立足于传感，非对称偏置仅限制触觉查询对状态和动作键的注意力；状态和动作无偏置地关注门控触觉 token。由于动作专家否则可能仅依赖视觉-语言路径，触觉样本训练时偶尔将状态和动作行的交叉注意力输出置零，迫使上下文流经触觉行。区域力窗口还通过零初始化的 AdaLN 通路调制每个块，动作从最后 H 个动作行解码。细节见附录 B。

4.4 训练目标与部署

所有组件联合训练：

L = L_act + λ_geo·L_geo + L_con，λ_geo = 0.2。　(6)

几何对齐适用于每个可用视角，接触对齐适用于有效接触图，触觉编码器通过带触觉样本上的 L_act 学习。推理时，DA3 教师和对齐头被移除，触觉捷径被禁用，而非对称偏置和门控触觉通路保留。相同权重支持带触觉占位符的纯视觉部署和带在线信号的触觉条件部署，无需额外模块。

6.3 预训练与触觉规模分析

7 结论

我们提出了空间对齐 VTLA 模型 Spark-0，以及 1,000 小时全手触觉数据集 HumanTouch 和配对纯视觉仿真任务与触觉条件真实机器人任务的基准 SparkArena。Spark-0 将触觉既用作视觉 token 的仅训练监督又用作动作专家输入，因此单一检查点支持纯视觉和触觉条件部署。它在两条 SparkArena 赛道上取得最高平均成功率，并在所有 Ego Humanoid 汇总指标上排名第一。1,000 小时 HumanTouch 触觉预训练在纯视觉部署下的未见 Ego Humanoid 本体上产生最大增益，表明触觉不仅是策略输入，也是灵巧视觉运动预训练的可扩展监督。

附录 B 架构细节

B.1 动作专家

动作专家的块数 L 与 VLM 层数相同。VLM 隐藏状态从 1 开始索引，DiT 块从 0 开始：偶数块 i 对投影的 VLM 隐藏状态 h^(i+1) 交叉注意力，奇数块在联合状态-触觉-动作序列上运行掩码自注意力（图 3(b)）。每个块执行恰好一次注意力操作加一个前馈子层。动作 token 接收可学习位置嵌入，而触觉 token 由流、手和区域嵌入区分，因此不移动预训练动作位置。每个块中的注意力前归一化由共享条件 AdaLN 调制：

c = Embed(τ) + Embed(vec(ψ(F_left), ψ(F_right)))，　(7)

其中 ψ 是附录 B.2 的压力变换。第二项展平 2×6×20 = 240 维区域力窗口并通过隐藏宽度 512 的零初始化 MLP，独立于触觉 token 门；对手套缺失样本为零。视觉 token 剪枝和可选的未来接触头被禁用。

B.2 触觉编码器

流：区域流对每只手接收 60 Hz 下 20 帧上的六个区域力信号。核大小 3、隐藏宽度 512 的三层时间卷积加时间平均池化，每区域产生一个 token。3D 流仅接收当前帧：每手 320 个触点，各带头部相机坐标系 xyz 和压力。四频带傅里叶特征通过两层宽度 512 的点 MLP，softmax 注意力在每个区域内池化触点。对手 k、区域 r 和触点集 R_{k,r}：

e^reg_{k,r} = f_temp(ψ(F_{k,r,1:TF}))，e^3d_{k,r} = f_set(Pool_{i∈R_{k,r}} f_pt(Γ([x_i, ψ(p_i)])))。　(8)

添加可学习手和区域嵌入后，两流投影到宽度 1024 并无 token 混合器地拼接，得到 12 个区域和 12 个 3D token。

压力条件化与质量检查：压力变换为 ψ(p) = log(1+p)/s，尺度 s 自动估计且无中心化；零压力触点仍有效。若 3D 行的坐标和压力有限值少于 25% 或超过 85% 饱和超过幅值 1.5，则用占位符替换，卡死触点在池化前移除。训练中 3D 流以 0.15 概率丢弃，而区域流无模态丢弃。

门控与缺失流：存在的流由可学习标量门 γ^reg 和 γ^3d 缩放，均初始化为 0.1 且无 L1 惩罚。缺失流用复制到其槽位的单一可学习占位符填充且不门控：

ẽ_q = m_q·γ_q·e_q + (1−m_q)·e∅，q ∈ {reg, 3d}，　(9)

其中 m_q ∈ {0,1} 指示流 q 是否存在。

B.3 联合注意力与触觉捷径

非对称偏置：在联合自注意力中，触觉查询对状态和动作键的注意力接收加性偏置

b(g) = −6(1−σ(g))，　(10)

g 可学习且初始化为 1.0。状态和动作查询无偏置地关注触觉键，因此该方向的触觉影响仅由值门控制。

触觉捷径：在带触觉样本训练时，捷径将每个偶数块中 3 个状态行和 50 个动作行的交叉注意力输出置零，而 24 个触觉行继续读取 VLM，使视觉-语言上下文仅通过触觉行到达动作行。其概率在前 20k 步（微调时 8k 步）从 0 线性升至 0.1，推理时禁用。

C.1 接触图生成

接触图从每只手 320 个观测触点离线生成，分别处理。MANO 手部姿态从手套重建，因此人类数据和同手套机器人数据共享相同流程。

接触检测：每个触点的压力 p 偏移校正为 Q = max(p−10, 0)。每触点噪声尺度 σ 每序列估计一次：跳过前 10 帧后，接下来（最多）60 帧构成静息窗口 R，稳健尺度 MAD(X) = 1.4826·median(|X−median(X)|)。设 L 为 Q 的运行 3 帧最大值。若 R 被接触污染，即 MAD(R) ＞ max(3, 3·max(σ_fb, 1)) 或 max(R) 超过 L 的第 70 百分位数，我们使用回退 σ_fb，即 L 最安静 20% 的 MAD；σ 被钳制到至少 1。z_level 为 Q 的 3 帧最大值，z_rise 为 24 帧峰值相对其前最小值的上升，均除以 σ，当 z_level ≥ 2 且 z_rise ≥ 2 时触点进入接触。接触在 z_level ≥ 1 时保持，在连续五帧低于此下限后释放，或在 z_level ＜ 1 且压力下降至少 2σ 时立即释放。进入上升 z_enter 在接触回合中冻结，触点强度为

A_taxel = clip(z_level/6, 0, 1)·clip(0.35 + 0.65·z_enter/6, 0, 1)，　(11)

结合当前压力水平与接触起始的锐度。释放后，强度在八帧内线性衰减到零。区域强度是其触点的最大值，手强度 A ∈ [0,1] 是接触区域的最大值。

表面扩散：在每个接触区域中，最多三个 z_level·z_rise 最高的活跃触点映射到 778 顶点 MANO 网格的掌侧顶点作为源；若映射无顶点，则使用该区域的顶点集。d(v) 为顶点 v 到最近源的测地距离，d_ref 为 d(v) 的第 98 百分位数，钳制到至少 0.03m，顶点强度为

F(v) = max((0.35 + 0.65A)·clip(1 − d(v)/d_ref, 0, 1), 0.05)，　(12)

当手无活跃接触时 F ≡ 0。

渲染：带姿态的 MANO 顶点用每帧外参和标定内参投影到头部相机；深度低于 0.03m 的顶点被丢弃。仅当三角形三个顶点投影在图像边界 8 像素内时光栅化，三角形按平均深度从远到近绘制。每个覆盖像素取其顶点强度的重心插值，负权重被裁剪并重新归一化。两只手通过逐像素最大值合并并裁剪到 [0,1]，得到 480×640 图。

接触目标的性质：空间范围。由于 d_ref 是测地距离的第 98 百分位数且接触手的每个顶点至少接收 0.05，该图覆盖几乎整个可见手，强度在源附近达到峰值。结合 12×12 token 网格（每 token 32 像素），目标编码手级接触区域而非精确接触点。强度范围。接触中的触点有 z_level ≥ 1 和 z_enter ≥ 2，因此 A ≥ (1/6)(0.35 + 0.65·2/6) ≈ 0.09；接触手的峰值强度因此位于 [0.41, 1]，无接触的手贡献零。逐帧最大值归一化仅保留每帧内的相对分布。过滤。过滤阈值等于强度下限（0.05），因此仅当源附近 (0.35 + 0.65A)(1−d/d_ref) ＞ 0.05 的区域覆盖足够图像时保留帧。离线估计。回退噪声尺度使用整个序列，因此非因果，这是可接受的，因为接触图仅是训练目标。遮挡。深度排序仅解决每只手内的自遮挡，因此目标标记手接触的位置，包括隐藏在被操作物体后面的区域。

附录 F 基线细节

基线涵盖不同的架构和数据扩展策略。通用机器人策略：π0.5、GR00T-N1.7 和 StarVLA 将预训练 VLM 与流匹配动作专家耦合 [1, 2, 3]。RDT-1B 是在超过一百万条多机器人轨迹上以统一动作空间预训练的 1.2B 扩散 transformer [26]。X-VLA 通过本体特定软提示适配跨机器人流匹配主干 [27]。人类先验迁移：EgoVLA 从自我中心视频预测人类腕部和手部运动，然后重定向并在机器人演示上微调 [8]。H-RDT 在姿态标注的 EgoDex 轨迹上预训练 2B 流匹配扩散 transformer [33]。VITRA 将一百万人类视频片段转换为语言条件 3D 手部动作 [32]。UniT 学习视觉锚定的离散潜在动作并用流头解码 [34]。其他策略：FastWAM 作为世界动作模型协同训练视频和动作 DiT 并在推理时丢弃视频生成 [35]。我们还包括 ACT [22]、多流 RLDX-1 策略 [25] 和跨传感器触觉基础策略 FTP-1 [5]。
