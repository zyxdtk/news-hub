中文摘要： 德国 AI 公司 Black Forest Labs 开放 FLUX 3 Image Klein 权重。该 56 亿参数图像模型支持原生 4K 输出、参考图像引导编辑与边界框控制，可在 8GB 显存的消费级 GPU 上本地运行，并提供基础、蒸馏及 INT8 等压缩版本。年收入低于 500 万美元的企业和个人可免费商用，更大组织需单独授权或使用 API（1K 图像 0.009 美元起）。官方基准称其偏好评分超过 Qwen-Image 2.1、Ideogram 4.5 等开放权重模型，但未测试 4K

图片来源：VentureBeat 使用 GitHub 上的 Flux 3 Klein 制作

德国 AI 视频与图像公司 Black Forest Labs 今日发布 FLUX 3 Image Klein 的开放权重。这是一款 56 亿参数的图像模型，旨在让开发者能够在自己的硬件上生成、编辑和定制视觉内容。

该公司表示，Klein 保留了其 7 月发布的更大模型 FLUX 3 Image 的能力，包括：

  • 原生 4K 输出
  • 由参考图像驱动的空间控制与编辑
  • 可在显存低至 8 GB 的消费级 GPU 和笔记本电脑上运行

本次发布包括一个用于适配改造的基础版本、一个速度更快的蒸馏版本，以及旨在降低部署要求的 FP8、NVFP4 和 INT8 版本。

对于企业买家而言，最关键的细节在于许可证。Black Forest Labs 允许年收入低于 500 万美元的个人和企业免费商用。规模更大的组织需要另行签订商业自托管协议，或使用该公司的 API——Klein 的 1K 分辨率图像起价为每张 0.009 美元。

这使得 Klein 成为本地 AI 图像处理的又一个选择，但能够下载其权重并不意味着每家企业都拥有不受限制的商业权利。

面向私有、可定制图像工作流的小型模型

Klein 支持根据文字指令进行生成、修改现有图像，以及由多张参考图像引导的创作。Black Forest Labs 表示，该模型还支持边界框，让开发者可以指定某个元素应出现的位置。

该公司将基础检查点定位为微调的起点。蒸馏检查点所需的生成步骤更少，面向更低延迟的场景。压缩版本则通过降低数值精度来减少内存需求。

Black Forest Labs 列出了对 ComfyUI、Hugging Face Diffusers、Ostris 的 AI Toolkit、vLLM-Omni 和 SGLang Diffusion 的支持，并表示开发者可使用 Nvidia NeMo AutoModel 对模型进行微调。该公司称，Klein 是在 NVL72 系统中的 Nvidia GB200 GPU 上训练的，并针对 Nvidia 的加速计算平台进行了优化。

BFL 现已明确，在 GeForce RTX 硬件上进行本地使用的最低显存要求为 8 GB。但该公司并未将这一最低要求与特定的模型变体、输出尺寸或生成时间挂钩，且所提供的速度图表并未测试 8 GB 配置或 4K 输出。买家可以更具体地规划所支持的硬件，但仍需要这些细节来估算最低规格下的性能。

其实际吸引力在于控制权。企业可以让模型适应自己的样本数据，并在自己的基础设施内运行，而无需将每个图像请求都经由托管服务处理。潜在应用包括产品摄影、可重复使用的品牌资产和内部设计工具。这些是可用于评估 Klein 的用例，而非发布材料中报告的实际客户部署情况。

托管蒸馏版本还包含 Black Forest Labs 的提示词处理和定向编辑流水线。因此，API 基准测试本身并不能确定未经修改的检查点在本地运行时的实际表现。

商业许可证是分界线

本次发布采用 FLUX Kommunity 许可证。Black Forest Labs 表示，收入低于 500 万美元门槛的企业可免费将 Klein 用于商业用途；规模更大的组织则可洽谈自托管权利或购买 API 访问权限。

该公司已发布的 FLUX 3 Action Kommunity 许可证以合并关联方后的年化总收入来界定资格。同一份已发布的许可证还对输出审查或过滤以及再分发设置了条件。该现有文本为这一许可证家族提供了背景参考；而随 Klein 实际下载附带的条款才是本次发布的权威文件。

这一区别对于大公司旗下的小型子公司或实验性团队意义重大。单个项目的预算并不能决定其在该现有收入定义下是否具备资格。

该公司随后的 API 文档列出了具体价格：768 × 768 像素分辨率为 0.008 美元，1K 为 0.009 美元，1.5K 为 0.011 美元，2K 为 0.014 美元，4K 为 0.036 美元。

在同一分辨率下，生成与编辑的单张图像价格相同。BFL 尚未公布标准的商业自托管费用。

早前的一次简报曾将 API 定价描述为约为某领先开放权重竞争对手价格的四分之一，但既未点名比较对象，也未说明匹配的输出设置。

免费商业许可也并不意味着计算、存储、适配或维护成本就此消失。对于利用闲置本地硬件的团队与构建持续需求服务的企业来说，商业账目的算法并不相同。

基准图表显示了什么——又留下了哪些空白

Black Forest Labs 表示，其内部评估显示，Klein 在生成、基于参考图像的创作和编辑方面领先于其他领先的开放权重模型。

提供给 VentureBeat 的图表将 Klein 及其基础版本与 Qwen-Image 2.1、Ideogram 4.5、FLUX.2 [pro]、FLUX.2 [klein] 9B 和 Krea 2 进行了比较，绘制了偏好评分与模型大小的关系，以及单独的一百万像素输出的 API 延迟。

在更新后的 API 延迟图表中，无论是文生图还是编辑，Klein 的偏好评分均高于图中所示的其他模型。对于一百万像素输出，BFL 图表显示蒸馏版本生成约需 5 秒、编辑约需 7 秒，而基础检查点分别约为 11 秒和 22 秒。这些是从该公司图表上读取的数据点，并非独立复现的测量结果。

BFL 还提供了本地速度测量数据，并标明了所用硬件、精度和采样步数。

图片来源：Black Forest Labs

在 RTX 5090 上使用 INT8 版本时，其 16 步蒸馏模型生成一张 1,024 × 1,024 像素图像需 4.1 秒，编辑需 7.2 秒。在 2,048 × 2,048 像素下，耗时分别升至 15 秒和 43 秒。

图片来源：Black Forest Labs

在同一 GPU 上，50 步基础模型在 1,024 × 1,024 分辨率下需 12.5 秒和 27.4 秒，在 2,048 × 2,048 下需 79.8 秒和 236 秒。

BFL 将每项结果标注为该 GPU 上速度最快的构建版本，测量方式为每次运行处理一张图像。

消费级硬件之间的性能差距相当显著。在同样的 16 步测试中，RTX 4070 生成一张 1,024 × 1,024 像素图像需 8.9 秒，2,048 × 2,048 需 50.4 秒；编辑则分别需要 18.9 秒和 150 秒。

在 DGX Station 上，BFL 报告 1,024 × 1,024 生成需 0.59 秒，2,048 × 2,048 需 2.2 秒。图表中 GeForce 显卡采用 INT8，而 DGX Station 和 DGX Spark 采用 NVFP4，因此这些跨硬件数据并非仅针对芯片本身的受控比较，且其测量的是本地处理耗时，而非完整的托管 API 请求耗时。

以上均为 Black Forest Labs 的评估结果。偏好图表没有提供足够的关于提示词、评判标准、样本量或不确定性的信息，无法独立确立其质量优势的幅度。

这些图表量化了指定 GPU 上的生成和编辑表现，但没有提供与之匹配的竞争对手运行数据、能耗或成本测量，也没有对 16 步版本与 50 步基础版本进行质量评估，且未测量 4K 输出。

图表比较的是 Krea 2，而非单独向 VentureBeat 简报过的 Krea 3 版本。它同样未包含 OpenAI 当前的 GPT Image 2.5 模型或 Google 的 Nano Banana 2.1。因此，这些图表并不能支持“Klein 领先整个图像模型市场”的说法。

竞争对手提供不同的访问与控制组合

最接近的比较对象是阿里巴巴的 Qwen-Image 2.1，它拥有 70 亿参数的视觉生成器、可下载的权重、集生成与编辑于一体的单一模型、原生透明度支持，以及最多十张参考图像的支持。

不过，Qwen-Image 2.1 的研究许可证将其标准授权范围限定为非商业研究或评估，商业使用需另行获得许可。Klein 对小型企业明确给予的商用许可构成了有意义的差异。更早的 Qwen-Image-Edit 采用 Apache 2.0 许可证，因此买家应核实具体检查点的条款，而非默认整个系列条款一致。

Ideogram 4.5 通过其应用、MCP 和 API 提供生成与编辑功能，支持原生 2K 输出。Ideogram 强调在反复编辑中保持图像保真度。Klein 则强调可下载部署与定制能力；BFL 提供的评估并未测试 Ideogram 的重复编辑声明。

OpenAI 的 GPT Image 2.5 提供用于精确编辑的 Sunburst 和面向更快日常生成的 Flare，并可通过 Responses API 进行对话式编辑。

Google 的 Nano Banana 2.1 支持 1K、2K 和 4K 的生成与编辑、参考图像工作流以及基于搜索的接地能力。

这些有据可查的 API 工作流为偏好提供商托管基础设施的组织提供了替代方案。Klein 则为希望自行管理模型的企业开辟了一条新路径。

同期发布的 Krea 3 公告则在定制和价格方面加剧了竞争。在提供给 VentureBeat 的材料中，Krea 报出的价格为 1K 图像 0.03 美元、2K 图像 0.06 美元，并描述了针对特定产品、人物或风格的微调能力。这些是 Krea 的发布声明，而非 BFL 比较图表的结果。

Klein 与竞争对手图像模型的 API 价格对比

Klein 公布的 1K 图像 0.009 美元、2K 图像 0.014 美元的价格，低于 Krea 在相应分辨率上报出的 0.03 美元和 0.06 美元。

BFL 更大的 FLUX 3 Image 模型在发布时于该公司 API 定价页面上列为 1K 图像 0.048 美元。这些是不同模型的价格，并不能证明输出质量相当。BFL 表示，Klein 在给定输出分辨率下的生成与编辑价格相同。

Google 列出的标准 Nano Banana 2.1 图像输出费用为 1K 0.0336 美元、2K 0.0504 美元、4K 0.113 美元。这些数字不包括输入处理、文本或思考输出，以及任何可计费的搜索查询。

OpenAI 列出的 GPT Image 2.5 图像输出定价为每百万 token 30 美元，另加输入费用。每张图像的总费用因尺寸和质量而异，因此该 token 费率并非成品图像的固定价格。

Klein 公布的单张图像费率同样低于 Google 列出的 1K、2K 和 4K 图像输出费用，但 Google 的数字未包含其他可计费项目。

要比较总成本，需要匹配的工作负载以及对每家提供商费用的完整核算。

图像生成与机器人技术共享基础，但并非同一产品

Black Forest Labs 将 Klein 描述为其近期 FLUX 3 Action 机器人模型背后同一 FLUX 3 基础的产物。该公司表示，跨图像、视频和音频的共享训练有助于系统学习视觉结构与物理行为。Klein 所宣布的功能均与图像相关；本次发布并未证明该图像检查点能够直接控制机器人。

“FLUX 3 让这个社区能够将同一基础适配到截然不同的需求上，从创意生成到机器人技术，”Black Forest Labs 联合创始人兼 CEO Robin Rombach 在公告中表示。

该公司还表示，外部合作伙伴 Cinder 在发布前对两个 Klein 检查点进行了安全评估，此前已进行数据集过滤和旨在限制有害输出的后训练。该公司报告其漏洞少于其他流行的开放权重模型，但发布材料中未提供数值比较或完整方法论。

对企业而言，Klein 的价值将取决于本地控制、适配和许可是否能比托管方案带来更好的契合。

GPU 测量数据说明了为什么分辨率、检查点和硬件选择应纳入这项考量：在消费级显卡上，从 1K 提升到 2K 可能让耗时从几秒增加到几十秒甚至几分钟。BFL 公布的费率现已提供各个分辨率档位的 API 成本，而更大组织的商业自托管条款仍需另行签订协议。
