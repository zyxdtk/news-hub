Abstract.
近年来，使用视频生成模型对场景进行建模引起了越来越多的研究兴趣。然而，大多数现有方法依赖于透视视频模型，仅合成场景的有限观察，导致完整性与全局一致性问题。
我们提出 \papername，一种可控的全景视频生成框架，利用全景表示丰富的每帧场景覆盖和内在的长期空间与时间一致性，实现长时场景漫游。我们的框架首先通过一个 preview 阶段，使用轨迹控制的视频生成模型从给定的输入图像或视频快速生成场景概览。然后，在 refine 阶段，将该视频在时间上扩展并在空间上上采样，生成长距离、高分辨率视频，从而实现高保真度的世界漫游。
为了训练我们的模型，我们引入了两个包含合成和真实世界捕获视频的全景视频数据集。
实验表明，我们的框架在视觉质量、可控性和长期场景一致性方面均优于现有最先进方法，无论是在定性还是定量上。我们进一步展示了该框架的多个扩展，包括实时视频生成和3D重建。代码可在 https://github.com/yuhengliu02/OmniRoam 获取。

1.
引言
生成模型在创建图像和视频等视觉内容方面已取得显著保真度（Feng et al., 2025; Zhang et al., 2025b; Zhu et al., 2025）。然而，在大规模生成连贯视觉内容方面仍面临根本性挑战，尤其是在场景建模方面。大多数现有场景生成方法（Ho et al., 2020, 2022; Sohl-Dickstein et al., 2015; Kim et al., 2024; Oh et al., 2024）基于透视视频，反映以人为中心的视角，由于其有限的视野覆盖，限制了对物理环境的全面建模。最近基于自回归的世界模型（Blattmann et al., 2023; Chen et al., 2024; Guo et al., 2024; Long et al., 2024; Hong et al., 2025）在长时视频合成方面展现出潜力，但在大相机运动时往往导致累积误差和时间漂移（Li et al., 2025; Yu et al., 2025）。这些透视视频面临挑战，主要因为其视野受限，使得在空间和时间上保持全局场景一致性变得复杂。
为解决这些局限，我们引入全景视觉作为大规模场景生成的基础。与透视视图不同，全景表示固有地提供整体场景覆盖和全局空间记忆（Lin et al., 2025a, b; Wang et al., 2025），为保持长期一致性提供了稳健基础。特别是，我们专注于全景视频漫游任务，其中相机沿扩展轨迹探索场景。该任务允许视频中的每一帧保留全局上下文，而无需随时间累积，为长期视频生成提供了一种自然且显式的机制来保留空间和时间信息。尽管最近的工作开始将现有生成架构适应全景数据（Liu et al., 2025; Zhang et al., 2025a; Xing et al., 2025; Xie et al., 2025），但这些努力通常将全景视为透视图像的直接扩展，未能充分利用其表示优势。
在本工作中，我们提出 OmniRoam，一种用于长时全景视频合成的可控视频生成框架（图 1）。我们认为，有效的场景建模受益于全局到局部的设计：首先通过全景表示建立全局场景结构，然后通过增加空间和时间分辨率逐步细化局部细节，从而生成既高保真又全局连贯的场景表示。受此启发，我们引入了一个 preview 阶段，生成场景的粗略概览：给定用户提供的输入图像或视频和指定的相机轨迹，我们的框架生成中等空间分辨率的全景视频，并以加速播放速度，实现大规模场景布局的高效导航。实际上，由于生成模型的随机性，用户能够高效生成多个视频变体并选择其偏好的场景配置。基于选定的预览，后续的 refine 阶段对生成的全景视频进行操作，以正常播放速度合成最终高分辨率结果，支持沉浸式、连贯的长时场景漫游。
为了在可扩展的数据集上训练我们的模型，我们实现了一个带有规范坐标系的全景数据生成流水线。我们准备了合成和真实世界捕获的视频，提供精确的相机轨迹和高保真视觉质量。我们还提出了一种新颖的度量标准——循环一致性，用于评估场景生成中的长期全局一致性，定量展示了全景表示的优势。
大量实验表明，我们的方法在多个指标上表现更优，包括视觉质量、可控性和长期全局一致性。我们进一步展示了该框架的扩展，包括实时预览模式和基于生成的全景漫游视频构建的3D高斯点云（3DGS）重建流水线。我们工作的主要贡献如下：
• 我们引入了一种基于全局到局部预览-细化设计的长时全景视频生成可控框架，实现了连贯且可扩展的场景漫游。
• 我们展示了全景表示和我们的设计在多个指标上优于基于透视的方法，并展示了使用我们框架的扩展和应用。
• 我们构建了一个可扩展的全景视频数据生成流水线，并将发布带有相机轨迹的全景视频数据集，以支持大规模场景建模。
• 我们提出了一种新颖的评估度量——循环一致性，用于量化场景级视频生成中的长期全局空间一致性，定量展示了全景表示的优势。
2.
相关工作
透视视频生成。
随着扩散模型的出现，视频生成迅速发展（Ho et al., 2020, 2022; Sohl-Dickstein et al., 2015; Peebles and Xie, 2023; OpenAI, 2024; Xiao et al., 2025; Dalal et al., 2025; Kahatapitiya et al., 2025; Feng et al., 2025; Zhu et al., 2025; Haji-Ali et al., 2025）。最近的强模型如 Hunyuan-Video (Kong et al., 2024)、CogVideoX (Yang et al., 2024) 和 Wan (Wan et al., 2025) 通过架构优化实现了高保真合成。然而，保持长期一致性仍然困难；标准和控制方法通常在长时间内遭受严重质量退化或结构不一致（Guo et al., 2024; Long et al., 2024）。尽管最近的自回归方法（Yin et al., 2025; Huang et al., 2025）试图解决此问题，但基于透视的方法本质上受限于狭窄的视野（FoV），限制了其捕捉整体场景上下文或在大规模探索中保持全局空间一致性的能力。
Figure 2
. OmniRoam 流水线包括 (1) 一个 preview 阶段，该阶段接收输入图像/视频和用户指定的相机轨迹，通过分解轨迹条件（流 + 缩放）生成加速的中等分辨率全景视频，以及 (2) 一个 refine 阶段，该阶段执行缩放对齐和分段扩散，生成最终的高分辨率长时全景视频。该框架进一步支持实时自回归预览和下游3D重建。preview 和 refine 阶段的两个模型均从预训练的扩散变换器微调而来。
全景视频生成。
全景视觉提供整体几何线索，以克服透视视图的空间限制。早期的文本到全景框架通常分为两类：失真感知方法，即适应球形几何的架构（例如，DynamicScaler (Liu et al., 2025)、PanoDiT (Zhang et al., 2025a)），以及利用多视图或混合关系实现全局一致性的投影驱动方法（例如，TiP4GEN (Xing et al., 2025)、VideoPanda (Xie et al., 2025)）。
最近，WorldPrompter (Zhang et al., 2025c) 利用全景生成作为中间表示，合成全局一致的3D场景以用于高斯点云重建。
相机控制视频扩散模型。
最近的研究将显式相机信号注入视频主干，以解耦动态与内容，如 (Wang et al., 2024b; Bai et al., 2025)。在全景领域，360DVD (Wang et al., 2024a) 引入了球形运动条件。更先进的框架，如 Matrix-3D (Yang et al., 2025) 和 CamPVG (Ji et al., 2025)，结合轨迹引导与球形感知机制或3D重建，以生成可探索的世界。
然而，这些方法通常专注于短片段，并因误差累积而难以进行长时生成。相比之下，我们的方法采用全局到局部的预览-细化框架，利用全景一致性实现高保真、可扩展的长期场景漫游。
3.
OmniRoam：长时全景视频漫游
OmniRoam 是一个基于全局到局部生成策略的相机控制长时全景视频合成框架。如图 2 所示，该框架包括一个 preview 阶段（第 3.1 节），该阶段在加速播放速度下，基于输入图像和相机轨迹生成中等分辨率的全景视频，随后是一个 refine 阶段（第 3.2 节），该阶段生成最终的高质量全景视频以实现沉浸式世界漫游。我们还描述了我们的全景数据生成流水线（第 3.3 节）和一种新颖的长期场景一致性度量（第 3.3 节）。此外，我们展示了扩展，包括实时自回归预览和3DGS重建（第 4.5 节）。
3.1.
轨迹控制视频预览
预览阶段从用户提供的图像或视频和指定的相机轨迹生成全景视频，提供场景的快速概览。我们基于一个预训练的视频生成模型 (Wan et al., 2025) 并微调为一个条件于视觉输入和显式轨迹及运动动态线索的全景视频生成模型。一个关键创新是将相机运动控制分解为两个正交因素：flow，指定移动的归一化方向；scale，控制全局步长。
帧维度视频条件。
遵循 ReCamMaster (Bai et al., 2025)，我们采用帧维度条件策略以确保严格的视觉连续性。令 V_in ∈ ℝ^{f×3×H×W} 表示输入视频或图像，V_v ∈ ℝ^{f×3×H×W} 表示要生成的目标视频，其中 f 是时间长度。一个3D变分自编码器 ℰ_v 将它们编码为潜在表示：
(1) z_in = ℰ_v(V_in), z_v = ℰ_v(V_v), z_in, z_v ∈ ℝ^{f′×c×h×w}
其中 f′, c, h, w 分别表示潜在空间中的时间长度、通道维度和两个空间维度。遵循 ReCamMaster (Bai et al., 2025) 和 Wan (Wan et al., 2025)，源和目标潜在表示在帧维度上进行分块并拼接。
分解轨迹条件。
我们将相机轨迹控制分解为两个正交分量：flow 和 scale。这种分解使得速度调整直观，便于高效场景探索，并提供更精细的控制：scale 在所有帧上全局调节运动，而 flow 指定每帧的方向信息。这种分离也简化了后续的 refine 阶段，该阶段仅需调整单个参数（即 scale）而无需包含轨迹向量。此外，在两个关键假设下——(a) 匀速：相机沿轨迹以几乎恒定速度移动，以及 (b) 固定朝向：相机朝向在整个序列中保持不变，将轨迹分解为 flow 和 scale 是直接的。这些假设在数据整理过程中被强制执行，详见第 3.3 节。
Scale。
Scale s ∈ ℝ⁺ 是一个全局标量，表示每时间步相机位移的大小。我们引入它以量化播放速度，并采用 log 空间表示以处理广泛的速度范围。Scale 嵌入 z_s 通过投影计算：
(2) z_s = ϕ(log(s)),
其中 ϕ ∈ ℝ → ℝ^{c_s} 是一个输出通道大小为 c_s 的可学习线性投影器。该嵌入全局注入到变换器块中，均匀调节所有时间令牌。
Flow。
Flow 𝒟 = {𝐝_k}{k=1}^f 是一个包含 f 个单位向量的序列，表示每个时间步相机位移的归一化3D方向。在速度分解下，我们有 ‖𝐝_k‖ = 1 对所有 k 成立。该方向信息通过一个零初始化的相机编码器 ℰ_c 编码：
(3) z_d = ℰ_c(𝒟),
其中 z_d ∈ ℝ^{f′×c_d} 是通道大小为 c_d 的嵌入，编码器 ℰ_c 是插入每个变换器块中的全连接层，用于帧级轨迹控制。
训练目标。
遵循 Wan et al. (2025) 中的修正流框架，前向过程在数据 z_v 和噪声 ϵ ∼ 𝒩(0,𝐈) 之间插值，z_t = t z_v + (1-t) ϵ。在训练过程中，仅对目标潜在添加噪声，而保持源潜在 z_in 清洁。我们沿时间维度将源和目标潜在帧级拼接，其中 z_in 作为条件信号以确保严格的视觉连续性。损失仅在目标部分计算：
(4) ℒ_preview = 𝔼{t,z_0,ϵ} ‖v_Θ([z_in, z_t]frame, t, 𝐜) - (z_v - ϵ)‖_2^2,
其中 v_Θ 是预测的速度场，[⋅]_frame 表示帧级拼接，𝐜 = {z_d, z̃_s} 表示包含流嵌入和带时间重复的缩放嵌入的条件集。

3.2.
长时视频细化
尽管预览阶段以加速速度（即大 scale s）生成相机控制视频，但捕捉扩展轨迹需要时间扩展和质量增强。由于计算限制，直接在单次传递中生成长、高分辨率视频是不可行的。我们引入了一个第二阶段扩散模型，通过缩放对齐和可见性掩码条件进行分段细化。细化的 n 个片段随后被拼接形成最终的长时视频 V = [V^(1), V^(2), ..., V^(n)]。
缩放对齐和可见性掩码条件。
给定在 scale s ∈ [1.1, 8.0] 下生成的预览视频 V_p ∈ ℝ^{f×3×H×W} 和目标 scale s′（例如，s′=1.0 表示正常播放），我们需要将时间分辨率扩展 s/s′ 倍。我们计算所需的片段数为 n = ⌈s/s′⌉。对于第 i 个片段（i = 1, ..., n），通过增加空间和时间分辨率合成一个细化视频序列 V^(i)，条件是选定的预览帧。具体来说，我们构建一个二进制可见性掩码 𝐦^(i) ∈ {0,1}^f 以选择哪些帧来自 V_p 作为生成的条件：
(5) m_j^(i) = {1 如果 j_0^(i) ≤ j < j_0^(i) + w, 0 否则},
其中 w = ⌈(f-1)/n⌉ 是窗口大小，j_0^(i) = (i-1)w 在推理时。该掩码选择对应的预览帧作为稀疏条件。
在训练期间，我们随机采样 j_0 ∼ 𝒰[0, f-w] 以获得更好的泛化。
预览被编码为 z_p = ℰ_v(V_p) ∈ ℝ^{f′×c×h×w}，掩码通过平均池化下采样为 𝐦′^(i) ∈ ℝ^{f′}，如图 2 所示。掩码潜在条件是：
(6) z̃_p^(i) = z_p ⊙ 𝐦′^(i),
其中 𝐦′^(i) 在通道和空间维度上广播。
训练目标。
我们将目标潜在 z_v′ ∈ ℝ^{f′×c×h×w}（在 scale s′ 下）与 z̃_p^(i) 沿帧维度拼接。仅对目标部分添加噪声。修正流目标为：
(7) ℒ_refine = 𝔼{t,j_0,z_v^(i),ϵ} ‖v_Φ([z̃p^(i), z_t′]_frame, t) - (z_v′ - ϵ)‖_2^2,
其中 z_t′ = t z_v′ + (1-t) ϵ，z_v′ 是在 scale s′ 下的目标视频片段，v_Φ 是细化模型预测的速度场。
3.3.
新数据集和基准
轨迹对齐训练数据的规模和精度对于高保真和可探索的全景视频生成至关重要。我们首先建立一个规范的全景坐标系，将相机旋转与平移解耦，将控制空间定制为球形几何。
基于此协议，我们构建了一个混合数据集，包括从稳定的真实世界视频中提取的场景现实数据和从3DGS场景中合成的轨迹精确数据，带有复杂的路径规划（图 3）。这种设计有助于模型从多样化、物理可行的运动模式中学习稳健的几何先验。
规范全景坐标系。
在等矩投影（ERP）全景中，相机旋转对应于循环像素偏移，而不是透视视图中的几何遮挡。
因此，我们设计了一个旋转不变的坐标系，不同于标准的6自由度方法 (Yang et al., 2025)。
通过消除相机自旋转（滚转、俯仰、偏航），我们严格通过相对于ERP中心（ϕ=0, θ=0）的平移 (x, y, z) 定义轨迹。
此种形式化简化了生成空间，确保视觉动态仅由相对于锚点的空间平移驱动。
场景现实真实数据。

遵循我们的旋转不变协议，我们对视频进行重力对齐，并使用COLMAP (Schonberger and Frahm, 2016) 估计相机轨迹。
我们随后过滤掉尺度异常的视频，以确保所有数据大致处于相同尺度。

长期场景一致性度量。
评估长时空间一致性具有挑战性，因为标准度量（例如，FVD、FID）无法捕捉长时间内的全局结构一致性。因此，我们提出循环一致性（𝒞_loop），用于衡量生成场景在遍历闭合环路相机轨迹后是否返回初始视图。给定一个沿环路轨迹生成的序列 V = {I_i}{i=1}^f，我们定义：
(8) 𝒞_loop = (1-S_2)/(1-S_1),
(9) S_1 = (1/P^2) ∑{q=1}^P ∑{p=1}^P Sim(I_p, I_{f-q+1}),
(10) S_2 = (1/P(f-2P)) ∑{p=1}^P ∑{q=P+1}^{f-P} Sim(I_p, I_q).
其中 Sim(⋅,⋅) 表示CLIP嵌入余弦相似度。这里，S_1（环路闭合得分）衡量第一帧和最后P帧之间的视觉相似性，而S_2（中间得分）捕捉其与中间帧的相似性。P=5帧的缓冲区提高了对轻微时间错位的鲁棒性。该度量奖励具有高环路闭合相似性（S_1 → 1）的生成，同时在探索过程中保持足够的变化（S_2 → 0）。

4.
实验
4.1.
评估协议
我们从三个方面评估我们的方法：视觉质量、轨迹可控性和循环一致性。评估在两个输出分辨率下进行：480p（我们的预览）和720p（我们的细化）。
我们定义了七种相机轨迹：前进、后退、左、右、S形曲线、环路和真实轨迹（GT）。这些轨迹在训练中均未直接包含。对于每种轨迹和每种方法，我们使用测试集生成24个视频。在论文中展示的定性可视化中，生成模型的输入是单个从互联网收集的全景图像，以展示超越训练数据的泛化能力。更多细节见补充材料。
视觉质量。
我们使用 Fréchet Auto-Encoder Distance (FAED) (Zhang et al., 2024)、结构相似性指数 (SSIM) 和 LPIPS 评估视觉质量。FAED 通过在自编码器特征空间中计算距离，扩展了 Fréchet Inception Distance，从而减少了等矩投影引入的失真伪影的敏感性。对于 SSIM 和 LPIPS，我们生成以 GT 轨迹为条件的视频，并逐帧将合成结果与对应的真实视频进行比较。
轨迹可控性。
直接比较不同方法的相机运动是不公平的，因为有效运动尺度可能不同，且从生成视频中提取相机姿态会引入额外噪声。为避免这些问题，我们遵循 CamPVG (Ji et al., 2025) 的评估协议，所有方法均在相同的 GT 轨迹上进行条件生成。我们计算三个时间窗口的平均 PSNR：第20–25帧（PSNR’25）、第50–55帧（PSNR’55）和第70–75帧（PSNR’75）。对于641帧的长视频生成，我们额外报告第610–615帧（PSNR’615）和第630–635帧（PSNR’635）的PSNR。更高的PSNR值表示更准确地遵循指定轨迹。
循环一致性。
我们使用第3.3节中介绍的度量评估循环一致性。具体来说，我们生成遵循环路轨迹的视频，并在所有帧上计算循环一致性得分。更高的得分表示生成的视频在完成完整环路后返回到更接近初始视图的视觉状态，反映出更强的长期空间一致性。
4.2.
实验设置
模型训练。
我们在480×960（480p）和720×1440（720p）分辨率下分别训练预览和细化阶段的两个模型。两个模型均从 Wan2.1-1.3B (Wan et al., 2025) 微调而来。预览模型生成81帧视频，支持全景图像或视频、轨迹尺度和运动动态作为条件。我们首先在真实数据上使用随机时间切片训练120k步，批量大小为64，学习率为5×10⁻⁴。然后在合成数据上微调64k步，批量大小相同，学习率降低至1×10⁻⁴。对于细化阶段，模型以时间加速的480p视频片段为输入，重建720p视频，尺度为1×，共81帧。训练时真实和合成数据以相等概率采样。我们使用批量大小64，学习率1×10⁻⁴，训练120k步。
基线。
我们与 Matrix-3D (Yang et al., 2025) 和 Imagine360 (Tan et al., 2024) 进行比较。Matrix-3D 在 Wan2.1-14B 上微调，支持480p和720p输出，最多生成81帧，并允许带轨迹控制的全景图像输入。Imagine360 将透视视频转换为全景视频，输出512×1024的32帧序列。为公平比较，我们将其输出下采样至480p，并在时间上插值至81帧。我们输入从全景中裁剪的透视视图，并主要评估其生成质量。

4.4.
设计分析
表示选择的影响。
我们通过在相同设置下使用从全景数据集中裁剪的透视数据训练透视视频变体，比较了全景和透视表示。如表2所示，用透视视频替换全景视频会一致地降低视觉质量、轨迹可控性和循环一致性。这种退化在预览阶段生成的短序列（81帧）和细化后生成的长序列（641帧）中均被观察到。这些结果表明，透视视频有限的视野使得在大相机运动下难以保持全局场景结构，即使使用相同的模型设计。
生成策略的影响。
为评估我们的全局到局部生成框架，我们实现了一个直接产生长视频序列的简单自回归全景视频生成器，通过将每个片段的输出输入到下一个片段，训练设置相同。如表2所示，自回归变体在所有指标上均劣于我们的完整模型，尤其是在循环一致性方面差距显著，这可能是由于片段间误差累积所致。我们的方法的循环一致性得分几乎是自回归基线的两倍，表明更强的长期空间一致性。
循环一致性分析。
图5提供了在环路轨迹下通过CLIP相似性测量的一致性生成的时间分析。对于我们的方法，与第一帧的相似性随着相机远离起始位置而降低，然后随着环路闭合而逐渐恢复，最终接近初始帧的相似性。相比之下，自回归变体（图5(a)）单调漂移，后期帧生成的内容与初始全景有显著偏差。透视视频变体（图5(b)）也表现出结构退化。尽管相似性曲线在末尾有轻微恢复，但最终帧与初始视图有显著差异，物体几何和场景细节明显丢失。这些结果共同证明了我们的表示和设计选择对于稳定长时场景漫游的必要性。
4.5.
扩展与应用
通过自强制实现的实时预览。
我们扩展模型以实现实时预览，遵循自强制 (Huang et al., 2025)，将完整模型蒸馏为轻量级自回归预览器。给定一个训练好的预览模型（教师），我们通过最小化 𝔼_{𝐱̂∼p_θ̂, 𝐱∼p_θ} [D(𝐱̂{1:T}, 𝐱{1:T})] 匹配实时预览器的分布（学生）p_θ̂ 与教师的分布 p_θ，其中 𝐱̂{1:T} 和 𝐱{1:T} 分别是学生和教师生成的序列，D(⋅) 是分布匹配损失（例如，判别损失或DMD分数）。我们的实时预览器在7秒内生成81帧全景视频，远快于原始预览阶段模型（∼5分钟），且显著优于Matrix-3D（∼11分钟）。图9(a)显示实时预览器保留了整体场景结构并生成了合理的结果。此外，图7展示了使用实时模型生成480p视频并随后使用我们的细化模型增强至720p的结果。更多细节见补充材料。
3D场景生成。
我们还展示了我们一致长时全景视频生成框架在3D场景生成和重建中的应用。具体来说，给定包含641帧的生成长视频，我们均匀提取100个中间帧以表示场景序列。对于每个采样的全景帧，我们裁剪五个视野为120°、分辨率为512×512的透视视图。这些透视裁剪随后作为输入图像用于3D高斯点云（3DGS）重建 (Kerbl et al., 2023)。得益于我们生成的长距离一致性，重建的3DGS场景（图9(b)）在不同视角下具有连贯的结构，表明我们的全景视频提供了足够的视图覆盖和多视图一致性，可作为合理的3D表示。更多细节见补充材料。
5.
结论
在本工作中，我们提出了 OmniRoam，一种用于长时场景漫游的可控全景视频生成框架。通过使用全景表示和全局到局部的预览-细化设计，我们的方法实现了在显式相机控制下的大型场景连贯探索。我们构建了一个带有精确轨迹的全景视频数据集，并引入了一种度量以评估长期场景一致性。实验表明，OmniRoam 在视觉质量、可控性和长期一致性方面优于基于透视的方法。我们进一步展示了生成的视频支持实时预览和下游3D场景重建，突显了全景视频生成在场景级建模中的实用性。
