摘要
目标检测器通常会对训练类别之外的目标产生过度自信的预测，从而导致所谓的分布外（OoD）幻觉。现有检测或缓解此类幻觉的方法通常要么直接在学习到的目标检测器表示上构建评分函数，要么修改目标检测器本身以抑制幻觉的产生。然而，这些表示中隐式编码的潜在先验在很大程度上仍未被探索，也未被显式解码用于OoD检测。为了揭示和利用这些潜在先验，我们提出了结构化先验知识（SPK），这是一个面向幻觉的框架，它从预训练的目标检测器中显式提取与OoD相关的先验。具体而言，SPK利用分布内数据和诱导幻觉的样本作为诊断监督，以提取目标检测器决策背后的部件级语义概念，而不是仅仅将它们用于拒绝或目标检测器适应。提取的语义先验进一步与几何先验和上下文先验相结合，形成用于OoD检测的紧凑五维SPK表示。在多种目标检测器架构和多个OoD基准上的广泛实验表明，SPK实现了最先进的OoD检测。我们的发现表明，预训练的目标检测器已经编码了比通常用于OoD检测的丰富得多的潜在知识。更重要的是，这些知识可以被显式提取并组织成一个紧凑、结构化且可解释的知识空间，用于预测可靠性分析。这提出了一条有前途的主动路线，通过显式揭示和利用潜在先验来提高目标检测器的可靠性。代码和数据可在以下地址获取：
https://gricad-gitlab.univ-grenoble-alpes.fr/dnn-safety/spk

目标检测已成为现代视觉系统的基础能力，支持自动驾驶、机器人和智能感知等众多现实应用。尽管取得了显著进展，现代目标检测器仍然面临一个关键的可靠性问题：它们经常对属于预定义训练类别之外类别的目标产生自信的预测。这些错误的预测被称为分布外（OoD）幻觉 (13; 48)，当开放世界环境中违反了检测器训练底层的封闭世界假设时，就会出现这种幻觉。这种幻觉可能会严重损害下游视觉系统的可靠性和安全性，使得有效的 OoD 幻觉缓解成为一个日益重要的问题。
现有方法通过两条互补的路线来缓解 OoD 诱导的幻觉。反应式方法通过引入基于置信度估计 (28; 20)、不确定性建模 (6) 或中间特征表示 (7; 42; 46; 47; 12) 的外部 OoD 检测器，在生成预测后检测幻觉。相比之下，主动方法试图通过适应目标检测器本身来减少幻觉的发生，例如通过利用检测器内在特性的轻量级微调 (48)。尽管这两种路线在缓解策略上有所不同，但它们最终都在目标检测器相同的学习高维表示空间上运行：现有方法要么在这些表示上设计越来越先进的 OoD 评分函数，要么修改目标检测器以提高其判别能力。
这自然引出了一个基本问题：
目标检测器在这些表示中已经学习了哪些潜在先验，决定了预测是成为有效检测还是 OoD 幻觉？
我们认为，回答这个问题为 OoD 幻觉缓解提供了一个根本不同的主动视角。我们不是在不透明的高维表示上设计越来越复杂的算法或修改目标检测器本身，而是寻求显式提取预训练目标检测器中已经编码的潜在先验，并将它们组织成一个紧凑且可解释的表示空间用于 OoD 检测。
为了回答这个问题，我们提出了结构化先验知识（SPK），这是一个面向幻觉的框架，它从预训练的目标检测器中显式提取与幻觉相关的先验。我们的关键观察是，OoD 幻觉不是任意的预测失败，而是始终与两个代表性来源相关。第一个来源是近端 OoD 目标，它们的视觉外观与已知类别相似，因此会引起语义混淆。第二个来源是纯背景样本，其中非目标区域意外地激活了检测器的目标性并产生错误检测。SPK 不是将这些样本用于离群值暴露或检测器适应，而是将它们作为诊断监督，以揭示目标检测器决策背后的部件级语义概念。基于这一观察，我们开发了一个自动化数据构建流水线，该流水线可以发现信息丰富的近端 OoD 和纯背景样本，同时生成高质量的部件级语义监督。提取的语义先验进一步与几何先验和上下文先验相结合，形成紧凑的五维 SPK 表示。由此产生的表示由捕获部件级目标概念的三个语义先验、测量预测相对空间范围的几何先验以及反映图像级上下文证据的上下文先验组成。
重要的是，尽管其维度大幅降低，这种结构化表示仍能实现更强的 OoD 检测性能。如表 1 所示，当应用相同的下游 OoD 检测算法时，SPK 始终优于原始目标检测器表示。更重要的是，如图 1 所示，在 SPK 表示上运行的轻量级孤立森林异常检测器超越了现有的最强缓解策略 (48)，即 Proximal-OoD，该策略结合了用于抑制幻觉产生的目标检测器微调和基于 KNN 的 OoD 检测。这种优势在不同的检测器架构中始终存在，与现有缓解策略相比具有明显的性能优势。这些结果突显了通过揭示和利用预训练检测器中嵌入的结构化知识来提高目标检测器可靠性的新视角。我们的贡献总结如下：
•
我们提出了一个主动框架，用于从预训练的目标检测器中提取潜在先验，并将其组织成用于 OoD 检测的结构化知识空间。
•
我们通过在多种目标检测器架构和多个 OoD 基准上的广泛实验证明了 SPK 的有效性，在实现轻量级和可解释部署的同时，在 OoD 检测中取得了最先进的性能。
•
我们的发现表明，预训练的目标检测器编码了极其丰富的潜在知识，这些知识可以被显式组织成一个紧凑、结构化且可解释的知识空间，为提高目标检测器可靠性开辟了一条有前途的新方向。
相关工作
目标检测器中的 OoD 幻觉检测与理解
目标检测器通常在封闭世界假设下进行训练，可能会对训练类别之外的目标产生过度自信的预测，从而导致所谓的 OoD 幻觉。现有方法大致可分为反应式和主动式范式。反应式方法将 OoD 幻觉表述为事后检测任务（OoD 检测）。它们通过置信度估计 (28; 20)、不确定性建模 (6) 或中间特征表示 (7; 42; 47) 在目标检测器推理后检测幻觉预测。尽管这些方法在改善 ID 和 OoD 预测之间的分离方面很有效，但它们在很大程度上将幻觉视为预测级别的异常，并且对检测器为何做出此类决策提供的见解有限。主动方法则试图通过主动诊断检测器行为来理解幻觉的根本原因。最近的主动干预方法 (13; 48) 揭示了传统的目标性估计可能对一般的类目标模式而不是 ID 目标做出响应，并利用近端 OoD 数据将目标性校准为分布感知预测。相比之下，我们的工作遵循主动提取的视角。我们不是干预检测器的决策机制，而是旨在通过提取负责其决策的类别级语义原型，揭示预训练检测器中编码的潜在语义知识。通过 SPK 空间，我们的方法提供了检测器在生成预测时观察到的证据的可解释视图，并能够基于这些提取的表示进行 OoD 幻觉检测。
基于概念的知识提取与结构化先验
通过特征解码和基于概念的表示学习，理解和从深度网络中提取可解释的知识已被广泛研究。线性探测 (1)、网络解剖 (2) 和 Net2Vec (10) 表明中间表示包含人类可解释的语义信息。概念瓶颈模型进一步引入了显式概念变量以提高模型透明度，最近的工作探索了无标签和空间概念表示 (27; 4; 33)。除了可解释性之外，语义概念和结构化先验也被研究用于提高模型的鲁棒性。部件级监督已被证明能够鼓励更鲁棒的目标表示，超越脆弱的外观线索 (35; 19)，而最近基于检测器的概念分解方法探索了用于未知目标发现的可解释语义证据 (24)。然而，现有的基于概念的方法很少被设计用于分析目标检测器中的 OoD 幻觉。相比之下，我们的工作利用部件级概念和目标检测器行为来提取与幻觉相关的先验，将语义、几何和上下文知识整合到紧凑的 SPK 表示中，以实现可解释的 OoD 检测。
问题表述
我们遵循目标检测中 OoD 检测的标准表述 (8; 48)。设 𝒟_ID 表示用于训练目标检测器的 ID 数据集，其中目标属于预定义的类别集 𝒞_ID。给定输入图像 I，在 𝒟_ID 上训练的目标检测器 f 产生一组预测 𝒫=f(I)={p_i}{i=1}^N，其中每个预测表示为 p_i=(𝐛_i, ŷ_i)。这里，𝐛_i 表示预测的边界框，ŷ_i∈𝒞_ID 表示预测的类别。对于每个预测 p，我们用 I_ctx​(p) 表示其对应的上下文图像，它表示生成预测的图像。
给定一个 OoD 数据集 𝒟_OoD，其目标类别与 𝒞_ID 不相交，OoD 检测旨在识别在应被拒绝的 OoD 输入上生成的预测。形式上，OoD 检测器 g 是一个二元决策函数：
g:𝒫→{0,1},
其中输出 1 表示 p_i 是 OoD 诱导的幻觉，应被拒绝，而输出 0 表示 p_i 被保留。这种 OoD 诱导的幻觉可能来源于不同的源头，包括来自 𝒞_ID 之外类别的目标以及虚假激活检测器响应的背景区域。
结构化先验知识框架

为了回答目标检测器已经获得了什么知识的问题，我们提出了 SPK，这是一个主动框架，它显式提取检测器先验以进行 OoD 幻觉检测。与直接在目标检测器输出或高维特征表示上操作的现有方法不同，SPK 旨在揭示导致检测器决策的潜在因素。如图 2 所示，SPK 通过面向幻觉的监督提取了三种互补类型的检测器先验，即语义、几何和上下文先验。这些先验提供了对检测器行为的显式表征，并被组织成紧凑的五维 SPK 表示。最后，轻量级 OoD 检测器使用 SPK 表示来确定每个预测应被保留还是拒绝。以下小节描述了所提出框架的每个组件。
面向幻觉的数据构建
在本节中，我们首先详细介绍了产生幻觉的两类 OoD 数据的构建，这些数据与 ID 数据一起用于在 SPK 框架中提取语义先验。然后，我们介绍了我们为这三类数据在部件级进行标注而构建的工具。
幻觉诱导数据准备
我们从两个互补的来源构建幻觉诱导训练数据：近端 OoD 目标和纯背景图像。对于每个 ID 类别，我们遵循 (48) 的提示设计并查询 GPT-5 以识别语义或视觉上相似的非 ID 类别，并从 Objects365 (34) 中检索带标注的图像。我们还从 DTD 数据集 (5) 中收集纯背景样本，并使用预训练的目标检测器过滤掉包含 ID 目标的图像。然后，我们在两个来源上运行目标检测器，并仅保留诱导幻觉 ID 预测的样本。这些幻觉诱导样本用于训练语义提取头。有关数据构建和过滤的更多详细信息在附录 A.1 数据准备 中提供。
部件级自动标注
训练语义提取模块需要空间定位的部件级语义监督，以捕获与目标检测器决策相关的视觉证据。为了消除部件级标注作为实际瓶颈，我们开发了一个自动标注工具，该工具生成可定位的部件概念，将它们在目标区域内定位，并生成相应的概念掩码用于训练语义提取头。由此产生的标注只需要轻量级的人工验证。更多实现细节在附录 部件级自动标注 中提供。
先验提取
SPK 没有直接在高维目标检测器表示上构建 OoD 决策函数，而是研究是否可以通过一小组显式潜在先验来表征目标检测器预测。为此，我们提取了三种互补类型的目标检测器先验，即语义、几何和上下文先验，每种先验都捕获检测器行为的不同方面。具体而言，语义先验表征与预测相关的语义证据，几何先验描述目标级几何规律，上下文先验捕获预测的关联图像 I_ctx​(p) 与 ID 样本在图像级表示空间中的相似度。以下小节描述了每个先验提取模块。
语义先验提取
语义信息为确定检测器预测是否对应于有效目标或 OoD 幻觉提供了重要线索。受基于概念的表示学习最新进展 (37) 的启发，我们假设目标检测器也在其中间表示中隐式编码了特定类别的语义证据。我们的目标不是学习新的语义知识，而是通过部件级语义概念提取并解码这些潜在知识。因此，我们引入了一个语义先验提取模块，将检测器表示转换为结构化的部件级语义响应。
给定预测 p_i=(𝐛_i, y_i)，我们首先提取对应于其预测边界框 b_i 的感兴趣区域特征 𝐅_i。我们不直接使用 𝐅_i 作为 OoD 表示，而是学习一个特定类别的语义提取头 ℋ{y_i} 来解码检测器表示中编码的潜在语义证据。具体而言，每个语义头预测与预测类别相关的一组部件级概念的激活。
设 𝒞_{y_i}={1,…,N_{y_i}} 表示与预测类别 y_i 相关的概念词汇。为了构建语义监督，我们考虑与类别 y_i 相关的三个互补概念组：(1) 来自 ID 类别 y_i 的部件级概念，(2) 来自与 y_i 相关的近端 OoD 类别的概念，以及 (3) 从纯背景数据获得的背景概念。这些概念组分别从 ID、近端 OoD 和纯背景数据构建，代表了可能有助于检测器预测的不同语义来源。对于每个预测，语义头输出一个概念激活张量：
𝐀_i=ℋ_{y_i}(𝐅_i)∈[0,1]^{N_{y_i}×H×W},
其中每个通道对应于 𝒞_{y_i} 中的一个特定部件级概念，空间维度表示 RoI 内的单元格级布局。遵循部件级概念标注，每个 RoI 被划分为固定的空间网格，并训练语义头以恢复相应的单元格级概念掩码。这种表述使得检测器表示能够被解码为可解释的部件级语义响应，而无需像素级分割。
为了优化语义提取头，我们采用了三个互补目标：
ℒ_SPK=ℒ_concept+λ_g​ℒ_suppress+λ_s​ℒ_group.
第一个目标鼓励准确重建部件级语义概念。具体而言，我们在预测的概念激活张量 𝐀_i 和相应的单元格级概念标注 𝐌_i 之间最小化 Dice 损失 (36)：
ℒ_concept=𝔼_{p_i}[DiceLoss(𝐀_i,𝐌_i)].
Dice 目标鼓励每个概念通道恢复其相应部件级概念的空间分布。
第二个目标防止语义提取头激活不受观察到的 RoI 支持的概念。给定预测的标注概念集，我们引入了一个虚假概念抑制损失，对缺失概念的响应进行惩罚。该目标提高了提取语义响应的特异性，并减少了虚假概念激活。
对于预测 p_i，我们将其缺失概念集定义为 𝒞_i^-。例如，鸟的 RoI 通常包括眼睛、喙、翅膀、躯干和脚等部件级概念；然而，如果脚被遮挡且不可见，则脚概念的真值标注变为空，相应的概念通道属于 𝒞_i^-。
设 A_{i,c}∈[0,1]^{H×W} 表示对应于概念通道 c 的激活图，U_i∈{0,1}^{H×W} 表示空间联合掩码。
我们将空间约束表述为
ℒ_suppress=𝔼_{p_i}[1/|𝒞_i^-|∑{c∈𝒞_i^-}⟨U_i,−log(1−A{i,c})⟩/‖U_i‖1]
(1)
其中 ⟨⋅,⋅⟩ 和 ‖U_i‖_1 分别表示 Frobenius 内积和标注为正的单元格数量。对数是逐元素应用的。
最后，我们引入了一个组级语义目标，以确保主导语义响应对应于底层视觉证据的实际来源。我们将语义组集合定义为 𝒦={id,prox,bg}，其中每个概念通道通过映射 π{y_i}:𝒞_{y_i}→𝒦 被分配到一个组。
给定通道激活 a_i^c，每个语义组的响应通过下式获得：
s_i^k=max_{c∈𝒞_{y_i}:π_{y_i}(c)=k}a_i^c, k∈𝒦

由此产生的组响应使用交叉熵损失进行优化：
ℒ_group=−𝔼_{p_i}∑{k∈𝒦}q_i^k log(exp(s_i^k)/∑{k′∈𝒦}exp(s_i^{k′}))
其中 𝐪_i 表示预测 p_i 的独热语义组标签。
几何先验提取
目标检测器在生成边界框预测时本质上依赖于几何规律。例如，常见的目标检测器设计通过锚框设计或边界框回归先验利用目标尺度和空间分布。受此观察的启发，我们从预测的边界框中提取几何先验，以表征预测是否遵循已知目标的几何模式。
给定预测 p_i=(𝐛_𝐢, ŷ_i)，我们计算其相对面积作为几何描述符：
r_i=Area(b_i)/Area(I_ctx​(p_i)),
其中 I_ctx​(p_i) 表示与预测 p_i 关联的图像。相对面积提供了预测目标大小的尺度归一化测量，并且对图像分辨率不变。这个简单的几何统计量捕获了目标检测器隐式使用的目标尺度先验，并作为所提出的 SPK 表示的几何组件。
上下文先验提取
除了目标级属性外，检测器预测还受到它们出现的图像的视觉上下文的影响。因此，我们引入了一个上下文先验，用于测量预测的关联图像与 ID 训练图像之间的相似度。
给定预测 p_i，我们首先提取其关联的图像表示：
𝐯_i=ϕ_det(I_ctx​(p_i))
其中 ϕ_det​(⋅) 表示从检测器中提取的图像级表示。为了关注检测器内在编码的先验，我们直接利用检测器表示，而不引入额外的外部模型。我们构建了一个 ID 图像表示库：
𝒱_ID={ϕ_det(I_j)∣I_j∈𝒟_ID^{train}}。然后通过测量 𝐯_i 与其在 𝒱_ID 中的 K 近邻 (KNN) 之间的相似度来计算上下文先验：
d_i^{ctx}=KNN(𝐯_i,𝒱_ID),
其中 d_i^{ctx} 表示由此产生的图像级上下文分数。较低的值表示预测的关联图像与 ID 训练数据中观察到的视觉特征更一致。
结构化先验知识
提取的语义、几何和上下文先验提供了目标检测器编码的潜在知识的互补视图。我们将这些先验组织成每个预测的紧凑 SPK 表示。具体而言，语义模块产生三个组级响应 𝐬_i=[s_i^{id},s_i^{prox},s_i^{bg}]，对应于 ID、近端 OoD 和背景概念组。连同几何先验 r_i^{geo} 和上下文先验 d_i^{ctx}，最终的 SPK 表示定义为
𝐳_i^{SPK}=[s_i^{id},s_i^{prox},s_i^{bg},r_i^{geo},d_i^{ctx}]∈ℝ^5.
SPK 向量的每个维度对应于目标检测器知识的可解释方面，从而能够基于结构化先验而不是原始高维检测器特征进行 OoD 检测。
基于 SPK 的 OoD 检测
给定结构化先验表示 𝐳_i^{SPK}，我们学习一个 OoD 检测器 g_SPK:𝐳_i^{SPK}→{0,1} 来确定预测应被保留还是拒绝。具体而言，g_SPK​(𝐳_i^{SPK})=1 表示预测 p_i 被作为 OoD 诱导的幻觉拒绝，而 g_SPK​(𝐳_i^{SPK})=0 表示该预测作为 ID 预测被保留。
在实践中，g_SPK 可以应用于不同的 OoD 检测方法，例如 KNN (38) 和孤立森林 (22)。通过将 OoD 检测与原始检测器特征解耦，SPK 使得最终决策能够基于显式提取和结构化的检测器先验来做出。
实验
在本节中，我们从两个角度全面评估了 SPK：在底层目标检测器不变的情况下的 OoD 检测，以及针对修改目标检测器参数的方法的 OoD 幻觉缓解。该评估在不同的目标检测架构和基准设置下进行。
实验设置
OoD 检测
我们遵循最近引入的校准评估协议 (48)，该协议消除了 OoD 评估中潜在的测试污染。此外，该基准考虑了三种具有代表性的目标检测架构，包括 YOLO (40)、Faster R-CNN (30) 和 RT-DETR (51)，涵盖单阶段、双阶段和基于 Transformer 的检测器。我们在两个 ID 检测任务 PASCAL-VOC (9) 和 BDD-100K (50) 上进行评估，包含两类 OoD 测试样本：Near-OoD 和 Far-OoD。Near-OoD 样本与 ID 类别具有视觉相似性，而 Far-OoD 样本表现出更大的语义和视觉差异。基线方法包括 MSP (15)、EBO (23)、MLS (14)、MDS (18)、BAM (47)、SCALE (49)、KNN (38)、iForest (22) 和 Proximal-OoD (48)。
我们采用两个互补的评估指标。首先，我们报告标准的 OoD 检测指标，包括 AUROC 和 FPR95，其中 FPR95 表示 ID 样本在 95% 真阳性率下的假阳性率。其次，我们报告 OoD 诱导幻觉数量的减少，这使得能够与修改底层目标检测器的强 OoD 缓解方法进行比较。特别是，我们与 (48) 进行了比较，该方法通过目标检测器微调显著改善了 OoD 幻觉缓解，并代表了该评估设置的强基准。
对于由于架构特定设计或实现不可用而难以应用于校准基准的 OoD 检测方法，尽管 (48) 中提到了其已知的标注问题，我们还是在这些方法采用的未校准基准下额外评估了 SPK。我们遵循 (28) 的配置，该配置考虑了在 PASCAL-VOC 和 BDD-100K 上的 Deformable-DETR (53) 以及在 PASCAL-VOC 上的 Faster R-CNN，并以 MS-COCO (21) 和 OpenImages (16) 作为 OoD 测试集。SPK 通过利用检测器内在先验实现了具有竞争力的性能。基于 DINO 的变体通过用更强的外部视觉表示替换上下文先验进一步改善了结果。完整的比较结果在附录 A.5 未校准基准上的实验结果 中提供。
先验提取
对于语义先验提取，我们训练了一个轻量级的四层残差卷积头，该卷积头将每个检测器 RoI 特征解码为空间概念逻辑图形式的部件级语义响应，对应词汇表中的每个概念都有一个。由于相关概念因目标类别而异，我们为每个 ID 类别训练一个语义提取头。每个头使用提前停止训练最多 80 个 epoch。例如，在 10 类 BDD 数据集上训练所有头在单个 NVIDIA A100 GPU 40GB 上大约需要一小时。额外的训练细节和定性可视化在附录 部件级语义概念学习 中提供。为了提取上下文先验，我们将整个图像视为 RoI，并使用其通道级空间均值和标准差聚合每个多尺度颈部特征，以形成图像级上下文嵌入。我们根据每张图像中存在的目标类别将这些嵌入组织成特定类别的参考库。更多细节在附录 上下文先验学习 中提供。

结论
在这项工作中，我们提出了结构化先验知识（SPK），这是一个主动框架，它从预训练的目标检测器中显式提取潜在先验以进行 OoD 检测。通过将这些先验组织成紧凑且可解释的表示，SPK 能够在不修改底层检测器的情况下实现有效的 OoD 检测和幻觉缓解。在多种目标检测器架构和基准设置上的广泛实验证明了所提出框架的有效性和通用性。除了框架本身，我们的结果还表明，预训练的目标检测器编码了比通常用于 OoD 检测的丰富得多的知识。SPK 表明，这些潜在先验可以被显式提取到一个可解释的知识空间中，而不是从原始高维检测器特征中学习新的表示，其中每个维度对应于一个语义上有意义的量。我们相信这项研究将先验提取确立为 OoD 检测的一个有前途的主动方向，并表明暴露潜在模型知识可能为提高基础模型的可靠性和可解释性提供通用策略。
虽然这项工作主要集中在 OoD 诱导幻觉的两个代表性来源，即近端 OoD 目标和背景诱导的错误预测，但所提出的先验提取框架可以自然地扩展到额外的幻觉来源和更广泛的可靠性挑战。未来的工作将研究如何揭示更丰富的潜在先验，以及如何更好地利用提取的知识来防止 OoD 幻觉的生成。

A.1 数据准备
近端挖掘
近端 OoD 目标是检测器幻觉的主要来源之一，因为它们与 ID 类别共享语义或视觉特征。为了整理此类数据，我们遵循 (48) 中引入的提示设计，并查询 GPT-5 为每个 ID 类别生成一组近端类别集。所提出的近端类别应与 ID 类别不相交，同时在语义或视觉上与相应的 ID 类别相似。对于每个 ID 类别，我们使用获得的近端类别集从 Objects365 (34) 中检索 1,000 张带标注的图像，Objects365 是一个涵盖各种目标类别的大规模目标检测数据集。由于我们的评估基准是从 Open Images V7 (3) 构建的，因此使用 Objects365 作为训练数据的来源有助于避免任何数据泄露问题。我们在这些图像上运行目标目标检测器，并保留诱导幻觉 ID 预测的图像。
背景挖掘
当目标检测器遇到具有与 ID 目标相似的纹理或局部线索的背景时，目标检测中的 OoD 幻觉也可能发生。为了捕获这种失败模式，我们从可描述纹理数据集 (DTD) (5) 中收集纯背景样本。DTD 是一个图像级纹理识别数据集，包含各种真实世界的纹理模式，使其成为探测背景诱导检测器幻觉的良好来源。由于 DTD 是一个没有目标级标注的图像分类数据集，并且可能包含 ID 目标，我们首先使用 YOLOE-11-L (41) 过滤掉包含 ID 目标的图像。
部件级自动标注
图 3：
自动部件级标注流水线。
给定一个 RoI 裁剪及其目标类别，OWLv2 将相应的 GPT-5 生成的概念词汇定位到部件边界框中。每个框提示 SAM 2 生成精细的像素级部件掩码。满足目标掩码覆盖阈值的掩码被投影到检测器 RoI 坐标中，并光栅化为二进制 7×7 目标。没有保留掩码的概念接收全零目标。
为了训练语义提取头，我们需要部件级语义标注，以捕获与目标检测器预测相关的视觉证据。由于手动标注此类概念既费时又难以扩展，我们开发了一个自动部件级标注工具（如图 4 所示），以高效地生成所需的监督。给定一个目标类别，我们的工具首先遵循 (27) 的提示设计查询 GPT-5，以生成视觉上可定位的部件级概念的紧凑词汇表。例如，对于类别鸟，生成的概念包括喙、眼睛、翅膀、躯干和脚。然后，该工具使用 OWLv2 (26) 在相应的感兴趣区域 内定位每个概念。每个定位的部件随后由 SAM 2 (29) 精细化为像素级分割掩码。为了抑制背景诱导的标注，仅当生成的部件掩码中至少 70% 的像素与 SAM 2 预测的相应目标掩码重叠时，才保留该掩码。最后，每个保留的部件掩码被投影到目标检测器 RoI 坐标中，并转换为用于训练语义提取头的概念级监督。没有有效标注的概念被分配为空监督。
我们在表 5 中评估了所提出的标注工具的质量。我们的工具始终优于现有的自动部件标注方法，实现了最高的总体平均交并比 和 Recall@0.5。与最强的基线 VLPart (37) 相比，它将 mIoU 和 Recall@0.5 分别提高了 3.8 和 1.6 个百分点。这种改进在不同目标类别中是一致的，我们的工具在七个评估类别中的六个上实现了最佳的概念 mIoU。这些结果表明，所提出的工具可以自动生成准确的部件级语义标注，使得语义提取变得实用，而无需大量的手动标注。

A.2 先验提取的实现细节
多尺度 RoI 特征提取
我们的语义提取头的一个重要要求是重建每个检测到的提议内部的空间概念证据，这使得提议级表示的选择变得至关重要。设 p_i=(𝐛_i, y_i) 表示检测器预测，𝐅_i 表示与其预测边界框 𝐛_i 关联的 RoI 特征。
对于 YOLO 和 RT-DETR，我们从三个空间特征级别提取特征，表示为 {𝐄^ℓ}{ℓ=1}^L，其中 𝐄^ℓ∈ℝ^{C_ℓ×H_ℓ×W_ℓ}。具体而言，我们使用 YOLO 的检测颈部输出和 RT-DETR 的多尺度混合编码器输出。对于后者，我们使用混合编码器特征而不是最终的解码器查询，因为解码器查询没有在预测边界框内定义规范的空间网格 (51)。
对于每个预测，RoIAlign 独立应用于每个特征级别：
𝐅_i^ℓ=RoIAlign(𝐄^ℓ,𝐛_i;7×7)∈ℝ^{C_ℓ×7×7}.
(3)
然后沿通道维度连接多尺度 RoI 特征：
𝐅_i=Concat{ℓ=1}^L(𝐅_i^ℓ)∈ℝ^{D×7×7}, D=∑{ℓ=1}^L C_ℓ.
