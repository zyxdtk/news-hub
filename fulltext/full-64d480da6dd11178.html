摘要
本文提出了一种用于绳索辅助机器人攀爬垂直表面的运动规划流程框架。该框架被表述为一种双层优化方案，用于解决混合整数问题：在优化控制输入（即绳索张力和腿部作用力）及着陆位置的同时，选择可行的地形区域进行着陆。优化外层使用交叉熵方法求解，而内层则依靠基于梯度的非线性优化来计算动态可行的运动。该方法在新型攀爬机器人平台 ALPINE 上进行了验证，涵盖了多种具有挑战性的地形配置。

I 引言与相关工作
在山区环境中作业的机器人系统面临着由环境恶劣带来的诸多挑战，包括严酷的气候条件和高度多变的地形形态 [12, 13]。特别是攀爬机器人，已被用于在不平坦的地形中导航，一些系统采用了替代的运动策略，如绳索，以攀登极其陡峭或垂直的表面 [18, 8, 4]。然而，虽然绳索使得能够进入原本无法到达的空间，但由于几个因素，它们增加了规划和控制策略的复杂性，最显著的是由于重力下绳索张力的单边性引起的欠驱动。尽管文献中有几项工作涉及攀爬腿式机器人的运动和接触规划 [1]，但明确纳入绳索及其影响的数量有限。例如，在 [9] 中，采用最优控制来规划由单绳锚固的腿式系统动态索降的运动和接触，使用了模板模型。在 [5] 中，研究了绳索弯曲对攀爬系统的影响。[8] 涉及为名为 ALPINE 的新平台生成可行的摆动运动，结合腿部和可调节绳索的作用将起始位置连接到着陆位置。

关于接触规划策略，一类包括接触隐式方法 [14, 10]，它们将机器人动力学建模为混合动力系统。为了使由此产生的优化问题在计算上易于处理，这些方法通常依赖于互补约束的松弛 [11]。第二类方法在优化中显式参数化接触位置，产生混合整数非线性规划 [3]。虽然这种表述能够对离散接触决策进行直接推理，但其计算复杂度随候选接触点的数量呈指数级增长。

图 1：(左) ALPINE 机器人在粗糙墙壁上执行多跳机动的动力学仿真；(右) 机器人在第一次中间（向下）跳跃期间的特写。参考轨迹显示为白色，而绿色标记表示中间着陆目标。绳索描绘为绿色，红色箭头表示瞬时拉力。

混合方法试图通过预选一部分步态或接触参数同时优化其余变量来桥接这两种方法。一个特别有前景的方向是使用双层混合优化框架，该框架结合了黑盒优化和基于优化的运动规划，能够为给定的运动任务独立发现可行的接触序列 [17, 6]。因此，尽管关于运动和接触规划的现有文献非常广泛，但当针对物理和环境约束下的绳索辅助机器人制定相同问题时，受到的关注相对较少。

贡献。在这方面，本工作提出了一种计算高效的算法，用于规划由绳索辅助的攀爬机器人的跳跃运动序列，明确考虑了硬件的物理限制和环境的约束。我们将同时进行接触和运动规划的问题表述为双层嵌套优化，包含离散和连续决策变量：
• 外循环由一个黑盒优化器组成，通过将环境划分为离散面片来处理接触调度（跳跃次数）和面片选择；
• 内循环由基于梯度的优化组成，试图在选定的面片内提供可行的跳跃轨迹和接触位置。
所提出的规划策略的有效性在多种地形和涉及 ALPINE 机器人的动力学仿真中进行了测试，如 [8] 所示。

本文组织如下：第 II 节介绍了特定的 ALPINE 机器人运动学和动力学模型，以及用于定义环境面片的代价地图；第 III 节介绍了双层优化策略及其组成部分；第 IV 节展示了规划和仿真实验；最后，第 V 节提供结论并讨论未来工作。

ALPINE 机器人的完整详细模型是欠驱动的，需要考虑完整运动学环路约束。然而，通过忽略角动力学并假设质量集中在质心，加上绳索始终保持紧绷的额外假设，可以采用降阶（3自由度）模型。在此公式中，完整约束通过适当选择广义坐标消除，即 𝐪_r = [ψ l_1 l_2] ∈ ℝ^3，其中 ψ 是绳索定义的平面与通过锚点的垂直平面之间的夹角，l_1、l_2 分别是左绳和右绳的长度。连接到左锚点的惯性系 𝒲 中，机器人的动力学为：
m(𝐩¨ − 𝐠) = 𝐟_rl + 𝐟_rr + 𝐟_leg (1)
其中 𝐚̂_ri = (𝐩 − 𝐩_ai) / ‖𝐩 − 𝐩_ai‖ ∈ ℝ^3 且 f_ri ∈ ℝ，i = {r, l}，分别是绳索轴线和施加力的大小，两个锚点位置分别由 𝐩_al 和 𝐩_ar 定义 1。机器人位置 𝐩（基座连杆原点）的正运动学表达式作为 𝐪_r 的函数给出：
𝐩(𝐪_r) = [p_x; p_y; p_z] = [l_1 sin(ψ) sqrt(1 − (d_a^2 + l_1^2 − l_2^2)^2 / (4 d_a^2 l_1^2)); (d_a^2 + l_1^2 − l_2^2) / (2 d_a); -l_1 cos(ψ) sqrt(1 − (d_a^2 + l_1^2 − l_2^2)^2 / (4 d_a^2 l_1^2))] (2)
对状态变量进行二次微分，可以得到降阶模型的最终方程 (3)（详见 [8]），其中完整约束由于坐标 𝐪_r 的特定选择而（通过构造）嵌入：
[ψ¨; l¨_1; l¨_2] = 𝐀_d^{-1} [1/m 𝐟_tot − 𝐛_d] (3)
降阶模型在 [8] 中被证明是真实系统的良好近似，足以生成不涉及大方向变化的可行跳跃轨迹。

II-B 代价地图
关于机器人作业的地形（例如岩壁），所提出的规划框架依赖于从获取的地形高度图导出的综合代价地图。我们假设输入的地形点云已经过预处理，如异常值剔除和修复，以去除虚假测量并填补缺失区域，从而消除孔洞并确保空间一致的表示。然后将得到的稀疏点云插值为连续表面表示。这一步使得能够应用具有多个卷积核的卷积运算，其输出随后被映射到地形每个点的特定代价值。除了评估表面形态的滤波器外，我们还结合了相对于机器人锚点的基于距离的代价。该项严重惩罚相对于机器人锚点位置明显更深的区域，因为它们会导致机器人产生静态不可行的构型（无法应对悬垂）。地形划分为面片的详细程度是根据地图尺寸手动选择的。对于每个候选落脚点，我们计算一个质量分数，定义为坡度和粗糙度指标的线性组合，从上述滤波器获得。高度图中的每个单元都与着陆代价 c_l(Y, Z) 相关联，表示着陆位置的质量，是不同质量指标的线性组合：
c_l(Y, Z) = ∑_i w_cm,i c_i, (4)
其中 𝐰_cm = [w_sl w_sd w_d] 表示分配给形态滤波器和质量指标的权重向量：
• w_sl（坡度滤波器）：与一阶导数相关的滤波器，用于惩罚坡度。
• w_sd（粗糙度滤波器）：与二阶导数相关的滤波器，用于惩罚曲率的突变。
• w_d（深度滤波器）：严重惩罚锚点垂直面内部的区域。

III 方法
所提出的规划算法基于双层优化方案。外循环采用无梯度的交叉熵方法 (CEM) 来处理整数变量，如面片选择和跳跃次数。内循环执行非线性轨迹优化，以计算与外优化选择的跳跃次数相对应的一组轨迹，同时尊重欠驱动、硬件和绳索约束，并同时确定选定面片内着陆接触的最佳位置。流程的框图如图 4 所示。

图 4：ALPINE 机器人的双层多跳优化流程框图。

这种表述使内循环能够规划物理上一致的运动和着陆位置，而外循环则根据能量消耗、内循环收敛质量和地形代价信息，选择最少的中间跳跃序列和着陆面片以连接起点和目标。我们用 𝒟 表示整数决策变量集，即跳跃次数 n ∈ ℤ^+, n ≥ 1 和选定中间面片的索引 𝝅 ∈ ℤ^{n−1}：
𝒟 = {n, 𝝅} (5)
注意 𝝅 的维度是 n−1，因为假设目标位置已知。每次迭代求解的双层优化问题具有以下形式：
min_𝒟 ℱ(𝒟) = {f(𝒟_0), f(𝒟_1), …, f(𝒟_{I−1})} (6)
s.t. n_i ≥ 1, ∀ i ∈ I,
𝝅_i ∈ 𝚷_ID, ∀ i ∈ I,
其中 I 表示每次迭代中种群个体的数量，𝒟_i 是与个体 i 相关的离散变量集，由跳跃次数 n_i 和所有面片标识符 集合 𝚷_ID 组成。目标是通过从目录 𝚷_ID 中选择最佳跳跃次数和面片 ID 集来最小化代价函数 ℱ(𝒟)。代价 f(𝒟_i) 由两项之和组成：
f(𝒟_i) = f_1(𝒟_i) + f_2(𝒟_i) (7)
第一项是与选定面片 j 相关联的平均地形代价 c̄{t,j} 之和：
f_1(𝒟_i) = w_ac ∑{j∈𝝅_i} c̄{t,j} (8)
这使我们能够排除不良的岩石特征，如裂缝、粗糙点、孔洞等，有利于局部平坦的表面。第二项源于多个非线性最优控制问题 (OCP) 的求解，这些 OCP 由外优化选择的整数变量集 𝒟_i 参数化，将在第 III-B 节中详述。特别地，f_2(𝒟_i) 由在选定面片之间跳跃所消耗的累积能量 c_e（权重为 w_e）组成。如果对于每个子跳跃发生约束违反和/或不收敛，则返回高惩罚 w_p。
f_2(𝒟_i) = { ∑{j=1}^n w_e c_{e,j}, 如果 ∀ j OCP_j 收敛; w_p, 如果 ∃ j: OCP_j 不收敛 } (9)
时间不被视为最小化的特征，因为它与能量消耗相关，优化可能会利用更长的跳跃来适应绳索力大小中更严格的约束。例如，考虑向上跳跃：绳索有限的驱动能力强烈限制了可实现的向上加速度，因此需要更强的腿部推力。这种增加的冲量使机器人能在空中停留更长时间，从而达到所需的垂直位移。每当在面片选择中检测到循环时，即在同一跳跃序列中同一面片被访问两次或多次时，代价 f_2(𝒟_i) 被赋予一个大惩罚而不执行内循环优化。这避免了不必要的计算，并降低了此类候选解在采样期间被青睐的可能性。

III-A 外层优化：交叉熵方法
我们的双层优化框架的外循环采用 CEM，因为它能够处理整数变量和任意的、不可微的代价函数，并收敛到概率分布，其质量集中在接近最优解的区域 [15]。

算法 1 用于接触选择的交叉熵方法
1: procedure CEM(N_iter, N_elites, K, ℱ)
2: 初始化概率 𝒓^[1]
3: for iter = 1 → N_iter do
4: 𝒟 = {𝒟_1, …, 𝒟_I}, 𝒟_i ∼ Cat(K, 𝒓^[k])
5: ℱ(𝒟) = {f(𝒟_1), …, f(𝒟_I)}
6: 𝒟_elite = {𝒟_1_elite, …, 𝒟_{N_elites}^elite}
7: for i = 1 → K do
8: 𝒓^[iter+1] = count_occurrences(K_i, 𝒟_elite) / N_elites
9: end for
10: end for
11: end procedure

如算法 1 所示，CEM 是一种黑盒优化方法，将最优解建模为参数化概率分布，在我们的例子中是分类分布。在每次迭代中，它生成一个种群成员样本，即跳跃次数和面片 ID（算法 1.4），并评估它们的代价（算法 1.5），如 (7) 所示。给定一定比例的最佳表现候选者，每个类别的概率 𝒓 更新为精英选择它的次数的算术平均值（算法 1.8）。在 CEM 的每次迭代中，选择一定比例的最适应成员（精英），以更新分布参数从而收敛到 (6) 的解。

III-B 内层优化
外循环优化确定中间跳跃的次数以及机器人必须着陆的相关面片集以达到目标。本节的目的是描述如何用从一个面片到下一个面片的可行跳跃运动计划连接它们，并在每个面片内选择/青睐具有最低代价的着陆位置。外循环输出向量的第一个分量指定了跳跃次数 n ≤ n_max。由于种群中的所有个体必须共享相同的维度，因此仅评估离散决策向量的前 n 个元素。这些元素编码了与中间着陆相关联的面片 ID。对于每个选定的面片，其质心 𝐩_{c,i} ∈ ℝ^2 和相应的代价函数 c_i(·) 作为相关中间跳跃的轨迹优化的输入提供。跳跃按级联顺序求解：第一次跳跃的离地位置与机器人的起始位置重合，随后的所有跳跃的离地位置与前一次的着陆位置重合。

为 ALPINE 机器人规划运动具有挑战性，因为机器人的动力学高度非线性，且腿部推力是脉冲式的并受摩擦限制。因此，我们将机器人的运动规划表述为非线性 OCP，转录为有限维非线性规划 (NLP)，其中我们将绳索力沿水平线离散为 N 个节点，时间间隔 dt = t_f/N，状态变量 𝐗 = [𝐱_0, …, 𝐱_N]，控制 𝐔 = [𝐮_0, …, 𝐮_{N−1}] 2：
min_{𝐗,𝐔,t_f} ∑{k=0}^{N−1} ℓ(𝐱_k, 𝐮_k) + ℓ_f(𝐱_N) (10a)
s.t. 𝐱_0 = 𝐱̂_0, (10b)
𝐱{k+1} = int(𝐱_k, 𝐱̇k), ∀ k ∈ [0, N), (10c)
𝐡_k(𝐱_k, 𝐮_k) ≤ 0, ∀ k ∈ [0, N), (10d)
𝐠_k(𝐱_k) ≤ 0, ∀ k ∈ [0, N], (10e)
其中 ℓ(𝐱_k, 𝐮_k) 和 ℓ_f(𝐱_N) 是运行代价和终端代价，(10c) 是 (3) 中降阶机器人动力学的积分离散版本，(10d) 和 (10e) 是路径约束，(10b) 是边界条件。控制输入包括绳索力和腿部冲量 𝐮_k = [f{rl,k}, f_{rr,k}, 𝐟_{leg,k}] ∈ ℝ^5。注意 𝐟_leg ∈ ℝ^3 仅在跳跃开始时的短推力阶段（t ≤ t_th ∈ ℝ）施加 3。状态是第 2 节中介绍的降阶模型的广义变量及其一阶导数：𝐱_k = [ψ_k l_{1,k} l_{2,k} ψ̇k l̇{1,k} l̇{2,k}]^T ∈ ℝ^6 (11)。因此，以仿射输入形式 [8] 转换的非线性动力学 (3) 的状态空间表示可以推导为：
𝐱̇_k = 𝐟(𝐱_k) + 𝐠(𝐱_k)𝐮_k, (13)
其中：
𝐟(𝐱_k) = [ [ψ̇_k l̇{1,k} l̇{2,k}]^T; 𝐀_d(𝐱_k)^{-1} (𝐠 − 𝐛_d(𝐱_k)) ], (14)
𝐠(𝐱_k) = [ 𝐎{3×1} 𝐎_{3×1} 𝐎_{3×3}; 𝐀_d(𝐱_k)^{-1} 𝐚̂{rl} 𝐀_d(𝐱_k)^{-1} 𝐚̂{rr} 1/m 𝐈_{3×3} ] (15)
最后，我们还将跳跃持续时间 t_f ∈ ℝ 视为决策变量。为了求解 (10) 中的优化问题，我们使用单次打靶法消除了可由控制 𝐔 表达的相关状态变量 𝐗。特别地，我们通过 Runge-Kutta 4 (RK4) 方法从初始状态 𝐱_0 = 𝐱̂0（边界条件）开始积分动力学，从输入 𝐮_k 计算状态向量 𝐱{k+1}，直到水平线结束，而时间 t_f 限制为正。

状态约束。状态约束与不可达的操作空间区域有关。添加了约束以防止在整个跳跃期间与墙壁网格发生碰撞。由于岩壁可能具有不规则的形状，或者存在机器人应克服以到达最终目的地的障碍物，我们将不可达区域建模为边界为表面的区域。我们假设该表面可以表示为由 Q(𝐱) = 0 表示的平滑二维流形。因此，允许区域通常由 Q(𝐱) ≥ 0 给出，并且可能是非凸的。考虑在点 (Y, Z) 处插值网格的函数 f_mesh(.)，见图 2(a)，约束可以表示为：
p_X(𝐱_k) ≥ f_mesh(p_Y(𝐱_k), p_Z(𝐱_k)), ∀ k ∈ [0, N] (16)
此外，我们发现鼓励间隙 h ∈ ℝ 是有用的，包括一个不等式，例如在跳跃轨迹持续时间的中间：
𝐧_c^T 𝐩(𝐱_{N/2}) ≥ h, (17)
其中 𝐧_c 是接触位置的地形表面法线，计算为：
𝐧_c = ∇F / ‖∇F‖, (18)
其中 F = 0 是定义空间中地形二维曲线的参数函数。在我们的具体情况下，由于图 3(a) 中惯性系的定义，我们将曲线定义为 Y, Z 平面上的标量场 F = f_mesh(Y, Z) − X：
𝐧_c = [−1 ∂f_mesh/∂y ∂f_mesh/∂z]^T / sqrt(1 + (∂f_mesh/∂y)^2 + (∂f_mesh/∂z)^2) (19)

着陆点优化。我们通过优化中间跳跃在地形网格（即高度图/体素图）上的着陆位置，改进了 [8] 中的原始问题表述。为此，我们约束求解器在当前跳跃选定的着陆面片内搜索着陆位置 (20a)，而 (20b) 强制与网格的一致性：
𝐩_{c,i} − 𝐝/2 ≤ 𝐩_{Y,Z}(𝐱_N) ≤ 𝐩_{c,i} + 𝐝/2, (20a)
‖p_X(𝐱_N) − f_mesh(p_Y(𝐱_N), p_Z(𝐱_N))‖ ≤ ϵ, (20b)
其中 𝐝 表示第 i 个面片沿 Y 和 Z 方向的大小，𝐩_{c,i} ∈ ℝ^2 表示第 i 个面片中心位置的 Y, Z 坐标，ϵ ≥ 0 是固定的松弛参数。与优化选择的着陆位置相关的地形代价将在目标 (26) 中考虑。由于外循环决定的跳跃序列中，最后一次跳跃必须着陆在期望的目标位置 𝐩_f，着陆约束 (20) 被替换为：
‖𝐩(𝐱_N) − 𝐩_f‖ ≤ ϵ (21)

驱动约束。沿各自绳索轴线 𝐚̂{rl}, 𝐚̂{rr} 方向作用的力，见第 2 节，不能推动机器人，而腿不能拉扯岩壁：
𝐧_c^T 𝐟_{leg,k} ≥ 0, 𝐟_{r,k} ≤ 𝟎, ∀ k ∈ [0, N), (22)
其中 𝐟_{r,k} = [f_{rl,k}, f_{rr,k}]^T。此外，绳索力和腿部冲量都受驱动限制和二阶摩擦锥的约束：
‖𝐟_{leg,k}‖ ≤ f_{leg,max}, ∀ k ∈ [0, N), (23)
−𝐟_{r,k}^{max} ⪯ 𝐟_{r,k}, ∀ k ∈ [0, N), (24)
‖𝐭_x^T 𝐟_{leg,k} + 𝐭_y^T 𝐟_{leg,k}‖ ≤ μ 𝐧_c^T 𝐟_{leg,k}, ∀ k ∈ [0, N), (25)
其中 μ 是摩擦系数，𝐭_x 和 𝐭_y 是垂直于接触法线的单位向量。我们观察到，强烈减小 𝐟_{r,max} 会鼓励机器人更多地依赖其腿部并进一步脱离墙壁，在空中花费更多时间，从而给绳索卷扬更多时间加速。

目标函数。我们不考虑任何特定的终端代价。对于运行代价，我们使用绳索力的平滑项，惩罚卷扬功（即卷绕/展开绳索所做的功）的第二项，以及最小化着陆位置地形代价的第三项。因此，代价函数为：
J = w_s ∑{i∈{r,l}} [∑{k=0}^{N−1} (𝐟_{ri,k} − 𝐟_{ri,k−1})^2 + w_{hw} ∑{k=0}^{N−1} |𝐟{ri,k} 𝐥̇{i,k}| T_s] + w_l c_l(𝐩(𝐱_N)), (26)
其中 c_l(.) 是评估特定位置代价的函数，w_s、w{hw} 和 w_l 是与这三个代价相关的权重。时间 t_f 使用围绕初始位置 𝐩_0 线性化的系统时间常数进行初始化。绳索力初始化为零，腿部冲量初始化为 𝐟_{leg,max}。

对外层优化代价的贡献。从内循环优化的输出中，我们计算多次跳跃的累积代价值 f_2 (9)：1) 总能量消耗 c_{e,j}，2) 评估内循环计算轨迹最后一点的着陆位置的点代价，以及 3) 收敛程度。第 j 次跳跃的总能量消耗将是卷扬功（第一项）和由于推力作用产生的推力功（第二项），即从静止开始的离地动能：
c_{e,j} = ∑{i∈{r,l}} ∑{k=0}^{N−1} |𝐟_{ri,k} 𝐥̇k| T_s + 𝕀{t∈[0,t_{th}]} 1/2 m 𝐩̇(𝐱_k)^T 𝐩̇(𝐱_k), (27)
其中 𝕀_{t∈[0,t_{th}]} 是选择满足 0 ≤ t_k ≤ t_{th} 的样本 k 的指示函数。

本节展示了仿真结果，演示了所提出的框架如何使机器人能够沿山壁导航。我们展示了 3 个实验，我们将优化输出应用于：1) 一个大的半球形障碍物，以展示将跳跃分割为更小中间跳跃的能力，2) 凸起地形，以展示我们的方法避免复杂障碍物模式的能力，3) 岩壁模板，我们在真实的仿真环境中使用 MPC 控制器跟踪优化结果。实验在一台配备 20 核 Intel Core 7 CPU（时钟频率可达 4.9 GHz）的笔记本电脑上进行。我们修改了 CEM 算法，使得每个类别（即跳跃次数和面片 ID）都有被选中的最小非零概率。这种机制作为一种学习率正则化形式，防止精英样本过度主导概率更新，从而保持探索并避免过早收敛到局部最小值。此外，我们发现通过注入一定比例的遵循连接起始和目标位置的直线路径的精英来偏置算法的初始迭代是有益的。这代表了一种合理的启发式方法，将为面片 ID 概率提供良好的初始猜测。然后算法继续通过在该初始路径周围移动来导航可能的障碍物。还应注意的是，由于 CEM 中的每次评估都是独立的，它们可以并行计算以改善我们框架的总执行时间。内循环优化最初在 Matlab 中使用 fmincon 函数实现。为了提高性能，我们使用了 C++ 实现的 OCP 用于运动规划和控制。外循环优化用 Python 编写，利用多线程进行并行化。其中每个线程运行内部循环组合的独立实例，并且仅通过受锁保护的共享汇总统计信息进行通信。我们使用高斯滤波器等基元生成了三个实验的高度图，以创建模拟柱子的凸起。在实验 3 中，我们在局部重塑了地图以形成山脊和二面角，产生高方向梯度，并添加了具有 Perlin 结构的多尺度分形噪声，以模拟跨多个空间频率的表面粗糙度。生成的每个实验的高度图大小为 10×20 m，网格分辨率为 0.5 m，路径间距为 1 m。然后将高度图传递给第 II-B 节中描述的代价地图滤波器。使用双线性插值在查询点上获得平滑函数。内循环优化和仿真的参数报告在表 I 中。源代码公开于：https://anonymous.4open.science/r/climbing_robots2-3D28

IV-A 用例 1：半球形障碍物
我们首先在一种场景中评估我们的框架，机器人必须通过多次中间跳跃找到从起点到目标的可行路径。这种约束要么来自物理硬件限制，要么来自阻碍单次大跳跃的障碍物。在此设置中，半球形障碍物位于机器人初始位置和上方目标之间。目标位于起点上方，要求机器人执行向上跳跃，由于没有重力帮助，这更容易触及驱动边界。因为机器人无法在单次向上跳跃中越过障碍物，它必须执行一系列跳跃来绕过它，见图 5 (左)。如图 6 (上图) 所示，CEM 求解器探索了几次跳跃，适应度在 4 次迭代后收敛到 321.3 的值，见图 6 (下图)。

IV-B 用例 2：多凸起地形
在这个用例中，我们测试了我们的方法在产生可行无障碍计划方面的有效性。以下用例中的目标位于起点下方（见图 5 (中)），机器人在 YZ 起始姿态 𝐩_0 = (6.556, -18.49) m 和目标姿态 𝐩_f = (2.47, -6.3) m 初始化，因此机器人将执行向下跳跃。这样，我们期望机器人由于重力的帮助执行更少的跳跃，但途中复杂障碍物模式的存在需要至少 3 次跳跃。多跳序列的总持续时间为 9.45 秒。

IV-C 用例 3：岩石地形 Gazebo 仿真
最后，我们在真实的岩壁上评估了我们方法的有效性，通过在高保真 Gazebo 环境中使用模型预测控制 (MPC) 控制器模拟机器人跟踪优化的多跳序列，见图 1。仿真使用 ODE 物理引擎 [16] 计算完全受约束的机器人动力学。结果行为的可视化在补充视频中提供。我们采用 URDF 形式描述机器人模型，并使用 Pinocchio 库 [2] 计算运动学函数。我们想从 𝐩_0 = (2.5, -6) m 跳跃 20 m 到 𝐩_f = (4.5, -17) m，我们故意设置驱动约束 f_{leg}^{max} = 150 N 和 f_r^{max} = 60 N，使得机器人无法通过单次可行跳跃到达 𝐩_f。给定岩壁的网格，我们求解双层优化问题以找到中间跳跃的最佳着陆位置。我们没有严格遵循相应的计划轨迹（这可能由于不完美的控制器跟踪导致误差累积），而是在着陆后使用机器人的实际着陆位置作为新的初始条件重新优化每次跳跃。每次优化提供每次跳跃的初始腿部冲量、绳索力模式和跳跃持续时间的值。仿真以 1 kHz 运行，由于优化的轨迹具有不同的时间离散化 (d_t = t_f/N)，根据跳跃持续时间 t_f，执行适当的插值以适应速率差异。每次跳跃由一个状态机调节，该状态机排序一组阶段，即腿部重定向、推力、飞行和着陆。在推力阶段，我们通过在接触点施加力 𝐟_c 在质心处产生推冲量 𝐟_{leg}。由于 𝐟_{leg} 施加在推力腿尖端，为了避免在质心处产生力矩，我们执行伸缩腿的预定向，使其与 𝐟_{leg} 的方向对齐。在飞行阶段，绳索（平动）关节在力控制模式下驱动。离地后，腿不再影响基座的线性运动；因此，在飞行阶段，MPC 作用叠加在优化的力分布上，以消除干扰并最小化飞行期间相对于参考轨迹的跟踪误差 [8]。由于机器人在空中时在垂直于绳索平面的方向上没有控制权限，控制器还命令安装在机器人背面的螺旋桨的推力 f_p 以调节 ψ 状态 [8]。螺旋桨沿基座连杆 X 单位轴 𝐱̂_b ∈ ℝ^3 产生力 𝐱̂_b f_p，该轴垂直于绳索平面。对于控制计算，我们使用稍微修改的降阶模型，其中项 𝐱̂_b f_p 被添加到 (1) 的右侧。在每次中间跳跃后，假设机器人的速度被伸缩腿上的阻抗控制器完全耗散。

V 结论
我们提出了一种基于双层优化的运动和接触规划器，用于导航复杂的地形环境，如山区。外优化层依赖 CEM，而内循环制定 OCP 以从给定的地形表示自主计算接触时间表、接触位置和运动轨迹。我们通过支持任意地形网格和使用地形代价地图优化着陆位置，扩展了 [8] 中引入的原始问题表述。该规划器与基于 MPC 的控制器耦合，并使用 ALPINE 机器人在仿真中进行了验证。尽管在此特定平台上进行了演示，该框架通过调整内循环优化中使用的动力学模型，很容易推广到其他机器人系统。框架目前的局限性包括对缆绳的处理，其穿透障碍物的可能性尚未考虑，以及缺乏考虑为驱动腿部的气动活塞供气的气瓶消耗水平的适应度项。我们计划在未来的工作中考虑这些方面，并在真实硬件上进行实验。
