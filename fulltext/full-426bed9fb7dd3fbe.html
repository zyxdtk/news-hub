摘要

决策模型通过在单次前向传播中对候选答案进行评分，实现快速且具备置信度感知的决策，无需生成文本或中间推理。然而，推理能够显著提升决策质量，这就引出了一个问题：能否在不承担生成推理成本的情况下保留其收益。我们借助 GLiDE 对这一问题进行了研究，GLiDE 是一个涵盖 0.4B 至 27B 参数的决策模型家族。

基于 Qwen 混合语言模型，GLiDE 通过移除全注意力层的因果掩码，使上下文、问题和候选答案之间能够进行双向交互。为了将推理能力迁移到单次前向推理中，我们将来自多个教师（包括一个推理模型）的软目标蒸馏与在多样化决策任务上的渐进式后训练相结合。我们还探索了无参数循环深度，以在不生成 token 的情况下增加推理时计算量。

在五种模型规模上，GLiDE 均位于 Hugging Face 决策指数的性能–参数帕累托前沿之上，每个模型都优于同等或更小规模的已评估替代方案。

GLiDE V1.2（27B）在 Hugging Face 决策指数（0.4.1 版，2026 年 10 月 22 日）上排名第一，隐藏集得分为 71.52，期望校准误差为 2.0%，单 GPU 中位延迟为 92.9 毫秒。它还在 Artificial Analysis 决策指数的全部三个版本（2026 年 11 月 5 日、8 日和 15 日）上并列第一。这两个排行榜均由其维护者运行，他们亲自在模型开发者无法看到的测试集上评估每个模型：Hugging Face 上完全隐藏，Artificial Analysis 上部分私有。进一步的检查点平均与无参数循环深度得到了 GLiDE 27B，其得分达到 73.37，期望校准误差为 2.1%。

1 引言

决策模型与推理差距。
大语言模型的应用已不仅限于生成文本，还越来越多地用于做出决策：选择工具、路由请求、对输入进行分类，以及在预定义动作中做出选择。在这些场景中，逐 token 生成答案往往是不必要的。决策模型转而在单次前向传播中对候选答案进行评分，产生可用选项上的概率分布。这一方法已经从紧凑的、基于模式条件化的编码器（如 GLiNER2（Zaratiana 等，2025））发展到更大的系统，包括 Jev（TypeSafe AI，2026）、Decider（Perplexity AI，2026）和 Mammoth（Kirkby 等，2026）。然而，一个核心矛盾依然存在：多步推理可以显著提升决策质量，而生成这些推理恰恰引入了决策模型试图避免的顺序计算。因此，挑战在于在保持直接预测速度的同时捕获推理的收益，而不牺牲校准或泛化能力（Tian 等，2023；Xiong 等，2024；Recht 等，2019）。

图 2：GLiDE V1.2 架构。每个决策被编码为单个序列，包含上下文、问题、编码后的候选答案以及答案前缀。从 64 层 Qwen 混合解码器出发，GLiDE 移除了其 16 个全注意力层的因果掩码，在保留 48 个 Gated DeltaNet 层因果循环的同时实现双向交互。一个专用的 255 路读出对最终隐藏状态进行评分，对所提供选项进行 softmax 得到归一化的概率分布。决策在单次前向传播中完成计算，无需生成 token 或中间推理。附录 C 详细说明了输出语义和部署策略。

我们的方法。
我们提出了 GLiDE，一个涵盖 0.4B 至 27B 参数的单次前向决策模型家族。从 Qwen 混合语言模型出发，我们移除了其全注意力层的因果掩码，允许上下文、问题和候选答案进行双向交互，同时保留因果 Gated DeltaNet 层（图 2）。随后，一个专用读出在所提供的选项上产生概率。为了将融合推理的监督迁移到该架构中，我们将来自多个教师（包括一个在推理后评估的模型）的软目标蒸馏与在多样化决策任务上的渐进式后训练相结合。通过这种方式，GLiDE 从推理产生的分布中学习，而无需在推理时生成中间推理。

决策性能与校准。
我们首先在 Hugging Face 决策指数（Passos，2026a）上评估 GLiDE，该指数使用独立管理的隐藏测试集对模型进行排名。在 0.4.1 版（2026 年 10 月 22 日）中，GLiDE V1.2（27B）取得 71.52 的得分，在 225 个模型中排名第一，领先第二名 1.77 分（图 4）。它还在两个隐藏组件上均处于领先，这两个组件分别涵盖来自既有技能的未见问题以及新领域中的决策。伴随这一性能的是 2.0% 的期望校准误差和单块 RTX PRO 6000 GPU 上 92.9 毫秒的中位延迟，表明强大的决策准确率可以与可靠的置信度估计和高效推理并存。

隐藏集评估。
Hugging Face 决策指数使用由基准维护者管理的私有测试集来评估提交的模型。截至 2026 年 11 月 15 日，GLiDE 系列模型在多个排行榜版本中均取得了有竞争力的表现，其中 GLiDE 27B 在隐藏评估集上得分为 73.37。全部五种规模的模型也都位于所报告的性能–参数帕累托前沿之上。

规模扩展与循环深度。
最后，我们研究了该方法如何跨模型规模和推理时计算预算进行扩展。我们通过渐进式训练和来自 27B 模型的蒸馏开发了四个更小的 GLiDE 模型。全部五个模型都位于 Hugging Face 决策指数的性能–参数帕累托前沿之上，每个模型都优于同等或更小规模的全部已评估替代方案。我们还研究了无参数循环深度，它通过重新应用选定的中间层来增加计算量，而不引入新的权重或生成 token。结合进一步的检查点平均，这产生了 GLiDE 27B，其在 Hugging Face 决策指数上达到 73.37，期望校准误差为 2.1%。总而言之，这些结果将 GLiDE 确立为一个快速、校准良好的决策模型家族，它受益于融合推理的训练，而无需在推理时进行显式的推理生成。

综上所述，这些发现表明，无需在推理时生成显式推理，即可跨模型规模实现强大且校准良好的决策性能。更广泛地说，GLiDE 展示了融合推理的监督和模型内部的额外计算如何在不牺牲直接候选评分效率的前提下提升决策质量。

2 决策模型架构

不熟悉决策模型的读者可以先阅读附录 A，该附录从基础语言模型出发逐步构建出该模型。

2.1 任务形式化

我们考虑模型从有限候选集中选择答案的决策任务。一个请求由上下文 c 和 M 个问题组成：

ℛ = (c, {(q_j, 𝒜_j)}_{j=1}^M，（1）

其中 𝒜_j = {a_{j,1}, …, a_{j,K_j}} 表示问题 j 的候选答案集合。为简洁起见，令 u_j = (c, q_j, 𝒜_j)。

模型预测一个类别分布：

p_θ(·|u_j) ∈ Δ^{K_j−1}，Σ_{k=1}^{K_j} p_θ(k|u_j) = 1。（2）

预测的决策及其置信度为

k̂j = argmax{k∈[K_j]} p_θ(k|u_j)，（3）

p̂_j = p_θ(k̂_j|u_j)。

与自回归生成不同，决策推理只需单次前向传播，无需生成中间推理或答案 token。附录 C 对类型化输出、成本敏感决策、基于置信度的延迟以及批量问题的语义进行了形式化。

2.2 模型架构

图 2 展示了 GLiDE V1.2 的架构，从输入编码到单次前向决策概率。

输入编码。
每个问题被转换为单个序列，将上下文、问题和候选答案拼接在一起。上下文在每个序列中出现一次，而每个候选答案被分配一个唯一的单 token 代码 γ_k。最后一个答案前缀标记了模型预测决策分布的位置。形式化地，输入序列定义为

x_j = Tok(c ⊕ q_j（4）
⊕ ⨁{k=1}^{K_j}(γ_k ⊕ a{j,k}) ⊕ s_ans)，

其中 ⊕ 表示拼接，s_ans 为最终答案前缀。来自同一请求的问题作为独立序列在一个批次中处理。

混合解码器。
我们基于 Qwen3.8-27B（Qwen 团队，2026）构建，它包含 48 个 Gated DeltaNet 层（Yang 等，2025）和 16 个全注意力层。标准因果注意力定义为

Attn(Q, K, V; Ω) = softmax(QK^⊤/√d_k + Ω)V，（5）

其中因果掩码为

Ω_ij = 0（当 j≤i）；−∞（当 j＞i）。（6）

我们从这 16 个全注意力层中移除该掩码，即设 Ω = 0。这使得上下文、问题和候选答案之间能够进行双向交互。Gated DeltaNet 层则保留其因果循环和在序列长度上的线性复杂度。

选项读出。
令 F_θ 表示混合解码器，L_j 表示 x_j 的长度。我们在答案前缀处提取最终隐藏状态：

H_j = F_θ(x_j)，h_j = H_j[L_j] ∈ ℝ^d。（7）

一个专用的线性读出将该表示映射为 255 个可能选项代码上的 logits：

z_j = Wh_j，W ∈ ℝ^{255×d}。（8）

由于每个问题的候选答案数量可能不同，我们将读出限制为输入中实际出现的 K_j 个选项代码，并丢弃未使用代码对应的 logits。随后对剩余 logits 进行 softmax，得到所提供候选答案上的归一化概率分布：

p_θ(k|u_j) = exp(z_{j,k}) / Σ_{ℓ=1}^{K_j} exp(z_{j,ℓ})（9）

其中 k ∈ [K_j]。该读出从预训练语言模型头的对应行初始化。因此，对 F_θ 的单次评估即可产生所有候选答案上的归一化分布，无需自回归解码。

3 训练

我们通过渐进式后训练来训练 GLiDE V1.2，将推理能力迁移到单次前向推理中，并利用多样化的决策数据和多教师监督加以精炼。图 9 展示了模型在各阶段间的演进。

3.1 渐进式训练与蒸馏

我们通过四个连续阶段训练 GLiDE，每个阶段都建立在前一阶段产生的检查点之上。该流程首先开发一个具备推理能力的教师模型，然后将其转换为单次前向决策模型，再逐步精炼其预测。

阶段 1：推理教师。
我们首先使用 LoRA（Hu 等，2022）分两步对 Qwen3.8-27B 进行适配。第一步，我们为训练问题生成推理轨迹，并保留约 6,400 个推理能够得出正确答案的示例。在这些示例上训练 Rank-64 LoRA 适配器（冻结基础权重），对推理轨迹使用下一 token 预测，对最终答案使用交叉熵。接下来，适配后的模型对约 135K 个额外问题进行推理，我们收集其在候选答案上的思考后概率分布。第二轮 LoRA 训练模型直接预测这些分布，而不产生书面推理。由此得到的教师模型可以在有或无显式推理的情况下运行，为后续蒸馏同时提供直接预测和思考后预测。这是唯一使用 LoRA 的阶段。

阶段 2：单次前向转换。
从推理教师出发，我们移除全注意力层的因果掩码并引入专用选项读出。然后，我们从多个教师（包括推理模型的思考后预测）蒸馏软概率分布，训练该架构在单次前向传播中进行直接决策评分。

阶段 3：短训练轮次。
随后我们通过五个短轮次继续训练。每轮结束后，更新后的检查点与其父检查点进行等权平均，得到 GLiDE V1.1。这种递归平均使最新更新占最终权重的二分之一，前一更新占四分之一，更早轮次的贡献逐级递减，有助于在吸收新改进的同时保留先前学到的能力。

阶段 4：最终后训练。
最后，我们在重建的多样化决策任务混合数据上继续训练 GLiDE V1.1，使用任务特定的多教师分布作为监督。该阶段巩固了此前的改进，并产生我们的最终决策模型 GLiDE V1.2。

蒸馏推理。
核心挑战在于在不于推理时执行缓慢的多步推理的前提下保留其收益。对于输入 x，令 q_think 和 q_direct 分别表示推理教师在有思考和无思考时的答案分布。我们将目标分布构造为

q = ½(q_think + q_direct)（当 κ(x)＜η）；q_direct（当 κ(x)≥η），（10）

其中 κ(x) = max_k q_direct(k|x) 是直接模型的置信度，η = 0.8。换言之：如果教师在不思考的情况下已有至少 80% 的置信度，我们就使用其直接分布；否则，我们将其直接分布与思考后分布取平均。对分布取平均既保留了直接模型的信号，又纳入了推理带来的变化。这样，思考后监督主要在直接模型不确定时提供。给定黄金答案 y 和教师分布 q，学生最小化

ℒ(θ) = −α log p_θ(y|x)（11）
+ (1−α) D_KL(q‖p_θ)，

其中 α = 0.3。第一项奖励正确答案，第二项使学生匹配教师的完整分布。软目标不仅传达首选答案，还传达推理后残余的不确定性，使学生能够在单次前向传播中逼近教师的决策分布。

3.3 多教师监督

最终训练阶段结合了互补的多个教师，包括现有的单次前向决策模型、我们模型的早期检查点以及一个标注器。由于教师在不同任务上的表现各异，我们采用任务特定的对数线性池化（Genest 和 Zidek，1986）。对于任务家族 f，聚合目标为

q_f(k|x) = exp(s_{f,k}(x)) / Σ_{ℓ=1}^{K_x} exp(s_{f,ℓ}(x))，（12）

其中 s_{f,k}(x) = Σ_{t=1}^{T} λ_{f,t} log p_t(k|x)。（13）

这里 p_t 表示教师 t，λ_{f,t} ∈ [0,4] 为其任务特定权重。我们通过在保留的 5% 训练数据切片上最小化黄金标签负对数似然来优化这些权重，并使用两折交叉拟合。

黄金锚定。
为限制教师错误的传播，池化目标需通过黄金一致性检查，必要时替换为黄金锚定目标。该流程给下游学生带来的增益仍在单种子波动范围内。

弃权。
对于知识类任务，“我不知道”被视为普通候选答案。我们并非模仿教师的不确定性，而是从起始学生自身的置信度导出弃权目标，鼓励其在自身知识不足时选择弃权。

3.4 优化细节

最终阶段采用全参数微调，使用 AdamW（Loshchilov 和 Hutter，2019），学习率为 10^−6，批次大小为 128，在单个 epoch 中进行 2,928 步。训练过程中对候选选项进行打乱以减少位置偏差。每个种子在八块 B200 GPU 上约需六小时。发布的模型是两个独立训练种子的权重平均（Wortsman 等，2022）。

4.1 基准

决策指数。

其中 n_b 为区间 b 中的预测数量。ECE 越低表示校准越好。

5.2 校准与效率

概率校准。
当模型表示有 90% 的把握时，它是否在大约 90% 的情况下是正确的？
GLiDE V1.2 的期望校准误差为 2.0%（基于榜单样本的 10 个区间；区间约为 [1.7, 2.4]），是排名前十的模型中最低的（表 7）。其平均置信度比准确率高 1.1 个百分点（82.6% 对 81.5%），而其他九个模型的过度自信程度在 2.5 到 10.5 个百分点之间。在其置信度高于 0.9 的答案（占 56%）中，97.4% 是正确的。其综合校准与准确率的 Brier 分数略高于三个在该样本上准确率高出 0.9–1.3 分的模型。

6 循环深度与模型规模扩展

我们研究了 GLiDE V1.2 的两个扩展方向：在不引入额外参数的情况下增加推理时计算量，以及将训练流程迁移到更小的模型规模。图 5 总结了由此形成的模型谱系。除非另有说明，开发阶段使用内部评估数据，报告的比较使用独立的保留集。Hugging Face 决策指数得分为来自 0.4.1 版的外部管理测量（Passos，2026b）。

6.1 GLiDE 27B

参数平均。
我们在同一条谱系上基于更广泛的数据混合（各约 170 万个问题）训练了两个额外检查点。单独来看，它们分别使保留集性能变化 +0.21 和 −0.20 分，未达到 +0.5 的预设改进阈值。随后我们构造凸参数平均，GLiDE V1.2 的权重为 1/2，两个额外检查点各占 1/4。平均后的模型使保留集性能提升 0.86 分。这一结果与先前的观察一致，即来自同一微调谱系的检查点可以在权重空间中保持连通（Wortsman 等，2022；Izmailov 等，2018）。整条谱系的训练共使用了来自 340 万个不同问题的约 39 亿 token。

无参数循环深度。
GLiDE 27B 使用平均后模型的参数，无需进一步训练。在推理时，两个中间层块——64 层网络中的第 24–35 层和第 36–47 层——各被应用两次。对于层块映射 F，循环更新为

x_{k+1} = x_k + η[F(x_k) − x_k]，k=0,1，η=½，（15）

其中 x_0 为该块的输入，x_2 被传递给后续层。公式 15 定义了一种阻尼不动点迭代，与权重绑定网络和循环深度网络相关（Dehghani 等，2019；Bai 等，2019；Geiping 等，2025；Saunshi 等，2025）。它增加了计算量但不增加可训练参数。阻尼系数限制了传递给下游层的分布偏移；在我们的实验中，无阻尼更新（η=1）表现更差。图 6 说明了该流程。

评估协议。
候选配置在重复层块、循环次数和阻尼调度上有所不同。配置选择使用内部开发数据。我们在两个独立的保留集上将所选配置与平均模型基线进行比较。

结果。
循环深度使两个保留集的得分分别提升 0.69 分（区间 [0.02, 1.42]）和 0.56 分（区间 [0.27, 0.89]）。GLiDE 27B 在隐藏集上获得 73.37 分，而 GLiDE V1.2 为 71.52；该差距同时包含参数平均和循环深度的贡献。中位延迟从 92.9 毫秒增加到 122 毫秒，因为 64 层中有 24 层被计算了两次。校准保持相近，ECE 从 2.0% 升至 2.1%。在基准校准样本上，58% 的预测置信度高于 0.9，其中 97.3% 正确。

消融。
将每个层块应用三次的效果不如应用两次；引入可训练的循环参数也未能超越无参数更新。高学习率蒸馏和替代性参数平均同样未能改善保留集性能。

训练流程。

7 结论

我们提出了 GLiDE V1.2，一个将推理蒸馏进单次前向传播的决策模型。通过结合非因果全注意力、专用选项读出和多教师蒸馏，该模型在不生成中间推理的情况下对候选决策产生校准的概率。在 Hugging Face 决策指数（0.4.1 版，2026 年 10 月 22 日）上，GLiDE V1.2 取得 71.52 的得分，在 225 个模型中排名第一，并在两个隐藏评估集上均居首位，期望校准误差为 2.0%，中位延迟为 92.9 毫秒。这些结果不止于初始模型。无需重新训练，GLiDE V1.2 在 Artificial Analysis 决策指数的三个版本中与最高得分的差距均保持在 0.6 分以内。进一步的检查点平均与无参数循环深度得到了 GLiDE 27B，在不引入额外参数的情况下达到 73.37。在涵盖 0.4B 至 27B 参数的五种模型规模中，每个 GLiDE 模型都优于所有同等或更小规模的已评估替代方案。总而言之，这些发现表明，融合推理的训练能够跨模型规模实现强大且校准良好的决策，同时保持直接推理的效率。

附录 A 从语言模型到决策模型的逐步构建

此附录以通俗的语言解释 GLiDE V1.2 如何从其基础语言模型构建而来。它只假设读者对 transformer 有基本了解。第 2 节和第 3 节给出正式版本，表 9 总结了全部改动。

A.1 起点

Qwen3.8-27B 是一个普通的语言模型：它读入一个 token 序列并预测下一个 token。它有 64 层，隐藏层大小为 5,120，其最后一层为约 248,000 个词汇 token 中的每一个打分。这些层分为两类。

  • 16 个自注意力层。在每一层中，每个 token 回看之前的 token 并整合所获信息。
  • 48 个 Gated DeltaNet 层。每一层从左到右读取序列并携带一个滚动摘要，很像循环网络。其开销随输入长度线性增长，这使长文档的处理成本保持低廉。

两类层都是因果的：一个 token 只能使用它之前的内容。一个逐 token 写文本的模型需要这一点，因为后面的 token 尚不存在。

A.2 目标

决策模型回答的是另一类请求。它接收一个上下文、一个问题和一组选项，并为每个选项返回一个概率。例如：

上下文：订单 1182。包裹到货时已损坏；附有两张照片。
问题：客服下一步应该怎么做？
选项： 退款 替换 上报 请求更多信息
期望输出：A 0.64，B 0.21，C 0.11，D 0.04

语言模型可以通过写文本来回答，但这有三个缺点。写文本很慢，因为每个生成的 token 都需要再过一遍网络。文本还需要被解析。而且选项的概率并非直接给出。让模型在作答前逐步推理可以提升准确率，但会使成本成倍增加。

我们希望以单次前向传播的成本获得推理模型的准确率。以下六个步骤实现了这一目标。

A.3 步骤 1：将请求写成一个提示

上下文、问题和选项被放入单个提示中。每个选项被分配一个单 token 代码（A、B、C……）。提示以"Answer: ("前缀结尾，这样语言模型接下来会写的 token 就是其答案的代码。

A.4 步骤 2：从一个位置读取答案

网络将提示转换为每个 token 一个向量。我们只保留最后一个 token 处的向量 h，它包含 5,120 个数字。一个有 255 行的小矩阵 W（每个可能的选项代码一行）将 h 转换为 255 个分数 z = Wh。我们保留实际提供的选项（示例中为四个）的分数并应用 softmax。结果就是每个选项一个概率，且概率之和为一。

该读出替换了原始输出层——后者为 248,000 个 token 打分。W 并非从随机值开始：每一行都从原始输出层中相同代码 token 对应的行复制而来。因此，在任何训练之前，读出对选项 A 的打分与语言模型对 token A 的打分完全一致。

之所以有 255 行，是因为我们使用 255 个单 token 代码：先是 26 个字母，然后是双字母代码。因此一个问题最多可以有 255 个选项。

A.5 步骤 3：让每个 token 看到整个提示

在语言模型中，注意力掩码使 token i 只能关注 token 1, …, i。对于决策而言，这一限制并无必要，因为整个提示在模型开始工作前就是已知的。它甚至是有害的：上下文在问题被看到之前就被读取，选项 A 在选项 B、C、D 之前被读取。

我们移除了 16 个自注意力层中的掩码。此后每个 token 都可以关注其他所有 token。模型可以在知晓问题的情况下阅读上下文，也可以将各个选项相互比较。我们保持 48 个 Gated DeltaNet 层不变。它们在设计上就是循环的，保持原样可维持其线性开销。

由此带来两个后果。第一，模型不再能写文本，因为写文本依赖于掩码。第二，预训练权重从未见过“未来”token，因此模型必须先经过训练才能利用它们。这正是下一步的任务。

A.6 步骤 4：在概率上训练，而不仅在答案上

每个训练示例由一个提示、正确选项以及由一个或多个教师模型提供的目标分布组成。损失（公式 11）包含两项：0.3 倍与正确选项的交叉熵，加上 0.7 倍相对目标分布的 KL 散度。

第二项正是其区别于普通分类训练之处。一个标签只说明 A 是正确的。而像 (0.70, 0.05, 0.25, 0.00) 这样的目标还表明 C 是一个合理的备选，D 则不是。在此类目标上训练的学生学到的不只是回答什么，还有该有多确定。这正是模型校准的来源。训练后没有拟合温度或任何其他校正。

A.7 步骤 5：把思考移入训练

其中一个教师是基础模型本身的一个会先推理再作答的版本（第 3 节中的阶段 1）。对每个训练问题，我们让该教师写出其推理，然后记录它赋予每个选项的概率。学生从不看到推理文本。它只看到教师思考后达到的分布，并学习直接产生该分布。

因此，思考的成本在训练期间一次性支付，而不是分摊到每个请求上。思考并非对每个问题都有帮助。如果教师不推理就已经足够自信，我们使用其直接分布；否则，我们将其直接分布与思考后分布取平均（公式 10）。

A.8 步骤 6：分轮精炼并平均权重

转换完成后，进行五个短训练轮。每轮结束后，我们将新权重与该轮起始权重平均。这保留了早期轮次学到的内容。最后一个阶段在重建的数据混合上重新训练模型，目标来自多个教师的池化（第 3 节）。发布的模型是两个使用不同随机种子的此类训练的平均。

A.9 最终产出

完成的模型接收一个提示并在单次前向传播中为每个选项返回一个概率，中位耗时 92.9 毫秒。应用可以采用概率最高的选项，也可以只在该概率足够高时采取行动，而将其余情况转交给人处理（附录 C）。

A.10 GLiDE V1.2 之后

三个后续步骤建立在完成的模型之上（第 6 节）。它们都没有改变上述图景：模型仍然在单次前向传播中为每个选项返回一个概率。

  • 再平均两个模型。在更广泛数据上又训练了两个模型，其权重与 GLiDE V1.2 的权重进行了平均。
  • 将某些层运行两次。GLiDE 27B 在推理时将两个中间层块各应用两次，每次前进一半。模型对每个问题计算更多，且没有新权重、没有生成的 token。
  • 训练更小的模型。相同设计的更小模型重复该流程，然后被训练去匹配 27B 模型的输出分布。

附录 B 相关工作

蒸馏与单次推理。
知识蒸馏将教师的软分布传递给学生（Hinton 等，2015；Kim 和 Rush，2016），包括分配给错误答案的概率质量中的信息（Menon 等，2021）。先前的工作通过采样理由、最终答案、删除的推理步骤或潜在 token 来压缩思维链推理（Hsieh 等，2023；Yu 等，2024；Deng 等，2024；Goyal 等，2024）。相比之下，我们蒸馏的是完整的思考后答案分布，保留了教师的残余不确定性。

单次决策模型。
GLiNER、GLiNER2 和 GLiGuard 等模式条件化编码器支持对自然语言标签或模式的高效预测（Zaratiana 等，2024；2025；2026a；2026b）。非因果解码器方面的工作通过移除因果掩码来产生强表示（BehnamGhader 等，2024；Lee 等，2025）；在我们的混合解码器中，我们只解除了全注意力层的掩码。由于选项符号评分可能引入顺序偏差（Robinson 等，2023；Zheng 等，2024），我们使用专用读出并在训练期间打乱选项。Drex Max（Dhankhar 等，2026）为同期开发的工作，使用相同主干，同样移除因果掩码并添加 255 路读出。其训练方式不同：加入了一致性损失和一个强化学习阶段。

校准与弃权。
神经网络和语言模型常常过度自信（Guo 等，2017；Tian 等，2023；Xiong 等，2024）。选择性预测因此引入拒绝机制（Chow，1970；Geifman 和 El-Yaniv，2017；Kamath 等，2020）；我们将显式弃权作为普通选项进行训练，并公开概率以供应用层的延迟决策。

附录 C 决策模型输出语义

第 2 节定义了 GLiDE V1.2 如何将上下文、问题和有限答案集映射为类别分布。本附录说明应用如何解释该分布，并明确若干独立于网络架构的操作属性：类型化问题、成本敏感决策、延迟、置换等变性以及批量问题的独立性。

C.1 类型化问题

对于问题 j，令 p_j = (p_{j,1}, …, p_{j,K_j}) ∈ Δ^{K_j−1} 为公式 9 得到的分布。同一分布支持三种输出类型。

选择。
对于无序的命名动作集合，默认决策及其置信度为

k̂j = argmax{k∈[K_j]} p_{j,k}，p̂j = p{j,k̂_j}。

选项描述是输入的一部分，因此动作不必属于固定的全局标签词汇表。模型最多可为 255 个选项打分，因为其读出包含 255 个单 token 选项代码。

是/否。
若两个选项为“是”和“否”，有用的标量为

s_j = p_j(是)，p_j(否) = 1 − s_j。

只有当假阳性与假阴性的代价相等时，1/2 的阈值才是最优的。若其代价分别为 C_FP 和 C_FN，则最小期望代价规则在 s_j ≥ C_FP/(C_FP+C_FN) 时预测“是”。
因此，应用可以在不重新训练模型的情况下改变其工作点。

有序评分。
假设选项表示有序的数值等级 v_1 ＜ ⋯ ＜ v_{K_j}。众数评分与期望评分为

v̂j^mode = v{argmax_k p_{j,k}}，v̂j^mean = Σ{k=1}^{K_j} p_{j,k} v_k。

完整分布还通过 Var(v_j) = Σ_{k=1}^{K_j} p_{j,k}(v_k − v̂_j^mean)² 揭示歧义性。
例如，等级 0, …, 4 上的分布 (0.05, 0.10, 0.20, 0.45, 0.20) 的众数为 3，均值为 2.65，并保留了相邻等级仍然可信的信息。

C.2 自动化、延迟与弃权

模型分布与应用的决策策略是两回事。一种常见的选择性策略（Chow，1970；Geifman 和 El-Yaniv，2017）只自动化足够自信的预测：

δ_τ(u_j) = k̂_j（当 p̂_j ≥ τ 时）；延迟处理（当 p̂_j ＜ τ 时）。

在包含 N 个问题的评估集上，该策略的覆盖率为 Cov(τ) = (1/N)Σ_{j=1}^N 𝟏[p̂_j ≥ τ]，选择性风险为 Risk(τ) = Σ_j 𝟏[p̂_j ≥ τ]𝟏[k̂_j ≠ y_j] / Σ_j 𝟏[p̂_j ≥ τ]。
提高 τ 通常会降低覆盖率并有望降低风险；校准则决定了置信度在部署人群上是否具有稳定的操作意义。延迟与显式弃权不同。延迟由调用方在推理之后施加，可以使用任意阈值。显式弃权则是在候选集中加入“我不知道”选项 ⊥，使得 p_j ∈ Δ^{K_j}，k̂_j ∈ {1, …, K_j, ⊥}。
因此，它是从训练目标中学到的行为，而非事后的置信度规则。应用可以同时结合两种机制：当模型选择 ⊥ 时予以接受，并将任何低于所选置信度阈值的其余答案转交延迟处理。

C.3 批量问题与独立性

一个请求可以包含 M 个共享上下文 c 的问题。每个问题被渲染为独立的序列，

x_j = Tok(c, q_j, 𝒜_j)，j = 1, …, M，

这些序列经填充后在一个批次中评估：

(p_1, …, p_M) = BatchEval_θ(x_1, …, x_M)。

批处理共享一次设备调用，但不会耦合答案分布：API 暴露的是 M 个边缘分布而非联合分布。如果应用独立地解释它们，所诱导的联合分布为

p(k̂1, …, k̂_M|ℛ) = ∏{j=1}^M p_j(k̂_j|c, q_j, 𝒜_j)。

因此，跨问题约束——例如要求若干标志中恰好一个为真——必须由下游的约束解码器强制执行，或者表示为一个联合选择问题。上下文在每个问题序列中出现一次，但会在 M 个批量序列中重复出现。

C.4 选项顺序与语义等变性

候选顺序不应改变底层决策。对于 K_j 个选项的置换 π，期望的等变性属性为

p_θ(π(k)|c, q_j, π(𝒜_j)) = p_θ(k|c, q_j, 𝒜_j)。

该属性无法由架构保证，因为每个选项都与一个有序代码配对并占据不同的提示位置。在训练期间打乱选项、同时对目标分布施加相同置换，可鼓励近似等变性。在提示中保留完整的选项描述，也使预测依赖于选项的语义，而非代码 A、B 等的固定含义。

D.1 检查点谱系

令 θ_0 表示 Qwen3.8-27B 的参数。四个阶段构成一条有向检查点谱系，而非四次独立的训练运行：

θ_{4,s} = 𝒯_final(θ_V1.1; D_final, Q_routed, s)，s ∈ {1, 2}。

这里 𝒯_reason 产生启用思考的教师；𝒯_convert 引入非因果全注意力和 255 路选项读出，同时蒸馏思考后行为；𝒯_rounds^(5) 表示五个短训练轮。在第 r 轮中，新训练的检查点 θ̃_{3,r} 与初始化它的父检查点取平均，

θ_{3,r} = ½(θ_{3,r−1} + θ̃_{3,r})，r = 1, …, 5，（17）

这在累积更新的同时限制遗忘。两个最终种子从相同的 GLiDE V1.1 检查点出发，仅因训练随机性而不同。发布的参数是二者的均匀平均，

θ_V1.2 = ½(θ_{4,1} + θ_{4,2})。（18）

D.2 监督路径

最终阶段并非直接只在原始标签上训练。其 374,720 个问题首先经过格式规范化和数据质量筛选。每个保留的行 i 包含输入 x_i、黄金选项 y_i、任务家族 f_i 和路由软目标 q_i。对于普通行，q_i 是公式 12 的经交叉拟合、任务特定的对数线性教师池；不正确的教师共识会被黄金锚定目标替换。知识类行则使用起始学生自身的正确性和置信度来决定目标应支持答案还是显式弃权选项。在每个优化步骤中，候选选项、其代码、黄金索引以及 q_i 的每个坐标会被一同置换。然后学生最小化公式 11。这一顺序很重要：教师路由和黄金锚定在选项打乱之前定义目标，而共享置换保持了目标的语义，并防止代码位置成为标签捷径。
