摘要
自动语音识别（ASR）传统上使用词错率（WER）进行评估，该指标对语义不敏感。基于嵌入的语义指标与人类感知的相关性更好，但基于解码器的大语言模型在此任务上的应用仍未被充分探索。本文通过三种方法评估了它们的相关性：（1）在两个候选假设中选择最佳假设，（2）使用生成式嵌入计算语义距离，以及（3）错误的定性分类。在 HATS 数据集上，对于假设选择，最佳 LLM 与人类标注者的一致性达到 92–94%，而 WER 仅为 63%，同时也优于语义指标。基于解码器的 LLM 嵌入表现出与编码器模型相当的性能。最后，LLM 为可解释和语义化的 ASR 评估提供了一个有前景的方向。

1 引言
自动语音识别（ASR）是语音控制应用、转录和无障碍技术的基础。对 ASR 系统的可靠评估对于衡量进展和指导模型改进至关重要。从历史上看，词错率（WER）一直主导着这一领域，但该指标有众所周知的局限性：它死板且区分大小写，不一定能捕捉到对任务或人类感知重要的信息。

面对这些挑战，人们提出了几种替代方案。基于词嵌入的语义指标 Kim 等人 (2021); Zhang 等人 (2019) 显示出了良好的性能，特别是那些利用像 BERT Devlin 等人 (2019) 这样的上下文编码器模型的方法。这些方法更好地捕捉了语言的语义细微差别，解释了它们与人类判断更好的相关性。然而，虽然编码器在此任务中已被频繁探索 Bañeras-Roux 等人 (2022); Kim 等人 (2021); Le 等人 (2016); Gordeeva 等人 (2021)，但基于解码器的大语言模型（LLM）——如 GPT Radford 等人 (2018)、Llama Touvron 等人 (2023) 或 Gemma Team 等人 (2024)——却鲜少受到关注。然而，这些模型在广泛的任务中展示了卓越和通用的能力 Ahuja 等人 (2023); Labrak 等人 (2024); Naveed 等人 (2025)，这表明它们可以为 ASR 评估提供创新的视角。

本研究正是探讨了基于解码器的 LLM 在评估自动语音识别系统这一特定背景下的能力，沿着两个互补的轴线进行。第一个轴聚焦于“LLM 作为评判者”范式：我们能否利用 LLM 深度的上下文和语义理解来直接评估转录假设的质量？第二个轴考察从这些模型中提取的向量表示的质量：解码器 LLM 的嵌入在捕捉相关语义相似性方面与编码器的嵌入相比如何？

我们的实验依赖于 HATS 数据集 Bañeras-Roux 等人 (2023)，该数据集提供了语音识别错误的人类标注，并表明语义指标与人类感知的相关性显著优于 WER。我们评估了 (1) LLM 在两个候选假设中选择最佳假设的能力，(2) 应用于 LLM 嵌入以构建语义相似性指标的不同聚合策略（池化）的有效性，以及 (3) LLM 为转录错误分配定性标签的能力。我们的结果表明，最佳的 LLM 不仅优于 WER 和 CER，而且优于基于编码器的复杂语义指标，同时提供了更好的错误可解释性。

2 相关工作
2.1 词错率的局限性
如前所述，词错率一直是评估自动语音识别系统的参考指标。然而，文献中记录了 WER 的显著局限性 Wang 等人 (2003); Morris 等人 (2004); He 等人 (2011)。首先，该指标在词汇层面上操作，不考虑语义上下文，将严重影响理解的错误与对意义没有影响的轻微错误同等对待。其次，WER 不一定与依赖于所产生转录的下游任务 Favre 等人 (2013) 相关，这表明 WER 的改进并不能保证最终用户能感知到改进。最后，几项研究表明 WER 与人类对转录质量的感知之间相关性很差 Kim 等人 (2022); Thennal 等人 (2025)，这质疑了它对于评估旨在供人类阅读的 ASR 系统真实性能的实用性。

这些局限性具有重要的实际意义。事实上，研究表明，根据用于评估的指标不同，ASR 系统的排名可能会有显著差异 Bañeras-Roux 等人 (2024a)。对于特定目标——例如，生成供人类阅读的字幕——使用与人类感知相关性更好的指标可能比优化不能捕捉相关感知细微差别的 WER 更为相关 Kafle 和 Huenerfauth (2017); Nam 和 Fels (2019)。

2.2 基于嵌入的语义指标
面对 WER 的局限性，人们提出了几种替代方案。其中，基于词嵌入的语义指标已被证明特别有前景。这些方法利用通过词嵌入或上下文模型获得的语言的向量表示，允许捕捉参考转录和转录假设之间的语义相似性。

第一代这些指标利用静态词嵌入来改进机器翻译背景下的 ASR 评估 Le 等人 (2016)。最近，强大的上下文模型的出现，特别是像 BERT 及其多语言变体这样的双向编码器，使得开发更复杂的语义指标成为可能。这些上下文模型提供了更丰富的表示，对词位置和每个语言单位周围的上下文敏感。在著名的语义方法中，SemDist 指标 Kim 等人 (2021) 提出了一种源自参考和假设嵌入之间余弦相似度的距离。该指标与人类感知的相关性显著优于 WER，验证了语义是转录质量感知评估的关键因素这一假设。

McCowan 等人根据包括可解释性在内的几个标准定义了自动语音识别的理想指标。问题在于语义指标主要基于嵌入之间的余弦相似度构建，产生的分数如：0.62、0.75 或 0.81。与错误百分比（如 WER 和 CER）不同，这些分数的可解释性较差。

为了解决这个问题，一些工作 Gordeeva 等人 (2021); Roy (2021) 提出了一种可适应下游任务的语义指标，并且可以解释为基于错误的语义和词汇严重性的加权词错率。其他工作 Bañeras-Roux 等人 (2024b) 也提出了基于严重性及其对使用上下文嵌入的语义指标的影响来解释 ASR 错误的范式。这些方法提供了对错误更细粒度的理解，允许识别哪些错误类型最影响感知的转录质量。

2.3 人类感知与可解释的评估
一个互补的研究轴聚焦于自动指标与人类感知之间的显式对齐。几项工作提出了基于人类感知的评估模型 Itoh 等人 (2015); Sasindran 等人 (2024)。

实证研究收集了人类标注，以评估说话者如何感知自动转录的质量。这些标注使得创建像 HATS 这样的数据集成为可能，这是一个法语数据集，整合了对错误质量的显式人类判断，允许验证和比较不同的评估指标。这项研究表明其与人类感知的相关性高于 WER，证实了另一项 Kim 等人 (2022) 在整合人类感知的私有数据集上进行的研究。另一项最近的研究 Thennal 等人 (2025) 也使用人类标注证明，在多语言环境下，字符错误率比 WER 更具相关性。

3.1 使用 LLM 选择最佳假设
我们使用不同的 LLM 来确定，在两个转录假设中，哪一个最接近给定的参考。本实验旨在评估不同 LLM 比较两个不正确假设并识别出与参考转录最匹配的假设的能力，同时考虑词汇保真度和语义连贯性。

模型通过单样本提示进行查询，包括一个带标注的示例，然后是一个要预测的案例。明确要求模型证明其答案的合理性，然后以 A 或 B 的形式得出决定。这种表述允许利用模型的推理（思维链），同时便于自动提取最终预测。

使用的提示如下（从原文翻译）：
用户：参考是对音频的精确转录。提出了两个不正确的假设。解释你的推理，并在句子末尾写下 'A'、'B'、'a' 或 'b'（如果无法决定）。
参考：it's to him self
假设 A：are to him self
假设 B：it's uh to him-self
助手：虽然假设 B 包含不流畅之处，但它在词汇和含义上与参考更为一致。如果不流畅是原始内容的一部分，则是可以容忍的，而假设 A 的语法错误问题更大。因此，最可接受的转录是假设 B。
用户：
参考：<reference>
假设 A：<hypothesis A>
假设 B：<hypothesis B>

3.2 基于解码器 LLM 嵌入的语义指标
我们在 HATS 数据集上评估了 SemDist 指标的相关性，该指标定义为参考和假设嵌入之间余弦相似度导出的距离。

为了获得转录的表示，我们使用了不同系列的 LLM，涵盖多种规模和训练方法。文本首先被标记化为标记序列，然后由 LLM 转换为嵌入序列，对应于每个标记的向量表示。

由于 SemDist 指标需要固定维度的表示，该序列通过池化操作进行聚合。我们比较了几种池化策略，从简单的方法（如平均嵌入）到加权方法。

目标是评估这些选择对表示质量的影响，特别是它们捕捉由人类标注反映的语义相似性的能力。因此，LLM 系列和池化方法之间的所有组合都根据 SemDist 和 HATS 数据集标注之间的相关性进行评估。

池化策略。我们考虑以下池化策略，其中 t_i 表示第 i 个标记的嵌入，n 表示序列长度：
• 最后一个标记：使用最后一个标记嵌入 t_n。
• 倒数第二个：使用最后一个标记之前的标记嵌入 t_{n-1}。
• 平均：所有标记嵌入的平均值，1/n ∑{i=1}^{n} t_i。
• 去除最后一个的平均：排除最后一个标记的嵌入平均值，1/(n-1) ∑{i=1}^{n-1} t_i。
• 加权平均：所有标记嵌入的加权平均值，权重随位置线性增加（即标记 t_i 的权重为 i），∑{i=1}^{n} i t_i / ∑{i=1}^{n} i。
• 去除最后一个的加权平均：排除最后一个标记的嵌入加权平均值，具有相同的位置权重，∑{i=1}^{n-1} i t_i / ∑{i=1}^{n-1} i。
• 最后 4 个标记的平均：最后四个标记嵌入的平均值，1/4 ∑_{i=n-3}^{n} t_i。

与最初的直觉相反，分析揭示了模型规模与嵌入与人类感知的相关性之间关系微弱。虽然通常会观察到较大模型有更好的性能，但我们很少观察到这种现象，有时甚至相反：Qwen3.5-35B 的表现弱于 Qwen3.5-27B。有趣的是：在将假设分类为更好方面表现最佳的 LLM（见表 2）不一定具有 SemDist 指标最相关的嵌入（Qwen3.5-27B 在假设选择上得分为 91%，而使用最后 4 个标记的平均值为 78%）。

一个显著的结果是，仅基于最后一个标记的表示在大多数情况下被其他替代方案超越。例如，Qwen3.5-27B 使用最后一个标记池化仅达到 59%，而加权池化（该 LLM 第二差的方法）至少为 74%，差距达 15 个百分点。我们将此归因于 LLM 的训练目标：下一标记预测任务优化表示以预测未来的标记，而不是捕捉整体的语义内容。位于序列末尾的最后一个标记必须预测无信息的延续，因此携带了关于完整句子很少的语义信息。

尽管平均池化具有潜在的擦除和丢失信息的能力，但它被证明特别有效，通常等于或超过更复杂的策略。我们通过嵌入空间的几何属性来解释这一点：当假设和参考具有可比的长度（在 ASR 任务中预期如此）时，语义相似的对表现出收敛的嵌入轨迹，导致它们的平均值在潜在空间中聚集。

毫不奇怪，明确为嵌入任务微调的模型大大超过了同等规模的通用 LLM，即使使用最后一个标记嵌入，这也是用于 LLM 微调的标记 Zhang 等人 (2025)。Qwen3-Embedding-8B 使用平均池化达到 89%，而 Qwen3-8B 为 85%，提高了 4 个百分点。值得注意的是，这种微调缩小了最后一个标记和其他方法之间的差距，表明特定任务的训练重新定向了最后一个标记，使其作为连贯的语义表示，而不仅仅是作为下一标记预测器。

3.3 用于假设分类的生成式 LLM
在本节中，我们评估了语言模型在给定参考的情况下对假设进行分类的能力。与第 3.1 节中任务包括在同一参考的两个候选者中选择最佳假设不同，我们在这里独立考虑每个（参考，假设）对，模型必须在四个类别中分配一个定性类别。目标是对模型进行内在和客观的评估。

给定一个参考和一个假设，模型必须分配以下标签之一：
• 相同：假设与参考相同（或仅在大小写或连字符方面不同）；
• 有用：尽管有轻微错误（规范化、标点、拼写、大写、缩写、轻微的句法变化而不丧失理解力），但含义得以保留；
• 差：含义部分改变（关键词上的重大错误、重要的替换或遗漏，但部分内容仍可理解）；
• 不可理解：含义完全丢失（相对于参考，句子无法被理解或正确解释）。

每对由所考虑的模型自动标注，而不与其他假设进行显式比较。这种表述允许评估模型绝对而非相对地判断假设质量的内在能力。

与这种分类标注并行，我们使用我们已知的最佳执行编码器 LLM：sentence-camembert-large 计算参考和假设之间的 SemDist 分数。该度量提供了一个独立的定量信号，允许分析模型的定性判断与模拟人类感知的连续指标之间的一致性。

4 结论
本文通过三种互补的方法系统地评估了大语言模型在自动语音识别评估中的能力。首先，生成式 LLM 在选择最佳假设的任务中优于经典和现有的语义指标，与人类标注者的一致性达到 92-94%，展示了在自动标注和寻找最佳 ASR 系统方面的有效能力。其次，从基于解码器的 LLM 中提取的嵌入提供了高质量的表示，即使使用简单的聚合策略也是如此。对于此任务，模型规模似乎不是决定性因素，而明确微调的模型在所有池化技术中均取得了最佳性能。第三，LLM 似乎能够以与人类数据一致的方式对转录错误进行定性分类，与不透明的数值指标相比提供了卓越的可解释性。

这些结果表明，LLM 为 ASR 系统的感知评估提供了一条有前景且可解释的途径，为更好地将测量性能与实际人类感知对齐的下一代评估指标铺平了道路。
