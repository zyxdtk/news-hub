摘要
多模态大语言模型（MLLMs）的自我提升通常由基于奖励的方法驱动，这些方法仅提供粗糙的标量反馈。蒸馏通过密集的 token 级别监督提供了更丰富的替代方案，但在视觉领域，它通常依赖于使用外部标注和工具或更强模型构建的特权上下文。我们引入了 CVPD（对比反事实视觉过程蒸馏，Contrastive Counterfactual Visual Process Distillation），据我们所知，这是第一个完全自包含的框架，用于 MLLMs 的密集、同策略、token 级别视觉自蒸馏。CVPD 识别视觉盲点，在这些区域中，放大某个区域会改变并锐化模型的答案分布，而移除同一区域则使全图行为基本保持不变。这些区域揭示了模型能够编码但在全图条件下无法持续利用的感知信息。我们提出了一个三重门反事实准则，直接从模型自身的响应中识别这些区域，并将它们转化为用于自蒸馏的密集对比监督。在 Qwen3-VL-8B-Instruct 上，CVPD 在十二个基准测试中优于六个自我进化基线，包括依赖外部 GPT-4o 监督的方法，且没有任何性能衰退。它在 OCRBench 上取得了 +3.60 的提升，在 MMStar 细粒度感知上取得了 +3.38 的提升，在 MMStar 逻辑推理上取得了 +3.08 的提升，同时在更广泛的多模态基准测试中保持或改善了性能。

1 引言

自我提升已成为多模态大语言模型（MLLMs）后训练的核心目标，并出现了两种广泛的方法。基于奖励和正确性的方法在模型自己生成的响应上进行训练，使用可验证的结果或偏好信号选择示例。这些方法避免了人工标注，但训练信号仍然很粗糙。整个 rollout 或轨迹接收一个标量奖励或优势，而不是密集的 token 级别反馈。基于蒸馏的方法通过在学生生成的轨迹上匹配教师的下一个 token 分布，提供了更丰富的替代方案。这提供了标量奖励无法提供的 token 级别纠正监督。

挑战在于蒸馏需要特权上下文，即一种能够诱导教师和学生之间产生有意义行为差距的输入版本。从历史上看，构建这种上下文依赖于模型外部的信息。在文本领域，这个问题相对简单。将参考解决方案、编译器错误或反馈跟踪附加到提示中通常足以产生所需的差距。然而，在视觉领域，为模型提供同一图像的更好感知视图相当困难。这样做通常需要外部识别系统、分割模型或更强的标注器。这种对外部工具的依赖一直是完全自包含的密集视觉自蒸馏对于 MLLMs 的主要障碍。

图 1：CVPD 将视觉盲点转化为密集的自监督。基于奖励的自我进化可以识别更好或更差的响应，但它不提供 token 级别的纠正分布。标准的视觉蒸馏可以提供密集的监督，但通常依赖于外部构建的特权视图。CVPD 相反使用模型自身的响应来识别区域，在这些区域中，裁剪会锐化答案分布，而幽灵图像保留模型的默认行为。裁剪视图作为正教师，幽灵视图作为反事实负教师，无需外部区域提议、标签或更强的标注器即可实现密集的视觉自蒸馏。

先前的工作从两个方向探讨了这一挑战，但并未完全解决。在蒸馏方面，Vision-OPD 表明，当给定以证据为中心的裁剪时，同一个 MLLM 通常可以正确回答细粒度问题，而在全图上却失败了。它利用这种区域到全局的差距进行同策略视觉蒸馏，并取得了强劲的结果。然而，该方法依赖于外部标注和分割模型来识别证据区域、生成可裁剪回答的问题，并提供共识答案标签。因此，监督是密集且同策略的，但特权上下文仍然是外部构建的。在自我提升方面，通过在奖励过滤或偏好排序的自生成数据上进行训练来消除外部标注的方法消除了这种依赖性，但又退回到更粗糙的学习信号。响应或轨迹接收标量分数，而不是 token 级别的纠正监督。因此，在没有外部构建的特权上下文的情况下，针对视觉感知的密集、同策略、token 级别自蒸馏仍然是一个开放问题。

为了解决这一差距，我们引入了 CVPD（对比反事实视觉过程蒸馏），这是一个直接从模型自身的反事实行为中恢复特权视觉上下文的框架。我们的关键洞察是，当一个区域在放大时改变并锐化模型的答案分布，而移除同一区域时却不改变，该区域就提供了有用的特权上下文。这表明模型已经具备了相关的感知能力，但在全图条件下未能充分利用它。CVPD 完全从模型自身的响应中识别这些区域，并将它们用于对比训练。裁剪条件视图作为正教师，引导学生走向其潜在的感知能力，而幽灵条件视图作为负教师，捕获模型不注意的默认行为。这些信号共同在学生自己的 rollout 的每个 token 位置提供密集监督（图 1）。通过完全从模型自身的行为中派生特权上下文，CVPD 实现了无需外部标注、工具或更强模型的自包含密集视觉自蒸馏，如图 1 所示。

我们的贡献总结如下：
* 我们引入了一个三重门反事实盲点准则，用于识别包含模型可以使用但在全图条件下未能利用的感知信息的图像区域。该准则仅依赖于模型自身的反事实响应，无需外部工具、标注或更强模型即可构建特权上下文。
* 我们开发了一个对比自蒸馏目标，将每个发现的区域转换为从同一主干派生的成对正负教师信号。这提供了密集的、逐 token 的、同策略的监督，而无需外部奖励、验证器或标注器。
* 我们表明，所提出的准则可靠地识别了裁剪和幽灵信号最大程度对立的区域，并且 CVPD 在十二个视觉感知和推理基准测试中提供了一致的改进。最大的改进出现在需要精确定位注意力的任务上，同时保持或改进了通用多模态能力。

2 相关工作

多模态 LLMs 的自我提升。
大型语言模型（LLMs）和多模态 LLMs（MLLMs）的自我提升通常被构建为从模型生成的数据、可验证的结果或内在一致性中进行后训练。带有可验证奖励的强化学习是一种广泛采用的途径。GRPO 通过从采样响应组中估计优势来移除 PPO 的学习评论家，而 DAPO 则为大规模推理 RL 改进了这一目标。在多模态设置中，R1 风格的方法通过基于规则的、逐步的或共享的视觉推理奖励扩展了这一范式，如 VLM-R1、R1-VL 和 R1-ShareVL。这些方法使基于奖励的后训练变得实用，但它们的反馈仍然是通过奖励和相对优势来调节的，而不是密集的下一个 token 分布。即使奖励是可靠的，它们也表明哪个 rollout 或推理步骤更可取，而不是模型在每个访问状态的下一个 token 分布应该如何改变。

自我进化系统通过在任务生成、解决和评估之间形成闭环来减少对标注的依赖。在纯文本设置中，自举方法如 STaR、ReST 和自我奖励语言模型在模型生成的理由、过滤样本或自我判断的偏好上进行训练。最近的 MLLM 变体通过具有连续或内在奖励的提议者-解决者或提问者-解决者代理、自一致性和基于判断的轨迹重新加权、战略性视觉自博弈以及合成或主动检索的视觉环境来实例化这个循环。这些工作证明了在有限的人类监督下改进 MLLMs 的可行性。然而，训练信号仍然是聚合的。响应、轨迹、问题或代理角色接收奖励、分数或优势，而不是 token 级别的监督。这激发了一个互补问题，即在不依赖外部教师或验证器的情况下，为视觉感知获取 token 级别的纠正反馈。

同策略自蒸馏。
知识蒸馏提供了一种不同的监督机制，学生匹配教师的下一个 token 分布，而不是仅优化终端或轨迹级别的奖励。对于自回归模型，普通的离线蒸馏会受到暴露偏差的影响，因为学生是在教师或数据集诱导的前缀上训练的。广义知识蒸馏（GKD）通过在学生生成的轨迹上查询教师来解决这种不匹配，将蒸馏转变为同策略目标。最近的同策略自蒸馏方法表明，教师不必是单独的外部模型。OPSD 将同一个 LLM 条件化于特权推理轨迹或参考解决方案，而 SDPO 将模型条件化于丰富的文本反馈，并将由此产生的反馈感知预测蒸馏回无条件策略。进一步的变体校准或定位这种密集信号，例如通过结果引导的 logit 转向、反射引导的错误定位蒸馏和对比证据策略优化。共同原则是，同一模型内由上下文诱导的行为差距可以转化为学生自己采样前缀上的密集 token 级别监督。

视觉设置缺乏同等直接的特权上下文来源。参考解决方案、编译器错误或反馈消息可以附加到 LLM 提示中，但给 MLLM 提供同一图像的更好感知视图需要构建该视图。Vision-OPD 识别了区域到全局的差距：同一个 MLLM 可能从以证据为中心的裁剪中正确回答细粒度问题，而在全图上失败。它使用这种差距通过 token 级别的同策略分歧将裁剪条件教师蒸馏到全图学生中，密切相关的并行工作研究了 VLM 蒸馏的视觉优势加权。Vision-OPD 是与我们最接近的先前工作。然而，其区域数据合成并非完全从目标模型自身的行为中派生。对象识别和分割系统提出证据区域，MLLM 生成可裁剪回答的问题，Qwen3.5-397B 提供用于过滤和替代训练基线的共识答案标签。因此，尽管蒸馏期间使用的教师分布来自同一主干，但裁剪-问题监督是外部构建的，而不是从目标模型的反事实行为中自我发现的。

这就留下了一个开放问题：在没有外部构建的特权上下文的情况下，是否可以实现密集的视觉自蒸馏。现有方法要么依赖于基于奖励的监督（仅提供粗糙的训练信号），要么依赖于其特权上下文是通过外部数据合成、标注管道或更强模型产生的密集蒸馏目标。因此，密集 token 级别监督和完全自包含的自我提升在视觉 MLLM 训练中在很大程度上仍然是分离的方向。我们通过直接从模型自身的行为而不是从外部生成的区域、问题、标签或验证器中派生特权视觉上下文来解决这一差距。在此过程中，我们的工作将同策略自蒸馏的密集 token 级别监督与完全自包含的训练过程相结合，实现了无需外部标注、奖励信号、分割系统或更强标注器的视觉自我提升。

3 预备知识

同策略蒸馏训练学生 $p_{S}$ 在学生自己生成的轨迹上匹配特权教师 $p_{T}$，避免了离线蒸馏的前缀分布不匹配。在推理时，学生条件化于自己的前缀；而在教师诱导的前缀上进行训练会引入状态分布偏移，这种偏移可能会在长生成视野中复合错误。对于多模态输入 $(I,q)$ 和 rollout $y\sim p_{S}(\cdot\mid I,q)$，目标是：

$$ \mathcal{L}{\mathrm{OPD}}(\theta)=\mathbb{E}{(I,q)\sim\mathcal{D},\;y\sim p_{S}(\cdot\mid I,q)}!\left[\frac{1}{|y|}\sum_{t=1}^{|y|}D!\left(p_{T}!\left(\cdot\mid\tilde{I},q,y_{<t}\right)\;\Big|\;p_{S}!\left(\cdot\mid I,q,y_{<t}\right)\right)\right], \quad (1) $$

其中 $\tilde{I}$ 是教师可用但在推理时对学生隐瞒的特权视觉上下文，$D$ 是逐 token 的分歧。与优化标量奖励的强化学习方法不同，同策略蒸馏沿着学生自己的轨迹提供密集的 token 级别监督。

公式 (1) 的有效性取决于教师和学生之间存在有意义的不对称性。在教师和学生共享同一主干的自我蒸馏设置中，这种不对称性必须源于条件上下文而不是模型容量。对于视觉任务，先前的工作表明，同一个 MLLM 可以从以证据为中心的裁剪中正确回答问题，而在全图上失败，揭示了可以作为特权上下文的区域到全局的感知差距。然而，现有的方法使用外部分割管道、区域提议或更强的模型来构建这种上下文。直接从模型自身的行为中构建特权视觉上下文，而没有任何外部监督，是 CVPD 解决的核心问题。

在整篇论文中，我们使用 $D=D_{\mathrm{JS}}$，在教师和学生在每个 token 位置的 top-$K$ logit 索引的并集上进行近似，其中 $K=100$。

4 方法：CVPD

图 2：CVPD 概览。CVPD 从模型在无标签图像上的自身响应中派生所有监督，无需外部标签、标注工具、分割模型或更强的标注器。
阶段 1（反事实盲点发现）：模型为每张图像生成一个细粒度的问答对 $(q,a)$，并通过自定位（Track A）、$3\times3$ 网格（Track B）和 $2\times2$ 网格（Track C）提出候选区域。三重门反事实准则（公式 2-4）选择裁剪会改变并锐化答案分布而幽灵图像保留原始行为的区域，产生精选的元组 $(I,q,R,a)$。
阶段 2（对比自蒸馏）：每个元组在不同的视觉视图下从同一主干实例化四个策略。在线学生 $\pi_{s}$ 从裁剪条件教师 $\pi_{+}$、幽灵条件教师 $\pi_{-}$ 和冻结的参考策略 $\pi_{\mathrm{ref}}$ 中学习。它们的潜在转移、对比排序和 KL 锚定目标共同形成 $\mathcal{L}_{\mathrm{CVPD}}$（公式 7）。

完全无监督的同策略自蒸馏需要一个模型未充分利用其自身感知能力的区域，以及一种仅使用模型本身来定位和验证该差距的方法。CVPD 通过反事实探测来识别这些区域。当一个区域在放大时改变并锐化模型的答案分布，而擦除它时全图行为基本保持不变时，该区域被视为盲点。这个三重门准则（第 4.1 节）验证了存在有意义的教师-学生差距，并使幽灵条件视图成为模型不注意默认值的可靠代理。然后，CVPD 使用两个教师进行训练：一个裁剪条件的正教师将学生拉向更敏锐的区域感知，一个幽灵条件的负教师在每个 token 位置将其推离其测量的默认行为。通过从模型自身的反事实行为中派生这两个信号，CVPD 实现了 MLLMs 中用于细粒度视觉感知的自包含、对比、同策略自蒸馏。

4.1 自我发现的视觉盲点

设 $I$ 为图像，$q$ 为模型自身生成的问题，$R$ 为由轴对齐边界框指定的候选区域。我们使用同一模型 $p_{\theta}$ 定义三个视图。全视图 $p_{\mathrm{full}}=p_{\theta}(\cdot\mid I,q)$ 条件化于未修改的图像。裁剪视图 $p_{\mathrm{crop}}=p_{\theta}(\cdot\mid\mathrm{crop}(I,R),\,q)$ 条件化于 $R$，提取时带有 20% 的边距并放大到原始分辨率。幽灵视图 $p_{\mathrm{ghost}}=p_{\theta}(\cdot\mid\mathrm{ghost}(I,R),\,q)$ 条件化于将 $R$ 内的像素替换为其高斯模糊后的全图。

每个分歧都是在短探测答案 $a$ 上逐 token 计算的，使用 $D_{\mathrm{JS}}$ 的 top-$K$ 并集近似，其中 $K=100$。当 $R$ 满足三个反事实条件时，我们称 $R$ 为 $(I,q)$ 的视觉盲点：

(G1) 潜在能力分歧：
$$ D_{\mathrm{JS}}(p_{\mathrm{crop}}|p_{\mathrm{full}})\geq\tau_{\mathrm{crop}}, \quad (2) $$

(G2) 默认感知不变性：
$$ D_{\mathrm{JS}}(p_{\mathrm{ghost}}|p_{\mathrm{full}})\leq\tau_{\mathrm{ghost}}, \quad (3) $$

(G3) 认知锐化：
$$ H[p_{\mathrm{crop}}(y_{0})]<H[p_{\mathrm{full}}(y_{0})]. \quad (4) $$

门 (G1) 要求裁剪视图将答案分布移离全图基线，确保裁剪条件教师携带学生尚未表达的信息。门 (G2) 要求抑制该区域不会实质性地改变全图分布。这证实了模型在全图条件下没有使用 $R$，并使 $p_{\mathrm{ghost}}$ 成为其不注意默认行为的可靠代理。门 (G3) 要求裁剪锐化模型的预测而不是仅仅扰动它，过滤掉破坏有用上下文或增加不确定性的区域。总之，这些门选择裁剪和幽灵视图提供相反信号的区：裁剪捕获模型在关注正确区域时可以感知到的内容，而幽灵捕获模型在不关注时默认的内容。

当多个区域通过所有三个门时，我们按以下方式对它们进行排序：
$$ \mathrm{score}(R)=D_{\mathrm{JS}}(p_{\mathrm{crop}}|p_{\mathrm{full}})-D_{\mathrm{JS}}(p_{\mathrm{ghost}}|p_{\mathrm{full}})+\bigl(H[p_{\mathrm{full}}(y_{0})]-H[p_{\mathrm{crop}}(y_{0})]\bigr), \quad (5) $$
这奖励大的裁剪侧分歧、低的幽灵侧扰动和裁剪下大的熵减少。我们保留每张图像得分最高的区域。

为了在完整训练之前隔离反事实准则的效果，图 3 分析了从 500 张原始图像中采样的 6,791 个候选区域。未经精选，任意区域在裁剪和幽灵干预下都产生高 JSD（0.359 和 0.387）和负的熵增量（$\Delta H=-0.211$）。换句话说，它们扰动模型但并没有锐化其预测。通过公式 (2)-(4) 的区域保留了强烈的裁剪侧敏感性（0.265），将幽灵侧噪声抑制了 24 倍至 0.016，并将熵增量反转为 +0.378。裁剪与幽灵的差距从 -0.028 上升到精选后的 +0.249，支持了该准则隔离了两个教师提供真正和相反监督的区域的观点。

图 3：反事实盲点精选的分布特征。我们从 500 张原始图像中采样了 6,791 个候选区域。
(a) 未经精选的区域产生相似的裁剪/全图和幽灵/全图分歧（0.359 vs. 0.387），表明两种干预都以可比的方式扰动模型。通过反事实准则的区域保留了强烈的裁剪侧分歧（0.265），同时将幽灵侧分歧降低至 0.016，对无关扰动的抑制达 24 倍。
(b) 精选还将熵变化从 -0.211 反转为 +0.378，表明所选裁剪锐化了模型的答案分布，而不是仅仅改变它。总之，这些结果表明，反事实准则隔离了裁剪和幽灵视图提供强烈分离和信息性监督信号的区域。

CVPD 在两个阶段使用精选盲点池，如图 2 所示并在算法 1 中总结。阶段 1 使用反事实准则从原始图像中发现盲点元组，阶段 2 在每个发现的区域使用成对的裁剪和幽灵教师训练在线学生。

反事实盲点获取。
对于每张原始图像 $I$，模型生成一个针对小属性、计数或文本元素的细粒度问题 $q$，然后采样一个短的确定性探测答案 $a$。对 $(q,a)$ 固定了该图像上所有后续前向传递的教师强制目标。候选区域从三个轨道收集。Track A 通过查询同一模型在 $(I,q)$ 上的边界框来获得自定位提议。Track B 将 $I$ 划分为 $3\times3$ 均匀网格，Track C 使用更粗糙的 $2\times2$ 网格。管道的每个组件，包括问题生成、区域提议、答案生成和区域评分，都仅使用正在训练的模型。这种自包含设计避免了标注工具、分割模型或更大的查询模型将重新引入的监督瓶颈。覆盖小于 1% 或大于 50% 图像面积的候选者作为退化被丢弃。然后将公式 (2)-(4) 中的反事实准则应用于剩余的候选者，并为每张图像保留得分最高的盲点。没有通过区域的图像被跳过。

应用于 15,000 张无标签图像，该管道产生 $|\mathcal{D}_{\mathrm{CVPD}}|\approx 2,590$ 个精选元组，对应于 17.2% 的产率。在保留的盲点中，27% 来自 Track A 自定位提议，53% 来自 Track B $3\times3$ 网格区域，30% 来自 Track C $2\times2$ 网格区域。由于在多区域保留下图像可能贡献来自多个轨道的候选者，这些百分比描述的是轨道成员身份而不是互斥分区（见第 5 节）。

对比蒸馏目标。
给定精选盲点池 $\mathcal{D}{\mathrm{CVPD}}={(I{i},q_{i},R_{i},a_{i})}{i=1}^{N}$，阶段 2 在不同的视觉条件下从同一主干 $p{\theta}$ 实例化四个策略。在线学生 $\pi_{s}=p_{\theta}(\cdot\mid I,q)$ 观察启用梯度的全图。动量教师对 $\pi_{+}$ 和 $\pi_{-}$ 共享系数为 $\alpha=0.05$ 的 LoRA 参数的指数移动平均（EMA），并停止梯度：$\pi_{+}=p_{\bar{\theta}}(\cdot\mid\mathrm{crop}(I,R),\,q)$ 条件化于裁剪视图，$\pi_{-}=p_{\bar{\theta}}(\cdot\mid\mathrm{ghost}(I,R),\,q)$ 条件化于幽灵视图。参考策略 $\pi_{\mathrm{ref}}=p_{\theta_{0}}(\cdot\mid I,q)$ 使用禁用 LoRA 适配器的相同全图输入。

逐 token 的损失结合了三个目标：
$$ \mathcal{L}{t}=\underbrace{D{\mathrm{JS}}(\pi_{+}|\pi_{s})}{\displaystyle\text{潜在转移}}+\;\lambda{\mathrm{rank}}\cdot\underbrace{\max!\bigl(0,\;m+D_{\mathrm{JS}}(\pi_{+}|\pi_{s})-D_{\mathrm{JS}}(\pi_{-}|\pi_{s})\bigr)}{\displaystyle\text{对比排序}}+\;\beta{t}\cdot\underbrace{D_{\mathrm{KL}}(\pi_{s}|\pi_{\mathrm{ref}})}{\displaystyle\text{KL 锚定}}, \quad (6) $$
并且训练目标对 rollout token 进行平均：
$$ \mathcal{L}{\mathrm{CVPD}}(\theta)=\mathbb{E}{(I,q,R,a)\sim\mathcal{D}{\mathrm{CVPD}}}!\left[\frac{1}{|a|}\sum_{t=1}^{|a|}\mathcal{L}{t}\right], \quad (7) $$
其中间隔 $m=0.1$，排序权重 $\lambda{\mathrm{rank}}=0.5$。

潜在转移目标在每个 token 位置将在线学生 $\pi_{s}$ 拉向裁剪条件教师 $\pi_{+}$，将模型的区域感知能力转移到其全图策略中。对比排序目标使幽灵条件教师 $\pi_{-}$ 成为训练的活跃部分，而不仅仅是发现期间的过滤条件。没有这个间隔损失，幽灵视图将在阶段 1 中使用并在之后丢弃。有了它，门 (G2) 保证 $\pi_{-}$ 反映模型不注意默认值成为在整个 rollout 期间将 $\pi_{s}$ 推离该默认值的逐 token 压力。KL 锚定正则化约束 $\pi_{s}$ 在相同的全图分布上保持接近参考策略 $\pi_{\mathrm{ref}}$，防止目标感知更新侵蚀通用语言和多模态能力。系数 $\beta_{t}$ 在线适应以维持目标 KL 分歧 $\kappa=0.03$。

因为教师强制目标 $a$ 在所有四个条件上下文中共享，所有策略在相同的 token 位置进行评估，这使得公式 (6) 中的逐位置分歧定义良好。

5 实验

实现细节。
我们将策略 $\pi$ 实例化为 Qwen3-VL-8B-Instruct，在语言模型主干的注意力和 MLP 投影上应用秩为 32 和 $\alpha=64$ 的 LoRA 适配器；视觉编码器被冻结。对于盲点发现，我们设置 $\tau_{\mathrm{crop}}=\tau_{\mathrm{ghost}}=0.05$。问题生成使用温度 0.7、top-p 0.9 和最多 64 个 token，而探测答案在温度 0 下解码并限制在 24 个 token。训练使用 AdamW 优化器，学习率为 $2\times10^{-5}$，权重衰减为 0.01，梯度裁剪为 1.0，在精选盲点池上进行一个 epoch 的训练。KL 锚定系数初始化为 $\beta_{0}=10^{-3}$ 并在线适应以维持目标 KL 分歧 $\kappa=0.03$。所有图像（全图、裁剪和幽灵）都被调整为 $448\times448$，保持四个前向传递中的视觉 token 数量相同。所有模型都在 8× AMD MI250X GPU 上使用 bfloat16 精度进行训练。

训练数据。
CVPD 在完全无标签的图像上运行，在任何阶段都没有使用标题、边界框、语义标签、真实答案、奖励信号或外部模型。我们从离线反事实盲点发现管道处理的两个无标签池中提取。阶段 1 由 10,000 张自然场景图像组成。阶段 2 由 5,000 张图像组成，混合了 40:60 的推理领域内容（图表、科学图表和结构化文档图形）和自然场景。发现管道处理所有 15,000 张图像并产生约 2,590 个精选 $(I,q,R,a)$ 元组（通过反事实准则的通过率为 17.2%）。在保留的盲点区域中，53% 源自 Track B（$3\times3$ 分区），30% 源自 Track C（$2\times2$ 分区），27% 源自 Track A 自定位提议。

基线和评估。
我们在两个基础模型 Qwen3-VL-4B-Instruct 和 Qwen3-VL-8B-Instruct 上将 CVPD 与六个自我进化基线进行比较。基线包括 VisPlay、EvoLMM 和 iReasoner，它们是完全自监督的，不依赖外部奖励、验证器或标注数据，以及 VisionZero 的 CLEVR、Chart 和 Real-World (RW) 变体。其中，VisionZero-CLEVR 是无标签的，而 Chart 和 Real-World 变体在数据集构建期间使用 GPT-4o。所有方法都在相同的基础模型上训练，并在相同条件下使用 lmms-eval 框架、HuggingFace Transformers v4.38 和 bfloat16 精度在 AMD MI250X GPU 上进行评估。对于每个基线，我们遵循原始论文中报告的训练设置：VisPlay（10 个 epoch）、EvoLMM（1 个 epoch）、iReasoner（1 个 epoch）和所有 VisionZero 变体（100 个 epoch）。

我们在十二个基准上进行评估。五个直接针对 CVPD 旨在改进的细粒度视觉定位能力：OCRBench（局部文本理解）、InfoVQA（从密集信息图中提取信息）和三个 MMStar 子量表：细粒度感知、实例推理和逻辑推理。这些任务需要识别、提取和推理特定图像区域，而不是依赖整体场景理解。

其余七个基准评估更广泛的多模态能力，并作为检查 CVPD 的目标感知改进不以牺牲一般性能为代价：ScienceQA、RealWorldQA、CV-Bench、AI2D、MMBench-EN、MME-Perception 和 SEED-Image。这些基准共同涵盖了科学推理、真实世界视觉理解、图表解释、以视觉为中心的推理、整体感知和一般多模态能力。

值得注意的是，VisionZero-Chart 和 VisionZero-RW 在数据集构建期间依赖 GPT-4o，而 CVPD 完全从无标签图像和模型自身的反事实响应中派生其训练信号。尽管没有使用外部标注器、验证器或奖励模型，CVPD 在两种规模的所有基准上都优于这两种方法。这表明在这种设置下，自我发现的密集分布监督提供了比外部构建的基于奖励的反馈更强的学习信号。

设置 $\lambda_{\mathrm{rank}}=0$ 移除了排序损失，同时保留了裁剪条件教师。性能大幅下降，OCRBench 降至 84.10（-2.30），MMStar FG 降至 61.47（-2.16），这是表中第二大的退化。这表明仅从裁剪条件教师学习是不够的。来自幽灵条件教师的额外信号提供了重要的对比压力，帮助学生远离不注意的行为，而不是仅仅模仿改进的行为。

支持性设计选择 (b, c, e)。
移除 EMA 稳定（行 b，$\alpha=0$）导致中等程度的性能下降，表明动量教师在训练期间随着学生的进化提供了更稳定的分布目标。将训练限制在仅最高分的精选元组（行 c）比随机区域选择表现更好，但仍低于完整 CVPD，表明来自完整精选集的广泛覆盖提供了超出小部分高置信度示例的额外学习信号。最后，解冻视觉编码器（行 e）略微降低了性能。这表明预训练的视觉表示已经与语言模型很好地对齐，使用相对较小的精选数据集更新编码器提供的好处很少，同时引入了轻微的不稳定性。

5.4 盲点来源分析

表 4：Qwen3-VL-8B-Instruct 上的候选区域来源消融。每一行使用从单独的单个区域生成轨道派生的盲点训练 CVPD。所有三个轨道都单独改进了基础模型，其中 Track B（$3\times3$ 网格）是最强的独立来源。在所有基准上结合所有三个轨道获得了最佳结果，证实了自定位提议、粗网格裁剪和细网格分区在不同的空间粒度上发现了互补的盲点。每列最佳结果以粗体显示。

来源 样本 MMStar FG OCRBench MMStar Log
仅定位 ~699 62.50 84.90 63.30
仅 $2\times2$ 网格 ~777 62.80 85.30 63.80

表 4 通过使用从单独的轨道派生的盲点训练 CVPD 来评估每个候选区域来源的贡献。

所有三个轨道都改进了基础模型（MMStar FG：60.25→62.50/62.80/63.20；OCRBench：82.80→84.90/85.30/85.95），表明每个来源都有能力识别有用的训练区域。在各个轨道中，Track B（$3\times3$ 网格）表现最好，在 MMStar FG 上达到 63.20，在 OCRBench 上达到 85.95。一个可能的解释是，更精细的空间分区为每张图像产生更多的候选区域，增加了捕获信息性局部证据的机会。

结合所有三个轨道在所有基准上产生了最强的整体性能（63.63，86.40，64.77），始终优于任何单独的来源，这意味着自定位提议、粗糙的 $2\times2$ 裁剪和精细的 $3\times3$ 分区捕获了任何单一策略无法完全覆盖的互补区域。Track A 自定位提议仅占保留盲点的 27%，是三个来源中最小的份额。这与盲点背后的直觉一致：模型未能关注的区域也不太可能通过其自身的定位预测来识别。相比之下，基于网格的分区系统地探索图像，因此更有可能发现模型原本会忽略的区域。

6 结论

我们引入了 CVPD，一个用于 MLLMs 中密集同策略视觉自蒸馏的完全自包含框架。通过直接从模型自身的反事实响应中识别视觉盲点，CVPD 在不依赖外部标注、分割工具、奖励信号或更强模型的情况下恢复了密集监督。在十二个基准和多个模型规模上，CVPD 始终优于基础模型和所有自我进化基线，在需要精确定位视觉注意力的任务上取得了最大的改进，同时保留了更广泛的多模态能力。这些结果表明，细粒度视觉感知的主要瓶颈不仅在于模型容量或标记数据的可用性，而在于模型可靠地利用其已经编码的感知信息的能力。更广泛地说，我们的发现表明，视觉自我提升的密集监督可以从模型自身的潜在感知能力中产生，而无需任何外部监督来源。这项工作朝着完全自包含的视觉自蒸馏迈出了一步，并为直接从模型自身能力中派生密集监督提出了有希望的未来方向。
