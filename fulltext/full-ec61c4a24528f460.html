摘要

基于LoRA的参数高效微调由秩控制，秩决定了参数预算与局部可访问的任务更新。现有动态秩方法主要关注容量分配，但尚未解决当前适应空间对任务是否充分的问题。我们刻画了标准因子梯度的一阶信息边界，证明其不可观测子空间与低秩流形的法空间重合。因此，仅凭因子梯度无法区分当前空间内的欠优化与超出其一阶可达范围的任务相关方向。这启发了秩演化的几何视角：切向信息用于优化现有自由度，法向谱用于量化新自由度的价值。在局部二次模型下，我们证明主导法向奇异方向给出局部最优的秩扩展，其谱能量决定扩展增益。基于这一刻画，我们提出GEAR，通过切空间优化、面向秩扩展的无矩阵法向谱估计以及任务诱导的几何初始化，将切向–法向分解转化为秩演化。在语言与视觉基准上，GEAR在所有评估设置中以显著更少的可训练参数取得最佳平均性能。在LLaMA3-8B上，它将常识推理平均分从86.61提升至88.45，同时将可训练参数从42.0M减少到14.4M。

1 引言

参数高效微调（PEFT）已成为通过仅更新一小部分任务特定参数来适配大型预训练模型的主流方法（Ding等，2023b）。在PEFT方法中，LoRA将权重增量表示为低秩矩阵 ΔW=BA，其中 A∈ℝ^{r×m}、B∈ℝ^{n×r}，将可训练参数量从 nm 减少到 r(n+m)（Hu等，2022）。因此，r 既直接控制适配预算，也决定了低秩约束下可访问的局部一阶更新空间（Vandereycken，2013）。秩因而同时支配适配容量与哪些任务诱导方向可被表达。由于这些需求随层与训练进程而变化，统一的固定秩难以匹配任务需求的演化结构，这促使了动态秩适配的研究。

大多数动态秩方法仍主要将秩视为容量分配变量。例如，AdaLoRA根据各奇异分量的重要性在权重矩阵间重新分配给定的秩预算（Zhang等，2023），而DyLoRA训练嵌套的低秩结构以支持在多个截断秩下推理（Valipour等，2023）。更近期的方法允许更灵活的秩演化：FlexLoRA利用当前低秩更新的谱熵决定何时剪枝或扩展容量（Liu等，2026），GeoLoRA则在动态低秩积分框架内结合梯度驱动的基增强与谱截断（Schotthöfer等，2025）。尽管这些方法显著提升了秩适配的灵活性，其秩决策主要源自当前适配器已表示的容量或结构。因此，它们刻画的是当前低秩空间"已使用"的内容，却没有提供直接准则来判断任务相关的下降方向是否仍缺失于该空间之外。这留下了一个更根本的问题：

当前适应空间是否局部足以表达任务相关的下降方向，还是必须扩展其秩才能使这些方向成为一阶可访问的？

回答这一问题需要区分当前低秩空间内的优化不足与空间本身的不足。进展有限可能源于两个根本不同的原因：当前秩可能充分但欠优化，或者任务相关的下降方向位于其一阶可达空间之外。只有后者才证明增加秩是合理的。现有秩分配准则并未明确区分这两种情形，因而难以判断是否真正需要额外容量。这一区别引出我们的核心观点：动态秩不仅应由当前适应空间已表示的内容驱动，还应由其无法访问的任务相关下降信息驱动。

图1：GEAR的动机与概述。 (a) 标准因子梯度观测对法向分量不敏感，因此相同的一阶观测可能对应不同的秩需求。(b) GEAR区分当前流形内的优化与向当前一阶可达空间之外任务相关方向的扩展。(c) 这种几何引导的秩演化在常识推理上带来更强的性能–参数权衡。

为解决这一局限，我们提出GEAR（Geometry-guided Evolution of Adaptive Rank，几何引导的自适应秩演化），将动态秩适配形式化为任务相关低秩空间的演化。我们不是从现有因子统计推断秩的充分性，而是刻画固定秩参数化下可用的一阶信息。对于 X=BA，我们证明标准因子梯度映射存在可观测性间隙，其零空间与固定秩流形 ℳ_r={X∈ℝ^{n×m}: rank(X)=r} 的法空间 N_X ℳ_r 重合。这确立了一个结构性信息限制：标准因子梯度揭示了与优化当前秩相关的切向分量，而法向分量保持不可观测。因此，它们无法区分当前适应空间内的欠优化与需要秩扩展才能一阶可访问的任务相关方向。对于给定的秩增量，我们进一步证明主导法向模式决定局部最优扩展，其谱能量量化扩展增益。基于这一刻画，我们提出GEAR，通过切空间优化、面向秩扩展的无矩阵法向谱估计以及任务诱导的几何初始化，将切向–法向分解转化为实用的秩演化机制。仅当估计的法向谱揭示有价值的任务相关方向时才扩展秩，GEAR由此提升适配效果与参数效率。在多个基准上，它以更少的可训练参数持续优于有竞争力的PEFT基线。我们的贡献如下：

  • 秩适配的一阶可观测性障碍。 据我们所知，我们是首个刻画标准固定秩因子梯度可用信息并证明其不可观测子空间为低秩流形法空间的工作，从而将当前空间优化与秩扩展方向分离。
  • 几何引导的秩演化。 我们提出GEAR，统一了当前固定秩流形上的优化与秩扩展：用切向信息优化适应空间，用法向谱识别并评估新的任务相关方向。
  • 优异的性能–参数权衡。 在语言与视觉基准上，GEAR在每个评估设置中均取得最佳平均性能，同时使用的可训练参数显著少于强PEFT基线。

2 相关工作

LoRA与自适应秩适配。 LoRA通过低秩因子参数化任务特定更新，在保持预训练权重冻结的同时减少可训练参数与存储（Hu等，2022）。后续工作通过改进的参数化与初始化策略提升低秩适配。DoRA解耦权重幅值与方向以增强适配灵活性（Liu等，2024）；PiSSA从预训练权重的主奇异子空间初始化适配器（Meng等，2024）；LoRA-GA利用任务梯度识别更有效的初始低秩方向（Wang等，2024）。尽管有这些进展，大多数方法仍在固定秩下运行，可能难以匹配不同层与训练阶段的异构适配需求。这一局限催生了自适应秩LoRA方法：AdaLoRA根据奇异分量重要性在模块间动态重新分配给定秩预算（Zhang等，2023）；DyLoRA训练嵌套低秩结构以支持多个有效秩（Valipour等，2023）；SoRA通过稀疏门控学习有效秩（Ding等，2023a）。更近期的方法允许秩收缩与扩展：FlexLoRA根据当前适配器的谱结构调整秩（Liu等，2026），GeoLoRA在动态低秩公式下结合梯度驱动的基增强与谱截断（Schotthöfer等，2025）。GeLoRA进一步估计隐藏表示的本征维度以导出自适应逐层秩（Ed-dib等，2025）。总体而言，这些方法推动LoRA从固定秩适配走向日益灵活、任务相关的容量分配。然而，现有自适应秩方法主要决定如何分配或重组已表示的低秩容量，而GEAR提出的是一个不同的问题：任务相关的下降信息是否仍存在于当前一阶可达空间之外，从而值得新增秩维度。

LoRA的几何优化。 固定秩矩阵具有天然的黎曼流形结构，为独立于特定分解优化低秩状态提供了原则性途径（Vandereycken，2013）。早期的LoRA几何方法通过黎曼度量与预条件利用该结构；例如，黎曼预条件LoRA从低秩矩阵空间的几何导出低维预条件子，以改善优化稳定性与收敛（Zhang和Pilanci，2024）。GeoLoRA进一步将动态低秩积分引入PEFT，结合梯度驱动的基增强与谱截断实现结构保持与秩自适应更新（Schotthöfer等，2025）。相关工作还探索了对LoRA因子的显式流形约束：Park等在Stiefel流形上优化B因子以保持正交性与有效秩（Park等，2025），Manifold-LoRA为LoRA微调提出无回缩的Stiefel流形公式（Zhang等，2026）。更近期，Riemannion直接在固定秩流形上优化适配矩阵，消除分解歧义并实现独立于参数化的几何更新（Bogachev等，2026）。

这些方法确立了几何作为改进低秩优化的有效工具，主要通过精化度量、约束因子几何或演化当前低秩状态。GEAR则关注确定当前适应空间本身何时应当扩展所需的信息。从一阶可观测性视角，它将标准因子梯度不可观测的法向分量与当前一阶可达空间之外的任务相关方向联系起来，从而将流形优化与秩扩展相连接。

3 方法

GEAR建立在固定秩适配中的一阶可观测性间隙之上：标准因子梯度刻画当前空间内的优化，却不刻画支配其扩展的法向任务信息。我们首先形式化这一边界，然后开发一个几何引导的适配框架，在优化低秩空间的同时识别何时以及如何扩展它。

算法1 GEAR：几何引导的自适应秩演化

输入：预训练权重 W；初始秩 r_0；秩上界 r_max；审计集 𝒯_audit；预算 ℬ_target
(U,C,V) ← TGI(W, r_0)；X ← UC，W ← W − sX，r ← r_0
for t = 1, …, T do
    G_T ← U(U^⊤G) + (I − UU^⊤)GVV^⊤                    // 式(1)
    (X,U,C,V) ← Retr_{ℳ_r}(X − η_t G_T)                // 式(2)
    if t ∈ 𝒯_audit 且 r ＜ r_max then
        (Û, Σ̂, V̂) ← NormalSketch(X)                    // 式(3)–(4)

        X_cand ← Propose(X, 𝒮)                          // 式(6)
        if Validate(X_cand, X) then
            (U,C,r) ← Expand(U,C,𝒮)，X ← UC             // 式(7)
        end if
    end if
end for
输出：X

3.1 标准因子梯度的一阶信息边界

考虑预训练权重矩阵 W∈ℝ^{n×m}，按 W′=W+sX、X=BA 进行适配，其中 s＞0 为固定缩放因子。令 f(X)=ℒ(W+sX)，G=∇_X f(X)。对于秩为 r 的适配矩阵 X=BA，我们在固定秩流形 ℳ_r 上分析 X，其切空间刻画了不增加秩即可一阶访问的方向（Vandereycken，2013）。

令 X=UΣV^⊤ 为 X 的紧凑SVD，定义 P_U=UU^⊤、P_V=VV^⊤。全梯度具有正交分解 G=G_T+G_N，其中 G_T=P_U G+(I−P_U)GP_V ∈ T_X ℳ_r，G_N=(I−P_U)G(I−P_V) ∈ N_X ℳ_r。在因子化参数化 X=BA 下，相应梯度为 ∇_B f=GA^⊤，∇_A f=B^⊤G。

因此我们定义因子梯度观测算子 𝒪_{A,B}(G)=(GA^⊤, B^⊤G)，它捕获标准因子反向传播中可用的关于 G 的一阶信息。

定理1（因子梯度可观测性障碍）。 设 A∈ℝ^{r×m} 与 B∈ℝ^{n×r} 满秩，X=BA∈ℳ_r。则 ker 𝒪_{A,B} = N_X ℳ_r。等价地，对任意 G_1 与 G_2，𝒪_{A,B}(G_1)=𝒪_{A,B}(G_2) 当且仅当 (G_1)_T=(G_2)_T。

该定理建立了精确的一阶可观测性边界，表明标准因子梯度保留了任务梯度的切向分量，但无法区分仅在法向分量上不同的梯度。完整证明见附录C.1。因此，同一因子梯度观测既可能对应完全由当前适应空间表示的梯度，也可能对应包含超出其一阶可达范围的额外任务相关方向的梯度。这种歧义源于当前固定秩参数化下可用的信息，而非分解本身。

该结果将当前适应空间内的优化与秩扩展的需求区分开来。切向分量表示在秩 r 下一阶可访问的方向，而法向分量捕获当前空间之外的任务相关方向。因此，切向信息用于优化现有自由度，法向信息为评估秩扩展的价值提供相关信号。后续两节分别发展这两种机制。

3.2 固定秩流形优化

对于固定秩 r，GEAR利用梯度的切向分量在流形 ℳ_r 上优化。我们将适配矩阵表示为 X=UC，U^⊤U=I_r，其中 U 为 X 列空间的正交基，C 包含相应的低秩系数。令 V 为 C^⊤ 列空间的正交基。切向梯度为

G_T = U(U^⊤G) + (I−UU^⊤)GVV^⊤. (1)

式(1)表明 G_T 可由两个梯度收缩 U^⊤G 与 GV 计算，避免显式构造全梯度 G。

为通过反向传播直接获得这些量，GEAR采用前向等价表示

B_ext=[U, 0]，A_ext=[C; V^⊤]，

满足 B_ext A_ext = X。虽然该表示不改变前向映射，但其反向导数暴露了所需的梯度收缩：∇C f=U^⊤G，∇{B_ext^{(2)}} f=GV。由此，切向梯度可在不显式物化 G 的情况下恢复。GEAR随后执行切向更新并回缩到固定秩流形：

X^- = X − ηG_T，X_{t+1} = Retr_{ℳ_r}(X^-). (2)

由于 X^- 的秩至多为 2r，回缩在其紧凑因子上而非全矩阵上进行。具体地，薄QR分解将更新归约为一个小核心矩阵，对其做截断SVD即得回缩后的秩 r 状态及更新后的左右子空间基。完整细节见附录B.1。

3.3 几何引导的秩演化

上一节在 ℳ_r 上优化当前适配状态。相比之下，秩扩展由法向分量 G_N 支配，它捕获当前一阶可达空间之外的任务相关方向。我们接下来量化这些方向对秩扩展的局部价值。

令 G_N=∑_{i≥1} σ_i u_i v_i^⊤，σ_1≥σ_2≥⋯，其最佳秩 k 近似记为 (G_N)_k。

定理2（秩扩展的局部最优性）。 设 X∈ℳ_r，𝒞_{r,k}(X) 表示 X 处相对于有界秩集合 𝒱_{r+k}={Y∈ℝ^{n×m}: rank(Y)≤r+k} 的切锥。对于局部二次模型 q_η(H)=⟨G,H⟩F+(1/2η)‖H‖_F^2，𝒞{r,k}(X) 上的一个最优方向为 H_k^⋆=−η[G_T+(G_N)_k]，其中 (G_N)_k 为 G_N 的最佳秩 k 近似。此外，相对于在 T_X ℳ_r 上优化，额外 k 个秩维度所能带来的最优模型下降为

Δ_k := min_{H∈T_X ℳ_r} q_η(H) − min_{H∈𝒞_{r,k}(X)} q_η(H) = (η/2)∑_{i=1}^{k} σ_i^2(G_N).

完整证明见附录C.2。该结果表明，法向梯度的主导奇异方向构成秩扩展的局部最优方向，而其谱能量精确量化了局部二次模型下可获得的额外下降。

然而，构造 G_N=(I−UU^⊤)G(I−VV^⊤) 需要全梯度 G。GEAR转而通过随机化探测估计其主导谱（Halko等，2011）。给定 Ω∈ℝ^{m×h}，h≪min{n,m}，将其投影到右子空间的正交补：Ω_⊥=(I−VV^⊤)Ω。我们引入零初始化的辅助变量 P，通过 ΔX_probe=PΩ_⊥^⊤ 引入。由于 P=0，前向映射不变，而反向传播给出 ∇P f=GΩ⊥。再投影到左子空间的正交补，得

Y=(I−UU^⊤)∇_P f=G_N Ω. (3)

令 Q=orth(Y)。若 G_N=U_N Σ_N V_N^⊤，则 Y=U_N Σ_N(V_N^⊤Ω)，故与较大奇异值对应的奇异方向对 Y 的贡献更强。因此 span(Q) 捕获 G_N 的主导左奇异子空间。再用相同的零输出探测得到 Q^⊤G，由此计算

Z_N=Q^⊤G(I−VV^⊤)=Q^⊤G_N=Ũ Σ̂ V̂^⊤. (4)

于是，主导法向分量可近似为 û_i=Qũ_i、v̂i=V̂{:,i}、σ̂i=Σ̂{ii}，而无需显式物化 G_N。所得近似对秩扩展局部价值的影响是可控的。

定理3（非精确法向估计下的稳定性）。 设 Ĝ_N∈N_X ℳ_r 满足 ‖Ĝ_N−G_N‖_F≤ε，τ_k=‖G_N−(G_N)_k‖_F。则基于 (Ĝ_N)_k 的秩 k 扩展满足

0 ≤ q_η(−η(Ĝ_N)_k) − q_η(−η(G_N)_k) ≤ 2ηε(τ_k+ε).

完整证明见附录C.3。GEAR随后利用估计的法向谱在全局参数预算下分配秩。受定理2启发，我们按每新增参数的估计局部增益为每个候选法向方向打分，并施加全局秩预算：

a_{ℓ,i} = σ̂{ℓ,i}^2 / (n_ℓ+m_ℓ)，ℬ_target = r̄_budget ∑{ℓ=1}^{L}(n_ℓ+m_ℓ). (5)

其中 r_ℓ 表示模块 ℓ 的当前秩，n_ℓ+m_ℓ 为模块 ℓ 新增一个秩维度的代价，r̄budget 为加权平均秩预算。候选按 a{ℓ,i} 在全局预算与每模块秩上限约束下选取。对选出的 k_ℓ 个方向，令 Û_{ℓ,k_ℓ}=[û_{ℓ,1},…,û_{ℓ,k_ℓ}]，V̂{ℓ,k_ℓ}=[v̂{ℓ,1},…,v̂{ℓ,k_ℓ}]，Σ̂{ℓ,k_ℓ}=diag(σ̂{ℓ,1},…,σ̂{ℓ,k_ℓ})。它们定义候选扩展

X_{ℓ,cand} = X_ℓ − η_b Û_{ℓ,k_ℓ} Σ̂{ℓ,k_ℓ} V̂{ℓ,k_ℓ}^⊤. (6)

我们在各候选变体共享的一小组独立训练微批次上验证 X_{ℓ,cand}，仅当其平均损失改进超过相对裕度 ρ 时才接受扩展；完整细节见附录B.2。

对于被接受的扩展，由于 Û_{ℓ,k_ℓ}⊥U_ℓ 且 V̂_{ℓ,k_ℓ}⊥V_ℓ，低秩状态直接更新为

U_ℓ^+=[U_ℓ, Û_{ℓ,k_ℓ}]，C_ℓ^+=[C_ℓ; −η_b Σ̂{ℓ,k_ℓ} V̂{ℓ,k_ℓ}^⊤]，X_ℓ^+=U_ℓ^+ C_ℓ^+. (7)

被接受的扩展将适配状态从 ℳ_{r_ℓ} 迁移到 ℳ_{r_ℓ+k_ℓ}。与既有分量相关的优化器状态被继承，新引入方向的状态初始化为零。后续更新则遵循3.2节的固定秩流形优化。

3.4 任务诱导的几何初始化（TGI）

秩不足是相对于当前适应空间定义的。为避免将随机子空间失配与真正缺失的方向相混淆，GEAR从小型校准集上估计的任务梯度结构出发初始化该空间。

令 G_0=∇X f(0)。在左探测阶段，设 X=PΩ^⊤，其中 P=0，Ω∈ℝ^{m×h} 固定。这保持了预训练映射，而反向传播给出 Z_0=∇_P f(PΩ^⊤)|{P=0}=G_0 Ω∈ℝ^{n×h}，无需形成 G_0。

为统一表达两个阶段的归一化，记 Z_0∈ℝ^{d×h}，左探测时 d=n，右探测时 d=m。设 M=Z_0^{⊙2}，μ=(dh)^{−1}∑{i,a} M{ia}。为防止过大的梯度尺度主导子空间估计，我们沿两个维度对草图归一化：

d_i^{row}=(1/h)∑a M{ia}+λμ，d_a^{col}=(1/d)∑i M{ia}+λμ，Z̃_0=D_row^{−1/2} Z_0 D_col^{−1/2}，

其中 D_row=diag(d_i^{row})，D_col=diag(d_a^{col})。对左阶段的 Z̃0 做薄QR分解得 Q_L∈ℝ^{n×h}。固定 Q_L，零初始化的右探测 X=Q_L R 给出转置草图 Z_0=(∇_R f(Q_L R)|{R=0})^⊤=G_0^⊤ Q_L∈ℝ^{m×h}。非最终的右阶段用QR更新下一左探测基。TGI执行 p+1 轮左右探测，共 2(p+1) 个阶段。更多轮次可通过以连续更新的基进行探测来精化主导子空间估计；实验中我们取 p=1。

在最终右阶段，归一化草图 Z̃_0∈ℝ^{m×h} 给出 Z̄_0=Z̃_0^⊤=ÛΣV^⊤。保留前 r_0≤h 个分量，初始化

U_0=Q_L Û_{:,1:r_0}，C_0=diag(γ_1,…,γ_{r_0}) V_{:,1:r_0}^⊤，X_0=U_0 C_0. (8)

其中 γ_i 为保留奇异值与保留值均值之比的截断比率。由于 X_0 一般非零，我们在冻结权重中补偿其初始贡献：W̃=W−sX_0，W̃+sX_0=W。由此，训练从一个任务对齐的适应空间出发，同时在初始化时保持预训练前向映射。

4.1 秩审计调度

为确保秩适配稳定，GEAR在训练早中期周期性执行秩增长审计，此后冻结秩。令 t_start 为首次审计步，Δt 为审计间隔，t_final 为秩扩展停止的步数。审计步定义为

𝒯_audit = {t_start + kΔt | k∈ℤ_{≥0}，t_start + kΔt ≤ t_final}.

每次审计中，GEAR估计当前适应空间之外的任务相关方向，并将其作为秩扩展候选进行评估。t_final 之后秩保持固定，训练仅以所得秩进行流形优化。

5 结论

我们提出了GEAR，一个几何引导的动态低秩适配框架，将关注点从容量分配转向当前适应空间的充分性。我们建立了标准因子梯度的一阶信息边界，证明任务相关的法向信息在当前固定秩参数化下不可观测，并进一步将法向谱与秩扩展的局部最优价值联系起来。基于这一分析，GEAR结合固定秩流形优化、高效法向谱估计与任务诱导的几何初始化，依据超出当前一阶可达范围的任务相关方向来适配秩。在常识推理、GLUE与VTAB-1K上，GEAR在所有评估设置中取得最高平均性能，同时使用的可训练参数显著少于强自适应秩基线。总体而言，我们的结果表明，动态秩最有效的视角不仅是预算分配问题，而是适应空间对先前未被表示的任务信息所作出的受控演化。

B.1 低秩回缩

我们详述3.2节中使用的回缩。回顾当前适配状态表示为 X=UC，U^⊤U=I_r，令 D=U^⊤G，K=(I−UU^⊤)GV。利用式(1)的切向梯度分解，回缩前的更新可写为

X^- = U(C−ηD) − ηKV^⊤ = LR，

其中 L=[U, K]，R=[C−ηD; −ηV^⊤]。因此 X^- 的秩至多为 2r，可在不形成完整 n×m 矩阵的情况下进行操作。

我们对两个紧凑因子做薄QR分解，

L=Q_L R_L，R^⊤=Q_R R_R，

得到 X^- = Q_L(R_L R_R^⊤)Q_R^⊤。矩阵 R_L R_R^⊤ 至多为 2r×2r。因此我们只需计算其紧凑SVD，R_L R_R^⊤=PΣQ^⊤，并保留前 r 个奇异分量。回缩后的状态为

X_{t+1} = (Q_L P_r) Σ_r (Q_R Q_r)^⊤。

相应地，更新后的低秩表示可直接得到：U_{t+1}=Q_L P_r，V_{t+1}=Q_R Q_r，C_{t+1}=Σ_r V_{t+1}^⊤。因此，回缩同时恢复了秩 r 约束并更新了下一次迭代所需的左右子空间基，同时避免了对完整适配矩阵的任何SVD。

B.2 秩扩展候选验证

在每次秩审计中，选定的法向方向被视为候选扩展而非立即提交。我们按式(5)的效用分数对提议方向排序，并以不同的出生步尺度构造若干前缀。当前适配器与所有候选变体在匹配随机性的同一组独立训练微批次上评估，使其损失直接可比。

令 L̄_0 与 L̄_cand 分别表示当前适配器与某候选的平均训练损失。定义相对改进为

RI = (L̄_0 − L̄_cand) / |L̄_0|。

仅当 RI＞ρ 时接受该候选，其中 ρ 为规定的接受阈值。在被接受的候选中，我们偏好损失接近最佳观测值的最小秩增量，其次偏好较小的出生步尺度。仅当选定的扩展同时满足每模块秩上限与全局预算时才予以提交。若无候选通过接受准则，则审计保持适配器不变。

B.3 计算与内存复杂度

GEAR在整个训练过程中保持低秩计算结构。对于秩为 r 的适配器，标准LoRA因子更新需要 𝒪((n+m)r) 次逐元素操作，而GEAR中额外的回缩由于薄QR分解与 2r×2r 核心矩阵的SVD，代价为 𝒪((n+m)r^2+r^3)。由于 r≪min{n,m}，该开销仍局限于低秩因子与小核心矩阵，不引入任何完整的 n×m 分解。

提交的适配器状态仅需 𝒪((n+m)r) 内存。TGI在微调前执行一次。在语言实验中，其 2(p+1) 个探测阶段每次初始化运行需要 2(p+1) 次校准反向传播，每个适配矩阵需要 𝒪(h·max{n,m}) 的峰值草图存储。QR与SVD操作代价为 𝒪((p+1)(n+m)h^2)。我们使用 p=1 且 h≪min{n,m}。在VTAB中，初始化改为从三个校准批次聚合所选Q/V投影的密集梯度代理，每个适配矩阵需要 𝒪(nm) 的临时梯度存储。

秩审计仅在计划的审计步引入额外计算。在相同探测宽度 h 下，压缩法向草图的投影、正交化与分解产生 𝒪((n+m)rh+(n+m)h^2) 的低秩线性代数代价与 𝒪((n+m)h) 的临时内存，此外还有用于获取梯度乘积的反向探测。r 与 h 相对于环境维度都很小，且不显式存储任何全梯度或法向矩阵。因此，主要审计开销来自额外的反向探测与候选前向评估，而非大规模矩阵操作。这些计算仅在 t∈𝒯_audit 时执行，而普通训练步仅产生固定秩流形更新。此外，所有探测变量均为瞬态，不对提交的适配器秩或我们实验中报告的可训练参数计数产生贡献。

附录C 证明

C.1 定理1的证明：因子梯度可观测性障碍

证明。 考虑分解映射 Φ:ℝ^{n×r}×ℝ^{r×m}→ℝ^{n×m}，Φ(B,A)=BA。其在 处的微分为 DΦ_{(B,A)}[ΔB,ΔA]=ΔBA+BΔA。

对任意扰动，定义 B(t)=B+tΔB 与 A(t)=A+tΔA。由于满秩矩阵集合是开集，两个因子在足够小的 t 下保持满秩。因此 X(t)=B(t)A(t)∈ℳ_r 在 t=0 附近局部成立，且 Ẋ(0)=ΔBA+BΔA=DΦ_{(B,A)}[ΔB,ΔA]。故 Im DΦ_{(B,A)} ⊆ T_X ℳ_r。

为确定该像的维数，考虑核条件 ΔBA+BΔA=0。由于 A 满行秩，存在右逆 A_R 满足 AA_R=I_r。右乘 A_R 得 ΔB=−BΔAA_R，故 ΔB=BK 对某个 K∈ℝ^{r×r} 成立。代入核条件得 B(KA+ΔA)=0。由于 B 满列秩，ΔA=−KA。反之，每对 均满足 DΦ_{(B,A)}[BK,−KA]=0。因此 ker DΦ_{(B,A)}={(BK,−KA):K∈ℝ^{r×r}}。由 B 满列秩知 K 的参数化为单射，故 dim ker DΦ_{(B,A)}=r^2。由秩–零化度定理，dim Im DΦ_{(B,A)}=nr+rm−r^2=r(n+m−r)。由于 dim T_X ℳ_r=dim ℳ_r=r(n+m−r)，上述包含关系在等维空间之间成立，因此 Im DΦ_{(B,A)}=T_X ℳ_r。

接下来识别 DΦ_{(B,A)} 的伴随。在Frobenius内积下，

⟨G, DΦ_{(B,A)}[ΔB,ΔA]⟩_F = ⟨G, ΔBA+BΔA⟩_F = ⟨GA^⊤, ΔB⟩_F + ⟨B^⊤G, ΔA⟩_F。

故 DΦ_{(B,A)}^(G)=(GA^⊤, B^⊤G)=𝒪_{A,B}(G)。对有限维内积空间之间的任意线性算子 L，有 ker L^=(Im L)^⊥。将该恒等式应用于 DΦ_{(B,A)} 并利用上述刻画，得

ker 𝒪_{A,B} = (Im DΦ_{(B,A)})^⊥ = (T_X ℳ_r)^⊥ = N_X ℳ_r。

最后，对 D=G_1−G_2，𝒪_{A,B}(G_1)=𝒪_{A,B}(G_2) 当且仅当 𝒪_{A,B}(D)=0，等价于 D∈N_X ℳ_r。等价地，D 的切向投影为零，故 (G_1)_T=(G_2)_T。两个命题均得证。∎

C.2 定理2的证明：秩扩展的局部最优性

证明。 令 X=UΣV^⊤∈ℳ_r 为紧凑SVD，U_⊥ 与 V_⊥ 为 U 与 V 的正交补。对任意扰动 H，写

[U^⊤; U_⊥^⊤] H [V V_⊥] = [H_11 H_12; H_21 H_22]。

其法向分量为 H_N=U_⊥ H_22 V_⊥^⊤，其余三个块构成切向分量 H_T。

首先刻画 𝒱_{r+k}={Y: rank(Y)≤r+k} 在 X 处的切锥。在上述坐标下，

𝒞_{r,k}(X) = {H_T+H_N : H_T∈T_X ℳ_r, H_N∈N_X ℳ_r, rank(H_N)≤k}。

为验证该刻画，考虑可行曲线 X(t)∈𝒱_{r+k}，X(0)=X，Ẋ(0)=H。其块形式为

X(t) = [Σ+tH_11+o(t), tH_12+o(t); tH_21+o(t), tH_22+o(t)]。

对足够小的 t，左上块非奇异。由于 rank(X(t))≤r+k，其Schur补的秩至多为 k。除以 t 并令 t→0，得 rank(H_22)≤k。

反之，设 rank(H_22)≤k 并定义 A_t=Σ+tH_11。考虑

X̃(t) = [A_t, tH_12; tH_21, tH_22+t^2 H_21 A_t^{−1} H_12]。

其关于 A_t 的Schur补为 tH_22，故 rank(X̃(t))=r+rank(H_22)≤r+k。此外 X̃(0)=X 且 X̃̇(0)=H，从而建立了所述切锥刻画。

现在在 𝒞_{r,k}(X) 上最小化 q_η(H)=⟨G,H⟩_F+(1/2η)‖H‖_F^2。由于切向与法向空间正交，写 G=G_T+G_N 与 H=H_T+H_N。则

q_η(H) = (⟨G_T,H_T⟩_F+(1/2η)‖H_T‖_F^2) + (⟨G_N,H_N⟩_F+(1/2η)‖H_N‖_F^2)，

仅受 rank(H_N)≤k 约束。对切向分量，

⟨G_T,H_T⟩_F+(1/2η)‖H_T‖_F^2 = (1/2η)‖H_T+ηG_T‖_F^2 − (η/2)‖G_T‖_F^2，

故唯一最小化子为 H_T^⋆=−ηG_T。类似地，对法向分量，

⟨G_N,H_N⟩_F+(1/2η)‖H_N‖_F^2 = (1/2η)‖H_N+ηG_N‖_F^2 − (η/2)‖G_N‖_F^2。

因此，在 rank(H_N)≤k 下，最小化法向项等价于在Frobenius范数下求 −ηG_N 的最佳秩 k 近似。由Eckart–Young–Mirsky定理，H_N^⋆=−η(G_N)_k。故 H_k^⋆=−η[G_T+(G_N)_k]。

最后评估相对于固定秩优化的额外下降。在 T_X ℳ_r 上，min q_η=−(η/2)‖G_T‖F^2；而在 𝒞{r,k}(X) 上，min q_η=−(η/2)‖G_T‖_F^2−(η/2)‖(G_N)_k‖_F^2。因此，

Δ_k = (η/2)‖(G_N)k‖_F^2 = (η/2)∑{i=1}^{k} σ_i^2(G_N)。

故主导法向奇异方向给出最优的局部秩 k 扩展，其平方奇异值决定局部二次模型的额外下降。∎

C.3 定理3的证明：非精确法向估计下的稳定性

证明。 为简洁起见，令 N=G_N，N̂=Ĝ_N，N_k=(G_N)_k，N̂_k=(Ĝ_N)_k。由假设，‖N̂−N‖_F≤ε 且 τ_k=‖N−N_k‖_F。

由于 N_k 与 N̂_k 位于法向空间，它们与 G 的切向分量正交。故对任意法向矩阵 B，

q_η(−ηB) = (η/2)‖N−B‖_F^2 − (η/2)‖N‖_F^2。

将该恒等式应用于 B=N_k 与 B=N̂_k，得

q_η(−ηN̂_k) − q_η(−ηN_k) = (η/2)(‖N−N̂_k‖_F^2 − ‖N−N_k‖_F^2)。

因为 N_k 是 N 的最佳秩 k 近似且 rank(N̂_k)≤k，有 ‖N−N_k‖_F≤‖N−N̂_k‖_F。因此 q_η(−ηN̂_k)−q_η(−ηN_k)≥0。

再证上界。由于 N̂_k 是 N̂ 的最佳秩 k 近似，‖N̂−N̂_k‖_F≤‖N̂−N_k‖_F。利用三角不等式，

‖N−N̂_k‖_F ≤ ‖N−N̂‖_F + ‖N̂−N̂_k‖_F ≤ ε + ‖N̂−N_k‖_F ≤ ε + ‖N̂−N‖_F + ‖N−N_k‖_F ≤ τ_k + 2ε。

将该界代入前述恒等式，得

q_η(−ηN̂_k) − q_η(−ηN_k) ≤ (η/2)[(τ_k+2ε)^2 − τ_k^2] = 2ηε(τ_k+ε)。

因此，0 ≤ q_η(−η(Ĝ_N)_k) − q_η(−η(G_N)_k) ≤ 2ηε(τ_k+ε)。证明完毕。∎
