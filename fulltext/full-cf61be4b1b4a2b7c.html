摘要

奖励无关表示使强化学习智能体能够跨任务复用知识，但有限的表示容量引出三个基本问题：这些表示应捕获何种统计依赖、该依赖的哪些成分应被保留用于策略改进、以及丢弃其余成分如何影响决策？我们通过典型依赖分析解决这些问题。对于参考策略，我们构建了一个以动作为中心、正滞后的典型依赖矩阵（CDM），该矩阵分离了当前动作在当前状态之外的额外预测贡献。其奇异分解产生谱通用优势特征（SUAF），即通过线性奖励投影恢复延迟优势的成对特征。我们证明该谱量化了在给定当前状态下当前动作与未来状态–动作访问之间的互信息，并确定了特定奖励的近似误差。在各向同性平均情形和奖励一致极小极大准则下，保留前若干主模式可给出最优的秩约束近似。分离即时奖励对比也避免了直接压缩完整优势算子所产生的谱底。为从无奖励数据中学习SUAF，我们开发了一种带双向时序差分估计的以动作为中心的Soft-HGR目标。我们进一步将谱近似误差与策略改进的充分条件联系起来。有限状态实验验证了谱预测和特征学习方法，而在离散任务和连续控制基准上的零样本评估展示了所学表示跨奖励的实用性。

1 引言

大语言模型（LLM）和具身人工智能（AI）的最新进展激发了构建在开放环境中运行的通用智能体的日益增长的热情 [Xi et al. (2025); Liu et al. (2025)]。与传统的任务特定模型不同，这些智能体被期望在同一环境中处理多样化的目标、成本和偏好，这些通常由人类指令或变化的任务情境即时指定。尽管这些变化会改变奖励函数，但关于动作如何影响未来结果的知识仍然是可复用的。奖励无关表示旨在捕获这些知识，并支持新任务而无需从头学习单独的评论家。

在奖励无关表示中，后继特征（SFs）通过将奖励权重与特征的折扣累积分离，为此类复用提供了基础框架 [Dayan (1993); Barreto et al. (2017)]。在此基础上，更近期的后继测度（SM）表示寻求使用无奖励交互数据来编码跨策略的行为 [Blier et al. (2021); Touati and Ollivier (2021); Touati et al. (2023)]。然而，一个关键挑战出现了：应该学习哪些特征？为解决这一问题，Ollivier (2025) 通过强行为克隆正则化下的预期下游性能，将最优特征与完整优势算子的谱结构联系起来。尽管有这些理论进展，有限的表示容量仍然引出三个基本问题：这些表示应捕获何种统计依赖、该依赖的哪些成分应被保留用于策略改进、以及丢弃其余成分如何影响决策？

为解决这些问题，我们引入谱通用优势特征（SUAF），一种关于相应行为策略的延迟优势的奖励无关表示。我们的出发点是未来结果同时依赖于状态和动作，而优势度量动作相对于参考策略的贡献。因此，我们分离减去策略平均的未来状态–动作访问后剩余的依赖。基于典型依赖分析 [Huang et al. (2024)]，我们构建了一个当前状态–动作对与未来访问之间的以动作为中心、正滞后的典型依赖矩阵（CDM），其中动作中心化通过减去策略平均的访问进行，正滞后将当前时间步从访问计数中排除。该矩阵的奇异值分解产生当前和未来状态–动作对的成对特征，这定义了所提出的SUAF。SUAF的完整展开通过将下游奖励投影到未来特征上来恢复优势函数。我们进一步证明，即时奖励对比对在低秩下直接近似完整优势算子的最坏情况误差施加了严格正的下界。我们称此下界为谱底。当即时奖励对比可以直接评估时，SUAF通过保持其显式性并仅压缩延迟分量来避免此谱底。对于此延迟分量，SUAF在平均情形和最坏情况奖励目标下都给出最优的秩约束近似。在弱依赖下，我们进一步将奇异值平方和与给定当前状态下当前动作与未来状态–动作对之间的条件互信息联系起来。

然后我们询问丢弃其余模式如何影响决策，并通过投影到被丢弃模式上推导出精确的近似误差表达式，区分被丢弃模式携带的总依赖与其对给定奖励优势的贡献，并获得预测策略改进增益超过近似损失的充分条件。我们进一步界定信任域内策略变化下的局部表示复用。为在不构建CDM的情况下学习SUAF，我们开发了一种带双向时序差分估计的以动作为中心的Soft-HGR目标 [Wang et al. (2019)]，使用无奖励转移中的前向和后向预测器。所学表示支持优势读出和策略提取。实验检验了谱底、截断误差和特征学习精度，并在离散和连续控制基准上进行零样本评估。

总之，我们的贡献有三方面：

  1. 我们通过以动作为中心的正滞后CDM引入SUAF，将延迟优势与当前动作和未来结果之间的依赖联系起来。我们在完整优势算子中识别出一个谱底，这促使显式保留即时奖励对比并仅压缩延迟分量。

  2. 我们为延迟优势的谱近似建立了平均情形和奖励一致极小极大最优性。我们推导出产生策略改进充分条件的特定奖励截断误差。

  3. 我们开发了一种带双向TD估计的以动作为中心的Soft-HGR学习方法。实验验证了谱分析和特征学习性能，并评估了离散和连续环境中跨奖励的零样本策略改进。

2 预备知识

2.1 高维学习的通用特征函数

设 X ∈ 𝒳 和 Y ∈ 𝒴 为两个随机变量，联合分布为 P_XY，边缘分布为 P_X 和 P_Y。假设 P_X(x) > 0 和 P_Y(y) > 0 在其支撑上成立，典型依赖矩阵（CDM） B̃ ∈ ℝ^(|𝒴|×|𝒳|) 定义为

B̃(y,x) = [P_XY(x,y) − P_X(x)P_Y(y)] / √(P_X(x)P_Y(y))。

CDM 是联合分布 P_XY 与独立分布 P_X P_Y 之间的归一化残差。特别地，B̃ = 0 当且仅当 X 和 Y 独立。当 X 和 Y 弱依赖时，‖B̃‖F² ≈ 2I(X;Y)，其中 I(X;Y) 是互信息。设CDM的奇异值分解（SVD）为 B̃ = Σ{i=1}^R σ_i ψ_i^Y (ψ_i^X)^T，其中 σ_1 ≥ σ_2 ≥ ⋯ ≥ σ_R > 0，R ≤ min{|𝒳|−1, |𝒴|−1}。相应的特征函数定义为

f_i(x) = ψ_i^X(x)/√(P_X(x))，g_i(y) = ψ_i^Y(y)/√(P_Y(y))。

这些特征函数在其各自的边缘分布下是中心化和正交归一的。对于任意 k ≤ R，前 k 对 {f, g} 求解广义典型相关问题

max_{{f_i,g_i}{i=1}^k} Σ{i=1}^k 𝔼[f_i(X)g_i(Y)] (1)
s.t. 𝔼[f_i(X)] = 𝔼[g_i(Y)] = 0,
𝔼[f_i(X)f_j(X)] = 𝔼[g_i(Y)g_j(Y)] = 1(i=j),

其最优值为 Σ_{i=1}^k σ_i。k=1 的情形退化为 Hirschfeld-Gebelein-Rényi（HGR）最大相关。在 Huang et al. (2024) 的局部信息几何表述下，这些前导特征函数是通用的，即它们对 Y 的未知弱属性优化平均局部推断性能。

J_r(π_θ) = 𝔼_{s_0∼μ} 𝔼_{π_θ}[Σ_{t=0}^∞ γ^t r(s_t, a_t)]

3 谱通用优势特征函数

本节介绍SUAF并建立其普适性的理论基础。我们首先通过依赖CDM定义SUAF并推导优势函数的精确谱表示。然后我们在秩约束下通过平均情形和极小极大最优性建立其普适性。最后，我们证明直接压缩完整优势会由于即时奖励对比而引入谱底，为显式保留即时奖励并仅压缩延迟分量提供理论依据。

SUAF的奖励无关通用最优性

在本段中，我们提出SUAF对下游任务是通用的。此外，当优势算子以至多 k 的秩近似时，我们证明SUAF对下游任务是极小极大最优的。

定理 3.1（通用优势函数表示）。对于任意奖励函数 r: 𝒮×𝒜 → ℝ，以及 d^π 支撑中的每个，优势函数具有精确表示

A_r^π(s,a) = C_π r(s,a) + γ/(1−γ) Σ_{i=1}^R σ_i^{+,π} f_i(s,a) ⟨g_i, r⟩_{ν^{+,π}}, (4)

其中 C_π r(s,a) := r(s,a) − 𝔼_{a∼π(·|s)}[r(s,a)] 是即时中心化奖励，⟨g_i, r⟩{ν^{+,π}} = Σ{s,a} ν^{+,π}(s,a) g_i(s,a) r(s,a) 是希尔伯特空间 L²(ν^{+,π}) 上的内积。

定义正滞后未来算子为 𝒯^{+,π} r(s,a) = Σ_{s⁺,a⁺} (M^{+,π}(s⁺,a⁺|s,a) − 𝔼_{a′∼π(·|s)}[M^{+,π}(s⁺,a⁺|s,a′)]) r(s⁺,a⁺)，优势函数可写为 A_r^π = C_π r + γ/(1−γ) 𝒯^{+,π} r，其中 𝒯^{+,π} = Σ_i σ_i^{+,π} f_i ⊗ g_i。

inf_{rank(K)≤k} sup_{‖r‖{ν^{+,π}}≤1} ‖A_r^π − Kr‖²{d^π} ≥ α_π + (γ/(1−γ))² (σ_{k+1}^{+,π})², (6)

其中超过 𝒯^{+,π} 秩的奇异值定义为零。

相比之下，精确保留 C_π r 并仅截断未来项会产生如定理3.2所示的无 α_π 的最坏情况误差。如果 ν^{+,π} = d^π，则 α_π = 1，公式6以等式成立。

因此，直接压缩完整优势算子在 k < q 时保留非零误差底，而SUAF近似误差仅遵循延迟谱，并在保留所有非零未来模式后消失。改进来自精确计算已知的即时项，而不是将学习的秩预算花费在表示它上。逐奖励分析请参见附录A.5。

4 方法

在本节中，我们使用截断的SUAF实现策略改进。我们提出两类改进，包括一步更新和信任域更新。之后，我们介绍估计SUAF的方法。

一步策略更新

遵循One-step FB [Zheng et al. (2026)]，我们使用固定行为策略 π 的SUAF执行奖励条件化的策略改进。给定下游奖励 r，我们计算其系数 β_i(r) = ⟨g_i^π, r⟩{ν^{+,π}} 并按照公式5构建 A{r,k}^π(s,a)。改进的策略选择最大化此得分的动作：

π_r⁺(s) ∈ argmax_a A_{r,k}^π(s,a)。

对于连续动作，此最大化可以通过训练一个执行器（部署时冻结）来近似，同时保持SUAF固定。软变体可以用Boltzmann更新替换argmax，如 π_r⁺(a|s) ∝ π(a|s) exp(τ A_{r,k}^π(s,a))。等价地，π_r⁺ 求解KL正则化策略改进问题 max_{π′} 𝔼_{π′}[A_{r,k}^π(s,a)] − τ^{−1} 𝒟_KL(π′‖π)。当 τ→∞ 时恢复贪婪更新，当 τ→0 时恢复 π。

对于仅状态奖励，C_π r = 0，因此以 β(r) 为条件的执行器可以跨系数向量预训练，并在无需进一步参数更新的情况下复用于新奖励。在精确满秩SUAF和精确最大化下，π_r⁺ 相对于 Q_r^π 是贪婪的，因此满足 V_r^{π_r⁺} ≥ V_r^π。这提供了一个策略改进步骤。注意部署到下游任务时无需训练步骤，因此形成零样本部署。

定理 4.1（截断SUAF的Boltzmann策略改进）。设 A_{r,k}^π 为精确的秩-k SUAF优势近似，π_τ(a|s) ∝ π(a|s) e^{τA_{r,k}^π(s,a)}，τ > 0。定义 B_k := sup_{s,a,b} |A_{r,k}^π(s,a) − A_{r,k}^π(s,b)|，ε_k(r) = γ/(1−γ) [Σ_{i>k} (σ_i^{+,π})² β_i(r)²]^{1/2}，Δ_k(r) := ‖A_{r,k}^π‖²_{d^π} − ‖C^π r‖_{d^π} ε_k(r)。如果 Δ_k(r) > 0，则当温度满足 0 < τ < 4(1−γ)²Δ_k(r)/(R_max B_k²) 时，保证 J_r(π_τ) > J_r(π)。

对于仅状态奖励，C^π r = 0 且 Δ_k(r) = (γ/(1−γ))² Σ_{i≤k} (σ_i^{+,π})² β_i(r)²。此时若 Δ_k(r) > 0，更大的充分范围 0 < τ < 4γ/(R_max B_k²) Σ_{i≤k} (σ_i^{+,π})² β_i(r)² 也保证严格改进。

信任域策略梯度

除一步策略改进外，SUAF还可以在局部策略变化下复用。信任域方法约束策略更新以防止破坏性变化 [Schulman et al. (2015); Schulman et al. (2017)]。我们表明从旧策略复用SUAF的误差在信任域内受控。

考虑同一有限MDP中的两个策略 π 和 π_θ，具有共同的初始分布和 0 < γ < 1。假设 d^π 和 ν^{+,π} 具有满支撑。使用在 π 下学习的SUAF f^π 和 g^π，我们通过以下方式近似 π′ 下的优势：

Â_r = C_{π_θ} r + γ/(1−γ) Σ_{i=1}^R σ_i^{+,π} (C_{π_θ} f_i^π) β_i(r), (7)
Â_r^k = C_{π_θ} r + γ/(1−γ) Σ_{i=1}^k σ_i^{+,π} (C_{π_θ} f_i^π) β_i(r)

其中 C_{π_θ} u(s,a) = u(s,a) − 𝔼_{a∼π_θ(·|s)}[u(s,a)]，β_i(r) = ⟨g_i^π, r⟩_{ν^{+,π}}。此近似保留旧特征和奖励系数，同时在新策略下重新中心化依赖动作的特征。与 A_r^{π_θ} 的差异分离了由复用旧策略未来信息引起的误差。

我们用KL散度度量策略偏移：

𝒟_KL(π_θ|π) := 𝔼_{d_S^{π_θ}}[D_KL(π_θ(·|s)‖π(·|s))], (8)
𝒟_KL(π‖π_θ) := 𝔼_{d_S^π}[D_KL(π(·|s)‖π_θ(·|s))], (9)

其中 d_S^π(s) = Σ_a d^π(s,a) 是边缘状态分布⁴。

⁴𝒟_KL(π‖π_θ) 和 𝒟_KL(π_θ‖π) 通常分别称为前向和反向KL散度。

定义动作敏感度

L_max := sup_{‖r‖{ν^{+,π}}≤1} max{max{s,a,b} |A_r^π(s,a) − A_r^π(s,b)|, max_{s,a,b} |A_r^{π_θ}(s,a) − A_r^{π_θ}(s,b)|}. (10)

对于策略梯度 ∇θ J̄_r(π_θ) = (1−γ)∇_θ J_r(π_θ)，我们将近似梯度为 Ĝ_r = 𝔼{d^{π_θ}}[∇θ log π_θ Â_r]，秩-k近似为 Ĝ_θ^k(r) = 𝔼{d^{π_θ}}[∇_θ log π_θ Â_r^k]。

定理 4.2（使用迁移SUAF的策略改进）。给定信任域内 π_ref 的策略 π_θ，即 𝒟(π_θ‖π_ref) < δ，固定满足 ‖r‖{ν^{+,π_ref}} ≤ 1 的奖励 r，定义 u_r := F_θ^† Ĝ_r，s_r := ‖Ĝ_r‖{F_θ^†}，ε_δ := (γL_max²/(2(1−γ)) δ)^{1/2}，其中 F_θ = 𝔼_θ[∇θ log π_θ (∇_θ log π_θ)^T] 为Fisher矩阵。则 ∇_θ J̄_r(π_θ)^⊤ u_r ≥ s_r(s_r − ε_δ)。特别地，若 s_r > ε_δ，则 u_r 是严格上升方向，存在 η_0 > 0 使得 J_r(π{θ+ηu_r}) > J_r(π_θ)，0 < η < η_0。此外，若 θ ↦ J̄_r(π_θ) 在包含更新线段的凸邻域上具有 L-Lipschitz 梯度，则当 0 < η < 2s_r(s_r − ε_δ)/(L‖u_r‖₂²) 时严格改进成立。

定理4.2表明，当估计的梯度信号超过近似误差时，所得的自然梯度方向是严格上升方向，足够小的步长可改进策略性能。这些结果与信任域原则一致，并促使将SUAF作为可复用的评论家集成到现有的策略优化框架中，如TRPO [Schulman et al. (2015)] 和PPO [Schulman et al. (2017)]。训练后，SUAF和奖励条件化的执行器被冻结。对于新奖励，只需计算线性系数，策略通过单次前向传播获得，无需任何执行器更新。

定理 4.3（截断SUAF的策略梯度误差）。在定理4.2的假设下。对于 η_δ = min{1, √(δ/[2(1−γ)])}，B(δ) = min{R_max², 1 + R_max² C_γ √δ}，C_γ = √((4+γ^{−1})/(2(1−γ)²))，

sup_{‖r‖{ν^{+,π_θ}}≤1} ‖∇_θ J̄_r(π_θ) − Ĝ_θ^k(r)‖²{F_θ^†} ≤ B(δ)[√(γδL_max²/(2(1−γ))) + √((γ/(1−γ))²(σ_{k+1}^{+,π})² + L_max² η_δ)]²。

定理4.3表明信任域控制在截断SUAF下仍然有效。策略梯度误差界同时考虑策略偏移和谱截断。较小的信任域控制复用参考策略特征的误差，而保留更多谱模式减少截断误差。当策略不变时，仅剩截断项。相反，当保留所有非零模式时，界随策略偏移消失而趋于零。

Soft-HGR

Soft-HGR通过用协方差惩罚替换硬正交约束提供了一种学习特征函数的方法 [Wang et al. (2019)]。我们将此目标适配到DCDM，并使用双向时序差分（TD）学习来估计长视界条件期望。算法的详细过程见附录E.1。

我们参数化两个 k 维特征函数 f_θ 和 g_ω，分别使用神经网络参数 θ 和 ω，强制 𝔼_π[f_θ|s] = 0，𝔼_{ν^{+,π}}[g_ω] = 0。这些条件通过减去相应的条件和边缘均值实现。在连续空间中，均值使用样本近似。

此外，定义 C_f = 𝔼_{d^π}[f_θ f_θ^T] 和 C_g = 𝔼_{ν^{+,π}}[g_ω g_ω^T]，soft-HGR的特征学习目标为

max_{θ,ω} 𝒥(θ,ω) = 𝔼_{(s,a)∼d^π} 𝔼_{(s⁺,a⁺)∼M^{+,π}(·|s,a)}[f_θ^T(s,a) g_ω(s⁺,a⁺)] − (1/2)tr(C_f C_g). (11)

f_θ 的条件中心化去除了仅由当前状态解释的依赖，因此目标针对由 B̃^{+,π} 表示的依赖动作的后继残差。Soft-HGR学习低秩因子而非单独归一化的奇异函数。然后应用加权白化以获得典型特征对和使用样本矩的估计奇异值。

双向条件预测。原始soft-HGR方法需要完整轨迹，这可能是一种负担。我们转而引入双向Bellman条件预测。公式11中的相关项有两个等价表达式：

𝔼_{(s,a)∼d^π} 𝔼_{(s⁺,a⁺)∼M^{+,π}(·|s,a)}[f_θ^T(s,a) g_ω(s⁺,a⁺)] = 𝔼_{d^π}[f_θ^T h] = 𝔼_{ν^{+,π}}[b^T g_ω], (12)

其中 h(s,a) = 𝔼[g_ω(s⁺,a⁺)|s,a]，b(s⁺,a⁺) = 𝔼[f_θ(s,a)|s⁺,a⁺]。

我们用辅助预测网络估计这些量。对于单步转移 (s,a) ∼ d^π 和 (s′,a′) ∼ P_π(·|s,a)，前向预测器和后向递归满足

h(s,a) = 𝔼_{P_π}[(1−γ)g_ω(s′,a′) + γh(s′,a′) | s,a],
v(s′,a′) = w_1(s′,a′) 𝔼[(1−γ)f_θ(s,a) + γv(s,a) | s′,a′],

其中 ν^{+,π}(s,a) b(s,a) = d^π(s,a) v(s,a)，w_1(s,a) = ν_1^π(s,a)/d^π(s,a)。因此，网络 h_ξ 和 v_η 用TD目标训练

ℒ_F(ξ) = 𝔼_{(s,a)∼d^π} 𝔼_{(s′,a′)∼P_π}[‖h_ξ(s,a) − sg[(1−γ)g_ω(s′,a′) + γh_ξ̄(s′,a′)]‖²₂], (13)
ℒ_B(η) = 𝔼_{(s′,a′)∼ν_1^π} 𝔼_{(s,a)∼p_π}[‖v_η(s′,a′) − sg[w_1(s′,a′)((1−γ)f_θ(s,a) + γv_η̄(s,a))]‖²₂],

其中 sg 表示停止梯度，ξ̄, η̄ 是目标网络参数。密度比 w_1 可以通过与 ℒ_B(η) 共享相同最小值的代理损失 ℒ̂_B(η) 消除。我们将其推导推迟到附录E.1。

交替soft-HGR更新。在预测网络固定的情况下，我们在以下之间交替最小化

ℒ_f(θ) = 𝔼_{d^π}[−f_θ^T sg[h_ξ] + (1/2) f_θ^T sg[C_g] f_θ],
ℒ_g(ω) = 𝔼_{ν^{+,π}}[−g_ω^T sg[b̂_θ] + (1/2) g_ω^T sg[C_f] g_ω]. (14)

在精确条件预测器和总体矩下，这些更新恰好是公式11上的块梯度上升。前向和后向预测器 h_ξ 和 v_η 在每次特征更新期间保持固定。在精确条件预测和总体矩下，这些更新恢复相应的soft-HGR梯度，而无需通过时序差分（TD）解进行微分。在实践中，预测和矩估计误差会引入这些梯度估计的误差。

期望使用样本估计。特别地，ν^{+,π} 样本通过从 d^π 中选择锚点和未来滞后 L 获得，Pr(L=ℓ) = (1−γ)γ^{ℓ−1}。

5 实验

本节评估SUAF是否提供准确的优势表示和跨奖励任务的有效零样本控制。我们首先描述实验设置和评估协议。然后我们使用有限状态环境检验表示精度、分离即时和延迟效应的好处以及由此产生的策略改进。最后，我们在连续运动、导航和操作任务上针对特征学习和基于后继的方法评估零样本性能。

5.1 实验设置

离散有限环境。我们在Grid World [Chevalier-Boisvert et al. (2023)]、Four-room [Sutton et al. (1999)] 和Taxi [Dietterich (2000)] 上评估，分别涵盖基本导航、具有长程信用分配的狭窄通道和组合任务（导航、拾取、交付）。这些领域在状态空间大小和时间结构上有所不同。对于每个领域，我们在固定动力学的同时将奖励任务划分为分布内（ID）和分布外（OOD）集合。表示从行为策略下的无奖励转移中学习，奖励仅用于策略提取。由于状态和转移是可枚举的，我们通过动态规划计算最优回报 J(π*)。

连续状态和动作环境。我们进一步使用四个基于状态的连续控制领域：来自ExORL [Yarats et al. (2022)] 的walker和cheetah，以及来自OGBench [Park et al. (2025)] 的antmaze-large-navigate（简称antmaze-large）和cube-single-play。这些共同涵盖不同奖励下的运动、目标导航和机器人拾取放置。表示在无奖励离线转移上训练并跨下游任务复用。由于表格动态规划不可行，我们遵循基准指标：ExORL的无折扣情景回报和OGBench的任务成功率。

此外，我们通过在预定义的ID/OOD分割下重新训练所有方法来评估对保留奖励任务的泛化。对于Walker，stand和walk是ID任务，run和flip是OOD任务。对于Cheetah，run和run backward是ID任务，walk和walk backward是OOD任务。对于Antmaze-large和Cube-single-play，任务1–2构成ID集合，任务3–4构成OOD集合。

基线。对于基线，我们与奖励无关特征中常用和最先进的方法进行比较，包括Laplacian特征 [Wu et al. (2019)]、BYOL-γ [Lawson et al. (2026)]、TD-JEPA [Bagatella et al. (2026)]、ICVF [Ghosh et al. (2023)]、HILP [Park et al. (2024)]、Forward-Backward [Touati et al. (2023)] 和One-Step FB [Zheng et al. (2026)]。

6 结论

在这项工作中，我们引入了SUAF，一种保留即时奖励对比并将学习容量分配给延迟动作效果的奖励无关表示。这种分解避免了完整优势压缩的即时项谱底，并产生延迟算子的最优谱近似。我们将表示误差与策略改进的充分条件联系起来，并刻画了策略偏移下的局部复用。双向TD提供了一种从无奖励数据学习成对特征的实用方法。实验支持它们在多样化奖励任务间进行零样本策略提取的实用性。结果突出了将直接可计算的奖励信息与学习的时间效应分离的价值，同时将弱谱模式的改进估计和更大策略变化下的可靠复用作为未来工作的方向。

后继特征与奖励分解。经典后继特征 [Barreto et al. (2017); Borsa et al. (2018)] 建模 r_w = φ^T w，产生 Q_{r_w}^π = (ψ^π)^T w，其中 ψ^π 累积折扣特征。SUAF转而从延迟信用中推导 g_i，读出为 β_i^{+,π}(r) = ⟨g_i, r⟩{ν^{+,π}}。残差 r⊥ = r − Σ_{i=1}^R β_i^{+,π}(r) g_i 与所有 R 个非零模式正交，不贡献延迟优势，而 C_π r 保持其即时效应。截断到 k < R 可能丢弃决策相关模式，误差为 ‖A_r^π − A_{r,k}^π‖²_{d^π} = (γ/(1−γ))² Σ_{i=k+1}^R (σ_i^{+,π})² [β_i^{+,π}(r)]²。因此，SUAF优化优势重建而非奖励重建。

最优后继特征。Ollivier (2025) 通过强行为克隆正则化下的渐近下游性能刻画 𝒜_π = C_π(I−γP_π)^{−1} 的前导右奇异函数，未提供学习算法。如果在匹配的平稳测度和 L² 几何下，完整DCDM具有相同的右奇异子空间。然而，我们的 g_i 转而对角化 (𝒟_π^+)* 𝒟_π^+，其中 𝒟_π^+ = 𝒜_π − C_π = γC_π P_π (I−γP_π)^{−1}，通常不同。这样做使我们能够获得对 𝒜_π 可能接近0的近似损失，从而能够控制策略梯度误差。详见附录D.2的讨论。我们的秩-k最优性对固定策略延迟算子是精确的。我们使用Soft-HGR [Wang et al. (2019)] 和双向TD联合估计成对的动作信用和奖励特征。我们强调，仅状态奖励子空间上的 C_π r = 0 不改变SUAF背后的全空间算子。SUAF分解以动作为中心的正滞后DCDM，而完整后继测度、完整优势算子和单步转移核定义不同的谱问题，通常产生不同的特征。

原型后继测度与范围。原型后继测度 [Agarwal et al. (2025)] 以策略无关的仿射基表示跨策略的可行后继测度，M^π = b + Σ_ℓ w_ℓ^π Φ_ℓ。对于 0 < γ < 1，M^π = (1−γ)I + γM^{+,π} 将PSM与 B̃^{+,π} = D_{d^π}^{1/2} C_π M^{+,π} D_{ν^{+,π}}^{−1/2} 联系起来，其中 D_μ = diag(μ)。它去除动作不变的占用，转而在固定 π 下通过 β^{+,π}(r) 编码奖励。精确PSM确定DCDM，但截断的DCDM通常无法重建完整的后继测度。策略相关的中心化和边缘阻止自动继承PSM的跨策略仿射结构。我们的范围是固定策略的奖励复用，而非策略无关的最优控制。使用SUAF的零样本学习请参见附录D.5。

左列显示奇异谱。对于SUAF，我们绘制延迟贡献 D^π := γ/(1−γ) 𝒯^{+,π} 的奇异值，而完整优势曲线从 A^π = C_π + D^π 获得。虚线水平线标记由即时动作中心化算子 C_π 贡献的单位谱底。在GridWorld和Four Rooms中，它恢复 σ_i(A^π) = √(1+σ_i(D^π)²)。因此，即使延迟奇异值很小，完整优势的谱也不能衰减到一以下。直接截断 A^π 因此将秩花费在解析已知的即时项上，而SUAF将其整个秩预算分配给延迟信用分配。One-Step FB谱是未中心化正滞后后继核的谱；其绝对尺度取决于后继测度归一化，因此该曲线主要用于比较谱衰减而非幅度。

中列测量特征子空间之间的差异。设 U_k^D, V_k^D 表示SUAF的前导左右奇异向量，U_k^m, V_k^m 表示方法 m 的相应向量。我们通过 cos θ_i^L = σ_i((U_k^D)^⊤ U_k^m)，cos θ_i^R = σ_i((V_k^D)^⊤ V_k^m) 计算主角度，并报告 RMS-sin = ((1/k) Σ_{i=1}^k sin²θ_i)^{1/2}。值为零意味着两个子空间重合，而接近一的值意味着它们几乎正交。尽管 D^π 和 A^π 的左奇异子空间在平稳的GridWorld和Four Rooms构建中重合，它们的右子空间差异很大。在 k=8 时，右子空间RMS正弦在GridWorld中为0.458，Four Rooms中为0.439，Taxi中为0.438。由于Ollivier提出的特征是 A^π 的右奇异函数，Ollivier和完整A^π的右子空间在构造上是相同的。

与One-Step FB的差异更大。One-Step FB分解未中心化的后继测度，因此保留了仅从当前状态可预测的未来信息。SUAF转而减去此状态可预测分量，仅保留当前动作的增量效应。因此，在 k=8 时，SUAF与One-Step FB之间的右子空间RMS正弦在三个环境中分别为0.612、0.707和1.000。这些主角度提供了SUAF不仅仅学习One-Step FB表示的旋转版本的直接谱证据。

右列评估每个子空间重建延迟算子的程度。对于提供左右子空间的方法，我们报告 Err_D^m(k) = ‖D^π − P_{U_k^m} D^π P_{V_k^m}‖F / ‖D^π‖_F，其中 P_U = UU^⊤。对于Ollivier，仅规定右子空间，因此我们使用最佳无约束左读出，Err_D^Oll(k) = ‖D^π − D^π P{V_k^A}‖F / ‖D^π‖_F。对于SUAF，此误差退化为 Err_D^SUAF(k) = (Σ{i>k} σ_i(D^π)² / Σ_i σ_i(D^π)²)^{1/2}，这是Eckart-Young最优秩-k误差。SUAF因此在每个评估秩下在所有秩匹配方法中实现最低的延迟算子误差。例如，在 k=8 时，SUAF、完整A^π和One-Step FB的误差在GridWorld中分别为0.812/0.855/0.971，Four Rooms中为0.906/0.925/0.994，Taxi中为0.978/0.982/1.000。

A.3.1 DCDM的秩界

对于有限MDP，正滞后未来优势算子满足 R := rank(𝒯^{+,π}) ≤ |𝒮|−1，与动作数量无关。为看到这一点，定义策略平均奖励 r̄π(s) := Σ_a π(a|s) r(s,a)。由于所有未来动作从 π 采样，未来项仅通过 r̄_π 依赖于 r。更明确地，设 (Tv)(s,a) := Σ{s′} T(s′|s,a) v(s′)，P_S^π 为 π 下的状态转移算子。则 𝒯^{+,π} r = (1−γ) C_π T (I−γP_S^π)^{−1} r̄_π。因此，𝒯^{+,π} 通过 |𝒮| 维状态函数空间分解。此外，常数 r̄_π 不产生动作对比，因为 (I−γP_S^π)^{−1} 1 = (1−γ)^{−1} 1 且 C_π T 1 = 0。因此，至多需要 |𝒮|−1 个非零SUAF对来表示未来优势。
