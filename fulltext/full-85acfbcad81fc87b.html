GPT-6.1 Terra：快速强大的电脑操作能力

📅 2026-10-27 📄 OpenAI 🔗 原文链接

原标题：Introducing GPT-6.1 TerraBringing fast and capable computer use to everyone

中文摘要： OpenAI 发布 GPT-6.1 Terra 模型，融合细致视觉推理与精准电脑操作能力，写作更清晰自然。其标准 API 定价比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%。在 Agents' Last Exam 基准上得分提升 15 个百分点，成本仅约三分之一；幻觉错误率从 53.6% 降至 16.7%；Terminal-Bench 4.0 编程任务解决率达 50.3%，实现翻倍。该模型已向 Plus、Pro、Enterprise 和 Edu 用户开放，安全与对齐能力同

GPT-6.1 Terra

大规模提供快速而强大的电脑操作能力

我们隆重推出 GPT-6.1 Terra——一个快速、高效的模型，它将细致的视觉推理与精准的电脑操作相结合，同时带来更清晰、更自然的写作能力。相比 GPT-5.6 Terra 是一次重大飞跃，它擅长处理日常工作中的沟通与电脑任务，从起草提案、解读技术图纸到填写表单、编辑视频。

Terra 持续推进我们各模型系列的性价比前沿，在速度、能力和成本之间实现了新的平衡。其标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%，使开发者能够切实地自动化大批量工作，例如读取收到的发票并将其详细信息录入会计软件。在 ChatGPT Work 和 Codex 中，GPT-6.1 Terra 能让您的套餐发挥更大价值——相同的使用额度可覆盖比 GPT-5.6 Terra 更多的任务，且远多于 GPT-6.1 Sol 或 GPT-6 Astra。

从视觉理解到行动

我们在 Agents' Last Exam 上测量了 GPT-6.1 Terra 的电脑操作能力。这是一个专业任务基准测试，包括将建筑图纸转换为 3D 模型，以及逐镜头审看动画电影，为修复团队创建带时间码的日志。在中等推理强度下，GPT-6.1 Terra 的得分比 GPT-5.6 Terra 高 15 个百分点，而成本仅约为其三分之一。它甚至能与 GPT-6 Astra 表现相当，而每 token 价格仅为其十分之一。在最大强度下，Terra 的 token 效率是 Claude Opus 5.5 的三倍以上，每 token 价格仅为其四分之一，从而使每项任务的成本降低约 9 倍。Terra 的速度也快得多，完成任务的速度比 GPT-6 Astra 和 GPT-6.1 Sol 快三倍以上。

在视觉推理基准测试 MMMU-Pro 上，GPT-6.1 Terra 在所有推理设置下均优于 GPT-5.6 Terra。它甚至以低得多的成本，接近我们最强大的前沿模型 GPT-6 Astra 和 GPT-6.1 Sol 的得分。

OSWorld 2.1 测试 AI 智能体使用桌面应用完成多步骤任务的能力，例如根据技术图纸构建 3D 模型。在中等推理强度下，GPT-6.1 Terra 以远低于 GPT-5.6 Terra 的每任务成本超越了其最佳得分。

在事实性与编程方面取得重大进步

今年，我们投入了大量资源来减少模型产生的幻觉和事实性错误。在我们内部的诱导错误提示基准测试中，低推理强度下的错误率从 GPT-5.6 Terra 的 53.6% 降至 GPT-6.1 Terra 的 16.7%，下降了近 37 个百分点。在最大强度下，错误率下降了 18 个百分点，降至 4.3%，几乎与 GPT-6 Astra 和 GPT-6.1 Sol 的水平相当。

在软件工程方面，GPT-6.1 Terra 相比 GPT-5.6 Terra 有显著提升。Terminal-Bench 4.0 测试编程智能体从命令行解决问题的能力，例如修复一个在加载过程中布局会发生偏移的网页。在最大推理强度下，GPT-6.1 Terra 解决了 50.3% 的任务，是 GPT-5.6 Terra 公布得分 21.5% 的两倍多。对于最复杂的编程任务，GPT-6.1 Sol 和 GPT-6 Astra 仍是更好的选择。

Terminal-Bench-Science 0.1 测试智能体使用代码执行科学研究任务的能力，例如在延时视频中追踪细胞分裂。在最大推理强度下，GPT-6.1 Terra 以更低的成本超越了 GPT-6.1 Sol，与 Opus 5.5 的得分差距在五分以内，而估算成本不到其五分之一。

安全与对齐

随着我们让强大的 AI 变得更高效、更易获取，我们也在持续训练、测试和完善安全保障措施。根据我们的准备框架，GPT-6.1 Terra 在网络安全方面达到了“关键”级别阈值，并保留了为 GPT-6 Astra 开发的各项防护措施。

GPT-6.1 Terra 带来了 GPT-6 系列的对齐改进。根据我们的评估，与 GPT-5.6 Terra 相比，GPT-6.1 Terra 更能保持在任务范围内，并诚实地向用户披露局限性和潜在阻碍因素。在我们的提示注入测试中，GPT-6.1 Terra 对旨在使其偏离用户任务的恶意指令也表现出很强的抵抗力。更多详情请参阅系统卡片（在新窗口中打开）。

定价与可用性

从今天起，GPT-6.1 Terra 面向 ChatGPT Work 和 Codex 中的所有 Plus、Pro、Enterprise 和 Edu 用户开放。开发者也可以通过 OpenAI API 以 gpt-6.1-terra 的名称访问该模型。

标准 API 定价为每百万输入 token 1 美元，每百万缓存输入 token 0.05 美元，每百万输出 token 5 美元。
