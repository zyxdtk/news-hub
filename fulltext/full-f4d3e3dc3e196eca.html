我们正在 ChatGPT、Codex 和 API 中推出 Images 2.6，更快地将您的想法变为现实。借助这一版本，您可以使用 GIF 为图像增添动感——从为品牌吉祥物或角色制作动画，到将产品照片变成引人注目的循环动画。您还可以更快地创建精致的视觉内容，并以更高的精度进行优化——在编辑过程中保持角色、产品和品牌细节的一致性。

目前，全球用户每周通过 ChatGPT、Codex 和 API 创建 40 亿张图像。平均而言，每天创建的图像超过 5 亿张。

更快的迭代和更专业的视觉效果

Images 2.6 的图像生成速度比之前快 50%。在 API 中，我们提供 GPT‑Image‑2.6 Flare 和 Sunburst 供开发者选择。当质量设置为低时，Flare 最快可在六秒内生成图像。对于需要更高细节和精度的工作，当质量设置为中或高时，GPT‑Image‑2.6 Sunburst 可带来更高质量的图像生成，并在多次编辑中保持更高的一致性。Flare 还提升了海报、产品图像和其他专业视觉内容的排版质量。

用 GIF 为您的创意注入动感

在需要动感的时刻，GIF 为您的创意增添了另一个维度。营销人员和创作者可以为活动制作品牌吉祥物动画，为社交媒体创建表情包和梗图，或在视频制作前使用动画分镜来探索角色动作。

而且，您不需要精致的设计就可以开始——即使是一个简单的草图，也可以变成用于视频、游戏等的富有表现力的动画角色。

从个人表情到品牌吉祥物和产品视觉，GIF 为人们和企业提供了一种有趣的沟通方式。Town 是一家构建 AI 工作助手的初创公司，它使用 API 中的 Images 2.6 探索动画角色如何为日常工作互动增添更多个性。

API 中更多的创建和编辑方式

借助 Images 2.6，开发者可以更好地控制图像的创建、编辑方式，以及如何将其带入项目的下一阶段。图像标记（Image markup，已在 ChatGPT 中提供）现已登陆 API，团队可以精确指出需要进行特定更改的位置。SVG 导出使设计可以直接用于网站、应用和印刷。

新的复杂度参数让开发者可以调整模型为满足请求所进行的规划程度，较低的设置适合快速编辑。图像质量控制视觉细节和保真度，而复杂度则指导场景中包含的内容量。

"GPT‑Image‑2.6 将速度与创意控制结合在一起，帮助您在生成和编辑图像的同时，保留定义角色、产品或品牌的关键细节。我们很高兴将其添加到 Figma Weave 中，为团队提供另一个强大的创意制作模型，所有这些都在可复用的工作流程中完成。"

——Figma Weave 创意总监 Itay Schiff

对于大多数编辑任务，我们建议使用低复杂度以获得更快的编辑速度，并搭配您工作流程所需的图像质量。对于包含许多元素或约束的场景，请尝试中或高复杂度。
