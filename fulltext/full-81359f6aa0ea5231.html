视觉生成中文本条件化的缩放特性

📅 2026-07-31 📄 arxiv 🔗 原文链接

原标题：Scaling Properties of Text Conditioning in Visual Generation

中文摘要： 本文研究了视觉生成中文本条件化的缩放特性，发现扩散损失随提示中结构化语言的数量而缩放，而非词元数量。作者引入结构化提示（SP）组织图像信息，并采用GPG和ED两种指标量化信息量。通过提升扩散模型的可扩散性和LLM提示器的可提示性，该系统在多项基准测试中超越了现有开源模型。

摘要

我们研究了视觉生成中文本条件化的经验缩放特性。这些特性很少被测量，因为扩散损失并不随自然语言提示中的词元数量而缩放。令人惊讶的是，我们发现收敛的扩散损失随提示中结构化语言的数量而缩放。为了量化结构化语言，我们采用了两种互补的度量方法：一种白盒似然指标（GPG）和一种黑盒属性指标（ED）。在受控的训练运行中，收敛的扩散损失随 GPG 呈近似线性下降，并随 ED 呈幂律关系。在这些缩放特性的指导下，我们通过构建由图像衍生的语义和几何注释的结构化提示来提高可扩散性，并通过监督微调、冷启动和验证器门控的在线策略蒸馏来训练提示器，从而提高可提示性。最终系统在几乎所有组合、推理和世界知识基准上都优于所有评估的开源权重模型，同时在大多数评估中匹配或超越了最强的闭源权重模型。

1 引言

大型语言模型通过扩大模型规模、训练数据和计算量取得了进展（Kaplan 等，2020；Hoffmann 等，2022）。文本到图像的生成也遵循了同样的配方，采用了更大的扩散骨干、更重的训练运行（Podell 等，2023；Esser 等，2024）和更大的带描述图像语料库（Schuhmann 等，2022）。然而，这种类比隐藏了一个基本的不对称性。语言模型的训练信号来自文本流本身，而文本到图像模型通过图像-描述对学习文本条件生成。描述中模糊绑定的视觉内容仅作为弱条件监督到达模型，而描述中遗漏的内容根本不会到达模型，尽管两者都存在于像素中。因此，描述中基于图像的信息可能限制了生成器能从文本中学习恢复的内容，但这很少被视为一个显式的训练变量。我们询问增加这些信息是否能改善视觉生成，特别是在当前系统难以处理对象、布局、关系和视觉连贯性的信息密集型提示上（Jiao 等，2025；Yang 等，2026；Wei 等，2025）。图 1 预览了答案。给定逐渐变长的自然语言描述，我们评估的每个现有系统都会早早达到峰值（如果有的话），并最终低于其自身的最短描述，而我们在该阶梯上训练的扩散模型仅略有改善便趋于饱和：散文不会缩放，无论系统是仅被其提示还是在其上训练。只有当添加的词元携带更多基于图像的信息时，质量才会持续上升，结构化描述提供了这些信息，并且也预测了收敛的扩散损失。

我们从图 3 所示的固定骨干重建探测开始。从一张参考图像开始，我们对其进行详细注释，然后将其表述为长度逐渐增加的自然语言（NL）描述，并条件化相同的已训练扩散模型以重建参考。因为它们共享一个源注释，这些 NL 描述通过阐述相同的注释实体和关系而不是添加新的实体和关系来变得更长，并且重建很快饱和。这表明仅仅冗长并不能改善扩散模型能恢复的内容，从而促使我们采用一种使视觉变量显式化的表示。因此，我们引入了结构化提示（SP），一种序列化为 JSON 的类型化语义表示。用于全局场景上下文、逐元素属性和几何以及跨元素关系的专用字段以精确、一致可寻址的形式暴露了相同的注释。随着模式覆盖范围的增加，重建效果稳步提升。为了在这个说明性探测之外量化描述信息，我们从先前的工作中采用了两种互补的指标：基础困惑度增益（GPG），测量揭示配对图像在多大程度上提高了冻结视觉-语言模型下描述的似然（Favero 等，2024）；以及有效细节度（ED），测量描述属性相对于基于图像参考的精确率和召回率（Wang 等，2025b；Cheng 等，2024）。

3
技术报告

使用 GPG 和 ED 作为互补度量，我们系统地研究了描述信息量如何影响扩散训练，以收敛的扩散损失作为训练侧的读数。我们扫描了 NL 和 SP 描述格式及细节级别，在保持图像数据、架构、初始化和计算量固定的同时，为每个条件运行单独的扩散训练。在这次扫描中，收敛的扩散损失与 GPG 呈线性函数关系，与 ED 呈幂律趋势。我们将这两种关系称为受控配方下文本条件化的缩放特性。一旦校准，它们可以在另一次扩散训练运行之前对测试范围内的候选描述条件进行排序。因此，它们分离出一种格式侧的能力，我们称之为可扩散性：描述表示在多大程度上有效地暴露和组织基于图像的信息以供扩散学习。为了大规模提高它，我们首先使用一个图像到 SP 的注释管道，结合 VLM 和用于人体姿态、深度和分割的冻结领域专家来生成全模式 SP，然后在由此产生的有组织监督上训练扩散模型。

然而，在测试时，没有配对的图像或预言机注释可用于填充 SP，因此 LLM 提示器必须在保留显式请求的同时，推断出用户未指定的合理视觉细节。我们将此能力称为可提示性。在一项零样本扫描中，生成图像的质量随提示器规模的扩大而提高，并且除了最小规模外，还随思维链推理而提高。这将通用 LLM 的进展与通过描述接口实现的更好生成联系起来，而无需特定任务的训练。我们进一步通过监督微调（SFT）、冷启动蒸馏和验证器门控强化微调（RFT）来提高可提示性；最后阶段在验证的在线策略 rollout 上蒸馏了一个图像条件化的教师模型。在推理时，一个代理式的细化-渲染-判断循环通过修改导致视觉决策失败的 SP 字段，进一步改善了生成。

这两个因素共同产生了一个端到端系统，该系统在除一个报告指标外的所有评估指标上均领先于所有评估的开源权重模型，并在大多数指标上匹配或超越了最强的闭源系统，在组合和推理繁重的基准测试中优势最大。这些增益不仅限于训练损失关系，还延伸到生成图像中的提示保真度、视觉连贯性和组合细节。

总之，我们展示了如何在视觉生成中扩展文本条件化。我们的贡献是：
• 文本条件化的缩放特性。 我们采用 GPG 和 ED 来量化描述信息量，并表明两者在固定训练配方下都能预测收敛的扩散损失。
• 通过结构化提示提高可扩散性。 SP 将基于图像的内容组织到命名字段中，在不改变架构的情况下提高了测量的信息量并降低了扩散损失。
• 通过训练和推理时细化提高可提示性。 我们的 SFT-冷启动-RFT 管道最终以验证器门控的在线策略自蒸馏（OPSD）结束，而字段级代理细化在推理时进一步改善了生成。
• 端到端扩展文本条件化。 结合这两个因素在组合、推理和世界知识评估中产生了广泛的收益。

2 相关工作

文本到图像的缩放、长描述和结构化控制。 扩散模型（Ho 等，2020；Song 等，2021）、潜在扩散（Rombach 等，2022）和 Transformer 骨干（Peebles & Xie，2023；Esser 等，2024）主要通过模型侧的扩展推进了 T2I 生成。条件化也很重要：Imagen（Saharia 等，2022）发现更大的文本编码器能提高保真度，而 LLM 条件化器（Hu 等，2024）、长上下文编码器（Zhang 等，2024）和密集描述语料库（Urbanek 等，2024；Onoe 等，2024）扩展了提示中可用的信息。现有的缩放定律为 DiT 建立了计算-损失关系（Liang 等，2024）；我们则固定模型、数据和计算量，并表明收敛的扩散损失由描述信息（通过白盒 GPG 或黑盒 ED 测量）预测，而不是长度。这种区别与长提示基准一致：DetailMaster（Jiao 等，2025）按词元数量对提示进行分箱，并报告提示长度与字符属性、字符位置和实体关系的准确性之间存在一致的负相关，而 LongT2IBench（Yang 等，2026）报告说，实体、属性和关系的图结构对齐在词数区间内稳步下降。TIIF-Bench（Wei 等，2025）则将每个提示与一个语义等价的长版本配对，发现对这种变化的鲁棒性与整体指令跟随能力相关，最强的模型在两种设置下都保持稳定。

图 4：方法概述：注释和测量、训练、生成。 (a) VLM 和冻结的领域专家将每个训练图像映射到一个 SP（§3.3）；在受控的描述配置中，GPG 和 ED 预测收敛的扩散损失，产生文本条件化的缩放特性（§3.2）。(b) 扩散模型学习 SP → 图像；提示器学习用户提示 → SP，并且提示器侧的比较保持模式和训练好的扩散模型固定。(c) 单次推理将两者组合，一次提示器调用后跟一次扩散模型调用，用户提示→SP→图像。

我们的测量表明，这种行为反映的是信息平台期，而不仅仅是长度。另一条工作线是对扩散模型而不是描述进行干预。布局条件化生成（例如 GLIGEN（Li 等，2023））和注意力操纵方法（例如 Attend-and-Excite（Chefer 等，2023））通过辅助空间条件或模型内部干预来引导固定的扩散模型；而我们的模式将边界框、深度和关系放在普通文本字段中，在相同的 GPG/ED 轴上与自由格式描述进行评分，并针对描述信息而非布局控制。

重描述和描述质量。 DALL-E 3（Betker 等，2023）表明，详细的合成重描述可以显著改善提示跟随；PixArt-α（Chen 等，2024b）、PixArt-Σ（Chen 等，2024a）、CogView3（Zheng 等，2024）和 RECAP（Segalis 等，2023）同样证明了更丰富或更有原则的描述的价值。最近的系统超越了自由格式的散文。FIBO（Gutflaish 等，2025）在长 JSON 描述上进行训练，在匹配的训练下将它们与短描述进行比较，并学习一个从短请求到其模式的 VLM 翻译器。Cosmos 3（NVIDIA，2026）使用结构化 JSON 注释和提示上采样器，表明预定义字段比密集散文提高了注释召回率。Reve 2.0（Reve Team，2026）使用分层布局中介，并报告了相对于纯文本生成的增益以及随着区域增加而改善的重建；Merchant 等（2025）的并发工作研究了一个固定的四部分描述模板。这些结果确立了结构化表示作为一种有用的设计选择。我们的重点是互补的：我们测量跨 NL 长度、嵌套 SP 级别、空间序列化和字段消融的基于图像的信息，然后针对匹配预算的收敛扩散损失校准该公共变量。我们进一步通过改变提示器规模、推理和训练同时保持模式和训练好的扩散模型固定，来隔离提示生成。GPG 将 Favero 等（2024）的每词元基础信号从解码时幻觉定位调整为语料库级描述信息量；ED 将描述细节度评估（Wang 等，2025b）调整为黑盒、基于图像的描述评分；我们加权精确率的匹配器受到 Cheng 等（2024）的启发，他们发现训练文本到图像模型时，描述的精确率比召回率更重要。

LLM 提示器、RFT 和推理时方法。 LLM 已成为有效的推理时提示增强器：RPG（Yang 等，2024b）利用多模态 LLM 推理将提示分解为区域子提示；PromptEnhancer（Wang 等，2025a）将 RFT 应用于带有专用奖励模型的思维链重写器；而输入侧推理时缩放（Chen 等，2025）训练带有迭代 DPO 的重写器。这些方法为固定的生成器改进提示。我们的结构化格式还提高了描述表示的训练时可扩散性；在固定该模式和骨干的情况下，我们研究了 LLM 规模、思维链、来自图像条件化教师的验证器门控自蒸馏以及代理式细化-渲染-判断循环下的提示器可提示性。诸如 ImageReward（Xu 等，2023）之类的奖励模型和诸如 Diffusion-DPO（Wallace 等，2024）之类的模型侧偏好优化优化了生成器，而我们的验证器过滤提示器 rollout，同时 RFT 保持已训练 SP 的扩散模型固定。最后，CLIPScore（Hessel 等，2021）和 VQAScore（Lin 等，2024）测量图像-文本对齐；GPG 测量描述相对于其配对图像的信息量，而 ED 使用一次性基于图像的注释过程，随后进行纯文本评分。

3 方法

我们的目标是理解和利用描述为视觉生成提供的基于图像的监督。我们首先测试了延长自由格式自然语言（NL）描述的标准描述侧干预，发现它并不能可靠地增加有用的监督（§3.1）。这一局限性促使了结构化提示（SP）的产生，这是一种类型化的 JSON 描述，将基于图像的变量组织到命名字段中。图 4 总结了 SP 如何成为我们方法的共享接口。使用 GPG 和 ED，我们量化了每个描述暴露的信息，并在受控的训练扫描中将其与收敛的扩散损失联系起来（§3.2）。由此产生的缩放特性隔离了描述接口在扩散侧的作用；从用户请求实现该接口引入了第二个 LLM 侧因素。我们将两者总结为：可扩散性 × 可提示性：可扩散性捕获描述表示在多大程度上有效地暴露和组织扩散模型学习的监督，而可提示性捕获 LLM 提示器在多大程度上有效地从用户请求实例化该接口。我们通过将训练图像注释为 SP 并将其纳入扩散训练来提高可扩散性（§3.3），并通过扩展和训练提示器来提高可提示性（§3.4）。

3.1 从自然语言描述到结构化提示

大多数现代 T2I 系统根据自由格式的自然语言（NL）描述来条件化其扩散模型，无论是从网络规模语料库收集、重新描述还是由 LLM 生成（Rombach 等，2022；Podell 等，2023；Black Forest Labs，2024；Betker 等，2023）。一种常见的描述侧干预是使这个 NL 条件更长、更详细。图 3 的 NL 行测试了使用固定骨干重建探测器是否有帮助。一个在跨越不同长度和丰富度的描述上训练的 Qwen-Image（Wu 等，2025a）骨干，试图从相同注释实体和关系的四个 NL 描述中的每一个重新生成一张保留的图像。令我们惊讶的是，随着描述变得相当长，重建效果基本保持平缓，而骨干和采样种子是固定的。在这个探测中，添加的散文阐述了现有内容，而没有改善扩散模型恢复的内容。这种饱和促使我们测试一种有组织的表示是否能更有效地暴露基于图像的变量。因此，我们引入了结构化提示（SP），一种类型化的 JSON 描述，将每个表示的视觉变量分配给一个命名字段。

SP 在三个范围内组织基于图像的信息，如图 5 所示。全局字段描述整体意图、场景、氛围、摄影、风格和光照。每个前景对象都有一个逐元素条目，用于其身份、属性、动作、边界框位置、可选深度和摄影，而跨元素关系将这些条目相互绑定。图 3 的 SP 行显示了不同的趋势：随着包含额外的字段组，重建效果稳步提升，这与平缓的 NL 长度扫描不同。该探测激发了这种表示，但一张图像无法确定描述信息量是否可以预测跨训练配置的扩散学习。因此，我们接下来介绍描述侧信息度量和受控训练扫描。

缩放特性。 使用 GPG 和 ED，我们询问描述信息量是否预测在共同训练预算下达到的收敛扩散损失。受控扫描包括从相同的完整图像注释构建的 15 个描述配置。三个 NL 控制在不断增加的长度预算下阐述了相同的核心事实。六个 SP 配置逐步暴露了更丰富的模式子集；第 3.3 节定义了相应的字段阶梯。所有六个都是相同全模式记录的确定性投影，通过掩码预定义字段组并随着细节增加累积恢复它们来获得。其余六个更直接地探测表示选择：三个用 3×3、5×5 或 9×9 网格上的位置替换边界框，三个从全模式 SP 中掩码场景、边界框或关系字段。附录 A.3 报告了完整的扫描及其测量值。

对于每个配置，我们在固定的评估池上计算 GPG 和 ED，并从相同的内部 BAGEL 继续训练检查点（Deng 等，2025）训练一个单独的扩散模型，达到 2.84×10 10 累积图像词元的共同预算。图像、初始化、架构和优化配方在运行中是相同的，使得描述配置成为唯一变化的变量。我们使用 BAGEL，因为用大得多的 Qwen-Image 骨干重复所有 15 次运行将非常昂贵；附录 C 和表 11 提供了完整的设置。

这种校准具有科学和实际意义。在科学上，它将描述信息从描述性属性提升为受控训练变量：在架构、图像和计算固定的情况下，它对跨描述格式达到的损失进行排序。实际上，一次校准后，它可以在相同配方下训练另一个扩散模型之前筛选候选描述配置。配置级别的留出直接测试了这种用途：仅从 NL 和嵌套 SP 族学习的拟合预测了从拟合中排除的所有六个空间和字段变体的收敛 MSE。基于 GPG 和 ED 的拟合分别实现了 5.0×10 −4 和 8.1×10 −4 的平均绝对 MSE 误差，表明该关系可以预测用于估计它的配置之外的配置；在这个误差水平下，筛选分离的是损失差距超过拟合误差的配置，而不是几乎相同的配置。

3.3 提高可扩散性：构建结构化监督

使用领域专家的图像到 SP 注释。 为了在语料库规模上提高可扩散性，我们用忠实的全模式 SP 注释每个训练图像，并使用由此产生的 SP 级别作为扩散训练中的结构化监督。构建该监督是一个异构感知问题：它将全局语义和局部外观及动作与用于人体姿态、深度、范围、遮挡和跨元素关系的专门证据相结合。通用 VLM 能很好地处理语义内容，但在身体侧朝向和精确几何方面仍然不太可靠；如果直接序列化，这些错误将成为显式的条件变量。为了结合这些互补的信号，我们提出了图 8 所示的五阶段图像到 SP 注释管道。冻结的专家提取姿态和几何证据，最后的 VLM 将其与场景语义协调为一个连贯的 SP。附录 C.2 提供了实现细节。

该管道首先建立一个共享的语义框架。阶段 1 读取完整图像以恢复其意图、场景和氛围、风格、光照和相机设置，同时创建一个带有标识符和边界框的有序元素清单。阶段 2 重新访问每个元素裁剪，以便 VLM 可以在较少受到周围场景干扰的情况下解析局部描述、属性、动作和摄影。人类元素额外通过 Sapiens（Khirodkar 等，2024），其 133 个姿态关键点被渲染为 VLM 的叠加层；这一证据帮助它消除身体侧朝向和关节几何的歧义，而不是仅仅从外观推断。阶段 3 提供

3.4 提高可提示性：扩展和训练 LLM 提示器

注释管道在训练期间从配对图像生成 SP，但推理仅从用户请求开始。因此，LLM 提示器必须将该请求转换为 SP。这不仅仅是格式化任务：提示器必须推断出用户未指定的合理视觉细节，并用它们填充模式，而不违反显式约束。因此，我们通过从其 SP 渲染的图像质量来评估可提示性，而不是仅仅通过 JSON 有效性或模式完整性。我们在 SP 级别和 NL 描述的混合上训练一个 Qwen-Image 扩散模型，以便相同的骨干可以适应具有不同结构和丰富度的条件输入。对于下文受控的可提示性扫描，我们固定此扩散模型和 L10 模式，仅改变提示器 π。由此产生的图像差异因此隔离了其模型、推理模式或训练配置（§4.2 中的训练管道消融）。
