实践中的AI代理自主性测量

📅 Feb 18, 20 📄 Anthropic 🔗 原文链接

URL 来源：https://www.anthropic.com/research/measuring-agent-autonomy Markdown 内容：

AI 代理（agents）已然到来，并已在多种差异巨大的场景中投入应用，从电子邮件分类到[网络间谍活动](https://www.anthropic.com/news/disrupting-AI-espionage)。理解这一应用范围的广度，对于安全地部署 AI 至关重要；然而，我们对人们在现实世界中实际如何使用代理所知甚少。

我们利用[隐私保护型工具](https://www.anthropic.com/research/clio)，分析了 Claude Code 及其公开 API 上的数百万次人机交互，旨在探究以下问题：人们赋予代理多大程度的自主权？这种自主权如何随用户经验增长而变化？代理主要运行于哪些领域？代理所执行的操作是否存在风险？

研究发现如下： * [**Claude Code 的自主运行时长正在延长。**](https://anthropic.com/research/measuring-agent-autonomy#claude-code-is-working-autonomously-for-longer) 在运行时间最长的会话中，Claude Code 在停止前的连续自主运行时长在三个月内几乎翻倍，从不足 25 分钟增至超过 45 分钟。该增长趋势在各模型版本间较为平稳，表明其并非单纯源于模型能力的提升，也说明现有模型在实践中可实现的自主性水平尚有提升空间。 * [**经验丰富的 Claude Code 用户更频繁地自动批准操作，但中断频率也更高。**](https://www.anthropic.com/research/measuring-agent-autonomy#expe

* [**经验丰富的用户在 Claude Code 中更频繁地启用自动批准，但也会更频繁地进行人工干预。**](https://www.anthropic.com/research/measuring-agent-autonomy#experienced-users-in-claude-code-auto-approve-more-frequently-but-interrupt-more-often) 随着用户对 Claude Code 的熟悉程度提高，他们倾向于不再逐项审查每一步操作，而是让 Claude 自主运行，仅在必要时才进行干预。在新用户中，约有 20% 的会话使用了完全自动批准功能；而随着用户经验积累，该比例上升至 40% 以上。 * [**Claude Code 主动暂停以寻求澄清的频率高于人类用户主动中断它的频率。**](https://www.anthropic.com/research/measuring-agent-autonomy#claude-code-pauses-for-clarification-more-often-than-humans-interrupt-it) 除人类用户发起的中断外，由**智能体**（agent）主动发起的中断也是已部署系统中一种重要的监督形式。在最复杂的任务中，Claude Code 主动暂停以寻求澄清的频率是人类用户中断它的两倍以上。 * **[智能体已被应用于高风险领域，但尚未实现规模化应用。](https://anthropic.com/research/measuring-agent-autonomy#agents-are-used-in-risky-domains-but-not-yet-at-scale)** 我们公开 API 上的大多数智能体操作风险较低且可逆。软件工程领域占智能体活动的近 50%，但我们观察到其在医疗、金融和网络安全等领域的应用正在兴起。

下文将更详细地介绍我们的研究方法与发现，并为模型开发者、产品开发者及政策制定者提出建议。我们的核心结论是：对智能体实施有效监督，将需要构建新型的**部署后监控基础设施**，并发展新型的**人机协作机制**。
