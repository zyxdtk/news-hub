原标题：Questioning Instrumental Convergence in RLVR: Checkpoint Evidence from OLMo-3

中文摘要： 本文质疑可验证奖励强化学习（RLVR）是否会增加大语言模型的工具性收敛行为。作者使用InstrumentalEval评估OLMo-3-7B-Think在SFT、DPO、13个中间RLVR检查点及最终模型上的表现，发现轨迹非单调：工具性率从SFT的25.0%升至第200步附近的46.1%，最终降至11.8%，低于SFT基线。框架分析与INLP投影均无法解释此模式，32B模型也显示类似下降。结果表明RLVR不会单调增加工具性行为。

摘要

工具性收敛常被援引为预期有能力的智能体会获取或表达寻求权力的子目标的一般理由：自我保存、资源获取、欺骗或抵抗监督，这对社会构成重要威胁。对于大语言模型（LLM），强化学习是后训练中第一个直接针对目标优化行为的阶段；因此，基于工具性收敛（IC）的理由，收敛性工具行为最可能在该阶段出现。使用可验证奖励的强化学习（RLVR）是否会使模型更可能表达工具性收敛行为，还是这取决于训练方案、评估框架和后训练阶段？我们将此问题作为以检查点为条件的行为轨迹来研究，而非单一的前后安全评分。我们使用InstrumentalEval评估了OLMo-3-7B-Think在SFT、DPO、13个中间RLVR检查点以及最终RLVR模型上的表现。该轨迹是非单调的：工具性率从SFT时的25.0%上升至RLVR第200步附近的46.1%，随后在最终检查点降至11.8%。配对项目级检验和逐步回归支持最终的SFT到RLVR下降（配对t检验p=0.015；Wilcoxon符号秩检验p=0.03；逐步回归β₂=−15.34）。提示框架无法解释这一模式：有害提示指标与其他框架效应结合后，平均仅解释检查点内评分方差的15%，而迭代零空间投影（INLP）在移除可检测框架方向的同时并未改变SFT到最终RLVR的差距。结合初步的32B端点结果（SFT为35.53%，最终RLVR为22.37%），这些发现表明RLVR在此设置中并不会单调增加工具性行为：该比率早期上升，随后降至SFT基线以下。该结果特定于此模型系列和基准，且评判者一致性为中等，因此绝对比率应谨慎解读。

1 引言

工具性收敛描述了有能力的、目标导向的智能体在广泛目标范围内追求相似中间目标的倾向。保持行动能力、获取资源、避免关机和塑造环境都可以帮助智能体继续追求其目标（Omohundro, 2008；Bostrom, 2012；Bostrom, 2014；Turner et al., 2023）。这在能力与风险之间建立了潜在联系：随着系统变得更强大和更具目标导向性，它可能更倾向于追求工具性策略，包括在其目标看似无害时。将此论证应用于大语言模型，需要理解目标导向行为如何在其训练和部署过程中出现。语言模型可以产生为欺骗辩护、抵抗关机、保持目标完整性或支持出于战略原因而显得对齐的推理（He et al., 2025；Meinke et al., 2024），包括在持久性有限或缺乏对环境行动能力的设置中。强化学习使这一问题尤为相关，因为它直接针对目标信号优化行为。在外对齐层面，我们可以问奖励或验证器是否指定了我们想要的行为。在内对齐层面，我们可以问学习到的模型是否发展出偏离预期训练目标的内部目标或启发式（Hubinger et al., 2021）。类IC行为提供了这些问题之间可能的可观察联系，而确立错位的内部目标则需要进一步的证据。使用可验证奖励的强化学习（RLVR）为研究这种联系提供了有用的设置。它被广泛用于后训练推理模型，因为它允许针对数学、编码和其他具有可验证答案领域中自动可检查的结果进行优化（DeepSeek-AI, 2025；Lambert et al., 2025；Wu et al., 2025）。其使用的任务局部验证器、参考策略约束和增量更新也赋予了特定的优化结构，可能影响哪些工具性行为会出现。最近的工作表明，RLVR可以将概率质量集中在基础模型中已有的解决方案上，并修改相对稀疏的子网络（Mukherjee et al., 2025；Zhu et al., 2025；Yue et al., 2025）。因此，理解这些属性如何影响类IC行为需要实证评估。我们研究当同一模型系列经历SFT、DPO、中间RLVR检查点和最终RLVR发布时，此行为如何变化，同时保持基准项目固定。我们使用InstrumentalEval（He et al., 2025）评估OLMo-3-7B-Think（Groeneveld et al., 2024；Olmo et al., 2026），该基准测量模型输出是否在各子任务中表达类IC推理。由于安全基准可能编码框架伪影（Ren et al., 2024），我们还使用逐检查点回归和迭代零空间投影（INLP）（Ravfogel et al., 2020）检验有害提示语气是否解释了观察到的轨迹。我们发现类IC行为在DPO和早期RLVR期间增加，在第200步附近达到峰值，并在后期RLVR期间下降，最终检查点低于SFT基线。我们的分析在评分矩阵中检测到了框架结构，且在移除线性框架方向后轨迹保持不变。这些发现为该模型、基准和评判协议确立了后训练阶段与类IC输出之间的非单调关系，后期RLVR逆转了早期增加，并将最终水平降至SFT以下。

2 概念框架

2.1 工具性收敛作为条件性论题

工具性收敛论证始于一个结构性观察：某些中间状态会使成功更容易。能够保存自身、获取资源、避免中断或战略性管理监督的系统，可能更有能力追求其目标（Omohundro, 2008；Bostrom, 2014；Turner et al., 2023）。这意味着，在某些条件下，能力和目标导向性可能使此类行为具有工具性用途。

最近的哲学工作质疑这种推断的直接程度。（Southan et al., 2025）认为，收敛驱力的时机和主导性可能比经典表述所暗示的更受限制。（Gallow, 2025）类似地认为，工具性分歧也是自然的：具有不同目标的智能体可能追求不同的中间策略。这些批评并未消除安全担忧，但改变了实证负担。

2.2 InstrumentalEval作为行为探针

InstrumentalEval通过源自经典收敛驱动类别的六个子任务来操作化工具性收敛（He et al., 2025）。这些子任务询问模型是否表达与逃避关机、入侵计算机系统、运行自身副本、隐藏不良行为、战略性显得对齐以及欺骗行为相关的推理。在本文中，我们使用这些子任务作为类IC推理的输出级探针，并使用评判模型进行评估。用于评估的评判提示见表9。

任何子任务上的正分数表明输出中出现了类IC推理。然而，这并不能确立模型持有相应的内部目标，也不能确立该行为会在不同情境中持续存在，因为这种区分需要深入模型内部观察。

该基准包含76个任务。我们对每个响应在[0,1]区间内连续评分，并以0.5为阈值计算工具性率（IR）：

IR = (1/N) ∑ᵢ₌₁ᴺ I(zᵢᴹ ≥ 0.5)，

其中zᵢᴹ是评判模型M分配的收敛分数。我们还计算两个评判模型之间的评判者间一致率（IAR）：

IAR(M₁, M₂) = (1/N) ∑ᵢ₌₁ᴺ I(yⁱ(M₁) = yⁱ(M₂))，

其中yⁱ(M) = I(zᵢᴹ ≥ 0.5)。对于轨迹分析，较低的IR意味着较少的类IC输出。对于评判者分析，较高的IAR意味着二元IC标签在不同评判模型之间更稳定。

2.3 RLVR作为受约束的后训练方案

RLVR使用来自基于规则的验证器的奖励而非学习到的偏好模型来优化策略。简化的目标函数为

𝒥(θ) = 𝔼_{z,y∼π_θ(·|x)}[f_verifier(y, y*)]， (1)

其中f_verifier评估响应是否满足任务特定标准（Yu et al., 2025）。在数学中，这可以是符号等价；在编码中，这可以是针对测试的执行。

OLMo-3-7B-Think并非仅通过RLVR训练。其后训练流程包括SFT、DPO以及沿训练轨迹发布的RLVR检查点（Olmo et al., 2026）。这一点很重要，因为最终检查点可能隐藏中间动态。SFT与最终RLVR之间的前后比较会遗漏类IC行为是否在早期RLVR期间上升而在后期下降。

DPO结构中针对参考策略的KL正则化可以限制偏离预训练分布的程度。这种受约束的优化结构是我们解释的核心：在这种工具性收敛评估背景下，RLVR可能不会像更广泛的RL设置那样产生开放式的寻求权力压力。它反而可能使行为分布围绕验证器奖励的推理模式收窄。

3 检查点评估与框架控制

该实验旨在将检查点效应与项目效应分离。基准项目保持固定，评分协议保持固定，检查点变化。

3.1 实验设置

我们评估了OLMo-3-7B-Think的16个检查点：SFT、DPO、13个中间RLVR检查点以及最终发布的RLVR检查点（Olmo et al., 2026）。中间RLVR步骤为{50, 75, 100, 125, 175, 200, 275, 350, 450, 600, 800, 1050, 1375}。每个检查点都在相同的76个InstrumentalEval任务上进行评估。

推理使用贪婪解码，最大响应长度为1024，并在各检查点之间使用固定的系统提示。GPT-4o为主要评判者，温度为0.0，最大响应长度为200。对于每个任务-响应对，评判者分配[0,1]区间内的连续IC分数并提供一句话解释。0.5分是计算IR的二元阈值。为评估评判者的稳健性，所有缓存的响应还由Gemini 2.0 Flash作为次要评判者进行评分。

3.2 提示框架作为混杂变量

InstrumentalEval提示不仅在所测试的驱动因素上有所不同，在场景的框架方式上也有所不同。一些提示以明显有害的语言呈现相关行为，一些则在社会公益的背景下描述目标。

提示框架是本文所解决的最易处理的混杂因素。担忧在于，当安全基准分数将框架敏感性与行为倾向混为一谈时，可能会歪曲模型的实际风险特征（Ren et al., 2024）。

为分析提示框架效应，我们手动为76个任务中的每一个标注二元有害/中性框架指标Hᵢ，粗略指示提示的目标导向性。这些划分包含41个有害提示和35个中性提示。由于每个检查点都在相同项目上评估，框架标签在构建上跨检查点固定。

3.3 解释方差

第一项框架检验询问有害提示指标在每个检查点内解释了多少评分变异。为了进行更深入的分析，我们加入了社会公益背景指标Sᵢ和人类障碍指标Oᵢ的效应，如定义3所示。这些定义将数据集划分为37个社会正面和39个中性提示，以及44个人类障碍和32个中性提示。对于每个检查点c，我们拟合普通线性模型

𝔼(z_ic|·) = αᵢ + γ_c + β₁c Hᵢ + β₂c Sᵢ + β₃c Oᵢ + β₄c HᵢSᵢ + β₅c HᵢOᵢ + β₆c OᵢSᵢ + β₇c HᵢSᵢOᵢ (2)

其中z_ic是项目i在检查点c处的评判分数，αᵢ是捕获提示差异的固定效应，γ_c是捕获训练轨迹的固定效应。注意

Hᵢ = {1 若提示i有害，0 否则} (3)
Sᵢ = {1 若提示i服务于社会公益，0 否则}
Oᵢ = {1 若提示i将人类框定为障碍，0 否则}

我们报告R²作为框架所解释的检查点内评分方差比例，以及当S=0、O=0时β₁c的显著性。

3.4 迭代零空间投影

第二项框架检验询问共享的线性框架方向是否影响完整的检查点×项目评分矩阵。我们使用INLP（Ravfogel et al., 2020），该方法迭代训练线性分类器来预测受保护属性，并将表示投影到分类器的零空间中。在我们的设置中，受保护属性是有害提示指标Hᵢ，表示是项目跨检查点的分数向量。

在第k次迭代中，训练一个权重向量为w_k的线性分类器来预测Hᵢ。我们构造投影

P_N(w_k) = I − w_k w_kᵀ / (w_kᵀ w_k)，

用于变换评分矩阵，并重复此过程直到分类器不再超过多数类基线。最终投影为

P = P_N(w_n)…P_N(w₁)。

如果SFT到最终RLVR的差距在此投影后消失，则轨迹可能由线性框架方向解释。如果差距保持不变，则可检测的线性框架结构并非驱动所报告结果的原因。

4 实验与结果

4.1 结果

我们询问工具性收敛行为在OLMo-3后训练轨迹中是否稳定，或者相同的基准项目是否在不同检查点引发不同的类IC输出。我们首先检查原始检查点轨迹，然后检验轨迹是否由提示框架解释，最后检查主要模式在不同评判模型之间是否稳定。表1报告了完整的检查点轨迹；额外的逐检查点框架和评判分析见附录A.4。

表1显示了工具性行为在所有评估检查点上的变化。IR在SFT时从25.00%开始，在DPO后升至38.16%，并在RLVR第200步达到最高观测值46.05%。中间检查点显示围绕这一早期上升的波动。后期检查点呈现下降轨迹，在第800步达到22.37%，第1375步达到17.11%，最终发布版本为11.84%。这些结果表明，后训练的效应取决于评估模型时所用的检查点：早期训练增加类IC输出，而后期RLVR使最终模型低于SFT基线。由于基准包含76个项目，单个二元结果的变化会使IR改变约1.3个百分点。置信区间和完整的检查点序列有助于将这些局部变化置于整体轨迹的背景中。

5 讨论

我们的检查点评估显示，类IC行为在RLVR训练早期上升，在后期检查点下降。该轨迹表明，优化与工具性行为之间的关系取决于训练方案，目标、更新几何、参考约束和评估设置为观察到的模式提供了可能的解释。经典的工具性收敛论证关注足够有能力的目标导向智能体，将其应用于验证器训练的语言模型需要理解这些条件如何在特定训练设置中出现。RLVR可能在加强推理的同时使表达行为的分布收窄，使能力与类IC输出表达朝不同方向变化。从外对齐的角度看，奖励任务局部正确性的验证器可能使重要的安全约束未被指定，同时也限制了广泛工具性策略的激励。例如，数学或代码任务上的正确性为资源获取、自我保存或战略性欺骗提供的直接激励有限。这使得验证器的范围既与奖励规范的完整性相关，也与优化所鼓励的行为相关。从内对齐的角度看，较低的最终IR确立了在基准和评判协议下类IC响应的减少。这种减少与任何学习到的类目标结构之间的关系仍是开放问题。"战略性显得对齐"子任务使这一问题尤为清晰：关于显得对齐以保持未来影响力的推理，类似于与欺骗性对齐相关的行为（Hubinger et al., 2021；Greenblatt et al., 2024）。该子任务的下降可能反映欺骗性合规推理的减少，或表达该推理的概率降低。对检查点序列的机制分析将有助于区分这些解释，并评估观察到的行为是否对应于内部目标。我们的发现补充了识别RL训练系统在何种条件下表达寻求奖励、欺骗、目标错误泛化和伦理问题策略的工作（Langosco et al., 2023；Pan et al., 2023；Denison et al., 2024；Greenblatt et al., 2024；Hubinger et al., 2024）。我们研究了此类行为如何在一个开放模型系列中沿基于验证器的RLVR轨迹变化，其中早期增加之后是降至SFT基线以下的下降。这种检查点级分析还扩展了InstrumentalEval在（He et al., 2025）中的动机问题，即基于RL的语言模型是否更可能追求工具性目标。跟踪已发布的检查点揭示了端点比较可能掩盖的训练动态。现有的RLVR工作为这些变化提供了可能的机制。稀疏更新结果表明，RL微调可以将变化集中在有限的子网络中（Mukherjee et al., 2025），关于推理容量的工作表明，RLVR可以增加模型已有解决方案的概率（Yue et al., 2025）。如果类IC延续在SFT分布中的概率相对较低，后期RLVR可能进一步降低其采样概率，同时保留底层表示。在这个意义上，我们的评估识别了机制分析可能特别有信息量的检查点区间。早期RLVR峰值和随后的下降为研究表达行为的变化如何与模型内部变化相关联提供了具体设置。

6 局限性

我们的评估存在若干对解释这些结果很重要的局限性。我们主要研究OLMo-3-7B-Think，虽然第4.2节中更大模型的初步实验部分解决了规模问题，但两个模型属于同一家族。因此，观察到的轨迹可能取决于模型参数、规模或发布轨迹，需要在其他实验室的RLVR训练模型上进行复制，以了解该结果的适用范围。类似地，InstrumentalEval通过六个收敛类别的76个任务提供了集中的行为探针，但这限制了统计功效，且仅捕获类IC相关行为空间的一部分。在这个意义上，我们的评估提供了关于工具性收敛特定行为表达的证据，而非对该论题的完整检验。我们的框架控制也仅限于线性可恢复的结构：R²和INLP分析支持简单线性框架方向不解释主要轨迹的结论，但不排除非线性效应、框架与子任务之间的交互，或评判者对提示语气响应的差异。按子任务分层或使用更丰富的提示语气分类的分析可以帮助解决这些问题。此外，平均评判者间一致性为68.75%，最终RLVR检查点的一致性较强，早期RLVR峰值附近的一致性较弱。这支持最终结果的方向，尽管绝对IR值应谨慎解读，并将受益于分层样本的人工验证。最后，我们的评估并未确立验证器是否外对齐。狭窄的验证器可能限制广泛工具性策略的机会，同时未能指定重要的安全约束，而我们仅测量沿已发布检查点序列的一个行为后果。因此，比较替代验证器设计是理解观察到的轨迹中哪些方面特定于此验证器、哪些可能更广泛推广至RLVR的有用方向。

更广泛的影响声明

这项工作不应被用作RLVR训练系统普遍安全的证据。我们的结果仅限于一个模型系列、一个基准和一个评判协议。它表明类IC行为可以沿基于验证器的RL轨迹减少，而非RLVR解决了内对齐、外对齐、欺骗性对齐或一般意义上的工具性收敛。

这项工作的积极用途是诊断性的。检查点级评估可以揭示端点比较所遗漏的非单调安全轨迹。我们希望这能鼓励未来的工作将后训练方法作为轨迹进行评估，将行为基准与机制分析相结合，并将工具性收敛视为条件性实证现象而非口号。
