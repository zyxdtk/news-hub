PHP末日：OpenAI与谷歌Wiz发现陈年漏洞

📅 2026-10-21 📄 TechCrunch AI 🔗 原文链接

原标题：PHP Armageddon: OpenAI, Google’s Wiz find ancient holes, panicking the internet

中文摘要： 美国国家安全局（NSA）警告称，PHP 中发现两个严重安全漏洞，而 PHP 驱动着互联网约 70% 的网站。这些漏洞自 2004 年的 PHP 5 起便一直存在。OpenAI 与谷歌旗下 Wiz 借助 AI（GPT-5.6 Sol、Wiz Atlas、Gemini 4 Argon）发现了漏洞，并在公开披露前与 PHP 基金会合作推出补丁。目前尚无在野利用报告，但 AI 大幅降低了黑客利用漏洞的门槛。NSA 建议：无法立即打补丁的网站应暂时下线，并尽快升级至 PHP 8.5.12。

美国国家安全局（NSA）于本周三发出了一则令人震惊的警告：PHP 中被发现两个严重漏洞，PHP 基金会已发布相应补丁。

PHP 是一种服务器端编程语言，被广泛用于 Web 应用，以至于互联网上约 70% 的网站都由它驱动；据某些统计，这相当于超过 3300 万个网站。WordPress 等流行的内容管理系统也在使用它。

NSA 警告称，这些漏洞非常严重，如果网站无法立即打上补丁，就应该先将其下线，直到完成修补为止。这些漏洞允许攻击者渗透服务器的文件系统或 Web 应用可能使用的数据库。

有趣的是，这些漏洞自 2004 年发布的 PHP 5 版本起，就一直潜藏于所有版本的 PHP 之中。未运行相对较新版本 PHP 的网站将有一些更新工作要做，因为 PHP 8.1 及更早版本已不再获得支持。建议将 Web 服务器更新至当前版本的 PHP，即 8.5.12。

那么，两个如此无处不在、存在数十年、影响互联网上几乎所有网站的漏洞，为何会突然曝光？答案自然是 AI，尤其是通过 OpenAI 和谷歌旗下的 Wiz。

安全测试公司 Calif 参与了 OpenAI 的"Patch the Planet"（修补地球）计划，负责查找开源软件中的漏洞。OpenAI 在一篇博客文章中披露，该公司使用 GPT-5.6 Sol 发现了其中一个漏洞。另外，Wiz 团队也借助 AI——具体而言是其 Wiz Atlas 安全 AI 智能体、Gemini 4 Argon 以及 GPT-5.6 Sol——在 PHP 中发现了多个漏洞。

OpenAI 和 Wiz 都遵循了负责任的安全研究实践，在公开披露漏洞之前先与 PHP 方面合作开发补丁。随后，各方通力合作，充实各自的发现并测试补丁，还召集了一大批其他机构前来协助。

Wiz 感谢了 Automattic、Akamai、AWS、Cloudflare、Fastly、Imperva、Microsoft 和 Vercel。（尽管 WordPress 网站使用 PHP，但 WordPress 已发表声明称该漏洞并非 WordPress 所特有，运行其 CMS 的网站必须修补服务器，并与各自的网站托管公司合作，以确保网站得到保护。）

OpenAI 表示，研究人员在黑客之前发现了这些漏洞，因此没有收到任何在野利用的报告。这在一定程度上也是因为在 AI 出现之前，这些漏洞对黑客而言太难利用。"有了 AI，这不再是障碍。LLM 可以帮助将漏洞利用程序适配到不同的 PHP 版本、配置和内存布局，"Wiz 在其关于这些漏洞的博客文章中警告道。

换言之，这是一类因 AI 而被发现和防范的安全问题，但同时也正是因为 AI 才构成了高风险。

如今问题已经披露，黑客们已完全掌握情况。一场竞赛就此展开：互联网要在黑客攻击未打补丁的网站之前，为数千万个网站完成修补。这也正是 NSA 提出如下指导的原因：如果你无法立即为你的 PHP 网站打上补丁，最好先让它下线，直到可以修补为止。
