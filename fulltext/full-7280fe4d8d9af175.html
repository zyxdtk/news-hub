生成式媒体领域日益拥挤，Runway推出AI...

📅 2026-07-23 📄 TechCrunch AI 🔗 原文链接

原标题：Runway launches AI model router as generative media gets crowded

中文摘要： 生成式媒体领域竞争日益激烈，Runway 推出了专为生成式媒体设计的 AI 模型路由器 Media Router。该工具通过 Runway Dev 平台提供，可根据开发者对质量、速度或成本的偏好，自动选择最佳的图像、视频或音频生成模型。此举标志着 Runway 从单纯的 AI 视频初创公司向生成式媒体基础设施层的战略转型，使其在自身模型不再绝对领先的情况下，通过提供最佳的编排层服务保持竞争力。

Runway 不再想仅仅成为又一家 AI 模型公司。它希望成为生成式媒体的基础设施层。

周四，这家初创公司通过其本月早些时候发布的开发者平台 Runway Dev 推出了 Runway Media Router，该平台提供 API 访问权限，不仅支持 Runway 自家的模型，还支持越来越多的第三方图像、视频和音频模型。

Media Router 是一款工具，可根据开发者对质量、速度或成本的优先级，自动为请求选择最佳的图像、视频或音频生成模型。虽然模型路由器在大语言模型领域已变得越来越普遍，但 Runway 表示这是首个专为生成式媒体构建的路由器。

Runway 首席产品官 Anthony Maggio 告诉 TechCrunch：“这种路由真正符合我们成为开发者集成任何类型生成式媒体模型最简单的一站式服务的总体承诺。”

这一独家分享给 TechCrunch 的发布，标志着 Runway 从一家 AI 视频初创公司向为构建生成式媒体的公司提供基础设施的演变又迈出了一步。通过 Runway Dev，包括 Adobe、Cloudflare、ElevenLabs、Expedia、Shutterstock 和 Quora 在内的客户可以使用 Runway 的 API 将媒体生成直接构建到他们自己的产品中，而无需将用户引导至 Runway 自己的应用程序或网站。

该路由器的推出正值生成式媒体模型数量激增之际，这使得开发者评估新版本变得越来越困难和耗时。通过 Runway Dev 平台，开发者可以在最新媒体模型发布时立即访问它们。

“大多数开发者并没有花时间去真正了解这些模型各自的功能，以及它们在视频、图像和音频的各种输出类型中的优势和差异，”Maggio 说。“我们带来的独特主张是，围绕不同用例的最佳模型提供所有这些智能，并将其与您根据业务背景设定的偏好相融合。”

Maggio 指出，中国的生成式媒体模型正变得越来越受欢迎。然而，许多构建自己产品的企业可能对使用来自中国的模型感到不放心，因此他说，他们可能会设定对美国模型提供商的偏好——随着特朗普政府探索对中国开源 AI 模型实施禁令和制裁，这种偏好可能会变得更加普遍。

不过，这只是开发者可以设置的偏好之一。Maggio 表示，客户主要对根据 token 定价和质量进行模型路由感兴趣。Token 定价在 2026 年成为热门话题，因为全面投入智能体 AI 的企业感受到了高昂 token 账单的刺痛。在 LLM 领域，针对 token 定价的模型路由已变得很普遍，因此生成式媒体的路由紧随其后也就顺理成章了。Media Router 的发布也是在 Runway 用基于 token 的定价取代其无限订阅计划的几周之后，这一举动引起了一些用户的批评。

Maggio 说，在质量方面，为任何给定任务决定哪个模型提供最佳质量，对于生成式媒体来说并不像语言模型那么容易。这就是路由器智能层发挥作用的地方。它基于 Runway 内部创意团队在评估各种媒体类型输出方面积累的专业知识——比如视频模型如何处理运动、图像模型如何处理构图，或者语音模型如何处理唇形同步。

Runway 已经为其智能体产品完成了大量构建该智能层的工作，这款于 5 月推出的对话式 AI 创意合作伙伴可以帮助将文本提示转化为经过完全剪辑的多镜头视频和营销活动。

Maggio 表示，Runway Media Router 采用了 Runway 为自己产品构建的相同路由技术，并将其打包供外部开发者使用。

Runway 今天的战略反映了当前生成式媒体领域的碎片化和竞争激烈程度，以及这家初创公司需要多大程度的扩张和转型才能保持竞争力。Runway 上一次发布 AI 视频模型 Gen 4.5 是在 12 月。当时，该模型登上了排行榜榜首，表现优于谷歌等老牌公司的类似模型。同月，Runway 发布了其首个世界模型。

除了 5 月份对其视频编辑模型 Aleph 2.0 进行升级外，Runway 已经几个月没有发布新的专用前沿视频模型了。（TechCrunch 已询问该初创公司计划何时发布 Gen 5。）如今，根据 Artificial Analysis 的数据，虽然 Aleph 2.0 位列领先的视频编辑模型之中，但该公司的文本转视频和图像转视频模型已不再领先排行榜。排名前 20 位的是来自谷歌以及中国字节跳动和阿里巴巴等重量级企业的模型。

Media Router 并不要求开发者押注于单一模型保持领先，而是假设最佳模型会不断变化——这让 Runway 得以留在游戏中，以便继续在前沿进行构建。如果不能作为最好的新 AI 模型，那就作为最好的编排层。

Runway 联合创始人兼联合首席执行官 Anastasis Germanidis 承认，这家初创公司长期以来主要因“面向终端用户的部分”而闻名，但它必须构建一个完整的堆栈才能达到这一目标，该堆栈包括开发者平台、创意工具套件以及底层的推理层。他说，公司看到越来越多的公司对让 Runway 存在于该堆栈的每个部分产生了兴趣。

“底层需要优秀的模型，但编排变得越来越重要，因为人们正在使用这些模型构建整个营销活动，或者使用这些模型生成完整的、多场景的最终作品，”Germanidis 告诉 TechCrunch。“这是我们越来越必须构建的东西——即位于纯像素模型之上的智能层。路由器是将其优势带给用户的一种方式。”

或者正如 Maggio 更宏观的表述：“如果你纵观 Runway 自 2018 年以来一直在做的一件事，那就是我们深度专注于研究，同时为我们认为该领域的发展方向进行构建。”
