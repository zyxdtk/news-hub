大推理模型的最新进展表明，带有可验证奖励的强化学习（RLVR）可以显著改善数学和代码领域的推理能力，因为这些领域的结果可以自动检查。将这一进展扩展到开放式和智能体任务仍然困难，因为可靠的奖励更难获得，而且直接的人类监督无法跟上模型生成经验规模和复杂性的步伐。本文研究当人类监督逐渐从学习循环中退出时，LRM 如何继续改进。我们考察了这个问题的两个相互关联的维度。奖励轴追踪了从单实例人类判断到可重用验证器和奖励的发展，这些验证器和奖励甚至可以在没有人类反馈的情况下运行。经验轴研究了学习如何从人类策划的任务和环境发展到自我生成的课程、构建的环境和自主协同进化。我们通过从 L0 到 L4 的五级阶梯连接这些维度，该阶梯识别了学习过程中哪些部分仍在持续的人类控制之下。我们的分析进一步强调了日益自主的奖励和经验生成所带来的风险，包括奖励黑客、反馈漂移、课程崩溃和环境错误。因此，我们还提供了围绕三个互补对象的评估：策略能力、反馈保真度和经验质量。这一分析提供了对超越人类监督扩展 LRM 的当前方法的结构化说明，以及在开发迈向超智能的自我维持学习系统中所涉及的开放问题。此外，我们维护着一个持续更新的

当人类监督无法再跟上其经验规模和难度时，大推理模型如何继续改进？
我们使用超越人类监督的扩展来描述一种转变，在这种转变中，学习过程中需要持续人类提供的组件越来越少。人类意图仍然至关重要，可以通过目标、初始数据、工具、环境、安全约束和独立审计来表达。核心变化在于学习期间所需的周期性努力，因为模型越来越需要获得有用的反馈并获得有信息量的经验，而不依赖人们来评估或设计每个训练实例。我们通过两个相连的轴来研究这种转变。奖励轴涉及用于评估行为的证据，而经验轴涉及产生模型从中学习的轨迹的任务和环境。
沿着奖励轴，可验证的任务为可扩展反馈提供了最直接的途径，因为正确性基于答案检查或执行。对于没有确切答案的任务，学习到的奖励模型、评分规则和语言模型评判器可以编码评估标准并将其应用于许多轨迹

;
Su et al., 2025
)
。其他方法从模型内部的确定性、采样响应之间的一致性或与可用参考的一致性中得出奖励
(
Prabhudesai et al., 2025
;
Zuo et al., 2025b
;
Zhang et al., 2025o
;
Tang et al., 2025

。当成功在环境中产生可观察的变化时，交互结果提供了另一种基础。总之，这些方法拓宽了可以支持强化学习的经验范围。同时，随着反馈越来越不依赖于独立证据，它变得更容易受到校准不良、相关错误和奖励利用的影响。因此，扩展奖励获取必须伴随着对每个信号的基础以及该基础在优化下如何表现的仔细分析。
仅靠可靠的反馈并不能确保持续的进步，因为学习还取决于应用该反馈的经验。最初，模型可能在固定环境中对人类编写的任务进行训练。它们随后可以生成推理轨迹、合成指令或通过提议者-解决者交互调整任务难度

)

这两个轴最终会收敛，因为如果生成的任务的结果无法评估，它就无法支持学习，而如果模型反复遇到熟悉或无信息的情况，可扩展的奖励就具有有限的价值。因此，持续的改进需要奖励和经验共同发展。在一个成熟的学习循环中，更强的策略揭示新的弱点，这些弱点指导新任务和环境的生成，而可靠的评估将由此产生的轨迹转化为进一步的策略更新。这种协同进化提供了一条可能的路线，使能力增长超越人类监督者的带宽和专业知识。然而，它也创造了紧密耦合的失败模式，因为策略、生成器和评估器可能相互适应，而在独立标准下的性能却停滞或下降。

该框架将两个问题分开：用于改进策略的反馈来自哪里，以及谁决定产生其经验的任务和环境。奖励轴解决第一个问题，从直接的人类判断开始，扩展到可重用的评估器和其他反馈来源。经验轴解决第二个问题，涵盖从固定的、人类设计的训练设置到在学习期间生成或发现的经验的转变。

L0

。每个训练实例都配有人类提供的答案、偏好或判断，作为其评估目标。
L1

。人类标准被编码在可重用的奖励模型、评分规则或语言模型评判器中，允许将相同的评估标准应用于许多轨迹。
L2
超越人类评估的奖励
。训练不是主要依赖人类判断，而是从模型置信度、样本间的一致性、可用参考或可观察的环境结果中得出奖励，而任务和环境在很大程度上仍然由外部提供。
L3
超越人类设计的经验
。随着任务、课程和环境在学习期间被生成、发现、选择或重组，训练分布变得自适应，而人类继续设定广泛的目标、约束和初始条件。
L4
自主协同进化
。反馈、经验和策略改进在一个持久循环中共同适应，而人类的参与集中在意图、安全约束和独立监督的层面。
该阶梯对监督来源进行分类，而不是对整个训练流程进行分类。标准的 RLHF 跨越 L0 和 L1，例如，人类偏好提供 L0 监督，而由此产生的奖励模型用作可重用的 L1 评估器。这些级别之间的边界并不总是清晰的，因为一种方法可能减少一个组件中的人类参与，而在另一个组件中保留它。例如，即使参考答案是由专家编写的，奖励计算也可以自动化。一种方法也可能在继续使用人类设计的环境的同时生成新任务。因此，我们根据学习循环中变得不那么依赖人类输入的部分对每种方法进行分类，同时指出它仍然需要的人类输入。
每一步远离直接的人类监督也会引入不同的错误来源。基于模型置信度或一致性的奖励可能会强化模型输出中共享的错误。基于测试或环境结果的奖励在评估规则不完整时可能会偏向非预期行为。自动生成的任务和环境可能无效、太容易或太困难，而自博弈可能反复产生狭窄范围的经验。第

自训练评估器位于基于人类的评估和在没有人类评估的情况下获得的奖励之间。自奖励语言模型使用相同的模型生成响应并对其进行判断，然后根据得分最高和最低的候选对进行训练

3.3. 超越人类评估的奖励来源
在 L2 处，奖励不再主要依赖于训练用于重现人类判断的评估器。在此机制内，我们区分三种证据来源。模型衍生信号使用策略或其采样输出的属性，包括确定性和一致性。参考锚定信号测量推理轨迹如何支持或重建可用目标。环境基础信号评估可观察的后果，例如执行、正式接受或游戏结果。
这些类别涉及对 rollout 评分时使用的证据，而不是流水线中每个工件的历史起源。参考可能来自人类编写的语料库，人们可能设计了测试、工具或游戏规则
(
Zhou et al., 2025b
;
Yu et al., 2025d
;
Liu et al., 2025h
;
Gehring et al., 2025
;
Liu et al., 2025a

(
Jin et al., 2025

Song et al., 2025a
)

3.4. 局限性和失败模式
随着评估从单实例目标转向可重用或自动获得的信号，监督变得更加可扩展，但错误来源也发生了变化。基于人类的评估器可能会歪曲它们被训练以重现的判断。模型衍生的奖励可能会强化策略自己的错误。参考锚定的奖励可能会过拟合不完整的目标，而环境基础的奖励可能会利用测试或规则中的遗漏。因此，相关的问题不是奖励是否自动，而是在优化下什么证据使其值得信赖。
