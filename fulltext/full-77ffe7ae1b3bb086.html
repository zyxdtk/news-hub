摘要

世界模型将视觉表示转化为预测和行动。我们认为，其视觉基础应结合物理状态信息、原生语言对齐和像素重建，使单一表示能够支持预测、指令和检查。然而，现有编码器通常只专注于其中一两项能力；因此我们提出 ALPS，一种预训练视觉状态编码器，将三种能力统一到单一的 patch token 集合中。仅使用静态图像和文本，我们从零开始预训练 ViT-B/16，采用语言、重建和空间对应目标，然后通过跨视图自蒸馏进行精炼。在十五个公共编码器的统一评估中，ALPS 在 ViT-B 模型中实现了最低的 LIBERO 状态探针聚合误差（与 3.5 倍大的 V-JEPA 2-L 相当），同时保持强大的语言对齐和精确的像素重建。在下游任务中，冻结的 ALPS token 配合我们的原生文本塔，在 LIBERO 上达到最高的平均策略成功率（85.5%），在 PushT、Wall 和 Granular 上的世界模型规划中匹敌或超越领先的编码器，并允许将预测的未来 token 直接解码为像素以进行视觉检查。我们希望这项工作有助于将视觉预训练确立为世界模型中理解、预测和行动的共享基础。

1 引言

世界模型预测场景如何响应行动而变化，并利用这些预测进行规划。许多世界模型在冻结的预训练视觉编码器的潜在空间中运行 [91, 6, 4]。因此，编码器决定了世界模型能看到什么：只有当其 token 编码了物体位置及其所处状态时，下游世界模型才能从稀缺的交互数据中学习该状态如何变化。

两个互补的接口使这样的编码器更加通用。当 token 与语言对齐时，可以用文字表述的指令和目标可以直接与场景关联，而无需第二个视觉编码器。当 token 可以解码回图像时，观察到的场景和想象的未来都可以被渲染和检查。

这引出了一个核心问题：如何预训练一个同时提供物理状态信息、语言对齐和像素重建的单一视觉编码器？

现有的公共编码器通常只专注于其中一两项能力。自监督和聚合模型如 DINOv2、DINOv3 和 C-RADIOv3 提供可迁移的空间特征 [53, 66, 30]，而预测性视频编码器如 V-JEPA 2 通过潜在预测学习时空表示 [4]。同时，图像-文本编码器如 CLIP、SigLIP 2 和 PE-Core 将视觉与语言对齐 [61, 69, 7]，基于重建的编码器在像素或潜在空间中保留精细的视觉细节 [29, 86]。

将状态信息、语言对齐和像素重建组合在单一表示中并非易事。例如，改善图像-文本编码器状态信息的精炼可能会大幅降低其语言对齐能力，如我们在 SigLIP 2 和 CLIP 上所示（第 5.2 节）。

为解决这一矛盾，我们分两个阶段预训练编码器（图 2）。第一阶段在共享表示中建立语言对齐、像素重建和空间特征。我们从零开始在图像-文本对上训练 ViT-B/16，在相同的 patch token 上使用对比对齐、字幕生成、重建和密集对应目标。第二阶段通过跨视图自蒸馏增强状态信息，训练编码器在裁剪、尺度和外观变化下预测场景内容。从增强视图中，学生预测冻结的第一阶段教师在干净视图中对应位置的 patch token。两个阶段都仅在静态图像和文本上训练，不使用视频或交互监督。

我们将最终编码器称为 ALPS（A Language-aligned, Pixel-renderable State encoder，语言对齐、可像素渲染的状态编码器），第一阶段后的中间编码器称为 ALPS（Stage 1）。

我们将 ALPS 与十五个公共编码器进行比较，所有编码器均冻结并在通用协议下评估（表 1）。ALPS 在 ViT-B 编码器中实现了最低的 LIBERO 状态探针聚合误差，与 3.5 倍大的 V-JEPA 2-L 相当，同时保持强大的语言对齐和精确的像素重建。跨视图精炼将状态探针误差降低了 17%，而图像-文本检索变化不超过 0.5 个点，同时也改善了世界模型预测。相比之下，相同的精炼使 SigLIP 2 和 CLIP 的 ImageNet 零样本准确率和图像到文本检索降低了 4-12 个点（图 5）。

冻结的 ALPS token 配合我们的原生文本塔，在 LIBERO 比较中达到最高的平均策略成功率，并在 PushT、Wall 和 Granular 上支持领先的规划性能（第 5.3 节）。预测的未来 token 也可以被解码为图像进行检查。

我们的贡献如下：

  • 我们为世界模型制定了视觉状态预训练方案，并建立了涵盖物理状态信息、原生语言对齐、像素重建以及下游控制、规划和预测的统一评估协议。
  • 我们引入 ALPS，从零开始在静态图像和文本上预训练，采用联合语言、重建和空间目标，随后进行跨视图自蒸馏。
  • 我们证明一个冻结表示可以结合所有三种能力的竞争性能，并作为机器人策略和世界模型的共享视觉基础。

2 相关工作

图 2：两阶段视觉状态预训练。 Stage 1 从零开始训练编码器 E，在共享 patch token 上使用四个目标。Stage 2 从 E 初始化学生，并将 E 冻结作为教师。给定来自增强裁剪 A 的学生 token 和编码位置及相对尺度的查询 token，预测器从干净裁剪 B 回归标准化教师 token。只有中心位于 A 内的 B 的 patch 参与损失计算。训练后，预测器被丢弃，精炼后的学生作为 ALPS。

图像-文本和统一视觉预训练。 对比图像-文本预训练将视觉表示连接到语言 [61, 84]。后续方法引入字幕监督 [82, 40, 44]、自蒸馏和掩码预测 [69]、空间目标 [49, 12]、图像重建 [67] 或自回归 patch 预测 [23]。同时，统一分词器和多模态模型将理解与生成耦合 [46, 89, 76]。其他工作则将冻结的自监督骨干适应到语言，如 dino.txt [32]，或编码生成自编码器的潜在表示，如 OpenVision 3 [86]。我们不是适应冻结骨干或编码自编码器潜在表示，而是第一阶段联合训练未标准化的 patch token 用于语言对齐、像素重建和密集对应，为第二阶段跨视图精炼提供统一的初始化。

自监督和聚合表示。 自蒸馏 [13, 92, 53, 66]、潜在预测 [3, 18] 和多教师蒸馏 [63, 30] 学习可迁移的 patch 表示。为进一步增强密集空间特征，最近的方法将区域特征与裁剪嵌入对齐 [75]、跨视图匹配 patch 邻域排序 [55]、强制局部性对齐 [17]、应用空间精炼如 Perception Encoder [7]，或在多个深度监督预测 [51]。不依赖外部教师，我们的第二阶段通过几何条件化的跨视图自蒸馏从自身冻结的第一阶段权重精炼编码器，在保持原生语言对齐和像素重建的同时锐化状态信息。

机器人学习的视觉表示。 使用预训练视觉表示的策略可以与使用真实状态输入的策略竞争 [54]。机器人表示已从自我中心视频 [52]、掩码自编码 [62, 48]、语言监督 [33]、基础模型蒸馏 [65] 和神经渲染 [93] 中学习。比较研究发现没有单一主导表示 [48]，表明通用视觉数据可以在视觉运动预训练中匹敌自我中心视频 [19]，并指出领域特定预训练不保证在视觉偏移下的鲁棒性 [11]。ALPS 在通用领域图像和文本上预训练，提供可直接迁移到语言条件操作的冻结状态 token 和原生文本塔。

世界模型的表示。 世界模型可以在拟合潜在动力学之前学习视觉自编码器 [27]，与动力学联合学习表示 [28, 47, 36]，或基于预训练特征构建 [6]。特别是，DINO-WM 在冻结的 DINOv2 token 上进行规划 [91]，V-JEPA 2 将视频预训练连接到动作条件规划 [4]，冻结特征也支持语言条件规划 [38]，而 RepWAM 直接从机器人数据学习视觉和动作分词器 [70]。生成式世界模型则使用学习的分词器配合自回归或扩散动力学模拟观察 [50, 9, 1]，或通过像素空间扩散 [2]。最近的研究进一步表明，现成特征不会自动改善基于模型的强化学习中的样本效率 [64]，仅像素重建保真度是从潜在转移中恢复动作的不可靠代理 [80]，静态图像编码器可以根据下游协议优于视频编码器 [68]。我们专注于预训练视觉编码器，其冻结 token 作为下游世界模型的状态表示。

3 方法

设 E 将图像 x 映射到 patch token z = E(x) ∈ ℝ^(N×d)。下游状态探针、策略、世界模型和像素解码器直接在冻结 token z 上操作。对于语言对齐，线性投影 W_img 后接平均池化和 ℓ₂ 标准化将 z 映射到全局图像嵌入 v = norm((1/N)ΣW_img·z_i) ∈ ℝ^D，与文本编码器 E_text 配对。

3.1 Stage 1：从零开始的联合预训练

Stage 1 通过互补的语言、像素和空间监督构建共享表示（图 2，上）。对比对齐和字幕生成将 token 连接到语言，重建保留视觉细节，密集对应跨视图监督局部空间关系。

架构。 图像编码器 E 是 ViT-B/16 [22]，使用固定的正弦-余弦位置嵌入。它输出最后一个 transformer 块的原始 patch token z，没有最终标准化层。我们联合训练一个与 E 相同宽度和深度的文本编码器和字幕解码器（第 S1 节）。轻量级卷积解码器 D 将 z 映射到像素用于预训练重建目标，而所有报告的重建使用在冻结 token 上训练的单独评估解码器（第 4 节）。

目标。 四个目标监督相同的 patch token：

ℒ₁ = ℒ_itc + ℒ_cap + w_rec·ℒ_rec + 0.25·ℒ_dense (1)

对比对齐。 每张图像与其网络字幕和较长合成字幕中的一句话配对。我们在平均池化、投影的图像 token 和每个字幕集之间计算 InfoNCE 损失 [61]，然后平均两个损失得到 ℒ_itc。每个损失使用自己的 softmax，因此与同一图像配对的两个字幕不会被视为彼此的负样本。

字幕生成。 字幕解码器自回归地预测完整的合成字幕，以图像 token 和前文为条件 [82]。

重建。 解码器 D 从 z 和 z 的噪声副本重建 x。目标结合 ℓ₁、结构相似性和图像梯度项（第 S1 节）。我们不 对 x 应用颜色增强，x 直接作为重建目标。

密集对应。 此目标直接监督跨裁剪、尺度和翻转的 patch 对应。我们通过 x 的随机裁剪和翻转形成第二视图 g(x)，因此原始视图中每个 patch 的位置是已知的。一个小投影头将两个视图的 token 映射到对比特征。对于 g(x) 的每个 patch，正样本特征从 x 的投影 token 场中在对应位置双线性采样。同一图像中其他位置和其他图像的特征作为 InfoNCE 损失 ℒ_dense 的负样本（第 S1 节），鼓励局部可判别性。遵循密集对应和像素级一致性的先前工作 [71, 77]，此项为全局图像-文本对齐和单图像重建添加了显式的跨视图 patch 监督。

数据。 我们在 DataComp-1B [24] 上训练，使用其网络字幕和由 Recap-DataComp-1B [39] 的 LLaVA-LLaMA-3 字幕生成器生成的合成字幕，以原始网络字幕为条件 [44]。因为字幕生成器使用冻结的 CLIP ViT-L/14 [39]，来自该图像-文本模型的知识仅通过文本到达我们的编码器；没有外部视觉模型提供特征目标。训练在 128×128 分辨率下处理 128 亿样本，然后在 224×224 分辨率下处理 10 亿样本（第 S1 节）。Stage 1 后，我们保留图像编码器、文本编码器和图像投影，同时丢弃字幕解码器、密集对应投影器和 D。

图 3：LIBERO 状态探针。 (a) 轻量级探针从最后 16 帧读取冻结 token，仅从观察估计当前场景状态（读出）或在给定机器人动作的情况下预测 1 或 3 秒前的状态（预测）。(b) ALPS 和 SigLIP 2 的 3 秒前状态预测，叠加在 3 秒后观察到的帧上，显示在两个编码器之间误差差值中位数的 LIBERO-Spatial 保留集上。(c) 此步骤的每物体位置误差、被操作碗在整个回合中的误差及其在 50 个保留回合上的平均误差。

3.2 Stage 2：单图像上的跨视图自蒸馏

Stage 2 通过跨视图自蒸馏精炼共享表示（图 2，下）。从增强裁剪中，学生预测冻结 Stage 1 教师对同一图像干净裁剪产生的 token。已知的裁剪几何指定目标位置，监督集中在视图之间的重叠区域。

教师和学生。 冻结教师和可训练学生都从 Stage 1 编码器初始化，只有学生编码器和预测器被更新。训练前，我们计算固定的每通道统计量以在整个阶段标准化教师 token。对于每张图像，我们独立采样两个视图：教师接收覆盖图像 40% 到 100% 的干净裁剪 B，而学生以等概率接收局部裁剪 A（10% 到 40%）或带光度增强的全局裁剪（40% 到 100%）（第 S1 节）。

几何查询。 几何查询指定预测器应估计教师特征的位置和尺度。四层 transformer 预测器 P 读取学生 token E(A) 并为与 B 的 patch i 关联的每个查询 q_i 产生一个输出。在每层中，查询首先彼此注意，然后注意 E(A)。裁剪框确定 A 坐标系中每个教师 patch 中心的位置。每个查询使用固定的正弦-余弦嵌入编码此位置（以 A 的 patch 单位测量），并通过学习的嵌入编码 B 与 A 的对数边长比（表 S2）。查询因此提供几何对应，而学生特征提供用于预测教师 token 的视觉内容。

训练目标。 设 V 表示中心落在学生裁剪 A 内的教师 patch 集合。我们在 V 上最小化预测特征与标准化教师 token 之间的均方误差：

ℒ₂ = (1/|V|d)Σ_{i∈V} ||P(E(A), q_i) − z̄_i^teacher(B)||² (2)

V 外的 patch 被排除在损失之外，如果 |V| < 16 则重新采样学生裁剪。与未见区域的掩码预测不同，此几何条件化目标训练局部 patch token 在裁剪上下文、尺度和外观变化下保持一致，同时与冻结的 Stage 1 教师保持对齐。

数据和输出。 Stage 2 在从精选的公共图像编辑数据集中抽取的 500 万单图像样本上训练（第 S1 节）。这些源提供高分辨率、以对象为中心的场景，非常适合局部跨视图裁剪，我们将它们作为单独图像采样，不使用编辑对或指令监督。训练后，我们丢弃预测器并保留精炼的学生编码器作为 ALPS，直接与未更改的 Stage 1 文本编码器和图像投影配对。

编码器。 我们将十五个公共编码器与我们的第一阶段编码器和 ALPS 进行比较（表 1）。十四个公共模型是图像编码器，而 V-JEPA 2 ViT-L [4] 是视频编码器，接收 256×256 分辨率的最后 16 帧并输出当前帧的 token。我们的主要比较使用 224×224 分辨率的 ViT-B 图像塔（B/16 为 196 个 token，B/14 为 256 个），取每个编码器最后一层 patch token 及其默认标准化。除 ViT-B 模型外，OpenVision 2、V-JEPA 2 和 dino.txt [32] 作为 ViT-L 参考；对于 dino.txt，我们提取其语言对齐视觉头之后的 patch token。

状态探针。 状态探针直接从冻结 token 评估场景状态读出和动作条件预测（图 3）。使用 LIBERO-Object 和 LIBERO-Spatial [42] 的演示，两层注意力探针（2.5M 参数）读取最后 16 帧的 token，以估计可移动物体的 3D 位置、方向和二元谓词，与模拟器真实值对比。在读出设置中，探针仅从帧估计当前状态；在两个预测设置中，它还接收未来 1 或 3 秒的机器人动作以预测该时间范围的未来状态。我们报告相对于我们第一阶段编码器的位置误差，在两个套件和三个设置的六种组合上平均（表 S4 报告以厘米为单位的绝对误差）。世界模型则在潜在空间中预测未来 token 并单独评估（第 5.3 节）。

语言对齐。 我们使用每个模型的原生文本塔评估语言对齐，报告 ImageNet-1k [20] 零样本准确率和 Flickr30k [81] 和 COCO [41] 上图像-文本检索的 Recall@1。对于未发布配对文本塔的编码器，这些指标标记为 n/a，表示缺少原生文本接口而非特征中缺少语义信息。C-RADIOv3 使用其两个语言适配头中较强的那个，而 ALPS 使用其未修改的 Stage 1 语言接口。

像素重建。 为了在同等基础上评估像素重建，我们为每个编码器训练一个单独的轻量级卷积适配器，将其冻结 token 映射到冻结 SDXL 自编码器 [57] 的潜在表示以进行图像解码。适配器在 19,000 张 ImageNet 验证图像上训练，在 1,000 张保留图像（每类一张）上使用 ℓ₁ 误差和 LPIPS [87] 评估。虽然更大的生成解码器可以从 DINOv2 或 SigLIP 2 token 重建合理的图像 [90]，但我们的协议测量轻量级探针可直接恢复的视觉细节，并且 ALPS 在配对更强解码器时保持其优势（第 S2 节）。

控制。 对于视觉运动控制，我们在四个 LIBERO 套件中通过行为克隆在冻结视觉 token 上训练 LIBERO transformer 策略 [42]，每个任务 50 个演示。任务指令由冻结 BERT 模型 [21] 或每个编码器的原生文本塔嵌入。每个训练的策略在每任务 50 次 rollout 上评估三次（第 S2 节）。

世界模型预测和规划。 我们在 PushT、Wall、PointMaze、Granular 和 Rope 上遵循 DINO-WM 协议 [91]，在 Reacher 上遵循 LeWorldModel [47]。在每个任务上，我们在每个编码器的冻结 patch token 上训练相同的动力学预测器，以支持交叉熵规划和多步预测评估（第 S2 节）。

5 结果

5.1 一个编码器用于状态、语言和像素

图 4：从冻结 token 重建。 按照输入列，每列显示评估解码器从一个编码器冻结 token 的输出，标注其在 1,000 张保留 ImageNet 图像上的平均 ℓ₁ 误差。行显示随机样本的前三张图像（图 S7）。ALPS、OpenVision 3、MAE 和 VC-1 保留锐利边缘和纹理。C-RADIOv3 和 DINOv3 以较柔和的细节保留空间布局，而 SigLIP 2、PE-Core 和 CLIP 主要恢复粗略结构。

表 1 和图 4(b) 在状态信息、语言对齐和像素重建方面将 ALPS 与十五个公共编码器进行比较。

状态。 ALPS 在比较的 ViT-B 编码器中实现了最低的聚合相对位置误差（.829），其次是 C-RADIOv3（.864）和 DINOv3（.870）；这三个模型组成了领先 PE-Spatial（.936）的领先组。ALPS 在三个单独设置（读出、+1s 和 +3s）以及 256×256 分辨率渲染的帧上也达到最低误差（表 S6）。虽然 V-JEPA 2-L 使用 3.5 倍的参数和视频预训练匹配其聚合误差，但两个模型显示互补优势：V-JEPA 2 更准确地读出当前状态（.741 vs .842），而 ALPS 在 3 秒预测上更准确（.813 vs .904）。与 SigLIP 2 和 PE-Core（1.160 和 1.170）相比，ALPS 将聚合状态探针误差降低约 29%，探测其中间层缩小但不消除这一差距（第 S2 节）。在移动物体上，ALPS 在四个预测设置中达到 3.22 cm 的平均误差，与 V-JEPA 2、DINOv3 和 C-RADIOv3 的 3.04-3.25 cm 范围相匹配（表 S5）。

语言。 ALPS 保持接近我们比较中最强图像-文本编码器的检索性能。它在 Flickr30k 上达到 93.2/78.9 Recall@1，在 COCO 上达到 70.2/51.9（图到文/文到图），在四项措施中的每一项都在最佳分数的 2 个点以内。其 ImageNet 零样本准确率为 73.4，而 PE-Core 为 78.4，PE-Core 是该指标上最强的 ViT-B 图像-文本编码器。在描述性合成字幕上预训练时，分类上这 5.0 个点的较大差距是预期的，因为其分布与简短的 ImageNet 类别提示不同 [43]。

图 5：相同的 Stage 2 精炼应用于 ALPS (Stage 1)、SigLIP 2 和 CLIP，每个使用自己的冻结副本作为教师。 线连接精炼前后的每个编码器，星标标记 ALPS。语言通过每个编码器未更改的头评估。每个面板中值越高越好，(a) 中相对于 ALPS (Stage 1) 的状态探针误差被反转。端点标签显示 Stage 2 后的值及其变化（表 S20）。三者都改善状态信息，但只有 ALPS 保持语言对齐。

像素。 ALPS 保留可直接从其 token 解码的精细视觉细节。使用评估解码器，ALPS 达到 .120 的 ℓ₁ 误差和 .372 的 LPIPS（图 4），产生比每个未明确训练重建像素或潜在表示的比较编码器更低的 ℓ₁ 误差。特别是，C-RADIOv3 的 ℓ₁ 误差高 34%（.161），DINOv3 高 63%（.196），图像-文本编码器的误差超过两倍。预训练重建像素的编码器（MAE 为 .109，VC-1 为 .106）或自编码器潜在表示（OpenVision 3 为 .104）重建更准确，但产生 14% 至 22% 更高的状态探针误差。LPIPS 给出略有不同的排序：这三个以重建为重点的编码器得分为 .243-.260，C-RADIOv3 也略优于 ALPS（.359，约低 4%）。然而，在更强的解码器配置下，ALPS 保持比 C-RADIOv3 更低的 ℓ₁ 误差（.107 vs .141，约低 24%）并在 LPIPS 上超过它（.302 vs .311；表 S18）。

三者兼备。 ALPS 在一个冻结表示中结合了领先的状态探针性能、强大的语言对齐和精确的像素重建。其他领先的状态编码器具有较弱的检索或没有配对文本塔，而具有可比检索或较低重建误差的编码器具有更高的状态探针误差。我们使用这些接口进行指令条件控制和预测世界模型 rollout 的视觉检查（第 5.3 节）。

5.2 跨视图精炼对状态和语言的影响

跨视图精炼将我们的编码器移入领先的状态组：精炼前，ALPS (Stage 1) 的状态探针误差高于表 1 中七个公共 ViT-B 编码器，而精炼后它达到最低。图 5 比较了相同 Stage 2 配方在我们的第一阶段编码器、SigLIP 2-B/16 和 CLIP-B/16 上的应用，每个训练 500 万样本，以自己的冻结副本作为教师，通过未更改的语言头评估（表 S20）。对于我们的编码器，在 DataComp 网络图像上精炼也降低状态探针误差，但在相同训练预算下不如我们默认的精选集合（.886 vs .829），反映了场景内容和原生分辨率的差异（第 S3 节）。

所有三个编码器在状态探测上都有改善。 Stage 2 将我们编码器的聚合状态探针误差降低 17%（六个单独设置为 14% 至 19%），并将 DAVIS 视频对象分割从 .456 提高到 .533（第 S2 节）。类似地，SigLIP 2 在状态探针上从 1.160 改善到 .893，在 DAVIS 上从 .503 改善到 .552，而 CLIP 分别从 1.194 改善到 .898 和从 .574 改善到 .585。

只有我们的编码器保持其语言对齐。 对于 ALPS，状态准确性的改善伴随其他能力的最小变化：图像-文本检索变化最多 0.5 个点，ImageNet 准确率变化约 1 个点，重建保持接近其第一阶段水平（ℓ₁ .120 vs .112，LPIPS .372 vs .365）。相比之下，公共编码器失去更多的语言性能。SigLIP 2 在 ImageNet 准确率上下降 4.3 个点，在 Flickr30k 和 COCO 图像到文本检索上分别下降 7.5 和 11.4 个点，而 CLIP 分别下降 10.2、10.9 和 11.8 个点。这些结果表明跨视图精炼可以在保持其他接口的同时增强状态信息，但这种平衡关键取决于被精炼的编码器。

降低学习率不能消除语言差距。 为了测试 SigLIP 2 是否只需要更小的步长，我们将其编码器学习率从 10⁻⁵ 降低到 3×10⁻⁶，同时保持所有其他设置不变。其状态探针误差然后下降 17%（从 1.160 到 .959），与我们编码器的相对降低（从 1.000 到 .829）相匹配。但它在每个语言指标上仍然失去更多：图像到文本 Recall@1 在 Flickr30k 上下降 2.3 个点，在 COCO 上下降 2.9 个点，而 ALPS 分别为 0.2 和 0.4（第 S5 节）。在默认精炼计划下，ALPS 在其 patch token 和图像嵌入中也表现出较小的漂移（第 S5 节）。一个关键的结构差异在于语言读出：ALPS 线性投影平均池化的 patch token，而 SigLIP 2 使用非线性注意力池化，CLIP 读取类 token。因为线性投影与平均池化可交换，零均值局部 token 更新可以在池化图像表示中抵消，即使在 Stage 2 中没有显式语言约束。

状态、语言和像素。 第一阶段目标对三种能力的贡献不同。我们在 Stage 1 计划的十分之一处从零开始训练每个变体，然后应用相同的 Stage 2 精炼（表 5）。所有变体保留对比对齐，因此消融测试三个辅助目标。重建损失对像素接口至关重要：没有它的两个变体在 Stage 1 后产生 72% 和 78% 更高的 ℓ₁ 重建误差（.194 和 .200 vs .113）。移除重建或字幕分别将状态探针误差降低 8.5% 和 4.3%，表明辅助任务之间的容量权衡。在所有变体中，Stage 2 将状态探针误差降低 14% 至 19%，很大程度上保持语言性能，ℓ₁ 误差变化小于 4%。因此我们在完整配方中保留所有目标，以少量状态探针准确性换取精确的像素解码，同时在大规模上仍优于专业化的 ViT-B 空间编码器（表 1）。

跨目标的语言保持。 即使没有三个辅助目标，精炼也保持语言对齐。对于仅对比变体，ImageNet 零样本准确率从 69.8 变为 67.9，而图像到文本 Recall@1 在 Flickr30k 上从 91.0 变为 89.3，在 COCO 上从 67.1 变为 64.1。因此，在此减少预算的设置中，辅助目标不是保持强语言对齐所必需的。

密集对应。 密集对应直接监督跨裁剪、尺度和翻转的局部 patch 匹配（第 3.1 节）。在表 5 的十分之一预算下，移除 ℒ_dense 对全局和单视图指标的影响最小（聚合状态探针误差变化小于 1%，ℓ₁ 误差变化低于 .001，LPIPS 可忽略不计，检索最多变化 1.1 个点），因为这些基准不直接测试跨视图 patch 对应。然而，当直接在跨视图 patch 匹配上评估时（第 S4 节），移除 ℒ_dense 在 Stage 1 后将匹配准确性降低 6.0 个点（从 37.4% 到 31.4%），完整配方即使在 Stage 2 精炼后仍保持 2.6 个点的优势（40.8% vs 38.2%）。

6 结论

ALPS 表明，在静态图像和文本上预训练的单一冻结视觉表示可以结合竞争性的状态信息、原生语言对齐和像素重建。跨视图精炼增强状态表示同时保持语言和像素接口。相同的 token 支持机器人控制、世界模型预测和规划，以及预测场景的视觉检查。这些结果表明视觉状态预训练作为机器人策略和世界模型的共享基础。

局限性和未来工作。 我们专注于 ViT-B/16 骨干和仿真基准以在十五个编码器之间进行受控比较，将更大的模型规模和真实机器人部署留给未来工作。在训练方面，我们的配方依赖两阶段课程来平衡重建、语言和空间状态（第 5.4 节）；将跨视图精炼折叠到单个训练阶段仍然是一个开放问题。此外，ALPS 在没有视频监督的情况下预训练，尽管改善了 DAVIS 上的跨帧对应（第 S2 节），但对细粒度时间动作不太敏感，这激发了将 Stage 2 扩展到视频和交互数据。最后，我们的下游评估在单独的设置中测试语言条件控制和世界模型规划；将状态、语言和像素解码集成到单一的语言引导、像素可验证的规划器中是自然的下一步。

S1 训练细节

Stage 1。 表 S1 列出了 Stage 1 的架构和优化超参数。文本编码器和字幕解码器都有 12 层和 768 宽度；一个类 token 参与注意力但不用于任何损失。训练在 128×128 分辨率下运行 128 亿样本（批次大小 32,768，峰值学习率 1.0×10⁻³，w_rec=2），然后在 224×224 分辨率下运行 10 亿样本（批次大小 16,384，峰值学习率 2.6×10⁻⁵，w_rec=1）。对比温度是学习的（初始化为 0.07），logit 尺度限制在 1 和 100 之间。

重建。 使用 z̃ = z + 0.05·rms(z)·ε 和 ε ~ 𝒩(0, I)，其中每 token 均方根 rms(z) 在不反向传播梯度的情况下计算，重建损失为 ℒ_rec = ρ(D(z), x) + 0.25·ρ(D(z̃), x)，其中 ρ 结合 ℓ₁、结构相似性和图像梯度项，权重分别为 1、0.2 和 0.1。

密集对应。 投影头将两个视图的 token 映射到 256 维，ℒ_dense 是温度为 0.1 的 InfoNCE 损失。它作为两个单独 softmax 项的加权和计算，一个在同一图像中其他位置的负样本上（权重 0.75），一个在其他图像的负样本上（权重 0.25），这在不同分辨率下保持它们的平衡固定。
