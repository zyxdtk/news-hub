摘要

下一词元预测被用于同时学习预测行为和内部表示。我们提出一个问题：表示结构本身是否应成为一种显式归纳偏置。受柯尔莫哥洛夫复杂度的两部分编码视角启发，我们研究了一种结构-残差原则，其中表示将结构与实现细节分离。我们以两种互补的方式实例化这一原则。边界瓶颈概念（BBC）通过边界载体路由来自词元段的信息，同时保留局部自回归计算。连续概念（CC）对表示几何进行正则化，并诱导出低频结构和高频残差的谱分解。我们为两种视角推导了编码界限，并证明当段内路径能量趋于零时，经多重性校正的边界注意力变得精确。在实验上，BBC和CC表现出截然不同的深度偏好：BBC在早期层效果最佳，而CC在后期层最有效。在3亿训练词元规模下，结合BBC和CC在GPT-2 Medium上改善了1.44%的NLL。这些增益在长达200亿词元的训练中持续存在。表示诊断表明，BBC增加了边界状态的相对预测重要性，而CC降低了谱残差能量。总之，这些结果表明结构-残差偏置可以超越下一词元预测来改善语言模型预训练。代码：

1 引言

改进语言模型的主流方案非常简单：扩展模型、数据和计算规模，并优化下一词元预测（NTP）（Kaplan et al., 2020; Hoffmann et al., 2022）。在这一范式下，训练过程——主要是基于梯度的优化——不仅被信任能学习预测任务，还被信任能发现完成该任务所需的信息应如何在内部表示。

我们提出一个不同的问题：表示结构本身是否应成为一种归纳偏置？

一个有原则的出发点是柯尔莫哥洛夫复杂度的两部分编码视角。一个对象可以通过首先指定一个结构 Z，然后指定恢复特定实现 X 所需的残差信息来描述：

𝖪(X) ≤ 𝖪(Z) + 𝖪(X|Z) + O(1)

这为语言模型提供了一个通用的归纳原则：鼓励内部表示发现结构与残差之间的有利平衡。

这种结构在语言模型中应该是什么样的？我们从语言建模涉及的两个基本功能中汲取灵感。

首先，感知通常涉及抽象。诸如"法国的首都"和"France's capital"这样的短语在词元层面不同，但共享大量预测结构。这建议将必须跨区间携带的信息压缩为紧凑表示。然而，仅有结构的表示是不够的：精确的表面实现对于自回归预测仍然重要。

受这种结构-残差平衡的启发，我们引入了边界瓶颈概念（BBC），它将来自已完成段的信息通过边界载体路由到后续段，同时在当前段内保留普通的词元级自回归（图1(a)）。相关方法包括MEGABYTE的全局补丁建模与局部自回归字节解码的组合（Yu et al., 2023a），以及通过注意力瓶颈压缩提示信息的gist tokens（Mu et al., 2023）。BBC则使用现有的段末状态作为载体。

其次，生成需要精细的位置信息：每个词元位置都可能对下一词元分布相关。这似乎没有给结构压缩留下多少空间。然而，位置细节并不意味着任意的表示复杂性。隐藏状态序列可以在保留每个词元位置的同时，仍然具有简单的底层轨迹。受此观察启发，我们研究了连续概念（CC），它鼓励相邻隐藏状态平滑变化（图1(b)）。我们分析了谱结构-残差分解：低频模式形成结构化组件，而CC能量在共享编码约定下限制了高频残差及其有限精度索引长度。

在GPT-2 Small上，BBC在3亿训练词元时将评估NLL改善约0.99%，而BBC+CC改善1.30%。在更深的GPT-2 Medium模型上，增益分别为1.11%和1.44%。BBC不能仅用稀疏性来解释：相同密度的滑动窗口和随机稀疏注意力对照无法复现其增益，而随机化BBC载体的位置会显著降低性能。类似地，CC也不能仅用其两个组件中的任何一个来解释。它们的改进在更长的训练中也持续存在，在200亿词元运行中BBC达到1.12%，BBC+CC达到1.26%。

我们的实证研究还揭示了这两种偏置偏好不同的深度。BBC在网络底部附近效果最佳，而CC在后期层最有效。有趣的是，这种深度不对称性与更广泛的直觉一致，即Transformer的不同深度执行不同的计算角色：早期表示可以从紧凑的跨段结构中受益，而后期表示在保留精细词元级访问的同时受益于更简单的特征几何。

我们的结果表明，扩展NTP不是改进语言模型训练的唯一杠杆。对信息如何表示的显式偏置可以改善相同的预测目标。

我们的贡献如下：

  • 我们使用两部分编码原则来分析语言模型表示中的结构-残差归纳偏置。
  • 我们引入了BBC，通过边界载体压缩跨段通信，并将CC表征为具有显式重构和残差描述界限的谱结构-残差偏置；它们的参数 K 和 β 设定了平衡。
  • 我们发现BBC和CC偏好不同的深度，优于匹配的架构和正则化对照，并且增益在不同模型规模和长训练周期中持续存在；K 和 β 的扫描呈U形，与此角色一致。

2 结构-残差编码原则

两部分编码通过结构和识别其特定实现所需的细节来描述一个对象（Vereshchagin and Vitanyi, 2004）。我们用 𝖪 表示前缀柯尔莫哥洛夫复杂度。对于有限描述的对象，

𝖪(X|C) ≤ 𝖪(Z|C) + 𝖪(X|Z,C) + O(1)

这里 Z 描述结构，条件项描述剩余的实现细节。

我们使用这一原则来激发具体的编码界限。设 Γ 表示编码器和解码器共享的编码约定。假设在解码 Z 后，具有 M_δ(Z) 个条目的残差码本允许将 X 重构到精度 δ。则两部分编码满足

ℓ_δ^SR(X|C,Γ) ≤ ℓ_str(Z|C,Γ) + ⌈log₂ M_δ(Z)⌉

结构码是自定界的，解码的结构和编码约定决定了残差索引长度。任何未提前共享的码本或参数也必须被描述。

对于离散对象，残差码本可以枚举共享结构的实现。对于连续表示，覆盖码本以选定的精度给出重构。下面的界限涉及这些显式编码；BBC和CC都不直接优化柯尔莫哥洛夫复杂度。

BBC和CC实现了这一观点的不同部分。BBC限制直接跨段通信同时保留局部自回归细节；第3节表明其段长 K 设定了这一限制，且 K 的两个极端值都给出原始模型。CC控制隐藏状态轨迹低频表示之外的残差；第4节用CC能量限制这一残差，并将权重 β 与能量预算关联。第5节连接两种机制，第6节在经验上定位最佳 K 和 β。

3 边界瓶颈概念

边界瓶颈概念（BBC）通过粒度超参数 K 实例化结构-残差原则。序列被分为 K 个词元的段。在选定的Transformer层，每个已完成的段仅通过其边界状态与后续段通信，同时在当前段内保留普通自回归计算。

边界限制注意力。 为记号简便，假设 K 整除 N 并按 i = 0,…,N/K−1 索引段。注意力掩码中的空范围被解释为空集。

对于固定段长 K，定义 S_i = (x_{iK+1},…,x_{(i+1)K})。每个段的最后位置作为其边界载体。

对于段 s = ⌊(t−1)/K⌋ 中的查询词元 x_t，BBC在选定层用以下方式替换普通因果注意力模式：

𝒜_BBC(t) = {K, 2K, …, sK} ∪ {sK+1, …, t} (1)

一旦段完成，其 K 个词元状态在BBC层不再对后续段独立可访问。

当前段保持自回归。设 C_s 表示段 S_s 之前的因果上下文，定义 x_{s,r} = x_{sK+r+1}。段分布分解为

p_θ(S_s|C_s) = ∏{r=0}^{K−1} p_θ(x{s,r}|C_s, x_{s,<r})

所有其他层保留标准因果掩码。由于其他层和残差流可以保留额外的前缀信息，这种层局部限制并不意味着完整模型仅以边界载体为条件。

结构与实现残差。 设 a = φ(S) 为分配给 K 词元段的离散结构。其实现类为 𝒮_K(a) = {S′ ∈ 𝒱^K : φ(S′) = a}，其中 𝒱 是词汇表。

段分布诱导结构分布：
p_θ(a|C_s) = ∑_{S′∈𝒮_K(a)} p_θ(S′|C_s)

对于观测段 S 且 φ(S) = a 和正概率，

−log p_θ(S|C_s) = −log p_θ(a|C_s) − log p_θ(S|a,C_s) (2)

因此精确的段预测同时指定结构和实现。特别地，

−log p_θ(a|C_s) ≤ −log p_θ(S|C_s)

实现类也给出了编码界限。假设 φ 是可计算的，且有限词汇表、段长和结构映射作为 Γ_BBC 提供给解码器。该类可以被枚举，实现由其索引标识：

𝖪(S|C_s,Γ_BBC) ≤ 𝖪(a|C_s,Γ_BBC) + ⌈log₂|𝒮_K(a)|⌉ + O(1)

由于 𝒮_K(a) ⊆ 𝒱^K，实现类大小的对数满足

log₂|𝒮_K(a)| ≤ K log₂|𝒱| (3)

命题1（段长设定瓶颈）。固定 N 和BBC层。对于位置 t ≤ N 的查询，写 t = sK+r+1，其中 s = ⌊(t−1)/K⌋ 且 0 ≤ r ≤ K−1。

(i) 路由。 查询关注已完成段的 s 个边界载体及其当前段的 r+1 个位置 sK+1,…,t。相对于因果掩码，它恰好失去对 s(K−1) 个位置的直接访问，即已完成段的非边界词元。

(ii) 端点。 𝒜_BBC(t) = {1,…,t} 对所有 t ≤ N 成立当且仅当 K=1 或 K≥N。两种情况下BBC层都是标准因果注意力层。

(iii) 结构与实现。 段分布允许方程2中的分解。在所述编码约定下，非空实现类最多需要 ⌈log₂|𝒮_K(a)|⌉ ≤ ⌈K log₂|𝒱|⌉ 索引位。

部分和对所有 K ≥ 1 成立；证明在附录C.5中。

由，K 在BBC层设定分割：每个已完成的段仅通过其边界状态在那里可见，而当前段最多 K 个位置保持直接可见。距离 δ ≥ 1 个词元之前的关键对查询偏移的分数 (min(δ,K)−1)/K 被移除，因此从距离 K 开始，K 个关键中恰好保留一个：K 设定了距离尺度，不仅是稀疏度水平（引理2，附录C.6）。由，K=1 和 K≥N 给出原始模型。

概率恒等式对任何段分布成立；BBC贡献了架构路由限制。其结构-残差解释因此是紧凑的跨段载体加上保留的局部自回归计算。边界不必等于 φ(S) 或在构造上具有预测充分性。

4 连续概念

连续概念（CC）是隐藏状态轨迹几何上的优化偏置。

设 N ≥ 2，H ∈ ℝ^{N×d} 的第 i 行等于 h_i^⊤。状态取自选定层。CC惩罚相邻变化：

ℒ_CC = (1/(N−1)) ∑{i=1}^{N−1} ‖h{i+1}−h_i‖₂²

目标为 ℒ = ℒ_NTP + βℒ_CC，其中 β ≥ 0 控制正则化强度。

在我们的实现中，ℒ_CC 也在 d 个隐藏坐标上取平均，因此每个报告的 β 等于此处定义系数的 d 倍；第6节中的 ℒ_scale 和 ℒ_CC-2 同样如此。

我们将轨迹分析为低频结构加高频残差。CC目标控制残差大小的上界。

谱结构与残差。 设 L 为单位权重路径拉普拉斯算子。非归一化CC能量为

E(H) = ∑{i=1}^{N−1} ‖h{i+1}−h_i‖₂² = Tr(H^⊤LH) = (N−1)ℒ_CC

写 L = QΛQ^⊤, 0 = λ₁ < λ₂ ≤ ⋯ ≤ λ_N，具有正交归一特征向量。这些在词元位置上形成图频率基（Shuman et al., 2013）。这是Laplacian Eigenmaps（Belkin and Niyogi, 2003）下图平滑度目标的向量值路径实例。

对于 1 ≤ m < N，定义 Q_m = [q₁,…,q_m], H_m = Q_mQ_m^⊤H。H_m 是低频结构，R_m = H−H_m 是谱残差。

命题2（谱残差界限）。对于 1 ≤ m < N，

‖R_m‖F² ≤ E(H)/λ{m+1}

证明。 设 Ĥ = Q^⊤H。正交性给出

‖R_m‖F² = ∑{r>m} ‖Ĥ_r‖₂², E(H) = ∑_r λ_r‖Ĥ_r‖₂²

因此

‖R_m‖F² ≤ (1/λ{m+1}) ∑{r>m} λ_r‖Ĥ_r‖₂² ≤ E(H)/λ{m+1} ∎

对于选定的截断，当 E(H)/λ_{m+1} 小时，近似是准确的。

残差码本大小。 固定维度、截断和能量预算 E⋆ ≥ 0。对于 E(H) ≤ E⋆ 的轨迹，残差位于维度 D = (N−m)d 的子空间和半径 r⋆ = √(E⋆/λ_{m+1}) 的球中。

半径 r⋆ 的 D 维欧几里得球可以用最多 (1+2r⋆/η)^D 个半径 η > 0 的球覆盖（Vershynin, 2018）。

命题3（谱残差索引长度）。对于满足方程4的共享覆盖码本，标识Frobenius误差最多为 η 的残差近似的索引位长度满足

L_η(R_m|Γ) ≤ ⌈(N−m)d log₂(1 + (2/η)√(E⋆/λ_{m+1}))⌉

证明。 选择距残差 η 以内的覆盖中心并传输其索引；方程4随后给出界限。∎

编码约定 Γ 包括维度、基、截断、能量预算、精度和码本；任何未共享的组件都会产生额外的描述成本。将重构误差 δ/2 分配给结构和残差给出 ‖H−(H̃_m+R̃_m)‖_F ≤ δ，因此

ℓ_δ^SR(H|Γ) ≤ ℓ_{δ/2}^str(H_m|Γ) + ⌈(N−m)d log₂(1+4r⋆/δ)⌉

因此，在固定维度、截断和精度下，较小的能量预算减少残差描述界限，而结构保留其自身的描述成本。

更大的 β 从不增加最优模型的CC能量（附录C.7）。其在层 l 的强度为 κ_l = βρ_l，其中 ρ_l 是CC与NTP梯度的比率（附录C.8）。

5 从谱平滑到边界表示

结构-残差编码视角激发了两种干预。我们现在给出定性联系：低段内路径能量限制了经多重性校正边界注意力的误差（附录B.3在训练层上测试）。反向需要额外条件；见附录B。

设 I_j 包含已完成的 K 词元段的位置，边界 b_j = max I_j，定义

E_j = ∑{t∈I_j, t<b_j} ‖h{t+1}−h_t‖₂²

引理1（低路径能量下的边界近似）。

max_{i∈I_j} ‖h_i−h_{b_j}‖₂ ≤ √((K−1)E_j)

证明。 对于 r = b_j−i, h_{b_j}−h_i = ∑{t=i}^{b_j−1}(h{t+1}−h_t)。因此

‖h_{b_j}−h_i‖₂² ≤ r∑{t=i}^{b_j−1}‖h{t+1}−h_t‖₂² ≤ (K−1)E_j

相等、对齐的增量达到界限。∎

考虑一个注意力头（Vaswani et al., 2017），具有固定查询 q、共享线性键和值映射，无注意力dropout：

s_i = q^⊤W_K h_i/√d_k, v_i = W_V h_i

将所有允许的关键位置分组为 G_j。已完成的段形成大小为 K 的组；保留的局部前缀位置保持单例组。写 κ_j = |G_j|，设 b_j 为边界或单例代表。

定义 g_j = log ∑{i∈G_j} e^{s_i}, u_j = ∑{i∈G_j} (e^{s_i}/∑_{r∈G_j} e^{s_r}) v_i

重新分组分子和分母给出

o = Attn_dense(q) = ∑_j a_j u_j, a = softmax(g)

代表近似为

g̃j = s{b_j} + log κ_j, ũ_j = v_{b_j}

其中 õ = ∑_j ã_j ũ_j 且 ã = softmax(g̃)。

如比例注意力中（Bolya et al., 2023），log κ_j 保留相同条目的质量。单例组不变。

设 c_K = ‖q‖₂‖W_K‖_op/√d_k, c_V = ‖W_V‖_op，我们有

|g_j−g̃_j| ≤ c_K√((K−1)E_j), ‖u_j−ũ_j‖₂ ≤ c_V√((K−1)E_j)

对每个已完成的段成立。实际上，每个词元得分与其边界得分最多相差 c_K√((K−1)E_j)；限制其指数和给出第一个不等式。第二个成立因为 u_j 是单独接近 v_{b_j} 的值的凸组合。

命题4（多重性校正边界注意力）。设 Δ_s = max_j|g_j−g̃_j|, Δ_v = max_j‖u_j−ũ_j‖₂。如果 ‖ũ_j‖₂ ≤ V_max 对每个组（包括局部前缀单例）成立，则

‖o−õ‖₂ ≤ Δ_v + 2V_max tanh(Δ_s)

证明。 得分界限意味着 e^{−2Δ_s} ≤ a_j/ã_j ≤ e^{2Δ_s}。因此 |a_j−ã_j| ≤ tanh(Δ_s)(a_j+ã_j)，所以 ‖a−ã‖₁ ≤ 2tanh(Δ_s)。因此

‖o−õ‖₂ ≤ ∑_j a_j‖u_j−ũ_j‖₂ + ∑_j|a_j−ã_j|‖ũ_j‖₂ ≤ Δ_v + 2V_max tanh(Δ_s) ∎

对于固定 K 和一致有界的敏感度和值常数，误差随最大段能量消失而消失。这是同一层上多重性校正注意力的结果，不直接适用于未校正的BBC掩码。该界限假设 h_i 进入所述的键和值映射；中间归一化必须包含在敏感度常数中，位置相关映射或logit偏置需要额外项。附录C.9给出了旋转位置嵌入的这些项，适用于此结果和命题6；我们的GPT-2模型使用学习的绝对位置嵌入，不需要这样的项。

设置。 我们预训练 gpt2-small 和 gpt2-medium 模型（Radford et al., 2019），上下文长度 N=1024，在FineWeb-Edu（Penedo et al., 2024）随机采样的10亿词元子集上。我们在从同一数据集采样的100万词元保留集上评估并报告保留NLL。主要运行使用10亿词元上的余弦学习率调度和500万词元线性预热。为减少计算，超参数扫描和消融在1亿或3亿训练词元后评估，同时保留相同的10亿词元学习率衰减调度。除非另有说明，我们使用三个种子{82,23,37}，报告均值和标准差。对于200亿词元运行，我们将保留集扩大到1000万词元并使用单一种子（82）以减少计算成本。

BBC和CC是深度相关的。 我们的第一个发现是两种方法都有明显的深度依赖。我们在 gpt2-small 和 gpt2-medium 的偶数Transformer层上扫描干预层，BBC使用 K ∈ {4,8,16}，CC使用 β ∈ {0.00125,0.0025,0.005}（图2及附录A.1中表2、3）。两种模型规模出现相同的定性模式：BBC在应用于较低层时最有效，而CC在较高层变得更有效。这种深度不对称性没有被内置到任何一种方法中。有趣的是，这与激发性直觉一致，即BBC是感知启发的而CC是生成启发的，表明不同的Transformer深度可能偏好不同的表示功能。

CC需要尺度和粗糙度两者。 CC目标有减少隐藏状态尺度的自然倾向（见附录C.1的正式讨论）。为测试其增益是否主要来自这种尺度效应，我们与尺度正则化器比较，

ℒ_scale = (1/N)∑_{i=1}^N ‖h_i‖₂²

和归一化粗糙度正则化器，

ℒ_norm = (1/(N−1))∑{i=1}^{N−1} ‖h{i+1}−h_i‖₂²/(‖h_{i+1}‖₂²+‖h_i‖₂²+ε)

归一化粗糙度项在CC目标中与尺度互补。CC基于路径图拉普拉斯算子，其Dirichlet能量是此处考虑的有限范围成对族中最弱的惩罚（见附录C.2）。我们还包括CC-2

ℒ_CC-2 = (1/(N−2))∑{i=1}^{N−2} ‖2h{i+2}−h_{i+1}−h_i‖₂²

一个双前驱拉普拉斯残差惩罚，在消融研究中。CC也与余弦距离密切相关（见附录C.4），也被包括在内。

我们为每个变体分别调整应用层和 β（附录A.5中表9、10、11和12）。如图5所示，CC显著优于所有这些变体。附录A.5中表13报告了相应的配对t检验p值。

200亿训练运行。 我们接下来将训练扩展到200亿词元。我们发现改变学习率衰减范围也会改变最优CC权重 β。遵循10亿词元实验中使用的相同低成本调整策略，我们使用10亿词元运行选择 β，发现其增益持续到200亿词元（图1(c)）。

然而在200亿运行期间，BBC+CC在中间检查点暂时落后于BBC。我们假设这部分是数值稳定性问题：因为 β≪1，CC项的有效贡献随着训练期间 ℒ_CC 的减少在数值上变得可以忽略。

因此我们研究两种变体：随机dropout，在部分优化步骤中随机省略CC项；自适应dropout，当其值低于前 h 步历史的第 p 百分位数时省略CC项。后者旨在避免重复应用在乘以 β 后可能消失的非常小的CC更新。

使用自适应dropout，BBC+CC在每个中间检查点都持续优于BBC（见表15和附录A.6中图7）。

7 相关工作

LLM的表示学习。 表示学习在视觉自监督学习中一直处于核心地位，其中联合嵌入预测架构（JEPA）（Assran et al., 2023）通过嵌入空间预测学习语义表示。最近的工作将相关思想引入语言：LLM-JEPA（Huang et al., 2026a）将JEPA风格目标纳入语言模型训练，而语义管预测（STP）（Huang et al., 2026b）在隐藏状态轨迹上引入几何先验。大概念模型（LCM Team et al., 2024）在句子级嵌入空间中执行自回归预测。我们的工作共享一般动机并引入有原则的结构-残差归纳偏置。

结构化通信。 固定稀疏注意力（Child et al., 2019）结合局部注意力与对先前块边界附近位置的访问。BBC可被视为单载体（c=1）特化——Child et al. (2019)发现过于限制的设置——但我们表明在适当深度应用它可改善预测性能。Block Transformer（Ho et al., 2024）将全局块处理置于局部词元解码之下。Activation Beacon（Zhang et al., 2025）将上下文压缩到插入的beacon tokens的键-值状态中。H-Net（Hwang et al., 2026）学习边界，以降低的分辨率处理选定状态，并为解码上采样。局部、随机和全局连接是Big Bird（Zaheer et al., 2020）和Landmark Attention（Mohtashami and Jaggi, 2023）等稀疏注意力设计的标准成分。

平滑度和谱结构。 AWD-LSTM（Merity et al., 2018）通过时间激活正则化惩罚连续循环状态变化。Li et al. (2026)鼓励跨批次隐藏状态的角分散。Shuman et al. (2013)通过拉普拉斯频率表达图平滑度。CC正则化相邻Transformer隐藏状态并限制低频重构误差和有限精度残差码长度，消融将尺度与位置粗糙度分离。

两部分编码。 CRATE（Yu et al., 2023b）交替词元压缩和特征稀疏化；ToST（Wu et al., 2025）通过展开变分编码率减少推导注意力。Delétang et al. (2024)将预测概率转化为无损数据编码。最小描述长度（Rissanen, 1978）对模型和其下编码的数据收费，而算法统计（Gács et al., 2001）通过两部分编码形式化结构和实现。我们对BBC的段实现和CC的谱表示采用这种两部分核算，保留结构和残差成本而不直接优化柯尔莫哥洛夫复杂度。

深度专门化。 Skean et al. (2025)评估嵌入质量的逐层几何和信息内容。Lad et al. (2025)通过删除和交换层探测计算敏感度。我们的训练时层扫描在两种GPT-2模型规模中识别早期BBC和晚期CC为有利位置；这些偏好是经验观察的，不是方法规定的。

8 结论

受柯尔莫哥洛夫复杂度的两部分编码视角启发，我们引入了BBC和CC作为语言模型预训练的互补结构-残差归纳偏置，并推导了表征两种机制的显式界限。BBC通过边界载体压缩跨段通信，而CC鼓励隐藏状态轨迹中的紧凑谱结构。我们进一步给出两者之间的定性联系，发现BBC偏好早期层而CC偏好后期层。它们的增益在不同模型规模和长达200亿词元的训练周期中持续存在，证明显式表示偏置可以改善下一词元预训练。

A.6 200亿训练运行

当扩展训练到200亿词元时，我们首先使用10亿词元扫描重新调整CC权重 β。在更长的调度下，较慢的学习率衰减允许CC对 ℒ_CC 施加更大的累积向下压力，这可以改变最优 β。使用单一种子（82），我们发现 β=0.000625 在10亿词元处表现最佳。

在此设置下，BBC+CC最终在100亿词元后优于BBC，但在40亿到90亿词元之间的中间检查点表现不佳。进一步减少 β 不能改善10亿词元结果。

我们假设这种行为部分是由于数值稳定性：随着 ℒ_CC 减少，将其乘以 β≪1 可能使相应的优化信号在数值上可以忽略。因此我们研究两种变体。

随机dropout 以dropout率 d>0 独立跳过CC项。自适应dropout 则在 ℒ_CC 低于前 h 个优化步值的第 p 百分位数时跳过CC项，减少非常小CC更新的频率。

A.7 边界干预诊断

为测试BBC是否增加边界表示的相对重要性，我们使用两种匹配的激活干预评估冻结的1亿词元原始和BBC检查点。对于每个已完成的段，我们要么用零向量替换边界表示并测量由此产生的NLL增加，记为 Δ_b，要么替换同一段中随机选择的非边界表示并测量相应的增加，记为 Δ_i。我们使用

G = Δ_b − Δ_i (5)

作为边界偏好统计量。正的 G 表明消融边界比消融匹配的内部位置更具破坏性。更重要的是，

G_BBC > G_Vanilla (6)

表明BBC增加了边界表示的相对预测重要性。

控制早期位置效应。 对整个序列的直接干预受到前几个词元异常大影响的混淆。图8显示了当消融的内部位置相对于段边界移动时的边界偏好统计量。当 K=8 时，位置−7对应于段的第一个词元。在不排除初始段的情况下，消融此位置产生不成比例的NLL变化，主导了边界与内部的比较。

因此我们从干预统计量和相应的NLL评估中排除前 W=4 个段。在此预热排除后，对特定非边界位置的依赖变得可以忽略（图8），允许诊断隔离边界放置的相对效应而非最早词元的特殊角色。

附录B BBC和CC之间的额外联系

我们现在考虑反向。BBC限制跨段通信可用的值子空间。平滑度需要关于相邻查询之间注意力如何变化的额外条件。

B.1 跨段特征子空间

考虑一个确定性注意力头。设 B 为查询可用的边界位置并集，对不可访问位置分配零权重。设

A_B ∈ ℝ^{N_q×|B|}, V_B ∈ ℝ^{|B|×d_v}

跨段贡献为

O_cross = A_B V_B (9)

A_B 的行不必求和为一，因为局部前缀词元也接收注意力。

命题5（跨段子空间约束）。

rank(O_cross) ≤ min(N_q, |B|, d_v) (10)

且每个输出行属于 span{v_b : b ∈ B}。

证明。 A_B V_B 的每一行是边界值的线性组合，乘积的秩不能超过任一因子的秩。∎

这约束了一个头的跨段贡献，而非完整隐藏状态。载体计数界限在 |B| ≥ d_v 时不必收紧值维度界限。低秩也不意味着平滑度：交替行 u,−u,u,−u,… 秩为一且相邻能量为 4(N_q−1)‖u‖₂²。

B.2 条件平滑度

对于相邻差分算子 D，

‖DO_cross‖_F² ≤ ‖V_B‖_op² ‖DA_B‖_F² (11)

因此相似的边界注意力权重产生相似的跨段输出。

对于此比较，将 B 限制为一个段之前的固定非空边界集。设 K_B ∈ ℝ^{|B|×d_k} 包含其键作为行，并将 V_B 限制到相同位置。假设边界logits为 q_i^⊤k_b/√d_k。定义边界归一化分布和总边界注意力质量：

ā_i = softmax(K_B q_i/√d_k), γ_i = ∑{b∈B}(A_B){ib} (12)

则

z_i = V_B^⊤ā_i, o_i^cross = γ_i z_i (13)

这里 0 ≤ γ_i ≤ 1；剩余的注意力质量属于局部前缀。

写 E_intra 为限制在此段的相邻能量，设 Q^qry 为查询矩阵。设

V_max = max_{b∈B}‖v_b‖₂, C_B = ‖V_B‖_op‖K_B‖_op/(2√d_k)

命题6（条件BBC到CC平滑度）。对于固定边界键和值，

E_intra(O_cross) ≤ (V_max√(E_intra(γ)) + C_B√(E_intra(Q^qry)))² (14)

证明。 softmax雅可比矩阵为 J = diag(p) − pp^⊤。它是对称的且绝对行和为 2p_i(1−p_i) ≤ 1/2，因此其欧几里得算子范数最多为 1/2。因此

‖z_{i+1}−z_i‖₂ ≤ C_B‖q_{i+1}−q_i‖₂

使用 o_i^cross = γ_i z_i, ‖z_i‖₂ ≤ V_max 和 0 ≤ γ_i ≤ 1 给出

‖o_{i+1}^cross−o_i^cross‖₂ ≤ V_max|γ_{i+1}−γ_i| + C_B‖q_{i+1}−q_i‖₂

连续差分上的三角不等式给出结果。∎

两项都重要。当有一个边界值 u、零局部值和相同的零logits时，当局部前缀从一个词元增长到两个时，跨段输出从 u/2 变为 u/3，即使查询相同。因此当查询和总边界注意力质量都平滑变化时，BBC传递平滑度。段之间的转换（边界集改变处）需要单独的项。

B.3 训练BBC层处的命题4

我们在训练了10亿词元的两个模型的BBC层（第2层）测试命题4：K=16 且具有学习位置嵌入的 gpt2-medium，以及 K=16 且具有旋转嵌入的 Pythia-410M。我们使用前10万个保留词元的查询、键和值（98和50个序列，所有16个头，每序列256个随机查询）。由于键和值映射已经应用，我们在键和值路径本身上使用引理1：

|g_j−g̃_j| ≤ ‖q‖₂√((K−1)E_j^K)/√d_k 和 ‖u_j−ũ_j‖₂ ≤ √((K−1)E_j^V)

其中 E_j^K 和 E_j^V 是段 j 中键和值的路径能量。对于Pythia，我们使用旋转前的键并添加附录C.9的旋转项。因为 ‖W(h_i−h_b)‖₂ ≤ ‖W‖_op‖h_i−h_b‖₂，此版本不弱于用 c_K、c_V 和 h 的路径能量陈述的版本。链中的每个不等式在所有采样查询上成立。

表19显示低能量条件不成立。段内部值与相同词元的随机重排序一样粗糙，键在 gpt2-medium 中仅略微平滑。路径能量隐含的logit半径约为150 nats，因此 tanh 饱和且界限超过每个查询的 2V_max。使用测量的 Δ_s 和 Δ_v，界限更紧但对几乎所有查询仍然空洞，并且它不按误差对查询排序。原因是logit差距本身很大：测量的 Δ_s 中位数为10.8和12.6 nats，因此 tanh(Δ_s) ≈ 1 且界限对几乎每个查询都接近 Δ_v + 2V_max，无论实际误差如何。在16个Pythia头上，界限和中位误差的秩相关为−0.72。

误差由掩码移除的注意力质量控制。设 m 为BBC模式外键上的密集注意力质量，ū_M 为其值的注意力加权均值。限制在可见键上的密集注意力等于 (1−m)o_BBC，因此 o−o_BBC = m(ū_M−o_BBC) 精确成立，且 m 按误差对查询的排序远好于界限。在 gpt2-medium 中，具有相同 q 和 k 的密集注意力几乎将其所有质量放在BBC模式之外，分布在数百个位置上。使用旋转嵌入时logits保持局部且 m 很小。训练的BBC层因此可以依赖掩码实现局部性；它不必近似密集层。我们将命题4解读为定性连续性结果，而非训练模型的定量估计。Pythia结果在 K=16 时相同。
