摘要

扩散模型已成为求解逆问题的强大先验。然而，当多个与测量一致的解只能依靠先验加以区分时，相位恢复等非线性逆问题仍然具有挑战性；我们将此类测量称为歧义测量。现有的基于扩散的采样器在重建过程中依赖局部近似。对于歧义测量，这些近似可能使测量引导偏向某个测量一致的模式——该模式虽然接近某个先验支持的模式，但其本身并不受先验支持。评估通常通过报告k次运行中的最佳结果来掩盖此类失败，而最佳结果是经由与真实值比较选出的。我们提出先验一致DAPS（Prior-Consistent DAPS，PC-DAPS），它是解耦退火后验采样（DAPS）的一种变体，旨在通过在单次采样运行中维护多个候选解来解决这一失败情况。随着退火噪声降低，PC-DAPS依据先验一致性修剪并替换较弱的候选解，且无需访问任何真实值。PC-DAPS降低了先验不一致样本的出现频率，提升了非线性逆问题上的样本质量，同时在线性逆问题上保持了样本质量与多样性。

1 引言

图1：测量一致性不足以完成重建。 单个傅里叶幅度测量被图像的旋转、平移和颜色通道反转所共享。现有求解器可能返回这些先验不一致的模式，而PC-DAPS选择由学习到的图像先验所支持的重建。每个样本均为随机选取，或来自其他方法的四次独立运行，或来自单次PC-DAPS运行中生成的四个粒子。

每当需要从间接测量中恢复未知信号时，逆问题便会出现于科学与工程的各个领域，包括图像恢复（Bertero等，2021）、医学成像（Song等，2022）以及天文成像（Event Horizon Telescope Collaboration，2019）。给定通过已知但可能含噪的测量过程生成的观测y，逆问题的目标是恢复原始信号x。对于欠定问题，即许多不同信号x可能产生同一测量y，贝叶斯成像将后验分布定义为p(x|y) ∝ p(y|x)p(x)，其中似然p(y|x)刻画候选图像x的测量一致性，先验p(x)刻画哪些候选重建是合理的自然信号。因此，后验采样的目标是生成同时与测量和先验一致的候选重建。

例如，在傅里叶相位恢复中，多幅图像可以产生完全相同的傅里叶幅度测量（Fienup，1982）。这些测量等价的解因此具有相同的似然，但依据其与图像先验的一致性，其后验概率可能大相径庭。特别地，我们观察到，应用于人脸图像的现有相位恢复求解器有时会返回旋转或颜色反转的人脸，它与测量一致，却在集中于正立人脸的自然图像先验下不合理。因此，挑战不仅在于找到测量一致的重建，更在于采样受先验支持的测量一致解。

扩散模型为后验采样提供了强大的图像先验（Ho等，2020；Song等，2021）。在每个噪声水平，扩散模型隐式定义了一个去噪器，将含噪样本x_t映射到对应干净图像的估计；该扩散去噪器可用于在后验采样中融入先验p(x)。基于扩散的逆问题求解器沿采样轨迹（即从含噪样本演化至重建的中间状态序列）应用这一先验信息。现有方法主要要么使用近似似然梯度来倾斜无条件反向扩散过程（Zhang等，2025；Chung等，2023；Song等，2023；Boys等，2024），要么在各噪声水平之间交替执行先验更新与测量更新（Wu等，2024；Xu与Chi，2024；Chen等，2026；Ahmed与Makin，2026）。在这些方法中，每个噪声水平可用的先验信息通过以单个干净图像估计为中心的局部去噪近似来表示，而非在中间时间步显式维护多个相互竞争的先验模式。

当测量具有歧义时（如相位恢复及其他欠定逆问题的情形），遵循采样轨迹可能导致过早模式选择。在高噪声水平，多个先验模式可能仍然合理，但轨迹只能朝其中一个演化。一旦轨迹选定了特定先验模式，后续细化主要在该模式的局部邻域内改善测量一致性，而不再考虑更远的替代方案。当满足以下两点时问题尤为严重： 所选先验模式与测量不一致； 其最近的测量一致模式不受先验支持。基于轨迹的采样器可能过早地承诺于这一对模式，最终产生既不受真实后验、甚至不受真实先验支持的幻觉重建。Best-of-k评估通过生成多个独立重建并选取最接近真实值者，部分掩盖了这一问题（Chung等，2023；Zhang等，2025）。然而，这种选择使用了测试时不可获得的信息，且无法确保产生的样本是先验一致的。基于粒子的方法在中间时间步维护多个候选（Cardoso等，2024；Dou与Song，2024；Wu等，2023），但主要聚焦于线性逆问题与粒子多样性，而非先验一致的采样。

为解决这一问题，我们提出先验一致DAPS（PC-DAPS），它将样本选择移入采样器内部，从而无需基于真实值的best-of-k评估。PC-DAPS维护一袋在相同测量下退火的K个粒子，并用K分量高斯混合而非单峰估计来建模去噪器后验p(x_0|x_t)。在采样早期，当噪声水平较高且先验信息仍然较弱时，保留多个候选。随着退火过程中噪声降低，先验一致性低的粒子被修剪，并被先验一致性更高的幸存候选替换。因此，PC-DAPS将模式选择推迟至先验变得更具信息量之时，在单次采样运行中（且无需访问真实值）完成了best-of-k只能在k次独立采样运行之后才能完成的工作。

我们在FFHQ（Karras等，2019）和ImageNet（Deng等，2009）上评估PC-DAPS，涵盖三个非线性与七个线性任务，包括DAPS（Zhang等，2025）报告的八个任务，以及高通滤波（Thaker等，2025）和16倍超分辨率。我们在单样本与best-of-k两种评估协议下报告PSNR、SSIM（Wang等，2004）和LPIPS（Zhang等，2018）。此外，我们还对比了先验不一致幻觉的发生率与独立DAPS运行。PC-DAPS降低了先验不一致样本的出现频率，提升了歧义非线性问题上的性能，同时在线性逆问题上保持了图像质量与多样性。我们的贡献如下：

  • 我们提出PC-DAPS，它维护一袋粒子，用高斯混合建模去噪器后验，并在无法访问真实值的情况下执行基于先验的修剪。
  • 我们在FFHQ和ImageNet上跨七个线性与三个非线性逆问题评估PC-DAPS，结果表明先验不一致重建更少、非线性重建质量更高，同时保持了线性任务上的性能。

2 相关工作

似然引导的扩散采样。 给定已学习无条件分数∇{x_t} log p(x_t)的扩散先验，我们可将条件分数（观测到测量y后）分解为∇{x_t} log p(x_t|y) = ∇{x_t} log p(x_t) + ∇{x_t} log p(y|x_t)。似然项∇_{x_t} log p(y|x_t)是难解的，因此一系列方法对其加以近似以引导反向扩散过程。特别地，DPS（Chung等，2023）在单步后验均值处评估似然p(y|x_t) ≈ p(y|E[x_0|x_t])，并通过反向传播计算分数。对于线性测量算子，ΠGDM（Song等，2023）与TMPD（Boys等，2024）转而传播p(x_0|x_t)的高斯近似，而DDRM（Kawar等，2022）利用对角化方法。MCG（Chung等，2022）添加流形校正项以使引导迭代保持接近数据流形。Jin等（2026）针对这一族方法中的幻觉问题，通过稳定先验更新加以解决，但仍 committed 于单一轨迹。

分裂与退火后验采样。 相比之下，变量分裂方法在“仅先验”与“仅测量”步骤之间交替。在使用扩散模型执行先验步骤的方法中，PnP-DM（Wu等，2024）使用分裂Gibbs采样器处理似然，DPnP（Xu与Chi，2024）使用Metropolis-Hastings，而DiffPIR（Zhu等，2023）利用近端步骤。最后，DAPS（Zhang等，2025）利用重复的“去噪-再加噪”方案（第3.2节）。RePS（Ahmed与Makin，2026）在该调度中加入重启，DAPS++（Chen等，2026）报告称DAPS重建主要由测量一致性驱动。因此，我们将PC-DAPS设计为DAPS的修改版本，保留其变量分裂结构，但引入基于先验的选择机制来甄别测量一致的重建。

基于粒子的后验采样。 另一组方法在整个采样过程中维护大量粒子，并使用序贯蒙特卡洛来传播、重加权与重采样粒子，以逐步改善测量一致性（Cardoso等，2024；Janati等，2025）。FPS-SMC（Dou与Song，2024）将反向采样过程表述为状态空间模型并应用粒子滤波。TDS（Wu等，2023）使用扭曲函数为一般测量模型获得渐近精确性。虽然基于粒子的方法通常关注大量粒子极限下粒子集合的保真度，我们关注的则是单个返回重建先验不一致的概率，并将粒子用于探索后验景观。

幻觉与先验失配的诊断。 早在采用扩散先验之前，幻觉就已被作为逆问题重建算法的一种性质加以研究（Bhadra等，2021），指任何与测量或先验不一致的重建。近期工作试图专门针对基于扩散的求解器量化幻觉（Jin等，2026）。在模型层面而非单个样本层面，DiME（Wang与Bouman，2026）通过对后验采样器的时间边缘分布积分来估计扩散先验的证据，可与DAPS并行运行以检测先验失配。与我们的框架最接近的是，Burns与Fridovich-Keil（2026）采用有限样本视角研究反向扩散动力学，表明广泛使用的引导近似在中间噪声水平错误估计了后验展布。这种错误估计既产生真实后验中不存在的先验模式，也产生不受先验支持的似然（测量一致）模式，而这正是PC-DAPS旨在解决的具体失败。后验解析可解的基准为求解器报告的不确定性提供了互补检验（Crafts与Villa，2025；Zach等，2026；Zheng等，2025）。所有这些现有幻觉诊断均在采样后应用；PC-DAPS则在采样过程中利用先验支持来决定哪些重建得以存活，从而降低先验不一致幻觉的发生率。

3 预备知识

3.1 贝叶斯逆问题

我们考虑如下形式的贝叶斯逆问题：

y = A(x) + n，n ∼ N(0, β_y² I)，(1)

其中x ∈ R^d为感兴趣的未知信号，A: R^d → R^m为已知的确定性测量算子（可线性可非线性），n ∈ R^m为未知加性高斯噪声，y ∈ R^m为观测测量。给定先验分布p(x)，贝叶斯法则给出与给定测量y一致的似然信号x上的后验分布：

p(x|y) ∝ p(y|x) p(x)，p(y|x) = N(y; A(x), β_y² I)。(2)

我们特别关注这样的前向模型：测量一致信号集合

M(y) = {x ∈ R^d : ‖A(x) − y‖ ≤ δ} (3)

包含多个在信号空间中彼此分离良好的候选重建。在此背景下，M(y)中的两个不同信号可被赋予相等的似然p(y|x)，却具有截然不同的后验概率p(x|y)，因为其中一幅图像可能不真实（即先验概率p(x)显著更低）。现有重建方法的一个常见失败是以大致相等的频率采样这两个信号，从而将其后验概率错误地呈现为相对相等。

例如，在傅里叶相位恢复中，两幅仅在旋转、平移和/或颜色通道符号上不同的图像在视觉上截然不同，却产生相同的傅里叶幅度测量（Fienup，1982）。在结构化的人脸图像上，求解器可能返回180°旋转或颜色反转（例如蓝色）的人脸，它拟合观测的傅里叶测量，尽管与仅支持正立人脸集合的先验分布不一致。我们将此类重建称为先验不一致的。先验不一致重建常见于经典相位恢复方法（Fienup，1982）、深度学习方法（Metzler等，2018；Işil与Oktem，2025）以及基于扩散的逆问题求解器（Xu与Chi，2024；Zhang等，2025）。我们的目标是在保持测量且先验一致样本的质量与多样性的同时，降低先验不一致解的频率。

3.2 解耦退火后验采样（DAPS）

为开发产生较少先验不一致样本的采样器，我们在现有方法基础上构建： 识别产生不一致样本的根本原因； 进行调整以降低此类样本的发生率。具体而言，我们基于DAPS（Zhang等，2025）构建——这是一种基于扩散的变量分裂方法，它重复地 通过反向扩散过程去噪至干净图像； 通过MCMC（如Langevin动力学（Roberts与Tweedie，1996））改善干净图像的似然一致性； 通过前向扩散过程对MCMC输出重新加噪。通过加回比原有噪声更少的噪声，DAPS旨在迭代地去噪至测量一致的干净样本。

数学上，DAPS利用如下事实：给定中间图像x_t ∼ p(x_t|y)，抽取：

x_0 ∼ p(x_0|x_t, y)，x_{t−1} ∼ N(x_0, σ_{t−1}² I)，(4)

即可产生x_{t−1} ∼ p(x_{t−1}|y)。为从引导去噪分布p(x_0|x_t, y)采样，注意到y与x_t在给定x_0时条件独立；因此由贝叶斯法则可分解：

p(x_0|x_t, y) ∝ p(y|x_0) p(x_0|x_t)。(5)

虽然p(y|x_0)由公式1诱导，但去噪分布p(x_0|x_t)未知且难以通过采样估计。DAPS对该分布使用高斯近似：

p(x_0|x_t) ≈ N(x_0; x̂_0(x_t), r_t² I)，(6)

其中x̂_0(x_t)为E[x_0|x_t]的估计，r_t为启发式设定。注意到公式5近似右端关于x_0的分数有闭式解，从而可从初始化x̂_0(x_t)出发，以步长η_t通过未调整Langevin算法采样：

x̂0^{(j+1)} ← x̂_0^{(j)} + η_t(∇{x̂0} log p(x̂_0^{(j)}|x_t) + ∇{x̂_0} log p(y|x̂_0^{(j)})) + √(2η_t) ε^{(j)}，ε^{(j)} ∼ N(0, I)。(7)

当Langevin算法终止（在用户指定的N次迭代后），结果使用前向扩散过程的EDM参数化（Karras等，2022）重新加噪：x_{t−1} = x̂0^{(N)} + σ{t−1} ε，其中ε ∼ N(0, I)。DAPS中引入再加噪是为了抵消Langevin细化的局部性：由于连续的Langevin更新是局部的，样本可能无法探索远离x̂_0(x_t)的替代先验模式。再加噪-去噪更新旨在允许粒子每次迭代进行更大移动，并考察替代先验模式。

图2：过早模式选择。 我们考虑一个具有二次型A与双原子先验的非线性逆问题；细节见第A.2节。我们选择y使得一个原子与似然一致，而另一个原子与似然不一致但邻近一个似然一致的先验不一致模式。图中展示了精确后验、DAPS与PC-DAPS在跨噪声水平σ（采样方向→）上的分布（图例：多数后验模式x_1、少数后验模式x_2、DAPS幻觉模式x_3）。精确后验赋予两个原子正权重，且似然一致原子占多数权重。然而，DAPS将多数质量赋予先验不一致的似然模式（如最后一幅放大面板所突出显示），该模式在真实后验中并不存在。PC-DAPS的选择算法修剪了该模式，仅从后验一致的原子采样。虽然DAPS与PC-DAPS都未能以足够概率从似然不一致原子采样，但PC-DAPS消除了DAPS产生的幻觉先验不一致模式。

然而，如图1所示，DAPS更新规则仍会产生第3.1节所述的先验不一致样本。注意到，DAPS近似从p(x_0|x_t, y)采样的过程实际上在E[x_0|x_t]附近产生一个先验一致的样本，并从其邻域的似然一致区域采样。当x_t选择了先验一致但似然不一致的样本，而信号空间中又存在与y一致的邻近区域时，公式7可能会从该区域采样——即使它是先验不一致的——因为对p(x_0|x_t)的高斯近似仅是阻止样本在信号空间中偏离x̂_0(x_t)过远。我们观察到，x_0再加噪得到的x_t随后以高概率去噪至同一区域，导致粒子被困于先验不一致但测量一致的模式。我们将这一现象称为过早模式选择，因为样本x_t过早地承诺仅从特定先验模式采样x_0，而无法充分解除承诺，即使该先验模式在后验中并不存在。

图2说明了这一现象。此处，先验在两个候选解x_1与x_2上放置质量，而测量y由x_1与先验不支持的第三点x_3解释。类比傅里叶相位恢复，可将x_1视为期望的重建，例如既与测量一致又受图像先验支持的正立、非蓝色人脸；x_2视为与特定测量不一致的真实人脸；x_3视为期望图像x_1的结构上不合理的变换，如旋转或蓝色人脸。精确后验应当偏向x_1模式，同时赋予先验不一致的x_3零质量。然而，DAPS通过 从先验采样x_2， 从x_2的局部似然采样x_3，从而从x_3的邻域采样。一旦粒子进入这一局部吸引的似然一致区域，后续再加噪与Langevin更新便被困住，导致过早模式选择。

这一玩具示例激发了PC-DAPS的设计：维护多个候选的测量一致模式，以识别并纠正被困的先验不一致样本。如图2所示，PC-DAPS将其质量仅置于x_1处受先验支持且测量一致的模式上，避免从x_3附近先验不一致、测量一致的区域采样。我们将在下一节描述PC-DAPS如何识别并移除此类先验不一致粒子。

4 方法

为解决先验不一致样本的存在，第一种思路可能是通过DAPS产生多个样本并丢弃先验不一致者。这种做法有两个主要缺点： 该采样方法的有效样本量是次优的，因为大量计算资源被用于产生随后被丢弃的样本； 在无法访问真实信号或后验的情况下，如何选择丢弃哪些样本并不清楚。

为解决这些问题，我们提出PC-DAPS——一种在采样过程中纠正过早承诺粒子的流程，无需访问真实图像或任何预训练的先验不一致分类器。PC-DAPS维护一袋K个粒子，每个粒子使用相同的退火调度与预训练去噪器去噪，但在其Langevin与再加噪更新中使用不同的初始化与随机噪声。若不对DAPS做额外修改，这K个粒子将独立去噪，并可划分为（非空的）“坏”过早承诺粒子集合与后验一致的“好”粒子集合。PC-DAPS的核心思想是改进DAPS现有的再加噪策略：在采样过程中识别过早承诺的粒子，并将其转移至袋中其他粒子发现的更有前景的模式。此外，PC-DAPS利用粒子来细化DAPS的其他设计决策，例如用自适应高斯混合模型（GMM）近似替换去噪分布的单峰高斯近似。说明该高斯混合近似益处的玩具示例见第A.3节。

剩下需要描述的是PC-DAPS如何 识别粒子何时过早承诺； 识别哪些粒子有问题； 纠正被识别的粒子； 从袋中构造多峰去噪分布近似。

PC-DAPS利用并行退火的K个粒子对DAPS做出两项核心更改：一种修剪技术，用于纠正在线性歧义任务中被困于先验不一致似然模式的粒子（第4.1节）；以及一种从粒子多样性估计的多峰去噪分布近似（第4.2节）。其他实现细节与消融见第A.4节，例如省略最终Langevin细化以及从高噪声到低噪声的自适应ODE步进，以在降低计算成本的同时提高重建质量（第A.5节）。完整算法（算法1）见第A.1节。

4.1 修剪方案

PC-DAPS首先从反向扩散过程的初始分布初始化一袋K个粒子B = {x_{t_max}^{(k)}}_{k=1}^K，并按DAPS的规定对粒子去噪。在M(y)（公式3）包含多个明显分离候选的任务上（例如非线性A），粒子将开始去噪至真正不同的候选重建。在DAPS去噪过程中先验首次变得具有判别力的退火时刻，PC-DAPS调用一次性共识检查来识别先验不一致粒子。

为确定检查何时发生，我们在每次迭代测试袋的多样性。定义：

r̄ = (1/K) Σ_{k=1}^K ‖A(x^{(k)}) − y‖²，r* = ‖A(x̄) − y‖²，x̄ = (1/K) Σ_{k=1}^K x^{(k)}。(8)

注意到，对于线性A，平方范数的凸性使Jensen不等式强制r̄ ≥ r*。利用这一凸性直觉，对于非线性A，条件r̄ < r*表明袋占据了似然势的多个井，说明模式级修剪是有意义的。

为识别哪些粒子需要纠正，我们将袋划分为簇C_m，并通过其在若干噪声尺度S上的平均先验一致性（经Tweedie公式获得）评估每个簇：

s(C_m) = −(1/(|C_m||S|)) Σ_{x∈C_m} Σ_{σ∈S} ‖x − D_θ(x + σε; σ)‖²，ε ∼ N(0, I)。(9)

该准则的前提是：位于（先验）数据流形附近的样本在每个噪声尺度下去噪的分数都很小。若某簇的先验一致性分数s(C_m)超过阈值，则其粒子保持不变；否则，其粒子被得分高于阈值的簇中粒子的副本随机替换。包括聚类方法、噪声尺度S的选择与阈值确定在内的实现选择在第A.4节讨论。

4.2 去噪器后验的高斯混合近似

维护粒子袋的另一益处是，我们可以通过选择由袋的多样性所启发的多峰分布，来改进DAPS在公式6中的单峰近似。我们提出用高斯混合替换DAPS高斯近似。将第k个粒子的干净信号估计记为x̃_0^{(k)} = D_θ(x_t^{(k)}; σ_t)。

在第4.1节所述修剪激活之前，我们使用以干净估计为中心的均匀加权高斯混合：

q(x_0|x_t) = (1/K) Σ_{k=1}^K N(x_0; x̃_0^{(k)}, diag(Var_B(x̃_0^{(k)})))。(10)

修剪之后，我们为每个未修剪的簇维护一个模式，其相应分量参数由该簇的经验权重、均值与对角协方差给出：

q(x_0|x_t) = Σ_{m=1}^M π_m N(x_0; μ_m, Σ_m)，(11)

π_m = |C_m|/K，μ_m = (1/|C_m|) Σ_{x^{(k)}∈C_m} x̃0^{(k)}，Σ_m = diag(Var{C_m}(x̃_0^{(k)}))。(12)

当某簇仅含单个粒子时，其分量使用整个袋的对角协方差。

与DAPS将去噪近似中心化于点估计x̂_0(x_t)不同，PC-DAPS在同一模式的所有粒子间共享袋均值中心，给出方差缩减的先验估计，我们发现这在线性重建任务上提升了重建质量。此外，当整个袋位于单一簇时，混合退化为以袋的平均Tweedie估计为中心、具有数据依赖协方差的单个高斯。这与DAPS所用的启发式、几何无关的协方差形成对比。

注意到GMM去噪近似q(x_0|x_t)的分数具有闭式形式：

∇{x_0} log q(x_0|x_t) = Σ{m=1}^M q_m(x_0) Σ_m^{-1}(μ_m − x_0)，(13)

权重为q_m(x_0) = π_m N(x_0; μ_m, Σ_m) / Σ_{m'} π_{m'} N(x_0; μ_{m'}, Σ_{m'})，因此可用于公式7引入的DAPS Langevin更新。注意到当权重q_m近似为独热时，该更新近似退化为数据依赖的高斯。回顾DAPS高斯近似不鼓励Langevin动力学偏离点估计x̂_0(x_t)过远，PC-DAPS高斯近似则不鼓励Langevin动力学偏离由袋的集体簇所识别的先验模式过远，如第A.3节图4所示。

6 讨论

动机、局限性与未来工作。 扩散文献中针对歧义逆问题的结果通常以best-of-k形式报告，并使用真实值进行选择。这种评估方式之所以普遍，是因为现有求解器在不同运行间不一致，单样本结果会有较大的质量波动。我们将这种不稳定性视为测量歧义背景下过早模式选择的一种症状。我们提出PC-DAPS，利用学习到的先验信息在采样过程中减少这种不期望的方差，而无需真实值参考。即使在包括FFHQ在内的高维数据集上，由于先验的局部结构，我们的方法仍显示出显著改进。PC-DAPS在结构更多样的数据集（即ImageNet）上改进较小，因为先验景观更复杂，这暴露了一个尚待解决的剩余局限与开放问题。我们鼓励未来工作进一步探索我们提出的在推理时利用先验分数评估候选重建的范式，并致力于即使在结构较弱的先验下也能消除先验不一致重建。

后验采样指标。 PSNR、SSIM与LPIPS等标准指标衡量生成图像与单张参考图像的相似程度。注意到，若某方法找到多个在测量与先验下同等有效的合理解，这些评估指标会惩罚那些与固定参考不相似的解。由于样本多样性与似然一致性是后验采样的明确目标（包括不确定性量化等应用），这些样本质量指标不能充分替代所采样后验的质量。在本工作中，我们报告了重建质量的一个独立维度：先验一致性。我们相信，这一或类似的多维指标应与标准保真度指标一同考虑。

A.2 玩具实验细节

先验。 信号x为R²中的元素。我们定义参考向量u，此处为第一个标准基向量u = e_1。先验在±au处有两个原子（标量a > 0）：

p(x_0) = (1/2) δ_{−au} + (1/2) δ_{au}，a = 1。(14)

注意到，对于EDM参数化的前向模型x_σ = x_0 + σε（ε ∼ N(0, I)），先验去噪器精确已知：

D(x, σ) = E[x_0 | x_σ = x] = a tanh(a⟨x, u⟩/σ²) u。(15)

DAPS与PC-DAPS使用该闭式去噪器代替训练网络，既用于概率流ODE也用于所有Tweedie估计。

测量与似然。 测量算子为内积的二次函数：

A(x) = f(⟨x, u⟩)，f(z) = (c/(2ab)) (z−a)(z+a−b)，(16)

选择其插值f(−a) = c、f(a+b) = c与f(a) = 0。测量遵循y = A(x_0) + n，n ∼ N(0, β_y²)，故似然为p(y|x_0) = N(y; A(x_0), β_y²)。观测设为y = c = κβ_y。图2使用的精确值为β_y = 0.05、b = 0.1、κ = 2（因此c = 0.1）。

精确后验。 由贝叶斯法则，真实后验p(x_0|y)具有闭式形式：

p(x_0|y) = (1−π) δ_{−au} + π δ_{au}，π = p(y|au)/(p(y|−au) + p(y|au))。(17)

注意到，虽然A((a+b)u) = A(−au)，但(a+b)u没有先验质量，因此来自（其邻域的）(a+b)u的样本是先验不一致的幻觉。

A.4 其他实现选择

有两个与PC-DAPS核心算法正交但在实践中提升重建质量或计算效率的实现选择：跳过最终Langevin细化与使用自适应ODE步进。其效果总结于表3，详述如下。

跳过最后一次Langevin细化。 在最终退火时刻（t_0 = 0），不执行Langevin更新，而以ODE端点x̂0(x{t_0})作为输出。当噪声接近零时，Langevin步长变得非常小，且添加的噪声可能略微降低样本质量。

自适应ODE步进。 为计算DAPS干净估计x̂0(x{t_i})，概率流ODE使用欧拉步积分。在高噪声水平使用一个欧拉步（此时干净估计对精确ODE积分不太敏感），在较低噪声水平增至五步（此时先验更具判别性，更精细的积分可减少数据流形附近的离散化误差）。由于PC-DAPS使用多粒子袋，减少不必要的ODE评估对控制额外计算成本很重要。因此采用自适应ODE步进来提升基于粒子的采样器的时间效率。

PC-DAPS所用的粒子聚类与修剪过程的实现细节描述如下。

聚类技术。 为将粒子分配至分量，将第4.2节所述的对应干净样本{x̃0^{(k)}}{k=1}^K下采样至粗分辨率（如32×32），中心化，并投影至解释90%方差的前若干主成分上。在该子空间上拟合高斯混合模型，M经贝叶斯信息准则选取（Schwarz，1978）。随后每个粒子被硬分配至其最可能的分量，得到袋的一个划分{C_m}_{m=1}^M。

修剪阈值。 仅当公式8中的测试触发（r* > r̄）且聚类返回多于一个簇时，才对Langevin后样本应用修剪。每个簇使用非正函数公式9（S = {0.5, 1, 2}）评分。记s* = max_m s(C_m)，所有满足s(C_m) < (1+γ)s*的簇C_m被修剪，而满足(1+γ)s* ≤ s(C_m) ≤ s*的簇被保留。每个被修剪的粒子被一个幸存粒子的副本替换，并在幸存者之间循环。注意到产生分数s*的簇总是幸存。γ从簇内分数变化中校准：遵循Zhang等（2025），每个数据集的10张校准图像经PC-DAPS（含聚类过程）去噪而不进行修剪。计算每个簇内所有粒子对的相对平均分数差异，γ设为这些差异的第95百分位数。

A.5 时间成本

PC-DAPS在一条采样轨迹中保留K个粒子，而DAPS需要K次独立运行才能获得K个候选重建。若忽略实现开销，两种方法需要大致相同的去噪器评估次数，随K近似线性增长。PC-DAPS确有额外步骤，包括聚类、估计混合参数与一次性修剪步骤。然而，与ODE和Langevin更新的成本相比，这些仅增加很小开销。

第A.4节中的实现选择（如跳过最终Langevin细化与低噪声时使用自适应ODE步进）有助于降低PC-DAPS的采样成本。图8展示了实测耗时与重建质量。对于超分辨率，PC-DAPS因使用多粒子而比DAPS耗时更长。但对于相位恢复，DAPS的运行时间包含四次独立运行，因其使用best-of-4评估协议；而PC-DAPS在一次运行中创建粒子集并在内部选择。这些结果表明，使用多个粒子并不总是意味着达到相同质量指标需要高得多的实际时间成本。
