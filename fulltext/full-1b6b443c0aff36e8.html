我们隆重推出 GPT‑6 Astra，全球最智能、最对齐的模型。

GPT‑6 Astra 汇集了多年来在预训练、强化学习和对齐方面的深入研究与重大投入。Astra 在计算机使用、浏览、软件工程、网络安全、科学和专业工作领域均处于最先进水平。Astra 以 98% 的成绩饱和了 FrontierMath Tier 4，并已帮助解决数学领域的长期开放问题⁠。Astra 还以 99.9% 的成绩饱和了 ARC-AGI-3，以 100% 的成绩饱和了 ExploitBench。它在计算机和浏览器使用方面也设立了新的前沿标准，以无与伦比的速度、准确性和判断力处理最苛刻的专业工作。

GPT‑6 Astra 今天开始向有限的组织推出，并将在未来几天内向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，同时也可通过 OpenAI API、Microsoft Azure 和 AWS Bedrock 使用。

全球最佳计算机使用模型

GPT‑6 Astra 标志着计算机使用速度、准确性和安全性的新前沿。它可以处理繁琐任务，如填写在线表单、更新 CRM 中的客户记录以及整理日程。它可以进行在线研究，并在你的电子邮件或文档编辑器中起草摘要。它可以分析科学数据、生成图表、创建网站，并运行前端 QA 检查以确保网站上的所有功能正常运行。它可以帮助你自主安装和测试软件，并排查你在屏幕上看到的问题。这些改进也反映在我们最先进的评估结果中。

这些改进在实际知识工作任务中也带来了显著的效率提升。在 OSWorld 2.0 的延迟模拟中，Astra 每个任务用时减少约 47% 的情况下实现了更高的计算机使用性能，得分为 72.6%（每个任务约 40 分钟），而 GPT‑5.6 Sol 得分为 65.7%（每个任务约 75 分钟）。³

专业工作的重大跃升

GPT‑6 Astra 将计算机使用的进步与针对专业环境的定向训练相结合，帮助解决复杂的工作任务。它将解决复杂问题所需的智能与执行多步骤工作流以及生成精美文档、电子表格和演示文稿的能力相结合。

GPT‑6 Astra 是我们最擅长遵循现有模板并生成排版良好、以结构化叙事简洁传达关键点的幻灯片的模型。它创建清晰、结构良好的文档、演示文稿、电子表格和分析，遵循你的模板并匹配你的写作和视觉风格。Astra 还经过专门训练，仅将重要的上下文提取到输出中，而不是重复对当前工作不必要的信息。所有这些意味着它可以输出更直接可用的成果，符合你的业务背景和标准。

GPT‑6 Astra 还为其构建的网站、游戏、应用程序和渲染带来了更强的视觉判断力。通过 ChatGPT 中的 Sites⁠（在新窗口中打开），Astra 可以直接从提示创建、托管和分享网站、Web 应用和游戏。

借助 Astra，我们引入了一种新方法，让 Codex 在上下文窗口填满时保留和检索上下文。从历史上看，模型在长会话期间使用压缩来总结工作，例如在调试复杂问题或进行大型重构时。每次压缩都可能遗漏关于修复为何失败或组件如何行为的细节。在 Codex 中，Astra 可以跨上下文窗口保留笔记，保留累积的细节，而无需反复将它们压缩成单个摘要。早期的上下文窗口仍然可搜索，因此 Astra 可以从之前的消息和工具输出中找到需求或测试结果——即使该信息未被捕获在其笔记中。你可以在 Codex config.toml⁠（在新窗口中打开）中启用此实验性功能，它将在未来几周内成为 Astra 的默认设置。

网络安全

正如我们在安全更新⁠中所讨论的，Astra 在网络能力方面是一个重大飞跃，在我们的准备框架⁠下达到了网络安全的关键阈值。它识别和开发零日漏洞的能力可以帮助防御者发现和修补弱点，但这也需要更强的保障措施。为了了解这些能力延伸到什么程度，我们在内部和第三方专家评估中运行了 Astra。

我们首先在没有生产安全防护的情况下在 ExploitBench 和 ExploitGym 上测试了该模型，这些测试评估模型是否能将已知软件漏洞转化为可用的漏洞利用。在 ExploitBench 上，Astra 获得了 100% 的满分，而我们之前的前沿网络能力模型 GPT‑5.6 Sol 为 78.5%。在 ExploitGym 上，Astra 达到了 42.4% 的成功率，而 GPT‑5.6 Sol 为 30.3%，同时使用的输出 token 大幅减少。¹³

鉴于对历史软件漏洞的接触可能影响基准测试结果的担忧，我们还在两个新基准上评估了 Astra。其中一个，我们构建了一个内部"ExploitBench（2026年6月–8月）"评估，使用前三个月的漏洞来测试漏洞利用开发。¹⁴ Astra 在该数据集上实现了比 GPT‑5.6 Sol 显著更高的任意代码执行率，同时使用的输出 token 远少于后者。在评估过程中，Astra 甚至发现并使用了两个之前未知的零日漏洞。我们正在向其维护者披露这两个漏洞。

我们还在 SRE-Bench¹⁵ 上测试了 Astra，这是一个衡量模型是否能在不访问原始源代码的情况下逆向工程软件二进制文件以理解其核心逻辑的基准。Astra 在单次尝试中解决了 88.0% 的任务，在四次尝试中解决了 99.2%，而 GPT‑5.6 Sol 分别为 55.9% 和 68.7%。

除基准测试外，专家主导的评估发现，在没有生产安全防护的情况下运行时，Astra 能够利用之前未知的漏洞在加固浏览器中实现任意代码执行，并为加固操作系统创建权限提升漏洞利用。

正如我们在《防御者之窗》⁠中所讨论的，前沿网络能力可以帮助防御者更快地发现弱点，但也使这些弱点更容易被利用，提高了防御者适应的紧迫性。对于今天发布的 Astra 版本，防御者可以使用它来完成安全代码审查和修补等任务。

然而，Astra 将拒绝执行更高级的网络安全任务，例如为漏洞创建概念验证漏洞利用。通过 OpenAI Daybreak⁠，我们计划在未来几周内扩大访问范围并推出限制较少的安全防护。这将支持更多防御性工作流，包括漏洞和概念验证验证、恶意软件分析和检测工程。

我们还加强了针对潜在网络滥用的保护，在 GPT‑5.6 Sol 的安全防护栈基础上进行了构建。这些包括更强的模型鲁棒性以更好地抵御潜在的越狱，以及为我们的监控系统提供更多上下文。我们继续进行严格的内部和外部测试，包括使用内部红队攻击者⁠进行自动化评估。有关我们的网络保障和测试的更多详细信息，请参阅 Astra 安全概述⁠和系统卡⁠（在新窗口中打开）。

负责任地对齐和部署 GPT‑6 Astra

Astra 是我们对齐程度最高的模型。Astra 在谨慎行事、尊重任务边界和透明沟通方面表现出色。这项工作是我们长期研究计划的最新成果，该计划专注于训练从头到尾都与人类意图保持一致的模型。

在敏感环境中，Astra 以与其风险相称的谨慎程度行事。在一项经过对抗性选择以引发不当行为的计算机使用任务评估中，Astra 在避免意外后果方面更加成功。在默认提供的额外安全措施下运行时，性能更加出色。

Astra 产生的失齐结果比测试过的任何其他前沿模型都少。为了公平比较，我们使用了通用的计算机使用智能体工具链（基于 OpenAI Responses API⁠（在新窗口中打开）和 Anthropic Messages API⁠（在新窗口中打开）中可用的原生计算机使用工具），并且没有通常部署给 Codex 和 ChatGPT Work 用户的额外保护（自动审查、确认策略）。¹⁶

Astra 也更有可能在用户设定的边界和其环境暗示的边界内运作。在一项内部评估中，Astra 从未试图绕过 Codex 自动审查的拒绝。即使自动审查被故意配置为可绕过，且任务否则无法完成，这一点仍然成立。这种对环境限制的尊重与我们在本文引言中分享的不可能网络任务评估结果以及系统卡⁠（在新窗口中打开）中记录的其他发现一致。

Astra 在透明的用户沟通方面也创下了新纪录。在一项评估中，Astra 对其能力和功能做出不准确陈述的可能性比 GPT‑5.6 Sol 低三倍。

在我们的能力幻觉评估中，Astra 相比 GPT‑5.6 Sol 有显著改善，对其能力做出误导性陈述的情况更少。

我们的评估发现，基于明确要求其规避监控的测试，Astra 的书面推理比 GPT‑5.6 Sol 更难监控。我们将此归因于 Astra 在较简单任务上对书面推理的更强控制力，以及用更少的书面步骤解决问题的能力。Astra 似乎仍然难以隐藏复杂任务所需的推理，但我们认真对待这一下降。改善可监控性仍然是研究优先事项，随附的系统卡⁠（在新窗口中打开）详细介绍了我们的发现和正在进行的工作。

对齐训练是我们部署方法的核心。作为额外的防御层，我们还构建了系统保障措施，如 Codex 自动审查⁠（在新窗口中打开）以及监控智能体的推理和行动，以帮助检测和遏制不安全行为。正如我们的安全更新⁠中所述，我们还在 Astra 级模型的生产中部署失齐监控，以便了解失齐情况并帮助遏制其最严重的情况。这些保障措施类似于我们对内部部署的监控，涉及一个分类器系统，检查模型的推理和行动是否存在未经授权的行为，并自动停止潜在的未经授权的活动。

鉴于 Astra 网络安全能力的显著提升，我们在确保此次部署安全可靠方面格外谨慎。额外的安全检查有时会减慢、暂停或停止合法工作，包括防御性网络安全。如果任务在 ChatGPT 或 Codex 中被暂停，你可能会被要求在继续之前审查该操作。在 API 中，任务将停止。这些检查有时会中断合法工作，我们正在继续迭代该系统以减少不必要的中断。失齐监控不能替代对齐：我们的目标是构建可靠地保持在授权范围内的模型，这样这些保护措施就不需要干预。

可用性

GPT‑6 Astra 今天开始向有限的组织推出，并将在未来几天内向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，同时也可通过 OpenAI API、Microsoft Azure 和 AWS Bedrock 使用。Astra 的使用包含在现有订阅额度中——用户和企业还可以购买额外使用量的积分。Pro、Business 和 Enterprise 计划的用户还将获得 GPT‑6 Astra Pro 的访问权限。企业管理员可以为其工作区启用 Astra；发布时默认关闭。

Astra 为符合条件的 API 客户端支持零数据保留，正如我们上个月分享的，我们正在测试私有安全处理⁠，以在保护客户隐私的同时加强安全监控。

对于开发者，GPT‑6 Astra 将在 OpenAI API 中以 gpt-6-astra 的名称提供，并可通过 Microsoft Azure 和 Amazon Bedrock 使用。

OpenAI API 标准定价为每百万输入 token 10 美元，每百万输出 token 50 美元。缓存读取和写入适用单独费率。GPT‑6 Astra 在 API 中提供快速模式，以标准价格 2 倍的价格提供高达 2 倍的标准处理速度。
