特色文章

Carl Franzen

谷歌今日发布了其最新、最智能的前沿 AI 模型：Gemini 4 Carbon 承诺在网络安全和复杂软件工程方面实现改进，入门期 token 定价与前代旗舰模型 Argon 相同。根据谷歌及第三方的测试，它还声称在大多数常见企业基准测试中位居全球第一。

然而，谷歌最初仅向其精心策划的"Fairwind 计划"中选定的网络安全防御者授予访问权限，大多数开发者和企业只能等待更广泛的发布。谷歌表示，在"收集反馈并迭代改进防护措施"之后，将"尽快"进行广泛发布。

独立评估机构 Artificial Analysis 将使用高推理模式的 Carbon 列为其智能指数 v5.0 的第一名，得分 59 分，领先于 58 分的 Claude Opus 5.5、57 分的 GPT-6 Astra 和 50 分的 Argon。

另外，在谷歌公告的 17 项基准测试中，Carbon 在 15 项上取得最高成绩，不过 OpenAI 在一项软件工程测试中保持优势，Anthropic 在一项计算机使用评估中领先。

谷歌 Gemini 4 Carbon 基准测试对比图。图片来源：谷歌

谷歌表示，Carbon 将以每百万输入 token 2 美元、每百万输出 token 10 美元的价格推出，缓存输入可享 95% 折扣。

这些费率是暂时的：脚注中注明后续价格分别为 4 美元和 20 美元。谷歌在其发布博文中未具体说明 Carbon 的入门期将于何时结束。

独立测试也揭示了一些权衡：Carbon 在编程和知识工作方面较 Argon 有显著改进，但在专业任务上落后于多个竞争对手，并且在一项事实知识测试中的幻觉率高于 Argon。

对于企业而言，此次公告在谷歌已发布的测试中展示了一个更强大的模型，且相对 Argon 其公布的每 token 费率并未提高。但它尚未提供普遍可用的替代方案。谷歌已于 10 月 13 日更广泛开放的 Argon 仍是客户可通过其现有公开产品进行评估的模型。

Carbon 沿袭 Argon 的发布路径，但侧重点不同

从时间上看，需要区分 Argon 的发布公告与公开发布。谷歌于 9 月 30 日推出 Argon，最初通过 Fairwind 向获批的网络安全合作伙伴授予访问权限，随后于 10 月 13 日进行了更广泛的推出。Carbon 在那次扩展之后 15 天到来。

Argon 本已针对高要求的工程、专业研究和安全任务。谷歌描述了协助内存优化以及 C/C++ 向 Rust 迁移的智能体，敏感代码变更需经过测试和人工审查。网络安全同样是核心：Argon 被设计用于发现缺陷、验证其重要性并生成修复程序。

因此，Carbon 与 Argon 之间的重大区别在于谷歌报告的在现有领域的改进，尤其是持续性工程工作、漏洞利用测试和智能体可靠性。谷歌尚未发布技术报告，也未说明 Gemini 4 Argon 是否采用新的模型架构，更未披露参数数量。

"在内部，我们的团队已经看到 Carbon 连续运行数天，"谷歌在这份公告中写道。公告由 Google DeepMind 高级副总裁兼谷歌首席 AI 架构师 Koray Kavukcuoglu 撰写。该公司描述称，该模型在大型代码库中诊断缺陷和开发补丁时，即使方法不成功也会持续尝试。

Argon 的模型文档已明确规定超过 100 万 token 的共享上下文容量（涵盖输入和输出），并可在默认 65,536 token 输出限制之外进行扩展生成。

它接受文本、图像、视频、音频和 PDF 作为输入，同时生成文本。它还支持函数调用、代码执行、结构化响应以及预览阶段的计算机交互。

这些规格确定了 Argon 目前为开发者提供的功能。Carbon 的公告未提供同等的 API 规范，因此无法确定这些限制和受支持的功能是否会原封不动地延续。

与此同时，谷歌 10 月 13 日的公告使 Argon 可通过其 API 使用，并将其引入付费消费者产品。其单独的开发者发布通知还确定了通过 AI Studio 和 Android Studio 的访问方式。Carbon 的公告承诺进行有控制的扩展，但未确定类似的公共端点或逐个产品的发布时间表。

前 Windsurf CEO、现任谷歌 Antigravity 负责人 Varun Mohan（在 X 上以 @_mohansolo 发帖）也指出了通过 Antigravity 进行的内部使用："……大家真的很喜欢在 Antigravity 内部使用它来解决最棘手的任务，"他写道。

他表示，在 Antigravity 更广泛可用之前，访问权限将通过 Fairwind 扩大，并援引了 Carbon 在漏洞发现和修补方面的能力。他的帖子给出了产品去向，但没有发布日期。

价格相同，但截止日期和总成本仍然不同

目前，Carbon 拟议的定价与 Argon 的入门期及后续费率一致：

每百万 token 的 API 定价

Gemini 4 Carbon Gemini 4 Argon
入门期输入 2 美元 2 美元
入门期输出 10 美元 10 美元
入门期缓存输入 0.10 美元（根据公布的折扣计算） 0.10 美元
后续输入 4 美元 4 美元
后续输出 20 美元 20 美元
入门期结束时间 未指定 12 月 1 日

最后一行的区别很重要。谷歌的 Argon 开发者指南明确规定其更高费率将于 12 月 1 日生效。Carbon 目前没有确定的截止日期。

以一个使用 1000 万个未缓存输入 token 和 100 万个计费输出 token 的示例工作负载计算，公布的入门费率将产生 30 美元的 token 账单，后续费率则产生 60 美元。该计算不包括其他费用，并假设 token 消耗量不变。

相同的单价并不意味着完成任务的成本相同。Carbon 的发布材料没有提供将其每个成功任务的成本与 Argon 进行比较所需的 token 消耗量、重试次数或执行时间。

Argon 的文档使这一区别具体化：其输出费用包含推理 token，其低、中、高推理设置会影响消耗量和响应时间。使用 grounding 时，谷歌还会对与内部工具指令和函数定义相关的 token 收费，而 Google Search grounding 另有单独的查询费用。

Carbon 的 95% 缓存输入折扣相当可观，但公告未具体说明其缓存机制。Argon 的指南描述了自动缓存，并明确表示不支持显式创建的缓存。开发者目前还不能假设 Carbon 的实现会与之完全相同。

现有证据仅支持一个狭义的定价结论：谷歌正以相同的 token 费率宣传改进的基准性能。它尚未发布足够的运营数据来证明在已完成的工程或安全工作上支出更低。

基准测试收益广泛，但优势大小不一

谷歌的对比显示，Carbon 在全部 17 个报告项目上均较 Argon 有所改进。其中几个最大的百分点增益涉及长时间推理、安全测试和科学工作。

下表复制了谷歌发布图表中的部分分数。除 AA 指数（以指数点计）外，差异均以百分点表示。

Vals Index v2.2 69.2% 70.4% +1.2
SWE-sweep 4.3% 9.6% +5.3
FrontierSWE 2 55.0% 61.2% +6.2
Terminal-Bench 4.0 (AA) 57.1% 65.2% +8.1
Agents' Last Exam v1.1 69.0% 77.4% +8.4
OSWorld-2.1 离线子集 74.7% 81.5% +6.8
AutomationBench 51.3% 53.9% +2.6
GraphWalks 84.2% 96.2% +12.0

GraphWalks（谷歌报告的上下文范围为 25.6 万至 100 万 token）显示出与所提及竞争对手的特别大差距：Carbon 达到 96.2%，而 Astra 为 71.8%，Opus 为 66.8%。该结果衡量的是在指定评估中的表现，并不能独立确定 Carbon 的生产 API 限制。

软件工程方面的结果则不那么一致。Carbon 的 SWE-sweep 分数是 Argon 的两倍多，但其 9.6% 的结果仅比 Astra 的 9.5% 高出十分之一个百分点。在 FrontierSWE 2 上，Carbon 的 61.2% 落后于 Astra 的 65.5% 和 Opus 的 62.3%。

计算机使用方面同样结果分化。Carbon 在展示的 Agents' Last Exam 分数中领先，但 Opus 在 OSWorld 离线子集上达到 87.2%，领先于 Carbon 的 81.5%。

在业务工作流方面，AutomationBench 显示相对 Argon 的改进较小，从 51.3% 升至 53.9%，但相对展示的 Astra 和 Opus 结果仍保持较大优势。Vals Index 则更为接近：Carbon 的 70.4% 仅略高于 Opus 的 70.2%。

其他报告的改进包括图表解读、蓝图相似性和数学。Carbon 在 Vending-Bench 2 上以 16,484 美元的银行余额收官，相比之下 Argon 为 13,718 美元，Astra 为 15,515 美元。这是基准测试的结果，并非为客户创造收入的证据。

自主组织初创公司 Andon Labs 表示，这一结果使谷歌时隔一年重返 Vending-Bench 2 榜首。其图表追踪了大约一个模拟年内的余额变化，Carbon 最终领先于 Astra、Argon 和 Opus。评估者还将这句话归于 Carbon："我的首要任务是最大化我的利润并消灭我的竞争对手。"

Artificial Analysis 将其指数描述为由九项独立进行的评估组成的综合指标。其新发布的图表证实了 Carbon 的第一名分数，并标注该模型尚无公开可用的 API。

这一领先优势来自一套修订后的测试组合，旨在降低饱和度并减少对公开题目的暴露。Artificial Analysis 表示，v5 版本中 60% 采用私人测试或保留答案。该版本增加了 FrontierCode 2.0 和 Terminal-Bench-Science，以 HLE-Diamond 替换了 HLE，并修订了 AA-Omniscience 和 CritPt。Omniscience 更新移除了已饱和和公开题库的问题，增加了替代题目并修正了有问题的项目。Carbon 的领先及其与 Argon 的比较均基于这一修订版本，不应与旧版指数分数混为一谈。

谷歌的图表也未提供不确定性估计。即便更广泛的比较显示出相对 Argon 的显著进步，其最微弱的差距也不能证明对公司特定工作负载具有决定性优势。

独立测试：编程进步与知识工作的局限并存

Artificial Analysis 报告，在通过 Antigravity CLI 运行的 Coding Agent Index 上，Carbon 的单独得分为 59，比 Argon 的 53 高出 6 分。使用 Opus 5.5 的 Claude Code 以 62 分领先。展示的图表还显示，使用 Sonnet 5.5 的 Claude Code 和使用 Muse Wonder Full 的 Muse Code 同为 59 分，因此 Carbon 并非唯一处于该四舍五入分数的模型。

该智能体指数评估的是在编程工具内运行的模型，而非测量与通用智能指数相同的能力集合。其三个组成部分为 FrontierCode v1.1、Terminal-Bench 4.0 和 SWE-Atlas-QnA-AA。

Artificial Analysis 将 Carbon 在前两项上列为第二，得分分别为 51% 和 64%。其 SWE-Atlas-QnA-AA 结果为 64%，落后于使用 Muse Wonder Full 的 Muse Code 的 69%。64% 的 Terminal-Bench 结果属于 Antigravity CLI 评估；谷歌单独的模型对比报告为 65.2%。这些结果应保留其评估语境。

知识工作呈现出更为复杂的图景。Carbon 在 AA-Briefcase 上达到 1,609 Elo，比高推理模式下的 Argon 高出 126 分。据评估者称，它仍低于 xhigh 推理模式下的 Grok 4.7（1,638）、max 模式下的 Muse Wonder（1,659）以及 Kimi K3.1 Pro（1,678）。

演示质量是报告的最大改进项：Carbon 增加 293 Elo，达到 1,598。分析质量提高 120 Elo，达到 1,671。这些结果显示出相对 Argon 的改进，但并未确立在该评估所涵盖的专业工作中的领先地位。

网络安全是最清晰的焦点——但有一个评估注意事项

谷歌将 Carbon 的安全结果围绕三个阶段组织：发现漏洞、验证其是否可被利用以及生成纠正性补丁。

在这些评估中，相对 Argon 的最大增益出现在 ExploitGym 上，Carbon 从 42.0% 升至 54.8%。在 SEC-bench Pro 上，报告结果从 83.4% 提高到 88.2%。CWE-bench 从 68.0% 增至 71.0%。

这些区别在操作层面很重要。发现可疑代码本身并不能证明存在可利用的缺陷，而演示漏洞利用也不能证明所提议的修复有效。谷歌将 Carbon 的结果作为覆盖这些独立步骤的证据。

这里有一个重要前提条件：谷歌表示，外部网络安全评估是在"无防护措施"（without guardrails）的情况下进行的。因此，该公告并不能证明客户在其部署所附带的任何限制条件下会获得相同的分数。

谷歌补充了内部证据，报告 Carbon 在生成安全代码时的成功率是 Argon 的两倍以上。它还表示，Chrome 团队观察到在生成高质量补丁方面，Carbon 相对某竞争实验室的模型具有超过十倍的优势。该竞争对手未被点名，公告也未提供独立评估这一比较所需的基础结果。

这些主张延续了谷歌在 Argon 上已着重强调的工作。早期模型的发布材料在描述其工程用途的同时，也描述了漏洞发现与修复。Carbon 更强的报告结果强化了这一现有重点，但并不能证明网络安全能力始于此次发布。

可靠性改进伴随受限的发布

谷歌与 Argon 的另一项主要比较涉及模型在完成任务过程中的行为表现。

该公司报告，在内部测试中，Carbon 将无依据断言大约减少了一半。它表示，在其内部编程环境中，严重对齐警报下降了近 80%，而超出任务范围和未能提供足够帮助的指标分别下降了 26% 和 29%。

独立的事实知识测试使这一可靠性叙事变得复杂。Artificial Analysis 给予 Carbon 最高的 AA-Omniscience 分数 54，比 max 推理模式下的 Opus 5.5 高出 6 分。Carbon 正确回答了 58% 的问题，而 Argon 为 48%，但其报告的幻觉率从 4% 升至 11%。评估者报告，Opus 5.5 和 Astra 在 max 推理模式下均为 50%。

该基准测试的方法论将幻觉率定义为错误回答数除以错误、部分正确和未回答的总数。因此，11% 并不意味着所有回答中有 11% 是编造的。总体指数奖励正确回答，惩罚错误回答，并允许不作回答而不受罚。

因此，Carbon 在这一综合指标上领先，但在幻觉组成部分上表现不如 Argon。这一发现来自与谷歌内部无依据断言测量不同的评估；这两个结果既不能证明跨任务的事实可靠性有一致的改进，也不能证明有一致的退步。

在 Terminal-Bench 4.0 上，谷歌报告成功作弊率为 0.0%，尝试作弊率为 0.4%。对于一个被期望完成实际任务而非利用测试或谎报完成情况的智能体而言，这些是重要的区别。

谷歌还报告，在 Gray Swan 的间接提示注入评估中，攻击成功率为 0.0%，而 Argon 为 0.7%。该结果仅适用于所评估的攻击，并不能证明对在每个代码库、文档或网页中遇到的恶意指令具有免疫力。

据谷歌称，Carbon 采用与 Argon 相同的广泛安全方法，结合了训练、防滥用防御、对注入指令的抵抗力以及对模型推理的监控。该公司表示，额外的工作针对复杂或高要求任务下的行为表现。

这些改进仍属于公司自行报告的测量结果。此次发布并不能证明外部客户遇到相同故障的频率，也无法重现这些降幅。

谷歌表示，它正在参与美国政府的自愿预发布测试流程，同时收集反馈并完善保护措施。它计划在向更广泛受众推出之前，先通过 Fairwind 扩大 Carbon 的访问权限。

这使得企业在两款旗舰模型之间面临一个实际区别。Argon 拥有公开的访问渠道、有据可查的 API 行为和明确日期的定价过渡。Carbon 在谷歌的对比中拥有更强的报告结果、相同的公布 token 费率，但初始受众更窄。其更广泛的发布日期、详细的 API 规范和促销价格截止日期均尚未公布。
