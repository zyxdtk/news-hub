中文摘要： 本文研究大语言模型在自然语言推理（NLI）中如何处理否定，提出极性组合假说：事件匹配门控相对极性，极性一致为真、不一致为假、无匹配为未知。行为实验表明Qwen3-8B和Phi-4 Mini的预测符合该假说。利用分布式对齐搜索（DAS），作者识别出与假说变量对齐的因果有效子空间，证明匹配与相对极性子空间相互作用决定输出。这些表示可跨否定形式迁移并部分迁移至MNLI，但相对极性迁移依赖匹配上下文。

摘要

我们研究语言模型如何在自然语言推理（NLI）中处理否定。我们提出极性组合假说，这是对该计算过程的一个高层因果模型。行为评估表明，语言模型的预测在很大程度上符合所提出的假说。利用分布式对齐搜索，我们识别出与极性组合假说中变量对齐的因果有效子空间。这些表示可跨否定形式迁移，并部分迁移到MNLI的一个子集。我们发布了数据集和代码¹。

¹ https://github.com/hnhine/polarity_composition

1 引言

大语言模型（LLM）在自然语言推理（NLI）上取得了强劲表现，该任务要求模型判断一个假设是由前提推出、与之矛盾，还是无法确定（Bowman等，2015；Williams等，2018）。然而，正确的标签并不能揭示模型如何做出决策。模型可能利用词汇相关性和标注伪影，同时在受控对照上仍然脆弱（Gururangan等，2018；Hossain等，2020）。否定提供了一个有用的诊断工具，因为改变单个算子可以将事件从肯定极性转变为否定极性，同时基本保留其底层内容。

自然逻辑通过为原子编辑分配关系并将其组合成句子级关系来对推理建模（MacCartney和Manning，2007，2009）。先前的工作使用受控NLI数据和干预来测试微调编码器是否部分实现了此类算法（Geiger等，2020，2021；Rozanova等，2024）。在互补的设置中，Zhou等（2026）研究了仅解码器语言模型如何处理否定表达式，识别出建设性与抑制性机制以及后层注意力捷径。他们的工作关注否定如何改变概念表示，而我们研究多个假设事件与声明中事件之间的否定关系。我们从自然逻辑中借鉴了一个想法：当假设和声明共享内容时，它们至多相差一个原子编辑，即否定算子。因此，解决该任务需要将“两个句子是否描述同一事件”与“它们的极性是否一致”这两个问题分开。冻结的仅解码器LLM是否分离这两个组件并在NLI中使用它们仍不清楚。

为弥补这一空白，我们构建了一个包含多个假设事件和单个声明的受控任务。如图1所示，我们假设模型基于两个关键因素处理NLI中的否定：事件匹配和受否定影响的相对极性。事件匹配确定假设事件与声明是否描述同一事件，而相对极性表示它们的极性是否相等。

我们将该假说作为高层因果模型，使用分布式对齐搜索（DAS）在Qwen3-8B和Phi-4 Mini Instruct这两个通过我们行为测试的开源权重模型上进行测试，所有模型参数均被冻结（Geiger等，2024）。我们的主要贡献如下：

  • 我们提出极性组合假说，该假说提出了LLM在NLI中处理否定的内部机制（§3）。
  • 我们证明两个模型在行为上遵循所提出因果假说的预测（§4）。
  • 我们识别出与该假说对齐的因果有效表示，并表明它们在决定NLI输出时相互作用（§5）。
  • 学习到的表示可跨否定形式迁移并迁移到MNLI示例，尽管相对关系迁移依赖于匹配上下文（§6）。

总之，这些结果支持了对LLM如何在NLI中处理否定的一个高层因果解释：识别事件是否匹配，为匹配事件形成极性关系，并联合使用这两个信号来解决问题。

2 相关工作

NLI中的否定 自然逻辑通过为原子编辑分配关系、通过单调性上下文投影它们并组合结果，直接在语言表达上进行推理（MacCartney和Manning，2007，2009）。该框架推动了对单调性和否定的受控评估，包括MED、MoNLI、NaN-NLI和ScoNe-NLI（Yanaka等，2019；Geiger等，2020；Truong等，2022；She等，2023）。这些评估表明，神经NLI模型通常无法在词汇、辖域和否定对比上泛化。更广泛的研究报告了自回归语言模型中的类似敏感性，并表明否定在NLI基准中的表示仍然较弱（Hossain等，2020；Truong等，2023；García-Ferrero等，2023；Vrabcová等，2025）。我们将自然逻辑作为动机而非实现：我们仅保留原子否定编辑，不对单调性投影建模。事件内容与极性的类似分离也出现在形式语义学中：情境语义学用关系、其论元和极性来描述基本事态（Kratzer，2023，§2），事件语义学（Davidson，1966）将否定视为应用于事件描述的算子（Champollion，2010；Bernard和Champollion，2018）。这些理论也处理量词辖域，而我们的假说不处理。

因果分析 自然逻辑的显式中间结构使NLI成为因果分析的有用设置。交换干预将模型在一个输入上的隐藏状态的一部分替换为在另一个输入上计算的状态，并检查输出是否如高层因果模型预测的那样变化。Geiger等（2020）结合探测和交换干预来测试在MoNLI上微调的BERT是否部分实现了连接词汇蕴含和否定的算法。这种在神经语言模型上实现因果推断（Pearl，2001）的方法被Geiger等（2021）扩展到组合NLI。最近，Rozanova等（2023，2024）对自然逻辑特征进行干预并估计其对NLI预测的影响。这些研究关注任务训练的编码器以及词汇关系与单调性之间的相互作用。在互补的设置中，Zhou等（2026）识别了仅解码器LLM中被否定概念的建设性和抑制性机制。这两条工作路线都没有识别出LLM解决涉及否定的NLI的机制。我们通过提出并因果测试极性组合假说作为候选机制来弥补这一空白。

变量同一性 我们跨层和词元位置的分析与事实回忆和信念追踪中的信息路由相关（Geva等，2023；Prakash等，2026）。学习到的干预子空间引发了关于变量同一性和干预忠实性的问题：一个按预测改变输出的子空间可能携带源标签或其他相关特征，而非预期变量。成功的修补可以激活替代通路或产生分歧的下游表示（Makelov等，2024；Wu等，2024；Grant等，2026），而RAVEL和MIB评估因果变量的隔离和恢复（Huang等，2024；Mueller等，2025）。因此，我们冻结每个学习到的子空间，并在不进行特定同一性重拟合的情况下比较预先指定的同一性假说。该测试区分了在给定位置考虑的候选解释，但不声称恢复唯一的内在变量。

3 极性组合假说

否定本身并不决定两个句子之间的推理关系。我们用极性来表示一个句子是肯定还是否定一个事件描述。考虑以下句子对：

假设：John did not visit PlaceA.
声明：John visited PlaceA.

这两个句子共享相同的无极性事件内容，但极性相反，因为假设被否定，结果为FALSE。如果将声明替换为"John visited PlaceB"，假设仍然被否定，但事件内容不再匹配。因此其极性不应影响输出，合适的标签是UNKNOWN。

这一对比启发了极性组合假说。该假说将事件匹配与相对极性分离，并允许极性关系仅对匹配事件影响决策。极性一致产生TRUE，不一致产生FALSE，无匹配产生UNKNOWN。对于多个假设事件，只有与匹配事件相关的关系才应起作用。

图2：提示模板。 输入包含一个或三个假设事件和一个声明。

我们考虑对假设事件A = (e1, ..., ei, ..., en)和声明事件C = ec的推理。每个事件表示为ei = (zi, pi)，其中zi = (si, vi, oi)是其主谓宾内容，pi ∈ {−1,+1}是其极性。肯定和否定事件分别取值+1和−1。声明类似地表示为ec = (zc, pc)。

我们用变量将假说形式化为：

ρi = PolComp(pi, pc) = pi pc,
mi = 1[zi = zc],
ri = Gate(mi, ρi) = mi ρi,
r(A, C) = Σi ri, y(A, C) = g(r(A, C)). (1)

这里，当两个极性一致时ρi = +1，不一致时ρi = −1。翻转任一极性会反转ρi，而翻转两者则保持不变。匹配mi要求主语、动词和宾语的同一性，这在主语和宾语是专有名词时有效²。在高层代数层面，ρi = pi pc对任何事件对都有定义，mi决定它是否对输出有贡献。这不要求模型在mi = 0时实例化可迁移的关系代码。

²量化主语在局限性部分讨论。

决策函数满足g(+1) = T，g(−1) = F，g(0) = U。我们的主要设置假设至多一个匹配假设，Σi mi ≤ 1，因此r(A, C) ∈ {−1,0,+1}。多个匹配或相互矛盾的假设需要额外的聚合规则，这超出了本工作的范围。图1展示了该假说。

4 模型究竟能否解决否定？

我们首先评估LLM能否解决受控NLI设置并表现出极性组合假说预测的行为（§3）。在本节中，该评估分三个阶段进行：我们在固定事件匹配下分离极性比较（§4.1），测试事件匹配是否门控该比较（§4.2），并在完整的多事件设置中评估假设选择（§4.3）。

我们评估Qwen3-8B（Qwen团队，2025）和Phi-4 Mini Instruct（Microsoft等，2025），在表格中缩写为Phi-4 Mini。我们在以下三个测试上评估了七个类似规模的开源权重模型（附录C.4，表9）。三个模型在所有测试上超过85%的准确率：Qwen3-8B、Phi-4 Mini Instruct和Gemma 3 12B。我们在前两个模型上运行完整的逐层分析，这是我们计算预算的极限。其他四个模型在不匹配事件上低于60%，因此该任务在此规模上并非微不足道。所有提示遵循图2；前两个实验使用一个假设事件，第三个使用三个。我们提取单标签"T"、"F"和"U"的下一词元logits并取其argmax；不生成自由格式文本。

我们使用R = logit(T)−logit(F)来衡量T/F偏好的方向：R > 0偏向T，而R < 0偏向F。我们使用GU = logit(U)−max{logit(T),logit(F)}来衡量对不确定性的偏好：GU > 0偏向U，而GU < 0偏向极化的T/F决策。每个实验从附录B词汇表中采样的1,000个SVO事件开始；提示数量不同，因为每个实验以不同的设计扩展这些事件（附录C）。结果在三个独立生成的集合上取平均。否定极性使用did not；§6测试替代形式。

4.2 匹配作为极性门控

我们接下来测试事件匹配是否决定极性是否影响输出。我们比较完整SVO一致与部分和完全不匹配在四种极性组合上的表现（20,000个提示）。如果匹配门控基于极性的推理，完整匹配应产生GU < 0，而不匹配应产生GU > 0。

最后，我们测试模型是否使用匹配假设的极性而非干扰项的极性。每个提示包含一个匹配假设（目标）和两个干扰项，目标位置和极性平衡（18,000个提示）。我们在目标或干扰项上添加或移除否定，并测量R的相应变化。如果模型选择匹配假设，修改目标极性时R应显著变化，而修改干扰项时R应几乎不变。

5 极性组合的因果性

行为结果（§4）与公式1中的极性组合假说一致，这验证了假说与实际模型行为之间的正相关。我们现在测试§3中定义的四个变量：假设极性pi、声明极性pc、相对极性ρi和事件匹配mi是否与因果有效子空间对齐。我们首先识别和定位单个变量（§5.2），测试匹配和关系子空间是否联合控制输出（§5.3），最后检查关系表示是否跨匹配上下文迁移（§5.4）。

5.1 实验设置

分布式对齐搜索 我们使用DAS（Geiger等，2024）将每个高层变量与模型内部表示的子空间对齐。每次干预将提供周围上下文的基提示b与提供目标变量预期值的源提示s配对。在选定的层和词元位置，令h(b), h(s) ∈ Rd分别表示未修改模型为基提示和源提示产生的隐藏状态。图4说明了ρi的干预。

对于目标变量v，令Bv ∈ Rd×k为k维学习子空间的正交基。DAS对基表示进行干预：

h̃(b) = h(b) + Bv Bv⊤ (h(s) − h(b)), (2)

令h(x)v = Bv Bv⊤ h(x)且h(x)rest = h(x) − h(x)v，此更新变为h̃(b) = h(b)rest + h(s)v：源分量替换基分量，同时保留基的剩余部分。语言模型保持冻结；仅优化Bv。

我们对每个子空间使用AdamW优化一个epoch，学习率为2×10−3，两个模型的秩均为k = 64³。我们在每隔一层学习一个单独的子空间，并在两个词元位置评估：声明的最后一个词元（声明末尾）和"Answer:"之后的词元（答案词元）⁴。层索引按模型深度归一化。

6 鲁棒性

我们评估在受控设置中识别的行为和因果结构是否跨否定形式泛化并泛化到自然NLI示例。所有因果评估重用§5中识别的DAS子空间。没有在鲁棒性数据上重新训练任何旋转。答案词元和变量特定的结果在附录F中提供。

6.1 对否定形式的鲁棒性

除了规范的did not之外，我们测试相同的计算是否泛化到didn't、never、did not ever、failed to和it is not the case that。在此使用的开门设置（mi = 1）中，冻结的ρi子空间跨形式强烈迁移：确证性IIA在形式内至少为96.8%，从did not到替代形式至少为98.3%。其状态内迁移比Phi-4 Mini Instruct的端到端行为更稳定（附录F）。由于子空间仅在did not上学习，这种迁移表明ρi对齐状态不依赖于否定的表面形式，包括不包含否定词的failed to。

7 讨论

我们的结果表明一种分阶段计算。原始极性在其被读取的位置附近最可识别，而匹配状态和相对极性在后期保持因果有效。联合干预表明学习到的匹配和关系子空间在声明末尾位置相互作用。这里，匹配指的是精确的SVO同一性，用平衡的部分和无重叠控制进行测试。这种相互作用支持所提出的门控结构，但未识别其确切的神经操作。

我们对ρi的结论在门开启且假设事件与声明匹配时最强。在此设置中，相对极性对齐是可识别的、因果有效的，并与匹配子空间相互作用。当门关闭时，mi已经确定输出为U，而不管ρi如何。因此，模型不需要使用相对极性值，其输出也不揭示这样的值是否或如何被表示。一致地，学习到的ρi对齐在匹配状态之间不可靠迁移。因此，ρi可能仅为匹配事件形成，或在无事件匹配时以不同方式表示或解释；我们的实验不区分这些可能性。

跨否定形式和MNLI子集，冻结的ρi对齐比模型的端到端行为更可靠地迁移。在MNLI上，开启匹配门（U→极化）比关闭它更弱，表明事件匹配可能是自然迁移中的重要瓶颈。

8 结论

我们提出并因果测试了极性组合假说，以解释LLM在否定下解决NLI时的内部机制，其中事件匹配门控相对极性。DAS识别出事件匹配和相对极性子空间，其联合干预比任一单独干预更可靠地恢复严格的门开启目标。相对极性子空间持续到答案并跨否定结构迁移，并部分迁移到MNLI，但其行为在匹配状态之间不可靠互换。这些结果支持门控极性一致性，但未确立上下文不变的关系代码或完整的自然逻辑实现。

局限性

我们的受控语法涵盖简单的英语SVO事件，并假设至多一个匹配假设。对于量化主语，如"No one visited PlaceA"与"John visited PlaceA"，内容不同，假说返回UNKNOWN，尽管正确标签是FALSE；此类量化否定和否定一致语言超出了本设计。DAS识别因果有效的低秩方向，而非唯一的内在变量，跨状态结果表明其干预语义可能依赖于上下文。MNLI评估使用精选子集，我们仅研究两个模型。

在单匹配设计下，ρi在门开启时与T/F方向对齐，而mi与极化与U的区分对齐。我们的控制将这些通道与原始极性和直接源标签复制区分开来，但不能唯一排除所有下游决策对齐的表示。

D.4 ρi控制

ρi混合物为flip_pi、flip_pc、hold_both和source_m0各占20%，gate_m0和label_copy_trap各占10%。在开基门下，改变pi或pc任一都会反转ρi并必须反转T/F输出。改变两者保留ρi并必须保留输出。这三个状态内条件将ρi与任一原始极性区分开来。

source_m0条件使用带有相反标注ρi的闭门源。它仍然是训练混合物的一部分，但我们将其视为跨状态诊断而非同一性控制。第5.4节中的因子审计表明，当标注的ρi值不变时，跨状态迁移也可以反转预测。因此我们将source_m0从确证性IIA和NEx中排除。

D.5 匹配控制
