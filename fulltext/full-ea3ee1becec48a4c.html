摘要

本文提出了一种用于摩擦接触的光滑解析梯度，并将其应用于足式运动的策略学习和接触隐式轨迹优化。精确的接触灵敏度具有闭式解，但仅描述当前接触模式内的变化，不提供指向相邻接触模式的一阶信息。所提出的梯度仅在反向传播中替换该灵敏度，保持硬接触前向求解不变，并使实际滚动保持可行。对经de Saxcé修正的库仑摩擦二阶锥互补问题进行中心路径松弛，平滑了定义分离、夹持和滑动模式的条件。松弛灵敏度在由硬接触解初始化的牛顿迭代所获得的中心路径上的点处进行评估。该灵敏度在接触模式转换中保持连续，并在松弛消失时收敛到精确灵敏度。使用100,000个样本和在台式PC上不到2分钟的训练，采用所提出梯度的策略学习产生的策略无需微调即可迁移到硬件。在硬件上，采用小跑策略的机器人能够承受推撞并穿越碎石和湿滑地面。在轨迹优化中，所提出的梯度达到了精确梯度和Signorini松弛梯度所遗漏的富接触解。项目页面：https://diffcontact.github.io

关键词：可微仿真、摩擦接触、二阶锥互补、接触隐式轨迹优化、解析策略梯度、四足运动。

I 引言

在可微物理仿真器中，穿越接触的一阶梯度为接触丰富机器人控制中的两类方法提供了共同的计算原语。第一类是策略学习，其中无模型强化学习被广泛使用，策略梯度估计通过数千个并行环境的滚动计算[1,2,3]。一阶策略学习[4,5]保持相同的目标，但用通常方差更低的一阶估计[8]替换评分函数（REINFORCE）估计[6,7]。该估计可以通过对仿真器求导获得，用更少的样本学习到相当的策略[9]。

第二类是轨迹优化。接触隐式轨迹优化（CITO）方法在没有预定接触模式序列的情况下确定何时何地建立和断开接触[10,11,12]。基于打靶法的DDP/iLQR方法[13,14]使用与策略学习估计器相同的转移雅可比矩阵，并已在线应用于接触丰富运动的滚动时域控制[15]。

对于足式机器人，这两种工具都受到可微仿真所提供的接触灵敏度的限制。仿真器可以是可微的，但不提供指向相邻接触模式的有用一阶方向[16,17]。精确的接触灵敏度具有闭式解[18,19]，但它是在活动集（即接触模式分配）固定的情况下评估的，因此仅描述当前模式内的响应。夹持接触被线性化为保持夹持，不提供指向起飞或滑动的一阶信息，并且当活动集改变时灵敏度会发生不连续变化。在接触隐式优化中，这种模式受限的灵敏度使局部搜索保持在标称轨迹的接触序列附近[15,18,20]。在一阶策略学习中，相同的雅可比矩阵进入时间反向传播（BPTT），在接触丰富的系统中可能产生脆弱或无效的优化[16,17,21,22]。

先前的工作以不同的方式解决策略学习和CITO中的接触灵敏度问题。在策略学习中，方法包括缩短求导时域[9,22]、在反向传播中使用降阶模型[23]、或在正向滚动中平滑接触[24]。较短的时域可以帮助解决长时域梯度不稳定问题，但不改变每个窗口内的接触灵敏度。在CITO中，转录方法将接触冲量与轨迹一起优化[11,12,25]，而打靶方法依赖来自接触动力学的转移雅可比矩阵[13,14,15]。其他方法平滑前向接触模型[26,20]、对松弛接触解求导[27,28]、或通过扰动求解估计梯度[29,30]。然而，对于具有硬接触前向求解的基于打靶法的CITO，精确的接触灵敏度仍然与当前接触模式绑定，对向不同模式的转变仅提供有限的一阶指导[18]。在求导期间仅松弛Signorini条件[15]通过提供接触建立/断开转换的方向部分解决了这一限制，但未解决滑动和法向-切向耦合问题。

因此，我们提出一种仅在反向传播中松弛完整摩擦接触条件而获得的接触灵敏度，在保持硬接触前向求解的同时提供指向相邻接触模式的搜索方向。de Saxcé修正将摩擦接触表示为单个二阶锥互补条件[31,32]。沿中心路径[33]松弛该条件，在分离、夹持和滑动之间耦合法向和切向接触灵敏度。这些耦合灵敏度在每个接触模式中均可用，允许优化器通过基于梯度的更新改变模式。我们进一步研究它们在引导向滑动转换中的作用，其中仅法向松弛缺乏所需的切向信息。

我们使用四足机器人在两种最优控制设置中测试该灵敏度的效果：一阶策略学习和接触隐式轨迹优化。在每个设置中，我们比较精确[19]、Signorini松弛[15]和所提出的灵敏度，同时保持前向接触模型、目标和初始化固定。策略学习实验探究单环境BPTT是否可以产生直接迁移到硬件的运动策略。轨迹优化实验探究所提出的灵敏度是否通过启用接触模式变化和足部重新定位来改善富接触运动生成及从未建模外拉中的恢复。

主要贡献如下：

• 一种解析反向接触灵敏度，沿其中心路径松弛完整的de Saxcé修正摩擦接触定律，同时保持硬接触前向求解。它在每个接触模式下提供指向分离、滑动和夹持的一阶方向，并在松弛消失时恢复精确灵敏度。

• 所提出的梯度在基于BPTT的一阶策略学习和接触隐式轨迹优化中引导接触模式变化，产生改进的策略和更低成本的富接触轨迹。

• 使用所提出梯度进行四足策略学习的硬件演示，涵盖小跑、侧对步和无步态运动。使用100,000个样本在2分钟内获得的小跑策略在硬件上无需微调进行测试，经受了推撞、碎石和低摩擦表面的考验。

本文的其余部分结构如下。第II节回顾相关工作，第III节介绍最优控制和接触动力学背景。第IV节阐述所需的接触灵敏度，第V节推导所提出的梯度，第VI节介绍实现细节。第VII和VIII节介绍策略学习和轨迹优化演示，第IX节进行总结。

II 相关工作

II-A 接触仿真与可微接触

前向模型。 刚性摩擦接触通常使用三个耦合原理建模[32,34]：Signorini条件、库仑摩擦锥约束和Moreau最大耗散原理（MDP）[35]。它们的组合产生关于接触冲量的非光滑非线性互补问题，在每个时间步使用迭代方法求解，如投影Gauss–Seidel法和交错投影法[32]。线性互补（LCP）模型将摩擦锥多边形化，允许使用主元方法[36]。凸锥互补（CCP）模型松弛严格的Signorini互补性以获得凸接触问题。在滑动期间，这可以允许非零法向力与分离法向速度共存，导致人工法向运动，并且在时间步进仿真中出现跨间隙的力[32]。MuJoCo采用相关的凸软接触公式[37]。柔顺模型使用有限接触刚度和耗散；通过适当的正则化，凸公式也可以处理近刚性接触[38]。

在本工作中，CITO中的硬接触前向模型保持刚性非线性互补问题的三个原理。我们使用逐接触迭代[34]，通过结合de Saxcé修正的二分法求解滑动接触子问题[39]。对于BPTT策略学习，我们改用RaiSim[34]进行高效的前向滚动，因为训练需要以精细时间步长进行重复仿真。这也允许我们在相同的仿真环境中比较BPTT与PPO，尽管标准RaiSim在滑动期间可能偏离最大耗散[39]。在这两种设置中，我们都从刚性摩擦接触定律的de Saxcé表示推导接触梯度[31,40]。

接触求导。 有限差分通过用扰动输入重复评估来估计接触灵敏度，评估次数随输入维度增长[37,13]。在接触模式转换附近，估计值可能取决于扰动大小。自动微分则对仿真器执行的操作应用链式法则[41,17,5]。解析方法可以将刚体算法的导数[42,43]与收敛接触解处接触方程的隐式求导相结合[18,19,44]。所提出的方法遵循这种解析方法，但在摩擦接触条件的松弛中心路径点评估灵敏度。

II-B 用于策略学习的可微仿真

无模型强化学习（RL）广泛用于足式运动。评分函数策略梯度方法不需要仿真器的导数[45]，大规模并行仿真加速了大批量样本的收集以进行稳定的策略更新[2]。这种方法已经产生了硬件运动[1,46,47,48]和示例引导的运动技能[49]。一阶策略学习则对滚动动力学求导以估计策略梯度[5,17]，可以提高样本效率[9,50]。相关的基于模型的RL方法对学习到的世界模型而非物理仿真器求导[4,51]；DayDreamer将这种方法应用于四足硬件学习[52]。

通过长展开动力学的一阶估计可能不稳定或不如零阶估计有效，特别是在刚性或非光滑动力学下[16,21]。为了缓解这些困难，SHAC[9]将一阶估计与短时域演员-评论家训练相结合，AHAC[22]自适应调整求导时域以避免刚性接触动力学。对于没有接触转换的系统，可微飞行模型支持四旋翼策略训练和硬件迁移[50,53]。富接触运动还要求反向传播遍历分离、夹持和滑动接触之间的重复变化。

最近的运动方法以不同的方式修改用于求导的动力学以获得信息丰富的接触梯度。Schwarke等人[24]用距离相关的sigmoid缩放平滑接触激活，并使用自动微分对得到的仿真求导。这改善了梯度信息量，但也修改了前向接触动力学。Song等人[23]保留Isaac Gym进行前向仿真，同时通过依赖于预定步态时间表的状态对齐单刚体替代模型计算梯度。两种方法都演示了硬件迁移，分别使用128和64个并行仿真环境训练的策略。本工作则使用铰接式硬接触仿真器进行前向滚动，并对其摩擦接触灵敏度进行仅反向的松弛，没有降阶替代模型或平滑的前向动力学。此外，我们证明每次更新单次滚动足以让采用所提出梯度的BPTT学习直接迁移到硬件的运动策略。

II-C 接触隐式轨迹优化

接触隐式轨迹优化（CITO）联合确定接触时机和位置以及状态和控制轨迹。早期公式包括接触不变优化[10]和通过互补约束编码接触激活和分离的公式[54,11]。得到的数学规划必须求解嵌入这些约束中的离散接触模式结构。

CITO方法在处理接触定律的位置上有所不同。直接转录法将接触力或冲量纳入轨迹决策变量[11]；相关公式将质心动力学与完整运动学相结合[55]，或使用正交配置[56]和变分积分[12]。基于共识的算法将轨迹范围的动力学约束与每步接触约束分离，并通过ADMM协调子问题[57,58]。基于相位的公式则通过支撑和摆动持续时间优化接触时机[59,60]。

基于打靶法的方法在每个仿真步内求解接触，并向轨迹优化器提供转移雅可比矩阵[13,61,62]。当在固定活动集内计算时，硬接触灵敏度对接触模式变化只能提供有限的指导[18]。

平滑的接触灵敏度可以通过修改接触模型或其求导方式来获得。柔顺和障碍平滑模型在规划模型中替换硬接触，可能引入超距力或相互穿透[13,14,26]。局部平滑解析地或通过对扰动取平均来正则化接触映射[20,29,30]；基于采样的变体需要多次扰动求解。内点方法在非零中心路径参数处对松弛系统求导[27,28]；求导点是前向求解器的中间迭代，因此其松弛水平与求解器访问的值绑定，梯度在该求解器内部获得。

在求导期间仅松弛Signorini条件[15,63]将松弛点与前向求解分离，后者保持硬接触。然而，摩擦锥保持未松弛，因此夹持接触没有指向滑动的切向方向。所提出的梯度则将中心路径松弛应用于完整的de Saxcé修正摩擦锥，从而在分离、夹持和滑动接触之间耦合法向和切向灵敏度。其评估点不是前向求解的副产品，而是通过从硬接触解出发的单独牛顿迭代计算，因此可以为反向传播单独选择松弛参数。

III 背景

基于打靶法的轨迹优化和基于BPTT的策略学习在反向递归中使用转移雅可比矩阵 (f_x, f_u)。通过接触形成这些雅可比矩阵需要接触冲量灵敏度 ∂λ/∂(A,b)。本节回顾两种最优控制公式和求解接触的前向动力学，并推导每种接触模式的解析接触冲量灵敏度。还回顾了所提出梯度计算所使用的摩擦接触二阶锥互补问题（SOCCP）公式。

III-A 最优控制公式

以状态 x、控制输入 u 和离散时间动力学 x_{t+1} = f(x_t, u_t)，轨迹优化和一阶策略学习可以表述为以下形式的有限时域最优控制问题：

min_ξ E_{x_0∼p_0}[ Σ_{t=0}^{H-1} ℓ_t(x_t, u_t) + ℓ_H(x_H) ] (1)
s.t. x_{t+1} = f(x_t, u_t), u_t = u_t(ξ; x_t),

其中决策变量 ξ 通过 u_t(ξ; x_t) 确定控制，ℓ_t 和 ℓ_H 为运行代价和终端代价，p_0 为初始状态分布。两种设置在 ξ、p_0、时域和求解器的选择上有所不同。两者都依赖转移雅可比矩阵 f_x := ∂x_{t+1}/∂x_t 和 f_u := ∂x_{t+1}/∂u_t。

全文中，d(·) 表示关于任意扰动的全微分，d(·)/dη 表示关于参数 η 的相应全导数（灵敏度），∂(·)/∂(·) 表示其余参数固定时的偏导数，∇ 表示标量函数的梯度。

轨迹优化（基于打靶法的DDP/iLQR）。 这里决策变量是从固定初始状态 x_0 出发的开环控制序列 ξ = u_{0:H-1}。微分动态规划[64,13]是一种打靶法，通过交替进行 f 的显式前向滚动和从Bellman最优性原理导出的反向Riccati扫描来求解(1)。扫描形成状态-控制值函数 Q 的局部二次近似，其导数结合代价 ℓ 的导数、转移雅可比矩阵 (f_x, f_u) 和下一步值函数导数 (V'x, V'{xx})。迭代线性二次调节器（iLQR/iLQG）使用省略二阶动力学项的Gauss–Newton近似[65,13]。在该近似下：

Q_x = ℓ_x + f_x^⊤ V'x, Q_xx = ℓ_xx + f_x^⊤ V'{xx} f_x, (2)

Q_u、Q_uu、Q_ux 类似地形成。在控制增量上最小化局部二次模型得到前馈和反馈增益，其回代更新前一步的成本并携带扫描回到 t=0。其可行性驱动的多重打靶变体（FDDP）[66]允许不可行的状态-控制初始化并在迭代过程中闭合动力学间隙，在不良初始化下扩大了吸引域。

策略学习（一阶，通过BPTT）。 这里决策变量是反馈策略 u_t = π_θ(x_t) 的策略参数 ξ = θ，初始状态从 x_0 ∼ p_0 采样。对于长度为 H 的截断滚动，有限时域损失为 L(θ) = E_{x_0∼p_0} Σ_{t=0}^{H-1} ℓ_t。可以加入学习到的值函数作为终端项以自举剩余回报，如SHAC[9]等演员-评论家变体。L 的梯度通过沿闭环滚动的时间反向传播（BPTT）[67]获得。令 π_{x,t} := ∂π_θ(x_t)/∂x_t，状态和动作梯度遵循以下反向递归：

∇{x_t}L = ℓ{x,t} + π_{x,t}^⊤ ℓ_{u,t} + (f_x + f_u π_{x,t})^⊤ ∇{x{t+1}}L, (3)
∇{u_t}L = ℓ{u,t} + f_u^⊤ ∇{x{t+1}}L.

第一个递归通过闭环雅可比矩阵 f_x + f_u π_{x,t} 向后传播未来损失，而第二个给出滚动损失对每步动作的灵敏度。参数梯度随后为 ∇θL = E{x_0∼p_0} Σ_t (∂π_θ(x_t)/∂θ)^⊤ ∇_{u_t}L。在实践中，反向模式自动微分使用可微仿真器在每步提供的转移雅可比矩阵 f_x 和 f_u 在展开的滚动上累积该递归[41,17]。

与强化学习的关系。 无模型强化学习（RL）则优化随机策略的期望回报，并通过评分函数（似然比）规则估计其梯度：∇θJ = E{τ∼π_θ}[R(τ)∇_θ log p(τ;θ)] [6,7]，其中 τ 为采样轨迹。这种零阶估计器不需要动力学导数，可应用于非光滑甚至不连续的动力学，策略随机性提供目标的随机平滑[68,16]，代价是高方差[8,69]。相比之下，上述一阶梯度方差更低且样本效率更高[4,9]，但非光滑和近刚性接触可能产生退化或病态的梯度[16,21]。

III-B 动力学模型与摩擦接触问题

足式机器人通过间歇性摩擦接触与环境交互，此处用接触冲量建模。其状态由构型 q ∈ Q ≅ R^{n_q} 和广义速度 v ∈ T_qQ ≅ R^{n_v} 描述，其中 T_qQ 表示 q 处的切空间。动力学在速度层面使用时间步进方案[35,70]积分，采用步长为 Δt 的半隐式Euler步：

M(q)(v⁺ − v) = (S^⊤u − h(q,v))Δt + J_c(q)^⊤λ,

其中对称正定关节空间惯性 M ≻ 0，非线性（科里奥利、离心和重力）项为 h，驱动选择器为 S，控制输入（关节力矩）为 u，接触雅可比矩阵 J_c: T_qQ → R^{3n_c} 将广义速度映射到 n_c 个接触点的速度；λ ∈ R^{3n_c} 在该步上堆叠接触冲量。

求解下一步速度 v⁺ 将其分解为自由速度 v_free 和接触贡献：

v⁺ = v_free + M⁻¹J_c^⊤λ, v_free := v + M⁻¹(S^⊤u − h)Δt. (4)

将(4)映射到接触坐标系给出接触空间关系：

σ = Aλ + b, A := J_c M⁻¹ J_c^⊤ ⪰ 0, b := J_c v_free,

其中 σ 为接触速度，A 为Delassus矩阵（接触空间逆惯性），b 为自由接触项。为抑制接触漂移，b 的法向分量通过位置级校正 φ(q_t)/Δt 增强，其中 φ(q_t) 为带符号法向间隙，分离时为正。因此，σ_N = J_N v⁺ + φ(q_t)/Δt，其中 J_N 表示 J_c 的法向行，Δt σ_N 近似下一步的带符号间隙。

对于单个接触，去掉索引 i 并写 (λ, σ) ∈ R³×R³，具有Delassus对 (A, b)，摩擦点接触由三个原理控制[70,35,32]。Signorini条件将接触单侧性表示为：

0 ≤ σ_N ⊥ λ_N ≥ 0.

库仑定律将冲量限制在摩擦锥内：

λ ∈ K_μ := {(λ_N, λ_T) ∈ R×R² : ‖λ_T‖ ≤ μλ_N},

而最大耗散原理（MDP）选择最大化耗散功率的可行摩擦冲量：

λ_T ∈ argmax_{‖γ‖≤μλ_N}(−σ_T^⊤γ).

对于滑动接触（σ_T ≠ 0），MDP给出 λ_T = −μλ_N σ̂_T，其中 σ̂_T := σ_T/‖σ_T‖。这些条件定义以下接触模式[32]：

{ λ = 0, σ_N > 0, （分离），
σ = 0, λ ∈ int K_μ, （夹持），
σ_N = 0, λ_T = −μλ_N σ̂_T, （滑动）。 } (5)

分离模式不携带接触冲量，夹持模式对应于具有摩擦锥内部冲量的粘附，滑动模式将冲量置于锥边界 ‖λ_T‖ = μλ_N。活动模式由解 (λ, σ) 而非先验确定，由此产生接触问题的组合结构。

III-C de Saxcé SOCCP及其Jordan代数形式

Signorini条件、库仑摩擦锥和MDP可以使用de Saxcé修正[31,40]重新表述为单个锥互补条件。修正项 Γ_μ(σ) = (μ‖σ_T‖, 0, 0)^⊤ 通过MDP规定的耗散偏移法向速度：

K_μ ∋ λ ⊥ σ + Γ_μ(σ) ∈ K_μ^, K_μ^ = K_{1/μ}. (6)

正交性"⊥"包含三个耦合条件：原始可行性 λ ∈ K_μ，对偶可行性 σ + Γ_μ(σ) ∈ K_μ^*，以及互补性 λ^⊤(σ + Γ_μ(σ)) = 0。该互补条件对(5)中的三种接触模式均成立[32]。对于分离和夹持接触，分别由 λ = 0 和 σ = 0 得出。对于滑动接触，σ_N = 0 和MDP关系 λ_T = −μλ_N σ̂_T 给出 λ_T^⊤σ_T = −μλ_N‖σ_T‖。该项抵消了来自de Saxcé修正的贡献 μλ_N‖σ_T‖，因此 λ^⊤(σ + Γ_μ(σ)) = 0。

为了将此互补性转化为标准二阶锥求解器所使用的形式，摩擦的内点法处理[33]通过自对偶锥的Jordan代数重写它。这需要自对偶（对称）锥 K = K^*，而摩擦锥仅在单位摩擦时自对偶；因此我们应用标准的单位摩擦重缩放[33]：

λ̃ := (μλ_N; λ_T), σ̃ := (σ_N/μ + ‖σ_T‖; σ_T). (7)

这将 λ ∈ K_μ 和 σ + Γ_μ(σ) ∈ K_μ^ 映射到自对偶二阶锥 K = {(w_0, w̄) ∈ R×R² : ‖w̄‖ ≤ w_0} = K^，即 λ̃, σ̃ ∈ K，同时保持原始-对偶配对 λ̃^⊤σ̃ = λ^⊤(σ + Γ_μ(σ))。对于 λ̃, σ̃ ∈ K，标量互补条件可以等价地通过Jordan积表示[71,33]：λ̃^⊤σ̃ = 0 ⟺ λ̃∘σ̃ = 0，其中 ∘ 表示 K 上的Jordan积（附录A）。de Saxcé条件(6)因此成为二阶锥互补问题（SOCCP）：

σ = Aλ + b（仿射映射）， λ̃, σ̃ ∈ K（原始/对偶可行性）， λ̃∘σ̃ = 0（互补性）， (8)

其三个解分支即(5)的分离、夹持和滑动模式，可以通过基于Jordan的内点法和路径跟踪方法求解[33]。

III-D 接触冲量灵敏度

接触冲量 λ 由Delassus对 (A, b) 和(5)中的接触条件隐式确定。对这些条件与 σ = Aλ + b 一起求导，同时保持接触模式固定，给出每种模式的独立灵敏度[18,19]。对于给定的变化 dA 和 db，相应的 dλ 如下获得。

分离。 在分离模式内，接触冲量保持为零，因此

dλ = 0. (9)

夹持。 夹持条件为 σ = Aλ + b = 0。对该条件求导给出

A dλ = −((dA)λ + db), (10)

因此 dλ = −A⁻¹((dA)λ + db)。

滑动。 在滑动模式中，Signorini条件给出 σ_N = 0，而最大耗散原理施加 λ_T = −μλ_N σ̂_T。按照[19, App. A]，对 σ = Aλ + b 求导给出 dσ = A dλ + (dA)λ + db，因此法向条件给出 A_N dλ = −((dA)λ + db)_N。通过 σ̂_T 对MDP关系求导给出 K dλ = −(1/α)P dσ_T，其中 K := [μσ̂_T I₂]，P := I₂ − σ̂_Tσ̂_T^⊤，α := ‖σ_T‖/(μλ_N)。利用 dσ_T = A_T dλ + ((dA)λ + db)_T 消去 dσ_T 得到

σ_N = 0: A_N dλ = −((dA)λ + db)_N,
MDP: (1/α P A_T + K) dλ = −1/α P((dA)λ + db)_T. (11)

这里，A_N 和 A_T 表示 A 的法向行和切向行。两个条件构成关于 dλ ∈ R³ 的 3×3 线性系统。

对于多个接触，模式特定条件组装成单个线性系统。分离接触满足 dλ = 0 并从简化系统中省略，而夹持和滑动方程为其余接触堆叠。非对角Delassus块 A^{ij} 耦合接触灵敏度，单次线性求解即可得到其余接触冲量的变化[18,15,19]。由于求导是在接触模式分配固定的情况下进行的，灵敏度在 (A, b) 上分段定义，每种模式分配有不同的表达式。

IV 问题设置

在本节中，我们研究接触灵敏度必须捕捉什么，才能引导接触模式之间转换附近的一阶优化。我们使用点质量示例研究摩擦接触条件的不同松弛如何影响可用的优化方向。

IV-A 对反向接触梯度的要求

精确接触灵敏度对于需要接触模式转换的一阶更新可能缺乏信息[18,30]；因此即使另一种模式会降低目标函数，优化器也可能被限制在当前接触模式内。灵敏度是通过对前向求解所选择的模式的接触约束求导获得的；因此它仅描述保持该模式的扰动。对于损失 ℓ，通过接触点运动对其导数的贡献可写为 (∂ℓ/∂σ)(dσ/dη)，其中 σ 表示接触点速度。第一个因子度量损失对接触点运动的灵敏度，而 dσ/dη 由接触灵敏度确定。限制来自后一项。在夹持接触处，模式约束施加 σ = 0，在固定模式内求导给出 dσ/dη = 0。因此，即使这种运动会降低目标函数，通过接触点运动传递的损失导数也为零。类似的限制出现在其他接触模式中。在分离接触处，λ = 0 给出 dλ/dη = 0；在滑动接触处，σ_N = 0 和求导后的MDP将灵敏度约束到滑动分支。

V-A 中心路径松弛与统一接触灵敏度

de Saxcé修正的锥互补性 λ̃∘σ̃ = 0 沿中心路径松弛，如同在将摩擦接触表述为SOCCP的原始-对偶内点法中那样[33]：

λ̃∘σ̃ = ρe, ρ > 0, e = [1, 0^⊤]^⊤, (12)

这将 λ̃ 和 σ̃ 都置于 int K 中。我们直接对该内部关系求导，在不区分分离、夹持和滑动模式的情况下推导接触灵敏度。

在固定 ρ 处，使用Jordan积表示对(12)求导给出

L(σ̃) dλ̃ + L(λ̃) dσ̃ = 0, (13)

其中 L(·) 为Jordan积箭头矩阵（附录A）[71]。对于缩放后的冲量：

L(λ̃) = [μλ_N λ_T^⊤; λ_T μλ_N I₂],

L(σ̃) 类似定义。由 λ̃ = [μλ_N, λ_T^⊤]^⊤ 和 σ̃ = [σ_N/μ + ‖σ_T‖, σ_T^⊤]^⊤，对这些缩放求导给出 dλ̃ = C dλ 和 dσ̃ = D(σ) dσ，其中

C = [μ 0^⊤; 0 I₂], D(σ) = [1/μ σ_T^⊤/‖σ_T‖; 0 I₂].

将这些微分代入(13)给出

M_λ dλ + M_σ dσ = 0, M_λ := L(σ̃)C, M_σ := L(λ̃)D(σ), (14)

其中 M_λ 和 M_σ 的显式块形式如下给出。

利用 L(·)、C 和 D(σ) 的定义，直接相乘 M_λ = L(σ̃)C 和 M_σ = L(λ̃)D(σ) 得到：

M_σ = [λ_N | μλ_N σ_T^⊤/‖σ_T‖ + λ_T^⊤ ; λ_T/μ | λ_T σ_T^⊤/‖σ_T‖ + μλ_N I₂],

和

M_λ = [σ_N + μ‖σ_T‖ | σ_T^⊤ ; μσ_T | (σ_N/μ + ‖σ_T‖)I₂].

与求导后的Delassus关系 dσ = A dλ + (dA)λ + db 结合，得到统一灵敏度方程：

(M_λ + M_σ A) dλ = −M_σ((dA)λ + db). (15)

例如，对于单个接触，关于变量 η 的灵敏度为

∂λ/∂η = −(M_λ + M_σ A)⁻¹ M_σ (∂A/∂η λ + ∂b/∂η).

对于 n_c 个接触，M_λ 和 M_σ 的每接触 3×3 块组装成相应的 3n_c 维系统，联合求解接触冲量灵敏度。取 η 为 x 或 u 的分量即可提供用于计算 f_x 和 f_u 的接触灵敏度。

V-B 在 ρ > 0 处评估灵敏度

我们在满足Delassus关系 σ = Aλ + b 和松弛互补性 λ̃∘σ̃ = ρe（ρ > 0）的松弛对 (λ^⋆, σ^⋆) 处评估(15)中的灵敏度，而非在硬接触对处评估。评估点的这一变化也改变了对线性化接触响应所施加的约束。在 ρ = 0 处，硬接触对满足刚性互补性并位于锥的模式相关边界上。在接触模式固定下的求导强制执行(5)中的条件；例如，夹持中 dσ = 0，分离中 dλ = 0。因此，精确灵敏度不提供指向当前接触模式变化的一阶方向。对于 ρ > 0，物理中心路径分支上的松弛对满足 (λ̃^⋆, σ̃^⋆) ∈ int K × int K。其线性化由统一系统(15)而非硬接触模式条件控制，因此相应的灵敏度分量可以非零。

图2说明了夹持、分离和滑动接触的评估点几何。在硬接触根处，夹持中 σ̃_h = 0，分离中 λ̃_h = 0，而在滑动中两个变量都非零且位于各自的锥边界上。随着 ρ 从零增加，松弛点离开其硬接触根并移入各自的锥内部。图3显示了具有对角 A 和非零 b_T 的单接触模型在 b_N 扫过三种接触模式时的灵敏度。对于精确灵敏度，切向冲量和接触速度导数在夹持和分离中为零，法向接触速度导数在夹持和滑动中为零。这些导数在接触模式边界处发生不连续变化。对于 ρ > 0，所提出的曲线在所绘制的接触模式转换中连续变化，且被精确接触模式约束为零的分量变为非零；特别是，全锥耦合对法向扰动（如本例中的 db_N）产生非零切向灵敏度。由重复的零阶和一阶随机平滑估计获得的经验均值在该扫描中显示相同的定性特征[16,30]，而所提出的灵敏度不需要蒙特卡罗采样。

松弛评估点由在前向传递返回的硬接触解 (λ_h, σ_h) 处初始化的牛顿迭代计算，同时保持相关的Delassus对 (A, b) 固定。为了将松弛互补性与Delassus关系一起表述为仅关于冲量的求根问题，我们将 σ = Aλ + b 代入(12)并定义残差：

F_ρ(λ) := λ̃(λ)∘σ̃(Aλ + b) − ρe. (16)

其雅可比矩阵即(15)中的系统矩阵：

∂F_ρ/∂λ = L(σ̃)C + L(λ̃)D(σ)A = M_λ + M_σ A.

为求解 F_ρ(λ) = 0，我们在第 k 次迭代使用以下带正则化项 β‖F_ρ^{(k)}‖I 的牛顿更新：

(M_λ^{(k)} + M_σ^{(k)}A + β‖F_ρ^{(k)}‖I) Δλ^{(k)} = −F_ρ^{(k)}, (17)
λ^{(k+1)} = λ^{(k)} + Δλ^{(k)},
σ^{(k+1)} = Aλ^{(k+1)} + b,

其中 F_ρ^{(k)} = F_ρ(λ^{(k)})。最后一次更新保持Delassus关系在每个迭代点都满足。收敛后，(λ^⋆, σ^⋆) 同时满足两个关系，并用于评估接触灵敏度的 M_λ 和 M_σ。

项 β‖F_ρ^{(k)}‖I 提供牛顿系统的残差缩放对角正则化，如同非线性方程的正则化牛顿方法[72]；这里 β ≥ 0 为正则化参数。该项在早期牛顿迭代期间正则化线性求解，特别是当硬接触初始化产生病态牛顿矩阵时。例如，对于接近摩擦锥边界的夹持接触，μλ_N − ‖λ_T‖ 变小，L(λ̃) 接近奇异。随着牛顿迭代收敛和残差减小，正则化减弱并在松弛根处消失，恢复未正则化的牛顿系统。算法1总结了该过程。

V-C 法向自由速度偏移

为改善数值条件，我们在牛顿迭代之前对反向自由接触项的法向分量额外应用非负偏移 δ：

b_N ← b_N + δ.

在求导期间 δ 保持固定，该偏移改变牛顿残差和松弛评估对 (λ^⋆, σ^⋆) 而不改变灵敏度系统(15)的形式。对于给定冲量，该偏移向牛顿矩阵添加正对角贡献，可以改善线性求解的条件数。我们观察到启用该偏移时收敛到伪根的比率更低（第VII-D节）。

图4说明了增大 δ 如何将法向灵敏度曲线移向未偏移 b_N 的更负值。在相同 b_N 处，该偏移为硬接触前向解保持夹持的状态提供更大的指向接触释放的法向灵敏度。该灵敏度可以引导轨迹优化趋向涉及起飞的解。

V-D 当 ρ → 0 时固定模式灵敏度的恢复

在极限 ρ → 0⁺ 且 δ = 0 时，中心路径松弛消失，所提出的灵敏度恢复第III-D节中导出的精确固定模式灵敏度。对于分离接触，λ̃ → 0 给出 M_σ → 0 且 M_λ 非奇异，因此极限灵敏度给出 dλ = 0；对于夹持接触，σ̃ → 0 给出 M_λ → 0 且 M_σ 非奇异，因此给出 dσ = 0，等价于 A dλ = −((dA)λ + db)。这些分别恢复(9)和(10)。对于滑动接触，将硬解代入 M_λ 和 M_σ 给出

M_λ → ‖σ_T‖[μ σ̂_T^⊤; μσ̂_T I₂], M_σ → μλ_N[1/μ 0^⊤; −σ̂_T/μ P],

其中 P := I₂ − σ̂_Tσ̂_T^⊤。在 M_λ dλ + M_σ dσ = 0 中，将第一行与后两行沿 σ̂_T 方向的分量结合给出 dσ_N = 0。当 dσ_N = 0 时，后两行简化为 K dλ = −(1/α)P dσ_T，其中 K := [μσ̂_T I₂] 且 α := ‖σ_T‖/(μλ_N)。这些条件与(11)中求导后的Signorini和MDP条件一致，恢复了精确的滑动灵敏度。
