摘要. 基于 Shapley 值的解释被广泛用于机器学习中的特征归因。然而，在计算机视觉中，某个特征在添加到完整真实图像时可能会降低目标类别的得分，即使预测标签保持不变。我们将此类特征形式化为上下文干扰项（contextual distractors），并在半值和最小核框架下研究其归因。在较弱的平均边际单调性假设下，我们推导出定量的半值–最小核差距界，以及基于采样较小上下文概率的充分条件。我们进一步证明，将半值权重向较大上下文转移会减小有符号差距。最后，受控图像分类实验和 Salient ImageNet 上的评估为我们的理论发现提供了强有力的实证支持。

1 引言

可解释 AI 的一个核心目标是理解分类器为何做出特定决策。对于固定输入，这通常等同于识别最能解释预测的特征子集。例如，在图像分类中，人们可能寻找一个小的像素、图像块或分割区域子集，其存在足以在掩蔽下保持预测标签。大小约束很重要：若无此约束，完整图像往往是平凡但无信息量的解释。该问题在计算机视觉中尤其具有挑战性，因为解释必须扩展到高维输入，同时保持有意义。

博弈论方法在此环境中已被证明有用，因为它们提供了推理特征重要性的原则性方法。特别是，Shapley 值 [40] 由于其简洁性和吸引人的公理性质，已成为标准的归因机制。然而，仍存在两个困难。第一个是广受认可的，即计算方面的：精确的 Shapley 值需要在全部 N 个参与者的所有子集上评估特征函数。因此，大量文献专注于近似方法，尤其是基于采样的方案 [45, 34, 18, 1, 25]，以及在特征函数结构假设下的更高效计算 [15, 8]。这些保证在子模性 [3, 4] 和超模性 [31] 等假设下得到进一步改进。然而，此类假设在自然环境中不太可能成立，尤其是在计算机视觉中，因此这些正面保证通常无法扩展到感兴趣的领域。

虽然 Shapley 值的计算挑战已被充分理解，但第二个较少被研究的、更概念性的问题是：在存在虚假上下文线索时，基于平均的归因会产生何种影响。特别是，一组特征可能在平均上看起来有益，尽管它恰恰在对预测最具信息量的上下文中是有害的。例如，在计算机视觉中，背景块、纹理或相关伪影可能使分类器偏向某个标签，而并未捕获实际感兴趣的对象。此外，由此类效应诱导的特征函数不太可能满足子模性/超模性等正则性。图 1 展示了这一效应。

这种现象与计算机视觉中若干著名的"捷径"示例密切相关。在 [38] 中，背景雪可以虚假地驱动狼与哈士奇分类器。在 [5] 中，动物分类器被证明依赖于水等上下文线索而非动物本身。[32] 中的 Waterbirds 基准通过对比水鸟/陆鸟身份与背景来明确这一点，使背景可能主导预测。类似地，[43] 记录了相关上下文（如人与滑板同时出现）可能主导分类器推理的情形。在 [29] 中，解释图揭示模型有时依赖源标签等伪影而非对象本身。

这些例子表明，一组特征在平均上可能看起来有用，但在人们真正关心的重要上下文中仍然有害。这正是 Shapley 值可能通过上下文平均而忽略的行为类型。这一视角促使我们超越纯粹基于平均的归因，转向基于稳定性的概念，例如最小核（least core）[35]，它聚焦于最重要的联盟而非对所有上下文进行平均，这正是本工作所追求的方向。

图 1： 受控标记偏置设置。红色标记被添加到所有狗图像和一部分猫图像，而鸟图像保持无标记。这创建了一个与狗相关联的线索，可能作为猫预测的上下文干扰项。在第 4 节中，我们观察到 Shapley 本质上是对各上下文的贡献取平均，而最小核包含稳定性约束，可以考虑标记对完整真实图像和预测标签的影响。

我们的贡献. 主要贡献如下。

  1. 在第 3.1 节中，我们通过上下文干扰项形式化捷径现象，即在添加到完整真实图像时会降低目标类别得分的特征组，即使预测标签保持不变。

  2. 我们建立了最小核捕获这种有害效应的条件，并在较弱的平均边际单调性假设下推导出定量的半值–最小核差距界。我们进一步刻画了当半值对较大上下文赋予更大权重时差距的变化。

  3. 通过受控图像分类实验和 Salient ImageNet [44] 上的评估，我们比较了各方法对上下文干扰项的归因。我们发现 Shapley 及其他归因方法通常比最小核给干扰项分配更大的重要性，即使真实图像内容已足以进行正确分类。

本工作的早期研讨会版本发表于 ICML 2026 NExT-Game 研讨会 [36]。本文通过发展一般的半值–最小核理论、在较弱假设下推导新的差距条件与权重转移结果，并增加更多实验和评估（包括 Salient ImageNet 上的评估），大幅扩展了该初步版本。

相关工作. 我们的工作与三个方向的文献相关。首先，基于 Shapley 值的解释，以及更广泛的半值方法，如 Data Shapley、Beta Shapley、Data Banzhaf 和加权 Banzhaf，已成为机器学习归因的标准工具，包括通过为视觉 Transformer 定制的 Shapley 估计器应用于计算机视觉 [34, 47, 28, 48, 12]。与这一仍属基于平均的路线不同，我们将半值方法与一种稳定的归因方法——最小核——进行比较。

其次，越来越多的文献研究 Shapley 式解释的局限性，包括其对值函数选择、基线值、遮挡策略或特征分布的依赖性，以及产生误导性特征重要性得分的可能性 [47, 24, 1, 23, 37, 6, 7]。我们的工作通过识别此类失败在视觉类环境中的特定机制——即上下文干扰项的存在——来补充这些批评。

第三，我们的工作与分类器中捷径学习、虚假相关性和基于解释的偏置检测的文献相关 [2]。这些工作记录了模型可能依赖虚假线索，并研究事后解释能否揭示此类行为。我们的贡献在于通过联盟博弈和上下文干扰项的概念将这一现象形式化。此外，我们在理论和经验上展示了基于稳定性的解释何时可能与基于平均的解释产生显著差异。

最近的工作还修改了考虑交互的 Shapley 式归因 [50, 10, 46, 6]，但这些方法仍处于平均范式之内，属于修改的 Shapley 值，而我们的重点是最小核这一替代原则。

最后，关于最小核作为 Shapley 式解释的可行替代方案，[49, 17] 等工作已开发出在大规模博弈中近似求解它的计算方法。在上下文干扰项博弈的设置中，Kera 等人 [26] 研究了如何在实践中计算和选择最小核归因这一互补问题。最近，Li 等人 [30] 研究了超越 Shapley 的归因方法，包括平等主义最小核（从最小核集合中选择 ℓ₂ 范数最小的分配），并评估了此类方法识别重要特征的能力。我们的贡献解决的是另一个问题：我们研究上下文相关的特征效应何时会在广泛的非凸区域内造成 Shapley/半值与最小核解释之间的系统性分离。特别地，我们的理论保证适用于最小核集合中的每一个分配，而非特定的最小核选择器。

2 博弈论预备知识

本节介绍一些博弈论预备知识，包括最小核和半值的概念。

考虑一个可转移效用博弈 𝒢 = (N, v)，其中 N 表示参与者集合，v: 2^N → ℝ 表示特征函数或值函数。支付向量是任意向量 x ∈ ℝ^|N|，其中 x_i 表示分配给参与者 i ∈ N 的支付。对任意联盟 S ⊆ N，记 x(S) := Σ_{i∈S} x_i。当 x(N) = v(N) 时，该支付向量称为有效的（efficient）。更多细节见 [9]（第 2 章）。

解释方法的目标正是将这一总值分配给各特征。在此观点下，每个子集 S ⊆ N 定义一个联盟，其价值由标量联盟值 v(S) 给出。不同的解释方法对应于执行此分配/归因的不同解概念。

2.1 半值

由 Dubey、Neyman 和 Weber [13] 引入的半值推广了 Shapley 值和 Banzhaf 值。我们考虑对称半值，它对相同大小的联盟分配相等权重，尽管总权重可能随大小而异。

定理 1（半值的表示 [13]）。设 n = |N|。对称半值具有如下表示：

φ^w(i; v) = Σ_{k=0}^{n−1} w_k · (1/C(n−1,k)) · Σ_{S⊆N∖{i}, |S|=k} (v(S∪{i}) − v(S))，

其中 w_k ≥ 0 且 Σ_{k=0}^{n−1} w_k = 1。

Shapley 值. 对每个 k = 0, …, n−1 设 w_k = 1/n 即可恢复 Shapley 值：

φ^Shap(i; v) = (1/n) Σ_{k=0}^{n−1} (1/C(n−1,k)) Σ_{S⊆N∖{i}, |S|=k} (v(S∪{i}) − v(S))。 (1)

与一般半值不同，Shapley 值满足有效性，并且是唯一的有效半值。Banzhaf 值则对每个单独的联盟分配相等权重，对应于 w_k = C(n−1,k)/2^(n−1)。

群体半值. 为将值归因于组 D ⊆ N，我们将其视为单个参与者 [40, 16]。设 m := |N∖D|。所得群体半值为

φ_D^w(v) = Σ_{k=0}^{m} w_k · (1/C(m,k)) · Σ_{T⊆N∖D, |T|=k} (v(T∪D) − v(T))， (2)

其中 w_k ≥ 0 且 Σ_{k=0}^{m} w_k = 1。

采样解释. 大小权重 w = (w_0, …, w_m) 在上下文 T ⊆ N∖D 上诱导一个概率分布：

μ_w(T) = w_{|T|} / C(m, |T|)。

等价地，先按 w 采样上下文大小 k，再在 N∖D 的所有 k 元子集中均匀采样。记 Δ_D(T) := v(T∪D) − v(T) 并省略对 v 的依赖，可得

φ_D^w = 𝔼_{T∼μ_w}[Δ_D(T)]。 (3)

这一表示自然地提示可通过采样上下文并平均其边际贡献来估计半值。在附加结构假设（包括子模性及相关受限设置）下，近似保证也得到了研究 [4, 31]。

2.2 最小核

核寻求稳定的支付分配。对支付向量 x，记 x(S) := Σ_{i∈S} x_i 为分配给联盟 S ⊆ N 的支付。若 x(N) = v(N)，则该分配是有效的。若没有任何联盟 S 能通过自行结盟来改进其分配，即 x(S) ≥ v(S)，则它是稳定的。这给出了核的定义，归功于 Shapley 和 Gillies [41, 19]。

定义 1. 博弈 𝒢 = (N, v) 的核为集合

𝒞(𝒢) := {x ∈ ℝ^|N| : x(N) = v(N), x(S) ≥ v(S), ∀S ⊆ N}。

核可能为空；参见 [9] 中的例 2.22。一种补救办法是施加附加结构。对于满足对所有 S, T ⊆ N 均有 v(S∪T) + v(S∩T) ≥ v(S) + v(T) 的超模（或凸）博弈，核非空且包含 Shapley 值 [42]。因此，Shapley 值在此设置中也是稳定的，尽管该保证无法推广到一般博弈。

由 [35] 引入的另一种方法是通过 ε-核来放松稳定性。

定义 2. 对 ε ≥ 0，𝒢 = (N, v) 的 ε-核为

𝒞_ε(𝒢) := {x ∈ ℝ^|N| : x(N) = v(N), x(S) ≥ v(S) − ε, ∀S ⊆ N}。

由于 ε 足够大时 ε-核非空，我们寻求允许可行分配的最小放松。

定义 3. 最小核值为 ε(𝒢) := min{ε ≥ 0 : 𝒞_ε(𝒢) ≠ ∅}。最小核为 ℒ𝒞(𝒢) := 𝒞_{ε(𝒢)}(𝒢)。

计算最小核. 最小核值由如下线性规划求得

min_{x, ε≥0} ε s.t. x(N) = v(N), x(S) ≥ v(S) − ε, ∀S ⊆ N。 (4)

分配 x* 属于最小核当且仅当 对该规划可行。

实践中，可以采用搜索高度被违反联盟的近似过程。最近的工作如 [49, 17] 通过基于采样和基于梯度的方案来近似求解最小核问题。然而，联盟采样本身可能影响所得归因：在上下文干扰项博弈中，Kera 等人 [26] 观察到采样可能使有害特征更难被识别，即使有用特征仍能被良好识别。

另一个问题是最小核是集合值的，因此实际应用需要选择器来挑选特定分配。Kera 等人 [26] 进一步表明这一选择在实践中可能很重要，并提出了熵最小核——一种随温度参数降低而逼近核仁的平滑选择程序。然而，我们的理论结果对最小核中的每一个分配均成立，因此与选择器的选取无关。

3 带上下文干扰项的分类解释

Shapley 值已被广泛用于图像分类，以可视化哪些像素或图像区域对模型在给定目标类别上的输出贡献最大。

设 𝒳 和 𝒴 = {1, …, K} 分别表示图像空间和标签空间。图像分类器是映射 f: 𝒳 → ℝ^K，其中 f(x) 为图像 x ∈ 𝒳 的 logits 向量。预测标签是 logit 最大的类别。

为将合作博弈与固定图像 x 相关联，设 N 为其像素（或特征）集合。对每个 S ⊆ N，记 x_S 为仅保留 S 中特征、其余特征以固定基线替换的掩蔽图像。对目标类别 y ∈ 𝒴，定义诱导值函数为

v_f^{x,y}(S) := [f(x_S)]_y。

因此，v_f^{x,y}(S) 是对应类别 y 的 logit，可能为负。目标类别在所有联盟中固定，与掩蔽图像的预测标签无关。重要的是，同一特征可能因被解释的目标类别不同而具有不同的边际贡献。为符号简洁，我们固定 x 和 y，记 v 以代替 v_f^{x,y}。所得合作博弈记为 𝒢 = (N, v)。我们的理论结果适用于任意固定目标类别，尽管其假设及所得归因幅度可能因类别而异。

3.1 上下文干扰项

本节研究特征的贡献如何强烈依赖于周围图像上下文。重要的是，这种效应是相对于被解释的目标类别而言的：同一特征可能抑制某一类别的输出而支持另一类别。这对于在训练期间与某类别产生关联的虚假特征尤为相关。这样的特征可能作为关联类别的支持性线索，而在解释另一类别时成为上下文干扰项。

我们关注后一种现象。给定固定目标类别，上下文干扰项是指其存在会在完整真实图像上下文中降低相应模型输出的特征。其边际效应在部分上下文中可能截然不同，这使得基于上下文平均的归因方法与受特定联盟约束的基于核的概念之间产生区别。

定义 4（上下文干扰项）。固定目标类别 y，设 D ⊆ N 为被视为单个参与者的特征或特征组。记 C := N∖D 为其余真实图像特征。若

Δ_D(C) := v(C∪D) − v(C) = v(N) − v(C) ≤ −γ，

则称 D 为 γ-上下文干扰项，其中 γ > 0。

因此，将 D 添加到完整真实图像会使目标类别 logit 至少降低 γ。

该定义仅涉及 D 对完整真实图像的影响，对其在较小上下文中的贡献不作任何限制。特别地，上下文干扰项在几乎没有真实图像内容时最初可能是有帮助的，但随着更多上下文的揭示，其贡献可能下降，最终变得有害。更一般地，其贡献可能始终为负且危害逐渐加剧。

我们通过平均边际单调性假设来研究这一行为，该假设仅要求 D 的平均贡献随上下文大小非递增。我们在受控实验和第 4 节所研究的 Salient ImageNet 数据集自然图像中均观察到这一点，尤其是图 2 和图 3 中呈现的近似线性下降。

假设 1（平均边际单调性）。设 m = |C|，T 从 2^C 中均匀随机抽取。对每个 j = 0, …, m，定义

r_j := 𝔼[Δ_D(T) | |T| = j] = (1/C(m,j)) Σ_{T⊆C, |T|=j} Δ_D(T)。

由于 C 是大小为 m 的唯一联盟，有 r_m = Δ_D(C)。我们假设 D 的平均边际贡献随上下文大小非递增：

r_0 ≥ r_1 ≥ ⋯ ≥ r_m = Δ_D(C)。

下面陈述主定理并给出相关解释。

定理 2（半值–最小核差距）。设 D 为满足平均边际单调性的 γ-上下文干扰项。设 φ_D^w 为对称半值，J 表示其采样的上下文大小，即 Pr(J = j) = w_j。对 k = 1, …, m 定义 d_k := r_{k−1} − r_k ≥ 0。则每个 x ∈ ℒ𝒞 满足

φ_D^w − x(D) ≥ Σ_{k=1}^{m} d_k · Pr_w(J < k) − ε*。 (5)

特别地，若 Σ_{k=1}^{m} d_k · Pr_w(J < k) ≥ ε* + δ，则保证至少 δ > 0 的差距。

此外，假设对某个 k < m 有 r_k > β，其中 β + γ > 0。则每当

Pr_w(J ≥ k+1) ≤ 1 − (ε* + δ)/(β + γ)

时，即保证至少 δ > 0 的差距。

该定理的证明见附录 A.1。这里我们详细解释条件与结论。首先，充分条件刻画了半值的平均行为与最小核的联盟稳定性之间的张力。假设干扰项在较小上下文中平均有益（r_k > β > 0），但在完整真实上下文中有害（r_m ≤ −γ < 0）。则每当 Pr_w(J ≥ k+1) ≤ 1 − (ε + δ)/(β + γ) 时，即保证至少 δ > 0 的差距。因此，当半值对较大上下文赋予的权重足够小时，它可能在存在真实图像特征的情况下忽略干扰项的有害效应，并给其分配比最小核更大的归因。该条件随对比度 β + γ 增大而更易满足，随最小核值 ε 增大而更难满足。

注 1（归因差距的解释）。考虑一张猫图像，无论有无干扰项 D 均被正确分类，但加入 D 后猫 logit 下降。理想情况下，解释应反映真实猫特征的贡献，而非给干扰项分配过多功劳。因此，正的 Shapley–最小核差距刻画了 Shapley 分配给干扰项的更大相对归因，这与我们的实验观察一致。

以下引理刻画半值–最小核差距如何随上下文权重变化。在平均边际单调性下，将权重向较大上下文转移会减小有符号差距。

引理 1（上下文权重对差距的影响）。假设 D 满足平均边际单调性，即 r_0 ≥ r_1 ≥ ⋯ ≥ r_m。考虑两个具有上下文大小分布 w 和 w′ 的对称半值。假设 w′ 随机地对较大上下文赋予更大权重：

Σ_{j=k}^{m} w′j ≥ Σ{j=k}^{m} w_j，k = 1, …, m。

定义二者的有符号差距为

G_w := φ_D^w − max_{x∈ℒ𝒞} x(D)，G_{w′} := φ_D^{w′} − max_{x∈ℒ𝒞} x(D)。

则

G_w − G_{w′} = Σ_{k=1}^{m} (r_{k−1} − r_k) Σ_{j=0}^{k−1} (w_j − w′_j) ≥ 0。 (6)

若至少一个被加项中的两个因子均严格为正，则不等式严格成立。

该引理的证明见附录 A.2。附录 B.2.2 中的实验评估（特别是图 6）证实了这一模式。接下来我们讨论将权重集中于非常大或非常小上下文的半值的局限性。

注 2（极端上下文权重的局限性）。虽然对较大上下文赋予更大权重会减小半值–最小核差距，但这未必产生更有信息量的解释。某特征可能在较小上下文中真正支持目标类别，但随着更多特征的揭示而变得不那么有用甚至有害。过度集中于较大上下文的半值可能忽略这种正贡献，正如强调较小上下文的半值可能忽略其在完整图像中的有害效应。相比之下，最小核通过其稳定性约束考虑所有联盟，而非对不同上下文大小分配固定权重。

特化. 我们的结果直接适用于 Shapley、加权 Banzhaf 和 Beta-Shapley 值。对 Shapley 而言，定理 2 中的单阈值条件简化为

Pr_Sh(J ≥ k+1) = (m−k)/(m+1) ≤ 1 − (ε* + δ)/(β + γ)。

此外，引理 1 表明有符号差距关于加权 Banzhaf 参数 p 非递增，关于 Beta-Shapley 的参数 a 非递减、关于 b 非递增。相应推论及证明见附录 A.3。

4 实验

我们在两种设置中研究上下文干扰项：受控图像分类实验和 Salient ImageNet 上的评估。我们比较其对 Shapley 和最小核归因的影响，附加实验报告于附录 B。

4.1 受控标记偏置实验

首先，我们进行受控标记偏置实验，以检验理论的 Shapley–最小核差距是否会在图像分类中出现。

我们构建一个三分类的狗/猫/鸟任务并训练 ResNet-50 [22] 分类器。如图 2(a) 所示，红色标记区域 D 被添加到 100% 的狗图像和 30% 的猫图像，而鸟图像无标记。这使 D 与狗类强烈关联，从而可能成为猫图像的误导性上下文线索。

我们首先验证 D 对猫预测表现为上下文干扰项。每张图像被划分为图像块网格，定义参与者集合 N。标记区域 D ⊆ N 由与红色标记重叠的图像块集合表示。然后从非标记块中采样联盟 T ⊆ N∖D 并计算 Δ_D(T) = v(T∪D) − v(T)。如图 2(b) 所示，Δ_D(T) 随上下文增强而下降并由正转负。因此，标记在弱上下文中有助于猫预测，但当已存在强猫证据时则起抑制作用。

最后，我们比较分配给标记区域的归因。图像（224×224）被划分为 8×8 网格，产生 64 个图像块参与者。Shapley 值通过蒙特卡洛置换采样估计，每张图像使用 100 个随机置换。对每个置换，顺序加入 64 个图像块并记录模型输出的变化，从而每张图像得到 100×64 个采样输出变化。对于最小核，我们避免枚举所有联盟，而是在采样约束上求解线性规划 [49]。我们以概率 p = 0.5 独立包含每个参与者来采样 6,400 个联盟，并加入空联盟和全联盟。优化使用 CVXPY 实现。神经网络评估在 CUDA 上使用 PyTorch 执行，CVXPY 优化通常在 CPU 上运行。

图 2(c) 显示，对大多数图像，Shapley 给 D 分配的值大于最小核。这支持了我们的理论预测：Shapley 可能通过上下文平均而过度归因上下文干扰项，而最小核则惩罚破坏高价值联盟的特征。

4.2 自然图像中的上下文干扰项

接下来我们检验相同的分离现象是否出现在自然产生的区域而非合成标记中。我们使用 Salient ImageNet [44] 的类别–特征对来识别 ImageNet 训练图像中的候选虚假区域。每张图像表示为 7×7 图像块博弈，目标类别 logit 用作联盟值。候选区域使用 Grounding DINO [33] 和 SAM [27] 独立定位，且仅当所得区域 D 满足上下文干扰项符号反转时才保留：其平均边际贡献在弱上下文中为正、在强上下文中为负，且在两组中至少 60% 的采样上下文中观察到预期符号。

我们分析了 ResNet-50 的 354 个上下文干扰项和 ViT-B/16 的 108 个，仅考虑模型预测与真实标签一致的图像。完整的选择和计算细节见附录 B.4。进一步评估见附录 B.3。

对每个候选，我们将蒙特卡洛 Shapley 与采样的平等主义最小核分配（Core，细节见附录 B.4.3）进行比较，报告总干扰项归因 A_D = Σ_{i∈D} a_i 和掩码加权归因 A_mask = Σ_{i=1}^{49} a_i w_i，其中 w_i 为最终掩码覆盖图像块 i 的比例。作为对照，我们为每种架构生成 200 个预测活跃的随机 SAM 区域，并排除那些上下文干扰项危害大到足以改变标签的区域。

图 3： 上下文干扰项的代表性示例。输入 + D：原始输入，干扰项区域 D 以黄色勾勒。Shapley 与最小核：图像块归因热图，红色和蓝色分别表示正、负归因；A_D 为分配给 D 中图像块的总归因。上下文依赖性：边际贡献 Δ_D(T) = v(T∪D) − v(T) 关于周围上下文 T 的目标类别 logit v(T) 绘制。强上下文中的 logit 变化：加入 D 前后的采样强联盟 T，报告所得目标类别 logit v(T∪D) 及其相对 v(T) 的变化 Δ_D。

定性评估. 图 3 以两个自然图像示例说明相同机制。在炉灶图像中，火焰充当干扰项 D；而在旗杆图像中，美国国旗充当 D。在这两个示例中，上下文依赖图显示 Δ_D(T) 随周围上下文的目标类别 logit v(T) 增大而下降，由弱上下文中的正值变为强上下文中的负值。因此，火焰和国旗并不提供一致有用的类别证据；相反，其贡献取决于周围上下文，与上下文干扰项的行为一致。

强上下文示例进一步说明了这一效应。对炉灶图像，仅周围上下文就已产生 v(T) = 9.00 的高炉灶 logit。加入火焰后 logit 降至 v(T∪D) = 7.80，即 Δ_D = −1.19。该例表明火焰在此上下文中并非维持高炉灶得分所必需；相反，其他视觉证据（如炉灶框架）已足够且保持信息量。然而，Shapley 给火焰分配了 A_D = 3.60 的较大归因，而 Core 仅分配 0.85，并相对更强调炉灶结构。

旗杆示例呈现类似模式。旗杆为目标类别提供稳定证据，而将美国国旗加入所显示的强上下文使旗杆 logit 从 9.87 降至 7.05，即 Δ_D = −2.82。尽管边际贡献为负，Shapley 仍给国旗分配 A_D = 3.76，而 Core 下为 1.77，后者相对更强调旗杆。

这些示例展示了 Shapley 热图如何在存在更强上下文的情况下仍可能过度强调火焰或国旗等上下文相关线索。最小核给它们的功劳更少，而更强调仍然有用的证据。

5 局限性与讨论

我们的结果强调最小核作为一种补充性归因方法，尤其适用于计算机视觉，其中较大的半值–最小核差距可能指示捷径特征或上下文干扰项。其主要局限在于计算方面：式 (4) 涉及指数级多的联盟约束。虽然给定有效分离预言机后可通过椭球法在多项式时间内求解该 LP [20, 14]，但此类预言机在实践中可能难以获得。开发可扩展的最小核算法——通过应用特定结构或启发式分离预言机——仍是未来工作的重要方向。

我们以 Hart 和 Mas-Colell [21] 的观点作结，他们强调研究不同合作解概念的价值：

"更简单的解可能更易于研究和应用，从而增加其有用性。然而，重要的是考察基于不同公设的不同解概念，因为它们从不同角度阐明问题。"

本着这一精神，最小核通过强调联盟稳定性而非平均边际贡献，为 Shapley 值提供了补充性视角。

附录 A 缺失证明与附加推论

A.1 定理 2 的证明

证明. 设 x ∈ ℒ𝒞 为任意最小核分配。由有效性及对 C 的最小核约束，

x(D) = v(N) − x(C) ≤ v(N) − v(C) + ε = r_m + ε。

由于 φ_D^w = Σ_{j=0}^{m} w_j r_j 且 Σ_{j=0}^{m} w_j = 1，可得

φ_D^w − x(D) ≥ Σ_{j=0}^{m−1} w_j (r_j − r_m) − ε*。

记 d_ℓ := r_{ℓ−1} − r_ℓ ≥ 0，平均边际单调性给出 r_j − r_m = Σ_{ℓ=j+1}^{m} d_ℓ。交换求和顺序得

φ_D^w − x(D) ≥ Σ_{ℓ=1}^{m} d_ℓ · Pr_w(J < ℓ) − ε*。

这即一般差距界。

现假设对某个 k < m 有 r_k > β > 0。由平均边际单调性，对每个 j ≤ k 有 r_j ≥ r_k > β。由于 D 是 γ-上下文干扰项，r_m ≤ −γ，故对每个 j ≤ k 有 r_j − r_m > β + γ。对 j > k，单调性仍保证 r_j − r_m ≥ 0。因此，

φ_D^w − x(D) ≥ Σ_{j=0}^{m−1} w_j (r_j − r_m) − ε ≥ (β + γ) Pr_w(J ≤ k) − ε = (β + γ)(1 − Pr_w(J ≥ k+1)) − ε*。

因此，若 Pr_w(J ≥ k+1) ≤ 1 − (ε* + δ)/(β + γ)，则对每个 x ∈ ℒ𝒞 有 φ_D^w − x(D) ≥ δ。∎

A.2 引理 1 的证明

证明. 记 d_k := r_{k−1} − r_k ≥ 0。对每个 j = 0, …, m，有 r_j = r_m + Σ_{k=j+1}^{m} d_k。利用 Σ_{j=0}^{m} w_j = 1 并交换求和顺序得

φ_D^w = Σ_{j=0}^{m} w_j r_j = r_m + Σ_{k=1}^{m} d_k Σ_{j=0}^{k−1} w_j。

由于底层博弈固定，最小核项对两个半值相同。减去 w′ 的对应表达式即得

G_w − G_{w′} = Σ_{k=1}^{m} d_k (Σ_{j=0}^{k−1} w_j − Σ_{j=0}^{k−1} w′_j)。

由随机占优及两个分布和为一的事实，

Σ_{j=0}^{k−1} w_j − Σ_{j=0}^{k−1} w′j = Σ{j=k}^{m} w′j − Σ{j=k}^{m} w_j ≥ 0。

由于 d_k ≥ 0，每个被加项非负，证毕。∎

A.3 对经典半值的推论

一般差距定理通过代入标准半值的上下文大小分布给出显式条件。权重转移引理进一步刻画参数变化时差距的变化。

推论 1（Shapley 特化）。在定理 2 的假设下，分组 Shapley 值满足

φ_D^Sh − x(D) ≥ (1/(m+1)) Σ_{j=0}^{m−1} (r_j − r_m) − ε = (1/(m+1)) Σ_{k=1}^{m} k(r_{k−1} − r_k) − ε (7)

对每个 x ∈ ℒ𝒞 成立。此外，假设对某个 k < m 有 r_k − r_m ≥ η > 0。则每当

Pr_Sh(J ≥ k+1) = (m−k)/(m+1) ≤ 1 − (ε* + δ)/η

时，即保证至少 δ > 0 的差距。特别地，若 r_k > β > 0 且 r_m ≤ −γ，只需 (m−k)/(m+1) ≤ 1 − (ε* + δ)/(β + γ)。

证明. 对 Shapley，每个 j 有 w_j = 1/(m+1)。将这些权重代入定理 2 得 (7) 中第一个不等式。等式由 r_j − r_m = Σ_{ℓ=j+1}^{m} (r_{ℓ−1} − r_ℓ) 交换求和顺序得出。现设 r_k − r_m ≥ η > 0。由平均边际单调性，对每个 j ≤ k 有 r_j − r_m ≥ η，而对 j > k 有 r_j − r_m ≥ 0。因此，

φ_D^Sh − x(D) ≥ η Pr_Sh(J ≤ k) − ε = η(1 − Pr_Sh(J ≥ k+1)) − ε。

由于 Shapley 均匀采样上下文大小，Pr_Sh(J ≥ k+1) = (m−k)/(m+1)。所述充分条件随之成立。最后，r_k > β 与 r_m ≤ −γ 蕴含 r_k − r_m > β + γ，给出最后一个条件。∎

推论 2（加权 Banzhaf 特化）。在定理 2 的假设下，考虑 p-加权 Banzhaf 半值，其中 w_j(p) = C(m,j) p^j (1−p)^{m−j}，0 < p < 1。对每个 x ∈ ℒ𝒞，

φ_D^{Banz(p)} − x(D) ≥ Σ_{j=0}^{m−1} C(m,j) p^j (1−p)^{m−j} (r_j − r_m) − ε*。 (8)

此外： p 中的单调性。实际有符号差距 G_{Banz(p)} 关于 p 非递增。 集中于较小上下文。若 p ≤ 1/(m+1)，则 G_{Banz(p)} ≥ G_Sh。因此，为 Shapley 建立 δ-差距的任何充分条件同样为这些加权 Banzhaf 值建立 δ-差距。标准 Banzhaf 对应 p = 1/2。

证明. 该界由定理 2 代入二项式大小权重得出。对，对归因求导得

(d/dp) φ_D^{Banz(p)} = m Σ_{j=0}^{m−1} C(m−1,j) p^j (1−p)^{m−1−j} (r_{j+1} − r_j) ≤ 0。

由于最小核项不依赖 p，有符号差距亦非递增。对，当 p ≤ 1/(m+1) 时，序列 j ↦ w_j(p) 非递增，因为 w_{j+1}(p)/w_j(p) = ((m−j)/(j+1))·(p/(1−p)) ≤ 1。{0, …, m} 上的非递增概率分布被这些大小上的均匀分布随机占优。引理 1 因此给出与 Shapley 的期望比较。∎

推论 3（Beta-Shapley 的单调性）。在定理 2 的假设下，考虑参数为 a, b > 0 的 Beta-Shapley，大小权重为

w_j^{(a,b)} = C(m,j) · Beta(j+b, m−j+a)/Beta(b, a)，j = 0, …, m。

其有符号差距满足 G_{a,b} ≥ Σ_{j=0}^{m−1} w_j^{(a,b)} (r_j − r_m) − ε*。此外： 固定 b 时，G_{a,b} 关于 a 非递减； 固定 a 时，G_{a,b} 关于 b 非递增。特别地，增大较大上下文的相对权重会减小有符号差距。a = b = 1 时恢复 Shapley。

证明. 差距界是定理 2 的直接应用。对单调性陈述，使用 beta-二项分布表示：Θ_{a,b} ~ Beta(b, a)，J_{a,b} | Θ_{a,b} = θ ~ Bin(m, θ)。固定 b 时，增大 a 使 Θ_{a,b} 随机下移，从而使 J_{a,b} 向较小上下文大小移动。固定 a 时，增大 b 使两个分布均随机上移。两个结论均由引理 1 得出。∎

B.1 解释方法的 Epsilon 评估

我们在 100 张 ImageNet 测试图像上使用 ResNet-50 分类器 [22] 评估解释方法。每张图像调整为 224×224 并划分为 8×8 网格，产生 64 个图像块参与者。对固定归因向量 x，定义 epsilon 值为最坏联盟赤字：

ϵ(x) = max_{S⊆N} (v(S) − x(S))，

其中 x(S) = Σ_{i∈S} x_i。实践中，该最大值在 4,096 个采样联盟上近似。

对 Grad-CAM [39] 和 Grad-CAM++ [11]，解释方法不直接产生 epsilon 值。因此我们通过在每个图像块内平均热图，将每个热图转换为图像块级分配 x。由于这些热图不一定满足有效性约束，我们重新缩放 x 使 Σ_i x_i = v(N)。然后通过采样联盟评估 ϵ(x)。

对蒙特卡洛 Shapley，我们将 ϵ(x) 作为所得归因向量的事后评估。Shapley 值通过蒙特卡洛置换采样估计，每张图像使用 64 个随机图像块排序（每张图像 64×64 = 4,096 个采样输出变化）。对最小核，我们使用相同的 64 个图像块参与者，并在 4,096 个采样联盟约束上求解最小核优化。我们直接报告最小核求解器返回的优化 ϵ。因此，最小核 epsilon 不是对生成热图的事后评估，而是最小核优化过程中获得的目标值。较低的 epsilon 表明解释更好地满足采样核约束，从而从联盟角度看更稳定。

B.2.2 上下文权重对群体半值差距的影响

接下来我们考察上下文大小分布如何影响半值–最小核差距。本实验将整个标记区域 D 视为单个参与者，直接估计其群体边际 Δ_D(T) = v(T∪D) − v(T)，T ⊆ N∖D。这不同于对标记图像块的个体半值归因求和。对上下文大小分布 α，我们估计 φ_α^group(D) = 𝔼_{T∼μ_α}[Δ_D(T)]，并将其与原始图像块博弈最小核解的 x(D) = Σ_{i∈D} x_i 进行比较。我们报告有符号差距 G_α := φ_α^group(D) − x*(D)，故 G_α > 0 表示群体半值给标记分配的功劳大于最小核。

上下文加权族. 我们使用与前述实验相同的每种骨干网络 100 张带标记猫图像，在保持模型、掩蔽程序、基线和最小核分配固定的同时改变上下文大小分布。对 p-加权 Banzhaf 族，N∖D 中的每个图像块以概率 p ∈ {0.2, 0.35, 0.5, 0.65, 0.8} 独立包含。因此，较大的 p 将概率质量移向较大上下文，而 p = 0.5 给出标准 Banzhaf 值。我们还考虑 Beta-Shapley 族， ∈ {(4,1), (2,1), (1,1), (1,2), (1,4)}，其期望归一化上下文大小为 b/(a+b)； = (1,1) 恢复群体 Shapley 值。作为参考基线，我们还独立估计群体 Shapley 值，而非仅将其等同于 = (1,1) 的 Beta-Shapley 设置。每个群体半值（包括该群体 Shapley 基线）由每张图像 3,200 个边际样本估计。由于一个边际样本同时评估 T 和 T∪D，这与最小核约束所用的名义 6,400 联盟评估预算相匹配。

B.4.1 数据、预处理与合作博弈

v(S) = f_c(x_S)。 (9)

B.4.2 上下文干扰项选择

虚假特征筛选. 每个 Salient ImageNet 类别–特征对由五名 MTurk 工作者注释 [44]。我们保留多数工作者判断不属于主要对象的特征。工作者的自由文本描述用作下述定位阶段的文本提示。

初始符号反转搜索. Salient ImageNet 软掩码在其图像特定的第 90 百分位数处二值化，覆盖超过 25% 图像的掩码被排除。当图像块面积的至少 20% 与二值掩码重叠时，该图像块被划入初步干扰项区域 D。对每个候选区域，我们先均匀采样上下文大小，再均匀采样该大小的子集，从而采样上下文 T ⊆ N∖D。我们评估区域边际贡献：

Δ_D(T) = v(T∪D) − v(T)。 (10)

设 τ 为采样 v(T) 值的第 70 百分位数，定义

𝒯_weak = {T : v(T) < τ}， (11)
𝒯_strong = {T : v(T) ≥ τ}。 (12)

我们保留平均边际贡献在弱上下文中为正、强上下文中为负的候选：

𝔼[Δ_D(T) | T ∈ 𝒯_weak] > 0， (13)
𝔼[Δ_D(T) | T ∈ 𝒯_strong] < 0， (14)

同时还要求相应符号在每组的大多数采样上下文中出现。

独立定位与重新评估. 为获得候选特征的独立定位，我们使用 Grounding DINO [33] 配合工作者提供的文本提示，并用 SAM [27] 细化所得区域。我们保留与 Salient ImageNet 掩码足够一致的区域，并排除过大的掩码。干扰项区域 D 随后由所得的一致掩码重新定义，并重复上下文相关符号反转测试。两种架构使用相同的定位流程。对每个模型，符号反转标准使用该模型自身的联盟值评估，从而使所得上下文干扰项集合可能因架构而异。

B.4.3 Shapley 与采样平等主义最小核的计算

Shapley 值使用随机参与者置换近似。对参与者 i，

φ̂i = (1/R) Σ{r=1}^{R} [v(P_i^{(r)} ∪ {i}) − v(P_i^{(r)})]， (15)

其中 P_i^{(r)} 包含置换 r 中位于 i 之前的参与者。

对最小核近似，我们以概率 0.5 独立包含每个参与者来采样联盟约束，并显式包含空联盟和全联盟。我们将博弈平移为

v′(S) = v(S) − v(∅)， (16)

并求解

min_{x,ε} ε (17)
s.t. Σ_{i∈N} x_i = v′(N)， (18)
Σ_{i∈S} x_i + ε ≥ v′(S)，S ∈ 𝒞_sample， (19)
ε ≥ 0。 (20)

获得 ε 后，我们在相同联盟和有效性约束下（ε 固定为 ε 直至数值容差）最小化 ‖x‖₂² (21) 以选择平等主义最小核分配。我们不对分配施加非负性约束。在此及第 4.2 节中，Core 指该采样平等主义最小核分配。

B.4.4 预测活跃的随机 SAM 对照

我们为每种架构构建单独的对照队列。候选图像从排除所选上下文干扰项图像后的同一 ImageNet 图像池中抽取。随机放置的框（大小与上下文干扰项区域分布匹配）被提供给 SAM 以获得对照区域。Salient ImageNet 掩码和 Grounding DINO 均不用于确定对照位置。为避免与预测无关的区域，我们仅保留平均绝对边际贡献超过相应上下文干扰项分布第 10 百分位数的对照，得到 ResNet-50 的 0.60 logit 单位和 ViT-B/16 的 0.90 阈值。满足上下文符号反转标准的区域被排除。对照选择过程中不使用 Shapley 或 Core 归因。所选对照使用与上下文干扰项相同的 Shapley 和采样最小核流程进行评估。

B.4.5 比较的范围

自然上下文干扰项队列是使用人类注释、独立定位和上下文相关符号反转标准选出的。因此，所报告的归因结果刻画的是这一选定群体，而非一般意义上的 ImageNet 图像。此外，由于上下文干扰项和随机 SAM 队列采用不同的选择标准构建，二者的比较应被解读为所得队列之间的经验比较，而非单独符号反转的因果效应。
