原标题：Multimodal Masked Diffusion Autoencoder for Modeling Impaired Driving

中文摘要： 本文提出多模态掩码扩散自编码器ID-MAE，将驾驶员损伤标签与注视、轨迹作为掩码token联合建模，通过重建被掩码的行为模态提供自监督信号。同时发布DIVERT驾驶模拟器数据集，包含109名参与者103小时数据，涵盖十种损伤诱导与六类道路危险。实验表明，该方法在DIVERT上损伤检测配对AUC达0.706，显著优于无重建损失的0.590及现有基线，并支持轨迹与注视预测，且视觉分心与认知分心可被有效区分。

摘要

人类认知状态（如分心、压力）、注视和行为以微妙的方式与驾驶环境交互，AI 可以利用这些信息来辅助驾驶员，但大规模获取人类认知状态水平的真实标签成本高昂。我们提出一种多模态掩码扩散自编码器 ID-MAE，为损伤预测添加了自监督目标：在将损伤标签作为掩码 token 进行预测的同时，它还重建被掩码的注视和轨迹。为探究不同模态和损伤类型对模型推断的影响，我们引入 DIVERT——一个驾驶模拟器数据集，包含 103 小时驾驶数据（n = 109），涵盖认知、视觉和情绪状态的十种损伤诱导，并记录了注视、车辆状态和场景视频。我们展示了 ID-MAE 如何在 DIVERT 数据集和现有数据集上的损伤推断结果中取得显著改进，并在轨迹预测和注视预测等额外任务中取得强劲结果。对于位置匹配的样本对，我们的模型在 DIVERT 上的损伤检测配对 AUC 达到 0.706，而无重建损失时为 0.590，超越了现有基线。我们从输入模态、掩码方案、位置编码、注意力机制和解码等方面探究了设计空间。我们还研究了训练和推断中各种损伤之间的交互作用，证明视觉需求高的分心与认知分心是可分离的。代码和数据将在论文接收后公开。

1 引言

图 1：ID-MAE 将注视（红色和绿色圆圈）、轨迹、场景视频和损伤视为掩码扩散模型的 token；当损伤被掩码时，该单一网络推断驾驶员状态；当注视和轨迹的 token 被掩码时，则预测注视和轨迹。我们在 DIVERT（不同损伤和危险下的注视、智能体轨迹、场景视频）上进行了训练和评估，实现了损伤检测、受损驾驶员与基线驾驶员的比较、模态对损伤推断影响的评估以及损伤类型交互的分析。

人类认知状态、注视和行为之间的交互是人类安全方法的核心 [73, 106]。对驾驶员安全的推理要求我们理解这些因素在较长时间和多种模态上的相互作用。例如，考虑推理一个忽视前方停车的驾驶员——其对仪表盘或附近物体的凝视可能是判断其分心、执行任务还是疲劳的迹象。然而，所有多模态行为和注意力序列的空间极其庞大。在这些序列的分布中，风险关键因素可能不会被强烈观察到；例如，认知分心可能仅表现为视觉扫描范围的轻微缩小和对周边事件反应的轻微延迟。用于时间信号分析的自监督方法已被证明极具价值 [66, 26]，尤其是在标签稀缺 [99] 或有噪声 [33] 的情况下。在本质上多模态的推断任务中，例如连接注视、行为和潜在认知因素的任务，利用自监督成为解决方案中具有挑战性但至关重要的方面。风险相关的罕见事件数据量有限 [30, 23]，以及行为观测序列的高维特性，因此要求我们从行为本身而非仅从标签中获取监督。

我们在带有损伤类型标签的驾驶数据上探究自监督，将其表述为多模态掩码扩散推断，并研究联合建模多种损伤和驾驶员行为如何影响损伤检测。这需要比现有受损驾驶数据集更丰富的数据，这些数据集规模较小 [80]、缺乏场景视频或智能体轨迹 [46]、在不同车辆自动化水平下收集 [20]，或损伤类别有限 [39]。因此，本工作的贡献包括：

• 我们提出受损驾驶 MAE（ID-MAE），一种通过掩码扩散方法利用注视、轨迹、场景视频和驾驶员损伤状态的模型。它使用多模态自监督和损伤任务的联合训练来改进损伤检测，同时还能生成注视和轨迹预测。

• 我们引入"日常真实任务多样化受损驾驶"数据集（DIVERT）：一个包含多样化、受控的驾驶员损伤、场景和危险的新数据集。

• 我们在 DIVERT 上建立基线，并证明 ID-MAE 在 DIVERT 和受损驾驶数据集（IDD）[30] 上优于现有基线。行为模态的掩码重建显著改进了仅使用标签监督的损伤检测。我们分析了每种损伤的性能，并报告了跨损伤类型联合训练的益处。

2 相关工作

驾驶员损伤和状态检测。 认知分心长期以来通过其对视觉扫描、工作负荷和车辆控制的影响来表征 [73, 82]，并且可以使用学习模型从行为和生理信号中检测 [52]。大量工作针对受损或其他负面驾驶员状态的自动检测 [78]，使用车辆控制、生理、注视和视频信号 [53, 59, 98, 47, 51, 1, 77, 96]。具有注视/注意力的多模态模型已经探索了基线和受损驾驶（参见 [95, 2] 及其参考文献），最近的数据集增加了模态 [20] 或潜在因素 [30]。由于损伤标签稀缺，一些工作通过视觉对比学习减少监督 [48, 104]，以及对车辆、生理和周围物体信号进行无监督学习 [69]，而其他工作则探究对未见个体的泛化 [72, 13, 9]。我们则训练一个生成模型，其掩码目标包括损伤标签以及注视和轨迹。重建行为提供自监督，联合监督损伤类型可以提高检测性能。

多模态序列的掩码建模。 掩码自编码器（MAE）已被扩展到视频 [29, 31] 和其他模态 [8, 61]，统一序列模型将许多任务和模态作为 token 序列处理，其预训练目标包括掩码去噪 [57]，迭代去掩码 [14] 是许多生成变体的基础。对于运动数据，掩码轨迹模型随机化轨迹的哪些部分被隐藏，以支持预测、插补和表示学习 [91, 63]。2D 和 3D 表示的联合掩码也被用于点云预训练 [34]，这启发了我们的几何感知掩码。我们将模态级掩码与时间窗口相结合，使得单个任务无关的目标涵盖预测和插补，以及标签被掩码时的损伤推断。

图 2：架构概览。注视、轨迹、视频和损伤 token 被分为干净 token（模型将其视为上下文）和噪声 token（虚线，模型学习重建）。单模态编码器嵌入每个模态，多模态编码器融合它们。解码器然后以类似 U-Net 的方式对噪声 token 去噪。视频仅作为编码上下文，不被解码。

用于表示学习和多模态序列的扩散模型。 扩散模型已被用于自监督预训练 [11, 60, 94] 和半监督学习 [97, 37]。MAE 扩散已被用于表示学习 [88, 35] 和预测 [55]，掩码生成补充了仅去噪训练 [92, 87] 并鼓励信息瓶颈 [90]。我们的解码器使用每 token 噪声水平，类似于 [15]；我们不是采样独立水平，而是在噪声 token 之间共享一个采样步骤，将噪声与模态和窗口掩码绑定，并将该水平作为注意力偏置提供给解码器。我们使用吸收态过程 [7] 联合扩散连续信号（注视、轨迹）和离散标签，这与语言的掩码离散扩散 [75, 56, 64] 和相关方法 [101] 密切相关。用于生成的多模态扩散已经在连续潜在变量 [10]、掩码离散 token [83] 以及通过结合扩散的语言建模损失 [103] 或任意状态空间上的联合过程 [74] 的混合连续和离散模态中进行了探索；掩码扩散也被用于音频-视频表示学习 [65]。这些大多针对生成，而我们推断潜在状态并插补或预测缺失的行为。在驾驶之外，扩散实现了多变量时间序列的插补 [85, 71, 3]；时间序列基础模型 [32, 5, 21] 专注于单变量序列，不利用信号之间的几何关系。潜在变量模型 [44]，包括扩散变体 [22, 4]，大多解决孤立的预测或分类问题。

轨迹和注视预测。 轨迹预测有标准基准 [27, 89]、强大的基于注意力的模型 [63, 62, 81] 和基于扩散的预测器 [42, 58, 102]。这些方法仅从场景上下文预测智能体运动，不使用驾驶员注视或潜在状态；注视建模涵盖显著性 [40, 38]、扫描路径预测 [6, 49]、注意力焦点 [68, 28]，以及最近的基于扩散的注视生成 [43, 45]。一些工作使用注视和视场来条件化自车轨迹预测 [2, 54]。我们则联合建模注视、轨迹和场景。

3 模型

我们的模型（图 2）是一个编码器-解码器 transformer，以 DiffMAE [88] 的风格训练为掩码扩散模型。我们将其从图像扩展到四种模态（注视、轨迹、视频和损伤），将损伤标签作为离散 token 与连续信号一起扩散，并引入几何相对注意力。每个模态是时间轴 T 和帧内轴 W 上的 token 网格（轨迹为智能体，视频为图像块，注视和损伤的 W=1）。可见（干净）token 由每个模态的单模态编码器嵌入，并由多模态编码器融合。隐藏（噪声）token 被前向扩散破坏，并由多模态解码器去噪，随后是每个模态的单模态解码器。视频仅作为上下文：其掩码 token 对编码器隐藏，但从不被解码或监督。

3.1 几何相对注意力

每个注意力层向缩放点积 logit ℓ 添加学习到的偏置 [70]，该偏置由两个 token 之间的几何关系计算，类似于编码智能体之间成对相对位姿的轨迹预测模型 [17, 105, 100]，但扩展到其他模态：

ℓ_ij^(h) = ⟨q_i^(h), k_j^(h)⟩/√d_h + b_ij^(h)，b_ij = MLP_pos(γ(r_ij))，(1)

其中 q_i^(h) 和 k_j^(h) 是头 h 的查询和键，d_h 是每个头的维度，r_ij 收集从 token i 到 token j 的偏移。每个偏移通过正弦函数嵌入（γ），多层感知机（MLP）MLP_pos（针对每个查询-键模态对和层分别学习）将嵌入映射为每个头一个偏置。

偏移是时间索引、智能体索引和扩散步骤的差异，加上几何偏移。干净 token 的步骤为零，因此步骤偏移是噪声查询学习其时间步的方式。在两个传感器 token（注视或视频块中心）之间，几何偏移是视线方向 (ψ, ϑ) 的差异。否则，它是从某个视点看到的键的位移、方位角和仰角：对于两个轨迹 token，是查询智能体的朝向；对于传感器 token 和智能体，是沿传感器 token 视线方向看的自车。损伤 token 充当直视前方的自车。时间、位置和视线方向从不是 token 内容；它们仅通过此偏置到达模型（详见补充材料）。

• 视频 使用冻结的视觉 transformer（ViT-B/32）[25] 特征，在裁剪到驾驶视场的 3×7 网格上。

3.3 多模态编码器和解码器

多模态编码器在干净 token 的单模态编码 z_u 上堆叠 N_mm = 5 个块。每个块有一个时间层，其中 token 在局部窗口内随时间关注其自身模态的干净 token，和一个跨模态层，其中它关注所有模态在最近时间索引处的干净 token。因此，10 Hz 的注视或损伤 token 读取最近的 2 Hz 轨迹和视频 token，偏置保留残余时间偏移（第 3.1 节）。每个模态有自己的查询和输出投影以及前馈块，在跨模态层中，每个查询-键模态对有自己的键和值投影以及自己的 MLP_pos。每个块的输出 z^(1), …, z^(N_mm) 被缓存。

多模态解码器作用于被解码模态的噪声 token。噪声 token 携带干净内容的噪声版本，其中会泄露真实标签的通道（有效性、自车标志、注视事件）被保留：

• 损伤：one-hot 设置为 mask。
• 注视：无内容；token 作为学习到的嵌入进入。
• 轨迹：扩散的加速度 a 和偏航率 ω，以及从扩散的 a 重新积分的速度 v。

噪声坐标（注视角度，以及从扩散控制积分的轨迹位置和朝向）仅通过注意力偏置可见。每个模态的线性层将噪声内容 x_u^(τ) 投影到初始解码器状态 d_u = W_dec^m x_u^(τ)。解码器镜像编码器的层和参数化并以相反顺序构建：在其第 n 个块的每一层中，噪声 token 首先交叉关注深度 N_mm+1−n 处的缓存编码器输出，

d_u ← d_u + MHA(d_u, z^(N_mm+1−n))，(2)

其中多头注意力（MHA）是公式 (1) 的偏置注意力，读取与相应编码器层相同的干净键，然后在噪声 token 之间自注意力。这种类似 U-Net 的耦合遵循 Wei 等人 [88] 的扩散掩码自编码器。扩散过程、轨迹控制积分和局部注意力窗口在补充材料中详述。

3.4 单模态解码器

每个被解码的模态然后用 N_uni = 2 个块沿其固有轴细化 d_u（表 1），镜像其单模态编码器。其第 n 个块交叉关注同一模态单模态编码器块 N_uni+1−n 的输出，因此第一个解码器块读取最深的单模态特征，然后在该模态的噪声 token 之间自注意力。LayerNorm 和线性头产生预测：

• 损伤：每个 token 处每种损伤类型一个 logit。
• 注视：每只眼睛的偏航角 ψ 和俯仰角 ϑ。
• 轨迹：加速度 a 和偏航率 ω，积分到速度、位置和朝向（类似于 [18, 76, 41]）。

遵循 Wei 等人 [88]，轨迹和注视头直接预测干净目标而非噪声。

3.5 掩码和损失

掩码。 每个训练示例分三步绘制掩码。首先，连续模态（轨迹、注视、视频）的非空子集保持可用；其他模态从输入中丢弃，损伤标签始终可用。其次，可用模态的非空子集被加噪。它必须至少包括一个被解码的模态，并且可以包括损伤标签，因此一个示例训练以标签为上下文的重建、标签预测或两者兼有。第三，噪声连续模态共享一个长度为 4-12 秒的连续窗口 T_ξ，以相等概率选择在片段结束处结束（未来预测）或位于片段内部（插值）。T_ξ 内的 token 被加噪，损伤标签在被加噪时对整个片段被掩码。

损失。 轨迹和注视使用 L1 损失 L_traj 和 L_gaze 训练，计算其目标（轨迹为 a 和 ω，注视为 ψ 和 ϑ）的预测值和真实值之间的差异，在噪声 token 上平均；L_traj 添加单独在自车上计算的相同项。损伤损失 L_imp 是每种损伤类型掩码标签上的二元交叉熵（BCE），在片段的 token 上平均。它将该损伤与基线片段进行比较，正类权重等于负训练片段与正训练片段的比率。总损失为

L = L_traj + L_gaze + λ L_imp，λ = 10，(3)

其中 L_imp 对每种损伤类型的损失取平均。掩码采样、损失加权和实现的更多细节见补充材料。

4.1 贡献

概览。 虽然已有包含驾驶损伤的公开数据集（见表 2），但 DIVERT 旨在涵盖广泛的损伤类别，同时保持一致的丰富模态，提供可复现的驾驶环境和危险，并为训练多模态深度模型提供充足的规模。DIVERT 包含在 CARLA [24] 中从 109 名参与者收集的 103.3 小时模拟器驾驶数据。它涵盖十种"诱导"技术下 46.42 小时的驾驶，覆盖四个损伤类别——认知分心、挫败和压力、视觉分心和认知负荷。更多信息见补充材料。

数据发布。 DIVERT 包括带损伤标签的同步前向场景视频、车辆轨迹和控制输入——以及面向驾驶员的信号，包括眼动注视和驾驶员认知负荷、疲劳和情绪状态的定期调查。它包括一组六种受控道路危险类别，如停放车辆弹出和闯红灯者。该数据集将公开提供。

阶段。 数据集分三个"阶段"收集，以下称为阶段 1（自然驾驶）、阶段 2（受损）和阶段 3（危险）。从阶段 1 开始，参与者作为"送货驾驶员"在城镇环境中驾驶，遵循定制的 GPS 应用完成游戏化任务，有机会以"小费"形式获得额外金钱激励，作为重复驾驶 5-10 分钟路线（被调查打断）的动力。阶段 2 在驾驶场景中添加了不同的损伤，阶段 3 添加了危险。

驾驶场景。 参与者被分配到三个收集阶段之一（被试间），并在该阶段内完成一系列约 5-15 分钟的驾驶场景——从阶段 2 开始，每个场景在不同的基线或受损条件下（被试内）。

诱导。 损伤诱导参考了先前关于跨领域受损驾驶研究方法的工作 [12]，并分为三组：被动——参与者选择的音乐和广播片段；连续——自动电话、邮箱场景搜索、广播理解、n-back（1-back）任务和婴儿哭泣；以及瞬时——短信弹出、使用模拟内道具的视觉吸附（例如图 3(a)；仅阶段 3），以及道路阻塞的强制 GPS 改道（例如图 3(b)；仅阶段 3）。诱导被构建为次要任务，主要任务是在遵循 GPS 应用的同时驾驶。

危险。 从阶段 3 开始，我们在整个地图中包含了 21 个可能的六类预编程危险（例如图 3(c)）：闯红灯者（4）、正交停放弹出车辆（5）、平行停放弹出车辆（5）、鲁莽驾驶员（1）、截断转弯危险（3）和自车转弯危险（3）。添加危险旨在补充其他阶段中交通行为引起的无意危险，并提供驾驶员受损时发生危险的有趣组合的机会。

4.2 数据收集

方案。 同意后，参与者戴上 EmotiBit [16]，调整模拟器座椅，并完成注视校准。一段视频介绍了 GPS 引导的驾驶任务，并完成了一次练习驾驶。在阶段 2 和 3 中，参与者还观看了解释路线计时器和性能"小费"的视频，并观看了介绍次要任务的视频。每个实验块遵循相同的结构：参与者驾驶基线路线，观看场景的次要任务视频（仅阶段 2 和 3），驾驶 GPS 引导的路线，并完成调查，包括晕动症检查、简化版 NASA 任务负荷指数（NASA-TLX）[36]、卡罗林斯卡嗜睡量表（KSS）[79] 和正负情绪量表（PANAS）[86]。块重复直到所有场景完成，随后是汇报（阶段 2 和 3）和报酬。

4.3 数据集统计

人口统计。 三个收集阶段共 109 名完成参与者（阶段 1 n=25，阶段 2 n=35，阶段 3 n=49），参与者年龄从 21 到 66 岁（平均 37.7 岁，标准差 10.7 岁）。

任务负荷。 为检查我们的损伤在心理上是否可察觉，我们比较了 NASA-TLX 分数在不同损伤类型与每个参与者基线驾驶平均值之间的差异。我们使用带 Holm 校正的配对 t 检验。N-back（+5.0，p<.001，dz=1.94）和广播理解（+2.5，p<.001，dz=0.98）提高了整体工作负荷。其他损伤有较小的、特定维度的影响，在整体分数中无法检测到。强制改道增加了时间压力（+2.3，p=.013），婴儿哭泣增加了挫败感（+2.5，p=.013），电话和场景搜索增加了身体需求（+1.3，p=.034；+1.4，p=.016），音乐降低了挫败感（−1.2，p=.020）。这些结果支持诱导是有效的，并且在施加的需求类型和强度上有所不同。完整分析结果见补充材料。

标签、片段和折。 出于评估目的，我们将基线驾驶和被动任务视为负样本（统称为基线片段），连续损伤视为正样本。瞬时损伤用作无标签数据，因为其标签取决于片段在场景中的位置以及事件触发的时间。我们遵循 IDD [30] 专注于 30 秒片段。DIVERT 被分为五个参与者不相交的折，按阶段分层，IDD 使用提供的折。我们选择三个折作为训练，一个作为验证，一个作为测试。预测损伤时，所有其他模态作为干净输入提供。验证数据用于使用基线片段对每个二元头的 logit 进行 Z 归一化，并选择最大值作为样本的整体损伤水平。我们从训练和评估中排除 DIVERT 练习驾驶和阶段 1 数据，因为它们不包含任何损伤标签。

自监督的效果。 移除重建损失并仅在损伤头上训练，在 DIVERT 上将 P-AUC 从 0.706 降低到 0.590，I-AUC 从 0.728 降低到 0.603（Δ −0.116 和 −0.125），在 IDD 上从 0.744 降低到 0.689，从 0.691 降低到 0.635（Δ −0.055 和 −0.056）。在两个数据集的每个测试折上均较低，在 DIVERT 上每折低 0.08-0.20。因此，行为模态的掩码重建提供了仅标签监督无法提供的有价值训练信号。

哪些损伤被混淆。 损伤形成两组：场景搜索与所有其他损伤分离（0.89-0.92），而 n-back、电话、婴儿哭泣和广播理解难以区分（0.55-0.63；例外是 n-back 对婴儿哭泣为 0.68，仅基于 314 对）。这些组遵循任务的需求。场景搜索是一项将视线从道路上拉开的视觉任务，而其他四项是认知任务，在没有相应视觉需求的情况下加载注意力。相对于基线片段，场景搜索（0.91）被最清晰地检测到，n-back（0.83）和广播理解（0.70）在认知任务中得分最高。电话（0.64）和婴儿哭泣（0.60）与基线片段的区分仅略好于它们彼此之间的区分。

6 结论

我们提出了 ID-MAE，一种联合建模损伤、注视、轨迹和视频的多模态掩码扩散自编码器，以及 DIVERT，一个包含 109 名驾驶员在十种损伤诱导下的驾驶模拟器数据集。我们展示了损伤检测等微妙、数据受限的任务如何利用来自相邻任务的监督，将配对检测从 0.590 提高到 0.706 AUC，同时还实现了注视和轨迹预测。DIVERT 中的损伤和危险开辟了我们渴望探索的几个方向：以更低延迟检测损伤，分析损伤如何影响危险下的行为，以及通过进一步注释和建模研究语言的作用。
