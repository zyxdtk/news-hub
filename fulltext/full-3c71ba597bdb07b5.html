摘要

异构团队中的智能体可以通过协作完成超出其个体能力的任务。只要生成模型在智能体协作的演示数据上训练过，就可以用它生成协作任务的团队轨迹。然而，协作演示的获取成本高昂，而且对于团队从未执行过的任务，此类演示可能根本不存在。但智能体能够组合其能力的条件是团队的物理属性，在收集任何演示之前就已知晓。我们将这些条件编码为对团队轨迹的约束，并在从仅基于单个智能体演示训练的生成模型中采样时施加这些约束。我们证明，尽管演示中不包含任何协作，所提方法仍能生成所有满足约束的团队轨迹。因此，约束决定了哪些团队轨迹可以被生成，而演示决定了每条团队轨迹被生成的可能性。在两个协作任务上的数值结果验证了该方法的有效性：它生成的协作团队轨迹满足约束，且当智能体加入或离开团队时无需重新训练。最后，我们在多机器人测试平台上实现了该方法。

关键词

多智能体系统、协作机器人、能力组合、规划与学习的集成

1 引言

协作使团队中的智能体能够完成超出其个体能力的任务。多智能体团队中的协作早已被广泛研究，从任务分配与调度 [1, 2] 到多个机器人作用于同一物体的控制 [3, 4]。现有方法假设团队的能力是预先指定的，连同每种能力可使用的条件一起。然而，任务所需的能力取决于智能体部署的环境，而在训练智能体时环境往往是未知的。任务可能需要一种任何单个智能体都不具备的能力，而智能体只能通过组合各自的个体能力来获得这种能力。因此，所需的协作既无法预先指定，也无法预先演示，为该任务生成协作行为仍然是一个挑战。

生成模型，尤其是扩散模型，是生成单个智能体 [5, 6] 或团队 [7, 8] 轨迹的有效方法，前提是演示数据中包含所需的行为。

为克服这一局限，我们观察到智能体能够组合其能力的条件源自团队的物理特性。因此，这些条件可以在没有任何演示的情况下写成对团队轨迹的约束。然后，我们从仅基于单个智能体演示训练的生成模型中采样团队轨迹，并在采样过程中使用引导方法 [9, 5] 施加约束。由此得到一种从基于非协作演示预训练的模型中采样协作团队轨迹的方法。

相关工作。 任务分配与调度决定哪个智能体在何时执行哪个任务 [1, 2]，然后由轨迹规划器实现该决策。我们直接从扩散模型中采样轨迹，并从结果中读出协作模式，无需预先计算任何内容。一类多智能体扩散规划器在存在协作演示之处基于协作演示进行训练 [7, 8]，但只能复现那些演示中包含的协作。另一类基于单机器人数据训练，并通过搜索 [10] 或投影 [11] 来协调所得的规划。这些方法通过交集来组合约束，例如用于避障。我们则通过并集来组合约束，因为协作允许出现任何单个智能体都无法单独到达的构型。协作只在智能体按协作要求进行物理排列时才可用，因此必须将其编码为在轨迹每个时间步都成立的约束。控制屏障函数 [12]（简称屏障）正是编码此类约束的工具。屏障使轨迹保持在其定义的集合内。屏障的布尔组合给出容许集合的交集与并集 [13, 14]。在生成方面，屏障已被用于将扩散样本保持在安全集合内 [15]，以及用随噪声下降而收紧的收缩条件来引导采样 [16]。屏障还能使流匹配采样器安全化 [17, 18]。在多智能体系统中，引导可以分布式实现，使每个智能体计算自己基于 Lyapunov 的引导输入 [19]。

贡献。 我们的贡献如下。第一，我们将无协作演示的协作轨迹生成问题表述为屏障引导的扩散采样，其中的约束编码了智能体的个体能力与协作能力。第二，我们提出一种方案，将针对每个智能体独立训练的分数求和构成乘积先验，并证明该和是乘积在每个噪声水平下的精确分数，因为不同智能体的密度依赖于不相交的变量集合。第三，我们证明采样器能以非零概率生成每条满足约束的团队轨迹，且当其引导在每一步都成功时，不会生成其他轨迹。因此，约束允许的每种协作模式都可以被生成，且没有任何模式被指定或预先计算。第四，我们在渡河任务上（仿真和 Robotarium 平台上）演示了该方法。生成的轨迹以协作方式渡河，而仅从先验采样得到的智能体则互相忽略并导致任务失败。我们还表明，当智能体加入或离开团队时，采样器无需重新训练即可生成轨迹。最后，我们考虑了一个协作还需要定时配合的任务。采样器在没有演示的情况下生成了此类轨迹，但频率低于渡河任务。采样器的大多数失败与屏障的局部极大值一致。

2 问题表述

考虑一个由 N 个智能体组成的团队，其状态为 x_i ∈ ℝ^{n_i}，输入为 u_i ∈ ℝ^{m_i}，按离散时间演化：

x_i(t+1) = f_i(x_i(t), u_i(t)), t = 0, …, T−1. (1)

令 x = (x_1, …, x_N) ∈ ℝ^n 为团队状态，u = (u_1, …, u_N) ∈ ℝ^m 为团队输入，其中 n = ∑_i n_i，m = ∑_i m_i。团队轨迹是矩阵 X = (x(0), …, x(T)) ∈ ℝ^{n×(T+1)}，其行块 X_i ∈ ℝ^{n_i×(T+1)} 对应智能体 i 的轨迹。

在没有协作的情况下，智能体 i 被限制在满足 c_i(x_i, u_i) ≥ 0 的状态和控制上，其中 c_i: ℝ^{n_i} × ℝ^{m_i} → ℝ 是依赖于问题的约束函数。协作扩大了这一集合。令 c_coup,i: ℝ^n × ℝ^m → ℝ 描述与团队其他成员协作时允许的构型，于是智能体 i 的约束集合为

𝒜_i = {(x,u): c_i(x_i, u_i) ≥ 0} ∪ {(x,u): c_coup,i(x, u) ≥ 0}. (2)

当对每个智能体 i 和所有时刻，对 (x(t), u(t)) 都属于 𝒜_i 时，团队轨迹是容许的。协作扩大了容许状态和控制的集合，而动力学 (1) 无论 c_coup,i ≥ 0 与否都保持不变。组合约束集合在安全控制文献中是标准做法 [13]。多机器人规划通过交集来组合它们，因为避障要求规划满足每个智能体的约束，可行集可能因此缩小 [10]。而在 (2) 中，第二个集合依赖于其他智能体，因此 𝒜_i 容许智能体 i 无法单独到达的构型。

任务由依赖于问题的函数 c_task: ℝ^{n×(T+1)} → ℝ 指定，当 c_task(X) ≥ 0 时团队轨迹成功完成任务。我们关注的是任何单个智能体都无法单独完成而团队可以共同完成的任务。这引出以下假设。

假设 2.1（协作是完成任务的必要且充分条件）。每条完成任务的容许团队轨迹 X 都满足：对某个智能体 i 和某个时刻 t，有 c_i(x_i(t), u_i(t)) < 0 ≤ c_coup,i(x(t), u(t))。此外，至少存在一条这样的轨迹。□

假设 2.1 要求，在每条完成任务的轨迹上，某个智能体在某个时间步违反其自身约束 c_i，仅通过耦合约束 c_coup,i 才是容许的。因此，任何每个智能体始终满足自身约束的轨迹都无法完成任务，即协作是必要的。协作也是充分的，因为至少存在一条完成任务的容许轨迹。

图 1：例 1 中车辆约束集合 𝒜_1 所容许的位置，针对船只（方块）的某一位置：由 c_1 确定的陆地（左），由 c_coup,1 确定的距船只 r 以内的区域（中），以及它们的并集（右）。圆盘比河流窄，因此只有当船只靠近陆地时它才能到达陆地。当 c_1 < 0 且 c_coup,1 ≥ 0 时，车辆（圆圈）位于船上。

例 1（渡河）。考虑一个由两个智能体组成的团队：一辆地面车辆和一艘船，在单位正方形环境中运行，该环境被一条宽度为 w 的河流从中间分隔。任务是让车辆到达河对岸的某个位置。车辆不能进入水中，船不能离开水，因此车辆无法单独完成任务。

令 x_i = (z_i, q_i) 为智能体 i 的位置，其中 z_i 和 q_i 分别是其水平和垂直坐标。智能体 i = 1 是车辆，智能体 i = 2 是船，动力学为 f_i(x_i, u_i) = x_i + u_i。

约束函数为

c_1(x_1, u_1) = min(|q_1 − 1/2| − w/2, v^max − ‖u_1‖),

c_2(x_2, u_2) = min(w/2 − |q_2 − 1/2|, v^max − ‖u_2‖),

c_coup,1(x, u) = min(r − ‖x_1 − x_2‖, v^max − ‖u_1 − u_2‖),

且 c_coup,2 处处小于 0，因为协作永远不会让船离开水。因此，当车辆在陆地上且不超过其自身速度限制时 c_1 ≥ 0；当船在水中且不超过其自身速度限制时 c_2 ≥ 0；当两者距离在容差半径 r 之内且车辆相对船的移动速度不超过 v^max 时 c_coup,1 ≥ 0。图 1 展示了这些集合（位置）。因此，车辆只有在乘坐船只时才可能处于水中。当车辆在船上时，其速度限制相对于船适用，因此其速度是船的速度加上一个范数至多为 v^max 的输入。由于 c_coup,2 < 0 使得 𝒜_2 = {(x,u): c_2(x_2, u_2) ≥ 0}，船在任何时候都受 ‖u_2‖ ≤ v^max 约束，且每当车辆距船 r 以内时 ‖u_1‖ ≤ 2v^max。车辆从河一侧的给定位置 x_1^0 出发，船从水上的给定位置 x_2^0 出发，车辆必须到达河对岸的目标 g：

c_task(X) = min(δ − ‖x_1(0) − x_1^0‖, δ − ‖x_2(0) − x_2^0‖, δ − ‖x_1(T) − g‖),

其中 δ > 0 是对这三个位置的容差。□

我们研究以下能力组合问题：给定任务 c_task 和一个由 N 个具有约束集合 𝒜_i 的智能体组成的团队，采样满足 c_task(X) ≥ 0 且对所有 i 和所有 t 都有 (x(t), u(t)) ∈ 𝒜_i 的团队轨迹 X。我们使用去噪扩散模型生成轨迹，该模型是将高斯分布传输到数据分布的动力学系统 [20, 21]。前向过程在扩散时间 τ ∈ [0,1] 上向 X 添加噪声：

dX = −(1/2) g²(τ) X dτ + g(τ) dw, (3)

其中 g > 0 是噪声调度，w 是维纳过程。我们记 p_τ 为 X 在时刻 τ 的密度，因此 p_0 是演示数据的密度，p_1 接近标准高斯分布 𝒩(0, I)。(3) 的系数是标量，因此噪声独立地进入每个坐标。采样是 (3) 的逆过程，从 τ = 1 运行到 τ = 0，按照

dX = f_θ(X, τ) dτ + g(τ) dw, (4)

其中 dw 现在是逆时间维纳过程，漂移项 f_θ 由训练来近似分数 ∇_X log p_τ 的分数网络构建。

我们假设没有可用于训练的协作演示。令 𝒟_i 为智能体 i 单独演示 X_i ∈ ℝ^{n_i×(T+1)} 的集合，p^i 为它们的密度，s_{θ_i} 为在 𝒟_i 上训练的分数网络。团队先验是各智能体密度的乘积 p^⊗ = ∏_i p^i。我们假设每个 𝒟_i 都是在无约束环境中收集的，其中智能体 i 可以自由占据任何状态。因此这些演示可跨任务复用，而 c_i 是任务特定的，在采样时施加。在例 1 中，𝒟_1 和 𝒟_2 分别包含车辆和船的轨迹。

3 主要结果

通过 (4) 生成团队轨迹需要在每个扩散时刻的团队分数，而第 2 节只给我们每个智能体一个分数。令 p_τ^⊗ 表示从 p^⊗ 出发的前向过程 (3) 在时刻 τ 的密度。我们将证明，独立训练的各智能体分数可以精确地给出团队分数。

命题 3.1（智能体分数构成团队分数）。令 p_τ^i 为 X_i 在时刻 τ 的密度。则团队分数中对应智能体 i 的行就是其自身的分数：对每个 τ 和 i，

∇{X_i} log p_τ^⊗(X) = ∇{X_i} log p_τ^i(X_i). (5)

证明。 令 k_τ(X | X_0) 为当前向过程从轨迹 X_0 出发时 X 在时刻 τ 的密度。它在坐标间可分解，因此 p_τ^⊗(X) = ∏_i ∫ p^i(Y_i) k_τ(X_i | Y_i) dY_i，对数将乘积变为和，其第 i 项仅依赖于 X_i。∎

只要乘积中的密度依赖于不相交的变量集合，恒等式 (5) 就成立。前向过程独立地向每个坐标添加噪声，因此它分别平滑每个变量。当密度定义在相同的变量上时（如专家乘积模型），平滑乘积与乘以平滑后的密度并不相同，恒等式只能近似成立 [22]。

用该分数采样 (4) 得到从 p^⊗ 中抽取的团队轨迹，但没有理由认为它们是容许的或能完成任务：各智能体密度是在演示上训练的，不携带任何关于 𝒜_i 或 c_task 的信息。因此必须在轨迹生成过程中施加约束。

遵循 [16]，我们向 (4) 添加控制 u，

dX = [f_θ(X, τ) + u] dτ + g(τ) dw, (6)

并在每一步选择 u，使标量屏障沿采样轨迹保持非负。屏障编码了第 2 节指定的所有约束。采样器只生成状态轨迹，而约束函数还依赖于输入。因此我们假设，对每个智能体 i 和状态 x_i，(1) 中的映射 u_i ↦ f_i(x_i, u_i) 是单射的，因此 u_i(t) 是将 x_i(t) 转移到 x_i(t+1) 的唯一输入。在例 1 中，u_i(t) = x_i(t+1) − x_i(t)。因此沿轨迹的约束仅是 X 的函数。容许性是对智能体和时间的交集，而 (2) 是并集：

min_{i,t} max{c_i(x_i(t), u_i(t)), c_coup,i(x(t), u(t))} = h_comp(X), (7)

因此当轨迹容许时 h_comp ≥ 0。驱动限制不需要单独的项，因为 (2) 已经在 c_i 中携带了每个智能体的驱动限制，在 c_coup,i 中携带了耦合状态下的限制。屏障于是成为

h(X) = min{h_comp(X), c_task(X)},

集合 𝒞 = {X: h(X) ≥ 0} 恰好包含完成任务的容许团队轨迹。

[16] 的采样器在网格 τ_K > ⋯ > τ_0 = 0 上以步长 Δτ_k = τ_k − τ_{k−1} 模拟 (6)：

X_{k−1} = X_k − [f_θ(X_k, τ_k) + u_k] Δτ_k + g(τ_k) √(Δτ_k) ζ_k, (8)

从 X_K ∼ 𝒩(0, I) 到返回的轨迹 X* = X_0，其中 ζ_k 是独立的高斯增量。控制使用松弛屏障 h̃(X, τ) = h(X) + ϵ(X_K, τ)，其裕度是连续的、关于 τ 非减的、在 τ_0 处为零，并在 τ_K 处等于 max{0, −h(X_K)}，因此 h̃(X_K, τ_K) ≥ 0。在每一步先抽取 ζ_k，然后选择 u_k 使得

h̃(X_{k−1}, τ_{k−1}) ≥ (1 − αΔτ_k) h̃(X_k, τ_k), (9)

其中 α > 0 且 αΔτ_k ≤ 1。如果 (9) 在每一步都成立，则 h̃ 保持非负，且对噪声的每个实现都有 h(X) ≥ 0 [16]。在这种情况下，X 是容许的并完成任务，且根据假设 2.1，在某个时间步某个智能体违反其自身约束 c_i，仅通过其耦合约束 c_coup,i 才是容许的。

令 X_{k−1}(u) 表示在 u_k = u 且噪声 ζ_k 已抽取时 (8) 给出的状态，因此 (9) 通过 h̃(X_{k−1}(u_k), τ_{k−1}) 依赖于 u_k。在点 X̄ 处线性化 h̃(·, τ_{k−1}) 得到条件

h̃(X̄, τ_{k−1}) + ⟨∇h̃(X̄, τ_{k−1}), X_{k−1}(u) − X̄⟩ ≥ (1 − αΔτ_k) h̃(X_k, τ_k), (10)

该条件关于 u 是线性的，因此满足 (10) 的最小范数控制有闭式解。[16] 的采样器取 X̄ = X_k 时的最小范数控制。如 [16] 所指出的，线性化误差关于位移 X_{k−1} − X_k 是二次的，而位移由噪声项 g(τ_k) √(Δτ_k) ζ_k 主导。因此误差的阶为 g(τ_k)² Δτ_k，与 (9) 允许的下降同阶。因此，在 X̄ = X_k 处满足 (10) 的控制可能违反 (9)，保证随之丧失。

为克服这一局限，我们使用 [16] 的采样器并做三处修改。第一，松弛屏障在正在形成的轨迹的估计上求值，而不是在迭代点本身上求值，因为在逆过程的大部分时间里迭代点被噪声主导，几乎不携带采样器将返回的轨迹的信息。该估计是从 X_τ 对 X_0 的最佳仿射估计，由下文引理 3.2 给出。第二，每当无引导更新满足 (9) 时，控制取 u_k = 0，而不是像 [16, 备注 2] 那样取其线性化。第三，当无引导更新违反 (9) 时，我们在局部搜索 u_k。我们首先将 u_k 设为满足 (10) 且 X̄ = X_k 的最小范数控制，如 [16] 中那样。当 (9) 失败时，我们设 X̄ = X_{k−1}(u_k)，即当前控制到达的状态，并从 (10) 重新计算 u_k。如果在 j_max 次迭代内未找到满足 (9) 的控制（这发生在 h̃ 的局部极大值附近，梯度在那里消失），我们用最后一个控制执行该步。此时保证丧失，但返回的轨迹仍可能位于 𝒞 中，因为后续步骤可以再次增大 h̃。因此，算法 1 在返回 X 的同时返回 h(X)。

引理 3.2（返回轨迹的仿射估计）。令 X_0 ∈ ℝ^{n×(T+1)} 为具有均值 μ 和协方差 Σ > 0 的随机变量。令 X_τ 从 X_0 出发按 (3) 演化，并令 a_τ = exp(−(1/2) ∫_0^τ g²(s) ds) 和 σ_τ² = 1 − a_τ²。则

(A_τ, b_τ) = arg min_{A,b} 𝔼‖X_0 − AX_τ − b‖²

由 A_τ = a_τ Σ (a_τ² Σ + σ_τ² I)^{−1} 和 b_τ = (I − a_τ A_τ) μ 给出，因此 M_τ X = A_τ X + b_τ 满足

M_τ X = μ + A_τ(X − a_τ μ). (11)

此外，M_τ 对每个 τ ∈ [0,1] 都可逆，M_0 = I，且当 X_0 是高斯时 M_τ X = 𝔼[X_0 | X_τ = X]。

证明。 方程 (3) 是具有标量系数的线性方程，因此 X_τ = a_τ X_0 + σ_τ ξ，其中 ξ ∼ 𝒩(0, I) 与 X_0 独立，且 σ_τ² = a_τ² ∫_0^τ g²(s)/a_s² ds = 1 − a_τ²。因此 X_τ 的均值为 a_τ μ，协方差为 a_τ² Σ + σ_τ² I，其与 X_0 的互协方差为 a_τ Σ。最小化子为 A_τ = Cov(X_0, X_τ) Cov(X_τ)^{−1} 和 b_τ = 𝔼[X_0] − A_τ 𝔼[X_τ]，由此得到上述表达式。Σ 的特征值 λ_j 为正，A_τ 具有相同的特征向量和特征值 a_τ λ_j / (a_τ² λ_j + σ_τ²) > 0，因此 M_τ 可逆。由于 a_0 = 1 且 σ_0 = 0，故 A_0 = I 且 b_0 = 0。当 X_0 是高斯时，(X_0, X_τ) 是联合高斯的，其条件均值是仿射的且等于 (11)。∎

引理 3.2 只使用 X_0 的均值和协方差，因此 M_τ 可以闭式计算，无需学习。在采样过程中，X_τ 是当前迭代点，M_τ X_τ 是正在形成的轨迹的最佳仿射估计。因此我们令 μ 和 Σ 为乘积先验 p^⊗ 的均值和协方差（从训练集 𝒟_i 估计），并在该估计上求松弛屏障的值，即 h̃(X, τ) = h(M_τ X) + ϵ(X_K, τ)，裕度为 ϵ(X_K, τ_K) = max{0, −h(M_{τ_K} X_K)}。[16] 的定理 4.2 是针对屏障 h(X) + ϵ(X_K, τ) 陈述的，它可以用相同的证明推广到上面修改后的 h̃。裕度给出 h̃(X_K, τ_K) ≥ 0，且如果 (9) 在每一步都成立，则由归纳法，对每个 k 都有 h̃(X_{k−1}, τ_{k−1}) ≥ (1 − αΔτ_k) h̃(X_k, τ_k) ≥ 0。由于 ϵ 在 τ_0 处为零且 M_0 = I，h(X) = h̃(X_0, τ_0) ≥ 0，因此 X ∈ 𝒞。在我们的实现中，(9) 的右端被替换为其与 0.15 + ϵ(X_K, τ_{k−1}) 的最小值，使得一旦轨迹深入 𝒞 内部，引导就停止作用。右端保持非负，上述论证仍然适用。

算法 1 屏障引导采样，修改自 [16]

接下来我们刻画扩散采样器能够生成的轨迹类型。特别地，我们证明任何完成任务的容许团队轨迹都可以以任意精度和非零概率被生成，即使训练集中不包含此类轨迹。为此，我们做以下技术假设。

假设 3.3（单调可达性）。对每个 X ∈ 𝒞 和 s ≤ 0，存在 X′ 满足 h(X′) = s，以及一条从 X′ 到 X 的连续路径，沿该路径 h 非减。□

假设 3.3 要求 𝒞 中的每条轨迹都可以从下方到达而不降低 h。当 𝒞 中的某条轨迹位于被 h 的更高值包围的区域中，使得沿每条从较低水平集到达它的路径 h 先增后减时，该假设失效。它只涉及 h，而不涉及先验或数据。对于 X ∈ ℝ^{n×(T+1)} 和 ρ > 0，B(X, ρ) 表示在 Frobenius 范数下以 X 为中心、半径为 ρ 的开球，supp(μ) 表示分布 μ 的支撑，即概率为一的最小闭集。

定理 3.4（𝒞 中的每条轨迹都可以被生成）。设假设 3.3 成立，f_θ 和 h 连续，𝒞 为 {X: h(X) > 0} 的闭包，μ 为算法 1 返回的轨迹 X* 的分布。则对每个 X̄ ∈ 𝒞 和每个 ρ > 0，都有 μ(B(X̄, ρ) ∩ 𝒞) > 0。此外，如果 (9) 在每一步都成立，则 supp(μ) = 𝒞。

证明。 固定满足 h(X̄) > 0 的 X̄ 和 ρ > 0，令 ρ′ ∈ (0, ρ] 使得 h 在 B(X̄, ρ′) 上大于 0，该球存在是因为 h 连续。假设 3.3 与任意 s < 0 给出轨迹 Ŷ_K 满足 h(Ŷ_K) = s，以及一条从 Ŷ_K 到 X̄ 的连续路径，沿该路径 h 非减。令 X̂K = M{τ_K}^{−1} Ŷ_K。在 X̂K 处裕度为 ϵ(X̂_K, τ_K) = −s，因此 h̃(X̂_K, τ_K) = 0，且由于 ϵ 在 τ_0 处为零且 h(X̄) > 0，有 ∑{k=1}^K [ϵ(τ_k) − ϵ(τ_{k−1})] = −s < h(X̄) − h(Ŷ_K)，因此该路径存在点 Ŷ_K, …, Ŷ_0 = X̄ 满足

h(Ŷ_{k−1}) − h(Ŷ_k) > ϵ(τ_k) − ϵ(τ_{k−1}). (12)

令 X̂k = M{τ_k}^{−1} Ŷ_k，由于 M_0 = I，有 X̂0 = X̄，且 h̃(X̂_k, τ_k) = h(Ŷ_k) + ϵ(τ_k) 随 k 减小而严格增加。由于 h̃ 在 X̂_K 处为零，它在每一步都非负，且由 (12) 它严格增加。因此从 X̂_k 到 X̂{k−1} 的无引导更新严格满足 (9)，算法 1 在那里设 u_k = 0。递归 (8) 将 g(τ_k) √(Δτ_k) ζ_k 加到由 X_k 和 u_k 决定的项上，且 g(τ_k) > 0，因此恰好有一个增量 ζ_k 将 X̂k 带到 X̂{k−1}，且 (X̂_K, ζ{1:K}) 返回 X̄。屏障 h̃ 连续且 (12) 是严格的，因此对 k 的归纳给出在 (X̂_K, ζ*{1:K}) 的一个邻域上每一步都有 u_k = 0。那里的递归是无引导的，因此连续，且更小的邻域被带入 B(X̄, ρ′)。该邻域在高斯初始化和增量下具有正概率，因此 μ(B(X̄, ρ) ∩ 𝒞) ≥ μ(B(X̄, ρ′)) > 0。若 h(X̄) = 0，则 B(X̄, ρ/2) 包含满足 h(X′) > 0 的轨迹 X′，因为 𝒞 是 {h > 0} 的闭包，且由 B(X′, ρ/2) ⊆ B(X̄, ρ) 可得结论。最后证明第二个结论。如果 (9) 在每一步都成立，则由引理 3.2 之后给出的 [16, 定理 4.2] 的推广，对噪声的每个实现都有 h(X_0) ≥ 0，因此 μ(𝒞) = 1。由于 h 连续，𝒞 是闭集，因此 supp(μ) ⊆ 𝒞。反向包含 𝒞 ⊆ supp(μ) 是第一个结论，因为 𝒞 中每个点周围的每个球都具有正概率。∎

接下来我们问哪些智能体在何时协作。令智能体 i 仅通过其耦合约束才容许的时刻为

S_i(X) = {t: c_i(x_i(t), u_i(t)) < 0 ≤ c_coup,i(x(t), u(t))}, (13)

我们称 S(X) = (S_1(X), …, S_N(X)) 为 X 的耦合模式。𝒞 中具有模式 S 的轨迹构成集合 𝒞_S = {X ∈ 𝒞: S(X) = S}，这些集合划分了 𝒞。采样器以非零概率返回每条严格满足约束的轨迹的耦合模式。

推论 3.5（每种耦合模式都可能出现）。设定理 3.4 的假设成立，且 X 满足 h(X) > 0，并且对每个 t 和 i，要么 c_i(x_i(t), u_i(t)) > 0，要么 c_i(x_i(t), u_i(t)) < 0 < c_coup,i(x(t), u(t))。则采样器以非零概率返回 𝒞 中具有 X 的耦合模式的轨迹，即 μ(𝒞_{S(X)}) > 0。

证明。 假设中的不等式是严格的，且 c_i、c_coup,i 和 h 连续，因此存在 ρ > 0 使得 B(X, ρ) 中的每条轨迹都满足这些不等式且 h > 0。由 (13)，耦合模式在整个 B(X, ρ) 上都是 S(X)，且定理 3.4 给出 μ(𝒞_{S(X)}) ≥ μ(B(X, ρ) ∩ 𝒞) > 0。∎

约束函数 c_i、c_coup,i 和 c_task 决定了 𝒞。由定理 3.4，采样器可以返回 𝒞 中的每条轨迹，其概率由演示决定。约束不规定耦合模式，因为只要 c_i ≥ 0 或 c_coup,i ≥ 0， 就属于 𝒜_i。因此 𝒞 包含具有不同耦合模式的轨迹，推论 3.5 给出每种模式被采样的正概率。最后，由命题 3.1，每个智能体向乘积先验贡献自己的分数，而约束仅通过引导进入。因此，添加或移除智能体只改变约束函数和乘积中的分数集合，无需重新训练任何网络。

采样器返回 𝒞 中轨迹的概率取决于 (9) 能否在每一步得到满足，因为 (9) 在每一步成立保证了返回的轨迹位于 𝒞 中。算法 1 沿 h̃ 的梯度局部搜索这样的步。由于 (7) 中的 h_comp 是每个并集的两个集合上的最大值，h 可能存在 h < 0 的局部极大值，到达此类点的搜索可能找不到满足 (9) 的步，即使 𝒞 非空。基于控制屏障函数的控制器也有同样的局限，因为它们的二次规划可能在非预期点上停滞 [23]。编码集合并集的最大值 [13] 增加了此类点。

团队变化时采样器无需重新训练。我们添加第二艘也能载车辆的船，使 (2) 中的 𝒜_1 增加第三个集合。两艘船使用相同的分数，c_task 固定每艘船的初始位置，新船从水上距 x_2^0 为 0.2 处出发。为该团队生成的所有 500 条轨迹都位于 𝒞 中，其中 127 条中车辆从一艘船转移到另一艘。对于三辆车和三艘船，所有 500 条轨迹都位于 𝒞 中。它们展示了 144 种不同的耦合模式，而无先验的轨迹优化的 100 个解中只有 12 种。移除智能体的方式相同，除非剩余团队无法完成任务。例如，没有船时，假设 2.1 失效，没有轨迹位于 𝒞 中。

我们在 Robotarium [24] 上实现了渡河任务，这是一个由独轮机器人在 3.2 米 × 2 米场地中组成的测试平台。例 1 的单位正方形被映射到场地中边长为 2 米的正方形，轨迹的每个时间步在 1.2 秒内执行。机器人有物理尺寸，因此我们更改约束函数而保留网络和采样器。河流加宽到 80 厘米，r 增大到 32 厘米，使两个机器人能容纳在彼此 r 范围内，同时 2r < w 仍迫使船载着车辆。我们还添加了两个仿真中不需要的约束。第一个要求每对机器人保持至少 20 厘米的距离，以避免机器人碰撞。第二个要求每个机器人保持在场地内。最后，在每个时间步都成立的约束仍可能在两个相邻时间步之间被违反，因此我们对它们之间的整个线段施加每个约束。我们称之为 Robotarium 设置。

算法 1 将每条轨迹都置于 𝒞 中，无论是一艘船还是两艘船。每个机器人通过 Robotarium 从单积分器到独轮机器人输入的映射跟踪其采样位置，因此非完整约束仅表现为跟踪误差。我们执行了单船的前 15 条轨迹和双船的前 5 条轨迹。所有 20 次运行在跟踪误差范围内满足约束，误差保持在 5 厘米以下。图 4 展示了一次双船运行，其中一艘船将车辆移交给另一艘。

在第二个任务（密室逃脱）中，协作还需要定时配合。两个智能体从带门洞的墙的一侧出发，都必须在时间范围结束前到达另一侧的出口。当在 t−1 时刻有某个智能体位于墙前的踏板上或门洞中时，门在时刻 t 是打开的。智能体 i 的状态由其当前和先前位置 p_i 和 p_i^− 组成，因为门依赖于前一步。

令 W 为门关闭时的墙，W_s ⊂ W 为其实体部分，因此 W ∖ W_s 是门洞，P 为踏板，d_S 为到 S 的带符号距离（在 S 外为正）。则

c_i(x_i, u_i) = min{d_W(p_i), v^max − ‖u_i‖},

c_coup,i(x, u) = min{d_{W_s}(p_i), o(x), v^max − ‖u_i‖},

o(x) = max_j ω(p_j^−),

ω(p) = max{−d_P(p), min{d_{W_s}(p), −d_W(p)}},

其中当 p 在踏板上或门洞中时 ω(p) ≥ 0，因此当门打开时 o(x) ≥ 0。任务函数 c_task 要求每个智能体从距其初始位置 δ 以内处出发，并在距出口 δ 以内处结束。墙比一步厚，踏板距门洞超过一步，因此单个智能体无法通过。两个智能体可以：一个站在踏板上，另一个进入门洞然后扶住门。两个智能体使用相同的分数网络，该网络在无墙房间中记录的 4000 条单智能体轨迹上训练。

需要定时配合的协作更难生成。在密室逃脱中，算法 1 生成的轨迹约有 30% 位于 𝒞 中，且在每一条中，一个智能体站在踏板上而另一个进入门洞（图 5）。如果没有局部搜索（如 [16] 中那样），则没有轨迹位于 𝒞 中。大多数失败使某个智能体停留在关闭的门前，这与第 3 节讨论的 h 的局部极大值一致。

5 结论

本文研究了在任务需要任何单个智能体都不具备的能力时，如何在没有协作演示的情况下为智能体团队生成轨迹。我们将能力编码为对团队轨迹的约束，并用由约束构建的屏障函数引导从仅基于各智能体训练的扩散模型中的采样。所得采样器可证明地生成每条满足约束的团队轨迹。我们的数值结果表明，采样器生成的协作轨迹满足约束，且当智能体加入或离开团队时无需重新训练。在 Robotarium 上，即使由独轮机器人执行，生成的轨迹在跟踪误差范围内也满足约束。然而，当约束集合复杂时（例如协作还需要定时配合时），现有引导方法可能失败。未来工作包括为复杂约束集合设计引导方法，以及从交互智能体的演示中学习耦合约束。
