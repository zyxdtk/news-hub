Figma 联合创始人：MCP 并非完美协议

📅 2026-09-30 📄 TechCrunch AI 🔗 原文链接

原标题：Figma co-founder Dylan Field thinks MCP is not a perfect protocol

中文摘要： Figma 联合创始人 Dylan Field 在印度首届 Config 大会上宣布 20 个新 MCP 合作伙伴，但同时表示 MCP 并非完美协议，仍有巨大改进空间，且更有利于前沿实验室。他此前在 X 上质疑 Anthropic 未通过 MCP 开放自家资源，并指出“开放与封闭”之争忽视了上下文不对称共享问题。Field 解释称，公司不愿完全开放是因为通过 MCP 暴露的数据越多，被滥用的风险越高，尽管大多数用户并无恶意。

在这家设计公司于印度举办的首届 Config 大会上，公司宣布了 20 个新的 MCP 合作伙伴，包括 Amp、ClickUp、Dia、Junie by JetBrains、Linear、Meta Muse、Mistral、Notion、OpenCode 和 Sarvam Agents。

Field 此前已表达过对 MCP 的疑虑。在此次消息公布的几天前，MCP 的一位联合创始人抱怨 Figma 不支持开源工具 Pi。作为回应的一部分，Field 评论了 Anthropic 未通过 MCP 开放其各种资源一事。

“我觉得很有意思的是，Anthropic（MCP 标准的创造者）并没有公开通过 MCP 创建的 artifacts（产物）及其他云资源，”他在 X 上写道。“这场辩论被框定为开放与封闭之争。显然，所有人都更喜欢开放……与此同时，上下文不对称共享的问题却被忽视了。”

（Field 后来补充说，Figma 计划支持 Pi。）

你能帮我理解一下，为什么你们不通过 MCP 提供各种 Anthropic 资源吗？也许是我遗漏了什么。
— Dylan Field (@zoink)

在一场媒体简报会上，我就这场辩论询问了 Field。这位联合创始人解释说，虽然 Figma 希望保持开放，但他认为 MCP 并不是一个完美的协议。

“我对我们在开放生态系统方面所做的事情感到非常兴奋。我也认为 MCP 不是一个完美的协议，而且我认为它还有巨大的改进空间，”这位联合创始人回应道。“它对前沿实验室（frontier labs）更有利。同时，我也理解网上那些只是想要一个协议、以便在需要时使用自己 Figma 数据的用户，我也希望他们能使用它。”

Figma 的 CEO 表示，公司不想完全开放的原因在于：公司通过 MCP 暴露的数据越多，被滥用的几率就越高。

他还澄清说，虽然大多数用户并不打算以恶意方式使用 MCP 或 Figma 数据，但公司仍然必须考虑这些潜在风险。
