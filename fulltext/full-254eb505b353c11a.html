摘要

在所有可用基准任务的全部查询上评估生成模型的成本极高。因此，模型通常在不同的任务子集和/或给定任务的不同查询子集上进行评估。由此产生的响应集合及相应的（模型，任务）得分矩阵是稀疏且非配对的。本文引入乘积核透视空间（Product Kernel Perspective Space, PKPS），这是一组基于模型嵌入响应的低维表示。PKPS通过比较对相似（而非仅相同）查询的响应，泛化了现有的黑盒生成模型表示方法，因此能够利用稀疏和非配对信息。在理论上，我们证明使用PKPS的基准预测相对于仅使用评估数据中密集和配对部分信息的方法具有查询效率。在实验上，我们展示了基于PKPS的方法在两个大型基准套件上的基准预测中优于基线方法。

1 引言

评估生成模型对于理解其能力是必要的。随着生成模型能力的提升（Wei et al., 2022; Bubeck et al., 2023），其应用范围扩展到更多领域——这往往需要为数学（Hendrycks et al., 2021）、法律（Guha et al., 2023）、金融（Islam et al., 2023）、风险投资（Chen et al., 2025b）和智能体任务（Liu et al., 2024）等创建基准。

当前的基准评测格局相应地非常庞大：仅BIG-bench就包含超过200个任务（Srivastava et al., 2023），HELM在多个版本中跟踪数十个场景（Liang et al., 2023），最近的一个汇编包含了133个不同的前沿模型基准（Zeng and Papailiopoulos, 2026）。

因此，模型很少在所有基准上进行评估：在上述汇编的（模型，任务）对中，仅有23%有报告得分。此外，基准在不断演进（例如，添加查询（Chollet et al., 2025）、刷新以避免污染（White et al., 2025）或子采样以降低成本（Perlitz et al., 2024）），在同一基准上评估的模型可能回答了不同的查询集合。

基准预测试图通过使用现有信息而非仅从新生成的响应计算得分来缓解评估的资源负担。

基准预测有两个主要任务：查询高效评估和（模型，任务）得分补全。

在查询高效评估中，模型回答任务查询的一小部分子集，并从产生的响应预测其在完整任务上的得分。现有的查询高效评估方法需要访问项目级得分（Polo et al., 2024; Hofmann et al., 2025; Li et al., 2024; Bowyer et al., 2026）和/或所有模型都回答过的查询的缓存嵌入响应（Helm et al., 2026），并且在不同模型在不同查询集合上评估的场景中通常无效。

在（模型，任务）得分补全中，模型未回答任务的任何查询，其在该任务上的得分从得分矩阵的观测条目中预测。现有的得分补全方法仅使用聚合得分，并丢弃产生这些得分的项目级响应（Zeng and Papailiopoulos, 2026）。

本文引入乘积核透视空间（PKPS）来直接从稀疏和非配对的响应集合中预测基准得分。我们的贡献可总结如下：

  1. 概念性：我们将两个预测任务统一为单一问题的实例：从先前评估模型的稀疏、非配对响应集合中预测得分。
  2. 方法性与理论性：我们提出PKPS，一组在可能非配对的嵌入响应上定义的模型低维表示，并证明使用PKPS的基准预测至少与仅使用配对响应信息的方法一样具有查询效率（定理2）。
  3. 实验性：我们展示PKPS在查询预算减少8倍的情况下匹配样本得分的准确性，并且当与低秩矩阵补全集成时，将得分矩阵补全误差降低多达28%。我们的实验评估涵盖两个大型基准套件。

1.1 相关工作

基准预测。 我们将基准预测分解为两条先前工作的路线：查询高效基准测试和（模型，任务）得分补全。

查询高效基准测试的方法通过模型对任务查询小子集的响应来预测其在完整任务上的得分——通常通过选择信息丰富的查询子集并通过项目反应理论（Polo et al., 2024; Hofmann et al., 2025）、聚类（Vivek et al., 2024）、保序子采样（Perlitz et al., 2024）、学习获取策略（Li et al., 2024）、项目级得分回归（Bowyer et al., 2026）或模型表示回归（Helm et al., 2026）进行外推。所有先前提出的查询高效基准测试方法隐含地需要项目级得分或参考模型在共同查询集合上的响应。

（模型，任务）得分补全的方法通过跨任务可预测性（Ye et al., 2023）、观测缩放定律（Ruan et al., 2024）或低秩矩阵补全（Zeng and Papailiopoulos, 2026）预测从未评估过的得分矩阵条目。所有方法仅在聚合得分上操作，并丢弃项目级得分或响应中的信息。

我们提出的方法使用来自稀疏和非配对跨任务评估数据的项目级信息来改进两个文献中的方法。

模型的低维表示。 我们处理稀疏和非配对基准预测的方法首先构建模型的低维表示，然后在表示空间中学习简单的回归器。现有的模型表示方法因访问模式而异。例如，在白盒设置中，可以通过比较内部激活（Duderstadt et al., 2023; Huh et al., 2024）和/或权重（Chen et al., 2025a）来诱导表示。评估者不一定有白盒访问权限，而是依赖黑盒方法，如数据核透视空间（DKPS）（Helm et al., 2024; Helm et al., 2025），它基于配对查询集合上嵌入响应矩阵之间的距离构建低维表示。与我们设置最相关的是，Helm et al. (2026)将先前评估模型的基准得分回归到DKPS表示上，并证明预测相对于样本得分具有查询效率。提出的乘积核透视空间通过在查询空间上引入核来泛化这一构造，从而在稀疏和非配对模式下进行比较。

2 基准预测

在我们的设定中，模型是从查询空间到响应空间的随机映射 f: Q → X。任务是一对 (Q^(t), s^(t))，其中 Q^(t) ⊆ Q 是查询集合，M^(t) := |Q^(t)|，s^(t) 是将模型和查询集合映射到非负实数的评分函数。模型 i 在任务 t 上的真实得分为 y_i^(t) := s^(t)(f_i, Q^(t)) ∈ R≥0。

评估数据由（模型，任务，查询）三元组索引：对于 n 个模型 f_1,...,f_n 和 T 个任务 Q^(1),...,Q^(T)，模型 i 对查询 q ∈ Q^(t) 的响应可能已生成并评分，也可能未生成。设 Q_i^(t) ⊆ Q^(t) 为模型 i 的响应（和得分）已被观测的查询集合，m_i^(t) := |Q_i^(t)|，Q_i := ∪_t Q_i^(t)。相应的样本得分 ỹ_i^(t) := s^(t)(f_i, Q_i^(t)) 是 y_i^(t) 的估计。

评估数据在给定任务上很少有模型 m_i^(t) > 0 时是稀疏的。当跨模型查询集合交集 m_ii'^(t) := |Q_i^(t) ∩ Q_i'^(t)| 的大小很小时，它是非配对的。我们设 ρ_ii'^(t) := m_ii'^(t)/m_i^(t) 为给定模型对的共享查询比率，并注意到在高度策划的排行榜中所有对的 ρ_ii'^(t) ≈ 1，而在部署的评估设置中 ρ_ii'^(t) ≈ 0。

基准预测的目标是从可用的评估数据中估计模型的得分。第1节中引入的两个任务是观测计数 m_i^(t) 的两个模式：

  1. 查询高效评估是 m_i^(t) > 0 的情况。其他模型在任务 t 上的响应或得分通常可用。
  2. （模型，任务）得分矩阵补全是 m_i^(t) = 0 的情况。不存在来自目标（模型，任务）切片的响应，预测必须基于模型 i 对其他任务的响应以及其他模型在任务 t 上评估的响应。

3 乘积核透视空间

我们通过基于适当定义的成对距离矩阵构建模型的低维表示，从稀疏和非配对的评估数据中估计 y_i^(t)。

我们假设可以访问每个观测到的（模型，任务，查询）三元组的响应，以及两个嵌入函数 g_Q 和 g_R，分别将查询和响应映射到 R^{p_Q} 和 R^{p_R}。

设 q_1, q_2, ..., q_M 枚举观测到的查询，x_ij 表示嵌入响应 f_i(q_j)，u_j 表示嵌入查询 q_j。

给定查询核 k_Q: R^{p_Q} × R^{p_Q} → R≥0 和响应核 k_R: R^{p_R} × R^{p_R} → R≥0，我们通过计算成对亲和矩阵 A 来比较模型 i 和 i'：

A_ii' = [∑{j∈Q_i} ∑{l∈Q_i'} k_Q(u_j, u_l) k_R(x_ij, x_i'l)] / [∑{j∈Q_i} ∑{l∈Q_i'} k_Q(u_j, u_l)] (1)

每个条目由其自身的查询核质量归一化，因此回答不同数量查询或完全不同查询的模型仍然可比。

我们使用诱导的平方相异度 D²_ii' = A_ii + A_i'i' - 2A_ii' 来捕获模型（不）相似性。

最后，模型的乘积核透视空间表示——ψ̂_1, ..., ψ̂_n——通过经典多维缩放（CMDS）从 D² 获得（Torgerson, 1952; Borg and Groenen, 2005）。即，设 B = -½JD²J，其中 J = I - (1/n)11^T，λ_1 ≥ ... ≥ λ_n 和 v_1, ..., v_n 表示其特征值和特征向量。则

Ψ̂ = [ψ̂1, ..., ψ̂_n]^T = [v_1, ..., v_d] diag((λ_1)+^{1/2}, ..., (λ_d)_+^{1/2}) (2)

使得 Ψ̂Ψ̂^T 是 B 的最佳秩-d半正定近似。当 D² 是维度至多为 d 的欧几里得距离平方矩阵时，CMDS在刚性运动意义下恢复相应的构型（Dokmanić et al., 2015）。

我们注意到PKPS的定义严格泛化了先前的工作，将恒等查询核（k_Q(u,u') = 1{u=u'}）替换为通用查询核。重要的是，对于任何严格正的 k_Q（如RBF），D²_ii' 包含来自非配对响应的信息，因此当 |Q_i|, |Q_i'| ≥ 1 时，公式(1)总是有定义的。

3.1 PKPS表示的集中性

我们接下来建立PKPS的理论性质，这些性质对于证明其在稀疏和非配对基准预测中的效率是必要的。本节的主要结果建立了表示围绕其总体对应物集中，其速率由查询分布的重叠决定。

我们将第2节的评估数据建模为采样的（任务，查询，响应）三元组：在模型 i 的条件下，每个三元组独立地抽取一个任务，然后从任务中抽取一个查询，最后是模型的响应（在附录D的定义2中形式化）。我们在附录D的定义2中正式定义总体PKPS；广义上，它通过将公式(1)中的求和替换为期望来定义。

我们的集中结果需要有界的查询和响应核、有界的嵌入响应、正的跨模型查询核质量，以及总体双中心矩阵第d个特征值之后的间隙（见假设2-4，附录D）。所需的有界性和谱间隙在谱嵌入分析中是标准的（Yu et al., 2015; Acharyya et al., 2024; Acharyya et al., 2025）。我们设置中非典型的要求是正的跨模型查询核质量，尽管这在严格正的 k_Q 下平凡成立，且不假设任何单个查询是共享的。

设 (ψ_1, ..., ψ_n) 表示总体PKPS，κ = inf_{i,i'} E[k_Q(u,u')] 为跨模型查询核质量，λ_d 为总体双中心矩阵 B 的第d大特征值，Δ = λ_d - λ_{d+1} 为其特征间隙，β = ‖B‖_op/Δ。

定理1（PKPS表示的集中性）。 假设假设2-4成立且每个模型至少回答了 m 个查询。则对于任意 δ ∈ (0,1)，以至少 1-δ 的概率，存在正交矩阵 W 使得

max_i ‖ψ̂_i - Wψ_i‖ ≤ Cκ^{-2}λ_d^{-1/2}(1+β) n√(log(4n²/δ)/(2m))

其中 C 仅依赖于核界限。

定理1表明PKPS表示以完全配对DKPS（Acharyya et al., 2025）在 m 中享有的速率集中，而不需要任何共享查询。非配对的代价是 κ^{-2} 的因子，由查询分布的重叠决定。完整证明在附录D中。

3.2 PKPS中的推断

我们接下来描述PKPS中的基准预测并建立其查询效率。

使用PKPS的推断是一个两步统计问题：首先嵌入模型（公式(2)），然后训练一个使用表示作为模型代理的决策函数。

固定任务 t，设 f_0, f_1, ..., f_n 为从模型分布中独立同分布抽取的样本。我们的目标是预测 f_0 在任务 t 上的真实得分 y_0 := s^(t)(f_0, Q^(t))。

m_i^(t) > 0 的（模型，任务）对和模型 f_0 从任务 t' ≠ t 的响应提供了可能与预测 y_0 相关的信息。

我们通过公式(2)联合嵌入所有 n+1 个模型，在观测对 {(ψ̂i, ỹ_i^(t))}{i=1}^n 上拟合回归器 ĥ^(t): R^d → Y，并预测 ŷ_0^(t) = ĥ^(t)(ψ̂_0)。我们注意到公式(1)不使用得分信息，因此目标模型与参考模型一起嵌入。存在样本外扩展（参见Trosset and Priebe, 2008; Chen et al., 2022）。

Helm et al. (2026)建立了使用配对DKPS表示的最近邻回归相对于样本得分具有查询效率。本节的主要结果表明使用PKPS的基准预测相对于配对DKPS具有查询效率。

我们结果的第一部分仅需要有界得分（假设1）。第二部分额外要求没有两个查询设计共享原子，使得独立采样的查询集几乎必然不相交（假设5），模型及其缓存独立抽取（假设6），以及固定预算下总体双中心矩阵类似物的谱间隙（假设7）。所有假设在附录D中陈述。

在下文中，MSE表示均方误差，m表示每模型查询预算，min_i |Q_i| ≥ m。我们假设查询核来自以带宽 σ 为索引的有界核族，其 σ→0 极限使得 k_0(u,u') > 0 当 u=u' 时，否则为0（例如 k_σ(u,u') = exp(-‖u-u'‖²/2σ²)）。

定义1（查询效率；遵循Helm et al., 2026）。 固定每模型查询预算 m，设 h_n 表示使用 n 个参考模型的得分估计器。序列 (h_1, h_2, ...) 相对于 (h'_1, h'_2, ...) 是查询高效的，如果存在 N 使得对所有 n ≥ N，以高概率 MSE(h_n) ≤ MSE(h'_n)，且对至少一个 n* ≥ N 不等式严格成立。

我们写 h_{n,σ}^{(K)} 表示在以带宽 σ 的查询核构建的PKPS上使用K近邻回归器的估计器。由于 k_0 仅在相同查询上放置正质量，h_{n,0}^{(K)} 是配对DKPS上的K近邻回归。设 ĥ_n^{(K)} 表示交叉验证的PKPS估计器（在附录D中指定），其中带宽在留出参考模型上从包含 σ=0 的有限网格中选择。仅当估计的改进超过验证置信半径时才选择非零带宽。最后，设 I_m(σ) 表示由目标模型从其 m 个缓存响应计算的总体表示所解释的目标得分方差（定义3）。

定理2（PKPS相对于配对DKPS具有查询效率）。 固定任意每模型查询预算 m ≥ 1 并假设参考得分被精确观测。 在假设1下，对于每个配对分数 ρ ∈ [0,1] 和每个 K，以高概率对所有足够大的 n，MSE(ĥ_n^{(K)}) ≤ MSE(h_{n,0}^{(K)})。 假设假设1、2、5、6和7成立且网格包含带宽 σ > 0 使得 I_m(σ) > 0。则对于每个 0 < c < I_m(σ) 和每个 K_n → ∞ 且 K_n/n → 0，以高概率对所有足够大的 n，MSE(ĥ_n^{(K_n)}) ≤ MSE(h_{n,0}^{(K_n)}) - c。特别地，(ĥ_n^{(K_n)}) 在每个 I_m(σ) > 0 的预算 m 下相对于 (h_{n,0}^{(K_n)}) 具有查询效率。

定理2表明，在任何固定预算下，PKPS在任何配对水平下都不劣于配对DKPS。当查询集不相交（假设5）时，配对DKPS不能比预测平均得分做得更好，而PKPS通过其预算-m表示解释的得分方差 I_m(σ*) 来改进它。需要某种此类条件：如果模型的缓存响应不携带关于其得分的信息，则从中构建的任何估计器都不会改进均值。

我们注意到查询效率是传递的，定理2与Helm et al. (2026)的定理2一起，暗示 ĥ_n^{(K)} 相对于样本得分具有查询效率。

相同的机制涵盖（模型，任务）得分补全（m_i^(t) = 0）：由于公式(1)仅使用响应，未回答任务 t 任何查询的模型从其对其他任务的响应中嵌入，回归转移在 t 上评估的参考模型的得分。我们在第4节中实证评估查询效率和补全。

4 实验

我们在合成数据和两个大型基准套件上评估PKPS。

合成数据。 我们生成具有潜在能力向量 v_i ∈ R^5 的 n 个模型和具有潜在向量 t_k ∈ R^5 的 T 个任务，得分 v_i · t_k + ε（加性噪声 ε），以及在每个任务中心附近抽取的查询（u_j = t_k + η_j，各向同性噪声 η_j）。每个模型每任务回答 m 个查询。我们通过 ρ = m_ii'/m 控制非配对性，通过观测任务的概率 p_task 和在观测到任务条件下回答查询的概率 p_query 控制稀疏性。

基准套件。 我们考虑两个大型基准套件。

第一个套件由HELM-Lite（Liang et al., 2023）的18个任务组成——7个数学学科（MATH, Hendrycks et al., 2021）、5个翻译对（WMT-14, Bojar et al., 2014）、医学多选（MedQA, Jin et al., 2021）和5个法律学科（LegalBench, Guha et al., 2023）。我们考虑在所有18个任务上评估过的93个模型，并通过子采样每个模型的观测查询来诱导稀疏性和非配对性。

第二个套件由Every Eval Ever数据存储（Batzner et al., 2026）构建，这是一个社区维护的项目级评估结果集合，涵盖36个基准和165个模型（且在增长）。该存储展示了激励本文的稀疏性和非配对性：仅有15%的（模型，基准）对被评估过，59%的模型对完全不共享任何基准。在一个基准内，配对性是双峰的：在33个任务中的26个上，模型回答了基本相同的项目集合（平均 ρ_ii' > 0.99），而其余七个——全部是竞技场风格（Chiang et al., 2024）——严重非配对（平均 ρ_ii' 在0.27到0.66之间）。我们研究一个密集的45模型和16任务子矩阵，以便真实得分可用且稀疏性和配对性可以控制。任务包括MATH-MC级别1-5（Hendrycks et al., 2021）、GSM-MC（Cobbe et al., 2021）、GPQA-Diamond（Rein et al., 2024）、JudgeBench的九个类别（Tan et al., 2025）和RewardBench 2（Malik et al., 2025）。

两个套件都因为包含项目级响应而被选择——大多数大型公共基准排行榜仅包含得分。描述HELM和EEE数据的详细信息（如包含的模型、包含的任务、每个任务的查询数量等）分别在附录A和B中提供。

方法和基线。 我们在查询效率和（模型，任务）得分补全上评估PKPS。除非另有说明，我们通过gemini-embedding-001（Lee et al., 2025）将所有响应和查询嵌入到3072维空间中，分别对嵌入查询和嵌入响应集合应用PCA，并在降维后的查询空间上使用RBF核，在降维后的响应空间上使用线性核。给定PKPS成对相异度矩阵，我们通过公式(2)将模型嵌入到 d=8 维空间中，并使用 K=5 的K近邻回归。

根据任务不同，我们包含不同的基线。每个基线产生 y_i^(t) 的估计：

  1. 查询效率。我们将PKPS与样本得分（即 ỹ_i^(t)）、配对DKPS（Helm et al., 2026）、项目反应理论（"IRT", Polo et al., 2024）以及PKPS和样本得分的凸组合（即 αỹ_i^(t) + (1-α)ŷ_i,PKPS^(t)）进行比较。
  2. 得分补全。我们将PKPS与低秩矩阵补全（"LRMC", Zeng and Papailiopoulos, 2026）以及LRMC和PKPS的凸组合（即 αŷ_i,LRMC^(t) + (1-α)ŷ_i,PKPS^(t)）进行比较。

查询核RBF带宽和集成的凸系数都通过对观测数据的交叉验证来选择。遵循Zeng and Papailiopoulos (2026)，补全方法在预处理的得分矩阵上操作：观测得分经过logit变换、按任务标准化，并通过双向（模型，任务）加性偏差中心化。遵循Helm et al. (2026)，我们使用留一家族协议，其中排除来自目标模型开发者的所有模型。因此，报告的误差是保守的。我们报告每个设置在16个种子（合成数据为50个）上预测得分与真实得分的平均绝对误差（MAE）。其他实验细节在附录A中提供。

5 讨论

本文引入了PKPS，一组在稀疏和非配对嵌入响应集合上定义的模型低维表示——这是高度策划的排行榜和评估集合之外的现实设置。我们证明PKPS相对于其完全配对对应物具有查询效率，并展示随着 ρ→0，配对DKPS急剧退化而PKPS不会。相同的表示支持两个基准预测任务，基于PKPS的方法在两者上都优于基线。

实际部署。 我们的结果建议了一个简单的实际部署工作流程： 维护评估模型时产生的缓存响应（以及可选的每响应得分）； 在缓存响应上拟合PKPS； 在透视空间中用简单回归进行预测，可选地与样本得分集成。随着像Every Eval Ever数据存储这样的共享缓存增长，每次新上传都改进透视空间，累积节省也随之增长。

局限性和未来工作。 随机评分函数。我们的分析假设从响应到其得分的映射是确定性的。许多现代评估框架使用LLM作为评判者的评分（Zheng et al., 2023），其中得分是随机的，可能取决于超出单个响应的上下文因素。如果每个得分采取 s(f(q))+ε 的形式且 ε 独立同分布，则重复评分在极限中恢复当前设置，扩展在概念上是直接的。 超越均匀观测。假设1将观测单元格建模为均匀子样本，我们的实验通过均匀掩码诱导稀疏性和非配对性。部署评估数据中的缺失不是均匀的：哪些模型在哪些基准上评估与开发者、发布日期和预期性能相关。将分析扩展到建模的观测过程是自然且重要的下一步。 多智能体系统中的非配对监控。配对DKPS已被用作跟踪多智能体系统视角的工具（Helm et al., 2024）。这些方法需要每个时间点向每个智能体询问一组固定查询，在大规模时成本过高。PKPS消除了这一要求，因为智能体可以通过它们自然产生的异构交互来监控。

核。 查询核是RBF，其带宽每次运行通过留一模型K-NN（K=8）在观测得分上选择，网格为 σ∈{0.03,0.1,0.3,1,3}×中位数成对查询距离加上近增量（DKPS）极限；附录C显示交叉验证的带宽跟踪最佳固定选择。响应核在真实数据上是线性的，在合成数据上是RBF。每个（模型，查询）对使用一个采样响应（r=1）。

模型嵌入。 模型通过经典MDS（公式(2)）嵌入，全程 d=8，遵循Helm et al. [2026]并先验固定（合成数据上 d=潜在维度）；附录C探讨了 d 的选择。

回归器。 所有嵌入方法使用距离加权K-NN（K=5）回归在模型嵌入上，留一家族拟合：目标开发者的所有模型都从其训练集中排除，因此预测从不依赖近似重复的兄弟姐妹[Helm et al., 2026]。留出单元格直接预测；观测单元格留出自己的目标。对于查询效率，回归目标是参考模型的完整任务得分。对于补全，目标是logit变换、按任务标准化到单位方差和双向（模型+任务）加性偏差后的残差；此流水线与LRMC基线的相同，因此两种方法仅在残差建模方式上不同（透视上的K-NN与低秩分解），性能差异可归因于表示。匹配每任务标准化很重要：没有它，模型偏移被具有最大logit方差的任务主导。

基线。 低秩矩阵补全（LRMC）遵循BenchPress [Zeng and Papailiopoulos, 2026]：logit空间、按任务标准化、双向偏差、秩-2 ALS带岭 λ=0.1，在5个随机初始化上平均；在观测单元格上交叉拟合，因此单元格的预测从不看到自己的样本。IRT是二值任务上的1PL（Rasch）模型[Rasch, 1960]：项目难度通过最大似然（L-BFGS, Liu and Nocedal, 1989）在最大完全观测（模型×项目）块上，每模型能力通过有界标量MLE，截断到[-4,4]。样本基线是单元格自己的 m 查询均值。

集成。 在观测单元格上，预测为 αŷ_sample + (1-α)ŷ_PKPS，标量 α 每个留出家族一个，在21点网格上通过留一家族验证对其他家族的缓存完整得分（回归器训练的相同信息）选择；在缺失单元格上，PKPS和LRMC用通过留出交叉验证对观测得分拟合的权重混合。任何量都不使用被预测家族的得分。

扫描和报告。 所有真实数据扫描使用16个种子；曲线和表条目报告任务上的每种子均值，然后是种子上的均值（±1 SEM）。查询效率：预算 m∈{1,2,4,8,16,32}，完整队列和覆盖率；队列 n∈{10,20,40,60,93}（HELM）或{10,20,40,45}（EEE）和任务覆盖率 p_task∈{0.2,0.35,0.5,0.7,0.9}，两者都在少查询点 m=2。补全：任务覆盖率如上，查询深度 p_query∈{0.1,0.25,0.5,0.75,1.0}，队列线 n∈{10,full}；任务数 T∈{4,8,12,18}（HELM）或{4,8,12,16}（EEE）；队列扫描保持 p_task=p_query=0.5。

统计测试。 方法之间的配对差异用双侧Wilcoxon符号秩检验[Wilcoxon, 1945]在每任务误差差异上评估：对每个任务，我们在模型和种子上平均每单元格绝对误差差异，并测试每任务均值是否为零（HELM上18个任务，EEE上16个）。查询效率测试在 m=1（完整队列和覆盖率）下比较集成与样本得分；补全测试在每个队列大小的中心操作点（p_task=p_query=0.5）比较集成与LRMC。第4.1节中引用的每单元格改进分数从相同的每单元格记录计算，在条件图扫描上汇总。

形式定义和假设。 我们陈述第3节中引用的形式陈述。

定义2（总体PKPS）。 设每个模型 i 的（任务，查询，响应）三元组从设计分布 P_i 独立同分布抽取：每个三元组独立抽取一个任务，然后在任务条件下抽取一个查询，然后是模型的响应。写 z=(u, x_i(u)) 表示嵌入的查询-响应对（包含响应噪声）。总体亲和为

A*_ii' = E[k_Q(u,u')k_R(x_i(u), x_i'(u'))] / E[k_Q(u,u')], z∼P_i, z'∼P_i' 独立

总体平方相异度为 D²(i,i') = A_ii + A_i'i' - 2A_ii'，总体透视 ψ_1,...,ψ_n ∈ R^d（Ψ ∈ R^{n×d} 的行）是双中心矩阵 B = -½JD²J 的秩-d谱嵌入，其中 J = I - (1/n)11^T：Ψ = [v_1,...,v_d]diag(λ_1(B)^{1/2},...,λ_d(B)^{1/2})，取 B 的 d 个最大特征值的特征对。B 不必是半正定的。

假设1（观测模型）。 每个评分函数是有界每查询得分的均值，每个观测单元格 Q_i^(t) 是预算 m 下 Q^(t) 的均匀子样本。

假设2（有界性）。 核和嵌入响应是有界的。

假设3（总体重叠）。 跨模型查询核质量有下界：κ = inf_{i,i'} E[k_Q(u,u')] > 0。

假设4（谱可识别性）。 B 的第 d 大特征值为正且与下一个分离：λ_d(B) > 0 且 Δ = λ_d(B) - λ_{d+1}(B) > 0。

假设5（配对缺失）。 精确匹配核的跨模型质量消失：κ_0 = sup_{i≠i'} E[k_0(u,u')] = 0，对于独立查询 u∼P_i, u'∼P_i'，其中 k_0(u,u') = 1{u=u'}；等价地，没有两个查询设计共享原子。

假设6（独立缓存）。 模型及其查询设计 (f_i, P_i)，i=0,...,n，是独立同分布的，在给定它们的情况下缓存跨模型独立抽取。

总体量。 全文中，定义2的量按那里的陈述使用。由假设2，核是有界的，归一化后 k_Q ∈ [0,1]（例如RBF）且 |k_R| ≤ B_R；由假设4，秩-d谱嵌入存在且 λ_d(B*) > 0。

引理1（亲和集中）。 在假设2和3下，对于 min(|Q_i|,|Q_i'|) ≥ m 的模型 i, i' 和任意 δ ∈ (0,1)，以至少 1-δ 的概率，

前提是 t_m(δ) ≤ κ/2。
