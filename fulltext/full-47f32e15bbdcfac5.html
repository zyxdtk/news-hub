摘要

仅使用预填充阶段隐藏状态来预测大语言模型（LLM）将解码多少 token，是推理调度的关键原语。我们表明，当前基准测试将预测器质量与任务难度混为一谈：当目标模型、数据集或采样配置改变时，即使预测器本身未变，报告的准确率也会崩溃。我们将这种不稳定性追溯到一个被忽视的误差源——自回归解码的固有随机性——并推导出每个预填充侧方法都必须遵守的界限。我们的分析将解码视为一个停止的随机过程。响应的每步停止概率并非恒定，而是在数百步内逐渐上升，因此解码长度从决定响应结束位置的众多局部决策中继承了中心极限定理；这产生了带有显式误差项的逐提示正态性，以及仿射方差律 σ = αμ + b，其斜率是响应段数的变异系数。在经验上，正态律在几个百分点内再现了逐提示 MAE 和解码长度分布的中心质量，而与正态性的残余偏差（轻度右偏、轻微超额峰度）正是采样噪声修正所预测的。在固定的模型、数据和采样条件下，广泛的预测器设计空间（MLP、EGTP、FiLM、软标签和混合专家变体）收敛到接近界限的相似性能，证实了系统误差主导模型误差。我们主张建立一个固定模型、数据和采样参数的基准测试协议，并在绝对指标之外报告相对误差指标。代码和分析工具可在 https://github.com/ShwStone/DecodingPredict 获取。

1 引言

大语言模型（LLM）推理由两个不同的阶段组成：并行处理输入提示的计算密集型预填充阶段，以及自回归生成输出 token 的内存密集型解码阶段（Kwon et al., 2023; Yu et al., 2022）。由于解码阶段主导端到端延迟和能耗（Zhong et al., 2024），在解码开始之前知道将解码多少 token，对于批处理调度、PD 分离和资源调配极为宝贵（Shahout et al., 2024; Qiu et al., 2024; Zheng et al., 2023）。

出于这一需求，越来越多的工作提出从预填充阶段信息预测解码长度。早期方法在表面特征上训练外部代理模型（Qiu et al., 2024）。较新的方法复用目标 LLM 自身的内部激活：Shahout 等人（2024）使用中间层嵌入来调度请求；Piotrowski 等人（2025）在逐层隐藏状态上构建图卷积回归器；并发的 EGTP 框架（Xie et al., 2026）在即时隐藏状态上引入熵引导 token 池化（EGTP），在最新发布的 ForeLen 基准上取得了最先进的结果。

公平性问题。 尽管有这些进展，我们观察到已发表的数字难以比较。一个预测器在 ForeLen 长序列分割上使用 Qwen2.5-7B 可达到 MAE ≈ 80，但同一架构在 ShareGPT 上使用 Qwen3-32B 时退化到 MAE > 150，或在 RL 采样数据上退化到 MAE > 260。根本原因是自回归生成的固有随机性——而非预测器设计——是主导误差源。当一个查询具有高解码长度方差时，没有预填充侧预测器能够高精度地预测单一确定性长度，因为长度本身就是一个随机变量。

我们的贡献。 我们做出三项贡献。

  1. 误差来源的理论。 我们将解码建模为具有非常数风险率的停止时间，并证明解码长度渐近正态，带有显式的 Berry–Esseen 误差项（§3）。同样的分析产生了仿射方差律 σ = αμ + b，并将拟合斜率识别为响应段数的变异系数。然后我们从正态律推导出对每个预填充侧预测器都成立的界限，包括锐化的 MAE 和通过率界限，以及将超额风险精确分解为系统项和模型项。

  2. 经验验证，包括定律失效之处。 在 300 个 ShareGPT 提示（每个 200 次解码）上，我们针对界限实际使用的量测试正态近似：逐提示 MAE 与高斯值 σ√(2/π) 的匹配在 1.9% 以内，中心质量匹配在两个百分点以内（§4）。与正态性的残余偏差（中位偏度 +0.27，超额峰度 +0.35）正是我们分析的采样噪声修正所预测的。我们还确认 σ 遵循关于 μ 的仿射律，其系数 (α, b) 在模型和后训练配方之间显著变化（表 1）。

  3. 架构无关的评估。 我们在固定的模型、数据和采样设置下，对广泛的预测器设计进行基准测试——拼接隐藏状态上的 MLP 回归、EGTP 风格的熵池化、FiLM 条件化、软标签分类和 MoE 路由。所有方法都收敛到接近理论界限的相似性能（§5）。

最后，我们认为现有的基准如 ForeLen 将预测器质量与任务难度混为一谈，我们建议一个在绝对指标之外同时报告相对误差指标的受控评估协议（§6）。

2 预备知识和相关工作

问题表述。 设提示 x 被分词为 x₁:ₗ，并设 𝐡^(l)₁:ₗ 表示在预填充期间计算的层 l 的隐藏状态，其中 l ∈ [L_model]。设 Y 为模型发出序列结束（EOS）token 之前解码的新 token 数量，并设 ŷ = f(x, {𝐡^(l)₁:ₗ}ₗ) 为仅使用预填充可观测信息的 Y 的估计。

指标。 遵循先前工作（Xie et al., 2026），我们报告平均绝对误差（MAE = (1/N)∑ᵢ|ŷᵢ − Yᵢ|）和容差 τ 下的通过率准确率：

acc@τ := Pr(|ŷ − Y| < τ)，　(1)

即预测误差低于 τ 个 token 的测试提示比例。我们报告 acc@100、acc@200、acc@500 和 x(p90)，即使 acc@τ ≥ 90% 成立的最小 τ。

特征提取。 大多数基于嵌入的方法将逐层隐藏状态池化为固定维度的向量。常见的策略是在层和 token 上进行平均池化、取最后一层的最后一个 token，或拼接所有层（Shahout et al., 2024; Xie et al., 2026）。与先前关于句子嵌入的观察一致（Jiang et al., 2023; Lei et al., 2024），我们发现拼接所有层为该任务提供了最丰富的表示。

EGTP 和 ForeLen。 Xie 等人（2026）提出熵引导 token 池化（EGTP），它从下一个 token 分布计算每个 token 的熵 Hᵢ，并使用 softmax(H) 作为注意力权重来池化隐藏状态。他们引入了 ForeLen，一个包含三个分割（长序列、思维链推理和 RL 采样）的基准，并报告了比基线高达 29.16% 的 MAE 降低。EGTP 是一种有吸引力的特征工程技术，但 ForeLen 在不同的模型-数据集组合上评估不同的方法，因此报告的收益无法与任务难度的差异分开。

其他预测器。 Piotrowski 等人（2025）将逐层隐藏状态视为图并应用 GCN 回归器。Zheng 等人（2023）通过在推理时插入的轻量级侧网络预测长度。Qiu 等人（2024）仅在提示文本上训练单独的代理模型。我们的工作与所有这些的不同之处在于针对它们共享的基本极限。

迭代和在线预测。 上述所有方法都在解码开始之前做出单一预测。一条互补的工作线在部分输出可用时更新估计。Choi 等人（2025）提出 ELIS，它以固定间隔（例如每 50 个 token）将提示加上已生成的 token 输入基于 BGE 的预测器，并表明 MAE 随着更多上下文的揭示而单调递减。Wu 等人（2026）采取了不同的路线：他们不预测长度，而是使用跳转 MLFQ 调度器自适应地估计剩余时间，该调度器在每次迭代时重新确定作业的优先级。这两种方法都不与我们的预填充侧界限矛盾：它们在更丰富的信息集（x 和 y<ₜ）上操作，因此面临更小的有效 σ。我们在 §6.4 讨论它们的影响。

3 预测误差的理论分析

本节分离出任何预测器都无法消除的预测误差部分。我们首先将解码描述为停止的随机过程并记录精确的风险率恒等式（§3.1）。然后我们给出响应如何获得其长度的机制模型，从中解码长度的正态性作为定理而非假设得出（§3.2）。最后，我们将该定律转化为对每个预填充侧预测器有效的界限（§3.3），并识别控制逐提示标准差的因素（§3.5）。为保持简洁，所有证明和推导都推迟到附录 A：正文陈述每个结果，在有用处给出单行证明思路，并指向完整的论证。

3.1 作为停止时间的解码长度

固定提示 x、目标模型和采样配置。解码从模型的下一个 token 分布中抽取 y₁, y₂, … 并在

Y = min{t ≥ 1 : yₜ ∈ 𝒮}，　(2)

处停止，其中 𝒮 是停止 token 集合（EOS 以及任何配置的停止字符串）。因此 Y 是采样过程的停止时间，其随机性正是采样延续的随机性。其分布由停止概率（离散风险率）和生存函数

pₜ = Pr(Y = t | Y ≥ t, x)，　Sₜ = Pr(Y ≥ t | x) = ∏ₛ₌₁^(t−1)(1 − pₛ)，　(3)

支配，其中 S₁ = 1 且 Pr(Y = t | x) = Sₜpₜ。风险率本身是随机的，因为采样的上下文决定了模型在第 t 步停止的可能性。

附录 A.1 记录了 (3) 所蕴含的精确矩恒等式，并表明常数风险率会使 Y 成为几何分布，σ/μ → 1，因此不可约相对 MAE 约为 74%；测量的 σ/μ ≈ 0.15（§4）排除了该模型。此外，由于求和得到 Y 的指示变量 1{Y ≥ t} 是嵌套的而非独立的，正态性不能从 token 上的中心极限定理继承：它必须来自更粗的层级，这是 §3.2 的主题。

3.2 更新模型和中心极限定理

长响应不是一个不间断的决策：它是段的拼接——句子、列表项、子句或推理步骤——每段在模型决定是否继续之前完成。

假设 3.1（段（更新）结构）。在 x 的条件下，响应分裂为 M 个长度为 L₁, …, L_M 的段，使得 在给定 M 和 x 的情况下，Lᵢ 独立同分布，具有均值 m、方差 v 和有限的三阶绝对中心矩 ρ； M 是段级延续过程的停止计数，与 Lᵢ 独立，具有 𝔼[M] = n 和 Var(M) = c²n² + c₁n，其中常数 c, c₁ ≥ 0。

那么 Y = ∑ᵢ₌₁^M Lᵢ。

定理 3.2（解码长度的正态性）。在假设 3.1 下，设 μ = mn，σ² = vn + m²Var(M)，且 ρ_M = 𝔼|M − n|³/Var(M)^(3/2)。此外假设 M 满足速率为 n^(−1/2) 的 Berry–Esseen 界限，即 sup_u |Pr((M − n)/√Var(M) ≤ u) − Φ(u)| ≤ C_M ρ_M n^(−1/2)。则存在常数 C 使得

sup_{u∈ℝ} |Pr((Y − μ)/σ ≤ u | x) − Φ(u)| ≤ (C/√n)(ρ_M + √v/(mc))，　(4)

因此当 n → ∞ 时 (Y − μ)/σ ⇒ 𝒩(0,1)。

假设 3.1 是本文唯一的统计假设，并且是故意粗粒度的：它约束的是段计数而非 token 级行为。附录 A.2 证明了该定理，讨论了 c = 0（更新计数）和 c > 0（比例波动段计数）两种情形，并推导了下面使用的推论：仿射方差律 σ = αμ + b，其中 α = CV(M)（推论 A.3）；聚合指数 σ/μ ≥ c，其中 k := (μ/σ)² 为有效停止机会数（推论 A.4）；以及残余偏度的高斯-几何形状（注记 A.5）。图 2 的停止爬坡和 §4 的测量在经验上检验了该假设及其推论。

3.3 预测误差的下界

定理 3.2 证明了工作模型

Y | x ~ 𝒩(μ(x), σ²(x))，　(5)

在 (4) 量化的修正范围内成立。我们现在推导该定律对任何只看到预填充阶段信息（因此在给定 x 时与解码噪声独立）的预测器 ŷ = f(x) 的含义。

命题 3.3（不可约 MAE）。对于 Y ~ 𝒩(μ, σ²)，

inf_{ŷ∈ℝ} 𝔼[|Y − ŷ|] = 𝔼[|Y − μ|] = σ√(2/π) ≈ 0.7979σ，　(6)

且下确界在 ŷ = μ 处唯一取得。

命题 3.4（最大通过率准确率）。对于每个容差 τ > 0 和每个 ŷ ∈ ℝ，

acc@τ = Pr(|Y − ŷ| < τ) ≤ 2Φ(τ/σ) − 1，　(7)

其中 Φ 是标准正态 CDF。

命题 3.3 通过对 ŷ ↦ 𝔼|Y − ŷ| 求导得出，命题 3.4 通过对长度为 2τ 的区间进行分层蛋糕（重排）论证得出；两个极值都在 ŷ = μ 处唯一取得，因此这些陈述关注的是最佳可能的预测器而非均值预测器（附录 A.3）。

命题 3.3 和 3.4 表明，一旦 σ(x) 固定，没有预填充侧预测器能做得更好：这些界限对 MLP、图回归器、熵加权池化和专家混合同样成立。具体而言，单个提示的 acc@100 ≥ 90% 要求 σ ≤ 100/Φ⁻¹(0.95) = 61 个 token，acc@200 ≥ 90% 要求 σ ≤ 122 个 token；高于这些阈值，高准确率是不可能的，无论容量或训练数据量如何。

测试集聚合了具有不同 σ 的提示。由于 σ ↦ 2Φ(τ/σ) − 1 是强非线性的，对逐提示界限取平均与代入 σ̄ 有实质性差异——对于 §5.3 的测试集是 57.9% 对 46.2%；因此我们总是报告逐提示界限的平均值（映射的曲率在附录 A.3 中计算）。

命题 3.5（超额风险）。对于任何预测器 ŷ = f(x)，

𝔼[(Y − ŷ)²] = 𝔼[σ²(x)]（系统误差）+ 𝔼[(μ(x) − ŷ)²]（模型误差），　(8)

𝔼[|Y − ŷ|] ≤ 𝔼[σ(x)√(2/π)] + 𝔼[|μ(x) − ŷ|]。　(9)

方程 (8) 是全方差定律，(9) 是逐提示应用的三角不等式（附录 A.3）。因此预测器与界限之间的差距至多是其与预言均值 μ(x) 的距离，并且由于训练标签是单一解码而非均值 μ(x)，回归目标携带方差为 σ²(x) 的噪声，这减慢了有限 N 下的学习——§5.3 中观察到的残余差距。

推论 3.6（相对误差指标是正确的度量）。在仿射律 (18) 下，对于长响应（μ ≫ b/α），

MAE_min/μ → α√(2/π) ≈ 0.798α，　acc@100_max → 2Φ(100/(αμ)) − 1。　(10)

因此绝对 MAE 随数据长度尺度无界增长，而相对误差趋向于由生成过程固定的、架构无关的稳定常数——这是 §6.1 报告协议的形式化理由。

3.4 从有限次解码估计 σ

在实践中 σ 是未观测的：我们只看到每个提示的 K 次解码。当 Y₁, …, Y_K ~ 𝒩(μ, σ²) 独立同分布时，样本方差满足 (K−1)S²/σ² ~ χ²(K−1)，因此要求 S 在 95% 置信度下以 10% 的精度估计 σ 相当于两个同时不等式

χ²(K−1,0.025) ≥ 0.81(K−1) 且 χ²(K−1,0.975) ≤ 1.21(K−1)，　(11)

它们首次在 K = 193 时成立（附录 A.5）；我们使用每个提示 K = 200 次解码。因此下面报告的所有界限应被理解为 σ 的精度约为 ±10%，因此界限本身的精度约为 ±10%。

4 经验验证

4.1 解码长度是正态的吗？

我们从 ShareGPT 中采样 300 个提示，并使用 Qwen3-32B 对每个提示解码 K = 200 次，使用模型推荐的采样配置（温度 0.6，top-k 20，top-p 0.95），以便长度定律反映部署情况。300 个提示中有两个是确定性的（所有 200 次解码返回相同的 8 个 token 答案）；那里 σ = 0，下面的每个陈述都平凡成立。其余 298 个提示每个产生 200 个长度。

在 K = 200 时，单一 p 值是一个糟糕的总结，因为一旦样本量大，检验就会拒绝微小的偏差。因此我们报告三个互补的诊断：正态性被拒绝的频率、偏差的大小和方向（标准化偏度和超额峰度），以及——最重要的——高斯定律再现界限实际使用的量的准确程度。

拒绝率。 Shapiro–Wilk 在 α = 0.05 下对 298 个提示中的 79 个（26.5%）不拒绝正态性，而 Kolmogorov–Smirnov 对 226 个（75.8%）不拒绝。这一差距反映了 Shapiro–Wilk 在 K = 200 时对微小偏差的敏感程度。

效应量。 偏差是小的且系统性的而非任意的：中位标准化偏度为 +0.27（70.8% 的提示右偏），中位超额峰度为 +0.35；58% 的提示 |偏度| < 0.5，69% 的提示 |峰度| < 1。汇总所有 59,600 个标准化长度 (Y − μ̂)/σ̂ 得到偏度 0.34、超额峰度 1.48，以及与 𝒩(0,1) 的 Kolmogorov–Smirnov 距离 0.019。这正是注记 A.5 预测的修正：高斯主体加上一个小的右偏采样分量。对观察到的中位数求解 (32) 得到 r = 0.60（从偏度）和 r = 0.57（从峰度），即一个相互一致的分解，约四分之一的方差来自采样噪声。

在关键处的准确性。 以 σ 为单位的逐提示平均绝对偏差为 𝔼|Y − μ|/σ = 0.783（提示上的中位数），而高斯预测为 √(2/π) = 0.798：命题 3.3 的界限准确到 1.9% 且略微保守。同样，τ/σ ∈ {0.625, 1, 1.28, 1.645} 内的经验概率质量分别超过高斯值 1.1、1.7、2.0 和 1.1 个百分点，因此命题 3.4 的界限在感兴趣的容差处偏向安全一侧。因此正态模型不是一个方便的虚构：它在界限依赖它的地方精确到几个百分点。最明显的例外是一个真正的异常提示（CV 0.61，偏度 9.1），一个任何预填充侧预测器都无法预见的失控生成；更一般地，σ 的分布是右尾的（10% 的提示 σ > 300），这就是为什么每当引用上限时我们同时报告平均 σ（162.3）和中位数（133.9）。

5 预测器架构和结果

5.1 实验设置

主要评估（ShareGPT 自测试）。 我们的主要实验使用 ShareGPT 作为训练和测试源。ID 为 0–18000 的提示（约 18K 个提示）构成训练和验证集，提示 18000–18300（恰好 300 个）构成测试集。所有实验将目标模型固定为 Qwen3-32B（no-thinking 模式）及其推荐的采样参数（温度 0.6，top-k 20，top-p 0.95），以便生成与部署条件匹配。预填充隐藏状态每个提示导出一次，解码元数据用相同的模型配置产生。在评估其他模型（Llama3-8B、Qwen3-4B、DeepSeek-R1-distilled）时，我们同样采用每个模型自己的默认采样配置。

为什么只有 300 个测试提示？ 测试我们的框架需要准确的逐提示 σ 估计。如 §3.4 所示，在 95% 置信度下以 10% 的精度估计 σ 需要 K ≥ 193 次重复解码，我们使用 K = 200；每个测试提示 200 次解码，测试集必须保持小才能使评估负担得起。相比之下，训练集使用单次解码标签，这足以拟合预测器。

跨数据集泛化。 除了 ShareGPT 自测试，我们还进行了跨数据集实验（附录 D）。例如，在 LMSYS-200K 上训练并在 ShareGPT 18000–18300 上测试得到 MAE 182.40，在 LeetCode 上训练并在 HumanEval 上测试得到 MAE 29.28，acc@100 = 96.28%。因此预测器性能对训练和测试之间的领域对齐高度敏感，而 σ 驱动的上限在每个设置中仍然是主导约束。

数据生成注意事项。 由于资源原因，预填充隐藏状态和长度标签由 PD 分离的流水线产生：特征在预填充节点上计算，标签在单独的解码工作器上产生。批处理以及因此低级数值行为在两个阶段之间没有严格控制；我们在 §6 回到这一限制。

5.2 评估的架构

我们评估以下预测器设计，它们都只看到预填充隐藏状态：

  • MLP-Concat：拼接所有层的最后 token 隐藏向量（约 100k 维），并通过 3 层 MLP（隐藏宽度 128）回归。这是我们的最简单基线。
  • MLP-Mean：在层和 token 上平均池化隐藏状态，然后 MLP 回归。
  • EGTP 风格：从下一个 token logits 计算每个 token 的熵，softmax 归一化为注意力权重，并加权池化隐藏状态（Xie et al., 2026）；在池化向量上进行 MLP 回归。
  • FiLM：将预填充 token 计数视为条件信号，使用 FiLM 生成器（Perez et al., 2018）在回归前调制隐藏表示。
  • 软标签：将长度离散化为 50 或 100 个区间，训练带有高斯平滑目标的分类头，并将期望区间映射回连续长度。
  • MoE-Hard：在基于长度的分割上训练 4 个专家回归器，带有选择一个专家的硬门分类器（Shazeer et al., 2017）。
  • MoE-Soft：相同的专家，带有平均其预测的软门。
  • MoE-E2E：门和专家的端到端联合训练，带有辅助路由损失。

6 讨论

6.1 迈向更公平的基准

ForeLen 基准（Xie et al., 2026）在不同的模型-数据集组合上评估不同的方法（例如长序列上的 Qwen2.5-7B，RL 采样上的 Llama3.2-3B）。因为每个组合有自己的 σ，报告的 MAE 差异将预测器质量与任务难度混淆。我们建议未来的基准：

  1. 在比较预测器时固定目标 LLM、数据集和采样参数；
  2. 报告逐提示 σ（或至少其在测试集上的平均值和中位数），以便绝对 MAE 值可以对照命题 3.3 和 3.4 的界限来读取；
  3. 采用相对误差指标（MAE/μ，或表示为上限 2Φ(τ/σ) − 1 的分数的通过率）与绝对 MAE 并列，因为推论 3.6 表明只有前者在长度尺度变化下是稳定的。

6.2 运行时计算不一致

我们的预填充特征和解码标签由不同工作器上的独立流水线阶段产生，没有严格控制批大小、CUDA 内核版本或确定性模式。用作特征的隐藏状态和产生标签的隐藏状态因此可能在浮点级别上不同。我们相信相对于 σ 驱动的系统误差，这一效应很小，但它仍然未受控制。未来的工作应该在相同的前向传递中生成特征和标签，或至少固定所有运行时确定性标志。

6.3 PD 分离生成

为了大规模获得标签，我们使用了 PD 分离的服务设置（Zhong et al., 2024），其中预填充节点导出隐藏状态和 KV 缓存，而解码节点生成补全。这种分离引入了两个潜在的偏差：预填充和解码工作器之间的数值差异（如上所述），以及两侧可能不同的批处理策略。由于我们的训练标签是单一解码而非 200 次解码的均值，标签噪声被进一步放大。这些是大规模数据收集的实际约束；它们应该被承认，并且在理想情况下在未来的研究中被控制。

6.4 迭代预测作为不确定性缩减

我们的分析假设预测器只看到预填充阶段信息。这是最困难的情形，因为 Var(Y|x) 此时达到最大。一旦解码开始，每个生成的 token yₜ 都携带关于剩余长度的信息，后验方差只能缩小：

Var(Y | x, y<ₜ) ≤ Var(Y | x)，

对大多数提示严格成立。Choi 等人（2025）利用这一点，在解码期间以固定间隔重新运行基于 BGE 的预测器，并报告 MAE 随着观察到更多 token 而单调递减。

理论上，迭代预测是在不改变生成过程的情况下减少不确定性的最有效方式。预填充侧特征工程只能缩小命题 3.5 的模型误差，而迭代预测通过减少目标的条件方差来缩小系统误差。在预测器在每个 token 之后被调用的极限情况下，剩余长度塌缩为近乎确定性的倒计时，MAE 界限趋向于零。

代价是运行时成本：每次预测需要编码器前向传递，为服务系统增加延迟和内存压力。对于使用预填充侧估计来批处理请求的调度应用，这种开销通常只对粗粒度更新（例如每 50–100 个 token）是可接受的。因此我们将仅预填充的界限和迭代细化视为互补：前者设定无需解码侧开销即可达到的基线，后者量化愿意付费的系统可获得的不确定性缩减。

7 结论

我们已经表明，从预填充隐藏状态进行解码长度预测受到自回归生成随机性的根本约束。将解码视为停止时间并将响应的增长建模为更新过程，产生了带有显式误差项的逐提示正态性、仿射方差律 σ = αμ + b，以及没有预填充侧预测器能击败的 MAE 和通过率准确率下界。在经验上这些界限是紧的：一个简单的 MLP 已经落在噪声下限的 30% 以内，而更精细的设计（EGTP、FiLM、软标签、MoE）产生边际或负的回报。其含义是，努力应该从更复杂的预测器转向 控制生成过程本身的方差——通过更低温度的采样、约束解码或提示设计——以及 固定模型、数据和采样参数并报告相对于上限的相对误差的基准协议。

A.1 风险率恒等式和几何基线

引理 A.1（风险率恒等式）。对于任何具有生存函数 Sₜ = ∏ₛ₌₁^(t−1)(1 − pₛ) 的风险率序列 {pₜ}ₜ≥₁，如 (3) 中，

𝔼[Y] = ∑ₜ≥₁ Sₜ，　𝔼[Y²] = ∑ₜ≥₁ (2t−1)Sₜ，
Var(Y) = ∑ₜ≥₁ (2t−1)Sₜ − (∑ₜ≥₁ Sₜ)²。　(13)

证明。 对于整数值的 Y ≥ 1，分层蛋糕恒等式为 Y = ∑ₜ≥₁ 1{Y ≥ t}，并且使用 ∑ₜ₌₁ⁿ(2t−1) = n²，

Y² = ∑ₜ≥₁ (2t−1)1{Y ≥ t}。　(14)

取期望并使用 𝔼[1{Y ≥ t}] = Pr(Y ≥ t) = Sₜ 得到 (13)。□

注记 A.2（常数风险率给出指数律，而非正态律）。如果 pₜ ≡ p，则 Y ~ Geom(p) 且变异系数为 √(1−p) → 1，因此无论输出长度如何，不可约相对误差为 𝔼|Y − μ|/μ → 2/e ≈ 0.74。由于求和得到 Y 的指示变量 1{Y ≥ t} 是嵌套的而非独立的，首达时间不继承和的 CLT：正态性需要许多近乎独立的贡献，它们在比 token 更粗的层级进入。

论证。 对于 pₜ ≡ p，我们有 Sₜ = (1−p)^(t−1)，因此 (13) 给出 𝔼[Y] = 1/p 且 Var(Y) = (1−p)/p²。对于小 p，重标度变量 pY 收敛到单位速率指数，因此

𝔼|Y − 𝔼Y|/𝔼Y → 𝔼|E − 1| = 2/e ≈ 0.736，　E ~ Exp(1)，　(15)

其中常数来自 ∫₀¹(1−x)e^(−x)dx + ∫₁^∞(x−1)e^(−x)dx = 2e^(−1)。因此在常数风险率下 O(1) 相对误差是不可避免的，无论对 x 知道多少，这就是为什么测量的 σ/μ ≈ 0.15 排除了该模型。□

A.2 定理 3.2 的证明及其推论

Wald 恒等式。 写 Y = ∑ᵢ₌₁^M Lᵢ，其中 M 与独立同分布的段独立。那么 𝔼[Y] = m𝔼[M] = mn，并且由全方差定律和 Wald 恒等式 𝔼[Var(Y|M)] = v𝔼[M]，所以

Var(Y) = vn + m²Var(M) = vn + m²(c²n² + c₁n) = κ₂μ² + κ₁μ，　(16)

其中 κ₂ = c² 且 κ₁ = v/m + mc₁。取平方根并展开，

σ = √(κ₂μ² + κ₁μ) = αμ√(1 + κ₁/(κ₂μ)) = αμ + κ₁/(2α) + O(μ^(−1))，　(17)

这就是仿射方差律：

推论 A.3（仿射方差律）。在假设 3.1 下，κ₂ = c² 且 κ₁ = v/m + mc₁，

σ² = κ₂μ² + κ₁μ，因此 σ = αμ + b + O(μ^(−1))，　(18)

其中 α = √κ₂ = c 且 b = κ₁/(2α)。因此斜率是段计数的变异系数，截距收集被 1/(2α) 折扣的逐段噪声——是生成过程而非预测器的属性。

推论 A.4（聚合指数）。在假设 3.1 下，

σ/μ = √(c² + (v/m² + c₁)/n) ≥ c，　(19)

当 c > 0 时随着 n → ∞ 取等号。因此 k := (μ/σ)² 度量一个提示提供多少有效独立的停止机会：具有单一决定时刻的模型有 k = O(1)，聚合的模型有 k ≫ 1。对于 §4 的提示，σ/μ 的中位数为 0.145，即 k ≈ 47。

两种情形。 假设 3.1 的方差形式 Var(M) = c²n² + c₁n 覆盖了两种感兴趣的情形。当 c = 0 时，段计数表现得像更新计数，Var(M) ∝ n，下面分解的采样项和内容项具有相同的阶。当 c > 0 时，段数在同一提示的解码之间成比例波动——由波动的内容路径所蕴含的情形——且 c = CV(M|x)，这是 §4 中测量的情形。

双尺度分解。 令 A = ∑ᵢ≤M(Lᵢ − m) 且 B = m(M − n)，我们有 Y − μ = A + B 精确成立，其中 𝔼[A] = 𝔼[B] = 0，Var(A) = vn 且 Var(B) = m²Var(M)，所以 σ² = Var(A) + Var(B)。尽管 A 和 B 不独立（都依赖 M），它们在给定 M 时条件独立，因此由塔性质

φ₍Y−μ₎/σ(t) = 𝔼[e^(itB/σ) φₐ/σ(t|M)]。　(20)

给定 M = k，变量 A 是 k 个中心化独立同分布项的和，因此二阶展开（或长度为 k 的和的 Berry–Esseen 界限）给出

|φₐ/σ(t|M=k) − 1| ≤ (t²/2)(Var(A|M=k)/σ²) + O(ρ|t|³k^(3/2)/(m³σ³)) = O(t²/n)，　(21)

对 k = O(n) 一致成立，因为 Var(A|M=k) = vk 且 σ² ≥ m²c²n²。由于 |e^(itB/σ)| = 1，

|φ₍Y−μ₎/σ(t) − φ_B/σ(t)| ≤ 𝔼[|φₐ/σ(t|M) − 1|] = O(t²/n)，　(22)

即采样项仅以 1/n 的阶扰动特征函数。对于内容项，假设的 M 的 Berry–Esseen 界限给出，其中 σ_B = m√Var(M)，

|φ_B/σ(t) − e^(−t²/2)| ≤ |φ_B/σ_B(t) − e^(−t²/2)| + (t²/2)|1 − σ_B²/σ²| ≤ C(ρ_M|t|³/√n + |t|²/n)，　(23)

其中 1 − σ_B²/σ² = vn/σ² = O(n^(−1))。结合这三个式子，对每个固定的 t，

|φ₍Y−μ₎/σ(t) − e^(−t²/2)| ≤ C′(ρ_M|t|³/√n + |t|²/n) → 0，　(24)

且 Lévy 连续性定理给出 (Y − μ)/σ ⇒ 𝒩(0,1)。Esseen 的平滑引理将逐点特征函数收敛升级为一致的 CDF 界限 (4)。□

定理假设和不假设什么。 该论证不是从头推导正态性。它将 token 级停止时间的正态性归约为段计数 M 的正态性——一个粗得多的对象，只有几十个有效单元——并且为归约定价：token 级（采样）贡献仅以相对阶 vn/σ² = O(n^(−1)) 进入方差，因此其形状在首阶无关。在更新情形（c = 0，Var(M) ∝ n）中，两项具有相同的阶，随机停止和的 Anscombe 定理扮演内容 CLT 的角色；每当 M/n → 1 依概率成立时结论不变。§4 的经验检验测试的是结果而非假设：仿射律 (16)、比率 𝔼|Y − μ|/σ，以及偏度/峰度对都匹配模型的预测。

A.3 第 3.3 节的证明和辅助计算

命题 3.3 的证明。 设 Z ~ 𝒩(0,1) 且 c = (ŷ − μ)/σ，因此 𝔼|Y − ŷ| = σψ(c)，其中 ψ(c) = 𝔼|Z − c|。在期望下求导，

ψ′(c) = 𝔼[−sgn(Z − c)] = Pr(Z < c) − Pr(Z > c) = 2Φ(c) − 1，　(25)

它对 c < 0 为负，在 c = 0 处为零，对 c > 0 为正；因此 c = 0 是唯一的极小化点。值来自 u = z²/2：

𝔼|Z| = 2∫₀^∞ z e^(−z²/2)/√(2π) dz = 2∫₀^∞ e^(−u)/√(2π) du = √(2/π)。　(26)

对于 Y ~ 𝒩(μ, σ²)，这给出 MAE_min = σ√(2/π) ≈ 0.7979σ。□

命题 3.4 的证明。 密度 f(y) = σ^(−1)φ((y−μ)/σ) 关于 μ 对称且在 |y − μ| 中非增，因此其超水平集 Aₛ = {y : f(y) ≥ s} 是以 μ 为中心、长度为 ℓ(s) 的区间。由分层蛋糕表示和长度为 2τ 与 ℓ(s) 的两个区间的交长度至多为 min{2τ, ℓ(s)} 的事实，

Pr(Y ∈ I) = ∫₀^∞ |I ∩ Aₛ| ds ≤ ∫₀^∞ min{2τ, ℓ(s)} ds = Pr(|μ − Y| < τ)　(27)

对每个长度为 2τ 的区间 I 成立；等号情形是 I = [μ − τ, μ + τ]，即 ŷ = μ。取 I = [ŷ − τ, ŷ + τ] 得到 (7)。□

命题 3.5 的证明。 对于在给定 x 时与解码噪声独立的预测器 ŷ = f(x)，塔性质给出

𝔼[(Y − ŷ)²] = 𝔼[𝔼[(Y − μ(x))²|x]] + 𝔼[(μ(x) − ŷ)²] = 𝔼[σ²(x)] + 𝔼[(μ(x) − ŷ)²]，　(28)

这是 (8)，并将两项识别为不可约（系统）和可约（模型）误差。对于绝对损失，三角不等式加上逐提示应用的命题 3.3，𝔼[|Y − ŷ||x] ≥ σ(x)√(2/π)，给出

𝔼[|Y − ŷ|] ≤ 𝔼[σ(x)√(2/π)] + 𝔼[|μ(x) − ŷ|]，　(29)

即 (9)：超出界限的部分至多是预测器到预言均值的 L₁ 距离。□

推论 3.6 的证明。 在 (18) 下，σ/μ = α√(1 + κ₁/(κ₂μ)) → α，因此命题 3.3 给出 MAE_min/μ → α√(2/π)，命题 3.4 给出 acc@τ_max = 2Φ(τ/σ) − 1 → 2Φ(τ/(αμ)) − 1。因此界限仅通过比率 τ/μ 依赖 μ，这正是使相对误差指标无尺度的原因。□

测试集聚合。 对于 g(σ) = 2Φ(τ/σ) − 1，

g′(σ) = −2τφ(τ/σ)/σ²，　g″(σ) = (2τφ(τ/σ)/σ³)(2 − τ²/σ²)，　(30)

因此 g 处处递减，对 σ > τ/√2 凸，低于则凹。σ ≪ τ 的提示使 g 饱和接近 1，因此测试集平均由凸区域主导且通常超过 g(σ̄)：对于 §5.3 的测试集，逐提示平均为 57.9% 而 g(σ̄) 为 46.2%。这就是为什么本文中的所有上限都对逐提示界限取平均。

A.4 偏差的形状

注记 A.5（方差预算和偏差的形状）。将分解

Y − μ = ∑ᵢ₌₁^M(Lᵢ − m)（采样噪声）+ m(M − n)（内容噪声）　(31)

的两项写为 A 和 B，并令 r = σ_samp/σ_cont。如果路径级风险率在交叉点附近局部平坦，A 表现得像中心化几何变量，因此标准化定律是高斯-几何卷积，其累积量给出

skew(Y) = 2r³/(1+r²)^(3/2)，　kurt(Y) = 6r⁴/(1+r²)²，　(32)

其中 kurt 是超额峰度；r → 0 恢复高斯。经验中位数（偏度 0.27，超额峰度 0.35；§4）反演为 r = 0.60 和 r = 0.57——相互一致，并暗示在此实现的段计数（n ≈ 45，远离定理 3.2 的渐近情形）下，约四分之一的逐提示方差是采样噪声。在这个精确的意义上，解码长度"是"高斯的：界限的位置和尺度是高斯的，残余右偏是一个小的、可量化的修正而非建模失败。

推导。 设 X = N + r(E − 1)，其中 N ~ 𝒩(0,1)，E ~ Exp(1) 独立，r ≥ 0。累积量是可加的，指数律有 κ₃ = 2，κ₄ = 6，所以

Var(X) = 1 + r²，　κ₃(X) = 2r³，　κ₄(X) = 6r⁴，　(33)

从而

skew(X) = 2r³/(1+r²)^(3/2)，　kurt(X) = 6r⁴/(1+r²)²，　(34)

即 (32)。映射 r ↦ skew(X) 严格递增，因此 r 可以从观察到的偏度（或冗余地，从观察到的超额峰度）反演；比率 r²/(1+r²) 是几何分量携带的方差份额。对于 §4 的经验中位数（偏度 = 0.27，峰度 = 0.35），两次反演给出 r = 0.60 和 r = 0.57，即采样噪声份额为 24–26%。定理 3.2 仅在 n → ∞ 的极限下使采样分量消失；在此实现的段计数（n ≈ 45）下，其份额小但不可忽略，这正是残余偏度可测量的原因。

A.5 σ 的 χ² 置信界限

给定 K 个独立同分布观测 Y₁, …, Y_K ~ 𝒩(μ, σ²)，样本方差 S² = (1/(K−1))∑ᵢ(Yᵢ − Ȳ)²，

(K−1)S²/σ² ~ χ²(K−1)。　(35)

我们希望 S 在置信度 0.95 下以 10% 的相对误差估计 σ，即 Pr(0.9σ ≤ S ≤ 1.1σ) ≥ 0.95，等价于

Pr(0.81(K−1) ≤ χ²(K−1) ≤ 1.21(K−1)) ≥ 0.95。　(36)

令 χ²(K−1,α) 表示自由度为 K−1 的卡方分布的 α 分位数。使用两个中心分位数 0.025 和 0.975，

χ²(K−1,0.025) ≥ 0.81(K−1) 且 χ²(K−1,0.975) ≤ 1.21(K−1)。　(37)

两个不等式首次在 K = 193 时同时成立：那里 χ²(192,0.025) = 155.52 ≥ 0.81·192 = 155.52 且 χ²(192,0.975) = 232.27 ≤ 1.21·192 = 232.32，而在 K = 192 时相应的值为 154.62 < 154.71 和 231.16 > 231.11。我们向上取整到每个提示 K = 200 次解码。这一要求是我们的测试集限制在 300 个提示的原因：每个提示 200 次解码使得更大测试集的详尽评估成本过高。

附录 B 训练细节

所有预测器在 PyTorch 中实现并用 Adam 训练。除非另有说明：

  • 学习率 10^(−3)，余弦衰减；
  • 批大小 32；
  • 最多 100 个 epoch，在验证 MAE 上早停（耐心 10）；
  • 输入是用 attn_implementation="eager" 导出的预填充隐藏状态；
  • 损失：回归用 Smooth-L1（Huber），软标签用交叉熵加 MSE 混合。

MLP-Concat。 拼接所有层的最后 token 隐藏向量。对于 Qwen3-32B（64 层，隐藏大小 5120），输入维度为 327,680，主干应用 327680 → 128 → 128 → 1 的线性映射，中间有 ReLU 激活。

EGTP 风格。 计算每个预填充位置的下一个 token 分布的熵 Hᵢ，归一化为权重 wᵢ = softmax(H)ᵢ，逐层加权池化隐藏状态，并跨层平均池化。在得到的 5120 维向量上拟合 MLP 回归器。

FiLM。 通过产生尺度 γ 和偏移 β 的小型 MLP 对预填充 token 计数 L 进行条件化，在回归头之前逐元素应用于平均池化的隐藏状态。

软标签。 将目标长度离散化为 100 个等宽区间，并用 σ_bin = 2 个区间的高斯核平滑目标。损失为 ℒ = λℒ_CE + (1−λ)ℒ_MSE，其中 λ = 0.5。

MoE 变体。 四个专家覆盖四个长度区间，有 20% 的重叠，即 [0,375)、[375,750)、[750,1149) 和 [1149,∞)。每个专家是 2 层 MLP，门是带有 softmax 输出的 2 层网络。MoE-E2E 添加从专家预测区间导出的辅助路由损失。

附录 E MoE 元门定义

为完整起见，我们记录 MoE 实验中使用的置信感知元门。设 K = 4 个专家，其中专家 i 输出均值预测 μᵢ(x) 和风险估计 rᵢ(x)：

μᵢ(x) = W_{i,μ}hᵢ(x) + b_{i,μ}，　(38)
rᵢ(x) = Softplus(W_{i,r2}ReLU(W_{i,r1}hᵢ(x) + b_{i,r1}) + b_{i,r2})。　(39)

风险头被训练以预测专家的绝对误差 eᵢ(x, Y) = |μᵢ(x) − Y|，使用 Smooth-L1 损失。

元门拼接特征 x、专家预测 μ(x)、风险 r(x) 和区间距离 d(x)，其中 dᵢ(x) = max(aᵢ − μᵢ, 0) + max(μᵢ − bᵢ, 0)，对应专家区间 [aᵢ, bᵢ]。它输出先验 π(x) = softmax(g(z(x))) 和分数

sᵢ(x) = log(πᵢ(x) + ε) − αrᵢ(x) − βdᵢ(x)，　(40)

路由权重为 wᵢ(x) = exp(sᵢ(x)/T)/∑ⱼexp(sⱼ(x)/T)，最终预测为 ŷ(x) = ∑ᵢwᵢ(x)μᵢ(x)。

总训练损失为 ℒ = ℒ_reg + λ_klℒ_kl + λ_balℒ_bal，其中 ℒ_reg 是 ŷ 上的 Smooth-L1，ℒ_kl 是来自预言软路由目标 qᵢ ∝ exp(−|μᵢ − Y|) 的 KL 散度，ℒ_bal 惩罚不平衡的专家使用。
