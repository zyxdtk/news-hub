摘要

偏好优化已成为将大语言模型与人类价值观对齐的核心方法，但其有效性在很大程度上取决于偏好标注的质量。在实践中，由于标注错误和歧义，偏好数据往往含有噪声。现有的鲁棒偏好优化方法主要在序列级别操作，隐式地将整个响应视为一致正确或一致错误。然而，被拒绝的响应可能仍包含有信息量的推理步骤，而偏好的响应也可能包含细微错误。在本工作中，我们提出 Preference Optimization via Robust Token-level reweighting（PORT，基于鲁棒词元级重加权的偏好优化），这是一个在噪声偏好下实现鲁棒对齐的细粒度框架。PORT 利用词元对数概率的经验累积分布函数（CDF）进行词元级重加权，得到一种高效的、仅需前向传播的梯度范数惩罚代理方法，可选择性抑制受损词元而无需额外的反向传播计算。我们提供了理论分析，表明 PORT 通过最小化偏差项的上界来减少噪声偏好标签引起的梯度偏差。在多种噪声设置下的大量实验表明，PORT 持续提升鲁棒性，并优于现有的序列级基线方法。代码可在 https://github.com/osu-srml/PORT 获取。

1 引言

偏好优化已成为将大语言模型（LLM）与人类价值观对齐、确保其输出有用、安全且符合用户意图的主流方法 [2]。与基于人类反馈的强化学习（RLHF）[18] 不同——RLHF 需要先训练一个显式奖励模型，再通过强化学习引导策略趋向高奖励响应——直接偏好优化（DPO）[20] 和恒等偏好优化（IPO）[7] 等偏好优化方法则在稳定的监督学习范式内，直接优化偏好响应与被拒绝响应之间的隐式奖励差距。

尽管取得了成功，偏好优化方法存在一个关键脆弱点：其有效性严重依赖偏好标注的质量。然而在实践中，偏好数据很少是干净的，大规模获取高质量数据往往成本高昂甚至不可行。标注者分歧、难以区分样本对中的内在歧义以及标注错误都会给训练信号引入噪声，从而使梯度估计产生偏差并降低对齐性能。为此，近期工作探索了标签平滑 [4, 13, 16]、正则化 [15, 26] 和启发式数据过滤 [8, 17] 等缓解技术（各方法讨论见附录 A）。

然而，这些方法从根本上受限于对偏好噪声的序列级建模。现有的偏好优化目标及其噪声缓解变体在整个响应上均匀聚合逐词元的对数比率，隐式地将所有词元位置视为同等可靠。这一假设在实践中经常被违背：偏好响应可能包含局部幻觉或推理错误，而被拒绝的响应可能仍包含正确的中间推理步骤。

考虑一个偏好对，其中偏好响应为“澳大利亚的首都是堪培拉，它是作为悉尼和墨尔本之间的折中方案而专门建造的”，而被拒绝的响应为“澳大利亚的首都是悉尼，因为它是最大的城市”。如果偏好标签因噪声而被翻转，序列级方法会同等惩罚被拒绝响应中的所有词元。然而，这种处理过于粗糙：尽管该响应在事实上不正确，但许多词元（如“因为它是最大的城市”）在局部是流畅的，并不直接造成错误。因此，均匀惩罚所有词元会给学习信号引入不必要的偏差，使噪声或无信息量的词元对梯度产生不成比例的影响。

遗憾的是，现有噪声缓解策略无法解决这种不匹配。保守 DPO（cDPO）[16] 等标签平滑方法对整个目标施加均匀收缩，实际上等比例缩放了所有词元的贡献。分布鲁棒化 DPO（Dr.DPO）[26] 等样本对级重加权方法为每个偏好对分配单个标量权重，序列内部的变化未被建模。即使词元级重要性采样（TIS-DPO）[14] 等词元级方法引入了更细的粒度，但它们依赖外部奖励模型，从而重新引入了奖励误泛化风险和额外的计算开销。总体而言，这些局限凸显了一个关键空白：现有方法要么操作粒度过粗，要么依赖外部监督来实现词元级自适应性。

图 1：PORT 训练流程概述：1) 给定一批偏好对 ℬ = {(x̃, ỹ_w^[b], ỹ_l^[b])}{b=1}^{|ℬ|}，其中 ỹ_w^[b] 和 ỹ_l^[b] 分别表示选定和被拒绝的响应。2) 前向传播：评估策略 π_θ 和参考策略 π_ref，得到逐词元对数比率 δ_t^b 和词元级 logits s̃{w,t}^[b]、s̃{l,t}^[b]。3) ΔCDF 估计：将词元对数概率在整个批次中汇集形成全局经验 CDF F(·)，为选定和被拒绝词元给出百分位排名 F{w,t}^[b] 和 F_{l,t}^[b]。较大的差距表明被拒绝词元相对于选定词元被赋予了异常高的概率，提示潜在的词元级标签噪声。4) 权重转换：将差距 Δ_t^[b] = F_{l,t}^[b] − F_{w,t}^[b] 映射为权重 w_t^[b] = γ exp(ρΔ_t^[b])。5) 加权词元级更新：将这些权重纳入偏好目标 L̃_w，产生抑制受损词元的鲁棒梯度更新。该过程仅需单次前向传播，不引入额外的反向传播开销。

受此启发，我们探索实例依赖偏好噪声下的词元级噪声缓解，并提出 Preference Optimization via Robust Token-level reweighting（PORT），一个无需外部奖励模型或额外反向传播即可执行词元级重加权的框架。核心思想是为每个词元位置分配一个权重，使得在噪声数据上求解加权偏好优化所得到的解与真实人类偏好一致。

为将这一设计奠定在理论基础之上，我们分析了噪声对偏好优化梯度的影响，并推导出由此产生的梯度偏差的上界。最小化该上界可得到闭式最优词元级加权函数，它刻画了每个词元应如何根据其对噪声的敏感度及其对学习信号的贡献进行重加权。

然而，这一最优解在实践中无法直接计算，因为它依赖于未知的噪声统计量以及关于所有模型参数的梯度范数（计算代价极高）。为弥合这一差距，我们找到了一个保留最优解结构的实用替代方案。特别地，我们证明批次内词元概率的相对排序为近似最优权重提供了充分信号。由此得到一个基于模型对数概率计算的 CDF 加权方案，作为理论最优解的高效、纯前向传播代理。

我们的主要贡献如下：

  • 我们提出 PORT，一个引入词元级 CDF 重加权目标的鲁棒对齐框架，零额外反向传播开销且无需外部奖励模型。
  • 我们提供理论保证，表明我们的加权方案在实例依赖噪声下最小化梯度偏差的上界，并刻画了其严格减少偏差的条件。
  • 我们在 Anthropic HH 和 AlpacaFarm 基准上进行了大量实验，证明在多种噪声设置下相对序列级基线取得一致且显著的改进。

2 背景与问题表述

设 π_θ 表示由 θ 参数化的语言模型，它定义了给定提示 x ∈ 𝒳 时响应上的条件分布 π_θ(·|x)。考虑偏好数据集 𝒟 = {(x, y_w, y_l)}¹，其中 y_w 和 y_l 分别是提示 x 的偏好响应和不偏好响应。传统 RLHF [18] 首先通过拟合 Bradley-Terry 模型 [3] 训练奖励模型 r_ϕ(x, y)：

P(y_w ≻ y_l | x) = exp(r_ϕ(x, y_w)) / (exp(r_ϕ(x, y_l)) + exp(r_ϕ(x, y_w))).

随后将学到的奖励与近端策略优化（PPO）[21] 结合来优化 π_θ：

max_{π_θ} E_{x∼𝒟, y∼π_θ(·|x)} [r_ϕ(x, y) − β D_KL(π_θ(·|x) ∥ π_ref(·|x))] (1)

其中 π_ref 为参考策略（通常为初始的监督微调模型）。

¹ 为与先前工作保持一致，我们对符号 w 进行重载。当 w 作为 y 的下标（如 y_w、ỹ_w）时，表示选定或获胜响应；在其他所有上下文中，w 指词元级权重或由其导出的量。

（词元级）偏好优化。 Ouyang 等人 [18] 证明，公式 (1) 下的最优策略满足 r_ϕ(x, y) = β log(π_θ(y|x)/π_ref(y|x)) + β log Z(x)，从而使奖励模型可以被完全消去。这一洞察催生了 DPO [20]，它直接从偏好数据优化策略。Rafailov 等人 [20] 进一步提出了涵盖若干现有算法的广义偏好优化框架：

min_θ L(θ) = E_{(x,y_w,y_l)∼𝒟} [f(βh(x, y_w, y_l; θ))] = E_{(x,y_w,y_l)∼𝒟} [f(β log(π_θ(y_w|x)/π_ref(y_w|x)) − β log(π_θ(y_l|x)/π_ref(y_l|x)))]

其中我们定义 h(x, y, y′; θ) := log(π_θ(y|x)π_ref(y′|x) / (π_θ(y′|x)π_ref(y|x))) 为在提示 x、策略 π_θ 下响应 y 相对于 y′ 的偏好分数。f(·) 的选择实例化不同算法：DPO [20] 取 f(x) = −log σ(x)，恢复偏好对上的交叉熵损失；IPO [7] 取 f(x) = (x − 1/2)²，直接回归偏好差距以缓解过度优化。

上述序列级对数比率在策略的自回归分解下可自然分解。具体而言，对于长度为 T 的响应 y = (y_1, y_2, …, y_T)，有 log(π_θ(y|x)/π_ref(y|x)) = Σ_{t=1}^T log(π_θ(y_t|x, y_{<t})/π_ref(y_t|x, y_{<t}))。将其代入上式即得分解形式的偏好优化目标，将序列级对数比率表示为逐词元对数比率之和：

min_θ L(θ) = E_{(x,y_w,y_l)∼𝒟} [f(Σ_{t=1}^{|y_w|} β log(π_θ(y_{w,t}|x, y_{w,<t})/π_ref(y_{w,t}|x, y_{w,<t})) − Σ_{t=1}^{|y_l|} β log(π_θ(y_{l,t}|x, y_{l,<t})/π_ref(y_{l,t}|x, y_{l,<t})))] (2)

噪声人类反馈。 在实践中，人类偏好数据往往含有噪声，可能无法准确反映真实偏好。设 D̃ = {(x, ỹ_w, ỹ_l)} 表示观测到的（噪声）偏好数据集，它源自底层的无噪声数据集 𝒟 = {(x, y_w, y_l)}。为简化符号，设 z 表示来自 𝒟 的样本元组，−z := (x, y_l, y_w) 为其翻转对应项；类似地，z̃ := (x, ỹ_w, ỹ_l) 与 −z̃ := (x, ỹ_l, ỹ_w) 表示噪声数据集 D̃ 中的对应元组。我们定义翻转概率 η(z) := P(z̃ = −z)，即真实排序 y_w ≻ y_l 被损坏为 y_l ≻ y_w 的概率。

遵循 [9]，我们考虑两种刻画系统性标注错误与难以区分样本对中内在歧义的噪声模型： ϵ-误标噪声：每个偏好标签以概率 η(z) ≡ ϵ 独立翻转，ϵ 越大表示损坏越严重。 α-不确定噪声：偏好标签 ỹ_w ≻ ỹ_l 以概率 σ(α(r(y_w|x) − r(y_l|x))) 采样，否则为 ỹ_l ≻ ỹ_w，其中 r 表示真实奖励函数，α > 0 控制不确定性水平。相应翻转概率为 η(z) = 1 − σ(α(r(y_w|x) − r*(y_l|x)))；当 α → 0 时，标签趋近随机猜测。

研究目标。 如第 1 节所述，现有噪声缓解方法要么在序列级操作，要么依赖外部监督，这促使我们研究无需外部奖励模型的词元级噪声缓解。本文提出一种用于鲁棒偏好优化的词元级加权机制，从噪声偏好数据集 D̃ = {(x, ỹ_w, ỹ_l)} 中有效学得与真实偏好对齐的策略 π_θ。具体而言，对每个位置 t 的词元级对数比率 δ_t(θ)（定义见下），我们赋予标量权重 w(z, t) ≥ 0，并定义加权目标²：

min_θ L̃w(θ) = min_θ E{(x,ỹ_w,ỹ_l)∼D̃} [f(β Σ_{t=1}^T w(z, t; θ) · δ_t(θ))]，其中 δ_t(θ) = log(π_θ(ỹ_{w,t}|x, ỹ_{w,<t}) π_ref(ỹ_{l,t}|x, ỹ_{l,<t}) / (π_θ(ỹ_{l,t}|x, ỹ_{l,<t}) π_ref(ỹ_{w,t}|x, ỹ_{w,<t}))) (3)

² 若 ỹ_w 与 ỹ_l 长度不同，可对较短序列添加填充词元使其等长。因此目标函数中 T = max{|ỹ_w|, |ỹ_l|}。

核心挑战在于识别最优权重 {w(z,t)}_{t=1}^T，使上式的解与从无噪声数据 𝒟 学习的公式 (2) 的解对齐。我们并非学习一组固定权重，而是寻求一个最优权重函数 w(x, ỹ_w, ỹ_l, t) := w(z̃, t)，它根据数据和当前策略计算位置级权重。

在整个分析中，我们将词元级加权函数记为 w(z, t)，其对当前策略参数的依赖保持隐式。计算梯度时，我们将权重视为固定系数。因此权重可随策略演进更新，但梯度不会通过权重计算传播。

3 最优加权函数

接下来，我们识别最优权重函数 w(z̃, t; θ)，使得最小化重加权目标 L̃_w 所得的解与在无噪声数据上最小化 L 的解相近。为此，我们首先分析梯度偏差以理解噪声偏好标签如何影响梯度更新，然后推导最小化该偏差的最优权重函数。最后，我们确定所提出的词元级加权机制保证减少梯度偏差的条件。

偏好噪声下的梯度偏差。 给定公式 (2) 中的标准偏好优化目标，设 L(θ) 与 L̃(θ) 分别表示在真实偏好数据集 𝒟 与噪声数据集 D̃ 上的损失。依据 [16]，其相应梯度为：

g(θ) := ∇_θ L(θ) = E[∇ℓ(z; θ)]

g̃(θ) := ∇_θ L̃(θ) = E[(1−η(z))∇ℓ(z; θ) + η(z)∇ℓ(−z; θ)]

其中 η(z) = P(z̃ = −z) 为第 2 节定义的翻转概率，ℓ(z; θ) := f(β Σ_t δ_t(z; θ)) 为逐样本损失，ℓ(−z; θ) 表示其在翻转三元组 上的取值。标签噪声的影响可由梯度偏差刻画，定义为 g̃(θ) 与 g(θ) 之差。

定义 1（梯度偏差）。g̃(θ) 偏离无噪声梯度 g(θ) 一个偏差项 B：

B = g̃(θ) − g(θ) = E[η(z)(∇ℓ(−z; θ) − ∇ℓ(z; θ))] := Δg (4)

为缓解噪声影响，我们考虑词元级加权机制，得到 (3) 中的加权目标 L̃_w(θ)。记其梯度为 g̃_w(θ) := ∇_θ L̃_w(θ)，其干净数据对应项为 g_w(θ) := ∇_θ L_w(θ)。最小化 L̃_w(θ) 能否恢复与真实偏好对齐的模型，可由加权梯度偏差刻画，定义为 g̃_w(θ) 与 g(θ) 之差。

定义 2（加权梯度偏差）。g̃_w(θ) 偏离无噪声 g(θ) 一个偏差项 B_w：

B_w = g̃_w(θ) − g(θ) = [g̃_w(θ) − g_w(θ)] + [g_w(θ) − g(θ)] := Δg_w + R_b (5)

其中 ℓ_w(z; θ) := f(β Σ_{t=1}^T w(z,t) δ_t(z; θ))，Δg_w := g̃_w(θ) − g_w(θ) = E[η(z)(∇ℓ_w(−z; θ) − ∇ℓ_w(z; θ))]，R_b := g_w(θ) − g(θ)。详细推导见附录 B.1。在分析中，权重对交换两个响应保持不变。

最优加权函数。 我们的目标是识别一个最优权重函数，使噪声数据上公式 (3) 加权目标的解与真实偏好对齐。为此，我们最小化加权梯度偏差 B_w 的范数：

min_w ‖B_w‖ = ‖Δg_w + R_b‖ (6)

我们将权重函数 w(z, t; θ) 限制在容许集 𝒲 := {w ≥ 0 : E_p[w(z,t)] = 1} 以避免平凡解，其中 p 为 z 的概率密度函数。定义重加权分布 p_w(z) := w(z, t; θ) p(z)。应用 Jensen 不等式与 Pinsker 不等式，可对 ‖Δg_w‖ 与 ‖R_b‖ 进行上界估计：

‖Δg_w‖ ≤ βK E[η(z) w(z,t) ‖∇δ_t(z; θ)‖]

‖R_b‖ ≤ C · √(2 D_KL(p_{w_t} ∥ p))

其中 C、K 为常数。注意 ‖R_b‖ 的上界通过 KL 散度 D_KL(p_w ∥ p) 依赖于权重函数 w(z, t; θ)；最小化该项可防止重加权分布过度偏离原始数据分布。由于直接最小化 ‖B_w‖ 难以处理，我们转而最小化所导出的上界，它具有易于处理的闭式解。由此得到如下优化问题：

min_w E[w(z,t) η(z) ‖∇δ_t(z; θ)‖] + (1/λ) D_KL(p_w ∥ p) (7)

其中 λ > 0 为平衡两个上界的权衡参数。定理 1 表明该优化问题具有闭式解，证明见附录 B.2。

定理 1（代理最优加权函数）。最小化 (7) 的代理最优权重函数 w* 为：

w*(z, t) ∝ exp(−λ η(z) ‖∇δ_t(z; θ)‖) (8)

定理 1 表明，噪声率 η 高、梯度范数 ‖∇δ_t(z; θ)‖ 大或二者兼有的样本应被赋予更小的权重。这与鲁棒优化的目标一致，因为此类样本可能在错误方向上施加强烈梯度更新，因而危害最大。参数 λ 控制权衡：当 λ → 0 时权重趋于均匀，恢复未加权目标；当 λ → ∞ 时则趋近于对高风险样本的硬过滤。

局部改进保证。 所提出的重加权目标严格推广了原始目标：在 L̃_w 中令 w_t(·) ≡ 1 即可恢复未加权目标 L̃。一个自然的问题是，我们的加权机制是否以及在何种条件下严格优于未加权基线，即何时能保证梯度偏差减少 ‖B_w‖ < ‖B‖。

命题 1（严格改进的充分条件）。假设

Cov(η(z) ‖Σ_t ∇δ_t(z; θ)‖, (η(z) + f′(β Σ_t δ_t(z; θ)) ⟨Σ_t ∇δ_t(z; θ), η(z) Σ_t ∇δ_t(z; θ)⟩)) ≻ 0, (9)

其中 ≻ 表示逐分量比较算子。则对足够小的 λ > 0，重加权目标严格减少梯度偏差：‖B_w‖ < ‖B‖。

证明见附录 B.3。注意该条件仅为充分而非必要：它刻画了一种自然情形——降低噪声样本权重所带来的收益超过其在干净梯度方向上引入的失真。下面我们验证该条件在第 2 节定义的两种噪声模型下均成立。

  • α-不确定噪声。 当 η(z) = 1 − σ(α(r(y_w|x) − r(y_l|x))) 时，公式 (9) 可简化为在期望意义下要求 η(z) > σ(−Σ_t δ_t(z; θ))，即真实噪声率超过模型的隐式不确定性。代入噪声模型得 σ(−α Σ_t σ_t(z; θ)) > σ(−Σ_t σ_t(z; θ))，只要 α < 1 即严格成立。直观上，α < 1 意味着标注者比模型更不确定：标注者的标签比模型当前的偏好预测更嘈杂。这种情形自然出现在训练早期或模糊偏好对上，此时噪声缓解最为有益。当 α = 1 时，噪声项与置信项恰好抵消，重加权不带来收益。
  • ϵ-误标噪声。 当标签以恒定速率 η(z) = ϵ 均匀翻转时，噪声率与样本内容解耦，公式 (9) 简化为 ϵ > E_z[σ(−β Σ_t δ_t(z; θ))]（见附录 B.3）。由于 σ(0) = 1/2，对任何 ϵ < 1/2，该条件在初始化附近不成立，此时降低样本对权重移除的干净信号多于噪声。而当模型以足够差距分开大多数干净样本对时该条件成立，即训练后期——此时梯度日益被翻转标签主导，DPO 倾向于记住这些标签。

4 PORT：基于鲁棒词元级重加权的偏好优化

从理论到实践。 定理 1 表明 w* ∝ exp(−λ η(z) ‖∇δ_t(z; θ)‖)。然而，η(z) 与 ‖∇δ_t(z; θ)‖ 均无法直接观测，且在训练中计算它们代价高昂。因此，我们寻求实践中可近似最优加权的可行代理。

图 2：ΔCDF 与词元级梯度差异的散点图。由于 ‖∇δ_t(z; θ)‖ = ‖∇θ π_θ(y{w,t}|x) − ∇θ π_θ(y{l,t}|x)‖，我们分别计算选定与被拒绝响应的 SFT 梯度并求其差的范数来得到该量。在大规模词元总体上，两个量之间呈现隐含的线性趋势（Pearson r = 0.4526，n = 8,752），表明 ΔCDF 可作为定理 1 中噪声诱导梯度幅度的轻量级代理，无需访问不可观测的统计量。

我们假设批次内 logits 累积分布函数（CDF）的相对差异可作为此类代理。为形式化这一想法，考虑包含 B 个偏好对 的批次。我们将批次中所有非填充词元的对数概率汇集为单一参考集 ℛ = ∪{b=1}^B ∪{t=1}^{T^[b]} {π_θ(ỹ_{w,t}^[b] | x^[b], ỹ_{w,<t}^[b]), π_θ(ỹ_{l,t}^[b] | x^[b], ỹ_{l,<t}^[b])}，其中包含批次内所有非填充选定与被拒绝词元的分数。基于该参考集，定义经验 CDF F(u; ℛ) = (1/|ℛ|) Σ_{r∈ℛ} 𝟙(r < u)。

对第 b 个偏好对，进一步定义 F_{w,t}^[b] = F(π_θ(ỹ_{w,t}^[b] | x^[b], ỹ_{w,<t}^[b]); ℛ) 与 F_{l,t}^[b] = F(π_θ(ỹ_{l,t}^[b] | x^[b], ỹ_{l,<t}^[b]); ℛ)，它们度量选定与被拒绝词元 logits 在批次分布中的相对百分位排名。利用这些量，定义方向性 CDF 差异 ΔCDF = F_{l,t}^[b] − F_{w,t}^[b]。直观上，较大的正 ΔCDF 表明被拒绝词元相对于选定词元获得了异常高的概率质量，是偏好噪声的强烈信号。

为验证我们的假设，我们将真实梯度范数与所提出的基于 CDF 的度量进行了实证比较。具体而言，图 2 绘制了 SFT（监督微调）梯度范数 ‖∇δ_t(z; θ)‖ 与 α-不确定噪声的乘积相对于 ΔCDF = F_{l,t}^[b] − F_{w,t}^[b] 在 8,752 个词元上的散点。结果显示强正线性相关，Pearson 相关系数 r = 0.4526。这一实证证据表明，易于计算的词元级 CDF 差异能有效捕捉底层梯度范数的幅度。特别地，具有较大 ΔCDF 的词元倾向于产生更大的梯度范数，恰好对应定理 1 指出应赋予较低可靠性权重的词元——因为这些高梯度、高噪声位置在损坏情形下对梯度更新的危害最大。

受此观察启发，我们将基于 CDF 的代理代入理论最优加权函数，得到计算高效的重加权方案。具体而言，定义第 b 个偏好对位置 t 的词元级权重为：

w_t^[b] = γ exp(−ρ(F_{l,t}^[b] − F_{w,t}^[b])) (10)

其中 γ 与 ρ 为缩放超参数。重要的是，我们对加权函数不施加归一化约束。最后，将这些权重纳入 (3)：

L̃w(θ) = E{(x^[b],ỹ_w^[b],ỹ_l^[b])∼D̃} [f(β Σ_{t=1}^T w_t^[b] · δ_t^b)]，其中 δ_t^b = log(π_θ(ỹ_{w,t}^[b]|x^[b], ỹ_{w,<t}^[b]) π_ref(ỹ_{l,t}^[b]|x^[b], ỹ_{l,<t}^[b]) / (π_θ(ỹ_{l,t}^[b]|x^[b], ỹ_{l,<t}^[b]) π_ref(ỹ_{w,t}^[b]|x^[b], ỹ_{w,<t}^[b]))) (11)

词元级加权作为广义序列级加权。 现有序列级方法可视为对所有词元统一施加单个标量权重的特例，即 w_t^[b] = w^seq。相比之下，PORT 允许 w_t^[b] 随位置变化，实现对序列中哪些部分对学习贡献更强的细粒度控制。

重要的是，我们对 {w_t^[b]} 不施加归一化约束，每个词元权重基于其局部 CDF 信号独立确定。这种设计使方法能自然适应不同的损坏模式。当噪声为局部性时，仅部分词元权重受影响，其余词元基本不变。当噪声分布于整个序列时，方向性 CDF 差距 F_{l,t}^[b] − F_{w,t}^[b] 在各位置持续较大，导致整个偏好对被一致地降权或升权。

总体而言，PORT 在不增加反向传播开销的情况下实现了命题 1 所刻画的偏差减少特性。通过选择性抑制不可靠或高噪声词元并保留有信息量的词元，它在受损偏好监督下保持鲁棒。

5.4 PORT 将梯度集中于可靠词元

为研究所提加权机制对学习动态的影响，我们跟踪了标准 DPO 与 PORT 两个模型在 30 个梯度步内的逐样本训练损失。两个模型均以 Qwen2.5-0.5B [19] 为基础策略，在从 HH-RLHF 数据集抽取的 128 个样本子集上训练。

为按偏好可靠性对样本对分组，我们使用一种与训练时差距 Δ_t^[b] 不同的诊断分数。对每个样本对 z，我们在任何偏好训练之前对初始策略 π_{θ_0} 在真实选定与被拒绝响应 上评估一次，计算初始分离分数 m_0(z) := F̄w(z) − F̄_l(z)，其中 F̄_w(z) 与 F̄_l(z) 分别为 y_w 与 y_l 所有非填充词元的经验 CDF 排名平均值。较大的 m_0(z) 表示 π{θ_0} 已将选定响应的排名远高于被拒绝响应；较小的 m_0(z) 表示两个响应获得相近排名，即该样本对对模型而言是模糊的。我们按 m_0(z) 的中位数将 128 个样本对划分为高分离组与低分离组各 64 对，并在全部 30 步中保持该划分不变。两组分离度差异显著：高分离样本对 m_0 = 0.367 ± 0.167（范围 [0.151, 0.801]），低分离样本对为 0.064 ± 0.039（范围 [0.000, 0.146]）。作为独立检验，奖励模型在 82.8% 的高分离样本对上与真实排序一致，而在低分离样本对上仅为 59.4%，只略高于随机水平。在 α-不确定噪声模型下，翻转概率 η(z) 随奖励差距减小而增大，因此高分离样本对是标签最可能保持正确的样本对，而低分离样本对最易发生翻转。真实标签仅用于这一事后诊断。

高差距组由选定与被拒绝奖励分布分离良好的样本组成，代表可靠的偏好标注；相反，低差距组由奖励分布重叠的样本组成，代表噪声或模糊标签。如图 3(a) 所示，在标准 DPO 下两组表现出几乎相同的损失轨迹。模型无视样本固有标签质量而一视同仁，到第 30 步收敛到相近的低损失。相比之下，图 3(b) 揭示了 PORT 下的明显分化：高差距样本以更快速度达到显著更低的损失，而低差距样本在整个训练过程中明显滞后。这一分化从实证上验证了 PORT 基于 ΔCDF 的加权成功将梯度信号集中于可靠、分离良好的样本对，使模型能够更高效地从可信样本学习偏好区分，同时安全地边缘化噪声标注的影响。

6 结论

在本工作中，我们提出了 PORT（Preference Optimization via Robust Token-level reweighting），一个在噪声偏好标注下实现鲁棒 LLM 对齐的细粒度框架。与现有序列级方法或依赖外部奖励模型的方法不同，PORT 通过词元 logits 的经验 CDF 执行词元级重加权——这是一种轻量级、仅需前向传播的代理方法，不产生额外的反向传播开销。在理论上，我们通过最小化噪声诱导梯度偏差的上界推导出最优加权函数，并建立了在 ϵ-误标与 α-不确定两种噪声模型下 PORT 保证严格减少该偏差的充分条件。在实证上，我们通过在 AlpacaFarm、Anthropic HH 和 PKU-Beaver 上的大量实验证明，PORT 在多种噪声设置和模型架构下持续优于广泛的序列级基线方法。

附录 A 相关工作

A.1 大语言模型的基于偏好的对齐

将大语言模型与人类偏好对齐已成为现代 NLP 的核心问题 [31]。基于人类反馈的强化学习（RLHF）[18] 是使用最广泛的方法之一，其从人类标注训练奖励模型，再用其指导策略优化。尽管取得了成功，RLHF 需要训练额外的奖励模型并执行强化学习，使流程复杂且不稳定。直接偏好优化（DPO）[20] 最近被提出作为一种更简单的替代方案，直接利用成对偏好数据优化策略而无需显式训练奖励模型。DPO 使用 Bradley–Terry 模型 [3] 形式化偏好学习，并优化一个将策略隐式正则化向参考模型靠拢的监督目标。后续工作 [7, 15] 以不同目标、正则化策略和理论分析扩展了 DPO，展示了具有改进稳定性的竞争性能。虽然这些方法显著提升了对齐质量，但它们共享一个在实践中很少满足的假设：可获得干净、无噪声的偏好标注 [25]。

A.2 噪声反馈下的鲁棒偏好优化

标注大规模偏好数据集仍然成本高昂且劳动密集，不可避免地损害标注质量。实证研究表明，常用数据集中 20%-40% 的偏好标注存在标注错误 [13]，凸显了该问题的现实严重性。研究者日益认识到偏好对齐中噪声鲁棒性的重要性，催生了越来越多关于鲁棒 DPO 变体的工作。

一条研究路线通过标签平滑应对噪声。保守 DPO（cDPO）[16] 引入保守平滑项来降低可能被翻转标签的影响，在有界噪声率下提供可证明的鲁棒性保证。鲁棒偏好优化（ROPO）[13] 进一步引入自适应平滑机制，根据估计的噪声水平调整校正强度。然而，这两种方法都对响应中的所有词元施加均匀校正，无法考虑标注质量的词元级差异。

第二条路线通过数据过滤应对噪声。Filtered DPO [17] 使用预训练奖励模型为每个偏好对打分，并过滤掉奖励差距低于阈值的样本。自适应批次样本调度（SamS）[8] 采用批次级训练样本调度方法，动态自适应地调度训练样本。虽然有效，但这些方法重新引入了依赖奖励模型流程的计算开销与误泛化风险，且即使只有部分词元受损也可能丢弃整个样本对。

第三条路线通过重加权应对噪声。分布鲁棒化 DPO（Dr.DPO）[26] 基于估计的噪声率赋予样本对级权重，以降低受损样本的影响。Winsorized 直接偏好优化[15] 在序列级应用 Winsorized 重加权以限制异常偏好对的影响。Im 与 Li [9] 对偏好优化在噪声反馈下的泛化能力进行了理论分析，刻画了噪声降低对齐质量的条件。虽然这些重加权方法提升了鲁棒性，但它们仍是序列级方法，为每个响应对赋予单个标量权重，忽略了序列内部的词元级差异。

A.3 词元级建模与细粒度对齐

另一条平行的研究路线探索了词元级建模，作为序列级偏好优化的更细粒度替代方案。TDPO [30] 提出词元级 DPO 形式化，将偏好信号分解到单个词元上，使目标能够反映每个词元对整体偏好的贡献。与我们的工作最密切相关的是 TIS-DPO [14]，它引入由外部奖励模型估计的词元级重要性采样权重，在词元级实现细粒度噪声缓解。然而，TIS-DPO 继承了依赖奖励模型方法的局限：它需要一个额外模型进行权重估计，带来计算开销与误泛化风险。LLMDoctor [22] 提出用于测试时对齐的流引导词元级偏好优化，而 TIDPO [29] 使用由注意力权重导出的词元重要性分数来引导偏好优化目标。

受这些观察启发，我们从词元级视角研究噪声反馈下的偏好优化。我们不为每个样本对赋予单一权重，而是设计一种词元级加权机制，利用批次内 logits 的经验分布估计每个词元的相对质量。这能够更准确地识别受损区域，并带来相比序列级方法更优的鲁棒性。

附录 B 理论证明

B.1 梯度偏差

给定正常设定下的 DPO/IPO 损失：

ℓ(x, y_w, y_l; θ) = L*(θ) = E_{(x,y_w,y_l)∼D} [f(σ(r_ϕ(x, y_w) − r_ϕ(x, y_l)))] (12)
= E_{(x,y_w,y_l)∼D} [f(β log(π_θ(y_w|x)/π_ref(y_w|x)) − β log(π_θ(y_l|x)/π_ref(y_l|x)))]

DPO 情形下 f(x) = −log σ(x)，IPO 情形下 f(x) = (x − 1/2)²。因此公式 (12) 可重写为：

ℓ(z; θ) = E_{(z)∼D} f(βh(z; θ)) (13)

在以下证明中，当 x、y_w、y_l 隐含可知时，我们将 h(θ; x, y_w, y_l) 简记为 h(θ)。考虑实例依赖噪声 η(x, y, y′) 下的标准目标与加权目标：

L(θ) = E[(1−η(z)) ℓ(z; θ) + η(z) ℓ(−z; θ)] (14)

L_w(θ) = E[((1−η(z)) ℓ_w(z; θ) + η(z) ℓ_w(−z; θ))]

定义 1（梯度偏差）的证明。 噪声设定下标准 DPO 的梯度为：

g(θ) = ∇L(θ) = E[∇ℓ(z; θ)] (15)

g̃(θ) = ∇L̃(θ) = E[(1−η(z))∇ℓ(z; θ) + η(z)∇ℓ(−z; θ)]

B = Δg = g̃(θ) − g(θ) = E[η(z)(∇ℓ(−z; θ) − ∇ℓ(z; θ))] ∎

定义 2（加权梯度偏差）的证明。 对加权目标，梯度为：

g_w(θ) = ∇L_w(θ) = E[∇ℓ_w(z; θ)] (16)

g̃_w(θ) = ∇L̃_w(θ) = E[((1−η(z))∇ℓ_w(z; θ) + η(z)∇ℓ_w(−z; θ))]

Δg_w = g̃_w(θ) − g_w(θ) = E[η(∇ℓ_w(−z; θ) − ∇ℓ_w(z; θ))]

我们希望最小化总偏差 B_w = g_w(θ) − g(θ)：

B_w = [g̃_w(θ) − g_w(θ)] + [g_w(θ) − g(θ)] = Δg_w + R_b (17)

其中 R_b = g_w(θ) − g(θ) 表示重加权干净数据引入的失真。∎

B.2 权重函数的最优解

我们现在关注 ∇ℓ(−z; θ) − ∇ℓ(z; θ)。根据链式法则：

∇ℓ(−z; θ) − ∇ℓ(z; θ) = ∇_θ(f(−β Σ_t δ_t(z; θ))) − ∇_θ(f(β Σ_t δ_t(z; θ))) (18)
= β(f′(−β Σ_t δ_t(z; θ)) × (−Σ_t ∇_θ δ_t(z; θ)) − f′(β Σ_t δ_t(z; θ)) × (∇_θ Σ_t δ_t(z; θ)))
= −β ∇_θ Σ_t δ_t(z; θ) × (f′(−β Σ_t δ_t(z; θ)) + f′(β Σ_t δ_t(z; θ)))

在标准偏好学习框架中，我们证明 f′(−β Σ_t δ_t(z; θ)) + f′(β Σ_t δ_t(z; θ)) 的取值为常数：

i. DPO：若 f(x) = −log σ(x)，则 f′(x) + f′(−x) = −1。因此 (∇ℓ(−z; θ) − ∇ℓ(z; θ)) = β ∇_θ Σ_t δ_t(z; θ)。

ii. IPO：若 f(x) = (x − 1/2)²，则 f′(x) = 2(x − 1/2) 且 f′(x) + f′(−x) = −2。因此 (∇ℓ(−z; θ) − ∇ℓ(z; θ)) = 2β ∇_θ Σ_t δ_t(z; θ) ∝ ∇_θ Σ_t δ_t(z; θ)。

iii. SLiC：若 f(x) = max(0, 1−x)，则当 x ∈ [−1, 1] 时 f′(x) + f′(−x) = −2，否则为 −1。因此 (∇ℓ(−z; θ) − ∇ℓ(z; θ)) ∝ ∇_θ Σ_t δ_t(z; θ)。

类似地，对 ∇ℓ_w(−z; θ) − ∇ℓ_w(z)，可得：

∇ℓ_w(−z; θ) − ∇ℓ_w(z; θ) = ∇_θ(f(−β Σ_t w(z,t) δ_t(z; θ))) − ∇_θ(f(β Σ_t w(z,t) δ_t(z; θ))) (19)
= β(f′(−β Σ_t w(z,t) δ_t(z; θ)) × (−∇_θ Σ_t w(z,t) δ_t(z; θ)) − f′(β Σ_t w(z,t) δ_t(z; θ)) × (∇_θ Σ_t w(z,t) δ_t(z; θ)))
= −β ∇_θ Σ_t w(z,t) δ_t(z; θ) × (f′(−β Σ_t w(z,t) δ_t(z; θ)) + f′(β Σ_t w(z,t) δ_t(z; θ)))

并假设 f′(h_w(z; θ))/f′(h(z; θ)) ≤ f′(−w_max H)/f′(H) := K，于是噪声诱导偏差可表示为：

Δg_w = E[‖η(z) Σ_{t=1}^T (f′(Σ_t w(z,t) δ_t(z; θ))/f′(Σ_t δ_t(z; θ))) w_t ∇θ δ_t(z; θ)‖] (20)
≤ K E[‖η(z) Σ{t=1}^T w_t ∇θ δ_t(z; θ)‖]
≤ K Σ{t=1}^T E[η(z) w(z,t) ‖∇_θ δ_t(θ)‖]

由 Jensen 不等式，‖E(w_t(z; θ) η(z) ∇δ_t(z; θ))‖ ≤ E(w_t(z; θ) η(z) ‖∇δ_t(z; θ)‖)。最小化该上界即可有效控制 Δg_w。

对重加权偏差 R_b = E(∇ℓ_w(z; θ) − ∇ℓ(z; θ))，假设梯度范数以 M = sup_z ‖∇ℓ(z; θ)‖/β 为界，则有：

‖R_b‖ = ‖E(∇ℓ_w(z; θ) − ∇ℓ(z; θ))‖ (21)
≤ ‖f′(Σ_t w(z,t) δ_t(z)) Σ(w_t − 1) ∇δ_t + (f′(Σ_t w(z,t) δ_t(z)) − f′(Σ_t δ_t(z))) Σ_t ∇δ_t‖
≤ L_0 Σ_t |w_t − 1| ‖∇δ_t‖ + (f′(Σ_t w(z,t) δ_t(z)) − f′(Σ_t δ_t(z))) Σ_t ∇δ_t
≤ L_0 Σ_t |w_t − 1| ‖∇δ_t‖ + L_1 ‖Σ_t w(z,t) δ_t(z) − Σ_t δ_t(z)‖ ‖Σ ∇δ_t‖
≤ (L_0 + L_1 T D) Σ_t E_p[|w_t − 1|]

其中 L_0 为 ∇δ_t 梯度范数的上界，L_1 为 f′ 的 Lipschitz 常数，D 为 δ_t 的上界，T 为 Σ_t ∇δ_t 的上界。

因此，最小化 D_KL(p_w ∥ p) 可直接控制 ‖R_b‖ 的上界。我们引入以下引理：

引理 1。设 X ∼ P 为随机变量。设 w, g: ℝ → ℝ 为可测函数，使得 w(X) 可积且 E_{X∼P}[w(X)] = 1。正则化优化问题：

min_w (β E(w(z; θ) ϕ(z; θ)) + β (1/λ) D_KL(p_w ∥ p)) (22)

具有非平凡最优解 w* ∝ exp(−λ ϕ(z, θ))。

定理 1 的证明。 使用拉格朗日乘子法，构造泛函：

F = E(w(z; θ) ϕ(z; θ)) + (1/λ) E(w(z; θ) log(w(z; θ))) (23)
= E(w(z; θ)(ϕ(z; θ) + (1/λ) log(w(z; θ))))

假设 w(z) = exp(−ϕ(z, θ) λ)/Z 且 Z = E[exp(−λ ϕ(z; θ))]。对任意 z，ϕ(z; θ) + (1/λ) log(w) = −(1/λ) log Z。因此，

E[w(z; θ)(ϕ(z; θ) + (1/λ) log(w(z; θ)))] (24)
= E[w(z; θ)(ϕ(z; θ) + (1/λ) log(w(z; θ)) − (ϕ + (1/λ) log w(z; θ)))] + E[w(z; θ) · (−1/λ) log Z]
= (1/λ) E[w(z; θ) log(w(z; θ)/w(z; θ))] − (1/λ) log Z · E[w(z; θ)]
= (1/λ)(D_KL(p_w ∥ p_{w*}) − log Z)
≥ −(1/λ) log Z

由于 Z 为常数，且当且仅当 w = w 时 D_KL(p_w ∥ p_{w}) = 0。∎

B.3 有效状态分析

我们现在分析最优权重 w_λ(x) ∝ e^{−λ ϕ(x)} 何时有效减少总偏差。

命题 1 的证明。 定义 ϕ(z; θ) := β η(z) ‖∇δ_t(z; θ)‖ 及归一化权重：
