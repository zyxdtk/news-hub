摘要
模型合并无需额外训练，即可将多个特定任务微调的大语言模型（LLM）组合成一个单一的多任务模型。然而，已知合并后的模型会存在表征偏差：合并模型的隐藏状态与每个单独源模型的隐藏状态之间存在系统性漂移。先前的工作（Yang et al., 2024a）使用通过 L1 损失训练的轻量级校正模块，研究并缓解了基于编码器的视觉模型中的这种偏差。然而，由于解码器模型的自回归特性，这种偏差尚未在解码器模型中得到研究。因此，我们首先分析了解码器模型中的表征偏差问题，并揭示了编码器中不存在的两个挑战：（1）因果注意力掩码导致偏差在各个 token 位置上累积，需要依赖位置的校正；（2）并非所有 token 位置都同等重要，即高熵（决策关键）位置远比低熵位置重要。为了应对这些挑战，我们提出了通过手术进行解码器感知表征微调（DARTS）。DARTS 采用了一种新颖的熵加权 L1 损失，在错误最影响生成质量的高熵位置加大校正权重，并引入了逐位置加性偏差，在不产生过参数化的情况下捕获依赖位置的误差。我们在三个领域对 Llama-2-7B 模型进行了广泛评估：代码生成、数学推理和指令遵循，结果表明 DARTS 在仅增加极少参数（占总参数量的 0.1%）的同时，比标准手术方法取得了显著提升。

1 引言

图 1：合并后的 Llama-2-7B 模型与每个单独微调模型之间的逐 token L1 表征偏差，在最后一个 transformer 层测量。每一行是一个校准样本；每一列是一个 token 位置。在所有三个领域（代码、数学、指令）中，由于因果注意力掩码下的误差累积，我们看到偏差随 token 位置呈现增加趋势。这种依赖位置的结构激发了 DARTS 中提出的解码器感知校正。

大语言模型在从代码生成（Chen et al., 2021; Rozière et al., 2024）和数学推理（Cobbe et al., 2021; Luo et al., 2025; Wei et al., 2022）到开放式指令遵循（Ouyang et al., 2022）的广泛任务中展示了卓越的能力。然而，这些能力通常是通过特定任务的微调（Hu et al., 2021; Touvron et al., 2023）获得的，这导致了专业化模型的激增，每个模型都在其目标领域表现出色，但需要独立部署。随着专业化模型数量的增长，服务它们的成本也随之增加，使得多任务整合变得越来越有吸引力。

模型合并（Wortsman et al., 2022; Ilharco et al., 2023; Yadav et al., 2023; Yang et al., 2024b; Yadav et al., 2025）为这个问题提供了一个优雅的解决方案：将多个微调模型的权重组合成一个单一模型，该模型继承所有源模型的能力，而无需任何额外的训练数据或计算。诸如任务算术（Task Arithmetic, Ilharco et al., 2023）、TIES-Merging（Yadav et al., 2023）和 DARE（Yu et al., 2024）等方法已经表明，在权重空间中进行简单的算术运算（如添加缩放的任务向量、解决符号冲突或丢弃冗余参数）可以产生出人意料的有效多任务模型。这使得模型合并成为开源 LLM 生态系统中的标准工具（Goddard et al., 2024），从业者经常将指令微调、代码专业化和数学专业化的模型合并到统一的检查点中。

尽管取得了这些进展，但合并模型与其单独微调的对应模型之间仍存在巨大的性能差距。合并模型经常在一个或多个组成任务上发生退化（Ilharco et al., 2023; Yadav et al., 2023; Yang et al., 2024b），并且这种退化的严重程度在不同的任务、合并方法和模型规模之间不可预测地变化。理解合并为什么损害性能，并找到有原则的方法来缩小差距，仍然是一个开放的挑战。

Yang et al. (2024a) 最近为这种退化提供了一个令人信服的解释。通过可视化合并视觉模型（在八个分类任务上的 ViT-B/32, ViT-B/16, ViT-L/14）的隐藏表征，他们证明了合并模型存在表征偏差：合并模型提取的特征表征与每个单独微调模型的特征表征之间存在系统性差异。至关重要的是，他们表明表征偏差与任务性能相关：产生较小表征偏差的合并方法（例如 AdaMerging, Yang et al., 2024b）始终优于具有较大偏差的方法（例如权重平均）。基于这一见解，他们提出了表征手术：一个通过 L1 损失训练的轻量级低秩模块，用于预测并减去表征偏差，在所有合并方法中取得了显著的性能提升。

然而，最初的手术框架是专为基于编码器的视觉模型设计的。在 ViT 架构（Dosovitskiy et al., 2021）中，双向自注意力确保每个 token（图像块）同等地被所有其他 token 上下文化，产生的表征偏差在各个 token 位置上大致是均匀的。一个位置无关的手术模块在每个位置应用相同的校正，非常适合这种设置。同样，用于训练的均匀 L1 损失将所有 token 位置视为同等重要，当每个块对分类决策的贡献相似时，这是合理的。

基于解码器的 LLM 有着根本的不同。自回归 transformer 架构（Vaswani et al., 2017; Brown et al., 2020）在因果注意力掩码下从左到右处理 token：token $t$ 只能关注 token $0, 1, \ldots, t{-}1$。这种架构约束对表征偏差有两个后果，使得最初的手术框架显得不足：

首先，解码器模型中的表征偏差是依赖位置的。因为每个 token 的表征是从严格的因果上下文中计算得出的，所以在较早位置由权重空间合并引入的任何偏差都会通过注意力机制向前传播。后面的 token 不仅聚合了其自身位置的原始合并误差，还聚合了所有前面位置的累积误差。图 1 经验性地展示了这种效应：绘制合并模型和单独模型表征之间的逐 token L1 距离揭示了一个明显的增加趋势，后面位置的偏差比早期位置高 2-3 倍。一个在每个位置应用相同校正的位置无关手术模块，在结构上无法捕获这种模式，迫使它在欠校正后面 token 和过校正早期 token 之间进行妥协。

其次，并非所有 token 位置对生成质量都同等重要。在自回归 LLM 中，模型在每个位置的预测决定了生成序列中的下一个 token。在某些位置，模型非常自信，并将大部分概率质量分配给单个 token（例如，闭括号、确定性语法、常见短语）。在其他位置，模型将概率分布在许多合理的续写中；这些是决策关键位置，下一个 token 的选择有意义地影响生成输出的质量和正确性。高熵位置的小隐藏状态误差可以翻转 argmax 预测并级联到后续 token，而低熵位置的类似误差则被吸收而不产生后果。标准的 L1 损失（Yang et al., 2024a）均匀对待所有位置，将手术模块有限的校正能力浪费在不影响下游生成的位置上。图 2 说明了这个想法。

为了应对这些解码器特有的挑战，我们提出了通过手术进行解码器感知表征微调（DARTS），它通过两项互补的创新将表征手术适应到自回归设置中。首先，我们引入了熵加权 L1 损失（EWL1），它通过目标模型的预测熵对逐位置校正惩罚进行加权，将手术模块的能力集中在错误最影响生成质量的决策关键位置。其次，我们用位置校正模块增强了低秩内容校正，这是一个直接的逐位置加性偏差表，为每个 token 位置学习独立的校正向量，在不使网络过参数化的情况下捕获结构化的依赖位置的偏差。我们在由三个专门微调（代码生成、数学推理和指令遵循）合并而来的 Llama-2-7B（Touvron et al., 2023）模型上评估了 DARTS，表明它比原始手术方法取得了显著改进。

本文的主要贡献如下：
1. 我们分析了解码器模型中的表征偏差问题，并经验性地证明了编码器模型中不存在的两个挑战：因果注意力掩码下的依赖位置的偏差累积，以及自回归生成过程中产生的非均匀位置重要性。
2. 为了应对这些挑战，我们提出了 DARTS，它使用新颖的熵加权 L1 损失和位置校正模块，在决策关键位置加大校正权重，并执行依赖位置的偏差校正。
3. 我们进行了广泛的实验，表明 DARTS 减少了因果表征偏差，并在各种不同任务上显著提高了 MTL 性能，同时仅向模型增加了 0.1% 的参数。

图 2：解码器模型中 token 位置的非均匀重要性。我们展示了三个代表性领域（数学、代码、指令）。对于每个例子，我们说明了 token 级熵（$H$）并可视化了位置重要性（熵越高 = 重要性越高）。在低重要性位置注入相同幅度的表征偏差 $\delta$ 影响微乎其微，而在高重要性位置注入则会导致显著的性能下降。这激发了将校正集中在最关键位置的熵加权损失。

2 相关工作

多任务学习的模型合并。模型合并已成为传统多任务学习（Crawshaw, 2020; Zhang and Yang, 2022）的实用替代方案，后者需要集中数据收集和联合训练。早期工作表明，简单平均模型权重可以提高在相同任务上训练的模型的泛化能力（Wortsman et al., 2022），随后将这些扩展到合并在不同任务上训练的模型。任务算术（Ilharco et al., 2023）引入了任务向量的概念，定义为微调权重和预训练权重之间的差异 $\tau_{i}=\theta_{i}-\theta_{\text{pre}}$，并表明将缩放的任务向量添加到预训练模型中可以产生有效的多任务模型。TIES-Merging（Yadav et al., 2023）通过修剪、选举符号和仅合并对齐的组件来解决参数符号冲突和冗余问题。DARE（Yu et al., 2024）随机丢弃增量参数并重新缩放幸存者以减少干扰。Fisher-Merging（Matena and Raffel, 2022）使用 Fisher 信息对参数重要性进行加权，而 RegMean（Jin et al., 2023）基于训练统计量进行重新加权。最近，AdaMerging（Yang et al., 2024b）学习任务级或层级的合并系数，Concrete（Tang et al., 2026）寻找共享子空间，ZipIt（Stoica et al., 2024）通过对齐中间特征来合并模型。这些方法的全面调查可以在 Yadav et al. (2025) 中找到。上述所有方法都在权重空间中操作，没有明确解决由此产生的表征级差异。

表征手术。Yang et al. (2024a) 将表征偏差确定为模型合并中的关键障碍：合并的 ViT 模型（Dosovitskiy et al., 2021; Radford et al., 2021）的隐藏表征与单独微调模型的隐藏表征发生系统性偏离，这种偏离与任务性能退化相关。他们提出了一个轻量级的类适配器（Houlsby et al., 2019）校正模块 $\Phi(Z)=W_{\text{up}}\cdot\ReLU(W_{\text{down}}\cdot Z)$，通过 L1 损失训练以从合并表征中减去偏差。这种方法在三种 ViT 架构的八个图像分类任务上得到了验证，在权重平均、任务算术、TIES-Merging 和 AdaMerging 之上应用时取得了持续的增益。然而，最初的框架假设位置无关的校正和均匀的损失加权。这些假设对于双向编码器模型是有充分根据的，但正如我们所证明的，对于自回归解码器模型是不够的。

推理时干预和路由。除了静态权重空间合并，最近的工作探索了用于 LLM 能力整合的推理时方法。激活引导（Turner et al., 2023; Li et al., 2023）在生成循环期间动态注入或减去引导向量，以在测试时调节模型行为。混合专家架构（Shazeer et al., 2017; Fedus et al., 2022）和动态路由机制（Muqeeth et al., 2023）维护多个专家子网络，并采用学习到的路由器在逐 token 或逐层基础上在它们之间进行选择。专家组合方法（Tang et al., 2024）在推理时组合多个专门的适配器或模块。虽然这些方法提供了灵活的能力控制，但它们在几个实际维度上与 DARTS 存在根本不同。首先，路由和 MoE 方法需要在 VRAM 中加载多个模型块或扩展的参数集，而 DARTS 保持单一的模型占用空间，仅增加约 0.1% 的额外参数。其次，推理时引导和路由增加了动态计算分支，从而增加了服务延迟，而 DARTS 应用的静态校正具有与基础模型相同的延迟。第三，DARTS 产生标准的单检查点模型，可作为直接替代品，无需专门的推理引擎。我们将这些方法视为互补：DARTS 最适合用于低开销、永久性地整合合并模型，而推理时方法以部署复杂性为代价提供了更大的灵活性。

3 模型合并中的因果表征偏差

我们首先建立符号并定义问题（第 3.1 节），然后经验性地表征解码器模型中表征偏差的依赖位置结构（第 3.3 节）。然后我们介绍 DARTS 的两个核心组件：位置校正模块（第 3.4 节）和熵加权 L1 损失（第 3.5 节）。

3.1 预备知识

3.1.1 符号
我们考虑通过在任务 $\mathcal{T}{1},\dots,\mathcal{T}{K}$ 上微调共享预训练模型获得的 $K$ 个特定任务模型。设 $M$ 表示合并模型，$M^{}{k}$ 表示第 $k$ 个单独的微调（每个任务的“目标”）。对于分词长度为 $T$ 的输入序列 $x{1:T}$，我们表示：
- $h^{M}_{t}\in\mathbb{R}^{H}$：合并模型在位置 $t$ 的最后一层隐藏状态
- $h^{k}{t}\in\mathbb{R}^{H}$：目标模型 $k$ 对应的隐藏状态
- $W{U}^{*k}\in\mathbb{R}^{V\times H}$：目标模型 $k$ 的 LM 头（解嵌入矩阵）

其中 $H=4096$（隐藏层大小，Llama-2-7B），$V=32,000$（词汇表大小），$T_{\max}=512$（校准最大序列长度）。对于每个任务 $k$，我们学习一个手术模块 $\mathcal{S}{k}$，它产生校正后的隐藏状态 $\hat{h}{t}=\mathcal{S}{k}(h^{M}){t}$。在上下文清晰的地方，我们省略 $k$ 下标。

3.1.2 任务向量和合并
给定预训练模型 $\theta_{\text{pre}}$ 和在任务 $k$ 上微调的模型 $\theta_{k}$，任务向量为 $\tau_{k}=\theta_{k}-\theta_{\text{pre}}$。任务算术（Ilharco et al., 2023）通过以下方式合并 $K$ 个任务：
$$ \theta_{\text{merged}}=\theta_{\text{pre}}+\lambda\sum_{k=1}^{K}\tau_{k} \quad (1) $$
其中 $\lambda$ 是缩放系数。其他合并方法（TIES-Merging, DARE, AdaMerging）修改了任务向量的组合方式，但共享相同的一般框架（Yadav et al., 2025）。

3.1.3 表征偏差
遵循 Yang et al. (2024a)，我们将逐位置表征偏差定义为合并模型和目标模型隐藏状态之间的归一化 L1 距离：
$$ \delta_{t}=\frac{1}{H}|h^{M}{t}-h^{*k}{t}|_{1} \quad (2) $$
在编码器模型中，Yang et al. 表明这种偏差在 token 位置上近似均匀，并与下游任务性能相关。我们在下一节将此分析扩展到解码器模型。

3.2 标准手术（基线）
原始的表征手术（Yang et al., 2024a）采用秩为 $r$ 的低秩瓶颈和内容校正函数 $c(h)=W_{\text{up}}\,\ReLU(W_{\text{down}}\,h)$：
$$ \hat{h}{t}=h^{M}{t}-c(h^{M}{t}) \quad (3) $$
其中 $W{\text{down}}\in\mathbb{R}^{r\times H}$ 和 $W_{\text{up}}\in\mathbb{R}^{H\times r}$。遵循 Yang et al. (2024a)，$W_{\text{up}}$ 被零初始化，使得手术模块作为恒等映射开始，这意味着未训练的模块不产生校正。参数数量：$2rH$。至关重要的是，该模块是位置无关的：相同的参数在每个 token 位置 $t$ 上相同地应用。

3.3 解码器中依赖位置的偏差
为了检查基于编码器手术的均匀偏差假设是否适用于解码器模型，我们使用 Llama-2-7B 合并模型计算了每个领域提示校准集上的逐 token L1 偏差 $\delta_{t}$（公式 2）。

结果（图 1）揭示了编码器模型中不存在的显著模式：表征偏差随 token 位置呈现明显的增加趋势。早期位置（0-50）的 token 显示出相对较低的偏差，而后期位置（100-256）的 token 表现出明显更高的偏差，通常是早期 token 的 2-3 倍。这种模式在所有三个领域（代码、数学、指令遵循）中都是一致的。

解释直接来自因果注意力机制（Vaswani et al., 2017）。在编码器模型（例如 ViT）中，双向注意力将合并误差均匀地分布在所有 token 上。在解码器模型中，token $t$ 只关注前面的上下文 ${0,1,\ldots,t{-}1}$。如果较早的 token 带有来自合并的表征偏差，token $t$ 会通过注意力聚合这些有偏差的表征，导致偏差复合。每个后续位置不仅累积其自身的合并误差，还累积所有前面位置的误差，产生观察到的单调递增模式。

这对手术模块设计有直接影响：在每个位置应用相同校正幅度的位置无关校正，必须在欠校正后面 token（偏差最大）和过校正早期 token（偏差最小）之间进行妥协。这激发了下面描述的位置感知校正。

3.4 位置校正模块
为了解决表征偏差的依赖位置结构，我们用直接的逐位置加性偏差 $b\in\mathbb{R}^{T_{\max}\times H}$ 增强内容校正，零初始化：
$$ \hat{h}{t}=h^{M}{t}-\underbrace{c(h^{M}{t})}{\text{内容 (依赖输入)}}-\underbrace{b_{t}}{\text{位置 (独立于输入)}} \quad (4) $$
该设计解耦了表征偏差的两个来源。内容校正 $c(h^{M}{t})$ 处理依赖输入的误差，特别是随位置 $t$ 的特定输入而变化的偏差。位置偏差 $b_{t}$ 捕获在输入之间一致的系统性逐位置偏移，反映了第 3.3 节中记录的因果误差累积的累积效应。

一个关键的设计选择是 $b_{t}$ 是每个位置的自由参数，而不是由网络参数化。每个位置的校正独立于其他位置，不能组合。这提供了结构正则化，防止位置校正过拟合到小的校准集。我们探索了网络参数化的替代方案（即并行适配器；见附录 E），但发现直接的加性偏差在没有额外超参数的情况下，始终匹配或优于这些更复杂的架构。

参数数量。$2rH+T_{\max}H$。对于 Llama-2-7B（$H=4096, r=16, T_{\max}=512$）：每个领域约 2.2M，3 个领域总共约 6.6M（约占 7B 的 0.1%）。

3.5 熵加权 L1 损失
标准手术目标（Yang et al., 2024a）最小化校正后和目标表征之间的 L1 距离，平等对待所有 token 位置：
$$ \mathcal{L}{\text{L1}}=\frac{1}{H\,|\mathcal{T}|}\sum{t\in\mathcal{T}}|\hat{h}{t}-h^{*}{t}|_{1} \quad (5) $$
其中 $\mathcal{T}$ 是非填充位置的集合。这种均匀加权非常适合分类任务，其中所有块位置对最终预测的贡献相似。然而，在自回归生成中，并非所有位置都同等重要。

我们提出通过目标模型的预测熵对每个位置进行加权。设 $p^{}{t,v}=\softmax(W{U}^{}h^{}{t}){v}$ 为目标模型在位置 $t$ 的预测分布，并设 $\mathcal{H}{t}=-\sum{v}p^{}{t,v}\log p^{}{t,v}$ 表示其熵。熵加权 L1 损失为：
$$ \mathcal{L}{\text{EWL1}}=\frac{1}{H\,|\mathcal{T}|}\sum_{t\in\mathcal{T}}\frac{\mathcal{H}{t}}{\bar{\mathcal{H}}}|\hat{h}{t}-h^{}{t}|{1} \quad (6) $$
其中 $\bar{\mathcal{H}}=\frac{1}{|\mathcal{T}|}\sum{t^{\prime}}\mathcal{H}_{t^{\prime}}$ 是平均熵。单位均值归一化确保整体损失规模与标准 L1 保持可比，允许使用相同的学习率而无需调整。

直觉如下。在高熵位置，目标模型将概率分布在许多合理的下一个 token 上，小的隐藏状态误差可以翻转 argmax 预测，改变将要生成的 token 并级联到后续的自回归步骤。在低熵位置（例如，确定性语法、常见短语、标点符号），模型的预测对扰动具有鲁棒性：即使是中等的隐藏状态误差也不会改变 argmax。通过增加高熵位置的权重，EWL1 将手术模块有限的校正能力集中在实际影响生成质量的位置上，类似于重要性加权蒸馏（Hinton et al., 2015）专注于信息丰富的训练样本。

4 实验设置

4.1 模型和合并
我们使用 Llama-2-7B（Touvron et al., 2023）（$H=4096, V=32,000$）作为预训练基础，并合并三个公开可用的微调：Llama-2-7B-Instruct (Meta)、WizardMath-7B-v1.0（Luo et al., 2025）和 Llama-2-7B-Code（Rozière et al., 2024）。

我们在总计超过 124 个配置的广泛超参数扫描中评估了四个系列的合并方法。任务算术（Ilharco et al., 2023）使用缩放系数 $\lambda\in{0.3,0.5,0.7,0.9,1.0}$ 合并任务向量。权重平均涵盖 22 种权重分布，包括等权重、单模型主导（一个模型占 40-80% 权重）和成对重度配置。TIES-Merging（Yadav et al., 2023）在结合权重 $\in{0.3,0.5,0.7,1.0,1.2,1.5}$ 和密度 $\in{0.1,0.2,0.3,0.5,0.7,0.9}$ 的 42 个配置上进行扫描，包括对称和非对称的每模型权重分配。DARE（Yu et al., 2024）涵盖 dare_ties 和 dare_linear 变体的 60 个配置，权重 $\in{0.3,0.5,0.7,1.0,1.2}$ 和密度 $\in{0.1,0.2,0.3,0.5,0.7,0.9}$。所有合并模型均使用 mergekit（Goddard et al., 2024）生成。对于每种合并方法，我们通过汇总基准得分选择性能最佳的配置，作为后续手术实验中该方法的代表性基线。

4.2 评估指标
我们在涵盖互补能力的三个基准上进行评估。对于代码生成，我们使用 HumanEval（Chen et al., 2021）（164 个问题）并报告 Pass@1，它衡量第一次尝试正确解决的问题比例。对于数学推理，我们使用 GSM8K（Cobbe et al., 2021）的测试集（1,319 个问题），采用思维链零样本提示（Wei et al., 2022），并报告准确率。对于指令遵循，我们使用 AlpacaEval（Dubois et al., 2024）（805 条指令），并报告由 GPT-4.1 评判的针对 GPT-3.5-Turbo 的胜率。

除了这些任务级指标外，我们还报告 L1 减少量（$\rho_{L_{1}}$）作为手术在隐藏状态空间中有效校正表征偏差的指标。设 $\delta^{\text{before}}{t}=\frac{1}{H}|h^{M}{t}-h^{}{t}|{1}$ 和 $\delta^{\text{after}}{t}=\frac{1}{H}|\hat{h}{t}-h^{}{t}|{1}$ 分别表示手术前后的逐位置 L1 残差。L1 减少量为：
$$ \rho_{\text{$L_{1}$}}=1-\frac{\sum_{t\in\mathcal{T}}\delta^{\text{after}}{t}}{\sum{t\in\mathcal{T}}\delta^{\text{before}}{t}} \quad (7) $$
较高的 $\rho{\text{L1}}$ 表明已去除更大比例的表征偏差。正如 Yang et al. (2024a) 所示，该指标与编码器模型中的下游任务性能相关；我们在第 6 节中检查解码器模型是否保持相同的关系。

4.3 实现细节
所有合并模型均使用 mergekit（Goddard et al., 2024）从三个 Llama-2-7B 微调生成：Llama-2-7B-Instruct、WizardMath-7B-v1.0 和 Llama-2-7B-Code。手术模块使用 Adam 优化器（$\beta_{1}=0.9, \beta_{2}=0.999, \eta=10^{-3}$）训练 500 次迭代，使用 50 个特定领域的校准样本（代码用 HumanEval 提示，数学用 GSM8K 问题，指令用 AlpacaEval 指令），分词最大长度为 512。校准样本完全从最终评估集中排除，以确保主要结果代表仅在未见测试样本上评估的真正零样本性能（拆分详情见表 7）。隐藏状态从两个冻结模型中以 bfloat16 预计算并缓存在 GPU 上；仅更新手术参数。对于评估，HumanEval 和 GSM8K 通过 lm-eval-harness（Gao et al., 2024）运行，使用贪婪解码（温度 0.0）和 HuggingFace 后端；HumanEval 和 GSM8K（思维链，零样本）的最大生成 token 数为 512。AlpacaEval 响应通过采样生成（温度 0.7，top-p 0.9，最大 1024 个 token），并由 GPT-4.1 作为评判者与 GPT-3.5-Turbo 进行成对评判。所有实验均在 NVIDIA A100-SXM4-80GB GPU 上进行。

8 结论
我们将表征手术从基于编码器的视觉模型扩展到基于解码器的语言模型，并确定了自回归设置特有的两个基本挑战：因果注意力掩码下的依赖位置的偏差累积，以及语言生成结构引起的非均匀位置重要性。为了应对这些挑战，我们提出了 DARTS，它结合了熵加权 L1 损失（将校正集中在决策关键位置）和结构正则化的位置校正模块（捕获单调递增的偏差模式）。我们在三个不同领域的 Llama-2-7B 合并模型上的实验表明，损失函数设计是主导因素：仅熵加权 L1 就占了大部分性能增益，而位置校正提供了互补的改进。在涵盖代码、数学和指令遵循领域的 Llama-2-7B 合并模型上，DARTS 比原始手术方法取得了显著改进。

局限性
1. 序列长度泛化。位置校正偏差表 $b\in\mathbb{R}^{T_{\max}\times H}$ 无法外推到 $T_{\max}=512$ 之外。超过 $T_{\max}$ 的位置接收零位置校正（内容校正仍然适用）。未来的工作可以探索连续位置函数或相对位置编码。
2. 规模。我们仅在 Llama-2-7B 上进行评估。DARTS 是否能转移到更大的模型（13B, 70B）或不同的架构（Mistral, Jiang et al., 2023）仍有待测试。
3. 领域不对称。熵加权可能会降低对代码生成至关重要的位置的优先级（例如，语法上确定但在语义上关键的 token），这可能解释了依赖领域的增益。

附录 B 校准成本
尽管 DARTS 引入了可忽略的推理开销（约 0.1% 的额外参数），但离线校准阶段需要通过合并和目标模型进行前向传递，以预计算隐藏状态和预测熵权重。为了使实际的资源需求完全透明，我们使用 Llama-2-7B-Code 作为目标模型，在单个 NVIDIA A100-SXM4-80GB GPU 上测量端到端校准成本，采用标准协议：50 个未标记的校准提示，$T_{\max}=512$，批次大小 8，500 次训练迭代，秩 16 手术瓶颈。
