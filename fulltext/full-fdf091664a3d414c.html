URL 来源：https://www.anthropic.com/news/anthropic-codepath-partnership Markdown 内容：

Anthropic 正与 CodePath（美国规模最大的高校计算机科学教育提供方）展开合作，共同重构其编程课程体系，以应对人工智能对软件开发领域的深刻变革。CodePath 将 Claude 和 Claude Code 置于其课程与职业发展项目的核心位置，使超过 20,000 名来自社区学院、州立大学及传统黑人学院和大学（HBCUs）的学生，在学习过程中即可接触前沿人工智能工具。

超过 40% 的 CodePath 学生来自年收入低于 5 万美元的家庭，CodePath 致力于为他们提供经行业验证的课程内容，并开放传统上仅面向富裕院校学生的职业网络资源。

**我们正在构建什么** -----------------------

CodePath 正将 Claude 整合进其人工智能相关课程中——包括《人工智能工程基础》《人工智能工程应用》及《人工智能开源项目综合实践》——帮助学生掌握使用 Claude Code 等工具进行开发的能力，并参与真实世界的开源项目贡献。

2025 年秋季，超过 100 名 CodePath 学生参与了 Claude Code 的试点项目，为 GitLab、Puter 和 Dokploy 等开源项目贡献力量。学生们反馈称，该体验既富有价值又颇具挑战性。“Claude Code 对我的学习过程起到了关键作用，尤其是当我进入项目时，对代码仓库中使用的编程语言（包括 TypeScript 和 Node.js）几乎一无所知，”Laney Hood 表示。

德克萨斯理工大学的计算机科学专业学生，CodePath 项目成员。

今年 1 月，霍华德大学宣布推出一门重新设计的《人工智能导论》课程，该课程由 CodePath 与瑟古德·马歇尔学院基金（Thurgood Marshall College Fund）合作开发。该课程为学生提供使用 Claude 辅助进行软件开发的实践经验，帮助他们为当前定义初级工程岗位的工作内容做好准备。这也是 CodePath 应用型人工智能课程首次在高校中提供学分认证。

CodePath 联合创始人兼首席执行官迈克尔·埃利森（Michael Ellison）表示：“如今我们已有技术可在两年内完成过去需四年才能完成的教学内容。但若只让部分人加速，而其他人仍原地踏步，只会加剧不平等。与 Anthropic 合作意味着我们的学生从第一天起就能在那些历史上被忽视的院校中学习如何使用 Claude 进行构建，从而为学生带来更优的学习成果，并从根本上改变‘谁有资格塑造人工智能经济’这一问题的答案。”

除课堂教学外，Anthropic 与 CodePath 还将合作开展公共研究，探索人工智能如何改变编程教育及经济机会的动态格局。我们将分享从学生、教育工作者及行业领袖处获得的见解，说明在人工智能重塑人们获取技术技能与进入职场方式的过程中，哪些做法行之有效，哪些则不然。

**对人工智能教育的更广泛承诺** ---------------------------------------- 此次合作建立在 Anthropic 推动将人工智能工具交到教育者手中的工作基础之上。
