摘要。
技能在智能体策略的演化过程中扮演着不同的角色：它们首先应提供可学习的知识，然后支持能力的形成，最后仅在能改善个体决策时被调用。现有方法很少对这一生命周期进行建模。它们要么将技能保持在模型外部，要么将其完全内化，或者通过带有噪声的任务级成功率在内化和利用目标之间进行选择。这种设计割裂了训练过程，并对同一轨迹内的动作赋予相同的重要性，尽管技能指导可能对某些决策有帮助，而对另一些决策产生干扰。为了解决这些问题，我们引入了 AUSO（动作级统一技能优化），它通过渐进的、动作感知的优化过程统一了技能学习和技能使用。在训练开始时，AUSO 联合学习教师指导和环境结果，使策略能够获得基础技能而不失去面向任务的反馈。随后，它强调基于结果的策略优化，以巩固自主解决问题的能力。随着策略的成熟，AUSO 在技能条件和无技能上下文下评估每个采样动作。由此产生的动作级信息信号与轨迹结果优势相耦合，使有益的技能敏感动作获得更强的更新，而有害的动作被抑制。因此，技能逐渐从外部监督源过渡为根据其动作级收益进行调整利用的决策知识，而强化学习始终是贯穿所有阶段的共享骨干。在 ALFWorld、WebShop 和 SearchQA 上的实验表明，AUSO 持续提升了智能体的性能和分布外泛化能力，优于有竞争力的基线。我们的代码可在 https://github.com/JordanSancholhz/Action-Skill 获取。

  1. 引言
    大语言模型（LLM）正越来越多地从静态文本生成器演变为在复杂、长时程环境中做出序列决策的交互式智能体。这些智能体不再仅仅产生单一回复，而是交织进行推理、行动和观察：它们调用外部工具、检索信息、浏览网页界面、操纵具身环境，并根据反馈修改计划 (Yao et al., 2023b; Schick et al., 2023; Zhou et al., 2023; Huang et al., 2025a)。这种以交互为中心的设置是现代信息访问和决策任务的核心，包括网络购物、具身家庭执行和基于搜索的问答 (Yao et al., 2022; Shridhar et al., 2021; Dunn et al., 2017; Lou et al., 2025)。然而，随着任务时程的增长，智能体不仅必须反复决定采取什么动作，还要决定哪种过程性知识、工具使用策略或环境启发式方法应该指导该动作。

智能体技能已成为解决这一问题的一种有前景的抽象。它们编码了可重用的过程性知识、任务策略、工具使用模式或特定环境的指导，从而为智能体进行长时程决策提供了可迁移的先验知识 (Wang et al., 2023; Huang et al., 2026)。在基于提示的智能体中，技能被检索、组合或作为显式指导注入，以支持复杂的交互式任务求解 (Xia et al., 2026)。近期的后训练方法进一步通过细粒度的环境反馈优化了多样的技能条件行为，将技能使用从静态提示转变为智能体策略的可学习组件 (Shi et al., 2026; Zhu et al., 2026)。

现有的基于技能的智能体学习方法大致可分为三种范式。第一种范式将技能完全外部化：智能体在模型外部维护一个持久的技能库，并在任务执行期间检索或更新技能，如 Voyager (Wang et al., 2023)、SkillRL (Xia et al., 2026) 和 Skill1 (Shi et al., 2026)。这种设计保留了可解释性、模块化和组合重用性，但也引入了上下文开销和检索噪声。第二种范式将技能完全内化到模型参数中，旨在消除推理时的技能提示并实现自主执行，如 SKILL0 (Lu et al., 2026)、LatentSkill (Yu et al., 2026) 及相关的技能到参数方法 (Zhang and Qi, 2026)。这提高了 token 效率并减少了对外部记忆的依赖，但可能会失去显式技能的可控性和特定任务的适应性。第三种范式联合外部化和内化技能。Skill0.5 (Zhu et al., 2026) 将可泛化的技能内化到模型中，同时保留显式的特定任务技能利用，表明这种混合策略可以更好地在跨任务迁移、推理效率和跨不同环境的任务级专业化之间取得平衡。

尽管取得了这些进展，现有的混合方法仍然存在一个关键的优化差距。Skill0.5 依赖任务级成功率将样本路由到难度层级，然后对困难、中等和简单任务应用不同的目标。这种路由使得内化和利用之间的边界对带有噪声的聚合结果很敏感：具有非常相似经验成功率的样本可能仅仅因为它们落在阈值的两侧而接受不同的训练处理。如图 1 所示，这个问题在实践中并不罕见：在 ALFWorld、WebShop 和 SearchQA 中，大量样本位于中/易边界附近，它们的通过率最多相差一个 rollout 单位，但被分配到不同的优化目标。这一观察表明，轨迹级路由引入的固有边界促使我们超越显式技能选择，追求一种更统一的学习范式，即技能首先被内化到策略中，然后在后续交互中被自然利用。更重要的是，轨迹级技能路由是广泛且稳定的，但对于技能指导改变特定决策质量的关键状态来说，可能过于粗糙。相比之下，动作级技能信号更精确，但更难获得，因为环境通常只提供轨迹级奖励。这种粗粒度的结果反馈无法直接揭示哪些个体动作受益于技能条件，哪些动作受到干扰，这呼应了强化学习中的信用分配挑战 (Schulman et al., 2017; Shao et al., 2024)。因此，现有方法在技能内化和利用方面，难以在智能体决策的实际粒度上优化技能使用。

为了解决这些局限性，我们提出了 AUSO（动作级统一技能优化），这是一个渐进式强化学习框架，通过动作感知优化统一了技能内化和技能利用。其核心是，AUSO 采用 Jensen–Shannon 散度（JSD）作为统一的信息增益信号，以量化技能指导如何改变策略的动作分布，从而在动作级别支持技能内化和利用。AUSO 首先允许策略从教师提供的技能指导和环境结果中学习，然后通过基于结果的策略优化巩固自主解决问题的能力，最后在技能条件和无技能上下文下评估每个采样动作。通过将这种动作级技能敏感信号与轨迹级优势相耦合，AUSO 加强了真正受益于技能的动作的更新，同时抑制了技能指导有害的动作。这样，技能逐渐从外部监督过渡为根据其动作级收益进行利用的决策知识，而强化学习始终是贯穿智能体策略演化的共享骨干。大量实验表明，AUSO 在 WebShop、ALFWorld 和 Search-QA 上始终优于 Skill0.5 等强大的基线，在 WebShop 和 ALFWorld 的 ID 和 OOD 设置下均显示出稳健的改进，并在 Search-QA 的单跳和多跳任务中表现出色，证明了 AUSO 在不同智能体任务和技能设置下的有效性和泛化能力。我们的贡献如下：

  • 我们提出了 AUSO，一种动作级统一技能优化方法，它在渐进式强化学习过程中统一了技能内化和利用，使技能随着策略模型能力的逐渐提高，从外部监督演变为根据其动作级收益进行利用的决策知识。
  • 我们引入了动作级技能敏感优化，它在共享的基于 JSD 的信息增益度量下，在动作级别统一了技能内化和利用。它量化了由技能指导引起的动作分布差异，以促进可泛化技能的内化，随后在交互过程中指导自适应的技能利用，克服了轨迹级技能路由粒度粗糙的问题。
  • 我们在 ALFWorld、WebShop 和 SearchQA 上经验性地验证了我们的 AUSO 框架，显示出在长时程智能体性能和分布外泛化方面相对于竞争基线的持续改进。
  1. 相关工作
    2.1. LLM 智能体
    大语言模型越来越多地被研究为交互式智能体，通过迭代推理、动作执行和来自外部环境的反馈来解决长时程任务。诸如思维链、ReAct 和思维树等提示方法表明，中间推理和深思熟虑的搜索可以显著改善复杂决策 (Wei et al., 2022; Yao et al., 2023b; Yao et al., 2023a)。工具增强的智能体通过启用 API 调用、搜索、计算和其他外部操作，进一步将 LLM 扩展到纯文本生成之外 (Schick et al., 2023; Li et al., 2023)。这些能力推动了广泛的智能体基准测试，涵盖网页导航、在线购物、具身家庭任务、软件工程和通用智能体评估 (Yao et al., 2022; Shridhar et al., 2021; Zhou et al., 2023; Deng et al., 2023; Liu et al., 2023; Chen et al., 2026b)。

另一条工作线通过记忆 (Cong et al., 2026; Ye et al., 2026)、反思、经验重用或交互中的强化学习来改进 LLM 智能体。Reflexion 使用先前失败的口头反馈来指导未来的决策，而无需更新模型参数 (Shinn et al., 2023)，而 Voyager 在开放式具身环境中构建可重用的程序和课程驱动的探索 (Wang et al., 2023)。最近关于智能体强化学习的工作进一步强调，为交互式环境后训练 LLM 不同于标准的静态偏好优化 (Huang et al., 2025b; Gao et al., 2026)，因为智能体必须收集轨迹、与环境状态交互并在延迟结果下优化行为 (Zhang et al., 2025; Chen et al., 2026b)。然而，大多数 LLM 智能体方法仍将外部指导、记忆和可重用知识视为辅助模块，而不是建模这种知识应如何逐渐过渡到策略本身。AUSO 通过在统一的强化学习周期过程中优化技能学习和技能使用来填补这一空白。

2.2. 智能体技能
智能体技能为解决复杂任务提供了可重用的过程性知识。在具身和机器人设置中，技能通常对应于可执行的基元、可供性感知的子程序或程序化任务计划，将高级语言指令转化为可行的动作 (Ahn et al., 2022; Singh et al., 2023)。在 LLM 智能体中，技能通常表示为自然语言策略、特定环境的启发式方法、工具使用模式或存储在外部库中的可执行程序 (Wang et al., 2023; Xia et al., 2026)。这种外部技能范式提高了可解释性和模块化重用，但也引入了检索噪声、上下文开销，以及难以决定应为特定决策加载哪些技能的问题 (Jiao et al., 2026b; Jiao et al., 2026a; Huang et al., 2025c)。

最近的研究使这一瓶颈变得明确。技能检索增强将大规模技能检索表述为一个独特的问题，并表明智能体通常难以确定何时真正应合并检索到的技能 (Su et al., 2026)。SkillComposer 研究了结构化技能组合，其中智能体不仅要选择使用哪些技能，还要选择使用多少以及按什么顺序 (Zhao et al., 2026)。技能使用基准测试进一步表明，在现实的检索和细化设置下，技能的收益可能会降低，特别是当技能有噪声、不匹配或未针对任务直接定制时 (Liu et al., 2026a)。这些工作表明，外部技能有用但脆弱：它们在处理复杂任务时的有效性取决于准确的检索、组合和选择性使用。

一个互补的方向试图将技能内化到模型参数中。SKILL0 训练智能体吸收技能知识并减少在推理时对显式技能提示的依赖 (Lu et al., 2026)，而 LatentSkill 和 Skill-to-LoRA 研究了技能内化的参数或潜在空间形式 (Yu et al., 2026; Zhang and Qi, 2026)。其他最近的工作研究了持续经验内化和测试时技能演化，表明经验注入的粒度和时机对于稳定的长时程智能体学习很重要 (Chen et al., 2026a; Mao et al., 2026)。在完全外部化和完全内化之间，Skill0.5 通过难度感知路由联合考虑了技能利用和内化 (Zhu et al., 2026)。AUSO 遵循这种混合动机，但不同之处在于它在单一的动作级优化框架内统一了技能内化和利用，用技能敏感学习取代了轨迹级路由，这种学习渐进地内化可泛化技能并根据其对每个动作的收益调整技能利用。

  1. 方法
    3.1. 问题表述
    我们考虑一个技能增强的交互式智能体，它通过与环境的多次交互来解决长时程任务。
    每个任务被表述为一个片段决策过程。
    在时间步 t，智能体观察到一个交互历史状态 h_{t}=(o_{1},a_{1},\ldots,o_{t}) 并生成一个动作 a_{t}\sim\pi_{\theta}(\cdot\mid h_{t})，其中 \pi_{\theta} 表示由 LLM 参数化的策略。
    然后环境返回下一个观察 o_{t+1}，片段在 T 步后或任务完成时终止。
    轨迹表示为 \tau=(o_{1},a_{1},\ldots,o_{T},a_{T})，并接收一个轨迹级结果奖励 R(\tau)，例如任务成功或任务得分。
    在基于技能的智能体学习中，策略可以额外地以技能 s 为条件，该技能提供可重用的过程性知识、任务解决指导或特定环境的策略。
    我们将技能条件策略计算为：
    (1)
    \pi_{\theta}^{+}(a_{t}\mid h_{t},s),
    以及不使用技能的策略计算为：
    (2)
    \pi_{\theta}^{-}(a_{t}\mid h_{t}).

现有方法通常根据在滑动窗口内估计的经验成功率来决定轨迹是用于技能内化还是技能利用。然而，这种轨迹级路由引入了模糊的决策边界，并为同一轨迹中的所有动作分配了统一的训练角色，尽管技能指导可能对某些动作有益但对其他动作有害。因此，我们的目标是训练一个智能体，其技能学习遵循渐进的生命周期：策略首先内化有用的技能，然后通过自主探索进行改进，最终学会评估技能指导对每个动作的收益，而不是依赖粗粒度的任务级路由。为了实现这一目标，我们将基于技能的智能体训练表述为一个统一的渐进式策略优化问题。

AUSO 没有通过硬性的轨迹级成功率阈值来选择技能内化或技能利用，而是将学习过程组织为一个连续的策略演化：智能体首先内化有用的技能知识，然后通过自主探索进行改进，最后学会评估技能指导对每个动作的收益并相应地调整其利用。为了支持这一点，AUSO 进一步通过 JSD 引入了动作级技能感知加权，因此不同的动作根据其结果贡献和对技能指导的依赖性接收不同的更新强度。

3.2. ID 和 OOD 设置
为了在不同的泛化场景下评估我们的方法，我们遵循 Skill0.5 的 ID/OOD 设置。具体来说，任务域空间被划分为 ID 域 \mathcal{D}{\mathrm{id}} 和 OOD 域 \mathcal{D}{\mathrm{ood}}，其对应的任务集表示为 \mathcal{X}^{\mathrm{id}} 和 \mathcal{X}^{\mathrm{ood}}。因此，我们将技能空间区分为捕获跨域共享的可迁移知识的通用技能 \mathcal{S}{G}，以及特定领域的技能 \mathcal{S}{S}。后者根据其关联的领域进一步划分为 ID 特定技能 \mathcal{S}{S}^{\mathrm{id}} 和 OOD 特定技能 \mathcal{S}{S}^{\mathrm{ood}}。在训练期间，智能体仅与 ID 任务 x\sim\mathcal{X}{\mathrm{train}}^{\mathrm{id}} 交互，连同可访问的通用技能 \mathcal{S}{G} 和 ID 特定技能 \mathcal{S}{S}^{\mathrm{id}} 一起，而 OOD 任务 \mathcal{X}^{\mathrm{ood}} 及其对应的技能 \mathcal{S}{S}^{\mathrm{ood}} 保持未见。在评估期间，我们在 ID 和以前未见的 OOD 任务上评估智能体，以评估其域内性能和跨域技能泛化。我们在 ALFWorld 和 WebShop 中都采用了这种设置。由于 Search-QA 不支持相同的 ID/OOD 划分，我们遵循 Skill0 的原始设置进行评估。

3.3. 动作级统一技能优化概述
图 2.
我们的 AUSO（从内化到利用的动作级统一技能优化）概述：(1) 通用技能内化：通过动作级师生指导内化可迁移的通用技能。(2) 技能探索：通过 GRPO 探索和优化多样技能。(3) 特定技能利用：评估特定任务技能对每个动作的收益，以指导动作级技能利用。

为了训练一个技能学习遵循渐进生命周期并实现动作级技能感知优化的智能体，我们提出了动作级统一技能优化（AUSO）框架。AUSO 没有将技能内化和技能利用视为由硬性轨迹级路由选择的两个不相交目标，而是将基于 GRPO 的强化学习保留为共享的优化骨干，并改变了技能信息注入到更新中的方式。

在早期阶段，技能提供由动作级信息增益加权的教师指导监督 (Wang et al., 2026)，因此学生偏离技能条件教师行为较大的状态会接收更强的纠正性更新。在后期阶段，随着策略通过自我探索变得更强大，AUSO 从外部指导的技能内化过渡到自我指导的技能利用，其中技能条件的动作级影响通过 JSD 测量，并用于自适应地重新加权策略梯度。

3.3.1. 早期阶段的教师指导技能内化
在早期阶段，主要挑战是仅基于结果的强化学习可能无法为困难任务提供学习信号。
当所有采样轨迹都失败时，根据 GRPO 优势计算算法的优势，组归一化优势几乎变为零：
(3)
A_{q,i}^{\mathrm{GRPO}}=\frac{R_{q,i}-\bar{R}{q}}{\sigma{q}+\epsilon}\approx 0,\quad\text{if }R_{q,1}=\cdots=R_{q,G}=0
其中 R_{q,i} 表示第 q 条轨迹和轨迹中的第 i 步。在这种情况下，策略无法仅从结果奖励中推断出应该纠正哪些动作。
因此，AUSO 引入了教师指导的动作分布监督项，但仅针对这种无信号的任务组。
对于每个时间步 t，智能体观察历史状态：
(4)
h_{t}=(o_{0},a_{0},\ldots,o_{t})
给定当前观察状态 h_{t}，我们的目标是将技能知识内化到模型中，而不是在推理期间依赖显式的技能检索。为此，我们在不需要额外环境 rollout 的情况下，从同一模型构建一个师生范式。具体来说，教师以可用的通用技能 \mathcal{S}{G} 为条件，而学生仅在原始观察上操作，不访问任何技能。因此，我们计算两个动作分布：
(5)
\pi{S}(\cdot\mid h_{t}),\qquad\pi_{T}(\cdot\mid h_{t},\mathcal{S}{G})
其中 \pi{T} 代表带有 S_{G} 的教师分布，为转移 \mathcal{S}{G} 中编码的可泛化知识提供指导，而 \pi{S} 表示无技能的学生分布。教师分布在优化期间被分离，因此监督专门更新学生模型，逐步将通用技能内化到其策略参数中。

我们通过 Jensen-Shannon 散度测量教师和学生之间的信息增益差异：
(6)
D_{t,k}^{T\rightarrow S}=\mathrm{JSD}\left(\pi_{T}(\cdot\mid h_{t},C_{\mathrm{teacher}})\,|\,\pi_{S}(\cdot\mid h_{t})\right)
在 top-k 教师 token 上计算。
由于一个环境动作可能包含多个生成的 token，我们在动作跨度 \mathcal{A}{t} 内聚合 token 级散度：
(7)
D{t}^{T\rightarrow S}=\frac{1}{|\mathcal{A}{t}|}\sum{k\in\mathcal{A}{t}}D{t,k}^{T\rightarrow S}
这防止了较长的文本动作或推理 token 获得过大的监督权重。

为了使教师监督具有动作感知能力，同时保持损失尺度稳定，AUSO 首先在同一任务组的有效动作中归一化师生差异：
(8)
z_{t}=\frac{D_{t}^{T\rightarrow S}-\mu_{q}}{\sqrt{\sigma_{q}^{2}+\epsilon}}
其中 D_{t}^{T\rightarrow S} 表示动作 t 处的动作级师生散度，\mu_{q} 和 \sigma_{q}^{2} 是任务组 q 中有效动作上这些散度的均值和方差。然后，我们将归一化的差异 z_{t} 转换为中心化和有界的调制：
(9)
\hat{u}{t}=\frac{\tanh(z{t})-\mathbb{E}{t\in q}[\tanh(z{t})]}{\max_{t\in q}\left|\tanh(z_{t})-\mathbb{E}{t\in q}[\tanh(z{t})]\right|+\epsilon}
这里，\tanh(\cdot) 限制了调制，期望项在任务组内重新中心化权重，分母归一化了最大幅度，使得 \hat{u}_{t}\in[-1,1]。

最后，动作级教师监督权重定义为
(10)
u_{t}=1+\beta_{\mathrm{int}}\hat{u}{t},\qquad u{t}\in[1-\beta_{\mathrm{int}},1+\beta_{\mathrm{int}}]
遵循裁剪策略优化的稳定原则 (Shao et al., 2024)，我们用动作级内化裁剪限制 \beta_{\mathrm{int}}，使得教师指导的 JSD 仅轻微地重新加权动作，而不是改变整体优化尺度。
这防止了高差异动作主导梯度，同时仍为它们分配更强的纠正监督。早期阶段的蒸馏损失为：
(11)
\mathcal{L}{\mathrm{JSD}}=\frac{1}{N}\sum{t}u_{t}D_{t}^{T\rightarrow S}
我们用时间相关系数控制教师指导内化的强度：
(12)
\lambda_{\mathrm{JSD}}(s)=\lambda_{0}\alpha(s)
其中 \lambda_{0} 是基础 JSD 系数，\alpha(s) 决定了在训练步 s 时教师监督的贡献强度。
遵循课程和计划监督的一般原则，辅助指导应逐步引入，并随着学习者能力的提高而退火 (Bengio et al., 2009; Bengio et al., 2015)。
在 AUSO 中，这是通过一个短暂的上升期和随后的平滑衰减来实现的：教师指导信号在前 r 个训练步中逐渐激活，然后随着策略转向自主探索而退火。
因此，我们将 \alpha(s) 定义为一个上升项乘以一个平滑衰减项：
(13)
\alpha(s)=\mathrm{Ramp}(s)\cdot\left[1-\mathrm{SmoothStep}\left(\frac{s/T}{\rho_{\mathrm{int}}}\right)\right]
其中 s 是当前训练步，T 是总训练步数，\rho_{\mathrm{int}} 表示分配给内化阶段的训练比例。上升函数定义为：
(14)
\mathrm{Ramp}(s)=\min\left(1,\frac{s}{r}\right)
其中 r 是上升步数。

平滑衰减使用标准的 SmoothStep 函数，这是一种常用于平滑过渡的三次埃尔米特插值 (Perlin, 1985; Khronos Group, 2026)：
(15)
\mathrm{SmoothStep}(x)=\tilde{x}^{2}(3-2\tilde{x})\qquad\tilde{x}=\mathrm{clip}(x,0,1)
有了这个时间表，教师监督在训练开始时逐渐激活，然后平滑退火，因此策略首先接收纠正性技能指导，但随后被鼓励依赖环境驱动的优化。
早期阶段的目标最终写为：
(16)
\mathcal{L}{\mathrm{early}}=\mathcal{L}{\mathrm{GRPO}}+\mathbb{I}[p_{q}=0]\,\lambda_{\mathrm{JSD}}(s)\mathcal{L}{\mathrm{JSD}}
其中 p{q} 表示学生智能体在任务 q 中的成功率。

3.3.2. 结果驱动的自主探索
在早期技能内化之后，AUSO 移除教师指导的监督，让智能体通过标准 GRPO 进行改进。
在这个阶段，策略为每个任务采样多条轨迹，并使用组归一化的结果优势来更新自身：
(17)
\mathcal{L}{\mathrm{mid}}=\mathcal{L}{\mathrm{GRPO}}
这鼓励智能体通过环境驱动的探索巩固自主解决问题的能力。

3.3.3. 后期阶段的动作级技能利用
在后期阶段，AUSO 停止使用外部教师作为蒸馏目标。
问题不再是如何模仿教师行为，而是学生自身的决策何时受到技能信息的有意义影响。
对于学生访问的每个状态 H_{t}，我们在两种上下文下从同一策略计算两个分布：
(18)
\pi_{\theta}(\cdot\mid h_{t},C=\mathrm{Skill}),\qquad\pi_{\theta}(\cdot\mid h_{t},C=\mathrm{No\text{-}skill})
因为这两个分布都在同一访问状态下评估，所以这种比较不需要额外的环境 rollout，并避免了比较两个单独生成的轨迹时可能出现的不匹配。动作级技能信息为：
(19)
I_{t}=\mathrm{JSD}\left(\pi_{\theta}(\cdot\mid h_{t},C=\mathrm{Skill})\,|\,\pi_{\theta}(\cdot\mid h_{t},C=\mathrm{No\text{-}skill})\right)
这里，I_{t} 不用作蒸馏损失。
它是一个信息度量：值越大意味着技能条件在状态 H_{t} 下更强地改变了学生的下一动作分布。
由于 I_{t} 的原始尺度在不同任务间存在差异，AUSO 在每个任务组内对其进行标准化：
(20)
z^{1}{t}=\frac{I{t}-\mu^{t}{q}}{\sqrt{\sigma{q,I}^{2}+\epsilon}},\qquad m_{t}=\tanh(\mathrm{clip}(z^{1}{t},-3,3))
归一化得分 m{t}\in[-1,1] 表示一个动作比任务级平均水平更敏感还是更不敏感。
AUSO 进一步通过基于归一化伯努利方差的全局不确定性门来调制动作级信号：
(21)
g(p_{q})=K\cdot p_{q}(1-p_{q})
其中 K 是一个正的缩放常数。这种形式遵循常见的不确定性原则，即当二元结果的经验概率接近 0.5 时信息量最大，而当结果几乎确定时信息量最小 (Settles, 2009)。
因此，当所有 rollout 都失败或所有 rollout 都成功时，门值很小，因为组结果为动作级信用分配提供的对比很小。我们在附录 A.1 中提供了这个门的详细数学证明。当成功和失败的 rollout 共存时，它达到最大值，此时结果差异对于识别哪些技能敏感动作最重要最具信息量。最终的动作权重计算为：
(22)
w_{t}=1+\beta(s)g(p_{q})m_{t}

与早期阶段的课程策略相同，我们也引入了 \beta(s)，它在训练期间平滑增加：
(23)
\beta(s)=\operatorname{SmoothStep}\left(\frac{s-s_{\mathrm{start}}}{T-s_{\mathrm{start}}}\right)
其中 s 表示当前训练步，s_{\mathrm{start}} 是利用优化阶段激活的步骤，T 是总训练步数。加权优势变为：
(24)
A_{q,t}^{\mathrm{AUSO}}=A_{q}^{\mathrm{GRPO}}w_{t}.
这种重新加权保留了原始 RL 优势的符号：
(25)
A_{q}^{\mathrm{GRPO}}>0\Rightarrow A_{q,t}^{\mathrm{AUSO}}>0,\qquad A_{q}^{\mathrm{GRPO}}<0\Rightarrow A_{q,t}^{\mathrm{AUSO}}<0
因此，AUSO 不会产生人为的奖励或反转轨迹级结果信号。
相反，它根据信息增益在动作之间重新分配更新强度：在成功的轨迹中，高度技能敏感的动作获得更强的正强化；在失败的轨迹中，高度技能敏感的动作获得更强的抑制；而低信息量的动作获得较小的更新。
后期阶段的目标仍然是标准的同策略 RL，但具有动作级技能感知优势：
(26)
\mathcal{L}{\mathrm{late}}=-\sum{t}A_{q,t}^{\mathrm{AUSO}}\log\pi_{\theta}(a_{t}\mid h_{t},C=\mathrm{Skill})

3.3.4. 统一的技能生命周期目标
完整的 AUSO 目标表述为：
(27)
\displaystyle\mathcal{L}{\mathrm{AUSO}}(\theta;s)={}
\displaystyle\mathcal{L}{\mathrm{GRPO}}\left(\theta;A_{q,i}^{\mathrm{GRPO}}\left[1+\beta(s)\,4p_{q}(1-p_{q})\,m_{q,i,t}\right]\right)
\displaystyle+\lambda_{0}\alpha(s)\sum_{q}\mathbb{I}[p_{q}=0]\,\mathcal{L}_{\mathrm{JSD}}^{(q)}.
这里，\alpha(s) 逐渐移除教师指导的监督，而 \beta(s) 逐渐激活动作级技能利用。AUSO 保留结果驱动的 GRPO 作为持久的优化骨干，并从外部技能内化逐步推进到由技能对每个动作的收益指导的动作级技能利用。

    4.1. 实验设置
    4.1.1. 数据集
    我们在三个长时程智能体基准上评估 AUSO：ALFWorld (Shridhar et al., 2021)、WebShop (Yao et al., 2022) 和 SearchQA (Dunn et al., 2017)。
    这些基准涵盖了具身决策、基于网络的交互和面向搜索的问答，使我们能够检查 AUSO 是否能在不同形式的智能体与不同环境交互中改善任务 ID 性能和 OOD（分布外）泛化。
    ALFWorld 是一个具身家庭任务基准，将基于文本的环境与具身操纵场景对齐。
    智能体必须遵循自然语言目标，并通过导航、对象交互和状态操纵等文本动作完成多步家庭任务。
    我们使用 ALFWorld 来评估技能指导是否能改善具身环境中的长时程规划和动作执行。
    WebShop 是一个基于网络的购物基准，智能体在其中与模拟电子商务网站交互，以查找并购买满足用户指令的产品。
    智能体必须通过多步网络动作进行搜索、比较产品、检查属性并做出购买决策。
    遵循我们的分布外设置，我们根据 Skill0.5 构建了基于类别的 ID 和 OOD 划分：ID 任务来自服装、电子产品、鞋类和其他产品等频繁类别，而 OOD 验证任务来自配饰、美容健康和家居装饰等保留类别。

4.1.2. 基线
我们将 AUSO 与多种智能体学习方法进行了比较。
(1) 基于提示的方法：零样本和少样本提示，它们直接在任务指令上条件化骨干模型，无需额外的智能体训练 (Brown et al., 2020)。
(2) 基于提示的智能体和基于记忆的方法：ReAct (Yao et al., 2023b)、Reflexion (Shinn et al., 2023)、ExpeL (Zhao et al., 2024)、Mem0 (Chhikara et al., 2025) 和 SimpleMem (Liu et al., 2026b)，它们通过上下文推理、口头反馈、经验记忆或外部记忆检索来改善多步决策，而无需更新策略参数。
(3) 基于 RL 的方法：RLOO (Ahmadian et al., 2024) 和 GRPO (Shao et al., 2024)，它们使用结果奖励和组相对或留一优势估计来优化 LLM 策略。
(4) 记忆增强的 RL 方法：MemRL (Zhang et al., 2026) 和 Memory-R1 (Yan et al., 2026)，它们将强化学习与持久或可学习的记忆机制相结合。
(5) 技能增强的 RL 方法：SkillRL (Xia et al., 2026)、Skill1 (Shi et al., 2026)、SKILL0 (Lu et al., 2026)、LatentSkill (Yu et al., 2026) 和 Skill0.5 (Zhu et al., 2026)，代表了使用外部技能、内化技能或混合技能利用和内化来训练智能体的近期尝试。

4.1.3. 实现细节
所有实验都在配备 4 块 NVIDIA H200 GPU 的服务器上进行。遵循 Skill0.5 (Zhu et al., 2026)，我们在所有实验中采用 Qwen2.5-7B-Instruct (Yang et al., 2024) 作为骨干策略模型。为了公平比较，所有方法在每个基准内使用相同的骨干模型、rollout 配置、最大交互长度和优化预算。具体来说，对于每个任务 q，策略执行 G=8 次 rollout 以构建用于基于组的策略优化的 rollout 组。在包括 ALFWorld、WebShop 和 SearchQA 在内的所有基准中，我们为每种方法训练 150 个优化步。对于 ALFWorld 和 WebShop，我们遵循基于类别的 ID/OOD 评估协议，并报告分布内 (ID) 验证性能和分布外 (OOD) 泛化性能。对于未采用 ID/OOD 划分的 SearchQA，我们遵循 Skill0 报告任务成功率以进行评估。更多的训练和评估细节在补充材料中提供。

4.3. 消融研究
我们在 ALFWorld 和 WebShop 上进行了全面的消融研究，以调查 AUSO 中每个组件的贡献。如表 3 所示，移除任何组件都会持续降低整体性能，表明动作级技能优化的不同阶段是互补的。特别是，移除 Int.-Action（动作级内化）导致 ALFWorld 上的性能大幅下降，在 ID/OOD 设置下从 94.3/67.9 降至 85.1/54.7，突出了技能内化的重要性。同样，移除 Ut.-Action（动作级利用）或利用/内化中的自适应增加/减少策略会导致一致的退化，表明动态控制技能利用对于将学习的技能转移到不同的交互状态至关重要。移除门控机制也会导致两个基准上的性能明显下降，进一步验证了其在协调动作级技能优化中的作用。

我们在表 4 中进一步调查了不同优化阶段之间的时间分配。采用的 2:5:3 比例实现了最佳的 ID 和 OOD 性能，表明技能内化、探索和利用之间的适当平衡对于有效的策略优化很重要。最后，图 4 研究了超参数 K 的影响。性能在 K=4 时达到峰值，实现了 94.3 的 ID 和 67.9 的 OOD 成功率，而更小或更大的值都会导致退化，特别是在 OOD 评估下。这表明适中的 K 为技能优化和泛化提供了有效的平衡。

  1. 结论
    在本文中，我们提出了 AUSO，一个基于信息增益的、通过 JSD 的动作级统一技能优化框架，它为 LLM 智能体统一了技能内化和技能利用。AUSO 逐步从外部技能指导中学习，通过强化学习巩固自主决策，最后使用动作级技能敏感信号来强调受益于技能的决策，同时抑制技能指导无益的决策。在 ALFWorld、WebShop 和 SearchQA 上的实验表明，AUSO 始终优于有竞争力的基线，并实现了更强的分布外泛化。进一步的消融研究验证了渐进式调度、动作级优化和基于不确定性的门控的贡献。这些结果表明，在动作级别对技能进行建模为长时程 LLM 智能体将外部指导转化为可迁移的策略知识提供了一种有效的方法。

A.1. 全局不确定性门的分析
不确定性门的统计证明。
我们为 AUSO 技能利用阶段中使用的全局不确定性门 g(p_{q})=K\cdot p_{q}(1-p_{q}) 提供了统计解释。
关键直觉是，当成功和失败的轨迹在 rollout 组中都有充分代表时，动作级信用分配更可靠。对于任务 q，假设 rollout 组包含 G 条轨迹，经验成功率为 p_{q}。因此，成功轨迹 G_{+} 和失败轨迹 G_{-} 的预期数量可表示为：
(28)
G_{+}=Gp_{q},\qquad G_{-}=G(1-p_{q})
设 I 表示动作级技能信息增益得分。为了确定技能敏感动作是否与成功结果相关，考虑成功和失败轨迹的预期信息得分之间的差异：
(29)
\Delta_{I}=\mathbb{E}[I\mid R=1]-\mathbb{E}[I\mid R=0].
其经验估计量计算为：
(30)
\widehat{\Delta}{I}=\overline{I}{+}-\overline{I}{-},
其中 \overline{I}{+} 和 \overline{I}_{-} 分别表示从成功和失败轨迹计算的平均动作级信息得分。

受两个样本均值差异的标准方差分析启发 (Welch, 1947)，我们分析了这种成功-失败信息对比的统计可靠性。为此，我们考虑在成功和失败结果下动作级信息得分的条件方差：
(31)
\sigma_{I,+}^{2}=\operatorname{Var}(I\mid R=1),\qquad\sigma_{I,-}^{2}=\operatorname{Var}(I\mid R=0)
估计信息对比的方差可以表征为：
(32)
\operatorname{Var}(\widehat{\Delta}{I})
\displaystyle=\frac{\sigma{I,+}^{2}}{n_{+}}+\frac{\sigma_{I,-}^{2}}{n_{-}}
\displaystyle=\frac{\sigma_{I,+}^{2}}{Gp_{q}}+\frac{\sigma_{I,-}^{2}}{G(1-p_{q})}
为了将 rollout 结果组成的影响与信息得分方差的依赖任务变化分离开来，我们考虑同方差近似：
(33)
\sigma_{I,+}^{2}\approx\sigma_{I,-}^{2}\approx\sigma_{I}^{2}
在此近似下，等式 (32) 变为：
(34)
\operatorname{Var}(\widehat{\Delta}{I})
\displaystyle\approx\frac{\sigma{I}^{2}}{Gp_{q}(1-p_{q})}
对于固定的 rollout 预算 G 和信息得分方差 \sigma_{I}^{2}，估计的成功-失败对比的精度（定义为其方差的倒数）因此满足：
(35)
\operatorname{Precision}(\widehat{\Delta}{I})
\displaystyle=\frac{1}{\operatorname{Var}(\widehat{\Delta}{I})}\propto p_{q}(1-p_{q})
这一结果表明，成功-失败对比的可靠性直接取决于 rollout 结果的组成。当 p_{q} 接近 0 或 1 时，一个结果组缺失或严重代表不足，使得对比越来越不可靠。

有界性和方向保持性。
回想一下，动作级调制权重为：
(36)
w_{t}=1+\beta(s)g(p_{q})m_{t}
其中 |m_{t}|\leq 1 且 0\leq\beta(s)<1。由于 0\leq g(p_{q})\leq 1，我们有：
(37)
1-\beta(s)\leq w_{t}\leq 1+\beta(s)
因此，w_{t}>0，并且由此产生的动作级优势
(38)
A_{q,t}^{\mathrm{AUSO}}=w_{t}A_{q}^{\mathrm{GRPO}}
保留了原始 GRPO 优势的符号：
(39)
\operatorname{sign}\left(A_{q,t}^{\mathrm{AUSO}}\right)=\operatorname{sign}\left(A_{q}^{\mathrm{GRPO}}\right)
此外，
(40)
A_{q}^{\mathrm{GRPO}}=0\quad\Longrightarrow\quad A_{q,t}^{\mathrm{AUSO}}=0
因此动作级信息信号不能引入原始结果奖励不支持的人为优化方向。
最后，因为动作级调制在每个任务内是中心化的，\mathbb{E}{t\in q}[m{t}]=0，我们得到：
(41)
\displaystyle\mathbb{E}{t\in q}[w{t}]
\displaystyle=1+\beta(s)g(p_{q})\mathbb{E}{t\in q}[m{t}]=1
因此，全局不确定性门不会改变任务内的平均优化尺度。相反，它根据可用的成功-失败对比控制动作级调制的可靠性，而 m_{t} 在同一轨迹中的智能体的各个动作之间重新分配由此产生的信用。

A.2. 内化和利用的统一视角
统一过程的分析。
尽管技能内化和技能利用在训练期间扮演不同的角色，AUSO 通过相同的动作级反事实信息算子实现了两者。两个阶段之间的区别不在于如何测量动作级信息，而在于如何将由此产生的信息信号用于优化。对于在交互历史 h_{q,t} 处采取的动作 a_{q,t}，设 C_{q,t}^{+} 和 C_{q,t}^{-} 表示两个反事实上下文条件。
我们将任务 q 的统一动作级信息算子定义为：
(42)
\mathcal{I}{q,t}\left(C{q,t}^{+},C_{q,t}^{-}\right)=\operatorname{JSD}\left(\pi_{\theta}\left(\cdot\mid h_{q,t},C_{q,t}^{+}\right)\,\middle|\,\pi_{\theta}\left(\cdot\mid h_{q,t},C_{q,t}^{-}\right)\right)
由于一个环境动作可能包含多个生成的 token，实现的动作级得分在动作跨度上平均 token 级散度：
(43)
\displaystyle\mathcal{I}{q,t}
\displaystyle=\frac{1}{|a{q,t}|}\sum_{j=1}^{|a_{q,t}|}\operatorname{JSD}\Bigg(\pi_{\theta}!\left(\cdot\mid h_{q,t},a_{q,t,<j},C_{q,t}^{+}\right)
\displaystyle\Big|\pi_{\theta}!\left(\cdot\mid h_{q,t},a_{q,t,<j},C_{q,t}^{-}\right)\Bigg)
两个学习阶段用不同的反事实上下文实例化此算子：
(44)
\left(C_{q,t}^{+},C_{q,t}^{-}\right)=\begin{cases}\left(C_{q}^{\mathrm{general}}\cup C_{q}^{\mathrm{specific}},C_{q}^{\mathrm{specific}}\right),&x\in\mathcal{H},\[4.0pt]
\left(C_{q}^{\mathrm{specific}},\varnothing\right),&q\in\mathcal{E}.\end{cases}
这里，\mathcal{H} 和 \mathcal{E} 分别表示对应于技能内化和技能利用的任务机制。
对于 \mathcal{H} 中的任务，信息得分衡量特权技能条件教师和学生之间的差异。因此它被用作直接监督信号：
(45)
\mathcal{L}{\mathrm{int}}(q)=\frac{1}{T{q}}\sum_{t=1}^{T_{q}}w_{q,t}^{\mathrm{int}}\mathcal{I}{q,t}\left(C{q}^{\mathrm{general}}\cup C_{q}^{\mathrm{specific}},C_{q}^{\mathrm{specific}}\right)
对于 \mathcal{E} 中的任务，同一算子转而衡量当前策略对特定任务技能条件的依赖程度：
(46)
\mathcal{I}{q,t}^{\mathrm{util}}=\mathcal{I}{q,t}\left(C_{q}^{\mathrm{specific}},\varnothing\right)
此信息不直接优化。相反，它被转换为动作级调制：
(47)
w_{q,t}^{\mathrm{util}}=1+\beta(s)g(p_{q})m_{x,t},
重新加权原始 GRPO 优势：
(48)
\mathcal{L}{\mathrm{util}}(q)=\mathcal{L}{\mathrm{GRPO}}\left(q;w_{q,t}^{\mathrm{util}}A_{q}\right)
因此，统一过程可以总结为：
(49)
\mathcal{I}_{q,t}\longrightarrow\begin{cases}\text{direct skill supervision},&q\in\mathcal{H},\
\text{GRPO credit modulation},&q\in\mathcal{E}.\end{cases}
而中间机制中的任务由标准 GRPO 优化，没有额外的基于技能的纠正。

统一路由目标。
设 \rho_{\mathrm{int}}、\rho_{\mathrm{exp}} 和 \rho_{\mathrm{util}} 分别表示分配给技能内化、自主探索和技能利用的课程比例：
(50)
\rho_{\mathrm{int}}+\rho_{\mathrm{exp}}+\rho_{\mathrm{util}}=1.
AUSO 不是将单个任务路由到不同的目标，而是沿着此训练课程逐步改变技能信息的贡献。完整目标写为
(51)
\displaystyle\mathcal{L}{\mathrm{AUSO}}(\theta;s)={}
\displaystyle\mathcal{L}{\mathrm{GRPO}}\left(\theta;A_{q,t}^{\mathrm{GRPO}}\left[1+\beta(s)g(p_{q})m_{q,t}\right]\right)
\displaystyle+\lambda_{0}\alpha(s)\sum_{q}\mathbb{I}[p_{q}=0]\mathcal{L}_{\mathrm{JSD}}^{(q)},
其中 \alpha(s) 逐渐减少教师指导的技能内化的贡献，而 \beta(s) 逐渐激活动作级技能利用。课程比例决定了这些转换发生的时间，而不是将单个任务路由到离散的优化机制中。
因此，GRPO 在整个训练过程中仍然是持久的优化骨干，而技能信息的角色从外部技能内化，通过自主探索，到动作级信息增益指导的技能利用逐步演化。

平滑退化为公共骨干。
当动作级证据无信息量时，利用分支连续退化为标准 GRPO。具体来说，
(52)
w_{q,t}^{\mathrm{util}}=1
只要满足以下任一条件：
(53)
p_{q}\in{0,1},\qquad m_{q,t}=0,\qquad\beta(s)=0.
因此，我们可以在这些条件中的每一个下得到结果：
(54)
\mathcal{L}{\mathrm{util}}(q)=\mathcal{L}{\mathrm{GRPO}}(q)
此外，因为：
(55)
\lim_{\beta_{(s)}\rightarrow 0}w_{q,t}^{\mathrm{util}}=1,
那么我们可以得到以下结果：
(56)
\lim_{\beta_{(s)}\rightarrow 0}\mathcal{L}{\mathrm{util}}(q)=\mathcal{L}{\mathrm{GRPO}}(q).
因此，利用不是一个独立或竞争的优化目标；它是同一 GRPO 目标的连续、有界的细化。类似地，当内化系数消失时：
(57)
\lambda_{\mathrm{int}}(s)=0
硬辅助纠正消失。当两个辅助机制都不活动时，我们可以得到：
(58)
\mathcal{L}{\mathrm{unified}}\longrightarrow\mathcal{L}{\mathrm{GRPO}}

统一结果。
以上建立了三种形式的统一：
(1) 信号统一：内化和利用均来自相同的反事实动作级 JSD 算子；
(2) 优化统一：所有路由分支在一个互斥的路由目标下更新单一策略；
(3) 骨干统一：当辅助信息缺失或不可靠时，提出的目标连续退化为标准 GRPO。
因此，该框架没有启发式地组合不相关的辅助损失。相反，它在两个互补的方向上实例化了单一的反事实信息原则：通过内化减少对通用技能的依赖，并通过利用保持对特定任务技能的敏感性。

A.3. 为什么用 Jensen–Shannon 散度作为动作级信息增益？
基于 JSD 的动作级信息增益
在每个环境状态 h_{t}，AUSO 评估同一策略的两次反事实执行：一次以检索到的技能为条件，一次不使用技能条件。设 C\in{0,1} 表示技能上下文，其中 C=1 表示技能条件执行，C=0 表示无技能执行。因为语言模型动作是自回归生成的，我们将第 \ell 个响应 token 位置处的动作分布定义为：
(59)
P_{t,\ell}(a)=\pi_{\theta}(a\mid h_{t,\ell},C=1),\qquad Q_{t,\ell}(a)=\pi_{\theta}(a\mid h_{t,\ell},C=0).
这里，h_{t,\ell} 表示环境动作 u_{t} 内的 token 级历史。在本文中，我们为这两个上下文分配统一的先验：
(60)
p(C=0)=p(C=1)=\frac{1}{2}
相应的边际 token 分布为
(61)
M_{t,\ell}(a)=p(a\mid h_{t,\ell})=\frac{1}{2}P_{t,\ell}(a)+\frac{1}{2}Q_{t,\ell}(a).
技能上下文和 token 级动作之间的条件互信息为：
(62)
\displaystyle I(C;A_{t,\ell}\mid h_{t,\ell})
\displaystyle=\sum_{c\in{0,1}}p(c)D_{\mathrm{KL}}\left(p(A_{t,\ell}\mid h_{t,\ell},C=c)\,\middle|\,p(A_{t,\ell}\mid h_{t,\ell})\right)
\displaystyle=\frac{1}{2}D_{\mathrm{KL}}\left(P_{t,\ell}\,\middle|\,M_{t,\ell}\right)+\frac{1}{2}D_{\mathrm{KL}}\left(Q_{t,\ell}\,\middle|\,M_{t,\ell}\right)
\displaystyle=D_{\mathrm{JS}}\left(P_{t,\ell}\,\middle|\,Q_{t,\ell}\right)
因此，我们可以得到：
(63)
\boxed{D_{\mathrm{JS}}\left(P_{t,\ell}\,\middle|\,Q_{t,\ell}\right)=I(C;A_{t,\ell}\mid h_{t,\ell})}
这个恒等式表明，token 级 JSD 衡量了在局部动作分布中表达了多少关于技能上下文的信息。特别是，当：
(64)
D_{\mathrm{JS}}\left(P_{t,\ell}\,\middle|\,Q_{t,\ell}\right)=0\iff P_{t,\ell}=Q_{t,\ell}
这意味着技能条件不会改变该位置的 token 级决策。

对称性。
两个分布 P_{t,\ell} 和 Q_{t,\ell} 对应于同一策略的两个反事实决策。它们不构成具有预定义参考方向的师生对。单侧 KL 散度是方向相关的：
(65)
D_{\mathrm{KL}}(P_{t,\ell}|Q_{t,\ell})\neq D_{\mathrm{KL}}(Q_{t,\ell}|P_{t,\ell})
通常。因此，选择这两个方向之一会引入任意的非对称性。相比之下，JSD 满足
(66)
D_{\mathrm{JS}}(P_{t,\ell}|Q_{t,\ell})=D_{\mathrm{JS}}(Q_{t,\ell}|P_{t,\ell}),
更适合比较两个反事实策略决策。

有界性。
因为 JSD 等于二元上下文变量和 token 动作之间的互信息，它受上下文熵的限制：
(67)
0\leq D_{\mathrm{JS}}(P_{t,\ell}|Q_{t,\ell})=I(C;A_{t,\ell}\mid h_{t,\ell})\leq H(C)=\log 2.
因此，动作级平均值也是有界的：
(68)
0\leq\mathrm{IG}(u_{t})\leq\log 2.
这种有界尺度对于稳定的动作级调制很有用。相比之下，KL 散度满足
(69)
D_{\mathrm{KL}}(P_{t,\ell}|Q_{t,\ell})\in[0,\infty]
并且当 Q_{t,\ell} 为 P_{t,\ell} 偏好的动作分配非常小的概率时，可能变得任意大。

实现中使用的 Top-k 近似。
在整个词汇表上计算精确的 JSD 很昂贵。因此，对于每个 token 位置，AUSO 构建一个粗粒度支持
(70)
\mathcal{S}{t,\ell}=\operatorname{TopK}(P{t,\ell})\cup\operatorname{TopK}(Q_{t,\ell})\cup{\mathrm{tail}}.
前两项包含由技能条件和无技能策略选择的 top-k token 的并集。所有剩余的词汇概率质量被分组到一个聚合的尾部类别中。设 \widetilde{P}{t,\ell} 和 \widetilde{Q}{t,\ell} 表示在 \mathcal{S}{t,\ell} 上得到的归一化分布。然后，实现的 token 级得分为
(71)
\widehat{\mathrm{IG}}{t,\ell}=D_{\mathrm{JS}}\left(\widetilde{P}{t,\ell}\,\middle|\,\widetilde{Q}{t,\ell}\right),
实现的动作级得分为
(72)
\widehat{\mathrm{IG}}(u_{t})=\frac{1}{L_{t}}\sum_{\ell}m_{t,\ell}\widehat{\mathrm{IG}}_{t,\ell}.
Top-k 并集和聚合尾部保留了两个分布的归一化，同时避免了构建两个全词汇表大小的概率张量。

在 AUSO 中的作用
JSD 在内化和利用过程中都被用作统一的动作级信息信号，为技能知识如何影响个体决策提供了一致的度量。在内化期间，它量化了技能条件教师行为和无技能反事实行为之间的差异，从而识别出外部技能指导为其提供更强纠正信息的动作。在利用期间，相同的度量表征了当前策略决策对检索到的技能的依赖程度，允许策略选择性地强调技能敏感动作。因此，相同的动作级信号自然地连接了从外部技能监督到自主技能利用的过渡，同时提供了对称性、有界性、支持鲁棒性和直接的信息论解释。

重要的是，\mathrm{IG}(u_{t}) 衡量的是技能条件对动作分布的影响，而不是直接表示任务成功概率。大的信息增益表明引入技能实质性地改变了策略的决策，但不一定意味着这种改变是有益的。这种技能诱导变化的实际有用性最终由强化学习目标和由此产生的任务奖励决定。这样，JSD 识别了技能在“哪里”发挥有意义的影响，而环境反馈决定了这种影响“是否”有助于成功的行为。
