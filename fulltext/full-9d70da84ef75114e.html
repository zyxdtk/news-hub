摘要
大型语言模型 (LLM) 越来越多地被部署在网络安全运营中，以协助网络安全分析师针对新出现的威胁做出快速决策。然而，在网络安全中使用 LLM 时必须满足一个主要标准，即对生成输出的信任。随着智能体 AI (Agentic AI) 被集成到运营系统中，稳健的证据归因和来源追踪技术对于追溯模型生成的起源至关重要。当自主智能体做出决策（无论对错）时，回溯决策链的能力至关重要，因为如果没有这种能力，团队就无法识别数据的哪一部分导致了模型的生成。现有方法通常难以区分复杂且高度相似的证据源，例如网络事件日志。这揭示了一个关键差距：当前的方法未能充分捕捉检索到的证据与生成的响应之间的整体几何关系，以进行可靠的证据验证。为了弥补这一差距，受拓扑学启发，我们提出了拓扑归因距离 (TAD)，用于表征和捕捉输出的全局几何形状及其相对于检索到的日志的变化。换句话说，如果特定源日志的嵌入极大地改变了模型响应在嵌入空间中的几何形状，这表明该日志是模型生成响应的关键来源。因此，TAD 由片段级消融归因驱动，以调查实际网络攻击的事件日志。我们展示了 TAD 如何以自适应的方式找到对 LLM 输出归因最大的日志。这可以提供基于每个 LLM 隐藏状态的可解释和可信赖的追踪，以了解几何上不同的检索日志如何影响模型生成，并在网络安全和智能体 AI 工作流中提供证据验证。

I 引言
检索增强生成 (RAG) 已成为智能体 AI 工作流中广泛使用的方法，通过为大型语言模型 (LLM) 提供相关的外部知识来进行基础支撑。在网络安全中，RAG 允许 LLM 访问最新信息（如漏洞报告和事件日志），以帮助支持更明智的安全分析和决策。然而，单纯的检索并不能保证解释的正确性，特别是当模型暴露于大量高度结构化和语义相似的信息时。正如 Zhang 等人 [37] 所指出的，当查询含糊、检索到的上下文过多或源质量较差时，RAG 系统仍然容易产生无根据的输出。这引发了 AI 在网络安全应用中采用的一个关键担忧，即：对生成输出的信任。随着智能体 AI 被集成到运营系统中，稳健的证据归因和来源追踪对于将模型决策追溯至其原始来源至关重要。没有这种可追溯性，AI 智能体做出的决策（无论对错）都难以诊断、验证和审计。因此，将模型决策可靠地归因于其原始来源以进行证据验证仍然是一个挑战。了解模型为何生成特定响应以及哪些检索到的上下文影响了模型的决策，对于在智能体 AI 时代提供信任、透明度和可审计性至关重要。

为了应对这些挑战，已有几条研究路线调查了为 LLM 生成的响应提供可解释性和归因 [4, 14, 33, 16, 22, 29]，但每种方法都有明显的局限性。一种突出的方法采用基于 LLM 的评判器来评估来源 [4, 14, 33]。由于这些方法依赖于同一类别或另一组正在被评估的模型，其准确性从根本上受到 LLM 自身固有的偏见、幻觉倾向和自我评估模式的限制。第二项工作侧重于词元级归因，通过为单个输入词元产生重要性分数来识别哪些词元对给定生成的影响最大 [16, 22, 29]，或相似性度量（例如，余弦相似度和 Rouge-L）。这些方法要么计算成本高昂，要么在高度结构化和相似的数据（如事件日志）上无效。因此，这些方法没有捕捉整体片段级基础，即模型响应作为一个整体受检索来源驱动的程度。换句话说，安全日志对模型行为的影响最好从整体上理解为作为一个完整的证据单元，而不是作为单独评分的词元集合。例如，在结构相似的日志中，关键区别可能源于几个词元之间的连通性，例如 psexec.exe 出现在异常的时间戳。词元级归因可能会在许多共享的、非区分性的词元中稀释这种信号。这突出了当前归因方法中的一个关键差距：缺乏一种机制，将词元级信号聚合为连贯的片段级归因，以识别何时一个小但关键的特征使整个检索片段变得具有影响力。

为了应对这些挑战，我们转向拓扑数据分析 (TDA)，这是一个用于研究数据形状的数学框架 [9]。TDA 借用了拓扑学的概念，其中代数不变量（如同调和同伦群）被分配给拓扑空间以表征其结构 [27]。同伦和同调是看待同一个潜在问题的两个视角：“两个拓扑空间何时相同？”同伦是两个映射 ($f,g:X\to Y$) 之间的连续变形，形式化为一个连续函数 ($H:X\times[0,1]\to Y$)，满足 ($H(x,0)=f(x)$) 和 ($H(x,1)=g(x)$)。直观上，同伦捕捉了这样一个概念：如果一个空间可以连续拉伸或压缩成另一个空间，则这两个空间是等价的。虽然同伦是更直观的概念，但直接计算通常是难以处理的 [2]。同调通过提取在同伦等价下保持的可计算代数不变量（例如，H0 用于连通分量，H1 用于查找孔洞等）来解决这个问题。换句话说，同调充当了同伦的计算可处理的代理，这意味着如果两个空间具有不同的同调，它们就不可能是同伦等价的。

现有研究表明，前馈网络在数据流经各层时逐渐转换数据的拓扑，这意味着拓扑能够映射非线性空间 [30]。先前的工作也表明，更深的层并不总是意味着更好的表示，证明了所有层对最终结论的影响的重要性 [20]。因此，在 LLM 的背景下，嵌入空间在各层（即非线性隐藏状态空间）上的几何和拓扑属性可以产生关于模型决策、归因和不确定性的有意义的解释 [18, 15]。有趣的是，LLM 的自回归特性（即先前的上下文塑造响应）可以为推理模型生成提供强大的视角。我们可以通过嵌入空间表征响应作为一个整体的词元连通性，并单独追踪每个先前上下文（每个片段）的影响，而不是比较响应中孤立的词元表示。换句话说，如果包含和省略检索到的上下文嵌入能够强烈地使模型响应的几何变形，这可以作为该上下文作为基础来源的证据。这种拓扑视角直接解决了上述片段级归因差距。

基于这种直觉，我们提出了拓扑归因距离 (TAD)，一种片段级归因指标，用于识别在 LLM 生成中引起最大几何变化的片段（例如，日志）。TAD 的工作原理是在 Transformer 层上追踪生成响应的嵌入几何的拓扑特征，包括存在和不存在每个检索片段的情况。更具体地说，我们从它们在具有和不具有上下文中每个片段的每个 Transformer 层上的嵌入几何中计算生成响应的持续图，并用 Wasserstein 距离量化响应嵌入上的变化。通过测量生成响应几何上显著变化的拓扑成本，TAD 在片段级产生归因分数。该分数捕捉了每个检索片段在几何上影响模型输出的程度。

我们在真实世界的网络攻击日志上以及三种不同场景下评估了 TAD，即直接、常规和间接。这些场景指向了相对于真实攻击日志的响应难度级别。更具体地说，直接案例在响应中包含日志中的许多词元，常规案例包含一些特定关键词，而间接案例在日志和响应之间几乎没有词元重叠。此外，我们将 TAD 与多个基线进行了比较，即 LLM-as-a-judge、相似性度量和词元级归因技术。我们展示了所提出的 TAD 指标在四个不同的 LLM（具有不同大小和架构）上的有效性。我们的结果表明，TAD 在追踪归因最高的日志方面显著优于现有基线，平均准确率超过 97%，并且在所有三种场景中与表现最好的基线相比，精确率差距超过 39%。在图 1 中，我们提供了一个案例研究，以展示不同的归因技术如何在将安全日志追踪到响应时失败，以及 TAD 如何在这些情况下发挥作用。总之，这些结果将 TAD 定位为一种可审计、感知来源的度量，能够将模型决策追溯至其检索来源，从而在网络安全运营和关键决策中建立信任。

这项工作的主要贡献如下：
* 我们将 RAG 系统中的片段级归因问题形式化为拓扑比较问题，在同伦理论推理和嵌入空间几何之间建立了明确的联系。
* 我们引入了拓扑归因距离 (TAD)，一种新颖的归因指标，捕捉了 LLM 响应几何在隐藏状态上变化的片段级影响，并计算它们的 Wasserstein 距离以找到归因最高的片段。
* 我们证明 TAD 非常适合事件日志分析，因为日志彼此之间共享高词元重叠，并展示了 TAD 如何能够识别对 LLM 响应几何影响最大的日志。
* 我们证明所提出的 TAD 指标在四个不同的 LLM 上平均准确率达到 97%，在三种不同难度级别的案例中精确率差距超过 39%，优于其他基线。

II 相关工作
II-A 现有 LLM 归因指标的挑战
RAG 系统的出现引发了关于来源归因的研究，即验证生成的文本是否由已识别的源文档支持。对于基于 LLM 的评判器，已经提出了不同的工作来评估 RAG 系统。Self-RAG [4]、RAGAS [14] 和 ARES [33] 采用基于 LLM 的评判器来自我评估 RAG 系统，无论是通过生成模型本身，还是通过另一组 LLM。然而，这些方法受到评估模型的自我解释和推理偏见的限制，并且它们没有将归因评估与参数化模型知识（即隐藏状态）完全解耦。

词元归因方法旨在量化单个输入特征（通常是词元嵌入）对模型输出的贡献。许多工作已经解决了将模型预测归因于单个输入特征的问题 [23]。在 LLM 中，LIME [31] 生成输入文本的变体（例如，通过掩蔽或移除词元）并观察输出概率的变化 [29]，而 SHAP [24] 分数是通过掩蔽或扰动输入词元的子集并观察输出变化得出的 [29]。然而，这些方法计算成本高昂，SHAP 是指数级的，并且无法随大量检索到的上下文（例如，安全日志）进行扩展。LRP [5] 是一种基于反向传播的方法，它将模型的预测分数通过网络层向后重新分配，将相关性分数分配给输入特征，并且已有工作使用 LRP 进行归因 [1, 22]。此外，在我们之前的工作 [16] 中，我们提出了 LLM 基于嵌入的归因 (LEA) 指标，这是一种基于输入嵌入的线性依赖分析的计算高效的词元级归因指标。总的来说，尽管取得了重大进展，但现有的特征归因技术仅限于词元级，并且在检索到的信息包含高度重叠的词元（例如，日志）时可能会遇到困难。这些方法虽然词元级归因对于识别哪些词元最影响给定预测很有用，但它没有捕捉整体片段级基础，即模型响应作为一个整体受检索上下文驱动的程度。这指向了该领域一个更广泛的开放挑战：弥合词元级归因到 RAG 系统中片段级归因追踪之间的差距。

II-B LLM 中的拓扑数据分析 (TDA)
拓扑数据分析在语言模型中的应用跨越了几个相互关联的方向 [34]。Draganov 和 Skiena [12] 证明了应用于词嵌入云的持久同调编码了有意义的语言结构。Rottach 等人 [32] 引入了统一拓扑特征，这是一个聚合拓扑和几何描述符以表征嵌入空间的框架。作者揭示了同一家族内的模型显示出相似的拓扑属性，这表明架构和训练数据强烈地塑造了嵌入空间的几何。

在 LLM 内部表示中，有一些工作将拓扑直接应用于隐藏状态激活。Fitz 等人 [17] 使用持久同调和穿孔比较了 Transformer 和 LSTM 隐藏状态的分层拓扑复杂性，他们发现 LSTM 展现出特定于自然语言的更丰富的拓扑结构。Gardinazzi 等人 [18] 采用锯齿持久性来追踪拓扑特征在各层之间的演变，引入了持久相似性指标，该指标识别冗余层并允许在性能损失最小的情况下进行原则性剪枝。Fay 等人 [15] 提出将持久同调作为架构无关的对抗检测框架，在提示注入和后门攻击下识别出一致的“拓扑压缩”特征，其中对抗性输入简化了潜在空间结构，并通过条形码摘要统计证明了正常和对抗性激活的清晰分离。

尽管前景广阔，但现有的 LLM 分析拓扑方法存在显著局限性。Fitz 等人 [17] 证明了 Transformer 模型在层变深时没有显示出拓扑复杂性（与 LSTM 相比）。然而，他们的穿孔指标排除了 H0 同调以捕捉连通分量。我们将在本文中展示，H0 在发现嵌入空间中的形状差异方面起着关键作用。Gardinazzi 等人 [18] 展示了不同 LLM 中每一层的重要性。虽然某些层比其他层对模型输出的贡献更大，但即使是最不关键的层被剪枝也会导致基准性能的显著下降。这表明了所有层表示的重要性，因此促使我们将这一见解纳入我们提出的方法中。此外，Fay 等人 [15] 在六个 LLM 中将拓扑压缩识别为对抗特征。然而，该框架完全专注于最后一个词元的隐藏状态，并依赖于批次级统计，这要求它们依赖于类似类别（干净或中毒）的数据批次来获得条形码摘要。这种对同质批次定义关系几何的依赖阻碍了对孤立生成的单个响应进行归因，并且缺乏实时适用性。最后，这些工作都没有考虑片段级归因和多源对响应生成的影响。

III 拓扑数据分析背景
在本节中，我们解释了拓扑数据分析 (TDA) 的数学基础。我们讨论了从点云数据构建单纯复形、跨尺度追踪拓扑特征的持久同调，以及用于比较持续图的 Wasserstein 距离。

III-A 点云和度量空间
TDA 的输入通常是点云，即表示为以下形式的有限集：
$V={v_{1},v_{2},\ldots,v_{n}}\subseteq M,$ (1)
其中每个点 $v_{i}$ 嵌入在配备了度量 $d:M\times M\to\mathbb{R}$ 的特征空间 $M$ 中，因此 $(M,d)$ 形成了一个度量空间。度量 $d(v_{i},v_{j})$ 量化了任意两点之间的相异性。当 $M=\mathbb{R}^{n}$ 时的一个常见选择是 $L_{\infty}$ 距离：
$d(v,w)=|v-w|{\infty}=\max{k}\,|v_{k}-w_{k}|.$ (2)
TDA 的核心见解是，离散的点集携带了潜在的几何和拓扑信息，这些信息可以从它们的成对距离中系统地提取 [7]。因此，这样做需要将点云提升到称为单纯复形的更高级别的组合结构。

III-B 单纯复形
单纯复形使用称为单纯形的基本构建块提供点云的组合表示 [13]。一个 $k$-单纯形被定义为 $k+1$ 个仿射无关点的凸包。换句话说，$k=0$ 给出顶点，$k=1$ 给出边，$k=2$ 给出填充三角形等。

从度量点云构建单纯复形的一种标准构造是 Vietoris–Rips 复形 [21]。给定一个尺度参数 $\varepsilon>0$，点集 $V$ 上的 Vietoris–Rips 复形定义为：
$\mathcal{R}{\varepsilon}=\bigl{\sigma\subseteq V\;\big|\;d(v{i},v_{j})\leq\varepsilon\;\;\forall\,v_{i},v_{j}\in\sigma\bigr}.$ (3)
也就是说，只要其 $k+1$ 个顶点之间的所有成对距离最多为 $\varepsilon$，就会包含一个 $k$-单纯形。$\varepsilon$ 的选择决定了形成哪些连接：值太小会导致几乎空的复形，仅捕捉平凡的局部结构，而值太大则会将所有点折叠成一个单一的完全连通分量，这促使我们同时研究所有尺度上的复形。

III-C 过滤与多尺度分析
不存在全局最优的 $\varepsilon$ 值。TDA 通过过滤 [13] 同时考虑所有尺度来解决这种模糊性，过滤是单纯复形的嵌套序列：
$\emptyset=K_{0}\subseteq K_{1}\subseteq K_{2}\subseteq\cdots\subseteq K_{m}=K,$ (4)
这些由参数值 $\varepsilon_{0}<\varepsilon_{1}<\cdots<\varepsilon_{m}$ 的递增序列索引。随着 $\varepsilon$ 的增长，新的单纯形被逐渐添加。最初，点表现为孤立的顶点；然后在附近的点之间形成边；最终，出现更高维的单纯形，代表空间的聚类区域。给定定义在点云 $\mathcal{V}\subset\mathbb{R}^{n}$ 上的标量函数 $f:\mathcal{V}\to\mathbb{R}$，相关的子水平集过滤 [11] 是子集的嵌套族：
$\mathcal{V}{t}=f^{-1}!\bigl((-\infty,\,t]\bigr)=\bigl{\,v\in\mathcal{V}\;\big|\;f(v)\leq t\,\bigr},$ (5)
它是通过随着阈值 $t$ 的增长，按 $f$ 值递增的顺序逐渐接纳点而获得的。在每一步，在 $\mathcal{V}{t}$ 上构建一个单纯复形（例如，Vietoris–Rips 复形），捕捉随着点根据其功能值被包含时空间拓扑的演变。

在过滤的每个阶段，复形的形状使用同调 [27] 进行量化。对于每个非负整数 $k$，第 $k$ 阶同调群 $H_{k}(K)$，通常在域 $\mathbb{F}$（通常是 $\mathbb{F}{2}={0,1}$）上计算，捕捉维度为 $k$ 的独立拓扑特征。更具体地说，$H{0}(K)$ 计算连通分量，$H_{1}(K)$ 捕捉独立的环或循环，$H_{2}(K)$ 检测封闭的空隙，而更高的 $H_{k}(K)$ 编码它们的高维类似物。

III-D 持久同调：诞生、消亡与持久性
持久同调追踪同调特征在过滤过程中的演变 [7, 13, 38, 26]。随着过滤参数 $\varepsilon$ 的增加，拓扑特征诞生（首次出现在 $H_{k}(K_{\varepsilon})$ 中）并最终消亡（与较旧的分量合并或被更高维的单纯形填充）。该特征的持久性为：
$\operatorname{pers}(\alpha)=\varepsilon_{death}-\varepsilon_{birth}.$ (6)
具有高持久性的特征被认为具有拓扑显著性，而具有低持久性的特征通常归因于噪声或采样变异性 [11]。请注意，$H_{0}$ 中至少有一个连通分量永远不会消亡，因为某些分量在整个过滤过程中持续存在。拓扑特征的完整生命周期可以用两种等效表示来总结：
持久条形码 [19, 6]：持久条形码是区间 $[b_{i},d_{i})$ 的多重集，绘制为水平条，其中每个条对应一个拓扑特征，其长度等于该特征的持久性。长条表示稳定特征，短条（接近零）表示噪声结构。
持续图 [13, 11, 8]：持续图是点 $(b_{i},d_{i})\in\overline{\mathbb{R}}^{2}$（其中 $d_{i}\geq b_{i}$）的多重集，绘制在对角线 $\Delta={(x,x):x\in\mathbb{R}}$ 上方的半平面中。对角线本身以无限多重性包含，代表诞生后立即消亡的特征。远离 $\Delta$ 的点对应于显著特征，而靠近 $\Delta$ 的点表示噪声。由维度 $k$ 中的过滤函数 $f$ 产生的持续图表示为 $\operatorname{Dgm}_{k}(f)$。因此，在建立了一种将拓扑特征表示为持续图的方法之后，自然会产生一个问题：“如何以几何上有意义的方式量化两个这样的图之间的相似性（或距离）？”我们将在接下来讨论。

III-E Wasserstein 距离
为了比较两个可能具有不同基数的持续图 $P$ 和 $Q$，人们寻求一种最小化总成本的部分匹配 $\gamma$ [11, 8, 25]。为了容纳未匹配的点，设 $\widehat{P}=P\cup\Delta$ 和 $\widehat{Q}=Q\cup\Delta$ 表示用对角线 $\Delta={(x,x):x\in\mathbb{R}}$ 扩充的图，将其视为持久性为零的平凡特征。匹配是一个双射 $\pi:\widehat{P}\to\widehat{Q}$，其中任何与对角线点配对的点都被视为未匹配。在 $L^{\infty}$ 范数下将点 $u=(b_{u},d_{u})$ 传输到点 $v=(b_{v},d_{v})$ 的成本为：
$|u-v|{\infty}=\max!\bigl(|b{u}-b_{v}|,\,|d_{u}-d_{v}|\bigr),$ (7)
而将 $u=(b,d)$ 匹配到其在 $\Delta$ 上的正交投影会产生与持久性成正比的成本 $|u-\Delta|{\infty}=\tfrac{d-b}{2},$ (8)
反映了移除持久性为 $d-b$ 的拓扑特征所需的最小 $L^{\infty}$ 位移。因此，持续图 $P$ 和 $Q$ 之间的 $(\infty,1)$-Wasserstein 距离 ($W{1}^{(\infty)}$) 定义为：
$W_{1}^{(\infty)}(P,\,Q)\;=\;\inf_{\gamma}\Bigg[\sum_{(u,v)\,\in\,\gamma}|u-v|{\infty}\;+$ (9)
$\sum{u\,\in\,P\setminus\gamma}d(u,\Delta)\;+\;\sum_{v\,\in\,Q\setminus\gamma}d(v,\Delta)\Bigg]$
其中 $\gamma$ 遍历 $P$ 和 $Q$ 之间的所有部分匹配，而 $d(u,\Delta)=(d_{u}-b_{u})/2$ 表示 $u=(b_{u},d_{u})$ 到其在 $\Delta$ 上的正交投影的 $\ell^{\infty}$ 距离。直观上，第一个和惩罚了匹配特征之间的几何差异，而第二个和第三个和分别惩罚了 $P$ 和 $Q$ 中未匹配的特征。

总的来说，Wasserstein 距离为持续图之间的相异性提供了一种几何上有意义且计算上可处理的度量 [25, 10, 3]。它量化了必须改变多少拓扑结构才能将一个图转换为另一个图。

IV 方法论
在本节中，我们在 LLM 的背景下实例化第 III 节中讨论的 TDA 流程，并讨论使用 Wasserstein 距离在 Transformer 层上追踪生成归因的拟议方法。

IV-A 将 TDA 概念映射到 LLM
词元嵌入作为度量空间：在 LLM 设置中，点云中的每个点 $v_{i}$ 对应于词元的向量表示（嵌入）。空间为 $M=\mathbb{R}^{n}$，其中 $n$ 是模型的隐藏维度，度量 $d$ 捕捉嵌入之间的几何相异性。我们采用 $L_{\infty}$ 距离，因为它可以显示高维嵌入空间中显著的方向差异。
用于编码语义关系的单纯复形：我们将 Vietoris–Rips 复形应用于词元嵌入点云。在阈值 $\varepsilon$ 处，只要两个词元嵌入之间的 $L_{\infty}$ 距离最多为 $\varepsilon$，它们就通过一条边连接。当一组嵌入彼此之间的距离在 $\varepsilon$ 范围内时，就会形成高阶单纯形。由于没有单一的 $\varepsilon$ 能捕捉嵌入空间的完整分层组织，我们在词元嵌入上构建完整的 Vietoris-Rips 过滤。每个 $K_{\varepsilon_{i}}$ 代表尺度 $\varepsilon_{i}$ 处的单纯复形，嵌套序列追踪随着阈值增长语义分组如何形成和合并。
过滤可以由定义在嵌入上的标量函数驱动。在我们的设置中，一个自然的选择是由分层隐藏状态参数化的子水平集过滤。过滤捕捉在每个阶段“关注”了哪些词元。这种构造将拓扑分析直接与模型内部信号连接起来，使过滤对 LLM 表示中的显著性和异常模式敏感。
用于嵌入空间拓扑不变量的同调群：在每个尺度 $\varepsilon_{i}$，我们计算在词元嵌入上构建的 Vietoris-Rips 复形的同调群：
$H_{0}$ 反映了嵌入在给定尺度下如何分组为连贯的语义区域（簇）。
$H_{1}$ 捕捉嵌入空间中的环，这可能对应于表示中的间隙或循环相关的语义概念。更高维的群 $H_{k}$ ($k\geq 2$) 编码嵌入之间更抽象的多向关系结构。这些同调不变量提供了每个尺度下嵌入空间全局几何的紧凑摘要。
跨尺度追踪语义结构的持久同调：将持久同调应用于词元嵌入过滤，可以完整记录随着 $\varepsilon$ 增长哪些语义结构出现和消失。$H_{0}$ 中的诞生事件对应于在尺度 $\varepsilon_{b}$ 处出现的新孤立连通分量。$H_{0}$ 中的消亡事件对应于两个连通分量在尺度 $\varepsilon_{d}$ 处合并为一个更广泛的组。$H_{1}$ 中的诞生和消亡对应于嵌入环的形成和填充，这可能表明概念关系。在这项工作中，我们的主要重点是 $H_{0}$ 同调，但我们将在附录 -A 中提供 $H_{1}$ 结果。
语义特征 $\alpha$ 的持久性 $\operatorname{pers}(\alpha)=\varepsilon_{d}-\varepsilon_{b}$ 量化了其稳定性。具有高持久性的特征代表嵌入空间中稳健且有意义的模式（如明确定义的主题），而低持久性的特征可能源于噪声或偶然的嵌入邻近。所有此类持久性值的多重集形成持续图 $\operatorname{Dgm}(X)\subset\mathbb{R}^{2}$，其中每个特征 $\alpha$ 贡献一个点 $(\varepsilon_{b},\varepsilon_{d})$。然后可以通过 Wasserstein 距离（参见公式 9）量化两个此类图之间的结构相似性。因此，人们可能会问：“如何利用这些拓扑描述符来系统地追踪嵌入空间中语义域的归因和映射？”我们将在下一节讨论这个问题。

IV-B 拓扑归因距离 (TAD)
现在我们转向将模型生成归因于单个事件日志片段的问题。我们的方法使用持久同调来量化每个检索到的日志片段如何影响模型响应的拓扑结构。为了量化不同的 RAG 片段如何影响模型输出，我们必须首先将我们的方法建立在仅解码器 LLM 的基本属性上：自回归词元生成。由于每个生成的词元完全依赖于上下文窗口中所有先前的词元，因此一个关键的推论随之而来：提示中的每个元素都以不同程度的因果影响塑造响应几何。因此，RAG 片段在上下文窗口中的位置放置、顺序排列和组合结构可以对模型输出产生可测量的影响。
为了全面测量给定检索日志集如何对最终响应做出贡献，该方法需要完整的上下文连接：所有片段与生成的响应一起按顺序附加到单个上下文中。这种设计确保了每个片段与模型输出之间的因果关系可以被明确追踪。通过这样做，可以通过受控的消融来隔离片段级贡献：在保持所有其他变量不变的情况下，在实验运行中系统地排除单个片段。这两种机制（即完全连接和定向消融）共同构成了将响应内容归因于其起源上下文的基础。
为了获得每个日志片段对输出贡献的模型输出的拓扑映射，我们计算 LLM 每一层上它们对应的持续图之间 H0 同调的 $(\infty,1)$-Wasserstein 距离（参见公式 9）。选择 H0 同调的原因是它计算效率更高（见第 V 节），并且先前的工作已经证明了 H0 在几何重组任务中的有效性 [36]。为了捕捉整体表示，我们在各层上聚合 Wasserstein 值以获得每个日志片段的归因。这是由于 Transformer 的性质，即每一层都对应于最终决策，正如先前工作 [18] 所讨论的。以下是拟议的 TAD 指标：
$\mathcal{TAD}(P,\,Q)\;=\;\sum_{\ell=1}^{L}W_{1}^{(\infty)}!\left(\operatorname{Dgm}{0}(P{\ell}),\,\operatorname{Dgm}{0}(Q{\ell})\right)$ (10)
其中 $Dgm_{0}$ 代表 H0 同调，$P_{l}$ 和 $Q_{l}$ 分别是每一层上消融上下文和完整上下文的持续图。这种提出的扩展可以提供超越词元级影响的归因，因为它可以在片段级提供可解释性。关键见解是，每个对输出影响最大的日志片段在特征空间中与输出本身具有表示相似性。因此，相应地消融这些有影响力的片段应该会产生大得多的 Wasserstein 距离，从而直接衡量它们的贡献。
图 2 展示了我们提出的方法。首先，我们通过在其表示上构建 Vietoris-Rips 复形并提取具有完整上下文 + 生成响应的 H0 持久同调来表征生成输出的拓扑结构。接下来，由于在规模上每日志消融在计算上是令人望而却步的，我们采用了先筛选后确认的归因策略。在筛选阶段，输入日志序列被划分为大约 $\sqrt{N}$ 个批次。每个批次依次被消融，并且对输出形状产生的扰动通过原始和消融的 LLM 响应的持续图之间的 Wasserstein 距离来量化，在每个 Transformer 层独立计算并跨层聚合为每个批次的单个距离度量。然后选择具有最大聚合距离的批次进行更细粒度的分析。在确认阶段，我们执行仅限于该高归因批次的单日志消融，再次计算生成的持续图之间的分层 Wasserstein 距离，以识别和排列最负责塑造模型输出几何的单个日志条目。在算法 1 中，我们展示了拟议 TAD 方法的完整详细过程。

V 复杂度讨论
TAD 的成本分为两个阶段：Transformer 推理和持久同调。设 $N$ 为上下文中候选日志条目的数量，$T$ 为点云中响应词元的数量，$d$ 为模型的隐藏维度，$L$ 为 Transformer 层的数量。
推理成本。TAD 是基于消融的归因，因此复杂度是向模型发出的前向传递次数 $M$。一个纯线性的情况，即每个日志单独消融，需要 $M=N+1$ 次传递（一个基线加上每个日志一次），这在上下文长度上线性扩展，对于长的智能体轨迹来说变得令人望而却步。我们提出的先筛选后确认的过程反而将池划分为 $\lceil\sqrt{N}\rceil$ 个组，并且仅在被标记为峰值的组上递归，这将预期成本降低到 $M=O(\sqrt{N})$ 次传递。
拓扑成本。对于每次前向传递和每一层 $\ell$，TAD 从响应词元隐藏状态构建点云 $X_{\ell}\in\mathbb{R}^{T\times d}$，并计算其 Vietoris–Rips 过滤的持续图。形成成对距离矩阵的成本为 $O(T^{2}d)$。当限制于 $H_{0}$ 时，只需要 1-骨架：$O(T^{2})$ 条边在 $O(T^{2}\log T)$ 时间内排序。因此，每次传递的成本为 $O(L\,T^{2}(d+\log T))$，即在响应词元数量上是二次的，在网络深度上是线性的。扩展到 $H_{1}$ 的成本要高得多，因为它需要 2-骨架，可能包含 $O(T^{3})$ 个三角形，并且在单纯形数量上具有三次复杂性。
总的来说，在 $H_{0}$ 同调下，TAD 的端到端成本为 $O(M\cdot L\cdot T^{2}(d+\log T))$，在自适应筛选下 $M=O(\sqrt{N})$，这是我们在整个实验中采用的配置。

VI-B 实验设计
在可能生成数千或数百万条日志条目的真实场景中，由于上下文窗口限制、增加的推理成本以及可能降低响应质量的不相关信息的存在，将所有可用日志直接提供给 LLM 通常是不切实际的。有针对性的调查允许模型专注于与分析师假设最相关的证据子集，同时减少噪声和计算开销。因此，我们的实验场景是由有针对性的威胁调查工作流程驱动的。我们假设安全分析师已经怀疑特定用户账户可能已被攻陷。分析师随后使用以下形式的提示查询系统：
检查 [日期] [开始时间] 和 [结束时间] 之间记录的日志。这些日志中是否有攻击的证据？
这种表述通过日期和时间限制了调查，反映了现实的告警后工作流程。模型评估提供的日志是否支持分析师的假设，而不是执行不受限制的威胁搜寻。
此外，直接比较来自多个 LLM 的自然语言响应会引入混淆因素，例如措辞、细节、结构、置信度和事件解释方面的差异。为了提高可比性，我们假设从真实攻击日志派生的规范响应已经可用，并在所有评估模型中保持此响应不变。为了整理这些规范响应，我们使用 Claude-Opus-4.5 模型生成与真实攻击日志密切匹配的高质量输出。这种设计构成了受控的实验抽象。在真实部署中，每个模型都会生成自己的调查报告，由此产生的结论可能会根据模型的训练数据、推理能力和上下文理解而有所不同。因此，使用规范响应提高了实验可比性，但并未评估特定于模型的响应生成的质量。
为了在不同难度级别上评估 TAD，我们考虑了三种场景：“直接”、“常规”和“间接”。“直接”适用于 LLM 显著复制源日志中的词语时。“常规”案例适用于 LLM 复制一些关键词但给出更一般性解释时。“间接”案例适用于 LLM 几乎不使用任何可以通过关键词搜索将响应映射到特定日志的关键词时。这样做的原因是我们将展示 TAD 不是基于查找确切的关键词并对这些关键词投入更高注意力。相反，它基于每个日志作为一个片段的整体解释。
此外，我们将 TAD 与多个基线进行比较：LLM-as-a-judge、内联引用、基于相似性的度量（余弦相似度和 ROUGE-L）以及词元级归因技术 (LEA)。这些基线代表了评估 LLM 生成响应来源的常用方法。对于 LLM-as-a-judge 和内联引用基线，我们使用贪婪解码以获得确定性和可重现的响应。附录 -C 展示了这些方法的工程提示。对于词元级归因，我们采用我们之前提出的 LEA 指标 [16]，因为它基于输入嵌入的线性依赖并且计算效率高。请注意，由于计算复杂性高，我们不考虑其他词元级归因方法（如 SHAP）。最后，对于余弦嵌入模型，我们使用了 Alibaba-NLP/gte-modernbert-base 模型，因为它非常适合长上下文语义搜索（8,192 个词元）。
用于分析的 LLM 是：Qwen3-4B、Gemma3-4B、Qwen2.5-7B 和 Granite4.1-8B。选择这些模型是因为它们具有长上下文窗口（最少 128K 上下文窗口）以处理大型安全日志以及良好的指令遵循能力。值得注意的是，我们在配备两个 Intel Xeon E5-2650 CPU、256 GB RAM 和 NVIDIA Tesla L40S GPU 的系统上进行了实验。代码和数据可在以下网址获取：https://github.com/RezzFayyazi/TAD。

VI-C 用于事件日志分析的 TAD
如上一节所述，我们在三种设置下比较 TAD 与不同的基线：直接、常规和间接，这些设置在响应公开引用日志的方式上有所不同。所有方法都使用相同的选择规则：我们按分数对候选者进行排序，找到连续分数之间的最大差距，并返回其上的所有内容。我们这样做是因为分析师事先不知道有多少日志影响了响应。固定的 top-$k$ 截止值要么会切断真正的贡献者，要么会增加噪声，而差距规则让分数设定自己的阈值。
表 III 展示了结果。可以看出，TAD 在几乎所有三种设置中都获得了最佳的准确率和 F1 分数，尽管差距有所不同。平均而言，对于“直接”、“常规”和“间接”案例，TAD 在准确率上分别比最接近的基线高出 1.60%、3.11% 和 6.63%，在 F1 分数上分别高出 7.35%、15.77% 和 17.63% 的差距。请注意，差距范围在准确率上为 1.60% 到 6.63%，在 F1 分数上为 7.35% 到 17.63%，其中“间接”案例表现出最大的差距。这是因为当日志和响应之间存在高词元重叠时，其他基线表现更好，而当响应与日志几乎没有共享词元时，它们的表现很差。
值得注意的是，在附录 -A 中，我们提供了基于 H1 同调的 TAD 结果，在附录 -B 中，我们提供了一个定性示例以及一些关于 TAD 如何追踪对 LLM 响应贡献最大的日志的具体示例。
此外，根据我们的观察，基线表现出一个清晰的模式：每个基线都达到了高召回率但精确率低得多：它找到了有影响力的日志，但只能通过返回一个包含许多误报的大集合来实现。TAD 通过在“直接”、“常规”和“间接”案例中分别达到 94.23%、86.90% 和 57.70% 的高精确率来以不同方式实现这一点。平均而言，对于“直接”、“常规”和“间接”案例，TAD 在精确率上分别比最接近的基线高出 39.47%、47.46% 和 40.88% 的差距。这在实践中很重要，因为在现实世界中，分析师时间有限且有数千条日志池。因此，一种返回如此多候选者（即高召回率）以揭示少数真实候选者的方法，恢复了自动归因旨在消除的手动工作。
此外，查看结果，人们可能会问：“为什么每个 LLM 的 F1 分数质量有所不同？”。原因是每个 LLM 单独学习的表示。学习的表示影响每个 LLM 如何在嵌入空间中将词元作为一个片段连接，正如 Rottach 等人 [32] 所讨论的。这意味着如果一个 LLM 比另一个学习到更多的网络安全知识，它自然会更复杂地连接词元。因此，像 Gemma3-4B 这样的 LLM 在我们的实验中表现不如其他模型，表明该模型没有正确学习安全日志和响应之间的映射。
此外，所选基线由于不同原因表现不佳。首先，基于 LLM 的自我评估对提示设计很敏感，这意味着不同的工程提示可能会给出不同的归因判断。这种可变性是因为决策来自模型自身对后续提示的推理，而不是 TAD 对原始上下文（导致 LLM 生成）的数学可追踪的内部属性。其次，相似性和词元级方法失败是因为事件日志共享高度重叠的词元，导致在余弦相似度下塑造响应的日志与其近似重复项几乎相同。TAD 通过测量模型对上下文做了什么（对于生成的响应）而不是上下文与响应如何相似来避免这两个问题。移除有影响力的日志会在分层持续图之间的距离中产生一个大的、清晰分离的峰值。因为响应是固定的且计算是确定性的，所以结果是可重现、可追踪的，并反映了模型如何将上下文映射到响应。未来的工作可以调查各个层对生成的重要性，并探索 Vietoris-Rips 构建的可扩展变体。我们将此视为朝着透明和可验证归因迈出的一步，允许分析师检查和验证证据，而不是简单地信任模型的输出。

VII 结论
我们引入了拓扑归因距离 (TAD) 来捕捉 LLM 输出的全局几何形状及其相对于检索上下文的变化。换句话说，我们展示了当检索到的上下文（例如，安全日志）的嵌入极大地改变了模型响应的几何形状时，这可作为证据的稳健验证，并且可以被追踪。因此，我们设计了由片段级消融归因驱动的 TAD，以调查实际网络攻击的事件日志，并展示了 TAD 如何自适应地找到对 LLM 输出归因最大的日志。TAD 可以提供基于每个 LLM 隐藏状态的可解释和可信赖的追踪，以了解不同的 RAG 片段如何在几何上影响模型生成，并在网络安全运营和智能体 AI 工作流中提供证据验证。
