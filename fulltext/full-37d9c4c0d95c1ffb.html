摘要

跨模态地点识别（CMPR）将自然语言描述与带地理标签的参考图像数据库进行匹配，实现无需视觉查询的定位。尽管其在语言引导导航方面潜力可观，现有视觉-语言模型即使在任务适配后仍远落后于视觉地点识别（VPR）基线。与通用文本-图像检索不同，地点识别依赖细微的局部线索来区分视觉上相似的位置。因此我们假设，CMPR的一个主要瓶颈在于捕捉图像区域与文本细节之间的细粒度对应关系，这需要更高的视觉token粒度、强大的文本表示能力以及局部跨模态匹配。为应对这一挑战，我们提出CrossPlace——一个两阶段CMPR框架。阶段1通过将联合对齐的DINOv2-B/14视觉骨干网络与渐进微调的BGE-Large文本编码器配对执行全局检索；阶段2使用轻量级token级交叉注意力重排序器对头部候选进行精炼。通过系统分析，我们分离出检索准确性的驱动因素，表明视觉token密度带来最大的性能提升，而文本编码器容量与任务微调提供互补增益。为评估现实条件下的鲁棒性，我们还将CMPR评估扩展至城市规模以及恶劣天气与光照设置。在所有现有与新增基准上，CrossPlace较先前跨模态方法取得两位数的Recall@1提升，缩小了与单模态文本检索的差距，并逼近单模态VPR。

1 引言

视觉地点识别（VPR）将视觉查询与地理定位的图像数据库进行匹配，在各种应用中实现全局重定位 [35, 22]。跨模态地点识别（CMPR）由LaVPR [13] 引入，将该任务扩展至自然语言，无需输入图像即可纯粹从文本描述中检索地理位置。

CMPR弥补了一项根本性的操作空白。例如，在搜救行动中，急救人员口头描述所观察到的地标，这些地标必须立即完成地理定位。类似地，人在回路的导航要求操作员在摄像头画面不可用时通过语言指挥自主系统。更广泛地说，当图像采集受损、物理上不可行或操作上不切实际时——这些条件从根本上限制或破坏标准VPR流程——文本查询提供了独特的灵活性。

图1：MSLS Val和Pitts30k基准上的跨模态地点识别性能（Recall@1）。柱状图展示跨模态模型：LaVPR表示LaVPR跨模态模型（其最佳变体，使用BLIP）；CrossPlace阶段1（CP-S1）为我们的全局检索模型；CrossPlace阶段2（CP-S2）加入交叉注意力重排序。水平参考线提供跨模态检索相对于单模态性能的参照：青色点线标记使用BGE-Large的单模态文本到文本检索（T2T），橙色虚线给出使用CricaVPR的视觉（图像到图像，I2I）地点识别性能。(a) MSLS Val：LaVPR 38.0，CP-S1 53.8，CP-S2 60.1，I2I参考85.9；(b) Pitts30k：LaVPR 50.2，CP-S1 61.2，CP-S2 66.4，I2I参考93.2。

尽管跨模态定位前景可期，语言到图像检索仍大幅落后于单模态视觉地点识别。例如，在MSLS-Val基准 [38] 上，表现最佳的跨模态方法（LaVPR [13]）的Recall@1为38.0%，而最先进的纯视觉模型超过85% [22, 14]。

与聚焦粗粒度语义类别的通用文本-图像检索不同，地点识别依靠细微的局部线索来区分特定位置，例如门的样式、窗户的形状、立面纹理，以及它们在场景中的空间布局。

我们提出CrossPlace，一个两阶段CMPR框架，旨在通过更高的视觉token粒度、强大的文本表示能力和局部跨模态匹配来应对这一挑战。在阶段1中，CrossPlace将联合对齐的DINOv2-B/14视觉骨干网络与渐进微调的BGE-Large文本编码器配对，执行全局候选检索。在阶段2中，受视觉地点识别中空间重排序 [36] 的启发，我们对文本token和局部图像块采用轻量级token级交叉注意力重排序器来精炼候选分数。

通过对CrossPlace及替代配置的系统分析，我们分离出实践中检索准确性的驱动因素。研究表明，视觉token密度（空间块粒度）是性能提升的主要来源：将块密度从ViT-B/32的49个token提升至DINOv2-B/14的256个token，在所有基准上带来最大的性能提升，并进一步得到自监督空间表示的强化。与此同时，一旦建立了足够的视觉粒度，文本编码器容量和渐进任务微调可提供互补的支持性增益。此外，由于CrossPlace匹配或接近单模态文本到文本检索参照（图1，青色点线），这些发现表明全局跨模态对齐只是次要瓶颈。

为建立更广泛的基准套件并评估可扩展性与域泛化能力，我们在既有的LaVPR基准上评估我们的方法，并引入源自旧金山超大规模数据集（SF-XL）和SVOX的新跨模态基准。在这些多样化设置中，仅我们的全局检索阶段就大幅超越现有基线，Recall@1提升5.2–20.3个百分点。引入我们轻量级的交叉注意力重排序模块后，在所有基准上相比先前跨模态最新技术总体提升9.7–32.4个百分点，且引入的延迟可忽略不计。此外，CrossPlace缩小了与单模态VPR基线的差距（图1，橙色虚线）。

综上，我们的主要贡献如下：

  • 我们提出CrossPlace，一个旨在捕捉细粒度图像-文本对应关系的两阶段CMPR框架：阶段1将联合对齐的DINOv2-B/14视觉骨干网络与渐进微调的BGE-Large文本编码器配对，阶段2采用轻量级token级交叉注意力重排序器。
  • 通过系统的架构分析，我们精确定位CMPR准确性的驱动因素，表明视觉token密度是性能提升的主要来源，而文本编码器容量和渐进任务对齐提供互补增益，有效缩小了与单模态文本检索的差距。
  • 我们将CMPR评估扩展至城市规模（SF-XL）以及恶劣天气与光照（SVOX）设置，证明CrossPlace在所有既有和新基准上相比先前跨模态基线实现两位数的Recall@1提升。

2 相关工作

2.1 视觉地点识别

基于图像的地点识别。 视觉地点识别（VPR）通过从地理标记数据库中检索最近匹配来识别查询图像的位置。全局描述符通常通过NetVLAD [3] 或GeM [29] 等池化层形成，近期工作通过最优传输 [14]、特征融合 [2, 22] 和基础模型适配 [23, 36] 提升判别能力。训练目标主要依赖对比多相似性损失 [1, 37] 以强制条件不变性，或采用分类代理 [5, 6]。

尽管行之有效，但当查询图像因传感器故障、严重视觉退化 [38, 35] 或人在回路操作而无法获取时，仅基于图像的地点识别便会失效，这促使了直接从描述性语言查询定位地点的跨模态范式 [13]。

2.2 跨模态地点识别（CMPR）

虽然标准视觉定位通常以单模态方式运行，但相关工作探索了异构输入。一条研究路线考察多模态融合，将2D图像与3D LiDAR点云结合 [28, 17, 18, 11]，或以提取的场景文本 [9]、描述性语言 [13] 和多传感器流 [25] 增强视觉查询。UniLoc [39] 等统一架构进一步支持映射到3D子图的多种查询模态。其他研究通过将描述直接映射到3D点云坐标来处理文本到3D定位 [16, 40, 21, 42]，或将文本与俯视卫星和地图图块匹配 [44]，偏离了可扩展的街景级视觉数据库。近期的跨模态地理定位方法还探索了用于几何对齐的多锚点投影相似性 [12]、多视图文本-视觉配准 [33]，以及桥接图像与文本用于地理定位的语义锚定多视图基础模型 [34]。这些方法依赖多视图图像或专门的几何锚点，不能直接应用于标准文本到图像地点识别或其既有基准 [13]。

我们的工作聚焦于跨模态文本到图像地点识别，即纯粹从输入的自然语言描述检索街景级图像数据库中的地理位置。LaVPR [13] 形式化了这一设置，表明通过LoRA [10] 与多相似性损失 [37] 适配视觉-语言模型可大幅超越零样本基线。然而，即使经过任务特定适配，这些模型仍落后于VPR基线。本工作中，我们旨在通过引入CrossPlace来缩小这一差距。

2.3 地点识别中的重排序

两阶段粗到细流程在VPR中已十分成熟。超越全局描述符的检索精度通常通过几何验证 [30]、局部块匹配 [8]、学习型关键点对应网络 [31] 或学习型候选重评分器 [46] 来增强。近来，SelaVPR++ [24] 和EffoVPR [36] 等基础模型方法证明，适配冻结骨干网络的token级特征可实现高效的两阶段视觉检索。然而，所有现有的地点识别重排序器仅在图像到图像对应关系上运行，直接比较视觉查询特征与数据库视觉表示。

相比之下，两阶段重排序在跨模态地点识别中完全未被探索，LaVPR [13] 等现有方法严格依赖单阶段全局描述符检索。虽然细粒度后期交互已在通用视觉-语言领域得到探索 [26, 15]，但这些方法无法直接迁移到跨模态地点识别。TERAN [26] 等通用文本-图像检索方法将单词与预训练检测器产生的显著目标提议对齐。此类以目标为中心的提议在城市规模数据库上计算成本过高，且丢弃了消歧地点所必需的背景建筑语境和结构纹理。

为弥合这一差距，我们引入首个专为语言到视觉地点识别定制的轻量级交叉注意力重排序器。我们的架构通过让文本token直接关注预计算的视觉图像块来精炼候选相似度，以适度的延迟捕捉细粒度空间对应关系。

3 方法

我们形式化跨模态地点识别问题（3.1节），详述阶段1全局检索架构及其对齐方案（3.2节），并介绍轻量级token到块重排序模块（3.3节）。

3.1 问题表述

设 𝒟 = {I_i}_{i=1}^{N} 表示带地理标签的图像数据库，t_q 为描述目标位置的自然语言查询。跨模态地点识别任务检索与所述位置对应的数据库图像 I* ∈ 𝒟。在粗到细框架中，检索首先将文本查询和数据库图像投影到共享度量空间，基于全局嵌入相似度（如余弦相似度）选出前K个候选图像构成候选列表，然后利用细粒度token级对应关系对候选列表重排序以确定最终预测。

3.2 跨模态全局检索（阶段1）

骨干网络表述。 设 f_v 为从输入图像 I 提取全局表示 f_v(I) ∈ ℝ^{d_v} 的视觉骨干网络，f_t 为将输入描述 t 映射为池化句子嵌入 f_t(t) ∈ ℝ^{d_t} 的文本编码器。两个编码器均遵循LaVPR [13]，采用低秩适应对齐所有线性投影层，秩为r。学习到的线性头 h_v: ℝ^{d_v} → ℝ^{d_c} 与 h_t: ℝ^{d_t} → ℝ^{d_c} 将各自的池化表示映射到共享的 d_c 维度量空间：

z_v = h_v(f_v(I))，z_t = h_t(f_t(t))，z_v, z_t ∈ ℝ^{d_c}　　(1)

两个描述符均做L2归一化。查询 t_q 与候选图像 I_i 之间的全局相似度通过余弦相似度 S(z_t, z_v^i) = z_t^⊤ z_v^i 计算。在实现中，我们用DINOv2-B [27]（d_v = 768）实例化视觉骨干网络 f_v，用BGE-Large [41]（d_t = 1024）实例化文本编码器 f_t，并设 r = 64，d_c = 768。

对齐与训练目标。 直接从通用预训练检查点优化跨模态对齐可能导致表示漂移，因为文本编码器必须同时适配领域特定的地点描述并与视觉特征对齐。为避免这一点，我们采用由通用多相似性（MS）损失 [37] 主导的两阶段训练策略。对于查询批次 ℬ，基于成对余弦相似度 S_qp 与 S_qn 的损失定义为

ℒ_MS = (1/|ℬ|) Σ_{q∈ℬ} { (1/γ_p) log[1 + Σ_{p∈𝒫_q} e^{−γ_p(S_qp−λ)}] + (1/γ_n) log[1 + Σ_{n∈𝒩_q} e^{γ_n(S_qn−λ)}] }　　(2)

其中 𝒫_q 与 𝒩_q 分别为查询 q 挖掘的正、负候选集，γ_p、γ_n 与 λ 为缩放超参数。

我们在两个连续训练阶段实例化公式2：

  1. 文本到文本域适应。 我们首先仅在文本到文本检索上对齐文本编码器。给定从不同视角描述同一地理位置的成对描述，我们通过LoRA优化BGE-Large，其中 S_qp 与 S_qn 表示成对文本到文本相似度 S^tt = S(z_t^q, z_t^i)。该单模态阶段建立了专为地点判别定制的强语言表示。

  2. 联合跨模态对齐。 以第一步的文本编码器权重为初始化，我们联合训练适配后的BGE-Large编码器与DINOv2视觉骨干网络。此时公式2中的相似度变为跨模态文本到视觉相似度 S^tv = S(z_t^q, z_v^i)。该联合对齐锚定了共享度量空间，使模型能够检索前K个数据库图像候选列表以供后续重排序。

3.3 跨模态重排序（阶段2）

Token到块交叉注意力。 阶段1检索将图像映射为单一全局向量，而查询常常描述多个特定空间地标。为解决细粒度歧义，我们的阶段2模块计算语言token与局部视觉区域之间的交互。

对于查询 t_q，我们从阶段1文本编码器提取未池化的文本token表示 T_q ∈ ℝ^{L×d_t}，其中L为token序列长度。对于候选图像 I_i，我们从阶段1视觉骨干网络提取未池化的视觉token P_i ∈ ℝ^{N_p×d_v}，其中 N_p 为局部块数量。为了在不向重型骨干网络反向传播的情况下高效提取局部特征，我们将阶段1的LoRA适配器合并到各自的基础模型中，并在重排序器训练期间保持所有骨干网络参数冻结。

由于两个编码器均在全局池化目标下优化，其局部token空间缺乏逐元素对齐，这妨碍了无参数后期交互算子的有效使用。因此我们引入轻量级可学习交叉注意力模块。文本与视觉token被线性投影到共享内维d，构成矩阵 X_0 ∈ ℝ^{L×d} 与 P ∈ ℝ^{N_p×d}。序列随后经过 n_ℓ 个交互块处理。每个块先执行从文本token到视觉块的交叉注意力，随后是文本自注意力和前馈网络：

X′ℓ = X{ℓ−1} + MHA(LN(X_{ℓ−1}), LN(P), LN(P))，　　(3)
X″_ℓ = X′_ℓ + MHA(LN(X′_ℓ), LN(X′_ℓ), LN(X′_ℓ))，　　(4)
X_ℓ = X″_ℓ + FFN(LN(X″_ℓ))　　(5)

其中LN表示层归一化，MHA表示具有h个头的多头注意力，ℓ ∈ {1, …, n_ℓ}。经过 n_ℓ 个块后，上下文化的文本CLS token通过线性投影向量 w ∈ ℝ^d 产生标量重排序分数：

R(t_q, I_i) = w^⊤ LN(x_CLS^{(n_ℓ)})。　　(6)

推理时，最终匹配分数将两个阶段线性组合：

Ŝ(t_q, I_i) = α S(t_q, I_i) + (1−α) R(t_q, I_i)　　(7)

其中 S(t_q, I_i) 与 R(t_q, I_i) 分别为阶段1检索（余弦相似度）与阶段2重排序（公式6）的分数，α为权重系数。

重排序目标。 重排序器使用阶段1全局检索器离线挖掘的困难负样本训练。对每个训练查询q，阶段1检索产生排序候选池，我们从中采样包含至少一个正匹配的训练候选列表。我们在候选列表上以列表式交叉熵目标优化重排序器：

ℒ_listwise = −(1/|ℬ|) Σ_{q∈ℬ} Σ_{k∈𝒱_q} ỹ_k log[exp(R_k) / Σ_{j∈𝒱_q} exp(r_j)]，　　(8)

其中ℬ为训练批次，𝒱_q 为查询q的候选列表索引集，R_k = R(t_q, I_k) 为候选k的预测重排序分数。归一化目标分布 ỹ_k = y_k / Σ_{j∈𝒱_q} y_j 在 𝒱_q 中所有正候选（y_k ∈ {0,1}）上分配均匀概率质量，负样本为零。

我们在补充材料中提供方法的扩展描述及推理流程的视觉概览。

4 实验设置

数据集。 我们在LaVPR [13] 引入的跨模态地点识别（CMPR）基准上评估CrossPlace，该基准将Pittsburgh30k（Pitts30k）[35]、MSLS-val [38] 和AmsterTime [45] 数据集与文本查询描述配对。为建立更广泛的评估套件，我们进一步将LaVPR提供的描述生成流程应用于两个具有挑战性的基准：涵盖恶劣天气与光照变化的SVOX [7]，以及大规模城市数据集旧金山超大规模（SF-XL）[5]。

基线。 我们将CrossPlace与先前跨模态最新技术进行比较，采用LoRA-MS-BLIP [13] 作为主要基线。在涵盖CLIP、BLIP、SigLIP2和EVA-CLIP2的零样本与PEFT微调变体的系统性LaVPR评估中，LoRA-MS-BLIP取得了最强的CMPR性能。所有微调的LaVPR变体在所有线性投影上应用LoRA（r = 64），与我们的阶段1设置一致，确保我们的比较隔离的是骨干架构而非适配方案。我们使用作者公开发布的代码和检查点，在统一协议下评估LaVPR。标准基准上的结果复现了 [13] 的报告，同一检查点直接在SVOX和SF-XL上评估。

评估协议。 我们报告 k ∈ {1, 5, 10} 的Recall@k（R@k），遵循标准VPR评估协议 [38]。若检索图像位于查询位置25米范围内（Pittsburgh30k、MSLS和SF-XL），或具有相同地点标识（AmsterTime和SVOX），则视为正确匹配。阶段1 R@k指全局嵌入检索，阶段2 R@k报告前K个候选列表经跨模态重排序后的结果。

训练与实现细节。 阶段1训练使用每批80个地点、每地点4张图像（每批320张图像），MS损失（公式2）参数 γ_p = 2，γ_n = 40，λ = 0.5。优化采用AdamW，初始学习率 2×10^{−5}，在第10和16个epoch衰减，共20个epoch。LoRA（r = 64）应用于BGE-Large和DINOv2-B的所有线性投影。对DINOv2-B，这覆盖了全部12个transformer块的查询、键、值和输出投影及MLP层。DINOv2-B以224×224分辨率处理图像，块大小为14，产生 N_p = 256 个维度为768的块token。BGE-Large以最大512 token的序列长度对描述分词（覆盖LaVPR描述的最大长度）。

所有实验在单块具有96 GB显存的RTX Pro 6000 Blackwell GPU上进行。

阶段2中，局部块与文本token从冻结的阶段1编码器预计算（LoRA矩阵已并入冻结编码器）并存储于磁盘，因此重排序器训练时骨干网络完全不运行。我们使用 d = 128，h = 4个注意力头，n_ℓ = 1层，批次大小64，AdamW学习率 10^{−4}，余弦衰减，训练10个epoch。列表式损失（公式8）的候选池由每查询100张图像的阶段1候选列表中取前 K_cand = 50 个条目构成。

分数融合（公式7）采用 α = 0.2，通过Pitts30k验证集上的消融实验选定（见图4）。

所有跨模态检索模型在GSV-Cities [1]（529,506张图像，67,331个地点，每地点四个视角）上训练，并配以LaVPR文本描述 [13]，采用先前工作 [13] 的标准VPR协议评估。CrossPlace重排序器在通过CrossPlace阶段1检索从GSV-Cities离线挖掘的困难负样本数据集上训练：对每个训练查询，检索前100个候选图像，该候选列表中所有非正匹配均视为困难负样本。

5.2 性能提升的驱动因素

为理解检索准确性的驱动因素，我们沿两条主轴分离各架构组件的贡献：视觉编码器粒度与预训练、文本编码器容量与任务对齐。图3报告了AmsterTime、MSLS-val和Pitts30k上的阶段1 Recall@1。

视觉编码器粒度与预训练。 视觉token密度是检索性能的首要驱动因素，其重要性超过文本编码器容量。在每个基准上，以较小文本编码器升级视觉粒度（ViT-B/16 + BGE-B）优于以较粗块升级文本容量（ViT-B/32 + BGE-L），例如在MSLS-val上取得43.8%对37.8%，在AmsterTime上15.4%对13.7%。固定CLIP初始化与BGE-B，将块粒度从ViT-B/32（49个token）提升至ViT-B/16（196个token）可分离该效应，MSLS-val上Recall@1提升+7.7个百分点（从36.1%到43.8%），Pitts30k上提升+4.4个百分点（从48.6%到53.0%）。切换到配以BGE-B的DINOv2-B/14（256个token）持续进一步提升Recall@1，表明自监督空间表示在扩展文本编码器之前就已强化更高块密度的收益。

文本编码器容量。 将文本骨干从BGE-B扩展至BGE-L在所有视觉编码器上带来一致改进。与DINOv2-B/14配对时，增大文本编码器容量使Recall@1在AmsterTime上从18.1提升至20.6%，MSLS-val上从49.2%至50.3%，Pitts30k上从54.7至57.8%。

文本编码器任务对齐。 在地点描述上渐进微调BGE-L（BGE-L_ft）在每个视觉骨干和基准上均带来进一步增益。与DINOv2-B/14配对时，任务对齐使Recall@1在AmsterTime上达21.0%，MSLS-val上53.8%，Pitts30k上61.2%，分别比微调后的CLIP ViT-B/16下限基线高出6.7、10.3和9.5个百分点。在各数据集上，编码器容量与领域微调在文本侧提供互补且相当的增益，其中微调在MSLS-val（+3.5个百分点）和Pitts30k（+3.4个百分点）上带来最大提升。

综合来看，这些结果表明三项设计选择呈加性贡献：更高的视觉token密度与自监督预训练（DINOv2-B/14）提供主要的性能提升，而增大文本编码器容量并使其对齐地点描述则带来稳定、互补的改进。我们完整的阶段1配置（DINOv2-B/14 + BGE-L_ft）在全部三个基准上取得最高准确性。

跨模态对齐差距。 为考察跨模态对齐本身是否仍是限制因素，我们通过评估单模态文本到文本检索来分离文本表示，其中查询与数据库地点均仅由文本嵌入表示。使用相同的微调文本编码器，检索在Pitts30k、MSLS-val和AmsterTime上分别取得67.6%、58.1%和22.5%的Recall@1。CrossPlace密切匹配并在MSLS-val和AmsterTime上超越这些单模态参照（Pitts30k上66.4%对67.6%，MSLS-val上60.1%对58.1%，AmsterTime上24.0%对22.5%）。我们观察到CrossPlace的文本到图像检索密切匹配单模态文本到文本检索，这表明一旦强视觉表示与细粒度重排序相结合，跨模态对齐便成为次要瓶颈。

5.3 与替代重排序范式的比较

为评估token到块交叉注意力设计的必要性，我们将其与应用于完全相同阶段1候选列表（表2）的替代重排序策略进行比较。我们与以下方法进行基准对比：采用 [20] 中Q-Former模块的学习型瓶颈查询、遵循FILIP [43] 的token级对比匹配（在文本token与图像块之间应用ColBERT风格 [15] 的MaxSim后期交互），以及大型零样本视觉-语言模型（包括BLIP-2 ITM和Qwen2.5-VL-72B [4]）。

在所有基准上，我们的token到块交叉注意力模块取得最高重排序性能，Pitts30k上R@1达65.1%，MSLS-val上57.0%，AmsterTime上23.0%。Q-Former基线在Pitts30k上达60.2%，MSLS-val上55.3%，尽管参数预算相当；而采用token级对比监督的FILIP风格基线 [43] 在Pitts30k上降至37.9%，低于我们的阶段1 CrossPlace检索器。

零样本视觉-语言模型在候选列表上的表现进一步退化。BLIP-2 ITM [20] 在Pitts30k上给出28.6% R@1，而Qwen2.5-VL-72B [4] 在AmsterTime上达11.5%，MSLS-val上37.3%，Pitts30k上48.8%，在所有三个基准上低于LaVPR。与补充材料G节中我们的编码器级发现一致（LoRA适配的BGE-Small优于冻结的BGE-Large），我们约0.6M参数、在分布内困难负样本上训练的重排序器优于未对齐的72B模型。总体而言，对于跨模态重排序，在困难负样本上对齐地点识别任务比模型规模更重要。

6 结论

总结。 我们介绍了CrossPlace，一个旨在捕捉图像区域与文本之间细粒度对应关系的两阶段跨模态地点识别框架。系统分析证实视觉token密度是检索准确性的主要驱动因素，并由文本编码器规模和任务微调加以补充。在现有及新引入的、呈现多样化环境挑战的基准上，CrossPlace相比先前跨模态基线实现了两位数的Recall@1增益，缩小了与单模态文本检索的差距，并逼近单模态VPR。

局限性与未来工作。 相对单模态VPR仍存在性能差距，或可通过查询条件化的视觉编码来缩小。此外，重排序的权衡可通过压缩与量化方法缓解。

A 流程概述与实现细节

图5展示了我们的两阶段流程。阶段1中，微调后的BGE-Large编码文本查询，DINOv2-B编码数据库图像，两个编码器均以LoRA适配。学习到的投影头将其全局特征映射到共享的768维嵌入空间，余弦相似度最高的前K张图像构成候选列表。阶段2中，轻量级交叉注意力重排序器对候选列表中的每张图像重新评分。它直接作用于阶段1编码器的token级特征并绕过投影头。每个文本token关注候选图像的块token，所得局部分数与阶段1全局分数融合。由于仅处理K个候选，块token可缓存或即时重算，阶段2的成本不依赖于图库规模。

图5：两阶段流程概览。阶段1通过LoRA微调的BGE与DINOv2全局嵌入之间的余弦相似度检索前K个候选列表。阶段2以轻量级交叉注意力模块重排序候选列表，该模块作用于来自冻结阶段1编码器的原始文本token与图像块token，绕过投影头，并将局部分数与全局分数融合。

文本查询。 每个查询是对某一地点的文本描述。对于AmsterTime、MSLS和Pittsburgh30k（Pitts30k），我们使用LaVPR [13] 发布的描述，使结果可直接与其比较。对于SVOX和SF-XL，我们自行生成了描述（D节）。

阶段1：双编码器。 文本编码器BGE-Large是具有3.35亿参数的BERT-large模型。图像编码器DINOv2-B是具有8600万参数的ViT-B/14。我们保持其基础权重冻结，并向两者的注意力和MLP层添加LoRA适配器。数据库图像离线编码一次，因此查询时只需编码文本查询并检索前K张图像。

阶段2：交叉注意力重排序器。 重排序器作用于阶段1编码器的最后一层token：每个词片对应一个BGE token，以及DINOv2块token。由于跳过投影头，它可利用全局嵌入丢失的细节。其交互块（主论文公式(3)–(5)）包含三步。首先，每个文本token关注图像块，使诸如“招牌”或“拱门”之类的词可聚焦于图像中呈现它的部分。其次，文本token间的自注意力在整个描述中共享这一视觉证据。第三，前馈网络（隐藏维度4d = 512，GELU）精炼每个token。重排序器训练使用权重衰减 10^{−3}、200步预热和dropout 0.1。对每个训练查询，候选列表包含其所属地点的图像以及在GSV-Cities上运行阶段1模型找到的其他地点中排名最高的图像。

B 基线与参考系统

以下描述结果表中出现的每个系统：检索基线BLIP和LaVPR、我们自己的参考点与消融变体，以及主论文表2中的重排序基线。

BLIP（零样本）。 BLIP [19] 是在大规模网络数据上以图像-文本对比、图像-文本匹配和描述生成目标预训练的视觉-语言模型。我们不做任何微调直接使用它，以衡量通用视觉-语言模型在无任务适配情况下的地点检索表现。其在除Pitts30k（8.1%）外的每个基准上R@1均低于2%，因此显然需要地点特定训练。

LaVPR。 LaVPR [13] 是文本到图像地点检索最接近的先前方法。我们所比较的配置以LoRA适配BLIP的文本和图像编码器，并以多相似性损失训练。由于我们使用相同的适配与训练目标，CrossPlace在结构上仅有两处不同：以BGE-Large和DINOv2-B/14替换BLIP的编码器，以及增加通过token级交叉注意力重排序候选列表的第二阶段。关键在于，我们的贡献不在于引入复杂架构，而在于诊断真正决定CMPR准确性的因素，表明细粒度视觉token粒度、密集文本容量和局部token-块匹配解决了主要瓶颈，并缩小了与单模态视觉地点识别的性能差距。

文本到文本参考。 我们将文本到文本作为参考系统而非直接的跨模态基线。该设置中查询与数据库均为文本，由我们比较中表现最佳的纯文本编码器（全线性LoRA的BGE-Large，r = 64，以多相似性损失训练，记为LoRA-MS）编码，并以余弦相似度匹配。由于不涉及跨模态对齐，它展示了文本编码器单独区分地点的能力。它与跨模态系统之间的差距即G节讨论的对齐差距。

重排序基线。 主论文表2将我们的重排序器与四种替代方案比较，所有方案均应用于相同的阶段1候选列表，并作为独立评分器评估（α = 0）。

BLIP-2 ITM [20]：我们使用BLIP-2的预训练图像-文本匹配头，不做任何微调，按其匹配分数对前K个候选排序。

Qwen2.5-VL [4]：我们使用预训练的Qwen2.5-VL-72B模型，量化为8位，不做任何微调。出于计算原因，它仅重排序前10个候选。

基于FILIP的 [43]：我们训练FILIP风格的token级后期交互模型，在文本token与图像块token之间使用最大相似度对比损失。原始FILIP模型以非常大的批次（65,536）在约3亿个多领域图像-文本对上训练。我们的训练集GSV-Cities仅包含约50万个单一城市领域的图像-文本对，且我们以小得多的批次训练。我们将该基线的低准确性归因于这些差异，因为token级对比学习依赖大量批内负样本和大规模数据。

Q-Former：一组遵循BLIP-2 [20] Q-Former设计的学习型瓶颈查询，在冻结的CrossPlace阶段1编码器之上训练。查询关注图像块token和文本token，其池化输出映射为标量分数。它以与我们重排序器相同的列表式损失和相同的困难负样本候选列表训练。
