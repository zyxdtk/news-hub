更强的科学推理

药物化学

GPT‑Rosalind 在药物化学（专注于将分子转化为有用药物的字段）领域实现了业界领先的性能。我们设计了 MedChemBench 以反映真实的药物化学工作流，评估多模态化学结构理解；构效关系 (SAR)；预测药物效力、毒性和吸收、分布、代谢、排泄 (ADME)；多参数先导化合物优化决策；以及逆合成。GPT‑Rosalind 在 MedChemBench 上以 27.5% 对 25.1% 的成绩优于 GPT‑5.5，同时使用的 token 减少了 7.2%。
GPT‑Rosalind 在药物化学中显示出更好的多模态合成和机制推理。

基因组学与定量生物学

在 GeneBench（我们对基因组学和定量生物学中长期端到端分析的代理评估）上，GPT‑Rosalind 使用的 token 比 GPT‑5.5 少 31%，同时准确率达到 21.6%，而 GPT‑5.5 为 20.4%。GeneBench 评估了在长期定量任务上的代理性能：基于真实的科学数据，代理能否规划有效的分析、QC、建模和校正以得出决策相关的答案？包含的问题涵盖多个领域，包括功能基因组学、空间转录组学、蛋白质组学、表观基因组学和应用遗传学。
GPT‑Rosalind 使用的 token 比 GPT‑5.5 少 31%，同时提高了准确率。

协助真实世界的实验室工作

我们引入了一项新的评估来测试 GPT‑Rosalind 帮助科学家在现实世界中进行实验室工作的能力。LabWorkBench 测试了模型在科学家使用的真实湿实验室协议中将扰动与实验结果联系起来的能力，目的从故障排除到优化。LabWorkBench 使用的数据是专有的，因此未受污染。GPT‑Rosalind 得分为 63.2%，而 GPT‑5.5 为 55.8%，同时使用的 token 减少了 5.3%。
在真实的湿实验室协议协助方面，GPT‑Rosalind 相比 GPT‑5.5 有显著提升，同时提高了 token 效率。

从推理到执行工作流

我们构建了 生命科学研究⁠(opens in a new window) 和 生命科学 NGS 分析⁠(opens in a new window) 插件，以通过可重复科学工作流的实际执行层来扩展 GPT‑Rosalind 增强的智能。这些插件共同将来源证据检索、生物学解释和生物信息学执行引入同一工作区，帮助研究人员将外部证据与内部组学分析联系起来，同时保留工件和来源。所有用户现在都可以通过 Codex 访问这两个插件。符合条件的 GPT‑Rosalind 企业用户还可以使用 GPT‑Rosalind 为这些插件提供支持。
为了更好地利用 Codex 作为科学家的动态工作台，我们为生物学原生文件类型添加了交互式查看器。最初的序列、比对和结构查看器旨在让科学家在 GPT‑Rosalind 跨工作流推理时保持接近证据，并使用上下文中的活动查看器直接回答后续问题。
上面的演示展示了由 GPT‑Rosalind 编排的这些功能的实际应用。我们跟随一位研究液体肿瘤活检的科学家，以识别可能为治疗提供信息的突变和其他分子变化。生命科学 NGS 分析插件将已处理的 ctDNA 记录审查转化为交互式笔记本，显示反复出现的改变、低频调用和样本轨迹，从而将调查重点放在 KRAS G12C 上。从那里，生命科学研究插件添加了来源靶点、抑制剂和耐药性背景，而原生序列、比对和结构查看器允许科学家直接检查突变残基 12、其在 RAS 家族中的保守性以及抑制剂结合口袋。该工作流最后将这些证据转化为具体的后续选项，每个步骤和工件都可供专家审查。
