用户提供，并将在未来几周内推广到其他国家以及 Free 和 Go 用户。 ## 记忆的演变 记忆功能于 2024 年 4 月首次推出（也称为保存的记忆）。该功能让你可以要求 ChatGPT 记住信息并将其带入未来的聊天中。 ![Image 4: Saved memories modal showing a searchable list of personal details, including 保存的记忆仅在对话期间写入，并依赖强烈的提示来决定何时触发记忆，例如“记住我七月份要去新加坡旅行”的指令。在实践中，与这个系统交互就像在和一个人说话，他记了几个笔记，但仍然忘记了所有没有写下来的东西。保存的记忆也往往随着时间的推移而过时，最终变得不正确或无关紧要。 在 2025 年 4 月，我们更新了 ChatGPT 的记忆，赋予模型引用保存的记忆列表之外的聊天上下文的能力；这是通过引入第一版**梦境**来实现的——这是一种让 ChatGPT 通过引用聊天历史在后台*自动*整理记忆的方法。 ![Image 5: Memory settings page in ChatGPT showing options to reference chat history, use saved memories, manage saved memories, and enable Pulse memory suggestions.](https://images.ctfassets.net/kftzwdyauwt9/nSkMroPG2SPQCrcIUh2l4/bf05aa9cfb0287cfa7f187f9d84674dd/Memory_settings__1_.png?w=3840&q=90&fm=webp) 与保存的记忆相比，梦境利用了一个后台过程，允许 ChatGPT 从许多对话中学习并合成 ChatGPT 的记忆状态，以便始终为你的对话提供最新、最相关的上下文。梦境还使记忆更容易包含对话中自然发生的上下文，而无需依赖明确的请求来记住某事。 在过去的一年里，梦境*补充*了保存的记忆，在 ChatGPT 个性化响应的能力上创造了阶跃式改善，并抵消了保存记忆的过时问题。然而，从历史上看，它作为独立的记忆系统从来都不够用。 今天，我们正在推出一个基于梦境的、功能显著更强且计算效率更高的记忆架构。 通过梦境合成的记忆可以通过在记忆摘要页面上显示的摘要进行查看。从记忆摘要中，你可以快速了解 ChatGPT 对你了解的要点，添加或更新关于你自己的信息，并提供关于 ChatGPT ChatGPT 中“好记忆”是什么样的时，会想到以下几点： 1. **延续有用的上下文：**你告诉 ChatGPT 一次，它就会在随后的聊天中记住该信息。 2. **遵循偏好和限制：**如果你描述了一个偏好（例如，你是素食主义者），那么 ChatGPT 今后应该采取与该偏好一致的行动。 3. **随时间保持时效性：**记忆应考虑到时间的流逝。想象一下“用户正在为下周六计划生日派对”；最终，周日到来了。 我们可以评估 ChatGPT Plus 和 Pro 的记忆在上述三个记忆目标方面是如何随时间改进的。我们对以下每一项进行此操作： 1. **2024**：保存的记忆 2. **2025**：保存的记忆 + 梦境 V0 3. **2026**：梦境 V3 ## 延续上下文 当你与
