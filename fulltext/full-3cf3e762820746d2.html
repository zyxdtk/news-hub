安提克与卢旺达政府签署AI医疗教育合作备忘录

📅 Feb 17, 20 📄 Anthropic 🔗 原文链接

URL 来源：https://www.anthropic.com/news/anthropic-rwanda-mou Markdown 内容：

卢旺达政府与 Anthropic 已签署为期三年的合作备忘录，以正式确立并拓展双方合作关系，推动人工智能（AI）在卢旺达教育、医疗及公共部门系统的应用。该协议是在我们 [2025 年 11 月宣布的 ALX 教育合作基础上](http://anthropic.com/news/rwandan-government-partnership-ai-education)进一步深化，并标志着 Anthropic 首次通过政府间合作备忘录（MOU）在非洲大陆确立跨领域战略合作。

我们的合作涵盖以下三个领域： * **加速实现卢旺达的医疗目标**：Anthropic 将支持卢旺达卫生部推进其雄心勃勃的国家医疗目标，包括消除宫颈癌的计划，以及持续降低疟疾和孕产妇死亡率的相关努力。 * **赋能卢旺达公共部门开发者**：政府部门各机构的开发团队将可使用 Claude 和 Claude Code。结合实操培训、能力建设及 API 额度支持，此举将助力卢旺达更广泛地将人工智能融入其他公共部门领域。 * **深化卢旺达及整个地区的教育合作**：该备忘录正式确立了我们 [2025 年秋季教育合作协议](https://www.anthropic.com/news/rwandan-government-partnership-ai-education)，内容包括向卢旺达全国教育工作者提供 2,000 份 Claude Pro 许可证、面向公务员的 AI 素养培训，以及部署……

在八个非洲国家部署由 Claude 驱动的 AI 学习伴侣 推动人工智能在医疗、教育及公共部门的应用 ------------------------------------------------------------ 卢旺达信息技术、通信与创新部长 Paula Ingabire 表示：“此次与 Anthropic 的合作是卢旺达人工智能发展进程中的重要里程碑。我们的目标是持续设计并部署可在国家层面应用的人工智能解决方案，以加强教育、改善医疗成果、提升治理效能，并紧密结合卢旺达自身实际。”

Anthropic 的“有益部署”（Beneficial Deployments）团队已与卢旺达信息技术、通信与创新部及合作伙伴紧密协作，设计出契合卢旺达需求与优先事项的项目。

Anthropic “有益部署”负责人 Elizabeth Kelly 表示：“技术的价值取决于其覆盖范围。我们正投资于培训、技术支持与能力建设，以扩大服务覆盖，确保教师、医护人员及公职人员在整个卢旺达境内都能安全、自主地使用人工智能。”

致力于以人工智能服务公共利益 -------------------------------------- 本次公告是在既有教育合作基础上发布的，相关合作已帮助学生与教育工作者与人工智能互动，并标志着向医疗领域迈出的重大扩展。
