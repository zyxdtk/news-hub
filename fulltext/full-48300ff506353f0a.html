摘要
多模态大语言模型（MLLMs）展现出强大的视觉理解能力，但引发这些行为的内部特征仍难以识别、审计或控制。虽然适用于事后检查，但使用稀疏自编码器（SAEs）将隐藏状态分解为可解释特征方向的方法，既不能直接分离出哪些特征是由多模态训练改变的，也不能直接用于定向控制。我们引入了 MMDiff，这是一个多模态模型差异分析框架，它训练多模态 SAEs 并将其转化为特征级接口，用于发现和控制多模态行为。MMDiff 支持三种用途： 特征分离，通过将基础语言模型 SAE 与其多模态适配版本进行差异比对，以识别被多模态训练改变的特征； 任务特定特征检测，通过逐 token 对比激活分析来分离因果特征； 特征级控制，通过因果移除或引导已发现的特征方向。我们为三个 MLLM 家族（LLaVA-MORE、PaliGemma 2 和 InternVL3.5）训练了多模态 SAEs，并在视觉空间理解、多模态安全性和 OCR 上进行了评估。MMDiff 发现了稀疏且具有因果特异性的特征，移除这些特征会使空间任务的目标行为平均下降 12%，OCR 下降 17%，并使多模态安全攻击的成功率降低 24%，且对 VQA 性能没有影响。与标准的单层引导基线相比，引导这些特征使空间和 OCR 准确率平均提高了 +3.6% 和 +1.8%。这些结果表明，多模态 SAEs 不仅可以作为可解释性工具，还可以作为审计、引导和控制 MLLM 行为的机制，以实现更安全、更强大的生成。

1 引言
多模态大语言模型（MLLMs）将语言模型扩展到文本之外，在视觉问答、图像描述、OCR、空间推理和图像条件对话中实现了强大的性能 [42, 1, 51, 52, 88, 14, 78]。然而，它们的内部机制仍然难以解释：MLLMs 能够阅读文本、定位物体、推理空间关系并识别细粒度的视觉细节，但目前尚不清楚这些行为背后的内部特征是什么。这限制了我们在不重新训练的情况下审计失败、抑制不良行为或引导能力的能力。

图 1：MMDiff 将多模态 SAE 特征转化为审计和控制的接口。分离由多模态训练改变的特征会产生与特定行为有因果关系的方向：引导它们可以提高空间和 OCR 准确率并抑制不安全的生成，对一般视觉问答没有可测量的影响。

稀疏自编码器（SAEs）通过将隐藏状态分解为稀疏的学习方向，为模型内部提供了一个特征级词汇表 [8, 16, 21, 79]。最近的工作将 SAEs 扩展到了视觉-语言模型和多模态组件 [38, 67, 35, 47]，但直接在 MLLM 激活上训练的 SAEs 会将语言骨干网络继承的特征与多模态训练改变的特征混合在一起。模型差异分析通过比较不同训练阶段的 SAEs 并跟踪对齐特征的变化——它们是保持稳定、旋转还是被重新利用——来解决这种模糊性 [9]。对于 MLLMs，将基础语言模型 SAE 与其多模态适配版本进行差异比对，可以揭示哪些特征是由多模态训练改变的，而不是简单继承的。

我们引入了 MMDiff，一个多模态模型差异分析框架，它训练多模态 SAEs 并将其转化为特征级接口，用于发现和控制 MLLM 行为。MMDiff 通过一个统一的流水线来解决这一挑战，该流水线分离视觉改变的特征，识别任务特定的子集，然后将它们用于特征级因果移除和引导。具体而言，MMDiff 将预训练的基础语言模型 SAE 适配到冻结的 MLLM，分离解码器方向发生旋转且激活变得对视觉有响应的特征，并使用逐 token 对比激活分析来提取任务特定的子集，同时过滤词汇提示伪影。对于引导，我们将检测到的顶层特征层上的多层骨干对比激活引导与在特征关联层注入发现特征的解码器方向相结合；我们称之为 MMDiff-CAA。

我们在三个 MLLM 家族（LLaVA-MORE [14]、PaliGemma 2 [78] 和 InternVL3.5-2B [86]）上训练和评估了 MMDiff，涵盖了不同的语言骨干、视觉编码器和 SAE 目标。在视觉空间理解、多模态安全性和 OCR 方面，MMDiff 发现了与目标行为相关的稀疏特征集。特征级因果移除选择性地使空间任务的目标行为下降 12%，OCR 下降 17%，并使多模态安全攻击的成功率平均降低 24%，且对 VQA 性能没有影响。此外，与单层引导基线相比，MMDiff-CAA 使空间和 OCR 准确率平均提高了 +3.6% 和 +1.8%。这些结果表明，多模态 SAEs 可以作为审计、引导和控制 MLLM 行为的机制。

我们的贡献是： 多模态模型差异分析。 我们训练了从基础语言模型词典初始化的多模态 SAEs，并识别了在多模态适配后重塑且对视觉有响应的特征。 任务特定特征发现。 我们引入了用于发现任务相关特征的逐 token 对比激活流水线，并在视觉空间理解、多模态安全性和 OCR 上进行了演示。 特征级控制。 我们表明 MMDiff 发现的特征提供了有针对性的干预手段：特征级因果移除抑制了不安全响应等目标行为，而 MMDiff-CAA 引导提高了空间推理和 OCR 能力。第 6 节报告了用于定位任务特定注意力头的归因修补和用于标记特征的自动解释。

2 预备知识
稀疏自编码器（SAEs）
SAEs 学习一个特征词典，将隐藏状态近似为学习方向的稀疏线性组合，从而缓解超叠加现象 [8, 16]。形式上，SAE 将 $x \in \mathbb{R}^{D}$ 映射为稀疏激活 $h(x) = \mathrm{ReLU}(W_{\mathrm{enc}}x+b_{\mathrm{enc}}) \in \mathbb{R}^{F}$，并重构 $\hat{x} = W_{\mathrm{dec}}h(x) + b_{\mathrm{dec}}$，在稀疏性约束下进行训练。每个解码器列 $v_{f} = (W_{\mathrm{dec}}){:,f}$ 定义了残差流中的一个特征方向，$h{f}(x)$ 表示其激活强度。我们微调了与每个 VLM 骨干匹配的预训练 SAE 套件：用于 LLaVA-MORE 和 InternVL3.5-2B 的 TopK SAEs [21, 28, 71]，以及用于 PaliGemma 2 的 JumpReLU SAEs [73, 46]。在 MMDiff 中，解码器方向是跨训练阶段比较以及下游特征级因果移除和引导的基本单元。完整细节见附录 A.2。

MLLMs 的模型差异分析
模型差异分析比较相关的检查点，以识别内部表示在训练中如何变化。早期的工作通常在表示层面比较模型，而稀疏特征级的模型差异分析直接跟踪对齐的特征 [64, 41, 5, 39, 6, 9, 49]。给定对齐的 SAE 解码器 $W_{\mathrm{dec}}^{(0)}, W_{\mathrm{dec}}^{(1)} \in \mathbb{R}^{D \times F}$，特征 $f$ 具有方向 $v_{f}^{(0)} = (W_{\mathrm{dec}}^{(0)}){:,f}$ 和 $v{f}^{(1)} = (W_{\mathrm{dec}}^{(1)}){:,f}$；其变化可以通过余弦相似度 $s{f} = \frac{\langle v_{f}^{(0)}, v_{f}^{(1)} \rangle}{|v_{f}^{(0)}| |v_{f}^{(1)}|}$ 和激活偏移 $\Delta a_{f} = \mathbb{E}[h_{f}^{(1)}(x)] - \mathbb{E}[h_{f}^{(0)}(x)]$ 来总结。在 MMDiff 中，我们将基础语言模型 SAE 与其多模态适配版本进行差异比对，以分离由多模态训练改变的特征，然后再进行下游任务特定的发现和控制。

3 MMDiff：多模态模型差异分析流水线
概述。 我们使用稀疏自编码器（SAEs）作为特征级视角，以跟踪当预训练语言骨干 $\mathcal{M}{\mathrm{base}}$ 被微调以接受视觉输入 $\mathcal{M}{\mathrm{vlm}}$ 时内部方向的转变，并将生成的特征作为下游控制的目标。基于阶段性差异分析（第 2 节），我们的流水线分为三个阶段。(1) 我们在 $\mathcal{M}{\mathrm{vlm}}$ 的多模态激活上微调 SAEs，以获得与视觉-语言空间对齐的特征词典（第 3.1 节）；(2) 我们分离出偏好视觉 token 并在 $\mathcal{M}{\mathrm{base}}$ 和 $\mathcal{M}_{\mathrm{vlm}}$ 之间经历显著几何旋转的特征子集，表明它们已被多模态训练改变（第 3.2 节）；(3) 在此适配集中，我们在目标分布和基线分布之间应用对比 token 激活，随后进行词汇不变性选择性过滤，以获得任务特定的特征集（第 3.3 节）。生成的集合支持因果移除（第 5.2 节）、层定向 MMDiff CAA 引导（第 5.1、5.3 节）、自动解释（附录 6.3）和归因修补（附录 6.2）。

3.1 训练多模态 SAEs
我们首先将在基础语言骨干上训练的稀疏自编码器适配到相应 MLLM 的隐藏状态。每个 SAE 附加到一个 Transformer 块的残差流输出，并在来自 50k 个 VQAv2 图像-问题对的缓存激活上进行训练 [24]。由于输入序列包含投影的视觉 token 和随后的文本 token，我们可以在训练期间掩码 token 跨度以分离特定模态的贡献。

我们从与每个骨干匹配的 SAE 套件初始化：用于 LLaVA-MORE（LLaMA-3.1-8B）的 LLaMA-Scope Top-K SAEs [28]，用于 PaliGemma 2（Gemma-2-2B）的 Gemma-Scope JumpReLU SAEs [46]，以及用于 InternVL3.5-2B（Qwen3-1.7B）的 Qwen-Scope Top-K SAEs [71]。这种热启动保留了基础语言特征词典，同时允许特征适配多模态激活。我们训练了三个掩码变体：全序列、仅图像和仅文本；作为对照，我们还从随机初始化训练了全序列 SAEs。仅文本训练是与模型差异分析最相关的机制：当文本 token 关注视觉上下文时，多模态能力在语言骨干中显现，因此文本 token 激活保留了 LM 基础同时反映了多模态变化，而重构视觉 token 则直接鼓励向投影器空间激活进行更大的旋转 [83]。

我们使用保留分割上的未解释方差分数（FVU）评估重构，并报告稀疏度。仅文本 SAEs 实现了最低的 FVU，并与基础 LM 词典保持最对齐，而仅图像和全序列变体由于视觉 token 输出与 LM 残差基础之间的投影器引起的分布差距，显示出更大的早期层旋转 [83]。因此，我们使用仅文本 SAEs 进行后续的模型差异分析。训练细节见附录 C。

3.2 识别适配特征
我们旨在分离满足以下条件的 SAE 特征： 在多模态适配后经历几何重定向； 对视觉输入表现出明确的模态偏好。这些特征对于模型差异分析和后续因果分析最具信息量。为了识别它们，我们依赖两个信号。

几何重定向（解码器余弦）。 为了测试 $f$ 是否被多模态微调重新利用，我们比较其适配前后的解码器方向。设 $W^{\text{LLM}}{\text{dec},f}$ 为基础 LM SAE 解码器向量，$W^{\text{MLLM}}{\text{dec},f}$ 为 MLLM 适配 SAE 中的对应向量。我们计算 $c_{f} = \cos(W^{\text{LLM}}{\text{dec},f}, W^{\text{MLLM}}{\text{dec},f})$。高 $c_{f}$ 意味着 $f$ 的语义方向与原始语言词典保持对齐；低 $c_{f}$ 表示显著的旋转，与 $f$ 被重新分配以编码新的多模态结构一致。我们使用解码器向量而不是编码器参数，因为解码器方向更直接地索引特征的语义。在两个词典中比较相同索引处的 $f$ 假设热启动保留了特征身份，我们通过在整个词典上进行显式匹配来验证这一点（附录 E.2）。

模态偏好（视觉能量）。 鉴于 SAE 激活的稀疏性，我们通过特征 $f$ 在视觉输入下的均方激活来评分，$E_{v}(f) = \mathbb{E}{\text{vision}}[h{f}^{2}]$，在 MLLM 的 VQA 运行中测量。由于近一半的特征 $E_{v} = 0$，简单的截断 $E_{v} > \epsilon$ 足以丢弃不活跃的方向并保留携带视觉信号的方向。仅 $E_{v}$ 无法区分图像驱动和文本驱动的激活。固定文本的图像反事实减少了每个域的平均激活（附录 D.7），证实所选特征是图像基础的。

选择过程。 我们将适配特征定义为满足两个标准的特征：$E_{v} > \epsilon$，确保视觉响应性；余弦相似度 $c_{f}$ 在底部 $p_{\cos} = 25\%$，表示强烈的解码器旋转。这分别为 MMDiff-Llama、MMDiff-Gemma 和 MMDiff-Qwen 产生了约 5%、约 20% 和约 13% 的所有特征作为适配集（图 9，图 10）。每层适配特征计数和平均余弦相似度见附录 D（图 11(a)，图 11(b)）。

3.3 发现任务特定特征
在适配集 $\mathcal{A}$ 中，我们在目标分布 $\mathcal{D}{\mathrm{tgt}}$ 和基线分布 $\mathcal{D}{\mathrm{base}}$ 之间应用对比 token 激活，随后进行词汇不变性选择性过滤，以获得任务特定的特征集 $\mathcal{T}$。对比提取在目标偏移下更频繁激活的特征；过滤器只保留在不包含目标特定词汇的中性提示下继续激活的特征，从而排除词汇伪影。我们按 token 而不是按样本计算激活，以保持选择性。

分布偏移。 设 $h_{f}(x_{t}) \ge 0$ 表示特征 $f$ 在输入 $x$ 的 token $t$ 上的激活。对于具有 $n(\mathcal{D})$ 个总 token 的数据集 $\mathcal{D}$，$f$ 的激活频率为 $p_{f}(\mathcal{D}) = \frac{1}{n(\mathcal{D})} \sum_{x \in \mathcal{D}} \sum_{t} \mathbf{1}{h_{f}(x_{t}) > 0}$。我们为基线分割 $\mathcal{D}{\text{base}}$（一般 VQAv2）和表现出感兴趣属性的目标分割 $\mathcal{D}{\text{tgt}}$（空间、OCR 或不安全的多模态提示；见第 5 节）计算此值，并通过其频率差距 $\Delta p_{f} = p_{f}(\mathcal{D}{\text{tgt}}) - p{f}(\mathcal{D}{\text{base}})$ 和优势比 $\mathrm{OR}{f}$ 对每个特征进行评分，由激活/未激活 $\times$ 基线/目标的列联表上的 Fisher 精确检验筛选。我们保留 $\mathrm{OR}{f} \ge 3$ 且 $\Delta p{f} \ge 0.05$ 的特征作为任务特定候选。

过滤词汇伪影。 为了排除提示词汇效应，我们将每个最高激活样本中的原始问题替换为一小部分中性提示（例如，对于空间任务使用“描述物品是如何排列的”；完整提示见附录 D.6）。在这些通用指令下继续激活的特征被保留为真正的图像基础特征，而未能激活的特征则被丢弃。这确保了存活的单元反映目标行为而不是记忆的词汇线索；在空间扫描中，约 60% 的候选通过了词汇过滤器。

与适配集的交集。 我们只保留也属于 $\mathcal{A}$ 的候选（第 3.2 节），因此存活的特征同时在多模态微调下重定向，响应目标偏移，并保持图像基础。图 9 以蓝色突出显示了这个集合，用于下游分析的子集以红十字表示。对于空间目标，这为 MMDiff-Gemma 产生了约 1,400 个特征（总共约 416K 个），为 MMDiff-Llama 产生了 711 个特征（总共约 1M 个）；对于 MMDiff-Gemma 上的安全相关提示，我们获得了 1,061 个跨 VLSBench 类别的候选不安全特征（第 5.2 节），以及在 OCRBench 上的 1,070 个 OCR 选择性特征（第 5.3 节）。跨模型和目标分布的每阶段计数见附录 D.4。

4 实验设置
我们在三个目标分布 $\mathcal{D}{\mathrm{tgt}}$（空间推理、多模态安全、OCR）上应用 MMDiff，$\mathcal{D}{\mathrm{base}}$ 固定为一般 VQAv2。本节描述了跨应用通用的评估协议；特定领域的结果在第 5 节中报告。

因果移除。 对于具有单位范数解码器方向 $v_{f}$ 的目标特征 $f$，我们通过在推理期间在每个 Transformer 层且仅在文本 token 位置将其正交投影出去来移除模型对该方向的使用，保持图像 token 不变。具体而言，对于每一层 $\ell$ 和文本 token $t$，我们在三个点应用 $y \leftarrow y - (y^{\top} v_{f}) v_{f}$：注意力块输出、MLP 块输出和层残差输出。这种三点、全层干预防止了特征方向通过中间路径重新进入，并隔离了其在语言骨干而非视觉投影器中的贡献。我们报告了三个增量：每个特征评估子集的目标任务准确率、VQAv2 上的一般视觉问答能力（$\Delta$VQA），以及通过在控制数据集上移除相同目标特征计算的领域特定行为控制（$\Delta$Ctrl），如果特征是目标特定的，则该控制数据集不应受到影响：对于空间任务是具有非空间关系（has, wears, holds, made of, part of, contains）的 VSR 样本，对于安全任务是 MSSBench 安全分割，对于 OCR 是 VQA-clean（非 OCR）是/否子集。特征选择的显著性使用带有 Benjamini-Hochberg 校正的 Fisher 精确检验（第 3.3 节）。

MMDiff CAA 引导。 我们采用规范的激活引导形式 $h^{\prime} \leftarrow h + \alpha d$ [74]，其中 $h$ 为残差流隐藏状态，$\alpha$ 为干预强度。原始 CAA 在一个固定的中间层使用单一的平均差异方向。MMDiff CAA 则在 $\mathcal{M}{\mathrm{base}}$ 上结合了两个组件： 从 $\mathcal{M}{\mathrm{vlm}}$ 提取的层 $\ell \in \mathcal{L}{\mathrm{task}}$ 的多层骨干 CAA 方向 $d{\ell} = \mathbb{E}[h_{\mathrm{pos}}^{\ell}] - \mathbb{E}[h_{\mathrm{neg}}^{\ell}]$； 发现特征 $f$ 在其特征关联层 $\ell_{f}$ 的解码器方向 $v_{f}$。在推理时，对于每个文本 token 位置，我们在每个 $\ell \in \mathcal{L}{\mathrm{task}}$ 处添加 $\alpha d{\ell}$，并在 $\ell_{f}$ 处额外注入 $\gamma_{f} v_{f}$，因此 $h^{\prime}{\ell{f}} \leftarrow h_{\ell_{f}} + \alpha d_{\ell_{f}} + \gamma_{f} v_{f}$，其中 $\gamma_{f} \in {1, 3, 10}$。因此，与原始的单层 CAA 不同，MMDiff CAA 在选定层中添加任务级骨干引导，并在特征关联层用特征特定的 SAE 方向对其进行增强。完整的引导过程见算法 2（附录 B.1）。

6.2 任务特定头的归因修补
方法。 归因修补 [60] 是激活修补 [92] 的可扩展替代方案，它通过用反事实替换激活来测量因果效应。激活修补每次干预需要一次前向传递；归因修补使用基于梯度的线性近似，通过两次前向传递和一次反向传递来估计干预，使得探测跨层和头的归因分数变得实用。我们对此进行调整以识别驱动任务特定 SAE 特征的注意力头。对于层 $L$ 的目标特征 $f$，我们将层 $L$ 激活投影到 SAE 解码器向量以定义标量目标；该目标相对于上游残差和注意力输入的梯度，指示每个头对 $f$ 的贡献程度。我们将干净运行（原始图像-文本输入）与损坏运行进行比较，在损坏运行中，层 0 视觉 token 嵌入被替换为在许多 VQA 样本上计算的平均嵌入，从而在保持分布统计的同时抑制视觉内容。两种归因变体是 $(\text{corr} - \text{clean}) \cdot \nabla_{\text{clean}}$（方法 A）和 $(\text{clean} - \text{corr}) \cdot \nabla_{\text{corr}}$（方法 B）；我们报告在最强激活 $f$ 的前 $k$ 个样本上平均的每层和每头分数。详情见附录 G.1。

结果。 在我们检查的空间选择性特征中，逐层归因曲线通常在中间层达到峰值，这与 MMDiff 发现的空间特征的层分布一致（图 17）。在头级别，两种方法都突出显示了一小部分具有显著高分 的头，并且识别出的顶级头在不同方法之间基本一致（图 18）。一些相同的头在相关的空间关系中重复出现：在图 4 的顶行中，头 L13H1 在关于“on top of”的查询中关注语义相关的区域；中间行确认相同样本上排名靠后的头无法有意义地定位，底行确认不相关的查询不会触发虚假激活。驱动头在每个特征所在层附近的聚类为第 5.1 节中用于引导的层定向注入提供了机制上的理由。

7 相关工作
模型差异分析。 模型差异分析研究内部表示如何跨模型或训练阶段变化。早期的工作主要通过函数空间可视化、模型拼接或相似性度量在表示层面比较模型 [64, 19, 41, 5, 39, 6]，而后来的研究也检查了收敛的神经元和类似特征的单元 [45, 63]。SAEs 提供了特征级视角，Kissane 等人 [38] 表明基础 LM SAE 词典很大程度上可以转移到微调模型。阶段性模型差异分析 [9] 在具有对齐特征索引的检查点上重新训练 SAEs，揭示了包括潜伏代理特征在内的动态 [31, 57]。基于交叉编码器的差异分析 [49, 59, 33] 和 diff-SAEs [58, 3] 是替代公式。我们将特征级模型差异分析扩展到 LM $\rightarrow$ MLLM 的过渡，使用特征变化作为下游控制的发现信号。

机制可解释性和 MLLMs 上的 SAEs。 先前的 MLLM 内部工作跨越了基于工具和因果的解释 [77, 7, 68] 以及基于探测和特征的分析 [81, 20, 13, 75, 32, 61, 83, 37, 84, 48, 93, 34]。MLLM 上的 SAE 工作针对视觉编码器或 LM 骨干 [17, 35, 67, 47, 36, 65, 15, 38, 40]。这些研究分析了多模态表示、对齐或引导接口，但据我们所知，没有将基础 LM SAE 与 MLLM 适配的 SAE 结合起来并使用它们的差异作为发现信号。

激活引导和多模态安全。 激活引导沿选定方向修改残差流 [82, 43, 74, 4]；CAA [74] 在固定的中间层使用平均激活差异，任务/函数向量针对特定层 [29, 80, 56]，基于 SAE 的方法沿特征方向引导 [11, 2, 55]。多模态扩展将此类方向注入 MLLMs 和 VLAs [76, 27, 25, 10, 71]。多模态安全基准 [53, 30, 23, 70, 44, 12] 与提示级防护 [87]、潜在空间引导 [85, 90] 和拒绝方向干预 [62, 69] 配对。MMDiff-CAA 的不同之处在于，在特征关联层使用 MMDiff 发现特征的解码器方向进行引导，而不是仅依赖通用的单一中间层方向。

8 局限性
我们在三个骨干（LLaMA-3.1-8B、Gemma-2-2B 和 Qwen3-1.7B）上实例化了 MMDiff；安全性和 OCR 仅在 PaliGemma 2 上进行评估。将完整配方应用于其他 MLLM 家族，包括更大的骨干、混合专家变体以及 Qwen-VL 或 Pixtral 风格的架构，是自然的下一步。MMDiff CAA 假设可以访问指令微调的参考模型，从中可以提取引导方向；在只有基础模型或只有指令微调模型可用的设置中，该配方退化为标准的 SAE 特征引导。最后，少数安全候选在消融时会导致生成崩溃而不是拒绝，目前需要事后过滤器来排除。

9 结论
我们提出了 MMDiff，一个用于 MLLMs 的模型差异分析流水线，它分离多模态适配特征并将其用作因果消融、MMDiff CAA 引导、自动解释和归因修补的目标。在三个 MLLMs（LLaVA-MORE、PaliGemma 2、InternVL3.5-2B）和三个领域（空间推理、多模态安全、OCR）中，相同的配方通过消融支持行为控制，并通过层定向干预改进引导，每个应用仅通过改变目标分布来实例化。跨阶段消融表明，PaliGemma 2 中的中间层空间特征主要是在多模态微调期间获得的，而不是从基础 LM 继承的。更广泛地说，我们的结果将多模态 SAEs 定位为审计、定位和控制 MLLMs 中多模态行为的特征级接口。该流水线自然地扩展到其他 MLLM 家族以及包括具身 AI 安全、视觉数学推理和医学图像基础在内的领域。我们希望 MMDiff 为未来在多模态系统中的机制理解和干预工作提供有用的基础，包括隔离未对齐的特征和引导向更安全的生成。

A.1 多模态大语言模型
我们在本文中始终使用多模态大语言模型（MLLM）来指代扩展了视觉编码器和投影器的预训练语言模型。我们的实验使用的是语言骨干为文本预训练 LM（LLaMA、Gemma）的 MLLMs，并且公开可用的基础 LM SAE 套件；将每个 MLLM 与同一骨干上匹配的基础 LM SAE 词典配对，使得阶段性模型差异分析变得可行。

架构。 MLLM 由三个组件组成：视觉编码器 $f_V$、预训练语言模型 $f_{\mathrm{LM}}$ 和可训练投影器 $P$。视觉编码器通常是视觉 Transformer [72, 91]，提取补丁嵌入 $V = f_V(x) = [v_1, \ldots, v_{N_V}]$，其中 $x$ 是输入图像，$N_V$ 是视觉 token 的数量（取决于 $f_V$ 的图像分辨率和补丁大小）。投影器将 $V$ 映射到 LM token 空间：$\tilde{V} = P(V) = [\tilde{v}1, \ldots, \tilde{v}{N_V}]$，$\tilde{v}i \in \mathbb{R}^d$，其中 $d$ 是 $f{\mathrm{LM}}$ 的隐藏维度。投影的图像 token 与分词后的文本嵌入 $T = [t_1, \ldots, t_{N_T}]$ 连接，形成多模态输入 $X = [\tilde{v}1, \ldots, \tilde{v}{N_V}, t_1, \ldots, t_{N_T}]$。视觉 token 在前；这种排序对我们的分析很重要，因为它让我们可以在 SAE 训练和下游干预期间按模态干净地掩码 token 跨度。

研究的模型。 我们在不同骨干家族的三个 MLLMs 上实例化了 MMDiff。
* LLaVA-MORE [14] 通过将最近的语言模型与不同的视觉骨干集成来扩展 LLaVA 框架 [51, 52]。我们使用结合 CLIP ViT-Large-Patch14–336 编码器 [72] 和 LLaMA-3.1-8B 语言骨干 [26] 的变体。
* PaliGemma 2 [78] 结合了 SigLIP-So400m 视觉编码器 [91] 和 Gemma-2-2B 语言骨干 [22]。
* InternVL3.5-2B [86] 将 InternViT 视觉编码器与 Qwen3-1.7B 语言骨干 [89] 配对。我们针对该骨干与 Qwen-Scope Top-K SAE [71] 进行差异比对（宽度 32,768，$k=50$）。

这三个 MLLM 在几个对于评估 MMDiff 通用性很重要的轴上有所不同：骨干家族（LLaMA vs. Gemma vs. Qwen）、视觉编码器目标（CLIP 对比 vs. SigLIP 成对）、隐藏大小、深度以及每个骨干可用的基础 LM SAE 套件家族（用于 LLaVA-MORE 的 LLaMA-Scope TopK SAEs [28]，用于 PaliGemma 2 的 Gemma-Scope JumpReLU SAEs [46]，以及用于 InternVL3.5-2B 的 Qwen3 骨干的 Qwen-Scope Top-K SAEs [71]）。在模型之间共享的属性，我们将其报告为 MMDiff 的属性；在特定于一个 MLLM 的情况下，我们会明确说明。

A.2 稀疏自编码器
动机。 大型语言模型的内部表示表现出超叠加：编码的特征比神经元维度多，许多特征共享相同的残差流坐标 [18]。因此，单个神经元通常是多语义的，逐个神经元的分析会混淆多种功能角色。稀疏自编码器（SAEs）试图通过学习一个超完备的特征方向词典来消除超叠加，其中每个输入激活由少量活跃特征近似 [8, 16]。词典方向不受约束与神经元对齐，这使得它们能够恢复更细粒度、通常更可解释的计算单元。

原始 SAE。 给定从 Transformer 残差流中提取的激活 $x \in \mathbb{R}^D$，原始 SAE 由编码器和解码器组成，$h(x) = \mathrm{ReLU}(W_{\mathrm{enc}} x + b_{\mathrm{enc}})$，$\hat{x} = W_{\mathrm{dec}} h(x) + b_{\mathrm{dec}}$，其中 $W_{\mathrm{enc}} \in \mathbb{R}^{F \times D}$，$b_{\mathrm{enc}} \in \mathbb{R}^F$，$W_{\mathrm{dec}} \in \mathbb{R}^{D \times F}$，$b_{\mathrm{dec}} \in \mathbb{R}^D$。词典大小 $F$ 通常选择大于输入维度 $D$（超完备）。每个解码器列 $v_f = (W_{\mathrm{dec}}){:,f} \in \mathbb{R}^D$ 定义了特征 $f$ 在残差流空间中的方向，相应的编码器行 $(W{\mathrm{enc}})_{f,:}$ 充当检测器，决定 $f$ 何时存在于输入中。我们将 $h_f(x)$ 称为特征 $f$ 在 $x$ 上的激活强度。

训练最小化重构项加上稀疏性惩罚，$\mathcal{L}(x) = |x - \hat{x}|2^2 + \lambda \sum{f=1}^F |h_f(x)|$，其中 $\lambda$ 权衡重构质量和 $L_1$ 稀疏性。

TopK SAEs。 TopK SAEs [21] 用编码器预激活上的硬 top-$k$ 算子替换 $L_1$ 惩罚：$h(x) = \mathrm{TopK}k(W{\mathrm{enc}} x + b_{\mathrm{enc}})$，保留 $k$ 个最大的预激活并将其余置零。这为每个 token 产生了精确的 $k$ 稀疏性保证：对于每个 $x$，$|h(x)|_0 = k$。由于稀疏性由架构强制执行而不是由可调惩罚强制执行，TopK SAEs 将特征激活率与重构目标解耦。LLaMA-Scope 套件 [28] 发布了用于 LLaMA-3.1-8B 的 TopK SAEs，Qwen-Scope 套件 [71] 发布了用于 Qwen3-1.7B 的 TopK SAEs，两者都处于固定的 $k$ 值；我们在 MMDiff-Llama 和 MMDiff-Qwen 中使用 $k=50$。

JumpReLU SAEs。 JumpReLU SAEs [73] 使用学习到的每特征阈值 $\theta_f$，并且仅在其预激活 $z_f(x) = (W_{\mathrm{enc}}){f,:} x + (b{\mathrm{enc}})_f$ 超过 $\theta_f$ 时激活特征 $f$：$h_f(x) = z_f(x)$ 如果 $z_f(x) > \theta_f$，否则为 $0$。阈值 $\theta_f$ 使用直通估计器与编码器/解码器权重联合学习，目标平均稀疏性为 $\ell_0$（每个 token 的预期活跃特征数）。与 TopK 不同，JumpReLU 不强制固定的每 token 稀疏性；相反，稀疏性围绕目标波动。对于 MMDiff-Gemma，我们使用目标为 $\ell_0 = 50$ 的 Gemma-Scope JumpReLU SAE [46]。

A.3 MLLMs 的阶段性模型差异分析
设置。 阶段性模型差异分析 [9] 通过在相同架构的连续检查点的激活上重新训练词典，同时保持跨阶段的特征索引对齐，将基于 SAE 的可解释性扩展到训练阶段。对齐的索引意味着阶段 A 的 SAE 中的特征 $f$ 和阶段 B 的 SAE 中的特征 $f$ 旨在指代相同的概念单元，因此可以通过其解码器方向之间的余弦相似度 $\cos(v_f^{(A)}, v_f^{(B)})$ 或其在固定数据集上的激活模式变化来跟踪特征的演变。这种每特征对齐允许对每个方向 $f$ 询问它是被保留（高余弦，相似激活）、旋转（低余弦，相似角色）、被重新利用（低余弦，不同激活），还是新出现的。

与交叉编码器的比较。 阶段性差异分析的替代方案是基于交叉编码器的模型差异分析 [49]，它训练一个类似 SAE 的单一模型，同时重构来自多个检查点的激活，在它们之间共享特征词典。交叉编码器提供单一的全局分解，当目标是在许多模型中定位系统共享或独特的特征时非常方便。阶段性差异分析则为每个阶段训练一个词典并事后对齐特征，这提供了更精细的每特征分辨率：特征可以以在词典级别可见但会被单一共享解码器平均掉的方式旋转或特化。最近的分析 [59] 报告称，交叉编码器对稀疏适配特征（那些很少激活且占激活方差一小部分的特征）的敏感性较低，而这正是我们运行的机制，因为单一空间关系和每个类别的安全触发器在一般 VQA 分布中是罕见的。
