诊断大型视觉语言模型中的密集同类属性误绑定

📅 2026-08-17 📄 arxiv 🔗 原文链接

原标题：Diagnosing Dense Same-Class Attribute Misbinding in Large Vision-Language Models

中文摘要： 本文提出了“密集同类属性误绑定”（DSCAM）这一新失败类别，指大型视觉语言模型将属性错误分配给同类实例的现象。研究构建了InstaBind-Lite基准，通过受控同类组和源实例注释，量化属性转移频率、邻接性与干预效果。实验表明，即使总体准确率高，模型仍存在显著的误绑定率，且大部分转移源自相邻实例，揭示了常规评估无法发现的可靠性盲区。

摘要
大型视觉语言模型能够识别拥挤场景中的物体和属性，却可能将属性分配给错误的同类实例。通用的视觉问答准确率会将此响应标记为错误，而物体幻觉指标可能认为物体和属性均有图像支持；两者都未揭示这种转移。本研究将这一盲区形式化为“密集同类属性误绑定”，并提出了 InstaBind-Lite，一个使其可直接测量的受控基准。其 524 张图像包含 529 组精心挑选的 3–6 个同类实体、1773 个边界框实例、有序的邻居、可区分的类颜色属性，以及四个互补的问题级别，共产生 9580 个确定性评估问题。与现有协议不同，源实例注释将不支持的生成和识别失败与从另一个可见实体复制的属性区分开来。特定绑定指标进一步量化了转移频率、邻接性、序数距离和干预效果。在五个开源和两个商业/API 模型中，开源系统的平均误绑定率为 19.84%，API 系统为 7.55%；这些错误被总体准确率所掩盖。在可识别的转移中，分别有 80.70% 和 81.51% 源自相邻实例。定位和实例优先干预对部分模型有帮助，但并非通用的解决方案。因此，InstaBind-Lite 将以前未分化的错误答案转化为可识别来源的失败类别，并测试了常规基准无法确定的可靠性维度：模型是否不仅知道可见的是“什么”，还知道“哪个实例”拥有该属性。

I 引言
大型视觉语言模型（LVLMs）现在支持图像搜索、视觉辅助、交通分析、零售检查和机器人交互 [31, 20, 1, 19, 5]。然而，它们的错误有不同的原因和风险：模型可能虚构不存在的内容、遗漏物体、误读属性或关系，或者将正确感知的属性附加到错误的实体上。现有的基准通常将这些结果合并为同一个错误答案，因此总体准确率的提高并不能建立可靠的实例-属性对应关系 [2, 21, 37, 9]。将正确的颜色附加到错误的车辆、人、产品或容器上，仍然可能产生不安全的特定实体检索或操作。
LVLM 基准测试之外的公共事件说明了视觉归因失败的利害关系。据报道，宁波的一个交通识别系统将印在公交车广告上的一张脸视为乱穿马路的行人 [34]；美国国家运输安全委员会发现，在 2018 年坦佩致命碰撞事故中，处于研发阶段的自动驾驶系统在发生致命碰撞前反复改变了对行人的分类 [27]。这两个事件都没有确立 DSCAM 或评估 LVLM，但都说明了当身份、位置和属性必须保持与正确实体相连时，为什么视觉支持的内容是不够的。类似的 LVLM 错误可能会将用户引导至错误的人、产品、车辆或废物流。
通用的视觉问答基准将这些情况合并为同一个零准确率事件，而物体幻觉基准主要测试预测内容是否在图像中的某处得到支持 [32, 21, 37, 9]。因此，它们无法确定多媒体系统是否保留了“哪个实体具有哪个属性”。
本研究将这种隐藏的失败定义为“密集同类属性误绑定”（DSCAM）：从另一个可见的同类实例复制而来的错误答案。其假设是结构性的：在同类竞争下，转移应该不成比例地源自邻居，而不是均匀随机的来源。识别该来源将绑定失败与识别错误区分开来，并为定位、解码和训练方法提供了具体的修复目标。
现有资源缺乏测试此假设所需的联合注释。通用 VQA 不保证提供具有可区分属性的可检查同类组；定位评估的是定位能力，而不是哪个邻居提供了错误的属性；而组合性基准不测量自然密集场景中的定向实例到实例的转移。因此，它们的标准分数无法恢复 DSCAM 的普遍性、来源或距离。
InstaBind-Lite 通过有序的同类组、可见的类颜色属性、边界框和邻居链接提供了这种缺失的能力。四个级别探测了位置到属性、属性到位置、关系介导的绑定和命题验证。受控的词汇表和源注释支持确定性解析为相邻或非相邻误绑定、识别失败和集合外幻觉。在七个 LVLM 中，这种设计揭示了即使在总体准确率很高的情况下也存在可测量的 MBR，并表明转移绝大多数遵循邻居结构。
贡献有三个：
• 将“密集同类属性误绑定”形式化为一个独特的失败类别，解决了不支持的幻觉、属性识别失败和转移到错误同类实例的可见属性之间的评估歧义。
• 将 InstaBind-Lite 构建为一个高纯度诊断基准，包含 524 张图像、1773 个实例和 9580 个问题。其受控组和源实例注释使得错误实例绑定变得可测量，这是总体 VQA 和物体存在分数所做不到的。
• 引入了面向绑定的指标和受控干预。MBR 识别可见的错误实例转移，A-MBR 和序数 Distance-MBR 定位其空间来源，而裁剪/上下文定位和实例优先提示测试了减少视觉竞争或显式枚举实例-属性对是否能减轻这种失败。

II-A LVLM 幻觉评估
CHAIR 识别标题中不存在的物体 [32]；POPE 测试物体存在性 [21]；AMBER 提供无评判者的多维分析 [37]；HallusionBench 将语言幻觉与视觉错觉耦合 [9]。检测和解码方法同样针对不支持的生成 [10, 12]。DSCAM 则不同：类和属性都有图像支持，但它们的实例对应关系是错误的。基于存在性的协议要么错过此事件，要么仅将其视为未指定的错误。

II-B 视觉问答和通用多模态基准
VQA、VQA v2 和 Visual7W 评估图像条件下的答案，并减少语言偏差或增加区域定位 [2, 8, 45]；COCO、Visual Genome、GQA 和 VAW 提供类别、边界框、场景图、关系和属性 [22, 16, 13, 28]；MME、SEED-Bench、MM-Vet 和 MMBench 扩大了能力覆盖范围 [6, 18, 41, 25]。它们的标准协议没有联合控制同类密度、属性唯一性、有序邻居和错误来源归因。因此，相邻转移得到与不存在颜色猜测相同的分数。InstaBind-Lite 以广度换取受控证据，从而分离这些风险。

II-C 视觉定位和指代表达
Flickr30K Entities、ReferItGame 和 RefCOCO 将表达与图像区域关联，而 MAttNet 将指代分解为主体、位置和关系模块 [29, 15, 40, 39]。它们的输出通常是按定位重叠评分的区域。DSCAM 则在选择之后或同时测试归因：模型可能定位到目标，却用其邻居的属性作答。因此，InstaBind-Lite 保留了用于干预的边界框，但增加了单独的重叠无法提供的有序属性和源实例错误标签。

II-D 组合性和属性-关系绑定
CLEVR 研究合成场景中的组合推理 [14]；Winoground 对比具有共享单词但组合不同的图像-标题对 [35]；ARO、VL-CheckList、CREPE 和 SugarCrepe 测试属性、关系和词序 [42, 43, 26, 11]。Winoground 的最小对原则促使在 InstaBind-Lite 中将组件识别与组合分离：同类组和词汇表保持固定，而查询的实例发生变化。ARO 的关系敏感度启发了 L3 和序数距离分析。因此，自然图像组合成为从目标 i 到源 j 的定向转移，MBR 将失败与竞争实体联系起来，而不仅仅是错误的全局匹配。

II-E 绑定机制和多主体误绑定
机制研究检查物体-引用绑定及其在视觉编码器和语言骨干中的分布 [33, 4]；MultiBind 研究图像生成中的跨主体属性转移 [36]。这项工作提出了一个互补的行为问题：读取自然图像的 LVLM 是否将观察到的属性分配给正确的同类实例。空间特征和干预可以指导，但不能替代机制分析。

III 问题定义
设图像包含一个同类组 G = {e1, e2, ..., en}，(1)
其中所有实体共享类别 c 并具有空间顺序，例如从左到右。每个实体 ei 具有针对属性类型（如颜色或上衣颜色）的属性值 ai。
问题直接或间接指定了目标实体 et。在 L1 中，目标由位置指定，答案是其属性。在 L2 中，指定了属性，答案是目标位置。在 L3 中，目标通过局部关系（如左邻或右邻）获得。在 L4 中，模型验证一个实例-属性命题。如果模型预测在答案归一化后与标准答案匹配，则预测正确。
如果预测不正确，但匹配另一个同类实体 ej 的属性或位置，则该错误被分类为误绑定：
a^ = aj, j ≠ t. (2)
误绑定的实例距离由绝对顺序差定义：
d(t, j) = |order(et) - order(ej)|. (3)
当 d(t, j) = 1 时发生相邻误绑定。
该定义有意将误绑定与集合外幻觉区分开来。如果模型预测的属性未出现在同类组中，则该错误被计为集合外幻觉而非误绑定。这种区别测试了错误答案是否基于图像但附加到了错误的实例上。
因此，关键的诊断问题不仅在于模型是否回答正确，还在于它给出了哪种错误答案。随机属性错误、图像外幻觉和邻居的属性在准确率上都是不正确的，但它们意味着不同的失败机制。“密集同类属性误绑定”关注最后一种情况。

InstaBind-Lite 是一个高纯度诊断基准，而不是通用 VQA 数据集。每张图像都经过精心挑选，包含 3–6 个具有清晰顺序、可见属性和低歧义的同类实体，使目标和邻居可供人工检查。表 II 总结了 524 张图像、529 个组、1773 个实例和 9580 个问题。

IV-A 数据来源
图像来自 COCO [22]、GQA [13]、VAW [28]、手动挑选的开放许可网络图像和自拍图像。手动验证去除了不完整的组、严重遮挡、强反射、微小物体和不确定的属性。源元数据和原始许可证与基准注释保持分离。

IV-B 注释模式
每个组记录其图像、类别、空间顺序、边界框、属性和邻居链接。边界框支持质量控制和干预；问题使用自然语言位置和关系。人物问题使用上衣颜色，只有在无歧义时才保留透明或多色标签。

IV-C 属性范围和设计权衡
该基准侧重于颜色和上衣颜色：跨类别共享且可用紧凑词汇表表达的局部属性。这使得无需 LLM 评判即可进行来源归因；L2 还要求组内属性唯一性。该范围是绑定的受控切片，不假设动作、材料、纹理、形状或状态具有相同的比率。

IV-D 问题级别
该基准生成四个级别的问题：
• L1：位置到属性，例如，“最左边的汽车是什么颜色的？”
• L2：属性到位置，例如，“红色的汽车在哪里？”
• L3：关系干扰，例如，“红色汽车右边的那辆汽车是什么颜色的？”
• L4：实例验证，例如，“中间的汽车是红色的吗？”
L2 问题要求查询的属性在同类组中是唯一的。
L1 测试位置条件读取，L2 测试反向绑定，L3 测试局部关系干扰，L4 测试命题验证，从而将感知错误与实例级转移区分开来。

V 指标
V-A 准确率
准确率测量归一化的模型预测是否与标准答案匹配。它提供了标准的任务级分数，但不解释错误答案如何与图像内容相关联。

V-B 误绑定和邻接性
设 Q、W、M 和 A 表示所有问题、错误答案、误绑定和相邻误绑定。三个比率为
MBR = |M| / |Q|, Err-MBR = |M| / |W|, A-MBR = |A| / |M|. (4)
MBR 测量转移频率，错误条件 MBR 测量其在错误答案中的份额，A-MBR 测量转移是否遵循组内邻居结构。

V-C 集合外幻觉
集合外幻觉测量不匹配任何同类实例属性或位置的预测。这将无根据的属性与图像内但误绑定的属性区分开来。因此，模型可以具有较低的对象幻觉特征，同时仍然表现出大量的实例级误绑定。

V-D 距离-MBR 和混淆矩阵
Distance-MBR 分析误绑定在第三节中定义的序数距离 d(t, j) 上的分布。因此，距离 1 表示在注释的从左到右顺序中的相邻实例；它不是欧几里得像素距离区间。这种选择对图像比例和物体间距不均具有鲁棒性，并直接测试局部实例竞争，但它无法确定序数邻接或物理分离是否是主要原因。误绑定混淆矩阵记录了目标实例索引 i 与源实例索引 j 混淆的频率。

V-E 干预差距
全图评估与局部变体进行比较，包括裁剪预言机和上下文裁剪。绑定差距是在相同的基础目标问题子集上，干预设置与全图设置之间的准确率差异。由于裁剪视图需要查询的局部化重构，这些是视觉和查询的联合干预，而不是仅图像的消融。正差距表明减少同类视觉竞争有助于模型，而较小或负的差距表明局部化是不够的，或者模型依赖于更广泛的上下文。

VI 实验
VI-A 模型和推理协议
评估涵盖五个开源 LVLM 和两个商业/API LVLM：Qwen2.5-VL-7B [3]、InternVL3-8B [44]、LLaVA-1.5-7B [24, 23]、LLaVA-OneVision-7B [17]、MiniCPM-V-2.6 [38]、Gemini-3.5-Flash [7] 和 Qwen3-VL-Plus [30]。每个模型都接收相同的问题集、答案约束和归一化解析器。只要支持，就使用确定性或低温解码，并且提示要求简短答案，以便评估反映视觉绑定而不是生成风格。

这种区别在开源模型中更大。它们的 MBR 范围从 13.65% 到 34.01%；对于 LLaVA-1.5，所有错误答案中有 74.54% 是可识别的错误实例转移，而不是任意错误。此外，在七个模型中的六个中，MBR 超过了集合外幻觉。因此，传统的物体存在评估会低估一个实质性的错误组成部分：预测的属性通常存在于场景中并得到视觉支持，但其所有者是错误的。这些结果并不否定通用基准测量的改进；它们表明，视觉可靠性的声明需要补充的实例绑定测试。
第二个发现涉及错误几何结构。在所有七个模型中，A-MBR 范围从 76.97% 到 84.65%。即使这两个 API 系统也保持了 78.38% 和 84.64% 的 A-MBR，尽管它们的总 MBR 较低。更强的模型减少了误绑定的频率，但残留的失败保留了相同的局部特征。这种跨架构和能力水平的一致性反对了均匀的属性猜测，并支持相邻同类表示之间的竞争。

图 2：全图错误分解。相邻误绑定在开源模型中构成了一个实质性的错误组成部分，并在 API 模型中保持结构上可见。

VI-D 解析器可靠性
分层审计涵盖了五个开源模型的 200 个输出，每个模型 40 个输出。它包括 87 个全图和 113 个干预输出，所有四个问题级别，以及五个结果分层：50 个正确答案、50 个相邻误绑定、35 个非相邻误绑定、35 个集合外幻觉和 30 个属性识别失败。人工判断在所有 200 个输出上与归一化解析器一致。因此，点估计为 100%，95% 的 Wilson 区间约为 [98.1%, 100%]。这种有限的审计并不能证明解析在样本之外是无误的，但它排除了足以解释报告的 MBR 和 A-MBR 模式的解析器分歧率，并验证了错误分类法可以跨答案格式和干预设置可重复地应用。

这种转移可能在辅助搜索中返回错误的所属物，选择错误的库存或机器人拣选物品，或者在交通分析中检索错误的车辆。这些是风险映射而不是测量的部署结果，但它们说明了为什么图像内答案不一定安全：当每个类别和颜色都可见时，物体存在检查无法标记错误的所有者。

VIII 干预分析
VIII-A 协议
干预应用于具有单个定义目标和属性的 4261 个 L1/L3 问题。所有干预图像都保持纵横比。仅当源图像的长边超过 1800 像素时才对其进行下采样，目标边界框按相同比例缩放。裁剪预言机使用注释的目标边界框，水平和垂直填充等于目标宽度和高度的 15%，并裁剪到图像边界。上下文裁剪使用 50% 的填充以保留更多局部上下文。由于诸如“从左数第三个”之类的原始表达在裁剪后不再有意义，因此直接裁剪提示要求描述的实例的属性，而上下文提示要求最接近裁剪中心的实例的属性。
“预言机”表示可以访问真实目标边界框，而不是完美的像素隔离。15% 的裁剪可以保留重叠邻居的片段，而 50% 的上下文裁剪有意保留附近的实体和场景线索。因此，该比较是一项联合视觉和查询定位测试：它询问使目标更容易隔离是否会减少可归因于来源的误绑定。

IX 讨论
IX-A 为什么需要感知来源的基准
标准准确率回答响应是否正确；物体幻觉指标回答预测内容是否得到支持；定位指标回答指代是否被定位。这些量单独都无法回答可见属性是否被分配给了其所有者。InstaBind-Lite 通过记录目标和竞争源实例来添加这个缺失的变量。由此产生的分解在操作上很重要：不支持的生成需要幻觉抑制，识别失败需要更强的视觉特征，而相邻转移需要更好的实例分离或绑定。将它们合并为一个错误率会掩盖新模型或缓解措施实际改进了哪个组件。
七个模型的结果说明了后果。API 模型在总体准确率上领先，但仍保留了可测量的 MBR 和高 A-MBR。七个模型中有六个产生错误实例转移的频率高于集合外幻觉。因此，一个模型在广泛能力和物体存在测试下可能看起来很强大，但对于特定实体问题仍然不可靠。InstaBind-Lite 并不取代这些基准；它防止在没有直接绑定测试的情况下将其分数解释为实例定位可靠性的证据。

IX-B 相邻结构和机制含义
跨架构来看，大多数可识别的转移源自序数距离 1。自举分析表明，即使总 MBR 差异很大，这种邻居浓度在图像级重采样下仍然存在。这一结果支持局部同类竞争而不是均匀的答案噪声，并激励了显式对比相邻实例的机制。当前的序数分析并未确立欧几里得分离的因果效应：相邻索引可能具有不等的像素间隙、对象比例和重叠。因此，需要归一化的中心距离、边界距离和重叠来区分顺序局部竞争和物理接近度。

IX-C 对多媒体系统的影响
图 4 中的案例将这种区别映射到多媒体操作：属性提示辅助识别、媒体和目录搜索、机器人选择和交通检索。真实的视觉证据仍然可能识别错误的实体，导致错误的项目检索或操作，而不仅仅是尴尬的标题。因此，在将 LVLM 视为对特定实体决策可靠之前，需要进行感知来源的评估。

IX-D 诊断范围和缓解
受控的颜色域实现了确定性的来源归因，并暴露了清晰的绑定信号。这并不意味着动作、材料、状态或部分属性将表现出相同的比率。这些语义引入了时间和注释的歧义，需要适应的问题模板和评判者。同样，裁剪和实例优先提示是探针，而不是完整的解决方案。它们依赖于模型的效果指向了两个研究方向：对比相邻同类实例的绑定感知训练，以及在显式定位目标的同时保留全局上下文的推理方法。该基准提供了评估此类方法是修复绑定还是仅仅改变总体准确率所需的边界框、邻居结构和错误标签。

X 数据可用性和伦理考虑
InstaBind-Lite 旨在发布注释、生成的问题、评估脚本、解析器代码和模型输出元数据，以重现报告的表格和图表。对于来自既定数据集的图像，发布程序将遵循原始条款，并在不适合直接重新分发时提供来源标识符。对于手动收集的网络图像，重新分发将限于具有允许此类使用的可恢复许可证证据的文件；否则，公共包将提供派生注释并排除图像文件。自拍图像可由作者直接发布。
该基准包含人物图像仅用于视觉属性绑定评估。排除身份、人口统计和敏感属性问题；人物问题仅涉及可见的上衣颜色。人工审查排除了可能具有攻击性、隐私性或歧义性的描绘。该数据集设计用于 LVLM 行为的诊断评估，不应用于监视、身份推断或人口统计分析。

XI 结论
本研究将“密集同类属性误绑定”形式化为一种可识别来源的失败，其中 LVLM 预测了图像中存在的属性，但将其分配给了错误的同类实例。InstaBind-Lite 解决了总体 VQA、物体幻觉、定位和组合性评估留下的空白：其受控组、有序实例注释和四个问题级别不仅揭示了答案是否错误，还揭示了其证据是否从特定的可见邻居复制而来。
对七个 LVLM 的评估表明，实例级可靠性不能仅从总体准确率推断。开源模型平均 MBR 为 19.84%，API 模型为 7.55%，而两组在可识别转移中均保留了约 81% 的相邻浓度。图像簇置信区间、分层解析器审计、真实图像案例以及受控的定位和提示干预支持了相同的结论：DSCAM 是一种可重现的、空间结构化的错误类别，缓解必须减少错误实例转移，而不丢弃有用的上下文或一般能力。

XI-A 未来工作
未来的工作将把 InstaBind-Lite 转变为一个受控的模型开发循环。防泄漏的训练、验证和保留测试集将支持边界框条件视觉标记、坐标嵌入、邻居对比损失和有序实例-属性监督的比较。实例优先提示和邻居对比解码将保留为推理时基线。所有变体都将使用相同的冻结测试集和解析器；成功需要更低的 MBR 和 Err-MBR，稳定或更高的准确率，并且不增加集合外幻觉或无效答案。声称的空间修复还必须减少 A-MBR 或 Distance-MBR，并具有图像簇自举区间、成对图像级测试以及按类别、级别、组大小、位置和源距离的分层。
扩展将平衡代表性不足的类别，并使用可审计的评估将属性扩展到材料、状态、动作、部分、深度和时间身份。序数距离将由归一化的像素距离、重叠、深度和遮挡来补充；解析器审计将包括 API 输出和更广泛的分层。成功的缓解措施最终将在新收集和跨数据集图像上进行测试，以建立超越受控颜色切片的转移。
