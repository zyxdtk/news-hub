摘要
最先进的多变量时间序列预测器能够对复杂的时间和跨变量依赖关系进行建模，但其不透明的表示方式对于为何产生特定预测提供的洞察有限。这种缺乏透明度的情况限制了它们在从业者必须理解和评估预测背后因素的场景中的应用。我们引入了 ConceptTS，这是一个可解释的预测框架，它围绕命名的、人类可读的概念来组织预测。ConceptTS 使用大型语言模型提出与任务相关的概念并生成可执行的标记规则，将语言模型的领域知识转化为直接监督，而无需昂贵的人工概念标注。所提出的概念被组织成三个互补的瓶颈，分别描述历史上下文、局部预测区间和整个预测期。一个共享解码器结合从其预测激活中导出的表示来构建预测，使模型的决策过程显式化，并支持直接的概念级干预。在北京多站点空气质量数据集上的实验表明，ConceptTS 实现了与强大的黑盒基线相媲美的准确性，同时产生了具有语义意义的概念激活。

I
引言
多变量时间序列预测从历史观测和相关协变量中预测目标轨迹。在医疗保健、环境监测、能源和工业领域，这些持续收集的数据既需要可扩展的建模，也需要可解释的时间分析 [1, 2]。现代循环、卷积、图、线性/MLP 和 Transformer 架构能够以很高的准确性捕捉非线性时间动态和跨变量依赖关系 [3]。然而，它们在预测方面的进展超过了可解释性：预测并没有揭示是哪些时间条件或变量交互塑造了它，也没有揭示模型是否使用了合理的证据。这种不透明性在数据密集型的高风险场景中是致命的，在这些场景中，从业者必须在信任预测之前了解潜在的失败模式。

解释多变量时间序列尤其具有挑战性，因为预测证据分布在变量和时间尺度上，并且其相关性在整个预测期内可能会发生变化 [4, 5, 6]。一个预测可能共同依赖于一个通道的长期趋势、另一个通道的短暂事件以及它们不断演变的交互作用。归因或显著性方法可以识别有影响力的通道和时间戳，但这些低级的重要性分数并不一定能解释所选证据所代表的语义条件。基于概念的模型通过围绕人类可理解的中间变量组织预测，提供了一个有前途的替代方案。概念瓶颈模型（CBM）使这些变量变得可检查且可直接干预 [7]，而最近的时间序列方法提供了互补的方向：ProtoTS 为预测引入了分层原型推理 [8]，而 TimeX++ 通过信息瓶颈学习保留标签的解释性实例 [9]。然而，传统的 CBM 依赖于专家定义的概念和逐例标注；ProtoTS 学习的潜在原型，其含义必须在训练后进行推断；而 TimeX++ 解释的是现有的预测器，而不是要求预测通过命名的语义证据。因此，要获得一个内部证据在语义上是明确的、受监督的、并且与预测路径相关联的准确预测器，同时又不产生大量标注成本，仍然很困难。

我们用 ConceptTS 解决了这一差距，这是一个用于可解释多变量时间序列预测的 LLM 引导的概念瓶颈框架。给定领域上下文、数据集统计信息和代表性时间状态，离线大型语言模型提出概念名称、自然语言定义和可执行谓词，以自动标记训练片段。ConceptTS 将这些概念组织成互补的瓶颈，分别描述历史上下文、预测期内的局部区间以及整个预测期。一个保持结构的编码器预测它们的激活，一个共享解码器从生成的概念表示中构建预测。独立于输入的概念嵌入限制了围绕所显示激活路径的信息泄漏，而一个小型正则化残差通道容纳了离散概念未完全表示的连续幅度信息，并暴露了明确的准确性-可解释性权衡。LLM 仅在概念构建期间使用，在推理时不需要。我们在北京多站点空气质量数据集的三个站点上评估了 ConceptTS，在具有未来感知和仅回溯两种设置下进行。该模型与强大的黑盒预测器相比仍具有竞争力，包括 MAE 在最佳测试的仅回溯基线的 5% 以内。除了预测准确性之外，概念计数和残差通道消融、定性案例研究、反事实概念扫描和激活干预检查了概念是如何被学习和使用的。特别是，用反转的真实概念标签替换激活，将测试 MAE 从 15.371 增加到 99.661，提供了直接的证据，证明解码器在测试配置中依赖于概念激活通道。

我们的贡献有三个方面：
•
LLM 引导的概念构建和监督。
我们引入了一个管道，将领域上下文和数据集摘要转换为命名的时序概念、自然语言定义和可执行的标记规则，避免了为单个训练片段进行人工概念标注。
•
多尺度、可干预的预测架构。
我们在历史、局部预测和全局预测范围内组织概念，并设计了一个预测路径，在限制概念瓶颈周围信息泄漏的同时，保持时间和变量结构。
•
预测和可解释性的评估。
跨越三个监测站和两种输入机制的实验确立了具有竞争力的预测性能，而消融、案例研究、概念扫描和受控干预评估了概念质量、模型依赖性以及准确性-可解释性的权衡。

II
相关工作
II-A
时间序列模型的可解释性
解释时间序列预测不仅仅是将重要性分配给独立的特征。预测证据可能在于一个事件、其持续时间、一个窗口内的趋势或通道之间的交互；此外，相关证据可能在预测期内发生变化。因此，调查将事后归因、扰动和基于实例的解释与内在可解释的架构区分开来，并沿着局部与全局范围、忠实度、稳定性和人类可理解性等维度评估解释 [4, 5, 6]。这些要求对于多变量预测尤为苛刻：相关变量使个体归因变得模糊，时间聚合可能隐藏短暂事件，而掩码可能产生分布外输入 [9]。

几种预测方法暴露了输入中哪些部分看起来有影响力。Series Saliency 联合学习多变量输入区域上的预测和显著性，而 Temporal Fusion Transformer 提供变量选择权重和时间注意力模式 [10, 11]。TimeX++ 通过信息瓶颈目标学习分布内、保留标签的解释性实例，解决了传统掩码的局限性 [9]。这些方法提供了有用的定位和模型诊断，但它们的解释主要表示为变量和时间戳上的重要性或选定的输入实例。从业者仍然必须推断该证据所代表的语义条件——例如，一个联合变化是否表示污染事件、天气转变或重复的日常状态。此外，为现有预测器选择的解释不一定是计算其预测的中间表示。我们的工作相反，针对一个内在的预测路径，其证据以命名的时序概念的稳定词汇表达，并且可以直接干预。

II-B
基于概念和语言引导的模型
概念瓶颈模型最初是为图像分类开发的，其中模型在推断目标标签之前预测人类定义的视觉属性 [7]。因为任务预测是通过这些中间概念表达的，用户可以检查和干预模型的推理。概念嵌入模型通过用学习到的嵌入表示每个概念的活动和非活动状态，增加了这个瓶颈的容量 [12]。将这种范式适应于多变量时间序列并非易事：与静态视觉属性不同，时序概念可能描述不同时间尺度的趋势、持续时间、跨变量关系和模式。此外，定义这些概念和标记每个序列通常需要大量的领域专业知识。我们的工作将概念瓶颈范式适应于预测，同时减少了这种监督负担。

语言引导的方法提供了一种减少这种监督负担的途径。LaBo 使用语言模型提出候选概念，并通过视觉-语言模型将其落地，用于可解释的图像分类，而概念瓶颈 LLM 围绕人类可读的中间概念组织语言模型决策 [13, 14]。这些研究表明语言模型可以辅助概念发现，但它们主要解决图像或文本任务。连续的多变量序列还需要操作定义，指定时序概念何时处于活动状态，适应变量之间的交互，并区分在不同时间范围内出现的模式。

ProtoTS 通过学习与规范预测曲线相关联的分层潜在原型，为可解释的时间序列预测提供了一种相关的类概念方法 [8]。虽然这些原型支持检查，但它们是未命名的，并且预测可以利用所显示的原型匹配之外的学习信息。因此，用户必须在训练后推断它们的语义，而单独的匹配并不能完全解释预测。相比之下，ConceptTS 使用离线 LLM 提出命名的时序概念和可执行的标记规则，然后在历史上下文、局部预测区间和整个预测期内组织受监督的概念。这种设计为预测路径提供了一个稳定的语义词汇，支持直接检查和干预，而无需人工的片段级标注。

III
方法
图 1：ConceptTS 用于单个预测子窗口的整体架构。LLM 提出了三个概念集，分别涵盖回溯窗口、每个预测子窗口和全局预测期。ModernTCN 风格的编码器嵌入输入；嵌入的时间切片驱动概念激活概率，这些概率与两个静态概念嵌入结合形成概念-上下文向量。这些向量与位置嵌入、跨子窗口 BiGRU 输出和残差通道连接，并馈入一个堆叠残差解码器，以由粗到细的方式细化预测。

III-A
公式化和框架
III-A
1
问题公式化
在本项目中，我们考虑多变量时间序列预测问题，其中一组外生特征被用作上下文信息，以帮助预测内生（目标）特征。给定回溯目标序列 𝐘_{1:L}∈ℝ^L，回溯协变量 𝐗_{1:L}∈ℝ^{L×C}，以及预测期内可用的协变量 𝐗_{L+1:L+H}∈ℝ^{H×C}，我们的模型 ℱ 预测 𝐘̂{L+1:L+H}=ℱ(𝐘{1:L}, 𝐗_{1:L}, 𝐗_{L+1:L+H})。除了这种未来感知设置外，我们还评估了一种仅回溯设置，该设置移除了对 𝐗_{L+1:L+H} 的访问，并强制模型仅从 𝐘_{1:L} 和 𝐗_{1:L} 进行预测。

III-A
2
框架概述
图 1 说明了 ConceptTS 的管道。离线 LLM 提议器生成三个概念集——分别用于回溯窗口、预测子窗口和整个预测期——每个概念集都配有一个可执行的谓词，用于标记每个训练片段。ModernTCN 风格的编码器保留每个通道和时间的结构，产生驱动三个并行 CEM 瓶颈中概念激活的嵌入。一个共享的残差子解码器将概念上下文、跨子窗口 BiGRU 输出和正则化残差通道组装成最终预测，并使用混合损失进行端到端训练。

III-B
LLM 驱动的概念提议器
我们不依赖人工编写的概念集和逐片段标签（标准 CBM/CEM 的要求），而是向离线 LLM 提供数据集统计信息，并要求它返回三个概念集以及可执行的 Python 谓词，用于标记每个训练片段。

III-B
1
逐片段统计摘要
对于每个输入片段 s_i，我们首先从这四个方面提取结构化的统计摘要：
•
回溯统计：每个通道的 {均值、标准差、斜率、极差}；加上 FFT 导出的 {主周期、24h 振幅、谱熵、低频比} 以暴露循环模式。
•
预测统计：预测期内每个非目标特征通道的 {均值、标准差、斜率、极差}。
•
子窗口统计：每个子窗口的 {均值、标准差、斜率、极差}，用于更细粒度的描述。
•
跨通道和时间上下文：关键通道对之间的成对皮尔逊相关系数；回溯/预测期起止时间戳；季节标签（春/夏/秋/冬）。
这些信息组合在一起，为 LLM 提供了每个片段外观的全面视图，促进了其后续的概念提出和逐概念激活标记。

III-B
2
摘要向量聚类和分析
为了向 LLM 提供关于数据集状态结构的现实指导，摘要向量通过 K-means 聚类成 N_c 组。为了防止泄漏，此聚类以及下面引用的所有每簇和全局统计信息仅在训练集上计算。对于每个簇 c，我们计算一个紧凑的概况，包含 其大小和训练集的比例， 对于每个连续通道 j，簇均值相对于全局（训练）分布的 z-score (μ_{c,j} - μ_{global,j}) / σ_{global,j}，以及 对于每个分类通道 j，主导值及其纯度（共享该值的簇成员比例）。这 N_c 个概况与全局每通道统计信息一起包含在 LLM 提示中，为 LLM 提供基于数据的局部统计信息，以促进其概念生成，同时不会使提示过长。

III-B
3
LLM 概念提议生成
对于初始概念生成，我们向 LLM 提供一个包含背景信息、通道描述、全局统计摘要、簇概况、片段方案、任务规范和输出格式的综合提示。一个关键的设计选择是我们要求 LLM 生成三种类型的概念集，每种针对不同的输入方面：
•
回溯概念 描述在回溯窗口中观察到的语义模式，提供历史上下文和一般趋势信息。例如：“回溯窗口平均气温高吗？”、“历史总体多雨吗？”
•
预测子窗口概念 描述预测期内子窗口中上下文特征的细粒度局部细节（例如：“子窗口处于早高峰时段吗？”、“子窗口风速正在上升吗？”）
•
全局预测概念 描述预测期的一般特征（例如：“预测期观察到极端温度变化吗？”、“预测期经历大幅气压波动吗？”）。此类全局预测概念作为预测子窗口概念的补充，提取整个预测期内的宏观模式。
对于预测子窗口和全局预测概念，提示明确指示 LLM 仅从上下文协变量而不是目标变量本身构建谓词，因为在推理时模型无法获得预测期内的目标值。
与其他领域仅提示 LLM 提供概念的自然语言描述的类似工作不同，我们明确要求语言模型返回一个可执行的 Python 谓词，该谓词使用预计算的统计信息作为输入来评估片段是否匹配该概念。LLM 提议器本身仅被调用一次以生成这些谓词；然后通过在片段的预计算统计信息上执行每个谓词，自动生成每个训练片段的概念标签，从而避免了昂贵的逐片段 LLM 调用。

III-B
4
概念过滤
在提出 N_initial = N_look-back + N_sub-window + N_forecast 个概念后，我们计算每个概念在训练集上的正例率 r_i，并通过仅保留 r_i ∈ [r_min, r_max] 的概念来过滤掉无用的概念。过滤后，剩余 N_concept 个概念。在概念评估过程中，为每个片段导出的二进制标签 y_i ∈ {0,1}^{N_concept} 成为概念监督损失的训练目标。

III-C
基于卷积的编码器
ProtoTS 的特征融合和时间均值池化形成了紧凑的原型表示，而我们的多尺度概念需要特定于变量的局部证据，这导致我们采用 ModernTCN 的变量独立嵌入来保留通道标识，并采用其大核深度卷积来捕捉广泛的时间上下文 [15]。
给定形状为 (B, T, C) 的输入，每个变量通道将被单独编码并投影到相同的嵌入维度 D，所有嵌入沿变量轴连接形成形状为 (B, T, C, D) 的张量。接下来，使用步长为 S 的深度卷积将张量分块为形状 (B, C, D, N)，其中 N = T/S。每个 ModernTCN 块结合了一个大核深度时间卷积和两个分组的逐点倒置瓶颈，分别在每个变量的特征轴和每个特征的变量轴上混合信息。每个块都包裹在残差连接中。对分块轴进行最后的线性投影，将 N 个分块位置映射回原始的 T 个时间步，产生输出嵌入 𝐄 ∈ ℝ^{B×T×D_enc}。我们保留时间轴以向后续的概念瓶颈模块提供更全面的信息。总体而言，编码器结构产生的嵌入在特征和时间轴上都具有丰富的语义。
在我们的默认设置中，我们使用两个并行的编码器分别编码回溯窗口 𝐘_{1:L}, 𝐗_{1:L} 和预测期 𝐗_{L+1:L+H}。我们这样做是为了在两个时间段之间手动设置信息屏障。

III-D
并行概念嵌入瓶颈模块
对输入片段进行编码后，嵌入被传递到三个并行的概念嵌入瓶颈中：一个回溯概念瓶颈总结“最近的历史上下文是什么样的”，N_sw 个预测子窗口概念瓶颈每个捕捉“其他协变量在预测期的这一部分中显示了什么关键模式”，以及一个全局预测概念瓶颈告诉“上下文特征通道在预测窗口中暴露了什么宏观趋势和行为”。通过将这三个概念嵌入馈入解码器，模型可以进行准确的预测，并且通过检查三个概念瓶颈模块中每个模块的概念激活，预测具有高度的可解释性。

III-D
1
注意力加权的上下文池化
如上一节所述，从编码器出来的嵌入表示为 𝐄_𝐥𝐨𝐨𝐤−𝐛𝐚𝐜𝐤 ∈ ℝ^{B×T_look-back×D_enc} 和 𝐄_𝐟𝐨𝐫𝐞𝐜𝐚𝐬𝐭 ∈ ℝ^{B×T_forecast×D_enc}。为了使三个概念瓶颈总结正确的时间部分，我们首先使用三个注意力加权池化模块将嵌入转换为三个相应的上下文向量：
𝐳_lb = AttentionPool(𝐄_look-back[1:T_look-back])
𝐳_sw^(k) = AttentionPool(𝐄_forecast[(k-1)T_sw+1 : kT_sw])
𝐳_gfc = AttentionPool(𝐄_forecast[1:T_forecast])
其中 T_look-back、T_forecast 和 T_sw 分别表示回溯窗口中的时间步数、预测期中的时间步数和每个子窗口中的时间步数。
对于任何时间切片 𝐄 ∈ ℝ^{B×T'×D}，AttentionPool(·) 计算每个时间步的加性注意力分数，沿时间轴对它们进行 softmax，并返回加权和：
𝜶 = softmax(𝐖_2 tanh(𝐖_1 𝐄)), 𝐳 = Σ_{t=1}^{T'} α_t 𝐄_t ∈ ℝ^D, (1)
其中 𝐖_1 和 𝐖_2 是一个小型注意力 MLP 的两层。
我们使用加性注意力而不是 ProtoTS 中采用的时间轴均值池化：均值池化对每个时间步同等加权，并将任何时间局部的信号稀释为单个平均值，而加性注意力学习依赖于内容的权重，强调语义上重要时间步并抑制其余时间步，从而为概念瓶颈提供更锐利的时间摘要。

III-D
2
概念嵌入模块
我们在模型中适应了完整的概念嵌入模型（CEM）结构，这是原始概念瓶颈模型（CBM）的替代选项 [12]。在 CEM 中，每个概念的表达能力通过两个高维嵌入得到增强，一个表示“概念何时处于活动状态”（𝐞_c^+），另一个表示“概念何时不存在”（𝐞_c^-）。一个重要的创新是我们将 𝐞_c^+ 和 𝐞_c^- 设计为“独立于输入”的，这意味着所有概念嵌入都是通过学习塑造的，并在推理阶段保持静态。这样的设计是为了确保没有强烈的信息泄漏破坏可解释性的强度。
一个小型评分头 h_c 接收编码器输出嵌入 𝐳 并产生一个标量 logit，在 sigmoid 激活函数之后给出概念激活概率：
p_c(𝐳) = σ(h_c(𝐳)). (2)
对于每个概念，最终的概念上下文向量是两个概念嵌入的相应加权混合：
𝐜_c(𝐳) = p_c(𝐳) · 𝐞_c^+ + (1 - p_c(𝐳)) · 𝐞_c^- ∈ ℝ^{d_c}. (3)
将瓶颈内的所有 N 个概念堆叠起来产生瓶颈输出：
𝐂(𝐳) = [𝐜_1(𝐳); 𝐜_2(𝐳); ...; 𝐜_N(𝐳)] ∈ ℝ^{N·d_c}. (4)

III-D
3
序列感知的子窗口连接
由于预测子窗口在时间上是相关的（例如，高风速的影响取决于前一个子窗口的湿度），我们使解码器具有子窗口感知能力。每个子窗口的概念上下文 𝐂_sw^(k) 被投影到一个摘要向量 𝐬^(k) = 𝐖_summ 𝐂_sw^(k)，并通过双向 GRU：
[𝐮^(1), ..., 𝐮^(N_sw)] = BiGRU([𝐬^(1), ..., 𝐬^(N_sw)]). (5)
输出 𝐮^(k) 被连接到子窗口 k 的子解码器输入中，提供跨子窗口上下文。使用概念瓶颈输出 𝐂_sw^(k)（而不是编码器嵌入）作为 BiGRU 输入可以防止信息绕过瓶颈泄漏。

III-D
4
残差子解码器堆栈
最终，预测由一个共享子解码器产生，该解码器接收所有三种类型的概念瓶颈输出嵌入、跨子窗口上下文嵌入、位置子窗口 ID 嵌入和一个狭窄残差旁路的连接：
𝐝^(k) = [𝐂_lb; 𝐂_sw^(k); 𝐂_gfc; 𝐮^(k); 𝐞_sw^(k); 𝐫_lb; 𝐫_sw^(k)], (6)
其中 𝐞_sw^(k) = Embedding(N_sw, d_id)(k)，一个仅携带位置嵌入，不携带数据派生信号。𝐂_lb 和 𝐂_gfc 分别表示回溯概念瓶颈和全局预测概念瓶颈的最终输出。最后两项形成一个可选的残差旁路，其中 𝐫_lb = 𝐖_lb 𝐳_lb 在所有子窗口之间共享，而 𝐫_sw^(k) = 𝐖_sw 𝐳_sw^(k) 按子窗口计算，两者都是将池化的回溯和预测子窗口编码器特征线性投影到低维空间 ℝ^r。该旁路携带软标量概念激活无法完全表达的连续信息。它保持低维，并由专门的损失项进行正则化，以阻止模型过度依赖残差连接；此正则化的权重 α_res 是权衡预测准确性与多少预测通过概念瓶颈路由的直接旋钮。
受 NHiTS 启发，解码器总共有 N_dec 个堆叠的 MLP 块，每个块细化从前一个块获取的输出 [16]。
𝐲̂^(k) = Σ_{b=1}^{B_dec} 𝚫_b^(k), 𝚫_b^(k) = Block_b(𝐢_b^(k)). (7)
我们还使用解码器反馈结构，这意味着块 b>1 额外看到到目前为止的运行预测：𝐢_1^(k) = 𝐝^(k) 且对于 b>1，𝐢_b^(k) = [𝐝^(k); flatten(Σ_{b'<b} 𝚫_{b'}^(k))]。本质上，堆叠的子解码器模块不断利用三种类型的概念瓶颈总结的信息以及相邻子窗口的上下文来改进其预测，从初始的粗略预测到最终的高质量预测。
共享解码器输出第 k 个子窗口的预测 𝐲̂^(k) ∈ ℝ^{B×T_sw×1}。然后，所有部分预测沿时间轴连接以形成最终的预测曲线。

III-E
训练管道
两个并行编码器、三个 CEM 模块和解码器端到端联合训练。我们使用混合损失函数来确保模型的不同部分按预期工作：
ℒ = α_f ℒ_forecast + α_lb ℒ_concept^lb + α_fc ℒ_concept^fc + α_gfc ℒ_concept^gfc + α_bd ℒ_boundary + α_cc ℒ_collapse + α_residual ℒ_residual, (8)
完整目标结合了七个加权损失项： 目标上的 L_1 预测损失；- 三项在 LLM 导出的二进制标签上的 BCE 概念损失，分别用于回溯、预测子窗口和全局预测瓶颈，迫使每个概念的预测激活分数接近 LLM 导出的标签； 跨子窗口边界的 L_1 边界平滑惩罚，防止最终预测输出中的不连续值； 保持每个概念的激活不崩溃到接近常数（因此无信息）值的方差下限；以及 残差通道上的 L_2 正则化器，直接控制准确性-可解释性权衡。

实验
IV-A
模型性能
IV-A
1
数据集
我们选择使用北京多站点空气质量数据集，这是加州大学欧文分校机器学习仓库提供的一个开源多变量时间序列数据集 [17]。该数据集包含北京 12 个空气质量监测站的 6 种污染物浓度和 5 个相关气象上下文特征，时间跨度从 2013 年 3 月 1 日至 2017 年 2 月 28 日，记录间隔为 1 小时。我们选择使用 PM2.5 浓度作为目标特征，上下文特征包括其他五种污染物（PM10、SO2、NO2、CO、O3）和五项气象测量（温度、气压、露点、降水量、风速）。每个特征通道中的缺失数据使用线性插值进行填充。
我们在三个监测站——Aotizhongxin、Dingling 和 Tiantan——对整体预测性能进行基准测试，并使用 Aotizhongxin 作为所有后续消融和案例研究实验的代表站点。

IV-A
2
评估指标
我们使用时间序列预测中的两个标准指标报告模型性能：平均绝对误差（MAE）和均方根误差（RMSE）。
这两个指标是互补的：MAE 显示模型预测在每个时间步平均偏离真实值的程度，而 RMSE 更重地惩罚大误差，显示模型处理预测中具有挑战性部分（如空气污染物峰值）的能力。指标以原始 μg/m^3 报告，通过反转训练集的 z-score 计算。

IV-A
3
实验设置
我们实施了两种实验设置，以反映多变量时间序列预测领域中常见的两种自然数据可用性机制。在“未来感知”设置（第 3.1.1 节阐明的默认设置）中，假设预测期的外生特征是预先已知的，当上下文特征来自上游预测系统时，这是现实的。在预测与风速、降水量和温度等气象因素相关的任务中通常是这种情况。在“仅回溯”设置中，模型只能访问历史中的所有特征 {𝐘_{1:L}, 𝐗_{1:L}}，与 Time-Series-Library 用于其基准模型的常规设置相匹配。
这两种设置共享相同的编码器-池化-CEM-解码器模型结构，但概念瓶颈类型不同。在未来感知设置中，LLM 提议器分别为回溯窗口、预测子窗口和全局预测期提出三个概念集。在仅回溯设置中，只有一个编码回溯窗口的编码器（因为没有未来数据可编码），提议器转而提出两个概念集，一个用于全局回溯窗口，一个用于回溯子窗口，因为现在模型额外将回溯窗口划分为 N_lbsw 个子窗口，以提供更多的可解释性和更高的预测准确性。
由于大多数 Time-Series-Library 基线仅消耗回溯窗口，我们在每种设置中与不同的基线集进行比较。

IV-A
4
模型评估
在未来感知设置下，如表 I 所示，我们的模型与最先进的基准时间预测器具有竞争力。以 Aotizhongxin 为例，我们的模型实现了 12.71 μg/m^3 的 MAE，优于 Informer（28.62 μg/m^3）[18]、Random Forest（26.73 μg/m^3）[19]、DeepAR（13.97 μg/m^3）[20] 和 NHiT（16.94 μg/m^3）[16]，并匹配了 XGBoost（12.34 μg/m^3）[21]、TFT（12.44 μg/m^3）[11] 和 LightGBM（12.46 μg/m^3）[22] 的性能，同时提供了这些模型无法提供的概念级解释。因此，我们的模型通过在实现 SOTA 准确性的同时，直接将类似人类的概念决策过程纳入预测管道，为多变量时间序列预测做出了贡献。
对于仅回溯设置，我们将我们的模型与几个 Time-Series-Library 基准进行比较，结果如表 II 所示。结果表明，即使仅接收历史上下文，我们模型的预测准确性也与 SOTA 时间序列预测器具有竞争力。对于 Aotizhongxin 站，ConceptTS（55.59 μg/m^3 MAE）击败了 TimeXer（57.43 μg/m^3）[23]、iTransformer（59.16 μg/m^3）[24]、DLinear（56.27 μg/m^3）[25] 和 LSTM（55.91 μg/m^3）[26]。值得注意的是，尽管其他两个模型（Informer、Crossformer）产生了较低的 MAE，但我们的模型仍然具有高度竞争力，分别仅落后它们 0.55 μg/m^3 和 0.81 μg/m^3 [18] [27]。
在这两种情况下，RMSE 上的差距稍大，表明 ConceptTS 很好地处理了典型时间步，但对极端污染峰值的敏感度稍低，我们将这一限制留给未来的工作。

IV-B
消融研究
我们进行实验以研究不同的结构设计如何对模型的性能做出贡献。具体来说，我们研究 预测子窗口概念的数量如何影响预测准确性，以及 残差通道权重 α_residual 如何权衡准确性和可解释性。

IV-B
2
准确性和可解释性之间的权衡
在方法部分，我们介绍了残差通道及其权重 α_residual；本节从经验上研究 α_residual 如何平衡预测准确性和可解释性。

总之，这两个案例研究说明了我们模型的两个互补的可解释性属性：概念激活忠实地描述了输入，并且对概念的激活进行干预可以帮助领域专家直观地理解该概念如何对预测做出贡献。

IV-C
3
概念干预诊断
为了进一步验证我们的模型确实依赖概念激活通道进行预测，我们在测试集上进行了概念干预诊断。在推理时，我们保持模型的权重不变，但用四种机制之一替换每个概念的预测激活概率 p_c：
•
基线：模型自身的预测激活概率（无变化）。
•
先知：每个概念激活被替换为其真实的二进制标签。
•
翻转：每个概念激活被替换为 1 减去真实标签（纯粹反转原始预测）。
•
随机：每个概念激活被替换为来自 Bernoulli(0.5) 的样本（“随机猜测”）。
这个想法很简单。如果解码器主要依赖概念激活通道进行预测，那么将激活翻转为相反的值应该会极大地损害预测质量。另一方面，如果解码器主要绕过概念并从 CEM 的 ± 嵌入中读取信息，那么翻转激活应该对预测几乎没有影响。

V
结论
我们引入了 ConceptTS，这是一个可解释的多变量时间序列预测器，它改编了图像分类中的概念瓶颈。离线 LLM 构建命名的时序概念和可执行的标记规则，减少了人工标注，并且在推理时不需要 LLM。在三个空气质量站点和两种设置中，ConceptTS 实现了具有竞争力的准确性，同时支持概念级检查和干预。反转真实概念标签使 MAE 增加了约九倍，显示了对概念路径的强烈依赖。

A-A
ProtoTS 结构
ProtoTS 是一个两阶段的、分层原型的时间序列预测器，它将目标通道加上一组上下文通道作为输入。
阶段 1：编码器预训练。
每个输入通道首先被独立嵌入——连续特征（例如，皮肤温度）通过 MLP，离散特征（例如，一天中的小时）通过查找表。然后，每通道嵌入通过一堆残差 MLP-mixer 块，沿时间和特征轴混合信息。在这个阶段，编码器被训练以产生嵌入和预测曲线，迫使它学习已经携带下游任务所需信息的表示。
阶段 2：原型层。
分层原型层与预训练的编码器联合训练。每个原型由两个随机初始化的部分组成：一个 prototype_embedding（原型的特征）和一个 prototype_value（原型的规范预测曲线）。适配器模块将输入窗口的嵌入投影到较低维的“键”中，通过 softmax 路由与每个原型的 prototype_embedding 进行比较，最终预测是所有 prototype_value 曲线的分数加权和。
ProtoTS 的一个核心设计选择是原型形成一棵树。
训练从 6-12 个根原型开始，每当验证损失停止改善过长时间时，就会触发分裂机制。此时，按按激活计数归一化的累积损失排名的最高误差原型每个分裂成几个子原型，以便每个子原型专门处理父原型更复杂场景的一个方面。

A-B
来自 ProtoTS 的动机
在 ProtoTS 设计的基础上，我们的分析确定了激发 ConceptTS 中设计选择的三个方面：
(1) 随机初始化的原型。
因为原型是随机初始化并通过梯度下降塑造的，它们的语义含义不是由设计本身指定的。解释一个训练好的原型通常需要领域专家在训练后检查其激活模式和相应的 prototype_value 形状，这可能很耗时并且有时是模糊的。
(2) 混合时间和特征轴的编码器。
ProtoTS 的编码器在原型模块之前沿时间和特征轴混合信息。这种设计对于捕获联合时间-通道模式是有效的，但它使得隔离特定的跨通道语义变得更加困难——像“极低温度导致电力负荷激增”这样的概念很难仅通过事后检查从单个学习到的原型中恢复。
(3) 通过 value_bias 的辅助路径（对我们的设计影响最大）。
除了 softmax 归一化的激活分数——表示“输入窗口与此原型的相似程度”——ProtoTS 将每个原型的贡献乘以一个由读取编码器输出嵌入的单独 MLP 产生的 value_bias 标量。因此，最终预测是 y^ = Σ_{prototypes} activation_score × value_bias × prototype_value。
在我们的实验中，我们观察到，由于编码器与原型层共同训练，模型倾向于收敛到一种配置，其中原型激活分数在输入窗口之间变得几乎均匀，而大多数依赖于输入的预测信号由 value_bias × prototype_value 通道携带。因为 value_bias 直接从编码器输出读取，这条路径不保留与激活通道相同的可解释性结构。ProtoTS 包含一个基于熵的正则化项，旨在保持激活分数非均匀；我们发现它的默认权重对我们的数据影响有限，当我们提高权重足以让熵项积极塑造训练时，预测准确性明显下降——这表明在这种配置中，训练模型的准确性部分取决于辅助路径保持活跃。

A-C
从原型到概念
在本项目的早期阶段，我们尝试直接改编 ProtoTS 的结构以改进上述三个方面，但每次尝试在恢复可解释性的同时保持准确性的尝试都失败了。回想起来，这是有道理的：将每个原型限制为单一的规范预测曲线对于多变量时间序列预测来说太具限制性，其中“原型”需要共同表示目标曲线和可能产生它的每个有意义的跨通道条件。
我们还考虑将多个 prototype_value 曲线附加到每个原型以增加表达能力，但这引发了一个新问题：需要多少原型才能覆盖每个现实场景？即使是一个广泛的原型，如“夏夜”，在正交轴上也有许多变体——“是否下雨”、“下班高峰期还是深夜”、“热得不舒服还是可以忍受”——并且枚举每种组合呈指数级增长。ProtoTS 的树分裂机制通过按需增长新原型部分解决了这个问题，但每次分裂都会增加参数并使训练复杂化，所需的原型数量仍然随着特征轴的数量组合增长。
正是这个瓶颈引导我们走向基于概念的框架。一个真实的多变量任务所需的看似无界的原型数量，可以被一个更小的概念集所取代，这些概念的开/关组合有效地跨越了相同的空间。每个概念集中在一两个特征通道上，这使得训练和事后检查都大大容易，同时表达能力仍然很高：即使是 20-30 个精心挑选的概念也可以组合起来描述数以万计的不同场景——这种相同的覆盖范围基于原型的方法只能通过不受控制的树增长来实现。

附录 D
损失函数组成
我们在等式 (8) 中描述了七个损失项中的每一个：
预测损失。
ℒ_forecast 是 𝐘̂{L+1:L+H} 和 𝐘{L+1:L+H} 之间在 z-score 目标上的平均 L_1 误差。这是驱动模型预测曲线向真实目标靠拢的标准损失项。
概念损失。
ℒ_concept^lb、ℒ_concept^fc 和 ℒ_concept^gfc 分别表示回溯、预测子窗口和全局预测瓶颈的概念损失。每个都是预测概念 logit 和 LLM 导出的二进制标签之间的二元交叉熵，在概念上（对于子窗口瓶颈，在 N_sw 个子窗口位置上）取平均。
边界平滑损失。
由于解码器逐个子窗口预测目标子窗口并连接结果，子窗口边界处的转换可能是不连续的。我们惩罚 N_sw-1 个边界位置处相邻预测时间步的 L_1 差异：
ℒ_boundary = (1 / (N_sw - 1)) Σ_{k=1}^{N_sw-1} |ŷ{L+kT_sw} - ŷ{L+kT_sw-1}|. (9)
概念崩溃损失。
如果 p_c 在批次中变得接近常数，CEM 门 𝐜̂_c = p_c 𝐞_c^+ + (1-p_c) 𝐞_c^- 会退化：生成的 𝐜̂_c 对于每个输入几乎相同，因此概念不携带每个样本的信息，解码器无法使用它。尽管概念损失已经惩罚了错误的概率分配，但我们添加了一个明确的基于方差的惩罚以防止这种崩溃：
ℒ_collapse = Σ_c max(0, σ_min - Var_batch(p_c)), (10)
其中 σ_min 是最小方差阈值。任何批次激活方差低于 σ_min 的概念都会产生与其低于阈值的程度成正比的正惩罚。
残差正则化损失。
如模型架构部分所述，在概念瓶颈旁边添加了一个低维残差通道，以补偿静态概念嵌入引入的表达能力损失。为了防止解码器过度依赖此通道并绕过概念瓶颈，我们在残差向量上添加了 L_2 惩罚：
ℒ_residual = ‖𝐫‖_2^2, (11)
其中 𝐫 是残差通道输出。权重 α_res 直接控制预测准确性和可解释性之间的权衡。

滑动窗口的提取回溯长度 L=96 小时，预测期 H=96 小时，步长为 6 小时。
虽然训练使用 1 小时的滑动窗口步长，但 LLM 概念标记谓词以 6 小时的较粗步长进行评估，以使整个概念提议阶段更高效。具体来说，对于任何回溯窗口在同一 6 小时块内开始的六个连续训练片段组，我们计算一次二进制概念标签，并在所有六个片段中重用它们。
这种设计有两个动机。首先，它将谓词评估次数减少了 6 倍，当训练集包含数十万个窗口时，保持离线标记过程可行。其次，更重要的是，它与所提出概念的自然时间连贯性相匹配：它们中的大多数（例如，is_history_cold、is_forecast_humid、is_winter_block）描述了至少持续几个小时的条件，因此它们的真实二进制状态很少在 6 小时窗口内翻转。
