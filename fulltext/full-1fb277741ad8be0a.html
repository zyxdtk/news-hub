中文摘要： 本文提出DreamerAD，一种基于潜在世界模型的自动驾驶高效强化学习框架。通过将扩散采样从100步压缩至1步，实现80倍加速，同时保持视觉可解释性。该方法利用视频生成模型的去噪潜在特征，结合快捷强制、自回归密集奖励建模和高斯词汇采样，有效提升驾驶安全性和规划性能。在NavSim v2上达到87.7 EPDMS，创最先进水平，证明潜在空间RL对自动驾驶的有效性。

策略成本高昂且存在不可接受的安全风险。传统基于模拟器的方法引入了额外的模拟到现实的差异。 基于视频生成的世界模型提供了一种有前景的替代方案，通过想象式策略学习实现 [16, 15]。然而，现有的像素级扩散模型 [34] 面临两个关键瓶颈：(1) 多步采样（100 步）导致严重的推理延迟，与 RL 的交互需求不兼容；(2) 像素级目标优先考虑视觉保真度，而非对驾驶安全至关重要的空间和动态理解。 为解决这些挑战，我们提出 DreamerAD，一个在视频生成模型的潜在想象空间内完全执行 RL 的潜在世界模型框架。我们的关键洞察是利用视频生成模型的去噪特征构建潜在世界模型。具体而言，如图 2 所示，我们发现 Video DiT 的去噪潜在特征展现出良好的空间信息和语义一致性。基于此潜在世界模型，DreamerAD 训练一个用于 RL 训练的奖励模型。 具体而言，我们通过在 NavSim [5] 数据集上对自回归扩散世界模型进行微调，开发了一个高效的推理世界模型，采用快捷强制机制，将世界模型采样从 100 步压缩至单步。这实现了潜在空间内的低延迟 RL 训练，同时保持特征可无损解码为高保真 RGB 帧，以确保严格的可解释性。 其次，我们构建了一个基于潜在世界模型模拟的 RL 算法，以进一步提升规划性能。具体而言，如图 1 所示，我们设计了一个奖励模型，以每个动作条件下的潜在特征作为“想象输入”，对每个动作步骤进行评分，提供密集的质量评估和奖励分配。基于该奖励模型，我们提出一种基于高斯词汇采样的 GRPO 优化方法，从轨迹词汇的邻域中选择候选轨迹。与先前工作 [31] 中的随机高斯点采样相比，基于邻域词汇的采样确保了有效的策略探索，实现了更物理合理且更平滑的轨迹规划。 我们在 NavSim v2 闭环基准上验证了 DreamerAD。DreamerAD 在 NAVSIM v2 上达到 87.7 EPDMS，确立了新的最先进水平。 2 相关工作 2.1 自动驾驶世界模型 以视觉为中心的世界模型 [2, 9] 因其传感器灵活性和数据可访问性而受到关注。早期方法将预训练的扩散模型（如 Stable Diffusion [25]）适应到驾驶场景，但通常局限于短期或低分辨率生成，且缺乏集成规划能力 [8]。 近期方法将视频生成作为核心模拟组件。GAIA-1 [13] 采用自回归场景生成，而 DriveDreamer [26] 和 MagicDrive [8] 将扩散模型条件于 BEV 地图和 3D 边界框。DriveArena [32] 和 DrivingSphere [29] 进一步通过将世界模型视为动作条件模拟器来推进闭环模拟。基于体素的世界建模方法探索了 3D 几何和时空动态 [36]。大型基础模型如 Cosmos [1] 实现了高真实感，但计算成本高昂。 尽管取得了这些进展，现有世界模型仍因多步扩散推理延迟和在分布外动作下易产生幻觉而难以支持高频 RL 训练。我们的工作通过降低采样复杂度和引入探索受限的强化学习来解决这些问题。 2.2 世界模型中的强化学习 降低现实世界试错成本推动了在世界模型想象空间内进行 RL 训练。ReSim [30] 和 OmniNWM [17] 使用轨迹条件视频合成进行评估反馈。Dreamer 系列 [10, 11, 12] 执行多步潜在展开优化。 在自动驾驶领域，RAD [7] 采用 3D 高斯点云世界建模，而 AD-R1 [28] 探索基于占用表示的 RL。然而，这些方法在效率、标注依赖性和潜在世界模型特征利用方面存在局限。 我们的框架完全在潜在想象空间内执行 RL，直接从内部表示生成密集奖励信号，无需显式 3D 监督即可实现高效且精确的策略优化。 3 方法 3.1 总体框架 DreamerAD 的总体流程包含两个紧密耦合的组件：带潜在奖励建模的世界模型 和 带词汇采样的强化学习。 第一个组件在潜在空间内完全执行基于想象的轨迹评估。如第 3.2.1 节所述，快捷强制世界模型（SF-WM）通过单步潜在展开预测未来场景表示。自回归密集奖励模型（AD-RM）随后自回归地评估这些预测的潜在状态，生成涵盖八个驾驶指标的逐步奖励信号。 第二个组件通过从预定义的高质量词汇中采样的轨迹来优化策略。如第 3.3 节所述，高斯加权词汇采样确保探索保持在物理合理的轨迹流形内，防止 RL 训练中的世界模型幻觉 [16]。 图 3 ：DreamerAD RL 训练架构概览。 RL 训练流程包含三个主要阶段：1) 策略生成与采样（黄色）：从历史输入生成基础策略，并基于预定义词汇采样一组候选轨迹。2) 通过世界模型进行 RL 训练（绿色）：对采样轨迹执行潜在展开以想象未来状态。从这些潜在特征解码逐步奖励并聚合为时间感知的密集奖励。值得注意的是，我们的潜在表示可无损解码为 RGB 帧，用于事故分析或可视化，但在训练期间为效率考虑会绕过解码。3) 策略优化（蓝色）：计算密集奖励的组优势，使用 GRPO 算法优化策略网络。 3.2 带潜在奖励建模的世界模型 本节介绍我们的潜在世界建模框架，旨在联合捕捉未来场景动态和轨迹演化。我们首先介绍用于构建潜在空间预测表示的基础世界模型，然后描述显著减少采样步骤同时在低步推理下保持预测保真度的 SF-WM，最后描述用于轨迹评估和潜在空间奖励建模的 AD-RM。 3.2.1 快捷强制世界模型 基础世界模型。 为支持想象式训练，我们采用 Epona [34] 作为基础世界模型。Epona 是一个基于流匹配的自回归扩散模型，统一了视频生成和轨迹规划，能够根据动作控制预测未来视频。 给定历史观测 O ∈ ℝ^{B×P×H×W×3} 和动作 A ∈ ℝ^{B×P×3}，视觉自动编码器和动作编码器将其压缩为潜在嵌入： Z = DCAE-encoder(O) ∈ ℝ^{B×P×L×C}, a = MLP(A) ∈ ℝ^{B×P×3×D} (1) 然后图像嵌入 Z 经过时间投影模块处理，得到 Z_proj ∈ ℝ^{B×P×L×D}。沿空间维度拼接投影的视觉标记和动作嵌入，形成统一的潜在表示 E ∈ ℝ^{B×P×(L+3)×C}。 E 的最后一帧用作紧凑条件 F ∈ ℝ^{B×(L+3)×C}，供流匹配生成器预测下一帧潜在 ẑ_next ∈ ℝ^{B×L×C} 和未来轨迹 τ_pred ∈ ℝ^{B×T×3}。 模型使用真实下一帧潜在 z_next 和未来轨迹 τ_gt 联合训练。 由于原始模型在 NuPlan 数据集上以 10 Hz 运行，而 NavSim 环境以 2 Hz 运行，我们首先在 NavSim 上微调世界模型以适应 2 Hz 生成间隔，然后进行步长蒸馏。 快捷强制世界模型。 基础模型如 Epona 每帧需要 100 步采样，对高频 RL 训练造成严重的延迟。为解决此限制，我们提出快捷强制世界模型（SF-WM），将采样压缩至 1-4 步，同时保持预测保真度——实现高达 80× 的推理加速。 受快捷模型 [6] 和扩散强制 [3] 启发，SF-WM 引入递归快捷强制机制，将连续流过程离散化为由 2 的幂定义的多分辨率步空间。模型通过步嵌入条件于信号水平 t 和请求的步长 d。 在修正流框架中，给定条件潜在特征 Z，我们定义插值： x_t = t x_1 + (1-t) x_0, v = dx_t/dt = x_1 - x_0. (2) 其中 x_0 ∼ 𝒩(0, I) 且 x_1 表示干净数据的潜在表示。 令 K_max 为最大采样步数，d_min = 1/K_max。在训练期间，步长采样为： d ∼ 1/𝒰({1,2,4,8,…,K_max}), t ∼ 𝒰({0,d,2d,…,1-d}). (3) 训练采用教师-学生蒸馏方案。对于 d = d_min，模型使用标准流匹配损失训练。对于 d > d_min，使用两个教师半步： v_1 = ϕ_θ(x_t, t, d/2), (4) x_mid = x_t + v_1 d/2, (5) v_2 = ϕ_θ(x_mid, t+d/2, d/2). (6) 目标速度定义为： v_target = { x_1 - x_0, d = d_min, sg((v_1 + v_2)/2), otherwise. } (7) 优化目标为： ℒ(θ) = 𝔼_{x_0,x_1,t,d} [ω(t) ‖ϕ_θ(x_t, t, d) - v_target‖^2], (8) 其中 ω(t) = 0.9t + 0.1 平衡全局结构和局部细节保留。 在推理时，SF-WM 可条件于期望的步长（如 d=1/4），仅使用 1-4 步采样生成预测。如图 4 所示，SF-WM 在单步推理下保持清晰的自回归预测质量，而原始模型则出现严重的误差累积和模糊。 (a) Epona：累积误差随时间增加，导致单步推理时场景模糊。 (b) 我们的方法：单步推理时各时间步保持视觉清晰。 图 4 ：Epona 和快捷强制世界模型的单步推理可视化。 3.2.2 自回归密集奖励建模 奖励标注与标记。 在近专家演示上训练的世界模型在评估分布外轨迹（具有大空间偏差）时易产生幻觉。为缓解此问题，我们构建了一个空间受限的探索词汇。 具体而言，从 8192 条轨迹的大词汇中，我们筛选出位于人类驾驶轨迹邻域内的候选轨迹。我们提取每条轨迹的终点状态 (x,y,θ) 并与对应真实轨迹的终点状态进行比较。仅当满足横向和纵向约束 |Δy| ≤ y_thresh 和 |Δx| ≤ x_thresh，以及航向偏差 Δθ = min(|θ_vocab - θ_gt|, 2π - |θ_vocab - θ_gt|) ≤ θ_thresh 时，轨迹才被保留。 我们设置 x_thresh = 10 m, y_thresh = 5 m, θ_thresh = 20°。 为避免候选集中过度集中，我们进一步采用基于横向偏移的均匀采样策略。筛选后的轨迹按 |Δy| 排序，并选择等间距样本以获得 K 个代表性轨迹，形成最终词汇 Γ = {τ^0, τ^1, ..., τ^K}，其中 K=256。这确保奖励模型观察到具有不同偏差水平的轨迹。 筛选后的轨迹在 NavSim PDM 模拟器中进行评估，以获得八个奖励维度 r = {r_nc, r_dac, r_ddc, r_tlc, r_ep, r_ttc, r_lk, r_hc}。 与仅评估完整轨迹得分的先前工作不同，我们在 0 到 4.0 秒（步长 0.5 秒）的多个预测时域下计算奖励，生成八个时间步的得分 {r^1, r^2, ..., r^8}。这使奖励模型能够捕捉轨迹整体质量和奖励的时间演化，促进短期安全与长期规划之间的权衡。 奖励模型训练。 奖励模型参数化为一个神经网络，使用历史上下文自回归预测轨迹奖励，公式化为： r_pred^t = RewardModel(traj_{0:t}, his_{-3:t}), (10) 其中 t ∈ {1, ..., 8} 表示预测时域，t < 0 表示历史时间步。 在推理时，第 3.2.1 节中的世界模型被冻结，并自回归预测潜在未来表示 {ẑ_1, ..., ẑ_t}，条件于轨迹输入 traj_{0:t} 和潜在上下文 Z。历史信息通过多层感知机编码： his_{0:t} = his_enc(concat[z_{-3}, z_{-2}, z_{-1}, z_0, ẑ_1, ..., ẑ_t]). (11) 由于潜在维度 L=512 较高，可学习的查询压缩机制将其降至 l=32。为区分八个奖励维度，我们初始化八个独立的可学习基础 Q_base ∈ ℝ^{8×D}。动态轨迹和时间信息编码为： C_dyn = MLP_traj(traj_{0:t}) + Emb_step(t), (12) 奖励查询定义为： Q_r = Q_base + C_dyn. (13) 奖励表示通过交叉注意力后接 MLP 头解码： r_pred^t = MLP(Cross-Attention(traj_{0-t}, his_{-3:t})). (14) 训练使用二元交叉熵损失监督： ℒ_sup = ∑_{k=1}^8 ω_k · γ(t) · BCEWithLogits(r_pred, r), (15) 其中 ω_k 和 γ(t) 分别表示奖励类型和时间加权因子。 3.3 带词汇采样的强化学习 本节介绍在潜在想象空间中进行轨迹优化的强化学习框架。我们设计了一种以安全为优先的奖励公式，将安全合规性和任务性能信号分离，引入密集时间奖励聚合以减少奖励稀疏性，并采用高斯引导的词汇采样以实现平衡探索。策略优化采用基于 GRPO 的演员训练方案，结合行为克隆和 KL 正则化以实现稳定训练。 RL 的奖励设计。 传统强化学习方法通常通过简单的加权求和组合奖励，可能忽视不同奖励组件的相对重要性。在自动驾驶中，安全被视为首要优化约束。 遵循 NavSim [5]，我们将八个奖励维度划分为安全项 r_safe = {r_nc, r_dac, r_ddc, r_tlc} 和任务性能项 r_task = {r_ep, r_ttc, r_lk, r_hc}。安全合规奖励采用对数sigmoid聚合： L = ∑_{i∈safe} w_i log(sigmoid(r_i)), (16) 任务奖励计算为： S = log(∑_{j∈task} w_j r_j). (17) 总奖励定义为： r_total^t = L + S = log(∏_i r_i^{w_i} × ∑_j w_j r_j), (18) 其中 t ∈ {0,1,…,7}。对数融合机制确保安全违规主导奖励信号，因为碰撞事件会使安全项趋近于零，从而推动 log(r_i) 趋近负无穷。 为缓解轨迹级评分中的奖励稀疏性，我们引入步级密集奖励进行时间奖励分配。与仅评估完整轨迹结果不同，我们保留中间预测时域的轨迹质量信号。最终奖励计算为： r_final = ∑_{t=1}^8 w_t · r_total^t, (19) 使模型能够识别轨迹中的退化点并更好地指导优化。 词汇采样。 先前的随机高斯探索方法 [31, 38] 通常因确定性流匹配采样而遭受动态不一致或有限的多模态覆盖。为解决此限制，我们提出一种基于高斯的词汇采样策略，以实现更可靠和多样化的轨迹探索。模型首先提取历史和环境潜在表示，生成基线轨迹 τ_act ∈ ℝ^{B×T×3}。以 τ_act 为均值和固定方差 σ²，构建高斯分布： τ ∼ 𝒩(τ_act, σ²). (20) 由于对数高斯似然与负马氏距离成正比，轨迹候选通过计算词汇轨迹 Γ ∈ ℝ^{N×T×3} 与策略轨迹之间的马氏距离进行排序： d(x, τ_act) = ∑_{t=1}^T ∑_{i=1}^3 (x_{t,i} - τ_{act_{t,i}})^2 / σ_{t,i}^2. (21) 采用混合采样策略，选择 g_1 条轨迹根据 softmax 概率进行判别，g_2 条轨迹从高斯邻域进行局部探索，生成采样轨迹集 τ_sample ∈ ℝ^{B×G×T×3}，其中 G = g_1 + g_2。采样轨迹由奖励模型评估，获得最终奖励 r_final^i。 策略优化。 策略学习使用 GRPO 算法。归一化组优势计算为： A_i = (r_final^i - mean(r_final^{1..G})) / √(var(r_final^{1..G})). (22) 为约束策略更新，使用重要性比率： ρ = exp(log π_θ - log π_old). (23) 演员损失为： L_actor = 𝔼[ max(-A_i ρ, -A_i clip(ρ, 1-ϵ, 1+ϵ)) ]. (24) 我们进一步使用行为克隆损失 L_bc = ‖τ_act - τ_gt‖_1 和 KL 散度损失 L_kl = D_KL(π_θ ∥ π_ref) 进行正则化。最终目标为： L_total = L_actor + L_bc + L_kl. (25) 我们还评估了 Flow-GRPO [23]，一种专为流匹配架构设计的 RL 方法，详细讨论见补充材料。 4 实验 4.1 数据集 我们在 NavSim 数据集上评估 DreamerAD，该数据集基于 nuPlan 构建，提供来自 8 个摄像头的环视图像和高质量 LiDAR 点云。 数据集分为 1,192 个训练场景和 136 个测试场景。在采集过程中，排除了静态场景和恒速驾驶场景，以保留高挑战性场景。NavSim 提供闭环评估的模拟环境。NavSim v1 采用预测驾驶员模型得分（PDMS）作为评估指标，聚合了多个驾驶相关标准，包括无碰撞（NC）、可行驶区域合规（DAC）、碰撞时间（TTC）、舒适度（Comf.）和自车进展（EP）。 在此基础上，NavSim v2 引入了扩展的 PDM 得分（EPDMS），包含驾驶方向合规（DDC）、交通灯合规（TLC）、车道保持（LK）、历史舒适度（HC）和扩展舒适度（EC）。指标介绍和计算方法详见补充材料。 4.2 实现细节 我们采用在 NuPlan 和 NuScenes 数据集上从头训练的 Epona 作为基础世界模型。所有图像调整为 512×1024。所有训练运行在 32 个 NVIDIA H20 GPU 上。 为便于在 NavSim 数据集上进行生成和规划，我们格式化 NavSim 数据，并应用 AdamW 优化器，批量大小为 128，学习率为 3×10⁻⁵，权重衰减为 5×10⁻²。 微调过程在约一天内完成 5 个 epoch。 在快捷强制世界模型训练阶段，我们使用相同参数在三天内训练 12 个 epoch。 对于奖励模型训练，我们应用批量大小 320 和学习率 3×10⁻⁴，训练 12 个 epoch，约一周完成。 在强化学习阶段，我们使用批量大小 196 和学习率 1×10⁻⁴，在约 8 小时内微调 2 个 epoch。 推理速度在单个 NVIDIA H20 GPU 上测量。 我们设置 VisDiT 采样步数为 1，TrajDiT 采样步数为 20，贯穿所有实验。 4.3 主要结果 如表 1 所示，我们的方法在 NAVSIM v2 闭环规划基准上实现了最先进性能。我们的方法达到 87.7
