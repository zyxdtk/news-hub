WeightLoop：基于实验反馈的权重空间编程

原标题：WeightLoop: Weight-Space Programming with Experimental Feedback

中文摘要： WeightLoop是一个将实验反馈转化为已部署预测器持久更新的框架。GPT-6 Astra一次性构建可复用的参数编辑程序，该程序在新测量数据到达时识别预测差异、验证候选编辑并写回模型。编辑器保持固定而预测器持续演化，无需额外LLM调用或梯度重训练。在细胞扰动实验的离线回放中，定向编辑在八个端点-预算设置中的七个改善了平均排序效用，并在三个序列发现任务中均改善了最终发现。该框架将权重空间编程与递归自我改进循环结合，使实验证据成为模型更新的直接驱动力。

WeightLoop：基于实验反馈的权重空间编程

作者： Mengran Li（香港科技创新研究院）、Bo Li（澳门大学）、Weijing Zhao（澳门大学）、Chengyang Zhang（四川大学）、Boyu Zhang（中山大学）、Jinfeng Xu（英属哥伦比亚大学）、Zelin Zang（香港科技创新研究院）、Victor C. M. Leung（英属哥伦比亚大学）、Stan Z. Li（西湖大学）

摘要

权重空间编程（WSP）表明语言模型可以推理并重写神经网络权重；递归自我改进（RSI）则推动了反馈驱动的改进机制。指导实验的模型接收具体反馈：完成的测定揭示预测误差并告知下一步测试内容。我们提出WeightLoop框架，将实验反馈转化为已部署预测器的持久更新。GPT-6 Astra检查任务规范和模型实现，然后编写一个有界的、可复用的参数编辑程序。当新测量数据到达时，该程序识别预测差异，使用观测结果验证候选编辑，并将选定更改写回原始模型。编辑器保持固定而预测器不断演化，无需额外LLM调用或梯度重训练即可实现重复更新，同时保留原始推理接口。在离线回放中，定向编辑在八个端点-预算设置中的七个（相对随机编辑为全部八个）改善了平均排序效用，并在三个序列任务中改善了平均最终发现。WeightLoop将WSP与RSI启发的改进循环连接起来，使实验证据成为模型变化和后续决策的直接驱动因素。

关键词： 科学推荐、模型编辑、实验反馈、权重空间编程

1. 引言

实验不仅测试预测，还产生可以改变下一个决策的证据。在实验决策制定中，预测器对候选干预进行排序，但其效果只有在测量后才变得已知。历史数据提供可复用的知识，但新目标可能只有几十个功能测量。这些结果可能暴露原本有用的模型中的任务特定错误。因此，挑战不仅在于评估预测，还在于将证据纳入已部署的预测器，使后续决策反映已学到的内容。

细胞扰动研究和虚拟细胞提供了一个具有挑战性的例子。

从模型编辑到权重空间编程

模型编辑研究关注对神经参数的定向修正。Takehi等人引入了权重空间编程（WSP），展示了语言模型在指定设置下根据自然语言目标解释和重写权重。这开启了一种可能性：当实验证据到达时，LLM能否编程已部署模型应如何变化？除了产生一个参数修正之外，这样的程序可以将连续测量与模型的未来行为连接起来。

改进循环所在之处

递归自我改进（RSI）推动了如STOP等系统，其改进程序可以自我修正。在WeightLoop中，序列是具体的：LLM一次性编写编辑器；每个返回的测定批次让该编辑器修正预测器；修正后的预测器推荐下一批次。在此循环中编辑器代码和LLM保持固定。新的测量结果确定参数变化，无需另一次LLM调用或梯度重训练。科学预测器是此改进循环的对象。

WeightLoop工作流程

给定任务目标和模型，GPT-6 Astra识别任务相关的可变参数并编写一个有界的编辑程序。当反馈到达时，程序评估预测与测量之间的差异，构建候选更改，并选择经验证的更新。更改被写入检查点，通过其原始推理接口重新加载。更新后的预测器指导下一个决策，过程随测量到达而重复（图1）。因此，反馈改变了模型本身，而不仅仅是调整一个推荐列表。

我们研究两个互补的设置：单轮排序和序列发现。细胞生长、迁移、自噬和LDL摄取测量提供了跨目标的具体反馈。在这里，生物学为测试可复用的编辑工作流程提供了可测量的结果。神经、线性和基于树的预测器为同一工作流程提供了不同的参数结构。记录的测量使离线回放成为可能，以测试更新是否改善后续决策并在检查点写回和重载后仍然可用。总之，这些实验展示了WSP如何将返回的测量转化为持续的模型改进来源。

2. WeightLoop

2.1. 固定编辑器，更新预测器

GPT-6 Astra从任务目标、模型实现、参数结构和可用反馈构建编辑器。它产生一个可执行的编辑器，指定可变参数、候选更新、验证规则和模型保存。编辑器通过重复的数值执行使用测量支持来更新预测器，无需额外LLM调用。对于原始参数θ₀、编辑器ℰ_ℐ和累积支持Sₜ = {(gᵢ, xᵢ, yᵢ)}记录身份、输入和测量结果：

(1) Δₜ = ℰ_ℐ(θ₀, Sₜ), θₜ = θ₀ + Δₜ, Aₜ₊₁ = 𝒟(f_θₜ)

其中𝒟应用剩余候选、预算和决策规则；ℐ之外的Δₜ,ⱼ = 0。更新在支持训练记录上构建，在支持验证记录上选择，然后在所有支持上重建。无合格改进则Δₜ = 0。每次更新从θ₀开始，因此补丁不会复合。只有观测结果进入支持；未测量候选和永久测试集的结果被排除。

一个具体的程序设计选择

神经编辑器将功能输出权重暴露为其更新接口。模型代码将可复用的分子编码器与线性功能读出分离：更改一个读出权重改变该特征的贡献，同时保留表示和RNA辅助分支。此结构还使候选更改可以从缓存的激活中精确计算，因此编辑器可以在不反向传播的情况下测试单个连接。其诊断询问是否弱化连接改善测量基因的排序；其验证结合成对排序损失与顶预算效用。

对于系数和叶值更新，实现的目标是残差预测误差。因此，程序构建将可变接口和验证标准与模型结构和任务目标绑定。一旦这些选择被编码，测量在每次执行时确定受影响的坐标和接受的参数值。

2.2. 神经输出权重编辑

ReLU MLP编码静态GO、scGPT和MAP-KG特征，以及可用性指示器，得到h_ϕ(x_g) ∈ ℝ¹²⁸。其原始拟合使用功能标签和历史RNA辅助监督；候选特定的扰动RNA不是推理输入。以测定单位表示的功能预测为：

(2) f_θ(g) = s_y{w^⊤h_ϕ(x_g) + b} + μ_y

只有w的128个条目是可编辑的。编码器、偏置、输入变换、原始25标签输出缩放器(μ_y, s_y)、RNA头和源参数保持固定；编辑重新加权现有表示。

诊断、选择和写入

反馈由新测量的基因效应组成。如果隐藏特征对测量效应弱的基因给出高分，衰减其输出连接可以减少排序错误。编辑器针对观测测量测试此可能性。

使用原始25标签输出缩放器，令pᵢ = (f_θ(gᵢ) - μ_y)/s_y和ỹᵢ = (yᵢ - μ_y)/s_y。令aᵢⱼ = |ỹᵢ - ỹⱼ|和sᵢⱼ = sgn(ỹᵢ - ỹⱼ)。支持损失为：

(3) ℒ(p, ỹ) = Σᵢ<ⱼ aᵢⱼ log{1 + exp[-sᵢⱼ(pᵢ - pⱼ)]} / Σᵢ<ⱼ aᵢⱼ

逻辑比较遵循learning-to-rank公式。我们缓存hᵢ并通过将wⱼ减半来探测每个连接，这将标准化预测精确改变-0.5wⱼhᵢⱼ。其诊断增益是ℒ的相应减少。高于10⁻¹²的顶部正增益确定至多k个坐标Sₖ用于六个更新设置：k ∈ {4, 8, 16}和α ∈ {0.25, 0.5}：

(4) w'ⱼ = wⱼ(1 - α·𝟏[j ∈ Sₖ])

等标签对权重为零；全并列集合损失为零。诊断和更新并列遵循固定顺序。三个基于身份的支持折叠选择最低平均验证损失，受限于非递减平均验证效用（单轮排序为BU@10）。每个折叠仅使用其训练基因诊断坐标。接受的更新在所有反馈上重建并写入模型的输出权重向量。其效果是基因特异的：δf(g) = s_y Σⱼ δwⱼ hⱼ(x_g)，因此可以在保留学习表示的同时改变排序。

匹配对照在坐标间排列相同的诊断更新。对于给定的支持集和更新设置，它们保留更改的数量和范数，并接受相同的六设置验证机会。单轮排序使用三个固定排列；序列发现使用一个，可能获取不同的后续支持。

2.3. 系数和叶值编辑

使用标准化反馈ỹᵢ和原始预测p₀ᵢ，定义残差rᵢ = ỹᵢ - p₀ᵢ。岭回归添加δw = (X_c^⊤X_c + λI)⁻¹X_c^⊤r_c和δb = r̄ - x̄^⊤δw，其中中心化使用拟合支持，λ = mγ，γ ∈ {0.1, 1, 10, 100}。XGBoost保留所有300个树结构并修改每个支持的预测叶：

v'_ℓ = v_ℓ + α Σᵢ∈ℓ rᵢ / [300(n_ℓ + 5)]

其中α ∈ {0.1, 0.25, 0.5}。这里m是支持大小；n_ℓ计数到达叶ℓ的支持记录。不支持的叶保持不变。

三折支持MSE选择这些更新；无改进保留原始模型。这些有监督的分析算子在保留输入/输出变换和推理代码的同时更改系数或原始叶值。

3. 评估与结果

我们使用公共功能筛选评估单轮排序和序列发现。编辑器设计使用DepMap实验；所得规则对HL60和序列评估固定。每个预测或批次选择在其评估结果可用之前进行。表格呈现匹配反馈预算下的完整端点-预算网格。

3.1. 单轮排序

单轮实验询问一次反馈更新是否改善后续排序。涵盖来自DepMap 24Q4的HepG2/Jurkat负Chronos效应、HL60增殖和血清梯度迁移抑制。每个端点五个基因分区和两个种子给出40个初始n=25模型。反馈是对应n=100训练集中但不在初始25之外的75个基因；查询基因从两者中排除。所有六个分支共享查询池。现有n=100参考和初始模型各拟合1600次更新；编辑使用额外测量维护n=25模型。

对于预算B = 20, 50，令d_r为在所有B个位置上归一化的1/log₂(r+1)。我们报告：

(5) U_B = Σ_{r=1}^{B} d_r y_{π_r}, BU_B = (U_B - ȳ)/(U_B^{oracle} - ȳ)

其中零是同池随机期望，一是oracle。配对摘要在研究的每个基因分区内平均种子。

编辑效用在所有八个设置中超过随机，在七个设置中优于原始（表1）。HepG2在两个预算下的所有五个配对折叠中均有改善，将平均增益与任务内一致改善联系起来。

追踪一个推荐

在图1的HepG2示例中，编辑器选择k=16, α=0.5：验证损失从0.54235降至0.53837，BU@10从0.43363升至0.47502。图1显示了两个实现的权重变化。Top20保留19个基因，添加SNRPB，移除GEMIN2；查询BU@20从0.604554升至0.621258（BU@50：0.559769→0.560715）。

3.2. 序列发现

序列发现复用15个初始25标签模型用于LC3/NBR1自噬通量和HuH7细胞中脂蛋白丰富培养基减少的LDL摄取：三个端点、五个基因折叠和一个种子。不变、定向编辑和排列编辑策略各获取五批20个基因。每批在其测量可用之前选择。后续编辑仅使用该策略获取的反馈；初始25标签影响θ₀但不重新进入Sₜ。每个补丁从θ₀重建，在B = min(5, n_validation - 1)处有验证保护。

对于从候选池C获取的集合A_K，发现为：

D_K = (Σ_{g∈A_K} y_g - Kȳ_C) / (Σ_{g∈Top_K(C)} y_g - Kȳ_C)

其oracle归一化随K变化，因此策略在相同获取计数下比较。永久集预测在所有45条轨迹完成后评估，与查询池中的发现分开。

编辑选择在所有三个任务中改善平均D₁₀₀相对于两个对照，分别有4/5、4/5和3/5的正配对折叠（表2）。相同的第一批次将这些差异定位于后续反馈驱动的选择中。永久集BU@50分别增加0.0254、0.0098和0.0096（图2e）。在75个定向更新中，56个更改权重，每个至多16个；最终更新仅用于永久集预测。

配对面板将这些聚合改善与实际模型更新联系起来。发现测量选择用于测定的基因的价值，而永久集效用测量从未提供反馈的基因的排序。它们的联合平均改善将选择循环与超出获取集合的预测联系起来。编辑计数面板使机制可见：单个反馈批次可以保留原始模型或选择不同数量的坐标。因此，固定程序将变化的证据转化为自适应模型状态，而不是在每个批次后应用相同的扰动。

持久模型更新

在具有3,604,535个网络参数的已部署预测器中，HepG2更新仅更改16个权重（0.00044%），并在原生检查点重载后精确重现所有914个编辑预测。这些是128个功能输出权重中的16个；网络计数包括编码器和RNA头。两者保持不变，单独存储的源适配器也是如此。重新排序的查询也重现所有保存的分数，单基因推理检查通过原始输入/输出变换。

因此，更新在预测器中持久存在，并通过原始推理接口为后续查询服务。

4. 结论

WeightLoop将实验反馈转化为持久模型更新。固定的、LLM构建的编辑器从观测测量中选择参数变化，更新后的预测器指导下一个决策。排序、序列获取和多种参数接口展示了WSP如何通过原始预测接口将积累的科学证据与未来实验选择连接起来。

伦理考虑

本研究使用公共功能筛选测量，没有新的人类受试者实验或个人数据收集。推荐指导研究测定；生物效力需要在预期设置中进行验证。保留原始模型使参数更新可逆，并支持可追溯的部署。
