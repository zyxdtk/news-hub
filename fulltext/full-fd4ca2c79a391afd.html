摘要
摘要：
语言推理允许基础模型在困难问题上投入更多测试时计算资源，例如那些需要分解、约束跟踪和预测未来后果的问题。这种机制是否能改善机器人操作仍不清楚，因为长时序任务需要跟踪部分进度、推理物体关系、从错误中恢复以及引导噪声低级策略。在本文中，我们研究视觉语言模型（VLM）是否可以被训练为直接用自然语言推理来指导低级操作策略。

我们引入了 $\mathcal{R}^3$，这是一个简单的后训练方案，可将现成的 VLM 转化为机器人推理器：它首先在专家生成的推理轨迹上对 VLM 进行中期训练，以初始化所需的推理风格，然后利用离线动作数据中的单步基于评分标准的强化学习（RL）来改进推理器。

与以往主要使用结构化轨迹作为辅助监督的机器人推理方法不同，$\mathcal{R}^3$ 训练自由形式的语言推理，为动作产生测试时指导。

我们在 Language Table 和模拟双臂杂货打包环境中实例化了 $\mathcal{R}^3$，这是两个用于研究机器人推理和长时序操作的受控测试平台。

$\mathcal{R}^3$ 改进了在未见任务上的探索和泛化能力，并在两个基准测试上均显著优于仅指令模仿学习基线。

我们的分析表明，自由形式的语言推理可以作为引导低级策略的测试时计算机制。

1 引言
自然语言推理提供了一种有效的机制，可以在更困难的测试问题上投入更多计算资源，并为广泛泛化提供了数据高效的方案。这种方案在包括视觉感知 [17, 9] 在内的许多领域都明显有用。更广泛地说，即使最终输出不是语言 [15]，语言推理也可以帮助模型分解问题、识别相关约束并做出可靠的预测。因此，机器人操作是基于推理的基础模型的自然领域：操作需要解释场景、理解物理约束、预测动作对轨迹未来部分的影响，并基于这种理解采取行动。人们可能期望，训练机器人策略在行动前进行推理，可以通过允许模型在问题实例上投入测试时计算来提高泛化能力。

针对机器人操作的推理已经受到了相当多的关注。最近的通用机器人策略和视觉-语言-动作模型，包括 ECoT [64]、SteerVLA [21] 和 MolmoAct [32]，结合了从以对象为中心的注释和短计划到深度感知感知标记和图像空间轨迹的中间表示。互补的方法通过语义接口公开通用策略：$\pi_{0.7}$ 可以在推理时通过子任务指令和视觉子目标进行引导 [28]，而 SARL 使用在线 RL 学习语言命令上的高级策略，通过长时序任务引导固定的 VLA [3]。然而，这些方法并没有训练在语言中被证明有效的自由形式自然语言推理。先前的工作表明，结构化推理监督可以改善接地和感知 [8]，但这些收益似乎主要来自训练时的监督：在用推理进行训练后，在测试时生成推理几乎没有提供额外的好处 [8, 18]。因此，现有工作将结构化 CoT 确立为辅助训练信号，但留下了灵活的语言推理是否可以作为花费测试时计算进行操作的机制，以及如何在现实中学习这样做的问题。

图 1：$\mathcal{R}^3$ 的两阶段训练。$\mathcal{R}^3$ 训练高级 VLM 用自然语言推理，并引导固定的低级机器人策略执行机器人操作任务。$\mathcal{R}^3$ 分两个阶段进行：阶段 I（中期训练）赋予现成的 VLM 产生低级策略有用指令所需的推理风格和行为。阶段 II（单步 RL）通过训练 VLM 生成与离线数据中专家指令相匹配的推理轨迹来进一步改进它。

我们研究如何训练视觉语言模型（VLM）使用自由形式的自然语言作为花费测试时计算进行机器人操作的机制。我们的主要思想是将专家数据转化为 VLM 推理的监督。给定一个场景、交互历史和专家动作，我们后训练 VLM 产生基于语言的推理，使其能够得出与专家语义相似的指令。然后，一个语言条件的低级策略接受该 VLM 的指令，并输出直接控制机器人的动作。

这个训练过程赋予了 VLM 推理能力，使其在测试时能够产生语言指导来引导低级策略。为了实例化这个想法并研究其背后的关键设计选择，我们专注于 Language Table [41] 环境和长时序杂货打包环境 [2]，它们为研究视觉推理、语言条件操作和长时序规划提供了受控设置，以及一个可靠遵循广泛指令的预训练可引导策略。

我们的方法 $\mathcal{R}^3$ 使用了受 LLM 后训练启发的两阶段方案，如图 1 所示。我们首先通过提示专家推理器引导低级策略同时记录其推理来生成多轮操作轨迹。这些轨迹包含部分进度、错误、恢复和替代动作选择，产生了模型必须基于过去交互而不是仅基于当前帧进行推理的上下文。阶段 I 在专家生成的推理轨迹上对 VLM 进行中期训练，无论轨迹是否成功，以初始化操作所需的推理风格。阶段 II 然后利用离线数据中的单步强化学习（RL）来改进这个推理器。在这里，我们不再假设可以访问专家推理轨迹：在场景和交互历史的条件下，模型生成推理和指令，当其指令在语义上与专家的指令匹配时，由基于评分标准的 VLM 评判器 [14] 给予奖励。这产生了一个实用的方案：使用有限的推理标记轨迹来初始化推理器，然后使用更多仅指令的离线数据来进一步改进它。

除了方法本身，这个框架还让我们研究机器人推理的关键设计选择：如何收集演示、以历史为条件、初始化推理器，以及哪种 RL 公式可以从动作监督中改进推理。

在实验上，我们发现 $\mathcal{R}^3$ 改进了在已见和未见 Language Table 任务上的高级引导，优于仅指令模仿学习。

同样，在杂货打包环境中，$\mathcal{R}^3$（仅 RL）优于无推理的仅指令模仿。我们的分析表明，$\mathcal{R}^3$ 学习了更深思熟虑的面向动作的推理行为：它比较替代选择，在不确定时重新检查场景和历史，并更渐进地选择下一步。

通过 VQA 诊断、与具有辅助推理监督的非推理策略的比较，以及对推理预算的受控干预，我们发现显式的推理时推理在泛化方面优于仅将推理作为训练时监督信号。总之，这些结果提供了证据，表明语言推理在因果上有助于任务性能，并作为有用的测试时计算。

2 相关工作
推理和测试时计算。
思维链推理和测试时缩放方法表明，语言模型可以通过在回答前花费额外计算进行推理来解决更难的问题 [59, 31, 56, 63, 52, 62]。类似的想法扩展到 VLM，其中文本依据、接地解释和视觉思维链轨迹改进了 VQA 和多模态推理 [39, 66, 48, 65]。然而，这些工作主要评估静态问答而不是长时序交互：关于静态图像的推理不必转化为具身动作。事实上，我们的实验表明，具有相似静态 VQA 性能的 VLM 在需要推理的长时序操作任务上引导低级策略时可能有很大差异。推理在编码和网络代理等交互领域也有帮助 [60, 10]，模型在这些领域调用工具、观察反馈并在线修改其行为 [47, 42, 51]。机器人操作的不同之处在于，推理必须接地于通常对高级推理器引起大量部分可观测性的低级控制器。

机器人操作中的中间结构。
机器人学长期以来在感知和动作之间使用中间结构。任务与运动规划将符号任务推理与几何运动规划相结合 [29, 22, 23]；视觉预见预测未来观测以进行规划 [20, 16]；分层或潜在规划方法从演示或游戏中学习可重用的技能 [40, 46]。基于语言的系统如 SayCan [1]、Inner Monologue [25] 和 Code as Policies [35] 使用 LLM 进行分解、反馈或程序合成，同时依赖外部技能、值或控制器。这些工作展示了在行动前推理的价值，但推理通常是符号的、预测性的、潜在的、模块化的或手工设计的。相比之下，我们训练 VLM 本身产生自然语言推理，在测试时引导一个冻结的低级语言条件策略。

通用机器人策略中的推理。
最近的通用机器人策略和视觉-语言-动作模型，包括 RT-2、Octo、OpenVLA、GR00T、GR-3 和 Gemini Robotics，使用在互联网数据上预训练的 VLM 主干，但不包含显式推理 [5, 54, 30, 4, 7, 53]。一些后续工作仅使用类似推理的信号作为训练时监督，例如接地推理轨迹、物体检测或语义子任务预测 [8, 27]。

其他工作还在推理时产生或消耗中间产物，如语言指导、计划、子任务、约束、可供性、历史摘要、视觉轨迹、深度表示或动作生成前的子目标图像 [11, 43, 26, 68, 12, 64, 61, 36, 50, 28, 32, 18, 21, 33, 67, 34, 3]。

相比之下，我们将推理隔离为一个训练设计问题：我们训练 VLM 推理器生成自由形式的自然语言推理作为指导，而不是依赖手工设计的中间表示，同时保持低级策略冻结。

3 $\mathcal{R}^3$：通过强化学习实现的机器人推理器
为了训练机器人操作的推理器，我们使用先前工作 [50] 中的分层架构：低级策略控制机器人，而高级 VLM 提供引导该策略的指令。图 2 显示了我们的具体架构。我们的目标是训练高级 VLM 在发出指令前用自然语言进行推理。

我们首先描述问题设置，然后描述我们的方法。

3.1 问题设置和环境
我们将每个任务建模为一个决策过程 $\mathcal{M}{g}=(\mathcal{S},\mathcal{A},P,r{g})$，其中 $g$ 是文本长时序目标，$s_{t}\in\mathcal{S}$ 包含视觉和本体感觉信息，$a_{t}\in\mathcal{A}$ 是机器人动作，$P$ 是转移动力学，$r_{g}$ 是二元成功奖励。例如，$g$ 可能是“用红色月亮、蓝色立方体和黄色星星摆出一个 V 形”。我们假设可以访问预训练的低级策略 $\pi_{\mathrm{lo}}(a_{t}|s_{t},u_{t})$，其中 $u_{t}\in\mathcal{U}$ 是短时序子任务指令，如“向左移动红色方块”或“将蓝色立方体推向绿色星星”。我们训练高级 VLM $\pi_{\theta}(\mathbf{z}{t},u{t}|\mathbf{x}{t},g)$，其中 $\mathbf{x}{t}$ 是历史上下文，$\mathbf{z}{t}$ 是推理轨迹，$u{t}$ 是给低级策略的指令。在每一步，高级 VLM 使用 $\mathbf{z}{t}$ 推理任务进度和动作后果，发出 $u{t}$，低级策略执行固定长度的动作块 $a_{t}$，其中 $\mathbf{z}{t},u{t}\sim\pi_{\theta}(\cdot|\mathbf{x}{t},g)$ 且 $a{t}\sim\pi_{\mathrm{lo}}(\cdot|s_{t},u_{t})$。

训练推理器需要设计选择，这对于任何基于学习的机器人系统都是核心的：
(1) 应该使用什么数据，以及推理过程应该如何参数化；
(2) 如何初始化或热启动推理器；
(3) 什么目标可以改进推理，而不仅仅是记忆专家的推理。在本节中，我们开发了 $\mathcal{R}^3$，一个训练机器人推理器的方案。在高层面上，$\mathcal{R}^3$ 在不同任务上收集高覆盖率的专家轨迹，在一小部分专家推理轨迹上对 VLM 进行中期训练以初始化所需的推理风格，并利用更广泛的离线非推理专家数据上的基于评分标准的 RL 进一步改进它。这将专家操作演示转化为实用的推理训练信号，同时避免了昂贵的机器人 rollout。

图 2：策略架构。高级 VLM 在给定场景、目标和先前响应的情况下生成推理轨迹和指令。语言条件的低级执行器将指令作为输入，并发出控制机器人的动作。

Language Table 的数据收集。
训练操作推理器需要的不仅仅是状态、动作和子任务注释。标准的遥操作演示，即使经过子任务或指令的后处理 [27]，也不能解释为什么专家选择该子任务，它如何解释部分进度，或者它如何从错误中恢复。我们需要涵盖多样行为（包括展示恢复和不完美操作或高级规划尝试的行为）和中间状态的数据，以及解释高级决策的推理轨迹。任务本身也必须需要大量推理：如果它们太短时序或可以从当前帧解决，推理提供的好处很少，并且可能在后训练期间被丢弃 [19]。不幸的是，许多模拟环境在相对简单的场景中测试短时序性能，没有明显从语言推理中受益的空间。相比之下，Language Table 提供了杂乱的场景和有些不完美的低级策略，这需要推理系统故意评估多种行动方案才能成功完成任务。

因此，我们在 Language Table 中设计了 14 种长时序积木排列任务，需要组合物体移动和推理空间关系。该任务套件旨在测试关系转移、组合泛化，并呈现不断增加的几何难度。

我们使用 Gemini 3 Flash 作为“人类”专家，并根据向学习者公开的监督构建两个数据子集。第一个子集将专家推理轨迹与指令一起公开，用于在 中期训练 期间播种推理行为（第 3.2 节）。第二个子集仅公开专家指令，保留推理轨迹，用于 RL（第 3.3 节）。这模拟了我们目标的监督机制：高质量的推理轨迹很昂贵，而子任务级指令标签更容易获得。在 RL 中，模型必须生成自己的推理，并通过将其预测的指令与专家的指令进行比较来获得奖励。这种分离也符合数据收集的实际约束：虽然很难获得所有转移的专家推理，但专家指令在许多设置中很容易获得。

VLM 的输入。
人类在解决长时序（操作）任务时自然依赖记忆，通常保持连贯的计划并重用或完善先前的动作。没有历史上下文，专家缺乏这些行为。因此，我们收集有和没有历史的数据。历史可以用几种方式表示，包括过去的帧、过去的响应和学习的摘要。在这项工作中，我们将历史实例化为上一步的完整响应。这允许 VLM 推进其推断的进度和计划。我们评估了 Gemini 3 Flash（专家推理器）在两个代表性任务 line 和 V 上（任务描述见附录 A），上下文中有和没有历史的情况。如表 1 所示，历史上下文持续改进 pass@1：在 line 上从 44.9% 提高到 51.0%，在 V 上从 52.3% 提高到 57.6%。这些收益表明，历史有助于跟踪进度、解决歧义并保持连贯的计划。因此，我们使用历史进行数据收集。收集的轨迹示例见图 3 和附录 C。

3.2 阶段 I：将推理行为中期训练到 VLM 中
在初步实验中，我们发现即使是适合实时机器人控制的模型大小（即 100 亿参数以下）的最强开源 VLM，也不能自然地产生我们操作任务所需的推理风格。

它们的推理通常很肤浅：提到了识别物体或向目标移动等通用步骤，但未能跟踪任务进度、物体关系、失败尝试或对选择下一个子任务至关重要的约束。在附录 C 中，我们观察到基础模型要么未能使用积木之间的空间关系，要么盲目相信先前的指令被正确执行，这些行为阻碍了它解决任务。我们还观察到大量的思维切换，这是一种与“思考不足”相关的失败模式 [57]。这些观察突出了在现成的 VLM 能够作为可靠的机器人推理器之前需要一个热身训练阶段。

预训练模型通常不能产生有用或有效的推理，即使它们能生成听起来自然的思维链。一个常见的修复方法是 中期训练：一个不直接优化奖励的阶段，而是用有用的推理模式或先验（如分解、约束跟踪和自我纠正）初始化模型 [44]。

我们通过在专家生成的推理轨迹上对 VLM 进行中期训练，将同样的想法应用于机器人推理。这反映了中期训练在语言和数学推理中的作用，其目标是在 RL 之前让模型接触有用的推理模式 [45, 58]。

具体来说，每个中期训练示例由交互上下文 $\mathbf{x}{t}$、专家推理轨迹 $\mathbf{z}{t}$ 和高级指令 $u_{t}$ 组成。设 $\mathbf{y}{t}=(\mathbf{z}{t},u_{t})$ 表示通过连接推理和指令形成的目标序列。我们使用标准的下一个标记预测目标进行训练：
$\mathcal{L}{\mathrm{SFT}}(\theta)=-\mathbb{E}{(\mathbf{x}{t},\mathbf{y}{t})\sim\mathcal{D}{\mathrm{SFT}},\;i\sim\mathrm{Unif}({1,\ldots,|\mathbf{y}{t}|})}\left[\log p_{\theta}!\left(\mathbf{y}{t,i}\mid\mathbf{x}{t},\mathbf{y}_{t,<i}\right)\right].$ (3.1)

这教会模型在为低级策略发出指令之前，对状态和交互历史进行推理。我们在成功和不成功的推理轨迹上进行训练。成功的轨迹展示了推理如何导致有用的指令，而不成功的轨迹仍然提供了关于部分进度、错误和恢复尝试的监督。

3.3 阶段 II：使用离线数据的基于评分标准的单步 RL
虽然中期训练为 VLM 播种了所需的推理行为，但它不能确保测试时推理产生有效的指令来引导低级策略。优化推理行为的一个自然下一步是在线 RL：运行多轮 rollout，交替调用高级 VLM 推理器和执行低级策略，并使用最终任务成功作为奖励。然而，这需要昂贵的环境交互和长时序信用分配。信用分配在我们的分层设置中尤其困难，因为失败可能源于糟糕的推理、模糊的高级指令或固定低级策略的不良指令遵循。

因此，我们在专家数据集上使用单步 RL 公式，该数据集由交互历史 $\mathbf{x}{t}$ 和相应的专家指令 $u{t}^{\star}$ 组成，没有专家推理。模型采样 $(\mathbf{z}{t},u{t})\sim\pi_{\theta}(\cdot|\mathbf{x}{t},g)$，其中 $\mathbf{z}{t}$ 是自由形式的推理，$u_{t}$ 是低级指令。当 $u_{t}$ 在语义上与 $u_{t}^{\star}$ 一致，并且 $\mathbf{z}_{t}$ 解释了为什么在给定场景和交互历史的情况下该指令是合适的时，我们给予模型奖励。因此，单步 RL 从动作监督中改进推理器，而不需要人类编写的奖励或多轮机器人 rollout。

奖励函数接收 $g$、$\mathbf{x}{t}$、$u{t}^{\star}$ 和 $(\mathbf{z}{t},u{t})$，并返回一个标量奖励 $R(\mathbf{x}{t},g,u{t}^{\star},\mathbf{z}{t},u{t})$。它可以实例化为由评分标准指导的 VLM 评判器或可验证的奖励。虽然像字符串匹配这样简单的可验证奖励很容易实现，但 VLM 作为评判器允许更灵活的答案格式和更详细的评分标准。

我们还对过短的响应分配负奖励，以避免跳过推理直接跳到最终指令的退化轨迹。

然后我们使用 Dr.GRPO [38] 训练 VLM 推理器。对于每个上下文 $\mathbf{x}{t}$，我们采样一组 $K$ 个响应 ${(\mathbf{z}{t}^{(k)},u_{t}^{(k)})}_{k=1}^{K}$，每个都用奖励 $R^{(k)}$ 评分。

然后我们优化策略梯度损失：
$\mathcal{L}{\mathrm{GRPO}}(\theta)=-\mathbb{E}{t,k}\left[\min\left(\rho_{t}^{(k)}A^{(k)},\mathrm{clip}(\rho_{t}^{(k)},1-\epsilon_{\mathrm{clip}},1+\epsilon_{\mathrm{clip}})A^{(k)}\right)\right],$ (3.2)
其中 $\rho_{t}^{(k)}=\frac{\pi_{\theta}(\mathbf{z}{t}^{(k)},u{t}^{(k)}|\mathbf{x}{t},g)}{\pi{\theta_{\mathrm{old}}}(\mathbf{z}{t}^{(k)},u{t}^{(k)}|\mathbf{x}{t},g)}$ 表示当前和旧策略之间的重要性采样比，$A^{(k)}=R^{(k)}-\frac{1}{K}\sum{j=1}^{K}R^{(j)}$ 是通过在组内归一化奖励获得的奖励。

总结：通过强化学习训练机器人推理器（$\mathcal{R}^3$）
• $\mathcal{R}^3$ 训练高级 VLM 在指导预训练的低级机器人策略之前进行推理。
• 我们在一小部分推理标记子集上进行中期训练，以初始化有用的推理行为。
• 然后我们在仅包含专家指令的更广泛离线数据上应用单步 RL。

特别是，我们强调另外两个设计选择：
(1) 推理上下文插补。
RL 数据包含专家指令但不包含专家推理轨迹。由于先前的响应是交互历史的一部分，我们通过在每一步从中期训练模型中采样 48 个响应来插补缺失的推理。如果任何采样响应导致与前一个状态的专家相同的指令，我们将其用作前一步的上下文；否则，我们仅提供先前的指令而没有推理。
(2) 过滤重复步骤。
在我们初步的 RL 实验中，VLM 推理器经常学会重复先前的指令，因为许多专家轨迹包含重复的指令，并且重复在 RL 期间可能成为严重的奖励捷径。因此，我们从 RL 数据中删除重复步骤，以便训练集中在有意义的指令变化上。我们观察到，RL 后 VLM 的重复指令比例仅略有下降，表明这种数据过滤不会阻止模型在适当的时候重复指令。

杂货打包的 RL 设计选择。
打包指令形成一组有限的打包/移除/转移命令，每个命令都没有语义歧义，因此可以提示和训练策略以匹配完全真实的指令。因此，我们使用简单的精确匹配奖励而不是 VLM 作为评判器：如果解析的指令字符串等于专家指令则为 1.0，否则为 0.0。

我们还根据经验发现，将交互历史实例化为先前的响应或先前的指令会产生可比的性能，因此我们简单地使用先前的指令，从而消除了 RL 之前推理上下文插补过程的需要。

• $\mathcal{R}^3$ 在每个留出的 OOD 任务上均显著优于仅指令模仿。
• RL 从仅指令演示中自动发现有用的推理，而中期训练通过提供强大的行为先验使该优化更可靠。

4.2 推理时推理比表示学习更重要
先前的一些工作研究了思维链推理有助于机器人操作的根本原因，并主要得出结论，其好处来自于改进的表示学习 [8, 64]。一个可能的原因是，这条工作线显式地构建了包含以视觉为中心的信息（如边界框或物体坐标）的推理轨迹。事实上，Chen 等人 [8] 表明，在测试时使用推理并不是必不可少的，其主要好处来自于提供额外的训练时监督。这些发现与 LLM 中的发现有些对比，在 LLM 中，花费额外的测试时计算本身会导致性能提升。

一个自然的问题是：$\mathcal{R}^3$ 的收益是由从推理监督中学到的更好表示解释的，还是显式的测试时推理本身提高了泛化？

我们用三个互补的证据来回答这个问题。
首先，我们在一个探测静态感知能力和面向动作推理的 VQA 套件上评估模型。

这些诊断表明，$\mathcal{R}^3$ 改进了静态感知和动作理解，但它们也表明，仅 VQA 性能（即改进静态感知）并不能完全解释操作性能的收益。即使是我们最好的模型在几个 VQA 类别上仍然远低于 Gemini，但在许多操作任务上却匹配或接近 Gemini。因此，$\mathcal{R}^3$ 的收益不仅仅是因为更好的静态感知；它们可能还来自于模型如何使用语言推理来引导低级策略的变化。

要点：推理和表示学习
• 虽然 $\mathcal{R}^3$ 确实改进了感知和动作理解，但仅感知的改进并不能解释在推理和操作上的改进。
• 使用推理数据作为共同训练的辅助监督并不能解释其好处。
• 增加推理时预算可提高性能，并且训练的推理器在更难的任务上花费更多标记进行推理。

4.3 理解 $\mathcal{R}^3$ 学习的推理行为

图 6：RL 影响指令分布。从基础模型进行的 RL 广泛重写了指令分布，而中期训练后的 RL 进行局部编辑。

$\mathcal{R}^3$ 学习对操作有用的推理策略。
除了成功率之外，我们还在附录 C 中定性检查了 $\mathcal{R}^3$ 产生的推理轨迹。这些轨迹表明，$\mathcal{R}^3$ 学习了对长时序操作有用的行为，而这些行为在中期训练数据中表示不足。首先，训练的推理器在选择指令之前会比较多种替代方案并进行自我纠正。在图 17 中，它考虑了物体-顶点分配，注意到其初始计划与当前场景不一致，并修改了计划。其次，推理器使用推理来解决视觉和历史的不确定性。在图 16 中，一个物体被手臂部分遮挡；模型没有盲目遵循先前的响应，而是重新检查场景、任务信息和历史，以推断正确的物体状态。

我们进一步在相同的 30 个验证场景上定性比较了基础、中期训练和 RL 训练变体的对齐推理轨迹。完整的分析在附录 B.2 中。基础模型具有探索性但不可靠，格式多变、物体幻觉、非收敛回溯和格式错误的指令。中期训练在很大程度上修复了这些接口级别的失败，但通常给出简短和单次的推理。中期训练后的 RL 保持了这种可靠性，同时使推理更加具有状态意识：模型更经常重申任务约束、跟踪进度并渐进地选择下一步。总之，这些比较表明，中期训练稳定了推理接口，而 RL 将其细化为更深思熟虑的面向动作的规划。

中期训练学习与专家对齐的行为先验，RL 选择性地更新它。
我们在图 6 中分析了每个模型产生的指令原语的分布。

基础模型的分布与专家的分布差异很大，过度使用短时序原语如 MoveRelObj，而在空间目标任务上使用 MoveAbs 不足。
从基础模型进行的 RL 提高了成功率，但没有恢复专家分布；相反，它通常将策略转向不同的模式，过度使用 MoveAbs 或 PushInto。

中期训练在很大程度上使模型的指令分布与专家对齐，在 RL 之前提供了强大的行为先验。当在中期训练之后应用 RL 时，产生的指令分布与中期训练的模型在很大程度上保持一致，较大的转变主要发生在中期训练的模型仍然与专家不匹配的地方，例如在 diag_line/gris 上增加 PushInto 的使用，在 V 和 iV 上增加 MoveAbs 的使用。这支持了中期训练作为热启动的作用：从弱先验出发，RL 必须发现新的有用行为，而有了中期训练，RL 可以改进已经合理的行为分布。

这种细化也反映了 RL 的寻模性质，如图 20 中的示例所示。
对于专家策略多样的此类任务，中期训练使模型接触到广泛的行为，随后的 RL 倾向于将其行为集中在高奖励的好策略上。

我们还观察到，罕见的指令（Separate、Touch 和 ArmMoveAbs）在 RL 后崩溃，表明与专家不对齐的行为在 RL 中被丢弃。

• 中期训练锚定了广泛的、类似专家的行为分布；然后 RL 将该先验细化为更深思熟虑的面向动作的规划和集中的行为。

6 讨论和未来工作展望
我们引入了 $\mathcal{R}^3$，一个训练 VLM 在发出引导固定低级机器人策略的高级指令之前用自然语言灵活推理的方案。通过将专家推理轨迹上的中期训练与离线动作数据中基于评分标准的单步强化学习相结合，$\mathcal{R}^3$ 学会了生成可以引导冻结的低级机器人策略的面向动作的推理。在 Language Table 和双臂杂货打包上的实验表明，这种方法在性能上优于无推理的仅指令模仿。在 Language Table 上，$\mathcal{R}^3$ 进一步在已见和未见长时序任务上都有所改进，并展示了更强的分布外泛化能力。我们进一步发现，训练的推理器学习了诸如跟踪交互历史、解决视觉歧义和自我纠正等行为。我们表明，自由形式的语言推理可以作为引导低级策略的有效测试时计算机制。

局限性。
首先，我们的实验是在两个模拟领域（Language Table 和双臂杂货打包）中进行的，具有固定的低级语言条件策略。虽然这有助于我们进行系统研究，但将该方法扩展到真实机器人仍然是重要的未来工作。其次，阶段 I 仍然依赖专家生成的推理，阶段 II 依赖 VLM 评判器提供语义奖励。虽然这减少了对多轮机器人 rollout 的需求，但它也优化了一个替代目标。将我们的方法扩展到多轮在线 RL 将进一步改进长时序行为。

未来工作。
我们相信未来工作有几个方向。首先，$\mathcal{R}^3$ 可以部署在真实机器人上，并在更灵巧、更长时序的操作任务上进行评估。这将测试自然语言推理在噪声感知、物理恢复和适应未见环境等现实挑战下是否仍然有用。

其次，未来工作可以减少高级推理器和低级机器人策略之间的分离。虽然我们的分层设计隔离了推理的效果，但它可能引入高级意图和低级执行之间的不匹配。联合训练推理和动作预测可以在保持基于语言推理的可解释性好处的同时改善协调。研究推理是否不仅可以支持高级引导，还可以支持低级动作本身的生成，也会很有趣。最接近的现有方法是以中间元数据为条件进行动作生成 [28]，但同样依赖高度结构化的模板，表明仍有很大的收益有待实现。此外，联合训练在同步高级推理和低级动作方面引入了技术系统挑战，这将是解决的重要问题。

第三，RL 阶段可以扩展到单步离线训练之外。我们当前的公式通过奖励与专家指令的语义一致性来避免昂贵的在线交互，但它优化的是替代目标而不是最终任务成功。具有来自任务完成、中间进度、恢复行为或人类偏好的反馈的多轮 RL 可能会进一步改进长时序推理。

最后，$\mathcal{R}^3$ 可以扩展以支持在线改进。推理 VLM 可以从环境反馈或人类纠正中更新，而不是仅仅依赖批量离线训练。自由形式的推理也可以为探索提供自然机制，允许机器人将其行为的支持扩展到离线数据中表示的内容之外。虽然今天大多数机器人 RL 方法专注于锐化现有的低级策略，但推理可以实现定性上更广泛的探索，支持对训练期间未遇到的新具身、新物体和失败模式的鲁棒适应。
