黑客攻击AI编程工具OpenCode，盗刷用户账户

📅 2026-10-19 📄 TechCrunch AI 🔗 原文链接

原标题：Hackers hit AI coding tool OpenCode, running up charges on users’ AI accounts

中文摘要： 开源 AI 编程工具 OpenCode 遭黑客入侵，其在线平台 OpenCode Console 约 1.4% 的用户受影响，存储的 API 密钥泄露并遭盗刷，部分账户损失超 1000 美元。Anthropic、Google 封锁泄露密钥，OpenAI 协助退款。事件暴露"不对称问题"：AI 模型安全护栏无法区分攻击者与防御者，OpenCode 团队分析恶意代码时遭模型拒绝，后获 OpenAI Daybreak Blue 权限才推进调查。此前 Hugging Face 也遇到类似困境。

OpenCode 是一款开源 AI 编程智能体，作为 Claude Code 和 Cursor 的替代品，它在开发者中越来越受欢迎。该公司周六表示，攻击者在一夜之间侵入了其一个较旧的系统，影响了其在线平台 OpenCode Console 1.4% 的用户——部分用户在该平台上存储用于访问 AI 服务的 API 密钥（即数字密码）。

在 OpenCode 团队疲于应对攻击之际，这场仓促的响应行动凸显出一个日益突出的问题：那些未经审核、无法使用安全限制较少的 AI 模型的公司，很难抵御大规模的、由 AI 驱动的网络攻击。

"昨晚我们遭遇了一起安全漏洞事件，与一次大规模蒸馏攻击有关，影响了 1.4% 的 OpenCode Console 用户，"该公司在 X 上写道。"我们已于今天早上通过电子邮件通知了所有受影响用户。"该公司表示，未收到电子邮件的用户未受影响。

虽然该公司没有具体说明蒸馏攻击是如何发生的，但泄露的 API 密钥可以帮助那些无法正常访问美国模型的国家的用户，生成该过程所需的大量输出。一些质疑者认为这种说法言过其实，他们认为这只是一起普通的数据泄露事件，密钥是否被用于蒸馏尚无证据证实。

一夜之间，开发者们开始在 Reddit 和 X 上发布消费警报和未经授权的扣费信息："睡觉前，我看到我的 OpenAI、Anthropic 和 Google AI 消费警报接连响起，完全不知道发生了什么，"一位开发者写道。

其他用户报告称单个账户被扣费数百美元；少数用户称总额超过 1000 美元。

Anthropic 和 Google 均已封锁了他们认为已泄露的 API 密钥，而 OpenAI 表示已与 OpenCode 合作恢复访问权限，并就攻击中消耗的额度向其 API 客户退款。OpenCode 表示，针对未经授权扣费的退款工作正在进行中。

据联合创始人 Dax Raad 介绍，泄露的密钥仅限于 Console 平台，部分用户曾将密钥存储在工作区中。开源应用和命令行工具未受影响。"请注意，这是 OpenCode Console，而不是 OpenCode 本身，那些密钥从未传到我们这里，"他在 X 上写道。

就在用户和 AI 公司纷纷采取行动禁用泄露密钥之际，OpenCode 团队仍承受着巨大压力。Raad 表示，攻击者连续 48 小时不停地试图侵入其系统，团队不得不让 AI 防御智能体全天候运行。OpenCode 团队求助用于分析的 AI 模型起初有所帮助，但当被要求检查的恶意代码触发安全过滤器时，这些模型便开始拒绝工作。

"[这]有点令人沮丧，"他在 X 上写道。

OpenCode 随后获得了 OpenAI Daybreak Blue 计划的访问权限，该计划为经过审核的用户提供不太可能拒绝防御性安全工作请求的 AI 模型。Raad 表示，这一权限提升了团队调查此次攻击的能力。

OpenCode 并不是第一家撞上这堵墙的公司。今年 7 月，AI 平台 Hugging Face 表示，商业 AI 模型阻止了其分析自主 AI 智能体入侵活动日志的尝试，而 OpenAI 后来透露，这些智能体其实是它自己的模型，在测试期间降低了安全防护运行。Hugging Face 在其博客文章中题为"不对称问题"的一节里写道，护栏"无法区分事件响应者和攻击者"。

安全研究人员也提出了类似的抱怨，称这些限制前后不一致，并促使一些人转向国外的开源权重模型——任何人都可以下载并运行这些模型。

周末的这一事件引来了总统科技顾问委员会联合主席 David Sacks 的回应。

"OpenCode（以及之前的 Hugging Face）在攻击进行中都撞上了同一堵墙：前沿模型拒绝分析防御所需的漏洞利用代码，因为这些载荷触发了安全过滤器。护栏适得其反，"他在 X 上写道。

此次泄露事件发生在 OpenCode 向用户免费开放 GLM-5.3-Flash 的同一晚。更广泛的 GLM-5.3 系列已引起研究开源权重模型的研究人员的关注，他们指出其网络安全能力已接近此前仅与受限访问模型（如 Anthropic 的 Claude Mythos Preview）相关的水平。

OpenCode 尚未详细说明攻击者如何获得旧系统的访问权限、密钥是如何存储的，以及任何滥用的完整范围。该公司已告知受影响的用户直接向各服务商撤销并更换其密钥。该公司表示，事件仍在处理中。

此次泄露事件发生之际，一系列由 AI 促成的网络安全事件接连出现。本月早些时候，网络安全公司 CrowdStrike 表示，一名位于中国的黑客很可能在针对韩国银行的攻击中使用了 AI 渗透测试智能体（用于探测计算机系统弱点的工具）和 Claude。上周，印度网络安全机构警告称，AI 智能体（包括一些正在被 AI 公司测试的智能体）已在未经授权的情况下进入了印度组织的系统。
