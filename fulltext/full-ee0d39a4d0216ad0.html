互联网遭遇网络安全噩梦日

📅 2026-10-21 📄 TechCrunch AI 🔗 原文链接

原标题：The internet is having a very bad cybersecurity day

中文摘要： 本文报道互联网遭遇的"网络安全噩梦日"：AI 发现 PHP 严重漏洞后，NSA 建议相关组织立即更新或下线系统；Node.js 修复四个高危漏洞，涉及远程代码执行和 TLS 验证绕过；开源 LLM 代理 LiteLLM 遭入侵，恶意代码被发布至 PyPI 等平台，可窃取云凭证和密码；印度证书机构 eMudhra 私钥泄露，清理工作"比 Heartbleed 更大"。加上 TiDB Cloud 泄露、Plex 漏洞利用及 BeyondTrust 零日漏洞等事件，凸显了网络安全团队面临的严峻挑战。

据路透社报道，在人工智能（AI）发现影响编程语言 PHP 的严重安全漏洞后，相关系统已下线。这些问题足够严重，以至于美国国家安全局（NSA）建议在其系统上使用 PHP 的组织要么立即更新，要么在完成更新之前将系统下线。

但 PHP 的更新并不是网络安全从业者周三面临的唯一难题。开源 JavaScript 运行时环境 Node.js 也抛出了自己的安全"惊雷"，其透露在最新版本中刚刚修复了四个高危漏洞。其中一个漏洞允许远程代码执行，另外两个漏洞则可能导致 TLS 验证绕过，可能使攻击者绕过旨在验证服务器身份的检查。

此外，LiteLLM——一个用于将请求路由到多个 LLM 提供商的流行开源代理——遭到入侵，这一消息于周三下午在 X 平台的一篇帖子中公布。该帖子指出，恶意工件已被发布到 PyPI（Python 包索引）、Docker Hub 和 GHCR（GitHub 容器注册表）。

据报道，恶意代码包括一个针对云凭证、密码和 AI 服务凭证的信息窃取程序，以及一个远程访问木马，后者可能允许黑客在被入侵的系统上执行命令。

LiteLLM 表示，目前已删除了恶意版本和镜像，并建议所有安装过这些内容的用户遵循其提供的修复指南。

等等，还有更多！印度证书颁发机构 eMudhra 的私钥遭泄露，这可能使攻击者能够签发欺诈性证书并冒充合法网站。

安全专业人士称这是一项庞大的清理工作，其规模"比心脏出血（Heartbleed）还大"。（后者指的是 OpenSSL 加密软件库中的那个严重安全漏洞。）

这些问题是在其他安全漏洞和黑客攻击之后接踵而至的，其中包括云原生数据库即服务 TiDB Cloud 的数据泄露事件，该公司已于周一宣布了这一消息。另有黑客一直在利用四个已修补的 Plex Media Server 漏洞，这些漏洞统称为 Plex2Shell。而上周，网络安全公司 BeyondTrust 警告客户修补其 Remote Support 产品中的一个严重零日漏洞，该漏洞自 8 月以来一直遭到利用。

虽然这些问题彼此之间并无关联，但它们的接连而至凸显了网络安全团队如今面临的挑战。这一点尤为重要，因为 AI 可能会让攻击者更容易利用一旦被发现的漏洞。
