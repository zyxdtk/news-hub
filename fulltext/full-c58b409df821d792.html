摘要
先前的运动生成方法主要遵循两种范式：擅长运动学控制的连续扩散模型，以及在语义条件化方面有效的离散标记生成器。为结合二者优势，我们提出一个三阶段框架，包括条件特征提取（感知）、离散标记生成（规划）和基于扩散的运动合成（控制）。该框架的核心是 MoTok，一种基于扩散的离散运动标记器，它通过将运动恢复任务委托给扩散解码器，从而将语义抽象与细粒度重建解耦，实现了紧凑的单层标记同时保持运动保真度。对于运动学条件，粗粒度约束在“规划”阶段引导标记生成，而细粒度约束则在“控制”阶段通过基于扩散的优化进行强制执行。该设计防止了运动学细节干扰语义标记规划。在 HumanML3D 数据集上，我们的方法相比 MaskControl 显著提升了可控性和保真度，仅使用其六分之一的标记量，轨迹误差从 0.72 cm 降低至 0.08 cm，FID 从 0.083 降低至 0.029。与先前方法不同，我们的方法在保持高保真度的同时实现了更高效的标记表示。

在保持语义意图的同时有效集成此类低层次约束，仍然是一个核心挑战。
基于 token 的运动生成方法
[DBLP:conf/cvpr/ZhangZCZZLSY23, DBLP:conf/cvpr/GuoMJW024]

然而，现有的运动分词器 [DBLP:conf/cvpr/GuoMJW024] 通常将高层语义与低层运动细节交织在一起，需要较高的分词率或分层编码才能确保忠实重建。
这增加了下游生成器的负担，并使可控生成变得复杂，因为细粒度的运动学条件信号可能会与语义条件相互竞争或覆盖语义条件。
相比之下，扩散模型 [DBLP:journals/pami/ZhangCPHGYL24, DBLP:conf/cvpr/ChenJLHFCY23] 在重建具有平滑动力学和丰富局部细节的连续运动方面表现出色。
这表明在运动生成中可以实现分工：扩散模型负责细粒度重建，而离散分词则捕捉语义抽象。

在 感知 阶段，异构条件被编码为全局条件（例如，文本），用于引导整体运动，或局部条件（例如，关键点轨迹），用于提供局部约束。
在 规划 阶段，一个分词空间规划器在统一接口下预测离散运动分词序列，支持自回归（AR）和离散扩散（DDM）两种生成器。
在 控制 阶段，最终运动通过基于扩散的解码合成，同时强制施加细粒度的运动学约束。

在去噪过程中。
这种分解将高层规划与低层运动学分离，使得同一管道能够泛化到不同的生成器架构和运动生成任务。
基于这一范式，我们引入了 MoTok，一种基于扩散的离散运动标记器，它将语义抽象与低层重建解耦。

这种设计减少了下游规划器所需的标记预算，并允许在解码时进行精细化调整，而无需强制离散标记编码精细的运动学细节。
此外，我们提出了一种条件注入方案，通过在不同阶段分配控制权，协调语义线索与运动学约束（图 1c）。
运动学条件在 规划（Planning） 阶段作为 粗粒度（coarse） 约束，引导标记生成；而在 控制（Control） 阶段通过基于优化的引导，在扩散去噪过程中作为 细粒度（fine-grained） 约束发挥作用。

3.2
基于扩散的离散运动分词器
MoTok 是一种基于扩散的离散运动分词器，它将运动表示分解为紧凑的离散码序列和用于精细重建的扩散解码器。
与传统的 VQ-VAE 分词器直接从离散码解码连续运动不同，MoTok 首先将离散码映射为逐帧条件信号，然后利用条件扩散模型重建运动细节。
通过显式地将精细重建任务卸载给基于扩散的解码，离散标记可以专注于语义结构，从而实现显著减少的标记预算。
如图 2a 所示，MoTok 包含三个组件：
1) 一个卷积编码器 $\mathcal{E}(\cdot)$，用于生成时间下采样的潜在序列；
2) 一个向量量化器 $\mathcal{Q}(\cdot)$，用于将潜在表示映射为离散码；
以及
(3) 一个具有扩散重建的解码器，包括卷积解码器 $\mathcal{D}(\cdot)$ 和条件扩散模型 $\mathcal{P}_{\phi}(\cdot)$。

卷积编码器
使用卷积编码器 $\mathcal{E}(\cdot)$ 来获得压缩的潜在表示。
给定一个运动序列 $\boldsymbol{\theta}{1:T}$，通过逐步的时间下采样提取潜在特征：
$\mathbf{h}{1:N} = \mathcal{E}(\boldsymbol{\theta}_{1:T})$。
其中，$N = T / r$，$r$ 是时间下采样率。
编码器由多个卷积块组成，每个块包含一个卷积层、归一化层和激活函数。
为了增强时间建模能力，我们在编码器中引入了时间注意力机制，使模型能够捕捉长距离依赖关系。
最终，编码器输出一个长度为 $N$ 的潜在序列，每个潜在向量的维度为 $d$。

向量量化器
向量量化器 $\mathcal{Q}(\cdot)$ 将潜在序列 $\mathcal{E}(\boldsymbol{\theta}{1:T})$ 映射为离散码序列 $\mathbf{z}{1:N}$。
我们采用 VQ-VAE 中的标准量化方法，即通过最近邻搜索将每个潜在向量映射到码本中的最近码字。
码本大小为 $K$，每个码字的维度为 $d$。
量化过程可表示为：
$\mathbf{z}i = \mathcal{Q}(\mathbf{h}_i) = \arg\min{k \in {1,\dots,K}} |\mathbf{h}_i - \mathbf{e}_k|^2$，
其中 $\mathbf{e}_k$ 是码本中的第 $k$ 个码字。
为了稳定训练，我们使用带梯度直通（straight-through estimator）的量化操作。

扩散解码器
扩散解码器由卷积解码器 $\mathcal{D}(\cdot)$ 和条件扩散模型 $\mathcal{P}{\phi}(\cdot)$ 组成。
卷积解码器 $\mathcal{D}(\cdot)$ 将离散码序列 $\mathbf{z}{1:N}$ 上采样回原始时间分辨率，生成一个粗略的潜在序列 $\mathbf{h}'{1:T}$。
然后，条件扩散模型 $\mathcal{P}{\phi}(\cdot)$ 以 $\mathbf{h}'{1:T}$ 为条件，逐步去噪生成最终的运动序列 $\boldsymbol{\theta}{1:T}$。
扩散模型采用标准的前向扩散和反向去噪过程，其中噪声水平由时间步 $t$ 控制。
条件信号 $\mathbf{h}'_{1:T}$ 通过交叉注意力机制注入到扩散模型中，以引导生成过程。
通过这种两阶段设计，MoTok 能够在保持语义一致性的同时，实现高保真运动重建。

训练目标

MoTok 采用端到端训练方式，结合了扩散重建目标和 VQ 承诺损失（VQ commitment loss），遵循 MAR 的扩散训练策略 [DBLP:conf/nips/LiTLDH24]。在扩散训练过程中，采样一个时间步 ( t )，并优化条件去噪目标：

[
\mathcal{L}{\mathrm{diff}}=\mathbb{E}{t,\epsilon}\Big[\ell\big(\hat{\mathbf{x}}{0},\mathbf{x}{0}\big)\Big],

[

3.3 统一的条件运动生成

如图 2 所示，MoTok 通过将离散标记空间中的规划与基于扩散的解码中的控制解耦，实现了统一的条件运动生成流程。给定条件集 ( \mathbf{c}={\mathbf{c}^{g},\mathbf{c}^{s}_{1:T}} )，一个标记序列被生成，该序列随后被用于指导扩散解码器生成连续运动。

生成器首先生成一个离散序列 $\mathbf{z}{1:N}$，然后通过基于 MoTok 提取特征的扩散过程将其解码为连续运动 $\hat{\mathbf{x}}{0}$。该框架支持通过共享的条件接口实现离散扩散和自回归 token 生成器。条件根据其时间特性分为两类：
1) 全局条件 $\mathbf{c}^{g}$，提供序列级指导，无需逐帧对齐（例如，文本描述）；
2) 局部条件 $\mathbf{c}^{s}_{1:T}$，与运动时间轴对齐，指定细粒度控制信号（例如，目标轨迹）。

全局条件通过 $\mathcal{E}{g}(\cdot)$ 编码为序列级特征 $\mathbf{M}^{g} \in \mathbb{R}^{d}$，并在离散规划过程中作为专用 token 使用；局部条件通过 $\mathcal{E}{s}(\cdot)$ 编码为特征序列 $\mathbf{M}_{1:N}^{s} \in \mathbb{R}^{N \times d}$，与 token 长度 $N$ 对齐。

离散 Token 空间中的规划
Token 空间规划在异构条件下生成离散运动 token，并通过共享的规划接口支持离散扩散和自回归生成器。

离散扩散规划

$$

4.1 实验设置
数据集
实验在 HumanML3D [DBLP:conf/cvpr/GuoZZ0JL022] 和 KIT-ML [DBLP:journals/bigdata/PlappertMA16] 上进行，这两个数据集是广泛使用的文本-动作配对基准数据集。每个数据集为每条动作序列提供了自然语言描述，并附带一种基于标准化骨架的动作表示。

文本条件
文本条件被视为全局条件，使用预训练的 CLIP 文本编码器（ViT-B/32）[DBLP:conf/icml/RadfordKHRGASAM21] 编码为序列级特征，生成一个 512 维的嵌入。该嵌入在离散扩散和自回归生成器的 token 空间规划中作为全局条件 token 使用。

轨迹条件
轨迹条件被视为局部条件，使用与 MoTok 中动作编码器结构相同的卷积编码器，编码为与 token 对齐的特征序列。编码器将轨迹下采样以匹配 token 长度，并应用 dropout（0.1）以增强鲁棒性，同时支持无分类器引导（classifier-free guidance）。

在所有设置下，解码器性能呈现出清晰的层次结构：基于扩散的解码器优于普通的卷积解码器，而引入显式的时序建模则进一步优于逐帧扩散。

相比之下，DiffusionConv 通过残差 1D 卷积引入局部时序相关性，在两种规划器下均能持续提升生成保真度和可控性。

如表 4 所示，低级条件是必要的，不能移除而不损害可控生成。仅在生成器中注入低级信号会迫使令牌空间规划同时满足语义和精确约束，通常会增加控制误差并降低运动保真度。仅在令牌解码器中注入低级信号则缺乏规划阶段的指导，导致不稳定或较弱的约束遵循。只有在两个阶段都应用低级条件时，才能获得最佳结果：生成器提供粗粒度、条件感知的规划，而扩散解码器在去噪过程中强制执行细粒度约束。

5 结论
在本工作中，我们结合了连续扩散模型在运动学控制方面的优势和离散令牌生成器在语义条件方面的优势。我们引入了一种三阶段的 感知–规划–控制 范式，该范式编码条件、规划离散运动令牌，并通过基于扩散的解码合成运动，同时强制执行细粒度约束。在此框架中，

amework，我们提出了 MoTok，一种基于扩散的离散运动分词器，它将低层次重建任务卸载到扩散解码过程中，从而实现紧凑且语义丰富的分词。在 HumanML3D 和 KIT-ML 数据集上的实验表明，MoTok 在激进的分词压缩下仍表现出强大性能，并在文本与轨迹可控生成任务中取得显著提升，轨迹误差从 0.72 厘米降低至 0.08 厘米，同时仅使用六分之一的分词数量。

0.D.1
评估指标

在本工作中，我们主要关注三类指标：

  1. 文本到动作（Text-to-Motion, T2M）：我们评估动作的真实性和文本-动作对齐程度。动作真实性通过 Fréchet Inception Distance（FID）进行衡量。文本-动作一致性通过 R-Precision（R@1/2/3）和多模态距离（MM Dist）进行评估。我们进一步报告多样性（Div）以量化生成动作之间的变化程度，并报告多模态性（MM）以衡量为同一文本生成多个合理动作的能力。

  2. 动作到文本（Motion-to-Text, M2T）：我们采用标准的图像描述生成指标，包括 BLEU@1/4、ROUGE-L、CIDEr 和 BERTScore。此外，我们报告 R-Precision 以衡量生成的描述与对应动作之间的对齐程度。下文将定义每个指标。

Details for Motion-to-Text

Task Formulation

对于运动到文本（M2T），目标是生成一段自然语言描述，以忠实总结给定的运动序列。形式上，给定输入运动序列 $\mathbf{x} = {x_{t}}{t=1}^{T}$，其中 $x{t}$ 表示时间步 $t$ 的姿态表示，模型预测一个由 $L$ 个token组成的描述 $y = {y_{i}}_{i=1}^{L}$。我们将M2T建模为条件语言生成，通过最大化

似然函数
$p(y\mid\mathbf{x})$。在我们的框架中，运动序列首先通过 MoTok 分词器编码为离散的分词序列 $\mathbf{z}={z_{n}}{n=1}^{N}$，其中 $N$ 取决于时间下采样率。随后，一个自回归语言解码器在 $\mathbf{z}$ 的条件下生成描述：
$p(y\mid\mathbf{x})=p(y\mid\mathbf{z})=\prod{i=1}^{L}p(y_{i}\mid y_{<i},\mathbf{z}).$
(31)
该公式允许描述生成器在紧凑的分词空间中运行，同时利用 MoTok 保留语义相关的运动内容。

实现细节

我们实现 M2T 描述生成器为一个标准的自回归 Transformer 解码器，其条件基于 MoTok 分词。具体而言，我们首先使用预训练的 MoTok 分词器（编码器 + 代码本）将运动编码为离散分词，并在描述生成训练过程中固定分词器。分词嵌入通过查表获得，并可选地添加位置嵌入。描述生成模型以 MoTok 分词序列作为条件上下文，在训练过程中使用教师强制（teacher forcing）生成文本，并针对真实描述分词优化交叉熵损失。在推理阶段，我们使用贪心解码或束搜索（beam search）自回归地解码描述。除非另有说明，我们遵循先前工作中常见的 M2T 训练实践，包括使用 HumanML3D 描述作为监督信号，t
