摘要

强化学习（RL）后训练显著提升了扩散Transformer的视觉质量、文本渲染和组合准确性。由于渲染指定文本或组合多个对象等能力本质上依赖于提示词，一个自然的假设是：提升这些能力需要学习复杂的、依赖输入的变换。为了分离出与输入无关的偏移能解释这些增益中的多少，我们用一种刻意简单的参数化来探测每个RL调优模型：在冻结基础模型的块输出上添加一组固定的引导向量。在SD3.5-M上，这些向量的参数量比RL调优的LoRA少65倍（0.29M对比18.8M）。我们通过匹配公开RL调优检查点的速度预测来拟合它们，目标函数中不含奖励。尽管这些向量对每个提示词、词元和采样种子都完全相同，它们却恢复了六个RL调优图像模型90.0–96.3%的奖励增益，以及两个RL调优视频模型上89.8%和111.9%的增益。从零初始化并用在线RL训练，仅这些向量在SD3.5-M的文本渲染（OCR）和人类偏好上就超过了基于权重的RL的奖励增益。因此，一个常数偏移就足以获得策略梯度RL后训练的大部分增益：无需新的依赖输入的变换，它将预训练生成器引导向其已经能够计算的内容。

1 引言

强化学习（RL）后训练提升了图像和视频扩散Transformer中的文本渲染、组合准确性和人类偏好分数。这些改进通常通过更新模型权重获得，或通过LoRA等参数高效适配器，或通过全量微调。尽管更新ΔW在训练后是固定的，但更新后的权重W+ΔW作用于每个词元的输入，因此不同的提示词和词元产生不同的激活变化。这种灵活性对视觉生成而言似乎很自然，因为要渲染的词语和要组合的对象随每个提示词而变化。但这种输入依赖性对于获得RL后训练的增益是否真的必要？

令人惊讶的是，我们发现，多样化的RL调优图像和视频生成器的大部分奖励改进，可以通过冻结全部预训练权重并在模型激活上添加一小组固定引导向量来重现。我们将这些向量拟合以匹配每个RL调优模型的输出速度，目标函数中不含奖励；而简单地对RL引起的激活变化取平均所恢复的增益要少得多。对于给定的RL调优模型，相同的向量用于每个提示词、每个采样种子和每个词元（图2）。总体上，它们的参数量仅为SD3.5-M上rank-32 LoRA的1.5%，且不依赖于请求的文本、对象或组合。然而，它们能使冻结的生成器渲染指定短语、满足组合约束并提高偏好分数，正如其RL调优的对应模型一样（图1和图5）。在跨越SD3.5-M和FLUX.1-dev的六个RL调优图像模型上——涵盖多种RL算法、LoRA与全量微调，以及包括PickScore、HPSv2.1、OCR和GenEval在内的奖励——这些固定激活偏移恢复了90.0–96.3%的RL奖励增益。该结果还扩展到视频：在两个RL调优视频生成器上，相同的干预恢复了89.8%和111.9%的增益。

接下来我们追问：RL能否在扩散Transformer中直接从奖励学到这种常数偏移？我们冻结生成器并运行Flow-GRPO，仅让引导向量可训练，从零开始。训练后的向量达到OCR调优和PickScore调优的SD3.5-M模型增益的104.6%和103.6%，因此RL仅通过学习一小组常数向量就实现了这两个增益，而无需更新任何预训练权重。

一个常数干预如何为不同提示词产生不同的改进？引导向量不携带提示词信息，因此变化的提示词特定部分必然来自冻结的生成器。在Transformer内部，注意力、归一化和MLP层将常数向量与依赖提示词的表示混合，因此它对输出的影响可以强烈依赖于提示词。在SD3.5-M上，我们追踪了偏移如何到达图像：通过图像词元在联合注意力中从文本词元读取的内容。当图像词元改为读取未引导基础模型的文本键和值时（其他一切不变），OCR和PickScore增益的大部分消失。相同的替换也移除了OCR调优和PickScore调优模型的大部分增益，因此引导向量和RL通过相同的路径到达图像。文本流、条件引导通道和早期采样步骤携带了大部分增益：仅拟合到这些部分的向量，参数比rank-32 LoRA少531倍，恢复了OCR上89.5%和PickScore上73.7%的RL增益（第5节）。

这些结果提出了对视觉生成器RL后训练的一种不同理解：常数偏移足以将生成引导至大部分RL增益，而冻结的生成器完成提示词特定的工作。我们的主要贡献如下：

  • 我们展示了固定引导向量（拟合时目标函数中不含奖励）可恢复八个RL调优图像和视频模型的大部分增益，包括两个全量微调模型。
  • 我们发现匹配RL调优模型的速度比添加其平均激活变化恢复的增益多得多。
  • 我们仅用Flow-GRPO训练冻结SD3.5-M的引导向量，即超过了RL调优OCR和PickScore模型的奖励增益，且用户研究中图像评级与其相当。
  • 我们追踪了常数偏移如何产生提示词特定增益：在SD3.5-M上，它通过图像词元从文本读取的内容到达图像，与RL的变化路径相同。

2 相关工作

扩散Transformer的RL后训练。 奖励微调通过将分数经采样器反向传播、从偏好对中学习或使用策略梯度来提高扩散模型样本的得分。策略梯度每个样本只需一个分数，其在Flow-GRPO和DanceGRPO中的组相对形式现已用于图像和视频扩散Transformer的后训练。奖励包括OCR准确率、GenEval和T2I-CompBench分数，以及在人类判断上训练的偏好模型。其他研究报告了对颜色饱和度和输出多样性的副作用。我们则追问RL在模型内部改变了什么以产生这些增益。

RL的作用位置。 语言模型中RL的研究追问其更新位于何处。RL微调更新一个小的子网络，用很少的训练参数即可达到大部分增益，并使模型保持接近基础模型。对齐微调主要改变每个答案的风格或前几个词元，RL提高了基础模型已经采样的答案的概率。Venhoff等人用分类器门控引导向量弥补了与RL训练推理模型的大部分差距：由分类器决定在哪里添加每种推理行为。Sinii等人在数学奖励上用RL训练引导向量，匹配或几乎匹配完整RL微调；Vakada等人用无标签奖励做了同样的事情。我们将引导向量拟合到给定的RL调优模型以测量常数能恢复其多少增益，同时也用奖励直接训练它们（第4.6节）。我们研究的是扩散Transformer，其中奖励增益是整个图像或视频的提示词特定变化。

激活引导。 激活引导向模型的隐藏状态添加固定向量，可取自对比提示词或通过优化得到。在图像模型中，深层特征中的固定方向可编辑图像内容，类似的（通常是门控的）添加可引导扩散模型和扩散Transformer。任务算术添加微调模型的权重差异，它在权重空间中是常数，但对每个输入的激活改变不同。在并行工作中，一阶引导将这种权重更新一阶近似地转化为引导向量。Adila等人发现块输出（我们的引导向量所在位置）是此类偏移的高表达性位置。我们则是将引导向量拟合到给定RL调优模型的速度预测。

网络中的常数。 许多适应方法通过对每个输入相同的参数改变冻结模型。在输入端，提示词调优训练软提示词词元，文本反演为新概念拟合一个词，ReNeg在奖励上学习负嵌入。RaTE通过流匹配将一个提示词词元拟合到Flow-GRPO模型。在网络内部，前缀调优和P-Tuning v2将学习的键和值前置到注意力层，ReFT学习对隐藏表示的干预。BitFit和(IA)³训练偏置和通道缩放，DiffFit调优扩散Transformer的偏置和缩放，Calibri在奖励上调优扩散Transformer的块门。BitFit和DiffFit用任务损失训练偏置以使模型适应新数据，而我们将块输出处的引导向量拟合到现有RL调优模型，以测量它们能重现多少增益。

3 方法

3.1 预备知识

扩散Transformer。 基础模型、RL调优模型和引导的基础模型都是通过流匹配训练的扩散Transformer。每个模型在噪声潜变量x_t = (1−t)x_0 + tε处预测速度v，其中x_0为干净潜变量，噪声水平t∈[0,1]，高斯噪声ε~N(0,I)。设v_θ表示基础模型，v_{θ_RL}表示RL调优模型，v_{θ,s}表示引导的基础模型。采样器从t=1到0执行N个采样步骤，每个离散噪声水平一步。我们在SD3.5-M上使用N=40，与Flow-GRPO一致。

引导通道。 无分类器引导（CFG）结合提示词y的条件通道和空提示词∅的无条件通道，即v_∅ + w(v_c − v_∅)，CFG尺度为w。FLUX.1-dev经过引导蒸馏，每个采样步骤只运行单次通道。

词元流。 SD3.5-M以两个流处理图像和文本词元。在联合注意力中，每个词元同时关注两个流。

3.2 引导向量

图3：一个引导向量偏移块输出的每个词元。图示显示一个流。引导通道p和步骤分箱k选中带轮廓的向量，将其添加到每个词元h。

引导向量是在推理时添加到模型隐藏状态的常数向量，它在不改变权重的情况下改变模型输出。在具有L个块和宽度d的模型中，设h^str_{ℓ,i}∈ℝ^d为图像或文本流中块ℓ∈{0,…,L−1}输出的词元i，str∈{img,txt}。引导向量s = {s^str_{ℓ,p,k}}在每个输出中向每个词元添加一个ℝ^d中的向量（图3）：

h̃^str_{ℓ,i} = h^str_{ℓ,i} + α·s^str_{ℓ,p,k(t)}，对每个词元i。（公式1）

引导通道p∈{c,∅}和包含t的步骤分箱k(t)∈{1,…,K}选择向量，引导强度α对其进行缩放。拟合和所有主要结果均使用α=1。我们使用K=2个连续步骤分箱，固定边界τ将调度的N个噪声水平平均分为早期（t≥τ）和晚期（t<τ）步骤，SD3.5-M的偏移调度上τ=0.75。p和k都仅依赖于采样器，因此每个流的每个提示词、采样种子和词元接收相同的向量。

线性层的全量或LoRA权重更新ΔW则给出+W)z_i = Wz_i + ΔWz_i，其中z_i是词元i处的层输入（图2）。添加的项在词元和提示词之间各不相同，这与公式1不同。Rank-1 LoRA（ΔW = ba^⊤）添加固定方向b，其权重为a^⊤z_i，因此它是一个具有依赖输入权重的引导向量。在SD3.5-M上，引导向量有288,768个参数（表S3），是Flow-GRPO为PickScore训练的rank-32 LoRA的1.5%。

单通道模型（FLUX.1-dev和Wan2.2-5B）去掉通道索引。

跨词元共享。 引导向量不依赖于词元数量，因此在一个分辨率上拟合的向量可不变地应用于另一分辨率。它们可从512迁移到768和1024像素，以及迁移到其他采样步骤数和CFG尺度（图S1）。

按引导通道分割。 引导将条件速度中的变化Δv_c缩放w倍，将无条件速度中的变化Δv_∅缩放(1−w)倍。两个通道共享的一个向量无法独立设置这两个变化，且当w>1时两个因子符号相反。

按步骤分箱分割。 早期采样步骤确定图像布局，晚期步骤细化其细节。RL调优模型的平均块输出变化也随步骤变化：两个步骤分箱保持了八个分箱所保持能量的83%至94%（表S4），一个分箱给出的奖励增益与两个几乎相同（表S11）。

3.3 速度匹配拟合

均值差基线。 最简单的与输入无关的变化是添加均值差引导向量s_mean，这是s布局下的免训练基线。s_mean的每个向量是RL调优模型的块输出减去基础模型的块输出，在其步骤分箱内的词元、提示词和噪声水平上取平均。两个模型在RL调优模型采样轨迹上的相同噪声状态上运行。我们按顺序测量块ℓ=0,…,L−1，较早的向量已添加到基础模型上，因此没有块的变化被重复计算。s_mean的向量是激活引导中对比均值差向量的双模型对应物。

图4：拟合匹配RL调优模型的速度。RL调优模型的最终潜变量x_0被重新加噪为x_t，损失L仅训练s（虚线箭头），不含奖励。

速度匹配。 我们改为将引导向量拟合以匹配RL调优模型的输出速度，而非其激活变化（图4），正如RaTE对单个提示词词元所做的那样。拟合最小化：

L(s) = E‖v_{θ,s}(x_t, t, y_p) − v_{θ_RL}(x_t, t, y_p)‖²，（公式2）

其中期望在提示词y、y对应的RL调优模型最终样本x_0，以及t、ε和p上运行，y_c = y，y_∅ = ∅，t从采样器的N个噪声水平中抽取（第A节）。在v_{θ,s}中，公式1仅添加通道p和包含t的步骤分箱的向量，因此公式2可分解为每个通道和步骤分箱一个独立项。两个模型均保持冻结，最小化公式2得到拟合的引导向量s_fit。速度匹配是对RL调优模型训练提示词缓存样本的回归，因此训练循环既不需要奖励模型也不需要采样。构建缓存、测量s_mean和拟合，每个图像模型最多需要17个H100 GPU小时，每个视频模型70个（表S1）。在测试时，引导向量在每个块输出上只需一次向量加法。

5 增益作用于何处？

为了理解一个共享偏移如何产生提示词特定增益，我们在SD3.5-M上拟合受限的引导向量集，并测试变化如何穿过联合注意力。

发现1：增益偏向条件通道、早期步骤和文本流。 我们用完整集合的配方和训练长度拟合每个受限集合，并在一个采样种子的OCR和PickScore测试集上评估（图7(b)）。仅在条件通道上作用的引导向量恢复的RL增益比完整集合更多（图7(b)），而完整集合中的无条件通道向量单独添加时会降低两个奖励（表S12）。两个通道的向量指向相似的方向，而引导会减去无条件通道，因此缺少其向量时净引导变化增大，如同更大的α。单独拟合时，任一流都能恢复大部分增益（图像流在OCR上为91.4%，PickScore上为84.9%）。然而在完整集合内，文本流向量单独添加时携带了大部分增益（表S12）。早期步骤分箱携带的增益远多于晚期。三项选择合并后，35,328个参数（完整集合的12%，rank-32 LoRA的0.19%）恢复了OCR上89.5%和PickScore上73.7%的RL增益。

图8：仅由RL训练的引导向量像RL调优模型一样改变图像。每个提示词的图像共享一个起始噪声。

发现2：增益通过图像词元从文本读取的内容到达图像。 文本流向量仅偏移文本词元，而速度是从图像流投影出来的，因此其变化必须通过联合注意力到达图像——在联合注意力中，图像和文本词元读取两个流的键和值。将图像查询所读取的文本键和值替换为未引导基础模型在相同噪声状态下的文本键和值，仅保留了引导向量OCR增益的20.5%和PickScore增益的10.5%（图9）。RL调优模型依赖相同的路径，在此干预下分别保留26.4%（OCR调优）和24.5%（PickScore调优）的增益，而重置文本词元从图像词元读取的内容则保留了全部四个增益的至少84.4%。在图S8的OCR测试提示词上，恢复图像词元从文本读取的内容会将两个模型的清晰文本变回基础模型的乱码文本。在PickScore上，替换文本词元从其他文本词元读取的内容仅保留引导向量增益的43.8%和RL调优模型的40.9%，而OCR上分别为93.6%和89.6%；因此偏好增益也会在图像词元读取之前修改文本词元，这与风格通过文本词元到达图像的发现一致。使用OCR引导基础模型的文本键和值时，OCR调优模型保留其增益的95.2%，而使用PickScore引导的仅为44.0%（第I节）。

图9：引导向量和RL通过图像词元从文本读取的内容到达图像。当某条路径读取基础模型的键和值时所保留的增益份额，带95%区间。"图像读图像"携带图像流自身的变化以及图像词元在较早块中从文本读取的内容。

共享偏移如何变为提示词特定。 冻结的块将相同的偏移转化为每个词元不同的变化（图S7），一个维度为d_h的联合注意力头可以说明这一点。设图像词元i的查询为q_i，其对文本词元的注意力份额为m_i，ō^txt_i和ō^img_i分别为其在每个流内的注意力加权平均价值。如果查询和图像键值保持固定，而每个文本键在归一化后移动一个共享向量δ_key，每个文本值移动δ_val，则份额和头输出o_i变为（定理S1）：

m'_i/(1−m'_i) = (m_i/(1−m_i))·e^(q_i^⊤δ_key/√d_h)，

o'_i − o_i = (m'_i − m_i)(ō^txt_i − ō^img_i) + m'_i·δ_val。（公式3）

两项都可以通过q_i和m_i依赖于提示词，而只有第一项使用流平均值；若无键偏移，则o'_i − o_i = m_i·δ_val。在SD3.5-M中，注意力前的归一化通常使键和值偏移在词元间不同，定理S1给出其一阶效应。交叉注意力（每个查询仅读取文本词元）则不同：归一化后的共享键偏移会抵消，共享值偏移则向每个查询词元添加一个固定向量。在Wan2.1上，仅作用于键输入的常数无法恢复HPSv3增益，接近此预测，尽管Wan2.1对其键做了归一化（第I节）。

6 结论

RL后训练更新扩散Transformer的权重，因此它对每个提示词和词元产生不同的激活变化，这似乎是文本渲染等提示词特定技能所需要的。然而，在所有输入间共享且拟合时目标函数中不含奖励的引导向量，恢复了六个图像和两个视频RL调优模型的大部分奖励增益。在冻结的SD3.5-M上用Flow-GRPO训练，这些向量超越了OCR调优和PickScore调优模型的奖励增益，且用户研究将所得图像评为与RL调优模型相当。因此，大部分RL增益存在于一小组常数向量中，由冻结生成器将其转化为提示词特定的图像。在SD3.5-M上，增益偏向条件通道、早期步骤和文本流，并通过图像词元在联合注意力中从文本读取的内容到达图像。我们推测，策略梯度RL后训练主要是将基础模型引导向其已经能够计算的内容。优化这些奖励是否能从新的依赖输入的变换中获益，还是当前RL方法无法学到它们，仍是开放问题。所有八个RL调优模型都使用策略梯度，因此偏好优化和奖励反向传播尚未被测试。

训练种子。 对于SD3.5-M上的每个PickScore调优和OCR调优模型，三个训练种子的拟合达到几乎相同的增益。1,500次训练更新后，三个PickScore增益在512个PickScore提示词上跨度为0.006点（图S1）。三个OCR增益在256个OCR提示词上跨度为0.011。

起点。 零初始化在PickScore和OCR上达到与s_mean初始化几乎相同的增益。在512个提示词的PickScore测试子集上，零初始化拟合获得+1.34，而s_mean初始化拟合获得+1.36。在256个OCR提示词上，10,000个训练提示词上的零初始化拟合获得+0.317，s_mean初始化拟合获得+0.324。两个OCR拟合用不同的向量达到该增益，余弦相似度为0.33。s_mean初始化的拟合与s_mean保持0.97的余弦相似度，训练在其上添加的变化与零初始化拟合的余弦相似度为0.90。所有四个拟合最多使用1,500次训练更新和一个训练种子。

提示词数量。 在OCR上，64个不同训练提示词足以拟合引导向量（图S1）。此消融中的每次拟合使用约10,000个RL调优模型样本、最多1,500次训练更新和一个训练种子。在256个OCR提示词上，256个训练提示词上s_mean初始化的拟合保持了10,000个提示词拟合的全部增益。64个提示词上的拟合保持该增益的94%，64个提示词上的零初始化拟合保持其自身10,000提示词增益的全部。64个提示词上的零初始化拟合获得+0.318，其与10,000提示词零初始化拟合的配对差异为+0.000 [-0.019, +0.019]。在每个提示词数量上，每个拟合的增益都在其自身10,000提示词增益的0.02以内。

训练状态。 引导的基础模型应当在RL调优模型自身采样所访问的状态上匹配它。速度匹配使用RL调优模型的重新加噪最终图像，它们位于其采样轨迹附近。对于SD3.5-M和FLUX.1-dev上的四个RL调优模型，我们分别在其重新加噪最终图像上和其采样轨迹的状态上各拟合一组引导向量。每个拟合使用1,500次训练更新和一个训练种子，每个在其奖励的提示词上用一个采样种子评分。在全部四个模型上，两个拟合达到几乎相同的增益（图S1）。最大差异出现在SD3.5-M的PickScore调优模型上，为512个PickScore提示词上的-0.030 [-0.050, -0.011]点（采样轨迹状态减去重新加噪状态）。

颜色。 颜色能量是YCbCr中图像两个色度通道方差之和。两个RL调优模型都降低了基础模型图像的颜色能量，无KL的RL调优模型比有KL的降低更多。每组引导向量跟随其对应的RL调优模型。有KL的RL调优模型保持了基础模型颜色能量的0.550，引导的基础模型为0.542。无KL的RL调优模型保持了0.379，引导的基础模型为0.377。

F 注意力恒等式

本节证明第5节中的注意力恒等式。

图S7：冻结的块将相同偏移转化为不同的速度变化。示意图：相同的s相等地移动块输出A、B和C，而它们的速度以不同幅度和方向变化。

带偏移键和值的联合注意力。 考虑第5节中的一个联合注意力头，头维度为d_h。图像词元i具有查询q_i，任一流的词元j具有键k_j和值u_j（我们不称之为v_j，因为v表示速度）。这些是进入注意力的向量，位于任何归一化之后。注意力概率为

m_ij = e^(q_i^⊤k_j/√d_h) / Σ_{j'} e^(q_i^⊤k_{j'}/√d_h)，（公式S1）

其中j'遍历两个流的词元，头输出为o_i = Σ_j m_ij·u_j。设m_i = Σ_{j∈txt} m_ij为文本词元上的注意力份额，在联合注意力中位于(0,1)内。设ō^txt_i = Σ_{j∈txt} m_ij·u_j/m_i和ō^img_i = Σ_{j∈img} m_ij·u_j/(1−m_i)为各流内值的平均值，因此o_i = m_i·ō^txt_i + (1−m_i)·ō^img_i。撇号标记变化后的量。如果每个文本键移动一个向量δ_key，每个文本值移动δ_val，而查询和图像词元不变，则

m'_i/(1−m'_i) = (m_i/(1−m_i))·e^(q_i^⊤δ_key/√d_h)，

o'_i − o_i = (m'_i − m_i)(ō^txt_i − ō^img_i) + m'_i·δ_val。（公式S2）

定理S1（带偏移键和值的注意力） 设每个文本键变为k_j + δ_key，每个文本值变为u_j + δ_val，查询、图像键和图像值不变。则文本词元内的权重m_ij/m_i和图像词元内的m_ij/(1−m_i)不变，且公式S2成立。 对于可能跨词元不同的变化dq_i、dk_j和du_j，输出的一阶变化为

do_i = Σ_j m_ij·du_j + (1/√d_h)·Σ_j m_ij·(u_j − o_i)·(q_i^⊤dk_j + k_j^⊤dq_i)。（公式S3） 如果图像词元i仅读取文本词元（如交叉注意力），且其查询不变，则文本键的公共偏移使其输出不变，文本值的公共偏移向其添加δ_val。

证明。 设S^txt_i和S^img_i为公式S1分子在文本和图像词元上的和，因此m_i/(1−m_i) = S^txt_i/S^img_i。键偏移将每个文本词元的分子乘以e^(q_i^⊤δ_key/√d_h)，而图像词元的不变。一个流内的权重是该流分子的比值，因此不变。S^txt_i乘以相同因子而S^img_i不变，得到公式S2的第一行。文本词元内的权重和为一，因此值偏移将ō^txt_i移动到ō^txt_i + δ_val，而ō^img_i不变。因此o'i = m'_i·(ō^txt_i + δ_val) + (1−m'_i)·ō^img_i，减去o_i即得第二行。 logit q_i^⊤k_j/√d_h的一阶变化为Δ_ij = (q_i^⊤dk_j + k_j^⊤dq_i)/√d_h。对公式S1微分得dm_ij = m_ij·(Δ_ij − Σ{j'} m_{ij'}·Δ_{ij'})。则do_i = Σ_j m_ij·du_j + Σ_j dm_ij·u_j，且Σ_j m_ij·u_j = o_i，因此Σ_j dm_ij·u_j = Σ_j m_ij·Δ_ij·(u_j − o_i)，即公式S3。 若词元i仅读取文本词元，键偏移将公式S1的每个分子乘以相同因子，因此无权重变化。权重和为一，因此值偏移向输出添加δ_val。□
