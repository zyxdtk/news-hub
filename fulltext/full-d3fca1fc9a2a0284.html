Spatial-Aware VLAs. Most existing VLMs are pre-trained solely on 2D image-text data, which inherently limits their accurate understanding of the 3D physical world. SpatialVLA [ 41 ] introduced 3D positional encodings and adaptive action grids to capture transferable spatial knowledge. BridgeVLA [ 28 ] takes as input orthographic projection images of 3D point clouds and aligns point clouds across different views by predicting corresponding heatmaps. IV-B VLM Model We construct a tiny-scale vision-language model based on Prismatic-VLM [ 20 ] , which consists of a Qwen2.5-0.5B [ 54 ] language model backbone, a projector composed of MLPs, and a dual-component visual encoder comprising pretrained SigLIP [ 58 ] and DinoV2 [ 39 ] models. Here, SigLIP extracts high-level open-vocabulary semantic information, while DinoV2 features are incorporated to enhance spatial perception in robotic manipulation tasks [ 20 ] . Given an input image, the DINO and SigLIP encoders extract visual features separately, which are then concatenated along the channel dimension to form the combined visual representation. The projector takes this visual representation and maps it into the space of the language model. During VLM training, we perform end-to-end training via next-token prediction using multimodal data pairs collected from diverse internet sources.
