摘要

智能体强化学习（RL）与多教师在线策略蒸馏（MOPD）为后训练提供了互补路径。然而，对于视觉智能体而言，工具使用带来两个相互关联的挑战：模型可能忽视工具返回的有用观测，而定位不佳的动作会限制后续蒸馏可用的证据。我们提出 Reframe，一个将观测状态（而不仅是输出分布）作为对齐对象的后训练框架。首先，Ground-Drop-GRPO（GD-GRPO） 使用证据感知奖励和随机移除原始视觉输入来训练空间与时间专家模型，鼓励它们获取有依据的证据并使用返回的观测。其次，Observation-Gated-MOPD（OG-MOPD） 在 rollout 中途将有缺陷的工具动作替换为规范动作，并从修复后的观测继续蒸馏。两个阶段相辅相成，因为学会依赖工具返回的观测可以帮助策略从观测修复中受益。两个阶段均无需任务特定的 SFT 冷启动。在 14 个图像和视频基准上的大量实验表明，Reframe 优于 Mix-RL 和原始 MOPD。消融结果显示，与基于结果的 GRPO 相比，GD-GRPO 提升了观测依赖度和工具增益。

1 引言

智能体视觉推理通过为视觉-语言模型（VLM）配备工具来获取细粒度证据，从而解决以感知为中心任务中的证据稀疏瓶颈。相关工作包括“借助图像思考”[32, 46, 48, 13, 33, 34, 25]与“借助视频思考”[45, 41, 12, 28]。然而，调用工具并不能保证模型会使用其返回的内容。我们将这一问题称为观测忽视（observation neglect）：模型获取了中间观测，但其后续推理基本未受影响 [37]。在改进工具调用时机的研究 [33, 42, 34] 之外，这引出了一个互补性问题：如何训练模型有效利用所获取的观测。

与此同时，以往大多数工作仅关注单一模态，而少数同时纳入图像和视频工具的工作依赖于“混合数据先 SFT 后 RL”的训练范式。然而，这往往使最终的统一模型显著落后于单模态训练的模型。我们认为，这是离线 SFT 训练的模式冲突与 RL 监督稀疏性共同作用的结果。一个更有前景的替代方案是密集监督、以在线策略为主的训练范式。在线策略蒸馏（OPD）是一种基础性方法：通过以密集的 token 级反馈监督学生自身的 rollout，它同时规避了 RL 的稀疏信用分配和离线模仿的参考偏差 [1, 31]。扩展这一范式，多教师在线策略蒸馏（MOPD）[24] 将学生生成的轨迹路由到领域专门化的教师，并已被前沿模型日益广泛地采用 [23, 44, 14, 5, 4]。后续工作进一步在能力失衡 [11]、异构收敛 [2]、工具使用下的行为漂移 [29] 以及跨模态路由 [20, 27] 等方面加以完善。然而，现有范式主要改进监督的传递方式，而不干预 rollout 轨迹。这对智能体视觉推理是一个关键限制，因为后续监督全部以工具返回的内容为条件。

基于上述动机，我们提出 Reframe，一个由 Ground-Drop-GRPO（GD-GRPO）和 Observation-Gated-MOPD（OG-MOPD）组成的两阶段训练框架。两个训练阶段共同强化有效工具使用的两个核心属性：GD-GRPO 使获取的观测成为必要，而 OG-MOPD 保持其有效。GD-GRPO 通过增强基于观测的奖励并随机丢弃原始视觉输入，直接针对观测忽视问题，迫使模型真正依赖工具返回的结果。随后，OG-MOPD 通过修复偏离的工具使用，确保能力整合始终以有效轨迹为条件。在 14 个图像和视频基准上，Reframe 优于 Mix-RL 和原始 MOPD，甚至平均而言超越了专门的专家模型。此外，观测依赖度的诊断分析证实，Reframe 对工具返回结果表现出比以往方法显著更强的因果依赖。

我们的贡献总结如下：

  • 我们提出 Reframe，首个统一图像与视频智能体推理的工具使用 MOPD 框架。其 OG-MOPD 主动干预 rollout 轨迹并修复偏离的工具动作，在跨模态整合全程促进观测有效性。
  • 我们解决观测忽视问题——即智能体 VLM 调用工具却忽视其返回内容的问题。通过 GD-GRPO，我们借助输入丢弃和观测奖励强化观测必要性。
  • 我们构建了 Reframe-100K 数据集以支持两个训练阶段。在 14 个图像和视频基准上的评估显示性能持续提升。代码、数据集和模型均已开源。

2 相关工作

智能体视觉推理。 多模态推理常使用文本思维链[6, 7]，但其收益因视觉任务而异 [43, 9, 22]。近期方法转而将视觉信息纳入推理过程 [25, 16]，包括通过界面或代码形式的工具调用获取与查询相关的观测。这些工具使模型能够以更细的粒度检查图像区域和视频片段，而这些细节可能难以从原始输入中直接解析。然而，获取更精细的视觉证据并不能保证其被使用。近期研究发现，工具返回的观测对后续预测可能几乎没有因果影响 [37, 26]。

在线策略蒸馏。 OPD 对学生生成的 rollout 提供密集的 token 级反馈，减少离线模仿的状态分布失配 [1, 31]。有效的迁移取决于兼容的推理方式与教师的新颖能力 [19]、对学生已访问状态的覆盖 [10]，以及教师纠正落在学生可学习的 token 支持范围内 [36]。扩展工作包括通过无 logit 验证支持黑盒教师 [50]、时序视频定位 [17]，以及通过教师生成的推理步骤进行监督 [39]。这些方法主要沿学生生成的轨迹改进监督。然而，对于视觉智能体，先前的工具动作同样决定了监督应用时可用的观测。对后续内容的 token 级反馈无法追溯性地恢复先前动作未能获取的证据。

多教师在线策略蒸馏。 MOPD 通过在共享学生的 rollout 上路由教师监督来整合独立训练的专家模型 [24]，这一方法在前沿模型后训练中日益普及 [23, 44, 14, 4]。Open-MOPD 研究了 token 预算、收敛漂移和过时监督导致的失衡 [11]；D³-MOPD 使领域采样适应不同的收敛速率 [2]。多模态变体为 GUI 交互和视频理解路由专家 [20, 27]。其他工作发现，尽管保留了足够的教师概率质量，决策关键的工具 token 仍会出现失真 [29]。这些进展聚焦于路由和监督，而通常将 rollout 观测视为既定条件。Reframe 则同时考虑所获取的观测是否被使用，以及它们是否为后续蒸馏提供有效证据，从而支持统一的图像与视频推理。

3 方法

本节介绍 Reframe 的数据构建和两阶段训练流程。我们做出三项设计选择：(1) 为简单起见，将工具集限制为两个基础视觉工具 CropImage 和 SelectFrames；(2) 采用 Qwen3.5-9B 作为基础模型；(3) RL 和 OPD 阶段使用相同的数据语料。

3.1 训练数据构建

Reframe-100K 包含 63K 图像问答对和 37K 视频问答对，由异构的空间和时间定位标注构建而成。如图 2 所示，我们建立了遵循以下三项原则的五步级联数据构建流程。

图 2：Reframe-100K 的构建流程。

我们首先收集公开数据源并预处理为原始数据池；然后剔除仅凭文本即可回答的样本，并用 8 次 rollout 分别在完整输入（F）和仅标注证据（E）上审计其余样本，丢弃 过易或过难、 证据支持不足的样本。剩余可疑样本由 Qwen 诊断，仅在最终审核者确认答案或证据错误时才移除。

定位标注质量控制。 定位标注的质量对我们的框架至关重要，因为不可靠的证据会同时损害证据感知奖励和后续的观测修复。因此，我们在整个数据清洗流程中强调证据质量，纳入多轮证据审计与验证。如图 2 所示，这些程序旨在确保保留的标注为视觉工具使用提供可靠监督。

以数据为中心的工具适用性。 判断工具调用是否有益仍具挑战性，尤其是当模型尚未形成可靠的工具使用能力时。与依赖模型的策略 [33, 34] 不同，我们从标注覆盖范围推导工具适用性标签，区分有益、中性和无益样本，而不依赖基础模型的 rollout 准确率或更强模型对工具效用的判断。这避免了将模型预测偏差引入适用性标签。重要的是，样本不会仅因基础模型能不用工具答对而被丢弃，因为即使被正确回答的问题也能提供有价值的空间或时间工具使用监督。

上下文感知证据。 定位标注通常定位最小目标或时间事件，而视觉问答通常需要周围上下文来进行识别、比较或消歧。因此，我们将每个空间边界框以其中心为中心将宽和高各放大 1.5 倍，并将结果裁剪至图像边界内。对于时间证据，我们将每个连续标注片段的两端各延长一帧。这种保留上下文的松弛提供了额外证据，同时不会引入过多无关视觉内容。我们仅在计算证据覆盖率和构建工具监督之前应用一次。

最后，空间和时间标注被转换为统一格式下的可执行工具元数据。由此得到的 Reframe-100K 同时支持 RL 和 OPD。

3.2 GD-GRPO

图 3：GD-GRPO 概览。策略采样多轮工具使用 rollout。首次成功调用工具后，原始输入 o₀ 以 0.5 的概率被丢弃，而工具返回的观测 oₜ 保持可见，因此答案必须依赖工具检索到的内容。Rollout 按预采样的丢弃标志 dᵢ 分组，优势在各子组内归一化，使丢弃操作不会混淆比较。

我们使用 GD-GRPO 在 Reframe-100K 的图像和视频子集上独立训练空间和时间专家模型。核心思想是将观测获取与观测依赖相耦合：观测奖励引导策略采取信息丰富的工具动作，而原始观测丢弃降低其绕过所得观测的倾向，从而确立所获取观测的必要性。GD-GRPO 的特征在于三个关键设计：奖励、丢弃和子组。

3.2.1 奖励设计

仅凭结果正确性无法稳定揭示工具是否检索到相关信息，或后续推理是否使用了其返回的观测。对于由问题及其原始观测组成的输入 x=(Q, o₀)，奖励定义为

R(τ; x, p) = R_ans(τ, x) + f(p)·R_call(τ, x) + λ_obs·R_obs(τ, x) − R_pen(τ, x)，(1)

其中 τ 和 p∈[0,1] 分别表示轨迹和训练进度。四个项分别评估答案正确性、工具调用行为、定位质量和输出有效性，其中工具调用项提供源自基于标注的适用性的临时探索激励。有效调用奖励和不适用的调用惩罚均随训练进度按以下方式衰减：

f(p) = (exp(−κp) − exp(−κ)) / (1 − exp(−κ))，κ>0。(2)

与 R_call 不同，R_obs 在整个训练过程中保持活跃。对于图像，我们使用全局一对一 IoU 匹配将轨迹上的裁剪图像与标注区域联合匹配，这奖励互补覆盖，同时防止对同一目标的重复定位使奖励倍增。对于视频，我们使用帧 IoU 评估最新尝试，而非回顾性地选择最有利的尝试。较晚的尝试会被折扣以鼓励高效获取。重要的是，定位监督不受答案正确性门控：即使策略未正确回答，恰当的工具动作也会获得信用。没有定位标注的样本不获得 R_call 或 R_obs，仍由答案正确性和有效性惩罚监督。

3.2.2 原始观测丢弃

精确定位本身并不能确立观测依赖。模型仍可能从原始视觉输入作答而不使用工具返回的结果。为减少这种绕过行为，我们在训练中首次成功调用工具后以 0.5 的概率丢弃 o₀，同时保留问题、文本历史和工具返回的观测。模型随后必须依赖所获取的观测进行后续推理，而非通过原始输入绕过它们。推理时，原始视觉输入始终保留。

丢弃操作并非规定工具动作，而是改变其促成成功推理的条件。通过移除原始视觉输入，它将工具返回的观测从补充线索转变为后续推理的必要信息。与定位奖励相结合，它鼓励策略既获取信息丰富的观测，又真正依赖它们。

3.2.3 丢弃条件子组

原始观测丢弃为 rollout 难度引入了外部变异源。将丢弃和保留的轨迹与共享组基线比较可能会鼓励低质量轨迹，从而将动作质量与随机分配的条件相混淆。为此，我们在共享相同预采样丢弃指示符 dᵢ∈{0,1} 的子组内计算相对优势。对于输入 x 的 rollout {τᵢ}，定义 𝒢_{x,d}={i: dᵢ=d}。优势为

Aᵢ = (Rᵢ − μ_{x,dᵢ}) / (σ_{x,dᵢ} + ε)，若 |𝒢_{x,dᵢ}|>1；否则为 0。(3)

关键在于，子组由预采样的丢弃指示符而非实际丢弃定义，确保组分配保持独立于策略的工具使用决策。

总体而言，GD-GRPO 将观测获取与下游依赖耦合：定位奖励鼓励策略获取信息丰富的观测，而原始视觉丢弃促进其实际使用。这为后续 OG-MOPD 阶段的观测对齐能力整合奠定了基础。

3.3 OG-MOPD

对于工具使用模型，蒸馏的有效性不仅取决于所选教师，还取决于其监督应用时可用的观测。有缺陷的工具动作可能使学生陷入信息匮乏的视觉状态，约束所有后续教师反馈。尽管 token 级优化可以改进未来的动作，但对当前后续内容的反馈无法追溯性地修复已返回的观测。因此，OG-MOPD 在工具动作边界进行干预以提高观测有效性，同时保留学生的生成。本质上，这是在线策略学习与观测有效性之间的权衡。

图 4：OG-MOPD 概览。学生策略的工具动作通过 IoU 阈值与标注证据核对。缺失、无效或定位不佳的动作被替换为源自标注的动作，以获取与查询相关的观测。注入的动作 token 接受 NLL 监督，而保留的学生生成 token 用 MOPD 训练。

3.3.1 观测门控 Rollout

设 aₜ 表示学生提出的工具动作，aₜ 表示从定位标注导出的规范动作，eₜ 表示相应的标注证据。对于工具适用的样本，我们按以下方式选择性地替换缺失、无效或定位不佳的动作：

ãₜ = aₜ，若 aₜ 无效或 IoU(aₜ, eₜ) < δ；否则为 aₜ，(4)

其中 δ 为定位阈值。缺失动作被视为无效，IoU 相对原始或上下文扩展标注测量。

环境执行 ãₜ 并返回相应观测，学生从该观测恢复采样。关键在于，这种选择性干预保留了定位良好的学生动作，同时修复有缺陷的动作，在在线策略探索与观测有效性之间取得平衡。

3.3.2 分支感知蒸馏

观测修复引入两种不同的 token 来源：学生采样 token 𝒮 和注入的动作 token ℐ。对于前者，我们保留标准 MOPD 监督，由相应的图像或视频专家对学生实际的后续内容提供密集的 token 级反馈。教师路由遵循已执行的工具动作，输入模态提供初始分配。然而，注入的动作并非从学生策略采样，不应被视为在线策略 token。因此我们引入单独的 NLL 目标：

ℒ_OG-MOPD = ℒ_MOPD(𝒮) + λ_br·ℒ_NLL(ℐ)，(5)
ℒ_NLL(ℐ) = −(1/|ℐ|) Σ_{k∈ℐ} log π_θ(yₖ | hₖ)，

其中 hₖ 表示 token yₖ 之前的交互历史。若无注入动作，则省略 NLL 项。这种分离提供了互补监督：NLL 教会学生如何到达信息丰富的观测状态，而 MOPD 沿后续学生采样轨迹迁移专家行为。推理时，既不需要观测门控，也不需要专家教师。训练细节见附录 B。

4 实验

4.1 实验设置

基准。 我们在七个图像基准和七个视频基准上评估 Reframe，检验针对性的视觉检查能否转化为细粒度感知和更广泛的视觉理解。图像方面，V* [40]、HR-Bench 4K/8K [35]、VisualProbe [15] 和 ZoomBench [38] 强调在复杂视觉输入中发现并解析任务相关细节的能力；MME-RealWorld [47] 将评估扩展到多样化的真实场景；PerceptionBench [21] 探测原子级视觉感知。视频方面，Video-MME [8]、Video-MME-v2 [9]、MVBench [18] 和 MLVU [49] 评估跨多样任务和时间尺度的理解；MME-VideoOCR [30] 和 VSI-Bench [43] 分别针对视频文本理解和空间推理；V-STaR [3] 探测空间和时间证据理解。

基线。 我们进行两组比较。第一组使用五个基线比较训练范式：Qwen3.5-9B；Image-RL 和 Video-RL（用 GD-GRPO 在单模态数据上训练的模态专门专家）；Mix-RL（用 GD-GRPO 在图像和视频合并数据上训练）；以及 MOPD（通过原始 MOPD 整合两个专家）。第二组将 Reframe 与现有智能体视觉推理模型 Pixel-Reasoner、Thyme、DeepEyes 和 DeepEyesV2 在性能、观测依赖度和工具增益方面进行比较。此外，基于结果的 GRPO 作为诊断所提 GD-GRPO 的基线。

评估协议。 我们使用贪心解码在共享视觉 token 预算下评估所有模型。每张原始图像最多 5,120 个 token，每张工具返回图像最多 1,960 个 token。视频使用 64 帧、每帧 128 个 token。每个选定帧最多 400 个 token，并受所有 select 调用累计 4,096 token 预算约束。评估细节见附录 C。

4.3 消融与分析

我们首先检验 GD-GRPO，然后比较专家整合方法，最后针对现有智能体分析观测依赖度和工具增益。

4.3.1 GD-GRPO 的有效性

表 3 比较了分别用 GD-GRPO 和基于结果的 GRPO（仅使用正确性奖励且无原始观测丢弃）训练的图像专家。GD-GRPO 将图像平均分提高 2.07 分。在工具增益评估中，启用工具为 GD-GRPO 增加 3.82 分，而 GRPO 为 1.97 分，同时无工具准确率仅提高 0.22 分。这些结果表明，GD-GRPO 对一般视觉能力的提升有限，其主要收益在于使模型能够将视觉工具使用转化为更好的推理性能。

为更好地理解这种与工具相关的改进，我们考察 GD-GRPO 如何改变模型对不同工具观测的响应。GD-GRPO 在 GT、Random 和 Blank 条件下分别将准确率提高 5.23、3.67 和 3.14 分，其中 GT 条件下增益最大。我们用依赖度分数（附录 C.2）总结这一行为，其定义为在无信息观测（Random 和 Blank 的均值）下的错误中，一旦提供真实观测即被纠正的比例。它衡量对观测内容的敏感性而非整体能力。GD-GRPO 将其从 52.59 提高到 69.03，同时还提高了受损观测下的准确率。结合更大的工具增益，这些结果支持模型更好地利用返回观测，而非更容易受误导性观测影响。

4.3.2 训练范式比较

我们在表 2 中将 Mix-RL、MOPD 和 Reframe 与模态专门专家进行比较。

Mix-RL 不及专家模型。 Mix-RL 在各自模态上分别落后 Image-RL 和 Video-RL 1.17 和 1.37 分（表 2），保留了其相对基础模型增益的 74% 和 55%。尽管它使用 GD-GRPO 奖励，但这些信号被聚合为轨迹级优势，而非对每个获取和推理决策的单独评估。共享策略因此必须联合发现空间和时间策略，但有利于某一模态的梯度更新未必有益于另一模态。这将跨模态探索与粗粒度信用分配相耦合，为专家差距提供了合理解释。相比之下，MOPD 的结果表明在两种模态上接近专家的性能是可实现的，说明学习过程确实重要。

MOPD 接近专家性能。 MOPD 分别保留了 Image-RL 和 Video-RL 所获增益的 106% 和 85%，并在 14 个基准中的 5 个上超越两个教师。与 Mix-RL 的关键区别在于监督密度：Mix-RL 使用轨迹级优势，而 MOPD 为每个生成的 token 提供专家反馈。这为学生提供了对中间生成选择更直接的指导，减少了从聚合的响应级信号推断其价值的需要。这种密集监督可以更好地利用每次 rollout，使 MOPD 成为整合专家的更实用选择。

观测修复带来额外增益。 以相同的 GD-GRPO 专家为教师，Reframe 在图像上比 MOPD 提高 1.29 分，在视频上提高 0.78 分。最大增益出现在 VisualProbe 上（+4.86）。MOPD 已同时教授动作和推理，但其对后续内容的反馈以学生已获得的观测为条件。修复在蒸馏继续之前提供任务相关的证据，因此其贡献集中于工具适用样本中有缺陷的动作，补充了 MOPD 已实现的更广泛整合。观测修复的核心权衡在于观测有效性与 rollout 保持在线策略的程度之间：外部提供的动作改变了学生继续的历史，尽管后续内容本身仍是学生生成的。OG-MOPD 通过保留有效的学生动作并仅修复有缺陷的动作来限制这种干预。对注入动作的 NLL 鼓励学生在推理时自行产生纠正后的动作。

视觉推理可部分跨模态迁移。 Image-RL 将视频平均分从 49.75 提高到 50.39，而 Video-RL 将图像平均分从 63.46 提高到 66.35。可迁移的成分可能包括实体识别、OCR 和空间智能等基础视觉能力，以及寻求细粒度证据的共同倾向。面向定位的训练可以提升超越其训练任务的一般感知。

4.3.3 与现有智能体模型的比较

Reframe 在表 4 的全部 14 个基准上领先，图像和视频平均分分别超过最强的外部模型 11.71 和 8.86 分。在共享视觉预算下，我们考察模型如何使用所获取的观测并从工具中受益。

Reframe 使用其获取的证据。 在 V* 上，我们以真实（GT）、随机和空白裁剪图像作为工具返回观测来考察模型性能。Direct 评估无工具的模型，Natural 让模型自行决定何时以及如何使用工具。Reframe 的依赖度分数为 75.53，而其他模型至多为 41.93。尽管原始图像仍然可用，其准确率在 GT 下达到 96.86，而 Random 下为 85.86、Blank 下为 88.48。当工具动作可靠地获取相关证据时，对返回观测的依赖可以是有益的。Reframe 在各条件间更大的差距、强劲的 GT 表现和正的工具增益共同表明，它能够将这种依赖转化为更好的推理性能。

工具对 Reframe 的贡献更大。 工具增益通过衡量自主工具使用的收益，补充了受控观测分析。在七个图像基准上，工具将 Reframe 从 64.25 提高到 69.48，增益 5.23 分，而其他模型至多 1.47 分。相对于无工具的 Qwen3.5-9B（63.46），总增益的 87% 源自工具使用，表明 Reframe 的优势主要来自与视觉工具的交互。有用的观测必须通过模型自身的动作获取，因此更大的工具增益证明 Reframe 能够结合证据获取与使用来改进最终答案。

5 结论

Reframe 主要通过在线策略训练整合图像与视频推理。GD-GRPO 通过定位奖励和原始输入丢弃鼓励对工具返回观测的依赖，而 OG-MOPD 在继续蒸馏前修复有缺陷的工具动作。在 14 个基准上，Reframe 优于 Mix-RL 和原始 MOPD，甚至超越了两个专家模型。诊断评估显示，与所比较的智能体视觉模型相比，Reframe 具有更强的观测依赖度和更大的工具增益，凸显了既获取有用证据又学会使用它的重要性。

C.2 观测依赖度研究

该研究使用 V* 的 191 道选择题，每个问题在五种条件下各采样一次。Direct 中，模型不用工具回答。Natural 中，模型选择自己的工具动作。对每个模型和问题，三个受控条件共享注入的规范裁剪动作、相同的前置延续文本和相同的工具响应文本，仅返回的图像内容变化。每个受控工具响应以相同指令结束：“这是你唯一的工具调用。现在根据上方图像回答问题，不要再调用任何工具。”

  • GT：标注的目标区域，使用构建规范裁剪时保留上下文的扩展。
  • Random：原始图像中不同位置的相同大小裁剪，使用依赖问题的随机种子。
  • Blank：相同大小的恒定灰色图像，RGB 值为 (128,128,128)。

所有三个返回图像使用相同的调整大小和视觉 token 预算。随机裁剪与 GT 的 IoU 至多为 0.1。若 100 个采样位置均不满足，我们选择样本和四个图像角中 IoU 最低的位置。

完整原始图像在所有五个条件下保持可见。插入受控观测后，模型生成一个延续，不再执行进一步工具动作。再次调用工具的尝试被单独记录。最终选择针对选项字母确定性评分。无可解析最终答案的模型输出得零分。外部智能体探测还将尝试延续工具调用标记为无效完成，包括伴随答案的情况。

观测依赖度定义为相对无信息观测的归一化错误减少率（%）：

Dependence = 100 × (S_GT − (S_Random + S_Blank)/2) / (100 − (S_Random + S_Blank)/2)。(6)

依赖度衡量在固定工具动作下、提供真实观测时，无信息工具输出下的错误被解决的比例，并考虑不同基线准确率模型间的天花板效应。
