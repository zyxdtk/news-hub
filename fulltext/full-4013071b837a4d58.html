面向5G及未来的多基地ISAC深度学习杂波抑制

作者： Yalin E. Sagduyu、Tugba Erpek、Sastry Kompella

单位： Nexcepta, Gaithersburg, MD, USA

摘要

利用5G及更先进机遇信号的集成感知与通信（ISAC）系统，可借助共享基础设施和频谱资源实现无线感知与通信的联合运行。虽然多基地ISAC能够通过空间分布的接收机扩大感知覆盖范围，但密集且动态的杂波会显著降低双基地距离与多普勒估计性能，导致目标定位和速度估计出现误差。本文提出一种带杂波抑制的多基地ISAC框架，用于高保真地估计目标位置和速度。分布式杂波采用位置随机、多普勒扩展和雷达截面积各异的散射体建模，以刻画密集和动态杂波效应。本文评估了多种传统信号处理杂波抑制基线方法，结果显示其在强杂波条件下鲁棒性有限。为解决这一局限，引入了基于深度学习的杂波抑制方法，采用残差和注意力增强的深度神经网络架构，直接从受杂波污染的观测中增强目标响应，从而提升对密集和动态杂波的鲁棒性。在多基地ISAC的多种杂波条件下，这些方法在目标位置和速度估计方面显著优于传统方法。

索引词： ISAC、多基地、深度学习、5G、6G、定位、速度估计、杂波抑制

I 引言

集成感知与通信（ISAC）是下一代无线网络的关键技术，它利用共享频谱和基础设施将通信信号重新用于感知[1]。ISAC的一项重要优势是能够利用机遇信号（如商用5G NR信号）进行目标感知与检测[2,3,4]。尤其是，5G NR定位参考信号（PRS）提供了结构化的导频图案，可被有效重新用于被动感知，无需专用雷达发射机，并支持在大范围内进行持续的低成本感知[5]。ISAC能力对情报、监视与侦察（ISR）、边境监控和反无人机系统等关键任务应用尤为重要，这些应用需要在复杂环境中进行稳健的感知、定位和跟踪。

单基地ISAC系统采用同址部署的发射机和接收机，这简化了同步和信号处理，但限制了感知覆盖范围和几何分集[6,7,8,9,10]。相比之下，多基地ISAC系统利用空间分布的接收机观测来自同一发射机的反射，可获得更好的空间分集、更广的覆盖范围、更强的目标可观测性以及更精确的定位[11,12]。尽管具有这些优势，多基地ISAC感知在密集杂波环境中仍面临挑战，因为延迟和多普勒频移的杂波反射可能在双基地距离-多普勒空间中与目标回波重叠。由于杂波特性在空间分布的各接收机之间可能存在差异，杂波会显著降低目标定位和速度估计性能[13,14]。

本文研究杂波环境中使用5G NR PRS的多基地ISAC，利用空间分布的接收机进行双基地距离-多普勒估计、二维（2D）目标定位和速度估计。采用基于互模糊函数（CAF）处理和非线性多边定位的多基地感知框架。杂波由位置、雷达截面积（RCS）和多普勒扩展均随机化的分布式散射体引入，以刻画包括与目标回波存在显著多普勒重叠的高度动态杂波在内的多种杂波条件。我们表明，基于传统信号处理的杂波抑制方法只能带来部分改善，其有效性在使多基地ISAC性能退化的密集或动态杂波条件下会明显下降。

为提升鲁棒性，我们引入基于深度学习（DL）的杂波抑制方法，直接从受杂波污染的观测中增强目标响应。第一种方法采用残差U-Net架构进行目标增强的残差估计；第二种方法引入方向性卷积处理和注意力门控特征融合，以进一步改善杂波抑制、目标增强和多基地感知性能。我们证明，所提出的残差与注意力感知DL方法在广泛的杂波条件下显著优于传统杂波抑制方法，实现了显著改善的双基地距离-多普勒估计、目标定位和速度估计性能。

本文其余部分组织如下：第II节介绍信号与杂波模型；第III节描述位置与速度估计；第IV节讨论传统杂波抑制方法；第V节介绍基于DL的杂波抑制；第VI节评估性能；第VII节总结全文。

II 多基地ISAC信号与杂波模型

我们考虑一个发射5G NR PRS的照射源（基站）和M=3个协同处理反射信号以进行2D感知的分布式接收机，如图1所示。假设采用与[11]相同的5G数字学0，子载波间隔Δf=15 kHz，FFT大小N=1024，载波频率fc=2.5 GHz，采样率fs=15.36 MHz。PRS跨越K_RB=76个资源块，并按照3GPP TS 38.211使用QPSK Gold序列的流程生成[15]。资源分配采用梳状结构，梳齿间隔K_comb=2，偏移k_offset=0，不含直流子载波。每个NR时隙包含14个OFDM符号，其中含L_PRS=2个PRS符号。跨多个时隙的连续PRS传输产生K=128个相干慢时间感知观测。

对于接收机m∈{1,2,3}，双基地传播长度为

B_m(p) = ‖p−t‖ + ‖p−r_m‖, (1)

其中t为发射机位置，r_m为接收机m的位置，p和v分别为目标位置和速度（均在R²中）。

接收机m处对应的双基地径向速度为

v_m(p,v) = v^T[(p−t)/‖p−t‖ + (p−r_m)/‖p−r_m‖], (2)

其中(·)^T表示转置。它表示目标速度向量v在与接收机m对应的双基地观测方向上的投影。接收机m处产生的多普勒频移为

f_d,m = (fc/c)·v_m(p,v), (3)

其中c为光速。感知区域内包含N_c个随机分布的杂波散射体。第q个RCS为σ_q^(c)的杂波散射体位于c_q∈R²。杂波RCS值建模为独立的对数均匀随机变量，其尺度由杂波强度参数α_c控制，α_c越大对应越强的杂波回波。每个散射体贡献一个随接收机而异的多普勒分量

f_m,q^(c) ~ N(0, σ_f,c²), (4)

其中f_m,q^(c)为零均值高斯随机变量，方差为σ_f,c²，σ_f,c控制杂波多普勒扩展。σ_f,c越大杂波越动态，N_c越大杂波越密集。接收机m处的接收信号是目标回波、杂波反射和噪声的叠加：

y_m[n] = α_m·s[n−τ_m]·e^(j2πf_d,m·nT_s) + Σ_{q=1}^{N_c} β_m,q·s[n−τ_m,q^(c)]·e^(j2πf_m,q^(c)·nT_s) + w_m[n], (5)

其中s[n]表示发射的PRS波形，T_s=1/f_s为采样间隔，τ_m和τ_m,q^(c)分别表示目标和杂波的传播时延，α_m和β_m,q为其反射系数，w_m[n]~CN(0, σ_n²)为加性高斯白噪声。反射系数计入了双基地传播损耗、天线增益、载波波长以及目标和杂波的RCS。在窄带近似下，位于位置x的散射体的回波幅度建模为

γ(x) = √(P_T·G_T·G_R)·λ·√σ / [(4π)^(3/2)·R_tx·R_rx], (6)

其中P_T为发射功率，G_T和G_R分别为发射和接收天线增益，λ=c/f_c为载波波长，R_tx和R_rx分别为发射机到散射体和散射体到接收机的距离，σ为RCS。

在CAF处理之前，先估计直射路径并将其从接收信号中去除。

III 目标定位与速度估计

每个感知接收机将接收样本与已知的PRS参考序列进行相关。设0≤k≤K−1为慢时间PRS观测索引，t_k为第k个PRS符号的中点时刻，s_k[n]（0≤n≤N−1）为对应的无循环前缀（CP）PRS参考符号。对于时延单元0≤d≤D−1，接收机m处的相关输出为

C_m(k,d) = Σ_{n=0}^{N−1} y_m[n_k^cp + d + n]·s_k*[n], (7)

其中n_k^cp为观测k的无CP PRS区域的起始样本索引，(·)*为复共轭。所得矩阵C_m∈C^(K×D)表示用于杂波缓解和多普勒分析的慢时间时延响应。经杂波抑制（见第IV-V节）后，在慢时间维度上使用覆盖[−400, 400] Hz、含N_f=401个频率单元的多普勒网格进行相干积累。采用汉宁窗W[k]，接收机m在多普勒频率f处的CAF为

CAF_m(d,f) = Σ_{k=0}^{K−1} W[k]·C_m(k,d)·e^(−j2πf·t_k). (8)

幅度响应|CAF_m(d,f)|生成双基地距离-多普勒图。目标检测在CAF幅度响应上采用二维单元平均恒虚警率（CA-CFAR）方法。在检测单元附近沿时延和多普勒维度进行三点抛物线插值，以精化双基地距离和径向速度估计B̂_m和v̂_m。目标定位对所有接收机的双基地距离测量进行联合拟合。每个双基地测量定义一个以发射机和对应接收机位置为焦点的椭圆。当

ε_m(p) = ‖p−t‖ + ‖p−r_m‖ − B̂_m (9)

为与接收机m关联的双基地残差时，估计的目标位置通过求解

p̂ = arg min_p Σ_{m=1}^{M} (ε_m(p))² (10)

确定。由于双基地约束是非线性的，采用带多个随机初始化点的信赖域反射最小二乘求解器，并选择产生最小总残差误差的解作为最终估计。

估计出目标位置后，双基地径向速度关系关于笛卡尔速度向量变为线性。定义

u_m = (p̂−t)/‖p̂−t‖ + (p̂−r_m)/‖p̂−r_m‖ (11)

为接收机m的双基地观测方向。将这些向量堆叠构成观测矩阵U∈R^(M×2)，而估计的径向速度收集为

v̂_r = [v̂_1, …, v̂_M]^T. (12)

笛卡尔速度采用岭正则化最小二乘法估计（正则化参数ε＞0）：

v̂ = (U^T·U + ε·I)^(−1)·U^T·v̂_r, (13)

其中I为单位矩阵。目标速度大小为‖v̂‖，航向角由atan2(v̂_y, v̂_x)计算。

IV 杂波抑制基线方法

接下来，我们比较一组在慢时间时延相关矩阵C_m上运行的多种传统杂波抑制方法。它们利用时间差分、子空间投影、多普勒域滤波、自适应预测和平滑分量估计等技术抑制杂波。杂波抑制后，所得相关矩阵用于CAF计算和双基地距离-多普勒估计。

IV-1 无杂波抑制（NCS）
NCS跳过杂波缓解，直接由相关矩阵C_m计算CAF。

IV-2 当前-参考相减（CUR）
CUR作为基于相干参考的杂波抑制基准。设C_m^cur为当前受杂波污染的相关矩阵，C_m^ref为接收机m的仅含杂波的参考相关矩阵。从参考和当前观测中的主导杂波分量估计全局杂波相位偏移φ_m。相减前对当前观测进行相位对齐，得到杂波抑制后的相关矩阵

C_m^CUR = e^(−jφ_m)·C_m^cur − C_m^ref. (14)

杂波抑制后的矩阵C_m^CUR按式(8)用于CAF计算，以估计双基地距离和多普勒。

IV-3 空间投影自适应差分（SP-AD）
SP-AD通过在CAF处理前对相邻慢时间快照进行差分来抑制缓变杂波。

IV-4 秩一慢时间投影（SP-R1）
SP-R1将杂波建模为主导的秩一慢时间分量，并在多普勒处理前移除最强的奇异模式。

IV-5 DPSS带阻滤波（DPSS）
离散长球序列（DPSS）将杂波建模为低多普勒过程，通过将信号投影到DPSS杂波子空间的正交补空间来抑制杂波。

IV-6 杂波图时间多普勒滤波（CMTD）
CMTD利用以零频附近为中心的基于FFT的慢时间陷波滤波来抑制近零多普勒杂波。

IV-7 全变分高通滤波（TVHP）
TVHP将杂波建模为时间平滑分量，利用全变分正则化去除平滑的杂波响应。

IV-8 滚动中值高通滤波（RMHP）
RMHP沿慢时间维度采用滑动窗口中值滤波器抑制杂波，在去除缓变杂波响应的同时保留局部化的目标峰值。

IV-9 小波高通滤波（WHP）
WHP沿慢时间应用Haar小波分解，并利用高频细节分量重构信号。

IV-10 自适应最小均方（LMS）残差滤波（ALMS）
ALMS沿慢时间应用自适应LMS预测，并利用预测残差进行杂波抑制。

IV-11 多项式高通滤波（POLYHP）
POLYHP将杂波建模为沿慢时间缓变的低阶多项式，并去除估计出的多项式分量。

V 基于深度学习的杂波抑制

除基于信号处理的杂波抑制方法外，我们还引入两种监督DL方法，直接作用于经匹配滤波得到的慢时间时延相关矩阵C∈C^(K×D)。其目标是学习一个非线性映射，在保留精确双基地距离-多普勒估计所需目标响应的同时抑制杂波。训练数据由前述多基地ISAC信号与杂波模型生成。每个训练样本包含随机的接收机几何结构、目标位置、目标速度、杂波密度、杂波RCS、杂波多普勒扩展和噪声实现。训练输入为受杂波污染的匹配滤波矩阵

C_raw = C_target + C_clutter + N, (15)

其中C_target和C_clutter分别表示仅目标和仅杂波的相关矩阵，N表示加性噪声。期望输出为C_target。

下面介绍两种基于DL的杂波抑制方法，用于从C_raw估计C_target。估计得到的仅目标相关矩阵随后在式(8)中替代C_m用于距离-多普勒估计。

V-A 基于残差U-Net的DLCS

第一种DL方法DLCS-1采用监督残差U-Net架构，直接从受杂波污染的观测中估计仅目标的匹配滤波响应。

V-A1 输入表示
输入为

X = [C_raw^(I), C_raw^(Q)], (16)

其中C_raw^(I)和C_raw^(Q)分别为复值相关矩阵的同相和正交分量，在送入网络前使用输入张量的均方根（RMS）幅度进行归一化。

V-A2 网络架构
网络遵循带跳跃连接的编码器-解码器U-Net结构。编码器由重复的卷积块组成，通过最大池化操作逐步提取层次化的杂波与目标特征，同时降低空间分辨率。每个卷积块包含3×3卷积层、批归一化和修正线性单元（ReLU）激活。第ℓ层的特征张量F^(ℓ)编码为

F^(ℓ+1) = ReLU(BN(Conv(F^(ℓ)))), (17)

其中Conv(·)表示卷积，BN(·)表示批归一化。解码器通过双线性上采样和跳跃连接的编码器特征逐步重建目标增强的残差图。跳跃连接保留了与距离-多普勒域中局部化目标峰值对应的精细空间结构。最终输出层为1×1卷积，产生双通道估计

Ŷ = [Ĉ_target^(I), Ĉ_target^(Q)], (18)

其中Ĉ_target^(I)和Ĉ_target^(Q)为预测的仅目标相关矩阵的同相和正交分量。

V-A3 训练目标
网络采用由均方误差和稀疏正则化组成的残差重建损失训练：

L_DLCS = ‖Ĉ_target − C_target‖₂² + λ₁·‖Ĉ_target‖₁, (19)

其中λ₁＞0控制稀疏正则化。ℓ₂项鼓励精确的目标重建，ℓ₁项促进稀疏的目标响应并抑制残余杂波伪影。

V-A4 优化
网络参数采用AdamW优化器优化，学习率η_DLCS=10⁻³，权重衰减正则化系数λ_wd=10⁻⁵。采用随机杂波和目标实现进行小批量训练。为稳定优化，应用梯度裁剪：

‖∇_θ L‖₂ ≤ γ_max, (20)

其中θ为可训练网络参数，裁剪阈值γ_max为5。训练完成后，输出Ĉ_target进入CAF和距离-多普勒估计阶段处理。

V-B 注意力门控各向异性DLCS

第二种DL方法DLCS-2通过各向异性卷积处理和专为杂波主导的距离-多普勒图设计的注意力门控跳跃连接，对残差U-Net架构进行扩展。

V-B1 多通道输入表示
网络不仅使用实部和虚部通道，还利用四种互补的输入表示：

X = [C_raw^(I), C_raw^(Q), |C_raw|, log(1+|C_raw|)]. (21)

幅度通道显式捕获目标能量分布，对数通道压缩动态范围并改善强杂波环境下弱目标响应的表示。

V-B2 各向异性卷积编码器
编码器采用分别建模慢时间和时延域结构的各向异性卷积块。每个各向异性块包含标准3×3卷积、拉长的(5×1)卷积、拉长的(1×5)卷积、批归一化和ReLU非线性。(5×1)核学习慢时间多普勒结构和杂波轨迹，而(1×5)核学习距离域相关性和时延扩展的杂波结构。设F为中间特征图，各向异性块计算F_st = Conv_{5×1}(F)和F_rg = Conv_{1×5}(F)，随后进行非线性特征融合。这种方向性处理能更好地区分在时延和慢时间维度上呈现不同几何行为的目标特征与杂波结构。

V-B3 注意力门控跳跃连接
解码器引入注意力门控跳跃连接，在特征融合前抑制杂波主导的编码器激活。设S为编码器跳跃特征图，G为解码器门控特征图。注意力掩码计算为

A = σ(ψ(φ(S)+θ(G))),

其中φ(·)、θ(·)和ψ(·)为可学习的卷积变换，σ(·)为sigmoid激活函数。精细化后的跳跃特征为S_att = A⊙S，其中⊙表示逐元素相乘。该机制通过强调与解码器目标相关上下文一致的特征，在保留目标主导空间结构的同时抑制杂波主导的特征激活。

V-B4 解码器结构
解码器通过双线性上采样以及与注意力精细化跳跃特征的拼接来重建目标增强的残差图。每个解码器阶段采用与编码器类似的各向异性卷积块。各向异性卷积采用在各维度上空间支持不相等的方向相关卷积核，使用5×1和1×5大小的核分别建模慢时间多普勒结构和时延域相关性。最终输出层生成目标残差的双通道估计：

Ŷ = [Ĉ_target^(I), Ĉ_target^(Q)]. (22)

V-B5 损失函数
网络采用重建与稀疏损失的组合进行训练：

L_Attn = ‖Ĉ_target − C_target‖₂² + λ_s·‖Ĉ_target‖₁ + λ_TV·TV(Ĉ_target), (23)

其中λ_s控制稀疏正则化，λ_TV控制全变分正则化。全变分项在保留局部化目标峰值的同时促进空间平滑。

V-B6 优化与训练
训练采用AdamW优化器和小批量梯度下降。应用梯度裁剪和权重衰减以提升优化稳定性和泛化性能。训练完成后，网络输出直接用于基于CAF的距离-多普勒估计和双基地定位。

VII 结论

本文研究了密集和动态杂波环境下使用5G NR PRS进行双基地距离-多普勒估计、目标定位和速度估计的多基地ISAC杂波抑制。我们表明，杂波会严重降低多基地ISAC的感知精度，而传统信号处理杂波抑制方法在恶劣杂波条件下仅能提供有限增益。为提升多基地ISAC的抗杂波鲁棒性，我们引入了基于DL的杂波抑制方法，直接从受杂波污染的观测中增强目标响应。在多基地ISAC的多种杂波条件下，这些方法显著改善了杂波抑制效果，并相对于传统方法降低了感知误差。
