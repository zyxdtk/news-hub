原标题：Claude重磅上新：录屏+语音，一键蒸馏Skill替自己干活

中文摘要： Anthropic 在 Claude 桌面端推出「Record a Skill」功能，用户通过录屏和语音讲解，即可将工作流自动转化为可复用的 Skill。该功能跳过了繁琐的文档编写环节，大幅降低了企业知识管理和流程自动化的门槛。然而，这也意味着工作的护城河正从“会做”向“会做别人做不了的事”迁移，AI 对传统岗位的替代效应日益显著。

现在，你可以通过录屏 + 语音讲解的方式，彻底把自己蒸馏成 Skill 了。

7 月 21 日，Anthropic 在 Claude 桌面端 Cowork 的 + 菜单里加了一项「Record a Skill」：录屏，一边操作一边用语音讲解，录完后 Claude 自动把演示转化成一个可复用的 Skill。

![Image 1](https://img.36krcdn.com/hsossms/20260722/v2_6c2a79afdbe94319a931ab36bc4cdb82@46958_oswg357741oswg1080oswg1332_img_000?x-oss-process=image/format,jpg/interlace,1)

https://x.com/claudeai/status/2079595988998554047

这个功能目前面向 Pro、Max 和 Team 用户开放。

## **一手实测：真能用**

我们第一时间对该功能进行了简单实测。

打开 Claude 客户端，点击聊天框左下角的【+】-> Skills -> Manage skills -> Add -> Record your screen，即可开始使用这个新功能。

![Image 2](https://img.36krcdn.com/hsossms/20260722/v2_4e5d1ed96e194631bdcb24618e692b67@46958_oswg47928oswg494oswg440_img_000?x-oss-process=image/format,jpg/interlace,1)

要注意，避免在录屏过程中录入明文密码、密钥、API Key、信用卡信息等个人敏感信息。

![Image 3](https://img.36krcdn.com/hsossms/20260722/v2_d3b67a3480b84fd69bb695d6af642d36@46958_oswg73314oswg998oswg506_img_000?x-oss-process=image/format,jpg/interlace,1)

第一次可能需授予录屏和录音权限，允许后点击【Start Recording】，即可开启录制。

只需要在电脑上重复一遍你的完整工作流，口述补充必要的隐含操作逻辑，同时避免无关操作（比如等结果时看个小视频摸摸鱼），点击结束录制即会自动回到 Claude Cowork 界面中进行分析与 Skill 提炼工作。

![Image 4](https://img.36krcdn.com/hsossms/20260722/v2_782508700fa24191905be33ba2050c08@46958_oswg317668oswg1080oswg751_img_000?x-oss-process=image/format,jpg/interlace,1)

等一阵过后，你的专属 Skill 就出炉了，点击【Save Skill】即可直接部署到 Claude 中。

![Image 5](https://img.36krcdn.com/hsossms/20260722/v2_6cafaa30a4364ec1a7752c24251e9c35@46958_oswg233876oswg1080oswg738_img_000?x-oss-process=image/format,jpg/interlace,1)

聊天中使用斜杠命令（/）即可调用该 Skill 干活了。

![Image 6](https://img.36krcdn.com/hsossms/20260722/v2_01363e4c11644f0189bf22ec7621d92b@46958_oswg350345oswg1080oswg1132_img_000?x-oss-process=image/format,jpg/interlace,1)

没有多余的一遍遍微调，新鲜出炉的专属 Skill 开箱即用。

## **绝非仅仅是效率提升工具**

多数报道把「Record a Skill」（录屏生成 Skill）归类为「更方便地创建自动化流程」，但这个理解停在了表面。

此前创建 Skill 要手写一份 SKILL.md 文件，用 Markdown 写清步骤、触发条件和元数据。

非技术人员必须像流程设计师一样思考才能完成这件事。

门槛在于把隐性经验翻译成显性指令。

而现在，「Record a Skill」跳过了翻译环节。

这些东西很难写成操作手册，但能被一段录屏完整保留。

「Record a Skill」绕开了「写」这一步。

企业知识管理砸了几十年的钱建知识库、写 SOP、搞最佳实践库，核心痛点始终是一个：专家不愿意写文档，写了也没人维护。

录屏讲解的门槛比写文档低一个量级，产出的 Skill 人能读，AI 也能直接跑。

## **录屏的另一面**

科技媒体 MakeUseOf 今年 3 月报道了一个案例：

一位自由撰稿人在离职交接期间用 Claude Cowork 搭了一套内容生成工作流，品牌文档、风格指南和历史稿件打包喂进去，按 Skill 流程输出月度内容日历。

交接时客户说：

> 你既然要走了，能不能把这个配好，我们自己跑？

五年的合作关系被一个 Skill 文件夹替代了。

![Image 7](https://img.36krcdn.com/hsossms/20260722/v2_9abb841061314cb484fab9bbfee7d2b9@46958_oswg721802oswg1080oswg712_img_000?x-oss-process=image/format,jpg/interlace,1)

https://www.makeuseof.com/claude-cowork-automated-away-job/

这个故事发生在「Record a Skill」上线之前，用的还是手写 Skill 的方式。

录屏教学把同一件事的操作成本又压低了一截：不需要懂 Markdown，不需要抽象流程，做一遍、讲一遍就够了。

哈佛商学院 2026 年 3 月的研究数据可以作为另一面的注脚：AI 暴露度最高的岗位招聘量下降了 17%，需要人机协作的岗位招聘量增加了 22%。

![Image 8](https://img.36krcdn.com/hsossms/20260722/v2_cd6a5d5959974483956fcd280511f36d@46958_oswg53924oswg1080oswg591_img_000?x-oss-process=image/format,jpg/interlace,1)

https://www.hbs.edu/ris/Publication%20Files/25-039_05fbec84-1f23-459b-8410-e3cd7ab6c88a.pdf

但「Record a Skill」推动的方向很明确：工作的护城河，从「会做」迁移到了「会做别人做不了的事」。
