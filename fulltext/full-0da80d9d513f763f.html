Warp推出开箱即用的AI开发软件工厂系统

📅 2026-08-18 📄 TechCrunch AI 🔗 原文链接

原标题：Warp’s new system is an out-of-the-box software factory for AI development

中文摘要： AI编程公司Warp推出了名为Warp Factories的新系统，旨在为企业提供开箱即用的AI软件工厂基础设施。该系统简化了AI智能体的部署与运营，集成了主流编程模型和办公协作工具，并提供性能监控与自我优化功能。Warp Factories主要面向缺乏资源从零搭建系统的中小企业，旨在辅助而非完全取代工程师，帮助他们更高效地与新智能体劳动力协作。

现在，Warp 推出的一款系统可能会让这种转变变得容易得多。周二，这家 AI 编程公司推出了 Warp Factories，这是一个旨在让构建和运营 AI 软件工厂变得尽可能简单的新系统。

作为基础设施层运行，Warp Factories 为企业提供了一个用于部署智能体的简单环境，以及如何使用它们的路线图。

需要明确的是，许多公司在没有任何 Warp 帮助的情况下，已经通过工厂模式取得了成功。Stripe 特别公开了其技术进展，开发了一个“minions”系统，在其自己的代码库中实现开发自动化。Ramp 也取得了类似的进展，开发了一个后台智能体，可以在代码部署后对其进行监控。

Warp Factories 的分析界面
图片来源：Warp Factories

在 Warp 首席执行官 Zach Lloyd 看来，Warp Factories 的目标市场将是那些没有资源从零开始构建系统的中小型公司。

“[如果你看看]在云端运行你的智能体并在它们运行时进行引导，或者将它们正在做的工作引入你的本地环境，或者设置跨这些智能体的记忆，或者设置跨这些智能体的评估——要把这些做好，实际上是一项庞大的基础设施工程，”Lloyd 告诉 TechCrunch。

在 Warp Factories 中，架构已经是开箱即用的，许多最困难的决策都已经做出了。Warp 的系统基于软件开发的标准阶段（分类、规范、实现、审查和验证），但智能体方法意味着这些步骤中的任何一个都可以被自动化。

用户可以根据需要选择自己的编程模型和配套工具；该系统与 Codex 和 Claude Code 都能很好地配合。它还与 Linear 和 Jira 等工单系统，以及 Slack 和 Teams 等消息系统进行了集成，努力无缝接入现有的工作流程。

除了发布代码之外，Warp Factories 还将为管理者提供跟踪工厂运行状况的工具。由于所有智能体都在同一环境中运行，因此很容易比较不同配置的性能指标，并密切关注整体的 Token 花费。Warp Factory 还允许自我改进循环来优化整个系统，实现流程管理的自动化。

即便如此，Warp Factories 并非旨在完全取代软件工程师——只是为他们提供一种与新智能体劳动力协作的更简单方式。在 Lloyd 自己的经验中，仍然有很多任务需要人类来掌控。

“我们每周大约会自动化 30% 到 35% 的任务，”Lloyd 告诉 TechCrunch，“随着模型的改进、上下文的改善以及配套工具的优化，我认为这个数字随着时间的推移还会上升。”
