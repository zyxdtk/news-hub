SHUSH：主动式视频助手的发言感知奖励设计

📅 2026-11-19 📄 arxiv 🔗 原文链接

原标题：SHUSH: Emission-Aware Reward Design for Proactive Video Assistants

中文摘要： 本文研究主动式视频助手的过度发言问题。作者发现MMDuet2的PAUC奖励不计算发言数量，使额外回复几乎零成本，系统性鼓励过度发言。为此提出发言感知F1奖励，通过独占的跨度-发言一对一匹配为虚假发言与遗漏跨度定价。实验表明，该方法在OmniPro上减少82.5%的发言量，精确率从0.161升至0.418，F1从0.259升至0.346；在ProactiveVideoQA上也能在基线沉默处增加回复并提升F1。

SHUSH：主动式视频助手的发言感知奖励设计

Shawn Liang¹、Soamar Homsi²、Gourav Datta¹

摘要

主动式视频助手不仅必须决定说什么，还必须决定何时说话。现有的强化学习目标能够在不计入响应数量的情况下奖励及时、正确的响应，从而鼓励不必要或重复的发言。我们在 MMDuet2 中识别出这一失败模式：其主动式曲线下面积（PAUC）奖励促进了及时响应，却未对发言数量定价。我们通过分析表明，这使得额外的响应仅受到微弱惩罚甚至完全免费，从而系统性地鼓励过度发言。随后，我们提出了一种面向区间值标注的发言感知 F1 奖励，利用独占的“跨度—发言”匹配为虚假发言和遗漏跨度定价。在 MMDuet2 的训练配方下，我们的策略在 OmniPro 视觉子集上的回复频率比 MMDuet2 低 2.5 倍，同时将时序 F1 从 0.259 提升至 0.396，内容感知 F1 从 0.103 提升至 0.154；更保守的变体将回复量削减 82.5%，并将精确率从 0.161 提升至 0.418。在 ProactiveVideoQA 上，同一奖励在基线几乎沉默之处增加了回复；而 PAUC 将一个严重过度发言的策略排在第二位——尽管其 F1 接近垫底——因为它对响应数量不敏感。我们的结果表明，主动式助手应当使用对发言定价的目标函数进行训练和评估。

索引词： 主动式视频助手；视频理解；强化学习；发言感知奖励；响应时序；多模态 AI。

1 引言

视频大语言模型正日益从离线视频理解转向连续流式交互：帧按顺序到达，模型必须自主决定何时响应 [2, 14, 12]。在这类主动式系统中，响应时序本身就是预测问题的一部分——说话太晚会降低效用，而不必要地说话则会产生重复或无依据的响应。由于助手在未被提示的情况下主动发起这些交互，每一次不必要的回复都会消耗用户注意力，可能分散对真正相关事件的关注，并增加本可避免的推理与通信开销；反复出现的低价值回复还会侵蚀用户信任。我们将模型在某个决策回合生成的每条回复称为一次发言。

因此，近期系统已开始学习何时说话，而非仅依赖固定的推理阈值。例如，MMDuet2 [12] 将响应触发形式化为逐回合的文本决策，并使用强化学习优化该策略。尽管时序性能有所改善，但近期评估表明，主动式 Video-LLM 仍可通过频繁响应获得高时间分数，以牺牲精确率为代价换取召回率 [4]。这引出一个根本性问题：所学策略的过度发言，究竟源于优化失败，还是源于奖励本身使频繁发言变得有利？

图 1： 所提出的发言感知奖励设计概览。对数量不敏感的时序奖励可能偏好重复或不必要的响应，而我们的区间感知 F1 公式通过独占的“发言—跨度”匹配为虚假发言和遗漏跨度定价。

我们证明后者确实可能发生。在 MMDuet2 中，占主导地位的基于 PAUC（主动式曲线下面积）的奖励在标注时间跨度上对响应质量积分，奖励早期的改进，却未显式计入发言总数。因此，一条额外的回复在改善当前得分时可以增加奖励，而在未改善时则不付出任何代价；并且随着决策回合数的增长，针对跨度外发言和重复回复的辅助惩罚会逐渐减弱。第 3 节刻画了这些激励结构，并表明当相关事件相对于决策机会较为稀疏时，过度发言变得愈发有利。

为解决这一失配，我们提出一种面向区间值标注的发言感知 F1 奖励，显式地将奖励与模型产生的响应数量耦合。我们的公式采用发言与黄金跨度之间的一对一最大权重匹配，允许每个跨度至多为一条回复记分，同时显式惩罚未匹配的发言和遗漏的跨度。由此，一条额外的响应必须提供足以覆盖其成本的价值，而不再是近乎免费的额外尝试。我们的贡献有三：(1) 对基于 PAUC 的奖励设计如何系统性激励过度发言的分析性诊断；(2) 基于独占“跨度—发言”匹配的、区间感知且对发言计价的 F1 奖励；(3) 实证评估表明，在 OmniPro 上发言量减少 82.5%，同时精确率从 0.161 提升至 0.418，F1 从 0.259 提升至 0.346。图 1 对比了两种奖励结构。

2 相关工作

主动式流式 Video-LLM。 流式 Video-LLM 必须同时确定响应内容与响应时序 [2, 16]。现有触发机制包括：基于 token 的决策 [2, 18, 3]、专用分类头 [14, 8, 11]，以及启发式的视觉或不确定性判据 [15, 17]。近期方法越来越多地直接通过强化学习学习这一决策。例如，MMDuet2 [12] 将触发形式化为通过 RL 优化的逐回合文本决策，免除了对固定推理阈值的需要。我们关注此类学习型响应策略的奖励设计。

时序指标与奖励。 StreamingBench [6] 与 OVO-Bench [7] 评估时间正确性，但每个查询至多对一条响应计分。ProactiveVideoQA [13] 提出了 PAUC，它在标注时间跨度上对响应质量积分，但未显式计入所发响应的数量。更近期的基准直接处理过度触发问题：OmniPro [19] 惩罚不必要的响应，StreamPro-Bench [4] 则使用精确率—召回率 F1 评估响应轨迹。相应地，MMDuet2 [12] 优化了一个 PAUC 派生奖励，偏好早期、正确的响应，并对重复、跨度外发言和冗长前缀施加惩罚；而 StreamPro [4] 针对时间戳型目标引入了数量敏感的回合级 F1 项。两者均使用 LLM 评判器 [5] 为响应内容打分。相比之下，我们分析了数量不敏感的时序目标为何偏好过度发言，并针对区间值标注提出了发言感知的公式。

3 时序奖励何时鼓励过度发言

我们以 MMDuet2 [12] 作为基于 RL 的主动式响应时序的代表性案例研究。在 OmniPro 的视觉子集上，它针对 1,723 个标注触发器产生了 6,961 条回复，这促使我们深入检视其底层目标。这些多余发言既出现在标注事件之外，也表现为已覆盖跨度内的重复响应。我们不将其视为模型特定的优化失败，而是识别出数量不敏感时序目标中两个更广泛的结构性激励：额外预测可能几乎不产生甚至完全不产生边际成本；归一化惩罚可能随决策机会数量的增加而减弱。

3.1 基于 PAUC 目标中的边际激励

设一次视频 rollout 共包含 K 个决策回合，其中 M 个回合落在任何标注真实跨度之外。标注给出 N 个由 [t_start, t_end] 界定的黄金跨度。在给定跨度内，模型在时间戳 τ_p 处发出 P 条回复，每条回复由 LLM 评判器赋予内容得分 s_p ∈ [0, S]（其中 S = 4）。已发表的奖励为：

r = 3·r_PAUC + 2·r_rep + 0.5·r_in_span + 2·r_pfx.　　(1)

主导项 r_PAUC 派生自 ProactiveVideoQA [13] 的 PAUC 指标。它将响应得分表示为随时间变化的阶跃函数，在 t_start 处初始化为下限 s₀ = 0.5，并将其面积表示为最大可能面积的比例：

PAUC = 1/((t_end − t_start) × S) × [(τ₁ − t_start) × 0.5 + Σ_{p=1}^{P−1} (τ_{p+1} − τ_p) × s_p + (t_end − τ_P) × s_P].　　(2)

该奖励对 N 个跨度取 PAUC 的平均值。按照官方实现，时间戳在 τ̃_p = t_start + (1 − φ)(τ_p − t_start) 处评估，其中 φ = 0.5。其余各项分别惩罚语义重复、跨度外发言和重复前缀；重要的是，这些惩罚分别按发言数、跨度外回合数 M 和总回合数 K 进行归一化。

设 ξ ∈ [0, 1] 表示一次发言在跨度内的分数偏移。当当前生效得分为 s_prev 时，追加一条得分为 s 的最终回复所带来的增益为：

ΔPAUC = (1 − (1 − φ)ξ)(s − s_prev)/S.　　(3)

边际增益取决于 s − s_prev，即仅奖励相对当前响应的改进。然而，发言数 P 并未出现在 PAUC 的归一化中，因此额外的尝试在未能改进当前得分时可以不付任何成本地增加奖励。

图 2： 在一条代表性轨迹上计算的发言感知 F1 奖励。

3.2 跨度外发言

对于跨度的首条回复，s_prev = s₀，而沉默的得分为 s₀/S = 0.125。由于评判器得分为 [0, S] 上的整数，任何正面判定都优于沉默。当 φ = 0.5 时，式 (3) 中的时间因子保持在 [0.5, 1] 区间，因此较晚的响应会降低增益，但不会使说话变成损失。只有 r_in_span 惩罚标注跨度之外的发言。由于其权重为 0.5 且按 M 个跨度外回合归一化，一次虚假发言的边际成本为 κ = 0.5/M。相比之下，完美回答一个跨度对加权 PAUC 奖励的贡献为 3(1 − s₀/S)/N = 2.625/N。因此，当 N ≤ 5 时，完美回答一个跨度的增益即可超过跨度外惩罚的最大总量。更一般地，由于流式过程中跨度边界未知，每次发言都是不确定性下的决策。设 ρ 表示命中一个未回答跨度的期望奖励。当发言的成功概率超过 κ/(ρ + κ) 时，发言是有利的。由于每个跨度的可用奖励按 1/N 缩放，而 κ ∝ 1/M，虚假发言的激励大致随 M/N 增长。因此，当事件稀疏时，数量不敏感的奖励最不保守。

图 3： 一条轨迹上的奖励响应。四条连续得分为 3 的回复使 r_PAUC 保持不变（因为没有一条改进了当前生效的得分），而 R_span 随每条回复下降，仅在 τ = 14 处回升——此处一条得分更高的回复证明了其成本的合理性。

3.3 跨度内的重复发言

对于同一跨度内的后续回复，s_prev 为当前生效的得分。若新回复获得相同得分，则式 (3) 的值为零。因此，PAUC 本身不因重试施加任何成本，而得分更高的回复仍可增加奖励。当内容得分在不同评判的响应之间存在波动时，只要当前得分足够低，再试一次就可能具有正的期望价值。

辅助重复项仅部分缓解了这一行为。由于 r_rep 是对发言取平均，追加一条重复程度相近的回复未必会显著恶化归一化后的惩罚。同样，r_pfx 针对词法层面的前缀重复，可能漏掉语义上冗余的换述。图 3 直接展示了这一点：四条得分相同的回复使 r_PAUC 保持不变，而 R_span 随每条回复递减。

4 发言感知奖励设计

第 3 节提示了一个一般性设计要求：说话的边际成本应直接取决于策略产生的响应数量。仅对数量不敏感的各项重新加权无法保证这一性质。精确率—召回率公式则天然具备该性质，因为其预测侧分母随模型输出而增长。

在数量敏感的回合级 F1 奖励设计 [4] 的基础上，我们提出面向区间值标注的发言感知 F1 奖励。与点时间戳监督不同，区间值目标引入了分配问题：多条发言可能落入同一跨度，而重叠的跨度可能竞争同一条预测。我们优化：

R = w_fmt·R_fmt + w_span·R_span，
R_span = (1 + β²)·Σ_{i∈A} c_i·w(τ_i) / (N_match + γ·N_out + β²·N_gt).　　(4)

其中，R_fmt 奖励每个决策回合处格式良好的输出；A 为匹配的“发言—跨度”对集合；N_match = |A| 为匹配发言数；N_out 为未匹配发言数；N_gt 为可达的真实跨度数。我们记 N_pred = N_match + N_out 为总发言数。每条匹配发言从 LLM 评判器获得内容得分 c_i ∈ [0, 1] 以及时间权重 w(τ_i)。当 γ = β = 1 时，分母变为 N_pred + N_gt，恢复标准的 F1 计数结构。图 2 以一条代表性轨迹进行了演算。

4.1 匹配区间值标注

区间值监督引入了点式标注中不存在的分配问题。多条发言可能位于单个跨度内，而重叠的跨度可能使一条发言有资格匹配多个跨度。若为每一对符合条件的组合都记分，将再次奖励过度生成；而贪婪匹配又可能消耗掉本可用于覆盖另一个可达跨度的发言。因此，我们采用一对一最大权重二分匹配，允许每条发言和每个黄金跨度至多参与一个计分配对。

时间事件边界的人工标注本身也不可避免地存在不精确性。严格的二元归属判定将使恰好落在标注边界之外的、原本正确的响应得不到任何分数。因此，我们在每个跨度周围采用连续衰减。对于跨度 [a, b]，令 D = min(W, b − a)，其中 W 为斜坡宽度的上限：

w(t) = max(0, 1 − (a − t)/D)，当 t < a；
w(t) = max(α, 1 − (1 − α)(t − a)/D)，当 a ≤ t ≤ b；
w(t) = max(0, α − (t − b)/D)，当 t > b.　　(5)

于是，靠近边界的响应获得部分分数，而非经历奖励的突变。参数 α 控制跨度内较晚响应的折扣；我们设 α = 1，使奖励在标注跨度内保持平坦。

4.2 为发言与遗漏跨度定价

参数 γ 与 β 控制两类互补的错误。系数 γ 提高未匹配发言的成本，而 β 控制对覆盖真实跨度的相对重视程度。因此，增大 γ 倾向于更保守的策略，而增大 β 更加强调召回率。独占匹配也直接为重复响应定价：若多条发言竞争同一跨度，至多一条可为该目标获得分数，其余发言计入 N_out，除非它们匹配到别处。匹配保留最高价值（即最佳）的指派，允许真正改进的响应替换较弱的响应，同时为不必要的重试收费。因此，该奖励规定的不是模型应多久说一次话，而是一条新响应必须增添多少价值。

5 实验结果

设置。 MMDuet2 的 SFT 检查点未公开发布，因此我们依照已发表的配方、以 Qwen2.5-VL-3B [1] 初始化进行复现。从该检查点出发，我们使用 VeRL [10] 与 SGLang 在 MMDuet2 的 RL 数据上运行 GRPO [9] 一个 epoch，仅更改奖励；奖励内评判器为温度 0 的 Qwen2.5-32B，并设 w_fmt = 0.1、w_span = 1。我们报告两种配置：γ = 1.5（对跨度外发言的计价高于跨度内发言）与 β = 1.5（带软跨度归属的 F_β 奖励，见第 4 节）。基线为已发布的 MMDuet2 检查点 [12]。我们还运行了已发布的 MMDuet [14] 与 VideoLLM-Online [2]。我们在 OmniPro [19] 的视觉子集与 ProactiveVideoQA [13] 上评估。对两者，时序精确率、召回率与 F1 均采用回复与黄金答案之间的一对一匹配；N_pred/N_gt 统计每个黄金答案的回复数。

OmniPro 上的结果。 OmniPro 将每个答案标注为点式触发器；回复在 3 秒内匹配触发器即为命中。为了同时评价回复的内容与时机，我们定义 F1_c = 2S_c/(N_pred + N_gt)，其中 S_c 对匹配对的 GPT-4.1 内容得分（0、0.5 或 1，参照触发器的参考答案）求和；时序 F1 即每次匹配得分均为 1 的情形。表 1 展示了主动式模型失败的两种相反方式。VideoLLM-Online 几乎从不回复，仅覆盖 1.0% 的触发器。MMDuet 每个触发器回复 5.39 次，取得最高召回率（0.738），但其回复仅有 13.7% 命中触发器。我们的策略介于两个极端之间。β 策略每个触发器回复 1.63 次，比 MMDuet2 少 2.5 倍、比 MMDuet 少 3.3 倍，并取得所有模型中最高的时序 F1（0.396）与内容 F1_c（0.154）。γ 策略每个触发器回复 0.71 次，取得最高精确率（0.418），甚至高于近乎沉默的 VideoLLM-Online（0.395）。F1_c 与时序 F1 同步提升，说明保留下来的回复时机更准、内容也更常正确。MMDuet2 通过生成更多响应来覆盖每个触发器，从而取得比两种策略都高的召回率；而 β 策略以 40% 的回复量保留了其 80% 的召回率。

ProactiveVideoQA 上的结果。 我们使用 MMDuet2 发布的评分器与 GPT-4.1 评判器报告 PAUC 与重复率（Rep%），其中 Rep% 为重复回复所占比例（对跨度取平均）。PAUC 对每个跨度内给出的最佳答案积分，并且如第 3 节所论证，无法感知回复数量。表 2 以基线模型展示了这一点。在 EGO 上，MMDuet 的 PAUC 排名第二（43.6），每个黄金答案回复 16.9 次，但其 F1 倒数第二。在 VAD 上，它每个答案 29 条回复仅得 23.1 的 PAUC，低于沉默模型可得的 25。我们的奖励并非单纯抑制回复。在 EGO 上，MMDuet2 每个黄金答案仅回复 0.54 次，且在 39.6% 的视频上保持沉默；我们的策略每个答案回复 0.79–1.72 次，将 F1 从 0.248 提升至 0.419，为所有模型中最高；γ 策略在说话更多的同时于每一列均优于 MMDuet2，而 β 策略在 EGO（46.0）与 TV（47.0）上均取得最高 PAUC。在 TV 与 VAD 上，β 策略的 F1 与 MMDuet2 相当；在 WEB 上则落后：WEB 的黄金跨度覆盖了 81% 的视频时长，因此随机时刻的回复已有 81% 的概率落入某个跨度，密集发言几乎不付代价。在此种密度下的区间标注几乎没有给“为回复定价”的奖励留下空间。因此，OmniPro 的点式触发器是我们的主要测试场。

6 结论

我们表明，主动式视频助手中的过度发言可能源于奖励设计而非优化失败。我们识别出基于 PAUC 的目标中的一类一般性失败模式——额外预测可在无数量相关成本的情况下提升奖励——并用基于独占“跨度—发言”匹配的发言感知 F1 奖励加以解决。在 OmniPro 上，我们的策略将发言量减少 82.5%，同时将精确率从 0.161 提升至 0.418，F1 从 0.259 提升至 0.346。局限性包括跨度内时序问题以及人工选取的 γ 与 β，未来工作可从部署特定的成本中推导这些参数。
