GPT-5.3-Codex 发布

📅 2026-04-16 📄 OpenAI 🔗 原文链接

原标题：GPT-5.3-Codex

中文摘要： OpenAI发布GPT-5.3-Codex，这是迄今最强大的智能体编程模型。它融合了GPT-5.2-Codex的编程与GPT-5.2的推理能力，速度提升25%，支持长时任务与实时交互。该模型首次参与自身创建与调试，在SWE-Bench Pro等基准上创下新高，并具备强大的计算机使用与网络安全能力。同时，OpenAI推出网络安全可信访问计划，投入千万美元API额度支持防御研究。

我们正在推出一款解锁 Codex 更多能力的新模型：GPT‑5.3‑Codex，这是迄今为止最强大的智能体编程模型。该模型将 GPT‑5.2‑Codex 的前沿编程性能与 GPT‑5.2 的推理和专业知识能力集于一身，并且速度提升了 25%。这使其能够承担涉及研究、工具使用和复杂执行的长时间运行任务。就像同事一样，你可以在 GPT‑5.3‑Codex 工作时对其进行引导和交互，而不会丢失上下文。

GPT‑5.3‑Codex 是我们第一款在自身创建过程中发挥关键作用的模型。Codex 团队使用早期版本调试其自身的训练过程，管理其自身的部署，并诊断测试结果和评估——我们的团队对 Codex 能够在多大程度上加速自身的发展感到震惊。

借助 GPT‑5.3‑Codex，Codex 从一个能够编写和审查代码的智能体，转变为一个几乎可以完成开发人员和专业人员在计算机上所能做的任何事情的智能体。

## 前沿智能体能力 GPT‑5.3‑Codex 在 SWE-Bench Pro 和 Terminal-Bench 上创下了行业新高，并在 OSWorld 和 GDPval 上表现出色，这四个基准测试是我们用来衡量编程、智能体和现实世界能力的。

GPT‑5.3‑Codex 在 SWE-Bench Pro 上实现了最先进的性能，这是对现实世界软件工程的严格评估。SWE‑bench Verified 仅测试 Python，而 SWE‑Bench Pro 涵盖四种语言，并且更具抗污染性、更具挑战性、更多样化且与行业更相关。它还在 Terminal-Bench 2.0 上远超之前的最先进性能，该基准测试衡量的是像 Codex 这样的编程智能体所需的终端技能。值得注意的是，GPT‑5.3‑Codex 使用的 token 比以往任何模型都要少，从而让用户能够构建更多内容。

结合前沿的编程能力、美学上的改进以及紧凑性，造就了一个能够完成惊人工作的模型，它可以在几天内从零开始构建功能高度复杂的游戏和应用程序。为了测试该模型的 Web 开发和长时间运行的智能体能力，我们要求 GPT‑5.3‑Codex 为我们构建两款游戏：[Codex 应用发布⁠](https://openai.com/index/introducing-the-codex-app/)中的赛车游戏第二版，以及一款潜水游戏。使用开发网页游戏的技能以及预先选定的通用后续提示（如“修复错误”或“改进游戏”），GPT‑5.3‑Codex 在数百万个 token 上自主迭代这些游戏。请观看预告片并亲自试玩游戏，看看 Codex 能做什么。

与 GPT‑5.2‑Codex 相比，当你要求 GPT‑5.3‑Codex 制作日常网站时，它能更好地理解你的意图。简单或不够明确的提示现在默认生成具有更多功能和合理默认设置的网站，为你提供了一个更强大的起始画板来实现你的想法。

例如，我们要求 GPT‑5.3‑Codex 和 GPT‑5.2‑Codex 构建下面两个着陆页。GPT‑5.3‑Codex 自动将年度计划显示为折扣后的月度价格，使折扣感觉清晰且刻意，而不是直接乘以年度总价。它还制作了一个自动切换的评价轮播，包含三条不同的用户评价而不是一条，从而使页面在默认情况下感觉更完整且更接近生产就绪状态。

**提示：** 为 Quiet KPI 构建一个着陆页，这是一个对创始人友好的每周指标摘要。美学风格是柔和的 SaaS，玻璃态卡片，薰衣草色到蓝色的渐变，微妙的模糊效果。板块包括：带有电子邮件捕获的主视觉区、示例报告卡网格、集成行、评价轮播、按月/年切换的定价、常见问题解答、页脚。 - 字体为 Satoshi 或类似的几何无衬线字体。 - 按钮为圆角，14px 半径，强烈的焦点状态。 - 添加一个有品位的基于滚动的显示效果。

软件工程师、设计师、产品经理和数据科学家所做的工作远不止生成代码。GPT‑5.3‑Codex 旨在支持软件生命周期中的所有工作——调试、部署、监控、编写 PRD、编辑文案、用户研究、测试、指标等。其智能体能力超越了软件领域，可帮助你构建任何你想要构建的东西——无论是幻灯片演示还是分析表格中的数据。

借助与我们之前 GDPval 结果中使用的类似的自定义技能，GPT‑5.3‑Codex 在 [GDP⁠val⁠](https://openai.com/index/gdpval/) 衡量的专业知识工作上也表现出色，与 GPT‑5.2 相当。GDPval 是 OpenAI 在 2025 年发布的一项评估，用于衡量模型在 44 个职业中执行明确的知识工作任务的表现。这些任务包括制作演示文稿、电子表格和其他工作产品。

综合这些在编程、前端、计算机使用和现实世界任务中的结果表明，GPT‑5.3‑Codex 不仅在单个任务上表现更好，而且标志着向单一通用智能体迈出了跨越性的一步，该智能体能够在现实世界技术工作的全谱系中进行推理、构建和执行。

## 交互式协作者 随着模型能力变得越来越强大，差距已从智能体能够做什么，转移到了人类能够多容易地与它们交互、指挥和监督它们并行工作。Codex 应用使管理和指挥智能体变得容易得多，现在有了 GPT‑5.3‑Codex，它变得更具交互性。使用新模型，Codex 提供频繁的更新，让你在工作时随时了解关键决策和进展。你无需等待最终输出，而是可以实时交互——提出问题、讨论方法并引导至解决方案。GPT‑5.3‑Codex 会讲述它正在做的事情，对反馈做出响应，并让你从头到尾都参与其中。

在应用中通过“设置 > 通用 > 后续行为”启用模型工作时的引导功能。

## 我们如何使用 Codex 来训练和部署 GPT‑5.3‑Codex 最近 Codex 的快速改进建立在 OpenAI 全公司历时数月或数年的研究项目成果之上。这些研究项目正被 Codex 加速，OpenAI 的许多研究人员和工程师表示他们今天的工作与两个月前已截然不同。即使是早期版本的 GPT‑5.3‑Codex 也展现出了卓越的能力，使我们的团队能够与这些早期版本合作，改进训练并支持后续版本的部署。

Codex 可用于非常广泛的任务，因此很难完全列举它帮助我们团队的方式。举几个例子，研究团队使用 Codex 来监控和调试本次发布的训练运行。它不仅加速了调试基础设施问题的研究：它还帮助跟踪整个训练过程中的模式，对交互质量提供深度分析，提出修复建议，并为人类研究人员构建了丰富的应用程序，以精确了解模型的行为与以前的模型有何不同。

工程团队使用 Codex 来优化和调整 GPT‑5.3‑Codex 的测试套件。当我们开始看到影响用户的奇怪边缘情况时，团队成员使用 Codex 来识别上下文渲染错误，并找出缓存命中率低的根本原因。在整个发布过程中，GPT‑5.3‑Codex 继续通过动态扩展 GPU 集群以适应流量激增并保持延迟稳定来帮助团队。

在 Alpha 测试期间，一位研究人员想了解 GPT‑5.3‑Codex 每轮完成了多少额外工作以及相关的生产力差异。GPT‑5.3‑Codex 提出了几个简单的正则表达式分类器，用于估计澄清的频率、用户的正面和负面响应以及任务进度，然后在所有会话日志上可扩展地运行它们，并生成了一份带有结论的报告。使用 Codex 构建的人更高兴，因为智能体更好地理解了他们的意图，并且每轮取得了更多进展，提出的澄清问题也更少。

由于 GPT‑5.3‑Codex 与其前身有很大不同，Alpha 测试的数据显示出许多不寻常和反直觉的结果。团队的一位数据科学家与 GPT‑5.3‑Codex 合作构建了新的数据管道，并以比我们标准仪表板工具更丰富的方式可视化结果。这些结果与 Codex 共同分析，Codex 在不到三分钟的时间内简明扼要地总结了数千个数据点的关键见解。

单独来看，所有这些任务都是 Codex 如何帮助研究人员和产品构建者的有趣示例。综合来看，我们发现这些新能力极大地加速了我们的研究、工程和产品团队。

## 守护网络前沿 最近几个月，我们看到模型在网络安全任务上的性能取得了有意义的提升，使开发人员和安全专业人员都受益。与此同时，我们一直在[准备加强的网络保障措施⁠](https://openai.com/index/strengthening-cyber-resilience/)，以支持防御性使用和更广泛的生态系统韧性。

GPT‑5.3‑Codex 是我们根据[准备框架⁠](https://openai.com/index/updating-our-preparedness-framework/)在网络安全相关任务中分类为[高能力⁠](https://openai.com/index/gpt-5-3-codex-system-card/)的首个模型，也是我们首个直接训练用于识别软件漏洞的模型。虽然我们没有确凿的证据表明它能够端到端地自动化网络攻击，但我们正在采取预防措施，并部署迄今为止最全面的网络安全安全栈。我们的缓解措施包括安全培训、自动监控、高级功能的可信访问以及包括威胁情报在内的执行管道。

由于网络安全本质上具有双重用途，我们正在采取基于证据的迭代方法，在加速防御者发现和修复漏洞的能力的同时，减缓滥用。作为其中的一部分，我们正在推出[网络安全可信访问⁠](https://openai.com/index/trusted-access-for-cyber/)，这是一项旨在加速网络防御研究的试点计划。

为了帮助防止滥用，我们的系统检测到具有较高网络风险的一些请求可能会自动从 GPT‑5.3‑Codex 路由到 GPT‑5.2。我们正在继续完善这些保障措施。正在进行安全研究或认为其请求被错误分类的开发人员，可以通过我们的网络安全可信访问计划申请完全访问权限，或使用 /feedback 命令报告问题。

我们正在投资生态系统保障措施，例如扩大我们的安全研究智能体 [Aardvark⁠](https://openai.com/index/introducing-aardvark/) 的私有测试版，作为我们 Codex Security 产品和工具套件中的首个产品，并与开源维护者合作，为 Next.js 等广泛使用的项目提供免费的代码库扫描——上周一名安全研究人员使用 Codex 发现了[已披露⁠(在新窗口中打开)](https://vercel.com/changelog/summaries-of-cve-2025-59471-and-cve-2025-59472)的漏洞。

在 2023 年推出的 100 万美元网络安全资助计划的基础上，我们还将投入 1000 万美元的 API 额度，以利用我们最强大的模型加速网络防御，特别是针对开源软件和关键基础设施系统。从事善意安全研究的组织可以通过我们的[网络安全资助计划⁠](https://openai.com/index/openai-cybersecurity-grant-program/)申请 API 额度和支持。

## 可用性与详细信息 GPT‑5.3‑Codex 随付费 ChatGPT 计划提供，可在所有使用 Codex 的地方使用：应用程序、CLI、IDE 扩展和网页。我们正努力尽快安全地启用 API 访问。

借助此次更新，得益于基础设施和推理堆栈的改进，我们现在为 Codex 用户运行 GPT‑5.3‑Codex 的速度提升了 25%，从而实现更快的交互和更快的出结果。

GPT‑5.3‑Codex 是为 NVIDIA GB200 NVL72 系统联合设计、训练和部署的。我们感谢 NVIDIA 的合作。
