**摘要**

我们提出了 WorldDirector，这是一个高度可控的视频世界模型框架，专为持久动态对象记忆和不受限制的视角探索而设计。与现有的将物理动力学与像素渲染纠缠在一起、并依赖持续视觉观察来维持运动的世界模型不同，我们的框架明确地将语义运动编排与视觉生成解耦。通过利用大语言模型（LLM）协调3D轨迹与相机运动，随后将这些编排好的轨迹作为视频生成的控制信号，我们的方法确保了严格的物理逻辑和外观稳定性，即使在动态实体长时间离开视野后重新进入场景时，也能成功保持其精确的视觉身份。实验结果表明，我们的方法支持合成复杂且扩展的事件，具有前所未有的可控性和持久动态对象记忆。

## 1 引言

视频生成的格局正在经历深刻变革，从被动像素合成 [7, 5, 27, 13] 转向交互式环境模拟 [8, 9, 11, 20, 33, 38, 36]。这一范式转变的基石是记忆：保持静态场景一致性和动态对象连续运动的能力，无论它们在画面中可见还是不可见。虽然最近的方法通过记忆检索或上下文条件化在保持静态场景一致性方面取得了显著成功 [50, 46, 21, 35, 44]，但一个关键领域在很大程度上仍未被探索："对象永久性"和"动态对象记忆"。具体而言，这意味着动态实体持续存在并执行其物理运动，独立于相机可见性。因此，每当动态对象重新出现在画面中时，它们新更新的位置和状态应该被准确观察到。

为实现这一目标，我们认为具有鲁棒动态记忆的世界模拟器必须建立在两个基础支柱之上。首先，实体必须表现出独立的运动。它们的轨迹应遵循不受相机可见性约束的连续物理逻辑，确保未观察到的动力学自然推进。其次，系统必须保证严格的外观一致性。当一个隐藏的实体重新进入画面时，其视觉身份和精细细节必须完全保持不变，不产生失真。满足这两个标准是将不可预测的视频生成提升到持久世界模拟水平的先决条件。

受这一目标驱动，最近已经提出了几种方法来实现配备动态记忆的世界模拟器。一种框架 [16] 引入了基于监视器的机制，通过注册显式"监视器"来处理视野外的动力学，这些监视器自主跟踪并快进未观察到的活动实体的时间推进。然而，这种显式跟踪系统在涉及多个动态实体的场景中扩展性差，并产生过高的计算开销。相反，另一种方法 [12] 跟踪动态特征，但将轨迹外推完全委托给内部生成先验。虽然这种隐式估计对于短暂遮挡可能足够，但在长时间相机偏移或复杂动态交互中会失败。依赖生成权重在没有专门编排机制的情况下猜测连续物理演化，不可避免地会导致轨迹崩溃、冻结状态或重新进入时的严重身份错误。

为克服上述限制并实现这两个基础支柱，我们引入了 WorldDirector。我们的核心见解是明确地将动态对象的运动规划与视频合成过程解耦。通过利用可控生成范式，我们将语义级规划结果作为条件传输给生成模型，从而实现一个配备鲁棒动态记忆的持久世界模拟器。这种架构不仅保证了动态对象的独立和连续运动，还提供了高可控性，使用户能够独立决定多个不同动态实体的具体动作和语义行为。

具体而言，我们采用LLM作为中央编排器，将用户指令转换为3D边界框和相机轨迹。这些空间计划随后被投影到2D边界框序列中，为视频合成提供位置条件。为防止隐藏实体重新进入画面时的身份失真，我们提出了一种外观绑定机制，将来自上下文的RGB动态对象特征作为视觉锚点注入。对于细粒度状态控制，空间感知交叉注意力机制 [41] 将实体特定的文本提示路由到其对应区域。这些机制集成在因果自回归架构中，确保了具有严格动态记忆的扩展视频生成。

大量评估表明，WorldDirector 能够合成高度可控的动态场景，同时在扩展序列中严格保持动态记忆。通过确保长时间不可见间隔后的对象永久性和外观一致性，我们的方法超越了被动视频生成，代表了向具有前所未有的动态对象记忆的交互式和持久世界模拟器迈出的重要一步。

## 2 相关工作

### 2.1 基础视频模型与世界模拟器

生成式视频合成随着扩散和Transformer架构 [7, 5, 27, 13] 取得了快速进展。除了像素保真度之外，该领域正越来越多地转向用于模拟交互环境的视频世界模型。Sora [8]、Genie [9]、Oasis [15] 和 DIAMOND [1] 等开创性工作将生成模型视为基础物理引擎，在类游戏模拟器 [11, 20] 和长序列交互生成器 [33, 22, 36] 方面取得了进一步进展。然而，依赖生成模型隐式记忆对象状态、动作和外观会使其容量过载：当活动实体退出相机视野时，这些纠缠的模型无法维持动力学，导致对象冻结或消失。我们的工作通过明确地将语义运动编排与视觉渲染解耦来解决这一问题。

### 2.2 可控视频生成

为超越随机生成，可控合成已被广泛探索。图像控制机制 [51, 34, 25, 2] 已被扩展到视频 [52]。对于空间和运动控制，Boximator [42] 和 GLIGEN [30] 利用边界框，而其他方法针对相机轨迹 [19] 或运动跟踪 [49, 43]。最近，密集或点轨迹引导已成为细粒度、实体级运动控制的灵活接口 [53, 45, 18, 28, 40, 14]。虽然这些方法在短片段中有效，但它们缺乏长时程模拟所需的自回归记忆。我们的框架在持久记忆架构中采用了 GLIGEN [30] 的空间感知交叉注意力，实现了跨扩展时间窗口的一致控制。

### 2.3 视频世界模型中的记忆机制

记忆支撑着超越即时上下文窗口的时间连贯性。长视频生成器 [21, 35] 使用滑动窗口但在扩展遮挡方面存在困难。先前的工作通过FOV检索 [50, 46] 或3D表示 [29] 保持静态场景一致性，但假设世界是静态的。对象永久性——定义为对象在未被观察时持续存在和演化——仍然是物理推理中的核心挑战 [48, 4, 6]，对于复杂场景中的活动实体来说更加困难。最近的方法采用隐式混合记忆令牌 [12] 或外部监视器进行视野外动态模拟 [16]。然而，内部先验在长时间偏移期间有轨迹崩溃的风险，而外部监视器在计算上是不可承受的。结合外观绑定机制，我们LLM编排的方法提供了可控生成和鲁棒的动态对象记忆，为世界探索中的对象永久性提供了一条可扩展的路径。

### 3.1 数据整理流程

我们引入了一个专门的数据整理流程来解决第1节中概述的基础需求。具体而言，该流程构建了全面的训练元组，包括：用于动态空间定位的2D边界框、用于细粒度视觉条件化的外观参考、详述行为动态的以对象为中心的字幕，以及促进因果生成的上下文信号。所提出的流程包含以下关键组件：

**动态对象跟踪和基于实体的字幕生成。** 为解决具有动态实体退出和重新进入视野（FOV）的真实世界数据的稀缺性，我们开发了一个基于游戏的平台来生成15秒的视频，具有精确的相机参数，刻意编写脚本以引发目标的消失和重新出现。我们使用 SAM3 [10] 提取2D边界框轨迹；其鲁棒的重识别能力能够无缝跟踪对象，尽管暂时退出FOV，确保了高度可靠的标注。对于训练，我们从每个视频中采样一个连续的5秒窗口，该窗口最大化新可见对象的数量（在第一帧中不存在但稍后出现的对象），以专门捕获关键的重新进入场景。剩余的10秒作为候选池，提供历史外观和时空上下文。最后，我们将唯一的颜色编码边界框叠加到源帧上以保持实例身份，并将这些视觉增强的序列输入 Qwen2.5-VL-72B [3]，以生成每个实体动作动态的细粒度文本字幕。

**动态对象的双条件化准备。** 我们为每个训练序列构建两个条件化视频。首先，为了编码时空轨迹并提供位置先验，我们通过在零初始化背景上用唯一颜色标识符填充每个动态对象的2D边界框来生成空间位置条件视频。其次，为了确保重新进入对象的外观一致性，无论其缺席持续时间如何，我们引入了外观条件化视频。具体而言，对于帧 *t* 处边界框 box_{a,t} 的对象 *a*，我们从10秒候选池中检索同一对象的参考 box_{a,t'}，该参考相对于 box_{a,t} 最小化纵横比偏差。然后裁剪 box_{a,t'} 内的图像区域，进行空间重采样，并映射到外观视频中 box_{a,t} 的坐标，直接为模型在指定的时空索引处提供精确的视觉特征。

**静态和动态上下文检索。** 为更好地支持鲁棒的因果推理并保持时空一致性，我们通过双视角方法检索上下文。对于静态场景，我们遵循 [50] 检索最大化视野（FoV）重叠的前 *K* 帧。对于动态对象，我们引入了一种贪心算法，优先选择当前时间块内具有活动对象身份的帧。为确保均匀的时空分布，我们强制选定帧之间的最小时间步长为四帧。然后将从两种策略得出的排序列表进行交错和去重，以产生最终的 *N* 个记忆帧索引。详细的选择过程在附录B中概述。

### 3.2 构建具有持久动态记忆的可控世界模拟器

在我们建立的数据整理流程基础上，我们提出了 WorldDirector，这是一个将视频生成重新概念化为具有持久动态记忆的可控世界模拟的框架。我们将此目标表述为由多模态结构先验引导的条件去噪过程。形式上，设 V ∈ ℝ^{T×3×H×W} 表示包含 *T* 帧的训练视频序列。生成过程以复合元组 𝒯 = {ℬ, 𝒜, 𝒫, ℳ} 为条件：

- **位置条件** ℬ ∈ ℝ^{T×3×H×W} 编码所有实体的2D边界框的精确时空轨迹，渲染为保持身份的颜色编码掩码。 - **外观条件** 𝒜 ∈ ℝ^{T×3×H×W} 提供从上下文帧导出的稀疏RGB特征，以保持序列中动态对象外观的一致性。 - **多粒度提示** 𝒫 = {p_global, p₁, p₂, …, p_k} 由总结整体视频叙事的全局提示 p_global 和详述 *k* 个动态实体特定语义行为的细粒度文本描述 {p_i}_{i=1}^k 组成。 - **上下文记忆帧** ℳ 代表通过双流选择策略检索的上下文帧，与其对应的位置和外观条件化配对，以使特征维度与当前生成窗口对齐，从而将生成内容锚定在更广泛的全局场景中。

在本节中，我们详细阐述如何利用这些多模态条件先验来实现动态记忆增强的世界模拟。

#### 3.2.1 空间位置和视觉外观的控制

为实现具有严格动态一致性的可控世界模型，我们用辅助特征通道扩展了 LingBot-World-Base 架构，用于空间（ℬ）和外观（𝒜）约束，实现了具有高物理保真度的高保真自由探索模拟。具体而言，ℬ 使用实例特定的颜色编码掩码来明确区分多个实体，作为其轨迹、形状和方向的确定性几何先验。同时，𝒜 锚定历史视觉特征以确保身份连贯性，防止实体重新进入相机视野时的视觉退化。

为防止模型过度依赖 𝒜 并产生实体仅平移而不表现出适当关节运动的不自然滑动伪影，我们引入了**时间丢弃机制**。对于每个动态实体，我们保留其进入视野后紧接着的初始16帧的密集序列。随后，我们采用稀疏采样策略，每六帧间隔仅保留一个参考帧。这种信息瓶颈迫使模型合成由轨迹和语义字幕驱动的自然对象运动，将 𝒜 严格用作身份锚点。

在架构上，ℬ 和 𝒜 都由3D VAE编码为潜在令牌，并沿特征维度与噪声潜在序列拼接：

z_in = Conv3D(z_t ⊕ ℰ(ℬ) ⊕ ℰ(𝒟_τ(𝒜))) (1)

其中 z_t 表示噪声潜在表示，ℰ(·) 代表预训练的3D VAE编码器。⊕ 表示通道拼接。𝒟_τ(·) 表述了我们的时间丢弃机制，定义为：

𝒟_τ(𝒜_t^{(i)}) = 𝒜_t^{(i)}, 如果 k^{(i)} < 16 𝒟_τ(𝒜_t^{(i)}) = 𝒜_t^{(i)}, 如果 k^{(i)} ≥ 16 且 (k^{(i)} - 16) mod 6 = 0 𝒟_τ(𝒜_t^{(i)}) = 0, 否则 (2)

这里，𝒜_t^{(i)} 表示实体 *i* 在全局帧 *t* 处的外观条件，k^{(i)} ≥ 0 是其实例特定的相对帧索引（即自实体 *i* 新进入视野以来经过的帧数）。完整的外观条件化特征 𝒟_τ(𝒜) 聚合了这些处理后的实体级表示，其中被掩码的实体被替换为零嵌入 0。融合的潜在表示随后由专用层 Conv3D(·) 处理，其中与 ℰ(𝒟_τ(𝒜)) 对应的通道权重从首帧处理器初始化以进行RGB身份迁移，而 ℰ(ℬ) 的权重则零初始化，以将轨迹引导生成作为残差过程来学习。

#### 3.2.2 上下文整合

为在因果块生成过程中保持静态场景和动态对象的一致性，我们通过将上下文帧沿时间轴前置于噪声潜在序列的序列级拼接来整合检索到的上下文 ℳ。为强制结构对齐，与每个上下文帧关联的位置和外观条件化沿特征维度拼接，严格镜像训练段的输入公式。此外，为明确将这些历史锚点与当前生成块解耦，用于上下文帧的旋转位置嵌入的时间步被偏移了一个 substantially 超过最大训练序列长度的偏移量，在RoPE表示空间中建立了确定的频率边界。为防止噪声训练潜在表示污染高保真上下文 ℳ，我们施加了非对称注意力掩码，其中上下文令牌专门自注意力以保持稳定、无噪声的参考。这使模型能够利用历史先验而不损害上下文完整性。最后，为使模型具备从头直接生成初始序列块的能力，我们在训练阶段以30%的概率随机丢弃上下文信息 ℳ。

### 3.3 相机注入和空间感知文本控制

为准确建模透视变化并在生成过程中有效利用上下文相机信息，我们首先将所有上下文帧和当前视频块的相机位姿转换为相对于当前生成块第一帧的相对相机位姿。遵循 Wan [39]，我们利用普吕克坐标来编码这些相对内参和外参。接下来，我们对这种表示应用空间下采样，然后通过一系列卷积模块提取多级相机运动嵌入。这些嵌入随后通过自适应归一化层注入到每个扩散Transformer（DiT）块中。

对于文本条件注入，确保实体特定的字幕精确地定位在其对应的空间区域至关重要。为此，我们采用了 [41] 中的空间感知加权交叉注意力机制。该方案不是在整个帧上均匀计算交叉注意力，而是识别由每个实体的2D边界框轨迹所包含的视觉令牌。然后，我们对这些局部视觉令牌与描述该实体的特定文本令牌之间的预softmax注意力logits应用有针对性的空间权重偏置。通过这样做，它有效地减轻了语义泄漏，并促进了对合成场景中多个动态对象的细粒度控制。

### 3.4 训练和推理

我们遵循流匹配框架 [31, 17]，使用均方误差（MSE）损失进行后训练。训练目标仅应用于当前目标段，而历史上下文保持无噪声并仅作为参考。

形式上，设 x₁ 表示目标视频块的真实潜在表示，x₀ ~ 𝒩(0, I) 为随机噪声。在采样时间步 t ∈ [0, 1]，目标部分的训练输入为 x_{tgt,t} = t·x₁ + (1-t)·x₀，相应的真实速度定义为 v_t = x₁ - x₀。如第3.2节所述，模型 *u* 接收拼接序列 [x_ctx, x_{tgt,t}]，其中 x_ctx 表示干净的上下文令牌。训练目标表述为：

ℒ = 𝔼_{x₀, x₁, t, Ω} [Σ_{i∈ℐ_tgt} ‖u(x_t, t, Ω; θ)_i - v_{t,i}‖²] (3)

其中 Ω = {ℬ, 𝒜, 𝒫, ℳ} 是所有位置、外观、文本和上下文条件的并集，ℐ_tgt 表示属于当前视频段的令牌索引集。通过将损失计算限制在 ℐ_tgt，我们确保模型学习合成以前帧的干净记忆为锚点的新内容，而不试图重建已确定的上下文。

在推理过程中，我们的方法分为两个主要阶段，如下所述：**通过LLM进行世界规划**和**基于因果块的生成**。关于推理实现的更多细节在附录C中提供。

**通过LLM进行世界规划。** 我们首先估计给定初始图像中目标动态对象的3D边界框，为LLM提供基础的空间上下文，LLM随后预测连续的3D边界框轨迹——包括空间坐标和方向——以及我们设计的相机路径。该轨迹规划不仅包括初始帧中存在的实体，还包括稍后出现的实体。初始帧中不存在的对象在首次进入相机视野时根据其字幕合成。后续生成然后以这些初始输出为条件以保持外观一致性。然后将这些3D轨迹投影到2D图像平面上，产生2D边界框序列，形成与我们训练阶段采用的位置条件化格式严格对齐的空间条件 ℬ。

**基于因果块的生成。** 为促进计算高效的长时程世界探索，我们引入了自回归基于块的生成策略（详见附录C）。投影的2D位置条件 ℬ 被划分为连续的时间块。在第一个块生成期间，该过程仅依赖初始参考帧来获取外观条件 𝒜，记忆上下文 ℳ 为空。对于所有后续块，我们从先前生成块的持续更新池中递归构造 𝒜 并检索 ℳ。这个因果循环在整个动态模拟过程中明确保持实体身份和时空一致性，最终促进任意长度的世界探索。

## 4 实验

**实现细节。** 我们在预训练的 LingBot-World-Base 模型 [38] 上构建 WorldDirector。所有训练视频被预处理为 832×480 像素的固定分辨率，帧率为16 fps。对于条件化，上下文长度设为 N=10 帧，每帧通过预训练的3D VAE独立编码。我们的模型训练3,000步，使用64的全局批量大小和 1×10⁻⁵ 的恒定学习率。在推理过程中，我们利用 Gemini [37] 作为编排器来规划所有动态实体的3D轨迹和状态。随后，全长视频被划分为五秒的段，以自回归方式逐块生成。LLM的综合提示模板在补充材料中详述。

**基线方法。** 我们将 WorldDirector 与最先进的因果交互式世界模型进行比较：Yume 1.5 [32]，使用均匀时间下采样进行记忆；HY-World 1.5 [24]，在混合数据上应用基于FOV的注意力以实现记忆；Infinite World [44]，通过分层上下文压缩实现记忆；LingBot-World-Fast [38]，利用因果注意力进行无限生成；以及 HyDRA [12]，利用时空检索来维持屏幕外角色运动。

**评估协议。** 为评估我们的方法，我们使用我们的数据流程构建了一个包含100个视频样本的测试集，这些样本具有训练中未见过的全新场景和主体。遵循 HyDRA [12]，我们使用PSNR、SSIM和LPIPS通过像素级分析来评估整体重建保真度，以及VBench [23] 的主体和背景一致性用于帧级连贯性评估。我们还采用动态主体一致性（DSC），通过裁剪YOLO检测到的动态对象边界框并计算其与上下文对应物的平均DINO和CLIP相似度。该指标有效捕获动态对象一致性，特别是对于屏幕外重新出现的情况。

(2) **身份不一致**：虽然 LingBot-World 和 HyDRA 捕获了男人的运动，但它们在身份保持方面存在困难。LingBot-World 尽管将男人保持在画面内，但表现出轻微的外观退化，而 HyDRA 在男人重新出现时生成了一个完全新的身份。

(3) **控制不足**：由于缺乏位置条件，所有基线都无法将相机和对象动态与用户的设计正确同步。LingBot-World 自动生成相机平移以确保男人保持在镜头中；Infinite-World 正确执行了相机控制但遗漏了对象运动；HyDRA 直接忽略了远处的男人并生成了一个在相机前行走的新男人。

相比之下，通过明确地以位置和外观条件为条件，我们的方法准确生成了用户期望的场景，并保持了男人在长时间消失后重新出现的一致性。我们在附录F中展示了更多定性比较结果。

**消融研究。** 我们研究模型是否可以在没有显式外观条件的情况下隐式保持视觉一致性。假设位置条件中的唯一颜色编码掩码可以引导从上下文帧中检索外观，我们观察到模型无法自主利用此上下文，导致重新进入的动态对象出现严重的身份丢失（图4，第二行）。

为在不引入新条件通道的情况下尝试解决此问题，我们应用了一种启发式自注意力路由策略，以放大当前和上下文动态对象令牌之间共享相同身份的注意力权重。虽然这种显式偏置捕获了一般风格（人们衣着的颜色保持一致），但它从根本上破坏了预训练的潜在分布，导致严重的伪影、模糊和细粒度纹理的丢失（图4，第三行）。

我们将这些失败归因于训练数据中像素分布的不平衡。由于静态背景占据了大部分像素并主导MSE损失，模型难以隐式学习小型动态区域中高保真一致性所需的复杂映射。表2中的结果也表明，没有外观条件时所有指标都下降。这证实了显式注入外观条件对于动态记忆是必要的。

**可提示世界事件。** 我们的框架不受初始帧中存在的实体的约束。LLM可以通过为新对象定义身份、进入时间和3D运动轨迹来自由填充模拟世界。在首次进入相机视野时，它们的外观和运动直接从文本提示合成，并附加到外观条件池中以确保后续的时间一致性。如图5所示，这种范式能够同时编排多个出现的实体以及不受约束的相机探索。因此，我们的方法不仅仅是外推现有视频内容，而是为开放式场景生成和动态环境模拟提供了一种高度可控的机制。

## 5 结论

我们提出了 WorldDirector，一个用于视频世界模型中自由探索和灵活事件设计的新框架，同时保持严格的动态记忆。通过将语义编排与潜在合成解耦，WorldDirector 使LLM能够规划复杂的3D轨迹和开放世界事件。抽象规划通过基于因果块的上下文路由在视觉上实现，利用空间和外观条件化。实验证实我们的方法保持了严格的动态一致性，为未来视频世界模型建立了一个高度可控的范式。

**局限性。** 依赖合成游戏数据引入了领域差距，偶尔限制视觉保真度（例如，不自然的运动或模糊的面部）。未来的工作将纳入真实世界数据集以弥合这一差距并增强整体视觉真实感。

## 附录B 静态和动态上下文检索的细节

**算法1：静态和动态上下文检索**

``` 输入：候选上下文帧 ℱ，训练帧 𝒱，相机位姿 𝒞， 2D边界框 ℬ，上下文长度 N 输出：静态和动态上下文 ℳ

过程 Static_Context(ℱ, 𝒱, 𝒞): 对每个候选 c ∈ ℱ: score(c) ← max_{v∈𝒱} FoV_Overlap(𝒞_c, 𝒞_v) 返回按 score(·) 降序排列的 ℱ

过程 Dynamic_Context(ℱ, 𝒷, N, 𝒱): 为 𝒱 中出现的每个动态实体 i 初始化 cnt[i] ← 0 当 |selected| < N: 找到实体 i* = argmin_i cnt[i] ▷ 目前覆盖最少的实体 选择帧 f* ∈ ℱ，使 area(ℷ_{f*}^{(i*)}) 最大 ▷ 实体 i* 的最佳可见上下文 将 f* 加入 selected，从 ℱ 中移除 f* A_max ← max_e area(ℷ_{f*}^{(e)}) ▷ f* 中最大边界框面积，用作归一化器 对 f* 中的每个实体 j: cnt[j] += area(ℷ_{f*}^{(j)}) / A_max ▷ 归一化边界框面积作为可见性权重 返回 selected

𝒫_cam ← Static_Context(ℱ, 𝒱, 𝒞) 𝒫_box ← Dynamic_Context(ℱ, 𝒷, N) ℳ ← [] k = 0, 1, ... 直到 |ℳ| = N: 如果 𝒫_cam[k] 不在 ℳ 中，则将 𝒫_cam[k] 加入 ℳ 如果 𝒫_box[k] 不在 ℳ 中，则将 𝒫_box[k] 加入 ℳ 返回按时间顺序排列的 ℳ ```

在本节中，我们详细阐述静态和动态上下文检索机制的具体实现细节（如算法1所述）。该算法旨在从候选帧集 ℱ 中选择 *N* 个记忆帧来构建最终上下文集 ℳ。输入主要包括候选帧 ℱ、当前训练帧 𝒱、相机位姿 𝒞 和动态实体的2D边界框 ℬ。检索过程由两个并行评分模块和随后的交错融合模块组成：

**静态上下文检索。** 静态检索模块旨在找到与当前训练帧视角重叠最高的上下文帧，以提供全面的静态背景信息。对于候选集 ℱ 中的每帧 *c*，算法计算其相机位姿 𝒞_c 与所有训练帧位姿 𝒞_v 之间的视野（FoV）重叠，取最大重叠值作为候选的分数。随后，所有候选帧按这些分数降序排列，生成静态上下文候选列表 𝒫_cam。

**动态上下文检索。** 为确保动态对象的平衡时空覆盖，我们为 𝒱 中出现的每个动态实体 *i* 维护一个覆盖计数器 cnt[i]（初始化为0）。在每次贪心迭代中，我们识别覆盖最少的实体 i*，并检索使其可见2D边界框面积最大的帧 f* ∈ ℱ。然后通过添加 f* 中所有实体 *j* 的边界框面积（用 f* 中最大边界框面积 A_max 归一化）来更新它们的覆盖。此过程重复直到收集到足够的帧，产生动态列表 𝒫_box。

**交错和融合。** 我们交替将 𝒫_cam 和 𝒫_box 中的帧附加到最终记忆集 ℳ。在此步骤中，去重并严格执行最小四帧时间步长以保证均匀分布。当 |ℳ| = N 时交错终止，上下文帧按时间顺序返回。

## 附录C 推理系统细节

我们的推理系统包括两个主要组件：通过LLM进行世界规划和基于因果块的生成。在本节中，我们详细阐述这些操作的具体细节。

### C.1 通过LLM进行世界规划

我们采用 Gemini [37] 作为世界规划的核心语义引擎。具体而言，给定初始帧，我们首先选择感兴趣的动态对象。我们利用 SAM [26] 和 DepthAnything v2 [47] 粗略估计这些对象的3D边界框，并为实体和相机建立初始方向。

然后将这些结构化信息输入LLM，提示其根据我们定制的叙事设计分析性地规划相应的3D轨迹。我们使用的提示示例如下：

``` 你是一位具有强大3D空间想象能力的专家。给定以下信息： { "coordinate_system": "OpenGL (X-right, Y-up, Z-backward)", "camera_position": {"position": [0.0, 0.0, 0.0]}, "camera_intrinsics": { "fx": 565.4046, "fy": 565.4046, "cx": 416.0, "cy": 240.0, "image_width": 832, "image_height": 480, "fov_v_deg": 46 }, "ground_height_y": [-1.248], "bboxes_3d": [ { "bbox_3d": { "center": [-1.7175, -0.4237, -3.4715], "dimensions": [0.6799, 1.8, 0.442], "rotation_yaw_deg": 90, "prompt": "A woman walks on the road." } }, { "bbox_3d": { "center": [3.227, -0.8014, -7.1893], "dimensions": [1.2749, 1.1321, 3.1872], "rotation_yaw_deg": 90, "prompt": "A car first keep still, then starts driving on the road." } } ] } ```

这里，"coordinate_system"表示3D坐标系；"camera_position"指初始相机位置；"camera_intrinsics"指定相机参数；"ground_height_y"是地面的y坐标；"bboxes_3d"包含多个主体的信息。对于每个"bbox_3d"，"center"表示初始3D中心坐标，"dimensions"表示对象的实际宽度、高度和长度，"rotation_yaw_deg"是初始偏航角。"prompt"提供轨迹生成的文本描述。

``` 用户指令： 请帮我生成这些主体对应的3D bbox轨迹和相机位姿。总时长为15s，帧率16 fps。初始相机位置在原点，位姿为单位矩阵，面向-Z方向。

0-5s： 相机和汽车保持静止。女人沿+X方向向前走，在5s时到达相机视野边缘。

5-10s： 在5-6s，相机从-Z旋转到+X。从6-10s，相机沿+X向前移动，超过女人。女人继续沿+X行走，汽车保持静止。

10-15s： 在10s，相机停止。从10-11s，从+X旋转到-Z，从11-15s，保持严格静止。女人沿+X行走，在11s重新进入相机视野，然后在画面内继续行走。汽车在10s开始沿+X行驶，在11s进入相机视野，在14s退出。

返回生成上述3D bbox轨迹和相机位姿的Python代码，并进行可视化。同时，对于每一帧，使用当前相机位姿将3D bbox投影到相机平面以生成2D bbox。将投影的2D bbox写入最终输出并进行可视化。 ```

除了为初始帧中明确选择的对象规划轨迹外，用户还可以在提示中为完全新颖的对象定义运动路径。LLM展示了为这些新引入的实体自动合成物理上合理的运动学的卓越能力（即可提示世界事件）。

因此，我们获得了所有动态对象的完整3D轨迹及其对应的投影到相机平面上的2D边界框序列。这些2D投影序列直接用作后续生成阶段中应用的确定性空间位置条件（ℬ）。

### C.2 基于因果块的生成

在规划阶段的投影2D位置条件和相机轨迹基础上，我们以因果自回归方式执行视频合成，如算法2所述。

**算法2：基于因果块的生成**

``` 输入：位置条件序列 ℬ_{1:T}，字幕 𝒫，初始参考帧 I_0，总帧数 T，块大小 K，相机位姿 𝒞_{1:T} 输出：生成的连续视频流 V

过程 Causal_Generation(ℬ_{1:T}, 𝒫, I_0, T, K, 𝒞_{1:T}): 将 ℬ_{1:T} 划分为 N=T/K 个块：{ℬ^(1), ..., ℬ^(N)} 将 𝒞_{1:T} 划分为 N=T/K 个块：{𝒞^(1), ..., 𝒞^(N)} 初始化视频缓冲区 V ← I_0 对 n = 1, 2, ..., N: 如果 n = 1: 𝒜 ← Appearance_condition_generation(ℬ, I_0) ℳ ← ∅ ▷ 第一个块没有历史上下文 否则: 𝒜 ← Appearance_condition_generation(ℬ, V) ℳ ← Context_Retrieval(ℬ, 𝒞, V) I_start ← V_last ▷ 使用缓冲区V的最后一帧作为当前块生成的初始帧 V^(n) ← WorldDirector(ℬ^(n), 𝒫, 𝒜, ℳ, 𝒞^(n), I_start) V ← V ∪ V^(n)[1:] ▷ 将生成的块（不含第一帧）附加到缓冲区 返回 V ```

给定完整的空间位置序列 ℬ_{1:T} 和相机位姿 𝒞_{1:T}，我们首先将它们划分为 *N* 个大小为 *K* 的顺序块。生成过程维护一个全局连续视频缓冲区 *V*，用起始参考帧 I_0 初始化。

在迭代生成过程中，条件化策略根据时间状态进行调整。对于第一个块（n=1），模型在位置条件 ℬ 的引导下直接从 I_0 提取外观条件（𝒜），而历史上下文记忆（ℳ）保持为空，因为没有前序时间信息。对于所有后续块（n>1），框架从先前生成的视频缓冲区 *V* 中动态构造 𝒜 并检索历史上下文（ℳ）。此检索机制严格利用位置约束 ℬ 和相机参数 𝒞 来获取精确的动态实体身份和静态背景锚点。

关键的是，为保证块边界处的时间平滑性，当前缓冲区的最后一帧（V_last）作为生成下一个块 V^(n) 的条件初始帧（I_start）。核心扩散模型 WorldDirector 处理这些多模态条件（ℬ^(n), 𝒫, 𝒜, ℳ, 𝒞^(n), I_start）来合成当前段。最后，我们将生成的帧附加到 *V*——排除重叠的第一帧以防止冗余——从而逐步展开长时程视频流而不受固有长度限制。
