开源小米MiMo-V2.5及Pro版在智能体任务中高效实惠

Carl Franzen
发布于
2026年4月27日，太平洋时间 下午2:45
更新于
2026年4月28日，太平洋时间 下午1:22


图片来源：VentureBeat 使用 Google Gemini 3.1 Pro Image 制作

小米这家以智能手机和电动汽车闻名的中国公司，最近推出了一些极其实惠且强大的开源 AI 大语言模型。

这一趋势在今天随着 Xiaomi MiMo-V2.5 和 Xiaomi MiMo-V2.5-Pro 的发布得以延续，这两款模型均在宽松且对企业友好的 MIT 许可下提供，使其适合在商业应用的生产环境中使用。企业和个人/独立开发者现在可以直接从 Hugging Face 下载其中任一模型（以及更多小米开源选项），根据需要进行修改，并在本地或虚拟私有云上按自己的意愿运行。

除了开源许可外，这些模型最显著的特点是，根据小米发布的基准测试，它们是处理智能体“爪”（claw）任务效率最高的模型之一，即为 OpenClaw、NanoClaw 和 Hermes Agent 等系统提供支持。在这些系统中，用户可以通过第三方消息应用直接与它们交流，并让智能体代替人类用户去完成任务，例如制作和发布营销内容、运营账户、整理邮件和安排日程等。


Xiaomi MiMo-V2.5-Pro 和 MiMo-V2.5 的 ClawEval 基准测试图表。图片来源：小米

正如小米的 ClawEval 基准测试图表所示，MiMo-V2.5 特别是 Pro 版本都出现在图表的左上方，这表明它们在完成基准测试的“爪”任务时性能极高，同时使用的 token 数量最少——为人类用户节省了资金，尤其是在越来越多服务（如微软的 GitHub Copilot）正转向基于使用量计费的世界里（向智能体背后的人类按使用的每个 token 收费，而不是像 Anthropic 那样施加速率限制，或像 OpenAI 那样提供“自助餐”式的订阅）。

事实上，Pro 模型以 63.8% 的成功率领先开源领域，每条轨迹仅消耗约 70K token。

这比 Anthropic Claude Opus 4.6、Google Gemini 3.1 Pro 和 OpenAI GPT-5.4 达到可比结果所需的 token 少了约 40-60%。

双轨并行策略

小米发布了两个不同版本的模型，以满足开发领域的不同需求：MiMo-V2.5（“全能”多模态专家）和 MiMo-V2.5-Pro（“智能体”专家）。

基础模型提供原生多模态能力，而 MiMo-V2.5-Pro 则专为“长程连贯性”和复杂软件工程而设计。

在 GDPVal-AA (Elo) 基准测试中，Pro 模型获得了 1581 分，超越了 Kimi K2.6 和 GLM 5.1 等竞争对手。


Xiaomi MiMo-V2.5 Pro 基准测试对比表。图片来源：小米

小米研究人员进一步发布了 V2.5-Pro 自主执行的几项高复杂性任务的数据：

  • Rust 中的 SysY 编译器： 该模型从头开始实现了一个完整的编译器——包括词法分析器、解析器和 RISC-V 汇编后端——耗时 4.3 小时。跨越 672 次工具调用，该模型在隐藏测试套件上获得了完美的 233/233 分，这项任务通常需要计算机科学专业的学生几周时间才能完成。
  • 全功能视频编辑器： 在超过 11.5 小时和 1,868 次工具调用中，该模型生成了一个 8,192 行的桌面应用程序，具有多轨时间线和导出管线。
  • 模拟 EDA 优化： 在一项研究生级别的工程任务中，该模型在台积电 180nm 工艺中优化了翻转电压跟随器 (FVF-LDO) 稳压器。通过迭代 ngspice 仿真循环，该模型将其初始尝试的线路调整率等指标提高了 22 倍。

这些实验突出了 V2.5-Pro 的“脚手架感知”能力，即模型主动管理自己的内存并塑造其上下文，以在数千次连续的工具调用中保持连贯性。

通过 API，小米为国内（中国）和国际市场（如美国）制定了具有竞争力的模型价格。对于海外开发者，高性能的 MiMo-V2.5-Pro 在高达 256K 的上下文窗口内，输入价格为每百万 token 1.00 美元（缓存未命中时），输出为 3.00 美元。

对于 256K 到 1M token 之间的超长上下文任务，成本翻倍，输入为 2.00 美元，输出为 6.00 美元，尽管架构的缓存能力提供了显著的缓解，在缓存命中时将输入成本降低至每百万 token 仅需 0.20 至 0.40 美元。

在国内，这些费率以人民币体现，Pro 模型标准上下文的输入价格从每百万 token 7.00 元起，扩展的 1M 范围达到 14.00 元。同时，基础模型海外输入价格仅为每百万 token 0.40 美元，输出为每百万 token 2.00 美元，使其跻身全球领先大语言模型中最实惠的三分之一之列（见下表）：

为了进一步降低智能体开发的门槛，小米限时对所有模型的缓存写入免费，同时完全免除整个 MiMo-V2.5-TTS 套件的费用，该套件包括其专门的语音克隆和设计功能。

这种定价逻辑显然是为了加速从简单的聊天应用向持久、长程的智能体过渡，这些智能体的运行成本仅为传统前沿模型的一小部分。

小米还推出了全新版本的订阅服务，称为“Token 计划”，目前提供四个级别：

  • Lite“入门包”每年 63.36 美元，提供 7.2 亿积分
  • 标准层每年 168.96 美元，提供 24 亿积分
  • Pro 层每年 528.00 美元，提供 84 亿积分（专为企业用例设计）
  • Max——面向高强度编码爱好者——每年 1,056.00 美元，提供 192 亿积分

除了积分分配，所有计划还包括优惠的 API 费率、非高峰时段调用 20% 的折扣，以及对 Cursor、Zed 和 Claude Code 等流行编码脚手架的“Day-0”支持。

然而，无论是通过 API 还是通过 Token 计划，从中国访问小米模型可能会给美国企业客户带来障碍或额外的合规及监管风险。因此，对于担心依赖中国技术但又希望利用低成本和开源模型的美国企业来说，最好的选择可能是建立自己的虚拟私有云或本地服务器，下载模型权重，并在本土运行模型。

MoE 架构，但 V2.5 和 V2.5-Pro 的训练方案不同

MiMo-V2.5 的核心是稀疏混合专家架构。虽然该模型总共有 3100 亿个参数，但在任何给定的推理周期中只有 150 亿个参数是“活跃”的。

同时，V2.5-Pro 是一个拥有 420 亿活跃参数的 1.02 万亿参数混合专家模型。

在这两种情况下，这种设计的功能都非常像一个专门的研究医院：虽然该设施有数百名医生（参数），但只有特定病例（查询）所需的特定专家才会被叫到房间里。

Pro 版本参数量的大幅增加提供了复杂软件工程和长程任务中深度、多步推理所需的“神经容量”，就像一家更大的医院里有更多的专家一样。

根据小米的博客文章，常规 V2.5 遵循严格的五个阶段演进：

  1. 文本预训练： 在 48 万亿 token 上构建庞大的语言主干。
  2. 投影器预热： 将内部音频和视觉编码器与语言核心对齐。
  3. 多模态预训练： 在高质量的跨模态数据上进行扩展。
  4. 智能体后训练： 逐步将上下文窗口从 32K 扩展到 1M token。
  5. 强化学习与 MOPD： 利用强化学习和多模态偏好优化 (MOPD) 来增强现实世界的推理和感知。

该主干采用继承自 MiMo-V2-Flash 的混合滑动窗口注意力架构，优化了模型“记忆”长程信息的方式。这一技术基础使 MiMo-V2.5 能够原生地看、听和推理，而不是依赖外部的“插件”工具进行视觉或听觉处理。

相反，MiMo-V2.5-Pro 的训练将“动作空间”置于感官感知之上。Pro 模型的训练重点不再是感官对齐，而是转向扩展后训练计算。

这一过程旨在灌输“脚手架感知”，即专门训练模型在 Claude Code 或 OpenCode 等自主智能体脚手架内管理自己的内存和上下文。

基础 V2.5 模型被训练用于跨模态推理，而 Pro 版本则被训练用于在超过一千次的连续工具调用中保持连贯性。

标准 V2.5 模型平衡了局部和全局注意力以维持多模态感知。然而，Pro 模型采用了更高的混合注意力比例——从上一代的 5:1 演变为更激进的 7:1 比例。

这使得 Pro 模型能够“略读”其绝大部分上下文，同时对其当前目标最相关的特定 15% 数据应用高密度注意力，这是调试大型代码库或优化研究生级别电路的关键特性。

最后，虽然两个模型都经历了强化学习 (RL) 和多模态偏好优化 (MOPD)，但这些阶段的目标不同。

对于 MiMo-V2.5，RL 阶段用于增强感知和多模态推理。对于 MiMo-V2.5-Pro，RL 专注于智能体场景中的指令遵循，确保模型遵守深藏在超长上下文中的细微要求，并在自主执行期间从错误中优雅地恢复。

这造就了 Pro 模型的“自我纠正”纪律，正如其在 4.3 小时的 SysY 编译器构建过程中诊断和修复回归问题的能力所示。

完整的 MIT 许可非常适合企业用例

为了区别于许多包含限制性“可接受使用”政策的“开放”模型，小米在 MIT 许可下发布了 MiMo-V2.5。MIT 许可是宽松软件许可的黄金标准。对于开发者和企业来说，这意味着：

  • 无需授权： 公司可以在不寻求小米明确许可的情况下将模型用于商业部署。
  • 继续训练： 开发者可以自由地在专有数据上微调模型，甚至发布这些衍生权重。
  • 不受限制的商业使用： 没有通常困扰“社区”许可的收入上限或用户群限制。

通过选择 MIT 而不是定制的“开放权重”许可，小米将 MiMo 定位为下一代 AI 智能体的基础设施，实际上是邀请全球开发者社区将该模型视为一种公共设施。

小米的背景：从智能手机和电动汽车到中国开源 AI 宠儿

小米向前沿 AI 智能体的转型是十年建设的逻辑顶峰，在这十年中，它构建了世界上最密集的硬件-软件飞轮之一。

这家总部位于北京的公司成立于 2010 年，最初是智能手机领域的颠覆者，它已经完成了一场高风险的转型，成为一家由其“人 x 车 x 家”战略定义的垂直整合巨头。这个生态系统现在包含超过 8.23 亿个可连接的智能设备，统一在 HyperOS 架构下。

该公司在 2024 年凭借 SU7 进入汽车领域，随后推出高性能 YU7 SUV，这成为了这种整合的概念验证，使小米成为全球豪华品牌的直接竞争对手。

通过向芯片和操作系统的基础研发投资 2000 亿元人民币（290 亿美元），小米已经超越了消费电子组装；它已成为“动作空间”的架构师，利用其庞大的硬件足迹作为 MiMo-V2.5 系列中智能体智能的主要试验场。

生态系统支持

此次发布得到了更广泛的 AI 生态系统的即时“Day-0”支持。MiMo 团队宣布，SGLang 和 vLLM——两个最受欢迎的高吞吐量推理引擎——在发布时即支持 V2.5 系列。

这得益于与 AWS、AMD、T-HEAD 和 Enflame 的硬件合作伙伴关系，确保该模型可以从基于云的 H100 到国产加速器的一切设备上高效运行。

小米 MiMo 项目负责人、DeepSeek 团队前核心成员罗福莉在 X（前身为 Twitter）上强调了此次发布背后的理念：

“一个模型的价值不能仅仅用排名来衡量——而是由它解决的问题来衡量。现在让我们用 MiMo 来构建吧！”

为了启动这一构建阶段，罗福莉宣布为构建者和创作者提供100 万亿免费 token 额度。这一巨大的激励措施旨在降低想要尝试 1M 上下文窗口而又没有直接财务风险的开发者的入门门槛。

经济重构：开源与计量专有

此次发布正值 AI 经济学的关键时刻。向基于使用量计费的转变标志着 AI 服务“自助餐”时代的彻底结束，GitHub 今天的公告强调了这一趋势，即其 AI 编码助手 Github Copilot 将把所有计划转换为计量的、基于 token 的积分。

随着基于席位的可预测性让位于消费驱动的成本，高级智能体工作流——在单个推理会话中可能消耗数百万 token——正变得越来越难以让企业进行预算。

用户的情绪变得可以预见的愤世嫉俗，开发者抱怨说，随着订阅转换为有限的配额，他们将“得到更少，但支付相同的价格”。这种定价演变显著增强了 MiMo 系列的战略吸引力。通过在宽松的 MIT 许可下发布，小米允许组织绕过不断升级的“SaaS 税”，并通过私有部署重新获得财务可预测性。

关键是，小米取消了其 API 的“上下文税”。100 万 token 的上下文窗口现在按标准费率计费——V2.5 为 1 token = 1 积分，Pro 版本为 2 积分——没有额外的乘数。这与全行业转向基于会话上限的趋势形成了鲜明对比，使 MiMo 成为对成本敏感、高吞吐量开发的避风港。

企业分析

MiMo-V2.5 的发布不仅仅是权重的发布；它是开源社区的一份独立宣言。

通过在多模态智能体工作中匹配 Claude Sonnet 4.6，在视频理解中匹配 Gemini 3 Pro，小米证明了“闭门”实验室与开放研究之间的差距已经有效弥合。

以 MIT 许可为催化剂，以 100 万亿 token 额度为燃料，未来几个月可能会看到基于 MiMo 主干构建的专业智能体应用激增。

为了证实该项目雄心勃勃的发展轨迹，该团队指出他们已经在训练下一代，重点是“更深的推理”和“更丰富的现实基础”。目前，MiMo-V2.5 证明了在迈向功能性 AGI 的竞赛中，稀疏架构和宽松许可的力量。
