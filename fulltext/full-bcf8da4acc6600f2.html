Our code, data, and trained models are at https://peterwang512. github.io/TPIPS. 2 Related Works Perceptual similarity and preferences.Comparing two images is a fundamental problem in vision, with early approaches relying on hand-engineered, patch-based metrics [1, 6, 7]. With advances in deep image recognition [18, 19, 20, 21, 22, 23], learned deep features have been found to provide a more useful similarity signal than hand-engineered descriptors [ 2, 24, 25, 26, 27]. LPIPS [ 2], PieAPP [28], and DISTS [29] directly optimize deep features to align better with human judgments on low-level distortions. DreamSim [3] learns human perceptual judgments on synthesized images with high-level variations. Muttenthaler et al. [30] study perceptual judgments across object categories 2 with THINGS [ 11]. Other works improve metric robustness to spatial shifts [ 31], adversarial perturbations [32], and arbitrary transformations [33]. Alternative metrics isolate specific attributes like style [34, 35] or relationships between visual elements [ 36]. While these methods predict a single similarity score, similarity is inherently multi-f

aceted [4]. We address this by introducing a benchmark and model for human similarity judgements conditioned on various visual aspects. A separate but adjacent line of work uses pairwise human comparisons over generated or edited images to learn a scalar quality score over a single image [37, 38, 39, 40]. In contrast, we learn from triplet judgments to model pairwise similarity conditioned on visual aspects. Conditional representation.Various research has studied learning representations of an input conditioned on different aspects. A line of work explores learning conditional representation given an explicit aspect, but assumes a fixed, finite vocabulary of conditions [41, 42, 43, 44, 45]. More recent work generalizes the condition input to free-form text, including training-free methods via vision-language models [46, 47, 48] and training-based methods that curate conditional supervision. Text guidance proposal and refinement.For each generated triplet, we first construct a candidate set of prompts. During prompt-variation generation, we also prompt an LLM to identify the aspects of the images that are intended to change. If the images were fully described by the input text prompts, this would be sufficient. However, as the mapping between prompts and images is not one-to-one, images may vary from the prompt, or show additional unspecified properties. As such, 4 we pass the triplet and the candidate list to a VLM for refinement, removing unrelated ones and adding visually-varying factors that are not explicit in the prompts (e.g., pose or object size). The resulting aspect list is intentionally over-complete, and it is not guaranteed to be aligned with how humans describe (or attend to) differences in the triplet. We therefore treat these as proposals and prune. For each triplet, we ask 5 annotators for judgments. We provide an additional “can’t tell” option, and if marked by 3 or more users, we remove the attribute from the list. From the remaining triplets we remove the “can’t tell” votes and normalize to get probability distribution y= (y 1, y2, y3)∈∆ 3. To contextualize absolute agreement numbers, we computehuman consensus. It is defined as y2 1 +y 2 2 +y 2 3, the expected agreement within raters for each aspect condition, averaged over the test set. This human consensus reflects the best achievable agreement; we report it alongside all agreement numbers. Likewise, the 2AFC analogue is defined identically over two choices.
