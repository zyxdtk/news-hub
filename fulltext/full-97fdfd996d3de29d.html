摘要

自一致性是一种广泛使用的解码策略，用于改进思维链推理，但它需要在预设预算下采样大量完整的推理轨迹。其高效变体主要通过提前停止完整轨迹采样或在问题之间分配样本数量来降低成本。本文提出 StepBack，一种面向高效测试时推理的步骤级错误定位重采样方法。给定一小组草稿轨迹，StepBack 利用轻量级信号定位可能的首次错误位置，然后对检测到的错误步骤及其后缀进行重采样，随后进行多数答案投票。实验表明，StepBack 在七个数学推理和多跳问答基准上的平均准确率与 SC 相当，同时最多减少 41.26% 的 token 使用量。此外，StepBack 天然可与自适应推理方法（如自适应一致性）结合，进一步提升其推理时效率。

思维链提示通过鼓励语言模型在产生最终答案之前表述中间步骤，从而提高大语言模型（LLM）的推理能力。进一步提高准确率的一种广泛使用的方法是自一致性（SC），它采样多条“完整”的推理轨迹并选择最频繁出现的最终答案。尽管 SC 有效，但其计算成本高昂：每个额外的候选答案都需要从头开始生成完整的推理轨迹，因此 token 成本随采样轨迹数量和每条轨迹长度的增加而线性增长。

最近的研究试图通过调整完整轨迹的采样数量来降低这一成本。自适应一致性（AC）和早停自一致性（ESC）在观察到足够的答案一致性后停止采样；难度自适应自一致性（DSC）为更难的问题分配更大的预算；推理感知自一致性（RASC）利用理由特征使停止和投票更具选择性。这些方法改进了何时停止采样或采样多少轨迹的决策，但它们主要在完整轨迹的层面上操作。因此，它们留下了一个更细粒度的问题：在推理轨迹内部，应该在哪里高效地花费额外的采样？

这个问题很重要，因为推理失败通常出现在中间推理步骤，而不仅仅是在最终答案。一旦发生这样的错误，后续步骤可能依赖于被破坏的推理状态，导致错误传播并最终得到错误的最终答案，这一现象在先前关于思维链推理累积错误的工作中也有记载。同时，推理链的早期步骤包含有用的问题设置。这为高效测试时推理提供了一个合理的机会：如果可以定位可能的首次错误步骤，则可以保留有效的早期步骤，仅对错误步骤及其后续后缀进行重采样。

基于这一动机，我们提出 StepBack，一种用于高效自一致推理的步骤级错误定位重采样方法。StepBack 首先生成一小组草稿轨迹，并将每条轨迹分解为推理步骤。然后，它使用轻量级信号（如步骤级负对数似然）来定位可能的首次错误位置。对于每条定位后的轨迹，StepBack 复用检测到的错误之前的早期步骤，回溯到错误步骤，并对检测到的错误步骤及其后缀进行重采样。当未检测到显式错误时，StepBack 仅采样最终答案步骤。然后按照标准 SC 的方式，通过多数投票聚合得到的候选答案。这种方法显著减少了 token 使用量，同时平均匹配 SC 的准确率，如图 1 所示。我们工作的主要贡献是：

2 相关工作

高效自一致性。 最近的工作通过自适应控制完整轨迹的采样数量来降低自一致性成本。自适应一致性在答案一致性足够时停止；早停自一致性使用简单的基于窗口的停止规则；推理感知自一致性将理由质量特征纳入停止和投票；难度自适应自一致性为更难的问题分配更大的预算。这些方法通过决定生成多少轨迹来提高采样效率。相比之下，StepBack 解决的是在轨迹内部应该在哪里花费额外计算的问题。因此，StepBack 与自适应 SC 方法互补：它们减少消耗的候选数量，而 StepBack 减少每个候选的成本。

步骤级信号和回溯。 过程监督和步骤级验证表明，中间推理步骤携带有关解质量的有用信号。一旦早期步骤变得无效，错误往往会传播；早期前缀通常包含可复用的问题设置；当给定错误位置时，LLM 能更有效地纠正推理。几种方法根据这些信号采取行动，返回到较早的步骤并从那里重新生成：LeCo 在最低置信度步骤之后重新开始，直到两个连续的答案一致；Singh 等人（2025）在以先前尝试的修订为条件的步骤级验证器指导下进行回溯；自适应修正采样提示模型重新思考 PRM 分数低于阈值的步骤；思维回滚在分析错误后回滚到较早的思维；自我回溯训练模型本身决定何时何地回溯。在这些方法中，每次回滚取决于早期尝试的结果，因此修订是顺序运行的，其总成本不是预先固定的。StepBack 则使用轻量级信号（如负对数似然增加或过程奖励分数下降）为每个独立的草稿分配单个回滚点，因此所有后缀延续可以并行生成，并且候选答案的数量固定为 B = n_d·n_s，与完整轨迹自一致性相同的预算。每个额外的候选复用其草稿前缀，因此比完整轨迹花费更少的 token，并且 StepBack 不需要训练，并通过标准多数投票聚合答案。

3 预备知识和动机观察

3.1 步骤级推理轨迹

设 x 为输入问题，p_θ 为语言模型。我们将推理轨迹写为 τ = (z₁, z₂, …, z_T, z_{T+1})，(1) 其中 z₁, …, z_T 是中间推理步骤，z_{T+1} 是最终答案步骤。我们将提取的答案表示为 a(τ)。

我们的方法依赖于这样一个事实：经过指令微调的模型通常产生自然可分离的推理步骤。例如，Qwen2.5-3B-Instruct 在数学和多跳 QA 任务中通常用空行（即“\n\n”）分隔步骤。我们测试的其他模型显示类似的行分隔输出。

因此，我们使用空行边界将每条轨迹解析为步骤。模型输出示例和由此产生的步骤分解在附录 A 中提供。

3.2 准确错误定位的价值

对于错误的轨迹，设 e(τ) 表示推理首次变得无效的步骤位置。之前的推理步骤 z_{＜e(τ)} 保持有效，而后续步骤 z_{≥e(τ)} 可能被第一个错误破坏。

草稿-后缀重采样。 给定答案预算 B，我们考虑一个两阶段过程，该过程由下面的先知研究和我们的方法（第 4 节）共享。我们首先采样 n_d 条草稿轨迹 τ⁽¹⁾, …, τ⁽ⁿᵈ⁾。对于每条具有 T_j 个推理步骤的草稿 τ⁽ʲ⁾，我们选择一个回滚点 e_j ∈ {1, …, T_j+1}，保留前缀 z⁽ʲ⁾{＜e_j}，并抽取 n_s−1 个后缀 z̃⁽ʲ⁾{e_j:T_j+1} ~ p_θ(·|x, z⁽ʲ⁾_{＜e_j})。(2) 连同草稿自身的答案，这产生 B = n_d·n_s 个候选答案，像自一致性一样通过多数投票聚合。唯一的设计选择是如何选择 e_j。

先知回滚。 为了理解准确错误定位的价值，我们首先考虑一个先知设置，其中真实的首次错误位置 e(τ) 是已知的，并为每条草稿设置 e_j = e(τ⁽ʲ⁾)。我们从 LLM 验证器提示产生的首次错误标注中获得这些先知位置。我们手动检查了 100 个标注样本，未发现明显的误判；完整的标注协议和示例在附录 B 和附录 C 中提供。

对于没有标注首次错误的草稿，我们设置 e_j = T_j+1 并仅重采样最终步骤答案。

4 StepBack：步骤级错误定位重采样

第 3.2 节中的先知研究表明，当首次错误推理步骤已知时，定位重采样可以是有效的。然而，在实践中，真实的首次错误位置 e(τ) 在推理时是不可用的。StepBack 通过用从轻量级步骤级信号获得的预测回滚点替换 e(τ)，将这一先知诊断转化为实用的解码过程。

对于每条草稿 τ⁽ʲ⁾ = (z⁽ʲ⁾₁, …, z⁽ʲ⁾{T_j+1})，j = 1, …, n_d，StepBack 应用推理时定位规则 ê_j = Loc(x, τ⁽ʲ⁾) ∈ {1, …, T_j+1}。(3) 这里 ê_j ≤ T_j 意味着步骤 ê_j 被预测为第一个不可靠的推理步骤。然后 StepBack 保留早期步骤 (z⁽ʲ⁾₁, …, z⁽ʲ⁾{ê_j−1})，并对检测到的步骤及其后缀进行重采样。如果 ê_j = T_j+1，则未检测到显式推理错误，因此 StepBack 保留完整的推理链，仅重采样最终答案步骤，以简单地获得与 SC 相同数量的答案。得到的 B 个答案候选用与 SC 相同的归一化多数投票进行聚合。详情见算法 1。

4.1 推理时定位信号

我们在实验中用轻量级的推理时信号实例化 Loc，包括 NLL 信号和 PRM 信号。在本小节中，我们考虑单个草稿并省略上标⁽ʲ⁾，写作 τ = (z₁, …, z_{T+1})。

NLL 信号：步骤级负对数似然（NLL）增加

对于每个推理步骤 z_t，我们计算其在基础模型下的平均 token 负对数似然：

u_t = −(1/|z_t|) Σ_{y_i∈z_t} log p_θ(y_i|x, z_{＜t}, y_{＜i})。(4)

u_t 的突然增加表明模型在生成当前步骤时变得不那么自信。我们定义 Δ^NLL_t = u_t − u_{t−1}，(5) 并预测回滚点为 ê_NLL = min{t : Δ^NLL_t ≥ δ_NLL}（如果存在这样的步骤），否则为 T+1。(6)

回退位置 T+1 意味着未检测到显式推理错误。在这种情况下，StepBack 保持完整的推理链，仅重采样最终答案步骤。

PRM 信号：步骤级过程奖励模型（PRM）分数下降

我们还考虑外部过程奖励模型（PRM），表示为 R_φ。给定问题 x 和部分推理轨迹 z_{≤t}，PRM 分配一个分数 r_t = R_φ(x, z_{≤t})，(7) 该分数估计推理前缀的可靠性。添加步骤 z_t 后的大幅下降表明新步骤使推理变得不那么可靠。

我们定义 Δ^PRM_t = r_{t−1} − r_t，(8) 并预测回滚点为 ê_PRM = min{t : Δ^PRM_t ≥ δ_PRM}（如果存在这样的步骤），否则为 T+1。(9)

在我们的实验中，除非另有说明，我们使用 Qwen2.5-Math-PRM-7B 作为 PRM 评分器。

两种信号都很廉价。NLL 信号使用基础模型已可用的 token 概率，而 PRM 信号仅对部分推理轨迹评分，而不需要额外的完整轨迹采样。我们在附录 D 中提供详细的诊断。

4.2 与自一致性的比较

标准自一致性从 p_θ(·|x) 采样 B 条完整推理轨迹，并返回多数归一化答案。在相同的答案预算下，SC 将所有样本花费在独立的完整轨迹上，而 StepBack 将预算花费在修复或多样化一小组草稿锚点的不确定后缀上。这允许 StepBack 复用可靠的早期步骤，同时将额外的采样集中在更可能影响最终答案的步骤上，如图 2 所示。

5 实验

我们评估 StepBack 是否可以在固定的候选答案预算下超越或达到与完整轨迹自一致性相当的性能，同时降低生成成本。结果集中在预算 B = 32，并将回滚重采样与 Greedy@1 和 SC@32 进行比较。

5.1 实验设置

基准。 我们在 GSM8K、MATH500、AMC2023、AIME24 和 OlympiadBench 上评估数学推理，涵盖从小学算术到竞赛级数学的任务。我们进一步在 HotpotQA 和 2WikiMultiHopQA 上评估多跳问答，这些任务需要组合多个支持事实的证据。为了效率，我们从 7,405 个 HotpotQA 验证集示例中随机采样 500 个示例，从 12.6K 个 2WikiMultiHopQA 验证集示例中采样 1,000 个示例。

模型。 模型集包含 Qwen-2.5-3B-Instruct、Llama-3.2-3B-Instruct 和 Qwen-2.5-7B-Instruct。这些模型涵盖各种架构和规模，使我们能够测试错误定位的后缀重采样是否在单一骨干之外具有鲁棒性。

基线和变体。 主要基线是自一致性（SC），它独立采样 B = 32 条完整的思维链轨迹，并选择最频繁的归一化最终答案。我们还报告贪婪思维链解码，它生成一条确定性的推理轨迹，作为低成本参考点。在第 5.3 节中，我们还与自适应推理方法进行比较，包括自适应一致性（AC）、早停自一致性（ESC）和难度自适应自一致性（DSC）。它们的超参数详情可在附录 J 中找到。对于主要比较，StepBack 使用与 SC@32 相同的候选答案预算。我们考虑定位信号的两种轻量级变体：NLL 信号和 PRM 信号，两者都在第 4.1 节中描述。

除非另有说明，我们对 NLL 信号使用阈值 0.1，对 PRM 信号使用阈值 0.05，没有针对特定数据集进行调整。较低的阈值在步骤级信号的适度下降时触发回滚，因此更多的草稿从较早的步骤被重写；这有利于准确率而非 token 节省。这些阈值在所有数据集和模型之间共享；在训练问题上的留出校准（附录 F）表明，宽网格中的每个阈值都匹配或超过 SC@32 的平均准确率，同时节省 20–44% 的 token。

评估指标。 对于所有数据集，我们在答案提取和归一化后报告答案级准确率。对于数学推理，提取的答案在适用时使用精确或符号等价性与参考答案进行比较。对于多跳 QA，我们使用归一化精确匹配。在表 2 中，我们对每个模型-数据集对报告一次 SC@32 准确率，并报告 StepBack 相对于 SC 的准确率变化 ΔAcc = Acc(StepBack) − Acc(SC@32)，(10) 其中正值表示 StepBack 优于 SC。我们通过相对于 SC@32 的 token 节省来衡量生成效率，η = 100(1 − Tok/Q(StepBack)/Tok/Q(SC@32))，(11) 其中 Tok/Q 表示每个问题的平均生成 token 数。在表 3 中，我们进一步报告路径扩展（PExp），即每个问题采样的推理延续的平均数量，以及 G/1kT = 1000·(Acc(m) − Acc(CoT))/Tok/Q(m)，(12) 它衡量每 1k 生成 token 相对于贪婪 CoT 的准确率增益。较高的 η 和 G/1kT 表示更好的推理效率。

实现细节。 除非另有说明，我们使用温度 0.7 和 top-p 0.95 进行采样。所有实验都在配备两个 AMD EPYC 9005 系列 CPU 和 NVIDIA RTX PRO 6000 Blackwell 服务器版 GPU（每个 96 GB）的计算节点上运行；每次运行使用 4 个 GPU，CUDA 12.8，PyTorch 2.7.0 和 vLLM 0.9.2。

StepBack 以更少的生成 token 平均匹配 SC@32 准确率。 表 2 的 Avg. 行总结了所有 4,166 个问题的比较。使用 PRM 信号，StepBack 在 Llama-3B、Qwen-3B 和 Qwen-7B 上分别将平均准确率比 SC@32 提高 0.36、0.17 和 0.82 个百分点，同时生成 21.07%、18.66% 和 22.80% 更少的 token。使用 NLL 信号，它节省更多的 token，在两个 3B 模型上与 SC@32 的差异保持在 0.2 点以内（+0.12 和 −0.17），在 Qwen-7B 上比 SC@32 高 0.55 点。两种信号还提高了每个生成 token 获得的准确率：在 Llama-3B 上，G/1kT 从 SC@32 的 1.392 提高到使用 PRM 信号的 1.769 和使用 NLL 信号的 1.978。

在每个数据集上，PRM 信号在所有 21 个模型-数据集对中减少生成的 token（7.66–41.26%），在 14 个对中提高准确率，1 个持平，6 个较低。在 MATH500 上，它分别将 Qwen-3B、Llama-3B 和 Qwen-7B 提高 +0.40、+1.20 和 +2.00 点，同时分别节省 25.60%、20.81% 和 28.53% 的 token。值得注意的是，尽管 PRM 主要为数学过程监督而训练，但它也为逻辑和多跳推理提供了有用的步骤级可靠性估计：在 HotpotQA 上，PRM 信号将 Qwen-3B 和 Qwen-7B 分别提高 +1.20 和 +2.20 点，但将 Llama-3B 降低 2.00 点，这表明 PRM 信号可以捕获一些超出纯算术错误的推理质量下降，但不如在数学推理上可靠。

同时，NLL 信号提供了一种不需要外部模型的互补低成本定位信号：它在 21 个对中的 17 个上实现了比 PRM 信号更大的 token 节省，并在两个多跳 QA 数据集上提高了 Qwen-3B 和 Qwen-7B 的准确率。我们的解释是，NLL 信号往往不那么激进地定位错误，通常回滚到更接近最终答案的位置，因此重采样更短的后缀。这产生了更强的 token 节省，但与 PRM 信号相比，可能会留下更多早期的推理错误未被编辑。

定位开销相对于生成而言较小。 计算定位信号的额外成本与生成完整推理轨迹的成本相比仍然适中。表 2 中的相对定位开销 ρ₁₆，即 StepBack 花费在评分草稿上的 wall-clock 时间份额，在 Llama-3B、Qwen-3B 和 Qwen-7B 上，NLL 信号平均为 8.38%、9.52% 和 10.93%，PRM 信号为 7.48%、9.86% 和 6.98%。因此，StepBack 实现的 token 节省不会被大的评分成本所抵消。

StepBack 受益于可复用的早期推理步骤。 准确率的增益表明，许多错误的草稿轨迹并非完全无用，因为它们通常包含正确的早期步骤。StepBack 不是像 SC 那样丢弃这些步骤，而是保留每条草稿的可靠部分，仅从预测的错误区域重采样。这种设计在错误通常出现在后期推理阶段的数据集上特别有效，例如 GSM8K、MATH500 和 AMC2023，其中 PRM 信号在节省 10.83–41.26% 生成 token 的同时提高了所有三个模型的准确率。所有设置中一致的 token 减少进一步表明，定位重采样避免了大量冗余的早期步骤生成。

在更难数据集上的局限性。 在更难的竞赛风格基准（如 AIME24 和 OlympiadBench）上，增益不太稳定，特别是对于 Llama-3B。这表明某些失败无法通过仅重采样定位的后缀来纠正，因为它们可能需要修改早期的推理决策或探索截然不同的解决方案路径。

总体而言，这些结果支持 StepBack 的核心前提：在固定答案预算下，通过从定位的可能错误步骤重采样而不是从头重新生成每个候选，可以更高效地花费额外的测试时计算。

6 分析和讨论

不同的过程奖励模型大小。 附录 H 中的表 14 研究 StepBack 是否依赖大型 PRM 进行错误定位。我们将生成器固定为 Qwen2.5-3B，并在 MATH500 上评估，在相同的 B = 32 候选答案预算下比较 Skywork-o1-Open-PRM-Qwen-2.5-1.5B 与 Qwen2.5-Math-PRM-7B。

结果表明 StepBack 不需要比生成器更大的 PRM。使用 1.5B Skywork PRM，StepBack 在 8×4 设置下仍然优于 SC@32，准确率提高 +0.36 点，同时节省 23.8% 的生成 token，尽管在 16×2 时准确率比 SC@32 低 0.36 点。7B Qwen PRM 提供更强的定位，在 16×2 时实现 +0.72 点的更高准确率增益，但 1.5B PRM 已经以较低的评分开销（每个草稿样本 13.7ms vs. 19.7ms）保留了相当大一部分收益。

这表明关键要求不是 PRM 规模，而是定位信号是否有信息量。即使是轻量级信号，如 NLL 信号或较小的 PRM，当它们识别有用的回滚点时，也可以支持有效的后缀重采样。

草稿与后缀样本。 附录 H 中的表 12 研究如何在草稿锚点和后缀样本之间分配相同的候选预算 B = 32。后缀重的设置（如 1×32 和 2×16）节省最多的 token，2×16 在七个数据集中的三个上达到最高的 G/1kT，因为许多候选共享相同的短早期步骤。然而，它们在准确率上不太稳定，因为少量有缺陷的草稿前缀可能限制恢复。草稿重的设置（如 8×4 和 16×2）更鲁棒，因为它们提供更多样化的推理前缀。8×4 在所有五个数学基准上优于 SC@32，16×2 在 GSM8K、MATH500、AMC2023、AIME24 和 HotpotQA 上有所改善，并在 OlympiadBench 上匹配，同时仍然节省 token。这些表明 n_d 和 n_s 控制准确率-效率权衡：后缀重的设置更面向成本，而草稿重的设置更面向准确率。

替代回滚规则。 任何将草稿映射到回滚点的规则都可以作为算法 1 中的 Loc，包括无信号规则（如随机、固定位置和最终步骤回滚）以及来自先前回溯方法的基于 PRM 的规则。附录 G 将它们与固定的草稿、后缀重采样和多数投票进行比较。前缀复用和后缀重采样在任何规则下都产生大部分 token 节省，而晚期规则（如最终步骤重采样）是强效率基线；在 HotpotQA 上，最终步骤重采样比 PRM 信号更准确且更便宜。当后缀样本主导投票时，定位帮助最大：在 4×8 时，PRM 信号在所有七个数据集上比最终步骤重采样准确 2.06 点。

7 结论

我们提出了 StepBack，一种用于高效测试时推理的步骤级错误定位重采样方法。StepBack 不是从头重新生成每个候选，而是保留每条草稿的可靠前缀，并仅从轻量级 NLL 信号或 PRM 信号定位的可能首次错误处重采样。在七个数学推理和多跳问答基准和三个模型上，StepBack 在相同答案预算下匹配 SC@32 的平均准确率，同时生成最多 41.26% 更少的 token，并且它进一步降低了自适应方法（如 AC、ESC 和 DSC）的成本。

这些结果表明，在轨迹内花费测试时计算的位置是一个有用的效率轴，与决定采样多少轨迹互补。

8 局限性和更广泛的影响

局限性。 StepBack 有局限性，为未来的工作留下了空间。首先，我们关注两个代表性的定位信号，NLL 信号和 PRM 信号。尽管它们已经显示出明显的收益，但探索更广泛的更轻量级信号集可能进一步提高 StepBack 的效率。其次，我们的实验主要集中在数学推理和多跳问答上。虽然 StepBack 在这些设置中表现良好，但其对其他领域（如代码生成或长上下文摘要）的泛化能力仍有待进一步研究。

更广泛的影响。 更高效的推理可以以更低的成本获得更强的推理能力，这对科学和教育使用是一个积极的结果。同时，更便宜的推理也可以使有能力的系统更容易大规模部署。因此，我们认为高效推理的研究理想情况下应该既提高性能，又提高对收益来源的透明度。

附录 D 首次错误定位诊断

在本节中，我们评估轻量级信号是否可以近似第 3.2 节中使用的先知首次错误位置。对于每个错误的轨迹，我们有一个标注的首次错误位置 e。给定一个定位信号，我们预测一个首次错误位置 ê 并将其与 e 进行比较。我们还包含一个基线 Random，它从轨迹中可用的推理步骤中随机采样一个回滚位置。该基线测试基于信号的方法是否比不使用轨迹任何信息选择重采样点做得更好。

对于每个具有标注首次错误位置 e 的轨迹，我们使用以下四个指标评估预测位置 ê。

I. Exact。 Exact 衡量预测位置是否与标注的首次错误步骤完全匹配：ê = e。(13)

II. Prev-1。 Prev-1 衡量预测位置是标注的首次错误步骤还是紧邻的前一步骤：ê ∈ {max(1, e−1), e}。(14) 此指标捕获预测的重采样点是否足够接近以覆盖第一个错误，同时避免在已经正确的早期推理步骤上浪费大量计算。当 ê = e 时，重采样恰好从第一个错误开始；当 ê = e−1 时，仅重采样一个额外的有效步骤。

III. Not-Later。 Not-Later 衡量预测位置是否在首次错误之前或恰好位于首次错误处：ê ≤ e。(15) 此指标很重要，因为从真实首次错误之前或处的位置重采样会将错误步骤包含在重采样的后缀中。然而，它应该与错误前距离一起解释：非常早期的预测可以满足 Not-Later，但通过重采样许多已经正确的早期推理步骤而浪费计算。因此，我们还引入以下指标。

IV. Mean Pre-Error Distance。 平均错误前距离衡量预测位置在标注首次错误步骤之前多远，仅计算在真实首次错误之前或处出现的预测：对于 ê ≤ e 的轨迹，e − ê。(16) 较低的值表明预测的重采样点更接近第一个错误，同时仍然覆盖它。此指标将有用的早期定位与过于保守（即太晚）的预测区分开来，后者重新启动太多推理轨迹。

附录 G 与替代回滚规则的比较

StepBack 的框架不固定如何选择回滚点。对于给定的分配 (n_d, n_s)，草稿、后缀重采样和多数投票在规则之间是一致的，只有第 4 节的定位规则 Loc 发生变化。这使我们能够将定位的效果与前缀复用和后缀重采样的效果分开。本节中的所有结果使用 Qwen-3B、第 5.1 节的采样设置和每个问题 B = 32 个答案。

无信号规则。 这些规则忽略草稿的内容。Random 回滚到从草稿推理步骤中均匀随机抽取的步骤，如表 5 所示。Fixed-q 回滚到草稿推理步骤的固定比例 q ∈ {25%, 50%, 75%} 处的步骤。Final-step 对每条草稿设置 ê_j = T_j+1：它保留整个推理链并仅重采样最终答案步骤。这也是 NLL 信号和 PRM 信号在没有步骤超过阈值时的回退，因此两种信号都随着 δ 增长而接近 Final-step。

受先前回溯方法启发的规则。 几种测试时方法从被标记为错误的步骤修改推理轨迹。我们仅保留它们选择该步骤的规则，用与 PRM 信号相同的 PRM（Qwen2.5-Math-PRM-7B）计算它，并保持 StepBack 的其余部分不变。

  • Min-advantage 受 Singh 等人 [2025] 启发。原始方法基于过程验证器预测的变化识别回溯点，并使用以先前尝试为条件的验证器执行多轮修订。我们的版本回滚到具有最负优势 r_t − r_{t−1} 的步骤，即 ê_j = argmax_t Δ^PRM_t。与 PRM 信号不同，它在每条草稿中都回滚，无论最大的下降有多小。
  • Absolute-PRM 受 AR-Sampling [Tan 等， 2025] 启发。AR-Sampling 在生成过程中用 PRM 对每个步骤评分。当分数低于固定阈值时，它保留该步骤并附加一个触发句子，要求模型从该步骤重新思考。我们的版本回滚到 PRM 分数低于 0.8 的第一个步骤，即 ê_j = min{t : r_t ＜ 0.8}，否则回退到 T_j+1。它用绝对分数阈值替换 PRM 信号的相对分数下降。

最终投票解释了这一趋势。每条草稿贡献其原始答案和来自重写后缀的 n_s−1 个答案。因此，原始草稿答案贡献 32 票中的 n_d 票，重写答案贡献其余的 n_d(n_s−1) 票。定位仅改变重写的答案。设 V_D、V_R 和 V_full 分别表示草稿答案、重写答案和所有 32 个答案中最频繁的答案（众数，不需要占多数）。当 V_D ≠ V_R 时，我们将该问题称为冲突。在 4,166 个问题中，使用 PRM 信号的 StepBack 在 4×8、8×4 和 16×2 时分别有 1,098、853 和 756 个冲突（表 11）。最终答案 V_full 在这些冲突中分别有 89.34%、74.33% 和 48.02% 匹配 V_R。它分别有 6.92%、19.58% 和 43.39% 匹配 V_D。在其余冲突中，最终答案与两者都不匹配。当重写贡献 32 票中的 28 票时，它们的最频繁答案几乎赢得所有冲突。当草稿和重写各贡献 16 票时，这一份额下降到大约一半。基于这些观察，我们可以得出结论：定位决定后缀重写从哪里开始，而分配决定重写答案对最终投票的影响程度。

总结。 在 StepBack 中，回滚规则设定了准确率-效率权衡，而不是有单一的最佳选择。无信号的晚期回滚，尤其是 Final-step，给出了最大的节省，并且在 HotpotQA 上是最准确的规则。定位信号给出了最高的汇总准确率，并且使用 7B PRM 时，给出了最高的 MATH500 准确率，它们的好处 在重写后缀主导投票时最大。阈值 δ 沿着这一权衡移动每个信号，从早期回滚向 Final-step 回退移动。
