Anthropic称80倍狂飙后收入年化率达...

📅 2026-05-09 📄 VentureBeat AI 🔗 原文链接

原标题：Anthropic says it hit a $30 billion revenue run rate after 'crazy' 80x growth

中文摘要： Anthropic CEO透露，公司年化收入运行率已达300亿美元，年化增长率高达80倍，远超预期。其AI编程工具Claude Code成为企业软件史上增长最快的产品，甚至推动了公司内部工程产出的飞轮效应。然而，超高速增长引发了严重的算力危机，迫使Anthropic与马斯克的SpaceX达成合作以解燃眉之急。目前公司估值逼近万亿美元，计划最早于10月IPO。Amodei坦言80倍增长是紧急状态，需尽快让基础设施跟上需求步伐。

[Dario Amodei](https://www.darioamodei.com/) 不是那种对数字口无遮拦的CEO。作为 Anthropic 的联合创始人兼首席执行官、OpenAI 前研究副总裁以及普林斯顿大学计算神经科学博士，他以公开声明的严谨克制而闻名——尤其是在一家直到最近对其业务几乎只字不提的公司的财务表现方面。

因此，当 Amodei 周三在 Anthropic 的 [Code with Claude](https://claude.com/code-with-claude) 开发者大会上登台，并展现出真正令人瞩目的财务坦诚时，全场都竖起了耳朵。

“我们曾试图为每年10倍增长的世界做好规划，”Amodei 在与 Anthropic 首席产品官 Ami Vora 的炉边谈话中说。“然而我们看到了80倍的增长。这就是我们在算力方面遇到困难的原因。”

Anthropic 原本计划的是十倍增长。但在年化基础上，第一季度的收入和使用量增长了80倍，Amodei 将这一速度描述为“简直疯狂”且“难以应对”。

这个数字需要结合背景来看。年化增长率可能会夸大持续表现——将单个强劲季度的表现推算至全年，可能会描绘出一幅站不住脚的图景。Amodei 明白这一点。但潜在的增长轨迹并非海市蜃楼。Anthropic 已经突破了 [300亿美元的年化收入运行率](https://www.bloomberg.com/news/articles/2026-04-06/broadcom-confirms-deal-to-ship-google-tpu-chips-to-anthropic)，比2025年底的约90亿美元大幅跃升，且这一增长主要由企业需求驱动。该公司的收入轨迹可谓势如破竹：[2024年1月运行率为8700万美元](https://www.saastr.com/anthropic-just-passed-openai-in-revenue-while-spending-4x-less-to-train-their-models/)，2024年12月达到10亿美元，[2025年底达到90亿美元](https://www.reuters.com/business/retail-consumer/anthropic-aims-nearly-triple-annualized-revenue-2026-sources-say-2025-10-15/)，2026年2月达到140亿美元，3月达到190亿美元，4月达到300亿美元。

作为参考：Salesforce 花了大约20年才达到300亿美元的年收入。而 Anthropic 从零开始，在不到三年的时间里就做到了。

Anthropic 的年化收入运行率从2024年1月的8700万美元飙升至2026年4月的300亿美元——CEO Dario Amodei 表示，这一速度超出了公司自身预测的八倍。注：运行率数据为年化快照，非全年GAAP收入。使用对数刻度。（图片来源：Michael Nunez / VentureBeat）

## **Claude Code 成为企业软件史上增长最快的产品**

在很大程度上，Anthropic 的增长故事是一个单一产品的故事。[Claude Code](https://www.anthropic.com/product/claude-code) 是该公司于2025年中公开发布的代理式AI编程工具，它已成为公司历史上增长最快的产品——而且从多个指标来看，它也是有史以来增长最快的软件产品之一。

Claude Code 在发布后六个月内就达到了 [10亿美元的年化收入](https://www.anthropic.com/news/anthropic-acquires-bun-as-claude-code-reaches-usd1b-milestone)，并且增长并未放缓。到2026年2月，该产品创造了 [超过25亿美元的运行率收入](https://news.ycombinator.com/item?id=46997292)。该公司还表示，自1月1日以来，Claude Code 的周活跃用户翻了一番，企业订阅量自2026年初以来增长了四倍。

该产品的运作机制很简单。Claude Code 不是那种建议代码片段的聊天机器人。它能读取代码库，规划一系列操作，使用真实的开发工具执行它们，评估结果，并调整其方法。开发者设定目标并保留对提交内容的控制权，但执行循环是独立运行的。使用 [Claude Code](https://code.claude.com/docs/en/overview) 的普通开发者现在每周要花20小时使用该工具。

在 Anthropic 内部，现在大部分代码都是由 Claude Code 编写的。工程师们专注于架构、产品思考和持续编排：并行管理多个代理，给出方向，并做出决定构建内容的决策。

最后一点可能是 Amodei 在大会上披露的最具启发性的细节：这是 Anthropic 自己内部的拉取请求（pull requests）首次因为 Claude 在公司自有代码库上的工作而出现向上拐点。Anthropic 卖给开发者的工具现在已成为 Anthropic 自身工程产出的重要贡献者。这创造了一个反馈循环，对于没有类似产品的竞争对手来说几乎是不可能复制的——该公司正在使用自己的产品来构建自己产品的下一个版本。

企业端的数据也讲述了同样的故事。该公司目前拥有超过1000家每年在 Claude 服务上花费超过100万美元的企业客户，这一数字自2月以来已经翻了一番。这种增长很大程度上是由包括 Uber 和 Netflix 在内的一波企业客户推动的。

Amodei 用经济学术语来构建这种采用曲线。“软件工程师是采用新技术最快的人群，”他在台上说。“这预示着整个经济运作的方式，以及经济将如何被 AI 改变。”

## **Anthropic 80倍的增长引发了其无法独自解决的算力危机**

超高速增长带来了它独有的问题。当需求以数量级超过供应时，限制因素就不是走向市场战略或产品市场契合度了。限制因素是物理规律。

公司的快速增长导致其基础设施难以跟上，迫使 Anthropic 达成了当前 AI 周期中最出人意料的合作。就在 Amodei 发表上述言论的几个小时前，[Anthropic 宣布与 Elon Musk 的 SpaceX 达成协议](https://www.cnbc.com/2026/05/06/anthropic-spacex-data-center-capacity.html)，使用其公司位于田纳西州孟菲斯的 Colossus 1 数据中心的全部算力。作为协议的一部分，Anthropic 将获得超过 [300兆瓦的容量](https://www.wsj.com/tech/ai/anthropic-inks-deal-to-use-all-of-spacexs-colossus-1-compute-capacity-56a7e2a1)——超过22万块 Nvidia GPU，包括 H100、H200 和下一代 GB200 加速器的密集部署。

这笔交易之所以引人注目有几个原因。直到最近，Musk 还是 Anthropic 最激烈的批评者之一。他曾说 Anthropic “[注定会走向其名字的反面](https://x.com/elonmusk/status/1803783427616821401?lang=en)”，并在2月份写道“[Anthropic 仇恨西方文明](https://x.com/elonmusk/status/2027294561467613256)”。但在周三，Musk 改变了口风，他说过去一周他与 Anthropic 团队的高级成员共度了很多时间，并且他“[印象深刻](https://x.com/elonmusk/status/2052069691372478511)”。Musk 写道：“我遇到的每个人都非常有能力，并且非常在乎做正确的事。没有人的邪恶探测器警报响起。”

双方的战略逻辑很清晰。xAI 的 Colossus 1 最终拥有的容量是 Grok 用户群从未达到的，而 Anthropic 则急需算力。Anthropic 一直在与亚马逊、谷歌、Nvidia 和微软签署获取更多算力的协议，但其中大部分预计要到2026年底或2027年初才能上线。与 SpaceX 的交易让 Anthropic 在当下获得了显著提升——关键词是“当下”。

正如一位行业观察家对这种结盟的总结：“[Elon 的敌人是 Sam。Dario 的敌人是 Sam。敌人的敌人就是算力合作伙伴](https://x.com/benitoz/status/2052061969969238317)。”

上个月，Anthropic 表示对 Claude 的需求导致了“我们基础设施不可避免的压力”，这影响了用户的“可靠性和性能”，尤其是在高峰时段。该公司在4月底的复盘文章中承认，自3月4日以来有三个 Bug 影响了 Claude Code，而内部测试没有发现它们，导致性能下降数周。Amodei 在 Code with Claude 大会上表示，公司正在“尽可能快地提供更多”容量，并将“尽快将这些算力交给大家”。

## **近万亿美元的估值使 Anthropic 的 IPO 成为多年来最受期待的上市**

这些增长数据出现之际，Anthropic 的估值本身正成为 AI 时代最具决定性的财经故事之一。

据知情人士透露，Anthropic 已开始考虑新一轮融资，对该公司的估值将超过 [9000亿美元](https://www.reuters.com/business/retail-consumer/anthropic-weighs-new-funding-round-valuation-exceeding-900-billion-bloomberg-2026-04-29/)，可能会超越其长期竞争对手 OpenAI，成为全球最有价值的 AI 初创公司。这种攀升速度再怎么夸张也不为过。从2025年3月的615亿美元，到9月F轮融资时的1830亿美元，到2月的3800亿美元，再到如果当前讨论顺利进行的话，5月份将超过9000亿美元。本月早些时候，Anthropic 的股票在二级市场上的交易价格已隐含了1万亿美元的估值。

许多现有投资者并没有套现，而是在等待可能于今年晚些时候 Anthropic 预期的 IPO 期间退出。该公司正在筹集可能是上市前的最后一轮私募资金，以满足其庞大的算力需求。彭博社报道称，[该公司正在考虑最早于2026年10月进行 IPO](https://www.bloomberg.com/news/articles/2026-04-29/anthropic-considering-funding-offers-at-over-900-billion-value)，高盛、摩根大通和摩根士丹利已在进行初步讨论。

Anthropic 也在更长的时间跨度上建设基础设施。亚马逊已同意 [向 Anthropic 投资高达250亿美元](https://www.cnbc.com/2026/04/20/amazon-invest-up-to-25-billion-in-anthropic-part-of-ai-infrastructure.html)，为其训练和部署 Claude 模型确保高达5吉瓦的算力。作为与 [谷歌和 Broadcom 另一项交易](https://www.anthropic.com/news/google-broadcom-partnership-compute) 的一部分，Anthropic 还获得了5吉瓦的算力，该算力将于明年开始上线。总承诺额令人惊叹——横跨三个独立硬件生态系统的数十吉瓦算力：亚马逊的 Trainium 芯片、通过 Broadcom 提供的谷歌 TPU，以及通过 SpaceX 和 Microsoft Azure 提供的 Nvidia GPU。

从宏观角度来看：Anthropic 300亿美元的运行率超过了标准普尔500指数中除约130家公司之外所有公司的过去十二个月收入。一家在2024年初基本上还没有收入的公司，现在的收入超过了财富500强中的大多数。

![图片 2: anthropic 标普500收入排名图表](https://venturebeat.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fjdtwqhzvc2n1%2F31QhvuBeQaour0HnvD8fCd%2F99db99e972eb35fbeca1a6a086376c44%2Fanthropic_sp500_revenue_rank_graph.png%3Fw%3D1000%26q%3D100&w=3840&q=75)

按照300亿美元的年化运行率，Anthropic 的收入将超过大约四分之三的标普500家公司——对于一家在2024年初基本处于收入前阶段的公司来说，这是一个惊人的里程碑。注：Anthropic 的数据为年化运行率，非过去十二个月GAAP收入。（图片来源：Michael Nunez / VentureBeat）

这种比较是有附加说明的。私募市场的收入运行率与经过审计的 GAAP 收入、毛利率、自由现金流或公众流通股不是一回事。OpenAI 内部曾争辩说，Anthropic 300亿美元的数据 [被夸大了约80亿美元](https://thenextweb.com/news/openai-852-billion-valuation-investor-scrutiny-anthropic-revenue)，指出来自 AWS 和 Google Cloud 的收入是应该按总值还是扣除合作伙伴分成后的净值报告存在疑问。这个会计问题最终将在两家公司提交 IPO 招股说明书时得到解决——但即使按净值计算，Anthropic 的增长率在企业软件历史上也是史无前例的。

## **Dario Amodei 对 AI 的愿景远不止于编程——他给自己定下了最后期限**

这个财经故事——80倍的增长、近万亿美元的估值、为满足需求而争相确保足够的 GPU——本身就极具戏剧性。但 Amodei 利用他在台上的时间，将其纳入了关于 AI 发展方向的更大主题中。

他描述了一个从单一代理到多个代理，再到他所谓的整个组织智能的演进过程——从“房间里的一个聪明人团队”到“数据中心里的天才之国”。这种框架是刻意宏大的。Anthropic 今天卖的是编程工具。而 Amodei 描述的是这样一个未来：整个类别的知识工作由并行操作的 AI 代理群完成，由定义目标和审查输出的人类进行监督。

他重申了大约一年前做出的预测：2026年将出现第一家完全由单人运营的十亿美元公司。“还没有完全发生，”他说。“但我们还有七个月的时间。”

该公司也一直在应对政治逆风。[五角大楼在3月份宣布 Anthropic 为供应链风险](https://www.npr.org/2026/03/06/g-s1-112713/pentagon-labels-ai-company-anthropic-a-supply-chain-risk)，将其列入与军方合作黑名单。该公司曾警告，这一认定可能导致数十亿美元的收入损失，据报道有一百多家企业客户对是否继续合作关系表示怀疑。

然而——随着那场冲突在法律系统中推进，Anthropic 反而越来越受欢迎。Amodei 本周表示，他最终希望实现“更正常”的扩张。

在报道一家以这种速度增长的公司时，人们会有一种让数字自己说话的诱惑。但不应如此。80倍的年化增长不是一个商业计划——而是一场紧急状态。这意味着需求已经超过了基础设施，客户想要的东西该公司还无法大规模可靠地交付，而容量受限的每一周都是竞争对手缩小差距的一周。

为 Anthropic 提供资金的投资者——包括 [SoftBank](https://www.softbank.jp/en//)、[Amazon](https://www.amazon.com/)、[Nvidia](https://www.nvidia.com/en-us/)、[Google](https://www.google.com/)、[a16z](https://a16z.com/)、[Lightspeed](https://www.lightspeedhq.com/home/) 和 [ICONIQ](https://www.iconiq.com/)——正在下一个具体的赌注：单位智能的算力成本继续下降，收入继续以快于消耗的速度复合，且无论谁在2029年拥有 AI 基础设施层，都将产生让中期损失变得微不足道的回报。

Amodei 在 [Code with Claude](https://claude.com/code-with-claude/san-francisco) 上的坦诚并不是一场胜利巡游。它是一次诊断——承认他的公司跑得太快以至于难以驾驭。他为一个10倍增长的世界做了计划，却迎来了80倍的增长。现在他有七个月的时间来证明基础设施、组织和愿景能够赶上需求。数据中心里的天才之国正变得拥挤。问题是，是否有人记得建造足够的房间。
