OpenAI终于合并ChatGPT的聊天与工作标签

📅 2026-11-02 📄 TechCrunch AI 🔗 原文链接

原标题：OpenAI is finally merging ChatGPT’s Chat and Work tabs

中文摘要： OpenAI 宣布将合并 ChatGPT 的 Chat 和 Work 标签页，用户可在一个界面内从探索想法到让 ChatGPT 执行任务，包括导入文件和插件、构建网站、创建演示文稿，并审查和指导其工作。该功能将先向部分用户开放收集反馈，再广泛推出。合并后 ChatGPT 和 Codex 将共享同一 token 配额池，部分用户或需更频繁等待配额重置，Codex 仍保持独立体验。竞争对手 Anthropic 已于 9 月合并 Claude 的聊天与 Cowork 功能。

OpenAI 终于要合并 ChatGPT 的 Chat 和 Work 标签页了

ChatGPT 桌面应用可能会让人感到困惑：它分为 ChatGPT 和 Codex 两个板块，而在前者之中，又有 Chat 和 Work 两个标签页。选项如此之多，有时很容易忘记自己正在哪里工作，以及你的项目究竟在哪里。

根据发给用户的一封邮件，OpenAI 显然是为了解决这一问题，目前正准备将 ChatGPT 体验中的 Chat 和 Work 标签页合并。OpenAI 表示，这一体验最初将向部分选定用户开放以收集反馈，之后才会广泛推出。

邮件中写道："这将使你能够从一个想法的探索开始，到让 ChatGPT 将其付诸实现，全部在一个地方完成。你可以导入你的文件和插件，让 ChatGPT 构建网站、创建演示文稿，或在网络上为你办事，同时审查和指导它的工作。Codex 在 ChatGPT 桌面应用中仍将保持独立的体验。"

OpenAI 还表示，随着这一转变，ChatGPT 和 Codex 将从同一个配额池中提取 token。该公司称这一变化不会影响大多数用户，但根据使用量和所用模型的不同，部分用户可能需要更频繁地等待配额重置。

竞争对手 Anthropic 已于 9 月将 Claude 的聊天和 Cowork 功能合并到了同一个界面。
