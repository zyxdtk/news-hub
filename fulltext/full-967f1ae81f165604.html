摘要
产品捆绑通过推荐互补商品组合提升电商收入。然而，现有方法面临两个关键挑战：（1）协同过滤方法因依赖历史交互而难以处理冷启动商品；（2）大语言模型（LLM）缺乏直接建模交互图的能力。为弥合这一差距，我们提出一种双增强方法，融合交互图学习与基于LLM的语义理解用于产品捆绑。该方法引入图到文本范式，利用动态概念绑定机制（DCBM）将图结构转化为自然语言提示。DCBM在对齐领域特定实体与LLM分词方面起关键作用，实现对组合约束的有效理解。在三个基准数据集（POG、POG_dense、Steam）上的实验表明，相较于最先进基线，性能提升6.3%–26.5%。

引言
图1：
产品捆绑示例。
产品捆绑基于用户偏好和产品信息，战略性地组合互补商品，以提升购买意愿和效率（Sun等，2024a）。与传统的顺序推荐不同，产品捆绑任务创建协同解决方案。例如，汉堡与薯条和冷饮的捆绑不仅提供令人满意的餐食组合，而且相比单独购买，成本更低，如图1所示。互补价值使捆绑推荐比单个商品推荐更具吸引力。

尽管协同过滤（CF）方法在推荐系统中广泛应用并表现出有效性（Ma等，2024b），但在处理冷启动商品时仍面临显著挑战：新引入且缺乏已建立交互模式的产品，如图2所示。这一局限性尤为明显，因为CF方法的性能严重依赖于历史交互数据（Jeon等，2024）。

近期大语言模型（LLM）的突破揭示了其在语义理解和跨域知识迁移方面的卓越能力。鉴于此，近期尝试利用LLM增强基于CF的捆绑构建方法（Liu等，2025）。然而，LLM主要处理文本语义和通用领域知识，本质上缺乏理解产品捆绑任务中图结构信息的能力。

图2：
不同方法在产品捆绑任务中的示意图。
为弥合这一差距，我们提出一种基于交互图学习和LLM的产品捆绑双增强方法。通过利用LLM丰富的语义理解和推理能力，旨在提升关系建模的整体有效性。具体而言，所提出的方法是一种针对大语言模型的两阶段微调方案。第一阶段，我们使用动态概念绑定机制，将商品文本描述映射到领域特定词汇，从而弥合LLM预训练知识与产品领域概念之间的差距。进一步，我们引入一种新颖的图到文本范式，将交互信息转换为结构化文本描述。第二阶段专注于产品捆绑任务优化，其中LightGCN特征被整合到商品表示中，作为大语言模型的输入嵌入（He等，2020）。

我们总结本工作的主要贡献如下：
• 双增强框架：我们提出一种新颖的双增强框架，采用两阶段微调。
• 动态概念绑定机制：一种创新的适配方法，实现LLM世界知识与精确商品实体绑定的同时保留。
• 图到文本原生建模：一种图感知的转换范式，将用户-商品交互转换为文本描述，有效缓解跨模态对齐中的信息损失。

2
相关工作
在捆绑推荐领域，多种方法利用预训练的CF模型捕捉用户-捆绑交互。Ma等（2024c）提出一种框架，结合预训练CF模型与内容编码器，有效解决用户-捆绑交互的稀疏性问题。Chen等（2019a）引入基于注意力的方法，聚合商品嵌入以表示捆绑。Li等（2023）将捆绑推荐形式化为图上的链接预测任务，设计紧凑的谱图滤波器以捕捉用户-捆绑和捆绑-商品关系。Chang等（2020）提出一种异构图框架，统一商品和捆绑层面的关系，通过硬负采样进行嵌入传播和用户偏好探索。

2.1 产品捆绑中的图卷积网络
近年来，图卷积网络（GCNs）发展迅速，展现出强大的关系建模能力。近期研究持续探索GCN的潜力，涌现出各种改进和优化模型。在众多GCN变体中，LightGCN因其独特优势脱颖而出，已成为关系建模的主流方法（He等，2020）。LightGCN的模型结构能够有效捕捉高阶连接信息，并在处理复杂图结构数据方面表现出色。这一特性使其在Nguyen等（2024）；Ma等（2022）；Jeon等（2024）；Du等（2023）；Ma等（2024a）等研究和应用中被广泛采用。

2.2 捆绑构建中的LLM
近期，随着计算能力和数据资源的不断增加，LLM的发展取得了显著突破。LLM的进步激发了其在产品捆绑领域潜在应用的探索。众所周知，传统产品捆绑框架通常依赖于用户的历史行为数据和人工整理的捆绑，缺乏对单个商品及其相互关系的深入理解。LLM的出现为解决这些局限性提供了新颖且强大的方案（Sun等，2024b；Liu等，2025；Avny Brosh等，2022）。通过将LLM与产品捆绑领域结合，我们可以利用其能力分析商品描述和用户-商品交互，从而更准确地捕捉用户兴趣和需求，实现个性化和精准的产品捆绑。

3.1 第一阶段：交互知识增强
在此阶段，我们将图转换为自然语言知识以微调LLM，旨在在执行产品捆绑任务前增强LLM的适应性。

3.1.1 动态概念绑定机制
图4：
动态概念绑定机制示意图。
对于商品表示，我们提出的DCBM创建领域特定的分词概念，其中每个商品作为附加token添加到LLM的词汇表中。如图4所示，我们将这些商品与商品的文本描述对齐，以解决LLM预训练获得的世界知识与推荐系统中领域特定商品知识之间的词汇差距。该方法有效解决复合术语中的语义模糊，防止概念混淆。

我们利用商品描述初始化这些商品节点 Eᵢ ∈ ℝᵈ。如公式1所示，商品描述将被分词。
Tokensᵢ = LLM_Tokenizer(despᵢ),
(1)
其中 Tokensᵢ 是商品i描述的token ID，despᵢ 是商品i的文本描述，LLM_Tokenizer(⋅) 表示将描述字符串分割为K个子词token字符串的LLM分词器。然后，我们可以根据公式2获得商品i的嵌入 Eᵢ。
Eᵢ = (1/K) ∑_{k=1}^K LLM_Embedding(Tokensᵢ^(k)),
(2)
其中 LLM_Embedding(⋅) 表示LLM的嵌入层。在获得 Eᵢ 后，我们设计如图3所示的交互增强提示模板。
这里，商品ID对应一个附加token，带有可学习的节点 Eᵢ，而商品描述包含实际的文本描述，如图4所示。该机制通过公式3进行优化。
ℒ_DCBM = -∑_{i=1}^N log P(Despᵢ | Itemᵢ; θ),
(3)
其中 θ 表示LLM的LoRA参数。目标是最小化模型在给定商品节点时生成文本描述的负对数似然，从而有效对齐节点与商品的文本信息。

3.1.2 图到文本原生建模
基于DCBM，我们通过提出的图到文本原生建模方法，分别将用户-商品和捆绑-商品图转换为问答对，使LLM能够理解复杂关系。该方法充分利用LLM原生的文本理解能力，增强结构化关系的语义建模，有效缓解跨模态特征增强中的信息损失。

为建模用户-商品交互，我们定义增强目标为：
ℒ_user = -∑_{u∈𝒰} log P(Sᵤ∖ℋᵤ | ℋᵤ; θ),
(4)
其中 𝒰 表示用户集合，Sᵤ = {i | (u,i) ∈ ℰᵤ} 表示用户u的完整交互商品序列。令 ℋᵤ ⊆ Sᵤ 表示从Sᵤ中采样的部分交互序列，代表用户u的观测历史。条件概率 P(Sᵤ∖ℋᵤ | ℋᵤ; θ) 建模用户未来交互（即 Sᵤ∖ℋᵤ）在观测历史 ℋᵤ 下的可能性，其中 θ 表示模型参数。我们设计用户-商品关系增强模板以提示LLM，如图3所示。

遵循相同原则，我们制定捆绑-商品关系增强目标为：
ℒ_bundle = -∑_{b∈ℬ} log P(b ∈ ℬ* | 𝒞(b); θ),
(5)
其中 ℬ* 表示真实捆绑集合，𝒞(b) 表示捆绑构建的候选商品集合，条件概率 P(b ∈ ℬ* | 𝒞(b); θ) 衡量候选商品集合 𝒞(b) 形成有效捆绑的可能性。
我们设计捆绑-商品关系增强模板，如图3所示。

3.2 第二阶段：图结构特征与语义融合增强
第二阶段专注于跨模态特征融合。在此，我们预处理训练数据，将产品捆绑作为指令微调的文本生成任务。对于结构特征，我们采用注意力投影器，在潜在空间中对齐LightGCN特征与LLM文本表示，在保留原始图建模优势的同时，通过这种轻量级设计增强语义理解。

3.2.1 融合方法
为整合LightGCN特征与LLM语义，我们采用交叉注意力机制融合商品表示 𝐈_b 和 𝐈_u 与文本嵌入。
首先，我们通过两层MLP将两个商品表示映射到文本嵌入维度：
𝐈_multi = [𝐈_b ∥ 𝐈_u] ∈ ℝ^{B×M×2d},
(6)
𝐈_mapped = GELU(𝐈_multi 𝐖₁ + 𝐛₁) 𝐖₂ + 𝐛₂,
(7)
其中 𝐖₁ ∈ ℝ^{2d×d_hidden}, 𝐖₂ ∈ ℝ^{d_hidden×d_h}, 𝐛₁ ∈ ℝ^{d_hidden}, 𝐛₂ ∈ ℝ^{d_h} 是可学习参数。
对于交叉注意力机制，我们直接从查询、键和值矩阵计算注意力输出：
𝐐 = 𝐓𝐖_q, 𝐊 = 𝐈_mapped 𝐖_k, 𝐕 = 𝐈_mapped 𝐖_v,
(8)
𝐀_output = softmax(𝐐𝐊ᵀ / √d_h) 𝐕 ∈ ℝ^{B×T×d_h},
(9)
其中 𝐖_q, 𝐖_k, 𝐖_v ∈ ℝ^{d_h×d_h} 是可学习投影矩阵。
最后，通过投影、残差连接和层归一化获得融合表示：
𝐈_fusion = LayerNorm(𝐓 + 𝐀_output 𝐖_out),
(10)
其中 𝐖_out ∈ ℝ^{d_h×d_h} 是可学习输出投影矩阵。

3.2.2 产品捆绑任务微调
在此阶段，我们在LLM上进行监督微调以优化产品捆绑。我们构建一个专用微调数据集，其中前一阶段交叉注意力机制的融合表示 𝐈_fusion 作为输入特征，引导模型理解商品关系和捆绑组成模式。
训练数据被形式化为多项选择问答任务，每个实例包含一个部分指定的捆绑和一组候选商品。具体而言，给定目标捆绑 ℬ = {i₁, i₂, ..., i_k}，我们通过掩码一个商品 i_j ∈ ℬ 并将剩余商品 ℬ_{-j} = ℬ ∖ {i_j} 作为上下文来构建训练示例。然后，模型被提供一个包含真实商品 i_j 和负样本的候选集 𝒞 = {c₁, c₂, ..., c_n}，并需要选择正确的补全商品。
如图3所示，输入提示遵循一个结构化模板，包含上下文捆绑信息和融合表示。
LLM处理这种结构化输入，增强交叉注意力融合特征 𝐈_fusion，并生成候选选择的概率分布。训练目标采用交叉熵损失，最大化正确答案的似然：
ℒ_SFT = -∑_{i=1}^{|𝒟|} log P(y_i | ℬ_{-j}^{(i)}, 𝒞^{(i)}, 𝐈_fusion^{(i)}),
(11)
其中 𝒟 表示微调数据集，y_i 是第i个训练实例的真实标签，P(⋅) 表示LLM输出的概率分布。这种监督学习方法使模型能够通过利用预训练LLM的语义理解能力和嵌入在融合表示中的协同过滤洞察，学习复杂的捆绑补全模式。

4.2 基线
我们将所提出的方法与以下最先进基线进行比较：
• ICL（Dong等，2022）：语言模型通过利用输入中提供的示例和上下文来执行任务的能力，而非仅依赖预训练知识。
• MultiVAE（Liang等，2018）：变分自编码器框架，将离散的商品-用户交互编码为连续的潜在嵌入。
• BiLSTM（Han等，2017）：双向LSTM网络，用于捕捉序列依赖并学习捆绑表示。
• UHBR（Yu等，2022）：基于超图的方法，使用图卷积网络建模捆绑关系。
• CLHE（Ma等，2024b）：具有对比学习的分层编码，用于判别性捆绑表示。
• Bundle-MLLM（Liu等，2025）：具有混合分词和渐进优化的多模态方法，用于跨域适应性。

4.3 实现细节
本实验使用Llama-2-7b-Chat和Qwen2-7B-Instruct作为基础LLM，采用LoRA方法进行微调。LoRA配置将秩设为16，缩放因子alpha设为32，并对模型模块（包括注意力层的k_proj、v_proj、q_proj、o_proj，MLP层的gate_proj、up_proj、down_proj，以及lm_head和embed_tokens）进行低秩适配。然后，使用2个GPU进行BF16混合精度训练，训练10个epoch，采用线性预热余弦学习率调度，基础学习率为8e-5，从预热初始学习率8e-6开始，在预热阶段逐渐增加到基础速率，批量大小为8。

4.4 评估指标
我们采用HitRate@1作为主要指标，衡量模型从10个候选商品中选择最合适商品的准确性。此外，我们引入ValidRatio来评估响应的有效性，量化所有生成响应中有效预测的比例。
HitRate@1 = (1/N) ∑_{i=1}^N ℤ(ŷ_i = y_i),
(12)
ValidRatio = (1/N) ∑_{i=1}^N ℤ(valid(r_i)),
(13)
其中 N 表示测试样本总数，ŷ_i 和 y_i 分别表示预测和真实标签，r_i 是生成的响应，ℤ(⋅) 是指示函数。

5
结论与未来工作
传统产品捆绑系统在同时捕捉全面世界知识和理解用户行为模式方面存在显著局限。本文介绍了DPB-LLM，一种双增强产品捆绑框架，利用交互图增强将协同过滤知识注入大语言模型。在三个数据集上的大量实验表明，我们的框架显著优于最先进的基线模型，性能提升范围为6.3%至26.5%。这些结果验证了将传统推荐系统的关系建模能力与LLM的世界知识编码优势相结合的有效性。
尽管取得了这些有前景的结果，但仍有一些方向值得未来探索。首先，研究更高效的知识注入方法可以进一步释放LLM在理解产品语义和复杂用户-商品关系方面的潜力。其次，在多样化数据集和真实场景中评估框架将更好地评估其泛化能力。最后，优化模型复杂度与计算效率之间的平衡对于大规模实时推荐部署至关重要。
