TorchCurves：可微参数曲线

Alex Shtoff（alex.shtf@gmail.com）

摘要

我们提出 TorchCurves——一个将向量值参数曲线视为可学习基元的 PyTorch 库。其核心操作将成批的标量输入映射到以 B 样条或勒让德多项式基表示的曲线上的点，并支持对输入和系数的微分。曲线系数既可以与外围模型联合优化，也可以由另一个网络生成。该库提供可训练模块、可复用的基模块以及函数式接口，支持从连续特征嵌入到柯尔莫哥洛夫–阿诺德网络（KAN）以及函数回归等多种应用。其实现将经典求值算法与向量化 PyTorch 操作相结合，注重可读性与可维护性，且无需自定义硬件内核。计时实验在一系列问题规模上将曲线求值与 NumPy 和 SciPy 进行了比较，并将 KAN 训练与 EfficientKAN 进行了比较。结果说明了这种通用性在哪些场景下仍具备计算实用性，以及在哪些场景下开销显著。该库已在 GitHub 上开源：
https://github.com/alexshtf/torchcurves

关键词：样条、柯尔莫哥洛夫-阿诺德网络、KAN、机器学习

1 引言

图 1：TorchCurves 背后的基本操作。输入：一小批数值特征。输出：多维曲线上的一小批点。

参数曲线的应用遍及机器学习领域内外的众多科学与工程学科，例如样条回归、连续特征嵌入（Shtoff et al., 2024）、柯尔莫哥洛夫-阿诺德网络（Liu et al., 2025）、计算机辅助设计（Bézier, 1968）等。然而，目前似乎并没有一个软件库为"作为可学习基元的曲线"提供通用、可组合的接口，大家往往各自直接重新实现自己的高级对象。TorchCurves 将可学习的参数曲线本身确立为一种基元，并使其便于在各种模型架构中使用。其通用性使 PyTorch（Ansel et al., 2024）用户能够构建将可学习参数曲线作为组件的模型。

TorchCurves 的精髓在于一个操作——将一小批输入特征变换为 ℝᵈ 中曲线上的一批点，如图 1 所示。目前我们支持 B 样条和勒让德多项式。我们的实现是向量化的，在特征、批次和曲线维度上均无循环。但我们没有为专用硬件编写自定义内核——出于可读性与可维护性的考虑，我们选择完全用纯 PyTorch 实现。这一基本操作对其参数、输入特征以及曲线参数均可微，因而既能学习曲线本身，也能反向传播到先前的网络层。

后续各节安排如下：第 3 节介绍库的主要组件并给出应用示例：连续特征嵌入、柯尔莫哥洛夫-阿诺德网络和函数回归；第 4 节讨论一些实现与测试细节。

2 相关工作

多项式和样条表示在数值软件中已十分成熟。NumPy（Harris et al., 2020）和 SciPy（Virtanen et al., 2020）提供了表示、求值和微分此类函数的例程。PyTorch 生态系统中也存在可微样条包：torchcubicspline（Kidger, n.d.）从观测数据构造自然三次插值函数，而 torch-bspline（Melchers and Cochran, 2025）提供可微的 B 样条求值。

在机器学习中，从标量值到学习向量的映射出现在数值特征嵌入中（Gorishniy et al., 2022; Shtoff et al., 2024）。可学习的一元函数也构成柯尔莫哥洛夫-阿诺德网络的边（Liu et al., 2025），并有 EfficientKAN（Cao, 2024）等专门实现。这些应用展示了参数曲线在更大模型中所能扮演的多种角色。

TorchCurves 将曲线本身作为可复用的抽象：一个从标量输入到向量输出的参数化映射，对输入和系数均可微。它为 B 样条和勒让德多项式表示提供统一接口，其系数既可以直接学习，也可以由另一个模型提供。其贡献在于使这些曲线便于与其他学习组件组合，而无需求解插值问题，也不规定特定的网络架构。

3 API 与应用

我们首先介绍基本 API，然后展示其适用的用例示例。

3.1 API

该库提供两个基本组件 BSplineCurve 和 LegendreCurve，它们是嵌入在高维空间中的一维曲线。每条曲线表示为

c(x) = Σᵢ₌₁ⁿ vᵢ Bᵢ(x),

其中 Bᵢ 是相应的基础函数（B 样条或勒让德多项式），v₁, …, vₙ 是其（可能）被学习的系数。每个组件可同时求值大量曲线 c₁, …, cₘ，如图 1 所示。以下是一个示例：

import torch
import torchcurves as tc

u = torch.rand(4, 3)  # 4 个样本，3 个特征
curve = tc.BSplineCurve(
    num_curves=3,
    dim=2  # 2 维空间中的 3 条曲线
)
y = curve(u)  # (4 个样本, 3 条曲线, 2 个维度)
print(u.shape, "->", y.shape)
# torch.Size([4, 3]) -> torch.Size([4, 5, 2])

当然，有数学素养的读者会说这个例子并不完整，而且理由充分——B 样条和勒让德多项式基都需要配置，例如多项式次数、B 样条情形下的节点数等。此外，样条和多项式逼近是在紧区间上工作的，而这在上面的例子中并未体现。

实际上，我们为模块提供了默认值，但它们完全可配置。B 样条和勒让德多项式都假定在区间 𝒰 = [-1, 1] 上逼近输入，并可通过配置一个映射将输入变换到该区间。例如：

spl_curve = tc.BSplineCurve(
    num_curves=3,
    dim=2,  # 维度
    input_map='real.arctan',  # 将 x 映射为 2·arctan(x)/π
    num_knots=20,  # 20 个均匀分布的节点，端点采用 not-a-knot 条件
    degree=5  # 5 次多项式样条
)

lgd_curve = tc.LegendreCurve(
    num_curves=3,
    dim=5,  # 维度
    input_map='arctan',  # 同上
    degree=50  # 50 次勒让德多项式
)

映射函数包括上述反正切函数（也是默认值），还有 x → x/√(1+x²)，称为 real.rational，其灵感来自无界域微分方程文献中的用法（Guo and Wang, 2004; Boyd, 1987; Wang and Guo, 2004），以及简单地截断到 𝒰 的 real.clamp。前缀 real 表示这些映射面向任意实数设计。该库还提供面向非负数的 nonneg.rational 和 nonneg.arctan。用户也可以以 Python 可调用对象的形式提供自己的映射。

可训练模块很有用，但并不能涵盖该库旨在支持的所有用例。因此，该库提供三个层级的 API，下面分别说明： 可训练模块，如上所示； 基模块，缓存张量以避免重复计算，但没有可训练参数； 完全函数式 API，类似于 torch.nn.functional。

完全函数式 API 顾名思义由无状态的纯函数组成。以下是一个示例：

import torchcurves.functional as tcf

bspl_func = tcf.bspline_curves(
    inputs,   # (B, C) - 每条曲线的一批输入点
    coefs,    # (C, P, D) - C 个 B 样条函数的系数，各有 P 个系数、D 个维度
    knots,    # B 样条节点。若未指定，则在 [-1, 1] 上均匀分布并带 not-a-knot 条件
    degree=5  # 分段多项式次数。若未指定则为 3
)

leg_func = tcf.legendre_curves(
    inputs,    # (B, C) - 每条曲线的一批输入点
    coefs,     # (C, P, D) - C 个勒让德多项式的系数，各有 P 个系数、D 个维度
    degree=50  # 多项式次数。恒有 P = degree - 1
)

当系数不是直接学习、而是来自另一个模块的输出时，这些接口很有用。注意，对于 B 样条函数，节点数与系数数量 P 之间必须满足 P = |knots| - degree + 1。若未指定节点向量，则均匀分布节点的数量会根据次数和系数数量 P 自动确定。

最后，介于可学习模块与完全函数式 API 之间的是基模块。基模块类似于函数式 API，但为方便起见会存储不可变缓冲区（如节点向量）。这样，当模型从 CPU 迁移到 GPU 等加速器时，缓冲区会由 PyTorch 自动随之移动。以下是一个示例：

import torchcurves as tc

# 50 个 B 样条函数的 2 次样条，使用 rational 映射到 [-1, 1]
bspl_basis = tc.BSplineBasis(
    degree=2,
    knot_config=50,
    input_map="real.rational"
)

# 求值 B 样条函数。注意 - 50 个 B 样条函数对应 50 个系数。
bspl_func = bspl_basis(
    input,  # (B, C) - 每条曲线的一批输入点
    coefs   # (C, 50, D) - C 个 B 样条函数在 D 个维度上的系数
)

3.2 应用

首先想到的应用之一是为连续特征生成嵌入，例如身高、体重、BMI、用户上次访问我们网站以来的时间等。设想我们有一个以嵌入向量为输入的模型，例如因子分解机或 Transformer。对于离散或分类特征，我们可以直接用标准嵌入表将特征映射为嵌入。但对于连续值，我们需要一个从该值到嵌入空间中向量的映射——而曲线正是这样一种映射。下面是一个使用勒让德多项式基构造此类曲线的示例：

from torch import nn, cat
import torchcurves as tc

class Net(nn.Module):
    """将 PyTorch 的 nn.Embedding 和勒让德曲线与另一个模型组合"""
    def __init__(self, n_discrete, n_continuous, degree, dim):
        super().__init__()
        self.discrete = nn.Embedding(n_discrete, dim)
        self.cont = tc.LegendreCurve(n_continuous, dim, degree)
        self.inner_model = my_super_duper_transformer()

    def forward(self, cat, cont):
        # 将所有嵌入拼接为一个张量
        embeddings = cat((self.discrete(cat), self.cont(cont)), dim=-2)
        # 在嵌入上调用我们期望的模型
        return self.inner_model(embeddings)

柯尔莫哥洛夫-阿诺德网络也是一个直接的应用——每一层计算输入的许多一元函数并对其结果求和。回想一下，我们的曲线层输出形状为（样本， 曲线， 维度），因此一个 KAN 层只需应用我们的曲线层，再沿曲线维度求和即可。为方便起见，库中还提供了 Sum 模块。以下是一个示例：

from torch import nn
import torchcurves as tc

kan = nn.Sequential([
    # 第 1 层
    tc.BSplineCurve(input_dim, hidden_dim),
    tc.Sum(dim=-2),
    # 第 2 层
    tc.BSplineCurve(hidden_dim, hidden_dim),
    tc.Sum(dim=-2),
    # 第 3 层
    tc.BSplineCurve(hidden_dim, output_dim),
    tc.Sum(dim=-2),
])

一个不那么平凡的应用是函数回归——即输出本身为函数的模型。理论上，我们可以把任何模型 f(x) 都看作"函数回归"——只需将 x 划分为 (x₁, x₂)，并将模型定义为函数 f(x₁, ·)。关键不在于模型的架构，而在于将模型（包括其性能）作为这样一个函数来研究。由于作者来自在线广告领域，一个突出的例子是在给定拍卖特征和非负出价的条件下拟合赢得广告拍卖的概率，参见 Pan et al. (2020); Zhou et al. (2021)。

注意这是一个累积分布函数（CDF）——它必须是非递减的。一个自然的选择是利用 B 样条函数的性质：若系数向量非递减，则函数也非递减。下面就是这样一个例子——我们将拍卖编码为一个非递减的系数向量，该向量进而作为出价的 B 样条函数的系数向量。以下是一个学习这种概率的模型：

from torch import nn
import torch.nn.functional as F
import torchcurves as tc

class AuctionWinModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.encoder = MySuperBestAuctionEncoder()
        self.spline = tc.BSplineBasis(input_map="nonneg.arctan")

    def forward(self, auction_features, bids):
        # 将拍卖编码为潜在向量
        raw = self.encoder(auction_features)
        # 将潜在向量转换为非递减系数：
        # 第一个分量原样使用，对其余部分取 softplus 后累加
        increments = F.softplus(raw[:, 1:])
        coefficients = raw[:, :1] + F.pad(increments.cumsum(-1), (1, 0))
        # 出价的非递减样条函数，产生 P(win) 的 logits
        return self.spline(bids[None], coefficients[..., None]).flatten()

4 算法

除了向量化之外，我们所用的实现还必须足够高效，才能对机器学习研究有用。我们的效率目标并不高——旨在不使用自定义内核的前提下，用纯 PyTorch 代码达到最佳效果。因此，我们为 B 样条和勒让德多项式求值实现了经典算法的向量化版本。

B 样条基的主要特征是其稀疏性——在任意给定点，仅有 degree+2 个基函数非零。利用这种稀疏性的高效算法是著名的 Cox-deBoor 方法（COX, 1972; De Boor, 1972）。该算法提供了一种利用稀疏性来同时高效计算函数值和导数的方法。这些又被用于自定义的 PyTorch autograd 函数中，以便对输入和系数进行高效的反向传播。该实现以向量化方式完成，不对任何输入维度迭代，但确实需要按次数迭代。因此，计算一个 5 次样条需要 6 次 Python 迭代。

对于勒让德多项式，我们使用著名的 Clenshaw 递推（Clenshaw, 1955）。同样，我们不迭代任何输入张量维度，但需要按次数迭代。由于通常需要比 B 样条更高次的多项式才能获得良好的逼近效果，这在某些情况下可能效率较低。例如，一个 50 次多项式需要 51 次 Python for 循环迭代。

在实现中，我们特别注意避免张量的内存分配。我们不声称最优，只是尽力而为。再次强调，我们的效率目标并不高——只需足够快以实用。

该库经过了充分测试，特别是将结果与 SciPy（Virtanen et al., 2020）的样条和 NumPy（Harris et al., 2020）的勒让德多项式进行了比较。导数通过 PyTorch 内置的梯度检查机制验证，该机制将数值近似的导数与反向传播得到的导数进行比较。比较同时针对 32 位和 64 位浮点数进行。

5 实验

我们的目标是让读者定性地理解"我们的效率目标并不高"的含义。为此，我们进行两项比较： 在 CPU 上仅推理计算勒让德多项式和样条的速度，与 NumPy 和 SciPy 相比； KAN 的训练速度，与 EfficientKAN（Cao, 2024）相比，均在 CPU 和 GPU 上进行，各自以其惯用形式实现。我们的目的不是超越专门的实现，而是表明将曲线视为通用可训练基元的灵活性在计算上仍然可行，即使将它们组合成 KAN 这样的更高层架构。

所有测量均在 Lenovo P14s Gen-7 笔记本电脑上进行，配备 Intel Core Ultra 7 356H CPU 和 NVIDIA RTX PRO 500 Blackwell GPU。实验运行于 Ubuntu 26.04.01，使用 Python 3.12、NumPy 2.5.4、SciPy 1.18.1 和 PyTorch 2.15（CUDA 13.2）。CPU 亲和性限制在前 1-4 个核心（即该 CPU 的性能核心），以便既让 PyTorch 利用并行性，又获得一致的速度测量。
