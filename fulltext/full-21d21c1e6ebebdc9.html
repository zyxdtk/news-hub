原标题：FOCUS: Active Critic Learning for Long-Horizon Language Model Agents

中文摘要： FOCUS 是一种面向长程语言模型智能体的强化学习方法，通过选择性分支实现评论家网络的主动学习。其 rollout 控制器从预期最能降低价值估计误差的状态采样延续，以精炼中间状态价值，并用 TD(λ) 优势进行片段级功劳分配，同时为评论家提供训练目标。借助将上下文管理与 rollout 分配解耦的模块化接口，FOCUS 在法律推理、深度搜索和代码定位三个长程基准上，以匹配的每步生成预算全面超越 GRPO 与 VinePPO。

摘要

稀疏的结果奖励使长程语言模型智能体难以将功劳分配给早期动作。学习到的评论家（critic）可为中间状态提供价值估计，但这些估计可能不准确，而通过从轨迹内的点重复采样延续来估计中间价值又会产生巨大成本。为缓解这些问题，我们引入 FOCUS——一种利用选择性分支帮助评论家网络学习其价值估计器的强化学习方法。该 rollout 控制器通过从预期最能降低评论家估计误差的状态采样延续，为评论家实现主动学习。这些精炼后的价值估计随后以 TD(λ) 优势对相邻状态之间的片段进行评分，同时采样得到的证据为评论家提供训练目标。FOCUS 通过将上下文管理与 rollout 分配解耦的模块化上下文管理接口，支持长程智能体强化学习。实验表明，利用压缩产生的片段边界进行价值估计与功劳分配，FOCUS 在匹配每步生成预算的条件下，于法律推理、深度搜索和代码定位基准上优于 GRPO 和 VinePPO：在 Qwen3.5-9B 规模上，BrowseComp-Plus 的保留集准确率较最强基线提升 7.2 个百分点（55.4 对 48.2），DeonticBench 上提升 4.1 个百分点（56.5 对 52.4）。

1 引言

语言模型智能体越来越多地被训练来解决需要数十甚至数百次工具调用的任务：在真实代码仓库中修复问题（Jimenez et al., 2024; Cursor Research, 2026）、在真实网站上完成任务（Zhou et al., 2024b），或回答需要多轮搜索与阅读的问题（Chen et al., 2026; Kimi Team, 2026）。带验证奖励的强化学习（RLVR）是改进此类智能体的标准方法，但长轨迹意味着采样和功劳分配都很昂贵。单个可验证的奖励必须分摊到 rollout 中的每个 token 上，即使许多 token 对最终结果影响甚微。为了高效学习，我们需要在有限的 rollout 预算下获得恰当的中间价值估计。

这些估计可以来自学习到的评论家网络（Konda & Tsitsiklis, 1999），或通过从给定状态进行蒙特卡洛近似（Shao et al., 2024）。学习到的评论家可跨轨迹复用信息，但其预测可能不准确。树形结构 rollout 在中间状态处分支以精炼价值估计（Kazemnejad et al., 2025; Hou et al., 2025; Li et al., 2026d; Guo et al., 2025; Ji et al., 2026）。然而，为每个估计采样额外的语言模型延续会产生巨大成本，这引出了一个问题：如何分配 rollout 预算才能最有效地改进价值估计。

我们将通过额外延续分支来精炼价值估计视为评论家网络的主动学习问题：应当有选择地从那些额外证据预期最能改进价值估计的状态采样延续。我们引入 FOCUS：Focused Optimization on Critical Underperforming Segments（对关键欠佳片段的聚焦优化），一种将每个回合作为搜索树运行的 rollout 控制器。FOCUS 将评论家的预测与采样延续的证据相结合，并根据其对价值估计误差的估计边际缩减量来分配后续 rollout（Hay et al., 2012; Kaufmann & Koolen, 2017）。这些精炼的价值为策略提供逐步的功劳分配，而获得的证据为评论家提供训练目标。

在长程任务中，上下文压缩（Cursor, 2026; Harvey, 2026; Sun et al., 2026; Li et al., 2026e）——即智能体从其先前动作和观察的压缩记述中恢复运行——为应用选择性 rollout 提供了自然结构：每次压缩之间的片段成为一个"步骤"，在该步骤级别可以计算奖励和价值（图 1）。然而，FOCUS 不依赖于特定的上下文管理协议；其模块化设计将 rollout 分配、上下文管理和功劳分配彼此分离。

我们在 DeonticBench（Dou et al., 2026a）、BrowseComp-Plus（Chen et al., 2026）和 LocBench（Chen et al., 2025）上评估 FOCUS。在匹配的每步生成预算下，FOCUS 在所有三个基准上均优于 GRPO 和 VinePPO。使用 Qwen3.5-9B 时，FOCUS 在 BrowseComp-Plus 上将保留集准确率较最强基线提升 7.2 个百分点（55.4 对 48.2）（表 1）。诊断分析显示，随着精炼预算增加，价值估计误差的缩减更为有效；消融实验则表明这些增益不依赖于某一种特定的压缩实现（第 3.4 和 3.5 节）。

总结起来，我们的贡献包括：

  • 我们将评论家预测与延续证据的结合构建为主动评论家学习问题（第 2.2 和 2.3 节）。
  • 我们引入 FOCUS，一个高度可定制的 rollout 控制器，它依据估计的价值估计误差缩减量来分配有限的 rollout 预算，并将所得估计与功劳分配相集成。
  • 我们表明 FOCUS 在长程基准上优于无评论家基线（第 3 节）。

2 方法

2.1 问题设置

我们考虑从结果奖励中对语言模型策略 π_θ 进行强化学习。策略从其当前上下文生成回复或动作，而由 φ 参数化的评论家 V_φ 估计预期的剩余回报。我们假设至少部分中间状态易于分叉，且从中重复采样是平凡的。一个回合 ξ 记录一次完整运行中所生成的轮次和奖励。

给定有限的 rollout 预算，FOCUS 从候选状态中进行选择以采样额外延续，精炼其价值估计，并为评论家和策略构建训练样本。对于使用工具的智能体，压缩边界提供了自然的候选状态。附录详述了我们实验中使用的执行机制。

2.2 评论家精炼与学习

我们首先描述收集到的延续如何为评论家和策略产生学习信号。第 2.3 节描述我们如何分配 rollout 预算。

状态与 rollout 片段。 对于每个提示 x，我们将收集到的 rollout 表示为树 𝒯_x。非终端节点表示策略可以在相同上下文和环境状态下恢复的状态；边包含策略生成的延续以及直到下一个状态的环境转换。我们用 c̄ 表示节点（状态）的上下文，其关联的环境状态保持隐式。一条完整轨迹包含非终端节点 c̄0 = x, c̄_1, …, c̄_M 和终端节点 c̄{M+1}，由边 e_i = (c̄_{i−1} → c̄_i)，i = 1, …, M+1 连接。

精炼状态价值。 设 V^π(c̄) 表示在收集策略下从 c̄ 出发的延续的预期折扣回报。评论家 V_φ(c̄) 从状态的上下文预测该值，但该预测可能具有高方差。我们使用从已扩展的 n(c̄) 个延续 ch(c̄) 获得的结果证据来精炼其预测，并像 TreeRPO（Yang et al., 2025）那样向上回溯一层：

Ḡ(c̄) = (1/n(c̄)) Σ_{c̄′∈ch(c̄)} ( R_{c̄→c̄′} + γ^{d_{c̄→c̄′}} · Ṽ(c̄′) )，若 c̄′ 为终端则 Ṽ(c̄′) = 0，　(1)

其中 Ṽ(c̄′) 是延续自身的精炼价值（见下式 2）。我们倾向于此方法而非后代结果的原始平均（Li et al., 2026d），因为分配器会选择扩展哪些节点，所以 c̄ 下方的叶子不再是来自 c̄ 的同策略抽样；而延续的精炼价值会将其证据逐层向上传递。

我们以固定的伪观测权重 κ 结合评论家预测和递归回溯：

Ṽ(c̄) = ( κ·V_φ(c̄) + n(c̄)·Ḡ(c̄) ) / ( κ + n(c̄) )。　(2)

当 n(c̄) = 0 时，我们设 Ṽ(c̄) = V_φ(c̄) 而不计算 Ḡ；终端价值为零。随着 n(c̄) 增大，混合会将更多权重放在回溯均值上（Silver et al., 2016; Tesauro et al., 2010）。

评论家监督与演员优势。 收集和最终回溯完成后，我们在每个非终端状态上以递归目标 Ḡ 训练评论家：

ℒ_critic(φ) = E[ Σ_{c̄∈𝒯_x: n(c̄)>0} ( V_φ(c̄) − Ḡ(c̄) )² ]。　(3)

目标在训练期间保持固定。此更新将收集到的延续证据转移到后续训练所使用的评论家中。在当前迭代内，精炼价值 Ṽ 提供片段级时序差分残差²：

Â_i = δ_i = R_i + γ^{d_i} Ṽ(c̄i) − Ṽ(c̄{i−1})。　(4)

我们将每条边的分离优势应用于其策略生成的任务 token 和上下文管理 token（记为 y_{e_i}），并屏蔽环境观察和条件文本。以 π_old 为收集策略，ρ_t 为 token 级重要性比率，ε 为裁剪阈值，演员最小化：

ℒ_actor(θ) = −E[ Σ_i Σ_{t∈y_{e_i}} min( ρ_t·Â_i, clip(ρ_t, 1−ε, 1+ε)·Â_i ) ]，ρ_t = π_θ(y_t | y_{<t}) / π_old(y_t | y_{<t})。　(5)

2.3 面向评论家学习的选择性 rollout 分配

从候选状态分支延续可提供额外的价值证据（Kazemnejad et al., 2025; Hou et al., 2025; Li et al., 2026d; Guo et al., 2025），但均匀分配未考虑评论家误差的差异或额外样本的预期收益。给定已探索的树 𝒯_x 和额外 rollout 预算 B，FOCUS 选择哪个候选节点接收下一个延续，目标是在预期最能降低价值估计误差之处获取证据（Roy & McCallum, 2001; Mussmann et al., 2022）。

用于选择的结果证据。 虽然选择阶段使用与"混合观测延续结果和评论家预测"相同的公式，但它不使用其子节点的延续精炼回溯（如式 1）。具体而言，设 N(c̄) 为延续结果的数量，Ḡ_obs(c̄) 为其均值。一条完整的延续在其起始节点以及沿该延续新创建的每个节点各贡献一个结果；之后从后代分支不会向其严格祖先添加更多观测。因此 N(c̄) 计算观测到的延续结果，而式 1 中的 n(c̄) 计算直接子节点。

对于二元延续结果，选择模型使用以 v = V_φ(c̄) 为中心、强度为 κ 的 Beta 先验。其后验均值和预期评论家平方误差为：

μ_obs = ( κv + N·Ḡ_obs ) / ( κ + N )，ê² = ( v − μ_obs )² + μ_obs(1−μ_obs) / ( κ + N + 1 )。　(6)

注意 μ_obs 不同于延续精炼的训练价值 Ṽ。下一个结果的预测方差为 σ̂² = μ_obs(1−μ_obs)。特别地，基于附录 E 中概述的观察，我们依靠 μ_obs 进行选择。

延续的预期收益。 我们用该候选状态处价值估计误差的边际 MSE 缩减量来对延续的预期效用评分。对于评论家平方误差 e² 和结果方差 σ²，获取函数变为 MSE(N) = (κ²e² + Nσ²)/(κ+N)²。在 e² 和 σ² 固定的条件下求导，再代入后验估计，得：

g(c̄) = ( 2κ²·ê² + (N−κ)·σ̂² ) / ( κ + N )³，　(7)

其中 N = N(c̄) 计算已完成的延续结果。

实际考虑。 任何节点的总分支宽度不受限制。分配阶段也可以异步运行，每个完成的延续更新获取统计信息，而其他延续仍在进行中。在这种情况下，我们将式 7 中的 N 替换为 N_eff(c̄) = N(c̄) + m(c̄)，其中 m 计算待处理的延续；后验估计仍仅使用已完成的结果。我们将每个节点的并发延续数限制为 C = 2，全局限制为工作器容量 W，并将资格限定为 m(c̄) < C。已完成的子节点不占用并发槽位。实践中，两个循环可以并发运行，各自采用多进程。启动预算耗尽后，待处理的延续继续完成，最终的自底向上精炼确保训练目标反映完整的树。

3 实验

我们首先在 MATH（Hendrycks et al., 2021）难度 4–5 级问题上将 FOCUS 与 PPO 和 GRPO 进行初步评估，跟踪准确率、评估输出长度以及每次 rollout 缩减量随训练更新的变化。随后在 Qwen3.5-9B 和 Qwen3.5-27B（Qwen Team, 2026）（LoRA）上，于三个长程基准上将 FOCUS 与 GRPO 和 VinePPO 比较，评估 MCTS 精炼如何改进评论家估计，并对压缩算子和精炼 rollout 进行消融。

3.1 数学推理的初步评估

我们使用 Qwen3.5-4B（Qwen Team, 2026）在 MATH 4–5 级问题上比较 FOCUS、PPO 和 GRPO，进行 32 次完整更新，评估基础检查点以及第 8、16、24、32 次更新时的检查点。我们使用官方 MATH 训练划分中的 512 个训练问题和官方测试划分中的 256 个验证问题。训练集包含 226 个 4 级和 286 个 5 级问题；验证集包含 123 个 4 级和 133 个 5 级问题。所有方法在 32 个训练步中消耗固定的 512 题顺序。PPO 每训练步使用 64 个问题；GRPO 和 FOCUS 每训练步各使用 16 个问题。为使训练计算量大致匹配，GRPO 使用组大小 6，FOCUS 使用每题边预算 64，每条边最多 256 个 token。

3.2 长程数据集

DeonticBench（Dou et al., 2026a） DeonticBench 评估模型在上下文扎根的道义推理上的表现：从真实法规和案例事实中推导义务、许可和禁止。它包含 6,232 个任务，涵盖美国联邦税法、航空行李政策、移民管理以及州住房法。将长法规应用于具体案例是一个多步骤过程，这使该基准成为长程智能体推理的场景——模型按需查阅法规（Dou et al., 2026b），也是逐步 rollout 的天然测试平台。我们关注 airline、sara-numeric 和 sara-binary 子集，其法规相当长且涉及非平凡的长程任务。演员框架提供 Agy list、Agy grep、Agy read 和 Agy python 工具。我们将数据分层划分为等大小的训练集和保留集。

BrowseComp-Plus（Chen et al., 2026） BrowseComp-Plus 在固定的人工验证语料库（而非实时网络 API）上评估深度搜索智能体处理复杂多跳信息查询的能力。由此产生的轨迹是长程的：迭代式查询制定、检索和反思，这使该基准成为逐步 rollout 的天然测试平台。遵循 TRACE（Tao et al., 2026），演员框架在固定语料库上提供 Agy search、Agy open 和 Agy find 工具。我们将 830 个测试任务随机划分为 498 个训练、83 个验证和 249 个保留任务。

LocBench（Chen et al., 2025） LocBench 是一个代码定位基准，包含 560 个真实 GitHub issue（242 个错误报告、150 个功能请求、139 个性能问题和 29 个安全问题），来自 transformers、scikit-learn、vllm 和 ultralytics 等仓库；在 LocAgent 的构建中，错误报告是相对较新创建的 issue，安全和性能实例通过 GitHub 关键词搜索收集。仅给定 issue，智能体必须定位金标准补丁所涉及的文件和函数。我们使用附录所述框架进行实例化；演员提供 Agy list、Agy grep 和 Agy read 工具用于仓库导航。我们按照 LocAgent 的方式评分：当每个金标准位置都出现在前 k 个中时（新增函数被排除），文件级和函数级 Acc@k 为 1；我们报告文件级 Acc@{1,5}，并在 k=5 的文件级召回率上进行训练。我们将实例按仓库和问题类别分层划分为相等的训练集和保留集。

4 相关工作

结构化 rollout 与 rollout 分配 对中间状态的搜索最初是一种推理时技术：LLM 树搜索（Yao et al., 2023; Hao et al., 2023; Zhou et al., 2024a）和验证器引导的测试时扩展（Lightman et al., 2024; Snell et al., 2025）改进了模型回复。后来它被离线用于生成训练监督（Tian et al., 2024; Zhang et al., 2024; Guan et al., 2025），继而进入 RL 循环。VinePPO（Kazemnejad et al., 2025）、SPO（Guo et al., 2025）和 TEMPO（Tran et al., 2025）从中间推理步骤重采样延续，用蒙特卡洛估计替代价值网络；TreeRL（Hou et al., 2025）、TreePO（Li et al., 2026d）和 DeepSearch（Wu et al., 2026）在 RLVR 训练内部运行搜索，使共享前缀削减生成成本且树产生过程级信号。其他工作提出分支位置：在高熵 token 处（Zheng et al., 2025; Cao et al., 2026）、注意力峰值处（Liu et al., 2026）、模型信念转变处（Lei et al., 2026），或对于使用工具的智能体，在观察之后的轮次边界处（Dong et al., 2026; Zong et al., 2026）。Tree-GRPO（Ji et al., 2026）使每个智能体步骤成为一个节点，并表明树内组目标等同于步骤级偏好学习；PaTR（Li et al., 2026c）通过过程分数路由分支预算，IGRPO（Zhang et al., 2026b）和 SIGHT（Zhong et al., 2026）则通过信息增益路由。T²PO（Wang et al., 2026a）转而重采样被其 token 级和轮次级不确定性信号标记为无进展的轮次。TRACE（Zou et al., 2026）用条件成功的学习预测器统一提示级和轮次级分配，将额外 rollout 引向最有可能产生混合终端奖励的前缀。

FOCUS 依据额外延续对价值估计误差的估计缩减量来分配它们，并使用获得的证据精炼状态价值、训练可复用的评论家。

主动学习与预期误差缩减 预期误差缩减方法根据观测对学习者误差的预测影响来选择观测。Roy & McCallum (2001) 通过抽样近似该目标；Mussmann et al. (2022) 使用贝叶斯参数样本估计未标记验证集上预测损失的缩减，而无需为每个候选查询重新训练。相关方法选择数据以降低预测方差，在近似无偏学习者下将方差缩减与平方误差最小化联系起来（Cohn et al., 1996）。影响函数方法通过近似额外训练数据如何影响拟合模型的评估损失来估计获取效用，无需为每个候选重新训练（Koh & Liang, 2017; Xu & Kazantsev, 2019）。FOCUS 将误差缩减原则应用于在中间状态之间分配延续样本。

评论家学习与功劳分配 已知轨迹级奖励对多轮智能体会失效，因为它无法区分有用的轮次与冗余的轮次，且仅在其上训练并不稳定（Wang et al., 2025; Wei et al., 2025; Tan et al., 2026）。一种应对是将奖励和评论家置于轮次或步骤级别，而非 token 级（太细粒度）或整条轨迹级（太粗粒度）（Zhou et al., 2024c; Zhou et al., 2025; Li et al., 2026a; Zhang et al., 2026a; Zhen et al., 2026）。轮次是智能体自然的决策单元；以轮次衡量的视野足够短，评论家可以自举，且每轮价值从单次 rollout 中为每个轮次提供自己的信号。大规模训练也在从结构比较转向学习价值：SAO（Hou et al., 2026）用每个提示一次由价值模型评分的 rollout 替代 GRPO 的组采样，因为完整组在异步训练下缓慢且偏离策略。一些过程奖励模型在策略优化期间充当固定价值估计器（Wang et al., 2024; Luo et al., 2024; Li & Li, 2025; Choudhury, 2025; Setlur et al., 2025; Tao et al., 2026）。最近，Le Critique（Venkatraman et al., 2026）根据评论家的准确度，将学习基线与免训练的组相对基线相混合。

FOCUS 使用精炼的状态价值构建片段级演员优势，并使用递归回溯监督评论家，将当前迭代中的功劳分配与后续迭代的评论家学习相耦合。

长程智能体的上下文管理 压缩正成为超出上下文窗口的智能体的标准做法（Packer et al., 2023; Yu et al., 2026; Sun et al., 2026; Li et al., 2026b），且最近有推动将其与任务联合训练，而非视为冻结的预处理器（Cursor, 2026; Li et al., 2026e）。状态恢复也是识别步骤级功劳的核心（Zhang, 2026）。在我们的长程实验中，压缩边界为获取延续证据提供了可恢复的状态。rollout 控制器独立于压缩算子在这些状态上运行；其目标是通过选择性 rollout 精炼价值估计并构建评论家监督。

5 结论

我们提出了 FOCUS，一种用于语言模型强化学习的 rollout 控制器，它通过主动评论家学习和选择性 rollout 来精炼中间价值估计。FOCUS 通过灵活且模块化的上下文管理协议（如压缩）自然地支持长程智能体 RL。

在 DeonticBench、BrowseComp-Plus 和 LocBench 上，FOCUS 在匹配的每步生成预算下优于 GRPO 和 VinePPO，在深度搜索和道义推理上保留集增益最大，在代码定位上收益一致。训练曲线表明这些改进伴随着更稳定的探索：FOCUS 保持更高的收集奖励，并避免了轨迹级组功劳下出现的训练后期工具使用崩溃。消融表明收益不依赖于单一压缩实现，且精炼 rollout 在 BrowseComp-Plus 上有益。我们发布了带有替代框架、搜索策略和功劳估计器接口的模块化 rollout 控制器。未来工作可将 FOCUS 扩展到更大的模型和更长的预算，加强压缩质量与训练稳定性之间的联系，并为价值精炼采用更强的不确定性量化。

附录 C BrowseComp-Plus 冷启动

我们在第 3 节匹配的 RL 运行之前，先用监督模仿对 BrowseComp-Plus 进行冷启动。我们首先从 Qwen3.5-9B 在训练划分问题上收集 200 条成功的未压缩轨迹，保留 20 条用于开发，其余 180 条用于模仿。对于每条轨迹，我们确定性地重放所记录的 9B 动作和工具观察。每当生产框架会执行压缩时——在 14,336 个提示 token 或 10 次工具调用后——我们查询 Qwen3.5-27B 仅总结该检查点时可用的历史，并在重放中的每个后续压缩边界重复此操作。教师提示要求包含证据、已确定的要求和真正开放的问题，并将"后续步骤"字段固定为"无"，以免压缩指示演员重复验证。我们拒绝不完整或无效的摘要，并验证重放保留了原始动作、观察和最终答案。然后，监督目标将教师压缩轮次与从第一次压缩开始的被重放的 9B 执行轮次配对，因此模仿阶段同时训练压缩和持续搜索。由于执行是重放而非从教师摘要重新采样的，任何冗余研究的减少都在实时 RL 和保留集评估中评估，而非在此合成构建阶段。
