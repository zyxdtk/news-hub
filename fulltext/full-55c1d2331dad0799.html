# 摘要

基于人类反馈的强化学习（RLHF）已成为将生成模型与人类偏好对齐的强大范式。然而，将RLHF应用于扩散模型仍然存在反馈效率极低的问题，因为现有方法通常需要大量的人类或奖励模型评估。这一局限性降低了扩散RLHF在反馈是主要瓶颈的现实场景中的实用性。在本文中，我们提出了两种互补策略，在保持对未见提示的泛化能力的同时，大幅提升扩散RLHF的反馈效率。我们的关键观察是：扩散轨迹中的奖励信息分布不均匀——并非所有去噪时间步或轨迹对奖励信号的学习贡献相同。通过在优化过程中强调信息量大的时间步和轨迹，我们获得了更有效的梯度更新。首先，我们引入了一种逐时间步加权方案，在策略优化过程中对去噪步骤进行重新加权。我们从理论上将这种加权与近端策略优化（PPO）的最优收敛性质联系起来，并通过经验近似得到相应的加权趋势。其次，我们引入了一种重放机制，优先选择信息量大的轨迹，使模型能够复用过去的样本，而非反复查询新的奖励。这两种策略共同显著提升了扩散RLHF的反馈效率。在相同的超参数设置下，与广泛使用的扩散RLHF基线方法相比，我们的方法在样本效率上实现了高达6倍的提升。

# 1 引言

扩散模型[41]已成为高质量图像生成的主导框架。然而，由于它们被训练来重现训练数据的分布，因此并不天然地反映人类偏好。最近的工作[2, 8]通过基于人类反馈的强化学习（RLHF）[6]来解决这一局限性，该方法使用来自人类或奖励模型的标量反馈来微调扩散模型，以显式地优化偏好对齐。

扩散模型中RLHF的一个主要挑战是信用分配问题：即确定扩散过程中哪些中间时间步实际上对最终奖励做出了贡献。由于人类反馈仅在最终图像上给出，DDPO[2]等方法简单地将相同的损失分配给每个时间步。这种设置忽略了去噪过程的结构以及不同时间步如何在不同粒度级别上编辑图像[25]。因此，模型在不考虑去噪轨迹非均匀性质的情况下均匀地优化转换，导致训练效率低下。

先前的工作试图通过对比从相同初始噪声生成的成对去噪轨迹来解决这一问题[14, 52]。在这些方法中，轨迹在指定的分支时间步之前保持相同，之后发散。虽然对比两条共享初始噪声的轨迹可以突出它们发散时间步的效果，但该方法并未对比序列中的其他时间步。较早的步骤保持相同因此不提供信息，而较晚的步骤仍然继承相同的均匀优势，使得更广泛的信用分配问题未得到解决。此外，这些方法需要每个起始噪声进行多次奖励评估，降低了样本效率并增加了计算成本。

在本文中，我们论证了扩散轨迹中的奖励信息在时间步和轨迹之间本质上是不均匀分布的。某些去噪步骤和轨迹比其他步骤和轨迹贡献了更多的学习信号。为了利用这一观察，我们提出了两种互补策略来强调信息量大的训练数据。

首先，我们引入了一种逐时间步加权方案，在优化过程中选择性地对去噪步骤进行重新加权。我们通过分析群体相对策略优化（GRPO）与近端策略优化（PPO）之间的关系来为这种加权提供理论动机，表明每个时间步理想情况下应与TD误差PPO优势的方差成正比进行加权。虽然这一量在训练过程中难以高效估计，但我们分析了其行为，并使用基于逐时间步潜在变化平方幅度的简单启发式来近似其趋势。从经验上看，这种加权提高了训练样本效率。

其次，我们引入了一种受机器人强化学习中常用重放缓冲区启发的轨迹重放机制[34, 1, 22]。我们不再丢弃先前采样的轨迹，而是在训练过程中复用信息量大的轨迹。从优先重放缓冲区[34]中汲取灵感，我们发现对具有最大优势[40]的轨迹进行难例挖掘能提供最高效的学习。通过强调信息量大的轨迹，模型可以在不反复采样新轨迹和奖励评估的情况下持续改进。

总体而言，我们的方法在保持简单且与现有扩散RLHF流程兼容的同时，将基线方法的效率提高了2-6倍。

总结来说，我们的主要贡献包括：

- 一种计算上可行且数学上有动机的逐时间步加权方案，缓解了扩散RLHF中的信用分配问题。 - 一种重放缓冲区机制，在训练过程中检索信息量大的历史轨迹，减少了对重复奖励查询的需求。 - 一种简单的即插即用方法，可无缝集成到现有扩散RLHF流程中，无需架构更改。 - 大量实验展示了在多种奖励函数上的一致性增益，突出了我们方法的通用性。

# 2 相关工作

## 2.1 重放缓冲区

重放缓冲区存储策略先前的环境交互以供训练使用。它是DDPG[20]、Soft-Actor Critic[9]和Deep Q-Networks[24]等离策略方法的标准配置，但在PPO[37]和TRPO[36]等在策略方法或当前RLHF方法中并不常见，因为这些方法依赖于从最新权重中采样以保持在分布内。

存在许多重放缓冲区变体。后见之明经验重放[1]用新目标重新标记失败轨迹以合成成功轨迹。其他方法在特定标准下优先选择转换。[34]的方法按高时间差（TD）误差进行采样，作为网络在给定点的训练不足程度的代理，而基于能量的后见之明[54]优先选择高动能轨迹。[22]提出了由扩散模型生成的合成轨迹，[47]展示了检索可以增强机器人模仿学习。最后，[19]使用累积TD误差对先前的PPO轨迹进行难例挖掘。

## 2.2 RLHF

RLHF已成为对齐大型语言模型（LLM）的核心范式。现代RLHF由[27]引入，他们通过监督微调、奖励建模和强化学习的三步流程将其扩展到预训练LLM。后续方法如群体相对策略优化[38]完全移除了奖励模型，转而使用群体归一化优势，而[39]表明GRPO比监督微调更能防止灾难性遗忘。基于偏好的方法如[31]让人类对一个样本相对于另一个样本进行排名，而非给出数值奖励。最近，[4]在计算段级奖励之前对LLM的token流进行分段，[29]将GRPO与提示难例挖掘相结合。

RLHF也在机器人领域进行了探索：[16, 45]在基于偏好的机器人轨迹评估上训练策略，[51]在预训练的轨迹扩散模型上使用奖励引导的进化搜索，[32]微调预训练的模仿学习扩散策略如扩散策略[5]。

## 2.3 扩散RLHF

RLHF在将扩散模型与人类偏好对齐方面也很有效。扩散RLHF始于DPOK和DDPO[8, 2]，它们将RL应用于扩散模型并优于奖励加权回归（RWR）[28]。后续方法如B2-DiffuRL[14]和Branch-GRPO[18]从共享输入噪声分支以锐化轨迹之间的对比，另一条工作线表明GRPO可以应用于流匹配和扩散[21, 50, 55, 18]。与GRPO相比，基于偏好的方法[52, 3, 44]让人类在生成的图像对之间进行选择，而非分配数值奖励，并在此反馈上进行训练。扩散RLHF已被证明在视频扩散[30]和2步扩散[17]设置中有效。

相比之下，一些方法[7, 23, 48]假设奖励是可微的（例如分类器或VLM）并直接通过它进行反向传播，而其他方法则定位奖励重要性的空间区域[15, 48]。工作SIPO[53]在非数值成对偏好反馈下重新加权轨迹时间步以实现更稳定的训练，而最近的工作TempFlow[10]探索了流匹配而非DDPM风格模型中的时间步加权，但没有进行难例挖掘。此外，他们在单个奖励函数上进行评估，而我们在5个奖励函数上的评估表明他们的加权方案不如我们的。

# 3 预备知识

## 3.1 马尔可夫决策过程

形式上，MDP[43]可以表示为元组 $(S, A, P, R, \gamma)$，其中 $S$ 是状态空间，$A$ 是动作空间，$P(s'|s,a)$ 是从当前状态 $s$ 和动作 $a$ 到新状态 $s'$ 的概率转移函数，$R(s,a)$ 是奖励函数，$\gamma$ 是折扣因子。在每个时间步 $t$，智能体可以访问状态 $s$ 并选择动作 $a$。结果是新状态 $s'$ 从 $\mathcal{P}(s'|s,a)$ 中采样，以及奖励 $R(s,a)$。

强化学习的目标是最大化衰减奖励的总和，形式化表示为：

$$J(\pi)=\mathbb{E}_{\tau\sim p_{\pi}}\left[\sum_{i=0}^{n}\gamma^{i}R(s_{i},a_{i})\right]$$

## 3.2 扩散模型

对于给定的数据样本 $x_0 \in \mathbb{R}^d$，前向扩散过程在 $T$ 步中逐渐添加噪声以获得噪声轨迹 $(x_0, x_1, \ldots, x_T)$。数学上，前向过程可以定义为：

$$q(x_t|x_{t-1})=\mathcal{N}(x_t; \sqrt{1-\beta_t}x_{t-1}; \beta_t I)$$

其中 $\beta_t$ 是单调噪声调度。反向扩散过程由训练好的模型 $p_\theta$ 组成，其中 $p_\theta(x_{t-1}|x_t)$ 学习近似后验分布 $q(x_{t-1}|x_t, x_0)$，这也是一个具有单调方差调度 $\tilde{\beta}_t$ 的正态分布。

在奖励反馈下，反向扩散过程可以解释为MDP，其中动作是扩散模型预测的噪声，状态是图像的潜在空间，转移函数是如DDIM[42]和DDPM[12]等采样器，输入当前潜在表示和预测噪声。

## 3.3 PPO与扩散RLHF

PPO[37]是经典强化学习中常用的方法。形式上，PPO使用以下损失函数：

$$L_{\text{PPO}}=\min\big(A_t \frac{\pi_\theta(a|s)}{\pi_{\theta_{\text{old}}}(a|s)}, \operatorname{clip}(\frac{\pi_\theta(a|s)}{\pi_{\theta_{\text{old}}}(a|s)}, 1-\epsilon, 1+\epsilon)A_t\big)$$

其中 $A_t$ 是时间步 $t$ 的优势，$\epsilon$ 是防止过大权重偏移的裁剪值，$\pi_{\theta_{\text{old}}}(a|s)$ 是使用旧参数 $\theta_{\text{old}}$ 采取动作 $a$ 的概率，与当前参数 $\theta$ 相对。在经典机器人RL中，优势由TD误差给出：

$$A_t = \gamma V(s_{t+1}) + R_{t+1} - V(s_t)$$

其中 $V$ 是价值函数。在扩散RLHF的背景下，先前的方法不使用TD误差，而是计算均匀优势：

$$A = \frac{r - r_{\text{mean}}}{\text{std}(r)}$$

其中 $r$ 是轨迹末端的奖励，$r_{\text{mean}}$ 是一批样本中的平均奖励，$\text{std}(r)$ 是一批奖励的标准差。相同的优势值 $A$ 用于轨迹中的所有时间步。

# 4 方法

**图6**：我们方法的概述。与DDPO相比，我们添加了一个时间步相关的权重来考虑去噪过程的不对称性质，并添加了一个重放缓冲区用于存储先前的轨迹并对重要轨迹进行难例挖掘。

在现有的扩散RLHF流程中，信息量大的训练信号常常被无信息或低奖励的数据所掩盖。我们的方法在两个层面解决这一问题：（1）时间步级信用分配和（2）轨迹级数据选择。我们首先分析信用分配问题并推导出时间步相关的加权方案，然后引入基于重放的难例挖掘策略来优先选择信息量大的轨迹。

首先，在时间步级别（第4.2节），我们尝试解决信用分配问题。虽然标准扩散RLHF方法对所有去噪步骤分配均匀信用，但我们引入了一种理论上动机驱动的加权方案的实用近似，将更大的重要性分配给对最终奖励贡献最大的扩散步骤（图1（左））。

其次，在轨迹级别（第4.4节），我们引入了一种难例挖掘机制，选择性地复用具有高绝对优势的过去轨迹，确保在学习过程中强调最具信息量的经验（图1（右））。

## 4.1 非均匀信用分配

传统扩散RLHF使用GRPO数学计算单一优势 $A = \frac{R - R_{\text{mean}}}{\text{std}(R)}$。根据扩散RLHF方法的不同，$R_{\text{mean}}$ 和 $R_{\text{std}}$ 分别指群体或批次的均值和标准差。这个优势常数 $A$ 在其损失函数中均匀应用。每个时间步使用相同的常数：

$$\mathcal{L}_{\text{ddpo}} = \sum_{t=1}^{n} -A \cdot \log(P_\theta(x_{t-1}|x_t, c))$$

这个损失函数有问题，因为它没有考虑每个步骤对最终奖励的贡献程度。为了更好地理解信用分配问题，我们首先分析奖励如何沿扩散轨迹演变。

### 4.1.1 案例研究

让我们看看时间步 $t$ 处预测的干净图像 $\hat{x}_0(x_t)$ 对应的奖励，定义为 $R_t = R(\hat{x}_0(x_t))$，对于某个奖励函数 $R$。为简洁起见，我们将其记为 $R(x_t)$，因为 $\hat{x}_0$ 随 $x_t$ 平滑变化。考虑量 $\Delta R_t = R(x_{t+1}) - R(x_t)$。对于小的扩散更新 $x_{t+1} = x_t + h_t$，一阶泰勒级数展开给出 $R(x_{t+1}) \approx R(x_t) + h_t^\top \nabla R(x_t)$。对时间步 $t$ 求和在局部线性假设下产生望远镜分解 $R(x_T) - R(x_0) \approx \sum_t \Delta R(x_t)$。这提供了最终奖励在 $\Delta R_t$ 和初始奖励方面的近似分解。如果我们忽略初始奖励 $R(x_0)$（在随机初始噪声下应该平均到相同的量），$\Delta R_t$ 可以被视为时间步 $t$ 对最终奖励贡献的粗略代理。在图3中，我们观察到 $\Delta R_t$ 在不同时间步之间变化显著，表明去噪轨迹的不同部分对最终奖励信号的贡献不均等。我们强调 $\Delta R_t$ 不应直接用于信用分配，因为它只捕获即时奖励变化，没有考虑状态 $x_t$ 对未来去噪步骤的长期影响。

### 4.1.2 优势方差比例加权作为自然结果

受此观察的启发，我们接下来将扩散RLHF与PPO联系起来，以推导出有原则的时间步级信用分配方案。

PPO和GRPO之间的一个关键区别是PPO基于TD误差进行逐时间步优势计算，从而减少了GRPO中出现的信用分配问题。我们推导出一个方程，从使用GRPO计算的单一最终优势重建PPO时间步级优势。我们证明PPO时间步优势与轨迹级优势 $A_{\text{final}}$ 成正比，对于某些时间步相关常数 $w(t)$。通过使用这些PPO优势值代替均匀GRPO优势，我们可以获得更好的收敛性。

原始PPO使用TD误差优势：

$$A_t = \gamma V(s_{t+1}) + R_{t+1} - V(s_t)$$

其中 $A_t$ 是时间步级优势，$V$ 是来自强化学习的价值函数。

为简化符号，我们假设20步扩散过程。令状态 $s_k = \{x_k, T_k\}$，其中 $T_k$ 是扩散时间步，$x_k$ 是噪声图像。考虑扩散轨迹 $(s_0, s_1, \ldots, s_{20})$，其中状态 $s_0$ 对应纯噪声，$s_{20}$ 对应最终图像，$s_k$ 对应中间潜在表示。考虑动作序列 $a_0, \ldots, a_{19}$。在RLHF场景中，只有来自 $s_{20}$ 的单一奖励，因此将最终奖励记为 $R_{\text{final}}$，所有中间奖励为0。最后，我们假设 $\gamma = 1$，这在RLHF中是典型的。

对于 $t = 0, \ldots, 19$，我们的 $A_t$ 方程简化为：

$$A_t = \gamma V(s_{t+1}) + R_{t+1} - V(s_t) = V(s_{t+1}) - V(s_t)$$

我们有 $V(s_{20}) = R_{\text{final}}$。这给出：

$$A_0 + A_1 + \ldots + A_{19}$$ $$= [V(s_1) - V(s_0)] + [V(s_2) - V(s_1)] + \ldots + [V(s_{20}) - V(s_{19})]$$ $$= V(s_{20}) - V(s_0) = R_{\text{final}} - V(s_0)$$

由于 $s_0$ 是从 $\mathcal{N}(0, 1)$ 采样的纯噪声，由于现有采样器的高重采样噪声，从相同起始噪声可以产生非常多样化的去噪轨迹。因此，我们假设 $V(s_0) \approx \mathbb{E}_{s_0 \sim N(0,1)}(R_{\text{final}}) = R_{\text{mean}}$。因此：

$$A_0 + \ldots + A_{19} = R_{\text{final}} - V(s_0) \approx R_{\text{final}} - R_{\text{mean}} = A_{\text{final}} \cdot \text{std}(R)$$

在假设我们只知道最终优势 $A_{\text{final}}$ 而不知道其他信息的情况下，我们可以估计每个 $A_t$。

我们有 $A_t = V(s_{t+1}) - V(s_t)$ 在所有轨迹上均值为零，因为：

$$V(s_t) = \mathbb{E}_{s_{t+1}|s_t}[\gamma V(s_{t+1}) + R_t] = \mathbb{E}_{s_{t+1}|s_t}[V(s_{t+1})]$$

$$\implies \mathbb{E}_{s_{t+1}|s_t}[A_t] = \mathbb{E}_{s_{t+1}|s_t}[V(s_{t+1}) - V(s_t)] = 0$$

令 $\sigma_t$ 为 $A_t$ 在 $\pi$ 生成的轨迹分布上的标准差。我们进一步近似每个 $A_t$ 来自高斯分布 $\mathcal{N}(0, \sigma_t^2)$。

我们想找到条件分布：

$$P\!\left(A_k \mid \sum_{i=0}^{19} A_i = A_{\text{final}} \cdot \operatorname{std}(R)\right)$$

这是线性约束下多元正态分布的条件分布。这给出分布：

$$A_k \Big| \sum_{i=0}^{19} A_i = A_{\text{final}} \cdot \text{std(R)} \sim \mathcal{N}(\mu, \sigma^2)$$

其中：

$$\mu = \frac{\sigma_k^2 \, \text{std}(R)}{\sum_{i=0}^{n}\sigma_{i}^{2}} A_{\text{final}}, \quad \sigma^{2} = \sigma_{k}^{2}\!\left(1 - \frac{\sigma_{k}^{2}}{\sum_{i=0}^{n}\sigma_{i}^{2}}\right)$$

有关此分布如何推导的更多细节请参见附录。因此，$A_k$ 的期望值/均值是 $A_{\text{final}}$ 乘以一个常数，该常数为：

$$w(t) = \frac{\sigma_t^2 \cdot \text{std}(R)}{\sum_{i=0}^{n}\sigma_{i}^{2}}$$

注意当 $\sigma_k$ 较大时 $w(t)$ 也较大，这发生在改变最终奖励最多的时间步。因此，如果我们将调度 $w(t)$ 与 $\sigma_t$ 正确对齐，我们就可以构建PPO时间步级优势 $A_t$ 的准确估计。在我们的公式中，$\sigma_t$ 不依赖于 $s_t$ 或 $a_t$，仅依赖于时间步 $t$。这允许我们对不同轨迹普遍使用相同的 $w(t)$。

### 4.1.3 $\text{Var}(A_t)$ 的经验测量

直观上，优势方差 $\text{Var}(A_t) = \sigma_t^2$ 应该在不同扩散时间步之间变化，因为前向过程添加的噪声具有时间步相关方差 $\beta_t$。在图4中，我们通过将轨迹部分去噪到时间步 $t$，然后分支为多个去噪轨迹并计算其最终奖励的方差来估计 $\sigma_t^2$。

这在训练中是不可取的，因为需要大量分支才能准确计算方差。然而，这清楚地表明需要非均匀加权方案，并提供了预期加权趋势的初步指示。我们在这里看到单调递减的趋势（最后几步略有增加，可能是由于图像生成的随机性）。

## 4.2 策略1：逐时间步加权

之前，我们通过案例研究论证了使用非均匀加权方案的必要性。然后我们证明PPO时间步级优势可以在某些假设下从原始GRPO优势推导出来，并且它直接依赖于优势的方差。

虽然这一推导提供了理论指导，但在训练过程中精确估计这些量是不切实际的。因此，我们寻求一种简单的、实用的加权方案来近似这种行为。

我们在图5中实验了多种加权方案。

对于这种单调递减加权方案，一个明显的选择是使用用于在采样过程中添加随机性的反向扩散标准差 $\sqrt{\tilde{\beta}_t}$。（最近的工作[10]尝试在Flow-GRPO SDE中使用类似的基于噪声标准差的加权策略。）

我们还考虑将扩散模型的平均绝对潜在变化 $|z_t - z_{t-1}|$ 和均方潜在变化 $|z_t - z_{t-1}|^2$ 作为加权方案的其他选择，它们具有相同的单调性。这里，$z_t$ 是Stable Diffusion VAE潜在空间中的扩散状态。与之前的静态加权方案不同，最后一种方案是动态的，因为它依赖于潜在表示，而潜在表示又依赖于当前模型如何去噪。

最后，我们还尝试了关于采样步骤的早期、中期和晚期聚焦的高斯加权方案。这些不是单调的，但可以指示应更多关注哪个采样步骤。

我们用新的优势 $w(t) A_{\text{final}}$ 替换GRPO优势 $A_{\text{final}}$。我们的新损失为：

$$\mathcal{L}_{\text{reweighted}} = \sum_{t=1}^{n} -A_{\text{final}} \cdot w(t) \cdot \log(P_\theta(x_{t-1}|x_t, c))$$

其中 $w(t)$ 是仅依赖于转换时间步的标量。

## 4.3 重放缓冲区

到目前为止，我们专注于在时间步级别改进信用分配。我们现在解决第二个效率低下的来源：训练过程中如何复用轨迹。在经典机器人RL中，方法[24, 20, 9]经常使用重放缓冲区来存储先前epoch的先前轨迹。在训练过程中，从重放缓冲区中提取episode，与当前epoch的数据一起用于训练模型。这允许策略从比仅当前epoch轨迹更大的数据集中采样。重放缓冲区的一个扩展是优先重放缓冲区[34]，它重放具有高TD训练误差的转换，已被证明可以加速训练。

与重放缓冲区相比，GRPO在当前epoch完成后丢弃扩散轨迹。虽然这种在线采样允许方法在由最新权重生成的轨迹上进行训练，但我们认为这仍然是高度样本低效的，存储先前的轨迹在提高样本效率方面更有效。

在RLHF设置中无法获得TD误差，因为奖励仅在末端提供。这阻止了我们实现优先重放缓冲区。相反，我们实现了一个优先选择高绝对优势值的缓冲区。

## 4.4 策略2：历史难例挖掘

在此重放缓冲区公式的基础上，我们提出了一种难例挖掘策略，优先选择具有高绝对优势值的轨迹。

我们的直觉是，具有高绝对优势的轨迹，无论是强正还是强负，都包含一个或多个显著改变奖励的时间步，使其成为高度信息化的训练数据。

我们执行两种不同的轨迹重放方法：（1）轨迹级难例挖掘，我们在先前几个epoch中基于 $|A|$ 找到最高的 $k$ 条轨迹；（2）先前轨迹的随机采样。

我们发现仅保留最近几个epoch的轨迹重放缓冲区是最有利的，因为从太久之前的epoch采样会导致分布外轨迹。

总体而言，我们的方法结合了这两种策略：时间步级重新加权和轨迹级难例挖掘。两种策略都受到重新加权训练数据的想法的启发，以便在训练过程中强调更具信息量的样本。详见算法1。

从经验上看，我们发现时间步加权持续提供最高效的样本结果，有时效率高达6倍。

尽管我们的奖励函数关注图像的不同方面，但我们的时间步加权在所有情况下都提升了样本效率，如图12和图12所示。

**时间步加权的选择。** 使用我们的高斯加权方案，我们发现更重地加权较早的时间步比加权中间时间步效果更好，而加权中间时间步又比加权较晚的时间步效果更好。这表明单调递减的加权方案更可取。作为参考，均匀（未加权）加权的样本效率介于中期和早期聚焦方法之间。

在我们的实验中，在所有奖励函数上表现最一致的方案是均方潜在变化 $|z_t - z_{t-1}|^2$（见图12）。这甚至优于最近工作TempFlow[10]提出的DDIM采样标准差。我们相信这种方案效果良好，因为它为模型对潜在表示做出最大变化的时间步分配了更高的权重。通过在奖励对齐训练中优先考虑这些高变化时间步——而非使用固定系数——模型被更有效地引导向更好的奖励。

# 6 结论

在本文中，我们提供了一种简单但有效的方法来增强扩散RLHF的样本效率。我们的方法易于适应现有RLHF平台，并有可能在保持提示遵循度和泛化到新颖提示能力的同时，将训练速度提高多达6倍。我们的方法偏离了每个时间步对输出奖励影响相同的常见RLHF假设。我们的方法基于这样的直觉：在训练过程中，某些时间步和某些轨迹比其他更具信息量。未来的方向可以分析不同的调度器和 $\alpha$-调度如何影响训练样本效率，或将方法扩展到基于偏好的模型如D3PO[52]。

## A.4 $A_k$ 均值为 $\frac{\sigma_k^2 \cdot \text{std}(R)}{\sum_{i=1}^{n}\sigma_{i}^{2}} A_{\text{final}}$ 的证明

我们想找到 $A_k$ 的概率分布，其中我们假设每个 $A_i$ 的均值为0，标准差为 $\sigma_i$，$i \in \{0, 1, 2, \ldots, n\}$。此外，我们有条件：对于给定常数 $C$，

$$A_0 + A_1 + A_2 + \ldots + A_n = C$$

为简化符号，假设 $k = 0$。证明可以轻松推广到其他 $k$ 值。

令 $B = A_1 + A_2 + \ldots + A_n$。$B$ 的均值是 $A_1 + A_2, \ldots, A_n$ 均值之和，即0。$B$ 的方差是 $A_1 + A_2, \ldots, A_n$ 方差之和。这意味着 $\sigma_B^2 = \sigma_1^2 + \sigma_2^2 + \ldots + \sigma_n^2$。最后，高斯分布之和仍为高斯分布。因此，

$$B = A_1 + A_2 + A_3 + \ldots + A_n \sim \mathcal{N}(0, \sigma_B^2)$$

我们可以将问题重写为找到分布 $A_0 | A_0 + B = C$。对于给定值 $a$ 使得 $A_0 = a$，

$$P(A_0 = a | A_0 + \ldots + A_n = C)$$ $$= P(A_0 = a | A_0 + B = C)$$ $$= P(A_0 = a \;\&\; A_0 + B = C) / P(A_0 + B = C)$$ $$= P(A_0 = a \;\&\; B = C - a) / P(A_0 + B = C)$$ $$\propto P(A_0 = a \;\&\; B = C - a)$$ $$= P(A_0 = a) P(B = C - a)$$ $$= \frac{1}{\sqrt{2\pi\sigma_0^2}} \exp\left(-\frac{a^2}{2\sigma_0^2}\right) \cdot \frac{1}{\sqrt{2\pi\sigma_B^2}} \exp\left(-\frac{(C-a)^2}{2\sigma_B^2}\right)$$ $$= \frac{1}{2\pi\sigma_0\sigma_B} \exp\left(-\frac{a^2}{2\sigma_0^2} - \frac{(C-a)^2}{2\sigma_B^2}\right)$$ $$\propto \exp\left(-\frac{a^2}{2\sigma_0^2} - \frac{(C-a)^2}{2\sigma_B^2}\right)$$

经过配方法化简后，最终结果是一个均值为

$$\mu = C \frac{\sigma_0^2}{\sigma_0^2 + \sigma_B^2} = C \frac{\sigma_0^2}{\sigma_0^2 + \sigma_1^2 + \ldots + \sigma_n^2}$$

方差为

$$\frac{\sigma_0^2 \sigma_B^2}{\sigma_0^2 + \sigma_B^2} = \sigma_0^2 \left(1 - \frac{\sigma_0^2}{\sum_{i=0}^{n}\sigma_i^2}\right)$$

的高斯分布。

令 $C = \text{std}(R) A_{\text{final}}$，我们得到在 $A_0 + A_1 + \ldots + A_n = \text{std}(R) A_{\text{final}}$ 假设下 $A_0$ 的分布均值为

$$\mu = \frac{\sigma_0^2}{\sigma_0^2 + \sigma_1^2 + \ldots + \sigma_n^2} \text{std}(R) A_{\text{final}}$$
