摘要

多模态医学AI需要一个通用的视觉接口来编码异构的影像学证据，用于患者状况建模。然而，现有的医学视觉分词器通常绑定于特定维度和成像模态，迫使多模态系统依赖于碎片化且难以复用的表示。我们提出了MedVTok，一种通用视觉分词器，可将来自多种成像模态的2D图像和3D体积映射到统一的token空间中。构建这样的分词器面临两个关键挑战：跨维度保持解剖结构以及跨模态捕获临床语义。为此，MedVTok引入了 切片微分正则化，显式建模先前逐像素/逐体素监督中缺失的切片间解剖连续性；以及 多专家表示对齐，整合来自多个医学专家编码器的知识，同时保留模态特定的互补知识。MedVTok在9种成像模态的2800万张图像和7万个体积数据上训练，通过单一分词器支持分类、检索、分割、合成、视觉问答和医学报告生成。在24个基准测试中，MedVTok取得了最先进的性能，展示了一种可扩展的token接口，统一了医学图像的维度、模态和任务用途。

1 引言

多模态医学AI旨在整合异构的患者证据，包括实验室测量、纵向记录和医学图像，以形成对患者状况的整体理解。随着该领域从孤立的任务特定模型向通用多模态系统转变[1,2,3]，一个核心需求是一个共享接口，通过它可以将多样化的临床证据进行编码、传输和跨任务复用。在这些证据来源中，医学图像特别丰富且高维，捕获了解剖结构、病理发现和疾病进展。因此，视觉分词化作为关键的前端，将原始影像数据转换为与多模态模型兼容的紧凑视觉token。

然而，医学影像数据在模态和维度上都高度异构，包括2D图像如皮肤镜图像、彩色眼底照片（CFP）和组织病理切片，以及3D体积如计算机断层扫描（CT）和磁共振成像（MRI）。这些数据在采集协议、解剖覆盖和诊断内容上各不相同。现有的医学视觉分词器通常绑定于特定模态和维度，产生难以在多模态系统中复用的碎片化表示。因此，下游模型必须承担模态适应和跨模态表示学习的重担[4]。

一个通用医学视觉分词器应该提供跨模态的单一token接口，同时原生支持2D图像和3D体积。构建这样的分词器面临两个关键挑战：

跨维度保持结构保真度。 与2D图像不同，3D扫描呈现体积连续性，器官、血管、病变和组织边界跨越相邻切片。现有分词器通常专门针对2D或3D设置[5,6]，或针对局部外观保真度或逐像素/逐体素重建进行优化[7,8]，未能编码切片间结构。

跨模态捕获多模态语义。 不同模态可能描述相关的临床概念同时展示不同的证据，例如组织病理学揭示细胞和组织水平的形态，而CT和MRI捕获器官水平的解剖。现有语义对齐策略通常从单个预训练语义编码器学习不同成像模态的表示[9,10,6,11]，这可能低估了该编码器表示空间之外的模态特定语义。

本文提出了MedVTok，一种通用医学视觉分词器，将来自多种成像模态的异构2D图像和3D体积映射到统一的token空间中。为保持跨维度结构保真度，MedVTok在逐像素/逐体素监督之外引入了切片微分正则化（SliDR），显式建模切片间体积连续性。为捕获跨模态临床语义，MedVTok提出了多专家表示对齐（MERA），构建一个整合来自多个模态专用专家知识的共享表示空间，而非单一专家，同时保留每个专家表示空间中的互补语义。

为大规模训练和评估MedVTok，我们策划了一个涵盖9种模态的大规模医学影像语料库，包含超过2800万张2D图像和7万个3D体积。我们在6种任务类型上评估MedVTok：分类、分割、检索、合成、视觉问答和医学报告生成，涵盖24个基准测试的广泛实用性。我们的结果表明MedVTok取得了最先进的性能，展示了统一医学图像维度、模态和下游任务用途的可扩展token接口的价值。

贡献。 我们的主要贡献如下：
我们提出了MedVTok，一种通用医学视觉分词器，提供跨多种成像模态的共享token接口，并原生支持2D图像和3D体积。
我们提出了一种多级监督策略，将切片间连续性的切片微分正则化与跨模态临床语义的多专家表示对齐相结合。
我们策划了一个大规模医学影像语料库，并在24个基准测试上进行了全面评估，展示了MedVTok在分类、分割、检索、合成、视觉问答和医学报告生成方面的广泛实用性。

2 相关工作

跨2D和3D医学影像的Token化。 视觉分词器将图像转换为紧凑的token同时保持结构保真度[12,7]。最近的分词器[13,9]进一步探索了单一分词器如何处理异构视觉格式如图像和视频。然而在医学影像中，分词器通常绑定于特定的输入维度[5,6]。一些工作通过将3D权重池化为2D[8]或复制2D图像以适应3D模型[14]来探索对不同维度的适应。虽然这些方法可以同时处理2D和3D输入，但它们没有考虑每种维度的各自特性，例如体积中的面间解剖连续性，因此无法完全保持跨输入形式的结构保真度。相比之下，MedVTok引入切片微分正则化来显式保持体积数据中的解剖连续性，并通过维度无关的patch化提供统一的2D-3D token接口。

跨医学影像模态的语义表示。 医学图像表示学习已经产生了广泛的生物医学编码器和模态专用专家模型。通用医学编码器[15,16,17,18,19]从大规模生物医学数据中学习可迁移的表示，提供跨医学领域的广泛覆盖，但可能缺少专科特定的线索。同时，专用编码器在单个成像模态或专科中捕获更精细的临床语义[20,21,22,23,24,14,25,26]，但仍然孤立于不同的表示空间中。现有分词器[5,6]仅部分捕获了这些不同的语义，例如MedITok[6]将其表示与单个语义编码器[15]的表示对齐，从而继承了单专家偏差并限制了跨模态互补知识的学习。MedVTok则使用多专家表示对齐将来自多个医学专家的知识整合到单一token空间中，同时保留模态特定的语义。

图2：MedVTok训练框架概览。MedVTok学习 在重建损失 ℒ_R 加上切片微分正则化 ℒ_SliDR 下跨2D和3D输入的结构保真度，以及 由 ℒ_MERA = ℒ_shared + ℒ_expert 驱动的跨模态临床语义。

3 方法

3.1 MedVTok概述

MedVTok学习一个统一的潜在空间，通过两种互补的监督机制捕获2D和3D数据的结构保真度和临床语义： 切片微分正则化，保持超出逐体素重建所能捕获的体积解剖连续性（§3.2）；以及 多专家表示对齐（MERA），将来自多个模态特定专家编码器的临床知识整合到共享token空间中（§3.3）。图2展示了训练框架。

具体而言，给定输入图像或体积 x ∈ ℝ^(C×T×H×W)，其中T=1表示图像，T>1表示体积，MedVTok首先将其划分为N个大小为C×P_t×P_h×P_w的非重叠patch，其中N = THW/(P_t·P_h·P_w)。批次中来自不同样本的patch被连接成一个序列，每个patch关联一个记录其在原始输入中位置的坐标。这使得可变分辨率和混合维度批处理成为可能。然后，Transformer编码器E使用从坐标导出的旋转位置嵌入[27]，将序列映射为逐patch token h = E(x) ∈ ℝ^(N×d)。

这些token一方面通过KL散度项 ℒ_KL 进行正则化，在投影和重参数化后施加标准高斯约束；另一方面，它们由解码器D处理以重建原始输入 x̂。重建由重建损失 ℒ_R 和提出的切片微分正则化 ℒ_SliDR 监督。同时，聚合头f将token h 聚合为整体表示 r = f(h) ∈ ℝ^d，¹用于通过MERA进行语义对齐。

¹我们发现，与先前工作中使用的注意力池化[28,9]不同，采用带线性层的简单均值池化可以改善密集任务同时在其他任务上保持性能（§4.3）。

3.2 切片微分正则化

在断层扫描体积如CT和MRI扫描中，相邻切片共享强烈的解剖上下文：器官沿深度轴连续延伸，其边界从切片到切片逐渐移动。逐体素重建损失如ℓ₁可能产生单独准确但呈现面间不连续性的输出，损害诊断效用。我们通过切片微分正则化来解决这个问题，它作用于切片间连续性而非单个体素。

对于沿深度轴具有T>2个切片的3D体积，令 x(k) 和 x̂(k) 分别表示输入和重建的第k个轴向切片。我们定义一阶和二阶切片微分 Δ_k(x) = x(k+1) - x(k) 和 Δ²_k(x) = x(k+1) - 2x(k) + x_(k-1)，并对输入和重建转换之间的差异进行惩罚：

ℒ_SliDR = (1/(T-1)) Σ_{k=1}^{T-1} ‖Δ_k(x̂) - Δ_k(x)‖₁ + (1/(T-2)) Σ_{k=2}^{T-1} ‖Δ²_k(x̂) - Δ²_k(x)‖₁ (1)

其中第一项匹配切片间转换，第二项保持面间曲率。

3.3 多专家表示对齐

除了结构保真度外，统一的医学视觉分词器还应编码高级临床语义。在医学影像的全部范围内实现这一点具有挑战性，因为不同模态嵌入不同的知识。对齐到单一专家[15,6]限制了分词器继承单一语义几何，这可能低估了专家训练分布之外的模态。因此我们提出多专家表示对齐（MERA），使用一组预训练的模态特定编码器作为语义专家。MERA涉及两个目标： 共享空间对比对齐，将来自多个模态专家的表示联合对齐到共享空间；以及 专家空间互补对齐，在每个模态专家的表示空间中保留互补信息。

共享空间对比对齐。 成像模态m(i)的输入 xi 被路由到相应的专家 E{m(i)} 以产生特征 ei = E{m(i)}(xi)，该特征将被线性投影到共享空间，得到 ẽ_i = p{m(i)}(e_i) ∈ ℝ^d。然后我们在批次内使用可学习温度τ在MedVTok的表示 r_i 和专家特征 ẽ_i 之间应用对比损失 ℒ_shared：

ℒ_shared = -(1/2B) Σ_{i=1}^{B} [log(exp(ri·ẽ_i/τ)/Σ{j=1}^{B}exp(ri·ẽ_j/τ)) + log(exp(r_i·ẽ_i/τ)/Σ{j=1}^{B}exp(r_j·ẽ_i/τ))] (2)

专家空间互补对齐。 注意到ℒ_shared将异构专家特征投影到单一空间，这可能丢弃每个专家原生空间中存在的模态特定细微差别。为解决这个问题，我们引入专家空间互补学习。对于每个模态m(i)，反向投影器 q_{m(i)} 将 ri 映射回专家空间，得到 r̃_i = q{m(i)}(ri) ∈ ℝ^{d{m(i)}}。然后我们在反向投影表示和原始专家特征之间强制余弦相似性：

ℒ_expert = (1/B) Σ_{i=1}^{B} (1 - r̃_i·e_i/(‖r̃_i‖·‖e_i‖)) (3)

总之，ℒ_shared和ℒ_expert提供双向表示对齐：前者将MedVTok锚定在单一表示空间中，而后者保留可能在共享空间投影中被压缩掉的模态特定专家知识。MERA的总损失为：

ℒ_MERA = ℒ_shared + ℒ_expert (4)

3.4 训练与推理

MedVTok使用组合目标进行训练：

ℒ = ℒ_R + λ_KL·ℒ_KL + λ_SliDR·ℒ_SliDR + λ_MERA·ℒ_MERA (5)

其中标准的[7,29,10]重建损失ℒ_R由像素级、LPIPS[30]和对抗损失组成。训练分两个阶段进行：阶段1仅使用2D图像构建基础视觉结构和语义能力，其中λ_SliDR=0；阶段2继续在2D图像和3D体积上训练，λ_SliDR=0.1。

在推理时，MedVTok作为通用分词器：给定图像或体积，它编码的token直接被下游模型消费，并可跨各种任务迁移而无需进一步微调分词器。

4 实验

4.1 预训练

训练数据。 我们通过聚合现有的大规模公开可用的训练就绪数据集来准备训练数据，以确保图像质量和多样性。总共，我们获得了28,769,502张图像和70,144个体积用于训练MedVTok。

实现细节。 我们使用AdamW[31]优化器，(β₁,β₂)=(0.9,0.95)，每阶段100K步的余弦退火调度。学习率在阶段1从10⁻⁴衰减到10⁻⁵，在阶段2从2×10⁻⁵衰减到2×10⁻⁶，其中λ_KL=10⁻⁶，λ_MERA=1，λ_SliDR=0.1。在阶段2训练期间，2D和3D数据以交替迭代方式输入MedVTok，2D图像的有效批次大小为600，3D体积为48。

4.2 下游任务评估

评估协议。 我们将MedVTok与医学领域分词器[6,5,8]和通用领域分词器[29,4,32,10,9]进行比较。我们首先通过自编码重建评估不同分词器的token保真度，然后在6个下游任务上评估token表示质量：图像分类、图像到图像检索、图像分割、图像合成、视觉问答（VQA）和医学报告生成。所有评估使用冻结的分词器，关注编码token的质量而非构建任务特定模型。

评估数据。 Token保真度、分类和检索评估共享9个基准测试：JSIEC（眼底，视网膜疾病）[33]、ChestCTScan（CT，胸部癌症）[34]、HAM10K（皮肤镜，皮肤疾病）[35]、BRISC（MRI，脑肿瘤）[36]、PolypDiag（内镜，息肉检测）[37]、OCTDL（OCT，视网膜疾病）[38]、LungHist700（病理，肺癌）[39]、BUSBRA（超声，肿瘤分期）[40]和Kermany（X射线，肺炎）[41]。

分割数据集包括MaplesDR（眼底，视盘/视杯）[42]、MosMedDataPlus（CT，COVID-19病变）[43]、HAM10K（皮肤镜，病变）[35]、PolypDB（内镜，息肉）[44]、BRISC（MRI，脑肿瘤）[36]、PanNuke（病理，不同细胞）[45]、BUSBRA（超声，肿瘤）[40]和VinDr-RibCXR（X射线，肋骨）[46]。

图像合成使用GMAI-VL-5.5M[1]数据集的图像。VQA基准测试包括GMAI-MMBench[47]、Fundus-MMBench[48]、PathVQA[49]、MM-Skin[50]、Kvasir-VQA-x1[51]和SLAKE[52]。对于3D任务，我们使用AMOS-MM[53]和MRISegmenter[54]评估3D token保真度。AMOS-MM CT-报告对用于报告生成评估。

图5：消融研究。

MERA组件的效果。 从没有任何语义对齐的基线（图5中的E1）开始，使用单专家ℒ_shared的共享空间对比学习（E2，使用MedImageInsight[16]）在分类和分割上产生了初始改进，证实语义监督对下游理解至关重要。将ℒ_shared扩展到多个专家（E3）进一步改善了两个指标，证明一组模态特定专家提供了更全面的语义。添加专家空间互补学习ℒ_expert（E4）通过保留共享空间对比学习单独可能在共享空间投影期间压缩掉的模态特定细微差别，带来了额外的+1.53%分类增益。

聚合头设计。 用均值池化替换注意力池化[28,9]（E4→E5）在分割上产生了显著的增益。注意力池化倾向于将patch级细节折叠为全局摘要，而均值池化保留了密集预测任务关键的分布式空间信息，同时仍然实现有竞争力的分类性能。

5 结论

我们提出了MedVTok，一种通用医学视觉分词器，通过单一Transformer架构将2D图像和3D体积编码到共享表示空间中。两种互补的监督机制在不同层面塑造这个空间：切片微分正则化保持了逐体素监督所缺失的切片间保真度，多专家表示对齐从一组专家中注入模态特定的临床语义而无需配对注释。MedVTok在重建和六个下游任务中取得了最先进的结果，从像素级保真度到报告生成，证明结构保真度和语义丰富性可以在单一分词器中联合优化。

我们承认几个局限性。首先，训练数据目前侧重于常见的成像模态。其他成像模态、临床照片或医学出版物中的插图仍未探索。纳入这些将增强对现实世界临床工作流程中遇到的非标准视觉输入的泛化能力。其次，虽然MERA使用冻结的专家编码器，但在计算预算允许时，联合微调选定的专家或纳入新专家可以进一步改善领域覆盖。

我们希望MedVTok将作为可扩展多模态医学AI系统的有用构建模块，使跨异构影像证据和临床任务的患者级建模成为可能。
