摘要

长上下文模型使用稀疏或结构化注意力来避免二次方代价，然而在数十万个干扰项中检索少量相关事实时，性能会随着归一化质量随长度分散而退化。枢纽-辐条最优传输（OT）用局部窗口和K个共享枢纽上的线性规模图（由Sinkhorn缩放平衡）取代了密集的L×L矩阵。基于块级尾部细化和固定支撑传输拓扑[11, 12]，我们提出拓扑枢纽最优传输（THOT）：(1) 通过单纯形sparsemax（O(L log L)）或免排序的令牌局部阈值ReLU（O(L)）进行有界支撑容量门控，将多余干扰质量驱动至精确零；(2) 三次扫描的1+2退火行封闭Sinkhorn调度，抑制二部残差；(3) 在分批分裂因子Triton内核（BF16 Tensor Cores，FP32势）中实现精确的秩-(D+2R+1)单参考瓦片伴随；(4) 具有经验证的零未来泄漏的分块独占前缀因果变体。在NVIDIA L4上，sparsemax THOT在L=128训练，在纯任务损失（α=0）下于L=262,144达到97.40%的固定绑定零样本召回率，α=0.05时达98.83%（O(L)阈值ReLU在α=0.05时匹配，α=0时为80.60%），而softmax门控枢纽OT降至3.52%。在双向算子微基准中，我们的内核在H=8、D=64、L=262K时前向+VJP耗时100.1 ms（比潜在softmax快2.2倍，编译器临时存储小4.0倍），L=4,096时为1.34 ms对比cuDNN FlashAttention的4.37 ms；多层LM运行使用未融合路径。零样本WikiText-103多针检索达100.00%（L=65K时128/128查询），而短训练RoPE FlashAttention为0.78%，紧凑4层WikiText-4K运行显示适度的因果和掩码LM增益。

1 引言

将注意力扩展到数万或数十万令牌的序列面临两个耦合瓶颈。计算瓶颈是标准注意力的二次方O(L²)代价[34]：即使采用FlashAttention [8, 7, 27]等IO感知分块，L=262,144时密集前向加反向传播在单个中端GPU上需数秒。第二个瓶颈是归一化分散：随着无关背景令牌累积，标准softmax将严格正的概率质量分散到干扰项上，降低长上下文检索保真度[18, 14, 36, 35]，并使超出训练长度的零样本外推对位置编码或sink缓存敏感[24, 22, 38]。

一种自然的稀疏替代方案是枢纽-辐条拓扑——将半径r的局部滑动窗口与K个共享全局枢纽[2, 41]、潜在瓶颈阵列[15]或全局寄存器槽[9]结合。表述为熵正则化最优传输（OT）问题[6, 23, 31, 25, 28]，每个令牌和枢纽接收依赖于输入的路由容量，Sinkhorn矩阵缩放在O(L(r+K))条边上分配注意力质量。与无约束softmax注意力不同，边际容量约束防止枢纽坍缩到单个热门键上，并使令牌能调节自身路由预算——直接针对次二次序列模型中观察到的联想召回脆弱性[1]。

本工作直接建立在Forde [11]（引入块级可微Sinkhorn尾部细化）和Forde [12]（分析固定稀疏传输支撑上的梯度传播）基础上。将固定支撑枢纽OT扩展到端到端训练和25万令牌评估暴露了四个具体工程和建模瓶颈：

  1. Softmax容量稀释（Θ(1/(1+αL))）。即使在O(L)稀疏拓扑上，用全局softmax分配令牌容量也会为每个干扰令牌分配严格正的多余质量。在有界logit边际下，累积背景质量随序列长度增长压倒K个枢纽，将零样本联想召回率从98.31%（L=128）降至3.52%（L=262,144）。

  2. 二部枢纽路由下的有限步奇偶残差。阻断枢纽到枢纽捷径（BHH = −20）隔离了通过枢纽的两跳路由[11, 12]，但使活动子图接近二部图。在有限Sinkhorn调度中，交替的行和列更新留下5%–6%行边际残差，除非展开六次或更多昂贵扫描。

  3. 展开反向内存和瓦片填充开销。通过有限Sinkhorn扫描的朴素反向模式自动微分启动重复的宽度-D稀疏传递并产生寄存器填充浪费，使未融合OT在L=262K时比潜在softmax注意力慢4倍以上。

  4. 全序列列缩放的非因果性。标准双边Sinkhorn列归一化将未来查询耦合到较早列势中，违反自回归因果性。

我们用拓扑枢纽最优传输（THOT）解决这四个问题，专注于稀疏容量分配、精确有限扫描微分、硬件高效双向执行和严格因果分块变体：

  • 有界支撑容量门控（§3.1）。用单纯形sparsemax [20, 5]或免排序令牌局部阈值ReLU门[37]替换全局softmax容量分配，将多余干扰容量钳制到精确零。纯任务损失（α=0）下，sparsemax THOT在L=262,144保持97.40%的R=8固定绑定零样本召回率（α=0.05时98.83%）；阈值ReLU在α=0.05时以O(L)时间匹配98.83%，但α=0时降至80.60%。

  • 扫描拓扑退火和行封闭（§3.2）。从边际热启动[32]和局部度偏移开始，一次分离非周期扫描后跟两次可微二部扫描和精确行归一化，在总共三次扫描中消除行边际误差，并在非退火行封闭二部OT上提供+1.04到+1.44个百分点细化（α=0时跨种子分布更紧密）。我们还通过精确变分目标形式化保持先验的半松弛变体（THOT-SR）。

  • 精确单参考瓦片伴随和分裂因子Triton内核（§3.3，附录A）。利用有限Sinkhorn迭代间的对角重缩放，我们将扫描2–3和行封闭的所有分数梯度压缩为秩-(D+2R+1)修正子，在终端方案上以两次宽度-D稀疏传递（加∇V一次传递和四次一维标量传递）评估，与精确FP32微分匹配至4.47×10⁻⁸以内。具有BF16 Tensor Cores和FP32双势的批处理多头Triton内核[33]在H=8、D=64、L=262K达100.1 ms前向+VJP（比潜在softmax快2.2倍，编译器临时变量小4.0倍），算子微基准中L=4,096时为1.34 ms对比cuDNN FlashAttention的4.37 ms。

  • 严格因果分块传输和实证评估（§3.4–§4）。结合块局部写入OT、过去枢纽摘要上的独占前缀扫描和读取OT期间的独占块内因果前缀log-sum-exp，保证精确0.0未来依赖（通过扰动测试和反向模式雅可比验证）。因果THOT在L=262K达90.10%零样本召回率（带退火门控预热），双向sparsemax THOT在L=65,536的WikiText-103散文中达100.00%（128/128查询）零样本多针检索（α=0），紧凑4层WikiText-4K实验在因果和掩码语言建模上显示适度NLL改进。

2 背景：枢纽-辐条OT的失败模式

我们首先形式化枢纽-辐条最优传输注意力层，并诊断为什么朴素公式随干扰长度增长或有限扫描调度缩短而失败。

2.1 枢纽-辐条传输公式

考虑由L个真实令牌和K≪L个共享全局枢纽槽组成的输入序列（每注意力头N=L+K个节点）。每个真实令牌i∈{1,...,L}通过活动稀疏边集Ω连接到： 环形局部窗口{j∈{1,...,L}: min(|i−j|, L−|i−j|) ≤ r}，及 所有K个全局枢纽；每个枢纽连接到所有N个节点（枢纽到枢纽边由BHH调制）。因此|Ω| = O(L(2r+1+K))在序列长度L上线性缩放，将边数从O(L²)减至O(L)。

给定查询和键投影qi, kj ∈ ℝ^D，分数尺度sscale = D^(−1/2)，及由是否为实到实（BRR）、实到枢纽（BRH）、枢纽到实（BHR）或枢纽到枢纽（BHH）索引的学习2×2节点类型偏置矩阵B，边亲和力得分为

Sij = qi^⊤ kj / √D + Bτ(i),τ(j)，(i,j)∈Ω。(1)

给定正行边际a ∈ ℝ^N_{>0}（每查询或枢纽的发射预算）和列边际b ∈ ℝ^N_{>0}（每键或枢纽的吸收预算，平衡模式下满足Σi ai = Σj bj = T），Sinkhorn缩放[29, 6, 17]迭代更新定义Ω上传输方案Pij = exp(Sij + ui + vj)的对数空间对偶势u, v ∈ ℝ^N：

ui ← ln ai − log Σ_{j:(i,j)∈Ω} exp(Sij + vj)，(2)
vj ← ln bj − log Σ_{i:(i,j)∈Ω} exp(Sij + ui)。(3)

一旦行归一化使Σj Pij = ai，行随机注意力权重为Wij = Pij/ai，通过Y = WV = diag(a)⁻¹(PV)聚合值向量。注意单个双向THOT层在Ω上执行一跳Y = WV，更新令牌和枢纽状态；因此两跳源→枢纽→查询值传播发生在两个或更多堆叠Transformer层间（而§3.4的因果架构在每层内执行显式先写后读传输）。遵循Forde [11]，我们执行Tbase次初始扫描不跟踪梯度，并通过Ttail次扫描的短细化尾部精确反向传播。

2.2 失败模式1：1/(1+αL)容量稀释定律

假设路由门在均匀局部基线1/L之上为真实令牌分配总多余容量预算M，使bj = 1/L + b^ex_j。定义多余填充份额为落在无关干扰位置上的多余源预算比例：

填充份额 = Σ_{j∈filler} b^ex_j / Σ_{j=1}^L b^ex_j，b^ex_j = max(bj − 1/L, 0)。(4)

当多余容量通过全局softmax分配，b^ex_j = M·softmax(g)j，假设R个相关源令牌以logit边际Δ超过无关背景填充。因为softmax为每个干扰项分配严格正权重∝exp(g_fill)，若α = exp(−Δ) > 0随L增长保持有界远离零，分母扩展为R + α(L−R)。因此多余路由容量的信号份额衰减为

信号份额(L) = R / (R + (L−R)e^(−Δ)) = Θ(1/(1+αL))，(5)

反映Veličković等[36]和Vasylenko等[35]为尖锐尺寸泛化分析的softmax分散现象。从(5)看，每当学习边际Δ在长度间保持有界，精确零稀疏性是充分解；原则上，以Ω(ln L)增长的logit间隙Δ(L)（例如通过长度自适应温度[36]）也可保持非零信号份额，使长度缩放softmax门控成为未来工作的信息性对照。

图1(a)经验证实(5)：固定温度softmax门控下，Hub OT（Softmax Gate）在L=128达98.31%准确率（99.2%多余源份额），L=8,192达83.98%（67.3%份额），然后在L=131K骤降至12.24%，L=262,144降至3.52%（6.6%信号份额，93.4%多余填充份额）。具有相同结构偏置先验的非OT全局softmax注意力从12.63%降至0.65%。交叉注意到固定K=16瓶颈（Latent Softmax，遵循Jaegle等[15]）更好抵抗查询侧稀释，但键侧softmax归一化仍将多余源份额从96.2%稀释至1.4%，准确率从87.24%降至76.30%。

2.3 失败模式2：二部路由下的慢收缩和奇偶残差

一旦稀疏门控消除多余填充容量，Sinkhorn求解器内部出现有限迭代优化问题。先前枢纽路由[11]设置大负枢纽到枢纽惩罚（BHH = −20），使查询通过枢纽路由到源令牌而非在枢纽间循环质量。然而当干扰项减至1/L下限且BHH被阻断，活动路由质量集中在真实令牌（R）和枢纽（H）间的近二部子图上。

为经验量化类级混合，令F ∈ ℝ^(2×2)表示两节点类间聚合方案质量，Fc,c' = Σ_{i∈c, j∈c'} Pij（c, c' ∈ {R, H}），令Qrow = diag(F1)⁻¹F和Qcol = diag(F^⊤1)⁻¹F^⊤为相应1跳行和列归一化类转移矩阵。注意Qrow不同于列势上的全周期Sinkhorn不动点雅可比J = diag(b)⁻¹P^⊤ diag(a)⁻¹P [17]：J与正半定Gram矩阵对角相似故具有非负特征值，2×2类商M_sink = Qrow diag(γb, 1)Qcol。然而当Qrow接近二部时，次优特征值λ2(Qrow) = tr(Qrow) − 1接近−1，既在R和H分区产生交替半步奇偶不平衡，又驱动M_sink的非负两步商特征值趋向λ2(Qrow)² ≈ 1（慢收缩）。

在L=262,144诊断（表1）上，标准二部调度三次扫描后保留λ2(Qrow) = −0.9924，留下5.53%行总变差（TV）误差和仅89.4%查询到枢纽流量份额。无行封闭时在3次热启动扫描处提前停止，L=262K仅达70.57%召回率，除非扩展至6次展开扫描（96.48%）。同时，用无中心隐式梯度求解器（Uncentered Implicit-VJP OT）替换显式尾部微分无法训练（262K时0.91%）。

3 拓扑枢纽最优传输

拓扑枢纽最优传输（THOT）通过四个组件解决容量稀释、有限步二部残差、反向传递开销和自回归因果性。算法1总结双向前向传递和伴随，算法2指定严格因果分块变体，表2保持所有评估THOT变体明确分离。

3.1 有界支撑容量门控：Sparsemax和O(L)阈值ReLU

为防止多余容量在有界分数边际下泄漏到干扰项，我们在均匀1/L局部基线之上分配具有紧支撑的多余预算a^ex, b^ex：

算法1：双向THOT——前向传递和精确单参考瓦片伴随
输入： ∈ ℝ^(N×D)（N = L+K），节点类型偏置B ∈ ℝ^(2×2)，局部半径r，来自(6)或(7)的边际 ∈ ℝ^N_{>0}。
1. 热启动和度先验：设v0 ← ln b和BRR ← BRR + ln(L/min(L, 2r+1))。
2. 分离非周期扫描1：以开放枢纽到枢纽耦合BHH（停止梯度），运行一次Sinkhorn循环(2)–(3)，在活动行上中心化u1（u1 ← u^(1)raw − ū^(1)，v1 ← v^(1)_raw + ū^(1)），并分离v1 ← detach(v1)。
3. 可微二部扫描2–3：钳制BHH ← −20并从v1开始运行两次中心化Sinkhorn循环，产生原始行势和中心化对（u2, v2），（u3, v3）（THOT-SR时扫描3真实列上可选保持先验半松弛指数γb = 0.92）。
4. 精确行封闭和行随机读取：计算uout,i = ln ai − LSE{j:(i,j)∈Ω}(Sij + v3,j)，终端方案P^out_ij = exp(Sij + uout,i + v3,j)（行和ai），未归一化聚合Z = P^out V，行随机注意力输出Wij = P^out_ij/ai，Y = WV = diag(a)⁻¹Z。缓存用于反向。
5. 精确单参考瓦片伴随（反向；完整递归见附录A）：给定Ȳ，设Z̄i = Ȳi/ai（将商项−Ȳi^⊤ Yi/ai加到āi）并在一次宽度-D转置传递计算∇V = (P^out)^⊤ Z̄。通过行封闭和扫描3–2传播终端对偶敏感性，经四次轻量一维标量稀疏matvec，用相对于P^out的对角重缩放形成2R+1 = 5个标量因子列 ∈ ℝ^(N×5)。最后在单个参考方案P^out上执行两次宽度-D分裂因子稀疏传递：一次行主序传递用于（∇Q, ∇B），一次转置传递用于∇K。

单纯形sparsemax门（O(L log L)）。给定轻量令牌级MLP产生的标量路由logit s^rec, s^src ∈ ℝ^L，我们用欧几里得单纯形投影sparsemax [20, 5]替换softmax：

ai = 1/L + M·sparsemax(s^rec)_i，bj = 1/L + M·sparsemax(s^src)_j，(6)

总多余质量M = 8.0分布在真实令牌上并在K个枢纽上匹配（a^hub_h = b^hub_h = M/K，h = 1,...,K；真实令牌加枢纽总序列质量1+M）。因为sparsemax将其数据依赖阈值τ(s)以下的低logit映射到精确零，多余填充份额(4)在L = 128...262,144范围降至恒等0.00%，同时每令牌保留1/L基线用于局部窗口连接。

令牌局部阈值ReLU门（O(L)，免排序）。全局sparsemax需在所有L令牌间排序，成本O(L log L)并通过τ(s)在因果模型中耦合未来令牌。受ReLU注意力[37]启发，学习标量阈值θ^rec, θ^src ∈ ℝ（初始化−0.25）产生免排序O(L)门：

ai = 1/L + M·ReLU(s^rec,i − θ^rec) / (Σ_{m=1}^L ReLU(s^rec,m − θ^rec) + ε)，(7)

对bj对称，或流式因果模式中纯令牌局部未归一化ai = 1/L + c·ReLU(s^rec,i − θ^rec)。每当干扰logit保持在θ以下，多余填充份额(4)恒等于零，无需跨令牌排序。

3.2 扫描拓扑退火：1+2行封闭调度

为在保持总扫描深度3的同时保留干净二部路由和精确行归一化，我们使用经验有效的1+2退火行封闭调度：

  1. 边际热启动和度先验。我们在目标对数边际v0 = ln b [32]处初始化列势，并将结构度先验ln(L/d)添加到实到实边BRR（d = min(L, 2r+1)），使局部邻域随L缩放保持与枢纽平衡。

  2. 扫描1（分离非周期热启动）。保持枢纽到枢纽亲和力BHH开放而非钳制到−20，执行一次停止梯度Sinkhorn扫描并在活动令牌上中心化行势。开放BHH在L=262,144的扫描1上将1跳类特征值λ2(Qrow)从−0.99移至−0.7451（表1），在二部细化前提供良好平衡的初始化。

  3. 扫描2–3（可微二部细化）。钳制BHH ← −20在两次可微Sinkhorn循环间抑制枢纽到枢纽捷径。

  4. 精确行封闭和归一化。列更新在有限扫描计数下留下4%–5%行边际误差。执行最后一次行对数归一化uout,i = ln ai − LSE_j(Sij + v3,j)并将P^out V除以ai保证精确行随机性（行TV = 0.0000）和100.0%查询→枢纽质量利用率。

保持先验的半松弛退火（THOT-SR）。当许多活动绑定竞争较少枢纽（R > K）时，放松真实令牌列约束可减少边际残差。具有未加权参考核exp(Sij)的标准KL不平衡Sinkhorn [4]将松弛指数γb = ρb/(1+ρb)应用于整个对偶更新vj = γb(ln bj − LSE_i(Sij + ui))，这会缩小学习对数容量先验ln bj。为在放松列匹配同时保留完整学习容量先验bj，我们改用参考测度Kij = bj exp(Sij)最小化保持先验半松弛目标：

min_{P1=a, P≥0} KL(P ‖ exp(S)diag(b)) + ρb KL(P^⊤1 ‖ b)。(8)

一阶驻点lnPij = Sij + ln bj + ui − ρb ln(b̂j/bj)，其中vj := ln bj − ρb ln(b̂j/bj)和ln b̂j = vj + LSE_i(Sij + ui)得出(1+ρb)vj = (1+ρb)ln bj − ρb LSE_i(Sij + ui)，因此精确不动点更新

vj = ln bj − γb LSE_{i:(i,j)∈Ω}(Sij + ui)，γb = ρb/(1+ρb) ∈ (0,1]，(9)

应用于真实令牌列（枢纽上保持γb = 1）。从扫描1开始天真应用标准未加权半松弛更新（Naive Semi-Relaxed OT，γb = 0.85）在纯交叉熵训练下坍缩（α=0，0.13%准确率；§4.1）。在保持先验松弛前进行两次平衡扫描（THOT-SR，γb = 0.92）保持α=0稳定性（L=262K时95.57%），同时将六次扫描边际TV误差从0.0185降至0.0102（表1）。因为天真（γb = 0.85）与退火（γb = 0.92）比较同时改变调度和γb，我们还在表4评估中间退火γb = 0.88配置，α=0时仍达88.54%（α=0.05时97.53%）。

S̄ij = P^out_ij (Z̄i^⊤ Vj + Σ_{m=1}^{2R+1} L^(s){i,m} R^(s){j,m})。(10)

所有参数分数梯度（∇Q, ∇K, ∇B）然后在单个参考方案P^out上以两次宽度-D稀疏传递执行（一次行主序传递用于∇Q和∇B，一次转置传递用于∇K），加∇V的一次宽度-D转置传递。在单个D=32、L=262K头上，仅此一项将前向+VJP延迟降低1.58倍（42.17 → 26.64 ms），静态编译器临时变量缩小2.86倍（412.1 → 144.0 MiB）。

具有BF16 Tensor Cores的分裂因子多头Triton分块。我们进一步移除自定义Triton内核中四个多头GPU瓶颈：

  1. 分离特征和标量因子累加器：将宽度-D因子（Z̄, V）和宽度-(2R+1)标量因子连接到单个瓦片会强制在D=64时填充到宽度128的二次幂。保持为两个独立SRAM点积——宽度D和宽度2R+1 = 5（填充到16）——将寄存器占用减半。

  2. 原生头批网格调度：直接在GPU线程块网格中跨头和批项调度，消除每头向量化包装器，并通过谓词寄存器掩码在每次半扫描移除填充/连接HBM拷贝。

  3. 专用一维标量matvec和融合偏置梯度：四次反向递归标量传递完全跳过向量载荷分块，2×2节点类型偏置梯度∇B在行主序∇Q传递期间直接在寄存器累加（二部尾部上∇BHH = 0）。

  4. 具有FP32对偶的混合精度BF16 Tensor Cores：矩阵乘法在BF16 Tensor Cores上以FP32累加执行，而势和log-sum-exp状态严格保持FP32——类似混合精度FlashAttention [7, 27]。在L∈{128, 256}（H∈{2, 4}，D∈{32, 64}）上针对（Y, ∇Q, ∇K, ∇V, ∇a, ∇b, ∇B）的未融合FP32参考实现，FP32模式最坏情况最大绝对误差4.47×10⁻⁸（相对L2 ≤ 5.02×10⁻⁷），BF16 Tensor-Core模式3.27×10⁻⁴（FP32中独立匹配纯JAX展开密集自动微分至≤6.56×10⁻⁷以内）。

3.4 严格因果自回归分块传输

全序列Sinkhorn缩放通过(3)将未来键和查询耦合到较早势中。为支持线性时间自回归建模以及因果线性注意力、选择性状态空间和槽记忆架构[16, 13, 39, 42]，我们将序列划分为大小C=32的块，用严格因果操作替换全局排序和块内列耦合，在算法2中完整指定。

算法2：严格因果分块THOT（单注意力头）
输入：令牌张量 ∈ ℝ^(L×D)（可选位置不变写入键Kw），令牌局部容量 ∈ ℝ^L_{>0}，枢纽槽 ∈ ℝ^(K×D)，偏置B ∈ ℝ^(2×2)，块大小C=32，局部半径r。将序列划分为Nc = ⌈L/C⌉个块。

  1. 块局部写入OT（K个枢纽 ← 每块c的C个令牌）：以块分数矩阵Sw_c = sscale Q^hub_0 (K^w_c)^⊤ + BHR和枢纽容量上限κc = max((1/K)Σ_{j∈c} bc,j, max_{j∈c} bc,j)，在尺度sscale/εf（εf = 1.5）运行1次分离基础扫描，随后2次可微尾部扫描和最终列封闭：u^w_{c,k} ← −γw ReLU(LSE_{j∈c}(S^w_{c,k,j} + v^w_{c,j}) − ln κc)，v^w_{c,j} ← ln bc,j − LSE_{K k=1}(S^w_{c,k,j} + u^w_{c,k})，γw = 0.70，产生P^write_c ∈ ℝ^(K×C)满足Σk P^write_{c,k,j} = bc,j。计算块矩W^(V)_c = P^write_c Vc，W^(K)_c = P^write_c K^w_c和枢纽质量zc = P^write_c 1_C。

  2. 跨过去块（c' < c）的独占前缀累加：计算独占前缀和(M^(V){<c}, M^(K){<c}, z_{<c}) = Σ_{c'<c}(W^(V){c'}, W^(K){c'}, z_{c'})（c=0时为零），以先验权重m0 = 0.05和残差键混合β = 0.80形成归一化过去枢纽摘要：V^hub_{<c} = (m0 V^hub_0 + M^(V){<c})/(m0 + z{<c})，K^hub_{<c} = (1−β)K^hub_0 + β(m0 K^hub_0 + M^(K){<c})/(m0 + z{<c})，和有界过去枢纽容量b^hub_{<c,k} = min(Σh z_{<c,h}, M^hub) z_{<c,k}/Σh z_{<c,h}（M^hub = 8.0）。

  3. 严格因果读取OT（C个查询 ← (r+C)局部过去 + K个过去枢纽）：对块c，每个查询i∈{0,...,C−1}（全局索引t = cC+i）连接到Ω_{c,i} = {j: max(0, t−r) ≤ j ≤ t} ∪ {H_{<c,k}: c > 0, z_{<c,k} > 0}，源容量b^read_c = [b^loc_c; b^hub_{<c}]。初始化v^r_{c,i,s} = ln b^read_{c,s}并运行1次分离基础扫描、2次可微尾部扫描和最终行封闭，其中每次列归约严格在块c内较早查询0 ≤ i' < i上使用独占因果前缀log-sum-exp：u^r_{c,i} ← ln ac,i − LSE_{s∈Ω_{c,i}}(S^read_{c,i,s} + v^r_{c,i,s})，v^r_{c,i,s} ← ln b^read_{c,s} − γr LSE_{0≤i'<i} Σ_{s∈Ω_{c,i'}}(S^read_{c,i',s} + u^r_{c,i'})，γr = 0.25。返回Y_{c,i} = a^(−1){c,i} Σ{s∈Ω_{c,i}} exp(S^read_{c,i,s} + u^r,out_{c,i} + v^r_{c,i,s}) V^read_{c,s}。

因果依赖保证。考虑任何输出位置t = cC+i。 其容量 = 1/L + ReLU(st − θ)严格依赖令牌t。 其过去枢纽摘要严格聚合已完成块c' < c，其所有令牌满足t' < cC ≤ t。 其局部候选集Ω_{c,i}仅含位置j ≤ t。 关键的是，块c内读取侧Sinkhorn扫描期间，列势v^r_{c,i,s}通过独占前缀log-sum-exp严格在较早查询0 ≤ i' < i上归约，防止同块中较晚查询i' > i改变v^r_{c,i,s}。通过对有限扫描归纳，进入Yt的任何中间状态不依赖t' > t处任何输入。跨块边界的对抗性未来扰动检查和精确反向模式雅可比（∂Yt/∂{Kt', Vt', s^src_{t'}}，t < t'）验证最大泄漏恒等于0.0。

5 相关工作

稀疏、潜在、槽记忆和线性长上下文架构。Longformer [2]和BigBird [41]为线性时间Transformer引入组合局部滑动窗口和全局令牌，而Perceiver [15]通过学习潜在瓶颈阵列路由输入，Vision Transformers采用全局寄存器令牌作为路由暂存器[9]。互补线性时间方法——包括线性注意力[16]、选择性状态空间模型[13]、门控线性注意力[39]和门控槽注意力（GSA）[42]——通过并行扫描将历史压缩成循环或基于槽的记忆；GSA与我们的因果扩展（§3.4）特别相关，因为它通过具有上下文相关读取的紧凑循环槽针对联想召回，而因果THOT通过与显式局部窗口和阈值令牌容量耦合的半松弛最优传输平衡块写入和前缀读取。Arora等[1]强调次二次模型中的召回缺陷，而长上下文评估记录U形位置下降[18]、多针退化[14]及对位置外推或注意力sink的敏感性[24, 22, 38]。

可微最优传输和低秩Sinkhorn注意力。熵正则化[6, 23]使Sinkhorn缩放[29, 17]在神经层内实用，激发特征匹配[26]、不平衡/半松弛传输[4]、平滑二次传输[3]、双随机注意力[31, 25]、热启动初始化[32]及展开或隐式微分[19, 10]。与我们的枢纽介导架构密切相关的是LOTFormer [28]，它通过小的学习中间测度构造查询到枢轴和枢轴到键最优传输问题，并组合成O(nr)低秩双随机注意力算子。THOT在五个具体方面不同于LOTFormer： 将全局枢纽与局部滑动窗口带联合耦合在单个稀疏图Ω内， 用依赖输入的有界支撑令牌容量替换均匀边际以消除干扰稀释， 引入1+2退火行封闭有限扫描调度（和保持先验半松弛变体）， 推导在分裂因子BF16 Tensor-Core Triton内核实现的精确秩-(D+2R+1)单参考瓦片伴随，及 提供严格因果分块独占前缀构造。最直接地，本文建立在Forde [11]（块级Sinkhorn尾部细化）和Forde [12]（固定支撑梯度混合）基础上。

稀疏注意力归一化和抗稀释。Sparsemax [20]和α-entmax [5]用紧支撑单纯形投影替换softmax，而Wortsman等[37]研究逐点ReLU注意力缩放。与我们的抗稀释动机最一致的是Veličković等[36]，他们证明标准softmax必须在尖锐尺寸泛化上分散并研究自适应温度，以及Long-Context Generalization with Sparse Attention [35]，他们显示干扰项累积softmax质量并使用精确零稀疏注意力归一化实现高达~1,000倍合成长度外推和改进语言模型泛化。虽然Vasylenko等[35]将精确稀疏性直接应用于成对注意力权重，THOT在OT边际容量门处应用精确零稀疏性（通过sparsemax或O(L)阈值ReLU），将稀疏容量分配与线性时间枢纽和局部传输图及自定义Triton内核配对。

IO感知注意力和OT内核。FlashAttention家族[8, 7, 27]通过SRAM分块和以CUDA或Triton [33]实现的混合精度Tensor Cores避免O(L²) HBM具体化。密集熵最优传输方面，FlashSinkhorn [40]最近为完整N×N Sinkhorn缩放引入IO感知流式Triton内核。我们的分裂因子Triton内核将类似SRAM分块和BF16 Tensor Cores直接应用于稀疏枢纽-辐条图，同时保持双势严格FP32并将所有有限尾部分数梯度压缩到两次宽度-D参考瓦片传递中。

6 局限性、可复现性和结论

局限性。我们强调当前研究的五个边界：

  1. 算子与全模型内核集成：我们的分裂因子BF16 Tensor-Core内核在独立双向算子上基准测试（262K时100.10 ms；4K时1.337 ms对比4.368 ms cuDNN FlashAttention），而多层WikiText-4K训练循环在未融合路径上运行（MLM 174.15 ms/步对比密集136.32 ms；因果211.41 ms/步对比密集126.45 ms）。因此更快的端到端语言模型训练尚未得到证明，需要将Triton内核连接到完整多层双向和因果堆栈。

  2. 静态编译器与运行时内存：报告的内存数字反映静态XLA编译器临时估计而非动态峰值运行时VRAM配置文件，4.0倍编译器临时减少严格相对于Latent Softmax（非FlashAttention）。

  3. 固定绑定检索与信息容量缩放：我们的262K外推基准在扩展干扰项时保持R=8相关绑定固定；枢纽过载（R=32对比K=16）下召回率降至38%–40%。联合缩放R、K和L仍是重要未来工作。

  4. 初步LM规模和密集基线诊断：我们的WikiText-4K实验使用紧凑4层（D=256，V=2,048，512–640步，2种子）模型，与附近结构化基线相比有适度0.015–0.016 nat边际，且散文针密集基线将RoPE外推与注意力分散混淆。诊断为什么密集MLM基线保持接近单字（6.3424对比6.4788）和添加仅内容（无RoPE）密集检索对照是后续修订的优先事项。

  5. 变体权衡：免排序O(L)阈值ReLU依赖α=0.05在262K匹配sparsemax（98.83%对比α=0时80.60%），因果召回使用步骤1–256内退火门控预热，非退火行封闭二部OT在α=0下非零碰撞压力上超过退火THOT。

可复现性和代码可用性。所有实验在NVIDIA L4 GPU上以JAX（0.11.1，jaxlib 0.11.1，NumPy 2.4.6）运行，具有固定随机种子、确定性数据生成器和跨比较臂的匹配参数预算。关键实验配置、评估计数和各每种子结果见附录A。涵盖容量门、批处理分裂因子THOT内核（具有用于CPU验证的精确纯JAX参考）和严格因果分块算子的简明独立JAX/Triton参考实现随本手稿提供。关于arXiv:2609.07954的通知：本手稿用稀疏容量门控、有限扫描退火、精确Triton伴随内核、因果分块和实证长上下文基准扩展了我们早期的固定支撑传输分析。

结论。拓扑枢纽最优传输将有界支撑容量门控、1+2退火行封闭Sinkhorn调度、在分裂因子BF16 Tensor-Core Triton内核实现的精确秩-(D+2R+1)单参考瓦片伴随和严格因果独占前缀分块变体配对。受控消融将稀疏容量分配隔离为防止1/(1+αL)干扰坍缩的决定性因素（L=262K纯交叉熵召回率3.52% → 97.40%），而算子微基准显示线性时间双向OT已在L=4,096超过cuDNN FlashAttention（1.34对比4.37 ms），并在L=262K比潜在softmax快2.2倍运行。将这些内核集成到更大规模完整多层因果和双向语言模型中是自然的下一步。

A.1 算法1的精确单参考瓦片伴随

我们推导由批处理Triton内核为算法1中双向1+2退火行封闭算子实现的精确反向模式向量-雅可比积（VJP）（R=2次可微二部尾部扫描，BHH = −20，跟随分离非周期热启动势v1）。令A = {i: ai > 0}和B = {j: bj > 0}表示活动行和列，|A| = Σi 1[i∈A]。

为反向缓存的前向状态。算法1中，扫描t∈{2, 3}在二部边分数S下从v1 = detach(v1)迭代：

u^(t){raw,i} = ln ai − LSE{j∈Ω(i)}(Sij + v_{t−1,j})，st = (1/|A|) Σ_{i∈A} u^(t){raw,i}，
u{t,i} = u^(t){raw,i} − st，v{t,j} = ln bj − LSE_{i∈Ω^⊤(j)}(Sij + u^(t)_{raw,i}) + st，(11)

随后精确行封闭uout,i = ln ai − LSE_{j∈Ω(i)}(Sij + v3,j)，终端方案P^out_ij = exp(Sij + uout,i + v3,j)，未归一化聚合Z = P^out V，和行随机注意力输出Yi = Zi/ai。前向执行缓存（Z, v1, u^(2)_raw, s2, v2, u^(3)_raw, s3, v3, uout）（每头总存储O(N)标量加Z），消除反向期间所有五次重计算log-sum-exp传递。

步骤1：商归一化和终端值传递。给定上游损失梯度Ȳ = ∂ℓ/∂Y，微分Yi = Zi/ai得出未归一化聚合余切Z̄i = Ȳi/ai及直接归一化边际贡献ā^norm_i = −(Ȳi^⊤ Yi)/ai。微分Z = P^out V通过一次宽度-D转置稀疏传递给出值梯度：

∇V = (P^out)^⊤ Z̄ = W^⊤ Ȳ，(12)

和非零终端对数势敏感性

g_{u,i} = Z̄i^⊤ Zi = Ȳi^⊤ Yi，g_{v,j} = V_j^⊤ (∇V)_j，(13)

具有直接分数梯度E^direct_ij = P^out_ij (Z̄i^⊤ Vj)。

步骤2：终端行封闭反向步骤。使用Σj P^out_ij = ai微分uout,i = ln ai − LSE_j(Sij + v3,j)得出

r^out_i = g_{u,i}/ai（i∈A），ā ← ā^norm + r^out，g_v ← g_v − (P^out)^⊤ r^out，(14)

并添加秩-1分数贡献−P^out_ij r^out_i（注意ā^norm_i + r^out_i = 0，确认行随机Yi = Zi/ai在尾部扫描外对ai具有零净直接敏感性）。

步骤3：通过扫描t = 3, 2的精确反向递归。定义中间方案P^(t)ij = exp(Sij + u{t,i} + v_{t,j})（列和满足(P^(t))^⊤1 = b）和P^(t){raw,ij} = exp(Sij + u^(t){raw,i} + v_{t−1,j})（行和满足P^(t)_{raw}1 = a）。对t = 3然后t = 2（注意进入时gu = 0，因为u3, u2在其自身扫描外未使用）：

c_{t,j} = g_{v,j}/bj（j∈B），d_{c,t} = (1/|A|) Σ_{j∈B} g_{v,j}，r_{t,i} = (d_{c,t} − (P^(t) c_t)i)/ai（i∈A），(15)
ā ← ā + r_t，b̄ ← b̄ + c_t，g_v ← −(P^(t){raw})^⊤ r_t（仅t = 3），

其中v1被分离，故不需要传播超过t = 2。每次扫描t贡献−P^(t)ij c{t,j} − P^(t){raw,ij} r{t,i}到边分数伴随S̄ij。跨步骤2–3，整个向量递归仅需四次轻量一维标量稀疏matvec：(P^out)^⊤ r^out，P^(3) c3，(P^(3)_{raw})^⊤ r3，和P^(2) c2。

步骤4：到P^out上的精确对角重缩放分解。关键的是，因为中间方案P^(t)和P^(t)_{raw}在Ω上与终端方案P^out不同，其分数贡献不会坍缩为秩-2加性行加列项αi + βj。相反，每个中间方案是P^out的精确秩-1对角重缩放：

P^(t)ij = P^out_ij exp((u{t,i} − uout,i) − µ_{u,t}) exp((v_{t,j} − v3,j) + µ_{u,t})，
P^(t){raw,ij} = P^out_ij exp((u^(t){raw,i} − uout,i) − µ_{raw,t}) exp((v_{t−1,j} − v3,j) + µ_{raw,t})，(16)

其中平均势偏移µ_{u,t} = (1/|A|) Σ_{i∈A}(u_{t,i} − uout,i)和µ_{raw,t} = (1/|A|) Σ_{i∈A}(u^(t)_{raw,i} − uout,i)在乘积内恒等抵消同时防止浮点溢出。将终端行封闭项和2R = 4个重缩放尾部项收集到两个(N×5)因子矩阵

L^(s) = [−r^out, −e^u_3, −e^raw_3 ⊙ r3, −e^u_2, −e^raw_2 ⊙ r2] ∈ ℝ^(N×(2R+1))，
R^(s) = [1_B, e^v_3 ⊙ c3, e^prev_3, e^v_2 ⊙ c2, e^prev_2] ∈ ℝ^(N×(2R+1))，(17)

行封闭和扫描2–3的精确总边分数伴随为

S̄ij = P^out_ij (Z̄i^⊤ Vj + Σ_{m=1}^{2R+1} L^(s){i,m} R^(s){j,m})。(18)

因此∇Q = sscale S̄K（连同融合节点类型偏置和∇B_{c,c'} = Σ_{(i,j)∈Ω_{c,c'}} S̄ij，钳制∇BHH = 0）和∇K = sscale S̄^⊤ Q在单个参考方案P^out上以两次宽度-D分裂因子稀疏传递执行（从朴素展开微分中12次宽度-D分数梯度传递降低）。L∈{128, 256}（H∈{2, 4}，D∈{32, 64}）上的GPU验证中，该精确自定义VJP在FP32匹配未融合参考实现至≤4.47×10⁻⁸最大绝对误差（≤5.02×10⁻⁷相对L2），BF16 Tensor-Core模式≤3.27×10⁻⁴，FP32中跨所有六个输入梯度（∇Q, ∇K, ∇V, ∇a, ∇b, ∇B）匹配纯JAX展开密集自动微分至≤6.56×10⁻⁷以内。
