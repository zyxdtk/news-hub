金融服务智能体

📅 2026-05-05 📄 Anthropic 🔗 原文链接

原标题：Agents for financial services

中文摘要： Anthropic发布了十个面向金融服务的即用型AI智能体模板，涵盖构建推介材料、KYC筛选和月末结账等耗时工作。这些模板可作为插件或Cookbook使用，使团队在数天内即可部署。同时，Claude现已通过加载项支持跨Excel、PowerPoint、Word和Outlook工作，实现上下文自动流转。此外，通过新增的连接器和MCP应用，Claude可实时访问更多市场数据。这些更新与在金融任务上表现最佳的Claude Opus 4.7完美搭配，助力金融机构提升效率。

我们正在发布十个即用型智能体模板，用于处理金融服务中最耗时的工作：构建推介材料、筛选KYC文件以及月末结账。每个模板都作为 Claude Cowork 和 Claude Code 中的插件，以及 Claude Managed Agents 的 cookbook 发布，因此团队可以在几天而不是几个月内让 Claude 投入实际的金融工作中。

通过适用于 Microsoft 365 的 Claude 加载项，Claude 现在还可以跨 Microsoft Excel、PowerPoint、Word 和 Outlook（即将推出）工作。一旦安装了加载项，上下文就会在应用程序之间自动传递，因此在模型中开始的工作可以在演示文稿中结束，而无需在中间重新解释任何内容。

最后，我们正在通过新的连接器和 MCP 应用程序继续扩展我们的合作伙伴生态系统，以便智能体能够利用金融专业人士已经在使用的数据。连接器为 Claude 提供了对提供商数据的受治理的实时访问，而 MCP 应用程序则更进一步，将提供商自己的工具直接嵌入到 Claude 中。

这些更新与 Claude Opus 4.7 配合使用效果最佳，后者在金融任务上处于最先进水平，并在 Vals AI 的金融智能体基准测试中以 64.37% 的得分领先业界。

面向金融工作的新型智能体模板

每个智能体模板都是一个参考架构，它打包了三样东西：技能（任务指令和领域知识）、连接器（对任务运行数据的受治理访问）和子智能体（主智能体为特定子任务（如可比公司选择或方法论检查）调用的额外 Claude 模型）。公司可以对其中的任何一个进行调整，以适应自己的建模惯例、风险政策和审批流程。

可以在 Claude Cowork 或 Claude Code 中作为插件启用这些新的智能体模板，或者作为 Claude Managed Agents 的 cookbook 启用。在金融服务市场中找到所有插件和 cookbook。

新智能体的完整列表如下：

研究与客户覆盖
* 推介材料构建器 创建目标列表，运行可比公司分析，并为客户会议起草推介材料；
* 会议准备器 在通话前汇总客户和交易对手简报；
* 财报审查器 阅读记录和文件，更新模型，并标记与投资主题相关的变化；
* 模型构建器 根据文件、数据源和分析师输入创建和维护财务模型；
* 市场研究员 跟踪行业和发行人动态，综合新闻、文件和经纪商研究，并标记出需要进行信贷和风险审查的项目。

财务与运营
* 估值审查器 根据可比公司、方法论和公司的审查标准检查估值；
* 总账对账器 对总账账户进行对账，并根据记录账簿运行净资产值计算；
* 月末结账器 运行结账清单，准备日记账分录，并生成结账报告；
* 报表审计器 审查财务报表的一致性、完整性和审计准备情况；
* KYC筛选器 汇总实体文件，审查源文件，并打包升级事项以供合规审查。

有两种方法可以将它们投入使用。

作为 Claude Cowork 或 Claude Code 中的插件，该模板与分析师并行运行，使用他们桌面上已有的软件。将目标列表交给推介智能体，你就可以在 Excel 中获得一个可比公司模型，在 PowerPoint 中生成一份起草的推介材料，并在 Outlook 中准备好一封附言。

作为 Claude Managed Agent，相同的模板在 Claude 平台上自主运行，适用于跨越整个交易账簿或夜间计划的工作。Cookbook 使用公司原本需要自己设计的构建块来搭建它：可以在长达数小时的交易结账过程中工作的长时间运行会话、每个工具的权限、托管凭证库，以及 Claude 控制台中的完整审计日志，合规和工程团队可以在其中检查每个工具调用和决策。

在这两种情况下，用户都始终处于闭环中——在 Claude 的工作发送给客户、归档或执行之前，对其进行审查、迭代和批准。

Claude 跨 Excel、PowerPoint、Word 和 Outlook 工作

通过加载项，Claude 可以直接在 Microsoft Excel、PowerPoint、Word 和 Outlook 中工作。

在 Outlook 中，它可以充当参谋长，对您的收件箱进行分类，安排会议，并以您的语气起草回复。在 Excel 中，它根据文件和数据源构建财务模型，跨链接的工作簿审计公式，并运行敏感性分析。在 PowerPoint 中，它起草当基础数字改变时自动更新的演示文稿。在 Word 中，它根据公司自己的模板编辑信用备忘录。Claude 在所有四个平台上都保持其知识和上下文：在 Excel 中启动了模型的分析师，当该工作转移到 PowerPoint 时，不需要重新解释它。

在 Claude Cowork 中，用户还可以使用 Dispatch 从任何地方通过文本或语音为 Claude 分配工作任务。Claude 可以在分析师离开办公桌时继续处理他们的本地文件，等他们回来时，完成的工作已准备好接受审查。

最广泛的金融服务生态系统

AI 智能体的好坏取决于它能访问的数据和上下文。Claude 连接到数十个市场数据、研究平台和金融公司的内部系统——包括 FactSet、S&P Capital IQ、MSCI、PitchBook、Morningstar、Chronograph、LSEG 和 Daloopa——以及公司自己的数据仓库、研究存储库和 CRM，所有这些都在受治理的访问控制之下。

我们现在正在添加来自新合作伙伴的连接器和 MCP 应用程序。新的连接器提供对市场和研究数据的直接实时访问，而 MCP 应用程序则直接在 Claude 中显示自定义的交互式 UI。

新的连接器包括：
* Dun & Bradstreet，提供经验证的商业身份的全球标准，帮助企业连接记录系统并扩展支持 AI 的工作流；
* Fiscal AI，将实时基本面覆盖范围扩展到公共股票，以进行更深入的研究和基准测试；
* Financial Modeling Prep，提供跨股票、ETF、加密货币、外汇和大宗商品的实时报价、基本面、报表、文件和记录；
* Guidepoint，搜索超过 100,000 份经合规审查的专家访谈记录，并提供链接到来源的逐字摘录；
* IBISWorld，跟踪数千个行业的行业级收入、财务比率、风险评分、成本结构和预测；
* SS&C IntraLinks，让 Claude 能够访问 DealCentre 数据室，进行文档搜索、尽职调查问答和交易活动跟踪；
* Third Bridge，让 Claude 能够访问关于公司、行业和价值链的一手专家访谈；
* Verisk，提供用于承保、理赔和风险分析的财产、意外伤害和特种保险数据。

此外，Moody's 推出了一款 MCP 应用程序，该应用程序引入了超过 6 亿家公共和私人公司的专有信用评级和数据，用于合规、信用分析和业务开发。

Claude 在金融服务领域的影响力

许多领先的银行、资产管理公司和保险公司选择了 Claude。它支持这些组织的全方位工作：前台任务（如研究和客户体验），中台工作（如承销、风险和合规），以及后台工作（如代码现代化和运营）。

我们的投资专业人士生活在数据和分析模型中，而 Claude for Excel 正好满足了他们的需求。分析师正在使用它来构建和更新覆盖模型，从噪音中分离出信号，并对他们的工作进行压力测试——所有这些都带来了效率的阶跃式变化。

FIS 处于全球数千家金融机构资金流动的中心。当我们开始构建 AI 智能体时，我们知道我们需要一个我们可以信任的提供商。Anthropic 是明确的选择。我们正在共同构建一个将反洗钱调查从数天压缩到数分钟的智能体，随后还将推出信贷决策、欺诈预防和存款保留智能体。FIS 客户不需要自己构建这种基础设施。它已经在这里了。

借助 Eliza 和 Claude，我们正在为流程提供端到端处理案例的新数字员工。

凯雷已将 Claude 作为我们 AI 技术栈的关键部分，因为它具有强大的编码能力、智能体推理能力，并且在底层模型和关键功能方面不断进步。Claude 是在我们公司从投资到运营再到投资组合管理各个层面交付价值的核心工具。

Claude 压缩并增强了会议前的工作，使每一次会议都更具影响力——准备时间变成了构思时间，工作流更快捷，客户洞察更丰富，并出现了我们未曾预料到的新用例。

自从我们开始引入个性化的 Claude 和 Claude Code 助手以来，我们看到工程卓越水平显著提升，生产力也有了有意义的改善。我们很高兴能通过让 AI 发挥作用来交付价值，推进公司在风险专业知识方面扩展优势的战略创新重点；为我们的客户、分销合作伙伴和员工提供出色的体验；并优化我们的生产力和效率。

Walleye Capital 100% 的员工都在使用 Claude Code。我们这家拥有 400 人的对冲基金能达到这种采用水平，反映了我们 AI 至上的心态：我们期望每个人都能不断重新思考他们的工作方式，总是问‘AI 能如何帮我做这件事？’——无论他们是否处于传统的技术职位。

由 Claude Opus 4.6 驱动的 Claude for Excel 代表了一次重大的飞跃。从尽职调查到财务建模，它证明了是我们团队非常强大的工具——获取非结构化数据并在最少的提示下智能工作，从而有意义地自动化复杂的分析。这是 AI 以切实、省时的方式增强投资专业人员能力的绝佳例证。

风险工作流中的智能体必须了解他们正在与谁打交道。将 Dun & Bradstreet 的商业图谱和 D-U-N-S® 编号（商业身份的全球标准）引入 Claude，可确保 AI 智能体在经过验证的数据上运行，并提供金融工作流所需的确定性、可审计的结果。

投资者需要他们可以信任的 AI——而信任始于其背后的数据。Morningstar 和 PitchBook 为 Claude 带来了数十年的独立、分析师支持的情报，因此用户不仅能得到更快的答案。他们还能得到更好的答案。我们正在共同构建为公共和私人市场更明智决策提供动力的智能层。

我们的客户——机构投资者、资产管理者、对冲基金和银行——越来越希望直接针对选定的 FactSet 数据集运行 AI 辅助的工作流。与 Anthropic 合作让我们能够将 Claude 引入托管的编程环境，他们可以在已经使用的工具中对我们的基础市场数据、研究和分析进行推理。在内部，我们工程组织中全公司范围内采用 Claude Code 正在加速我们交付这些能力的速度。
