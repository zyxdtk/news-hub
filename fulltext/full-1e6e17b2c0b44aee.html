2 相关工作 近年来开发的视觉 token 剪枝方法可沿两个主要维度进行组织：剪枝阶段和剪枝标准。本节将讨论并比较代表性工作的关键技术。

2.1 Token 剪枝阶段 根据视觉 token 的剪枝位置，现有方法可分为预-LLM 方法（pre-LLM methods）和内部-LLM 方法（intra-LLM methods），即在 LLM 处理之前或在 LLM 主干网络内部对视频 token 进行剪枝。

预-LLM 方法在视觉编码器之后、LLM 主干网络之前对视觉 token 进行剪枝。这些与提示无关（prompt-agnostic）的方法利用视觉信号（如相似性）进行剪枝。例如，PruneVid [10] 将连续帧分组为片段，并利用帧间相似性压缩静态 token，从而更好地保留动态信号。HoliTom [16] 进一步发展了这一思路，将视频分段问题表述为静态 token 最大化问题，并通过动态规划求解。

相比之下，内部-LLM 方法在 LLM 主干网络内部进行剪枝，能够捕捉文本提示与视觉 token 之间的跨模态交互，利用文本到图像的注意力分数 [4] 或 token 相似性 [21] 进行剪枝。

2.2 Token 剪枝标准 现有工作主要采用两种 token 选择标准，即显著性（saliency）和多样性（diversity）。我们根据主要标准对代表性工作进行组织。

基于显著性（Saliency-Based）的方法。 这类方法主要依赖特定的度量指标，通常是注意力得分，来识别并保留关键的视觉标记（tokens）。 FastV [4] 计算从提示（prompt）到视觉标记在特定大语言模型（LLM）层中的注意力权重，保留得分最高的标记。 PyramidDrop [23] 通过多阶段策略改进了这一方法，在更深的LLM层中逐步提高剪枝比例。

基于多样性（Diversity-Based）的方法。 与基于显著性的方法不同，基于多样性的方法旨在最小化所保留视觉标记之间的信息冗余。余弦相似度是衡量标记相似性的主要指标。 例如，DART [21] 初始化一组基准标记（pivot tokens），并迭代地加入与当前选择集差异最大的新标记。 类似地，VidCom² [14] 采用两阶段剪枝框架，第一阶段明确关注帧级别的唯一性，第二阶段关注标记级别的唯一性。
