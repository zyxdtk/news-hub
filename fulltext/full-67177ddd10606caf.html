在紧张帧预算下的视频问答需要保留局部化运动和事件顺序，然而当前的视频多模态大语言模型（MLLMs）通过丢弃未选中的帧并独立编码关键帧，将视频理解简化为静态多图推理：（1）空间上，整帧池化将小的运动目标稀释到静态背景中；（2）时间上，丢弃中间帧或平均化token会抹除帧间运动，混淆方向、速度和顺序。我们提出 VIVID（Visual Inter frame Variations and Individual Dynamics，视觉帧间变化与个体动态），它像人类视觉一样超越静态快照：关键帧捕获核心状态，而帧间 Patch Diffs（补丁差异）在 K_f 个关键帧内保留邻近变化。自主增量驱动关键帧规划（ADKP）从 3 fps 候选池中选择锚点，并将周围补丁差异馈入双路变化记忆（DRCM），以零额外锚点token形成动态token，同时配备相机稳定的主动运动感兴趣区域（ROI）和按时间顺序的实体状态链。在冻结的 27B 骨干网络上仅添加 0.22% 可训练参数，VIVID-Small（50个样本，约1.5 GPU小时）在 8,083 个问题上的整体准确率击败全部十一个基线，仅次于 VIVID-Large（3,600个样本），后者在 MotionBench、Video-MME 和 TempCompass 上领先。

1 引言

视频理解与图像识别有着根本区别，因为其意义在于视觉实体及其状态如何跨帧演变 [7, 42, 2, 20]。然而，当前的视频多模态大语言模型（MLLMs）在很大程度上将视频理解简化为静态多图推理：其视觉编码器将每一帧作为静态图像独立处理 [6, 44, 40, 16, 35, 36, 41, 28]，或将静态特征压缩为压缩记忆和摘要表示 [39, 13, 37, 38, 31, 25, 30, 27, 11]，迫使语言模型隐式地猜测帧间转换。

如图1所示，这种静态范式在空间和时间上存在双重瓶颈：

空间瓶颈（基于相似性的token压缩与帧选择）。 token压缩和帧选择方法 [6, 40, 16, 35, 36, 28, 41] 通过注意力分数、token聚类或整帧相似性来修剪冗余，但关键运动往往只跨越静态背景下的一小块图像区域。在图1(a)中，当足球穿过画面上部向右移动时，0.0秒与1.0秒之间的平均池化 Vision Transformer（ViT）余弦相似度仍保持在 99.8%（0.9983）：在局部扰动下（第3.1节），全局余弦距离与变化补丁比例 ρ 呈二次方关系，从而淹没小的运动目标，而对变化最大的前 15% 补丁取平均则可产生 20.4% 的局部信号。

时间瓶颈（长时程视频记忆与事件定位）。 长时程记忆和事件定位方法 [39, 13, 37, 38, 31, 5, 25, 30] 将相邻帧特征平均到记忆槽中，或将片段总结为粗粒度字幕。等间隔采样会跳过短暂的转换峰值（如图1(b)中的 1.0秒和 6.0秒），而无时间特征池化和片段字幕则将多个对象和时间戳纠缠在一起，混淆方向、速度、重复计数和顺序 [24, 34, 14]。

我们的范式转变：VIVID。 传统的关键帧选择会丢弃未选中的帧，并将选定的关键帧作为孤立图片馈送给 LLM，对相邻帧运动视而不见。相比之下，人类视觉将对关键状态的稀疏注视与对帧间差异的敏感性相结合。受此原理启发，我们提出 VIVID（Visual Inter frame Variations and Individual Dynamics，视觉帧间变化与个体动态；图2）：尽管读取器只处理 K_f 个关键帧，VIVID 利用帧间 Patch Diffs（ΔE_t = E_t − E_{t−1}，其中 E_t 表示候选帧 t 的补丁特征矩阵），既通过自主增量驱动关键帧规划（ADKP，第3.3节）来规划关键帧，又将邻近帧运动注入转换条件输入内的双路变化记忆（DRCM，第3.2节）：

（1）在视觉增量路径中，我们可训练的视觉增量模块（θ_Δ）将 220 个补丁差异压缩为 16 个潜在槽，并将门控运动残差注入每个选定的关键帧，以零额外锚点token形成动态token（Ẽ_t，同时编码关键帧外观和邻近帧变化），并配以相机稳定的主动运动感兴趣区域（ROI）；（2）在实体状态路径中，视觉语言写入器将候选转换跟踪为按时间顺序的实体状态链。

因此，K_f 个关键帧之外的邻近差异和实体观察得以保留而非被丢弃。零初始化（第0步时 Ẽ_t = E_t）和密集的 220 补丁重建使 θ_Δ 与最后 16 层的低秩适应（LoRA，θ_LoRA，占 27B 骨干网络的 0.22%；第3.4节）能够联合适应，在极少的资源下（VIVID-Small，50个样本约 1.5 H20 GPU小时）取得强大增益，并在紧凑的 3,600 片段语料库上干净地扩展（VIVID-Large，不到 VideoMind [25] 中 481K 训练样本的 0.8%）。

我们的主要贡献有三方面：

  • 邻近帧动态token：我们的视觉增量模块（θ_Δ）不丢弃未选中的帧，而是将邻近帧 Patch Diffs 以零额外锚点token的代价折叠进每个关键帧，形成动态token（Ẽ_t）（第3.2节）。
  • 双路变化记忆与 ADKP：我们在 VIVID-Small（50）和 VIVID-Large（3,600）上统一了 ADKP 规划与动态token、相机稳定的主动运动 ROI 以及按时间顺序的实体状态链（第3.3和3.4节）。
  • 受控的多基准验证：在共享 27B 骨干网络上严格匹配的 K_f=8 协议下，跨 MotionBench [14]、Video-MME [10] 和 TempCompass [24]（8,083个问题），VIVID 在token压缩、帧选择、记忆和定位方面均优于十个已发表的基线以及均匀采样（第4节）。

2 相关工作

基于相似性的token压缩与帧选择。 早期的 ViT 修剪方法合并相似token（ToMe [3]、vid-TLDR [8]）或丢弃低注意力token（FastV [6]、VisionZip [44]、LLaVA-PruMerge [33]）。近期的视频 MLLMs 将缩减扩展到跨帧：DyCoke [40] 合并时间组，PruneVid [16] 聚类静态和动态token，HoliTom [35] 执行时空合并，FastVID [36] 按整帧相似性分割片段，EarlyTom [41] 早期压缩空间token，ST-SimDiff [28] 平衡相似性原型与时间差异token选择。作为选择和修剪的补充，VIVID 学习将周围 Patch Diffs 直接作为动态token注入锚点嵌入，同时用学习到的门和前 15% 局部变化来引导 ADKP。

图2：VIVID 架构概览（ViT：Vision Transformer；MLP：多层感知机；FFN：前馈网络；ROI：感兴趣区域；LoRA：低秩适应）： 在 3 fps 候选帧中（第3节），冻结的 ViT 计算 Patch Diffs ΔE_t，使 ADKP（公式6、7和8）跨区间 ℬ_1…ℬ_6 选择 K_f=8 个转换锚点并裁剪 320×180 主动运动 ROI； 周围的 Patch Diffs 进入双路变化记忆（DRCM），其中视觉增量模块 θ_Δ 将静态锚点 E_{t̂k} 丰富为动态token Ẽ{t̂_k}（公式3和4），同时预计算实体状态链（公式5）； 转换条件输入馈送共享读取器，前 48 层 LLM 冻结，最后 16 层通过 LoRA 适应。

长时程视频记忆与事件定位。 为了将视频 MLLMs 扩展到多分钟基准 [29, 43, 45]，长视频方法将视频流压缩为特征槽或文本摘要：MovieChat [39]、MA-LMM [13]、Chat-UniVi [18]、LLaMA-VID [23]、LongVU [37]、Video-XL [38]、Oryx [26]、ProtoKV [30] 和 Vista [27] 将历史帧池化为压缩槽或原型，而 VideoLLM-online [5]、VideoStreaming [31]、Goldfish [1]、VideoChat-Online [17]、VideoMind [25] 和 VideoStir [11] 生成片段字幕或检索事件。为了在紧凑记忆的同时保留细粒度的每对象顺序，VIVID 将动态token与结构化的每实体实体状态链配对。

克服视频时间适应中的静态捷径偏差。 先前的诊断研究 [4, 19] 表明，视频语言模型经常依赖单帧外观线索而非帧间转换，这促使了专门的时间和运动基准 [21, 24, 22, 9, 34, 14] 的出现。虽然 LoRA [15] 提供参数高效适应，直接偏好优化（DPO）[32] 包含参考策略似然项，但 VIVID 用密集补丁差异重建和无参考的选项偏好边际损失来监督适应。

3 方法

给定时长为 T 秒的视频，VIVID 在时间戳 τ_1 ＜ ⋯ ＜ τ_M 处采样 M(T) = clip(⌊3.0T⌋+1, 8, 96) 帧 F_1, …, F_M 的候选池，其中 clip(·, 8, 96) 将候选数量限制在 [8, 96] 范围内，适用于短片段和长视频。类似于人类视觉，VIVID 将邻近帧补丁差异折叠进 K_f=8 个选定的关键帧，同时保持所有 27B 骨干网络权重冻结（图2）：冻结的编码器 Φ_vis 提取补丁矩阵 E_t = Φ_vis(F_t) ∈ ℝ^{N_p×D}，其中 N_p=220 为补丁数，D=5120 为嵌入宽度（第3.1节）；DRCM（第3.2节）构建动态token、主动运动 ROI 和实体状态链；ADKP（第3.3节）选择 K_f=8 个转换锚点；联合适应（第3.4节）在最后 16 层用 LoRA（θ_LoRA）和学习到的路径门优化 θ_Δ。全文中，X^(i) ∈ ℝ^d 表示 X ∈ ℝ^{N×d} 第 i 行的转置。

3.1 预备知识：局部变化的衰减

整帧相似性方法用单位归一化的平均补丁向量 g_t = Ē_t/max(‖Ē_t‖2, ε) 来总结帧 F_t（20×11 网格的 32×32 合并补丁单元，N_p=220）（其中 Ē_t = (1/N_p)Σ{i=1}^{N_p} E_t^(i)，ε=10^−12；公式S1），并在 s_global = g_{t−1}^⊤ g_t 接近 1 时将连续帧视为冗余 [36]。假设只有比例 ρ ∈ (0,1) 的补丁嵌入以均值 d_t ∈ ℝ^D 发生偏移，其余 1−ρ 的嵌入保持不变（Ē_t = Ē_{t−1} + ρd_t）。对于小的局部扰动（ρ‖d_t‖2 ≪ ‖Ē{t−1}‖2），单位归一化会抵消沿 g{t−1} 的一阶径向分量，因此二阶泰勒展开得到公式1：

1 − s_global ≈ ρ²‖d_{t,⊥}‖2² / (2‖Ē{t−1}‖_2²)，　(1)

其中 d_{t,⊥} = d_t − (g_{t−1}^⊤ d_t) g_{t−1} 是与 Ē_{t−1} 正交的分量。由于主导项与 ρ² 成比例，小的运动目标（ρ ≪ 1）会被静态背景衰减：在图1(a)中，尽管前 15% 补丁的余弦变化达 20.4%，s_global = 0.9983 仍超过 FastVID 的 0.95 阈值。

3.2 双路变化记忆（DRCM）

3.2.1 视觉增量路径：视觉增量模块与主动运动 ROI

为了在零额外锚点token下将冻结的视觉快照丰富为具有显式帧间动态的动态token，我们可训练的视觉增量模块（θ_Δ，52.5M 参数）在规划期间处理连续候选对（F_{t−1}, F_t），在读取期间处理邻近同场景参考对（F_ref, F_{t̂k}）（锚点1保持不变；附录B）。对于任何具有当前嵌入 E_t 和参考 E{t−1} 的帧对，我们在每个补丁 i ∈ {1, …, N_p} 处计算补丁差异矩阵 ΔE_t 和非负余弦距离 m_t^(i)：

{ ΔE_t = E_t − E_{t−1} ∈ ℝ^{N_p×D}，　m_t^(i) = max(0, 1 − Ê_{t−1}^(i)⊤ Ê_t^(i)) }，　(2)

其中 Ê_t^(i) = E_t^(i)/max(‖E_t^(i)‖_2, ε) 表示单位归一化的补丁向量。

交叉注意力差异重采样器。 设 D̃_t = LN_Δ(ΔE_t) 表示层归一化的补丁差异。为防止静态背景补丁主导注意力，我们用 (0.2 + 5.0 m_t^(i)) 对每个补丁加权，并通过带学习查询 Q_Δ ∈ ℝ^{K×d_b} 的瓶颈交叉注意力（d_b=512）将全部 N_p=220 个补丁差异压缩为 K=16 个潜在槽 Z_t ∈ ℝ^{K×D}：

{ ΔÊ_t^(i) = (0.2 + 5.0 m_t^(i)) D̃_t^(i)，　A_t = softmax(Q_Δ(ΔÊ_t W_K)^⊤/√d_b)，　Z_t = SiLU(A_t ΔÊ_t W_V) W_O }，　(3)

其中 A_t ∈ ℝ^{K×N_p} 是补丁归一化的注意力矩阵，SiLU 是 Sigmoid 线性单元，W_K, W_V ∈ ℝ^{D×d_b} 和 W_O ∈ ℝ^{d_b×D} 是学习到的投影。

零开销门控残差注入。 瓶颈多层感知机（MLP）不附加额外token，而是将每个补丁的局部差异 D̃t^(i) 与池化摘要 z̄_t = (1/K)Σ{k=1}^K Z_t^(k) 结合，并将门控残差原位注入 E_t^(i)：

{ G_t^(i) = σ(w_g^⊤ D̃_t^(i) + b_g + 2.0 m_t^(i))，　h_t^(i) = SiLU(W_down[D̃_t^(i); z̄_t] + b_down)，　U_t^(i) = W_up h_t^(i) + b_up，　Ẽ_t^(i) = E_t^(i) + tanh(α_res) G_t^(i) U_t^(i) }，　(4)

其中 σ 是逻辑 Sigmoid，[·;·] 表示向量拼接，G_t^(i) ∈ (0,1) 是由 w_g ∈ ℝ^D 和 b_g ∈ ℝ 参数化的学习运动门，h_t^(i) ∈ ℝ^{d_b} 和 U_t^(i) ∈ ℝ^D 是由 W_down ∈ ℝ^{d_b×2D}、b_down ∈ ℝ^{d_b}、W_up ∈ ℝ^{D×d_b}、b_up ∈ ℝ^D 参数化的隐藏向量和残差向量，标量 α_res（初始化为 0.1）控制残差尺度。将 W_O、W_up 和 b_up 初始化为零可确保第 0 步时 Ẽ_t = E_t，在零额外锚点token下保持预训练对齐。

为了解析仅跨越几个 32×32 单元的微小目标，我们在 (2r+1)×(2r+1) 网格窗口（r=3）内估计变化最大的前 25% 补丁的 2D 补丁位移（Δx_t, Δy_t），在 160×90 灰度帧上沿外 20% 图像边界在 [−6, 6] 像素内对齐以补偿相机平移，并在 μ_t^loc ≥ 0.015 时以 320×180 分辨率裁剪残差最高的 80×45 窗口，作为一个 66 token 的主动运动 ROI（附录B）。

3.2.2 实体状态路径：实体状态链

为防止多帧合并混淆实体顺序、速度和交互，实体状态路径在 L+1 ∈ {4, 6} 个选定的候选帧 {F_{t_0}, …, F_{t_L}} 上构建按时间顺序的实体状态链，定义跨 [0, T] 的 L 个转换（图2(b)）。在（F_{t_{l−1}}, F_{t_l}）上调用视觉语言写入器之前，我们将 τ_{t_{l−1}} 之前最多八个活动实体检索到工作记忆中（规范名称、类别、属性和最新位置/状态）。在工作记忆、（F_{t_{l−1}}, F_{t_l}）、主动运动 ROI 和（Δx_{t_l}, Δy_{t_l}）的条件下，写入器对持续出现的对象重用规范名称，仅对未见过的对象引入新名称（附录C），并更新区间描述 M_seg 和每实体的实体状态链：

C(e_j) = { (τ_{j,0}, s_{j,0}, p_{j,0}, δ_{j,0}) → … → (τ_{j,L_j}, s_{j,L_j}, p_{j,L_j}, δ_{j,L_j}) }，　(5)

其中对于实体 e_j 的 L_j+1 个记录观察（r = 0, …, L_j），τ_{j,r} 是时间戳，s_{j,r} 和 p_{j,r} 表示状态和屏幕位置，δ_{j,r} 记录状态变化、方向、速度和实体间关系。对于问题 Q，检索为每个相关实体选择最多六个转换，并按与 Q 的内容词重叠加上局部补丁显著性 μ_t^loc 对候选区间排序，保持到查询时间戳为止的时间顺序（附录C）。

3.3 自主增量驱动关键帧规划（ADKP）

与丢弃未选中帧的静态选择方法不同，VIVID 重用候选 Patch Diffs，既在此处选择 K_f=8 个关键帧，又在 DRCM 内形成邻近帧动态token Ẽ_{t̂_k}。ADKP 利用公式2、3和4中的三个统计量捕获活跃状态变化，而不会在单次突发中聚类槽：

{ μ_t^gate = (1/k_20)Σ_{i∈I_{0.20}(G_t)} G_t^(i)，　μ_t^loc = (1/k_15)Σ_{i∈I_{0.15}(m_t)} m_t^(i)，　ε_t^Δ = ‖Z_t‖_F/√(KD) }，　(6)

其中 I_p(v) 索引 v 的最大 pN_p 个条目（门显著性 μ_t^gate 的 k_20=44；局部变化 μ_t^loc 的 k_15=33），∥·∥_F 是槽能量 ε_t^Δ 的 Frobenius 范数。

将公式6与实体时间戳指示器 I_t^mem(Q) = 𝕀(min_{τ∈T_mem(Q)} |τ_t − τ| ≤ δ_τ) 结合（其中 𝕀 是指示函数，T_mem(Q) 是检索到的时间戳集合，若为空则 I_t^mem = 0，平均步长 Δτ̄ 下 δ_τ = max(1.25 s, 1.25 Δτ̄)，在第 1 步评估 μ_t^loc，1秒步长为3），t ∈ {2, …, M} 的规划分数为：

S_plan(t|Q) = μ_t^gate + γ_1 μ_t^loc + γ_2 ε_t^Δ + γ_3 I_t^mem(Q)，　(7)

其中 (γ_1, γ_2, γ_3) = (2.5, 0.5, 0.35) 为标量权重。当 M ＞ K_f 时，ADKP 固定端点 S_0 = {1, M}，将内部累积权重分割为 K_f−2 个区间 ℬ_b，并在每个非空区间中选择峰值（附录B）：

{ w_t = 0.45 S̄ + 0.55 S̃t，　C_t = Σ{j=2}^t w_j / Σ_{j=2}^{M−1} w_j，　t_b* = arg max_{t∈ℬ_b∖S_{b−1}} S_plan(t|Q) }，　(8)

其中 S̃t = max(10^−4, S_plan(t|Q))（t = 2, …, M−1）具有均值 S̄，S_b = S{b−1} ∪ {t_b*}（用最高分数填充空区间），对 S_{K_f−2} 排序得到锚点 t̂1 ＜ ⋯ ＜ t̂{K_f}。

处理镜头切换、相机平移与周围帧。 直接对补丁变化排序可能会在硬镜头切换上浪费锚点槽，或在全局相机平移期间扰乱均匀速度线索。因此，当整帧相似性 g_{t−1}^⊤ g_t ＜ 0.80 或中位数补丁距离 med(m_t) ＞ 0.22 时，ADKP 将候选分数乘以 0.1；当全局相机运动占主导时（75% 的帧中 μ_t^loc/(med(m_t)+0.02) ＜ 2.35），保持均匀锚点间距。在读取期间，当连续锚点（t̂{k−1}, t̂_k）跨越镜头切换或超过均匀步长时，θ_Δ 在 ΔE{t̂k}^read = E{t̂k} − E_ref 上评估公式2、3和4，使用通过场景相似性阈值（g_ref^⊤ g{t̂k} ≥ 0.82）的邻近候选参考 E_ref，以零额外锚点token将未选中的邻近帧折叠进 Ẽ{t̂_k}。

3.4 联合适应与神经路径门控

在推理时，每个读取器上下文按时间顺序连接全部 K_f=8 个锚点（每个锚点 220 个动态token Ẽ_{t̂k}，触发时外加一个 66 token 的主动运动 ROI E_ROI），每个锚点前有显式时间戳头（Frame #k/8 at t=...s），以便读取器将 ADKP 锚点与实体状态链对齐。在共享读取器上评估视觉上下文 [{(τ{t̂k}, Ẽ{t̂k})} ∥ Q] 和双路上下文 X = [M_seg ∥ {C(e_j)}{j=1}^J ∥ {(τ_{t̂k}, Ẽ{t̂_k})} ∥ (τ, E_ROI) ∥ Q]，得到选项对数概率 ℓ_vis, ℓ_mem ∈ ℝ^4。由于空间属性问题有利于直接检查动态token，而多步顺序和速度问题更受益于实体状态链，我们通过两层神经路径门* λ_ψ(h_Q, c) ∈ (0,1) 将两条路径融合为 (1−λ_ψ)ℓ_vis + λ_ψ ℓ_mem，该门在不使用数据集或任务标签的留出验证片段上训练，映射冻结骨干网络的池化中间层和最终层问题向量 h_Q ∈ ℝ^{2D} 以及六个路径预测熵、前2边际、对称 Kullback-Leibler（KL）散度和预测一致性特征 c ∈ ℝ^6（在 λ_ψ = 0.5 附近零初始化；附录B）。

差异重建与方向对齐。 如果 θ_Δ 仅由答案损失监督，那么只要粗略上下文足够，Z_t 就可能忽略细微的空间变化。我们附加一个辅助训练时解码器（推理时丢弃），其中归一化的前序token LN_ctx(E_{t−1}) 查询 Z_t 以重建全部 N_p=220 个补丁差异：

其中 Q_rec ∈ ℝ^{N_p×d_b}、K_rec ∈ ℝ^{K×d_b}、V_rec ∈ ℝ^{K×D} 使用学习投影 W_Q^rec、W_K^rec ∈ ℝ^{D×d_b} 和 W_V^rec ∈ ℝ^{D×D} 预测 D̂t ∈ ℝ^{N_p×D}，Q_Δ W_K^⊤、Q_Δ W_V^⊤ 在第 0 步打破槽对称性。我们将补丁加权重建 L_recon（m_t^(i) 最大的前 25% 上 ω_t^(i) = 1.1，其余补丁上为 0.1，ΔE_t^(i) 上停止梯度）与方向对齐损失 L_dir（边际 ξ = 0.5；公式S2）结合，后者作用于平均归一化补丁差异 d̄_t = (1/N_p)Σ{i=1}^{N_p} D̃t^(i) 与池化上下文位移 ē_t^ctx − ē{t−1}^ctx（ē_t^ctx = (1/N_p)Σ_{i=1}^{N_p} (LN_ctx(E_t))^(i)）之间，得到 L_Δ = L_recon + 0.2 L_dir：

{ Δs_t^dir = (W_Q^dir d̄t)^⊤ W_K^dir (ē_t^ctx − ē{t−1}^ctx)/√d_b，　L_recon = (1/(N_p D))Σ_{i=1}^{N_p} ω_t^(i) ‖D̂_t^(i) − ΔE_t^(i)‖_2²，　L_dir = log(1 + exp(ξ − Δs_t^dir)) }，　(10)

其中 W_Q^dir、W_K^dir ∈ ℝ^{d_b×D} 是学习投影。

4.1 实验设置与基准

受控协议与模型规模。 我们在共享冻结的 Qwen3.8 27B 骨干网络上、统一的 3 fps 候选池 M(T) = clip(⌊3.0T⌋+1, 8, 96) 下评估十个已发表的基线、静态均匀采样和 VIVID（在 MotionBench、TempCompass 和 Video-MME 上平均分别为 26.1、35.8 和 95.6 个候选），压缩或选择为 640×360 的 K_f=8 读取器帧，采用贪婪解码。可训练参数总计 60.2M（27B 骨干网络的 0.22%：θ_Δ 中 52.5M，块 48–63 的 12 个线性注意力层和 4 个全注意力层的 r=16 LoRA 中 7.7M），通过 AdamW 优化。虽然近期的后训练流程需要 481K 训练样本 [25]，VIVID 在两个轻量级规模上运行：

  • VIVID-Small（50个样本，约1.5 H20 GPU小时）：在单 GPU 上从零初始化校准 θ_Δ 和 θ_LoRA，使用 45 个 TempCompass 问题-片段对（44个片段）外加五个合成片段。

基准。 所有训练片段与评估严格分离，共 8,083 道多选题：MotionBench [14]（六个运动类别共 4,017 个问题；表1）、Video-MME [10]（2,700 个无字幕问题，涵盖短视频＜2分钟、中视频 4–15 分钟和长视频 30–60 分钟；表2和S1）以及 TempCompass [24]（1,366 个留出问题，涵盖五个时间维度：动作、方向、速度、顺序和属性变化；表2和D）。

4.2 主要结果

在 MotionBench 上捕获局部运动。 在 MotionBench（表1）上，几乎所有基于相似性的压缩和记忆基线在移动对象和动作顺序上的得分低于静态均匀采样：整帧余弦池化将大静态背景下的小前景运动视为冗余，而跨帧合并将运动对象补丁平均进周围背景上下文。通过对局部补丁差异加权、裁剪相机稳定的主动运动 ROI，并以零额外锚点token代价将周围候选变化注入动态token，VIVID-Small 和 VIVID-Large 在整体准确率和全部五个对象与动作运动类别中占据前两位（在动作顺序上与均匀采样并列第二），同时在全局相机平移下保持均匀帧间距，保留了相机运动类别上的速度线索。

在 Video-MME 上扩展到多场景视频。 在未修剪的多场景视频（表2和S1）上，将多达 96 个候选压缩到八个槽对 30–60 分钟视频上的合并和修剪方法构成挑战，因为场景内的短暂动作被跨镜头边界平均，而粗粒度片段字幕则跨切换混合了不同的实体。降低硬镜头切换的权重可防止 ADKP 在场景转换上浪费槽位，邻近同场景候选帧为动态token提供准确的运动残差，工作记忆实体状态链跨场景保持规范实体身份，使 VIVID-Small 和 VIVID-Large 在所有时长划分中分别取得第二和第一名（表2），并在十二个任务类别中的九个中领先或并列第一（表S1），尤其是在时间推理和计数上。

在 TempCompass 上克服静态捷径。 表2揭示了静态识别与时间状态推理之间的差距：虽然所有方法在单帧动作上都接近饱和，但token修剪和槽合并在速度、方向和属性变化上明显下降，因为跨帧池化平滑了位移幅度和渐进漂移。提供显式锚点时间戳，同时将静态锚点转换为周围帧动态token并配以按时间顺序的实体状态链，既保留了瞬时速度又保留了渐进属性演变，使 VIVID-Small 能够从 50 个样本匹配或超越经过大量训练的基线，VIVID-Large 在整体准确率、速度和属性变化上领先。

推理开销与多查询效率。 原位残差注入以每个锚点零额外token形成动态token（8×220 视觉token，触发时外加一个 66 token 的主动运动 ROI），辅助差异解码器（公式9）在训练后丢弃，零推理成本。添加 0.22% 可训练参数使单个冻结的 27B 骨干网络保留在内存中，无需每层 KV 原型库 [30] 或每问题智能体展开 [25]，同时每视频一次性构建候选特征和视频级实体状态链，将构建成本 C_build 在同一视频的 q 个查询上摊销为 C_build/q（附录B），查询时仅保留轻量级的 ADKP 评分、实体检索和路径门控。

5 结论

我们识别了视频 MLLMs 将视频理解简化为静态多图推理时出现的空间和时间瓶颈，并提出 VIVID 以超越孤立快照，同时保持所有 27B 骨干网络权重冻结，仅添加 0.22% 可训练参数。将自主增量驱动关键帧规划（ADKP）与双路变化记忆（DRCM）耦合，以零额外锚点token将邻近帧 Patch Diffs 折叠进动态token，同时配备相机稳定的主动运动 ROI 和可重用的视频级实体状态链，其构建成本可在多查询工作负载中摊销。在 MotionBench、Video-MME 和 TempCompass 上跨 8,083 个问题的评估证实，VIVID 仅从 50 个校准样本（VIVID-Small）起就在整体准确率上超越十个已发表的基线和静态均匀采样，并在 3,600 个片段（VIVID-Large）时在每个基准上取得最高整体准确率，确立了局部变化表示和按时间顺序的实体状态记忆作为紧张帧预算下资源高效视频推理的有效范式。

附录B 实现、工程与训练细节

架构超参数与空间预处理。 视觉增量模块（θ_Δ）包含 52,468,226 个可训练参数（D=5120，d_b=512，K=16），其中 W_O、W_up 和 b_up 零初始化，α_res 初始化为 0.1，因此第 0 步时 Ẽ_t^(i) = E_t^(i)。读取器 LoRA 模块（θ_LoRA，7,733,248 参数，r=16，α=32，dropout 0.05）适应 64 层读取器的第 48 至 63 层（12 个线性注意力层和 4 个全注意力层）。对于 2D 补丁位移估计，余弦变化 m_t^(i) 最大的前 25% 中的每个补丁 在 F_t 中搜索 (2r+1)×(2r+1) 网格窗口（r=3）以找到与 F_{t−1} 的最大余弦相似度，并对活动补丁的偏移 (x̂−x, ŷ−y) 取平均。对于无检测器的主动运动 ROI 裁剪，连续帧被下采样到 160×90 灰度图，沿外 20% 图像边界搜索 [−6, 6] 像素内的整数位移以补偿全局相机平移，并从 F_t 以 320×180 分辨率裁剪平均残差最高的 80×45 窗口（μ_t^loc ≥ 0.015 时为 66 token）。在 ADKP（公式8）中，区间 ℬ_b（b ∈ {1, …, K_f−2}）收集满足 (b−1)/(K_f−2) ＜ C_t ≤ b/(K_f−2) 的内部索引（b=1 时在 0 处包含），降低硬镜头切换的权重（g_{t−1}^⊤ g_t ＜ 0.80 或中位数补丁余弦距离 ＞ 0.22），并在全局相机平移下保持等区间间距（当 75% 的帧中局部变化 μ_t^loc 低于整帧中位数 med(m_t)+0.02 的 2.35 倍时）。在读取期间，当锚点 t̂k 在同一场景内偏离均匀间距（g_ref^⊤ g{t̂k} ≥ 0.82）时，θ_Δ 针对 3 fps 池中的邻近同场景候选帧 E_ref 评估 ΔE{t̂k} = E{t̂_k} − E_ref，而不是丢弃中间候选帧，以零额外读取器token（每帧 220 token）保留周围帧运动。

训练计划与学习的神经路径门。 我们使用 AdamW 优化 {θ_Δ, θ_LoRA}（权重衰减 0.01，梯度裁剪 1.0）。VIVID-Small（50个样本：44 个片段中的 45 个 TempCompass 问题-片段对外加五个合成片段，严格排除在 1,366 个留出评估问题之外）先在 33 个样本上以 1.5×10^−4 训练三个 epoch，然后在全部 50 个样本上以 8×10^−5 训练两个 epoch，每片段使用四帧。VIVID-Large（3,600个样本：2,205 个 TVBench 片段 [9]、800 个自监督时间反转反事实样本和 595 个 Charades-STA 片段 [12]）直接以八个关键帧（K_f=8）和双路历史训练（梯度累积 8，学习率 2.5×10^−5，以及向初始参数 θ_0 的 ℓ_2 正则化 λ_reg‖θ − θ_0‖_2²，λ_reg = 10^−3）。为了在没有基准元数据或手工规则的情况下融合路径预测，两层神经路径门 λ_ψ(h_Q, c) ∈ (0,1) 将冻结骨干网络的上下文化问题隐藏向量 h_Q ∈ ℝ^{2D}（平均池化中间层与最终层最后token拼接）和六个路径预测熵、前2边际、对称 KL 和预测一致性特征 c ∈ ℝ^6 映射到 (ℓ_vis, ℓ_mem) 上的融合权重 (1−λ_ψ, λ_ψ)，在 [0.5, 0.5] 处零初始化，并在留出验证片段上训练。
