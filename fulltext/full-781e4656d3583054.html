Box 借英伟达 Nemotron 打造智能...

📅 2026-11-05 📄 TechCrunch AI 🔗 原文链接

原标题：Box taps Nvidia’s Nemotron for new agent-first content retrieval system

中文摘要： Box 推出名为 Box Content Retrieval 的新功能，基于英伟达 Nemotron Embed 开放权重嵌入模型构建。该功能通过嵌入式元数据让智能体更高效地回答查询，预计查询速度提升四倍、错误减少 20%、token 消耗降低 90%。系统将于明年初面向 Enterprise Advance 客户推出，并深度整合 Box 既有的元数据与权限控制体系，律师等用户可更轻松地检索相关条款与判例。

这项名为 Box Content Retrieval 的新功能，依靠 Nemotron 生成的嵌入式元数据，让智能体能够更高效地回答查询。

Box 表示，用户最终将获得更快、更准确、成本更低的查询体验。英伟达生成式 AI 软件副总裁 Kari Briski 告诉 TechCrunch，她预计查询速度将提升四倍，错误减少 20%，token 使用量减少 90%。

该系统将面向所有 Box Enterprise Advance 客户开放，并将于明年初正式推出。

Box 首席执行官 Aaron Levie 表示：“这极大地提升了我们的搜索技术对智能体的相关性。智能体不必逐篇通读每份文档，我们可以直接返回与用户查询或智能体正在执行的任务最相关的文档片段。”

该功能是英伟达 Nemotron Embed 项目的一次落地实践。该项目提供开放权重的嵌入模型，用于改进自动化检索系统。这类模型利用大语言模型（LLM）对数据进行预处理，使其能更好地为智能体所用，但长期以来一直被各大 AI 实验室所忽视。这一领域一直是英伟达开源模型项目的重点，其今年 7 月发布的最新版 Nemotron 在衡量检索质量的 RTEB 基准测试中名列榜首。

Box 表示，该系统在与活跃智能体配合使用时将发挥最大价值。以律师为例，在新系统下，他们显然能够更轻松地找到相关条款和判例。由于 Nemotron 的嵌入技术超越了简单的关键词匹配，能够映射底层概念，即使措辞不同或使用不同语言，搜索工具也能呈现相关的法律主题。

虽然 Nemotron 模型可免费获取，但该系统还在很大程度上依赖 Box 既有的元数据和权限控制体系，这使得从零开始复刻颇具挑战。Levie 告诉 TechCrunch：“我们可能是把五种不同的技术打包进了一个简单的 API 中。”
