摘要
在不断演变的环境中进行长期机器人操作，需要能够在重复重访中持续存在的对象级理解。现有系统要么通过覆盖历史记录来维护最新地图，要么存储语义快照而不保持一致的跨会话对象身份，从而导致“时间失忆”：即对象历史的系统性丢失，这使得系统无法回答诸如“在所有会话中，那把绿椅子去过哪里？”之类的查询。我们提出了 LT-Mem，这是一个波动性感知的记忆演化框架，它将空间对齐的实例级 3D 感知与波动性条件化的时间推理统一起来。首先，多会话 SLAM 主干网络提供跨会话的空间对齐逐对象观测。其次，推理层控制对象记忆如何演化：确定性证据评分保持跨会话身份，而波动性感知策略则根据每个对象的动态在覆盖、保持和多假设动作之间进行选择。第三，由此产生的三重记忆结构（Live、Delta、Meta）同时保留当前状态和事件历史，从而实现纵向的以对象为中心的推理。我们进一步引入了 LT-VQA，这是一个包含多会话记录、持久身份标注和时间问答对的数据集和评估套件。实验表明，LT-Mem 在所有指标上均优于基线，同时消耗的 token 数量少了一个数量级，消融实验也证实了性能的提升源于结构化的记忆架构，而非 LLM 的容量。

机器人会反复重访不断演变的环境 [4, 20, 2]。在跨会话的过程中，对象可能会移动、消失，或者由于遮挡和对齐噪声而被不一致地观测 [16]。多会话建图提供了一个共享的空间框架 [14, 10]，但单纯的空间一致性并不能保证对象记忆随时间推移仍然有效。终身操作需要对对象状态何时以及如何更新进行推理，保留变化的轨迹，而不是将其折叠为单个被覆盖的状态。例如，回答一个带有会话索引的查询，如：“在第 3 次会话时，机器狗在白色桌子附近。它在第 9 次会话时在哪里？”这需要持久的跨会话身份和明确的状态转换建模。目前的系统并不是为这种形式的时空以对象为中心的推理而设计的。

现有的终身场景理解方法遵循两个方向：以几何为中心的建图和语义记忆。以几何为中心的系统 [14, 16, 10] 在变化中保持全局一致性，但将对象转换简化为删除和重新创建，从而丢失了时间历史。语义记忆方法 [1, 7, 19] 通过视图级嵌入、开放词汇 3D 场景图或结构化探索记忆构建丰富的表示。然而，它们通常依赖于最新的观测或将各个会话独立处理，而没有强制执行持久的跨会话身份。即使结合了长时序上下文，重新处理累积的历史视频流在计算上也是要求很高的，并且无法随着部署时间的延长而扩展。因此，对象历史无法被连贯地组合，也不直接支持带有会话索引的时间查询。

为了弥合这些方向，我们首先分析了跨会话对象状态转换的分类法及其所引出的纵向查询，如表 I 所示。该分类法阐明了持续长期操作所需的记忆演化类型。在此分析的基础上，我们提出了 LT-Mem，这是一个具有两层的波动性感知记忆演化框架：一个用于空间对齐对象观测的感知层，以及一个控制记忆更新的推理层。

• 感知层。我们扩展了 MASt3R-SLAM [13] 用于多会话对齐，并应用实例级 3D 分割 [3] 来提取每个对象的质心、体积和语义嵌入。
• 推理层。通过确定性证据评分（表 II 中的 E1–E5，包括外观和时空一致性）来解决跨会话身份问题，仅在模糊情况下使用受限的 LLM。然后，波动性感知策略根据对象动态和对齐质量，在覆盖、保持和多假设更新之间进行选择。

推理输出被组织到一个三重记忆结构中：Live Memory 存储当前状态，Delta Memory 记录带有时间戳的事件，Meta Memory 积累长期统计数据（如波动性）。这同时保留了当前状态和历史轨迹，从而实现了长时序的时间查询。由于推理层是在紧凑的结构化表示上运行，而不是在原始视频流上运行，因此 LT-Mem 实现了强大的时间推理，且每个会话的 token 成本与帧数无关，从而实现了可扩展的终身操作。

为了评估这一能力，我们引入了 LT-VQA 数据集 1 1 1 https://lt-mem.github.io/ ，它提供了具有对齐姿态、逐对象标注和时间问答对的多会话记录。与 NaVQA [1] 等单会话 QA 数据集不同，LT-VQA 针对跨会话的长期地图管理，评估系统是否正确识别了发生了什么变化、何时发生以及跨哪些会话发生。

总之，这项工作做出了以下贡献：
• 我们提出了 LT-Mem，一个波动性感知的记忆演化框架，其中更新决策由波动性条件化的推理层控制，并可选地由受限 LLM 辅助，产生一个三重记忆结构，同时保留当前和历史对象状态。
• 我们构建了 LT-VQA，一个需要持久对象身份和跨多会话重访的结构化时间推理的数据集和评估套件。
• 我们证明了波动性感知演化在覆盖和累积基线之上改善了长时序以对象为中心的推理，同时与基于视觉的方法相比，将 token 消耗减少了多达一个数量级。

II 相关工作
II-A 终身空间建图
长期自主性需要在重复重访中保持空间一致性，同时适应环境变化。诸如 LT-mapper [10] 和 14 [14] 等经典系统检测地图与观测之间的差异，并通过移除或纠正过时元素来解决它们。最近，Khronos [16] 构建了密集的时空度量语义地图，统一了短期动态和长期场景变化，但没有为单个对象维护保持身份的事件日志。即使是跟踪每个对象平稳性分数的概率方法 [15] 最终也会丢弃过去的对象状态以刷新地图，而不是保留状态历史。当对象从位置 A 移动到 B 时，先前状态被覆盖或移除，而不是作为时间轨迹的一部分被记录。我们将这种对象状态历史的系统性丢失称为“时间失忆”，这一局限性使得无法回答诸如“机器狗移动了多少次？”之类的纵向查询。

图 2：系统流程。（左）感知层对齐多会话观测，并通过 3D 分割提取对象实例。推理层执行经过完整性检查的记忆演化，包括身份匹配、变化检测和波动性感知更新选择。（右）更新后的状态被组织在 Tri-Memory（Live、Delta、Meta）中，并通过以对象为中心的检索进行检索，以支持长期视觉问答。

II-B 语义场景记忆
一个互补的方向是围绕语义表示构建机器人的长期记忆。基于视图的系统（如 ReMEmbR [1]）累积观测级嵌入以进行检索增强推理，而对象级方法则将基础模型特征嵌入到 3D 表示中，如点云 [7] 或场景记忆 [19]。最近的一种方法 [6] 进一步将其扩展为具有详细时空描述的分层 4D 场景图。然而，视图级记忆并不强制执行显式的跨会话数据关联；对“椅子”的两次观测可能对应也可能不对应同一个物理实例。以对象为中心的语义地图在单个会话内运行，通常只提交到最新状态而不对转换进行建模，表现出与以几何为中心的系统相同的时间失忆。即使是按需回忆原始观测的检索代理 [5] 也只保留原始记录，因此这两个家族都没有维护纵向以对象为中心的推理所需的、结构化的、已解决身份的时间历史。

II-C 3D 基础模型与感知-推理差距
密集重建方法（如 DUSt3R [18] 和 MASt3R [13]）无需特定任务训练即可实现度量准确的多视图几何，而通用分割模型（如 SAM3 [3]）则提供了跨不同环境的实例级对象提取。然而，单纯提高感知精度并不能解决长期存在的更新困境：是覆盖还是累积相互冲突的观测。LT-Mem 通过将空间接地对象实例与控制身份和更新逻辑的波动性条件化推理层相结合，弥合了这一差距，产生 Tri-Memory 结构作为其异构输出的自然组织。

III 方法
III-A 问题表述
我们考虑一个在 $T$ 个会话（即在不同时间进行的独立建图运行）$S_{1},\ldots,S_{T}$ 中观测到的环境，其中对象可能移动、出现、消失或被暂时遮挡。对于会话 $S_{t}$ 中的每个对象 $q$，感知层产生一个 3D 观测 $o_{t}^{q}=\left(\mathbf{c}{t}^{q},\;v{t}^{q},\;\mathbf{f}{t}^{q}\right),$ (1) 其中 $\mathbf{c}{t}^{q}\in\mathbb{R}^{3}$ 是质心，$v_{t}^{q}$ 表示体积，$\mathbf{f}_{t}^{q}$ 是从分割区域提取的视觉嵌入。系统维护一个持久记忆 $\mathcal{M}^{q}$，该记忆在每个会话后更新，以支持长期时间查询，例如“白椅子现在在哪里？”和“机器狗移动的频率是多少？”

III-B 感知层
III-B 1 多会话 SLAM (SLAM)
我们基于 MASt3R-SLAM [13] 构建，该系统使用 3D 重建先验从单目视频中估计相机姿态和密集点云地图。为了将跨会话的观测对齐到一个共享的全局框架中，我们基于 MR.ScaleMaster [8] 构建，该系统通过 $\mathrm{Sim}(3)$ 锚点节点 [9] 估计每个会话的尺度。每个会话 $S_{t}$ 在会话局部框架中维护关键帧姿态 $X_{i}^{t}\in\mathrm{Sim}(3)$，而锚点节点 $A^{t}\in\mathrm{Sim}(3)$ 将此局部框架映射到全局框架，因此关键帧 $i$ 的世界框架姿态为 $T_{i}^{t}=A^{t}\cdot X_{i}^{t}$。会话间回环闭合是通过使用 MASt3R [12] 跨会话匹配关键帧图像，并通过基于射线的几何优化计算相对 $\mathrm{Sim}(3)$ 约束来建立的。生成的因子图包含会话内里程计边和会话间回环闭合边，使用 g2o [11] 进行联合优化，从而产生跨所有会话的全局一致轨迹。这种多会话对齐为 LT-Mem 提供了空间主干。由于所有每个会话的对象观测都在同一个全局坐标系中表示，推理层可以直接比较跨会话的对象质心，并检测诸如位移或消失之类的状态转换。

III-B 2 实例分割与 3D 提升
对于会话 $S_{t}$ 中的每个关键帧，我们应用带有文本提示的 SAM3 [3] 来获取 2D 实例掩码。给定来自 SLAM 后端的全局一致姿态和密集点云地图，每个掩码区域被投影到全局框架中以获取每个实例的 3D 点，从中计算出质心 $\mathbf{c}^{q}{t}$、体积 $v^{q}{t}$ 和视觉嵌入 $\mathbf{f}^{q}{t}$。在一个会话内，使用空间一致性和点云聚类合并同一实例的碎片化检测结果，从而为每个会话中的每个对象产生一个合并的观测 $o^{q}{t}$。

III-C 推理层
III-C 1 跨会话重新识别
当重访环境时，单纯的几何邻近性不足以保持身份。给定一个会话级观测和来自先前会话的候选轨迹，我们计算五个归一化证据评分（表 II）。重新识别置信度是它们的加权组合，其中每个 $E_{i}\in[0,1]$ 且 $\sum_{i}w_{i}=1$。为了减少搜索空间，通过在持久向量存储上进行基于嵌入的检索来预过滤候选轨迹。基于余弦相似度检索前 $k$ 个（在所有实验中 $k=5$）候选者。如果检索没有产生高置信度的候选者，则考虑所有具有兼容语义标签的跨会话轨迹。最终关联遵循混合策略。简单情况由确定性硬规则解决（例如，首次观测、类别不匹配）。模糊的跨会话情况被委托给一个受限的 LLM 裁判，该裁判在严格受限的输出空间下输出匹配、新轨迹或保持之一。因此，结构化证据控制大多数关联；LLM 仅在最终消歧时被调用，并且不修改证据评分，严格在预计算的结构化输入上运行。

表 II：用于跨会话重新识别的证据评分。
评分 | 线索 | 作用
$E_{1}$ | 空间邻近性 | 弱先验；避免惩罚位移
$E_{2}$ | 时间连续性 | 跨连续会话的稳定线索
$E_{3}$ | 特征相似性 | 主要信号；对视角变化具有鲁棒性
$E_{4}$ | 运动一致性 | 以波动性估计为条件
$E_{5}$ | 遮挡处理 | 抑制错误消失

III-C 2 结构完整性检查
在更新记忆之前，我们使用结构锚点验证全局对齐质量。对于每个会话，将当前会话中观测到的锚点质心与其在 Live Memory 中注册的位置进行比较。我们计算所有匹配锚点的平均锚点位移 $\bar{d}{\text{anchor}}$。如果 $\bar{d}{\text{anchor}}>\tau_{\text{align}},$ 则触发会话保持：该会话的所有更新都被跳过，并记录一个对齐失败事件。这种机制防止了在全局未对齐情况下损坏的观测传播到记忆中。

图 3：三个 LT-VQA 环境和数据集概览。每列显示一个全局对齐的 3D 点云地图，叠加了多会话轨迹（上）和代表性 RGB 帧（下）。（左）Lab-S：一个紧凑的室内房间，有 10 个被跟踪对象。（中）Lab-L：一个更大的室内空间，布局更复杂。（右）Parking Lot：一个用于空间统计评估的室外场景。轨迹颜色区分各个会话；由于重新定位和暂时消失，对象配置在会话之间发生变化。

III-C 3 变化检测
我们计算会话间位移 $d=|\mathbf{c}{t}^{q}-\mathbf{c}{t-1}^{q}|$。我们不是依赖单一阈值，而是应用一个按优先级排序的确定性规则集，该规则集考虑： 对齐质量， 缺失证据信号（从旧位置消失），以及 以波动性为条件的运动容差。

III-C 4 波动性感知记忆更新
波动性评分 $V_{t}\in[0,1]$ 使用归一化证据累积规则进行更新：
$V_{t}=\frac{P(E_{t}\mid V_{t-1})\,V_{t-1}}{P(E_{t}\mid V_{t-1})\,V_{t-1}+P(E_{t}\mid 1{-}V_{t-1})(1{-}V_{t-1})},$ (2)
其中 $E_{t}\in{\textsc{none},\allowbreak\ \textsc{move},\allowbreak\ \textsc{appear},\allowbreak\ \textsc{disappear},\allowbreak\ \textsc{re-appear}}$ 被建模为 $V$ 的固定单调函数（例如，$P(\textsc{move}\mid V)$ 随 $V$ 增加），作为一个轻量级的时间证据累积器，并且不是学习得到的。初始先验 $V_{0}$ 是通过对对象语义标签进行一次性 LLM 查询获得的。图 5 说明了 LT-Mem 如何针对具有不同动态的对象跨会话更新 $V_{t}$；经验行为在第 IV 节中讨论。给定变化决策和波动性估计，确定性更新策略选择三种动作之一：
• 保持：在低置信度或遮挡下保留先前状态，
• 覆盖：提交新状态，
• 多假设：保留竞争的位置假设。
在多假设下，维护一小组带有置信度评分的候选状态。当一个假设的置信度在连续会话中超过竞争假设一个边际 $\Delta$ 时，该假设被提升。随着一致证据在主导位置上累积，竞争假设被合并。对于当前状态查询，使用最高置信度的假设。

III-D 三重记忆架构
上述更新动作产生三种不同类型的输出：当前状态估计、带时间戳的事件记录和长期统计数据。为了组织这些异构输出，记忆 $\mathcal{M}^{q}$ 被结构化为三个互补组件（图 1）。我们强调，Tri-Memory 设计并不是作为一个独立的架构贡献提出的；相反，它是波动性感知推理层的直接结果，该层产生不同的输出——状态估计、事件记录和长期统计数据——这些输出如果不重新引入第 II 节中描述的时间失忆，就无法折叠成单一的地图表示。我们注意到，delta 和 meta 地图的术语在终身建图文献 [10] 中是有先例的，在那里它们表示几何点云差异和用于检测和移除过时空间元素的地图级统计。相比之下，LT-Mem 的 Delta 和 Meta Memory 在对象语义级别上运行：Delta Memory 记录保持身份的状态转换（例如，一把特定的椅子在会话 $S_{5}$ 中从 A 移动到 B），而 Meta Memory 积累每个对象的行为统计，例如反馈到更新策略中的波动性评分。这种从点级地图差异到对象级事件记录的转变，使得纯几何 delta 地图无法支持的结构化时间查询成为可能。

Live Memory 存储每个对象的当前确认状态。当更新策略选择覆盖时，先前状态被替换；在多假设下，一小组竞争的位置假设及其置信度评分被保留。当前状态查询（例如，“白椅子现在在哪里？”）直接从该组件解决。

Delta Memory 记录带时间戳的、每个对象的事件日志。每个更新动作都会附加一个结构化条目：移动、出现、消失、重现或无，以及会话索引和度量上下文（例如，位移幅度）。来自结构完整性检查的对齐失败事件也被记录下来，即使在更新被抑制时也保留可审计的记录。事件历史查询（例如，“剪刀什么时候首次出现？”）和反事实查询（例如，“机器狗在 S1 和 S10 的位置相同吗？”）通过遍历此日志来回答。

IV 实验
IV-A 数据集
我们构建了 LT-VQA，一个受控的多会话数据集，用于评估长期以对象为中心的场景理解。它共同提供全局对齐的多会话几何、持久的对象实例身份、事件级状态转换标注以及会话索引的时间 QA 对。虽然 3RScan [17] 提供了跨重扫的实例级对应，但它缺乏事件级标注和时间 QA 监督。据我们所知，没有现有的多会话数据集同时提供这些组件；与单会话 VQA 不同，跨会话事件标注需要对每个对象进行细致的多时间对齐，使得密集标注本质上资源密集。两个室内环境 Lab-S 和 Lab-L，各自在 10 个会话中跟踪 10 个对象，跨会话的对象配置不断演变（表 III），从高度波动的实例（例如，棕色篮子、剪刀）到完全静止的实例（例如，冰箱、沙发）。表 I 中列出了每种事件类型的代表性查询。真值标注提供每个会话的事件标签（出现、消失、移动、重现、无）；标注统计如图 6 所示。Parking Lot 序列将评估扩展到室外环境，在不同日期和一天中的不同时间记录了 10 个会话，针对聚合的时空模式。

IV-B 实验设置
数据收集。所有序列均捕获为单目 RGB 视频（Lab-L 和 Parking Lot 使用 iPhone 15 Pro；Lab-S 使用 iPhone 17 Pro），并通过我们的多会话 SLAM 流程处理。
实现细节。所有实验均在配备 64 GB RAM 的 NVIDIA RTX 5070 Ti GPU 上进行。对于依赖 LLM 的组件，LT-Mem 和适用的基线都使用 Gemini 2.5 Pro 以确保一致的比较。以对象为中心的检索使用 BGE-small-en-v1.5 和 ChromaDB，在检索期间不调用 LLM。对于跨会话重新识别（表 II），证据权重为 $w_{1}=0.05$，$w_{2}=0.20$，$w_{3}=0.45$，$w_{4}=0.15$，$w_{5}=0.15$。对齐门控阈值（第 III-C2 节）为 $\tau_{\text{align}}=0.3$ m。

我们报告了实例历史跟踪的三个指标。事件表示连续会话之间的对象级状态转换——移动、出现、消失、重现或无之一。事件 F1 将每个真值事件视为一个正实例，测量检测精度和召回率。QA-Event 测量关于对象事件历史的自然语言查询的精确匹配准确率（例如，“在第 6 次会话时机器狗发生了什么？”）。QA-Freq 根据在 Meta Memory 中累积的真值统计评估频率查询（例如，“机器狗移动了多少次？”）。QA-Event 和 QA-Freq 通过将结构化 JSON 输出与真值标注匹配来自动评估。

对于实例历史跟踪，我们与代表多会话对象推理不同范式的四个基线进行比较。诸如 Khronos [16]、ConceptGraphs [7] 和 ReMEmbR [1] 等现有系统不产生对象级事件日志或支持时间 QA，而增强它们以实现这一点将需要超出其原始设计范围的模块。相反，我们的基线隔离了核心推理范式以实现受控评估。
仅几何。遵循以几何为中心的终身建图范式 [10]，我们构建了一个基线，该基线通过会话观测上的距离阈值来检测对象级变化。由于此方法仅维护当前地图状态而没有事件日志，因此事件历史和频率查询在结构上无法回答，报告为 N/A。

表 V 报告了 Lab-S 和 Lab-L 合并的结果。仅几何基线通过距离阈值实现了合理的 Event F1，但在没有事件日志的情况下无法回答任何时间查询（N/A）——这是时间失忆的直接后果。文本批处理在所有指标上得分均较低，证实了没有空间接地或跨会话身份的帧级描述不足以进行时间推理。VLM 批处理在具有每个对象的完整视觉上下文的情况下取得了有竞争力的分数，但 token 成本要高得多。STAR 尽管消耗的 token 最多，但 Event F1 最低：没有持久的身份或事件日志，其对原始记录的每次查询检索无法组合连贯的对象历史，并且需要结构化计数的频率查询无法回答（N/A）。表 V 中的 token 计数反映了评估集上的累积运行时 token 使用量；感知（分割、特征提取）是一次性离线成本，分摊到所有后续查询中。Gemini 2.5 Pro 和 Qwen2.5-3B 的计数反映了每个模型的原生分词器；尽管绝对值不同，但两者都远低于基于视觉的基线，后者通过反复向模型输入原始帧或视觉记录来消耗更多的 token。LT-Mem 通过在感知期间将视觉观测转换为结构化表示，从而使得推理层仅接收紧凑的文本输入，因此所需的 token 要少得多。由于 LT-Mem 的每个会话 token 预算与帧数无关，随着会话的增长，这种差距会扩大——这是终身操作的一个关键优势。LT-Mem（完整版）在所有适用的指标上始终优于所有基线，即使使用 Qwen2.5-3B 作为轻量级本地 LLM，这也表明增益源于结构化的记忆架构，而非 LLM 的容量。

IV-G 消融研究
表 VI 展示了 Lab-S 和 Lab-L 合并的组件级消融结果。
结构完整性检查：在所有实验中，平均锚点位移保持在门控阈值以下；没有会话被拒绝。这证实了多会话 SLAM 对齐（第 III-B 节）为下游推理提供了足够准确的全局配准。

波动性感知更新的效果：用以固定阈值替换以波动性为条件的更新（无波动性）会降低所有指标，因为固定阈值无法适应每个对象的动态，从而产生破坏 Meta Memory 统计数据的错误事件。

V 结论
我们引入了 LT-Mem，一个波动性感知的记忆演化框架，它将多会话空间对齐与用于终身机器人操作的波动性条件化更新逻辑统一起来。由此产生的 Tri-Memory 结构同时保留当前状态和事件历史，从而实现了仅维护单一当前地图状态无法实现的纵向以对象为中心的推理。在 LT-VQA 上的实验验证了结构化记忆演化在保留对象历史和支持跨多会话重访的时间查询方面的有效性，其具有可扩展到更长部署的实用 token 效率。虽然 LT-VQA 目前包含两个室内和一个室外环境，跨越 10 个会话，但更广泛的验证将进一步评估泛化能力。当多个对象共享相似的外观和空间上下文时，跨会话重新识别仍然具有挑战性，这反映了在模糊性下保持身份的根本困难。扩展到更长的部署周期和更多样化的环境，以期将 LT-VQA 建立为纵向以对象为中心的推理的公共基准，是未来工作的一个有前景的方向。
