摘要

为真实设备选择量子纠错码，意味着需要用电路级仿真对候选码进行评分，而这类仿真非常缓慢，只能运行几百次。因此每一次评估都很宝贵，一个搜索方法的优劣取决于它在每次付费评估中能找到多少好码。由少数群元素构造的量子LDPC码可以保护许多逻辑量子比特，但在巨大的空间中好码十分稀少。我们提出GFlowQEC，据我们所知，这是首个用于量子码设计的生成流网络。它每次添加一个群元素来构建码，并学习按码得分的幂次成比例地提出码。我们用早期搜索得到的分数对其进行一次训练，然后将其冻结，让它提出具有180个物理量子比特的提升积码，并以距离作为评分标准。在每次付费调用中对其抽取的十个候选进行排序，它找到的新顶级码（与其训练过的任何码不等价）数量是调优并行回火的两倍多，即使回火从GFlowQEC的训练码开始也是如此。它找到的顶级码数量是每次调用排序十个随机候选的监督筛选器的三倍半以上。当两者都排序一百个候选时，筛选器超过了GFlowQEC，而对GFlowQEC抽取的候选进行排序的筛选器表现最佳。软Q学习与GFlowNet共享最优策略，在一个噪声偏置下表现相当，在另一个偏置下表现更好，因此这种增益并不依赖于GFlowNet的训练损失。当好码稀少时，训练有素的提议器可以让昂贵的评估预算发挥更大作用。

关键词： 量子纠错、量子LDPC码、生成流网络、码搜索

1 引言

量子低密度奇偶校验（LDPC）码可以在单个物理量子比特块中保护许多逻辑量子比特[25, 6]。其中许多码由有限群元素的短列表指定，由于每个列表都给出一个有效码[23, 31]，设计一个码就相当于在列表空间中进行搜索。这一搜索之所以困难，有两个原因。空间巨大：Bhardwaj等人[4]的[[300,60,14]] mitten码是一个包含十个元素的列表，这些元素来自一个有六十个元素的群，而该长度的列表最多可给出约3×10⁸个不等价的码。而且每个候选码都必须评分，要么通过计算其距离，要么通过模拟其失败频率，每个码需要大约一秒到几分钟。因此，搜索只能看到空间的一小部分。

我们的动机场景是为特定设备选择码。在那里，每个候选码通过电路级仿真评分，包括有故障的测量和真实的解码器，每个码需要几分钟到几小时，因此一次搜索只能评分几百个码[42, 5, 4]。由于最佳码也可能随设备的噪声和连接性而变化[5, 3]，较便宜的评分只能为昂贵的仿真筛选候选码，因此搜索应该在其预算内提供许多好的候选码，而不是单一的最佳码[1]。由于在该成本下还无法公平地比较各种方法，我们在评分足够便宜、可以多次运行每种方法的环境中进行比较，但我们保留了在设备上重要的成本单位：付费调用，即对运行中尚未评分过的码调用评分例程（预言机）一次。

贝叶斯优化、强化学习、过滤均匀采样和大语言模型（LLM）已被用于搜索此类码族，表1将这些搜索与我们的工作进行了比较。然而，它们都没有训练模型按码质量的比例来采样码。

学习可以通过两种方式将固定预算转化为更多好码。筛选器抽取随机候选码，只对学习模型排名最高的候选码付费，而提议器则学习直接抽取好的候选码。当好码稀少时，这种差异很重要：筛选器必须查看许多随机候选码才能保留一个，而提议器将这种拒绝机制内建到自己的抽取过程中。

生成流网络（GFlowNet）[1, 2]就是这种提议器。GFlowNet逐步构建对象，并经过训练使其在最优状态下以与奖励成比例的概率产生每个对象，这意味着一个模型可以产生许多不同的好对象，而奖励最大化则会收敛到一个对象[1]。据我们所知，尚未有GFlowNet被用于设计量子纠错码。

本文做出两项贡献：

  • 我们提出GFlowQEC，这是一个GFlowNet，其策略每步填充一个群元素，并使用轨迹平衡[41]进行训练，以与列表得分的幂次成比例的概率产生每个列表。
  • 作为概念验证，我们在具有180个物理量子比特的提升积码上测试该策略，其中它在早期搜索存储的分数上训练一次，冻结，并在匹配的付费调用预算下与调优并行回火、监督筛选器和软Q学习进行比较。

在180个物理量子比特下，冻结策略为每次付费调用抽取十个候选码，并对其排名最有可能的候选码付费。仅计算与其训练码不等价的码，它每次付费调用找到的顶级码数量是调优并行回火的两倍多，在我们测试的两种噪声偏置下分别为2.4倍和2.8倍，其中比特翻转比相位翻转可能性高十倍或相反。从相同的存储码开始，调优PT并没有缩小差距，因此领先优势不仅仅来自对存储数据的访问。它找到的顶级码数量也超过建立在相同网络上并用相同分数训练的监督筛选器的三倍半。由于这里大约只有百分之一的随机码是顶级码，每次付费调用只看十个随机码的筛选器很少能看到顶级码。当每次付费调用显示一百个随机码时，筛选器找到的码比策略多，而所有方法中数量最多的是对策略自身抽取的候选进行排序的筛选器。以相同方式训练的软Q学习（在我们的构造上与GFlowNet共享最优策略[38]）在一个偏置下表现相当，在另一个偏置下表现更好，因此增益不依赖于GFlowNet的训练损失。

2 相关工作

码搜索。 在这种设置下，简单的基线方法很强：Freire等人[13]像我们一样在匹配预算下用同一个预言机比较方法，他们发现在超图积码上，随机游走与模拟退火和强化学习相当。除表1外，LLM智能体还在电路级噪声下搜索[42]，并在平衡积码上搜索[32]。强化学习已将小码粘合成最多20个物理量子比特、一个逻辑量子比特的码[36]，并找到了九个物理量子比特上的码及其编码器，噪声偏置作为输入[29]。我们没有重新实现LLM搜索[11, 24, 42, 32]，因为它们的预言机和预算与我们的不同，而且它们的模型可能在预训练期间见过这些码族的已发表码。

GFlowNet。 在树上（每个对象只有单一构造路径），GFlowNet训练等价于熵正则化强化学习，如软Q学习[38]。条件GFlowNet将奖励的参数作为输入，例如Logit-GFN中的奖励温度[19]或GFlowQEC中的噪声偏置。仅在存储的奖励上训练GFlowNet，不使用奖励模型也不调用新的预言机，是一种成熟的设置[8]。像该工作的简单基线一样，GFlowQEC直接在其存储的码上训练，并增加了对偏置的条件化以及对自身抽取候选进行排序的部署方式。GFlowNet也已应用于量子电路：FlowQ-Net[12]逐门构建量子电路，并将量子纠错码合成列为其未来应用之一，QFlowNet[21]将GFlowNet应用于酉综合。

3 背景

3.1 量子LDPC码

量子比特上的错误是比特翻转（X）、相位翻转（Z）或两者兼有（Y）。Calderbank-Shor-Steane（CSS）码[7, 35]由两个二进制矩阵H_X和H_Z指定，每个矩阵每个物理量子比特对应一列，共n列。每行是一个校验，即对行中为1的量子比特进行奇偶校验测量，当且仅当 H_X H_Z^𝖳 = 0 (mod 2) 时，这对矩阵定义一个有效码。(1)

逻辑量子比特数为 k = n − rank H_X − rank H_Z，(2)

其中秩在F_2（只有两个元素的域，即模2算术）上计算。相位翻转模式 e_Z ∈ F_2^n 标记被击中的量子比特，其重量|e_Z|是被击中量子比特的数量。当 H_X e_Z ≠ 0 时，X校验检测到该模式，Z校验以相同方式检测比特翻转e_X。全文中，e、d和p的下标X或Z表示翻转类型，因此e_Z、d_Z和p_Z都指相位翻转。

H_Z的行之和，视为相位翻转，是Z稳定子：它们不改变码的状态，且不被X校验检测到（式(1)）。其他所有未检测到的模式都会改变编码信息，是逻辑算符，每种类型最轻的逻辑算符定义距离：

d_Z = min{|e_Z| : H_X e_Z = 0, e_Z ∉ rowspace H_Z}，(3)
d_X = min{|e_X| : H_Z e_X = 0, e_X ∉ rowspace H_X}，
d = min(d_X, d_Z)，

其中rowspace H是H的行之和的集合。具有这些参数的码记为[[n,k,d]]。其Tanner图每个量子比特和每个校验各有一个顶点，校验行中为1的地方有一条边。对于量子LDPC码，该图是稀疏的[25]。

3.2 群上的提升积码

我们码族中的码由群G的十个元素的元组x指定，本文中的每个搜索方法都提出这样的元组。我们使用 G = Z_6 × S_3，其元素将Z_6（模6整数加法群）的一个元素与三个对象的六种排列之一（群S_3）配对，逐项组合，因此G有|G| = 36个元素。当乘积顺序不影响结果时，群是阿贝尔群，而G不是。像 a = g_1 + g_2 + g_3 这样的和是群元素的集合。|G| × |G|二进制矩阵λ(a)和ρ(a)，行列由G的元素索引，分别左乘和右乘a：λ(a)的第v列标记元素gv，ρ(a)的第v列标记元素vg，对a中的每个g。两者只有在G是非阿贝尔群时才不同。最后，和a将a的每个元素替换为其逆元，因此λ(a)和ρ(a*)分别是λ(a)和ρ(a)的转置。

我们的码族扩展了Bhardwaj等人[4]的mitten码（其定义4），这些码定义在非阿贝尔群上，因为在阿贝尔群上其构造的距离最多为6。十个群元素和单位元1形成四个由三个不同元素组成的和：

a_1 = g_1 + g_2 + g_3，
a_2 = 1 + g_4 + g_5，(4)
b_1 = h_1 + h_2 + h_3，
b_2 = 1 + h_4 + h_5。

基矩阵以和为条目，当每个条目被其|G| × |G|矩阵替换时变为二进制矩阵。mitten码是行(a_1 a_2)和列(b_1 b_2)^𝖳的提升积[31, 30]，在我们的约定中，行通过λ进入，列通过ρ进入：

H_X = (λ(a_1) 0 λ(a_2) 0 ρ(b_1); 0 λ(a_1) 0 λ(a_2) ρ(b_2))，(5)
H_Z = (ρ(b_1) ρ(b_2) 0 0 λ(a_1); 0 0 ρ(b_1) ρ(b_2) λ(a_2))，

其中0是|G| × |G|零矩阵。该码有 n = 5|G| = 180 个物理量子比特，重量为9的校验，并且由式(2)，k ≥ |G|。Bhardwaj等人还要求λ(a_2)和ρ(b_2)可逆，这给出k = |G|。在Z_6 × S_3上，a_2和b_2的595种选择中只有123种满足这一要求。我们去掉了这一要求，因此我们的码族大得多，包含k > |G|的码。在该码族中d_X和d_Z可以不同，因此最佳码取决于比特翻转和相位翻转之间的偏置。

在每个和乘以一个群元素使其包含单位元后，我们要求a_1和a_2的元素生成G，即G的每个元素都是它们及其逆元的乘积，b_1和b_2的元素同样如此。这丢弃了所有分裂为较小码的不连通副本的码[23]。

3.3 GFlowNet

GFlowNet[1, 2]每步构建一个对象片段。一个参数为θ的神经网络，称为策略，选择每个片段，并训练其以与正奖励成比例的概率产生每个完整对象：

p_θ(x) = R(x) / Σ_{x'} R(x')，(6)

其中x'遍历所有完整对象。当对象太多无法列出时，总奖励无法计算，因此它与网络一起作为标量Z_θ被学习。

4 搜索空间与预言机

4.1 等价码与规范形式

当重新标记量子比特和校验可以将一个CSS码的矩阵变为另一个的矩阵时，两个CSS码等价，等价码共享n、k、d_X和d_Z。对元组的四种操作产生等价元组：重新排序和中的元素、平移一个和（将其所有元素乘以一个群元素）、通过自同构重命名G的元素（尊重乘法表的一对一重命名），以及仅对g_i或仅对h_i进行共轭（对某个g，g_i → gg_ig⁻¹）。元组的规范形式只撤销重新排序和平移。两个不同的规范形式仍可能是等价码，图同构程序在Tanner图上精确判定等价性。码的镜像交换H_X和H_Z，使d_X和d_Z互换，我们将码及其镜像计为两个码。

4.2 预言机与参考样本

预言机返回元组x对应码的得分s(x)，码越好得分越高。每个搜索方法只从预言机获取分数，预言机首先将元组替换为其规范形式。运行中已评分的形式从内存中免费回答，而新形式是付费调用，因此方法的成本是其付费调用次数。

评分假设每个量子比特以概率p_X发生比特翻转，并独立地以概率p_Z发生相位翻转。噪声偏置 γ = log₁₀(p_X/p_Z) 表示哪种翻转更可能，而较稀有的翻转固定为10⁻³。相位翻转距离为d_Z的码可以纠正所有少于d_Z/2个相位翻转的模式，因此击败它的最轻模式的概率约为 p_Z^(d_Z/2)，比特翻转与d_X和p_X的情况相同。我们称之为失败指数的得分，计算这两种失败中更可能的那种被抑制的数量级：

s(x, γ) = min(c_X d_X, c_Z d_Z)，(7)
c_X = ½ log₁₀(1/p_X)，c_Z = ½ log₁₀(1/p_Z)。

例如，得分10意味着最轻的不可纠正错误的概率约为10⁻¹⁰。我们在γ = ±1下报告结果，其中更可能的翻转概率为10⁻²，系数为1.0，较稀有的翻转系数为1.5。当偏置固定时，我们记为s(x)。

顶级码的阈值是均匀参考样本中的最高得分，即1,000次均匀抽取中元素生成G的666个，每个都有精确距离：在γ = ±1时为10.0，666个中有6个达到。因此，顶级码在γ = +1时 d_X ≥ 10 且 d_Z ≥ 7，在γ = −1时相反。相比之下，在γ = 0时，666个中有116个共享样本最高得分，因此该阈值无法区分方法。搜索运行认证的最佳码具有 d_X = d_Z = 10，因此它们是k ≥ 36的[[180, k, 10]]码。

精确距离来自我们所说的SAT阶梯，这是可满足性求解器的成熟用法[9]。对于w = 1, 2, …依次，阶梯询问是否存在重量至多为w的逻辑算符，在其预算内未决的问题使阶梯停在某个下界。两个这样的阶梯，即精确阶梯，给出d_X和d_Z。它们很昂贵，因此每个新码首先获得一个便宜且略微乐观的界限得分。它使用d_A和d_B，即校验矩阵为(λ(a_1) | λ(a_2))和(ρ(b_1) | ρ(b_2))的经典码的距离，由同类阶梯（经典阶梯）计算。第一个码的最轻码字放在五个量子比特块中的两个上，是没有X校验检测到的相位翻转模式，因此除非它是稳定子，否则 d_Z ≤ d_A，同样 d_X ≤ d_B。界限得分是用d_B和d_A代替d_X和d_Z的式(7)。

在γ = ±1时，每当界限得分达到阈值或经典阶梯未决时，同一付费调用也会运行精确阶梯。运行过精确阶梯的码是认证的，当它们证明的得分达到阈值时，它被计为顶级码。提前停止的阶梯（0.7%的认证码会发生这种情况）或失败的经典界限可能使好码未被计数，但都不能使坏码被计数。在单个CPU核心上，界限得分中位数需要0.8秒，平均1.5秒，而精确阶梯在均匀抽取上需要约10秒，在认证码上需要约2分钟。

5 GFlowQEC

GFlowQEC的策略是一个因果transformer[39]，它一次构建元组x的一个位置（槽位），其训练目标是

p_θ(x) ∝ R(x) = max(s(x), 0.01)^β，(8)

其中p_θ(x)是策略构建x的概率，得分s(x)被钳制在0.01，指数β > 0设置策略偏爱高得分的程度。图1显示了其训练和部署。

图1： GFlowQEC（n = 180）。槽位行是元组，灰色槽位固定为单位元，Tanner图是码。 训练，无预言机调用：(1) 存储形式x及其得分s和偏置γ，给出其奖励R(x, γ)，(2) 增强，并以概率1/2通过M镜像，γ ↦ −γ，(3) 由transformer（三个块，因果掩码着色）读取，它将偏置作为其起始标记上的条件z，(4) 轨迹平衡损失，将R(x, γ)与Z_θ(z) p_θ权衡，及其梯度步（虚线）。 部署：(1) γ = ±1处的冻结策略，(2) μN个抽取形式（第5.4节），(3) log p_θ(x | z)最高的N个，(4) 预言机的界限得分和SAT认证，(5) 存储形式之外的顶级码。

5.1 逐槽构造

元组有T = 10个槽位，策略按g_1, …, g_5，然后h_1, …, h_5的顺序填充。我们将槽位t中的元素记为x_t，其之前的元素记为x_{<t}，策略对x_t的概率记为 P_F(x_t | x_{<t}; θ)。槽位g_1和h_1固定为单位元。通过平移，这在等价意义上不丢失任何码，并且它将单位元放入每个和中。为了保持每个和中的元素不同，掩码将其他每个槽位t限制到其合法集合，即群去掉单位元和已放在同一和中的元素：

A_t(x_{<t}) = G \ ({1} ∪ {x_{t'} : t' < t, t'与t在同一和中})。(9)

当 g_1 = h_1 = 1 且其他每个元素都在其合法集合中时，元组是合法的，因此有 ((|G|−1)(|G|−2))⁴ 个合法元组。一个便宜的测试，生成检查，无需预言机调用即可判断元素是否生成G，未通过检查的元组永远不会发送给预言机。

5.2 目标函数与β的选择

因为部分填充的元组只能通过按顺序填充其槽位来到达，部分元组的图（其每条边添加一个元素）是一棵树。产生x的概率是槽位概率的乘积：

p_θ(x) = ∏{t=1}^{T} P_F(x_t | x{<t}; θ)。(10)

轨迹平衡[41]要求 Z_θ p_θ(x) = R(x)，我们最小化两边对数之间的平方差距：

L(x) = (log Z_θ + Σ_{t=1}^{T} log P_F(x_t | x_{<t}; θ) − log R(x))²，(11)

其中log是自然对数。我们在训练前通过固定规则将指数设为β = 8：它是1、2、4、8、16、27、40和64中最小的，使得按钳制得分排序的均匀参考样本及其镜像的最佳十分之一持有至少五分之四的总奖励。

5.3 训练数据

策略仅在42次早期运行（几种搜索方法）已付费的分数上训练，因此训练本身不进行预言机调用。这些运行进行了126,000次付费调用，覆盖116,972个不同的规范形式（存储形式），包括表2中种子0到2背后的调优PT运行。每个形式与预言机返回的两个距离一起存储，给出其在任何偏置下的得分（式(7)）：6,770个认证码的精确距离（除了45个其阶梯提前停在某个下界的码），其他110,202个的界限d_A和d_B。

训练期间，每个抽取的元组被替换为具有相同奖励的随机等价元组x̃，通过打乱每个和中的两个自由元素并将g_i用一个随机群元素共轭、h_i用另一个共轭获得，从不通过平移。以二分之一概率，训练元组还被替换为其镜像 M(x) = (h_1⁻¹, …, h_5⁻¹, g_1⁻¹, …, g_5⁻¹)，它构建与x的镜像等价的码，因此它在−γ处的得分是x在γ处的得分，并在相反偏置下以相同奖励训练。单个网络通过将偏置作为输入（条件向量z）来服务两种偏置，每个偏置有自己的学习归一化器Z_θ(z)。我们每个随机种子训练一个模型，共十个，在γ = ±1（它们部署的偏置）下，然后冻结它们。transformer有三个宽度为128的块，四个头（605,863个参数），用Adam[20]训练315,280次更新，每次256个元组，约690遍存储形式。

5.4 部署

冻结策略在γ = +1或γ = −1处提出码。它抽取直到持有μN个不同的规范形式，其中N = 1,000是付费调用预算，μ = 10或100是过采样因子，并且不调用预言机就丢弃每个未通过生成检查或重复形式的抽取。然后它按 log p_θ(x | z)（抽取元组的对数概率）对形式排序，这代替了得分：在零损失下 log p_θ(x | z) = β log max(s(x), 0.01) − log Z_θ(z)，因此在固定偏置下它按存储得分排序存储元组。它为最高的N个各支付一次预言机调用。抽取不与存储形式核对，因此发送的形式可能已被存储，但仍需付费。我们在阅读早期运行后选择了这种排序方式，在早期运行中，按抽取顺序付费在两种偏置的每个种子中都落后于早期的较小监督筛选器。排序找到的顶级码数量是按抽取顺序付费的五倍半以上。

6 实验设置

6.1 对比方法

每个方法使用相同的预言机、搜索空间和预算，运行按随机种子配对。

  • 调优并行回火（tuned PT）[37, 14, 16]在不同温度下运行八条局部搜索链，每次移动均匀重绘一个槽位，采用Metropolis接受[27]和链间交换。它在其自身运行中使用两个温度范围中较好的一个，0.25到2.0，这是一个有利于它的选择。一个变体从存储形式而不是均匀抽取开始其链，这些起始形式从不计入其结果。
  • 监督筛选器使用策略的网络作为预测码得分的回归器。与策略不同，它一次看到所有十个槽位，它还读取在和平移时不改变的特征。它通过平方误差训练来预测相同存储形式的得分，使用策略的增强、批次和种子。其变体和训练长度在存储形式的十分之一留出集上调优，这是策略没有得到的选择，之后在所有形式上训练。部署时，它对十倍或百倍于N的均匀随机候选排序，并为其最高的N个付费。
  • 软Q学习[15]离线训练，使用与GFlowQEC相同的存储分数、网络、训练步骤和部署规则。它共享GFlowNet的最优策略（第2节），因此它测试训练目标是否重要。
  • MAP-Elites[28]是一种进化质量多样性算法，保留廉价码属性网格每个箱中找到的最佳码，我们在两个网格上调优它，五个d_A − d_B箱单独或与四个k箱交叉。
  • 贝叶斯优化（BO）将Matérn 5/2高斯过程拟合到元组的独热编码，在200次均匀抽取后，按预期改进为2,000个均匀候选中的最佳者付费。它不是Chengyu等人[10]的方法，后者使用学习的图嵌入和不同的解码器、噪声率和码族。
  • 均匀采样为通过生成检查的均匀随机元组付费。

我们还在两个熵权重下运行了PPO[33]，在二十箱网格上运行了MAP-Elites，以及在搜索期间训练的软Q学习和Munchausen DQN[40]，每个方法在两种偏置的每个种子中找到的顶级码都比调优PT少。

6.2 度量

主要度量是运行前1,000次付费调用中认证顶级码的数量。当付费码的规范形式不在存储形式中时，它是新颖的。对于在存储形式上训练或从存储形式开始的方法，只计算新颖码，而其他方法从未见过存储形式，因此它们的所有码都计算。因为新颖码仍可能与存储码或其镜像等价，我们还给出不等价计数，它丢弃这些码，并且对每个方法，每个等价类只计算一次。

为了比较两种方法，我们使用它们的合并比率，即将它们的计数（各自在两种方法运行的种子上求和）相除，并使用Katz等人[18]的95%对数比率区间。对于ν_1和ν_2次付费调用中的计数κ_1和κ_2，区间是比率乘以 e^(±1.96ω)，其中 ω² = 1/κ_1 − 1/ν_1 + 1/κ_2 − 1/ν_2。当区间包含1时，我们说两者未被区分。它将每次付费调用视为独立的，这忽略了种子之间和搜索链内的变异，因此我们还给出一种方法领先的种子数。

表2给出了计数，GFlowQEC和监督筛选器在μ = 10。在每个配对种子和两种偏置下，GFlowQEC（下文简称策略）找到的顶级码比表中除离线训练的软Q学习外的任何其他方法都多。下文每对数字依次为γ = +1和γ = −1。

对比调优PT。 在不等价码上，调优PT是没有存储数据的最强方法，尽管五箱MAP-Elites在等价码合并前找到的略多。策略找到的不等价顶级码数量是调优PT的2.4 [2.2, 2.6]和2.8 [2.6, 3.0]倍，并且在其20次运行中的19次中超过两倍。从存储形式开始调优PT并不能缩小差距，因为在相同计数上策略仍找到2.8倍和2.7倍。

对比软Q学习。 离线训练的软Q学习找到的策略新颖码数量的1.01倍和1.15倍，在γ = +1下未被区分，在γ = −1下领先，区间[1.10, 1.19]不包含1。它在十个种子中的7个和8个中领先。

对比监督筛选器。 在μ = 10时，策略找到的顶级码数量是筛选器的3.6倍和3.8倍，并且在十个种子中的每一个中都领先。当两者都在μ = 100过采样时，筛选器在十个种子中的每一个都找到更多，策略找到的数量是其的0.45 [0.44, 0.47]和0.62 [0.61, 0.64]倍。尽管如此，两个对照实验表明策略的优势在于其抽取。在μ = 10时对筛选器的均匀候选而不是自己的抽取排序，策略找到的码数量是从自己抽取的五分之一，且少于筛选器。在μ = 100时对策略的抽取而不是均匀候选排序，筛选器找到的数量是其自身的1.27倍和1.30倍，在每个种子中都更多，因此更好的抽取和更好的排序相结合。

码的来源。 在γ = +1时，上界 d_X ≤ d_B 只依赖于h_i，因此当两个顶级码（无论是否新颖）的h_i在将每个元素用一个群元素共轭的意义上一致时，我们将它们计为一个邻域，在γ = −1时g_i扮演这个角色。在策略的每次运行中，87%到93%的邻域也包含存储的顶级码，因此策略主要是为存储数据中已有的好半部分找到新伙伴。

成本。 策略的付费调用运行精确阶梯的频率是调优PT的3.5倍和4.2倍，这些阶梯在这里主导付费调用的成本。在种子0到2上，按精确阶梯的CPU秒计算，策略和调优PT以相同速率找到顶级码，在两种偏置下相差不超过5%，在不等价计数上调优PT领先。在种子3到9上，两者在不同机器上运行，因此我们不比较它们的CPU秒。

8 讨论

当四个条件同时满足时，训练的提议器最有可能获得回报：好码太稀少而无法通过采样找到，没有从奇偶校验矩阵廉价计算的量能对其进行排序，每次预言机调用都很昂贵，训练成本由多次搜索分摊。在180个物理量子比特下，好码不够稀少，这可能是每次付费调用显示一百个随机码的筛选器超过策略的原因。但逻辑量子比特数k（显而易见的廉价量）并不能挑出顶级码：按k对存储得分排序最多将其顶级码份额提高1.4倍。在四个条件中，只有调用成本已知会增长，既随码的大小增长，也在电路级噪声下增长。而且搜索已经在600到1,500个物理量子比特上运行[24]，超过了穷举目录停止的几百个物理量子比特[22]。

局限性。

  • 增益在于预算能买到多少好码，而不是找到的最佳码。我们没有展示比贝叶斯优化、强化学习或LLM驱动搜索找到的更好的码。在这个规模上，好码也不需要训练的策略，因为均匀采样每1,000次付费调用找到约十个顶级码（表2）。
  • 领先是按付费调用计数的，存储数据（第5.3节的126,000次付费调用，而每次运行为1,000次）或策略训练不收取任何费用，并且按精确阶梯的CPU秒计算它会消失（第7节）。
  • 得分仅从距离计算（式(7)），没有解码器。我们尚未测量具有故障校验测量和真实解码器的电路级噪声是否会重新排序码。
  • 我们将策略用作对自己抽取进行排序的提议器，尚未测试它是否按奖励比例采样。

9 结论

在存储得分上训练一次并在180个物理量子比特下冻结使用，GFlowQEC每次付费调用找到的顶级码数量是调优PT的两倍多，只计算与其训练数据不等价的码。增益在于候选码，而不是训练损失，因为软Q学习表现相当或更好，而筛选器在对策略的抽取排序时表现最佳。

未来工作。 为设备选择码的下一步是在电路级噪声下重新评分180个物理量子比特的顶级码，看它们的排名是否保持。然后，提议器将在该成本下评分，与Chengyu等人[10]的方法在该方法设计的预算（几百次昂贵预言机调用）下进行比较。通过多目标GFlowNet[17]以测量噪声为条件的策略可以在每次校准后提出一组新的好码，而无需运行新的搜索。

我们瞄准的场景是量子编译器自己选择码。中性原子量子计算的战略计划[26]呼吁编译器从应用和硬件规范中选择码，并将生成神经网络列为能找到适合设备噪声和操作约束的码的方法之一。GFlowQEC作为条件生成器适合这一角色，其中一个策略可以回答每个请求。请求的硬约束，如设备的连接性、校验重量或k的下限，将内建到式(9)的掩码中，其噪声模型将通过条件z进入。

单个策略也可以跨码族搜索，如果每个动作依次选择构造的一个层级：码族、群、基矩阵和填充它们的和。Liu和Marquardt[24]让语言模型变异这种三级语法，而我们的将是一个选择每个层级的训练策略。
