摘要
思维链推理提升了多步问题解决能力，但过长的推理轨迹会增加推理成本。Token 级别的 CoT 压缩通过将完整推理链剪枝为更短的轨迹以进行模型适配，从而降低成本，这使得 Token 选择成为核心挑战。
现有方法通常依赖外部评分器或仅与模型内部答案计算间接相关的启发式信号。
我们转而采用模型内部的视角：当模型生成答案时，每个推理 Token 都会在残差流（即模型的“思维流”）中留下涟漪，该涟漪的幅度反映了该 Token 对答案计算的贡献。
基于这一观点，我们提出了 MIST（用于 Token 级 CoT 压缩的模型内部显著性），它沿着两个互补的轴定义 Token 重要性：必要性（即移除 Token 的内部贡献时答案似然的下降程度）和充分性（即仅提供该贡献时答案似然的增加程度）。将两者结合可产生用于剪枝的统一重要性评分。
在四个推理基准和四个模型上，MIST 始终优于基线方法，这表明模型内部显著性为推理 Token 重要性提供了有效的代理。

1 引言
思维链推理（wei2022chain; kojima2022large; wang2023selfconsistency）提升了大语言模型（LLMs）的多步问题解决能力，但过长的推理轨迹会增加延迟、内存使用和推理服务成本。
这促使了关于 CoT 压缩的研究，旨在缩短中间轨迹的同时保持推理性能。
先前的方法通过多种方式获取紧凑的轨迹：通过提示或蒸馏进行简洁生成（xu2025cod）、自适应推理预算（han2025token）、替代显式推理的潜在计算（shen2025cod），以及从完整轨迹中剪枝 Token 或步骤（xia2025tokenskip; li2026making）。
我们专注于 Token 剪枝设置，即将完整的 CoT 轨迹剪枝为一部分推理 Token，用于监督模型生成更短的链。此设置明确了核心瓶颈：在保留预算 γ \gamma 下，应该保留哪些推理 Token？

图 1：模型内部 Token 显著性的概念概述。对于每个推理 Token： 必要性测量当该 Token 的残差贡献被移除时，答案似然的下降程度； 充分性测量当该贡献被修补进无链前向传播时，答案似然的增加程度。这两个轴结合用于对 Token 进行排序，并在压缩时保留得分最高的 Token。

现有的 Token 级压缩方法使用仅与目标模型的答案计算间接相关的信号来回答这个问题。例如，TokenSkip 风格（xia2025tokenskip）的方法依赖辅助评分器（pan2024llmlingua），其排序取决于评分器自身的训练目标、监督和领域假设，而不是从目标模型的内部推理过程中推导而来。
虽然有效，但它们留下了一条更直接、更有原则的测量 Token 重要性的路径未探索：从目标模型在生成答案时所依赖的内容中推导重要性。
因此，我们将焦点从启发式代理转移到互补的模型内部视角。
在这种观点下，当目标模型的答案计算依赖于某个推理 Token 在残差流中携带的信息时，该 Token 就是重要的。残差流是信息跨层传播的内部基底。我们将此残差流视为模型的“思维流”，其中每个 Token 都会留下涟漪，其幅度反映了它对答案的贡献。
因此，对压缩而言，携带较少与答案相关信息的 Token 是自然可被移除的候选者。
这将 Token 级 CoT 压缩重新定义为模型内部显著性问题：哪些推理 Token 对模型的答案计算做出了最大的内部贡献？
我们沿着两个互补的轴将此显著性形式化：
(Q1) 必要性：如果移除某个 Token 的内部贡献，真实答案似然会下降多少？
(Q2) 充分性：如果仅提供该 Token 的内部信息，能恢复多少真实答案似然？
必要性反映了全链依赖性：它捕获了其擦除会破坏链自身计算的 Token。
充分性反映了无链可恢复性：它捕获了上下文枢纽，这些枢纽的残差在给定查询时，无需链的其余部分即可恢复与答案相关的信息。
如果没有另一个轴，每个视图都是有偏的：必要性在充足的保留预算下，会允许未直接锚定于答案相关性的低信息上下文；而仅靠充分性在激进压缩下表现不佳，因为没有单个 Token 的残差可以替代整条链。
将两者结合产生了一个在各种压缩预算下保持可靠的排序。

图 2：双轴模型内部 Token 显著性的经验性表征。在 Qwen2.5-1.5B-Instruct 上对 100 条 MATH 推理链的结果。 保留最高必要性的 Token 在所有预算下始终优于位置和随机基线。 保留最高充分性的 Token 比随机和范数匹配的对照组恢复更多的答案信号。 必要性和充分性诱导出弱相关的排序（平均 Spearman ρ = − 0.07 \rho=-0.07 ，前 30 % 30\% 重叠为 0.28 0.28 ），表明它们捕获了不同但互补的信号。

基于这一框架，我们提出了 MIST（用于 Token 级 CoT 压缩的模型内部显著性）。
对于每个推理 Token，MIST 将这两个轴操作化为残差流干预：必要性测量从全链计算中擦除 Token 残差状态的效果，而充分性测量将该状态修补进无链前向传播时恢复的答案信号。
直接评估这些干预需要为每个 Token 进行单独的前向传播，其复杂度随链长 T 缩放为 O ⁡ ( T ) O(T) ，这使得逐 Token 评分成本高昂。
我们证明，这两个轴都允许在残差流中进行一阶泰勒线性化，将每个 Token 的得分简化为梯度和激活的内积，因此每个轴只需一次反向传播即可得出所有 Token 得分。
然后，MIST 将这两个得分结合为一个统一的 Token 重要性得分。
保留得分最高的 Token 形成压缩的 CoT 轨迹，随后用于适配模型以生成更短的推理链。
我们在涵盖数学推理（GSM8K（cobbe2021training）和 MATH（hendrycks2021measuring））和通用领域推理（MMLU-Pro（wang2024mmlupro）和 BIG-Bench Hard（suzgun2023challenging））的四个基准上评估 MIST，使用 Qwen2.5-1.5B-Instruct、Qwen2.5-7B-Instruct（qwen2.5）、Llama-3.1-8B-Instruct（grattafiori2024llama）和 Mistral-7B-Instruct-v0.3（Jiang2023Mistral7）。
大量结果表明，模型内部显著性可作为推理 Token 重要性的可靠代理，并且所提出的方法在各种设置下始终提升 CoT 压缩性能。

总结，我们的贡献如下：
• 我们将 Token 级 CoT 压缩形式化为模型内部显著性问题：我们不再询问哪些 Token 对启发式代理显得重要，而是询问哪些推理 Token 对目标模型自身的答案计算有贡献，并沿着两个互补的轴（必要性和充分性）进行形式化。
• 我们提出了 MIST，它将这两个轴操作化为残差流干预，推导出将每条链的评分简化为每个轴一次反向传播的一阶线性化，并将这两个轴结合为统一的 Token 重要性得分。
• 跨越不同数据集和模型的大量实验结果证明了我们提出方法的有效性。

3 MIST：用于 Token 级 CoT 压缩的模型内部显著性
我们提出了 MIST，一种用于 Token 级 CoT 压缩的模型内部方法。
给定查询 x x ，由目标模型 M M 生成的推理链 c = ( t 1 , … , t T ) c=(t_{1},\ldots,t_{T}) 以及答案 a a ，MIST 为每个链 Token 分配一个显著性得分，在保留预算下保留得分最高的 Token，并使用生成的压缩链来适配模型以生成紧凑的推理轨迹。
核心思想是首先定义 Token 对目标模型自身答案计算“有影响”的含义，然后从模型的内部状态量化这种重要性。

3.1 问题形式化：模型内部的 Token 重要性概念
Token 级 CoT 压缩需要对推理 Token 进行排序。一个自然的目标是保留最能支持模型答案计算的 Token 子集：
c γ ⋆ = arg ⁡ max c ′ ⊆ c , | c ′ | = ⌈ γ ​ T ⌉ ​ log ​ p M ​ ( a ∣ x , c ′ ) , c_{\gamma}^{\star}=\arg\max_{c^{\prime}\subseteq c,\ |c^{\prime}|=\lceil\gamma T\rceil}\log p_{M}(a\mid x,c^{\prime}), (1)
其中 γ ∈ ( 0 , 1 ] \gamma\in(0,1] 是保留预算。直接求解该目标是组合优化问题，因此实际的压缩方法将问题简化为计算每个 Token 的重要性并保留排名最高的子集。
在这项工作中，我们将这种重要性形式化为模型内部显著性：如果目标模型自身的答案计算依赖于该 Token 携带的内部信息，则该 Token 是显著的。
为了使这一概念可操作，我们通过其残差流来测量 Token 的内部贡献，这是一个自然的选择，因为残差流是模型的内部计算基底。
然后，我们通过两个互补的轴来定义这种显著性。
必要性。必要性测量当 Token 的内部贡献从完整推理链中被移除时，模型失去了什么。
设 h i h_i 表示与 Token i i 相关的残差流状态。我们通过将 h i h_i 置零来操作化这种移除，然后将由此产生的答案似然下降量化为必要性显著性：
ϕ i := log ⁡ p M ​ ( a ∣ x , c ) − log ⁡ p M ​ ( a ∣ x , c h i → 0 ) . {\phi}{i}:=\log p{M}(a\mid x,c)-\log p_{M}\bigl(a\mid x,c^{h_{i}\to 0}\bigr). (2)
充分性。充分性询问如果仅提供 Token i i 的内部状态，相对于无链前向传播，能恢复多少答案似然。我们通过将 h i h_i 修补到最终位置的无链前向传播中来操作化这一点，并将由此产生的答案似然增益量化为充分性显著性：
ψ i := log ⁡ p M ​ ( a ∣ x , patch ⁡ ( i ) ) − log ⁡ p M ​ ( a ∣ x , ∅ ) . {\psi}{i}:=\log p{M}\bigl(a\mid x,\mathrm{patch}(i)\bigr)-\log p_{M}(a\mid x,\emptyset). (3)
为什么需要两个轴？信息丰富且互补的 Token 重要性视图。
上述必要性和充分性的定义提供了两种基于行为的 Token 重要性概念。我们进一步在 100 条黄金 MATH 链上进行了实证评估，以表明这两种概念在实践中都能产生有意义的 Token 重要性信息。
在各种压缩预算下，保留由精确必要性排序的 Token 始终优于位置和随机基线，这表明必要性识别了全链答案计算所依赖的 Token（图 2a）。相反，将最充分的 Token 修补到无链计算中可恢复大量与答案相关的信息，而随机 Token 和范数匹配的对照组则不能（图 2b）。尽管它们各自都有效，但这两种排序仅弱相关，并且顶部 Token 重叠有限（图 2c），表明它们捕获了 Token 重要性中大部分不同的方面。
因此，单独一个轴都不能完整地解释 Token 重要性，这促使我们在双轴显著性测量中将它们结合起来。

4.2 主要结果
我们在图 3 和表 1 中报告主要结果。
模型内部显著性优于外部评分器。TokenSkip 总体上是最强的基线，但它依赖于辅助评分器，其重要性信号并非从目标模型自身的答案计算中推导而来。在评估的数据集和模型中，MIST 实现了比 TokenSkip 更好的性能。在 γ \gamma 上的平均值，MIST 在使用 Qwen2.5-7B 和 Mistral-7B 的 GSM8K 上仅产生 1.3-2.4 个百分点 的准确率下降，而 TokenSkip 为 2.1-4.3 pp。在 MATH-500 上的差距更大：MIST 在 Qwen2.5-1.5B 上将平均准确率提高了 5.3 pp，在 Llama-3.1-8B 上提高了 1.2 pp，而 TokenSkip 分别下降了 4.1 pp 和 2.3 pp。这表明目标模型自身的内部计算为识别它实际依赖的推理 Token 提供了可靠的信号。
有原则的内部评分器优于内部启发式。其余基线使用目标模型信号（如梯度、困惑度或注意力权重），但通过启发式评分规则将这些信号映射到 Token 重要性。例如，GoGI 是最接近的内部梯度基线，但它将预选层的梯度范数作为 Token 重要性的启发式代理，而不是从任何明确的显著性定义中推导出来。相比之下，MIST 通过必要性和充分性干预将 Token 重要性操作化，并从它们对答案似然的一阶效应中推导其评分器。在 MIST 中，梯度仅与激活相乘并跨所有层聚合；GoGI 使用的纯梯度范数可视为这种构造沿必要性轴的严格简化。经验差距进一步凸显了 MIST 有原则的显著性构造的优势。在 GSM8K 上，GoGI 在 Qwen2.5-7B 和 Mistral-7B 上分别产生 11.9 和 9.2 pp 的准确率下降，而 MIST 仅为 2.4 和 1.3 pp。在 MATH-500 上，GoGI 在 Qwen2.5-1.5B 和 Llama-3.1-8B 上分别下降 6.6 pp 和 3.8 pp，而 MIST 比完整 CoT 提高了 5.3 和 1.2 pp。其他内部或模型衍生的启发式方法退化更严重，困惑度、注意力展开和 H2O 的下降分别高达 39.5、28.8 和 32.6 pp（表 1）。
MIST 实现了有利的准确率与压缩权衡。MIST 在产生最小推理性能损失的同时实现了有竞争力的压缩。在 Qwen2.5-7B 的 GSM8K 上，MIST 实现了 21.3% 的链长减少，而 TokenSkip 为 20.0%，同时准确率仅下降 2.4 pp，而 TokenSkip 为 4.3 pp。具有内部启发式信号的方法（如困惑度、注意力展开和 H2O）可以实现相似或更高的压缩率，但准确率下降要大得多。这种权衡表明，在相同的保留预算下，MIST 选择的 Token 携带了更大比例的答案相关信号，允许适配器从较短的轨迹中恢复链级准确率。

5 结论
我们提出了 MIST，一种用于 Token 级 CoT 压缩的模型内部方法。
MIST 通过在残差流上实例化的两个互补干预（必要性和充分性）在操作上定义了 Token 重要性，并通过一阶泰勒近似将两者转换为可处理的每 Token 评分器，将逐 Token 干预的成本降低到每条链两次反向传播。
跨不同数据集和模型的大量实证评估证明了我们提出方法的有效性。

局限性
模型规模和梯度访问。我们的实验使用 1.5B 到 8B 的指令微调模型。显著性信号是否在更大模型中保持类似集中尚未确定。此外，MIST 需要访问目标模型的内部激活和梯度，因此不适用于黑盒纯 API 系统。
评估领域。我们的四个基准涵盖数学和通用领域推理。未来的工作可以将该框架扩展到开放式生成、代码生成或多轮对话，以进一步验证所提出方法的有效性。
近似干预得分。MIST 用其在残差流中的一阶泰勒项近似必要性和充分性干预。由于 Transformer 计算是非线性的，Token、层和头之间的高阶交互未被捕获，因此 MIST 得分是模型内部显著性估计器，而不是精确的因果分解。
