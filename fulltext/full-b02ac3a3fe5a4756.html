中文摘要： OpenAI 发布 GPT-6.2 Astra 与 Sol 双模型。Astra 面向最复杂的专业项目，在 Agents' Last Exam、Terminal-Bench-Science 等多项基准上创新高，API 价格较 GPT-6 Astra 降低 20%，缓存输入再享 60% 折扣；Sol 主打日常高效任务，价格保持不变。两款模型在幻灯片、文档、代码、3D 设计及网络安全能力上显著提升，token 效率更高。安全方面达到网络安全"关键"阈值与 AI 自我改进"高"阈值，并配备更严格防护。现

专业工作的新标准

[在 ChatGPT Work 中试用（在新窗口中打开）]

我们推出 GPT‑6.2 Astra——面向你最艰难项目的新前沿模型，以及 GPT‑6.2 Sol——面向日常工作的高效多功能模型。两款模型都能以更少的输出 token 在高难度任务上交付更好的结果，让你在使用限额内完成更多工作。对于企业和开发者而言，这意味着以在大规模场景下合理的成本获得前沿性能。

GPT‑6.2 Astra 为 AI 在复杂专业工作方面树立了新的质量标杆。它生成的幻灯片、电子表格和文档读起来更不像出自 AI 之手，并且更贴近你提供的模板和你所在领域的规范。它编写的代码更简洁，构建的前端外观和功能更佳，尤其是在网站、游戏和 3D 设计方面。

在测试多步骤专业工作的 Agents' Last Exam 上，GPT‑6.2 Astra 创下新高，以不到三分之一的成本比 GPT‑6 Astra 高出 5.2 分，以仅 5% 的成本领先 Claude Fable 5.2 达 5.5 分。

Agents' Last Exam 评估模型在长周期专业工作流上的表现。其排行榜上 Fable 5.2 的结果排除了九项使用了备用模型的任务。

我们相信 GPT-6.2 Astra 是世界上最适合科学家的模型。它在 Terminal-Bench-Science 0.1 上创下新高，该基准测试模型在终端中开展科学工作的能力。GPT-6.2 Astra 以不到三分之一的成本比 GPT-6 Astra 高出 9 个百分点。它还在 Vals Science Index 上创下新高，该指数要求模型解读真实生物数据并运行实验，以推断模拟系统的运作方式。

在 API 方面，GPT‑6.2 Astra 的输入和输出 token 价格比 GPT‑6 Astra 低 20%，缓存输入享 60% 折扣（输入每百万 token 8 美元，缓存输入每百万 token 0.40 美元，输出每百万 token 40 美元）。GPT‑6.2 Sol 沿用 GPT‑6.1 Sol 的 API token 价格。在多项基准测试中，两款模型都以每任务极小比例的成本接近或超越其他领先模型。

GPT-6.2 Sol：我们日常工作的首选模型

与 GPT‑6.1 Sol 相比，GPT‑6.2 Sol 更智能、更高效，让你在相同的付费计划下完成更多任务。它能强力推进多步骤智能体工作流，写作清晰自然，协作直观。许多 OpenAI 员工将其作为技术和非技术任务的默认模型。

在 Cognition 的 FrontierCode 2.0 上，GPT‑6.2 Sol 以约五分之一的成本取得与 GPT‑6.2 Astra 相差不到 0.5 分的成绩（两者均在最大设置下）。

FrontierCode 2.0 评估对真实代码库的更改是否符合维护者的合并标准。

它的速度和智能也使其成为人们在工作之外向 AI 求助的重要任务的理想选择。在我们最近发布的 LifeVal 评估（衡量模型在具有挑战性的日常任务上的表现）中，GPT‑6.2 Sol 以约七分之一的成本超越 GPT-6 Astra。

LifeVal 测试模型处理按个人需求定制的日常任务的能力，例如搬家后筛选幼儿园、寻找符合家庭预算和通勤需求的住房，或为正在适应新诊断的父母规划饮食。

符合行业标准的专业输出

我们训练 GPT‑6.2 Astra 创建更清晰、设计更佳的幻灯片、电子表格和文档，使其更贴近法律、销售、金融和会计等领域专业人士所遵循的规范。写作更直接、更具体，泛泛而谈的结论和冗余内容更少。

Harvey LAB‑AA v1.1 使用法律任务测试模型能否在源文档中找到相关事实，将其应用于详细的案情摘要，并产出满足每项要求的准确交付物。GPT‑6.2 Astra 创下新的最先进水平，以约六分之一的成本将 Claude Fable 5.2 的通过率提高了一倍以上。Astra for Law——我们面向律师的 GPT-6.2 Astra 配置——在该基准测试中得分更高。

Harvey LAB‑AA 测试审查合同条款等法律工作。其 headline 得分只有在交付物满足所有评分标准且不含实质性幻觉时才计分。

我们的内部 GDPval v2 基准是 GDPval 的下一代版本，衡量来自咨询、金融和设计等行业真实项目的复杂长周期工作流。GPT‑6.2 Astra 在我们测试的模型中领先，比 GPT‑6 Astra 提高 6.2 个百分点，同时输出 token 减少 22%。GPT‑6.2 Sol 比 GPT‑6.1 Sol 提高 5.3 分。

GDPval v2 由来自金融、数据科学、生物技术和营销等行业真实项目的长周期知识工作任务组成。

工作簿与备忘录

构建估值工作簿或撰写投资备忘录，首先要从源文件中找到相关数字并理清它们之间的关联。Artificial Analysis 的 AA‑AnalystAgent 在真实的电子表格和报告上测试这项工作。在其中一项任务中，模型使用加州 Medicaid（医疗补助）的支出报告计算该计划在医疗交通上的花费。GPT‑6.2 Astra 创下新高，在全部五次独立尝试中均正确回答了 62.5% 的问题。

幻灯片

GPT‑6.2 Astra 是我们迄今最擅长设计幻灯片和遵循幻灯片模板的模型，无论是给定原始文件还是一张截图。它可以精确匹配布局、配色和排版，直至确切的字号，并将模板的写作风格延续到新幻灯片中。早期测试者发现这些幻灯片更易于直接使用、所需编辑更少，这得益于点明主要结论的标题和聚焦读者所需细节的简洁正文。

计算机使用与交互式网页设计

GPT‑6.2 Astra 更精确的计算机使用能力，使其能够在 CAD 和仿真工具中深入操作单个零件及其连接。工程师可以利用这些额外的细节检查组件如何配合、观察设计移动时载荷如何转移，并在制作原型之前测试修改方案。

驾驶仿真

我们让 GPT‑6.2 Astra 可视化一辆汽车在山路上行驶时的底盘动力学。Astra 创建了 3D 模型，编写了 Python 求解器来模拟轮胎与悬架之间的复杂动力学，然后在 Blender 中将结果制作成动画。这使工程师能够快速测试新设计，并随时间推移不断提高仿真精度。

机械设计与装配

GPT‑6.2 Astra 可以逐个零件地对机械系统建模，让工程师能够展示系统如何组装，并测试设计变更如何影响其行为。

从 CAD 到纸质灯具

我们的团队使用 GPT‑6.2 Astra 将芝加哥 Marina City 大楼的扇贝形阳台转化为一盏灯。视频记录了设计从参考照片、CAD 修改到手工组装实体灯具的全过程。由 GPT-6.2 Astra 生成的网站可用于制作你自己的纸质灯具。

GPT‑6.2 Astra 为网页设计带来更强的视觉推理能力，选择能让每个网站独具特色的布局和图像，并围绕网站的实际目标构建页面元素。

视觉推理和计算机使用方面的这些进步也延伸到了 3D 设计。GPT‑6.2 Astra 和 Sol 可以将书面简报转化为交互式浏览器体验，从可以游玩的弹球台到可从不同角度探索的罗马斗兽场复刻。在 Artificial Analysis 的 AA‑3D 上，人类评委体验两个基于同一提示构建的盲测作品，并投票选出自己更偏好的一款。GPT‑6.2 Astra 以 1,318 的 Elo 评分排名第一，其次是 Claude Fable 5.2（1,271）和 GPT‑6.2 Sol（1,259）。

高效工作流与更简洁的代码风格

GPT‑6.2 Astra 在如何执行任务方面具备更好的判断力，包括让工具和投入程度与工作流相匹配，以及知道何时使用插件、何时使用计算机操作。

在编码方面，GPT-6.2 Astra 更擅长在现有代码库中实现和测试复杂变更。早期测试者反馈代码风格更简洁、测试更聚焦，修改轮次更少。

网络安全能力

GPT‑6.2 Astra 和 GPT‑6.2 Sol 标志着网络能力的又一次显著跃升。它们能更有效地发现和利用漏洞，编写更安全的代码，并生成更好的补丁，在多项评估中 token 效率大幅提升。与 GPT‑6 Astra 一样，6.2 Astra 和 Sol 在我们的《准备框架》下达到网络安全"关键"阈值。

由于其能力提升，我们为 GPT‑6.2 Astra 和 Sol 配备了更严格的安全防护，以应对高风险网络安全协助。这些保护措施降低了滥用风险，但也限制了部分合法的漏洞研究和安全测试工作流。通过 OpenAI Daybreak，防御者目前可在 Daybreak Blue 上访问网络相关拒绝更少的 GPT-6 Sol，此外还有 GPT-6 Astra 的 alpha 版本，以及在 Daybreak Red 上用于高级授权安全测试的 GPT‑6 Cyber。我们将努力把 GPT‑6.2 模型引入 Daybreak。

我们在下方重点展示关键基准测试结果，采用的是禁用网络安全防护和分类器的内部测试配置。完整结果和方法论请参阅随附的系统卡（在新窗口中打开）。

为网络防御者提供优势

开发者日益依赖编码智能体编写生产软件，与此同时，更强大的智能体也降低了发现和利用漏洞的门槛。PHP2Shell 展示了 AI 如何帮助研究人员发现关键缺陷。在 GPT‑6.2 Astra 和 Sol 中，我们将防御能力作为核心重点，引入了新的训练信号，帮助开发者预防和修复这些缺陷——从一开始就编写安全的代码，并生成保留预期行为的补丁。

安全与对齐

我们正在为 GPT-6.2 Astra 和 Sol 部署迄今最强大的安全防护。我们收紧了限制，并强化了用于监控模型和在需要时进行干预的系统。

与 GPT-6 Astra 一样，除达到网络安全"关键"阈值外，GPT‑6.2 Astra 和 Sol 均在我们的《准备框架》下达到生物和化学能力的"高"阈值。我们已实施保护措施以缓解相关风险，并对一组潜在的生物和网络安全双重用途请求加强了限制。

有关我们的安全防护和测试的更多详情，请参阅 GPT-6.2 系统卡（在新窗口中打开）。

AI 研究能力与防护

GPT-6.2 Astra 是我们首个在外部发布并达到 AI 自我改进"高"阈值的模型，该指标衡量模型加速 AI 研究的能力。"高"评级反映了我们的评估：相对于 2024 年基线，该模型的影响相当于为每位 OpenAI 研究员配备一名额外的、能力出众的研究工程师作为助手。我们追踪这一能力，因为能够协助开发未来 AI 系统的模型也可能带来新的安全风险，例如使进展速度超过安全防护或人类监督的适应速度。

为应对这些风险，我们在模型训练和部署方式中内置了更多监督与控制。在扩大 GPT-6.2 Astra 的内部访问之前，我们评估了其对齐情况，并验证了每个阶段所需的防护措施均已到位。我们加强了研究环境中的遏制措施，并用我们最强大的模型测试了这些保护措施。我们还构建了 Control Room——一个追踪研究工作负载的系统，可在需要干预时停止模型的进一步输出。我们扩展的监控会审查模型在内部工作负载和受支持的外部部署中的推理与行动，可自动标记未经授权的行为，并在受支持的场景下暂停工作负载或对话。

对齐

两款模型在大多数对齐评估中的表现与 GPT‑6 Astra 相似，并且在模拟工作场所任务中采取不当行为的次数更少。然而，在两项测试中，它们更倾向于不提及阻碍其工作的障碍，例如缺失的文件或不可用的搜索工具。我们在 Codex 中添加了指令，大幅减少了此类遗漏，我们也在继续调查这一行为。

定价与可用性

从今天起，GPT-6.2 Astra 和 Sol 面向所有 Plus、Pro、Enterprise 和 Edu 用户开放，可在 ChatGPT Work 和 Codex 中使用。Pro 500 订阅者可在任一模型上使用 Ultrafast。我们还首次将 Ultrafast 带给 Pro 200 订阅者，首先从 GPT-6.2 Sol 开始。符合条件的 Enterprise 和 Edu 用户将在其工作区管理员启用后获得相同权限。开发者还可以通过 OpenAI API 访问 gpt-6.2-astra 和 gpt-6.2-sol，两款模型在发布时均支持 Ultrafast。

得益于更佳的 token 效率、输入和输出 token 20% 的降价以及缓存输入 token 更大幅度的 60% 折扣，GPT‑6.2 Astra 的每任务成本显著低于 GPT‑6 Astra。标准 API 费率为每百万 token 输入 8 美元、缓存输入 0.40 美元、输出 40 美元。GPT‑6.2 Sol 沿用 GPT‑6.1 Sol 的费率，即每百万 token 输入 2 美元、缓存输入 0.10 美元、输出 10 美元。

对于 GPT-6.2 Astra 和 Sol，为了提高缓存复用率、帮助降低成本和延迟，并在多轮对话间保留推理，我们建议保持提示前缀不变，并将新指令追加到对话中（在新窗口中打开）。
