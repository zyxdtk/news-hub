Claude Sonnet 5 发布

📅 2026-06-30 📄 Anthropic 🔗 原文链接

原标题：Introducing Claude Sonnet 5

中文摘要： 本文介绍了 Anthropic 推出的 Claude Sonnet 5 模型。该模型是目前最具代理能力的 Sonnet 模型，在推理、工具使用、编码和知识工作等方面有显著提升，性能接近 Opus 4.8，但价格更低。安全评估显示，其不良行为率低于前代，并默认启用网络安全防护措施。该模型已在所有套餐中可用，并推出至 2026 年 8 月的初始优惠定价。

<![CDATA[Claude Sonnet 5 旨在成为迄今为止最具代理能力的 Sonnet 模型。它可以制定计划，使用浏览器和终端等工具，并以几个月前还需要更大、更昂贵模型才能达到的水平自主运行。

对于许多开发者来说，代理式 AI 时代始于 Sonnet 级别的模型：Claude Sonnet 3.5、3.6 和 3.7 是首批在编码和工具使用方面展现出令人印象深刻技能的模型。然而最近，代理能力最明显的提升体现在我们的 Opus 级别模型中。

Sonnet 5 缩小了差距：其性能接近 Opus 4.8，但价格更低。与其前身 Sonnet 4.6 相比，它在推理、工具使用、编码和知识工作等代理性能的重要方面有了实质性改进：

![Image 1: Claude Sonnet 5 benchmark table](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F9941d610909f28a504e16dd5af823df172ec6035-2600x1234.png&w=3840&q=75) _Sonnet 5 在各种评估中的得分与 Sonnet 4.6 和 Opus 4.8（一个更通用的模型，供参考）的得分比较。[Claude Sonnet 5 系统卡](https://www.anthropic.com/claude-sonnet-5-system-card) 详细报告了更广泛的评估集。_

我们的安全评估发现，Sonnet 5 表现出总体上低于 Sonnet 4.6 的不良行为率，在代理环境中使用通常更安全。评估还表明，它执行网络安全任务的能力远低于我们目前的 Opus 模型。

从今天起，Claude Sonnet 5 在所有套餐中可用：它是 Free 和 Pro 套餐的默认模型，并可供 Max、Team 和 Enterprise 用户使用。它还可以在 Claude Code 和 Claude 平台上使用，在 2026 年 8 月 31 日之前，其初始定价为每百万输入 token 2 美元，每百万输出 token 10 美元，之后定价将为每百万输入 token 3 美元，每百万输出 token 15 美元。开发者可以通过 [Claude API](https://platform.claude.com/docs/en/about-claude/models/overview) 使用 `claude-sonnet-5`。

## 安全评估

我们部署前的安全评估发现，Sonnet 5 总体上比 Sonnet 4.6 有所改进。在代理安全方面，该模型在拒绝恶意请求和抵抗提示注入攻击中的劫持企图方面表现更好。该模型表现出比 Sonnet 4.6 更低的幻觉和谄媚率。在我们的自动化行为审计中（该审计测试了广泛的行为失调，如与滥用和欺骗的合作），Sonnet 5 总体得分较低（即更安全）。然而，在此次评估中，与更强大的 Opus 4.8 和 Claude Mythos Preview 相比，它确实表现出略高的行为失调率。

![Image 12: Rates of misaligned behavior across Claude models](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2Fd018d76aa03c0ef18abc8a68de8f6fcd51c0a574-3840x2160.png&w=3840&q=75) _我们自动化行为审计中的行为失调率，该审计测试了在许多情况和背景下非常广泛的不良行为（完整列表和每种特定行为的结果请参见 [Sonnet 5 系统卡](https://www.anthropic.com/claude-sonnet-5-system-card) 的第 6.4 节）。Sonnet 5 的行为失调率总体上低于 Sonnet 4.6，但高于 Mythos Preview 和 Opus 4.8。_

我们没有刻意在网络安全任务上训练 Sonnet 5。它可以执行一些常规的、无害的网络任务，但在测试潜在危险网络技能（如开发软件漏洞利用）的评估中，它的表现明显差于 Opus 4.8 和 Mythos 5 等模型。下图表显示了一项评估的得分，该评估测试了模型为 Firefox 浏览器中的漏洞开发漏洞利用的能力。Sonnet 5 从未能够开发出完整可用的漏洞利用，但它确实表现出比 Sonnet 4.6 略高的_部分_成功率。后者的变化可能是由于通用智能的改进，而不是特定的训练。

![Image 13: Scores measuring Claude models’ success at developing exploits for software vulnerabilities in Firefox 147](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2Fee9944c865937053bae293f057fffa478ee0f46b-3840x2160.png&w=3840&q=75) _衡量模型在为 Firefox 147 中的软件漏洞开发漏洞利用方面成功与否的得分（此评估是与 [Mozilla 合作](https://www.anthropic.com/news/mozilla-firefox-security) 开发的；所有漏洞已在 Firefox 148 中修补）。对于每个模型，左侧的条形图显示模型（在没有保障措施的情况下）开发出可用漏洞利用的频率；右侧的条形图显示模型部分成功的频率。两个 Sonnet 模型都无法成功开发出可用的漏洞利用（得分均为 0.0%）；Sonnet 5 的部分成功率略高于 Sonnet 4.6。两个 Sonnet 模型的网络能力都明显逊于 Opus 4.8 和 Mythos 5。完整详情请参见 [Sonnet 5 系统卡](https://www.anthropic.com/claude-sonnet-5-system-card) 的第 3.2.4 节。_

由于 Sonnet 5 在这些任务上比其前身稍强，我们在发布它时默认启用了网络保障措施。这些[保障措施](https://support.claude.com/en/articles/14604842-real-time-cyber-safeguards-on-claude)——实时检测和阻止危险的网络使用——与 Claude Opus 4.7 和 4.8 中的相同（因为我们认为 Sonnet 5 带来的整体网络安全风险水平较低，所以这些保障措施不如随 Fable 5 发布的措施严格，后者阻止了更广泛的网络安全任务）。1

我们在 [Claude Sonnet 5 系统卡](https://www.anthropic.com/claude-sonnet-5-system-card) 中报告了对 Sonnet 5 在许多安全性和能力评估方面的完整评估。

## 可用性和定价

Claude Sonnet 5 今天在所有地方均以初始价格提供，在 2026 年 8 月 31 日之前，每百万输入 token 2 美元，每百万输出 token 10 美元。然后它将转为标准定价，即每百万输入 token 3 美元，每百万输出 token 15 美元。2 我们提高了 Chat、Cowork、Claude Code 和 Claude Platform 3 的速率限制，以适应更高努力级别下更高的 token 使用量；用户可以选择对其特定项目有意义的任何级别。
