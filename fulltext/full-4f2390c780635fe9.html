Claude 提高使用限制及与 SpaceX...

📅 2026-05-06 📄 Anthropic 🔗 原文链接

原标题：Higher usage limits for Claude and a compute deal with SpaceX

中文摘要： Anthropic宣布与SpaceX达成算力合作，将使用其Colossus 1数据中心超30万千瓦（超22万块NVIDIA GPU）的算力，直接提升Claude Pro和Max订阅容量。受此及近期其他算力协议推动，Anthropic即日起将Claude Code的五小时速率限制翻倍，取消高峰时段限制缩减，并大幅提高Claude Opus模型的API速率限制。此外，公司正拓展国际算力布局以满足合规需求，并有意与SpaceX合作开发轨道AI算力。

我们已与 SpaceX 达成合作伙伴关系，这将大幅提升我们的算力。加上我们最近达成的其他算力协议，这意味着我们能够提高 Claude Code 和 Claude API 的使用限制。

以下我们将介绍这些变化以及我们在算力方面取得的进展。

以下三项变更——均于今日生效——旨在改善我们最忠实用户使用 Claude 的体验。

首先，我们将 Pro、Max、Team 和基于席位的 Enterprise 计划的 **Claude Code 五小时速率限制提高了一倍**。

其次，我们**取消了 Pro 和 Max 账户在高峰时段对 Claude Code 的限制缩减**。

第三，我们**大幅提高了 Claude Opus 模型的 [API 速率限制](https://platform.claude.com/docs/en/api/rate-limits)**，如下表所示：

![Image 1](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2Fd8f4f661bde0f11088d087dcda98916becad077f-1920x801.png&w=3840&q=75) _我们更新后的 Claude Opus 模型 API 速率限制。_

## 与 SpaceX 达成新的算力合作

我们已与 SpaceX 签署协议，将使用其 Colossus 1 数据中心的全部算力。这使我们能在本月内获得超过 300 兆瓦的新算力（超过 220,000 个 NVIDIA GPU）。这些额外的算力将直接提升 Claude Pro 和 Claude Max 订阅用户的容量。

这与我们其他重要的算力公告相呼应：

* [与亚马逊高达 5 吉瓦 (GW) 的协议](https://urldefense.us/v3/__https:/www.anthropic.com/news/anthropic-amazon-compute__;!!Fqb0NABsjhF0Kh8I!f3EziG8q3wGsRgicn_ZGbvtLp5ZdopVN_KTE1QXfiqHcZ0l9w_sq_kpBwgsm-IHRGC18VQ89pRZ3BOVEnw$)，包括到 2026 年底近 1 GW 的新算力； * [与 Google 和 Broadcom 的 5 GW 协议](https://urldefense.us/v3/__https:/www.anthropic.com/news/google-broadcom-partnership-compute__;!!Fqb0NABsjhF0Kh8I!f3EziG8q3wGsRgicn_ZGbvtLp5ZdopVN_KTE1QXfiqHcZ0l9w_sq_kpBwgsm-IHRGC18VQ89pRZtorfLOg$)，将于 2027 年开始上线； * [与 Microsoft 和 NVIDIA 的战略合作伙伴关系](https://urldefense.us/v3/__https:/www.anthropic.com/news/microsoft-nvidia-anthropic-announce-strategic-partnerships__;!!Fqb0NABsjhF0Kh8I!f3EziG8q3wGsRgicn_ZGbvtLp5ZdopVN_KTE1QXfiqHcZ0l9w_sq_kpBwgsm-IHRGC18VQ89pRaViUpCKQ$)，包括价值 300 亿美元的 Azure 容量； * 我们与 Fluidstack [对美国 AI 基础设施的 500 亿美元投资](https://urldefense.us/v3/__https:/www.anthropic.com/news/anthropic-invests-50-billion-in-american-ai-infrastructure__;!!Fqb0NABsjhF0Kh8I!f3EziG8q3wGsRgicn_ZGbvtLp5ZdopVN_KTE1QXfiqHcZ0l9w_sq_kpBwgsm-IHRGC18VQ89pRYa_xNtww$)。

我们在多种 AI 硬件（AWS Trainium、Google TPU 和 NVIDIA GPU）上训练和运行 Claude，并继续探索将额外算力上线的机会。

作为该协议的一部分，我们还表达了与 SpaceX 合作开发数吉瓦轨道 AI 算力的意向。

## 国际扩张

我们的企业客户——尤其是金融服务、医疗保健和政府等受监管行业的客户——越来越需要区域内基础设施来满足合规和数据驻留要求。因此，我们的部分算力扩张将面向国际：我们最近宣布的[与亚马逊的合作](https://www.anthropic.com/news/anthropic-amazon-compute)包括在亚洲和欧洲增加推理能力。

我们对增加算力的地点非常谨慎——我们与那些法律和监管框架支持此类规模投资的民主国家合作，并确保我们所依赖的算力供应链（硬件、网络和设施）是安全的。

最后，我们最近做出了一项[承诺](https://www.anthropic.com/news/covering-electricity-price-increases)，承担我们在美国的数据中心引起的任何居民电价上涨费用。作为国际扩张的一部分，我们正在探索将这一承诺扩展到新司法管辖区的方法，同时与当地领导人合作，对托管我们设施的社区进行再投资。
