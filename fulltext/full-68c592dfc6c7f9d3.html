自适应量化保持速率受限信道上TD学习的快速收敛

Sreejeet Maity 和 Aritra Mitra

摘要——受通信约束下强化学习问题的启发，我们研究了速率受限信道上采用线性函数逼近的策略评估问题。在我们的设定中，一个与未知环境（建模为马尔可夫决策过程）交互的智能体通过有限容量信道向服务器传输时序差分（TD）学习更新方向的量化估计。我们的目标是研究在多大程度上可以保持信道具有无限容量时可实现的统计收敛速率。为此，我们提出了一种名为批量自适应量化TD（BAQ-TD）的新算法，该算法使用批处理来降低传输信息的方差，并使用自适应量化来编码增量。我们为BAQ-TD证明了高概率有限时间误差界，并表明在某个有限信道容量之上，BAQ-TD在对数因子意义下保持了未量化TD的收敛速率。具体而言，对于d维值函数参数，我们证明了在长度为T的时间范围内总共传输O(dlog(T))比特即可达到阶数最优的˜O(1/T)速率，这标志着相对于先前工作在通信复杂度上的指数级改进。

I. 引言

网络控制的经典范式旨在刻画通信网络的存在如何影响闭环性能[1]–[3]。具体而言，当从多个传感器收集的数据通过速率受限、有噪声、有丢失且引入延迟的非理想信道传输时，目标是理解状态估计、稳定化和最优控制设计等任务如何受到影响。尽管此类问题的研究目前已相当成熟，但网络控制中普遍存在的核心假设是系统模型是完全已知的。由于意识到这种假设对现代复杂动态系统并不现实，过去十年间，研究兴趣逐渐转向数据驱动控制/强化学习（RL）算法。通常，RL算法的性能通过样本复杂度来评估，即学习近似最优策略所需的样本数（或与未知环境的交互次数）。当感知模块和决策模块不在同一位置时，通信再次成为这一背景下的核心考量。令人惊讶的是，即使对于最简单的RL问题，通信约束对样本复杂度的影响也尚未得到充分理解。受这一空白的启发，本文旨在阐明控制、通信与模型不确定性之间的相互作用。

研究设定。 我们研究的自然出发点是（可以说是）最简单的RL问题——策略评估，即估计对应于给定策略的值函数以用于后续的策略改进。我们在具有有限状态和动作的离散马尔可夫决策过程（MDP）中考虑此类问题。为了适应大规模状态空间，我们遵循线性函数逼近（LFA）的标准思想，其中值函数估计由线性函数类参数化。经典的时序差分（TD）学习算法[4]使用由（待评估）策略生成的数据迭代更新值函数参数。尽管文献中已有TD学习的渐近[4]和有限样本[5]–[8]收敛结果，但我们在此的具体关注点是刻画通信约束如何影响此类收敛。为此，我们从网络控制文献[1]中汲取灵感，考虑这样一种设定：一个工作智能体直接与MDP交互，收集原始数据样本，并通过无噪声、速率受限的上行链路信道向远程服务器通信编码信息，该信道每次传输仅能支持有限比特的消息；见图1。智能体使用观测数据维护TD方向的有噪估计，并传输此类估计的量化版本。服务器使用量化TD方向的解码版本来更新值函数参数，该参数通过无限容量的完美下行链路信道传回给智能体。在我们的设定中，基本上可以将智能体视为负责数据收集和估计的"传感器"，将服务器视为负责参数更新的"决策者"。基于这一前提，我们提出问题：在T个时间步的时间范围内（等价于样本预算T），需要从智能体向服务器传输多少比特的信息才能（如果可能的话）匹配未量化TD学习（即无通信约束的TD学习）的统计精度？ 我们所知对这一问题提供部分答案的仅有两篇论文[9]和[10]，它们分别探索了通用误差反馈和随机量化机制的使用。在这些论文中，总通信成本与样本预算T成线性关系，这对于通信受限的环境来说可能过于庞大。本文的主要贡献是提供一种新的TD(0)算法变体，其相应的通信复杂度仅随T对数增长，相对于先前工作[9]、[10]标志着指数级的改进。在下文中，我们将详细阐述这一贡献。

  • 算法贡献。 我们的设定中存在两个误差源，使编码器-解码器设计过程复杂化。首先，数据（奖励和状态转移）中的随机性导致经验估计的TD方向出现波动。此类随机波动需要在编码半径的设计中被准确考虑：如果半径太小，则可能无法捕捉均值估计周围的最坏情况偏差；如果半径太大，则由此产生的样本复杂度界可能过于宽松。其次，速率受限的信道会使估计的TD方向失真，增加了第二层不确定性。挑战在于确保上述两种误差不会在迭代过程中累积。针对这一挑战，我们开发了BAQ-TD，这是一种新颖的TD(0)算法变体，依赖于两个关键思想：基于模型的方差缩减来降低每个估计TD方向的方差，以及自适应量化来编码TD方向中的增量。具体而言，我们的算法按周期运行，在每个周期中，智能体使用该周期内收集的数据生成理想稳态TD(0)方向的"高精度"方差缩减估计。这里的简单直觉是，降低方差会带来更低的不确定性，进而转化为编码该不确定性所需的更少比特数。为了进一步节省比特，我们仅编码"增量"，即捕捉智能体处的新信息（基于新鲜数据）相对于服务器从先前传输中已知的部分。设计一个（以高概率）包含此类随机增量过程的自适应编码半径是主要的非平凡任务；我们在第三节展示如何做到这一点。

  • 理论贡献。 给定T个样本，我们在定理1中为BAQ-TD提供了阶为˜O(1/T)的高概率收敛速率。该速率与已知的未量化TD(0)[5]–[8]的结果一致，并且在样本量T上是阶数最优的。因此，我们表明尽管信道容量有限，统计速率仍可保持。有趣的是，实现这一结果所需的信道容量不依赖于T，而是按dlog(d/ω)的规模增长，其中d是值函数参数的维度，ω是我们在第四节中指定的问题相关常数。此外，我们表明˜O(log(T))次传输足以保持阶数最优速率，从而总通信成本为˜O(dlog(T))阶。

相关工作。 最近，越来越多的工作开始关注不确定性下决策问题的通信约束效应，以随机老虎机[11]–[13]和表格型MDP[14]作为自然起点。超越简单的表格情形，函数逼近与比特约束之间的相互作用已在[9]、[10]中被探索。此外，对于连续状态-动作空间，一些最近的论文对线性二次调节器（LQR）的策略梯度算法进行了类似研究[15]、[16]。事实上，我们建立在[16]中自适应量化思想的基础上。然而，所有论文[9]、[10]、[15]、[16]的通信成本都与样本量/时间范围成线性关系。相比之下，我们表明尽管存在函数逼近、随机数据和信道引起的失真所带来的误差，样本量对数级的通信成本足以保持"理想"收敛速率。

II. 背景与问题表述

我们考虑折扣马尔可夫决策过程M = (S, A, P, R, γ)，其中S和A是（有限）状态空间和动作空间，P是转移核的集合，R指定奖励函数，γ∈[0,1)是折扣因子。我们考虑确定性策略，其中每个确定性策略µ:S → A将状态映射到动作。固定策略µ诱导出具有转移矩阵Pµ和奖励函数Rµ : S → ℝ的马尔可夫奖励过程。对于每个s∈S，令r(s)表示分布为Dµ(·|s)、均值为Rµ(s) = E[r(s)]的有噪随机单步奖励。我们假设¹|Rµ(s)| ≤ r̄，且中心化奖励r(s) − Rµ(s)是方差代理为σ²的次高斯分布，即对每个s∈S和λ∈ℝ，E[exp(λ(r(s) − Rµ(s)))] ≤ exp(λ²σ²/2)。在MDP M中从初始状态s开始执行策略µ所获得的长期回报由值函数Vµ(s)给出，其正式定义为

Vµ(s) = E[Σ_{t=0}^∞ γ^t Rµ(s_t) | s₀ = s, µ], (1)

其中s_t表示（由µ诱导的）马尔可夫链在时刻t的状态，且s₀ = s。为开启通信受限RL的研究，本文考虑最简单的RL问题之一，即策略评估——在Rµ = [Rµ(s)]_{s∈S} ∈ ℝ^{|S|}和Pµ未知时，评估对应于给定策略µ的Vµ的任务。我们做如下标准假设[4]–[6]、[8]。

假设1。 由策略µ诱导的马尔可夫链s_t是非周期且不可约的。

假设1确保由µ诱导的马尔可夫链具有唯一的满支撑平稳分布ν。为了分离通信约束带来的挑战，我们采用常用的独立同分布平稳采样模型[5]、[19]–[21]：在每个时间步t，智能体接收一个独立转移样本，其中s_t ∼ ν，s′_t ∼ Pµ(s_t,·)，且r_t ∼ Dµ(·|s_t)。本文的结果可以通过子采样和分块论证[17]、[22]扩展到单轨迹马尔可夫设定。

线性函数逼近（LFA）。 为适应大规模状态空间的可扩展性，通常考虑Vµ的参数化逼近V̂θ。此类逼近的最简单形式是V̂_θ属于由d ≪ |S| := p个基向量组成的集合{ϕ_k}{k∈[d]}张成的线性子空间，其中ϕ_k = [ϕ_k(1), . . . , ϕ_k(p)]^⊤ ∈ ℝ^p。令Φ ∈ ℝ^{p×d}为以ϕ_k作为第k列的矩阵，其第s行ϕ(s) ∈ ℝ^d表示状态s的特征向量。于是我们有V̂θ = Φθ，且V̂_θ(s) = Σ{k=1}^d θ_kϕ_k(s) = ϕ(s)^⊤θ，其中θ = [θ₁, . . . , θ_d]^⊤ ∈ ℝ^d是参数化逼近向量。为便于分析，我们做标准假设[5]、[6]、[8]：Φ的列线性无关，且特征向量是归一化的，即对每个s∈S，∥ϕ(s)∥ ≤ 1。²给定上述设定，目标是估计"最佳拟合"参数θ*，该参数在适当范数下最小化V̂_θ与Vµ之间的距离。

带LFA的TD(0)算法。 为实现这一目标，我们现在介绍经典的TD(0)算法[23]，该算法处理由策略µ生成的观测元组{O_t = (s_t, r_t, s′_t)}，以维护最佳拟合参数θ*的估计序列{θ_t}。为说明其原理，对任意θ∈ℝ^d，定义TD(0)方向：g_t(θ) = [r_t + γϕ(s′_t)^⊤θ − ϕ(s_t)^⊤θ]ϕ(s_t)。标准TD(0)更新由下式给出：

θ_{t+1} = θ_t + α_t g_t(θ_t), (2)

其中{α_t} ∈ (0,1)是适当的步长序列。在我们从平稳分布ν进行独立同分布采样的假设下，稳态"均值路径"TD(0)方向可定义为：ḡ(θ) := E[g_t(θ)] = b − Aθ，其中A := E[ϕ(s_t)(ϕ(s_t) − γϕ(s′_t))^⊤]，b := E[r_tϕ(s_t)]。在假设1以及我们对特征矩阵Φ所做的假设下，可以证明A是可逆的。因此，定义θ⋆ = A⁻¹b。在开创性论文[4]中，作者表明在温和条件下，由(2)生成的迭代序列{θ_t}几乎必然渐近收敛到θ，后者是某个投影Bellman方程的唯一不动点。更近期的工作建立了非渐近有限时间收敛速率，证明在(2)的T次迭代后，平方误差∥θ_T − θ∥²的期望为˜O(1/T)阶[5]、[6]、[8]。我们研究在接下来描述的通信约束下是否可以保持类似的速率。

速率受限的TD(0)策略评估。 我们在图1所示的智能体-服务器架构中研究TD(0)不动点θ⋆的估计。在此设定中，直接与MDP M交互的智能体观测形如{O_t = (s_t, r_t, s′_t)}的数据元组，并通过每次信道使用支持B比特无噪声无差错传输的有限容量信道向服务器传输编码信息。遵循分布式/联邦RL中的标准通信协议，我们施加额外的信息约束：智能体只能传输TD(0)更新方向的编码估计，而不能传输原始数据元组。从服务器到智能体的信道被假设为具有无限容量的无损信道。给定这一通信模型，我们的目标是设计 智能体处的编码方案，以及 服务器处继续保证收敛到θ*（如果可能）的参数更新规则。此外，我们寻求量化信道容量与有限时间收敛速率之间的相互作用。

问题1。 给定T个独立同分布平稳转移样本{(s_t, r_t, s′t)}{t=0}^{T−1}和失败概率δ∈(0,1)，使用固定长度B比特的智能体到服务器消息构造θ⋆的估计θ̂，并建立形如：∥θ̂ − θ*∥² ≤ e(δ,T)的界，该界以至少1−δ的概率成立。研究在容量B适当大时，是否可能保持e(δ,T) = ˜O(log(1/δ)/T)的阶数最优速率。

挑战。 即使对于带LFA的标准TD(0)算法，由于有噪TD更新方向相关的随机性，获得高概率集中界也非易事。在我们的设定中，从智能体到服务器的信道通过使智能体生成的估计失真而注入额外的不确定性。因此，我们需要应对两种不同形式的不确定性：一种来自采样，另一种来自有限比特量化。尽管如此，我们在第三节中开发了一种算法，在长度为T的时间范围内仅使用总共˜O(dlog(T))比特即可保持˜O(1/T)的阶数最优速率。

III. 所提出的算法

中点编码。 在介绍算法1中概述的主要方法之前，我们指定一个关键的有限比特编码子程序。假设我们希望用每坐标m比特编码d维向量u，使得每条消息包含B = dm比特。编码器以向量u∈ℝ^d、决定编码器输入范围的半径ρ > 0和整数精度m ≥ 1作为输入。编码器和解码器共享ρ、d和m。为了对每个u（包括∥u∥ > ρ的情形）定义编码操作，我们首先将u裁剪到半径ρ：若∥u∥ ≤ ρ，sat_ρ(u) := u；否则sat_ρ(u) := ρu/∥u∥。令v = sat_ρ(u)，显然∥v∥ ≤ ρ，因此v_i ∈ [−ρ, ρ]，∀i∈[d]，其中v_i是v的第i个坐标。这启发了一种简单的中点编码方案，其中我们将区间[−ρ, ρ]划分为2^m个等宽的区间。对于每个坐标v_i ∈ [−ρ, ρ]，令ṽ_i为包含v_i的区间的中心。于是，向量u∈ℝ^d的量化版本可以简洁地表示为Q_{m,ρ}(v) := [ṽ₁ ṽ₂ ··· ṽ_d]^T，其中v = sat_ρ(u)。应当清楚的是，这种中点编码方案每坐标恰好需要m比特。以下简单结果提供了量化误差的有用界。

引理1（量化误差）。 假设v∈ℝ^d满足∥v∥ ≤ ρ。则

∥Q_{m,ρ}(v) − v∥ ≤ ηρ, η = √d/2^m. (3)

证明。 该证明是标准的，我们在此仅为完整性而提供。由于∥v∥ ≤ ρ，每个v_i位于[−ρ, ρ]中。由中点编码器的描述，回顾Q_{m,ρ}(v)的第i个分量即ṽ_i是v_i的量化版本，且由构造知|v_i − ṽ_i| ≤ ρ/2^m。因此，∥Q_{m,ρ}(v) − v∥² = Σ_{i=1}^d |ṽ_i − v_i|² ≤ dρ²/2^{2m}，由此平凡地得到所声称的界。

特别地，若∥u∥ ≤ ρ，则sat_ρ(u) = u，且(3)给出∥Q_{m,ρ}(sat_ρ(u)) − u∥ ≤ ηρ。在下文中，我们解释所提出的BAQ-TD算法如何利用上述中点编码子程序。

批量自适应量化TD： 我们现在介绍我们的算法BAQ-TD，它采用自适应量化原理来编码TD(0)更新方向中的"增量"。对于我们的设定，这带来了挑战，因为此类增量继承了更新方向中由采样引起的噪声的随机性。直观上，通过降低增量过程的不确定性，可以减少以给定精度编码增量所需的比特数。为此，我们的主要思想是通过将在线收集的T个样本分批为适当长度的周期，在智能体处维护TD(0)更新方向的方差缩减估计。在下文中，我们提供两个核心算法思想的细节：批量估计和自适应量化。

  • 批量TD方向估计。 我们将时间范围/样本预算T划分为K个周期，每个周期H个样本，T = KH。对于周期k = 0, . . . , K−1，定义其样本索引为I_k := {kH, . . . , (k+1)H−1}。在每个周期k的开始，服务器将其当前参数θ_k ∈ ℝ^d、先前解码方向h_{k−1}和半径ρ_k发送给智能体。我们将很快解释θ_k、h_{k−1}和ρ_k如何被初始化并在每个周期中更新。然后，智能体基于第二节的独立同分布采样模型依次收集H个观测元组{(s_j, r_j, s′j)}{j∈I_k}。利用这些样本和接收到的参数θ_k，智能体按如下方式计算均值路径TD(0)方向ḡ(θ_k)的估计Y_k：

Y_k = (1/H) Σ_{j∈I_k} ϕ(s_j)[r_j + γϕ(s′_j)^⊤θ_k − ϕ(s_j)^⊤θ_k]. (4)

鉴于上述被平均的每个对象都具有共同的"冻结"参数θ_k，不难看出在我们的独立同分布采样模型下，Y_k是ḡ(θ_k)的无偏估计，其方差与批量大小H成反比。正如我们即将看到的，通过控制H，可以进而控制增量过程{u_k := Y_k − h_{k−1}}的不确定性，以及（以高概率）包含此类过程所需的球的半径ρ_k。

  • 增量的编码与解码。 智能体形成增量u_k := Y_k − h_{k−1}，它度量智能体处当前估计方向与服务器处先前解码方向之间的差异。使用前面描述的标量中点编码器，智能体传输对应于量化信号z_k := Q_{m,ρ_k}(v_k)的dm比特消息，其中v_k = sat_{ρ_k}(u_k)。服务器解码消息以完美恢复z_k，然后使用它重构TD(0)方向并按如下方式更新模型参数：

h_k = h_{k−1} + z_k, θ_{k+1} = θ_k + αh_k, (5)

其中α是步长，我们将在下一节中指定。剩下需要解释的是半径ρ_k如何在每个周期中被自适应调整以包含增量过程。为此，给定K、H、m ≥ 1、置信水平δ∈(0,1)以及奖励分布的统计量r̄和σ（在第二节中定义），设

C_δ² = 2 max{4d², d(r̄² + σ²)} log(4Kd²/δ), (6)

并定义固定的批量误差容许量ϵ_H := C_δ/√H；注意ϵ_H可以离线计算。智能体和服务器共享这些量以及初始参数θ₀。我们初始化解码方向和编码半径为

h_{−1} = 0, ρ₀ = r̄ + 2∥θ₀∥ + ϵ_H(∥θ₀∥ + 1). (7)

令η = √d/2^m为引理1中的量化常数。更新参数后，服务器按如下方式调整编码半径：

ρ_{k+1} = ηρ_k + 2α∥h_k∥ + 2ϵ_H(∥θ_k∥ + 1). (8)

下一次服务器传输向智能体提供(θ_{k+1}, h_k, ρ_{k+1})，确保双方在编码-解码过程中使用相同的参考。这也使服务器能够从接收到的B = dm比特智能体消息中精确解码{z_k}序列。现在让我们简要解释(8)中自适应范围更新规则背后的原理。

  • 自适应编码半径。 半径ρ_k的选择是为了包含下一个增量Y_{k+1} − h_k。(8)右端的第一项，即ηρ_k，来自引理1，在饱和不活跃时（即∥u_k∥ ≤ ρ_k时）界定当前解码方向中的重构误差。由于Y_{k+1}是在θ_{k+1}处计算的而h_k对应于θ_k，差距Y_{k+1} − h_k依赖于参数变化θ_{k+1} − θ_k = αh_k，这解释了(8)右端的第二项。最后，编码半径需要考虑批量TD(0)估计过程中的误差。在这方面，我们稍后在引理2中表明，以至少1−δ的概率，经验TD矩阵和奖励向量在所有K个批次中同时分别位于A和b的ϵ_H范围内。因此，精度水平ϵ_H出现在(8)的最后一项中。结合初始半径ρ₀，这些界归纳地确保每个传输的增量以高概率满足∥u_k∥ ≤ ρ_k；见引理3。

我们的方法每通信轮处理H个样本，在整个样本预算上产生K次参数更新和K条固定长度消息。因此，在长度为T的时间范围内，总通信成本为Kdm比特。在下一节中，我们表明对于适当选择的参数m，K = O(logT)个周期足以获得期望的˜O(1/T)速率。我们算法的步骤在算法1中概述，其中▶和▶分别表示由智能体和服务器执行的操作。

算法1 批量自适应量化TD（BAQ-TD）
1: 输入：满足定理1条件的T、K、δ、α、m、θ₀。
2: 初始化：设H = T/K且η = √d/2^m；由(6)计算C_δ；按(7)设置h_{−1}、ρ₀。
3: for k = 0, . . . , K−1 do
4: (•) 服务器（下行链路）：
▶ 向智能体发送(θ_k, h_{k−1}, ρ_k)。
5: (•) 智能体（计算与传输）：
▶ 抽取独立同分布元组{(s_j, r_j, s′j)}{j∈I_k}，其中|I_k| = H。
▶ 由(4)计算Y_k。
▶ 设u_k = Y_k − h_{k−1}且v_k = sat_{ρ_k}(u_k)。
▶ 使用标量中点编码器发送编码增量z_k = Q_{m,ρ_k}(v_k)的dm比特消息。
6: (•) 服务器（解码与更新）：
▶ 解码z_k = Q_{m,ρ_k}(v_k)。
▶ 设h_k = h_{k−1} + z_k且θ_{k+1} = θ_k + αh_k。
▶ 由(8)计算ρ_{k+1}。
7: end for
8: 返回θ_K。

IV. 主要结果

我们现在为BAQ-TD建立有限时间收敛保证。为此，令e_k := θ_k − θ⋆表示参数误差，并定义耦合Lyapunov函数V_k := ∥e_k∥² + αρ_k²，联合跟踪参数误差和编码半径。令D为对角线上放置平稳分布ν的元素的对角矩阵，并定义Σ = Φ^⊤DΦ。在假设1和我们施加于Φ的条件下，可以验证Σ是正定的，其最小特征值为ω̃∈(0,1)。定义ω := ω̃(1−γ)，并回顾(6)中的C_δ，我们可以陈述主要结果。

定理1（有限时间收敛）。 假设假设1成立。给定δ∈(0,1)，以步长α∈(0, ω/32]和满足m ≥ ⌈(1/2)log₂(64d/ω)⌉的精度运行算法1。选择K = ⌈c₁logT/(αω)⌉并假设总样本数T = KH满足T ≥ c₂KC_δ²/ω²。则至少以1−δ的概率（w.p.），界

∥θ_k − θ⋆∥² ≤ (1−αω)^k V₀ + O(C_δ²(1 + ∥θ⋆∥)²logT/(αω³T)) (9)

对所有k∈[K]同时成立。这里，V₀ = ∥θ₀ − θ⋆∥² + αρ₀²，c₁、c₂是足够大的通用常数。

每个周期使用H个样本并产生一次参数更新和一条dm比特的智能体到服务器消息。因此总成本为KH个样本、K条消息和Kdm个传输比特。以下推论直接由定理1得出，将这些通信成本与统计保证相结合。

推论1（精度与通信）。 在定理1的条件下，选择m = ⌈(1/2)log₂(64d/ω)⌉和α = ω/32。在T = KH时间范围内，BAQ-TD传输K = ⌈32c₁logT/(ω²)⌉条固定长度消息，每条包含dm比特。因此传输的总比特数为

Kdm = O(dlog(d/ω)logT/ω²). (10)

对任意δ∈(0,1)，若T满足定理1的样本量条件，则至少以1−δ的概率，

∥θ_K − θ⋆∥² ≤ V₀/T + C_p logT/T · log(d²logT/(ω²δ)), (11)

其中C_p = Cc₁²(1 + ∥θ⋆∥)²max{4d², d(r̄² + σ²)}/ω⁴，C > 0是足够大的通用常数。

定理1和推论1的讨论。 定理1为有限比特通信的TD学习提供了有限时间高概率保证。(9)中的第一项是形如e^{−αωk}V₀的几何衰减瞬态项，其中V₀ = ∥e₀∥² + αρ₀²反映了参数估计误差与量化误差（由编码半径ρ刻画）之间的耦合。(9)中的第二项是随样本量T收缩的统计误差项。我们在下面讨论方法的样本复杂度和通信复杂度。

  • 统计精度。 我们分析中得到的统计残差为C_δ²(1 + ∥θ⋆∥)²/(ω²H)阶，其中回顾H是每个周期的大小。显然，增加H会降低残差，但代价是用于控制瞬态的收缩周期K变少（因为T = KH）。幸运的是，由于瞬态项随K指数衰减，设置K = O(log(T))足以实现˜O(1/T)的总体速率，如推论1所建立的。该速率与先前TD(0)的非渐近均方误差[5]、[6]、[8]和高概率界[7]一致，并且在对样本量T的依赖上是阶数最优的。

  • 通信成本。 在通信复杂度方面，我们的结果提供了两个关键信息。首先，我们表明当m = O(log(d/ω))时，B = dm比特的固定信道容量足以保持˜O(1/T)的理想速率，即我们证明了在某个有限信道容量之上，可以确保性能无损失。值得注意的是，我们确定的m的要求仅依赖于特征维度d和"类强凸性"参数ω，而不依赖于批量大小H或总预算T。因此，即使样本预算T增加，每条消息的比特数仍可继续保持固定。虽然这解决了每轮需要发送多少信息的问题，但确定智能体应与服务器通信的频率问题仍然悬而未决。由于通信轮数恰好为K且K = log(T)，我们表明此类轮数随时间范围T呈温和的对数增长。形成鲜明对比的是，[9]、[10]中的压缩TD方案在每个时间步都通信，产生与T成线性关系的总通信成本。因此，我们相对于先前工作实现了通信成本的指数级改进，并提供了首个结果表明仅用总共O(dlog(T))比特即可继续获得˜O(log(1/δ)/T)阶的高概率速率。

VI. 主要收敛性分析

为证明定理1，我们首先界定每个周期中TD更新方向批量估计的估计误差。为此，回顾ϵ_H = C_δ/√H且η = √d/2^m。对于一般转移样本，令B := ϕ(s)(ϕ(s) − γϕ(s′))^⊤。由于特征归一化，∥B∥ ≤ ∥ϕ(s)∥(∥ϕ(s)∥ + γ∥ϕ(s′)∥) ≤ 2。因此，由于A = E[B]，我们有∥A∥ ≤ E[∥B∥] ≤ 2。对于每个周期k∈[K−1]，定义以下内容：

ĝ_k(θ) := b̂_k − Â_kθ, θ∈ℝ^d, (12)

其中Â_k := H^{−1}Σ_{j∈I_k} ϕ(s_j)(ϕ(s_j) − γϕ(s′j))^⊤且b̂_k := H^{−1}Σ{j∈I_k} r_jϕ(s_j)。于是由(4)知Y_k = ĝ_k(θ_k)。此外，在独立同分布平稳采样模型下，我们有E[Â_k] = A且E[b̂_k] = b。我们有以下结果。

引理2（算子估计）。 定义

G := ∩_{k=0}^{K−1} {∥Â_k − A∥ ≤ ϵ_H, ∥b̂_k − b∥ ≤ ϵ_H}. (13)

则P(G) ≥ 1−δ，且在G上，

∥ĝ_k(θ) − ḡ(θ)∥ ≤ ϵ_H(∥θ∥ + 1) (14)

对所有k = 0, . . . , K−1和∀θ∈ℝ^d同时成立。

证明。 我们首先控制经验矩阵。对于j∈I_k，记B_j := ϕ(s_j)(ϕ(s_j) − γϕ(s′j))^⊤。特征归一化给出∥B_j∥ ≤ ∥ϕ(s_j)∥(∥ϕ(s_j)∥ + γ∥ϕ(s′_j)∥) ≤ 1 + γ ≤ 2。因此，对每个实现的批次∥Â_k∥ ≤ 2且E[B_j] = A。此外，每个元素满足|[B_j]{iℓ}| = |ϕ_i(s_j)||ϕ_ℓ(s_j) − γϕ_ℓ(s′_j)| ≤ 2。由于Â_k对H个期望为A的独立矩阵取平均，标量Hoeffding不等式[24]给出，对每个i、ℓ∈{1, . . . , d}，

P(|[Â_k − A]_{iℓ}| > ϵ_H/d) ≤ 2exp(−Hϵ_H²/(8d²)) ≤ δ/(2Kd²).

最后一个不等式由Hϵ_H² = C_δ²和(6)得出。对所有d²个元素和K个周期取并集界，则确保至少以1−δ/2的概率，∥Â_k − A∥ ≤ ∥Â_k − A∥F ≤ d max{i,ℓ}|[Â_k − A]_{iℓ}| ≤ ϵ_H对k = 0, . . . , K−1同时成立。这里，∥·∥_F表示Frobenius范数。接下来，考虑经验奖励向量。令为一般平稳转移元组并固定i∈{1, . . . , d}。由于E[r|s] = Rµ(s)，我们有[b]_i = E[Rµ(s)ϕ_i(s)]。对每个λ∈ℝ，定义(•) ≜ E[exp(λ(rϕ_i(s) − [b]_i))]。对s∈S取条件并使用第二节的奖励假设，我们得到：

(•) = E[exp(λ(Rµ(s)ϕ_i(s) − [b]_i))E[exp(λϕ_i(s)(r − Rµ(s)))|s]] (i) ≤ exp(λ²σ²/2)E[exp(λ(Rµ(s)ϕ_i(s) − [b]_i))] (ii) ≤ exp(λ²(r̄² + σ²)/2). (15)

这里，通过对标量λϕ_i(s)将条件次高斯假设应用于r − Rµ(s)并使用|ϕ_i(s)| ≤ 1得出。对于，Hoeffding引理适用于Rµ(s)ϕ_i(s)，它位于[−r̄, r̄]中且均值为E[Rµ(s)ϕ_i(s)] = [b]_i。因此，rϕ_i(s) − [b]_i是方差代理为r̄² + σ²的次高斯变量。每批次内的独立性意味着[b̂_k − b]_i是方差代理为(r̄² + σ²)/H的次高斯变量。由(6)，ϵ_H/√d ≥ √(2(r̄² + σ²)log(4Kd/δ)/H)。因此标量次高斯集中给出

P(|[b̂_k − b]_i| > ϵ_H/√d) ≤ 2exp(−log(4Kd/δ)) = δ/(2Kd),

同样由(6)得出。对d个坐标和K个周期取并集界，再由∥x∥ ≤ √d max_i |x_i|，给出∥b̂_k − b∥ ≤ √d max_i |[b̂_k − b]_i| ≤ ϵ_H对所有k = 0, . . . , K−1同时成立，概率至少为1−δ/2。结合矩阵和向量界得到P(G) ≥ 1−δ。在G上，对每个周期k和每个θ∈ℝ^d，恒等式ĝ_k(θ) − ḡ(θ) = (b̂_k − b) − (Â_k − A)θ和三角不等式给出∥ĝ_k(θ) − ḡ(θ)∥ ≤ ∥b̂_k − b∥ + ∥Â_k − A∥∥θ∥ ≤ ϵ_H(∥θ∥ + 1)。

接下来，我们表明以高概率，每个增量都位于(7)和(8)指定的编码半径内。

引理3（无饱和）。 在(13)定义的事件G上，(7)和(8)蕴含对所有k = 0, . . . , K−1有∥u_k∥ ≤ ρ_k。因此，由引理1，重构误差满足

q_k = Q_{m,ρ_k}(u_k) − u_k, ∥q_k∥ ≤ ηρ_k. (16)

证明。 我们在(13)定义的事件G上证明该断言。第二节的奖励界|Rµ(s)| ≤ r̄和特征界∥ϕ(s)∥ ≤ 1给出∥b∥ = ∥E[Rµ(s)ϕ(s)]∥ ≤ E[|Rµ(s)|∥ϕ(s)∥] ≤ r̄。由于h_{−1} = 0且Y₀ = ĝ₀(θ₀)，初始增量为u₀ = ĝ₀(θ₀)。在G上应用(14)给出∥u₀∥ ≤ ∥ḡ(θ₀)∥ + ϵ_H(∥θ₀∥ + 1) ≤ r̄ + 2∥θ₀∥ + ϵ_H(∥θ₀∥ + 1) = ρ₀。因此，周期0处饱和不活跃。假设对所有j = 0, . . . , k有∥u_j∥ ≤ ρ_j，其中k∈{0, . . . , K−1}。由于∥u_k∥ ≤ ρ_k，我们有sat_{ρ_k}(u_k) = u_k。利用u_k = Y_k − h_{k−1}（其中Y_k由(4)定义），重构更新(5)给出q_k = h_k − Y_k = Q_{m,ρ_k}(u_k) − u_k。引理1于是蕴含∥q_k∥ ≤ ηρ_k。对于k ≤ K−2，我们将u_{k+1}表示如下：

u_{k+1} = Y_{k+1} − h_k = Y_{k+1} − Y_k − q_k = ĝ_{k+1}(θ_{k+1}) − ĝ_k(θ_k) − q_k = ĝ_{k+1}(θ_{k+1}) − ĝ_{k+1}(θ_k) + ĝ_{k+1}(θ_k) − ĝ_k(θ_k) − q_k = Â_{k+1}(θ_k − θ_{k+1}) − (Â_{k+1} − Â_k)θ_k + (b̂_{k+1} − b̂_k) − q_k.

该分解将参数变化与在θ_k处求值的两个批量估计之间的差异分离开来。在G上，∥Â_{k+1} − Â_k∥ ≤ 2ϵ_H且∥b̂{k+1} − b̂_k∥ ≤ 2ϵ_H，因为每个经验算子都在其期望的ϵ_H范围内。因此，利用∥Â{k+1}∥ ≤ 2和θ_{k+1} − θ_k = αh_k，我们得到∥u_{k+1}∥ ≤ 2∥θ_{k+1} − θ_k∥ + 2ϵ_H(∥θ_k∥ + 1) + ηρ_k = 2α∥h_k∥ + 2ϵ_H(∥θ_k∥ + 1) + ηρ_k = ρ_{k+1}。归纳法建立了对每个传输的增量∥u_k∥ ≤ ρ_k和(16)。

定义采样误差ξ_k := Y_k − ḡ(θ_k)。于是解码方向允许分解h_k = ḡ(θ_k) + ξ_k + q_k。这里ξ_k对应批量估计，q_k对应有限比特重构。回顾e_k = θ_k − θ⋆。由于Aθ⋆ = b，我们有ḡ(θ_k) = b − Aθ_k = −Ae_k。我们的下一个结果给出采样误差ξ_k、重构误差q_k和编码半径ρ_k作为次优性e_k的函数的界。

引理4（方向与半径界）。 假设0 < α ≤ ω/32。在(13)定义的事件G上，以下界对每个k = 0, . . . , K−1同时成立：

∥ξ_k∥ ≤ ϵ_H(∥e_k∥ + 1 + ∥θ⋆∥), (17)

∥ξ_k + q_k∥² ≤ 2η²ρ_k² + 4ϵ_H²∥e_k∥² + 4ϵ_H²(1 + ∥θ⋆∥)², (18)

ρ_{k+1}² ≤ 12η²ρ_k² + (48α² + 96ϵ_H²)∥e_k∥² + 96ϵ_H²(1 + ∥θ⋆∥)². (19)

证明。 由(14)，在G上，∥ξ_k∥ = ∥ĝ_k(θ_k) − ḡ(θ_k)∥ ≤ ϵ_H(∥θ_k∥ + 1)。利用θ_k = e_k + θ⋆和三角不等式证明(17)。接下来，将∥x+y∥² ≤ 2∥x∥² + 2∥y∥²应用于ξ_k + q_k。由(17)和(16)，

∥ξ_k + q_k∥² ≤ 2∥ξ_k∥² + 2∥q_k∥² ≤ 2ϵ_H²(∥e_k∥ + 1 + ∥θ⋆∥)² + 2η²ρ_k² ≤ 4ϵ_H²∥e_k∥² + 4ϵ_H²(1 + ∥θ⋆∥)² + 2η²ρ_k²,

其中最后一个不等式使用了 ≤ 2a² + 2b²。这证明了(18)。为界定下一个半径，将h_k = ḡ(θ_k) + ξ_k + q_k代入(8)。利用(16)的∥q_k∥ ≤ ηρ_k和(14)的∥ξ_k∥ ≤ ϵ_H(∥θ_k∥ + 1)，我们得到

ρ_{k+1} ≤ ηρ_k + 2α(∥ḡ(θ_k)∥ + ∥ξ_k∥ + ∥q_k∥) + 2ϵ_H(∥θ_k∥ + 1) ≤ η(1 + 2α)ρ_k + 2α∥ḡ(θ_k)∥ + 2(1 + α)ϵ_H(∥θ_k∥ + 1).

由于α ≤ ω/32 ≤ 1/32，我们有1 + 2α ≤ 2且2(1 + α) ≤ 4。利用∥θ_k∥ + 1 ≤ ∥e_k∥ + 1 + ∥θ⋆∥给出

ρ_{k+1} ≤ 2ηρ_k + 2α∥ḡ(θ_k)∥ + 4ϵ_H(∥e_k∥ + 1 + ∥θ⋆∥). (20)

对该界取平方并应用 ≤ 3(a² + b² + c²)得到以下结果：

ρ_{k+1}² ≤ 12η²ρ_k² + 12α²∥ḡ(θ_k)∥² + 48ϵ_H²(∥e_k∥ + 1 + ∥θ⋆∥)².

利用ḡ(θ_k) = −Ae_k和算子范数界∥A∥ ≤ 2给出∥ḡ(θ_k)∥ = ∥Ae_k∥ ≤ ∥A∥∥e_k∥ ≤ 2∥e_k∥。此外，(∥e_k∥ + 1 + ∥θ⋆∥)² ≤ 2∥e_k∥² + 2(1 + ∥θ⋆∥)²。代入这些界证明了(19)。

我们所需的最后一块是来自[5]的以下结果。

⟨θ − θ, ḡ(θ)⟩ ≥ ω∥θ − θ∥², ∀θ∈ℝ^d, (21)

其中回顾ω = (1−γ)ω̃∈(0,1)，ω̃是Σ = Φ^⊤DΦ的最小特征值。我们现在通过联合Lyapunov函数V_k = ∥e_k∥² + αρ_k²结合这些界来证明定理1。

■定理1的证明。 由引理2，(13)定义的事件G的概率至少为1−δ。我们在该事件上证明断言。回顾η = √d/2^m。规定的精度m ≥ ⌈(1/2)log₂(64d/ω)⌉给出η² = d/2^{2m} ≤ ω/64。由于T = KH，样本量条件蕴含H ≥ c₂C_δ²/ω²。因此取通用常数c₂ ≥ 1024确保ϵ_H² = C_δ²/H ≤ ω²/1024。步长满足0 < α ≤ ω/32。引理3给出对每个k = 0, . . . , K−1有∥u_k∥ ≤ ρ_k和∥q_k∥ ≤ ηρ_k。于是采样和重构误差满足引理4中的界。

我们首先推导V_k = ∥e_k∥² + αρ_k²的递推。参数更新和h_k的分解给出e_{k+1} = e_k + αḡ(θ_k) + α(ξ_k + q_k)。由此和(21)，我们得到

∥e_{k+1}∥² ≤ (1−2αω)∥e_k∥² + 2α⟨e_k, ξ_k + q_k⟩ + 2α²∥ḡ(θ_k)∥² + 2α²∥ξ_k + q_k∥².

Young不等式给出2⟨e_k, ξ_k + q_k⟩ ≤ (ω/2)∥e_k∥² + (2/ω)∥ξ_k + q_k∥²。结合∥ḡ(θ_k)∥ ≤ 2∥e_k∥，这给出

∥e_{k+1}∥² ≤ (1 − (3/2)αω + 8α²)∥e_k∥² + 2(α/ω + α²)∥ξ_k + q_k∥².

由于αω ≤ 1，最后一项的系数至多为4α/ω。因此代入(18)给出

∥e_{k+1}∥² ≤ (1 − (3/2)αω + 8α² + 16αϵ_H²/ω)∥e_k∥² + (8αη²/ω)ρ_k² + (16αϵ_H²/ω)(1 + ∥θ⋆∥)². (22)

将α乘以(19)加到(22)并合并项，得到

V_{k+1} ≤ [1 − (3/2)αω + α(8α + 48α² + (16/ω + 96)ϵ_H²)]∥e_k∥² + αη²(8/ω + 12)ρ_k² + α(16/ω + 96)ϵ_H²(1 + ∥θ⋆∥)². (23)

由于0 < ω ≤ 1且α ≤ ω/32，我们有αω ≤ 1/32且η²(8/ω + 12) ≤ (ω/64)(8/ω + 12) = 1/8 + 3ω/16 ≤ 5/16 ≤ 31/32 ≤ 1 − αω。此外，步长和批量大小界给出8α + 48α² + (16/ω + 96)ϵ_H² ≤ 13ω/32 ≤ ω/2。因此，(23)中∥e_k∥²和αρ_k²的系数都至多为1 − αω。最后，16/ω + 96 ≤ 112/ω将加性项界定为O(αϵ_H²(1+∥θ⋆∥)²/ω)。将这些估计代入(23)并利用V_k = ∥e_k∥² + αρ_k²，得到

V_{k+1} ≤ (1−αω)V_k + O(αϵ_H²/ω)(1 + ∥θ⋆∥)² (24)

对每个k = 0, . . . , K−1。迭代(24)给出

V_k ≤ (1−αω)^k V₀ + O(αϵ_H²/ω)(1 + ∥θ⋆∥)² Σ_{j=0}^{k−1}(1−αω)^j (25)

对每个k = 1, . . . , K。由于0 < αω < 1，几何和的上界为1/(αω)。在(25)中使用ϵ_H² = C_δ²/H并丢弃非负项αρ_k²，我们得到

∥θ_k − θ⋆∥² ≤ (1−αω)^k V₀ + O(C_δ²(1 + ∥θ⋆∥)²/(ω²H)). (26)

同样的界在k = 0处成立，因为∥θ₀ − θ⋆∥² ≤ V₀。因此，(26)在单一事件G上对所有k = 0, . . . , K同时成立；不需要额外的并集界。为了用样本预算表示统计贡献，将H = T/K代入(26)。这给出O(C_δ²(1 + ∥θ⋆∥)²K/(ω²T))。在规定的选择K = ⌈c₁logT/(αω)⌉下，这变为O(C_δ²(1 + ∥θ⋆∥)²logT/(αω³T))，证明了(9)。

VII. 结论

我们研究了速率受限信道上带线性函数逼近的策略评估，并提出了BAQ-TD，它将基于模型的方差缩减与增量的自适应量化相结合。我们的高概率保证匹配未量化TD的速率，仅需随样本量对数增长的适度通信预算。
