Jev 成为 Vercel 史上采用最快的 ...

📅 2026-10-16 📄 TechCrunch AI 🔗 原文链接

原标题：Jev is Vercel’s fastest-adopted AI model ever

中文摘要： Vercel 数据显示，AI 决策模型 Jev 发布两周内即被 35% 的付费团队采用，创模型史上最快采用纪录，覆盖面约为第二名 Sonnet 5.5 的两倍。Jev 是一款轻量级分类工具，通过限制输出数量实现更低成本和更快速度。数据来自 Vercel 的 AI 网关，证明热议已转化为实际使用。同时，开源模型占网关 token 处理量超 70%，前沿实验室支出增长十倍，表明前沿模型与开源方案或为互补关系。

Vercel 周四发布的数据显示，这款备受热议的决策模型在发布两周内已被 35% 的付费团队使用，覆盖范围几乎是第二受欢迎的模型 Sonnet 5.5 的两倍。据 Vercel 的数据，这是有史以来模型在发布头两周内创下的最快采用速度，也是该模型创造者 TypeSafe AI 的一项重大成就。

Jev 于 9 月 15 日限量发布，被设计为一款轻量级工具，用于在少数预定输出之间进行选择。限制输出数量使该模型的运行成本比 Sonnet 等替代方案更低、速度更快，因此非常适合快速分类大量数据。自 Jev 发布以来的几周里，这种新方法引发了巨大轰动——促使 OpenAI 和 Amazon 等公司推出竞争产品——但在此之前，几乎没有硬数据来支撑这种好评。

这些数据来自 Vercel 的 AI 网关，这是一项类似于 OpenRouter 的统一 API 服务。这必然是一个有限的视角——尤其可能低估 OpenAI 和 Anthropic 等提供自家 API 的大型实验室——但它表明围绕 Jev 的热议确实转化为了实际使用量。事实上，Vercel 是 Jev 的早期采用者，用它取代 GPT-6 Luna 来分类有害命令。

报告还显示开源模型持续保持增长势头，目前占 Vercel 网关处理 token 总量的 70% 以上，占总支出的近 25%。

虽然开源模型正在占据更大的市场份额，但市场本身也在快速增长。前沿实验室的支出增长了十倍，尽管其占总支出的比例有所下降，这印证了这样一种观点：前沿模型和开源替代方案最终可能是互补而非竞争关系。
