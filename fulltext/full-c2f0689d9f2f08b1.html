摘要

安全上下文内强化学习要求参数固定的策略从其交互历史中改进以适应未见过的受约束任务，同时力求将成本保持在预算之内。先前的工作在三大家族的五个基准上研究了 Safe ICRL：具有隐藏目标和障碍物的网格世界、目标和危险在到达之前保持不可见的连续导航，以及具有隐藏速度限制的运动任务。安全算法蒸馏在安全强化学习算法的学习历史上训练，在先前的评估中显示出适应失败。例如，在运动任务中其回报保持为负，且在 CarGoal 中很少到达目标。我们重新审视了 Safe AD 的两个部分。首先，我们蒸馏一个具有两个阶段的预算感知教师：它搜索隐藏任务，剩余预算越多探索越多；在首次获得奖励或成本后，专家策略在剩余预算内利用该任务。我们在固定或动态预算下收集教师的历史。动态预算在每个环境中都增加了回报和预算输入的占据熵，且在测试时它们在 DarkRoom 和 HalfCheetah 中提高了回报并降低了成本。其次，我们提出 A-Lag，一种测试时调整方法，通过预测成本重新加权蒸馏策略的动作，并使用从观察到的成本自适应更新的拉格朗日乘子。在我们的实验中，A-Lag 在所有五个环境中的平均回合成本均低于 Safe AD，其中四个环境的平均最终回报较低。

1 引言

上下文内强化学习（ICRL）通过交互历史适应新任务，而无需更新模型参数。当测试任务与训练任务不同时，这种适应带来了安全性-泛化问题：动力学或任务条件的变化可能部分未被观察到，降低策略泛化能力，并产生安全风险。

Safe ICRL 将 ICRL 扩展到这种设置，要求策略在控制成本的同时改进其任务行为。Transformer 策略可以学习仅奖励目标的上下文内适应，先前的工作用受约束马尔可夫决策过程形式化了 Safe ICRL。算法蒸馏（AD）在强化学习算法的学习历史上训练 Transformer。Safe AD 是该工作的 AD 基线，蒸馏了诸如 PPO-Lagrangian 等安全强化学习算法的历史，并在其中一些基准上显示出适应失败。在 HalfCheetah 和 Ant 中，其回报在每个上下文内回合中都保持为负，而在 CarGoal 中，它很少到达目标（附录 J）。这激发了本文的核心问题：如果 Safe AD 从预算感知教师学习并在测试时显式调整预算，它能否以更低的成本适应未见过的任务？

我们研究 Safe AD 的两个部分，即它学习的数据以及它在部署时如何使用预算。在安全强化学习中，学习历史通常来自在一个固定成本限制下训练的收集器。Safe AD 蒸馏学习历史。这些历史显示了策略改进，但它们并非旨在展示行为应如何随预算变化或如何以低成本搜索未知任务。我们改为蒸馏一个教师，其历史展示了我们希望学生表现的行为。它在预算允许时搜索隐藏任务，然后切换到专家策略，用适合剩余预算的最佳行为利用它所发现的内容，类似于 ICRL 的专家数据预训练。在部署时，Safe AD 在每一步将剩余成本预算（cost-to-go，CTG）作为输入，但它对该输入的反应是在训练中学习的。例如，如果一个回合超支其预算，Safe AD 只能以其在训练期间学到的方式，通过其上下文中的历史来调整下一个回合。

为了解决这个问题，我们提出动作级拉格朗日，它在保持训练权重不变的同时添加显式校正。其拉格朗日乘子在蒸馏策略内部惩罚每个动作的预测成本，而不是训练目标。A-Lag 保持 Safe AD 的 Transformer、其 RTG 和 CTG 输入以及其行为克隆目标，并训练一个额外的头，从策略的表示预测动作的即时成本。在部署时，蒸馏策略通过每个动作的预测成本重新加权，由乘子 λ 缩放，因此具有高预测成本的动作变得不太可能。乘子在回合之间通过对相对于预算的实现回合成本的对偶上升步骤进行更新。因此 A-Lag 以两种方式适应：通过其上下文（如 Safe AD 所做）和通过乘子（显式响应相对于预算的观察到的成本）。我们的实验使用 Moeini 等人（2026）的五个 Safe ICRL 基准：具有隐藏目标和障碍物的网格世界、目标和危险在到达之前保持不可见的连续导航，以及具有隐藏速度限制的运动任务。我们的贡献如下。

  • 预算感知教师。 我们提出蒸馏一个搜索隐藏任务然后利用它的预算感知教师。在动态预算下收集其历史使得回报和预算输入通过占据熵更加多样化（表 1）。
  • A-Lag。 我们提出一个拉格朗日乘子，通过预测成本重新加权动作，并在测试时从观察到的回合成本更新。在我们的实验中，A-Lag 在所有五个环境中的平均回合成本低于 Safe AD，其中四个的平均最终回报较低（第 5.3 节）。

2 背景

受约束马尔可夫决策过程。 我们将每个任务建模为有限视界受约束马尔可夫决策过程（CMDP）M = (S, A, r, c, p, p₀, T, δ)，其中 c: S×A→ℝ 是成本函数，δ ≥ 0 是安全预算。在时间步 t，智能体观察状态 Sₜ ∈ S，根据策略 π(·|Sₜ) 采取动作 Aₜ ∈ A，接收奖励 Rₜ₊₁ ≐ r(Sₜ, Aₜ) 和成本 Cₜ₊₁ ≐ c(Sₜ, Aₜ)，并转移到 Sₜ₊₁ ~ p(·|Sₜ, Aₜ)。一个回合是轨迹 τ = (S₀, A₀, R₁, C₁, S₁, …, Sₜ₋₁, Aₜ₋₁, Rₜ, Cₜ)，其回报为 G(τ) ≐ ∑ₜ₌₁ᵀ Rₜ，回合成本为 G꜀(τ) ≐ ∑ₜ₌₁ᵀ Cₜ。目标是在 E[τ~π][G꜀(τ)] ≤ δ 的约束下最大化 E[τ~π][G(τ)]。

上下文内强化学习。 ICRL 在记录轨迹的静态数据集上预训练 Transformer 策略 π_θ，然后通过以其不断增长的交互历史为条件来适应新任务，而无需在测试时进行梯度更新。参数 θ 在预训练期间学习一次，然后固定。在测试时，策略在第 k 个回合的每一步 t 以上下文 Hₜᵏ 为条件：π_θ(·|Sₜᵏ, Hₜᵏ)。上下文的一个常见选择是观察到的转移历史：Hₜᵏ ≐ (τ₁, …, τₖ₋₁, τₖᵗ)，其中 τₖᵗ 是当前回合到时间 t 的观察前缀，每步成本仅在受约束设置中包含。我们分别用 Gᵣ,ₜ(τ) 和 G꜀,ₜ(τ) 表示未来实现的奖励和成本总和。我们使用 RTGₜ 表示目标奖励（在训练中实现，在部署时由用户指定），CTGₜ 表示成本预算。这种适应通常被解释为网络在其前向传播中运行强化学习算法，随着上下文增长而改进。

安全上下文内强化学习。 Safe ICRL 研究对未见任务适应的安全性。Safe ICRL 的目标是预训练参数 θ，使得当策略 π_θ 在测试时部署于未见 CMDP 时，性能在回合间提高同时满足安全预算 δ。形式上，参数 θ 在训练 CMDP 上学习。在固定的未见 CMDP 上，所得策略在回合 {τₖ}ₖ₌₁ᴷ 上通过 E[π_θ][∑ₖ₌₁ᴷ G(τₖ)] s.t. ∀k, E[π_θ][G꜀(τₖ)] ≤ δ 进行评估。由于 CMDP 和 θ 在此评估期间保持固定，任何适应都来自不断增长的上下文 Hₜᵏ。

3 安全算法蒸馏的教师数据

Safe AD 只能学习其历史展示的行为。在一个固定成本限制下安全强化学习算法的学习历史显示了策略的改进，但没有显示如何以低成本搜索隐藏任务或在剩余预算较少时如何行动。为了解决这个问题，我们使用第 3.2 节的两阶段教师收集历史，采用下文定义的固定和动态预算方案。

3.1 动态预算收集

每个训练历史由一个训练任务上的 K 个上下文内回合组成，由教师策略 π_T 生成。预算 B₀（第 2 节的 δ）每个历史采样一次，剩余预算 Bₜᵏ 在每个回合从它重新开始：

B₀ ~ D_budget，B₀ᵏ = B₀，Aₜᵏ ~ π_T(·|Sₜᵏ, Hₜᵏ, Bₜᵏ)，Bₜ₊₁ᵏ = max(0, Bₜᵏ − Cₜ₊₁ᵏ)，（公式 1）

其中 k ∈ {1, …, K} 索引上下文内回合，Sₜᵏ 和 Hₜᵏ 在第 2 节中定义。在动态预算收集中，D_budget = U[B_min, B_max] 覆盖环境的预算范围。在固定预算收集中，每个历史使用一个预算 B₀ = B_max。先前的 Safe ICRL 工作使用固定成本限制，使用诸如 PPO-Lagrangian 等安全强化学习算法的学习历史。固定预算历史在实现成本上仍然不同，因为教师探索多少取决于任务，但它们从未显示当起始预算较小时行为应如何变化。每个记录的步骤携带状态、动作、奖励、成本、RTGₜᵏ = Gᵣ,ₜ(τₖ) 和 CTGₜᵏ = Bₜᵏ，执行的动作是训练目标。RTG 是回合 τₖ 中尚未到来的奖励，而 CTG 是剩余预算，不是尚未到来的成本。

3.2 教师

教师看不到任务（目标位置或速度阈值）或危险布局。它仅根据学生也看到的输入决定：观察、奖励、成本和回合边界。将 H 写为历史 Hₜᵏ 连同当前状态 Sₜᵏ，B 写为 Bₜᵏ，它分两个阶段行动：

π_T(·|H, B) = Search(H, B)，直到 H 中出现首个奖励（目标任务）或成本（速度任务）；之后为 Expert_q(H, B)。（公式 2）

搜索在剩余预算更多时探索更多，并避免它已经付出成本的地方。在此切换事件之后，质量为 q 的专家用它所知的最佳行为利用它。在 DarkRoom 中，专家沿着没有观察到成本的最短已知路径行走，这适合任何剩余预算。在导航任务中，它驶向从其历史估计的目标位置。在速度任务中，它以成本适合 B 的最快速度运行。在导航和速度任务中，专家决定去哪里或跑多快。然后，训练用于到达给定位置或保持给定速度的 PPO 策略相应地产生动作。Search、Expert_q 和它们之间的切换事件取决于环境（附录 B 和表 3）。

3.3 专家质量

Expert₁ 是我们在每个环境中回报最高的专家。像每个专家一样，它只使用已知成本适合剩余预算的行为。在 DarkRoom 中，它走最短的已知无成本路径。在其他环境中，它运行验证得分最佳的 PPO 控制器检查点（附录 B）。专家的质量 q 是其在切换事件后的回报，作为 Expert₁ 的比例：

q = E[Ḡpost]{Expert_q} / E[Ḡpost]{Expert₁}，（公式 3）

其中 Ḡ_post 是跟随具有切换事件的回合的上下文内回合的平均回报。我们在 q = 1 和 q ≈ 0.5 收集历史并在两者上训练，因此学生看到强专家和弱专家。较弱的专家是同一控制器的较早检查点，或者在 DarkRoom 中，Expert₁ 以选定的速率混合随机动作以给出 q ≈ 0.5。较强的专家也是更安全的专家。在动态预算历史中，其违约率和成本在每个环境中都低于较弱的专家（附录 B）。

4 A-Lag：上下文内对偶适应

A-Lag 是动作级拉格朗日的简称，它用拉格朗日乘子惩罚每个动作的预测成本，并在部署期间更新该乘子。它结合了 Safe AD 序列模型（如 Safe AD 中训练，第 4.1 节）、定义成本重加权策略族的成本头（第 4.2 节）以及部署时从实现成本更新乘子（第 4.3 节）。除了不断增长的上下文外，只有此更新改变训练网络的行为方式。

4.1 序列模型

我们将 Safe ICRL 建模为状态、动作、奖励和成本历史上的因果动作预测。每个完成的转移添加四个位置：状态、动作、奖励和成本。状态、动作、奖励和成本具有不同的输入域，因此单独的编码器 E_s、E_a、E_r 和 E_c 将它们映射到共享嵌入空间，进一步的编码器 E_RTG 和 E_CTG 将两个控制输入映射到同一空间。标量用带符号对数编码：

ψ(z) = sign(z) log(1 + |z|)，（公式 4）

它保留符号和顺序并减少跨环境的尺度差异。设 p = (k, t) 标识回合 k 的步骤 t，其中 Rₚ₊₁ ≐ Rₜ₊₁ᵏ，Cₚ₊₁ ≐ Cₜ₊₁ᵏ。如 Safe AD 中一样，控制输入进入状态位置：

e_{p,s} = E_s(Sₚ) + E_RTG(ψ(RTGₚ)) + E_CTG(ψ(CTGₚ))，e_{p,a} = E_a(Aₚ)，e_{p,r} = E_r(ψ(Rₚ₊₁))，e_{p,c} = E_c(ψ(Cₚ₊₁))。（公式 5）

采样的训练窗口 τ 是来自一个 K 回合历史的这些位置的连续窗口。状态位置在其转移的动作、奖励和成本位置之前，因此在因果掩码下，Aₚ 的预测不能看到该动作或其结果。动作头读取 L 层 Transformer 中步骤 p 状态位置的最后一层表示 uₚ，并定义基础策略 π_θ(·|uₚ)：对于离散动作是具有 logits ℓ(uₚ, ·) 的分类分布，或者对于连续动作是在动作维度 d 中具有均值 μ_d(uₚ) 和方差 v_d(uₚ) 的对角高斯。训练最小化记录动作的负对数似然：

L_act = E_τ[−∑ₚ mₚ log π_θ(Aₚ|uₚ)]，（公式 6）

其中 mₚ 掩码填充位置。这是 Safe AD 的模型和目标。

4.2 成本头和成本重加权策略

第二个头 ĉ(uₚ, ·) 通过其预测的即时成本对每个动作评分，由 c₀ 缩放（公式 8）。对于离散动作，它为每个动作输出一个分数。对于连续动作，它是每个动作维度的二次函数：

ĉ(u, A) = b(u) + ∑_d (g_d(u)A_d + ½κ_d(u)A_d²)，其中 κ_d ≥ 0。

对于乘子 λ，该头定义成本重加权策略：

π_λ(A|uₚ) ∝ π_θ(A|uₚ) exp(−λ ĉ(uₚ, A))。（公式 7）

对于离散动作，重加权的 logits 是 ℓ(uₚ, A) − λ ĉ(uₚ, A)。对于连续动作，成本重加权策略是闭式高斯，维度 d 中的方差为 (v_d⁻¹ + λκ_d)⁻¹，均值为 (v_d⁻¹μ_d − λg_d)/(v_d⁻¹ + λκ_d)。正的 λ 将概率转移到具有低预测成本的动作，且 π₀ = π_θ。

训练。 成本头通过回归拟合到执行动作的缩放即时成本，为此损失保持策略表示固定：

L_cost = E_τ[∑ₚ mₚ (ĉ(sg(uₚ), Aₚ) − Cₚ₊₁/c₀)²]，（公式 8）

其中 sg 阻止成本损失梯度进入主干，c₀ > 0 是环境训练数据中即时成本的标准差。我们在整个训练中以 λ = 0 最小化 L_act + η_C L_cost。成本损失训练成本头，而动作损失训练主干和动作头。

4.3 上下文内对偶适应

在预算为 B₀ 的 K 个回合的部署中，A-Lag 为每个回合 k 保持一个乘子 λₖ。它从 λ₁ = 0 开始，在回合 k 之后从该回合的实现成本更新：

λₖ₊₁ = Π_0,λ_max，（公式 9）

其中 η > 0 是步长，B_max 是环境预算范围的上端（第 3.1 节），用作固定尺度，Π 是到 [0, λ_max] 上的投影。在回合 k 内，每个动作从 π_λₖ(·|uₚ) 采样。上下文和 RTG 及 CTG 输入与 Safe AD 的相同，λ 在下一次部署中重新从零开始。高于预算的回合成本提高 λ 并使下一个回合更加保守。低于它的成本再次降低 λ，最多降到 0，此时 A-Lag 作为其基础策略行动。

公式 (9) 具有回合约束 E[G꜀(τₖ)] ≤ B₀ 的拉格朗日函数上的投影对偶次梯度上升的形式，以实现的回合成本作为约束值的单样本估计。拉格朗日安全强化学习在训练期间对其乘子应用此更新。A-Lag 在蒸馏策略的单次测试部署期间使用它，从智能体产生的成本调整乘子，无需重新训练，也无需为每个任务选择 λ。只有上界 λ_max 是按环境设置的，事先通过固定规则在训练任务上设置。步长以 λ_max 为单位，在每个环境中都相同（附录 E）。

4.4 性质

对于固定表示 u，设 Z_λ = E[A~π_θ][exp(−λĉ(u, A))] 为 π_λ 的归一化因子。对于每个 λ ≥ 0 它是有限的，无论对于有限动作集还是高斯情况。对于每个 λ ≥ 0，π_λ 是在具有有限目标的动作分布 π 上 KL(π‖π_θ(·|u)) + λ E[A~π][ĉ(u, A)] 的唯一最小化者，因为该目标等于 KL(π‖π_λ) − log Z_λ。对于 λ ≥ 0，成本重加权策略是 KL 正则化拉格朗日松弛的解，其中 λ 惩罚预测成本，蒸馏策略扮演无约束策略的角色。下一个命题表明提高乘子永远不会提高预期预测成本。

命题 1（单调预测成本）。 假设上下文中的历史是固定的，因此 uₚ 不变。那么对于每个 λ ≥ 0：

d/dλ E[A~π_λ][ĉ(uₚ, A)] = −VarA~π_λ ≤ 0。（公式 10）

附录 F 给出证明和上述 KL 特征的推导。根据公式 (9)，成本高于预算 B₀ 的回合不会降低 λ，根据命题 1，在每个固定历史处，下一个回合的每步预期预测成本随后不会增加。低于预算的回合不会提高 λ，因此预期预测成本不会降低。这仅在上下文固定时对预测成本成立。它并不意味着实际回合成本随着 λ 增长而下降，因为不同的动作导致不同的上下文，它也不保证满足预算。成本头仅预测下一步的成本，因此它无法预测后续成本。

5 实验

我们提出三个问题。RQ1：动态预算（使教师数据覆盖更多样化的回报和预算输入）是否比固定预算提高测试回报和成本？RQ2：A-Lag 是否在未见测试任务上改进 Safe AD 的回报和成本，CDT 如何比较？RQ3：每种方法超出其预算的频率和程度如何？

5.1 实验设置

我们使用源自 Moeini 等人（2026）的 Safe ICRL 基准的五个环境。每个环境都有单独的训练和测试任务。附录 A 给出布局和分割大小。

  • DarkRoom 是一个具有隐藏目标和隐藏障碍物的部分可观察网格世界。训练目标和障碍物是中心导向的，而测试目标和障碍物是边缘导向的。
  • PointGoal 和 CarGoal 是具有损坏激光雷达的连续导航任务，因此智能体在到达或触碰之前无法感知目标或危险。它们的训练布局是中心导向的，测试布局是边缘导向的。
  • HalfCheetahVelocity 和 AntVelocity（下文称 HalfCheetah 和 Ant 或速度任务）是运动任务，其中在隐藏速度限制之上产生成本，该限制因任务而异。测试速度限制是未见的。

模型。 Safe AD 和 A-Lag 都使用第 4.1 节的主干从头训练。除非另有说明，这里的 Safe AD 是在教师数据上训练的，而不是 PPO-Lagrangian 历史。主要模型每个任务使用 32 个历史。我们报告 50% 混合。A-Lag 添加成本头和部署时更新。CDT 是一个以 RTG 和 CTG 为条件的离线安全强化学习序列策略。所有模型训练 100,000 次更新，使用三个随机种子和相同的每环境架构。我们还展示了初步研究中的两个安全元强化学习基线：带成本惩罚的 MAML 和 SafeMeta，它们通过在每个新任务上更新策略参数来适应。我们不与 SCARED 或潜在 Q 屏蔽比较，因为它们是在线预训练的，在训练环境下根据自己的目标进行交互。Safe AD 和 A-Lag 而是从固定的教师历史离线学习，我们的问题是数据和部署时乘子对 AD 本身的作用。

评估。 部署在固定参数下运行一个测试任务 K 个回合，同时上下文增长。历史在部署内的回合重置之间保留，在部署之间清除。K 在 DarkRoom 中为 50，在 PointGoal 和 CarGoal 中为 20，在速度任务中为 10。每次部署从训练数据固定的两个值之间均匀采样其初始 RTG——训练任务上教师最佳上下文内回合回报的最低值和中值——其预算 B₀ 在训练预算范围内均匀采样。两者在部署内保持固定。每个测试任务接受 15 次部署，所有方法共享这些抽取。我们报告四个量，在抽取、任务和种子上平均。最终回报是最后三个回合的平均回报。在 PointGoal 和 CarGoal 中奖励是稀疏的。回合回报在到达目标时为 1，否则为 0，因此那里的回报是成功率。成本是所有 K 个回合的平均回合成本 G꜀。违约率是这些回合中成本超过 B₀ 的比例，超额成本是它们的 max(0, G꜀ − B₀) 的平均值。每个曲线点是该回合在所有部署、测试任务和种子上的平均值，因此它汇集了不同预算的部署。表条目在回合上平均这些。图中的阴影带显示部署上的 ±2 标准误。文本比较在相同种子和部署抽取上配对方法。正文比较描述观察到的均值。附录 I 给出每个种子的结果和测试任务的区间。

调整 A-Lag。 我们从训练任务上固定乘子的扫描中按环境设置 λ_max（图 6）。它是平均最终回报保持在 λ = 0 时的 75% 以上的最大测试值。步长 η = λ_max 在 DarkRoom 中选择一次并在每个环境中使用（附录 E）。主要比较是测试任务上 A-Lag 与 Safe AD 的比较。在任何环境中，A-Lag 都没有同时具有更低的平均违约率和更高的平均最终回报（表 6）。

5.2 RQ1：教师数据中的固定与动态预算

我们在固定预算历史上训练 Safe AD 和 A-Lag，其中 B₀ = B_max，并将它们与在动态预算历史上训练的主要模型进行比较。两者使用相同的训练设置，因此两者仅在数据上不同。

为什么覆盖重要。 Safe AD 和 A-Lag 从历史和两个控制输入（尚未达到的回报 RTG 和剩余预算 CTG）中选择每个动作。每次部署采样一个新预算，剩余预算随着成本产生而下降，因此在测试时模型看到许多 (RTG, CTG) 对。它最有可能在其训练数据中出现的对上表现良好。在固定预算下，每个回合以剩余预算 B_max 开始，小剩余预算仅在成本产生后出现。表 1 测量两种历史的多样性，附录 D 中的图 5 显示它们的步骤落在哪里。更多占据的单元格意味着历史到达更多 (RTG, CTG) 对，更高的熵意味着它们的步骤在这些对上更均匀地分布而不是集中在少数几个。在 RTG 和 CTG 上的 20×20 网格上，动态预算步骤在 DarkRoom 和速度任务中占据所有 400 个单元格，而固定预算步骤在 DarkRoom 中占据 179 个。动态预算历史在所有五个环境中也具有更高的熵。

5.4 RQ3：预算违约

先前的 Safe ICRL 工作通过平均回合成本评估安全性。这还不够，因为部署之间的预算不同，因此低平均成本仍然可能隐藏频繁或大的预算违约。例如，在 HalfCheetah 中，A-Lag 的平均成本低于 Safe AD 但更频繁地超出其预算（表 6）。因此，我们还报告方法超出其预算的频率和程度。图 3 显示每种方法在部署期间超出其预算的频率和程度。A-Lag 的违约率和超额成本在每个环境中在第一个回合后下降。在 Ant 中，Safe AD 的违约率在第二个回合下降但在其余回合中再次上升，而 A-Lag 的保持较低。

A-Lag 在 DarkRoom、PointGoal、CarGoal 和 Ant 中的平均违约率低于 Safe AD。DarkRoom、CarGoal 和 Ant 中的减少分别为 0.049、0.043 和 0.172，但正如 RQ2 所示，它在那里也返回较少。在 PointGoal 中，A-Lag 和 Safe AD 的平均违约率分别为 0.137 和 0.139。在 HalfCheetah 中，A-Lag 更频繁地违约。

与 λ = 0（附录 H）相比，乘子在所有五个环境中降低平均违约率。最小的平均减少在 PointGoal 中。在 HalfCheetah 中，λ = 0 的 A-Lag 已经比 Safe AD 更频繁地违约，乘子减少了它。

为什么违约率和超额成本不一致。 超额成本是违约率乘以违约回合超出其预算的平均量：

E[max(0, G꜀ − B₀)] = Pr(G꜀ > B₀) E[G꜀ − B₀ | G꜀ > B₀]。（公式 11）

因此，一种方法可以比另一种更少超出其预算但仍然具有相同的超额成本，如果它每次超出预算更多，反之亦然。在 Ant 中，A-Lag 的违约率为 0.184，约为 Safe AD 的 0.356 的一半，但两者的超额成本都约为 2.2，因为违约的 A-Lag 回合平均超出其预算约 12，而 Safe AD 为 6。乘子对此有贡献，因为与 λ = 0 相比，它将违约率从 0.210 降低到 0.184，但将超额成本从 1.56 提高到 2.23。HalfCheetah 则相反。A-Lag 比 Safe AD 更频繁地超出预算，0.158 对 0.123，但每次约 13 对 20，因此其超额成本低 0.47。在其他三个环境中，两个测量值朝相同方向移动。

在 DarkRoom 中，CDT 没有找到目标，三种方法中违约最少，0.108，其超额成本 0.43 位于 A-Lag 的 0.39 和 Safe AD 的 0.60 之间。在导航任务中，CDT 比 Safe AD 更频繁地超出预算，0.195 和 0.270 对 0.139 和 0.207，超额成本更高，8.5 和 9.5 对 4.2 和 5.8。在速度任务中，它也更频繁地违约，0.239 和 0.364 对 0.123 和 0.356，其超额成本为 20.2 和 40.5，而 Safe AD 为 2.5 和 2.2。

6 相关工作

上下文内强化学习。 在不更新参数的情况下适应新任务源于循环元强化学习。现代 ICRL 而是预训练固定序列策略以通过其交互历史改进。算法蒸馏从完整的强化学习学习历史中学习，而监督预训练方法从预训练策略或动作标签学习，决策重要性 Transformer 通过学习到的优势加权模仿损失，使其能够从次优历史中学习。后来的工作涵盖多任务智能体、各种动作空间和上下文内 Q 学习，理论研究何时 Transformer 在上下文中学习。最近的分析将时序差分策略评估与特定的 Transformer 构造联系起来，包括 softmax 注意力和线性 Transformer 的思维链生成。这些工作主要研究奖励最大化。

安全强化学习。 安全强化学习通常使用 CMDP 在期望成本约束下最大化奖励。策略优化、安全探索和运行时屏蔽在线更新策略或模型，或过滤动作，而不是将适应算法蒸馏到上下文中。离线序列策略，包括 CDT 和安全条件变体，以回报和成本为条件，但不针对对未见 CMDP 的重复上下文适应。其他工作处理已知任务内的变化预算，通过以成本阈值为条件的一个策略或从离线数据推断部署时设置的预算的轨迹。

安全上下文内和元强化学习。 安全元强化学习通过梯度更新或额外的特定任务数据适应受约束任务。Safe ICRL 而是保持参数固定。SCARED 形式化此设置并使用预算敏感的拉格朗日预训练。最近，潜在 Q 屏蔽添加了显式的部署时过滤器，使用预测的未来成本重新加权来自冻结 Safe ICRL 策略的动作。A-Lag 也在部署时行动，但它仅惩罚预测的即时成本，每次部署一个乘子从实现的回合成本更新。

7 结论

我们用预算感知教师和 A-Lag（部署时拉格朗日乘子）重新审视了 AD 蒸馏的历史和蒸馏策略使用预算的方式。A-Lag 在所有五个环境中的平均成本低于 Safe AD，其中四个的平均最终回报较低。与固定乘子相比，自适应乘子在四个环境中平均成本较低，但在 Ant 中成本和回报较高。数据收集期间的动态预算在每个环境中给出了回报和预算输入的更高占据熵，并且在 DarkRoom 中改善了回报和违约率。与先前报告平均回合成本的 Safe ICRL 评估不同，我们还报告每种方法超出其预算的频率和程度。在 HalfCheetah 中，A-Lag 的平均成本低于 Safe AD 但更频繁地超出其预算，在 Ant 和 HalfCheetah 中违约率和超额成本不一致，因此两者都应报告。我们的研究有局限性。成本头仅预测即时成本，并且仅从教师采取的动作中学习。教师还需要特定于环境的搜索、专家和切换事件。

附录 A 环境和任务分割

在每个环境中，任务被分为训练集和测试集。遵循 Moeini 等人（2026），布局以密度 ∝ exp(α d(x,c)) 采样，其中 d(x,c) 是距网格或竞技场中心的距离。负 α 偏爱中心，正 α 偏爱边缘。

  • DarkRoom 是一个部分可观察的 13×13 网格，有一个隐藏目标和 50 个隐藏障碍物，智能体从中心开始。训练使用 103 个目标，每个有三个障碍物图，目标和障碍物以 α = −0.5 绘制（中心导向）。测试集有 32 个其他目标，没有一个是训练目标，每个配对一个新的障碍物图。测试目标和障碍物从边缘导向分布中抽取。
  • PointGoal 和 CarGoal 是具有损坏激光雷达的连续导航任务，因此智能体在到达或触碰之前无法感知目标或危险。目标和危险都以这种密度放置。训练使用 128 个中心导向布局，α = −0.2。测试集有 30 个边缘导向布局，α = +0.2，将目标和危险放在训练中罕见的地方。
  • 在 HalfCheetah 和 Ant 中，隐藏速度限制是 Safety-Gymnasium 的默认速度阈值乘以 [0.5, 2.0] 中的因子。训练使用 64 个因子，测试集使用 30 个其他因子。

DarkRoom。
- 切换事件：第一个奖励。其位置是目标。
- 搜索：在每个单元格，教师以概率 0.1 + 0.9 min(B/B_max, 1) 尝试它尚未尝试的移动，否则等待。连续两次等待后它必须尝试移动。产生成本的移动永远不会再次尝试。当其单元格没有未尝试的移动时，它沿着最短已知路径走到有移动的最近单元格。
- 专家：它沿着到目标的最短已知路径行走（没有观察到成本），然后停留在目标上。

PointGoal 和 CarGoal。
- 切换事件：第一个奖励。其位置给出目标。
- 规划器：0.1 米网格上的最短路径规划器，具有 8 连通移动。路径的成本是其长度加上进入距观察到成本的位置 0.25 米内的每个单元格的惩罚。当 B < B₀/2 时惩罚为 1000，否则为 0.3。没有观察到成本的地面没有惩罚，因此教师仅在相同 K 个上下文内回合中在那里付出成本后才避开危险。没有剩余预算时，机器人只离开已知成本的地面然后站立不动。
- 搜索：规划器驶向竞技场上 0.5 米网格的最近未访问点。当 B < B₀/2 时，它跳过观察到成本 0.35 米内的网格点。
- 专家：规划器驶向估计的目标，即有奖励步骤的平均位置。
- 控制：PPO 航点控制器驶向规划路径前方 0.6 米的点。

HalfCheetah 和 Ant。
- 切换事件：第一个成本，意味着机器人跑得比隐藏阈值快。这仅限制阈值，专家继续缩小它。
- 搜索：第一速度从每个历史的 [0.8, 1.2] 米/秒或 [0.5, 0.8] 米/秒中抽取。每 25 步，教师将指令速度提高约 0.5 米/秒或 0.35 米/秒，只要 B 覆盖另一次探测。在第一个成本时，它返回到最后的无成本速度。
- 专家：它指令它观察到成本的最慢速度，只要 B 覆盖该速度的每步成本，否则它保持无成本的最快速度。当回合开始时剩余足够预算时，它首先在这两个速度之间的中点花费 25 步，这缩小它们之间的差距。
- 两个阶段的规则：每个回合以迄今为止发现的最快无成本速度开始 25 步。探测需要至少 1 加上速度下降后减速时付出的成本的运行估计（初始为 1）的储备。命令更改后前 10 步的成本不归因于新命令。如果成本出现在被认为安全的速度上，该速度降低半步。
- 控制：PPO 速度控制器跟踪指令速度。

PPO 控制器。 每个控制器是具有两个 128 单元隐藏层的 PPO 策略。训练在 PointGoal、CarGoal、HalfCheetah 和 Ant 中分别需要 6M、8M、20M 和 30M 步，每 10% 的训练保存一个检查点。不使用环境自身的奖励和成本。PointGoal 和 CarGoal 的航点控制器看到机器人的加速度计、速度计、陀螺仪和磁力计（CarGoal 还有其后轮传感器）以及目标相对于机器人的位置。它们在竞技场上均匀抽取的至少 0.6 米远的目标上训练，因朝向目标的进展而获得奖励，到达目标有额外奖励。HalfCheetah 和 Ant 的速度控制器看到环境观察和目标速度。它们在 [0.5, 7] 米/秒和 [0.25, 5.5] 米/秒的目标速度上训练，并因跟踪它们而获得奖励。

附录 C 训练细节

基线。 序列模型共享表 4 中的主干和相同的标记化，每步四个标记用于状态、动作、奖励和成本。Safe AD 和 A-Lag 在每一步将 RTG 和 CTG 嵌入添加到状态标记。A-Lag 还有成本头，它仅通过部署时乘子改变动作。在我们的 CDT 实现中，RTG 和 CTG 由上下文级前缀标记携带而不是每步。这与原始 CDT 不同，后者在每一步以回报和成本为条件，CDT 使用与 Safe AD 和 A-Lag 相同的训练设置而不是单独调整的设置。RQ1 的固定预算模型仅在训练数据上与主要模型不同。两个基于梯度的安全元强化学习基线（带成本惩罚的 MAML 和 SafeMeta）在每个评估任务上调整策略参数，因此不共享任何此主干。它们保持初步研究的设置（表 4 底部）。

A-Lag 实现。 成本头是状态位置表示 uₚ 上的一个线性层。对于离散动作，它为每个动作输出一个分数。对于连续动作，它输出 b、g_d 和每个动作维度的原始曲率，κ_d 是原始值的 softplus。初始化时 b = g_d = 0，κ_d = 10⁻³，因此重加权策略开始时接近基础策略。损失权重 η_C = 1 在每个环境中。第 4.2 节的重加权高斯是采样动作在任何裁剪到动作范围之前的分布，命题 1 涉及该分布。在回合内，RTG 和 CTG 输入随着收到的奖励和产生的成本而下降，CTG 不低于零，两者在下个回合重新从其部署值开始。

附录 F A-Lag 性质的证明

本附录证明第 4.4 节的陈述。上下文始终固定，因此 u = uₚ 不变。我们将 ĉ(a) 写为 ĉ(u, a)，π_θ(a) 写为 π_θ(a|u)，因此 π_λ(a) = π_θ(a) e^(−λĉ(a)) / Z_λ，其中 Z_λ = E[π_θ][e^(−λĉ)]。最后一段表明下面使用的每个期望都是有限的。

KL 特征。 由于 log π_λ(a) = log π_θ(a) − λĉ(a) − log Z_λ，每个具有有限目标的动作分布 π 满足 KL(π‖π_θ) + λE_π[ĉ] = E[A~π][log(π(A)/π_θ(A)) + λĉ(A)] = E[A~π][log(π(A)/π_λ(A))] − log Z_λ = KL(π‖π_λ) − log Z_λ。项 log Z_λ 不依赖于 π，且 KL(π‖π_λ) ≥ 0，仅当 π = π_λ 时相等。因此 π_λ 是唯一最小化者。

命题 1 的证明。 设 N_λ = E[π_θ][ĉ e^(−λĉ)] 和 M_λ = E[π_θ][ĉ² e^(−λĉ)]。那么 E[π_λ][ĉ] = N_λ/Z_λ 且 E[π_λ][ĉ²] = M_λ/Z_λ。在下一段证明的条件下对期望求导，给出 Z_λ′ = −N_λ 和 N_λ′ = −M_λ。对 N_λ/Z_λ 求导给出：

d/dλ E[π_λ][ĉ] = (N_λ′Z_λ − N_λZ_λ′)/Z_λ² = −M_λ/Z_λ + (N_λ/Z_λ)² = −E[π_λ][ĉ²] + (E[π_λ][ĉ])² = −Varπ_λ ≤ 0。

交换导数和期望。 对于有限动作集，每个期望是有限和，交换是直接的。在高斯情况下，π_θ 是对角高斯，ĉ(a) = b + ∑_d (g_d a_d + ½κ_d a_d²)，其中 κ_d ≥ 0（第 4.2 节）。固定 Λ > 0。对于 λ ∈ [0, Λ]，我们有 e^(−λĉ(a)) ≤ 1 + e^(−Λĉ(a))，因为当 ĉ(a) ≥ 0 时左边至多为 1，当 ĉ(a) < 0 时至多为 e^(−Λĉ(a))。由于 κ_d ≥ 0，e^(−Λĉ(a)) ≤ e^(−Λb−Λ∑_d g_d…)（后续推导表明该上界可积，从而由控制收敛定理保证导数与期望的交换合法，所有涉及的期望均为有限。）
