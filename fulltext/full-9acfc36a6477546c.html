摘要

分支定界（B&B）与A是分别源自运筹学与人工智能的两种流行精确搜索方法。尽管两种方法共享基本的搜索原理，但它们探索搜索空间的不同方式可能导致截然不同的计算性能。我们以资源受限项目调度问题（RCPSP）作为示例问题背景来研究这些差异。我们首先建立了混合整数线性规划、状态-动作与时间Petri网表示之间的关系。由于B&B和A可容纳大量算法增强，我们专注于相对基础的实现。这使我们能够考察方法之间的根本差异，而非比较最先进求解器的性能。通过使用相同的下界和最佳优先节点选择，我们分离了搜索机制的影响，特别是对经由不同调度决策序列到达的等价状态的识别。在480个基准RCPSP实例上的实验表明，基于图的A显著优于所考虑的B&B变体。借助附加剪枝规则，A证明了全部480个实例的最优性，而在相同时间和内存限制下最佳优先B&B仅为445个。深度优先B&B使用更少内存，且即使搜索未在时限内完成也能找到可行解。更强的线性规划松弛缩小了搜索空间，但引入了相当大的计算开销。我们的发现突出了重复状态检测的重要性，并阐明了两种搜索方法之间的计算权衡。这些见解可帮助研究人员选择合适的方法，并识别将一种方法的有效机制融入另一种方法的机会。

关键词：调度；项目管理；分支定界；A*；人工智能

1 引言

资源受限项目调度问题（RCPSP）寻求一个在遵守活动间相互依赖关系和资源限制的同时最小化项目完工时间的调度方案（最新综述参见Artigues等，2026）。该问题本身及其扩展模拟了建筑（参见Zhang等，2024）、制造（参见Čapek等，2012）、维护（参见Chen等，2024）、医疗保健（参见Yousefzadeh和Harati Motlagh，2026）、软件开发（参见Li等，2024）以及其他基于项目的环境中的常见挑战——在这些环境中，本可并行执行的活动必须竞争稀缺资源。由于即使是中等规模的实例也难以最优求解，RCPSP既是一个重要的实际调度问题，也是精确优化方法的重要基准。

两个成熟的研究传统从不同视角处理该问题（详见第2节）。在运筹学（OR）中，精确方法通常使用分支定界（B&B）探索受限子问题或部分调度构成的树。下界用于剔除无法改进当前已找到的最佳完整调度的子问题。在人工智能（AI）中，该问题则可表示为状态空间图，并使用A求解；A依据可采纳的评估函数以最佳优先顺序扩展状态，并合并经由不同决策序列到达的等价状态。在足够抽象的层面上，A可以被纳入B&B的一般性表述之中（Nau等，1984）。然而，这一理论关系并不能解释当应用于同一调度问题时，OR与AI中实际使用的算法有何具体差异。在实践中，普通型B&B（参见Nau等，1984中的ordinary B&B）探索由部分调度隐式定义的可行解子集构成的树，而基于图的A则系统地搜索图，检测并合并经由不同决策序列到达的重复状态。B&B还可利用迄今找到的最佳可行解来剪枝节点。现有比较往往受到问题表示、下界强度、节点选择策略或算法特定增强措施差异的影响。因此，观察到的性能差异中有多少源自搜索机制本身仍不清楚。

本研究旨在解释这两种广泛使用的精确搜索范式之间的根本计算权衡，并为选择、改进或组合它们提供依据。因此，其目的并非判定任一方法的基础实现是否优于最先进的RCPSP求解器。相反，我们的贡献有三方面。第一，我们通过给出RCPSP的混合整数线性规划（MILP）、状态-动作与时间Petri网表示，并建立它们的调度、状态与搜索图之间的关系，为比较构建了共同的建模基础。第二，我们在相同的下界信息和最佳优先节点选择下，对B&B与A*进行了机制性与形式化的比较。该分析确定了重复状态、剪枝、重复的启发式评估以及内存需求如何影响两种搜索。最后，我们在基准RCPSP实例上进行了受控实证研究，比较计算时间、生成与扩展的节点数、下界评估次数和内存使用。实验考察了实例特征与搜索机制如何影响两种方法的相对性能。

本文其余部分组织如下。第2节回顾相关文献并指出本研究 addressed 的空白。第3节定义RCPSP并引入贯穿全文的运行示例。第4节给出MILP、状态-动作与时间Petri网表示并建立它们的联系。第5节描述B&B与A*算法并比较其搜索机制。第6节报告实证研究。最后，第7节总结全文并讨论未来研究方向。

2 相关文献

本节回顾三个相关研究流派：RCPSP的B&B方法（第2.1节）、面向调度的启发式状态空间搜索（第2.2节），以及B&B与A关系的理论研究（第2.3节）。这些流派共同定位了我们关于基于优化的B&B与基于图的A的比较（第2.4节）。

2.1 RCPSP的分支定界方法

OR中的精确RCPSP求解方法主要集中于MILP和专门的B&B算法。早期精确方法由Patterson（1984）进行了比较。后续的B&B算法引入了延迟替代方案、调度方案、内存高效枚举和约束传播（Demeulemeester和Herroelen，1992；Brucker等，1998；Sprecher，2000；Dorndorf等，2000）。其性能取决于分支方案、下界、支配规则、节点选择策略以及良好可行调度的早期发现（Brucker和Knust，2003；Coelho和Vanhoucke，2018；Guo等，2023）。与此同时，MILP公式从经典的时间索引模型（Pritsker等，1969）发展到基于事件的公式（Koné等，2011）。综述文献记录了这些方法的持续发展（Brucker等，1999；Artigues等，2026）。

在这种OR解释中，B&B是一个优化框架。搜索树中的每个节点表示可行调度的一个子集，由部分调度或受限的优化子问题编码。分支决策将该子集划分为更小的子集。有效的下界（通常但不必然由松弛获得）限定节点内可达到的最佳调度，而迄今找到的最佳完整调度提供上界。若节点不可行，或其下界不小于上界，则该节点可被丢弃。节点选择是灵活的，可采用深度优先、最佳优先、广度优先或混合策略。经由不同决策序列到达的等价节点不会被系统地合并，尽管针对具体问题的支配规则可能消除部分此类冗余。

2.2 面向调度的状态空间搜索

在A中，节点依据 f̂ = g + h 进行选择，其中g为迄今累积的成本，h为剩余成本的可采纳下界（Hart等，1968）。正如最初定义的那样，A执行图搜索：其Open和Closed结构可检测某状态何时经由另一条路径被重新生成，且仅保留通往每个状态的最廉价路径。

该机制的效果取决于状态表示。相比之下，普通B&B可能将相应的决策序列保留为不同节点，除非某支配规则识别出它们的等价性。

时间Petri网长期以来被用于建模调度问题，包括作业车间系统（Hillion和Proth，1989）、制造系统（Proth和Sauer，1998；Lee和DiCesare，1994；Mejía和Odrey，2005）以及数据驱动的项目规划（Cohen，2024）。通过可达图搜索进行调度，尤其是使用A*，是该文献流派中的成熟方法（Lee和DiCesare，1994；Huang等，2023）。

Bell和Park（1990）为RCPSP开发了一种基于A的精确算法。其节点是通过添加优先约束以解决资源冲突而得到的子问题，因此经由不同修复序列到达的等价项目状态从未被识别。相应地，Nazareth等（1999）后来将该方法解释为表述为A树搜索的最佳优先B&B过程。最近，Lublin等（2026）将RCPSP表述为Petri网可达图上的最优搜索，并表明基于图的A可与通用MILP求解器竞争。该比较展示了A的潜力，但并未在相同的下界信息和搜索条件下分离A*与B&B之间的算法差异。

2.3 B&B与A*之间的关系

早期研究将B&B与动态规划和状态空间表示相关联（Morin和Marsten，1976；Ibaraki，1978），而Kumar和Kanal（1983）提出了面向AND/OR树搜索的广义B&B表述。Nau等（1984）引入了广义分支定界（GBB），通过抽象的表示、目标、选择、分裂与剪枝函数加以定义。这些函数足够一般，使普通B&B和A均可表示为特例。我们认为，这一共同抽象不应被理解为表明基于图的A与普通优化型B&B是相同的实用算法。用Nau等（1984）的术语来说，普通B&B每次选择一个活动子问题，并利用下界和由迄今最佳解给出的上界进行剪枝。A则通过表示、选择规则和剪枝函数的不同选择嵌入GBB之中。类似地，Labat和Pomerol（2003）得出结论：启发式搜索与B&B应用相同的原理，主要区别在于B&B抽象视图中的解释层面。因此，AI文献是在高度一般的搜索抽象中比较这些方法，而非将RCPSP研究中实际使用的基于优化的B&B与基于图的A进行比较。

2.4 研究空白

综合来看，现有文献尚未针对RCPSP提供对这两种搜索范式的受控、实用性比较。可采纳的A启发式与B&B下界服务于相同的数学目的，且可由同一松弛计算得到。因此，比较两种方法时应控制界的强度差异。据我们所知，尚无研究在下界函数和节点选择条件固定的前提下，在相同的RCPSP实例上比较普通OR风格B&B与基于图的A。本文填补了这一空白，并分离了B&B中基于树的枚举与上界剪枝同基于图的A*中系统性重复状态检测各自带来的后果。

3 资源受限项目调度问题

项目由必须在优先关系和有限资源约束下执行的活动组成。在RCPSP中，目标是选择活动开始时间，在满足所有优先和资源约束的同时最小化完工时间。本节给出形式化问题定义（第3.1节），并引入贯穿全文的运行示例（第3.2节）。

3.1 形式化定义

设 𝒱 表示不可抢占活动的集合，d_i ∈ ℕ₀ = {0,1,2,…} 表示活动 i ∈ 𝒱 的工期。设 ℛ 为可更新资源的集合，每种资源 k ∈ ℛ 的容量为 R_k。此外，设 ℰ ⊂ 𝒱 × 𝒱 为所有直接优先关系的集合，即当活动 i 的完成是活动 j 开始的直接前提时， ∈ ℰ。对每个活动 i ∈ 𝒱，定义 Pred(i) = {j ∈ 𝒱 : (j,i) ∈ ℰ}，Suc(i) = {j ∈ 𝒱 : (i,j) ∈ ℰ}。Pred(i) 与 Suc(i) 中的元素分别为 i 的直接前驱和直接后继。

不失一般性，假设项目的唯一起点（无前驱）为活动 0，唯一终点（无后继）为活动 n，其中 0, n ∈ 𝒱 且 d₀ = d_n = 0。我们将活动 0 和 n 称为虚活动。对任何其他活动 i，假设 d_i > 0。活动 i ∈ 𝒱 对资源 k ∈ ℛ 的需求记为 r_ik，其中对所有 k ∈ ℛ 有 r₀k = r_nk = 0；活动 i ∈ 𝒱 的开始时间记为 S_i。我们假设 (𝒱, ℰ) 无环，且对所有 i ∈ 𝒱 和 k ∈ ℛ 有 0 ≤ r_ik ≤ R_k。

对每个时刻 t ∈ ℕ₀，设 𝒜(t) ⊆ 𝒱 表示在时刻 t 正在进行的活动集合，即当 S_i ≤ t < S_i + d_i 时 i ∈ 𝒜(t)。调度 S = {S_i}_{i∈𝒱} 是对所有活动开始时间的指派。若调度满足所有优先约束，且在任一时刻正在执行的活动的资源需求均不超过可用资源量，则该调度可行。若可行调度的完工时间（由 S_n 给出）在所有可行调度中最小，则该调度为最优。

等价地，RCPSP可表述为如下优化问题：

min_S S_n　　(1a)
s.t. S_i + d_i ≤ S_j, ∀(i,j) ∈ ℰ,　　(1b)
Σ_{i∈𝒜(t)} r_ik ≤ R_k, ∀k ∈ ℛ, t ∈ ℕ₀,　　(1c)
S_i ∈ ℕ₀, ∀i ∈ 𝒱.　　(1d)

若不存在可行调度 S′ ≠ S 使得每个活动的开始都不晚于 S 中相应活动，且至少一个活动严格提前，则可行调度 S 称为活动调度（active）；即不存在可行调度 S′ 和活动 j ∈ 𝒱 使得 S′_i ≤ S_i（∀i ∈ 𝒱）且 S′_j < S_j。等价地，S 无法在不延迟任何其他活动或不违反优先或资源约束的前提下，通过将一个或多个活动提前来改进。由于至少存在一个最优调度是活动调度（Kolisch，1996），聚焦于最早开始调度生成可保持最优性。在下文的搜索表述中，一旦选定某活动，它就在满足优先和资源可行性的前提下，相对于当前状态在最早可行时刻开始。因此，所得状态空间至少包含一条对应于最优活动调度的路径。

我们使用"部分调度"一词指限于已调度活动子集的可行调度。形式上，部分调度是一个二元组 (𝒥, S_𝒥)，其中 𝒥 ⊆ 𝒱 是前驱封闭的，即若 j ∈ 𝒥 且 ∈ ℰ，则 i ∈ 𝒥；S_𝒥 = {S_j}_{j∈𝒥} 为 𝒥 中所有活动指派开始时间。该指派必须满足由 𝒥 中活动引起的所有优先和资源约束。每个部分调度诱导一个带时间的系统状态，记录当前时刻（即最新被调度活动的开始时间）、已完成和正在进行的活动，以及正在进行活动的剩余工期。该状态包含确定未来可行调度决策所需的全部信息。因此，任何诱导相同带时间状态的两个部分调度定义了相同的剩余调度问题。我们的B&B表述搜索部分调度树，而基于图的A*搜索通过合并诱导相同带时间状态的部分调度而得到的相应状态图。因此，两种方法表示相同的底层调度决策，区别仅在于等价的调度历史是作为独立节点保留还是合并为单一状态。

RCPSP在强意义下是NP难的（Blazewicz等，1983），这要求在精确方法中使用有效的定界与剪枝策略。

4 问题表示

RCPSP可从多个计算视角建模。MILP公式（第4.1节）通过决策变量表示完整调度，支持普通OR风格B&B。状态-动作表示（第4.2节）将调度表示为带时间系统状态间的转移，支持A*等图搜索方法。Petri网表示（第4.3节）提供基于令牌的优先关系、时间与可更新资源可用性的显式模型，其带时间可达图与状态图等价。本节介绍三种表述并形式化它们之间的关系（第4.4节）。

4.1 混合整数线性规划表述

RCPSP可通过引入编码调度决策的二进制决策变量表述为MILP。文献中存在多种MILP表述；这里我们给出标准的时间索引表述。

设 H 表示项目持续时间的上界，通常通过将所有活动顺序调度获得，故 H = Σ_{i∈𝒱} d_i；设 𝒯 = {0,1,…,H} 为相应的离散时间范围。

定义二进制变量：

y_it = {1, 若活动 i 在时刻 t 开始；0, 其他}，　　(2)

对所有 i ∈ 𝒱 和 t ∈ 𝒯。

于是，MILP表述如下：

min S_n　　(3a)
s.t. Σ_{t=0}^{H−d_i} y_it = 1, ∀i ∈ 𝒱　　(3b)
S_i = Σ_{t=0}^{H−d_i} t·y_it, ∀i ∈ 𝒱　　(3c)
S_i + d_i ≤ S_j, ∀(i,j) ∈ ℰ　　(3d)
Σ_{i∈𝒱} r_ik Σ_{τ=max{0,t−d_i+1}}^{min{t,H−d_i}} y_iτ ≤ R_k, ∀t ∈ 𝒯, k ∈ ℛ　　(3e)
S_i ∈ ℕ₀, ∀i ∈ 𝒱　　(3f)
y_it ∈ {0,1}, ∀i ∈ 𝒱, t = 0,…,H−d_i　　(3g)

目标(3a)最小化完工时间，即虚活动 n 的开始时间 S_n。约束(3b)确保每个活动恰好开始一次，约束(3c)定义相应的开始时间 S_i。约束(3d)强制优先关系。对固定活动 i 和时段 t，活动 i 在时段 t 正在进行当且仅当它在某时刻 τ 开始且 t−d_i+1 ≤ τ ≤ t。由于开始变量仅对可行开始时刻 τ ∈ {0,…,H−d_i} 定义，(3e)中的内层求和遍历这两个区间的交集，即 τ = max{0,t−d_i+1},…,min{t,H−d_i}。最后，约束(3f)和(3g)对开始时间变量施加整数性、对决策变量施加二值性。

4.2 状态-动作表示

另一种表示将RCPSP视为状态空间中的最短路径问题，其中每个状态编码项目当前的执行状况，而转移（动作）对应调度决策。更具体地，状态 s 刻画特定时间点上的项目状况，记录：

  • 当前系统时间 g(s) ∈ ℕ₀，即状态 s 所代表的观察系统并考虑下一调度决策的时刻；
  • 已完成活动集合 𝒱^c(s) ⊆ 𝒱，即在 g(s) 时刻或之前已完成的活动；
  • 正在进行活动集合 𝒱^o(s) ⊆ 𝒱，即已开始但在 g(s) 时尚未完成的活动，及其相对于 g(s) 的剩余工期 d̃_i(s) ∈ ℕ₀（对所有 i ∈ 𝒱^o(s)），表示当前系统时刻下的剩余加工时间。

尽管 𝒱^o(s) 是集合，但在状态元组中我们将其元素表示为有序元组，活动按固定顺序列出，其相应剩余工期在 d̃(s) 中按相同顺序列出。

𝒱^u(s) = 𝒱 \ (𝒱^c(s) ∪ 𝒱^o(s)) 中的活动称为未开始活动。

我们定义初始状态 s₀，满足 𝒱^c(s₀) = ∅、𝒱^o(s₀) = ∅、g(s₀) = 0，以及完全的资源可用性。此外，定义目标状态集合 𝒮_f 为所有满足 𝒱^c(s) = 𝒱 的状态 s 的集合。时刻 g(s) 的可用资源状况可由正在进行活动所消耗的资源及其容量推得。若状态 s 满足资源约束 Σ_{i∈𝒱^o(s)} r_ik ≤ R_k（对所有 k ∈ ℛ）以及优先约束（即若 j ∈ 𝒱^o(s) 且 ∈ ℰ，则 i ∈ 𝒱^c(s)），则称状态 s 可行。

在每个状态 s，我们可选择下一个被调度的活动，从而导出新状态 s′。状态 s 处可选择的活动集合记为 𝒱^a(s)，由其直接前驱已完成或正在进行的未开始活动组成：

𝒱^a(s) = {i ∈ 𝒱^u(s) : Pred(i) ⊆ 𝒱^c(s) ∪ 𝒱^o(s)}。

因此 𝒱^a(s) ⊆ 𝒱^u(s)。若所选活动的某些前驱仍在进行，或当前可用资源不足，系统时间推进到所选活动可以开始的最早时刻。本文其余部分采用这一最早开始解释。因此，对给定活动 j ∈ 𝒱^a(s)，我们得到：

  • 时间转移：
    g(s′) = min{t : t ≥ g(s)；对所有满足 ∈ ℰ 的 i ∈ 𝒱^o(s)，t ≥ g(s) + d̃i(s)；对所有 k ∈ ℛ，r_jk ≤ R_k − Σ{i∈𝒱^o(s): g(s)+d̃_i(s)>t} r_ik}，　　(4)
    其中 Δ(s,s′) = g(s′) − g(s) 表示转移中流逝的时间。

  • 正在进行活动：
    𝒱^o(s′) = {i ∈ 𝒱^o(s) : Δ(s,s′) < d̃_i(s)} ∪ {{j}, 若 d_j > 0；∅, 若 d_j = 0}。　　(5)

因此，当某活动在转移后具有正的剩余工期时，它在 s′ 中正在进行。先前正在进行活动的剩余工期减少流逝的时间，而新开始的活动 j 若工期为正则获得其完整工期。故对所有 i ∈ 𝒱^o(s′) \ {j}，有 d̃_i(s′) = d̃_i(s) − Δ(s,s′)；若 d_j > 0，则 d̃_j(s′) = d_j。

  • 已完成活动：
    𝒱^c(s′) = 𝒱^c(s) ∪ {i ∈ 𝒱^o(s) : Δ(s,s′) ≥ d̃_i(s)} ∪ {{j}, 若 d_j = 0；∅, 若 d_j > 0}。　　(6)

可达状态空间可表示为有向图 G = (𝒮, 𝔼)，我们称之为状态图，其中 𝒮 是从 s₀ 出发经可行调度决策可达的状态集合，𝔼 是由这些决策诱导的有向边集合。若在状态 s 选择活动 j 依上述转移规则导出后继状态 s′，我们记 s →^j s′。寻找最优调度等价于寻找从初始状态到目标状态的、使目标状态系统时间最小的路径。因此，路径的成本由其最终状态的系统时间度量。这一等价性成立，因为最优调度可按活动开始时间排序，并沿该顺序应用最早开始转移规则来表示。

为说明该记号，考虑运行示例。我们从状态 s₀ 出发。由于 𝒱^a(s₀) = {0}，调度虚活动 0 得到 s₁ = (g(s₁), 𝒱^c(s₁), 𝒱^o(s₁), d̃(s₁)) = (0, {0}, (), ())。在该状态，可选择活动集合为 𝒱^a(s₁) = {a,b,c}。若接下来选择活动 a，搜索移动到 s₂ = (0, {0}, (a), (3))，可选择活动变为 𝒱^a(s₂) = {b,c}。若随后选择活动 b，转移将时间推进到状态 s₅。活动 b 需要两个资源单位，而其中一个当前被活动 a 占用，因此必须等到 a 释放该单位后才能开始。故 g(s₅) = 3 且 s₅ = (3, {0,a}, (b), (2))。相反，若在活动 a 之后选择活动 c，由于资源容量充足，a 和 c 可并行加工，结果状态为 s₆ = (0, {0}, (a,c), (3,3))。

在 a 之前先调度 c 同样到达状态 s₆，这说明了不同调度决策序列可导出相同状态。

4.3 Petri网表示

Petri网可视为具有两类节点（库所与变迁）的有向二部图。Petri网为并发系统建模提供了形式化的数学框架，可刻画同步、优先关系和共享资源（Murata，1989）。我们用它来建模并发的项目活动与资源可用性，并建立其带时间可达图与A*所用状态图之间的形式对应。

库所表示条件、中间项目状态或可用资源；变迁表示活动或事件。有向弧仅连接库所到变迁或变迁到库所，因此两个库所之间或两个变迁之间不存在直接弧。令牌是驻留在库所中的标记，令牌在库所上的分布表示系统当前状态。令牌在网络中的流动自然地表示活动间的同步与并行。Petri网还可表示备选行动方案之间的XOR选择，但本文考虑的RCPSP仅包含AND型优先关系：活动只有在其所有前驱完成后才能开始。因此，我们在Petri网表示中不使用XOR结构。在本比较中，Petri网表示为基于状态的搜索提供了成熟的建模框架，而非应用A*的必要条件。

Petri网支持诸如以下正确性检查：项目的所有活动是否可执行、项目是否总能推进至完成、最终状态中是否无剩余工作。因此，它们提供了远超其他表示能力的验证能力（Murata，1989；van der Aalst和Carmona，2022）。此外，Petri网可用于建模和可视化资源约束。

4.3.1 带资源的时间变迁Petri网

我们将RCPSP建模为所谓带资源的时间变迁Petri网（TTPNR），即元组 TTPNR = (P, T, F, W, M₀, L, τ, ℛ)，其中除第3.1节的定义外，还定义：

  • P = P_C ∪ P_R 为有限的库所集合，绘制为圆形，其中 P_C ∩ P_R = ∅。集合 P_C 包含控制流库所 {p₁, p₂, …, p_m}，表示项目进展；集合 P_R = {p_{r_k} : k ∈ ℛ} 为每种可更新资源包含一个资源库所。资源库所中的令牌表示可用的资源单位。

  • T = {t_i : i ∈ 𝒱} 为有限的变迁集合，绘制为矩形，其中 P ∩ T = ∅。变迁 t_i 表示活动 i。特别地，虚开始和结束活动分别由零工期变迁 t₀ 和 t_n 表示。

  • F ⊆ (P × T) ∪ (T × P) 为有向弧集合，亦称流关系。我们区分控制流弧与资源弧：控制流弧连接控制流库所与变迁，编码项目的优先/进展结构；资源弧连接资源库所与变迁，建模可更新资源单位的使用。对RCPSP而言，控制流结构由连接到 t₀ 的源库所 p_start、从 t_n 连出的汇库所 p_end，以及对每个 ∈ ℰ 连接 t_i 到 t_j 的库所 p_ij 组成。这些是仅有的控制流弧，且初始时只有 p_start 含有令牌。在运行示例（图3和图4）中，这些库所记为 p₁,…,p₁₁。

  • W : F → ℤ⁺ 是为每条弧赋正整数权重的权重函数。对输入弧，W(p,t) 为变迁 t 开始时库所 p 中必须可用的令牌数；对输出弧，W(t,p) 为变迁 t 完成后存入库所 p 的令牌数。在我们的RCPSP模型中，控制流弧权重为一；资源弧权重等于相应活动所需的资源单位数，且活动完成时相同数量的资源令牌归还至资源库所。

  • 标识 M : P → ℕ₀ 指定每个库所中的令牌数，从而编码当前系统状态。特别地，M₀ : P → ℕ₀ 为初始标识。对控制流库所，M₀ 编码初始项目状态；对每个资源库所 p_{r_k} ∈ P_R，M₀(p_{r_k}) = R_k 指定资源 k 的初始可用单位数。在第4.3.2节引入的带时间状态表示中，这种普通标识通过为每个令牌关联剩余可用时间加以细化，定义为从当前系统时刻起直至令牌可用的 时间单位数。库所上令牌的底层分布仍为此处定义的标识。

  • L : T → 𝒱 是为每个变迁赋予相应项目活动的标记函数。由于变迁 t_i 表示活动 i，对所有 i ∈ 𝒱 有 L(t_i) = i。

  • τ : T → ℕ₀ 是指定每个变迁工期的定时函数。由于变迁 t_i 表示活动 i，对所有 i ∈ 𝒱 设 τ(t_i) = d_i。启动（激发）一个变迁意味着消耗所需输入令牌并投入相应活动。当变迁 t_i 激发时，所需输入令牌被消耗，其输出控制流令牌和归还的资源令牌以剩余可用时间 τ(t_i) 与相应库所关联。这些令牌仅在其剩余可用时间降为零后才能使后续变迁可用。

当不存在资源（ℛ = ∅，P_R = ∅）且所有工期为零（对所有 t 有 τ(t) = 0）时，TTPNR退化为标准Petri网；当资源不存在但定时存在时，退化为时间变迁Petri网。

为紧凑起见，我们通常仅列出令牌计数为正的库所来表示标识。因此 [p₁] 表示标识 M 满足 M(p₁) = 1 且对所有 p ≠ p₁ 有 M(p) = 0。更一般地，p^q 表示库所 p 中的 q 个令牌，q = 1 时省略指数。例如 [p₁, p_{r₁}²] 表示控制流库所 p₁ 中一个令牌、资源库所 p_{r₁} 中两个令牌、其余库所零令牌的标识。

库所 p 是变迁 t 的输入库所当且仅当 ∈ F，输出库所当且仅当 ∈ F。我们记 ∙t = {p ∈ P : ∈ F} 和 t∙ = {p ∈ P : ∈ F} 分别为 t 的输入和输出库所集合；类似地，∙p 和 p∙ 表示库所 p 的输入和输出变迁。

变迁 t ∈ T 在标识 M 下使能，若对所有 p ∈ ∙t 有 M(p) ≥ W(p,t)。该条件要求每个输入库所（包括控制流和资源库所）都含有足够多的令牌。

当 t 激发时，它从输入库所消耗令牌并为输出库所产生令牌。相应的结构性标识更新 M′ 由下式给出：

M′(p) = M(p) − {W(p,t), 若 ∈ F；0, 其他} + {W(t,p), 若 ∈ F；0, 其他}，∀p ∈ P。　　(7)

方程(7)描述了库所上令牌分布的结构性变化。然而，在本文采用的带时间解释下，库所中令牌的存在并不必然意味着它立即可用。所产生的控制流令牌和归还的资源令牌的可用性取决于工期 τ(t)。该定时信息被纳入第4.3.2节引入的状态表示。

4.3.2 状态表示与搜索图构建

TTPNR的动态行为可由可达图 RG = (𝒮_RG, 𝔼_RG) 表示。节点集 𝒮_RG 由可达的带时间状态组成，每个节点 s ∈ 𝒮_RG 由当前系统时间 g(s) 和带时间标识 M_s 表示。边集 𝔼_RG 包含由变迁激发诱导的有向边，每条边对应一次变迁激发，即一个调度决策。变迁激发序列称为迹，表示一种可能的项目实现序列。若可选择多个变迁，则每个这样的变迁定义一条不同的后继边。

带时间标识 M_s 细化第4.3.1节定义的普通标识 M : P → ℕ₀：它保持库所上令牌的分布，同时为每个令牌关联剩余可用时间。形式上，设库所 p 在状态 s 的底层普通标识中含 q 个令牌。令 ν_p 表示这些令牌的不同剩余可用时间的个数，θ_{p,1},…,θ_{p,ν_p} 表示这些时间，q_{p,ℓ} 表示剩余可用时间为 θ_{p,ℓ} 的令牌数。p 处的带时间标识表示为 M_s(p) = {q_{p,1}^{θ_{p,1}},…,q_{p,ν_p}^{θ_{p,ν_p}}}，其中 Σ_{ℓ=1}^{ν_p} q_{p,ℓ} = q。

这里 q_{p,ℓ}^{θ_{p,ℓ}} 表示在 θ_{p,ℓ} 个时间单位后可用的 q_{p,ℓ} 个令牌。若 q = 0，则 M_s(p) = ∅。在初始状态 s₀，每个令牌均立即可用。因此，若 M₀(p) = q > 0，则 M_{s₀}(p) = {q⁰}。

为紧凑起见，我们仅列出至少含一个令牌的库所。剩余可用时间相同的令牌被分组，等于零的上标被省略。因此 p:2^θ 表示库所 p 中两个均在 θ 个时间单位后可用的令牌，而 p:1,1³ 表示一个立即可用的令牌和一个在三个时间单位后可用的令牌。特别地，M_{s₀}(p) = {q⁰} 写作 M_{s₀}(p) = {q}。例如，M_s = [p₁:1, p_{r₁}:1,1³] 表示库所 p₁ 中一个立即可用的令牌，以及资源库所 p_{r₁} 中的两个令牌——一个立即可用，一个在三个时间单位后可用。

4.4 表示之间的映射

三种表示——MILP、状态-动作与Petri网——从不同视角描述同一底层RCPSP。MILP表述编码完整调度，而状态-动作与Petri网表示编码中间执行状态及其转移。特别地，状态-动作表示显式记录哪些活动已完成、正在进行或尚未开始，而Petri网表示通过带时间的控制流与资源令牌隐式记录相同信息。

4.4.1 状态-动作表示与Petri网表示之间的映射

5 求解方法

本节描述两种精确求解方法B&B（第5.1节）和A*（第5.2节），并对两种方法进行结构性比较（第5.3节）。我们首先以一般形式给出每种方法，然后将其特化到RCPSP。两种方法均使用最佳可达项目完工时间的下界来引导搜索。在基线比较中，两种方法使用相同的关键路径下界和最佳优先（BF）节点选择规则。该设计控制了下界和搜索顺序的共性，同时保留了区分两种方法的算法特定机制。在第6节中，我们还将考察采用深度优先（DF）搜索以及产生更强下界的线性规划（LP）松弛的B&B变体。

5.1 分支定界

在OR领域，B&B是组合优化问题的精确求解框架，在避免穷举枚举的同时系统地探索解空间。在RCPSP背景下，它自然适用于MILP表示及相应的部分调度。

在B&B中，被探索的解可由有根搜索树表示，其中根节点 N₀ 对应待求解的优化问题（即其目标函数与约束）。B&B搜索树的其他每个节点 N_j 由待求解问题的目标函数、其父节点 N_i 对应问题的约束，以及一个附加属性（通常是约束）隐式定义——N_j 处问题的每个解都必须满足该属性，而 N_i 处问题的解则不必全部如此。因此，搜索树中从根节点 N₀ 到叶节点的路径对应于 N₀ 中的初始问题被沿该路径各分支添加的约束逐步扩展。从而，从节点 N_i 到其子节点 N_j，可行解集合只会缩小，而相应子问题的最佳可达目标值不会改善。因此，B&B依赖于划分解空间（分支）并剔除不可能包含最优解的问题（节点）（定界与剪枝）。整体搜索通常由选择下一评估节点的策略引导。

由于节点的最佳可达目标值一般难以计算，需要在搜索树的节点处计算界。首先，全局上界是 N₀ 中问题某可行解的目标值，随着搜索中找到新的更好可行解，它可被多次改进。其次，在每个节点 N_i 处计算 N_i 中问题的局部下界，即不超过 N_i 中任何可行解可达到的最佳目标函数值的数值。该界的计算例如可通过求解 N_i 中所考虑优化问题的一个可高效求解的松弛（简化）版本来完成。若该界表明在源于 N_i 的相应子树中找不到更好的解，则该节点被丢弃（剪枝、探明）。

5.1.1 最小化问题的一般框架

考虑组合优化问题 min_{x∈𝒳} F(x)，可行解集合为 𝒳，目标函数为 F : 𝒳 → ℝ。假设 𝒳 过大而无法显式枚举，故通过B&B系统探索。根节点 N₀ 表示原始问题，其余节点 N_i 与可行解子集 𝒳(N_i) ⊆ 𝒳 相关联。因此，节点 N_i 的分支对应于将 𝒳(N_i) 划分为更小的不相交子集 𝒳(N_i) = ⋃{j=i+1}^{k} 𝒳(N_j)，其中 N{i+1},…,N_k 为 N_i 的子节点。该划分通常由固定决策变量或施加附加约束诱导。

算法维护全局上界 F̄，对应迄今找到的原始问题最佳可行解的目标值。此外，对每个节点 N_i 计算下界 F̲(N_i) ≤ min_{x∈𝒳(N_i)} F(x)。这些界的质量影响算法效率。

若下列条件之一成立，节点 N_i 被剪枝：

  • F̲(N_i) ≥ F̄，因为 𝒳(N_i) 中没有解能改进当前最佳解；
  • 𝒳(N_i) = ∅，即 N_i 处的子问题不可行；
  • 在 N_i 处求解的松弛产生了原始问题的可行解 x ∈ 𝒳。

节点探索顺序由搜索策略决定，常见策略包括DF搜索和BF搜索。DF搜索在回溯之前完整探索单一分支，旨在快速找到可行解从而获得全局上界；BF搜索则基于尚未探明（活动）节点的下界来选择下一探索节点。

概言之，一般形式的B&B可描述如下：

  1. 以根节点（对应原始问题）初始化活动节点集合。
  2. 设 F̄ := +∞；若预先已知可行解 x⁰，则设 F̄ := F(x⁰)。
  3. 当存在活动节点时：
  4. 依据搜索策略选择节点 N_i。
  5. 计算 F̲(N_i)，例如通过考虑并求解 N_i 中问题的松弛版本。
  6. 若 F̲(N_i) ≥ F̄ 或 N_i 处的问题无可行解，则剪枝 N_i，即从活动节点集合中删除 N_i，继续。
  7. 否则，若 N_i 中问题松弛版本的解 x_i 对原始问题可行，设 F̄ ← min{F̄, F(x_i)}，可能将最佳解更新为 x_i，剪枝 N_i 并继续。
  8. 否则，在 N_i 上分支，即从活动节点集合中删除它并将其子节点加入活动节点集合。

该一般形式B&B的正确性源于：只有不可能包含优于当前已知最佳解的节点才被剪枝。因此，若尚未知晓最优解，最优解永远不会被丢弃。该方法的效率关键取决于界的强度、分支方案和搜索策略的有效性。在最坏情况下，算法仍可能探索整个搜索空间；但在实践中，强界和好的分支规则可显著降低计算量。

5.1.2 面向RCPSP的分支定界方法

由于本文目标是比较A*与B&B的基线变体，我们不采用复杂的RCPSP B&B方法（见第2节），而是将自己限制于本节描述的相当基础的版本。

每个节点 N_i 与所考虑RCPSP实例的部分调度 (𝒥, S_𝒥) 相关联，当前时间 g(N_i) = max_{j∈𝒥} S_j。从节点 N_i 可达的项目工期的状态一致关键路径（CP）下界记为 f̂(N_i)（即一般框架中的 F̲(N_i)），对应于在给定部分调度及开始时间 S_𝒥 = {S_j}_{j∈𝒥} 下忽略所有资源约束的问题(3a)–(3g)松弛的最优目标值：

f̂(N_i) = min_{S_j, j∈𝒱\𝒥} S_n　　(8a)
s.t. S_j + d_j ≤ S_l, ∀(j,l) ∈ ℰ　　(8b)
S_j ≥ g(N_i), ∀j ∈ 𝒱\𝒥　　(8c)

由于该松弛仅含优先约束，f̂(N_i) 可通过单次前向关键路径遍历得到，无需优化求解器。

在该松弛中，已调度活动的开始时间是固定的。等价地，在带时间状态表示中，已完成活动无需进一步处理，正在进行活动贡献其剩余工期，未开始活动不得早于 g(N_i) 开始，服从优先约束但资源约束被松弛。所得下界满足 f̂(N_i) = g(N_i) + h(N_i)，其中 h(N_i) 是到项目完成的剩余时间的下界。

若带部分调度 (𝒥, S_𝒥) 的节点 N_i 不能被剪枝，我们在所有可在时刻 t ≥ g(N_i) 开始的活动上进行分支，同时遵守所有优先和资源约束。因此，N_i 的子节点 N_k 对应于以附加活动 j 扩充部分调度，使得 j 的所有前驱属于 𝒥，且活动 j 在不早于 g(N_i) 的最早可行时刻开始，得到部分调度 (𝒥 ∪ {j}, S_{𝒥∪{j}})（见第3.1节）。

于是，S_j 由以下混合整数规划的解给出，其中对所有 i ∈ 𝒥，若 S_i = t 则 y_it 固定为 1，否则为 0：

min_{S_j, y_jt} S_j　　(9a)
s.t. Σ_{t=g(N_i)}^{H−d_j} y_jt = 1　　(9b)
S_j = Σ_{t=g(N_i)}^{H−d_j} t·y_jt　　(9c)
S_l + d_l ≤ S_j, ∀(l,j) ∈ ℰ, l ∈ 𝒥　　(9d)
Σ_{l∈𝒥∪{j}} r_lk Σ_{τ=max{0,t−d_l+1}}^{min{t,H−d_l}} y_lτ ≤ R_k, ∀t ∈ 𝒯, k ∈ ℛ　　(9e)
y_jt = 0, ∀t = 0,…,g(N_i)−1　　(9f)
y_jt ∈ {0,1}, ∀t = g(N_i),…,H−d_j　　(9g)

这确保 g(N_k) ≥ g(N_i)，且活动 j 的开始时间 S_j 同时考虑了资源和优先约束。我们注意到，实践中 S_j 可解析计算，无需求解(9a)–(9g)。

将所有活动顺序调度可得工期为 H 的可行调度，因此我们将上界初始化为 F̄ = H。

我们采用BF搜索策略，选择 f̂(N_i) 值最小的活动节点 N_i。作为平局决胜规则，我们选择 g(N_i) 值最大者；若两者仍相同，则采用先进先出（FIFO）策略。B&B也可采用其他节点选择策略，但此选择使B&B节点选择规则与A*的BF扩展规则保持一致，从而控制搜索顺序差异，使比较聚焦于基于树的枚举与重复状态检测的影响。

5.2 A*搜索

A是著名的BF图搜索算法，用于寻找从初始状态到目标状态的最小成本路径（Hart等，1968）。我们首先描述一般A框架，然后将其特化到第4.2节定义的RCPSP状态图。

5.2.1 一般框架

考虑一个具有初始状态、目标状态集合和非负转移成本的有向状态空间图。对每个已生成的状态 s，A使用评估函数 f̂(s) = g(s) + h(s)，其中 g(s) 是当前已知的从初始状态到 s 的最佳路径成本，h(s) 估计从 s 到目标状态的最小剩余成本。若启发式 h 从不高估该剩余成本，则称其为可采纳的。若此外 h 还是一致的，则A的标准图搜索版本保证首个被选择扩展的目标状态位于最优路径上。
