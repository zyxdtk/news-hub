摘要

我们引入了一个可微分精确学习框架，该框架将无界外部环境与状态跟踪神经控制器相耦合，并在策略轨迹观测上训练该控制器：专家行为轨迹展示观测和动作，同时隐藏内部状态。除了学习框架之外，我们还引入了可微分有限状态转换器（DFST），它们使用多线性更新，支持对数并行训练，并能模拟任意有限状态控制器，通过环境交互实现计算通用性。从极小的训练数据集出发，紧凑的 DFST 在算术和通用模拟任务上实现了极端长度泛化。我们在 RNN 和 GRU 上复制了 DFST 的成功，从而支持更广泛的学习配方：

状态跟踪控制器 + 无界外部环境 + PTO = 极端长度泛化

除了长度泛化之外，我们的度量提取协议从训练好的 DFST 中恢复可解释的离散控制器，我们证明这些控制器等价于目标算术和通用模拟算法。此外，对于我们的 Softmax DFST 模型，只需对转移概率取 argmax 即可得到离散控制器，这些控制器可证明精确执行通用图灵机模拟和二进制算术。证明神经控制器的精确学习需要假设，我们通过实验支持这些假设。我们公开了代码、训练配方、模型权重和证明检查器。

图 1：基于小 PTO 数据集和紧凑控制器的极端长度泛化。从头训练的 DFST 模型在算术和通用模拟任务上的长度泛化。阴影标记训练期间看到的输入长度。我们的模型看到的计算轨迹中，加法输入不超过 3 位，乘法输入不超过 5 位。在通用任务上，DFST 看到 5 台图灵机在最多 5 个符号输入上的模拟轨迹，并泛化到 5 台未见过的图灵机。端点标记达到预定义测试上限的成功长度泛化。

1 引言

几十年来，研究人员一直致力于让神经网络从数据中学习算法程序，认为真正的机器智能需要精确恢复底层规则，而非匹配表面统计规律（Solomonoff 等，2006；György 等，2025）。然而，算术作为算法学习的典型测试平台，持续暴露出一个持久的差距。在输入-输出数据上训练的 Transformer 和 RNN 对更长输入的泛化能力仅略有提升（Delétang 等，2022）。即使有大量草稿板协议、位置编码方案和输入格式化技巧，Transformer 的长度泛化¹也只能达到训练操作数长度的 2–7 倍，且随着输入变长，精确匹配准确率迅速衰减（Hou 等，2025；Y. Zhou 等，2024；Cho 等，2024a）。Neural GPU（Kaiser 和 Sutskever，2015）在随机二进制算术实例上达到 100 倍长度泛化而脱颖而出，尽管后来的诊断暴露了长进位和对称输入失败（Price 等，2016）（见表 1）。这种有限测试的成功使得任意长输入上的精确性问题仍未解决。

¹在引用论文中定义为达到 95% 以上的精确匹配准确率（EMA）。

一个相关的例外来自递归神经程序员-解释器（NPI）（Reed 和 De Freitas，2015；Cai 等，2017），它可证明地恢复了十进制加法和几种排序算法。然而，该训练通过递归调用/返回注释使用了更强的监督形式，这超出了仅在外部环境中观察专家动作的范围。

相比之下，真实的学习者经常正是在这种限制下取得成功。事实上，儿童通过观察成年人执行目标导向的动作来获得复杂的程序性技能，而无法访问成年人的内部神经过程。仅从这些行为轨迹中，婴儿就能推断出底层的程序结构，并通过练习重现目标行为（Meltzoff 和 Moore，1995）。

受自然学习者成功的启发，本文探讨了基于梯度的、从行为观测中进行精确算法学习的想法，并提供了一个简单的配方，通过在小数据集上从头训练紧凑控制器来实现极端长度泛化（见图 1）。

据我们所知，这项工作首次提供了对固定通用解释器的可微分精确恢复，其正确性证明涵盖具有无界输入长度和无界执行视野的图灵机任意模拟。我们同样在加法和乘法任务上实现了精确的可微分恢复。我们的训练不提供专家控制状态，且学习到的解释器在更换输入程序时无需重新训练。

我们只需要两个要素：足够信息丰富的观测和足够表达能力的学习器。

足够信息丰富的观测。 训练数据的选择决定了精确学习的可能性。Gold（1967）证明了没有算法可以仅从输入-输出示例中在极限内识别递归函数类（Gold，1967，定理 I.5）。此外，这种不可能性在主动学习设置中仍然存在（Gold，1967，定理 I.3）。因此，从 (z, f(z)) 对的监督学习，以及仅在正确输出时给予奖励的强化学习（没有有用的课程），一般无法识别每个递归函数。为了在这个一般识别障碍与 NPI 的额外（强且不现实的）程序结构监督之间寻找中间道路，我们采用策略轨迹观测（PTO）作为训练信号。PTO 记录环境在专家策略下如何演化，而不暴露专家的内部状态转移。² 这种中间立场具有两个优势： PTO 避开了 Gold 的不可能性障碍（Papazov 和 Flammarion，2025，定理 16）； PTO 可以自然地解释为行为观测——学习者只观察世界在专家动作下如何变化。

²用 PTO 恢复算法反映了更现实的从演示中学习的设置（Argall 等，2009）。

足够表达能力的学习器。 由于我们的目标是任意算法的精确学习，学习器必须属于图灵完备的模型类。先前的工作通过排除有效优化的假设建立了 Transformer 和 RNN 的图灵完备性：无界算术精度（Siegelmann 和 Sontag，1992；Pérez 等，2019）、无界上下文窗口（Dehghani 等，2018；Bhattamishra 等，2020；Merrill 和 Sabharwal，2023a）或不可微分的环境交互（Chung 和 Siegelmann，2021；Schuurmans 等，2024）。我们提出了一个更简单的解决方案，保持有限精度和固定大小的上下文，从而允许有效的基于梯度的优化。关键思想是将状态跟踪³控制器（如 RNN、LSTM 或 GRU）耦合到动态调整大小的外部环境中，控制器可以在其中移动、读取和写入。因为环境按需增长，计算不再受控制器固定内部内存的瓶颈限制。Zaremba 和 Sutskever（2015）探索了将 LSTM 控制器与外部磁带配对的相关架构，但仅通过强化学习在输入-输出奖励上进行训练，而 Gold 定理表明这不足以进行一般的精确学习。我们希望通过更丰富的 PTO 监督来复兴并加强这一架构思想。

³我们将状态跟踪定义为在给定足够模型容量下能够模拟任意有限状态自动机。

因此，我们的学习配方浓缩为一个简单的等式：

状态跟踪控制器 + 无界外部环境 + PTO = 极端长度泛化

事实上，我们更进一步，引入了一个简单的提取程序，从训练好的神经模型中恢复离散控制器。我们证明提取的控制器精确遵循目标行为，因此证明了以下可微分精确学习算法的方法：观察 PTO → 可微分学习 → 提取。状态跟踪神经控制器预测写入和移动；专家状态隐藏；最终得到可证明与专家等价的离散控制器，实现极端长度泛化。

主要贡献。

  1. 可微分精确学习的概念框架。 我们复兴了通过状态跟踪神经控制器与无界外部环境耦合来实现图灵完备可微分计算的思想。在少量 PTO 上训练可产生极端长度泛化。随后的提取为研究任务中恢复的离散控制器建立了精确学习，并在稳定性假设下对神经控制器成立。

  2. 可微分有限状态转换器（DFST）。 我们引入了一个 简约、 多线性、 可微分、 状态跟踪和 可并行化的模型族，其成员在我们的实验中充当控制器。DFST 不使用非线性激活，通过前缀扫描实现对数并行训练（Blelloch，1990），并为研究算法学习的损失景观和梯度下降的有用隐式偏置提供了透明结构。

  3. 从小 PTO 数据集实现极端泛化。 我们在小 PTO 数据集上训练（add2 为 25 条轨迹，mult2 为 100 条，add10 为 250 条，mult10 为 10000 条），达到加法 5000 位和乘法 1000 位的鲁棒测试上限。训练操作数分别最多包含 3 位和 5 位数字。我们使用 RNN 和 GRU 控制器在二进制算术上复制了极端长度泛化，从而支持我们的泛化配方。

  4. 通用控制器的精确学习。 一个具有 4335 个参数的 DFST，仅从 5 个程序模拟的 75 个 PTO 上从头训练（输入最多 5 个符号），在所有 10 个通用模拟任务上达到 500 符号评估上限，包括 5 个保留程序。从训练好的 DFST 模型中，我们的提取程序恢复了可证明等价于专家通用解释器的控制器，能够在任意输入长度和执行视野上模拟任意程序。

  5. 精确学习的提取和验证。 应用于训练好的 DFST 的轻量级提取程序恢复了紧凑的 FST。八个证明建立了二进制和十进制算术以及通用模拟上的精确专家策略等价性。额外的经验验证假设证明了训练好的神经控制器与专家的等价性。

备注。 早期研讨会版本引入了 DFST 并报告了相当可观的算术长度泛化（Papazov 等，2025）。本工作简化了训练；将长度泛化推向极端；并增加了学习到的通用模拟、Softmax DFST、递归控制器比较以及提取控制器的精确等价证书。

2 预备知识

如引言中所讨论的，我们精确学习的配方将状态跟踪控制器与无界外部环境耦合。

2.1 策略轨迹观测

我们将外部环境建模为符号网格。

定义 2.1（符号网格）。 给定包含空符号 λ 的有限字母表 Σ，网格配置 w: ℤ² → Σ 为每个单元格 p ∈ ℤ² 分配一个符号 w(p) ∈ Σ，使得只有有限多个单元格不同于 λ。符号网格 𝒢 = 𝒢(ℤ², Σ) 表示所有此类配置的集合。

有限性要求捕捉了这样的想法：环境按需增长，但在任何时间点都不存储无限量的信息。我们现在形式化居住在网格中的智能体。

定义 2.2（网格智能体）。 符号网格 𝒢(ℤ², Σ) 上的网格智能体代表一个有限状态转换器 T = (Q, Σ, Γ, δ, γ, q₀, q_f)，其中 Q 表示有限状态集，Σ 同时作为读取字母表和写入字母表，Γ = Σ × ℳ 且 ℳ = {L, R, U, D, S} 构成将网格符号与移动方向配对的输出字母表，δ: Q × Σ → Q 指定状态转移函数，γ: Q × Σ → Γ 指定输出函数，q₀ ∈ Q 表示初始状态，q_f ∈ Q 表示停机状态。智能体总是从 p₀ = (0, 0) 开始。

图 2：DFST 智能体的一步。左：动作前的网格 w_{t-1}；位于位置 p_{t-1} 的智能体读取红色单元格中的符号作为观测 x_t。中：DFST_θ 控制器通过 h_t = A[x_t] h_{t-1} 更新隐藏状态，并产生离散输出 σ_t = argmax(B[x_t] h_{t-1}) ∈ Σ（写入）和 μ_t = argmax(C[x_t] h_{t-1}) ∈ ℳ（移动）。右：结果网格 w_t；橙色单元格显示在 p_{t-1} 处写入的符号 σ_t，智能体已移动到青色单元格中的 p_t。我们提供了一个交互式查看器，可动画演示专家和训练好的神经控制器。

智能体在每个时间步 t 占据单个单元格 p_t ∈ ℤ²，读取符号 x_{t+1} = w_t(p_t)，产生输出 γ(q_t, x_{t+1}) = (s_{t+1}, m_{t+1})，在位置 p_t 写入 s_{t+1} 并将智能体的位置移动 m_{t+1}，然后转移到状态 δ(q_t, x_{t+1})。我们采用如下约定：每个包含停止移动 S 的转移都导致停机状态 q_f，且 q_f 的所有转移满足 δ(q_f, x) = q_f 和 γ(q_f, x) = (x, S)（对每个 x ∈ Σ），使 q_f 成为使网格保持不变的死状态。

注意，网格智能体一次只感知一个单元格。未来的工作可以探索更丰富的感知机制，编码多个单元格的内容，以及与更大移动词汇表交互的智能体。由于标准图灵机可作为限制在网格单行上的网格智能体的特例出现，所有网格智能体的类 𝒜 在与 𝒢 交互时实现计算通用性。

PTO。 在每个时间步 t，观察智能体 T 的外部学习者只感知写入的符号 s_t ∈ Σ、移动 m_t ∈ ℳ 以及触发该动作的观测 x_t。重要的是，内部状态 q_t 保持隐藏。结果序列 (x_t, s_t, m_t)_{t=1}^T 构成策略轨迹观测（PTO），与 Papazov 和 Flammarion（2025）的形式化相匹配。关键的是，Papazov 和 Flammarion（2025，定理 16）证明了 PTO 能够在极限内精确识别任何可计算函数——这是仅通过输入-输出监督无法实现的保证（Gold，1967）。

困难性。 每个算法任务 𝒫 带有一组有效输入 S_𝒫 ⊆ Σ*。由于每步输出的移动标记约束了下一个观测，S_𝒫 可能永远不会覆盖所有可达的转换器转移，从而使学习问题从根本上变得困难。Papazov 和 Flammarion（2025，定理 17）证明了在这种受限输入机制中不存在多项式质量特征集，排除了任何从多项式数量、多项式长度的 PTO 中学习每个网格智能体策略的算法（详见第 C.3 节）。

2.2 状态跟踪可微分控制器

虽然 Papazov 和 Flammarion（2025，定理 16）表明枚举学习策略可证明地从 PTO 中识别任何网格智能体，但这种方法需要与目标专家智能体大小成指数级的时间和内存。我们转而追求基于梯度的学习，引入一个简单的可微分模型，可用作网格智能体控制器。

定义 2.3（DFST）。 维度为 d 的可微分有限状态转换器（DFST）定义在符号网格 𝒢(ℤ², Σ) 上，具有移动词汇表 ℳ，包含三个可训练权重张量 A ∈ ℝ^{|Σ|×d×d}，B ∈ ℝ^{|Σ|×|Σ|×d}，C ∈ ℝ^{|Σ|×|ℳ|×d}，以及可训练的初始隐藏状态 h₀ ∈ ℝ^d。在每个时间步 t ≥ 1，控制器读取当前网格单元格 w_{t-1}(p_{t-1}) 中符号的独热编码 x_t ∈ ℝ^{|Σ|}，并计算

h_t = A[x_t] h_{t-1}，ŝ_t = B[x_t] h_{t-1}，m̂t = C[x_t] h{t-1}。

A 驱动隐藏状态递归，B 产生符号标记上的分数，C 产生移动标记上的分数。在推理时，控制器发出 σ_t = argmax(ŝ_t) ∈ Σ 和 μ_t = argmax(m̂t) ∈ ℳ，在位置 p{t-1} 写入 σ_t 并按 μ_t 移动到 p_t（见图 2）。

DFST 的递归和读出仅使用输入索引的矩阵-向量乘积，没有非线性激活。这种多线性结构通过前缀扫描实现对数并行训练，并产生紧凑的参数化。字母表大小为 k = |Σ| 且有 r = |ℳ| 个移动标记的 d 维 DFST 携带 kd(k+d+r)+d 个可训练参数，规模为 O(d²)。

定义 2.4（Softmax DFST）。 Softmax DFST 具有与 DFST 相同的递归和读出机制，具有可训练的 logits Θ^A、Θ^B、Θ^C、θ^h 进行参数化：

P[x]{:j} = softmax(Θ^P[x]{:j})，P ∈ {A, B, C}，h₀ = softmax(θ^h)。

每列的总和为一。因此，隐藏状态保持在概率单纯形中，读出给出写入和移动的分布。执行使用与 DFST 相同的 argmax 解码。

这种参数化使提取变得透明：每列为后继状态或动作分配概率，在单纯形顶点附近的集中表明确定性转移。递归保留了结合矩阵扫描。第 4 节发展了可微分锐化和忠实提取的条件。

尽管这些架构简单，两个模型族都支持状态跟踪：

定理 2.5（DFST-网格通用性）。 任何 d 状态网格智能体在任何有限算术精度下都允许被 d 维 DFST 精确模拟，以及在精确实数算术中具有有限 logits 的 (d+1) 维 Softmax DFST 精确模拟。在 softmax 能达到单纯形顶点且递归保持顶点操作的四舍五入算术下，d 维 Softmax DFST 也足够。

因此，DFST 和 Softmax DFST 模型族在各自算术条件下都在符号网格上实现图灵完备性。附录 B 给出构造性证明，并讨论 DFST 参数化的非唯一性以及隐藏维度与专家状态数之间的关系。

更广泛地说，任何能够模拟有限状态转换器的序列模型都可以表示网格智能体的策略，从而在网格上计算任何可计算函数。这个类包括 RNN、LSTM 和 GRU（Alon 等，1991；Indyk，1995；Siegelmann，1996；Weiss 等，2018；Merrill，2019；Svete 和 Cotterell，2023），而标准 Transformer 和对角 SSM 面临状态跟踪限制，如 Merrill 和 Sabharwal（2023b）以及 Merrill 等（2024）所证明的。我们关注 DFST 是因为该模型类的多线性结构和简单性，我们希望这将激发对梯度下降向泛化解的隐式偏置的理论分析。第 3 节中的 DFST、RNN 和 GRU 实验支持这种更广泛的状态跟踪视角。

2.3 实验设置

我们研究二进制和十进制算术（add2、add10、mult2、mult10）的网格智能体，以及在 {λ, 0, 1} 字母表上模拟图灵机的通用网格智能体 U。表 2 总结了所有已实现的网格智能体和图灵机的专家状态数、字母表和运行时间。

算术任务。 每个算术智能体接收 z = a ∘ b，其中 ∘ ∈ {+, ×}，水平写在 otherwise 空白的网格上。智能体执行加法和乘法的教科书算法，当网格上只剩结果时停止。

数据生成。 每个算术 PTO 数据集包括所有 R² 个单位数操作数对，然后采样不同的对，操作数长度在 1, …, q 中独立均匀分布，数字在 0, …, R-1 中。前导零保留在表示中。普通 DFST 数据集总是使用：add2：q=3，N=25；add10：q=3，N=250；mult2：q=5，N=100；mult10：q=5，N=10k。

长度泛化指标。 均匀长度泛化（ULG）记录由有上限搜索返回的操作数长度，要求在恰好该长度的十个随机对上实现完美的下一动作精确匹配准确率。鲁棒长度泛化（RLG）额外要求在结构化重复数字探针上实现完美准确率，且不能超过 ULG。每次 RLG 评估测试所有 R² 个重复数字对 (a^m, b^m)，其中 a, b ∈ {0, …, R-1}。每个时间步必须同时匹配专家的写入和移动。Neural GPU 启发了这种区分：在随机二进制输入上的强泛化（Kaiser 和 Sutskever，2015）可能与重复数字实例上的失败共存（Price 等，2016）。第 D.6 节指定了搜索、数值执行模式和有限测试的限制。

学习通用解释器。 通用网格智能体 U 使用 15 个状态和字母表 {0, 1, λ, X, Y, Z, L, R, S}。给定图灵机 M 和输入 z ∈ {0,1}⁺ 的编码 ⟨M, z⟩，U 在 z 上模拟 M，每当 M 停机时，在指定网格区域停机并带有 M(z)。U 使用 3 个传送符文 {X, Y, Z} 来标记位置并在网格位置之间直接跳转，从而缩短模拟轨迹。网格存储当前模拟的图灵机 M 的编码以及输入。从通用专家的 PTO 中，可微分控制器学习如何读取和执行该程序，而无需访问 U 的内部状态或转移映射。公共存储库提供了模型权重和动画执行。

数据生成和评估。 通用数据集包含 N ∈ {75, 150, 225} 个 PTO，覆盖 5 个程序，二进制输入长度最多为 5。在为每个程序采样一个随机字符串后，数据集的其余部分来自随机程序-输入对。评估涵盖 10 个任务，包括 5 个保留程序以及同时增加输入长度和程序大小的缩放任务。附录 F 详述了符文机制、程序/输入编码以及训练和评估任务。

控制器训练。 对于每个任务，手动设计的专家提供 PTO。我们通过下一动作预测训练控制器，使用 MSE 损失：

(1/2T) Σ_{t=1}^T [‖ŝ_t − 1_{s_t}‖₂² + ‖m̂t − 1{m_t}‖₂²]，

其中 1_{s_t} 和 1_{m_t} 表示时间 t 专家写入和移动的独热编码。我们在所有任务上训练 DFST 控制器，在二进制算术和通用模拟上研究 Softmax DFST，并在二进制算术上比较 RNN 和 GRU 控制器。训练始终使用 Adam（Kingma，2014）、批量大小 32 和 float32 精度。

DFST 训练。 除非另有说明，DFST 隐藏维度与专家状态数匹配。我们始终使用简单的确定性初始化。转移矩阵从恒等矩阵开始，输出矩阵从零开始，可训练初始状态为 1_d。所有普通 DFST 运行使用指数预热和冷却学习率调度器（第 D.1 和 D.2 节）。第 B.3 节考察了使用更小和更大隐藏维度的成功学习。

Softmax DFST 训练。 Softmax DFST 在 softmax 归一化之前对 logits 应用相同的初始化配方。扫描使用专家状态数的一倍、两倍或三倍维度，并改变数据集大小。训练使用 100k 次更新，恒定学习率 0.1（以及可选的向近似独热转移概率退火）。第 D.4 节给出完整训练设置。

3.1 算术上的长度泛化

图 3 比较了提取前的算术泛化。所有 DFST 和 Softmax DFST 模型都从头训练，使用相同的简单确定性初始化配方。

图 3：可微分训练在算术上的鲁棒泛化。前两列显示普通 DFST 学习率调度扫描。最后一列显示 100k 次恒定学习率训练更新后的 Softmax DFST 维度/数据扫描。单元格报告以操作数位数计的 RLG。附录 E 提供配对的 ULG/RLG 图。

几个 DFST 运行同时达到 ULG 和 RLG 测试上限：加法每个操作数 5000 位，乘法 1000 位，在二进制和十进制基数中，分别在最多 3 位和 5 位操作数上训练后实现。成功因训练调度而异，额外的更新不一定改善泛化。

在 100k 次恒定学习率更新后，许多 Softmax DFST 配置达到鲁棒二进制加法和乘法上限。Softmax DFST 运行具有提供可解释转移概率的优势，同时也支持极端泛化。然而，Softmax DFST 优化更具挑战性，我们甚至无法在十进制任务上拟合小训练集。第 D.7 节讨论了这些限制。

数千万次连续正确动作。 操作数长度低估了这种外推的规模。两个 5000 位全 9 数字相加需要 50,070,010 个 PTO 步骤；两个 1000 位全 9 数字相乘需要 15,012,991 步。每步都需要正确的写入和移动，包括最终的停止动作。相应的二进制全 1 探针需要完全相同数量的步骤（第 F.5 节）。成功的十进制 DFST 重现了全 9 轨迹，而多个二进制 DFST 和 Softmax DFST 配置重现了等长的全 1 轨迹。二进制控制器仅从 25–75 个加法 PTO 或 100–300 个乘法 PTO 中学习，操作数分别最多 3 或 5 位。这种训练支持在这些结构化探针上数千万步的忠实执行，远超短训练轨迹。

小数据学习与隐式偏置。 这些长执行提出了一个超越表示能力的问题：为什么基于梯度的训练偏爱在训练长度之外仍能继续工作的规则？仅匹配训练 PTO 并不强制这种行为。我们构造了虚假的二进制加法和乘法控制器，它们在训练长度范围内重现每个专家 PTO，但在更长输入上过早停止。因此，即使在整个 3 或 5 位输入域上的详尽监督也无法区分专家算法和这些退化替代方案。此外，虚假控制器只需要 14 和 38 个状态（第 I.1 和 I.2 节），而二进制算术专家分别为 11 和 32 个状态。

图 3 中较大的 Softmax DFST 有足够容量表达这些虚假解：加法使用维度 22 和 33，乘法使用 64 和 96（第 I.3 节）。然而，每个较大扫描中六个配置中有五个达到鲁棒测试上限。这些成功配置因此避免了构造的虚假规则，尽管有足够容量表示这些规则。使用所选参数化和初始化的基于梯度的优化反复偏爱能在长执行视野中存活的行为，尽管训练集未能区分其他虚假目标。

这些结果支持存在一种向泛化规则的有用隐式偏置。表征这种偏置的来源和可靠性仍然是一个开放方向。

3.2 通用任务上的长度泛化

这些评估测试了 3 种不同形式的泛化：更长的输入、向 5 个未见程序的迁移，以及更大的编码图灵机。每个控制器在所有评估中保持相同的学习权重。因此，固定模型可以执行新颖的计算而无需重新训练，只需更改输入图灵机。

4 精确学习的验证

除了第 3 节中的有限长度泛化测试外，我们提取并验证离散控制器，然后识别将正确性转移到神经执行的条件（第 1 节）。即使有离散控制器，无界网格也阻止了通用充分测试视野的存在：

引理 4.1（有限视野验证的不可判定性）。 没有算法可以接受两个网格智能体 T、M 的描述并返回有限输入长度界限 L，使得对所有 z ∈ Σ^{≤L} 的 PTO 一致性 T[z] = M[z] 蕴含在所有输入上的一致性。

第 H.1 节通过从停机问题归约证明了该论断。因此，一般而言，没有算法可以保证长度泛化到某个上限就能证明精确学习。为了证明精确学习，我们必须考虑特定的控制器结构。由于有限精度神经控制器表示的 FST 大得难以处理，我们首先需要提取可管理的东西。

4.1 恢复显式控制器

度量提取。 我们将随机输入馈送到训练好的 DFST 控制器，并从执行中展开隐藏状态轨迹。我们连接 ε 欧几里得距离内的隐藏状态，并将隐藏状态聚类为连通分量，这些分量成为初始离散状态。每个离散状态通过从连通分量内隐藏状态继承的符号转移指向其他离散状态。这样，我们获得了非确定性 FST。我们开始合并离散状态，直到得到确定性 FST 并返回，或者直到出现某种不一致。在不一致的情况下，我们将 ε 减半并重新开始。对于足够小的 ε，我们将获得一致的确定性转移图。结果图重现了收集的轨迹，未观察到的转移保持未定义。有趣的是，我们经验性地验证了在足够多的采样隐藏状态轨迹后，提取的图会稳定。注意，这种类型的提取不使用专家隐藏状态标签。详见第 G.1 节。

Softmax 退火和直接读出。 训练好的 Softmax DFST 为后继状态和动作分配概率。我们继续训练，使用 G(p) = 1 − ‖p‖₂² 惩罚来锐化分布。逐渐增加（退火）惩罚权重将概率集中到近似独热向量。然后逐列 argmax 选择确定性离散转移，从而提取 FST。第 G.2 节给出完整目标和调度。

两种提取路线都产生候选离散控制器。图 6 显示了经验图稳定性和近似独热概率集中。

图 6：从训练控制器到可解释图。左：提取的图在 23 个采样轨迹后稳定，为图稳定性提供了有限证据。右：退火期间次大概率接近 10⁻⁷；更长退火与更大正则化系数达到最小正次正规概率，仍与精确零不同。

4.2 证明恢复算法的目标等价性

我们将提取的状态和网格配置与专家算法的阶段相关联。该关系最初成立，我们证明每个允许的转移产生匹配的动作并保持该关系。算法特定的不变量表明这些阶段覆盖每个有效执行。归纳法然后建立任意执行长度上的一致性，包括同时停止。不同的内部表示和状态数因此可以实现相同的算法（第 H.3 节）。

八个证书。 我们提供五个度量提取证书和三个退火证书。定理 H.3、H.7、H.14 和 H.18 涵盖任意非空操作数上的二进制和十进制算术，包括不等长度和前导零。通用证书远远超出五个训练程序。定理 H.24 证明恢复的离散控制器对任意正确编码的机器和输入长度实现解释器的规则，产生以下推论。

推论 4.2（通用控制器的精确学习）。 通过度量提取和 softmax 退火从可微分训练的 DFST 和 Softmax DFST 获得的通用控制器，正确模拟每个二进制图灵机在每个非空二进制输入上的运行。

GPT-6 Astra 生成了证明。我们验证了论证。存储库检查器机械验证有限转移义务，而归纳论证建立无界正确性。

4.3 将保证转移到神经控制器

两种路线在显式假设下将恢复的 FST 证书转移到神经执行。

度量提取的图稳定性。 图稳定性要求每个进一步的神经隐藏状态轨迹保持从阈值 ε 处轨迹 S 提取的图，直到状态重命名。

Softmax DFST 的一致有界泄漏。 我们假设 ‖h_t − e_{q_t}‖₁ ≤ ε 在有效输入和执行长度上一致成立，其中 q_t 跟踪由相同观测驱动的未最小化 argmax 控制器。这限制了偏离目标的泄漏和偏离预期独热状态的漂移。在独热隐藏状态处，令 μ 表示在所有有效执行中，规定的写入或移动相对于任何竞争选择的最小分数优势。隐藏状态泄漏最多可将此优势减少 ε。四舍五入可以将优势再减少 2ρ，因为两个比较分数中的每一个最多可以改变 ρ。因此，μ > ε + 2ρ 确保两个读出仍然选择规定的动作。

定理 4.3（行为忠实性）。 在假设 H.1 下，确定性轨迹一致的度量提取在每个有效输入上重现神经控制器的每个 PTO。在假设 G.1 下，Softmax DFST 和 argmax 控制器同样产生相同的 PTO。在任何一种情况下，保持轨迹的商约简保持这种等价性，因此提取控制器的专家等价证书在同一域上转移到神经控制器。

第 H.2 节证明了两种情况。对于 Softmax DFST，读出裕度超过组合泄漏和四舍五入扰动，因此归纳法保持每个动作和环境更新。

5 结论

我们的框架将可微分参数搜索置于离散算法外壳内：训练神经控制器，通过固定规则提取离散模型，并验证与目标算法的精确一致。由于提取遵循固定的简单程序（特别是 Softmax DFST 的 argmax 读出），我们将这种可微分搜索和离散读出的组合视为可微分精确学习。证书涉及恢复的离散模型，而图稳定性或有界泄漏假设额外将正确性转移到神经执行。

附录 A 相关工作

我们的工作建立在长期以来的神经程序归纳研究之上，该研究方向使用神经架构学习算法程序。在这一范式内，先前的工作探索了多种学习信号和模型类。我们的框架结合了以下三个期望特性： 从专家行为观测中学习； 学习框架的计算通用性； 在完全可微分设置中的连续优化。

这项工作研究了这三个原则交叉处的精确学习，并对提取的控制器在所有有效输入上进行等价证明。具体而言，我们关注智能系统仅从外部可观察行为推断算法过程的学习场景，如从演示中学习的设置（Argall 等，2009）。关键的是，行为观测避开了输入-输出监督的一般识别障碍（Gold，1967；Papazov 和 Flammarion，2025），而无需访问专家的内部状态。此外，我们要求框架具有计算通用性和可微性，以便将学习作为通用机制研究，避免训练期间的任务特定指令模板和手工搜索程序。

先前的通用性结果在计算资源和学习保证方面有所不同：

  • 精度和上下文要求：具有无界精度内部算术的 RNN 和 Neural GPU（Siegelmann 和 Sontag，1992；Pérez 等，2019）；具有增长上下文窗口或无界精度内部算术的 Transformer（Pérez 等，2019；Dehghani 等，2018；Bhattamishra 等，2020；Merrill 和 Sabharwal，2023a）。
  • 外部内存构造：与增长内存耦合的有界精度递归控制器（Chung 和 Siegelmann，2021）；用完整产生式规则系统提示的语言模型（Schuurmans 等，2024）。
  • 视野依赖架构：对有界时间计算的统计近似保证，模型大小取决于执行视野（Wei 等，2022）。

这些结果建立的是计算表达力或统计近似，而非从行为观测中恢复持久控制器。因此，仅有限精度通用性并不能区分我们的框架。我们的通用控制器从 75 个 PTO 中学习，无需提供控制状态或转移表，能迁移到训练中未出现的五个程序，并产生覆盖任意有效机器编码的提取控制器证书（附录 F 和 H）。经过认证的控制器在无界输入长度和执行视野上保持相同参数。

我们现在比较相关学习框架的监督和验证保证。

外部内存框架。 Zaremba 等（2016）的工作可能与我们的设置最接近。作者考虑了一个基于 RNN 的控制器，该控制器在只读输入网格和只写单向输出磁带上操作，发出包含移动和写入命令的动作标记。Zaremba 等（2016）研究神经控制器在通过强化学习获得正确输出奖励或专家策略监督训练时，是否能学会执行简单算法（如复制、反转、加法）。与我们的实验不同，训练使用了非平凡的课程，现成的 Q-learning 在大多数任务上失败，需要额外修改。任务套件包括单位数乘法，并在选定任务上展示了可观的外推。我们的实验额外涵盖了不受限制的双操作数乘法以及使用无界读写工作区的通用模拟。

相关的神经符号框架包括高阶 RNN（Giles 等，1989）、记忆网络（Weston 等，2014）、神经图灵机（Graves 等，2014）、Neural GPU（Kaiser 和 Sutskever，2015）、神经随机访问机（Kurach 等，2015）、神经程序员（Neelakantan 等，2015）、指针网络（Vinyals 等，2015）、堆栈增强 RNN（Joulin 和 Mikolov，2015）、可微分神经计算机（Graves 等，2016）、分层注意力记忆（Andrychowicz 和 Kurach，2016）、TerpreT（Gaunt 等，2016）、R3NN（Parisotto 等，2016）、可微分 Forth 解释器（Bošnjak 等，2017）以及神经符号堆栈机（Chen 等，2020）。外部存储甚至无界可微分内存已出现在该文献中（Grefenstette 等，2015）。我们的区别在于从 PTO 中学习潜在控制器状态并认证提取的计算，而非仅外部内存。

输入-输出观测。 另一个密切相关的方法出现在 Zaremba 和 Sutskever（2015）中，考虑了一个在只读输入磁带、读写内存磁带和只写单向输出磁带上操作的 LSTM 控制器。读写内存的加入使模型具有计算通用性。然而，学习仅通过强化学习进行，奖励为正确输出。Gold（1967，定理 I.3 和 I.5）排除了从输入-输出观测识别完整递归函数类的可能性；这些结果并不禁止学习特定的算术算法。PTO 避开了这一一般识别障碍（Papazov 和 Flammarion，2025），而本实验研究有限数据优化和验证。

程序结构观测。 一条特别相关的工作线来自神经程序员-解释器（NPI）（Reed 和 De Freitas，2015）。NPI 使用 LSTM 控制器作为程序执行器：在每一步，控制器消费局部环境快照以及活动子程序嵌入和当前参数，然后输出 固定库中下一个子程序的分布、 相应参数，以及 停止/返回决策。训练轨迹显式监督这种调用-返回结构。每个程序调用启动新的递归状态；返回恢复调用者的状态。这些注释暴露了程序结构，而不提供数值递归隐藏向量。

这种额外的程序监督支持数据高效的学习⁴，并在特殊情况下允许形式化的精确性保证。Cai 等（2017）观察到，当专家程序遵循每个子程序只允许有限多个基本配置和归约的递归模板时，可以形式化认证训练的 LSTM 控制器恢复了真实算法。实验已达到 5000 位加法，并对加法和若干排序任务有全输入证明。我们的区别在于在没有规定子程序身份或递归边界的情况下恢复持久控制器状态，并将证书扩展到完整的二进制和十进制乘法以及通用模拟。

⁴加法实验在 200 条执行轨迹上训练，操作数最多三位。

Pierrot 等（2019）进一步展示了通过分层程序规范、前置/后置条件检查和递归树搜索的强化学习；归纳论证为满足指定基本情况和递归轨迹条件的智能体认证了无界汉诺塔执行。我们的训练使用 PTO 下一动作损失，无需提供递归分解或程序库。

精确指令学习与逻辑归纳。 Back de Luca 等（2025）在无限宽度神经正切核机制中证明了高概率精确指令执行，使用显式指令模板，但每当内存预算增加时需要重新训练；神经训练实验涵盖排列，而算术训练因集成成本而未测试。我们的控制器在输入长度上保持固定参数；提取控制器证明不施加内存或执行视野界限。Payani 和 Fekri（2019）从正/负事实和提供的背景谓词中恢复显式递归程序，包括用于乘法的加法，没有 NPI 式的程序结构监督；经验研究使用有限域，既不提供长度泛化测量也不提供所有有效输入上的等价证明。我们的乘法控制器学习数字级动作和进位传播，无需提供的加法子程序，并在提取后接受全输入证明。

算术长度泛化。 最后，我们将贡献定位于算术泛化文献中。最近的经验研究（Joulin 和 Mikolov，2015；Delétang 等，2022；Liu 等，2022；Zhang 等，2022；Shen 等，2023；Kazemnejad 等，2023；Jelassi 等，2023）表明，当在输入-输出数据上训练时，Transformer、修改的 RNN 和 LSTM 在各种简单算法任务上长度泛化能力很差。通过额外的数据格式化策略（如任务特定索引提示、优化的位置编码、输入反转、位置耦合和草稿板指导），Transformer 算术泛化的多项工作（Anil 等，2022；Jelassi 等，2023；H. 本附录收集第 2 节中推迟的 DFST 表达力的形式细节。我们证明定理 2.5，讨论模拟参数化的非唯一性，并将所需的隐藏状态维度与目标智能体的状态数相关联。

B.1 通用性证明

为方便起见，我们重述该定理。

定理 2.5 见上文。

证明。 令 T = (Q, Σ, Γ, δ, γ, q₀, q_f) ∈ 𝒜 表示具有 d 个状态 q₀, …, q_{d-1} = q_f 的网格智能体。记 k = |Σ| 为字母表大小，符号为 s₀, …, s_{k-1}，r = |ℳ| 为移动标记数 m₀, …, m_{r-1}。我们将状态、符号和移动编码为标准基向量：q_i ↔ e_{i+1} ∈ ℝ^d，s_j ↔ e_{j+1} ∈ ℝ^k，m_ℓ ↔ e_{ℓ+1} ∈ ℝ^r。

定义 DFST 权重 (A, B, C, h₀) 如下。设 h₀ = e₁ = (1, 0, …, 0)ᵀ ∈ ℝ^d。对于每个转移 δ(q_i, s_j) = q_{i'} 且 γ(q_i, s_j) = (s_{j'}, m_ℓ)，分配

A[j, i', i] = 1，B[j, j', i] = 1，C[j, ℓ, i] = 1，

并将其余张量条目设为 0。

在此分配下，如果 h_{t-1} = e_{i+1} 编码状态 q_i 且输入 x_t = e_{j+1} 编码符号 s_j，则 A[x_t] h_{t-1} = e_{i'+1}，B[x_t] h_{t-1} = e_{j'+1}，C[x_t] h_{t-1} = e_{ℓ+1}。由于 h₀ = e₁ 编码初始状态 q₀，对 t 的归纳表明 DFST (A, B, C, h₀) 在每个输入上精确重现 T 的输出序列。此构造仅使用 {0, 1} 值权重，因此在任何有限算术精度 p ≥ 1 下都有效。

精确实数算术中的 Softmax DFST。 令 D_x ∈ {0,1}^{d×d} 表示读取符号 x 的确定性转移矩阵，O_x^s ∈ {0,1}^{k×d} 和 O_x^m ∈ {0,1}^{r×d} 表示相应的独热输出矩阵。设 n = d+1 且 u = 1_n/n。定义

V = (I_d; −1_dᵀ)，W = (I_d 0) − 1_d uᵀ。

则 WV = I_d，Wu = 0，且 1_nᵀV = 0。选择 0 < α < 1 和 η > 0 足够小，使得

A[x] = u 1_nᵀ + α V D_x W，h₀ = u + η V e_{q₀}

的每个条目保持严格为正。这样的选择存在，因为字母表和状态集包含有限多个元素。A[x] 的列和向量 h₀ 总和为一。归纳给出

h_t = u + η α^t V e_{q_t}，q_t = δ(q_{t-1}, x_t)。

对于大小为 a ∈ {k, r} 的任一输出字母表，记 u_a = 1_a/a，V_a = I_a − u_a 1_aᵀ，O_x ∈ {O_x^s, O_x^m}。选择 β > 0 足够小，使得列随机矩阵

P[x] = u_a 1_nᵀ + β V_a O_x W

具有严格为正的条目，并相应地使用 P = B 或 P = C。如果 y_t 表示 (q_{t-1}, x_t) 上的专家输出，则读出满足

P[x_t] h_{t-1} = u_a + βηα^{t-1}(e_{y_t} − u_a)。

因此，只要 a > 1，坐标 y_t 就达到唯一最大值；单例输出字母表无需比较。每个严格为正的概率向量都接受由逐坐标对数给出的有限 logits。因此，这些张量和初始化定义了一个 Softmax DFST，在每个有限时间重现每个专家动作。裕度随 t 缩小，因此仅此精确实数构造不提供有限精度鲁棒性保证。

四舍五入算术下的 Softmax DFST。 对于上述 d 维独热构造，为每个选定坐标分配 logit 0，为其他每个坐标分配 −L。稳定 softmax 的指数将 exp(−L) 四舍五入为零时，产生精确所需的独热列；对初始状态应用相同构造。例如，正确四舍五入的 binary32 指数运算在向最近值四舍五入下将 exp(−128) 下溢为零。一旦实现产生这些顶点并保持相应的矩阵-向量操作，原始归纳对每个执行长度不变地适用。饱和条件涉及有效概率，而非仅大有限 logits。

对于图灵完备性，观察到标准图灵机可作为限制在网格单行上的网格智能体出现。每个构造在所述算术条件下模拟每个此类智能体，因此两个控制器族都可以模拟任何图灵机。∎

B.2 模拟参数化的非唯一性

上述证明中的独热构造产生模拟给定网格智能体 T 的一个特定 DFST，但许多其他参数化实现相同行为。在精确算术中，任何可逆矩阵 R ∈ ℚ^{d×d} 通过以下方式定义等价控制器：

A'[x] = R A[x] R⁻¹，B'[x] = B[x] R⁻¹，C'[x] = C[x] R⁻¹，h'₀ = R h₀。

归纳给出 h't = R h_t 对每个读取序列成立，同时 B'[x_t] h'{t-1} = B[x_t] h_{t-1} 和 C'[x_t] h'{t-1} = C[x_t] h{t-1} 保持两个读出。因此，变换后的控制器重现每个动作和 PTO。为不同的非零有理值 c 选择 R = cI_d 已经产生无限多个不同的精确算术参数化，因为 h₀ ≠ 0。这些变换保持 PTO 损失，因此产生专家独热目标的无限多个零损失实现。

固定的有限算术格式只允许有限多个参数配置。任意有理基变换不一定保持四舍五入下的可表示性或执行，因此无穷性声明不扩展到固定有限精度。然而，独热构造的排列保持二值权重和顶点操作，只要这些操作保持精确，就产生等价的有限精度实现。另外，添加不可达状态产生具有相同可观察策略的无限多个离散网格智能体。

B.3 隐藏状态维度与状态复杂度

定理 2.5 保证 n 维普通 DFST 足以模拟任何 n 状态网格智能体。因此，大多数普通 DFST 实验将隐藏维度与专家状态数匹配，但成功学习不需要精确匹配。对于 11 状态 add2 专家，隐藏维度 d ∈ {5, 8, 11, 14, 17} 的扫描在每个测试维度（除 d = 5 外）都达到 5000 位 RLG 上限。因此，更小的控制器和具有过剩容量的控制器都实现了极端的测试泛化。这些有限探针不能建立任意输入上的精确模拟或识别最小充分维度。

Softmax DFST 扫描为额外容量的好处提供了补充证据（图 9 和 13）。二进制加法在维度 22 和 33 达到两个上限，而专家状态为 11；二进制乘法在维度 64 和 96 达到两个上限，而专家状态为 32；通用模拟在维度 30 和 45 达到每个任务上限，而专家状态为 15。在这些任务中，成功配置容纳专家状态数的两倍或三倍。更大维度不改善每个配置，但这些结果支持在专家状态数未知时选择过剩容量：成功训练不需要先精确了解该数量。

精确表征 DFST 模拟给定 n 状态 FST 所需的最小隐藏维度仍然是一个开放方向。独热构造为普通 DFST 提供了 n 的上界，而更小的表示可能利用目标转移和输出的结构。这种表征应区分所有输入字符串上的一致性与仅在可实现环境轨迹上的一致性，并考虑算术精度和读出裕度。另一个问题是基于梯度的训练是否能可靠地发现接近最小维度的表示。
