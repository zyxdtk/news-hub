安谋与Infosys合作构建电信等受监管行业...

📅 Feb 17, 20 📄 Anthropic 🔗 原文链接

URL Source: https://www.anthropic.com/news/anthropic-infosys Markdown Content:

Anthropic 与全球下一代数字服务与咨询领域的领导者 [Infosys](https://www.infosys.com/)（该公司成立于班加罗尔并总部设于此）今日宣布展开合作，共同开发并交付面向电信、金融服务、制造业及软件开发等领域的 enterprise AI（企业级人工智能）解决方案。

此次合作将 Anthropic 的 Claude 模型与 Claude Code 和 [Infosys Topaz](https://www.infosys.com/services/data-ai-topaz.html)（一套以 AI 为优先的服务、解决方案与平台，融合生成式人工智能与自主式人工智能技术）相集成，助力企业加速软件开发进程，并在符合监管行业所要求的治理性与透明度前提下，顺利采用人工智能技术。

印度是 Claude.ai 的第二大市场，拥有全球最活跃、技术实力最强的人工智能开发者社区之一：在印度，近一半的 Claude 使用场景涉及应用程序构建、系统现代化改造及生产环境软件交付。Infosys 是 Anthropic 在印度 [扩大业务布局](https://www.anthropic.com/news/bengaluru-office-partnerships-across-india) 过程中的首批合作伙伴之一。

“在演示环境中表现良好的 AI 模型与真正适用于受监管行业的 AI 模型之间存在显著差距——若想弥合这一差距，就必须具备深厚的行业专业知识。Infosys 正是拥有电信、金融服务及制造业等关键领域所需专业能力的企业之一。”

“Anthropic 的首席执行官兼联合创始人 Dario Amodei 表示：“许多软件开发者已开始使用 Claude Code 来加速自身工作，并为需要高精度、合规性及深厚领域知识的行业构建 AI 代理。”

Infosys 首席执行官 Salil Parekh 表示：“人工智能不仅正在重塑商业，更在重新定义各行业的运营与创新方式。我们与 Anthropic 的合作标志着在推进企业级人工智能方面迈出了战略性一步，使组织能够释放价值，变得更智能、更具韧性且更负责任。从通过智能风险管理与合规服务推动金融服务现代化，到助力工程类企业以 AI 驱动的设计与制造引领行业，我们的目标是整合 Infosys 与 Anthropic 的联合专长，加速全球企业实现人工智能价值。”

为受监管行业构建代理式人工智能 -------------------------------------------- 此次合作的核心聚焦于代理式人工智能（agentic AI）——即不仅能回答问题，还能独立处理多步骤任务的系统，例如处理理赔、生成与测试代码，或管理合规审查。借助 Claude Agent SDK 等工具，Infosys 与 Anthropic 将协助客户构建可在长期、复杂任务与流程中持续运行的 AI 代理。此次合作还将帮助组织现代化其遗留系统，通过整合Infosys Topaz 与 Claude，使系统迁移更快速、更简便，并降低系统升级成本。
