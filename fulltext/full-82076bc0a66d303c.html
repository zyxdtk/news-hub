摘要
现代优化器（如 Adam 和 Muon）是训练大语言模型的核心，但其依赖一阶与二阶动量导致显著内存开销，制约了可扩展性与计算效率。
本文将这些优化器中的指数移动平均（EMA）重构为在线梯度流下的线性回归训练过程。基于该等价性，我们提出 LoRA-Pre——一种面向高效预训练的新型低秩优化器。具体而言，LoRA-Pre 通过将完整动量矩阵分解为紧凑低秩子空间，显著压缩优化器内存占用，同时保持优化性能。
我们通过从 Llama 系列模型（参数量从 60M 到 1B）的预训练实验验证了 LoRA-Pre 的有效性：其在所有模型规模下均取得最优性能；尤其值得注意的是，LoRA-Pre 展现出卓越的秩效率，仅需基线方法 1/8 的秩即可达到相当或更优结果。
除预训练外，我们还在微调场景中评估了 LoRA-Pre。在相同秩下，LoRA-Pre 持续超越所有高效微调基线方法：相比标准 LoRA，在 Llama-3.1-8B 和 Llama-2-7B 上分别提升 3.14 和 6.17 分，验证了本方法在预训练与微调双范式中的有效性。

1 引言
大语言模型（LLMs）（Guo 等，2025；Yang 等，2025；Grattafiori 等，2024；Brown 等，2020；Comanici 等，2025；Touvron 等，2023；Jaech 等，2024）已成为现代深度学习的核心。其在异构来源的万亿级 token 上训练，参数量达前所未有的规模，展现出卓越的泛化与迁移能力；部分模型还具备推理能力并可调用外部工具（Guo 等，2025；Yang 等，2025）。这些进展使 LLMs 从统计学习器演变为多功能系统，推动了科研与实际应用的突破。
然而，LLMs 的成功伴随着高昂的训练与适配成本（Grattafiori 等，2024）。海量可训练参数在预训练与微调阶段均需巨大内存与算力资源，其中优化器状态是关键负担来源。例如，Adam（Kingma 和 Ba，2015）——LLM 训练的事实标准优化器——除模型权重外，还需维护梯度的一阶与二阶动量估计，使内存占用增至三倍，进一步加剧可扩展性瓶颈，凸显了高效优化策略的迫切需求。
为应对该挑战，一系列低秩优化方法相继涌现。其中代表性工作通过投影梯度下降实现优化器状态压缩（Zhao 等，2024；Chen 等，2024；Hao 等，2024；Modoranu 等，2025）：此类方法通过 SVD 或随机映射初始化投影矩阵，将梯度投影至低维子空间进行优化器状态计算，再投影回原空间以更新参数，从而压缩优化开销；此外，还需周期性更新子空间以实现高秩参数更新（W = ΔW_{T₁} + ΔW_{T₂} + ⋯）。然而，因子空间无法即时更新，状态计算中易产生误差累积，导致性能次优。这促使我们寻求一种能快速适应变化梯度子空间的动态新方法。
本文提出 LoRA-Pre——一种面向 LLM 预训练的新型低秩优化器，通过全新视角解决上述局限。核心洞见在于：动量的 EMA 更新与线性回归存在有趣的数学等价性。具体而言，我们证明 EMA 动量更新等价于在在线梯度流上以梯度下降训练线性回归器：
m ← β·m + (1−β)·g ⟺ minₘ L(m;g) = ½‖m−g‖F²，
其中 m ∈ ℝ^{p×q} 为动量，g 为在线梯度，β 为动量系数。该等价性揭示：动量累积可视为用线性模型拟合梯度历史。
基于此理论洞见，我们通过低秩分解压缩动量项，构建高效优化器：不再维护完整动量矩阵 m，而是将其分解为两个低秩矩阵乘积 m = m_B·m_A（m_B ∈ ℝ^{p×r}, m_A ∈ ℝ^{r×q}, r ≪ min(p,q)），将内存复杂度从 p×q 降至 (p+q)×r，大幅节省大规模模型内存。低秩动量通过求解 min{m_B,m_A} L(m_B,m_A;g) = ½‖m_B m_A − g‖_F² 更新，其显式更新规则见定理 3.1。
该理论框架可压缩任意动量型优化器。我们通过为 Adam（Kingma 和 Ba，2015）与 Muon（Jordan 等，2024）开发 LoRA-Pre 变体验证其通用性，详细算法见附录 B。
广泛的预训练与微调实验验证了本方法的有效性，消融实验则证明其在不同秩设置下的强鲁棒性。主要贡献如下：
• 建立新理论连接：证明 EMA 动量更新等价于在线梯度流下的线性回归训练；
• 基于此提出 LoRA-Pre——一种面向预训练的高效低秩优化器，通过低秩分解压缩优化器状态；为 Adam 与 Muon 构建变体，基于回归框架导出低秩更新规则，在大幅减存同时保持优化动态；
• 在预训练与微调任务中提供充分实验验证：LoRA-Pre 在各类模型规模与应用场景下均以显著秩效率（仅需基线 1/8 或更低）实现更优性能，证实其高效性与有效性。

2 相关工作
低秩自适应（Low-Rank Adaptation）。LLM 规模扩张推动了参数高效微调（PEFT）方法发展（Hu 等，2022；Liu 等，2024；Wang 等，2025；Ding 等，2023；Liu 等，2022；2023；Hayou 等，2024；Wang 等，2024a；Edalati 等，2023；Zhang 等，2023；Tastan 等，2025；Wang 等，2023；2024c；2024b），旨在以低计算/内存开销适配预训练模型至下游任务。其中，低秩自适应（LoRA）（Hu 等，2022）及其变体（Wang 等，2025；2024a；Hayou 等，2024；Liu 等，2024；Yen 等，2025）已成为主流。LoRA 基于微调中权重更新具有内在低秩结构的原理（Aghajanyan 等，2021），通过将更新重参数化为两低秩矩阵乘积，大幅减少可训练参数量，同时保持竞争力性能，实现 LLM 在有限资源下的高效适配。LoRA 的有效性激发了一系列改进研究：LoRA+（Hayou 等，2024）引入两低秩矩阵的差异化学习率以改善收敛与最终性能；DoRA（Liu 等，2024）将预训练权重分解为幅值与方向分量，仅对方向分量施加 LoRA 以更好捕捉微调动态；近期工作如 LoFT（Tastan 等，2025）与 LoRA-Pro（Wang 等，2025）通过投影梯度等价性建立 LoRA 与全量微调的理论联系。
然而，现有 LoRA 方法应用于从零预训练时面临根本挑战：微调中微小调整自然呈现低秩结构，而从随机初始化预训练需全秩权重更新以学习全参数空间的多样化表征（Lialin 等，2024；Kamalakara 等，2022），LoRA 的低秩假设与预训练全秩需求不匹配，导致预训练阶段性能次优。

低秩预训练。LLM 预训练成本随模型规模激增而大幅上升。缓解成本的有前景方向是将优化器状态压缩至低秩子空间，显著降低内存占用与通信开销（Zhao 等，2024；Modoranu 等，2025；Ma 等，2025；Han 等，2024；Zmushko 等，2025；Chen 等，2024；Hao 等，2024；Shen 等，2025；Mahdavinia 和 Mahdavi，2025；Zhang 等，2025）。例如，GaLore（Zhao 等，2024）利用 SVD 将梯度信息投影至低秩子空间进行状态压缩，再将优化梯度投影回原空间更新参数；Flora（Hao 等，2024）以随机投影替代昂贵的 SVD 操作；Fira（Chen 等，2024）引入 SGD 动量以利用互补子空间梯度信息。然而，这些投影方法通常依赖周期性子空间更新以摊销成本，导致子空间适应滞后，引发优化不连续与误差累积。近期工作探索在线策略：MLorc（Shen 等，2025）采用随机 SVD 进行动量在线压缩；MoFaSGD（Mahdavinia 和 Mahdavi，2025）利用动量分解在线逼近全秩动量，确保非凸收敛；ADAPM（Zhang 等，2025）通过线性回归将一阶动量压缩至低秩子空间。相较之下，本文提出的 LoRA-Pre 将动量维护根本性重构为在线回归任务，通过每步直接演化低秩因子实现连续子空间适应，有效消除周期更新或启发式近似带来的不稳定性。

3 方法
3.1 预备知识
图 1：LoRA-Pre 方法示意图。
本文建立新连接：优化器动量的指数移动平均（EMA）更新在数学上等价于用在线梯度下降训练线性回归器。利用该等价性，我们提出用低秩矩阵压缩优化器状态（即动量）以降低内存占用，其闭式更新规则见定理 3.1。
我们首先回顾 Adam（Kingma 和 Ba，2015）——现代深度学习的事实标准优化器，其结合 AdaGrad（Duchi 等，2011）与 RMSProp（Hinton 等，2012）优势，通过维护梯度一阶与二阶矩估计实现自适应学习率与鲁棒性能。
考虑优化问题：x_t ∈ 𝒳 为从分布 p_data 中抽取的数据点，ℒ(·): 𝒳 → ℝ 为损失函数，θ ∈ ℝ^d 为优化参数。Adam 更新 θ 的步骤如下：
g_t = ∂ℒ(x_t)/∂θ, x_t ∼ p_data(x), （梯度计算）
m_t = β₁·m_{t−1} + (1−β₁)·g_t, （一阶矩 EMA）
v_t = β₂·v_{t−1} + (1−β₂)·g_t², （二阶矩 EMA）
m̂t = m_t/(1−β₁^t), v̂_t = v_t/(1−β₂^t), （偏置校正）
θ{t+1} = θ_t − γ/(√v̂_t + ε) · m̂_t. （参数更新）
其中 m_t 与 v_t 分别为一阶与二阶矩的 EMA。超参数包括学习率 γ、动量估计的指数衰减率 β₁, β₂ ∈ [0,1) 及小常数 ε > 0 保证数值稳定性。类似 Adam，动量在其他现代优化器（Shazeer 和 Stern，2018；Jordan 等，2024）中亦至关重要，可提升稳定性与收敛性，但存储动量状态带来显著内存开销。本文直接通过压缩动量项以降低优化器内存占用。

3.2 你的动量是一个秘密的在线线性回归器
我们揭示一个有趣连接：现代优化器中的动量更新实则在秘密执行在线线性回归。具体而言，通过 EMA 更新动量 m 等价于以在线梯度流优化 m 作为线性回归器参数。以一阶动量为例，标准 EMA 更新可重写为：
m_{t+1} = β·m_t + (1−β)·g = m_t − (1−β)·(m_t − g)，
即等价于梯度下降步骤：优化参数为动量 m，学习率为 (1−β)，梯度为 ∂L(m_t;g)/∂m = m_t − g。该重构揭示 EMA 更新本质上是持续根据输入梯度调整动量权重的在线线性回归器，其最小化目标为：
minₘ L(m;g) = ½·‖m−g‖_F²。
此洞见为优化器足迹优化开辟新路径：既然动量参数即线性模型权重，可应用标准模型压缩技术降低训练中优化器内存占用。

3.3 LoRA-Pre：低秩在线线性回归
现介绍 LoRA-Pre——一种面向预训练的新低秩优化器。基于 EMA 与在线线性回归的等价性，LoRA-Pre 通过低秩分解压缩动量项 m（灵感源于 LoRA 技术 Hu 等，2022），可应用于任意动量型优化器（如 Adam 与 Muon）。
一阶动量压缩：由 3.2 节知，动量更新等价于 minₘ L(m;g) = ½·‖m−g‖F² 的梯度下降，可应用低秩压缩。不再直接存储更新完整动量矩阵 m ∈ ℝ^{p×q}，而是分解为两低秩矩阵乘积 m = m_B·m_A（m_B ∈ ℝ^{p×r}, m_A ∈ ℝ^{r×q}, r ≪ min(p,q)），将原问题转化为：
min{m_B,m_A} L(m_B,m_A;g) = ½·‖m_B m_A − g‖_F²。
为保持内存效率，对分解矩阵 m_B 与 m_A 应用标准梯度下降；为确保计算效率，推导无需反向传播的闭式更新规则（定理 3.1），采用牛顿法因其可自然呈现 EMA 形式。

定理 3.1。假设 m_B ∈ ℝ^{p×r} 与 m_A ∈ ℝ^{r×q} 均为满秩，则对目标 min_{m_B,m_A} L(m_B,m_A;g) = ½·‖m_B m_A − g‖_F²，牛顿法给出以下闭式更新规则：
m_B ← (1−γ₁)·m_B + γ₁·g m_A^T (m_A m_A^T)^{-1},
m_A ← (1−γ₁)·m_A + γ₁·(m_B^T m_B)^{-1} m_B^T g。
其中 γ₁ 为分解优化问题的学习率。

二阶动量压缩。二阶动量 v 的压缩更具挑战，因 Adam 参数更新规则要求其平方根 √v 存在，故 v 必须逐元素为正。朴素方法将 v 参数化为 v = v_B·v_A 并以回归损失 L(v_B,v_A;g) = ½·‖v_B v_A − g²‖F² 优化，但无法保证 v{i,j} > 0，导致 √v 计算困难。为此，我们将二阶动量重参数化为 v = (v_B v_A)^{∘2}（∘ 表示 Hadamard 积），确保逐元素正性同时保持低秩结构，优化目标为：
min_{v^B,v^A} L(v_B,v_A;g) = ½·‖v_B v_A − |g|‖_F²，
其更新规则可直接由定理 3.1 导出：
v_B ← (1−γ₂)·v_B + γ₂·|g| v_A^T (v_A v_A^T)^{-1},
v_A ← (1−γ₂)·v_A + γ₂·(v_B^T v_B)^{-1} v_B^T |g|。

低秩优化器算法。如前所述，本方法可应用于任意含动量优化器，压缩其在预训练与微调阶段的优化器状态。AdamW（Kingma 和 Ba，2015）与 Muon（Jordan 等，2024）的 LoRA-Pre 详细伪代码见附录 B。

5 结论
本文提出 LoRA-Pre——一种新型低秩高效优化器。我们证明 EMA 动量更新等价于在线梯度流上的线性回归训练。基于此，提出通过低秩分解压缩动量项，导出保持 EMA 形式且在压缩参数空间运行的更新规则。提供 LoRA-Pre Adam 与 LoRA-Pre Muon 两种变体。广泛的预训练与微调实验表明，LoRA-Pre 在所有评估任务与模型规模下均实现竞争性或更优性能；尤其值得注意的是，其秩鲁棒性优异，仅需基线方法 1/8 或更低秩即可达相当结果；该方法可有效泛化至各类优化器，是内存高效优化的通用解决方案。

附录 A 理论结果证明
定理。假设 m_B ∈ ℝ^{p×r} 与 m_A ∈ ℝ^{r×q} 均为满秩，则对目标 min_{m_B,m_A} L(m_B,m_A;g) = ½·‖m_B m_A − g‖_F²，牛顿法给出以下闭式更新规则：
m_B ← (1−γ₁)·m_B + γ₁·g m_A^T (m_A m_A^T)^{-1},
m_A ← (1−γ₁)·m_A + γ₁·(m_B^T m_B)^{-1} m_B^T g。
其中 γ₁ 为分解优化问题的学习率。

证明。目标推导 min_{m_B,m_A} L(m_B,m_A;g) = ½·‖m_B m_A − g‖F² 的牛顿法更新规则。首先计算一阶梯度：
∂L/∂m_B = (m_B m_A − g) m_A^T,
∂L/∂m_A = m_B^T (m_B m_A − g)。
牛顿法需二阶导数（Hessian 矩阵）：
H{BB} = m_A m_A^T ⊗ I_p,
H_{AA} = I_q ⊗ m_B^T m_B。
求解 H·d = ∇L 得牛顿方向：
d_{m_B} = m_B − g m_A^T (m_A m_A^T)^{-1},
d_{m_A} = m_A − (m_B^T m_B)^{-1} m_B^T g。
应用学习率 γ₁ 得更新：
m_B ← (1−γ₁)·m_B + γ₁·g m_A^T (m_A m_A^T)^{-1},
m_A ← (1−γ₁)·m_A + γ₁·(m_B^T m_B)^{-1} m_B^T g。
最终表达式揭示牛顿法自然产生 EMA 形式更新，体现其本质特性。

附录 B LoRA-Pre 详细算法
B.1 Adam 的 LoRA-Pre 算法
一阶动量更新：对参数化 m = m_B m_A，更新规则为：
m_B′ ← (1−γ₁)·m_B + γ₁·g m_A^T (m_A m_A^T)^{-1},
m_A′ ← (1−γ₁)·m_A + γ₁·(m_B^T m_B)^{-1} m_B^T g。
默认 1−γ₁ = √β₁ 以保持 EMA 系数一致性。
二阶动量更新：对参数化 v = (v_B v_A)^{∘2}，更新规则为：
v_B′ ← (1−γ₂)·v_B + γ₂·|g| v_A^T (v_A v_A^T)^{-1},
v_A′ ← (1−γ₂)·v_A + γ₂·(v_B^T v_B)^{-1} v_B^T |g|。
默认 1−γ₂ = β₂^{0.25}。
完整算法见算法 1（Adam 与 LoRA-Pre Adam 对比）。

B.2 Muon 的 LoRA-Pre 算法
Muon 更新可重写为 m′ = μ·m + g = m − (1−μ)·(m − g) + μ·g，等价于优化问题：
L(m;g) = ½·‖m−g‖_F² − μ/(1−μ)·⟨m,g⟩_F。
应用低秩分解 m = m_B m_A 后，牛顿法更新为：
m_B′ ← (1−γ₁)·m_B + γ₁/(1−μ)·g m_A^T (m_A m_A^T)^{-1},
m_A′ ← (1−γ₁)·m_A + γ₁/(1−μ)·(m_B^T m_B)^{-1} m_B^T g。
默认 1−γ₁ = √μ。
完整算法见算法 2（Muon 与 LoRA-Pre Muon 对比）。

附录 C 近似误差与收敛性理论分析
C.1 问题设定与算法动态
考虑无约束优化 min_{θ∈ℝ^{p×q}} f(θ)，g_t = ∇f(θ_{t−1}) 为第 t 步随机梯度。标准 Adam 状态为 m_t, v_t，LoRA-Pre Adam 有效状态为 m̃t, ṽ_t。
标准 Adam 动态：
m_t = β₁·m{t−1} + (1−β₁)·g_t,
v_t = β₂·v_{t−1} + (1−β₂)·g_t^{∘2}。
LoRA-Pre 动态：维护低秩因子 (m_{B,t}, m_{A,t}) 近似梯度历史，精确同步更新（在线最小二乘）为：
m_{B,t} = (1−γ₁)·m_{B,t−1} + γ₁·g_t m_{A,t−1}^†,
m_{A,t} = (1−γ₁)·m_{A,t−1} + γ₁·m_{B,t−1}^† g_t，
其中 m_A^† = m_A^T (m_A m_A^T + λ·I)^{-1} 等为 Tikhonov 正则化伪逆。
定义投影算子：𝒫_A = m_{A,t−1}^† m_{A,t−1}（行空间投影），𝒫_B = m_{B,t−1} m_{B,t−1}^†（列空间投影）。令 m̂t = m{B,t} m_{A,t} 为低秩历史重构。
有效动量用于参数更新：
m̃t = β₁·m̂{t−1} + (1−β₁)·g_t,
ṽt = β₂·(ĥ{t−1})^{∘2} + (1−β₂)·g_t^{∘2}。

C.2 假设
假设 1（正则性与有界性）：
1. L-光滑性：‖∇f(x)−∇f(y)‖F ≤ L‖x−y‖_F；
2. 梯度有界：‖g_t‖_F ≤ G, ‖g_t‖∞ ≤ G_∞；
3. 更新映射 ϕ(m,v) = m/√(v+ε) 关于 m 与 v 的 Lipschitz 常数分别为 L_m = 1/√ε, L_v = G/(2ε^{1.5})。
假设 2（子空间逼近能力）：梯度动态具有低秩结构，存在 δ ≥ 0 使得：
‖g_t − (𝒫_{B,t} g_t + g_t 𝒫_{A,t})‖F ≤ δ,
‖|g_t| − (𝒫{B,t} |g_t| + |g_t| 𝒫_{A,t})‖_F ≤ δ。
假设 3（参考优化器下降性）：标准全秩 Adam 更新方向 u_t = m_t/(√v_t + ε) 在期望下为有效下降方向：𝔼[⟨∇f(θ_t), u_t⟩] ≥ c 𝔼[‖∇f(θ_t)‖_F²]（c > 0）。

C.3 因子重构误差有界性
引理 C.1。令 ℰ_t^m = ‖m_t − m̂_t‖_F，在假设 1 与 2 下，ℰ_t^m 一致有界于常数 ℰ_bound。

证明概要。严格满足时间尺度对齐条件 β₁ = (1−γ₁)²。展开 LoRA 动态得：
m̂t = β₁ m̂{t−1} + (1−√β₁)√β₁ (𝒫_B g_t + g_t 𝒫_A) + (1−√β₁)² Q_t。
误差动态满足 ℰ_t^m ≤ β₁ ℰ_{t−1}^m + Δ_res，其中 Δ_res 为残差项。因 0 ≤ β₁ < 1，几何级数收敛至稳态：
lim_{t→∞} ℰ_t^m ≤ Δ_res / (1−β₁) = ℰ_bound。

C.4 联合有效动量误差
引理 C.2。令 Δ_m = ‖m_t − m̃t‖_F, Δ_v = ‖v_t − ṽ_t‖_F，则：
Δ_m ≤ β₁ ℰ_bound,
Δ_v ≤ β₂ (2G∞ ℰ_bound + σ_total²)，
其中 σ_total² = √d/4 · G_∞² 由 Popoviciu 不等式导出。

证明概要。第一矩误差：m_t − m̃t = β₁ (m{t−1} − m̂{t−1})，直接得 Δ_m ≤ β₁ ℰ_bound。
第二矩误差：v_t − ṽ_t = β₂ [v{t−1} − (ĥ_{t−1})^{∘2}]，引入辅助变量 h_{t−1}（梯度幅值的精确 EMA），分解误差为：
Term I（固有方差）：由 Popoviciu 不等式，|v_{t−1,j} − (h_{t−1,j})²| ≤ ¼ G_∞²，Frobenius 范数上界为 √d/4 G_∞²；
Term II（近似误差）：由均值定理，|(h_{t−1,j})² − (ĥ_{t−1,j})²| ≤ 2G_∞ |h_{t−1,j} − ĥ_{t−1,j}|，得 Term II ≤ 2G_∞ ℰ_bound。

C.5 收敛性分析
定理 C.3。设步长 η_t = η/√t，在假设 1,2,3 下，LoRA-Pre Adam 收敛至驻点邻域：
min_{1≤t≤T} 𝔼[‖∇f(θ_t)‖²] ≤ C_init/√T + C_noise (ℰ_bound + σ_total²)²，
其中 C_init 依赖初始函数间隙，C_noise 依赖更新规则的 Lipschitz 常数。

证明概要。更新方向误差 ξ_t = ‖u_t − ũt‖_F ≤ K₁ ℰ_bound + K₂ σ_total² = ξ_total（均匀确定上界）。
利用 L-光滑性，期望下降不等式为：
𝔼_t[f(θ{t+1})] ≤ f(θ_t) − (c η_t /2) ‖∇f‖² + (η_t /2c) ξ_total² + (L η_t² /2) G_step²。
求和并除以 S_T = ∑η_t ≥ √T，得：
min_t 𝔼[‖∇f‖²] ≤ 2(f(θ₁)−f*)/(c S_T) + ξ_total²/c² + (L G_step² /c) (∑η_t² / S_T)。
因 η_t = η/√t，S_T ≥ √T, ∑η_t² ≈ ln T，当 T→∞ 时前两项消失，留下误差阈值：
min_t 𝔼[‖∇f‖²] ≤ C_init/√T + C_noise (ℰ_bound + σ_total²)²。

D.1 超参数敏感性分析：β 与 γ 的耦合
LoRA-Pre Adam 的关键设计原则是低秩更新系数 (γ₁, γ₂) 并非独立超参数，而是与标准 Adam 动量系数 (β₁, β₂) 解析耦合以确保一致衰减动态。
推导耦合策略：重构有效全秩动量 m ≈ m_B m_A，有效衰减率近似为个体衰减率乘积：
m′ = m_B′ m_A′ ≈ (1−γ₁)² m。
为与标准 Adam（动量衰减 β₁）对齐，施加耦合约束 (1−γ₁)² = β₁；对二阶动量，因 LoRA-Pre 先近似梯度幅值再平方，衰减率复合两次，得 (1−γ₂)⁴ = β₂。
