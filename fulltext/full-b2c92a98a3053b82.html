Arcade工具推荐系统省37%输入token成本

📅 2026-10-17 📄 VentureBeat AI 🔗 原文链接

原标题：New Tool Recommendation system cuts your firm's input token costs by 37%, according to Arcade.dev

中文摘要： Arcade.dev推出工具推荐功能，帮助AI智能体按需发现工具，避免反复加载庞大工具目录。公司称工具发现token最多减少91%，建模输入成本节省达37%；408个会话实测显示总token费用降低7.6%。功能通过MCP网关工作，兼容多模型，10月15日起向Arcade Cloud客户免费开放。微软等巨头已有类似方案，Arcade的差异在于将工具发现与权限控制、审计打包。

太平洋时间 2026 年 10 月 15 日上午 9:00

Arcade.dev 是一家帮助 AI 智能体在企业软件中工作、同时控制其被允许执行哪些操作的初创公司。该公司正在推出“工具推荐”功能，帮助智能体找到正确的操作，而无需在对话中反复加载冗长的软件功能列表。

此次发布针对企业 AI 的一个实际问题：将智能体连接到更多业务系统，也会使其指令变得更大、更昂贵。

Arcade.dev（也简称"Arcade"）表示，其方法可将用于工具发现的 token 减少多达 91%，建模的输入成本节省可达 37%。

在一项针对完整工作流的单独测试中，该公司报告了一个较小但更直接适用的结果：输入/输出合并 token 账单减少 7.6%。

Arcade 发言人告诉 VentureBeat，该功能将于 10 月 15 日向公司 Arcade Cloud 全托管软件即服务（SaaS）平台的客户开放，且不收取单独的功能费用。

该公司的常规平台费和使用费仍适用于付费计划，而企业部署（包括本地部署）则单独定价。

Arcade 进入的市场中，微软、Anthropic 和 OpenAI 已经提供了按需发现工具的方式。它的卖点是将这种能力与一个运行时相结合——该运行时可检查权限、应用公司策略，并跨不同模型记录智能体活动。

Arcade 已经做了什么，以及谁在使用它

首先要理解的是，Arcade 不是聊天机器人，也不是新的大语言模型。

它提供幕后软件，使由 Claude 或 ChatGPT 等模型驱动的 AI 智能体能够在工作场所系统中采取行动。

例如，当智能体需要更新 Salesforce 记录或通过 Gmail 发送电子邮件时，Arcade 可以将其连接到应用程序，检查员工和智能体是否有权执行该操作，处理必要的凭证，并记录所发生的情况。

该公司现有的平台整合了三项核心能力：

  • 为 AI 智能体进行安全和权限检查
  • 提供现成的软件操作目录，以及供开发者构建自己操作的工具
  • 为管理员提供集中控制，以管理和审计智能体采取的操作

其 MCP 网关可以在单一连接背后汇集来自 Arcade 和其他提供商的工具。MCP 即模型上下文协议，是一种将 AI 助手与外部应用程序连接的新兴通用方式。Arcade 还于 10 月 7 日推出了私有注册表，让员工可以查看其智能体可使用哪些工具，并请求缺失的工具。

Arcade 列出了 LangChain、Relevance AI、Snyk 和 Sybill 等使用其技术的组织，并发布了这些公司代表的推荐语。

其网站还展示了 Duracell 和 YUR，以及它描述为一家财富 100 强金融机构和一家纳斯达克 100 指数消费互联网公司的未具名客户。这些参考并不能证明任何具名客户已实现新功能所报告的 token 节省。

联合创始人兼首席技术官 Sam Partee 于 7 月在 VentureBeat Transform 2026 创新展示会上展示了 Arcade 的安全和监督技术。

在那次活动上，他描述了该平台如何让智能体以适当的用户权限行事，同时让其活动对安全团队保持可见。

新的工具推荐系统建立在现有基础设施之上：除了确定智能体是否可以行动之外，Arcade 现在还希望让智能体更容易、更低成本地识别应采取什么行动。

为什么智能体的工具列表会成为一项业务开支

工具是一个可调用的函数：搜索收件箱、检索客户记录、更新工单或创建文档。智能体在选择和使用这些功能之前，需要这些功能及其所需输入的描述。

根据 Arcade 的公告，其目录包含超过 8,000 个工具。

在用户提交请求之前，描述整个清单将消耗大约 175 万个 token。即使是小得多的目录，随着交互的持续也会产生反复出现的开销。

工具推荐用几个入口点取代了该清单，用于发现应用程序、请求相关函数和执行选定的操作。智能体描述其即时需求；Arcade 搜索并对目录进行排名，返回一份简短列表，并运行选定的函数。

Arcade 使用更小的专用模型来匹配和排名相关工具，而不是让更大的 AI 模型反复阅读整个目录。它不会取代智能体的底层智能：智能体自身的模型仍然决定执行哪项建议的操作。

Partee 在一次独家采访中告诉 VentureBeat，Arcade 基于开源生态系统中的较小模型以及智能体所采取操作的数据进行构建。

“我们能够利用这些数据训练小型语言模型，基本上可以预测你接下来想做什么，”他在接受 VentureBeat 采访时说。

他说，与针对个人定制的社交媒体信息流不同，许多智能体任务属于更宽泛的类别，例如发送电子邮件、编辑草稿或更新 Salesforce 记录。

Partee 将这项工作追溯到一个早期的站点可靠性工程智能体，当时语言模型经常难以选择工具并格式化其输入。

“如果你当时给一个模型五个工具，它也生成不出正确的 JSON，”他回忆道。

随着模型的改进，同样的推荐方法可以更广泛地应用于选择操作以及提供执行这些操作所需的输入。

这对于跨越多个系统的工作可能很重要：一个续订流程可能需要客户数据、支持历史、财务信息和起草的回复。工具发现允许不同的功能在需要时进入交互。这是否能改善特定工作流，取决于简短列表的质量和额外搜索的成本。

Arcade 表示，工具推荐通过 MCP 工作，可以在其网关（智能体与其可用工具之间的连接点）开启，而无需重建现有集成。该公司表示，它可以跨多个模型、智能体构建框架和支持 MCP 的应用程序工作。这一点很重要，因为客户不必为了使用推荐系统而更换 Claude、ChatGPT 或他们自己的智能体。

37% 的声明与实测的 7.6% 结果描述的是不同的事情

Arcade 的方法论做了几项企业买家应当留意的区分。

最大 37% 的降幅来自针对一个配备 100 个固定工具的助手进行输入成本建模。对于包含三个请求、每个请求约八次工具调用的典型交互，Arcade 估计节省约为 20%，具体取决于模型。

Partee 在采访中给出了类似的估计：“你只需作为一个普通用户进行一次 10 轮对话，就能节省 18% 到 20% 的 token。”

该数字描述的是代表性会话的预期 token 减少，而不是企业客户总账单中经独立验证的节省。

该计算不包括输出 token，并假设客户端将大型工具结果保留在对话之外。当这些结果留在交互中时，公司估计节省仅为 5% 到 7%。短交互产生最大的建模百分比改进。

其对 1,000 名 Claude Opus 5 用户每年节省约 119,000 美元的预测，假设每人每月进行 20 次对话。这是一个情景估计，而非来自具名客户部署的报告节省。

91% 的声明有一个更窄的分母。它涉及与函数描述和推荐响应相关的输入 token，基于建模的 10 轮交互，不包括对话本身和返回的业务数据。

在该计算中，GPT-5.6 的计数从 256,650 降至 22,164；Claude Opus 5 的计数从 411,729 降至 38,170。

“这些是定义 token 的节省，而不是整个会话的节省，”Arcade 在随公告发布的方法论中写道。

更全面的测试在 408 个会话中对 64 个工作流进行了有无工具发现的配对测试，使用 Codex 和 Claude Code。Arcade 报告总 token 费用（包括输入和输出）减少 7.6%，95% 区间为 2.5% 至 12.6%，任务完成率不变。

Claude Code 的报告降幅为 9.7%，Codex 为 5.5%；Codex 的区间包含零。VentureBeat 尚未独立复现这些测试。

Partee 承认，反复调用推荐系统可能消耗足够多的资源，从而抵消节省，甚至使交互变得更昂贵。他坚持认为这种情况并不常见，但没有提供关于其发生频率的独立可验证数据。

其与微软的比较需要另一个限定条件

Arcade 还使用公共基准 ToolRet 评估工具检索。

Recall@10 衡量所需工具中有多少出现在返回的前十个结果中。它并不衡量整个业务任务的完成情况。

Arcade 提供了以下数据，以展示其工具推荐系统与现有竞争对手 Microsoft Foundry 的对比：

ToolRet 类别 Arcade 报告的 Recall@10 Microsoft Foundry 公布的 Recall@10
Web 56.81% 45.99%
Code 57.25% 39.56%
Customized（自定义） 42.65% 41.36%

来源：Arcade 的公告图表和微软公布的评估。这些运行使用了不同的设置。

Arcade 的生产设置包括一个额外的排名阶段和基准指令字符串。

微软的测试省略了指令字符串，以避免使用另一次模型调用生成它所带来的费用和延迟。微软还描述了一种在服务期间避免使用资源密集型排名模型的检索方法。

Arcade 承认，该比较表明的是潜在优势，而非确立了受控的正面交锋结果。这些分数值得测试，但并不能证明 Arcade 比 Foundry 提供更好的任务完成率或更低的总成本。

微软、Anthropic 和 OpenAI 已经在解决工具发现问题

微软的 Foundry Toolboxes 方法公开搜索和执行入口点，然后提供匹配的定义。微软将其描述为独立于特定模型系列，并能够跨越不同的工具来源。因此，模型灵活性并非 Arcade 独有。

Anthropic 的工具搜索工具同样将定义的加载推迟到 Claude 需要它们时。其实现支持内置的文本搜索方法以及自定义检索。Anthropic 在自己的示例中报告了 85% 的 token 减少，但该示例使用的基线与 Arcade 的测量不同。

OpenAI 的 Responses API 支持延迟函数和 MCP 工具，具有托管式或由应用程序执行的搜索。其文档称，新发现的定义在上下文末尾进入以保留缓存；支持从 GPT-5.4 开始。

Arcade 强调的区别在于，将发现与执行控制打包在一个客户可跨其选定的 AI 系统使用的层中。

据该公司称，该层会检查用户的权限和智能体被允许的操作，将凭证保持在模型上下文之外，在调用前后应用策略钩子，并通过 OpenTelemetry 提供审计记录。这些钩子还可以支持敏感数据检查。

Partee 表示，这种方法还让 Arcade 能够适应更新的前沿模型，而无需为每家供应商重建其推荐系统。

他说，在大约三到四次主要模型发布之后，该技术的行为基本保持一致。“每次新模型发布时，我们都应该能够在一周内保证达到同等水平，”他说。

这是一个前瞻性的期望，而不是经过独立测试的服务保证；他还提醒说，该技术正在快速变化。他表示，该功能可以在 Claude、ChatGPT 和其他智能体环境中工作。

Arcade 的现有价格为新的节省声明提供了背景

Arcade 已经对其底层平台收费，公开价格基于使用量而非员工人数。其公布的选项包括：

Arcade 计划 公布价格 包含的服务和使用条款
Free（免费版） 每月 0 美元 Arcade Cloud 上每月 2,000 次授权事件和 2,000 次工具调用，提供社区支持。
Team（团队版） 每月 25 美元，外加使用费 每次授权事件 0.10 美元，每次工具调用 0.01 美元；托管在 Arcade Cloud 上，提供次个工作日电子邮件支持。
Enterprise（企业版） 定制报价 授权事件和工具调用的年度捆绑包、批量折扣、云/私有云/隔离部署选项、24/7 支持和额外的治理控制。

授权事件与将智能体连接到用户账户有关；工具调用是智能体为执行特定操作而发出的请求。这些公布的费用涵盖 Arcade 的平台，不包括客户可能为其智能体所依赖的大语言模型支付的单独费用。

Arcade 表示，工具推荐本身不会为 Arcade Cloud 用户增加单独的功能费用。这不应与无限免费使用混为一谈：Team 计划的客户仍需为授权事件和工具调用支付正常费用。Arcade 还在客户控制的云、本地和隔离环境中提供其底层平台。新推荐功能的单独企业版推广已在计划中，但该公司尚未公布这些部署的价格或具体推广时间表。

Partee 将大型组织描述为商业重点，尤其是那些为跨员工队伍的智能体安全和管理向 Arcade 付费的组织。对于这些客户，他说：“是的，我会要求人们为此付费。”他的言论涉及企业部署，而非免费包含在标准 Arcade Cloud 中的功能。

这意味着 AI 模型 token 的减少并不会自动转化为企业总 AI 支出相同百分比的减少。买家还必须考虑 Arcade 的平台费和按操作收费、任何企业许可成本，以及运营自己基础设施的成本。Arcade 尚未提供任何具名客户对新功能的全部成本对比。

该功能也不一定对每个智能体都自动具有经济性。Arcade 自己的建模更有利于大约 25 到 28 个工具以下的固定工具列表。对于更大的清单，买家需要在自己的工作负载上测量搜索开销、完成率和最终账单。

对于使用多个业务应用程序和 AI 模型的公司来说，实际的主张比 token 节省更为宽泛：Arcade 旨在提供一个统一的地方来决定智能体可以做什么，将其连接到发生工作的系统，记录其操作，并且现在还能建议相关工具，而不会让 AI 的对话变得杂乱。其材料中最有力的证据是完整工作流成本的实测降幅；更大的百分比则解释了在特定假设下可能产生额外节省的空间。
