记忆缓存：具备增长记忆的RNN

📅 2026-02-27 📄 arxiv 🔗 原文链接

原标题：Memory Caching: RNNs with Growing Memory

中文摘要： 本文提出记忆缓存（MC）技术，通过缓存RNN记忆状态的检查点，使其有效记忆容量随序列长度增长，从而在RNN的𝒪(L)复杂度与Transformer的𝒪(L²)复杂度之间提供灵活权衡。MC包含四种变体（如门控残差记忆、稀疏选择缓存等），实验表明其显著提升循环模型在语言建模、长上下文理解与检索任务中的性能，缩小与Transformer的差距。

记忆缓存：具备增长记忆的RNN Ali Behrouz¹,²,† Zeman Li¹,³ Yuan Deng¹ Peilin Zhong¹ Meisam Razaviyayn¹,³ Vahab Mirrokni¹ ¹ Google Research ² University of Southern California ³ University of California, Los Angeles † 通讯作者：alibehrouz@google.com

**摘要** Transformer已成为近期序列建模诸多进展的事实标准骨干网络，主要归功于其随上下文长度增长的记忆容量。尽管该特性在检索任务中表现良好，却导致了二次复杂度，从而推动了近期对可行的次二次循环替代方案的研究。尽管在多个领域展现出初步前景，此类循环架构在高召回率任务中仍逊于Transformer，常被归因于其固定大小的记忆。本文提出**记忆缓存**（Memory Caching, MC），一种简单而有效的技术，通过缓存RNN记忆状态（即隐藏状态）的检查点来增强循环模型。MC使RNN的有效记忆容量随序列长度增长，提供了在RNN的固定记忆（𝒪(L)复杂度）与Transformer的递增记忆（𝒪(L²)复杂度）之间灵活插值的权衡。我们提出了四种MC变体，包括门控聚合与稀疏选择机制，并讨论其在线性与深度记忆模块中的影响。在语言建模与长上下文理解任务上的实验结果表明，MC显著提升了循环模型性能；在上下文内召回任务中，尽管Transformer准确率最高，但MC变体展现出竞争力，显著缩小与Transformer的差距，并优于现有最先进循环模型。

**1 引言** Transformer（Vaswani等，2017）是近期机器学习在各领域取得突破的基础（Jumper等，2021；Dosovitskiy等，2021；Comanici等，2025）。其成功常归因于其可扩展学习与上下文学习能力（Kaplan等，2020；Brown等，2020），而这源于其核心模块——注意力模块——作为具有递增容量的联想记忆（Ramsauer等，2021；Bietti等，2024；Behrouz等，2026）。尽管对许多检索任务有效（Arora等，2024b），该递增记忆带来二次复杂度与高推理时内存开销（KV缓存），推动了次二次架构的发展，旨在提升效率同时保持性能（Dai等，2019；Child等，2019；Poli等，2023）。

特别是，循环神经网络（RNN）旨在将过去数据压缩为固定大小的记忆状态，近年来重新受到关注（Katharopoulos等，2020；Irie等，2021；Sun等，2023；Behrouz等，2025c）。尽管在短上下文语言建模（Irie等，2022）及视频数据等序列建模任务中表现良好（Park等，2025），其固定记忆状态仍是释放其真正潜力的瓶颈。

这些架构的基础是递归与数据压缩，精心设计可形成高效且表达力强的学习算法（Merrill等，2024；Huang等，2024）。然而，其固定压缩容量迫使模型在序列增长时遗忘过去信息，这在高召回率与长上下文任务中尤为关键（Arora等，2024b；Kuratov等，2024）。

**贡献**： 我们提出**记忆缓存**（MC），一种通用技术，通过缓存记忆状态的检查点，使循环模型的有效记忆随序列长度增长（见图1）。MC在标准递归与注意力之间提供灵活折中，复杂度为𝒪(NL)，可在RNN的𝒪(L)与Transformer的𝒪(L²)复杂度之间灵活插值。

我们的贡献有三方面： • **MC框架**：我们提出将序列分段并缓存每段的压缩记忆状态，使模型能直接访问整个历史的压缩信息。 • **新颖聚合策略**：我们提出四种利用缓存记忆的方法：(i, ii)（门控）残差记忆，使用残差连接与新颖的上下文感知门控机制；(iii)记忆汤（Memory Soup），受权重融合启发，平均缓存记忆模块的参数（对非线性记忆而言各不相同）；(iv)稀疏选择缓存（SSC），采用类专家混合（Mixture-of-Experts）路由器选择最相关的缓存记忆以高效聚合。 • **实证验证**：作为概念验证，我们在三种架构（线性注意力LA、深度记忆模块Titans、滑动窗口线性注意力SWLA与深度线性注意力DLA）上验证MC在语言建模、长上下文与检索任务中的有效性，表明MC提升了性能并扩展了RNN的有效上下文长度。

**2 预备知识与背景** 本节回顾必要背景并建立符号。我们首先回顾注意力及其线性变体，随后讨论参数化上下文学习与嵌套学习范式（Behrouz等，2026；2025b），MC即构建于此。

**符号**： 我们用粗体小写（大写）表示向量（矩阵），下标t表示时间t的状态。设输入x∈ℝᴸˣᵈⁱⁿ，ℳₜ为记忆ℳ(·)在时间t的状态，𝐊为键矩阵，𝐕为值矩阵，𝐐为查询矩阵，L为序列长度。我们聚焦基于MLP的记忆架构，其层数ℒℳ ≥ 1。特别地，当ℒℳ = 1时，该形式包含线性矩阵值记忆模块。必要时，以𝜽ℳ := {W₁, …, Wℒℳ, …}参数化记忆模块ℳ(·)，至少包含MLP中线性层的参数。

**注意力**： 注意力（Vaswani等，2017）是Transformer的核心模块，作为其联想记忆（Bietti等，2023；Behrouz等，2026；Wang等，2025）。给定输入x∈ℝᴸˣᵈⁱⁿ，因果注意力计算输出𝐲∈ℝᴸˣᵈⁱⁿ，其键、值、查询矩阵为𝐐 = x𝐖𝐐, 𝐊 = x𝐖𝐊, 𝐕 = x𝐖𝐕： 𝐲ᵢ = ∑ₜ₌₁ⁱ [exp(𝐪ᵢᵀ𝐤ₜ)𝐯ₜ / ∑ℓ₌₁ⁱ exp(𝐪ᵢᵀ𝐤ℓ)] = (1/Zᵢ) ∑ₜ₌₁ⁱ exp(𝐪ᵢᵀ𝐤ₜ)𝐯ₜ, 其中𝐖𝐐, 𝐖𝐊, 𝐖𝐕 ∈ ℝᵈⁱⁿˣᵈⁱⁿ为可学习参数，Zᵢ = ∑ℓ₌₁ⁱ exp(𝐪ᵢᵀ𝐤ℓ)为归一化项。 注意力需𝒪(L²)操作，因其需访问所有过去token。

**线性注意力**： 线性注意力（Katharopoulos等，2020）及其变体（Schlag等，2021；Peng等，2023；Yang等，2024b）通过将式(1)中的exp(·)替换为可分离核ϕ(·)，实现高效循环形式： 𝐲ᵢ = ∑ₜ₌₁ⁱ [ϕ(𝐪ᵢ)ᵀϕ(𝐤ₜ)𝐯ₜ / ∑ℓ₌₁ⁱ ϕ(𝐪ᵢ)ᵀϕ(𝐤ℓ)] = (1/Zᵢ) ℳᵢ ϕ(𝐪ᵢ), 其中ℳₜ = ℳₜ₋₁ + 𝐯ₜϕ(𝐤ₜ)ᵀ为固定大小记忆（Katharopoulos等，2020）。

**推理时记忆化与嵌套学习视角**： 近期统一框架将序列模型（包括注意力与现代RNN）的更新规则解释为动态上下文学习/记忆化过程，具有不同目标（Behrouz等，2026；2025b）。在此视角下，模型作为联想记忆，主动学习输入token（键与值）间的映射。该记忆化通过优化内部目标实现，常形式化为L₂回归问题（Wang等，2025）或“注意偏差”目标（Behrouz等，2026；2025b）。此视角将记忆状态视为前向传递中优化的动态实体。特别地，在Miras框架的最简形式中（Behrouz等，2026），联想记忆ℳ(·)旨在基于目标（称为“注意偏差”）学习键{𝐤ₜ}ₜ₌₁ᴸ与值{𝐯ₜ}ₜ₌₁ᴸ间的映射： ℳₜ₊₁ = arg minℳ ℒ(ℳ(𝐤ₜ); 𝐯ₜ) + Ret(ℳ; ℳₜ), 其中ℒ(·)衡量映射质量，Ret(ℳ; ℳₜ)使新解接近记忆最后状态。对特定注意偏差选择，可恢复已知架构：例如，令ℒ(ℳ(𝐤ₜ); 𝐯ₜ) = ⟨ℳ(𝐤ₜ), 𝐯ₜ⟩且ℳ(·)∈ℝᵈˣᵈ，可恢复未归一化线性注意力架构（Katharopoulos等，2020）。我们利用此视角引入记忆缓存，其中缓存状态作为该优化过程的检查点，增强模型在长序列中检索信息的能力。

**3 具备记忆缓存的循环神经网络** RNN维持固定大小记忆以压缩输入序列。序列过长时，导致记忆溢出与性能下降。相反，注意力缓存所有过去token，导致记忆递增但计算二次开销。我们提出记忆缓存（MC）缓存中间记忆状态，提供中间方案，使模型记忆可任意规模增长，计算开销可在𝒪(L)（类似RNN）与𝒪(L²)（类似Transformer）之间插值。

为此，给定序列x∈ℝᴸˣᵈⁱⁿ，我们将序列分为N段S⁽¹⁾, …, S⁽ᴺ⁾，长度为L⁽¹⁾, …, L⁽ᴺ⁾，并用记忆ℳ⁽¹⁾, …, ℳ⁽ᴺ⁾压缩各段。第s段的记忆更新规则为： 𝐤ₜ = xₜW𝐤, 𝐯ₜ = xₜW𝐯, 𝐪ₜ = xₜW𝐪, ℳₜ⁽ˢ⁾ = f(ℳₜ₋₁⁽ˢ⁾; 𝐤ₜ, 𝐯ₜ), 其中1 ≤ t ≤ L⁽ˢ⁾, 其中f(·)为学习更新规则（如线性注意力中f(ℳₜ₋₁⁽ˢ⁾; 𝐤ₜ, 𝐯ₜ) = ℳₜ₋₁⁽ˢ⁾ + 𝐯ₜ𝐤ₜᵀ）。

更新记忆后，我们缓存每段最后状态{ℳ_{L⁽ˢ⁾}⁽ˢ⁾}，标准RNN仅用当前记忆计算输出：𝐲ₜ = ℳₜ(𝐪ₜ)。而我们的形式用所有缓存记忆与当前记忆（在线记忆）计算查询𝐪ₜ的输出。给定任意聚合函数Agg(·;·;·)，输出为： 𝐲ₜ = Agg({ℳ_{L⁽¹⁾}⁽¹⁾(·), …, ℳ_{L⁽ˢ⁻¹⁾}⁽ˢ⁻¹⁾(·)}; ℳₜ⁽ˢ⁾(·); 𝐪ₜ), 其中s为当前段索引。对1 ≤ i ≤ s，项ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾(𝐪ₜ)提供段i中查询𝐪ₜ的对应信息。

**3.1 残差记忆** 我们首先采用最简单的Agg(·;·;·)算子：求和，作为记忆状态间的残差连接。 给定键、值、查询（见式4）与段S⁽¹⁾, …, S⁽ᴺ⁾，段s中时间t的记忆更新与输出计算为： ℳₜ⁽ˢ⁾ = f(ℳₜ₋₁⁽ˢ⁾; 𝐤ₜ, 𝐯ₜ), 其中1 ≤ t ≤ L⁽ˢ⁾, 𝐲ₜ = ℳₜ⁽ˢ⁾(𝐪ₜ) + ∑ᵢ₌₁ˢ⁻¹ ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾(𝐪ₜ).

记忆缓存的关键变化在于输出计算方式：模型对当前记忆（在线记忆）与缓存记忆均进行前向传递以检索记忆。

**门控残差记忆**（GRM）： 当记忆模块严格线性（即ℳ为矩阵）时，残差记忆形式（式7）在数学上坍缩为标准固定大小记忆（见式13）。但实验表明，即使此简单形式也能增强循环模型能力（见第5节）。主要原因是简单残差记忆作为保留算子，增强对远期历史的访问。 残差方法的另一局限是平等对待所有缓存记忆，忽略其与查询𝐪ₜ的相关性。为实现选择性检索，我们引入输入依赖门控。给定段s中输入xₜ，定义0 ≤ γₜ⁽¹⁾, …, γₜ⁽ˢ⁾ ≤ 1为输入依赖参数，输出重写为： ℳₜ⁽ˢ⁾ = f(ℳₜ₋₁⁽ˢ⁾; 𝐤ₜ, 𝐯ₜ), 对1 ≤ t ≤ L⁽ˢ⁾, 𝐲ₜ = γₜ⁽ˢ⁾ℳₜ⁽ˢ⁾(𝐪ₜ) + ∑ᵢ₌₁ˢ⁻¹ γₜ⁽ⁱ⁾ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾(𝐪ₜ).

参数γₜ⁽ⁱ⁾调节各段对输出的贡献。当γₜ⁽ⁱ⁾ → 1（或→0），第i段对输出贡献更大（或更小）。因这些输入依赖参数，上述形式无法提前计算，也不能复用于下一token/段，故不坍缩为固定大小记忆（即使线性记忆），需对每个token重新计算并缓存记忆状态。γₜ⁽ⁱ⁾的简单参数化是将其定义为输入xₜ的线性投影（类似键、值、查询投影）。但此时γₜ⁽ⁱ⁾作为位置过滤/聚焦，即xₜ的上下文仅决定第i段记忆（基于位置）的贡献程度，与其内容无关。为克服此问题，我们建议γₜ⁽ⁱ⁾为xₜ与第i段S⁽ⁱ⁾的函数，融合二者上下文及其相似性。为此，引入连接参数𝐮ₜ（输入的线性投影），定义γₜ⁽ⁱ⁾为𝐮ₜ与第i段S⁽ⁱ⁾的相似性： γₜ⁽ⁱ⁾ = ⟨𝐮ₜ, MeanPooling(S⁽ⁱ⁾)⟩, 其中𝐮ₜ = xₜWᵤ. MeanPooling(·)提供段上下文的简单表示（所有token的均值），可替换为其他池化方式。实践中，我们用softmax(·)对γₜ⁽ⁱ⁾归一化。另一参数化是令𝐮ₜ = 𝐪ₜ。当γₜ⁽ⁱ⁾为常数时，GRM等价于残差记忆变体。

**示例**： 为更好说明上述形式，令f(ℳₜ₋₁⁽ˢ⁾; 𝐤ₜ, 𝐯ₜ) = ℳₜ₋₁⁽ˢ⁾ − ∇⟨ℳₜ₋₁⁽ˢ⁾(𝐤ₜ), 𝐯ₜ⟩，其中记忆ℳ(·)为任意前馈层（如MLP或门控MLP层）。此通用形式等价于深度线性注意力（DLA）（Behrouz等，2025a），当记忆为矩阵（即单层MLP）时等价于线性注意力（Katharopoulos等，2020）。对DLA使用残差记忆缓存，其更新与检索规则为： ℳₜ⁽ˢ⁾ = ℳₜ₋₁⁽ˢ⁾ − ∇⟨ℳₜ₋₁⁽ˢ⁾(𝐤ₜ), 𝐯ₜ⟩, 𝐲ₜ = ℳₜ⁽ˢ⁾(𝐪ₜ) + ∑ᵢ₌₁ˢ⁻¹ ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾(𝐪ₜ).

当使用线性矩阵值记忆（即线性注意力）时，式(11)可简化为： ℳₜ⁽ˢ⁾ = ℳₜ₋₁⁽ˢ⁾ + 𝐯ₜ𝐤ₜᵀ, 𝐲ₜ = ℳₜ⁽ˢ⁾𝐪ₜ + ∑ᵢ₌₁ˢ⁻¹ ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾𝐪ₜ = (ℳₜ⁽ˢ⁾ + ∑ᵢ₌₁ˢ⁻¹ ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾)𝐪ₜ.

**记忆复杂度**： 在检索过程中，我们使用当前记忆（在线记忆）与所有先前段的缓存记忆，给定固定训练序列长度，缓存记忆数量为段长度的函数。记忆更新过程未变，仍需𝒪(L)操作，但检索过程需对所有缓存记忆进行前向传递，每token需𝒪(N)操作，使模型复杂度为𝒪(NL)，其中1 ≤ N ≤ L。当N = 1（仅一段），无需缓存任何记忆状态，为简单循环记忆模型。当N = L，每token视为独立段，缓存所有过去token的记忆状态，这与注意力的直觉高度一致——通过缓存所有过去token，提供对序列各部分的直接访问，增强检索能力。

**3.2 记忆汤** 将递归视为元学习过程（记忆状态为检查点），我们引入记忆汤变体，受Wortsman等（2022）启发。核心思想是将记忆状态（参数）组合为单一数据依赖记忆用于检索。

类似前一变体，我们用ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾表示第i段对应的缓存记忆，参数化为𝜽ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾ := {W₁⁽ⁱ⁾, …, W_c⁽ⁱ⁾}。注意记忆架构不变，故c（参数数量）对所有记忆状态相同。记忆缓存的记忆更新与检索过程定义为： ℳₜ⁽ˢ⁾ = f(ℳₜ₋₁⁽ˢ⁾; 𝐤ₜ, 𝐯ₜ), 对1 ≤ t ≤ L⁽ˢ⁾, 𝐲ₜ = ℳₜ*(𝐪ₜ), 其中ℳₜ*参数化为： 𝜽ℳₜ* := {∑ᵢ₌₁ˢ γₜ⁽ⁱ⁾W₁⁽ⁱ⁾, …, ∑ᵢ₌₁ˢ γₜ⁽ⁱ⁾W_c⁽ⁱ⁾}.

因此，每个token拥有其自己的检索记忆，且依赖输入数据并可变化。可将上述过程解释为记忆系统：每个token构建其自己的记忆以从其中检索对应信息。注意此处γₜ⁽ⁱ⁾参数定义同式(10)。

当记忆模块ℳ为线性时，记忆汤在数学上等价于GRM（式9）。这是因为对权重求和再应用查询，与对各记忆应用查询后集成输出，在线性操作下等价。当使用深度或非线性记忆模块（如DLA或Titans）时，该等价性被打破。记忆汤通过插值参数本身构建新的输入依赖记忆模块ℳₜ*，有效创建为该时间步定制的专用非线性检索函数。

**3.3 稀疏选择缓存**（SSC） 前一变体关注所有过去缓存记忆，对超长序列造成显著内存开销。我们引入稀疏选择缓存（SSC），每个token上下文选择缓存记忆的子集，提升效率。

受专家混合（MoEs）启发（Shazeer等，2017），我们使用路由器，基于token及其与各段上下文的相似性选择缓存记忆子集。对每段S⁽ⁱ⁾，按式(10)，令MeanPooling(S⁽ⁱ⁾) = ∑ⱼ∈S⁽ⁱ⁾ 𝐤ⱼ，定义段S⁽ⁱ⁾对查询xₜ的相关性分数为： 𝐫ₜ⁽ⁱ⁾ = ⟨𝐮ₜ, MeanPooling(S⁽ⁱ⁾)⟩, 其中𝐮ₜ = xₜWᵤ.

给定相关性分数，路由器选择k个最高相关性的缓存记忆，即ℛₜ = arg Top-k({𝐫ₜ⁽ⁱ⁾}ᵢ₌₁ˢ⁻¹)，以及当前在线记忆用于检索。给定所选记忆，检索过程同前一变体，但仅使用所选记忆： ℳₜ⁽ˢ⁾ = f(ℳₜ₋₁⁽ˢ⁾; 𝐤ₜ, 𝐯ₜ), 其中1 ≤ t ≤ L⁽ˢ⁾, 𝐲ₜ = γₜ⁽ˢ⁾ℳₜ⁽ˢ⁾(𝐪ₜ) + ∑ᵢ∈ℛₜ γₜ⁽ⁱ⁾ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾(𝐪ₜ).

在此形式中，每段的MeanPooling(S⁽ⁱ⁾)可预先计算，计算相关性分数及为每个token选择Top-k段均为可并行化。此外，此类计算无需在加速器（如GPU、TPU）中存储缓存记忆状态，仅需为每个token加载“所选”记忆，从而提升训练与推理时的内存消耗。

**有效记忆**： SSC的一个有趣解释是将其视为稀疏统一记忆模块。图2（右）对此进行了说明。可将SSC视为具备增长记忆的模型，其中每个token激活子集参数用于记忆写入操作（存储token），并激活更大子集参数用于检索。此形式使记忆(1)在不干扰过去记忆的情况下存储信息，(2)高效自适应地检索信息。此处段大小决定统一记忆中激活块的大小。

**3.4 缓存检查点还是独立压缩器？** 回顾式(4)的通用记忆缓存形式，存在设计选择：缓存单个记忆的检查点，或使用独立记忆模块压缩每段信息。即两种视角： (1) 从优化视角（式3），我们训练联想记忆，序列token为训练样本。为避免遗忘过去知识，缓存记忆在训练（优化）过程中的检查点。对每个s = 0, …, N，有ℳ₀⁽ˢ⁾(·) = ℳ_{L⁽ˢ⁻¹⁾}⁽ˢ⁻¹⁾(·)，即每段记忆从上一段最后状态开始。 (2) 从压缩视角，缓存过去段记忆时，希望其为该段信息的压缩代表。前向传递ℳ_{L⁽ˢ⁾}⁽ˢ⁾(𝐪ₜ)表示段s中查询𝐪ₜ的对应信息。为避免不同段记忆干扰，对每段使用独立记忆，即段s的记忆从独立于ℳ_{L⁽ˢ⁻¹⁾}⁽ˢ⁻¹⁾(·)的初始点ℳ₀⁽ˢ⁾(·)开始。

实践中，我们观察到两种选择各有优劣（见第5.6节）。

**4 讨论与概念验证** 本节讨论记忆缓存技术对线性与深度记忆模块的影响，以及评估中使用的模型作为概念验证。

**4.1 记忆缓存对线性与深度记忆模块的影响** **线性记忆**： 从简单但极端情况开始，段大小为1，循环记忆为无值向量记忆模块¹。每token xₜ∈ℝᵈ视为一段，记忆状态仅存储此token： ℳ₁⁽ᵗ⁾ = ℳ₀⁽ᵗ⁾ + 𝐤ₜ = 𝐛𝐊 + xₜ𝐖𝐊, 其中ℳ₀⁽ᵗ⁾为输入xₜ到键𝐤ₜ投影的偏置项。应用记忆缓存后： 𝐲ₜ = ∑ᵢ₌₁ᵗ γₜ⁽ⁱ⁾ℳ₁⁽ⁱ⁾(𝐪ₜ) = ∑ᵢ₌₁ᵗ [exp(𝐮ₜᵀ𝐤ᵢ) / ∑ℓ₌₁ⁱ exp(𝐮ₜᵀ𝐤ℓ)] (𝐛𝐊 + xᵢ𝐖𝐊) 𝐪ₜ.

鉴于𝐪ₜ为自由参数且为输入函数，可重新参数化ℳ₁⁽ⁱ⁾ = 𝐯ᵢ′： 𝐲ₜ = (∑ᵢ₌₁ᵗ [exp(𝐮ₜᵀ𝐤ᵢ) / ∑ℓ₌₁ⁱ exp(𝐮ₜᵀ𝐤ℓ)] 𝐯ᵢ′) ⊗ σ(xₜ𝐖𝐐), 等价于门控全局注意力块——增强版注意力，其输出以输入的线性投影为门控。因此，设置段长为1并使用无值向量循环记忆与记忆缓存，可恢复门控全局softmax注意力块。此再发现基于记忆缓存的最简设计选择，激励设计原则上更强大的架构。此设计可扩展至更复杂的全局注意力形式。例如，上述形式缓存token投影的直接值，即每个token存储于无值记忆模块。但可扩展为更富表现力的记忆更新：如使用线性注意力。

然而，记忆的线性性与/或简单检索过程（如令𝐲ₜ = ℳₜ𝐪ₜ）可能导致不期望的简化，使设计坍缩或性能次优。例如，前文讨论记忆融合技术对线性记忆坍缩为（门控）残差记忆变体，而对深度记忆模块提供不同解。另一例，在线性记忆配置中，以𝐪ₜ = xₜ𝐖𝐐解释检索过程为门控架构，可简化为移除门控，设𝐪ₜ = 1∈ℝᵈ。我们将此类模块称为**压缩器**。

近期，混合模型（即交错全局注意力与记忆受限模块的架构）因在高召回率任务中稳健性能及提升纯全局注意力模型效率而流行。考虑压缩器层（向量值循环记忆）后接全局注意力块。给定输入xₜ，第一块计算为： 𝐪ₜ = 1, 𝐤ₜ = xₜ𝐖𝐊, 𝐯ₜ = xₜ𝐖𝐕, ℳₜ = f(ℳₜ₋₁; 𝐤ₜ, 𝐯ₜ), 𝐲ₜ = ℳₜ.

此输出作为下一块输入，最终输出计算为（为清晰忽略归一化）： 𝐪ₜ⁽ᵃᵗᵗⁿ⁾ = 𝐲ₜ𝐖𝐐⁽ᵃᵗᵗⁿ⁾, 𝐤ₜ⁽ᵃᵗᵗⁿ⁾ = 𝐲ₜ𝐖𝐊⁽ᵃᵗᵗⁿ⁾, 𝐯ₜ⁽ᵃᵗᵗⁿ⁾ = 𝐲ₜ𝐖𝐕⁽ᵃᵗᵗⁿ⁾, 𝐨ₜ = ∑ᵢ₌₁ᵗ [exp(𝐪ₜ⁽ᵃᵗᵗⁿ⁾𝐤ᵢ⁽ᵃᵗᵗⁿ⁾) / ∑ℓ₌₁ⁱ exp(𝐪ₜ⁽ᵃᵗᵗⁿ⁾ᵀ𝐤ℓ⁽ᵃᵗᵗⁿ⁾)] 𝐯ᵢ⁽ᵃᵗᵗⁿ⁾.

注意𝐲ₜ = ℳₜ，因此上述形式等价于段大小为1的记忆缓存，当缓存记忆**检查点**而非使用独立记忆时（见第3.4节）。此视角不仅解释为何著名混合模型配方应有效（因其增强循环模型的有效记忆容量），还激励设计更强大变体，将注意力视为强制缓存过去输入的模块。注意上述解释仅对过度简化版本展示等价性，考虑归一化与前馈层后，两种情况的建模表达力可能不同。但上述讨论支持记忆缓存技术的威力，并激励超越𝐪ₜ = 1。当𝐪ₜ = xₜ𝐖𝐐时，记忆缓存可导致临时注意力，其中注意力块的输入序列对每个查询𝐪ₜ不同。即，与混合变体中完全预确定的token序列（即最后记忆层输出𝐲ₜ）不同，记忆缓存允许模型基于查询𝐪ₜ构建其自己的输入序列（即{ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾(𝐪ₜ)}ᵢ₌₁ˢ）。

**深度记忆**： 与上述相反，深度记忆的记忆缓存产生与混合变体无重叠的新架构。回顾线性记忆模块的初始示例。令记忆ℳ(·)为2层MLP，每token xₜ∈ℝᵈ为一段（段大小为1，每记忆仅存储一token）： ℳ₁⁽ᵗ⁾ = ℳ₀⁽ᵗ⁾ − ηₜ∇ℒ(ℳ₀⁽ᵗ⁾; 𝐤ₜ, 𝐯ₜ).

这有两点含义：(i) 现在每token由张量而非矩阵或向量表示，token不再由常量向量表示，给定查询𝐪ₜ，token xᵢ的上下文与表示可不同（即ℳ₁⁽ⁱ⁾(𝐪ₜ)）；(ii) 初始点或偏置项ℳ₀⁽ⁱ⁾（编码一般知识）为神经网络，其对不同查询检索过程（即ℳ₁⁽ⁱ⁾(𝐪ₜ)）的影响不同。

**4.2 分段对容量与复杂度的影响** 记忆缓存的关键设计选择是序列分段。直观上，段长提供压缩水平与计算成本间的权衡：(1) 如前所述，Transformer可视为段大小为1的记忆缓存，即每个token本身被缓存（无压缩，高计算成本𝒪(L²)）；(2) RNN模块是记忆缓存的极端情况，整个序列视为一段，仅缓存单个在线记忆（全压缩，每token恒定计算成本𝒪(L)）。

更详细地，对token xₜ，将序列分为N段S⁽¹⁾, …, S⁽ᴺ⁾，长度L⁽¹⁾, …, L⁽ᴺ⁾，用记忆ℳ⁽¹⁾, …, ℳ⁽ᴺ⁾压缩各段。每段压缩过程与段大小线性相关，即𝒪(L⁽ⁱ⁾)。因此，记忆更新操作成本为𝒪(∑ᵢ₌₁ᴺ L⁽ⁱ⁾) = 𝒪(L)，检索过程需对所有过去缓存记忆（每段一个）进行前向传递。假设记忆前向传递需𝒪(p)操作，则每token计算成本为𝒪(p×N)。因此，记忆缓存总成本为𝒪(L + p×N×L)。注意此处N为分段的函数。例如，若段等长，大小C = L/N ≥ 2，则计算成本为𝒪(p×L²/C)，类似Transformer但常数项更小（即更高效）。另一例为对数分段：即写L为二进制，令L⁽ⁱ⁾为非零位对应2的幂次。图3（左）展示此分段示例。对长度37 = (100101)₂的序列，此分段用三段，长度L⁽¹⁾=32, L⁽²⁾=4, L⁽³⁾=1。因此，N最大值为log₂(L)，计算复杂度为𝒪(p×L log(L))。

如前所述，分段提供压缩水平（召回性能）与计算成本间的权衡。图3通过恒定大小与对数分段示例说明此权衡。如上，这些方法的时间复杂度分别为𝒪(L²/C)与𝒪(L log(L))，使对数分段更高效。但另一方面，对数分段对远期token提供显著更低分辨率，限制其在高召回率任务中的能力。

**4.3 Titans与线性注意力变体的记忆缓存** 如前文所述，记忆缓存技术适用于任意循环更新规则，可增强其有效上下文长度。作为概念验证，我们在滑动窗口线性注意力（SWLA）与深度线性注意力（DLA）（Behrouz等，2025a）、线性注意力（Katharopoulos等，2020）及Titans（Behrouz等，2025c）的更新规则上使用记忆缓存。

**滑动窗口线性注意力**（SWLA）： 近期，Behrouz等（2025a）引入滑动窗口线性注意力（SWLA），其记忆基于c ≥ 1个过去token更新权重（与仅基于最后token更新的在线RNN相反）。更具体地，给定记忆模块ℳ(·)与键、值、查询{ (𝐤ₜ, 𝐯ₜ, 𝐪ₜ) }ₜ₌₁ᴸ，更新与检索规则为： ℳₜ = αₜℳₜ₋₁ + ∑ᵢ₌ₜ₋c₊₁ᵗ βᵢ⁽ᵗ⁾𝐯ᵢ𝐤ᵢᵀ, 𝐲ₜ = ℳₜ𝐪ₜ,

当c = 1时，设计坍缩为简单线性注意力（在线线性RNN）及其门控变体（Katharopoulos等，2020；Sun等，2023；Li等，2025）。作为概念验证，我们在c = 2的SWLA上使用记忆缓存，结果递归与检索为： ℳₜ⁽ˢ⁾ = αₜℳₜ₋₁⁽ˢ⁾ + (βₜ𝐯ₜ₋₁𝐤ₜ₋₁ᵀ + λₜ𝐯ₜ𝐤ₜᵀ), 𝐲ₜ = γₜ⁽ˢ⁾ℳₜ⁽ˢ⁾𝐪ₜ + ∑ᵢ₌₁ˢ⁻¹ γₜ⁽ⁱ⁾ℳ_{L⁽ⁱ⁾}⁽ⁱ⁾𝐪ₜ.

**6 结论** 本文提出记忆缓存（MC），一种适用于所有循环神经网络的简单技术，缓存部分记忆状态，使后续token可直接关注其过去相关token。我们的实验显示相比部分基线有改进。本文许多选择旨在使所得模型尽可能简单，更好地展示记忆缓存思想的效果。然而，未来工作中可使用更富表现力的池化或路由机制进一步提升性能。
