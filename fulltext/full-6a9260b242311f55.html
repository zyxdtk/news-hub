摘要
出行行为研究日益将数字数据采集与预测建模相结合，但这两个阶段往往被分开开发和评估。本研究提出并应用了一种三智能体工作流，整合了对话式数据采集、结构化数据处理和行为预测。通过一个由聊天机器人管理、图像增强的意向调查，收集了 92 名学生通勤者在五种预定义天气场景下的出行方式选择，获得了 454 条“受访者-场景”观测数据。使用多项 Logit 模型分析了与天气相关的关联，同时使用逻辑回归和随机森林提供了机器学习基准。评估了 9 个本地部署的大型语言模型（LLM）（参数量从 20 亿到 350 亿不等），测试了四种零样本提示与上下文条件，并通过角色设定、少样本和基于视觉的配置进行了进一步扩展。骑行对恶劣天气尤为敏感，而公共交通在降雪场景下的使用量显著增加。随机森林达到了 69.6% 的五分类准确率，而最佳的纯文本零样本 LLM 在无需特定任务拟合的情况下达到了 69.9%。习惯性出行信息使 LLM 预测的改进最为一致，专家框架通常优于角色扮演，且在缺乏习惯性出行信息时，角色设定信息最为有益。少样本提示进一步提高了一些模型的五分类预测性能，且增益通常在少量示例后趋于稳定。还使用向受访者展示的相同天气图像评估了具备视觉能力的模型，最佳的基于视觉的配置达到了 71.5% 的最高五分类准确率，表明视觉上下文可以为特定模型提供额外的预测信息。综上所述，研究结果表明，习惯性出行信息、提示策略、示例展示和视觉上下文能够显著影响基于 LLM 的出行选择预测。更广泛地说，本研究展示了如何将对话式调查管理、结构化数据处理、传统行为建模、机器学习和多模态 LLM 预测协调在一个可审计的多智能体工作流中，尽管更广泛的应用需要更大、更具代表性的旅客样本进行验证。

1 引言
理解和预测出行行为是交通规划的基本组成部分，涵盖了关于个人何时、何地以及如何出行的相互关联的决策。在这些决策中，方式选择尤为重要，因为它决定了需求在交通系统中的分布方式，并影响基础设施需求、环境影响以及旨在鼓励可持续出行政策的成效 (31; 4)。方式选择不仅受个人和替代方案特定特征的影响，还受出行发生背景的影响。天气就是一个重要的例子，因为降水、极端温度和恶劣的道路条件会改变步行和骑车的吸引力，使出行者转向公共交通或私家车，其影响因个人和季节而异 (21; 7; 37)。因此，理解这种依赖于背景的反应，需要能够捕捉在观测出行数据中可能未充分体现的条件下异质出行行为的方法。

收集能够捕捉这些背景变化的行为数据仍然具有挑战性。传统的出行调查，无论是通过访谈、纸质问卷还是静态网络表单进行，在实施和扩展时既昂贵又耗时 (24; 3)。意向调查（SP）提供了一个重要的替代方案，允许研究人员在受控或假设条件下（包括在显示偏好数据中难以系统观测的天气场景）检验选择。然而，传统的 SP 工具通常使用固定的文本描述来描述这些情况，要求受访者自行构建预期的背景，并限制了更丰富背景信息的纳入 (11)。这对于依赖天气的出行选择尤为相关，因为降水、能见度、积雪或道路条件等视觉条件可能构成决策环境的重要组成部分。这些局限性促使人们寻找能够将可扩展的调查部署与更丰富、更一致的出行背景表示相结合的数据采集方法。

人工智能（AI）的最新进展为解决这些局限性提供了新的可能。对话式聊天机器人可以通过引导式互动进行调查，结合受访者之前的回答，并直接在调查体验中嵌入多媒体内容，从而可能实现更灵活、更具吸引力的行为数据采集 (44; 35; 23)。同时，生成式 AI 工具可以支持预定义视觉场景的构建，而大型语言模型（LLM）则实现了自然语言交互和异构信息的处理。这些能力共同创造了机会，使我们能够超越静态、基于文本的问卷，转向对话式和背景丰富的行为调查。然而，尽管对话式 AI 在调查研究中的应用不断增长，但在出行行为和方式选择研究中，基于聊天机器人的数据采集在很大程度上仍未被探索，特别是对于整合了图像增强背景信息的意向调查。

出行选择建模也取得了平行进展。基于随机效用理论的离散选择模型（DCM）仍然是方式选择分析的核心，因为它们具有可解释性，并且能够估计具有行为意义的关联 (31; 4; 39)。机器学习（ML）方法随后通过捕捉非线性关系和复杂交互（这些可能难以用参数化方法指定）扩展了预测工具箱 (18; 1)。最近，LLM 引入了一种不同的范式，它们不是估计解释变量与选择之间的固定数学映射，而是能够解释通过自然语言提示表达的出行者特征和背景信息，并在有限或无需特定任务训练的情况下生成个体层面的预测 (45; 10)。这种灵活性还使得改变提供给模型的信息成为可能；例如，通过替代的提示配置，改变人口统计特征、出行历史、先前决策的示例或背景描述。然而，在出行行为预测中，有两个重要问题仍未得到充分研究。第一个问题是预测性能如何在系统设计的 LLM 配置和提示策略之间变化。第二个问题是具备视觉能力的 LLM 能否直接纳入出行条件的视觉表示（例如向人类受访者展示的相同天气图像），而不是完全依赖文本描述。

除了预测之外，LLM 作为合成受访者的研究也日益增多，作为个体的计算表示，生成以特定角色和选择背景为条件的决策。这一研究方向最初发展于经济学、政治学和调查研究中，其中 LLM 生成的回复已被用来与人类决策进行比较 (19; 2)。最近的交通研究同样表明，以出行者特征、行为历史或潜在态度为条件的 LLM 可以提高其与观测到的出行选择的对应度 (29; 36)。一个相关的发展是多智能体系统的出现，其中专门的或基于角色的 LLM 智能体执行互补功能或大规模代表异质决策者 (29; 28; 13)。尽管如此，LLM 生成的行为并不一定能可靠地再现人类决策，特别是在背景有限或零样本设置下 (26; 6; 20)。尽管在其他行为领域取得了这些进展，但在出行行为和个体方式选择建模中，将用于数据采集、数据处理和基于 LLM 的行为预测的专门智能体整合到一个通用的多智能体工作流中，在很大程度上仍未被探索。

本研究通过一个多智能体工作流来解决这些空白，该工作流将 AI 辅助的行为数据采集与出行选择建模和基于 LLM 的预测联系起来。本文做出了四个主要贡献。首先，它开发了一项对话式、图像增强的 SP 调查，其中基于 AI 的聊天机器人收集了出行者特征和跨预定义天气场景的重复方式选择，提供了一个专门为下游行为预测设计的结构化数据集。其次，它通过检验相同个体在系统变化的天气场景下如何改变其陈述选择，为通勤者方式选择的天气相关变化提供了实证证据。第三，它在多种预测配置下系统评估了 LLM 作为方式选择预测器的表现，包括零样本、少样本、角色和出行历史增强提示，以及使用向受访者展示的相同天气图像进行基于视觉的预测，并将其性能与传统 DCM 和 ML 方法进行了基准比较。第四，它展示了一个多智能体工作流，该工作流在一个集成的“从数据采集到预测”的过程中，将对话式调查管理、结构化数据处理以及并行的离散选择、机器学习和基于 LLM 的建模联系起来，为探索 AI 辅助出行行为研究提供了可复现的基础。

本文的其余部分组织如下。第 2 节回顾了出行行为数据采集与对话式智能体、方式选择建模、基于 LLM 的选择预测以及多智能体应用的相关工作。第 3 节介绍了提出的多智能体方法论。第 4 节描述了案例研究的实施，第 5 节报告了描述性和行为建模结果以及 LLM 预测实验。随后各节讨论了研究结果的含义和局限性，并总结了未来研究的方向。

2 背景与相关工作
2.1 出行行为与方式选择
方式选择是交通研究中最古老且建模最多的问题之一，多项 Logit（MNL）模型几十年来一直是其主导框架 (31; 4)。基于随机效用理论，MNL 及其扩展（如嵌套和混合 Logit 模型）仍然是估计出行时间、成本和个人特征如何转化为离散出行选择的标准工具，这在很大程度上是因为它们的系数允许直接的行为解释 (39)。机器学习（ML）分类器，包括随机森林、梯度提升和支持向量机，已成为离散选择模型日益常见的补充。比较研究反复发现，ML 分类器在预测准确率上可以匹敌或超越 MNL，特别是当特征集较大或选择集不平衡时，尽管由此产生的模型在行为术语上更难解释 (18; 1)。

两个模型族都面临一个共同挑战：出行者的偏好不是固定的，而是随天气、季节、建成环境和个人异质性而变化。特别是天气，有充分的文献记录其与主动出行方式选择的关联，寒冷、潮湿和低能见度条件会抑制步行和骑行，使出行者转向公共交通或驾驶 (7; 37; 21)。捕捉这种敏感性通常需要直接改变条件的意向调查（SP）方法，因为显示偏好数据可能无法涵盖受访者可能遇到的全部天气范围 (3; 24)。然而，MNL 和 ML 模型都需要标记数据，当应用条件与模型开发期间代表的条件不同时，其预测性能可能会下降。这一局限性促使了人们对基于 LLM 的选择预测的兴趣日益增长（在第 2.3 节中回顾）。

2.2 出行行为研究中的数据采集方法
出行行为数据传统上是通过纸质日记、电话访谈和静态网络调查收集的。每种工具都在成本、覆盖范围和深度之间进行权衡；例如，纸质调查处理起来劳动强度大，电话访谈难以规模化，而静态网络表单虽然分发成本低，但向每位受访者呈现相同的固定问题序列，而不考虑他们的回答 (8)。对话式和数字工具放宽了其中一些限制。聊天机器人管理的调查可以根据先前的回答动态分支，早期评估报告称，受访者发现对话界面比静态表单更具吸引力，且数据质量没有损失 (11)。最近针对交通的特定工作已开始将模块化 AI 智能体应用于调查管理和访谈，认为与传统工具相比，对话式智能体可以提高参与度、透明度和成本效率 (44)，并且已经提出了自适应、强化学习驱动的对话式调查设计，以进一步个性化访谈流程 (38)。

意向调查任务也开始纳入更丰富的视觉辅助工具，从虚拟现实环境到视频和照片级真实感图像，其前提是视觉场景比单纯的文本描述能引发更具生态效度的反应 (16)。使用基于视频的对话式聊天机器人来引出感知骑行安全感的试点研究 (35)，以及在调查研究中使用照片级真实感的具身对话式智能体 (23) 都指向了同一方向，但在规模上仍然有限。尽管取得了这些进展，交通领域的大多数聊天机器人工具仍用于信息传递（如行程规划或公交信息），而不是用于行为数据采集，且很少有意向研究将生成图像等富媒体直接嵌入到聊天机器人管理的选择任务中。这正是第 4.1 节中数据采集智能体旨在解决的空白。

2.3 用于行为模拟的 LLM
大型语言模型最近被探索作为多个领域行为模拟的工具。在经济学中，它们被提议作为模拟智能体 (19)；在政治学中，它们被用于再现调查样本 (2) 并支持人口规模的基于智能体的模拟 (34)；在市场研究和消费者行为中，它们被应用于细分和行为模拟 (25; 9; 15)。相关研究还检验了信任行为 (22) 以及心理学和管理学实验的大规模复制 (14)，说明了 LLM 作为合成参与者的更广泛潜力。同时，这些文献也提出了重要的关切。复制研究表明，LLM 生成的调查回复可能以难以察觉的方式偏离人类数据 (6)，而方法论上的批评则警告不要在没有独立验证的情况下将模拟回复等同于人类受试者证据 (20)。对基于角色和角色一致提示的研究同样表明，采用模拟身份可能会改善或扭曲行为反应 (12; 42)。

在交通领域，一项规模虽小但不断增长的研究调查了 LLM 能否在未在目标数据集上训练的情况下预测个体出行选择。应用包括方式选择预测 (32)、替代集评估 (33) 以及行为信息驱动的网约车选择建模 (36)。其他研究检验了基于角色的表示是否改善了与观测出行选择的一致性 (27)，LLM 能否恢复出行者的时间价值评估 (43)，以及它们能否再现陈述的航空公司乘客偏好 (40)。一份早期的工作论文进一步表明，LLM 可以在没有特定数据集训练的情况下，捕捉观测方式选择数据中有意义的预测信号份额 (26)。尽管取得了这些进展，现有研究通常孤立地检验单个提示或建模选择。在单个出行行为预测任务中，对上下文丰富度、模型规模、角色信息、少样本学习和视觉输入的系统比较仍然有限。特别是，将向人类受访者展示的相同视觉出行条件作为具备视觉能力的 LLM 的直接输入，仍未被探索，这构成了本研究解决的另一个空白。

2.4 多智能体系统与 LLM 智能体框架
在交通领域之外，基于 LLM 的多智能体系统已被提议用于从模拟营销和消费者行为 (13) 到消费者偏好对齐的沙盒经济建模 (41) 以及为管理研究构建虚拟组织决策者 (17) 等任务。这些系统通常将任务分解给交换中间结果的专门智能体，借鉴了关于自主 LLM 智能体中工具使用和编排的更广泛的软件工程文献 (45)。在交通领域内，这种框架在很大程度上仍是概念性的。最近的工作提出了交通系统的基于 LLM 智能体建模的框架 (29)，以及将 LLM 智能体与人类学习和调整行为相对齐的双智能体方法 (28)。然而，很少有研究在共同的实证数据集上实施和评估从调查设计到数据处理再到行为预测的端到端工作流。本文通过将这三个阶段实例化为专门智能体，并将其应用于相同的通勤者方式选择数据集来填补这一空白。

3 方法论
3.1 框架概述
我们提出了一个多智能体框架，该框架整合了通勤者方式选择研究的数据采集、数据处理和行为建模。该框架由三个专门的智能体组成：数据采集智能体、数据处理智能体和数据建模智能体。这些智能体执行不同的研究功能，并通过标准化的数据对象和明确的输入-输出接口交换信息。数据传输、版本控制和执行记录通过共享工作空间和预定义的工作流规则进行组织。这些支持功能是系统基础设施，而不是额外的智能体。图 1 说明了正向工作流和相关的细化路径。

图 1：用于通勤者出行行为研究的多智能体框架。实线箭头表示正向数据和工件流，而虚线箭头表示在后续工作流迭代中实施的细化。

在本研究中，智能体被定义为一种目标导向且由研究人员监督的软件组件，它能够解释用户指令、维护任务状态、从授权的工具集中进行选择，并产生结构化和可审计的输出。因此，智能体不限于 LLM。根据任务的不同，它可以将 LLM 与确定性规则、数据库操作、统计软件、机器学习算法或通用编程工具相结合。因此，所提出的框架是一个多智能体研究工作流，而不是一个仅包含 LLM 的流水线。该框架中的术语“智能体”指的是支持研究过程的软件智能体，不应与传统的基于智能体的交通模拟中的出行者智能体相混淆。人类受访者仍然是陈述调查选择的来源，而研究人员保留对调查构建、数据处理要求、模型规范和结果解释的控制权。在本文中，“主动数据采集”指的是具有预定义交互逻辑和结构化响应捕获的有状态对话式调查管理；它不指代主动学习或自适应采样。天气敏感需求预测指的是跨五种预定义天气场景的个体方式选择预测。

方程 (1) 代表一次正向执行传递。图 1 中的虚线箭头表示可能引发修订调查、处理或建模规范的诊断反馈。此类修订不会自动修改正在进行的研究；它们由研究人员审查并作为新的工作流版本实施。该框架将原始响应视为不可变的，并保留留出测试结果用于评估，而不是修改在该测试集上评估的配置。

这种分离为每个智能体分配了明确的责任。数据采集智能体将调查规范转换为可部署的对话界面并收集响应。数据处理智能体将原始记录转换为可供分析的数据。数据建模智能体将研究目标转换为可执行的建模工作流，并返回拟合的模型和相关结果。这种分解减少了对单个通用智能体执行所有任务的需求，并使错误更容易在其源头被识别。

3.2 通用智能体表示与工作流编排
以下公式描述了通用框架支持的功能。第 4 节确定了当前案例研究中实例化的子集；并非所有支持的功能都在当前应用中得到了执行或实证评估。

设 k∈{col,pro,mod} k\in{\mathrm{col},\mathrm{pro},\mathrm{mod}} 索引这三个智能体。每个智能体表示为一个映射：

(2)

工作流编排器启动每个智能体，验证其所需输入是否可用，并仅将验证通过的工件传递到下一阶段。避免了智能体之间直接、不受限制的自然语言通信。相反，智能体通过类型化的数据对象进行通信，包括数据集、代码本、配置文件、模型规范和执行记录。这种设计提高了互操作性，并限制了不受支持的智能体输出的传播。

3.3 数据采集智能体
数据采集智能体将研究人员定义的问卷转换为可部署的对话式调查，管理调查分发，收集受访者输入，并聚合生成的记录。其设计建立在模块化对话式调查系统之上，其中用户界面、提示、知识资源、会话变量和对话逻辑都是明确配置的。

3.3.1 调查规范
调查仍然是研究人员定义的测量工具。设 𝒬={qℓ}ℓ=1L \mathcal{Q}=\left{q_{\ell}\right}{\ell=1}^{L} 表示包含 L L 个问题对象的调查。每个问题表示为：

可部署的聊天机器人生成如下：

智能体可以使用 LLM 生成界面代码，将研究人员指令重新表述为聊天机器人逻辑，或生成供审查的初始实施。但是，未经研究人员明确批准，不能更改构建、响应量表、实验属性和强制性问题。此限制保留了受访者之间测量的一致性。

对于受访者 i i 和问题 ℓ \ell，设 hiℓ(r) h_{i\ell}^{(r)} 表示澄清轮次 r r 之后的交互历史。智能体评估累积响应是否满足问题要求：

智能体还可以提供程序性协助，例如解释调查术语、重复问题、更改交互语言或允许受访者修改先前的答案。此类协助不得推荐出行方式、暗示首选响应或以其他方式改变预期的行为任务。

3.5 数据建模智能体
数据建模智能体根据处理后的数据和用户指令 𝐮mod \mathbf{u}_{\mathrm{mod}} 构建、估计和评估行为模型。指令可以指定预测目标、解释变量、候选模型族、验证方案、评估指标和所需输出。智能体可以使用 LLM 将指令转换为正式的模型规范或可执行代码，但数值估计委托给选定的统计或机器学习工具。

建模请求表示为：
𝒢mod=(𝒴,𝒳,𝕄,𝒱,𝒞)

设 𝒟tr \mathcal{D}{\mathrm{tr}}、𝒟va \mathcal{D}{\mathrm{va}} 和 𝒟te \mathcal{D}{\mathrm{te}} 表示训练、验证和测试分区。智能体通过求解以下问题来选择模型族 m m 和配置 𝝀 \boldsymbol{\lambda}：

其中 ℛ^va \widehat{\mathcal{R}}{\mathrm{va}} 是验证损失，Ω(⋅) \Omega(\cdot) 是可选的复杂性或约束惩罚，η \eta 控制惩罚权重。然后选定的模型拟合为：

(28)
其中 𝒥 \mathcal{J} 是出行方式集，aisj∈{0,1} a_{isj}\in{0,1} 表示方式 j j 是否可用 (39)。当用户请求明确处理偏好异质性时，可以选择更灵活的规范，如混合 Logit 或潜在类别模型 (30)。

该框架还允许通过替代的提示框架进行基于 LLM 的选择预测。设 ρ(⋅) \rho(\cdot) 表示提示构建函数，ψ \psi 表示 LLM 配置。对于重复运行 r r，预测的选择为：
y^is(r)=Fψ[ρ(𝐩i,𝐳is,𝐚is,𝐮mod);ϵr],r=1,…,R

(29)
其中 ϵr \epsilon_{r} 表示跨重复运行的随机变化。选择方式 j j 的经验 LLM 概率为：
P^isjLLM=1R∑r=1R𝕀(y^is(r)=j)

(30)
LLM 预测器可以在零样本或少样本模式下运行。在零样本预测中，提示包含受访者配置文件、通勤场景、可用方式和输出要求，但没有标记示例。在少样本预测中，从训练数据中添加标记示例。不允许使用来自验证或测试受访者的示例。

当每个受访者贡献多个场景时，数据分区在受访者层面而不是记录层面进行。因此，
ℐtr∩ℐva=ℐtr∩ℐte=ℐva∩ℐte=∅
\mathcal{I}{\mathrm{tr}}\cap\mathcal{I}{\mathrm{va}}=\mathcal{I}{\mathrm{tr}}\cap\mathcal{I}{\mathrm{te}}=\mathcal{I}{\mathrm{va}}\cap\mathcal{I}{\mathrm{te}}=\varnothing
(31)
其中 ℐtr \mathcal{I}{\mathrm{tr}}、ℐva \mathcal{I}{\mathrm{va}} 和 ℐte \mathcal{I}_{\mathrm{te}} 是分配给这三个分区的受访者集。此规则防止来自同一受访者的信息同时出现在模型开发和评估中。

建模输出表示为：
ℛmod=(𝜽^,𝐘^,ℐeffect,𝒰model,𝒢diagnostic,𝒱evaluation)
\mathcal{R}{\mathrm{mod}}=\left(\widehat{\boldsymbol{\theta}},\widehat{\mathbf{Y}},\mathcal{I}{\mathrm{effect}},\mathcal{U}{\mathrm{model}},\mathcal{G}{\mathrm{diagnostic}},\mathcal{V}{\mathrm{evaluation}}\right)
(32)
其中 𝜽^ \widehat{\boldsymbol{\theta}} 包含估计参数或拟合模型状态，𝐘^ \widehat{\mathbf{Y}} 包含预测，ℐeffect \mathcal{I}{\mathrm{effect}} 包含效应估计或变量重要性度量，𝒰model \mathcal{U}{\mathrm{model}} 包含不确定性信息，𝒢diagnostic \mathcal{G}{\mathrm{diagnostic}} 包含诊断输出，𝒱evaluation \mathcal{V}_{\mathrm{evaluation}} 包含验证指标。除非研究设计支持因果识别，否则智能体必须区分预测关联和因果效应。

每个工作流版本遵循正向执行路径，每个阶段产生一个结构化输出，供下一个智能体通过定义的接口使用：向数据采集智能体提供调查规范，返回原始数据；向数据处理智能体提供原始数据，返回处理后的数据集；向数据建模智能体提供处理后的数据集，返回拟合模型、预测、诊断和评估指标。如图 1 中的虚线箭头所示，一个阶段的诊断可能会促使研究人员在后续工作流版本中批准修订早期的调查、处理或建模规范。当前的案例研究实施了一次正式的正向传递；虚线路径代表了后续版本支持的细化机制。第 4 节描述了如何为麦吉尔通勤者方式选择案例研究实例化这三个智能体，第 5 节报告了由此产生的分析和预测。

4 案例研究
第 3 节中的框架在加拿大蒙特利尔麦吉尔大学的通勤者方式选择案例研究中得到了实例化，该环境中的学生通过步行、骑行、公共交通和驾驶通勤，经历了从夏季炎热到冬季降雪的各种季节性天气。本节描述了在该案例研究中如何实施这三个智能体；详细结果见第 5 节。

4.1 数据采集智能体：聊天机器人调查与部署
数据采集智能体被实施为一个专门构建的对话式聊天机器人 TravelBehaviorSurveyBot，该机器人在 Voiceflow 中开发，并部署为可通过公共链接和二维码访问的网络应用程序（图 2）。受访者通过引导式对话在自己的设备上完成调查，该对话收集了人口统计和出行资源信息、通常的夏季和冬季出行模式、每周方式使用频率以及影响方式选择的因素评分，随后是五个 SP 天气场景。每个场景展示了一张使用定义提示生成的照片级真实感图像，以代表晴天、炎热潮湿、雨天、雾/冷和雪天通勤条件。所有受访者在每个场景中看到的都是相同的固定图像。对于每个场景，受访者在五个建模的替代方案中进行选择：步行、骑行、公共交通、骑行与公共交通结合以及驾驶。聊天机器人遵循预定义的调查逻辑，在部署期间未改变实验属性或选择集。图 2 说明了聊天机器人界面和调查期间呈现的天气图像。这种设计既不需要安装应用程序，也不需要访谈员，并确保了场景在受访者之间的一致呈现。第一阶段样本包括 92 名麦吉尔学生通勤者。

4.2 数据处理智能体
数据处理智能体将聊天机器人的原始 JSON 编码响应导出转换为可供分析的数据集。处理步骤包括解析嵌套列表和滑块值字段、验证和重编码分类响应、构建派生特征，以及标记不完整或不一致的记录以供排除。在来自 92 名受访者和五个场景的 460 个潜在观测中，有 6 个因记录的方式选择缺失或无法解析而被排除。因此，最终处理的数据集包含 454 个有效的受访者-场景观测。关键的派生特征包括按季节划分的每周方式使用频率、七个因素重要性得分、二元的车辆/驾照/自行车所有权标志以及骑行经验年数，这些在第 5.1 节中报告。

4.3 数据建模智能体：建模与 LLM 设置
数据建模智能体在处理后的数据集上实施了两个模型族。传统模型族包括在 Biogeme (5) 中估计的 MNL 和 ML 分类器，主要是逻辑回归和随机森林。LLM 模型族包括 9 个本地运行的模型，参数量从 20 亿到 350 亿不等。传统和 LLM 方法作为并行的模型族执行，而不是顺序的建模阶段。对于每个受访者-场景对，LLM 接收受访者配置文件的自然语言表示以及相应的天气条件，并被要求预测选择的出行方式。提示实验遵循结构化的进展，其中两种提示框架——专家（EXP）和角色扮演（RP）——与两个级别的上下文信息——基础上下文（BC）和丰富上下文（RC）——交叉；更丰富的设置纳入了来自受访者配置文件的额外习惯性出行信息。然后，通过基于使用三类潜在类别分析提取的受访者角色的角色增强提示、在 k k 的几个值下带有标记示例的少样本上下文学习，以及使用向调查受访者展示的相同天气图像为具备视觉能力的模型提供直接图像输入，对这四个基础条件进行扩展。对五分类方式选择任务和二元主动与非主动分类的预测均进行了评估，所有 LLM 和传统模型都在相同的 454 个受访者-场景观测上进行了评估。准确率是相对于五分类任务 20.0% 和二元任务 50.0% 的随机猜测基线进行报告和解释的。完整的传统模型估计和 LLM 实验在第 5 节中报告。

5.2 LLM 零样本
零样本实验评估了提示设计的两个维度：上下文丰富度和提示框架。基础上下文（BC）包括受访者人口统计、出行资源、因素重要性评分和天气场景，而丰富上下文（RC）另外纳入了额外的习惯性出行信息。专家（EXP）框架要求 LLM 作为交通专家预测受访者的选择，而角色扮演（RP）框架要求模型直接模拟受访者。由此产生的四个条件——EXP-RC、EXP-BC、RP-RC 和 RP-BC——在 9 个本地部署的 LLM（参数量从 20 亿到 350 亿不等）上进行了评估（表 3）。

图 5 揭示了两种一致的模式。首先，纳入额外的习惯性出行信息显著改善了零样本预测。对于 Gemma 3:4B，五分类准确率从 EXP-BC 下的 41.3% 提高到 EXP-RC 下的 64.2%，表明习惯性出行信息提供了超越人口统计和出行资源的强预测信号。其次，在相同上下文水平下，专家框架通常优于角色扮演框架，这种差异在较小模型中更为明显。评估集中较大的模型通常比最小的模型产生更高的五分类准确率，尽管这种模式不是单调的，且模型大小与模型族和架构混淆。最高的零样本五分类点估计由 Gemma 4:12B 达到，约为 70%，而二元准确率在各模型间的变化较小。总之，这些结果表明，提供给模型的信息和预测任务的框架可能与所选模型一样重要。

5.3 高级 LLM 配置：角色、少样本和视觉
高级实验检验了额外的行为和上下文信息是否能在基础零样本配置之外改善预测。当缺乏明确的出行历史时，角色增强最为有益。在基础上下文下，添加行为角色显著改善了一些较小的模型，特别是 Llama 3.2:3B，而当丰富上下文已经包含受访者习惯性季节性出行方式时，其效果有限。这种模式表明，角色信息主要在缺乏直接出行历史信息时总结行为信息，而不是在习惯性出行信息已经可用时添加大量信息。

少样本提示在五分类预测中提供了进一步的改进，尽管增益的幅度因模型而异，并且随着引入更多示例而递减。图 7 显示，少量标记示例改善了大多数模型的性能，在较小模型中比例增益更大。准确率通常在约十个示例后趋于稳定，而额外的示例提供的改进有限或不一致。所考虑的替代示例选择策略产生了大致可比的性能，表明信息性示例的存在比复杂的检索策略更重要。这些改进在五分类任务中比在二元主动与非主动分类中更为明显，表明少样本提示对于预测特定出行方式特别有效。

使用向调查受访者展示的相同生成的天气图像，对具备视觉能力的模型进行了进一步评估。视觉输入为几个模型提供了额外的上下文信息，尽管效果并不统一。对于一些较大的模型，基于视觉的提示接近或超过了相应的基于文本的丰富上下文性能，表明特定的场景图像提供的预测信号可以补充或部分替代基于文本的上下文描述。例如，当用场景图像替换文本天气表示时，Qwen 3.6:35B 有所改善，而当视觉输入与少样本示例结合时，Gemma 4:26B 进一步受益。其他模型显示出较小的增益或下降，表明多模态能力本身并不能保证改进的方式选择预测。

总体而言，高级实验表明，当额外信息有助于提示中尚未表示的行为或上下文信号时，它最有价值。习惯性出行信息仍然是最一致的预测信息来源，当缺乏该历史时，角色描述特别有用，而少样本示例提供了有用的任务指导，但收益递减迅速。视觉输入提供了独特的上下文信息来源，可以改进特定模型的预测，支持在出行行为应用中进一步评估多模态 LLM。

6 讨论
结果表明，在用于出行行为研究的通用多智能体工作流中，对话式数据采集、传统行为模型和基于 LLM 的预测如何联系起来。超越任何单个模型的性能，本研究为三个更广泛的问题提供了证据：AI 辅助调查是否能捕捉有意义的依赖于背景的出行行为，哪些形式的信息对基于 LLM 的方式选择预测最有用，以及这些模型与既定的 DCM 和 ML 方法相比如何。

多智能体工作流与行为证据。
该工作流通过结构化输出将数据采集、数据处理和数据建模智能体联系起来，创建了一个从调查管理到行为预测的透明和模块化过程。这种组织本身并不能提高准确率；相反，它实现了数据的一致传输，并系统评估性能提升的来源。聊天机器人调查在天气场景中产生了连贯的差异：随着条件恶化，骑行和骑行+公共交通下降，而公共交通获得了相当大的份额。MNL 估计与这些描述性模式一致，显示在不利场景下骑行相关方式的相对效用较低，而公共交通和驾驶的相对效用较高。这种一致性支持了调查回复的内部连贯性，尽管它本身并不能确立外部有效性或实际天气下的实际出行行为。

LLM 配置与传统模型的比较。
LLM 性能受到提示中包含的信息的强烈影响。RC 在 BC 的基础上增加了习惯性出行信息，产生了最一致的改进，表明习惯性出行行为包含了人口统计和出行资源未完全捕捉的预测信息。EXP 框架通常优于 RP，特别是对于较小模型，而随着模型规模增大，增加模型规模带来的收益递减。

角色增强和少样本提示在提供缺失信息时最为有用。角色描述主要在 BC（习惯性出行信息不可用）下改善了预测，但在 RC 下几乎没有增加什么。少样本示例提高了几个模型的五分类准确率，特别是较小模型，尽管增益通常在少量示例后趋于稳定。

因此，传统和基于 LLM 的模型发挥着互补的作用。MNL 提供行为解释，而逻辑回归和随机森林提供数据训练的预测基准。随机森林达到了最高的训练模型准确率，而最佳的零样本 LLM 在无需对调查记录进行特定任务拟合的情况下，产生了可比的五分类点估计。这一结果表明，当标记的出行行为数据有限时，基于 LLM 的预测具有潜在价值，尽管样本量小和评估的多种配置需要谨慎解释。五分类任务为模型是否能区分个体方式提供了更清晰的评估。

基于视觉的预测。
视觉实验通过向模型提供向受访者展示的相同生成的天气图像，直接连接了多智能体工作流的调查和预测阶段。最佳的基于视觉的配置达到了 71.5% 的五分类准确率点估计，相比之下，最高的纯文本零样本 LLM 结果为 69.9%，随机森林为 69.6%。这些微小的差异应被解释为描述性点估计差异，而不是统计优势的证据。视觉与少样本提示结合也为特定模型产生了增益。因为每种天气条件由一张固定图像表示，结果表明这些特定图像为特定模型提供了额外的预测信号；它们并不能确立对未见天气图像或视觉环境的泛化。

局限性与未来研究。
在解释研究结果时，应考虑到几个局限性。样本由来自一所大学的 92 名学生组成，不能代表更广泛的人群。分析基于陈述选择，而不是实际天气条件下的实际出行，且生成图像中不受控制的视觉特征可能影响了受访者和模型。每种天气条件由一张固定图像表示，因此天气条件和图像身份没有单独识别。相对较小且不平衡的数据集也限制了对少数方式和出行者子群体的详细分析，而结果可能因其他 LLM 族和推理设置而异。框架本身未与传统研究工作流进行实验比较；因此，其贡献在于集成性、可追溯性和模块化，而不是在调查成本或处理工作量的可测量减少。此外，配置比较是探索性的，报告的最高准确率可能部分反映了对同一样本上多个模型和提示设置的评估。未来的研究可以用更大、更多样化的样本、额外的出行目的和地点以及显示偏好验证来评估该工作流。受控的图像实验可以分离天气、道路条件和周围环境的影响。进一步的工作还可以检查预测校准、子群体性能和跨人群的可转移性。多智能体工作流可以支持自适应调查和经过仔细验证的合成受访者，但在将此类输出用于交通规划或政策分析之前，应针对人类行为进行验证。

7 结论
本研究开发并评估了一个多智能体工作流，该工作流在统一的出行行为研究框架内，整合了对话式调查设计、AI 生成的视觉场景、结构化数据处理、传统选择和机器学习模型以及基于 LLM 的预测。该工作流使用 92 名麦吉尔学生通勤者在五个图像增强天气场景下的陈述方式选择进行了演示。

实证结果支持三个主要结论。首先，对话式调查产生了跨天气条件的行为连贯响应，恶劣天气减少了骑行相关选择并增加了对公共交通的依赖。其次，MNL、随机森林和基于 LLM 的预测器的比较突出了它们的互补作用。MNL 提供了可解释的行为关系，随机森林提供了强大的训练预测基准，而 LLM 能够灵活地纳入习惯性出行信息、角色描述、示例和视觉上下文，而无需为每种信息类型单独指定模型。第三，LLM 性能在很大程度上取决于提示设计和输入配置。习惯性出行信息和面向专家框架通常改善了预测，而选定的具备视觉能力的模型则受益于纳入向受访者展示的相同天气图像。最佳的零样本 LLM 在无需对调查观测进行特定任务拟合的情况下，达到了与训练机器学习基准相当的点估计。

因此，本研究的主要贡献不是取代既定的出行选择模型，而是展示了一个集成且可扩展的工作流，在该工作流中，数据采集、处理、行为分析、预测建模和多模态推理可以通过专门智能体进行协调。该框架为将异构行为信息纳入出行选择分析提供了实用基础，同时保留了传统模型用于解释、基准测试和验证。更广泛地说，研究结果表明，如果 LLM 的输出能够针对观测到的人类行为进行系统评估，它们可能会扩展交通研究中出行者特征和背景条件的表示方式。
