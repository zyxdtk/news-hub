Canva 发布其首个图像生成模型

📅 2026-10-22 📄 TechCrunch AI 🔗 原文链接

原标题：Canva releases its first image generation model

中文摘要： Canva 发布其首个图像生成模型 Craft，采用两阶段工作方式：先解读用户提示词并制定包含空间关系、视觉层次等细节的计划，再生成最高 2K 分辨率、支持 30 种宽高比的图像。该模型使用 Canva 库中人工设计模板而非照片训练，生成的图像可通过 Canva Magic 转换为分层设计。模型已向所有用户开放，并将通过 API 及 ChatGPT、Gemini 等第三方聊天机器人提供。Canva 还在开发 Craftfast 和 Craft-ultrafast 两个高性价比版本。

该公司表示，其模型分两个阶段工作。在第一阶段，它会解读用户的提示词，并制定一个计划，其中包含元素的空间关系、相对比例、视觉层次结构以及文本生成信息等细节。在第二阶段，该模型会生成最高 2K 分辨率的图像，并支持多达 30 种不同的宽高比，以适配各种平台。

Canva 表示，这种方法使其能够创建具有精确物体细节和清晰可读文本的图像。此外，用户还可以进行精确编辑，而不会改变图像的其他部分。

该公司指出，它没有使用照片，而是使用 Canva 库中人工设计的模板来训练该模型，包括海报、社交媒体帖子、演示文稿、信息图表、菜单和富含排版设计的布局。

这意味着使用 Canva Craft 生成的图像可以通过 Canva Magic（该公司的图像转设计转换器）转换为分层设计。去年，该平台发布了能够理解设计和图层的自有模型。

Canva Craft 已在该公司的平台上向所有用户开放，用户可以从 Dream Lab 标签页访问该模型。该模型还将通过 Canva API 提供。此外，该公司计划通过 Canva 的 MCP 支持在 ChatGPT 和 Gemini 等第三方聊天机器人中进行图像生成。

Canva 一直在其平台上使用多种图像模型进行生成，因此新模型很可能有助于该公司节省 API 成本。该公司表示，除了成本之外，新模型还使平台能够更好地控制质量和速度。

2024 年，Canva 收购了媒体生成平台 Leonardo.ai。该公司表示，来自 Leonardo 的研究人员为新图像模型做出了贡献。

Canva 表示，正在开发该模型的两个高性价比版本，分别名为 Craftfast 和 Craft-ultrafast，即将发布。

该公司去年的收入有望达到 40 亿美元。然而，据外部分析师称，该公司下调了 2026 年的增长预测，导致其估值据报道从 420 亿美元暴跌至 350 亿美元。
