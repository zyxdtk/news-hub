摘要 现有提升大型视觉-语言模型（LVLMs）效率的方法大多基于视觉标记减少的概念。然而，这种方法会形成信息瓶颈，损害模型性能，尤其在需要细粒度理解和推理的复杂任务中表现明显。本文提出一种新范式——VISion On Request（VISOR），该方法在不丢弃视觉信息的前提下降低推理成本。与压缩图像不同，VISOR 通过稀疏化图像与文本标记之间的交互来提升效率。具体而言，语言模型通过少量战略性放置的注意力层，关注完整的高分辨率视觉标记：文本-图像之间的高效交叉注意力提供通用视觉上下文，而少数精心放置且动态选择的自注意力层则进一步优化视觉表示本身，从而在需要时支持复杂的高分辨率推理。

1 引言 大型视觉-语言模型（LVLMs）在多模态理解方面展现了卓越的能力 [48, 8, 22]。这些系统通常将视觉编码器（例如 CLIP [36]）与大型语言模型（LLM）[43, 16, 48] 配对。视觉编码器将输入图像映射为密集的视觉标记，这些标记通过连接模块传递，并与文本提示/查询一起输入到 LLM 中。LVLM 的大部分计算开销源于大量视觉标记，而这一成本会随着图像分辨率的提高而急剧增加 [22]。

为了缓解这一问题，大量研究提出了“标记减少/压缩”的思路。这些方法通过在测试时动态剪枝和/或合并冗余标记 [1, 47, 50, 56, 6]，或通过训练专用压缩器 [4, 14, 9] 来减少视觉标记的数量。尽管这些方法在需要粗粒度视觉理解的任务中表现良好，但我们发现，它们在需要精细视觉理解的复杂、高分辨率任务中往往会造成显著的信息损失。请参见图 10 中“简单”与“困难”任务的准确率对比。这表明

不令人意外，因为此类方法通过减少视觉标记的数量，不可避免地会创建一个信息瓶颈。 在本工作中，我们提出了一条与现有标记压缩方法完全不同的、正交的路径，以提高大视觉语言模型（LVLMs）的效率。与以往旨在减少LVLM处理的视觉标记数量的标记减少/压缩方法不同，我们的方法旨在减少/稀疏化LVLM内部执行的计算层数。具体而言，我们的方法在LVLM中战略性地仅执行少量的交叉注意力和自注意力层，使得模型仅在前向传播过程中的少数选定点上对完整的视觉标记集进行注意力计算和更新。由于这一特性，我们将该方法命名为VISOR（Vision on Request，按需视觉）。我们的思路建立在这样一个观察之上：查询和答案标记仅在少数几个关键层中稀疏地与视觉标记进行交互[17]。我们证明，这一现象高度依赖于任务本身，不同任务在关键层的位置、层数以及稀疏程度上存在显著差异，这取决于任务的复杂性。 总体而言，我们做出以下贡献： • 首先，我们将LVLM层分解为图像-图像和文本-图像（跨模态）交互，并表明，对于需要粗粒度视觉理解的任务，仅执行少量廉价的文本-图像交叉注意力层（这些层作用于相同的视觉表示）就已足够。仅此一项就可显著提升效率。

在一系列视觉-语言基准测试中，VISOR 在准确性和速度方面均超越了先前的最先进方法。

• **第二**，我们证明了对于复杂任务，无论是先前的工作还是我们仅使用交叉注意力的变体，都难以实现细粒度的视觉理解。我们认为这是由于交叉注意力层允许语言标记关注图像信息，但并不会更新或修改视觉标记本身。为了解决这一问题，我们引入并执行少量自注意力层，用于**更新视觉标记**，从而实现从低级到高级视觉特征的逐步优化。

• **第三**，由于不同任务和样本需要不同程度的视觉细节，我们首先通过调整自注意力层数量，在多种计算预算下训练一个单一的通用网络。然后，我们提出一种**自适应推理**方法，利用通过离线伪标注训练的轻量级策略机制，自动为每个样本选择应执行的自注意力层。

• **第四**，我们展示了 VISOR 可以**与现有的标记减少方法结合**，在不牺牲性能的前提下进一步提升效率。

尽管这些方法表现出有前景的结果，但大多数方法主要关注较粗粒度的理解。

和低分辨率任务，通常使用 LLaVA-1.5 模型 [4, 50, 2]。很少有工作（例如 [1, 21]）考虑更具有挑战性且更细粒度的任务，这些任务需要更高的分辨率，而那些尝试处理此类任务的研究要么在准确率上出现大幅下降 [1]，要么在这些数据集上几乎没有速度提升 [21]。在本研究中，我们在统一的设置和架构下进一步评估现有方法，并指出这是现有 token 减少方法中的普遍趋势。我们认为，这种性能下降主要源于 token 减少过程中固有的信息瓶颈。

为了解决这一问题，VISOR 完全绕过了 token 减少范式。它不通过丢弃 token 来降低计算成本，而是战略性地限制语言模型与视觉信息交互并更新视觉信息的层数，从而在整个模型中保持对完整、高分辨率视觉上下文的访问。这确保了关键的视觉细节永远不会永久丢失，并且在需要进行细粒度推理时，模型可以随时访问这些细节，同时仍能实现显著的计算节省。此外，我们的方法与现有的 token 压缩方法是正交的，可以与它们结合使用，以进一步提升效率。

4.2 按需视觉（VISOR） 为了减少

### 4.2.1 通过交叉注意力实现高效的视觉上下文

对于许多任务，LLM 只需要查询视觉特征，而无需更新它们。交叉注意力层为此提供了一种高效机制，因为它可以在不修改视觉表示的情况下，将视觉信息整合到文本处理流中。

tokens 本身。我们通过让大多数 Transformer 层仅在文本 tokens 上操作来利用这一点。然后，我们指定一小部分均匀分布的层，其索引集合记为 $\mathcal{L}_{CA}$，用于执行交叉注意力（cross-attention），从而允许文本流在选定位置高效查询静态的视觉特征。

设 $\mathbf{V}^{(0)}$ 为视觉编码器输出的初始视觉 tokens。对于第 $l$ 层，更新规则如下：

$$ \begin{split} \mathbf{V}^{(l)} &= \mathbf{V}^{(l-1)}, \\ \mathbf{T}^{(l)} &= \begin{cases} \text{TL}_{l}(\text{CrossAttn}(\mathbf{T}^{(l-1)}, \mathbf{V}^{(l-1)})), & \text{if } l \in \mathcal{L}_{CA} \\ \text{TL}_{l}(\mathbf{T}^{(l-1)}), & \text{otherwise.} \end{cases} \end{split} \tag{2} $$

CrossAttn 模块以文本 tokens 作为查询（queries），以视觉 tokens 作为键（keys）和值（values），其输出残差加到文本流上。关键的是，在这种仅使用交叉注意力的变体中，视觉 tokens $\mathbf{V}^{(l-1)}$ 从不更新（即 $\mathbf{V}^{(l-1)} = \mathbf{V}^{(0)}, \forall l$），从而使得整个过程非常高效。

最后，为确保视觉 tokens 保留位置信息（这对于空间推理至关重要），受 Chu 等人 [10] 的启发，我们将条件位置编码（conditional positional embeddings）的思想适配到一维序列，并使用一维深度卷积（1D depth-wise convolution）来实现。

4.3 自适应推理 如第 3 节所述，所需的视觉处理量会因任务而异，甚至在同一基准测试中的不同样本之间也存在显著差异。这一观察表明，单一固定的配置可能并非所有场景下的最优选择。为解决此问题，我们采用第 4.2.3 节中提出的通用模型（设计用于在一系列预定义的计算预算下运行），并引入一个轻量级策略网络，该网络能够动态决定为每个输入执行多少个自注意力层，从而实现逐样本的自适应。

我们通过内部路由机制实现这一功能。在问题之后附加一个特殊的 **路由 token**，并在第一个可能被跳过的自注意力块之前的块中放置一个 MLP 层。该 MLP 处理路由 token，并预测后续自注意力层的最优配置。

如果存在多个问题，模型会保守地选择各个预测中计算成本最高的配置，以确保有足够的处理能力。

由于训练路由机制可能不稳定 [12]，我们采用离线伪标签方法。首先，我们在训练子集上运行通用模型，记录每个潜在层配置的正确性以及 token 级别的损失。然后，我们为该子集生成伪标签，方法是 i

4.4 将按需视觉（Vision-on-Request）与令牌减少相结合 我们的方法与现有的令牌减少方法是正交的，可以与它们结合以进一步提升效率。为此，我们探索了两种策略：(i) 将VISOR与表现最佳的令牌剪枝方法结合 [50, 53]，以及 (ii) 设计一种简单的令牌打包策略，该策略可适用于任意令牌压缩比。后者被称为VISOR-TR。更多细节请参见补充材料。

7 结论 在本工作中，我们提出了Vision-on-Request（VISOR），一种通过稀疏化图像-文本和图像-图像交互来降低LVLMs推理成本的方法，同时不丢弃视觉信息（与以往的token减少方法不同）。VISOR使用高效的交叉注意力机制建模文本-图像交互，并采用少量选择性的自注意力层对视觉特征进行精炼，以支持细粒度的视觉理解和推理。 VISOR在一系列计算预算下训练一个通用网络，然后在推理阶段利用轻量级策略，根据每项任务或每个样本的复杂度动态分配视觉计算资源。我们证明，VISOR显著提升了效率，并在广泛基准测试中超越了最先进的token压缩方法，尤其在需要详细视觉理解的挑战性任务上表现突出。

Appendix I 关于 Token Packing 的额外细节 为进一步增强一个

为在主文中验证我们方法的有效性，我们引入了一种轻量级的 token 打包适配方案，能够支持非 2 的幂次的压缩率。

具体而言，在视觉编码器之后，我们将 patch 嵌入重新重塑回其 2D 空间网格，然后在每个空间维度上以 $1/\sqrt{2}$ 的因子对网格进行插值，实现 $2\times$ 的压缩比，接着应用 space-to-depth 变换（像素重排）。该方法能确定性地将视觉 token 数量减半，同时信息损失极小且不引入额外参数，与我们稀疏注意力设计带来的计算节省相辅相成。注意，插值因子可向上调整以适应任意压缩率。

附录 L 基线方法的重新实现 在本节中，我们详细说明了我们对所比较基线方法的重新实现以及所使用的超参数。由于 LLaVA-OV 使用的是不包含 CLS token 的 SigLIP-400M 视觉编码器，因此对于所有依赖 CLS token 注意力分数来选择重要 token 的方法，我们改用序列中每个 token 从其他所有 token 获得的平均注意力，如 Yang 等人 [50] 所提出的方法。

VisionZip。VisionZip [50] 是一种基于视觉编码器注意力分数选择最重要 token（称为“主导 token”）的 token 减少方法。为了避免信息丢失，剩余的 token 会根据语义相似性合并为“上下文 token”。在我们的实验中，我们将官方 VisionZip 的 LLaVA-Next [27] 代码适配到 LLaVA-OV。与 LLaVA-Next 不同，LLaVA-OV 的图像处理 AnyRes 策略在 token 数量超过阈值时会进行双线性插值。为了避免对已移除 token 进行插值导致的错误，并尽量贴近原始设计，我们移除了这一步骤。

Yang 等人 [50] 还提出了 VisionZip†，即经过训练的版本，该版本对跨模态投影器进行了微调。为了公平比较，我们训练了 Visi

onZip † 在 LLaVA-OV 单图像 3.2M 数据集 [22] 上。在所有 VisionZip 和 VisionZip † 实验中，我们将每个图像块保留的 token 数量设置为 128，分为 104 个 主导 token 和 24 个 上下文 token 。

VisPruner. VisPruner [53] 是一种无需训练的 token 剪枝方法，基于视觉注意力分数保留视觉 token。它首先选择 重要 token ，即得分最高的 token，然后通过保留基于相似度的 多样化 token 来去除重复项。与 VisionZip 类似，我们将官方 VisPruner LLaVA-Next 代码适配到 LLaVA-OV 主干网络。在我们的实验中，每个图像块保留 128 个 token，分为 96 个 重要 token 和 32 个 多样化 token 。

HiRed. 高分辨率早期丢弃（HiRed） [1] 是一种即插即用的 token 减少方法，设计用于在固定预算下工作。它针对高分辨率 LVLM（即 LLaVA-Next）并在 token 到达 LLM 之前进行丢弃。核心思想是使用完整图像的注意力分数评估每个图像块的视觉内容，然后相应地为每个图像块分配预算。在每个图像块内，保留最具信息量的 token 并传递给 LLM。在我们的实验中，我们按照与 VisionZip 和 VisPruner 相同的方法，将官方代码适配到 LLaVA-OV。在我们的实验中，我们使用与原始实现相同的超参数，设置 token 预算为 20%。

M³. Matryoshka 多模态模型（M³） [4] 将视觉内容表示为嵌套的

一组在不同细节层次（从粗到细）上捕获信息的视觉标记。编码器生成的视觉标记被分组为多个从粗到细的层次，其中较粗的标记 $X_{S_{i-1}}$ 是通过平均池化从较细的标记 $X_{S_{i}}$ 得到的。M³ 方法不引入任何额外参数。为了公平比较，我们在 LLaVA-OV Single-Image 3.2M 数据集 [22] 上训练 M³，同时更新视觉编码器和大语言模型（LLM）的权重。在我们的实验中，我们定义了一组尺度 $\{X_{S_{i}}\}_{i=1}^{M}$，分别将视觉标记数量减少为原始数量的 1、4、8 和 16 倍。为了与我们的方法进行公平比较，我们在 8× 减少的情况下报告结果。

PyramidDrop。PyramidDrop [47] 是一种渐进式标记剪枝方法，随着 LLM 层深度的增加，逐步减少视觉标记的数量。具体而言，LLM 层被划分为多个阶段，每个阶段开始时，根据预定义的、按阶段设定的缩减率减少视觉标记数量。在每次剪枝步骤中，输入特征被分为视觉特征和文本特征，然后仅保留与用户查询或指令最后一个标记位置对应的文本特征，从而得到 $N_{v} \times d$ 维的视觉特征和一个单一的文本特征向量。接着，将下一个注意力层应用于这些特征，其中文本特征作为 t

查询，从而生成图像-文本注意力权重，这些权重被解释为每个视觉标记的重要性得分。这些得分与每个阶段预定义的丢弃率（drop-rate）结合，用于保留得分最高的前 k 个视觉标记，其中 k 为目标保留的视觉标记数量。该过程在 LLM 的每一层深度的每个阶段开始时逐步应用。在我们的实现中，对于具有 24 层 LLM 的 LLaVA-OV 0.5B，我们定义了 4 个阶段： `(1, 2-6, 7-12, 13-24)`， 对应的丢弃率为 `(1.0, 0.3, 0.2, 0.1)`，适用于简单数据集； 而对于困难数据集，阶段定义为 `(1-4, 5-10, 11-16, 17-24)`， 丢弃率为 `(1.0, 0.5, 0.25, 0.125)`，平均 FLOPs 节省达到 `4.2×`。 对于具有 28 层 LLM 的 LLaVA-OV 1.5B，我们定义了 5 个阶段： `(1, 2, 3-6, 5-10, 11-28)`， 丢弃率为 `(1.0, 0.5, 0.3, 0.2, 0.1)`，适用于简单数据集； 而对于困难数据集，阶段定义为 `(1-2, 3-8, 8-12, 13-18, 19-28)`， 丢弃率为 `(1.0, 0.75, 0.5, 0.25, 0.125)`，平均 FLOPs 节省达到 `4.6×`。
