Superhuman 全力推广其 Go 助手

📅 2026-11-19 📄 TechCrunch AI 🔗 原文链接

原标题：Superhuman pushes its Go assistant everywhere

中文摘要： Superhuman 正大力推广其 Go AI 助手，使其能跨应用学习上下文并提供个性化提示建议。新功能包括：与光标内联协作、主动管理日程与邮件、学习用户写作风格，并通过 Go SDK 新增 20 个连接智能体（如 DeepL、Databricks 等）。Go 正取代 Mail 中的 AI 成为核心工具，支持企业搜索和跨账户收件箱整理。公司还推出实时协作笔记功能，并可在会后自动起草提案初稿。Go 已拥有超 100 万活跃用户，CEO 表示其虽侧重工作场景，但也可协助处理个人事务。

尽管该公司的一些 AI 功能曾受到批评，但 Superhuman 在去年品牌重塑后开始大力推广其 Go 助手。随着新版本的推出，Go 现在可以跨不同应用学习上下文，并为提示词提供更好的个性化建议。Superhuman 正在改进其新手引导流程，让用户连接自己偏好的工具，并预先加载与其工作相关的上下文。

该助手与光标内联协作——就像 Grammarly 一样——并且还能管理其他智能体。Superhuman 还在让该智能体变得更加主动，这意味着它会查看你的日程安排、留意你的电子邮件，甚至起草回复。更新后的 Go 智能体还会学习用户的写作风格，并在电子邮件和 Docs 中做出相应的回应。

这家生产力公司正在通过其 Go SDK 新增 20 个连接智能体，包括 DeepL、Legora、Amplitude、Databricks 和 Blackboard。

该公司还在考虑将 AI 引入不同的产品，包括 Docs 和 Superhuman Mail。在 Docs 中，所有 Go 智能体均可原生运行，你可以让它们在后台处理不同的任务。用户还可以设置例程，根据事件触发工作流程。

图片来源：Superhuman

到目前为止，Mail 一直将 AI 作为其核心工具，而现在正被 Go 取代。用户还可以利用公司知识库和已连接工具中的数据进行企业搜索。Go 还会利用这些上下文来起草内容，并整理 Google 和 Outlook 账户的收件箱。

Superhuman 于 9 月收购了笔记工具 Fathom，为其产品套件增加更多上下文。该公司现在正在推出实时协作笔记功能，可在团队间共享。此外，Go 现在可以在会议结束后做出决策，比如起草提案的初稿。

图片来源：Superhuman

公司 CEO Shishir Mehrotra 表示，Go 发展势头良好，已拥有超过 100 万活跃用户。如今有大量智能体正在个人和专业领域争夺用户的注意力。Mehrotra 认为，虽然 Go 更侧重于工作场景，但它也可以帮助处理个人电子邮件和日程安排。

“这些助手之所以受欢迎，原因之一在于它们把你当作一个完整的人来对待，并认识到我们需要兼顾两个极端。Go 肯定比一些来自纯消费者生态系统的工具更侧重于工作。但这并不意味着我们会划清界限，不帮助你处理个人任务、日历或所有电子邮件，”他在与 TechCrunch 的通话中表示。

虽然 Go 可能不会与 Instinct、Muse 和 Fo 等产品直接竞争，但 Superhuman 希望用户选择它的助手，而不是 OpenAI 的 Dots 或 Claude Duet 之类的产品。
