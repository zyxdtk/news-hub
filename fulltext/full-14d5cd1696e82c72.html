## 面向灵巧操作的极简重定向引导强化学习方法

Yunhai Feng¹, Natalie Leung¹, Jiaxuan Wang¹, Lujie Yang², Haozhi Qi², Preston Culbertson¹

¹康奈尔大学 ²Amazon FAR

### 摘要

近期在人形机器人全身控制领域的研究中发现了一个简单而有效的方案：将人体运动重定向为机器人运动学参考，然后通过强化学习（RL）训练策略来跟踪这些参考。但这一方案如何迁移到灵巧操作中呢？答案并不显而易见，因为操作涉及复杂的、富接触动力学，并且需要对接触模式和接触力进行精细调节。我们提出了 **Regrind**，一个极简的重定向引导RL流程，能够从单次人类演示中学习灵巧操作策略。Regrind将人手与物体的运动重定向为保持手-物空间和接触关系的机器人参考轨迹，在仿真中训练残差RL策略来跟踪沿该参考轨迹的以物体为中心的关键点，并通过精心的系统辨识将所得策略零样本迁移到硬件上。最终策略在两种不同的多指机械手上产生了流畅的、类人的行为，涵盖富接触工具使用任务，包括操作剪刀和转动螺丝刀。通过系统的硬件实验，我们识别并分析了影响灵巧操作中仿真到现实迁移的关键因素，为富接触环境中基于重定向的学习提供了实用指导。视频和代码可在 https://yunhaifeng.com/REGRIND 获取。

**图1：灵巧工具使用任务。** 我们提出了一种极简的重定向引导RL流程，从单次人类演示中学习灵巧操作。我们在两种机器人手上的四个富接触任务-手部设置上评估了我们的方法： LEAP-剪刀、 WUJI-螺丝刀、 LEAP-螺丝刀和 WUJI-剪刀。

**关键词：** 灵巧操作、运动重定向、仿真到现实迁移

### 1 引言

人形机器人和拟人化手与人手共享运动学结构，这为直接从大量人体运动数据中学习技能提供了可能。在人形机器人全身控制中，这已经形成了一个简单且日益有效的方案：将人体运动参考重定向到机器人上，在仿真中训练策略来跟踪重定向后的参考，然后将策略部署到硬件上 [19, 45]。然而，灵巧操作在很大程度上走了一条不同的道路。当前的操作技能通常是从直接在真实机器人上收集的遥操作演示中学习的 [49, 42, 4]，对人体运动数据或大规模仿真的利用有限。

虽然近期的工作探索了将人形机器人风格的重定向流程用于灵巧手，但结果大多局限于仿真或仿真运动的闭环回放 [18, 24]。对于这种在现实世界中有限成功的一个假设是：简单的运动学重定向虽然能紧密匹配人手姿态，但忽略了手-物交互，产生了物理上不合理的轨迹，这对下游RL来说是一个糟糕的参考。这引出了一个自然的问题：**在重定向过程中保持交互是否能改善富接触灵巧操作的RL效果？**

在本工作中，我们通过提出 **Regrind** 来回答这个问题：**RE**targeting-**G**uided **Re**IN**forcement learning for **D**exterous manipulation，一个从单次人类演示中学习富接触灵巧操作技能的极简流程。我们首先将人手-物运动重定向为保持交互的机器人参考轨迹，维持手与物体之间的空间关系。为缓解多指灵巧操作数据的稀缺性，我们通过扰动初始配置动态增强重定向后的参考轨迹，以提供对任务空间更广泛的覆盖。然后，我们在仿真中训练一个残差RL策略来跟踪沿该参考轨迹的以物体为中心的关键点，将重定向后的轨迹同时用作运动先验和探索的重置分布。

所得策略能够迁移到真实的多指手上，完成具有挑战性的工具使用任务，包括操作剪刀和转动螺丝刀，这些任务需要协调的手指运动、复杂的接触转换以及利用摩擦的交互。

同时，我们的研究揭示了运动与操作之间的一个重要区别。虽然基于重定向的学习可以产生高度有效的操作策略 [18, 24]，但灵巧操作对仿真到现实差异表现出更大的敏感性。操作依赖于机器人与物体之间丰富的、持续的接触，当策略的成功取决于这些交互时，摩擦、柔顺性或几何方面的小建模误差会迅速累积。我们的结果表明，成功的仿真到现实迁移不仅需要保持交互的重定向，还需要精心设计的观测和动作空间、适当的域随机化和课程学习，以及仔细的系统辨识。这些要素共同构成了仿真到现实灵巧操作的实用方案。

**我们的贡献如下：**

- 我们提出了一个通用且极简的框架，从单次人类演示中学习灵巧操作。我们发布了代码和数据，供社区复现结果并在我们的工作基础上构建。 - 我们应用了一种简单而有效的数据增强策略，使RL策略暴露于多样化的轨迹中，以提高鲁棒性和泛化能力。 - 我们在具有挑战性的富接触灵巧操作任务上评估了我们的方法，并展示了其相对于现有方法的优越性能，特别是保持交互的运动重定向的价值。

### 2 相关工作

**基于强化学习的灵巧操作。** 强化学习（RL）推动了灵巧操作的大部分进展。虽然一些工作直接在真实世界中训练操作策略 [52, 25, 23, 7]，但真实世界交互的高成本和RL的样本低效性使得在仿真中训练后进行仿真到现实迁移成为更实际的方法。这类仿真到现实的工作从重新定向立方体和求解魔方 [27, 10, 26]，发展到重新定向多样化物体 [2, 31, 32, 43]，并越来越多地扩展到富接触、双手和工具使用任务 [21, 20, 17]。然而，跨任务的RL扩展仍受到奖励工程和探索的瓶颈限制。越来越多的工作注入外部先验，如重定向的参考轨迹 [22, 24]或来自视觉-语言模型的粗略计划 [6]，以提高学习效率。我们遵循这一方向，使用人手运动——通过保持交互的重定向忠实迁移——作为先验，简化奖励设计并将探索偏向可靠的类人策略。

**基于模仿学习的灵巧操作。** 在可扩展数据收集系统 [49, 4, 42]和表达性策略类 [5, 1]的推动下，模仿学习（IL）通过直接从真实机器人演示中学习视觉运动策略，从而绕过仿真到现实差距，已成为真实世界机器人操作的中心范式。然而，IL依赖于准确的机器人动作数据，这对于高自由度灵巧手来说难以捕获。针对多指手出现了多种数据收集流程，包括使用动捕手套、VR头显或RGB相机捕获人手运动然后重定向到机器人手上的系统 [46, 42, 38, 34]，通过机械耦合人手和机器人手指实现便携式野外收集的可穿戴手部外骨骼 [9, 44, 41]，以及用基于物理的仿真增强人类演示的方法 [15]。我们的流程不需要收集机器人特定数据；相反，它通过运动重定向将原始人体运动转化为机器人轨迹，这使其接近于利用动捕和视频数据作为人体运动广泛来源的工作 [24, 18, 33, 50, 48]。

**从人类数据的运动重定向。** 将人体运动重定向到机器人上并在仿真中训练策略来跟踪参考，已成为人形机器人全身控制中日益常见的方案 [13, 12, 19, 45]。对于灵巧手，重定向主要通过逐帧运动学优化 [11, 34]或从人类视频中学习映射 [40, 37]来支持遥操作和演示生成。更新的流程通过功能性重定向到演示物体状态 [24]、物理信息重定向 [28]、学习人-机迁移 [29, 18]、仿真中轨迹引导的细化 [3]，或稀疏的以物体为中心的奖励和手部姿态来引导RL [22]，将物体上下文纳入考虑。然而，以手为中心的重定向仍可能产生物理上不合理的接触结构，而先前的物体感知方法要么针对数据集生成和模仿，要么强调仅仿真的跟踪，要么依赖稀疏的物体或手部线索而非密集的交互结构。我们将人形机器人 loco-manipulation 中的交互网格公式 [14, 45]适配到灵巧手-物操作中，并将保持交互的参考用作高效闭环仿真到现实RL的探索性重启分布。

### 3 方法：重定向引导的强化学习

**图2：方法概览。** 我们遵循真实-仿真-真实的流程，从3D人类数据中学习RL策略。(1) 给定包含手部和物体姿态的人类演示，我们(2)通过交互感知的运动重定向将其重定向到机器人，(3)在仿真中通过大规模RL训练策略来跟踪重定向后的轨迹，然后(4)将策略零样本迁移到真实世界。我们在RL训练期间动态增强参考轨迹，使策略能够泛化到不同的初始配置。

#### 3.1 问题定义

机器人策略学习与强化学习（RL）可以表述为一个有限时域马尔可夫决策过程（MDP），定义为 ⟨𝒮, 𝒜, P, ρ₀, r, T⟩，其中 𝒮 和 𝒜 是连续的状态和动作空间，P: 𝒮 × 𝒜 → Δ(𝒮) 是转移动力学，ρ₀ 是初始状态分布，r: 𝒮 × 𝒜 → [0,1] 是奖励函数，T 是时域。目标是找到最优策略 π*: 𝒮 → 𝒜，最大化期望累积奖励：

π* = arg max_π 𝔼_{τ∼π, s₀∼ρ₀} [∑_{t=0}^{T-1} γ^t r(s_t, a_t)], (1)

其中 τ = (s₀, a₀, s₁, a₁, …, s_{T-1}, a_{T-1}) 是从策略 π 采样的轨迹，γ ∈ [0,1) 是折扣因子。

操作任务由人类演示 τ̃ = (s̃₀, s̃₁, …, s̃_{T-1}) 指定，奖励鼓励机器人跟踪人类演示，例如 r(s_t, a_t) = exp(−dist(s_t, s̃_t))，其中 dist(·,·) 是某种距离度量。这里，s̃_t ∈ 𝒮̃ 是包含时间步 t 时物体和人手信息的演示状态。注意 𝒮 和 𝒮̃ 是两个不同的空间，因为机器人和人之间存在 embodiment 差距。例如，s_t ∈ 𝒮 包含机器人关节位置，而 s̃_t ∈ 𝒮̃ 可能只提供手部关键点。我们假设物体状态表示在两个空间中相同，因此合理的距离度量可以是两个物体姿态在 SE(3) 中的距离。

RL的一个挑战是探索。Kakade和Langford [16]引入了探索性重启分布的概念来引导探索过程，后来被DeepMimic [30]推广为参考状态初始化（RSI）。策略不是优化公式(1)中的目标，而是相对于探索性重启分布 μ 进行优化：

max_π 𝔼_{τ∼π, s₀∼μ} [∑_{t=0}^{T-1} γ^t r(s_t, a_t)]. (2)

**图3：交互网格。** 我们用演示中的物体和手部关键点构建源交互网格（上），用相同的物体关键点和与手部关键点对应的机器人关键点构建目标交互网格（下）。虚线连接两个网格中对应的关键点。

研究还表明，μ 需要接近最优策略 π* 的状态访问分布 d_{ρ₀}^{π*} [16]，这促使我们在本案例中将 μ 自然选择为支持人类演示中状态的分布。由于前面讨论的 embodiment 差距，我们使用运动重定向过程将演示状态 s̃_t 转换为机器人状态 s_t，并将重定向后的轨迹用作探索性重启分布。

本节其余部分组织如下。我们首先在第3.2节介绍交互感知的运动重定向过程，将人类演示转换为保持手-物交互语义的机器人轨迹。然后，我们在第3.3节介绍以重定向后的机器人轨迹作为参考运动的RL训练流程。我们方法的完整流程如图2所示。

#### 3.2 交互感知的运动重定向

运动重定向的目标是将人类演示转换为模仿人类运动的机器人轨迹。演示由每个时间步的MANO手部关键点 [35]和物体配置组成，其中物体配置由6D姿态指定（如果物体是铰接的，还包括额外的关节位置）。

我们将运动重定向问题表述为机器人配置 𝐪_{0:T-1} = {(𝐓_t^r, 𝐪_t^r)}_{t=0}^{T-1} 上的优化问题，其中 𝐓_t^r 是机器人手腕姿态，𝐪_t^r 是时间步 t 的机器人关节位置向量。

关键设计决策是选择一个度量来衡量机器人轨迹对人类演示的模仿程度。重要的是，我们需要同时考虑人-机 embodiment 差距和机器人手与物体之间的复杂交互，这是与先前不考虑物体进行纯运动学重定向的工作的关键区别。

受OmniRetarget [45]启发，我们定义了一个基于交互网格的重定向目标，以鼓励机器人运动保持操作物体的语义，例如机器人手与物体之间的空间和接触关系。

我们在人手和物体上定义语义关键点分别为 𝒫_t^h 和 𝒫_t^o。它们构成演示中源点集合 𝒫̃_t = 𝒫_t^o ∪ 𝒫_t^h。给定机器人配置 𝐪_t，我们定义一组机器人关键点 𝒫_t^r(𝐪_t)，它们在语义上对应人手关键点 𝒫_t^h。机器人关键点 𝒫_t^r(𝐪_t) 和原始物体关键点 𝒫_t^o 构成目标点集合 𝒫_t(𝐪_t) = 𝒫_t^o ∪ 𝒫_t^r(𝐪_t)。我们通过交互网格的形变来衡量保持交互的特性（见图3的说明）。优化问题表述为：

𝐪̄_{0:T-1} = arg min_{𝐪_{0:T-1}} ∑_{t=0}^{T-1} D(ℳ(𝒫̃_t), ℳ(𝒫_t(𝐪_t))) + λ ∑_{t=1}^{T-1} ‖𝐪_t − 𝐪_{t-1}‖₂² (3)

s.t. 𝐪_{0:T-1} ∈ 𝒬,

其中 λ 是权重因子，𝒬 是机器人配置的可行集，包括机器人的运动学约束和碰撞避免约束。

关键点 𝒫 之间的连接性由Delaunay四面体化 [39]决定，以形成具有顶点 𝒫 和边 ℰ 的交互网格 ℳ(𝒫)。我们最小化两个网格之间的形变能量，定义为网格拉普拉斯坐标的变化：

D(ℳ(𝒫̃_t), ℳ(𝒫_t(𝐪_t))) = ∑_i ‖L_i(𝒫̃_t) − L_i(𝒫_t(𝐪_t))‖₂, (4)

其中 L_i(𝒫) 是网格 ℳ(𝒫) = (𝒫, ℰ) 中第 i 个顶点的拉普拉斯坐标，定义为：

L_i(𝒫) = 𝐩_i − (1/|𝒩_i|) ∑_{j∈𝒩_i} 𝐩_j, (5)

其中 𝐩_i 是第 i 个顶点的坐标，𝒩_i = {j ∈ 𝒫 : (i,j) ∈ ℰ} 是第 i 个顶点的邻域。目标中的第二项（公式(3)）鼓励轨迹的时间平滑性。该程序使用序列二次规划（SQP）风格的求解器对每个时间步 t 顺序求解。实现细节见附录A。

#### 3.3 参考运动引导的策略学习

使用重定向后的机器人轨迹 𝐪̄_{0:T-1}（即公式3的解）作为参考运动，我们学习一个RL策略来跟踪它，使用可泛化的关键点跟踪奖励和参考状态初始化。我们用 ⋅̄ 表示来自重定向轨迹的"标称"量，以区别于RL中的实际状态。

**动作空间。** 策略 π_θ 在参考运动之上学习一个残差动作。控制目标计算为：

𝐪_t^{target} = 𝐪̄_t + 𝛂 ⊙ π_θ(𝐪̄_t, 𝐨_t),

其中 𝐪̄_t 是来自重定向轨迹的标称机器人配置，𝐨_t 是观测，𝛂 是控制每个自由度动作幅度的缩放向量，⊙ 表示逐元素乘积。该控制目标然后发送给低级PD控制器。

**观测空间。** 我们使用非对称actor-critic观测。Actor观测包含物体和机器人的配置、上一步动作 𝐚_{t-1}，以及一个相位变量 ϕ ∈ [0,1]，其中 ϕ = 0 表示运动开始，ϕ = 1 表示运动结束 [30]。物体配置包括物体姿态，包括位置 𝐩_t^o ∈ ℝ³ 和方向 𝐑_t^o ∈ ℝ⁶（用Rot6D [51]表示），以及铰接物体的关节位置 𝐪_t^o ∈ ℝ^{n_o}，其中 n_o 是物体关节数。这些值从动捕系统获取。机器人本体感知包含当前和前一时间步的所有关节位置 𝐪_{t-1:t}。我们使用在真实世界系统中可以相对可靠获取的观测，避免使用速度等噪声传感器测量值，以减少仿真到现实迁移差距。除上述观测外，critic还可以访问机器人的指尖位置和关节速度。

**奖励函数。** 我们的奖励函数设计为可泛化到不同任务和物体，且易于实现，不需要像 [24, 6]中那样的显式接触先验。相反，手-物交互的先验隐式编码在由保持交互的重定向过程生成的参考轨迹中。主要奖励是激励紧密物体跟踪的接近度奖励。

我们利用基于关键点的距离度量来衡量当前物体配置与目标物体配置之间的差异：

ε_{object} = dist_{KP}(𝒫_t^o, 𝒫̄_t^o) = (1/N_k) ∑_{i=1}^{N_k} ‖𝐩_{t,i}^o − 𝐩̄_{t,i}^o‖₂, (6)

其中 𝐩_{t,i}^o 和 𝐩̄_{t,i}^o 分别是物体上第 i 个关键点的当前位置和目标位置，𝒫̄_t^o = {𝐩̄_{t,i}^o}_i。与为刚体定义的平移和旋转误差相比，该距离度量通常适用于刚体和铰接物体。

奖励然后用指数核进行整形：

r_{object} = exp(−ε_{object}/σ),

其中 σ 控制奖励的锐度。我们还包括物体速度和手腕姿态跟踪奖励，以及对大动作幅度和动作速率的惩罚，以激励平滑运动。所有RL训练细节见附录B。

**图4：数据增强。** 𝐓^{ref} 和 𝐓⋆ 分别表示原始和增强后的重定向轨迹。𝐓⋆ 在时间步 t_{pickup}（物体被拿起时）和时间步 t_{use}（主体开始在目标位置使用工具时）之间向 𝐓^{ref} 插值。更多细节见附录B.3。

**参考运动引导的训练。** 如第3.1节所述，我们采用参考状态初始化（RSI）[30]，将重定向轨迹作为参考运动，用重启状态分布 μ 引导策略学习。我们从重定向轨迹中采样重启状态，并在episode开始时将机器人和物体初始化到相应状态，同时施加小扰动以提供对潜在高价值状态的更广泛覆盖。如果物体偏离参考轨迹太多，我们也会终止episode。使用严格的物体偏差阈值有助于防止策略过度偏离参考轨迹，因为残差RL策略可能无法从大偏差中恢复。

**数据增强。** 由于我们的流程从单次人类演示中学习，重定向轨迹仅覆盖任务的一个实例，这限制了学习策略的空间泛化能力。因此，我们进行数据增强以合成一组多样化的参考轨迹，用于训练更鲁棒和可泛化的RL策略。我们通过在演示配置周围扰动其位置和方向来随机化初始物体配置（位置 ±5 cm，方向 ±30度），这定义了扰动初始物体姿态与原始初始物体姿态之间的刚体变换 Δ𝐓₀ ∈ SE(3)。为了生成与此扰动起始一致的新参考轨迹，我们对重定向轨迹的每个状态施加时变刚体变换 Δ𝐓(t)，该变换通过在起始时的 Δ𝐓₀ 和目标时的单位变换之间插值获得。这将轨迹的起始部分向增强后的初始状态弯曲，同时在结束时平滑返回原始目标状态。图4展示了拿起并转动螺丝刀的增强轨迹示例。

与OmniRetarget [45]不同——后者重新运行重定向过程为增强后的物体轨迹生成新的机器人轨迹——我们直接在每个时间步对物体姿态和机器人手根部姿态施加相同的刚体变换，而无需重新求解重定向的优化问题。这使我们能够在RL训练时动态生成无限数量的增强轨迹，同时仍然保持原始重定向过程捕获的相对空间和接触关系。

**域随机化和课程学习。** 为了进一步增强学习策略的鲁棒性，我们在RL训练期间对物理仿真参数（如摩擦、电机增益、时间延迟等）应用域随机化，并添加观测噪声。此外，我们对物体和机器人施加随机推力，并对推力强度采用课程学习。我们还采用重力课程，将重力幅度从零逐渐增加到完整值，这对涉及拿起物体的任务很有用。

### 4 实验

我们设计实验来回答以下关键问题：

**(Q1)** 保持交互的重定向是否能提高重定向保真度？

**(Q2)** 在重定向过程中保持交互是否能改善下游RL性能？

**(Q3)** 用Regrind训练的策略能否迁移到真实世界动力学？

**(Q4)** 策略能否从不同的初始状态复制演示？

#### 4.1 实验设置

**机器人和任务。** 我们的方法在两个灵巧操作任务上评估：来自ARCTIC数据集 [8]的**剪刀**任务，以及来自我们自己数据收集设置的**螺丝刀**任务（演示收集细节见附录C），涵盖刚体和铰接物体。每个任务在两只拟人化机器人手上评估：16自由度LEAP手 [36]和20自由度WUJI手。机器人手安装在7自由度UR5e机械臂上。任务如图1所示。在剪刀任务中，机器人拿起剪刀并在期望方向操作；在螺丝刀任务中，机器人抓住螺丝刀并在保持直立的同时连续转动。由于尺寸原因，LEAP手无法在正常尺寸的工具上进行语义相似的抓取，因此我们对LEAP手使用3D打印的放大物体，对WUJI手使用真实物体。

为了隔离仿真到现实迁移中的动力学差距，我们在部署时将动捕系统的物体姿态直接馈送给策略，这最小化了感知误差并防止其作为混淆因素。

**评估指标。** 我们使用以下两个指标来评估策略性能：

- **物体跟踪误差（Err.）**：当前物体关键点位置与目标物体关键点位置之间的平均距离（公式6）。 - **成功率（SR）**：成功试验数与总试验数的比率。每个任务的详细成功标准见附录D。

**基线方法。** 我们将我们的方法与两种从人类演示中学习灵巧操作的代表性基线进行比较：

- **SPIDER** [28]：一种基于物理的重定向方法，生成动力学可行的机器人轨迹。重定向轨迹可以作为开环策略执行或用作下游RL的参考运动。 - **DexMachina** [24]：也训练RL策略来跟踪运动学重定向的机器人轨迹，但在重定向过程中不考虑机器人-物体交互语义。

此外，我们还与一个简单的基线进行比较，该基线使用微分逆运动学（使用Mink [47]）将人体运动重定向到机器人，然后使用与我们方法相同的设置训练RL策略，命名为 **Mink IK + RL**。

### 5 局限性

我们对基于重定向学习的灵巧操作持乐观态度，因为我们在具有挑战性的任务上展示了有前景的结果，并更好地理解了富接触操作中仿真到现实迁移的挑战。同时，仍存在若干局限性。首先，我们的方法在部署时依赖动捕来获取物体状态。将基于状态的RL策略蒸馏为基于视觉的策略是使系统更适用于野外场景的自然下一步。

其次，我们的流程仍需要仔细的系统辨识来实现仿真到现实迁移；一个有前景的方向是在测试时使用从与真实世界交互中推断的上下文来适应策略。

公式(3)中的运动学约束在每个时间步作为 𝐪_t 的硬约束执行。我们将可行集写为：

𝒬 = {𝐪_t : 𝐪_min ≤ 𝐪_t ≤ 𝐪_max, 𝐯_min Δt ≤ 𝐪_t − 𝐪_{t-1} ≤ 𝐯_max Δt, ϕ_j(𝐪_t) ≥ 0, ∀j}, (7)

其中 𝐪_min 和 𝐪_max 是关节限位，𝐯_min 和 𝐯_max 限制每帧配置变化，Δt 是演示时间步，ϕ_j(𝐪_t) 是第 j 个碰撞对的有符号距离。

**关节限位。** 我们要求 𝐪_min ≤ 𝐪_t ≤ 𝐪_max，限位取自机器人模型。对于浮动基座，四元数分量在重新归一化前约束为 [-1, 1]。

**速度界限。** 为鼓励平滑的重定向运动，我们将帧间变化限制为 𝐯_min Δt ≤ 𝐪_t − 𝐪_{t-1} ≤ 𝐯_max Δt，与OmniRetarget中使用的速度限制约束一致。

**非穿透。** 对于每个活动碰撞对 j，我们通过 ϕ_j(𝐪_t) ≥ 0 来执行非穿透。在我们的灵巧操作设置中，我们激活机器人-物体和机器人-环境（桌面/地面）碰撞对。不应产生约束的相邻几何体（如手掌-手指连杆）在plant设置时被过滤。

#### B.2 奖励函数

我们使用密集奖励训练，将仿真状态与来自重定向参考运动的时间索引目标进行比较。在每个控制步 t，标量奖励是整形项的加权和：

r_t = ∑_k w_k ϕ_k(𝐞_{k,t}), (8)

其中 w_k 是项权重，𝐞_{k,t} 是相应的跟踪或正则化误差，ϕ_k 将误差映射到 [0,1]（或二元惩罚）。大多数跟踪项使用标量误差 e 上的指数核：

ϕ_lin(e; σ) = exp(−e/σ). (9)

物体线/角速度匹配、动作幅度和动作速率项使用平方误差成本 c：

ϕ_sq(c; σ) = exp(−c/σ²). (10)

#### B.3 数据增强

参考状态初始化（RSI）在重置时采样随机演示相位。轨迹增强在时间步 t_{pickup} 和 t_{use} 之间对物体和手部目标应用每episode的扰动，并逐渐淡出。

设 (Δ𝐩, Δψ) 为采样的扰动变换，其中 Δ𝐩_{xy} ∈ [-5,5]² cm，Δ𝐩_z = 0，Δψ ∈ [-30°, 30°]。混合权重（扰动强度的线性插值）计算为：

w(t) = { 1, t < t_{pickup}; 1 − (t − t_{pickup})/(t_{use} − t_{pickup}), t_{pickup} ≤ t ≤ t_{use}; 0, t > t_{use} } (11)

参考姿态 (𝐩_t^{ref}, 𝐑_t^{ref}) 然后变换为增强轨迹：

𝐩⋆(t) = 𝐩_t^{ref} + w(t) Δ𝐩, (12)

𝐑⋆(t) = 𝐑_z(w(t) Δψ) 𝐑_t^{ref}. (13)

手腕和指尖位置使用关于未扰动物体根 𝐩_{obj,t}^{ref} 的相同刚体映射：

𝐩_{hand}⋆(t) = 𝐑_z(w(t) Δψ)(𝐩_{hand,t}^{ref} − 𝐩_{obj,t}^{ref}) + 𝐩_{obj,t}^{ref} + w(t) Δ𝐩; (14)

### 附录D 评估细节

#### D.1 任务成功标准

我们定义任务成功标准如下。

**剪刀。** 设 z_t 为物体根高度，q_t 为旋转关节角度。定义平均刀片方向 𝐝_t 为世界坐标系中两个刀片本体 +x 轴均值的单位向量（顶部刀片绕关节轴旋转 q_t）。

一个时间步是**直立的**如果：

z_t − z₀ > 0.05 · s m （离开桌面） (15)

𝐝_t · [0, -1, 0]ᵀ > 0.7 （正确朝向：本体x轴与世界-y对齐） (16)

其中 z₀ 是初始高度，s 是任务物体尺度（3D打印的LEAP手剪刀 s = 2，真实尺寸的WUJI剪刀 s = 1）。

如果某个连续的直立段同时包含至少20°的打开和闭合扫描，即该段内最大关节增加和减少各自 ≥ 20°，则判定为成功。

**螺丝刀。** 设 𝐲_t 为世界坐标系中螺丝刀本体 +y 轴。

当 −𝐲_t · [0, 0, 1]ᵀ > 0.9（本体y轴与世界-z轴对齐）时，该步为**直立的**。

在直立期间，我们从连续的方向中累积绕世界+z的旋转；当物体不直立时，累加器重置。

成功要求最终时间步直立且累积旋转幅度至少为一整圈（≥ 2π）。
