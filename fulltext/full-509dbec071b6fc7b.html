原标题：Introducing Claude Sonnet 4.6

中文摘要： Anthropic 正式发布 Claude Sonnet 4.6，作为迄今最强 Sonnet 模型，其在编码、计算机使用、长上下文推理、智能体规划等方面全面升级，支持 100 万 token 上下文窗口。性能媲美 Opus 4.6，成本更低，用户反馈优于前代 Sonnet 4.5，甚至在部分任务中胜过 Opus 4.5。安全评估表现优异，计算机使用能力显著提升，并在 OSWorld、Vending-Bench Arena 等基准测试中大幅领先。产品更新包括自适应思考、上下文压缩及多项工具 GA，

Claude Sonnet 4.6 是我们迄今最强大的 Sonnet 模型。该模型在编码、计算机使用、长上下文推理、智能体规划、知识工作与设计等能力上实现了全面升级。Sonnet 4.6 还在测试阶段提供了 100 万 token 的上下文窗口。

对于使用我们免费版与专业版计划的用户，claude.ai 和 Claude Cowork 中默认模型现已更新为 Claude Sonnet 4.6。定价 与 Sonnet 4.5 保持一致，起步价为每百万 token 3 美元 / 15 美元。

Sonnet 4.6 显著提升了编码能力，为更多用户带来更优体验。其在一致性、指令遵循等方面均有改进，早期试用开发者普遍更偏好 Sonnet 4.6，甚至大幅优于其前代版本；部分用户还表示，它优于我们 2025 年 11 月发布的旗舰模型 Claude Opus 4.5。

此前需调用 Opus 级模型才能实现的性能——包括在真实世界、具有经济价值的办公任务中——如今 Sonnet 4.6 即可胜任。与此前 Sonnet 模型相比，其计算机使用能力也有显著提升。

与每一代新 Claude 模型一样，我们对 Sonnet 4.6 开展了全面的安全评估，结果显示其安全性与近期其他 Claude 模型相当，甚至更优。安全研究人员总结称：“该模型整体展现出温暖、诚实、亲社会，有时还带幽默感的个性，具备极强的安全行为，未发现任何重大对齐风险。”

计算机使用

几乎每个组织都拥有难以自动化的软件系统：那些早于现代 API 接口而构建的专用工具。此前若要让 AI 使用此类软件，用户需定制开发连接器；而一个能像人类一样操作计算机的模型，彻底改变了这一局面。

2024 年 10 月，我们首次推出通用型计算机使用模型。当时我们指出其“仍属实验阶段——操作繁琐且易出错”，但预期将快速进步。OSWorld（AI 计算机使用标准基准）清晰展示了我们模型的飞速进步：该基准测试涵盖数百项在模拟计算机（运行 Chrome、LibreOffice、VS Code 等真实软件）上执行的任务；模型无需特殊 API 或定制连接器，仅通过点击（虚拟）鼠标与键盘与系统交互。

十六个月内，Sonnet 系列模型在 OSWorld 上持续进步。实际应用也印证了这一趋势：早期 Sonnet 4.6 用户已能完成人类水平的任务，如操作复杂电子表格、填写多步骤网页表单，并跨多个浏览器标签页协同处理。

尽管模型在计算机使用方面仍逊于顶尖人类用户，但进步速度令人瞩目——这意味着计算机使用已更广泛适用于各类工作场景，且更强大模型已触手可及。


Sonnet 4.5 之前模型得分基于原始 OSWorld；Sonnet 4.5 起采用 OSWorld-Verified。OSWorld-Verified（2025 年 7 月发布）是对原基准的就地升级，改进了任务质量、评估评分与基础设施。

与此同时，计算机使用亦伴随风险：恶意行为者可通过网页隐藏指令发起“提示注入攻击”（prompt injection）。我们持续提升模型对提示注入的抗性——安全评估显示，Sonnet 4.6 相较前代 Sonnet 4.5 有显著进步，性能与 Opus 4.6 相当。更多缓解提示注入及其他安全风险的方法，请参阅我们的 API 文档。

评估 Claude Sonnet 4.6

除计算机使用外，Claude Sonnet 4.6 在各类基准测试中全面进步，其智能水平已逼近 Opus，而成本更具实用性。完整能力与安全行为分析请见系统卡；下表为与近期模型的对比摘要。

在 Claude Code 中，早期测试显示用户有约 70% 的时间更偏好 Sonnet 4.6 而非 Sonnet 4.5。用户反馈其在修改代码前更善于理解上下文，更倾向于复用共享逻辑而非重复编写，使长时间使用体验更顺畅。

用户甚至有 59% 的时间更偏好 Sonnet 4.6 而非我们 2025 年 11 月发布的前沿模型 Opus 4.5。他们认为 Sonnet 4.6 更少出现过度设计与“偷懒”行为，指令遵循能力显著提升；误报成功、幻觉现象减少，多步骤任务执行更连贯一致。

Sonnet 4.6 的 100 万 token 上下文窗口足以容纳整个代码库、冗长合同或数十篇研究论文。更重要的是，它能在此上下文中有效推理，大幅提升长期规划能力。在 Vending-Bench Arena（测试模型能否长期运营模拟企业并竞争盈利）中表现尤为突出：Sonnet 4.6 采用新策略——前 10 个月大力投资产能，随后在最后阶段转向盈利，精准的时机选择助其大幅领先对手。


Sonnet 4.6 通过前期投资产能、后期转向盈利，在 Vending-Bench Arena 中超越 Sonnet 4.5。

早期客户亦报告多方面提升，前端代码与财务分析尤为突出。客户独立反馈称，Sonnet 4.6 的视觉输出更显精致——布局、动画与设计感明显优于前代模型，且达到生产级质量所需的迭代轮次更少。

Claude Sonnet 4.6 在 OfficeQA（评估模型阅读企业文档（图表、PDF、表格）、提取事实并推理）中达到 Opus 4.6 水平，大幅提升了文档理解任务能力。

Claude Sonnet 4.6 的性能/成本比极为出色——Claude 模型近期演进之快难以言表。它在编排测试中表现更优，可处理最复杂的智能体任务，且在提高“努力设置”时持续进步。

Claude Sonnet 4.6 在各维度上均显著优于 Sonnet 4.5，尤其在长期任务与难题求解方面。

Sonnet 4.6 初次发布即在复杂代码修复中表现出色，尤其适用于需跨大型代码库搜索的场景。对规模化运行智能体编码的团队，其修复成功率高、一致性强，符合开发者需求。

Claude Sonnet 4.6 在漏洞检测方面显著缩小与 Opus 的差距，使我们能并行运行更多审查器，覆盖更广漏洞类型，且不增加成本。

首次，Sonnet 以更小、更经济的形态提供前沿推理能力——对重度 Opus 用户而言，它已成为可行替代方案。

Claude Sonnet 4.6 显著提升了我们核心产品背后的答案检索能力——在金融行业基准测试中，答案匹配率较 Sonnet 4.5 大幅跃升，对客户依赖的关键工作流召回率更高。

Box 对 Sonnet 4.6 在真实企业文档上的深度推理与复杂智能体任务进行了评估，其在重型推理问答中较 Sonnet 4.5 提升 15 个百分点。

Sonnet 4.6 在我们的保险基准测试中达到 94%，为计算机使用测试中表现最佳模型。此类精度对投保受理、初损通知等关键流程至关重要。

Sonnet 4.6 在复杂应用构建与 bug 修复中达到前沿水平，正成为执行深度代码库工作的首选，此前此类任务需依赖更昂贵模型。

Sonnet 4.6 生成了 Rakuten AI 测试中最佳的 iOS 代码：规范符合度更高、架构更优，并主动采用我们未要求的现代工具，一次即令人惊喜。

Sonnet 4.6 在处理复杂任务推理方面实现重大飞跃。它在分支与多步骤任务（如合同路由、条件模板选择、CRM 协调）中尤为突出——这正是客户对模型判断力与可靠性要求最高的场景。

Sonnet 4.6 在复杂计算机使用任务中准确度令人印象深刻，是我们测试中明显优于其他模型的成果。

Sonnet 4.6 构建前端页面与数据报告时具备完美设计品味，所需人工干预远少于以往测试过的任何模型。

Sonnet 4.6 对指令响应极为精准——按需提供精确数据与结构化对比，同时生成真正实用的庭审策略与证据准备建议。

产品更新

在 Claude 开发者平台，Sonnet 4.6 支持自适应思考与扩展思考，以及处于测试阶段的上下文压缩，可在对话接近上限时自动摘要旧上下文，提升有效上下文长度。

在 API 中，Claude 的网页搜索与获取工具现可自动编写并执行代码，筛选与处理搜索结果，仅保留相关上下文内容——提升响应质量与 token 效率。此外，代码执行、记忆、程序化工具调用、工具搜索与工具使用示例现已全面上线。

Sonnet 4.6 在任意“思考强度”下均表现强劲，即使关闭扩展思考亦然。迁移自 Sonnet 4.5 时，我们建议用户探索不同设置，根据构建需求找到速度与可靠性能的最佳平衡点。

我们发现，Opus 4.6 仍是深度推理任务（如代码库重构、多智能体工作流协调、对结果“必须精准”的场景）的最佳选择。

对 Claude in Excel 用户，插件现支持 MCP 连接器，使 Claude 可与日常工具（如 S&P Global、LSEG、Daloopa、PitchBook、Moody’s、FactSet）协同工作。您可在 Excel 内直接请求外部上下文，无需切换应用。若已在 claude.ai 中配置 MCP 连接器，这些连接将自动同步至 Excel。该功能适用于 Pro、Max、Team 与 Enterprise 计划。

如何使用 Claude Sonnet 4.6

Claude Sonnet 4.6 现已上线所有Claude 计划、Claude Cowork、Claude Code、API 及主流云平台。我们亦将免费层默认升级为 Sonnet 4.6——现包含文件创建、连接器、技能与压缩功能。

开发者可快速上手，通过 Claude API 使用 claude-sonnet-4-6。
