摘要

持续强化学习（CRL）智能体在适应新情境的同时保留既有知识方面存在困难，由此产生稳定性–可塑性权衡问题。解决该问题的一种途径是采用互补学习系统：一个系统负责缓慢的长期学习，另一个负责快速的瞬态适应。Anand 与 Precup (2023) 利用永久性与瞬态性价值函数将这一思想具体化，但两个系统使用了相同的特征。直观上，长期学习应更依赖参数化表示以实现广泛泛化，而瞬态学习则最适合采用非参数化表示以实现针对具体情境的适应。本文从理论和实证两个层面探索了这一想法。通过引入一种新颖的非参数近似方法来估计复杂任务中的瞬态价值函数，我们证明该方法可实现在线学习，并在基于图像的任务和 Craftax-Classic 上优于有竞争力的基线方法，凸显了我们系统级分解的有效性。

1 引言

持续强化学习（CRL）是通用智能的关键组成部分 [55, 54]。CRL 中的一个重要挑战在于保留已获取的知识与适应新信息之间的张力——即所谓稳定性–可塑性权衡 [13]。相比之下，人类和其他生物智能体终其一生都能适应环境变化。Kumaran 等人 [32] 提出，这种天然能力源于两个互补学习系统（CLS）的存在：一个快速适应，另一个则缓慢地在经验之间巩固信息。

Anand 与 Precup [6] 在强化学习（RL）智能体的语境下实现了这一架构，将价值函数分解为两部分：永久组件为智能体可能面临的任何情境提供稳定的基线估计，瞬态组件则根据当前情境调整这些估计。两个组件均采用时序差分（TD）式的修正进行更新，协同工作。然而，在他们的工作中，两个价值函数共享同一组特征。直观上，为这两个近似器使用各自独立的特征空间更符合“保持互补”的理念：一个系统应弥补另一个系统的弱点，从而使框架对 CRL 更有效，也更符合生物学合理性。永久特征应编码环境中平稳或缓慢变化的成分，例如城市地图；而瞬态特征可捕捉情境特定的方面，例如某条道路在某天被封闭。因此，永久表示应有助于在不同情境间泛化，而瞬态表示则应直观地促进快速适应所需的局部调整。这些瞬态更新还须支持临时性适应，即根据情境修正永久行为，并在情境改变时无缝回归该行为（例如，常走的办公路线临时封闭后又重新开通）。这一直觉表明，永久函数近似器应为参数化的，而瞬态近似器则可能需要对其形成补充。

本文从理论和实证两方面发展并验证了这一直觉。我们工作的一个重要目标是将此类 CRL 智能体扩展到大型环境。为此，我们引入了一种新颖的非参数近似器，它直接作用于原始观测，能够实现快速、精确的修正，支持在线学习与受控泛化。

我们的主要贡献如下：

  • 我们扩展了永久–瞬态价值函数框架，允许两个近似器使用各自独立的特征表示，并在线性函数近似下利用双时间尺度收敛技术给出了收敛性保证；
  • 我们提出了一种新颖的非参数方法来估计瞬态价值函数，可用于补充基于神经网络的永久特征，其功能类似于齿状回，能够快速编码特定信息而不发生灾难性干扰 [8, 52]；
  • 我们在小型示例、基于图像的任务以及 18M 与 250M 步的 Craftax 任务 [41] 上评估了该方法，结果表明其优于其他基线（包括在参数层面处理稳定性–可塑性的方法）。

2 背景

持续 RL。 CRL 智能体必须展现无尽的适应能力（亦称可塑性 [3]），而非收敛到固定解 [2, 56]。当环境的某些方面（如奖励或转移动态）随时间变化 [27, 46]，或智能体的资源相对于环境复杂性受限而被迫不断更新其知识时 [31, 24, 34]，就需要 CRL。在这类场景中，智能体必须权衡：保留过去的有用信息以便在相似情境重现时更快适应——稳定性；同时分配资源以从新经验中学习——可塑性。

机制层面方法。 由于神经网络已成为近似价值函数和策略的主流方法 [43]，大多数 CRL 研究聚焦于理解神经网络中的稳定性–可塑性权衡 [37, 44, 1, 39, 38]，并开发新的正则化技术 [35, 33, 15] 与优化器 [28, 7, 18, 25, 19, 51, 16, 23] 来改善它。关于该主题的详细综述见 [29]。

系统层面方法。 延续早期在基于模型的 RL 中分解价值函数的思想 [53]，Anand 与 Precup [6] 提出将价值函数与动作价值函数均分解为两个组件，以权衡稳定性与可塑性：永久组件 V^(P) 与 Q^(P) 从智能体的全部经验中学习一般性估计（类似于迁移学习中的 [4]）；瞬态组件 V^(T) 与 Q^(T) 通过计算残差将这些估计调整到当前情境。总体价值函数 V^(PT) 与 Q^(PT) 表示为两个组件之和：

V^(PT)(s) = V^(T)_w(s) + V^(P)_θ(s)，(1)

Q^(PT)(s,a) = Q^(T)_w(s,a) + Q^(P)_θ(s,a)，(2)

其中 θ 与 w 分别为永久和瞬态函数近似器的参数。

永久价值函数更新较慢，或每 k 个时间步更新一次，或在任务边界处（若可用）利用该阶段的经验样本更新：

θ_{k+1} ← θ_k + ᾱ_k (V^(PT)(S_k) − V^(P)_θ(S_k)) ∇_θ V^(P)_θ(S_k)，(3)

θ_{k+1} ← θ_k + ᾱ_k (Q^(PT)(S_k,A_k) − Q^(P)_θ(S_k,A_k)) ∇_θ Q^(P)_θ(S_k,A_k)，(4)

其中 ᾱ 为永久更新的学习率。

相反，瞬态价值函数快速更新，以捕捉尚未反映在永久估计中的价值成分：

w_{t+1} ← w_t + α_t δ^V_t ∇_w V^(T)_w(S_t)，(5)

w_{t+1} ← w_t + α_t δ^Q_t ∇_w Q^(T)_w(S_t,A_t)，(6)

其中 α 为瞬态更新的学习率，δ^V_t = R_{t+1} + γV^(PT)(S_{t+1}) − V^(PT)(S_t) 与 δ^Q_t = R_{t+1} + γ max_{a'} Q^(PT)(S_{t+1},a') − Q^(PT)(S_t,A_t) 为 TD 误差。为保持可塑性，瞬态参数在每次永久更新后衰减或重置。

沿着类似思路，神经情景控制（NEC）方法将整体学习分解为：通过神经网络进行缓慢的表示学习，以及通过可微字典进行快速的价值学习 [47, 22]。然而，包括其他快慢方法 [11] 在内，它们在持续 RL 中的适用性受限于调参复杂性与不断变化的表示。

3 永久与瞬态表示

既然永久与瞬态价值函数应当互补，合理假设它们使用具有不同要求的不同表示。在 CLS 理论 [32] 中，瞬态表示的对应物被认为是海马体，它存储具体的、独立的情节或近期经验的潜在嵌入快照。这些内容随后在睡眠中被重放，从而实现巩固并缓慢学习永久表示——后者被认为主要位于前额叶皮层。该表示对新情境具有良好的泛化能力，并支持长期规划。

在本文余下部分，我们考虑将这一直觉落实于 CRL 的架构选择。具体而言，永久表示应具备足够的表达能力，以学习智能体可能遇到的任何情境的基线预测。学习这些表示可以缓慢，但所获信息应能长期持久并发挥作用（即高稳定性）。因此，永久表示应支持预测在相似情境间的广泛泛化。许多神经网络架构，如前馈、卷积或循环网络，都满足这些要求，是永久价值函数的良好候选。

瞬态表示应支持快速在线学习（即高可塑性），以便迅速适应新情境。在某些情况下，例如 F1 赛道的高速弯道，它们应能支持学习精确的估计，同时在当前经验周围保持最小或经过审慎控制的泛化。此外，瞬态表示应支持快速、准确的信息检索。正如 CLS 理论所述，存储在瞬态表示中的知识应支持永久表示的长期学习。

一维链任务。 智能体从 S_0 出发，每个时间步确定性地转移到下一个相邻状态（S_i → S_{i+1}），直至终止。奖励的构造使得任务 τ 中状态的真实价值 V_τ(s) 恰好等于 φ_1(s) + w_τ φ_2(s)，其中 φ_1(s) 与 φ_2(s) 分别为状态 s 的一阶与三阶傅里叶特征 [30]。变量 w_τ 是引发任务间非平稳性的自回归权重，按 w_{τ_{k+1}} = 0.25·w_{τ_k} + X 更新，其中 X ~ N(0, 2.0)。我们总共运行 750 个回合，每 75 个回合采样一个新任务。设 γ = 0.9，状态数为 20，报告在线任务与其他任务上的均方根价值误差（RMSVE），在 30 个种子上计算，使用 z* = 1.645 的 90% 置信区间。

5 理论结果

本节证明：在使用线性函数近似且满足标准假设的情况下，永久估计与瞬态估计均收敛到唯一不动点。这些结果显著强于此前已有的表格型结果 [6]，并且重要的是，在两个函数近似器使用不同特征空间时提供了理论保证。也就是说，它们证明了使用两组不同特征来估计永久与瞬态组件不会导致发散——而这在许多线性 RL 场景中是常见问题。

我们利用 Borkar 提出的双时间尺度证明技巧（见附录 A.1）[10]，并结合 Bertsekas 与 Tsitsiklis [9] 以及 Tsitsiklis 与 Van Roy [59] 提出的条件进行证明。我们考虑在每个时间步更新永久价值函数。

假设 5.2。 永久与瞬态特征矩阵 Φ ∈ R^{|S|×d} 与 Z ∈ R^{|S|×l} 均为满列秩，即列向量线性无关。且其范数有界：‖Φ‖ ≤ M₁，‖Z‖ ≤ M₂，其中 M₁、M₂ 为常数。

假设 5.3。 共有 N 个任务，任务 τ 依据 p_τ 独立同分布采样。每个任务为一个 MDP：M_τ = (S, A, R_τ, P_τ, γ)。令 E_τ 表示关于任务分布的期望。每个任务的奖励 R_τ 有界。任务边界可观测。

假设 5.4。 每个任务 τ 在固定评估策略 π 下诱导不可约、非周期的马尔可夫链，且该链快速混合：|P_{π,τ}(S_t = s | S_0) − d_π(s)| ≤ Cσ^t，∀S_0 ∈ S，σ ＜ 1，其中 C 为常数。

定理 5.5（主要结果）。 在假设 5.1–5.4 下，永久与瞬态更新所计算的期望更新序列收敛到唯一不动点：

θ* = E_τ[Φᵀ D_τ Π_{Z,τ} Φ]⁻¹ E_τ[Φᵀ D_τ Z w^(TD)_{Z,τ}]，

wτ = w^(TD){Z,τ} − (Zᵀ D_τ (I − γP_{π,τ}) Z)⁻¹ Zᵀ D_τ (I − γP_{π,τ}) Φθ，

其中

Π_{Z,τ} = Z (Zᵀ D_τ (I − γP_{π,τ}) Z)⁻¹ Zᵀ D_τ (I − γP_{π,τ})，

w^(TD){Z,τ} = Z (Zᵀ D_τ (I − γP{π,τ}) Z)⁻¹ Zᵀ D_τ R_{π,τ}。

证明。 我们在此概述证明，完整细节见附录（A.1 节）。由于永久与瞬态更新之间学习率的差异，在更新瞬态值时，永久估计近似静止；而在更新永久估计时，瞬态值近似已收敛。因此，我们首先将永久值视为固定，通过验证定理 A.2 [59] 所列条件（见附录引理 A.3）建立瞬态更新的收敛性。随后，将瞬态参数的不动点代入永久更新，证明其同样满足所需条件，从而由定理 A.1 [10] 得到收敛性（见附录引理 A.4）。∎

推论 5.6。 若 Z = Φ，则

θ* = E_τ[Φᵀ D_τ Φ]⁻¹ E_τ[Φᵀ D_τ Φ w^(TD)_{Φ,τ}]，

wτ = w^(TD){Φ,τ} − θ。

此外，在单任务设定下，θ = w^(TD)_{Φ,τ} 且 w_τ = 0。

证明。 证明见附录 A.5。∎

上述推论表明：在单任务设定下，若永久与瞬态价值函数使用相同的特征表示，则仅永久价值函数便足以刻画预测，而瞬态组件收敛为零。

6 非参数瞬态近似

本节介绍一种满足瞬态表示要求（见第 3 节）的新型非参数架构。该架构的灵感来自瓦片编码 [57]、CMAC [42]，以及 1990 年代至 2000 年代初被用作独立函数近似器的相关稀疏分布式记忆架构 [26, 50, 49]。这些早期近似器受制于维度灾难，而我们通过哈希并将其与深度神经网络相配合来绕过这一限制，而非将其作为独立近似器使用。

我们假设每个观测由若干通道组成，每个通道指示智能体视野中特定位置是否存在特定类型的物品。许多常用的 RL 环境（如 Minigrid [14]、Craftax [41] 与 MinAtar [61]）均采用这种结构。该假设使我们能够利用 MinHash [12] 生成观测的哈希签名。

图 4： (a) 瞬态近似器的端到端概览。观测经四步映射为价值函数：(1) 标记化；(2) 哈希；(3) 分箱；(4) 价值估计。(b) 瞬态表。在每个表内，查询观测的价值以权重 ρ 加权，其余权重（1−ρ）分配给其邻居以形成估计。

整体流程如图 4 所示。它将观测转换为稀疏的哈希表示，支持具有受控泛化的非参数价值估计。该流程包含四个主要阶段：

1. 标记化。 每个观测被转换为一组离散标记，每个标记编码智能体视野中特定 位置上存在的对象类型。这将原始网格状观测转换为符号集合表示。在基于图像的任务中，灰度观测（由 RGB 对应图像导出）可量化为 N 个灰度级并视为符号观测。尽管图像标记化仍处于大量研究之中，任何新方法都可以整合进我们的框架。

2. 哈希。 标记化集合通过若干独立的 MinHash 函数映射为紧凑的哈希签名及辅助标签。之所以使用 MinHash，是因为它保持 Jaccard 相似度：两个集合产生相同 MinHash 值的概率恰好等于它们的 Jaccard 分数²。

² 两个集合 A 与 B 之间的 Jaccard 分数为 J(A,B) = |A∩B| / |A∪B|，广泛用于检索 [12]、生物信息学 [45] 与聚类 [58]。

因此，共享许多元素的观测会产生相似的签名（即在许多比特上重叠），这构成了局部泛化的基础，并可避免不良的哈希冲突。

3. 分箱。 签名被划分为多个子序列，每个子序列索引到瞬态表中的一个箱。概念上，每个表对应瓦片编码中的一个 tiling [57]。每个箱内有 S 个槽位。当新观测映射到某箱时，若有空槽则占据之；否则淘汰最近最少使用（LRU）的槽位。槽位的初始值设为该箱中已存值的平均值，使新条目继承一定的局部上下文。前一阶段计算的辅助标签也存入槽位，使其对该观测唯一（见算法 3）。

4. 价值估计。 为诱导类似 CMAC [42] 的泛化，查询观测的价值并非仅取自单个槽位，而是焦点槽位与匹配箱内其他已占用槽位的凸组合（见图 4(b)）：

Q^(T){t+1}(x,a;k) = ρ Q^(T){t+1}(x,a;k) + ((1−ρ)/(S−1)) ∑{j≠i} Q^(T){t+1}(o_j,a;k)，

其中 ρ 控制焦点槽位与其邻居的相对权重，x 为查询观测，o_j 为匹配箱中槽位 j 存储的观测，S 为每箱总槽位数，Q^(T)_{t+1}(x,a;k) 为第 k 个表对 二元组估计的瞬态价值。这在相似观测之间促成平滑插值，同时保留各槽位的独立身份。最终瞬态价值由所有瞬态表的估计求和得到。更多细节见附录中的图 4 与算法 3。

由于多个表及其对应箱共同贡献于瞬态价值函数的总体估计，TD 误差按各自贡献比例分配（见附录算法 5）。具体而言，TD 误差首先在全部 T 个表之间均分，再在每个表内部分配给匹配箱中的各槽位。焦点槽位获得权重 ρ，其余槽位共享权重 (1−ρ)/(S−1)。更新方式与瓦片编码类似：

Q^(T){t+1}(O_t,A_t;k,i) ← Q^(T)_t(O_t,A_t;k,i) + (α/T) η{k,i} δ_t，

其中 α 为瞬态更新的学习率，T 为表总数，δ_t 为时刻 t 的 TD 误差。权重因子 η_{k,i} 反映表 k 中槽位 i 的贡献：若槽位 i 在匹配箱中存储查询观测，则 η_{k,i} = ρ；若槽位 i 为同箱邻居，则 η_{k,i} = (1−ρ)/(S−1)；否则为 0。

尽管瞬态表大小固定，且箱内较旧的观测采用 LRU 策略淘汰，但如果时间上相邻的状态彼此相似并持续映射到同一箱，很久以前的观测仍可被保留；而更晚遇到的观测与先前状态不同，被哈希到不同箱中，从而使旧观测不受影响。

7 大规模实验

我们在 CIFAR 图像任务（可塑性文献中常用任务的 MDP 变体，如 Lyle 等 [39]）以及 Craftax-Classic 上进行实验，以展示我们这种在系统层面权衡稳定性与可塑性的方法的有效性。我们的实现基于 PQN 库，代码公开于 https://github.com/NishanthVAnand/pt_representations_crl 。

图像任务。 该任务是一个由五个状态和五个动作组成的基于图像的 MDP。每个状态的观测从 CIFAR-10 数据集的特定类别中采样。我们评估了该任务的三个“完整 CRL”变体（任务边界对智能体隐藏），分别将每类子采样数据量限制为 250、500 和 1000 张图像。任务中转移是随机的：选择奖励性动作（+1）时以 0.8 的概率进入下一状态（否则以 0.2 概率停留在当前状态），次优动作则带来小幅负惩罚并以 0.8 的概率停留在当前状态。奖励受高斯噪声扰动（μ=0，σ=0.01）。为引入非平稳性，最优动作（从三个动作一组中）在 600k 时间步内每 100k 步切换一次。我们取 γ=0.9。报告 600 个时间步上的平均奖励（30 个种子上的 90% 置信区间）。超参数细节见附录 A.4.1。

基线： 我们将本方法与以下基线比较：PQN，Craftax 上最先进的基于价值的算法 [21]；PT 的三个变体：PT-IHT（使用索引哈希表（IHT）而非基于槽位的表，即基于 MinHash-IHT 的瓦片编码）、T-Only（仅依赖非参数瞬态近似器（第 6 节））、PT-NN [6]（完全基于神经网络、端到端训练的基线）；EWC（以弹性权重巩固增强 PQN 以保持稳定性 [28]）；CB（将 PQN 与持续反向传播结合以保持可塑性 [16]）；以及神经情景控制（NEC），其具有参数化/非参数化的划分 [47]。

我们还使用另一个含 250 张图像的变体来测试适应速度。在该实验中，我们在单个任务上训练各智能体 250k 时间步，然后在接下来的 50k 时间步中评估其对新任务的适应速度。进行该实验是为了与那些利用任务边界信息的流行方法比较，而我们的方法中任务边界保持隐藏。具体比较对象包括：CompoNet（利用注意力将已学策略与最新策略组合 [40]）、Reset(Final)（任务切换时重置最后一层 [44]）、Reset(Full)（完全重新初始化网络以获得完全可塑性）。

为了在图像输入上使用 MinHash 哈希，我们先将 RGB 图像转为灰度，再量化为 64 个灰度级，将处理后的图像视为像素级符号集合。

图 5：图像任务结果。 (a) 图像任务 250。(b) 图像任务 1000。(c) 图像任务适应。无论任务边界是否可用或隐藏，我们的算法在任务切换时都能快速适应，而其他方法则较慢。

结果： 结果见图 5 与图 9。我们的方法表现优于基线。采用具有受控泛化的非参数近似保证了精确的瞬态更新和对任务切换的快速适应——这是相对基于神经网络的基线的关键优势。相比之下，PT-NN 与 T-only 分别因更新不稳定和容量不足而未能学到有意义的策略。PQN 通过批量更新获得稳定性，但初始学习缓慢，任务切换后恢复也慢。用 EWC 或 CB 增强它并未改变其表现，说明机制层面的干预并不必然带来快速适应。类似地，PT-IHT 受观测空间规模所限，哈希冲突增多导致有害的过度泛化和价值估计退化，凸显了我们基于槽位设计的重要性。由于 NEC 的估计依赖神经网络学到的特征，它对训练敏感，整体表现较差。

在适应实验中，我们的方法比那些利用任务边界信息（以及更多参数）的方法适应更快，展示了采用互补表示的系统级分解的优势。

Craftax-Classic。 该环境是开放式的，包含 22 项难度各异的成就。在每一步 t，智能体接收一个 7×9 的网格观测，包含其视野内的对象类型（图 2(d)），以及其物品栏（如木材、石头或制作的工具）和内在变量（如生命、饥饿或口渴）。智能体可执行 17 个可用动作之一。在每个回合内，首次完成某项成就（如采集煤炭或制作铁镐）时获得奖励。较简单的成就奖励较小，更高级的成就奖励更大。当回合长度达到 1000 步、智能体完成全部 22 项成就、被僵尸或骷髅杀死，或其内在变量耗尽时，回合结束。更多细节见 [41]。我们进行了两项实验：双流任务，以及使用 1024 个并行环境的 250M 步基准测试，以展示本方法在复杂任务上的竞争力。完整的超参数与架构细节见附录（A.4.2）。

结果： 双流实验使用 3 个种子，250M 基准测试使用 10 个种子。主要结果在此给出，参数消融与逐成就结果见附录图 11。如图 6(a)、图 6(b) 与图 13 所示，我们的方法在双流设定中成功学习，并在大规模 250M 基准测试中优于所有基线。它在不到 50M 步内回报超过 10（比 PQN(32) 快一倍），并在 150M 步内达到 15 的回报（PQN(32) 需要超过 200M 步）。这一成功源于瞬态表在显式控制状态间泛化的同时计算精确、局部更新的能力，这反过来加速了永久组件估计基线预测并广泛泛化的能力。相比之下，缺乏这种槽位设计或系统级分解的基线表现挣扎：PT-IHT 因不利的冲突随时间退化，T-only 则天然缺乏长期容量。PT-NN 与 PQN 等纯神经网络方法在没有大批量或环境并行化的情况下无法学习 [43, 20]，而它们依赖小批量来稳定更新，有引入首要偏差的风险 [44, 18]。EWC 与 CB 基线之间表现无差异，表明机制层面方法虽能维持神经网络的稳定性与可塑性，却无法实现 CRL 所需的快速适应。

图 6：Craftax-Classic 结果。 (a) 2 并行环境。(b) 1024 并行环境。在双并行和 1024 并行环境中，我们的算法（包括消融变体）均优于其他持续学习算法。

8 讨论与结论

本工作扩展并增强了 PT 框架：为永久组件引入缓慢演化或静态的特征（手工设计（如傅里叶基）或由神经网络学习），为瞬态组件引入奖励预测性、快速演化或非参数化的特征，以提升 CRL 性能。我们实现规模化的核心是一种新颖的基于 MinHash 的非参数近似器，它能像表格 RL 一样快速在线学习，像 CMAC 与瓦片编码一样进行局部泛化（但通过超参数 ρ 加以控制），并高效存储与检索观测和价值，同时其规模相对于环境复杂性而言保持适中。

我们在线性情形下的理论结果是对既有表格型结果的显著改进。这些结果表明，使用两组不同特征不会导致发散——而这在许多线性 RL 场景中是常见问题。我们期望这些证明能在未来更强理论结果的发展中发挥基础性作用，例如更快的适应速度、永久更新期间更少的干扰，或 CRL 的稳定性–可塑性分析。

新的非参数近似器引入了若干超参数。表大小、表数量与哈希数量决定近似器的容量；一般而言，越多越好，类似于神经网络中的层数与隐藏单元数。其余超参数既可以按坐标方式调优（Craftax；一种可扩展、实用的做法），也可以在所有组合上搜索（图像任务）。未来，我们期望元学习能实现参数调优的自动化 [60]，或出现更新、更简单的瞬态近似架构。我们也期望该非参数近似器能扩展到其他场景，如联想记忆与检索。

虽然标记化对符号观测是自然的，但在图像任务中我们对由 RGB 图像导出的灰度图进行了量化。为进一步改进，可借鉴基础模型研究中的先进标记化策略 [17, 48, 36]。将本方法扩展至策略梯度算法、开发选择性巩固机制（决定何时以及将什么转移到永久组件）、将机制层面方法与我们的方法结合以改进永久组件，以及在流式 RL 中应用我们的框架，是直接的后续工作。

归根结底，RL 智能体持续从新经验中学习的能力，对于推进我们对智能的科学理解至关重要。我们的框架通过证明“维护相互独立的表示对于平衡稳定性与可塑性、实现快速适应至关重要”而朝此目标迈进一步。通过将架构植根于 CLS 理论，我们有助于弥合生物学习范式与人工学习范式之间的鸿沟，再次展示了神经科学与 RL 之间富有成效的思想交流。

A.1 理论结果

本节研究当永久与瞬态价值函数更新基于不同表示时的收敛性，利用 Borkar 提出的双时间尺度证明技巧 [10]。虽然该方法通用且适用于多种随机逼近算法，但如 [9, 59] 所示，针对 RL 的条件可以简化。特别地，Lipschitz 假设通过证明矩阵形式的期望更新（即关键矩阵）良定义且正定来满足；最后一项假设则通过证明噪声项构成零均值、有界方差的鞅差序列来满足。

定理 A.1（Borkar, 1997）。 考虑如下形式的 d 维与 l 维耦合迭代：

θ_{t+1} ← θ_t + ᾱ(A(θ_t, w_t) + M_{t+1})，(7)

w_{t+1} ← w_t + α(C(θ_t, w_t) + N_{t+1})，(8)

其中 t ≥ 0。若：(1) A: R^{d+l} → R^d 与 C: R^{d+l} → R^l 为 Lipschitz 映射；(2) ∑t ᾱ_t = ∑_t α_t = ∞，∑_t ᾱ_t² = ∑_t α_t² ＜ ∞，且 lim{t→∞} ᾱ_t/α_t → 0；(3) 对 F_t ≜ σ(θ_k, w_k, M_k, N_k, k ≤ t)，(M_t, F_t) 与 (N_t, F_t) 为满足 ∑_t ᾱ_t M_t 与 ∑_t α_t N_t 几乎必然有界的随机变量序列；则迭代几乎必然收敛到相应极限常微分方程的渐近稳定平衡点。

定理 A.2（Tsitsiklis 与 Van Roy, 1996）。 考虑形如 w_{t+1} = w_t + α_t (A(X_t) w_t + b(X_t)) 的迭代算法，其中：(1) 步长序列满足 ∑t α_t = ∞，∑_t α_t² ＜ ∞；(2) X_t 是具有唯一不变分布的马尔可夫过程；(3) A(·) 与 b(·) 分别为矩阵值与向量值函数，A = E{d_π}[A(X_t)] 与 b = E_{d_π}[b(X_t)] 良定义且有限；(4) 矩阵 A 正定；(5) 存在常数 K 与 q，使得对所有 X 有 ∑{t=0}^∞ ‖E_π[A(X_t)|X_0=X] − A‖ ≤ K(1 + h^q(X)) 且 ∑{t=0}^∞ ‖E_π[b(X_t)|X_0=X] − b‖ ≤ K(1 + h^q(X))；(6) 对任意 q ＞ 1，存在常数 μ_q 使得 E_π[h^q(X_t)|X_0=X] ≤ μ_q(1 + h^q(X))。则 w_t 以概率一收敛到 w_π，其中 w_π 是满足 A w_π + b = 0 的唯一向量。

引理 A.3。 对任意固定的 θ 取值，对任务分布中的任意任务 τ，期望瞬态更新序列收敛到唯一不动点。

证明。 我们采用 [5, 59] 中的证明技巧建立收敛性。

作为线性随机逼近的瞬态更新。 为清晰起见省略 (τ, π) 下标，瞬态更新可写为

w_{t+1} = w_t + α_t (R_{t+1} + γ(θᵀφ_{t+1} + w_tᵀ z_{t+1}) − (θᵀφ_t + w_tᵀ z_t)) z_t = w_t + α_t (b(X_t) + A(X_t) w_t)，

其中 b(X_t) = z_t (R_{t+1} + γθᵀφ_{t+1} − θᵀφ_t)，A(X_t) = z_t (z_t − γz_{t+1})ᵀ，且 X_t = (S_t, S_{t+1}, φ_t, z_t)。

极限期望。 定义 A = lim_{t→∞} E[A(X_t)]，b = lim_{t→∞} E[b(X_t)]。显式地，

A = ∑s d(s) z(s) (z(s) − γ ∑{s'} [P]_{ss'} z(s'))ᵀ = Zᵀ D (I − γP) Z，

b = ∑s d(s) z(s) (R(s) + γθᵀ ∑{s'} [P]_{ss'} φ(s') − θᵀφ(s)) = Zᵀ D R + Zᵀ D (γP − I) Φθ。

A 正定，因为 D(I − γP) 的行和为正（γP 为次随机矩阵），列和也为正（1ᵀ D(I − γP) = dᵀ − γdᵀ = (1−γ)dᵀ ＞ 0）。

有界噪声。 利用马尔可夫链的混合性，‖E[A(X_t)|X_0] − A‖ = ‖Zᵀ(D_t − D)(I − γP)Z‖ ≤ B₁·Cσ^t·B₂·B₁ ≤ K₁σ^t，‖E[b(X_t)|X_0] − b‖ ≤ K₂σ^t。因此，∑{t=0}^∞ ‖E[A(X_t)|X_0] − A‖ ≤ K₁/(1−σ) = K̄₁，∑{t=0}^∞ ‖E[b(X_t)|X_0] − b‖ ≤ K₂/(1−σ) = K̄₂。

不动点。 因此，期望迭代收敛到唯一不动点

wτ = A⁻¹ b = (Zᵀ D(I − γP) Z)⁻¹ (Zᵀ D R + Zᵀ D(γP − I) Φθ) = w^(TD){Z,τ} − (Zᵀ D_τ (I − γP_{π,τ}) Z)⁻¹ Zᵀ D_τ (I − γP_{π,τ}) Φθ。∎

引理 A.4。 期望永久更新序列收敛到唯一不动点。

证明。 带瞬态不动点的永久更新。 由于永久更新在较慢的时间尺度上演化，可将瞬态参数视为已收敛。更新为 θ_{t+1} = θ_t + ᾱ_t C(X_t)，其中 C(X_t) = w_tᵀ z_t φ_t。定义 C = ∑_τ p(τ) ∑_s d_τ(s) w_τᵀ z(s) φ(s) = ∑_τ p(τ) Φᵀ D_τ Z w*_τ。

有界性与 Lipschitz 条件。 对每个任务 τ，C_τ = Φᵀ D_τ Z w_τ，利用 w_τ = A_τ⁻¹(Zᵀ D_τ R_τ + Zᵀ D_τ(γP_τ − I)Φθ)，可得 ‖C_τ‖ ≤ K₃，进而 ‖C‖ ≤ ∑_τ ‖Φᵀ D_τ Z w_τ‖ ≤ K₃。因此该映射有界且 Lipschitz。

噪声有界性。 由于任务独立同分布采样且每个任务的马尔可夫链快速混合，噪声项具有有限方差。

不动点。 因此，期望永久更新收敛到唯一不动点：由 0 = E_τ[Φᵀ D_τ Z v^(TD){Z,τ}] − E_τ[Φᵀ D_τ Π{Z,τ} Φθ*]，可得

θ* = E_τ[Φᵀ D_τ Π_{Z,τ} Φ]⁻¹ E_τ[Φᵀ D_τ Z v^(TD)_{Z,τ}]。∎

推论 A.5。 若 Z = Φ，则 θ = E_τ[Φᵀ D_τ Φ]⁻¹ E_τ[Φᵀ D_τ Φ w^(TD)_{Φ,τ}]，wτ = w^(TD){Φ,τ} − θ。此外，在单任务设定下，θ = w^(TD)_{Φ,τ} 且 w*_τ = 0。

证明。 当 Φ = Z 时，Π_{Z,τ} = Π_{Φ,τ} = Φ(Φᵀ D_τ(I − γP_{π,τ})Φ)⁻¹ Φᵀ D_τ(I − γP_{π,τ})，且 Π_{Φ,τ} Φ = Φ。因此 θ = E_τ[Φᵀ D_τ Φ]⁻¹ E_τ[Φᵀ D_τ Φ w^(TD)_Φ]，wτ = w^(TD){Φ,τ} − θ。在单任务设定下，θ = (Φᵀ D_τ Φ)⁻¹(Φᵀ D_τ Φ) w^(TD){Φ,τ} = w^(TD){Φ,τ}，wτ = w^(TD){Φ,τ} − θ = 0。∎

A.3.1 伪代码

非参数瞬态近似器通过三个核心方法实现：Put（存储输入观测，见算法 3）、Get（检索已存价值估计，见算法 4）与 UpdateTDError（按贡献比例更新估计，见算法 5）。

算法 3：PUT 方法

function put(M, x)
输入：M：瞬态记忆；x：观测；输出：更新后的记忆 M
(sig, tag) ← Minhash(x)
bins ← GetBuckets(sig)

在所有表中插入观测

for t ← 0 to T−1 do
if ContainsTag(M[t, bins[t]], tag) == false then
# 优先空槽，否则 LRU
slot ← SelectSlot(M, t, bins[t])
M[t, bins[t], slot].tag ← tag
# 取其他有效槽位的均值
M[t, bins[t], slot].values ← Initialize(t, bins[t])
else
slot ← FindSlotByTag(M[t, bins[t]], tag)
end if
M[t, bins[t], slot].age ← Touch(M.clock)
end for
M.clock ← M.clock + 1
return M

算法 4：GET 方法

function GET(M, x, ρ)
输入：M：瞬态记忆；x：观测；ρ：混合权重；输出：values
(sig, tag) ← Minhash(x)
bins ← GetBuckets(sig)
values ← 0

从每个表中收集价值

for t ← 0 to T−1 do
slot ← FindSlotByTag(M[t, bins[t]], tag)
# 匹配槽位的更新权重为 ρ
values ← values + ρ · M[t, bins[t], slot].values
OSlots ← FindOtherValidSlots(M[t, bins[t]], tag)
n ← len(OSlots)
# 将权重 (1−ρ) 在其他有效槽位间均分
for s ← 0 to n−1 do
values ← values + ((1−ρ)/n) · M[t, bins[t], OSlots[s]].values
end for
end for
return values

算法 5：UpdateTDError 方法

function UpdateTDError(M, x, a, ρ, δ, α)
输入：M：瞬态记忆；x：观测；a：动作；ρ：混合权重；δ：TD 误差；α：学习率；输出：更新后的记忆 M
(sig, tag) ← Minhash(x)
bins ← GetBuckets(sig)
for t ← 0 to T−1 do
slot ← FindSlotByTag(M[t, bins[t]], tag)
# 匹配槽位权重为 ρ
M[t, bins[t], slot].values[a] ← M[t, bins[t], slot].values[a] + (α/T)·ρ·δ
OSlots ← FindOtherValidSlots(M[t, bins[t]], tag)
n ← len(OSlots)
# TD 误差以权重 (1−ρ) 在其他有效槽位间均分
for s ← 0 to n−1 do
M[t, bins[t], OSlots[s]].values[a] ← M[t, bins[t], OSlots[s]].values[a] + (α(1−ρ)/(n·T))·δ
end for
end for
