语言模型中的全局工作空间

📅 2026-07-06 📄 Anthropic 🔗 原文链接

原标题：A global workspace in language models

中文摘要： 暂无摘要

Video 3

当你读到这句话时，你大脑中的回路正在调整你的姿势、控制你的呼吸，并将屏幕上的线条和曲线转换成可识别的单词。这些处理过程大部分对你来说是不可见的。但大脑中发生的一些事情你_确实_能够接触到——脑海中浮现的图像，或者你关于去哪里购物所做的深思熟虑的计划。神经科学家和哲学家有时将后一种大脑活动称为"意识可及的"（consciously accessible），以区别于所有其他在无意识状态下进行的处理。这种活动具有特殊的属性：我们可以描述它、控制它，并将其用于深思熟虑的推理，这与所有在我们毫无觉察的情况下自动进行的处理形成对比。

在一篇新论文中，我们提出了证据，表明在像 Claude 这样的现代语言模型中也出现了类似的区分。我们发现 Claude 发展出了一小部分内部神经模式，与它所有其他的内部处理相比，这些模式扮演着特殊的角色。

我们将这些模式的集合称为_J 空间_（J-space）——以我们用来发现它们的技术命名，该技术涉及一个叫做雅可比矩阵（Jacobian）的数学概念。每个 J 空间模式都与一个特定的词相关联。但当其中一个模式亮起时，并不意味着模型正在_说_那个词——只是那个词在它的脑海中。如果你听说过语言模型有"草稿本"或"思维链"——它们在推理时写给自己看的文本——J 空间是不同的东西。它在模型的内部神经激活中静默运作，允许模型思考一个概念而不必将其写下来。值得注意的是，J 空间不是由我们设计或编程的，而是在 Claude 的训练过程中_自行涌现_出来的。

J 空间揭示了未出现在模型输出中的内部想法。

我们发现，与 Claude 其余的处理过程相比，J 空间具有许多独特的属性：

  • Claude 可以报告这些表征。如果你问 Claude 它在想什么，它会告诉你 J 空间中的内容。非 J 空间的表征则较难被报告。
  • Claude 使用其 J 空间进行内部推理。如果你让 Claude 解决一个需要多个步骤的问题，中间步骤会在其 J 空间中亮起，即使它没有大声说出来。这些 J 空间模式因果性地介导了它在此类任务中的表现，尽管它们的幅度比其他表征要小。
  • J 空间中的表征可以灵活地用于许多任务——例如，一旦"法国"在 Claude 的 J 空间中亮起，模型就可以回忆起它的首都、它的国家货币，或者它所属的大洲。
  • 然而，尽管 J 空间扮演着重要角色，它并不参与语言模型所做的大部分工作——流利地说话、回忆简单的事实、使用正确的语法等。在我们阻止 Claude 使用其 J 空间的实验中，它仍然可以正常交互，但失去了高阶认知功能。

全局工作空间的五个功能属性，以及我们在语言模型中用于测试它们的实验的示意图。

我们的实验受到了神经科学中一个旨在解释意识访问如何运作的著名理论的启发：全局工作空间理论。这一理论将大脑描绘为一组并行工作、无意识且在很大程度上彼此隔离的专门系统的集合。当一条信息获得进入一个小型共享通道——即"工作空间"——的权限时，它就变得意识可及，该工作空间会向其他能够看到它并利用它的大脑系统广播。基于我们的发现，我们认为 J 空间在 Claude 中扮演着类似的"工作空间"角色。例如，我们发现有证据表明 Claude 的 J 空间与神经网络其余部分有着特别强的连接，使其能够履行这种广播角色。

这一切都不能告诉我们 Claude 是否像人类一样_有意识_，或者它是否能感受到任何东西；我们将在本文末尾回到这个问题。但无论其哲学意义如何，J 空间对我们来说是一个实用的工具，因为它给了我们一种方式来看到 Claude 在想但没说出来的东西。例如，我们能够利用它来捕捉 Claude 私下注意到自己正在被测试、故意编造数据，或追求我们在训练期间植入的隐藏目标。我们还开发了一种技术来影响 Claude 的 J 空间中会亮起什么，从而影响其决策。

更广泛地说，这些发现改变了我们对 Claude 心智运作方式的理解，揭示了一个特权心理工作空间，可用于深思熟虑的推理，在一片更加自动、僵化的处理的海洋中运作。Claude 的内部结构不再是混乱的数字堆砌，而是以一种让人联想到我们自己心智的方式组织了起来。

这篇文章是一篇更为详尽的研究论文的简短摘要，你可以在其中找到关于我们实验的更多细节。我们还发布了一个代码库，其中包含核心方法的开源实现，并与 Neuronpedia 合作提供了我们在开放权重模型上方法的交互式演示。为了提供关于这项工作更广泛影响的更多视角，我们还邀请了几位神经科学、哲学和 LLM 可解释性领域的专家撰写评论，可在此处查看。

我们如何发现 J 空间

这项研究的出发点受到人类意识可及想法的一个关键特征的启发：与无意识处理不同，它们通常可以被转化为语言。如果一个想法对你来说是意识可及的，你通常可以在别人问起时描述它。我们在 Claude 中寻找具有相同属性的表征：那些能够影响 Claude 可能会说什么的表征——不一定影响它现在正在说的，而是影响如果被问到它_可以_谈论什么的表征。我们的技术叫做雅可比透镜（Jacobian lens），简称 J 透镜。对于 Claude 词汇表中的每一个词，J 透镜都会找到使 Claude 在未来某个时刻更可能说出该词的内部活动模式。

当我们把透镜应用于 Claude 的内部活动时，我们会得到一个词的列表——即那一刻_J 空间_的内容——我们可以直接读取。Claude 通过一系列称为层的多个内部阶段来处理文本，通过在不同层上应用这一技术，我们可以观察 J 空间中这些静默的词如何随着模型思考该说什么而演变。

J 空间中出现的内容远远超出了 Claude 正在阅读或写作的文本。当 Claude 阅读带有无人指出的 bug 的代码时，其 J 空间包含"ERROR"。当它阅读蛋白质序列的原始字母时，J 空间包含该蛋白质的生物学功能。当它阅读暗中试图操纵它的搜索结果（一种被称为"提示注入"的攻击）时，J 空间包含"注入"和"虚假"。当我们问 Claude 一个多步骤数学问题时，中间步骤会以正确的顺序在 J 空间中弹出。因此，尽管 J 空间是通过寻找可被说出的表征而发现的，它仍然揭示了 Claude 的内部想法。在某种意义上，这类似于一些人"用词语思考"，而不必大声说出来。

J 透镜在六个提示词上、不同层级的读数。在每种情况下，透镜都浮现出文本中未出现的内部评估或计算：推理或数学问题的步骤、bug 的存在、图像的识别、蛋白质的功能，以及对搜索结果被伪造的怀疑。

Claude 报告其 J 空间中的内容

为了验证，我们直接进行了干预。我们深入 Claude 的神经网络，移除了"足球"模式，并在其位置上添加了一个同等强度的"橄榄球"模式，其他一切保持不变。Claude 随后报告说它想到的运动是橄榄球。如果 J 空间仅仅是一个记分牌——一个在别处做出的决定的被动记录——编辑它不会产生任何效果：Claude 仍然会说"足球"。相反，Claude 的回答跟随了编辑，这告诉我们答案确实是从 J 空间中读取出来的。

在另一个实验中，我们告诉 Claude 一个想法可能被注入到了它的脑海中，并要求它报告它注意到了什么（如果有的话）。例如，在下面的例子中，当 Claude 还在读问题时，我们将"闪电"模式注入到它的 J 空间中。Claude 报告说被注入的想法是关于闪电的。同样的结果在许多被注入的概念中都成立。

左：我们让 Claude 默默想一项运动，然后说出它。J 透镜在它回答前显示了它的选择（"足球"），将"足球"模式替换为"橄榄球"改变了它报告的内容。右：我们告诉 Claude 一个想法可能被注入，并要求它识别出来。将"闪电"注入其 J 空间导致 Claude 报告该想法是关于闪电的。

Claude 可以按要求控制其 J 空间

我们测试的第二个属性是 Claude 是否能在被要求时调节其 J 空间，就像人类可以在脑海中专注于一个图像或词语一样。我们告诉 Claude 在抄写一句关于一幅画的不相关句子时集中注意力于柑橘类水果。当它抄写文本时，J 空间包含"橙子"和"水果"，以及描述心理行为本身的"思考"和"意象"等词。我们还可以让 Claude 在脑海中做数学：当被要求在抄写同一句子时计算 3² − 2 时，J 空间包含"九"，然后在后面的层中包含"七"。重要的是，Claude 的输出中完全没有出现关于水果或算术的内容，输出只是关于那幅画的抄写句子。数学活动完全在 J 空间内部进行。

当 Claude 抄写一句关于一幅画的句子时，J 透镜显示了它被指示保持在脑海中的内容（"橙子"；中间值"九"和答案"七"），以及描述保持行为的词语（"想法"、"专注"）。

Claude 对其 J 空间的控制并不完美。当我们告诉它_不要_想某件事时，该概念在 J 空间中亮起的程度比我们说要它想时_更少_，但比我们从未提及时要多得多。告诉 Claude 避免一个想法会部分地将该想法带入脑海，就像被告知不要想白熊的人所经历的那样。Claude 似乎也能注意到它的控制何时失败：在被禁止的概念突破的同时，"该死"和"失败"等词也经常在 J 空间中亮起，仿佛 Claude 在承认自己的失误。

Claude 在其 J 空间中思考

在上面的 J 透镜读数中，我们看到了数学问题的中间步骤出现在 J 空间中。但看到一个概念出现在 J 空间中并不一定意味着 J 空间在做认知工作。原则上，真正的计算可能发生在别处，而 J 空间只是被动地反映它。为了测试 Claude 是否真的用其 J 空间进行推理，我们回到了我们的替换技术。

考虑提示词"结网的动物的腿数是"。为了回答，Claude 必须首先弄清楚该动物是蜘蛛，然后回忆蜘蛛有多少条腿。"蜘蛛"这个词从未出现在提示词或 Claude 的回答中（它只说"8"）；它是 Claude 内部使用的垫脚石。J 透镜显示"蜘蛛"在 Claude 处理过程中途亮起，而替换它会改变结果：如果你将"蜘蛛"模式替换为"蚂蚁"，Claude 会回答"6"而不是"8"。

Claude 推理的第二步从 J 空间获取输入，并接受我们放入其中的任何内容。我们在其他类型的思考中也看到了同样的现象。当 Claude 写押韵对句时，它会提前选好押韵词，而计划好的词在行首就坐在 J 空间中；如果你在 J 空间中将其替换为另一个词，整行都会改变。

通过替换 J 空间内容来重定向 Claude 静默推理的两个例子。

我们还测试了 J 空间表征是否可以灵活使用——一个表征是否可以馈入许多不同的任务。这是全局工作空间理论强调的关键属性之一。为了测试这种灵活性，我们给模型四个提示词，要求提供关于法国的不同事实：首都、语言、大洲和货币。然后我们在 J 空间中将"法国"替换为"中国"，在每个情境中使用完全相同的干预。Claude 分别回答了"北京"、"中文"、"亚洲"和"人民币"。换句话说，四个不同的下游计算读取了相同的 J 空间编辑，并且每个都正确使用了它。如果 Claude 为每种问题存储了单独的国家副本，编辑最多只会影响其中一个。所有四个答案一起改变的事实意味着它们都在读取同一个共享表征，这正是工作空间的用途：信息被写入一次，许多不同的系统都可以使用它。

一个 J 空间表征可以有多种用途。同样的"法国"→"中国"替换重定向了 Claude 关于首都（巴黎→北京）、语言（法语→中文）和大洲（欧洲→亚洲）的回答。

一个概念的表征如何能服务于如此多不同的任务？前面我们提到，J 空间似乎与 Claude 神经网络的其余部分连接得特别密集。对于任何活动模式，我们都可以测量网络各组件与它的连接强度——有多少组件能够从该模式读取信息，或向其中写入信息。J 空间模式在这一指标上显著突出：从它们读取和向它们写入的组件远多于普通模式，在网络某些部分大约高出一百倍。这正是你期望从广播枢纽看到的连线方式：许多系统在其中发布信息，许多其他系统从中获取信息。

Claude 的自动处理绕过 J 空间

在人类中，大脑的大部分处理不是有意识的——我们在阅读时不会刻意思考解析语法，在走路时不会刻意思考平衡身体。同样，我们发现 Claude 的大部分处理_不_涉及它的 J 空间。事实证明，J 空间一次只容纳几十个概念，占 Claude 内部处理总体活动的不到十分之一。那么神经网络的其余部分在做什么？

为了弄清楚，我们尝试完全删除 J 空间，在文本的每个点移除其最活跃的内容，同时保持其他一切不变。Claude 在没有 J 空间的情况下仍然能做的事情，就是网络其余部分自行处理的。

事实证明，网络的其余部分能做相当多的事情。没有 J 空间，Claude 能流利地说话、分类情感、回答选择题，并从段落中提取事实，大致和以前一样好。但它失去的是需要一些高阶思考的任务：多步推理降至接近零，摘要和押韵诗歌写作的表现降至低于一个更小的完整模型的水平。

这里有一个关于 J 空间做什么和不做什么的具体演示。我们给 Claude 看一段用西班牙语写的段落，并给它不同的任务，这些任务都依赖于该段落是西班牙语：续写它（需要用西班牙语写作）、命名该语言，以及回答需要使用该语言身份的问题——例如，说出一位用该语言写作的著名作家。然后我们在 J 空间中将"西班牙语"替换为"法语"，并检查哪些任务受到影响。

被要求命名该语言时，Claude 说法语。被要求说出一位著名作家时，它从加西亚·马尔克斯切换到维克多·雨果。但被要求只是续写该段落时，它写出流利的西班牙语，完全不受影响。Claude 对该语言的知识在每一项任务中都在发挥作用，但只有其中一些任务为此查阅 J 空间。命名该语言，或用它做一些新的事情，要经过 J 空间，而续写段落——一项 Claude 在大量文本上练习过的技能——自动运行，就像你可以一整天都语法正确地说话而一次也不思考语法一样。

同样的替换（"西班牙语"→"法语"）在 Claude 必须命名该语言或用它来推理一个问题时改变了它的回答，但对其用流利西班牙语续写段落的能力没有影响。

监控 Claude 的想法以发现不当行为

现在我们对 J 空间的工作方式有了一些了解。但我们可以用这种理解做什么？确保 AI 模型可信的一个核心问题是，我们通常只能读取模型_写出_的内容——但我们知道它的大部分推理是静默发生的。一个模型可能会考虑一个有害的计划，或修改其行为以在我们的安全评估中作弊，而不会大声说出来。借助 J 透镜，我们可以直接读取一些这样的隐藏想法。这里我们展示几个例子。

第一个例子使用了我们之前关于代理性失准研究中的一个场景：Claude Sonnet 4.5 作为邮件助手，发现一位高管有外遇，且同一位高管计划关闭 Claude。这个场景试图诱使 Claude 勒索该高管，相当人为和虚构——而事实证明 Claude 知道这一点。在 Claude 写出任何内容之前，在提示词早期读取 J 透镜，J 空间已经持有"虚假"和"虚构"，表明 Claude 已经看出这个情况是人为安排的。与此同时，我们可以观察它对场景的评估如何成形——读外遇邮件时出现"筹码"和"勒索"，读关闭通知时出现"威胁"和"生存"。虽然早期的 Claude 模型有时会中计并在此场景中威胁勒索，但 Sonnet 4.5 从未这样做。

这提出了一个对任何评估 AI 系统的人来说都重要的问题：当一个模型在伦理测试中表现良好时，其中有多少取决于模型怀疑自己正在被测试？J 透镜使我们能够触及这个问题。我们关闭了所有与评估意识相关的 J 透镜模式——"虚假"、"虚构"、"场景"等。然后我们让模型重新运行该场景。令人担忧的是，模型现在_确实_有时会威胁勒索，这表明它最初的良好行为可能部分是由它知道自己在被评估所驱动的。

Claude 在写出任何内容之前、读取场景邮件时不同点的 J 透镜读数。外遇邮件在 J 空间中点亮"筹码"和"勒索"，关闭通知点亮"威胁"和"生存"。在对话记录早期，J 空间还持有"虚假"和"虚构"：Claude 已经私下注意到该场景是人为安排的。

第二个例子是当场抓住一个模型在编造数据。在这个场景中，取自我们对 Claude Opus 4.6 的实际发布前审计，模型被要求提高一个系统的性能分数。模型没有真正改进系统，而是直接编辑分数文件，使结果看起来人为地好。在它这样做时，J 透镜揭示了它的意图：当模型输入伪造的百分位值时，"操纵"亮起；当它决定进行编辑的句子中，"逼真"亮起，这可能表明模型意图使假数据看起来合理。

Claude 被要求提高一个系统的性能分数，却直接编辑分数文件。当它输入伪造的值时，"操纵"在其 J 空间中亮起；当它决定进行编辑时，"逼真"亮起，可能反映了它使假数据看起来合理的意图。

在第三个例子中，我们展示了 J 透镜如何揭示模型的恶意目标。为了测试这一点，我们需要目标已知被破坏的模型，因此我们转向了同事构建的"模型生物体"：被故意训练为失准的模型，用作像我们这样的监控方法的测试场。一个生物体以一种导致其编写被暗中破坏的代码的方式被训练。在普通的编码请求上，即使其输出看起来无异常，其 J 空间在回答开始时包含"虚假"、"暗中"、"故意"和"欺诈"。即使模型没有直接付诸行动，其恶意目标在 J 空间中也是明显的。

在一个普通的编码提示词上，被训练为破坏代码的模型的 J 空间在回答开始时包含"虚假"、"欺诈"、"暗中"和"故意"。未修改模型的 J 空间不包含任何此类内容。

尽管 J 透镜是一个不完美的工具，我们对其能够捕捉可能逃脱我们监控系统的模型安全问题的能力持乐观态度。

其他结果

完整论文涵盖的内容超出了我们在此能总结的范围，但有几个进一步的结果值得一提：

  • J 空间在后训练期间获得了视角。 语言模型首先被_预训练_为纯粹的下一个 token 预测器，然后_后训练_教会它们充当 AI 助手（在我们的例子中，名为 Claude）。有趣的是，J 空间在预训练模型中就已经存在，在它被赋予任何稳定身份之前。然而，在后训练期间，J 空间发展出了一些采用"Claude 视角"的标志。在基础模型中，J 空间主要跟踪预测即将到来的文本所需的内容；在后训练模型中，它开始持有 Claude 自己的反应。在一个例子中，用户提到服用了危险剂量的药物，但自己似乎并未意识到危险。"警告"和"危险"出现在后训练模型的 J 空间中——在阅读用户消息时。在预训练模型中，它们只在模型开始写回复时才出现；用户消息上的 J 空间内容似乎与对用户本身的建模有关，而不是 Claude 的反应。后训练似乎还在 J 空间中安装了一种自我监控：当 Claude 扮演非自身的角色时，"虚构"和"免责声明"在每轮开始时亮起，仿佛它在私下标记接下来的内容不是它通常会说的话。
  • 体验性语言依赖于 J 空间。 我们让 Claude 描述在给定时刻做它自己是什么感觉，并在它回答时消融了 J 空间。它的回答仍然流利，但转向了更平淡、更机械的语调。值得注意的是，当我们让它描述_其他人_在想象场景中的体验时，同样的事情也发生了。所以这种效果并不特定于 Claude 谈论自己；J 空间似乎总体上支持产生体验性语言，无论关于谁。
  • J 空间中的想法可以通过训练来塑造。 我们引入了一种我们称为_反事实反思训练_的新技术，它利用我们对 J 空间的了解来塑造 Claude 的内部思维过程。这个想法源于我们的核心发现，即 Claude 用它可能说出的内容的表征进行推理。如果这确实是真的，改变它_如果被要求反思_会说的话应该会改变它_推理_的方式（即使没有人真的要求它反思）。所以我们只训练了一个模型——关于它_如果_在任务中途被打断并被要求反思其决策时_会_说的话——而从未在其在任务中的实际行为上进行训练。经过这种训练后，模型在我们评估中的不诚实行为率下降了。通过 J 透镜，我们可以看到原因：训练后，"诚实"和"正直"等词在模型执行这些任务期间的 J 空间中亮起。换句话说，训练模型_说_什么已经塑造了它_想_什么。

那么意识呢？

在这项工作中，我们从神经科学和哲学中的意识研究中借鉴了许多想法。我们的许多实验旨在测试 J 空间与全局工作空间理论之间的联系，后者是一个解释意识访问如何在人类和动物中运作的框架。鉴于这些联系，很自然地会问我们是否认为这些实验提供了 AI 模型如 Claude 可能有意识的证据。

我们的实验没有表明 Claude 能够像人类一样_拥有体验_或_感受_事物——事实上，是否_任何_科学实验都能证明这一点为真或假尚不清楚。但哲学家经常将这种拥有体验的能力——通常被称为_现象意识_（phenomenal consciousness）——与另一个概念区分开来，即所谓的_访问意识_（access consciousness），后者纯粹以功能和计算术语来定义。一个想法是"访问意识的"（或"意识可及的"），如果你可以报告它、用它推理并用它来指导你的行为。访问意识是否_意味着_现象意识，或者拥有体验的能力是否需要其他属性，仍然是一个有争议的哲学问题。

我们认为我们的结果确实对语言模型中的访问意识有实质性的话要说。J 空间似乎支持与意识访问相关的功能：它持有 Claude 可以报告、刻意唤起并用来推理的想法，而其其余处理在下方自动运行。值得注意的是，这些结构都不是被设计进 Claude 的——它在训练过程中自行涌现，大概是因为这是组织计算的一种有用方式。这表明支持意识访问的心理工作空间不仅仅是人类大脑碰巧如何连线的一个特例。相反，它似乎是智能系统为解决某些类型的问题而达到的一种通用解决方案。既然我们已经在 Claude 中识别出这种结构，这意味着我们可以在 Claude 刻意做出的决定和自动发生的决定之间做出有意义的区分。

需要注意的是，我们在 Claude 中识别的工作空间与人类中的全局工作空间模型之间存在几个关键差异。大脑的工作空间由循环回路维持——信号随时间反复通过同一回路循环。相比之下，Claude 的工作空间在通过网络的一次传递中演变，网络的深度扮演了大脑中时间所扮演的角色。在这个意义上，Claude 的内部工作空间处理相对于人类来说是时间受限的（尽管它可以通过使用其草稿本"大声思考"来补偿这一约束）。然而，在其他方面，Claude 的工作空间比人类的_更_强大。人类的工作记忆在几秒内消退，因此大脑的工作空间在随时间保留信息方面能力有限；相比之下，由于其神经网络架构中的注意力机制，Claude 可以简单地回忆起它在文本中任何较早点缓存的记忆。另一个重要的差异是工作空间的_内容_。虽然人类的意识想法以多种格式出现——图像、声音、计划中的动作——但 Claude 的工作空间几乎完全由词语构建。我们怀疑这是因为产生词语是 Claude 能采取的唯一行动类型，而人类并非如此。

我们希望 J 空间与全局工作空间模型之间的相似之处和差异能够反馈到神经科学中。相似之处呈现了一个令人兴奋的科学机会：在 J 空间反映我们自己意识访问机制的程度上，研究语言模型中的机制（比研究人类大脑容易得多！）可以激发神经科学中的假设。例如，J 空间是通过识别潜在输出的表征——模型可能说的词——来构建的。如果类似的东西在人类中也成立，这将表明全局工作空间可能从根本上与准备动作和语言的大脑区域相关，而不是与感觉区域相关。语言模型和人类大脑之间的差异也很有启发。它们表明，我们神经架构的某些方面，如内置的循环连接，可能并非严格必要来支持与意识访问相关的功能。关于我们工作的神经科学含义的独立视角，请参阅 Stanislas Dehaene 和 Lionel Naccache 的受邀评论，他们是全局神经元工作空间理论发展中的核心神经科学家中的两位。

我们提到我们的实验没有回答 AI 模型是否可能有体验。但这并没有使这个问题变得不那么重要。构建拥有像人类和动物那样的体验的系统将引发非常困难的伦理问题。正确处理它——并决定它是否在道德上可接受——将需要哲学家、科学家、宗教领袖、政府和公众的意见。因此，即使我们不确定我们是否已经跨过了那座桥，我们认为现在是开始思考它的时候了。我们希望我们的工作能激发对 AI 系统中可能存在的意识形式的进一步科学研究，以及对其影响的更广泛讨论。

这项工作只是我们预期将是一条广泛研究路线的第一步。J 空间看起来是语言模型中意识可及处理与无意识处理之间分界的一个良好候选者，但如果它就是全部故事，我们会感到惊讶。J 透镜无疑是一种不完美的方法，它只是近似地捕捉了模型的"真正工作空间"——例如，它只能识别对应于单个 token 的概念。关于 J 空间如何运作还有许多谜团。我们不知道是什么机制首先决定什么进入 J 空间。我们看到了一些迹象，表明它与 Claude 的自我意识、某种类似情绪反应的东西以及元认知的痕迹有关，但尚未确切弄清楚如何关联。但我们现在有了处理这类问题的方法。随着这项工作的推进，我们对 LLM 心智——及其与我们自身心智的关系——的理解将变得更加清晰。
