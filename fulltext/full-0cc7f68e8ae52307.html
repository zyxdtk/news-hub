摘要

现代生成模型通常因其泛化能力而受到研究，而记忆则被视为一种失败模式。我们反转这一视角，追问生成模型如何能够回忆起单个数据。我们将记忆构建为一个控制问题：学习到的条件信号引导冻结的扩散模型趋向目标图像，我们在训练全程追踪这一记忆的形成。在收敛到精确复现（逐字）之前，记忆会经历一个抽象阶段：样本保留目标的语义内容（要点），同时在外观上保持多样性，将可预测的细节留给生成先验。这种语义组织在没有任何标签、标题或显式语义目标的情况下涌现。在抽象阶段，学习到的记忆接近普通文本条件的效果，并且比近乎完美的重建阶段更有效地支持编辑、单样本识别和检索。这些结果表明，记忆可以作为探针，用于探测生成模型所编码的相关性结构：关于一个数据必须存储什么、什么可以从先验知识重建，以及学习到的记忆如何在重建式回忆与字面数据存储之间插值。

一本浓缩了数十年研究的科学教科书所占用的磁盘空间，可能比一张模糊的度假照片还要少。从人类视角看，这一事实可能显得陌生，因为数据存储与记忆之间存在根本差异。磁盘字面地存储任何对象，没有相关性概念，也没有解释性先验。而记忆并不完整地保留观察：我们会选择保留什么，并在回忆时根据先验知识重建其余部分。

新信息与先验之间的交互如何塑造记忆的形成？这个问题处于两条长期研究路线的交汇处。记忆的重建观将存储的痕迹与用于重建经验的先验知识区分开来（Bartlett, 1932; Schacter and Addis, 2007; Spens and Burgess, 2024）。计算神经科学的近期工作将海马体痕迹解释为用于新皮层生成式重建的压缩线索，并将情景-语义记忆解释为一种自适应压缩过程（Spens and Burgess, 2026; Nagy et al., 2025）。编码与最小描述长度的视角类似地使描述长度相对于给定模型而言：一旦模型固定，只有未被解释的残差需要被编码（Rissanen, 1978; Grünwald and Roos, 2019）。这两种观点都表明，记忆应当相对于已知内容来理解。然而，尚未解答的是：单个数据中的信息如何按相关性排序——什么最先被提交到记忆，什么最初可以隐含在先验中。

现代生成模型为我们提供了探索这一问题的实验平台。关于扩散模型记忆的近期工作研究了训练样本何时被复现，以及如何检测或缓解这种复制（Carlini et al., 2023; Somepalli et al., 2023）。与此同时，多种个性化方法被提出用于使预训练扩散模型适应新主体或新概念，以便在新的上下文中重新生成它们（Gal et al., 2023; Ruiz et al., 2023; Kumari et al., 2023; Voronov et al., 2023）。在这项工作中，我们提出一个不同的问题：如果一个强大的生成先验被刻意要求去记忆一张图像，它在此过程中学到了什么？记忆形成如何展开？我们冻结先验，仅从单张图像训练条件信号，并在训练全程追踪由此形成的记忆。

由此得到的轨迹既令人惊讶又令人熟悉。在接近精确重建之前，记忆会经历一个抽象阶段：生成的样本纳入目标的语义内容（要点），同时在姿态、外观、背景和其他实例特定细节上保持多样性。只有经过进一步训练，记忆才进入锁定阶段，此时回忆变为逐字，即目标图像被完全复现。在记忆形成过程中没有提供任何标签、标题或语义标准。这种动态让人联想到谱偏差，即神经网络优先学习某些模式而非其他（Rahaman et al., 2019）。然而，这里的排序不仅仅是空间频率的排序：它源自新数据与预训练生成先验已编码结构之间的相互作用。

记忆回忆成为相关性的探针：模型存储什么、留给先验知识什么、以及以何种顺序。我们的贡献如下：

  • 我们识别并量化了单图像记忆中的抽象阶段（图 1），其中语义内容远早于实例特定外观被获取。类似的现象也可在不同设置和数据模态中被追踪到（图 4）。
  • 我们将记忆表述为先验介导的控制问题，并提供了一个最小理论框架，其中学习同时依赖于目标中的残差信息和生成先验的敏感度。随后我们在实验设置中验证了关于抽象阶段的两个定性预测（图 2）。
  • 我们通过评估学习记忆的三种能力，证明抽象是一个独特的功能阶段（图 3）：可编辑性（在回忆时整合新信息）、单样本识别（识别同一主体的未见实现）和文本-记忆检索（通过文本线索访问记忆）。这些能力在抽象阶段涌现，并随着重建趋近逐字目标而退化，揭示了回忆精度与记忆可复用性之间的权衡。

2 通过扩散先验进行记忆

条件扩散模型背景。扩散模型通过学习逆转渐进加噪过程，从复杂分布中生成样本。从数据点 x₀ ∼ p₀ 出发，我们定义其加噪版本 x_t ∼ p_t 为

x_t = α_t x₀ + σ_t ε， ε ∼ N(0, I)， t ∈ [0, T]。 (1)

在常见的保方差形式中，当 t → T 时 α_t → 0 且 σ_t → 1，因此 p_T 逼近标准高斯分布。该框架涵盖 DDPM（Ho et al., 2020）和连续时间扩散模型（Song et al., 2021b）。由于 p_T 易于采样，生成可以通过近似逆转加噪过程来完成。逆动力学由分数函数 s(x, t) = ∇_x log p_t(x) 决定。如附录 B 所述，该分数可通过去噪分数匹配学习，即优化神经网络 s_θ(x, t)，目标为

L(θ) = E_{t,x₀,ε}[λ(t) ‖s_θ(x_t, t) + ε/σ_t‖²]， (2)

其中 λ(t) 允许对不同噪声级别赋予不同权重。最优预测器可恢复边际分数 s(x, t)。在条件扩散模型中，生成还受变量 C（如文本标题）引导。在数据-条件信号对上训练，可使网络近似条件分数 s_C(x, t) = ∇_x log p_t(x | C)，从而从 p₀(x | C) 生成样本。

作为条件信号的记忆。考虑一个预训练条件扩散模型，其数据分布为 p₀，分数为 s₀(x, t)。我们研究如何让这样的模型回忆单个目标图像 x。重要的是，我们并非通过微调生成模型的参数来实现这一目标——这些参数保持预训练值冻结——而是通过学习一个紧凑的条件信号 C。下文中，我们关注 C 的训练轨迹，将其视为记忆过程，并将 C 称为记忆。在生成过程中，记忆充当控制：它引导逆扩散趋向 x，同时依托预训练先验编码的结构。

相对于先验的残差。目标在预训练生成模型下的负对数似然为 −log p₀(x)，可解释为其在先验下的理想码长（Rissanen, 1978; Grünwald and Roos, 2019）。在此观点下，记忆 C 无需从头编码数据：它只需提供模型尚未解释的部分。因此，学习可被视为逐步消减相对于先验的残差。本工作的核心问题是：这一残差如何在训练轨迹中被消解——数据的哪些性质在先验下是相关的*因而先被存储，哪些最初留给模型去猜测。

训练目标。我们在单个目标图像 x* 上使用扩散模型的去噪目标学习控制信号 C，保持所有预训练参数冻结。在公式 (1) 的加噪下，加噪目标的精确分数为

s(x_t, t) = −σ_t⁻²(x_t − α_t x)。 (3)

令 s_C(x, t) 表示记忆条件 C 下冻结模型的分数。我们通过仅对 C 最小化以下目标来建模记忆：

L(C) = E_{t,ε}[‖s_C(x_t, t) − s(x_t*, t)‖²]。 (4)

实例化。我们主要在 Stable Diffusion 2.1（SD2.1）（Rombach et al., 2022）中实例化这一构造。这是一个潜在扩散模型：预训练 VAE 将图像映射到潜在表示，UNet 学习对潜在表示的加噪版本去噪。因此，我们将去噪目标（公式 4）应用于目标的潜在表示 z = VAE(x)，使用模型原生的 v 预测参数化和均匀时间采样。

SD2.1 是文本条件化的。文本编码器将标题映射为标记嵌入序列，通过交叉注意力条件化 UNet：图像特征提供查询，文本嵌入提供键和值。当未提供标题时，模型接收空标题 c_∅ 的嵌入。我们以这个空标题模型作为生成先验 p₀。

我们用 M 个可学习向量 C = {c₁, …, c_M} 表示记忆，每个向量维度 D = 1024。这些向量进入与文本通路平行的第二条交叉注意力通路，使用相同的冻结投影参数。因此，在每个 UNet 交叉注意力层：

Attn_tot(h) = Attn_text(h, c_∅) + Attn_mem(h, C)。 (5)

只有 C 被优化；VAE、UNet、文本编码器和注意力投影的所有参数保持冻结。我们以小的随机值初始化 C，使记忆的贡献最初可忽略，模型从接近先验 p₀ 的状态出发。注意，我们学习到的条件向量是直接馈入交叉注意力机制的，而不像用户提示那样必须经过文本编码器。这使我们的设置尽可能不依赖于“SD2.1 通过文本条件化”这一事实，并可推广到任何可通过注意力条件化的模型。

模型生成目标 vs. 外部目标。除非另有说明，我们的主要实验使用 SD2.1 从精选标题集生成的目标。这一选择基于两个原因。第一，位于模型生成库内的目标应具有较小的初始残差，并允许 C 在渐近训练阶段达到较低的重建偏差。第二，每个目标都带有已知的语义参考——生成它的标题——我们在后续分析中使用。关键在于，该标题在记忆过程中不被提供：C 仅从目标图像学习。在附录 E.1 中，我们在外部数据上重复了实验。

3 从要点到逐字

我们首先追问：记忆获得了什么，以何种顺序获得。如图 1所示，在训练全程追踪单图像记忆（最小化公式 4）揭示出一致的轨迹。

先抽象后锁定。初始化时，样本重现预训练先验。经过相对较少的更新后，生成结果在语义上与目标对齐，同时在姿态、外观、背景和其他实例特定细节上保持多样性。随着训练继续和记忆向量范数增长（见附录 E.3），这种变异性逐渐消失，直至不同噪声实现收敛到同一图像。我们将中间阶段称为抽象阶段：记忆已获取目标的语义内容，而其特定外观仍在很大程度上不受约束。这种语义组织并非由记忆训练目标所施加——该目标既不提供标签也不提供语义监督。因此，抽象不是语义从零开始的涌现，而是数据特征与先验已表示的语义结构之间的共振。我们将之后的训练阶段称为锁定阶段，其中实例特定的空间与表面细节逐渐被固定到目标。

语义 vs. 表面。我们在图 1中量化这一转变。在每个检查点，我们从独立初始噪声生成多个样本，并在 DINOv2（Oquab et al., 2024）（语义）和 VAE（表面）表示空间中与目标比较。我们测量两个量：平均样本与目标表示之间的平方距离（偏差²），以及单个样本围绕其均值的分散度（方差）。两者均按目标表示的平方范数归一化；精确定义见附录 D.1。

两类信息在明显不同的时间尺度上被获取。表面与语义半衰期步数（定义为每条偏差²曲线完成其观测下降的一半时的步数）之比的中位数为 21.4（图 1b）。语义偏差迅速下降并在训练早期基本消除，而表面偏差在同一区间内保持高位，仅在之后的锁定阶段下降。重要的是，虽然语义偏差在训练结束时已基本收敛，表面偏差往往尚未收敛。若后者继续下降，有限的训练终点会低估其半衰期步数。由于我们的兴趣在于确立先后顺序而非精确的时间尺度比值，这使我们的结论对有限训练范围具有鲁棒性。

语义优先的排序在替代的语义与表面表示、归一化选择以及独立训练初始化下均保持稳健（附录 E.5 与 E.6）。在附录 E.1 中，我们还表明同样的现象可推广到外部照片。但对于强分布外目标，抽象阶段可能减弱甚至完全消失，这取决于先验所表示的属性（附录 E.2）。

记忆大小的影响。记忆大小 M 主要影响锁定阶段。如图 1所示，增加可学习向量的数量会降低最终表面误差，但早期语义时间尺度基本不受影响。特别地，单向量记忆（M=1）以与更大记忆大致相同的时间表获取语义内容，但不会趋近精确重建。因此，抽象不仅仅是表征容量不足的后果：即使最终能复现目标的记忆，也会经历一个语义内容已获取而细节尚未解决的阶段。记忆范数的作用（包括重缩放和固定范数对照）在附录 E.3 中考察。

4 抽象作为先验介导控制的框架

为组织这些观察，我们引入一个最小数学模型，刻画抽象阶段涌现的条件。令 φ: ℝ^d → {0,1}^F 为一组可测二值特征，捕获生成模型所表示的属性。这些特征可以是高级语义属性（如“一张脸”），也可以是空间局部化的几何细节（如“特定图像位置上的特定姿态”）。我们将学习到的记忆的效果建模为对预训练生成分布的指数倾斜：

p_u(x) = e^{u^⊤φ(x)} / Z(u) · p₀(x)， Z(u) = E_{p₀}[e^{u^⊤φ(X)}]。 (6)

这里 u ∈ ℝ^F 是学习记忆 C 的理论对应物。虽然 C 在 SD2.1 中由学习条件向量表示，u 则直接对抽象特征坐标 φ 加权，决定强调目标的哪些属性。倾斜后的分数分解为 s_u(x, t) = s₀(x, t) + δs_u(x, t)，其中

δs_u(x, t) = ∇_x log E₀[e^{u^⊤φ(X₀)} | X_t = x]， (7)

其中 E₀[· | X_t = x] 表示在 p₀ 与前向加噪过程诱导的后验下的期望。修正项 δs_u 是一个依赖状态和时间的控制场：在每个噪声级别，它在预训练模型自身的后验下评估所要求的属性距离实现有多远，并相应地推动动力学。

为研究记忆如何被获取，定义当前特征残差

r_φ(u) = φ(x*) − E_{p_u}[φ(X)]。 (8)

对于保方差扩散过程和适当的扩散时间加权（见附录 B），去噪目标等价于最小化目标的负对数似然。虽然这一加权与 SD2.1 中使用的不同，但它使我们能得到控制量 u 的简单梯度流动力学：

du/dτ = −η∇_u L = η r_φ(u)， dr_φ/dτ = −η Σ_u r_φ， (9)

其中倾斜模型下的特征协方差 Σ_u = Cov_{p_u}[φ(X₀)] 是一个线性敏感度，因为 ∂u E{p_u}[φ] = Σ_u：特征空间中特征值较大的方向对倾斜参数 u 的微小变化响应更强。公式 (9) 中的记忆动力学由两个要素支配：残差 r_φ，指明目标的哪些属性尚未被复现；以及敏感度 Σ_u，决定哪些特征空间方向最容易被改变。

考虑一个简单的二值特征有助于建立直觉。若某特征在当前倾斜模型下以概率 p 出现，其敏感度为 Var(φ) = p(1−p)。高度特定的事件（“某位置上的某姿态”）满足 p ≪ 1，因而敏感度低。更宽泛的属性（“一张脸”）可以有显著更大的敏感度，因此更容易被获取。在多变量情形中，相关性提供了另一个敏感度来源：语义属性往往参与连贯的组合，而高度局部化的细节通常与其他特征耦合较弱。这与图 1一致：身份与风格先出现，而姿态与服装仍在变化。

该框架刻意保持最小化：其目的是识别能够产生抽象阶段的要素，而非提供对 SD2.1 的精确描述。特别是，我们并不声称指数倾斜精确再现了交叉注意力条件化的效果。因此，证明高敏感度语义模式可以导致抽象，并不能确立该机制就是实验中观察到行为的原因。鉴于 SD2.1 的复杂性，直接验证这一假设颇具挑战。不过，该框架给出了两个可以在实验上检验的定性预测。 在记忆早期，倾斜较弱，敏感度结构仍接近预训练先验的结构。通过预训练，文本条件与先验中编码的高敏感度语义方向对齐。然而标题并不能完全约束生成图像：不同的初始噪声产生与同一文本一致的不同实现。若抽象记忆充当类似的弱语义约束，它应保留部分这种依赖噪声的先验变异性。 随着快速语义残差被消除，学习转向较慢的低敏感度特征。精确重建必须捕获这些更精细的约束，包括那些指定并控制目标空间实现的约束。在我们的实现中，这应表现为越来越依赖位置的寻址。

5 抽象阶段的分析

第 4 节给出了抽象与锁定阶段的两个特征。第一，抽象记忆应保留从先验继承的变异性，在该阶段表现出类似标题的行为。第二，随着记忆在锁定期间固定空间细节，其影响应变得更加位置特定。下面我们检验这些预测。

5.1 通过先验的泛化

为检验记忆是否保留从先验继承的变异性，我们用不同初始噪声实现从固定标题生成一组图像，然后在其中 N 张图像上联合训练单个记忆。当 N 大于 1 时，这成为一种提示反演形式。我们在留出的初始噪声上评估泛化：对每个噪声，比较在原始标题和学习记忆下生成的图像。同样的检验在 N = 1 时仍有意义：跨留出噪声的系统性对应表明，记忆通过先验恢复了其单张训练图像中不存在的变异性。

配对优势。我们用记忆条件样本与标题条件样本之间的 DINOv2 距离度量这种对应。对每个留出的初始噪声，我们比较从相同噪声生成的两个样本之间的距离，与将记忆样本与从不同噪声生成的标题条件样本配对所得到的平均距离。我们将“未配对距离减去配对距离”称为配对优势，并以平均成对距离归一化。度量公式的更多细节见附录 D.2、公式 (33)。

初始化时，记忆条件化可忽略，仅先验与标题条件化差异显著，因此共享相同初始噪声几乎不产生对应，优势接近零。在抽象阶段，正的配对优势表明记忆与标题条件化以足够相似的方式引导先验，使相同初始噪声产生对应的实现。随着趋近精确回忆，记忆条件化抑制了这种噪声依赖性，使优势回落至零。细节见附录 D.2。

图 2：通过先验的泛化。 每行对应一个标题-噪声对。对两个标题各展示两个输入噪声实现（1-2）。各列依次为：标题条件样本；记忆条件样本（N=1）在初始化时、配对优势峰值附近（第 100 步，红框）、训练后期（第 250 步）以及锁定后（第 4000 步）的样本；训练图像。每行输入噪声保持固定。对每个标题，展示的两个实现是在峰值处配对优势最大的那些。 十二个描述面部的标题在训练过程中的配对优势，每个标题一个记忆，N=1（蓝色）与 N=50（绿色）；中位数，色带：IQR。灰色虚线：相同样本与相同输入噪声下无关标题池的得分。 训练过程中的位置分数 f，对每个记忆大小取 30 个记忆的平均（动物、车辆、面部各 10 个；色带：标准误）。虚线：M=1 对照组，其无法直接学习依赖位置的寻址。

从单张图像泛化。图 2展示了两个示例和十二个标题的汇总结果。初始化时，记忆样本与标题条件参考无关。在配对优势峰值附近，样本倾向于跟随各自配对参考的属性，包括姿态、构图和色彩，同时与训练图像保持不同。训练后期，部分变异性仍然存在，但样本日益获取目标的身份、色调和背景。这种有偏泛化的中间形式（Garnier-Brun et al., 2026; Rodriguez et al., 2026）与“实例特定约束在语义内容获取之后增强”相一致。继续训练后，对初始噪声的依赖随着输出收敛到记忆图像而消失，配对优势回到零。

在峰值处，配对的标题参考是约 20% 记忆条件样本的最近邻（该实验中机会水平为 2%）。因此该效应显著但在不同噪声实现间并不均匀，表明标题条件先验所支持的不变性受到了限制。当与来自无关标题的图像比较时，相同样本不显示任何优势；而在同一标题的 N=50 张图像上训练的记忆达到约两倍的峰值优势，并在训练后期保持对应关系。

5.2 从内容依赖到位置特异性

第二个预测关乎记忆在网络内部如何起作用。记忆标记通过交叉注意力影响生成，在其中被投影为键和值。查询-键交互决定每个标记在何处贡献，而值决定它提供什么信息。因此我们考察记忆的寻址在训练中如何变化。

注意力 logits 中的内容与位置。我们想区分记忆的寻址是依赖于正在处理的图像，还是绑定到固定的空间位置。我们考察图像查询与记忆键之间的 softmax 前交互。我们使用图像查询与记忆键之间的余弦相似度，这可以排除训练中记忆范数的巨大变化，并且在 M=1 时仍有信息量——此时 softmax 注意力权重恒等于 1。

使用固定的留出图像集合，我们按全方差定律分解这些得分的变异性。第一个分量 V_cont 度量在固定空间位置上得分随图像变化的程度。第二个分量 V_pos 度量在图像上取平均后，跨位置保留的变异。我们报告位置分数 f，即 V_pos 占总方差的比例。小值表示以内容依赖的寻址为主，大值表示位置特异性增强。更多细节见附录 D.3。

锁定期间寻址变得位置特定。图 2显示出清晰的转变。在整个抽象阶段，位置分数保持低位且近似恒定。随着锁定开始，多标记记忆的位置分数急剧上升，表明跨图像共享的空间模式在寻址变异性中占据越来越大的比例。

M=1 的情形提供了有用的对照。对于单个记忆标记，softmax 注意力权重恒为 1，因此无法直接学习位置注意力。共享的记忆向量仍会通过值通路更新，这可以间接改变查询-键 logits 并产生渐进的位置漂移。这可以借助冻结先验支持良好的重建，但只会产生 M=1 所见的渐进变化。位置特异性的急剧上升仅在 M 大于 1 且记忆趋近逐字阶段时出现。

6 保真度-功能性权衡

记忆理论早已区分要点式与逐字式表征，行为研究表明泛化或可及性可能以精度为代价（Brainerd and Reyna, 2002; Berens et al., 2020）。在扩散个性化中，定制质量早期饱和的观察催生了高效的早停策略（Voronov et al., 2023）。我们现在追问：保真度-功能性权衡是否会在我们的记忆形成过程中自发出现？具体而言，提高对所存储实例的保真度，是否必然改善记忆的功用？

我们探测三种互补的功能形式。可编辑性问记忆能否与回忆时提供的新信息整合。单样本识别问它是否保留有用的不变性，能否对同一主体的未见实现给出良好解释。文本-记忆检索问它能否通过文本线索被访问。在全部三项探测中，功能性在抽象阶段涌现，随后随着重建趋近逐字目标而退化（图 3），即便回忆保真度仍在持续改善。

图 3：保真度-功能性权衡。 可编辑性。编辑后的图像被部分加噪并在目标的记忆下去噪。上：两个同身份编辑和两个跨身份输入。各列展示编辑、三个检查点的输出以及目标。输出在抽象阶段保留编辑，在锁定阶段回退到目标。下：到编辑的 DINOv2 距离（D_edit）随着到目标距离（D_orig）的减小而增大，在 20 个同身份目标-编辑对上测量，每对两个样本。 单样本识别。300 张留出图像（每个身份 10 张）中的每一张在 30 个身份记忆中被分类，分配给在 20 个共享时间步-噪声对上给出最低去噪误差的记忆（机会水平：1/30）。上：抽象与锁定阶段五个查询（编辑）在 30 个身份中得分最高的三个。下：top-1 与 top-3 准确率（按身份取中位数和 IQR），每个身份 10 个查询。 文本-记忆检索。15 个记忆中的每一个都在无文本线索的条件下，在由详细标题生成的单张图像上训练。三个特异性级别的线索根据文本编码器 EOS 嵌入与平均池化记忆向量之间的余弦相似度对记忆排序。上：抽象与锁定阶段两个身份排名最高的两个记忆，由其训练图像表示。下：与正确记忆的相似度减去与其他记忆的平均相似度。在 与 中，红框表示正确匹配。曲线：中位数；色带： 中目标-编辑对、 与 中身份的 IQR。

可编辑性。我们遵循类似基于扩散编辑的协议：从部分加噪的输入出发，让先验完成去噪过程（Meng et al., 2022）。对每个目标 x_orig 及其编辑版本 x_edit（用 FLUX 生成，Labs et al., 2025；见附录 D.4），我们对编辑图像部分加噪，并在检查点记忆下按 U 形协议完成去噪。然后测量所得样本与编辑的 DINOv2 余弦距离 D_edit，以及与存储图像的 D_orig。在抽象阶段，姿态、表情、配饰和场景的变化在输出中仍然可见。随着记忆推进，D_edit 增大而 D_orig 减小：更忠实重建目标的同一记忆，与外部编辑的兼容性却越来越低（图 3）。当要整合的新信息是另一个人的图像时，也出现同样的转变：抽象记忆保留输入的大量信息，而逐字记忆越来越多地以其存储主体覆盖输入。采样、加噪与平均的细节见附录 D.4。

单样本识别。条件去噪误差本身可以充当生成式分类器，无论零样本（Li et al., 2023）还是少样本（Chattopadhyay et al., 2024）设置。这里我们追问：训练得到的记忆是否会在一段时期内获得足够的不变性，以识别对应主体的未见实现。我们为三十个不同身份（人脸）各训练一个记忆，并构建一个留出查询集，展示相同身份在不同姿态与场景中的图像。在每个检查点，我们在每个候选记忆下评估公式 (4) 中每个查询的去噪损失，并将查询分配给损失最低的身份。识别准确率在抽象阶段迅速上升：top-3 准确率达到 0.9，top-1 达到 0.8，二者遵循相同的非单调轨迹，随后在锁定开始时退化至机会水平（图 3）。因此，尽管训练图像的重建持续改善，记忆却逐渐失去在新外观下识别同一主体所需的不变性。

文本-记忆检索。虽然文本从不参与记忆形成，我们仍可追问：仅从图像训练的记忆能否通过语义线索被访问，以及这种可及性如何随回忆精度变化。对每个身份，我们从详细标题生成单张训练图像并训练相应记忆。评估时，我们用三个特异性递增的文本描述查询记忆：类别标签加一个区分属性、简短描述、以及图像的详细描述（见附录 D.6）。在每个检查点，我们对 M 个条件向量做平均池化，并通过余弦相似度与冻结的标题嵌入比较。对每个线索级别，检索由每个描述与对应身份的相似度相对于其他身份来度量。与语义线索的对齐迅速出现并在抽象阶段达到峰值——尽管文本从未进入记忆训练目标。更详细的线索更强地检索记忆，而所有级别都随着记忆日益专门化于特定训练实现而失去对齐（图 3）。

这些实验揭示了保真度-功能性权衡：随着回忆变得更精确，记忆变得更难编辑、跨实现的不变性更弱、也更难通过语义线索访问。因此，额外的实例特定信息会改变记忆的功能。

我们现在检验在 SD 2.1 中观察到的“要点到逐字”排序是否可以跨架构、生成目标、记忆参数化和模态推广。我们用 CogVideoX-2b（Yang et al., 2025）和整流流图像模型 FLUX.2（Black Forest Labs, 2024）重复单数据记忆，将记忆注入适配到每个模型的原生注意力架构。

跨架构与模态的抽象。图 4表明，两个被测模型在逐字重建之前都经历了中间的抽象阶段。引人注目的是，在 CogVideoX 中，记忆轨迹揭示场景结构（街道/海滩）和特征运动（汽车或云的方向）属于最早被获取的属性，而实例特定的外观在不同初始噪声实现间仍在变化。只是到后来，生成的视频片段才收敛到目标。在 FLUX.2 中，身份与姿态同样先于训练图像的精确外观出现。在附录 E.4 中，我们进一步表明，对 SD 2.1 做单图像 LoRA 适应（Hu et al., 2021）会产生与图 1类似的抽象阶段。

这些结果共同表明，逐字回忆之前的抽象并不依赖于 SD 2.1 的交叉注意力接口或我们特定的记忆参数化，并且可以在架构、生成目标和模态的变化中持续存在。

8 局限性

我们指出四点局限。 观察到的语义优先组织无法完全与预训练期间文本条件化的影响分离。虽然记忆形成本身不接受文本监督，但数据结构与语言可能都是塑造抽象涌现所需语义方向的必要条件。 我们在强分布外目标上的实验有限。在这些极端情形下，记忆轨迹发生定性改变，抽象阶段收窄甚至完全消失。 理论框架主要作为解释性模型，而非对观测动力学的完整机制性说明。提取更详细的预测需要对模型结构做额外假设，这会降低框架的普适性。 保真度-功能性权衡是针对我们的记忆协议和有限的功能探测集建立的。不同的目标或记忆参数化可能削弱甚至完全避免这一权衡。

9 结论

结果表明，要点式与逐字式回忆可以在同一记忆过程的不同阶段涌现——数据是相对于生成先验被学习的。最先值得存储的内容并非数据的内在属性，而取决于先验能重建什么、以及哪些残差方向能被最高效地获取。结果还揭示了精确回忆的弊端：提高保真度可以丰富抽象记忆，却可能抹去使记忆可复用的不变性。

这一图景引出若干问题。抽象与语义结构的对齐可能同时反映语言监督与数据中已有的规律。分离这两者的贡献需要无文本或在受控数据统计下学习的先验。更广泛地说，保真度-功能性权衡表明，有用的人工记忆不必一路优化到精确重建；其特异性水平可以依用途调整：当灵活性、检索或与新信息整合更重要时，抽象记忆可能更可取；而忠实重建需要更精确的记忆。理解并控制这种平衡，可为基于预训练生成模型的记忆系统设计提供参考。最后，追踪记忆轨迹中被获取的内容，或许提供了一种揭示生成先验自身相关性结构的途径。

附录概述

附录 A 扩展相关工作

生成先验与有损压缩。将记忆视为“存储先验无法提供的内容”与有损压缩的生成式方法密切相关。经典率-失真理论形式化了表示速率与重建精度之间的权衡，而感知-失真与率-失真-感知框架则将逐样本保真度与“重建须在感知上与数据分布保持一致”的要求区分开来（Blau and Michaeli, 2018; 2019; Niu et al., 2025）。与我们的设置接近，Tschannen et al. (2018) 研究分布保持的有损压缩，其极限情形从零速率时由学习分布生成，到足够高速率时的精确重建。近来，预训练扩散模型被直接用作恢复压缩所丢弃信息的强先验（Relic et al., 2024）。信息论工作还研究了可在变化的失真与感知约束下逐步细化的表示（Zhang et al., 2021）。Bachmann et al. (2025) 与 Atanov et al. (2026) 学习有序表示，其中较短的标记前缀捕获抽象内容，附加标记细化重建。这些工作改变的是显式表示预算（如比特率或标记前缀长度）；而在本文中，表示大小固定，排序在优化时间上展开。

压缩与重建式记忆。认知科学与计算神经科学的平行文献将记忆视为压缩表示，其缺失信息可由先验知识重建。从贝叶斯观点看，回忆可形式化为噪声情景证据与不同抽象层级先验知识的交互（Hemmer and Steyvers, 2009）；率-失真方法则论证了感知与记忆资源的限制天然产生选择性、有损的表示（Bates and Jacobs, 2020）。在 Nagy et al. (2020) 的语义压缩框架中，通过学习到的生成模型进行压缩会产生系统性的记忆扭曲，以及细节化回忆与日益要点化回忆之间的连续谱。Fayyaz et al. (2022) 类似地提出，情景记忆存储不完整的“情景要点”，由生成式语义系统补全痕迹中省略的信息。这些工作与本文的共同观点是：必须显式存储的内容取决于先前经验模型能重建什么。

生成式记忆与残差信息。近期工作使记忆与生成预测的关系日益明确。Spens and Burgess (2026) 的海马-新皮层模型将海马痕迹描述为用于检索并条件化生成网络的压缩表示，避免显式存储可由新皮层知识提供的信息。Nagy et al. (2025) 的自适应压缩框架将该思想扩展到语义知识本身随时间变化的设定：令人惊讶的经验可以更新模型，而非仅仅相对于固定模型被压缩。我们的构造刻意冻结生成先验，从而分离出“相对于既有知识体系形成单个新记忆”这一互补问题。

互补视角来自 Chandra et al. (2025)，他们研究预先存在的海马空间结构如何改变情景与联想回忆所需显式存储的内容。其空间支架将序列学习简化为结构化转移，回忆细节取决于可用的表征资源。与我们的残差表述更直接相关的是，Lin et al. (2024) 表明压缩视觉表示的重建残差可预测人类记忆痕迹的强度与检索延迟。这支持了更广泛的观点：现有表示难以解释的信息可获得优先的记忆资源。

要点、意义与抽象。超越第 6 节讨论的要点-逐字之分，统计力学近期的一项工作将语义压缩形式化为“在保留语义表示空间中位置的同时最小化描述长度”，产生不同的无损/有损与抽取式/抽象式体制（Can, 2025）。尽管该工作关注语义压缩而非记忆形成，它为“抽象即保留语义结构、丢弃更细信息”提供了互补的形式化。

生成先验的倾斜与控制。我们将记忆描述为冻结生成分布的学习式修改，这一理论描述与近期关于扩散与流模型的控制论视角相联系。Uehara et al. (2024) 将扩散微调形式化为相对于预训练过程的熵正则化随机控制；Domingo-Enrich et al. (2025) 将扩散与流模型的奖励微调视为随机最优控制问题。更近的工作直接考虑通过指数倾斜基生成密度得到的目标分布（Potaptchik et al., 2026; Domingo-Enrich et al., 2026）。与之不同，我们的指数倾斜模型并非旨在成为新的微调算法的一部分，而是用于构建记忆形成的最小化描述。

学习式条件化与反演。除正文讨论的个性化方法外，ELITE 与 IP-Adapter 学习从参考图像到条件表示的映射（Wei et al., 2023; Ye et al., 2023）；Null-text Inversion 在图像特定的反演轨迹附近优化无条件嵌入，以支持重建与文本引导编辑（Mokady et al., 2023）。这些方法主要关注获得有用的条件化或可编辑的重建，而我们关注单个学习条件信号的属性在其优化过程中如何变化。

附录 B 数学框架推导

本附录给出第 4 节中各公式的推导。

首先定义 ℝ^d 中的前向加噪过程，它如公式 (1) 那样逐渐将数据点 x₀ ∼ p₀ 与高斯噪声混合：

x_t = α_t x₀ + σ_t ε， ε ∼ N(0, I)， t ∈ [0, T]， (10)

如第 2 节所述，通常取 t → T 时 α_t → 0、σ_t → 1，使终端分布 p_T 为标准高斯。在每个时间步，加噪点 x_t 的边际分布为

p_t(x) = ∫ dx₀ p₀(x₀) N(x; α_t x₀, σ_t² I)。 (11)

从 p₀ 采样通过逆转前向过程完成，即找到一个从 p_T 出发、把我们带回 p₀ 的过程。思路是 p_T 易于采样，因此获得 p₀ 的样本就像先从 p_T 抽取、再沿后向过程演化一样简单。这可以多种方式实现：例如训练模型从 x_t 推断原始 x₀，或推断所加噪声 ε，再逆转公式 (1)。这些方法都与分数函数 s(x, t) = ∇_x log p_t(x) 通过 Tweedie 公式（Efron, 2011）相关联，后者可由公式 (11) 直接计算得到：

s₀(x, t) = ∇_x log ∫ dx₀ p₀(x₀) N(x; α_t x₀, σ_t² I) = (α_t E[x₀|x_t] − x_t)/σ_t² = −E[ε|x_t]/σ_t。 (12)

现在转向公式 (6) 引入的二值特征 φ 的指数倾斜：

p_u(x₀) = e^{u^⊤φ(x₀)}/Z(u) · p₀(x₀)， Z(u) = E_{p₀}[e^{u^⊤φ(X₀)}]。

当对此新目标分布的样本加噪时，得到公式 (11) 边际的略微修改版本：

p_t^u(x_t) = (1/Z(u)) ∫ dx₀ p₀(x₀) N(x; α_t x₀, σ_t² I) e^{u^⊤φ(X₀)} = (1/Z(u)) p_t(x_t) E₀[e^{u^⊤φ(X₀)} | X_t = x]， (13)(14)

其中用贝叶斯定理写出

p₀(x₀) N(x; α_t x₀, σ_t² I) = p₀(x₀) p(x_t|x₀) = p(x₀|x_t) p_t(x_t)， (15)

并用 E₀[·] 表示对 p(x₀|x_t) 的期望，即由原始 p₀ 与前向加噪过程诱导的后验。

公式 (14) 的表达式使我们能直接推导新分数的分解 s_u(x, t) = s₀(x, t) + δs_u(x, t)（Kappen, 2005）：

δs_u(x, t) = ∇_x log E₀[e^{u^⊤φ(X₀)} | X_t = x]。 (16)

条件向量 u 的学习方式是：选定单个数据 x，使 p_u(x₀) 坍缩到 p(x₀) = δ(x₀ − x)，即强制条件模型只产生 x。这可通过最小化公式 (4) 的加权目标实现，更明确地写为：

L(u) = ∫₀^T dt w(t) E_{p}[‖s_u(X_t, t) − s(X_t, t)‖²]， (17)

其中

p(x_t, t) = N(x; α_t x, σ_t² I) (18)

是从 x 出发的前向过程的边际，而 s(x_t, t) = −σ_t⁻²(x_t − α_t x*) 是与之关联的分数，如公式 (3) 所得。

为进一步研究梯度流诱导的 u 的演化，我们采用基于 SDE 的生成框架。特别地，在加噪阶段使用 Ornstein-Uhlenbeck 过程，对应保方差（VP）格式：

dx_θ = −x dθ + √2 dW_θ， (19)

其中 dW_θ 为维纳过程，θ ∈ [0, Θ]。可证明该过程的解为

x_t = e^{−θ} x₀ + √(1−e^{−2θ}) ε， (20)

取 θ = −log α_t、σ_t = √(1−α_t²) 并令 Θ → ∞，即可化归为公式 (1)。若定义后向时间 s = Θ − θ（具有负增量 ds），后向过程可写为

dx_s = (−x_s − 2s(x_s, θ = Θ − s)) ds + √2 dW̃_s， (21)

其中 dW̃_s 与原过程独立。

在该框架下，有一种优雅的方式重写目标 L(u)：首先，类似于（Lyu, 2009），可以证明经公式 (20) 加噪的两个分布 p¹ 与 p² 之间的 Kullback-Leibler 散度按如下方式演化：

d/dθ D_KL(p_θ¹ ‖ p_θ²) = −E_{p_θ¹}[‖∇x log p_θ¹(X_θ) − ∇_x log p_θ²(X_θ)‖²] = −E{p_θ¹}[‖s¹(X_θ, θ=Θ−s) − s²(X_θ, θ=Θ−s)‖²]， (22)(23)

负号与两分布都趋于标准高斯的事实一致。在大 Θ 极限下，p_Θ¹ = p_Θ² = N(0, I)：从该分布出发并使用精确分数，后向过程（公式 21）将在 s = Θ − θ 时重现精确边际 p_θ¹ 与 p_θ²。于是，我们可以从 D_KL(p_Θ¹ ‖ p_Θ²) = 0 出发对前式积分（翻转符号）得到

D_KL(p¹ ‖ p²) = ∫₀^Θ ds E_{p_s¹}[‖s₁(X_s, θ=Θ−s) − s₂(X_s, θ=Θ−s)‖²]， (24)

再将该表达式与似然时间加权 w(t) dt ∝ ds（Song et al., 2021a）一并代入，得到：

L(u) = D_KL(p ‖ p_u) = −log p_u(x) = −u^⊤φ(x*) + log Z(u) + const。 (25)

需要强调，虽然这一 w(t) 的选择在理论设定中最为便利，但并非我们在实验中所用。公式 (25) 使我们能轻易得到公式 (9) 中学习率为 η 的 u 的梯度流动力学：

du/dτ = −η∇_u L = η r_φ(u)， (26)

其中使用了公式 (8) 的定义 r_φ(u) = φ(x*) − E_{p_u}[φ(X)]，以及

∇ log Z(u) = (1/Z(u)) ∫ dx₀ p(x₀) φ(x₀) e^{u^⊤φ(x₀)} = E_{p_u}[φ(X₀)] (27)

这一事实。剩下的工作是求 r_φ(u) 的导数，由链式法则可表示为

dr/dτ = (∂r/∂u)(du/dτ)， (28)

其中 ∂r/∂u 是以 ∂r_i/∂u_j 为元素的矩阵。这些元素可以容易地表示为：

∂r_i/∂u_j = −∂E_{p_u}[φ_i(X₀)]/∂u_j = −∂/∂u_j [(1/Z(u)) ∫ dx₀ p(x₀) φ(X₀) e^{u^⊤φ(X₀)}] = −E_{p_u}[φ_i(X₀)φ_j(X₀)] + E_{p_u}[φ_i(X₀)] E_{p_u}[φ_j(X₀)] = −[Σ_u]_{ij}， (29)(30)

最终得到公式 (9) 中的另一表达式：

dr_φ/dτ = −η Σ_u r_φ。 (31)

附录 C 实现细节

记忆参数化。记忆是 M 个可学习向量 C = {c₁, …, c_M}，c_m ∈ ℝ^1024，存在于冻结 UNet 的交叉注意力上下文空间中（M=8 时有 8,192 个可训练参数）。在每个交叉注意力层，记忆通过复用该层冻结查询/键/值/输出投影的第二次注意力通路被读取。值与输出投影在不带偏置的情况下应用，因此零记忆的贡献严格为零。由此，在 C = 0 时，生成与空标题模型严格一致。注意，这种并行构造允许我们自由改变记忆大小 M，而不受文本嵌入空间大小（77 个标记）的约束。文本通路在整个过程中以空标题为条件。

初始化。每个向量按独立同分布高斯绘制，标准差为 0.01（每向量范数约 0.32）。我们采用这种随机初始化而非将所有向量置零，因为后者是退化的：所有键将重合，并无限期地接收相同的梯度。

训练。我们在目标潜在表示（x* 在 768px 下的 VAE 后验均值）上最小化冻结模型自身的去噪目标（公式 4），使用原生 v 预测目标与均匀采样的 t。优化使用 AdamW，学习率 10⁻²，无权重衰减，恒定调度且无预热。每个梯度步对同一目标平均 8 次独立的 抽取。除非另有说明，每次运行持续 5,000 步，在固定网格上保存约 20 个检查点。

采样。所有样本使用 DPM-Solver++（多步，3 阶），50 步，768px，无分类器引导 ω = 3；无条件分支为分离记忆后的同一模型。对用作参考的标题条件生成图像，我们同样使用 ω = 3，因此记忆条件与标题条件样本始终在相同协议下比较。采样在给定噪声种子下是确定性的，这正是第 5 节种子配对比较的依据。评估种子按实验固定，且与任何参与创建训练目标的种子不相交。

计算。每次单图像运行（训练加检查点采样）在单块 A100/H100 级 GPU 上耗时数小时；论文中所有实验均为单 GPU。
