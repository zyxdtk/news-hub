摘要
测试时训练（TTT）通过在推理过程中持续更新权重来实现长上下文处理，但当前的方法难以在逐 token 更新动态的表达能力与分块近似的硬件效率之间取得平衡。我们提出了 E²-TTT（具有表达能力且高效的 TTT）来弥合这一差距。

在采用在块起始权重处计算梯度的标准近似下，我们推导出了一个闭式状态转移，它精确地重现了逐 token 递归在块末尾的快权重和动量状态。

这使得能够进行完全并行化的块级训练，同时保留了先前分块方法所丢弃的更新规则的时间结构。
我们通过从头开始训练高达 1.3B 参数的模型来验证 E²-TTT。

它在语言建模方面与以前的 TTT 和混合注意力基线表现相当，同时在上下文检索方面优于它们。它的优势在长度外推中最为明显：在标准的“大海捞针”密码测试中，它在 8 倍训练上下文长度下保持了超过 90% 的准确率。

同时，E²-TTT 可以匹配高效分块方法的训练吞吐量，这表明它有效地调和了表达能力与效率。

1 引言
最先进的大型语言模型（LLMs）[44, 16, 2] 在推理、编码和多模态理解方面展示了卓越的能力。然而，一旦训练完成，这些模型的权重就保持冻结，使得它们只能依赖累积的记忆（例如键值缓存 [48, 49]）来处理长上下文智能体任务 [43, 41, 34]。这一基本限制阻碍了它们从长时序任务中持续学习或在现实场景中跨任务泛化的能力。

为了解决这一限制，出现了两种主要方法。第一种方法试图通过引入 RNN 风格或混合架构 [13, 64, 47, 32]，将注意力的计算复杂度从二次降低到线性，从而能够处理更长的序列。然而，正如 Tandon 等人 [58] 所证明的，在长上下文语言建模中，这些技术仍然不如全注意力有效。第二种方法被称为测试时训练 [56, 9]，它将循环状态的概念扩展到小型的、在线自适应的子网络（例如快权重 [54]），允许模型在推理过程中不断调整其参数。最近的大量研究 [12, 58, 69] 探索了其在长上下文文本和多模态任务中的潜力。

尽管前景广阔，但现有的 TTT 方法面临着表达能力和效率之间众所周知的困境。一方面，原始 TTT [56, 9] 采用逐 token 更新，这提供了强大的表达能力，但导致训练缓慢，因为 token 级别的依赖性强制了顺序递归。另一方面，分块 TTT [69] 通过在更大的块上执行更新，显著提高了效率，但由于对更新规则的过度简化，它牺牲了表达能力，有效地掩盖了块内 token 重要性的时间方差。

为了在表达能力和效率两方面做到两全其美，我们提出了 E²-TTT，一种新颖的 TTT 方法，它将 token 级别的表达能力与块级别的计算效率相协调。

核心创新是一个闭式并行标量核，它能够并行执行具有逐 token 学习率、动量和衰减的递归动态。具体来说，我们的公式保留了对块末尾快权重状态的精确逐 token 影响，这是先前分块方法通过平均化丢弃的一种时间结构，同时保留了块级别的硬件并行性。

此外，我们将 E²-TTT 集成到一个结合了 TTT 和滑动窗口注意力的混合架构中，使我们的模型能够在保持细粒度局部上下文的同时处理长时序任务。

我们通过在 HuggingFace FineWeb-Edu 数据集 [46] 的 15B token 上从头开始训练高达 1.3B 参数的模型，并与强大的线性注意力和混合基线进行比较，从经验上验证了 E²-TTT。我们的评估涵盖了一般语言建模、上下文检索和长度外推，其中增益集中在检索和外推领域。

值得注意的是，我们的模型在长度外推方面表现出强大的鲁棒性，在 8 倍训练上下文的“大海捞针”密码检索测试中保持 >90% 的准确率，而在这种情况下，先前的基于块的方法已经崩溃。

最后，我们通过用于长上下文视频理解的参数高效适配来探索我们方法的多功能性，在标准多模态基准测试中，在 2B 参数规模下实现了与全量微调相当的性能。

总的来说，我们展示了表达性顺序更新的好处，同时匹配了标准分块 TTT 的训练吞吐量，为 TTT 范式提供了新的见解。

2 背景：测试时训练
与将历史压缩为激活向量或矩阵值状态的标准 RNN 或线性注意力模型不同，测试时训练（TTT）[56] 将隐藏状态建模为序列相关非线性函数 $f_{\mathbf{W}{t}}(\cdot):\mathbb{R}^{d}\rightarrow\mathbb{R}^{d}$ 的可学习权重 $\mathbf{W}{t}$。这些权重通常被称为快权重 [54]，在训练和推理期间都会快速调整以动态存储上下文，而慢权重（即模型参数）在推理期间是固定的。

图 1：TTT 的概念概述。首先，从输入派生的键（$\bm{k}{t}$）和值（$\bm{v}{t}$）用于更新（或“训练”）快权重 $\mathbf{W}$，编码当前上下文。其次，更新后的权重 $\mathbf{W}{t}$ 应用于查询（$\bm{q}{t}$）以产生输出 $\bm{o}_{t}$。

如图 1 所示，一般的 TTT 过程在每个步骤中分两个阶段运行：更新阶段和输出阶段。首先，输入 token 被投影为查询（$\bm{q}{t}$）、键（$\bm{k}{t}$）和值（$\bm{v}{t}$）向量，其中 $\bm{q}{t},\bm{k}{t},\bm{v}{t}\in\mathbb{R}^{d}$。键和值用于通过自监督目标更新快权重，有效地将上下文编码到具有固定状态大小的神经记忆中。其次，将更新后的快权重应用于查询以生成输出 token $\bm{o}_{t}$。根据这些更新和输出规则的结构方式，我们将当前的 TTT 公式分为三组，描述如下。

表达性逐 token 更新。
在这个标准公式中，更新严格发生在 token 级别。在每个时间步 $t$，快权重 $\mathbf{W}{t}\in\mathbb{R}^{d\times d}$ 通过最小化变换后的键 $f{\mathbf{W}{t-1}}(\bm{k}{t})$ 和值 $\bm{v}{t}$ 之间的自监督重建损失 $\mathcal{L}$ 来更新。设 $\mathbf{G}{t}$ 表示负梯度，$\eta_{t}$ 表示学习率：
$\mathbf{G}{t}=-\nabla{\mathbf{W}}\mathcal{L}\big(f_{\mathbf{W}{t-1}}(\bm{k}{t}),\bm{v}{t}\big),\qquad\mathbf{W}{t}=\mathbf{W}{t-1}+\eta{t}\mathbf{G}{t}.$ (1)
损失函数通常是均方误差 [56]。
更新后的快权重 $\mathbf{W}{t}$ 随后立即用于计算当前查询 $\bm{q}{t}$ 的输出向量 $\bm{o}{t}$：
$\bm{o}{t}=f{\mathbf{W}{t}}(\bm{q}{t}).$ (2)

具有小批量梯度的逐 token 更新。
虽然逐 token 更新提供了高表达能力 [56]，但它强制了阻止并行化的顺序递归，并导致硬件利用率低下的内存受限操作。因此，最近的工作 [56, 9] 采用了小批量方法。序列被划分为由 $r$ 索引的小批量，每个小批量的较小大小为 $B$（例如 16）。我们使用符号 $(\cdot)_{t}^{[r]}$ 来表示与第 $r$ 个批次中第 $t$ 个 token 相关联的变量。

设 $\mathbf{W}{B}^{[r-1]}=\mathbf{W}{0}^{[r]}$ 表示来自前一个批次的状态。在批次 $r$ 内部，使用这个固定的 $\mathbf{W}{B}^{[r-1]}$ 来近似梯度，这解耦了前向传播的依赖关系：
$\mathbf{G}{t}^{[r]}=-\nabla_{\mathbf{W}}\mathcal{L}\big(f_{\mathbf{W}{B}^{[r-1]}}(\bm{k}{t}^{[r]}),\bm{v}{t}^{[r]}\big),\quad\mathbf{W}{t}^{[r]}=\mathbf{W}{t-1}^{[r]}+\eta{t}\mathbf{G}{t}^{[r]},\quad\bm{o}{t}^{[r]}=f_{\mathbf{W}{t}^{[r]}}(\bm{q}{t}^{[r]})$ (3)
这种近似使得能够为所有 token $t\in{1,\dots,B}$ 并行计算梯度 $\mathbf{G}{t}^{[r]}$。一旦计算完成，快权重 $\mathbf{W}{t}^{[r]}$ 就可以被计算出来，例如通过并行关联扫描 [55]。

高效的分块更新。
尽管能够并行计算梯度，但小批量大小较小以及小批量更新中的 token 级别依赖性仍然导致硬件利用率低下（通常 FLOPs 效率 <5% [69]）。为了解决这个问题，LaCT [69] 转向了大块公式。序列被划分为由 $r$ 索引的大块，每块大小为 $C\gg B$（例如 $C=512$）。在第 $r$ 个块内，LaCT 利用微分的线性来聚合优化目标。它不是在每个 token 步骤具体化梯度，而是计算累积加权损失的梯度，为整个块产生一个单一的更新方向 $\mathbf{G}^{[r]}$。当整合动量时，LaCT 采用了一种简化的策略：对时间相关的动量因子 $\beta_{t}^{[r]}$ 取平均值，以维护块级别的动量缓冲 $\mathbf{M}^{[r]}$：
$\mathbf{G}^{[r]}=-\nabla_{\mathbf{W}}\bigg(\sum_{t=1}^{C}\eta_{t}^{[r]}\mathcal{L}\big(f_{\mathbf{W}^{[r-1]}}(\bm{k}{t}^{[r]}),\bm{v}{t}^{[r]}\big)\bigg),$ (4)
$\mathbf{M}^{[r]}=\bigg(\frac{1}{C}\sum_{t=1}^{C}\beta_{t}^{[r]}\bigg)\mathbf{M}^{[r-1]}+\mathbf{G}^{[r]},\qquad\mathbf{W}^{[r]}=\mathbf{W}^{[r-1]}+\mathbf{M}^{[r]}.$ (5)
这个公式允许维护块级别的状态（即 $\mathbf{G}^{[r]}, \mathbf{M}^{[r]}, \mathbf{W}^{[r]}$）而不是 token 级别的状态，将每个块具体化的快权重状态数量从 $C$ 减少到 $1$。由于新的权重 $\mathbf{W}^{[r]}$ 只有在处理完整个块后才可用，因此输出 $\mathbf{O}^{[r]}$（包含块中所有 token 的输出）是使用前一个块的权重计算的：
$\mathbf{O}^{[r]}=f_{\mathbf{W}^{[r-1]}}(\mathbf{Q}^{[r]}).$ (6)

3 表达性且高效的测试时训练
当前的 TTT 变体呈现出鲜明的权衡：逐 token 更新提供了高优化保真度，但受制于顺序瓶颈；而分块更新通过简化更新规则实现了硬件效率，有效地掩盖了块内 token 重要性的时间方差。

为了解决这种二分法，我们引入了 E²-TTT（表达性且高效的 TTT）。
我们的关键贡献是一个新颖的理论公式，它将具有耦合动量和衰减的逐 token 递归映射到一个闭式的、块并行的更新中，在不近似逐 token 动态的情况下重现其块末尾状态。

这使我们能够保留每个梯度贡献的精确逐 token 时间加权，同时匹配粗粒度块处理的硬件效率。

3.1 原始公式：逐 token 动态
我们首先定义我们的目标优化行为。与简化的块平均（公式 5）不同，我们的目标是强制执行精确的、具有耦合 L2 衰减和动量的 token 级别递归，这种配置在最近的工作 [69, 64, 9] 中被证明是有益的。设 $\mathbf{W}{t},\mathbf{M}{t},\mathbf{G}{t}\in\mathbb{R}^{d\times d}$ 分别表示快权重、动量和负梯度（更新方向）。设 $\gamma{t},\beta_{t}\in(0,1)$ 为标量衰减和动量因子，$\eta_{t}>0$ 为学习率。我们目标的顺序递归定义为：
$\mathbf{M}{t}=\beta{t}\,\mathbf{M}{t-1}+\eta{t}\,\mathbf{G}{t},\qquad\mathbf{W}{t}=\gamma_{t}\,\mathbf{W}{t-1}+\mathbf{M}{t}.$ (7)
$\gamma_{t}$、$\beta_{t}$ 和 $\eta_{t}$ 的特定参数化是从输入 $\bm{x}{t}$ 预测的，并且独立于 $(\mathbf{W},\mathbf{M})$，如第 4 节所述。与小批量设置（公式 3）一样，梯度 $\mathbf{G}{t}$ 是使用前一个块的固定权重（$\mathbf{W}_{C}^{[r-1]}$）计算的，这跨 $t$ 解耦了它们，并允许在更新步骤之前并行计算它们。

实际传播到下一个块的状态是块末尾状态 $(\mathbf{W}{C}^{[r]},\mathbf{M}{C}^{[r]})$；所有 $t<C$ 的中间状态 $(\mathbf{W}{t}^{[r]},\mathbf{M}{t}^{[r]})$ 都不会被存储。

3.2 通过标量核进行闭式并行化
天真地执行公式 (7) 需要顺序迭代（$t=1\to C$）。虽然并行前缀扫描理论上可以计算这些状态，但它们通常需要在每个时间步计算并存储 $\mathbf{W}{t}$、$\mathbf{M}{t}$ 和 $\mathbf{G}_{t}$。由于这些是密集矩阵，存储整个序列会产生 $O(C\cdot d^{2})$ 的高昂内存成本，在现代加速器上造成瓶颈，特别是考虑到较大的块大小 $C$。

为了在不简化公式 (7) 动态的情况下实现高效训练，我们推导出了一个闭式的等价形式，它可以在单步内从块起始（$t=0$）“跳跃”到末尾（$t=C$）。我们的见解是，虽然矩阵状态 $(\mathbf{W},\mathbf{M})$ 很昂贵，但衰减和动量因子 $(\gamma_{t},\beta_{t})$ 是标量。通过展开递归并对求和重新索引，我们可以将整个时间动态历史压缩为标量系数，这些系数隔离了每个梯度 $\mathbf{G}{t}$ 对最终状态的贡献（完整推导见附录 A）：
$\mathbf{W}{C}=\underbrace{\Big(\prod_{t=1}^{C}\gamma_{t}\Big)}{\text{衰减项}}\mathbf{W}{0}+\underbrace{\sum_{t=1}^{C}\Big(\Big(\prod_{i=1}^{t}\beta_{i}\Big)\mathbf{M}{0}\prod{q=t+1}^{C}\gamma_{q}\Big)}{\text{动量项}}+\underbrace{\sum{t=1}^{C}\eta_{t}\mathbf{G}{t}\sum{j=t}^{C}\Big(\prod_{i=t+1}^{j}\beta_{i}\prod_{q=j+1}^{C}\gamma_{q}\Big)}{\text{梯度项}}.$ (8)
梯度项中的内部求和包含了第 $t$ 个 token 对最终块权重的累积影响。我们通过定义高效的后缀乘积 $\widetilde{\beta}{t},\widetilde{\gamma}{t}$ 和比率总和 $R{t}$ 来形式化这一点：
$\widetilde{\beta}{t}:=\prod{i=t+1}^{C}\beta_{i},\quad\widetilde{\gamma}{t}:=\prod{i=t+1}^{C}\gamma_{i},\quad R_{t}:=\sum_{i=t}^{C}\frac{\widetilde{\gamma}{i}}{\widetilde{\beta}{i}},$ (9)
约定 $\prod_{i=C+1}^{C}(\cdot)=1$。这些项仅依赖于标量 $\beta_{t},\gamma_{t}$，因此可以以可忽略的成本并行高效计算（例如通过对数空间累加和）。
通过恒等式 $\prod_{i=1}^{j}\beta_{i}=\big(\prod_{i=1}^{C}\beta_{i}\big)/\widetilde{\beta}_{j}$ 重写公式 (8) 中的前缀乘积，并并行展开动量递归，得出以下结果。

命题 3.1（精确的块末尾状态）。
在公式 (7) 的递归下，$\mathbf{G}{t}$ 在冻结的块起始 $\mathbf{W}{0}$ 处评估，且标量 $\eta_{t},\beta_{t},\gamma_{t}$ 独立于 $(\mathbf{W},\mathbf{M})$，则块末尾状态满足
$\mathbf{M}{C} = \widetilde{\beta}{0}\,\mathbf{M}{0}+\sum{t=1}^{C}\mathcal{K}^{M}{t}\,\mathbf{G}{t}, \quad \mathcal{K}^{M}{t} := \eta{t}\,\widetilde{\beta}{t},$ (10)
$\mathbf{W}{C} = \widetilde{\gamma}{0}\,\mathbf{W}{0}+\widetilde{\beta}{0}R{1}\,\mathbf{M}{0}+\sum{t=1}^{C}\mathcal{K}^{W}{t}\,\mathbf{G}{t}, \quad \mathcal{K}^{W}{t} := \eta{t}\,\widetilde{\beta}{t}\,R{t}.$ (11)

具有不同时间加权的两个标量核。
命题 3.1 揭示了一个关键的结构事实：块末尾权重 $\mathbf{W}{C}$ 和块末尾动量 $\mathbf{M}{C}$ 通过两个不同的标量核聚合了逐 token 的梯度 ${\mathbf{G}{t}}$。动量核 $\mathcal{K}^{M}{t}=\eta_{t}\widetilde{\beta}{t}$ 衡量了 $\mathbf{G}{t}$ 通过动量衰减 $\widetilde{\beta}{t}$ 存活到块末尾的程度。权重核 $\mathcal{K}^{W}{t}=\eta_{t}\widetilde{\beta}{t}R{t}$ 额外地通过累积权重衰减存活率 $R_{t}$ 对此进行加权，捕捉了梯度如何通过动量缓冲区和后续权重更新进行传播。在接近单位的 $\beta_{t},\gamma_{t}$ 下对 $R_{t}$ 及由此产生的核 $\mathcal{K}^{W}{t},\mathcal{K}^{M}{t}$ 的界限分析在附录 A.3 中提供。这与 LaCT [69] 形成鲜明对比，在 LaCT 中梯度项仅带有 $\eta_{t}$（没有 $\widetilde{\beta}{t}$ 或 $R{t}$），并且动量因子被折叠为块平均值，消除了聚合的时间结构（公式 5）。

为两种聚合进行一次反向传播。
计算两个聚合 $\sum_{t}\mathcal{K}^{W}{t}\mathbf{G}{t}$ 和 $\sum_{t}\mathcal{K}^{M}{t}\mathbf{G}{t}$ 天真地需要两次反向传播。我们通过注意到核仅在标量系数上不同并共享逐 token 的激活梯度 $\bm{g}{t}=-\partial\mathcal{L}{t}/\partial f_{\mathbf{W}{0}}(\bm{k}{t})$（见附录 A.4），将它们折叠为一次。这些梯度作为 LaCT 反向传播的 $C\times d$ 中间体出现，LaCT 将它们收缩为 $d\times d$ 的权重梯度。我们在两种聚合中保留它们，而不是在第一次之后丢弃它们。因此，相对于 LaCT 的边际成本是单次重新加权的聚合。算法 1 将该过程总结为命题 3.1 的直接实例化。

输出使用前一个块的权重计算，$\mathbf{O}^{[r]}=f_{\mathbf{W}^{[r-1]}}(\mathbf{Q}^{[r]})$，这与分块 TTT 一致并确保了完全并行化的前向传播。算法 1 保留了 LaCT 每块 $O(C\cdot d^{2})$ 的渐近时间复杂度，我们在附录 B.5 中从经验上证实了这一点。

通过归纳法可以得出与原始顺序递归的跨块等价性，因为 $(\mathbf{W}{C},\mathbf{M}{C})$ 正是传播到下一个块的状态；我们在 128 块轨迹（$C=512$，65,536 个 token）上进行了数值验证，其中相对于完全顺序参考的相对 $L_2$ 偏差在 $\mathbf{W}{C}$ 和 $\mathbf{M}{C}$ 上均低于 $2\times 10^{-6}$，在轨迹上累积的 FP32 舍入误差范围内。

4 E²-TTT 模型架构
我们架构的设计是由分块处理的一个特定特征驱动的：输出步骤（公式 6）将固定状态应用于整个块。这使得 TTT 路径对当前块内的即时因果历史“盲目”（即 token $\bm{x}{t}^{[r]}$ 无法通过快权重影响 $\bm{x}{t+1}^{[r]}$ 的处理）。

为了解决这个问题，我们采用了先前工作 [3, 26, 42, 69] 中经过验证的混合设计模式，将我们的 E²-TTT 模块（用于建模非局部依赖关系）与标准的滑动窗口注意力模块（用于捕捉局部依赖关系）配对，如图 2 所示。

整体架构。
E²-TTT 的宏观架构遵循标准的 Llama 设计 [59]，将 token 混合层与 SwiGLU MLP 块交替排列。
给定输入序列 $\mathbf{X}\in\mathbb{R}^{L\times d}$，我们首先将其投影为共享的查询 $\mathbf{Q}$、键 $\mathbf{K}$ 和值 $\mathbf{V}$。这些被输入到两个并行的处理分支中：一个用于局部检索的滑动窗口注意力（SWA）模块，以及一个用于长程上下文建模的 E²-TTT 层。
对于 TTT 路径，我们遵循 [28, 69]，对查询和键应用 SiLU 激活，然后进行 L2 归一化以确保训练稳定性。
同时，TTT 更新规则所需的标量由网络直接预测：学习率 $\eta_{t}$、动量 $\beta_{t}$ 和衰减强度 $\alpha_{t}$ 通过轻量级线性头直接从 $\mathbf{X}$ 投影，而最终的衰减因子 $\gamma_{t}$ 由 $\eta_{t}$ 和 $\alpha_{t}$ 导出。为了结合两个分支的互补优势，我们采用了动态混合策略 [28]：输出通过元素级插值融合，由从输入 $\mathbf{X}$ 投影的数据相关门控控制。最后，融合后的输出被归一化并通过输出投影进行处理。

图 2：E²-TTT token 混合块。SWA 和 E²-TTT 在共享的 $\mathbf{Q},\mathbf{K},\mathbf{V}$ 上并行运行，并由数据相关门控融合。TTT 更新由依赖于输入的 $\alpha,\eta,\beta$ 调制。

依赖于输入的动态。
为了允许模型在 token 级别调制其学习动态，我们将更新系数 $\eta_{t},\beta_{t},\gamma_{t}$ 参数化为输入 $\bm{x}_{t}\in\mathbb{R}^{d}$ 的函数。我们采用先前 TTT 和线性注意力文献中的标准参数化方案，以确保稳定性和有效的长期保留。
相应的线性投影仅从语言建模损失中端到端学习，没有辅助目标。
具体的基标量在附录 B.1 中详述。在经验上，性能对这些基标量在一个数量级上具有鲁棒性（附录 B.3）。

学习率 $\eta_{t}$ 调制更新幅度。我们将其参数化为由基学习率 $\eta_{\text{base}}$ 缩放的 sigmoid 门控值 [56]：
$\eta_{t}=\eta_{\text{base}}\cdot\sigma(\text{Linear}{\eta}(\bm{x}{t})).$ (12)
动量因子 $\beta_{t}$ 决定了历史梯度的持久性。为了鼓励长期记忆保留，我们使用时间尺度因子 $\tau$ [65, 57] 将动量偏向接近 $1$ 的值：
$\beta_{t}=\sigma(\text{Linear}{\beta}(\bm{x}{t}))^{\frac{1}{\tau}}.$ (13)
衰减因子 $\gamma_{t}$ 用作遗忘门。为了在更新步骤较小时防止过度正则化，我们从与学习率 $\eta_{t}$ 耦合的动态衰减强度 $\alpha_{t}$（由 $\alpha_{\text{base}}$ 缩放）导出 $\gamma_{t}$，这与标准优化实践 [39] 一致：
$\alpha_{t}=\alpha_{\text{base}}\cdot\sigma(\text{Linear}{\alpha}(\bm{x}{t})),\quad\gamma_{t}=1-\eta_{t}\alpha_{t}.$ (14)

快权重网络。
虽然我们的框架支持任何神经网络作为快权重模块 $f$，但我们使用两种标准的 MLP 配置 [56, 69] 来实例化 $f$：标准的 GELU MLP 和 SwiGLU MLP。这两种变体都包含残差连接和层归一化（LN）。
GELU MLP 变体由两个权重矩阵 $\mathbf{W}{1}$ 和 $\mathbf{W}{2}$ 参数化。输入 $\bm{x}$ 的前向变换定义为：
$f_{\mathbf{W}}(\bm{x})=\bm{x}+\text{LN}\big(\mathbf{W}{2}\,\text{GELU}(\mathbf{W}{1}\bm{x})\big).$ (15)
SwiGLU 变体采用由三个矩阵 ${\mathbf{W}{1},\mathbf{W}{2},\mathbf{W}{3}}$ 参数化的门控机制：
$f{\mathbf{W}}(\bm{x})=\bm{x}+\text{LN}\big(\mathbf{W}{3}\,(\text{SiLU}(\mathbf{W}{1}\bm{x})\odot(\mathbf{W}_{2}\bm{x}))\big).$ (16)

LaCT-Matched 在训练上下文内和附近在 S-NIAH-1 上优于其默认配置（4K 时 81.0 $\to$ 99.2），并且在 2K 时略领先于我们自己的模型，而在 S-NIAH-2 上则好坏参半（2K 时 98.6 对比 91.4，4K 时 65.8 对比 80.6）。
然而，在训练上下文之外，它在 16K 时仍然崩溃到 0.0。Chunk-averaged 隔离了设计选择本身：折叠逐 token 标量将 8K 时的 S-NIAH-1 从 95.4 降至 6.8，即仅 SWA 基线的水平，并且退化已经在训练上下文内开始（2K 时 95.6 $\to$ 25.2）。这不是训练失败：在域内，折叠的模型略微领先，LAMBADA 困惑度为 15.6 对比 15.8，零样本平均为 53.8% 对比 53.6%。
因此，我们将训练上下文内外的长上下文检索增益归因于我们表达性的分块更新规则。

6 相关工作
测试时训练（TTT）[56] 是序列建模中的一种新兴范式，它将 RNN 中的循环状态重新定义为在线自适应非线性神经网络的可学习权重。这些权重通常被称为快权重 [54]，被持续更新以在上下文中学习。现有方法通常采用自监督损失，鼓励这些快权重从上下文 token 中记忆键值关联，有效地将推理视为使用梯度下降变体的在线学习问题。虽然 TTT [56, 61] 为新型循环模型架构 [9, 30, 8, 58] 开辟了广阔的设计空间，但由此产生的顺序瓶颈导致硬件利用率低下，限制了它们的可扩展性。最近像 LaCT [69] 这样的努力试图通过从逐 token 更新转向分块更新来缓解这个问题，牺牲块内依赖建模以提高吞吐量。然而，这些方法通常求助于简化的聚合规则（例如平局平均），这降低了优化保真度。我们的工作建立在这一基础之上，但通过引入 E²-TTT（表达性且高效的 TTT）脱颖而出，该公式将分块的硬件效率与复杂、逐 token 更新动态的数学精度相调和。

将全局递归与局部注意力相结合是高效长上下文建模的成熟策略 [36, 52, 15]。遵循最近的工作 [28, 69]，我们采用了一种层内混合架构，在局部注意力和全局递归之间共享键、值和查询向量。这种设计模式已以各种形式成功部署 [26, 42, 5]。然而，先前的实例化通常依赖标准线性注意力 [31, 54, 66, 28] 或简化的 TTT 更新规则 [69]。我们的工作保留了这种既定的架构模板，但用我们的 E²-TTT 替换了递归模块，从经验上显示出更优越的结果。

7 结论
我们提出了 E²-TTT（表达性且高效的 TTT），一种将分块处理的硬件效率与测试时训练中更新规则的逐 token 表达能力相调和的方法。
通过推导闭式标量核，我们实现了逐 token 递归动态的并行执行，而没有先前分块方法的块级近似。
从经验上看，E²-TTT 在语言建模方面与强大的次二次基线相当，并在检索方面优于它们，同时表现出卓越的长度外推能力，在 8 倍训练上下文长度的“大海捞针”中保持 >90% 的密码检索准确率，而基线方法在此崩溃。这些结果表明，保留精确的时间动态对于长上下文泛化至关重要，将 E²-TTT 定位为可扩展测试时训练的一个有前途的方向。

附录 A 并行核的详细推导
在本节中，我们推导长度为 $C$ 的单个块内 TTT 更新规则的闭式展开。这个公式允许我们直接从块起始（$t=0$）“跳跃”到末尾（$t=C$），而无需具体化中间状态。为简单起见，省略了块索引 $r$。

回想一下，我们考虑具有耦合 L2 衰减和动量的一般逐 token 更新。设快权重 $\mathbf{W}{t}\in\mathbb{R}^{d\times d}$、动量 $\mathbf{M}{t}\in\mathbb{R}^{d\times d}$ 和更新方向（负梯度）$\mathbf{G}{t}\in\mathbb{R}^{d\times d}$ 为矩阵值。设 $\gamma{t},\beta_{t}\in(0,1)$ 为标量衰减和动量因子，$\eta_{t}>0$ 为学习率。递归为：
$\mathbf{M}{t}=\beta{t}\,\mathbf{M}{t-1}+\eta{t}\,\mathbf{G}{t},\qquad\mathbf{W}{t}=\gamma_{t}\,\mathbf{W}{t-1}+\mathbf{M}{t}.$ (17)

A.1 展开动量和权重
展开动量。
通过归纳，步骤 $t$ 的动量 $\mathbf{M}{t}$ 是块起始处的衰减初始动量与梯度历史的总和：
$\mathbf{M}{t}=\Big(\prod_{i=1}^{t}\beta_{i}\Big)\mathbf{M}{0}+\sum{j=1}^{t}\Big(\eta_{j}\,\mathbf{G}{j}\prod{i=j+1}^{t}\beta_{i}\Big).$ (18)
展开权重。
类似地，展开权重更新（公式 17）得出：
$\mathbf{W}{t}=\Big(\prod{i=1}^{t}\gamma_{i}\Big)\mathbf{W}{0}+\sum{j=1}^{t}\Big(\mathbf{M}{j}\prod{i=j+1}^{t}\gamma_{i}\Big).$ (19)
将（18）插入（19）并分离 $\mathbf{M}{0}$ 和梯度部分：
$\mathbf{W}{t}=\underbrace{\Big(\prod_{i=1}^{t}\gamma_{i}\Big)\mathbf{W}{0}}{\text{衰减项}}+\underbrace{\sum_{j=1}^{t}\Big(\Big(\prod_{i=1}^{j}\beta_{i}\Big)\mathbf{M}{0}\prod{q=j+1}^{t}\gamma_{q}\Big)}{\text{动量项}}+\underbrace{\sum{j=1}^{t}\sum_{k=1}^{j}\Big(\eta_{k}\mathbf{G}{k}\prod{i=k+1}^{j}\beta_{i}\prod_{q=j+1}^{t}\gamma_{q}\Big)}{\text{梯度项}}.$ (20)
重新索引梯度贡献。
通过固定梯度索引 $k$ 并对 $j=k,\dots,t$ 求和，交换（20）最后一项中的求和顺序：
$\sum{j=1}^{t}\sum_{k=1}^{j}\Big(\eta_{k}\mathbf{G}{k}\prod{i=k+1}^{j}\beta_{i}\prod_{q=j+1}^{t}\gamma_{q}\Big)=\sum_{k=1}^{t}\eta_{k}\mathbf{G}{k}\sum{j=k}^{t}\Big(\prod_{i=k+1}^{j}\beta_{i}\prod_{q=j+1}^{t}\gamma_{q}\Big).$ (21)
这将公式 20 转换为：
$\mathbf{W}{t}=\underbrace{\Big(\prod{i=1}^{t}\gamma_{i}\Big)\mathbf{W}{0}}{\text{衰减项}}+\underbrace{\sum_{j=1}^{t}\Big(\Big(\prod_{i=1}^{j}\beta_{i}\Big)\mathbf{M}{0}\prod{q=j+1}^{t}\gamma_{q}\Big)}{\text{动量项}}+\underbrace{\sum{k=1}^{t}\eta_{k}\mathbf{G}{k}\sum{j=k}^{t}\Big(\prod_{i=k+1}^{j}\beta_{i}\prod_{q=j+1}^{t}\gamma_{q}\Big)}_{\text{梯度项}}.$ (22)

A.2 每块最后一步（$t=C$）的闭式
为了高效计算最终状态 $\mathbf{W}{C}$，我们定义了三个辅助标量序列。设衰减 $\gamma$ 和动量 $\beta$ 的后缀乘积为：
$\tilde{\beta}{t}:=\prod_{i=t+1}^{C}\beta_{i},\qquad\tilde{\gamma}{t}:=\prod{i=t+1}^{C}\gamma_{i},$ (23)
（具有空乘积约定 $\prod_{C+1}^{C}(\cdot)=1$）。
我们进一步定义累积比率总和 $R_{t}$：
$R_{t}:=\sum_{i=t}^{C}\frac{\tilde{\gamma}{i}}{\tilde{\beta}{i}}.$ (24)
由于这些项仅依赖于标量 $\beta,\gamma$，它们可以高效地并行预计算（例如通过对数空间累加和）。

初始权重结转（$\mathrm{carry}{\mathrm{w}}$）。
直接从定义得出：
$\mathrm{carry}{\mathrm{w}}:=\prod_{i=1}^{C}\gamma_{i}=\tilde{\gamma}{0}$ (25)
初始动量结转（$\mathrm{carry}{\mathrm{m}}$）。
我们将前缀乘积 $\prod_{i=1}^{j}\beta_{i}$ 重写为总乘积除以后缀乘积：
$\prod_{i=1}^{j}\beta_{i}=\big(\prod_{i=1}^{C}\beta_{i}\big)\big/\tilde{\beta}{j}.$ (26)
将此代入公式 22 中的 $\mathbf{M}{0}$ 项：
$\sum_{j=1}^{C}\Big(\big(\prod_{i=1}^{j}\beta_{i}\big)\,\mathbf{M}{0}\,\tilde{\gamma}{j}\Big)=\Big(\prod_{i=1}^{C}\beta_{i}\Big)\underbrace{\sum_{j=1}^{C}\frac{\tilde{\gamma}{j}}{\tilde{\beta}{j}}}{=\,R{1}}\,\mathbf{M}{0},$ (27)
其中 $\mathrm{carry}{\mathrm{m}}:=\tilde{\beta}{0}R{1}.$ (28)
梯度贡献。
从 $t=C$ 时的（21）来看，每个 $\mathbf{G}{k}$ 都带有标量权重
$\sum{j=k}^{C}\Big(\prod_{i=k+1}^{j}\beta_{i}\prod_{q=j+1}^{C}\gamma_{q}\Big)=\tilde{\beta}{k}\sum{j=k}^{C}\frac{\tilde{\gamma}{j}}{\tilde{\beta}{j}}=\tilde{\beta}{k}R{k}.$ (29)
$\mathbf{W}{C}$ 的闭式。
结合这些项，最终权重矩阵 $\mathbf{W}{C}$ 计算为：
$\mathbf{W}{C}=\tilde{\gamma}{0}\mathbf{W}{0}\,+\,\tilde{\beta}{0}R_{1}\mathbf{M}{0}\,+\,\sum{t=1}^{C}\big(\eta_{t}\,\tilde{\beta}{t}\,R{t}\big)\,\mathbf{G}{t}.$ (30)
$\mathbf{M}{C}$ 的闭式。
动量递归与 $\mathbf{W}{t}$ 解耦，因此其闭式直接通过在 $t=C$ 时设置（18）得出：
$\mathbf{M}{C}=\Big(\prod_{i=1}^{C}\beta_{i}\Big)\mathbf{M}{0}+\sum{t=1}^{C}\Big(\eta_{t}\,\mathbf{G}{t}\prod{i=t+1}^{C}\beta_{i}\Big).$ (31)
识别（23）中定义的后缀乘积，$\tilde{\beta}{0}=\prod{i=1}^{C}\beta_{i}$ 和 $\tilde{\beta}{t}=\prod{i=t+1}^{C}\beta_{i}$，公式（31）折叠为并行核形式
$\mathbf{M}{C}=\tilde{\beta}{0}\,\mathbf{M}{0}\,+\,\sum{t=1}^{C}\big(\eta_{t}\,\tilde{\beta}{t}\big)\,\mathbf{G}{t}.$ (32)
与 $\mathbf{W}{C}$ 不同，动量核不涉及累积比率 $R{t}$：每个梯度 $\mathbf{G}{t}$ 通过单个后缀乘积 $\tilde{\beta}{t}$ 传播到块末尾，因为只有一个衰减通道（$\beta$）作用于 $\mathbf{M}_{t}$。

这个公式允许我们直接从 $t=0$ “跳跃”到 $t=C$，而无需具体化中间状态。为了确保数值稳定性，特别是在块长度 $C$ 较长的情况下，我们在对数空间中执行累积乘积计算（$\tilde{\beta},\tilde{\gamma}$），并且仅针对最终求和转换回线性空间。

A.3 累积核 $R_{t}$ 的稳定性
我们在限制我们依赖于输入的动态的实际操作范围的两种机制下分析累积核 $R_{t}$ 的幅度： 接近单位的保留（$\beta_{t}\to 1$ 和 $\gamma_{t}\to 1$），正如为长程记忆的时间尺度参数化（公式 13）所鼓励的；以及 激进的衰减（$\gamma_{t}$ 较小）。
接近单位的保留机制。
当对于所有 $t$，$\beta_{t}\to 1$ 和 $\gamma_{t}\to 1$ 时，后缀乘积满足 $\tilde{\beta}{i}\to 1$ 和 $\tilde{\gamma}{i}\to 1$，因此对于每个 $i$，$\tilde{\gamma}{i}/\tilde{\beta}{i}\to 1$。代入 $R_{t}$ 的定义得出
$R_{t}\;\to\;\sum_{i=t}^{C}1\;=\;C-t+1\;\leq\;C.$ (33)
因此，权重核 $\mathcal{K}^{W}{t}=\eta{t}\,\tilde{\beta}{t}\,R{t}$ 受限于
$\mathcal{K}^{W}{t}\;\leq\;\eta{t}\cdot 1\cdot C.$ (34)
因为 $\eta_{t}$ 是 sigmoid 门控并由 $\eta_{\text{base}}$ 缩放（公式 12），所以逐 token 的核贡献受 $\eta_{\text{base}}\cdot C$ 限制。使用我们默认的 $\eta_{\text{base}}=10^{-2}$ 和 $C=512$，这产生了最坏情况下的界限 5.12。动量核 $\mathcal{K}^{M}{t}=\eta{t}\,\tilde{\beta}{t}$ 受 $\eta{\text{base}}$ 的限制更紧。
激进衰减机制。
当 $\gamma_{t}$ 较小时，后缀乘积 $\tilde{\gamma}{i}$ 在 $i$ 中几何衰减，因此比率 $\tilde{\gamma}{i}/\tilde{\beta}{i}$ 相应衰减。总和 $R{t}$ 随后由其前几项主导，并保持 $\mathcal{O}(1)$。
耦合参数化。
衰减参数化 $\gamma_{t}=1-\eta_{t}\alpha_{t}$（公式 14）强制了一种结构耦合：大的更新（$\eta_{t}$ 大）会自动增加遗忘（$\gamma_{t}$ 更小），防止跨块的结转膨胀。此分析与第 3.2 节中报告的数值验证一致：在 128 块轨迹（$C=512$，65,536 个 token）上，相对于完全顺序参考的相对 $\ell_2$ 偏差在 $\mathbf{W}{C}$ 和 $\mathbf{M}{C}$ 上均低于 $2\times 10^{-6}$。

A.4 为两种聚合进行单次反向传播
命题 3.1 通过对逐 token 梯度 $\mathbf{G}{t}=-\nabla{\mathbf{W}}\mathcal{L}{t}\big|{\mathbf{W}{0}}$ 的求和表达了两种块末尾状态：
$\sum{t=1}^{C}\mathcal{K}^{W}{t}\,\mathbf{G}{t} \;=\;-\sum_{t=1}^{C}\mathcal{K}^{W}{t}\,\nabla{\mathbf{W}}\mathcal{L}{t}\big|{\mathbf{W}{0}},$ (35)
$\sum{t=1}^{C}\mathcal{K}^{M}{t}\,\mathbf{G}{t} \;=\;-\sum_{t=1}^{C}\mathcal{K}^{M}{t}\,\nabla{\mathbf{W}}\mathcal{L}{t}\big|{\mathbf{W}{0}},$ (36)
其中核 $\mathcal{K}^{W}{t}=\eta_{t}\,\tilde{\beta}{t}\,R{t}$ 和 $\mathcal{K}^{M}{t}=\eta{t}\,\tilde{\beta}{t}$ 仅相差标量因子 $R{t}$。
链式法则分解。
每个逐 token 损失具有 $\mathcal{L}{t}=\mathcal{L}!\left(f{\mathbf{W}{0}}(\bm{k}{t}),\bm{v}{t}\right)$ 的形式。应用链式法则，
$\nabla{\mathbf{W}}\mathcal{L}{t}\big|{\mathbf{W}{0}}\;=\;\left(\frac{\partial f{\mathbf{W}{0}}(\bm{k}{t})}{\partial\mathbf{W}}\right)^{!\top}\bm{g}{t},\qquad\bm{g}{t}\;:=\;\frac{\partial\mathcal{L}{t}}{\partial f{\mathbf{W}{0}}(\bm{k}{t})}.$ (37)
雅可比矩阵 $\left(\partial f_{\mathbf{W}{0}}(\bm{k}{t})/\partial\mathbf{W}\right)^{!\top}$ 仅依赖于 $(\mathbf{W}{0},\bm{k}{t})$，并且独立于标量核。
共享反向传播，标量重新加权。
因此，两种聚合都简化为对相同激活梯度集合 ${\bm{g}{t}}{t=1}^{C}$ 和逐 token 输入 ${\bm{k}{t}}{t=1}^{C}$ 的标量加权收缩，仅在应用于每个 token 的标量权重 $\mathcal{K}^{W}{t}$ 与 $\mathcal{K}^{M}{t}$ 上有所不同。通过逐 token 损失的单次 autograd 反向传播产生 ${\bm{g}{t}}$；然后通过以适当的标量加权重用这些中间体来构建两种聚合。因此，除了 $\mathbf{W}{C}$ 之外还产生 $\mathbf{M}_{C}$ 的边际成本是一次额外的标量加权收缩，而不是第二次反向传播。这与图 5 中报告的吞吐量测量结果一致，其中尽管计算了精确的闭式核，E²-TTT 仍保持接近 LaCT [69] 的吞吐量。

A.5 块动态的两种等效视角
在一个块内，我们公式中的所有梯度 $\mathbf{G}{t}$ 都在冻结的 $\mathbf{W}{0}$ 处评估（第 3.2 节）。
在这种约束下，命题 3.1 的闭式块末尾状态允许两种互补的解读。
优化风格视角。
公式（7）读作具有动量因子 $\beta_{t}$ 和 L2 衰减因子 $\gamma_{t}$ 的逐 token 状态递归，两者都按 token 调制。这是我们在整篇论文中采用的框架，为了与小批量和分块 TTT 文献 [56, 9, 69] 保持一致。它在跨块级别是真正具有描述性的：$\mathbf{M}{C}$ 被带入下一个块并在整个序列上累积动量。
核加权视角。
等价地，块末尾状态可以读作逐 token 梯度的标量加权聚合，
$\mathbf{W}{C}\;=\;\tilde{\gamma}{0}\mathbf{W}{0}+\tilde{\beta}{0}R{1}\mathbf{M}{0}+\sum{t=1}^{C}\mathcal{K}^{W}{t}\,\mathbf{G}{t},\qquad\mathbf{M}{C}\;=\;\tilde{\beta}{0}\mathbf{M}{0}+\sum{t=1}^{C}\mathcal{K}^{M}{t}\,\mathbf{G}{t},$
其中 $(\mathcal{K}^{W}{t},\mathcal{K}^{M}{t})$ 作为对块末尾状态的逐 token 梯度贡献的学习到的、时间感知的核权重。
这两种视角对于块末尾对 $(\mathbf{W}{C},\mathbf{M}{C})$ 在数学上是等价的。它们仅在重点上有所不同：优化风格视角是跨块边界的自然解读，其中动量被真正地结转；核加权视角是块内聚合的自然解读，其中冻结的 $\mathbf{W}_{0}$ 约束使“动量”和“衰减”与梯度贡献的学习到的逐 token 加权相一致。
