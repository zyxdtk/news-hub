8
Discussion
Static and dynamic graphs.
Our evaluation assumes the MAS communication graph is known offline and remains fixed during execution. This matches many MAS frameworks in production (§
2.1
), where the operator specifies agents and routing rules explicitly. Dynamic MAS that create and remove agents and reroute messages at runtime require an online version of
Mesa
. A natural extension is to recompute edge features as the graph adapts.
S

ecurity scope.
We instantiate edge compromise with context-aware misinformation injection. This models a realistic class of attacks (§
3.2
) and directly tests if downstream agents rely on corrupted inter-agent content. Other message-level attacks, such as prompt injection and jailbreaks, may follow the same security-critical edges, but their success also depends on model-specific behavior and prompt semantics. We therefore treat our attack pipeline as one concrete integrity threat, not as an exhaustive model of all MAS attacks. Our defense experiments use oracle interception: as long as a protected edge is attacked, the defense blocks the malicious content and restores the original message with
100
%
100\%
accuracy. This assumption is used only to isolate the allocation problem (
i.e.
, which edges should receive defense first) and not to claim a perfect deployable detector. In practice, the selected edges could be protected by LLM judges, classifiers, or other guardrails (§
6.2
).
Mesa
is compatible with these mechanisms because it decides where they should be placed. Integrating concrete detectors and measuring their precision and recall is an important next step.
Beyond agent-to-agent edges.
This work focuses on communication channels between agents. Tool calls, retrieval systems, memory stores, and external services can introduce additional attack surfaces. However, malicious content from these sources often still propagates through inter-agent messages.

结论
我们提出了
Mesa
，这是一个在攻击痕迹出现之前，根据预期安全影响对 MAS 通信边进行评分的框架。
Mesa
仅使用通信图和动态探针，无需攻击标签。我们的结果表明，MAS 中的边级别漏洞通常是集中且可预测的：一小部分通信通道可以主导攻击影响，并且该信号可以指导防御、护栏和红队测试。因此，保护 MAS 的安全不仅仅是检查单个智能体或对所有消息统一应用防御。防御者应该思考：如果被攻破，哪些通信通道最有可能改变系统结果。
Mesa
