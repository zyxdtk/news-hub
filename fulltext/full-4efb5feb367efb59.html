推出 Claude Tag

📅 2026-06-23 📄 Anthropic 🔗 原文链接

原标题：Introducing Claude Tag

中文摘要： Claude Tag 是 Anthropic 推出的团队协作新功能，首先在 Slack 上线。团队可将 Claude 作为成员加入频道，通过标记 @Claude 委托任务。它支持多人协作、持续学习、主动提醒和异步工作，可访问选定工具和数据。目前向 Enterprise 和 Team 客户开放测试版，Anthropic 内部 65% 的产品代码由其生成。

Claude Tag 是团队与 Claude 协作的新方式。

我们首先从 Slack 开始，Claude 可以作为团队成员加入。授予 Claude 访问选定频道的权限，并将其连接到你选择的工具、数据——甚至代码库。然后，频道中的任何人都可以标记 **@Claude**，将任务委托给它，同时专注于其他工作。Claude 通过记住其所在频道的相关信息来构建上下文，并可以规划未来要完成的任务。

我们将 Claude Tag 视为 Claude Code 演进的开端：它使模型更加主动，并且能更好地与整个团队协作。标记 **@Claude** 现在是 Anthropic 完成工作的主要方式之一。如今，我们产品团队 65% 的代码由内部版本的 Claude Tag 创建。同样的模式现在已扩展到工程领域之外——我们标记 Claude 来追踪产品指标和数据、处理支持工单，甚至帮助查找棘手 bug 的根本原因。

我们在 Slack 上推出 Claude Tag，因为它是团队与 AI 协作工作的天然场所，也是 Anthropic 大部分日常工作已经发生的地方。它今天以测试版形式向 Claude Enterprise 和 Team 客户开放。我们的目标是扩大其可用范围，以便团队可以在他们工作的许多其他地方标记 @Claude。

## 与 @Claude 协作

如果你之前使用过 Claude Code 或 Cowork，Claude Tag 会让你感到熟悉。用简单的语言标记 @Claude 提出请求，它会将任务分解为多个阶段，然后使用其可访问的工具依次完成。完成后，它会在 Slack 线程中回复它所创建的内容。

但标记 Claude 带来了一些新的优势：

**@Claude 是多人协作的。** 在给定的 Slack 频道中，有一个 Claude 与所有人互动。这意味着任何人都可以看到它正在做什么，并可以从上一个人中断的地方继续对话。这使得标记 Claude 与在单个聊天中或为单个任务工作非常不同——它更像与队友协作互动。

**@Claude 会随时间学习。** 随着 Claude 跟踪其频道，它会构建更多关于工作的上下文。这意味着用户不需要一遍又一遍地从零开始向它解释事情。如果获得许可，Claude 甚至可以自动从_其他_ Slack 频道和数据源中学习。（它不会从私密频道报告。）这为它提供了提供最佳工作所需的隐性知识。

**@Claude 主动出击。** 如果启用了"环境"行为，Claude 会主动向你更新它认为你可能需要知道的任何信息。它会从其所在的频道和连接的工具中标记相关信息，并跟进已经沉寂但未解决的线程或任务。

**@Claude 异步工作。** 给 Claude 设定一个任务，你可以在它工作时专注于其他优先事项。它还可以为自己安排任务，在数小时或数天内自主推进项目。我们发现这在 Anthropic 特别有帮助：我们现在将更多时间花在并行向多个 Claude 委托任务上。

你也可以向 Claude 发送直接消息：它会使用你设置的个人工具和连接器进行私密回复。

## 开始使用

我们在设计 Claude Tag 时考虑了团队和组织：@Claude 对敏感数据和特定任务工具的访问可以被非常严格地控制。

要开始使用，系统管理员需指定模型应访问哪些工具和信息，以及在哪些频道中。可以将其视为为不同用途创建独立的 Claude 身份：一切内容，包括其记忆，都将保持在管理员定义的频道范围内。例如，为销售工作设置的模型不会将记忆传递给为工程设置的模型；也不会让工程师访问任何销售数据或工具。有关配置访问的更多信息，请[参见此处](https://claude.com/blog/agent-identity-access-model)。

权限设置完成后，所有人都可以立即开始标记。管理员可以设置 token 支出限制（针对组织和个人频道），并可以查看 @Claude 所做的一切日志，以及谁请求了每个任务。

如果你是 Claude Enterprise 或 Team 客户，从今天起你可以使用 Claude Tag 的测试版。要开始使用，请[访问此处](http://claude.ai/redirect/website.v1.92318750-bbe1-474f-a4d5-8ecaeebcff78/admin-settings/claude-in-slack)并按照以下四个步骤操作：

1. 将 Claude Tag 与你的 Slack 工作区配对 2. 授予 Claude 访问你的工具的权限 3. 设置你组织的月度支出限制 4. 在私密频道中测试 Claude 以确认其正常工作。

Claude Tag 取代了现有的 [Claude in Slack](https://support.claude.com/en/articles/11506255-get-started-with-claude-in-slack) 应用。要进行迁移，管理员可以在 30 天内选择加入。我们向符合条件的 Enterprise 和 Team 组织发放 introductory [启动额度](https://support.claude.com/en/articles/15575654)，以便整个公司都可以试用。

Claude Tag 与 Opus 4.8 配合使用。你可以[阅读我们的文档](https://www.claude.com/docs/claude-tag/overview)和[产品页面](https://www.claude.com/product/tag)。
