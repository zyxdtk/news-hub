PRIMA：面向医学诊断的LLM风险整合图像-元数据对齐预训练
作者：Yiqing Wang, Chunming He, Ming-Chen Lu, Mercy Pawar, Leslie Niziol, Maria Woodward, Sina Farsiu

摘要
医学诊断需有效融合视觉表现与临床元数据。然而，现有方法常将元数据视为孤立标签，未能挖掘临床描述中蕴含的丰富语义知识。本文提出PRIMA（Pre-training with Risk-integrated Image-Metadata Alignment），一种将领域知识融入多模态表征学习的框架。我们首先通过检索增强生成（RAG）构建专家风险-疾病关联语料库，优化Clinical ModernBERT文本编码器以嵌入诊断先验知识。为弥合模态鸿沟，我们提出双编码器预训练策略，结合DINOv3与优化BERT，并采用四种互补损失函数进行优化——这些损失旨在捕捉多粒度语义对齐，并通过软标签处理临床关联的模糊性。最终，我们利用Qwen-3融合对齐特征以实现精准疾病分类。大量实验表明，PRIMA能有效融合像素级特征与抽象临床知识，显著超越现有SOTA方法；尤其值得注意的是，该框架在无需海量数据或高计算资源的情况下展现出卓越鲁棒性。代码将在录用后公开。

1 引言
图1：传统方法 vs. 本文PRIMA方法。
医学影像在临床诊断中居核心地位，专家需综合多视角扫描与补充元数据（如患者风险因素）进行诊断。尽管深度学习已取得成功，多数方法仍局限于单图分析，忽视真实临床数据的异质性，导致算法与实际诊断流程（涉及多样化影像与结构化风险谱）间存在显著差距。此外，数据稀缺仍是长期障碍：尽管近期已构建大规模医学数据集[21,10,19]，但对专科任务或罕见病（患者队列天然有限）而言，依赖海量数据往往不可行。

既往研究[13,17]探索了元数据融合，但常依赖临时设计，难以适应不同临床格式。近期转向大语言模型（LLMs）与CLIP范式[18]提供了强大表征能力，但通常数据密集且对质量敏感。即使经过医学专用适配[22,8,5]，现有方法仍严重依赖大规模预训练或细粒度文本报告，导致结构化临床元数据中丰富的语义潜力未被充分挖掘，为构建更高效、属性感知的诊断框架提供了关键机遇。

本文提出PRIMA（Pre-training with Risk-integrated Image-Metadata Alignment），旨在协同领域特定临床知识与视觉特征（图1）。为获取高质量先验，我们首先通过GPT[15]与Gemini[3]基于临床文献（利用RAG[1]）构建风险-疾病关系专用知识库；随后在该语料上微调Clinical ModernBERT[7]，避免对海量配对数据的依赖，转而利用低成本专家文献增强语义理解。为弥合模态鸿沟，双编码器预训练阶段结合DINOv3[20]与优化文本编码器；我们引入四种互补目标函数，以在多尺度上协调异构影像模态与文本知识的整合。通过融合全局上下文与细粒度局部特征，该分层对齐策略确保模型对复杂临床场景具备鲁棒适应性。最终，Qwen3[24]聚合多模态特征以实现精准诊断。在PAD-UFES-20[16]与AQUA数据集上的评估表明，PRIMA显著超越SOTA基线，且无需海量数据或高计算开销。本文贡献总结如下：
• 知识增强编码：通过在RAG生成语料上微调ClinicalBERT，将元数据提升为语义知识，显式注入领域先验，无需海量配对数据。
• 多粒度对齐：提出包含四种互补损失的灵活策略，协调跨模态的全局-局部整合，适配异构临床数据。
• LLM驱动诊断：引入统一流程，利用Qwen3聚合对齐特征，在PAD-UFES-20与AQUA数据集上实现SOTA性能与强泛化能力。

2 方法
图2展示了PRIMA的整体架构，包含三个渐进式训练阶段。首先，基于公开文献，利用GPT[15]与Gemini[3]通过RAG构建领域专用知识库，作为微调文本编码器ClinicalBERT[7]的基础，以注入医学先验（第2.1节）。其次，引入四种互补目标函数，协调多层级语义与多视角图文知识的特征对齐（第2.2节）。最后，采用大语言模型融合预训练编码器提取的鲁棒特征，实现精准诊断预测（第2.3节）。
图2：PRIMA整体流程。

2.1 语料构建与知识先验注入
尽管LLMs通用性强，但在医学场景中常因复杂知识壁垒而表现不佳。Clinical ModernBERT[7]部分缓解此问题，但仍难以捕捉细粒度属性关联与罕见病理。鉴于数据稀缺常阻碍下游微调，我们利用PubMed[11]文献增强语义理解：通过检索任务相关文章（如系统综述与病例报告），提取专家风险-疾病关系知识，使编码器无需依赖稀缺临床数据即可捕获诊断先验。
然而，临床文献常隐式呈现关联或含矛盾证据，故我们采用GPT-5.1[15]与Gemini-2.5[3]通过RAG[1]合成这些发现。RAG通过将模型响应锚定于检索源，有效缓解幻觉。如图2所示，LLMs生成结构化描述（含全局摘要及特定风险因素的详细段落），并由资深医师审核确保准确性。遵循Clinical ModernBERT协议，我们采用掩码语言建模（MLM）[4]进行知识注入。为保持计算效率，采用LoRA[6]，仅更新1%参数，保留预训练特征。

2.2 风险整合的图像-元数据对齐
图像与文本编码器
我们采用DINOv3[20]与知识增强型Clinical ModernBERT[7]作为视觉与文本主干网络。对第i位患者，输入数据包括多模态扫描{v_{i,j}}j与结构化临床元数据{t{i,k}}k。在领域先验（第2.1节）指导下，筛选视觉相关属性并拼接为序列t_i。编码器从文本提取潜在特征q_i∈ℝ^{(n+1)×d}，从每张图像提取p{i,j}∈ℝ^{(m+1)×d}，其中n,m为序列长度，d为潜在维度。两模态通过投影头映射至共享空间。此阶段仅训练投影头及DINOv3中的LoRA[6]适配器（图2）。

对齐策略
我们将p_{i,j}与q_i分解为全局类别标记（p_{i,j}^{cls}, q_{i}^{cls}）与局部序列标记（p_{i,j}^{seq}, q_{i}^{seq}），通过四种互补目标实现多粒度对齐（图3）。
• 图像一致性损失ℒ_{img}：通过采样同一患者的不同扫描或同一扫描的增强版本构建正样本对，施加独立随机增强，提取全局类别标记并计算温度缩放点积相似度（公式1），其中τ为超参数：
sim(x₁,x₂) = (x₁^⊤ x₂) / (‖x₁‖ ‖x₂‖) / τ (1)
对N位患者批次，ℒ_{img}（公式2）通过对齐同一受试者特征促进患者不变表征学习，其中𝟙为指示函数：
ℒ_{img} = -1/N ∑{i=1}^N log [ e^{sim(p{i,1}^{cls},p_{i,2}^{cls})} / ∑{k=1}^N (e^{sim(p{i,1}^{cls},p_{k,2}^{cls})} + 𝟙_{[k≠i]} e^{sim(p_{i,1}^{cls},p_{k,1}^{cls})}) ] (2)
• 全局语义损失ℒ_{glo}：采用对称交叉熵目标（公式3），在N对匹配的全局对{(p_{i,j}^{cls}, q_i^{cls})}{i=1,j=1}^{N,2}上同步视觉与文本类别标记，确保全局视觉嵌入捕获元数据编码的抽象临床概念：
ℒ{glo} = -1/(4N) ∑{i=1}^N ∑{j=1}^2 [ log(e^{sim(p_{i,j}^{cls},q_i^{cls})} / ∑{k=1}^N e^{sim(p{i,j}^{cls},q_k^{cls})}) + log(e^{sim(q_i^{cls},p_{i,j}^{cls})} / ∑{k=1}^N e^{sim(q_i^{cls},p{k,j}^{cls})}) ] (3)
• 局部语义损失ℒ_{loc}：为捕捉细粒度关联，采用注意力引导机制，为每个文本标记q_i^l（序列q_i^{seq}={q_i^l}{l=1}^L）合成视觉词表示p̂{i,j}^l。以q_i^l为查询，对所有图像块p_{i,j}^{seq}={p_{i,j}^k}{k=1}^K计算注意力权重（公式4），聚合相关图像块：
α{l,k} = exp(q_i^{l⊤} p_{i,j}^k / √d) / ∑{r=1}^K exp(q_i^{l⊤} p{i,j}^r / √d), p̂{i,j}^l = ∑{k=1}^K α_{l,k} p_{i,j}^k (4)
随后最大化q_i^l与对应视觉上下文p̂{i,j}^l的相似度，最小化其与序列中其他标记的相似度（公式5），将抽象临床属性（如不规则边界）锚定于扫描中的对应视觉表现：
ℒ{loc} = -1/(4LN) ∑{l=1}^L ∑{i=1}^N ∑{j=1}^2 [ log(e^{sim(q_i^l, p̂{i,j}^l)} / ∑{m=1}^L e^{sim(q_i^l, p̂{i,j}^m)}) + log(e^{sim(p̂{i,j}^l, q_i^l)} / ∑{m=1}^L e^{sim(p̂{i,j}^m, q_i^l)}) ] (5)
• 软语义损失ℒ_{soft}：为解决标准对比损失中严格一对一映射忽略患者间共享临床属性的局限，引入软目标对齐机制。将元数据聚合为one-hot向量y，对疾病相关维度提升3倍权重以优先保证诊断判别力。通过标签锐化构建动态目标分布：s{i,j} = Softmax(⟨y_i, y_j⟩ / τ_{label})，其中τ_{label}控制信号稀疏性。最终，模型最小化该分布与预测图像-文本相似度的软交叉熵（公式6）：
ℒ_{soft} = -1/(4N²) ∑{i=1}^N ∑{j=1}^N ∑{k=1}^2 s{i,j} [ log(e^{sim(p_{i,k}^{cls}, q_j^{cls})} / ∑{l=1}^N e^{sim(p{i,k}^{cls}, q_l^{cls})}) + log(e^{sim(q_j^{cls}, p_{i,k}^{cls})} / ∑{l=1}^N e^{sim(q_j^{cls}, p{l,k}^{cls})}) ] (6)
最终对齐损失如公式7所示，权重系数设为β₁=0.2, β₂=0.3, β₃=0.2, β₄=0.3：
ℒ_{align} = β₁ℒ_{img} + β₂ℒ_{glo} + β₃ℒ_{loc} + β₄ℒ_{soft}. (7)
特征对齐后，图像主干通过真实标签与交叉熵损失[14]进行监督精炼，以弥合通用跨模态对齐与任务特定诊断需求间的差距，增强视觉表征判别力。

2.3 基于大语言模型的特征融合
为利用LLM推理能力，我们通过多模态投影策略连接编码器与LLM主干。全局标记经MLP层投影，局部序列标记通过1D/2D卷积块进行空间/时间下采样以降低开销。这些特征与可学习特殊标记（如<|img_start|>）拼接成输入序列，其初始化为语义嵌入以加速收敛。为保持效率并防止过拟合，采用LoRA[6]，仅更新投影层及约1%参数。进一步采用词汇受限策略消除幻觉：不进行自由生成，而是仅从对应预定义临床类别的标记子集𝒞中提取logits z_k，概率通过该约束集上的Softmax计算：P(y=k|x) = exp(z_k) / ∑_{j∈𝒞} exp(z_j)。模型通过交叉熵损失[14]优化。

3 实验与结果
数据集详情
我们在两个基准上评估PRIMA：
- PAD-UFES-20[16]：含1,373名患者的2,298张皮肤病变图像（1,891个病灶），分6类：基底细胞癌（BCC）、鳞状细胞癌（SCC）、光化性角化病（ACK）、脂溢性角化病（SEK）、黑色素瘤（MEL）、痣（NEV）。
- AQUA：在IRB批准的匿名医疗中心收集的私有数据集（[匿名化以供评审]），含1,827名受试者的19,567张裂隙灯摄影（SLP）图像，聚焦细菌性与真菌性角膜炎，采用三种模态：弥散白光、弥散蓝光与硬化散射照明。
对PAD-UFES-20采用病灶级划分，对AQUA采用患者级划分；采用五折交叉验证，评估指标为F1分数、准确率（Acc）与平衡准确率（BAcc）。

实现细节
PRIMA在两块NVIDIA RTX 4090 GPU（24GB）上训练，使用AdamW与余弦调度器（10%预热）。三阶段超参数：阶段1（学习率5e-5，权重衰减1e-3，2500轮）；阶段2（3e-5，1e-3，150轮）；阶段3（1e-5，3e-2，80轮）。LoRA秩分别设为8（文本编码器）、32（图像编码器）、16（LLM）。代码将在录用后公开。

3.1 主实验结果
我们在两个数据集上将PRIMA与多个显著基线对比。为建立严谨参考，首先通过LoRA微调DINOv3[20]作为纯图像基线；随后将视觉特征与原始Clinical ModernBERT[7]嵌入通过MLP融合，评估简单多模态融合效果。此外，对比专用诊断网络：DeepIK[9]（专为角膜炎诊断设计的CNN架构）；MedKLIP[23]（提出Transformer融合模块整合多模态图文信息）；KnoBo[25]（将图像特征投影至符号概念空间以促进临床决策）；以及MedBLIP[2]与MLRG[12]（利用LLM通过多样化训练策略聚合特征）。

表1-3结果表明：尽管DINOv3提供高性能基线，PRIMA通过多粒度对齐持续实现>5%的准确率提升，证实专家先验注入在通用视觉能力不足时至关重要。PRIMA在PAD-UFES-20（F1: 73.75%, Acc: 78.27%）与AQUA（F1: 85.22%, Acc: 86.04%）上均达SOTA性能，超越所有竞品。专用方法（MedKLIP, KnoBo）在PAD-UFES-20上的性能下降凸显其迁移能力有限，而我们的整体策略更具优势。尽管LLM基线（MedBLIP, MLRG）表现强劲，我们优化的训练与知识注入仍带来更优特征融合。虽PAD-UFES-20元数据可能部分存在于基础模型预训练语料中，我们通过仅在离线知识提取中使用LLM、避免与患者数据交互来缓解此问题。关键的是，PRIMA在完全无法访问基础模型的私有AQUA数据集上取得显著增益，验证了性能提升源于所提对齐策略而非数据记忆。

3.2 消融研究
消融结果（表3）验证了各组件的作用。尽管LLMs具备固有表征能力，但在有限医学监督下表现不佳（仅用类别标签训练时性能下降）。引入图像一致性损失（ℒ_{img}）提升视觉鲁棒性，但未解决跨模态对齐。全局语义损失（ℒ_{glo}）提供关键高层同步，局部语义损失（ℒ_{loc}）建立图像局部区域与文本标记的细粒度对应。软语义损失（ℒ_{soft}）利用临床元数据在特征聚合中纳入复杂关系。最后，注入领域特定先验显著增强模型对临床细微差别的把握，其协同作用实现PRIMA最优性能。为验证设计，我们评估了简化变体：移除ℒ_{loc}中的注意力机制（记为ℒ_{loc_dir}），以及将ℒ_{soft}限制为基本类别标签（记为ℒ_{sup_con}）。性能下降凸显了我们多粒度与元数据感知设计的必要性。

4 结论
我们提出PRIMA，将经专家医学语料库预训练的Clinical ModernBERT与DINOv3结合，对齐诊断先验与鲁棒视觉表征。四种多粒度损失同步各组件以捕获精确临床对应关系。通过Qwen-3协调最终多模态融合，PRIMA在无需海量计算的情况下实现SOTA准确率与高效率。我们承认两项局限：需进行主干网络控制实验以分离对齐增益与编码器强度影响；以及相似规模LLMs可能存在的生成偏见。这些将在后续期刊扩展中解决。
