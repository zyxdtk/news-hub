摘要

自回归图像生成近来已成为一种具有竞争力的视觉生成范式，但其生成顺序往往是预定义或启发式的，例如下一图块预测、随机顺序预测或特定尺度的一步生成。我们观察到，这些策略可能使模型忽略图像中重要的结构依赖，从而同时限制了结构鲁棒性与推理能力。在本工作中，我们提出一种上下文感知的自回归生成框架，模型基于全局上下文与当前局部信息动态决定下一个 token 的位置。我们的方法不遵循固定或随机顺序，而是让生成过程自适应于图像结构与语义依赖。大量实验表明，上下文感知生成在不同的图像 AR 范式（包括掩码自回归与尺度级自回归模型）上均显著提升了结构鲁棒性。除定量改进外，我们还观察到涌现的推理特性：模型能更好地理解复杂的语义指令，并生成更忠实遵循给定引导的图像。这些发现表明，生成顺序是图像自回归建模中一个关键却未被充分探索的因素，而上下文感知解码可以解锁更强的推理感知视觉生成能力。

代码可在 https://github.com/Hpesojyjx/Saccades-AR 获取。

1 引言

受自然语言处理中下一 token 预测成功的启发，近年来对自回归（AR）图像生成的兴趣日益增长。早期工作通过将 2D 图像、像素或离散视觉 token 展平为 1D 序列，并使用标准自回归 Transformer 按光栅或其他固定 token 顺序建模，直接将语言建模配方迁移到视觉生成（Chen et al., 2020; Ramesh et al., 2021; Esser et al., 2021; Yu et al., 2022; Sun et al., 2024）。虽然这种直接迁移概念简单且可扩展，但与图像的空间性质并不完全契合。与文本不同——文本的生成顺序通常遵循自然的语言推进——图像包含密集的 2D 结构与长程空间依赖，并不天然符合单一的从左到右序列。因此，固定顺序的 AR 生成容易未充分利用重要的结构线索，导致可见的伪影，例如逐行或逐列错位、物体布局扭曲以及全局一致性减弱。为缓解这些局限，后续工作探索了更灵活的生成方案，包括预测随机掩码 token 或迭代细化 token 集合的掩码生成建模（Chang et al., 2022; Chang et al., 2023; Li et al., 2023; Li et al., 2024c; Kim et al., 2025b），以及从粗到细分辨率逐步预测视觉 token 的尺度级自回归生成（Tian et al., 2024b; Ma et al., 2024; Han et al., 2025b），这些方法降低了光栅解码的刚性，提升了视觉保真度与结构稳定性。

图 1： 生成顺序塑造了自回归图像生成中类似推理的行为。在随机顺序解码（上）下，中间预测保持分散且不完整，削弱了用于计数的反馈（例如"四个花瓶"），并常导致过度生成。在上下文感知的位置选择（下）下，相同的模型与种子往往更连贯地完成物体（大致逐个完成），并在数量满足后停止添加新物体。

尽管如此，虽然随机顺序与尺度级生成缓解了结构失真，但图块级生成背后的推理逻辑在很大程度上被忽视。例如，当人类逐图块绘制图像时，通常可以基于已有上下文决定下一步在哪里绘制。这使他们能够建立更连贯的空间组织，并对部分完成的内容进行渐进推理。相比之下，掩码 AR 模型以随机顺序生成图块，而尺度级 AR 模型一步生成给定空间尺度内的所有 token。这两种策略都容易错过重要的中间推理过程。我们在图 1 中用一个直观例子说明这一问题，其中模型被要求生成四个花瓶。在案例 2 中，当模型被允许根据上下文确定下一个预测位置时，可以观察到涌现的推理行为：模型以有组织的方式、大致逐个地生成花瓶，并在生成过程中获得自我反馈。例如，在第 22 步之前，它已生成三个花瓶；在接下来的步骤中，模型似乎意识到还缺一个花瓶，并在第 25 步完成了第四个花瓶；在满足所需数量后，其余步骤主要用于填充背景。相比之下，在案例 1 中，随机顺序 AR 模型在每一步随机选择预测位置，导致大多数物体在中间生成过程中保持不完整，使模型难以获得关于物体数量的可靠反馈。因此，它不断生成新的类似花瓶的区域，无法与所需数量对齐。

受此观察启发，我们提出 Saccade AR（SAR）^1，一种简单却出奇有效的 AR 图像生成上下文感知解码策略。具体而言，在每个解码步骤，AR 模型通常为所有可编辑 token 位置产生候选预测，随后现有方法按照随机、预定义或尺度级的时间表提交 token。与此不同，SAR 根据候选 token 位置与全局上下文的语义相关性对其进行排序。具体来说，我们度量每个候选 token 表示与全局条件信号（如类条件生成中的类 token，或文生图中的文本嵌入）之间的距离，并按从语义接近到语义遥远的顺序确定优先级。这样，SAR 首先生成与全局意图强相关的区域，然后填充不太关键的细节。SAR 免训练、轻量且适用广泛：它可以在推理时插入预训练 AR 图像模型而无需更改模型参数，且几乎不引入额外计算，因为它只是重新排序提交哪些候选预测。此外，SAR 适用于不同的 AR 范式，包括掩码自回归模型（MAR（Li et al., 2024c））与尺度级自回归模型（VAR（Tian et al., 2024b））。重要的是，SAR 不改变模型架构或监督方式；它改变的是生成轨迹。我们的核心论点是这一轨迹至关重要：当模型以上下文感知的顺序生成时，它能更好地利用中间视觉反馈，并表现出更强的结构鲁棒性与推理相关的指令遵循。

^1 我们将该方法命名为 Saccade AR，因为它受人类视觉系统中扫视眼动的启发——人类视觉系统在解读视觉场景时会基于上下文主动选择注视位置。

大量实验验证了这一假设。在 GenEval（Ghosh et al., 2023）与 DPG-Bench（Hu et al., 2024）等文生图基准上，SAR 持续改进预训练 AR 生成器，包括 MaskGen（Kim et al., 2025b）与 Infinity（Han et al., 2025b），在计数、相对定位与组合指令遵循等推理相关维度上收益尤为明显。为进一步评估推理能力，我们构建了一个涉及物体数量、空间关系与细粒度属性分配复杂组合的长提示文生图基准。在该基准上，SAR 带来了更大的改进，支持我们的主张：生成顺序是现有 AR 图像模型推理局限背后的关键因素。

2 相关工作

语言与多模态生成中的自回归模型。 大型语言模型（LLM）（Brown et al., 2020; Touvron et al., 2023a; Touvron et al., 2023b; Gemini Team, Google, 2023; OpenAI, 2024; Yang et al., 2024）的最新进展使自回归（AR）模型成为现代生成建模的核心，因为它们灵活且广泛用于从先前 token 预测下一个 token。AR 模型最初为文本开发，如今也广泛用于视觉生成（Chen et al., 2020; Esser et al., 2021; Sun et al., 2024; Tian et al., 2024a; Li et al., 2024b），其中每张图像被视为离散 token 序列。同一思想进一步催生了同时处理多模态理解与生成的统一视觉-语言模型，如 Emu3（Emu3 Team, BAAI, 2024）、LaVIT（Jin et al., 2023）与 VILA-U（Wu et al., 2024）。在这些模型中，一个共享的 AR 主干读写混合的文本与图像 token。

光栅扫描 token 顺序的自回归图像生成。 AR 视觉建模的早期研究采用语言模型架构逐像素生成图像（Chen et al., 2020）。在图像分词器（Van Den Oord et al., 2017; Esser et al., 2021）的帮助下，后来的 AR 模型以下一 token 的方式生成离散 token 序列，将每张图像展平为 1D 序列并由仅解码器 Transformer 预测，类似于语言建模。该流程已被扩展到大规模文本条件生成，如 DALL-E（Ramesh et al., 2021）、CogView（Ding et al., 2021; Ding et al., 2022）、Make-A-Scene（Gafni et al., 2022）、Parti（Yu et al., 2022）、LlamaGen（Sun et al., 2024）与 Lumina-mGPT（Liu et al., 2024），并并行扩展到文生视频模型如 VideoPoet（Kondratyuk et al., 2023）。然而，这些方法以光栅扫描顺序生成图像 token，未能充分利用自然图像的 2D 结构，导致结构伪影与复杂语义指令下的一致性减弱。

改进自回归图像合成的生成顺序。 在光栅扫描生成之外，近期工作探索了两个互补方向。基于掩码的方法以非固定顺序每步预测多个 token：MaskGIT（Chang et al., 2022）每步联合预测一组 token，降低推理成本；Muse（Chang et al., 2023）将该思想扩展到文生图；MAGE（Li et al., 2023）在同一掩码 token 目标下统一表示学习与合成；MAR（Li et al., 2024b）通过小型扩散头将掩码预测引入连续值 token，取代离散码本；MaskGen（Kim et al., 2025a）将图像压缩为紧凑的 1D token 用于掩码文生图。基于尺度的方法用粗到细的尺度轴替代空间轴：VAR（Tian et al., 2024a）跨尺度求和预测，使推理步数等于尺度数，后续工作包括 STAR（Ma et al., 2024）与 Infinity（Han et al., 2025a）。虽然这两个方向都缓解了光栅扫描的刚性，但所得顺序仍然是先验固定的（预定的尺度时间表，如 VAR）或随机确定的（随机或基于置信度的去掩码，如 MaskGIT 与 MAR）——尚无方法基于已生成的语义上下文动态选择下一步。这激发了我们的上下文感知生成顺序：模型自身决定下一步关注与生成的位置，类似于人类视觉系统的扫视行为。

3 方法

图 2： 与一步生成及随机顺序生成范式的比较。我们的 SAR 模型基于每个 token 与全局 token 的潜在距离决定生成顺序。这对图像 AR 模型而言只是一个极小的改动，但我们发现它对 AR 模型的推理行为至关重要。

3.1 图像自回归模型

现代图像自回归模型按生成单元可分为两个家族。图块级模型将图像分词为空间（或 1D 压缩）潜在 token 的扁平序列，并一次预测一个或数个。尺度级模型以逐渐更细的分辨率预测图像，生成粗到细的 token 金字塔。下面分别描述图块级与尺度级的公式，然后说明 SAR 如何与之适配。

图块级掩码自回归模型。 我们采用掩码自回归（MAR）公式（Li et al., 2024b），将图像 x 编码为 N 个连续潜在 token z = {z_i}_{i=1}^{N}，并将条件分布按生成顺序 π 分解：

p_θ(z|c) = ∏{t=1}^{T} p_θ(z{S_t} | z_{S_<t}, c)， (1)

其中 c 为条件信号，{S_t}{t=1}^{T} 按 π 划分 token 索引。在第 t 步，模型在给定 z{S_<t} 的条件下并行预测 S_t，按上述余弦时间表去掩码 |S_t| 个 token。每个逐 token 条件由 MAE 风格的 Transformer 解码器与轻量级去噪扩散头实现，推理时我们在 AR 步骤间应用带线性时间表的无分类器引导（CFG）。

尺度级自回归模型。 我们还考虑 VAR（Tian et al., 2024a）与 Infinity（Han et al., 2025a）中的尺度级 AR，生成粗到细的金字塔 z = {z^(k)}_{k=1}^{K}（尺度 k 处有 N_k 个 token）：

p_θ(z|c) = ∏_{k=1}^{K} p_θ(z^(k) | z^(<k), c)， (2)

在尺度 k，模型以较粗尺度 z^(<k) 与 c 为条件预测下一层更细的 token，逐步细化细节。不同模型的实例化有所差异：VAR 使用离散的下一尺度 token，而 Infinity 使用多尺度残差分词器预测比特。

3.2 Saccade 自回归生成

公式 1 中的顺序 π 通常是固定的（如光栅/之字形）或均匀随机采样的（Li et al., 2024b），二者均未利用图像的空间语义。受人类扫视启发，我们在推理时自适应地选择顺序，先生成与条件最相关的 token，其显著性由模型而非手工设计的扫描决定。设 h_i^(t) ∈ ℝ^d 表示在掩码位置 i ∈ M_t 与 AR 步骤 t 处用于排序的模型特定候选表示。设 A^(t) ⊂ ℝ^d 为同一嵌入空间中的条件锚点：在任何图像 token 生成之前可见的条件 token（类条件用类 token，文本条件用提示 token）。模型特定细节见第 4 节。由于生成流程在每一步为所有掩码位置产生候选表示，我们可以即时对位置排序。我们以每个仍被掩码的位置与锚点的平均余弦相似度对其评分：

s_i^(t) = (1/|A^(t)|) Σ_{a∈A^(t)} ⟨h_i^(t), a⟩ / (‖h_i^(t)‖ ‖a‖)，i ∈ M_t， (3)

然后去掩码得分最高的前 |S_t| 个位置（余弦时间表与公式 1 相同）。每步重新计算 h^(t) 可得到自适应的、依赖上下文的顺序。SAR 仅改变推理时的排序，且每个（掩码 token、锚点、步骤）只增加一次相似度计算。

MAR 特征选择。 对 MAR 而言，位置选择在逐 token 扩散去噪之后执行，而非直接在确定性的掩码预测特征上进行。每一步，模型先从当前可见上下文为未解析位置产生候选，再采样去噪后的候选 token，然后 SAR 才选择提交哪些位置。扩散采样引入依赖随机种子的变化，因此给定类条件下首个被选位置不必固定。每次提交后，更新后的部分图像为下一轮候选生成与排序提供条件。

面向尺度级生成的 SAR。 尺度级 AR（公式 2）一次性生成某尺度的全部 N_k 个 token，因此不存在尺度内顺序。我们通过仅在最终尺度 K 上以 M > 1 步解码（尺度 1…K−1 保持不变）来引入顺序，因为最后一个尺度空间分辨率最高、包含大部分细节。我们将 N_K 个最终尺度位置划分为 M 个相等的组，每步提交一组。在第 m 步，已提交位置使用其解码后的嵌入，其余位置保持来自尺度 1…K−1 的粗特征；一次非因果前向传播为所有未提交位置产生新的隐藏状态 h_i^(m)。我们按与锚点 a 的平方 L2 距离对位置排序：

s_i^(m) = ‖h_i^(m) − a‖₂²， (4)

并提交得分最小的 N_K/M 个位置。我们复用模型已有的条件嵌入作为 a（类嵌入 c_class 或池化文本嵌入 c_pool），只需计算一次并在各步间保持固定，因此几乎不增加额外开销。

总体而言，尺度级 SAR 是在 M 步最终尺度解码之上的推理时重排序；它无需参数更新，且每步每个未提交位置只增加一次相似度计算。我们在 VAR（Tian et al., 2024a）（类条件；附录 B）与 Infinity（Han et al., 2025a）（文生图；第 4.2 节）上进行了实例化。表 7 在共享检查点上比较了推理时顺序。另外，表 8 研究了在最终尺度使用 SAR 顺序重训练的 VAR，并在不同推理顺序下评估。

4 实验

本节在图块级与尺度级 AR 上评估 SAR。第 4.1 节定性可视化随机与 SAR 下每个 AR 步骤的中间解码图像；第 4.2 节报告在 MaskGen 与 Infinity 上的主要文生图结果，涵盖 GenEval、DPG-Bench、MJHQ-30K FID 以及我们构建的复杂长提示推理基准（第 4.2.1 节）；第 4.3 节给出关于替代顺序与 VAR 重训练的消融实验。附录 B 还提供了 MAR 与 VAR 在类条件 ImageNet 上的结果。

4.1 定性分析

在定量结果之前，我们先通过可视化（固定检查点与提示）建立对 SAR 如何起作用的直觉。每个 AR 家族使用一个代表性模型：Infinity-8B（尺度级）与 MaskGen-XL（图块级）。实现细节见第 4.2 节。两者通过不同的推理行为实现 SAR 的改进，但收敛于相同的效果。

Infinity：先轮廓，后细节。 在 Infinity-8B（图 3）上，SAR 在前几个最终尺度步骤内即提交符合提示的全局轮廓（数量、物体身份与整体几何），后续步骤仅用于填充纹理。随机排序则在任何轮廓建立之前就散布部分纹理，且往往到最终步骤也无法恢复这些结构决策。

MaskGen：一次一个物体。 在 MaskGen-XL（图 4）上，SAR 则一次提交一个完整物体，只有前一个物体完成后才开始下一个；计数、空间关系与组合层次都源于这种顺序提交。随机排序同时生长所有部分，只在最后几步才确定身份与布局。

两个家族通过互补机制（轮廓到细节 vs 逐物体）实现 SAR，但在两种情形下，SAR 基于提示的排序都将 AR 解码转化为一系列清晰、与提示对齐的提交，而非半成形概念的杂烩。这种隐式视觉规划免费涌现，第 4.2 节与附录 B 中全部 8 个模型的定量结果证实，这种行为变化转化为一致的基准收益。

图 3： Infinity-8B：SAR 下的"轮廓到细节"推理。 每个条带中，顶行为随机排序，底行为 SAR；各列为 AR 步骤。在前几个 SAR 步骤内，全局轮廓已编码正确的数量（四支蜡烛、六盆绿植）、正确的物体集合且无幻觉多余物体（狐狸+兔子），以及正确的全局几何（圆形披萨）。后续步骤填充纹理而不改变这些结构决策。随机排序则在各处生长部分纹理，且常常到最终步骤仍无法恢复数量、身份或形状。

图 4： MaskGen-XL：SAR 下的"逐物体"推理。 从上到下："四个花瓶"、"一个孩子走在成年人右侧，沿着安静的街道"、"厨房台面上一个插着彩色蜡烛的生日蛋糕"。SAR 在开始下一个物体前先完成当前物体（计数），先提交一个实体再引入另一个（空间关系），并遵循场景→主体→部件的顺序（组合层次）；随机排序同时生长所有内容，只在最后几步才确定身份与布局。

4.2 文生图

设置。 我们在两个 AR 家族上评估文生图 SAR，它们覆盖了文献中的主流设计选择：MaskGen（Kim et al., 2025a）（图块级；MaskGen-L 与 MaskGen-XL）与 Infinity（Han et al., 2025a）（尺度级；Infinity-2B 与 Infinity-8B）。MaskGen 将 SAR 锚点取为单例 {W c_pool}，其中 W 是 MaskGen 已用于注入池化文本条件的同一线性投影；Infinity 将 SAR 锚点取为 a = c_pool，即 AdaLN 已使用的注意力池化文本嵌入。MaskGen 使用 T = 32 个 AR 步骤，Infinity 在最终尺度使用 M = 16 个相等分组。其余实现细节均遵循原始配方，列于附录 A。

评估。 我们使用三个互补基准：GenEval（Ghosh et al., 2023）评估组合能力，每提示采样 4 张并采用提示级通过标准；DPG-Bench（Hu et al., 2024）评估细粒度提示对齐，由 mPLUG-VQA 评估器在 2×2 图像网格上打分；MJHQ-30K FID（Li et al., 2024a）在 30K 提示子集上评估分布级美学质量。遵循原始 Infinity 协议，GenEval 在 Infinity 上使用提示重写；其余设置均使用原始提示。三项均对 3 个随机种子取平均。

结果。 表 2 与表 3 表明，仅推理阶段的 SAR 改动即可在两种范式的各个规模上提升组合能力。在 GenEval 上，总体通过率持续上升，在需要全局一致性的子类别（如计数、颜色与位置）上收益最大。在 DPG-Bench 上，各类别 L1 细分表现不一，但总体分数在各个规模上同样提升。在 MJHQ-30K FID（表 4）上，SAR 在所有规模上与随机顺序统计持平，说明组合能力的提升并未以牺牲分布级美学质量为代价。这些结果共同表明，单一的推理时干预可泛化到图块级与尺度级文生图 AR。针对尺度级设置，附录 C 进一步研究了 VAR 的 SAR 顺序最终尺度重训练，并在所得检查点上比较推理顺序。

推理开销与等预算比较。 我们在单块 NVIDIA H100 80GB GPU 上以 BF16、批大小 1 测量 VAR 端到端生成延迟。经过 20 次预热生成后，对 1,000 张 ImageNet 图像计时，包含 VAE 解码但不包括模型加载与图像保存。Random 与 SAR 使用同一重训练检查点与相同的四步最终尺度解码，仅位置选择不同。附录 D 的表 9 报告了平均延迟与总体标准差及生成质量。在全部四个 VAR 规模上，Random 与 SAR 在所报告精度下平均延迟相同，尽管其时间波动性可能不同。这表明在该设置下 SAR 的排序没有可测量的额外开销，而非零计算成本。相对一步解码的耗时增加来自共享的多步最终尺度流程；等预算的四步比较则分离出排序规则本身的影响。

5 结论

我们提出了 SAR，一种上下文感知的生成顺序：在每个 AR 步骤，按仍未提交位置与提示派生锚点（基础模型本身已维护的条件嵌入）的相似度进行排序，并优先提交最相关的位置；SAR 不引入新参数，纯在推理阶段运行。在覆盖两种 AR 范式（MAR、MaskGen、VAR、Infinity）的 8 个检查点、四个标准基准以及我们的复杂长提示基准上，SAR 持续提升提示对齐与组合推理，同时保持分布级美学质量，并在定性上引发两种互补的推理行为：尺度级模型中的"先轮廓"解码与图块级模型中的"逐物体"解码。这种隐式视觉规划从模型自身表示中免费涌现的事实表明，生成顺序是 AR 图像建模中一个关键且未被充分探索的轴，更丰富的锚点以及与美学感知准则的结合是进一步提升的自然方向。

A.1 文生图（第 4.2 节）

MaskGen。 我们使用公开的 MaskGen-L 与 MaskGen-XL 检查点（Kim et al., 2025a），二者均基于 TATiTok 1D 图像分词器的 KL 变体构建，将图像压缩为 N = 32 个连续潜在 token。冻结的 CLIP ViT-L/14-336 文本编码器产生逐 token 文本特征序列与池化嵌入 c_pool；用于构造 SAR 锚点的线性投影 W 正是 MaskGen 已用于向其解码器注入池化文本条件的同一投影。我们采用 T = 32 个 AR 步骤、CFG 强度 3.0（线性时间表）与美学微条件分数 6.5 进行采样，与原始 MaskGen 配方一致。

Infinity。 我们使用 Infinity-2B 与 Infinity-8B（Han et al., 2025a），二者均基于 BSQ-VAE 分词器构建，在 1024×1024 分辨率下具有 K = 13 个粗到细尺度；仅最终尺度就包含 4096 个空间位置，占 token 预算的绝大部分。冻结的 FLAN-T5-XL 文本编码器产生供交叉注意力使用的逐 token 特征序列与用于 AdaLN 调制的可学习注意力池化嵌入 c_pool。我们仅在最终尺度进行多步推理，M = 16 个相等分组，尺度 1 至 K−1 保持不变。CFG 对 Infinity-2B 为 4.0、对 Infinity-8B 为 3.0，采样温度 τ = 1，与原始 Infinity 配方一致。

A.2 类条件生成（附录 B）

MAR。 我们使用 MAR-Base（208M）与 MAR-Large（479M）（Li et al., 2024b）。图像由 KL 正则化的 2D VAE 编码为 N = 256 个维度为 16 的连续空间 token，类标签作为类 token 嵌入缓冲区前置到解码器输入。我们采用 T = 256 个 AR 步骤、逐 token 扩散头内 100 步扩散采样，以及带线性时间表的 CFG（MAR-Base 的 CFG 强度为 2.9，MAR-Large 为 3.0），均与原始 MAR 配方一致。

VAR。 我们使用 VAR-d16（310M）与 VAR-d20（600M）（Tian et al., 2024a）。每张图像由多尺度残差 VQ 分词器编码为 K = 10 个 token 图组成的粗到细金字塔，最终分辨率 16×16，输出 256×256；类标签作为类嵌入 c_class = ClassEmb(y) 注入，驱动 AdaLN 调制。我们以 M = 4 个相等分组进行最终尺度多步推理，尺度 1 至 K−1 保持不变，并采用原始 VAR 配方的 CFG 时间表与采样温度。
