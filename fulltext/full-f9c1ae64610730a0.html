摘要
用户越来越多地转向大语言模型（LLM）寻求情感支持，然而关于这些模型实际上是如何进行心理治疗互动的，我们知之甚少。
我们引入了一个包含十种治疗“动作”的本体论：
这些是基于 MULTI-60 量表的紧凑、功能化分类，通过五名持证心理学家的标注活动进行了验证，并使用一种与专家一致性相匹配的评判方法进行了规模化扩展。
将其应用于真实的咨询记录和模型主导的会话中，我们比较了人类临床医生与一系列前沿模型之间的动作分布。
模型过度使用“询问”，频率高达人类的三倍，忽视了“心理教育”，并且具有强烈的“上下文锚定”倾向：它们会延续由人类临床医生发起的策略，但很少自己主动发起这些策略。
将该本体论作为一组工具暴露给模型，大致将模型与人类动作分布的平均偏差减半，并在无需任何微调的情况下，将轮次级别上与人类治疗师的对齐度提高了 7-9 个百分点。

2.1
心理治疗编码
心理治疗过程研究长期以来将临床医生的语言视为一系列可观察的动作。早期的微咨询工作将访谈分解为可训练的行为，如关注和提问
(
Ivey et al., 1968
)
。
Hill 的咨询师言语反应类别系统同样将咨询师的反应编码为相互排斥的类别，后来被组织为探索、洞察和行动的助人阶段
(
Hill, 1978
;
Hill, 2014b
)
。
相关的反应模式分类法对话语的作用进行了分类——例如，提问、反映、解释或建议——而不是其主题
(
Stiles, 1979
;
Elliott et al., 1987
)
。
这些传统提供了有用的轮次局部描述，但它们的清单和单元化规则主要是为人类培训和过程研究设计的。
例如，认知治疗评定量表评估认知治疗的能力
(
Young and Beck, 1980
)
，而动机访谈技能编码和动机访谈治疗完整性编码则用于编码对动机访谈的依从性
(
Miller et al., 2003b
;
Moyers et al., 2016
)
。
这些工具提供了临床特定的区分，但它们的标签不能直接跨治疗模式应用。
多理论治疗干预措施列表（MULTI）是为了弥合这一分歧而开发的。MULTI-60 使用 60 个减少行话的项目来描述治疗师的行为，这些项目分为八个取向：心理动力学、过程-体验、认知、人际、行为、辩证行为、以人为中心和共同因素
(
McCarthy and Barber, 2009
;
Graham et al., 2020
)
。
重要的是，MULTI 是对干预措施的描述性测量，而不是对依从性或能力的测量，其标准形式总结了每个项目在会话中的特征程度。
先前的工作将 MULTI 改编为对话轮次分类，说明了它作为跨理论词汇的价值，以及在轮次级别密集应用面向会话的清单的困难
(
Mehta et al., 2022
)
。
我们的工作直接在 MULTI 的基础上，进一步将项目过滤和分组为一个紧凑的本体论，使其在处理 LLM 时更具适用性。

3
本体论
我们遵循相同的综合目标，但引入了进一步的抽象层次，用于模型开发和分析。
我们的本体论将每个治疗师轮次映射到十种动作中的一种或多种：紧凑的、基于功能的类别，旨在与局部语言环境区分开来。
该清单借鉴了上述的咨询技能和反应模式传统。
每个动作都建立在一个或多个 MULTI-60 项目之上（表
1
），提供了重要的临床可追溯性。
三个设计选择使该本体论适用于记录标注和 LLM 分类。
首先，编码遵循治疗功能而不是语法（例如，一个测试僵化信念的问题被标记为面质，而不仅仅是询问）
其次，标签是多标签的，因为一个轮次可能既反映了患者的经历，同时又要求澄清。
第三，本体论指南为经常混淆的对指定了对比边界，包括询问与面质、共享理解与解释，以及行动计划与会话内技能构建。
我们还额外使用 no_defined_move 作为用于行政、社交或程序性轮次的互斥控制标签。

7
结论
我们引入了一个基于 MULTI-60 的十种治疗动作的本体论，由五名持证心理学家进行了验证，并用它来表征 LLM 相对于人类临床医生如何进行心理治疗。
差异是系统性的：模型过度询问，忽视心理教育，并且具有强烈的上下文锚定性，维持人类发起的策略，但在主导会话时很少发起策略。将动作定义为工具将模型与人类动作分布的平均偏差减半，并将轮次级别的对齐度提高了 7-9 个百分点，无需任何微调。除了引导之外，该本体论还为临床医生和开发人员提供了一个共享的、可审计的词汇表，用于指定和评估 LLM 中的治疗行为。未来的工作应针对模型仍然避免的动作，将分析扩展到 CBT 相关模式之外，并将动作特征与临床结果联系起来。
局限性
在解释结果时，应考虑我们研究的一些局限性。
首先，人类和模型环境之间存在模式不匹配。人类参考数据（Alexander Street 记录）源自转录的口语治疗会话。在这些真实世界的环境中，治疗师可以获得严重影响其治疗动作选择的非语言信号。相比之下，我们研究中的 LLM 严格以基于文本的格式运行。这种约束改变了对话的自然节奏，并可能解释了我们观察到的一些分布差异。
其次，我们的 LLM 主导实验（§
4.2
）依赖 LLM 来扮演患者。虽然这将治疗师模型与人类上下文前缀隔离开来，但模拟患者无法完全复制寻求治疗的真实人物。
最后，我们对本体论的人类验证仅产生了中等的标注者间一致性，这突出了编码心理治疗对话的固有主观性，并给我们的分析带来了噪声。
伦理考量
这项工作研究 LLM 在安全关键领域的行为；它并不提倡将 LLM 部署为持证临床医生的替代品。我们的本体论是一种描述性工具：更紧密地匹配人类动作分布并不能证明临床能力或安全性，我们告诫不要将动作框架解释为现实世界治疗使用的充分基础。危机管理和安全关键行为超出了我们的分析范围。
