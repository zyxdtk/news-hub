摘要
自主科学发现系统越来越多地使用大型语言模型（LLM）来提出新假设，但许多此类系统主要以实验记忆为条件：高分候选者的档案或近期试验的启发式摘要。我们认为，发现代理应该转而对假设质量保持显式的、具有不确定性意识的信念。我们引入了 BayesEvolve，这是一个信念引导的发现框架，它将实验证据转化为预测性信念状态，并利用该信念来指导未来的实验。作为信念引导发现的控制测试平台，我们在偏移的 BBOB 风格黑盒优化任务上评估了 BayesEvolve，将程序和实验室发现领域留待未来工作。在固定的评估预算下，BayesEvolve 比基于记忆和档案引导的 LLM 基线提高了样本效率。我们进一步表明，该信念状态对留出的候选池具有预测性，受控的决策规则消融实验支持带有退火不确定性奖励的信念引导选择，并且 BayesEvolve 表现出富有成效的后期集中，而不是无重点的探索。

1 引言
LLM 引导的进化搜索已成为自动优化和发现的一个引人注目的范式。FunSearch (Romera-Paredes et al., 2024) 证明了对 LLM 生成的程序进行进化选择可以恢复新颖的组合结果；AlphaEvolve (Novikov et al., 2025) 将类似的想法扩展到更大的代码库和优化任务。尽管取得了这些成功，但许多系统主要将实验历史用作记忆：LLM 被提示以从先前评估的候选档案中采样的示例，通常偏向于高分示例。

这种档案引导的设计将大部分证据留在了隐式形式中。过去的实验列表说明了发生了什么，但它没有明确编码代理当前对未评估假设的信念、这些信念的不确定性程度，或者哪个实验将提供最多信息。随之而来的是两个代价。首先，代理无法直接推理超出观察到的档案的预测质量。其次，它可能过度集中在早期的精英候选者周围，或者在没有将证据转化为有重点的搜索方向的情况下继续探索。

我们提出了 BayesEvolve，它将自主发现重新构建为信念状态演化。BayesEvolve 没有将过去的评估视为非结构化记忆，而是对候选质量保持显式的预测性信念状态。在每一步，实验证据都会更新后验信念；该信念被暴露给提议过程，并被采集规则用于选择未来的评估。在下面的实验中，信念状态是通过数值候选者上的高斯过程（GP）后验来实现的，但该框架与代理模型和候选表示无关。

贡献。
• 我们将 LLM 引导的发现表述为显式的信念状态维护，而不仅仅是档案记忆。
• 我们引入了带有退火不确定性奖励的信念引导选择规则，随着证据的积累，该规则从探索转向利用。
• 我们在偏移的 BBOB 风格优化任务上评估了 BayesEvolve，表现出比档案和记忆引导的 LLM 基线更强的性能。
• 我们分析了信念质量、决策规则消融和多样性动态，表明 BayesEvolve 的信念状态具有预测性，并支持富有成效的后期集中。

2 相关工作
档案引导的 LLM 进化搜索。
FunSearch (Romera-Paredes et al., 2024) 使用已评估候选者的种群来进化程序，而 AlphaEvolve (Novikov et al., 2025) 将 LLM 引导的进化扩展到更广泛的工程问题。这些系统展示了 LLM 提议加选择的力量，但它们的历史信息主要通过档案和分数来表示。BayesEvolve 通过使预测信念显式化来补充这一系列工作。

贝叶斯和概率发现。
贝叶斯优化使用后验信念和采集函数来选择信息量大的评估 (Jones et al., 1998; Srinivas et al., 2010)。BayesEvolve 借用了这种决策论结构，但将其置于 LLM 引导的发现循环中，其中信念状态既用于总结证据，又用于指导候选选择。相关的概率发现系统，如 ModelSMC (Wahl et al., 2026)，在符号模型候选者上保持分布；BayesEvolve 专注于一般假设质量的显式预测信念。

记忆引导的 LLM 代理。
记忆缓冲区和档案摘要在基于 LLM 的科学代理和优化系统中很常见。这种记忆可能有用，但它本身并不能为未评估的候选者提供校准的预测或不确定性估计。我们的实验与档案和启发式记忆基线进行了比较，以分离显式信念状态的价值。

3 BayesEvolve
3.1 问题表述
设 $\mathcal{H}$ 为假设空间。在步骤 $t$，系统评估候选者 $h_{t}\in\mathcal{H}$ 并接收目标值 $y_{t}\in\mathbb{R}$。在本文中，我们考虑最小化，因此 $y_{t}$ 越低越好。评估历史为
$\mathcal{D}{t}={(h{i},y_{i})}_{i=1}^{t},$ (1)
目标是在固定的评估预算 $T$ 下找到具有低目标值的候选者。

档案引导方法将提议条件化于过去评估的子集，例如最高分的候选者或最近的实验摘要。BayesEvolve 则保持显式的信念状态
$P(y\mid h,\mathcal{D}{t})=\mathcal{N}(\mu{t}(h),\sigma_{t}^{2}(h)),$ (2)
其中 $\mu_{t}(h)$ 是预测目标，$\sigma_{t}(h)$ 是后验不确定性。

3.2 信念引导的选择
对于候选池 $\mathcal{C}{t}$，BayesEvolve 使用不确定性感知分数来选择下一个候选者。因为我们最小化目标，固定 UCB 规则为
$a{t}(h)=-\mu_{t}(h)+\beta\,\sigma_{t}(h).$ (3)
受强化学习中探索时间表的启发，我们的最终决策规则使用了衰减的不确定性系数：
$a_{t}(h)=-\mu_{t}(h)+\beta_{t}\,\sigma_{t}(h),\qquad\beta_{t}=\beta_{0}\sqrt{\frac{n_{0}}{t}},$ (4)
其中 $n_{0}$ 是共享初始化评估的数量。这鼓励在早期进行更广泛的探索，并随着证据的积累越来越多地利用信念均值。

算法 1 BayesEvolve
0: 提议模型 $\pi_{\mathrm{LLM}}$，代理模型，预算 $T$，初始化大小 $n_{0}$
1: 评估 $n_{0}$ 个初始候选者以形成 $\mathcal{D}{t}$
2: for $t=n{0}+1$ to $T$ do
3: 拟合/更新信念状态 $P(y\mid h,\mathcal{D}{t})$
4: 从 LLM 提议和/或档案突变中构建候选池 $\mathcal{C}{t}$
5: 为 $h\in\mathcal{C}{t}$ 计算 $\mu{t}(h)$ 和 $\sigma_{t}(h)$
6: 选择 $h_{t}=\arg\max_{h\in\mathcal{C}{t}}[-\mu{t}(h)+\beta_{t}\sigma_{t}(h)]$
7: 评估 $y_{t}=f(h_{t})$ 并更新 $\mathcal{D}{t}\leftarrow\mathcal{D}{t}\cup{(h_{t},y_{t})}$
8: end for
9: 返回 $\mathcal{D}_{t}$ 中的最佳候选者

4 实验评估
4.1 设置
基准测试。
我们在维度 $d=5$ 的五个偏移 BBOB 风格最小化函数 (Hansen et al., 2009) 上进行评估：Sphere、Ellipsoid、Rastrigin、Rosenbrock 和 Ackley。每个函数都偏移了一个固定的隐藏偏移量，并且 LLM 提示仅暴露不透明的任务 ID（例如 F01）而不是函数名称，以防止基准名称泄漏。每次运行使用 $n_{0}=6$ 次共享随机初始化评估和 $T=100$ 次评估的总预算。结果在五个随机种子和五个函数上取平均值；阴影区域和 $\pm$ 值报告标准误差。

方法。
所有基于 LLM 的方法都使用相同的提议模型 gpt-5.4-mini，仅在上下文中提供的信息不同：无记忆、顶级档案条目、最近的启发式记忆 或 BayesEvolve 的显式信念状态。GP-BO 是非 LLM 贝叶斯优化基线。对于局部消融，所有信念变体都使用相同的偏移基准、共享初始化、GP 后验和候选池机制；我们比较了仅均值选择、UCB (Srinivas et al., 2010)、汤普森采样 (Thompson, 1933) 和预期改进 (Jones et al., 1998)。

4.3 实验 2：信念状态质量
图 2：信念状态质量。BayesEvolve 的显式信念状态在偏移 BBOB 风格优化期间在留出的候选池上进行评估。左图比较了后验均值预测与实现的目标值；右图显示具有较高后验不确定性的候选者具有较大的预测误差。预测误差越低越好。
在 60,800 个留出的信念预测中，后验均值与实现的目标值具有强等级相关性（Spearman $\rho=0.774$）。不确定性也提供了信息：具有较大后验 $\sigma_{t}(h)$ 的箱体表现出较大的绝对预测误差。信念状态具有预测性，但校准并不完美，单 sigma 区间的经验覆盖率为 0.433，双 sigma 区间为 0.653。

4.5 实验 4：多样性动态
图 3：多样性动态和富有成效的集中。滚动候选多样性是在最近的 20 个候选者上计算的。仅靠高多样性是不够的：Random-LLM 和 GP-BO 保持了广泛的探索，但未实现最佳最终目标。BayesEvolve 在后期降低了多样性，同时实现了最低目标，表明这是富有成效的信念引导集中，而不是无重点的探索。目标越低越好。
在整个运行过程中最大化多样性本质上并不更好。Random-LLM 和 GP-BO 保持了较高的最终多样性，但 BayesEvolve 在训练后期集中搜索的同时实现了最低的最终目标。这表明 BayesEvolve 避免了无效的档案崩溃，同时仍将积累的证据转化为有重点的搜索方向。

5 讨论
实验支持三个主张。首先，相对于档案和启发式记忆基线，显式信念状态提高了样本效率。其次，学习到的信念状态对留出的候选者具有预测性，而不仅仅是作为提示产物。第三，决策规则很重要：大部分增益来自后验均值，而衰减的不确定性奖励通过从探索转向利用来提供最佳最终性能。

局限性。
我们目前的实验使用偏移的 BBOB 风格数值优化任务，而不是完整的程序或实验室发现。GP 信念状态具有预测性，但校准不完美，其扩展限制促使在更大的评估预算下使用稀疏或神经代理。最后，多样性分析显示了富有成效的集中，而不是持续的多样性；未来的工作应该研究程序和科学假设空间更丰富的语义和结构多样性概念。

结论。
我们引入了 BayesEvolve，这是一个用于自主发现代理的框架，可将实验证据转化为显式预测信念状态。在偏移的黑盒优化任务上，BayesEvolve 改进了记忆引导的 LLM 基线，产生了预测性信念估计，并受益于退火的不确定性感知决策规则。这些结果支持信念状态演化作为自主科学发现的有用原则。
