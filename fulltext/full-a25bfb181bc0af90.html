摘要

稀疏混合专家（MoE）模型通过为每个token仅激活一小部分专家来扩展参数容量。在固定的激活专家预算下，专家选择直接影响模型能力。然而，对所有专家进行密集评估发现，单路由器分数排名与专家效用评估排名之间的一致性较弱，尤其是在中间层和深层。为选择和计算获取更丰富的信号需要额外成本：基于专家内部激活的选择需要预计算，而通过同一专家分别处理多个完整表示会重复其计算。我们提出多视角MoE（Multi-View MoE），通过多个路由器改进专家选择，并进一步复用其偏好来调制专家计算，同时保持固定的专家预算。其多路由器（Multi-Router）子模块聚合来自独立初始化路由器的sigmoid分数。这些路由器在训练过程中发展出高度分化的专家偏好，使得被某个路由器强烈青睐或被多个路由器共同支持的专家能够被选中。多视角进一步使用每个选中专家在各路由器间的相对分数，将学习到的潜在视图混合到其输入中，将路由偏好同时复用于选择和计算。每个选中的专家执行一次前向传播，保持激活专家数量、专家FLOPs和全对全通信量不变。在708B token上训练的24层10B-A1B模型上，完整的多视角MoE在九个下游任务上将平均分数比基线提高1.18个百分点。仅其多路由器子模块就带来0.6个百分点的增益，并改善路由器分数与评估的专家效用之间的秩相关性，全局相对提升8.1%，在单路由器对齐度最低的层中约提升58%。受控混合干预进一步表明，模型使用了同时依赖于专家和token的输入差异。

1 引言

图2：24层10B-A1B骨干网络上单路由器分数与经验性专家效用评估之间的一致性。 训练期间的Spearman相关性。对数训练步轴扩展了早期阶段并压缩了后期区间，以更清晰地展示早期训练的变化。 路由器比较中使用的201次记录测量的逐层均值；阴影带表示±1标准差。分数不包括负载平衡偏置。专家效用使用每个专家的输出L2范数评估，并通过其在采样token上的均值归一化（附录B.5）。

稀疏混合专家（MoE）模型通过为每个token激活一小部分专家来扩展参数容量（Shazeer等，2017；Fedus等，2021）。这种条件计算在有限的激活计算预算下实现了更大的语言模型。路由分数决定哪些专家处理每个token以及它们的输出如何组合。由此产生的能力既取决于专家选择，也取决于所选专家执行的计算。

传统MoE使用单个路由头，然后进行硬top-k选择。对所有专家的密集评估显示，路由器的排名与经验性专家效用评估获得的排名之间的一致性有限，尤其是在中间层和深层（图2）。未选中的专家不会从该token接收直接的任务损失梯度，因此糟糕的选择可能变得自我强化。这促使我们从多个评分角度评估专家，而不是依赖单个路由器。

标准MoE使用路由分数来选择专家并加权其输出，但不会复用它们来构建专家输入。负载平衡方法调节专家利用率（Wang等，2024a），但本身不提供对每个专家的多次评估。基于激活的路由（如AoE）通过对所有专家的部分评估获得专家特定信号，使用低秩分解来控制成本（Lv等，2025）。分别评估多个输入表示也会增加专家计算。因此，挑战在于获得对专家的多次评估，并使用路由偏好来调制其计算，同时保持激活专家数量、专家FLOPs和通信量。

我们提出多视角MoE，一个复用路由器偏好以改进专家选择和调制专家计算的框架。其多路由器子模块结合对共享专家池的多次评估：独立初始化的sigmoid路由头产生分数，在一次top-k选择之前求和。这些路由器在训练过程中发展出高度分化的偏好。它们的聚合允许被一个路由器强烈青睐或被多个路由器共同支持的专家被选中。该子模块保留共享的专家输入，同时丰富用于选择的信息。

多视角进一步使用这些分化的偏好来调制每个选中专家的计算。仅求和的分数不保留路由器的相对偏好：分数向量(0.4, 0.1)和(0.2, 0.3)之和均为0.5，但表达相反的偏好（图1）。每个路由器与一个学习到的潜在投影配对，每个选中专家的原始sigmoid分数在各路由器间归一化，以在评估之前将视图混合到其输入中。投影在专家间共享，而混合比例同时依赖于token和专家。混合在分发之前进行，每个选中的专家执行一次前向计算，保持激活专家数量、专家FLOPs和全对全通信量。

在训练708B token的24层10B-A1B模型上，完整的多视角MoE将九项任务下游均值比基线提高1.18个百分点，达到34.25；仅其多路由器子模块就提供0.6个百分点的增益。路由诊断显示，该子模块将全局分数-效用秩相关性相对提高8.1%，在单路由器对齐度最低的层中相对增益约58%（第4.4节）。测量显示同一token的不同专家输入不同。在最后一个MoE层，固定专家选择和输出门控的同时置换专家间的视图混合比例，使保留NLL提高0.01340 nats/token；对同一专家跨token置换比例也会增加NLL（第4.3节）。这些结果表明，训练后的模型使用了混合比例、专家和token之间的对应关系。

贡献。

  • 用于改进专家排名的多路由器。对所有专家的密集评估显示，单路由器分数排名与专家效用评估排名之间的一致性较弱，尤其是在中间层和深层。基于这一观察，多路由器子模块聚合来自独立初始化路由器的sigmoid分数。这些路由器在训练过程中发展出高度分化的专家偏好，其聚合分数与评估的效用排名实现更接近的一致性。
  • 固定专家预算下的多视角MoE。该框架将其多路由器选择子模块与路由器条件化的潜在视图混合耦合。分发前的混合保留每个选中专家的一次前向计算、激活专家数量、专家FLOPs和全对全通信量。
  • 定量增益。在训练708B token的24层10B-A1B模型上，完整的多视角MoE将九项任务下游均值比基线提高1.18个百分点；仅多路由器就提供0.6个百分点的增益。多路由器将全局分数-效用秩相关性相对提高8.1%，在单路由器对齐度最低的层中相对增益约58%。

2 相关工作

稀疏MoE与专家专业化。稀疏MoE层将每个token路由到专家的一小部分并组合其输出（Shazeer等，2017）。具有线性路由头和top-k选择的token路由在稀疏MoE模型中仍然常见（Cai等，2024；DeepSeek-AI等，2024b；Jiang等，2024）。Switch Transformer使用top-1路由（Fedus等，2021）。最近的大型语言模型也采用MoE架构（GLM-5-Team等，2026；Wang等，2026a）。诸如具有始终激活的共享专家的细粒度专家等方法增加了专家专业化的灵活性（Dai等，2024）。然而，在这些架构中，离散路由决策决定激活的专家，这些专家处理共享的token表示。

路由器设计。路由器设计通过包括路由器z损失（Zoph等，2022）、专家选择路由（Zhou等，2022）、无辅助损失平衡（Wang等，2024a）、缓解表示坍塌（Chi等，2022）和专家注意力（Wu等，2024a）等方法解决路由质量、稳定性和负载平衡问题。专家分配在训练期间可能波动，促使更稳定路由方法的发展（Dai等，2022；Nguyen等，2025）。Router Upcycling在稠密到MoE升级中从前面的注意力层初始化查询投影和专家键，然后在softmax选择之前对路由器间的查询-键匹配分数求和（Ran等，2025）。MoR在LoRA专家混合中使用可学习的主路由器来加权子路由器输出，用于参数高效微调（Zhang等，2025）。我们的多路由器子模块在预训练期间对来自单独参数化的sigmoid路由头的分数求和。多视角进一步使用每个专家在各路由头间的相对分数来构建其输入。

多表示和潜在空间MoE。另一条工作线改变专家处理的表示。LatentMoE从完整隐藏状态计算路由器分数，并在低维潜在空间中评估专家（Elango等，2026）。Stable LatentMoE修改此设计以提高训练稳定性，同时保留单个下投影（Kimi团队等，2026）。我们基于这种共享投影架构构建。MoLAE将专家权重分解为共享潜在映射（可选地在专家组内）和专家特定变换（Liu等，2025b）。AoE移除单独的路由器：专家按其低维内部激活的L2范数排名，只有选中的专家继续计算；低秩分解降低了此初始评估的成本（Lv等，2025）。MH-MoE将投影的token拆分为共享路由器和专家池的子token（Wu等，2024b；Huang等，2024）。Multi-Head LatentMoE则为每个子token分配具有自己路由器和专家的独立MoE模块（Cui等，2026）；SliceMoE也探索token切片（Vejendla，2025）。MoH将共享和路由组件应用于注意力头而非FFN（Jin等，2024）。

多视角MoE使用完整隐藏状态的K个投影作为共享基础。对于每个选中的专家，原始分数在各路由器间归一化，以在专家计算之前确定依赖于token和专家的混合。投影数量取决于K，而不是专家数量，并且专家参数在视图间共享。这改变了每个专家接收的表示。先前的分析将隐藏状态几何与专家使用模式相关联（Wang等，2026b）。多路由器保留LatentMoE的共享潜在输入，同时聚合多个路由头；多视角进一步复用其偏好来调制专家输入。

3 方法

3.1 预备知识和框架概述

我们研究自回归语言建模，并修改潜在空间MoE骨干的路由和专家输入接口（Elango等，2026）。路由器读取隐藏状态h ∈ ℝ^D并从N个路由专家中选择k个。下投影P ∈ ℝ^(d×D)提供共享输入z = Ph。每个专家将ℝ^d映射到ℝ^d。对于选中的集合𝒮和输出门g_i，潜在专家聚合为：

y = Σ_{i∈𝒮} g_i E_i(z).　(1)

骨干将此聚合上投影到维度D，并将其与始终激活的共享专家输出结合。

多视角保留共享专家池和|𝒮| = k，同时复用各个路由头的偏好进行选择和输入构建。其多路由器子模块聚合分数；对于每个选中的专家，在各路由器间归一化的分数在一次专家评估之前混合潜在视图。图3显示了计算过程。

图3：潜在空间MoE架构比较。上： LatentMoE使用路由器和共享潜在输入； 多路由器对来自单独参数化的sigmoid路由头的分数求和以进行top-k选择，同时保留共享输入； 多视角添加不同的下投影和专家特定的视图混合。下：中框选路由路径的展开，颜色和编号标记匹配。平衡偏置b仅添加到求和分数用于选择。输出门g_i遵循公式3。对于每个选中的专家，原始sigmoid分数在各路由器间归一化形成视图比例a_{m,i}，其和为1。每个选中的专家处理其混合输入一次。聚合表示y被上投影并与上方所示的共享专家输出结合。K=2视图和选中的专家i、j是示例性的；k是N个中激活专家的数量。条形图描绘示例路由分数。为清晰起见，省略了归一化模块和残差路径。

3.2 多路由器：选择前的分数聚合

多路由器使用R个路由头{w^(r)}，w^(r) ∈ ℝ^(D×N)，从完整隐藏状态h对共享专家池评分。每个路由头的输出通过sigmoid，得到的分数在top-k选择之前求和：

s̄i = Σ{r=1}^{R} σ(w_i^(r)⊤ h),　(2)
𝒮 = TopK_k(s̄ + b).

这里b ∈ ℝ^N是骨干的专家平衡偏置，仅用于选择。输出门在选中的专家上对未校正的分数和进行归一化，并应用骨干的路由输出比例：

g_i = α_i · s̄i / Σ{j∈𝒮} s̄_j,　i ∈ 𝒮.　(3)

这里α_i是骨干对专家i的可学习标量；它缩放专家输出，而不是视图混合。

路由头用不同的种子初始化以打破对称性，没有多样性惩罚。我们默认使用R = 2。在多视角中（第3.3节），每个路由器与一个视图配对，因此R = K，两个符号指的是同一数量。

sigmoid之后的求和保持路由头作为不同的非线性评分函数。在sigmoid之前对logits求和则给出单个线性评分器，因为Σ_r w_i^(r)⊤ h = (Σ_r w_i^(r))⊤ h。sigmoid后求和允许来自一个路由头的强分数或跨路由头的支持影响共享排名，并提供用于输入混合的相对贡献。替代方案及其性质见附录A.3–A.5，训练比较见第4.5节。

3.3 多视角：路由器条件化的专家输入

多视角将R个路由头与K个潜在视图一一对应配对，因此R = K。选择和输出门控遵循多路由器的求和分数规则，而每个选中专家在各路由器间归一化的分数构建其输入v̂i = Σ_m a{m,i} v^(m)。视图在专家评估之前融合，每个选中的专家运行一次。这种参数化避免了对每个视图分别评估专家；对于非线性E_i，它通常不等价于在分别评估后混合输出：

E_i(Σ_m a_{m,i} v^(m)) ≠ Σ_m a_{m,i} E_i(v^(m)).

视图。我们形成K个潜在视图v^(m) = P_m h ∈ ℝ^d，每个P_m ∈ ℝ^(d×D)与骨干下投影的形状匹配。视图1使用骨干的投影P；其余K-1个视图使用独立初始化的扰动，如下所述。每个视图投影完整的隐藏状态而不是其通道的子集。专家架构和输入维度不变。

路由、混合和门控。所有R个路由头读取h。路由头m对每个专家i产生s_{m,i} = σ(w_i^(m)⊤ h)，这些分数决定三个操作。

(i) 选择：跨路由器求和，s̄i = Σ_m s{m,i}，添加平衡偏置，并进行一次top-k，𝒮 = TopK_k(s̄ + b)，如多路由器中所示。

(ii) 视图混合：对于每个选中的专家i，在R个路由头间归一化其原始sigmoid分数：

a_{m,i} = s_{m,i} / Σ_{n=1}^{R} s_{n,i},　Σ_{m=1}^{K} a_{m,i} = 1,　i ∈ 𝒮.　(4)

这些比例形成凸混合v̂i = Σ_m a{m,i} v^(m)。平衡偏置和路由输出比例均不进入此混合。

(iii) 输出门控：使用公式3中的g_i组合选中专家的输出。因此，输出门控在专家间归一化求和分数，而输入混合在每个专家的路由器间归一化分数。得到的专家聚合为：

y = Σ_{i∈𝒮} g_i E_i(Σ_m a_{m,i} v^(m)).　(5)

等价地，输入使用依赖于token和专家的有效投影：

P_eff,i(h) = Σ_m a_{m,i}(h) P_m,　v̂_i = P_eff,i(h) h.

投影基{P_m}在专家间共享；只有其混合系数依赖于h和i。实现混合投影向量，而不是为每个token-专家对实例化单独的矩阵P_eff,i。

在每个专家的路由器间归一化分数以导出混合权重不需要额外的混合网络，并使视图m对专家i输入的贡献取决于相应的路由偏好。算法1给出前向传播。学习到的混合权重和梯度耦合在第4.5节相应的消融配置中评估。

算法1 多视角路由专家分支前向传播

1: 输入：隐藏状态h；投影{P_m}{m=1}^K；路由头{w^(m)}{m=1}^R；专家{E_i}{i=1}^N；激活数量k；平衡偏置b；路由输出比例{α_i}{i=1}^N
2: v^(m) ← P_m h，m = 1, …, K　▷ K个潜在视图
3: s_{m,i} ← σ(w_i^(m)⊤ h)　▷ 在完整h上的每路由器分数
4: s̄i ← Σ_m s{m,i}　▷ 每个专家的求和分数
5: 𝒮 ← TopK_k(s̄ + b)　▷ 偏置仅用于选择
6: for i ∈ 𝒮 do
7: 　a_{m,i} ← s_{m,i} / Σ_{n=1}^R s_{n,i}　▷ 跨路由器归一化
8: 　v̂i ← Σ_m a{m,i} v^(m)　▷ 每专家视图混合
9: 　g_i ← α_i s̄i / Σ{j∈𝒮} s̄j　▷ 输出门，公式3
10: end for
11: return y = Σ{i∈𝒮} g_i E_i(v̂_i)

专家相关的混合权重。a_{m,i}中的索引i允许输入调制在专家间变化。如果同一token的所有选中专家共享a_{m,i} = a_m(h)，它们接收相同的输入(Σ_m a_m(h) P_m) h。这仍然是token条件化的调制，但不再区分该token的不同专家。如果权重进一步固定为常数，如a_m = 1/K，则混合可以吸收到固定投影中。多视角从专家i的原始分数导出a_{m,i}，在R个路由头间归一化，使调制同时依赖于token和专家（附录A.10）。

初始化。为了逐渐引入额外的投影，我们对视图1保留骨干下投影，并将其他视图参数化为渐进扰动，v^(m) = Ph + γ(t) ΔP_m h，其中γ在训练早期从0增加到1。在t = 0时，所有视图投影等于骨干投影；渐进之后，视图投影不受约束。专家输入是这些视图的加权组合。此过程也可以从现有检查点初始化视图（附录A.9）。

共享专家参数。所有视图使用一个专家池，因此专家参数不会在视图间复制或分区。每个选中的专家处理一个混合输入，梯度通过每个具有非零混合权重的视图传播。多路由器对所有选中的专家使用共享输入z = Ph；多视角通过路由器导出的系数添加输入调制（附录A.10）。

我们探测用于708B token下游评估的分数导出多视角检查点。分析覆盖256个4096 token的保留序列上的所有24个MoE层。它检查专家特定输入以及训练后的模型是否使用混合比例、专家和token之间的对应关系。

从偏好到不同的专家输入。两个路由头具有明显不同的排名：跨层，它们的top-8 Jaccard指数平均为0.145，top-1一致性平均为11.2%。对于每个token，探测导出其八个选中专家中每个的实际视图1混合比例r_{1,i} = a_{1,i}和混合输入。我们比较这些专家的所有28对：D_r是它们的平均绝对比例差，D_v是它们的平均输入距离除以平均输入范数（附录B.6）。当所有八个专家分别接收相同的比例或输入时，两者均为零。图5(a)总结了每层token间的这些token内差异。D_r的逐层中位数为0.27-0.46，D_v为0.42-0.58。因此，选中的专家根据其视图偏好接收不同的输入。

训练后的模型使用该对应关系。在最后一个MoE层，我们将选中的专家𝒮及其输出门g_i固定到数值精度，仅干预视图混合比例。对于替换比例r'{1,i}，两个分发器通道重建为(g_i r'{1,i}, g_i(1 - r'_{1,i}))，保持它们的和g_i。在同一token的选中专家间置换视图比例使NLL提高0.01340 nats/token（95%序列自助CI：[0.01256, 0.01435]）。使用均匀混合比例(1/2, 1/2)使NLL提高0.00662；对同一专家跨token置换比例使其提高0.00223。各自的CI为[0.00620, 0.00709]和[0.00205, 0.00241]。专家置换对所有256个序列增加序列平均NLL。这些干预表明，训练后的检查点使用混合比例、专家和token之间的对应关系。专家置换在这三种干预中产生最大的增加。

两个视图跨深度贡献。在最后一层应用仅视图1或仅视图2比例分别使NLL增加0.01881和0.02042 nats/token。因此，训练后的检查点使用两个视图分支。单独的80序列扫描一次扰动一层：专家置换和均匀混合增加NLL，在所有24层中逐点95% CI高于零。只有被干预层的选择和输出门被固定；后续路由重新计算，因此这些是包括下游响应的总效应。其他偏好、单视图和token组分析见附录B.6。

4.6 参数和计算效率

参数开销。对于具有两个路由头的24层10B-A1B骨干，多路由器子模块增加约0.06%的参数。多视角每层添加一个潜在视图投影，进一步贡献0.13%，总增加约0.19%。

专家计算和通信。每个选中的专家处理一个混合输入，保持激活专家数量和激活专家FLOPs。输入混合在分发之前在源设备上进行；每个token仍然发送k个维度为d的向量，保持全对全通信量。额外工作来自路由、投影和输入混合；对于固定K，额外的评分和投影成本按D(d+N)缩放。附录A.6给出参数和操作计数，以及路由器和视图馈送消融配置的同集群吞吐量测量。

5 结论

多视角MoE复用路由偏好以改进专家选择和塑造专家计算。基于单路由器排名与经验性专家效用排名之间的弱一致性，其多路由器子模块结合独立初始化的路由头，学习高度分化的偏好。路由诊断显示全局相对秩相关性增益8.1%，在单路由器对齐度最低的层中约58%。多视角进一步使用每个选中专家在各路由头间的相对分数，在分发之前将潜在视图混合到其输入中。每个选中的专家运行一次，保持激活专家数量、专家FLOPs和全对全通信量。在训练708B token的24层10B-A1B模型上，完整的多视角MoE将九项任务下游均值比基线提高1.18个百分点；仅其多路由器子模块就提供0.6个百分点的增益。受控混合干预表明，模型有效利用了依赖于专家和token的输入差异。这些发现确立了路由偏好作为选择专家和塑造其如何处理每个token的信号。

局限性

实验使用具有共享训练种子的24层10B-A1B骨干，并在708B token检查点评估九项下游任务。受控干预测量训练后的模型在该检查点对视图混合的使用。

A.1 LatentMoE作为骨干

因为专家在潜在空间中操作，用视图v^(m)替换选中专家的输入z不改变其架构、宽度和超参数。因此可以复用现有的专家块而不增加专家容量。潜在空间设计也在其他MoE架构中被研究（Elango等，2026；Liu等，2025b）。

A.2 上下文表示和专家输入

注意力产生上下文表示h，但基线MoE仍在相同的投影输入z = Ph上评估所有k个选中的专家。注意力表示和专家输入是独立的架构选择：多个投影可以为选中的专家提供从相同h导出的不同输入。我们对这种学习到的潜在投影或由此产生的专家输入使用术语"视图"。

A.3 融合位置的选择

我们考虑组合R个路由器分数的三种位置。(1) 非线性之前（logit求和）：Σ_r w_i^(r)⊤ h = (Σ_r w_i^(r))⊤ h等价于权重为Σ_r w_i^(r)的单个评分器（第3.2节）。(2) sigmoid之后（我们的方法）：每个路由器首先应用自己的非线性，然后组合得到的分数。(3) 归一化为概率之后：每个路由器的分数在求和之前归一化，消除其整体规模的差异。表3报告相应的训练比较。

A.4 融合算子的选择

对于sigmoid后融合，不同的聚合算子强调不同的分数模式。设s_m ∈ (0,1)表示一个路由器对某专家的分数。加法算子Σ_m s_m允许一个路由器的高分数即使其他分数低时也增加聚合。乘法算子Π_m s_m和几何均值(Π_m s_m)^(1/R)在任何路由器分配接近零分数时抑制专家。我们还考虑带一致性项的加法算子Σ_m s_m + λΠ_m s_m，或不一致性惩罚Σ_m s_m - λ|s_1 - s_2|；两者在λ = 0时退化为求和。

求和具有两个有用的性质，经验比较见表3和图7。首先，乘法聚合对低分数敏感：一个接近零的分数可以抑制专家，无论其他路由器的分数如何。求和不强加这种一致性要求。其次，当s̄i = Σ_m s{m,i}时，公式3中专家的输出门可以分解为每路由器贡献g_i = Σ_m α_i s_{m,i} / Σ_{j∈𝒮} s̄j。乘积没有这种加法分解，其规模取决于R。相同的原始sigmoid分数还在第3.3节中提供输入混合权重：对于每个选中的专家，其分数在各路由器间归一化，a{m,i} = s_{m,i} / Σ_n s_{n,i}，使得Σ_m a_{m,i} = 1。

我们还评估了一个变体，使用max_m s_{m,i}选择专家并使用Σ_m s_{m,i}门控其输出。因此选择取决于专家的最高路由器分数，而输出权重使用来自所有路由器的分数。这分离了分数聚合对选择和门控的影响。在概念上，它对应于在选择阶段选择一个路由器，类似于在硬单视图变体中为专家输入选择一个视图。表4单独报告评估的视图混合变体。

A.5 选择前的聚合

该层在单次top-k选择之前聚合所有路由器分数。每个路由器对完整专家集{1, …, N}评分，激活专家的数量保持为k，与路由器数量R或视图数量K无关。所有路由头贡献于完整专家池上的一个共享排名。

另一种选择是将固定的k个选择预算在路由器间自适应分配。虽然这保留了总预算，但每个路由器仍然独立排名专家并仅选择其分配的配额。因此，即使某专家的聚合分数将其置于全局top-k中，它也可能被每个局部选择排除。我们改为聚合分数并以固定的k个专家总数进行一次选择。

A.6 详细的成本核算

设L为MoE层数。隐藏维度为D，潜在维度为d，有N个路由专家，每token激活k个。对于R = K的主要配置，每层添加K-1个形状为d×D的投影和R-1个形状为D×N的路由头。因此：

Δθ_layer = (K-1) D(d+N),　(6)
Δθ_model = L Δθ_layer.

当L = 24、K = 2、D = 1024、d = 512和N = 256时，多视角每层添加786,432个参数，总共18,874,368个，约为10B参数骨干的0.19%。多路由器仅添加路由头：每层262,144个参数，总共6,291,456个，约0.06%。

专家路径仍在d维输入上评估k个未更改的专家。对于每个token和层，额外的投影和评分矩阵需要(K-1)D(d+N)次乘加运算(MAC)。将一个MAC计为两个FLOP，直接混合计为每坐标K次乘法和K-1次加法，K ≥ 2的额外前向成本约为：

ΔF_forward ≈ 2(K-1)D(d+N) + kd(2K-1).　(7)

该估计涵盖每token和每层的评分和投影矩阵乘法以及输入混合。专家块FLOPs不变。实现仍然每token分发k个维度为d的向量，保持全对全通信量（附录A.7）。

A.7 实现

标准MoE实现在全对全通信之前置换token，将每个token的潜在向量按选中专家复制一次到按专家组织的缓冲区。多视角改为在分发之前在token的设备上为每个选中的(token, expert)对构建d维混合输入v̂i = Σ_m a{m,i} v^(m)。对于T个token，实现展平T×k个token-专家槽，每个有一个选中的专家作为目的地。每个token仍然分发k个维度为d的向量，因此全对全通信量不变。分发所有K个视图并在专家设备上组合它们会使该通信量乘以K。返回的全对全通信、逆置换和专家输出的门控求和不变。

因为选择不使用每视图配额，负载平衡使用骨干现有方案在N个专家上应用一次。没有为视图添加辅助损失。

专家偏置在路由头分数求和之后添加，仅用于top-k选择，𝒮 = TopK_k(s̄ + b)；它既不进入输入混合权重也不进入输出门。输出门遵循公式3：未校正的s̄i在选中集合上归一化，然后乘以骨干的每专家输出比例。对于输入混合，公式4在每个选中专家的路由器间归一化原始sigmoid分数，得到的系数直接形成v̂_i = Σ_m a{m,i} v^(m)。输入比例计算使用ε = 10^-9以保证数值稳定性，数学公式中省略。在固定参数下，用其均值替换分数和并将b缩放1/R保持选择、输出门和视图权重。为了在训练期间保持偏置对应关系，其初始化和更新增量也必须缩放1/R。在多路由器中，重复一个路由头R次并将其平衡偏置乘以R保持与单个路由头相同的前向计算。

执行路径验证。对于检查点探测，我们验证分发器接收的专家ID、输出门和混合权重。附录B.6报告这些执行检查和恒等重放误差。

A.8 与其他组件的交互

多视角修改MoE下投影、路由器和置换步骤。注意力（包括多头潜在注意力MLA）（DeepSeek-AI等，2024a）不变，KV缓存也不变。超连接及其流形约束变体mHC使用多个残差流并在子层间学习混合（Zhu等，2024；Xie等，2025）。多视角接受得到的子层输入h并返回D维输出，因此这些设计在架构上兼容。多token预测（MTP）（DeepSeek-AI等，2024b）添加预测模块和损失项，而多视角保持训练目标不变。在我们的配置中，MTP模块使用稠密FFN，未被修改。该方法在设计上也与细粒度和共享专家、无辅助损失平衡以及稠密或哈希路由的早期层（Roller等，2021）兼容。它保持词汇表、嵌入、路由和激活专家数量、专家块、上投影和专家并行布局不变。

A.10 性质：绑定视图和视图分化

绑定视图归约。由于Σ_m a_{m,i} = 1，绑定所有P_m = P给出每个选中专家的v̂i = (Σ_m a{m,i}) Ph = Ph。在相同的路由器分数、选中集合和输出门下，这恢复为具有共享输入z = Ph的多路由器。所有路由器继续对相同的专家池评分，与视图投影是否绑定无关。

专家相关的混合。对于给定的token，跨专家变化的混合权重允许这些专家接收不同的输入。如果所有选中的专家共享a_{m,i} = a_m(h)，则v̂i = Σ_m a_m(h) P_m h = (Σ_m a_m(h) P_m) h = P{a(h)} h。所有k个专家然后共享一个输入，但P_{a(h)}仍然可以随token变化，因此输入调制保持。当a_m为常数（包括a_m = 1/K）时，混合可以吸收到固定投影中。主要方法的a_{m,i}保留token和专家依赖性，在此粒度上提供调制而无需额外的混合网络。

每视图负载。聚合负载平衡（附录A.7）控制分配给每个专家的token数量，影响分发成本和专家利用率。对于每视图诊断，设u_{m,i}(h_t)为专家i处视图m的记录权重。定义p_{m,i} = Σ_{t: i∈𝒮(h_t)} u_{m,i}(h_t) / Σ_j Σ_{t: j∈𝒮(h_t)} u_{m,j}(h_t)为分配给专家i的视图m记录权重质量的比例。聚合分配计数可以保持不变而p_{m,·}变化。因此，即使聚合专家负载均匀，不同视图也可以集中于不同的子集。我们报告p_{m,·}的变异系数和有效专家计数exp(H_m)，其中H_m是p_{m,·}的熵（附录B.7）。低有效计数表示集中于较少的专家。我们还报告专家的选择份额与其门质量份额的比率，区分分配频率的变化与输出权重的变化。

分化。绑定配置P_1 = … = P_K是对称的，但只有当视图的梯度分量一致时，梯度更新才保持它。每个P_m通过为视图m分配非零混合权重的选中专家接收梯度，在公式5中按a_{m,i}缩放。因为这些权重可以跨专家和token变化，视图可以接收不同的更新而无需显式的多样性惩罚。我们评估路由器分歧（第4.3节）和每视图负载（附录B.7）。

多样性定义。对于token t，设𝒮_t为其k = 8个选中的专家。探测使用主方法的实际混合比例，r_{m,i}(t) = a_{m,i}(t) = s_{m,i}(t) / Σ_n s_{n,i}(t)，因此Σ_m r_{m,i}(t) = 1且r_{2,i}(t) = 1 - r_{1,i}(t)。专家i的实际输入为v̂i(t) = r{1,i}(t) v^(1)(t) + r_{2,i}(t) v^(2)(t)。

我们计算：

D_r(t) = (2/(k(k-1))) Σ_{i<j, i,j∈𝒮_t} |r_{1,i}(t) - r_{1,j}(t)|,　(11)

D_v(t) = [(2/(k(k-1))) Σ_{i<j, i,j∈𝒮_t} ‖v̂i(t) - v̂_j(t)‖_2] / [(1/k) Σ{i∈𝒮_t} ‖v̂_i(t)‖_2].　(12)
