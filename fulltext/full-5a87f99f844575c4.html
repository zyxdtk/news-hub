原标题：Meituan open sources LongCat-2.0, the 1.6T, near-frontier agentic coding model that's been leading OpenRouter — trained entirely on Chinese chips

中文摘要： 美团开源了1.6万亿参数的MoE智能体编程模型LongCat-2.0，采用MIT许可证，拥有100万token上下文窗口。该模型完全由超5万个国产ASIC芯片训练，打破了英伟达GPU垄断。它在SWE-bench Pro上超越GPT-5.5，并引入缓存命中免费、限时闪售Token包等极具竞争力的商业定价模式，为企业自主软件开发提供了低成本、高性能的开源替代方案。

几小时前，中国外卖应用公司美团在 GitHub、Hugging Face 及其原生平台上正式发布了 LongCat-2.0，揭开了该模型的神秘面纱：它正是过去两个月在 OpenRouter 全球开发者排行榜上独占鳌头的匿名隐形模型“Owl Alpha”背后的计算引擎。

这款拥有 1.6 万亿参数的混合专家系统旨在从根本上打破闭源企业在自主软件工程领域的主导地位，它以高度宽松的、企业级的、可商用的 MIT 许可证将原生 100 万 token 的上下文窗口引入公共领域。然而，该公司尚未发布完整的模型权重——其 GitHub 和 Hugging Face 页面均显示“模型权重即将推出，敬请期待！”

该架构的商业访问引入了极具攻击性的定价层级，部署了一种所有上下文缓存命中均完全 免费 处理的机制，同时辅以限时的“Token Pack”闪售模式。此外，还有针对未缓存命中的标准“按量付费”API，每百万 token 的输入/输出标准价格分别为 0.75 美元/2.95 美元。

然而，限时促销折扣将这些运营成本大幅削减至未缓存输入每百万 token 0.30 美元，输出每百万 token 1.20 美元，两者均处于全球顶级模型价格区间的较低端。

使得此次发布成为全球科技基础设施明确转折点的是其运营独立性：这个庞大的模型完全在一个由超过 50,000 个国产中国专用集成电路（ASIC）组成的集群上训练而成，证明了在不依赖典型的美国英伟达 GPU 的情况下，也能成功扩展接近前沿的 AI 模型，而迄今为止，英伟达 GPU 一直为全球生成式 AI 前沿模型的训练工作提供动力。

这种替代性硅片的成功部署标志着一个深刻的结构性转变。如果中国企业集团能够使用本土 ASIC 而非通用 GPU 持续迭代万亿参数架构，这似乎将威胁到英伟达在该领域的主导地位。

至关重要的是，这种技术转型恰逢华盛顿向美国顶级实验室施压，要求其限制对最新模型的访问。在美国政府的要求下，OpenAI 被迫限制对其新 GPT-5.6 模型的访问，而 Anthropic 此前也被美国下令限制对其最新 Claude Fable 5 / Mythos 5 模型的访问，作为回应，该公司将这些模型完全下线。与此同时，越来越多的技术专家、活动家和行业专家警告称，这些防御性监管举措无意中产生了适得其反的效果。通过锁定西方闭源模型并推高 API 成本，美国政府为全球开发者留下了一个巨大的运营窗口，使他们转而寻找像美团 LongCat-2.0 这样的中国开源模型中那种经济实惠、高性能的替代品。

原始运营指标印证了开发者的热情：在 OpenRouter 上以未具名身份驻留期间，Owl Alpha 每月处理约 10.1 万亿个 token——平均每天 5590 亿个 token——这意味着环比激增 242%，将其推升至该平台全球前三名。

技术：构建 100 万 Token 稀疏上下文

LongCat-2.0 的核心在于对混合专家稀疏性的激进优化，将总参数量扩展至 1.6 万亿，同时将每个 token 的平均激活计算量限制在 480 亿。

根据查询的结构复杂性，模型的动态激活范围从 330 亿到 560 亿参数不等。该设计实现了“零计算专家”框架，确保常规执行元素通过较轻的子网络，完全消除了通常困扰超密集模型的闲置计算开销。

为了在不引起灾难性硬件瓶颈的情况下维持功能性的 100 万 token 上下文窗口，美团引入了 LongCat 稀疏注意力机制（LSA）。作为 DeepSeek 稀疏注意力机制的进化迭代，LSA 通过三个独立且正交的向量，解决了通常困扰细粒度稀疏机制的二次方评分成本和内存碎片化问题：

  • 流感知索引： 该系统通过将硬件对齐的连续数据读取与动态随机选择相融合，重构了 token 选择管道。通过将碎片化的内存访问转换为高度可预测的顺序块，该系统实现了高带宽内存（HBM）的合并利用并提升了有效带宽。
  • 跨层索引（CLI）： 利用注意力显著性在相邻隐藏层间保持高度稳定的经验现实，CLI 摊销了计算成本。单次索引过程即可在推理过程中成功引导多个连续层，这一能力在整个训练阶段通过跨层蒸馏得到了强化。
  • 分层索引（HI）： 该方法采用从粗到细的两阶段评分布局。索引器执行快速的近似块级召回以过滤候选者，然后仅对剩余部分进行细粒度的 token 选择。

此外，美团集成了继承自其较轻量级模型系列的 N-gram 嵌入模块。通过在完全正交于 MoE 专家布局的稀疏维度中扩展参数分配，该架构向 5-gram token 组合框架追加了 1350 亿个参数。

这将核心嵌入空间扩大了约 100 倍，使模型能够捕获密集的局部 token 关系，并通过减少内存输入/输出（I/O）瓶颈来加速大批量推理操作。

产品：训练后、MOPD 框架与基准测试性能

虽然通用大语言模型优先考虑流畅的对话界面，但 LongCat-2.0 明确专注于多步工程任务、工具集成和自动化代码库操作——即智能体任务。

在标准化评估中，LongCat-2.0 在 SWE-bench Pro 上的实测得分为 59.5，超过了 GPT-5.5 的 58.6 基准。该模型在 Terminal-Bench 2.1 上取得 70.8 分，在 SWE-bench Multilingual 上取得 77.3 分，在通用企业工作流模拟器 FORTE 上取得 73.2 分，进一步确立了其智能体专业化能力。


LongCat-2.0 基准测试对比柱状图。来源：美团 LongCat

这种精确的操作行为是通过一种名为“通过混合专业专家进行多教师优化”（MOPD）的结构化训练后层实现的。MOPD 架构没有将原始人类反馈混合到单一的奖励函数中，而是将训练后优化分离为三个独立、高度集中的专家集群。

  • 智能体专家 经过严格微调用于结构化执行，专精于精确的工具调用、多轮 API 参数解析以及避免执行停滞的自校正循环机制。
  • 推理专家 独立优化，以推进多跳逻辑、复杂的思维链工程、数学和高阶 STEM 问题解决。
  • 交互专家 完全专注于人类对齐、指令遵循细节、抑制幻觉的事实基础，并在不降低模型整体效用的情况下维持严格的安全护栏。

通过在训练后阶段分离这些向量，LongCat-2.0 防止了功能退化。动态门控路由机制随后在运行时无缝融合了这些专业化行为，使得最终模型能够同时协调深度推理、稳定的工具执行和安全的用户交互。

虽然在 FORTE 和 BrowseComp 等广泛的通用智能体基准测试中，LongCat-2.0 总体上落后于 Claude Opus 4.8 等高级前沿系统，但它在软件工程领域却表现出超常的实力。

这种开放权重架构的特殊之处在于其对自主开发的极度专注；它在严格的软件工程基准 SWE-bench Pro 上略微超过了 OpenAI 专有的 GPT-5.5（得分 59.5 对 58.6），证明尽管计算占用更少，但它在复杂编码任务方面具有高度能力和强劲的竞争力。

商业框架：按量付费 vs. 闪售 Token 包

美团的部署策略引入了一种专门的商业模式，将网络访问分为传统的实时 API 计费和结构化的“Token 包”。

对于传统的企业集成，提供标准的充值账户，根据 token 输入和生成指标直接实时扣除运营资金。

然而，为了适应自主开发智能体特有的不可预测的计算突发，美团推出了结构化的 Token 包框架。这些包作为固定的、一次性批量分配购买，在严格的 30 天窗口期内有效，可直接叠加在组织现有的基准 API 账户之上。

为了管理其 ASIC 集群的网络负载，美团每天四次通过限时闪售发布这些大批量包，时间精确在北京时间 10:00、16:00、21:00 和 23:00，先到先得。该框架的经济亮点是对上下文缓存命中进行零收费处理。

在大规模智能体环境中，编码助手必须在长时间的会话中反复读取、引用和修改同一个数百万 token 的代码库，标准架构会因为对重复的输入上下文收取全价而惩罚开发者。

在美团的基础设施下，只有缓存未命中的输入和最终的 token 生成才会消耗包配额。这种架构彻底改变了大规模智能体软件开发的运营成本经济学，实现了深度迭代上下文探索而不会产生复合成本。

许可：开源的结构性自由

通过以开源 MIT 许可证注册 LongCat-2.0 存储库，美团为该架构定位了最大的企业集成法律灵活性。

与 GNU 通用公共许可证（GPL）等 copyleft 范式形成对比——GPL 在法律上要求开发者将任何链接到该代码的衍生框架或内部软件开源——MIT 许可证允许近乎不受限制的自由。

对于企业工程团队来说，这一法律标准确保了 LongCat-2.0 可以被深度修改、编译并直接硬编码到闭源商业应用、专有开发工具和内部自动化后端中。

企业可以分叉该存储库，为私有数据库优化内部 LSA 机制，并将生成的软件堆栈出售给最终用户，而无需承担披露其专有知识产权或结构性增强的义务。

美团的演进：从外卖超级应用到 AI 巨头

美团由连续创业者王兴于 2010 年 3 月创立，最初是一家类似 Groupon 的每日优惠网站，随后迅速发展成为中国主导的“超级应用”之一。

在 2015 年与大众点评进行大规模合并后，这家总部位于北京的科技巨头巩固了其在中国城市配送走廊的主导市场份额，连接了本地消费者评论、即时零售、酒店预订和外卖。作为在香港证券交易所上市的巨头，美团拥有超过 7.7 亿年交易用户，并支持超过 1450 万商家的网络。

然而，面对激烈的国内市场竞争、严重的利润率压缩和不断下滑的利润率，该公司积极将战略转向物流以外的领域。美团公开承诺向人工智能和国产芯片能力投资“数十亿”，以振兴其技术驱动的产品。

这一进军全球 AI 竞赛的战略转变在 2025 年底随着 LongCat-Flash（一款 5600 亿参数的混合专家基础模型）的发布而开始显现，紧接着是高级推理模型 LongCat-Flash-Thinking。通过以对企业友好的许可证开源这些前沿级模型，美团表明了其成为全球 AI 基础设施基础参与者的雄心，而不仅仅是严格意义上的区域电商和外卖巨头。

企业影响：自主运营工作流

对于现代企业而言，LongCat-2.0 的发布解锁了在软件工程、系统运维和长文本数据解读方面明确的运营策略。

开放权重、MIT 许可的模型与 100 万 token 上下文窗口的结合，意味着组织可以绕过与托管专有第三方 API 相关的数据隐私问题和经常性开销。在大规模企业开发环境中，团队可以利用该模型专门的智能体专家来编排自主的代码库迁移。

工程师无需投入数百个开发小时来手动重写遗留应用框架，而是可以将整个企业代码库连同现代 SDK 文档直接传递到 100 万 token 的上下文窗口中。LongCat-2.0 可以映射依赖关系，执行代码库级别的结构更新，编译新代码库，并在生成最终拉取请求之前，在本地沙盒环境中自主捕获编译和执行错误。

通过 MOPD 门控路由机制实现的模型架构分离，为严格的企业合规性带来了显著优势。通过将特定的操作查询路由到隔离的专家集群，金融机构或医疗保健公司可以部署深度逻辑和数学推理过程，而不会冒产生事实幻觉或违反严格安全边界的风险。

交互专家充当隐式护栏层，在不降低内部推理专家原始处理能力的情况下抑制错误并强制执行指令遵循协议。结合零成本缓存模型，企业可以维持高度专注的自主软件网络，该网络可以反复检查企业数据池，以标准运营成本的一小部分持续维护和优化内部基础设施。
