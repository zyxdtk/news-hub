摘要

连续扩散模型的边缘分布可以由一个确定性常微分方程（ODE）复现，即概率流ODE，这为加速采样和一致性蒸馏奠定了基础。本文研究离散扩散模型是否存在类似的表述，并通过引入指数残差流（ERF）给出肯定回答。我们的框架为每个词元和位置增加一个连续残差变量来增强离散状态。这些残差根据分段定义的ODE确定性演化，其向量场依赖于当前离散状态以及指定扩散模型的前向和后向速率矩阵。当某个残差达到零时，离散状态发生改变。我们证明该构造保持了原始扩散的边缘分布。我们推导了采样器的实用离散化方案，并将其专门化到掩码扩散和均匀扩散。ERF的确定性轨迹支持一致性蒸馏，并在包括代码和文本生成任务在内的多种基准上取得了超越先前方法的实证改进。

1 引言

离散扩散模型已成为自回归模型的一个有力替代方案。通过允许多个位置并行更新，它们为实现更快的解码提供了途径（Lou等，2024；Sahoo等，2024），并可能实现更高效的引导和控制（Schiff等，2024）。在连续时间下，这些模型由前向和反向连续时间马尔可夫链描述（Campbell等，2022；Lou等，2024）。反向过程的标准模拟本质上是随机的：Gillespie算法在每次跳跃时抽取新的随机数（Gillespie，1977），而离散时间反向链的祖先采样同样依赖于随机转换（Shi等，2024；Sahoo等，2024；Hoogeboom等，2021；Schiff等，2024）。

这引出一个自然的问题：能否设计一个唯一随机性来自初始条件的离散扩散采样器，就像连续扩散模型的概率流ODE那样（Song等，2021b;a）？在有限状态空间上直接类比是不可能的，因为确定性映射无法分裂概率质量。因此需要在初始化时引入连续辅助随机性，特别是对于掩码扩散，其终端分布是狄拉克质量。现有辅助随机性的使用服务于不同目的。Sahoo等（2025）的投影高斯轨迹更多是一种重参数化，并未定义仅由当前离散状态驱动的确定性流。Gumbel蒸馏（Zhang等，2026）则使用Gumbel噪声从自回归教师构建用于并行解码的确定性训练目标，而非为离散扩散过程构建保持边缘分布的确定性流。

我们的贡献如下：

  • 我们的核心贡献是一种新的离散扩散模型确定性采样器，我们称之为指数残差流（ERF）。我们用称为残差的非负辅助变量增强状态，初始化为独立指数随机变量，每个词元和位置各一个。它们的演化由控制离散状态跳跃的离散动力学的前向和反向速率所确定的ODE支配。每当残差达到零时触发词元变化。与Gillespie第一反应构造（其中残差时钟在每次跳跃后刷新）不同，ERF继续确定性地演化所有剩余残差。因此，一旦采样了初始增强状态，就不再需要额外的随机性。我们证明这些增强动力学在每个时刻都保持原始CTMC的边缘分布。在每个固定时刻，残差保持为独立的标准指数随机变量，且与离散状态独立。所得过程通常不同于反向马尔可夫链，且不必是马尔可夫的。

  • 为使该构造适用于学习到的扩散模型，我们引入了一种新的数值积分方案，在每个采样区间冻结留一去噪器，同时保留转换速率已知的时间依赖性。我们为掩码和均匀扩散模型推导了显式公式，并证明当去噪器精确时，所得方案对因子化数据分布是精确的。

  • 我们在匹配的模型评估预算下将ERF与祖先采样进行比较，发现生成质量相当。ERF的确定性特性也使其直接适用于一致性蒸馏。我们利用这一特性训练少步学生模型，并在文本生成、代码生成和数独补全任务上评估所得的速度-质量权衡。

2 离散扩散模型背景

我们首先简要介绍离散扩散模型（Sahoo等，2024；Shi等，2024；Austin等，2021；Hoogeboom等，2021；Schiff等，2024）。这类生成模型构建一个随机过程，将简单参考分布p₁ := ∏_{ℓ=1}^L Cat(π_ℓ)（其中π∈(∆_K)^L）传输到目标数据分布p₀。为此，我们使用一个逐渐破坏数据分布的前向过程，最终将其转换为p₁。然后通过学习相应反向过程的近似来获得生成模型。

我们将前向过程考虑为连续时间马尔可夫链（CTMC）过程(Y_t){t∈[0,1]}，从p₀出发，转换概率q{t|s}(x_t|x_s) = ∏{ℓ=1}^L q^ℓ{t|s}(x^ℓ_t|x^ℓ_s)，其中x_s, x_t∈X，0≤s<t≤1，且

q^ℓ_{t|s}(x^ℓ_t|x^ℓ_s) = Cat(x^ℓ_t; α_{t|s}x̃^ℓ_s + (1−α_{t|s})π_ℓ), 0≤s<t≤1, (1)

其中x̃s表示x_s的独热编码，(α_t){t∈[0,1]}是单调噪声调度，满足α₀=1，α₁≈0，且α_{t|s}=α_t/α_s。该过程的时间反演通过反转时间方向获得，定义为过程(Y⁻t){t∈[0,1]}，在时间上向后，其中Y⁻t = lim{h↓0} Y_{t−h}。为便于记号，我们将Y⁻t记为X_t。由于对任意t有Y⁻_t=Y_t几乎必然成立，过程X_t具有边缘分布p_t，并且按构造将源分布p₁传输到目标p₀。此外，过程(X_t){t∈[0,1]}本身是具有转换概率

p_{s|t}(x_s|x_t) = Σ_{x₀} q_{s|0,t}(x_s|x₀, x_t) p_{0|t}(x₀|x_t), (2)

的CTMC，其中p_{0|t}(·|x_t)是去噪后验，q_{s|0,t}是给定(Y₀,Y_t)时Y_s的条件分布，其显式表达式在附录B中给出。在训练期间，这些反向转换使用由θ参数化的因子化模型学习：p^θ_{s|t}(x_s|x_t) := ∏{ℓ=1}^L p^{θ,ℓ}{s|t}(x^ℓ_s|x_t)。为获得推理的实用模型，我们考虑以下联合分布：

p^θ_{0:n}(x_{t_{0:n}}) = p₁(x_{t_n}) ∏{i=1}^n p^θ{s_i|t_i}(x_{s_i}|x_{t_i}), (3)

对应时间步选择0 = t₀ < ... < t_n = 1，为记号方便设s_i = t_{i−1}。文献中常用的参数化（Shi等，2024；Sahoo等，2024；Hoogeboom等，2021；Schiff等，2024）为p^θ_{s|t}(x_s|x_t) = q_{s|0,t}(x_s|x̂^θ₀(x_t,t), x_t)，其中q_{s|0,t}表示(17)中桥转换到单纯形值输入的扩展，x̂^θ₀表示取值于(∆_K)^L的神经网络。在下文中，我们不失一般性地假设它近似留一去噪器，其第ℓ个分量为(t,x_t) ↦ E[X̃^ℓ₀ | X^{−ℓ}_t = x^{−ℓ}_t]；见附录B。

速率矩阵和离散分数。 离散扩散的另一个有用视角是通过与前向和后向过程相关联的速率矩阵（Campbell等，2022；Sun等，2023；Lou等，2024）。与前向转换(1)相关联的速率矩阵对任意x,y∈X和t∈[0,1]为

Q_t(y|x) = Σ_{ℓ=1}^L 1_{y_{−ℓ}=x_{−ℓ}} Q^ℓ_t(y_ℓ|x_ℓ)，其中 Q^ℓ_t(y|x) = (−α̇_t/α_t)⟨ỹ, π_ℓ⟩(x≠y). (4)

这里x,y∈V，且Q^ℓ_t(x|x) = −Σ_{y≠x} Q^ℓ_t(y|x)对所有ℓ∈J1, LK。设(p_t){t∈[0,1]}表示(Y_t){t∈[0,1]}的边缘分布族，其转换概率由(1)给出，初始分布为p₀。根据定义，满足Kolmogorov方程（Feller，1940，定理1）：对t∈(0,1)和x,y∈X，

∂t p_t(y) = Σ{x∈X} Q_t(y|x)p_t(x). (5)

注意(1)中指定的前向转换q_{t|s}(·|x_s)是通过从时刻s的δ_{x_s}出发求解(5)获得的。与后向过程相关联的速率矩阵族为(Q̄t){t∈[0,1]}，其中Q̄_t对任意y≠x且p_t(x)>0满足

Q̄t(y|x) := p_t(y)/p_t(x) · Q_t(x|y) = Σ{ℓ=1}^L 1_{y_{−ℓ}=x_{−ℓ}} [p^ℓ_t(y_ℓ|x^{−ℓ}_t)/p^ℓ_t(x_ℓ|x^{−ℓ}_t)] Q^ℓ_t(x_ℓ|y_ℓ), (6)

其中Q̄t(x|x) := λ̄_t(x) = −Σ{y≠x} Q̄_t(y|x)。利用(2)、(5)和(6)中反向转换的定义，我们得到反向转换求解以下Kolmogorov方程：对任意x_t,y∈X，p_t(x_t)>0，

∂s p{s|t}(y|x_t) = −Σ_x Q̄s(y|x)p{s|t}(x|x_t)，p_{t|t}(y|x_t) = 1_{x_t=y}. (7)

3 通过指数残差流的确定性采样

在本节中，我们构造一个在单次随机初始化后轨迹确定性的采样器，其单时刻边缘分布与反向CTMC的一致。关键思想是用Gillespie第一反应方法中使用的指数变量增强离散状态，并用确定性的连续演化代替它们在跳跃时刻的重采样，得到算法1中描述的指数残差流采样器。

3.1 指数残差流

CTMC (X_t)_{t∈[0,1]}是分段常数且在随机时刻跳跃。我们首先介绍Gillespie算法，它允许精确模拟该CTMC。它使用定义随机跳跃时间的辅助指数随机变量模拟X_t的逐次跳跃。这些变量在X_t的轨迹中引入随机性，我们证明可以根据ODE改为回收初始指数变量。

Gillespie算法。 Gillespie的全局算法（Gillespie，1977）逐次跳跃地构造反向CTMC的分段常数轨迹。从X_t=x开始，它首先确定下一个向后跳跃时间τ<t，其中X_u=x对于u∈(τ,t]。为此，它抽取E∼Exp(1)并求解∫_τ^t λ̄_u(x)du = E。在时刻τ，轨迹通过改变单个词元跳跃：算法以概率Q̄^ℓ_τ(j|x)/λ̄_τ(x)选择位置ℓ∈[L]和新词元j≠x_ℓ。它设置X^ℓ_τ=j，保持所有其他位置不变，并从时间τ和状态X_τ重复；形式构造见附录C.1。

注意该构造有两个随机性来源：确定跳跃时间的指数抽取和确定词元变化的类别抽取。我们的目标是消除初始化之外的随机性。我们现在描述Gillespie的第一反应算法，它消除了类别抽取的需要（Gillespie，1977；Anderson，2007）。给定X_t=x，为每个位置ℓ∈[L]和词元j≠x_ℓ抽取独立变量E^ℓ_j∼Exp(1)，并从

∫_τ^{τ^ℓ_j} Q̄^ℓ_u(j|x)du = E^ℓ_j (8)

确定候选跳跃时间。从t向后遇到的下一个跳跃是这些跳跃时间中最大的，因此我们选择(ℓ⋆,j⋆)∈argmax_{(ℓ,j):j≠x_ℓ} τ^ℓ_j并设τ=τ^{ℓ⋆}_{j⋆}。轨迹在(τ,t]上保持等于x；在时刻τ，算法设置X^{ℓ⋆}_τ=j⋆，保持所有其他位置不变，并从时间τ和状态X_τ重复。该构造无需类别采样即可模拟反向CTMC，代价是每次跳跃抽取L(K−1)个独立同分布标准指数变量。

下一反应方法。 下一反应方法重用与未被选择的词元变化相关联的指数变量（Gibson & Bruck，2000；Anderson，2007；Durmus等，2021）。为理解这一点，我们可以将下一个跳跃的计算表示为连续演化。给定X_t=x，从E^ℓ_{t,j}=E^ℓ_j开始，同时根据dE^ℓ_{j,u}/du = Q̄^ℓ_u(j|x)演化所有变量j≠x_ℓ，时间向后演化。我们称这些演化中的变量为残差。第一个达到零的残差确定跳跃时间τ；其索引(ℓ⋆,j⋆)确定位置和新词元。这与对每对求解(8)并在第4行选择最大候选时间给出相同的跳跃。在整个演化过程中，离散状态保持等于x直到时刻τ，此时第12行设置X^{ℓ⋆}_τ=j⋆，保持所有其他位置不变。由无记忆性，其他词元变化的残差在给定离散轨迹的条件下是条件独立同分布标准指数变量，因此它们可以为新跳跃重用，只有达到零的残差需要重采样。我们使用该构造的一个变体，即算法1，为每个位置-词元对维护一个残差，在第1行初始化。j≠x_ℓ的残差是活跃的，在第6行更新。j=x_ℓ的残差是被动的，在第8行重采样。该变体在每次跳跃时需要L个独立同分布标准指数抽取。

指数残差流。 指数残差流（ERF）通过保持活跃残差的演化不变，并用确定性演化代替每次跳跃时L个被动残差的重采样来消除这剩余的随机性。在算法1中，这相当于保留第6行的活跃更新，并用第9行的确定性更新代替第8行的采样步骤。我们初始化(X₁,E₁)∼p₁⊗Exp(1)^{⊗(L×K)}。给定(X₁,E₁)，整个后续轨迹是确定性的。更精确地说，我们跟踪在每个位置对应于当前词元的残差E^ℓ_{t,j}，即j=x^ℓ_t，并以一定速率增加它们，而其他指数变量以不同速率减少并在达到零时触发跳跃。速率的选择是为了保持CTMC的边缘分布。

我们可以从算法推导出在[0,1]上定义的过程(X_t,E_t){t∈[0,1]}。算法在逐次跳跃时间(τ_k){k≥0}定义过程。然后，对任意k，在(τ_{k+1},τ_k]上，X_t保持等于X_{τ_k}，E_t求解ODE系统：

d/dt E^ℓ_{t,j} = { Q̄^ℓ_t(j|X_t), j≠X^ℓ_t; −λ^ℓ_t(X^ℓ_t), j=X^ℓ_t } (9)

我们称过程(X_t,E_t)_{t∈[0,1]}为指数残差流（ERF）过程。图1展示了一个具有三次连续跳跃的简单轨迹。

3.2 积分指数残差流

我们现在描述算法1的实用实现。对于y≠x，(6)中的反向速率通常近似为

Q̄^θ_t(y|x) := Σ_{ℓ=1}^L 1_{y_{−ℓ}=x_{−ℓ}} ⟨ỹ_ℓ, s^θ_t(x)_ℓ⟩ Q^ℓ_t(x_ℓ|y_ℓ), (11)

其中分数近似s^θ_t(x)_ℓ估计(6)右边的密度比（Lou等，2024）。然后我们必须估计第3-6行中这些近似反向速率的积分以及第9行中相关联的前向退出速率的积分。然而，精确积分可能在计算上具有挑战性或不可行。

为解决这个问题，大多数采样器为这些积分步骤引入离散化策略，并考虑网格0 = t₀ < ··· < t_n = 1。第一种选择是改编τ-leaping算法，通过在[s_i,t_i]上相继定义近似过程：给定X_{t_i}，(X_u){u∈[s_i,t_i]}是具有常数反向速率Q̄^θ_u(y;t_i|x) = Q̄^θ{t_i}(y|X_{t_i})的CTMC；更多细节在附录C.4中提供。另一种选择，鉴于反向速率的形式及其近似(11)，是仅冻结时刻t_i的分数近似，同时保留(4)中的前向速率Q^ℓ_u(y_ℓ|x_ℓ)，其时间积分具有闭式解，类似于（Conforti等，2025）。我们在这里开发一种不同的替代方案。首先，注意分数通过以下关系与留一去噪器相关：

⟨ỹ_ℓ, s^θ_t(x_t)ℓ⟩ = q{t|0}(y_ℓ|x̂^θ₀(x_t,t)ℓ) / q{t|0}(x^ℓ_t|x̂^θ₀(x_t,t)_ℓ) (12)

这一关系建议仅冻结时刻t_i的留一去噪器，因为如果我们将(12)代入(11)，对大多数感兴趣的模型，所得近似反向速率对时间的积分可以显式进行。这一选择的优点是，当留一预测器最优时，它对单个词元或因子化分布产生精确的采样器，与其他冻结策略相反；见附录C.5.2。

实用实现。 给定(X̂{t_i},Ê{t_i})，单个离散化步骤通过在[s_i,t_i]上应用算法1产生(X̂{s_i},Ê{s_i})，使用以下近似反向速率矩阵：

Q̄^θ_r(y;t_i|x) := Σ_{ℓ=1}^L 1_{y_{−ℓ}=x_{−ℓ}} [q^ℓ_{r|0}(y_ℓ|x̂^θ₀(X̂{t_i},t_i)_ℓ) / q^ℓ{r|0}(x_ℓ|x̂^θ₀(X̂_{t_i},t_i)_ℓ)] Q^ℓ_r(x_ℓ|y_ℓ), r∈[s_i,t_i] (13)

对于前向退出速率，我们保留原始速率(λ^ℓ_r){r∈[s_i,t_i]}。一般来说，离散化ERF需要通过在[s_i,t_i]上时间反转冻结反向过程获得的前向速率，而使用原始前向过程的速率（例如(4)）可能导致无限次跳跃。然而，对于留一冻结，(13)是从由x̂^θ₀(X̂{t_i},t_i)给出的因子化分布出发的原始前向过程在[s_i,t_i]上的精确时间反转。因此每个区间对该分布是精确的ERF步骤，且具有有限次跳跃；见附录C.5。

专门化到MDM和UDM。 在(13)中指定了部分冻结的反向速率矩阵后，我们现在将算法1第3-4行中跳跃时间的计算专门化到MDM和UDM。对于时刻r的当前状态X_r（r∈[s_i,t_i]）和每个活跃残差E^ℓ_{r,j}，候选时间通过求解∫^r_u Q̄^{θ,ℓ}v(j;t_i|X_r)dv = E^ℓ{r,j}关于u（算法1第3行）获得。对于MDM这是直接的，因为当X^ℓ_r=m时，

∫^r_u Q̄^{θ,ℓ}v(j;t_i|z)dv = x̂^θ₀(X{t_i},t_i)_{ℓj} log((1−α_r)/(1−α_u)) (14)

其候选时间通过求解u得到。未掩码位置不能跳跃，因此不计算其候选跳跃时间。然而，对于UDM，反向速率积分在u上不可显式反转，因此每个候选时间必须通过二分法近似。由于UDM可以在单个区间内产生许多跳跃，反复求解这些方程在计算上可能代价高昂。为控制这一成本，我们将每个区间分成k个子区间，并允许每个子区间中每个位置最多一次跳跃，在该跳跃后将所有残差推进到子区间边界；见附录C.5。为了同时减少跳跃次数和计算其时间的成本，我们利用不同的速率矩阵可以生成相同的边缘分布这一事实（Campbell等，2024; 2022；Gat等，2024），并使用净流反向速率（Zhang等，2023），对x≠y定义为

Q̄^NF_t(y|x) := [p_t(x)Q̄t(y|x) − p_t(y)Q̄_t(x|y)]+ / p_t(x) = −Σ_{ℓ=1}^L 1_{y_{−ℓ}=x_{−ℓ}} (α̇t/(Kα_t)) [p_t(y_ℓ|x^{−ℓ}_t)/p_t(x^ℓ_t|x^{−ℓ}_t) − 1]+ (15)

其中a₊ = max{a,0}，Q̄_t是规范的UDM速率矩阵。令人惊讶的是，UDM净流前向和后向速率是可处理的，它们的时间积分也是解析可逆的，这消除了跳跃时间的二分搜索需要，并大大提高了计算速度，正如我们在实验中展示的。所得更新在附录A中给出，净流构造在附录D中。

并行采样。 算法1跨位置顺序处理跳跃，因为跳跃可能改变反向速率。然而，对于具有留一冻结的MDM、UDM和均匀净流，位置ℓ的冻结反向速率Q̄^ℓ_t(y|z)仅通过z_ℓ依赖于当前状态z；见附录A和C.5。这意味着ℓ以外的位置变化不影响位置ℓ的反向速率和相关残差。因此，在[s_i,t_i]内，ERF动力学可以看作L个独立的单词元CTMC，不同位置可以并行处理，每个位置的跳跃顺序处理；见算法2。

4 蒸馏应用

与连续扩散情况一样（Salimans & Ho，2022；Song等，2023），确定性采样的一个应用是将教师扩散模型蒸馏为在少采样步下表现更好的学生模型。离散设置中缺乏概率流ODE的直接类似物经常被用作反对基于轨迹蒸馏的论据（Sahoo等，2025；Deschenaux & Gulcehre，2025；Zhang等，2023）。我们的指数残差流在增强状态(X_t,E_t)和(X_s,E_s)之间提供确定性传输，允许学生预测沿教师轨迹匹配。

一致性蒸馏。 我们遵循Song等（2023）的一致性蒸馏（CD）。从增强状态出发，学生预测教师轨迹在时刻0到达的干净离散状态，它不需要预测端点指数残差。我们训练其从同一轨迹上两点的预测达成一致。将Ψ^θ_{s|t}记为算法1的ERF传输，这些点满足(X_s,E_s) = Ψ^θ_{s|t}(X_t,E_t)（s<t）。在先前的方法中，Sahoo等（2025）通过在底层过程中使用相同的高斯噪声来耦合X_s和X_t。他们的构造在给定相同噪声的条件下是确定性的，但在仅给定X_t时转换仍然是随机的，这与CD中所需的要求相矛盾（见附录E.5）。相比之下，我们的方法从(X_t,E_t)确定性地产生(X_s,E_s)。

由于ERF在时刻0的输出由时刻t的增强状态唯一确定，一种朴素的方法是训练学生直接近似这一离散值映射。为使学习问题更易于处理，输出在每个位置被松弛为概率单纯形的元素。更精确地说，学生作为离散状态上的因子化分布：

p^ϕ_{0|t}(x₀|x_t,e_t) := ∏{ℓ=1}^L p^{ϕ,ℓ}{0|t}(x^ℓ₀|x_t,e_t)

对于当前参数ϕ和在优化期间保持固定的目标参数ϕ̄，我们考虑损失函数：

L_CD(ϕ;ϕ̄) = E[KL(p^ϕ̄{0|s}(·|X_s,E_s) ∥ p^ϕ{0|t}(·|X_t,E_t))], (16)

其中(X_t,E_t)∼p_t⊗Exp(1)^{⊗L×K}，(X_s,E_s) = Ψ^θ_{s|t}(X_t,E_t)，t从Unif(δ,1)采样，s=t−δ，其中δ是超参数。目标参数ϕ̄要么在每步后通过EMA更新，要么在一轮训练中冻结并在轮间刷新。如Song等（2023）所述，为使最小化器精确，我们需要施加边界条件p^ϕ_{0|0}(·|x₀,e₀) = δ_{x₀}并给s=0非零概率，以便在最优时，学生将其所有质量分配给ERF轨迹的干净端点。在时刻t的增强状态(X_t,E_t)上边缘化，这些端点具有分布p₀。在实践中，施加边界条件并未改善性能，因此我们不使用它，该条件的作用是从最小化器中移除平凡的常数解，但用教师初始化网络似乎足以达到非平凡解。我们还考虑有偏ERF采样器以从(X_t,E_t)获得(X_s,E_s)。在计算ERF速率时，我们不使用预训练的教师去噪器，而是使用冻结的学生。最后，对于UDM，我们在评估损失之前使用(32)将学生输出转换为去噪器类型预测。这是因为教师被训练为建模留一去噪器，而我们希望学生学习的内容更接近去噪器类型预测，因此这一转换至少在训练开始时消除了轻微的不匹配。固定教师和联合刷新程序分别在算法4和5中给出。

采样。 我们考虑离散状态的刷新和桥转换，分别为Σ_{x₀} q_{s|0}(x_s|x₀)p^ϕ_{0|t}(x₀|x_t,e_t)和Σ_{x₀} q_{s|0,t}(x_s|x₀,x_t)p^ϕ_{0|t}(x₀|x_t,e_t)，每次转换后独立抽取新的指数变量。当教师传输规定的增强边缘分布且学生学习其端点映射时，刷新是精确的。桥一般不精确，但在经验上表现良好。两种程序都在算法6中给出。

5 相关工作

CTMC采样和离散化。 Campbell等（2022）在连续时间中表述了离散扩散，将其采样与精确CTMC模拟（Gillespie，1977）和τ-leaping（Gillespie，2001）联系起来。修改的下一反应方法（Anderson，2007）在跳跃间保留积分速率时钟，但重射发射通道的指数阈值。ERF则在单次随机初始化后变为确定性的，在保持精确的单时刻CTMC边缘分布的同时回收残差，尽管通常具有不同的轨迹律。在实践中，我们仅在每个步骤冻结留一去噪器，同时保留速率的已知时间和状态依赖性，扩展了欧拉/τ-leaping式离散化。

离散扩散模型的确定性采样。 Zhang等（2023）引入净流速率(15)以减少概率流ODE离散类似物中的跳跃；见附录D，但所得过程仍然是随机的。Eyring等（2026）通过跨离散化步骤重用Gumbel噪声获得确定性轨迹，可能偏离目标分布。ERF则在初始化后给出确定性传输，同时精确保持单时刻边缘分布。

离散扩散模型的蒸馏。 蒸馏通过基于分布或轨迹的目标减少采样步数。D-MMD（Hoogeboom等，2026）使用离散矩匹配，而IDLM（Li等，2026）使用与分布匹配相关的路径空间KL目标（Yin等，2023）。两者都在学生样本上训练辅助去噪器。基于轨迹的方法建立在渐进蒸馏和一致性蒸馏之上（Salimans & Ho，2022；Song等，2023）：SDTT（Deschenaux & Gulcehre，2025）在随机去掩码步骤间聚合教师概率，而DCD（Sahoo等，2025）在具有共享干净状态和噪声的投影高斯轨迹上匹配预测。这些轨迹仍然是随机的，导致启发式或有偏的目标。以指数残差为条件反而使教师轨迹在给定(X_t,E_t)时是确定性的，从而在离散设置中实现一致性蒸馏。

6 实验

我们的实验首先研究ERF新联合律的经验后果，表明所得采样器在匹配的NFE下达到与标准祖先采样器相当的生成质量。然后我们表明ERF一致性蒸馏（ERC）使得能够以比教师模型更少的NFE进行有竞争力的生成。

一般设置。 我们考虑在OpenWebText（OWT；Gokaslan & Cohen，2019）和TinyGSM（Liu等，2023）上训练的掩码和均匀扩散模型，分别使用具有170M和168M参数的DDiT骨干。OWT生成是无条件的，序列长度为1,024；我们测量GPT-2 Large生成困惑度（Radford等，2019）以及1-gram熵。TinyGSM模型在512词元画布上生成Python解决方案，固定问题词元，我们在GSM8K（Cobbe等，2021）上评估答案准确率，使用全部1,319个测试问题进行采样比较，主蒸馏比较使用相同的前1,024个问题。对于采样，我们还评估了发布的指令微调DiffusionGemma模型，具有26B总参数和约4B活跃参数（Google DeepMind，2026），在MMLU-Pro（Wang等，2024）上。

7 结论

在这项工作中，我们表明离散扩散的规定边缘分布一旦用连续残差增强词元状态，就可以通过确定性动力学传输。该构造通过根据适当的ODE回收每次跳跃抽取的指数变量来推广Gillespie算法。这为一致性蒸馏提供了路径目标。在实践中，留一冻结保留了速率的解析已知时间依赖性，并对因子化数据是精确的。在评估的任务中，ERF在匹配的模型评估下达到与祖先更新相当的采样质量，其一致性目标在均匀扩散中产生了最明显的少步增益。

固定[s,t]=[s_i,t_i]并以X_{t_i}=x为条件。留一去噪器x̂^θ₀(x,t_i)在整个步骤中被缓存。设z为时刻r∈[s,t]的当前状态，u∈[s,r]为候选跳跃时间。活跃残差E^ℓ_{r,j}在从u到r的积分反向速率等于E^ℓ_{r,j}时穿过零；被动残差增加积分前向退出速率。更一般的冻结方案和推导在附录C.5和D中给出。

对于MDM，只有z_ℓ=m可以跳跃，且只能跳到j≠m。活跃和被动残差所需的积分为

∫^r_u Q̄^{θ,ℓ}v(j;t_i|z)dv = x̂^θ₀(x,t_i){ℓj} log((1−α_r)/(1−α_u)) (z_ℓ=m)，
∫^r_u λ^ℓ_v(z_ℓ)dv = 1_{z_ℓ≠m} log(α_u/α_r)。

如果x̂^θ₀(x,t_i){ℓj}>0且E^ℓ{r,j}≤x̂^θ₀(x,t_i)_{ℓj} log((1−α_r)/(1−α_s))，掩码位置的候选时间为

T^ℓ_j = α^{−1}(1−(1−α_r)exp(−E^ℓ_{r,j}/x̂^θ₀(x,t_i)_{ℓj}))，

否则T^ℓ_j=−∞。特别地，未掩码位置不可能发生进一步的活跃跳跃。净流不改变MDM速率。

对于具有净流的UDM和j≠z_ℓ，活跃和被动积分为

∫^r_u Q̄^{NF,θ,ℓ}v(j;t_i|z)dv = [x̂^θ₀(x,t_i){ℓj} − x̂^θ₀(x,t_i){ℓz_ℓ}]₊/(Kx̂^θ₀(x,t_i){ℓz_ℓ}−1) × log[(1+(Kx̂^θ₀(x,t_i){ℓz_ℓ}−1)α_u)/(1+(Kx̂^θ₀(x,t_i){ℓz_ℓ}−1)α_r)]，

∫^r_u b̂^{NF,ℓ}v(z)dv = Σ{j∈V{z_ℓ}}[x̂^θ₀(x,t_i){ℓz_ℓ} − x̂^θ₀(x,t_i){ℓj}]₊/(Kx̂^θ₀(x,t_i){ℓz_ℓ}−1) × log[(1+(Kx̂^θ₀(x,t_i){ℓz_ℓ}−1)α_u)/(1+(Kx̂^θ₀(x,t_i)_{ℓz_ℓ}−1)α_r)]。

这里b̂^{NF,ℓ}v(z)是位置ℓ的前向净流退出速率。当Kx̂^θ₀(x,t_i){ℓz_ℓ}=1时，每个除以Kx̂^θ₀(x,t_i){ℓz_ℓ}−1的对数商理解为α_u−α_r。如果x̂^θ₀(x,t_i){ℓj}>x̂^θ₀(x,t_i){ℓz_ℓ}且u=s处的活跃积分至少为E^ℓ{r,j}，其候选时间为

T^ℓ_j = α^{−1}([(1+(Kx̂^θ₀(x,t_i){ℓz_ℓ}−1)α_r)exp((Kx̂^θ₀(x,t_i){ℓz_ℓ}−1)E^ℓ_{r,j}/(x̂^θ₀(x,t_i){ℓj}−x̂^θ₀(x,t_i){ℓz_ℓ}))−1]/(Kx̂^θ₀(x,t_i)_{ℓz_ℓ}−1))。

当Kx̂^θ₀(x,t_i){ℓz_ℓ}=1时，这变为T^ℓ_j = α^{−1}(α_r+E^ℓ{r,j}/(x̂^θ₀(x,t_i){ℓj}−x̂^θ₀(x,t_i){ℓz_ℓ}))。当候选跳跃的所述条件不满足时，设T^ℓ_j=−∞。最大候选时间给出下一个跳跃。更新z后，使用相同的缓存去噪器重新计算残差积分。

对于0≤s0，位置间的条件独立性给出q_{s|0,t}(x_s|x₀,x_t) = ∏{ℓ=1}^L q^ℓ{s|0,t}(x^ℓ_s|x^ℓ₀,x^ℓ_t)。对于x₀,x_t∈X和满足q^ℓ_{t|0}(x^ℓ_t|x^ℓ₀)>0的位置ℓ，贝叶斯法则给出

q^ℓ_{s|0,t}(·|x^ℓ₀,x^ℓ_t) = Cat(·; [(α_{t|s}x̃^ℓ_t + (1−α_{t|s})⟨x̃^ℓ_t,π_ℓ⟩1_K) ⊙ (α_sx̃^ℓ₀ + (1−α_s)π_ℓ)] / [α_t⟨x̃^ℓ_t,x̃^ℓ₀⟩ + (1−α_t)⟨x̃^ℓ_t,π_ℓ⟩]), (17)

其中x̃^ℓ₀ = x̃{x^ℓ₀}，x̃^ℓ_t = x̃{x^ℓ_t}。对于ν∈∆K，我们通过将x^ℓ₀替换为ν来扩展该表达式，等价地设q^ℓ{s|0,t}(x^ℓ_s|ν,x^ℓ_t) = q^ℓ_{t|s}(x^ℓ_t|x^ℓ_s)q^ℓ_{s|0}(x^ℓ_s|ν)/q^ℓ_{t|0}(x^ℓ_t|ν)，其中q^ℓ_{r|0}(·|ν) = Cat(·;α_rν+(1−α_r)π_ℓ)。(17)中的分子具有非负项，其和为分母，因为α_{t|s}α_s = α_t。因此只要分母为正，该扩展就是概率向量。用任意概率向量补全零分母行并取位置乘积得到X上的随机反向转换矩阵；对于掩码扩散，我们在未掩码位置使用Cat(·;x̃^ℓ_t)。遵循Gourevitch等（2026，命题1），定义x̂^{loo}{0|t}(x_t)_ℓ := E[X̃^ℓ₀ | X^{−ℓ}_t = x^{−ℓ}_t]。先对X^{−ℓ}_t条件化再对X^ℓ_t条件化给出，只要p_t(x_t)>0，p^ℓ{s|t}(x^ℓ_s|x_t) = q^ℓ_{s|0,t}(x^ℓ_s|x̂^{loo}_{0|t}(x_t)_ℓ, x^ℓ_t)。因此将留一去噪器代入单纯形扩展恢复精确的位置反向条件概率，其乘积给出(3)中使用的因子化近似。

C.1 精确模拟算法的形式构造

C.1.1 Gillespie第一反应形式

Gillespie的第一反应形式（Gillespie，2001）可用于使用反向速率矩阵(Q̄u){u∈[s,t]}从X_t∼p_t向后模拟(X_u)_{u∈[s,t]}。我们按以下方式顺序定义跳跃时间和状态直至最大（随机）跳跃数N∞。

初始化。 设T⋆₀=t，N∞=∞，独立抽取X_{T⋆₀}∼p_t，且对每个(ℓ,j)∈J1,LK×J1,KK，E^ℓ_{j,T⋆₀}∼Exp(1)。

归纳。 在阶段k≥0，给定当前跳跃时间T⋆k、状态X{T⋆k}和每个(ℓ,j)∈J1,LK×J1,KK的指数时钟E^ℓ{j,T⋆_k}，定义

T^{ℓj}{k+1} = sup{u∈[s,T⋆_k] : ∫^{T⋆_k}_u Q̄^ℓ_r(j|X{T⋆k})dr ≥ E^ℓ{j,T⋆k}}，(ℓ⋆{k+1},j⋆{k+1})∈argmax{(ℓ,j)} T^{ℓj}_{k+1} (18)

我们使用约定sup∅=−∞。

  • 如果T^{ℓ⋆{k+1}j⋆{k+1}}{k+1}=−∞，程序停止，设N∞=k且X_s=X{T⋆_k}。
  • 否则，第(k+1)次跳跃发生在T⋆{k+1}=T^{ℓ⋆{k+1}j⋆{k+1}}{k+1}。设X^{ℓ⋆{k+1}}{T⋆{k+1}}=j⋆{k+1}，保持所有其他位置不变。对每个满足X^ℓ_{T⋆k}≠j的(ℓ,j)，设E^ℓ{j,T⋆{k+1}} = E^ℓ{j,T⋆k} − ∫^{T⋆_k}{T⋆{k+1}} Q̄^ℓ_r(j|X{T⋆k})dr ≥ 0。最后，独立于过去抽取E^{ℓ⋆{k+1}j⋆{k+1}}{T⋆_{k+1}}∼Exp(1)。

递归持续直到s之前没有候选事件发生。在适当条件下（见Feinberg等（2013）的讨论），N几乎必然有限，算法产生轨迹(X_u)_{u∈[s,t]}，其律为给定X_t=x条件下反向CTMC的律。

C.1.2 ERF采样器

ERF为每个位置ℓ和词元j用一个非负残差E^ℓ_{j,u}增强X_u。我们如下构造(X_u,E_u)_{u∈[s,t]}。

初始化。 设T⋆₀=t，抽取X_{T⋆₀}∼p_t，并对所有(ℓ,j)∈J1,LK×J1,KK独立于X_{T⋆₀}抽取E^ℓ_{j,T⋆₀}独立同分布∼Exp(1)。

归纳。 在阶段k≥0，给定(T⋆k, X{T⋆k}, E{T⋆k})，记z=X{T⋆_k}。对每个j≠z_ℓ，定义候选时间

T^{ℓj}{k+1} = sup{u∈[s,T⋆_k] : ∫^{T⋆_k}_u Q̄^ℓ_r(j|z)dr ≥ E^ℓ{j,T⋆k}}，(ℓ⋆{k+1},j⋆{k+1})∈argmax{(ℓ,j):j≠z_ℓ} T^{ℓj}_{k+1} (19)

设T⋆{k+1}=T^{ℓ⋆{k+1}j⋆{k+1}}{k+1}。

  • 如果T⋆_{k+1}=−∞，程序停止。设N=k，对v∈[s,T⋆_k]保持X_v=z，并通过(20)更新该区间上的残差。
  • 否则，对v∈(T⋆{k+1},T⋆_k]保持X_v=z，且对每个v∈[T⋆{k+1},T⋆_k]，通过

E^ℓ_{j,v} = E^ℓ_{j,T⋆_k} + {−∫^{T⋆_k}_v Q̄^ℓ_r(j|z)dr, j≠z_ℓ; ∫^{T⋆_k}_v λ^ℓ_r(z_ℓ)dr, j=z_ℓ} (20)

演化所有残差。设X^{ℓ⋆{k+1}}{T⋆{k+1}}=j⋆{k+1}，且对m≠ℓ⋆{k+1}，X^m{T⋆_{k+1}}=z^m。

递归持续直到s之前没有候选事件发生。

C.1.3 Gillespie全局形式

Gillespie算法的全局形式（Gillespie，1977）每次跳跃使用一个指数时钟。如上，它从X_t∼p_t向后构造(X_u)_{u∈[s,t]}。

初始化。 设T⋆₀=t并抽取X_{T⋆₀}∼p_t。

归纳。 在阶段k≥0，给定(T⋆k, X{T⋆k})，记z=X{T⋆k}，设λ̄_r(z) := Σ{ℓ=1}^L Σ_{j:j≠z_ℓ} Q̄^ℓ_r(j|z)，独立于过去抽取E_k∼Exp(1)，并设

T⋆_{k+1} = sup{u∈[s,T⋆_k] : ∫^{T⋆_k}_u λ̄_r(z)dr ≥ E_k} (21)

  • 如果T⋆_{k+1}=−∞，程序停止，设N=k且X_u=z对u∈[s,T⋆_k]。
  • 否则，在满足j≠z_ℓ的对中按概率Q̄^ℓ_u(j|z)/λ̄u(z)抽取(ℓ⋆{k+1},j⋆{k+1})。对v∈(T⋆{k+1},T⋆k]设X_v=z，设X^{ℓ⋆{k+1}}{T⋆{k+1}}=j⋆_{k+1}，保持其他位置不变，继续递归。

在与第一反应构造相同的非爆炸条件下，这在[s,t]上定义反向CTMC。

C.2 具有部分冻结速率的Gillespie离散化

具有时间非齐次Gillespie动力学的精确模拟需要积分时间相关转换速率并在每次单位置跳跃后重新评估其学习分量。为减少神经函数评估次数，考虑网格0=t₀<···<t_n=1，s_i:=t_{i−1}，以及3.2节引入的部分冻结反向速率矩阵Q̄_r(·;t_i|·)。在每个区间[s_i,t_i]上，我们用学习到的神经网络Q̄^θ_r(·;t_i|·)近似它，使用模型的单次前向传播，并可冻结与ERF相同的分量：完整速率矩阵、分数、去噪器或留一去噪器。注意该离散化与ERF采样器的离散化几乎相同，但Gillespie离散化比ERF提供稍多的灵活性，因为它不需要与近似冻结后向速率相关联的前向速率。对该近似速率矩阵应用第一反应构造得到算法3。

C.3 留一冻结Gillespie与祖先采样的等价性

固定[s,t]=[s_i,t_i]，X_t=x，且p̂^ℓ_i := x̂^θ₀(x,t)_ℓ。(3)中使用桥扩展(17)的转换为

p^θ_{s|t}(w|x) = ∏{ℓ=1}^L q^ℓ{s|0,t}(w_ℓ|p̂^ℓ_i,x_ℓ) = ∏{ℓ=1}^L [q^ℓ{s|0}(w_ℓ|p̂^ℓ_i)q^ℓ_{t|s}(x_ℓ|w_ℓ)]/q^ℓ_{t|0}(x_ℓ|p̂^ℓ_i) (22)

对于r∈[s,t]和y≠z_ℓ，通过冻结留一去噪器得到的近似速率为

Q̄^{θ,ℓ,loo}r(y;t_i|z) = Q^ℓ_r(z_ℓ|y_ℓ) q^ℓ{r|0}(y_ℓ|p̂^ℓ_i)/q^ℓ_{r|0}(z_ℓ|p̂^ℓ_i) (23)

由于q^ℓ_{r|0}(y_ℓ|p̂^ℓ_i)恰好是从Cat(p̂^ℓ_i)初始化并用Q^ℓ_r(z_ℓ|y_ℓ)演化的单词元CTMC在时刻r的边缘分布，(23)恰好是该过程的时间反转速率。因此我们知道从时刻t的x_ℓ到时刻s的w_ℓ的转换具有闭式：

q^ℓ_{s|0}(w_ℓ|p̂^ℓ_i)q^ℓ_{t|s}(x_ℓ|w_ℓ)/q^ℓ_{t|0}(x_ℓ|p̂^ℓ_i) = q^ℓ_{s|0,t}(w_ℓ|p̂^ℓ_i,x_ℓ)。

冻结速率跨位置独立作用。因此在完整联合分布上，精确Gillespie采样给出

∏{ℓ=1}^L q^ℓ{s|0,t}(w_ℓ|p̂^ℓ_i,x_ℓ) = p^θ_{s|t}(w|x)。

因此，所提出的具有留一冻结速率的Gillespie算法离散化等价于离散时间设置中使用的标准祖先采样。当冻结分数或普通去噪后验时，一般不成立相同结论。

C.4 欧拉和类别τ-leaping

词元级欧拉。 词元级欧拉冻结速率矩阵的状态和时间依赖性，有效地条件独立地抽取位置。对每个ℓ，其类别概率为

P(X^ℓ_s=y|X_t=x) = { hQ̄^{θ,ℓ}_t(y|x), y≠x_ℓ; 1+hQ̄^{θ,ℓ}_t(x_ℓ|x), y=x_ℓ } (24)

只要hΣ_{y≠x_ℓ} Q̄^{θ,ℓ}_t(y|x)≤1对每个位置ℓ成立，该步骤有效。

类别τ-leaping。 类别τ-leaping使用相同的冻结速率但对这些冻结速率精确求解Kolmogorov直到第一次跳跃。独立抽取

N^{ℓy}_i ∼ Poisson(hQ̄^{θ,ℓ}_t(y|x))，ℓ∈J1,LK，y≠x_ℓ (25)

如果Σ_{y≠x_ℓ}N^{ℓy}i=1，位置ℓ设为唯一使N^{ℓy}_i=1的y，否则保持等于x_ℓ。等价地，设λ̄^{θ,ℓ}_t(x) := Σ{y≠x_ℓ} Q̄^{θ,ℓ}_t(y|x)，更新概率为P(X^ℓ_s=y|X_t=x) = hQ̄^{θ,ℓ}_t(y|x)exp{−hλ̄^{θ,ℓ}_t(x)}对y≠x_ℓ，剩余质量分配给x_ℓ。

C.5 MDM和UDM的显式部分冻结更新

除了(11)中的分数表示，(6)中的密度比还满足恒等式

p^ℓ_t(w_ℓ|x^{−ℓ})/p^ℓ_t(x_ℓ|x^{−ℓ}) = Σ_{x⁰∈V} [q^ℓ_{t|0}(w_ℓ|x⁰)/q^ℓ_{t|0}(x_ℓ|x⁰)] p^ℓ_{0|t}(x⁰|x), (26)

p^ℓ_t(w_ℓ|x^{−ℓ})/p^ℓ_t(x_ℓ|x^{−ℓ}) = q^ℓ_{t|0}(w_ℓ|x̂^{loo}{0|t}(x)_ℓ)/q^ℓ{t|0}(x_ℓ|x̂^{loo}_{0|t}(x)_ℓ) (27)

这些恒等式建议三种冻结方案：冻结(11)中的分数、(26)中的去噪器或(27)中的留一去噪器。我们在下面给出其显式形式。

MDM。 由于π_ℓ=m，(4)给出对y≠z_ℓ有Q^ℓ_v(z_ℓ|y)=(−α̇v/α_v)1{z_ℓ=m}。因此(6)只允许从z_ℓ=m到y≠m的反向跳跃。在分数冻结下，速率及其积分为

Q̄^{θ,ℓ}v(y;t_i|z) = ⟨ỹ,s^θ{t_i}(X_{t_i})ℓ⟩(−α̇_v/α_v)，
∫^r_u Q̄^{θ,ℓ}_v(y;t_i|z)dv = ⟨ỹ,s^θ{t_i}(X_{t_i})_ℓ⟩log(α_u/α_r)。

在去噪后验冻结下，它们为

Q̄^{θ,ℓ}v(y;t_i|z) = p^{θ,ℓ}{0|t_i}(y|X_{t_i})(−α̇v/(1−α_v))，
∫^r_u Q̄^{θ,ℓ}_v(y;t_i|z)dv = p^{θ,ℓ}{0|t_i}(y|X_{t_i})log((1−α_r)/(1−α_u))。

C.5.1 从积分速率到跳跃更新

对每个候选转换(ℓ,y)，跳跃时间T^{ℓy}是∫^r_{T^{ℓy}} Q̄^{θ,ℓ}v(y;t_i|z)dv = E^ℓ{r,y}在[s,r]中的最大解(28)。如果[s,r]上的积分速率小于E^ℓ_{r,y}，设T^{ℓy}=−∞。MDM和UDM跳跃时间更新如下。

MDM的闭式更新。 所有活跃速率共享相同的时间相关因子，因此我们选择最小的归一化残差并评估一次α^{−1}。在本段中，零分母的商理解为+∞。在分数冻结下，选择(ℓ̂,ŷ)∈argmin_{ℓ:z_ℓ=m, y≠m} E^ℓ_{r,y}/⟨ỹ,s^θ_{t_i}(X_{t_i})ℓ⟩。如果最小值超过log(α_s/α_r)，s之前不发生转换。否则，选定的转换在单一时刻发生：T⋆ = α^{−1}(α_r exp(E^{ℓ̂ŷ}{r,y}/⟨ŷ,s^θ_{t_i}(X_{t_i}){ℓ̂}⟩))。对于去噪后验冻结，选择和反演具有附录A中的形式，其缓存去噪器概率替换为p^{θ,ℓ}{0|t_i}(y|X_{t_i})。在MDM中，留一和标准去噪器在掩码位置一致。

UDM的求根。 分数冻结UDM候选时间也是显式的。(ℓ,y)的候选时间在⟨ỹ,s^θ_{t_i}(X_{t_i})ℓ⟩/K·log(α_s/α_r) ≥ E^ℓ{r,y}时位于[s,r]，且当其系数为正时，T^{ℓy} = α^{−1}(α_r exp(KE^ℓ_{r,y}/⟨ỹ,s^θ_{t_i}(X_{t_i})ℓ⟩))。对于去噪后验和留一去噪器冻结，(28)一般无闭式解，因此我们用二分法求解方程。如果[s,r]上的积分速率达到E^ℓ{r,y}，反复二分[s,r]：在中点m，当∫^r_m Q̄^{θ,ℓ}v(y;t_i|z)dv ≥ E^ℓ{r,y}时用m替换下端点，否则用m替换上端点。积分在m中连续且非增，因此保留的区间收敛到最大解。

C.5.2 因子化下留一冻结的精确性

假设数据分布跨位置因子化，并记p^ℓ₀ := E[X̃^ℓ₀]∈∆K为其第ℓ个边缘。由于前向过程也跨位置独立作用，其边缘在每个时刻r保持因子化，第ℓ个边缘为q^ℓ{r|0}(·|p^ℓ₀)。独立性于是给出对每个r和z，x̂^{loo}_{0|r}(z)_ℓ = E[X̃^ℓ₀ | X^{−ℓ}_r = z^{−ℓ}] = p^ℓ₀。因此在最优时，缓存的留一预测独立于端点和演化中的离散状态。如果z和w仅在位置ℓ不同，留一冻结速率因此满足

Q̄^{θ,loo}r(w;t_i|z) = Q^ℓ_r(z_ℓ|w_ℓ) q^ℓ{r|0}(w_ℓ|p^ℓ₀)/q^ℓ_{r|0}(z_ℓ|p^ℓ₀) = Q̄_r(w|z) (29)

因此部分冻结生成器在每个离散化区间中都是精确的反向生成器，其精确积分不引入离散化误差。单词元情况是L=1的特例：条件化上下文为空，因此留一预测就是数据分布p₀。

其他潜在的冻结速率公式（分数冻结和去噪器冻结）在附录C.5中给出：它们保留s^θ_{t_i}(x)ℓ或p^{θ,ℓ}{0|t_i}(·|x)作为r和当前状态变化。它们在p₀因子化时不具有相同的精确性。例如，考虑具有均匀参考分布和p₀(1)=ρ∈(0,1){1/2}的单位置二值UDM。由于p_r(1)=α_rρ+(1−α_r)/2，其精确分数比和去噪后验满足⟨2̃,s_r(1)1̃⟩ = p_r(2)/p_r(1)，p¹_{0|r}(1|1) = ρ(1+α_r)/(2p_r(1))。两者都随α_r变化，因此将它们在t的缓存值代入速率公式一般不同于r<t时的精确反向速率。对于MDM，掩码位置处的普通后验等于留一后验；在因子化下两者都等于p^ℓ₀，因此去噪器冻结在那里也是精确的。

C.5.3 分数冻结的反例

我们现在表明，在保持原始前向速率的同时为ERF程序冻结分数可能导致有限时间内无限次跳跃。考虑具有一个位置、两个词元和调度α_t=exp(−2t)的UDM。原始前向速率是常数且满足Q_t(2|1)=Q_t(1|2)=1。在时刻t_i=1/10和状态X_{t_i}=1处冻结分数，缓存值s_{t_i}(1)=(1,2)。UDM中的分数冻结速率为Q̄^θ_t(2;t_i|1)=2，Q̄^θ_t(1;t_i|2)=1。然而ERF保留等于1的原始前向退出速率作为任一词元中的被动速度。这些活跃和被动速度不相容：如果冻结反向速率是某个正律q_t下原始前向速率的时间反转，两个方向将同时要求q_t(2)/q_t(1)=2和q_t(1)/q_t(2)=1。

设(E¹¹_{t_i},E¹²_{t_i})=(A,B)，A和B为独立Exp(1)变量。从X_{t_i}=1出发并记S:=A+B/2，第一次跳跃在向后经过时间B/2后发生，并在词元2中留下残差对。再经过时间S后，过程返回1且残差为(0,S)。更一般地，从具有残差(0,R)的1出发，双跳跃循环耗时R并返回具有残差(0,R/2)的1。因此相继循环的持续时间为S, S/2, S/4, ...，无限次跳跃累积在T_acc = B/2 + S + Σ_{n=0}^∞ S/2^n = 3A+2B < ∞ (30)。对每个h>0，事件3A+2B0。因此爆炸在任何正长度区间上以正概率发生，而具有相同有界冻结反向速率的Gillespie采样是非爆炸的。

问题不在于分数近似，缓存分数可以是总体最优的。实际上，选择p₀(1)=1/2−exp(1/5)/6，p₀(2)=1/2+exp(1/5)/6。则p_{t_i}(1)=1/3且p_{t_i}(2)=2/3，因此1处的精确分数为(1,2)。在X_{t_i}=1条件下，分数冻结ERF在事件3A+2B<t_i上于时刻零之前爆炸，该事件具有正概率。

C.5.4 为什么留一冻结不会发生爆炸

我们现在表明留一冻结不会发生相同现象。关键思想是证明(13)中的留一冻结反向生成器实际上是从时刻0的不同律出发的原始前向生成器的精确时间反转。因此定理I.1适用，不可能有无限次跳跃。设p̂^ℓ_i := x̂^θ₀(X_{t_i},t_i)ℓ（ℓ∈J1,LK），定义乘积律p̂{r|i}(z) := ∏{ℓ=1}^L q^ℓ{r|0}(z_ℓ|p̂^ℓ_i)。每个因子是从p₀=∏{ℓ=1}^L p̂^ℓ_i出发的原始前向过程的边缘，因此p̂{r|i}是以原始前向速率从p̂i出发的CTMC的边缘。如果z和w仅在位置ℓ不同，则(13)变为Q̄^{θ,loo}_r(w;t_i|z) = p̂{r|i}(w)/p̂{r|i}(z)·Q_r(z|w)。因此冻结反向速率是p̂{r|i}下原始前向速率的时间反转，前向退出速率λ^ℓ_r(z_ℓ)是ERF使用的被动速度。

固定缓存预测和前向与冻结反向速率有限且连续且p̂_{r|i}(z)>0对所有r∈[s,t]和z∈X成立的区间[s,t]。设B_i(z)为使得从(X_t,E_t)=(z,e)出发的ERF在[s,t]上发生无限次跳跃的e∈(0,∞)^{LK}的集合。由定理3.1，

0 = Σ_{z∈X} p̂_{t|i}(z)Exp(1)^{⊗LK}(B_i(z))。

每个B_i(z)具有Lebesgue测度零，因为p̂{t|i}(z)>0且指数密度在(0,∞)^{LK}上为正。在实际运行中，给定缓存预测的X_t条件律可能不同于p̂{t|i}。如果给定X_t=z和这些预测的E_t条件律对每个z具有密度，流仍然是非爆炸的：它给每个B_i(z)分配零概率。因此分数冻结示例中具有正Lebesgue测度的爆炸残差集合在这里不可能发生。

D.1 净流构造及与先前工作的关系

相关的分解是由反向速率诱导的概率流而非速率本身的分解。假设p_t(x)>0，对x≠w定义

F_t(x,w) := p_t(x)Q̄_t(w|x)，S_t(x,w) := [F_t(x,w)+F_t(w,x)]/2，J_t(x,w) := F_t(x,w)−F_t(w,x)。

这里S_t是无序对{x,w}上的对称流量，J_t是其反对称电流。使用Q̄t(x|x) = −Σ{w≠x} Q̄_t(w|x)，反向Kolmogorov方程变为

∂t p_t(x) = −Σ_w p_t(w)Q̄_t(x|w) = Σ{w≠x}[F_t(x,w)−F_t(w,x)] = Σ_{w≠x}J_t(x,w)。

因此边缘演化仅依赖于J_t：对称项S_t在两个方向上贡献相等并在每个差F_t(x,w)−F_t(w,x)中抵消。保持相同电流同时禁止两个方向的同时流动唯一地给出F^NF_t(x,w) = [J_t(x,w)]₊。将该流除以其源处的质量得到

Q̄^NF_t(w|x) := [J_t(x,w)]₊/p_t(x) = [p_t(x)Q̄_t(w|x)−p_t(w)Q̄_t(x|w)]₊/p_t(x)，

对角项选择使每行和为零。由于a₊−(−a)₊=a，净流速率保持J_t从而保持Kolmogorov方程，同时Q̄^NF_t(w|x)Q̄^NF_t(x|w)=0。此外，任何具有差J_t(x,w)的非负反向流对的总流量至少为|J_t(x,w)|，净流构造取等号。因此它是具有相同成对电流的最小活动生成器。

时间反演恒等式给出p_t(w)Q̄_t(x|w)=p_t(x)Q_t(w|x)，从而Q̄^NF_t(w|x) = [Q̄_t(w|x)−Q_t(w|x)]₊。

类似的构造出现在Campbell等（2024）中，但两个构造不等价，我们的构造导致一个随机性更小的过程。记Q̄^{X₀}_t(·|·)为以干净端点为条件的反向生成器。Campbell等（2024）条件地应用净流然后在X₀的后验下平均，而我们先形成无条件生成器再应用净流。因此，对x≠w，两个速率分别为E[Q̄^{NF,X₀}_t(w|x)|X_t=x]和Q̄^NF_t(w|x)，它们一般不相等，因为净流投影中的正部操作不与平均交换。更精确地，其凸性给出Q̄^NF_t(w|x) ≤ E[Q̄^{NF,X₀}_t(w|x)|X_t=x]。当不同干净端点在x和w之间诱导相反电流时，不等式严格。因此我们的无条件净流生成器对任何转换不具有更大的非对角速率，从而不具有更大的总跳跃强度，同时诱导相同的边缘演化。有趣的是，在平均条件构造后再次应用净流可恢复我们的生成器。

D.2 前向净流速率和被动残差

ERF需要与所选反向生成器相关联的前向速率来演化其被动残差。对于严格正边缘和精确规范速率，时间反演给出，对x≠w，

Q^NF_t(w|x) := p_t(w)/p_t(x)·Q̄^NF_t(x|w) = [Q_t(w|x)−Q̄_t(w|x)]₊ (31)

实际上，代入(15)给出[p_t(w)Q̄_t(x|w)−p_t(x)Q̄_t(w|x)]₊/p_t(x)，规范时间反演恒等式将其第一项化为Q_t(w|x)。对角项是相应行和的负值。因此两个净流生成器都通过以相反顺序相减规范前向和反向速率并取正部获得；不需要额外的模型或密度评估。

对位置ℓ，被动速度因此必须替换为b̂^{NF,ℓ}t(x) := Σ{w:w_{−ℓ}=x_{−ℓ},w_ℓ≠x_ℓ} Q^NF_t(w|x)。其留一冻结积分和跳跃时间在附录A中给出。

D.3 UDM净流的分数和去噪后验冻结

固定[s,t]=[s_i,t_i]，在x=X_{t_i}处缓存学习输出，设z为时刻r∈[s,t]的当前配置。对y≠z_ℓ，原始UDM前向速率为−α̇_v/(Kα_v)。对附录C.5中的冻结规范速率应用正部投影给出以下非对角速率。在分数冻结下，位置ℓ的投影反向速率和互补被动前向退出速率为

Q̄^{NF,θ,ℓ}v(y;t_i|z) = (−α̇_v/(Kα_v))[⟨ỹ,s^θ{t_i}(x)ℓ⟩−1]₊，
b̂^{NF,ℓ}_v(z) = (−α̇_v/(Kα_v))Σ{y∈V{z_ℓ}}[1−⟨ỹ,s^θ_{t_i}(x)_ℓ⟩]₊。

在去噪后验冻结下，相应速率为

Q̄^{NF,θ,ℓ}v(y;t_i|z) = −α̇_v[p^{θ,ℓ}{0|t_i}(y|x)/(1−α_v) − p^{θ,ℓ}{0|t_i}(z_ℓ|x)/(1+(K−1)α_v)]₊，
b̂^{NF,ℓ}_v(z) = −α̇_vΣ{y∈V{z_ℓ}}[p^{θ,ℓ}{0|t_i}(z_ℓ|x)/(1+(K−1)α_v) − p^{θ,ℓ}{0|t_i}(y|x)/(1−α_v)]₊。

每个被动速度是y≠z_ℓ上正部补[Q^ℓ_v(y|z_ℓ)−Q̄^{θ,ℓ}_v(y;t_i|z)]₊的和，如(31)中所示。对角项是相应行和的负值。分数冻结速率直接积分。
