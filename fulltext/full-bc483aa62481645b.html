**情况 A：信息性邻域探索** 如果 VLM 反馈表明当前方面 $r \in \mathcal{M}$ 在“验证”阶段证据不足（例如，“缺少关键词”），我们推断目标事件很可能位于当前锚点的时间或语义邻域内。因此，我们从亲和图中的未访问邻居中选择下一个锚点 $i^{\star(t)}$，优先选择与当前信念状态连接较强的节点： $i^{\star(t)}\leftarrow\operatorname*{arg\,max}_{j\in\mathcal{U},\,\tilde{W}_{i^{\star}j}>0}\left(\tilde{W}_{i^{\star}j}\cdot F^{(t-1)}_{j}\right)$, (6) 其中 $\mathcal{U}$ 表示未访问段的集合。

Case B: 全局间隙填充。 相反，如果语义面 $ r $ 的证据得到确认，我们将其从集合 $ \mathcal{M} $ 中移除。一旦所有语义面均成功解决（即 $ \mathcal{M} = \emptyset $），且迭代预算仍有剩余，我们切换至全局探索策略，以发现潜在的盲点。我们贪婪地选择具有最高全局信念得分的未访问节点 $ i^{\star(t)} $： $$ i^{\star(t)} = \operatorname*{arg\,max}_{i} \left( F^{(t-1)}_{i} \cdot (1 - v^{(t-1)}_{i}) \right), \quad (7) $$ 其中 $ v^{(t-1)}_{i} \in \{0,1\} $ 是一个二值掩码，用于指示节点 $ i $ 是否已被访问。该机制确保了那些被特定语义面搜索遗漏的有前景区域最终能够被捕捉到。

3.3.2 验证：多模态证据提取与相关性评分。 对于每个选定的锚点节点 $ i $，我们执行验证操作，检查观测到的片段是否覆盖了从语义面中提取出的关键词，并计算锚点的相关性得分。我们提取一个多源证据集 $ \mathcal{E}_{i} = \{e_{i}^{\mathrm{cap}},\,e_{i}^{\mathrm{ocr}},\,e_{i}^{\mathrm{asr}}\} $： (1) 我们利用视觉语言模型（VLM）执行双重任务：生成详细的场景描述，同时验证其与当前语义面的一致性，若语义面 $ \mathcal{K}_{r} $ 中的关键词 $ x $ 未在视觉内容中被观测到，则显式输出“missing keywords $ x $”。

视觉内容； (2) 我们通过 EasyOCR（JaidedAI, 2023）提取屏幕上的文本； (3) 我们使用 Whisper（Radford et al., 2023）对预生成的语音转录文本进行对齐。

**相关性评分。** 由于关键线索分布在视觉、文本和声学通道中，单一模态的观测通常不足以提供完整信息。我们提取一个多源证据集 $E = \{e_{cap}, e_{ocr}, e_{asr}\}$。对于每个证据项 $e \in E$，我们设计了一种“源感知”的评分机制来衡量其相关性。

**词汇相似性。** 我们使用证据文本与关键词之间的 IDF 加权词汇重叠分数来计算词汇相似性： $$ s_{\mathrm{lex}}(e,f_{r})=\min\left(1,\frac{\sum_{t\in e\cap\mathcal{K}_{r}}\mathrm{IDF}(t)}{Z_{\mathrm{lex}}}\right), $$ 其中 $Z_{\mathrm{lex}}$ 是归一化常数（见附录 E.4）。

**语义相似性。** 我们使用文本编码器 $\psi(\cdot)$（SigLIP 文本塔）生成密集嵌入，并计算其与语义查询（事件描述）之间的余弦相似度： $$ s_{\mathrm{sem}}(e,f_{r})=\max_{p\in\mathcal{P}_{r}}\frac{\langle\psi(e),\psi(p)\rangle}{\|\psi(e)\|_{2}\,\|\psi(p)\|_{2}+\epsilon}. $$

**源感知融合。** 不同证据源具有不同的信噪比。OCR 文本精确但稀疏（高精度）

# LLM 和 VLM 调用的提示词

本节提供了我们在实现中使用的核心提示词。

## D.1 查询分解提示词（LLM）

LLM 将查询分解为实体（用于关键词匹配）和事件（用于语义匹配）。

### 系统提示词

**角色：** 视频理解的实体与事件提取器。

**任务：** 从用户查询中提取实体（用于关键词匹配）和事件（用于语义匹配）。

**输出要求：**

1. **查询关键词（ENTITIES）：** 人名、地名、物体名、数字、年份。

2. **通用语义查询（EVENT）：** 为回答问题必须发生的事件。

3. **选项关键词：** 每个选项 2-5 个具体实体。

4. **选项语义查询：** 表明每个选项正确的具体事件。

**规则：** 关键词 = 实体（ENTITIES）；语义查询 = 事件（EVENTS）。每个选项至少有一个非空项。

### 用户提示词

**输入查询：** “{query}”

提取实体和事件用于视频检索。

**输出 JSON 格式：** ⬇ ```json { "query_keywords": [...], "option_keywords": { "A": [...], ... }, "semantic_queries": { "A": "...", ... }, "general_semantic_query": "...", "temporal_plan": "...", "vlm_query": "..." } ```

## D.2 观察者检查提示词（VLM）

VLM 观察视频片段并生成描述性字幕以及逻辑缺口分析。

E.4.1 动机：互补的稀疏-密集检索 稀疏检索（词法匹配）和密集检索（语义匹配）提供了互补的归纳偏置（Robertson et al., 2009; Karpukhin et al., 2020）： • 密集向量（嵌入）：擅长处理同义词改写和语义等价（例如，“automobile” ≈ “car”），能够实现稳健的泛化。然而，它们容易受到“语义漂移”的影响——嵌入可能混淆相关但不同的概念，导致误报（高召回率，低精确率）。 • 稀疏词法匹配（IDF加权重叠）：通过精确的词元匹配确保符号级别的精确性（例如，区分“bank”作为金融机构与河岸）。然而，它对改写和同义词不敏感（高精确率，低召回率）。该得分受TF-IDF启发，但无需构建完整的TF-IDF向量。 通过结合这两种方法并采用源感知加权（§ 3.3.1），我们同时实现了高精确率和高召回率：词法匹配捕捉精确提及，而语义匹配处理变体和隐式引用。
