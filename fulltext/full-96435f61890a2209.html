Σ-LeWM：基于S-信息的机器人控制世界模型学习

📅 2026-11-09 📄 arxiv 🔗 原文链接

原标题：$Σ$-LeWM: Learning World Models via S-Information for Robot Control

中文摘要： 本文提出Σ-LeWM，在无解码器世界模型LeWM上引入后向与逆动力学两个辅助对比任务，以解耦对比损失（DCL）训练。信息论分析表明，前向、后向与逆三目标之和恰为S-信息（总相关与对偶总相关之和），从而在潜在空间诱导三向预测依赖结构。实验显示，该方法在标准基准与齿轮装配等机器人任务上显著超越LeWM（严格成功率由10.9%升至74.9%），且支持更长规划视野、大幅降低测试时规划计算量，利于真实机器人实时控制。

摘要

世界模型越来越多地被用作机器人任务（如操作与运动）的基于模型的控制方法。早期的世界模型架构依赖解码器来防止模式坍塌并学习可预测的潜在空间，而近期的世界模型工作（如联合嵌入预测架构 JEPA 或 LeWorldModel）则日益倾向于在不依赖接地解码器的情况下学习嵌入，仅使用一个潜在前向动力学预测器和一个起稳定作用的熵正则项。本文旨在证明：在 LeWorldModel 基础上进一步引入两个额外的潜在损失——后向动力学预测器与逆动力学动作预测器——能够对潜在嵌入施加更强的结构约束，从而在性能与规划效率两方面带来进一步提升。这些正是让此类方法适用于真实机器人实时基于模型控制的关键属性。我们在标准世界模型基准和两个仿真机器人操作任务上验证了这些增益。

图 1：Σ-LeWM 为 LeWorldModel（LeWM）的潜在动力学学习引入两个辅助任务：除在潜在空间中学习标准的前向动力学函数（左）外，Σ-LeWM 还隐式学习后向动力学（中）与逆动力学函数（右）。将这些函数与标准 LeWM 一同学习，会对潜在嵌入空间施加进一步的约束与偏置。测试时，动作通过前向动力学（左）配合标准前向规划与模型预测控制（MPC）算法求得。

1 引言

世界模型对于在图像或高维本体感受数据等复杂观测空间中运行的机器人的基于模型控制正变得日益有用 [1,2,3,4,5]。其核心思想不是直接在复杂高维空间中规划，而是学习观测的嵌入空间，并在降维后的空间中高效、快速地执行规划 [6]。这需要一个将高维观测投影为潜在特征的嵌入函数，并在其中学习转移函数以执行模型预测控制。本工作研究如何通过在优化过程中引入多个学习信号来改进世界模型学习。

早期世界模型严重依赖编码器—解码器架构（如变分自编码器 [7]）来防止模式坍塌，确保动力学学习与规划的可靠性。解码器对原始观测的预测通常会对学到的潜在空间施加人为限制：每个观测特征都必须完全可预测，以满足并最小化重建损失。相反，在规划与基于模型控制的语境下，我们的主要目标是一个结构化的潜在空间——它将相似观测置于相近位置，同时最大化所学转移函数在给定动作时预测下一潜在状态的能力。

如先前工作所示，移除解码器虽有挑战，却能产生结构更好、可规划性更强的潜在空间，从而在机器人控制任务中带来性能提升 [8]。值得注意的是，近期工作 LeWorldModel（LeWM）[9] 表明：仅使用预测下一潜在特征的潜在转移损失，加上防止潜在表示模式坍塌的 Sketch 各向同性高斯正则项（SIGReg），即可训练出适用于物体操作等机器人任务的世界模型。

本工作更进一步：我们提出对 LeWorldModel 的一种自然且直观的扩展，其动机来自信息论洞察——额外的后向转移动力学损失与逆动力学损失会在世界模型的潜在嵌入空间上诱导出进一步的结构。我们证明这不仅带来更好的性能，还通过允许缩短视野长度并减少推理步数而提升计算效率，从而降低模型预测控制过程的测试时规划计算量，增强在真实机器人上的实用性。

总之，本文的贡献如下：

  • C1 我们提出 LeWM 的新扩展 Σ-LeWM，引入后向与逆动力学作为辅助损失/任务，以学习结构更好、更可预测的潜在嵌入。
  • C2 我们证明该方法在信息论上有直观依据：这一学习方式由最大化 S-信息所驱动。
  • C3 实验表明 Σ-LeWM 优于标准 LeWM，且在齿轮装配等更贴近现实的机器人任务上同样如此。

2 相关工作

潜在世界模型与 JEPA。 生成式世界模型（如 Dreamer 系列 [6]、PlaNet [10] 和 DIAMOND [11]）通过解码器重建与奖励信号学习潜在动力学。TD-MPC [8] 则舍弃解码器，通过时序差分目标学习潜在动力学。近来，JEPA [12] 受到越来越多关注，它无需重建或奖励，使用编码器和预测器学习预测潜在表示。I-JEPA [12] 与 V-JEPA [13] 等方法通过预测被掩码输入的潜在表示，将 JEPA 用于自监督表示学习。然而，潜在预测并不保证表示的信息量，且可能发生表示坍塌。

潜在世界模型中的抗坍塌。 近期类 JEPA 方法采用多种手段缓解表示坍塌、稳定训练：DINO-WM [14] 冻结预训练编码器以防预测坍塌；PLDM [15]、Sub-JEPA [16] 与 RC-aux [17] 则使用辅助目标来正则化潜在空间。然而，仅防止坍塌并不能保证潜在空间捕获对控制有用的结构，而这恰恰对机器人学习与规划十分重要。

潜在世界模型中的逆动力学。 近期工作越来越多地利用逆动力学使潜在表示更具控制相关性。SMWM [18] 与 AC-MTM [19] 在学习表示时，将基于两个潜在表示的逆动作预测作为辅助任务；另一方面，GC-IDM [20] 与 ACID [21] 仅在下游规划中使用逆动力学，而不改变潜在表示学习。

3 预备知识

3.1 LeWorldModel

我们考虑一个无解码器的潜在世界模型，由以下部分组成：

编码器：E: o_t ↦ z_t　(1)
潜在转移函数：f: (z_t, a_t) ↦ z_{t+1}　(2)

其中 z_t 与 z_{t+1} 分别表示观测 o_t 与 o_{t+1} 的潜在编码。观测 o_t 通常假设为高维数据（如图像）。

在 LeWM 中，上述函数通过结合潜在下一状态预测项 L_pred 与潜在状态正则项 L_reg 的目标进行训练：

L_LeWM = ‖f(z_t, a_t) − z_{t+1}‖₂²（L_pred）+ λ_sig · L_SIGReg(Z)（L_reg）　(3)

其中 SIGReg 是 LeWM 引入的正则项，用于在无解码器时防止潜在嵌入的模式坍塌。

测试时，由世界模型潜在空间中的规划算法计算动作。给定当前状态表示 E(o_0)=z_0 与编码后的目标状态 E(o_goal)=z_goal，类 MPC 规划方法采样候选动作序列并在潜在嵌入空间中向前滚动。规划器优化如下目标：

a*{0:H−1} = arg min{a_{0:H−1}} ‖h(z_0, a_{0:H−1}, f) − z_goal‖₂²　(4)

其中 h(z_0, a_{0:H−1}, f)=z̃H 表示以 z_0 为起点、用所学转移函数 z{t+1}=f(z_t, a_t) 向前滚动得到的潜在轨迹的预测最终潜在状态。沿用 LeWM，我们同样使用交叉熵方法（CEM）——一种基于采样的优化器，按潜在空间目标代价迭代筛选候选动作序列以找到最优轨迹。找到最优潜在轨迹后，先执行其中的第一个（批）动作，随后进入下一个规划周期。

3.2 解耦对比信息最大化

为优化后向与逆预测目标，我们采用解耦对比损失（DCL）[22]。DCL 可视为互信息最大化的对比代理，与 InfoNCE 下界密切相关 [23,24]。

对一批配对表示 {(q_i, k_i)}_{i=1}^N，定义归一化相似度 s_ij = ⟨q̂_i, k̂_j⟩ / τ，其中 q̂_i = q_i/‖q_i‖₂、k̂_j = k_j/‖k_j‖₂ 为归一化的判别输出，τ 为温度参数。

方向性 DCL 目标定义为：

L_DCL^{q→k} = (1/N) Σ_i [ −s_ii + log Σ_{j≠i} exp(s_ij) ]　(5)

我们使用其对称形式：

D(Q, K) = (1/2)( L_DCL^{q→k} + L_DCL^{k→q} )　(6)

与 InfoNCE 不同，DCL 将正样本对从归一化项中移除，从而将正样本吸引与负样本排斥解耦。对每个样本，相应的 InfoNCE 损失满足：

ℓ_InfoNCE = log(1 + exp(ℓ_DCL))　(7)

它是 ℓ_DCL 的严格递增函数。因此，最小化 DCL 与最大化相应 InfoNCE 互信息下界是一致的。

4 方法

本节首先介绍我们提出的 Σ-LeWM（标准 LeWM 的扩展），然后为该架构的效果提供形式化的直觉解释。

4.1 Σ-LeWM 概览

我们在标准潜在世界模型（具体为 LeWM）之上扩展两个预测函数：后向转移函数与逆转移函数。

组件：我们提出的 LeWM 扩展包含以下主要组件：

  • 观测编码器：z_t = E^O(o_t)　(8a)
  • 动作编码器：ã_t = E^A(a_t)　(8b)
  • 前向动力学：z_{t+1} = f(z_t, ã_t)　(8c)
  • 后向动力学（辅助）：z_t = f_back(z_{t+1}, ã_t)　(8d)
  • 逆动力学（辅助）：ã_t = f_inv(z_t, z_{t+1})　(8e)

在 LeWM 基础上，Σ-LeWM 保留标准观测与动作编码器 E(·)、E^A(·) 以及前向动力学模型 f(z_t, ã_t)。辅助目标（f_back(·) 与 f_inv(·)）仅在训练时使用，不会在推理阶段引入额外的动力学模型；它们可通过直接嵌入 DCL 损失而隐式训练（见 4.2 节）。因此，测试时规划与 LeWM 完全一致。不过，通过在训练中最大化后向与逆信息目标，Σ-LeWM 对所学潜在空间施加了额外的结构性偏置。

4.2 训练

为训练式 (8) 中世界模型的各个函数，我们使用由三个损失项组成的目标：

L_Σ = L_forward + λ_back · L_back + λ_inv · L_inv　(9)

其中 L_forward 为前向世界模型目标，L_back 与 L_inv 分别优化后向与逆视角，λ_back 与 λ_inv 为正则化权重。

前向损失（L_forward）：前向网络使用与 LeWM 相同的损失函数训练，另加权重 λ_multi=1 的多步预测项，即

L_forward = L_LeWM + Σ_{k=2}^{m} ‖ẑ_{t+k} − z_{t+k}‖₂²

并连同 LeWM 的潜在空间正则项。

后向损失（L_back）：为训练后向动力学函数 z_t = f_back(z_{t+1}, ã_t)，我们使用式 (6) 引入的 DCL。给定转移 (o_t, a_t, o_{t+1})，后向损失定义为：

L_back = D( f_back(z_{t+1}, ã_t), z_t )　(10)

其中 z_{t+1}=E(o_{t+1})，ã_t=E^A(a_t)，z_t=E(o_t)，目的是将未来“状态—动作”对 (z_{t+1}, ã_t) 的表示与当前观测 o_t 的潜在表示 z_t 对齐。实验中我们发现，为 z_t 的表示额外训练一个编码器能提升性能；因此在实现中我们优化 L_back = D( f_back(z_{t+1}, ã_t), E^z(z_t) )。

逆损失（L_inv）：与后向损失类似，我们再次使用式 (6) 的 DCL 损失训练逆动力学函数：

L_inv = D( f_inv(z_t, z_{t+1}), ã_t )　(11)

该目标最大化动作表示 ã_t 与相邻潜在状态对 (z_t, z_{t+1}) 之间的逆信息依赖。

4.3 理论分析：信息论直觉

从信息论视角看，上述学习目标可通过多变量信息最大化，为前向、后向与逆目标提供统一解释。为简洁起见，以下讨论使用 Z_t、Z_{t+1} 与 Ã_t，但注意它们是原始观测 O_t、O_{t+1} 与动作 A_t 的直接编码。

式 (3) 中 LeWM 的目标包含两项。就预测项而言，假设一个固定方差的高斯预测模型：

p_φ(Z_{t+1} | Z_t, A_t) = N( g_φ(Z_t, A_t), σ²I )　(12)

我们有：

−log p_φ(Z_{t+1} | Z_t, A_t) = (1/2σ²)‖Z_{t+1} − g_φ(Z_t, A_t)‖₂² + (d/2)log(2πσ²)　(13)

因此，最小化预测 MSE 等价于（至多相差一个加性常数）最小化条件负对数似然，后者可进一步分解为：

E_{p(Z_t,A_t,Z_{t+1})}[−log p_φ(Z_{t+1}|Z_t,A_t)] = H(Z_{t+1}|Z_t,A_t) + E_{p(Z_t,A_t)} D_KL( p(Z_{t+1}|Z_t,A_t) ∥ p_φ(Z_{t+1}|Z_t,A_t) )　(14)

由于 KL 散度非负，条件负对数似然是 H(Z_{t+1}|Z_t,A_t) 的上界。因此，最小化预测 MSE 即最小化条件熵的一个变分上界。

其次，SIGReg 促使聚合后的潜在分布逼近各向同性高斯 q(Z_{t+1}) ≈ N(0, I)。众所周知，在协方差矩阵固定的所有多元连续分布中，高斯分布使 Shannon 微分熵最大。因此 SIGReg 也能维持较高的边际熵 H(Z_{t+1})。

综合这两种效应，可将原始 LeWM 的目标直接关联为：

L_pred（降低 H(Z_{t+1}|Z_t,A_t)）+ λ·L_SIGReg（提升 H(Z_{t+1})）　(15)

又因

I(Z_{t+1}; Z_t, A_t) = H(Z_{t+1}) − H(Z_{t+1}|Z_t, A_t)　(16)

我们得到如下洞察：两个目标联合优化 max I(Z_{t+1}; Z_t, A_t)　(17)。因此，LeWM 可被解释为一种联合互信息最大化。

Σ-LeWM 的主要改动在于后向与逆方向：它通过 DCL 直接优化后向与逆目标，分别鼓励 Z_t 与 (Z_{t+1}, Ã_t) 之间、以及 Ã_t 与 (Z_t, Z_{t+1}) 之间的高互信息。类似地，后向与逆目标直接最大化相应互信息项的对比下界：

I_back = I(Z_t; Z_{t+1}, Ã_t)　(18a)
I_inv = I(Ã_t; Z_t, Z_{t+1})　(18b)

具体而言，我们使用 DCL 优化这两项；DCL 与相应 InfoNCE 目标单调相关，因此可作为最大化其互信息下界的代理。

值得注意的是，我们优化的是上述三个联合互信息项之和。已有研究表明，这样的和与总相关（Total Correlation, TC）[25] 及对偶总相关（Dual Total Correlation, DTC）[26] 直接相关，即：

I_forward + I_back + I_inv = TC(Z_t, Ã_t, Z_{t+1}) + DTC(Z_t, Ã_t, Z_{t+1})　(19)

式 (19) 的分解为所提目标提供了有用的信息论解释。TC 度量 Z_t、Ã_t 与 Z_{t+1} 之间的整体统计依赖，仅当三者相互独立时为零；DTC 则刻画一种互补的多变量依赖形式，反映每个变量被其余变量约束的程度。更重要的是，二者之和具有特别直观的形式：

Σ(Z_t, Ã_t, Z_{t+1}) = TC(Z_t, Ã_t, Z_{t+1}) + DTC(Z_t, Ã_t, Z_{t+1})　(20)

这被称为 S-信息（S-Information）[27]。

因此，我们的目标不再只鼓励前向可预测性，而是在三个方向上同时促进预测依赖：由当前状态与动作预测下一状态、由下一状态与动作预测当前状态、由两个相邻状态预测动作。故我们将所提方法命名为 Σ-LeWM。

5 实验

图 2：主要实验结果概览：Σ-LeWM 在长视野任务上优于标准 LeWM（a），并带来更高的规划效率（b）。这两点对复杂而真实的机器人任务至关重要。我们在 OGBench-Scene 操作任务上展示了相对 LeWM 的优越性能（c；数值为相对随机动作下界的增益；点：单次评估；标记形状：训练种子；误差条：全部 15 次评估的标准差，见表 1），并在机器人高精度任务上展示了 Σ-LeWM 的更优表现（d）。

实验中，我们考察以下问题：(RQ1) 所提 Σ-LeWM 相对 LeWM 是否有性能增益；(RQ2) 辅助任务对潜在嵌入及其结构有何影响；(RQ3) 最大化 S-信息相对最大化单项是否有优势。

为回答第一个问题，我们在 5.2 节的标准世界模型基准上评估方法的预测能力；并在 5.3 节展示更长规划视野与更低计算量下的性能增益——这对机器人场景至关重要。此外，我们引入两个更真实的机器人操作任务（5.5 节）以评估 Σ-LeWM 在更具挑战性任务上的端到端能力。

为回答 (RQ2)，我们对 Σ-LeWM 学到的潜在空间做降维可视化，考察任务的物理量（如物体位置）是否保留在嵌入结构中（5.6 节）；同时为 LeWM 与 Σ-LeWM 分别学习 GC-IDM [20] 规划器，评估 Σ-LeWM 的潜在表示是否更易于被其他规划方法利用。

最后，针对 (RQ3)，我们对后向与逆动力学两个辅助任务做因子消融研究，说明只有二者结合——即最大化 S-信息——才能带来更好的任务性能（5.7 节）。

5.1 实验设置

除非特别说明，各任务结果使用同一组辅助训练参数：多步前向预测权重 λ_multi=1.0、最大预测跨度 m=5，以及辅助目标权重：后向 λ_back=0.1、逆 λ_inv=0.05；相关参数的消融见 5.7 节。DCL 温度取 0.1，使用批内负样本（批大小 128）。为与 LeWM 保持一致并具备可比性，我们使用相同的编码器、预测器、优化器、训练流程，以及前向预测训练相关参数（学习率、SIGReg 权重 λ_sig=0.09、SIGReg 温度 τ=0.1）和规划方案：CEM 求解器每轮迭代采样 300 条动作序列并选取前 30 个候选更新采样分布。

任务设置。 使用标准 Push-T、TwoRoom、Reacher、OGBench-Cube 与 OGBench-Scene [28] 任务，并沿用 LeWM 的默认训练与规划设置：CEM 求解器 30 步优化、5 步规划视野、环境时间步设为 25 并采用 5 步帧跳过。对比基线包括：LeWM；Sub-JEPA [16]（以子空间高斯正则替代 SIGReg）；RC-aux [17]（使用时间/空间对齐的两个辅助目标）；以及添加逆动力学损失的 SMWM [18] 与 AC-MTM [19]（后者为对比形式）。对 LeWM 与 Sub-JEPA，训练种子 3072 为作者发布的检查点，种子 1、2 按公开配方重训；RC-aux 将作者的微调配方应用于每个 LeWM 种子。所有基线保留其原始目标，因此训练时不包含我们的多步前向项。Scene 无公开检查点，所有方法均由我们自行训练。为区分多步项与后向/逆目标的贡献，表 1 还报告了仅用多步项训练的 LeWM（即 5.7 节的“base”分支）。结果为 3 个训练种子 × 5 个评估种子 × 50 个回合的均值与标准差。

5.5 机器人任务：齿轮装配与立方体堆叠

6 结论

我们提出了一组新的辅助任务，使 LeWorldModel 等世界模型能够学习鲁棒且结构良好的潜在嵌入。所提损失函数基于信息论洞察，以有理论依据的方式补充 LeWM 的标准目标。在潜在空间中加入后向与逆动力学损失，等价于最大化对偶总相关与总相关之和，即 S-信息。该方法提高了潜在变量间的确定性与可预测性，同时促进它们之间的对齐。实验表明，Σ-LeWM 相对 LeWM 取得显著性能提升，在机器人操作基准上尤为明显。此外，我们观察到长视野规划稳定性的提升——这是现实机器人任务的重要特性。未来工作将研究在规划阶段利用后向与逆潜在动力学等辅助任务，以及将 Σ-LeWM 部署到真实机器人任务上。
