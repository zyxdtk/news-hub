I love this idea and the signup process was nice and easy. The loading icon is a little too subtle but setup can take a while so might need some optimising. I appreciate the AI tech is probably externally processed so you're waiting on APIs. I added some t

o-dos and the order they were added to my calendar felt really workable and possible. The time frames seemed a little out but that could be down to personal preference and was easy to change, although I'd expect to be able to click on the duration to quickly edit rather than have to click a different icon. One handy feature would be to easy drag and drop the calendar entries it adds, updating their start time. Pretty much ever calendar app allows that so it felt intuitive to try and do that. I can definitely see me using this to try and organise my days better. My only worry is that I can definitely see Google and Apple implementing this into their calendar apps which is where my calendar entries are right now. Having said that I don't use those calendars for daily to-do list management, so there's still scope for this service to remain relevant.
