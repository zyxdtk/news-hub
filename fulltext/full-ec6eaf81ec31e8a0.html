原标题：HSImul3R: Physics-in-the-Loop Reconstruction of Simulation-Ready Human-Scene Interactions

中文摘要： HSImul3R提出一种基于物理闭环的双向优化框架，从日常捕获中重建仿真就绪的人-场景交互。通过场景目标强化学习优化人体运动，并利用直接仿真奖励优化精炼场景几何，有效弥合感知与仿真鸿沟。实验表明，该方法在稳定性、几何保真度和机器人部署方面均优于现有方法，为具身AI提供可扩展解决方案。

具身人工智能旨在通过物理接地系统将智能代理融入日常生活。与局限于虚拟领域的无身模型 [xiu2023econ, cao2023sesdf, chen2025human3r, cai2025up2you] 不同，具身AI [ze2025twist, DBLP:journals/corr/abs-2601-22153, ze2025gmr, yin2025visualmimic] DBLP:journals/pami/LiBXCYL25]，在遮挡下具有鲁棒性，但孤立重建运动，未建模物理接触或环境约束。 3) 交互建模 [DBLP:conf/cvpr/YangL0LXLL22, DBLP:conf/cvpr/JiangZLMWCLZ024, DBLP:conf/cvpr/0009MGCPSJDXPWE24, DBLP:conf/cvpr/FanPK0KBH24, [DBLP:conf/iccv/LiuCYXKSQS23]、HSfM [DBLP:conf/cvpr/MullerCZYMK25]）尝试联合建模，但主要在2D图像空间优化，优先考虑视觉对齐而非几何和物理有效性。因此，重建结果缺乏度量和接触保真度，不适合仿真，保持了视觉真实与具身部署之间的鸿沟。 为弥合此鸿沟，我们引入 HSImul3R，一个仿真就绪的人-场景交互3D重建框架，将重建表述为双向物理感知优化问题。物理模拟器作为主动监督者，实现人体运动与场景几何之间的闭环精炼。HSImul3R 沿两个互补方向运行。正向优化在固定场景几何下精炼人体运动。在建立具有结构先验的度量一致人体-场景对齐后，我们将重建集成到模拟器中并执行场景目标强化学习。运动通过基于物理的信号（包括关键点跟踪一致性和几何接触约束）进行优化，提升交互稳定性。反向优化在物理验证运动下精炼场景几何。为解决结构缺陷几何导致的不稳定性，我们引入直接仿真奖励优化（DSRO），利用模拟器衍生的奖励增强重力稳定性和交互可行性。 给定日常捕获作为输入，我们通过物理闭环优化管道实现人-场景交互的仿真就绪重建。我们首先提出将3D显式生成先验注入重建管道，以实现人体与场景更好的对齐。然后，(1) 在正向传递中，我们提出场景目标强化学习，优化人体运动以在模拟器中实现交互稳定性；(2) 在反向传递中，我们引入直接仿真奖励优化（DSRO），通过关于稳定性的模拟反馈精炼场景几何。具体地，我们定义了四种反馈类型。类型1：物体在重力下不稳定；类型2：物体在人体交互期间无法稳定；类型3：物体稳定但无有意义交互；类型4：物体具有稳定交互。 如图3所示，HSImul3R 可从日常捕获重建仿真就绪的人-场景交互（HSI）。为实现此目标，我们首先重建人体运动和场景几何，然后通过从图像到3D生成模型 [DBLP:conf/cvpr/HuangGAY0ZLLCS25] 导出的显式3D结构先验进行对齐（第3.2节）。在此重建之后，我们引入一个基于物理的双向优化管道。该过程包括正向传递优化，采用提出的场景目标强化学习方案精炼人体运动（第3.3节），随后是反向传递优化，利用模拟器关于物理稳定性的反馈校正场景几何的结构正确性（第3.4节）。为简化说明，我们首先关注以下各节中 J=4 个未校准稀疏视角输入的设置，然后在第3.5节讨论其扩展到单目视频。方法论的基础在第3.1节提供。 3.1 基础 DUSt3R 近期，DUSt3R [DBLP:conf/cvpr/Wang0CCR24] 引入了一个3D重建框架，回归点图并采用全局对齐策略联合预测深度图和相机姿态。具体地，给定一组输入图像 I = {I₀, I₁, ..., Iⱼ}，DUSt3R 应用基于ViT的网络，对图像帧对 Iₙ, Iₘ (n,m ∈ [0,J]) 估计相应的点图 Pₙᵉ, Pₘᵉ ∈ ℝᴴ×ᵂ×³（相对于帧n的坐标系），以及置信度图 Cₙᵉ, Cₘᵉ ∈ ℝᴴ×ᵂ。这里，e = (m,n) 表示选定的图像对。聚合选定对的点图和置信度图后，DUSt3R 构建一个连通图 𝒢(𝒱,ℰ)，其中 𝒱 对应N个图像，ℰ 对应选定的图像对e。收集所有成对点图后，DUSt3R 执行全局对齐优化，恢复深度图 𝐃 = {D₀, D₁, ..., Dⱼ} 和相机姿态 π₀, π₁, ..., πⱼ： arg min_{D,π,σ} ∑_{e∈ℰ} ∑_{n∈e} Cₙᵉ ||Dₙ - σₑ · Fₑ(πₙ, Pₙᵉ)||₂², (1) 其中 σ = {σₑ, e∈ℰ} 表示边尺度因子，Fₑ(πₙ, Pₙᵉ) 将预测点图 Pₙᵉ 投影到视图n下，产生相应的深度。该目标强制输入帧对之间的几何对齐，确保优化后深度图的跨视图一致性。然而，DUSt3R 在人体主体上表现不佳，经常产生重建伪影，如不真实/错误的场景结构和非水密拓扑。这些缺陷使重建环境在稳定模拟和下游具身AI任务中不可靠。 3.2 人-场景交互重建与对齐 我们管道的第一阶段涉及从未校准捕获中独立重建静态场景几何和动态人体运动。我们采用 DUSt3R 恢复环境的3D结构。对于人体运动估计，我们首先利用 SAM2 [DBLP:conf/iclr/RaviGHHR0KRRGMP25] 在帧间检测和关联个体，生成精确的掩码和身份轨迹。随后，我们采用 4DHumans [goel2023humans] 和 ViTPose [DBLP:conf/nips/XuZZT22] 分别提取初始3D SMPL运动序列和2D关键点 (J₂D)。由于初始人体和场景重建可能位于不同的坐标空间，我们执行联合优化以统一它们 [DBLP:conf/cvpr/MullerCZYMK25]。这通过：(1) 以2D关键点 J₂D 为指导的人体中心束调整，以及 (2) 全局人-场景对齐，最小化 ViTPose检测关键点与投影3D SMPL关节之间的重投影误差，以确保空间一致性。 通过显式3D结构先验对齐 尽管上述初始对齐，两个关键问题常持续存在：(1) 重建的场景几何常包含结构伪影，如断开的组件、缺失的表面或非水密拓扑；(2) 人-场景对齐仅依赖2D投影监督，缺乏3D几何感知，易受遮挡影响。这些缺陷不可避免地导致物理模拟器中的不稳定和漂移。为解决这些挑战，我们利用预训练生成模型的3D结构先验来校正场景几何并强制更稳健的交互约束。 具体地，对于场景中的每个物体，我们自动识别最突出显示该物体的输入图像 Iₙ, n ∈ [1,J]，并使用 SAM [kirillov2023segment] 提取其分割掩码。该视图随后由预训练图像到3D生成模型 [DBLP:conf/cvpr/HuangGAY0ZLLCS25] 处理，以合成具有更好结构准确性的高保真3D表示： ℛ_scene := {MIDI(Iₙ[Mᵢ]), i ∈ [0,O]}, (2) 其中 ℛ_scene 表示精炼的3D场景，O 是物体总数。注意，我们的框架具有灵活性，允许使用替代或未来更先进的模型。 得益于3D结构先验的注入，我们现在能够通过3D显式约束精炼人-场景对齐。此过程至关重要，因为穿透伪影在模拟中尤其成问题：即使3D空间中的微小不一致也可能表现为身体部位与物体之间的严重碰撞，最终导致不稳定或失败的模拟。为此，我们提出优化恢复的人体和生成物体的位置。具体地，如果物体与人体不接触，我们通过以下方式优化其位置： ℓ_non-contact = (1/|Hₚ|) · ∑_{1≤j≤Nₒ} ||μᵢʰ - μⱼᵒ||₂ + (1/Nₒ) · ∑_{j=1}^{Nₒ} min_{i∈Hₚ} ||μⱼᵒ - μᵢʰ||₂, (3) 其中 Hₚ 表示最接近物体的人体部位，Nₒ 是物体上的顶点数，μⱼᵒ 和 μᵢʰ 分别表示物体和人体顶点的3D位置。当物体与人体接触时，我们改为应用： ℓ_contact = (1/|Hₚ|) · ∑_{i∈Hₚ} max(0, -δ(μᵢʰ)), (4) 其中 δ(·) 表示符号距离函数，测量人体顶点 μᵢʰ 相对于物体表面的穿透深度。 3.3 正向传递：场景目标运动优化 在完成人-场景交互的初始3D重建后，下一步是在物理模拟器 [DBLP:conf/nips/MakoviychukWGLS21] 中确保稳定动力学。直接方法是采用运动跟踪技术 [DBLP:conf/iccv/0002CWKX23] 将重建的人体姿态重定向到人形机器人。然而，直接模拟原始重建通常无法产生稳定交互（见图5）。在许多情况下，人形机器人意外地移开附近物体，使其与身体分离并独立地静止在地面上。这种不稳定性源于传统3D重建未考虑重力和交互力，以验证姿态和物体放置是否物理可实现。 为解决此问题，我们引入场景目标监督信号到基于强化学习的运动跟踪 [DBLP:conf/iccv/0002CWKX23]。具体地，我们提出一个目标，强制人形机器人与相关场景物体之间的空间邻近性，鼓励模拟中物理合理的接触。该损失定义为人体接触关键点 kⱼʰ 与其对应最近物体表面点 μᵢᵒ 之间的平均欧氏距离。 ℓ_scene = (1/(N_contact · N_surf)) · ∑_{j=1}^{N_contact} ∑_{i=1}^{N_surf} ||μᵢᵒ - kⱼʰ||₂², (5) 其中 N_contact 是人体与场景物体之间的接触数，N_surf 表示局部接触区域内采样的物体表面点数。 3.4 反向传递：模拟器引导物体精炼 尽管我们的正向传递与场景目标强化学习可增强仿真稳定性，我们仍可能观察到不令人满意的稳定性比率（见表1）。如图4所示，我们发现此问题主要源于我们显式3D生成先验的不一致质量，主要有两个原因：(1) 生成的物体常包含结构缺陷，尤其在细长几何中。例如，桌子或椅子可能缺少腿，使其在模拟器中即使无交互也不稳定；(2) 输入图像中人体的严重遮挡，这经常发生，常导致生成物体出现伪影，如表面扭曲或不需要的凸起。这些限制共同使人形机器人在模拟中难以建立稳定且物理合理的接触。 直接仿真奖励优化 受 DSO [DBLP:conf/iccv/LiZRV25] 启发，我们通过引入直接仿真奖励优化（DSRO）来解决此问题，这是一种新颖方法，利用基于物理的模拟反馈作为监督信号，以精炼3D显式物体生成。与依赖人类标注或3D真实值的方法不同，DSRO 直接利用模拟结果来评估生成物体及其与人类交互的物理合理性。 形式上，我们定义DSRO目标为： ℓ_DSRO = -T · 𝔼_{I∼ℐ, x₀∼𝒳_I, t∼μ(0,T), xₜ∼q(xₜ|x₀)} [w(t) · (1 - 2 · l(x₀)) ||ϵ - ϵ_θ(xₜ, t)||₂²], (6) 其中 I 表示从训练数据集 ℐ 中采样的图像，𝒳 对应其生成的3D显式物体，l(·) 编码从模拟中获得的稳定性反馈。 关键的是，我们根据重力稳定性和交互稳定性定义稳定性 l(x₀)： l(x₀) = {1, 如果稳定；0, 否则}, (7) 其中稳定性根据三个标准确定：(1) 物体必须在模拟器中在重力下保持直立和物理稳定；(2) 必须实现重建场景的稳定最终状态；(3) 交互必须涉及实际接触，而非物体独立静止在地面上。 HSIBench 为支持该框架的训练和基准测试，我们构建了一个专用基准数据集 HSIBench，专为人类-场景交互（HSI）设计。数据集通过系统性捕获三个志愿者（两名男性和一名女性）与多样物体（包括八把椅子、三张桌子和三张沙发）的交互场景构建。总共记录了300个独特HSI案例，每个案例从16个不同视角捕获，以提供丰富的多视角监督。代表性示例见附录。我们采用多视角2DGS重建 [Huang2DGS2024] 和SMPL估计，分别为物体几何和人体运动推导伪真实值，用于定量评估。 对于每个捕获案例，我们运行完整的重建和模拟管道（如第3.2和3.3节所述），在每个视角下使用15个不同的随机种子。此过程确保模拟结果的变异性，并允许我们系统性地收集微调所需训练信号。 3.5 扩展到单目视频 得益于我们在正向传递（第3.3节）中采用的运动跟踪技术的动态特性，我们的方法可轻松扩展以单目视频作为输入，生成仿真就绪的4D重建。在此管道中，我们分别采用 MegaSAM [li2025megasam] 和 TRAM [wang2024tram] 进行场景重建和人体运动估计 [allshire2025visual]。我们目前假设场景是静态的，人体是唯一移动实体。为实现人体与场景几何的动态3D对齐，我们采用 SAM2 [DBLP:conf/iclr/RaviGHHR0KRRGMP25] 提取人体和特定场景几何（如桌子、椅子）的2D边界框。此空间知识允许我们初步识别交互，并在整个序列中实现精确的3D对齐。 4 实验 表1 : 人-场景交互重建和模拟的定量比较。 我们评估 (1) 模拟后交互稳定性，(2) 3D重建中的人-场景穿透，以及 (3) 模拟后人体运动的变化。我们的方法在所有指标上均优于基线方法（HSfM）和不同变体。 方法 稳定性-HSI (%) ↑ 场景穿透 人体运动质量 结论 在本工作中，我们引入了HSImul3R，首个从未校准稀疏视角重建仿真就绪人-场景交互的框架。我们的方法结合了接触感知交互模型以缓解3D重建中的人-场景穿透问题，场景目标强化学习策略以促进模拟器中的稳定交互，以及直接仿真奖励优化方案，利用模拟反馈微调图像到3D生成模型，从而提高模拟成功率。为支持训练和评估，我们收集了HSIBench数据集。大量实验表明，HSImul3R实现了高保真结果，提供稳定模拟和高质量图像到3D重建，并优于现有最先进方法。
