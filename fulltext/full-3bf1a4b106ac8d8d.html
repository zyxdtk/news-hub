摘要

扩散模型的最新进展显著提升了文本到图像生成的质量，使其能够应用于视觉叙事，即从叙事提示生成连贯的图像序列。然而，现有方法主要关注身份保持，往往无法适应多样化的场景变化，导致语义错位和结构僵化。我们提出 EOS-Story，一个无需训练的框架，在文本和视觉空间中协调身份一致性与场景特定适应。

在文本空间中，我们将叙事解耦为身份子提示和场景子提示以防止信息稀释，但这导致场景无法获取外观线索。为弥合这一差距，我们引入跨上下文桥接，将短语级外观残差软注入场景的 ⟨EOS⟩ 嵌入中。在视觉空间中，我们发现身份主体与场景主体之间的尺度不匹配导致少数身份 token 被重复迁移，产生结构伪影。我们通过自适应身份保持解决这一问题，该方法在场景特定尺度上锚定身份特征（身份锚定），并通过身份感知自注意力整合这些特征。为评估不同空间构图下的性能，我们用多样化的取景场景扩展了 Consistory+ 基准（Consistory++）。大量实验表明，EOS-Story 在两个基准上均取得了有竞争力或更优的性能。

关键词： 叙事文本到图像生成

1 引言

扩散模型 [26, 23] 近期提升了文本到图像生成的质量，在视觉内容创作中实现了多样化应用。其中，可应用于数字漫画和角色驱动动画 [22] 的视觉叙事任务尤其具有挑战性，因为它需要在场景间保持主体连贯的同时对齐不断演变的叙事语义 [30]。

图 1： 先前方法在场景级适应方面的局限性。现有方法往往未能考虑场景特定差异： 简单情况下的语义错位， 复杂场景中细粒度提示细节的丢失，以及 无法适应多样化视角和尺度。这些问题常导致主体结构重复以及与场景特定提示的对齐减弱。相比之下，我们的方法通过自适应地协调身份一致性与每个场景的独特上下文，实现了更好的场景级保真度。

近期方法 [40, 17, 30] 明确设计机制，通过在生成过程中将与主体相关的特征迁移到每个场景来保持主体身份。虽然这些方法有效保持了身份一致性，但它们往往在文本和视觉空间中都未能充分表现场景特定差异——即在叙事上下文中变化的多样化语义和视觉元素（图 1）。

首先，在语义层面，当前方法 [17, 40, 30] 通常将叙事提示视为单一整体输入，各种语义（如外观和场景描述）被编码到统一嵌入中。这可能导致信息稀释，使模型难以均匀关注所有细节 [14]。因此，即使提示包含丰富细节（如特定动作或环境变化），模型也常常无法从提示中选择性地提取场景特定线索。这直接损害了叙事保真度，产生忽略其预期语义的场景（图 1 a,b）。

其次，在视觉层面，现有方法通常依赖空间盲特征注入，即在不考虑每个场景的空间约束或取景的情况下迁移身份特征。这种对结构场景差异（如相机角度或主体尺度）的忽视可能导致主体僵化，例如上下文不匹配的姿势或场景间重复的结构模式（图 1 b,c）。因此，主体以忽略每个场景预期布局的刚性结构模式渲染，进一步削弱了与场景特定提示的对齐。

因此，实现连贯的叙事需要场景特定适应，即身份一致性与每个场景的语义和结构差异相协调。

为解决这一问题，我们提出 EOS-Story，一个通过两个互补模块自适应考虑场景特定差异的框架：

(1) 跨上下文桥接： 我们假设语义错位源于长而复杂的提示被整体编码，导致场景变化属性被稀释 [16, 14]。我们不是在单个提示中编码所有信息，而是将叙事解耦为描述主体的身份提示和描述场景的场景提示。例如，"一个金发女人在读书"被拆分为身份提示（"一个金发女人"）和场景提示（"一个女人在读书"）。然而，这种分离带来了新挑战：由于场景提示不包含外观信息，场景中生成的主体无法反映实际的目标身份。为在不回退到整体编码的情况下弥合这一语义差距，我们将场景子提示保留为语义锚点，并在嵌入级别软注入外观信息。受 ⟨EOS⟩ 嵌入强大的生成影响力和摘要能力 [20, 37] 的启发，我们将其不仅仅解释为终止 token，而是作为场景感知叙事的基于残差的语义控制点（第 3.1 节）。与先前在仅相差一个词的提示之间替换 ⟨EOS⟩ 嵌入的基于 EOS 的方法（如对象类别）[9, 20] 不同，我们捕获短语级外观差异并将其注入场景的 ⟨EOS⟩ 中，反映丰富的多属性线索而无需显式的词级重复（第 3.2 节）。这在语义层面为场景图像提供了指定的外观线索，实现了更有效的特征级身份迁移。

(2) 自适应身份保持： 为缓解空间盲特征迁移导致的主体僵化，我们引入空间自适应身份注入机制，更好地将身份特征与场景特定布局对齐（第 3.3 节）。我们观察到身份主体与场景主体之间的尺度不匹配阻碍了各种身份 token 与场景 token 的对应。结果，只有少数身份 token 被重复迁移到场景并导致结构伪影。受此启发，我们应用身份锚定，自适应地调整身份特征大小以匹配场景的预期取景和尺度。这强制身份与场景表示之间的结构兼容性，减少尺度引起的失真（图 10 b）。然后我们通过身份感知自注意力细化整合，使场景特征能够选择性地关注主体特征，建立在 [30] 的基础上。与现有的空间盲迁移策略 [30, 17, 40] 不同，我们的方法支持主体结构的场景条件变化（如视角变化），同时保持核心身份特征。

为评估场景特定结构差异，我们引入 Consistory++，用多样化的取景提示 [15] 扩展 Consistory+ [17]，以模拟真实世界叙事的现实取景变化。我们在 Consistory+ 和 Consistory++ 上验证我们的方法，展示了取景变化下持续改进的性能。

我们的贡献如下：

  • 我们展示了 ⟨EOS⟩ 嵌入可以携带短语级、多属性信息，使外观线索能够在生成过程中被注入。
  • 我们提出 EOS-Story，一个包含两个模块的免训练框架：跨上下文桥接（文本空间语义重组）和自适应身份保持（视觉空间尺度感知迁移）。
  • 我们引入 Consistory++，一个具有多样化取景短语的扩展基准，并在原始和扩展基准上展示了对现有方法的持续改进。

2 相关工作

视觉叙事。 随着扩散模型 [26, 23] 的进步，其应用已扩展到各个领域。为满足用户生成保持主体身份图像的需求，已有大量个性化方法被提出 [1, 36, 13, 7, 28, 11]。然而，这些方法主要关注保持主体外观 [30]，往往忽视主体应如何在不同视觉上下文中适应。为弥合这一差距，视觉叙事 [40, 17, 25, 19, 33] 已成为在多样化和动态场景中生成身份一致图像的引人注目的范式 [17]。一些方法微调扩散模型以显式捕获主体身份 [33, 25]，而 [40, 30, 17, 19, 34, 8] 探索利用注意力机制中间特征的免训练策略。例如，Consistory [30] 直接在不同场景间映射主体身份以实现身份一致性，而 1P1S [17] 利用 CLIP [24] 的上下文一致性并通过交叉注意力机制迁移这些信息。然而，这些方法以牺牲场景适应为代价优先考虑身份一致性，常产生僵硬的主体描绘和较弱的提示对齐。虽然并行工作 [8, 34] 试图缓解主体僵硬，但它们仍将提示对齐委托给底层扩散模型。相比之下，我们发现忠实的场景适应不仅取决于视觉空间，还取决于文本空间，并设计我们的框架以共同解决两者——通过语义级残差注入改善提示对齐，并通过尺度感知特征迁移适应结构差异。

扩散模型中的 ⟨EOS⟩ 嵌入。 在广泛用于文本到图像生成模型中文本编码的 CLIP [24] 中，⟨EOS⟩ token 封装了整个提示的上下文摘要 [37]。最近的机制分析 [31] 进一步表明，填充 token（包括 ⟨EOS⟩）在文本到图像生成中携带非平凡的语义影响。在此基础上，[37] 证明 ⟨EOS⟩ 在图像生成中具有主导影响：将原始提示（如"一只蓝色的鸟"）的 ⟨EOS⟩ 嵌入替换为目标提示（如"一把蓝色的椅子"）的 ⟨EOS⟩ 嵌入，可以将生成的图像引导至目标语义。受此特性启发，若干工作 [9, 20, 12] 利用 ⟨EOS⟩ 或文本嵌入操作用于下游任务。具体而言，[9] 替换 ⟨EOS⟩ 以解决对象-属性提示中的语义绑定问题，[20] 将整个基础提示嵌入连同 ⟨EOS⟩ 注入到特定对象的位置以执行图像编辑，[12] 操纵文本嵌入以抑制不需要的内容。与先前在仅相差一个词的提示之间替换 ⟨EOS⟩ [9, 20] 或操纵嵌入以移除内容 [12] 的方法不同，我们将 ⟨EOS⟩ 用作场景感知接口，将短语级外观信息迁移到场景特定的提示表示中以进行视觉叙事。

3 方法

概述。 为实现身份一致性同时允许主体适应多样化场景，我们提出 EOS-Story（图 3），一个在两个互补空间中建模场景特定差异的框架。(1) 跨上下文桥接（CCB） 通过 ⟨EOS⟩ 嵌入将短语级外观线索迁移到场景上下文中，解决语义差异，缓解长而复杂提示中的信息稀释。(2) 自适应身份保持（AIP） 通过将身份特征对齐到每个场景的主体尺度（身份锚定），随后进行身份感知自注意力细化，解决结构差异。

3.1 EOS 嵌入作为语义句柄

在本节中，我们探索 ⟨EOS⟩ 嵌入的生成功能角色。

图 2： EOS 修改的效果。 将"黑色"注入 ⟨EOS⟩ token 最有效地反映了预期属性。 编辑 ⟨EOS⟩ 嵌入在图像中诱导连贯的语义变化。

我们首先测试 ⟨EOS⟩ 嵌入是否可以作为全局语义控制点。如图 2a 所示，在基础提示（"一张狗的照片"）的不同 token 位置添加属性嵌入（如"黑色"）会产生显著不同的结果。直接将属性嵌入添加到目标词 token（"狗"）无法改变输出，即使在所有非 EOS token 上进行广泛注入也只产生微小变化。相比之下，仅将属性注入 ⟨EOS⟩ 嵌入会诱导明显的语义转变，表明 ⟨EOS⟩ 嵌入在生成过程中作为嵌入级语义编辑的有效句柄。

我们进一步研究语义变化是否可以在 ⟨EOS⟩ 级别通过加法和减法运算组合（图 2b）。简单减法常产生不完整的编辑，可能是因为未改变的词级 token 继续保留原始语义（图 2b2），而加法和替换更可靠地诱导连贯的语义转变。值得注意的是，我们的观察是 ⟨EOS⟩ 嵌入不仅可以捕获单个属性 [9, 20]，还可以捕获多个语义因子，通过一次 EOS 级编辑同时影响动作和环境（图 2b3）。这些编辑在不修改词级 token 的情况下发生，表明 ⟨EOS⟩ 级别的语义调整可以覆盖或补充持久的 token 级语义。

这些观察表明，⟨EOS⟩ 嵌入提供了一个保持上下文的句柄，可以通过残差运算编码丰富的多属性语义。受此启发，我们设计了跨上下文桥接，将短语级外观信息迁移到每个场景的 ⟨EOS⟩ 嵌入中，允许在保持场景上下文的同时整合主体特定的外观线索。

图 3： EOS-Story 流程。我们的框架包含两个互补模块：(1) 用于表示级语义重组的跨上下文桥接（第 3.2 节），和 (2) 用于空间感知结构对齐的自适应身份保持（AIP）（第 3.3 节）。AIP 由两个子组件组成：身份锚定（IA），建立尺度和上下文感知的对应关系，和身份感知自注意力（IASA），细化上下文相关的特征整合。在扩散时间步 T 上的去噪过程中，我们在 unet 内的时间步 t 处从显式结构锚定（IA）切换到基于注意力的细化（IASA）。

3.2 跨上下文桥接

为避免将故事提示视为单一的整体描述，我们从结构化的故事板输入（如 Consistory+ 基准 [17]）构建参考子提示。每个输入被分解为四个语义组件：风格、主体、外观和场景。将所有组件编码为单个提示（如"一幅宏伟的冬季主题艺术品，一位帝王般的冰雪女王以冰之美貌守望冻结的王国"）会在长而组合复杂的描述中稀释细粒度外观线索 [14]。

为在不延长场景提示的情况下恢复这些外观线索，我们围绕最小共享上下文构建三个参考子提示：(1) 风格提示：风格+主体，(2) 身份提示：风格+主体+外观，和 (3) 场景提示：风格+主体+场景。共享的风格+主体提示作为测量外观特定位移的最小锚点，然后再将其迁移到每个场景提示。该锚点是场景无关的，同时仍保留主体槽位和视觉风格，使其适合定义可跨所有场景共享的外观线索。通过保持场景提示不含显式外观短语，我们将场景描述保留为主要语义上下文。

跨上下文桥接然后在嵌入级别重新引入缺失的外观线索。这允许在不修改词级场景描述的情况下恢复主体外观。基于我们的实证观察（第 3.1 节和附录 0.A），我们利用 ⟨EOS⟩ 嵌入作为可控语义句柄，实现短语级外观迁移而不增加场景描述的文本长度。

我们从 CLIP [24] 文本编码器获得相应的 ⟨EOS⟩ 嵌入 $eos_{sty}$、$eos_{id}$ 和 $eos_{sc}$。虽然 $eos_{id}$ 包含所需的外观信息，但直接将其添加到 $eos_{sc}$ 可能会冗余地强化共享的风格和主体语义，导致意外的语义漂移。因此，我们将外观残差定义为从共享风格-主体锚点到身份提示的局部位移，遵循 CLIP 嵌入空间的近似线性性 [32]：

$$\Delta_{app}=eos_{id}-eos_{sty}.$$

我们通过构建注入嵌入 $eos_{inf}$ 将此残差迁移到场景提示：

$$eos_{inf}=eos_{sc}+\Delta_{app}. \tag{1}$$

我们将每个场景 ⟨EOS⟩ 嵌入 $eos_{sc}$ 替换为其注入对应物 $eos_{inf}$。然后将身份提示嵌入和修改后的场景提示嵌入馈送到扩散模型以进行后续的特征级身份迁移。该公式在保留原始场景语义的同时，在场景提示表示中恢复主体外观线索。这种外观感知表示进一步减少了场景主体与其身份对应物之间的语义差距，为后续的特征级身份迁移提供了更强的基

3.3 自适应身份保持

与空间盲身份注入不同，我们专注于根据每个场景的主体结构锚定身份特征，允许主体在尺度和视角上适应，同时保持其核心身份线索。

为在场景间实现自然的主体对齐，我们将身份图像 $x_{id}\in\mathbb{R}^{HW\times C}$ 的视觉特征迁移到 N 个场景图像 ${x_{sc}^{n}}_{n=1}^{N}\in\mathbb{R}^{N\times HW\times C}$。我们使用 U-Net 第一个解码器块的中间特征（已知粗空间结构在此出现 [29]），以建立身份与场景主体区域之间的对应关系。身份锚定在早期去噪阶段应用（此时全局布局主要建立），以便后续步骤可以在不破坏已对齐结构的情况下细化细粒度细节。

在生成过程中，我们从相应主体 token 的交叉注意力图中获得主体掩码 $\mathcal{M}{id}\in\mathbb{R}^{HW\times 1}$ 和 ${\mathcal{M}{sc}^{n}}_{n=1}^{N}\in\mathbb{R}^{N\times HW\times 1}$。

身份锚定。 由于每个场景由不同的叙事提示引导，主体的尺度和取景在各场景间自然变化。我们在图 4 中实证发现，这种尺度变化直接降低了特征对应质量。在图中，随着身份主体与场景主体之间尺度不匹配的增大，场景 token 的对应关系集中在更小的身份 token 子集上。

图 4： 身份 token 覆盖率。唯一身份 token 覆盖率——被场景 token 引用的不同身份 token 的比例——在无尺寸匹配（橙色）时随尺度不匹配 $|\log r|$ 增大而急剧下降，而尺寸匹配（蓝色）保持其稳定。低覆盖率意味着少数 token 被重复迁移。

因此，少数身份 token 在场景主体中被过度使用，导致结构伪影和场景不灵活的描绘（图 10 b）。这表明建立可靠的对应关系需要首先将两个主体对齐到可比的大小。

因此，我们重新缩放身份特征以与每个场景中的主体大小对齐，实现跨不同空间上下文的自适应特征匹配（图 3 (2)）。对于每个场景，我们使用 $\mathcal{M}{id}$ 的边界框裁剪身份主体区域 $\hat{x}{id}\in\mathbb{R}^{h'w'\times C}$ 和掩码 $\hat{\mathcal{M}}{id}\in\mathbb{R}^{h'w'\times 1}$。我们类似地裁剪场景主体区域 $\hat{x}{sc}^{n}=\mathrm{Crop}(\mathcal{M}{sc}^{n}\odot x{sc}^{n})\in\mathbb{R}^{hw\times C}$，其中 $h'w'$ 和 $hw$ 分别表示身份和场景特定的主体大小。然后我们将掩码后的身份特征调整为场景主体的分辨率，获得尺寸对齐的身份特征：

$$\tilde{x}{id}^{n}=\mathrm{Resize}^{(n)}!\big(\hat{\mathcal{M}}{id}\odot\hat{x}_{id}\big)\in\mathbb{R}^{hw\times C},$$

其中 $\mathrm{Resize}^{(n)}(\cdot)$ 将输入调整为 $\hat{x}_{sc}^{n}$ 的空间大小。这种尺寸感知对齐允许场景特征在可比尺度上参考身份信息，减少来自无关身份区域的错误迁移。

为将身份信息迁移到每个场景中，我们计算尺寸对齐的身份特征 $\tilde{x}{id}^{n}\in\mathbb{R}^{hw\times C}$ 与场景主体特征 $\hat{x}{sc}^{n}\in\mathbb{R}^{hw\times C}$ 之间的对应图。在计算相似度矩阵 $S=\hat{x}{sc}^{n}\cdot(\tilde{x}{id}^{n})^{\top}$ 后，我们为每个场景位置 $i\in[1,hw]$ 识别身份特征中最相似的位置：

$$\Phi_{i}=\mathop{\mathrm{argmax}}{j\in[1,hw]}S{ij}. \tag{2}$$

由于每个场景位置都匹配到其最相似的身份特征，没有真正对应关系的位置仍被迫匹配，传播虚假身份线索。为抑制不可靠的迁移，我们仅保留相似度超过从相似度分布导出的自适应置信阈值（$\mu+\sigma$，其中 $\mu$ 和 $\sigma$ 表示所有场景位置相似度的均值和标准差）的匹配。然后我们混合场景主体和匹配的身份特征：

$$\hat{x}{sc}^{n}\leftarrow\lambda\cdot\hat{x}{sc}^{n}+(1-\lambda)\cdot\tilde{x}_{id}^{n}[\Phi], \tag{3}$$

其中 $\lambda\in[0,1]$ 平衡场景上下文保持和身份迁移。最后，我们用混合后的主体特征 $\hat{x}{sc}^{n}$ 替换 $x{sc}^{n}$ 中的主体区域。这种自适应对齐将身份线索与场景特定结构协调，保持每个场景的预期构图。

身份感知自注意力。 虽然混合后的场景特征 $x_{sc}^{n}$ 包含来自身份图像 $x_{id}$ 的视觉信息，但显式特征替换可能仍无法自然地融入周围的场景上下文。基于 [30]，我们使每个场景在自注意力期间动态关注身份特征（图 3 (3)）。从身份图像特征 $x_{id}$ 中提取尺寸对齐的键和值 $\tilde{K}{id}^{n}$ 和 $\tilde{V}{id}^{n}$ 后，我们将它们与场景特征 $x_{sc}^{n}$ 的相应键和值连接：

$$K_{sc,id}^{n}=\mathrm{Concat}(K_{sc}^{n},\tilde{K}{id}^{n}),\quad V{sc,id}^{n}=\mathrm{Concat}(V_{sc}^{n},\tilde{V}_{id}^{n}).$$

然后计算自注意力：

$$\mathrm{Attn}(Q^{n}{sc},K{sc,id}^{n},V_{sc,id}^{n})=\mathrm{Softmax}\left(\frac{Q^{n}{sc}K{sc,id}^{n\top}}{\sqrt{d}}\right)V_{sc,id}^{n}. \tag{4}$$

4.2 跨上下文桥接的有效性

基于第 3.1 节中 ⟨EOS⟩ 嵌入作为全局语义控制点的实证观察，我们在提供定性样本之外进行了定量评估。如表 2 所示，仅将外观信息注入主体 token 无法可靠地编码身份线索。将相同信息分布到所有非 EOS token 上部分改善了对齐，但增益仍然有限，表明局部化的 token 级注入难以在生成过程中一致地传播外观语义。相比之下，仅修改 ⟨EOS⟩ 嵌入持续取得最高的文本-图像对齐和感知相似度。这些结果表明，语义控制在整合全局上下文的 EOS 级别比在仅贡献局部表示的单个词 token 上更有效地执行。

5 结论

在本工作中，我们提出 EOS-Story，一个在文本和视觉空间中自适应建模视觉叙事中场景特定差异的免训练框架。我们引入跨上下文桥接，将叙事解耦为身份和场景子提示，并通过将短语级外观残差注入场景的 ⟨EOS⟩ 嵌入来弥合由此产生的语义差距。为补充结构适应，我们进一步提出自适应身份保持，在场景特定尺度上锚定主体特征，并通过身份感知自注意力细化整合。为评估场景适应性，我们用多样化的取景变化扩展了 Consistory+（Consistory++）。大量实验表明，EOS-Story 在提示保真度和结构适应性方面均取得了有竞争力或更优的性能。

附录 0.A EOS 分析

EOS 线性的实证分析。 虽然先前工作已表明 CLIP 文本嵌入通常在语义因子上表现出近似的线性组合性 [32]，但同样的性质是否适用于 ⟨EOS⟩ 隐藏状态并非显然，因为后者通过因果注意力聚合上下文信息，而非词嵌入的简单求和。我们不假设精确线性性，而是实证检验外观残差 $\Delta_{app}=eos_{id}-eos_{sty}$ 是否表现为可迁移的语义方向。

为此，我们构建了一个涵盖多样化主体、风格和场景的大型提示集，外观属性复杂程度各异——从短语到长关系描述（图 11）。

平行性。 我们首先测试 $\Delta_{app}$ 是否独立于提取它的主体编码外观。从相同属性但不同主体提取的残差保持高度对齐，而来自不同属性的残差明显分离。这表明 $\Delta_{app}$ 捕获的是主体无关的外观方向，而非主体特定的内容。

可迁移性。 然后我们将从一个主体提取的 $\Delta_{app}$ 添加到仅包含主体和场景描述的不同提示的 ⟨EOS⟩ 中，并将其与显式声明该属性的显式提示（主体+外观+场景）的嵌入（迁移目标）进行比较。两者高度相似，而无外观的基础和不匹配的随机属性则明显区分。值得注意的是，即使对于长的组合短语，这也成立，表明 EOS 级残差以线性方式迁移丰富的外观语义——而不仅仅是单个词。

生成效果。 最后，将注入的残差缩放为 $eos_{sc}+\lambda\cdot\Delta_{app}$ 会逐步增强生成图像中的目标外观（图 11 底部）：随着 $\lambda$ 增大，属性（如圆框眼镜）出现并增强，确认残差对生成施加可控的、单调的影响。

总之，这些结果表明 $\Delta_{app}$ 作为主体无关、可迁移且可控的外观方向——证明了我们 EOS 级残差操作的合理性。

子空间构造。 为计算与外观和场景子空间的对齐，我们首先从 Consistory+ 基准中收集所有外观和场景相关短语。为验证是否可以构造有意义的子空间，我们检查每组 PCA 的累积解释方差。如图 12 所示，捕获 90% 的累积方差仅需要 81 维（外观）和 221 维（场景），而 CLIP 文本嵌入空间总共有 768 维。

附录 0.D 局限性与未来工作

虽然我们的模型有效平衡了提示和主体的连贯性，但仍存在若干局限性。虽然交叉注意力图通常准确捕获主体区域，但它偶尔无法关注正确的区域，导致错位或部分错位的生成——这些问题在先前工作中也被观察到。这可以通过显式使用主体掩码作为附加条件来处理。此外，存在模型完全无法生成准确图像的情况（如图 30 中的"农牧神"），这似乎是底层 SDXL 主干的固有局限。此外，由于跨上下文桥接利用了 CLIP ⟨EOS⟩ token 的上下文摘要特性，它不能直接迁移到基于 T5 或基于 LLM 的文本编码器的模型，因为在这些模型中 ⟨EOS⟩ token 不再扮演可比的角色。在此类编码器上实现类似的基于残差的语义组合是将我们的框架扩展到更广泛的现代扩散模型的一个有前景的方向。
