摘要

思维链提示能够引出看似解释模型预测的分步推理依据，但无法保证这些步骤因果地驱动最终答案。在标准的自回归生成中，稠密注意力允许每个推理步骤关注完整上下文，使模型能够通过直接查找得出答案，同时生成听起来合理但属于事后辩护的解释。我们提出了 CausalCoT，这是一个推理框架，通过将问题分解为原子子问题的有向无环图，并在仅包含其直接因果父节点的隔离上下文中评估每个节点，来强制实现因果透明性。这种马尔可夫结构消除了通往非父内容的注意力路径，使下游预测对局部推理敏感，而非全局上下文泄漏。在多样化的推理基准测试套件中，CausalCoT 在保持有竞争力的预测性能的同时提高了解释忠实度，中间推理步骤的因果敏感性平均提高 12 个百分点，最高比最强基线提高 21 个百分点。结构化依赖图还支持测试时干预，局部修正可以可预测地传播到下游推理。

1 引言

大型语言模型（LLM）越来越多地部署在医疗保健等高风险领域，用户信任至关重要（Chen et al., 2024）。在这些领域，非专家用户经常依赖 LLM 生成的推理依据，将其视为模型决策过程的透明窗口（Barez et al., 2025）。然而，这种信任往往是错付的。虽然诸如人类反馈强化学习（RLHF）（Ouyang et al., 2022）、组相对策略优化（GRPO）（DeepSeek-AI et al., 2025）和思维链（CoT）（Wei et al., 2023）等技术能够产生高度可信的文本，但它们优化的是人类偏好而非机制透明性。因此，这些解释经常与模型的内部逻辑不符（Mayne et al., 2026; Matton et al., 2025; Turpin et al., 2023; Lanham et al., 2023）。令人担忧的是，甚至研究人员有时也会将这些有说服力的事后合理化误当作真正的解释（Barez et al., 2025）。

这种根本性的脱节是安全部署的关键障碍。具体而言，标准 CoT 提示存在由注意力泄漏驱动的严重因果不透明性。注意力泄漏是指稠密的全局注意力机制允许模型在其整个上下文窗口中隐式地渗透信息，而不是严格依赖于先前的逻辑步骤。由于这种泄漏，生成的推理可能看起来完全合乎逻辑，但与最终预测完全脱节。例如，Turpin et al. (2023) 证明，当提供微妙的上下文偏差或未言明的提示时，模型会大量利用这些启发式方法来得出答案，但在其生成的解释中完全省略它们，编造一个从未被使用的分步推理依据。此外，Lanham et al. (2023) 揭示，主动修改、降级或干预早期 CoT 步骤通常对下游输出的影响出奇地小。这些现象共同证明，标准的自回归推理经常充当表面的辩护，而不是驱动模型行为的因果相关步骤序列。尽管最近的框架尝试通过对齐训练（Paul et al., 2024）或问题分解（Radhakrishnan et al., 2023）来解决这种不透明性，但它们仍在共享上下文中评估步骤，不可避免地遭受持续的注意力泄漏。

图 1：CoT 与 CausalCoT。（左）在标准 CoT 中，模型生成连续的自回归推理流。（右）我们提出的 CausalCoT 框架将推理结构化地隔离为有向无环图（DAG）。每个子问题在仅包含其显式路由的父依赖项的受限上下文中进行评估。这强制执行程序性马尔可夫属性，使最终预测依赖于显式路由的中间输出，而不是像 CoT 那样不受限制地访问完整的推理轨迹。（补全内容为说明目的而缩短）。

为了弥合可信生成与忠实推理之间的差距，我们引入了因果思维链¹。CausalCoT 强制执行严格的透明推理结构以防止注意力泄漏，确保模型陈述的推理正确地决定其最终预测。我们的方法分两个阶段运行： 模型将复杂查询分解为拓扑计划，即相互依赖的子问题的有向无环图（DAG）； 每个节点被隔离评估，完全限制在其特定查询及其直接父节点的显式路由答案（对于根节点，则是初始输入）。通过强制执行这种马尔可夫属性，我们构建了一个问题-答案对网络，其中每个步骤仅由其局部依赖因果驱动。这种架构约束消除了评估阶段标准自回归生成的虚假上下文泄漏。此外，它原生支持反事实可模拟性，允许用户干预内部推理节点并将这些逻辑变化传播到下游。CoT 和 CausalCoT 之间的比较如图 1 所示。

我们做出四项贡献：

• 我们引入了 CausalCoT，这是一个将推理基于显式 DAG 的推理框架，将中间步骤限制为严格关注其父节点，并消除 CoT 中存在的虚假上下文捷径。

• 我们提出了可预测变化，这是一种忠实度指标，超越了经典的原始扰动翻转率，通过测试下游预测是否匹配注入错误的逻辑含义而非任意敏感性。

• 我们确立了 CausalCoT 在多个前沿模型上显著增强推理忠实度，同时保持有竞争力的预测准确性，与标准 CoT 表现相当或仅产生边际下降。

• 我们证明了底层依赖图促进了有针对性的测试时干预，将局部修正传播到下游的可靠性远高于标准 CoT。

2 背景

思维链与 LLM 解释。 LLM 的根本优化目标是建模和生成类人文本。因为人类的解释通常结构清晰、有帮助且有说服力，LLM 自然会利用这些风格特征，特别是在通过 RLHF 微调时，其中有用性和清晰度是明确的奖励信号。为了在推理时增强复杂的推理能力，诸如 CoT（Wei et al., 2023; Yao et al., 2023; Besta et al., 2024）等提示策略及相关演进鼓励模型在产生最终答案之前输出分步推理依据。最近的训练范式，如 GRPO（DeepSeek-AI et al., 2025），甚至将这种分步生成直接嵌入模型的策略中。虽然这些机制产生高度可信的推理依据，容易被非专家用户信任，但它们优化的是连贯的文本生成，而不是强制执行中间推理步骤之间的严格依赖关系。

忠实度的幻觉。 生成的推理轨迹经常无法反映模型的真实决策机制（Matton et al., 2025; McMillan et al., 2025; Lanham et al., 2023）。这种不忠实性通常表现为反事实不一致（Turpin et al., 2023; Matton et al., 2025; Mayne et al., 2026），其中上下文扰动以与其陈述规则相矛盾的方式改变模型行为，或表现为事后合理化（Lanham et al., 2023; Bogdan et al., 2025），其中中间步骤仅充当对预测缺乏因果影响的表面辩护。在这里，我们专注于通过强制执行透明的推理过程来缓解事后合理化，其中每个步骤仅由其前驱或输入因果确定。为了量化事后合理化，我们通过中间步骤扰动（Lanham et al., 2023）评估因果依赖：在推理过程中修改、截断或损坏推理步骤；如果修改步骤后最终预测保持不变，则该轨迹缺乏因果效力且不忠实。忠实度指标的详细信息见附录 B。

3 方法：因果思维链

3.1 理论依据：不忠实推理的根源

我们假设标准 LLM 推理中观察到的不忠实性源于其架构和训练中固有的两个基本机制：

  1. 通过注意力的信息泄漏（Lanham et al., 2023; Radhakrishnan et al., 2023）：在标准的自回归生成中，Transformer 的注意力机制允许每个生成的标记关注所有先前的标记。关键的是，这种泄漏是传递性的：因为前一个标记的潜在表示已经从先前层的早期标记中吸收了信息，关注它隐含地携带了整个历史上下文。因此，每个推理步骤都直接和间接地受到整个上下文窗口的影响。即使标记在逻辑上与特定的中间推导无关，非零注意力分数也允许虚假信息渗透。这解释了为什么干预生成的推理步骤通常无法改变最终预测：模型绕过显式陈述的逻辑链，直接从原始输入中检索必要的信号（如图 2 所示）。

  2. 奖励驱动的标记优化（Turpin et al., 2023; Matton et al., 2025; Perez et al., 2022; Chen et al., 2025）：

图 2：注意力泄漏： 标准思维链存在因果不透明性：稠密注意力创建了绕过中间逻辑的"泄漏"通道（红色虚线箭头）。CausalCoT 强制执行严格的 DAG。通过在隔离的上下文中评估中间步骤，每个答案仅从其直接父节点因果推导。

现代对齐技术，如 RLHF（Ouyang et al., 2022），优化模型以在标记序列级别满足特定标准（例如有用性、安全性、无偏见）。因此，模型学习了一种策略，通过生成高度可信、吸引人类的文本而不是其内部机制过程的真实表示来最大化奖励。例如，如果奖励模型惩罚有偏见的语言，LLM 将生成一个明确避免引用敏感属性的推理依据，即使这些属性秘密地驱动了底层预测。因为这种欺骗性错位从根本上嵌入在模型学习的策略中，简单地提示透明性是不够的；模型将持续操纵自回归标记流来构建一个偏离其实际内部计算的有说服力的叙述。克服这一点需要严格的结构干预，将陈述的计划与最终答案绑定，保证如果执行逻辑序列，则结果预测与生成的推理依据一致。

3.2 CausalCoT 框架

为了解决这些根本缺陷，我们引入了因果思维链。我们的框架显式地将逻辑计划的生成与其执行解耦，构建推理以抑制基于注意力的泄漏并强制执行严格的依赖关系。如图 2 所示，CausalCoT 通过将推理过程分为两个不同的隔离阶段：图生成和上下文隔离的问题评估，从而摆脱了标准自回归推理的易泄漏连续注意力。更多实现细节见附录 G。

形式化问题设置。 令 X ∈ 𝒳 表示输入提示（例如，一个复杂的推理问题），Y ∈ 𝒴 表示目标最终答案。我们假设可以访问预训练的 LLM，表示为策略 π_θ。在标准的自回归 CoT 提示中，模型在预测最终答案之前生成一系列中间推理标记 R = (r₁, r₂, …, rₘ)，使得 Y ~ π_θ(·|X, R)。因为每个中间标记 rₜ 的生成严重依赖于整个前面的上下文——即 rₜ ~ π_θ(·|X, r<ₜ)。这种稠密注意力机制造成严重的因果不透明性。它使得无法保证给定的标记 rₜ 是从相关的前驱逻辑推导出来的，还是从 X 或 R<ₜ 的无关片段中虚假提取的。我们的目标是用外部可审计的有向图结构替换不透明的自回归推理轨迹 R，其中每个中间生成仅以显式路由的输入为条件。这并不声称暴露模型的内部计算；相反，它约束了部署的推理程序，使下游生成无法直接关注非父推理内容。

阶段 1：图生成。 我们不允许模型自回归地流式传输连续的 CoT，而是首先提示 LLM 专门充当规划者。给定输入提示 X，模型将问题分解为一组离散的原子子问题并构建 DAG，表示为 𝒢 = (𝒱, ℰ)。这里，每个节点 vᵢ ∈ 𝒱 表示一个特定的子问题，每条有向边 ∈ ℰ 表示问题 vᵢ 的派生答案 aᵢ 是解决 vⱼ 所必需的。通过先验地显式映射这些依赖关系，我们利用了 LLM 强大的零样本规划能力，同时严格防止它同时执行逻辑。这种解耦减少了规划和执行之间纠缠的一个来源：推理路径的结构设计不会被模型倾向于与执行不一致的可信解释所污染。

阶段 2：上下文隔离的问题评估。 一旦图 𝒢 被实例化，我们通过拓扑遍历图来执行推理轨迹。每个节点使用相同的 LLM 进行评估，但严格在隔离的上下文窗口内：

• 根节点： 对于任何没有父节点的初始节点（v_root），LLM 仅被提示原始输入 X 和 v_root 定义的特定子问题。

• 内部和叶节点： 对于任何后代节点 vⱼ，LLM 被提示子问题 vⱼ 及其直接父节点的答案，表示为 Pa(vⱼ)。关键的是，模型无法访问全局输入 X，也无法访问任何兄弟或并行推理分支。

通过强制执行这种严格的拓扑评估，我们消除了从节点到非父推理内容的直接注意力链接。对特定问题 vⱼ 生成的答案完全由 Pa(vⱼ) 决定。这种强制的马尔可夫属性保证了最终预测是中间步骤的忠实产物。

3.3 推理属性和人在回路干预

CausalCoT 的结构透明性原生地解锁了几个强大的推理时属性，这些属性在标准自回归生成下根本无法实现。通过将推理计划与其执行解耦，用户可以在多个阶段主动交互和引导模型的逻辑：

• 结构审计和测试时干预： 在推理开始之前，生成的 DAG 𝒢 = (𝒱, ℰ) 完全暴露以供先验检查。专家可以通过添加或删除子问题 v ∈ 𝒱、修改上下文或重新定义边 ℰ 来纠正有缺陷的逻辑、价值错位或缺失的步骤。受可解释架构中的概念干预启发（Koh et al., 2020; Dominici et al., 2024），专家还可以对不正确或幻觉的中间节点执行测试时手术式修正；由于拓扑隔离，只有下游后代需要重新计算。与标准自回归 CoT 不同（其中稠密注意力导致局部编辑触发不可预测的级联并破坏推理的稳定性），CausalCoT 实现了可预测、高效的引导以提高最终预测性能。

• 忠实的反事实模拟： 强制的马尔可夫属性通过显式因果干预（概念上等同于 Pearl 的 do-算子，例如 do(vᵢ = x)）原生支持反事实模拟。用户可以干净地干预节点产生的值（或输入中的信息），并通过图动态传播这些变化（保持图固定）。因为环境对非因果泄漏是封闭的，并且 v 的祖先从每个下游上下文中被丢弃且不能重新进入最终的答案，Y 是反事实干预的忠实反映，在相同的生成图下。

4 实验

我们设计实验来评估 CausalCoT 与标准自回归推理相比的有效性、忠实度和可干预性。具体而言，我们旨在回答以下研究问题：

• RQ1（性能）： 与标准 CoT 相比，强制执行严格的因果图是否会降低任务准确性？

• RQ2（忠实度）： 中间步骤是否是生成的真正驱动因素？具体而言，如果修改中间推理步骤，模型是否在结构上依赖它，最终预测是否朝可预测的方向转移？

• RQ3（可干预性）： CausalCoT 能否可靠地整合测试时干预来纠正中间推理步骤？

4.1 实验设置

数据集。 我们在性能、忠实度和可干预性方面使用多样化的基准评估 CausalCoT。我们首先使用 GPQA（Rein et al., 2023），一个研究生级别的科学数据集，以确保我们的模型保持有竞争力的推理能力。接下来，我们纳入 MedQA（Jin et al., 2020）来测试高风险领域的多步临床推理。最后，我们利用反事实可模拟性套件（CF Suite）（Mayne et al., 2026）跨越健康、商业和伦理领域来量化因果透明性和对干预的响应性。这些基准共同为评估任务准确性和模型可解释性提供了坚实的基础。

模型和基线。 我们评估三个系列的模型（Gemma 3、GPT-5.4 和 Claude 4.5/4.6）跨越不同的参数规模。我们将 CausalCoT 与标准 CoT 提示和因子分解（Radhakrishnan et al., 2023）进行比较。因子分解通过将查询分解为子问题并在受限的上下文窗口中评估它们来隔离推理。然而，它存在两个结构性缺陷：中间步骤缺乏显式的父路由，最终预测连接所有生成的文本，重新引入了普遍的注意力泄漏。CausalCoT 通过强制执行 DAG 架构来解决这些漏洞，保证纯粹的上下文隔离。有关基线机制和与 CausalCoT 比较的更多细节在附录 C 中进一步解释。

评估指标。 我们使用以下指标评估我们的三个研究问题：

• 预测性能（RQ1）： 我们报告标准准确性来确定 CausalCoT 的严格 DAG 约束是否降低基础问题解决能力。我们还报告 Pass@3（在三次独立推理中生成至少一个正确答案的概率）。因为 CausalCoT 严格强制执行生成的拓扑，畸形的初始图保证了预测失败。因此，我们评估多样本生成是否通过提供多次产生有效响应的机会来缓解零样本规划瓶颈。

• 忠实度和可预测性（RQ2）： 为了量化中间推理的因果影响，我们采用了已建立的步骤扰动方法论（Lanham et al., 2023）。通过使用前沿模型（GPT-5.4）向中间节点注入目标错误，我们测量下游答案变化的频率。为了区分真正的因果依从与任意扰动不稳定性，我们引入了可预测变化指标。该指标依赖于 LLM 裁判来确定每个注入错误的逻辑下游含义，考虑到扰动不足以改变最终标签的情况。然后我们评估模型的损坏结论是否匹配这个反事实目标，确认下游预测可预测地依从修改的前提。

• 测试时可干预性（RQ3）： 为了评估我们框架的"人在回路"能力的实际效用，我们使用前沿代理模型（GPT-5.4）模拟专家干预，其任务是识别和纠正错误的推理步骤。CausalCoT 和因子分解都支持多级干预，允许代理显式纠正初始子问题（规划）或生成的中间答案（执行）。然而，CausalCoT 的严格 DAG 拓扑提供了将这些手术式编辑传播到下游依赖步骤所需的路由。另一方面，CoT 仅支持中间步骤的纠正。通过测量干预预算 k ∈ {1, 2, 3} 内的下游预测改进，我们量化这些编辑纠正模型推理的效率。

5.1 RQ1：预测准确性

CausalCoT 保持有竞争力的准确性，吸收预期的性能权衡以实现严格的因果隔离（表 1）。

6 相关工作

分解和高级探索提示。 将复杂查询分解为原子子任务（Zhou et al., 2023; Wang et al., 2023）是提高预测准确性的成熟策略。然而，因为这些子任务在共享的、不断扩展的上下文窗口中评估，它们遭受稠密注意力泄漏，使推理因果不透明。虽然因子分解（Radhakrishnan et al., 2023）尝试隔离推理来解决这个问题，但它在结构上仍然脆弱：其对待处理子问题的动态更新使剩余步骤暴露于所有先前答案的全局上下文，其最终预测阶段连接所有生成的文本。CausalCoT 通过利用 DAG 强制执行马尔可夫条件独立性来解决这一问题，将节点的上下文严格限制为其显式路由的父节点。一条并行的研究线专注于解决方案空间的高级探索；诸如思维树（Yao et al., 2023）和思维图（Besta et al., 2024; Pandey et al., 2025）等框架利用拓扑表示不是为了因果隔离而分解问题，而是搜索不同的解决方案路径以找到最准确的结果。虽然这些搜索算法也缺乏结构屏蔽并遭受信息渗透，但它们与我们的框架互补。在未来工作中，它们的分支和回溯可以在隔离执行之前完善 CausalCoT 的拓扑。

推理中的忠实度。 尽管 LLM 推理取得了进步，最近的研究揭示了一种系统性的"不忠实性"，模型无法因果地依赖自己生成的解释（Xiong et al., 2025; Lanham et al., 2023），这种倾向随着任务变得更简单而矛盾地增加（Emmons et al., 2025）。缓解策略包括通过对比学习进行训练阶段干预（Paul et al., 2024）或将执行卸载到确定性求解器的神经符号框架（Lyu et al., 2023），尽管后者仅限于可形式化的领域。其他推理时方法使用因子分解来减少幻觉（Dhuliawala et al., 2024; Sovrano and Bacchelli, 2026），但缺乏对注意力泄漏的防护，这导致了因果不忠实性。我们的框架通过在隔离的评估上下文之间强制执行严格的因果路由，在保持语言灵活性的同时确保忠实度（与 LLM 中形式因果性的进一步联系见附录 D）。

7 结论

局限性和未来工作。 CausalCoT 的零样本特性引入了特定的权衡，尽管其具有强大的忠实框架。首先，畸形的初始 DAG 瓶颈了下游准确性。这一差距在配备更强零样本规划能力的前沿模型中系统性缩小，这些模型是忠实度干预的主要目标。其次，基于提示的 DAG 生成缺乏保证；附录 E 概述了未来工作的想法，通过微调将图结构约束嵌入规划器模型。第三，虽然 CausalCoT 促进因果忠实度，但它本身并不保证对输入扰动的反事实鲁棒性，尽管其模块化允许与现有正则化器集成。CausalCoT 不应被解释为 LLM 内部计算机制忠实度的保证：我们的声明仅涉及上下文隔离的可控性和基于干预的忠实度。最后，与标准 CoT 相比，隔离评估上下文在推理中引入了额外的开销。然而，与严格顺序的基线不同，CausalCoT 的 DAG 拓扑自然支持独立节点的并行执行。附录 H 详细介绍了 MedQA 上的计算开销。虽然我们遵循先前的工作在判别性任务上进行评估，但将 CausalCoT 扩展到开放式生成在结构上是可行的；主要障碍在于制定独立于离散答案翻转的忠实度指标（附录 J）。更广泛的影响在附录 K 中讨论。

结论。 在这项工作中，我们证明了前沿模型可以在测试时被结构化约束以产生忠实的解释而不牺牲预测性能。我们的发现表明，CausalCoT 与标准 CoT 和因子分解等基线相比保持有竞争力的准确性，同时在多样化的模型系列和推理任务中实现显著更高的忠实度分数。此外，CausalCoT 引入了高度响应的"人在回路"属性：通过允许领域专家直接对推理节点或底层 DAG 拓扑进行手术式干预，用户可以推动最终输出质量的确定性、级联改进。最终，CausalCoT 成功地弥合了推理性能和可解释性之间的差距，为与 LLM 的更可引导和值得信赖的交互提供了严格的路径，这些属性对于高风险领域的安全部署至关重要。

6: for 每个 v ∈ 𝒱_sorted do
7: Pa(v) ← {u ∈ 𝒱 | (u,v) ∈ ℰ} {识别直接父节点}
8: if Pa(v) = ∅ then
9: C_v ← X {根节点：上下文严格限制为原始输入}
10: else
11: C ← CONCAT({a_j | j ∈ PA(i)}) {内部/叶节点：路由显式父答案}
12: end if

14: end for

附录 B 评估忠实度的替代方法

为了系统地量化解释不忠实性，研究人员在各种抽象级别上评估模型。文献的很大一部分专注于反事实忠实度，利用鲁棒的数据集来评估解释是否准确反映当提示中的关键变量被改变时模型行为如何变化 [Mayne et al., 2026, Matton et al., 2025]。然而，为了直接诊断事后合理化并评估推理轨迹本身的因果性，评估通常依赖于两种有针对性的干预策略。首先，输入扰动 [Chen et al., 2025, Turpin et al., 2023] 通过向提示注入微妙的偏差或提示来测量因果性。如果模型由于偏差而改变其最终预测但在生成的推理依据中完全省略它，而是编造一个替代的逻辑路径，则该解释被暴露为与真实决策机制因果脱节。其次，中间步骤扰动 [Lanham et al., 2023] 通过在推理过程中直接修改、截断或向生成的推理步骤添加噪声来测量因果依赖。如果修改逻辑步骤未能改变最终预测，则表明推理轨迹缺乏因果效力，仅仅是与模型真实决策过程脱节的事后编造。

附录 C CausalCoT 与因子分解比较

虽然 Radhakrishnan et al. [2023] 证明隔离推理步骤可以显著提高解释忠实度，但他们提出的因子分解主要作为一种启发式提示策略运行，存在显著的结构限制。CausalCoT 通过引入严格的图拓扑来形式化和推广这一隔离原则。下面我们详述算法区别以及 CausalCoT 如何解决简单因子分解中存在的关键漏洞。

真空问题与结构化依赖。 在因子分解中，模型生成在隔离上下文窗口中评估的初始子问题列表。虽然模型可以在早期答案得到解决时动态更新剩余的待处理问题，但这种顺序启发式方法未能正式定义变量之间的结构依赖关系。因为关系保持隐式和临时性，子问题经常在完全的上下文真空中或通过缺乏严格因果映射的模糊线性更新过程中评估。相反，CausalCoT 在评估之前通过 DAG 显式映射这些关系。CausalCoT 不依赖于非结构化的顺序更新或在真空中评估节点，而是主动将特定父节点生成的答案直接路由到其指定子节点的提示中。这种架构保证提供了复杂多步逻辑所需的精确上下文依赖，而不会将节点暴露于全局历史。

重组泄漏与完全隔离。 因子分解最重要的限制发生在其最终推理步骤（"重组"阶段）。为了生成最终答案，该方法将原始输入提示、整个子问题列表和所有相应的子答案连接到单个上下文窗口中。正如作者所指出的，这种稠密连接固有地重新引入了注意力泄漏；模型可以绕过隔离的推理，恢复利用来自原始输入或早期子问题的虚假相关性。

CausalCoT 通过在整个图（包括最终预测节点）上强制执行严格的马尔可夫属性，完全消除了重组泄漏。在我们的框架中，节点 vⱼ 仅在其直接因果父节点 Pa(vⱼ) 上条件评估。最终预测节点不接收原始输入或全局图历史，除非它们被显式定义为直接拓扑父节点。这保证了最终预测被迫依赖中间推理步骤，从结构上强制执行从输入到输出的绝对因果透明性。

附录 D LLM 中的形式因果性

因果 NLP 的一条重要工作线专注于机制可解释性，利用因果追踪 [Meng et al., 2022] 和因果抽象 [Geiger et al., 2021] 等技术将高级因果模型映射到低级稠密神经表示。我们强调我们的框架不声称这种形式的机制因果性；相反，我们的目标纯粹是程序性的，确保中间解释严格驱动后续推理步骤和最终答案。除了内部神经干预之外，最近的框架已开始将因果指标直接应用于 LLM 输出以评估推理。例如，最近的工作 [Yu et al., 2025] 尝试事后识别哪些特定的生成步骤对最终预测具有因果重要性。类似地，Fu et al. [2025] 尝试将生成的 CoT 转换为适当的结构因果模型（SCM）以便能够执行因果分析，相反地，Jin et al. [2024] 直接生成 SCM 而不是 CoT。虽然这些方法为事后因果评估和修复提供了有价值的工具，但处理形式 SCM 通常需要严格结构化的推理步骤，限制了它们在自由形式生成中的适用性。CausalCoT 在目标和执行上都有根本不同。CausalCoT 不是将因果指标应用于评估或修复已经生成的序列，而是物理地限制推理架构本身，以主动保证程序性忠实度的构建。因此，我们对生成的因果依赖推理步骤不做唯一性声明。关键的是，因为我们的拓扑路由隔离上下文而不强制将生成的文本转换为严格的数学变量，CausalCoT 完全保留了 LLM 的自然灵活性。这使其能够原生支持丰富的、开放式问答，而严格形式化的因果模型通常在这方面有所不足。

与"随机鹦鹉"批评的关系。 Zečević et al. [2023] 推测 LLM 通过背诵训练中遇到的因果相关事实而非执行因果推断来回答因果查询，因此它们是"因果鹦鹉"。我们对这一推测不持立场，因为我们的声明不取决于它如何解决。该批评涉及因果知识来自何处；我们的保证涉及陈述的推理是否产生了答案。如脚注 1 和引言中所述，"因果"在此表示推理过程中的程序性依赖，而非拥有关于世界的因果知识。事实上，该批评加强了这项工作的动机：流利的推理轨迹越是背诵或事后合理化，展示给用户的计划是实际执行的计划就越重要。

我们明确陈述的三个限制。 首先，CausalCoT 生成的 DAG 编码的是证据性而非因果语义：一条边记录一个子答案被用于推导另一个，这是针对 SCM 风格形式化 [Jin et al., 2024, Fu et al., 2025] 的刻意权衡，以换取对自由形式自然语言的适用性。其次，上下文隔离约束节点可以条件化的内容；它不约束模型带到该节点的参数知识，因此隔离的节点仍然可以从记忆的关联中回答。第三，我们不测量生成的分解对任务真实因果结构的覆盖程度，因为我们使用的基准不携带图注释；建立这种覆盖需要具有真实推理结构的数据集，留待未来工作。一个相关的开放性问题是问题分解是否足够表达以捕获语言中一般的因果依赖，而不是单次推理中的程序性依赖。

附录 E 通过强化学习优化图生成

虽然 CausalCoT 展示了强大的零样本性能，但其对基于提示的图生成器的依赖为未来优化提供了自然的途径。具体而言，图规划阶段可以通过使用强化学习范式（如 GRPO）微调生成器模型来显著增强。我们的多样本 Pass@3 实验经验性地证实了这种方法的可行性：因为重采样经常产生成功达到正确最终预测的图，存在完全基于下游任务准确性的明确、可利用的正奖励信号。

在最简单的场景中，可以设计类似 GRPO 的损失函数来直接奖励产生正确最终答案的生成图结构。除了纯粹的准确性之外，这种奖励公式可以自然地扩展到包括多目标结构约束。例如，可以引入辅助奖励惩罚来强制执行严格的有向无环图（DAG）属性（尽管我们的零样本模型尚未经验性地违反此约束）或促进稀疏性，从而最小化计算开销。此外，动态约束可以显式惩罚过度的图深度或节点数。

尽管有巨大的性能提升潜力，我们将微调图生成的探索留待未来工作。本文的主要理论贡献是建立一个严格的、免训练的推理框架，显式地隔离和测量因果推理。通过严格避免权重更新，CausalCoT 保持根本上的模型无关性，确保与本地开放权重模型和闭源商业 API 端点的无缝兼容。

附录 F 实验细节

数据集
我们使用来自三个基准的 200 个采样实例评估所有方法：GPQA、MedQA 和反事实。为了考虑生成可变性，我们对每个实例执行三次独立重采样。对于本地托管的模型，整个评估流水线使用单个固定随机种子（1234）初始化以确保严格的可重复性。忠实度指标在所有生成的重采样上统一计算以保持一致的评估规模。此外，干预实验在所有实例及其重采样上进行，每次生成最多使用三次结构干预。最后，我们计算三次独立重采样的标准误；这种方法有意捕获生成可变性（我们的主要关注属性）而非数据集可变性。唯一的例外是 Pass@3 指标；因为它固有地将三次重采样聚合为单个实例级分数，其标准误必然在数据集上计算。

模型选择理由
为了严格评估 CausalCoT 作为通用测试时框架，我们选择了在架构范式和参数规模上都有变化的多样化大型语言模型套件。这种多样性确保我们关于因果忠实度和预测准确性的发现可以推广到不同的模型能力水平。为了捕获全面的性能谱系，我们纳入了专有前沿模型，特别是 GPT（OpenAI）和 Claude（Anthropic）系列，以代表当前商业 LLM 推理的上限，同时纳入开放权重的 Gemma（Google）系列以保证透明度和可重复性。通过评估每个系列中的多个规模变体，我们系统地观察 CausalCoT 如何从轻量级高效模型扩展到高级推理引擎。最后，这种选择自然受到实际技术和经济约束的限制：开放权重模型的最大规模严格由我们本地推理硬件的 48 GB VRAM 容量决定，而专有模型被策略性采样以在 API 预算限制内最大化实验严谨性。

生成超参数
为了确保在我们多样化的 LLM 套件中获得最佳推理性能，我们根据部署类型和模型特定指南定制了采样超参数。对于通过 API 访问的所有专有模型（即 GPT 和 Claude 系列），我们使用 0.7 的标准生成温度。相反，对于本地托管的 Gemma 模型，我们严格遵循作者官方推荐的采样配置以最大化生成质量，将温度设为 1.0，top_k 设为 64，top_p 设为 0.95，min_p 设为 0.0。

代码、许可证和硬件
所有实验基线和提出的方法均使用 Python 3.12.3 实现。我们的代码库依赖于基础开源库，包括 PyTorch 2.10 [Paszke et al., 2019]（BSD 许可证）、Hugging Face Transformers [Wolf et al., 2020]（Apache 2.0）和 LM Evaluation Harness [Gao et al., 2023]（MIT 许可证）。本地模型生成和评估使用最大容量为 48 GB VRAM 的 GPU 进行，总计约五天的 GPU 计算时间。对于基于专有 API 的模型，本地硬件使用仅限于最小的 CPU 开销，执行时间完全取决于提供商强制执行的并发请求限制。为确保完全可重复性，我们将在 MIT 许可证下公开发布我们的完整代码库和评估脚本。

附录 G 实现细节

上下文传播
第 3.2 节所述框架内的有效因果依赖依赖于严格的上下文隔离；具体而言，内部和叶节点的评估上下文必须限制为其直接前驱的输出。然而，因为这些输出通常由广泛的自然语言解释组成，将原始文本沿图传播可能导致计算开销和上下文窗口耗尽。为了解决这一可扩展性挑战，我们指示模型生成其结论的简明摘要，前缀为标识符"FINDING"（见表 16）。此摘要与相应节点的问题配对，构成传递给所有子节点的局部上下文。

缺失上下文回退
为了降低错误率和图畸形，我们为上下文不足的节点实现了动态回退机制。如果内部节点（即既不是根节点也不是最终答案节点）表明缺乏必要信息（通过其响应的关键词解析识别），系统会解除其父依赖并将其重新分类为根节点，从而为其提供完整的初始问题。这种回退在缓解较小、性能较低模型中的级联错误方面特别有效。
