Abstract
As LLMs continue to scale, improving training efficiency increasingly depends on using data more effectively. Data selection addresses this problem by allocating a limited training budget to samples that best promote a target behavior. Existing methods usually represent the target behavior with a set of target examples, but often treat these examples as equally important. This can be inefficient because target examples may differ in their relevance to the current model: examples closer to the model’s current behavior provide more actionable guidance than those farther away. Target behavior representation.
Before training examples can be scored, the target behavior must be represented as a direction or signal. Existing methods build such representations in different spaces. Concept Influence and Persona Vectors construct activation-space directions, often by averaging representations of examples that express a concept or trait

PRISM relaxes this assumption by weighting target examples according to the current model’s preference, producing a preference-aware target direction for training-data scoring.

3.1
Motivation and Definition
The goal of PRISM is to identify, under a limited data budget, the candidate SFT examples that have the largest estima

ted effect on a target behavior. Achieving this requires a precise representation of the target behavior itself. When the target behavior is described by multiple target examples, these examples can differ substantially in how useful they are for guiding the current model: examples closer to the model’s existing behavior often provide more actionable local guidance, while distant examples may provide weaker selection signals.
PRISM therefore represents the target behavior in a preference-aware way. It first uses the current model’s preference to distinguish the local usefulness of different target examples, and then uses influence scoring to estimate how each candidate SFT example affects this preference-aware target behavior. The resulting ranking supports both directions of data control: for desired behaviors, high-ranked examples can be retained for efficient fine-tuning; for undesired behaviors, high-ranked examples can be removed for repair.

Ablation Studies on Reverse Repair
We ablate PRISM in the same reverse-repair protocol used above.
Specifically, we use the Qwen-3-14B emergent-misalignment settings from Section

Both preference weighting and paired anchors are necessary for stable repair.
Removing the preference weight reduces AUROC on all eight settings, indicating that the strength of the misaligned paired preference helps rank harmful examples. Removing both the preference weight and paired anchors causes a much larger AUROC drop. This supports the main design choice: target failures should be represented as paired preference signals, not as unpaired attribution targets. After retraining, the full method gives the lowest benchmark dishonesty on seven of the eight settings.
6
Conclusion
In this paper, we propose PRISM to improve the budget efficiency of data selection for SFT. PRISM represents a target behavior with model preference, giving larger weights to target examples that are more actionable for the current model, and then traces this preference-aware direction back to candidate training data through influence scori

ng. This enables the same ranking rule to support both efficient forward selection and safety-oriented reverse repair. Through experiments across model families and scales, PRISM consistently selects data that leads to stronger fine-tuning performance and more effective behavioral repair under fixed budgets. We also provide a first-order theoretical explanation showing why preference-aware target representation improves the selection direction. In this way, PRISM offers a simple perspective on data selection: better target-behavior characterization can make limited SFT data more useful.

Appendix A
Benchmark-derived Repair Signal
All data-selection methods are evaluated under the same benchmark-derived repair setting from Section
5.3
. For each mixed dataset, we first fine-tune the model on the unfiltered SFT data and evaluate both the pre-SFT and post-SFT models on
mask_provide_fact
. We then collect the benchmark queries whose behavior changes undesirably and pair the pre-SFT response with the post-SFT response on the same query. This shared paired-response set is the only benchmark-derived signal provided to the data-selection

methods. Each method converts this signal into a score over the original SFT examples, removes the same fixed fraction of high-risk examples within a setting, and retrains from the same starting model on the retained data. Thus, the experiments compare scoring rules while holding both the supervision source and the deletion budget fixed. Section
5.3.4
varies the retained data ratio explicitly.
