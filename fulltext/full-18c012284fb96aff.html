摘要

虽然直接从冻结的 LLM 中获取文本嵌入已成为一个有前景的方向，但现有方法几乎完全专注于英语，多语言场景在很大程度上尚未被探索。在本工作中，我们首次对 LLM 中的多语言免训练文本嵌入进行了系统研究。我们的分析揭示了一种语言条件化的嵌入几何结构，其中语义等价的句子在不同语言之间仍然错位。我们假设语言特定的变化可以从语义内容中解耦出来以提高嵌入质量。为此，我们提出了配对残差子空间移除（Paired-Residual Subspace Removal，PRSR），这是一种免训练的推理时干预方法，可将 LLM 表示引导至更语言不变的语义空间。PRSR 首先从多语言平行句中构建配对残差以捕获语言特定的偏差，然后从这些残差中估计逐层低秩子空间，并抑制最后一个 token 隐藏状态中的相应分量。我们使用 MTEB 和 MMTEB 对 18 种语言进行了 200 多项单语言评估，并进行了英语与 200 多种其他语言之间的跨语言双文本挖掘。实验结果表明，PRSR 在不同的 LLM 上持续提升了现有免训练基线在单语言和跨语言设置中的性能。

1 引言

文本嵌入支撑着信息检索、推荐和聚类等应用（Muennighoff et al., 2023; Enevoldsen et al., 2025）。虽然大型语言模型展现出卓越的语义理解能力，但将它们转换为嵌入模型通常需要大量的微调（BehnamGhader et al., 2024; Lin et al., 2026a）。免训练方法通过直接从冻结的 LLM 中获取嵌入，提供了一种有吸引力的替代方案。PromptEOL（Jiang et al., 2024）开创了这一方向，通过提示 LLM 将句子语义浓缩到单个词中。后续工作通过提示设计（Lei et al., 2024; Springer et al., 2025）或内部模型干预（Fu et al., 2025; Cheng et al., 2025; Tang and Yang, 2026; Ding et al., 2026）推进了这一范式。

然而，现有的免训练方法主要在英语中开发和评估，使其多语言行为在很大程度上未被检验。我们通过对 LLM 中跨语言的免训练文本嵌入进行首次系统研究来填补这一空白。我们对多语言平行文本的动机分析显示了明显的按语言聚类现象：传达相同含义的翻译往往占据最后一个 token 潜在空间的不同区域。至关重要的是，跨语言的语义等价性并不总是一致地反映在嵌入相似性中。这些发现揭示了一种语言条件化的嵌入几何结构，其中语言身份可能掩盖句子之间的语义关系。

值得注意的是，先前的工作表明语言特定的信息可以在 LLM 中被定位（Tang et al., 2024; Zhao et al., 2024）。操纵这种与语言相关的方向已被证明可以改善多语言推理（Zhao et al., 2025; Maraia et al., 2026）。这为免训练文本嵌入提出了一个自然的问题：能否在不牺牲语义的情况下抑制语言特定的变化？

为此，我们提出了 PRSR（配对残差子空间移除，Paired-Residual Subspace Removal），这是一种用于改进 LLM 中多语言免训练文本嵌入的推理时激活引导方法。PRSR 利用多语言平行句的语义对应关系，将语言特定的变化与共享的语义内容分离。具体而言，在每个选定层，PRSR 通过从每个平行句的表示中减去组均值来构建配对残差。堆叠残差矩阵的主奇异方向定义了一个低秩语言敏感子空间。在推理时，PRSR 移除最后一个 token 隐藏状态到这些子空间上的投影，使修改后的表示能够通过剩余的冻结层传播并影响后续计算。因此，PRSR 产生的文本嵌入对语言身份不太敏感，而更紧密地按语义相似性对齐，从而改善了语言内的语义判别和跨语言的对齐。这种设计可以轻松地与现有的免训练嵌入方法集成，而无需更新模型参数。

我们在 MTEB 和 MMTEB（Muennighoff et al., 2023; Enevoldsen et al., 2025）上进行了广泛的实验，包括 18 种语言的 200 多项单语言评估。此外，我们在 BUCC.v2（Zweigenbaum et al., 2018）、Tatoeba（Artetxe and Schwenk, 2019）和 FLORES（Goyal et al., 2022; Costa-Jussà et al., 2022）上评估了英语与 200 多种其他语言之间的跨语言双文本挖掘。三个 LLM 上的实验结果表明，PRSR 在单语言和跨语言设置中持续改进现有的免训练基线。全面的消融研究和分析进一步验证了所提出的引导机制的有效性。总体而言，这项工作强调，在冻结的 LLM 中抑制语言特定的变化可以提高多语言文本嵌入的质量。

本工作的主要贡献总结如下：(1) 我们提出了 LLM 中多语言免训练文本嵌入的首次系统研究。我们的动机分析揭示了一种语言条件化的嵌入几何结构，其中语言身份可能干扰语义关系。(2) 我们提出了 PRSR，一种免训练的推理时引导方法，从多语言平行句构建配对残差以估计语言敏感子空间，并在嵌入提取期间移除相应的分量。(3) 在单语言 MTEB/MMTEB 评估和跨语言双文本挖掘基准上的全面实验表明，PRSR 在各种 LLM 上持续改进现有的免训练基线。

2 相关工作

免训练文本嵌入。 LLM 的最新进展激发了将它们改造为专用嵌入模型的持续努力（Lee et al., 2025; Zhang et al., 2025）。然而，此类方法需要大量的训练数据和微调。免训练方法通过提示设计或内部模型干预直接从冻结的 LLM 中提取文本嵌入，提供了一种实用的替代方案。PromptEOL（Jiang et al., 2024）使用单字约束将句子语义浓缩到最后一个 token 表示中，而 Pretended CoT（Zhang et al., 2024）用思维链指令增强提示。ECHO（Springer et al., 2025）重复输入，使第二次出现的 token 能够关注整个句子，而 ReverseEOL（Lin et al., 2026b）结合原始文本和反转文本的嵌入以捕获互补的上下文。另一系列工作探索对内部表示的干预。对比提示（Contrastive Prompting，Cheng et al., 2025）通过对比目标和辅助提示激活来引导隐藏状态，Token 前置（Token Prepending，Fu et al., 2025）将每层的最后一个 token 表示前置到下一层的输入，KV-Embedding（Tang and Yang, 2026）将最后一个 token 的键值状态重新路由为内部前缀以进行全局上下文访问。这些方法主要在英语中评估，其在多语言设置中的有效性在很大程度上未被探索。我们的工作通过系统地考察它们跨语言的行为来填补这一空白。

语言无关表示。 多语言嵌入模型通常从平行数据中学习跨语言对齐（Artetxe and Schwenk, 2019; Feng et al., 2022）。为了进一步减少语言特定的信息，先前的工作在检索器训练期间抑制语言信号（Huang et al., 2024），或将多语言表示学习分解为专用组件和共享组件（Huang et al., 2025）。或者，LIR（Yang et al., 2021）和 LSAR（Xie et al., 2022）在不进行额外训练的情况下从提取的嵌入中移除与语言相关的子空间。相比之下，PRSR 修改冻结 LLM 内部的中间隐藏状态，使干预能够影响后续计算。

LLM 中的激活引导。 激活引导通过对中间激活的推理时修改而非参数更新来引导模型行为。在多语言处理方面，先前的研究已经确定了 LLM 各层中语言特定的神经元和功能特化（Tang et al., 2024; Zhao et al., 2024）。Dumas et al. (2025) 表明语言信息和概念信息可以在 LLM 的内部表示中被独立操纵。最近的研究进一步探索了多语言激活引导：语言-推理解耦通过抑制语言特定的激活来改善多语言推理（Zhao et al., 2025），而在英语中学习的引导方向可以泛化到其他语言的三段论推理（Maraia et al., 2026）。我们将多语言激活引导扩展到文本嵌入生成，改善了单语言和跨语言设置中的语义表示。

3 多语言分析

在本节中，我们研究表示是否跨语言保留语义对应关系。我们使用 PromptEOL（Jiang et al., 2024）从冻结的 LLaMA-2-7B（Touvron et al., 2023）中引出免训练文本嵌入。在 FLORES+ 平行文本（Goyal et al., 2022）上，我们首先表征语言特定的聚类，然后检验平行文本的共享语义是否反映在它们的嵌入相似性中。

3.1 语言条件化的嵌入几何结构

3.2 语言变化堪比语义变化

平行文本使我们能够进一步评估跨语言嵌入之间的相似性是否可靠地反映跨语言共享的含义。对于每个锚句，我们比较两个余弦相似度分数：一个是其翻译（跨语言保留语义），另一个是负例句（与锚句语言身份匹配但语义内容不同）。我们使用跨越 18 种语言的 1,500 个 FLORES+ 平行组，并通过长度分层抽样选择负例。图 2(b) 显示了相似性差距的分布，正值表示与翻译的相似性更高。

在 36.2% 的比较中，同语言负例比相应的翻译更相似于锚句。这揭示了跨语言的语义等价性并不总能带来相似性优势。此外，平均锚句-翻译余弦距离是平均锚句-负例距离的 85.6%。尽管含义共享，翻译在嵌入空间中几乎与内容不同的同语言句子一样远。结合聚类结果，这些发现表明免训练文本嵌入呈现出一种语言条件化的几何结构，其中语言身份可能干扰底层的语义结构。附录 B.1 提供了额外的分析。

4 配对残差子空间移除

现有的免训练方法主要在英语嵌入任务上进行评估，忽略了语言条件化的嵌入几何结构在多语言设置中的潜在影响。为此，我们提出了配对残差子空间移除（PRSR），这是一种推理时引导方法，可在保留共享语义的同时抑制语言特定的变化，如图 3 所示。

4.1 预备知识

免训练文本嵌入通常从仅解码器 LLM 中的最后一个 token 读出，因为在因果注意力下它是唯一能够关注整个序列的位置。形式上，给定输入文本 x，嵌入提示形成 token 序列 p(x) = (u₁, …, u_T)。设 h_ℓ(x) ∈ ℝ^(1×d) 表示解码器块 ℓ 之后最后一个 token 的隐藏状态，其中 d 为嵌入维度。文本嵌入随后从输出层提取：

e(x) = g(h_{ℓ_out}(x))，　(1)

其中 g 表示模型的输出归一化。

4.2 配对残差子空间估计

PRSR 的核心思想是在控制句子语义的同时捕获语言敏感的变化。为此，我们引入配对残差，它衡量每个翻译相对于其平行组平均表示的偏差。由于组内所有句子表达相同的底层含义，这些残差预计主要捕获与语言相关的变化而非语义差异。

给定 K 种语言中的 N 个平行组，设 x_i^(m) 表示语言 m 中组 i 的句子，其在解码器块 ℓ 之后的最后一个 token 隐藏状态为 h_{ℓ,i}^(m)。我们计算组均值并定义相应的配对残差 r_{ℓ,i}^(m)：

h̄{ℓ,i} = (1/K) Σ{m=1}^{K} h_{ℓ,i}^(m)，　r_{ℓ,i}^(m) = h_{ℓ,i}^(m) − h̄_{ℓ,i}。　(2)

我们将所有组和语言的配对残差堆叠为 R_ℓ ∈ ℝ^(NK×d)。

为了识别语言敏感变化的主导方向，我们寻找最小化重建误差的 q 维子空间：

B_ℓ = argmin_{B^⊤B=I_q} ‖R_ℓ − R_ℓ B B^⊤‖_F²，　(3)

其中 B ∈ ℝ^(d×q) 为正交基。该目标识别出捕获配对残差最大方差的子空间。对 R_ℓ = U_ℓ Σ_ℓ V_ℓ^⊤ 应用奇异值分解（SVD）可得到最优基，由对应于最大奇异值的 q 个右奇异向量组成：

B_ℓ = [v_{ℓ,1}, …, v_{ℓ,q}] ∈ ℝ^(d×q)，　(4)

其中 v_{ℓ,j} 表示 V_ℓ 的第 j 列。在实践中，我们为每个选定的 LLM 层估计一个单独的子空间基，并在跨语言评估期间复用这些基。

4.3 层特定的激活引导

给定语言敏感子空间，PRSR 在嵌入提取期间将最后一个 token 隐藏状态引导离开这些子空间。具体而言，到 B_ℓ 上的投影对应于配对残差所捕获的主导语言敏感变化。移除该投影可以减少与语言相关的信息，产生更语言不变的语义表示。

从指定的块 ℓ_s 开始，我们在直到输出层 ℓ_out 的每个解码器块上应用干预，使用相应的基 B_ℓ。在每层 ℓ_s ≤ ℓ ≤ ℓ_out，我们更新最后一个 token 隐藏状态 h_ℓ(x)：

h̃_ℓ(x) = h_ℓ(x) − (h_ℓ(x) B_ℓ) B_ℓ^⊤，　(5)

其中 (h_ℓ(x) B_ℓ) B_ℓ^⊤ 是 h_ℓ(x) 到估计的语言敏感子空间上的正交投影。在最终干预之后，文本嵌入通过下式获得：

e_PRSR(x) = g(h̃_{ℓ_out}(x))。　(6)

由于干预完全在内部表示上操作并保持底层 LLM 冻结，PRSR 可以轻松地与现有的免训练嵌入方法集成，以提升其在多语言设置中的性能。

5 实验

5.1 实验设置

基准。 我们在单语言和跨语言两种设置中评估 PRSR。对于单语言评估，我们进行了 208 项任务-语言评估，涵盖来自 MTEB（Muennighoff et al., 2023）和 MMTEB（Enevoldsen et al., 2025）的 18 种语言。特别是，我们使用 MTEB (eng, v2)，包含七个嵌入类别的 41 个数据集，用于消融和分析。我们报告每种语言的平均分数，以及所有 208 项评估的总体平均值。每种语言数据集组成的更多细节见附录 A.1。

对于跨语言评估，我们在 BUCC.v2（Zweigenbaum et al., 2018）、Tatoeba（Artetxe and Schwenk, 2019）和 FLORES（Goyal et al., 2022; Costa-Jussà et al., 2022）上执行双文本挖掘，涵盖英语与 200 多种其他语言的配对。对于 BUCC.v2 和 Tatoeba，我们使用每个基准的主要指标报告所有语言对的平均分数。对于 FLORES，我们分别报告英语到 X 和 X 到英语的分数及其平均值。更多基准细节见附录 A.2。

5.2 结果

单语言结果。 表 1 报告了 18 种语言的单语言性能。PRSR 持续改进所有评估的免训练基线，PromptEOL、Pretended CoT、ECHO、TP 和 CP 的平均增益分别为 7.3、6.2、6.0、6.7 和 6.8 个百分点。我们假设这些改进源于减少语言身份对嵌入相似性的影响，从而增加底层语义的相对贡献。由于语言敏感的变化即使在单一语言内部也可能扭曲语义几何结构，抑制这种效应可以使嵌入相似性更能反映语义关系，从而产生更具判别性的表示。详细的逐数据集结果见附录 B.5。

重要的是，包括日语、韩语、孟加拉语、印尼语、意大利语、马来语、葡萄牙语和泰卢固语在内的八个评估语言未用于配对残差子空间估计。然而，PRSR 仍然持续提升了这些保留语言的嵌入性能。这种泛化表明，估计的子空间捕获的是广泛可迁移的语言敏感结构，而非子空间估计所用语言特有的模式。

跨语言结果。 表 2 表明，PRSR 在跨语言双文本挖掘中的改进幅度远大于单语言评估。在 200 多个以英语为中心的语言对上，PRSR 改进了全部五个免训练基线。增益范围在 FLORES 上为 18.51 至 23.96 个百分点，Tatoeba 上为 25.89 至 34.90 个百分点，BUCC.v2 上为 31.46 至 55.25 个百分点。在 FLORES 上，PRSR 的收益同时体现在英语到 X 和 X 到英语两个方向上，表明其对检索方向的鲁棒性。

这些跨语言增益进一步支持了我们的假设，即语言特定的变化可以从语义内容中解耦出来以提高嵌入质量。通过抑制语言敏感的变化，PRSR 产生的表示对语言身份不太敏感，且能更好地反映语义关系。总之，这些结果突出表明，PRSR 有效地将冻结的 LLM 表示引导至更语言不变的语义空间，改善了多语言免训练文本嵌入。

6.4 子空间秩的影响

默认情况下，我们将子空间秩设置为 q=K−1，其中 K 为构建语言的数量。为了考察子空间维度的影响，我们将 q 从 1 变化到 128，研究有效捕获和移除语言敏感变化需要多少个方向。

如图 4 所示，性能随秩的增加稳步提升，并在 q=14 附近达到峰值。这一趋势表明，过少的方向无法捕获足够的语言敏感变化以进行有效移除。然而，随着秩进一步增大，分数逐渐下降。总体而言，这一模式与先前关于语言特定信息可以用低秩子空间表示的发现一致（Xie et al., 2022）。我们假设较高秩下的性能下降是因为估计的子空间开始包含对嵌入提取有用的语义信息。由于在 q=K−1 附近获得最佳结果，我们在所有实验中采用该设置，保持 PRSR 的简单性并避免额外的超参数调整。

6.5 干预层的影响

为了考察干预深度的影响，我们在每个后续块应用移除的同时改变起始块 ℓ_s，并在三个 LLM 系列上评估 MTEB (eng, v2) 的性能。

7 结论

在本文中，我们提出了 LLM 中多语言免训练文本嵌入的首次系统研究。我们的分析揭示了一种语言条件化的嵌入几何结构，其中语义等价的文本在不同语言间仍然错位。为解决这一问题，我们提出了 PRSR，一种推理时引导方法，从多语言平行文本的配对残差中估计语言敏感子空间，并在嵌入提取期间抑制相应分量。在单语言和跨语言基准上的广泛实验表明，PRSR 在不同的 LLM 主干上持续改进现有的免训练基线。进一步的消融和分析验证了所提出的配对残差子空间移除策略的有效性和必要性。我们希望这项工作为超越英语的免训练文本嵌入提供新的视角，并鼓励对多语言表示学习和冻结 LLM 的推理时引导进行进一步探索。

局限性

我们的实验专注于三个仅解码器 LLM 系列，参数规模从 7B 到 8B。尽管 PRSR 在这些主干上有效，但其对更大规模 LLM 的适用性仍有待进一步检验。此外，我们的跨语言评估涵盖英语与 200 多种其他语言的配对，但未直接评估非英语语言之间的语义匹配。将评估扩展到这些设置将进一步确立我们方法的普适性。

伦理考虑

这项工作旨在改进来自冻结 LLM 的多语言文本嵌入，对跨语言的信息检索和语义匹配具有潜在益处。我们的实验使用现有的预训练模型和基准数据集。所得表示可能保留底层模型和数据的社偏见，而语义对齐的改善并不一定确保跨语言或社区之间的公平性。因此，我们鼓励下游用户评估其预期应用中的潜在偏见，并遵循模型和数据集的使用条件。

A.3 实现细节

我们使用三个广泛使用的 LLM 系列进行实验：Llama-2-7b-hf（LLaMA-2-7B）（Touvron et al., 2023）、Mistral-7B-v0.3（Mistral-7B）（Jiang et al., 2023）和 Qwen3-8B（Yang et al., 2025），所有主干参数保持冻结。除 ECHO 外，所有方法的最大输入序列长度均设为 512 个 token；ECHO 由于重复输入，因此使用 1024 个 token 的最大长度。为确保公平比较和可重复性，所有实验使用相同的评估流程和随机种子。

对于子空间估计，我们从 XNLI 验证集（Conneau et al., 2018）中收集跨 K=15 种语言的前 1,500 个完整平行句组，将前提和假设视为单独的组。我们为每个主干和免训练基线分别估计层特定的基（在禁用 PRSR 的情况下），遵循相应的输入构建和表示提取流程。所得的语言敏感子空间在整个评估过程中保持固定，并在所有评估语言之间共享。

对于输入提示，PromptEOL（Jiang et al., 2024）使用 "This sentence: [TEXT] means in one word:"，而 Pretended CoT（Zhang et al., 2024）将其扩展为 "After thinking step by step, this sentence: [TEXT] means in one word:"。对于 ECHO（Springer et al., 2025），我们遵循 ReverseEOL（Lin et al., 2026b）中采用的改进公式，在 PromptEOL 风格的模板中重复输入："Sentence: [TEXT] This sentence: [TEXT] means in one word:"。在我们的实验中，CP（Cheng et al., 2025）和 TP（Fu et al., 2025）采用 PromptEOL 作为基础提示，同时保留其原始的最佳性能推理设置。

B.3 子空间构建数据的影响

在本节中，我们进一步研究子空间构建数据的选择如何影响 PRSR，同时考虑平行句子的来源和用于子空间估计的语言数量。所有实验均在 MTEB (eng, v2) 上使用 LLaMA-2-7B 和 PromptEOL 进行评估。

构建语料库。 我们首先通过将子空间构建的 XNLI 替换为 FLORES+ 来检验 PRSR 是否强烈依赖于平行语料库的选择。如图 7 所示，PRSR 在两个数据源上取得相当的性能，使用 XNLI 获得 54.62，使用 FLORES+ 获得 54.98。这一结果表明 PRSR 的有效性不特定于某个平行语料库，有效的语言特定子空间可以从不同来源的多语言平行数据中估计。

构建语言的数量。 我们接下来研究用于子空间估计的语言数量的影响。凭借其广泛的多语言覆盖，FLORES+ 为系统性地变化构建语言数量提供了合适的设置。如图 7 所示，仅使用两种语言就已经显著优于未引导的基线，将 MTEB 分数从 46.93 提高到 52.18。随着引入更多语言，性能不断提升，并在八种语言时达到最高值 54.98。进一步增加构建语言数量不会带来额外收益，在大多数较大设置下性能保持在 53–54 左右。这些结果表明，纳入多语言多样性对于估计有效的语言敏感子空间很重要，而一旦捕获了足够的跨语言变化，进一步增加语言数量的收益有限。为简单起见并避免引入额外的语言选择超参数，我们在整个实验中使用 XNLI 中可用的全部 15 种语言进行子空间构建。

B.4 与平均池化的兼容性

PRSR 主要针对从最后一个 token 表示提取嵌入的免训练基线而设计，配对残差子空间构建和推理时引导均在最后一个 token 隐藏状态上操作。在本节中，我们进一步检验 PRSR 在另一种常用嵌入提取策略下是否仍然有效：平均池化。

这里我们使用原始的 ECHO 公式（Springer et al., 2025），它重复输入并通过平均池化第二次出现的 token 来获得文本嵌入。具体而言，与我们主要实验中使用的 PromptEOL 风格 ECHO 变体不同，我们使用官方提示 "Rewrite the following paragraph: [TEXT]. The rewritten paragraph: [TEXT]"。为了在每个选定层构建语言敏感子空间，我们首先将第二次出现的 token 平均为句子级向量，然后按照与第 5.1 节相同的流程跨平行句构建配对残差。在推理期间，我们在每个选定层对第二次出现的每个 token 应用相同的投影移除。

如表 9 所示，PRSR 在平均池化下大幅改进了 ECHO。208 项评估的平均单语言分数从 41.5 提升至 44.5。在跨语言双文本挖掘上的改进要大得多：Tatoeba 从 1.44 提升至 20.93，FLORES 从 1.63 提升至 19.56，BUCC 从 0.50 提升至 91.79。这些结果进一步证明语言特定的变化广泛存在于免训练文本嵌入中，并不特定于最后一个 token 池化。更重要的是，平均池化下的强大性能表明，通过对子空间构建和推理时引导进行相应调整，PRSR 可以有效扩展到不同的池化策略，展示了所提出的配对残差子空间移除策略的更广泛适用性。
