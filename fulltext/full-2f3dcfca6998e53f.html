原标题：DistDNA: Language Model Fingerprinting under Stochastic Decoding

中文摘要： DistDNA 是一种针对随机解码场景的语言模型行为指纹方法。现有方法（如 LLM DNA）在温度和 top-p 等解码参数未知变化时识别性能受限。DistDNA 通过提示条件响应分布表示模型，采用逐提示最大均值差异（MMD）比较模型，将被检模型分配给参考指纹最近的已知检查点，无需训练分类器。理论证明有限采样引入的偏差以 O(1/R) 速率消失。在 115 个检查点条目上的实验表明，DistDNA 比最强基线 LLM DNA 的识别准确率提高 10.36%。

摘要

行为指纹通过大语言模型（LLM）对一组共享提示的响应来识别该模型，可实现诸如验证部署的模型是否与其声称的检查点一致等应用。然而，部署的模型通常使用随机解码提供服务，在此情况下，同一模型可能对相同提示产生不同的响应，具体取决于未知的温度和 top-p 设置。现有表示方法（如 LLM DNA）对这种变化的处理有限。一种自然的补救措施是通过响应分布来表征模型，但这带来了两个挑战。首先，每个分布必须仅从少量采样响应中估计。其次，解码设置的变化可以像检查点变化一样在相同程度上改变响应。因此，仅凭指纹距离无法为模型身份提供完整的基础，识别通常依赖于在来自多个检查点的指纹上联合训练的分类器。我们提出 DistDNA，它通过提示条件响应分布来表示模型，并通过逐提示最大均值差异（MMD）比较模型。被检查的模型被分配给其参考指纹（在多个解码设置下收集）最接近自身指纹的已知检查点，无需训练分类器。我们证明，有限采样会在期望的平方指纹距离中添加与方差相关的项，在响应数量相等时这些项以 O(1/R) 的速率递减，其中 R 是每个提示的响应数量。在 115 个模型检查点条目上的实验表明，DistDNA 比最强基线 LLM DNA 的识别准确率提高了 10.36%。

1 引言

从可观察行为中学习语言模型的表示已成为一个重要问题，其应用包括 API 验证、模型路由和系统发生分析。诸如 LLM DNA（Wu 等，2026b）和 PhyloLM（Yax 等，2025）等行为方法通过模型对共享提示的响应来表征模型，即使在模型参数、分词器或部署细节不可用时也能进行比较。这些表示已显示出强大的实证有效性，在预测模型关系和谱系等任务中实现了高准确率。

一个实际的例子是验证通过第三方 API 中继提供服务的模型。服务可能声称提供特定的检查点，同时隐藏实际的后端。通过使用诊断提示查询 API 并将其响应与注册的参考进行比较，可以识别实际部署的是哪个检查点。这需要区分甚至密切相关的检查点。

然而，现有的表示方法在很大程度上忽略了随机解码，尽管它现代大语言模型（LLM）系统中被广泛使用。在由温度和核采样等参数控制的随机解码下，同一 LLM 可能对同一提示产生不同的响应（Holtzman 等，2020）。因此，单个响应只是提示条件响应分布的一个样本，而不是响应分布的完整表示。这促使在分布层面而不是通过单个生成的响应来比较模型。

然而，在分布层面对模型进行指纹识别存在两个挑战。首先，模型的响应分布无法被详尽地观察。对提示的可能响应空间太大而无法枚举，并且每次查询都会产生成本；因此必须仅从少量采样响应中估计分布。其次，在没有训练分类器的情况下难以实现识别。由于温度或 top-p 的变化可以像检查点变化一样在相同程度上改变模型的响应（第 3 节），指纹之间的距离不能直接确定模型身份。因此，现有的表示方法如 LLM DNA（Wu 等，2026b）需要一个训练的分类器，尽管是轻量级的，它必须在来自多个检查点的标记指纹上联合拟合，使得对任何一个检查点的决策取决于所有其他已知检查点。

为了应对这些挑战，我们提出 DistDNA，它通过模型对一组共享提示的响应分布来表示模型。对于第一个挑战，DistDNA 对每个提示抽取重复响应，并通过它们在核特征空间中的均值嵌入来总结，这平均掉了采样噪声，使得少量响应就能产生稳定的指纹。对于第二个挑战，DistDNA 通过使用高斯核的最大均值差异（MMD）测量两个模型之间的距离，逐提示计算。该距离在所有频率上比较两个响应分布的特征函数（Sriperumbudur 等，2010），因此反映完整分布的差异，而不仅仅是均值响应的差异。然后将被检查的模型分配给其参考指纹（在多个解码设置下收集）最接近自身指纹的已知检查点，无需训练分类器。

本文的贡献有三方面：(1) 我们提出 DistDNA，一种通过提示条件响应分布表征语言模型的行为指纹，通过最近的注册参考实现识别，无需训练分类器。(2) 我们证明采样噪声会膨胀两个指纹之间的估计距离，并且这种偏差以 O(1/R) 的速率消失，其中 R 是每个提示的重复响应数量。(3) 我们在 115 个模型检查点条目上的实验表明，DistDNA 比最强基线 LLM DNA 的识别准确率提高了 10.36%。

2 相关工作

行为表示。 LLM-DNA 从共享探测响应构建功能表示，用于模型比较和下游任务，包括关系检测和路由（Wu 等，2026b）。提取无需训练；下游读出可以被训练。词汇和形态句法指纹也揭示了模型家族结构（McGovern 等，2025）。PhyloLM 估计提示条件输出频率，并使用分布相似性来研究模型关系和预测能力（Yax 等，2025）。先前表示的原生评估尚未建立在隐藏解码偏移下精确注册检查点识别；DistDNA 通过重复的提示条件核均值估计（Gretton 等，2012）和跨设置的单独注册参考来针对这一设置。

直接模型识别。 LLMmap 在未知系统提示和随机采样设置下直接识别模型版本（Pasquini 等，2025）。敏感探测检测模型篡改（Bai 等，2025；Hu 等，2025）。其他指纹利用优化的探测、反事实响应或种子行为（Hu 等，2026；Wu 等，2026a；Tong 等，2026）。水印和植入指纹修改模型行为以进行归因或所有权验证（Kirchenbauer 等，2023；Xu 等，2024；Yamabe 等，2025）；我们的协议仅需要文本访问。对于探测优化或模型修改不可用的设置，DistDNA 从固定的共享提示提供可重用的指纹，在共同的响应预算下支持最近参考匹配和使用支持向量机（SVM）的监督识别。表 1 总结了表示选择和识别目标。DistDNA 将重复的提示条件观察与隐藏解码设置下基于距离和监督读出的单独评估相结合。

3 DistDNA 的定义

动机：在解码偏移下识别模型。 一个有用的模型指纹必须支持当查询和参考使用不同解码设置时的识别。当每个提示只有一个响应时，观察到的指纹变化可能反映不同的检查点、不同的解码设置，或者只是来自同一响应分布的另一个样本。指纹可以容忍多少解码变化，直到精确检查点识别变得不可靠？

观察 1：解码偏移达到模型差异的规模。 图 1(a) 在 41 个检查点、九个设置和 32 个生成种子上比较这些效应。我们使用平方 Hellinger 距离（一种分布分离度量）比较拟合的高斯指纹分布。在固定 top-p=1 时，将 T 从 1.0 更改为 0.8 给出 0.975 的平均距离，高于家族内参考 0.943。在 T=0.7（|ΔT|=0.3）时，它达到 0.992，与跨家族参考 0.988 相当。因此，指纹比较必须应对与检查点间变化一样大的解码引起的变化。

观察 2：模型特定的参考尺度使识别复杂化。 图 1(b) 中的互补 W₂ 视图显示了相同的张力：T: 1→0.8 超过合并的家族内参考（3.049 对 2.727），而 T: 1→0.7 接近跨家族参考（3.715 对 4.003）。跨家族，家族内 H² 参考跨越 0.913–0.996（附录图 8）。下面的直接识别测试测量这些行为差异如何影响注册库中的检查点恢复。

设计启示。 这些观察促使从重复响应估计提示条件行为，并在解码设置上注册每个检查点。提示对齐保持每个探测的身份，而重复采样减少提示内估计误差。以下理论表征了这种估计机制；识别实验在匹配的观察预算下测量其实际效果。

随机模型对每个提示产生可能响应的分布。我们定义这些条件分布之间的行为距离，并构造其希尔伯特空间距离等于该距离的总体指纹。这将总体对象与第 4 节中的采样算法分开。

我们将表示与识别分开：指纹估计响应分布差异；读出使用这些差异预测注册身份。理论解决第一个问题。实验评估第二个问题。

3.1 提示条件行为

设 g=(m,θ) 表示解码设置 θ 下的检查点 m。在提示 xᵢ 处，Y_{g,i} ~ P_g(·|xᵢ)，冻结编码器与每响应单位归一化给出 Z_{g,i} = φ(Y_{g,i})。固定提示 S_t = (x₁, …, x_t) 和具有有限条件二阶矩的可测核特征映射 ψ: ℝ^d → ℋ。写 μ_{g,i} = 𝔼ψ(Z_{g,i}) 并定义

d²_{S_t,k}(g,h) = (1/t) Σᵢ₌₁ᵗ ‖μ_{g,i} − μ_{h,i}‖²_ℋ. (1)

提示对齐比较由相同问题引出的响应。线性 k 测量均值差异；特征 RBF 核在总体水平区分编码的响应律。平方根 d_{S_t,k} 是检查点-解码对上的伪度量：不同的对可以在选定的提示上共享相同的编码响应律。它测量由身份和解码设置共同引起的行为差异。

3.2 表示和采样性质

命题 3.1（核均值等距）。总体指纹 Γ(g) = t^{-1/2}[μ_{g,1}; …; μ_{g,t}] ∈ ℋ^t 满足

‖Γ(g) − Γ(h)‖²_{ℋ^t} = d²_{S_t,k}(g,h). (2)

缩放使平方距离成为提示上的平均值。证明展开直和范数；附录 A.2 给出细节。RBF 总体指纹位于希尔伯特空间中；核直接从响应样本评估其经验距离。有限集压缩是附录 A.1 中的单独存在结果。

对于每个提示 R_g 个响应，定义经验指纹

μ̂{g,i} = (1/R_g) Σᵣ₌₁^{R_g} ψ(z{g,i,r}), Γ̂g = t^{-1/2}[μ̂{g,1}; …; μ̂_{g,t}].

每个块估计一个固定提示的响应行为。

定理 3.2（有限生成方差）。在固定提示、固定检查点-解码对、独立收集的校准数据（用于设置核距离尺度的单独响应）和由此产生的固定平方可积特征映射的条件下。对于每个提示内 R 个 i.i.d. 响应，设 V_{g,i} = 𝔼‖ψ(Z_{g,i}) − μ_{g,i}‖²。则

𝔼‖Γ̂g − Γ_g‖² = (1/tR) Σᵢ V{g,i}. (3)

对于独立的查询和参考臂，

𝔼‖Γ̂q − Γ̂_r‖² = ‖Γ_q − Γ_r‖² + (1/tR_q) Σᵢ V{q,i} + (1/tR_r) Σᵢ V_{r,i}. (4)

居中后，独立性使提示内和跨臂项在期望中消失（附录 A）。因此，重复以 1/R 的速率减少固定面板估计 MSE。候选相关的方差也贡献于成对距离差异。实验评估提示面板上的识别和响应分配。

4.1 语义响应表示

设 φ 表示冻结的语义编码器，后跟每响应单位归一化，因此 z_{i,r} = φ(y_{i,r}) ∈ ℝ^d 且 ‖z_{i,r}‖₂ = 1。注册和查询共享提示和编码器约定，并使用不相交的响应抽取。

单独的校准提示在查询评估之前确定内部带宽。此参数校准设置距离尺度，监督外核尺度从注册距离单独设置（第 4.3 节）。

4.2 提示条件分布比较

我们使用正带宽 σ，σ² 设置为校准嵌入之间的中位数正平方距离。

DistDNA-RBF。 对于 k_σ(z,w) = exp[−‖z−w‖²/(2σ²)]，使用以下比较经验核均值

d̂²_RBF(q,r) = (1/t) Σᵢ [ (1/R_q²) Σ_{a,b} k_σ(z_{q,i,a}, z_{q,i,b}) + (1/R_r²) Σ_{a,b} k_σ(z_{r,i,a}, z_{r,i,b}) − (2/(R_qR_r)) Σ_a Σ_b k_σ(z_{q,i,a}, z_{r,i,b}) ]. (5)

此 V-统计量包括自对，并从保留的响应样本评估精确的经验核均值距离。比较在每提示响应计数中花费二次核工作。

DistDNA-Linear。 线性构造在提示内平均并连接：

v_g = (1/√t)[z̄{g,1}; …; z̄{g,t}], z̄{g,i} = (1/R) Σᵣ₌₁ᴿ z{g,i,r}. (6)

这些向量之间的平方欧几里得距离是经验线性核 MMD。提示均值及其连接保留其大小。此构造是响应表示的简化控制。

4.3 设置无关识别

线性和 RBF 构造都支持以下两种读出：无需识别分类器训练的最近参考识别和使用标准 SVM 的监督识别。对于最近参考识别，每个检查点接收其到任何单独注册指纹的最小距离；检查点分数对不同的候选 ID 排序。平局遵循固定的注册顺序。

m̂(q) = arg min_{m∈ℳ} min_{r∈ℛ_m} d̂²_k(q,r), (7)

其中 ℛ_m 包含检查点 m 的单独注册指纹，k 是选定的线性或 RBF 核。

监督识别为每个表示/编码器拟合单独的多类 SVM。设 δ²_k(a,b) = ‖Γ̂a − Γ̂_b‖²{ℋ^t} 表示经验指纹距离。共同的外核是

K(a,b) = exp[−δ²_k(a,b)/s_train], (8)

其中 s_train 是中位数正非对角注册平方距离。这将指纹距离转换为分类器相似性。我们固定 C=1，使用一对一拟合和一对多排序分数，并仅从注册设置尺度。外核与内响应核不同；真正的线性核 SVM 被单独评估。

5 实验

5.1 实验设置

数据集。 具有空上下文的 Dolly 指令（Conover 等，2023）提供 20 个校准提示和 80 个评估提示的类别平衡面板。主实验指纹使用前 20 个评估提示，与校准不相交。校准在查询评估之前确定内部带宽。

LLM。 主比较包含 115 个注册检查点条目，包括基础和指令微调版本。任务识别精确的注册检查点条目；每个查询身份属于候选集。附录 E 列出条目和修订。原始的 30 检查点集合提供支持控制和 t 分布随机邻域嵌入（t-SNE）插图。

超参数。 查询设置形成完整的笛卡尔网格 (T,p) ∈ 𝒢 × 𝒢，其中 𝒢 = {0.1, 0.3, 0.5, 0.7, 0.9, 1.0}。每个指纹在 20 个提示和每提示 4 个响应上保持一个隐藏对固定。这给出 4,140 个物理查询和 331,200 个新响应，每个查询 80 个响应。每个条目有 8 个单独的注册指纹，在 T ~ U(0.7, 1.0] 和独立地 p ~ U(0.7, 1.0] 下收集：920 个参考和每条目 640 个注册响应。注册、校准和分类器在所有 36 个查询单元中保持冻结。

基线。 LLM-DNA 将共享的 512 坐标高斯投影（种子 42）应用于连接的提示均值。PhyloLM-4char 使用全局归一化的提示特定四字符前缀频率。两者都使用共享的响应库和读出；它们的任务特定适配在附录 B.2 中详述。Random 评估每个物理查询所有 115 个候选 ID 的 1,000 个固定种子均匀排列，在编码器视图中重用预测。第一个 ID 提供 Top-1 准确率和 F1 分数（精确率和召回率的调和平均）；前三个不同的 ID 提供 Top-3 准确率。Random 的响应收集成本为零。

实现。 固定的北京智源人工智能研究院（BAAI）通用嵌入（BGE）和掩码置换预训练语言理解（MPNet）编码器产生单位归一化的 768 维响应嵌入。DistDNA-Linear 保留 15,360 个坐标；DistDNA-RBF 保留响应样本用于逐提示经验 MMD。高斯 SVM 保留 C=1 及其训练中位数尺度。最近参考匹配在声明的表示距离下按每个检查点最接近的单个注册指纹排序。两种读出使用相同的每条目 8 个参考、冻结的校准和候选集。所有 682 个空查询输出都被保留。

评估。 对于 k ∈ {1,3}，模型宏 Top-k 准确率（以下表示为 Top-k）是

Top-k = (1/M) Σ_{m=1}^M (1/|𝒮|) Σ_{s∈𝒮} Avg_e 1{m ∈ Top_k(a_{m,s,e})}, (9)

其中 M=115，𝒮 包含 36 个查询设置，e 索引编码器视图，a_{m,s,e} 是检查点分数，Top_k 对不同的 ID 排序。编码器结果首先在每个查询内平均；设置和检查点然后获得相等权重，因此每个检查点计数相等。PhyloLM 贡献一个无编码器视图；每个物理查询在编码器视图中仍是一个观察。宏 F1 在设置和编码器视图之间汇集 Top-1 预测并对每个检查点的 F1 取平均，宏 F1 = (1/M) Σ_m 2TP_m/(2TP_m + FP_m + FN_m)，其中 TP、FP 和 FN 是真阳性、假阳性和假阴性，零分母计为零。表格报告编码器聚合后 36 个设置级分数的分数 ± 样本 SD；中心宏 F1 保持汇集，其 SD 使用特定设置的汇集 F1。这些 SD 量化解码条件间的变化。Random 对 1,000 次试验的平均完整试验指标；其 SD 是跨试验平均设置分数，反映蒙特卡洛变化。

A.1 总体距离和有限集存在性

对于提示分布 ν，假设可积的条件特征二阶矩并定义

d²_{ν,k}(g,h) = 𝔼_{x~ν} ‖μ_{g,x} − μ_{h,x}‖²_ℋ. (10)

公式 (1) 中的提示面板距离是其固定面板对应物。使用特征核，零总体距离建立几乎每个提示的编码条件律的相等；权重身份和训练历史需要单独的证据。

定义 A.1（有限维距离保持）。对于固定提示、编码器和核以及有限行为集 𝒢_K，有限表示 τ: 𝒢_K → ℝ^L 保持声明的距离，如果

c₁ d_{S_t,k}(g,h) ≤ ‖τ_g − τ_h‖₂ ≤ c₂ d_{S_t,k}(g,h) (11)

对于正常数 c₁ ≤ c₂ 和 𝒢_K 中的每对。

推论 A.2（有限集压缩）。对于 K ≥ 2 和 0 < ϵ < 1，存在 K 个总体指纹跨度上的线性映射到 L = O(ϵ⁻² log K) 坐标，满足

√(1−ϵ) d_{S_t,k}(g,h) ≤ ‖AΓ(g) − AΓ(h)‖₂ ≤ √(1+ϵ) d_{S_t,k}(g,h). (12)

证明。 有限集合张成希尔伯特直和的有限维欧几里得子空间。对这 K 个点应用 Johnson-Lindenstrauss 引理并使用命题 3.1（Johnson 和 Lindenstrauss，1984；Larsen 和 Nelson，2017）。∎

主要的未压缩评估在 ℝ^{td} 中计算线性距离，并直接从保留的响应样本计算经验 RBF 距离，而附录 F.3 通过 PCA（Linear）和核 Nyström（RBF）将指纹投影到注册参考的无标签跨度上，在 L=512 处经验地实现推论 A.2。有限维跨度压缩和无限维总体嵌入因此发挥互补的操作作用。

A.2 命题 3.1 的证明

直和内积给出

‖t^{-1/2}[μ_{g,1}−μ_{h,1}; …; μ_{g,t}−μ_{h,t}]‖² = t^{-1} Σᵢ ‖μ_{g,i}−μ_{h,i}‖².

这是公式 (1)。直和范数独立地添加提示块贡献。恒等式同样适用于普通均值向量和 RBF 核均值。

A.3 定理 3.2 的证明

在提示面板、独立可采纳的校准和固定特征映射的条件下。设 ξ_{i,r} = ψ(Z_{i,r}) − μᵢ。这些变量在提示内的抽取间居中且独立，因此

𝔼‖R^{-1} Σᵣ ξ_{i,r}‖² = R^{-2} Σᵣ 𝔼‖ξ_{i,r}‖² = Vᵢ/R.

跨抽取内积通过独立性和居中消失。对提示块平方范数取平均证明公式 (3)；直和恒等式允许此期望的提示块间依赖。

对于第二个陈述，将经验差写为总体差加上 ϵ_q − ϵ_r。两个误差均值为零，独立臂给出 𝔼⟨ϵ_q, ϵ_r⟩ = 0。因此其期望平方范数是总体平方距离加上两个误差 MSE。用 R_q 和 R_r 应用第一个恒等式证明公式 (4)。

单位归一化线性特征具有 Vᵢ ≤ 1；RBF 特征映射也具有平方范数 k(z,z) = 1，因此 Vᵢ ≤ 1。马尔可夫不等式因此给出 Pr(‖Γ̂ − Γ‖ ≥ ε) ≤ 1/(Rε²) 对于任一保留构造。这个保守界限在声明的固定映射和提示内 i.i.d. 条件下控制指纹估计误差。分类准确率和样本相关归一化需要单独分析。

A.4 精确经验核距离

再生恒等式 ⟨k(z,·), k(w,·)⟩ = k(z,w) 将经验均值的平方差展开为公式 (5)。所有臂内对（包括自对）保留；交叉分母是 R_qR_r。V-统计量在数值舍入范围内非负。对于 R_g ≥ 2，定义无偏提示内特征方差

V̂{g,i} = (1/(R_g−1)) Σ{a=1}^{R_g} ‖ψ(z_{g,i,a}) − μ̂_{g,i}‖²_ℋ.

方差校正估计器是

d̂²_U = d̂²_V − (1/t) Σᵢ₌₁ᵗ (V̂{q,i}/R_q + V̂{r,i}/R_r).

这等于 R_q, R_r ≥ 2 的独立臂的无偏 MMD U-统计量。两种主要读出都使用 V-统计量。

A.5 最近参考识别的充分间隔

如果每个估计的平方候选距离在其总体对应物的 η 范围内，并且最近的正确候选与每个不正确候选分离超过 2η，则最近参考排序保持正确。减去两个估计误差证明此充分条件。该条件适用于解码偏移下正总体间隔持续存在的最近参考检索；SVM 预测需要单独分析。在固定总响应预算下，更改提示集会更改总体间隔和逐提示方差。

C.6 有限样本距离校正

对于独立臂，定理 3.2 将期望经验平方距离分解为总体平方距离加上查询和候选方差除以其重复计数。对于固定查询，查询方差项在期望候选分数的成对差异中抵消，而不相等的候选方差贡献排序偏移。减去估计的候选方差诊断排序偏差，同时可能增加估计器方差并产生负的校正分数。精确核对应物是 MMD U-统计量（直到查询常数项）。

附录 D 局限性和影响

D.1 局限性

我们的评估在指定的提示、解码和收集协议下识别注册检查点条目。原始的三十检查点实验平等地加权其八个报告组，而扩大的 115 条目库使用等条目加权。评估的条目是固定的存储库修订；权重等价别名需要单独审计。

DistDNA-Linear 在原始三十检查点监督研究中匹配 RBF Top-1 准确率。在主要的 115 条目网格中，RBF 在两种读出下具有更高的 Top-1，而 Linear 具有更高的监督 Top-3。比较匹配响应预算和读出策略，而指纹存储和原生基线操作机制不同。

原始的三十检查点集合使用简短的纯文本生成。领域和原生聊天实验在每个条件内单独注册和拟合分类器。固定分类器网格覆盖报告的温度/top-p 单元和单独的贪心端点。这些实验表征声明的条件；开集拒绝、零样本接口迁移和任意部署设置需要单独评估。响应编码器可以丢弃文本区别。统计间隔以观察到的名册、提示池和拟合注册为条件，有限分配网格表征评估的设计。理论建立检查点-解码对的表示和采样性质；识别性能通过经验评估。

D.2 更广泛的影响

行为指纹可以支持模型库存、API 验证、回归监控和来源调查，而无需访问权重。在积极部署中，操作员可以注册候选检查点并仅使用普通文本查询检测意外的服务变更。

相同的能力可以在未经同意的情况下揭示提供商的模型选择，或者被过度解释为不当行为的证据。关于复制权重、共同训练数据、许可违规或共享血统的声明需要超出响应相似性的证据。

错误归因可能导致声誉和法律损害，特别是当候选检查点不在库中时。因此，后果性使用需要佐证文档或参数级证据、校准的不确定性以及争议归因的程序。查询集和存储的指纹在暴露专有部署信息时也应受到保护。
