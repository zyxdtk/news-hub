别再对AI术语一知半解，这份词汇表帮你搞定

📅 2026-05-09 📄 TechCrunch AI 🔗 原文链接

原标题：So you’ve heard these AI terms and nodded along; let’s fix that

中文摘要： 本文是一份动态更新的AI术语词汇表，旨在帮助读者厘清常见的AI概念。文章详细解释了26个核心术语，包括AGI、AI智能体、思维链、深度学习、扩散模型、幻觉、LLM、强化学习、词元和权重等。通过通俗易懂的比喻与实例，文章揭示了这些术语背后的技术原理、行业应用及争议，为理解AI技术发展与行业动态提供了清晰的指引。

人工智能正在改变世界，同时也发明了一整套全新的语言来描述它是如何做到这一点的。花五分钟阅读关于AI的内容，你就会遇到LLM、RAG、RLHF以及其他十几个术语，这些术语甚至能让科技界非常聪明的人感到不自信。这本词汇表是我们试图解决这个问题的尝试。我们会随着该领域的发展定期更新它，因此请把它看作一份动态文档，就像它所描述的AI系统一样。

AGI

通用人工智能（AGI）是一个模糊的术语。但它通常指在许多（如果不是大多数）任务上比普通人更有能力的AI。OpenAI首席执行官萨姆·奥特曼曾将AGI描述为“相当于你可以雇佣为同事的中等水平人类”。同时，OpenAI的章程将AGI定义为“在大多数具有经济价值的工作上表现优于人类的高度自主系统”。谷歌DeepMind的理解与这两个定义略有不同；该实验室将AGI视为“在大多数认知任务上至少与人类一样有能力的AI”。感到困惑？不用担心——处于AI研究前沿的专家也是如此。

AI agent

AI智能体是指使用AI技术代表你执行一系列任务的工具——超出了基础AI聊天机器人的能力范围——例如报销费用、订票或订餐，甚至编写和维护代码。然而，正如我们之前所解释的，这个新兴领域有许多变动因素，因此“AI智能体”对不同的人可能意味着不同的东西。为了实现其设想的能力，基础设施也仍在建设中。但其基本概念意味着一个自主系统，它可以利用多个AI系统来执行多步骤任务。

API endpoints

可以将API端点看作软件背面的“按钮”，其他程序可以按下这些按钮使其执行操作。开发人员使用这些接口来构建集成——例如，允许一个应用程序从另一个应用程序提取数据，或者使AI智能体能够直接控制第三方服务，而无需人工手动操作每个界面。大多数智能家居设备和互联平台都有这些隐藏的按钮可用，即使普通用户从未看到或与它们交互。随着AI智能体变得越来越强大，它们越来越能够自己找到并使用这些端点，为自动化开启了强大——有时是意想不到的——可能性。

Chain of thought

给出一个简单的问题，人类大脑无需过多思考就能回答——比如“哪种动物更高，长颈鹿还是猫？”但在许多情况下，你通常需要纸和笔才能得出正确答案，因为存在中间步骤。例如，如果一个农民有鸡和牛，它们总共有40个头和120条腿，你可能需要写下一个简单的方程式来得出答案（20只鸡和20头牛）。
在AI语境中，大型语言模型的思维链推理意味着将问题分解为更小的中间步骤，以提高最终结果的质量。获得答案通常需要更长的时间，但答案更有可能是正确的，特别是在逻辑或编码语境中。推理模型是从传统的大型语言模型发展而来的，并通过强化学习针对思维链思考进行了优化。
(参见: 大型语言模型)

Coding agents

这是一个比“AI智能体”更具体的概念，指的是一个可以自行采取行动、逐步完成目标的程序。编码智能体是应用于软件开发的专用版本。编码智能体不是简单地建议代码供人类审查和粘贴，而是可以自主编写、测试和调试代码，处理通常消耗开发者一整天的迭代、试错工作。这些智能体可以在整个代码库中操作，发现错误，运行测试，并在最少的人工监督下推送修复。可以把它想象成雇佣了一个从不睡觉、从不分心的极快实习生——不过，就像任何实习生一样，人类仍然需要审查其工作。

Compute

虽然算力在某种程度上是一个多价术语，但它通常指允许AI模型运行的关键计算能力。这种处理能力为AI行业提供了动力，使其能够训练和部署强大的模型。该术语通常是提供计算能力的硬件类型的简称——比如GPU、CPU、TPU以及其他构成现代AI行业基石的基础设施形式。

Deep learning

深度学习是自我改进机器学习的一个子集，其中AI算法被设计为具有多层人工神经网络（ANN）结构。这使得它们能够比更简单的基于机器学习的系统（如线性模型或决策树）建立更复杂的相关性。深度学习算法的结构从人脑中神经元相互连接的通路中汲取灵感。
深度学习AI模型能够自行识别数据中的重要特征，而不需要人类工程师来定义这些特征。该结构还支持可以从错误中学习并通过重复和调整过程改进自身输出的算法。然而，深度学习系统需要大量数据点才能产生良好的结果（数百万或更多）。与更简单的机器学习算法相比，它们通常也需要更长的训练时间——因此开发成本往往更高。
(参见: 神经网络)

Diffusion

扩散是许多生成艺术、音乐和文本的AI模型的核心技术。受物理学启发，扩散系统通过添加噪声慢慢“破坏”数据的结构——例如照片、歌曲等——直到什么也不剩。在物理学中，扩散是自发且不可逆的——溶解在咖啡中的糖无法恢复成方糖。但AI中的扩散系统旨在学习一种“逆向扩散”过程来恢复被破坏的数据，从而获得从噪声中恢复数据的能力。

Distillation

蒸馏是一种使用“教师-学生”模型从大型AI模型中提取知识的技术。开发人员向教师模型发送请求并记录输出。答案有时会与数据集进行比较，以查看其准确程度。然后这些输出被用来训练学生模型，该模型被训练来近似教师的行为。
蒸馏可用于基于较大的模型创建更小、更高效的模型，且蒸馏损失最小。这可能是OpenAI开发GPT-4 Turbo（GPT-4的更快版本）的方式。
虽然所有AI公司都在内部使用蒸馏，但一些AI公司可能也使用它来追赶前沿模型。来自竞争对手的蒸馏通常违反AI API和聊天助手的服务条款。

Fine-tuning

这是指对AI模型进行进一步训练，以优化其在比之前训练焦点更具体的任务或领域的性能——通常通过输入新的、专门的（即面向任务的）数据来实现。
许多AI初创公司将大型语言模型作为构建商业产品的起点，但它们正试图通过基于自身特定领域知识和专业知识的微调来补充早期的训练周期，从而提高目标行业或任务的实用性。
(参见: 大型语言模型 [LLM])

GAN

GAN，即生成对抗网络，是一种机器学习框架，在生成式AI产生逼真数据方面支撑了一些重要的发展——包括（但不限于）深度伪造工具。GAN涉及使用一对神经网络，其中一个利用其训练数据生成输出，传递给另一个模型进行评估。
这两个模型本质上被编程为试图超越对方。生成器试图让其输出通过判别器，而判别器则致力于识别人工生成的数据。这种结构化的竞争可以在不需要额外人类干预的情况下优化AI输出，使其更加逼真。尽管GAN最适合较窄的应用（如生成逼真的照片或视频），而不是通用AI。

Hallucination

幻觉是AI行业对AI模型凭空捏造的偏好术语——字面意思就是生成不正确的信息。显然，这是AI质量的一个巨大问题。
幻觉产生的生成式AI输出可能会产生误导，甚至可能导致现实生活中的风险——带来潜在的危险后果（想象一下返回有害医疗建议的健康查询）。
AI捏造信息的问题被认为是训练数据空白造成的结果。幻觉正在推动越来越专业化和/或垂直化的AI模型——即需要更窄专业知识的特定领域AI——作为一种减少知识空白可能性和缩小虚假信息风险的方式。

Inference

推理是运行AI模型的过程。它是让模型自由地对以前见过的数据做出预测或得出结论。需要明确的是，没有训练就无法进行推理；模型必须在一组数据中学习模式，然后才能有效地从这些训练数据中进行推断。
许多类型的硬件都可以执行推理，从智能手机处理器到强大的GPU，再到专门设计的AI加速器。但并非所有硬件都能同样好地运行模型。与配备高端AI芯片的云服务器相比，非常大的模型在笔记本电脑上做出预测可能需要漫长的时间。
[参见: 训练]

Large language model (LLM)

大型语言模型（LLM）是流行的AI助手使用的AI模型，例如ChatGPT、Claude、Google的Gemini、Meta的AI Llama、Microsoft Copilot或Mistral的Le Chat。当你与AI助手聊天时，你是在与一个大型语言模型交互，该模型直接或借助不同的可用工具（如网络浏览或代码解释器）处理你的请求。
LLM是由数十亿个数值参数（或权重，见下文）组成的深度神经网络，它们学习单词和短语之间的关系，并创建一种语言的表示，一种多维的词汇地图。
这些模型是通过对在数十亿本书籍、文章和转录中发现的模式进行编码而创建的。当你提示LLM时，模型会生成最符合提示的可能模式。
(参见: 神经网络)

Memory cache

内存缓存是指提升推理（即AI努力生成对用户查询的响应的过程）的一个重要过程。本质上，缓存是一种优化技术，旨在使推理更高效。AI显然是由高强度的数学计算驱动的，每次进行这些计算时，它们都会消耗更多的功率。缓存旨在通过保存特定计算以供未来用户查询和操作使用，来减少模型可能必须运行的计算数量。内存缓存有不同的种类，其中较知名的一种是KV（或键值）缓存。KV缓存在基于Transformer的模型中起作用，并通过减少生成用户问题答案所需的时间（和算法劳动）来提高效率，推动更快的结果。
(参见: 推理)

Neural network

神经网络是指支撑深度学习的多层算法结构——而且更广泛地说，是大型语言模型出现后生成式AI工具的整个繁荣。
尽管从人脑密集互连的通路中汲取灵感作为数据处理算法设计结构的想法可以追溯到20世纪40年代，但真正释放这一理论威力的是图形处理硬件（GPU）通过视频游戏行业实现的更为近期的崛起。这些芯片被证明非常适合训练比早期时代可能的多得多的算法层——使基于神经网络的AI系统能够在包括语音识别、自主导航和药物发现在内的许多领域实现更好的性能。
(参见: 大型语言模型 [LLM])

Open source

开源指的是软件——或者越来越多的AI模型——其底层代码公开供任何人使用、检查或修改。在AI领域，Meta的Llama系列模型是一个突出的例子；Linux是操作系统中著名的历史先例。开源方法允许世界各地的研究人员、开发者和公司在彼此的工作基础上进行构建，加速进步，并实现闭源系统无法轻易提供的独立安全审计。闭源意味着代码是私有的——你可以使用该产品，但无法看到它是如何工作的，OpenAI的GPT模型就是如此——这一区别已成为AI行业最具决定性的辩论之一。

Parallelization

并行化意味着同时做许多事情，而不是一件接一件地做——就像让10名员工同时处理项目的不同部分，而不是一名员工按顺序做所有事情。在AI中，并行化是训练和推理的基础：现代GPU专门设计用于并行执行数千次计算，这是它们成为该行业硬件骨干的一个重要原因。随着AI系统变得越来越复杂，模型越来越大，跨多个芯片和多台机器并行化工作的能力已成为决定模型构建和部署速度及成本效益的最重要因素之一。对更好的并行化策略的研究现在本身已成为一个研究领域。

RAMageddon

RAMageddon（内存末日）是一个有趣的新术语，用来形容席卷科技行业的一个不太有趣的趋势：随机存取存储器（RAM）芯片日益短缺，而我们日常生活中使用的几乎所有科技产品都由它驱动。随着AI行业的蓬勃发展，最大的科技公司和AI实验室——都在争相拥有最强大、最高效的AI——购买了如此多的RAM来为其数据中心提供动力，以至于留给我们的已经所剩无几。这种供应瓶颈意味着剩下的东西变得越来越贵。
这包括游戏等行业（主要公司不得不提高游戏机价格，因为更难找到设备所需的内存芯片）、消费电子产品（内存短缺可能导致十多年来智能手机出货量最大幅度的下跌）以及一般企业计算（因为这些公司自己的数据中心无法获得足够的RAM）。预计只有在可怕的短缺结束后，价格的飙升才会停止，但不幸的是，目前并没有太多迹象表明这会很快发生。

Reinforcement learning

强化学习是一种训练AI的方法，系统通过尝试事物并为正确答案获得奖励来学习——就像用零食训练你心爱的宠物一样，只不过这种情况下的“宠物”是神经网络，“零食”是表示成功的数学信号。与在标记示例的固定数据集上训练模型的监督学习不同，强化学习让模型探索其环境，采取行动，并根据其收到的反馈不断更新其行为。这种方法已被证明在训练AI玩游戏、控制机器人以及最近在增强大型语言模型的推理能力方面特别强大。像人类反馈强化学习（RLHF）这样的技术，现在已成为领先AI实验室微调其模型以使其更有用、更准确和更安全的核心。

Token

在人机通信方面，存在一些明显的挑战——人们使用人类语言进行交流，而AI程序通过由数据驱动的复杂算法过程执行任务。词元填补了这一空白：它们是人机通信的基本构建块，代表由LLM处理或生成的离散数据段。它们是通过称为词元化的过程创建的，该过程将原始文本分解为语言模型可以消化的小单元，类似于编译器将人类语言翻译成计算机可以理解的二进制代码。在企业环境中，词元还决定了成本——大多数AI公司按词元收取LLM使用费，这意味着企业使用得越多，支付的费用就越高。

Token throughput

再次强调，词元是AI语言模型在处理语言之前将其分解成的小块文本——通常是单词的一部分而不是整个单词；为了理解AI工作负载，它们大致类似于“单词”。吞吐量指的是在给定时间内可以处理多少数据，因此词元吞吐量本质上是衡量一个系统一次可以处理多少AI工作的指标。高词元吞吐量是AI基础设施团队的一个关键目标，因为它决定了模型可以同时为多少用户提供服务，以及他们每个人能多快收到响应。AI研究员Andrej Karpathy曾描述说，当他的AI订阅处于闲置状态时会感到焦虑——这呼应了他作为一名研究生时，昂贵的计算机硬件未被充分利用时的感觉——这种情绪捕捉到了为什么最大化词元吞吐量在某种程度上成了该领域的痴迷。

Training

开发机器学习AI涉及一个称为训练的过程。简单来说，这指的是输入数据以便模型可以从模式中学习并生成有用的输出。本质上，这是系统响应数据中特征的过程，使其能够将输出调整到寻求的目标——无论是识别猫的图像还是按需生成俳句。
训练可能很昂贵，因为它需要_大量_的输入，而且所需的数量一直在上升——这就是为什么混合方法（例如使用有针对性的数据微调基于规则的AI）可以帮助管理成本，而无需完全从头开始。
[参见: 推理]

Transfer learning

一种将以前训练过的AI模型用作开发不同但通常相关的任务的新模型起点的技术——允许重新应用在以前训练周期中获得的知识。
迁移学习可以通过缩短模型开发时间来提高效率节省。当正在开发模型的任务的数据有些有限时，它也很有用。但需要注意的是，这种方法有局限性。依赖迁移学习获得通用能力的模型可能需要对额外数据进行训练，才能在其专注的领域中表现良好
(参见: 微调)

Weights

权重是AI训练的核心，因为它们决定了用于训练系统的数据中不同特征（或输入变量）被赋予多少重要性（或权重）——从而塑造AI模型的输出。
换一种说法，权重是定义数据集中对于给定训练任务最突出内容的数值参数。它们通过对输入应用乘法来实现其功能。模型训练通常从随机分配的权重开始，但随着过程的展开，当模型试图得出更接近目标的输出时，权重会进行调整。
例如，一个基于目标位置的历史房地产数据训练的预测房价的AI模型，可以包含卧室和浴室数量、房产是独立式还是半独立式、是否有停车位、车库等特征的权重。最终，模型附加到这些输入中的每一个的权重反映了基于给定数据集它们对房产价值的影响程度。

Validation loss

验证损失是一个告诉你AI模型在训练期间学习得有多好的数字——越低越好。研究人员像追踪实时成绩单一样密切追踪它，用它来决定何时停止训练，何时调整超参数，或者是否调查潜在问题。它有助于标记的关键问题之一是过拟合，这是一种模型记住其训练数据而不是真正学习它可以推广到新情况的模式的情况。可以把它想象成真正理解材料的学生和仅仅记住去年考试的学生之间的区别——验证损失有助于揭示你的模型正在变成哪一种。
