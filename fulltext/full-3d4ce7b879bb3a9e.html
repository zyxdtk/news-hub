LLM 能否将意外的观察转化为研究问题、进行实验并自主发现被改变的物理定律？
我们介绍了 LongChang，这是一个自动生成具有改变物理的模拟世界的框架，其中一个或多个定律与普通物理不同。
这种反事实设置用于测试 LLM 是否能在没有研究任务或关于被改变物理定律提示的情况下，独立注意到与普通物理的偏离并对其进行研究。
例如，较重的物体下落较慢可能会引导探索者提出质量如何影响下落的问题，并设计对照比较来测试这种关联。
这些定律对探索者是隐藏的，但可用于评估他们报告的解释。

3.2
自主探索
探索者选择要调查的观察结果，制定自己的研究问题，并通过物理干预测试解释。
初始提示要求自由探索，不提供研究任务或关于改变后物理的提示。
结构化观察提供物体位置、运动和仪器读数，距离以砖块为单位，经过时间以计数为单位。
探索者可以推动或投掷物体、抓取和移动物体、释放物体、等待以及标记参考位置。

一个 LLM 审查者会检查编译后的设计是否具有物理有效性，并在拒绝时返回反馈。
探索者可以修改被拒绝的设计并重新提交，成功的设计将被安装到当前场景中。
安装完成后，探索者可以在装置上放置物体或调整其关节，并在下一次观察时收到更新的运动读数。
在每一轮中，探索者记录其观察结果和行动理由，然后采取行动并接收更新的观察结果。
这一循环持续进行，直到其停止或达到轮次上限，同时保留所有尝试中的笔记、行动、观察结果和反馈。
最终报告会总结该记录中的观察结果和解释。
每个结论必须引用支持性的轮次，并且只能使用笔记中已记录的解释，同时保留其中所述的不确定性。
探索者也可以报告其在探索过程中未发现任何异常。
3.3
发现评估
一个 LLM 评判者会根据被改变的物理定律和完整的探索记录来评估报告，要求发现结果满足定律正确性（C）和证据支持（S）。
定律正确性要求识别出每个被改变的物理定律，包括其目标对象、条件、触发因素以及在报告单位中可识别的常数。
如果所提出的机制在允许的干预下产生相同的可观测预测，则这些机制可以有所不同。
证据支持要求有记录的实验来证明所有

在所述确定性水平上的目标和推理。
正确的猜测可能仅通过C。有支持的普通观察或部分发现可能仅满足S。

6
结论
LongChang 检验了 LLM 能否将意外观察转化为研究问题，并通过实验发现被改变的物理定律。
被评估的 LLM 在没有研究任务或关于这些定律的任何提示的情况下操纵物体并构建工具。
在十二个被评估的 LLM 中，只有一个做出了发现，这揭示了将观察转化为完整且有实验支持的定律的难度。
未解答的问题和已纠正

探索记录中的错误会引导独立的 LLM 智能体演化场景，在没有人工干预的情况下继续发现循环。
该框架支持对能够自主决定研究内容并设计实验以解决关于这些世界物理定律不确定性的 LLM 的研究。

7
局限性
本研究考察 LLM 是否会在模拟世界中主动发起调查并发现被改变的物理定律。
我们的结果表明，这项任务对当前的 LLM 而言仍然具有挑战性。
被改变的物理定律为评估发现提供了明确的依据，而现实世界中的许多科学问题仍未解决。
要将该框架扩展到这些开放性问题，需要在答案尚未确立的环境下进一步研究如何评估探索过程及其发现。

8
伦理考量
LongChang 不使用人工标注或测试，并在无人工干预的情况下评估 LLM。
因此，该评估不会引发与参与者隐私或知情同意相关的伦理问题。
